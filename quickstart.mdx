## 1. Install and launch

Download Enconvo from [enconvo.com](https://www.enconvo.com), open the DMG, and drag the app into **Applications**. Current builds target **macOS 14 or later**; choose the download for your Mac's processor.

Open the app and grant the [permissions](/configuration/permissions) needed for the features you will use. You can configure screen and microphone access when you first need them.

## 2. Choose AI access

| Option | Setup |
| --- | --- |
| Enconvo Cloud Plan | Sign in to your Enconvo account and choose a Cloud provider |
| Your own API key | Open **Settings → AI Model**, select a provider, and configure Authentication |
| Supported subscription connection | Choose the subscription/account tab offered by the provider and connect |
| Local models | Configure [Ollama](/providers/ollama), [LM Studio](/providers/lm-studio), or [MLX](/ai/local-llm) |

See your account and the [pricing page](/pricing) for current entitlements and usage. Your model provider's API billing is separate from buying an Enconvo app license.

## 3. Ask a small question

1. Open **SmartBar** using its shortcut, normally **Shift + Command + D**.
2. Type: “Give me a three-item checklist for a productive morning.”
3. Submit and wait for the reply.
4. Review the result and use the response's copy action if you want to keep it.

If nothing happens, check **Settings → Shortcut** and confirm your provider is configured. Shortcuts are customizable.

## 4. Try your own context

Select a short paragraph in another app and try **Summarize** or **Explain** through [PopBar](/features/popbar). For a visible app window, use [Appshots](/features/appshots). Check the captured context before sending it to your model.

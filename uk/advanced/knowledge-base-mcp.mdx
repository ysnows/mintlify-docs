---

Enconvo може надавати ваші бази знань клієнтам ШІ, сумісним з MCP, на тому самому Mac. Клієнти можуть шукати й читати бази знань, до яких ви надали доступ, і більше нічого; доступ лише для читання. Це окремо від **Параметри → Сервери MCP**, що додає зовнішні інструменти до Агентів Enconvo.

## Підключіть клієнт

1. Відкрийте [Базу знань](/uk/ai/knowledge-base), натисніть шестірню (**Параметри бази знань**), а потім **Клієнти ШІ (MCP)**.
2. Увімкніть **Увімкнути MCP бази знань**. Типово вимкнено, і поки вимкнено, підключені клієнти отримують відмову.
3. Виберіть, що можуть бачити клієнти. **Поділитися цією базою знань із клієнтами ШІ** стосується тієї, яку ви відкрили, а **Спільні бази знань** перелічує їх усі. Історія диктування та Пам’ять приховані, доки ви їх не ввімкнете.
4. У розділі **Під’єднати клієнт** виберіть свій клієнт (Claude Code, Cursor, Codex або Claude Desktop) і скопіюйте його налаштування.
5. Попросіть клієнт перелічити бази знань, потім пошукати в одній з них і прочитати відповідний елемент.

Локальна кінцева точка:

```text
http://localhost:54535/knowledge_base/mcp
```

Вона використовує транспорт Streamable HTTP. Тримайте Enconvo запущеним, поки клієнт ним користується. Claude Desktop підключається через невеликий міст, `mcp-remote`, тому для його налаштування потрібен Node.js; дотримуйтеся інструкцій для клієнта, показаних у діалозі.

## Доступні інструменти

| Інструмент | Призначення |
| --- | --- |
| `kb_list` | Перелічити видимі бази знань |
| `kb_search` | Шукати у видимій базі знань |
| `item_list` | Перелічити елементи у видимій базі знань |
| `item_read` | Читати проіндексований текст елемента сторінками |

Інструменти лише для читання. Ця кінцева точка не надає загальних інструментів Пам’яті чи Записів. Читання елемента може повернути шлях до його джерела або URL-адресу як метадані.

## Доступ і обробка

Сервер приймає лише петльові з’єднання й не вимагає токена. Увімкнення дає змогу локальним процесам читати бази знань, до яких ви надали доступ. Підключений клієнт ШІ може надіслати отримане своєму провайдеру моделі, тож перегляньте й параметри цього клієнта.

Пошук використовує модель вбудовування, задану в розділі **Пошук** у **Параметри → Пам’ять**. Коли вона працює в Enconvo Cloud, текст пошуку надсилається туди. «Локальна кінцева точка» не означає, що кожна частина пошуку й відповіді працює офлайн.

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| З’єднання відхилено | Переконайтеся, що Enconvo та його локальний API запущено. |
| Forbidden / 403 | Перевірте, що **Увімкнути MCP бази знань** увімкнено, що клієнт підключається з цього Mac і що його конфігурація збігається з діалогом. |
| Базу знань не знайдено | Увімкніть базу знань у розділі **Спільні бази знань**. Приховані та відсутні бази знань виглядають для клієнтів однаково. |
| Відкриття URL-адреси в браузері показує 405 | GET-запит браузера — це не запит MCP. Підключайтеся клієнтом MCP. |
| Довгий документ повертається неповним | Попросіть клієнт запросити подальші сторінки через `item_read`. |

Щоб зупинити весь доступ, вимкніть **Увімкнути MCP бази знань**. Щоб звузити те, що можуть отримувати клієнти, вимкніть окремі бази знань у розділі **Спільні бази знань**.

Enconvo може віддавати ваші бази знань MCP-сумісним ШІ-клієнтам на тому самому Mac. Клієнти можуть шукати й читати лише ті бази, якими ви ділитеся; доступ лише для читання. Це окремо від **Параметри → Сервери MCP**, де до агентів Enconvo додаються зовнішні інструменти.

## Під’єднати клієнт

1. Відкрийте [базу знань](/uk/ai/knowledge-base) і натисніть шестерню (**Параметри бази знань**), потім **Клієнти ШІ (MCP)**.
2. Увімкніть **Увімкнути MCP бази знань**. За замовчуванням це вимкнено, і поки вимкнено, підключені клієнти отримують відмову.
3. Виберіть, що клієнти можуть бачити. **Поділитися цією базою знань із клієнтами ШІ** стосується відкритої бази, а **Спільні бази знань** показують усі. Історія диктування та пам’ять приховані, доки ви їх не увімкнете.
4. У розділі **Під’єднати клієнт** виберіть клієнт (Claude Code, Cursor, Codex або Claude Desktop) і скопіюйте його налаштування.
5. Попросіть клієнт показати список баз знань, потім знайдіть одну й прочитайте знайдений елемент.

Локальна кінцева точка:

```text
http://localhost:54535/knowledge_base/mcp
```

Вона використовує транспорт Streamable HTTP. Поки клієнт нею користується, Enconvo має працювати. Claude Desktop підключається через невеликий місток `mcp-remote`, тому для його налаштування потрібен Node.js; дотримуйтеся інструкцій для конкретного клієнта в діалозі.

## Доступні інструменти

| Інструмент | Призначення |
| --- | --- |
| `kb_list` | Список видимих баз знань |
| `kb_search` | Пошук у видимій базі знань |
| `item_list` | Список елементів у видимій базі знань |
| `item_read` | Читання проіндексованого тексту елемента сторінками |

Інструменти лише для читання. Ця кінцева точка не відкриває загальних інструментів пам’яті чи записів. Читання елемента може повернути шлях до джерела або URL як метадані.

## Доступ і обробка

Сервер приймає лише з’єднання з loopback і не потребує токена. Увімкнення дозволяє локальним процесам читати бази знань, якими ви ділитеся. Підключений ШІ-клієнт може надсилати отримане власному провайдеру моделі, тому перегляньте також параметри цього клієнта.

Пошук використовує модель ембедингів, задану в розділі **Пошук** у **Параметри → Пам’ять**. Коли вона працює на Enconvo Cloud, текст пошуку надсилається туди. «Локальна кінцева точка» не означає, що пошук і відповідь повністю виконуються офлайн.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| З’єднання відхилено | Переконайтеся, що Enconvo і його Local API запущені. |
| Forbidden / 403 | Перевірте, що **Увімкнути MCP бази знань** увімкнено, що клієнт підключається з цього Mac і що його конфігурація збігається з діалогом. |
| Базу знань не знайдено | Увімкніть базу в розділі **Спільні бази знань**. Для клієнтів прихована і відсутня база виглядають однаково. |
| Відкриття URL у браузері показує 405 | GET з браузера — це не запит MCP. Підключайтеся клієнтом MCP. |
| Довгий документ повертається неповністю | Попросіть клієнт запитати наступні сторінки через `item_read`. |

Щоб зупинити будь-який доступ, вимкніть **Увімкнути MCP бази знань**. Щоб скоротити те, що клієнти можуть отримувати, вимкніть окремі бази в розділі **Спільні бази знань**.

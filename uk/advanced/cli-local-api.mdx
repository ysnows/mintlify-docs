Ця сторінка для розробників і досвідчених користувачів, які хочуть керувати Enconvo з Terminal, скрипта чи іншої програми. Команда `enconvo` поставляється разом із десктопною програмою Enconvo, окремого встановлення не потрібно, а програма віддає маршрути кожного встановленого плагіна через локальний HTTP API.

У цьому відео йдеться про сторінку API, посібник із CLI та хуки.

Для команд, які користуються локальним середовищем, Enconvo має бути запущений.

## Знайдіть команди

```bash
enconvo -h
enconvo knowledge_base -h
```

Додайте `-h` до команди, яку розглядаєте, щоб побачити її поточні підкоманди та параметри.

Відкрийте **Параметри → Посібник із CLI**, щоб побачити встановлені розширення з командами CLI. Натисніть назву, щоб скопіювати команду `enconvo <name> -h`. Список установлених розширень визначає, що підтримує ваша програма.

Якщо оболонка не знаходить `enconvo`, відкрийте посібник із CLI програми й перевірте версію встановленої програми та налаштування командного рядка.

## Виклик локального API

Програма віддає кожен маршрут за адресою `http://localhost:54535/api/<extension>/<route>`. Надішліть `POST` із тілом JSON:

```bash
curl -X POST http://localhost:54535/api/enconvo/extension/available_list \
  -H "Content-Type: application/json" \
  -d '{}'
```

Відкрийте **Параметри → API** і натисніть **Перевірити API**, щоб переглянути доступні маршрути та схеми запитів, з прикладом для кожного. Під час інтеграції беріть схему встановленої збірки: параметри маршрутів можуть змінюватися разом із розширеннями.

## Запустіть агента або ШІ-команду ззовні Enconvo

У параметрах кожного агента та кожної ШІ-команди є рядок **Посилання, CLI та API**. Він показує посилання, команду `enconvo` та виклик локального API, які запускають їх з вашим текстом і файлами, готові до копіювання.

| Спосіб | Що робить |
| --- | --- |
| Link | Відкриває новий чат і запускає там агента або ШІ-команду |
| CLI | Запускає у тлі і виводить відповідь |
| Local API | Запускає у тлі і повертає відповідь |

Посилання має такий вигляд:

```text
enconvo://<extension>/<command>?input_text=<text>&window=<window>&files=<path>
```

- `input_text` — текст, який треба надіслати.
- `window` — `chat_window` або `dynamic_island`. Пропустіть його, щоб запустити в SmartBar.
- `files` додає файл за абсолютним шляхом або шляхом вигляду `~/`. Повторіть його для кількох файлів, наприклад щоб надіслати зображення з іншої програми чи скрипта.

З Terminal:

```bash
enconvo agent call "What's on my calendar today?"
enconvo ai-command run 'writing_package|translate' --input-text "Bonjour" --files ~/Desktop/note.png
enconvo writing_package convert_to_list "eggs, milk, bread"
```

Команди для письма, наприклад Translate, Summarize і Convert to List, беруть текст як аргумент і відповідають, не додаючи чат до історії. `enconvo agent main` відповідає в новому чаті, коли агент зайнятий у своєму останньому.

Відповідні маршрути локального API: `agent/call` (`agentId`, `message`, `context_files`) та `ai-command/run` (`command_key`, `input_text`, `files`).

### Стежте за запущеними чатами

- `agent/session/list` перелічує чати, які зараз виконуються, для всіх агентів і проєктів, разом із чатами Claude Code і Codex, з назвою, агентом і проєктом кожного. Передайте `filter: "waiting"` для чатів, які чекають вашої відповіді, або `"active"` для обох.
- `agent/session/status` перевіряє один чат за його `sessionId`.
- `agent/session/steer` додає повідомлення до ходу, який чат виконує зараз, не зупиняючи його. Чат, який не виконується, відповідає `not_running`; новий хід починайте через `agent/call`. Запуск нижче повного доступу не може керувати ходом Enconvo.

## Користуйтеся безпечно

Якщо клієнту ШІ потрібний лише пошук у базі знань, використовуйте окреме з’єднання [MCP бази знань](/uk/advanced/knowledge-base-mcp), а не відкривайте загальний локальний API.

Локальний API і доступ до оболонки — це широкі можливості: команди можуть читати або змінювати локальні дані залежно від реалізації. У скриптах явно вказуйте команду, вхідні дані та призначення.

Збережені ключі API повертаються як `[hidden]`, коли програма читає параметри через локальний API, і лише власні вікна Enconvo можуть змінити, куди надсилається збережений ключ. Див. [Облікові дані](/uk/configuration/credentials).

Гаряча клавіша, яку ви задаєте через локальний API, може використовувати короткі назви модифікаторів (`cmd`, `ctrl`, `alt`, `opt`, `fn`) або їх символи. Клавіша со словом, якого Enconvo не знає, не реєструється, а клавіша, яка вводить символ, потребує Command, Control, Option або Function.

Enconvo розділяє програму та ШІ, який вона викликає. Ліцензія відкриває програму. ШІ може надходити з балів Enconvo Cloud, вашого власного ключа API, плану провайдера, до якого ви входите, або з моделі на вашому Mac, і кожен варіант оплачується окремо. Актуальні плани та ціни, доступні для вашого облікового запису, дивіться в **Параметри → Обліковий запис** і на сайті Enconvo.

## Способи оплатити ШІ

| Доступ | Що покриває | Де видно використання |
| --- | --- | --- |
| Довічна ліцензія Enconvo | Доступ до функцій програми | **Довічна ліцензія** в **Параметри → Обліковий запис** |
| План Enconvo Cloud | Хмарні моделі та служби, оплата балами | **Параметри → Використання балів** |
| Ваш власний ключ API | Запити до цього провайдера | Обліковий запис API самого провайдера |
| План провайдера, до якого ви входите | Підтримувані планом функції та ліміти | Сторінка провайдера в Параметрах |
| Локальні моделі | Працюють на обчислювальній потужності, пам’яті та сховищі вашого Mac, плюс завантаження моделей | Ваш Mac |

Купівля ліцензії на програму не додає платного кредиту API в жодного провайдера. Чат-план провайдера теж не включає всі API цього провайдера.

## Плани Enconvo

- **Довічна ліцензія**: одноразова покупка програми, рівні Standard і Premium, з бонусними балами. Користуйтеся ШІ зі своїми ключами API скільки завгодно. Teams — це довічна ліцензія для організацій: ви купуєте місця (Seats) і призначаєте кожне за електронною поштою. Дивіться [Teams](/uk/configuration/account).
- **Enconvo Cloud**: щомісячний або щорічний план рівнів Plus, Pro і Max. Він щомісяця додає бали та хмарні моделі, яким не потрібен ключ API.
- **Пробний період Standard**: безкоштовний обліковий запис може отримати одноразовий 7-денний пробний період Standard без картки. Коли його пропонують, у **Параметри → Обліковий запис** з’являється **Почати пробний період**.
- **Коди**: коди ліцензій і пробних періодів активуються в **Параметри → Активувати код**. Код Teams License робить ваш обліковий запис адміністратором команди для місць із цього коду, по 50 000 хмарних балів на місце.

Довічні ліцензії завжди називаються Standard і Premium, тож їхні назви не збігаються з хмарними планами Plus і Pro.

## Як витрачаються хмарні бали

Спершу витрачаються бали підписки. Під час кожного поновлення вони скидаються до обсягу вашого плану. Бали поповнення, з пакетів поповнення та довічних ліцензій, ніколи не згорають.

Вартість запиту залежить від моделі та способу доступу, який насправді використовує функція. Текст, зображення, відео, транскрибування, вбудовування та голос у реальному часі можуть мати різні ціни.

## Перевірка несподіваного використання

1. Відкрийте **Параметри → Використання балів** для Enconvo Cloud або сторінку використання самого провайдера для власних ключів API.
2. Відкрийте **Параметри → Статистика використання**, щоб побачити орієнтовну вартість, токени та запити за моделлю, провайдером і функцією.
3. Шукайте заплановані завдання, тривалі завдання, пошукові запити та запити генерації, що використовують той самий профіль провайдера.

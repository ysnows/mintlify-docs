Enconvo розділяє застосунок і ШІ, який він викликає. Ліцензія відкриває застосунок. ШІ може надходити з балів Enconvo Cloud, вашого власного ключа API, тарифу провайдера, в який ви входите, або моделі на вашому Mac, і кожен варіант оплачується окремо. Перевірте **Параметри → Обліковий запис** і сайт Enconvo, щоб побачити тарифи й ціни, доступні вашому обліковому запису зараз.

## Способи оплати ШІ

| Доступ | Що покриває | Де видно використання |
| --- | --- | --- |
| Довічна ліцензія Enconvo | Доступ до функцій застосунку | **Довічна ліцензія** в **Параметри → Обліковий запис** |
| Тариф Enconvo Cloud | Хмарні моделі та сервіси, оплачені балами | **Параметри → Використання балів** |
| Ваш власний ключ API | Запити до цього провайдера | Власний обліковий запис API провайдера |
| Тариф провайдера, в який ви входите | Підтримувані функції та ліміти тарифу | Сторінка провайдера в параметрах |
| Локальні моделі | Запуск на обчислювальній потужності, пам’яті та сховищі Mac, плюс будь-які завантаження моделей | Ваш Mac |

Купівля ліцензії застосунку не додає платного кредиту API жодного провайдера. Тариф чату провайдера також не включає всі його API.

## Тарифи Enconvo

- **Довічна ліцензія**: разова купівля застосунку, рівні Standard і Premium, з бонусними балами. Використовуйте ШІ з власними ключами API скільки завгодно. Teams — це довічна ліцензія для організацій: ви купуєте місця (Seats) і призначаєте кожне електронною поштою. Див. [Teams](/uk/configuration/account).
- **Enconvo Cloud**: місячний або річний тариф рівнів Plus, Pro і Max. Щомісяця додаються бали та хмарні моделі, яким не потрібен ключ API.
- **Пробний період Standard**: безкоштовний обліковий запис може отримати разовий 7-денний пробний період Standard без картки. Коли він пропонується, у **Параметри → Обліковий запис** з’являється **Почати пробний період**.
- **Коди**: коди ліцензії та пробного періоду активуються в **Параметри → Активувати код**. Код ліцензії Teams робить ваш обліковий запис адміністратором команди для місць цього коду, з 50 000 хмарних балів на кожне місце.

Довічні ліцензії завжди називаються Standard і Premium, тож вони не ділять назву з хмарними тарифами Plus і Pro.

## Як витрачаються хмарні бали

Спершу витрачаються бали підписки. Вони скидаються до кількості вашого тарифу при кожному поновленні. Бали поповнення, з пакетів поповнення та довічних ліцензій, ніколи не спливають.

Скільки коштує запит, залежить від моделі та способу доступу, який функція справді використовує. Текст, зображення, відео, транскрибування, вбудовування та голос у реальному часі можуть мати різну ціну.

## Перевірити неочікуване використання

1. Відкрийте **Параметри → Використання балів** для Enconvo Cloud або власну сторінку використання провайдера для ваших ключів API.
2. Відкрийте **Параметри → Статистика використання**, щоб побачити орієнтовну вартість, токени та запити за моделлю, провайдером і функцією.
3. Пошукайте заплановані завдання, довгі завдання, пошук у власних документах і запити генерації, які ділять один профіль провайдера.

SmartBar — це панель запуску, яку ви відкриваєте з будь-якої програми, щоб поставити запитання Агентові або виконати команду. Натисніть **⌥Space**, введіть текст і натисніть Return. Звертайтеся до неї, коли потрібна швидка відповідь, а потім повертайтеся до того, що робили.

Для інших завдань використовуйте [Вікно чату](/uk/ai/chat) для довгих розмов і файлів, [Бічну панель програми](/uk/features/app-sidebar), щоб працювати поруч з однією програмою, [PopBar](/uk/features/popbar), щоб діяти над виділеним текстом, або [Dynamic Island](/uk/features/dynamic-island) та [Улюбленця на робочому столі](/uk/features/pet) для невеликої точки входу, що залишається на екрані. [Керування вікнами](/uk/features/window-management) порівнює їх усі.

## Поставте запитання

1. Натисніть **⌥Space** або гарячу клавішу, яку ви задали в **Параметри → SmartBar**.
2. Введіть запитання. Якщо потрібно, спершу виберіть іншого Агента чи модель.
3. Долучіть контекст, потрібний Агентові. Він не бачить усіх відкритих програм; дивіться [Додавання контексту](#додавання-контексту).
4. Натисніть Return і стежте за відповіддю чи перебігом роботи інструментів. Щоб зупинити відповідь, натисніть круглу кнопку зупинки.
5. Скопіюйте результат або введіть уточнення, щоб продовжити розмову. Повідомлення, яке ви вводите, поки завдання виконується, показується одразу.

Коли ваші слова збігаються з командою, Return виконує підсвічений рядок. Щоб натомість надіслати свої слова Агентові, натисніть **⌘Return** або клацніть **Надіслати до ШІ**. **⌥Return** виконує другу дію рядка.

У режимі Агента чип **Дозволи** визначає, коли Агент питає перед дією, а його перемикач **Пісочниця** обмежує команди Агента робочою текою. Дивіться [Пісочниця Агента](/uk/configuration/sandbox).

## Пошук за допомогою символів-тригерів

Введіть у SmartBar один із цих символів, щоб шукати елементи одного виду:

| Введіть | Щоб |
| --- | --- |
| `@` | Шукати команди |
| `#` | Додати контекст |
| `$` | Використати навичку |
| `>` | Показати останні завдання |
| `/` | Відкрити дії, як-от вибір моделі та міркувань |

Перші чотири можна змінити в розділі **Пошук** у **Параметри → SmartBar**. `/` змінити не можна.

Вибирайте елементи зі списку, що відкривається, а не вводьте назву з пам’яті: список показує команди та джерела контексту, які у вас справді є. Дивіться [Інструменти для письма](/uk/features/writing-tools), [Швидкі посилання](/uk/features/quick-links) і [Розуміння контексту](/uk/features/context-awareness).

Деякі списки відкриваються за псевдонімом: введіть псевдонім і пропуск, і всередині SmartBar відкриється [Історія буфера обміну, Пошук закладок чи Пошук файлів](/uk/features/clipboard-history).

## Додавання контексту

SmartBar може підхопити виділений текст, виділене у Finder і поточну сторінку браузера в момент відкриття. Виберіть **Долучати**, **Запропонувати** або **Вимкнено** для кожного в **Параметри → Розуміння контексту**. Щоб додати щось інше, введіть `#` і виберіть джерело.

## Вибір макета

**Макет** в **Параметри → SmartBar** визначає, що ви бачите, коли SmartBar відкривається:

| Макет | Що відкривається |
| --- | --- |
| **Лише введення** | Тільки поле введення |
| **Введення та панель інструментів** | Введення, а також швидкі дії, вибір моделі та голосове керування |
| **Повна панель** | Усе це, а також список під полем введення |

У **Повна панель** параметр **Початковий вигляд** визначає, що список показує, поки ви нічого не ввели: **Рекомендовані запити** або **Список команд**. У будь-якому макеті список і результати все одно з’являються, щойно ви вводите текст чи виконуєте команду.

## Параметри

Відкрийте **Параметри → SmartBar**.

| Параметр | Що він змінює |
| --- | --- |
| **Гаряча клавіша** | Відкриває й закриває SmartBar з будь-якої програми. Типова: **⌥Space**. |
| **Типовий агент** | Агент, який відповідає на те, що ви вводите. |
| **Автоматично очищати бесіду** | Починає нову розмову, коли SmartBar відкривається після того, як був закритий так довго, від **Ніколи** до **Щоразу під час відкриття**. |
| **Макет** | Що ви бачите, коли SmartBar відкривається (дивіться вище). |
| **Вигляд** | Світле чи темне скло для SmartBar і Бічної панелі програми або **Як у програмі**. |
| **Автоперемикання джерела вводу** | Перемикається на це джерело вводу, поки ви друкуєте в SmartBar, і назад, коли він закривається. |
| **Клавіші навігації** | Скорочення з клавішею Control для переходу списками й текстом: **macOS** (⌃N ⌃P ⌃F ⌃B) або **Vim** (⌃J ⌃K ⌃L ⌃H). |
| **Пошук** | Символи-тригери для команд, контексту, навичок і останніх завдань. |
| **Калькулятор** | Відповідає на математичні вирази, одиниці, валюти, дати й часові пояси, поки ви друкуєте. Увімкнено за замовчуванням. |
| **Погода й авіарейси** | Також шукає погоду, авіарейси та час у будь-якому місці. Вимкнено за замовчуванням. |

Зміна типового значення не змінює всі наявні чати. [Вибір моделі](/uk/ai/model-selection-guide) пояснює, як кожен чат зберігає власний вибір моделі та міркувань.

## Голос і обчислення

Клацніть мікрофон, щоб промовити запитання через [Диктування](/uk/features/dictation). Для розмови вголос запустіть [Live Talk](/uk/features/live-voice); виклик, який ви починаєте з SmartBar, переходить у Dynamic Island.

Введіть арифметичний вираз, наприклад `2+3*4`, і SmartBar покаже результат. Калькулятор також переводить одиниці й валюти, працює з датами та часовими поясами й ділить суму, як-от `25% off $60 split by 3`. Перевірте результат і дію, яку він пропонує, перш ніж копіювати його.

Щоб дізнатися погоду, рейс чи час у певному місці, увімкніть **Погода й авіарейси** в **Параметри → SmartBar**. Потім введіть `weather in London`, `Tokyo feels like`, номер рейсу, наприклад `BA008`, або `time in Chernivtsi`. Надсилається лише назва місця чи номер рейсу, до Open-Meteo, adsbdb і adsb.lol. **Погода й авіарейси** спільні з калькулятором [Dynamic Island](/uk/features/dynamic-island).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| SmartBar не відкривається | Перевірте **Гаряча клавіша** в **Параметри → SmartBar** і пошукайте іншу програму, що використовує те саме скорочення. Якщо ви раніше задали власну клавішу, вона залишається такою, як ви її задали. |
| Return виконує команду замість того, щоб запитати Агента | Натисніть **⌘Return** або клацніть **Надіслати до ШІ**. |
| Обчислення чи погода нічого не показують | Перевірте **Калькулятор** і **Погода й авіарейси** в **Параметри → SmartBar**. |
| У контексті бракує програми чи виділеного тексту | Перевірте [Дозволи](/uk/configuration/permissions) і **Параметри → Розуміння контексту**. |
| Запит завершується помилкою | Перевірте вибраного провайдера й прочитайте повідомлення про помилку. |
| На цій сторінці бракує елемента керування | Ваша збірка може бути старішою за цей посібник. Дивіться [Оновлення](/uk/configuration/updates). |

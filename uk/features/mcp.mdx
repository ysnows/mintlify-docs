[Model Context Protocol (MCP)](https://modelcontextprotocol.io) — це відкритий стандарт, який дозволяє моделям ШІ використовувати зовнішні інструменти і дані. Кожен сервер MCP пропонує інструменти, які агент може викликати, як-от читання файлів, запит до бази даних або надсилання повідомлення. Додайте сервер в Enconvo, і агенти використовують його інструменти самі, коли завдання їх потребує.

## Додати сервер у Параметрах

<Steps>
  <Step title="Відкрийте сервери MCP">
    Відкрийте **Параметри** з іконки Enconvo в рядку меню (**Параметри...**) або натисніть **⌘,**. Потім відкрийте **Параметри → Сервери MCP**.
  </Step>
  <Step title="Додайте сервер">
    Натисніть **Додати сервер** і введіть **Назва сервера**. Оберіть транспорт: **STDIO** для команди, яка працює на вашому Mac, або **HTTP** чи **SSE** для сервера за URL. Заповніть поля і натисніть **Зберегти**.
  </Step>
  <Step title="Перевірте, що він підключається">
    Крапка поруч із сервером стає зеленою, і його рядок показує, скільки в нього інструментів. Натисніть лічильник інструментів, щоб побачити їх.
  </Step>
  <Step title="Оберіть, де застосовуються його інструменти">
    Використовуйте перемикач у рядку сервера. Увімкнено: Enconvo включає інструменти сервера щоразу, коли асистент готує відповідь, скрізь. Вимкнено: вони не завантажуються скрізь, але ви все одно можете додати сервер зі SmartBar або увімкнути його для однієї програми в бічній панелі програми.
  </Step>
</Steps>

Сервери, які використовують OAuth, відкривають сторінку входу вперше, коли ви підключаєтесь. Якщо сервер показує **Автентифікувати**, натисніть і завершіть вхід. **Надати доступ** з’являється, коли підключений сервер просить більше доступу, ніж дав ваш вхід.

Сервери, які постачаються з плагіном, перелічені в **З плагінів**.

<Tip>
Бічна панель Параметрів довга. Натисніть **⌘F** у Параметрах і введіть «MCP», щоб перейти до панелі, або відкрийте її глибоким посиланням `enconvo://preference?pane=mcp_management`.
</Tip>

## Додати сервер з CLI

```bash
# Add a stdio server
enconvo mcp add github --command npx --args "-y @modelcontextprotocol/server-github"

# Add an HTTP server
enconvo mcp add notion --transport http --url "https://mcp.notion.com/mcp"

# List servers
enconvo mcp servers list

# List tools
enconvo mcp tools list
```

## Імпортувати сервери з іншої програми

Принесіть конфігурації MCP, які ви вже використовуєте в Claude Desktop, Cursor або іншому інструменті.

1. У **Параметри → Сервери MCP** натисніть **Імпортувати**.
2. У **Формат конфігурації** оберіть **Claude Desktop** або **Codex CLI**.
3. Вставте конфігурацію в **Конфігурація JSON**.
4. Натисніть **Імпортувати**. Кожен сервер у ній додається.

## Інсталювати пакунок MCP

Пакунок MCP — це файл `.mcpb`, який пакує сервер для роботи на вашому Mac. У **Параметри → Сервери MCP** натисніть **Інсталювати пакунок** і оберіть файл. Відкриття файлу `.mcpb` у Finder приводить у те саме місце.

Сервер пакунка працює на вашому Mac з вашими дозволами, тож інсталюйте пакунки лише від людей, яким довіряєте. Щоб оновити, інсталюйте новіший файл `.mcpb`.

## Поділитися посиланням для інсталяції

Посилання для інсталяції додає сервер MCP в Enconvo одним клацанням. Воно використовує той самий формат, що й `mcp.json`: назву і конфігурацію транспорту.

```
https://enconvo.com/mcp/install?name=$NAME&config=$BASE64_ENCODED_CONFIG
```

| Компонент | Опис |
|-----------|-------------|
| `https://enconvo.com` | Вебсторінка інсталяції |
| `/mcp/install` | Шлях |
| `name` | Параметр запиту для назви сервера |
| `config` | Параметр запиту для конфігурації JSON у base64 |

Вебсторінка відкриває глибоке посилання `enconvo://` і показує конфігурацію сервера на випадок, якщо програма не відкриється.

### Зробити посилання

1. Отримайте назву сервера і конфігурацію JSON.
2. Зробіть `JSON.stringify` конфігурації, потім закодуйте в base64.
3. Замініть `$NAME` і `$BASE64_ENCODED_CONFIG` назвою і закодованою конфігурацією.

Наприклад, ця конфігурація:

```json Single MCP server config
{
  "exa": {
    "url": "https://mcp.exa.ai/mcp"
  }
}
```

дає такі результати:

### Що відбувається, коли хтось його відкриває

1. Вони натискають посилання або вставляють його в браузер.
2. Enconvo запитує **Додати сервер MCP «name»?** і показує, що сервер запускає або до чого підключається. Вони натискають **Додати**.
3. Відкриваються **Параметри → Сервери MCP**, і сервер додається і починає підключатися.
4. Щойно він підключений, агенти можуть використовувати його інструменти.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Сервер не запускається | Перевірте команду і аргументи. Для сервера STDIO переконайтеся, що програму інстальовано і вона в `PATH`. Для сервера Node.js переконайтеся, що доступні `npx` або `node`. |
| Його інструменти не з’являються | Перевірте, що крапка сервера зелена. Деяким серверам потрібен ключ API, перш ніж вони пропонують інструменти. Вимкніть сервер і увімкніть знову. |
| Сервер показує **Автентифікувати** | Натисніть і завершіть вхід на сторінці, що відкриється. |
| Помилки автентифікації | Перевірте, що ключі API правильні і не закінчилися, і що змінні середовища, потрібні серверу, задано. |

Повну специфікацію MCP див. на [modelcontextprotocol.io](https://modelcontextprotocol.io).

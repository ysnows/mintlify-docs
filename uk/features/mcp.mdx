[Model Context Protocol (MCP)](https://modelcontextprotocol.io) — відкритий стандарт, який дає моделям ШІ змогу користуватися зовнішніми інструментами та даними. Кожен сервер MCP пропонує інструменти, які може викликати агент: читати файли, виконувати запити до бази даних, надсилати повідомлення. Додайте сервер до Enconvo, і агенти самі користуватимуться його інструментами, коли це потрібно для завдання.

## Додавання сервера в параметрах

<Steps>
  <Step title="Відкрийте Сервери MCP">
    Відкрийте **Параметри** через значок Enconvo в рядку меню (**Параметри...**) або натисніть **⌘,**. Потім відкрийте **Параметри → Сервери MCP**.
  </Step>
  <Step title="Додайте сервер">
    Натисніть **Додати сервер** і введіть **Назву сервера**. Виберіть транспорт: **STDIO** для команди, що виконується на вашому Mac, або **HTTP** чи **SSE** для сервера за URL-адресою. Заповніть його поля й натисніть **Зберегти**.
  </Step>
  <Step title="Переконайтеся, що він підключається">
    Індикатор біля сервера стає зеленим, а в його рядку показано кількість інструментів. Натисніть на кількість інструментів, щоб побачити їх.
  </Step>
  <Step title="Виберіть, де діють його інструменти">
    Скористайтеся перемикачем у рядку сервера. Увімкнено: Enconvo додає інструменти сервера щоразу, коли помічник готує відповідь, усюди. Вимкнено: вони не завантажуються всюди, але сервер усе одно можна додати зі SmartBar або ввімкнути для одного застосунку в Бічній панелі програми.
  </Step>
</Steps>

Сервери з OAuth відкривають сторінку входу під час першого підключення. Якщо біля сервера з'явилося **Автентифікуватися**, натисніть його й завершіть вхід. Кнопка **Надати доступ** з'являється, коли підключений сервер просить більше доступу, ніж надав ваш вхід.

Сервери, що постачаються з плагіном, наведено в розділі **З плагінів**.

<Tip>
Бічна панель параметрів довга. Натисніть **⌘F** у параметрах і введіть «MCP», щоб перейти до цього розділу, або відкрийте його за deeplink `enconvo://preference?pane=mcp_management`.
</Tip>

## Додавання сервера через CLI

```bash
# Add a stdio server
enconvo mcp add github --command npx --args "-y @modelcontextprotocol/server-github"

# Add an HTTP server
enconvo mcp add notion --transport http --url "https://mcp.notion.com/mcp"

# List servers
enconvo mcp servers list

# List tools
enconvo mcp tools list
```

## Імпорт серверів з іншого застосунку

Перенесіть конфігурації MCP, які ви вже використовуєте в Claude Desktop, Cursor або іншому інструменті.

1. У **Параметри → Сервери MCP** натисніть **Імпортувати**.
2. У полі **Формат конфігурації** виберіть **Claude Desktop** або **Codex CLI**.
3. Вставте конфігурацію в поле **Конфігурація JSON**.
4. Натисніть **Імпортувати**. Буде додано кожен сервер із неї.

## Встановлення пакета MCP

Пакет MCP — це файл `.mcpb`, у якому запаковано сервер для запуску на вашому Mac. У **Параметри → Сервери MCP** натисніть **Встановити пакет** і виберіть файл. Відкриття файлу `.mcpb` у Finder приведе вас у те саме місце.

Сервер із пакета працює на вашому Mac з вашими дозволами, тож установлюйте пакети лише від людей, яким довіряєте. Щоб оновити пакет, установіть новіший файл `.mcpb`.

## Поширення посилання для встановлення

Посилання для встановлення додає сервер MCP до Enconvo в один клік. Воно має той самий формат, що й `mcp.json`: назва та конфігурація транспорту.

```
https://enconvo.com/mcp/install?name=$NAME&config=$BASE64_ENCODED_CONFIG
```

| Компонент | Опис |
|-----------|-------------|
| `https://enconvo.com` | Вебсторінка встановлення |
| `/mcp/install` | Шлях |
| `name` | Параметр запиту з назвою сервера |
| `config` | Параметр запиту з JSON-конфігурацією в кодуванні base64 |

Вебсторінка відкриває deeplink `enconvo://` і показує конфігурацію сервера на випадок, якщо застосунок не відкриється.

### Створення посилання

1. Отримайте назву сервера та його JSON-конфігурацію.
2. Застосуйте до конфігурації `JSON.stringify`, а потім закодуйте її в base64.
3. Замініть `$NAME` і `$BASE64_ENCODED_CONFIG` на назву та закодовану конфігурацію.

Наприклад, ця конфігурація:

```json Single MCP server config
{
  "exa": {
    "url": "https://mcp.exa.ai/mcp"
  }
}
```

дає такі результати:

|--------|---------|
| Текстове посилання | `https://enconvo.com/mcp/install?name=exa&config=eyJ1cmwiOiJodHRwczovL21jcC5leGEuYWkvbWNwIn0=` |

### Що відбувається, коли хтось відкриває посилання

1. Людина натискає посилання або вставляє його в браузер.
2. Enconvo запитує **Додати сервер MCP «name»?** і показує, що сервер запускає або до чого підключається. Людина натискає **Додати**.
3. Відкривається **Параметри → Сервери MCP**, сервер додається й починає підключатися.
4. Щойно його підключено, агенти можуть користуватися його інструментами.

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Сервер не запускається | Перевірте команду та аргументи. Для сервера STDIO переконайтеся, що програму встановлено й вона є в `PATH`. Для сервера на Node.js переконайтеся, що доступні `npx` або `node`. |
| Його інструменти не з'являються | Перевірте, що індикатор сервера зелений. Деяким серверам потрібен ключ API, перш ніж вони запропонують інструменти. Вимкніть сервер і ввімкніть знову. |
| Біля сервера показано **Автентифікуватися** | Натисніть його й завершіть вхід на сторінці, що відкриється. |
| Помилки автентифікації | Перевірте, що ключі API правильні й не прострочені та що змінні середовища, потрібні серверу, задано. |

Повну специфікацію MCP дивіться на [modelcontextprotocol.io](https://modelcontextprotocol.io).

---

Малювання на екрані дозволяє позначити частину екрана, перш ніж запитувати про неї свого Агента. Малюйте стрілки, кола, виділення чи нотатки, а потім надсилайте. Позначений знімок екрана долучається до вашого чату як зображення, у Dynamic Island, якщо ви перед цим не користувалися іншим чатом Enconvo, наприклад Вікном чату.

## Позначте свій екран

1. Виведіть на передній план вміст, про який хочете запитати.
2. Двічі клацніть правою кнопкою миші, щоб відкрити Малювання на екрані, або натисніть **Гарячу клавішу**, яку ви задали в **Параметри → Малювання на екрані**.
3. Якщо ввімкнено **Спочатку захопіть область**, перетягніть, щоб вибрати область. Інакше малюйте прямо на живому екрані.
4. Виберіть інструмент на панелі інструментів і позначте потрібну область.
5. Клацніть **Надіслати** (паперовий літачок) або натисніть **⌘↩**.
6. Перегляньте долучене зображення й введіть запит, наприклад: «Що означає виділене попередження?»

Малювання на екрані не має гарячої клавіші, доки ви не задасте її. Подвійне клацання правою кнопкою працює одразу.

### Додайте голосову мітку

Утримуйте ліву клавішу **Option** і говоріть, щоб описати щойно намальовану фігуру. Ваші слова з'являються поруч із нею як текст. Щоб Малювання на екрані слухало після кожної намальованої фігури, увімкніть **Диктувати після кожної фігури** на панелі інструментів і робіть паузу, щоб завершити кожну мітку.

## Інструменти

| Інструмент або дія | Клавіша |
| --- | --- |
| Стрілка | **A** |
| Лінія | **L** |
| Ручка | **P** |
| Маркер | **H** |
| Прямокутник | **R** |
| Коло | **O** |
| Лічильник (пронумеровані мітки) | **N** |
| Текст | **T** |
| Вибір | **V** |
| Гумка | **E** |
| Колір | **C** |
| Товщина лінії | **⌘** + прокручування |
| Дошка | **B** |
| Підсвічування курсора | **K** |
| Зберегти як… | **⌘S** |
| Надіслати | **⌘↩** |

Панель інструментів також має **Скасувати**, **Повторити**, **Очистити**, **Скопіювати в буфер обміну** та **Закрити**.

## Параметри

Відкрийте **Параметри → Малювання на екрані**.

| Параметр | Що він робить |
| --- | --- |
| **Спочатку захопіть область** | Вибрати область перед малюванням. Вимкніть, щоб малювати прямо на живому екрані. Типово ввімкнено. |
| **Гаряча клавіша** | Відкриває або закриває Малювання на екрані. Типово порожньо. |
| **Подвійний правий клік** | Відкриває або закриває Малювання на екрані швидким подвійним клацанням правою кнопкою. Типово ввімкнено. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Накладка не відкривається | Перевірте **Гарячу клавішу** та **Подвійний правий клік** у **Параметри → Малювання на екрані** і перегляньте [дозволи macOS](/uk/configuration/permissions). |
| Вам потрібне лише все вікно програми | Скористайтеся натомість [Appshots](/uk/features/appshots). |

Малювання на екрані дозволяє позначити частину екрана, перш ніж спитати агента. Намалюйте стрілки, кола, виділення чи нотатки, потім надішліть. Знімок екрана з позначками додається до чату як зображення, у Dynamic Island, якщо ви щойно не користували інший чат Enconvo, наприклад вікно чату.

## Позначити екран

1. Виведіть вміст, про який хочете запитати, на передній план.
2. Двічі натисніть правою кнопкою миші, щоб відкрити малювання на екрані, або натисніть **Гарячу клавішу**, яку задали в **Параметри → Малювання на екрані**.
3. Якщо **Спочатку захопіть область** увімкнено, перетягніть, щоб обрати область. Інакше малюйте прямо на живому екрані.
4. Оберіть інструмент на панелі і позначте потрібну область.
5. Натисніть **Надіслати** (паперовий літачок) або **⌘↩**.
6. Перегляньте додане зображення і введіть запит, наприклад «Що означає виділене попередження?»

У малювання на екрані немає гарячої клавіші, поки ви її не задасте. Подвійний правий клік працює одразу.

### Додати голосову мітку

Утримуйте ліву клавішу **Option** і говоріть, щоб описати фігуру, яку щойно намалювали. Ваші слова з’являються поруч із нею як текст. Щоб малювання слухало після кожної намалюваної фігури, увімкніть **Диктувати після кожної фігури** на панелі і зробіть паузу, щоб завершити кожну мітку.

## Інструменти

| Інструмент або дія | Клавіша |
| --- | --- |
| Стрілка | **A** |
| Лінія | **L** |
| Олівець | **P** |
| Маркер | **H** |
| Прямокутник | **R** |
| Коло | **O** |
| Лічильник (нумеровані мітки) | **N** |
| Текст | **T** |
| Виділення | **V** |
| Гумка | **E** |
| Колір | **C** |
| Товщина лінії | **⌘** + прокручування |
| Дошка | **B** |
| Підсвічування курсора | **K** |
| Зберегти як… | **⌘S** |
| Надіслати | **⌘↩** |

На панелі також є **Скасувати**, **Повторити**, **Очистити**, **Скопіювати в буфер обміну** та **Закрити**.

## Параметри

Відкрийте **Параметри → Малювання на екрані**.

| Параметр | Що він робить |
| --- | --- |
| **Спочатку захопіть область** | Оберіть область перед малюванням. Вимкніть, щоб малювати прямо на живому екрані. Увімкнено типово. |
| **Гаряча клавіша** | Відкриває або закриває малювання на екрані. Типово порожньо. |
| **Подвійний правий клік** | Відкриває або закриває малювання на екрані швидким подвійним правим кліком. Увімкнено типово. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Накладення не відкривається | Перевірте **Гарячу клавішу** та **Подвійний правий клік** у **Параметри → Малювання на екрані** і перевірте [дозволи macOS](/uk/configuration/permissions). |
| Вам потрібне лише все вікно програми | Використайте натомість [Appshots](/uk/features/appshots). |

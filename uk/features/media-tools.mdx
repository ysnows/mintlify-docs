Медіаутиліти — це локальні команди для повсякденних медіасправ: зменшити файли зображень, відео або аудіо, зберегти звукову доріжку відео або завантажити відео з вебсторінки. Знайдіть їх у SmartBar або в **Параметри → Плагіни**.

| Команда | Що робить | Куди зберігає |
| --- | --- | --- |
| **Image Compress** | Стискає одне чи кілька зображень або кожне зображення в папці та її підпапках, із регульованою якістю | Замінює оригінальні зображення |
| **Video Compress** | Робить відеофайл меншим | `~/Downloads` |
| **Audio Compress** | Робить аудіофайл меншим за обраною якістю і зберігає обкладинку (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Зберігає аудіодоріжку відео або кожного відео в папці як M4A (MP3, коли доріжку не можна скопіювати) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Завантажує відео або аудіо за посиланням, наприклад YouTube, TikTok, Instagram, Reddit, X або Vimeo | `~/Downloads` |

<Warning>
**Image Compress** за замовчуванням замінює оригінальні зображення. Щоб їх зберегти, спочатку вимкніть **Overwrite Original Image File** у його параметрах; стиснені копії тоді йдуть у папку `enconvo-compressed-images` поруч із зображеннями.
</Warning>

## Стиснути файл або видобути його аудіо

1. Виберіть файли у Finder або додайте їх. Для Image Compress можна також вибрати папку: її зображення і зображення в підпапках стискаються, а копії зберігають ту саму структуру папок.
2. Відкрийте SmartBar і запустіть команду.
3. Відкрийте результат і перевірте його.

Зберігайте оригінал, поки пробуєте параметри стиснення. Параметри кожної команди в **Параметри → Плагіни**: **Image Utils** для Image Compress і **Media Utils** для решти.

| Параметр | Що змінює |
| --- | --- |
| **Якість** | Від 0 до 100; вище зберігає більше якості і робить більший файл. За замовчуванням 80 |
| **Шлях до цільової папки** | Куди йде стиснений файл: абсолютний шлях або шлях відносно файлу |
| **Overwrite Original … File** | Замінює оригінальний файл. Увімкнено за замовчуванням для зображень, вимкнено для відео й аудіо |

## Завантажити відео

1. Відкрийте сторінку відео в браузері або скопіюйте посилання.
2. Запустіть **Online Video Downloader** зі SmartBar. Він бере посилання з активної вкладки браузера або з посилання, яке ви вводите.
3. Стежте за поступом на Dynamic Island, де можна скасувати. Коли готово, натисніть **Показати у Finder**.

Завантаження зберігається в історії чату, а вже завантажений файл використовується знову замість нового отримання. Чи працює сайт, залежить від сайту і від того, що він дозволяє. Завантажуйте лише вміст, який вам можна зберігати.

| Параметр | Що змінює |
| --- | --- |
| **Output Directory** | Куди йдуть завантаження. За замовчуванням `~/Downloads` |
| **Audio Only** | Завантажує лише аудіо |
| **Favorite Resolution** | Роздільність для завантаження, від **Best** (типово) до 144p |
| **Force Convert to Compatible MP4** | Перетворює відео на MP4, який відтворюється скрізь. Увімкнено за замовчуванням; це займає додатковий час і процесор |
| **Use Browser Cookies** | Входить із cookie вашого браузера для відео, які бачите лише ви. Виберіть браузер у **Browser** |

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| **No images to compress** | Виберіть зображення у Finder або додайте їх, потім запустіть команду знову |
| Перетворення не вдається | Перевірте формат файлу, що папка виводу доступна для запису і що є вільне місце на диску |
| Приватне відео не завантажується | Увімкніть **Use Browser Cookies** і виберіть браузер, у якому ви ввійшли |
| Завантаження з сайту перестають працювати | Прочитайте помилку й оновіть плагін, перш ніж пробувати знову. Сайти змінюють формати й правила доступу |

Медіаутиліти — це локальні команди для щоденних медіазавдань: зменшити зображення, відео чи аудіофайли, зберегти звукову доріжку відео або завантажити відео з вебсторінки. Знайдіть їх у SmartBar або в **Параметри → Плагіни**.

| Команда | Що вона робить | Куди зберігає |
| --- | --- | --- |
| **Image Compress** | Стискає одне чи кілька зображень або кожне зображення в папці та її підпапках із регульованою якістю | Замінює оригінальні зображення |
| **Video Compress** | Зменшує відеофайл | `~/Downloads` |
| **Audio Compress** | Зменшує аудіофайл за вибраною вами якістю й зберігає його обкладинку (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Зберігає аудіодоріжку відео або кожного відео в папці як M4A (MP3, коли доріжку не можна скопіювати) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Завантажує відео чи аудіо за посиланням, наприклад із YouTube, TikTok, Instagram, Reddit, X чи Vimeo | `~/Downloads` |

<Warning>
**Image Compress** за замовчуванням замінює ваші оригінальні зображення. Щоб їх зберегти, спершу вимкніть **Overwrite Original Image File** в її параметрах; стиснені копії тоді потраплять у теку `enconvo-compressed-images` поруч із зображеннями.
</Warning>

## Стисніть файл або витягніть із нього аудіо

1. Виділіть файли у Finder або прикріпіть їх. Для Image Compress також можна вибрати папку: її зображення та зображення в підпапках стискаються, а копії зберігають ту саму структуру тек.
2. Відкрийте SmartBar і запустіть команду.
3. Відкрийте результат і перевірте його.

Зберігайте оригінал, поки пробуєте параметри стиснення. Параметри кожної команди розташовано в **Параметри → Плагіни**: **Image Utils** для Image Compress і **Media Utils** для решти.

| Параметр | Що він змінює |
| --- | --- |
| **Quality** | Від 0 до 100; вище значення зберігає більше якості й дає більший файл. Типово 80 |
| **Destination Folder Path** | Куди потрапляє стиснений файл: абсолютний шлях або шлях відносно файлу |
| **Overwrite Original … File** | Замінює оригінальний файл. Типово ввімкнено для зображень, вимкнено для відео й аудіо |

## Завантажте відео

1. Відкрийте сторінку відео у браузері або скопіюйте його посилання.
2. Запустіть **Online Video Downloader** із SmartBar. Він бере посилання з активної вкладки браузера або з посилання, яке ви вводите.
3. Стежте за перебігом у Dynamic Island, де можна скасувати. Коли завершиться, клацніть **Показати у Finder**.

Завантаження зберігається в історії вашого чату, а файл, який ви вже завантажили, використовується повторно замість нового отримання. Чи працює сайт, залежить від самого сайту та від того, що він дозволяє отримати. Завантажуйте лише вміст, який вам дозволено зберігати.

| Параметр | Що він змінює |
| --- | --- |
| **Output Directory** | Куди потрапляють завантаження. Типово `~/Downloads` |
| **Audio Only** | Завантажує лише аудіо |
| **Favorite Resolution** | Роздільна здатність для завантаження, від **Best** (типово) до 144p |
| **Force Convert to Compatible MP4** | Перетворює відео на MP4, що відтворюється всюди. Типово ввімкнено; потребує додаткового часу й процесора |
| **Use Browser Cookies** | Входить за допомогою файлів cookie вашого браузера, для відео, які бачите лише ви. Виберіть браузер у **Browser** |

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| **No images to compress** | Виділіть зображення у Finder або прикріпіть їх, потім запустіть команду знову |
| Перетворення не вдається | Перевірте формат файлу, чи можна записувати у вихідну теку та чи є вільне місце на диску |
| Приватне відео не завантажується | Увімкніть **Use Browser Cookies** і виберіть браузер, у якому ви ввійшли |
| Завантаження з сайту перестають працювати | Прочитайте помилку й оновіть плагін, перш ніж пробувати знову. Вебсайти змінюють свої формати й правила доступу |

Попросіть агента показати відповідь, і він намалює візуалізацію прямо в розмові: діаграму SVG, попередній перегляд HTML або інтерактивний віджет, який можна клацати й налаштовувати. Користуйтеся цим, коли малюнок, графік або невеликий калькулятор пояснюють більше, ніж абзаци. Для цього агенту потрібні його візуальні інструменти.

Візуальна відповідь живе в розмові. Коли потрібне щось, що можна зберегти, змінити, презентувати чи поділитися, наприклад колода, панель, дизайн або документ, попросіть [артефакт](/uk/features/artifacts).

## Попросіть візуалізацію

Скажіть, на яке питання має відповісти візуалізація:

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

Для графіка чи калькулятора додайте дані та їхні одиниці. Охайна візуалізація все одно може мати хибні факти чи обчислення, тож перевіряйте їх.

## Посилання, карти й графіки у відповідях

Деякі відповіді стають візуальними без вашого запиту:

- **Посилання** показуються картками з піктограмою сайту.
- **Місця** показуються на справжній карті з назвою місця. Кілька місць ділять одну нумеровану карту, а маршрут показує лінію з часом і відстанню.
- У **графіків**, які робить агент, перевіряються кольори, тож кожен ряд лишається відмінним при дальтонізмі і в світлому, і в темному оформленні. Числа, дати й слова статусу показуються вашою мовою.

## Користуйтеся візуалізацією і зберігайте її

1. Зачекайте, доки візуалізація домальовується, потім користуйтеся її елементами керування. Деякі віджети надсилають наступний запит назад у чат.
2. Наведіть на готову візуалізацію і клацніть **⋯** у її верхньому правому куті.
3. Оберіть **Скопіювати в буфер обміну** або **Завантажити файл** і підтвердьте ім’я файлу. Візуалізації, намальовані власними картками, таблицями й графіками програми, натомість пропонують **Завантажити зображення**, яке зберігає PNG у теку «Викачане».

Збережене зображення фіксує один момент візуалізації; інтерактивні елементи керування не зберігаються. Після зміни значень віджета **Скинути значення** в тому самому меню повертає їх.

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Замість візуалізації ви отримуєте код | Перевірте увімкнені інструменти агента, потім попросіть показати результат у розмові |
| Віджет виглядає незавершеним | Зачекайте, доки він завершиться, потім попросіть простішу версію |
| Потрібен файл зображення, а не віджет чату | Скористайтеся [генеруванням зображень](/uk/ai/image-generation) |
| Хочете зберегти графік і повернутися до нього | Попросіть [панель](/uk/features/dashboards) |

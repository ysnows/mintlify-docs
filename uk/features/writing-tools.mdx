Набір для письма — це набір команд в один клік для тексту, який ви виділяєте в будь-якій програмі. Виправляйте помилки, змінюйте тон, робіть коротше або довше, пояснюйте або підсумовуйте, або перетворюйте на список чи таблицю, не залишаючи програму, у якій пишете.

## Редагувати виділений текст

1. Виділіть текст у програмі, де пишете.
2. Натисніть команду в [PopBar](/uk/features/popbar) або відкрийте [SmartBar](/uk/features/smartbar) і знайдіть команду.
3. Прочитайте результат. Коли **Підсвічувати правки** увімкнено, результат позначає, що команда додала і прибрала.
4. Натисніть **Вставити**, щоб замінити виділення, або скопіюйте результат.

Кожна команда зберігає мову вашого тексту і відповідає лише результатом. **Пояснити** також відповідає мовою виділеного тексту і трактує кожен запуск окремо, а не як частину ранішого. Коли виділений текст ставить запитання або дає інструкцію, команда редагує ці слова; вона не відповідає на них.

<Tip>
Увімкніть **Вбудований режим** для команди, якій довіряєте, і вона працює без вікна і вставляє результат прямо поверх виділення. Див. [Змінити команду](/uk/features/writing-tools).
</Tip>

## Обрати команду

| Мета | Команди |
| --- | --- |
| Виправити помилки | Виправити правопис і граматику, Вичитати |
| Поліпшити формулювання | Поліпшити письмо, Відшліфувати, Переписати, Звучати як носій, Редагування ШІ |
| Змінити довжину | Зробити довше, Зробити коротше, Зробити стисло |
| Змінити тон | Змінити тон на дружній, упевнений, невимушений або професійний |
| Зрозуміти вміст | Пояснити, Підсумувати, Витягти ключові моменти |
| Переформатувати | Перетворити на список, Перетворити на таблицю |
| Е-пошта | Відшліфувати е-пошту, Написати чернетку відповіді |
| Дописи в X | Відшліфувати для X, Вмістити в 280 символів, Перетворити на гілку, Запропонувати відповідь на X, Запропонувати коментар-цитату на X |
| Перекласти | Перекладач, Переклад знімка екрана (див. [Переклад](/uk/ai/translate)) |
| Щось на екрані | Пояснити знімок екрана |
| Диктування | Відшліфувати диктування, Перекласти диктування, Редагувати диктування, Очищення на пристрої (див. [Диктування](/uk/features/dictation)) |
| Короткий вираз | Емодзі |

**Звучати як носій** переписує текст так, як написав би носій, тією самою мовою. **Відшліфувати е-пошту** зберігає ваше привітання, підпис і ім’я і не додає підпису. **Написати чернетку відповіді** пише відповідь на виділений лист його мовою і тоном і лишає короткий заповнювач у квадратних дужках для імені, дати або рішення, якого не може знати.

## Змінити команду

Відкрийте **Параметри → Команди ШІ** і оберіть команду в розділі **Вбудовані**. Сторінка показує, що робить команда, з **Спробувати**, щоб спершу запустити на якомусь тексті.

| Параметр | Що він змінює |
| --- | --- |
| **PopBar** | Додає команду до PopBar або прибирає |
| **Підсвічувати правки** | Позначає, що команда додала і прибрала в результаті |
| **Гаряча клавіша** | Запускає команду на тексті, який ви виділяєте в будь-якій програмі |
| **Вбудований режим** | Працює без вікна і вставляє результат поверх виділення |
| **Післядія** | Що команда робить з відповіддю, коли завершує |
| **Модель ШІ** | Модель, яку використовує ця команда. За замовчуванням слідує моделі для всіх команд ШІ |

Інструкції вбудованої команди лише для читання. Натисніть **Налаштувати**, щоб зробити власну копію, яку можна вільно змінювати.

Інструменти письма працюють на моделі, заданій у **Параметри → Команди ШІ → Усі команди**, якщо команда не обирає власну. Ті самі команди також перелічені в **Параметри → Плагіни → Набір для письма**, і кнопка **Параметри** у вікні результату відкриває команду, яка його створила.

## Отримати надійні результати

Коли переписування може піти кількома шляхами, скажіть, для кого текст і що він має робити. Назвіть, що має лишитися тим самим, як-от імена, дати, цифри і цитовані формулювання.

Завжди порівняйте результат з оригіналом, перш ніж надсилати. Вільний текст усе одно може змінити сенс.

Для інструкції, яку повторюєте, зробіть власну [команду ШІ](/uk/features/ai-commands).

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Команди немає на PopBar | Натисніть **⌄** у кінці PopBar, куди йдуть кнопки, що не вміщуються, або увімкніть **PopBar** на сторінці команди в **Параметри → Команди ШІ** |
| PopBar не з’являється | Див. [усунення неполадок PopBar](/uk/features/popbar) |
| Результат неочікуваною мовою | Пояснити відповідає мовою виділеного тексту. Підсумувати зберігає мову тексту, якщо ви не задасте **Мова відповідей**. Інші команди зберігають мову тексту |
| Результат змінив сенс | Відредагуйте, перш ніж вставляти, або запустіть команду знову з оригінальним текстом |

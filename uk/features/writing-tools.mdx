Інструменти для письма — це набір команд в один клік для тексту, який ви виділили в будь-якій програмі. Виправляйте помилки, змінюйте тон, робіть текст коротшим чи довшим, пояснюйте або підсумовуйте його, чи перетворюйте на список або таблицю, не виходячи з програми, у якій пишете.

## Редагуйте виділений текст

1. Виділіть текст у програмі, де ви пишете.
2. Натисніть команду в [PopBar](/uk/features/popbar) або відкрийте [SmartBar](/uk/features/smartbar) і знайдіть команду.
3. Прочитайте результат. Коли ввімкнено **Виділяти зміни**, результат позначає, що команда додала й вилучила.
4. Натисніть **Вставити**, щоб замінити виділене, або скопіюйте результат.

Кожна команда зберігає мову вашого тексту й відповідає самим лише результатом. **Пояснити** також відповідає мовою виділеного тексту й розглядає кожен запуск окремо, а не як продовження попереднього. Коли виділений текст містить запитання чи вказівку, команда редагує ці слова; вона не відповідає на них.

<Tip>
Увімкніть **Вбудований режим** для команди, якій довіряєте, і вона працюватиме без вікна й вставлятиме результат прямо поверх виділеного. Див. [Змініть команду](#змініть-команду).
</Tip>

## Виберіть команду

| Мета | Команди |
| --- | --- |
| Виправити помилки | Fix Spelling & Grammar, Proofread |
| Покращити формулювання | Improve Writing, Polish, Rewrite, Природне звучання, AI Edit |
| Змінити довжину | Make Longer, Make Shorter, Make Concise |
| Змінити тон | Change Tone Friendly, Confident, Casual або Professional |
| Зрозуміти вміст | Пояснити, Summarize, Extract Key Points |
| Переформатувати | Convert to List, Convert to Table |
| Електронний лист | Polish Email, Скласти відповідь |
| Дописи в X | Polish for X, Fit in 280 Characters, Turn into a Thread, Suggest a Reply on X, Suggest a Quote Comment on X |
| Переклад | Translator, Screenshot Translate (див. [Переклад](/uk/ai/translate)) |
| Щось на екрані | Screenshot Explain |
| Диктування | Dictation Polish, Dictation Translate, Dictation Edit, On-Device Cleanup (див. [Диктування](/uk/features/dictation)) |
| Короткий вираз | Emoji |

**Природне звучання** переписує ваш текст так, як його написав би носій мови, тією самою мовою. **Polish Email** зберігає ваше власне привітання, завершення й ім’я та не додає підпису. **Скласти відповідь** пише відповідь на виділений лист його мовою й у його тоні та залишає короткий заповнювач у квадратних дужках для імені, дати чи рішення, яких не може знати.

## Змініть команду

Відкрийте **Параметри → ШІ-команди** і виберіть команду в розділі **Вбудований**. На її сторінці показано, що робить команда, а кнопка **Спробувати** дає змогу спершу запустити її на якомусь тексті.

| Параметр | Що він змінює |
| --- | --- |
| **PopBar** | Додає команду до PopBar або прибирає її |
| **Виділяти зміни** | Позначає в результаті, що команда додала й вилучила |
| **Гаряча клавіша** | Запускає команду на тексті, який ви виділяєте в будь-якій програмі |
| **Вбудований режим** | Працює без вікна й вставляє результат поверх виділеного |
| **Дія після завершення** | Що команда робить з відповіддю, коли закінчить |
| **Модель ШІ** | Модель, яку використовує ця команда. Типово вона слідує моделі для всіх ШІ-команд |

Інструкції вбудованої команди доступні лише для читання. Натисніть **Налаштувати**, щоб створити власну копію, яку можна змінювати вільно.

Інструменти для письма працюють на моделі, заданій у **Параметри → ШІ-команди → Усі команди**, якщо команда не вибирає власну. Ті самі команди також перелічено в **Параметри → Плагіни → Інструменти для письма**, а кнопка **Параметри** у вікні результату відкриває команду, яка його створила.

## Отримуйте надійні результати

Коли переписування може піти кількома шляхами, скажіть, для кого цей текст і що він має робити. Назвіть те, що має залишитися незмінним, як-от імена, дати, цифри й дослівні цитати.

Завжди порівнюйте результат зі своїм оригіналом, перш ніж надсилати. Бездоганно сформульований вивід усе одно може змінити зміст.

Для вказівки, яку ви повторюєте, створіть власну [ШІ-команду](/uk/features/ai-commands).

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| Команди немає в PopBar | Натисніть **⌄** наприкінці PopBar, куди потрапляють кнопки, що не вміщаються, або ввімкніть **PopBar** на сторінці команди в **Параметри → ШІ-команди** |
| PopBar не з’являється | Див. [Усунення проблем із PopBar](/uk/features/popbar) |
| Результат несподіваною мовою | Пояснити відповідає мовою виділеного тексту. Summarize зберігає мову тексту, якщо ви не задасте його **Мову відповідей**. Інші команди зберігають мову тексту |
| Результат змінив зміст | Відредагуйте його перед вставленням або запустіть команду знову зі своїм оригінальним текстом |

Контекст це те, що супроводжує ваше запитання: виділений вами текст, файли, вибрані у Finder, сторінка, відкрита у вашому браузері, або знімок екрана. SmartBar може підхопити частину цього під час відкриття, а ви можете додати більше, ввівши `#`. Тоді Агент відповідає про те, на що ви дивитеся, без ваших пояснень.

## Виберіть, що підхоплює SmartBar

1. Відкрийте **Параметри → Розуміння контексту**.
2. У розділі **Коли відкривається Smart Bar** задайте для кожного джерела **Долучати**, **Запропонувати** або **Вимкнено**.
3. Перейдіть в іншу програму, щось виділіть і відкрийте SmartBar, щоб побачити результат.

| Джерело | Що воно додає | Типово |
| --- | --- | --- |
| **Виділений текст** | Текст, виділений у програмі, якою ви користувалися | **Долучати** |
| **Вибране у Finder** | Файли й теки, вибрані у Finder | **Запропонувати** |
| **Поточна сторінка браузера** | Сторінка, відкрита в Safari, Chrome, Arc, Edge чи іншому браузері на основі Chromium | **Запропонувати** |

**Долучати** додає джерело у поле введення, щойно відкривається SmartBar. **Запропонувати** виводить його над командами, тож ви додаєте його одним клацанням. **Вимкнено** залишає його осторонь.

Ці параметри використовує лише SmartBar. Команди, які ви запускаєте на виділеному, завжди отримують виділений текст. Коли ви вперше додаєте контекст Finder чи браузера, macOS запитує, чи може Enconvo керувати цією програмою.

## Додавайте контекст за допомогою #

1. У SmartBar введіть `#`.
2. Введіть слово, щоб звузити список, наприклад `#screen`, `#finder`, `#clipboard` або `#browser`.
3. Виберіть джерело. Його буде додано до вашого повідомлення.
4. Введіть своє запитання й надішліть його.

| Джерело | Що воно додає |
| --- | --- |
| **Selected Text** | Текст, виділений у поточному вікні |
| **Clipboard Text** | Текст у буфері обміну |
| **Current Application Content** | Текст програми на передньому плані |
| **Current Application Screenshot** | Знімок екрана програми на передньому плані |
| **Current Screen Screenshot** | Знімок усього екрана |
| **Live Screen Screenshot** | Знімок екрана без вікон Enconvo |
| **User Select Area Screenshot** | Знімок вибраної вами області |
| **Finder Selected Items** | Файли й теки, вибрані у Finder |
| **Finder Current Directory URL** | Тека, відкрита у Finder |
| **Browser Current Tab URL** | Адреса поточної вкладки браузера |

Ваші відкриті вікна теж перелічені, тож можна додати вікно з іншої програми. Щоб використовувати інший символ замість `#`, змініть **Контекст** у розділі **Пошук** в **Параметри → SmartBar**.

## Що запитувати

Якщо долучено сторінку браузера, попросіть Enconvo підсумувати сторінку, перекласти її або витягти ключову інформацію. Якщо долучено файли Finder, попросіть описати файли, запропонувати, як їх упорядкувати, допомогти з пакетним перейменуванням або проаналізувати їхній вміст.

<Note>
Контекст, який ви долучаєте, надсилається моделі, що відповідає, або постачальнику, що його обробляє. Перегляньте, що долучено, і свої параметри постачальника, перш ніж працювати з чутливим вмістом.
</Note>

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Виділений текст не долучається | Перевірте, що для **Виділений текст** задано **Долучати**, і перегляньте [Дозволи](/uk/configuration/permissions). |
| Немає контексту Finder чи браузера | Дозвольте Enconvo керувати цією програмою, коли macOS запитає. Якщо ви відмовили, дозвольте це в [Дозволи](/uk/configuration/permissions). |
| Введення `#` не відкриває список | Перевірте символ **Контекст** в **Параметри → SmartBar**. |

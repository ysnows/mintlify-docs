Змінні підставляють значення, які щоразу різні: текст, який ви ввели в SmartBar, текст, виділений в іншому застосунку, або сьогоднішню дату. Використовуйте їх у промптах і налаштуваннях, що підтримують шаблони, щоб одна ШІ-команда, інструкція Агента чи робочий процес працювали з тим, що перед вами. Відкрийте **Параметри → Змінні**, щоб переглянути доступні змінні.

## Доступні змінні

| Змінна | Яке значення підставляється |
| --- | --- |
| Input Text | Поточний ввід у SmartBar |
| Selection Text | Текст, виділений у поточному застосунку |
| Latest Clipboard | Останній вміст буфера обміну |
| Active Application | Дані про застосунок на передньому плані |
| Active Application Screenshot | Зображення вікна на передньому плані |
| Active Screen Screenshot | Зображення активного екрана |
| Focused Window Content | Вміст, видобутий зі сфокусованого вікна |
| Browser Active Tab | URL активної вкладки та доступний вміст сторінки |
| Current Folder | Папка, відкрита у Finder |
| Selected Files | Файли, вибрані у Finder |
| History Messages | Історія поточної розмови |
| Now | Поточні дата й час |
| Your Language | Мова, якою ви читаєте: ваша **Мова відповідей** або системна мова, якщо вибрано «Авто» |
| Opened Applications | Дані про запущені застосунки |
| Opened Application Names | Назви запущених застосунків |

## Використання змінної

1. Відкрийте поле ШІ-команди, інструкції Агента або робочого процесу, яке хочете налаштувати.
2. Переконайтеся, що поле підтримує змінні; якщо в ньому є вибір змінних, скористайтеся ним.
3. Вставте потрібне значення та перевірте на нешкідливому прикладі вмісту.
4. Перевірте, чи не змінює результат порожній ввід або відсутній дозвіл.

Текстовий промпт може використовувати підтримувані назви шаблонів, наприклад:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Які змінні можна використовувати, залежить від команди та контексту, а не кожне текстове поле обробляє шаблони. Знімки екрана та вміст застосунків можуть потребувати дозволів macOS і моделі, що приймає такий тип вводу.

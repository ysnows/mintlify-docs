Змінні підставляють значення, які змінюються щоразу: текст, який ви ввели в SmartBar, текст, виділений в іншій програмі, або сьогоднішню дату. Використовуйте їх у підказках і параметрах, які підтримують шаблони, щоб одна ШІ-команда, інструкція агента чи робочий процес працювали з тим, що зараз у вас перед очима. Відкрийте **Параметри → Змінні**, щоб переглянути доступні змінні.

## Доступні змінні

| Змінна | Яке значення підставляється |
| --- | --- |
| Input Text | Поточний ввід у SmartBar |
| Selection Text | Текст, виділений у поточній програмі |
| Latest Clipboard | Останній вміст буфера обміну |
| Active Application | Відомості про програму на передньому плані |
| Active Application Screenshot | Зображення вікна на передньому плані |
| Active Screen Screenshot | Зображення активного екрана |
| Focused Window Content | Вміст, витягнутий із вікна у фокусі |
| Browser Active Tab | URL активної вкладки та доступний вміст сторінки |
| Current Folder | Папка, відкрита в Finder |
| Selected Files | Файли, виділені в Finder |
| History Messages | Історія поточної розмови |
| Now | Поточні дата та час |
| Your Language | Мова, якою ви читаєте: ваша **Мова відповідей** або мова системи, коли вона Авто |
| Opened Applications | Відомості про запущені програми |
| Opened Application Names | Назви запущених програм |

## Використати змінну

1. Відкрийте поле ШІ-команди, інструкції агента або робочого процесу, яке хочете налаштувати.
2. Перевірте, що поле підтримує змінні; якщо є вибір, використайте його.
3. Вставте потрібне значення і перевірте на нешкідливому зразку.
4. Перевірте, чи змінює результат порожній ввід або відсутній дозвіл.

Текстовий підказ може використовувати підтримувані імена шаблонів, наприклад:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Які змінні можна використати, залежить від команди та контексту, і не кожне текстове поле обробляє шаблони. Знімки екрана та вміст програм можуть потребувати дозволів macOS і моделі, яка приймає такий ввід.

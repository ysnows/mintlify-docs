Робочі процеси з’єднують підказки, агентів і інструменти в один повторюваний запуск. Цей посібник будує один від початку до кінця: створіть його з шаблону **Огляд видів кроків**, додайте крок вручну, дайте помічнику робочого процесу додати ще один, потім запустіть його й прочитайте вивід кожного кроку.

<YouTubePlayer videoId="g02LJwso1yk" title="Як створити робочий процес в Enconvo | Покроковий посібник" />

Відео триває 2 хвилини 24 секунди. Письмові кроки нижче йдуть у тому самому порядку, з відповідною позначкою часу для кожного кроку.

## Що ви створите

Шаблон **Огляд видів кроків** уже працює з коробки. За посібником він виростає в невеликий конвеєр вмісту:

| Крок | Тип | Що робить |
| --- | --- | --- |
| Отримати сьогоднішню дату | Оболонка | Друкує сьогоднішню дату |
| Перелічити збережені робочі процеси | Інструмент | Перелічує наявні робочі процеси (виконується паралельно з датою) |
| Попросити модель про ідею | Підказка | Пропонує одну нову автоматизацію про вхід `topic` |
| Дати агенту її розгорнути | Агент | Перетворює ідею на план із трьох кроків |
| Написати твіт | Підказка | Додано вручну: перетворює план на один влучний твіт |
| Перекласти твіт японською | Підказка | Додано помічником: перекладає твіт |

## Дотримуйтеся

<Steps>
  <Step title="Створіть робочий процес (0:07)">
    Відкрийте **Параметри → Робочі процеси → Керувати** і оберіть **Новий робочий процес**. У розділі **Або почніть із шаблону** оберіть **Огляд видів кроків**. Робочий процес створюється, і редактор відкривається в режимі **Візуальний**. Відео записано до появи діалогу **Новий робочий процес**, тож там стартовий називається *Starter Workflow*.
  </Step>
  <Step title="Прочитайте граф (0:18)">
    Читайте граф зверху. Вузол **Входи** оголошує, що потрібно запуску; тут це один `topic`. Перші два кроки стоять поруч, бо належать до окремих завдань, тож виконуються паралельно. Кожен результат потім тече вниз у кроки під ним, які виконуються по порядку.
  </Step>
  <Step title="Відредагуйте крок (0:28)">
    Оберіть крок, щоб відкрити його в інспекторі, де можна змінити ID, назву й підказку. Подвійні фігурні дужки підставляють значення в крок: `{{ inputs.topic }}` читає вхід запуску, а `{{ steps.idea.output }}` читає результат попереднього кроку. Так кроки говорять один з одним.
  </Step>
  <Step title="Додайте крок (0:37)">
    Оберіть **+** під останнім кроком і виберіть тип кроку, наприклад Підказка, Агент, Оболонка або Інструмент. Дайте новому кроку Підказка ID `tweet`, назву «Написати твіт» і цю підказку:

    ```text wrap
    Turn this plan into one punchy tweet: {{ steps.plan.output }}
    ```

    <Tip>
    Після перейменування ID кроку натисніть Return, перш ніж перейти до наступного поля.
    </Tip>
  </Step>
  <Step title="Або запитайте помічника робочого процесу (0:57)">
    Замість редагування вручну оберіть **Помічник** на панелі інструментів і опишіть зміну на панелі, що відкривається біля полотна:

    ```text wrap
    Add a final step that translates the tweet into Japanese
    ```

    Помічник редагує граф і перелічує кроки, які змінив. Оберіть **Скасувати** на його відповіді, якщо результат не подобається. У відео він додає крок `translate_ja`, чия підказка читає `{{ steps.tweet.output }}`. Перегляньте новий крок, перш ніж зберегти: правки помічника лишаються незбереженими, доки ви не оберете **Зберегти**.
  </Step>
  <Step title="Подивіться YAML (1:16)">
    Оберіть **YAML** на панелі інструментів, щоб побачити той самий робочий процес як джерело. Кожен робочий процес — один звичайний файл, збережений у `~/.enconvo/workflows/<id>.yaml`, тож його легко читати, порівнювати й ділитися. Оберіть **Візуальний**, щоб повернутися до графа. Повний файл — у розділі «Готовий робочий процес» нижче.
  </Step>
  <Step title="Запустіть його й перевірте вивід (1:28)">
    Оберіть **Входи**, задайте значення запуску (відео використовує `{"topic": "matcha"}`) і оберіть **Запустити**. Кроки, що виконуються, світяться синім, а завершені стають зеленими. Крок агента триває довше за інші.

    Коли запуск завершується, оберіть будь-який крок і відкрийте вкладку **Вивід**, щоб побачити точно, що він створив. Останній крок підхопив твіт і переклав його, без копіювання й вставлення.
  </Step>
  <Step title="Знайдіть минулі запуски (2:05)">
    Кожен запуск зберігається в **Запуски** на панелі інструментів, тож до будь-якого результату можна повернутися пізніше.
  </Step>
</Steps>

<Note>
Запуск робочого процесу викликає справжні моделі й інструменти. Він може використовувати кредити провайдера, а кроки оболонки або інструмента діють із дозволами облікового запису Mac. Перегляньте кроки робочого процесу, перш ніж його запускати.
</Note>

## Готовий робочий процес

Ось робочий процес, створений у відео, записаний як YAML. Вигляд **YAML** може форматувати його трохи інакше.

```yaml
version: agent-workflow/v1
title: Starter Workflow
description: "Starter workflow showing parallel jobs and the four executors: command (shell), prompt (LLM), agent, and tool (Local API)."
tags:
  - demo
inputs:
  topic:
    type: string
    description: Topic to brainstorm an automation for
    default: coffee
jobs:
  date:
    steps:
      - id: today
        name: Get today's date
        command: 'date "+%Y-%m-%d"'
  catalog:
    steps:
      - id: my_workflows
        name: List saved workflows (tool)
        tool: workflow/list
        with:
          limit: 5
  ideate:
    needs: [date, catalog]
    steps:
      - id: idea
        name: Ask the model for an idea
        prompt: "Today is {{ jobs.date.today.output.stdout | trim }}. Existing workflows: {{ jobs.catalog.my_workflows.output.summaries | dump }}. Suggest ONE new automation about {{ inputs.topic }} that is not in the list, in one sentence."
      - id: plan
        name: Let the agent expand it
        agent: agent/main
        message: "Expand this automation idea into a three-step execution plan: {{ steps.idea.output }}"
      - id: tweet
        name: Write a tweet
        prompt: "Turn this plan into one punchy tweet: {{ steps.plan.output }}"
      - id: translate_ja
        name: Translate the tweet into Japanese
        prompt: "Translate this tweet into natural, fluent Japanese. Keep hashtags, emojis, and links intact. Reply with only the translated tweet: {{ steps.tweet.output }}"
```

Завдання `ideate` чекає на `date` і `catalog` через `needs`, тож може читати їхні результати через `jobs.<job>.<step>.output`. Усередині завдання пізніші кроки читають попередні через `steps.<id>.output`.

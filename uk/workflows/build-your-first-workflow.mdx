Робочі процеси з’єднують запити, агентів та інструменти в один повторюваний запуск. Цей посібник створює його від початку до кінця: створіть його із шаблону **Огляд типів кроків**, додайте крок вручну, нехай асистент робочого процесу додасть ще один, потім запустіть його й прочитайте вихідні дані кожного кроку.

<YouTubePlayer videoId="g02LJwso1yk" title="How to Build a Workflow in Enconvo | Step-by-Step Tutorial" />

Відео триває 2 хвилини 24 секунди. Письмові кроки нижче йдуть у тому самому порядку, з відповідною позначкою часу для кожного кроку.

## Що ви створите

Шаблон **Огляд типів кроків** уже працює з коробки. Протягом посібника він зростає в невеликий конвеєр контенту:

| Крок | Тип | Що він робить |
| --- | --- | --- |
| Get today's date | Оболонка | Виводить сьогоднішню дату |
| List saved workflows | Інструмент | Перелічує ваші наявні робочі процеси (виконується паралельно з датою) |
| Ask the model for an idea | Запит | Пропонує одну нову автоматизацію на тему вхідного значення `topic` |
| Let the agent expand it | Агент | Перетворює ідею на план із трьох кроків |
| Write a tweet | Запит | Додано вручну: перетворює план на один влучний твіт |
| Translate the tweet into Japanese | Запит | Додано асистентом: перекладає твіт |

## Дійте разом із нами

<Steps>
  <Step title="Створіть робочий процес (0:07)">
    Відкрийте **Параметри → Робочі процеси → Керування** і виберіть **Новий робочий процес**. У розділі **Або почніть із шаблону** виберіть **Огляд типів кроків**. Робочий процес створюється, і редактор відкривається в режимі **Візуальний**. Відео було записано до того, як з’явилося діалогове вікно **Новий робочий процес**, тому там заготовку названо *Starter Workflow*.
  </Step>
  <Step title="Прочитайте граф (0:18)">
    Читайте граф згори. Вузол **Вхідні дані** оголошує, що потрібно запуску; тут це єдине значення `topic`. Перші два кроки стоять поруч, бо належать до окремих завдань, тож виконуються паралельно. Потім кожен результат стікає вниз до кроків під ним, які виконуються по черзі.
  </Step>
  <Step title="Змініть крок (0:28)">
    Виберіть крок, щоб відкрити його в інспекторі, де можна змінити його ID, заголовок і запит. Подвійні фігурні дужки втягують значення в крок: `{{ inputs.topic }}` читає вхідне значення запуску, а `{{ steps.idea.output }}` читає результат попереднього кроку. Так кроки спілкуються між собою.
  </Step>
  <Step title="Додайте крок (0:37)">
    Виберіть **+** під останнім кроком і оберіть тип кроку, як-от Запит, Агент, Оболонка чи Інструмент. Дайте новому кроку Запит ID `tweet`, заголовок «Write a tweet» і такий запит:

    ```text wrap
    Turn this plan into one punchy tweet: {{ steps.plan.output }}
    ```

    <Tip>
    Після перейменування ID кроку натисніть Return, перш ніж переходити до наступного поля.
    </Tip>
  </Step>
  <Step title="Або попросіть асистента робочого процесу (0:57)">
    Замість редагувати вручну виберіть **Асистент** на панелі інструментів і опишіть зміну на панелі, що відкривається поруч із полотном:

    ```text wrap
    Add a final step that translates the tweet into Japanese
    ```

    Асистент редагує граф і перелічує кроки, які змінив. Виберіть **Скасувати** у його відповіді, якщо результат вам не подобається. У відео він додає крок `translate_ja`, запит якого читає `{{ steps.tweet.output }}`. Перегляньте новий крок, перш ніж зберігати: зміни асистента залишаються незбереженими, доки ви не виберете **Зберегти**.
  </Step>
  <Step title="Перегляньте YAML (1:16)">
    Виберіть **YAML** на панелі інструментів, щоб побачити той самий робочий процес як вихідний текст. Кожен робочий процес — це один простий файл, збережений за адресою `~/.enconvo/workflows/<id>.yaml`, тож його легко читати, порівнювати й поширювати. Виберіть **Візуальний**, щоб повернутися до графа. Повний файл наведено в розділі [Готовий робочий процес](#готовий-робочий-процес) нижче.
  </Step>
  <Step title="Запустіть його й перевірте вихідні дані (1:28)">
    Виберіть **Вхідні дані**, задайте значення запуску (у відео використано `{"topic": "matcha"}`) і виберіть **Запустити**. Кроки, що виконуються, світяться синім, а завершені стають зеленими. Крок Агента триває довше за інші.

    Коли запуск завершується, виберіть будь-який крок і відкрийте його вкладку **Вихідні дані**, щоб побачити, що саме він видав. Останній крок підхопив твіт і переклав його, без копіювання й вставлення.
  </Step>
  <Step title="Знайдіть минулі запуски (2:05)">
    Кожен запуск зберігається в **Запуски** на панелі інструментів, тож до будь-якого результату можна повернутися пізніше.
  </Step>
</Steps>

<Note>
Запуск робочого процесу викликає справжні моделі та інструменти. Він може витрачати кредити постачальника, а кроки Оболонка чи Інструмент діють із дозволами вашого облікового запису Mac. Перегляньте кроки робочого процесу, перш ніж запускати його.
</Note>

## Готовий робочий процес

Ось робочий процес, створений у відео, записаний як YAML. Подання **YAML** може форматувати його трохи інакше.

```yaml
version: agent-workflow/v1
title: Starter Workflow
description: "Starter workflow showing parallel jobs and the four executors: command (shell), prompt (LLM), agent, and tool (Local API)."
tags:
  - demo
inputs:
  topic:
    type: string
    description: Topic to brainstorm an automation for
    default: coffee
jobs:
  date:
    steps:
      - id: today
        name: Get today's date
        command: 'date "+%Y-%m-%d"'
  catalog:
    steps:
      - id: my_workflows
        name: List saved workflows (tool)
        tool: workflow/list
        with:
          limit: 5
  ideate:
    needs: [date, catalog]
    steps:
      - id: idea
        name: Ask the model for an idea
        prompt: "Today is {{ jobs.date.today.output.stdout | trim }}. Existing workflows: {{ jobs.catalog.my_workflows.output.summaries | dump }}. Suggest ONE new automation about {{ inputs.topic }} that is not in the list, in one sentence."
      - id: plan
        name: Let the agent expand it
        agent: agent/main
        message: "Expand this automation idea into a three-step execution plan: {{ steps.idea.output }}"
      - id: tweet
        name: Write a tweet
        prompt: "Turn this plan into one punchy tweet: {{ steps.plan.output }}"
      - id: translate_ja
        name: Translate the tweet into Japanese
        prompt: "Translate this tweet into natural, fluent Japanese. Keep hashtags, emojis, and links intact. Reply with only the translated tweet: {{ steps.tweet.output }}"
```

Завдання `ideate` чекає на `date` і `catalog` через `needs`, тож може читати їхні результати через `jobs.<job>.<step>.output`. У межах завдання пізніші кроки читають попередні через `steps.<id>.output`.

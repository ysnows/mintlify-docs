<Note>
Enconvo для Windows перебуває на етапі бета-тестування й виходить у каналі оновлень **Бета**. Він розрахований на щоденне використання, але між збірками ще можуть бути зміни. Якщо щось зламається, повідомте нам на [сайті відгуків](https://feedback.enconvo.com).
</Note>

**Поточна бета-версія: 2.5.13 Beta 3** (`2.5.13-beta-3`). Щоб дізнатися, яка версія у вас, відкрийте **Параметри → Загальні → Оновлення**.

## Вимоги

- **Windows 10 версії 2004 (збірка 19041) або новішої чи Windows 11.**
- **64-бітні Intel/AMD (x64).** Збірки для Windows на Arm поки немає.
- **Microsoft Edge WebView2 Runtime.** На ньому працюють вікна Enconvo. У Windows 11 він вбудований. Якщо у Windows 10 вікна залишаються порожніми, дивіться [Усунення несправностей](#усунення-несправностей).

## Завантаження бета-версії

Бета-версія постачається як інсталятор `Enconvo-<version>-win32-x64-setup.exe`. В імені файлу міститься номер версії бети.

Поточну бета-версію 2.5.13 Beta 3 завантажте за посиланням [Enconvo-2.5.13-beta-3-win32-x64-setup.exe](https://file.enconvo.com/win32-x64/beta/Enconvo-2.5.13-beta-3-win32-x64-setup.exe).

Щоб завжди отримувати найновішу бета-версію, виконайте це в PowerShell. Команда читає стрічку бети, завантажує інсталятор у вашу теку «Завантаження» та перевіряє, що файл надійшов цілим.

```powershell
$feed = "https://file.enconvo.com/win32-x64/beta"
$latest = Invoke-RestMethod "$feed/latest.json"
$file = $latest.files.exe.url
$out = "$env:USERPROFILE\Downloads\$file"
$ProgressPreference = "SilentlyContinue"   # downloads much faster in Windows PowerShell
Invoke-WebRequest "$feed/$file" -OutFile $out
if ((Get-FileHash $out -Algorithm SHA256).Hash -eq $latest.files.exe.sha256) {
  "Downloaded Enconvo $($latest.version) to $out"
} else {
  "The download is damaged. Delete it and run this again."
}
```

## Установлення

<Steps>
  <Step title="Запустіть інсталятор">
    Відкрийте завантажений файл `.exe`. Якщо Windows показує **Windows захистила ваш ПК**, натисніть **Докладніше**, потім **Усе одно запустити**. SmartScreen показує це для програм, яких ще не знає.
  </Step>
  <Step title="Виберіть теку">
    Enconvo встановлюється лише для вашого облікового запису й не потребує прав адміністратора. Типова тека: `%LOCALAPPDATA%\Programs\Enconvo`. Якщо вибираєте іншу, вона має бути порожньою або вже містити Enconvo.
  </Step>
  <Step title="Відкрийте Enconvo">
    Залиште позначеним **Відкрити Enconvo** на останній сторінці або пізніше відкрийте **Enconvo** з меню «Пуск». Його значок з’явиться в області сповіщень панелі завдань.
  </Step>
  <Step title="Увійдіть">
    Увійдіть до свого облікового запису Enconvo, потім перейдіть до [Швидкого старту](/uk/quickstart).
  </Step>
</Steps>

Якщо Enconvo запущено під час установлення, інсталятор спершу попросить його закрити.

## Оновлення

Збірка бети залишається в каналі «Бета». Щоб змінити це, відкрийте **Параметри → Загальні** і виберіть **Канал оновлень**. Дивіться [Оновлення](/uk/configuration/updates).

Enconvo сам перевіряє наявність нової версії. Коли вона готова, натисніть **Оновити** у вікні чату. Також можна перевірити зараз у **Параметри → Загальні → Оновлення**.

Оновлення встановлюється на місці: Enconvo закривається, показує перебіг роботи інсталятора й знову відкривається вже в новій версії.

## Усунення несправностей

| Що ви бачите | Що робити |
| --- | --- |
| **Windows захистила ваш ПК** при відкритті інсталятора | Натисніть **Докладніше**, потім **Усе одно запустити** |
| **Enconvo потребує 64-бітної Windows** | Enconvo не працює в 32-бітній Windows |
| Інсталятор не приймає вибрану вами теку | Виберіть порожню теку або теку, у якій уже є Enconvo |
| Вікна Enconvo залишаються порожніми або не відкриваються | Установіть [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), потім знову відкрийте Enconvo |
| Клацання сповіщення Enconvo нічого не робить | Відкривайте Enconvo звичайним способом, а не через **Запуск від імені адміністратора** |

## Видалення Enconvo

Відкрийте **Параметри → Програми → Установлені програми** (у Windows 10 — **Параметри → Програми → Програми й функції**), знайдіть **Enconvo** і виберіть **Видалити**.

Ваші параметри та чати залишаються в теці `.config\enconvo` у вашій теці користувача (`%USERPROFILE%\.config\enconvo`). Видаліть цю теку, щоб прибрати й їх.

<Note>
Enconvo для Linux у беті і поставляється на каналі оновлень **Beta**. Він збудований для щоденного використання, але між збірками ще може змінюватися. Якщо щось ламається, скажіть нам на [сайті відгуків](https://feedback.enconvo.com).
</Note>

**Поточна бета: 2.5.13 Beta 3** (`2.5.13-beta-3`). Щоб побачити, яка версія у вас, відкрийте **Параметри → Загальні → Оновлення**. На сервері `enconvo update --check` друкує її.

## Оберіть, як запускати

| Що у вас є | Що ви отримуєте | Почніть звідси |
| --- | --- | --- |
| Комп’ютер Linux (GNOME, KDE та інші) | Програма Enconvo з вікном чату та вікнами параметрів | [Встановіть на комп’ютері](#) |
| Сервер або хмарний комп’ютер без робочого столу | Enconvo в фоні, яким користуються з браузера на вашому комп’ютері | [Встановіть на сервері](#) |

## Вимоги

- **64-бітний Intel/AMD (x86-64).** Збірки ARM ще немає.
- **Ubuntu 22.04, Debian 12, RHEL 9, Amazon Linux 2023 або новіші.** Rocky Linux і AlmaLinux 9 рахуються як RHEL 9. Старіші системи не можуть запустити Enconvo: їх бібліотека C застаріла.
- **Пам’ять:** рекомендуємо щонайменше 2 ГБ вільних і 4 ГБ, якщо агент користуватиметься браузером.
- **Звичайний обліковий запис.** Запускайте Enconvo як себе, не як root, бо його агент виконує команди з правами цього користувача. На сервері створіть користувача лише для Enconvo.

## Завантажте бету

Бета поставляється у трьох формах: `.deb` для Debian і Ubuntu, `.rpm` для Fedora, RHEL, Rocky, AlmaLinux і openSUSE та переносний `.tar.gz` для всього іншого. Кожна назва файлу містить номер версії бети. Для 2.5.13 Beta 3 це:

- `enconvo_2.5.13~beta~3_amd64.deb`
- `enconvo-2.5.13~beta~3-1.x86_64.rpm`
- `Enconvo-2.5.13-beta-3-linux-x64.tar.gz`

Ці команди знаходять найновішу бету і завантажують її.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo_[^"]*\.deb')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Fedora, RHEL, Rocky, AlmaLinux, openSUSE">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo-[^"]*\.rpm')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Portable .tar.gz">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'Enconvo-[^"]*\.tar\.gz')
    curl -fLO "$FEED/$FILE"
    tar xzf "$FILE"
    ```

    Це розпаковує папку `Enconvo`. Запускайте звідти і використовуйте `./Enconvo/enconvo` скрізь, де ця сторінка каже `enconvo`.
  </Tab>
</Tabs>

## Встановіть на комп’ютері

Менеджер пакетів також встановлює те, що потрібно вікнам програми: GTK і WebKitGTK.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    sudo apt install ./enconvo_*.deb
    ```
  </Tab>
  <Tab title="Fedora, openSUSE">
    ```bash
    sudo dnf install ./enconvo-*.rpm      # Fedora
    sudo zypper install ./enconvo-*.rpm   # openSUSE
    ```
  </Tab>
  <Tab title="Portable .tar.gz">
    Встановіть GTK 3 і WebKitGTK 4.1 зі свого дистрибутива, потім запустіть Enconvo з його папки:

    ```bash
    ./Enconvo/enconvo
    ```
  </Tab>
</Tabs>

RHEL 9, Rocky Linux 9 і AlmaLinux 9 не постачають WebKitGTK 4.1, який потрібен вікнам програми, тож на цих системах [запускайте Enconvo як на сервері](#).

Відкрийте **Enconvo** з меню програм, увійдіть і продовжте з [Швидкого старту](/uk/quickstart). Іконка Enconvo з’являється в системному треї, де робочий стіл її показує.

## Встановіть на сервері

Серверу не потрібні бібліотеки робочого столу, тож залиште їх.

<Steps>
  <Step title="Встановіть пакет">
    <Tabs>
      <Tab title="Debian, Ubuntu">
        ```bash
        sudo apt install --no-install-recommends ./enconvo_*.deb
        ```
      </Tab>
      <Tab title="Fedora, RHEL, Rocky, AlmaLinux">
        ```bash
        sudo dnf install --setopt=install_weak_deps=False ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="openSUSE">
        ```bash
        sudo zypper install --no-recommends ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="Portable .tar.gz">
        Встановлювати нічого: використайте розпаковану папку `Enconvo`.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Запустіть Enconvo як службу">
    ```bash
    enconvo service install --web
    ```

    Enconvo тепер працює в фоні і обслуговує вікно чату та параметри як вебсайт лише на цій машині, за адресою `127.0.0.1:54580`. Він запускається знову, коли сервер завантажується. Якщо команда каже, що він працює лише поки ви в системі, виконайте команду `sudo loginctl enable-linger`, яку вона друкує.
  </Step>
  <Step title="Увійдіть">
    ```bash
    enconvo login
    ```

    Enconvo друкує короткий код. Відкрийте `enconvo.com/device` на телефоні або комп’ютері, перевірте, що сторінка називає ваш обліковий запис, і схваліть код протягом 10 хвилин.
  </Step>
  <Step title="Відкрийте Enconvo зі свого комп’ютера">
    Виконайте це на своєму комп’ютері, потім залиште це працювати:

    ```bash
    ssh -N -L 54580:127.0.0.1:54580 you@your-server
    ```

    Відкрийте [http://localhost:54580](http://localhost:54580) у браузері. Ви отримуєте те саме вікно чату та параметри, що й у настільній програмі.
  </Step>
</Steps>

Щоб користуватися цим сервером із програми Enconvo на телефоні, виконайте `enconvo companion pair --phone` і відскануйте код, який вона друкує. Див. [Спаруйте з телефоном](/uk/integrations/pair-your-phone).

### Дістаньтеся без тунелю SSH

Тунель — найбезпечніший шлях, бо нічого на сервері не відкрите в мережу. Вебсайт має повні права вашого облікового запису і може дістатися файлів сервера, тож будь-хто, хто може його відкрити, може користуватися обома.

Щоб відкрити його з інших комп’ютерів напряму, наприклад у приватній мережі або VPN:

```bash
enconvo service install --web 0.0.0.0:54580
enconvo service url
```

`enconvo service url` друкує адресу з її токеном з’єднання. Тримайте цю адресу приватною і не відкривайте цей порт в інтернет.

Для публічної адреси поставте зворотний проксі з HTTPS перед Enconvo і скажіть Enconvo адресу, яку він обслуговує:

```bash
enconvo service install --web --web-url https://enconvo.example.com
```

З HTTPS вебсайт також можна встановити як програму на телефоні або комп’ютері.

## Користуйтеся використанням браузера на сервері

Агент може переглядати на сервері без екрана: Enconvo запускає власний безголовий браузер, який називається Enconvo Browser, коли агенту він уперше потрібен. Спочатку встановіть Chromium.

<Tabs>
  <Tab title="Debian">
    ```bash
    sudo apt install chromium
    ```
  </Tab>
  <Tab title="Ubuntu">
    ```bash
    sudo snap install chromium
    ```
  </Tab>
  <Tab title="Fedora">
    ```bash
    sudo dnf install chromium
    ```
  </Tab>
  <Tab title="RHEL, Rocky, AlmaLinux">
    Chromium походить з [EPEL](https://docs.fedoraproject.org/en-US/epel/):

    ```bash
    sudo dnf install epel-release
    sudo dnf install chromium
    ```
  </Tab>
</Tabs>

Потім попросіть агента, наприклад: «Відкрий news.ycombinator.com і скажи мені головну новину».

Enconvo Browser зберігає власні входи. Коли сайту потрібні ви, для входу або перевірки, агент дає вам живий вигляд сторінки у вашому браузері, де ви можете клацати і вводити самі. Він закривається, коли простоював 30 хвилин, і повертає вкладки наступного разу.

Сторінка, до якої може дістатися лише сервер, наприклад сервер розробки, який агент запустив на `localhost`, також відкривається поруч із чатом як живий вигляд, тож вона працює через тунель SSH.

## Що де працює

| Функція | Комп’ютер Linux | Сервер |
| --- | --- | --- |
| Вікно чату, параметри | Так | Так, у вашому браузері |
| Агенти, інструменти, файли, документи, артефакти | Так | Так |
| Використання браузера | Так | Так, з Chromium |
| База знань, пам’ять, автоматизації, робочі процеси | Так | Так |
| Моделі Enconvo Cloud, пошук в інтернеті, OCR, створення зображень, мовлення | Так | Так |
| Використання комп’ютера | Так | Ні: немає екрана, яким керувати |
| Глобальні скорочення, диктування, голосові нотатки, записи, малюнок на екрані, Appshots, сповіщення | Так | Ні: їм потрібен робочий стіл |

На Wayland глобальні скорочення потребують робочого столу, який пропонує їх програмам.

Цих функцій немає на Linux: SmartBar, PopBar, Dynamic Island, голосова команда, аватар, улюбленець на робочому столі, бічна панель програми, Live Talk і субтитри. SmartBar, PopBar, Dynamic Island, голосова команда, аватар і улюбленець на робочому столі є в [беті Windows](/uk/getting-started/windows).

Локальні моделі чату працюють із файлів GGUF на системах із glibc 2.38 або новішим. Моделі MLX потребують Mac.

## Ваш обліковий запис на Linux

Якщо ваш обліковий запис також користується [програмою iPhone](/uk/integrations/iphone-app), ваш типовий чат, мовлення та вибір зображень слідують за обліковим записом на цей комп’ютер. Провайдер, який працює на вашому ключі API, не слідує, бо ключі не копіюються. Додайте ключ у **Параметрах** на цьому комп’ютері, якщо хочете того самого провайдера тут.

Якщо годинник сервера в іншому часовому поясі, ніж ваш браузер, Enconvo пропонує використати ваш для часу та [автоматизацій](/uk/workflows/scheduled-jobs).

## Оновіть

Збірка бети лишається на каналі бета. Щоб змінити його, відкрийте **Параметри → Загальні** і задайте **Канал оновлень**. Див. [Оновлення](/uk/configuration/updates).

На комп’ютері використайте **Оновити** у вікні чату, коли воно з’являється. Переносна збірка замінює себе. Для `.deb` або `.rpm` Enconvo завантажує новий пакет до папки Downloads, і ви встановлюєте його, як у [Встановіть на комп’ютері](#).

На сервері:

```bash
enconvo update --check   # is there a newer version?
enconvo update           # download and check it
```

Якщо ви встановили `.deb` або `.rpm`, `enconvo update` завантажує новий пакет і друкує команду, щоб установити його як root. Виконайте цю команду, потім перезапустіть службу:

```bash
systemctl --user restart enconvo
```

Якщо ви запускаєте переносний `.tar.gz`, `enconvo update` замінює папку і перезапускає її службу за вас. Якщо нова версія не запускається, він повертає стару.

## Усунення неполадок

| Що ви бачите | Що робити |
| --- | --- |
| `enconvo` каже, що настільній програмі потрібні GTK 3 і WebKitGTK 4.1 | На комп’ютері встановіть пакети, які він називає. На сервері або на RHEL 9 використайте `enconvo service install --web` |
| `GLIBC_2.34 not found` або повідомлення зі списком підтримуваних систем | Система застаріла: використайте одну з [Вимог](#) |
| `dnf` каже `nothing provides libwebkit2gtk-4.1.so.0` | У вас старіший пакет. Встановіть поточну бету [командою сервера](#) |
| Enconvo зупиняється, коли ви виходите з сервера, або не запускається після перезавантаження | Виконайте `sudo loginctl enable-linger "$USER"` |
| `localhost:54580` не відкривається | Перевірте, що команда `ssh -L` усе ще працює і що `systemctl --user status enconvo` каже active |
| Вебсайт просить токен | Виконайте `enconvo service url` на сервері і відкрийте адресу, яку він друкує |
| Агент каже, що не може запустити Enconvo Browser | [Встановіть Chromium](#). Google Chrome 137 і пізніші не можуть завантажити розширення, яке потрібне Enconvo Browser |
| Код прострочився | Виконайте `enconvo login` знову, щоб отримати новий |

Щоб прочитати журнал Enconvo на сервері:

```bash
journalctl --user -u enconvo -n 100
```

## Вилучіть Enconvo

```bash
enconvo service uninstall
sudo apt remove enconvo     # Debian, Ubuntu
sudo dnf remove enconvo     # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper remove enconvo  # openSUSE
```

Ваші параметри і чати лишаються в `~/.config/enconvo`. Видаліть цю папку, щоб вилучити і їх.

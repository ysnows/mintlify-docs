Використовуйте свій план GitHub Copilot як провайдера Моделі ШІ в Enconvo. Ви входите з обліковим записом GitHub, що має план; ключ API не потрібен. Преміум-моделі враховуються в преміум-запитах вашого плану.

## Підключення

<Steps>
  <Step title="Відкрийте провайдера">
    Відкрийте **Параметри → Модель ШІ → GitHub Copilot**.
  </Step>
  <Step title="Почніть вхід">
    У розділі **Автентифікація** натисніть **З’єднати**.
  </Step>
  <Step title="Введіть код на GitHub">
    Ваш браузер відкриває сторінку пристрою GitHub, а Enconvo показує код, який потрібно там ввести. Введіть код і авторизуйте вхід.
  </Step>
  <Step title="Перевірте обліковий запис">
    Поверніться в Enconvo й перевірте, що під’єднано потрібний обліковий запис GitHub.
  </Step>
  <Step title="Виберіть модель">
    Виберіть модель і спробуйте короткий запит.
  </Step>
</Steps>

Закриття діалогу з кодом Enconvo до авторизації скасовує вхід.

## Моделі та параметри

Список моделей показує лише ті моделі, які може використовувати ваш план Copilot, спершу з власною типовою моделлю чату Copilot. Copilot Free пропонує менше моделей, ніж платні плани, тож модель, яку ви бачили деінде, може бути не в списку. Кожна модель використовує рівні міркування, які Copilot пропонує для неї.

## На iPhone

Програма для iPhone також може входити в GitHub Copilot для чатів Phone на телефоні. Дивіться [Чати на телефоні](/uk/integrations/iphone-phone-chats).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Вхід не завершується | Введіть код на сторінці GitHub, поки він не спливе, потім знову натисніть **З’єднати**, щоб отримати новий код. |
| Потрібної моделі немає в списку | Ваш план Copilot її не включає; виберіть іншу модель або оновіть план. |
| Запит завершується помилкою моделі | Виберіть модель із поточного списку; типова модель, вибрана до зміни вашого плану, може більше не пропонуватися. |
| Ліміт швидкості чи використання | Преміум-запити вашого плану та ліміти швидкості GitHub. |

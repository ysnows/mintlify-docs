Використовуйте тариф GitHub Copilot як провайдера моделі ШІ в Enconvo. Ви входите обліковим записом GitHub, який має цей тариф; ключ API не потрібен. Преміум-моделі враховуються в преміум-запити вашого тарифу.

## Підключення

<Steps>
  <Step title="Відкрити провайдера">
    Відкрийте **Параметри → Модель ШІ → GitHub Copilot**.
  </Step>
  <Step title="Почати вхід">
    У розділі **Автентифікація** натисніть **З’єднати**.
  </Step>
  <Step title="Ввести код на GitHub">
    Браузер відкриває сторінку пристрою GitHub, а Enconvo показує код, який треба там ввести. Введіть код і підтвердьте вхід.
  </Step>
  <Step title="Перевірити обліковий запис">
    Поверніться в Enconvo і переконайтеся, що підключено потрібний обліковий запис GitHub.
  </Step>
  <Step title="Обрати модель">
    Виберіть модель і спробуйте короткий запит.
  </Step>
</Steps>

Якщо закрити діалог коду Enconvo до підтвердження, вхід скасується.

## Моделі та параметри

Список моделей показує лише ті, які доступні вашому тарифу Copilot, і спершу стоїть власна типова модель чату Copilot. Copilot Free пропонує менше моделей, ніж платні тарифи, тож моделі, яку ви бачили деінде, може не бути в списку. Кожна модель використовує ті рівні зусилля міркування, які Copilot для неї пропонує.

## На iPhone

Застосунок iPhone теж може увійти в GitHub Copilot для чатів телефона на телефоні. Див. [Чати телефона](/uk/integrations/iphone-phone-chats).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Вхід не завершується | Введіть код на сторінці GitHub, поки він не прострочений, потім натисніть **З’єднати** ще раз, щоб отримати новий код. |
| Потрібної моделі нема в списку | Ваш тариф Copilot її не включає; оберіть іншу модель або підвищте тариф. |
| Запит завершується помилкою моделі | Виберіть модель із поточного списку; типова модель, обрана до зміни тарифу, може більше не пропонуватися. |
| Ліміт частоти або використання | Преміум-запити вашого тарифу та ліміти частоти GitHub. |

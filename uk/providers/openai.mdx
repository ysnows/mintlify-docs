Використовуйте моделі GPT від OpenAI у чатах, агентах і ШІ-командах. Під’єднуйтесь ключем API OpenAI, за який OpenAI виставляє рахунок за кожен запит, або увійдіть планом ChatGPT і використовуйте його ліміт.

## Під’єднати

<Steps>
  <Step title="Отримати ключ API">
    Створіть ключ на [платформі OpenAI](https://platform.openai.com/api-keys).
  </Step>
  <Step title="Додати його до Enconvo">
    Відкрийте **Параметри → Модель ШІ → OpenAI**. У розділі **Автентифікація** виберіть **Ключ API**, вставте ключ, потім натисніть **Перевірити**.
  </Step>
  <Step title="Вибрати модель">
    Виберіть модель у **Назва моделі** і надішліть коротке повідомлення. Відповідь означає, що з’єднання працює.
  </Step>
</Steps>

<Tip>
Маєте план ChatGPT? Натомість виберіть **ChatGPT Subscription** у розділі **Автентифікація** і натисніть **Під’єднати**. Див. [ChatGPT Subscription](/uk/providers/openai_subscription).
</Tip>

Щоб зберегти другий ключ OpenAI, наприклад для роботи, натисніть **Додати нового провайдера** і створіть інший профіль.

## Моделі й параметри

| Параметр | Що робить |
| --- | --- |
| **Назва моделі** | Модель, яку використовує цей провайдер. **Оновити** поруч перезавантажує список; **Керування моделями** (шестерня) додає або відновлює моделі. |
| **API Type** | В облікових даних. **Responses API** (типово) або **Completions API**. Залиште Responses, якщо сумісна служба не потребує Completions. |
| **API Base Url** | В облікових даних. Типово `https://api.openai.com/v1`. Змінюйте лише для служби, сумісної з OpenAI. |

Той самий профіль OpenAI також обслуговує ембедінги OpenAI, синтез мовлення, генерацію зображень і транскрибування, тож зміна його ключа впливає й на ці функції. Щоб використати іншу модель в одному чаті, виберіть її у виборі моделі того чату.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не вдається | Вставте весь ключ знову і перевірте, що він активний і має налаштовану оплату на платформі OpenAI. |
| Моделі бракує | Натисніть **Оновити** поруч із **Назва моделі**. Щоб додати модель самим, скористайтеся **Керування моделями**. |
| Сумісна служба не працює | Перевірте **API Base Url**, потім спробуйте **Completions API** як **API Type**. |
| Помилки ліміту частоти або використання | Перевірте використання й ліміти на платформі OpenAI або наразі перейдіть до іншого провайдера. |

Використовуйте моделі OpenAI, які ваша організація розгортає в Azure. Enconvo звертається до вашого ресурсу Azure напряму, тож доступ, квоти і оплата йдуть за підпискою Azure.

## Перш ніж почати

Потрібен ресурс Azure OpenAI щонайменше з одним розгортанням моделі. З порталу Azure скопіюйте **ключ** ресурсу, його **кінцеву точку** і **назву розгортання**, яку ви дали моделі. Див. [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview), якщо ще не налаштували.

## Підключити

<Steps>
  <Step title="Додайте облікові дані">
    Відкрийте **Параметри → Модель ШІ → Azure OpenAI**. У розділі **Автентифікація** заповніть **Ключ API**, **Кінцева точка** і **Версія API**, потім натисніть **Перевірити**. Кінцева точка виглядає як `https://<resource>.cognitiveservices.azure.com/`.
  </Step>
  <Step title="Задайте розгортання">
    Введіть назву розгортання в **Назва розгортання API Azure OpenAI**. Використовуйте назву з ресурсу Azure, яка може відрізнятися від назви моделі.
  </Step>
  <Step title="Перевірте">
    Надішліть коротке повідомлення. Відповідь означає, що підключення працює.
  </Step>
</Steps>

## Моделі і параметри

| Параметр | Що він робить |
| --- | --- |
| **Назва розгортання API Azure OpenAI** | Розгортання, яке викликає цей провайдер. |
| **Потокова передача** | Показує відповідь, поки її пишуть. Увімкнено за замовчуванням; вимкніть, якщо розгортання не підтримує потокову передачу. |
| **Версія API** | В облікових даних. Типове значення — `2025-01-01-preview`. |

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не вдається | Перевірте, що ключ і **Кінцева точка** походять з того самого ресурсу Azure. |
| Розгортання не знайдено | Скопіюйте назву розгортання точно з порталу Azure. |
| Відповідь ніколи не з’являється | Вимкніть **Потокова передача** і спробуйте знову. |
| Помилки частоти або квоти | Підвищіть квоту розгортання в Azure або перейдіть на іншого провайдера наразі. |

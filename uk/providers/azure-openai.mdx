Використовуйте моделі OpenAI, які ваша організація розгортає в Azure. Enconvo звертається безпосередньо до вашого ресурсу Azure, тож доступ, квоти й оплата залежать від вашої підписки Azure.

## Перш ніж почати

Вам потрібен ресурс Azure OpenAI принаймні з одним розгортанням моделі. З порталу Azure скопіюйте **ключ** ресурсу, його **кінцеву точку** та **назву розгортання**, яку ви дали моделі. Якщо ви ще нічого не налаштували, див. [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview).

## Підключення

<Steps>
  <Step title="Додайте облікові дані">
    Відкрийте **Параметри → Модель ШІ → Azure OpenAI**. У розділі **Автентифікація** заповніть **Ключ API**, **Endpoint** і **API Version**, а потім натисніть **Перевірити**. Кінцева точка має такий вигляд: `https://<resource>.cognitiveservices.azure.com/`.
  </Step>
  <Step title="Укажіть розгортання">
    Введіть назву розгортання в **Azure OpenAI Api Deployment Name**. Використайте назву з вашого ресурсу Azure — вона може відрізнятися від назви моделі.
  </Step>
  <Step title="Перевірте роботу">
    Надішліть коротке повідомлення. Відповідь означає, що підключення працює.
  </Step>
</Steps>

## Моделі та параметри

| Параметр | Що він робить |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | Розгортання, яке викликає цей провайдер. |
| **Потокове передавання** | Показує відповідь у міру її написання. Типово ввімкнено; вимкніть, якщо ваше розгортання не підтримує потокове передавання. |
| **API Version** | В облікових даних. Типове значення — `2025-01-01-preview`. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не проходить | Переконайтеся, що ключ і **Endpoint** належать до одного ресурсу Azure. |
| Розгортання не знайдено | Скопіюйте назву розгортання з порталу Azure точно. |
| Відповідь так і не з’являється | Вимкніть **Потокове передавання** й спробуйте ще раз. |
| Помилки ліміту чи квоти | Збільште квоту розгортання в Azure або тимчасово перейдіть на іншого провайдера. |

Користуйтеся моделями Qwen від Alibaba в чатах, агентах і ШІ-командах. Під’єднуйтеся ключем API з Alibaba Cloud Model Studio; Alibaba Cloud виставляє рахунок за використання на ваш обліковий запис. Для сервісу материкового Китаю (Bailian) використовуйте [DashScope](/uk/providers/dashscope).

## Під’єднання

<Steps>
  <Step title="Отримайте ключ API">
    Створіть ключ в [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Додайте його в Enconvo">
    Відкрийте **Параметри → Модель ШІ → Qwen**. У розділі **Автентифікація** вставте ключ у **Ключ API**, потім клацніть **Перевірити**.
  </Step>
  <Step title="Оберіть модель">
    Оберіть модель у **Назва моделі** і надішліть коротке повідомлення. Відповідь означає, що з’єднання працює.
  </Step>
</Steps>

Qwen під’єднується лише ключем API.

## Моделі та параметри

| Параметр | Що робить |
| --- | --- |
| **Назва моделі** | Модель, якою користується цей провайдер. **Оновити** поруч перезавантажує список; **Керування моделями** (шестірня) додає або відновлює моделі. |
| **Base Url** | У облікових даних. Типове значення — міжнародна кінцева точка, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Змініть її, якщо ключ належить іншому регіону. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не вдається | Перевірте, що ключ і **Base Url** належать тому самому регіону, потім вставте весь ключ знову. |
| Моделі бракує | Клацніть **Оновити** поруч із **Назва моделі**. Щоб додати модель самостійно, скористайтеся **Керування моделями**. |
| Помилки ліміту частоти або використання | Перевірте використання й квоту в Model Studio або поки перемкніться на іншого провайдера. |

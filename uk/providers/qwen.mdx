Використовуйте моделі Qwen від Alibaba у чатах, Агентах і ШІ-командах. Підключайтеся за допомогою ключа API з Alibaba Cloud Model Studio; Alibaba Cloud стягує плату за використання з вашого облікового запису. Для сервісу в материковому Китаї (Bailian) використовуйте [DashScope](/uk/providers/dashscope).

## Підключення

<Steps>
  <Step title="Отримайте ключ API">
    Створіть ключ в [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Додайте його в Enconvo">
    Відкрийте **Параметри → Модель ШІ → Qwen**. У розділі **Автентифікація** вставте ключ у поле **Ключ API** і натисніть **Перевірити**.
  </Step>
  <Step title="Виберіть модель">
    Виберіть модель у полі **Назва моделі** й надішліть коротке повідомлення. Відповідь означає, що підключення працює.
  </Step>
</Steps>

Qwen підключається лише за допомогою ключа API.

## Моделі та параметри

| Параметр | Що він робить |
| --- | --- |
| **Назва моделі** | Модель, яку використовує цей провайдер. **Оновити** поруч із нею перезавантажує список; **Керування моделями** (шестерня) додає або відновлює моделі. |
| **Базовий URL** | В облікових даних. Типове значення — міжнародна кінцева точка `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Змініть його, якщо ваш ключ належить до іншого регіону. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не проходить | Переконайтеся, що ключ і **Базовий URL** належать до одного регіону, а потім вставте весь ключ ще раз. |
| Бракує моделі | Натисніть **Оновити** поруч із **Назва моделі**. Щоб додати модель самостійно, скористайтеся **Керування моделями**. |
| Помилки ліміту швидкості чи використання | Перевірте використання та квоту в Model Studio або тимчасово перейдіть на іншого провайдера. |

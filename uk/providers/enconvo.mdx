Enconvo Cloud дає моделі кількох компаній, а також мовлення, зображення, відео й вебінструменти, через ваш обліковий запис Enconvo. Ключами API керувати не потрібно: запити використовують бали вашого плану. Це найшвидший спосіб почати.

## Налаштувати

<Steps>
  <Step title="Увійти">
    Увійдіть в обліковий запис Enconvo. Див. [Обліковий запис](/uk/configuration/account).
  </Step>
  <Step title="Вибрати Enconvo Cloud">
    Відкрийте сторінку параметрів для того, що хочете робити, наприклад **Модель ШІ**, **Синтез мовлення** або **Генерація зображень**, і виберіть провайдера з міткою **Enconvo Cloud** або **Enconvo Cloud Plan**.
  </Step>
  <Step title="Вибрати модель або голос">
    Виберіть модель або голос і виконайте короткий запит.
  </Step>
</Steps>

Кожна функція має власний вибір провайдера. Вибір Enconvo Cloud для чату не перемикає мовлення, зображення, відео, ембедінги, переранжування чи вебінструменти; задайте кожне там, де потрібно.

## Власні моделі Enconvo

Enconvo Cloud має три власні моделі, названі за роботою, якій вони пасують:

| Модель | Для чого |
| --- | --- |
| **Enconvo Fast** | Швидкі кроки: короткі відповіді, переписування, невеликі дії. З неї починає **Enconvo Cloud Plan**, і це типова модель для ШІ-команд. |
| **Enconvo Balanced** | Повсякденна робота з кількома кроками. |
| **Enconvo Ultra** | Складні завдання, які потребують глибокого міркування. |

Вони йдуть першими в **Enconvo Cloud Plan**, і [Auto Route](/uk/providers/auto-route) використовує їх для типових маршрутів.

## Знайти модель у виборі

Список **Enconvo Cloud Plan** групує моделі за постачальником: спочатку власні моделі Enconvo, потім Anthropic, OpenAI, Google і решта, кожна з лічильником. Постачальник показує чотири найновіші моделі; натисніть **Show N earlier models**, щоб побачити інші. Пошук перелічує кожен збіг, а модель, яку використовує чат, завжди видно. Моделі Claude наведено без префікса «Claude», наприклад **Sonnet 5.5** і **Opus 5.5**.

У виборі моделі Вікна чату модель Cloud може мати мітку:

| Мітка | Значення |
| --- | --- |
| **New** | Додано за останні 14 днів. |
| Знижка, наприклад **50% OFF** | Модель наразі коштує менше. Наведіть на рядок або дійдіть до нього стрілками, щоб побачити звичайну ціну. |
| **Безкоштовно** | Модель не витрачає балів. |
| **Попередній перегляд** | Рання версія моделі. |
| Дата | День, коли модель залишає Enconvo Cloud. |

Мітки задає Enconvo Cloud, тож вони змінюються без оновлення програми.

## Бали й використання

Моделі коштують різну кількість балів. Параметри показують ціну Cloud поруч із кожною моделлю й провайдером, а також те, що входить до плану, наприклад безкоштовні хвилини, які лишилися цього місяця. Поточні плани й тарифи див. на сторінках [Cloud Plan](https://www.enconvo.com/cloud-plan) і [Cloud pricing](https://www.enconvo.com/cloud-pricing). Щоб побачити, що ви використали, відкрийте **Параметри → Використання балів**.

[Auto Route](/uk/providers/auto-route), типова модель, працює на моделях Enconvo Cloud. Вибір маршруту для кожного повідомлення безкоштовний; модель, яка відповідає, витрачає бали.

Деякі служби Cloud безкоштовні для кожного облікового запису, у який виконано вхід:

- Вебпошук через **Enconvo Cloud** і **DeepSeek (Enconvo Cloud)**. Див. [Вебпошук](/uk/ai/web-search).
- Розпізнавання мовлення через **Enconvo Cloud Fast**. Див. [Розпізнавання мовлення](/uk/ai/speech-recognition).

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Запити просять увійти | Увійдіть у **Параметри → Обліковий запис**. |
| Запити не вдаються з помилкою балів або балансу | Перевірте **Параметри → Використання балів**, потім план на сторінці [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Моделі бракує | Вибір показує те, що входить до плану. Натисніть **Оновити** поруч із **Назва моделі**. |

Enconvo Cloud дає вам моделі від кількох компаній, а також інструменти мовлення, зображень, відео та вебу через ваш обліковий запис Enconvo. Ключами API керувати не потрібно: запити витрачають бали вашого плану. Це найшвидший спосіб почати.

## Налаштування

<Steps>
  <Step title="Увійдіть">
    Увійдіть у свій обліковий запис Enconvo. Дивіться [Обліковий запис](/uk/configuration/account).
  </Step>
  <Step title="Виберіть Enconvo Cloud">
    Відкрийте сторінку параметрів для того, що хочете робити, наприклад **Модель ШІ**, **Синтез мовлення** або **Генерація зображень**, і виберіть провайдера з позначкою **Enconvo Cloud** або **Enconvo Cloud Plan**.
  </Step>
  <Step title="Виберіть модель або голос">
    Виберіть модель або голос і виконайте короткий запит.
  </Step>
</Steps>

Кожна функція має власний вибір провайдера. Вибір Enconvo Cloud для чату не перемикає мовлення, зображення, відео, вбудовування, повторне ранжування чи вебінструменти; задайте кожне там, де потрібно.

## Власні моделі Enconvo

Enconvo Cloud має три власні моделі, названі за роботою, для якої вони підходять:

| Модель | Для чого використовувати |
| --- | --- |
| **Enconvo Fast** | Швидкі ходи: короткі відповіді, переписування, невеликі дії. Це модель, з якої починає **Enconvo Cloud Plan**, і типова для ШІ-команд. |
| **Enconvo Balanced** | Щоденна робота з кількома кроками. |
| **Enconvo Ultra** | Складні завдання, що потребують глибокого міркування. |

Вони перелічені першими в **Enconvo Cloud Plan**, а [Auto Route](/uk/providers/auto-route) використовує їх для своїх типових маршрутів.

## Пошук моделі у виборі

Список **Enconvo Cloud Plan** групує моделі за постачальником: спершу власні моделі Enconvo, потім Anthropic, OpenAI, Google та решта, кожна з кількістю. Постачальник показує свої чотири найновіші моделі; натисніть **Показати N попередніх моделей**, щоб побачити решту. Пошук перелічує кожен збіг, а модель, яку використовує ваш чат, показується завжди. Моделі Claude перелічені без префікса «Claude», наприклад **Sonnet 5.5** і **Opus 5.5**.

У виборі моделі Вікна чату хмарна модель може мати мітку:

| Мітка | Значення |
| --- | --- |
| **Нове** | Додано за останні 14 днів. |
| Знижка, наприклад **50% OFF** | Наразі модель коштує менше. Наведіть курсор на рядок або дійдіть до нього клавішами зі стрілками, щоб побачити звичайну ціну. |
| **Безкоштовно** | Модель не витрачає балів. |
| **Попередній перегляд** | Рання версія моделі. |
| Дата | День, коли модель залишає Enconvo Cloud. |

Мітки задає Enconvo Cloud, тож вони змінюються без оновлення програми.

## Бали та використання

Моделі коштують різну кількість балів. Параметри показують ціну в Cloud поруч із кожною моделлю та провайдером, а також те, що включає ваш план, наприклад безкоштовні хвилини, що залишилися цього місяця. Актуальні плани та тарифи дивіться на сторінках [Плану Cloud](https://www.enconvo.com/cloud-plan) і [Цін на Cloud](https://www.enconvo.com/cloud-pricing). Щоб побачити, скільки ви використали, відкрийте **Параметри → Використання балів**.

[Auto Route](/uk/providers/auto-route), типова модель, працює на моделях Enconvo Cloud. Вибір маршруту для кожного повідомлення безкоштовний; модель, що відповідає, витрачає бали.

Деякі служби Cloud безкоштовні для кожного облікового запису, у який виконано вхід:

- Вебпошук з **Enconvo Cloud** і **DeepSeek (Enconvo Cloud)**. Дивіться [Пошук в інтернеті](/uk/ai/web-search).
- Розпізнавання мовлення з **Enconvo Cloud Fast**. Дивіться [Розпізнавання мовлення](/uk/ai/speech-recognition).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Запити просять увійти | Увійдіть в **Параметри → Обліковий запис**. |
| Запити завершуються помилкою балів або балансу | Перевірте **Параметри → Використання балів**, потім свій план на сторінці [Плану Cloud](https://www.enconvo.com/cloud-plan). |
| Моделі немає | Вибір показує те, що включає ваш план. Натисніть **Оновити** поруч із **Назва моделі**. |

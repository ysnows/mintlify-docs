Soniox перетворює мовлення на текст у реальному часі й із файлів багатьма мовами, а також може перекладати субтитри наживо під час запису. Користуйтеся ним через Enconvo Cloud без ключа або з власним ключем API Soniox.

<Note>
**Soniox (Enconvo Cloud)** не потребує ключа API, а диктування через Soniox безкоштовне для учасників Cloud Plan, Lifetime і пробного періоду.
</Note>

## Підключення

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="Виберіть провайдера">
        Відкрийте **Параметри → Моделі диктування** і виберіть **Soniox (Enconvo Cloud)**.
      </Step>
      <Step title="Перевірте роботу">
        Продиктуйте коротке речення. Текст має з’являтися, поки ви говорите.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Власний ключ API">
    <Steps>
      <Step title="Отримайте ключ API">
        У [консолі Soniox](https://console.soniox.com) відкрийте свій проєкт і створіть ключ API.
      </Step>
      <Step title="Додайте його в Enconvo">
        Відкрийте **Параметри → Моделі диктування** і виберіть **Soniox**. Вставте ключ в облікові дані Soniox, а потім натисніть **Перевірити**.
      </Step>
      <Step title="Перевірте роботу">
        Продиктуйте коротке речення. Текст має з’являтися, поки ви говорите.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Щоб використовувати Soniox також для записів чи файлів, виберіть його в **Параметри → Моделі для запису** або **Параметри → Моделі транскрибування**. Кожна сторінка зберігає власний вибір.

## Моделі та параметри

| Параметр | Що він робить |
| --- | --- |
| **Модель** | Модель Soniox. Моделі реального часу, як-от **Soniox STT Realtime v5** (типово), записують текст, поки ви говорите; асинхронні моделі, як-от **Soniox STT Async v5**, транскрибують готові файли. Див. [моделі Soniox](https://soniox.com/docs/stt/models). |
| **Language Hints** | Мови, яким віддавати перевагу; типово англійська та китайська. Додайте кілька, якщо під час розмови ви перемикаєте мови. |
| **Переклад наживо** | Перекладає субтитри наживо під час запису. Збережений запис зберігає транскрипт мовою оригіналу. Типово вимкнено. |
| **Перекласти з** | Мова аудіо. **Автоматично** дозволяє Soniox визначити її самому. |
| **Translate To** | Мова перекладених субтитрів. |
| **Speak Translation** | Озвучує перекладені субтитри вашим типовим голосом. Типово вимкнено. |

Soniox має також провайдерів синтезу мовлення — з вашим ключем або в Enconvo Cloud — у **Параметри → Синтез мовлення**.

Soniox обробляє аудіо в хмарі. Щоб мовлення залишалося на вашому Mac, використовуйте натомість локального провайдера, як-от Parakeet MLX, Qwen3 MLX або Whisper MLX.

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не проходить | Скопіюйте ключ із консолі Soniox ще раз без зайвих пробілів і переконайтеся, що він належить потрібному проєкту. |
| Текст не з’являється, поки ви говорите | Виберіть модель реального часу, а потім знову запустіть диктування. |
| Слова виходять не тією мовою | Задайте **Language Hints** для мов, якими ви справді говорите. |
| Файл не дає транскрипту | Спробуйте поширений формат, як-от MP3, WAV, FLAC або M4A, і перевірте використання та оплату в Soniox. |

---

Soniox перетворює мовлення на текст у реальному часі й із файлів, багатьма мовами, і може перекладати субтитри наживо під час запису. Використовуйте його через Enconvo Cloud без ключа або з власним ключем API Soniox.

<Note>
**Soniox (Enconvo Cloud)** не потребує ключа API, а диктування Soniox безкоштовне для учасників Cloud Plan, Lifetime і пробного періоду.
</Note>

## Під’єднати

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="Вибрати провайдера">
        Відкрийте **Параметри → Моделі диктування** і виберіть **Soniox (Enconvo Cloud)**.
      </Step>
      <Step title="Перевірити">
        Продиктуйте коротке речення. Текст має з’являтися, поки ви говорите.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Власний ключ API">
    <Steps>
      <Step title="Отримати ключ API">
        У [Soniox Console](https://console.soniox.com) відкрийте проєкт і створіть ключ API.
      </Step>
      <Step title="Додати його до Enconvo">
        Відкрийте **Параметри → Моделі диктування** і виберіть **Soniox**. Вставте ключ в облікові дані Soniox, потім натисніть **Перевірити**.
      </Step>
      <Step title="Перевірити">
        Продиктуйте коротке речення. Текст має з’являтися, поки ви говорите.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Щоб використовувати Soniox також для записів або файлів, виберіть його в **Параметри → Моделі для запису** або **Параметри → Моделі транскрибування**. Кожна сторінка зберігає власний вибір.

## Моделі й параметри

| Параметр | Що робить |
| --- | --- |
| **Модель** | Модель Soniox. Моделі реального часу, як-от **Soniox STT Realtime v5** (типово), пишуть текст, поки ви говорите; асинхронні моделі, як-от **Soniox STT Async v5**, транскрибують готові файли. Див. [моделі Soniox](https://soniox.com/docs/stt/models). |
| **Language Hints** | Мови, яким надавати перевагу, типово англійська й китайська. Додайте кілька, якщо перемикаєте мови під час розмови. |
| **Переклад наживо** | Перекладає субтитри наживо під час запису. Збережений запис лишає транскрипт оригінальною мовою. Типово вимкнено. |
| **Перекласти з** | Мова аудіо. **Auto** дає Soniox визначити її. |
| **Translate To** | Мова перекладених субтитрів. |
| **Speak Translation** | Читає перекладені субтитри вголос типовим голосом. Типово вимкнено. |

Soniox також має провайдерів синтезу мовлення, з власним ключем або на Enconvo Cloud, у **Параметри → Синтез мовлення**.

Soniox обробляє аудіо в хмарі. Щоб мовлення лишалося на Mac, натомість використовуйте локального провайдера, як-от Parakeet MLX, Qwen3 MLX або Whisper MLX.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| **Перевірити** не вдається | Скопіюйте ключ знову з Soniox Console без зайвих пробілів і перевірте, що він належить потрібному проєкту. |
| Текст не з’являється, поки ви говорите | Виберіть модель реального часу, потім почніть диктування знову. |
| Слова виходять неправильною мовою | Задайте **Language Hints** мовами, якими ви справді говорите. |
| Файл не дає транскрипту | Спробуйте поширений формат, як-от MP3, WAV, FLAC або M4A, і перевірте використання й оплату Soniox. |

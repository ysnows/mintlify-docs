Провайдер — це служба, що стоїть за функцією Enconvo: модель, яка відповідає в чаті, голос, що читає вголос, рушій, який шукає в інтернеті. Ви обираєте одного для кожної функції й можете їх комбінувати.

Відео нижче за 2 хвилини проходить **Параметри → Модель ШІ**: Auto Route, план Cloud, вхід із планом ChatGPT, Claude, GitHub Copilot, Antigravity чи Grok, ключі API, моделі на вашому Mac, Ollama та LM Studio і додавання власного провайдера.

## Виберіть спосіб підключення

| Якщо ви хочете | Використовуйте | Почніть тут |
| --- | --- | --- |
| Почати одразу, без ключів | Enconvo Cloud через ваш обліковий запис Enconvo | [Enconvo Cloud](/uk/providers/enconvo) |
| Щоб Enconvo підбирав модель для кожного повідомлення | Auto Route, типова модель | [Auto Route](/uk/providers/auto-route) |
| Скористатися планом, за який ви вже платите | Вхід із ChatGPT, Claude, Grok, Mistral, GitHub Copilot або Antigravity | [Вхід із планом](#вхід-із-планом) |
| Платити провайдеру напряму | Ваш власний ключ API | [Популярні провайдери](#популярні-провайдери) |
| Дістатися до моделей багатьох компаній за одним ключем | Шлюз, як-от OpenRouter чи PipeLLM | [OpenRouter](/uk/providers/openrouter), [PipeLLM](/uk/providers/pipellm) |
| Тримати чати на вашому Mac | Локальна модель | [Локальні моделі](/uk/ai/local-llm) |
| Використовувати моделі, які ви вже запускаєте в Ollama чи LM Studio | Провайдер **Ollama** або **LM Studio** | [Ollama](/uk/providers/ollama), [LM Studio](/uk/providers/lm-studio) |
| Використовувати моделі у власних чатах програми для iPhone | Чати на телефоні | [Чати на телефоні](/uk/integrations/iphone-phone-chats) |

## Виберіть модель для чату

<Steps>
  <Step title="Відкрийте Модель ШІ">
    Відкрийте **Параметри → Модель ШІ**. Середній стовпець перелічує всіх провайдерів: **Auto Route** і **Enconvo Cloud Plan** угорі, далі компанії, локальні моделі та всі інші провайдери.
  </Step>
  <Step title="Виберіть провайдера та під’єднайте його">
    Натисніть провайдера. Якщо він пропонує обидва варіанти, виберіть **Ключ API**, щоб платити провайдеру за кожен запит власним ключем, або варіант підписки (наприклад, **Підписка ChatGPT**), щоб увійти й користуватися тим, що включає ваш план.
  </Step>
  <Step title="Виберіть модель">
    Виберіть модель у **Назва моделі** та **Рівень міркування**, якщо провайдер його має.
  </Step>
  <Step title="Зробіть її типовою">
    Натисніть **Зробити стандартним**. Чати та функції, що не вказують власної моделі, тепер використовують її.
  </Step>
</Steps>

Щоб додати службу, якої немає в списку, натисніть **Додати нового провайдера** внизу списку й виберіть **Сумісний з OpenAI** або **Сумісний з Anthropic**.

Ви можете змінювати провайдерів у будь-який час; ваші чати нічим не прив’язані до однієї компанії.

Угорі **Параметри → Модель ШІ** також є **Моделі завдань** — для малих моделей, що стоять за назвами чатів і підказками, та **Резервний варіант** — для резервних моделей, які перебирають роботу, коли модель чату недоступна. Дивіться [Вибір моделі](/uk/ai/model-selection-guide).

## Задайте провайдера для кожної функції

Кожна функція має власну сторінку параметрів: **Модель ШІ**, **Синтез мовлення**, **Пошук в інтернеті**, **Генерація зображень**, **Генерація відео**, **Отримання вебвмісту** та **OCR**. Розпізнавання мовлення має окремі сторінки для **Моделі диктування**, **Моделі для запису**, **Моделі транскрибування** і **Модель субтитрування**. Вбудовування та повторне ранжування задаються в Базі знань.

Вибір моделі для чату не змінює вашого провайдера мовлення, зображень чи пошуку. Задайте кожного там, де потрібно.

## Профілі

Профіль провайдера містить один ключ або вхід. Натисніть **Додати нового провайдера** на сторінці провайдера, щоб зберегти другий, наприклад робочий обліковий запис. Деякі профілі обслуговують кілька функцій: один профіль OpenAI охоплює чат, вбудовування, синтез мовлення, зображення й транскрибування, тож зміна його ключа змінює все це. Дивіться [Облікові дані та профілі](/uk/configuration/credentials).

Де задається ваша типова модель і як кожен чат зберігає власну, описано в [Виборі моделі](/uk/ai/model-selection-guide).

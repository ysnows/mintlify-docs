Провайдер — це сервіс за функцією Enconvo: модель, яка відповідає в чаті, голос, який читає вголос, рушій, який шукає в інтернеті. Ви обираєте одного для кожної функції і можете їх поєднувати.

Відео нижче за 2 хвилини проходить **Параметри → Модель ШІ**: Auto Route, план Cloud, вхід через план ChatGPT, Claude, GitHub Copilot, Antigravity або Grok, ключі API, моделі на Mac, Ollama і LM Studio, а також додавання власного провайдера.

## Оберіть, як під’єднатися

| Якщо хочете | Використайте | Почніть тут |
| --- | --- | --- |
| Почати одразу, без ключів | Enconvo Cloud через обліковий запис Enconvo | [Enconvo Cloud](/uk/providers/enconvo) |
| Нехай Enconvo обирає модель для кожного повідомлення | Auto Route, типову модель | [Auto Route](/uk/providers/auto-route) |
| Використати план, за який ви вже платите | Увійдіть через ChatGPT, Claude, Grok, Mistral, GitHub Copilot або Antigravity | Див. розділ «Увійдіть через план» нижче |
| Платити провайдеру напряму | Власний ключ API | Див. розділ «Популярні провайдери» нижче |
| Досягати моделей багатьох компаній одним ключем | Шлюз, наприклад OpenRouter або PipeLLM | [OpenRouter](/uk/providers/openrouter), [PipeLLM](/uk/providers/pipellm) |
| Тримати чати на Mac | Локальну модель | [Локальні моделі](/uk/ai/local-llm) |
| Використати моделі, які вже запущені в Ollama або LM Studio | Провайдера **Ollama** або **LM Studio** | [Ollama](/uk/providers/ollama), [LM Studio](/uk/providers/lm-studio) |
| Використати моделі у власних чатах програми iPhone | Телефонні чати | [Телефонні чати](/uk/integrations/iphone-phone-chats) |

## Оберіть модель чату

<Steps>
  <Step title="Відкрийте Модель ШІ">
    Відкрийте **Параметри → Модель ШІ**. Середній стовпець перелічує кожного провайдера: **Auto Route** і **План Enconvo Cloud** угорі, потім компанії, локальні моделі й усіх інших провайдерів.
  </Step>
  <Step title="Оберіть провайдера і під’єднайте його">
    Клацніть провайдера. Де є обидва варіанти, оберіть **Ключ API**, щоб платити провайдеру за запит власним ключем, або варіант підписки (наприклад **ChatGPT Subscription**), щоб увійти і використати те, що входить у план.
  </Step>
  <Step title="Оберіть модель">
    Оберіть модель у **Назва моделі** і **Рівень міркування**, де провайдер його має.
  </Step>
  <Step title="Зробіть її типовою">
    Клацніть **Зробити стандартним**. Чати й функції, які не називають власну модель, тепер використовують її.
  </Step>
</Steps>

Щоб додати сервіс, якого немає в списку, клацніть **Додати нового провайдера** внизу списку й оберіть **Сумісний з OpenAI** або **Сумісний з Anthropic**.

Провайдерів можна змінювати будь-коли; ніщо не прив’язує чати до однієї компанії.

Угорі **Параметри → Модель ШІ** також є **Моделі завдань** для малих моделей за назвами чатів і пропозиціями, і **Резервний варіант** для запасних моделей, які переймають роботу, коли модель чату не можна використати. Див. [Оберіть модель](/uk/ai/model-selection-guide).

## Задайте провайдера для кожної функції

Кожна функція має власну сторінку параметрів: **Модель ШІ**, **Синтез мовлення**, **Пошук в інтернеті**, **Генерація зображень**, **Генерація відео**, **Отримання веб-сторінок** і **OCR**. Розпізнавання мовлення має окремі сторінки для **Моделі диктування**, **Моделі запису**, **Моделі транскрибування** і **Модель субтитрів**. Ембедінги й переранжування задаються в базі знань.

Вибір моделі чату не змінює провайдера мовлення, зображень чи пошуку. Задайте кожного там, де хочете.

## Профілі

Профіль провайдера тримає один ключ або вхід. Клацніть **Додати нового провайдера** на сторінці провайдера, щоб тримати другий, наприклад робочий обліковий запис. Деякі профілі обслуговують кілька функцій: один профіль OpenAI покриває чат, ембедінги, синтез мовлення, зображення й транскрибування, тож зміна його ключа змінює все це. Див. [Облікові дані й профілі](/uk/configuration/credentials).

Де задано типову модель і як кожен чат тримає свою, описано в [Оберіть модель](/uk/ai/model-selection-guide).

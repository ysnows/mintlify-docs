Вікна і голосові можливості Enconvo відкриваються гарячою клавішею. **Параметри → Сполучення клавіш** перелічує кожну гарячу клавішу, яку використовує Enconvo, і команду, яку вона виконує, тож можна змінити одну або дізнатися, що робить комбінація. Гарячі клавіші, збережені на вашому Mac, завжди мають пріоритет над типовими значеннями в цьому посібнику.

Це відео охоплює сполучення клавіш, а потім інші параметри, які підганяють Enconvo до вашого Mac: розуміння контексту, Appshots, локальні моделі, дозволи і запобігання сну.

## Типові сполучення

| Дія | Типове |
| --- | --- |
| Показати SmartBar | **⌥Space** |
| Показати вікно чату | **⌃⌘X** |
| Показати бічну панель програми | **⌃⌘E** |
| Відкрити параметри зсередини Enconvo | **⌘,** |
| Почати диктування | **Right ⌘** |
| Почати голосову команду | **Right ⌥** |
| Пауза/відновити аудіо | **⌥P** |

Ці типові значення діють, лише якщо ви ніколи не задавали власну клавішу; задана вами клавіша лишається як є. Швидкий запис і Appshots не мають типової гарячої клавіші: задайте її на їхніх сторінках параметрів, перш ніж користуватися.

## Змінити гарячу клавішу

1. Відкрийте **Параметри → Сполучення клавіш**. Вкладка **Основні** містить головні можливості, **Інші гарячі клавіші** — ШІ-команди, плагіни, параметри і команди, яких немає на інших сторінках, а **Усі** показує обидва.
2. Введіть текст у **Фільтр за назвою…**, щоб знайти команду. Щоб знайти команду за комбінацією клавіш, натисніть **Знайти за гарячою клавішею** і натисніть її.
3. Натисніть поле гарячої клавіші команди і натисніть нову комбінацію.
4. Якщо ці клавіші вже виконують іншу команду, поле повідомить. Оберіть **Використати тут**, щоб перенести клавіші на цю команду, або одну з вільних гарячих клавіш, які воно пропонує.
5. Перейдіть до іншої програми і спробуйте гарячу клавішу.

Щоб звільнити клавіші гарячої клавіші, приберіть її з команди. Повідомлення з **Скасувати** дає змогу повернути це.

Позначка **Локально** позначає гарячу клавішу, яка працює лише всередині Enconvo, наприклад закріпити SmartBar.

## Як натискати

Коли ви записуєте одну клавішу-модифікатор саму по собі, наприклад Right ⌘, поле запитує **Спосіб натискання**:

| Варіант | Команда виконується, коли ви |
| --- | --- |
| **Утримувати або торкнутися** | Утримуєте клавішу або торкаєтесь, щоб перемкнути |
| **Торкніться** | Торкаєтесь клавіші, щоб почати, і торкаєтесь знову, щоб зупинити |
| **Утримувати** | Утримуєте клавішу; працює, поки ви її тримаєте |
| **Подвійний дотик** | Швидко торкаєтесь клавіші двічі |

Дві або більше клавіш-модифікаторів, натиснутих одночасно, рахуються як одна гаряча клавіша. Кожне поле показує лише види, які підтримує його команда, а опис поруч каже, як ця можливість реагує.

## Де живе гаряча клавіша кожної можливості

Окрім сторінки сполучень, кожна можливість має гарячу клавішу на власній сторінці параметрів:

| Можливість | Сторінка параметрів |
| --- | --- |
| SmartBar | **Параметри → SmartBar** |
| Dynamic Island | **Параметри → Dynamic Island** |
| PopBar | **Параметри → PopBar** |
| Бічна панель програми | **Параметри → Бічна панель програми** |
| Диктування | **Параметри → Диктування** |
| Голосова команда | **Параметри → Голосова команда** |
| Appshots | **Параметри → Appshots** |
| Малювання на екрані | **Параметри → Малювання на екрані** |
| Голосова нотатка | **Параметри → Голосова нотатка** |
| Швидкий запис | **Параметри → Швидкий запис** |
| Окрема команда | Параметри цієї команди, якщо в неї є поле **Гаряча клавіша** |

## Усередині SmartBar

Введіть символ-тригер у SmartBar, щоб шукати один тип елементів:

| Символ | Відкриває |
| --- | --- |
| **@** | Команди |
| **#** | Контекст, який додати до повідомлення |
| **$** | Навички |
| **>** | Нещодавні завдання |

Змініть ці символи в **Пошук** у **Параметри → SmartBar**. Меню скісної риски містить дії, наприклад вибір моделі і міркування.

Щоб рухатися списками з клавіатури, оберіть **Клавіші навігації** в **Параметри → SmartBar**: **macOS** використовує **⌃N** **⌃P** **⌃F** **⌃B**, а **Vim** — **⌃J** **⌃K** **⌃L** **⌃H**.

## Підігнати Enconvo до вашого Mac

Те саме вікно параметрів містить інші вибори, які показує відео:

| Сторінка параметрів | Що вона робить |
| --- | --- |
| **Розуміння контексту** | Обирає, що SmartBar підхоплює з програми, у якій ви були: виділений текст, виділення у Finder або сторінку в браузері. **Долучати** додає це, щойно відкривається SmartBar, а **Запропонувати** пропонує це одним натисканням. Див. [Розуміння контексту](/uk/features/context-awareness). |
| **Appshots** | Додає вікно перед вами до розмови гарячою клавішею. Див. [Appshots](/uk/features/appshots). |
| **Локальні моделі** | Показує ШІ, що працює на цьому Mac, пам’ять і диск, які він використовує, і де працює кожна можливість. Див. [Локальні моделі](/uk/ai/local-llm). |
| **Дозволи** | Перелічує, що macOS дозволяє Enconvo і чому; **Надати** виправляє відсутній дозвіл. Див. [Дозволи macOS](/uk/configuration/permissions). |
| **Запобігати сну** | Не дає цьому Mac заснути, поки вас немає, щоб ви все одно могли дістатися до нього з iPhone. |

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Гаряча клавіша працює лише всередині Enconvo | Перевірте, чи є позначка **Локально**. Якщо ні, перевірте моніторинг введення і доступність у [Дозволи macOS](/uk/configuration/permissions) і чи інша програма не використовує ті самі клавіші. |
| Натискання гарячої клавіші робить щось інше | Використайте **Знайти за гарячою клавішею**. Якщо жодна команда Enconvo не використовує ці клавіші, їх використовує інша програма або macOS. |
| Гаряча клавіша-модифікатор не спрацьовує | Відкрийте гарячу клавішу і перевірте **Спосіб натискання**: утримування, дотик, подвійний дотик або клавіші, натиснуті разом. |
| Сполучення з відео або іншого Mac не працює | Ваші гарячі клавіші можуть відрізнятися. Подивіться поточну в **Параметри → Сполучення клавіш**. |

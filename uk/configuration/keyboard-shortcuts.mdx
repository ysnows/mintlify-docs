Вікна та голосові функції Enconvo відкриваються гарячими клавішами. **Параметри → Сполучення клавіш** перелічує кожну гарячу клавішу Enconvo та команду, яку вона запускає, тож можна змінити будь-яку з них або дізнатися, що робить комбінація клавіш. Гарячі клавіші, збережені на вашому Mac, завжди мають перевагу над типовими значеннями з цього посібника.

Це відео розповідає про Сполучення клавіш, а потім про інші параметри, що підлаштовують Enconvo під ваш Mac: Розуміння контексту, Appshots, Локальні моделі, Дозволи та Запобігати сну.

## Типові скорочення

| Дія | Типове значення |
| --- | --- |
| Показати SmartBar | **⌥Space** |
| Показати Вікно чату | **⌃⌘X** |
| Показати Бічну панель програми | **⌃⌘E** |
| Відкрити Параметри зсередини Enconvo | **⌘,** |
| Почати Диктування | **правий ⌘** |
| Почати Голосову команду | **правий ⌥** |
| Призупинити/відновити звук | **⌥P** |

Ці типові значення діють, лише якщо ви ніколи не задавали власну клавішу; задана вами клавіша лишається як є. Швидкий запис і Appshots не мають типової гарячої клавіші: задайте її на їхніх сторінках параметрів, перш ніж користуватися.

## Зміна гарячої клавіші

1. Відкрийте **Параметри → Сполучення клавіш**. Вкладка **Основні** містить головні функції, **Інші гарячі клавіші** — команди ШІ, плагіни, параметри та команди, яких не показує жодна інша сторінка, а **Усі** показує обидві.
2. Введіть текст у **Фільтрувати за назвою…**, щоб знайти команду. Щоб знайти команду за комбінацією клавіш, натисніть **Знайти за гарячою клавішею** і натисніть її.
3. Натисніть поле гарячої клавіші команди й натисніть нову комбінацію.
4. Якщо ці клавіші вже запускають іншу команду, поле повідомить про це. Оберіть **Використати тут**, щоб перенести клавіші на цю команду, або виберіть одну з вільних гарячих клавіш, які воно пропонує.
5. Перейдіть в іншу програму й спробуйте гарячу клавішу.

Щоб звільнити клавіші гарячої клавіші, приберіть її з команди. Повідомлення з кнопкою **Скасувати** дає змогу це відмінити.

Позначка **Локально** вказує на гарячу клавішу, що працює лише всередині Enconvo, наприклад Закріпити SmartBar.

## Спосіб натискання

Коли ви записуєте окрему клавішу-модифікатор, як-от правий ⌘, поле запитує **Спосіб натискання**:

| Варіант | Команда запускається, коли ви |
| --- | --- |
| **Утримувати або торкнутися** | Утримуєте клавішу або торкаєтеся її, щоб перемкнути |
| **Торкніться** | Торкаєтеся клавіші, щоб почати, і ще раз, щоб зупинити |
| **Утримувати** | Тримаєте клавішу натиснутою; працює, поки ви її тримаєте |
| **Подвійний дотик** | Швидко двічі торкаєтеся клавіші |

Дві або більше клавіш-модифікаторів, натиснутих одночасно, вважаються однією гарячою клавішею. Кожне поле показує лише ті види, які підтримує його команда, а опис поруч пояснює, як реагує ця функція.

## Де розташована гаряча клавіша кожної функції

Крім сторінки Сполучення клавіш, гаряча клавіша кожної функції є на її власній сторінці параметрів:

| Функція | Сторінка параметрів |
| --- | --- |
| SmartBar | **Параметри → SmartBar** |
| Dynamic Island | **Параметри → Dynamic Island** |
| PopBar | **Параметри → PopBar** |
| Бічна панель програми | **Параметри → Бічна панель програми** |
| Диктування | **Параметри → Диктування** |
| Голосова команда | **Параметри → Голосова команда** |
| Appshots | **Параметри → Appshots** |
| Малювання на екрані | **Параметри → Малювання на екрані** |
| Голосова нотатка | **Параметри → Голосова нотатка** |
| Швидкий запис | **Параметри → Швидкий запис** |
| Окрема команда | Параметри цієї команди, якщо в неї є поле **Гаряча клавіша** |

## Усередині SmartBar

Введіть у SmartBar символ-тригер, щоб шукати один вид елементів:

| Символ | Відкриває |
| --- | --- |
| **@** | Команди |
| **#** | Контекст, який додається до вашого повідомлення |
| **$** | Навички |
| **>** | Недавні завдання |

Змінити ці символи можна в розділі **Пошук** у **Параметри → SmartBar**. Меню зі скісною рискою містить дії, як-от вибір моделі та міркування.

Щоб пересуватися списками за допомогою клавіатури, виберіть **Клавіші навігації** в **Параметри → SmartBar**: **macOS** використовує **⌃N** **⌃P** **⌃F** **⌃B**, а **Vim** — **⌃J** **⌃K** **⌃L** **⌃H**.

## Підлаштуйте Enconvo під свій Mac

У тому самому вікні параметрів є інші варіанти, які розглядає відео:

| Сторінка параметрів | Що вона робить |
| --- | --- |
| **Розуміння контексту** | Визначає, що SmartBar підхоплює з програми, у якій ви були: виділений текст, вибір у Finder або сторінку у вашому браузері. **Долучати** додає це одразу, щойно відкривається SmartBar, а **Запропонувати** пропонує це одним клацанням. Дивіться [Розуміння контексту](/uk/features/context-awareness). |
| **Appshots** | Додає до розмови вікно перед вами гарячою клавішею. Дивіться [Appshots](/uk/features/appshots). |
| **Локальні моделі** | Показує ШІ, що працює на цьому Mac, пам’ять і диск, які він використовує, і де запускається кожна функція. Дивіться [Локальні моделі](/uk/ai/local-llm). |
| **Дозволи** | Перелічує, що macOS дозволяє Enconvo і навіщо; **Надати** виправляє відсутній дозвіл. Дивіться [Дозволи macOS](/uk/configuration/permissions). |
| **Запобігати сну** | Не дає цьому Mac засинати, поки вас немає, щоб ви все одно могли дістатися до нього з iPhone. |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Гаряча клавіша працює лише всередині Enconvo | Перевірте, чи має вона позначку **Локально**. Якщо ні, перевірте Моніторинг введення й Універсальний доступ у [Дозволах macOS](/uk/configuration/permissions) та чи не використовує ті самі клавіші інша програма. |
| Натискання гарячої клавіші робить щось інше | Скористайтеся **Знайти за гарячою клавішею**. Якщо клавіші не використовує жодна команда Enconvo, їх використовує інша програма або macOS. |
| Гаряча клавіша з модифікатором не спрацьовує | Відкрийте гарячу клавішу й перевірте **Спосіб натискання**: утримування, дотик, подвійний дотик або клавіші разом. |
| Скорочення з відео чи з іншого Mac не працює | Ваші гарячі клавіші можуть відрізнятися. Дізнайтеся поточну в **Параметри → Сполучення клавіш**. |

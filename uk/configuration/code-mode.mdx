title: "Режим коду"
description: "Нехай агент напише один короткий скрипт, який робить багато викликів інструментів одразу і повертає лише результат."
---

Режим коду дає агенту зробити за один крок те, що інакше потребувало б багатьох: він пише короткий скрипт, який робить багато викликів інструментів, паралельно або по черзі, і повертає лише результат. Звертайтеся до нього, коли завдання повторює той самий виклик для багатьох елементів, наприклад перевіряє список сторінок або збирає результати з кількох сервісів, тож робота швидша, а чат не заповнюється кожним проміжним результатом.

Ви самі режим коду не викликаєте. Коли він увімкнений, агент користується ним, щойно завдання підходить, а чат показує картку з викликами, які зробив скрипт.

## Налаштуйте режим коду

1. Відкрийте **Параметри → Режим коду**. **Режим коду** також можна відкрити з вкладки **Вбудований** сторінки плагінів.
2. У розділі **Доступ скриптів** увімкніть те, що скрипт може викликати. Кожен виклик усе одно питає вас так, як каже [режим дозволів](/uk/ai/agents) чату.
3. Оберіть, які моделі можуть писати скрипти, що показує чат і що відбувається, коли скрипт працює довго.

## Параметри

**Доступ скриптів** перелічує, що скрипт може викликати:

| Доступ | Що дозволяє | Типово |
| --- | --- | --- |
| **Плагіни** | Пошук, база знань, документи та інші маршрути плагінів | Увімкнено |
| **Конектори та MCP** | Ваші пов’язані облікові записи та інструменти MCP | Увімкнено |
| **Файли** | Читання та запис файлів | Увімкнено |
| **Команди оболонки** | Запуск команд у терміналі | Увімкнено |
| **Браузер** | [Використання браузера](/uk/features/browser-control) у вашому браузері | Увімкнено |
| **Програми** | [Використання комп’ютера](/uk/features/computer-use) у межах його списку доступу до програм | Увімкнено |
| **Інші агенти** | Запуск або повідомлення субагентів | Вимкнено |
| **Виклики моделі** | Невелика модель, щоб підсумувати або оцінити елементи | Увімкнено |

Інші параметри:

| Параметр | Варіанти |
| --- | --- |
| **Use with** | **Models that write code well** (інші роблять виклики по одному) або **Every model**. |
| **Show in the chat** | **The calls** або **The calls and the code**. |
| **When a script runs long** | **Keep going, up to 2 hours** у тлі або **Stop after 10 minutes**. |

## Режим коду поза чатом

Коли скрипт працює поза чатом, наприклад в автоматизації, він викликає лише інструменти, які читають: вбудовані пошуки та читання, публічні вебсторінки, звичайні файли та інструменти MCP, які не кажуть, що щось змінюють. Enconvo перевіряє кожен виклик знову безпосередньо перед запуском.

## Використайте скрипт у навичці

Навичка може тримати скрипт режиму коду у власній папці `scripts` і запускати його як один зі своїх кроків. Див. [Навички](/uk/configuration/skills).

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Агент робить виклики по одному | Перевірте **Use with**. З **Models that write code well** інші моделі не користуються режимом коду. |
| Скрипт не досягає інструмента | Увімкніть цей вид доступу в **Доступ скриптів**. Поза чатом скрипти лише читають. |
| Довгий скрипт зупинився | З **Stop after 10 minutes** довші скрипти завершуються. Оберіть **Keep going, up to 2 hours**. |

Деякі функції Enconvo потребують доступу, який macOS просить вас схвалити, наприклад бачити ваш екран або вводити текст в інших програмах. **Параметри → Дозволи** перелічує кожен дозвіл, що він забезпечує і чи надано його. Текстовий чат не потребує жодного з них, тому Enconvo не питає під час запуску: він питає, коли ви вперше використовуєте функцію, якій потрібен дозвіл, і повідомляє, яка саме функція питала.

## Коли Enconvo питає

Коли ви використовуєте функцію, якій потрібен ненаданий дозвіл, Enconvo відкриває своє вікно дозволів, називає функцію та пропонує **Відкрити Системні параметри**. Можна також вибрати **Не зараз**.

Щоб функція більше не питала, позначте у вікні **Більше не питати** для цієї функції. Тоді функція не питатиме, доки ви не зміните це на сторінці Дозволів. Для Запису екрана, коли доступ лише чекає на перезапуск, вікно пропонує **Перезапустити**.

## Надання дозволу

1. Відкрийте **Параметри → Дозволи**.
2. Знайдіть дозвіл і натисніть **Надати**.
3. macOS показує свій запит або відкриває відповідну панель у **Системні параметри → Конфіденційність і безпека**. Для Універсального доступу та Моніторингу введення увімкніть перемикач Enconvo на цій панелі самостійно.
4. Якщо macOS просить, закрийте й знову відкрийте Enconvo.
5. Повернувшись в Enconvo, ви побачите в рядку **Надано**. Спробуйте функцію ще раз.

Сторінка сама перевіряє стан, коли ви на неї повертаєтеся. Натисніть **Оновити**, щоб перевірити негайно.

## Які функції використовують дозвіл

Під кожним дозволом **Використовується в** перелічує функції, яким він потрібен, і чи питатиме кожна з них:

| Стан | Значення |
| --- | --- |
| **Питає під час використання** | Функція попросить дозвіл наступного разу, коли ви її використаєте. |
| **Відхилено · питає за гарячою клавішею** | Ви відхилили; функція питає знову лише тоді, коли ви натискаєте її гарячу клавішу. |
| **Не питатиме** | Ви вибрали **Більше не питати**. Натисніть, щоб повернутися до **Питає під час використання**. |
| **Вимкнено** або **Плагін вимкнено** | Функцію або плагін, до якого вона належить, вимкнено. |

## Для чого потрібен кожен дозвіл

| Дозвіл | Для чого використовується |
| --- | --- |
| Універсальний доступ | Читання інтерфейсів програм, клацання, введення тексту та керування вікнами: Використання комп’ютера, PopBar, виділений текст і вставлення тексту |
| Запис екрана | Знімки екрана, що дають агентам бачити вміст програм: Використання комп’ютера, Appshots, контекст екрана та захоплення для OCR. macOS може називати його «Запис екрана та системного звуку», і він також охоплює захоплення системного звуку. |
| Моніторинг введення | Глобальне введення з клавіатури для PopBar, гарячих клавіш і подвійних модифікаторів, коли попереду інші програми |
| Мікрофон | Диктування, Голосова команда, Голосова нотатка, запис зустрічей, живі субтитри та Live Talk |
| Сповіщення | Сповіщення macOS, коли сеанс Agent завершується або потребує вашої уваги |
| Камера | Живі фото з камери за допомогою перемикача камери SmartBar |
| Геопозиція | Місцева погода в Dynamic Island і контекст місцеперебування для агентів |
| Автоматизація | Керування іншими програмами через Apple Events: читання вкладок браузера, вибору у Finder, Mail, Messages і System Events |
| Локальна мережа | Під’єднання до серверів моделей на іншому комп’ютері у вашій мережі. Її немає на сторінці Дозволів; знайдіть її в **Системні параметри → Конфіденційність і безпека → Локальна мережа**. |

Calendar, Reminders, Notes, Mail та інші програми Apple під’єднуються натомість на сторінці **Плагіни**. Дивіться [Програми Apple](/uk/integrations/apple-ecosystem).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Дозвіл увімкнено, але захоплення все одно не працює | Закрийте й знову відкрийте Enconvo, потім спробуйте ще раз. Переконайтеся, що ви ввімкнули ту програму Enconvo, яку запустили, а не стару копію. |
| Функція ніколи не просить потрібний дозвіл | Перевірте її рядок у розділі **Використовується в**. Якщо там **Не питатиме**, натисніть його або надайте дозвіл кнопкою **Надати**. |
| Запис екрана показано як наданий, але захоплення все одно не працює | Натисніть **Перезапустити** у вікні дозволів або закрийте й знову відкрийте Enconvo. |
| Диктування показує текст, але не вставляє його | Перевірте Універсальний доступ і те, що цільове поле приймає введення чи вставлення. |
| Гаряча клавіша працює лише всередині Enconvo | Перевірте Моніторинг введення та Універсальний доступ. Про гарячі клавіші, що конфліктують з іншими програмами, дивіться [Клавіатурні скорочення](/uk/configuration/keyboard-shortcuts). |
| Сервер моделей на іншому комп’ютері не під’єднується | Перевірте Локальну мережу та те, що сервер слухає на своїй мережевій адресі. |
| Немає банера, коли Agent завершує роботу | Перевірте тут Сповіщення, Фокус macOS і **Надіслати системне сповіщення** в [Сповіщеннях](/uk/configuration/notifications). |

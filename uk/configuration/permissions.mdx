Деяким функціям Enconvo потрібен доступ, який macOS просить вас схвалити, наприклад бачити екран або вводити текст в інші програми. **Параметри → Дозволи** перелічує кожен дозвіл, що він забезпечує і чи його надано. Текстовому чату жоден не потрібен, тож Enconvo не питає під час запуску: він питає вперше, коли ви використовуєте функцію, якій потрібен дозвіл, і каже, яка функція спитала.

## Коли Enconvo питає

Коли ви використовуєте функцію, якій потрібен дозвіл, якого ви ще не надали, Enconvo відкриває вікно дозволу, називає функцію і пропонує **Відкрити Системні параметри**. Можна також обрати **Не зараз**.

Щоб функція більше не питала, позначте **Don't ask again for** цю функцію у вікні. Тоді функція не питатиме, поки ви не зміните це на сторінці дозволів. Для запису екрана, коли доступ лише чекає перезапуску, вікно пропонує **Перезапустити**.

## Надати дозвіл

1. Відкрийте **Параметри → Дозволи**.
2. Знайдіть дозвіл і натисніть **Надати**.
3. macOS показує свій запит або відкриває відповідну панель у **Системні параметри → Конфіденційність і безпека**. Для доступності та моніторингу вводу увімкніть перемикач Enconvo на цій панелі самостійно.
4. Якщо macOS просить, завершіть Enconvo і відкрийте знову.
5. Повернувшись в Enconvo, побачите в рядку **Надано**. Спробуйте функцію ще раз.

Сторінка перевіряє сама, коли ви до неї повертаєтеся. Натисніть **Оновити**, щоб перевірити одразу.

## Подивитися, які функції використовують дозвіл

Під кожним дозволом **Використовується в** перелічує функції, яким він потрібен, і чи кожна з них питатиме:

| Стан | Значення |
| --- | --- |
| **Питає під час використання** | Функція попросить дозвіл наступного разу, коли ви її використаєте. |
| **Відхилено · питає за гарячою клавішею** | Ви відхилили; функція питає знову лише коли ви натискаєте її гарячу клавішу. |
| **Не питатиме** | Ви обрали більше не питати. Натисніть, щоб повернутися до **Питає під час використання**. |
| **Вимкнено** або **Плагін вимкнено** | Функцію або плагін, якому вона належить, вимкнено. |

## Для чого кожен дозвіл

| Дозвіл | Для чого |
| --- | --- |
| Доступність | Читання інтерфейсів програм, натискання, введення та керування вікнами: використання комп’ютера, PopBar, виділений текст і вставлення тексту |
| Запис екрана | Знімки екрана, щоб агенти бачили вміст програм: використання комп’ютера, Appshots, контекст екрана та знімання для OCR. macOS може називати це Screen & System Audio Recording, і воно також покриває захоплення системного звуку. |
| Моніторинг вводу | Глобальний ввід з клавіатури для PopBar, гарячих клавіш і подвійних модифікаторів, поки інші програми на передньому плані |
| Мікрофон | Диктування, голосова команда, голосова нотатка, запис зустрічі, субтитри наживо та Live Talk |
| Сповіщення | Сповіщення macOS, коли сеанс агента завершується або потребує вашої уваги |
| Камера | Живі фото з камери з перемикача камери SmartBar |
| Місце | Місцева погода в Dynamic Island і контекст місця для агентів |
| Автоматизація | Керування іншими програмами через Apple Events: читання вкладок браузера, виділень Finder, Mail, Messages і System Events |
| Локальна мережа | З’єднання з серверами моделей на іншому комп’ютері у вашій мережі. Його немає на сторінці дозволів; знайдіть у **Системні параметри → Конфіденційність і безпека → Локальна мережа**. |

Календар, нагадування, нотатки, пошта та інші програми Apple підключаються натомість на сторінці **Плагіни**. Див. [Програми Apple](/uk/integrations/apple-ecosystem).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Дозвіл увімкнено, але знімання все одно не вдається | Завершіть Enconvo і відкрийте знову, потім спробуйте ще раз. Переконайтеся, що увімкнули той Enconvo, який запущено, а не старішу копію. |
| Функція ніколи не просить потрібний дозвіл | Перевірте її рядок у **Використовується в**. Якщо там **Не питатиме**, натисніть його або надайте дозвіл через **Надати**. |
| Запис екрана показує надано, але знімання не вдається | Натисніть **Перезапустити** у вікні дозволу або завершіть Enconvo і відкрийте знову. |
| Диктування показує текст, але не вставляє його | Перевірте доступність і що цільове поле приймає введення або вставлення. |
| Гаряча клавіша працює лише всередині Enconvo | Перевірте моніторинг вводу та доступність. Див. [Комбінації клавіш](/uk/configuration/keyboard-shortcuts) щодо гарячих клавіш, які конфліктують з іншими програмами. |
| Сервер моделі на іншому комп’ютері не підключається | Перевірте локальну мережу і що сервер слухає свою мережеву адресу. |
| Немає банера, коли агент завершує | Перевірте сповіщення тут, Фокус macOS і **Надіслати системне сповіщення** в [Сповіщення](/uk/configuration/notifications). |

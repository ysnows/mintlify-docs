Вбудовані можливості нижче згруповано за завданнями, які вони підтримують. Наявність залежить від інстальованих розширень і збірки застосунку. Реалізації провайдерів наведено окремо в [Каталозі можливостей провайдерів](/uk/providers/catalog).

Скористайтеся SmartBar, щоб знайти команду за назвою. Відкрийте **Параметри → Плагіни**, щоб переглянути інстальовані розширення та налаштування їхніх команд. Інструменти Агента можна вибирати в параметрах Агента, а не як окремі команди запуску.

## Допоміжні сервіси

Деякі розширення надають інфраструктуру, а не команду, яку ви запускаєте напряму: локальні API, конфігурацію, маршрутизацію облікових даних, розбір документів, середовища виконання моделей, зберігання повідомлень, індексацію пошуку, керування плагінами та доставку через канали. Скористайтеся посібником із завдання для функції, яку вони підтримують, або [CLI і локальними API](/uk/advanced/cli-local-api) для інтеграційної роботи.

Mobile Companion підключає застосунок Enconvo для iPhone (бета) до вашого Mac; дивіться [Застосунок для iPhone](/uk/integrations/iphone-app), щоб з'єднати телефон. Для доступу через застосунки обміну повідомленнями скористайтеся [Каналами IM](/uk/integrations/messaging).

Пошук в інтернеті дає вашим Агентам актуальні результати з вебу. Шукати може кожен Агент; службу пошуку ви вибираєте окремо від моделі, яка пише відповідь.

## Виберіть провайдера пошуку

1. Відкрийте **Параметри → Пошук в інтернеті**.
2. Виберіть провайдера. Варіанти Enconvo Cloud не потребують ключа API; для більшості інших додайте свій ключ до цієї служби.
3. Натисніть **Зробити стандартним**.

| Провайдер | Примітки |
| --- | --- |
| **Автоматично** | Шукає за допомогою власного вебпошуку моделі чату, а якщо в моделі його немає, переходить до іншого провайдера. Див. [Пошук власним пошуком моделі](#пошук-власним-пошуком-моделі). |
| **Enconvo Cloud** | Безкоштовно для кожного облікового запису, у який виконано вхід, ключ API не потрібен |
| **DeepSeek (Enconvo Cloud)** | DeepSeek Search через Enconvo Cloud, безкоштовно для кожного облікового запису, у який виконано вхід |
| **Gemini** | Прив’язка до Google Search через модель Gemini |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | Пошук із вашим власним ключем до цієї служби |
| **Parallel** | Пошуковий індекс ШІ від Parallel, що повертає найрелевантніші уривки кожної сторінки, з вашим ключем API Parallel |
| **PipeLLM** | Результати Google через ваш ключ [PipeLLM](/uk/providers/pipellm) |
| **DeepSeek** | DeepSeek Search з вашим ключем API DeepSeek |
| **xAI X Search** | Шукає дописи, профілі й гілки в X, з ключем API xAI або входом в xAI |
| **xAI X Search (Enconvo Cloud)** | Пошук в X через тариф Enconvo Cloud |

У списку провайдерів безкоштовні варіанти позначено. Повний список дивіться в [Каталозі провайдерів](/uk/providers/catalog). У деяких моделей також є вбудовані варіанти прив’язки чи пошуку в параметрах їхнього провайдера.

## Пошук власним пошуком моделі

З варіантом **Автоматично** кожен пошук виконується вебпошуком моделі, яку використовує чат, якщо в неї він є: OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai та OpenRouter. Він використовує ключ чи вхід, які ви підключили для цієї моделі, а оплачує його вендор моделі.

Коли в моделі немає власного пошуку або її пошук завершується помилкою, «Автоматично» використовує **Резервний пошук**, яким є **Enconvo Cloud**, доки ви не виберете іншого провайдера.

| Параметр | Що він робить |
| --- | --- |
| **Маршрут пошуку** | Показує, який пошук працює для моделі чату і що відбувається в разі помилки. |
| **Надавати перевагу пошуку моделі** | Увімкнено за замовчуванням. Вимкніть, щоб завжди використовувати резервний пошук. |
| **Резервний пошук** | Провайдер, який використовується, коли в моделі немає пошуку або він не вдається. |

У чаті кожен крок вебпошуку показує, який пошук відповів і чому «Автоматично» перейшов до резервного, коли це сталося.

## Використання Parallel

1. Отримайте ключ API на [Parallel](https://platform.parallel.ai).
2. Додайте його в **Параметри → Керування обліковими даними → Parallel**.
3. У **Параметри → Пошук в інтернеті** виберіть **Parallel** і оберіть **Search Mode**:

| Search Mode | Для чого |
| --- | --- |
| **Turbo** | Найшвидші відповіді. Читає лише запити англійською та японською. |
| **Fast** | Більшість пошуків. Типовий режим. |
| **Basic** | Довші уривки з кожної сторінки. |
| **Advanced** | Найглибший пошук. Триває близько 3 секунд і коштує дорожче. |

Parallel стягує плату за кожен пошук з вашого облікового запису Parallel.

## Пошук з Агентом

1. Поставте конкретне запитання. Вкажіть діапазон дат чи місце, коли це важливо.
2. Агент шукає й відповідає з посиланнями на свої джерела.
3. Відкрийте наведені джерела й перевірте, що вони підтверджують відповідь.

Спробуйте:

> Знайди офіційні нотатки до випуску останньої стабільної версії цієї бібліотеки та підсумуй зміни, що ламають сумісність, з посиланнями.

## Виберіть правильну можливість вебу

| Потреба | Що використати |
| --- | --- |
| Знайти релевантні джерела | Пошук в інтернеті |
| Прочитати відому URL-адресу | [Отримання вебвмісту](/uk/ai/web-fetch) |
| Відкрити результати у браузері | [Швидкі посилання](/uk/features/quick-links) |
| Працювати з вебсайтом, де ви ввійшли | [Використання браузера](/uk/features/browser-control) |
| Шукати дописи, профілі чи гілки в X | Провайдер **xAI X Search** |

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| У відповіді немає джерел | Перевірте, що Агент шукав, а не відповідав лише з моделі. Попросіть його пошукати в інтернеті. |
| Провайдер повідомляє про помилку | Перевірте облікові дані провайдера та ліміт вашого облікового запису в цій службі. |
| «Автоматично» використав резервний пошук | У моделі чату немає власного вебпошуку або її пошук не вдався. Крок пошуку в чаті показує, що саме. |
| Результат за входом або на інтерактивній сторінці | Скористайтеся підтримуваним сценарієм браузера, як-от [Використання браузера](/uk/features/browser-control). Отримання публічної URL-адреси не дає доступу до вашого сеансу з входом. |

Пошук в інтернеті дає агентам актуальні результати з вебу. Шукати може кожен агент; ви обираєте службу пошуку окремо від моделі, яка пише відповідь.

## Обрати провайдера пошуку

1. Відкрийте **Параметри → Вебпошук**.
2. Оберіть провайдера. Варіанти Enconvo Cloud не потребують ключа API; для більшості інших додайте свій ключ цієї служби.
3. Натисніть **Зробити стандартним**.

| Провайдер | Примітки |
| --- | --- |
| **Auto** | Шукає власним вебпошуком моделі чату і переходить на іншого провайдера, коли в моделі його немає. Див. [Пошук власним пошуком моделі](/uk/ai/web-search). |
| **Enconvo Cloud** | Безкоштовно для кожного облікового запису, в який увійшли; ключ API не потрібен |
| **DeepSeek (Enconvo Cloud)** | DeepSeek Search через Enconvo Cloud, безкоштовно для кожного облікового запису, в який увійшли |
| **Gemini** | Підкріплення Google Search через модель Gemini |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | Пошук власним ключем цієї служби |
| **Parallel** | Пошуковий індекс ШІ Parallel, який повертає найрелевантніші уривки кожної сторінки, з вашим ключем API Parallel |
| **PipeLLM** | Результати Google через ваш ключ [PipeLLM](/uk/providers/pipellm) |
| **DeepSeek** | DeepSeek Search з вашим ключем API DeepSeek |
| **xAI X Search** | Шукає дописи, профілі та гілки X, з ключем API xAI або входом xAI |
| **xAI X Search (Enconvo Cloud)** | Пошук X через тариф Enconvo Cloud |

Список провайдерів позначає безкоштовні варіанти. Повний список див. у [каталозі провайдерів](/uk/providers/catalog). Деякі моделі також мають вбудоване підкріплення або параметри пошуку у власних параметрах провайдера.

## Пошук власним пошуком моделі

З **Auto** кожен пошук іде через вебпошук моделі, яку використовує чат, якщо в моделі він є: OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai та OpenRouter. Він використовує ключ або вхід, який ви підключили для цієї моделі, і рахунок виставляє постачальник моделі.

Коли в моделі немає власного пошуку або він не вдається, Auto використовує **Резервний пошук**, який є **Enconvo Cloud**, якщо ви не обрали іншого провайдера.

| Параметр | Що він робить |
| --- | --- |
| **Маршрут пошуку** | Показує, який пошук працює для моделі чату і що станеться в разі невдачі. |
| **Надавати перевагу пошуку моделі** | Увімкнено типово. Вимкніть, щоб завжди використовувати резервний пошук. |
| **Резервний пошук** | Провайдер, якого використовують, коли в моделі немає пошуку або він не вдається. |

У чаті кожен крок вебпошуку каже, який пошук відповів і чому Auto перейшов на резервний, якщо так сталося.

## Використати Parallel

1. Отримайте ключ API від [Parallel](https://platform.parallel.ai).
2. Додайте його в **Параметри → Керування обліковими даними → Parallel**.
3. У **Параметри → Вебпошук** оберіть **Parallel** і виберіть **Search Mode**:

| Search Mode | Для чого |
| --- | --- |
| **Turbo** | Найшвидші відповіді. Читає лише запити англійською та японською. |
| **Fast** | Більшість пошуків. Типовий режим. |
| **Basic** | Довші уривки з кожної сторінки. |
| **Advanced** | Найглибший пошук. Триває близько 3 секунд і коштує більше. |

Parallel виставляє рахунок за кожен пошук на ваш обліковий запис Parallel.

## Шукати з агентом

1. Поставте конкретне запитання. Додайте діапазон дат або місце, коли це важливо.
2. Агент шукає і відповідає з посиланнями на джерела.
3. Відкрийте цитовані джерела і перевірте, що вони підтверджують відповідь.

Спробуйте:

> Знайди офіційні примітки до релізу останньої стабільної версії цієї бібліотеки і підсумуй несумісні зміни з посиланнями.

## Обрати потрібну вебможливість

| Потреба | Що використати |
| --- | --- |
| Знайти релевантні джерела | Пошук в інтернеті |
| Прочитати відомий URL | [Отримання вебвмісту](/uk/ai/web-fetch) |
| Відкрити результати у браузері | [Швидкі посилання](/uk/features/quick-links) |
| Взаємодіяти з сайтом, на якому ви ввійшли | [Використання браузера](/uk/features/browser-control) |
| Шукати дописи, профілі чи гілки X | Провайдер **xAI X Search** |

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| У відповіді немає джерел | Перевірте, що агент шукав, а не відповідав лише з моделі. Попросіть його пошукати в інтернеті. |
| Провайдер повідомляє про помилку | Перевірте облікові дані провайдера та ліміт вашого облікового запису в цій службі. |
| Auto використав резервний пошук | У моделі чату немає власного вебпошуку або він не вдався. Крок пошуку в чаті каже, який саме. |
| Результат за входом або на інтерактивній сторінці | Використайте підтримуваний потік браузера, наприклад [використання браузера](/uk/features/browser-control). Отримання публічного URL не дає доступу до вашого сеансу, в який ви ввійшли. |

---
title: "Web Fetch"
description: "Нехай агент прочитає вебсторінку за її URL або збережіть сторінку в базі знань."
---

Користуйтеся Web Fetch, коли URL уже є і ви хочете, щоб агент прочитав сторінку. Кожен агент може прочитати посилання, яке ви даєте; ви обираєте сервіс, який її отримує. Використовуйте [пошук в інтернеті](/uk/ai/web-search), коли спочатку треба знайти потрібні сторінки.

## Оберіть провайдера

1. Відкрийте **Параметри → Web Fetch**.
2. Оберіть провайдера і натисніть **Зробити стандартним**.

| Провайдер | Використання |
| --- | --- |
| **Local Fetch** | Отримує сторінки на Mac безкоштовно, з необов’язковим отриманням через браузер |
| **Jina AI Link Reader** | Отримує читабельний вміст через Jina |
| **Firecrawl Link Reader** | Отримує вміст через Firecrawl |
| **DeepSeek** | Читає сторінки як Markdown з вашим ключем API DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Читає сторінки як Markdown через Enconvo Cloud, ключ API не потрібен |
| **Enconvo Cloud Plan** | Використовує хмарний сервіс читання посилань |

## Прочитайте сторінку

1. Вставте URL у розмову і поставте конкретне питання про неї.
2. Перевірте отриманий вміст і джерело, перш ніж покладатися на відповідь.

## Сторінки за входом

З **Local Fetch** **Browser-Assisted Fetching** може прочитати сторінку через браузер родини Chromium із розширенням Enconvo Companion.

| Варіант | Що робить |
| --- | --- |
| **Auto** (типово) | Повторно використовує відповідну вкладку, яку ви вже відкрили, повністю відрендерену і з вашим входом. Використовує тимчасову фонову вкладку, коли пряме отримання не вдається або сторінці потрібен JavaScript. |
| **Off** | Лише прямий HTTP |
| **Always** | Завжди отримує через браузер |

Без підключеного браузера Local Fetch робить прямий HTTP-запит. Інші провайдери отримують публічну URL і не мають вашого входу в браузері. Для інтерактивних сторінок використовуйте [розширення браузера](/uk/features/browser-extension) або [використання браузера](/uk/features/browser-control).

## Зберігайте вебвміст

Додайте URL через **Додати → Окрема вебсторінка** в [базі знань](/uk/ai/knowledge-base), коли хочете знайти її пізніше. Перевірте імпортовану сторінку та стан індексування; вебсторінки можуть змінитися після імпорту.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Вміст повертається порожнім | Перевірте, що сторінку можна прочитати без додаткової взаємодії, або використайте **Local Fetch** із **Browser-Assisted Fetching**. Екрани входу, заблоковані запити, динамічно завантажений вміст і непідтримувані сайти можуть завадити витяганню. |
| Відповідь описує те, чого на сторінці немає | Попросіть агента показати, що він насправді отримав, замість здогадок про відсутній вміст. |

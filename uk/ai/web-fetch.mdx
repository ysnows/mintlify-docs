---
title: "Отримання вебвмісту"
description: "Нехай ваш Агент прочитає вебсторінку за її URL-адресою або збережіть сторінку в базі знань."
---

Користуйтеся отриманням вебвмісту, коли ви вже маєте URL-адресу й хочете, щоб Агент прочитав сторінку. Кожен Агент може прочитати посилання, яке ви йому дасте; службу, що його отримує, вибираєте ви. Використовуйте [Пошук в інтернеті](/uk/ai/web-search), коли спершу потрібно знайти релевантні сторінки.

## Виберіть провайдера

1. Відкрийте **Параметри → Отримання вебвмісту**.
2. Виберіть провайдера й натисніть **Зробити стандартним**.

| Провайдер | Призначення |
| --- | --- |
| **Local Fetch** | Безкоштовно отримує сторінки на вашому Mac, за бажанням з отриманням за допомогою браузера |
| **Jina AI Link Reader** | Отримує читабельний вміст через Jina |
| **Firecrawl Link Reader** | Отримує вміст через Firecrawl |
| **DeepSeek** | Читає сторінки як Markdown з вашим ключем API DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Читає сторінки як Markdown через Enconvo Cloud, ключ API не потрібен |
| **Enconvo Cloud Plan** | Використовує хмарну службу читання посилань |

## Прочитайте сторінку

1. Вставте URL-адресу у свою розмову й поставте про неї конкретне запитання.
2. Перевірте отриманий вміст і джерело, перш ніж покладатися на відповідь.

## Сторінки за входом

З **Local Fetch** опція **Browser-Assisted Fetching** може прочитати сторінку через браузер родини Chromium, у якому є розширення Enconvo Companion.

| Параметр | Що він робить |
| --- | --- |
| **Автоматично** (типово) | Повторно використовує відповідну вкладку, яку ви вже відкрили, повністю відтворену і з вашим входом. Використовує тимчасову фонову вкладку, коли прямий запит не вдається або сторінці потрібен JavaScript. |
| **Вимкнено** | Лише прямий HTTP |
| **Завжди** | Завжди отримує через браузер |

Без підключеного браузера Local Fetch робить прямий HTTP-запит. Інші провайдери отримують публічну URL-адресу й не мають вашого сеансу з входом у браузері. Для інтерактивних сторінок скористайтеся [Розширенням браузера](/uk/features/browser-extension) або [Використанням браузера](/uk/features/browser-control).

## Збережіть вебвміст

Додайте URL-адресу через **Додати → Окрема вебсторінка** в [Базі знань](/uk/ai/knowledge-base), якщо хочете знайти її пізніше. Перевірте імпортовану сторінку та статус її індексування; вебсторінки можуть змінитися після імпорту.

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| Вміст повертається порожнім | Перевірте, що сторінку можна прочитати без додаткової взаємодії, або скористайтеся **Local Fetch** з **Browser-Assisted Fetching**. Екрани входу, заблоковані запити, динамічно завантажений вміст і непідтримувані сайти можуть завадити видобуванню. |
| Відповідь описує те, чого немає на сторінці | Попросіть Агента показати, що він справді отримав, замість того щоб домислювати відсутній вміст. |

Кожна голосова функція в Enconvo має власний параметр моделі мовлення, тож ви можете вибрати швидку потокову модель для Диктування й іншу для довгих файлів. Вибирайте модель у тій функції, якою справді користуєтеся.

| Функція | Де задати | Посібник |
| --- | --- | --- |
| Мовлення, набране як текст | **Параметри → Моделі диктування** | [Диктування](/uk/features/dictation) |
| Голосова команда | **Параметри → Голосова команда → Слухати** | [Голосова команда](/uk/features/dictation) |
| Дзвінки Live Talk | **Параметри → Live Talk → Слухати** | [Live Talk](/uk/features/live-voice) |
| Запис зустрічі чи лекції | **Параметри → Моделі для запису** | [Запис зустрічі](/uk/features/meeting-recording) |
| Наявний аудіо- чи відеофайл | **Параметри → Моделі транскрибування** | [Транскрибування](/uk/features/transcription) |
| Субтитри в реальному часі | **Параметри → Модель субтитрування** | [Субтитри наживо](/uk/features/live-captioning) |

## Вибір моделі

1. Відкрийте параметр вашої функції з наведеної вище таблиці.
2. На сторінці моделей Диктування, Запису, Транскрибування чи Субтитрування відфільтруйте список за допомогою **Усі**, **Enconvo Cloud**, **Локально** або **Власні постачальники**. У Голосовій команді та Live Talk пункт **Слухати** спершу показує рекомендовані моделі, а потім будь-яку іншу модель мовлення.
3. Виберіть модель, а потім перегляньте її мову та параметри моделі.

Моделі **Enconvo Cloud** використовують ваш обліковий запис Enconvo, без ключа API. **Enconvo Cloud Fast**, власне розпізнавання мовлення Enconvo Cloud, безкоштовне для всіх і має зелену позначку **Безкоштовно**. **Власні постачальники** використовують ваш власний ключ API цього постачальника. **Локальні** моделі (MLX і Core ML) розпізнають мовлення на вашому Mac, щойно їхню модель завантажено.

[Каталог постачальників мовлення](/uk/providers/catalog) перелічує кожного заявленого постачальника, зокрема хмарні служби та локальні варіанти Parakeet, Qwen, Whisper, SenseVoice, Paraformer і Nemotron. Апаратні вимоги та доступність залежать від середовища виконання й вашої збірки.

## Підберіть модель до завдання

| Можливість | Що варто знати |
| --- | --- |
| Потокове розпізнавання | Видає частковий текст, поки ви говорите. Використовуйте модель реального часу, коли хочете, щоб слова з'являлися під час мовлення. |
| Пакетне транскрибування | Обробляє файл після запису чи завантаження. |
| Підказки мови та гарячі слова | Спрямовують розпізнавання, коли постачальник їх підтримує. |
| Діаризація мовців | Розділяє голоси. Не гарантує правильного імені людини. |
| Переклад наживо | Пропонується лише деякими постачальниками й моделями, із вихідною та цільовою мовами. |
| Часові позначки та структурований вивід | Залежать від постачальника та формату виводу транскрибування. |

## Перевірте на короткому зразку

Запишіть короткий зразок мовою, мікрофоном і термінами, якими ви справді користуєтеся, і перегляньте його, перш ніж обробляти довгу зустріч. Якщо не вдається, прочитайте помилку: у ній ідеться про розмір файлу, формат, видобування, обліковий запис або мережу.

Завантаження локальних моделей можуть бути значно більшими за застосунок. Перевірте фактичний розмір завантаження та своє вільне місце; не всім локальним моделям мовлення потрібно однаково.

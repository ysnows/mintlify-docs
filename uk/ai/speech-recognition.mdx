Кожна голосова функція Enconvo має власний параметр моделі мовлення, тож можна взяти швидку потокову модель для диктування й іншу для довгих файлів. Вибирайте модель у тій функції, якою справді користуєтеся.

| Функція | Де задати | Посібник |
| --- | --- | --- |
| Мовлення, введене як текст | **Параметри → Моделі диктування** | [Диктування](/uk/features/dictation) |
| Голосова команда | **Параметри → Голосова команда → Слухати** | [Голосова команда](/uk/features/dictation) |
| Виклики Live Talk | **Параметри → Live Talk → Слухати** | [Live Talk](/uk/features/live-voice) |
| Запис зустрічі або лекції | **Параметри → Моделі для запису** | [Запис зустрічі](/uk/features/meeting-recording) |
| Наявний аудіо- або відеофайл | **Параметри → Моделі транскрибування** | [Транскрибування](/uk/features/transcription) |
| Субтитри в реальному часі | **Параметри → Модель субтитрування** | [Субтитри наживо](/uk/features/live-captioning) |

## Вибрати модель

1. Відкрийте параметр своєї функції з таблиці вище.
2. На сторінці моделі диктування, запису, транскрибування або субтитрування відфільтруйте список через **Усі**, **Enconvo Cloud**, **Локально** або **Власні постачальники**. У голосовій команді й Live Talk **Слухати** спочатку показує рекомендовані моделі, потім будь-яку іншу модель мовлення.
3. Виберіть модель, потім перегляньте її мову й параметри моделі.

Моделі **Enconvo Cloud** використовують ваш обліковий запис Enconvo, без ключа API. **Enconvo Cloud Fast**, власне розпізнавання мовлення Enconvo Cloud, безкоштовне для всіх і показує зелену мітку **Безкоштовно**. **Власні постачальники** використовують ваш ключ API цього провайдера. **Локально** (MLX і Core ML) розпізнає мовлення на вашому Mac після завантаження моделі.

[Каталог провайдерів мовлення](/uk/providers/catalog) перелічує кожного оголошеного провайдера, включно з хмарними службами і локальними варіантами Parakeet, Qwen, Whisper, SenseVoice, Paraformer і Nemotron. Обладнання й доступність залежать від середовища виконання і вашої збірки.

## Підібрати модель до завдання

| Можливість | Що знати |
| --- | --- |
| Потокова передача | Видає частковий текст, поки ви говорите. Беріть модель реального часу, коли слова мають з’являтися під час мовлення. |
| Пакетне транскрибування | Обробляє файл після запису або завантаження. |
| Підказки мови й гарячі слова | Спрямовують розпізнавання, коли провайдер їх підтримує. |
| Розділення мовців | Розділяє голоси. Не гарантує правильне ім’я людини. |
| Живий переклад | Є лише в деяких провайдерів і моделей, з мовами джерела й перекладу. |
| Мітки часу й структурований вивід | Залежать від провайдера і формату виводу транскрибування. |

## Перевірити коротким зразком

Запишіть короткий зразок тією мовою, мікрофоном і термінами, якими справді користуєтеся, і перегляньте його, перш ніж обробляти довгу зустріч. Якщо не вдається, прочитайте помилку щодо розміру файлу, формату, видобування, облікового запису або мережі.

Завантаження локальних моделей можуть бути набагато більшими за програму. Перевірте фактичний розмір завантаження і вільне місце; локальним моделям мовлення потрібне не однакове місце.

Агенти для програмування — це знайомі вам ШІ-інструменти для кодингу, як-от Claude Code і Codex, які працюють у чатах Enconvo. Користуйтеся ними, коли робота стосується коду в папці проєкту: агент редагує файли з показом змін, виконує команди й питає дозволу перед дією, а Enconvo зберігає чат, його історію та підтвердження у Вікні чату, SmartBar і на вашому телефоні.

| Агент для програмування | Розробник | Де працює |
| --- | --- | --- |
| **Claude Code** | Anthropic | На вашому Mac, із входом через Claude |
| **Codex** | OpenAI | На вашому Mac, із входом через ChatGPT |
| **Grok Build** | xAI | На вашому Mac, із входом через Grok |
| **Antigravity** | Google | На вашому Mac, із входом через Google |
| **Muse Code** | Meta | На вашому Mac, із входом через Meta, або на його локальній моделі |
| **Grok Bot** | xAI | У хмарі xAI, через процедуру, яку ви підключаєте |

## Перш ніж почати

Кожен агент для програмування має власну сторінку в **Параметри → Список агентів**. Натисніть її, щоб побачити **Статус**:

1. Якщо там **Не встановлено**, натисніть **Інсталювати** або виконайте показану команду в Терміналі й натисніть **Перевірити знову**. Для надто старої версії буде **Оновити**.
2. У розділі **Обліковий запис** натисніть **Увійти через Claude**, **Увійти через ChatGPT**, **Увійти через Grok**, **Увійти через Google** або **Увійти через Meta**. Enconvo використовує той самий вхід, що й командний рядок агента в Терміналі.

Коли вхід у Claude Code або Codex закінчується протягом десяти днів, про це повідомляють сторінка агента, список **Оновлення** та Дошка Проєкту з кнопкою **Увійти знову**. Завдання на Дошці, чий агент для програмування вийшов із облікового запису, чекає зі станом **Утримано** й запускається знову, щойно ви ввійдете.

Muse Code на локальній моделі не потребує входу в Meta. Grok Bot натомість потребує процедури; див. [Підключення Grok Bot](#підключення-grok-bot).

## Чат з агентом для програмування

1. У Вікні чату виберіть агента для програмування на картках агентів або в меню агентів.
2. Виберіть папку проєкту, у якій він працюватиме.
3. Введіть запит і надішліть його. Кроки агента, зміни та команди надходитимуть у чат, а його запити на підтвердження з’являтимуться як картки, на які ви відповідаєте.

Підтвердження в чаті підпорядковані [режиму дозволів](/uk/ai/agents) Enconvo. У режимі **Повний доступ** новий чат Claude Code починається з **Оминати дозволи** (якщо це дозволяють власні параметри Claude Code), а новий чат Codex — з **Повний доступ**, тож жоден із них не питає дозволу перед дією.

У чаті з робочим деревом вкладка **Pull Request** бічної панелі (**⌃⇧P**) показує pull request гілки на GitHub або створює його. Див. [Вікно чату](/uk/ai/chat).

Щоб продовжити попередній сеанс, виберіть **Відновити попередній сеанс**. Сеанси, які ви почали в командному рядку самого агента, теж у списку, під назвами, які ви їм дали.

Чат, який ви почали з Mavis, також можна передати агентові для програмування, продовживши його в новому чаті з ним. Інші Агенти можуть використовувати агентів для програмування як субагентів, а Проєкт може давати їм завдання або доручати одному з них керувати Проєктом. Див. [Субагенти](/uk/ai/agents) і [Проєкти](/uk/ai/projects).

### Claude Code: зусилля, швидкий режим і Ultracode

Перемикач зусиль у чаті Claude Code визначає, наскільки глибоко він міркує. Якщо сеанс це підтримує, у перемикачі також з’являються **Швидкий режим** і перемикач **Ultracode**. Ultracode вмикає оркестрацію робочих процесів до кінця сеансу за будь-якого вибраного рівня зусиль і залишається ввімкненим, коли ви змінюєте зусилля. Те саме робить команда `/effort ultracode`. У новому чаті швидкий режим і Ultracode можна налаштувати ще до першого повідомлення.

### Codex: попередження

Попередження Codex не потрапляють у розмову. Введіть `/warnings`, щоб побачити їх список.

### Muse Code: продовження в Терміналі

Щоб продовжити чат Muse Code в Терміналі, виберіть **Продовжити в Терміналі** або **Скопіювати команду**, щоб скопіювати її. Чат відкривається з `muse resume` у своїй папці. Коли ви виходите там із Muse Code й знову надсилаєте повідомлення з Enconvo, ходи, виконані в Терміналі, повертаються в чат.

Запити Muse Code на підтвердження показують зміну, яку внесло б редагування. Коли ви відхиляєте крок, текст, який ви вводите разом із **Відхилити**, надходить до Muse Code в тому самому ході, тож він може одразу врахувати його. Його навички та `/compact` є в меню `/`.

<Note>
Режим Contributor у Muse Code типово ввімкнений, і він дозволяє Meta навчати свої моделі на ваших запитах і коді. Enconvo залишає його без змін; вимкніть його у власних параметрах Muse Code.
</Note>

## Вибір того, чим агент для програмування може користуватися в Enconvo

Агенти для програмування можуть використовувати плагіни Enconvo у своїх чатах, як-от надсилання повідомлень вашим Агентам Enconvo, створення зображень і відео, пам’ять, браузер та Використання комп’ютера. На сторінці агента в **Параметри → Список агентів**, у розділі **Можливості Enconvo**:

- Вимкніть **Можливості Enconvo**, щоб заборонити цьому агентові всі плагіни Enconvo.
- Або натисніть **Налаштувати** поруч із **Плагіни** й вимикайте плагіни по одному. Вимкнений плагін прихований від цього агента, а його виклики відхиляються.

Зміна діє й на відкриті чати агента. Чати агентів для програмування в Робочому просторі клієнта залишаються цілком у межах цього Робочого простору.

## Підключення Grok Bot

Grok Bot працює в хмарі xAI. Enconvo надсилає кожне повідомлення до процедури з Webhook, яку ви створюєте в Grok Bot, і показує відповідь у чаті, навіть якщо вона приходить із запізненням.

1. У Grok Bot створіть процедуру з тригером Webhook.
2. Відкрийте **Grok Bot** у **Параметри → Список агентів**, натисніть **Скопіювати** поруч із **Інструкції для процедури** й вставте їх у процедуру.
3. Додайте URL-адресу вебхука процедури та ключ як облікові дані на тій самій сторінці, потім натисніть **Перевірити**. Перевірка чекає на відповідь процедури до приблизно 90 секунд.

Доки процедуру не підключено, вибір агента показує Grok Bot як **Не налаштовано**. Кожне повідомлення витрачає тижневий ліміт використання вашого тарифу Grok Bot. **Зупинити** лише припиняє очікування в Enconvo: запуск процедури триває в хмарі, а відповідь, що надійде пізніше, усе одно додається до чату.

Повідомлення може містити до 32 000 символів. Прикріплені файли й зображення залишаються на вашому Mac; надсилається лише текст.

### Дозвольте Grok Bot викликати Enconvo

Завдяки MCP-серверу Enconvo Grok Bot може відповідати у ваших чатах, сповіщати ваш Mac і сполучені телефони та просити Агента на вашому Mac виконати завдання.

1. На сторінці Grok Bot у розділі **Grok Bot викликає Enconvo** натисніть **З’єднати**. Ви маєте ввійти у свій обліковий запис Enconvo.
2. У Grok Bot відкрийте **Плагіни**, додайте показану **URL-адресу сервера** й увійдіть у свій обліковий запис Enconvo, коли Grok Bot про це попросить.

Кожен запит до Агента на вашому Mac чекає на ваше підтвердження, якщо ви не ввімкнете **Завжди дозволяти ask_mac**. Запити залишаються в списку чату **Grok Bot на цьому Mac**. Натисніть **Від’єднати**, щоб Grok Bot більше не міг викликати Enconvo; відключення або перехід вашого Mac в офлайн скасовує запит, що ще очікує.

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Чат повідомляє, що агент не ввійшов в обліковий запис | Відкрийте сторінку агента в **Параметри → Список агентів** і натисніть **Увійти знову**. Чат Mavis або застосунок, що викликав агента, отримує ту саму помилку входу, а їхні завдання на Дошці чекають зі станом **Утримано**, доки ви не ввійдете. |
| Агент показує **Не встановлено** або надто стару версію | Натисніть **Інсталювати** або **Оновити** на його сторінці, потім **Перевірити знову**. |
| Muse Code повідомляє, що Enconvo потрібно оновити | Оновіть Enconvo, щоб він працював з новішим Muse Code. |
| Grok Bot показує **Не налаштовано** | Додайте URL-адресу вебхука процедури та ключ на сторінці Grok Bot і натисніть **Перевірити**. |
| Перевірка Grok Bot повідомляє про забагато повідомлень | Процедура або Enconvo наразі відхиляє забагато повідомлень. Спробуйте пізніше. |
| Чат Muse Code, відкритий у Терміналі, не надсилає | Вийдіть із Muse Code у Терміналі, щоб повернути його ходи, потім надішліть з Enconvo. |

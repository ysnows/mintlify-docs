Агенти для коду — це інструменти програмування зі ШІ, якими ви вже користуєтеся, наприклад Claude Code і Codex, запущені в чатах Enconvo. Використовуйте їх, коли робота — це код у папці проєкту: агент редагує файли з diff, запускає команди і запитує перед дією, а Enconvo зберігає чат, історію і схвалення у вікні чату, SmartBar і на телефоні.

| Агент для коду | Хто створив | Де працює |
| --- | --- | --- |
| **Claude Code** | Anthropic | На вашому Mac, після входу через Claude |
| **Codex** | OpenAI | На вашому Mac, після входу через ChatGPT |
| **Grok Build** | xAI | На вашому Mac, після входу через Grok |
| **Antigravity** | Google | На вашому Mac, після входу через Google |
| **Muse Code** | Meta | На вашому Mac, після входу через Meta, або на локальній моделі |
| **Grok Bot** | xAI | У хмарі xAI, через процедуру, яку ви підключаєте |

## Перш ніж почати

Кожен агент для коду має власну сторінку в **Параметри → Список агентів**. Натисніть її, щоб побачити **Стан**:

1. Якщо показано **Не встановлено**, натисніть **Інсталювати** або виконайте команду, показану в Terminal, і натисніть **Перевірити знову**. Занадто стара версія показує **Оновити**.
2. У **Обліковий запис** натисніть **Увійти через Claude**, **Увійти через ChatGPT**, **Увійти через Grok**, **Увійти через Google** або **Увійти через Meta**. Enconvo використовує той самий вхід, що й власна команда агента в Terminal.

Коли вхід Claude Code або Codex закінчується протягом десяти днів, сторінка агента, список **Оновлення** і дошка проєкту повідомляють про це, з кнопкою **Увійти знову**. Завдання дошки, чий агент для коду вийшов з облікового запису, очікує як **Утримано** і запускається знову після входу.

Muse Code на локальній моделі не потребує входу через Meta. Grok Bot потребує процедуру; див. [Підключити Grok Bot](/uk/ai/coding-agents).

## Спілкуватися з агентом для коду

1. У вікні чату оберіть агента для коду на картках агентів або в меню агента.
2. Оберіть папку проєкту, у якій він працює.
3. Введіть запит і надішліть. Його кроки, diff і команди надходять у чат, а запитання на схвалення з’являються картками, на які ви відповідаєте.

Схвалення чату дотримуються [режиму дозволів](/uk/ai/agents) Enconvo. У режимі **Повний доступ** новий чат Claude Code починається в **Оминати дозволи**, якщо власні параметри Claude Code це дозволяють, а новий чат Codex — у **Повний доступ**, тому жоден не запитує перед дією.

У чаті worktree вкладка **Pull Request** бічної панелі (**⌃⇧P**) показує pull request гілки на GitHub або створює його. Див. [Вікно чату](/uk/ai/chat).

Щоб продовжити попередній сеанс, оберіть **Відновити попередній сеанс**. Сеанси, які ви почали у власній команді агента, теж у списку, під іменами, які ви їм дали.

Ви також можете передати чат, який почали з Mavis, агенту для коду, продовживши його в новому чаті. Інші агенти можуть використовувати агентів для коду як субагентів, а проєкт може давати їм завдання або доручити одному керувати проєктом. Див. [Субагенти](/uk/ai/agents) і [Проєкти](/uk/ai/projects).

### Claude Code: зусилля, швидкий режим і Ultracode

Вибір зусилля в чаті Claude Code задає зусилля міркування. Коли сеанс це підтримує, вибір також показує **Швидкий режим** і перемикач **Ultracode**. Ultracode вмикає оркестрацію робочого процесу до кінця сеансу на будь-якому зусиллі, яке ви оберете, і лишається увімкненим, коли ви змінюєте зусилля. Введення `/effort ultracode` робить те саме. У новому чаті швидкий режим і Ultracode можна задати до першого повідомлення.

### Codex: попередження

Попередження Codex лишаються поза розмовою. Введіть `/warnings`, щоб переглянути їх.

### Muse Code: продовжити в Terminal

Щоб продовжити чат Muse Code у Terminal, оберіть **Продовжити в Terminal** або **Скопіювати команду**, щоб скопіювати його. Чат відкривається з `muse resume` у своїй папці. Коли ви виходите з Muse Code там і знову надсилаєте з Enconvo, ходи, які ви виконали в Terminal, повертаються в чат.

Запитання на схвалення Muse Code показують зміну, яку зробило б редагування. Коли ви відхиляєте крок, те, що ви вводите разом із **Відхилити**, надсилається Muse Code в тому самому ході, тому він може діяти одразу. Його навички і `/compact` є в меню `/`.

<Note>
Режим учасника Muse Code увімкнений за замовчуванням, що дозволяє Meta навчати моделі на ваших запитах і коді. Enconvo лишає його як є; вимкніть у власних параметрах Muse Code.
</Note>

## Обрати, чим агент для коду може користуватися в Enconvo

Агенти для коду можуть використовувати плагіни Enconvo у своїх чатах, наприклад повідомлення вашим агентам Enconvo, створення зображень і відео, пам’ять, браузер і використання комп’ютера. На сторінці агента в **Параметри → Список агентів**, у **Можливості Enconvo**:

- Вимкніть **Можливості Enconvo**, щоб цей агент не мав доступу до жодного плагіна Enconvo.
- Або натисніть **Налаштувати** поруч із **Плагіни** і вимикайте плагіни по одному. Вимкнений плагін прихований від цього агента, і його виклики відхиляються.

Зміна діє і на відкриті чати агента. Чати агента для коду в робочому просторі клієнта лишаються повністю всередині цього робочого простору.

## Підключити Grok Bot

Grok Bot працює в хмарі xAI. Enconvo надсилає кожне повідомлення процедурі Webhook, яку ви створюєте в Grok Bot, і показує відповідь у чаті, навіть якщо вона надходить із запізненням.

1. У Grok Bot створіть процедуру з тригером Webhook.
2. Відкрийте **Grok Bot** у **Параметри → Список агентів**, натисніть **Копіювати** поруч із **Інструкції для процедури** і вставте їх у процедуру.
3. Додайте URL webhook процедури і ключ як облікові дані на тій самій сторінці, потім натисніть **Перевірити**. Перевірка очікує відповіді процедури до близько 90 секунд.

Доки процедуру не підключено, вибір агента показує Grok Bot як **Не налаштовано**. Кожне повідомлення використовує тижневе використання вашого плану Grok Bot. **Зупинити** лише зупиняє очікування Enconvo: запуск процедури триває в хмарі, і відповідь, яка надійде пізніше, усе одно додається до чату.

Повідомлення може мати до 32 000 символів. Долучені файли та зображення лишаються на вашому Mac; надсилається лише текст.

### Дозволити Grok Bot викликати Enconvo

З MCP-сервером Enconvo Grok Bot може відповідати на ваші чати, сповіщати ваш Mac і спарені телефони і попросити агента на вашому Mac виконати завдання.

1. На сторінці Grok Bot у **Grok Bot викликає Enconvo** натисніть **З’єднати**. Потрібно увійти в обліковий запис Enconvo.
2. У Grok Bot відкрийте **Плагіни**, додайте показаний **Server URL** і увійдіть в обліковий запис Enconvo, коли Grok Bot попросить.

Кожен запит до агента на вашому Mac очікує вашого схвалення, якщо ви не увімкнете **Завжди дозволяти ask_mac**. Запити лишаються в чаті **Grok Bot на цьому Mac**. Натисніть **Від’єднати**, щоб зупинити виклики Enconvo з Grok Bot; від’єднання або вихід вашого Mac офлайн скасовує запит, який ще очікує.

## Усунення неполадок

| Проблема | Що робити |
| --- | --- |
| Чат каже, що агент не увійшов | Відкрийте сторінку агента в **Параметри → Список агентів** і натисніть **Увійти знову**. Чат Mavis або програма, яка викликала агента, отримує ту саму помилку входу, а завдання дошки очікують як **Утримано**, доки ви не увійдете. |
| Агент показує **Не встановлено** або занадто стару версію | Натисніть **Інсталювати** або **Оновити** на його сторінці, потім **Перевірити знову**. |
| Muse Code каже, що Enconvo потребує оновлення | Оновіть Enconvo, щоб працювати з новішим Muse Code. |
| Grok Bot показує **Не налаштовано** | Додайте URL webhook процедури і ключ на сторінці Grok Bot і натисніть **Перевірити**. |
| Перевірка Grok Bot каже, що забагато повідомлень | Процедура або Enconvo наразі відхиляє забагато повідомлень. Спробуйте пізніше. |
| Чат Muse Code, відкритий у Terminal, не надсилає | Вийдіть з Muse Code у Terminal, щоб повернути його ходи, а потім надсилайте з Enconvo. |

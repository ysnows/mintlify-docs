title: "Файли й папки"
description: "Дозвольте Агентові знаходити, читати й редагувати файли на вашому Mac."
---

Файлові інструменти дають Агентові змогу знаходити файли, шукати всередині них, читати й редагувати їх. Вкажіть Агентові папку чи файл і просіть простими словами; він вибере потрібний інструмент і покаже, чим скористався.

## Перш ніж почати

- **Робоча папка:** **Робоча папка** Агента в розділі **Definition** його параметрів — це місце, звідки починаються відносні шляхи.
- **Схвалення:** позначка **Дозволи** в чаті визначає, коли Агент питає спершу. З **Запитувати дозвіл** він питає перед редагуванням файлів поза робочою папкою. Читання й пошук ніколи не питають. Див. [Схвалення дій](/uk/ai/agents).

## Почніть із завдання лише для читання

1. У параметрах Агента перевірте його файлові інструменти та **Робочу папку**.
2. У чаті назвіть папку або прикріпіть файл, який хочете використати.
3. Поставте обмежене запитання, наприклад: «Знайди файли Markdown у цьому проєкті й підсумуй README».
4. Перегляньте файли та вивід інструментів, які використав Агент, перш ніж просити його щось змінити.

## Що робить кожен інструмент

| Інструмент | Що він робить |
| --- | --- |
| Glob | Знаходить файли за шаблоном шляху, наприклад `**/*.md`, найновіші першими |
| Grep | Шукає текст усередині файлів, зі шаблонами файлів і номерами рядків |
| Read File | Читає текстові файли, витягує текст із документів і читає зображення, аудіо та відео |
| Edit File | Замінює точний текст у файлі й повідомляє про змінені рядки |
| Write File | Створює файл або замінює весь його вміст |

<Warning>
Write File може перезаписати наявний файл без попередження. Зберігайте копію або користуйтеся контролем версій для важливих документів і перевіряйте місце призначення та зміну, перш ніж схвалювати. Файли, які Агент змінює в чаті, перелічено на вкладці **Зміни** бічної панелі з кнопкою **Скасувати**.
</Warning>

## Документи та медіа

Читання PDF, документа Office, зображення, аудіофайлу чи відео може запускати розбір, OCR або транскрибування замість повернення сирих байтів. Для аудіо й відео Агент читає стенограму. У таблиці клітинка з формулою читається як її значення або як сама формула, якщо її ніколи не обчислювали. Які формати працюють, залежить від встановлених інструментів і провайдерів, яких ви налаштували. Див. [OCR](/uk/ai/ocr), [Транскрибування](/uk/features/transcription) і [Базу знань](/uk/ai/knowledge-base).

## Усунення проблем

| Проблема | Що робити |
| --- | --- |
| Помилка доступу | Перевірте **Робочу папку** Агента, позначку **Дозволи** та дозволи macOS |
| Документ читається як порожній | Перевірте тип файлу й чи його можна розібрати. Відсканований PDF може потребувати OCR |
| Редагування не знаходить текст, який має замінити | Попросіть Агента знову прочитати поточний файл, перш ніж редагувати |

title: "Файли та папки"

Інструменти файлів дозволяють агенту знаходити файли, шукати в них, читати їх і редагувати. Вкажіть агенту папку чи файл і сформулюйте запит звичайними словами: він обере потрібний інструмент і покаже, що використав.

## Перед початком

- **Робоча папка:** **Робоча папка** агента, у розділі **Definition** його параметрів, — це точка відліку для відносних шляхів.
- **Схвалення:** чіп **Дозволи** в чаті визначає, коли агент спитає спершу. З **Запитувати дозвіл** він питає, перш ніж редагувати файли поза робочою папкою. Читання і пошук ніколи не питають. Див. [Схвалювати дії](/uk/ai/agents).

## Почніть із завдання лише для читання

1. У параметрах агента перевірте його інструменти файлів і **Робочу папку**.
2. У чаті назвіть папку або додайте файл, який хочете використати.
3. Поставте обмежене запитання, наприклад «Знайди файли Markdown у цьому проєкті і підсумуй README».
4. Перегляньте файли та вивід інструментів, які використав агент, перш ніж просити щось змінити.

## Що робить кожен інструмент

| Інструмент | Що він робить |
| --- | --- |
| Glob | Знаходить файли за шаблоном шляху, наприклад `**/*.md`, спершу новіші |
| Grep | Шукає текст усередині файлів, з шаблонами файлів і номерами рядків |
| Read File | Читає текстові файли, витягує текст із документів і читає зображення, аудіо та відео |
| Edit File | Замінює точний текст у файлі і повідомляє про змінені рядки |
| Write File | Створює файл або замінює весь його вміст |

<Warning>
Write File може перезаписати існуючий файл без попередження. Зберігайте копію або користуйтеся контролем версій для важливих документів і перевірте призначення та зміну, перш ніж схвалювати. Файли, які агент змінив у чаті, перелічено на вкладці **Зміни** бічної панелі, з **Скасувати**.
</Warning>

## Документи та медіа

Читання PDF, документа Office, зображення, аудіочи відео може запускати розбір, OCR або транскрибування замість повернення сирих байтів. Для аудіо та відео агент читає транскрипт. У таблиці комірка з формулою читається як її значення або як сама формула, якщо її ніколи не обчислювали. Які формати працюють, залежить від установлених інструментів і налаштованих провайдерів. Див. [OCR](/uk/ai/ocr), [Транскрибування](/uk/features/transcription) та [База знань](/uk/ai/knowledge-base).

## Усунення несправностей

| Проблема | Що робити |
| --- | --- |
| Помилка доступу | Перевірте **Робочу папку** агента, чіп **Дозволи** та дозволи macOS |
| Документ читається як порожній | Перевірте тип файлу та чи його можна розібрати. Відсканованому PDF може знадобитися OCR |
| Редагування не знаходить текст, який має замінити | Попросіть агента перечитати поточний файл, перш ніж редагувати |

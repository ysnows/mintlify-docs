---
title: "macOS Permissions"
description: "Grant the permissions required by the features you use."
---

Open **Settings → General → Permissions** in Enconvo to review feature access. macOS permission names can vary by system version; use **System Settings → Privacy & Security** for the system controls.

| Permission | Features that need it |
| --- | --- |
| Accessibility | Selected-text access, inserting text, and app interaction |
| Screen Recording / Screen & System Audio Recording | Screen context, OCR captures, Appshots, and screen/system-audio capture |
| Microphone | Dictation, voice notes, microphone recording, and Live Voice |
| Automation | Controlling apps through supported macOS integrations |
| Notifications | macOS banners for completed Agent sessions |
| Local Network | Connecting to model servers on another computer in your network |

## Enable a feature

1. Try the feature and read its permission explanation.
2. Open the corresponding macOS permission pane.
3. Enable access for the Enconvo app you use.
4. Follow macOS instructions to quit and reopen the app if requested.
5. Try a small example again.

You can grant permissions as needed. Text-only chat does not require every screen and microphone capability.

## Common problems

- **A permission is enabled but capture fails:** quit and reopen Enconvo, then retry. Make sure you enabled the running app rather than an older copy.
- **Dictation produces text but cannot insert it:** check Accessibility and that the target field accepts typing/paste.
- **A remote local model server fails:** check Local Network permission and whether the server listens on its LAN interface.
- **No completion banner:** check macOS notifications and Focus as well as Enconvo's notification setting.

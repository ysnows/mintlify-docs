**Settings → General** holds the choices that change how Enconvo looks and which language it speaks. Use this page to switch the interface language, make Enconvo easier to read, and find a setting without knowing where it lives.

## Change the interface language

1. Open **Settings → General** and find **Language**.
2. Pick a language in **App Language**. **Follow System** uses your Mac's language.
3. Enconvo offers to change your **Response Language** to match. Accept it if you want Agents to reply in the new language too.

**App Language** changes the menus, buttons, and settings on this device: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, German, French, Italian, Portuguese, Ukrainian, and Russian. The iPhone and Android apps offer the same languages in their own settings.

**Response Language** is separate: Agents, voice calls, and the Avatar reply in it, and Translator translates into it.

## Adjust how Enconvo looks

Open **Settings → General** and find **Appearance**.

| Setting | What it changes |
| --- | --- |
| **Contrast** | Makes borders, dividers, and secondary text stronger or softer across Enconvo. |
| **Chat Width** | How wide messages and the composer grow in a large window: **Comfortable**, **Wide**, or **Full**. |
| **Wrap Code** | Wraps long lines in code blocks instead of scrolling sideways. |

## Find a setting

Type in the search field at the top of the Settings sidebar. Matching settings show as you type; click one to go to it.

To ask a question about your settings instead:

1. Type the question in the search field, and press Return, or click **Ask AI**.
2. The answer opens beside the sidebar, with cards for the settings it mentions.
3. Click a card's **Show in Settings** to go to that setting, or turn a switch on or off right in the card.
4. Type a follow-up in **Ask a follow-up…**, or click **Continue in Chat** to keep going in the Chat Window.

Ask AI uses your default AI model. If none is set up, it offers **Open AI Model settings**.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Some text stays in English after you switch languages | Update Enconvo, then report what's left with **Feedback** in the menu bar menu. |
| Agents reply in a different language from the interface | Set **Response Language** in **Settings → General → Language**. |
| Ask AI doesn't answer | Set up a model in **Settings → AI Model**. |
| Text is hard to read | Raise **Contrast** in **Settings → General → Appearance**. |

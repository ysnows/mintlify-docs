Every entry in Enconvo's Settings sidebar, in sidebar order, with the guide that explains it. To open Settings, click the Enconvo menu bar icon and choose **Settings**. To jump to an entry, type its name in **Search settings**.

The guides write Settings paths with the names below, such as **Settings → SmartBar**.

Open Settings from the Enconvo menu. Use **Search settings** to find an entry by name. The sections below follow the current settings sidebar; each links to its task guide.

Provider lists, available models, saved shortcuts, and defaults can vary by installed build and your configuration. Read the value in your app before changing it.

## Reset a command or provider

Where offered, open **More → Reset configuration** in the command or provider settings. Read the confirmation before restoring defaults. A shared provider profile can affect multiple categories; see [Credentials](/configuration/credentials).

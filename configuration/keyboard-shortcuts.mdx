Open **Settings → General → Shortcut** for the shortcut list. Feature pages also expose their relevant hotkey controls. Saved bindings on your Mac take precedence over examples in documentation.

## Common entry points

| Feature | Where to configure |
| --- | --- |
| SmartBar | Settings → Primary Function Area → SmartBar; commonly Shift + Command + D |
| Dynamic Island | Settings → Primary Function Area → Dynamic Island |
| PopBar | Settings → Primary Function Area → PopBar |
| App Sidebar | Settings → App Sidebar; commonly Shift + Command + T |
| Dictation | Settings → Dictation |
| Voice Trigger | Settings → Agents → Voice Trigger |
| Appshots | Settings → Context → Appshots |
| Screen Doodle | Settings → Context → Screen Doodle |
| Voice Note | Settings → Memory → Voice Note |
| Quick Capture | Settings → Memory → Quick Capture |
| Individual command | That command's settings, when a Hotkey field is offered |

## Record a shortcut

1. Click the hotkey field for the intended action.
2. Press the desired combination.
3. Select a gesture mode if the field offers one, such as Hold, Double Tap, or Modifier Keys.
4. Read the explanation next to the field and test the gesture from another app.
5. Clear or change a conflicting binding if a different action runs.

Hold and double-tap gestures behave differently from an ordinary key combination. Follow the description displayed in that feature's settings.

## Inside SmartBar

Use the configured command/context characters to open the relevant picker. The default settings expose **@** for command search, **#** for context mentions, and **>** for recent tasks. The slash menu provides actions such as model and reasoning selection.

Navigation bindings are configurable in SmartBar settings. Check that selection before assuming a particular Control-key sequence is enabled.

## Troubleshooting

If a shortcut works only inside Enconvo, review global permissions and app conflicts. If a modifier gesture fails, check whether the setting expects a press, hold, simultaneous modifier keys, or double tap. Avoid relying on a documentation shortcut if you have customized that feature.

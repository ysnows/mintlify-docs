title: "Keyboard Shortcuts"
description: "See every hotkey Enconvo uses, change one, and find which command a key combination runs."
---

Enconvo's windows and voice features each open with a hotkey. **Settings → Shortcut** lists every hotkey Enconvo uses and the command it runs, so you can change one or find out what a key combination does. The hotkeys saved on your Mac always win over the defaults in this guide.

## Default shortcuts

| Action | Default |
| --- | --- |
| Show SmartBar | **⇧⌘D** |
| Show Chat Window | **⌥⌘D** |
| Show App Sidebar | **⌃⌘E** |
| Open Settings, from inside Enconvo | **⌘,** |

## Change a hotkey

1. Open **Settings → Shortcut**. The **Core** tab holds the main features, **Other Hotkeys** holds AI commands, plugins, settings, and commands no other page shows, and **All** shows both.
2. Type in **Filter by name…** to find a command. To find the command behind a key combination, click **Find by hotkey** and press it.
3. Click the command's hotkey field and press the new combination.
4. If those keys already run another command, the field tells you. Choose **Use it here** to move the keys to this command, or pick one of the free hotkeys it suggests.
5. Switch to another app and try the hotkey.

To free a hotkey's keys, remove it from the command. A message with **Undo** lets you take that back.

A **Local** badge marks a hotkey that works only inside Enconvo, such as Pin SmartBar.

## How to press it

When you record one modifier key on its own, such as Right ⌘, the field asks **How to press it**:

| Option | The command runs when you |
| --- | --- |
| **Hold or Tap** | Hold the key, or tap it to toggle |
| **Tap** | Tap the key to start, and tap again to stop |
| **Hold** | Hold the key down; it works while you hold it |
| **Double Tap** | Tap the key twice quickly |

Two or more modifier keys pressed at the same time count as one hotkey. Each field shows only the kinds its command supports, and the description next to it says how that feature reacts.

## Where each feature's hotkey lives

Besides the Shortcut page, each feature has its hotkey on its own Settings page:

| Feature | Settings page |
| --- | --- |
| SmartBar | **Settings → SmartBar** |
| Dynamic Island | **Settings → Dynamic Island** |
| PopBar | **Settings → PopBar** |
| App Sidebar | **Settings → App Sidebar** |
| Dictation | **Settings → Dictation** |
| Voice Command | **Settings → Voice Command** |
| Appshots | **Settings → Appshots** |
| Screen Doodle | **Settings → Screen Doodle** |
| Voice Note | **Settings → Voice Note** |
| Quick Capture | **Settings → Quick Capture** |
| A single command | That command's settings, when it has a **Hotkey** field |

## Inside SmartBar

Type a trigger character in SmartBar to search one kind of item:

| Character | Opens |
| --- | --- |
| **@** | Commands |
| **#** | Context to add to your message |
| **$** | Skills |
| **>** | Recent tasks |

Change these characters under **Search** in **Settings → SmartBar**. The slash menu holds actions such as model and reasoning selection.

To move through lists with the keyboard, pick **Navigation Bindings** in **Settings → SmartBar**: **macOS** uses **⌃N** **⌃P** **⌃F** **⌃B**, and **Vim** uses **⌃J** **⌃K** **⌃L** **⌃H**.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A hotkey works only inside Enconvo | Check whether it has a **Local** badge. If not, check Input Monitoring and Accessibility in [macOS Permissions](/configuration/permissions), and whether another app uses the same keys. |
| Pressing a hotkey does something else | Use **Find by hotkey**. If no Enconvo command uses the keys, another app or macOS does. |
| A modifier-key hotkey doesn't fire | Open the hotkey and check **How to press it**: hold, tap, double tap, or keys pressed together. |
| A shortcut from a video or another Mac doesn't work | Your hotkeys may differ. Look up the current one in **Settings → Shortcut**. |

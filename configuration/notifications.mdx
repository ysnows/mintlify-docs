Enconvo can tell you when an Agent session finishes by opening the Dynamic Island, by posting a macOS notification, or both. You set this up in **Settings → Notifications**, along with quiet hours for the times you don't want to be interrupted.

## Set up completion alerts

1. Open **Settings → Notifications**.
2. If the page says **Notifications are turned off for Enconvo**, click **Enable**, or allow Enconvo in **System Settings → Notifications**.
3. Under **On session completion**, turn each switch on or off. They work independently.
4. Start a short Agent request and wait for it to finish.

| Setting | What it does |
| --- | --- |
| **Open the Dynamic Island** | When a session you started from the Dynamic Island finishes, the island expands to show the result. |
| **Send a system notification** | Posts a macOS notification when a session finishes. Click the notification to reopen the session in the window it started from. |

macOS Focus and notification settings can hide banners even when these switches are on.

## Quiet hours

Quiet hours hold Agent questions, Mail Alerts, and finished tasks until the quiet time ends, on this Mac and on your paired iPhone. Nothing is approved for you while they wait.

1. In **Settings → Notifications**, find **Updates (Outreach)**.
2. Turn on **Quiet hours**, then set **Starts** and **Ends**.
3. Choose what still gets through:

| Setting | What it does |
| --- | --- |
| **Let approvals through** | Approval requests still reach you during quiet hours. |
| **Let questions through** | Agent questions still reach you during quiet hours. |

The Enconvo menu bar menu also has **Quiet Hours**, and **Pause Updates for 1 Hour** for a short break.

## Scheduled results

A system notification is different from sending a scheduled task's result to Telegram or another IM chat. You set result delivery in the [scheduled task](/workflows/scheduled-jobs)'s editor.

A scheduled task can also post its own Mac notification when it runs (**Notify me when it runs**). That notification follows **Send a system notification** too. The task's run history shows whether each run worked and whether its result was delivered.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No banner when a session finishes | Check that **Send a system notification** is on, that macOS allows notifications from Enconvo, and that Focus isn't hiding them. |
| The Dynamic Island didn't open | **Open the Dynamic Island** applies only to sessions you started from the Dynamic Island. |
| A question or finished task arrived late | Quiet hours may have held it. Turn on **Let questions through**, or change **Starts** and **Ends**. |

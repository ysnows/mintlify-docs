Open the **Account** section of Settings to find **My Profile**, **Account**, and **Points Usage**.

| Entry | Purpose |
| --- | --- |
| My Profile | Information you choose to provide so Enconvo can tailor responses |
| Account | Your Enconvo account, app license, and plan information |
| Points Usage | Cloud usage records for your account |

## Check access and usage

1. Open **Account** and confirm which Enconvo account is signed in.
2. Review the current license or plan shown there.
3. Open **Points Usage** to inspect Cloud consumption.
4. If a request fails, also check the provider and authentication method used by that feature.

An Enconvo account, a provider API key, and a provider subscription sign-in are different connections. BYOK requests use the provider account's billing and limits. Supported subscription connections show their own usage in provider settings, separate from Enconvo Cloud points.

See [Pricing](/pricing) for official plan links and [Credentials](/configuration/credentials) for provider profiles. Only put information in My Profile that you want to use as personalization context.

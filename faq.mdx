## Which macOS version do I need?

Current builds target macOS 14 or later. MLX local processing requires Apple Silicon. See [Installation](/installation).

## Do I need an API key?

You can use Enconvo Cloud, your own provider API key, supported account connections, or local models. Configure the capability you need under [Providers](/providers/overview).

## Does a local model keep every task offline?

Only the operations performed by local providers stay local. Web search, remote MCP servers, cloud speech, or cloud embeddings can still send data outside the Mac. See [Privacy and Security](/configuration/privacy-security).

## What is the difference between Dictation, Voice Trigger, and Live Voice?

Dictation inserts recognized speech as text. Voice Trigger sends speech to an Agent. Live Voice is a two-way spoken conversation. See [Dictation](/features/dictation) and [Live Voice](/features/live-voice).

## What is the difference between Appshots and Quick Capture?

[Appshots](/features/appshots) attaches the current app window as conversation context. [Quick Capture](/features/quick-capture) saves current app content into a knowledge base for later retrieval.

## What is the difference between Memory and Knowledge Base?

[Memory](/ai/memory) holds reusable facts. [Knowledge Base](/ai/knowledge-base) stores reference material and retrieves relevant content.

## Why did changing the default model not change an existing chat?

Current chats can keep their own model and reasoning selection. Project defaults and Agent defaults also have different scopes. See [Model Selection](/ai/model-selection-guide).

## Can Enconvo use tools from other services?

Yes, through installed plugins, Skills, and configured [MCP Servers](/features/mcp). To let an external local AI client read Enconvo's knowledge bases, use [Knowledge Base MCP](/advanced/knowledge-base-mcp).

## Can tasks run while I am away?

[Scheduled Jobs](/workflows/scheduled-jobs) can run locally while Enconvo and the Mac are available. Configure IM delivery if you want the results sent to a connected chat.

## Where are missing features?

Check your app version, installed extensions, permissions, and [update channel](/configuration/updates). Beta and Dev features can appear before Production. Use the [Feature Directory](/reference/feature-directory) to find the guide and settings entry.

## Where should I report a problem?

Use the [Enconvo community](https://discord.gg/jYsdVRRK2k) with the app version, feature, expected result, actual error, and a small reproduction. Remove private content and credentials from screenshots and logs. See [Troubleshooting](/getting-started/troubleshooting).

## Getting started

<AccordionGroup>
  <Accordion title="Which Macs does Enconvo run on?">
    macOS 14 or later, on Apple Silicon and Intel. Some on-device features, such as [Local LLM (MLX)](/providers/mlx), need Apple Silicon. See [Installation](/installation).
  </Accordion>
  <Accordion title="Do I need an API key?">
    No. Sign in to your Enconvo account and [Enconvo Cloud](/providers/enconvo) works without one. You can also sign in with a plan you already pay for, such as ChatGPT or Claude, add your own API key, or run a model on your Mac. See [Providers](/providers/overview).
  </Accordion>
  <Accordion title="How is paying for Enconvo different from paying for AI?">
    A license unlocks the app. The AI is billed where it runs: Enconvo Cloud points, your provider account, or your own Mac. See [Plans and pricing](/pricing).
  </Accordion>
  <Accordion title="A feature in these docs is missing from my app. Why?">
    Some features reach the Beta channel first. Check your version and [update channel](/configuration/updates), then look the feature up in the [Feature directory](/reference/feature-directory).
  </Accordion>
</AccordionGroup>

## Models

<AccordionGroup>
  <Accordion title="Which model should I use?">
    If you're not sure, keep [Auto Route](/providers/auto-route): it picks a model for each message. To choose one yourself, see [Choose a model](/ai/model-selection-guide).
  </Accordion>
  <Accordion title="I changed the default model. Why does my chat still use the old one?">
    A chat keeps the model it started with until you change it in that chat. Projects and Agents have their own defaults too. See [Choose a model](/ai/model-selection-guide#where-the-default-is-set).
  </Accordion>
  <Accordion title="Does a local model keep everything offline?">
    Only the steps that run on local providers. Web search, remote MCP servers, cloud speech, and cloud embeddings still send data off your Mac. See [Local models](/ai/local-llm) and [Privacy and security](/configuration/privacy-security).
  </Accordion>
</AccordionGroup>

## Voice

<AccordionGroup>
  <Accordion title="What's the difference between Dictation, Voice Command, and Live Talk?">
    [Dictation](/features/dictation) types what you say into the app you're using. Voice Command sends what you say to an Agent as a request. [Live Talk](/features/live-voice) is a spoken back-and-forth conversation with an Agent.
  </Accordion>
  <Accordion title="Can Enconvo record and transcribe meetings?">
    Yes. [Meeting recording](/features/meeting-recording) records and transcribes as you go, and [Transcription](/features/transcription) works on audio and video files you already have.
  </Accordion>
</AccordionGroup>

## Context and knowledge

<AccordionGroup>
  <Accordion title="What's the difference between Appshots and Quick Capture?">
    [Appshots](/features/appshots) attaches the app window you're looking at to a question. [Quick Capture](/features/quick-capture) saves what's on screen into a knowledge base for later.
  </Accordion>
  <Accordion title="What's the difference between Memory and the Knowledge Base?">
    [Memory](/ai/memory) holds facts Agents learn about you and reuse. The [Knowledge Base](/ai/knowledge-base) holds documents you add, and Agents search them for answers.
  </Accordion>
  <Accordion title="Can other AI apps use my Enconvo knowledge bases?">
    Yes, through [Knowledge Base MCP](/advanced/knowledge-base-mcp), which you turn on and limit to the knowledge bases you choose.
  </Accordion>
</AccordionGroup>

## Agents and automation

<AccordionGroup>
  <Accordion title="Can Agents use tools from other apps and services?">
    Yes, through [plugins](/extensions/overview), [Skills](/configuration/skills), and [MCP servers](/features/mcp). Agents can also use your [browser](/features/browser-control) and [apps](/features/computer-use) when you allow it.
  </Accordion>
  <Accordion title="Can tasks run while I'm away?">
    Yes. [Automations](/workflows/scheduled-jobs) run on a schedule while Enconvo is running and your Mac is awake. Connect an [IM channel](/integrations/messaging) to get the results in a chat app.
  </Accordion>
</AccordionGroup>

## Help

<AccordionGroup>
  <Accordion title="Where do I report a problem?">
    Ask on [Discord](https://discord.gg/jYsdVRRK2k) with your Enconvo version, what you did, and what happened, or use **Feedback** in the menu bar menu. Remove private content and keys from screenshots and logs first. See [Troubleshooting](/getting-started/troubleshooting).
  </Accordion>
</AccordionGroup>

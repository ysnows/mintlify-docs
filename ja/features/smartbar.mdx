title: "SmartBar"
description: "1 つのショートカットでどのアプリからでも開けるランチャーから、エージェントへの質問やコマンドの実行を行います。"

SmartBar は、どのアプリを使っていても呼び出してエージェントへ質問したりコマンドを実行したりできるランチャーです。**⌥Space** を押して入力し、Return を押すだけで使えます。サッと答えを得て元の作業へすぐ戻りたいときに最適です。

用途に合わせて使い分けることもできます。長い会話やファイルを扱うときは[チャットウィンドウ](/ja/ai/chat)、1 つのアプリの横で作業するときは[アプリのサイドバー](/ja/features/app-sidebar)、選択テキストに操作を行うときは [PopBar](/ja/features/popbar)、画面上に常駐する小さな入口としては [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使えます。各ウィンドウの比較は[ウィンドウ管理](/ja/features/window-management)を参照してください。

## 質問する

1. **⌥Space**、または **設定 → SmartBar** で設定したホットキーを押します。
2. 質問を入力します。必要なら先に別のエージェントやモデルを選択します。
3. エージェントが必要とするコンテキストを添付します。開いているすべてのアプリを自動で見ているわけではありません。[コンテキストを追加する](#コンテキストを追加する)を参照してください。
4. Return を押し、回答やツールの実行状況を確認します。応答を止めるには丸い停止ボタンをクリックします。
5. 結果をコピーするか、続けて入力して会話を続けます。タスクの実行中に入力したメッセージはすぐに反映されます。

入力した文字がコマンドに一致する場合、Return キーは選択中の行を実行します。代わりにエージェントへ送るには **⌘Return** を押すか **AI に送信** をクリックしてください。**⌥Return** はその行のサブアクションを実行します。

エージェントモードでは、**権限** チップでエージェントが操作前に確認を求める条件を設定でき、**サンドボックス** スイッチでエージェントのコマンド実行を作業フォルダ内に制限できます。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。

## トリガー文字で検索する

SmartBar で次の文字を入力すると、それぞれの種類の項目を検索できます。

| 入力 | 動作 |
| --- | --- |
| `@` | コマンドを検索 |
| `#` | コンテキストを追加 |
| `$` | スキルを使用 |
| `>` | 最近のタスクを表示 |
| `/` | モデルや推論レベル選択などのアクションを開く |

最初の 4 つは **設定 → SmartBar** の **検索** で変更できます。`/` は変更できません。

名前を記憶して入力する代わりに、開いた一覧から項目を選んでください。一覧には実際に利用できるコマンドとコンテキストソースが表示されます。[ライティングツールキット](/ja/features/writing-tools)、[クイックリンク](/ja/features/quick-links)、[コンテキスト認識](/ja/features/context-awareness)を参照してください。

エイリアスで開く一覧もあります。エイリアスに続けてスペースを入力すると、SmartBar 内で[クリップボード履歴・ブックマーク検索・ファイル検索](/ja/features/clipboard-history)が開きます。

## コンテキストを追加する

SmartBar は開いたときに、選択中のテキスト、Finder の選択項目、現在開いているブラウザのページを取得できます。**設定 → コンテキスト認識** でそれぞれに **自動追加**、**提案**、**オフ** を選べます。それ以外のコンテキストを追加するには `#` を入力してソースを選んでください。

## レイアウトを選ぶ

  <img src="/images/guides/smartbar-layout.jpg" alt="入力欄のみ、入力欄とツールバー、フルパネルの SmartBar レイアウト選択肢" />
</Frame>

**設定 → SmartBar** の **レイアウト** で、SmartBar を開いたときの表示を設定します。

| レイアウト | 表示内容 |
| --- | --- |
| **入力欄のみ** | 入力欄だけを表示 |
| **入力欄とツールバー** | 入力欄に加えて、クイックアクション、モデル選択、音声コントロールを表示 |
| **フルパネル** | 上記すべてに加えて、入力欄の下に一覧を表示 |

**フルパネル** を選んだ場合、**初期表示** で入力前に一覧へ何を表示するか（**おすすめプロンプト** または **コマンド一覧**）を設定できます。どのレイアウトでも、文字を入力したりコマンドを実行したりすれば一覧と結果が表示されます。

## 設定

**設定 → SmartBar** を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **ホットキー** | どのアプリからでも SmartBar を開閉します。デフォルトは **⌥Space** です。 |
| **デフォルトエージェント** | 入力した内容に応答するエージェント。 |
| **会話を自動でクリア** | 閉じてからこの時間が経った後に SmartBar を開くと、新しい会話を開始します。**なし** から **開くたび** まで選べます。 |
| **レイアウト** | SmartBar を開いたときに何を表示するか（上記参照）。 |
| **外観** | SmartBar とアプリのサイドバーのガラススタイルをライト・ダーク・**アプリに合わせる** から選びます。 |
| **入力ソースを自動で切り替え** | SmartBar での入力中はこの入力ソースに切り替え、閉じると元に戻します。 |
| **ナビゲーションキー** | リストやテキスト内を移動する Control キーのショートカット：**macOS**（⌃N ⌃P ⌃F ⌃B）または **Vim**（⌃J ⌃K ⌃L ⌃H）。 |
| **検索** | コマンド、コンテキスト、スキル、最近のタスクを呼び出すトリガー文字。 |
| **電卓** | 入力するだけで数式、単位、通貨、日付、タイムゾーンに答えます。デフォルトでオンです。 |
| **天気とフライト** | 天気、フライト、各地の時刻も調べます。デフォルトでオフです。 |

デフォルト設定を変更しても、既存のチャットがすべて変わるわけではありません。各チャットが独自のモデルと推論選択をどう保持するかは[モデル選択ガイド](/ja/ai/model-selection-guide)で説明しています。

## 音声入力と計算

マイクをクリックすると[音声入力](/ja/features/dictation)で質問を話して入力できます。声でやり取りするには [Live Talk](/ja/features/live-voice) を開始してください。SmartBar から始めた Live Talk 通話は Dynamic Island へ移動します。

`2+3*4` のような数式を入力すると SmartBar が結果を表示します。電卓は単位や通貨の変換、日付やタイムゾーンの計算、`25% off $60 split by 3` のような割り勘計算にも対応しています。コピーする前に結果と提示されたアクションを確認してください。

各地の天気、フライト、現在時刻を調べるには、**設定 → SmartBar** で **天気とフライト** をオンにします。その後 `weather in London`、`Tokyo feels like`、便名 `BA008`、`time in Chernivtsi` などを入力します。Open-Meteo、adsbdb、adsb.lol には地名または便名のみが送信されます。**天気とフライト** は [Dynamic Island](/ja/features/dynamic-island) の電卓と共有されています。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| SmartBar が開かない | **設定 → SmartBar** の **ホットキー** を確認し、同じショートカットを使っている他のアプリがないか確認してください。自分でキーを設定していた場合はその設定が維持されます。 |
| Return を押すとエージェントへの質問ではなくコマンドが実行される | **⌘Return** を押すか **AI に送信** をクリックしてください。 |
| 計算や天気の検索結果が表示されない | **設定 → SmartBar** の **電卓** と **天気とフライト** を確認してください。 |
| アプリや選択テキストがコンテキストに含まれない | [権限](/ja/configuration/permissions) と **設定 → コンテキスト認識** を確認してください。 |
| リクエストが失敗する | 選択したプロバイダーを確認し、表示されたエラーメッセージを読んでください。 |
| このページの項目が見つからない | お使いのビルドがこのガイドより古い可能性があります。[アップデート](/ja/configuration/updates)を参照してください。 |

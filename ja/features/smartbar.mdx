SmartBar は、どのアプリからでも開けるランチャーで、エージェントへの質問やコマンドの実行に使います。**⌥Space** を押して入力し、Return を押すだけです。すばやく答えを得て、元の作業に戻りたいときに使います。

ほかの用途には、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、1 つのアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択したテキストへの操作には [PopBar](/ja/features/popbar)、画面に常駐する小さな入口には [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使います。それぞれの違いは[ウィンドウ管理](/ja/features/window-management)で比較しています。

## 質問する

1. **⌥Space**、または **設定 → SmartBar** で設定したホットキーを押します。
2. 質問を入力します。必要なら、先に別のエージェントやモデルを選びます。
3. エージェントに必要なコンテキストを添付します。エージェントは開いているすべてのアプリを見られるわけではありません。[コンテキストを追加する](#コンテキストを追加する)をご覧ください。
4. Return を押して、回答やツールの進行状況を確認します。返信を止めるには、丸い停止ボタンをクリックします。
5. 結果をコピーするか、続けてフォローアップを入力して会話を続けます。タスクの実行中に入力したメッセージは、すぐに表示されます。

入力した内容がコマンドに一致する場合、Return でハイライトされた行が実行されます。入力内容をエージェントに送るには、**⌘Return** を押すか、**AI に送信** をクリックします。**⌥Return** は、その行の 2 つ目のアクションを実行します。

エージェントモードでは、**権限** チップでエージェントが操作の前に確認するタイミングを設定でき、**サンドボックス** スイッチでエージェントのコマンドを作業フォルダ内に制限できます。[エージェントのサンドボックス](/ja/configuration/sandbox)をご覧ください。

## トリガー文字で検索する

SmartBar で次の文字を入力すると、1 種類の項目を検索できます。

| 入力 | 用途 |
| --- | --- |
| `@` | コマンドを検索 |
| `#` | コンテキストを追加 |
| `$` | スキルを使う |
| `>` | 最近のタスクを表示 |
| `/` | モデルや推論の選択などのアクションを開く |

最初の 4 つは、**設定 → SmartBar** の **検索** で変更できます。`/` は変更できません。

名前を記憶から入力するのではなく、開いたリストから項目を選んでください。リストには、実際に使えるコマンドとコンテキストソースが表示されます。[ライティングツール](/ja/features/writing-tools)、[クイックリンク](/ja/features/quick-links)、[コンテキスト認識](/ja/features/context-awareness)をご覧ください。

一部のリストはエイリアスで開きます。エイリアスとスペースを入力すると、[クリップボード履歴、ブックマーク検索、ファイル検索](/ja/features/clipboard-history)が SmartBar 内で開きます。

## コンテキストを追加する

SmartBar は、開いたときに選択中のテキスト、Finder の選択、現在のブラウザページを取得できます。それぞれについて、**設定 → コンテキスト認識** で **自動追加**、**提案**、**オフ** のいずれかを選びます。それ以外を追加するには、`#` を入力してソースを選びます。

## レイアウトを選ぶ

**設定 → SmartBar** の **レイアウト** で、SmartBar を開いたときの表示を設定します。

| レイアウト | 開いたときの表示 |
| --- | --- |
| **入力欄のみ** | 入力欄だけ |
| **入力欄とツールバー** | 入力欄に加えて、クイックアクション、モデルピッカー、音声コントロール |
| **フルパネル** | 上記すべてに加えて、入力欄の下のリスト |

**フルパネル** では、**初期表示** で入力前にリストに表示する内容を、**おすすめプロンプト** または **コマンド一覧** から選べます。どのレイアウトでも、入力したりコマンドを実行したりすると、リストと結果が表示されます。

## 設定

**設定 → SmartBar** を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **ホットキー** | どのアプリからでも SmartBar を開閉します。デフォルトは **⌥Space** です。 |
| **デフォルトエージェント** | 入力した内容に回答するエージェント。 |
| **会話を自動でクリア** | SmartBar を閉じてからこの時間が経って開くと、新しい会話を始めます。**しない** から **開くたびに** まで選べます。 |
| **レイアウト** | SmartBar を開いたときの表示(上記参照)。 |
| **外観** | SmartBar とアプリのサイドバーのライトまたはダークのガラス表現、または **アプリに合わせる**。 |
| **入力ソースを自動で切り替え** | SmartBar で入力している間はこの入力ソースに切り替え、閉じると元に戻します。 |
| **ナビゲーションキー** | リストやテキスト内を移動するための Control キーのショートカット。**macOS**(⌃N ⌃P ⌃F ⌃B)または **Vim**(⌃J ⌃K ⌃L ⌃H)。 |
| **検索** | コマンド、コンテキスト、スキル、最近のタスクのトリガー文字。 |
| **電卓** | 入力中に、計算、単位、通貨、日付、タイムゾーンに答えます。デフォルトでオンです。 |
| **天気とフライト** | 天気、フライト、任意の場所の時刻も調べます。デフォルトではオフです。 |

デフォルトを変更しても、既存のチャットすべてが変わるわけではありません。各チャットがそれぞれのモデルと推論の選択を保持する仕組みは、[モデルの選択](/ja/ai/model-selection-guide)で説明しています。

## 音声と計算

マイクをクリックすると、[音声入力](/ja/features/dictation)で質問を話せます。音声で会話するには [Live Talk](/ja/features/live-voice) を開始します。SmartBar から始めた通話は Dynamic Island に移ります。

`2+3*4` のような算術式を入力すると、SmartBar が結果を表示します。電卓は、単位や通貨の換算、日付やタイムゾーンの計算、`25% off $60 split by 3` のような合計の割り勘にも対応します。コピーする前に、結果と提案されるアクションを確認してください。

天気、フライト、任意の場所の時刻を調べるには、**設定 → SmartBar** で **天気とフライト** をオンにします。その後、`weather in London`、`Tokyo feels like`、`BA008` のようなフライト番号、`time in Chernivtsi` などを入力します。送信されるのは場所の名前またはフライト番号だけで、送信先は Open-Meteo、adsbdb、adsb.lol です。**天気とフライト** は、[Dynamic Island](/ja/features/dynamic-island) の電卓と共通です。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| SmartBar が開かない | **設定 → SmartBar** の **ホットキー** を確認し、同じショートカットを使っている別のアプリがないか確認してください。以前に独自のキーを設定した場合は、その設定のままです。 |
| Return でエージェントに質問せず、コマンドが実行される | **⌘Return** を押すか、**AI に送信** をクリックしてください。 |
| 計算や天気の検索結果が表示されない | **設定 → SmartBar** の **電卓** と **天気とフライト** を確認してください。 |
| アプリや選択したテキストがコンテキストに含まれない | [権限](/ja/configuration/permissions)と **設定 → コンテキスト認識** を確認してください。 |
| リクエストが失敗する | 選択しているプロバイダーを確認し、表示されたエラーを読んでください。 |
| このページにあるコントロールが見当たらない | お使いのビルドがこのガイドより古い可能性があります。[アップデート](/ja/configuration/updates)をご覧ください。 |

Enconvo には、日々の作業に合わせて選べる複数の入り口があります。タスクに必要な広さやコンテキストに応じて使い分け、よく使うものにショートカットを設定してください。

## ウィンドウを選ぶ

| ウィンドウ | 用途 | 開き方 | ガイド |
| --- | --- | --- | --- |
| SmartBar | さっと質問したりコマンドを実行したりする | **⌥Space** | [SmartBar](/ja/features/smartbar) |
| チャットウィンドウ | 履歴やファイル付きで継続的な会話を行う | **⌃⌘X** | [チャットウィンドウ](/ja/ai/chat) |
| アプリのサイドバー | ほかのアプリの横で作業する | **⌃⌘E**、またはアプリウィンドウ横のハンドル | [アプリのサイドバー](/ja/features/app-sidebar) |
| PopBar | 選択したテキストに対して操作する | テキストを選択 | [PopBar](/ja/features/popbar) |
| Dynamic Island | 画面上部で素早く入力し、セッションの進行を確認する | 画面上端の中央にポインタを合わせる | [Dynamic Island](/ja/features/dynamic-island) |
| ペット | Agent の動きを示すキャラクターをデスクトップに常駐させる | ペットをクリック | [デスクトップペット](/ja/features/pet) |
| アバター | 音声で Agent キャラクターと会話する | ガイドを参照 | [アバター](/ja/features/avatar) |

## 開くためのショートカットを設定する

**設定 → ショートカット** または各機能の設定ページを開き、割り当てられているキーの組み合わせと起動モードを確認します。SmartBar、チャットウィンドウ、アプリのサイドバーにはデフォルトのショートカットがあります。Dynamic Island と PopBar は、ご自身で設定するまでショートカットがありません。

グローバルショートカットは macOS や入力メソッド、ほかのアプリと競合することがあります。ショートカットでウィンドウが開かない場合は、ほかに使われていない組み合わせを選んでください。詳しくは[キーボードショートカット](/ja/configuration/keyboard-shortcuts)をご覧ください。

## 結果を表示したままにする

今開いているウィンドウのピン留めボタンやウィンドウコントロールを使います。別のアプリに戻っても SmartBar を最前面に保つには、**Pin SmartBar** を実行するか、SmartBar 上で **⌘P** を押します。

作業が終わったら Escape を押すか、ウィンドウの閉じるボタンを使います。ウィンドウを閉じても会話は削除されません。

## Dock アイコン

チャットウィンドウや設定を閉じた後も Enconvo は Dock に残るため、そこから再度開けます。これらのウィンドウを閉じたときに Dock アイコンも消したい場合は、**設定 → チャットウィンドウ** で **閉じたら Dock アイコンを隠す** をオンにしてください。

Dock アイコンのバッジには、確認が必要なチャットの数が表示されます。まだ開いていない結果やエラー、承認や回答を待っているチャット、さらにフレンドからの未読メッセージが含まれます。

Enconvo のウィンドウをしばらく隠したいときは、**⌘H**（**Enconvo を隠す**）を押してください。再度いずれかのウィンドウを開くまで非表示になります。

## マルチディスプレイ

各ウィンドウの設定にあるディスプレイ設定、特に Dynamic Island の **表示先** を確認してください。ディスプレイ配置を変更した後は、ウィンドウを開き直して想定した画面に表示されるか確認してください。アプリのサイドバーは紐づけられたアプリウィンドウに追従しますが、権限や対象アプリ独自のウィンドウ挙動によって表示位置が変わることがあります。

## 結果が表示される場所

一部のコマンドには **ウインドウモード** や出力先の設定があり、どこに結果を表示するか決められます。音声入力も前面のアプリへ直接貼り付けることができるため、音声入力の前にカーソル位置を確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ウィンドウが開かない | ショートカットとアクティブなディスプレイ、またほかのアプリの裏に隠れていないか確認してください。 |
| 以前覚えていたショートカットで開かない | デフォルトは SmartBar が **⌥Space**、チャットウィンドウが **⌃⌘X** です。ご自身で設定したキーは変更した内容のまま維持されます。 |
| ウィンドウを閉じたら Dock アイコンを消したい | **設定 → チャットウィンドウ** で **閉じたら Dock アイコンを隠す** をオンにしてください。 |
| それでも開かない、または権限が不足している | [トラブルシューティング](/ja/getting-started/troubleshooting)をご覧ください。 |

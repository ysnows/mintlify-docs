Enconvo には、同じ日常の作業に入る方法がいくつかあります。作業に必要なスペースとコンテキストの量で選び、よく使うショートカットを設定しましょう。

## ウィンドウを選ぶ

| ウィンドウ | 用途 | 開き方 | ガイド |
| --- | --- | --- | --- |
| SmartBar | 手早い質問やコマンドの実行 | **⌥Space** | [SmartBar](/ja/features/smartbar) |
| チャットウィンドウ | 履歴やファイルを使った継続的な会話 | **⌃⌘X** | [チャットウィンドウ](/ja/ai/chat) |
| アプリのサイドバー | ほかのアプリの横での作業 | **⌃⌘E**、またはアプリウィンドウの横のハンドル | [アプリのサイドバー](/ja/features/app-sidebar) |
| PopBar | 選択したテキストの操作 | テキストを選択 | [PopBar](/ja/features/popbar) |
| Dynamic Island | 画面上部での手早い入力とセッションの確認 | 画面上部の中央にポインタを合わせる | [Dynamic Island](/ja/features/dynamic-island) |
| ペット | エージェントの動きを映すキャラクターをデスクトップに置く | ペットをクリック | [デスクトップペット](/ja/features/pet) |
| アバター | エージェントのキャラクターと音声で話す | ガイドを参照 | [アバター](/ja/features/avatar) |

## 開くためのショートカットを設定する

**設定 → ショートカット** またはその機能の設定ページを開き、割り当てられているキーの組み合わせと起動モードを確認します。SmartBar、チャットウィンドウ、アプリのサイドバーにはデフォルトのショートカットがあります。Dynamic Island と PopBar には、設定するまでショートカットがありません。

グローバルショートカットは、macOS、入力メソッド、ほかのアプリと競合することがあります。ショートカットでウィンドウが開かない場合は、ほかで使われていない組み合わせを選んでください。[キーボードショートカット](/ja/configuration/keyboard-shortcuts)をご覧ください。

## 結果を見える状態に保つ

今いるウィンドウのピンまたはウィンドウのコントロールを使います。ほかのアプリに戻っても SmartBar を最前面に保つには、**SmartBar を固定** を実行するか、SmartBar で **⌘P** を押します。

終わったら、Escape を押すか、ウィンドウの閉じるコントロールを使います。ウィンドウを閉じても、会話は削除されません。

## Dock アイコン

チャットウィンドウや設定を閉じても Enconvo は Dock に残るので、そこからもう一度開けます。これらのウィンドウを閉じたときに Dock アイコンも消したい場合は、**設定 → チャットウィンドウ** で **閉じたときに Dock アイコンを隠す** をオンにします。

Dock アイコンのバッジは、対応が必要なチャットの数を表します。まだ開いていない結果や失敗、承認や回答を待っているチャット、友達からの未読メッセージが含まれます。

Enconvo のウィンドウをしばらく隠すには、**⌘H** (**Enconvo を非表示**) を押します。もう一度どれかを開くまで、隠れたままになります。

## 複数のディスプレイ

各ウィンドウの設定にあるディスプレイのオプション、特に Dynamic Island の **表示先** を確認してください。ディスプレイの配置を変更したら、ウィンドウをもう一度開き、思った画面に表示されていることを確認します。アプリのサイドバーは、取り付けられたアプリウィンドウに追従し、権限やアプリ自体のウィンドウの挙動が取り付け方に影響することがあります。

## 結果が表示される場所

一部のコマンドには、結果の表示先を決める **ウインドウモード** や出力の設定があります。音声入力は、最前面のアプリに貼り付けることもあるので、話す前にカーソルの位置を確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ウィンドウが開かない | ショートカットとアクティブなディスプレイ、ほかのアプリの後ろに隠れていないかを確認してください。 |
| 知っていたショートカットで何も開かない | デフォルトは、SmartBar が **⌥Space**、チャットウィンドウが **⌃⌘X** です。ご自身で設定したキーは、設定したままです。 |
| ウィンドウを閉じたあとに Dock アイコンを消したい | **設定 → チャットウィンドウ** で **閉じたときに Dock アイコンを隠す** をオンにします。 |
| それでも開かない、または権限が足りない | [トラブルシューティング](/ja/getting-started/troubleshooting)をご覧ください。 |

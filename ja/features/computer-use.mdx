コンピューター操作を使うと、テキストだけでは済まないタスクで、Enconvo が Mac のアプリを操作できます。前面のアプリを見て、見えているコントロールを見つけ、クリックしたりフィールドに入力したりし、リストをスクロールし、項目をドラッグし、ファイルを選び、アプリのメニューを使い、次のステップに進む前にアプリの反応を待ちます。

次のようなデスクトップ作業に使えます。

- Mac アプリでフォームに入力する
- ファイル選択ダイアログでファイルを選ぶ
- 設定ウィンドウの中を移動する
- ツールバーのボタンやメニュー項目をクリックする
- 複数のステップがあるアプリの作業を進める
- 現在のウィンドウに表示されている内容を読み取る

ウェブサイトでは、Enconvo のブラウザ拡張機能(ブラウザコンパニオン)を通じて、ブラウザを使用があなたのブラウザの中で動作します。Safari のように拡張機能のないブラウザでは、代わりにコンピューター操作が画面上でクリックや入力を行います。

次のビデオチュートリアルでは、コンピューター操作とブラウザを使用のセットアップから、最初から最後までの使い方を 5 分で紹介します。オンにして 2 つの権限を許可し、Chrome にブラウザ拡張機能を追加し、右の Option キーを押したまま頼み、Safari、Chrome、Mac アプリでの動作を確認し、タスク全体を任せます。

## コンピューター操作をオンにする

コンピューター操作には macOS の 2 つの権限が必要です。クリックと入力のためのアクセシビリティと、画面を見るための画面収録です。

<Steps>
  <Step title="コンピューター操作の設定を開く">
    **設定 → コンピューター操作** を開き、スイッチがオンになっていることを確認します。
  </Step>
  <Step title="両方の権限を確認する">
    **アクセシビリティ** と **画面収録** の両方が **有効** と表示されているはずです。
  </Step>
  <Step title="足りない権限を許可する">
    **必須** と表示されている権限があれば、その横の **開く** をクリックし、**システム設定 → プライバシーとセキュリティ** のその権限の項目で Enconvo をオンにします。Enconvo に戻って **更新** をクリックします。それでも状態が変わらないときは、Enconvo を終了して開き直してください。
  </Step>
</Steps>

## ブラウザ拡張機能を追加する

<Steps>
  <Step title="ブラウザを使用の設定を開く">
    **設定 → ブラウザを使用** を開きます。**ブラウザ拡張機能** に、拡張機能があるブラウザと接続状態が一覧表示されます。
  </Step>
  <Step title="ブラウザコンパニオンをインストールする">
    **ブラウザ連携アプリをインストール** をクリックします。Chrome ウェブストアで拡張機能のページが開きます。
  </Step>
  <Step title="拡張機能を追加する">
    **Chrome に追加**、続いて **拡張機能を追加** をクリックします。ブラウザの拡張機能メニューを開き、拡張機能をピン留めしてツールバーに表示したままにします。
  </Step>
  <Step title="接続を確認する">
    **設定 → ブラウザを使用** に戻ると、ブラウザが **接続済み** と表示されます。Edge、Arc、Brave も同じ手順で設定します。
  </Step>
</Steps>

拡張機能のポップアップ、対応ブラウザ、トラブルシューティングについては[ブラウザ拡張機能](/ja/features/browser-extension)をご覧ください。

## タスクを実行する

クリックの手順ではなく、望む結果を頼みましょう。

<Steps>
  <Step title="対象のアプリを開く">
    Enconvo に作業させたいアプリやウィンドウを前面に出します。
  </Step>
  <Step title="右の Option キーを押したまま頼む">
    右の **Option** キーを押したまま、してほしいことを話し、キーを離します。アプリとページを名指ししてください。たとえば「Safari で、このページの最安の直行便を探して」や「設定パネルを開いて、ログイン時に起動をオフにして」のように伝えます。エージェントにリクエストを入力して頼むこともできます。
  </Step>
  <Step title="作業を見守る">
    Enconvo が作業しているウィンドウの縁に柔らかな光が走り、クリックのたびに光の波が広がり、Dynamic Island が各ステップを表示します。ウィンドウが見えない場所にあるときは、[ピクチャインピクチャ](/ja/features/picture-in-picture)ウィンドウが画面の隅にその様子をライブで表示します。いつでも操作を引き継いだり、タスクを止めたりできます。
  </Step>
  <Step title="重要なステップを確認する">
    削除、金銭、アカウント、権限の変更にかかわる操作では、Enconvo が先へ進む前にそのステップを確認します。キーボードショートカットも同様です。削除、送信、支払い、アプリの終了、サインアウトを行うショートカットの前には、Enconvo が確認します。
  </Step>
  <Step title="結果を受け取る">
    Enconvo はアプリを見て、操作し、結果を待ち、タスクが終わるか確認が必要になるまで続けます。終わると、結果を伝えます。
  </Step>
</Steps>

### ブラウザで

> 「富士山とレーニア山の Wikipedia ページを開いて、どちらが高いか教えて。」

拡張機能が接続されていると、ブラウザを使用は専用のタブをバックグラウンドで開くので、いま見ているページはそのままです。拡張機能が作業している間、ブラウザにはページ上部にバーが表示されます。キャンセルしないでください。エージェントのターンが終わると、開いたタブは閉じます。結果としてエージェントが渡したページ、あなたに引き渡されたタブ、ピン留めしたタブ、いま見ているタブは開いたままで、あなた自身のタブが閉じられることはありません。

## コンピューター操作でできること

| 操作 | 例 |
|--------|----------|
| **アプリの状態を確認** | 現在のウィンドウ、コントロール、メニュー項目、選択中のテキスト、表示されているフィールドを読み取る |
| **クリックとダブルクリック** | ボタン、サイドバーの行、ツールバーの項目、メニューコマンド、座標をクリックする |
| **入力とキー操作** | フィールドへの入力、フォームの送信、**⌘S** などのショートカットの使用 |
| **スクロール** | リスト、表、設定ペイン、長いドキュメントを移動する |
| **ドラッグ** | アプリが対応していれば、ファイル、行、スライダー、選択ハンドルをドラッグする |
| **ファイル選択ダイアログの使用** | 開くダイアログや保存ダイアログでファイルやフォルダを選ぶ |
| **操作後に待つ** | クリック、移動、読み込みのあとにアプリをもう一度確認する |
| **アプリへのサインイン** | 保存済みのユーザー名とパスワードを、エージェントにパスワードを見せずにアプリのサインインへ入力する。[認証情報](/ja/configuration/credentials)をご覧ください。 |

複数のエージェント(たとえば別々のアプリで作業するサブエージェント)が、同時にコンピューター操作を使えます。それぞれが自分のアプリで同時に動作し、順番を待つのは同じアプリで作業するエージェントだけです。操作は、アプリの別のウィンドウが前面にあっても、エージェントが意図したウィンドウに送られます。

## 使えるアプリを選ぶ

**設定 → コンピューター操作 → アプリへのアクセス** で、コンピューター操作が見たり使ったりできるアプリを設定します。**モード** を選びます。

- **次を除くすべてのアプリ**:**ブロック中のアプリ** にあるアプリには触れず、それ以外のアプリを使います。
- **これらのアプリのみ**:**許可したアプリ** にあるアプリだけを使います。**エージェントがほかのアプリを必要とするとき** では、**確認を求める** を選ぶと、エージェントがアプリを必要としたときに「このアプリをコンピューター操作で使用しますか?」と確認され、**拒否** を選ぶと使われません。

**アプリを追加** をクリックして、いま開いているアプリまたは アプリケーション フォルダからアプリを追加します。ブロックしたアプリはスクリーンショットに含まれません。パスワードマネージャとシステムのサインイン画面は常にブロックされ、**パスワードとシステムの確認画面** と表示されます。PopBar、選択したテキスト、音声入力には、それぞれ専用の設定があります。

## 例

| 頼み方 | Enconvo の動作 |
| --- | --- |
| 「このファイル選択ダイアログで、デスクトップの最新のスクリーンショットを選んで。」 | ファイル選択ダイアログを見て、フォルダに移動し、ファイルを選んで、ダイアログを確定します。 |
| 「このアプリの環境設定を開いて、通知を無効にして。」 | アプリのメニューを使って設定を見つけ、オフにして、結果を確認します。 |
| 「時計アプリで、ワールドクロックに東京とロンドンを追加して。」 | それぞれの都市を見つけてリストに追加し、両方が追加されたことを確認します。 |
| 「履歴書を探して、この求人に応募して。」 | ファイルを見つけ、フォームのすべてのフィールドに入力し、ファイルを添付して送信します。送信させる前にフォームを確認してください。 |
| 「メールから確認コードをコピーして、ログインウィンドウに貼り付けて。」 | 表示されているウィンドウを読み取り、切り替えながらテキストをコピーして、フィールドに貼り付けます。 |

## 安全に使うために

<Warning>
コンピューター操作は、実際のアプリと実際のデータを扱います。フォームの送信、アカウント設定の変更、ファイルの削除、購入、メッセージの送信を Enconvo に行わせる前に、画面を確認してください。
</Warning>

- 可能なら、対象のウィンドウを表示したままにします。
- 具体的な目標と、守ってほしい制限を伝えます。
- 個人情報や金銭にかかわるページでは、Enconvo が操作する前に確認します。
- 画面の内容が頼んだこととずれてきたら、タスクを止めます。

## 設定

| 設定 | 場所 | 変わること |
| --- | --- | --- |
| **アプリへのアクセス** | **設定 → コンピューター操作** | コンピューター操作が見たり使ったりできるアプリ。[使えるアプリを選ぶ](#使えるアプリを選ぶ)をご覧ください。 |
| **ピクチャインピクチャウィンドウ** | **設定 → コンピューター操作** | アプリウィンドウのライブ表示を画面の隅に出すタイミング。**常に**(既定)、**必要なときのみ**、**オフ** から選びます。[ピクチャインピクチャ](/ja/features/picture-in-picture)をご覧ください。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| Enconvo がアプリのコントロールを認識できない | Enconvo にアクセシビリティの権限があることを確認し、Enconvo とそのアプリを再起動してください。アプリによって公開されるコントロールの数は異なりますが、スクリーンショットや位置を指定したクリックは使える場合があります。 |
| クリックが別のアプリに入る | 開始前にそのアプリを前面に出してください。複数のウィンドウを開いているときは、リクエストでアプリやウィンドウを指定します。 |
| ファイル選択ダイアログでファイルを選べない | ファイルが存在し、ダイアログがそのファイルの種類を受け付けることを確認してください。iCloud やネットワークドライブのファイルは、ダウンロードが終わるのを待ちます。 |
| エージェントがアプリを使えないと言う | そのアプリが **設定 → コンピューター操作 → アプリへのアクセス** でブロックされているか、許可リストにありません。リストを変更するか、エージェントがアプリの使用を求めたときに確認に答えてください。 |
| タスクの進みが速すぎる | 「保存ボタンが有効になるまで待って」「表が再読み込みされたら続けて」のように、目で確認できることを待つよう Enconvo に頼んでください。 |

コンピューター操作を使うと、テキストのやり取りだけでは完結しないタスクで、Enconvo が Mac 上のアプリを操作できるようになります。最前面のアプリを確認し、画面上のコントロールを見つけてクリックや入力、リストのスクロール、項目のドラッグ、ファイルの選択、アプリメニューの操作を行い、アプリが応答するのを待ってから次のステップに進みます。

次のようなデスクトップ作業に便利です：

- Mac アプリ内のフォームに入力する
- ファイル選択ダイアログでファイルを選ぶ
- 設定ウィンドウ内を移動して操作する
- ツールバーボタンやメニュー項目をクリックする
- 複数ステップからなるアプリ作業を進める
- 現在のウィンドウに表示されている内容を読み取る

ウェブサイトには、Enconvo ブラウザ拡張機能（ブラウザ連携アプリ）を通じてご自身のブラウザ内で動作するブラウザを使用（Browser Use）が適しています。Safari のように拡張機能がないブラウザでは、代わりにコンピューター操作が画面上でクリックや入力を行います。

下の動画チュートリアルでは、コンピューター操作とブラウザを使用の設定から実際の利用までを 5 分で解説しています。機能をオンにして 2 つの権限を付与し、Chrome に拡張機能を追加し、右 Option キーを押したまま頼んで、Safari・Chrome・Mac アプリでの動作や一連のタスクの依頼を確認します。

## コンピューター操作をオンにする

コンピューター操作には、クリックや入力を行うための「アクセシビリティ」と、画面を見るための「画面収録」という 2 つの macOS 権限が必要です。

<Steps>
  <Step title="コンピューター操作の設定を開く">
    **設定 → コンピューター操作**を開き、スイッチがオンになっていることを確認します。
  </Step>
  <Step title="両方の権限を確認する">
    **アクセシビリティ**と**画面収録**の両方が**有効**になっていることを確認します。
  </Step>
  <Step title="不足している権限を許可する">
    いずれかが**必須**と表示されている場合は、横の**開く**をクリックし、**システム設定 → プライバシーとセキュリティ**で該当権限の項目から Enconvo をオンにします。Enconvo に戻って**更新**をクリックします。状態が変わらない場合は、Enconvo を一度終了して開き直してください。
  </Step>
</Steps>

## ブラウザ拡張機能を追加する

<Steps>
  <Step title="ブラウザを使用の設定を開く">
    **設定 → ブラウザを使用**を開きます。**ブラウザ拡張機能**に、拡張機能が導入されているブラウザと接続状況の一覧が表示されます。
  </Step>
  <Step title="ブラウザ連携アプリをインストール">
    **ブラウザ連携アプリをインストール**をクリックします。Chrome ウェブストアで拡張機能のページが開きます。
  </Step>
  <Step title="拡張機能を追加する">
    **Chrome に追加**をクリックし、次に**拡張機能を追加**をクリックします。ブラウザの拡張機能メニューを開き、ツールバーに常に表示されるよう固定しておきます。
  </Step>
  <Step title="接続を確認する">
    **設定 → ブラウザを使用**に戻ると、ブラウザが**接続済み**と表示されます。Edge、Arc、Brave でも手順は同じです。
  </Step>
</Steps>

拡張機能のポップアップ、対応ブラウザ、トラブルシューティングについては[ブラウザ拡張機能](/ja/features/browser-extension)をご覧ください。

## タスクを実行する

クリック手順を並べるのではなく、求める結果を伝えてください。

<Steps>
  <Step title="対象のアプリを開く">
    Enconvo に操作させたいアプリまたはウィンドウを前面に出します。
  </Step>
  <Step title="右 Option キーを押したまま話しかける">
    右の **Option** キーを押したまま必要なことを話し、終わったら離します。「Safari のこのページで一番安い直行便を探して」や「設定パネルを開いてログイン時に起動をオフにして」のように、アプリやページを指定してください。エージェントにテキストで入力することもできます。
  </Step>
  <Step title="動きを見守る">
    Enconvo が操作しているウィンドウの縁に柔らかな光が走り、クリックごとに光の波紋が広がり、Dynamic Island に各ステップが表示されます。ウィンドウが隠れているときは、画面の隅に[ピクチャーインピクチャー](/ja/features/picture-in-picture)ウィンドウでライブ表示されます。いつでも自分で操作を引き継いだり、タスクを停止したりできます。
  </Step>
  <Step title="重要な操作を確認する">
    データの削除、金銭に関わる操作、アカウント設定や権限の変更を行う場合は、次に進む前に承認を確認します。これはキーボードショートカットにも適用され、削除、送信、支払い、アプリ終了、サインアウトにつながるショートカットの前には確認を求めます。
  </Step>
  <Step title="結果を受け取る">
    Enconvo はアプリを確認して操作し、結果を待ってから次の動作を続け、タスクが完了するか確認が必要になるまで進めます。完了すると結果をお知らせします。
  </Step>
</Steps>

### ブラウザ内での操作

> 「富士山とレーニア山の Wikipedia ページを開いて、どちらが高いか教えて。」

拡張機能が接続されていると、ブラウザを使用はバックグラウンドで独自のタブを開くため、今見ているページはそのまま残ります。拡張機能が作業している間はページ上部にバーが表示されますが、キャンセルしないでください。エージェントのターンが終わると、開いたタブは閉じられます。結果としてあなたに渡したページ、あなたに引き継いだタブ、ピン留めしたタブ、今見ているタブは開いたまま残り、あなた自身のタブが閉じられることはありません。

## コンピューター操作でできること

| 操作 | 例 |
|--------|----------|
| **アプリの状態を確認** | 現在のウィンドウ、コントロール、メニュー項目、選択中のテキスト、表示中の入力欄を読み取ります |
| **クリック・ダブルクリック** | ボタン、サイドバーの行、ツールバー項目、メニューコマンド、座標をクリックします |
| **入力・キー操作** | 入力欄を埋めたり、フォームを送信したり、**⌘S** などのショートカットを使ったりします |
| **スクロール** | リスト、表、設定パネル、長いドキュメントを移動します |
| **ドラッグ** | アプリが対応していれば、ファイル、行、スライダー、選択ハンドルをドラッグします |
| **ファイル選択ダイアログの操作** | 「開く」や「保存」ダイアログでファイルやフォルダを選択します |
| **操作後の待機** | クリック、ページ遷移、読み込みのあと、アプリの状態を再確認します |
| **アプリへのサインイン** | エージェントにパスワードを見せることなく、保存済みのユーザー名とパスワードをアプリのサインイン画面に入力します。詳しくは[認証情報](/ja/configuration/credentials)をご覧ください。 |

異なるアプリで作業するサブエージェント同士など、複数のエージェントが同時にコンピューター操作を使うこともできます。それぞれが別々のアプリで同時に操作を行い、同じアプリを操作する場合だけ順番待ちになります。アプリの別のウィンドウが前面にあっても、操作はエージェントが意図したウィンドウに対して行われます。

## 使用できるアプリを選ぶ

**設定 → コンピューター操作 → アプリへのアクセス**では、コンピューター操作が見て操作できるアプリを設定します。**モード**を選択してください：

- **次を除くすべてのアプリ**：**ブロック中のアプリ**にあるアプリには触れず、それ以外のアプリを使います。
- **これらのアプリのみ**：**許可したアプリ**にあるアプリだけを使います。**エージェントがほかのアプリを必要とするとき**では、エージェントが必要とした際に「コンピューター操作によるこのアプリの使用を許可しますか？」を確認する**確認を求める**か、**拒否**かを選べます。

**アプリを追加**をクリックすると、現在開いているアプリや「アプリケーション」フォルダから追加できます。ブロックされたアプリはスクリーンショットにも写りません。パスワードマネージャーとシステムの認証画面は常にブロックされ、**パスワードとシステムの確認画面**として表示されます。PopBar、選択テキスト、音声入力にはそれぞれ独自の設定があります。

## 使用例

| 依頼内容 | Enconvo の動作 |
| --- | --- |
| 「このファイル選択画面で、デスクトップにある一番新しいスクリーンショットを選んで。」 | ファイル選択ダイアログを確認し、フォルダを開いてファイルを選び、ダイアログを確定します。 |
| 「このアプリの環境設定を開いて、通知を無効にして。」 | アプリのメニューを使って設定を見つけ、オフにして、結果を確認します。 |
| 「時計アプリで、世界時計に東京とロンドンを追加して。」 | 各都市を検索してリストに追加し、両方が追加されたことを確認します。 |
| 「履歴書を見つけて、この求人に応募して。」 | ファイルを見つけ、フォームの各項目に入力し、ファイルを添付して送信しようとします。送信を許可する前にフォームの内容を確認してください。 |
| 「メールから確認コードをコピーして、ログインウィンドウに貼り付けて。」 | 表示されているウィンドウを読み取り、切り替えてテキストをコピーし、入力欄に貼り付けます。 |

## 安全に使うためのポイント

<Warning>
コンピューター操作は実際のアプリと実際のデータを操作します。フォームの送信、アカウント設定の変更、ファイル削除、購入、メッセージ送信を許可する前に、必ず画面を確認してください。
</Warning>

- 可能なときは対象のウィンドウを表示したままにしてください。
- 具体的なゴールと条件・制限を伝えてください。
- 個人情報やお金に関わるページを操作させる前は内容をよく確認してください。
- 画面上の動きが依頼内容と合わなくなったら、すぐにタスクを停止してください。

## 設定

| 設定 | 場所 | 変更される内容 |
| --- | --- | --- |
| **アプリへのアクセス** | **設定 → コンピューター操作** | コンピューター操作が見て操作できるアプリを指定します。詳しくは[使用できるアプリを選ぶ](#使用できるアプリを選ぶ)をご覧ください。 |
| **ピクチャーインピクチャーウィンドウ** | **設定 → コンピューター操作** | 操作中のアプリウィンドウのライブ表示を画面の隅に出すタイミング：**常に**（デフォルト）、**必要なときのみ**、または**オフ**。詳しくは[ピクチャーインピクチャー](/ja/features/picture-in-picture)をご覧ください。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| Enconvo がアプリのコントロールを認識できない | Enconvo にアクセシビリティ権限があるか確認し、Enconvo と対象アプリを再起動してください。アプリによっては公開されるコントロールが少ないものもありますが、スクリーンショットと座標クリックで操作できる場合があります。 |
| 別のアプリにクリックが行ってしまう | 開始前に操作したいアプリを前面に出してください。複数のウィンドウが開いている場合は、依頼時にアプリ名やウィンドウ名を指定してください。 |
| ファイル選択ダイアログでの選択に失敗する | ファイルが存在し、選択画面がそのファイル形式を受け付けられるか確認してください。iCloud やネットワークドライブ上のファイルは、ダウンロードが終わってから実行してください。 |
| エージェントがそのアプリを使えないと言う | **設定 → コンピューター操作 → アプリへのアクセス**で、そのアプリがブロックされているか許可リストに入っていません。リストを変更するか、エージェントが使用許可を求めたときの確認に答えてください。 |
| タスクが次の操作に急ぎすぎる | 「保存ボタンが有効になるまで待って」や「テーブルの再読み込みが終わってから続けて」のように、画面上で待つべき状態を指定してください。 |

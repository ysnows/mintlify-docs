title: "Dynamic Island"
description: "画面上部のコンパクトなパネルから、エージェントへの質問、ショートカットの実行、実行中のタスクの確認ができます。"
---

Dynamic Island は、画面の上部中央に表示されます。ポインタを合わせるとホームが開き、リクエストを入力または音声で伝えたり、コンテキストを添付したり、ショートカットを実行したり、進行中のタスクに戻ったりできます。手早いリクエストや、ウィンドウを開かずにエージェントの動きを見守りたいときに使います。

ほかの用途には、ショートカットから手早く質問やコマンドを実行するには [SmartBar](/ja/features/smartbar)、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、1 つのアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択したテキストを操作するには [PopBar](/ja/features/popbar)、デスクトップにキャラクターを置くには[デスクトップペット](/ja/features/pet)を使います。[ウィンドウ管理](/ja/features/window-management)で、すべてを比較できます。

## リクエストを始める

1. **設定 → Dynamic Island** を開き、**Dynamic Islandを有効にする** をオンにします。
2. 画面の上部中央にポインタを合わせて、ホームを開きます。キーボードから開くには、先に **開き方と表示** タブで **ショートカット** を設定します。
3. リクエストを入力するか、**ホームのショートカット** のいずれかをクリックします。
4. 送信する前に、添付されているコンテキストを確認します。[Appshots](/ja/features/appshots) と[画面に描画](/ja/features/screen-doodle)は、ほかのアプリについて質問するのに役立ちます。
5. 進行状況を確認し、タスクが終わったら結果を開きます。返信を止めるには、**停止** をクリックするか、Esc を押します。

タスクの実行中に入力したメッセージは、すぐに表示されます。チャットウィンドウに移動するには、アイランドの上部バーの **チャットウィンドウで開く** をクリックします。チャットが始まる前なら、そこで新しいチャットが開き、入力済みの内容も引き継がれます。

エージェントモードでは、**権限** チップがエージェントが実行前に確認するタイミングを設定し、**サンドボックス** スイッチがエージェントのコマンドを作業フォルダ内に限定します。[エージェントのサンドボックス](/ja/configuration/sandbox)をご覧ください。

## ホームで計算する

ホームで計算式、単位の換算、時刻を入力すると、アイランドの下のカードに答えが表示されます。Return を押すとコピーし、**⌘Return** を押すと代わりにエージェントに質問します。

電卓は、計算、単位、通貨、日付、タイムゾーンに対応しています。天気、フライト、世界各地の時刻も調べるには、**設定 → Dynamic Island → ホーム** で **天気とフライト** をオンにします。送信されるのは、地名またはフライト番号だけで、送信先は Open-Meteo、adsbdb、adsb.lol です。このスイッチは [SmartBar](/ja/features/smartbar) と共通です。

## タスクを確認する

タスク一覧には、実行中のチャット、承認が必要なチャット、失敗したチャット、結果が出ているチャットが表示されます。2 つ以上のタスクが実行中のときは、1 つの **タスク** チップにまとめられます。

1. ホームまたはノッチのタスクチップをクリックします。入力欄の代わりに一覧が開きます。
2. 承認は、その行でそのまま許可または拒否できます。
3. ほかのチャットをクリックすると、そのチャットが始まったウィンドウで開きます。

まだ読んでいないチャットを探すには、**履歴** を開き、**未読** で絞り込みます。**すべて既読にする** で一括で既読になり、考えが変わったときは **元に戻す** が使えます。チャット一覧には、**チャットをアーカイブ** と **チャットを削除** もあります。

## 設定

**設定 → Dynamic Island** を開きます。設定は 3 つのタブに分かれています。

### ホーム

| 設定 | 変更される内容 |
| --- | --- |
| **ホームのショートカット** | ホームの入力欄の横にあるショートカットのグリッド。ショートカットをドラッグして並べ替えたり別のページに移動したりでき、ポイントして **×** をクリックすると外せます。**ショートカットを追加** で追加できます。 |
| 天気ページとウィジェットページ | ショートカットの後ろに、**天気ページを追加** または **ウィジェットページを追加** します。 |
| **電卓** | ホームで入力しながら、計算、単位、通貨、日付、タイムゾーンに答えます。 |
| **天気とフライト** | 天気、フライト、世界各地の時刻も調べます。SmartBar と共通です。 |
| **デフォルトエージェント** | ホームで入力した内容に回答するエージェント。何も入力していないホームは、ボタンに表示されているデフォルトエージェントを常に実行します。入力欄でいつでもエージェントを切り替えられます。 |

**ホームをデフォルトに戻す** で、ホームのデフォルトのレイアウトに戻ります。各タブにそれぞれのリセットボタンがあります。

### 開き方と表示

| 設定 | 変更される内容 |
| --- | --- |
| **ポインタを合わせたら開く** | ポインタを合わせてから開くまでの時間: **すぐに**、**少し待つ**、**長めに待つ**。 |
| **離れたら折りたたむ** | ポインタが離れてから閉じるまでの時間: **すぐ** (0.5 秒)、**標準**、**ゆっくり**。 |
| **ショートカット** | どのアプリからでも、アイランドを表示、開く、折りたたむ。 |
| **ポインタを合わせるまで隠す** | 折りたたんだアイランドを、画面の上部中央にポインタを合わせるか、ショートカットを押すまで隠します。 |
| **ノッチをほかのアプリに任せる** | ノッチそのものにポインタを合わせてもアイランドが開かないので、ほかのノッチ用アプリが使えます。 |
| **バウンド** | アイランドが開閉するときのバネの強さ。 |
| **表示先** | **すべての画面**、**マウスに追従**、または選んだ 1 つのディスプレイ。 |
| **フルスクリーンでは隠す** | ディスプレイ上のアプリがフルスクリーンの間、アイランドの待機中のピルを隠し、アプリの上部を覆わないようにします。デフォルトでオンです。アプリがフルスクリーンと報告するウィンドウだけが対象で、最大化されたウィンドウは対象外です。アイランドにポインタを合わせたり話しかけたりすると、引き続き表示されます。 |
| **スクリーンショットと収録に表示** | オフにすると、キャプチャや共有する内容にアイランドが写りません。 |

### キャラクター

| 設定 | 変更される内容 |
| --- | --- |
| **アイランドにキャラクターを表示** | デスクトップペットまたはデフォルトエージェントのアバターが、折りたたんだアイランドに表示され、エージェントの動きを演じます。 |
| **キャラクター** | **アバター** または **ペット**。 |
| **モーション** | **常に**、**作業中のみ**、**しない**。 |
| **エージェントのアイコンに使う** | チャットウィンドウで、デフォルトエージェントのアイコンとしてキャラクターを表示します。 |

## 音声と完了したタスク

音声入力は、話した内容をプロンプトに変換します。音声での会話には [Live Talk](/ja/features/live-voice) を使います。SmartBar から始めた Live Talk の通話は、Dynamic Island に移ります。

アイランドから始めたタスクが終わったときにアイランドを自動で開くには、[通知](/ja/configuration/notifications)で **Dynamic Island を開く** をオンにします。この設定は macOS の通知とは別です。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 別のディスプレイに表示される | **表示先** を確認してください。 |
| アプリがフルスクリーンのときに消える | これがデフォルトの動作です。画面の上部にポインタを合わせて開くか、**フルスクリーンでは隠す** をオフにしてください。 |
| メニューバーが自動で隠れているときに開かない | 画面の上部中央をクリックしてください。 |
| ホームで計算や検索の結果が表示されない | **ホーム** タブの **電卓** と **天気とフライト** を確認してください。 |
| スクリーンショットや収録に写らない | 権限を変更する前に、**スクリーンショットと収録に表示** をオンにしてください。 |
| ポインタを合わせても開かない | ショートカットを押してみてください。ショートカットで開く場合は、**ポインタを合わせたら開く** と **ノッチをほかのアプリに任せる** を確認します。何をしても開かない場合は、**Dynamic Islandを有効にする** を確認します。 |

Dynamic Island は画面上端の中央に配置されます。ポインタを合わせるとホームが開き、テキストや音声での依頼、コンテキストの添付、ショートカットの実行、進行中タスクへの復帰が行えます。ウィンドウを開かずに素早く質問したり、エージェントの動きを見守ったりしたいときに便利です。

用途に応じて使い分けることもできます。どのアプリからでもショートカットで素早く質問やコマンドを実行するには [SmartBar](/ja/features/smartbar)、長い会話やファイルの扱いには[チャットウィンドウ](/ja/ai/chat)、特定のアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択テキストへの操作には [PopBar](/ja/features/popbar)、デスクトップ上に常駐するキャラクターとしては[デスクトップペット](/ja/features/pet)を使えます。各ウィンドウの比較は[ウィンドウ管理](/ja/features/window-management)を参照してください。

## リクエストを始める

1. **設定 → Dynamic Island** を開き、**Dynamic Islandを有効にする** をオンにします。
2. 画面上端の中央にポインタを合わせてホームを開きます。キーボードから開くには、まず **開き方と表示** タブで **ショートカット** を設定してください。
3. 依頼内容を入力するか、**ホームのショートカット** のいずれかをクリックします。
4. 送信前に添付されたコンテキストを確認します。[Appshots](/ja/features/appshots) や[画面落書き](/ja/features/screen-doodle)を使うと、他のアプリについて質問しやすくなります。
5. 進行状況を確認し、タスクが終わったら結果を開きます。応答を止めるには **停止** をクリックするか Esc を押します。

タスクの実行中に入力したメッセージはすぐに反映されます。チャットウィンドウへ移すには、アイランド上部のバーにある **チャットウィンドウで開く** をクリックします。チャット開始前にクリックすると、入力中の文字を引き継いでチャットウィンドウで新しいチャットを開きます。

エージェントモードでは、**権限** チップでエージェントが操作前に確認を求める条件を設定でき、**サンドボックス** スイッチでエージェントのコマンド実行を作業フォルダ内に制限できます。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。

## ホームで計算する

ホームで数式、単位変換、時刻を入力すると、アイランドの下のカードに答えが表示されます。Return を押すとコピーでき、**⌘Return** を押すと代わりにエージェントへ質問します。

電卓は四則演算、単位、通貨、日付、タイムゾーンに対応しています。各地の天気、フライト状況、現在時刻も調べるには、**設定 → Dynamic Island → ホーム** で **天気とフライト** をオンにしてください。Open-Meteo、adsbdb、adsb.lol には地名または便名のみが送信されます。このスイッチは [SmartBar](/ja/features/smartbar) と共有されています。

## タスクを追う

タスクリストには、実行中のチャット、承認待ちのチャット、失敗したチャット、結果の準備ができたチャットが表示されます。2 件以上のタスクが同時に動いている場合は 1 つの **タスク** チップに折りたたまれます。

1. ホームまたはノッチ上のタスクチップをクリックします。入力欄の位置にリストが開きます。
2. 承認待ちの項目はその行から直接許可または拒否できます。
3. その他のチャットをクリックすると、そのチャットを始めたウィンドウで開きます。

未読のチャットを探すには、**履歴** を開いて **未読** で絞り込みます。**すべて既読にする** で一括で既読にでき、気が変わったら **取り消す** で元に戻せます。チャットリストには **チャットをアーカイブ** と **チャットを削除** もあります。

## 設定

**設定 → Dynamic Island** を開きます。設定は 3 つのタブに分かれています。

### ホーム

| 設定 | 変更される内容 |
| --- | --- |
| **ホームのショートカット** | ホームの入力欄横に並ぶショートカットグリッド。ドラッグで並べ替えや別ページへの移動ができ、ポインタを合わせて **×** を押すと削除、**ショートカットを追加** で追加できます。 |
| 天気とウィジェットのページ | ショートカットの後に **天気ページを追加** または **ウィジェットページを追加** します。 |
| **電卓** | ホームに入力した数式、単位、通貨、日付、タイムゾーンにその場で答えます。 |
| **天気とフライト** | 天気、フライト、各地の時刻も調べます。SmartBar と共有されます。 |
| **デフォルトエージェント** | ホームに入力した内容に応答するエージェント。空のホームでは常にボタンに表示されているデフォルトエージェントが動きます。入力欄からいつでも他のエージェントに切り替えられます。 |

**ホームをデフォルトに戻す** を押すとホームの初期レイアウトに戻ります。各タブにそれぞれリセットボタンがあります。

### 開き方と表示

| 設定 | 変更される内容 |
| --- | --- |
| **ポインタを合わせたら開く** | ポインタを合わせてから開くまでの待ち時間：**すぐに**、**少し待つ**、**長めに待つ**。 |
| **離れたら折りたたむ** | ポインタが離れてから開いたままにする時間：**すぐ**（0.5 秒）、**標準**、**ゆっくり**。 |
| **ショートカット** | どのアプリからでもアイランドを表示・展開・折りたたみします。 |
| **ポインタを合わせるまで隠す** | 画面上端の中央にポインタを合わせるかショートカットを押すまで、折りたたんだアイランドを隠します。 |
| **ノッチをほかのアプリに任せる** | ノッチ自体にポインタを合わせてもアイランドを開かないようにし、他のノッチ系アプリと競合しないようにします。 |
| **バウンド** | アイランドが開閉する際の跳ねるアニメーションの強さ。 |
| **表示先** | **すべての画面**、**マウスに追従**、または選択した特定のディスプレイ。 |
| **フルスクリーンでは隠す** | アプリがフルスクリーン表示の間、そのディスプレイ上の待機中のアイランドを隠してアプリ上部を覆わないようにします。デフォルトでオンです。アプリがフルスクリーンとして報告したウィンドウのみが対象で、最大化ウィンドウは隠れません。ポインタを合わせるか話しかけると通常どおり開きます。 |
| **スクリーンショットと収録に表示** | 画面キャプチャや画面共有にアイランドを写り込ませたくない場合はオフにします。 |

### キャラクター

| 設定 | 変更される内容 |
| --- | --- |
| **アイランドにキャラクターを表示** | デスクトップペットまたはデフォルトエージェントのアバターが折りたたんだアイランドに現れ、エージェントの作業に合わせて動きます。 |
| **キャラクター** | **アバター** または **ペット**。 |
| **アニメーション** | **常に**、**作業中のみ**、または **なし**。 |
| **エージェントのアイコンに使う** | チャットウィンドウでデフォルトエージェントのアイコンとしてキャラクターを表示します。 |

## 音声と完了したタスク

音声入力は話した内容をプロンプトに変換します。声で会話するには [Live Talk](/ja/features/live-voice) を使ってください。SmartBar から始めた Live Talk 通話は Dynamic Island へ引き継がれます。

Dynamic Island から開始したタスクが完了したときに自動でアイランドを開くには、[通知](/ja/configuration/notifications)の **Dynamic Island を開く** をオンにします。この設定は macOS の通知とは独立しています。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 別のディスプレイに表示される | **表示先** を確認してください。 |
| アプリをフルスクリーンにすると消える | これがデフォルトの動作です。画面上端にポインタを合わせて開くか、**フルスクリーンでは隠す** をオフにしてください。 |
| メニューバーが自動非表示のときに開かない | 画面上端の中央をクリックしてください。 |
| ホームで計算や検索結果が出ない | **ホーム** タブの **電卓** と **天気とフライト** を確認してください。 |
| スクリーンショットや録画に写らない | 権限を変更する前に **スクリーンショットと収録に表示** をオンにしてください。 |
| ポインタを合わせても開かない | ショートカットを押してみてください。ショートカットで開く場合は **ポインタを合わせたら開く** と **ノッチをほかのアプリに任せる** を確認します。まったく開かない場合は **Dynamic Islandを有効にする** を確認してください。 |

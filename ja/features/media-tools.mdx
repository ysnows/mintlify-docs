メディアユーティリティは、画像・動画・音声ファイルのサイズ縮小、動画の音声トラック保存、Web ページからの動画ダウンロードといった日常の作業を行うローカルコマンド群です。SmartBar または**設定 → プラグイン**から利用できます。

| コマンド | 機能 | 保存先 |
| --- | --- | --- |
| **Image Compress** | 1 枚以上の画像、またはフォルダとそのサブフォルダ内のすべての画像を指定した品質で圧縮します | 元の画像を置き換え |
| **Video Compress** | 動画ファイルのサイズを小さくします | `~/Downloads` |
| **Audio Compress** | 選んだ品質で音声ファイルを圧縮し、カバーアートも保持します（MP3、WAV、M4A、AAC、OGG、FLAC） | `~/Downloads` |
| **Extract Audio** | 動画（またはフォルダ内のすべての動画）から音声トラックを M4A として保存します（そのままコピーできない場合は MP3） | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | YouTube、TikTok、Instagram、Reddit、X、Vimeo などのリンクから動画または音声をダウンロードします | `~/Downloads` |

<Warning>
**Image Compress** はデフォルトで元の画像を置き換えます。元の画像を残したい場合は、先に設定で **Overwrite Original Image File** をオフにしてください。圧縮後の画像は元の画像の横に `enconvo-compressed-images` フォルダを作って保存されます。
</Warning>

## ファイルを圧縮する・音声を抽出する

1. Finder でファイルを選択するか、コマンドに添付します。Image Compress ではフォルダも指定でき、サブフォルダ内も含めた画像を同じフォルダ構成のまま圧縮できます。
2. SmartBar を開いてコマンドを実行します。
3. 出力ファイルを開いて結果を確認します。

圧縮設定を試す間は元ファイルを残しておくことをおすすめします。各コマンドの設定は**設定 → プラグイン**にあり、Image Compress は **Image Utils**、その他は **Media Utils** にあります。

| 設定 | 変更される内容 |
| --- | --- |
| **Quality** | 0〜100 の値。高いほど画質・音質が保たれますがファイルサイズは大きくなります。デフォルトは 80 です |
| **Destination Folder Path** | 圧縮ファイルの保存先。絶対パス、または元ファイルからの相対パスで指定します |
| **Overwrite Original … File** | 元ファイルを上書きします。画像ではデフォルトでオン、動画と音声ではオフです |

## 動画をダウンロードする

1. ブラウザで動画ページを開くか、リンクをコピーします。
2. SmartBar から **Online Video Downloader** を実行します。ブラウザのアクティブタブの URL、または入力したリンクを使用します。
3. 進行状況は Dynamic Island に表示され、そこからキャンセルもできます。完了したら**Finder で表示**をクリックします。

ダウンロード履歴はチャット履歴に保存され、すでにダウンロード済みのファイルは再取得せずに再利用されます。ダウンロードできるかどうかは対象サイトとアクセス権限に依存します。保存が許可されているコンテンツのみをダウンロードしてください。

| 設定 | 変更される内容 |
| --- | --- |
| **Output Directory** | ダウンロード先のフォルダ。デフォルトは `~/Downloads` です |
| **Audio Only** | 音声のみをダウンロードします |
| **Favorite Resolution** | ダウンロードする解像度。**Best**（デフォルト）から 144p まで選べます |
| **Force Convert to Compatible MP4** | どの環境でも再生できる MP4 に変換します。デフォルトでオンになっており、変換には追加の時間と CPU を使います |
| **Use Browser Cookies** | 本人のみが閲覧できる動画向けに、ブラウザの Cookie を使ってサインイン状態を渡します。**Browser** で使用するブラウザを選びます |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **No images to compress** と表示される | Finder で画像を選択するか添付してから、もう一度コマンドを実行してください |
| 変換に失敗する | ファイル形式、出力先フォルダへの書き込み権限、およびディスクの空き容量を確認してください |
| 非公開動画がダウンロードできない | **Use Browser Cookies** をオンにし、サインイン済みのブラウザを選択してください |
| 特定のサイトからダウンロードできなくなった | エラー内容を確認し、プラグインを更新してからやり直してください。サイト側の形式やアクセス規則が変更されることがあります |

メディアユーティリティは、日常的なメディア作業のためのローカルコマンドです。画像、動画、音声ファイルを小さくする、動画のサウンドトラックを保存する、Web ページから動画をダウンロードするといったことができます。SmartBar または **設定 → プラグイン** にあります。

| コマンド | 内容 | 保存先 |
| --- | --- | --- |
| **Image Compress** | 1 つ以上の画像、またはフォルダとそのサブフォルダ内のすべての画像を、調整可能な品質で圧縮します | 元の画像を置き換えます |
| **Video Compress** | 動画ファイルを小さくします | `~/Downloads` |
| **Audio Compress** | 選んだ品質で音声ファイルを小さくし、カバーアートを保持します（MP3、WAV、M4A、AAC、OGG、FLAC） | `~/Downloads` |
| **Extract Audio** | 動画、またはフォルダ内のすべての動画の音声トラックを、M4A として保存します（トラックをコピーできない場合は MP3） | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | YouTube、TikTok、Instagram、Reddit、X、Vimeo などのリンクから、動画または音声をダウンロードします | `~/Downloads` |

<Warning>
**Image Compress** は、デフォルトで元の画像を置き換えます。元の画像を残すには、先に設定で **Overwrite Original Image File** をオフにしてください。その場合、圧縮されたコピーは、画像の隣の `enconvo-compressed-images` フォルダに保存されます。
</Warning>

## ファイルを圧縮する、または音声を抽出する

1. Finder でファイルを選択するか、添付します。Image Compress では、フォルダを選ぶこともできます。そのフォルダとサブフォルダ内の画像が圧縮され、コピーは同じフォルダ構成で保存されます。
2. SmartBar を開いて、コマンドを実行します。
3. 出力を開いて、確認します。

圧縮の設定を試している間は、元のファイルを残しておいてください。各コマンドの設定は **設定 → プラグイン** にあります。Image Compress は **Image Utils**、それ以外は **Media Utils** です。

| 設定 | 変更される内容 |
| --- | --- |
| **品質** | 0 から 100 まで。高いほど品質が保たれ、ファイルが大きくなります。デフォルトは 80 です |
| **保存先フォルダのパス** | 圧縮したファイルの保存先。絶対パス、またはファイルからの相対パスです |
| **Overwrite Original … File** | 元のファイルを置き換えます。画像ではデフォルトでオン、動画と音声ではオフです |

## 動画をダウンロードする

1. ブラウザで動画のページを開くか、リンクをコピーします。
2. SmartBar から **Online Video Downloader** を実行します。ブラウザのアクティブなタブのリンク、または入力したリンクが使われます。
3. Dynamic Island で進行状況を確認します。ここでキャンセルもできます。完了したら、**Finderで表示** をクリックします。

ダウンロードはチャット履歴に保存され、すでにダウンロードしたファイルは、もう一度取得せずに再利用されます。サイトが使えるかどうかは、そのサイトと、アクセスが許可されている内容によって決まります。保存が許可されているコンテンツだけをダウンロードしてください。

| 設定 | 変更される内容 |
| --- | --- |
| **Output Directory** | ダウンロードの保存先。デフォルトは `~/Downloads` です |
| **Audio Only** | 音声のみをダウンロードします |
| **Favorite Resolution** | ダウンロードする解像度。**Best**（デフォルト）から 144p まであります |
| **Force Convert to Compatible MP4** | どこでも再生できる MP4 に変換します。デフォルトでオンです。時間と CPU が余分にかかります |
| **Use Browser Cookies** | 自分にしか見られない動画のために、ブラウザの Cookie でサインインします。**ブラウザ** でブラウザを選びます |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **No images to compress** | Finder で画像を選択するか添付してから、もう一度コマンドを実行してください |
| 変換に失敗する | ファイルの形式、出力フォルダが書き込み可能か、ディスクに空き容量があるかを確認してください |
| 非公開の動画がダウンロードできない | **Use Browser Cookies** をオンにして、サインインしているブラウザを選んでください |
| あるサイトからのダウンロードが動かなくなった | エラーを読み、もう一度試す前にプラグインを更新してください。Web サイトは、形式やアクセスのルールを変更します |

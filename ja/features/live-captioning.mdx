---
title: "リアルタイム字幕"
description: "音声の再生中にリアルタイムで字幕を表示し、各字幕セッションを後から見返すことができます。"
---

リアルタイム字幕は、講演、動画、通話などの音声が再生またはキャプチャされている間に字幕を表示する機能です。各セッションは専用のリストに保存され、インポートした文字起こしファイルやミーティングの録音とは分けて管理されます。

## 字幕を開始する

1. **設定 → 字幕生成モデル** を開き、リアルタイム認識に対応したモデルを選択します。
2. **設定 → リアルタイム字幕** を開き、**追加** をクリックして **字幕を開始** を選択します。リストが空の場合は **字幕を開始** をクリックします。**ライブ字幕を開始** コマンドを実行するか、Enconvo のメニューバーメニューから **ライブ字幕を開始** を選ぶこともできます。
3. **ライブ字幕を開始** ウィンドウで、オーディオソース、字幕バーを開く位置、表示するスクリーンを選択します。macOS から確認を求められたら、マイクまたはシステムオーディオへのアクセスを許可してください。
4. 追いかけたい音声を再生し、字幕が表示されることを確認します。
5. 終了したら字幕を停止します。保存されたセッションは **リアルタイム字幕** リストから開けます。

キー操作で字幕を開始・停止するには、**設定 → ショートカット** の **音声** セクションでリアルタイム字幕のホットキーを設定してください。実行中に同じホットキーを押すと字幕を停止できます。

## 字幕バーの配置

字幕バーは次の 4 か所のいずれかに開きます。

| 位置 | 表示形式 |
| --- | --- |
| **左側** | 画面の左端に沿った縦長の列です。デフォルトの位置です。 |
| **右側** | 画面の右端に沿った縦長の列です。 |
| **上部中央** | 画面上部の横長の行で、広い字幕エリアの横にコントロールが並びます。 |
| **下部中央** | 画面下部の横長の行で、字幕のようにテキストが並びます。 |

複数のディスプレイを使用している場合は、表示先の画面も選択するか、**ポインタのある画面** のままにします。セッション中に字幕バーを右クリックすると、位置や画面を変更できます。どの位置でも、字幕エリアの端をドラッグしてサイズを調整できます。

## 字幕を翻訳する

一部の音声認識プロバイダーは、原文と言語先の指定や音声翻訳を伴うリアルタイム翻訳に対応しています。これらは選択した字幕生成モデル自身の設定でオンにします。Enconvo Cloud Fast および Soniox では **Translate From** と **Translate To** を使用します。すべての音声認識モデルがリアルタイム翻訳に対応しているわけではなく、ファイルの文字起こしに対応していてもリアルタイム字幕に対応しているとは限りません。

## セッションを見返す

保存されたセッションを開くと、文字起こしと処理結果を確認できます。正確さが求められる場合は、人名、数値、話者ラベルを音声と照らし合わせて確認してください。語彙や話者名を最新に保つには、[辞書と話者](/ja/configuration/speech-assets)をご利用ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 字幕が表示されない | オーディオソース、入力レベル、キャプチャ権限、選択中のモデルを確認してください。 |
| 停止した後にしか文字が出ない | ストリーミングに対応したモデルを選択してください。 |
| 言語が正しくない | モデルの設定で認識言語または言語ヒントを指定してください。 |
| 翻訳されない | モデルが翻訳に対応しているか確認し、翻訳先の言語を設定してください。 |
| セッションに処理エラーが表示される | 保存された項目のエラー詳細を確認してください。音声データが失われたと決めつけず確認してください。 |

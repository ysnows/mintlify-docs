---
title: "リアルタイム字幕"
description: "音声の再生中にリアルタイムで字幕を読み、あとから各字幕セッションを見返します。"
---

リアルタイム字幕は、講演、動画、通話など、音声の再生中または取り込み中に字幕を表示します。各セッションは、読み込んだ文字起こしファイルや会議の録音とは別の、独自のリストに保存されます。

## 字幕を開始する

1. **設定 → 字幕生成モデル**を開き、リアルタイム認識に対応したモデルを選びます。
2. **設定 → リアルタイム字幕**を開き、**追加**をクリックして**字幕を開始**を選びます。リストが空のときは、**字幕を開始**をクリックします。**ライブ字幕を開始**コマンドを実行するか、Enconvo のメニューバーのメニューで**ライブ字幕を開始**を選ぶこともできます。
3. **ライブ字幕を開始**ウィンドウで、音声ソース、字幕バーを開く場所、およびその画面を選びます。macOS から求められたら、マイクまたはシステムオーディオへのアクセスを許可します。
4. 追いかけたい音声を再生し、字幕が表示されることを確認します。
5. 終わったら字幕を停止し、**リアルタイム字幕**のリストから、保存されたセッションを開きます。

キーで字幕を開始または停止するには、**設定 → ショートカット**の**音声**で、リアルタイム字幕のホットキーを設定します。実行中の字幕は、同じホットキーで停止します。

## 字幕バーを配置する

字幕バーは、4 つの位置のいずれかに開きます。

| 位置 | 見た目 |
| --- | --- |
| **左側** | 画面の左端の縦の列です。デフォルトです。 |
| **右側** | 右端の縦の列です。 |
| **上部中央** | 上部の横の列で、広い字幕エリアの横にコントロールがあります。 |
| **下部中央** | 下部の横の列で、字幕が字幕スーパーのように並びます。 |

ディスプレイが複数ある場合は、その画面も選ぶか、**ポインタのある画面**のままにします。セッション中は、字幕バーを右クリックして、位置や画面を変更できます。字幕エリアの端をドラッグすると、どの位置でもサイズを変更できます。

## 字幕を翻訳する

音声プロバイダーによっては、元の言語と翻訳先の言語、または音声での翻訳に対応した、ライブ翻訳を提供します。これらは、選んだ字幕生成モデル自身の設定でオンにします。Enconvo Cloud Fast と Soniox は、**翻訳元**と **Translate To** を使います。すべての音声モデルがリアルタイム翻訳に対応しているわけではなく、ファイルの文字起こしに対応していても、ライブ字幕に対応しているとは限りません。

## セッションを見返す

保存されたセッションを開くと、その文字起こしと処理結果を確認できます。正確さが重要なときは、名前、数字、話者ラベルを、音声と照らし合わせて確認します。[辞書と話者](/ja/configuration/speech-assets)で、語彙と話者名を最新に保ちます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 字幕が表示されない | 音声ソース、入力レベル、キャプチャの権限、選択したモデルを確認します。 |
| 停止してからテキストが表示される | ストリーミングに対応したモデルを選びます。 |
| 言語が違う | モデルの設定で、認識言語または言語のヒントを設定します。 |
| 翻訳されない | モデルが翻訳に対応していることを確認し、翻訳先の言語を設定します。 |
| セッションに処理エラーが表示される | 保存された項目のエラーの詳細を読みます。音声がないと思い込まないでください。 |

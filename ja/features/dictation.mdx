音声入力を使うと、どんなアプリでも文字を入力している場所に話した言葉をそのままテキストとして入力できます。Voice Command では、話した内容を Agent に送り、音声で返答を受け取ったり、操作を代行させたりできます。双方向で会話しながらやり取りしたい場合は、[Live Talk](/ja/features/live-voice) を使用してください。

下の動画チュートリアルでは、5 分以内で音声入力の基本から応用までを一通り学べます。右 Command キーを長押しまたはタップして話す方法、画面上の名前を読み取らせる仕組み、辞書への名前登録、話した内容の整文や翻訳、そして Mac 上で動くモデルを含めた音声モデルの選び方を紹介しています。

## 始める前に

Enconvo が声を聞き取るには「マイク」権限が必要です。他のアプリに文字を入力するには「アクセシビリティ」権限が必要になる場合があります。詳しくは [権限](/ja/configuration/permissions) を参照してください。

## アプリに音声入力する

1. 任意のアプリで、文字を入力したいテキスト欄をクリックします。
2. 右側の **Command** キーを押したまま話します。音声入力が聞き取り中であることを示す小さなピルが表示されます。
3. 話し終えたらキーを離します。カーソル位置にテキストが入力されます。
4. 入力されたテキスト（特に人名、日付、数値）を確認します。

初期設定では、話している間ずっと右 Command キーを押し続ける方式です。1 回タップして好きなだけ話し続けたい場合は、**設定 → 音声入力 → 音声入力ホットキー** を開き、キーの押し方を変更してください。その場合は、もう一度ホットキーを押すかピル上のチェックマークをクリックして完了します。

中国語・日本語・タイ語を除き、音声入力は必要に応じて単語の前後に自動でスペースを補います。登録してあるスニペットの名前またはキーワードだけを単独で発音すると、その言葉の代わりにスニペットの本文が入力されます。

### 音声入力カードを使う

音声入力中にピルにカーソルを合わせるとカードに広がり、認識された言葉と各種コントロールが表示されます。カードからは、マイクの切り替え、音声入力の **下書き** への切り替え、**整文** オプションの選択、そして録音を止めずに **Return で入力して送信** や **リアルタイム文字起こし** のオン / オフを切り替えられます。録音を停止すると、カードに整文の処理状況が表示されます。

ピルを小さく保ちたい場合は **リアルタイム文字起こし** をオフにしてください。ピルにはボタンと波形だけが表示されます。

### Return で送信する

音声入力中に **Return** を押すと、その場で録音を停止してテキストを挿入し、チャットメッセージなどの送信まで 1 回の操作で行います。ホットキーまたはチェックマークで停止した場合はテキストの挿入のみを行います。この動作をオフにするには **設定 → 音声入力 → 挿入 → Return で入力して送信** をオフにします。

何も押さずに毎回自動で送信したい場合は、同じセクションにある **挿入後に送信** をオンにしてください。

### 一時停止と再開

タップで開始する設定にしている場合は、一時停止が使えます。ピルの音量レベル表示にカーソルを合わせて **一時停止** をクリックするか、**⌥P** を押します。マイクがオフになり、それまで話した言葉は保持されます。続けるときは **再開** をクリックするか同じキーをもう一度押し、完了するときは通常どおりホットキーまたはチェックマークを使います。キーを押し続ける方式では一時停止はありません。

キーを変更するには **設定 → 音声入力 → 一時停止 / 再開** を開きます。キーの組み合わせ、**Space** などの単一キー、またはタップ・ダブルタップ・長押しで反応する修飾キー 1 つを指定できます。長押し設定にすると、キーを離すまで一時停止します。

### ミーティング中は通話マイクをミュートにする

Zoom、Microsoft Teams、Google Meet、Mac 版 Telegram アプリの通話中、または Enconvo の [会議](/ja/features/video-conference) 中に音声入力を開始すると、通話側のマイクが自動でミュートになり、音声入力を終了または一時停止するとミュートが解除されます。専用アプリとブラウザタブの両方で動作します。自分で最初からミュートにしていた通話はミュートのまま保たれます。Enconvo が通話側のミュートボタンを見つけられない場合は、手動でミュートにするよう一度通知します。この機能をオフにするには **設定 → 音声入力 → 音声入力中は会議のマイクをミュートにする** をオフにします。

## 声で下書きを作成する

話した言葉をそのまま文字にするのではなく、書きたい内容の要点を話して下書きを作成させ、確認してから貼り付けることができます。

1. 返信を書く欄など、テキスト欄をクリックします。
2. 右の **Command** キーと **Shift** を同時に押したまま、「木曜の 14 時で大丈夫なことと、前日までに新しい画面を送ってほしいと伝えて」のように書きたい内容を話します。
3. キーを離します。下書きが生成されると同時に、音声入力ピルのすぐ上のパネルに表示されます。
4. **Return** を押すと貼り付けられ、**Esc** を押すと破棄されます。

別のアプリが前面に出てしまっても、**Return** は常に下書きを開始したアプリを前面に戻してから貼り付けます。パネルのヘッダーには対象アプリ名が表示されます。

音声入力の途中で下書きに切り替えることもできます。音声入力中（または音声入力キーを離した直後でも）、**Shift** を 1 回タップすると、それまで話した内容が下書きへの指示に変わります。

下書きパネルが開いている間に音声入力キーだけをもう一度押して修正点を話すと、その場で下書きをブラッシュアップできます。すでにテキストが入っている入力欄で再び下書き機能を使うと、既存の文章の続きを作成できます。

### 選択したテキストを書き直す・返信する

テキストを選択した状態で下書きを開始し、どう変えたいかを話すと、置換前に変更箇所を確認できます。

受信したメッセージやウェブページの一部など、直接編集できないテキストを選択していた場合、下書きはそのテキストを参考資料として新しい文章を作成し、元の入力欄に戻って **Return** を押したときに貼り付けます。これをオフにするには **選択したテキストを送信** をオフにします。

**アプリのコンテキストを送信** をオンにすると、今開いているアプリの内容を踏まえて下書きが書かれます。たとえばメールの返信画面では、返信相手のメッセージ内容から詳細を汲み取ります。

これらは **設定 → 音声入力 → 下書き** にあります:

| 設定 | 動作 |
| --- | --- |
| **下書き修飾キー** | 音声入力ホットキーと一緒に押して下書きを開始するキー、または音声入力中に単独でタップして切り替えるキー。初期設定は **Shift** です。 |
| **変更を差分として表示** | 下書きがテキストを編集するとき、追加・削除した語句をマーク表示します。オフにすると結果のみ表示します。 |
| **アプリのコンテキストを送信** | アプリのウィンドウタイトル、ウェブアドレス、表示中のテキストをモデルに渡します。初期設定はオンです。 |
| **スクリーンショットを含める** | アプリウィンドウの画像も送信します。「画面収録」権限と画像読み取り対応モデルが必要です。 |
| **選択したテキストを送信** | メッセージやウェブページなど、編集できない選択テキストを参考資料としてモデルに渡します。初期設定はオンです。 |
| **下書き用モデル** | 各下書きの作成と編集に使用するモデル。 |
| **下書き用プロンプト** | モデルが下書きを作成・編集する際の指示内容。 |

## 画面上の名前を活用する

**設定 → 音声入力 → 現在のアプリの内容を読み取る** をオンにしておくと、音声入力先のアプリの内容を読み取り、返信中のメッセージにある送信者の名前などを画面表示どおりの綴りで入力します。初期設定はオンです。

## 話しながら整文や翻訳を行う

録音ピル上の **整文** アイコンをクリックすると、話した言葉が入力される前に行う処理を選べます:

- **磨く**: フィラー（「えー」「あのー」など）や言い直しを取り除き、誤字や句読点を自然な文章に整えます。
- **翻訳**: 話した内容を回答言語に翻訳して入力します（すでにその言語で話している場合は英語に翻訳します）。
- **オンデバイス整文**: インターネット接続を使わず、Mac 上のモデルでテキストを整文します。対応する Mac でのみ表示され、初回のみモデルをダウンロードします。

**整文** チップには選択中のオプションのアイコンが表示され、カーソルを合わせると名前を確認できます。もう一度クリックすると次のオプションに切り替わり、**⌃⌥⌘I**（**音声入力中に切り替え**）でも切り替えられます。最初から選ばれるオプションを指定したり、名前・プロンプト・モデルを指定して独自オプションを追加したりするには、**設定 → 音声入力** の **整文** セクションを開きます。

翻訳およびスペル・文法の修正でも、「えー」「あのー」などのフィラーや言いよどみ、言い直しが取り除かれ、書き言葉のように整えられます。これらの **フィラーワードを削除** オプションは初期設定でオンになっています。

あるアプリ内で整文オプションを切り替えると、その変更はその音声入力に適用されます。カード上の **常に … を使用** をクリックすると、そのアプリのルールとして保存されます（**元に戻す** も可能）。すでにルールがあるアプリでは、カードに **これをルールにする** と **ルールに戻す** が表示されます。

### 翻訳スタイルを選ぶ

**翻訳** の表現トーンを変更するには、**設定 → 音声入力** の **整文** で **翻訳** 行のシェブロン（＞）をクリックし、**スタイル** を選びます:

- **標準**: 元の発言に忠実で正確な翻訳にします。
- **ネイティブ表現**: ネイティブスピーカーが書いたような自然な表現に言い換えます。
- **カスタム**: 自分で指定したスタイルに従って翻訳します。

選択したスタイルは **翻訳** 行にバッジとして表示されます。すでにターゲット言語で話した内容は、どのスタイルでももう一方の言語に翻訳されます。

## 特定のアプリ向けルールを設定する

**設定 → 音声入力 → アプリ別ルール** では、特定のアプリやウェブサイトごとに **整文**、**言語**、**Return キー** の動作を変えられます。ルールで翻訳を使う場合は、**翻訳先** を指定してそのアプリ内だけ別の言語に翻訳できます（たとえば普段の翻訳先は日本語のまま、特定のチャットアプリだけ英語に翻訳するなど）。

- Discord、Slack、Notion、Telegram、WhatsApp、ChatGPT、Claude、Linear、Figma、Teams に対するルールは、それぞれのウェブサイト版にも適用されます。
- 一番下の行には、ルールが設定されていないすべてのアプリに適用される既定値（音声入力設定の内容）が表示されます。
- **音声入力をよく使うアプリ** には、ルール追加の候補となるアプリが表示されます。

Enconvo 自身のメッセージ入力欄でマイクを使って音声入力する場合も、整文と言語については Enconvo のアプリ別ルールに従います。

<Note>
「磨く」「翻訳」、および独自に追加したオプションは AI モデルを使用するため、音声認識自体が Mac 上で実行された場合でも、認識後のテキストはそのモデルのプロバイダーへ送信されます。オンデバイス整文では Mac の外に出ません。
</Note>

## 音声モデルを選ぶ

1. **設定 → 音声入力** を開き、**音声モデル** の横にある **変更** をクリックします。
2. クラウドモデル、Mac 上で動作するローカルモデル、または自分の API キーを使うモデルから選択します。
3. **ローカル** をクリックするとオンデバイスモデルが表示されます。オフラインで動作し、音声データが Mac の外に出ません。
4. モデルを選択します。ローカルモデルは数秒で読み込まれます。

**設定 → 音声入力モデル** を直接開くこともできます。音声入力、Voice Command、Live Talk、会議の録音、ファイル文字起こし、リアルタイム字幕はそれぞれ個別に音声モデルを設定できます。バッチファイル向けのプロバイダーはリアルタイム入力に向かない場合があるため、[音声認識](/ja/ai/speech-recognition) と [プロバイダーカタログ](/ja/providers/catalog) も確認してください。

## 名前を教える

画面に表示されていない固有名詞は、たとえば「Lumyn」というプロジェクト名が「Lumen」と誤認識されることがあります。

1. **設定 → 辞書** を開き、**新しい単語** をクリックします。
2. 正しい単語を入力し、**誤認識されやすい音** に代わりに聞き取られた語句を入力します。
3. **保存** をクリックし、もう一度その名前を音声入力します。

カスタム語彙やプロバイダーごとの言語・ホットワード設定については [辞書と話者](/ja/configuration/speech-assets) を参照してください。

## 過去の音声入力を見直す

**設定 → 音声入力履歴** を開くと、過去に認識されたテキストを振り返ることができます。検索、コピー、録音の再生、再度の文字起こし、辞書への単語登録が行えます。

文字起こしできなかった音声入力、タイムアウトしたもの、途中で切れたものも録音データとともに履歴に残ります。**再試行** をクリックすると再度文字起こしできます。

## Voice Command で Agent と話す

Voice Command は Agent 向けのプッシュ・トゥ・トーク機能です。Dynamic Island 上と音声で回答し、アプリを開くなどの簡単な操作は即座に実行し、大きな依頼はタスクとして Agent に引き渡します。決まったフレーズにしか反応しないわけではなく、話した内容から意図をくみ取ります。

<Steps>
  <Step title="キーを押しながら話す">
    右の **Option** キーを押したまま、やってほしいことを話します。話した言葉は Dynamic Island に表示されます。キーを 1 回タップして開始することもできます。
  </Step>
  <Step title="送信する">
    キーを離します（タップで開始した場合はもう一度タップします）。
  </Step>
  <Step title="回答を受け取る">
    話した言葉の下に回答が表示され、**返答を読み上げる** がオンの場合は音声でも読み上げられます。開始されたタスクは、その Agent 自身のモデルとツールを使って実行されます。
  </Step>
</Steps>

回答を途中で止めるにはキーをもう一度押し、話している最中にキャンセルするには **Esc** を押します。Dynamic Island のマイクボタンでも操作できます。

設定は **設定 → Voice Command** で行います:

| 設定 | 動作 |
| --- | --- |
| **ホットキー** | 長押しまたはタップするキー。初期設定は右 Option キーです。 |
| **聞き取り** | 音声を認識する音声モデル（初期設定は **Enconvo Cloud Fast**）と、**マイク**・**言語**。個別に指定しない限り音声入力の設定を引き継ぎます。 |
| **思考** | 応答を生成するモデル。**チャットと同じ**（初期設定）では、チャットが Enconvo Cloud で動いているときは Enconvo Fast を、それ以外のときはそのチャットのプロバイダーの高速モデルを使うため、自分の API キー使用時に Enconvo Cloud ポイントを消費しません。開始されたタスクは、そのチャットで選ばれているモデルで実行されます。 |
| **回答** | **返答を読み上げる** のオン / オフと、読み上げに使う音声。オフにすると Dynamic Island への表示のみになります。 |
| **スクリーンショットを送信** | リクエストごとに現在開いている画面を送信し、見ている内容を Agent に共有します。Enconvo 自身のウィンドウは除外されます。 |
| **クイックアクション** | **管理** をクリックすると **設定 → クイックアクション** が開き、Voice Command と Live Talk が即座に実行できる操作の一覧確認や、オン / オフ切り替え、独自アクションの作成を行えます。 |

## 設定一覧

**設定 → 音声入力** には以下の設定があります:

| 設定 | 動作 |
| --- | --- |
| **音声入力ホットキー** | 音声入力を開始するキーと、長押し・タップのどちらで使うか。初期設定は長押しです。 |
| **効果音を再生** | 音声入力の開始時と終了時に短いチャイムを鳴らします。 |
| **マイク** | 録音に使用するマイクです。**テスト** をクリックして音声が入るか確認できます。接続されていない場合は、前回使用したマイクから録音します。 |
| **音声入力言語** | **デフォルト** は音声モデル自身の設定を維持し、**自動検出** は言語を自動判別します。 |
| **録音中は他のオーディオを無音にする** | 音声入力中に他のアプリの音声を一時停止またはミュートし、終了後に元に戻します。**無音化の方法** で一時停止・ミュート・両方から選べます。 |
| **音声入力中は会議のマイクをミュートにする** | 音声入力中、ミーティング通話側の自分のマイクをミュートにします。初期設定はオンです。 |
| **一時停止 / 再開** | 音声入力を一時停止・再開するキー。初期設定は **⌥P** です。 |
| **現在のアプリの内容を読み取る** | 使用中のアプリから固有名詞や用語を読み取り、「磨く」「翻訳」「下書き」にも文脈を渡します。 |
| **リアルタイム文字起こしを表示** | 話している最中に認識された言葉を表示します。オフにするとボタンと波形のみになります。 |
| **Return で入力して送信** | 音声入力中に **Return** を押すと停止・挿入・送信をまとめて行います。初期設定はオンです。 |
| **挿入後に送信** | Return を押さなくても、音声入力の終了と同時にテキストを送信します。初期設定はオフです。 |
| **音声入力したテキストをクリップボードにコピー** | 認識したテキストをクリップボードにもコピーします。 |
| **名前でスニペットを挿入** | スニペットの名前またはキーワードを単独で発音すると、その本文を挿入します。 |
| **音声入力中にアプリを切り替えた場合** | 音声入力が完了した時点で別のアプリが前面にあるとき、どこへ入力するか。初期設定は毎回確認します。 |
| **アプリ別ルール** | 特定のアプリやウェブサイトに対して、これらの設定を変更します。 |
| **音声入力履歴を保存** | 各音声入力の録音とテキストを、**履歴の保持期間** で指定した期間保存します。 |

| 問題 | 対処法 |
| --- | --- |
| マイクから音声が入らない | マイク名とともに無音である旨の通知が出た場合は、別のマイクを選ぶか、**設定 → 音声入力** の **マイク** 横にある **テスト** をクリックしてください。「マイク」権限も確認してください。 |
| テキストは認識されるが入力されない | 「アクセシビリティ」権限を確認し、テキスト欄をクリックしたうえで、そのアプリがペーストを受け付けるか確認してください。 |
| **Return** を押しても送信されない | **設定 → 音声入力 → 挿入** の **Return で入力して送信** と、対象アプリのアプリ別ルールにある **Return キー** 列を確認してください。 |
| 音声入力が失敗した、または途中で切れた | **設定 → 音声入力履歴** を開き、該当項目で **再試行** をクリックしてください。 |
| 認識後のテキストが意図と違う | 使用中の **整文** オプション、**音声入力言語**、および [辞書](/ja/configuration/speech-assets) を確認してください。 |
| 停止後に結果が出るまで遅い | バッチ型モデルは録音全体の完了を待ちます。ストリーミング対応モデルを選択してください。 |
| 別の機能がマイクを使用中 | 先に Live Talk または他の録音を終了してください。 |

音声入力は、どのアプリでも、入力中の場所に話した内容をテキストとして入力します。音声コマンドは、話した内容をエージェントに送ります。エージェントは声で答え、あなたの代わりに操作もできます。声で交互に会話したいときは、代わりに [Live Talk](/ja/features/live-voice) を使います。

下のビデオチュートリアルでは、音声入力を最初から最後まで 5 分以内で紹介しています。右の Command キーを押したまま、またはタップして話す方法、画面上の名前を読み取らせる方法、辞書に名前を覚えさせる方法、話した内容を整えたり翻訳したりする方法、そして Mac 上で動くモデルを含む音声モデルの選び方を扱います。

## はじめる前に

Enconvo があなたの声を聞くには、マイクの権限が必要です。ほかのアプリにテキストを入力するには、アクセシビリティの権限も必要になる場合があります。[権限](/ja/configuration/permissions)をご覧ください。

## アプリに音声入力する

1. どのアプリでも、テキストを入力したいテキストフィールドをクリックします。
2. 右の **Command** キーを押したまま話します。小さなピルに、音声入力が聞き取り中であることが表示されます。
3. 話し終えたらキーを離します。テキストがカーソル位置に入力されます。
4. 入力されたテキスト、特に名前、日付、数字を確認します。

デフォルトでは、話している間は右の Command キーを押したままにします。1 回タップして、好きなだけ話し続けたい場合は、**設定 → 音声入力 → 音声入力のホットキー** を開き、押し方を変更します。その場合は、もう一度ホットキーを押すか、ピルのチェックマークで終了します。

音声入力は、中国語、日本語、タイ語を除き、言葉の前後に必要なスペースを入れます。スニペットの名前やキーワードだけを話すと、その言葉の代わりにスニペットのテキストが入力されます。

### 音声入力カードを使う

音声入力中にピルにポインタを合わせると、ピルがカードに広がり、話した内容がコントロールの上に表示されます。カードでは、停止せずにマイクを切り替えたり、音声入力を**生成**に変えたり、**クリーンアップ**のオプションを選んだり、**Return で挿入して送信**と**ライブ文字起こし**をオンまたはオフにしたりできます。停止すると、カードにクリーンアップの進行状況が表示されます。

ピルを小さいままにするには、**ライブ文字起こし**をオフにします。ピルにはボタンと波形だけが表示されます。

### Return で送信する

音声入力中に **Return** を押すと、停止、テキストの挿入、送信をまとめて 1 回で行えます。チャットメッセージなどに便利です。ホットキーやチェックマークで停止した場合は、テキストが挿入されるだけです。オフにするには、**設定 → 音声入力 → 挿入 → Return で挿入して送信** を使います。

何も押さずにすべての音声入力を送信するには、同じセクションの**挿入後に送信**をオンにします。

### 一時停止と再開

タップして開始した場合は、一時停止できます。ピルのレベル表示にポインタを合わせて**一時停止**をクリックするか、**⌥P** を押します。マイクがオフになり、話した内容は残ります。続けるには**再開**をクリックするか、もう一度キーを押し、いつもどおりホットキーまたはチェックマークで終了します。キーを押したまま行う音声入力には、一時停止はありません。

キーを変更するには、**設定 → 音声入力 → 一時停止 / 再開** を開きます。キーの組み合わせ、**スペース**などの 1 つのキー、またはタップ、ダブルタップ、長押しする 1 つの修飾キーを指定できます。長押しの場合は、離すまで一時停止します。

### 会議中はミュートのままにする

Zoom、Microsoft Teams、Google Meet の通話、Mac 版 Telegram アプリの通話、Enconvo の[カンファレンス](/ja/features/video-conference)では、音声入力を開始すると通話内のマイクがミュートされ、終了または一時停止するとミュートが解除されます。アプリでもブラウザのタブでも動作します。自分でミュートした通話は、ミュートのままです。通話のミュートボタンが見つからない場合、Enconvo は 1 回だけ、そこで自分でミュートするよう知らせます。オフにするには、**設定 → 音声入力 → 音声入力中は会議のマイクをミュート** を使います。

## 声で下書きを書く

言葉そのものを話す代わりに、書いてほしい内容を話すと、音声入力が下書きを作ります。何かが入力される前に、その下書きを確認できます。

1. 書いている返信など、テキストフィールドをクリックします。
2. 右の **Command** キーと **Shift** を一緒に押したまま、テキストに書いてほしい内容を話します。たとえば「木曜 2 時で大丈夫だと伝えて、前日までに新しい画面を送ってほしいとお願いして」と話します。
3. キーを離します。下書きが作られるのに合わせて、音声入力ピルの上のパネルに表示されます。
4. **Return** を押して貼り付けるか、**Esc** を押して破棄します。

**Return** は常に、下書きを始めたアプリに貼り付けます。別のアプリが前面にある場合は、先にそのアプリを前面に戻します。パネルのヘッダーにそのアプリの名前が表示されます。

音声入力の途中で下書きに切り替えることもできます。音声入力中に **Shift** を 1 回タップすると、音声入力キーを離したあとでも、それまでに話した内容が下書きの指示になります。

下書きを開いたまま、音声入力キーだけを押して変更点を話すと、下書きを調整できます。テキストフィールドでもう一度「生成」を使うと、すでにあるテキストの続きを書けます。

### 選択したテキストを書き換える、またはそれに答える

下書きを始める前にテキストを選択し、どう変えたいかを話します。選択範囲を置き換える前に、生成が変更点を表示します。

受信したメッセージや Web ページの一部など、選択範囲を編集できない場合、生成はそれを参考として使い、新しいテキストを書きます。**Return** で、戻った先のフィールドに貼り付けられます。オフにするには、**選択したテキストを送信**を使います。

**アプリのコンテキストを送信**をオンにすると、下書きは使っているアプリの内容から書かれるため、作業内容に合ったものになります。たとえばメールに返信するときは、返信先のメッセージから詳細を拾えます。

これらは **設定 → 音声入力 → 生成** にあります。

| 設定 | 変わること |
| --- | --- |
| **下書きの修飾キー** | 下書きを始めるために音声入力のホットキーと一緒に押したままにするキー、または音声入力中に単独でタップするキーです。デフォルトは **Shift** です。 |
| **変更箇所を表示** | 下書きがテキストを編集するとき、追加された語と削除された語に印を付けます。オフにすると結果だけが表示されます。 |
| **アプリのコンテキストを送信** | アプリのウィンドウタイトル、Web アドレス、表示されているテキストをモデルに渡します。デフォルトでオンです。 |
| **スクリーンショットを含める** | アプリのウィンドウの画像も送ります。画面収録の権限と、画像を読み取れるモデルが必要です。 |
| **選択したテキストを送信** | 選択したものの編集できないテキスト(メッセージや Web ページなど)を、参考としてモデルに渡します。デフォルトでオンです。 |
| **下書きのモデル** | 各下書きを書いたり編集したりするモデルです。 |
| **下書きのプロンプト** | モデルが各下書きをどのように書いたり編集したりするかを指定します。 |

## 画面上の名前を使う

**設定 → 音声入力 → 現在のアプリの内容を読み取る**をオンにすると、音声入力は入力先のアプリを読み取り、返信しているメッセージの送信者名など、そこに表示されているとおりに名前を表記します。この設定はデフォルトでオンです。

## 話しながら整える、または翻訳する

録音ピルの**クリーンアップ**アイコンをクリックして、挿入する前に話した内容をどう処理するかを選びます。

- **推敲**は、えーとなどのフィラーや言い直しを取り除き、誤字や句読点を修正します。あなた自身の言葉づかいはそのままです。
- **翻訳**は、話した内容を応答言語で入力します。すでに応答言語を話している場合は、英語で入力します。
- **デバイス上でクリーンアップ**は、Mac 上のモデルを使い、オフラインでテキストを整えます。Mac が実行できる場合に表示され、モデルは初回に 1 回ダウンロードされます。

**クリーンアップ**チップには、選んだオプションのアイコンが表示されます。ポインタを合わせると名前が表示されます。もう一度クリックすると次のオプションに移り、**⌃⌥⌘I**(**音声入力中に切り替え**)でも切り替えられます。最初に選択されるオプションを選んだり、名前、プロンプト、モデルを指定して独自のオプションを追加したりするには、**設定 → 音声入力**を開き、**クリーンアップ**セクションを使います。

翻訳と「スペルと文法を修正」は、えー、あー、言いよどみ、言い直しも取り除くため、結果は書き言葉のように読めます。これらの**フィラーワードを削除**オプションは、デフォルトでオンです。

アプリでクリーンアップを切り替えると、その変更はその音声入力にだけ適用されます。その選択をそのアプリで維持するには、カードの**常に … を使用**をクリックします。**元に戻す**も表示されます。すでにルールがあるアプリでは、カードに**ルールにする**と**ルールに戻す**が表示されます。

### 翻訳スタイルを選ぶ

**翻訳**が結果をどう言い表すかを変えるには、**設定 → 音声入力**を開き、**クリーンアップ**に進んで、**翻訳**の行のシェブロンをクリックします。続いて**スタイル**を選びます。

- **標準**は、正確で、話した内容に近い訳です。
- **ネイティブ風**は、ネイティブスピーカーが書いたかのように、自由に言い換えます。
- **カスタム**は、あなたが説明したスタイルに従います。

選んだスタイルは、**翻訳**の行にバッジとして表示されます。すでに翻訳先の言語で話したテキストは、スタイルにかかわらず、もう一方の言語に翻訳されます。

## アプリ別にルールを設定する

**設定 → 音声入力 → アプリ別ルール**では、1 つのアプリまたは Web サイトについて、音声入力の**クリーンアップ**、**言語**、**Return キー**を変更できます。ルールで翻訳を使う場合は、**翻訳先**を選ぶと、そのアプリだけ別の言語に翻訳できます。たとえば、あるチャットアプリでは英語に翻訳し、ほかのすべての場所では、翻訳はいつもの言語のままにできます。

- Discord、Slack、Notion、Telegram、WhatsApp、ChatGPT、Claude、Linear、Figma、Teams のルールは、その Web サイトにも適用されます。
- 最後の行には、ルールのないすべてのアプリが使う設定が表示されます。これは音声入力の設定から決まります。
- **よく音声入力するアプリ**では、追加するアプリの候補が表示されます。

Enconvo 自身のメッセージ欄でマイクを使って音声入力する場合は、クリーンアップと言語について Enconvo のアプリ別ルールに従います。

<Note>
推敲、翻訳、追加したオプションは AI モデルを使うため、認識が Mac 上で実行された場合でも、認識されたテキストはそのモデルのプロバイダに送られます。デバイス上でクリーンアップなら、テキストは Mac の外に出ません。
</Note>

## 音声モデルを選ぶ

1. **設定 → 音声入力**を開き、**音声モデル**の横の**変更**をクリックします。
2. クラウドモデル、Mac 上で動くモデル、自分の API キーを使うモデルから選びます。
3. **ローカル**をクリックすると、デバイス上のモデルが表示されます。オフラインで動作し、音声は Mac の外に出ません。
4. モデルを選択します。ローカルモデルは数秒で読み込まれます。

**設定 → 音声入力モデル**を直接開くこともできます。音声入力、音声コマンド、Live Talk、会議の録音、ファイルの文字起こし、ライブキャプションには、それぞれ独自の音声モデル設定があります。ファイルの一括処理に向いたプロバイダが、ストリーミング入力にも最適とは限りません。[音声認識](/ja/ai/speech-recognition)と[プロバイダカタログ](/ja/providers/catalog)をご覧ください。

## 名前を覚えさせる

画面にない名前は、たとえば「Lumyn」というプロジェクト名が「Lumen」と認識されるように、間違って入力されることがあります。

1. **設定 → 辞書**を開き、**新しい単語**をクリックします。
2. 正しい単語を入力し、**聞き間違い**に、音声入力が代わりに聞き取った言葉を入力します。
3. **保存**をクリックして、もう一度その名前を音声入力します。

カスタム語彙、およびプロバイダの言語とホットワードの設定については、[辞書と話者](/ja/configuration/speech-assets)をご覧ください。

## 過去の音声入力を確認する

**設定 → 音声入力の履歴**を開くと、過去に認識されたテキストを見返せます。ここでは、検索、コピー、録音の再生、音声入力の再文字起こし、辞書への単語の追加ができます。

文字起こしできなかった音声入力、時間がかかりすぎた音声入力、途中で切れた音声入力は、録音とともに履歴に残ります。**再試行**をクリックすると、もう一度文字起こしします。

## 音声コマンドでエージェントに話しかける

音声コマンドは、エージェント向けのプッシュ・トゥ・トークです。Dynamic Island と音声で答え、アプリを開くといった簡単なことはその場で行い、大きな依頼はタスクとしてエージェントに引き渡します。決まったフレーズに一致させるのではなく、あなたが何を頼んだのかを判断します。

<Steps>
  <Step title="キーを押したまま話す">
    右の **Option** キーを押したまま、必要なことを話します。話した内容が Dynamic Island に表示されます。キーを 1 回タップして開始することもできます。
  </Step>
  <Step title="送信する">
    キーを離します。タップして開始した場合は、もう一度タップします。
  </Step>
  <Step title="答えを受け取る">
    答えは話した内容の下に表示され、**返答を読み上げる**がオンの間は読み上げられます。開始されたタスクは、そのエージェント自身のモデルとツールで実行されます。
  </Step>
</Steps>

もう一度キーを押すと答えが止まり、話している途中なら **Esc** を押すとキャンセルできます。Dynamic Island のマイクボタンも使えます。

**設定 → 音声コマンド**で設定します。

| 設定 | 変わること |
| --- | --- |
| **ホットキー** | 押したままにする、またはタップするキーです。デフォルトは右の Option キーです。 |
| **聞き取り** | あなたの声を聞き取る音声モデル(デフォルトは **Enconvo Cloud Fast**)、および**マイク**と**言語**です。独自に選ばない限り、音声入力の設定に従います。 |
| **思考** | あなたに答えるモデルです。**チャットと同じ**(デフォルト)は、チャットが Enconvo Cloud で動いている場合は Enconvo Fast を使い、それ以外の場合はチャット自身のプロバイダの高速モデルを使います。そのため、自分の API キーを使っているときは Enconvo Cloud のポイントを消費しません。開始されたタスクは、そのチャットで選ばれているモデルで実行されます。 |
| **回答** | **返答を読み上げる**と、答えに使う音声です。**返答を読み上げる**をオフにすると、答えは Dynamic Island にだけ表示されます。 |
| **スクリーンショットを送る** | 各リクエストと一緒に、表示中の画面を送ります。エージェントはあなたと同じものを見られます。Enconvo のウィンドウは除外されます。 |
| **クイックアクション** | **管理**を押すと**設定 → クイックアクション**が開きます。音声コマンドと Live Talk がその場で行うことの一覧で、オフにしたり、独自のものを作ったりできます。 |

## 設定

これらは **設定 → 音声入力** にあります。

| 設定 | 変わること |
| --- | --- |
| **音声入力のホットキー** | 音声入力を開始するキー、および押したままにするかタップするかです。デフォルトは押したままにします。 |
| **効果音を再生** | 音声入力の開始時と終了時に短いチャイムを鳴らします。 |
| **マイク** | 音声入力が録音に使うマイクです。**テスト**をクリックすると、声が聞こえているか確認できます。接続されていない場合は、以前に使ったマイクで録音します。 |
| **音声入力の言語** | **デフォルト**は音声モデル自身の設定のままにし、**自動検出**は言語を認識させます。 |
| **録音中はほかの音を止める** | 音声入力中にほかのアプリを一時停止またはミュートし、終了すると音を戻します。**消音の方法**で、一時停止、ミュート、またはその両方を選びます。 |
| **音声入力中は会議のマイクをミュート** | 音声入力中に、会議の通話であなたをミュートします。デフォルトでオンです。 |
| **一時停止 / 再開** | 音声入力を一時停止、再開するキーです。デフォルトは **⌥P** です。 |
| **現在のアプリの内容を読み取る** | 使っているアプリを読み取って名前や用語を正しく表記し、推敲、翻訳、生成にコンテキストを与えます。 |
| **ライブ文字起こしを表示** | 話している最中に内容を表示します。オフにすると、コントロールと波形だけが残ります。 |
| **Return で挿入して送信** | 音声入力中に **Return** を押すと、停止、テキストの挿入、送信を行います。デフォルトでオンです。 |
| **挿入後に送信** | Return を押さずに、音声入力が終わったときにテキストを送信します。デフォルトでオフです。 |
| **入力したテキストをクリップボードにコピー** | 認識されたテキストもコピーします。 |
| **名前でスニペットを挿入** | スニペットの名前やキーワードだけを話すと、そのテキストが入力されます。 |
| **音声入力中にアプリを切り替えたとき** | 音声入力が終わった時点で別のアプリが前面にある場合の、テキストの送り先です。デフォルトでは確認します。 |
| **アプリ別ルール** | これらの手順のいずれかを、特定のアプリや Web サイトごとに変更します。 |
| **音声入力の履歴を保存** | **履歴の保存期間**で指定した期間、各音声入力の録音とテキストを保持します。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| マイクから入力されない | マイクの名前が表示され、音が送られていないと通知された場合は、別のマイクを選ぶか、**設定 → 音声入力**の**マイク**の横にある**テスト**をクリックします。マイクの権限も確認してください。 |
| テキストは表示されるが挿入されない | アクセシビリティの権限を確認し、テキストフィールドをクリックして、アプリが貼り付けを受け付けることを確認します。 |
| **Return** で送信されない | **設定 → 音声入力 → 挿入**の**Return で挿入して送信**と、そのアプリのルールの **Return キー**列を確認します。 |
| 音声入力が失敗した、または途中で切れた | **設定 → 音声入力の履歴**を開き、その項目の**再試行**をクリックします。 |
| 認識後のテキストが違う | 使用中の**クリーンアップ**オプション、**音声入力の言語**、[辞書](/ja/configuration/speech-assets)を確認します。 |
| 停止後の結果が遅い | 一括処理のモデルは、録音全体を待ちます。ストリーミングに対応したモデルを選んでください。 |
| ほかの機能がマイクを使っている | 先に Live Talk または録音を終了してください。 |

アーティファクトは、エージェントがあなたのために作って残しておくものです。ドキュメント、スライド、デザインキャンバス、ダッシュボード、モーション、Web ページ、図、コードなどです。チャットの横のパネルで開き、すべてのバージョンを保持し、チャットが終わったあとも **アーティファクト** ライブラリに残ります。結果にあとで戻る、編集する、発表する、共有する場合に使ってください。

生成した画像、動画、音声は、代わりに[メディア](/ja/features/media)に保存されます。

## 新しいチャットからアーティファクトを始める

新しいチャットでは、メッセージ欄の下に **何かを作る** の行が表示され、種類ごとのピルが並びます。**スライド**、**ドキュメント**、**デザイン**、**モーション**、**ダッシュボード**、**Web ページ**、**画像**、**動画** です。各ピルには短い説明が付いているので、**モーション**（コードによるアニメーション）と **動画**（AI の映像）を見分けられます。

1. ピルをクリックします。まだ何も送信されません。メッセージ欄がその種類に切り替わります。
2. 始め方を選びます。
   - 3 つの例のどれかをクリックして、メッセージ欄に入力します。
   - **空のスライド**、**空のドキュメント**、**空のデザイン** などをクリックして、空のものをチャットの横で開きます。
   - **.pptx を開く**、**.docx を開く**、**スプレッドシートを開く** をクリックして、ファイルから始めます。
   - **あなたのスライド**、**あなたのドキュメント** などをクリックして、すでにあるものを開きます。
3. 作りたいものを説明して送信します。

アーティファクトはチャットの横で開き、エージェントの作業に合わせて内容が埋まっていきます。どのチャットでも、頼むだけで作れます。ティザー、解説、ウォークスルー動画を頼むと[モーション](/ja/features/motion)が作られ、追跡したい数値を頼むと[ダッシュボード](/ja/features/dashboards)が作られます。

**画像** と **動画** には、最近の画像やクリップと、**メディアを開く** リンクが表示されます。[メディア](/ja/features/media)を参照してください。

## アーティファクトを探す

チャットウィンドウのサイドバーで **アーティファクト** をクリックします。ライブラリは、最近変更したものが先頭のサムネイルのグリッドで開きます。

- 上部で **グリッド表示** と **リスト表示** を切り替えます。
- 種類で絞り込みます。**すべて**、**ページ**、**デザイン**、**ダッシュボード**、**スライド**、**モーション**、**書類**、**図**、**コード** があります。
- **アーティファクトを検索** に入力して、タイトルから探します。文字種や大文字小文字は問いません。
- **新規** をクリックして、任意の種類の空のものを始めます。
- **インポート** をクリックして、ドキュメントをドキュメントとして、またはデザインやダッシュボードの zip 化されたプロジェクトフォルダを取り込みます。

項目を右クリックするか、**⋯** をクリックすると、**開く**、**名前を変更…**、**リンクをコピー**、**作成したチャットを開く**、複数の **選択**、**削除** ができます。複数を一度に選ぶには、⌘ キーまたは ⇧ キーを押しながらクリックし、まとめて削除します。削除すると、すべてのバージョンと、そのアーティファクトが保存したものがすべて削除されます。作成したチャットは残ります。続けて表示される通知の **元に戻す** をクリックすると、復元できます。

何も書き込まなかった空のアーティファクトは保存されません。閉じると破棄されます。

## 以前のバージョンに戻る

エージェントが行うすべての変更と、あなたが保存するすべての編集は、新しいバージョンになります。

1. アーティファクトのヘッダーで、バージョン番号（たとえば **v4**）をクリックします。
2. **バージョン** の下から、目的のものを選びます。
3. **復元** をクリックするか、そのままにするには **現在のバージョンに戻る** をクリックします。復元は新しいバージョンとして保存されるため、何も失われません。

チャットで頼むこともできます。「色を変更する前の状態にスライドを戻して」。エージェントは、そのバージョンのデザイン、スライド、ダッシュボードを復元し、それ以外は保持します。

変更を頼むと、エージェントは、1 枚のスライド、1 つのグラフ、1 つのアートボードなど、指定された部分だけを編集し、それ以外はそのままにします。

## アーティファクトを共有する

ドキュメント、デザイン、スライド、ダッシュボード、モーションは、ユーザーやチームと共有できます。Enconvo アカウントにサインインしている必要があります。

1. アーティファクトを開き、**共有** をクリックします。
2. **メールアドレスでユーザーを追加** の下にメールアドレスを入力し、**閲覧可能**、**コメント可能**、**編集可能** から選んで、**共有** をクリックします。
3. チームと共有するには、**チームのアクセス** を設定します。Enconvo にサインインしている全員が開けるようにするには、**一般的なアクセス** を **リンクを知っている全員** にして、**リンクをコピー** をクリックします。
4. **完了** をクリックします。

共有すると、アーティファクトは Enconvo Cloud に移動し、追加したユーザーは自分の Mac で開いて、新しいバージョンのたびに内容を確認できます。`@Enconvo` で始まるコメントには、Enconvo が回答します。

## ページを Web サイトとして公開する

Web ページのアーティファクトは、Enconvo Cloud 上の専用アドレス `name.site.enconvo.com` でオンラインに公開できます。公開は、Enconvo アカウントに含まれています。

1. ページを開き、ヘッダーの **公開** をクリックします。
2. **サイト名** に、アドレスに使う名前を入力します。小文字の英字、数字、ハイフンで 3〜40 文字です。
3. **閲覧できる人** で、**リンクを知っている全員** を選ぶか、**パスワード** を選んで 4 文字以上のパスワードを入力します。
4. **公開** をクリックします。**サイトを公開しました** と表示されたら、**開く** をクリックして確認します。

公開後は、ボタンに **公開済み** と表示されます。ページを変更すると **更新** と表示されます。それをクリックして、もう一度 **更新** をクリックすると、最新のバージョンがオンラインになります。同じパネルで、**リンクをコピー**、以前に公開したバージョンに **戻す**、サイトをオフラインにする **公開を取り消す** ができます。公開を取り消すと、全員がリンクを開けなくなります。

エージェントにページのオンライン共有を頼むこともでき、エージェントがページまたはサイトのフォルダを公開します。

## スマートフォンでアーティファクトを開く

スライド、ダッシュボード、モーションは、iPhone と Android のアプリでも開けます。チャットまたは **アーティファクト** ライブラリから開いて、コメント、`@Enconvo` への質問、共有、書き出し、発表ができます。

## ドキュメントをスキルとして使う

ドキュメントは、エージェントが従うスキルとして使えます。ドキュメントを開き、**スキルとして使う…** を選びます。ドキュメントが他の人のものである場合、オンにできるのはあなただけで、Enconvo は、所有者がエージェントの従う内容をあとから変更できることを知らせます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 画像や動画がライブラリにない | 画像、動画、音声は[メディア](/ja/features/media)に保存されます |
| **共有** でサインインを求められる | Mac で Enconvo にサインインしてから、もう一度共有してください |
| 共有されたドキュメントが開かなくなった | 所有者があなたのアクセス権を削除したか、あなたがライブラリから外しました |
| エージェントが頼んだ以上に書き換えた | 変更する部分を指定するか、その前のバージョンを復元してください |
| 公開したページに古いバージョンが表示される | ページのヘッダーで **更新** をクリックし、もう一度 **更新** をクリックしてください |

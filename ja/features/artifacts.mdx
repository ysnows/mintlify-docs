アーティファクトは、ドキュメント、スライド資料、デザインキャンバス、ダッシュボード、モーション、ウェブページ、図表、コードなど、Agent が作成して後から使えるように残す成果物です。チャットの横のパネルに開き、すべてのバージョンを保持し、チャット終了後も **アーティファクト** ライブラリに残ります。結果に立ち返って編集したり、発表したり、共有したりするときに活用してください。

生成した画像、動画、音声ファイルは、代わりに[メディア](/ja/features/media)に保存されます。

## 新しいチャットからアーティファクトを始める

新しいチャットでは、メッセージ入力欄の下に **何かを作る** の行が表示され、種類ごとのボタン（**スライド**、**ドキュメント**、**デザイン**、**モーション**、**ダッシュボード**、**ウェブページ**、**画像**、**動画**）が並びます。各ボタンには短い説明が付いているため、コードで動かす **モーション** と AI 映像の **動画** を迷わず選べます。

1. ボタンを 1 つクリックします。まだ送信はされず、メッセージ入力欄がその種類に切り替わります。
2. 始め方を選びます。
   - 3 つの例のいずれかをクリックしてメッセージ入力欄に入力する。
   - **空白のスライド**、**空白のドキュメント**、**空白のデザイン** などをクリックし、チャットの横に空のキャンバスを開く。
   - **.pptx を開く**、**.docx を開く**、**スプレッドシートを開く** をクリックし、既存ファイルを元にする。
   - **あなたのスライド**、**あなたのドキュメント** などをクリックし、すでに作成したものを開く。
3. 作りたい内容を書いて送信します。

チャットの横にアーティファクトが開き、Agent の作業に合わせて内容が書き込まれていきます。どのチャットからでも直接頼むことができます。たとえばティーザー、解説動画、ウォークスルー動画の依頼は[モーション](/ja/features/motion)に、継続的に追いたい数値の依頼は[ダッシュボード](/ja/features/dashboards)になります。

**画像** と **動画** では代わりに最近の画像やクリップが表示され、**メディアを開く** リンクが表示されます。詳しくは[メディア](/ja/features/media)をご覧ください。

## アーティファクトを探す

チャットウィンドウのサイドバーで **アーティファクト** をクリックすると、更新日時の新しい順でサムネイルのグリッドが開きます。

- 上部で **グリッド表示** と **リスト表示** を切り替えられます。
- **すべて**、**ページ**、**デザイン**、**ダッシュボード**、**スライド**、**モーション**、**ドキュメント**、**図表**、**コード** で種類別に絞り込めます。
- **アーティファクトを検索** に入力すると、文字種や大文字・小文字を問わずタイトルで検索できます。
- **新規** をクリックすると、どの種類でも空の状態から始められます。
- **インポート** をクリックすると、ドキュメントとして文書を取り込んだり、デザインやダッシュボードの圧縮済みプロジェクトフォルダを読み込んだりできます。

項目を右クリックするか **⋯** をクリックすると、**開く**、**名前を変更…**、**リンクをコピー**、**作成元のチャットを開く**、複数項目の **選択**、**削除** ができます。複数を一度に選ぶには、⌘ クリックまたは ⇧ クリックしてからまとめて削除します。削除すると、すべてのバージョンとそのアーティファクトに保存されたすべてのデータが消去されます（作成元のチャット自体は残ります）。直後の通知で **元に戻す** をクリックすると復元できます。

一度も内容を書き込まなかった空のアーティファクトは保存されず、閉じた時点で破棄されます。

## 以前のバージョンに戻す

Agent が変更を加えるたび、およびご自身で編集を保存するたびに、新しいバージョンが作られます。

1. アーティファクトのヘッダーにあるバージョン番号（例：**v4**）をクリックします。
2. **バージョン** の一覧から戻したいものを選びます。
3. **復元** をクリックするか、そのままにする場合は **現在のバージョンに戻る** をクリックします。復元も新しいバージョンとして保存されるため、何も失われません。

チャットで「色を変更する前の状態にスライドを戻して」と頼むこともできます。Agent がデザイン、スライド、ダッシュボードの該当バージョンを復元し、それ以外の要素は保ちます。

変更を依頼したとき、Agent は「この 1 枚のスライド」「このチャート」「このアートボード」など指定された部分だけを編集し、ほかはそのまま残します。

## アーティファクトを共有する

ドキュメント、デザイン、スライド、ダッシュボード、モーションは、ほかの人やチームと共有できます。Enconvo アカウントへのサインインが必要です。

1. アーティファクトを開き、**共有** をクリックします。
2. **メールアドレスでユーザーを追加** にアドレスを入力し、**閲覧可能**、**コメント可能**、または **編集可能** を選んで **共有** をクリックします。
3. チームに共有するには **チームのアクセス** を設定します。Enconvo にサインインしている誰にでも開けるようにするには、**一般的なアクセス** を **リンクを知っている全員** にし、**リンクをコピー** をクリックします。
4. **完了** をクリックします。

共有するとアーティファクトが Enconvo Cloud へ移行し、追加した相手は各自の Mac から開いて最新バージョンをリアルタイムに参照できるようになります。`@Enconvo` で始まるコメントを付けると Enconvo が回答します。

## ページをウェブサイトとして公開する

ウェブページのアーティファクトは、Enconvo Cloud 上の独自アドレス `name.site.enconvo.com` にオンライン公開できます。公開機能は Enconvo アカウントに含まれています。

1. ページを開き、ヘッダーの **公開** をクリックします。
2. **サイト名** にアドレス用の名前を入力します（小文字の英字、数字、ハイフンで 3〜40 文字）。
3. **閲覧できるユーザー** で **リンクを知っている全員**、または **パスワード**（4 文字以上を設定）を選択します。
4. **公開** をクリックします。**サイトが公開されました** と表示されたら **開く** をクリックして確認します。

公開後はボタンの表示が **公開済み** になります。ページに変更を加えるとボタンが **更新** に変わるので、クリックしてさらに **更新** を押すと最新版が反映されます。同じパネルから **リンクをコピー**、以前公開したバージョンへ **戻す**、または **公開を取り消す**（リンクを無効にしてサイトを非公開にする）ことができます。

Agent にページをオンラインで共有するよう頼むと、ページまたはサイトフォルダを公開してもらうこともできます。

## スマートフォンでアーティファクトを開く

スライド、ダッシュボード、モーションは iPhone と Android のアプリでも開けます。チャットまたは **アーティファクト** ライブラリから開き、コメント、`@Enconvo` への質問、共有、書き出し、プレゼンテーションを行えます。

## ドキュメントをスキルとして使う

ドキュメントを Agent が従うスキルとして利用できます。ドキュメントを開いて **スキルとして使う…** を選択してください。ほかの人が所有するドキュメントの場合はご自身でのみ有効化でき、所有者が今後も内容を書き換えられる可能性がある旨の注意が表示されます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 画像や動画がライブラリに見つからない | 画像、動画、音声は[メディア](/ja/features/media)に保存されています |
| **共有** でサインインを求められる | Mac で Enconvo にサインインしてから、もう一度共有してください |
| 共有ドキュメントが開けなくなった | 所有者がアクセス権を削除したか、ご自身でライブラリから外しています |
| Agent が依頼した以上の範囲を書き換えてしまった | 変更したい箇所を具体的に指定するか、変更前のバージョンを復元してください |
| 公開したページに古いバージョンが表示される | ページのヘッダーにある **更新** をクリックし、続いて **更新** をクリックしてください |

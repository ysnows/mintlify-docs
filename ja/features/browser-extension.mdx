title: "ブラウザ拡張機能"
description: "Enconvo Companion 拡張機能をインストールして、サインイン状態・Cookie・拡張機能を維持したまま実際のブラウザを Enconvo に操作させます。"
---

Enconvo ブラウザ拡張機能「Enconvo Companion」を導入すると、サインイン済みのブラウザ状態が必要なタスクで Enconvo がお使いの実際のブラウザを操作できるようになります。LinkedIn、Gmail、Salesforce、管理ダッシュボード、社内ツールなど、Cookie やブラウザ拡張機能が重要なサイトで活用してください。設定画面上では**ブラウザ連携アプリ**（Browser Companion）と呼ばれています。

公開ページ、ローカルのプレビュー、個人のブラウザプロファイルに触れさせたくないワークフローには、代わりに分離されたブラウザ自動化機能を使用してください。

## 拡張機能をセットアップする

<Steps>
  <Step title="拡張機能をインストールする">
    **設定 → Browser Use** を開き、**ブラウザ拡張機能**内の **ブラウザ連携アプリをインストール** をクリックします。拡張機能の Chrome ウェブストアページが開きます。お使いのブラウザの拡張機能ストアから直接インストールすることも可能です。Chrome、Edge、Brave、Arc、Vivaldi、Opera、Firefox に対応しています。[Computer Use の動画チュートリアル](https://youtu.be/0CbQA7d8zqU?t=33)では Chrome へのインストール手順を確認できます。
  </Step>
  <Step title="ブラウザを開いたままにする">
    拡張機能は `ws://localhost:11225` 経由で Enconvo に自動接続します。
  </Step>
  <Step title="ポップアップを確認する">
    拡張機能のアイコンをクリックします。ポップアップに **Connected Chrome**、**Connected Edge**、**Connected Firefox** など、使用中のブラウザ名が表示されます。
  </Step>
  <Step title="ブラウザタスクを開始する">
    ブラウザ上のページの読み取り、クリック、入力、スクリーンショット撮影、タブ管理などを Enconvo に指示します。
  </Step>
</Steps>

## ポップアップの見方

| 項目 | 表示内容 |
| --- | --- |
| 接続状態 | このブラウザの拡張機能が Enconvo に接続されているかどうか |
| 現在のブラウザ | この拡張機能が接続しているブラウザ名（Chrome、Edge、Brave、Firefox など） |
| 接続中のブラウザ | 現在 Enconvo に接続されている他のブラウザの拡張機能 |
| バージョン | インストールされている拡張機能のバージョン |
| **Learn more** | このドキュメントページを開きます |

ポップアップに未接続（disconnected）と表示される場合は、Enconvo を再起動してブラウザを再読み込みしてください。それでも接続されない場合は、拡張機能を一度オフにしてから再度オンにします。

## 複数のブラウザを使い分ける

Enconvo は複数のブラウザに同時接続できます。タスク内でブラウザが指定されていない場合、Enconvo は次の優先順でブラウザを選びます。

1. Browser Use の設定で選んだ **デフォルトブラウザ**（**設定 → Browser Use** を開き、**⋯** メニュー内の **設定** から指定）。
2. Mac のデフォルトブラウザ。
3. 接続中のブラウザの中で直近に最も新しく使用したもの。

自動化 API から明示的にブラウザを指定することもできます。

```json
{
  "browser": "edge"
}
```

主な指定値として `chrome`、`google_chrome`、`edge`、`brave_browser`、`arc`、`vivaldi`、`opera`、`firefox` があります。

## 同じタブで作業を続ける

ブラウザタスクが開始されると、Enconvo は作業対象のブラウザとタブを記録します。その後ページがポップアップを開いたり、再読み込みされたり、フォーカスが外れたりしても、可能な限り同じタブで後続のステップを続けます。

安定して動作させるためのコツ：

- タスクが完了するまでそのタブを閉じないでください。
- 複数のブラウザを接続している場合は、使用するブラウザ名を指定してください。
- いま目の前に表示しているページを操作させたいときは、「現在のタブを使って」と伝えてください。
- ページ遷移後やフォーム送信後は、ページの状態を改めて読み直すよう指示してください。

## ウェブサイトへのアクセスと安全性

ウェブページには、あなたが書いていない悪意ある指示文が含まれている場合があります。重要なページでは、Enconvo に処理を続行させる前にサイトと操作内容を確認してください。

拡張機能は、タスクに必要な場合にページ内容の読み取り、クリック、入力、スクリーンショット撮影、タブの確認、Cookie の読み取りを行うブラウザ権限を使用します。ログイン済みのページ、閲覧履歴、社内ツールなどは機密データとして慎重に扱ってください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| ポップアップに未接続と表示される | Enconvo が起動していることを確認し、ブラウザを再起動してから拡張機能を一度オフにしてオンにし直してください。`localhost:11225` をブロックする設定がないかも確認してください。 |
| 意図しない別のブラウザが操作される | Browser Use の設定で **デフォルトブラウザ** を設定するか、ブラウザ操作時に `edge`、`chrome`、`firefox` などのブラウザ名を指定してください。 |
| 接続済みだがページを操作できない | `chrome://` などのブラウザ内部ページは操作できません。厳格な Content Security Policy が設定されたページ、閉じた Shadow DOM、ブラウザの権限確認プロンプトも操作を妨げる場合があります。 |
| ファイルのアップロードが機能しない | ブラウザ内の拡張機能詳細ページで、ファイルの URL へのアクセスを許可してください。ローカルファイルをアップロードするタスクや file URL を開くタスクではこの設定が必要です。 |

---
title: "ブラウザ拡張機能"
description: "Enconvo Companion 拡張機能をインストールすると、サインイン状態、Cookie、拡張機能がそろった実際のブラウザで Enconvo が作業できます。"
---

Enconvo のブラウザ拡張機能 Enconvo Companion を使うと、サインイン済みのブラウザの状態が必要なタスクで、Enconvo が実際のブラウザを操作できます。LinkedIn、Gmail、Salesforce、ダッシュボード、社内ツールなど、Cookie やブラウザ拡張機能が重要なサイトで使ってください。設定では **ブラウザコンパニオン** と呼ばれています。

公開ページ、ローカルのプレビュー、個人のブラウザプロファイルに触れさせたくないワークフローには、代わりに分離されたブラウザ自動化を使います。

## 拡張機能をセットアップする

<Steps>
  <Step title="拡張機能をインストールする">
    **設定 → ブラウザを使用** を開き、**ブラウザ拡張機能** の **ブラウザ連携アプリをインストール** をクリックします。拡張機能の Chrome ウェブストアのページが開きます。ブラウザの拡張機能ストアからインストールすることもできます。Chrome、Edge、Brave、Arc、Vivaldi、Opera、Firefox で動作します。[コンピューター操作のビデオチュートリアル](https://youtu.be/0CbQA7d8zqU?t=33)で、Chrome へのインストールを確認できます。
  </Step>
  <Step title="ブラウザを開いたままにする">
    拡張機能は `ws://localhost:11225` を通じて、自動的に Enconvo に接続します。
  </Step>
  <Step title="ポップアップを確認する">
    拡張機能のアイコンをクリックします。ポップアップに **Connected Chrome**、**Connected Edge**、**Connected Firefox**、または使用中のブラウザ名が表示されます。
  </Step>
  <Step title="ブラウザのタスクを始める">
    Enconvo に、ブラウザでの読み取り、クリック、入力、スクリーンショットの撮影、タブの管理を頼みます。
  </Step>
</Steps>

## ポップアップ

| 項目 | 表示される内容 |
| --- | --- |
| 接続状態 | このブラウザの拡張機能が Enconvo に接続されているかどうか |
| 現在のブラウザ | この拡張機能が接続しているブラウザ(Chrome、Edge、Brave、Firefox など) |
| 接続中のブラウザ | いま Enconvo に拡張機能が接続されている、ほかのブラウザ |
| バージョン | インストール済みの拡張機能のバージョン |
| **詳しく見る** | このページを開きます |

ポップアップに接続が切れていると表示された場合は、Enconvo を再起動してブラウザを更新してください。それでも接続できないときは、拡張機能を一度オフにしてからオンに戻します。

## 複数のブラウザを使う

Enconvo は複数のブラウザに同時に接続できます。タスクでブラウザを指定しなかった場合、Enconvo は次の順に選びます。

1. ブラウザを使用の設定(**設定 → ブラウザを使用**、続いて **⋯** メニューの **設定**)で選んだ **既定のブラウザ**。
2. Mac の既定のブラウザ。
3. 最後に使った接続中のブラウザ。

自動化 API でブラウザを指定することもできます。

```json
{
  "browser": "edge"
}
```

よく使う値は `chrome`、`google_chrome`、`edge`、`brave_browser`、`arc`、`vivaldi`、`opera`、`firefox` です。

## 正しいタブにとどまる

ブラウザのタスクが始まると、Enconvo は作業中のブラウザとタブを記録します。以降のステップは、ページがポップアップを開いたり、再読み込みされたり、フォーカスを失ったりしても、できるかぎりそのタブにとどまります。

よりよい結果を得るために:

- タスクが終わるまでタブを開いたままにします。
- 複数のブラウザが接続されているときは、ブラウザを指定します。
- いま目の前にあるページを操作してほしいときは、「現在のタブを使って」と伝えます。
- ページが移動した後やフォームを送信した後は、ページをもう一度確認するよう頼みます。

## ウェブサイトへのアクセスと安全性

ウェブページには、あなたが書いていない指示が含まれていることがあります。機密性の高いページでは、サイトと操作内容を確認してから Enconvo に続行させてください。

拡張機能は、タスクで必要なときに、ブラウザの権限を使ってページの読み取り、クリック、入力、スクリーンショットの撮影、タブの確認、Cookie の読み取りを行います。サインイン済みのページ、ブラウザの履歴、社内ツールは機密データとして扱ってください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ポップアップに接続が切れていると表示される | Enconvo が起動していることを確認し、ブラウザを再起動してから、拡張機能をオフにしてオンに戻します。`localhost:11225` をブロックしているものがないか確認してください。 |
| 違うブラウザが操作される | ブラウザを使用の設定で **既定のブラウザ** を設定するか、ブラウザ操作で `edge`、`chrome`、`firefox` などのブラウザの値を渡します。 |
| 接続されているのに、ページを操作できない | `chrome://` などのブラウザ内ページは操作できません。厳格なコンテンツセキュリティポリシーのページ、クローズドな Shadow DOM、ブラウザの権限確認も妨げになることがあります。 |
| ファイルのアップロードができない | ブラウザの拡張機能の詳細ページで、ファイル URL へのアクセスをオンにしてください。ローカルファイルをアップロードするタスクや、ファイルを元にしたページを開くタスクで必要です。 |

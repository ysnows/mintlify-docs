クイックキャプチャ（Quick Capture）は、現在前面にあるアプリの内容を後から参照できるようナレッジベースに保存する機能です。各キャプチャにはウィンドウのスクリーンショットとテキストが保存されます（ブラウザの場合はページの内容、YouTube 動画の場合は字幕）。[Appshots](/ja/features/appshots) が今尋ねている質問にアプリウィンドウを添付するのに対し、クイックキャプチャは後から使うアイテムとしてナレッジベースに保存します。

## 残しておきたい内容をキャプチャする

1. 内容を表示しているアプリを最前面に出します。
2. クイックキャプチャのホットキーを押すか、[Dynamic Island](/ja/features/dynamic-island) を開いて **クイックキャプチャ** をクリックします。クイックキャプチャのホットキーは初期状態では未設定のため、**設定 → クイックキャプチャ** の **ホットキー** で設定してください。
3. ホットキーを押した瞬間に Enconvo が画面を撮影してピルを表示し、**保存先**（変更していなければデフォルトナレッジベース）へ保存します。短いシャッター音が鳴ります。
4. 通知に保存された内容と場所が表示されます。ナレッジベースで確認するには **開く** を、取り消すには **元に戻す** をクリックします。

保存に失敗した場合、通知には **再試行** と **閉じる** が表示されます。[音声メモ](/ja/features/voice-notes)にも同じ **元に戻す**、**再試行**、**閉じる** があります。

インデックス作成と要約は、アイテムが表示されてから少し遅れて完了する場合があります。

## 設定

**設定 → クイックキャプチャ**を開きます。

| 設定 | 働き |
| --- | --- |
| **クイックキャプチャを有効にする** | ホットキーで現在のアプリを保存できるようにします。[音声メモ](/ja/features/voice-notes)のホットキーのオン・オフも切り替えます。初期設定はオンです。 |
| **保存先** | キャプチャの保存先となるナレッジベースです。メモリには保存できません。 |
| **音声を録音** | キャプチャが保存されたときに短いシャッター音を鳴らします。 |
| **自動要約** | AI を使って各キャプチャを要約します。要約はアイテムのプレビューに表示され、検索対象にもなります。 |
| **ホットキー** | 現在のアプリを保存するショートカットです。初期設定はなしです。右 **Shift** キーの 2 回押しなどの修飾キー、または通常のショートカットを設定できます。 |

**自動要約**をオンにすると、キャプチャしたテキストが AI モデルへ送信されます。キャプチャ内容をどこで処理するかを管理したい場合は、モデルとプロバイダーの設定を確認してください。

### X の投稿

同じページの **X** セクションでは、x.com 上での Enconvo [ブラウザ拡張機能](/ja/features/browser-extension)の動作を設定します。

| 設定 | 働き |
| --- | --- |
| **カードのスタイル** | 保存した投稿を **投稿** 形式で表示するか **スクリーンショット** で表示するかを選びます。切り替えると以前保存した投稿の表示も変わります。 |
| **X でブックマークしたとき** | X 本来のブックマークボタンの動作を選びます：**X でブックマーク**、**ブックマークして Enconvo に保存**、**Enconvo にのみ保存**。選択するまでは、最初のブックマーク時に確認が表示されます。ブックマークを外しても Enconvo に保存された投稿は残ります。 |
| **「Enconvo に質問」ボタン** | 各投稿のヘッダーにある Grok の横に Enconvo ボタンを表示し、その投稿と返信について質問できるようにします。 |
| **X の投稿を自動で要約** | 保存した各投稿とスレッドを AI で要約します。 |
| **保存した投稿を自動で分類** | 保存した投稿の内容に合わせてトピックのタグを付けます。サインインが必要です。 |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 内容が欠けている、または不完全 | [権限](/ja/configuration/permissions)を確認し、対象のアプリを最前面に出してから、小さく見やすい例で試してください。 |
| キャプチャが見つからない | **保存先**を確認し、そのナレッジベースを開いてください。インデックス作成と要約はアイテムが表示された後に完了する場合があります。 |
| ホットキーを押しても何も起きない | **クイックキャプチャを有効にする**がオンになっていることと、**ホットキー**が設定されていることを確認してください。 |

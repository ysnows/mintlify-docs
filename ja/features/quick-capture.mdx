title: "クイックキャプチャ"

クイックキャプチャは、現在のアプリの内容を、あとで使えるようにナレッジベースに保存します。各キャプチャには、ウィンドウのスクリーンショットとそのテキストが保存されます。ブラウザならページの内容、YouTube の動画ならその字幕です。[Appshots](/ja/features/appshots) は、今している質問にアプリのウィンドウを添付します。クイックキャプチャは、保持するナレッジベースの項目を作成します。

## 残しておきたいものをキャプチャする

1. 内容のあるアプリを前面に出します。
2. クイックキャプチャのホットキーを押すか、[Dynamic Island](/ja/features/dynamic-island) を開いて**クイックキャプチャ**をクリックします。クイックキャプチャには、**設定 → クイックキャプチャ**の**ホットキー**で設定するまで、ホットキーがありません。
3. Enconvo は、ホットキーを押した瞬間に画像を撮ってピルを表示し、その後、キャプチャを**保存先**のナレッジベースに保存します。ほかを選ばない限り、デフォルトのナレッジベースです。短いシャッター音が鳴ります。
4. 通知に、保存された内容と保存先が表示されます。**開く**をクリックするとナレッジベースで確認でき、**元に戻す**をクリックするとキャプチャを取り消せます。

保存に失敗した場合は、通知に**再試行**と**閉じる**が表示されます。[音声メモ](/ja/features/voice-notes)にも、同じ**元に戻す**、**再試行**、**閉じる**があります。

インデックス作成と要約は、項目が表示されたあと、少し遅れて完了することがあります。

## 設定

**設定 → クイックキャプチャ**を開きます。

| 設定 | 内容 |
| --- | --- |
| **クイックキャプチャを有効にする** | ホットキーで、現在のアプリを保存できるようにします。[音声メモ](/ja/features/voice-notes)のホットキーのオンとオフも切り替えます。デフォルトでオンです。 |
| **保存先** | キャプチャを保存するナレッジベースです。キャプチャをメモリに保存することはできません。 |
| **キャプチャ音** | キャプチャが保存されたときに、短いシャッター音を鳴らします。 |
| **自動要約** | 各キャプチャを AI で要約します。要約は、項目のプレビューに表示され、検索もできます。 |
| **ホットキー** | 現在のアプリを保存するショートカットです。デフォルトでは設定されていません。右の **Shift** キーなど、修飾キーのダブルタップでも、通常のショートカットでもかまいません。 |

**自動要約**は、キャプチャしたテキストをあなたの AI モデルに送ります。キャプチャした内容がどこで処理されるかを管理したい場合は、モデルとプロバイダーの設定を確認してください。

### X の投稿

同じページの **X** セクションでは、Enconvo の[ブラウザ拡張機能](/ja/features/browser-extension)が x.com でどのように動作するかを設定します。

| 設定 | 内容 |
| --- | --- |
| **カードのスタイル** | 保存した投稿を、**投稿**または**スクリーンショット**として表示します。切り替えると、以前に保存した投稿も変わります。 |
| **X でブックマークしたとき** | X 自身のブックマークボタンの動作です。**X でブックマーク**、**ブックマークして Enconvo に保存**、**Enconvo にのみ保存**から選びます。選ぶまでは、最初にブックマークしたときに Enconvo が尋ねます。ブックマークを削除しても、投稿は Enconvo に残ります。 |
| **「Enconvo に質問」ボタン** | 各投稿のヘッダーの Grok の横に Enconvo のボタンを表示し、投稿とその返信について質問できます。 |
| **X の投稿を自動で要約** | 保存した各投稿とそのスレッドを AI で要約します。 |
| **保存した投稿を自動で分類** | 保存した各投稿に、その内容のトピックのタグを付けます。サインインしている必要があります。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 内容がない、または不完全 | [権限](/ja/configuration/permissions)を確認し、対象のアプリを前面に出して、小さくはっきり見える例で試します。 |
| キャプチャが見つからない | **保存先**を確認して、そのナレッジベースを開きます。インデックス作成と要約は、項目が最初に表示されたあとに完了することがあります。 |
| ホットキーが反応しない | **クイックキャプチャを有効にする**がオンで、**ホットキー**が設定されていることを確認します。 |

---
title: "ダッシュボード"
description: "エージェントにデータを数値とチャートのページへ変換させて保存し、すべての数値を元の行と照合して最新状態に保ちます。"
---

ダッシュボードは、継続的に追跡、確認、報告する数値のためにエージェントがデータから作成する、数値とチャートのページです。すべての数値は元のデータ行と紐づいているため、根拠を確認できます。あとから何度も見返す数値に使い、1 回限りの集計を知りたい場合はチャットで直接質問してください。

## ダッシュボードを作る

1. 新しいチャットを開始してメッセージボックスの下の **ダッシュボード** を選ぶか、任意のチャットで作成を依頼します。
2. データを渡します。CSV、TSV、または JSON ファイルを添付するか、**何かを作る** 行の **スプレッドシートを開く** をクリックします。接続済みのサービス、Mac 上のファイル、ウェブアドレスをエージェントに指定することもできます。
3. 何を追跡し、どのように内訳を表示したいかを伝えます。

例：

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

ダッシュボードがチャットの横に開きます。エージェントがフィルターを追加すると、それぞれが上部にメニュー、スイッチ、またはボックスとして表示されます。

## 数値を確認する

1. ダッシュボードのヘッダーにある **数値を確認** をクリックします。
2. 確認したい数値をクリックします。
3. Enconvo がその数値のもとになった行、取得元、そして数値と行が一致しているかどうかを表示します。

数値について質問したい場合は、その数値にコメントを付けます。コメントを `@Enconvo` で始めるとエージェントから返信を受け取れます。

## データの取得元を確認する

**ソース** をクリックすると、各データセットの取得元、行数、最終更新日時を確認できます。更新期限を過ぎているデータには **古いデータ** と表示されます。**CSV をダウンロード** をクリックするとそのデータセットを保存できます。

## 数値を最新の状態に保つ

接続済みサービス、Mac 上のファイル、またはウェブアドレスから作られたダッシュボードは、許可を与えることで自動更新できます。

1. ダッシュボードに **これらの数値を最新の状態に保ちますか？** と表示されたら、各ソースが読み取る内容を確認して **許可** をクリックします。**ソース** 内で各ソースの横にある **更新を許可** をクリックしても設定できます。
2. 数値は **1時間ごと** や **更新したとき** など、エージェントが設定したスケジュールで更新されます。今すぐ更新するには **更新** をクリックします。
3. 停止するには、ソースの横にある **更新を停止** をクリックします。

更新に失敗した場合、ダッシュボードは前回の数値を保持したまま失敗理由を表示します。

<Note>
データの読み取り専用であることが明示されていないソースは、**更新** をクリックしたときにのみ実行されます。共有されたダッシュボードでは、参加している全員がそのソースの読み取り内容を見ることができます。
</Note>

## ダッシュボードをダウンロードまたは移行する

**ダウンロード** をクリックして次の中から選びます。

| オプション | 出力内容 |
| --- | --- |
| **PDF をダウンロード** | ページの PDF |
| **画像をダウンロード** | ページの画像 |
| **HTML をダウンロード** | どのブラウザでも開ける単一の HTML ファイル |
| **プロジェクトをダウンロード (.zip)** | 別のコンピュータにインポートできるプロジェクト一式 |

別のコンピュータに取り込むには、**アーティファクト** ライブラリで **インポート** をクリックして zip ファイルを選択します。コメントも一緒に移行されますが、接続済みサービスからの自動更新は移行先で再度許可する必要があります。

他の人やチームとダッシュボードを共有するには、**共有** をクリックします。詳しくは [アーティファクト](/ja/features/artifacts) を参照してください。ダッシュボードは iPhone アプリや Android アプリでも開けます。詳しくは [アーティファクト](/ja/features/artifacts) をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 数値と元の行が一致しない | コメントでエージェントに質問するか、計算の修正を依頼してください |
| ソースに **古いデータ** と表示される | **更新** をクリックするか、そのソースの更新を許可してください |
| **数値を更新できませんでした** | 理由を確認し、ソースへのアクセス権を修正してから **更新** をクリックしてください |
| ダッシュボードが空のまま | チャットでダッシュボードの内容と使用したいデータを説明してください |

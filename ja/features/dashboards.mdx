---
title: "ダッシュボード"
description: "エージェントにデータを数値とグラフのページにまとめさせ、すべての数値を元の行と照合して確認し、最新の状態に保ちます。"
---

ダッシュボードは、追跡、レビュー、報告する数値のために、エージェントがあなたのデータから作る、数値とグラフのページです。すべての数値は、元になった行と結び付いているため、確認できます。あとで数値に戻ってくる場合に使ってください。一度きりの回答なら、チャットで聞くだけで十分です。

## ダッシュボードを作る

1. 新しいチャットを開始して、メッセージ欄の下で **ダッシュボード** を選ぶか、どのチャットでもダッシュボードを頼みます。
2. データを添付します。CSV、TSV、JSON ファイルを添付するか、**何かを作る** の行で **スプレッドシートを開く** をクリックします。接続済みのサービス、Mac 上のファイル、Web アドレスをエージェントに指定することもできます。
3. 何を追跡し、どう分けるかを伝えます。

例:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

ダッシュボードはチャットの横で開きます。エージェントがフィルタを追加すると、それぞれが、メニュー、スイッチ、ボックスとして上部に表示されます。

## 数値を確認する

1. ダッシュボードのヘッダーで **数値を確認** をクリックします。
2. 任意の数値をクリックします。
3. Enconvo が、その数値の元になった行、取得元、そして 2 つが一致しているかどうかを表示します。

数値について質問するには、その数値にコメントします。エージェントの回答を得るには、コメントを `@Enconvo` で始めます。

## データの出どころを確認する

**ソース** をクリックします。各データセットに、取得元、行数、最終更新日時が表示されます。更新期限を過ぎたデータには **古いデータ** と表示されます。データセットを保存するには、**CSV をダウンロード** をクリックします。

## 数値を最新の状態に保つ

接続済みのサービス、Mac 上のファイル、Web アドレスから作ったダッシュボードは、許可すると、自動で更新できます。

1. ダッシュボードに **これらの数値を最新の状態に保ちますか？** と表示されたら、各ソースが何を読み取るかを確認して、**許可** をクリックします。**ソース** で、ソースの隣の **更新を許可** をクリックすることもできます。
2. 数値は、エージェントが設定したスケジュール、たとえば **1時間ごと** や **更新したとき** に従って更新されます。**更新** をクリックすると、今すぐ更新します。
3. 止めるには、ソースの隣の **更新を停止** をクリックします。

更新に失敗した場合、ダッシュボードは最後の数値を保持し、理由を表示します。

<Note>
データの読み取りのみを行うと明示していないソースは、**更新** をクリックしたときだけ実行されます。共有されたダッシュボードでは、参加者全員に、ソースが何を読み取るかが表示されます。
</Note>

## ダッシュボードをダウンロードまたは移動する

**ダウンロード** をクリックして、次から選びます。

| オプション | 得られるもの |
| --- | --- |
| **PDF をダウンロード** | ページの PDF |
| **画像をダウンロード** | ページの画像 |
| **HTML をダウンロード** | どのブラウザでも開ける 1 つの HTML ファイル |
| **プロジェクトをダウンロード (.zip)** | プロジェクト全体。別のコンピュータにインポートできます |

プロジェクトを取り込むには、**アーティファクト** ライブラリで **インポート** をクリックして、zip を選びます。コメントも一緒に取り込まれます。接続済みのサービスからの更新は、そこでもう一度許可する必要があります。

ダッシュボードをユーザーやチームと共有するには、**共有** をクリックします。[アーティファクト](/ja/features/artifacts)を参照してください。ダッシュボードは、iPhone と Android のアプリでも開けます。[アーティファクト](/ja/features/artifacts)を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 数値と、その元の行が一致しない | コメントでエージェントに質問するか、計算を修正するよう頼んでください |
| ソースに **古いデータ** と表示される | **更新** をクリックするか、そのソースの更新を許可してください |
| **数値を更新できませんでした** | 理由を読み、ソースへのアクセスを修正してから、**更新** をクリックしてください |
| ダッシュボードが空 | チャットで、ダッシュボードとそのデータについて説明してください |

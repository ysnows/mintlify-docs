---
title: "ビジュアル回答"
description: "プレーンテキストの代わりに、SVG 図表、チャート、操作可能なウィジェットをチャット内に直接表示します。"
---

Agent に回答を「見せて」と頼むと、会話の中にビジュアルを直接描画します。SVG 図表、HTML プレビュー、クリックや調整ができるインタラクティブなウィジェットなどです。文章で読むよりも図やチャート、簡単な計算機の方がわかりやすい場面で使ってください。これを行うには、Agent でビジュアル関連ツールが有効になっている必要があります。

ビジュアル回答は会話の中に表示されます。プレゼン資料、ダッシュボード、デザイン、ドキュメントのように、後から保存・編集・発表・共有したいものが必要な場合は、代わりに[アーティファクト](/ja/features/artifacts)の作成を依頼してください。

## ビジュアルを依頼する

ビジュアルでどのような疑問に答えたいのかを伝えます。

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

チャートや計算機の場合は、データと単位もあわせて伝えてください。見た目が整ったビジュアルであっても、事実や計算が誤っている場合があるため確認が必要です。

## 回答内のリンク、地図、チャート

依頼しなくても、回答の一部が自動的にビジュアル表示になることがあります。

- **リンク**は、サイトのアイコン付きのカードとして表示されます。
- **場所**は、実際の地図上に場所名付きで表示されます。複数の場所がある場合は 1 つの番号付き地図にまとまり、ルートの場合は経路と所要時間・距離が表示されます。
- Agent が作成する**チャート**は配色がチェックされ、色覚特性がある場合やライト／ダーク外観のどちらでも各系列が区別しやすいようになっています。数値、日付、ステータス表記はお使いの言語で表示されます。

## ビジュアルを使う・保存する

1. ビジュアルの描画が完了するまで待ち、備わっているコントロールを操作します。一部のウィジェットは、追加のプロンプトをチャットに送り返します。
2. 完成したビジュアルにポインタを合わせ、右上の **⋯** をクリックします。
3. **クリップボードにコピー**、または **ファイルをダウンロード** を選んでファイル名を確定します。アプリ独自のカード、表、チャートで描かれたビジュアルの場合は、代わりに **画像をダウンロード** が表示され、ダウンロードフォルダに PNG として保存できます。

保存した画像はその瞬間の表示をキャプチャしたものであり、操作可能なコントロールは引き継がれません。ウィジェットの値を変更した後に元へ戻したいときは、同じメニューの **値をリセット** を使います。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ビジュアルではなくコードが返ってくる | Agent で有効になっているツールを確認し、会話の中で結果を表示するよう依頼してください |
| ウィジェットの表示が不完全に見える | 描画が終わるまで待ってから、よりシンプルな構成を依頼してください |
| チャットのウィジェットではなく画像ファイルが必要 | [画像生成](/ja/ai/image-generation)をご利用ください |
| チャット後もチャートを残して見返したい | [ダッシュボード](/ja/features/dashboards)の作成を依頼してください |

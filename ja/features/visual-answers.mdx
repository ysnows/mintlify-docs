title: "ビジュアル回答"
description: "プレーンテキストの代わりに、図、グラフ、インタラクティブなウィジェットをチャットの中で表示します。"
---

エージェントに回答を見せるよう頼むと、会話の中にそのまま視覚的な回答が描かれます。SVG の図、HTML のプレビュー、クリックして調整できるインタラクティブなウィジェットなどです。何段落もの文章より、絵やグラフ、小さな計算機のほうが伝わるときに使ってください。これを行うには、エージェントのビジュアルツールが必要です。

ビジュアル回答は会話の中にあります。保存、編集、発表、共有したいもの、たとえばスライド、ダッシュボード、デザイン、ドキュメントが必要なときは、代わりに[アーティファクト](/ja/features/artifacts)を頼んでください。

## ビジュアルを頼む

ビジュアルがどの質問に答えるものかを伝えます。

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

グラフや計算機には、データとその単位を含めてください。見栄えのよいビジュアルでも、事実や計算が間違っていることがあるので、確認してください。

## 返信の中のリンク、地図、グラフ

頼まなくても、回答が視覚的になることがあります。

- **リンク** は、サイトのアイコン付きのカードとして表示されます。
- **場所** は、場所の名前付きで実際の地図に表示されます。複数の場所は、番号付きの 1 つの地図にまとまり、ルートは、所要時間と距離付きの線で表示されます。
- エージェントが作る **グラフ** は、色が確認されるため、色覚の違いがあっても、ライトとダークのどちらの外観でも、各系列を区別できます。数値、日付、ステータスの言葉は、お使いの言語で表示されます。

## ビジュアルを使って保存する

1. ビジュアルの描画が終わるまで待ってから、付いているコントロールを使います。ウィジェットによっては、追加のプロンプトをチャットに送り返します。
2. 完成したビジュアルにポインタを合わせ、右上の **⋯** をクリックします。
3. **クリップボードにコピー** を選ぶか、**ファイルをダウンロード** を選んでファイル名を確定します。アプリ自身のカード、表、グラフで描かれたビジュアルでは、代わりに **画像をダウンロード** が表示され、PNG が「ダウンロード」フォルダに保存されます。

保存した画像は、ビジュアルのある瞬間を取り込んだもので、インタラクティブなコントロールは残りません。ウィジェットの値を変更したあとは、同じメニューの **値をリセット** で元に戻せます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ビジュアルではなくコードが返ってくる | エージェントで有効になっているツールを確認し、結果を会話の中で見せるよう頼んでください |
| ウィジェットが不完全に見える | 完了するまで待ってから、より簡単なバージョンを頼んでください |
| チャットのウィジェットではなく画像ファイルが必要 | [画像生成](/ja/ai/image-generation)を使ってください |
| グラフを残して、あとで見返したい | [ダッシュボード](/ja/features/dashboards)を頼んでください |

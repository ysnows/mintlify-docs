description: "タスクがあなたを必要とするときにエージェントから電話をかけたり、あなたに代わって人や Enconvo の友だちに電話したり、出られなかった電話に応答したりできます。"

エージェント電話を使うと、エージェントが電話を使えます。エージェントは、タスクがあなたの入力を待っているときにあなたへ電話をかけ、チャットで指定した人や店舗に電話をかけ、あなたに代わって Enconvo の友だちやチームメイトに電話をかけ、あなたが出なかった iPhone への着信に応答できます。すべての通話の文字起こしは、チャットに戻ってきます。

## はじめる前に

**設定 → エージェント電話**を開き、電話をかける方法を少なくとも 1 つセットアップします。

| 方法 | 内容 | 費用 |
| --- | --- | --- |
| **あなたの iPhone** | iPhone が近くにある間、この Mac があなたの iPhone で、あなた自身の番号から発信、応答します。**代わりに電話に出る**に必要です。 | お使いの電話プランの範囲で無料です。 |
| **電話プロバイダー** | エージェントが、あなた自身の Twilio または Telnyx アカウントの番号から電話をかけます。 | 通話ごとにプロバイダーが課金します。 |
| **EnConvo モバイルアプリ** | エージェントが、スマートフォンの EnConvo アプリを電話のように鳴らします。応答すると [Live Talk](/ja/features/live-voice) が始まります。Android では、着信通知やロック画面から応答すると、ロックを解除したりアプリを開いたりせずに接続されます。あなたへの通話専用です。 | Wi-Fi またはモバイルデータ通信なら無料です。 |

## あなたの iPhone をセットアップする

1. **あなたの iPhone**の下で、**セットアップ**をクリックします。画像つきのガイドが 1 ステップずつ案内し、それぞれに合った場所を開きます。
2. **システム設定 → プライバシーとセキュリティ → アクセシビリティ**で Enconvo をオンにします。これにより、Enconvo は macOS の通話プロンプトで「発信」と「終了」を押せます。
3. **FaceTime → 設定 → 一般**で、**iPhoneからの通話**をオンにします。
4. **システム設定 → 通知**で、電話と FaceTime の**通知を許可**と**デスクトップ**をオンにします。macOS は、各通話を通知として表示します。
5. iPhone とこの Mac が同じ Apple アカウントを使っていることを確認します。iPhone で、**設定 → アプリ → 電話 → 他のデバイスでの通話**を開き、この Mac を許可します。
6. iPhone を、同じ Wi-Fi 上のこの Mac の近くに置いておきます。
7. **Enconvo Audio を追加**をクリックし、macOS から求められたら Mac のログインパスワードを入力します。Enconvo Audio は、マイクやスピーカーを使わずに、エージェントの声を通話に届け、相手の声を戻します。
8. **音声を確認**をクリックします。Enconvo Audio を通して短いトーンを再生し、それを聞き取ります。電話は鳴りません。

**準備完了**と表示されると、エージェントはあなたの iPhone の番号から電話をかけ、電話を受けた相手にはあなたの番号が表示されます。iPhone が近くにない間は、電話プロバイダーをセットアップしてあれば、代わりにそれで発信します。

## 電話プロバイダーをセットアップする

1. **電話プロバイダー**の下で、Twilio または Telnyx の横の**セットアップ**または**接続**をクリックします。Enconvo がプラグインを追加し、サインインまたは API キーを求めます。
2. **発信元の番号**で、通話の発信元にする番号を選びます。
3. **テスト通話**をクリックして試します。

エージェントはデフォルトのプロバイダーを使い、チャットで頼んだときやデフォルトで発信できないときだけ、別のプロバイダーを使います。Telnyx の通話は、Enconvo があなたのアカウントに追加する、Enconvo Agent Phone という名前の TeXML アプリケーション経由で行われます。Twilio のトライアルアカウントでは、Twilio で認証した番号にしか電話できません。

Twilio と Telnyx の通話はキーパッドのキーを押せるため、エージェントは自動音声メニューや内線を通過できます。あなたの iPhone 経由の通話でも同様です。

## タスクがあなたを必要とするときの着信

**エージェント通話の設定 → あなたの入力を待っているタスク**で、Mac から離れているときにエージェントがあなたに連絡する方法を選びます。

1. ペアリング済みなら、EnConvo モバイルアプリがすぐに鳴ります。
2. 応答がなければ、あなたの電話番号に電話をかけます。番号を設定し、**発信元**を選びます。**あなたの iPhone**、Twilio、Telnyx から選べます。

着信には、エージェントの名前が表示されます。同じチャットで保留中のリクエストは 1 回の通話にまとめられ、拒否した通話は再度かかりません。**通知までの時間**では、タスクが通知されるまで待つ時間を設定します。**タスクの詳細を含める**をオンにすると、電話番号への通話でタスクの内容を読み上げます。オフの場合は、チャットのタイトルだけが読み上げられ、電話で承認を行うことはできません。

チャットでエージェントに、アプリ、あなたの iPhone、Twilio、Telnyx のいずれかで自分に電話するよう頼むこともできます。頼んだ通話は毎回鳴ります。

## エージェントに誰かへ電話してもらう

1. **エージェント通話の設定**の下で、**あなたに代わる発信**をオンにします。
2. チャットで、人や店舗に電話をかけるようエージェントに頼み、何の用件の通話かを伝えます。
3. 通話カードに、電話番号と通話で伝える内容が表示されます。**発信する**をクリックします。フルアクセスで実行されるチャットでは、エージェントは待たずに発信します。
4. カードで通話を見守るか、**通話を終了**をクリックします。通話が終わると、結果カードに双方が話した内容が表示されます。

電話回線がセットアップされていない場合は、通話カードからチャット内で直接、あなたの iPhone または Telnyx をセットアップでき、準備ができ次第、通話が行われます。

## エージェントに友だちへ電話してもらう

エージェントに、Enconvo の[友だち](/ja/features/friends)やチームメイトに電話するよう頼み、伝える内容を指示します。エージェントはまず相手の Enconvo アプリを鳴らし、あなたの代わりに話し、相手の答えと通話の文字起こしをチャットに持ち帰ります。相手の電話番号にかけるのは、電話で話すよう頼んだとき、または Enconvo の通話がつながらなかったときだけです。

エージェントが連絡できるのは、あなたの友だちとチームメイトだけで、通話でしか会っていない人には連絡しません。スケジュールされたタスクは、連絡を許可した友だちにメッセージを送ったり電話したりできます。たとえば、深夜にレポートを送り、朝になっても返信がなければ電話をかけることができます。

## 通話を録音する

**通話を録音**をオンにすると、電話アプリや電話番号を通じた、あなたやほかの人へのすべてのエージェント通話を、文字起こしとともにこの Mac の[録音](/ja/features/meeting-recording)に保存します。**最近の通話**に表示される録音済みの各通話には、録音ボタンがあります。エージェントが電話をかけた友だちには、通話が録音されていることが聞こえ、見えます。録音を望まないと伝えられた場合、録音は保存されません。

<Warning>
場所によっては、通話を録音する前に、通話の全員の同意が必要です。エージェントが電話をかける相手を録音してよいかどうか、確認してください。
</Warning>

## 出られなかった電話にエージェントが応答する

**代わりに電話に出る**には、あなたの iPhone が必要です。iPhone への着信に出なかったとき、エージェントがこの Mac で応答して伝言を受け、要約と文字起こしを「アップデート」に送ります。

1. **あなたの iPhone**の下で、**代わりに電話に出る**をオンにします。求められたら連絡先を許可します。連絡先に保存された発信者を Enconvo が認識できるようになります。
2. **応答しなかったとき**を選びます。数回鳴らしたあとで、デフォルトは 5 秒です。
3. 応答する通話を選びます。**連絡先にない番号**または**全員**です。**おやすみ時間はすぐに応答**にすると、通知で設定したおやすみ時間中は待たずに応答します。
4. **話してよい内容**に、どのような立場で応答するか、発信者に何を伝えてよいかを書きます。エージェントは伝言を受けるだけで、あなたに代わって何かに同意することはありません。
5. Mac が複数ある場合は、**最初に応答**する Mac を選びます。ほかの Mac は、その Mac がオフラインのときだけ応答します。

各通話のあとに、スマートフォンに通知が届き、誰からの電話か、用件は何かが 1 文で表示され、緊急かどうかもわかります。緊急の通話は集中モードを突き抜けて通知されます。通知には**かけ直す**と**開く**があります。詐欺に見える通話には、**詐欺の可能性あり**のバッジと警告が付きます。

発信者がエージェントに何かをさせることはできません。通話中、エージェントは話して伝言を受けるだけで、ツール、チャット、メモリ、ファイルは使えません。要約もツールなしで書かれます。通話のチャットでは、あなたが返信するまで何も実行されず、送信、支払い、削除、コマンド実行を行う操作は、フルアクセスでも先に確認されます。設定の**発信者が到達できる範囲**に、これらの制限が表示されます。

### タスクを頼める番号

**タスクを頼める番号**に、あなた自身のほかの番号を追加します。それらの番号からの通話はエージェントと話すことができ、タスクを頼めます。それ以外の人は、伝言を残すだけです。偽の発信者番号がこれらの番号になりすませるため、**パスフレーズを求める**をオンにします。発信者がそれを言うまで、通話は伝言を受けるだけになります。

## 通話を確認する

チャットウィンドウのサイドバーにある**通話**セクションでは、エージェントが応答した通話が、ほかのチャットとは別にまとめられます。緊急の通話、かけ直しを希望する通話、まだ読んでいない通話に印が付き、各通話が着信した時刻と、発信者の番号または連絡先の名前が表示されます。**かけ直す**または**完了にする**をクリックします。同じセクションは、iPhone と Android アプリにもあります。

**設定 → エージェント電話**の下部にある**最近の通話**には、エージェントが発信または応答したすべての通話が、結果とともに一覧表示されます。

## 設定

| 設定 | 変わること |
| --- | --- |
| **あなたの iPhone** | この Mac を通じて、あなた自身の iPhone の番号から発信します。**代わりに電話に出る**も含みます。 |
| **電話プロバイダー** | Twilio と Telnyx のアカウント、デフォルトのプロバイダー、**発信元の番号**です。 |
| **EnConvo アプリを鳴らす** | エージェントが、ペアリング済みのスマートフォンを鳴らせるようにします。**スマートフォンをペアリング**で追加します。 |
| **あなたの入力を待っているタスク** | タスクが待機中のときにエージェントがあなたに連絡する方法です。アプリ、次にあなたの番号の順で、**発信元**、**通知までの時間**、**タスクの詳細を含める**があります。 |
| **あなたに代わる発信** | チャットで指定した人にエージェントが電話をかけられるようにします。 |
| **通話を録音** | エージェント通話とその文字起こしを録音に保存します。 |
| **代わりに電話に出る** | あなたが出なかった iPhone への着信に、エージェントが応答します。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **Enconvo Audio が見つかりません** | macOS のアップデートで削除されることがあります。**もう一度追加**をクリックし、macOS が表示するウィンドウに Mac のログインパスワードを入力します。ほかのウィンドウの後ろに隠れている場合があります。 |
| **アクセシビリティがオフです** | **システム設定 → プライバシーとセキュリティ → アクセシビリティ**で Enconvo をオンにします。 |
| **通話の音声を聞き取れません** | **システム設定 → プライバシーとセキュリティ → 画面とシステムオーディオの録音**の**システムオーディオ録音のみ**で Enconvo を許可し、**音声を確認**をクリックします。 |
| **通知がオフです** | 電話と FaceTime の**通知を許可**と**デスクトップ**をオンにします。オンにするまで、通話は電話プロバイダー経由になります。 |
| **iPhone が近くにありません** | 同じ Wi-Fi 上で、iPhone をこの Mac の近くに持ってきます。それまで、通話は電話プロバイダー経由になります。 |
| Twilio の通話がつながらない | トライアルアカウントでは、認証済みの番号にしか電話できません。Twilio でその番号を認証するか、アカウントをアップグレードします。 |
| **代わりに電話に出る**が連絡先を認識しない | Enconvo に連絡先を許可するか、連絡先を読み取れる Mac を最初に応答させます。 |

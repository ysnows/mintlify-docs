title: "エージェント電話"
description: "タスクで確認が必要なときにエージェントから電話をかけてもらったり、ユーザーに代わって人や Enconvo の友だちに電話をかけたり、不在着信に応答したりできます。"
---

エージェント電話は、エージェントが電話を使えるようにする機能です。タスクがあなたの入力待ちになったときにエージェントから電話をかけて知らせたり、チャットで指定した相手や企業、Enconvo の友だち・チームメンバーに代わりに電話をかけたり、あなたが取れなかった iPhone への着信に応答したりできます。すべての通話の文字起こしはチャットへ戻ります。

## はじめる前に

**設定 → エージェント電話** を開き、少なくとも 1 つの発信方法を設定してください。

| 方法 | できること | 費用 |
| --- | --- | --- |
| **あなたの iPhone** | iPhone が近くにある間、この Mac があなたの iPhone 経由で自分の番号から発信および応答を行います。**代わりに電話に出る** の利用に必要です。 | お使いの携帯プラン内なら無料。 |
| **電話プロバイダー** | ご自身の Twilio または Telnyx アカウントの番号からエージェントが発信します。 | プロバイダーより通話ごとに課金されます。 |
| **EnConvo モバイルアプリ** | エージェントが電話着信のようにスマートフォンの EnConvo アプリを呼び出します。応答すると [Live Talk](/ja/features/live-voice) が始まります。Android では着信通知やロック画面から応答すればロック解除やアプリ起動なしでつながります。自分宛ての通話専用です。 | Wi-Fi またはモバイル通信で無料。 |

## あなたの iPhone を設定する

1. **あなたの iPhone** の下にある **設定する** をクリックします。画像付きのガイドが 1 ステップずつ案内し、必要な設定画面を自動で開きます。
2. macOS の通話画面で Enconvo が「発信」や「終了」を押せるよう、**システム設定 → プライバシーとセキュリティ → アクセシビリティ** で Enconvo をオンにします。
3. **FaceTime → 設定 → 一般** で **iPhone からの通話** をオンにします。
4. **システム設定 → 通知** で「電話」と FaceTime の両方について **通知を許可** と **デスクトップ** をオンにします。macOS は各通話を通知として表示します。
5. iPhone とこの Mac で同じ Apple Account を使っていることを確認します。iPhone で **設定 → アプリ → 電話 → ほかのデバイスでの通話** を開き、この Mac を許可します。
6. iPhone をこの Mac の近くに置き、同じ Wi-Fi に接続します。
7. **Enconvo Audio を追加** をクリックし、macOS に求められたら Mac のログインパスワードを入力します。Enconvo Audio は、マイクやスピーカーを使わずにエージェントの声を通話へ送り、相手の声を戻す役割を果たします。
8. **音声を確認** をクリックします。Enconvo Audio 経由で短いテスト音を再生して聞き取りを確認します（呼び出し音は鳴りません）。

**準備完了** と表示されると、エージェントがあなたの iPhone の番号から発信できるようになり、相手にはあなたの番号が表示されます。iPhone が近くにない場合は、設定済みであれば電話プロバイダーが代わりに発信します。

## 電話プロバイダーを設定する

1. **電話プロバイダー** の下で Twilio または Telnyx の横にある **設定する** または **接続** をクリックします。Enconvo がプラグインを追加し、サインインまたは API キーの入力を求めます。
2. **発信元の番号** で発信に使う番号を選びます。
3. **テスト通話** をクリックして動作を試します。

エージェントはデフォルトのプロバイダーを使用します。別のプロバイダーが使われるのは、チャットで指定した場合か、デフォルトのプロバイダーで発信できない場合のみです。Telnyx の通話は、Enconvo がアカウントへ追加する「Enconvo Agent Phone」という TeXML アプリケーション経由で行われます。Twilio のトライアルアカウントでは、Twilio で認証済みの番号にしか発信できません。

Twilio および Telnyx 経由の通話ではプッシュボタン操作（キーパッド入力）もできるため、エージェントが自動音声案内や内線番号を突破できます。**あなたの iPhone** 経由の通話でも同様に可能です。

## タスクの対応が必要なときに電話を受け取る

**エージェント通話の設定 → あなたの入力を待っているタスク** で、Mac から離れている間にエージェントがどうやってあなたへ連絡するかを設定します。

1. ペアリング済みであれば、最初に EnConvo モバイルアプリが鳴ります。
2. 応答がない場合は、あなたの電話番号に発信します。電話番号を設定し、**発信元** を **あなたの iPhone**、Twilio、または Telnyx から選びます。

着信にはエージェント名が表示されます。同じチャット内の保留中リクエストは 1 つの通話にまとめられ、拒否した通話が何度もかけ直されることはありません。**通知までの時間** で連絡まで待つ時間を設定できます。**タスクの詳細を含める** をオンにすると電話番号への通話でタスク内容が読み上げられます。オフにするとチャットタイトルのみがアナウンスされ、電話越しの承認操作はできなくなります。

チャットでエージェントに直接「電話して」と依頼し、アプリ、あなたの iPhone、Twilio、Telnyx のいずれかを使ってもらうこともできます。自分で依頼した通話は毎回呼び出されます。

## エージェントに誰かへ電話をかけてもらう

1. **エージェント通話の設定** の下にある **あなたに代わる発信** をオンにします。
2. チャットで個人や店舗・企業への電話を依頼し、用件を伝えます。
3. 通話カードに電話番号と伝える内容が表示されます。**発信する** をクリックします。フルアクセスで実行中のチャットでは、確認を待たずに発信します。
4. カード上で通話の進行を見守るか、**通話を終了** をクリックします。通話が終わると、双方の発言をまとめた結果カードが表示されます。

回線がまだ設定されていない場合は、チャット上の通話カードから直接「あなたの iPhone」または Telnyx を設定でき、準備が整い次第そのまま発信されます。

## エージェントに友だちへ電話をかけてもらう

チャットで Enconvo の[友だち](/ja/features/friends)やチームメンバーに電話するようエージェントに依頼し、伝える内容を指示します。エージェントはまず相手の EnConvo アプリを呼び出して会話を行い、相手の返答と通話の文字起こしをあなたのチャットへ持ち帰ります。相手の電話番号へ発信するのは、あなたが電話での発信を指示した場合か、Enconvo 通話で相手につながらなかった場合のみです。

エージェントが連絡できるのはあなたの友だちとチームメンバーだけであり、通話だけで知り合った相手には連絡しません。スケジュールされたタスク（オートメーション）からも、許可した友だちにメッセージや電話を送れます。たとえば、深夜にレポートを送信し、朝までに返信がなければ電話をかけるといった使い方が可能です。

## 通話を録音する

**通話を録音** をオンにすると、自分宛て・相手先宛てを問わず、アプリ通話も電話番号への通話もすべて文字起こし付きでこの Mac の[録音](/ja/features/meeting-recording)に保存されます。**最近の通話** にある録音済みの通話にはそれぞれ録音ボタンが表示されます。エージェントが電話をかけた友だちには録音中であることが音声と画面で伝わり、相手が録音を望まないと言えば保存されません。

<Warning>
地域によっては、通話の録音に際して通話者全員の同意が必要な場合があります。エージェントが電話をかける相手を録音してよいか、事前に確認してください。
</Warning>

## 不在着信にエージェントが応答する

**代わりに電話に出る** を利用するには **あなたの iPhone** の設定が必要です。iPhone への着信に出られないとき、Mac 上でエージェントが代わりに応答して伝言を聞き取り、要約と文字起こしを「Updates」へ送ります。

1. **あなたの iPhone** の下で **代わりに電話に出る** をオンにします。Contacts（連絡先）に登録されている発信者を判別できるよう、求められたら連絡先へのアクセスを許可してください。
2. **応答しなかったとき** で、何秒鳴ったら出るか（デフォルトは 5 秒）を選びます。
3. 応答する相手を **連絡先にない番号** または **全員** から選びます。**おやすみ時間はすぐに応答** をオンにすると、通知のおやすみ時間中は待たずにすぐ応答します。
4. **話してよい内容** に、誰として応答するか、相手に伝えてよい内容は何かを記入します。エージェントは伝言を受け取るだけで、あなたの代わりに何かへ同意することはありません。
5. Mac を複数台使っている場合は、**最初に応答** する Mac を選びます。他の Mac はその Mac がオフラインのときだけ応答します。

通話が終わるたびに、誰からの着信か、用件の 1 文要約、緊急かどうかを記した通知がスマートフォンへ届きます。緊急の電話は集中モードを貫通して通知されます。通知には **かけ直す** と **開く** ボタンがあります。詐欺の疑いがある着信には **詐欺の可能性** バッジと警告が付きます。

発信者がエージェントを操って何かを実行させることはできません。通話中のエージェントは会話と伝言の聞き取りだけを行い、ツール、チャット履歴、メモリ、ファイルには一切アクセスしません。要約もツールを使わずに作成されます。着信チャットではあなたが返信するまで何も実行されず、送信、決済、削除、コマンド実行などの操作はフルアクセス設定であっても必ず最初にあなたへ確認します。設定の **発信者がアクセスできる範囲** でこれらの制限を確認できます。

### タスクを頼める番号

**タスクを頼める番号** に自分自身の別の電話番号を登録できます。登録された番号からの着信はエージェントと会話してタスクを依頼でき、それ以外の番号はすべて伝言のみを受け付けます。発信者番号は偽装されるおそれがあるため、**パスフレーズを求める** をオンにしておくと安心です。相手がパスフレーズを言うまで、通話は伝言の聞き取りのみに制限されます。

## 通話を振り返る

チャットウィンドウのサイドバーにある **通話** セクションでは、エージェントが応答した通話を他のチャットと分けて管理できます。緊急の通話、折り返しが必要な通話、未読の通話にマークが付き、各着信時刻と発信者の番号または連絡先名が表示されます。**かけ直す** または **完了にする** をクリックして処理できます。同じセクションは iPhone および Android アプリにもあります。

**設定 → エージェント電話** の下部にある **最近の通話** には、エージェントが発信または応答したすべての通話とその結果が一覧表示されます。

## 設定

| 設定 | 内容 |
| --- | --- |
| **あなたの iPhone** | この Mac を通じて自分の iPhone 番号から発信する設定と、**代わりに電話に出る** の設定。 |
| **電話プロバイダー** | Twilio と Telnyx のアカウント、デフォルトプロバイダー、**発信元の番号**。 |
| **EnConvo アプリを鳴らす** | ペアリング済みのスマートフォンをエージェントが呼び出せるようにします。**スマートフォンをペアリング** で追加します。 |
| **あなたの入力を待っているタスク** | タスクが待機中のときの連絡手順（アプリ、次に電話番号）。**発信元**、**通知までの時間**、**タスクの詳細を含める** を設定します。 |
| **あなたに代わる発信** | チャットで指定した相手にエージェントが電話をかけられるようにします。 |
| **通話を録音** | エージェントの通話と文字起こしを「録音」に保存します。 |
| **代わりに電話に出る** | iPhone で取れなかった着信にエージェントが応答します。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **Enconvo Audio が見つからない** | macOS のアップデートで削除されることがあります。**再度追加** をクリックし、macOS が表示するウィンドウに Mac のログインパスワードを入力してください（他のウィンドウの後ろに隠れている場合があります）。 |
| **アクセシビリティがオフ** | **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で Enconvo をオンにしてください。 |
| **通話の音声が聞こえない** | **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** の **システムオーディオ録音のみ** で Enconvo を許可し、**音声を確認** をクリックしてください。 |
| **通知がオフ** | 「電話」と FaceTime の **通知を許可** と **デスクトップ** をオンにしてください。それまでは電話プロバイダー経由で発信されます。 |
| **iPhone が近くにない** | 同じ Wi-Fi 上で iPhone をこの Mac の近くに置いてください。近くにない間は電話プロバイダー経由で発信されます。 |
| Twilio での発信が通らない | トライアルアカウントは認証済みの番号にしか発信できません。Twilio で番号を認証するか、アカウントをアップグレードしてください。 |
| **代わりに電話に出る** で連絡先が認識されない | Enconvo に連絡先へのアクセスを許可するか、連絡先を読み取れる Mac を最初に応答するよう設定してください。 |

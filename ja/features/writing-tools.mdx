ライティングツールは、どのアプリでも選択したテキストに使える、ワンクリックのコマンド集です。間違いの修正、トーンの変更、短くしたり長くしたり、説明や要約、リストや表への変換を、文章を書いているアプリから離れずに行えます。

## 選択したテキストを編集する

1. 文章を書いているアプリでテキストを選択します。
2. [PopBar](/ja/features/popbar) でコマンドをクリックするか、[SmartBar](/ja/features/smartbar) を開いてコマンドを検索します。
3. 結果を確認します。**変更箇所をハイライト** がオンの場合、コマンドが追加した部分と削除した部分が結果に表示されます。
4. **ペースト** をクリックして選択範囲を置き換えるか、結果をコピーします。

どのコマンドも、テキストの言語を保ち、結果だけを返します。**説明** も選択したテキストの言語で回答し、実行のたびに、以前の実行とは無関係に処理します。選択したテキストが質問や指示になっている場合、コマンドはその言葉を編集します。答えることはしません。

<Tip>
信頼できるコマンドには **インラインモード** をオンにすると、ウィンドウを開かずに実行し、結果を選択範囲の上にそのままペーストします。[コマンドを変更する](#コマンドを変更する)を参照してください。
</Tip>

## コマンドを選ぶ

| 目的 | コマンド |
| --- | --- |
| 誤りを直す | スペルと文法を修正、校正 |
| 表現を良くする | 文章を改善、推敲、書き直す、ネイティブ風、AI 編集 |
| 長さを変える | 長くする、短くする、簡潔にする |
| トーンを変える | トーンを変更：フレンドリー、自信、カジュアル、プロフェッショナル |
| 内容を理解する | 説明、要約、要点を抽出 |
| 形式を変える | リストに変換、表に変換 |
| メール | メールを推敲、返信を下書き |
| X の投稿 | X 向けに推敲、280 文字に収める、スレッドにする、X の返信を提案、X の引用コメントを提案 |
| 翻訳 | 翻訳ツール、スクリーンショット翻訳（[翻訳](/ja/ai/translate)を参照） |
| 画面上の内容 | スクリーンショットを説明 |
| 音声入力 | 音声入力の推敲、音声入力の翻訳、音声入力の編集、デバイス上でクリーンアップ（[音声入力](/ja/features/dictation)を参照） |
| 短い表現 | 絵文字 |

**ネイティブ風** は、同じ言語で、ネイティブスピーカーが書くようにテキストを書き直します。**メールを推敲** は、あなた自身の挨拶、結びの言葉、名前を保ち、署名は追加しません。**返信を下書き** は、選択したメールに対する返信を、そのメールの言語とトーンで書き、名前、日付、決定事項など分からない部分には、角括弧で短いプレースホルダを残します。

## コマンドを変更する

**設定 → AI コマンド** を開き、**組み込み** からコマンドを選びます。そのコマンドのページに内容が表示され、**試してみる** で、先にテキストに対して実行してみることができます。

| 設定 | 変更される内容 |
| --- | --- |
| **PopBar** | コマンドを PopBar に追加する、または外す |
| **変更箇所をハイライト** | コマンドが追加した部分と削除した部分を結果に表示する |
| **ホットキー** | どのアプリでも、選択したテキストに対してコマンドを実行する |
| **インラインモード** | ウィンドウを開かずに実行し、結果を選択範囲の上にペーストする |
| **完了後のアクション** | 完了したときに、コマンドが回答をどう扱うか |
| **AI モデル** | このコマンドが使うモデル。デフォルトでは、すべての AI コマンドのモデルに従います |

組み込みコマンドの指示は読み取り専用です。**カスタマイズ** をクリックすると、自分用のコピーが作られ、自由に変更できます。

ライティングツールは、コマンドが独自のモデルを選んでいない限り、**設定 → AI コマンド → すべてのコマンド** で設定したモデルで実行されます。同じコマンドは **設定 → プラグイン → ライティングツール** にも一覧表示され、結果ウィンドウの **設定** ボタンで、その結果を生成したコマンドが開きます。

## 信頼できる結果を得る

書き直しの方向が複数ありえる場合は、誰に向けた文章で、何を達成すべきかを伝えてください。名前、日付、数値、引用した文言など、変えてはいけないものを明示します。

送信する前に、必ず結果を元のテキストと比べてください。流暢な出力でも、意味が変わっていることがあります。

繰り返し使う指示は、自分用の [AI コマンド](/ja/features/ai-commands)を作りましょう。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| コマンドが PopBar にない | PopBar の右端にある **⌄**（収まりきらないボタンが入る場所）をクリックするか、**設定 → AI コマンド** のそのコマンドのページで **PopBar** をオンにします |
| PopBar が表示されない | [PopBar のトラブルシューティング](/ja/features/popbar)を参照してください |
| 結果が想定外の言語になる | 説明は、選択したテキストの言語で回答します。要約は、**応答言語** を設定しない限り、テキストの言語を保ちます。その他のコマンドは、テキストの言語を保ちます |
| 結果で意味が変わった | ペーストする前に編集するか、元のテキストでもう一度コマンドを実行します |

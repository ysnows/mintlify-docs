ライティングツール（Writing Toolkit）は、あらゆるアプリで選択したテキストに対してワンクリックで使えるコマンド集です。今書いているアプリを離れることなく、誤字脱字の修正、トーンの変更、文章の伸縮、説明や要約、リストや表への変換を行えます。

## 選択したテキストを編集する

1. テキストを入力しているアプリで文章を選択します。
2. [PopBar](/ja/features/popbar) のコマンドをクリックするか、[SmartBar](/ja/features/smartbar) を開いてコマンドを検索します。
3. 結果を確認します。**変更箇所をハイライト**がオンの場合、追加または削除された箇所が結果内で強調表示されます。
4. **貼り付け**をクリックして選択範囲を置き換えるか、結果をコピーします。

各コマンドは元のテキストの言語を維持し、結果の文章だけを返します。**説明**も選択されたテキストと同じ言語で回答し、以前の実行内容を引き継がず毎回独立して処理します。選択したテキストが質問文や指示文であっても、これらのコマンドはその質問に答えるのではなく、その文章自体を編集します。

<Tip>
信頼しているコマンドで**インラインモード**をオンにすると、結果ウィンドウを開かずに選択範囲へ結果を直接上書きペーストできます。[コマンドを変更する](#コマンドを変更する)を参照してください。
</Tip>

## コマンドを選ぶ

| 目的 | コマンド |
| --- | --- |
| 誤りを直す | Fix Spelling & Grammar（スペルと文法の修正）、Proofread（校正） |
| 表現を良くする | Improve Writing（文章の改善）、Polish（ブラッシュアップ）、Rewrite（書き直し）、Sound Native（自然なネイティブ表現にする）、AI Edit（AI 編集） |
| 長さを変える | Make Longer（長くする）、Make Shorter（短くする）、Make Concise（簡潔にする） |
| トーンを変える | Change Tone Friendly（親しみやすく）、Confident（自信のある調子に）、Casual（カジュアルに）、Professional（ビジネス向けに） |
| 内容を理解する | Explain（説明）、Summarize（要約）、Extract Key Points（要点を抽出） |
| 形式を変える | Convert to List（リストに変換）、Convert to Table（表に変換） |
| メール | Polish Email（メールを整える）、Draft a Reply（返信の下書きを作成） |
| X への投稿 | Polish for X（X 向けに整える）、Fit in 280 Characters（280 文字に収める）、Turn into a Thread（スレッド形式にする）、Suggest a Reply on X（X の返信案を提案）、Suggest a Quote Comment on X（X の引用コメント案を提案） |
| 翻訳 | Translator（翻訳）、Screenshot Translate（スクリーンショット翻訳）（[翻訳](/ja/ai/translate)を参照） |
| 画面上の内容 | Screenshot Explain（スクリーンショットの説明） |
| 音声入力 | Dictation Polish（音声入力の推敲）、Dictation Translate（音声入力の翻訳）、Dictation Edit（音声入力の編集）、On-Device Cleanup（オンデバイス整形）（[音声入力](/ja/features/dictation)を参照） |
| 短い表現 | Emoji（絵文字） |

**Sound Native** は、同じ言語のままネイティブ話者が書くような自然な表現に書き直します。**Polish Email** は元の挨拶や結びの言葉、あなたの名前を残し、勝手に署名を追加しません。**Draft a Reply** は選択されたメールと同じ言語・トーンで返信を下書きし、コマンドが知り得ない名前・日付・判断事項には角括弧で短いプレースホルダーを残します。

## コマンドを変更する

**設定 → AI コマンド**を開き、**組み込み**の下からコマンドを選びます。コマンドのページでは説明を確認でき、**試してみる**でテキストに対してテスト実行できます。

| 設定 | 変更される動作 |
| --- | --- |
| **PopBar** | コマンドを PopBar に追加または削除します |
| **変更箇所をハイライト** | 結果の中で追加および削除された部分をマーク表示します |
| **ホットキー** | あらゆるアプリで選択したテキストに対してコマンドを実行します |
| **インラインモード** | 結果ウィンドウを開かずに選択範囲へ結果を直接貼り付けます |
| **完了後のアクション** | 回答が生成された後にコマンドが自動で実行する処理を設定します |
| **AI モデル** | このコマンドが使用するモデルです。デフォルトでは「すべてのコマンド」で設定されたモデルに従います |

組み込みコマンドの指示文は読み取り専用です。**カスタマイズ**をクリックすると自分用のコピーが作成され、自由に書き換えられます。

ライティングツールは、コマンド個別に別のモデルが指定されていない限り、**設定 → AI コマンド → すべてのコマンド**で設定されたモデルを使用します。同じコマンドは**設定 → プラグイン → ライティングツール**にも一覧表示されており、結果ウィンドウの**設定**ボタンからはその結果を生成したコマンドの設定画面を直接開けます。

## 安定した結果を得るコツ

書き直し方によって複数の解釈があり得る場合は、誰に向けた文章か、何を達成したい文章かを明記してください。名前、日付、数値、引用表現など、変えてはならない箇所も指定しておくと安心です。

送信前には必ず元の文章と結果を比較してください。自然な文章になっていても、元の意味が変わってしまっていることがあります。

何度も繰り返す指示がある場合は、独自の [AI コマンド](/ja/features/ai-commands)を作成してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| PopBar にコマンドが表示されない | PopBar 末尾の収まりきらなかったボタンが入る **⌄** をクリックするか、**設定 → AI コマンド**内のそのコマンドのページで **PopBar** をオンにしてください |
| PopBar 自体が表示されない | [PopBar のトラブルシューティング](/ja/features/popbar)を参照してください |
| 結果の言語が意図したものと違う | Explain は選択されたテキストの言語で回答します。Summarize は**応答言語**を設定しない限り元のテキストの言語を維持します。その他のコマンドも元のテキストの言語を維持します |
| 意味が変わってしまった | 貼り付ける前に手直しするか、元のテキストを使ってコマンドを再実行してください |

アプリのサイドバーは、アプリウィンドウの横に Enconvo の会話を開きます。そのアプリのコンテキストを使うので、情報を別のチャットにコピーしなくても、読んだり、書いたり、作業したりできます。目の前のアプリについて質問したいときに便利です。

ほかの用途には、手早い質問やコマンドには [SmartBar](/ja/features/smartbar)、履歴やファイルのためにもっと広い場所が必要なときは[チャットウィンドウ](/ja/ai/chat)、選択したテキストを操作するには [PopBar](/ja/features/popbar)、画面に表示したままにできる小さな入口には [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使います。[ウィンドウ管理](/ja/features/window-management)で、すべてを比較できます。

下の動画は、2.5.13 のアプリのサイドバーを紹介します。**⌃⌘E** で Chrome の横に開き、サイトでの動作を設定し、動画の見どころを一覧表示してそこにジャンプし、Finder で選択した写真を圧縮します。

## サイドバーを開く

1. 助けが必要なアプリを最前面にします。
2. **⌃⌘E** を押すか、Enconvo から **アプリのサイドバーを表示** を実行するか、アプリウィンドウの横のハンドルをクリックします。
3. 具体的な質問をし、送信する前に添付されているコンテキストを確認します。

ハンドルは、ポインタがアプリウィンドウの右端に近づくまで隠れていて、ポインタが来た瞬間に表示され、離れた瞬間に隠れます。ハンドルにポインタを合わせると、動画の長さや字幕など、今見ているページのカードが表示されます。ハンドルを常に表示しておくには、**設定 → アプリのサイドバー** またはハンドルの右クリックメニューで、**ハンドルをウインドウの端でのみ表示** をオフにします。Finder のデスクトップでは、Finder ウィンドウが開いていてもいなくても、ハンドルが表示されます。

エージェントモードでは、**権限** チップがエージェントが実行前に確認するタイミングを設定し、**サンドボックス** スイッチがエージェントのコマンドを作業フォルダ内に限定します。[エージェントのサンドボックス](/ja/configuration/sandbox)をご覧ください。

ホットキーは **設定 → アプリのサイドバー** で設定します。以前のバージョンでは **⇧⌘T** でした。変更していなければ、Enconvo が **⌃⌘E** に移行しました。変更するには、[キーボードショートカット](/ja/configuration/keyboard-shortcuts)をご覧ください。

## サイドバーが見られるもの

サイドバーが取得する内容は、アプリと、許可した権限によって変わります。

- ブラウザは、ページのタイトル、URL、内容を提供できます。
- Finder は、選択したファイルを提供できます。
- ほかのアプリは、選択したテキスト、アクセシビリティで取得できるウィンドウの内容、またはスクリーンショットを提供することがあります。

コードエディタは、プロジェクト全体や開いているすべてのファイルを公開するとは限りません。コンテキストが不完全なときは、[Appshots](/ja/features/appshots) を追加するか、ファイルを自分で添付してください。

「選択した段落を説明して」「この下書きをもっと簡潔に書き直すのを手伝って」「このウィンドウに見えているものを説明して」などと頼んでみてください。

### ページカードとスターター

ウェブページでは、新しいサイドバーチャットがそのページのカードで始まります。動画のカードには、長さ、字幕の有無、チャプターの数が表示されます。カードの下には、そのサイト向けのスターターがあります。YouTube では、**この動画を要約してください**、**タイムスタンプ付きで見どころを一覧表示**、**文字起こしを表示** です。クリックすると送信されます。

動画に関する回答では、本文でもタイムラインでも、各時刻がリンクになっています。クリックすると、動画がその時点にジャンプします。カードに表示される動画のチャプターもリンクです。

カードには、記事の長さや PDF のページ数など、ほかのページで読み取れる内容も表示され、サイドバーはページを先読みするので、最初の回答がより早く始まります。タブはそのままの状態で読み取られ、ページの再読み込みや変更、2 つ目のタブを開く、ブラウザのデバッグバーを表示する、といったことは一切ありません。

字幕のない YouTube 動画では、**音声を文字起こし** を選びます。Enconvo が動画の音声を文字起こしし、タイムスタンプ付きで要約します。

チャットの途中でほかのページに移動すると、**表示中のページ** の行が表示されます。クリックすると、新しいページについて質問できます。

独自のスターターを持つ組み込みプロファイルが、YouTube、Bilibili、GitHub、Reddit、Hacker News、X、Amazon、Gmail、Outlook、Stack Overflow に用意されています。これらの回答は、ページが提供する内容に基づきます。

### 拡張機能のない Chromium ブラウザ

[Enconvo Companion 拡張機能](/ja/features/browser-control)のない Chrome、Edge、Brave、Arc などの Chromium ブラウザの横では、サイドバーに **インストール** ボタン付きのカードが表示されます。拡張機能が接続されると、カードはページカードに切り替わります。

### サイトごとの設定

カードのピルには、サイト名と設定の取得元 (**YouTube · 組み込み** など) が表示されます。ピルをクリックすると、そのサイトでのサイドバーの動作を変更できます。

| 設定 | 変更される内容 |
| --- | --- |
| **ページを読む** | 質問に必要なときに、サイドバーがページ全体を読めるようにします。 |
| **回答の言語** | **自分の言語**、または **ページの言語**。 |
| **要約** | **デフォルト**、**時刻付きのチャプター**、**短い段落**、**箇条書き**。 |
| **指示** | このサイトでの回答に対する、あなた独自の指示。 |
| **スターター** | カードの下に表示するスターター。削除するか、**スターターを追加** で新しいものを入力します。 |

何かを変更すると、ピルに **自分のもの** と表示されます。

### Finder のファイル

Finder でファイルを選択し、**⌃⌘E** を押します。スターターは選択した内容に応じて変わります。画像では、**選択した画像を圧縮**、**選択した画像を JPEG に変換**、**選択した画像をリサイズ** です。

サイドバーでは、画像の圧縮、変換、リサイズ、PDF の圧縮、動画と音声の変換、ZIP の圧縮と展開、選択したファイルの一括リネームができます。どの処理も、元のファイルの隣に新しいコピー (名前に `-compressed` が付いたコピーなど) を書き出し、元のファイルはそのまま残します。結果は、処理前後のサイズと **Finderで表示** が付いたカードに表示されます。同じ設定で処理済みのファイルは、もう一度処理せずに保持され、**処理済み** と表示されます。対応していない形式には、わかりやすいメッセージが表示されます。

### アプリに挿入する

Finder、WeCom や Teams などのチャットアプリ、SourceTree などの Git クライアント、Windsurf などのコードエディタ、ターミナル、メモアプリ、Pages、Word には、それぞれ独自のスターターを持つ組み込みプロファイルがあります。

これらのアプリでは、回答に **挿入** ボタンが付くことがあります。クリックすると、返信、コミットメッセージ、コマンドがアプリのテキストフィールドに入ります。挿入しても、送信や実行は行われません。内容を確認して、自分で Return を押します。挿入先のフィールドが見つからない場合は、サイドバーがそのことを知らせます。

### アプリごと、サイトごとのプリセット

**設定 → アプリ** には、サイドバーが対応するアプリごとのプロファイルがあります。

| 設定 | 変更される内容 |
| --- | --- |
| **スクリーンショットを添付** | アプリのウィンドウのスクリーンショットを、アプリのサイドバーのすべてのメッセージに添付します。デフォルトでオンです。 |
| **アプリの完全な状態を添付** | コンパクトな要約の代わりに、アクセシビリティの完全な状態を添付します。トークンを大幅に多く使います。 |
| **スキル**、**MCP サーバー**、**プラグイン** | このアプリ用のプリセット。アプリがアプリのサイドバーの会話をホストしているときに、エージェントに提供されます。 |

**設定 → ウェブサイト** には、ウェブサイト用の同じプリセットがあり、ブラウザが該当するページを開いているときに使われます。

## アプリ内でチャットして操作する

会話を続けたり、新しく始めたり、ウィンドウのコントロールでサイドバーを近くに置いたりできます。アプリのコンテキストは、エージェントが読み取る情報を提供します。エージェントにアプリ内でクリックや入力をしてもらうには、[コンピューター操作](/ja/features/computer-use)または[ブラウザを使用](/ja/features/browser-control)のツールが必要です。

## 設定

**設定 → アプリのサイドバー** を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **アプリのサイドバーを有効にする** | アプリウィンドウの横にハンドルを表示し、ホットキーを有効にします。オフにすると、どちらもなくなります。 |
| **デフォルトエージェント** | サイドバーで回答するエージェント。 |
| **すべてのアプリで隠す** | すべてのアプリで、サイドバーのハンドルを隠します。 |
| **ハンドルをウインドウの端でのみ表示** | ポインタをウィンドウの右端に移動するまで、ハンドルを隠したままにします。デフォルトでオンです。 |
| **以下のアプリが最前面のときはアプリのサイドバーのハンドルを隠す** | ハンドルを隠したままにするアプリ。 |
| **ホットキー** | 最前面のアプリ用にサイドバーを開きます。デフォルトは **⌃⌘E** です。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| サイドバーがアプリに取り付かない | アプリウィンドウを最前面にして、もう一度サイドバーを開いてください。 |
| ハンドルが見つからない | ポインタをウィンドウの右端に移動するか、**ハンドルをウインドウの端でのみ表示** をオフにしてください。 |
| Chromium ブラウザでページカードが表示されない | カードの **インストール** ボタンから、Enconvo Companion 拡張機能をインストールしてください。 |
| **挿入** が表示されない | サイドバーが識別できるテキストフィールドがアプリにありません。代わりに回答をコピーしてください。 |
| アプリのテキストが取得できない | [権限](/ja/configuration/permissions)のアクセシビリティ、ハンドルを隠すアプリ、添付されているコンテキストを確認してください。 |
| 履歴やファイルのためにもっと広い場所が必要 | [チャットウィンドウ](/ja/ai/chat)で続けてください。 |

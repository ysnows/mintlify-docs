アプリのサイドバーは、操作中のアプリウィンドウのすぐ横に Enconvo の会話画面を開きます。そのアプリのコンテキストを自動で取り込むため、別のチャットへ情報をコピーしなくても読み取り・執筆・作業を進められます。いま目の前にあるアプリについて質問したいときに最適です。

用途に合わせて使い分けることもできます。ちょっとした質問やコマンドには [SmartBar](/ja/features/smartbar)、履歴やファイルを広く扱いたいときは[チャットウィンドウ](/ja/ai/chat)、選択したテキストへの操作には [PopBar](/ja/features/popbar)、画面上に常駐する小さな入口としては [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)が便利です。各ウィンドウの違いは[ウィンドウ管理](/ja/features/window-management)で比較しています。

以下の動画では 2.5.13 でのアプリのサイドバーの使い方を紹介しています。**⌃⌘E** で Chrome の横に開き、サイトごとの動作を設定して、動画の重要なポイントをタイムスタンプ付きで一覧表示して該当箇所へジャンプし、最後に Finder で選択した写真を圧縮します。

## サイドバーを開く

1. サポートしてほしいアプリを最前面に表示します。
2. **⌃⌘E** を押すか、Enconvo から **アプリのサイドバーを表示** を実行するか、アプリウィンドウの横にあるハンドルをクリックします。
3. 具体的な質問を入力し、送信前に添付されたコンテキストを確認します。

ハンドルはアプリウィンドウの右端付近にポインタを近づけるまで隠れており、ポインタが近づくと現れ、離れると消えます。ハンドルにポインタを合わせると、動画の長さや字幕の有無など、開いているページに関するカードが表示されます。ハンドルを常に表示したままにするには、**設定 → アプリのサイドバー** またはハンドルの右クリックメニューで **ハンドルをウインドウの端でのみ表示** をオフにします。Finder のデスクトップ上では、Finder ウィンドウを開いているかどうかにかかわらずハンドルが表示されます。

エージェントモードでは、**権限** チップでエージェントが実行前に確認を求めるタイミングを設定でき、**サンドボックス** スイッチでコマンドの実行範囲を作業フォルダ内に制限できます。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。

ホットキーは **設定 → アプリのサイドバー** で変更できます。以前のバージョンでは **⇧⌘T** が使われていましたが、一度も変更していない場合は Enconvo により **⌃⌘E** へ移行されています。変更方法は[キーボードショートカット](/ja/configuration/keyboard-shortcuts)を参照してください。

## サイドバーが読み取れる内容

サイドバーが取得できる情報は、アプリの種類と付与された権限によって異なります。

- ブラウザ：ページのタイトル、URL、ページ内容を取得できます。
- Finder：選択中のファイルを取得できます。
- その他のアプリ：選択されたテキスト、アクセシビリティ経由で読み取れるウィンドウ内容、またはスクリーンショットを取得できます。

コードエディタなどは、プロジェクト全体や開いているすべてのファイルを公開するわけではありません。コンテキストが足りない場合は、[Appshots](/ja/features/appshots) を追加するか、自分でファイルを添付してください。

「選択した段落を説明して」「この下書きをもっと簡潔に書き直すのを手伝って」「このウィンドウに表示されている内容を説明して」などのように質問してみてください。

### ページカードとスターター

ウェブページ上でサイドバーのチャットを新しく開くと、そのページ用のカードが表示されます。動画ページでは、動画の長さ、字幕の有無、チャプター数がカードに表示されます。カードの下にはそのサイト向けのスターターが並びます。YouTube では **この動画を要約してください**、**重要なポイントをタイムスタンプ付きで一覧表示**、**文字起こしを表示** が用意されており、クリックするだけで送信できます。

動画に関する回答では、本文中でもタイムライン上でもすべての時刻がリンクになります。クリックすると動画がその位置へジャンプします。カード上の動画チャプターも同様にリンクになっています。

カードには記事の長さや PDF のページ数など、他ページで読み取れる情報も表示され、最初の回答を素早く始められるようサイドバーが事前にページを読み込みます。現在開いているタブをそのまま読み取るため、ページを再読み込みしたり書き換えたり、別のタブを開いたり、ブラウザのデバッグバーを表示したりすることはありません。

字幕のない YouTube 動画では **音声を文字起こし** を選びます。Enconvo が動画の音声を文字起こしし、タイムスタンプ付きで要約します。

チャット中に別のページへ移動すると、**現在のページ** 行が表示されます。クリックすると新しいページについて質問できます。

YouTube、Bilibili、GitHub、Reddit、Hacker News、X、Amazon、Gmail、Outlook、Stack Overflow には、専用のスターターを備えたビルトインプロファイルがあります。回答は各ページから取得できるコンテンツの内容に基づいて生成されます。

### 拡張機能なしの Chromium ブラウザ

[Enconvo Companion 拡張機能](/ja/features/browser-control)が入っていない Chrome、Edge、Brave、Arc などの Chromium 系ブラウザの横では、**インストール** ボタン付きのカードが表示されます。拡張機能が接続されると、通常のページカードに切り替わります。

### サイトごとの設定

カードのピルには、**YouTube · ビルトイン** のようにサイト名と設定元が表示されます。ピルをクリックすると、そのサイトでのサイドバーの動作を変更できます。

| 設定 | 内容 |
| --- | --- |
| **ページを読む** | 質問で必要なときにサイドバーがページ全体を読み取れるようにします。 |
| **回答の言語** | **自分の言語**、または **ページの言語** を選びます。 |
| **要約** | **デフォルト**、**時刻付きのチャプター**、**短い段落**、**箇条書き** から選びます。 |
| **指示** | このサイトで回答するときの独自の指示を設定します。 |
| **スターター** | カードの下に表示するスターターです。不要なものを削除したり、**スターターを追加** で新しく入力したりできます。 |

何か変更を加えると、ピルの表示が **自分のもの** に変わります。

### Finder でのファイル操作

Finder でファイルを選択してから **⌃⌘E** を押します。選択したファイルに応じたスターターが表示され、画像なら **選択した画像を圧縮**、**選択した画像を JPEG に変換**、**選択した画像のサイズを変更** が並びます。

サイドバーでは選択したファイルに対し、画像の圧縮・変換・リサイズ、PDF の圧縮、動画・音声の変換、zip 圧縮と解凍、一括リネームを行えます。各処理は元のファイルの隣に新しいコピー（名前に `-compressed` が付いたファイルなど）を書き出し、元のファイルはそのまま残します。結果は処理前後のファイルサイズと **Finderで表示** ボタン付きのカードに表示されます。すでに同じ設定で処理済みのファイルは再処理されず **処理済み** と表示され、元のファイルが維持されます。非対応の形式にはわかりやすいエラーメッセージが表示されます。

### アプリへの挿入

Finder、WeCom や Teams などのチャットアプリ、SourceTree などの Git クライアント、Windsurf などのコードエディタ、ターミナル、メモアプリ、Pages、Word には、それぞれ独自のスターターを備えたビルトインプロファイルがあります。

これらのアプリでは、回答に **挿入** ボタンが表示されることがあります。クリックすると返信文、コミットメッセージ、コマンドをアプリのテキスト欄へ直接入力します。挿入しただけで送信や実行はされないため、自分で内容を確認してから Return を押せます。挿入先のテキスト欄をサイドバーが見つけられない場合はその旨を知らせます。

### アプリごと・サイトごとのプリセット

**設定 → アプリ** には、サイドバーが連携する各アプリのプロファイルが保存されています。

| 設定 | 内容 |
| --- | --- |
| **スクリーンショットを添付** | アプリのサイドバーのすべてのメッセージにアプリウィンドウのスクリーンショットを添付します。デフォルトでオンです。 |
| **アプリの完全な状態を添付** | 簡易サマリーの代わりに完全なアクセシビリティ状態を添付します。消費トークン数が大幅に増えます。 |
| **スキル**、**MCP サーバー**、**プラグイン** | そのアプリ向けのプリセットとして設定され、そのアプリ上でアプリのサイドバーの会話を行う際にエージェントへ提供されます。 |

**設定 → ウェブサイト** にはウェブサイト用の同じプリセットが保存されており、ブラウザが該当ページを開いているときに使われます。

## アプリ内でチャットして操作する

会話を続けたり、新しく始めたり、ウィンドウ操作ボタンでサイドバーを近くに保ったりできます。アプリコンテキストはエージェントに読み取る情報を渡すためのものです。あなたの代わりにエージェントがアプリ内でクリックや入力を行うには、[コンピューター操作](/ja/features/computer-use)または[ブラウザを使用](/ja/features/browser-control)ツールが必要です。

## 設定

**設定 → アプリのサイドバー** を開きます。

| 設定 | 内容 |
| --- | --- |
| **アプリのサイドバーを有効にする** | アプリウィンドウ横にハンドルを表示し、ホットキーを有効にします。オフにすると両方とも無効になります。 |
| **デフォルトエージェント** | サイドバーで応答するエージェントです。 |
| **すべてのアプリで非表示** | すべてのアプリでサイドバーのハンドルを隠します。 |
| **ハンドルをウインドウの端でのみ表示** | ウィンドウの右端にポインタを合わせるまでハンドルを隠しておきます。デフォルトでオンです。 |
| **最前面に以下のアプリがあるときはアプリのサイドバーのハンドルを隠す** | ハンドルを表示しないアプリのリストです。 |
| **ホットキー** | 最前面のアプリに対してサイドバーを開くショートカットです。デフォルトは **⌃⌘E** です。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| サイドバーがアプリに追従・接続しない | 対象のアプリウィンドウを最前面に出してから、もう一度サイドバーを開いてください。 |
| ハンドルが見つからない | ウィンドウの右端にポインタを移動するか、**ハンドルをウインドウの端でのみ表示** をオフにしてください。 |
| Chromium ブラウザでページカードが出ない | カードの **インストール** ボタンから Enconvo Companion 拡張機能をインストールしてください。 |
| **挿入** が表示されない | サイドバーが認識できるテキスト欄がアプリ内にありません。代わりに回答をコピーしてください。 |
| アプリのテキストが取得できない | [権限](/ja/configuration/permissions)の「アクセシビリティ」、ハンドルを非表示にするアプリ設定、添付されたコンテキストを確認してください。 |
| 履歴やファイルを扱うスペースが足りない | [チャットウィンドウ](/ja/ai/chat)で続きを進めてください。 |

---
title: "ブラウザを使用"
description: "ブラウザで普段サインインしているタブを、エージェントが読み取って操作できます。"
---

ブラウザを使用すると、Enconvo Companion 拡張機能が接続されているブラウザタブで、エージェントが作業できます。ページの読み取り、コントロールのクリック、フィールドへの入力、結果の確認、タブの管理を、ブラウザにすでにあるサインイン状態のまま行えます。サインイン済みのウェブサイトが必要な作業に使ってください。

## セットアップ

<Steps>
  <Step title="拡張機能をインストールする">
    対応する Chromium 系ブラウザに [Chrome ウェブストアの Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd) をインストールするか、**設定 → ブラウザを使用** の **ブラウザ連携アプリをインストール** をクリックします。ほかのブラウザでは、そのブラウザ向けの拡張機能パッケージを使ってください。
  </Step>
  <Step title="両方を起動したままにする">
    Enconvo とブラウザを開いたままにします。
  </Step>
  <Step title="接続を確認する">
    拡張機能のアイコンをクリックします。ポップアップに **接続済み** とブラウザ名が表示されます。
  </Step>
  <Step title="アクセスを確認する">
    使用するエージェントでブラウザツールが有効になっていることを確認し、拡張機能が確認を求めるウェブサイトを承認します。
  </Step>
  <Step title="読み取り専用のタスクを試す">
    まずは何も変更しないタスクから始めましょう。たとえば「このページを読んで、要点を要約して」と頼みます。
  </Step>
</Steps>

Safari では Chromium 用の拡張機能は使えません。Safari では代わりに[コンピューター操作](/ja/features/computer-use)が画面上でクリックや入力を行うため、すべてのブラウザで同じことができるわけではありません。ポップアップ、接続中のブラウザ、タブの指定、ウェブサイトの承認については[ブラウザ拡張機能](/ja/features/browser-extension)をご覧ください。

## 特定のタブで作業する

リクエストの中でブラウザとページを指定します。

> Edge で、いま開いているドキュメントのタブを読んで、セットアップの 3 つの手順を挙げて。ページは開いたままにして。

エージェントはページを読み取り、要素を選び、操作して、何が変わったかを確認します。ページ移動やライブ更新のあとに、ページ上の要素が変わることがあります。エージェントが要素を見失ったときは、ページをもう一度確認するよう頼んでください。

エージェントが見えないタブで作業している間は、[ピクチャインピクチャ](/ja/features/picture-in-picture)ウィンドウが画面の隅にその様子をライブで表示します。クリックするとそのタブに移動し、操作を引き継げます。

## タスクが終わったとき

エージェントが開いたタブは、そのターンが終わると閉じます。次のタブは開いたままです。

- 結果としてエージェントがあなたに渡したページ
- あなたに引き渡されたタブ
- ピン留めしたタブ
- いま見ているタブ

あなた自身のタブが閉じられることはありません。

## できること

| 分野 | 例 |
| --- | --- |
| ナビゲーション | URL を開く、戻る・進む、再読み込み、条件が整うまで待つ |
| 読み取り | ページの状態、表示されているテキスト、属性、スクリーンショット、選択したコンテンツ |
| 操作 | クリック、入力、フィルイン、選択、キー操作、スクロール、ドラッグ |
| ブラウザの整理 | タブ、ウィンドウ、接続中のセッションの確認と管理 |
| 高度なツール | ページの評価、Cookie、ストレージ、履歴、ブラウザ固有の検査 |

### ページ全体をキャプチャする

エージェントにウェブページ全体のキャプチャを頼めます。たとえば「このページ全体のスクリーンショットをデスクトップに保存して」と伝えます。指定した場所に、ページ本来の解像度で、エージェントのカーソルを含まない PNG ファイルとして保存されます。

### サインインと人間による確認

タスクがサイトのサインインページに到達すると、カードでユーザー名とパスワードの入力を一度だけ求められます。Enconvo はそのサイトにだけ入力し、エージェントがパスワードを見ることはありません。詳しくは[認証情報](/ja/configuration/credentials)をご覧ください。ページに人間による確認が表示されたときは、エージェントがそのタブをあなたに引き渡せます。そのタブでサインインするか確認を済ませたら、**エージェントに戻す** をクリックして引き渡します。

できることは、ブラウザ、ページ、拡張機能のバージョン、オンにしたツールによって異なります。`chrome://` などのブラウザ内ページや制限されたコンテンツには、手が届かない場合があります。

<Warning>
ブラウザを使用は、あなたの実際のアカウントで動作します。タスクが下書きの準備だけか、送信まで行うかを伝えてください。
</Warning>

## 設定

| 設定 | 場所 | 変わること |
| --- | --- | --- |
| **既定のブラウザ** | **設定 → ブラウザを使用**、続いて **⋯** メニューの **設定** | ブラウザを指定しないときにタスクが使うブラウザ。**自動(システムの既定)** は Mac の既定のブラウザに従います。 |
| **ブラウザ拡張機能** | **設定 → ブラウザを使用** | 拡張機能があるブラウザを、それぞれ **接続済み** か **接続解除済み** で一覧表示します。 |
| **ピクチャインピクチャウィンドウ** | **設定 → ブラウザを使用** | エージェントのタブのライブ表示を画面の隅に出すタイミング。**常に**(既定)、**必要なときのみ**、**オフ** から選びます。[ピクチャインピクチャ](/ja/features/picture-in-picture)をご覧ください。 |

タスクの中でブラウザを指定することもできます。

開発者向け:`browser-use/status` Local API ルートが接続状態を返し、**設定 → API** にインストール済みのルートとそのスキーマが一覧表示されます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 接続されない | 拡張機能がオンで Enconvo が起動していることを確認し、ポップアップを見てください。拡張機能は、この Mac 上の Enconvo にポート 11225 経由で接続します。 |
| ブラウザやタブが違う | ブラウザとページを指定し、ページをもう一度確認するよう頼んでください。 |
| クリックや入力に失敗する | いまのページの状態を確認してください。ダイアログ、ページ移動、埋め込みフレームが対象の位置をずらした可能性があります。 |
| スクリーンショットが空白 | タブを前面に出し、ページの読み込みが終わるのを待ってください。 |
| ウェブサイトがサインインを求める | 通常どおりそのサイトにサインインしてください。ブラウザにサインインしていても、すべてのサイトのセッションが有効とは限りません。 |

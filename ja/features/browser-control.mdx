---
title: "ブラウザを使用"
description: "ブラウザに保存されているログイン状態のまま、実際のブラウザタブでエージェントにページの閲覧や操作を行わせます。"
---

「ブラウザを使用」を使うと、Enconvo Companion 拡張機能が接続されたブラウザのタブ上でエージェントが作業できるようになります。すでにログイン済みのセッションをそのまま使い、ページの読み取り、コントロールのクリック、フォーム入力、結果確認、タブ管理を行えます。ログインが必要なウェブサイトでの作業に活用してください。

## セットアップ

<Steps>
  <Step title="拡張機能をインストールする">
    対応する Chromium 系ブラウザに [Chrome ウェブストアから Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd) をインストールするか、**設定 → ブラウザを使用** で **ブラウザコンパニオンをインストール** をクリックします。その他のブラウザでは、そのブラウザ向けの拡張機能パッケージを使用してください。
  </Step>
  <Step title="両方を起動したままにする">
    Enconvo とブラウザの両方を開いた状態にします。
  </Step>
  <Step title="接続を確認する">
    拡張機能のアイコンをクリックします。ポップアップに **接続済み** とブラウザ名が表示されます。
  </Step>
  <Step title="アクセス権を確認する">
    使用するエージェントにブラウザツールが有効になっていることを確認し、拡張機能から確認を求められたウェブサイトを承認します。
  </Step>
  <Step title="読み取り専用タスクを試す">
    「このページを読んで要点をまとめて」のように、何も変更しない作業から試してみてください。
  </Step>
</Steps>

Safari は Chromium 系拡張機能を使いません。Safari では代わりに [コンピューター操作](/ja/features/computer-use) が画面上のクリックや入力を行うため、すべてのブラウザで同じことができるわけではありません。ポップアップ、接続済みブラウザ、タブ指定、ウェブサイトの承認については [ブラウザ拡張機能](/ja/features/browser-extension) を参照してください。

## 特定のタブで作業する

依頼の中でブラウザ名とページを指定します。

> Edge で今開いているドキュメントのタブを読んで、セットアップ手順を 3 つ挙げて。ページは開いたままにして。

エージェントはページを読み取り、要素を選んで操作し、変化を確認します。ページ移動やリアルタイム更新のあとでは要素が変わることがあります。エージェントが要素を見失った場合は、ページを見直すよう伝えてください。

見えていないタブでエージェントが作業している間は、画面の隅に [ピクチャー・イン・ピクチャー](/ja/features/picture-in-picture) ウィンドウでライブ表示されます。クリックするとそのタブへ移動して操作を引き継げます。

## タスク終了時のタブの扱い

エージェントが開いたタブは、ターン終了時に閉じられます。次のタブは開いたまま残ります。

- エージェントが結果としてあなたに提示したページ
- あなたに引き継いだタブ
- ピン留めしたタブ
- あなたが見ているタブ

あなた自身が開いたタブが勝手に閉じられることはありません。

## できること

| 分野 | 例 |
| --- | --- |
| ナビゲーション | URL を開く、戻る・進む、再読み込み、条件を待つ |
| 読み取り | ページ状態、表示テキスト、属性、スクリーンショット、選択中の内容 |
| 操作 | クリック、入力、フォーム記入、選択、キー押下、スクロール、ドラッグ |
| ブラウザ整理 | タブ、ウィンドウ、接続済みセッションの確認と管理 |
| 高度なツール | ページ評価、Cookie、ストレージ、履歴、ブラウザ固有の検証 |

### ページ全体をキャプチャする

「このページ全体のスクリーンショットをデスクトップに保存して」のように頼むと、指定した場所にページ本来の解像度でカーソルなしの PNG 画像として保存されます。

### ログインと人間確認

タスクがサイトのログインページに到達すると、カードが表示されてユーザー名とパスワードを 1 回だけ入力するよう求めます。Enconvo はそのサイトにだけ自動入力を行い、エージェントがパスワードを見ることはありません。詳しくは [認証情報](/ja/configuration/credentials) を参照してください。ページに人間確認（CAPTCHA 等）が表示された場合、エージェントはタブをあなたに引き渡せます。そのタブでログインや確認を済ませてから、**エージェントに戻す** をクリックして作業を戻してください。

実際に動作する範囲は、ブラウザ、ページ、拡張機能のバージョン、有効にしたツールによって異なります。`chrome://` などのブラウザ内部ページや制限されたコンテンツにはアクセスできない場合があります。

<Warning>
ブラウザを使用はあなたの実際のアカウント上で動作します。下書きの準備だけ行うのか、送信まで行うのかを明確に指示してください。
</Warning>

## 設定

| 設定 | 場所 | 内容 |
| --- | --- | --- |
| **デフォルトブラウザ** | **設定 → ブラウザを使用**、次に **⋯** メニューの **設定** | ブラウザを指定しなかったときに使うブラウザ。**自動（システムデフォルト）** は Mac のデフォルトブラウザに従います。 |
| **ブラウザ拡張機能** | **設定 → ブラウザを使用** | 拡張機能が入っているブラウザと、それぞれの **接続済み** / **未接続** を一覧表示します。 |
| **ピクチャー・イン・ピクチャーウィンドウ** | **設定 → ブラウザを使用** | エージェントが作業中のタブを画面隅にライブ表示する条件：**常に表示**（デフォルト）、**必要なときのみ**、または **オフ**。詳しくは [ピクチャー・イン・ピクチャー](/ja/features/picture-in-picture) を参照してください。 |

タスクの指示内でブラウザ名を直接指定することもできます。

開発者向けには、ローカル API ルート `browser-use/status` が接続状態を返し、**設定 → API** でインストール済みルートとスキーマ一覧を確認できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 接続されない | 拡張機能が有効で Enconvo が起動しているか確認し、ポップアップを確認してください。拡張機能はこの Mac 上のポート 11225 を通じて Enconvo に接続します。 |
| 違うブラウザやタブを操作してしまう | ブラウザ名とページを指定し、ページを見直すよう頼んでください。 |
| クリックや入力が失敗する | 現在のページ表示を確認してください。ダイアログ、ページ遷移、埋め込みフレームによって対象位置が動いている可能性があります。 |
| スクリーンショットが真っ白になる | タブを前面に出し、ページの読み込み完了を待ってから再試行してください。 |
| ウェブサイトでログインを求められる | 通常どおりサイトにログインしてください。ブラウザにログインしていても、すべてのサイトのセッションが有効とは限りません。 |

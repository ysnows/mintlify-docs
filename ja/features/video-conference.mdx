ビデオ会議を使うと、Enconvo の中でそのまま相手と顔を見ながら会話したり、画面を共有したりできます。友だちを呼び出したり、チーム全員に発信したり、ブラウザから誰でも開けるリンクを送ったりできます。字幕は自分の言語に翻訳でき、メモ機能が通話を録音して、参加者全員と共有できるメモのドキュメントを作成します。

以下の動画では、ビデオ会議に続いて、他アプリでの会議の録音、ファイルの文字起こし、リアルタイム字幕、話者、音声メモを紹介しています。

<Note>
ビデオ会議の利用には有料プランが必要です。招待リンクから参加するゲストは、Enconvo アカウントやアプリのインストールは不要です。
</Note>

## 会議を始める

チャットウィンドウのサイドバー、Dynamic Island、またはメニューバーのメニューから **ビデオ会議** を開きます。スマートフォンからは iPhone または Android アプリで開始または参加できます（[スマートフォンでの通話と友だち](/ja/integrations/phone-calls-and-friends)を参照）。Mac ではビデオ会議のホーム画面が開きます。

- 上部の入力欄には、参加する会議のリンク、または発信したい友だち・チームメンバーの名前を入力できます。入力して Return を押すか、そのまま今すぐ会議を開始します。
- **予定** には、スケジュールされた会議が表示されます。
- **以前** には過去 1 か月間の通話と録音が一覧表示され、**もう一度かける** で同じ相手に再発信できます。
- **チームに発信** を選ぶと、チームメンバー全員を一度に呼び出せます。

**設定 → ビデオ会議** を開いて **開始** をクリックすることもできます。

## 参加者を招待する

通話中に **メンバー** を開き、友だち、チームメンバー、または自分の他のデバイスを呼び出します。**全員を呼び出す** を押すとチームメンバー全員に発信します。まだ Enconvo にサインインしていないチームメンバーは **Enconvo 未登録** に表示され、**招待リンクをコピー** を利用できます。

それ以外の人を招待するには、`conference.enconvo.com` の会議リンクを送ります。相手はゲストとしてウェブブラウザから参加し、会話やチャットへの書き込み、コンピュータからの画面共有を行えます。

通話だけで知り合った相手には、友だちまたはチームメンバーになるまであなたの名前のみが表示され、メールアドレスは公開されません。

## 友だちに発信する

ホーム画面の入力欄や **設定 → 友だち**（[友だちと友だちチャット](/ja/features/friends)を参照）から友だちに発信すると、会議ウィンドウ内で自分のぼかしたカメラ映像の上に相手の顔が表示され、呼び出し音が鳴ってすぐに発信が始まります。相手が応答すると通話画面には相手の映像だけが表示され、通話内の **チャット** はその相手とのチャットになります。**メンバーを追加** をクリックすると、通話を途切れさせずに複数人の会議へ切り替えられます。

着信画面には **拒否** と **承認** が表示されます。応答できなかった着信には **メッセージ** と **かけ直す** のカードが残ります。すでに通話中のときは他のデバイスが鳴り続け、発信側には別の通話中であることが伝わります。通話中は友だちからのメッセージが通知ではなく画面内の小さな表示として出ます。

## リンクから参加する

Mac またはブラウザで会議リンクを開くと、入室前の準備画面が表示されます。

1. カメラとマイクを確認し、使用するデバイスを選びます。
2. 字幕の有無と字幕の言語、および背景を選択します。
3. ミュート状態で参加するかどうかを選びます。すでに参加している人も確認できます。
4. クリックして参加します。

5 人以上の会議ではマイクがオフの状態で開始され、その理由が表示されます。スマートフォンのブラウザで参加しているゲストが別アプリに切り替えると **離席中** と表示され、通話内の席は最大 5 分間保持されます。

## 会議を予約する

1. **設定 → ビデオ会議** で **会議を予約** をクリックします。
2. **開始日時**、**長さ**、**頻度**（1 回、毎日、平日毎日、毎週、または 2 週間ごと）を選択します。繰り返しの会議でもリンクは共通です。
3. メンバーまたはメールアドレスを追加し、タイトルを付けて保存します。

リンクは変わらないため、事前に共有しておけます。友だちやチームメンバーにはカレンダーファイル付きのメールが届きます。それ以外の人には自分でリンクを送ってください。後から日時、長さ、タイトル、ゲストを変更すると全員に更新通知が届き、会議をキャンセルすることもできます。予約した会議は **予定** に表示され、開始時刻になると **今はしない** と **参加** の通知が出ます。

## 通話中の操作

フローティングドックには、独立した **マイク**、**カメラ**、**字幕** ボタンがあります。1 つのサイドパネルに **チャット**、**メンバー**、**字幕** のタブがまとまっています。

- **レイアウト**：参加者が増えてもギャラリー表示の整列が保たれます。スピーカービューへの切り替え、特定の人のピン留め、クリックでの拡大表示が可能です。1 対 1 の通話では、自分の小窓を四隅の好きな位置へドラッグしたり、クリックして相手と表示を入れ替えたりできます。
- **発言中の表示**：話している人のタイルには緑色の枠と音量バーが表示されます。
- **チャット**：メッセージは全員に送信され、未読件数が表示されます。途中から参加した人も過去のメッセージを読み返せます。最大 1 GB までの画像やファイルを添付、ペースト、ドロップできます。通話内の誰かをクリックすると、その人だけにメッセージを送れます。
- **挙手とリアクション**：挙手した人は手を挙げた順に一覧表示され、リアクションは全員の画面上に浮かびます。
- **ミュート中の発言**：Space キーを長押しすると話せます。ミュートのまま話すと、**ミュート解除** を案内するリマインダーが表示されます。
- **自分の映像**：**自分の表示を隠す**／**自分の映像を表示**、**自分の映像を反転**、および **受信ビデオを停止**（音声と画面共有を維持したまま通信量を節約するため、他の人のカメラ受信を止めます）を選べます。通話中にマイク、スピーカー、カメラを切り替えられ、スマートフォンでは背面カメラへの切り替えも可能です。
- **背景**：参加前または通話中に、ぼかし、シーン、パターン、または手持ちの画像を設定できます。顔の認識が外れると背景マスクが映像全体をぼかすため、意図せず部屋などが映り込むことはありません。

すべてのボタンは Tab キーで移動でき、メニューは矢印キーで操作でき、Enter または Space キーで相手を拡大表示できます。

回線が遅い場合や不安定な場合は、音声が途切れる前に映像を一時停止し、各参加者の回線状況に合った画質・サイズに自動調整されます。自身の回線が不安定なときは通知が表示されます。8 人までの通話では、誰かが参加または退出した際に控えめな効果音が鳴ります。通話に 1 人きりの状態が続くと、自動で終了する前に **まだいますか？** と確認が出ます。

## 画面を共有する

1. ドックの共有ボタンをクリックします。各画面とウィンドウのプレビューがトレイに表示されます。
2. 共有したいものを選びます。Mac アプリからでもブラウザからでも、音声も一緒に共有されます。

Mac では共有中の範囲が緑色の枠で囲まれ、共有バーに **描く**、**ミュート**、**音声を停止**、**共有を停止** が表示されます。小さなウィンドウに現在話している人が表示されますが、共有画面には映り込みません。Enconvo 自身のピッカーやアラート、着信カードは相手に見えないようになっており、フルスクリーン通話から共有を開始するとフルスクリーンが解除されます。

他の参加者は共有画面をフルスクリーンで開いたり、iPhone ではピンチ操作で拡大したりできます。Mac、iPhone、ブラウザのどこからでも共有画面に直接書き込め、描いた線は全員の同じ位置に描いた人の名前付きで表示され、数秒後に消えます。

会議ウィンドウを最小化したり画面を共有したりしているときは、小さなフローティングウィンドウに現在話している人が表示され、ミュート、カメラ、退出、通話画面への復帰を行えます。

## 字幕

通話中に **字幕** を押すとオン／オフを切り替えられます。ドックの上の帯に各発言が表示され、翻訳がオンの場合は選択した言語で翻訳を大きく・原文を小さく表示するか、翻訳のみを表示します。翻訳の生成中はその旨のマークが付きます。

字幕と翻訳は音声エンジンが対応する全 60 言語をカバーしており、言語メニューに名称が並んでいます。

ライブ字幕をクリックすると、誰がいつ何を話したかを翻訳と原文を重ねた状態でさかのぼって確認できます。最新の行へすぐ戻ったり、1 行または全文をコピーしたりできます。この機能は Mac、iPhone、Android で動作します。

## メモと録画

メモ機能は通話を録音し、話者を認識して、AI メモをメモのドキュメントに書き出します。メモがオンになっていることは通話中の全員に表示と音声で通知されます。ドックの **メモ** から各自でオン／オフを切り替えられ、それぞれ自分用のメモのドキュメントが作成されます。

メモをオンにすると、メモパネルにそこまでの文字起こしが表示されます。**AI に質問** を使って通話を要約したり内容について質問したりでき、自分のメモやブックマーク（**⌘B**）を追加すると[録音](/ja/features/meeting-recording)にあるその通話のエントリへ保存されます。

メモには担当者と期限付きのアクションアイテム、通話中にエージェントが作成したドキュメントやホワイトボード、エージェントが共有画面上で確認した内容がまとまります。

主催者は **会議をレコーディング** をクリックして、通話を自身のコンピュータへ動画ファイルとして保存することもできます。録音・録画中であることは通話中の全員およびこれから参加する人にも表示されます。

## 主催者コントロール

会議を開始した人が主催者になります。主催者は次の操作を行えます。

| 操作 | 説明 |
| --- | --- |
| ミュート、**ミュート解除を依頼**、**全員にミュート解除を依頼** | 特定の人または全員をミュートします。依頼しても相手のマイクが勝手にオンになることはありません。 |
| **全員にスポットライト** | 全員の画面で特定の 1 人を大きく表示します。誰でもギャラリー表示に戻せます。 |
| **共有を停止** | 他の人の画面共有を停止します。 |
| 削除 | 会議から退出させます。 |
| **会議をロック** | 新しい参加者を待機室で待たせ、主催者が許可または拒否します。 |
| **ゲストの参加リクエスト** | ゲストが入室する前に許可を求めるようにします。 |
| **主催者にする** | 他の参加者に同じ管理権限を与えます。 |
| **全員に対して終了** | 全員の会議を終了します。 |

**全員に対して終了** と削除の確認ダイアログは、初期状態が **キャンセル** に選択されています。通話内に主催者がいない場合は、最も長く参加している人が **主催者代理** となり、ロックされた会議でも参加を許可できます。

## 会議にエージェントを呼ぶ

**メンバー** からエージェントを会議に呼び込んだり、選んだ会議へ自動的に参加させたりできます。Google Meet や Zoom の会議へ派遣することも可能です。[通話内のエージェント](/ja/features/agents-in-calls)を参照してください。

## 通話が終わったとき

終了画面には通話時間、話した相手、保存された内容が表示され、会議がまだ続いていれば **再参加** も表示されます。

会議ウィンドウの動作が停止した場合は通話が止まった旨を通知し、**再参加** と **閉じる** を表示します。接続が切れて 5 分以内に復帰しない場合は **再参加** が表示されます。通話中、Enconvo は Mac のディスプレイをスリープさせずに維持します。

## 設定

**設定 → ビデオ会議** を開きます。

| 設定 | 説明 |
| --- | --- |
| **マイクをオンにして参加**、**カメラをオンにして参加** | 会議に参加する際の初期状態です。入室前の画面でも変更できます。 |
| **参加時に字幕をオンにする** | 参加直後から字幕を表示します。表示されるのは自分の画面だけです。必要な人がいる間、各話者のデバイスで文字起こしが行われます。 |
| **字幕を翻訳** | 選んだ言語に字幕を翻訳します。**オフ** にすると話された言語のまま表示します。 |
| **自分の通話でメモを取る** | **オフ**、**メモ**、または **メモと録画** から選びます。開始・応答・参加した各通話で自動的に動作します。 |
| **録画・録音** | メモをオンにしたときの初期設定です。**音声**、または **音声と動画** を選びます。 |
| **話者で声を認識** | 声紋から話者の名前を判別します。新しい声は自分で選んだ場合のみ追加されます。[辞書と話者](/ja/configuration/speech-assets)を参照してください。 |
| **メモのドキュメントの共有先** | **通話の参加者** または **自分のみ** を選びます。ドキュメントの所有者はあなたであり、後から変更できます。 |
| **会議でのエージェント** | 選んだ会議にエージェントを参加させます。[通話内のエージェント](/ja/features/agents-in-calls)を参照してください。 |
| **どのアプリからでもミュート／ミュート解除** | どのアプリが最前面にあっても会議中に機能するショートカットです（デフォルトは **⌃⌥M**）。メニューバーの下に短い通知が表示されます。通話外ではこのキーは他のアプリのために空けておきます。 |
| **通話のおやすみモード** | **1 時間**、**明日まで**、または **オフにするまで**、この Mac での着信音を止めます。メッセージの通知は届き、自分から発信や参加をすることはできます。**設定 → 友だち** の月アイコンからも切り替えられます。 |

## 他アプリの会議

Zoom、Teams、FaceTime、WeChat 通話では[会議の録音](/ja/features/meeting-recording)を使います。**設定 → 録音 → 新規録音** でマイク音声、通話音声、または両方をリアルタイム文字起こし付きで録音できます。**新規録音** の横の矢印にある **会議のリマインダー** をオンにすると、これらの通話が始まったときに Dynamic Island で録音するかどうか尋ねます。

Google Meet や Zoom の会議にエージェントを代わりに参加させるには、[通話内のエージェント](/ja/features/agents-in-calls)を参照してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| カメラやマイクが許可されていない | メッセージ上の **システム設定を開く** をクリックして Enconvo を許可してからもう一度お試しください。 |
| 参加時にマイクがオフになっている | 5 人以上の会議ではミュート状態で参加します。**マイク** をクリックするか、Space キーを押しながら話してください。 |
| 参加できない人がいる | 会議がロックされているか、ゲストの承認が必要になっています。待機室から入室を許可してください。 |
| 他の人の映像が止まる | 回線が遅いか、**受信ビデオを停止** がオンになっています。音声と画面共有は継続します。 |
| この Mac で着信音が鳴らない | **設定 → ビデオ会議** の **通話のおやすみモード** を確認してください。 |
| 通話ウィンドウが止まった | ウィンドウ内のメッセージにある **再参加** をクリックしてください。 |

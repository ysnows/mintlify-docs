ビデオ会議では、Enconvo の中で、人と顔を合わせて話したり、画面を共有したりできます。友だちを呼び出す、チーム全体に発信する、ブラウザで誰でも開けるリンクを送る、といったことができます。字幕はあなたの言語に翻訳でき、メモは通話を録音して、通話の全員と共有できるメモのドキュメントを作成します。

このビデオでは、ビデオ会議に続いて、ほかのアプリでの会議の録音、ファイルの文字起こし、リアルタイム字幕、話者、音声メモを紹介します。

<Note>

</Note>

## 会議を開始する

チャットウィンドウのサイドバー、Dynamic Island、またはメニューバーのメニューで**ビデオ会議**を開きます。スマートフォンでは、iPhone または Android アプリから開始または参加します([スマートフォンでの通話と友だち](/ja/integrations/phone-calls-and-friends)をご覧ください)。Mac では、ビデオ会議のホームが開きます。

- 上部のボックスには、参加する会議のリンク、または発信する友だちやチームメイトの名前を入力します。入力して Return を押すか、すぐに会議を開始します。
- **予定**には、予約した会議が一覧表示されます。
- **以前**には、過去 1 か月の通話が録画とともに一覧表示され、**もう一度かける**で同じメンバーを呼び出します。
- **チームに発信**は、チームメイト全員を一度に呼び出します。

**設定 → ビデオ会議**を開いて**開始**をクリックすることもできます。

## メンバーを招待する

通話中に**メンバー**を開き、友だち、チームメイト、またはあなた自身のほかのデバイスを呼び出します。**全員を呼び出す**は、チームメイト全員を一度に呼び出します。Enconvo にまだサインインしていないチームメイトは、**Enconvo 未登録**の下に、**招待リンクをコピー**とともに表示されます。

そのほかの人を招待するには、conference.enconvo.com の会議リンクを送ります。ゲストとして Web ブラウザから参加し、話したり、チャットに入力したり、コンピュータから画面を共有したりできます。

通話でしか知らない相手には、友だちまたはチームメイトになるまで、あなたの名前は見えますが、メールアドレスは見えません。

## 友だちに発信する

ホームのボックス、または**設定 → 友だち**([友だちとフレンドチャット](/ja/features/friends)をご覧ください)から友だちに発信すると、会議ウィンドウですぐに呼び出しが始まり、ぼかしたあなた自身のカメラ映像の上に相手の顔が表示され、呼び出し音が鳴ります。相手が応答すると、通話には相手の映像だけが表示され、その**チャット**は相手とのチャットになります。**メンバーを追加**をクリックすると、途切れることなく会議に切り替わります。

着信には**拒否**と**応答**があります。出られなかった通話は、**メッセージ**と**かけ直す**のあるカードとして残ります。すでに通話中の場合は、ほかのデバイスが鳴り続け、発信者には、あなたがほかの通話中であることが伝わります。通話中は、友だちからのメッセージは、通知ではなく、通話の中の小さなお知らせとして表示されます。

## リンクから参加する

Mac またはブラウザで会議のリンクを開くと、入室前にページが表示されます。

1. カメラとマイクを確認し、使うデバイスを選びます。
2. 字幕と字幕の言語、背景を選びます。
3. ミュートで入室するかどうかを選びます。すでに参加している人も確認できます。
4. クリックして参加します。

5 人以上の会議では、マイクはオフで始まり、その理由が表示されます。スマートフォンのブラウザでは、ほかのアプリに切り替えたゲストは**離席中**と表示され、通話はその席を最大 5 分間保持します。

## 会議を予約する

1. **設定 → ビデオ会議**で、**会議を予約**をクリックします。
2. **開始日時**、**長さ**、**頻度**を選びます。頻度は、1 回、毎日、平日、毎週、2 週間ごとから選べ、すべて 1 つのリンクで使えます。
3. メンバーまたはメールアドレスを追加し、タイトルを付けて保存します。

リンクは変わらないため、今すぐ保存しておけます。友だちとチームメイトには、カレンダーファイル付きのメールが届きます。そのほかの人には、リンクを自分で送ってください。あとから時間、長さ、タイトル、ゲストを変更すると、全員に更新が届きます。会議を取りやめることもできます。予約した会議は**予定**に表示され、開始時には**今はしない**と**参加**が表示されます。

## 通話中

画面下部のフローティングドックには、**マイク**、**カメラ**、**字幕**のボタンがそれぞれ別にあります。1 つのサイドパネルに、**チャット**、**メンバー**、**字幕**のタブがあります。

- **レイアウト**: ギャラリーは、人が参加しても形を保ちます。スピーカービューに切り替える、誰かを固定する、誰かをクリックして大きく表示する、といったことができます。相手が 1 人の通話では、自分の小さな映像を好きな隅にドラッグしたり、クリックして入れ替えたりできます。
- **誰が話しているか**: その人のタイルに、緑のリングとレベルバーが表示されます。
- **チャット**: メッセージは全員に届き、未読の数が表示され、あとから参加した人も読み返せます。画像やファイルを最大 1 GB まで、添付、貼り付け、ドロップできます。通話中の誰かをクリックすると、その人だけにメッセージを書けます。
- **挙手とリアクション**: 挙手は上げた順に一覧表示され、リアクションは全員の画面に浮かびます。
- **ミュート中に話す**: スペースキーを押したままにすると話せます。ミュート中に話すと、リマインダーが**ミュート解除**を提案します。
- **自分の映像**: **自分の表示を隠す**または**自分の映像を表示**、**自分の映像を反転**、**受信ビデオを停止**があります。受信ビデオを停止すると、データ量を節約するため、ほかの人のカメラ映像の受信を止め、音声と共有画面は続きます。マイク、スピーカー、カメラは通話中に選べます。スマートフォンでは、背面カメラに切り替えられます。
- **背景**: ぼかし、シーン、パターン、またはあなた自身の画像を、参加前または通話中に選びます。顔を見失ったときは、マスクが映像全体をぼかすため、誤って何かが映ることはありません。

すべてのボタンは Tab キーで操作でき、メニューは矢印キーで移動し、Enter またはスペースで誰かを大きく表示します。

接続が遅いときや不安定なときは、音が途切れる前に映像が一時停止し、各自の接続に合った映像サイズになります。自分の接続状態が悪いときは、お知らせが表示されます。8 人までの通話では、誰かが参加または退出すると、やわらかい音が鳴ります。通話でしばらく 1 人きりのままだと、通話が自動的に終了する前に、**まだいますか？**と確認されます。

## 画面を共有する

1. ドックで共有をクリックします。トレイに、各画面とウィンドウの画像が表示されます。
2. 1 つ選びます。音声も共有されます。Mac アプリからでも、ブラウザからでも共有できます。

Mac では、共有しているものが緑のフレームで示され、共有バーに**描く**、**ミュート**、**音声を停止**、**共有を停止**があります。話している人は、共有内容に映り込まない小さなウィンドウに表示されます。Enconvo 自身のピッカー、アラート、着信カードは、ほかの人から見える画面に含まれず、フルスクリーンの通話から共有すると、フルスクリーンが解除されます。

ほかの人は、共有された画面をフルスクリーンで開け、iPhone ではピンチで拡大できます。誰でも、Mac、iPhone、ブラウザから、共有画面に描けます。線は全員に同じ位置に表示され、描いた人の名前が付き、数秒後に消えます。

会議を最小化したり、画面を共有したりすると、小さなフローティングウィンドウに、誰が話しているかが表示され、ミュート、カメラ、退出と、通話に戻るクリックができます。

## 字幕

通話中は、**字幕**でオンとオフを切り替えます。ドックの上のバンドに各行が表示されます。翻訳をオンにすると、翻訳が大きく、原文が小さく表示されるか、翻訳だけが、選んだ言語で表示されます。翻訳がまだ届いていない場合は、印が表示されます。

字幕と翻訳は、音声エンジンが対応するすべての言語(全部で 60)をカバーし、言語メニューに名前で一覧表示されます。

ライブ字幕をクリックすると、誰がいつ何を言ったかをさかのぼってスクロールでき、原文の上に翻訳が表示されます。最新の行に戻ったり、1 行または全行をコピーしたりできます。Mac、iPhone、Android で使えます。

## メモと録音

メモは、通話を録音し、誰が話しているかを認識して、AI のメモをメモのドキュメントに書き込みます。通話の全員に、メモがオンであることが見え、聞こえます。各自が、ドックの**メモ**で自分のメモをオンまたはオフにし、自分専用のメモのドキュメントを受け取ります。

メモをオンにすると、メモのパネルに、それまでの文字起こしが表示されます。**AI に質問**で、通話を要約したり、通話についての質問に答えさせたりできます。また、自分のメモとブックマーク(**⌘B**)を追加でき、これらは[録音](/ja/features/meeting-recording)の中のその通話の項目に入ります。

メモには、アクションアイテムごとに担当者と期限が、通話中にエージェントが作成したドキュメントとホワイトボードが、共有画面でエージェントが見たものが一覧表示されます。

主催者は、**会議をレコーディング**をクリックして、通話を自分のコンピュータにビデオファイルとして保存することもできます。通話の全員と、これから参加する人には、録画中であることが表示されます。

## 主催者の操作

会議を開始した人が主催者です。主催者は、次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| ミュート、**ミュート解除を依頼**、**全員にミュート解除を依頼** | 1 人または全員をミュートします。依頼しても、本人に代わってマイクをオンにすることはありません。 |
| **全員にスポットライト** | 1 人を、全員に対して大きく表示します。誰でもギャラリーに戻れます。 |
| **共有を停止** | その人の共有画面を停止します。 |
| 削除 | その人を会議から外します。 |
| **会議をロック** | 新しく来た人は、主催者が入室を許可するか断るまで、待機室で待ちます。 |
| **ゲストの参加リクエスト** | ゲストが入る前に、参加をリクエストするようにします。 |
| **主催者にする** | その人に同じ操作権限を与えます。 |
| **全員に対して終了** | 全員に対して会議を終了します。 |

**全員に対して終了**と削除は、**キャンセル**が選ばれた状態で始まります。通話に主催者がいない場合は、最も長くいる人が**主催者代理**を務めるため、ロックされた入口で待つ人も入室できます。

## 会議でのエージェント

**メンバー**からエージェントを会議に呼び込んだり、選んだ会議にあなたのエージェントを参加させたりできます。Google Meet や Zoom の会議にエージェントを送り込むこともできます。[通話でのエージェント](/ja/features/agents-in-calls)をご覧ください。

## 通話が終わったとき

まとめのページに、通話の長さ、通話した相手、保存された内容が表示され、会議がまだ続いている間は**再参加**も表示されます。

会議ウィンドウが動作しなくなると、通話が停止したことが通知され、**再参加**と**閉じる**が表示されます。接続が切れて 5 分以内に戻らない場合は、**再参加**が表示されます。Enconvo は、通話中、Mac のディスプレイをオンのままにします。

## 設定

**設定 → ビデオ会議**を開きます。

| 設定 | 内容 |
| --- | --- |
| **マイクをオンにして参加**、**カメラをオンにして参加** | 会議にどのように参加するかです。参加前のページで変更することもできます。 |
| **参加時に字幕をオンにする** | 参加するとすぐに字幕を表示します。見えるのはあなただけです。字幕が必要な人がいる間、各話者のデバイスが、その人の言葉を書き起こします。 |
| **字幕を翻訳** | 字幕を、選んだ言語に翻訳します。**オフ**にすると、話されたとおりに表示します。 |
| **自分の通話でメモを取る** | **オフ**、**メモ**、**メモとレコーディング**です。自分が開始、応答、参加する各通話で開始します。 |
| **録音** | メモをオンにしたときに、録音として開始する内容です。**音声**、または**音声と動画**です。 |
| **話者で声を認識** | 声紋から、話している人の名前を付けます。新しい声は、あなたが選んだときにだけ追加されます。[辞書と話者](/ja/configuration/speech-assets)をご覧ください。 |
| **メモのドキュメントの共有先** | **通話の参加者**または**自分のみ**です。ドキュメントはあなたが所有し、あとから変更できます。 |
| **会議でのエージェント** | 選んだ会議にあなたのエージェントを参加させます。[通話でのエージェント](/ja/features/agents-in-calls)をご覧ください。 |
| **どのアプリからでもミュート／ミュート解除** | 会議中は、どのアプリが前面にあっても使えるショートカットです。デフォルトは **⌃⌥M** です。メニューバーの下に短いお知らせが表示されます。通話の外では、そのキーはほかのアプリで使えます。 |
| **通話のおやすみモード** | この Mac での通話の呼び出しを、**1 時間**、**明日まで**、**オフにするまで**停止します。メッセージは通知され、通話の開始と参加もできます。**設定 → 友だち**の月のアイコンでも設定できます。 |

## ほかのアプリでの会議

Zoom、Teams、FaceTime、WeChat の通話には、[会議の録音](/ja/features/meeting-recording)を使います。**設定 → 録音 → 新規録音**は、マイク、通話の音声、またはその両方を、ライブの文字起こしとともに録音します。**新規録音**の横の矢印には**会議のリマインダー**があり、これらの通話が始まったときに、録音するかどうかを Dynamic Island で尋ねます。

エージェントに Google Meet や Zoom の会議へ参加してもらうには、[通話でのエージェント](/ja/features/agents-in-calls)をご覧ください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| カメラまたはマイクが許可されていない | メッセージの**システム設定を開く**をクリックして Enconvo を許可し、もう一度試します。 |
| 参加時にマイクがオフになっている | 5 人以上の会議では、ミュートで入室します。**マイク**をクリックするか、スペースキーを押したまま話します。 |
| 誰かが入室できない | 会議がロックされているか、ゲストの参加リクエストが必要です。待機室から入室を許可します。 |
| ほかの人の映像が止まる | 接続が遅いか、**受信ビデオを停止**がオンです。音声と共有画面は続きます。 |
| 通話がこの Mac で鳴らない | **設定 → ビデオ会議**の**通話のおやすみモード**を確認します。 |
| 通話ウィンドウが動作しなくなる | ウィンドウのメッセージの**再参加**をクリックします。 |

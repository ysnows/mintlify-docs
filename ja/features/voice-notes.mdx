音声メモは、思いついたアイデアを声で録音してナレッジベースに保存し、後から検索できるようにする機能です。別のアプリへ文字として直接入力したい場合は[音声入力](/ja/features/dictation)を使ってください。

## はじめる前に

メモを保存する[ナレッジベース](/ja/ai/knowledge-base)を作成または選択しておきます。音声メモのホットキーは設定するまで未割り当てになっています。

## ホットキーを設定する

1. **設定 → 音声メモ** を開きます。
2. **音声メモのホットキー** をクリックし、使いたいショートカットを押します。押しっぱなしにするか、押して切り替えるかを選びます。
3. **保存先** にメモを保存するナレッジベースを設定します。初期設定は **デフォルトのナレッジベース** です。

## メモを録音する

1. **音声メモのホットキー** を押し、短いメモを話します。長押しモードでは話している間ショートカットを押し続けます。
2. ショートカットを離すか録音コントロールを使って録音を終了すると、メモが保存されます。
3. 保存先のナレッジベースを開き、保存された項目と文字起こし結果を確認します。

## 後から見つけやすくする

録音するときは「プロジェクト Atlas：デザイナーに新しいオンボーディングアイコンを依頼する」のように、件名や固有名詞を口に出して入れておくと検索しやすくなります。文字起こしされた重要な名前、数字、日付をそのまま使う前に間違いがないか確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ホットキーを押しても反応しない | **音声メモのホットキー** を設定し、**設定 → クイックキャプチャ** で **クイックキャプチャを有効にする** がオンになっているか確認してください。このスイッチがクイックキャプチャと音声メモ両方のホットキーを有効にします。 |
| 音声が入らない | マイクの権限と選択中の入力デバイスを確認してください。 |
| 想定した場所にメモが保存されない | **設定 → 音声メモ** の **保存先** を確認してください。 |
| 文字起こしに失敗する | 同じメモを録音し直す前に、エラーメッセージを読んで設定済みの音声認識プロバイダーを確認してください。 |

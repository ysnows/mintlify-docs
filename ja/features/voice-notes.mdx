音声メモは、話したアイデアをナレッジベースに録音し、あとで見つけられるようにします。代わりに、ほかのアプリにテキストを入力したい場合は、[音声入力](/ja/features/dictation)を使います。

## はじめる前に

メモ用の[ナレッジベース](/ja/ai/knowledge-base)を作成するか、選択します。音声メモは、設定するまでホットキーがありません。

## ホットキーを設定する

1. **設定 → 音声メモ**を開きます。
2. **音声メモのホットキー**をクリックして、使いたいショートカットを押します。押したままにするか、押すだけにするかを選びます。
3. **保存先**に、メモを入れるナレッジベースを設定します。最初は**デフォルトのナレッジベース**です。

## メモを録音する

1. **音声メモのホットキー**を押して、短いメモを話します。押したままにするモードでは、話している間、ショートカットを押し続けます。
2. ショートカットを離すか、録音のコントロールを使って、録音を終えます。メモが保存されます。
3. 保存先のナレッジベースを開き、保存された項目とその文字起こしを確認します。

## メモを見つけやすくする

録音の中で、件名や役に立つ名前を話します。たとえば「Project Atlas の件、デザイナーに更新したオンボーディングのアイコンをお願いする」のように話します。重要な名前、数字、日付は、頼りにする前に、文字起こしで確認してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ホットキーが反応しない | **音声メモのホットキー**を設定し、**設定 → クイックキャプチャ**の**クイックキャプチャを有効にする**がオンになっていることを確認します。このスイッチは、クイックキャプチャと音声メモの両方のホットキーをオンにします。 |
| 音声がない | マイクの権限と、選択した入力デバイスを確認します。 |
| メモが想定した場所にない | **設定 → 音声メモ**の**保存先**を確認します。 |
| 文字起こしに失敗する | 同じメモをもう一度録音する前に、エラーを読み、設定した音声プロバイダーを確認します。 |

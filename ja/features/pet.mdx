---

デスクトップペットは、デスクトップに置く小さなアニメーションのキャラクターです。エージェントの動きを映し、ライブのセッションカードを表示し、対応が必要なセッションへ案内します。クリックすると、質問したり Enconvo を開いたりできます。エージェントにキャラクターと会話用の声を与える[アバター](/ja/features/avatar)とは別の機能です。

ほかの用途には、手早い質問やコマンドには [SmartBar](/ja/features/smartbar)、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、1 つのアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択したテキストを操作するには [PopBar](/ja/features/popbar)、画面上部のコンパクトな入力欄には [Dynamic Island](/ja/features/dynamic-island) を使います。[ウィンドウ管理](/ja/features/window-management)で、すべてを比較できます。

## ペットを選ぶ

1. **設定 → ペット** を開きます。
2. **マイペット** でキャラクターを選ぶか、**ギャラリー** で探します。
3. **ペットを起こす** をクリックして、デスクトップに表示します。
4. **タップしたときに開く** で、ペットをクリックしたときに表示するものを設定します。
5. **セッションカードを表示** のオンとオフを切り替え、**ペットのサイズ** を調整します。
6. デスクトップに戻ってペットをクリックします。手順 4 で選んだものが開きます。

## 設定

| 設定 | 変更される内容 |
| --- | --- |
| **ペットを起こす** / **ペットをしまう** | デスクトップ上のペットを表示または非表示にします。 |
| **タップしたときに開く** | ペットをクリックしたときに表示するもの: **質問ボックス** (デフォルト)、**Dynamic Island**、**チャットウィンドウ**、**Smart Bar**。 |
| **回答に使うエージェント** | ペットへの質問に回答するエージェント。質問ボックスでも変更できます。 |
| **セッションカード** | ペットの下に表示される、ライブのセッションステータスカード。 |
| **ペットのサイズ** | ペットの大きさ。 |

## カスタムペット

**マイペット** タブの **カスタムペット** には、ペットのパッケージを保存するフォルダが表示されます。**フォルダを開く** をクリックし、対応する形式のペットパッケージを追加して、**マイペット** でそのペットを選びます。キャラクターの画像だけでは、アニメーションするペットのパッケージにはなりません。

ペットを削除するには、そのカードの **削除** をクリックします。パックはライブラリから削除されますが、ギャラリーからもう一度インストールできます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ペットがデスクトップにいない | **ペットを起こす** をクリックし、**マイペット** でペットが選択されていること、**ペットのサイズ** を確認します。 |
| ペットをクリックすると違うウィンドウが開く | **タップしたときに開く** を変更します。 |
| 1 つのエージェントに音声での会話やキャラクターがほしい | 代わりに[アバター](/ja/features/avatar)を使ってください。 |

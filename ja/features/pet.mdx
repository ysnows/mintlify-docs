---

デスクトップペット（Desktop Pet）は、デスクトップ上に常駐する小さなアニメーションキャラクターです。エージェントの稼働状況に合わせて動き、ライブセッションカードを表示したり、対応が必要なセッションへすぐ移動したりできます。クリックすると質問したり Enconvo を開いたりできます。会話用のキャラクターと声を与える[アバター](/ja/features/avatar)とは別の機能です。

他の用途では、素早い質問やコマンドには [SmartBar](/ja/features/smartbar)、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、特定のアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択テキストの操作には [PopBar](/ja/features/popbar)、画面上部のコンパクトな入力欄には [Dynamic Island](/ja/features/dynamic-island) を使います。すべての比較は[ウィンドウ管理](/ja/features/window-management)をご覧ください。

## ペットを選ぶ

1. **設定 → ペット**を開きます。
2. **マイペット**でキャラクターを選ぶか、**ギャラリー**から見つけます。
3. **ペットを起こす**をクリックしてデスクトップに表示します。
4. **タップしたときに開く**で、ペットをクリックしたときに開く画面を選びます。
5. **セッションカードを表示**のオン・オフを切り替え、**ペットのサイズ**を調整します。
6. デスクトップに戻ってペットをクリックすると、ステップ 4 で選んだ画面が開きます。

## 設定

| 設定 | 変わる動作 |
| --- | --- |
| **ペットを起こす** / **ペットをしまう** | デスクトップ上のペットを表示または非表示にします。 |
| **タップしたときに開く** | ペットをクリックしたときに開くもの：**質問ボックス**（デフォルト）、**Dynamic Island**、**チャットウィンドウ**、**Smart Bar**。 |
| **回答に使うエージェント** | ペットに尋ねたときに回答するエージェントです。質問ボックス側でも変更できます。 |
| **セッションカード** | ペットの下に表示されるライブセッション状況カードです。 |
| **ペットのサイズ** | ペットの表示サイズです。 |

## カスタムペット

**マイペット**タブの**カスタムペット**には、ペットパッケージを保存するフォルダが表示されます。**フォルダを開く**をクリックし、対応形式のペットパッケージを追加してから、**マイペット**でそのペットを選択してください。単体のキャラクター画像だけではアニメーション付きのペットパッケージにはなりません。

ペットを削除するには、カードの**削除**をクリックします。ライブラリからパッケージが削除されますが、ギャラリーからいつでも再インストールできます。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| デスクトップにペットがいない | **ペットを起こす**をクリックし、**マイペット**でペットが選択されていることと、**ペットのサイズ**を確認してください。 |
| ペットをクリックしても意図しないウィンドウが開く | **タップしたときに開く**の設定を変更してください。 |
| 音声会話や特定エージェント用のキャラクターを使いたい | 代わりに[アバター](/ja/features/avatar)を使用してください。 |

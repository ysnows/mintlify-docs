---
title: "Appshots"
description: "ホットキー 1 つで最前面にあるアプリウィンドウを次の質問に追加します。"
---

Appshots は、最前面に表示されているアプリのウィンドウをチャットにコンテキストとして追加する機能です。ナレッジベースに保存するほどではない画面上の内容について質問したいときに使います。

## アプリウィンドウをキャプチャする

1. 質問したいアプリを最前面に表示します。
2. Appshots のホットキーを押します。ホットキーは初期状態では未設定のため、**設定 → Appshots** の **ホットキー** で設定してください。
3. SmartBar、チャットウィンドウ、またはアプリのサイドバーのいずれかが前面に開いている場合はそこへ、それ以外の場合は Dynamic Island へウィンドウが送られます。短いシャッター音が鳴ります。
4. 添付されたウィンドウを確認し、「このウィンドウのエラーを説明して」のように具体的な質問をします。

## 設定

**設定 → Appshots**を開きます。

| 設定 | 働き |
| --- | --- |
| **Appshotsを有効にする** | ホットキーで最前面のアプリウィンドウを追加できるようにします。初期設定はオンです。 |
| **音声を録音** | Appshot が追加されたときに短いシャッター音を鳴らします。音でキャプチャされたことが分かりますが、送信前にも添付内容を確認してください。 |
| **ホットキー** | ウィンドウを追加するショートカットです。初期設定はなしです。左右両方の **Option** キー同時押しなどの修飾キーの組み合わせや、通常のショートカットを設定できます。 |

## 目的に合ったキャプチャツールを選ぶ

| 目的 | 使う機能 |
| --- | --- |
| 現在のアプリウィンドウについて質問する | Appshots |
| 質問する前に特定の領域を囲って強調する | [Screen Doodle](/ja/features/screen-doodle) |
| 後で検索できるよう現在のアプリの内容を保存する | [クイックキャプチャ](/ja/features/quick-capture) |
| 画像からテキストを抽出する | [OCR](/ja/ai/ocr) |

キャプチャした内容は、リクエストの処理に使うモデルへ送信されます。コンテキストを追加する他の方法については[コンテキスト認識](/ja/features/context-awareness)を参照してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| コンテキストが表示されない | **設定 → 権限**、特に画面収録とアクセシビリティを確認してください。 |
| 意図しないウィンドウがキャプチャされる | 対象のアプリをもう一度最前面に出してください。Appshots は Enconvo 自身の設定ウィンドウなどではなく、他のアプリのウィンドウをキャプチャします。 |
| ホットキーを押しても何も起きない | **Appshotsを有効にする**がオンになっていることと、**ホットキー**が設定されていることを確認してください。 |
| ホットキーで別の動作が起きてしまう | 他のアプリが同じキーを使っています。**設定 → Appshots**で**ホットキー**を変更してください。 |

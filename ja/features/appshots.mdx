---
title: "Appshots"
description: "1 つのホットキーで、前面のアプリのウィンドウを、次の質問に追加します。"
---

Appshots は、前面にあるアプリのウィンドウを、コンテキストとしてチャットに追加します。ナレッジベースに保存せずに、画面上のものについて質問したいときに使います。

## アプリのウィンドウをキャプチャする

1. 質問したいアプリを前面に出します。
2. Appshots のホットキーを押します。Appshots には、**設定 → Appshots**の**ホットキー**で設定するまで、ホットキーがありません。
3. ウィンドウは、SmartBar、チャットウィンドウ、アプリのサイドバーのいずれかが前面で開いている場合は、そこに送られます。そうでない場合は、Dynamic Island に送られます。短いシャッター音が鳴ります。
4. 添付されたウィンドウを確認し、「このウィンドウのエラーを説明して」のように、具体的な質問をします。

## 設定

**設定 → Appshots**を開きます。

| 設定 | 内容 |
| --- | --- |
| **Appshotsを有効にする** | ホットキーで、最前面のアプリのウィンドウを追加できるようにします。デフォルトでオンです。 |
| **キャプチャ音** | Appshot が追加されたときに、短いシャッター音を鳴らします。この音はキャプチャの確認です。送信する前に、添付内容も確認してください。 |
| **ホットキー** | ウィンドウを追加するショートカットです。デフォルトでは設定されていません。両方の **Option** キーを同時に押すような修飾キーの組み合わせでも、通常のショートカットでもかまいません。 |

## 適切なキャプチャツールを選ぶ

| 目的 | 使うもの |
| --- | --- |
| 現在のアプリのウィンドウについて質問する | Appshots |
| 質問する前に、領域に注意を引く | [画面に描画](/ja/features/screen-doodle) |
| 現在のアプリの内容を、あとで検索できるように保存する | [クイックキャプチャ](/ja/features/quick-capture) |
| 画像からテキストを抽出する | [OCR](/ja/ai/ocr) |

キャプチャした内容は、リクエストに使うモデルに送られることがあります。コンテキストを追加するそのほかの方法は、[コンテキスト認識](/ja/features/context-awareness)をご覧ください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| コンテキストが表示されない | **設定 → 権限**、特に画面収録とアクセシビリティを確認します。 |
| 違うウィンドウがキャプチャされる | 対象のアプリを、もう一度前面に出します。Appshots がキャプチャするのは、ほかのアプリのウィンドウで、設定など Enconvo 自身のウィンドウではありません。 |
| ホットキーが反応しない | **Appshotsを有効にする**がオンで、**ホットキー**が設定されていることを確認します。 |
| ホットキーがほかの動作をする | ほかのアプリが同じキーを使っています。**設定 → Appshots**で**ホットキー**を変更します。 |

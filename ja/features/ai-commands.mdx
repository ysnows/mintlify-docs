AI コマンドは、繰り返し使うプロンプトをモデルや設定とセットでまとめ、任意のテキストに対してワンクリックで実行できるようにする機能です。サポート返信の書き直しのような単一の作業に向いています。ツールを使う幅広い作業には[エージェント](/ja/ai/agents)、複数ステップの連続処理には[ワークフロー](/ja/workflows/introduction)をお使いください。

## コマンドを作成する

1. **設定 → AI コマンド**を開くか、SmartBar から **Create AI Command** を実行し、**新しい AI コマンド**をクリックします。
2. コマンドにさせたいことを自分の言葉で入力し、**下書き作成**をクリックします。Enconvo がタイトル・アイコン・指示を作成し、サンプル入力で即座にテスト実行します。
3. サンプル欄に自分のテキストを貼り付け、**もう一度試す**をクリックして実際の入力での結果を確認します。
4. 動作を調整したい場合は、**変更したい点**に「担当者ごとにグループ化して」などと入力して**再作成**をクリックします。変更された行が指示内でハイライトされ、サンプル結果が再実行されます。
5. **使用する場所**で、テキスト選択時に PopBar ボタンを出したい場合は **PopBar に追加**をオンのままにするか、**ホットキーを追加**をクリックして好きなキーを押します。
6. **保存**をクリックします。

指示の例：

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## コマンドを実行する

- **PopBar から：** 任意のアプリでテキストを選択し、コマンドのボタンをクリックします。結果が出たら**貼り付け**をクリックして選択範囲を置き換えます。
- **ホットキーから：** テキストを選択してコマンドのホットキーを押します。結果が SmartBar で開き、貼り付けられます。
- **SmartBar から：** コマンドのタイトルを検索し、現在の入力に対して実行します。
- **エージェントから：** チャットでエージェントにコマンドの実行を頼みます。コマンドが終わると、エージェントはそのチャットを続行します。

翻訳などの組み込みコマンドや自作コマンドを含め、AI コマンドから開いたチャットはチャットウィンドウ、Dynamic Island の**履歴**、SmartBar のチャット一覧には表示されません。

## コマンドを変更する

**設定 → AI コマンド**でコマンドを開くと、タイトルと指示を編集できます。変更は入力と同時に自動保存されます。

| 設定 | 変更される内容 |
| --- | --- |
| **PopBar** | コマンドを PopBar に表示するかどうかを切り替えます。 |
| **ホットキー** | 任意のアプリで選択したテキストに対してコマンドを実行するキー。 |
| **インラインモード** | ウィンドウを開かずに実行し、結果で選択テキストを直接置き換えます。 |
| **実行後のアクション** | 完了後に回答をどう扱うか（対応している場合）。 |
| **AI モデル** | すべての AI コマンド用モデルに従うか、このコマンド専用のモデルを使うかを表示します。変更するには**変更**をクリックします。 |

### すべてのコマンドで使うモデルを選ぶ

AI コマンドは、別のモデルを選ばない限り Enconvo Fast で動作します。変更するには**設定 → AI コマンド**を開き、**すべてのコマンド**をクリックします。ここで設定する **AI モデル**は、文章作成ツール、PopBar、音声入力の**推敲**と**翻訳**でも使われます。**推奨を使用**で Enconvo Fast に戻ります。独自のモデルを指定しているコマンドはそのまま維持され、**確認**から一覧を見たり、**すべてに … を使用**でまとめてこのモデルへ切り替えたりできます。

組み込みコマンドには代わりに**カスタマイズ**が表示され、編集可能な自分用のコピーを作れます。自作コマンドの **⋯** メニューには**複製**と**削除**があります。コマンドを削除すると PopBar からも外れ、ホットキーも解放されます。

## 動的なコンテキストを使う

変数に対応している入力欄では、変数ピッカーを使って入力テキスト、選択中のテキスト、最前面のアプリなどのコンテキストを埋め込めます。詳しくは[変数](/ja/workflows/variables)をご覧ください。機密文書に対してコマンドを使う前に、展開されるコンテキストの内容を確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| コマンドが見つからない | 保存済みか確認し、タイトルで検索してください。 |
| 出力が選択テキストを無視する | コマンドの入力・コンテキスト設定、および[権限](/ja/configuration/permissions)のアクセシビリティを確認してください。 |

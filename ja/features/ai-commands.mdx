AI コマンドは、繰り返し使うプロンプトをモデルや設定と一緒にまとめたもので、どんなテキストにもワンクリックで実行できます。サポートへの返信の書き直しのように、用途が決まっている作業に使います。ツールを使う幅広い作業には[エージェント](/ja/ai/agents)を、一連のステップには[ワークフロー](/ja/workflows/introduction)を使ってください。

## コマンドを作成する

1. **設定 → AI コマンド**を開くか、SmartBar で **AI コマンドを作成**を実行して、**AI コマンドを新規作成**をクリックします。
2. コマンドにさせたいことを自分の言葉で説明し、**生成**をクリックします。Enconvo がタイトル、アイコン、指示を書き、すぐに例に対して実行します。
3. サンプルに自分のテキストの一部を貼り付けて**もう一度試す**をクリックすると、実際の入力での結果が確認できます。
4. 動作を変えるには、**変更したいことはありますか？**に変更内容を入力します（たとえば「担当者ごとにまとめて」）。そして**再生成**をクリックします。指示の中で変更された行に印が付き、サンプルの結果が再び実行されます。
5. **使う場所**で、**PopBar に追加**をオンのままにすると、テキストを選択するたびに PopBar にボタンが表示されます。または**ホットキーを追加**をクリックして、使いたいキーを押します。
6. **保存**をクリックします。

指示の例：

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## コマンドを実行する

- **PopBar から：** 任意のアプリでテキストを選択し、コマンドのボタンをクリックします。結果が表示されたら、**ペースト**をクリックして選択範囲を置き換えます。
- **ホットキーから：** テキストを選択して、コマンドのホットキーを押します。結果が SmartBar に表示されるので、そこからペーストできます。
- **SmartBar から：** コマンドのタイトルを検索して、現在の入力に対して実行します。
- **エージェントから：** チャットでエージェントにコマンドの実行を頼みます。コマンドが終わると、エージェントはあなたのチャットを続けます。

AI コマンドのチャットは、翻訳などの組み込みのものも自分で作ったものも、チャットウィンドウ、Dynamic Island の**履歴**、SmartBar のチャット一覧には表示されません。

## コマンドを変更する

**設定 → AI コマンド**でコマンドを開くと、タイトルと指示を編集できます。変更は入力と同時に保存されます。

| 設定 | 変更される内容 |
| --- | --- |
| **PopBar** | コマンドを PopBar に表示するか、外します。 |
| **ホットキー** | 任意のアプリで選択したテキストに対してコマンドを実行するキー。 |
| **インラインモード** | ウィンドウを開かずに実行し、結果を選択範囲に貼り付けます。 |
| **完了後のアクション** | コマンドが終わったあと、答えをどうするか（選択肢がある場合）。 |
| **AI モデル** | コマンドがすべての AI コマンド共通のモデルに従うか、専用に選んだモデルを使うかを表示します。**変更**をクリックして選びます。 |

### すべてのコマンドのモデルを選ぶ

AI コマンドは、ほかのモデルを選ばない限り Enconvo Fast で実行されます。変更するには、**設定 → AI コマンド**を開き、**すべてのコマンド**をクリックします。**AI モデル**のモデルは、ライティングツール、PopBar、音声入力の**推敲**と**翻訳**も実行します。**おすすめを使う**で Enconvo Fast に戻せます。専用のモデルを選んでいるコマンドは、このモデルを変えてもそのモデルのままです。**確認**をクリックすると一覧が表示され、**すべてに … を使う**をクリックすると、それらをこのモデルに切り替えられます。

組み込みコマンドには、代わりに**カスタマイズ**が表示されます。これは自分用のコピーを作り、編集できるようにします。自分で作ったコマンドには、**複製**と**削除**がある **⋯** メニューがあります。コマンドを削除すると、PopBar からも外れ、ホットキーも解放されます。

## 変化するコンテキストを使う

変数に対応しているフィールドでは、変数ピッカーを使って、入力テキスト、選択したテキスト、アクティブなアプリ、そのほかのコンテキストを含められます。[変数](/ja/workflows/variables)をご覧ください。非公開のドキュメントでコマンドを使う前に、展開されたコンテキストを確認してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| コマンドが見つからない | 保存されているか確認し、タイトルで検索してください。 |
| 出力が選択したテキストを無視する | コマンドの入力とコンテキストの設定、および[権限](/ja/configuration/permissions)のアクセシビリティを確認してください。 |

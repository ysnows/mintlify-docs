PopBar は、あらゆるアプリでテキストを選択したときにすぐ横に表示される小さなツールバーです。ボタンを使って選択範囲の説明、翻訳、編集、検索、コピー、読み上げができ、[PopBar 拡張機能](#popbar-拡張機能)を追加すると、ウェブ検索やテキスト変換、他アプリへの送信などの機能も増やせます。操作したいテキストがすでに画面上にあるときに最適です。

他の用途では、素早い質問やコマンドには [SmartBar](/ja/features/smartbar)、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、特定のアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、画面に常駐する小さな入口には [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使います。すべての比較は[ウィンドウ管理](/ja/features/window-management)をご覧ください。

以下のチュートリアル動画では、PopBar のセットアップから活用までを 6 分で解説しています（有効化、表示タイミングの選択、「スペルを修正」・「翻訳」・「AI に質問」の実行、インラインモードの利用、ボタンの追加と並べ替え、独自の AI コマンドの作成、PopBar 拡張機能の入手と作成）。

## PopBar を使う

1. **設定 → PopBar** を開き、**PopBarを有効にする**をオンにします。
2. アプリ内で短い文章を選択します。
3. ツールバー上のボタンをクリックします。
4. コピー、貼り付け、置換などの操作を使う前に結果を確認します。

ショートカットから PopBar を開くこともできます。**PopBar を表示**を実行するか、**表示するタイミング**タブで**ホットキー**を設定してください。ツールバーを閉じるには Escape キーを押します。

PopBar はアクセシビリティ権限を使って選択範囲を読み取るため、取得できる内容はアプリによって異なります。パスワードなどの保護された入力欄や一部のカスタムエディタではテキストを取得できません。

## 音声で質問する

入力欄に「選択したテキストについて質問…」と表示された質問パネルが開いているときは、入力する代わりに声で質問できます。

1. 入力欄のマイクボタンをクリックするか、[音声コマンド](/ja/features/dictation)のホットキーを押します。入力欄に**受信中…**と表示され、話した内容が文字起こしされます。
2. 話し終えたらボタンをもう一度クリックするか、押し続けていたホットキーを離します。質問が送信されます。

送信せずに聞き取りを中止するには Escape キーを押します。話す前に入力していた文字は、話した内容の前にそのまま残ります。

## ボタンを選ぶ

PopBar 設定の**ボタン**タブには、バー上のボタンが一列に表示されます。ボタンをドラッグして並び替えたり、カーソルを合わせて **×** をクリックして外したり、ボタンをクリックして詳細オプションを開いたりできます。**デフォルトに戻す**で初期状態のボタンに戻ります。

バーに収まりきらないボタンは末尾の **⌄** の下に格納されます。**⌄** をクリックすると**その他**パネルが開き、それらのボタンと、すべてのボタンや設定を対象とした検索欄が表示されます。ボタンを変更した後は、**PopBar をオフにする**の下にも**デフォルトに戻す**が表示され、**元に戻す**付きで初期のボタンと並び順に戻せます。

**ボタンを追加**をクリックするとボタンギャラリーが開きます。AI に質問、サイドバーで質問、リンクを開く、検索、コピー、翻訳、説明、スペルを修正、AI 編集、読み上げなどのほか、[PopBar 拡張機能](#popbar-拡張機能)のアクションや、独自の [AI コマンド](/ja/features/ai-commands)を作成する機能も並んでいます。自分専用の編集ワークフローとして[ライティングツール](/ja/features/writing-tools)のコマンドを追加することもできます。追加したボタンがツールバーに表示されます。

## 表示場所をコントロールする

**表示するタイミング**タブでは、PopBar が現れる条件を設定します。

| 設定 | 働き |
| --- | --- |
| **対象のテキスト** | 選択したすべてのテキストで PopBar を表示するか、外国語・コード・メールなど PopBar が役立つテキストのときだけ表示するかを選びます。 |
| **場所** | **次の場所以外すべて**を選び、**アプリを追加**または**ウェブサイトを追加**で特定のアプリやサイトを除外します。または**次の場所のみ**を選び、指定した場所だけで表示させます。 |
| **テキスト選択時に表示** | これをオフにすると、呼び出したときだけ PopBar が表示されるようになります。そのうえで**ホットキーを追加**をクリックしてショートカットを設定します。 |

Terminal など、自動表示のツールバーが作業の邪魔になるアプリは除外しておくと便利です。

## 見た目を変更する

**外観**タブの**レイアウト**では、選択範囲の上に一列に並べる（**横型**）か、ポインタの横に縦一列に並べる（**縦型**）かを選べます。バーが読んでいるテキストを隠してしまう場合は、**位置を微調整**の **X オフセット**と **Y オフセット**で位置を調整してください。

## インラインモード

一部のボタンは結果ウィンドウを開かずに動作させられます。PopBar 上の**スペルを修正**を右クリックし、**インラインモード**をオンにします。次回からテキストを選択して**スペルを修正**をクリックすると、修正結果がそのままテキストに反映されます。

## 結果のモデルや設定を変更する

AI モデル設定を持つコマンドでは、結果ツールバーにモデルピッカー（モデルプロバイダーのアイコン）が表示されます。ここでモデルを変更すると、次回以降に使うそのコマンドのデフォルト設定も更新されます。結果ウィンドウの「設定」ボタンからは、その結果を生成したコマンドの設定（**プラグイン → ライティングツール → 説明**など）を開けます。

## PopBar 拡張機能

PopBar 拡張機能は、アクションを PopBar のボタンとして追加できる小さなアドオンです。[PopClip](https://www.popclip.app) の拡張機能形式に対応しているため、PopClip 向けに作られた拡張機能も Enconvo にインストールできます。PopBar 拡張機能には Mac 版 Enconvo が必要です。

<Note>
Enconvo は PopClip の開発元である Pilotmoon Software とは提携関係にありません。
</Note>

### Enconvo のカタログからインストールする

1. **プラグイン**を開き、**PopBar 拡張機能**タブを選択します。
2. カテゴリから探すか、検索欄に入力して目的の拡張機能を見つけます。
3. 拡張機能の横にある **+** をクリックし、**インストール**をクリックします。
4. 続くカードに、拡張機能のボタン、各ボタンが表示される条件、配置場所が表示されます。それぞれについて **バーに表示**、**⌄ その他に格納**、または **オフ**を選び、**完了**をクリックします。**設定…** からは拡張機能のオプションを開けます。

新しいボタンは PopBar の **⌄ その他**パネルの先頭、またはバーに空きがある場合はバー上に追加されます。パネルを開くまで **⌄** にドットが表示され、パネル内では新しいボタンに **NEW** マークが付きます。

Enconvo はカタログに掲載する前にすべての拡張機能を審査し、審査済みのバージョンをそのままインストールします。インストール済みの拡張機能はタブの上部に表示されます。Enconvo が新しいバージョンを審査して公開すると、カタログ上の行に**アップデート**と表示されます。ボタンギャラリーの**さらに取得…** からも同じタブを開けます。

カタログはウェブ上の [app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions) でも閲覧できます。Mac で拡張機能の **Install** ボタンをクリックすると Enconvo が開き、何もインストールされる前にその拡張機能が何を行えるかを確認できます。

### 他の場所から拡張機能を追加する

**PopBar 拡張機能**タブ、または「プラグイン」ページの**追加**メニューにある**PopBar 拡張機能を追加…** をクリックし、次のいずれかを行います。

- `.popclipextz` パッケージへのリンクを貼り付けます。
- `#popclip` で始まる短いテキスト形式の拡張機能スニペットを貼り付けます。
- **ファイルを選択…** をクリックし、Mac 上の `.popclipextz` パッケージまたは `.popclipext` フォルダを選択します。

**プレビュー**をクリックします。Enconvo は拡張機能を実行せずに中身を読み取り、スクリプトの実行、インターネットへの接続、アプリの起動、キー入力など、PopBar 以外に何ができるかを一覧表示します。**許可してインストール**をクリックするまで何もインストールされず、インストール後はカタログからの場合と同じボタン設定カードが開きます。カタログ外の拡張機能は Enconvo の審査を受けていないため、信頼できる提供元のものだけをインストールしてください。

任意のアプリでスニペットを選択したときは、PopBar の最初に**拡張機能をインストール**ボタンが表示されます。クリックすると同じプレビューが開きます。

### PopClip から読み込む

PopClip をお使いの場合は、**PopBar 拡張機能**タブで**PopClip から読み込む…** をクリックします。Enconvo は PopClip の拡張機能とその設定を PopClip と同じ並び順でコピーし、それらのアクションを PopBar に追加します。PopClip 自体は変更されません。

- PopClip でオフにしている拡張機能はインストールされますが、PopBar には追加されません。
- API キーやパスワードはコピーされません。必要な拡張機能の一覧が表示されるため、各拡張機能の設定画面で再入力してください。
- Enconvo のカタログにあるバージョンと一致する拡張機能は審査済みとみなされ、カタログからアップデートされます。

### 設定・アップデート・削除

**PopBar 拡張機能**タブから拡張機能を開くと詳細ページが表示されます。**PopBar ボタン**セクションには各ボタンとその表示条件が並び、バーに表示、**⌄ その他**に格納、または PopBar からオフにする設定ができます。**PopBar 設定ですべてのボタンを並べる**をクリックすると「ボタン」タブが開きます。

オプションを持つ拡張機能では、ページ上部に**設定**、ボタンギャラリーのカード上に**設定…** が表示されます。

リンクからインストールした拡張機能は同じリンクからアップデートされます。アップデートによって以前許可した範囲を超える操作が可能になる場合、Enconvo は新たに追加された権限だけを表示し、更新前に再度確認を求めます。

拡張機能を削除するには、**PopBar 拡張機能**タブからその拡張機能を開いてアンインストールします。関連するボタンも PopBar から削除されます。

### まだ対応していない機能

- アカウントへのサインインを行う拡張機能。
- バーが表示されるたびに動的にアクションを生成する拡張機能。

これらを使用する拡張機能の場合は、プレビュー時に Enconvo がその旨を通知します。

### 拡張機能を提案する

Enconvo のカタログは [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions) で管理されています。審査対象の拡張機能を提案したい場合は、そちらで Issue またはプルリクエストを作成してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| ツールバーが表示されない | **PopBarを有効にする**、アクセシビリティ権限、**場所**で除外しているアプリやウェブサイトを確認してください。 |
| 意図しないテキストに対して動作する | テキストを選択し直してから、もう一度 PopBar を開いてください。 |
| コマンドが見つからない | **ボタン**タブと、そのコマンドのプラグインがインストールされているかを確認してください。 |
| 結果でテキストが置き換わらない | 対象のアプリが置換に対応していない可能性があります。結果をコピーして編集可能な入力欄に貼り付けてください。 |
| 拡張機能のボタンが表示されない | 新しいボタンが追加される PopBar 末尾の **⌄** をクリックするか、「プラグイン」内の該当拡張機能ページを確認してください（**オフ**のボタンは PopBar に表示されません）。また、特定の形式のテキストにしか表示されないボタンもあります。たとえば **Base64 Decode** は Base64 に見えるテキストを選択したときだけ表示されるため、通常のテキストでは **Base64 Encode** だけが表示されます。 |
| 拡張機能のボタンが選択テキストを上書きした | 多くの拡張機能は PopClip と同様に結果を選択範囲へ貼り付けます。編集できない場所では、代わりに結果がコピーされます。 |
| カタログが読み込まれない | インターネット接続を確認し、**PopBar 拡張機能**タブで**もう一度試す**をクリックしてください。 |

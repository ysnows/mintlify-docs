PopBar は、どのアプリでも、選択したテキストの隣に表示される小さなツールバーです。ボタンで、選択範囲の説明、翻訳、編集、検索、コピー、読み上げができ、[PopBar 拡張機能](#popbar-拡張機能)で、Web 検索、テキスト変換、選択範囲をほかのアプリに送るといった機能を追加できます。作業したいテキストがすでに画面にあるときに使います。

ほかの用途には、手早い質問やコマンドには [SmartBar](/ja/features/smartbar)、長い会話やファイルには[チャットウィンドウ](/ja/ai/chat)、1 つのアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、画面に表示したままにできる小さな入口には [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使います。[ウィンドウ管理](/ja/features/window-management)で、すべてを比較できます。

下の動画チュートリアルでは、PopBar の設定から使い方までを 6 分で紹介します。オンにする、表示するタイミングを選ぶ、スペルを修正・翻訳・AI に質問を実行する、インラインモードを使う、ボタンを追加して並べ替える、独自の AI コマンドを作る、PopBar 拡張機能を入手または作る、という内容です。

## PopBar を使う

1. **設定 → PopBar** を開き、**PopBarを有効にする** をオンにします。
2. アプリで短い文章を選択します。
3. ツールバーのボタンをクリックします。
4. コピー、貼り付け、置換の操作を使う前に、結果を確認します。

ショートカットで PopBar を開くこともできます。**PopBar を表示** を実行するか、**表示するタイミング** タブで **ホットキー** を設定します。ツールバーを閉じるには Esc を押します。

PopBar はアクセシビリティの権限を通じて選択範囲を読み取り、取得できる内容はアプリによって異なります。セキュアなフィールドや一部のカスタムエディタは、テキストを公開しません。

## 音声で質問する

Ask パネルが開いていて、フィールドに **選択したテキストについて質問…** と表示されているとき、質問を入力する代わりに話しかけられます。

1. フィールドのマイクボタンをクリックするか、[音声コマンド](/ja/features/dictation)のホットキーを押します。フィールドに **聞き取り中…** と、話している内容が表示されます。
2. 話し終えたら、もう一度ボタンをクリックするか、押し続けていたホットキーを離します。質問が送信されます。

送信せずに聞き取りを止めるには、Esc を押します。話す前に入力していた内容は、音声の内容の前に残ります。

## ボタンを選ぶ

PopBar 設定の **ボタン** タブには、バーのボタンが 1 つの帯に表示されます。ボタンをドラッグして並べ替えたり、ポイントして **×** をクリックして外したり、クリックしてほかのオプションを開いたりできます。**デフォルトに戻す** で、デフォルトのボタンに戻ります。

バーに収まらないボタンは、バーの端の **⌄** の下にあります。**⌄** をクリックすると **その他** パネルが開き、それらのボタンが一覧表示され、すべてのボタンと設定を検索するフィールドもあります。ボタンを変更すると、**PopBar をオフにする** の下に **デフォルトに戻す** も表示され、デフォルトのボタンとその順番に戻せます。**元に戻す** も使えます。

**ボタンを追加** をクリックすると、ボタンギャラリーが開きます。AI に質問、サイドバーで質問、リンクを開く、検索、コピー、翻訳、説明、スペルを修正、AI 編集、読み上げなどのほか、[PopBar 拡張機能](#popbar-拡張機能)のアクション、そして独自の [AI コマンド](/ja/features/ai-commands)を作る方法が並んでいます。独自の編集ワークフローのために、[ライティングツール](/ja/features/writing-tools)のコマンドを追加することもできます。ツールバーには、追加したボタンが表示されます。

## 表示される場所を制御する

**表示するタイミング** タブでは、PopBar が表示されるタイミングを設定します。

| 設定 | 動作 |
| --- | --- |
| **対象のテキスト** | 選択したすべてのテキストで PopBar を表示するか、外国語、コード、メールなど、PopBar が役立つテキストだけで表示します。 |
| **場所** | **次の場所以外すべて** にして **アプリを追加** または **ウェブサイトを追加** すると、一部のアプリやウェブサイトで表示しないようにできます。**次の場所のみ** を選ぶと、一覧にした場所だけで表示されます。 |
| **テキストを選択したときに表示** | これをオフにすると、PopBar は呼び出したときだけ表示されます。その場合は **ホットキーを追加** をクリックして、ショートカットを選びます。 |

ターミナルなど、自動で表示されるツールバーが邪魔になるアプリは除外してください。

## 見た目を変更する

**見る** タブの **レイアウト** で、ボタンを選択範囲の上に横一列に並べる (**横型**) か、ポインタの横に縦一列に並べる (**縦型**) かを選びます。バーが読んでいる内容を覆う場合は、**位置を微調整** の **X オフセット** と **Y オフセット** で移動します。

## インラインモード

一部のボタンは、結果ウィンドウなしで動作します。PopBar の **スペルを修正** を右クリックして **インラインモード** をオンにします。次回、テキストを選択して **スペルを修正** をクリックすると、修正がそのままテキストに反映されます。

## 結果のモデルや設定を変更する

AI モデルの設定があるコマンドでは、結果のツールバーにモデルピッカーが表示されます。モデルプロバイダーのアイコンで表示されます。変更すると、そのコマンドのデフォルトも更新され、以降の実行にも適用されます。結果ウィンドウの設定ボタンは、結果を生成したコマンドを開きます。たとえば **プラグイン → ライティングツール → 説明** です。

## PopBar 拡張機能

PopBar 拡張機能は、アクションが PopBar のボタンになる小さなアドオンです。[PopClip](https://www.popclip.app) の拡張機能形式を使っているので、PopClip 用に書かれた拡張機能も Enconvo にインストールできます。PopBar 拡張機能には、Mac 版 Enconvo が必要です。

<Note>
Enconvo は、PopClip の開発元である Pilotmoon Software とは提携していません。
</Note>

### Enconvo のカタログからインストールする

1. **プラグイン** を開き、**PopBar 拡張機能** タブを選びます。
2. カテゴリでカタログを閲覧するか、検索フィールドに入力して探します。
3. 拡張機能の横の **+** をクリックし、**インストール** をクリックします。
4. 続くカードに、拡張機能のボタン、それぞれの表示されるタイミング、場所が一覧表示されます。それぞれについて **バーに表示**、**⌄ その他に表示**、**オフ** を選び、**完了** をクリックします。**設定…** で、拡張機能のオプションが開きます。

新しいボタンは、PopBar の **⌄ その他** パネルの先頭か、バーに空きがあればバー上に追加されます。**⌄** には、パネルを開くまでドットが表示され、新しいボタンには **NEW** と表示されます。

Enconvo は、カタログに載せる前にすべての拡張機能を審査し、審査したバージョンそのものをインストールします。インストール済みの拡張機能は、タブの上部に一覧表示されます。Enconvo が新しいバージョンを審査すると、カタログのその拡張機能の行に **更新** と表示されます。ボタンギャラリーの **さらに入手…** で、同じタブが開きます。

カタログは、Web の [app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions) でも閲覧できます。Mac では、拡張機能の **インストール** ボタンで Enconvo が開き、インストールの前に拡張機能でできることが表示されます。

### ほかの場所から拡張機能を追加する

**PopBar 拡張機能** タブの **PopBar 拡張機能を追加…**、またはプラグインページの **追加** メニューをクリックします。次のいずれかを行います。

- `.popclipextz` パッケージへのリンクを貼り付けます。
- スニペットを貼り付けます。`#popclip` で始まる、拡張機能の短いテキスト形式です。
- **ファイルを選択…** をクリックして、Mac 上の `.popclipextz` パッケージまたは `.popclipext` フォルダを選びます。

**プレビュー** をクリックします。Enconvo は拡張機能を実行せずに読み取り、スクリプトの実行、インターネットへの接続、アプリの起動、キーの押下など、PopBar 以外でできることを一覧表示します。**許可してインストール** をクリックするまで何もインストールされず、クリックすると、カタログからインストールしたときと同じボタンのカードで終わります。Enconvo は、カタログ外の拡張機能を審査しないので、信頼できる提供元のものだけをインストールしてください。

どのアプリでもスニペットを選択すると、PopBar にまず **拡張機能をインストール** ボタンが表示されます。クリックすると、同じプレビューが開きます。

### PopClip から読み込む

PopClip を使っている場合は、**PopBar 拡張機能** タブで **PopClip から読み込む…** をクリックします。Enconvo は、PopClip の拡張機能とその設定を PopClip の順番どおりにコピーし、そのアクションを PopBar に追加します。PopClip 自体は変更されません。

- PopClip でオフになっている拡張機能は、インストールされますが、PopBar には追加されません。
- API キーとパスワードはコピーされません。それらが必要な拡張機能は Enconvo が一覧表示するので、各拡張機能の設定で入力し直してください。
- Enconvo のカタログのバージョンと一致する拡張機能は、審査済みとして扱われ、カタログから更新されます。

### 設定、アップデート、削除

**PopBar 拡張機能** タブから拡張機能を開くと、そのページが表示されます。**PopBar のボタン** セクションには、各ボタンと表示されるタイミングが一覧表示され、バーに表示、**⌄ その他** に表示、PopBar から外す、を選べます。**PopBar の設定ですべてのボタンを並べ替える** で、ボタンタブが開きます。

オプションのある拡張機能には、ページの上部に **設定** が、ボタンギャラリーのカードに **設定…** が表示されます。

リンクからインストールした拡張機能は、同じリンクから更新されます。更新で、許可したバージョンより多くのことができるようになる場合、Enconvo は新しい点だけを表示し、更新の前にもう一度確認します。

拡張機能を削除するには、**PopBar 拡張機能** タブから開いてアンインストールします。そのボタンは PopBar からなくなります。

### まだサポートされていないもの

- アカウントにログインする拡張機能。
- バーが表示されるたびにアクションを作る拡張機能。

拡張機能がこれらのいずれかを使っている場合は、プレビューの際に Enconvo が知らせます。

### 拡張機能を提案する

Enconvo のカタログは [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions) にあります。拡張機能の審査を提案するには、そこで Issue またはプルリクエストを作成してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ツールバーが表示されない | **PopBarを有効にする**、アクセシビリティの権限、**場所** のアプリとウェブサイトを確認してください。 |
| 違うテキストに対して動作する | 選択し直して、もう一度 PopBar を開いてください。 |
| コマンドがない | **ボタン** タブを確認し、そのコマンドのプラグインがインストールされていることを確認してください。 |
| 結果がテキストを置き換えない | アプリが許可していない可能性があります。結果をコピーして、編集可能なフィールドに貼り付けてください。 |
| 拡張機能のボタンが表示されない | PopBar の端の **⌄** をクリックしてください。新しいボタンはそこに入ります。または、プラグインにある拡張機能のページを確認してください。**オフ** のボタンは PopBar に表示されません。一部のボタンは、処理できるテキストにのみ表示されます。たとえば **Base64 Decode** は、Base64 のように見えるテキストにのみ表示されるので、通常のテキストを選択すると **Base64 Encode** だけが表示されます。 |
| 拡張機能のボタンが選択したテキストを置き換えた | 多くの拡張機能は、PopClip と同じように、結果を選択範囲に上書きして貼り付けます。テキストを編集できない場所では、結果がコピーされます。 |
| カタログが読み込まれない | 接続を確認してから、**PopBar 拡張機能** タブの **もう一度試す** をクリックしてください。 |

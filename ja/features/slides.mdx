---
title: "スライド"
description: "Agent にスライド資料を作成させ、発表者ノート付きで全画面プレゼンしたり、編集可能な PowerPoint や PDF としてダウンロードしたりできます。"
---

Agent にスライド資料の作成を依頼すると、チャットの横のパネルにスライドが作成されます。その場からプレゼンテーションを行ったり、手動で編集したりできるほか、テキストボックス・図形・表・発表者ノート・セクションを保持したまま PowerPoint として、または PDF としてダウンロードできます。発表や共有のためのスライドが必要なときにいつでもお使いください。

## スライドを作成する

1. 新しいチャットを開始してメッセージ入力欄の下にある **スライド** を選ぶか、任意のチャットでスライド資料の作成を依頼します。
2. 誰向けか、何分の発表か、何を盛り込むべきかなどプレゼンの内容を伝えます。ベースにする PDF、メモ、`.pptx` ファイルがあれば添付してください。
3. 送信します。Agent が作成するにつれてパネルにスライドが順次表示されます。枚数の多い資料は、数枚ずつ並列で作成されます。

例：

```text
A 5-minute talk from this doc, with speaker notes.
Keep one idea per slide and end with three next steps.
```

作成が終わると、Agent がレイアウトをチェックします。ヘッダーには **レイアウトに問題のないスライド** または **スライドの問題** が件数とともに表示されます。件数をクリックすると、スライドからはみ出したテキスト、見切れ、重なり、コントラスト不足、小さすぎる文字、壊れた画像などの問題を確認でき、Agent に修正を依頼できます。

## 発表する

- **発表** をクリックすると、アニメーションや画面切り替え付きで全画面プレゼンを開始します。
- 隣の **その他のプレゼン方法** を開くと、**このスライドからプレゼン** や、経過時間・次のスライド・ノートを確認できる **発表者ビュー** を選べます。
- 2 台目のディスプレイが接続されている場合、発表者ビューは観客用ウィンドウをそちらに表示します。

作成したスライドは iPhone や Android アプリでも開いて発表できます。詳しくは[アーティファクト](/ja/features/artifacts)をご覧ください。

## スライドを編集する

ご自身で直接編集することも、Agent に変更を依頼することもできます。Agent に頼むと、指定したスライドだけが更新され、現在表示中のスライド位置を保ったままパネルの内容が入れ替わります。

- **文字**：テキストをダブルクリックして書き換えます。選択範囲に対して **太字**、**斜体**、**下線**、**文字色**、**書式をクリア** が使えます。
- **レイアウト**：要素をドラッグして移動します。
- **発表者ノート**：**発表者ノート** をクリックし、スライドの下に入力します。
- **スライド操作**：**その他** メニューから **スライドを複製**（複製先へ移動します）、**スライドを前へ移動**、**スライドを後ろへ移動**、**スライドを削除** が行えます。削除したスライドは **元に戻す** で復元できます。
- **コメント**：**コメント** をクリックし、特定の箇所・選択した文字・スライド全体に対してコメントを残せます。コメントの先頭に `@Enconvo` を付けると Agent に質問・指示できます。

## デザインシステムを使う

デザインシステムを適用すると、すべてのスライドに統一された配色と書体が使われ、それらは PowerPoint のテーマにも反映されます。

1. **その他 → デザインシステム** を開き、システムを選択します。
2. チャットでそのデザインシステムに合わせてスライドのスタイルを整えるよう依頼します。本文の内容はそのまま保たれます。

スライドに適用した後にデザインシステム側が更新された場合、メニューに元のソースより古い状態であることが表示され、**元のシステムと同期** を実行できます。自社ブランドのデザインシステムを作る方法は[デザインキャンバス](/ja/features/design)をご覧ください。

Agent は約 1,500 種類のアイコンセットからスライド上にアイコンを配置することもできます。

## ダウンロードする

**ダウンロード** をクリックし、**PowerPoint をダウンロード** または **PDF をダウンロード** を選択します。Enconvo がファイルを保存し、保存場所を表示します。

ほかの人やチームと共有するには **共有** をクリックします。詳しくは[アーティファクト](/ja/features/artifacts)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **スライドの問題** に件数が表示される | クリックして各問題を確認し、Agent に修正を依頼してください |
| 入力した変更が保存されなかった | 編集している間にスライド側が更新された可能性があります。もう一度変更を加えてください |
| 削除したスライドが元に戻らなかった | その後に資料が変更されています。バージョンメニューから以前のバージョンを開いてください |
| 「hasn't finished drawing the export」というエラーで書き出しに失敗する | Enconvo を最新にアップデートしてから、もう一度ダウンロードしてください |

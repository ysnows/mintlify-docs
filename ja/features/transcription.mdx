---
title: "文字起こし"
description: "手持ちの音声ファイルや動画ファイルを検索可能な文字起こしデータに変換します。"
---

インタビューや講義動画など、すでに手元にあるメディアには文字起こしを使用します。リアルタイムの会議録音は **録音**、リアルタイムの字幕表示は **リアルタイム字幕** に保存されます。この 3 つは同じ録音ビューを共有していますが、それぞれ異なるソースの項目を一覧表示します。

## ファイルを読み込む

1. **設定 → 文字起こしモデル** でモデルを選びます。
2. **設定 → 文字起こし** を開き、**追加** をクリックして **音声** または **動画** を選びます。リストが空の場合は **ファイルを読み込む** をクリックします。音声ファイル・動画ファイル・フォルダをページへ直接ドラッグ＆ドロップすることもできます。
3. 音声抽出と文字起こしが完了するまで待ちます。複数ファイルを追加した場合はバックグラウンドで 1 つずつ処理され、長い音声ファイルを変換している間も Enconvo はそのまま使えます。
4. 項目を開いて文字起こしと処理ステータスを確認します。
5. 結果を使う前に、重要な話者名・専門用語・数値を修正してください。

**文字起こし** コマンドを直接実行することもできます。設定には **出力形式**、**話者分離**、**文字起こしプロバイダー** があります。

## 文字起こしを活用する

保存した項目を開くと、文字起こし全文、要約、**AI に質問** を利用できます。要約の仕組みは会議の録音と同じで、サイドパネル上部から出力言語とテンプレートを選べます。[会議の録音](/ja/features/meeting-recording)を参照してください。細部まで正しく認識されていると思い込まず、文字起こしについて質問して確認してください。タイムスタンプ、構造化出力、話者分離に対応しているかどうかは、使用するプロバイダーとコマンドによって決まります。

語彙や話者名の登録については[辞書と話者](/ja/configuration/speech-assets)を参照してください。他のドキュメントと一緒に後から文字起こしを検索する方法は[ナレッジベース](/ja/ai/knowledge-base)を参照してください。

## 文字起こしに失敗したとき

Enconvo は文字起こしの失敗と発話のないファイルを区別して扱います。エラー内容と診断詳細を確認してください。失敗の原因は音声抽出、プロバイダー側のファイル制限、アカウント権限、またはサービス自体の問題である場合があります。タイトル生成と検索インデックス作成は、文字起こし本体とは別処理として失敗することがあります。

文字起こし自体はすでに保存されている場合もあるため、同じファイルをもう一度読み込む前に、タイトル生成やインデックス作成だけが失敗していないか確認してください。文字起こしを確認し終えるまでは元のメディアファイルを削除しないでください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 文字起こしに失敗する | エラーとその詳細を確認してください。Enconvo Cloud Fast は最大 300 分の録音に対応し、大きなファイルはアップロード前に自動で再エンコードします。サービスの容量や時間の上限を超える場合はファイルを分割するか、より長いファイルに対応したモデルを選んでください。動画の音声を読み取れない場合は、WAV または MP3 ファイルに書き出してから文字起こししてください。 |
| タイトルまたは検索インデックス作成だけが失敗する | 文字起こしは保存済みなので、ファイルを再読み込みしないでください。インデックス作成が失敗した場合は **インデックス作成を再試行** を使用してください。 |
| 話者が分かれていない | 話者分離に対応したプロバイダーを選ぶか、**文字起こし** コマンドで **話者分離** をオンにしてください。 |
| **これらのファイルはすでに文字起こしにあります** | 同じファイルがすでに読み込まれています。既存の項目を開いてください。 |

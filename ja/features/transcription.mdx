---
title: "文字起こし"
description: "すでにある音声ファイルや動画ファイルを、検索できる文字起こしにします。"
---

文字起こしは、インタビューや講義のビデオなど、すでにあるメディアに使います。ライブで録音した会議は**録音**に、字幕のセッションは**リアルタイム字幕**に保存されます。3 つは同じ録音ビューを共有しますが、一覧に表示されるソースは異なります。

## ファイルを読み込む

1. **設定 → 文字起こしモデル**で、モデルを選びます。
2. **設定 → 文字起こし**を開いて**追加**をクリックし、**音声**または**動画**を選びます。リストが空のときは、**ファイルを読み込む**をクリックします。音声ファイル、動画ファイル、フォルダをページにドロップすることもできます。
3. 抽出と文字起こしが終わるまで待ちます。複数のファイルは、バックグラウンドで 1 つずつ文字起こしされ、長い音声ファイルの変換中も、Enconvo は使えます。
4. 項目を開き、文字起こしと処理状況を確認します。
5. 結果を使う前に、重要な話者名、用語、数字を修正します。

**文字起こし**コマンドを実行することもできます。設定には、**出力形式**、**話者分離**、**Transcription Provider** があります。

## 文字起こしを使う

保存された項目を開くと、文字起こし、その要約、**AI に質問**が表示されます。要約は録音と同じように動作します。サイドパネルの上部で、出力言語とテンプレートを選びます。[会議の録音](/ja/features/meeting-recording)をご覧ください。すべての詳細が正しく認識されたと思い込まず、文字起こしについて質問してください。タイムスタンプ、構造化出力、話者分離が得られるかどうかは、使うプロバイダーとコマンドによって決まります。

語彙と話者名については、[辞書と話者](/ja/configuration/speech-assets)をご覧ください。あとで、ほかのドキュメントと一緒に文字起こしを見つけるには、[ナレッジベース](/ja/ai/knowledge-base)をご覧ください。

## 文字起こしが失敗したとき

Enconvo は、文字起こしの失敗と、音声が含まれていないファイルを区別します。エラーと診断の詳細を読んでください。失敗の原因は、音声の抽出、プロバイダーのファイル制限、アカウントのアクセス、またはサービス自体にある場合があります。タイトルの生成と検索のインデックス作成は、文字起こしとは別に失敗することがあります。

文字起こしがすでに保存されている場合は、同じファイルを再び読み込む前に、タイトルまたはインデックス作成の手順だけが失敗したのかを確認します。文字起こしを確認するまで、元のメディアは保管しておいてください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 文字起こしに失敗した | エラーと詳細を読みます。Enconvo Cloud Fast は、300 分までの録音を扱い、大きなファイルはアップロード前に再エンコードします。ファイルがサービスにとって大きすぎるか長すぎる場合は、分割するか、長いファイルに対応したモデルを選びます。動画の音声を読み取れない場合は、WAV または MP3 ファイルとして書き出し、それを文字起こしします。 |
| タイトルまたは検索のインデックス作成だけが失敗した | 文字起こしは保存されているため、ファイルを再び読み込まないでください。インデックス作成が失敗したときは、**インデックス作成を再試行**を使います。 |
| 話者が分離されない | 話者分離に対応したプロバイダーを選ぶか、**文字起こし**コマンドの**話者分離**をオンにします。 |
| **これらのファイルはすでに文字起こしにあります** | これらのファイルは、以前に読み込まれています。既存の項目を開きます。 |

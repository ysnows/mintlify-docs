title: "Live Photo キャラクターを配信する"
description: "Live Photo キャラクターを字幕つきで OBS の配信に出し、Twitch、Kick、YouTube のライブチャットに声で答えさせます。"
---

[Live Photo キャラクター](/ja/features/avatar)は、ライブ配信の司会を務められます。Enconvo は、動くキャラクターの映像を表示するステージと字幕ページを OBS に提供します。キャラクターは配信のチャットを読み、エージェントを通して視聴者に声で答えます。

## はじめる前に

- **設定 → アバター**で Live Photo キャラクターを作成し、エージェントに連携します。
- OBS Studio をインストールします。配信パネルの **OBS Studio を入手**から入手できます。

<Note>
Atmee は、通話の実行中は、配信しているかどうかにかかわらず、またライブモードで答えている間も、キャラクターのライブ映像を分単位で課金します。
</Note>

## 配信パネルを開く

1. **設定 → アバター**を開き、**Live Photo** タブを開きます。
2. キャラクターのカードの**ライブ配信を開始**をクリックします。

配信パネルには、ステージ、字幕、向き(**縦長 9:16** または **横長 16:9**)、OBS の配信状態が表示されます。ステージには、アバターを開くとキャラクターが表示されます。

## OBS に追加する

1. OBS で **ツール → WebSocket サーバー設定**を開き、**WebSocket サーバーを有効にする**にチェックを入れて、**適用**をクリックします。
2. **接続情報を表示**をクリックし、サーバーのパスワードをコピーします。
3. 配信パネルで **OBS に接続**をクリックし、パスワードを貼り付けます。Enconvo は、ほかの認証情報と一緒にそれを保管します。
4. **OBS に追加**をクリックします。Enconvo は、配信のサイズに合わせて、ステージと字幕を含む「Enconvo · *キャラクターの名前*」というシーンを作成します。
5. OBS で配信を開始するか、パネルの**ライブ配信を開始**を使います。**配信を終了**で停止します。

向きを変えた場合は、**OBS に追加**をもう一度クリックして、シーンのサイズを変更します。シーンを自分で作るには、パネルにある透明なステージページと字幕ページを、**ブラウザ**ソースとして OBS に追加します。

## 背景を選ぶ

パネルの**バックグラウンド**で、OBS がキャラクターの後ろに受け取るものを選びます。OBS には、ステージのプレビューとまったく同じものが表示されます。

| 選択肢 | OBS が受け取るもの |
| --- | --- |
| **透明** | キャラクターだけを、アルファ付きで受け取ります。OBS のシーンがキャラクターの後ろに表示されます。 |
| **色** | **グリーンバック**や**カスタムカラー**など、1 色で塗りつぶしたフレーム全体です。 |
| **画像** | あなた自身の画像で塗りつぶしたフレーム全体です。画像はこの Mac に保管されます。 |
| **写真をぼかす** | キャラクターの写真をぼかして塗りつぶしたフレーム全体です。 |
| **元の写真** | キャラクターの元の写真です。 |

枠付きの**背景**を設定して保存したキャラクターは、自分の写真と枠を保ちます。バックグラウンドは、切り抜いたキャラクターに適用されます。

## ライブチャットに答えさせる

1. 配信パネルで、**Twitch チャンネル**または **Kick チャンネル**を入力するか、YouTube Data API キーで YouTube に接続します。
2. 誰に答えるかを設定します。キャラクターにメンションした視聴者、`!ask` で質問した視聴者、または支払いをした視聴者です。視聴者ごとと全体のクールダウン、ブロックする単語を設定し、質問を 1 件ずつ承認したい場合は、先に承認するキューをオンにします。
3. **ライブチャットを開始**をクリックします。

キャラクターは、エージェントを通して声で答えます。

### ライブモード

パネルの**ライブモード**をオンにすると、キャラクターは通話なしで、OBS のステージ上で唇を動かしながら各回答を話します。オフの場合は、回答がこの Mac で読み上げられます。

## 音声

通話中、ステージにキャラクターが表示されている間は、キャラクターの声は OBS からだけ再生されます。**この Mac でも再生**をオンにすると、Mac でもキャラクターの声が聞こえます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ステージが空 | アバターを開きます。通話中は、ステージにキャラクターがライブで表示されます。 |
| OBS に接続できない | OBS で**WebSocket サーバーを有効にする**にチェックが入っていることを確認し、パスワードをもう一度貼り付けます。 |
| シーンのサイズが違う | 向きを変えたあと、**OBS に追加**をもう一度クリックします。 |
| バックグラウンドが変わらない | キャラクターが枠付きの**背景**で保存されています。バックグラウンドは、切り抜いたキャラクターに適用されます。 |
| 声が二重に聞こえる、または聞こえない | **この Mac でも再生**を確認します。 |

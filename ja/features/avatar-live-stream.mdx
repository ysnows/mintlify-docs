title: "Live Photo キャラクターでライブ配信する"
description: "Live Photo キャラクターを字幕付きで OBS の配信に載せ、Twitch・Kick・YouTube のライブチャットに声で応答させます。"
---

[Live Photo キャラクター](/ja/features/avatar)にライブ配信を進行させることができます。Enconvo は彼女の動く映像のステージと字幕ページを OBS に提供し、紐づけたエージェントを通じて配信チャットのコメントを読み上げ、視聴者に声で回答させられます。

## はじめる前に

- **設定 → アバター** で Live Photo キャラクターを作成し、エージェントに紐づけます。
- OBS Studio をインストールします。配信パネルの **OBS Studio を入手** からダウンロードページを開けます。

<Note>
Atmee では、配信しているかどうかにかかわらず通話が動いている間と、ライブモードで彼女が回答を話している間、ライブ映像に対して分単位で課金されます。
</Note>

## 配信パネルを開く

1. **設定 → アバター** を開き、**Live Photo** タブを選択します。
2. キャラクターのカードで **ライブ配信を開始** をクリックします。

配信パネルにはステージ、字幕、画面の向き（**縦長 9:16** または **横長 16:9**）、OBS の配信状態が表示されます。アバターを開くとステージに彼女が表示されます。

## OBS に追加する

1. OBS で **ツール → WebSocket サーバー設定** を開き、**WebSocket サーバーを有効にする** にチェックを入れて **適用** をクリックします。
2. **接続情報を表示** をクリックし、サーバーパスワードをコピーします。
3. 配信パネルで **OBS に接続** をクリックし、パスワードを貼り付けます。Enconvo は他の認証情報と同じ場所に保管します。
4. **OBS に追加** をクリックします。Enconvo が配信サイズに合わせたステージと字幕を含む「Enconvo · *キャラクター名*」というシーンを作成します。
5. OBS から配信を開始するか、パネルの **ライブ配信を開始** をクリックします。**配信を終了** で停止します。

向きを変更した場合は、もう一度 **OBS に追加** をクリックしてシーンのサイズを合わせ直してください。自分でシーンを組む場合は、パネルの透過ステージページと字幕ページを OBS に **ブラウザ** ソースとして追加します。

## 背景を選ぶ

パネルの **背景** で、OBS へ渡す背後の映像を選べます。OBS にはステージプレビューそのままの映像が送られます。

| 選択肢 | OBS に表示される映像 |
| --- | --- |
| **透明** | アルファチャンネル付きで彼女だけを表示し、背後に OBS のシーンが透けて見えます。 |
| **色** | **グリーンバック** や **カスタムカラー** など単色で塗りつぶします。 |
| **画像** | この Mac に保存された任意の画像を背景にします。 |
| **写真をぼかす** | 彼女の元写真をぼかした背景にします。 |
| **元の写真** | 彼女の元の写真をそのまま使います。 |

フレーム付きの **背景** 付きで保存したキャラクターは元の写真とフレームを保持するため、この背景設定は切り抜きキャラクターに適用されます。

## ライブチャットに応答させる

1. 配信パネルで **Twitch チャンネル** または **Kick チャンネル** を入力するか、YouTube Data API キーで YouTube を接続します。
2. 誰のコメントに答えるか（メンションした視聴者、`!ask` で質問した視聴者、投げ銭・有料コメントした視聴者）を設定します。視聴者ごとのクールダウン、全体のクールダウン、NG ワードを設定し、質問を1件ずつ承認したい場合は事前承認キューをオンにします。
3. **ライブチャットを開始** をクリックします。

キャラクターがエージェントを通じて声で回答します。

### ライブモード

パネルで **ライブモード** をオンにすると、通話を開始しなくても OBS ステージ上で唇を動かしながら各回答を話します。オフにすると、この Mac 上で回答が読み上げられます。

## 音声

通話中、ステージに彼女が表示されている間は OBS からのみ声が再生されます。Mac でも声を聞きたい場合は **この Mac でも再生** をオンにしてください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ステージが空になっている | 彼女のアバターを開いてください。通話中はライブ映像がステージに表示されます。 |
| OBS に接続できない | OBS で **WebSocket サーバーを有効にする** がチェックされているか確認し、パスワードを貼り付け直してください。 |
| シーンのサイズが合っていない | 画面の向きを変えた後に、もう一度 **OBS に追加** をクリックしてください。 |
| 背景が変わらない | フレーム付きの **背景** として保存されたキャラクターです。背景変更は切り抜きキャラクターに適用されます。 |
| 声が二重に聞こえる、または聞こえない | **この Mac でも再生** の設定を確認してください。 |

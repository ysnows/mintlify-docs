---
title: "コンテキスト認識"
description: "直前に使っていたアプリから SmartBar が取り込む内容を選び、# でさらにコンテキストを追加します。"
---

コンテキストとは、質問と一緒に送られる情報のことです。選択したテキスト、Finder で選択したファイル、ブラウザで開いているページ、スクリーンショットなどがあります。SmartBar は、開くときにその一部を取り込めます。`#` を入力すれば、さらに追加できます。すると、エージェントは、あなたが説明しなくても、見ているものについて答えられます。

## SmartBar が取り込む内容を選ぶ

1. **設定 → コンテキスト認識**を開きます。
2. **Smart Bar を開いたとき**の下で、各ソースを**自動追加**、**提案**、**オフ**のいずれかに設定します。
3. 別のアプリに切り替えて何かを選択し、SmartBar を開いて結果を確認します。

| ソース | 追加される内容 | デフォルト |
| --- | --- | --- |
| **選択したテキスト** | 直前に使っていたアプリで選択したテキスト | **自動追加** |
| **Finder の選択項目** | Finder で選択したファイルとフォルダ | **提案** |
| **ブラウザの現在のページ** | Safari、Chrome、Arc、Edge、またはほかの Chromium ブラウザで開いているページ | **提案** |

**自動追加**は、SmartBar を開くとすぐに、そのソースを入力に追加します。**提案**は、コマンドの上にそのソースを表示するため、1 クリックで追加できます。**オフ**は、追加しません。

これらの設定を使うのは、SmartBar だけです。選択範囲に対して実行するコマンドは、常に選択したテキストを受け取ります。Finder やブラウザのコンテキストを初めて追加するとき、macOS は、Enconvo がそのアプリを操作してよいかを尋ねます。

## # でコンテキストを追加する

1. SmartBar で `#` を入力します。
2. `#screen`、`#finder`、`#clipboard`、`#browser` のように、単語を入力してリストを絞り込みます。
3. ソースを選びます。メッセージに追加されます。
4. 質問を入力して送信します。

| ソース | 追加される内容 |
| --- | --- |
| **Selected Text** | 現在のウィンドウで選択したテキスト |
| **Clipboard Text** | クリップボードにあるテキスト |
| **Current Application Content** | 前面にあるアプリのテキスト |
| **Current Application Screenshot** | 前面にあるアプリのスクリーンショット |
| **Current Screen Screenshot** | 画面全体のスクリーンショット |
| **Live Screen Screenshot** | Enconvo のウィンドウを除いた画面のスクリーンショット |
| **User Select Area Screenshot** | 選択した領域のスクリーンショット |
| **Finder Selected Items** | Finder で選択したファイルとフォルダ |
| **Finder Current Directory URL** | Finder で開いているフォルダ |
| **Browser Current Tab URL** | ブラウザの現在のタブのアドレス |

開いているウィンドウも一覧に表示されるため、別のアプリのウィンドウを追加できます。`#` 以外の文字を使うには、**設定 → SmartBar**の**検索**にある**コンテキスト**を変更します。

## 何を尋ねるか

ブラウザのページを添付した状態で、Enconvo にページの要約、翻訳、重要な情報の抽出を頼めます。Finder のファイルを添付した状態では、ファイルの説明、整理のしかたの提案、一括での名前変更の手伝い、内容の分析を頼めます。

<Note>
添付したコンテキストは、回答するモデル、またはそれを処理するプロバイダーに送られます。機密性の高い内容を扱う前に、添付されているものと、プロバイダーの設定を確認してください。
</Note>

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 選択したテキストが添付されない | **選択したテキスト**が**自動追加**に設定されていることを確認し、[権限](/ja/configuration/permissions)を確認します。 |
| Finder やブラウザのコンテキストがない | macOS から求められたときに、Enconvo がそのアプリを操作することを許可します。拒否した場合は、[権限](/ja/configuration/permissions)で許可します。 |
| `#` を入力してもリストが開かない | **設定 → SmartBar**の**コンテキスト**の文字を確認します。 |

コンテキストとは、選択したテキスト、Finder で選択したファイル、ブラウザで開いているページ、スクリーンショットなど、質問に添えて渡す情報のことです。SmartBar は開いた瞬間にこれらのいくつかを自動で取り込めるほか、`#` を入力してさらに追加することもできます。これにより、いちいち説明しなくても、いま見ているものについてエージェントがそのまま回答してくれます。

## SmartBar が自動で取り込む内容を選ぶ

1. **設定 → コンテキスト認識**を開きます。
2. **Smart Bar を開いたとき**の下で、各ソースを **自動追加**、**提案**、または **オフ** に設定します。
3. 別のアプリに切り替えて何かを選択し、SmartBar を開いて動作を確かめます。

| ソース | 追加される内容 | デフォルト |
| --- | --- | --- |
| **選択したテキスト** | 直前に使っていたアプリで選択したテキスト | **自動追加** |
| **Finder の選択項目** | Finder で選択しているファイルやフォルダ | **提案** |
| **ブラウザの現在のページ** | Safari、Chrome、Arc、Edge、その他の Chromium 系ブラウザで開いているページ | **提案** |

**自動追加**は SmartBar を開くと同時に入力欄へ追加します。**提案**はコマンド一覧の上に候補として表示し、ワンクリックで追加できるようにします。**オフ**は取り込みません。

これらの設定が使われるのは SmartBar だけです。選択テキストに対して直接実行するコマンドには、常にその選択テキストが渡されます。Finder やブラウザのコンテキストを初めて追加するときは、Enconvo がそのアプリを制御することを許可するか macOS が確認します。

## `#` でコンテキストを追加する

1. SmartBar で `#` を入力します。
2. `#screen`、`#finder`、`#clipboard`、`#browser` などの語を入力して一覧を絞り込みます。
3. ソースを選択すると、メッセージに追加されます。
4. 質問を入力して送信します。

| ソース | 追加される内容 |
| --- | --- |
| **選択したテキスト** | 現在のウィンドウで選択中のテキスト |
| **クリップボードのテキスト** | クリップボードに入っているテキスト |
| **現在のアプリの内容** | 最前面にあるアプリのテキスト |
| **現在のアプリのスクリーンショット** | 最前面にあるアプリのスクリーンショット |
| **現在の画面のスクリーンショット** | 画面全体のスクリーンショット |
| **ライブ画面のスクリーンショット** | Enconvo のウィンドウを除いた画面のスクリーンショット |
| **選択範囲のスクリーンショット** | ドラッグして指定した領域のスクリーンショット |
| **Finder の選択項目** | Finder で選択中のファイルやフォルダ |
| **Finder の現在のディレクトリ URL** | Finder で現在開いているフォルダ |
| **ブラウザの現在のタブの URL** | ブラウザで現在開いているタブのアドレス |

開いているウィンドウも一覧に表示されるため、別アプリのウィンドウを追加することもできます。`#` 以外の文字を使いたい場合は、**設定 → SmartBar** の **検索** にある **コンテキスト** を変更してください。

## 頼めることの例

ブラウザのページを添付したら、ページの要約、翻訳、重要情報の抽出などを Enconvo に頼めます。Finder のファイルを添付したら、ファイル内容の説明、整理方法の提案、一括リネームの相談、中身の分析などを依頼できます。

<Note>
添付したコンテキストは、回答を作成するモデルや処理を担当するプロバイダーへ送信されます。機密情報を扱う場合は、添付されている内容とプロバイダー設定を確認してから送信してください。
</Note>

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 選択したテキストが添付されない | **選択したテキスト**が**自動追加**になっていることと、[権限](/ja/configuration/permissions)を確認してください。 |
| Finder やブラウザのコンテキストが出ない | macOS の確認ダイアログが出たら Enconvo によるアプリ制御を許可してください。拒否していた場合は[権限](/ja/configuration/permissions)から許可します。 |
| `#` を入力しても一覧が開かない | **設定 → SmartBar**の**コンテキスト**文字の設定を確認してください。 |

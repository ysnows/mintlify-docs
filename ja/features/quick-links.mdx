---
title: "クイックリンク"
description: "Web 検索、Web サイト、ファイル、フォルダ、Deeplink を、1 つのコマンドで SmartBar から開きます。"
---

クイックリンクは、Web 検索、Web アドレス、ファイルやフォルダ、アプリの Deeplink を、SmartBar から実行できるコマンドにします。プレースホルダには、入力した内容、クリップボード、選択したテキスト、日付が入ります。Enconvo には、Google、YouTube、X の検索があらかじめ用意されています。

クイックリンクは、移動先を開きます。[ウェブ検索](/ja/ai/web-search)は、代わりに検索結果を AI の回答に取り込み、[ブラウザを使用](/ja/features/browser-control)は、エージェントが Web ページで作業できるようにします。

## SmartBar から Web を検索する

1. SmartBar を開き、**Google Search in Browser**、**YouTube Search in Browser**、**Twitter/X Search in Browser** を探します。
2. コマンドの入力として、検索するテキストを入力します。選択したテキストも使えます。
3. コマンドを実行します。検索がデフォルトのブラウザで開きます。

## クイックリンクを作成する

1. SmartBar から **クイックリンクを作成** を実行します。
2. **名前** を入力します。たとえば Search GitHub です。
3. **リンク** を入力します。Web アドレス、ファイルまたはフォルダのパス、Deeplink のいずれかです。**プレースホルダを挿入** をクリックして、`https://github.com/search?q={argument}` のようにプレースホルダを追加します。
4. 特定のアプリで開くには、**このアプリで開く** に、Safari などのアプリ名、アプリのパス、バンドル ID を入力します。デフォルトのアプリを使う場合は、空のままにします。
5. **保存** をクリックします。SmartBar でクイックリンクの名前を検索すると、実行できます。

クイックリンクを実行すると、入力または選択したテキストが、最初の引数に入ります。必須の引数がまだ空の場合は、リンクを開く前に、Enconvo が入力を求めます。

| プレースホルダ | 入る内容 |
| --- | --- |
| `{argument name="Query"}` | クイックリンクを開くときに入力する値 |
| `{clipboard}` | クリップボードのテキスト |
| `{selection}` | 使用中のアプリで選択されているテキスト |
| `{date}`、`{time}`、`{datetime}` | 現在の日付、時刻、またはその両方 |
| `{date format="yyyy-MM-dd"}` | 指定した形式の日付 |
| `{uuid}` | 新しい一意の ID |

新しいリンクは、まず、スペースや句読点を含む普通のテキストで試してください。

## クイックリンクを管理する

SmartBar から **クイックリンクを検索** を実行すると、すべてのクイックリンクが表示されます。そこから、開く、編集、複製、削除ができ、**新規** をクリックして別のものを追加できます。

**その他** メニューには、Raycast のクイックリンクと設定の書き出しを読み取る **クイックリンクを読み込む…** と、**ダウンロードに書き出す** があります。Raycast の設定の書き出しでは、書き出したときに設定したパスフレーズの入力が求められます。

## 設定

**設定 → プラグイン → クイックリンク** を開きます。各検索コマンドにも、独自の **リンク**（たとえば `https://www.google.com/search?q={query}`）があり、変更できます。

| 設定 | 変更される内容 |
| --- | --- |
| **新規ウインドウで開く** | Web のクイックリンクを、ブラウザの新しいウインドウで開きます。Chrome、Edge、Brave、Vivaldi、Opera、Chromium、Firefox、Zen で動作します。Safari、Arc、Orion では、通常どおりリンクが開きます。デフォルトではオフです |
| **選択したテキストがない場合** | 何も選択されていないときの `{selection}` リンクの動作です。**入力を求める**（デフォルト）または **クリップボードを使用** |
| **削除前に確認** | クイックリンクを削除する前に確認します。デフォルトでオンです |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 違うページが開く | クイックリンクの **リンク** とプレースホルダを確認してから、普通のテキストで試してください |
| ブラウザが開かない | デフォルトのブラウザ、クイックリンクの **このアプリで開く**、コマンドがインストールされているかを確認してください |
| `{selection}` のリンクがテキストを求める | 何も選択されていません。先にテキストを選択するか、**選択したテキストがない場合** を **クリップボードを使用** に設定してください |

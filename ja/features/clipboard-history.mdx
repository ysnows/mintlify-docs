title: "クリップボード履歴、ブックマーク、ファイル検索"
description: "コピーした内容、ブラウザのブックマーク、Mac 上のファイルを、ホットキーまたは SmartBar から検索します。"
---

クリップボード履歴、ブラウザのブックマーク検索、ファイル検索は、入力しながら絞り込める 3 つのクイックリストです。以前コピーしたものを貼り付けるにはクリップボード履歴、保存したページを任意のブラウザで開くにはブックマーク検索、Finder を使わずにファイルを開くにはファイル検索を使います。それぞれ専用のホットキー、または SmartBar からエイリアスで開けます。

## リストを開く

1. **設定 → ショートカット**、または **設定 → プラグイン** にあるそのリスト自体の設定ページで、リストのホットキーを設定します。
2. ホットキーを押します。**ホットキーで専用ウインドウを開く** がオン (デフォルト) の場合、リストは専用のウィンドウで開き、SmartBar はそのままです。
3. 入力してリストを絞り込み、矢印キーで項目に移動して、Return を押します。

代わりに SmartBar の中でリストを開くには、その **エイリアス** を設定します。SmartBar でエイリアスとスペースを入力すると、そこでリストが開きます。SmartBar の検索には、各リストのエイリアスが表示されます。

チャットでリストを `@` メンションすることもでき、エージェントがそのリストを検索してくれます。

## クリップボード履歴から貼り付ける

クリップボード履歴には、コピーしたテキスト、画像、ファイルが保存されます。お気に入りを固定したり、リンク、メール、カラー、画像、ファイルで絞り込んだりできます。

1. クリップボード履歴を開きます。
2. コピーした内容に含まれる語を入力します。
3. Return を押すと、使っていたアプリに項目が貼り付けられます。代わりにコピーするには **⌘C** を押します。**Return キー** をコピーに設定している場合は、**⌘Return** で貼り付けます。

Enconvo 自身のウィンドウの上でリストを開いた場合、Return はそのウィンドウのメッセージ欄に貼り付けます。

パスワードマネージャーとキーチェーンアクセスはデフォルトで除外され、パスワードなど、アプリが秘匿または一時的として印を付けたコピーは記録されません。

## ブックマークを開く

ブラウザのブックマーク検索は、Safari、Chrome、Edge、Brave、Arc、Dia、Vivaldi、Opera、Chromium、Comet、Firefox、Zen のブックマークを読み取ります。選んだフォルダに保存した Firefox と Zen のプロファイルも含まれます。検索はフォルダ名にも一致します。

Return を押すと保存元のブラウザでブックマークが開き、**⌘O** を押すとデフォルトのブラウザで開きます。**Return キー** でこの 2 つを入れ替えられます。

## ファイルを探す

ファイル検索は、デフォルトでは Mac 全体を検索します。検索フィールドのドロップダウンを使うと、この検索に限って **マイフォルダ**、**ホーム**、**ダウンロード** など 1 か所だけを検索できます。

Return を押すとファイルが開き、**⌘Return** を押すと Finder で表示します。**Return キー** でこの 2 つを入れ替えられます。

## 設定

**設定 → プラグイン** を開き、**クリップボード履歴**、**ブラウザのブックマーク**、**ファイル検索** のいずれかを選びます。

| 設定 | リスト | 変更される内容 |
| --- | --- | --- |
| **エイリアス** | 3 つすべて | SmartBar でそのリストを開くために、入力する語 (続けてスペース)。 |
| **ホットキーで専用ウインドウを開く** | 3 つすべて | オン: ホットキーでリストが専用のウィンドウで開きます。オフ: ホットキーで SmartBar の中で開きます。デフォルトはオンです。 |
| **Return キー** | 3 つすべて | Return の動作。クリップボード履歴: **最前面のアプリに貼り付け** または **クリップボードにコピー**。ブックマーク: **保存したブラウザで開く** または **デフォルトのブラウザで開く**。ファイル: **開く** または **Finderで表示**。 |
| **クリップボード履歴を記録** | クリップボード履歴 | コピーした内容の履歴を保存します。オフにしても、すでに保存された項目は残ります。 |
| **履歴の保存期間** | クリップボード履歴 | 項目を保存する期間。**1日** から **無期限** まで。デフォルトは 3 か月です。固定した項目は削除されません。 |
| **無視する App** | クリップボード履歴 | コピーを記録しないアプリ。バンドル ID で指定します。 |
| **フォルダ名を表示** | ブックマーク | 各ブックマークのフォルダを表示します。 |
| **オフにしたブラウザ** | ブックマーク | ブックマークを除外するブラウザ。 |
| **検索場所** | ファイル | ファイル検索を開いたときに検索する場所: **このMac**、**マイフォルダ**、**ホーム**、**デスクトップ**、**書類**、**ダウンロード**、**アプリ**。 |
| **検索フォルダ** | ファイル | **マイフォルダ** が検索するフォルダ。空の場合は、デスクトップ、書類、ダウンロードです。 |
| **隠しファイルを表示** | ファイル | 名前がドットで始まるファイルを含めます。 |
| **除外するフォルダ** | ファイル | 中身を表示しないフォルダ。 |

これらのリストの旧 Web 版で設定したショートカットやエイリアスは引き継がれます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ホットキーでウィンドウではなく SmartBar が開く | そのリストの **ホットキーで専用ウインドウを開く** をオンにします。 |
| クリップボード履歴にコピーしたものがない | **クリップボード履歴を記録** と **無視する App** を確認してください。パスワードなど秘匿されたコピーは記録されません。 |
| ブラウザのブックマークがない | **オフにしたブラウザ** を確認してください。 |
| ファイルが表示されない | **検索場所**、**除外するフォルダ**、**隠しファイルを表示** を確認してください。 |

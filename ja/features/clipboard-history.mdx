title: "クリップボード履歴、ブックマーク、ファイル検索"
description: "ホットキーや SmartBar から、コピーした履歴、ブラウザのブックマーク、Mac 内のファイルをすぐに検索できます。"
---

クリップボード履歴、ブラウザのブックマーク検索、ファイル検索は、入力しながら絞り込める 3 つのクイックリストです。前にコピーしたものを貼り付けるにはクリップボード履歴、保存したページを任意のブラウザで開くにはブックマーク検索、Finder を使わずにファイルを開くにはファイル検索を使います。それぞれ専用のホットキーから開くことも、SmartBar でエイリアスを入力して開くこともできます。

## リストを開く

1. **設定 → ショートカット**、または **設定 → プラグイン** にある各リストの設定ページでホットキーを設定します。
2. ホットキーを押します。デフォルトの **ホットキーでウィンドウを開く** がオンのときは、SmartBar をそのままに専用のウィンドウでリストが開きます。
3. 文字を入力してリストを絞り込み、矢印キーで項目を選んで Return キーを押します。

代わりに SmartBar の中でリストを開きたい場合は、**エイリアス** を設定します。SmartBar でそのエイリアスとスペースを入力するとリストが開きます。SmartBar の検索結果には各リストのエイリアスも表示されます。

チャット内でリストを `@` で指定すると、エージェントにそのリストを検索させることもできます。

## クリップボード履歴から貼り付ける

クリップボード履歴にはコピーしたテキスト、画像、ファイルが保存されます。お気に入りをピン留めしたり、リンク、メール、カラー、画像、ファイルで絞り込んだりできます。

1. クリップボード履歴を開きます。
2. コピーした内容に含まれる単語を入力します。
3. Return キーを押すと、直前に使っていたアプリへ貼り付けられます。代わりにコピーだけ行う場合は **⌘C** を押します。**Return キー** をコピーに設定している場合は、**⌘Return** で貼り付けます。

Enconvo 自身のウィンドウ上でこのリストを開いた場合、Return キーを押すとそのウィンドウのメッセージボックスに貼り付けられます。

パスワードマネージャーとキーチェーンアクセスはデフォルトで除外されており、パスワードなどアプリが秘匿または一時的とマークしたコピーは記録されません。

## ブックマークを開く

ブラウザのブックマーク検索は、Safari、Chrome、Edge、Brave、Arc、Dia、Vivaldi、Opera、Chromium、Comet、Firefox、Zen（指定フォルダに保存された Firefox や Zen のプロファイルを含む）のブックマークを読み取ります。検索ではフォルダ名も一致対象になります。

Return キーを押すとそのブックマークが元のブラウザで開き、**⌘O** を押すとデフォルトブラウザで開きます。**Return キー** の設定でこの 2 つを入れ替えられます。

## ファイルを探す

ファイル検索はデフォルトで Mac 全体を対象にします。検索欄のドロップダウンを使うと、**マイフォルダ**、**ホーム**、**ダウンロード** など、その 1 回の検索だけ特定の場所に絞れます。

Return キーでファイルを開き、**⌘Return** で Finder に表示します。**Return キー** の設定でこの 2 つを入れ替えられます。

## 設定

**設定 → プラグイン** を開き、**クリップボード履歴**、**ブラウザのブックマーク**、または **ファイル検索** を選択します。

| 設定 | 対象リスト | 内容 |
| --- | --- | --- |
| **エイリアス** | 3 つすべて | SmartBar でその後にスペースを入力してリストを開くためのキーワードです。 |
| **ホットキーでウィンドウを開く** | 3 つすべて | オン：ホットキーで専用ウィンドウを開きます。オフ：SmartBar 内で開きます。デフォルトはオンです。 |
| **Return キー** | 3 つすべて | Return キーの動作です。クリップボード履歴：**前面アプリに貼り付け** または **クリップボードにコピー**。ブックマーク：**保存したブラウザで開く** または **デフォルトブラウザで開く**。ファイル：**開く** または **Finderで表示**。 |
| **クリップボード履歴を記録** | クリップボード履歴 | コピー履歴の記録をオンにします。オフにしても保存済みの項目は残ります。 |
| **履歴の保持期間** | クリップボード履歴 | 項目を保持する期間（**1 日**〜**無期限**）。デフォルトは 3 か月です。ピン留めした項目は削除されません。 |
| **無視するアプリ** | クリップボード履歴 | コピーを記録しないアプリをバンドル ID で指定します。 |
| **フォルダ名を表示** | ブックマーク | 各ブックマークのフォルダ名を表示します。 |
| **無効にするブラウザ** | ブックマーク | ブックマークの読み込みから除外するブラウザです。 |
| **検索範囲** | ファイル | ファイル検索を開いたときの検索対象：**このMac**、**マイフォルダ**、**ホーム**、**デスクトップ**、**書類**、**ダウンロード**、または **アプリ**。 |
| **検索フォルダ** | ファイル | **マイフォルダ** が検索するフォルダです。空の場合はデスクトップ、書類、ダウンロードが対象になります。 |
| **隠しファイルを表示** | ファイル | ドット（`.`）で始まるファイル名も結果に含めます。 |
| **除外フォルダ** | ファイル | 中身を検索結果に表示しないフォルダです。 |

旧ウェブ版のリストで設定していたショートカットやエイリアスはそのまま引き継がれます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ホットキーでウィンドウではなく SmartBar が開く | そのリストの **ホットキーでウィンドウを開く** をオンにしてください。 |
| コピーした内容がクリップボード履歴にない | **クリップボード履歴を記録** と **無視するアプリ** を確認してください。パスワードなど秘匿されたコピーは記録されません。 |
| 特定のブラウザのブックマークが出てこない | **無効にするブラウザ** を確認してください。 |
| ファイルが検索結果に出ない | **検索範囲**、**除外フォルダ**、**隠しファイルを表示** を確認してください。 |

**メディア** は、Enconvo で作成したすべての画像、動画、音声クリップを集める 1 か所の場所です。ここで作ったものも、エージェントがチャットで作ったものも含まれます。設定を細かく制御して画像やクリップを生成したり、人物や製品の見た目を複数の作品で統一したり、作ったものを修正したり再利用したりできます。

**設定 → 画像生成** と **設定 → 動画生成** で設定したプロバイダーを使います。設定方法は[画像生成](/ja/ai/image-generation)と[動画生成](/ja/ai/video-generation)を参照してください。

## メディアを開く

チャットウィンドウのサイドバーで **メディア** をクリックします。上部で **画像**、**動画**、**音声** を選びます。

- **すべて**、**お気に入り**、各フォルダで、作ったものを整理できます。**新規フォルダ** をクリックして追加し、項目の **フォルダに移動** で振り分けます。
- **メディアを検索** に入力すると、プロンプトの言葉から項目を探せます。
- 星をクリックすると、項目が **お気に入り** に追加されます。

ファイルは Mac の `~/Enconvo/Media` にもあります。

新しいチャットのメッセージ欄の下で **画像** または **動画** を選ぶこともできます。モデル、設定、除外する内容がメッセージ欄の下にピルとして表示され、その下に、最近の画像や動画と **メディアを開く** リンクが並びます。

## 画像や動画を作る

1. **画像** または **動画** で、下部の入力欄に作りたいものを説明します。
2. その下のピルを確認します。モデル、**アスペクト比**、**品質**、画像の枚数、**除外**（含めたくない要素）です。ピルをクリックして変更するか、**その他の設定** で残りを設定します。選んだモデルが受け付ける設定だけが表示されます。
3. **生成** をクリックします。新しい項目は、完成した順に上部に表示されます。

複数のテイクを頼んだ場合は、残したいものを選びます。

### 動画の細かな制御

- **開始フレーム** と **終了フレーム**: クリップの開始または終了に使う画像を追加します。
- **ショットを追加**: 動画をショットに分割し、それぞれにプロンプトと長さを指定します。Enconvo が 1 つの動画につなぎます。
- **オーディオファイルを追加**: 自分の音声、または **音声** のクリップを使います。

## 被写体やスタイルを統一する

人物、ペット、製品、キャラクターの写真を数枚、被写体として保存するか、目指す雰囲気の画像を数枚、スタイルとして保存します。生成時にそれを選ぶと、すべての画像と動画で同じ見た目になります。

1. 入力欄で **被写体、スタイル、参照画像を追加** をクリックします。
2. **被写体** の下で **写真から作成** を選ぶか、**スタイル** の下で **新しいスタイル** を選びます。
3. **名前** を付け、**写真** を追加し、必要に応じて **説明して作る** を使います。
4. **保存** をクリックします。次に生成するときは、同じメニューから選びます。

## 作ったものを調整する

項目をクリックすると、詳細が開き、プロンプトと使われたすべての設定が表示されます。そこから次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| **設定を再利用** | 同じプロンプトと設定を入力欄に入力します |
| **動画にする** | この画像から動画を始めます |
| **アップスケール** | より大きく、よりシャープなコピーを作ります |
| **背景を削除** | 被写体を切り抜きます |
| **ライティングを変更** | 光と雰囲気を変更します |
| **一部を変更** | エディタを開き、変更したい範囲を塗ります |
| **その他の修正** | **古い写真を復元**、**アングルを変更**、**キャンバスを拡張**、**バリエーション** |
| **似たものをもっと作る** | 同じ設定から新しいテイクを作ります |

修正のたびに新しいバージョンが作られ、元のものは **バージョン** に残ります。**エディタで開く** をクリックすると、画像または動画のエディタで編集を続けられます。

## 音声を作る

1. **音声** を開き、**ミュージック**、**効果音**、**音声** のいずれかを選びます。
2. スタイルや音を説明するか、ナレーション用の言葉を入力します。音楽は、歌詞付きにすることも、**インストゥルメンタル** にすることもできます。
3. **生成** をクリックします。手元のファイルを使うには、**オーディオファイルを読み込む** をクリックします。

動画に音声を付けるには、動画を開いて **音声を追加** をクリックします。**あなたの音声** からクリップを選ぶか **ファイルを読み込む** を選び、**元の音とミックス** または **元の音を置き換える** を選んで、**動画に追加** をクリックします。

<Warning>
画像、動画、音声クリップはすべて、プロバイダーのクレジットまたは Enconvo Cloud のポイントを消費します。動画が最も高くつくので、まず短いものを試してください。
</Warning>

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 画像が被写体やフレームとして拒否される | PNG、JPEG、WebP の画像を使ってください |
| 使いたい設定が表示されない | 選んだモデルがその設定に対応していません。別のモデルを選んでください |
| 項目に **もう一度試す** と表示される | 失敗しています。プロバイダーのアクセスを確認してから、もう一度試してください |
| **音声** に音声やモデルがない | その種類の音声を作れるプロバイダーを設定してください。Enconvo Cloud は音声合成のみで、音楽と効果音には、自分の ElevenLabs のキーが必要です |

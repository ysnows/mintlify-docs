**メディア** は、自分で直接作成したかチャットでエージェントが作成したかにかかわらず、Enconvo で作ったすべての画像、動画、音声クリップをまとめる場所です。設定を細かく調整して画像やクリップを生成したり、人物や商品を同じ見た目のまま使い回したり、作った素材を修正・再利用したりできます。

**設定 → 画像生成** および **設定 → 動画生成** で設定したプロバイダーを使用します。設定方法は [画像生成](/ja/ai/image-generation) と [動画生成](/ja/ai/video-generation) を参照してください。

## メディアを開く

チャットウィンドウのサイドバーで **メディア** をクリックします。上部で **画像**、**動画**、または **音声** を選びます。

- **すべて**、**お気に入り**、および作成したフォルダで作品を整理できます。フォルダを作るには **新規フォルダ** をクリックし、整理するには項目の **フォルダに移動** を使います。
- **メディアを検索** に入力すると、プロンプトに含まれる言葉から項目を検索できます。
- 星アイコンをクリックすると **お気に入り** に追加されます。

ファイルは Mac 上の `~/Enconvo/Media` にも保存されています。

新しいチャットのメッセージボックスの下で **画像** や **動画** を選ぶこともできます。モデル、設定、除外したい内容がメッセージボックスの下にピルとして並び、その下に最近の画像や動画と **メディアを開く** リンクが表示されます。

## 画像や動画を作る

1. **画像** または **動画** タブで、下部の作成欄に作りたい内容を書きます。
2. その下のピル（モデル、**アスペクト比**、**品質**、生成枚数、**除外**（含めない要素））を確認します。ピルをクリックすると変更でき、それ以外の項目は **その他の設定** にあります。選んだモデルが対応している設定のみが表示されます。
3. **生成** をクリックします。完成した項目から順に上部へ表示されます。

複数のテイクを生成した場合は、残したいものを選んでください。

### 動画の細かな指定

- **開始フレーム** と **終了フレーム**: クリップの最初または最後に使いたい画像を追加します。
- **ショットを追加**: 動画を複数のショットに分割し、それぞれにプロンプトと長さを設定します。Enconvo がそれらを 1 本の動画につなぎます。
- **オーディオファイルを追加**: 手持ちの音声や **音声** タブにあるクリップを使用します。

## 被写体やスタイルを統一する

人物、ペット、商品、キャラクターの写真を数枚「被写体」として保存したり、好みのテイストの画像を数枚「スタイル」として保存したりできます。生成時に選ぶと、どの画像や動画でも同じ見た目を保てます。

1. 作成欄で **被写体、スタイル、参照画像を追加** をクリックします。
2. **被写体** の下の **写真から作成**、または **スタイル** の下の **新しいスタイル** を選びます。
3. **名前** を入力し、**写真** を追加して、必要に応じて **説明して作る** 欄に補足を書きます。
4. **保存** をクリックします。次回の生成時から同じメニューで選択できます。

## 作成した素材を仕上げる

項目をクリックすると、使用したプロンプトとすべての設定の詳細が開きます。そこから次の操作が行えます。

| 操作 | 内容 |
| --- | --- |
| **設定を再利用** | 同じプロンプトと設定を作成欄に読み込みます |
| **動画にする** | この画像を元にして動画作成を始めます |
| **アップスケール** | より大きく鮮明な画像を作成します |
| **背景を削除** | 被写体を切り抜きます |
| **ライティングを変更** | 光の当たり方や雰囲気を変えます |
| **一部を変更** | 変更したい箇所を塗れるエディタを開きます |
| **その他の修正** | **古い写真を復元**、**アングルを変更**、**キャンバスを拡張**、**バリエーション** |
| **似たものをもっと作る** | 同じ設定から新しいテイクを生成します |

修正を行うたびに新しいバージョンが作成され、元画像は **バージョン** に残ります。**エディタで開く** をクリックすると画像エディタまたは動画エディタで編集を続けられます。

## 音声を作る

1. **音声** を開き、**ミュージック**、**効果音**、または **音声** を選びます。
2. スタイルや音のイメージを記述するか、ナレーション用のテキストを入力します。ミュージックでは歌詞を入れることも、**インストゥルメンタル** にすることもできます。
3. **生成** をクリックします。手持ちのファイルを使う場合は **オーディオファイルを読み込む** をクリックします。

動画に音声を付けるには、動画を開いて **音声を追加** をクリックします。**あなたの音声** からクリップを選ぶか **ファイルを読み込む** で選択し、**元の音とミックス** または **元の音を置き換える** を選んで **動画に追加** をクリックします。

<Warning>
画像、動画、音声クリップの生成には、各プロバイダーのクレジットまたは Enconvo Cloud ポイントが消費されます。特に動画は消費が大きいため、最初は短いものから試してください。
</Warning>

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 被写体やフレームとして画像が受け付けられない | PNG、JPEG、または WebP 形式の画像を使ってください |
| 使いたい設定が表示されない | 選択中のモデルがその設定に対応していません。別のモデルを選んでください |
| 項目に **もう一度試す** と表示される | 生成に失敗しました。プロバイダーの接続状況を確認してから再試行してください |
| **音声** にボイスやモデルが表示されない | その種類の音声を作れるプロバイダーを設定してください。Enconvo Cloud はスピーチのみ対応しており、ミュージックと効果音にはご自身の ElevenLabs キーが必要です |

---
title: "会議の録音"
description: "会議や講義を録音し、その文字起こし、要約、フォローアップを確認します。"
---

録音は、会議や講義を、マイク、通話の音声、またはその両方から取り込み、人が話すのに合わせて文字起こしを書きます。あとから、要約を読んだり、話者に名前を付けたり、話された内容について質問したりできます。録音のモデルは、音声入力やファイルの文字起こしのモデルとは別に設定します。

## はじめる前に

- **設定 → 録音モデル**で、文字起こしモデルを選びます。
- macOS は、初めて録音するときに、マイクとシステムオーディオへのアクセスを求めます。使うソースについて、両方を許可してください。

<Note>
参加者に録音を知らせ、会議に適用される要件に従ってください。
</Note>

## 会議を録音する

<Steps>
  <Step title="新しい録音を開く">
    **設定 → 録音**を開いて**新規録音**をクリックするか、**録音を開始（会議／講義）**を実行します。
  </Step>
  <Step title="音声ソースを選ぶ">
    **マイク**を選び、録音する**通話の音声**を選びます。**オフ**はマイクだけ、**すべてのアプリ**は Mac が再生するすべての音、**1つのアプリ**は会議アプリの音だけを録音します。選ぶには、先に会議アプリを開いておきます。**文字起こし**のモデルを確認し、モデルが対応している場合は**リアルタイム翻訳**をオンにします。
  </Step>
  <Step title="録音を開始する">
    **録音を開始**をクリックし、ライブの文字起こしに言葉が表示されることを確認します。
  </Step>
  <Step title="停止する">
    終わったら**停止**をクリックし、**録音**で、保存された項目を開きます。
  </Step>
</Steps>

録音中は、一時停止と再開、メモの追加ができ、**⌘B** を押すと、その瞬間にブックマークを付けられます。録音は、進行に合わせて保存されるため、Enconvo が終了しても何も失われません。

あとからソースを変更するには、**新規録音**の横の矢印をクリックして、**音声ソースを選択…**を選びます。同じメニューの**会議のリマインダー**は、Zoom、Teams、FaceTime、WeChat の通話が始まったときに、録音するかどうかを Dynamic Island で尋ねます。

## 結果を確認する

録音を開くと、**文字起こし**が表示され、その横のサイドパネルに、**要約**、**アクションアイテム**、**メモ**のタブと、**AI に質問**があります。

- **文字起こし**: 誰が何を言ったかを、特に声が重なっている箇所で確認します。話者ラベルをクリックして、その話者に名前を付けます。以降、Enconvo は新しい録音でその声を認識します。繰り返し出てくる用語には、[辞書](/ja/configuration/speech-assets)を使います。
- **要約**: **会議の要約**には、概要、要点、決定事項、数字、時刻が録音のその瞬間にジャンプするタイムラインがあります。話者が 2 人以上いる場合、**通話時間**に、会話に占める各話者の割合が表示されます。
- **アクションアイテム**: 録音から見つかったタスクです。実行したらチェックを付けます。
- **メモ**: 録音中に追加したメモとブックマークです。**翻訳を表示**をオンにすると、各メモの下に、録音の出力言語での翻訳が追加されます。あなたのメモは、書いたままです。
- **AI に質問**: 録音について質問します。フォローアップを頼むときは、会議で担当者や期限が述べられている場合にだけ、それらを頼んでください。

サイドパネルの左端をドラッグすると、長い要約のために幅を広げられ、端をダブルクリックすると、デフォルトの幅に戻ります。幅は、すべての録音で保持されます。どのタブでも、テキストを選択してコピーできます。

## 要約の言語とテンプレートを選ぶ

録音のサイドパネルの上部で、要約、アクションアイテム、テンプレートの結果を書く**出力言語**と、テンプレートを選びます。文字起こしとあなた自身のメモは、元の言語のままです。

**会議の要約**のほかに、組み込みのテンプレートとして、**講義ノート**と**インタビューの要点**があります。録音のテンプレートは何度でも切り替えられ、各テンプレートの結果は保持されます。

独自のテンプレートを作るには、次のようにします。

<Steps>
  <Step title="テンプレートを開始する">
    サイドパネル上部のテンプレートメニューを開き、**新規テンプレート…**を選びます。
  </Step>
  <Step title="何を抜き出すかを伝える">
    **名前**を付け、録音から何を抜き出すかを、普通の言葉で説明します。**レイアウト**を選びます。**スマートレイアウト**は、カード、表、チェックリスト、フラッシュカード、クイズ、グラフを使えます。**プレーンテキスト**は、ほかの場所にコピーしやすい Markdown を書きます。
  </Step>
  <Step title="試してみる">
    **この録音で試す**をクリックして、結果を確認します。録音の内容は何も変わりません。
  </Step>
  <Step title="保存する">
    見つかったタスクを**アクションアイテム**タブに表示したい場合は、**タスクをアクションアイテムに送る**をオンにしてから、**テンプレートを保存**をクリックします。
  </Step>
</Steps>

新しい録音すべてが使う出力言語とテンプレートを設定したり、独自のテンプレートを編集または削除したりするには、**録音**ページの**新規録音**の横にある**要約の設定**をクリックします。

## 通話を確認する

Mac で録音した Enconvo の[会議](/ja/features/video-conference)の通話は、同じルームを使っていても、それぞれ**録音**に独自の項目ができます。メモをオンにした通話には、文字起こし、参加者、ビデオ、メモのドキュメントが表示されます。

通話のページは、**会議**の概要で開きます。

- **要約**と**アクションアイテム**: 各項目を誰が担当し、いつが期限かが表示されます。項目の**リマインダーに追加**をクリックすると、担当者と期限とともに、Apple のリマインダーに追加されます。
- **この通話で作成**: 通話中にエージェントが作成したドキュメントとホワイトボードです。
- **画面に表示された内容**: 共有画面でエージェントが見たものです。
- **この会議に質問**: 通話について質問します。

エージェントは、チャットで、以前の通話についての質問にも答え、各回答がどの会議から来たかを伝えます。

エージェントがかけた通話や受けた通話も、ここに保存できます。**設定 → エージェント電話**の**通話を録音**をオンにすると、各エージェントの通話が、文字起こしとともに**録音**に保存されます。[エージェント電話](/ja/features/agent-phone)をご覧ください。

## 手順が失敗したとき

文字起こし、タイトルの生成、検索のインデックス作成は、別々の段階です。あとの段階でのエラーは、音声や文字起こしが失われたという意味ではありません。長い録音は数分かかり、ページを離れても処理は続きます。Enconvo Cloud Fast では、300 分までの録音を、ファイル全体から文字起こしします。

ネットワークが切れている間にライブ字幕が止まった場合は、再接続され、保存された文字起こしは、録音全体をカバーしています。

録音の処理状況を読み、失敗した手順の**文字起こしを再試行**または**インデックス作成を再試行**を使います。問題を報告するときは、**サポート用の詳細をコピー**で、サポートが求める参照情報とログの場所を、録音を含めずにコピーできます。送る前に、個人情報が含まれていないか確認してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 音声がない | 選択したソースと、macOS のキャプチャの権限を確認します。 |
| マイクが使用中 | 録音を始める前に、音声入力または Live Talk を終了します。 |
| **利用できる文字起こしモデルがありません** | **設定 → 録音モデル**でモデルを選びます。 |
| 処理の手順が失敗した | 録音の処理状況から、その手順を再試行します。 |
| 要約の言語が違う | サイドパネル上部の**出力言語**を選びます。新しい録音には、**要約の設定**で設定します。 |
| アクションアイテムがない | **会議の要約**を使うか、**タスクをアクションアイテムに送る**をオンにしたテンプレートを使います。 |

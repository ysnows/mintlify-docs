---
title: "会議録音"
description: "会議や講義を録音し、文字起こし、要約、フォローアップを確認します。"
---

録音機能では、マイク、通話の音声、またはその両方から会議や講義を録音し、会話と同時に文字起こしを作成できます。録音後には要約を読んだり、話者に名前を付けたり、発言内容について質問したりできます。録音用モデルは、音声入力用やファイル文字起こし用のモデルとは別に設定されます。

## はじめる前に

- **設定 → 録音モデル** で文字起こしモデルを選択します。
- 初めて録音する際、macOS がマイクおよびシステム音声へのアクセス許可を求めます。使用するソースについて両方とも許可してください。

<Note>
録音を行うことを参加者に知らせ、会議に適用される要件に従ってください。
</Note>

## 会議を録音する

<Steps>
  <Step title="新しい録音を開く">
    **設定 → 録音** を開いて **新規録音** をクリックするか、**Start to Record (Meeting/Lecture)** を実行します。
  </Step>
  <Step title="音声ソースを選ぶ">
    **マイク** を選び、続いて録音する **通話の音声** を選びます。**オフ** はマイクのみ、**すべてのアプリ** は Mac で再生されるすべての音声、**1つのアプリ** はその会議アプリの音声だけを録音します。1 つのアプリを選ぶ場合は、先に会議アプリを開いておいてください。**文字起こし** モデルを確認し、モデルが対応している場合は **リアルタイム翻訳** をオンにします。
  </Step>
  <Step title="録音を開始する">
    **録音を開始** をクリックし、リアルタイムの文字起こしに言葉が表示されることを確認します。
  </Step>
  <Step title="停止する">
    終了したら **停止** をクリックし、**録音** に保存された項目を開きます。
  </Step>
</Steps>

録音中は一時停止と再開、メモの追加ができ、**⌘B** を押すとその時点をブックマークできます。録音内容は進行に合わせて保存されるため、Enconvo が終了しても失われません。

あとから音声ソースを変更するには、**新規録音** の横の矢印をクリックして **音声ソースを選択…** を選びます。同じメニューの **会議のリマインダー** をオンにすると、Zoom、Teams、FaceTime、または WeChat の通話が始まったときに Dynamic Island で録音するか尋ねます。

## 結果を確認する

録音を開くと、**文字起こし** の横に **要約**、**アクションアイテム**、**メモ** タブと **AI に質問** を備えたサイドパネルが表示されます。

- **文字起こし**: 誰が何と言ったかを確認できます（特に声が重なった箇所に便利です）。話者ラベルをクリックして名前を付けると、次回以降の新しい録音でも同じ声を認識するようになります。よく登場する用語には [辞書](/ja/configuration/speech-assets) を活用してください。
- **要約**: **会議の要約** では、概要、要点、決定事項、数値、そして時刻をクリックすると録音の該当箇所へジャンプするタイムラインが表示されます。話者が 2 人以上いる場合は、**通話時間** に各話者の発話割合が表示されます。
- **アクションアイテム**: 録音から見つかったタスクです。完了したらチェックを付けていけます。
- **メモ**: 録音中に追加したメモやブックマークです。**翻訳を表示** をオンにすると、各メモの下にその録音の出力言語での翻訳が追加されます（元のメモは入力したまま残ります）。
- **AI に質問**: 録音内容について質問できます。フォローアップを尋ねるときに「会議で明示されていた場合のみ担当者と期限を記載して」と指定することもできます。

長い要約を読むときはサイドパネルの左端をドラッグして広げられ、左端をダブルクリックするとデフォルトの幅に戻ります。調整した幅はすべての録音で維持されます。どのタブでもテキストを選択してコピーできます。

## 要約の言語とテンプレートを選ぶ

録音のサイドパネル上部で、要約・アクションアイテム・テンプレート結果を出力する **出力言語** と、使用するテンプレートを選択します。文字起こしとあなた自身のメモは、元の言語のまま残ります。

組み込みテンプレートには **会議の要約** のほか、**講義ノート** と **インタビューの要点** があります。1 つの録音に対して何度でもテンプレートを切り替えられ、各テンプレートの結果はそのまま保持されます。

独自のテンプレートを作成するには：

<Steps>
  <Step title="テンプレートを作成する">
    サイドパネル上部のテンプレートメニューを開き、**新規テンプレート…** を選択します。
  </Step>
  <Step title="抽出したい内容を指定する">
    **名前** を付け、録音から何を抜き出してほしいかを普通の言葉で記述します。**レイアウト** を選びます。**スマートレイアウト** ではカード、表、チェックリスト、フラッシュカード、クイズ、チャートを使え、**プレーンテキスト** では他へコピーしやすい Markdown で出力します。
  </Step>
  <Step title="試してみる">
    **この録音で試す** をクリックして出力結果を確認します。録音自体の内容は変更されません。
  </Step>
  <Step title="保存する">
    見つかったタスクを **アクションアイテム** タブに表示したい場合は **タスクをアクションアイテムに送る** をオンにし、**テンプレートを保存** をクリックします。
  </Step>
</Steps>

新しい録音に毎回適用する出力言語とテンプレートを設定したり、テンプレートを編集・削除したりするには、**録音** ページで **新規録音** の横にある **要約の設定** をクリックします。

## 通話を確認する

Mac で録音した Enconvo [ビデオ会議](/ja/features/video-conference) の通話は、同じルームを使っていても 1 回ごとに **録音** へ記録されます。メモが有効な通話では、文字起こし、参加者、動画、およびメモ用ドキュメントが表示されます。

通話ページを開くと、まず **会議** の概要が表示されます。

- **要約** と **アクションアイテム**（各担当者と期限付き）。項目の **リマインダーに追加** をクリックすると、担当者と期限付きで Apple リマインダーに登録されます。
- **この通話で作成**: 通話中にエージェントが作成したドキュメントやホワイトボード。
- **画面に表示された内容**: 共有画面上でエージェントが見ていた内容。
- **この会議に質問**: この通話について質問します。

チャット上で過去の通話についてエージェントに質問することもでき、エージェントはどの会議に基づく回答かを明示して答えます。

エージェントが発信・着信した通話もここに保存できます。**設定 → エージェント電話** で **通話を録音** をオンにすると、エージェントの通話が文字起こし付きで **録音** に保存されます。詳しくは [エージェント電話](/ja/features/agent-phone) を参照してください。

## ステップが失敗した場合

文字起こし、タイトル生成、検索インデックス作成はそれぞれ別の段階です。後半の段階でエラーが起きても、音声や文字起こしが失われたわけではありません。長時間の録音は数分かかり、ページを離れても処理は継続します。Enconvo Cloud Fast を使うと、最大 300 分の録音をファイル全体から文字起こしできます。

ネットワークが途切れてリアルタイム字幕が止まっても再接続され、保存される文字起こしには録音全体が含まれます。

録音のステータス表示を確認し、失敗したステップで **文字起こしを再試行** または **インデックス作成を再試行** を実行してください。問題を報告する際は、**サポート用の詳細をコピー** を使うとサポートに必要な参照情報とログの場所だけを録音ファイルなしでコピーできます。送信前に個人情報が含まれていないか確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 音声が入っていない | 選択した音声ソースと macOS の収録権限を確認してください。 |
| マイクが使用中になっている | 録音を開始する前に音声入力または Live Talk を終了してください。 |
| **文字起こしモデルの準備ができていません** | **設定 → 録音モデル** でモデルを選択してください。 |
| 処理ステップが失敗した | 録音のステータス表示から該当ステップを再試行してください。 |
| 要約の言語が違っている | サイドパネル上部の **出力言語** を選び直してください。新しい録音用の設定は **要約の設定** にあります。 |
| アクションアイテムが表示されない | **会議の要約** を使うか、**タスクをアクションアイテムに送る** をオンにしたテンプレートを使ってください。 |

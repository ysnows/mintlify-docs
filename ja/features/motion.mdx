title: "モーション"
description: "ティーザー、解説動画、ウォークスルーなどの音声付き短編アニメーション動画を Agent に作成させ、MP4 や GIF として書き出せます。"
---

モーションは、Agent がシーン、テキスト、画像から組み立てる短いアニメーション動画です。製品ティーザー、解説動画、操作ウォークスルー、アニメーションチャート、ロゴスティング、SNS 向けクリップなどを作成できます。チャットの横および **アーティファクト** ライブラリ上で再生でき、音声付きの MP4 または GIF として書き出せます。モーションはコードによってアニメーション化されるため、文字、価格、UI の細部まで正確に出力されます。AI 生成の実写・映像素材が必要な場合は、代わりに[動画生成](/ja/ai/video-generation)をご利用ください。

## モーションを作成する

1. 新しいチャットを開始してメッセージ入力欄の下にある **モーション** を選ぶか、任意のチャットでティーザー、解説動画、ウォークスルー、SNS クリップの作成を依頼します。
2. 見せたい内容、長さ、ターゲット層を伝えます。ベースにする台本や画像があれば添付してください。
3. 送信します。

例：

```text
A 30-second product teaser for our note-taking app, with captions.
Show quick capture, search, and sharing, and end on the logo.
```

Agent は最初に、動画全体の構成を **ラフカット**（各シーンを表すラベル付きの枠）として配置します。順番とタイミングを確認し、問題なければ続行を指示してください。この手順を飛ばしたい場合は、依頼時にその旨を伝えてください。

日付、価格、名前を指定しなかった箇所には、架空の値ではなくプレースホルダーが表示されます。正しい値を Agent に伝えて埋めてもらってください。

モーションを完了とする前に、Agent はバックグラウンドですべてのシーンを再生し、失敗したシーンや描画のずれを検出して、警告を修正するか残る理由を説明します。

## モーションに含められる要素

- カメラワーク、滑らかに動いてクリックするカーソル、手書き風のマーク、スポットライト
- 字幕チップ、1 語ずつ表示されるテキスト、光エフェクト
- 画像や動画クリップ
- Agent が作成する BGM と、お使いの[テキスト読み上げ](/ja/ai/text-to-speech)音声による字幕付きナレーション

## 視聴とレビュー

- **再生** をクリックするか、**タイムライン** に沿ってドラッグしてスクラブします。**前のフレーム** と **次のフレーム** で 1 フレームずつ送れます。
- **シーン** を開くと、任意のシーンへジャンプできます。
- **ループ** をオンにしたり、**全画面** に切り替えたり、音声を **ミュート** したりできます。
- **字幕をオフ** をクリックすると、ナレーションの字幕を非表示にできます。
- **コメント** をクリックすると、現在の再生位置にコメントを残せます。タイムライン上にマーカーとして表示されます。

シーンを変更したいときは Agent に依頼してください。指定した部分だけを修正します。

モーションは iPhone と Android アプリでも再生できます。詳しくは[アーティファクト](/ja/features/artifacts)をご覧ください。

## 書き出す

1. **書き出し** をクリックします。
2. **MP4 をダウンロード**、**字幕付き MP4 をダウンロード**、または **GIF をダウンロード** を選択します。
3. 進行状況が表示されるので完了まで待ちます。最大 4 GB までのファイルがダウンロードフォルダに保存されます。

MP4 には BGM とナレーションも含まれます。ほかの人やチームと共有するには、**共有** をクリックしてください。詳しくは[アーティファクト](/ja/features/artifacts)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 書き出しファイルのサイズが大きすぎる | モーションの尺を短くするか、解像度・フレームレートを下げてください。GIF の場合は代わりに MP4 をダウンロードしてください |
| モーションが日付・価格・名前を求めてくる | プレースホルダーを置き換える実際の値を Agent に伝えてください |
| **失敗したシーン** に件数が表示される | 失敗したシーンを修正するよう Agent に依頼してください |
| 描画ではなく枠だけが表示される | まだラフカットの段階です。続行するよう Agent に伝えてください |

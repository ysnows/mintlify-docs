画面に描画を使うと、エージェントに質問する前に、画面の一部に印を付けられます。矢印、円、ハイライト、メモを描いてから送信します。印を付けたスクリーンショットは、画像としてチャットに添付されます。直前に、チャットウィンドウなどほかの Enconvo のチャットを使っていた場合を除き、Dynamic Island に添付されます。

## 画面に印を付ける

1. 質問したい内容を前面に出します。
2. 右ダブルクリックして画面に描画を開くか、**設定 → 画面に描画**で設定した**ホットキー**を押します。
3. **先に範囲をキャプチャ**がオンの場合は、ドラッグして範囲を選びます。オフの場合は、ライブの画面の上に直接描きます。
4. ツールバーでツールを選び、対象の箇所に印を付けます。
5. **送信**(紙飛行機)をクリックするか、**⌘↩** を押します。
6. 添付された画像を確認し、「ハイライトした警告はどういう意味？」のように、リクエストを入力します。

画面に描画は、設定するまでホットキーがありません。右ダブルクリックは、すぐに使えます。

### 音声ラベルを追加する

左の **Option** キーを押したまま話すと、いま描いた図形を説明できます。話した内容が、図形の横にテキストとして表示されます。図形を描くたびに画面に描画に聞き取らせるには、ツールバーの**図形を描くたびに音声入力**をオンにし、ラベルごとに間を置いて終わらせます。

## ツール

| ツールまたは操作 | キー |
| --- | --- |
| 矢印 | **A** |
| 線 | **L** |
| ペン | **P** |
| 蛍光ペン | **H** |
| 四角形 | **R** |
| 円 | **O** |
| カウンター(番号付きのマーカー) | **N** |
| テキスト | **T** |
| 選択 | **V** |
| 消しゴム | **E** |
| 色 | **C** |
| 線の太さ | **⌘** + スクロール |
| ホワイトボード | **B** |
| カーソルのハイライト | **K** |
| 別名で保存… | **⌘S** |
| 送信 | **⌘↩** |

ツールバーには、**元に戻す**、**やり直す**、**消去**、**クリップボードにコピー**、**閉じる**もあります。

## 設定

**設定 → 画面に描画**を開きます。

| 設定 | 内容 |
| --- | --- |
| **先に範囲をキャプチャ** | 描く前に範囲を選びます。オフにすると、ライブの画面に直接描きます。デフォルトでオンです。 |
| **ホットキー** | 画面に描画を開く、または閉じます。デフォルトでは空です。 |
| **右ダブルクリック** | すばやく右ダブルクリックして、画面に描画を開く、または閉じます。デフォルトでオンです。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| オーバーレイが開かない | **設定 → 画面に描画**の**ホットキー**と**右ダブルクリック**を確認し、[macOS の権限](/ja/configuration/permissions)を確認します。 |
| アプリのウィンドウ全体だけでよい | 代わりに [Appshots](/ja/features/appshots) を使います。 |

title: "画面に描画"
description: "画面上に直接書き込んでポイントを差し示し、そのままエージェントに質問できます。"

画面に描画を使うと、エージェントに質問する前に画面の一部へ印を付けられます。矢印、円、ハイライト、メモなどを描き込んで送信すると、書き込み済みのスクリーンショットが画像としてチャットに添付されます。送信先は、直前にチャットウィンドウなどの別の Enconvo チャットを使っていた場合を除き、Dynamic Island になります。

## 画面に書き込む

1. 質問したい内容を最前面に表示します。
2. 右ダブルクリックで画面に描画を開くか、**設定 → 画面に描画** で設定した**ホットキー**を押します。
3. **先に範囲をキャプチャ**がオンの場合は、ドラッグして範囲を選択します。オフの場合は、ライブ画面の上に直接描画します。
4. ツールバーからツールを選び、伝えたい箇所に印を付けます。
5. **送信**（紙飛行機アイコン）をクリックするか、**⌘↩** を押します。
6. 添付された画像を確認し、「ハイライトした警告はどういう意味？」などのリクエストを入力します。

画面に描画には、自分で設定するまでホットキーが割り当てられていません。右ダブルクリックはすぐに使えます。

### 音声でラベルを追加する

左の **Option** キーを押したまま話すと、直前に描いた図形の内容を説明できます。話した言葉がその横にテキストとして表示されます。図形を描くたびに画面に描画が音声を待機するようにするには、ツールバーの**図形を描くたびに音声入力**をオンにし、各ラベルを話し終えたら少し間を置いてください。

## ツール

| ツールまたは操作 | キー |
| --- | --- |
| 矢印 | **A** |
| 直線 | **L** |
| ペン | **P** |
| ハイライター | **H** |
| 四角形 | **R** |
| 円 | **O** |
| 番号（連番マーカー） | **N** |
| テキスト | **T** |
| 選択 | **V** |
| 消しゴム | **E** |
| 色 | **C** |
| 線の太さ | **⌘** + スクロール |
| ホワイトボード | **B** |
| カーソルのハイライト | **K** |
| 別名で保存… | **⌘S** |
| 送信 | **⌘↩** |

ツールバーには**元に戻す**、**やり直す**、**消去**、**クリップボードにコピー**、**閉じる**もあります。

## 設定

**設定 → 画面に描画** を開きます。

| 設定 | 内容 |
| --- | --- |
| **先に範囲をキャプチャ** | 描画する前に範囲を選択します。オフにするとライブ画面上に直接描画できます。デフォルトでオンです。 |
| **ホットキー** | 画面に描画を開閉します。デフォルトでは未設定です。 |
| **右ダブルクリック** | 素早い右ダブルクリックで画面に描画を開閉します。デフォルトでオンです。 |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| オーバーレイが開かない | **設定 → 画面に描画** の**ホットキー**と**右ダブルクリック**、および [macOS のアクセス権限](/ja/configuration/permissions) を確認してください。 |
| アプリウィンドウ全体だけを送りたい | 代わりに [Appshots](/ja/features/appshots) を使用してください。 |

title: "Live Talk"
description: "エージェントに音声で通話し、会話をしながら相談できます。あなたの話を聞き、自分の声で答え、会話中にタスクを開始することもできます。"
---

Live Talk はエージェントとの音声通話機能です。キーを押し続ける必要なく話しかけることができ、エージェントは声で返答し、通話中でも有効になっているツールを使ってタスクを開始できます。音声をテキスト入力に変換したい場合は、[音声入力](/ja/features/dictation)をお使いください。

## はじめる前に

Enconvo には macOS のマイクアクセス権限が必要です。正常に動作するマイクとスピーカーを選択してください。通話で利用する Cloud サービスは Enconvo Cloud ポイントを消費しますが、ご自身の API キーや Mac 上のローカルモデルは消費しません。

## 通話を開始・終了する

1. 話したいエージェントのチャットを開きます。
2. マイクアイコンの横にある **Live Talk** をクリックし、通話がつながるのを待ちます。
3. そのまま話しかけてください。キーを押さえる必要はなく、エージェントが話している途中でもいつでも割り込んで話を止め、聞き役に回らせることができます。
4. 大きめの作業を頼むときは、求める結果と十分な背景情報を伝えてください。その作業は専用のチャットでタスクとして実行され、作業詳細を展開すると進捗や結果を確認できます。
5. マイクボタンでミュートし、通話終了ボタンで通話を切ります。通話を切ったあともタスクはそのまま実行を続けます。

会話したやり取りは通常のチャット履歴に保存されるため、あとからチャットを開き直して会話内容や作業詳細を確認できます。無言の状態が続いても、通話を切るまで接続は保たれます。チャット内のタスクリンクから通話に戻ることもできます。

## タスクを開始せずにその場で尋ねる

メモリや過去のチャットの検索、覚えたい事柄の保存、カレンダーやリマインダーの確認、メールの検索、MCP サーバーの読み取り専用ツールの利用など、エージェントがタスクを立ち上げずに通話内でそのまま処理できる操作もあります。詳細は設定の**クイックアクション**で確認できます。

長時間のタスクが動いている間は、エージェントがこれまでに分かった内容を声で伝えてくれます。

## エージェントを静かにさせる

「静かにして」や「しばらく黙っていて」と伝えてください。名前で呼びかけるか、もう話してよいと伝えるか、テキストを送るか、**QUIET** ステータスをクリックするまで、エージェントは何も返答せず報告も控えます。

## その他の通話方法

タスクであなたの確認が必要なとき、エージェントから iPhone アプリやあなたの電話番号宛てに発信することもできます。電話に出ると Live Talk が始まります。詳しくは[エージェントの電話](/ja/features/agent-phone)をご覧ください。

また、設定した[アバター](/ja/features/avatar)から通話を始める（話し手としてアバターが表示されます）ほか、[iPhone アプリ](/ja/integrations/iphone-app)の音声チャットから始めることもできます。iPhone アプリや Android アプリでの通話中は、**リモート画面**ツールで通話画面の上にパソコンの画面を小さなフローティングウィンドウとして表示できます。詳しくは [iPhone アプリ](/ja/integrations/iphone-app)をご覧ください。通話中にエージェントへ画面を見せるには、**ライブ画面**をオンにしてください。

## 設定

**設定 → Live Talk** を開きます：

| 設定 | 変更される内容 |
| --- | --- |
| **聞く** | 通話で声を聞き取る方法です。**Enconvo Cloud Fast**（デフォルト）と **ElevenLabs Scribe**（Scribe v3 Live）は話している最中の言葉をリアルタイムに聞き取ります。Mac 上で動くモデルや、任意の音声認識モデルも選べます。 |
| **考える** | エージェントが会話に使うモデルです。**チャットと同じ**（デフォルト）は、そのチャットが使っているプロバイダーの高速モデルを使用するため、ご自身の API キーを使っているチャットでの通話では Enconvo Cloud ポイントを消費しません。Enconvo Cloud を使うチャットでは Enconvo Fast になり、DeepSeek V4.1 Flash で応答し、見せた画像や画面も認識してそのモデルの料金で課金されます（有料プランやトライアル中の通話は無料のままです）。大きめの作業はエージェントに渡され、そのチャットで選んだモデルで実行されます。 |
| **話す** | エージェントが話す声です。デフォルトは ElevenLabs v4 Turbo です。Phonon は Mac 上で無料かつオフラインで動作します（英語のみ）。変更は次の通話から反映されます。 |
| **音声表現** | 会話の流れに合わせて声のトーンをどれだけ変えるかを設定します：**オフ**、**控えめ**、または**豊か**。ElevenLabs、Fish Audio、Gemini の音声で利用できます。 |
| **経過後に新しい会話を開始** | 前回の通話からこの分数以内にもう一度通話すると、前回の続きから再開します（アバター通話も含みます）。**0** にすると常に続きから話します。 |
| **クイックアクション** | **管理**をクリックすると**設定 → クイックアクション**が開き、頼んだときにタスクを立ち上げずその場でエージェントが実行する項目を確認できます。 |

<Note>
Live Talk の**考える**モデルはここで設定しますが、**設定 → AI モデル**の**タスクモデル**の下でも選択できます。
</Note>

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 通話が接続されない | 接続エラーの内容を確認し、**聞く**・**考える**・**話す**の設定を確認してください。Cloud サービスの場合は**設定 → ポイント使用量**でポイント残高を確認してください。 |
| マイクが使えない | 実行中の音声入力や録音を先に終了し、macOS のマイクアクセス権限を確認してください。 |
| エージェントが操作を実行できない | そのエージェントのツールと権限を確認してください。音声通話にすることでエージェントにないツールが追加されるわけではありません。 |
| 新しく選んだ声にならない | 音声の変更は次の通話から適用されます。 |
| 「オーディオデバイスが変更されました」と表示されて通話が切れる | マイクまたはスピーカーが繰り返し再起動しています。**システム設定 → サウンド**で別のデバイスを選び、もう一度通話を開始してください。 |
| エージェントが返事をしなくなった | 静かモードになっている可能性があります。名前で呼びかけるか、**QUIET** ステータスをクリックしてください。 |

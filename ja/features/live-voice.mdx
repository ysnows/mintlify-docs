title: "Live Talk"
description: "エージェントに電話をかけて話し合えます。エージェントは聞き取り、自分の声で答え、話している間にタスクを開始します。"
---

Live Talk は、エージェントとの音声通話です。キーを押さずに話すと、エージェントが声で答え、通話を続けながら、有効なツールを使ってタスクを開始できます。話した内容を入力テキストに変えたい場合は、代わりに[音声入力](/ja/features/dictation)を使います。

## はじめる前に

Enconvo には、macOS のマイクへのアクセスが必要です。動作するマイクとスピーカーを選択してください。通話で使うクラウドサービスは Enconvo Cloud のポイントを消費します。自分のキーや Mac 上のモデルを使う場合は消費しません。

## 通話を開始して終了する

1. 話したいエージェントとのチャットを開きます。
2. マイクの横にある **Live Talk** をクリックします。通話がつながるまで待ちます。
3. 話します。押したままにするキーはなく、エージェントの発話に重ねて話せば、いつでもエージェントを止めて聞かせられます。
4. 大きな作業は、望む結果を伝え、十分なコンテキストを添えます。作業は、専用のチャットでタスクとして実行されます。作業の詳細を展開すると、進行状況や結果を確認できます。
5. マイクのコントロールでミュートし、通話終了のコントロールで通話を終えます。通話を切ったあとも、タスクは実行され続けます。

話した内容は通常のチャット履歴に保存されるため、チャットを開き直すと、会話や作業の詳細を見返せます。静かな通話は、切るまで接続されたままです。チャット内のタスクのリンクから、通話に戻れます。

## タスクを開始せずに頼む

エージェントは、タスクを開始せずに、通話の中でそのまま行えることがあります。メモリや過去のチャットの検索、覚えておいてほしいと頼まれたことの保存、カレンダーとリマインダーの読み取り、メールの検索、MCP サーバーの読み取り専用ツールの利用などです。そのほかは、設定の**クイックアクション**に一覧があります。

長いタスクの間、エージェントはそのタスクがここまでに見つけたことを伝えます。

## エージェントを静かにさせる

エージェントに、静かにするよう、またはしばらく話さないよう伝えます。エージェントは何も答えず、知らせたいことを保留します。名前で呼ぶ、また話してよいと伝える、入力して話しかける、または**静かにしています**の表示をクリックするまで、そのままです。

## ほかの通話方法

タスクがあなたを必要とするときは、エージェントのほうから、iPhone アプリやあなたの電話番号に電話をかけることもできます。応答すると Live Talk が始まります。[エージェント電話](/ja/features/agent-phone)をご覧ください。

[アバター](/ja/features/avatar)から通話を開始することもできます。その場合は、アバターが話し手として表示されます。[iPhone アプリ](/ja/integrations/iphone-app)の音声チャットからも開始できます。iPhone または Android アプリでの通話中は、**リモート画面**ツールが、通話の上に重なる小さなフローティングウィンドウでコンピュータの画面を開きます。[コンピュータの画面を使う](/ja/integrations/iphone-app)をご覧ください。**ライブ画面**をオンにすると、通話中にエージェントがあなたの画面を見られます。

## 設定

**設定 → Live Talk** を開きます。

| 設定 | 変わること |
| --- | --- |
| **聞き取り** | 通話があなたの声をどう聞き取るかです。**Enconvo Cloud Fast**(デフォルト)と **ElevenLabs Scribe**(Scribe v3 Live)は、話した 1 語ずつをその場で聞き取ります。Mac 上で動くモデルや、任意の音声モデルも選べます。 |
| **思考** | エージェントが会話に使うモデルです。**チャットと同じ**(デフォルト)は、チャット自身のプロバイダの高速モデルを使うため、自分の API キーを使うチャットでの通話は Enconvo Cloud のポイントを消費しません。Enconvo Cloud のチャットでは Enconvo Fast になり、DeepSeek V4.1 Flash で答え、見せたものも認識し、そのモデルとして課金されます。有料プランまたはトライアルでの通話は無料のままです。大きな作業はエージェントに引き渡され、そのチャットで選ばれているモデルで実行されます。 |
| **話す** | エージェントが答える声です。デフォルトは ElevenLabs v4 Turbo です。Phonon は Mac 上で動作し、無料でオフラインで使えますが、英語のみです。次の通話から適用されます。 |
| **声の表現** | 会話に合わせて、各返答の口調をどの程度変えてよいかです。**オフ**、**控えめ**、**豊か**から選びます。ElevenLabs、Fish Audio、Gemini の音声で使えます。 |
| **新しい会話にするまで** | 前回の通話からこの分数以内にかけた通話は、続きから再開します。アバター通話も含みます。**0** にすると、常に続きから再開します。 |
| **クイックアクション** | **管理**を押すと**設定 → クイックアクション**が開きます。エージェントが、タスクを開始せずに、頼まれたときにその場で行うことの一覧です。 |

<Note>
Live Talk の**思考**モデルはここで設定します。**設定 → AI モデル**の**タスク用モデル**でも選べます。
</Note>

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 通話がつながらない | 接続エラーを読み、**聞き取り**、**思考**、**話す**の選択を確認します。クラウドサービスの場合は、**設定 → ポイント使用量**でポイントを確認します。 |
| マイクを使えない | 実行中の音声入力や録音を先に終了し、macOS のマイクへのアクセスを確認します。 |
| エージェントが操作を実行できない | そのエージェントのツールと権限を確認します。音声は、エージェントにないツールを追加しません。 |
| 新しい音声が使われない | 音声の変更は、次の通話から適用されます。 |
| 通話が「オーディオデバイスが変更されました」で終了する | マイクまたはスピーカーが再起動を繰り返しています。**システム設定 → サウンド**で別のものを選び、新しい通話を開始してください。 |
| エージェントが答えなくなった | 静かにしている可能性があります。名前で呼ぶか、**静かにしています**の表示をクリックします。 |

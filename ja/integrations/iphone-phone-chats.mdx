Phone chats は、iPhone アプリ自身のチャットです。Mac ではなく iPhone 上で動作するため、ペアリングした Mac がなくても使えます。各 Phone chat では、Enconvo Cloud ポイント、ご自身の API キー、または iPhone 上でサインインしたプランのいずれかを通じてモデルを利用します。Phone chats とパーソナル指示は Enconvo アカウントを通じて同期されます。

代わりに Mac 上で動作するチャットを続けたい場合は、[iPhone アプリ](/ja/integrations/iphone-app)をご覧ください。

## デフォルトモデルを選ぶ

1. iPhone で**設定 → AI モデル**を開きます。
2. **デフォルトモデル**をタップしてモデルを選びます。新しいチャットはこのモデルで始まります。
3. 1 つのチャットだけモデルを変えるには、そのチャット内のモデルピッカーを使います。

Mac に同じプロバイダーが設定されている場合、Mac 上の Enconvo も同じモデルで開始します。Mac のモデルが iPhone で利用できない場合は、**デフォルトモデル**の下にその旨が表示され、追加やサインインが必要な項目が案内されます。

## キーまたはプロバイダーを追加する

**AI モデル**には、Enconvo Cloud のほか、PipeLLM を含め iPhone 上で使えるすべてのプロバイダーが並びます。

1. プロバイダーをタップし、**API キーを追加**をタップして、プロバイダーのサイトで作成したキーを貼り付けます。
2. 一覧にないプロバイダーを追加するには、**プロバイダーを追加**をタップし、プロバイダー、**OpenAI 互換**、または **Anthropic 互換**を選びます。互換プロバイダーには、OpenAI の Chat Completions API / Responses API、または Anthropic の Messages API に対応したサーバーのアドレスが必要です。
3. プロバイダーの一覧に必要なモデルが見当たらない場合は、そのページで **ID でモデルを追加**をタップします。

キーは iCloud キーチェーンに保存され、そのキーが属するプロバイダーにのみ送信されます。

## プランでサインインする

次の 5 つのプロバイダーでは、API キーや Cloud ポイントを使わずに、すでにお支払いのプランを Phone chats で利用できます：

| プロバイダー | プラン | ボタン |
| --- | --- | --- |
| OpenAI | ChatGPT | **ChatGPT でサインイン** |
| xAI | Grok | **Grok でサインイン** |
| Mistral | Le Chat | **Mistral でサインイン** |
| GitHub Copilot | Copilot | **GitHub でサインイン** |
| Antigravity | Antigravity (Google) | **Google でサインイン** |

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル**でプロバイダーをタップします。OpenAI、xAI、Mistral の場合は**認証**の下にあるプランのカードを選びます。もう一方のカードは **API キー**で、現在 Phone chats が使っている方には**使用中**と表示されます。
  </Step>
  <Step title="サインインする">
    サインインボタンをタップし、開いたページでサインインを完了します。プランを契約しているアカウントを使ってください。
  </Step>
  <Step title="結果を確認する">
    プロバイダーのページに戻ると、ご自身のプラン、アカウント、プランに含まれるモデル数が表示されます。モデルを選ぶか、**デフォルトに設定**をタップして新しいチャットをそのモデルで始めます。
  </Step>
</Steps>

プランのサインイン情報はこの iPhone 内に留まります。iCloud や Mac には同期されず、Mac 側でも独自のサインインを保持します。プラン自体の利用上限が適用されます。

### GitHub Copilot

**GitHub でサインイン**をタップすると、アプリに GitHub コードが表示されます。**続ける**をタップするとコードがコピーされて GitHub のページが開くので、そこにコードを貼り付けて Enconvo を承認してください。GitHub のページを開いている間もコードは画面に残るため、何度でもコピーし直せます。

モデル一覧には、お使いの Copilot プランで利用できるモデルだけが表示されます。Copilot Free では有料プランより少ないモデルが提供されます。

### Antigravity

毎回サインインの前に **Antigravity にサインインする前に**が表示されます。Enconvo は Antigravity アプリ自身の Google クライアントを使用してサインインするため、Google が Antigravity 以外での利用を検知した場合に Antigravity アカウントが停止される恐れがあります。停止されても支障のないアカウントをお使いください。**同意する**で Google のサインインへ進み、**キャンセル**で変更せず戻ります。

Antigravity では、ご自身のプランに含まれる Gemini モデルと Claude モデルが、それぞれ Antigravity が提供する推論強度レベルとともに利用できます。

### ChatGPT の使用状況

OpenAI のページには、ChatGPT プランの 5 時間上限と週間上限の残り量、各上限のリセット日時、プランの更新日が表示されます。最新化するにはアカウントメニューの**使用状況を更新**をタップします。上限に達すると、リセットされるまでその旨が表示されます。

### サインアウト

プロバイダーを開き、アカウントメニューで**サインアウト**を選びます。サインアウト後は、そのプランを使っていたチャットに別のモデルを選ぶ必要があります。Mistral の場合、サインイン時に作成されたキーは Mistral ワークスペースに残ります。

## アプリを閉じたあとも返信を続ける

Enconvo Cloud モデルを使っている場合、アプリを離れたり iPhone をロックしたりしても返信処理を継続できます。メッセージ欄の**クラウドツール**で**クラウドで実行**をオンにしてください。ご自身のキーを使うチャットは常に iPhone 上で応答します。

## コンピュータで続ける

Phone chat をペアリング済みのコンピュータへ移し、そのコンピュータのエージェント、ファイル、ツールを使って続きを行えます。返信の生成中でも移行できます。

1. チャットのメニューを開くか、サイドバーでチャットを長押しして、**コンピュータで続ける**を選びます。メニューにはデフォルトの移行先コンピュータ名が表示されます。
2. コンピュータとエージェントを選んで確定します。

チャットはそのコンピュータへ移動し、そこで続行されます。共有されたチャットのリンクを開いたときも、どこで続けるか尋ねられます。

## アクションボタンからの音声チャット

アクションボタンから音声チャットを始めると、Dynamic Island に**Enconvo に画面を見せてもよろしいですか？**と表示されます。**音声のみ**を選ぶか、見ている画面を Enconvo に見せるには**画面を見せる**を選びます。通話コントロールの**画面を見せる**ボタンから、通話の途中で共有を開始・停止することもできます。

## 推論強度

思考を行うモデルを選ぶと、ピッカーが続いて推論強度の選択画面に進みます。モデルに対して選んだ強度はチャットのヘッダーにあるプロバイダー名の横に表示され、そのモデルを使うすべてのチャットに適用されます。プランのページには、ご自身のプランで提供されているレベルだけが表示されます。

## 長いチャット

長いチャットがモデルのコンテキストウィンドウに近づくと、Mac の場合と同様に、同じモデルが古いメッセージを要約します。チャット自体はすべてのメッセージを保持し、要約が始まる箇所に**コンテキストを圧縮しました**の印が表示されます。この機能は常にオンです。

## トラブルシューティング

| 表示される状態 | 対処方法 |
| --- | --- |
| **ChatGPT のサインインが完了しませんでした**（または Grok、Mistral、GitHub Copilot、Antigravity） | **もう一度サインイン**をタップし、開いたページでサインインを完了してください。 |
| **お使いのプランでは利用できません**と表示される | プランの一覧から別のモデルを選んでください。Copilot Free では一部のモデルのみ提供されます。 |
| **モデルを読み込み中…**が終わらない | iPhone のネットワーク接続を確認し、プロバイダーのページを一度閉じて開き直してください。 |
| Mac のデフォルトモデルが iPhone にない | **デフォルトモデル**の下の案内どおりに、そのプロバイダーのキーを追加するかプランでサインインしてください。 |

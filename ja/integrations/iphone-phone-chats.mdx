title: "iPhone のチャット"
description: "iPhone 自体で AI モデルとチャットします。デフォルトモデルの選択、プロバイダーとキーの追加、ChatGPT、Grok、Le Chat、GitHub Copilot、Antigravity でのサインインに対応しています。"
---

iPhone のチャットは、iPhone アプリ自身のチャットです。Mac ではなくスマートフォン上で動くため、Mac をペアリングしていなくても使えます。iPhone のチャットでは、Enconvo Cloud のポイント、自分の API キー、iPhone でサインインしたプランのいずれかを通じてモデルを使います。iPhone のチャットと個人用の指示は、Enconvo アカウントを通じて同期されます。

代わりに Mac 上で動くチャットを続けるには、[iPhone アプリ](/ja/integrations/iphone-app)をご覧ください。

## デフォルトモデルを選ぶ

1. iPhone で **設定 → AI モデル** を開きます。
2. **デフォルトモデル** をタップして、モデルを選びます。新しいチャットはそのモデルで始まります。
3. 1 つのチャットのモデルを変えるには、そのチャットのモデルピッカーを使います。

Mac がそのプロバイダーを持っている場合、Mac の Enconvo も同じモデルで始まります。Mac のモデルが iPhone で使えないときは、**デフォルトモデル** の下にそう表示され、追加するものやサインインするものが提案されます。

## キーまたはプロバイダーを追加する

**AI モデル** には、Enconvo Cloud と、スマートフォンで使えるすべてのプロバイダー(PipeLLM を含む)が一覧表示されます。

1. プロバイダーをタップし、**APIキーを追加** をタップして、プロバイダーのサイトで作成したキーを貼り付けます。
2. 一覧にないプロバイダーを追加するには、**プロバイダーを追加** をタップして、プロバイダー、**OpenAI 互換**、**Anthropic 互換** のいずれかを選びます。互換プロバイダーには、OpenAI の Chat Completions API または Responses API、あるいは Anthropic の Messages API に対応したサーバーのアドレスが必要です。
3. 必要なモデルがプロバイダーの一覧にないときは、そのページで **ID でモデルを追加** をタップします。

キーは iCloud キーチェーンに保管され、そのキーのプロバイダーにだけ送信されます。

## プランでサインインする

5 つのプロバイダーでは、すでに契約しているプランを、API キーも Cloud ポイントも使わずに iPhone のチャットで使えます。

| プロバイダー | プラン | ボタン |
| --- | --- | --- |
| OpenAI | ChatGPT | **ChatGPT でログイン** |
| xAI | Grok | **Grok でログイン** |
| Mistral | Le Chat | **Mistral でログイン** |
| GitHub Copilot | Copilot | **GitHub でサインイン** |
| Antigravity | Antigravity(Google) | **Google でログイン** |

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル** で、プロバイダーをタップします。OpenAI、xAI、Mistral では、**認証** の下でプランのカードを選びます。もう 1 つのカードは **API キー** で、いま iPhone のチャットが使っているほうに **使用中** と表示されます。
  </Step>
  <Step title="サインインする">
    サインインボタンをタップし、開いたページでサインインを完了します。プランのあるアカウントを使ってください。
  </Step>
  <Step title="結果を確認する">
    プロバイダーのページに戻ると、プラン、アカウント、プランで使えるモデル数が表示されます。モデルを選ぶか、**デフォルトに設定** をタップして、新しいチャットをそのモデルで始めます。
  </Step>
</Steps>

プランのサインインは、この iPhone にだけ保存されます。iCloud や Mac には同期されず、Mac は自分のサインインを保持します。プラン自体の使用上限が適用されます。

### GitHub Copilot

**GitHub でサインイン** のあと、アプリに GitHub のコードが表示されます。**続ける** でコードがコピーされ、GitHub のページが開くので、コードを貼り付けて Enconvo を承認します。GitHub のページを開いている間もコードは画面に残るので、もう一度コピーできます。

モデルの一覧には、Copilot のプランで使えるモデルだけが表示されます。Copilot Free は、有料プランよりモデルが少なくなります。

### Antigravity

サインインのたびに、アプリが **Antigravity にサインインする前に** を表示します。Enconvo は Antigravity アプリ自身の Google クライアントでサインインするため、Antigravity 以外での使用を Google が検知すると、その Antigravity アカウントが停止されることがあります。失ってもかまわないアカウントを使ってください。**同意する** で Google のサインインに進み、**キャンセル** では何も変わりません。

Antigravity では、プランの Gemini モデルと Claude モデルを、Antigravity が用意している推論の強度とともに使えます。

### ChatGPT の使用量

OpenAI のページには、ChatGPT プランの 5 時間と週ごとの上限の残り、各上限のリセット時刻、プランの更新日が表示されます。アカウントメニューの **使用量を更新** をタップすると更新されます。上限に達すると、リセットされるまでページにそのことが表示されます。

### ログアウト

プロバイダーを開き、アカウントメニューの **ログアウト** を選びます。ログアウトすると、そのプランを使っているチャットは別のモデルが必要になります。Mistral では、サインインで作られたキーが Mistral のワークスペースに残ります。

## アプリを離れても返信を続ける

Enconvo Cloud のモデルでは、アプリを離れたりスマートフォンをロックしたりしても、返信を続けられます。メッセージボックスの **Cloud ツール** で、**クラウドで実行** をオンにします。自分のキーを使うチャットは、常にスマートフォン上で答えます。

## コンピュータで続ける

iPhone のチャットをペアリングしたコンピュータに移すと、そのコンピュータのエージェント、ファイル、ツールを使って続けられます。返信の実行中でも移せます。

1. チャットのメニューを開くか、サイドバーでチャットを長押しして、**コンピュータで続ける** を選びます。メニューには、既定の移動先のコンピュータが表示されます。
2. コンピュータとエージェントを選んで、確定します。

チャットはそのコンピュータに移り、そこで続きます。共有されたチャットのリンクを開いたときも、どこで続けるかを尋ねられます。

## アクションボタンからの音声チャット

アクションボタンで音声チャットを始めると、Dynamic Island に **Enconvo に画面を見せますか?** と表示されます。**音声のみ** を選ぶか、読んでいるものを Enconvo に見せるために **画面を見せる** を選びます。通話中のコントロールにある **画面を見せる** ボタンで、通話の途中でも共有を開始・停止できます。

## 推論の強度

考えるモデルを選ぶと、ピッカーが推論の強度の選択に進みます。モデルに選んだ強度は、チャットのヘッダーのプロバイダーの横に表示され、そのモデルを使うすべてのチャットに適用されます。プランのページには、そのプランで使える強度だけが表示されます。

## 長いチャット

長いチャットがモデルのコンテキストウィンドウに近づくと、Mac と同じように、同じモデルが古いメッセージを要約します。チャットはすべてのメッセージを保持し、**コンテキストを圧縮しました** のマークが要約の開始位置を示します。この機能は常にオンです。

## トラブルシューティング

| 表示 | 対処 |
| --- | --- |
| **ChatGPT のサインインが完了しませんでした**(Grok、Mistral、GitHub Copilot、Antigravity も同様) | **再度ログイン** をタップし、開いたページでサインインを完了してください。 |
| **プランでは** モデルが **提供されていません** | プランの一覧から別のモデルを選んでください。Copilot Free では、一部のモデルしか提供されません。 |
| **モデルを取得中…** が終わらない | iPhone のネットワーク接続を確認し、プロバイダーのページを一度閉じてから開き直してください。 |
| Mac のデフォルトモデルが iPhone にない | **デフォルトモデル** の下のメモに従って、プロバイダーのキーを追加するか、そのプランにサインインしてください。 |

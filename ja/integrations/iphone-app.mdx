Enconvo の iPhone アプリを Mac とペアリングすると、Mac のプロジェクトやチャットを iPhone からそのまま利用できます。iPhone から開いたすべてのチャットは引き続き Mac 上で動作し、Mac のファイル、アプリ、Agent をそのまま使えます。このチュートリアルでは、サインインから Mac でのペアリングコード表示、iPhone でのスキャンまでを一通り説明します。

<YouTubePlayer videoId="rYhgz_SjnNs" title="How to Pair Your iPhone with Your Mac in Enconvo | Step-by-Step Tutorial" />

動画の長さは 1 分 12 秒です。以下の手順も動画と同じ順序になっており、各ステップに対応する再生時間を記載しています。

<Note>
iPhone アプリは現在ベータ版です。[TestFlight](https://testflight.apple.com/join/MJQuEN28) からインストールするか、Mac の **設定 → 接続** にある **スマートフォンアプリを入手** の QR コードをスキャンしてください。ペアリングには Mac 側で Enconvo 2.5.6 beta 以降が必要です。TestFlight 版 iPhone アプリと Google Play 版 Android アプリはアメリカ大陸、ヨーロッパ、中東、日本、韓国、東南アジアで利用できます。Android APK はどの地域でもインストール可能です。
</Note>

## iPhone をペアリングする

Windows PC、Linux デスクトップ、またはターミナルのみの Linux サーバーとペアリングする場合は、[スマートフォンとペアリング](/ja/integrations/pair-your-phone) を参照してください。

<Steps>
  <Step title="iPhone でサインインする (0:07)">
    iPhone アプリをインストールし、Mac と同じ Enconvo アカウント（Apple、Google、またはメールで届く 6 桁コード）でサインインします。ペアリングできるのは、同じアカウントでサインインしているスマートフォンのみです。無料アカウントでもペアリング、Mac のチャット利用、リモート画面、アバターを利用できます。
  </Step>
  <Step title="ペアリングコードを表示する (0:16)">
    Mac で **設定 → 接続** を開き、**ペアリングコードを表示** を選択します。QR コードの有効期限は 5 分間です。期限が切れた場合は **新しいコードを表示** を選択してください。
  </Step>
  <Step title="iPhone でスキャンする (0:22)">
    iPhone で **リモート** を開き、**コンピュータをペアリング**（動画内では **Pair a Mac**）をタップして Mac の画面上のコードにカメラを向けます。iPhone の標準カメラでもスキャンでき、Enconvo が開いて Mac の確認画面が表示されます。すぐにペアリングが完了します。スマートフォンは Enconvo リレー経由で Mac に接続し、メッセージはエンドツーエンドで暗号化されます。
  </Step>
  <Step title="iPhone 上で Mac を使う (0:34)">
    リモート画面で Mac が **オンライン** と表示されると、Mac のプロジェクトとチャットが iPhone に表示されます。
  </Step>
  <Step title="任意のチャットを開く (0:40)">
    任意のチャットを開いて、前回の続きからやり取りできます。チャットは引き続き Mac 上で実行されるため、その Mac のファイル、アプリ、Agent をそのまま使用できます。
  </Step>
  <Step title="常に接続できる状態を保つ (0:47)">
    **接続**（または **設定 → スリープ防止**）で **この Mac のスリープを解除したままにする** をオンにします。バッテリー駆動時も含めて Mac のスリープを防ぐため、iPhone からいつでも接続できるようになります。画面をオンのままにする設定、一定時間後に画面をオフにする設定、あるいは蓋を閉じた状態でもスリープしない設定（初回のみ管理者パスワードが必要）も選べます。
  </Step>
  <Step title="スマートフォンを削除する (0:52)">
    スマートフォンを紛失した場合は、**接続 → ペアリング済みのスマートフォン** で該当端末の横にある **削除** を選択します。その端末からは Mac にアクセスできなくなります。再度使うには新しいコードでペアリングし直してください。
  </Step>
</Steps>

Mac のコードの下にその旨が表示されている場合、コードをスキャンすると iPhone 側の Enconvo アカウントへのサインインも同時に行われます。このコードはご自身の iPhone でのみスキャンしてください。

## スマートフォンからできること

ペアリングが完了すると、次の操作を行えます:

- Mac のプロジェクトやチャットを閲覧し、任意のチャットを続ける。
- Mac 上で作業中の Agent からの質問に答える。
- チャットの処理が完了したときに通知を受け取り、通知から直接返信する。
- **リモート画面** で Mac の画面を見て操作する。
- Enconvo Cloud ポイント、独自の API キー、またはサインイン済みのプラン（ChatGPT、Grok、Le Chat、GitHub Copilot、Antigravity）を使って、スマートフォン単体で AI モデルとチャットする。詳しくは [スマートフォンのチャット](/ja/integrations/iphone-phone-chats) を参照してください。
- 友人やチームメンバーとチャットや通話を行ったり、ビデオ会議に参加したりする。詳しくは [スマートフォンでの通話とフレンド機能](/ja/integrations/phone-calls-and-friends) を参照してください。

アプリ内では、ペアリングされた Mac、Windows PC、Linux マシンをまとめて **コンピュータ** と呼びます。特に記載がない限り、Android アプリでも同じように動作します。

## コンピュータのチャットを操作する

コンピュータから開いたチャットは、バックグラウンドタスク、サブエージェント、操作の軌道修正（ステアリング）を含め、コンピュータ上と同じように表示・動作します。

- **ホーム** ではメッセージ入力欄のすぐ上にアクティブなチャットが表示されます。カードのグラバーを上にスワイプするか **すべて** をタップすると、ユーザーの確認待ち、実行中、結果ありのグループに分かれたすべてのアクティブなチャットを確認できます。
- サイドバーの **アクティブ** グループには、確認待ち・失敗・実行中・未読の結果があるチャットがまとまります。青いドットは未読の結果を、回転するリングは実行中のチャットを示します。**ピン留め** と **最近** は折りたたむことができます。
- 応答の生成中に送信したメッセージは、Mac 上で Return を押したときと同様に実行中のタスクへの軌道修正として送られます。その間、入力欄には「実行中のタスクに指示を追加…」と表示されます。
- サブエージェントをタップすると、そのステップがチャット上のシートに開きます。最新のステップが開き、新しい出力がリアルタイムで追従します。下にスワイプすると閉じます。
- 承認を求める質問では、Mac 上と同じく Agent が提示した選択肢を選べます。
- チャットの Agent を変更するには、チャットタイトルの下の Agent 名をタップします。**ここからフォーク** ではフォーク先の Agent を選択できます。
- モデルシートにはサブスクリプションのプラン、5 時間上限および週間上限の残量とリセット時刻、さらに各モデル行ごとの固有上限が表示されます。
- 写真ライブラリから写真や動画を添付できます。動画はそのままコンピュータに送信されます。
- アプリの **設定 → アバター** で、メッセージ入力欄の通話ボタンにアバターアイコンと音声波形アイコンのどちらを表示するか選べます。

コンピュータがオフラインまたは再接続中でも、送信操作自体は行えます。一般的な質問やウェブ検索などスマートフォン単体で答えられるものはその場で応答し、コンピュータが必要なメッセージは接続が回復した時点で送信されます。

スマートフォンで開けないドキュメントやリンクは、コンピュータ側で開くよう案内が表示されます。

## コンピュータの画面を操作する

**ホーム** 右上のディスプレイアイコン、またはチャットメニューの **リモート画面** をタップすると、コンピュータの画面を表示して操作できます。

| モード | タッチ操作の動作 |
| --- | --- |
| **トラックパッド** | 画面上のどこをスライドしてもポインタが移動し、タップするとポインタ位置をクリックします。使いながらジェスチャーを覚えられるヒントが表示されます。 |
| **タッチ** | タップした位置を直接クリックします。 |
| **閲覧のみ** | 操作は行わず、画面を見るだけになります。 |

モードボタンには現在のモード名が表示されます。ピンチ操作で拡大・縮小でき、**トラックパッド** モードではポインタを中心に拡大し、ポインタの動きに追従します。

他の作業をしながら画面を浮かせて表示し続けるには、左上のピクチャ・イン・ピクチャボタンをタップするか、ピンチインします。チャット画面の上や、Enconvo 以外のアプリを開いているときにも画面がフローティング表示されます。

Live Talk の通話中に **リモート画面** ツールを使うと、通話画面の上に小さなフローティングウィンドウで画面が開きます。トラックパッドと同様に操作でき、**タッチ** や **閲覧のみ** に切り替えるモードチップ、コンピュータに入力するキーボードボタン、通常表示を開く **フルスクリーン** ボタンを備えています。

## 通知

- 応答が完了したときの通知には、応答の冒頭が表示されます。通知上の **返信** を使えば、アプリを開かずに返信できます。
- アプリを開いている間や Mac を操作している間は通知は届きません（スマートフォンから送信したメッセージに対する通知を除く）。
- 1 つのデバイスで完了したチャットを読むと、他のデバイス上の通知は消えます。回答待ちの質問の通知は残ります。
- Android 14 以降で通知が表示されない場合は、アプリの「設定」から **全画面通知** がオフになっていないか確認し、オンにしてください。

## 他アプリから Enconvo に共有する

他のアプリからページ、写真、ファイルを Enconvo に共有すると **送信先** シートが開き、新しいチャットまたは最近のチャットを選択できます。毎回確認せずに新しいチャットへ送りたい場合は、シート内またはアプリの設定で **常に新しいチャットに共有** をオンにしてください。

## プロジェクトとアーティファクト

- プロジェクトの **アイデア** と **ボード** を開き、設定変更、**新規プロジェクト** の作成、ワークプランカード上の操作（回答、マージ、タスクの開始・再試行、Pull Request の作成、アイデアの記録と開始）を行えます。
- `@` メニューにはプロジェクトのメンバー、ワークフロー、参加可能な Agent が一覧表示されます。
- スライド、ダッシュボード、モーション動画はチャットまたはアーティファクトライブラリから開け、コメント、@Enconvo への質問、共有、書き出し、プレゼンを行えます。

## Android アプリ

Android アプリも同様にペアリングして動作します。Google アカウント、またはメールで届く 6 桁コードでサインインしてください。メッセージ入力欄は 1 行に収まっており、カメラボタン、コンピュータ・プロジェクト・**スキル** 用のクイックチップ、最近の写真や動画を選べるプラスパネルを備えています。

enconvo.com からダウンロードした Android アプリは、起動するたびにアップデートを確認します。**このバージョンをスキップ** を選ぶとさらに新しいバージョンが出るまで非表示になり、**後で** を選ぶと次回起動時まで通知を非表示にします。

## ペアリング済みスマートフォンを管理する

**設定 → 接続** にはペアリング済みのすべてのスマートフォンが一覧表示され、現在スマートフォンからこの Mac に到達できるかも確認できます。

| 操作 | 手順 |
| --- | --- |
| 別のスマートフォンをペアリングする | **別のスマートフォンをペアリング** を選択し、新しいコードをスキャンします。1 台の Mac に最大 10 台のスマートフォンをペアリングできます。 |
| スマートフォンの名前を変更する | スマートフォンをクリックし、名前の横にある **スマートフォンの名前を変更** をクリックします。 |
| スマートフォンを削除する | **ペアリング済みのスマートフォン** で対象端末の横にある **削除** を選択します。 |
| 最初からやり直す | **接続をリセット** を選択します。Enconvo が新しい接続キーを生成し、ペアリング済みのすべてのスマートフォンを削除します。その後、各端末で新しいコードをスキャンしてください。 |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| スマートフォンから Mac に接続できない | Mac がスリープしておらず、サインイン済みでオンラインになっており、**接続** で **オンライン** と表示されていることを確認してください。常に接続できるように **この Mac のスリープを解除したままにする** をオンにしてください。 |
| Mac がメッセージ・画面・ターミナルを拒否したと表示される | Mac 側でその端末に対するデバイスアクセスが許可されていません。スマートフォンに表示される手順に従ってください。 |
| コードに **このコードは期限切れです** と表示される | **新しいコードを表示** を選択し、5 分以内に再度スキャンしてください。 |
| Mac に **スマートフォンをペアリングするにはサインインしてください** と表示される | **サインイン** をクリックし、Mac でサインインしてください。iPhone と Mac で同じ Enconvo アカウントを使う必要があります。 |
| Mac に **新しい接続キーが必要です** と表示される | バックアップからの復元後などで、リレー側に異なるキーが登録されています。**接続をリセット** を選択し、各スマートフォンを再ペアリングしてください。 |
| **コンパニオンアクセスがオフになっています** と表示される | いずれかのデバイスからアクセスがオフにされました。**アクセスを再度オンにする** を選択するまで、スマートフォンから Mac に接続できません。 |

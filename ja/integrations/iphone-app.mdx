title: "iPhone アプリ"
description: "Enconvo の iPhone アプリを Mac とペアリングして、Mac のチャットをスマートフォンで続けます。"
---

Enconvo の iPhone アプリは Mac とペアリングでき、Mac のプロジェクトやチャットがスマートフォンに表示されます。スマートフォンから開いたチャットは、Mac のファイル、アプリ、エージェントを使って、Mac 上で動き続けます。このガイドでは、スマートフォンのペアリングを最初から最後まで説明します。サインインし、Mac にペアリングコードを表示して、iPhone でスキャンします。

<Note>
iPhone アプリはベータ版です。[TestFlight](https://testflight.apple.com/join/MJQuEN28) からインストールするか、Mac の **設定 → 接続** にある **スマートフォンアプリを入手** の TestFlight コードをスキャンしてください。ペアリングには、Mac に Enconvo 2.5.6 ベータ以降が必要です。TestFlight の iPhone アプリと Google Play の Android アプリは、南北アメリカ、ヨーロッパ、中東、日本、韓国、東南アジアで利用できます。Android の APK は、どこでもインストールできます。
</Note>

## iPhone をペアリングする

Windows PC、Linux デスクトップ、ターミナルしかない Linux サーバーとペアリングするには、[スマートフォンをペアリング](/ja/integrations/pair-your-phone)をご覧ください。

<Steps>
  <Step title="iPhone でサインインする">
    iPhone アプリをインストールし、Mac と同じ Enconvo アカウントでサインインします。Apple、Google、またはメールで届く 6 桁のコードでサインインできます。ペアリングできるのは、そのアカウントにサインインしているスマートフォンだけです。無料アカウントでもペアリングでき、Mac のチャットとリモート画面、アバターを使えます。
  </Step>
  <Step title="ペアリングコードを表示する">
    Mac で **設定 → 接続** を開き、**ペアリングコードを表示** を選びます。QR コードは 5 分間有効です。期限が切れたら、**新しいコードを表示** を選びます。
  </Step>
  <Step title="iPhone でスキャンする">
    スマートフォンで **リモート** を開いて **コンピュータをペアリング** をタップし、Mac のコードにカメラを向けます。iPhone のカメラでも読み取れます。Enconvo が開き、そこで Mac を確認します。ペアリングはすぐに完了します。スマートフォンは Enconvo のリレーを通じて Mac に接続し、メッセージはエンドツーエンドで暗号化されます。
  </Step>
  <Step title="Mac をスマートフォンで">
    リモートで Mac が **オンライン** と表示されたら、Mac のプロジェクトとチャットがそのままスマートフォンに表示されます。
  </Step>
  <Step title="チャットを開く">
    チャットを開いて、続きから再開します。チャットは引き続き Mac 上で動くので、その Mac のファイル、アプリ、エージェントを使えます。
  </Step>
  <Step title="接続できる状態を保つ">
    **接続**(または **設定 → スリープを防止**)で、**この Mac のスリープを防止** をオンにします。バッテリー駆動中でも Mac がスリープしないので、スマートフォンからいつでも接続できます。画面をオンのままにしたり、一定時間後にオフにしたり、蓋を閉じた状態で Mac を起動したままにしたりすることもできます(蓋を閉じた状態では、管理者パスワードを一度求められます)。
  </Step>
  <Step title="スマートフォンを削除する">
    スマートフォンをなくしましたか? **接続 → ペアリング済みのスマートフォン** で、その横の **削除** を選びます。そのスマートフォンは Mac に接続できなくなります。もう一度使うには、新しいコードでペアリングします。
  </Step>
</Steps>

コードの下に Mac がそう表示しているときは、スキャンすると iPhone も Enconvo アカウントにサインインします。そのようなコードは、自分の iPhone でだけスキャンしてください。

## スマートフォンでできること

ペアリングすると、次のことができます。

- Mac のプロジェクトとチャットを閲覧し、どのチャットも続ける。
- Mac で作業中のエージェントが尋ねる質問に答える。
- チャットが終わったときに通知を受け取り、通知から返信する。
- **リモート画面** で Mac の画面を表示して操作する。
- スマートフォン自体で AI モデルとチャットする。Enconvo Cloud のポイント、自分の API キー、サインインしたプラン(ChatGPT、Grok、Le Chat、GitHub Copilot、Antigravity)を使えます。[iPhone のチャット](/ja/integrations/iphone-phone-chats)をご覧ください。
- 友だちやチームメイトとチャットや通話をし、ビデオ会議に参加する。[スマートフォンでの通話と友だち](/ja/integrations/phone-calls-and-friends)をご覧ください。

アプリでは、ペアリングした Mac、Windows PC、Linux マシンを **コンピュータ** と呼びます。特に記載がない限り、Android アプリも同じように動作します。

## コンピュータのチャットで作業する

コンピュータのチャットは、そこで見るのと同じ見た目と動作で、バックグラウンドタスク、サブエージェント、ステアリングにも対応します。

- **ホーム** では、メッセージボックスのすぐ上にアクティブなチャットが表示されます。カードのつまみを上にスワイプするか **すべて** をタップすると、アクティブなチャットすべてが、自分の対応が必要なもの、実行中のもの、結果があるものに分けて表示されます。
- サイドバーの **アクティブ** グループには、あなたの対応待ち、失敗、実行中、未読の結果があるチャットが集まります。青いドットは誰も読んでいない結果、回転するリングは実行中のチャットを示します。**ピン留め済み** と **最近** は折りたたまれます。
- 返信の実行中に送ったものは、Mac で Return を押したときと同じように、実行中のタスクに指示として反映されます。その間、メッセージボックスには「実行中のタスクに指示…」と表示されます。
- サブエージェントをタップすると、そのステップがチャットの上のシートに開きます。最新のステップで開き、新しい出力を追いかけます。下にスワイプすると閉じます。
- 承認の質問には、Mac と同じように、エージェント自身の選択肢が表示されます。
- チャットのエージェントを変更するには、チャットのタイトルの下のエージェントをタップします。**ここから分岐** では、分岐先のエージェントを選べます。
- モデルシートには、サブスクリプションのプラン、5 時間と週ごとの上限、残りとリセットの時刻、そしてモデル自体の上限が各行に表示されます。
- フォトライブラリから写真やビデオを添付できます。ビデオはそのままコンピュータに送られます。
- アプリの **設定 → アバター** で、メッセージボックスの通話ボタンにアバターを表示するか、音声バーのアイコンを表示するかを選べます。

コンピュータがオフライン、または再接続中でも送信できます。スマートフォンは、質問やウェブの検索など、自分で答えられることには答え、コンピュータが必要なメッセージは、接続されてから送ります。

スマートフォンで開けないドキュメントやリンクには、コンピュータで開くよう表示されます。

## コンピュータの画面を使う

**ホーム** の右上のディスプレイアイコン、またはチャットのメニューの **リモート画面** をタップすると、コンピュータの画面を表示して操作できます。

| モード | タッチしたときの動作 |
| --- | --- |
| **トラックパッド** | どこでもスライドしてポインタを動かし、タップするとポインタの位置をクリックします。使いながらジェスチャーのヒントが表示されます。 |
| **タッチ** | クリックしたい場所をタップします。 |
| **見るだけ** | 何も起こりません。見るだけです。 |

モードボタンには、現在のモード名が表示されます。ピンチでズームでき、**トラックパッド** では、画像がポインタを中心にズームし、ポインタを追いかけます。

ほかのことをしながら画面を浮かせておくには、左上のピクチャインピクチャボタンをタップするか、ピンチインします。画面はチャットの上に浮かび、Enconvo を離れたときはほかのアプリの上にも浮かびます。

Live Talk の通話中は、**リモート画面** ツールが、通話の上の小さな浮動ウィンドウで画面を開きます。トラックパッドのように動作し、**タッチ** や **見るだけ** に切り替えるモードチップ、コンピュータに入力するキーボードボタン、通常の表示を開く **フルスクリーン** があります。

## 通知

- 完了した返信の通知には、返信の冒頭が表示されます。通知の **返信** を使うと、アプリを開かずに答えられます。
- アプリを開いている間や、Mac を使っている間は、スマートフォンから送ったメッセージでない限り、通知は届きません。
- 完了したチャットを 1 台のデバイスで読むと、ほかのデバイスの通知は消えます。回答を待っている質問は残ります。
- Android 14 以降で、Android がフルスクリーン通知をオフにしている場合は、アプリの設定で **フルスクリーン通知** をオンにしてください。

## Enconvo に共有する

ほかのアプリからページ、写真、ファイルを Enconvo に共有すると、**送信先** シートで新しいチャットまたは最近のチャットを選べます。シートで、またはアプリの設定で **常に新規チャットに共有** をオンにすると、この確認を省略できます。

## プロジェクトとアーティファクト

- プロジェクトの **アイデア** と **ボード** を開いたり、その設定を変更したり、**新規プロジェクト** を始めたり、作業計画カードを操作したりできます。回答、マージ、タスクの開始や再試行、プルリクエストの作成、アイデアの書き留めと開始が行えます。
- `@` メニューには、プロジェクトのメンバー、ワークフロー、参加できるエージェントが一覧表示されます。
- デッキ、ダッシュボード、モーションフィルムは、チャットまたはアーティファクトライブラリから開き、コメント、@Enconvo への質問、共有、書き出し、プレゼンテーションができます。

## Android アプリ

Android アプリも、同じようにペアリングして動作します。Google、またはメールで届く 6 桁のコードでサインインします。メッセージボックスは 1 行に収まり、カメラボタン、コンピュータ・プロジェクト・**スキル** のクイックチップ、最近の写真やビデオが並ぶプラスパネルがあります。

enconvo.com からダウンロードした Android アプリは、開くたびにアップデートを確認します。**このバージョンをスキップ** は新しいバージョンが出るまでそのバージョンを非表示にし、**後で** は次にアプリを開くまでアラートを非表示にします。

## ペアリングしたスマートフォンを管理する

**設定 → 接続** に、ペアリングしたすべてのスマートフォンと、いまスマートフォンがこの Mac に接続できるかどうかが表示されます。

| タスク | 方法 |
| --- | --- |
| 別のスマートフォンをペアリングする | **別のスマートフォンをペアリング** を選び、新しいコードをスキャンします。1 台の Mac にペアリングできるスマートフォンは最大 10 台です。 |
| スマートフォンの名前を変更する | スマートフォンをクリックし、名前の横の **スマートフォンの名前を変更** をクリックします。 |
| スマートフォンを削除する | **ペアリング済みのスマートフォン** で、その横の **削除** を選びます。 |
| 最初からやり直す | **接続をリセット** を選びます。Enconvo が新しい接続キーを作成し、ペアリングしたすべてのスマートフォンを削除します。各スマートフォンで、新しいコードをスキャンします。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| スマートフォンが Mac に接続できない | Mac がスリープしておらず、サインインしていて、オンラインであること、**接続** に **オンライン** と表示されていることを確認してください。**この Mac のスリープを防止** をオンにすると、接続できる状態が保たれます。 |
| メッセージ、画面、ターミナルを Mac が拒否したとスマートフォンに表示される | その操作に対する Mac のデバイスアクセスがありません。スマートフォンに表示される手順に従ってください。 |
| コードに **このコードは期限切れです** と表示される | **新しいコードを表示** を選び、5 分以内にもう一度スキャンしてください。 |
| Mac に **ログインしてスマートフォンをペアリング** と表示される | **ログイン** をクリックして Mac でサインインしてください。iPhone と Mac は同じ Enconvo アカウントを使う必要があります。 |
| Mac に **新しい接続キーが必要です** と表示される | リレーが、この Mac について別のキーを持っています。たとえば、バックアップから復元した後などです。**接続をリセット** を選び、各スマートフォンをもう一度ペアリングしてください。 |
| **Companionへのアクセスがオフになりました** | いずれかのデバイスからアクセスがオフにされ、**アクセスを再びオンにする** を選ぶまで、どのスマートフォンも Mac に接続できません。 |

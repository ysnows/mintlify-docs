メッセージングチャネルを使うと、Telegram や Discord から Enconvo エージェントに話しかけられます。各チャネルは 1 つのエージェントに紐づけられたボットとして動作し、受信したメッセージがそのエージェントへ渡され、エージェントが返信を作成します。1 つのエージェントで複数のチャネルを担当できますが、1 つのチャネルに紐づけられるエージェントは 1 つまでです。設定は **設定 → メッセージングチャネル** で行います。

以下の動画では、アバターと認証情報の管理の紹介に挟んで Telegram チャネルのセットアップを行っています。

## はじめる前に

- 各プラットフォームでボットを作成し、ボットトークンをコピーします（下記の [Telegram](#telegram) と [Discord](#discord) を参照）。
- ボットを待機させる間は、Mac をオンラインにし、Enconvo を起動したままにしてください。

<Note>
無料プランで同時に動かせる IM ボットは 1 つまでです。Enconvo Cloud プランまたは買い切りライセンスではさらに多く動かせます。[プランと料金](/ja/pricing)を参照してください。
</Note>

## チャネルを追加する

<Steps>
  <Step title="チャネルを追加する">
    **設定 → メッセージングチャネル** を開き、**新しいチャンネルを追加** をクリックして **Telegram** または **Discord** を選びます。
  </Step>
  <Step title="名前を付ける">
    わかりやすいチャネル名を付けます。
  </Step>
  <Step title="ボットトークンを貼り付ける">
    プラットフォームのボットトークンを **Bot Token** に貼り付けます。
  </Step>
  <Step title="エージェントを選ぶ">
    **bind agent** で受信メッセージを処理するエージェントを選択します。
  </Step>
  <Step title="有効にする">
    誰がボットを使えるか（Telegram の場合は **アクセス制御**）を確認してから、**チャネルを有効にする** をオンにします。
  </Step>
  <Step title="テストする">
    **接続を確認** をクリックしてチャネルが **接続済み** と表示されることを確かめます。その後、許可されたアカウントからテストメッセージを送信します。
  </Step>
</Steps>

ボットが答えられる内容は、紐づけたエージェントのモデルとツールによって決まります。

## Telegram

Telegram の **BotFather** でボットを作成し、ボットトークンをコピーします。チャネルをオンにする前に **アクセス制御** を開いてください。

| 項目 | 内容 |
| --- | --- |
| **ポリシー** | **ペアリングが必要です**（デフォルト）：新しいユーザーはペアリングコードを共有し、あなたの承認を待ちます。**公開（全員）**：ボットを見つけた誰でも利用できます。 |
| **保留中のリクエスト** | ペアリングを申請した各ユーザーを **承認** または **拒否** します。許可したい相手だけを承認してください。 |
| **許可されたユーザー** | 承認済みのユーザー一覧です。**削除** でリストから外すと、再び使うには再ペアリングが必要になります。 |

ダイレクトチャットでは動くのにグループで反応しない場合は、チャネルのアクセスポリシーだけでなく Telegram 側のボットプライバシー設定とグループ権限も確認してください。トークンだけではすべての会話へのアクセス権は付与されません。

## Discord

Discord Developer Portal でアプリケーションとボットを作成します。ボットをサーバーに招待し、対象メッセージの送受信に必要な権限とインテントを付与してください。ボットトークンを Discord チャネルに貼り付けてエージェントを紐づけます。

接続済みなのに返信しない場合は、Discord 側のチャンネル権限と、ボットがその種類のメッセージを受信できる設定になっているか確認してください。ボットの範囲は意図したサーバーとチャンネルのみに限定しておくことをおすすめします。

## セッションと返信

受信した会話ごとに、紐づけたエージェントとの独立したチャットセッションが作られます。返信はその会話に紐づき、接続中のユーザー間で履歴が混ざることはありません。紐づけるエージェントを変更するとチャネルが再起動し、それ以降のメッセージは新しいエージェントへ送られます。

チャットでボットコマンドを入力すると、エージェントへメッセージを送る代わりに会話を操作できます。`/new` で新しいチャットセッションを開始し、`/stop` で進行中の返信（直前に送信されたメッセージも含む）を停止します。ボットコマンドは Telegram と Discord の両方で動作し、添付ファイル付きで送信してもコマンドとして実行されます。

公開用やチーム用のボットには、目的に合った指示とツールを持つ専用エージェントを使用してください。他の人がアクセスできるようにする前に、そのエージェントが使えるツールを確認しておきましょう。

## スケジュール配信

[予約タスク（オートメーション）](/ja/workflows/scheduled-jobs)の結果を、設定した IM チャットへ送信できます。送信先は自分で選び、実行そのものが失敗したのか送信だけが失敗したのかはタスクの実行履歴で確認できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 切断される | ボットトークン、ネットワーク、**チャネルを有効にする** がオンか、Enconvo が起動中かを確認してください。接続が途切れた Discord ボットは自動で再接続します。 |
| 接続済みだが反応しない | 紐づけたエージェント、エージェントのモデルプロバイダー、プラットフォーム側の権限、ペアリングポリシーを確認してください。 |
| ボットの答え方が意図と違う | 紐づけたエージェントの指示、ツール、モデルを確認してください。 |
| Telegram ユーザーが接続できない | **保留中のリクエスト** にペアリング申請が来ていないかと、**許可されたユーザー** を確認してください。 |
| 2 つ目のボットが起動しない | 無料プランで動かせる IM ボットは 1 つまでです。もう一方のボットをオフにするか、アップグレードしてください。 |
| Enconvo を終了すると返信が止まる | ボットは Mac 上の Enconvo を通じて待機しているため、アプリを起動したままにする必要があります。 |

メッセージングチャネルで設定できるのは Telegram と Discord のみです。Slack や Feishu などを別プラグインや MCP サーバー経由で使う場合は、それぞれの連携ガイドに従ってください。

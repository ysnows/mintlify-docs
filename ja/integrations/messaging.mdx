メッセージングチャネルを使うと、Telegram や Discord から Enconvo のエージェントと話せます。各チャネルは 1 つのエージェントに結び付けたボットで、受信したメッセージはそのエージェントに届き、返信もエージェントが書きます。1 つのエージェントが複数のチャネルに対応できますが、各チャネルが対応するエージェントは最大 1 つです。**設定 → メッセージングチャネル** で設定します。

このビデオでは、アバターと認証情報管理の紹介の合間に、Telegram チャネルを設定します。

## 始める前に

- 各プラットフォームでボットを作成し、ボットトークンをコピーします(下の [Telegram](#telegram) と [Discord](#discord) をご覧ください)。
- ボットが待ち受けている間は、Enconvo を起動したまま、Mac をオンラインにしておきます。

<Note>
無料プランで同時に動かせる IM ボットは 1 つです。Enconvo Cloud プランまたは永久ライセンスでは、より多く動かせます。[プランと料金](/ja/pricing)をご覧ください。
</Note>

## チャネルを追加する

<Steps>
  <Step title="チャネルを追加する">
    **設定 → メッセージングチャネル** を開き、**新しいチャンネルを追加** をクリックして、**Telegram** または **Discord** を選びます。
  </Step>
  <Step title="名前を付ける">
    分かりやすいチャネル名を付けます。
  </Step>
  <Step title="ボットトークンを貼り付ける">
    プラットフォームのボットトークンを **ボットトークン** に貼り付けます。
  </Step>
  <Step title="エージェントを選ぶ">
    **エージェントを紐づけ** で、受信メッセージを処理するエージェントを選びます。
  </Step>
  <Step title="オンにする">
    ボットを使える人を確認し(Telegram では **アクセス制御**)、**チャネルを有効にする** をオンにします。
  </Step>
  <Step title="テストする">
    **接続を確認** をクリックし、チャネルに **接続済み** と表示されることを確認します。続いて、許可したアカウントからテストメッセージを送ります。
  </Step>
</Steps>

ボットが何に答えられるかは、紐づけたエージェントのモデルとツールで決まります。

## Telegram

Telegram の **BotFather** でボットを作成し、ボットトークンをコピーします。チャネルをオンにする前に、その **アクセス制御** を開きます。

| 設定 | 内容 |
| --- | --- |
| **ポリシー** | **ペアリングが必要です**(既定):新しいユーザーがペアリングコードを共有し、あなたの承認を待ちます。**公開(全員)**:ボットを見つけた人なら誰でも使えます。 |
| **保留中のリクエスト** | ペアリングを求めたユーザーを、それぞれ **承認** または **拒否** します。承認するのは、意図した相手だけにしてください。 |
| **許可されたユーザー** | 承認したユーザー。**削除** でリストから外せます。外されたユーザーは、ボットを使うにはもう一度ペアリングが必要です。 |

ボットがダイレクトチャットでは動くのにグループでは動かないときは、チャネルのアクセスポリシーに加えて、Telegram のボットのプライバシーとグループの権限も確認してください。トークンだけでは、すべての会話にボットがアクセスできるわけではありません。

## Discord

Discord Developer Portal でアプリケーションとボットを作成します。ボットをサーバーに招待し、必要なメッセージを受信・送信するために必要な権限とインテントを付与します。ボットトークンを Discord チャネルに貼り付けて、エージェントを紐づけます。

接続はできても返信がないときは、Discord 側のチャネルの権限と、ボットがその種類のメッセージを受信できるかを確認してください。ボットは、意図したサーバーとチャネルだけに限定しておきます。

## セッションと返信

受信した会話ごとに、紐づけたエージェントとの専用のチャットセッションが作られます。返信はその会話に沿って行われ、接続したユーザー同士が 1 つの履歴を共有することはありません。紐づけたエージェントを変更するとチャネルが再起動し、以降のメッセージは新しいエージェントに届きます。

チャットでボットコマンドを入力すると、エージェントにメッセージを送る代わりに会話を制御できます。`/new` は新しいチャットセッションを始め、`/stop` は、直前に送ったメッセージも含めて、進行中の返信を止めます。ボットコマンドは Telegram と Discord で使え、添付ファイル付きで送ったコマンドもコマンドとして実行されます。

公開用やチームで使うボットには、専用のエージェントを用意し、適した指示とツールを設定してください。ほかの人が使えるようにする前に、そのエージェントが使えるツールを確認します。

## スケジュール配信

[予約タスク](/ja/workflows/scheduled-jobs)は、設定した IM チャットに結果を送れます。送信先は自分で選び、タスクの実行履歴で、実行の失敗と配信の失敗を見分けてください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 接続が切れている | ボットトークン、ネットワーク、**チャネルを有効にする** がオンであること、Enconvo が起動していることを確認してください。接続が無応答になった Discord ボットは、自動的に再接続します。 |
| 接続済みなのに反応がない | 紐づけたエージェント、そのエージェントのモデルプロバイダ、プラットフォームの権限、ペアリングポリシーを確認してください。 |
| ボットの答え方がおかしい | 紐づけたエージェントの指示、ツール、モデルを確認してください。 |
| Telegram のユーザーが接続できない | **保留中のリクエスト** にそのユーザーのペアリングリクエストがないか探し、**許可されたユーザー** を確認してください。 |
| 2 つ目のボットが起動しない | 無料プランで同時に動かせる IM ボットは 1 つです。もう一方のボットをオフにするか、アップグレードしてください。 |
| Enconvo を終了すると返信が止まる | ボットは Mac 上の Enconvo を通じて待ち受けているため、アプリを起動したままにする必要があります。 |

メッセージングチャネルで設定できるのは Telegram と Discord だけです。別のプラグインや MCP サーバー経由で Slack や Feishu を使う場合は、その連携のガイドに従ってください。

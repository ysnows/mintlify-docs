エージェントは、この Mac 以外でも作業できます。SSH でサインインするサーバーを追加し、チャットでそのサーバーをメンションして頼むと、自分の Mac に頼むときと同じように、エージェントがそこでコマンドを実行し、ここで答えます。サーバーには何もインストールされません。Enconvo を実行しているほかのコンピュータも、同じようにペアリングできます。

下のビデオでは、SSH の設定から SSH ホストを追加し、エージェントにそのホストのログを読んでもらい、この Mac にアクセスできるデバイスを確認します。

## 始める前に

- この Mac から `ssh` でサインインできるサーバーが必要です。`~/.ssh/config` にあるホスト、または `user@host` と入力できるアドレスです。Enconvo はこの Mac の `ssh` と鍵をそのまま使います。サーバーがパスワードやパスフレーズを求めた場合は、`ssh` が Enconvo を通じて確認し、Enconvo はそれらを一切保存しません。
- ローカルネットワーク上のサーバーでは、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo を許可してください。

## 接続に一覧表示されるもの

**設定 → 接続** を開くと、3 つのリストがあります。

| リスト | 内容 |
| --- | --- |
| **スマートフォン** | この Mac とペアリングした iPhone アプリと Android アプリ。[iPhone アプリ](/ja/integrations/iphone-app)をご覧ください。 |
| **コンピュータ** | この Mac とペアリングした、Enconvo を実行しているほかのコンピュータ。それぞれ 1 回だけ表示され、どちら向きに操作できるかも分かります。**コンピュータをペアリング** をクリックして追加します。[ほかのコンピュータ](/ja/integrations/other-computers)をご覧ください。 |
| **SSH ホスト** | エージェントが SSH で接続するサーバー。何もインストールされません。 |

スマートフォンやコンピュータをクリックすると、その専用ページが開き、この Mac でできることが表示されます。

チャットウィンドウからも、ホストの追加、コンピュータのペアリング、スマートフォンのペアリングができます。サイドバー下部のデバイス切り替えをクリックし、**デバイスを追加** を選びます。

## SSH ホストを追加する

1. **設定 → 接続** を開き、**SSH ホスト** の下の **ホストを追加** をクリックします。
2. `~/.ssh/config` にあるホストが一覧表示されます。`build-server` などを選ぶか、`user@host`(または `user@host:port`)を入力します。
3. **接続** をクリックします。Enconvo が接続をテストします。ホストに到達し、ホスト鍵を確認し、サインインして、コマンドを実行します。
4. **各コマンドの前** で、そこでコマンドを実行する前にエージェントがどう確認するかを選びます。
   - **チャットに従う**:チャットの権限モードの設定に従って確認します。[操作を承認する](/ja/ai/agents)をご覧ください。
   - **毎回確認**:すべてのコマンドの前に確認します。
5. **ホストを追加** をクリックします。

ホストが **SSH ホスト** の下に表示され、すべてのチャットの `@` メニューにも表示されます。

Enconvo がサーバーのホスト鍵を初めて見たときは、サーバーの管理者に鍵を確認してから **信頼して接続** をクリックしてください。Linux サーバーでは、ダイアログに **そこに Enconvo もインストール** も表示され、サーバーをコンピュータとしてペアリングします。何もインストールしたくないときは、オフのままにします。

## ホストでの作業をエージェントに頼む

1. チャットで `@` とホスト名の最初の文字を入力します。コンピュータと SSH ホストは **コンピュータ** の下に一覧表示されます。
2. ホストを選びます。メッセージにチップとして入ります。
3. そこで行ってほしいことを頼んで、送信します。たとえば次のように頼みます。

   ```text
   @build-server ~/app/logs/app.log にどんなエラーがある? 読むだけで、何も変更しないで。
   ```

エージェントは SSH でホスト上のコマンドを実行します。そのホストについて選んだ設定のとおり、先に確認します。各コマンドのステップには、実行したホスト名が表示されます。答えはチャットに返ります。

何を実行したかを見るには、答えの上の **作業時間** をクリックします。折りたたみに各コマンドが一覧表示されます。

ペアリングしたコンピュータも同じようにメンションできます。エージェントは、そのコンピュータの専用エージェントにタスクを渡すか、そのコンピュータがこの Mac にターミナルを許可している場合はそこでコマンドを実行します。

チャットでは、ホストやほかのコンピュータで実行したコマンドは **コマンドを実行** と表示され、各ステップにマシン名が表示されます。

## ペアリングしたコンピュータでエージェントに作業させる

**設定 → 接続** で、**コンピュータ** の下のコンピュータをクリックしてそのページを開きます。ここでのチャットのエージェントがそのコンピュータで何をできるかは、2 つのスイッチで決まります。

| スイッチ | 内容 |
| --- | --- |
| **エージェント** | そのコンピュータのエージェントをプロジェクトに追加したり、チャットを渡したりします。タスクはそのコンピュータで実行され、そのエージェントが行おうとする操作は、先にそのコンピュータであなたに確認されます。 |
| **コマンド** | ここでのチャットのエージェントが、チャットの権限モードの設定に従って確認しながら、そのコンピュータでコマンドを実行できます。 |

スイッチが薄く表示されているときは、相手のコンピュータが許可していません。そのコンピュータで、この Mac に対する **エージェント** または **ターミナル** をオンにしてください。**コマンド** をオフにすると、同じコンピュータへの SSH ホスト経由のコマンドも止まります。

ほかのコンピュータのエージェントにこの Mac の画面とブラウザを直接使わせるには、ここでそのコンピュータのページの **エージェントによる操作** をオンにします。[ほかのコンピュータ](/ja/integrations/other-computers)をご覧ください。

## ホストの設定を変更する

**SSH ホスト** の下でホストをクリックすると、そのページが開きます。

| 設定 | 内容 |
| --- | --- |
| **エージェントが使用可能** | オフにすると、ホストはリストに残りますが、どのチャットでも使われません。 |
| **各コマンドの前** | **チャットに従う** または **毎回確認**。 |
| **ファイルをコピー** | エージェントが `scp` でホストとの間でファイルをコピーできるようにします。 |
| **開始フォルダ** | コマンドを開始するフォルダ。空欄ならログインフォルダです。 |

ページの **⋯** メニューには **接続をテスト** と **ホストを削除…** があります。ホストを削除すると、Enconvo からホストの情報が消えます。`~/.ssh/config` とサーバーはそのままです。

## この Mac にアクセスできるデバイスを確認する

**設定 → 接続** の **この Mac にアクセスできるデバイス** に、この Mac にアクセスできるスマートフォンとコンピュータの数が表示されます。

すべてを一度に遮断するには、**すべてのアクセスを停止** をクリックして確認します。スマートフォンやほかのコンピュータは、どの Mac にもアクセスできなくなり、そこで実行中の作業も止まります。再び許可するときは **アクセスを再びオンにする** をクリックします。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ローカルネットワーク上のサーバーにテストが届かない | macOS が、ローカルネットワークの権限のために接続を保留しています。**Enconvo にローカルネットワークを許可** をクリックするか、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo をオンにしてから、もう一度試してください。 |
| サーバーが鍵を拒否したとテストに表示される | `~/.ssh/config` のそのホストの `IdentityFile` を確認するか、`ssh-add` で鍵を追加してください。 |
| サーバーが別のホスト鍵で応答した | サーバーが再構築されたか、あなたとサーバーの間に何かが挟まっている可能性があります。再構築された場合は、ターミナルで `ssh-keygen -R` にサーバーのアドレスを続けて実行して古い鍵を削除し、もう一度試してください。 |
| ホストが `@` メニューにない | ホストのページを開き、**エージェントが使用可能** をオンにしてください。 |
| パスワードやパスフレーズが違う | ボックスがもう一度開き、うまくいかなかったことが表示されます。入力し直してください。 |
| 1 台のコンピュータに SSH ホストが 2 つある | 最初のホストがそのコンピュータにひも付いたままになり、そのページにはそちらが表示されます。それを削除すると、もう一方がひも付きます。 |
| `~/.ssh/config` にホストがない | **ホストを追加** で、アドレスを `user@host` の形式で入力してください。 |

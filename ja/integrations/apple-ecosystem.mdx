title: "Apple アプリ"
description: "カレンダー、リマインダー、連絡先、メモ、メール、メッセージ、ミュージック、マップなど、Mac のアプリでエージェントが作業できるようにします。"
---

エージェントは、カレンダーの確認、リマインダーの追加、電話番号の検索、メモの保存、メールの整理、iMessage の送信など、Mac に標準搭載されているアプリで作業できます。普段の言葉で頼むだけで、エージェントがあなたに代わってアプリを操作します。

各アプリは**設定 → プラグイン**の **Mac アプリ**タブにプラグインとして用意されています。接続時に求められるのはアカウントではなく macOS の権限です。Enconvo がアプリを読み取るのはエージェントが必要とするときだけで、バックグラウンドで同期されることはありません。読み取られた内容は、そのチャットで選んだ AI モデルに送られます。

## アプリを接続する

<Steps>
  <Step title="Mac アプリを開く">
    **設定 → プラグイン**を開き、**Mac アプリ**タブをクリックします。
  </Step>
  <Step title="アプリを接続する">
    対象のアプリをクリックして**接続**をクリックします。接続に伴う内容を確認し、**続ける**をクリックします。
  </Step>
  <Step title="アクセスを許可する">
    Enconvo によるアプリの使用を許可するか macOS が尋ねてくるので、許可します。一部のアプリでは、macOS が確認ダイアログを出せるよう、Enconvo がバックグラウンドでアプリを開きます。
  </Step>
  <Step title="試してみる">
    アプリに**この Mac で接続済み**と表示されます。**今すぐ試す**をクリックするか、下の例のような内容をエージェントに頼んでみてください。
  </Step>
</Steps>

## エージェントができること

| アプリ | エージェントができること | macOS の権限 |
| --- | --- | --- |
| カレンダー | カレンダーに設定されたすべてのアカウントから、任意の日付範囲のカレンダーと予定を読み取ります。予定の追加、時間・場所・メモの変更、削除も行えます。 | **カレンダー** |
| リマインダー | リストを 1 つずつ読み取り、未完了または完了済みのリマインダーを確認します。リマインダーの追加、期日やメモの変更、完了／未完了の切り替え、別リストへの移動、削除を行えます。 | **リマインダー** |
| 連絡先 | 名前、電話番号、メールアドレスで人を検索し、連絡先を 1 ページずつ読み取ります。エージェントが連絡先を変更することはできません。 | **オートメーション**、次に**連絡先** |
| メモ | メモをフォルダや添付ファイルを含めて検索・閲覧します。メモの作成、追記や書き換え、フォルダ間の移動、削除を行えます。ロックされたメモはロックされたままです。 | **オートメーション** |
| メール | メールに設定されたすべてのアカウントのメールボックスを検索し、メッセージや添付ファイルを読み取ります。下書き作成、送信、返信、転送、移動、フラグ付け、削除を行えます。 | **オートメーション** |
| メッセージ | グループチャットや米国外の番号を含め、未読メッセージと会話履歴を読み取ります。iMessage をすぐに送信したり、確認・キャンセルできる 1 回限りの[オートメーション](/ja/workflows/scheduled-jobs)として予約送信したりできます。 | **オートメーション**、履歴を読む場合は**フルディスクアクセス** |
| ミュージック | ライブラリや Apple Music カタログから曲、アルバム、アーティスト、プレイリストを再生します。一時停止、スキップ、音量調整、シャッフル、リピート、再生中の曲の確認を行えます。 | **オートメーション** |

**Mac アプリ**タブには同様に使える Spotify もあります。Mac に Spotify アプリが入っており、アカウントにサインインしている必要があります。

<Warning>
エージェントは確認を求めずに予定、リマインダー、メモ、メールを変更・削除したり、メールを送信したりできます。事前に確認したい場合は、計画や下書きを作成するよう頼んでください。メッセージアプリで送信する前には、宛先と本文を確認します。
</Warning>

## アプリの接続を解除する

**Mac アプリ**タブで該当のアプリを開き、**接続解除**をクリックします。これで Enconvo 上でそのアプリが無効になります。macOS のアクセス権も外す場合は、**システム設定 → プライバシーとセキュリティ**から上の表に示した該当権限を開き、Enconvo をオフにしてください。

## アプリごとの使用例

### メール

メール連携は、iCloud、Gmail、Outlook、Exchange など、メールアプリに設定されているすべてのアカウントに対応しています。エージェントはメールボックスの管理、メールルールのオン／オフ、添付ファイルの保存、未読メール数のカウントも行えます。

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### リマインダー

リマインダーには、期日と時刻、メモ、優先度（なし、低、中、高）、繰り返しルール、到着時または出発時に通知する場所を設定できます。繰り返しルールは毎日・毎週・毎月・毎年を 1 回以上（2 週間ごとなど）の間隔で設定でき、任意で終了日も指定できます。

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### カレンダー

予定には、終日設定、場所、メモ、リンク、開始前の指定分数に鳴る通知、状態（予定あり、空き、仮予定、不在）、さらに終了日または回数指定付きの毎日・毎週・毎月・毎年の繰り返しを設定できます。繰り返しの予定を削除するときは、すべての予定をまとめて削除することもできます。

**基本的な予定：**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**終日の予定：**
```
"Block off next Friday as a personal day"
```

**繰り返しの予定：**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**通知アラーム：**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**複数のカレンダー：**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 連絡先

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### メッセージ

メッセージ連携では、電話番号、メールアドレス、グループチャット宛てに iMessage を送信できます。iMessage を配信するには、メッセージアプリが Apple Account にサインインしている必要があります。メッセージアプリが「未配信」と表示したときは、送信済みと報告するのではなくその旨をお伝えします。

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### メモ

エージェントはメモアプリで現在選択しているメモも読み取れるため、「これを要約して」や「これを翻訳して」といった依頼にも向いています。

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### マップ

エージェントは Apple マップを開いて場所を検索したり、車・徒歩・公共交通機関での経路を表示したり、ピンを落としたり、ガイドを作成したりできます。結果はチャット内ではなくマップ上に表示されます。お気に入りへの保存やガイドへの追加は、エージェントが画面を開いたあとマップ上で完了させてください。

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### ショートカット

エージェントが直接ショートカットを実行することはできません。Enconvo からショートカットを実行するには、**設定 → クイックアクション**でクイックアクションに**ショートカットを実行**ステップを追加してください。

## 権限

各アプリは上の表に記載した macOS の権限を使用します：

- カレンダーとリマインダーは、**システム設定 → プライバシーとセキュリティ**の**カレンダー**および**リマインダー**一覧を使用します。
- 連絡先、メモ、メール、メッセージ、ミュージックは**オートメーション**を使用し、Enconvo が各アプリを制御してよいか macOS が尋ねます。連絡先は連絡先へのアクセス許可も求めます。
- メッセージは履歴を保護されたファイルに保存しているため、履歴を読むには Enconvo に**フルディスクアクセス**が必要です。

許可ダイアログを拒否すると、そのアプリは Enconvo と連携できなくなります。カレンダー、リマインダー、連絡先については、**Mac アプリ**タブでもう一度接続すると macOS が再度確認を出します。macOS が接続済みアプリをブロックしている場合、**Mac アプリ**タブの該当行に**設定を開く**と表示され、適切なスイッチ画面へ移動できます。これらの権限は、あとから**システム設定 → プライバシーとセキュリティ**でいつでも変更できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| メールが動作しない | メールアプリに少なくとも 1 つのメールアカウントが設定されているか確認してください。**システム設定 → プライバシーとセキュリティ → オートメーション**でメールに対する Enconvo がオンになっているかも確認してください。 |
| カレンダーへのアクセスが拒否される | **システム設定 → プライバシーとセキュリティ → カレンダー**で、Enconvo が一覧にありオンになっているか確認してください。許可したあと Enconvo を再起動してください。 |
| リマインダーが表示されない | **システム設定 → プライバシーとセキュリティ → リマインダー**で Enconvo にアクセス権があるか、およびリマインダーアプリ内にリマインダーが表示されているか確認してください。 |
| メッセージの履歴を読み取れない | **システム設定 → プライバシーとセキュリティ**で Enconvo の**フルディスクアクセス**をオンにしてください。 |
| 接続済みアプリに**設定を開く**と表示される | macOS が Enconvo をブロックしています。**設定を開く**をクリックし、Enconvo をオンにしてください。 |

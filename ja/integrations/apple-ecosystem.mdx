---
title: "Apple アプリ"
description: "Mac のカレンダー、リマインダー、連絡先、メモ、メール、メッセージ、ミュージック、マップでエージェントに作業させます。"
---

エージェントは、Mac に付属のアプリで作業できます。予定の確認、リマインダーの追加、電話番号の検索、メモの保存、メールの整理、iMessage の送信などです。ふだんの言葉で頼むと、エージェントがあなたの代わりにアプリを使います。

各アプリは、**設定 → プラグイン** の **Mac アプリ** タブにあるプラグインです。接続するときに求められるのはアカウントではなく、macOS の権限です。Enconvo は、エージェントが必要としたときだけアプリを読み取り、バックグラウンドで同期されることはありません。読み取った内容は、そのチャットで選んだ AI モデルに送られます。

## アプリを接続する

<Steps>
  <Step title="Mac アプリを開く">
    **設定 → プラグイン** を開き、**Mac アプリ** タブをクリックします。
  </Step>
  <Step title="アプリを接続する">
    アプリをクリックし、**接続** をクリックします。接続の内容を読んで、**続ける** をクリックします。
  </Step>
  <Step title="アクセスを許可する">
    macOS が、Enconvo にそのアプリの使用を許可するかを尋ねます。許可してください。アプリによっては、macOS が確認できるように、Enconvo がバックグラウンドでそのアプリを開きます。
  </Step>
  <Step title="試してみる">
    アプリに **この Mac で接続済み** と表示されます。**今すぐ試す** をクリックするか、下の例を参考にエージェントに何か頼んでみましょう。
  </Step>
</Steps>

## エージェントにできること

| アプリ | エージェントにできること | macOS の権限 |
| --- | --- | --- |
| カレンダー | カレンダーアプリに設定されたすべてのアカウントで、任意の期間のカレンダーと予定を読み取ります。予定の追加、時刻・場所・メモの変更、削除ができます。 | **カレンダー** |
| リマインダー | リストを 1 つずつ読み取り、未完了または完了済みのリマインダーを確認します。リマインダーの追加、期限とメモの変更、完了・未完了の切り替え、別のリストへの移動、削除ができます。 | **リマインダー** |
| 連絡先 | 名前、電話番号、メールアドレスで人を探し、連絡先を 1 ページずつ読み取ります。エージェントが連絡先を変更することはできません。 | **オートメーション**、続いて **連絡先** |
| メモ | メモをフォルダや添付ファイルごと検索して読み取ります。メモの追加、追記や書き換え、フォルダ間の移動、削除ができます。ロックされたメモはロックされたままです。 | **オートメーション** |
| メール | メールアプリに設定されたすべてのアカウントでメールボックスを検索し、メッセージと添付ファイルを読み取ります。下書きの作成、送信、返信、転送、メッセージの移動、フラグ付け、削除ができます。 | **オートメーション** |
| メッセージ | 未読のメッセージや会話の履歴を、グループチャットや米国外の番号も含めて読み取ります。iMessage はすぐに送るか、確認も取り消しもできる 1 回限りの[自動化](/ja/workflows/scheduled-jobs)として後で送れます。 | **オートメーション**、履歴を読み取るには **フルディスクアクセス** も必要 |
| ミュージック | ライブラリまたは Apple Music カタログの曲、アルバム、アーティスト、プレイリストを再生します。一時停止、スキップ、音量、シャッフル、リピートの設定や、再生中の曲の確認もできます。 | **オートメーション** |

**Mac アプリ** タブには Spotify もあり、同じように使えます。Mac に Spotify アプリがあり、アカウントにサインインしている必要があります。

<Warning>
エージェントは、確認なしに予定、リマインダー、メモ、メールを変更・削除したり、メールを送信したりできます。確認したいときは、計画や下書きを頼んでください。メッセージでの送信前には、エージェントが宛先と本文を確認します。
</Warning>

## アプリの接続を解除する

**Mac アプリ** タブでアプリを開き、**接続を解除** をクリックします。これで Enconvo でのアプリがオフになります。macOS のアクセスも取り消すには、**システム設定 → プライバシーとセキュリティ** で、表にあるそのアプリの権限の下の Enconvo をオフにします。

## アプリ別の例

### メール

メールは、iCloud、Gmail、Outlook、Exchange など、メールアプリに設定されたすべてのアカウントで使えます。エージェントは、メールボックスの管理、メールのルールのオン・オフ、添付ファイルの保存、未読メールの数え上げもできます。

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### リマインダー

リマインダーには、期限の日時、メモ、優先度(なし、低、中、高)、繰り返しのルール、到着時または出発時に通知する場所を設定できます。繰り返しのルールは、毎日、毎週、毎月、毎年のいずれかで、1 期間以上の間隔(2 週間ごとなど)と、任意の終了日を指定できます。

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### カレンダー

予定は、終日にしたり、場所、メモ、リンクを設定したり、開始の何分前かにアラームを鳴らしたり、予定ありの時間、空き時間、仮の予定、予定が入れられない時間として表示したり、毎日、毎週、毎月、毎年の繰り返しを終了日まで、または指定した回数だけ設定したりできます。繰り返しの予定を削除するときは、エージェントがすべての回を削除できます。

**基本の予定:**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**終日の予定:**
```
"Block off next Friday as a personal day"
```

**繰り返しの予定:**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**アラーム:**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**複数のカレンダー:**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 連絡先

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### メッセージ

メッセージは、電話番号、メールアドレス、グループチャットに iMessage を送信します。iMessage で配信するには、メッセージアプリが Apple アカウントにサインインしている必要があります。メッセージが **未配信** になったときは、送信済みと言う代わりに、エージェントがそのことを伝えます。

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### メモ

エージェントは、メモアプリで選択しているメモも読み取れるので、「これを要約して」「これを翻訳して」といった頼み方に向いています。

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### マップ

エージェントは Apple マップを開いて、場所の検索、車、徒歩、公共交通機関での経路の表示、ピンの追加、ガイドの作成を行います。結果はチャットではなくマップに表示されます。場所をお気に入りに保存したりガイドに追加したりするときは、エージェントがその場所を開き、最後の操作はマップであなたが行います。

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### ショートカット

エージェントはショートカットを実行しません。Enconvo からショートカットを実行するには、**設定 → クイックアクション** のクイックアクションに **ショートカットを実行** ステップを追加します。

## 権限

各アプリは、上の表に記載したそれぞれの macOS の権限を使います。

- カレンダーとリマインダーは、**システム設定 → プライバシーとセキュリティ** の **カレンダー** と **リマインダー** のリストを使います。
- 連絡先、メモ、メール、メッセージ、ミュージックは **オートメーション** を使い、macOS が Enconvo に各アプリの制御を許可するかを尋ねます。連絡先では、連絡先へのアクセスも求められます。
- メッセージは履歴を保護されたファイルに保存しているため、読み取るには Enconvo に **フルディスクアクセス** が必要です。

権限の確認を拒否すると、そのアプリは Enconvo で動作しません。カレンダー、リマインダー、連絡先では、**Mac アプリ** タブでアプリをもう一度接続すると、macOS が再び確認します。接続済みのアプリが macOS にブロックされているときは、**Mac アプリ** タブのその行に **設定を開く** が表示され、正しいスイッチに移動できます。これらの権限は、あとから **システム設定 → プライバシーとセキュリティ** でいつでも変更できます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| メールが動作しない | メールアプリにメールアカウントが 1 つ以上あることを確認してください。**システム設定 → プライバシーとセキュリティ → オートメーション** で、メールに対して Enconvo がオンになっていることを確認します。 |
| カレンダーへのアクセスが拒否される | **システム設定 → プライバシーとセキュリティ → カレンダー** で、Enconvo が一覧にあり、オンになっていることを確認してください。許可したあとは Enconvo を再起動します。 |
| リマインダーが表示されない | **システム設定 → プライバシーとセキュリティ → リマインダー** で Enconvo にアクセスが許可されていることと、リマインダーアプリにそのリマインダーが表示されていることを確認してください。 |
| メッセージの履歴を読み取れない | **システム設定 → プライバシーとセキュリティ** で、Enconvo の **フルディスクアクセス** をオンにしてください。 |
| 接続済みのアプリに **設定を開く** が表示される | macOS が Enconvo をブロックしています。**設定を開く** をクリックして、Enconvo をオンにしてください。 |

title: "スマートフォンとペアリング"
description: "iPhone または Android の Enconvo アプリを Mac、Windows PC、Linux デスクトップ、またはターミナルのみの Linux サーバーとペアリングします。"
---

スマートフォンの Enconvo アプリを自分の各コンピュータとペアリングすると、それらのプロジェクトやチャットをスマートフォンから利用できます。スマートフォンから開いたチャットはそのコンピュータ上で動き続け、コンピュータ内のファイルやアプリ、エージェントをそのまま使えます。スマートフォンとコンピュータは Enconvo リレー経由で接続され、メッセージはエンドツーエンドで暗号化されます。両者が同じネットワーク上にあるときは直接接続されるため、自宅やオフィスではさらに速く接続して応答します。

コンピュータはそれぞれ個別にスマートフォンとペアリングします。2 台のコンピュータ同士（例：Linux ノート PC と Mac）をペアリングしても、どちらもスマートフォンには追加されません。スマートフォンから使いたいコンピュータごとにペアリングを行ってください。

## はじめる前に

- **アプリを入手する：** iPhone は [TestFlight](https://testflight.apple.com/join/MJQuEN28)、Android は Google Play または APK から入手します。コンピュータ側の **設定 → 接続** にある **スマートフォンアプリを入手** にそれぞれのダウンロード用コードがあり、Mobile Companion プラグインの **スマートフォンアプリを入手** ボタンからも開けます。
- **同じアカウントを使う：** スマートフォンアプリとコンピュータを同じ Enconvo アカウントでサインインします。ペアリングできるのは同じアカウントのスマートフォンのみです。無料プランのアカウントでもペアリングでき、コンピュータのチャットやリモート画面をスマートフォンから使えます。
- **コンピュータの電源を入れ、Enconvo を起動しておく：** スマートフォンからコンピュータに接続できるのは、そのコンピュータ上で Enconvo が起動している間だけです。

## Mac、Windows、Linux デスクトップ

3 つの OS すべてで手順は同じです。

<Steps>
  <Step title="コンピュータでペアリングコードを表示する">
    サイドバー下部にあるデバイススイッチャーをクリックし、**デバイスを追加 → スマートフォンをペアリング** を選びます。または **設定 → 接続** を開いて **ペアリングコードを表示** を選択します。QR コードが表示されます。コードは 1 回限り有効で、有効期限は 5 分間です。
  </Step>
  <Step title="スマートフォンでスキャンする">
    Enconvo アプリで **リモート** を開き、**コンピュータをペアリング** をタップしてカメラをコードに向けます。iPhone のカメラ、Android のカメラ、Google レンズでもスキャンでき、コードから Enconvo が開いてそのコンピュータを承認できます。アプリがまだインストールされていない場合は、コードのリンクからインストールした後にペアリングできます。
  </Step>
  <Step title="スマートフォンからコンピュータを使う">
    すぐにペアリングが完了し、コンピュータが表示されます。複数のコンピュータをペアリングしている場合は **リモート** から切り替えられます。
  </Step>
</Steps>

コードの有効期限が切れた場合は、**新しいコードを表示** を選んでスキャンし直してください。

## ターミナルのみの Linux サーバー

サーバーにはコードを表示するウィンドウがないため、コマンドラインからコードを出力します。Enconvo 2.5.15 Beta 1 以降が必要です。先に[サーバーにインストール](/ja/getting-started/linux)の手順を行ってください。

<Steps>
  <Step title="サーバーでサインインする">
    ```bash
    enconvo login
    ```
    表示されたコードを `enconvo.com/device` で承認します。
  </Step>
  <Step title="Enconvo を常時起動しておく">
    ```bash
    enconvo service install
    ```
    スマートフォンからサーバーへ接続できるのは、Enconvo がそこで動作している間だけです。
  </Step>
  <Step title="ペアリングコードを出力する">
    ```bash
    enconvo companion pair --phone
    ```
    ターミナルに QR コードとその下のリンク、および有効期限が出力されます。コードは 1 回限り有効で、有効期限は 5 分間です。
  </Step>
  <Step title="スキャンする、またはリンクを開く">
    スマートフォンのカメラでコードをスキャンするか、スマートフォンでリンクを開きます。Enconvo アプリで承認すると、スマートフォンにサーバーが表示されます。
  </Step>
</Steps>

- **SSH 経由：** コードは手元のターミナルに描画されるため、SSH 経由でも動作します。行が折り返されて崩れる場合はウィンドウを広げるか、代わりにリンクを開いてください。
- **サインイン：** 自分のターミナルから直接実行した場合、そのコードはスマートフォンアプリのサインインも兼ねるため、必ず自分自身のスマートフォンでのみ読み取ってください。パイプやファイルへ出力した場合、またはエージェントがコマンドを実行した場合はリンクのみが表示され、サインインは行われません。その場合は先にスマートフォンアプリを同じアカウントでサインインしてください。
- **期限切れ：** `enconvo companion pair --phone` をもう一度実行します。

## ペアリング済みのスマートフォンを管理する

各コンピュータの **設定 → 接続** に、ペアリング済みのスマートフォンが一覧表示されます。

| やりたいこと | 手順 |
|---|---|
| 別のスマートフォンをペアリングする | 新しいコードを表示してそのスマートフォンでスキャンします。1 台のコンピュータにつき最大 10 台までペアリングできます。 |
| スマートフォンの名前を変更する | 対象のスマートフォンをクリックし、名前の横にある **スマートフォンの名前を変更** をクリックします。 |
| スマートフォンを削除する | 横にある **削除** を選択します。そのスマートフォンからはこのコンピュータに接続できなくなります。 |
| 最初からやり直す | **接続をリセット** を選択します。すべてのスマートフォンが削除され、再ペアリングが必要になります。 |

## トラブルシューティング

| 問題 | 対処方法 |
|---|---|
| スマートフォンにコンピュータが表示されない | スマートフォンをそのコンピュータ自身と直接ペアリングしてください。別のコンピュータとペアリングしても追加されません。 |
| **このコードは期限切れです** | 新しいコードを表示するかコマンドを再実行して、5 分以内にスキャンしてください。 |
| **ログインしてスマートフォンをペアリング** | コンピュータ側で Enconvo にサインインしてください。サーバーの場合は `enconvo login` を実行します。 |
| サーバーがサインインしていないと表示する | `enconvo login` を実行してから、もう一度 `enconvo companion pair --phone` を実行してください。 |
| スマートフォン上でサーバーがオフラインと表示される | Enconvo が起動しているか確認してください：`enconvo service install` を実行し、ログアウト時に止まる場合は `sudo loginctl enable-linger "$USER"` を実行します。 |

---
title: "スマートフォンをペアリング"
description: "Enconvo の iPhone アプリまたは Android アプリを、Mac、Windows PC、Linux デスクトップ、ターミナルしかない Linux サーバーとペアリングします。"
---

スマートフォンの Enconvo アプリは、各コンピュータとペアリングでき、そのプロジェクトやチャットがスマートフォンに表示されます。スマートフォンから開いたチャットは、そのコンピュータのファイル、アプリ、エージェントを使って、コンピュータ上で動き続けます。スマートフォンは Enconvo のリレーを通じてコンピュータに接続し、メッセージはエンドツーエンドで暗号化されます。スマートフォンとコンピュータが同じネットワークにあるときは、アプリが直接接続するので、自宅やオフィスでは接続も応答も速くなります。

各コンピュータは、それぞれ個別にスマートフォンとペアリングします。2 台のコンピュータ同士(たとえば Linux のノートパソコンと Mac)をペアリングしても、どちらもスマートフォンには追加されません。スマートフォンから使いたいコンピュータごとに、スマートフォンをペアリングしてください。

## 始める前に

- **アプリを入手する。** iPhone:[TestFlight](https://testflight.apple.com/join/MJQuEN28)。Android:Google Play、または APK。コンピュータの **設定 → 接続** にある **スマートフォンアプリを入手** に、それぞれのダウンロードコードがあります。モバイルコンパニオンプラグインの **スマートフォンアプリを入手** ボタンからも開けます。
- **同じアカウントを使う。** スマートフォンのアプリとコンピュータを、同じ Enconvo アカウントでサインインします。ペアリングできるのは、同じアカウントのスマートフォンだけです。無料アカウントでもペアリングでき、スマートフォンからコンピュータのチャットとリモート画面を使えます。
- **コンピュータをオンにして、Enconvo を起動したままにする。** スマートフォンがコンピュータに接続できるのは、そこで Enconvo が動いている間だけです。

## Mac、Windows、Linux デスクトップ

3 つとも手順は同じです。

<Steps>
  <Step title="コンピュータにペアリングコードを表示する">
    サイドバー下部のデバイス切り替えをクリックし、**デバイスを追加 → スマートフォンをペアリング** を選びます。または **設定 → 接続** を開いて **ペアリングコードを表示** を選びます。QR コードが表示されます。コードは 1 回だけ使え、5 分間有効です。
  </Step>
  <Step title="スマートフォンでスキャンする">
    Enconvo アプリで **リモート** を開き、**コンピュータをペアリング** をタップして、カメラをコードに向けます。iPhone のカメラ、Android のカメラ、Google レンズでスキャンすることもできます。コードから Enconvo が開き、そこでコンピュータを確認します。アプリがまだインストールされていないときは、コードのリンクからインストールしてペアリングできます。
  </Step>
  <Step title="スマートフォンからコンピュータを使う">
    スマートフォンはすぐにペアリングされ、コンピュータが表示されます。複数のコンピュータをペアリングしているときは、**リモート** から切り替えます。
  </Step>
</Steps>

コードの期限が切れたら、**新しいコードを表示** を選んで、もう一度スキャンします。

## ターミナルしかない Linux サーバー

サーバーにはコードを表示するウィンドウがないため、コマンドラインがコードを出力します。Enconvo 2.5.15 Beta 1 以降が必要です。先に[サーバーにインストールする](/ja/getting-started/linux)の手順を行ってください。

<Steps>
  <Step title="サーバーをサインインさせる">
    ```bash
    enconvo login
    ```
    出力されたコードを `enconvo.com/device` で承認します。
  </Step>
  <Step title="Enconvo を起動したままにする">
    ```bash
    enconvo service install
    ```
    スマートフォンがサーバーに接続できるのは、そこで Enconvo が動いている間だけです。
  </Step>
  <Step title="ペアリングコードを出力する">
    ```bash
    enconvo companion pair --phone
    ```
    ターミナルに QR コードが描画され、その下にリンクと有効期限が表示されます。コードは 1 回だけ使え、5 分間有効です。
  </Step>
  <Step title="スキャンするか、リンクを開く">
    スマートフォンのカメラでコードをスキャンするか、スマートフォンでリンクを開きます。Enconvo アプリで確認すると、サーバーがスマートフォンに表示されます。
  </Step>
</Steps>

- **SSH 経由**:コードは自分のターミナルに描画されるので、SSH 経由でも使えます。折り返されてしまうときは、ウィンドウを広げるか、代わりにリンクを開いてください。
- **サインイン**:自分のターミナルに入力したときは、コードがスマートフォンアプリのサインインも兼ねるので、自分のスマートフォンにだけ送ってください。パイプやファイルに保存した出力、またはエージェントが実行したコマンドではリンクだけが出力され、アプリはサインインされません。先に同じアカウントでアプリにサインインしておいてください。
- **期限切れ**:`enconvo companion pair --phone` をもう一度実行します。

## ペアリングしたスマートフォンを管理する

各コンピュータの **設定 → 接続** に、ペアリングしたスマートフォンが一覧表示されます。

| やりたいこと | 操作 |
|---|---|
| 別のスマートフォンをペアリングする | 新しいコードを表示し、そのスマートフォンでスキャンします。1 台のコンピュータにペアリングできるスマートフォンは最大 10 台です。 |
| スマートフォンの名前を変更する | スマートフォンをクリックし、名前の横の **スマートフォンの名前を変更** をクリックします。 |
| スマートフォンを削除する | その横の **削除** を選びます。そのスマートフォンは、このコンピュータに接続できなくなります。 |
| 最初からやり直す | **接続をリセット** を選びます。すべてのスマートフォンが削除され、もう一度ペアリングが必要です。 |

## トラブルシューティング

| 問題 | 対処 |
|---|---|
| コンピュータがスマートフォンに表示されない | そのコンピュータ自身とスマートフォンをペアリングしてください。別のコンピュータとペアリングしても、追加されません。 |
| **このコードは期限切れです** | 新しいコードを表示するか、コマンドをもう一度実行して、5 分以内にスキャンしてください。 |
| **ログインしてスマートフォンをペアリング** | コンピュータで Enconvo にサインインしてください。サーバーでは `enconvo login` を実行します。 |
| サーバーがサインインしていないと表示される | `enconvo login` を実行してから、もう一度 `enconvo companion pair --phone` を実行してください。 |
| スマートフォンでサーバーがオフラインと表示される | そこで Enconvo が動いていることを確認してください。`enconvo service install` を実行し、ログアウトすると止まる場合は `sudo loginctl enable-linger "$USER"` を実行します。 |

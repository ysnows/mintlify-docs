description: "Enconvo が動く複数のコンピュータをペアリングし、別のコンピュータからチャット・ターミナル・画面・エージェントを操作しながら作業を続けられます。"
---

Enconvo が動作する 2 台のコンピュータをペアリングすると、一方からもう一方のコンピュータ上で作業できるようになります。ペアリング先のコンピュータで開いたチャットは、そのコンピュータのファイル、キー、モデル、エージェントを使って現地で実行され、別の画面に移っても動き続けます。また、画面の閲覧や操作、ファイルの送信、こちらのエージェントから向こうへの作業の引き渡しも可能です。

Enconvo が入っていないサーバーに接続したい場合は、代わりに SSH ホストとして追加してください。[コンピュータと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)を参照してください。

## はじめる前に

- 両方のコンピュータに Enconvo をインストールし、同じ Enconvo アカウントでサインインします。
- 両方をオンラインにし、Enconvo を起動したままにします。Enconvo が実行されていないコンピュータには接続できません。
- Free プランでは、1 台のコンピュータを別の 1 台とペアリングできます。アカウントのデバイスシートはいずれか 1 台に割り当てられ、もう一方からそのデバイスを操作できます（操作される側からも、相手のチャット閲覧とファイル送信は行えます）。

## コンピュータをペアリングする

ペアリングでは、どちらが操作する側でどちらが操作される側かが常に明示されます。どちらのコンピュータからでも開始できます。

<Steps>
  <Step title="ペアリングを開始する">
    チャットウィンドウのサイドバー下部にあるデバイススイッチャーをクリックし、**デバイスを追加 → コンピュータをペアリング**を選びます。または**設定 → 接続**を開き、**コンピュータ**の下にある**コンピュータをペアリング**をクリックします。
  </Step>
  <Step title="操作するコンピュータを選ぶ">
    オンラインの他のコンピュータが一覧に表示されます。このコンピュータから操作したい相手を選び、アクセスを許可する範囲を選択します。双方向で操作したい場合は、相手側からもこのコンピュータを操作できるようにするオプションをオンにします。
  </Step>
  <Step title="相手のコンピュータで許可する">
    相手のコンピュータの Dynamic Island に番号付きのリクエストが表示されます。両方のコンピュータで同じ番号が表示されていることを確認し、**許可**をクリックします。
  </Step>
  <Step title="開き方を設定する">
    簡単なガイドが表示され、相手のコンピュータをチャットウィンドウ内で開くか専用ウィンドウで開くかを選べます。また、どのアプリからでも呼び出せるショートカットの設定や、できることの一覧も案内されます。このガイドは、コンピュータの **⋯** メニュー → **使い方**からいつでも開き直せます。
  </Step>
</Steps>

コンピュータ同士が互いを見つけられない場合は**リンクでペアリング**を使います。操作される側のコンピュータでリンクをコピーし、手元のコンピュータに貼り付けます。リンクは 1 回限り有効で、5 分間で失効します。

別のコンピュータとペアリングした後には、このコンピュータ上で相手が何を利用できるかを示す通知が表示されます。変更したい場合は**変更**をクリックしてください。

## 許可する操作範囲を選ぶ

ペアリングを許可するとき、および後から**設定 → 接続**のコンピュータページで、相手のコンピュータにここで何を許可するかを選べます。

| 選択肢 | 相手のコンピュータがここでできること |
| --- | --- |
| **チャット** | ここでチャットを開き、実行し続けます。 |
| **チャットとツール** | さらに**ターミナル**、**画面**、**ファイル**も利用でき、相手のエージェントがここでコマンドを実行できます。 |
| **すべて** | さらに相手のエージェントがここでチャットを開始したり、この画面を操作したりできます。 |

1 つずつ設定したい場合は**個別のスイッチ**を選択します。

| スイッチ | 許可される操作 |
| --- | --- |
| **チャット** | ここでチャットを開き、実行し続けます。 |
| **ターミナル** | シェルを開き、相手のエージェントがコマンドを実行できるようにします。 |
| **画面** | この画面を表示および操作します。 |
| **ファイル** | ここの「ダウンロード」フォルダにファイルを送信します。 |
| **エージェント** | 相手のエージェントがここでチャットを開始できるようにします。オンにするまで無効です。 |
| **エージェントによる操作** | 相手のエージェントがこの画面やブラウザを操作できるようにします。操作中は表示で分かり、いつでも停止できます。オンにするまで無効です。 |

## 他のコンピュータのチャットを開く

チャットウィンドウのサイドバーには、一度に 1 台のコンピュータのリストが表示されます。下部にあるデバイススイッチャーで現在のコンピュータとペアリング済みのコンピュータを切り替えたり、他のコンピュータで待機中のタスクを確認したり、各コンピュータを専用ウィンドウで開いたりできます。

- 各コンピュータの一覧にはそのコンピュータのチャットとプロジェクトが表示され、実行中の状態や確認待ちの状態も分かり、その場で開けます。
- コンピュータごとに色を設定できます。コンピュータの **⋯** メニュー → **カラー**から変更します。
- 別のコンピュータのエージェントが開始したチャットには目印が付き、チャットウィンドウの検索からも他のコンピュータのチャットが見つかります。
- 別のコンピュータで返信が完了したときや、そのエージェントがあなたの回答を待っているときには通知が届きます。

別のコンピュータで新しいチャットを始めるには、新しいチャットのメッセージボックスにある**実行先**チップを使います。入力したテキストはそのまま引き継がれます。**⌃1** 〜 **⌃9** キーでコンピュータを素早く切り替えることもできます。

他のコンピュータ上のスライド、デザイン、ダッシュボードは読み取り専用で開き、他のコンピュータのチャットでは**読み上げ**は提供されません。

### 専用のウィンドウで開く

コンピュータの **⋯** メニューで**専用のウィンドウで開く**を選ぶと、そのコンピュータのカラーが付いた専用 Dock アイコンを持つウィンドウでチャットが開きます。同じメニューの**Dockに追加**をオンにしておくと、アイコンを Dock に残して後から開けます。

これをデフォルトにするには、**設定 → 接続**でそのコンピュータをクリックし、**チャット**の下で**チャットウィンドウ**または**専用のウィンドウ**を選びます。**ショートカット**では、どのアプリからでもそのコンピュータを呼び出せるキーを設定できます。

### コンピュータがオフラインのとき

オフラインのコンピュータのチャットも閲覧できます。画面上の内容を使って手元で新しいチャットを始めるには**この Mac で続ける**を、復帰時に通知を受け取るには**戻ったら通知**をクリックします。

## 画面を使う

コンピュータのページには相手の画面が表示されます。画面を見守るだけでなく、制御を取って手元のマウスとキーボードで操作することもできます。

フルスクリーンボタンをクリックするか、**⌃⌥F**（Mac では **⌃⌘F** も可）を押すと画面いっぱいに表示されます。上端にポインタを動かすと操作バーが戻ります。同じキーを押すと終了し、閲覧のみの場合は **Esc** でも抜けられます。隣にある**表示領域いっぱいに表示**ボタンを使うと、黒い余白が出ないように画面を拡大して表示し、収まらない端の部分をトリミングします。

相手のコンピュータを操作している間、向こうでコピーした内容は手元のクリップボードにも届きます。制御を終了する方法は画面上に案内が表示されます。

## ファイルを送信する

コンピュータのページで**ファイルを送信**をクリックします。ファイルは相手のコンピュータの **ダウンロード → Enconvo** に保存され、同名の既存ファイルを上書きすることはなく、接続が切れても途中から再開されます。

別のコンピュータのチャットに添付したファイルも同様に転送され（1 ファイル最大 2 GB）、進捗バーが表示されます。

## 別のコンピュータに作業を引き渡す

コンピュータで**エージェント**がオンになっていると、こちらのエージェントが向こうでチャットを開始して回答を受け取れるようになります。チャット内で `@` を使ってコンピュータを指定するか、エージェントにそのコンピュータを使うよう指示してください。向こうでエージェントが何かを実行しようとするときは先にそのコンピュータ上で確認が求められ、承認待ちであることとその内容がチャットに表示されます。

**エージェントによる操作**がオンになっていれば、相手のコンピュータのエージェントがこの Mac の画面やブラウザを直接操作できます（たとえば修正をその場ですぐ再テストしたいときなど）。こちらには誰が操作中かを示すオーバーレイが表示され、いつでも操作を取り戻したり停止したりできます。

エージェントが別のコンピュータを使用している間は、チャット上部のストリップとメッセージボックス上のピルに先方の最新スクリーンショットと**停止**ボタンが表示されます。実行が終わると、ステップとスクリーンショットをまとめた 1 枚のカードとして表示されます。

別のコンピュータ上でコマンドを実行する方法については、[コンピュータと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)を参照してください。

## コンピュータを削除する

**設定 → 接続**でコンピュータをクリックして**削除**を選ぶか、サイドバーの **⋯** メニューから**ペアリングを解除…** を選びます。相手のコンピュータ上のチャット自体は残ります。もう一度使いたい場合は再度ペアリングしてください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| ペアリング一覧に相手のコンピュータが出ない | オンラインで Enconvo が起動しており、同じアカウントでサインインしているか確認してください。または**リンクでペアリング**を使います。 |
| 相手のコンピュータにペアリングリクエストが出ない | 相手コンピュータの Dynamic Island を確認してください。アプリが終了していたり接続が切れていたりした場合は、ペアリングをやり直してください。 |
| コンピュータのページのスイッチが淡色表示になっている | 相手のコンピュータ側でその権限が許可されていません。向こうのコンピュータでこの Mac に対して有効にしてください。 |
| 画面やチャットで接続できないと表示される | 相手のコンピュータがスリープしておらず Enconvo が起動しているか確認してください。復帰を待つ場合は**戻ったら通知**を使います。 |

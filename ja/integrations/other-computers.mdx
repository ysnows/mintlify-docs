---

Enconvo を実行している 2 台のコンピュータをペアリングすると、一方からもう一方で作業できます。ペアリングしたコンピュータで開いたチャットは、そのコンピュータのファイル、鍵、モデル、エージェントを使ってそこで実行され、目を離しても動き続けます。画面の表示や操作、ファイルの送信もでき、こちらのエージェントに作業を任せることもできます。

Enconvo を実行していないサーバーに接続するには、代わりに SSH ホストとして追加します。[コンピュータと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)をご覧ください。

## 始める前に

- 両方のコンピュータに Enconvo をインストールし、同じ Enconvo アカウントでサインインします。
- 両方をオンラインにし、Enconvo を実行したままにします。コンピュータには、そこで Enconvo が動いている間だけ接続できます。
- Free プランでは、1 台のコンピュータを別の 1 台とペアリングできます。アカウントのデバイスのシートは 2 台のうち 1 台に残ります。そのコンピュータは、もう一方から操作できます。そのコンピュータからは、もう一方のコンピュータのチャットを読み、ファイルを送れます。

## コンピュータをペアリングする

ペアリングでは、どちらが操作する側で、どちらが操作される側かが常に表示されます。どちらの側からでも始められます。

<Steps>
  <Step title="ペアリングを始める">
    チャットウィンドウのサイドバー下部にあるデバイス切り替えをクリックし、**デバイスを追加 → コンピュータをペアリング** を選びます。または **設定 → 接続** を開き、**コンピュータ** の下の **コンピュータをペアリング** をクリックします。
  </Step>
  <Step title="操作するコンピュータを選ぶ">
    オンラインのほかのコンピュータがリストに表示されます。このコンピュータから操作したいものを選び、そのコンピュータがアクセスできる範囲を選びます。双方向に操作したい場合は、相手からこのコンピュータを操作できるようにするオプションもオンにします。
  </Step>
  <Step title="相手のコンピュータで許可する">
    相手のコンピュータの Dynamic Island に、番号付きでリクエストが表示されます。両方のコンピュータに同じ番号が表示されていることを確認して、**許可** をクリックします。
  </Step>
  <Step title="開き方を設定する">
    短いガイドで、コンピュータをチャットウィンドウで開くか専用のウィンドウで開くかを選び、どのアプリからでも呼び出せるショートカットを設定し、できることを確認します。ガイドは、コンピュータの **⋯** メニュー → **使い方** からいつでも開き直せます。
  </Step>
</Steps>

コンピュータ同士が見えないときは、**リンクでペアリング** を使います。操作したいコンピュータでリンクをコピーし、手元のコンピュータに貼り付けます。リンクは 1 回だけ使え、5 分間有効です。

ほかのコンピュータがこのコンピュータとペアリングすると、ここで何を使えるかがお知らせで表示されます。**変更** をクリックして調整します。

## コンピュータがアクセスできる範囲を選ぶ

ペアリングを許可するときと、その後 **設定 → 接続** のコンピュータのページで、相手のコンピュータがここで何を操作できるかを選びます。

| 選択 | 相手のコンピュータがここでできること |
| --- | --- |
| **チャット** | ここのチャットを開いて、動かし続ける。 |
| **チャットとツール** | さらに **ターミナル**、**画面**、**ファイル** も使え、相手のエージェントがここでコマンドを実行できる。 |
| **すべて** | さらに、相手のエージェントがここでチャットを始め、この画面を使える。 |

**個別のスイッチ** を選ぶと、1 つずつ設定できます。

| スイッチ | 許可されること |
| --- | --- |
| **チャット** | ここのチャットを開いて、動かし続ける。 |
| **ターミナル** | シェルを開き、相手のエージェントにコマンドを実行させる。 |
| **画面** | この画面を見て、操作する。 |
| **ファイル** | ここの ダウンロード フォルダにファイルを送る。 |
| **エージェント** | 相手のエージェントがここでチャットを始められるようにする。オンにするまでオフです。 |
| **エージェントによる操作** | 相手のエージェントがこの画面とブラウザを使えるようにする。使っているときは通知され、止めることもできます。オンにするまでオフです。 |

## コンピュータのチャットを開く

チャットウィンドウのサイドバーには、一度に 1 台のコンピュータが一覧表示されます。下部のデバイス切り替えで、このコンピュータとペアリングしたコンピュータを切り替えられ、ほかのコンピュータで自分を待っているものが表示され、どれでも専用のウィンドウで開けます。

- 各コンピュータのリストには、チャットとプロジェクト、実行中のものと自分の対応が必要なものが表示され、その場で開けます。
- コンピュータごとに専用の色があります。コンピュータの **⋯** メニュー → **色** から変更できます。
- ほかのコンピュータのエージェントが始めたチャットには印が付き、チャットウィンドウの検索ではそのコンピュータのチャットも見つかります。
- ほかのコンピュータで返信が届いたときや、そのエージェントがあなたの回答を必要としているときは、Enconvo が通知します。

ほかのコンピュータで新しいチャットを始めるには、新しいチャットのメッセージボックスにある **実行先** チップを使います。入力した内容はそのまま引き継がれます。**⌃1** から **⌃9** を押すと、コンピュータを切り替えられます。

ほかのコンピュータのデッキ、デザイン、ダッシュボードは読み取り専用で開き、ほかのコンピュータのチャットでは **読み上げ** は使えません。

### 専用のウィンドウで

コンピュータの **⋯** メニューで **専用のウィンドウで開く** を選ぶと、そのコンピュータの色の専用 Dock アイコンが付いたウィンドウでチャットが開きます。同じメニューで **Dockに追加** をオンにすると、アイコンが Dock に残り、あとで開けます。

これを既定にするには、**設定 → 接続** を開いてコンピュータをクリックし、**チャット** の下で **チャットウィンドウ** または **専用ウインドウ** を選びます。**ショートカット** では、どのアプリからでもそのコンピュータを呼び出すキーを設定します。

### コンピュータがオフラインのとき

オフラインのコンピュータのチャットは、読めるまま残ります。**この Mac で続ける** をクリックすると、画面に表示されている内容を引き継いで、ここで新しいチャットを始められます。**戻ったら通知** も選べます。

## 画面を使う

コンピュータのページに、その画面が表示されます。見るだけにすることも、操作を引き継いで自分のマウスとキーボードで使うこともできます。

全画面ボタンをクリックするか、**⌃⌥F**(Mac では **⌃⌘F** も使えます)を押すと、画面全体に映像を表示します。ポインタを上端に動かすと、コントロールが再び表示されます。同じキーを押すと終了します。見ているだけのときは **Esc** でも終了できます。隣の **表示領域いっぱいに表示** ボタンを押すと、黒い帯が出ないように映像を拡大して表示領域を埋め、収まらない端は切り取られます。

相手のコンピュータを操作している間、そこでコピーしたものが自分のクリップボードに届きます。操作をやめる方法は、画面上の 1 行で案内されます。

## ファイルを送る

コンピュータのページで **ファイルを送信** をクリックします。ファイルは相手のコンピュータの **ダウンロード → Enconvo** に届き、すでにあるファイルを上書きすることはなく、接続が切れても再開されます。

ほかのコンピュータのチャットに添付するファイルも、進行状況バー付きで 1 件あたり 2 GB まで送られます。

## ほかのコンピュータに作業を任せる

コンピュータの **エージェント** がオンのとき、こちらのエージェントがそこでチャットを始め、答えを読み取れます。チャットで `@` を付けてそのコンピュータをメンションするか、エージェントにそのコンピュータを使うよう頼みます。エージェントがそこで行おうとする操作は、先にそのコンピュータであなたに確認され、ほかのコンピュータが承認を待っているときと、その内容はチャットに表示されます。

**エージェントによる操作** がオンのときは、ほかのコンピュータのエージェントがこの Mac の画面とブラウザを直接使えます。たとえば、変更をすぐに再テストするときなどです。ここに表示されるオーバーレイが、誰が操作しているかを示し、操作を引き継いだり止めたりできます。

こちらのエージェントがほかのコンピュータを使っている間は、チャット上部の帯とメッセージボックス上のピルに、そこから届いた最新のスクリーンショットと **停止** ボタンが表示されます。終了した実行は、ステップとスクリーンショットをまとめた 1 枚のカードとして表示されます。

ほかのコンピュータでコマンドを実行する方法は、[コンピュータと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)をご覧ください。

## コンピュータを削除する

**設定 → 接続** でコンピュータをクリックして **削除** を選ぶか、サイドバーのその **⋯** メニューで **ペアリングを解除…** を選びます。チャットはそのコンピュータに残ります。もう一度使うには、ペアリングし直します。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ペアリングのリストに相手のコンピュータがない | オンラインで、Enconvo が動いていて、同じアカウントでサインインしていることを確認してください。または **リンクでペアリング** を使います。 |
| ペアリングのリクエストが相手のコンピュータに表示されない | 相手のコンピュータの Dynamic Island を確認してください。終了していたり接続が切れていたりする場合は、ペアリングをやり直します。 |
| コンピュータのページのスイッチが薄く表示される | 相手のコンピュータが許可していません。そのコンピュータで、このコンピュータに対してオンにしてください。 |
| 画面やチャットでコンピュータに接続できないと表示される | コンピュータがスリープしておらず、Enconvo が動いていることを確認してください。**戻ったら通知** を使うと、復帰したときに知らせてくれます。 |

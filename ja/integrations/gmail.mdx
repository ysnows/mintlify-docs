title: "Gmail"
description: "Gmail を一度接続するだけで、どのチャットからでもエージェントがメールの検索、閲覧、整理、送信を行えるようになります。"
---

Gmail コネクタを使うと、Enconvo でメールを扱えるようになります。重要なメールの検索、スレッドの要約、返信の下書き作成、受信トレイの整理などをエージェントに頼むと、あなたの代わりに Gmail を操作します。Google アカウントを Enconvo アカウント経由で一度接続するだけで利用でき、Google Cloud プロジェクトや API キーの設定は不要です。

ここで接続した Gmail アカウントは[メール](/ja/integrations/email)にも表示され、自分でメールを読んだり整理したり返信したりできます。

## はじめる前に

**設定 → アカウント**で Enconvo アカウントにサインインしてください。コネクタはすべてのプランで無料ですが、Enconvo アカウントが必要です。

## Gmail を接続する

<Steps>
  <Step title="Gmail を探す">
    **設定 → プラグイン**を開き、**Enconvo** タブで **Gmail** を検索してクリックし、ページを開きます。
  </Step>
  <Step title="接続する">
    **接続**をクリックします。ブラウザで Google のサインイン画面が開きます。
  </Step>
  <Step title="アクセスを許可する">
    Google アカウントを選択し、求められるアクセス権限を確認してから許可します。Google の同意画面には、Enconvo の連携パートナーである Composio が表示されます。
  </Step>
  <Step title="結果を確認する">
    Enconvo に戻ると、**アカウント**の下にご自身のメールアドレスが表示されます。**今すぐ試す**をクリックするか、まずは「今日受信した受信トレイの未読メールを要約して」のような読み取り専用の質問をエージェントにしてみてください。
  </Step>
</Steps>

Gmail を接続する前にメールについてエージェントに尋ねると、チャット内に接続用のカードが表示されます。

## エージェントができること

| 分野 | エージェントができること |
| --- | --- |
| 読み取り | メールの検索、メッセージやスレッドの閲覧、添付ファイルのダウンロード、ラベルや下書きの一覧表示 |
| 整理 | ラベルの追加・削除、アーカイブ、ゴミ箱への移動および復元 |
| 作成・送信 | 下書きの作成と送信、新規メールの送信、返信、転送 |

検索では、`from:john@example.com`、`subject:invoice`、`after:2024/01/01` など Gmail 自身の検索構文が使えます。

エージェントがメールを作成または送信するときは、宛先（To）・CC・BCC の指定、プレーンテキストまたは HTML 本文の作成、既存スレッドへの返信、Mac 上のファイルの添付（最大 10 ファイル、1 ファイル最大 95 MB）が可能です。1 通のメールに添付できる上限（合計 25 MB）を超えるファイルは、代わりに file.enconvo.com 上のダウンロードリンクとして送られ、リンクを知っている人なら誰でもダウンロードできます。

<Warning>
エージェントは確認を求めずにメールを送信できます。送信前に確認したい場合は、下書きを作成するよう頼んでください。Enconvo がメールを完全に削除することはなく、削除操作を行うとゴミ箱へ移動します。
</Warning>

## オプション

アカウントを接続すると、Gmail のページに以下の項目が表示されます。

| オプション | 変更される内容 |
| --- | --- |
| **すべてのチャットで利用可能** | オン：エージェントがどの会話でも Gmail を使えるようになります。オフ：`@` でメンションしたとき、またはプロファイルに含まれているときだけ使います。 |
| **メールアラート** | 重要なメールが届いたときに Dynamic Island とスマートフォンに通知します。**オートメーション → 重要なメール**でオンにするまではオフになっており、その**スマートフォン**スイッチをオンにするとペアリング済みの iPhone や Android スマートフォンにも通知を送ります。重要度を判定するため、新着メールの送信者・件名・本文冒頭が Enconvo Cloud に送信されるため、オンにする前に確認が表示されます。メールが Cloud に保存されることはありません。 |
| **別のアカウントを接続** | 最大 5 つまで別の Gmail アドレスを追加します。 |

複数のアカウントがある場合は、エージェントはすべてのアカウントから読み取り、「仕事用アドレスから送って」のように別アカウントを指定しない限りデフォルトアカウントから送信・作成を行います。デフォルトを変えるには、アカウントのメニューから**デフォルトにする**を選びます。

## チャットで Gmail を使う

Gmail を接続したら、必要なことを頼むだけです。エージェントが適切な Gmail ツールを選びます。

**検索と要約：**
```
"Find all emails from John in the last week and summarize them"
```

**返信の下書きを作成：**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**受信トレイを整理：**
```
"Archive all newsletters from the past month"
```

**ラベルを管理：**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**古いメールを整理（ゴミ箱へ移動します）：**
```
"Delete all promotional emails older than 6 months"
```

## ワークフローのアイデア

Gmail は[ワークフロー](/ja/workflows/introduction)や[オートメーション](/ja/workflows/scheduled-jobs)でも使えます：

| アイデア | 内容 |
| --- | --- |
| **毎日のメールダイジェスト** | 未読メールを検索して要約し、朝のブリーフィングとして提示する |
| **自動分類** | 新着メールを検索し、内容に応じてラベルを付ける |
| **フォローアップリマインダー** | 返信待ちのメールを見つけてリマインダーを作成する |
| **レポート作成** | 条件に合うメールを検索し、集計レポートにまとめる |

## プライバシー

- **Enconvo Cloud と Composio を経由**：メールは依頼された処理を実行するためだけに Enconvo Cloud と Composio を通過し、保存されることはありません。
- **パスワードは Google に留まります**：Google のページ上でサインインするため、Enconvo が Google パスワードを知ることはありません。
- **オンデマンド動作**：エージェントが Gmail を読み取るのはタスクで必要なときだけです。唯一の例外は**メールアラート**で、オンにすると新着メールが届くたびに確認を行います。
- **いつでも解除可能**：Gmail ページの**接続解除**をクリックすると、すべてのデバイスからアクセスが削除されます。[Google アカウントの権限](https://myaccount.google.com/permissions)からもアクセスを削除できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **接続**がグレーアウトしている | 先に**設定 → アカウント**で Enconvo アカウントにサインインしてください。 |
| Gmail に**再接続**と表示されている | アクセス権限の期限が切れています。**再接続**をクリックして Google でもう一度サインインしてください。 |
| エージェントが Gmail を使わない | Gmail が接続されているか確認してください。**すべてのチャットで利用可能**がオフの場合は、チャットで `@` を使って Gmail をメンションしてください。 |
| 検索しても見つからない | まずは `from:john` のようなシンプルな検索を試し、そのメールが接続済みアカウントにあるか確認してください。Gmail 検索は Gmail のウェブサイトと同じように動作します。 |
| 添付ファイルが送信されない | ファイルパスが正しいか、ファイルが Mac 上に存在するか確認してください。 |

title: "Gmail"
description: "Gmail を一度接続すると、どのチャットからでもエージェントがメールを検索、閲覧、整理、送信できます。"
---

Gmail コネクタは、メールを Enconvo に取り込みます。エージェントに、重要なメールを探す、スレッドを要約する、返信を下書きする、受信トレイを整理するといったことを頼むと、あなたの代わりに Gmail を使います。Google アカウントは、Enconvo アカウントを通じて一度接続するだけで済み、Google Cloud プロジェクトや API キーの設定は不要です。

ここで接続した Gmail アカウントは[メール](/ja/integrations/email)にも表示され、自分で読んだり、整理したり、返信したりできます。

## 始める前に

**設定 → アカウント** で Enconvo アカウントにサインインします。コネクタはどのプランでも無料ですが、Enconvo アカウントが必要です。

## Gmail を接続する

<Steps>
  <Step title="Gmail を探す">
    **設定 → プラグイン** を開き、**Enconvo** タブで **Gmail** を検索します。クリックしてそのページを開きます。
  </Step>
  <Step title="接続する">
    **接続** をクリックします。ブラウザで Google のサインイン画面が開きます。
  </Step>
  <Step title="アクセスを許可する">
    Google アカウントを選び、求められるアクセス内容を確認してから許可します。Google の同意画面には、Enconvo の連携パートナーである Composio が表示されます。
  </Step>
  <Step title="結果を確認する">
    Enconvo に戻ると、**アカウント** の下にアドレスが表示されます。**今すぐ試す** をクリックするか、まずは「今日届いた受信トレイの未読メールを要約して」のような、読み取りだけの質問をエージェントに頼んでみましょう。
  </Step>
</Steps>

Gmail を接続する前にエージェントにメールのことを頼むと、チャットに接続用のカードが表示されます。

## エージェントにできること

| 分野 | エージェントにできること |
| --- | --- |
| 読み取り | メールの検索、メッセージやスレッドを開く、添付ファイルのダウンロード、ラベルと下書きの一覧表示 |
| 整理 | ラベルの追加と削除、アーカイブ、メッセージをゴミ箱に移動して復元 |
| 書き込み | 下書きの作成と送信、新規メールの送信、返信、転送 |

検索には、`from:john@example.com`、`subject:invoice`、`after:2024/01/01` のような Gmail 独自の検索構文を使います。

エージェントがメールを書いたり送ったりするときは、To、CC、BCC の指定、プレーンテキストまたは HTML の本文、既存のスレッド内での返信、Mac のファイルの添付(最大 10 ファイル、各 95 MB まで)ができます。1 通のメールで送れる容量(合計 25 MB)を超えるファイルは、代わりに file.enconvo.com のダウンロードリンクとして送られ、リンクを知っていれば誰でもそのファイルをダウンロードできます。

<Warning>
エージェントは、確認なしにメールを送信できます。確認したいときは、下書きを頼んでください。Enconvo がメールを完全に削除することはありません。削除するとゴミ箱に移動します。
</Warning>

## オプション

アカウントを接続すると、Gmail のページに次のオプションが表示されます。

| オプション | 変わること |
| --- | --- |
| **すべてのチャットで利用可能** | オン:エージェントがすべての会話で Gmail を使えます。オフ:`@` でメンションしたとき、またはプロファイルに含まれているときだけ使います。 |
| **メール通知** | 重要なメールが届いたときに、Dynamic Island とスマートフォンで通知します。**予約タスク → 重要なメール** でオンにするまではオフで、その **スマートフォン** スイッチで、ペアリングした iPhone や Android スマートフォンに通知を送ります。オンにする前に Enconvo が確認します。重要度を判断するために、新着メールごとの送信者、件名、冒頭が Enconvo Cloud に送られるためです。メールがそこに保存されることはありません。 |
| **別のアカウントを接続** | 別の Gmail アドレスを最大 5 つまで追加します。 |

アカウントが複数あるときは、エージェントはすべてのアカウントから読み取り、「仕事用のアドレスから送って」のように別のアカウントを指定しない限り、デフォルトのアカウントでメールを送信または作成します。デフォルトを変えるには、アカウントのメニューで **デフォルトにする** を選びます。

## チャットで Gmail を使う

Gmail を接続したら、必要なことをそのまま頼みましょう。エージェントが適切な Gmail ツールを選びます。

**検索と要約:**
```
"Find all emails from John in the last week and summarize them"
```

**返信の下書き:**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**受信トレイの整理:**
```
"Archive all newsletters from the past month"
```

**ラベルの管理:**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**古いメールの整理(ゴミ箱に移動します):**
```
"Delete all promotional emails older than 6 months"
```

## ワークフローのアイデア

Gmail は、[ワークフロー](/ja/workflows/introduction)や[予約タスク](/ja/workflows/scheduled-jobs)でも使えます。

| アイデア | 内容 |
| --- | --- |
| **毎日のメールダイジェスト** | 未読メールを検索して要約し、朝のブリーフィングとして表示します |
| **自動分類** | 新着メールを検索し、内容に基づいてラベルを付けます |
| **フォローアップのリマインダー** | 返信待ちのメールを見つけて、リマインダーを作成します |
| **レポートの作成** | 条件に合うメールを検索して、要約レポートにまとめます |

## プライバシー

- **Enconvo Cloud と Composio を経由**:メールは、あなたが頼んだことを実行するためだけに Enconvo Cloud と Composio を通り、保存されません。
- **パスワードは Google が管理**:サインインは Google 自身のページで行うため、Enconvo が Google のパスワードを見ることはありません。
- **必要時のみ**:エージェントは、タスクで必要なときだけ Gmail を読み取ります。唯一の例外が **メール通知** で、オンにすると、新着メールが届くたびに確認します。
- **取り消し可能**:Gmail のページで **接続を解除** をクリックすると、すべてのデバイスでアクセスが削除されます。[Google アカウントの権限](https://myaccount.google.com/permissions)からアクセスを削除することもできます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **接続** がグレーになっている | 先に **設定 → アカウント** で Enconvo アカウントにサインインしてください。 |
| Gmail に **再接続** と表示される | アクセスの有効期限が切れました。**再接続** をクリックして、もう一度 Google でサインインしてください。 |
| エージェントが Gmail を使わない | Gmail が接続されていることを確認してください。**すべてのチャットで利用可能** がオフの場合は、チャットで Gmail を `@` でメンションします。 |
| 検索しても何も見つからない | まず `from:john` のような単純な検索語を試し、そのメールが接続済みのアカウントにあることを確認してください。Gmail の検索は、Gmail のウェブサイトと同じように動作します。 |
| 添付ファイルが送られない | ファイルのパスが正しく、ファイルが Mac に存在することを確認してください。 |

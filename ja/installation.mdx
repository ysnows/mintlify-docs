---
title: "インストール"
description: "Mac に Enconvo をインストールし、最新の状態に保ち、インストール時の問題を解決します。"
---

Enconvo は macOS 14 以降を搭載した Apple Silicon および Intel Mac で動作します。[Local LLM (MLX)](/ja/providers/mlx) など一部のオンデバイス機能には Apple Silicon が必要であり、ローカルモデルには十分なメモリとディスク容量も必要です。

Windows 10 および 11（x64）では、Beta 版をデスクトップアプリとして利用できます。[Windows (Beta)](/ja/getting-started/windows) を参照してください。

Linux では、デスクトップおよびサーバー向けに Beta 版が動作します。[Linux (Beta)](/ja/getting-started/linux) を参照してください。

## インストール

<Steps>
  <Step title="ダウンロードする">
    [enconvo.com](https://www.enconvo.com) からお使いの Mac のプロセッサに合った DMG を入手します。
  </Step>
  <Step title="アプリケーションフォルダに移動する">
    DMG を開き、**Enconvo** を **アプリケーション** フォルダにドラッグします。
  </Step>
  <Step title="Enconvo を開く">
    **アプリケーション** 内の Enconvo を開き、案内手順に沿って進めます。その後は[クイックスタート](/ja/quickstart)へ進みます。
  </Step>
</Steps>

**アプリケーション** フォルダ内の 1 つだけを残してください。ショートカット、権限、アップデートはすべて 1 つのコピーを対象としており、別の場所に 2 つ目のコピーがあると、今使っている方ではなく別のコピーに権限が付与されてしまうことがあります。

## アップデート

メニューバーの Enconvo アイコンから **アップデートを確認** を選ぶか、**設定 → 一般 → アップデート** でクリックします。新機能をいち早く試したい場合は、**設定 → 一般** を開いて **更新チャンネル** を **Beta** または **Dev** に変更します（デフォルトは **本番環境** です）。[アップデート](/ja/configuration/updates)を参照してください。

アプリ本体と組み込みプラグインは別々にアップデートされます。機能が見当たらない、または動作が違う場合は両方の更新を確認してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| アプリが開かない | Mac が macOS 14 以降であることと、ダウンロードが完了していることを確認してください。 |
| 権限がオンなのに機能が使えない | Enconvo を終了し、**アプリケーション** フォルダから開き直してください。古いコピーが他に起動していないかも確認してください。 |
| ローカルモデルがダウンロードできない | ディスクの空き容量とネットワーク接続、およびそのモデルがお使いの Mac に対応しているかを確認してください。 |
| アプリのウィンドウが見つからない | メニューバーまたは Dock の Enconvo アイコンをクリックするか、**⌥Space** を押して SmartBar を開いてください。 |
| 破損している、または確認できないという警告が macOS に出る | [enconvo.com](https://www.enconvo.com) から新しいコピーをダウンロードしてください。macOS のセキュリティ設定はオフにしないでください。 |

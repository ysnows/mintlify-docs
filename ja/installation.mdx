---
title: "インストール"
description: "Enconvo を Mac にインストールし、最新の状態に保つ方法と、インストールの問題の解決方法を説明します。"
---

Enconvo は macOS 14 以降で動作し、Apple シリコンと Intel Mac の両方に対応しています。[ローカル LLM (MLX)](/ja/providers/mlx) など一部のオンデバイス機能には Apple シリコンが必要で、ローカルモデルには十分なメモリとディスク容量も必要です。

Windows 10 と 11 (x64) では、ベータ版がデスクトップアプリとして動作します。[Windows (ベータ版)](/ja/getting-started/windows) をご覧ください。

Linux では、ベータ版がデスクトップとサーバーで動作します。[Linux (ベータ版)](/ja/getting-started/linux) をご覧ください。

## インストール

<Steps>
  <Step title="ダウンロード">
    お使いの Mac のプロセッサに合った DMG を [enconvo.com](https://www.enconvo.com) からダウンロードします。
  </Step>
  <Step title="アプリフォルダに移動">
    DMG を開き、**Enconvo** を **アプリ** にドラッグします。
  </Step>
  <Step title="Enconvo を開く">
    **アプリ** にあるコピーを開き、ウェルカム画面の手順に従います。その後は[クイックスタート](/ja/quickstart)に進みます。
  </Step>
</Steps>

**アプリ** にあるコピーだけを残してください。ショートカット、権限、アップデートはすべて 1 つのコピーを対象にしており、ほかの場所にある 2 つ目のコピーには、普段使っているコピーにない権限が付与されることがあります。

## アップデート

Enconvo のメニューバーアイコンから **アップデートを確認** を選ぶか、**設定 → 一般 → アップデート** でクリックします。新機能をいち早く使うには、**設定 → 一般** を開き、**更新チャンネル** を **ベータ版** または **開発** に設定します。デフォルトは **本番環境** です。[アップデート](/ja/configuration/updates)をご覧ください。

アプリと内蔵プラグインは別々にアップデートされます。機能が見つからない場合や動作が違う場合は、両方を確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| アプリが開かない | Mac が macOS 14 以降であること、ダウンロードが完了していることを確認してください。 |
| 権限はオンなのに機能が使えない | Enconvo を終了し、**アプリ** から開き直してください。古いコピーが動いていないことも確認してください。 |
| ローカルモデルをダウンロードできない | ディスク容量と接続状況、そしてモデルがお使いの Mac に対応しているかを確認してください。 |
| アプリのウィンドウが見つからない | メニューバーまたは Dock の Enconvo アイコンをクリックするか、**⌥Space** で SmartBar を開いてください。 |
| macOS にダウンロードしたファイルが壊れている、または確認できないと表示される | [enconvo.com](https://www.enconvo.com) から新しいコピーをダウンロードし直してください。macOS のセキュリティ設定はオフにしないでください。 |

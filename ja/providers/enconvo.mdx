---
title: "Enconvo Cloud"
description: "プロバイダーキーなしで、Enconvo アカウントを通じてモデル、音声、メディアツールを利用します。"
---

Enconvo Cloud を利用すると、Enconvo アカウントを通じて各社のモデルに加え、音声・画像・動画・Web ツールを使うことができます。API キーの管理は不要で、リクエストにはプランのポイントが使われます。最も手軽に使い始められる方法です。

## セットアップ

<Steps>
  <Step title="サインイン">
    Enconvo アカウントにサインインします。詳しくは[アカウント](/ja/configuration/account)をご覧ください。
  </Step>
  <Step title="Enconvo Cloud を選択">
    使いたい機能の設定ページ（**AI モデル**、**テキスト読み上げ**、**画像生成**など）を開き、**Enconvo Cloud** または **Enconvo Cloud Plan** と表示されたプロバイダーを選びます。
  </Step>
  <Step title="モデルや音声を選択">
    モデルまたは音声を選び、短いリクエストを試してみてください。
  </Step>
</Steps>

プロバイダーは機能ごとに独立して設定されます。チャット用に Enconvo Cloud を選んでも、音声、画像、動画、埋め込み、リランキング、Web ツールは自動で切り替わらないため、必要な場所ごとに設定してください。

## Enconvo 独自のモデル

Enconvo Cloud には用途別に名付けられた 3 つの独自モデルがあります：

| モデル | 用途 |
| --- | --- |
| **Enconvo Fast** | 短時間のやり取り向け：短い回答、書き換え、小さな操作。**Enconvo Cloud Plan** の初期モデルであり、AI コマンドのデフォルトでもあります。 |
| **Enconvo Balanced** | いくつかのステップを伴う日常的な作業。 |
| **Enconvo Ultra** | 深い推論を必要とする難しいタスク。 |

これらは **Enconvo Cloud Plan** の先頭に並び、[Auto Route](/ja/providers/auto-route) のデフォルトルートにも使われています。

## ピッカーからモデルを探す

**Enconvo Cloud Plan** の一覧は、まず Enconvo 独自のモデル、次に Anthropic、OpenAI、Google と提供元ごとに件数付きでグループ化されています。各社とも最新 4 モデルが表示され、**Show N earlier models** をクリックすると以前のモデルも表示されます。検索すると一致するすべてのモデルが一覧に出て、現在のチャットで使っているモデルも常に表示されます。Claude のモデルは「Claude」を省き、**Sonnet 5.5** や **Opus 5.5** のように表示されます。

チャットウィンドウのモデルピッカーでは、Cloud モデルに以下のタグが付くことがあります：

| タグ | 意味 |
| --- | --- |
| **New** | 過去 14 日以内に追加されたモデル。 |
| **50% OFF** などの割引表記 | 期間限定で消費ポイントが割引されています。行にカーソルを合わせるか矢印キーで選択すると通常価格を確認できます。 |
| **Free** | ポイントを消費しないモデル。 |
| **Preview** | モデルの早期プレビュー版。 |
| 日付 | そのモデルが Enconvo Cloud から終了する日。 |

タグは Enconvo Cloud 側で設定されるため、アプリのアップデートなしに変更されます。

## ポイントと使用量

モデルによって必要なポイント数が異なります。設定画面では各モデルやプロバイダーの横に Cloud 料金が表示され、今月の残り無料分数などプランに含まれる特典も確認できます。最新のプランと料金は [Cloud プラン](https://www.enconvo.com/cloud-plan) および [Cloud 料金](https://www.enconvo.com/cloud-pricing) ページをご覧ください。使用済みのポイントを確認するには、**設定 → ポイント使用量**を開きます。

デフォルトモデルである [Auto Route](/ja/providers/auto-route) は Enconvo Cloud モデル上で動作します。メッセージごとに最適なモデルを選ぶ処理自体は無料で、実際に回答するモデルに対してポイントが消費されます。

一部の Cloud サービスは、サインイン済みのすべてのアカウントで無料です：

- **Enconvo Cloud** および **DeepSeek (Enconvo Cloud)** による Web 検索。詳しくは [Web 検索](/ja/ai/web-search)をご覧ください。
- **Enconvo Cloud Fast** による音声認識。詳しくは[音声認識](/ja/ai/speech-recognition)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| リクエストでサインインを求められる | **設定 → アカウント**でサインインしてください。 |
| ポイント不足や残高エラーで失敗する | **設定 → ポイント使用量**を確認し、[Cloud プラン](https://www.enconvo.com/cloud-plan)ページでプランを確認してください。 |
| モデルが見当たらない | ピッカーにはお使いのプランに含まれるモデルのみ表示されます。**モデル名**の横にある**更新**をクリックしてください。 |

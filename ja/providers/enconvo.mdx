title: "Enconvo Cloud"

Enconvo Cloud では、複数の企業のモデルに加え、音声、画像、動画、ウェブのツールを、Enconvo アカウントを通じて利用できます。管理する API キーはありません。リクエストにはプランのポイントが使われます。最も手軽に始められる方法です。

## セットアップ

<Steps>
  <Step title="サインインする">
    Enconvo アカウントにサインインします。[アカウント](/ja/configuration/account)を参照してください。
  </Step>
  <Step title="Enconvo Cloud を選ぶ">
    やりたいことの設定ページ（**AI モデル**、**テキスト読み上げ**、**画像生成** など）を開き、**Enconvo Cloud** または **Enconvo Cloud Plan** というラベルのプロバイダーを選びます。
  </Step>
  <Step title="モデルまたは音声を選ぶ">
    モデルまたは音声を選び、短いリクエストを実行します。
  </Step>
</Steps>

機能ごとに、プロバイダーの選択は別々です。チャットで Enconvo Cloud を選んでも、音声、画像、動画、埋め込み、リランキング、ウェブツールは切り替わりません。それぞれ、使いたい場所で設定してください。

## Enconvo 独自のモデル

Enconvo Cloud には、向いている作業にちなんで名付けられた、独自のモデルが 3 つあります。

| モデル | 用途 |
| --- | --- |
| **Enconvo Fast** | 素早いやり取り。短い回答、書き直し、小さな操作。**Enconvo Cloud Plan** の初期モデルで、AI コマンドのデフォルトでもあります。 |
| **Enconvo Balanced** | いくつかのステップがある日常的な作業。 |
| **Enconvo Ultra** | 深い推論が必要な難しいタスク。 |

これらは **Enconvo Cloud Plan** の下の先頭に表示され、[Auto Route](/ja/providers/auto-route) はデフォルトのルートでこれらを使います。

## ピッカーでモデルを探す

**Enconvo Cloud Plan** の一覧では、モデルがベンダーごとにまとめられます。最初に Enconvo 独自のモデル、続いて Anthropic、OpenAI、Google、その他が並び、それぞれに数が表示されます。ベンダーごとに最新の 4 モデルが表示され、**以前の N 個のモデルを表示** をクリックすると残りが表示されます。検索では一致するものがすべて表示され、チャットで使っているモデルは常に表示されます。Claude のモデルは、**Sonnet 5.5** や **Opus 5.5** のように、「Claude」の接頭辞なしで表示されます。

チャットウィンドウのモデルピッカーでは、Cloud のモデルにタグが付くことがあります。

| タグ | 意味 |
| --- | --- |
| **新規** | 過去 14 日以内に追加されました。 |
| **50% OFF** などの割引 | 当面、そのモデルの料金が安くなっています。行にポインターを合わせるか、矢印キーで移動すると、通常の価格が表示されます。 |
| **無料** | そのモデルはポイントを使いません。 |
| **プレビュー** | モデルの先行バージョンです。 |
| 日付 | そのモデルが Enconvo Cloud から終了する日です。 |

タグは Enconvo Cloud が設定するため、アプリのアップデートなしで変わります。

## ポイントと使用量

モデルごとに、消費するポイント数が異なります。設定には、各モデルとプロバイダーの横に Cloud の料金が表示され、今月の無料の残り時間など、プランに含まれる内容も表示されます。現在のプランと料金は、[Cloud プラン](https://www.enconvo.com/cloud-plan)と[クラウドの料金](https://www.enconvo.com/cloud-pricing)のページを参照してください。使用量を確認するには、**設定 → ポイント使用量** を開きます。

デフォルトモデルの [Auto Route](/ja/providers/auto-route) は、Enconvo Cloud のモデルで動作します。メッセージごとのルートの選択は無料で、回答するモデルがポイントを使います。

一部の Cloud サービスは、サインインしているすべてのアカウントで無料です。

- **Enconvo Cloud** と **DeepSeek (Enconvo Cloud)** によるウェブ検索。[ウェブ検索](/ja/ai/web-search)を参照してください。
- **Enconvo Cloud Fast** による音声認識。[音声認識](/ja/ai/speech-recognition)を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| リクエストでサインインを求められる | **設定 → アカウント** でサインインしてください。 |
| リクエストがポイントまたは残高のエラーで失敗する | **設定 → ポイント使用量** を確認し、次に [Cloud プラン](https://www.enconvo.com/cloud-plan)のページでプランを確認してください。 |
| モデルが見つからない | ピッカーには、プランに含まれるものが表示されます。**モデル名** の横の **更新** をクリックしてください。 |

---
title: "Ollama"
description: "この Mac や別のコンピュータ上で Ollama が提供するモデルとチャットします。"
---

Ollama を使うと、この Mac またはネットワーク上の別のコンピュータにあるご自身のハードウェアでモデルを実行できます。Enconvo は Ollama サーバーへチャットを送信するため、プロバイダーアカウントは不要です。

## この Mac で接続する

<Steps>
  <Step title="Ollama を起動する">
    [Ollama](https://ollama.ai/) をインストールして起動し、Ollama 自体のツールでモデルをダウンロードします。
  </Step>
  <Step title="Enconvo の接続先を指定する">
    **設定 → AI モデル → Ollama** を開きます。**認証**の下で、Ollama のポートを変更していない限り **BaseUrl** は `http://127.0.0.1:11434` のままにします。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル名**からモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

## 別のコンピュータに接続する

1. もう一方のコンピュータで、Ollama が自身からだけでなくネットワークからの接続を受け入れるように設定します。
2. Enconvo で **BaseUrl** を、ポートとパスを保ったままそのコンピュータのネットワークアドレスに設定します。`127.0.0.1` と `localhost` は常に Enconvo が動いている Mac を指します。
3. macOS が接続をブロックする場合は、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo をオンにします。

信頼できるネットワークにのみサーバーを公開してください。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横にある**更新**でサーバーから一覧を再読み込みします。 |
| **Response Timeout** | サーバーが応答を開始または継続するまでの待機時間です。デフォルトは**上限なし**です。ご自身のハードウェアでは、長いプロンプトの最初の単語が出るまでに数分かかることがあります。 |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 接続が拒否される | Ollama が起動していることと、**BaseUrl** のアドレスとポートが正しいことを確認してください。別のコンピュータの場合は、ネットワーク接続を受け入れているか確認してください。 |
| ネットワークに到達できない | ネットワークの状態と、システム設定の**ローカルネットワーク**権限を確認してください。 |
| モデル一覧が空になる | Ollama でモデルを読み込むかダウンロードしてから、**更新**をクリックしてください。 |
| 応答が途中でタイムアウトする | **Response Timeout** をより長い値、または**上限なし**に設定してください。 |
| ツールや画像が失敗する | ツール呼び出しや画像入力に対応したモデルを選択してください。 |
| メモリ不足になる | より小さいモデルを選ぶか、入力を短くしてください。 |

---
title: "Xiaomi MiMo"
description: "ご自身の Xiaomi MiMo API キーを使って、Enconvo で Xiaomi MiMo モデルとチャットします。"
---

Xiaomi MiMo は API キーを通じてモデルを提供しています。キーを Enconvo に追加すると、チャット、エージェント、AI コマンドでそれらのモデルを使用できます。利用料金は Xiaomi MiMo からご自身のアカウントに請求されます。

## 接続方法

<Steps>
  <Step title="API キーを取得">
    [Xiaomi MiMo プラットフォーム](https://platform.xiaomimimo.com/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → Xiaomi MiMo** を開きます。**認証** の下でキーを **API キー** に貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

仕事用など 2 つ目の Xiaomi MiMo キーを保存したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横の **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加・復元できます。 |

1 つのチャットだけで別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キー全体を貼り付け直し、Xiaomi MiMo アカウントで有効になっているか確認してください。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックして一覧を再読み込みします。自分でモデルを追加するには、**モデルを管理** を使用してください。 |
| 画像やツールが失敗する | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限や利用上限エラー | Xiaomi MiMo アカウントで使用量と上限を確認するか、いったん別のプロバイダーに切り替えてください。 |
| 返信が遅い | より小さなモデル、より短い入力、または低い推論の強さを試してください。 |

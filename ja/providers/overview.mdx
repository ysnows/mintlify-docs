プロバイダーとは、Enconvo の機能の裏側にあるサービスのことです。チャットに回答するモデル、読み上げる音声、ウェブを検索するエンジンなどがこれにあたります。機能ごとに 1 つずつ選べ、組み合わせて使うこともできます。

下の動画では、**設定 → AI モデル** を 2 分で紹介します。Auto Route、Cloud プラン、ChatGPT、Claude、GitHub Copilot、Antigravity、Grok のプランでのサインイン、API キー、Mac 上のモデル、Ollama と LM Studio、自分のプロバイダーの追加まで説明しています。

## 接続方法を選ぶ

| やりたいこと | 使うもの | 最初に見るページ |
| --- | --- | --- |
| キーなしですぐに始める | Enconvo アカウント経由の Enconvo Cloud | [Enconvo Cloud](/ja/providers/enconvo) |
| メッセージごとに Enconvo にモデルを選ばせる | デフォルトモデルの Auto Route | [Auto Route](/ja/providers/auto-route) |
| 契約中のプランを使う | ChatGPT、Claude、Grok、Mistral、GitHub Copilot、Antigravity でサインイン | [プランでサインインする](#プランでサインインする) |
| プロバイダーに直接支払う | 自分の API キー | [人気のプロバイダー](#人気のプロバイダー) |
| 1 つのキーで多くの企業のモデルを使う | OpenRouter や PipeLLM などのゲートウェイ | [OpenRouter](/ja/providers/openrouter)、[PipeLLM](/ja/providers/pipellm) |
| チャットを Mac 内にとどめる | ローカルモデル | [ローカルモデル](/ja/ai/local-llm) |
| Ollama や LM Studio で動かしているモデルを使う | **Ollama** または **LM Studio** プロバイダー | [Ollama](/ja/providers/ollama)、[LM Studio](/ja/providers/lm-studio) |
| iPhone アプリ独自のチャットでモデルを使う | 電話チャット | [電話チャット](/ja/integrations/iphone-phone-chats) |

## チャットモデルを選ぶ

<Steps>
  <Step title="AI モデルを開く">
    **設定 → AI モデル** を開きます。中央の列にすべてのプロバイダーが並びます。上に **Auto Route** と **Enconvo Cloud プラン**、その下に各社、ローカルモデル、その他すべてのプロバイダーです。
  </Step>
  <Step title="プロバイダーを選んで接続する">
    プロバイダーをクリックします。両方に対応している場合は、自分のキーでリクエストごとにプロバイダーへ支払う **API キー** か、サインインしてプランに含まれる分を使うサブスクリプションの選択肢(たとえば **ChatGPT Subscription**)を選びます。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル名** でモデルを選びます。プロバイダーに **推論の強さ** がある場合は、それも選びます。
  </Step>
  <Step title="デフォルトにする">
    **デフォルトに設定** をクリックします。独自のモデルを指定していないチャットや機能は、以後このモデルを使います。
  </Step>
</Steps>

一覧にないサービスを追加するには、リスト下部の **新しいプロバイダーを追加** をクリックし、**OpenAI 互換** または **Anthropic 互換** を選びます。

プロバイダーはいつでも切り替えられます。チャットが特定の 1 社に縛られることはありません。

**設定 → AI モデル** の上部には、チャットのタイトルや提案の裏で動く小さなモデル用の **タスクモデル** と、チャットのモデルが使えないときに引き継ぐ予備モデル用の **フォールバック** もあります。[モデルを選ぶ](/ja/ai/model-selection-guide)をご覧ください。

## 機能ごとにプロバイダーを設定する

各機能には、それぞれの設定ページがあります。**AI モデル**、**テキスト読み上げ**、**ウェブ検索**、**画像生成**、**動画生成**、**Web ページを取得**、**OCR** です。音声認識には、**音声入力モデル**、**録音モデル**、**文字起こしモデル**、**字幕生成モデル** の個別のページがあります。埋め込みとリランキングは、ナレッジベースで設定します。

チャットモデルを選んでも、音声、画像、検索のプロバイダーは変わりません。それぞれ、使いたい場所で設定してください。

## プロファイル

プロバイダーのプロファイルには、キーまたはサインインが 1 つ入ります。たとえば仕事用アカウントのように 2 つ目を保存するには、プロバイダーのページで **新しいプロバイダーを追加** をクリックします。1 つのプロファイルが複数の機能を担う場合もあります。たとえば 1 つの OpenAI プロファイルでチャット、埋め込み、テキスト読み上げ、画像、文字起こしをまかなうため、キーを変えるとそのすべてが変わります。[認証情報とプロファイル](/ja/configuration/credentials)をご覧ください。

デフォルトモデルの設定場所と、各チャットが独自のモデルを保持する仕組みは、[モデルを選ぶ](/ja/ai/model-selection-guide)で説明しています。

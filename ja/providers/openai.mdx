OpenAI の GPT モデルを、チャット、エージェント、AI コマンドで使えます。リクエストごとに OpenAI が課金する OpenAI API キーで接続するか、ChatGPT プランでログインしてその利用枠を使います。

## 接続

<Steps>
  <Step title="API キーを取得">
    [OpenAI プラットフォーム](https://platform.openai.com/api-keys)でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → OpenAI** を開きます。**認証** で **API キー** を選び、キーを貼り付けて **検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

<Tip>
ChatGPT プランをお持ちですか？ 代わりに **認証** で **ChatGPT Subscription** を選び、**接続** をクリックします。[ChatGPT Subscription](/ja/providers/openai_subscription) をご覧ください。
</Tip>

仕事用など、2 つ目の OpenAI キーを使うには、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成します。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **API Type** | 認証情報の項目です。**Responses API**（デフォルト）または **Completions API** を選びます。互換サービスが Completions を必要とする場合を除き、Responses のままにしてください。 |
| **API ベース URL** | 認証情報の項目です。デフォルトは `https://api.openai.com/v1` です。OpenAI 互換のサービスを使う場合にのみ変更します。 |

同じ OpenAI プロファイルは、OpenAI の埋め込み、テキスト読み上げ、画像生成、文字起こしにも使われるため、キーを変更するとそれらの機能にも影響します。1 つのチャットだけ別のモデルを使うには、そのチャットのモデルピッカーから選びます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キー全体をもう一度貼り付け、キーが有効で、OpenAI プラットフォームで支払い設定が済んでいるか確認します。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックします。自分でモデルを追加するには **モデルを管理** を使います。 |
| 互換サービスが動かない | **API ベース URL** を確認し、**API Type** を **Completions API** に変えて試します。 |
| レートまたは使用量の制限エラー | OpenAI プラットフォームで使用量と制限を確認するか、しばらく別のプロバイダーに切り替えます。 |

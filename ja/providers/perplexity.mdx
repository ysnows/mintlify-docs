---
title: "Perplexity"
description: "ご自身の Perplexity API キーを使って、Enconvo で Perplexity モデルとチャットします。"
---

Perplexity の Sonar モデルは Web を検索しながら回答を生成します。キーを Enconvo に追加すると、チャット、エージェント、AI コマンドでそれらのモデルを使用できます。利用料金は Perplexity からご自身のアカウントに請求されます。

## 接続方法

<Steps>
  <Step title="API キーを取得">
    [Perplexity API 設定](https://www.perplexity.ai/settings/api) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → Perplexity** を開きます。**認証** の下でキーを **API キー** に貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

仕事用など 2 つ目の Perplexity キーを保存したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横の **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加・復元できます。 |
| **frequencyPenalty** | 同じ単語が繰り返される確率を下げます。デフォルトは 1 です。 |

1 つのチャットだけで別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

このチャットプロバイダーは **設定 → Web 検索** とは別個の設定です。ここで Perplexity を選んでも、エージェントが使用する検索プロバイダーは変更されません。時事問題に関する回答では、引用されたソースも開いて確認してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キー全体を貼り付け直し、Perplexity アカウントで有効になっているか確認してください。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックして一覧を再読み込みします。自分でモデルを追加するには、**モデルを管理** を使用してください。 |
| 画像やツールが失敗する | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限や利用上限エラー | Perplexity アカウントで使用量と上限を確認するか、いったん別のプロバイダーに切り替えてください。 |
| 返信が遅い | より小さなモデル、より短い入力、または低い推論の強さを試してください。 |

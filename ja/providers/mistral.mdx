---
title: "Mistral AI"
description: "Mistral の API キーまたは Mistral アカウントを使って、Enconvo で Mistral モデルとチャットします。"
---

チャット、エージェント、AI コマンドで Mistral のモデルを使用できます。Mistral の API キーを貼り付けるか、Mistral アカウントでログインして Enconvo にキーを自動作成させることができます。どちらの方法でも、利用料金は Mistral からご自身のアカウントに請求されます。

## 接続方法

<Tabs>
  <Tab title="Mistral でログイン">
    <Steps>
      <Step title="プロバイダーを開く">
        **設定 → AI モデル → Mistral AI** を開きます。
      </Step>
      <Step title="ログイン">
        **認証** の下で Mistral アカウントでのログインを選択し、**接続** をクリックします。Mistral アカウントでログインしてワークスペースを選択します。このログインは Mistral Vibe と同じ仕組みで動作し、そのワークスペース用の API キーを自動作成するため、コピー作業は不要です。
      </Step>
      <Step title="モデルを選択">
        **モデル名** でモデルを選び、短いメッセージを送信します。
      </Step>
    </Steps>
  </Tab>
  <Tab title="API キーを使用">
    <Steps>
      <Step title="API キーを取得">
        [Mistral コンソール](https://console.mistral.ai/api-keys/) でキーを作成します。
      </Step>
      <Step title="Enconvo に追加">
        **設定 → AI モデル → Mistral AI** を開きます。**認証** の下でキーを **API キー** に貼り付け、**検証** をクリックします。
      </Step>
      <Step title="モデルを選択">
        **モデル名** でモデルを選び、短いメッセージを送信します。
      </Step>
    </Steps>
  </Tab>
</Tabs>

ログインが完了すると、アカウントカードにプラン、キー、および分あたりの制限残量が表示されます。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横の **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加・復元できます。 |
| **推論の強さ**（チャット内） | Mistral Large 4、Medium 3.5、Small 4 向け：**なし** は思考せずすぐ回答し、**高** は先に思考します。Large 4 はデフォルトで思考します。 |

Voxtral の文字起こしと Mistral OCR でも同じログインまたはキーを使用できます。

## iPhone での設定

iPhone アプリの電話チャットでも Le Chat プランを利用できます。iPhone で **設定 → AI モデル → Mistral** を開き、**認証** の下で Le Chat カードを選択して **Mistral でログイン** をタップします。[電話チャット](/ja/integrations/iphone-phone-chats)を参照してください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キー全体を貼り付け直し、Mistral コンソールで有効になっているか確認してください。 |
| ログインが機能しなくなる | アカウントカードのメニューを開き、**再接続** をクリックします。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックします。自分でモデルを追加するには、**モデルを管理** を使用してください。 |
| レート制限エラー | ワークスペースの 1 分あたりの上限に達しています。1 分待つか、Mistral コンソールで上限を確認してください。 |

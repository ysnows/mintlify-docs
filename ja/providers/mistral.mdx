---
title: "Mistral AI"
description: "Mistral API キーまたは Mistral アカウントを使って、Enconvo で Mistral モデルとチャットします。"
---

Mistral のモデルを、チャット、エージェント、AI コマンドで使えます。Mistral API キーを貼り付けるか、Mistral アカウントでログインして Enconvo にキーを作成させます。どちらの場合も、利用料金は Mistral からご自身のアカウントに請求されます。

## 接続

<Tabs>
  <Tab title="Mistral でログイン">
    <Steps>
      <Step title="プロバイダーを開く">
        **設定 → AI モデル → Mistral AI** を開きます。
      </Step>
      <Step title="ログイン">
        **認証** で Mistral アカウントのログインを選び、**接続** をクリックします。Mistral アカウントでログインし、ワークスペースを選びます。このログインは Mistral Vibe のログインと同じ仕組みで、そのワークスペース用の API キーが作成されるため、コピーするものはありません。
      </Step>
      <Step title="モデルを選択">
        **モデル名** でモデルを選び、短いメッセージを送信します。
      </Step>
    </Steps>
  </Tab>
  <Tab title="API キーを使う">
    <Steps>
      <Step title="API キーを取得">
        [Mistral コンソール](https://console.mistral.ai/api-keys/)でキーを作成します。
      </Step>
      <Step title="Enconvo に追加">
        **設定 → AI モデル → Mistral AI** を開きます。**認証** で、キーを **API キー** に貼り付け、**検証** をクリックします。
      </Step>
      <Step title="モデルを選択">
        **モデル名** でモデルを選び、短いメッセージを送信します。
      </Step>
    </Steps>
  </Tab>
</Tabs>

ログインすると、アカウントカードにプラン、キー、1 分あたりの制限の残りが表示されます。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **推論の強さ**（チャット内） | Mistral Large 4、Medium 3.5、Small 4 向けです。**なし** は考えずに回答し、**高** は先に考えます。Large 4 はデフォルトで考えます。 |

Voxtral の文字起こしと Mistral OCR も、同じログインまたはキーを使えます。

## iPhone では

iPhone アプリでも、iPhoneのチャットで Le Chat プランを使えます。iPhone で **設定 → AI モデル → Mistral** を開き、**認証** の Le Chat カードを選んで、**Mistral でログイン** をタップします。[iPhoneのチャット](/ja/integrations/iphone-phone-chats)をご覧ください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キー全体をもう一度貼り付け、Mistral コンソールでキーが有効か確認します。 |
| ログインが動かなくなった | アカウントカードのメニューを開き、**再接続** をクリックします。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックします。自分でモデルを追加するには **モデルを管理** を使います。 |
| レート制限エラー | ワークスペースの 1 分あたりの上限に達しています。1 分待つか、Mistral コンソールで制限を確認します。 |

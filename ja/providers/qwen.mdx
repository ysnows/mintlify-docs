title: "Qwen"
description: "Alibaba Cloud Model Studio の API キーを使って、Enconvo で Qwen モデルとチャットします。"
---

チャット、エージェント、AI コマンドで Alibaba の Qwen モデルを使用できます。Alibaba Cloud Model Studio の API キーで接続し、利用料金は Alibaba Cloud からご自身のアカウントに請求されます。中国本土のサービス（百煉 / Bailian）を利用する場合は、[DashScope](/ja/providers/dashscope) を使用してください。

## 接続方法

<Steps>
  <Step title="API キーを取得">
    [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → Qwen** を開きます。**認証** の下でキーを **API キー** に貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

Qwen は API キーのみで接続します。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横の **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加・復元できます。 |
| **Base Url** | 認証情報内にあります。デフォルトは国際版エンドポイントの `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` です。キーが別リージョンのものである場合は変更してください。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キーと **Base Url** が同じリージョンに属しているか確認し、キー全体を貼り付け直してください。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックしてください。自分でモデルを追加するには、**モデルを管理** を使用してください。 |
| レート制限や利用上限エラー | Model Studio で使用量とクォータを確認するか、いったん別のプロバイダーに切り替えてください。 |

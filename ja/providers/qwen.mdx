---
title: "Qwen"
description: "Alibaba Cloud Model Studio の API キーを使って、Enconvo で Qwen モデルとチャットします。"
---

Alibaba の Qwen モデルを、チャット、エージェント、AI コマンドで使えます。Alibaba Cloud Model Studio の API キーで接続します。利用料金は Alibaba Cloud からご自身のアカウントに請求されます。中国本土向けのサービス（百煉、Bailian）には [DashScope](/ja/providers/dashscope) を使ってください。

## 接続

<Steps>
  <Step title="API キーを取得">
    [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → Qwen** を開きます。**認証** で、キーを **API キー** に貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

Qwen は API キーでのみ接続できます。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **ベース URL** | 認証情報の項目です。デフォルトは国際向けのエンドポイント `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` です。キーが別のリージョンのものである場合は変更します。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キーと **ベース URL** が同じリージョンのものか確認してから、キー全体をもう一度貼り付けます。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックします。自分でモデルを追加するには **モデルを管理** を使います。 |
| レートまたは使用量の制限エラー | Model Studio で使用量とクォータを確認するか、しばらく別のプロバイダーに切り替えます。 |

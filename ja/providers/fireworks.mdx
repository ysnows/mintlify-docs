---
title: "Fireworks"
description: "自身の Fireworks API キーを使って、Enconvo で Fireworks モデルとチャットします。"
---

Fireworks は1つの API キーで多くのオープンモデルをホストしています。Enconvo にキーを追加すると、チャット、エージェント、AI コマンドでそれらのモデルを使えます。利用料金は自身のアカウントに請求されます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [Fireworks アカウント](https://fireworks.ai/account/api-keys) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → Fireworks** を開きます。**認証** の **API キー** にキーを貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル名** でモデルを選択し、短いメッセージを送信します。返信が返ってくれば接続は完了です。
  </Step>
</Steps>

仕事用など2つ目の Fireworks キーを登録したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーで使用するモデルです。横にある **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加または復元します。 |

特定のチャットだけで別のモデルを使いたい場合は、そのチャットのモデル選択メニューから選んでください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キー全体を貼り付け直し、Fireworks アカウントでそのキーが有効になっているか確認してください。 |
| モデルが表示されない | **モデル名** の横にある **更新** をクリックして一覧を再読み込みしてください。自分でモデルを追加するには **モデルを管理** を使用します。 |
| 画像やツールが失敗する | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限または利用制限のエラーが出る | Fireworks アカウントで使用量と上限を確認するか、いったん別のプロバイダーに切り替えてください。 |
| 返信が遅い | より小さなモデル、短い入力、または低い推論レベルを試してください。 |

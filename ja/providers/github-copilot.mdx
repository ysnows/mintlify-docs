---
title: "GitHub Copilot"
description: "Copilot のプランがある GitHub アカウントでサインインし、そのプランのモデルとチャットします。"
---

GitHub Copilot のプランを、Enconvo の AI モデルのプロバイダーとして使います。プランのある GitHub アカウントでサインインするだけで、API キーは不要です。プレミアムモデルは、プランのプレミアムリクエストとして数えられます。

## 接続する

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル → GitHub Copilot** を開きます。
  </Step>
  <Step title="サインインを開始する">
    **認証** で **接続** をクリックします。
  </Step>
  <Step title="GitHub でコードを入力する">
    ブラウザで GitHub のデバイスページが開き、Enconvo にそこで入力するコードが表示されます。コードを入力して、サインインを承認します。
  </Step>
  <Step title="アカウントを確認する">
    Enconvo に戻り、意図した GitHub アカウントが接続されていることを確認します。
  </Step>
  <Step title="モデルを選ぶ">
    モデルを選んで、短いリクエストを試します。
  </Step>
</Steps>

承認する前に Enconvo のコードのダイアログを閉じると、サインインはキャンセルされます。

## モデルとオプション

モデルの一覧には、Copilot のプランで使えるモデルだけが、Copilot 自身のチャットのデフォルトを先頭にして表示されます。Copilot Free では、有料プランより使えるモデルが少ないため、他の場所で見たモデルが表示されないことがあります。各モデルには、Copilot がそのモデル向けに提供する推論レベルが使われます。

## iPhone で使う

iPhone アプリも、スマートフォンでの電話チャット用に GitHub Copilot にサインインできます。[電話チャット](/ja/integrations/iphone-phone-chats)を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| サインインが完了しない | コードの有効期限が切れる前に GitHub のページで入力し、新しいコードを取得するには、もう一度 **接続** をクリックしてください。 |
| 使いたいモデルが一覧にない | Copilot のプランにそのモデルは含まれていません。別のモデルを選ぶか、プランをアップグレードしてください。 |
| リクエストがモデルのエラーで失敗する | 現在の一覧からモデルを選んでください。プランが変わる前に選んだデフォルトは、もう提供されていない場合があります。 |
| レート制限または使用上限 | プランのプレミアムリクエストと、GitHub のレート制限です。 |

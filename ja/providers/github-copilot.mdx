---
title: "GitHub Copilot"
description: "Copilot プランに加入している GitHub アカウントでサインインし、プラン内のモデルとチャットできます。"
---

GitHub Copilot プランを Enconvo の AI モデルプロバイダーとして利用できます。プランを含む GitHub アカウントでサインインするだけで、API キーは不要です。プレミアムモデルはプランのプレミアムリクエスト枠を消費します。

## 接続する

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル → GitHub Copilot** を開きます。
  </Step>
  <Step title="サインインを開始する">
    **認証** で **接続** をクリックします。
  </Step>
  <Step title="GitHub でコードを入力する">
    ブラウザで GitHub のデバイス認証ページが開き、Enconvo に入力用のコードが表示されます。そのコードを入力してサインインを承認してください。
  </Step>
  <Step title="アカウントを確認する">
    Enconvo に戻り、意図した GitHub アカウントが接続されていることを確認します。
  </Step>
  <Step title="モデルを選択する">
    モデルを選び、短いリクエストを送って動作を確認します。
  </Step>
</Steps>

承認する前に Enconvo のコードダイアログを閉じると、サインインはキャンセルされます。

## モデルとオプション

モデル一覧には、お使いの Copilot プランで利用できるモデルのみが表示され、Copilot 標準のチャット用デフォルトモデルが先頭に並びます。Copilot Free は有料プランより利用できるモデルが少ないため、ほかで見かけたモデルが一覧に表示されない場合があります。各モデルは Copilot が提供する推論の強さレベルを使用します。

## iPhone での利用

iPhone アプリでも GitHub Copilot にサインインして、iPhone 上のチャットで利用できます。詳しくは [Phone チャット](/ja/integrations/iphone-phone-chats) をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| サインインが完了しない | 有効期限が切れる前に GitHub のページでコードを入力し、期限が切れた場合は再度 **接続** をクリックして新しいコードを取得してください。 |
| 使いたいモデルが一覧にない | お使いの Copilot プランに含まれていません。別のモデルを選ぶか、プランをアップグレードしてください。 |
| モデルエラーでリクエストが失敗する | 現在のモデル一覧から選び直してください。プラン変更前に設定したデフォルトモデルが提供終了している可能性があります。 |
| レート制限または利用上限 | お使いのプランのプレミアムリクエスト枠および GitHub のレート制限を確認してください。 |

---
title: "Local LLM (MLX)"
description: "Enconvo 内蔵の MLX エンジンで、Mac 上で言語モデルを実行します。"
---

Local LLM は、アカウントも API キーも不要で、Mac の Apple Silicon 上で言語モデルを実行します。モデルをダウンロードしたあとは、そのモデルとのチャットは Mac の中にとどまります。macOS 15 以降が必要です。

## セットアップ

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル → Local LLM (MLX)** を開きます。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル** のリストを開きます。Enconvo はお使いの Mac に合ったモデルを提案し、Hugging Face で他のモデルを検索することもできます。リストは大きいモデルから順に表示されます。
  </Step>
  <Step title="ダウンロードする">
    ダウンロードを開始し、完了するまで待ちます。Enconvo は最初にディスクの空き容量を確認します。ダウンロードは、再起動やネットワークの切断のあとも再開されます。
  </Step>
  <Step title="テストする">
    短いメッセージを送信します。モデルがメモリに読み込まれる間、最初の返信には時間がかかります。
  </Step>
</Steps>

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル** | このプロバイダーが実行するローカルモデルです。 |
| **思考** | 思考モードを持つモデル向けです。**オフ**（デフォルト）はすぐに回答し、**オン** は先に推論します。**低**、**中**、**高** は gpt-oss モデルが推論する長さを設定します。他のモデルでは **オン** として扱われます。 |

ローカルモデルが使っているメモリとディスクの量を確認したり、モデルを削除したりするには、**設定 → ローカルモデル** を開きます。モデルは、機能が必要としたときに再び読み込まれます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ダウンロードが始まらない | ディスクの空き容量を確保します。Enconvo はダウンロードの前に空き容量を確認します。 |
| モデルに **不完全** と表示される | ダウンロードが途中で中断され、ファイルの一部が欠けています。もう一度ダウンロードして完了させるか、削除します。 |
| モデルの読み込みに失敗する、または Mac が重くなる | より小さいモデルを選ぶか、他の重いアプリを閉じます。**設定 → ローカルモデル** でメモリ使用量を確認できます。 |
| 返信が遅い | より小さいモデルを選ぶか、**思考** をオフにします。 |
| ツールや画像が動かない | ツール呼び出しまたは画像入力に対応したモデルを選びます。 |

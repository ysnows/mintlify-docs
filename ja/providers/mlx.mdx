---
title: "Local LLM (MLX)"
description: "Enconvo 組み込みの MLX エンジンを使って、Mac 上で言語モデルを実行します。"
---

Local LLM は、アカウントや API キーを使わずに Mac の Apple Silicon 上で言語モデルを実行します。モデルをダウンロードした後は、チャットの内容が Mac の外に出ることはありません。macOS 15 以降が必要です。

## セットアップ

<Steps>
  <Step title="プロバイダーを開く">
    **設定 → AI モデル → Local LLM (MLX)** を開きます。
  </Step>
  <Step title="モデルを選択">
    **Model** 一覧を開きます。Enconvo がお使いの Mac に適したモデルを提案するほか、Hugging Face から他のモデルを検索することもできます。一覧にはサイズの大きいモデルから順に表示されます。
  </Step>
  <Step title="ダウンロード">
    ダウンロードを開始して完了するまで待ちます。Enconvo は先にディスクの空き容量を確認し、再起動やネットワーク切断の後でもダウンロードを再開できます。
  </Step>
  <Step title="テスト">
    短いメッセージを送信します。最初の返信は、モデルをメモリに読み込むため少し時間がかかります。
  </Step>
</Steps>

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **Model** | このプロバイダーが実行するローカルモデルです。 |
| **思考** | 思考モードを備えたモデル向けの設定です。**オフ**（デフォルト）はすぐに回答し、**オン** は先に推論します。**低**、**中**、**高** は gpt-oss モデルが推論にかける長さを設定します。他のモデルでは **オン** として扱われます。 |

ローカルモデルがメモリやディスクをどれくらい使用しているか確認したり、モデルを削除したりするには、**設定 → ローカルモデル** を開きます。モデルは機能が必要になったときに再び読み込まれます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ダウンロードが開始されない | ディスクの空き容量を確保してください。Enconvo はダウンロード前に容量を確認します。 |
| モデルに **不完全** と表示される | ダウンロードが途中で中断されたため、一部のファイルが不足しています。再度ダウンロードして完了させるか、削除してください。 |
| モデルの読み込みに失敗する、または Mac が重くなる | より小さなモデルを選ぶか、他の重いアプリを終了してください。**設定 → ローカルモデル** でメモリ使用量を確認できます。 |
| 返信が遅い | より小さなモデルを選ぶか、**思考** をオフにしてください。 |
| ツールや画像が失敗する | ツール呼び出しまたは画像入力に対応したモデルを選択してください。 |

---
title: "Cohere"
description: "ご自身の Cohere API キーを使って、Enconvo で Cohere モデルとチャットします。"
---

Cohere は API キー経由でモデルを提供しています。チャット、エージェント、AI コマンドでそれらのモデルを使えるよう、Enconvo にキーを追加します。利用料金は Cohere からご自身のアカウントへ請求されます。設定画面では **Cohere AI** として表示されます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [Cohere ダッシュボード](https://dashboard.cohere.com/)でキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → Cohere AI** を開きます。**認証** の **API キー** 欄にキーを貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選ぶ">
    **Model Name** からモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

仕事用など 2 つ目の Cohere キーを保持したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 働き |
| --- | --- |
| **Model Name** | このプロバイダーで使用するモデルです。横の **更新** で一覧を再読み込みします。 |

特定のチャットだけ別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| **検証**に失敗する | キー全体を貼り直し、Cohere アカウントでそのキーが有効になっているか確認してください。 |
| モデルが見当たらない | **Model Name** の横にある**更新**をクリックして一覧を再読み込みしてください。 |
| 画像やツールが機能しない | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限や利用上限のエラーが出る | Cohere アカウントで利用状況と上限を確認するか、一時的に別のプロバイダーへ切り替えてください。 |
| 返信が遅い | より小さなモデル、短い入力、または低い推論の強さを試してください。 |

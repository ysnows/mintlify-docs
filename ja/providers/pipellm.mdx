PipeLLM はゲートウェイサービスです。1つの PipeLLM API キーで、Claude、GPT、Gemini、Grok、Qwen、Kimi、GLM をはじめとする多数の企業のモデルにアクセスできます。複数のベンダーの請求を1つにまとめたい場合に便利です。利用料金は自身の PipeLLM アカウントに請求されます。

同じキーは画像生成、動画生成、ウェブ検索にも使えます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [PipeLLM](https://pipellm.ai) アカウントでキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → PipeLLM** を開きます。**認証** の **API キー** にキーを貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル名** でモデルを選択し、短いメッセージを送信します。返信が返ってくれば接続は完了です。
  </Step>
</Steps>

2つ目の PipeLLM キーを登録したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーで使用するモデルです。横にある **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加または復元します。 |

PipeLLM のキーは次の機能でも使用できます。各ページでプロバイダーとして **PipeLLM** を選択してください。

| 機能 | 設定場所 | 利用できる機能 |
| --- | --- | --- |
| 画像生成 | **設定 → 画像生成** | GPT Image、Nano Banana、Seedream などのモデルを使った画像生成および編集。 |
| 動画生成 | **設定 → 動画生成** | Seedance、Veo、Kling、Sora などの動画モデル。 |
| ウェブ検索 | **設定 → ウェブ検索** | スニペット付きの Google 検索結果。PipeLLM は結果を返した検索ごとに課金します。 |

同じ認証情報を共有しているため、1か所でキーを変更すると、これらすべての機能に反映されます。iPhone および Android アプリの AI モデル設定でも PipeLLM を利用できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** に失敗する | キー全体を貼り付け直し、PipeLLM アカウントでそのキーが有効になっているか確認してください。 |
| モデルが表示されない | **モデル名** の横にある **更新** をクリックしてください。自分でモデルを追加するには **モデルを管理** を使用します。 |
| 画像やツールが失敗する | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限、残高、利用制限のエラーが出る | PipeLLM アカウントの残高と上限を確認するか、いったん別のプロバイダーに切り替えてください。 |

---
title: "OpenRouter"
description: "ご自身の OpenRouter API キーを使って、Enconvo で OpenRouter のモデルとチャットします。"
---

OpenRouter は、1 つの API キーでさまざまな企業のモデルにルーティングできるサービスです。Enconvo にキーを追加すると、チャット、エージェント、AI コマンドでそれらのモデルを利用できます。利用料金はご自身の OpenRouter アカウントに請求されます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [OpenRouter](https://openrouter.ai/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → OpenRouter** を開きます。**認証**の下で **API キー**にキーを貼り付け、**検証**をクリックします。
  </Step>
  <Step title="モデルを選ぶ">
    **モデル名**からモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

仕事用など 2 つ目の OpenRouter キーを保存しておきたい場合は、**新しいプロバイダーを追加**をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使用するモデルです。横にある**更新**で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルの追加や復元を行えます。 |
| **Google Search Tool** | Gemini モデルが Google 検索の結果をもとに回答できるようにします。デフォルトではオフです。 |
| **URL Context Tool** | Gemini モデルがメッセージ内のリンク先ページを読み取れるようにします。デフォルトではオフです。 |

1 つのチャットだけ別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

画像生成と動画生成には、**設定 → 画像生成** と **設定 → 動画生成** にそれぞれ専用の OpenRouter プロバイダーがあります。ツール呼び出しや画像入力に対応しているかは、選択したモデルによって異なります。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| **検証**に失敗する | キー全体をコピーし直し、OpenRouter アカウントで有効になっているか確認してください。 |
| モデルが見当たらない | **モデル名**の横にある**更新**をクリックして一覧を再読み込みしてください。自分でモデルを追加するには**モデルを管理**を使います。 |
| 画像やツールが失敗する | 画像入力またはツール呼び出しに対応したモデルを選択してください。 |
| レート制限や利用上限エラーが出る | OpenRouter アカウントの使用量と上限を確認するか、一時的に別のプロバイダーへ切り替えてください。 |
| 返信が遅い | より小さいモデルを試すか、入力を短くするか、推論レベルを下げてください。 |

---
title: "OpenRouter"
description: "ご自身の OpenRouter API キーを使って、Enconvo で OpenRouter のモデルとチャットします。"
---

OpenRouter は、1 つの API キーで多くの企業のモデルにつなぎます。キーを Enconvo に追加すると、チャット、エージェント、AI コマンドでそれらのモデルを使えます。利用料金は OpenRouter からご自身のアカウントに請求されます。

## 接続

<Steps>
  <Step title="API キーを取得">
    [OpenRouter](https://openrouter.ai/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → OpenRouter** を開きます。**認証** で、キーを **API キー** に貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

仕事用など、2 つ目の OpenRouter キーを使うには、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成します。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **Google Search Tool** | Gemini モデルが Google 検索に基づいて回答できるようにします。デフォルトではオフです。 |
| **URL Context Tool** | メッセージ内のリンク先のページを Gemini モデルが読めるようにします。デフォルトではオフです。 |

1 つのチャットだけ別のモデルを使うには、そのチャットのモデルピッカーから選びます。

画像生成と動画生成には、**設定 → 画像生成** と **設定 → 動画生成** に専用の OpenRouter プロバイダーがあります。ツール呼び出しと画像入力は、選んだモデルによって異なります。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キー全体をもう一度貼り付け、OpenRouter アカウントでキーが有効か確認します。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックしてリストを再読み込みします。自分でモデルを追加するには **モデルを管理** を使います。 |
| 画像やツールが動かない | 画像入力またはツール呼び出しに対応したモデルを選びます。 |
| レートまたは使用量の制限エラー | OpenRouter アカウントで使用量と制限を確認するか、しばらく別のプロバイダーに切り替えます。 |
| 返信が遅い | より小さいモデル、短い入力、または低めの推論の強さを試します。 |

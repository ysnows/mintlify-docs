---
title: "xAI (Grok)"
description: "xAI API キーまたは Grok プランを使って Enconvo で Grok モデルとチャットできます。"
---

チャット、Agent、AI コマンドで xAI の Grok モデルを利用できます。リクエスト単位で課金される xAI API キーで接続するか、Grok プランでサインインできます。設定画面では **X.AI-GROK** として表示されます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    xAI コンソールでキーを作成します。手順は [xAI クイックスタート](https://docs.x.ai/docs/quickstart#creating-an-api-key)をご覧ください。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → X.AI-GROK** を開きます。**認証** で **API キー** を選び、キーを貼り付けて **検証** をクリックします。
  </Step>
  <Step title="モデルを選択する">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返ってくれば接続は完了です。
  </Step>
</Steps>

<Tip>
Grok プランをお持ちの場合は、代わりに **認証** で **Grok サブスクリプション** を選択し、**接続** をクリックしてください。
</Tip>

2 つ目の xAI キーを保持したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーで使用するモデルです。横にある **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルの追加や復元を行えます。 |
| **API ベース URL** | 認証情報内にあります。デフォルトは `https://api.x.ai/v1` です。 |

xAI には、テキスト読み上げ、画像生成、文字起こし、動画生成、X Search 用の専用プロバイダーもあります。これらはこのプロファイルのキーまたは Grok サインインを共有します。それぞれの設定ページから選択してください。

## iPhone での利用

iPhone アプリの Phone チャットでも Grok プランを利用できます。iPhone で **設定 → AI モデル → xAI** を開き、**認証** の Grok カードを選んで **Grok でログイン** をタップしてください。詳しくは [Phone チャット](/ja/integrations/iphone-phone-chats) をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** が失敗する | キー全体をもう一度貼り付け、xAI コンソールでキーが有効になっているか確認してください。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックしてください。手動でモデルを追加するには **モデルを管理** を使用してください。 |
| Grok サインインが機能しなくなる | アカウントカードのメニューを開き、**再接続** をクリックしてください。 |
| レート制限や利用上限エラー | xAI アカウントで使用量を確認するか、一時的に別のプロバイダーへ切り替えてください。 |

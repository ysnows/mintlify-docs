---
title: "xAI (Grok)"
description: "xAI API キーまたは Grok プランを使って、Enconvo で Grok モデルとチャットします。"
---

xAI の Grok モデルを、チャット、エージェント、AI コマンドで使えます。リクエストごとに xAI が課金する xAI API キーで接続するか、Grok プランでログインします。設定では **X.AI-GROK** と表示されます。

## 接続

<Steps>
  <Step title="API キーを取得">
    xAI コンソールでキーを作成します。手順は [xAI のクイックスタート](https://docs.x.ai/docs/quickstart#creating-an-api-key)をご覧ください。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → X.AI-GROK** を開きます。**認証** で **API キー** を選び、キーを貼り付けて **検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

<Tip>
Grok プランをお持ちですか？ 代わりに **認証** で **Grok Subscription** を選び、**接続** をクリックします。
</Tip>

2 つ目の xAI キーを使うには、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成します。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **API ベース URL** | 認証情報の項目です。デフォルトは `https://api.x.ai/v1` です。 |

xAI には、テキスト読み上げ、画像生成、文字起こし、動画生成、X Search 用の専用プロバイダーもあります。これらはこのプロファイルのキーまたは Grok ログインを共有します。それぞれの設定ページで選んでください。

## iPhone では

iPhone アプリでも、iPhoneのチャットで Grok プランを使えます。iPhone で **設定 → AI モデル → xAI** を開き、**認証** の Grok カードを選んで、**Grok でログイン** をタップします。[iPhoneのチャット](/ja/integrations/iphone-phone-chats)をご覧ください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キー全体をもう一度貼り付け、xAI コンソールでキーが有効か確認します。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックします。自分でモデルを追加するには **モデルを管理** を使います。 |
| Grok ログインが動かなくなった | アカウントカードのメニューを開き、**再接続** をクリックします。 |
| レートまたは使用量の制限エラー | xAI アカウントで使用量を確認するか、しばらく別のプロバイダーに切り替えます。 |

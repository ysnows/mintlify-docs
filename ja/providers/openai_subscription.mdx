---
title: "ChatGPT サブスクリプション"
description: "ChatGPT のプランでサインインし、API キーなしで Enconvo から OpenAI のモデルを使います。"
---

ChatGPT に課金している場合は、API キーを作成する代わりに、そのプランでサインインします。リクエストにはプランの利用枠が使われ、Enconvo が残りの量を表示します。

## 接続する

<Steps>
  <Step title="サブスクリプションを選ぶ">
    **設定 → AI モデル → OpenAI** を開きます。**認証** で **ChatGPT サブスクリプション** を選びます。
  </Step>
  <Step title="サインインする">
    **接続** をクリックし、ブラウザで ChatGPT アカウントにサインインして、アクセスを許可します。ブラウザに完了と表示されたら、Enconvo に戻ります。
  </Step>
  <Step title="モデルを選ぶ">
    アカウントカードに正しいアカウントが表示されていることを確認し、**モデル名** でモデルを選んで、短いメッセージを送ります。
  </Step>
</Steps>

Enconvo はバックグラウンドでサインインを更新するため、数日おきにサインインし直す必要はありません。

## 使用状況を確認する

アカウントカードには、各使用枠の残り（**残り %**）とリセットされる時刻、プランの更新日または終了日が表示されます。カードのメニューを開くと、次の操作ができます。

- **使用量を更新**: 最新の数値を取得します。
- **再接続**: アカウントを切り替える場合などに、再度サインインします。

OpenAI が使用状況を報告しない場合、カードには理由とともに **使用状況を取得できません** と表示されます。これは、プランに上限がないという意味ではありません。

### 無料リセットを使う

Codex から無料の上限リセットが付与されている場合、カードに **無料リセット** が表示され、残りの数と有効期限が分かります。**リセットを使う** をクリックして確認すると、すぐに上限が回復します。リセットは取り消せません。

## プランの対象範囲

ChatGPT のサインインは、OpenAI の画像生成と文字起こしでも使えます。それらのページの **認証** で **ChatGPT サブスクリプション** を選んでください。OpenAI のテキスト読み上げと埋め込みには API キーが必要で、Live Talk の音声は別に設定します。

## iPhone で使う

iPhone アプリには、電話チャット用に独自の ChatGPT サインインがあります。iPhone で **設定 → AI モデル → OpenAI** を開き、**認証** の下の ChatGPT カードを選んで、**ChatGPT でログイン** をタップします。ページには、プラン、5 時間と週ごとの上限の残り、それぞれのリセット時刻が表示されます。このサインインは iPhone にとどまり、Mac は Mac で別に保持します。[電話チャット](/ja/integrations/iphone-phone-chats)を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| サインインに失敗する | OpenAI が返したエラーを読み、もう一度 **接続** をクリックしてください。プランのあるアカウントでサインインしていることを確認してください。 |
| モデルが見つからない | モデルはプランによって決まります。**モデル名** の横の **更新** をクリックしてください。 |
| チャットで使用上限に達したと表示される | カードに無料リセットがある場合はそれを使うか、アカウントカードに表示されるリセット時刻まで待つか、当面は **認証** を **API キー** に切り替えてください。 |
| しばらくするとチャットが動かなくなる | アカウントカードのメニューを開き、**再接続** をクリックしてください。 |

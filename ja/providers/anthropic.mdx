title: "Anthropic"
description: "Anthropic API キーまたは Claude プランを使って、Enconvo で Claude モデルとチャットします。"
---

Anthropic の Claude モデルを、チャット、エージェント、AI コマンドで使えます。リクエストごとに Anthropic が課金する Anthropic API キーで接続するか、Claude プランでログインします。

## 接続

<Steps>
  <Step title="API キーを取得">
    [Anthropic Console](https://console.anthropic.com/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加">
    **設定 → AI モデル → Anthropic** を開きます。**認証** で **API キー** を選び、キーを貼り付けて **検証** をクリックします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

<Tip>
Claude プランをお持ちですか？ 代わりに **認証** で **Claude Subscription** を選び、**接続** をクリックします。[Claude Subscription](/ja/providers/anthropic_subscription) をご覧ください。
</Tip>

2 つ目の Anthropic キーを使うには、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成します。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** でリストを再読み込みし、**モデルを管理**（歯車）でモデルを追加または復元します。 |
| **API ベース URL** | 認証情報の項目です。デフォルトは `https://api.anthropic.com` です。Anthropic 互換のサービスを使う場合にのみ変更します。 |

チャットの推論に関するコントロールは、選んだモデルによって異なります。Anthropic の最も高性能なモデルである Claude Fable 5.2 は、推論の強さを **低** から **最大** まで選べ、API キーでは Fast モードも使えます。最大 100 万トークンを扱える Claude モデルは、500K のコンテキストから始まります。**モデルを管理** で引き上げられます。1 つのチャットだけ別のモデルを使うには、そのチャットのモデルピッカーから選びます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キー全体をもう一度貼り付け、Anthropic Console でキーが有効か確認します。 |
| モデルが見つからない | **モデル名** の横の **更新** をクリックします。自分でモデルを追加するには **モデルを管理** を使います。 |
| レートまたは使用量の制限エラー | Anthropic Console で使用量と制限を確認するか、しばらく別のプロバイダーに切り替えます。 |
| 返信が遅い | より小さいモデル、短い入力、または低めの推論の強さを試します。 |

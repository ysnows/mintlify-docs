チャット、エージェント、AI コマンドで Anthropic の Claude モデルを利用できます。リクエストごとの従量課金になる Anthropic API キーで接続するか、契約中の Claude プランでサインインして利用します。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [Anthropic Console](https://console.anthropic.com/) でキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → Anthropic** を開きます。**認証** で **API キー** を選び、キーを貼り付けて **検証** をクリックします。
  </Step>
  <Step title="モデルを選ぶ">
    **Model Name** からモデルを選び、短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

<Tip>
Claude プランをお持ちの場合は、**認証** で **Claude サブスクリプション** を選んで **接続** をクリックしてください。[Claude サブスクリプション](/ja/providers/anthropic_subscription)を参照してください。
</Tip>

2 つ目の Anthropic キーを保持したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成します。

## モデルとオプション

| 設定 | 働き |
| --- | --- |
| **Model Name** | このプロバイダーで使用するモデルです。横の **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルを追加または復元します。 |
| **API Base Url** | 認証情報内にあります。デフォルトは `https://api.anthropic.com` です。Anthropic 互換サービスを使う場合のみ変更してください。 |

チャットでの推論コントロールは選択したモデルによって異なります。Anthropic の最上位モデルである Claude Fable 5.2 では、推論の強さを **Low** から **Max** まで選択でき、API キー利用時には Fast モードも使えます。最大 1M トークンに対応する Claude モデルは初期コンテキストが 500K になっており、**モデルを管理**から上限を引き上げられます。特定のチャットだけ別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| **検証**に失敗する | キー全体を貼り直し、Anthropic Console 上でそのキーが有効になっているか確認してください。 |
| モデルが見当たらない | **Model Name** の横にある**更新**をクリックします。自分でモデルを追加するには**モデルを管理**を使用してください。 |
| レート制限や利用上限のエラーが出る | Anthropic Console で利用状況と上限を確認するか、一時的に別のプロバイダーへ切り替えてください。 |
| 返信が遅い | より小さなモデル、短い入力、または低い推論の強さを試してください。 |

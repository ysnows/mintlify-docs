---
title: "MiniMax"
description: "ご自身の MiniMax API キーを使って Enconvo で MiniMax モデルとチャットできます。"
---

MiniMax は API キーを通じてモデルを提供しています。Enconvo にキーを追加すると、チャット、Agent、AI コマンドでそれらのモデルを利用できます。利用料金はご自身の MiniMax アカウントに請求されます。設定画面では **Minimax AI** として表示されます。

## 接続する

<Steps>
  <Step title="API キーを取得する">
    [MiniMax ユーザーセンター](https://platform.minimax.io/user-center/basic-information)でキーを作成します。
  </Step>
  <Step title="Enconvo に追加する">
    **設定 → AI モデル → Minimax AI** を開きます。**認証** の **API キー** にキーを貼り付け、**検証** をクリックします。
  </Step>
  <Step title="モデルを選択する">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返ってくれば接続は完了です。
  </Step>
</Steps>

仕事用など 2 つ目の MiniMax キーを保持したい場合は、**新しいプロバイダーを追加** をクリックして別のプロファイルを作成してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーで使用するモデルです。横にある **更新** で一覧を再読み込みし、**モデルを管理**（歯車アイコン）でモデルの追加や復元を行えます。 |

1 つのチャットだけ別のモデルを使いたい場合は、そのチャットのモデルピッカーから選択してください。

MiniMax にはテキスト読み上げプロバイダーもあります。**設定 → テキスト読み上げ** から選択できます。

モデルの詳細や制限については、[MiniMax API リファレンス](https://platform.minimax.io/docs/api-reference/api-overview)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| **検証** が失敗する | キー全体をもう一度貼り付け、MiniMax アカウントでキーが有効になっているか確認してください。 |
| モデルが見つからない | **モデル名** の横にある **更新** をクリックして一覧を再読み込みします。手動でモデルを追加するには **モデルを管理** を使用してください。 |
| 画像やツールが機能しない | 画像入力やツール呼び出しに対応したモデルを選択してください。 |
| レート制限や利用上限エラー | MiniMax アカウントで使用量と上限を確認するか、一時的に別のプロバイダーへ切り替えてください。 |
| 返信が遅い | より小さなモデル、より短い入力、または低い推論の強さを試してください。 |

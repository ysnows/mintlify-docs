---
title: "LM Studio"
description: "お使いの Mac や別のコンピュータ上の LM Studio で提供されているモデルとチャットできます。"
---

LM Studio を使うと、この Mac 上やネットワーク上の別のコンピュータなど、ご自身のハードウェアでモデルを実行できます。Enconvo は LM Studio サーバーへチャットを送信するため、プロバイダーのアカウントは不要です。

## この Mac で接続する

<Steps>
  <Step title="LM Studio を起動する">
    [LM Studio](https://lmstudio.ai/) でモデルを読み込み、ローカル API サーバーを起動します。
  </Step>
  <Step title="Enconvo の接続先を設定する">
    **設定 → AI モデル → LM Studio** を開きます。**認証** の **BaseUrl** は、LM Studio のポートを変更していない限り `http://127.0.0.1:1234/v1` のままにします。
  </Step>
  <Step title="モデルを選択する">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信が返ってくれば接続は完了です。
  </Step>
</Steps>

## 別のコンピュータに接続する

1. もう一方のコンピュータで、自身だけでなくネットワークからの接続を受け付けるように LM Studio を設定します。
2. Enconvo で、ポートとパスを保ったまま **BaseUrl** をそのコンピュータのネットワークアドレスに設定します。`127.0.0.1` と `localhost` は常に Enconvo を実行している Mac 自身を指します。
3. macOS が接続をブロックする場合は、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo をオンにしてください。

サーバーは信頼できるネットワークにのみ公開してください。

## モデルとオプション

| 設定 | 説明 |
| --- | --- |
| **モデル名** | このプロバイダーで使用するモデルです。横にある **更新** をクリックすると、サーバーから一覧を再読み込みします。 |
| **レスポンスタイムアウト** | サーバーが返信を開始または継続するまで待機する時間です。デフォルトは **上限なし** です。ご自身のハードウェアで長いプロンプトを処理する場合、最初の単語が出るまで数分かかることがあります。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 接続が拒否される | LM Studio が起動しているか、**BaseUrl** に正しいアドレスとポートが設定されているか確認してください。別のコンピュータに接続する場合は、ネットワーク接続を受け入れる設定になっているかも確認してください。 |
| ネットワークに到達できない | ネットワーク接続と、システム設定の **ローカルネットワーク** 権限を確認してください。 |
| モデル一覧が空になる | LM Studio でモデルを読み込むかダウンロードしてから、**更新** をクリックしてください。 |
| 返信が途中で中断される | **レスポンスタイムアウト** をより長い時間または **上限なし** に設定してください。 |
| ツールや画像が機能しない | ツール呼び出しや画像入力に対応したモデルを選択してください。 |
| メモリ不足 | より小さなモデルを選ぶか、入力を短くしてください。 |

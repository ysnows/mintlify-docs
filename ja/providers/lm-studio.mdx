---
title: "LM Studio"
description: "Mac または別のコンピューターで LM Studio が提供するモデルとチャットします。"
---

LM Studio を使うと、この Mac やネットワーク上の別のコンピューターなど、ご自身のハードウェアでモデルを実行できます。Enconvo はチャットを LM Studio サーバーに送るため、プロバイダーのアカウントは不要です。

## この Mac で接続する

<Steps>
  <Step title="LM Studio を起動する">
    [LM Studio](https://lmstudio.ai/) でモデルを読み込み、ローカル API サーバーを起動します。
  </Step>
  <Step title="Enconvo に接続先を設定する">
    **設定 → AI モデル → LM Studio** を開きます。**認証** で、LM Studio のポートを変更していない限り、**BaseUrl** を `http://127.0.0.1:1234/v1` のままにします。
  </Step>
  <Step title="モデルを選択">
    **モデル名** でモデルを選び、短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

## 別のコンピューターに接続する

1. 別のコンピューターで、LM Studio がそのコンピューター自身からだけでなく、ネットワークからの接続も受け付けるように設定します。
2. Enconvo で、**BaseUrl** にそのコンピューターのネットワークアドレスを設定します。ポートとパスはそのままにします。`127.0.0.1` と `localhost` は常に、Enconvo を実行している Mac を指します。
3. macOS が接続をブロックする場合は、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo をオンにします。

サーバーは、信頼できるネットワークにのみ公開してください。

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **モデル名** | このプロバイダーが使うモデルです。横の **更新** で、サーバーからリストを再読み込みします。 |
| **Response Timeout** | サーバーが返信を開始または継続するまで待つ時間です。デフォルトは **上限なし** です。ご自身のハードウェアでは、長いプロンプトだと最初の 1 語が出るまでに何分もかかることがあります。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 接続が拒否される | LM Studio が起動していること、**BaseUrl** のアドレスとポートが正しいことを確認します。別のコンピューターの場合は、ネットワーク接続を受け付けていることも確認します。 |
| ネットワークに到達できない | ネットワークと、システム設定の **ローカルネットワーク** の権限を確認します。 |
| モデルリストが空 | LM Studio でモデルを読み込むかダウンロードしてから、**更新** をクリックします。 |
| 返信が途中で止まる | **Response Timeout** をより長い値または **上限なし** に設定します。 |
| ツールや画像が動かない | ツール呼び出しまたは画像入力に対応したモデルを選びます。 |
| メモリ不足 | より小さいモデルを選ぶか、入力を短くします。 |

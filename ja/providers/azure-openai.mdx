---
title: "Azure OpenAI"
description: "Enconvo で Azure OpenAI のデプロイとチャットします。"
---

組織で Azure 上にデプロイした OpenAI モデルを利用できます。Enconvo は Azure リソースと直接通信するため、アクセス権、クォータ、課金はご利用の Azure サブスクリプションに従います。

## 始める前に

モデルが 1 つ以上デプロイされた Azure OpenAI リソースが必要です。Azure ポータルから、リソースの **キー**、**エンドポイント**、およびモデルに付けた**デプロイ名**をコピーしてください。まだ作成していない場合は、[Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview) をご覧ください。

## 接続する

<Steps>
  <Step title="認証情報を追加する">
    **設定 → AI モデル → Azure OpenAI** を開きます。**認証**の下で **API キー**、**Endpoint**、**API Version** を入力し、**検証**をクリックします。エンドポイントは `https://<resource>.cognitiveservices.azure.com/` のような形式です。
  </Step>
  <Step title="デプロイを設定する">
    **Azure OpenAI Api Deployment Name** にデプロイ名を入力します。モデル名とは異なる場合があるため、Azure リソース上の名前をそのまま使ってください。
  </Step>
  <Step title="テストする">
    短いメッセージを送信します。返信が返れば接続は正常です。
  </Step>
</Steps>

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | このプロバイダーが呼び出すデプロイです。 |
| **Streaming** | 返信を書きながら順次表示します。デフォルトでオンです。ご利用のデプロイがストリーミングに対応していない場合はオフにしてください。 |
| **API Version** | 認証情報内で設定します。デフォルトは `2025-01-01-preview` です。 |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| **検証**に失敗する | キーと **Endpoint** が同じ Azure リソースのものか確認してください。 |
| デプロイが見つからない | Azure ポータルからデプロイ名を正確にコピーしてください。 |
| 返信がまったく表示されない | **Streaming** をオフにしてもう一度試してください。 |
| レート制限またはクォータエラーが出る | Azure でデプロイのクォータを引き上げるか、一時的に別のプロバイダーへ切り替えてください。 |

---
title: "Azure OpenAI"
description: "Enconvo で Azure OpenAI のデプロイメントとチャットします。"
---

組織が Azure にデプロイした OpenAI モデルを使えます。Enconvo は Azure リソースと直接通信するため、アクセス、クォータ、課金は Azure サブスクリプションに従います。

## 始める前に

少なくとも 1 つのモデルデプロイメントがある Azure OpenAI リソースが必要です。Azure ポータルから、リソースの**キー**、**エンドポイント**、モデルに付けた**デプロイメント名**をコピーしてください。まだ設定していない場合は、[Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview) をご覧ください。

## 接続

<Steps>
  <Step title="認証情報を追加">
    **設定 → AI モデル → Azure OpenAI** を開きます。**認証** で、**API キー**、**エンドポイント**、**API バージョン** を入力し、**検証** をクリックします。エンドポイントは `https://<resource>.cognitiveservices.azure.com/` の形式です。
  </Step>
  <Step title="デプロイメントを設定">
    **Azure OpenAI Api Deployment Name** にデプロイメント名を入力します。Azure リソースにある名前を使ってください。モデル名とは異なる場合があります。
  </Step>
  <Step title="テストする">
    短いメッセージを送信します。返信があれば接続は成功です。
  </Step>
</Steps>

## モデルとオプション

| 設定 | 内容 |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | このプロバイダーが呼び出すデプロイメントです。 |
| **ストリーミング** | 返信を書かれている途中から表示します。デフォルトではオンです。デプロイメントがストリーミングに対応していない場合はオフにします。 |
| **API バージョン** | 認証情報の項目です。デフォルトは `2025-01-01-preview` です。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **検証** に失敗する | キーと **エンドポイント** が同じ Azure リソースのものか確認します。 |
| デプロイメントが見つからない | Azure ポータルからデプロイメント名を正確にコピーします。 |
| 返信が表示されない | **ストリーミング** をオフにして、もう一度試します。 |
| レートまたはクォータのエラー | Azure でデプロイメントのクォータを引き上げるか、しばらく別のプロバイダーに切り替えます。 |

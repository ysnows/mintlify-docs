以下の表から該当する症状を探し、右列の対処法を試してください。多くの問題は、プロバイダーが未接続であること、macOS の権限が不足していること、またはアプリのバージョンが古いことが原因です。解決しない場合は、[診断情報を送信する](#診断情報を送信する) の手順でログを送り、Discord でお尋ねください。

## まず試すこと

1. **Enconvo を終了して開き直す。** メニューバーの Enconvo アイコンから **終了** を選び、**アプリケーション** フォルダから Enconvo を起動します。
2. **アップデートする。** メニューバーアイコンから **アップデートを確認** を選ぶか、**設定 → 一般 → アップデート** の **アップデートを確認** をクリックします。
3. **モデルを確認する。** **設定 → AI モデル** を開き、使用しているプロバイダーが接続されていることを確認します。よく分からない場合は、Enconvo アカウントにサインインして [オートルート](/ja/providers/auto-route) を使用してください。
4. **権限を確認する。** **設定 → 権限** を開き、機能に必要な権限をオンにします。[権限](/ja/configuration/permissions)を参照してください。

## 回答とモデル

| 問題 | 対処法 |
| --- | --- |
| 回答が返らない、またはプロバイダーに関するエラーが出る | **設定 → AI モデル** でプロバイダーを開き、**検証** をクリックします。プランでサインインしている場合は、アカウントカードのメニューを開いて **再接続** をクリックしてください。 |
| 上限、クォータ、またはポイントに関するエラーが出る | 各プロバイダーの利用状況ページ、または Enconvo Cloud の場合は **設定 → ポイント使用量** を確認してください。一時的に別のプロバイダーへ切り替えることもできます。 |
| すべてのクラウドプロバイダーが失敗する | インターネット接続を確認してください。プロキシ環境下では、**設定 → 一般** の **ネットワークプロキシ** にある **システムのネットワークプロキシ設定を使用** をオンにします。オンにすると、モデルへのリクエスト、ウェブ取得、コネクタがシステムプロキシを経由するようになり、プロキシ変更時も Enconvo の再起動なしで反映されます。LM Studio や Ollama など、Mac 上やローカルネットワーク上のサーバーには引き続き直接接続されます。 |
| お住まいの国や地域では利用できないというメッセージが出る | **システムのネットワークプロキシ設定を使用** をオンにして、Enconvo のリクエストがプロキシを経由するようにしてください。 |
| 回答が遅い | より小さく高速なモデルを選ぶか、添付するコンテキストを減らすか、推論の強さを下げてください。ローカルモデルは入力が長くなると遅くなります。 |
| 1 つのモデルだけ失敗し、他は動作する | そのモデルまたはプロバイダー側の問題です。チャットのモデルピッカーで別のモデルを選んでください。 |
| Ollama や LM Studio に接続できない | サーバーが起動しており、**BaseUrl** がそのアドレスと一致していることを確認してから、**Model Name** の横にある **更新** をクリックしてください。[Ollama](/ja/providers/ollama) または [LM Studio](/ja/providers/lm-studio) を参照してください。 |

## ショートカットとウィンドウ

| 問題 | 対処法 |
| --- | --- |
| ショートカットを押しても何も起きない | Spotlight、Raycast、Alfred など他のアプリが同じキーを使っている可能性があります。**設定 → ショートカット** でいずれかを変更してください。 |
| アップデート後にショートカットが効かなくなった | Enconvo を終了して開き直してください。それでも改善しない場合は、システム設定で Enconvo のアクセシビリティを一度オフにしてからオンに戻してください。 |
| アプリが見つからない | メニューバーまたは Dock の Enconvo アイコンをクリックするか、**⌥Space** を押して SmartBar を開いてください。 |
| 記憶していた SmartBar やチャットウィンドウのキーで開かない | デフォルトは SmartBar が **⌥Space**、チャットウィンドウが **⌃⌘X** です。**設定 → ショートカット** を確認してください。 |

## 選択テキストと画面

| 問題 | 対処法 |
| --- | --- |
| PopBar が表示されない、または選択したテキストを読み取れない | **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で Enconvo をオンにしてください。すでにオンの場合は一度オフにして 2 秒待ち、再度オンにしてから Enconvo を開き直してください。パスワード入力欄や一部の独自エディタではテキストを取得できません。 |
| スクリーンショット、OCR、画面コンテキストが失敗する | **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で Enconvo をオンにし、Enconvo を開き直してください。 |
| 権限がオンなのにアップデート後から動作しない | システム設定の一覧から **−** で Enconvo を削除し、再度追加してから Enconvo を開き直してください。 |
| 権限の確認ダイアログが出なくなった | **今後確認しない** にチェックを入れた可能性があります。**設定 → 権限** に各権限の **使用機能** 一覧が表示されるため、そこから許可してください。 |

## 音声とオーディオ

| 問題 | 対処法 |
| --- | --- |
| 音声入力が音を拾わない | マイク権限と、**設定 → 音声入力** で選ばれているマイクを確認してください。 |
| 音声入力の精度が悪い、または遅い | **設定 → 音声入力モデル** で別の音声認識モデルを試してください。人名や専門用語は **設定 → 辞書** に追加できます。 |
| 読み上げの音が出ない | Mac の音量と出力デバイスを確認してください。**設定 → テキスト読み上げ** で **システム** を試すと、API キー不要かつオフラインで動作します。 |

詳しくは[音声入力](/ja/features/dictation)と[音声認識](/ja/ai/speech-recognition)をご覧ください。

## ナレッジベース

| 問題 | 対処法 |
| --- | --- |
| ドキュメントのインデックス作成が終わらない | **設定 → ナレッジベース** の埋め込みプロバイダー設定と、対応しているファイル形式かどうかを確認してください。 |
| 検索しても何も見つからない | チャットにナレッジベースが添付されているか確認してください。ナレッジベースの設定でスコアしきい値を下げるか、取得件数を増やしてください。 |
| 大きなナレッジベースが重い | トピックごとに小さなナレッジベースへ分割するか、リランカーを追加してください。 |

詳しくは[ナレッジベース](/ja/ai/knowledge-base)と[ナレッジベース設定](/ja/advanced/knowledge-base-advanced)をご覧ください。

## ブラウザ・アプリ・プラグイン

| 問題 | 対処法 |
| --- | --- |
| Enconvo がブラウザを操作できない | **設定 → Browser Use** から Enconvo Companion 拡張機能をインストールし、ブラウザを再起動してください。[ブラウザ拡張機能](/ja/features/browser-extension)を参照してください。 |
| エージェントがアプリを操作できない | **設定 → Computer Use** で求められる権限をオンにしてください。[Computer Use](/ja/features/computer-use) を参照してください。 |
| プラグインコマンドが失敗する | **設定 → プラグイン** を開き、プラグインの設定と認証情報を確認して Enconvo をアップデートしてください。 |
| エージェントのコマンドが権限エラーで失敗する | エージェントのサンドボックスが停止した可能性があります。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。 |

## 診断情報を送信する

Enconvo がフリーズやクラッシュを繰り返したり正常に動作しなくなったりした場合は、診断ログを Enconvo チームへ送信してください。メニューバーアイコンから **診断情報を送信…** を選ぶか、**設定 → 診断** を開きます。送信前にはファイル名、メールアドレス、キー、プロンプト本文などの個人情報が取り除かれ、実際に送信される内容を事前に確認できます。[プライバシーとセキュリティ](/ja/configuration/privacy-security)を参照してください。

## ヘルプを得る

- [Discord](https://discord.gg/jYsdVRRK2k) で質問する。Enconvo のバージョン（**設定 → このアプリについて**）、macOS のバージョン、行った操作、起きた現象を添えてください。
- メニューバーのメニューにある **フィードバック** から不具合の報告や機能の要望を送る。
- よくある質問は [FAQ](/ja/faq) を確認する。

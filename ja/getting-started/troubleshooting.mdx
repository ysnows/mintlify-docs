下の表から該当する問題を探し、右の列の対処方法を試してください。ほとんどの問題は、プロバイダーが接続されていない、macOS の権限が足りない、アプリが古い、のいずれかが原因です。ここで解決しない場合は、[診断情報を送信](#診断情報を送信)して Discord で質問してください。

## まず試すこと

1. **Enconvo を終了して開き直す。** メニューバーの Enconvo アイコンから **終了** を選び、**アプリ** から Enconvo を開きます。
2. **アップデートする。** メニューバーアイコンから **アップデートを確認** を選ぶか、**設定 → 一般 → アップデート** で **アップデートを確認** をクリックします。
3. **モデルを確認する。** **設定 → AI モデル** を開き、使用しているプロバイダーが接続されていることを確認します。わからない場合は、Enconvo アカウントにログインして[自動ルーティング](/ja/providers/auto-route)を使ってください。
4. **権限を確認する。** **設定 → 権限** を開き、機能に必要なものをオンにします。[権限](/ja/configuration/permissions)をご覧ください。

## 回答とモデル

| 問題 | 対処方法 |
| --- | --- |
| 回答がない、またはプロバイダーに関するエラーが出る | **設定 → AI モデル** でプロバイダーを開き、**検証** をクリックします。プランのログインの場合は、アカウントカードのメニューを開いて **再接続** をクリックします。 |
| 上限、クォータ、ポイントに関するエラーが出る | プロバイダーの使用状況ページを確認するか、Enconvo Cloud の場合は **設定 → ポイント使用量** を確認します。当面は別のプロバイダーに切り替えてください。 |
| すべてのクラウドプロバイダーで失敗する | インターネット接続を確認します。プロキシ経由の場合は、**設定 → 一般** の **ネットワークプロキシ** にある **システムのネットワークプロキシ設定を使用** を確認します。オンにすると、モデルへのリクエスト、Web の取得、コネクタがシステムのプロキシを経由し、プロキシの変更は Enconvo を再起動しなくても反映されます。LM Studio や Ollama など、Mac 上やローカルネットワーク内のサーバーには、引き続き直接接続します。 |
| モデルがお住まいの国または地域では利用できないと表示される | **システムのネットワークプロキシ設定を使用** をオンにして、Enconvo のリクエストがプロキシを経由するようにします。 |
| 回答が遅い | より小さいモデルや高速なモデルを選ぶ、添付するコンテキストを減らす、または推論の強度を下げてください。ローカルモデルは入力が長いと遅くなります。 |
| 1 つのモデルだけ失敗し、ほかは動作する | そのモデルまたはプロバイダーに問題があります。チャットのモデルピッカーで別のモデルを選んでください。 |
| Ollama や LM Studio に接続できない | サーバーが起動していて、**BaseUrl** がそのアドレスと一致していることを確認し、**モデル名** の横の **更新** をクリックします。[Ollama](/ja/providers/ollama) または [LM Studio](/ja/providers/lm-studio) をご覧ください。 |

## ショートカットとウィンドウ

| 問題 | 対処方法 |
| --- | --- |
| ショートカットが何も起こさない | Spotlight、Raycast、Alfred など、別のアプリが同じキーを使っている可能性があります。**設定 → ショートカット** でどちらかを変更してください。 |
| アップデート後にショートカットが動かなくなった | Enconvo を終了して開き直してください。解決しない場合は、システム設定で Enconvo のアクセシビリティをオフにしてからオンにします。 |
| アプリが見つからない | メニューバーまたは Dock の Enconvo アイコンをクリックするか、**⌥Space** で SmartBar を開いてください。 |
| 覚えていた SmartBar やチャットウィンドウのキーが何も起こさない | デフォルトは、SmartBar が **⌥Space**、チャットウィンドウが **⌃⌘X** です。**設定 → ショートカット** を確認してください。 |

## 選択したテキストと画面

| 問題 | 対処方法 |
| --- | --- |
| PopBar が表示されない、または Enconvo が選択したテキストを読み取れない | **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で Enconvo をオンにします。すでにオンの場合は、いったんオフにして 2 秒待ち、再びオンにして Enconvo を開き直します。セキュアなフィールドや一部のカスタムエディタは、テキストを共有しません。 |
| スクリーンショット、OCR、画面コンテキストが失敗する | **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で Enconvo をオンにし、Enconvo を開き直します。 |
| アップデート後に、権限がオンなのに効果がない | システム設定でそのリストから Enconvo を **−** で削除し、もう一度追加して、Enconvo を開き直します。 |
| 機能が権限を求めなくなった | **今後確認しない** にチェックを入れた可能性があります。**設定 → 権限** に各権限の **利用元** の一覧が表示されるので、そこで許可してください。 |

## 音声とオーディオ

| 問題 | 対処方法 |
| --- | --- |
| 音声入力が何も聞き取らない | マイクの権限と、**設定 → 音声入力** で選択しているマイクを確認してください。 |
| 音声入力の認識が誤る、または遅い | **設定 → 音声入力モデル** で別の音声認識モデルを試してください。**設定 → 辞書** に名前や用語を追加します。 |
| 読み上げが無音 | Mac の音量と出力デバイスを確認してください。**設定 → テキスト読み上げ** で **システム** を試してください。キーは不要で、オフラインでも動作します。 |

詳しくは、[音声入力](/ja/features/dictation)と[音声認識](/ja/ai/speech-recognition)をご覧ください。

## ナレッジベース

| 問題 | 対処方法 |
| --- | --- |
| ドキュメントのインデックス作成が終わらない | **設定 → ナレッジベース** で埋め込みプロバイダーを確認し、ファイルの種類が対応していることを確認してください。 |
| 検索しても何も見つからない | ナレッジベースがチャットに添付されていることを確認してください。ナレッジベースの設定で、スコアのしきい値を下げるか、結果の件数を増やします。 |
| 大きなナレッジベースが遅い | トピックごとに、より小さなナレッジベースに分割してください。 |

詳しくは、[ナレッジベース](/ja/ai/knowledge-base)と[ナレッジベースの設定](/ja/advanced/knowledge-base-advanced)をご覧ください。

## ブラウザ、アプリ、プラグイン

| 問題 | 対処方法 |
| --- | --- |
| Enconvo がブラウザを操作できない | **設定 → ブラウザを使用** から Enconvo Companion 拡張機能をインストールし、ブラウザを再起動します。[ブラウザ拡張機能](/ja/features/browser-extension)をご覧ください。 |
| エージェントがアプリを使えない | **設定 → コンピューター操作** が求める権限をオンにしてください。[コンピューター操作](/ja/features/computer-use)をご覧ください。 |
| プラグインのコマンドが失敗する | **設定 → プラグイン** を開き、プラグインの設定と認証情報を確認して、Enconvo をアップデートしてください。 |
| エージェントのコマンドが権限エラーで失敗する | エージェントのサンドボックスが止めた可能性があります。[エージェントのサンドボックス](/ja/configuration/sandbox)をご覧ください。 |

## 診断情報を送信

Enconvo がフリーズする、クラッシュする、または不調が続く場合は、診断ログを Enconvo チームに送信してください。メニューバーアイコンから **診断情報を送信…** を選ぶか、**設定 → 診断** を開きます。Enconvo は、ファイル名、メールアドレス、キー、プロンプトのテキストなどの個人情報を、Mac から送信される前に取り除き、実際に送信された内容をそのまま表示します。[プライバシーとセキュリティ](/ja/configuration/privacy-security)をご覧ください。

## サポートを受ける

- [Discord](https://discord.gg/jYsdVRRK2k) で質問してください。Enconvo のバージョン (**設定 → このアプリについて**)、macOS のバージョン、行った操作、起きたことを添えてください。
- メニューバーのメニューにある **フィードバック** から、問題の報告や機能の提案ができます。
- 簡単な回答は[よくある質問](/ja/faq)をご覧ください。

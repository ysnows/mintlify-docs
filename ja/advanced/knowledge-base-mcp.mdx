---
title: "ナレッジベース MCP"
description: "Mac 上の Claude、Cursor、Codex などの MCP クライアントから、共有したナレッジベースを検索して読めるようにします。"
---

Enconvo は、同じ Mac 上の MCP 対応 AI クライアントに、あなたのナレッジベースを提供できます。クライアントは、共有したナレッジベースの検索と読み取りだけができ、それ以外にはアクセスできません。アクセスは読み取り専用です。これは **設定 → MCP サーバー** とは別の機能で、MCP サーバーは Enconvo のエージェントに外部ツールを追加するものです。

## クライアントを接続する

1. [ナレッジベース](/ja/ai/knowledge-base)を開き、歯車（**ナレッジベースの設定**）をクリックして、**AI クライアント（MCP）** を開きます。
2. **ナレッジベースMCPを有効にする** をオンにします。デフォルトではオフで、オフの間は接続されたクライアントが拒否されます。
3. クライアントに見せる内容を選びます。**このナレッジベースを AI クライアントと共有** は開いているナレッジベースが対象で、**共有ナレッジベース** にはすべてが一覧表示されます。音声入力履歴とメモリは、オンにするまで非表示です。
4. **クライアントを接続** で、お使いのクライアント（Claude Code、Cursor、Codex、Claude Desktop）を選び、その設定をコピーします。
5. クライアントにナレッジベースを一覧表示させ、1 つを検索して、一致した項目を読ませます。

ローカルのエンドポイントは次のとおりです。

```text
http://localhost:54535/knowledge_base/mcp
```

Streamable HTTP トランスポートを使います。クライアントが使っている間は、Enconvo を起動したままにしてください。Claude Desktop は `mcp-remote` という小さなブリッジ経由で接続するため、設定には Node.js が必要です。ダイアログに表示されるクライアント別の手順に従ってください。

## 利用できるツール

| ツール | 目的 |
| --- | --- |
| `kb_list` | 表示可能なナレッジベースを一覧表示 |
| `kb_search` | 表示可能なナレッジベースを検索 |
| `item_list` | 表示可能なナレッジベース内の項目を一覧表示 |
| `item_read` | インデックス化された項目のテキストをページ単位で読み取り |

ツールは読み取り専用です。このエンドポイントは、一般的なメモリや録音のツールを公開しません。項目を読み取ると、メタデータとしてソースのパスや URL が返されることがあります。

## アクセスと処理

サーバーはループバック接続のみを受け付け、トークンは不要です。オンにすると、ローカルのプロセスが、共有したナレッジベースを読み取れるようになります。接続された AI クライアントは、取得した内容を自分のモデルプロバイダーに送信することがあるため、そのクライアントの設定も確認してください。

検索には、**設定 → メモリ** の **検索** で設定した埋め込みモデルが使われます。Enconvo Cloud で実行される場合、検索テキストはそこに送信されます。「ローカルのエンドポイント」という言葉は、検索と回答のすべてがオフラインで実行されることを意味しません。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 接続が拒否される | Enconvo とそのローカル API が起動していることを確認してください。 |
| Forbidden / 403 | **ナレッジベースMCPを有効にする** がオンであること、クライアントがこの Mac から接続していること、設定がダイアログの内容と一致していることを確認してください。 |
| ナレッジベースが見つからない | **共有ナレッジベース** でそのナレッジベースをオンにしてください。非表示のナレッジベースと存在しないナレッジベースは、クライアントからは同じに見えます。 |
| ブラウザで URL を開くと 405 になる | ブラウザの GET は MCP リクエストではありません。MCP クライアントで接続してください。 |
| 長いドキュメントが途中までしか返ってこない | `item_read` で続きのページをリクエストするよう、クライアントに頼んでください。 |

すべてのアクセスを止めるには、**ナレッジベースMCPを有効にする** をオフにします。クライアントが取得できる範囲を絞るには、**共有ナレッジベース** で個別のナレッジベースをオフにします。

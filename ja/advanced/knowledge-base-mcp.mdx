title: "ナレッジベース MCP"
description: "同じ Mac 上の Claude、Cursor、Codex などの MCP クライアントから、共有したナレッジベースを検索・閲覧できるようにします。"
---

Enconvo は同じ Mac 上にある MCP 対応の AI クライアントへナレッジベースを公開できます。クライアントはあなたが共有したナレッジベースの検索と閲覧だけを行え、読み取り専用でアクセスします。これは Enconvo のエージェントに外部ツールを追加する **設定 → MCP サーバー** とは別の機能です。

## クライアントを接続する

1. [ナレッジベース](/ja/ai/knowledge-base)を開き、歯車アイコン（**ナレッジベースの設定**）から **AI クライアント（MCP）** をクリックします。
2. **ナレッジベースMCPを有効にする** をオンにします。デフォルトではオフになっており、オフの間は接続要求を拒否します。
3. クライアントから見えるナレッジベースを選びます。**このナレッジベースを AI クライアントと共有** は今開いているナレッジベースを対象とし、**共有ナレッジベース** にはすべてのナレッジベースが一覧表示されます。音声入力履歴とメモリはオンにするまで非表示です。
4. **クライアントを接続** の下で使用するクライアント（Claude Code、Cursor、Codex、Claude Desktop）を選び、表示された設定をコピーします。
5. クライアント側でナレッジベースの一覧取得、検索、一致した項目の読み取りを試します。

ローカルエンドポイントは次のとおりです。

```text
http://localhost:54535/knowledge_base/mcp
```

Streamable HTTP トランスポートを使用しています。クライアントが利用している間は Enconvo を起動したままにしてください。Claude Desktop は `mcp-remote` という小さなブリッジ経由で接続するため Node.js が必要です。ダイアログに表示されるクライアント別の手順に従ってください。

## 利用できるツール

| ツール | 用途 |
| --- | --- |
| `kb_list` | 公開されているナレッジベースの一覧を取得する |
| `kb_search` | 公開されているナレッジベースを検索する |
| `item_list` | 公開されているナレッジベース内の項目一覧を取得する |
| `item_read` | インデックス化された項目のテキストをページ単位で読み取る |

これらのツールはすべて読み取り専用です。このエンドポイントから一般的なメモリや録音のツールは公開されません。項目を読み取る際、メタデータとして元のファイルパスや URL が返ることがあります。

## アクセス制御とデータ処理

このサーバーはループバック接続（ローカルからのアクセス）のみを受け付け、トークンは不要です。有効にすると、同じ Mac 上のローカルプロセスから共有したナレッジベースを読み取れるようになります。接続した AI クライアントは取得した内容を自身のモデルプロバイダーへ送信する場合があるため、クライアント側の設定もあわせて確認してください。

検索には **設定 → メモリ** の **検索** で設定されている埋め込み（Embedding）モデルが使用されます。Enconvo Cloud で検索を実行する場合、検索クエリのテキストは Enconvo Cloud へ送信されます。「ローカルエンドポイント」であっても、検索と回答のすべての工程がオフラインで完結するわけではありません。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 接続が拒否される（Connection refused） | Enconvo とそのローカル API が起動しているか確認してください。 |
| 権限エラー（Forbidden / 403） | **ナレッジベースMCPを有効にする** がオンか、この Mac 上から接続しているか、設定がダイアログの表示と一致しているか確認してください。 |
| ナレッジベースが見つからない | **共有ナレッジベース** で対象のナレッジベースをオンにしてください。非表示のナレッジベースと存在しないナレッジベースはクライアントから同じように見えます。 |
| ブラウザで URL を開くと 405 が表示される | ブラウザの GET リクエストは MCP リクエストではありません。MCP クライアントから接続してください。 |
| 長いドキュメントが途中で切れる | クライアントに `item_read` で続きのページをリクエストするよう指示してください。 |

すべてのアクセスを止めるには **ナレッジベースMCPを有効にする** をオフにします。クライアントが取得できる範囲を狭めるには、**共有ナレッジベース** で個別のナレッジベースをオフにしてください。

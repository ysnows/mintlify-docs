## はじめに

<AccordionGroup>
  <Accordion title="Enconvo はどの Mac で動作しますか？">
    macOS 14 以降、Apple シリコンおよび Intel Mac に対応しています。[Local LLM (MLX)](/ja/providers/mlx) などの一部オンデバイス機能には Apple シリコンが必要です。詳しくは[インストール](/ja/installation)をご覧ください。
  </Accordion>
  <Accordion title="API キーは必要ですか？">
    いいえ。Enconvo アカウントにサインインすれば、API キーなしで [Enconvo Cloud](/ja/providers/enconvo) を使えます。ChatGPT や Claude などすでに契約しているプランでサインインしたり、ご自身の API キーを追加したり、Mac 上でローカルモデルを動かしたりすることも可能です。詳しくは[プロバイダー](/ja/providers/overview)をご覧ください。
  </Accordion>
  <Accordion title="Enconvo の料金と AI の料金はどう違いますか？">
    ライセンスはアプリの機能を利用するためのものです。AI の利用料金は実行先ごとに課金されます（Enconvo Cloud ポイント、ご自身のプロバイダーアカウント、またはご自身の Mac）。詳しくは[プランと料金](/ja/pricing)をご覧ください。
  </Accordion>
  <Accordion title="Enconvo を日本語などの自分の言語で使えますか？">
    はい。**設定 → 一般 → 言語**の**アプリの言語**で、ウクライナ語やロシア語を含む 12 種類の表示言語から選択できます。エージェントが返信に使う言語は同じ場所の**応答言語**で設定できます。詳しくは[言語、外観、設定検索](/ja/configuration/appearance-language)をご覧ください。
  </Accordion>
  <Accordion title="機能を使うときに権限を求められるのはなぜですか？">
    Enconvo は起動時に macOS の権限を求めず、権限が必要な機能を初めて使ったときに、その機能名を明示して許可を求めます。次回から確認を出さないようにするには**今後表示しない**にチェックを入れてください。詳しくは [macOS の権限](/ja/configuration/permissions)をご覧ください。
  </Accordion>
  <Accordion title="ドキュメントにある機能が自分のアプリに見つからないのはなぜですか？">
    一部の機能は Beta チャンネルに先行公開されます。お使いのバージョンと[アップデートチャンネル](/ja/configuration/updates)を確認し、[機能一覧](/ja/reference/feature-directory)でその機能を探してみてください。
  </Accordion>
</AccordionGroup>

## モデル

<AccordionGroup>
  <Accordion title="どのモデルを選べばよいですか？">
    迷ったときは [Auto Route](/ja/providers/auto-route) のままにしておけば、メッセージごとに適したモデルを自動で選んでくれます。自分で選びたい場合は[モデルを選ぶ](/ja/ai/model-selection-guide)をご覧ください。
  </Accordion>
  <Accordion title="デフォルトモデルを変更したのに、チャットが古いモデルを使い続けているのはなぜですか？">
    各チャットは、そのチャット内で変更するまで開始時のモデルを保持します。プロジェクトやエージェントにもそれぞれ独自のデフォルト設定があります。詳しくは[モデルを選ぶ](/ja/ai/model-selection-guide)をご覧ください。
  </Accordion>
  <Accordion title="ローカルモデルを使えばすべてがオフラインに留まりますか？">
    ローカルプロバイダー上で動く処理だけがオフラインに留まります。Web 検索、リモートの MCP サーバー、クラウド音声、クラウド埋め込みを使う場合は、引き続き Mac の外部へデータが送信されます。詳しくは[ローカルモデル](/ja/ai/local-llm)および[プライバシーとセキュリティ](/ja/configuration/privacy-security)をご覧ください。
  </Accordion>
</AccordionGroup>

## 音声

<AccordionGroup>
  <Accordion title="音声入力、音声コマンド、Live Talk の違いは何ですか？">
    [音声入力](/ja/features/dictation)は、話した内容を現在使っているアプリに文字として入力します。音声コマンドは、話した内容をリクエストとしてエージェントに送ります。[Live Talk](/ja/features/live-voice) は、エージェントと声で双方向に会話できる機能です。
  </Accordion>
  <Accordion title="Enconvo で会議の録音と文字起こしはできますか？">
    はい。[会議の録音](/ja/features/meeting-recording)では録音しながらリアルタイムで文字起こしでき、[文字起こし](/ja/features/transcription)では手元にある音声や動画ファイルを文字に起こせます。
  </Accordion>
</AccordionGroup>

## コンテキストとナレッジ

<AccordionGroup>
  <Accordion title="Appshots とクイックキャプチャの違いは何ですか？">
    [Appshots](/ja/features/appshots) は、今見ているアプリウィンドウを質問に添付します。[クイックキャプチャ](/ja/features/quick-capture)は、画面に表示されている内容をあとで参照できるようナレッジベースに保存します。
  </Accordion>
  <Accordion title="メモリとナレッジベースの違いは何ですか？">
    [メモリ](/ja/ai/memory)にはエージェントがあなたについて学び再利用する事実を保存し、[ナレッジベース](/ja/ai/knowledge-base)にはあなたが追加した資料を保存してエージェントが答えを探すために検索します。どちらもナレッジベース内にあり、列の上部にある**ナレッジベース** / **メモリ**スイッチで切り替えます。
  </Accordion>
  <Accordion title="他の AI アプリから Enconvo のナレッジベースを使えますか？">
    はい。[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) をオンにして公開するナレッジベースを選ぶことで連携できます。
  </Accordion>
</AccordionGroup>

## エージェントと自動化

<AccordionGroup>
  <Accordion title="エージェントは他のアプリやサービスのツールを使えますか？">
    はい。[プラグイン](/ja/extensions/overview)、[スキル](/ja/configuration/skills)、[MCP サーバー](/ja/features/mcp)を通じて利用できます。許可すれば、[ブラウザ](/ja/features/browser-control)や [Mac アプリ](/ja/features/computer-use)も操作できます。
  </Accordion>
  <Accordion title="エージェントのコマンドが触れられる範囲を制限できますか？">
    はい。エージェントの**権限**チップで**サンドボックス**をオンにすると、コマンドは作業フォルダと一時領域だけを変更でき、キーの読み取りや他のアプリの制御ができなくなります。詳しくは[エージェントサンドボックス](/ja/configuration/sandbox)をご覧ください。
  </Accordion>
  <Accordion title="席を外している間にタスクを自動実行できますか？">
    はい。Enconvo が起動しており Mac がスリープしていなければ、[オートメーション](/ja/workflows/scheduled-jobs)がスケジュールに従って自動実行されます。[IM チャネル](/ja/integrations/messaging)を接続すれば、チャットアプリで結果を受け取れます。
  </Accordion>
</AccordionGroup>

  </Accordion>
</AccordionGroup>

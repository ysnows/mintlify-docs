## はじめに

<AccordionGroup>
  <Accordion title="Enconvo はどの Mac で動きますか？">
    Apple シリコンと Intel のどちらでも、macOS 14 以降で動作します。[ローカル LLM (MLX)](/ja/providers/mlx) など、一部のデバイス上の機能には Apple シリコンが必要です。[インストール](/ja/installation)を参照してください。
  </Accordion>
  <Accordion title="API キーは必要ですか？">
    いいえ。Enconvo アカウントにサインインすれば、[Enconvo Cloud](/ja/providers/enconvo) はキーなしで使えます。ChatGPT や Claude など、すでに契約しているプランでサインインしたり、自分の API キーを追加したり、Mac 上でモデルを実行したりすることもできます。[プロバイダー](/ja/providers/overview)を参照してください。
  </Accordion>
  <Accordion title="Enconvo の支払いと AI の支払いは、どう違いますか？">
    ライセンスはアプリを使えるようにするものです。AI は、実行される場所で課金されます。Enconvo Cloud のポイント、プロバイダーのアカウント、またはお使いの Mac です。[プランと料金](/ja/pricing)を参照してください。
  </Accordion>
  <Accordion title="Enconvo を自分の言語で使えますか？">
    はい。ウクライナ語とロシア語を含む 12 のインターフェース言語から、**設定 → 一般 → 言語** の **アプリの言語** で選べます。エージェントは、同じ場所で設定する **応答言語** で返信します。[言語、外観、設定の検索](/ja/configuration/appearance-language)を参照してください。
  </Accordion>
  <Accordion title="機能を使うと、なぜ Enconvo が権限を求めてくるのですか？">
    Enconvo は、起動時には macOS の権限を求めません。権限が必要な機能を初めて使うときに、その機能名を示して確認します。機能からの確認を止めるには、**今後確認しない** にチェックを入れてください。[macOS の権限](/ja/configuration/permissions)を参照してください。
  </Accordion>
  <Accordion title="このドキュメントにある機能が、自分のアプリにありません。なぜですか？">
    一部の機能は、まずベータ版チャンネルに提供されます。お使いのバージョンと[更新チャンネル](/ja/configuration/updates)を確認し、[機能ディレクトリ](/ja/reference/feature-directory)でその機能を探してください。
  </Accordion>
</AccordionGroup>

## モデル

<AccordionGroup>
  <Accordion title="どのモデルを使えばよいですか？">
    迷う場合は、[Auto Route](/ja/providers/auto-route) のままにしてください。メッセージごとにモデルを選んでくれます。自分で選ぶ場合は、[モデルの選び方](/ja/ai/model-selection-guide)を参照してください。
  </Accordion>
  <Accordion title="デフォルトのモデルを変更したのに、チャットが以前のモデルのままなのはなぜですか？">
    チャットは、そのチャットで変更するまで、開始時のモデルを使い続けます。プロジェクトとエージェントにも、それぞれのデフォルトがあります。[モデルの選び方](/ja/ai/model-selection-guide)を参照してください。
  </Accordion>
  <Accordion title="ローカルモデルを使えば、すべてオフラインで完結しますか？">
    ローカルのプロバイダーで動作するステップだけです。ウェブ検索、リモートの MCP サーバー、クラウドの音声認識、クラウドの埋め込みでは、引き続き Mac の外にデータが送信されます。[ローカルモデル](/ja/ai/local-llm)と[プライバシーとセキュリティ](/ja/configuration/privacy-security)を参照してください。
  </Accordion>
</AccordionGroup>

## 音声

<AccordionGroup>
  <Accordion title="音声入力、音声コマンド、Live Talk の違いは何ですか？">
    [音声入力](/ja/features/dictation)は、話した内容を、使っているアプリに入力します。音声コマンドは、話した内容をリクエストとしてエージェントに送ります。[Live Talk](/ja/features/live-voice) は、エージェントとの音声による双方向の会話です。
  </Accordion>
  <Accordion title="Enconvo は会議を録音して文字起こしできますか？">
    はい。[会議の録音](/ja/features/meeting-recording)は、録音しながら文字起こしを行い、[文字起こし](/ja/features/transcription)は、すでに手元にある音声ファイルや動画ファイルに対して使えます。
  </Accordion>
</AccordionGroup>

## コンテキストとナレッジ

<AccordionGroup>
  <Accordion title="Appshots とクイックキャプチャの違いは何ですか？">
    [Appshots](/ja/features/appshots) は、見ているアプリのウィンドウを質問に添付します。[クイックキャプチャ](/ja/features/quick-capture)は、画面に表示されている内容を、あとで使うためにナレッジベースに保存します。
  </Accordion>
  <Accordion title="メモリとナレッジベースの違いは何ですか？">
    [メモリ](/ja/ai/memory)には、エージェントがあなたについて学び、再利用する事実が保存されます。[ナレッジベース](/ja/ai/knowledge-base)には、あなたが追加したドキュメントが保存され、エージェントはそこから回答を検索します。どちらもナレッジベースの中にあり、その列の上部にある **ナレッジベース** / **メモリ** のスイッチで切り替えます。
  </Accordion>
  <Accordion title="他の AI アプリから、Enconvo のナレッジベースを使えますか？">
    はい。[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) を通じて使えます。オンにして、選んだナレッジベースだけに限定します。
  </Accordion>
</AccordionGroup>

## エージェントと自動化

<AccordionGroup>
  <Accordion title="エージェントは、他のアプリやサービスのツールを使えますか？">
    はい。[プラグイン](/ja/extensions/overview)、[スキル](/ja/configuration/skills)、[MCP サーバー](/ja/features/mcp)を通じて使えます。許可すれば、エージェントはあなたの[ブラウザ](/ja/features/browser-control)や[アプリ](/ja/features/computer-use)も使えます。
  </Accordion>
  <Accordion title="エージェントのコマンドが触れる範囲を制限できますか？">
    はい。エージェントの **権限** チップで **サンドボックス** をオンにすると、そのコマンドが変更できるのは作業フォルダーと一時フォルダーだけになり、キーを読んだり他のアプリを操作したりできなくなります。[エージェントのサンドボックス](/ja/configuration/sandbox)を参照してください。
  </Accordion>
  <Accordion title="離れている間もタスクを実行できますか？">
    はい。[予約タスク](/ja/workflows/scheduled-jobs)は、Enconvo が起動していて Mac がスリープしていない間、スケジュールどおりに実行されます。[IM チャンネル](/ja/integrations/messaging)を接続すると、チャットアプリで結果を受け取れます。
  </Accordion>
</AccordionGroup>

## ヘルプ

<AccordionGroup>
  <Accordion title="問題はどこに報告すればよいですか？">
    Enconvo のバージョン、行った操作、起きたことを添えて [Discord](https://discord.gg/jYsdVRRK2k) で質問するか、メニューバーのメニューの **フィードバック** を使ってください。Enconvo Feedback では、**Apple で続ける** でサインインできます。スクリーンショットやログから、非公開の内容とキーを先に取り除いてください。[トラブルシューティング](/ja/getting-started/troubleshooting)を参照してください。
  </Accordion>
</AccordionGroup>

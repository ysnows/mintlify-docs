Enconvo の各ウィンドウや音声機能は、それぞれホットキーで開くことができます。**設定 → ショートカット** には Enconvo が使用するすべてのホットキーと実行されるコマンドが一覧表示されており、キーの変更や組み合わせの調査を行えます。Mac に保存されているホットキーは、このガイドに記載されたデフォルト設定より常に優先されます。

この動画では、ショートカットに加えて Enconvo を Mac に合わせるための設定（コンテキスト認識、Appshots、ローカルモデル、権限、スリープを防止）を解説しています。

## デフォルトのショートカット

| 操作 | デフォルト |
| --- | --- |
| SmartBar を表示 | **⌥Space** |
| チャットウィンドウを表示 | **⌃⌘X** |
| アプリのサイドバーを表示 | **⌃⌘E** |
| Enconvo 内から設定を開く | **⌘,** |
| 音声入力を開始 | **右 ⌘** |
| Voice Command を開始 | **右 ⌥** |
| 音声の一時停止 / 再開 | **⌥P** |

これらのデフォルトは、ご自身でキーを設定していない場合にのみ適用されます。自分で設定したキーはそのまま維持されます。Quick Capture と Appshots にはデフォルトのホットキーがないため、使う前にそれぞれの設定ページで設定してください。

## ホットキーを変更する

1. **設定 → ショートカット** を開きます。**主要機能** タブには主な機能が、**その他のホットキー** にはほかのページに表示されない AI コマンド・プラグイン・設定・コマンドが、**すべて** には両方が表示されます。
2. **名前で絞り込む…** に入力してコマンドを探します。特定のキーの組み合わせに割り当てられているコマンドを調べるには、**ホットキーで検索** をクリックしてそのキーを押します。
3. コマンドのホットキー欄をクリックし、新しいキーの組み合わせを押します。
4. そのキーがすでに別のコマンドに割り当てられている場合は案内が表示されます。**ここで使う** を選んでこのコマンドに割り当て直すか、提案される空いているホットキーから選びます。
5. 別のアプリに切り替えてホットキーを試します。

ホットキーの割り当てを解除するには、コマンドからキーを削除します。直後に表示されるメッセージの **元に戻す** で取り消すこともできます。

**ローカル** バッジが付いているホットキーは、Pin SmartBar など Enconvo 内部でのみ動作します。

## 押し方の設定

右 ⌘ のように修飾キーを単独で記録すると、欄に **押し方**（How to press it）の確認が表示されます。

| オプション | コマンドが実行されるタイミング |
| --- | --- |
| **長押しまたはタップ** | キーを長押しするか、タップして切り替えます |
| **タップ** | キーをタップして開始し、もう一度タップして停止します |
| **長押し** | キーを押し続けている間だけ動作します |
| **ダブルタップ** | キーを素早く 2 回タップします |

2 つ以上の修飾キーを同時に押した場合は 1 つのホットキーとして扱われます。各欄にはそのコマンドが対応している種類のみが表示され、横の説明にその機能の反応方法が書かれています。

## 各機能のホットキーの設定場所

ショートカットページ以外にも、各機能はそれぞれの設定ページにホットキー欄を持っています。

| 機能 | 設定ページ |
| --- | --- |
| SmartBar | **設定 → SmartBar** |
| Dynamic Island | **設定 → Dynamic Island** |
| PopBar | **設定 → PopBar** |
| アプリのサイドバー | **設定 → アプリのサイドバー** |
| 音声入力 | **設定 → 音声入力** |
| Voice Command | **設定 → Voice Command** |
| Appshots | **設定 → Appshots** |
| Screen Doodle | **設定 → Screen Doodle** |
| Voice Note | **設定 → Voice Note** |
| Quick Capture | **設定 → Quick Capture** |
| 個別のコマンド | **ホットキー** 欄がある場合はそのコマンドの設定 |

## SmartBar 内の操作

SmartBar でトリガー文字を入力すると、特定の種類の項目を検索できます。

| 文字 | 開く対象 |
| --- | --- |
| **@** | コマンド |
| **#** | メッセージに追加するコンテキスト |
| **$** | スキル |
| **>** | 最近のタスク |

これらの文字は **設定 → SmartBar** の **検索** で変更できます。スラッシュメニューには、モデルや推論の選択などの操作が含まれています。

キーボードで一覧を移動するには、**設定 → SmartBar** の **ナビゲーションキー** を選びます。**macOS** では **⌃N** **⌃P** **⌃F** **⌃B**、**Vim** では **⌃J** **⌃K** **⌃L** **⌃H** を使用します。

## Enconvo を Mac に合わせる

同じ設定ウィンドウには、動画で解説しているほかの項目も並んでいます。

| 設定ページ | 役割 |
| --- | --- |
| **コンテキスト認識** | 元のアプリから SmartBar が何を拾うかを選択します（選択テキスト、Finder の選択項目、ブラウザのページ）。**自動追加** は SmartBar を開いた瞬間に添付し、**提案** はワンクリックで追加できる候補として表示します。詳しくは[コンテキスト認識](/ja/features/context-awareness)をご覧ください。 |
| **Appshots** | ホットキーひとつで最前面のウィンドウを会話に追加します。詳しくは [Appshots](/ja/features/appshots) をご覧ください。 |
| **ローカルモデル** | この Mac 上で動作する AI、使用中のメモリとディスク容量、各機能の実行場所を表示します。詳しくは[ローカルモデル](/ja/ai/local-llm)をご覧ください。 |
| **権限** | macOS が Enconvo に許可している操作とその理由を一覧表示します。不足している場合は **許可** で修正できます。詳しくは [macOS の権限](/ja/configuration/permissions)をご覧ください。 |
| **スリープを防止** | 外出中にこの Mac がスリープしないようにし、iPhone から引き続き接続できるようにします。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| ホットキーが Enconvo 内でしか効かない | **ローカル** バッジが付いていないか確認してください。付いていない場合は、[macOS の権限](/ja/configuration/permissions)で入力監視とアクセシビリティを確認し、ほかのアプリが同じキーを使っていないか調べてください。 |
| ホットキーを押すと別の動作になる | **ホットキーで検索** を使ってください。Enconvo のコマンドで使われていない場合は、ほかのアプリまたは macOS がそのキーを使用しています。 |
| 修飾キーのホットキーが反応しない | ホットキーを開いて **押し方**（長押し、タップ、ダブルタップ、同時押し）を確認してください。 |
| 動画や別の Mac で使っていたショートカットが効かない | お使いの環境のホットキーが異なっている可能性があります。**設定 → ショートカット** で現在の設定を確認してください。 |

Enconvo のウィンドウと音声機能は、それぞれホットキーで開きます。**設定 → ショートカット** には、Enconvo が使うすべてのホットキーと、それが実行するコマンドが一覧表示されるので、ホットキーを変更したり、キーの組み合わせが何をするのかを調べたりできます。Mac に保存されているホットキーは、このガイドのデフォルトよりも常に優先されます。

この動画では、ショートカットに続いて、Enconvo を Mac になじませるその他の設定を紹介します。コンテキスト認識、Appshots、ローカルモデル、権限、スリープを防止です。

## デフォルトのショートカット

| 操作 | デフォルト |
| --- | --- |
| SmartBar を表示 | **⌥Space** |
| チャットウィンドウを表示 | **⌃⌘X** |
| アプリのサイドバーを表示 | **⌃⌘E** |
| 設定を開く（Enconvo 内から） | **⌘,** |
| 音声入力を開始 | **右の ⌘** |
| 音声コマンドを開始 | **右の ⌥** |
| 音声の一時停止/再開 | **⌥P** |

これらのデフォルトは、自分でキーを設定したことがない場合にのみ適用されます。設定したキーはそのまま維持されます。クイックキャプチャと Appshots にはデフォルトのホットキーがないため、使う前にそれぞれの設定ページで設定してください。

## ホットキーを変更する

1. **設定 → ショートカット** を開きます。**主要機能** タブには主な機能、**その他のホットキー** タブには AI コマンド、プラグイン、設定、ほかのページに表示されないコマンドがあり、**すべて** では両方が表示されます。
2. **名前で絞り込む…** に入力して、コマンドを探します。キーの組み合わせから該当するコマンドを探すには、**ホットキーで検索** をクリックして、そのキーを押します。
3. コマンドのホットキーのフィールドをクリックして、新しい組み合わせを押します。
4. そのキーがすでに別のコマンドで使われている場合は、フィールドに表示されます。**ここで使う** を選ぶと、そのキーがこのコマンドに移ります。または、提案される空いているホットキーから選ぶこともできます。
5. 別のアプリに切り替えて、ホットキーを試します。

ホットキーのキーを空けるには、コマンドからそのホットキーを削除します。**元に戻す** が表示されるメッセージから、取り消すことができます。

**ローカル** バッジは、SmartBar を固定のように、Enconvo の中でのみ動作するホットキーを示します。

## 押し方

右の ⌘ のように、修飾キーを単独で記録すると、フィールドに **押し方** が表示されます。

| オプション | コマンドが実行されるタイミング |
| --- | --- |
| **長押しまたはタップ** | キーを長押しするか、タップして切り替える |
| **タップ** | キーをタップして開始し、もう一度タップして停止する |
| **長押し** | キーを押し続ける。押している間だけ動作する |
| **ダブルタップ** | キーをすばやく 2 回タップする |

2 つ以上の修飾キーを同時に押した場合は、1 つのホットキーとして扱われます。各フィールドには、そのコマンドが対応する種類だけが表示され、横の説明には、その機能がどう反応するかが書かれています。

## 各機能のホットキーの場所

ショートカットページのほかに、各機能のホットキーは、その機能自身の設定ページにもあります。

| 機能 | 設定ページ |
| --- | --- |
| SmartBar | **設定 → SmartBar** |
| Dynamic Island | **設定 → Dynamic Island** |
| PopBar | **設定 → PopBar** |
| アプリのサイドバー | **設定 → アプリのサイドバー** |
| 音声入力 | **設定 → 音声入力** |
| 音声コマンド | **設定 → 音声コマンド** |
| Appshots | **設定 → Appshots** |
| 画面に描画 | **設定 → 画面に描画** |
| 音声メモ | **設定 → 音声メモ** |
| クイックキャプチャ | **設定 → クイックキャプチャ** |
| 個別のコマンド | **ホットキー** フィールドがある場合は、そのコマンドの設定 |

## SmartBar の中で

SmartBar でトリガー文字を入力すると、1 種類の項目を検索できます。

| 文字 | 開くもの |
| --- | --- |
| **@** | コマンド |
| **#** | メッセージに追加するコンテキスト |
| **$** | スキル |
| **>** | 最近のタスク |

これらの文字は、**設定 → SmartBar** の **検索** で変更できます。スラッシュメニューには、モデルや推論の選択などの操作があります。

キーボードでリストを移動するには、**設定 → SmartBar** で **ナビゲーションキー** を選びます。**macOS** では **⌃N** **⌃P** **⌃F** **⌃B**、**Vim** では **⌃J** **⌃K** **⌃L** **⌃H** を使います。

## Enconvo を Mac になじませる

同じ設定ウィンドウに、動画で紹介しているその他の選択肢があります。

| 設定ページ | できること |
| --- | --- |
| **コンテキスト認識** | 直前に使っていたアプリから SmartBar が取得するものを選びます。選択したテキスト、Finder の選択、ブラウザのページです。**自動追加** は SmartBar が開いた時点で追加し、**提案** はワンクリックで追加できるように提示します。[コンテキスト認識](/ja/features/context-awareness) を参照してください。 |
| **Appshots** | ホットキーで、前面のウィンドウを会話に追加します。[Appshots](/ja/features/appshots) を参照してください。 |
| **ローカルモデル** | この Mac 上で動作している AI、使用しているメモリとディスク、各機能がどこで動いているかを表示します。[ローカルモデル](/ja/ai/local-llm) を参照してください。 |
| **権限** | macOS が Enconvo に許可していることとその理由を一覧表示します。**許可** で、足りない権限を補えます。[macOS の権限](/ja/configuration/permissions) を参照してください。 |
| **スリープを防止** | 離れている間、この Mac がスリープしないようにして、iPhone から引き続きアクセスできるようにします。 |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| ホットキーが Enconvo の中でしか動かない | **ローカル** バッジがあるか確認してください。ない場合は、[macOS の権限](/ja/configuration/permissions) で入力監視とアクセシビリティを確認し、他のアプリが同じキーを使っていないか確認してください。 |
| ホットキーを押すと別のことが起こる | **ホットキーで検索** を使ってください。そのキーを使う Enconvo のコマンドがない場合は、他のアプリか macOS が使っています。 |
| 修飾キーのホットキーが反応しない | ホットキーを開いて **押し方** を確認してください。長押し、タップ、ダブルタップ、同時押しのどれかです。 |
| 動画や別の Mac のショートカットが動かない | ホットキーが異なっている可能性があります。**設定 → ショートカット** で現在のホットキーを確認してください。 |

---
title: "macOS の権限"
description: "Enconvo が使う macOS の権限を確認し、機能に必要な権限を許可して、キャプチャや入力が動かなくなったときに対処します。"
---

Enconvo の機能の中には、画面の表示や他のアプリへの入力など、macOS での承認が必要なアクセスを使うものがあります。**設定 → 権限** には、各権限、その権限で動く機能、許可されているかどうかが一覧で表示されます。テキストチャットにはどの権限も必要ないため、Enconvo は起動時には確認せず、権限が必要な機能を初めて使うときに、どの機能が求めているかを示して確認します。

## Enconvo が確認するタイミング

許可していない権限が必要な機能を使うと、Enconvo は権限ウィンドウを開き、機能名を示して **システム設定を開く** を表示します。**今はしない** を選ぶこともできます。

機能からの確認を止めるには、ウィンドウで、その機能の **今後確認しない** にチェックを入れます。以後、その機能は、権限ページで変更するまで確認しなくなります。画面収録については、アクセスが再起動待ちの場合、ウィンドウに **再起動** が表示されます。

## 権限を許可する

1. **設定 → 権限** を開きます。
2. 権限を見つけて **許可** をクリックします。
3. macOS がプロンプトを表示するか、**システム設定 → プライバシーとセキュリティ** の該当するペインが開きます。アクセシビリティと入力監視では、そのペインで Enconvo のスイッチを自分でオンにします。
4. macOS から求められたら、Enconvo を終了してもう一度開きます。
5. Enconvo に戻ると、その行に **許可済み** と表示されます。もう一度その機能を試します。

このページは、戻ってきたときに自動でもう一度確認します。すぐに確認するには **更新** をクリックします。

## 権限を使う機能を確認する

各権限の下にある **利用元** には、その権限を必要とする機能と、それぞれが確認を行うかどうかが表示されます。

| 状態 | 意味 |
| --- | --- |
| **使うときに確認** | 次にその機能を使うときに、権限の確認が行われます。 |
| **拒否済み · ホットキーで確認** | 拒否した状態です。その機能のホットキーを押したときにだけ、もう一度確認します。 |
| **確認しない** | **今後確認しない** を選んだ状態です。クリックすると **使うときに確認** に戻ります。 |
| **オフ** または **プラグインはオフ** | その機能、またはその機能が属するプラグインがオフになっています。 |

## 各権限の用途

| 権限 | 用途 |
| --- | --- |
| アクセシビリティ | アプリのインターフェースの読み取り、クリック、入力、ウィンドウの操作。コンピューター操作、PopBar、選択したテキスト、テキストの挿入で使います |
| 画面収録 | エージェントがアプリの内容を見るためのスクリーンショット。コンピューター操作、Appshots、画面コンテキスト、OCR キャプチャで使います。macOS では「画面とシステムオーディオの録画」と表示されることがあり、システム音声のキャプチャも含まれます。 |
| 入力監視 | 他のアプリが前面にあるときの、PopBar、ホットキー、修飾キーのダブル操作のためのグローバルなキーボード入力 |
| マイク | 音声入力、音声コマンド、音声メモ、会議の録音、リアルタイム字幕、Live Talk |
| 通知 | エージェントのセッションが完了したときや、確認が必要なときの macOS 通知 |
| カメラ | SmartBar のカメラ切り替えで撮るライブ写真 |
| 位置情報 | Dynamic Island での地域の天気と、エージェント向けの位置情報コンテキスト |
| オートメーション | Apple イベントによる他のアプリの操作。ブラウザのタブ、Finder の選択、メール、メッセージ、System Events の読み取りに使います |
| ローカルネットワーク | ネットワーク内の別のコンピューター上にあるモデルサーバーへの接続。権限ページにはありません。**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で設定します。 |

カレンダー、リマインダー、メモ、メール、その他の Apple アプリは、代わりに **プラグイン** ページで接続します。[Apple アプリ](/ja/integrations/apple-ecosystem) を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 権限はオンなのに、キャプチャが失敗する | Enconvo を終了してもう一度開き、再度試してください。古いコピーではなく、実行中の Enconvo アプリをオンにしているか確認してください。 |
| 機能が必要な権限を確認してこない | **利用元** の下の、その機能の行を確認してください。**確認しない** と表示されている場合は、それをクリックするか、**許可** で権限を許可してください。 |
| 画面収録が許可済みと表示されているのに、キャプチャが失敗する | 権限ウィンドウで **再起動** をクリックするか、Enconvo を終了してもう一度開いてください。 |
| 音声入力でテキストは表示されるが、挿入されない | アクセシビリティを確認し、対象のフィールドが入力または貼り付けを受け付けるか確認してください。 |
| ホットキーが Enconvo の中でしか動かない | 入力監視とアクセシビリティを確認してください。他のアプリとキーが重なる場合は、[キーボードショートカット](/ja/configuration/keyboard-shortcuts) を参照してください。 |
| 別のコンピューター上のモデルサーバーに接続できない | ローカルネットワークを確認し、サーバーがネットワークアドレスで待ち受けているか確認してください。 |
| エージェントが完了してもバナーが表示されない | ここで通知を確認し、macOS の集中モードと、[通知](/ja/configuration/notifications) の **システム通知を送信** も確認してください。 |

---
title: "macOS の権限"
description: "Enconvo が使用する macOS の権限を確認し、機能に必要な権限を許可して、キャプチャや入力が動作しない問題を解決します。"
---

Enconvo の一部の機能では、画面の内容を読み取ったり、ほかのアプリへ文字を入力したりするため、macOS によるアクセス許可が必要です。**設定 → 権限** には、各権限の一覧、利用する機能、許可済みかどうかが表示されます。テキストチャットにはこれらの権限は不要なため、Enconvo は起動時に一括で許可を求めません。権限を必要とする機能を初めて使ったときに、どの機能が求めているかを明示して許可を求めます。

## Enconvo が確認を求めるとき

未許可の権限を必要とする機能を使うと、Enconvo は権限ウィンドウを開き、機能名を表示して **システム設定を開く** を案内します。**今はしない** を選ぶこともできます。

その機能からの確認を止めたい場合は、ウィンドウ内でその機能の **今後は確認しない** にチェックを入れてください。権限ページで設定を変更するまで、その機能は確認を求めなくなります。画面収録について、再起動のみで有効になる場合はウィンドウに **再起動** が表示されます。

## 権限を許可する

1. **設定 → 権限** を開きます。
2. 対象の権限を見つけ、**許可** をクリックします。
3. macOS の確認ダイアログが表示されるか、**システム設定 → プライバシーとセキュリティ** の該当ペインが開きます。アクセシビリティと入力監視については、そのペインでご自身で Enconvo のスイッチをオンにしてください。
4. macOS から求められた場合は、Enconvo を終了して開き直します。
5. Enconvo に戻ると、その行が **許可済み** になっています。機能をもう一度試してください。

権限ページに戻ると状態は自動的に再確認されます。すぐに確認したい場合は **更新** をクリックしてください。

## どの機能が権限を使うか確認する

各権限の下の **利用元** には、その権限を必要とする機能と、確認を求めるかどうかが表示されます。

| 状態 | 意味 |
| --- | --- |
| **使うときに確認** | 次回その機能を使ったときに権限の許可を求めます。 |
| **拒否済み · ホットキー押下時に確認** | 許可を拒否しました。ホットキーを押したときにのみ再度確認します。 |
| **確認しない** | **今後は確認しない** を選択した状態です。クリックすると **使うときに確認** に戻ります。 |
| **オフ** または **プラグインがオフ** | その機能、または所属するプラグインがオフになっています。 |

## 各権限の用途

| 権限 | 用途 |
| --- | --- |
| アクセシビリティ | アプリの UI の読み取り、クリック、入力、ウィンドウ操作：コンピュータ操作、PopBar、選択テキストの取得、テキストの挿入 |
| 画面収録 | Agent がアプリの内容を見るためのスクリーンショット：コンピュータ操作、Appshots、画面コンテキスト、OCR キャプチャ。macOS 上では「画面収録とシステムオーディオ録音」と表示される場合があり、システムオーディオのキャプチャも対象に含まれます。 |
| 入力監視 | ほかのアプリが前面にあるときの、PopBar、ホットキー、修飾キーの 2 回押しトリガーに対するグローバルキーボード入力 |
| マイク | 音声入力、Voice Command、Voice Note、ミーティング録音、リアルタイム字幕、Live Talk |
| 通知 | Agent セッションの完了時や操作が必要なときの macOS 通知 |
| カメラ | SmartBar のカメラ切り替えからのライブカメラ撮影 |
| 位置情報 | Dynamic Island での現在地の天気や、Agent に渡す位置情報コンテキスト |
| オートメーション | Apple Events を使ったほかのアプリの操作：ブラウザのタブ、Finder の選択項目、メール、メッセージ、System Events の読み取り |
| ローカルネットワーク | ネットワーク内の別コンピュータ上のモデルサーバーへの接続。権限ページには表示されないため、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で設定してください。 |

カレンダー、リマインダー、メモ、メールなどの Apple アプリは、代わりに **プラグイン** ページから接続します。詳しくは [Apple アプリ](/ja/integrations/apple-ecosystem)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 権限がオンなのにキャプチャが失敗する | Enconvo を終了して開き直し、もう一度試してください。古いコピーではなく、現在実行中の Enconvo アプリのスイッチがオンになっているか確認してください。 |
| 機能が必要な権限の確認を出さない | **利用元** の該当行を確認してください。**確認しない** になっている場合はクリックして戻すか、**許可** から権限を付与してください。 |
| 画面収録が許可済みと表示されているのにキャプチャが失敗する | 権限ウィンドウの **再起動** をクリックするか、Enconvo を終了して開き直してください。 |
| 音声入力で文字は出るが挿入されない | アクセシビリティ権限を確認し、入力先のフィールドが文字入力やペーストを受け付けるか確認してください。 |
| ホットキーが Enconvo 内でしか効かない | 入力監視とアクセシビリティを確認してください。ほかのアプリとの競合については[キーボードショートカット](/ja/configuration/keyboard-shortcuts)をご覧ください。 |
| 別コンピュータのモデルサーバーに接続できない | ローカルネットワーク権限と、サーバーがネットワークアドレスで待ち受けているかを確認してください。 |
| Agent 完了時にバナーが表示されない | ここの通知権限、macOS の集中モード、および[通知](/ja/configuration/notifications)の **システム通知を送信** を確認してください。 |

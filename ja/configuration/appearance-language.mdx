description: "Enconvo のインターフェース言語を選び、コントラストとチャットの幅を調整し、検索や AI への質問であらゆる設定を見つけます。"
---

**設定 → 一般** には、Enconvo の見た目と使用する言語を変える項目があります。このページでは、インターフェース言語の切り替え、Enconvo を読みやすくする方法、場所を知らなくても設定を見つける方法を説明します。

## インターフェース言語を変更する

1. **設定 → 一般** を開き、**言語** を探します。
2. **アプリの言語** で言語を選びます。**システムの設定に従う** を選ぶと、Mac の言語が使われます。
3. Enconvo が、**応答言語** も同じ言語に変更するか確認します。エージェントにも新しい言語で返信してほしい場合は、承諾してください。

**アプリの言語** は、このデバイスのメニュー、ボタン、設定の言語を変更します。対応言語は、英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、ウクライナ語、ロシア語です。iPhone アプリと Android アプリでも、それぞれの設定で同じ言語を選べます。

**応答言語** は別の設定です。エージェント、音声通話、アバターはこの言語で返答し、翻訳ではこの言語に翻訳されます。

## Enconvo の外観を調整する

**設定 → 一般** を開き、**外観** を探します。

| 設定 | 変更される内容 |
| --- | --- |
| **コントラスト** | Enconvo 全体の境界線、区切り線、補助テキストを強くしたり弱くしたりします。 |
| **チャットの幅** | 大きなウィンドウでメッセージと入力欄が広がる幅です。**標準**、**広い**、**全幅** から選びます。 |
| **コードを折り返す** | コードブロックの長い行を、横スクロールではなく折り返して表示します。 |

## 設定を見つける

設定のサイドバーの上部にある検索フィールドに入力します。入力するにつれて一致する設定が表示されるので、クリックするとその設定に移動します。

代わりに、設定について質問することもできます。

1. 検索フィールドに質問を入力して Return キーを押すか、**AI に質問** をクリックします。
2. サイドバーの横に回答が開き、言及された設定がカードで表示されます。
3. カードの **設定で表示** をクリックするとその設定に移動します。カード内でスイッチをオンまたはオフにすることもできます。
4. **追加で質問…** にフォローアップの質問を入力するか、**チャットで続ける** をクリックして、チャットウィンドウで続けます。

AI に質問では、デフォルトの AI モデルが使われます。何も設定されていない場合は、**AI モデルの設定を開く** が表示されます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 言語を切り替えたあとも、一部のテキストが英語のまま | Enconvo を更新し、残っている箇所を、メニューバーのメニューにある **フィードバック** から報告してください。 |
| エージェントの返信が、インターフェースと違う言語になる | **設定 → 一般 → 言語** で **応答言語** を設定してください。 |
| AI に質問が回答しない | **設定 → AI モデル** でモデルを設定してください。 |
| テキストが読みにくい | **設定 → 一般 → 外観** で **コントラスト** を上げてください。 |

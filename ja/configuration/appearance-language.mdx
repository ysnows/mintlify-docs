**設定 → 一般** には、Enconvo の見た目や話す言語を変更する項目がまとまっています。画面言語の切り替え、読みやすさの調整、場所がわからない設定の検索にこのページを活用してください。

## 画面表示の言語を変更する

1. **設定 → 一般** を開いて **言語** を見つけます。
2. **アプリの言語** で言語を選択します。**システムの設定に従う** は Mac の言語設定を使用します。
3. 合わせて **応答言語** も変更するかどうか確認が表示されます。エージェントにも新しい言語で返答させたい場合は承諾してください。

**アプリの言語** はこの端末のメニュー、ボタン、設定項目の表示言語を切り替えます（英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、ウクライナ語、ロシア語に対応）。iPhone アプリと Android アプリでも、それぞれの設定で同じ言語を選べます。

**応答言語** はこれとは別です。エージェント、音声通話、アバターはこの言語で応答し、翻訳機能もこの言語へ翻訳します。

## Enconvo の見た目を調整する

**設定 → 一般** を開いて **外観** を見つけます。

| 設定 | 変更される内容 |
| --- | --- |
| **コントラスト** | Enconvo 全体の境界線、区切り線、補助テキストをはっきりさせたり柔らかくしたりします。 |
| **チャットの幅** | 大きなウィンドウでメッセージと入力欄が広がる幅です：**標準**、**広い**、**全幅**。 |
| **コードを折り返す** | コードブロックの長い行を横スクロールではなく折り返して表示します。 |

## 設定を探す

設定サイドバー上部の検索欄に入力します。入力に合わせて一致する設定が表示され、クリックするとその設定へ移動できます。

設定について AI に質問したい場合は：

1. 検索欄に質問を入力し、Return キーを押すか **AI に質問** をクリックします。
2. サイドバーの横に回答が開き、関連する設定のカードが表示されます。
3. カードの **設定で表示** をクリックするとその設定画面へ移動でき、スイッチがあればカード上から直接オン・オフを切り替えられます。
4. 続けて質問するには **追加で質問…** に入力するか、**チャットで続ける** をクリックしてチャットウィンドウで会話を続けます。

「AI に質問」はデフォルトの AI モデルを使用します。まだモデルが設定されていない場合は **AI モデルの設定を開く** が表示されます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 言語を切り替えたあとも一部が英語のまま残る | Enconvo をアップデートし、残っている箇所があればメニューバーメニューの **フィードバック** から報告してください。 |
| エージェントが画面の言語と違う言語で返答する | **設定 → 一般 → 言語** で **応答言語** を設定してください。 |
| **AI に質問** が応答しない | **設定 → AI モデル** でモデルを設定してください。 |
| 文字が読みにくい | **設定 → 一般 → 外観** で **コントラスト** を上げてください。 |

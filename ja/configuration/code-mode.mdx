---
title: "コードモード"
description: "多数のツール呼び出しを一度に実行する短いスクリプトを Agent に書かせ、最終結果だけを読み込ませます。"
---

コードモードを使うと、通常なら何度もやり取りが必要な作業を Agent が 1 ステップで実行できます。複数のツール呼び出しを並列または順に行う短いスクリプトを書き、最終結果だけを受け取ります。ページ一覧の確認や複数サービスからの結果収集など、同じ呼び出しを多数の項目に対して繰り返すタスクで使うと、処理が速くなり、途中の結果でチャットが埋め尽くされるのを防げます。

コードモードをユーザー自身が直接呼び出す必要はありません。オンになっていれば、適したタスクの際に Agent が自動的に使用し、スクリプトが行った呼び出し内容を示すカードがチャットに表示されます。

## コードモードを設定する

1. **設定 → コードモード** を開きます。プラグインページの **組み込み** タブから **コードモード** を開くこともできます。
2. **スクリプトのアクセス** で、スクリプトに呼び出しを許可する項目をオンにします。各呼び出しはチャットの[権限モード](/ja/ai/agents)に従って確認を求めます。
3. どのモデルにスクリプト作成を許可するか、チャットに何を表示するか、スクリプトの実行が長引いたときの挙動を選択します。

## 設定項目

**スクリプトのアクセス** には、スクリプトが呼び出せる対象が並びます。

| アクセス対象 | 許可される操作 | デフォルト |
| --- | --- | --- |
| **プラグイン** | 検索、ナレッジベース、ドキュメントなどのプラグインルート | オン |
| **コネクタと MCP** | 連携済みのアカウントおよび MCP ツール | オン |
| **ファイル** | ファイルの読み取りと書き込み | オン |
| **シェルコマンド** | ターミナルでのコマンド実行 | オン |
| **ブラウザ** | お使いのブラウザでの[ブラウザ操作](/ja/features/browser-control) | オン |
| **アプリ** | アプリへのアクセス一覧の範囲内での[コンピュータ操作](/ja/features/computer-use) | オン |
| **ほかのエージェント** | サブエージェントの起動やメッセージ送信 | オフ |
| **モデル呼び出し** | 項目の要約や判定を行う小型モデルの呼び出し | オン |

その他のオプション：

| オプション | 選択肢 |
| --- | --- |
| **使用するモデル** | **コード作成が得意なモデル**（それ以外のモデルは 1 つずつ呼び出します）、または **すべてのモデル**。 |
| **チャットでの表示** | **呼び出しのみ**、または **呼び出しとコード**。 |
| **スクリプトの実行が長引いた場合** | バックグラウンドで **最大 2 時間まで続行**、または **10 分後に停止**。 |

## チャット外でのコードモード

予約タスクなどチャットの外でスクリプトが実行される場合は、組み込みの検索や読み取り、公開ウェブページ、通常のファイル、変更を行わないことを示す MCP ツールなど、読み取り専用のツールのみを呼び出します。Enconvo は実行直前に各呼び出しを再度チェックします。

## スキルでスクリプトを使う

スキルは専用の `scripts` フォルダ内にコードモード用スクリプトを保持し、ステップの 1 つとして実行できます。詳しくは[スキル](/ja/configuration/skills)をご覧ください。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| Agent がツールを 1 つずつ呼び出す | **使用するモデル** を確認してください。**コード作成が得意なモデル** が選ばれている場合、それ以外のモデルはコードモードを使用しません。 |
| スクリプトがツールにアクセスできない | **スクリプトのアクセス** で該当するアクセスをオンにしてください。チャット外ではスクリプトは読み取りのみ可能です。 |
| 長時間実行しているスクリプトが止まった | **10 分後に停止** になっていると長いスクリプトは終了します。**最大 2 時間まで続行** を選択してください。 |

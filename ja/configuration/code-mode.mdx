---
title: "コードモード"
description: "エージェントに、多くのツール呼び出しを一度に行い、結果だけを読み取る短いスクリプトを書かせます。"
---

コードモードを使うと、エージェントは通常なら何ステップもかかる作業を 1 ステップで行えます。多くのツール呼び出しを並行して、または順番に行う短いスクリプトを書き、結果だけを読み取ります。ページの一覧を確認する、複数のサービスから結果を集めるなど、同じ呼び出しを多数の項目に繰り返すタスクで使うと、作業が速くなり、途中の結果すべてでチャットがいっぱいになることもありません。

コードモードを自分で呼び出す必要はありません。オンにしておくと、エージェントはタスクに合うときに自動で使い、チャットにはスクリプトが行った呼び出しのカードが表示されます。

## コードモードを設定する

1. **設定 → コードモード**を開きます。プラグインのページの**組み込み**タブから**コードモード**を開くこともできます。
2. **スクリプトのアクセス**で、スクリプトが呼び出せるものをオンにします。各呼び出しは、チャットの[権限モード](/ja/ai/agents)に従って、引き続きあなたに確認します。
3. スクリプトを書けるモデル、チャットに表示する内容、スクリプトが長引いたときの動作を選びます。

## 設定

**スクリプトのアクセス**には、スクリプトが呼び出せるものが一覧されます。

| アクセス | 許可される内容 | 初期設定 |
| --- | --- | --- |
| **プラグイン** | 検索、ナレッジベース、ドキュメント、そのほかのプラグインのルート | オン |
| **Connector と MCP** | リンクしたアカウントと MCP ツール | オン |
| **ファイル** | ファイルの読み取りと書き込み | オン |
| **シェルコマンド** | ターミナルでのコマンドの実行 | オン |
| **ブラウザ** | お使いのブラウザでの[ブラウザ操作](/ja/features/browser-control) | オン |
| **アプリ** | アプリアクセスの一覧の範囲内での[コンピューター操作](/ja/features/computer-use) | オン |
| **ほかのエージェント** | サブエージェントの起動やメッセージの送信 | オフ |
| **モデル呼び出し** | 項目の要約や判断のための小さなモデル | オン |

そのほかのオプションは次のとおりです。

| オプション | 選択肢 |
| --- | --- |
| **使うモデル** | **コードに強いモデル**（それ以外のモデルは呼び出しを 1 つずつ行います）、または**すべてのモデル**。 |
| **チャットに表示** | **呼び出し**、または**呼び出しとコード**。 |
| **スクリプトが長引くとき** | バックグラウンドで**最大 2 時間まで続ける**、または **10 分後に停止**。 |

## チャット以外でのコードモード

予約タスクなど、チャット以外でスクリプトを実行する場合、呼び出せるのは読み取り専用のツールだけです。組み込みの検索と読み取り、公開されている Web ページ、通常のファイル、何かを変更するとは明記されていない MCP ツールが対象です。Enconvo は、各呼び出しを実行する直前に、もう一度確認します。

## スキルでスクリプトを使う

スキルは、コードモードのスクリプトを自分の `scripts` フォルダに保持して、ステップの 1 つとして実行できます。[スキル](/ja/configuration/skills)をご覧ください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| エージェントが呼び出しを 1 つずつ行う | **使うモデル**を確認してください。**コードに強いモデル**では、それ以外のモデルはコードモードを使いません。 |
| スクリプトがツールにアクセスできない | **スクリプトのアクセス**で、その種類のアクセスをオンにしてください。チャット以外では、スクリプトは読み取りのみです。 |
| 長いスクリプトが停止した | **10 分後に停止**では、それより長いスクリプトは終了します。**最大 2 時間まで続ける**を選んでください。 |

Enconvo はデータをあなたの Mac 上に保存し、あなたが選択した機能やプロバイダーに対してのみオンラインサービスを利用します。リクエストがどこへ送信されるかは、機能、選択したプロバイダー、有効にしたツール、接続した連携サービスによって決まります。このページでは各データの流れと管理方法を説明します。

## コンテンツの送信先

| 操作 | 送信される内容と送信先 |
| --- | --- |
| クラウド AI チャット | プロンプト、会話のコンテキスト、追加した添付ファイルをモデルプロバイダーへ送信 |
| Enconvo Cloud コンテンツチェック（2026 年 11 月 14 日以降） | 入力したばかりのテキストを、クラウドモデルへ送る前に OpenAI のモデレーションモデルへ送信 |
| クラウド音声認識 | 収録した音声を、選択した音声認識サービスへ送信 |
| クラウド音声合成 | テキストを、選択した音声合成サービスへ送信 |
| クラウド埋め込み（Embeddings）またはリランキング | 検索に必要なドキュメントとクエリの内容 |
| Web 検索または Web 取得 | 検索クエリまたは URL を、検索サービスまたはウェブサイトへ送信 |
| ローカルモデル推論 | Mac 内に留まります：モデルファイルをダウンロードした後はローカルで実行されます |
| ブラウザまたはコンピューターツール | ツールに付与されたアクセス権の範囲内のコンテンツと操作 |
| メッセージングチャネル | 接続されたメッセージングサービスとエージェント間のメッセージ |
| 同期 | 同期をオンにすると、チャット、設定、ナレッジベース、成果物が Enconvo アカウントまたは iCloud へ送信されます。API キーは暗号化をオンにした場合のみ、暗号化された状態で Mac から送信されます。 |

ローカルチャットモデルを使うだけでは、すべてのツールがオフラインになるわけではありません。Web 検索、リモート MCP ツール、クラウド文字起こしプロバイダー、クラウド埋め込みモデルなどは引き続きネットワーク経由でデータを送信します。

## Enconvo Cloud の利用ルール

2026 年 11 月 14 日以降、Enconvo Cloud は各メッセージをクラウドモデルへ渡す前に[利用規約](https://www.enconvo.com/terms)に照らして確認します。チェックされるのは入力したばかりのテキストのみで、過去の会話、ファイル、画像はチェックされません。ご自身の API キーやローカルモデルを使用する場合はこれまでと変わりません。

- **保存される内容：** メッセージが拒否またはフラグ付けされた場合、Enconvo はアカウント、時刻、モデル、スコアを最大 90 日間保持しますが、文章そのものは一切保存しません。
- **拒否されたメッセージ：** モデルへは送信されず、ポイントも消費されません。チャット上に理由が表示されます。
- **繰り返しの拒否：** 拒否が続くとアカウントのクラウド AI 利用が一時停止される場合があります。その間もサインイン、サブスクリプションの管理・キャンセル、アカウント削除は行えます。サブスクリプションはキャンセルするまで継続します。
- **誤判定と思われる場合：** support@enconvo.com までご連絡ください。

プロバイダー側の安全措置が全ユーザーではなく該当アカウントのみに適用されるよう、Enconvo Cloud はリクエストごとにアカウントから生成した一方向の識別子も OpenAI と Anthropic に送信します。これはメールアドレスではありません。詳しくは[プライバシーポリシー](https://www.enconvo.com/privacy)をご覧ください。

## 送信内容を管理する

リクエストを送信する前に、添付ファイルやコンテキストを確認してください。Appshots、スクリーンショット、選択したテキスト、クリップボードの内容、ブラウザのページには、質問したい一文以上の情報が含まれている場合があります。

使用するコンテキストソースは[コンテキスト認識](/ja/features/context-awareness)で選択できます。[macOS の権限](/ja/configuration/permissions)は使う機能にだけ許可し、不要になったらシステム設定で取り消してください。

## 認証情報

API キーやアカウントのサインインは、各プロバイダーの **認証** セクションおよび[認証情報の管理](/ja/configuration/credentials)で管理します。ローカルの Enconvo 設定、バックアップ、書き出した設定、サポートログは機密情報として扱い、プロンプト、スクリーンショット、共有ファイルにキーやアカウントトークンを含めないようにしてください。

1 つのプロバイダープロファイルが複数の機能で認証情報を共有している場合があります。プロファイルを削除または置き換える前に、それを使用している機能をすべて確認してください。

<Warning>
Enconvo からキーを削除しても、キー自体は無効化されません。キーが漏洩した場合は、プロバイダーのサイト上で取り消してください。
</Warning>

## ツールと連携機能

エージェントは有効にされたツールを通じて操作を実行できます。ブラウザ操作、コンピューター操作、シェルコマンド、ファイル編集、Gmail、外部 MCP サーバーはそれぞれ異なる領域にアクセスします。重要なデータを扱う際は、エージェントのツールと提案された操作内容を確認してください。

拡張機能が独立したワーカーで実行されていても、ローカルファイルやネットワークへのアクセスが止まるわけではありません。ツールは信頼できる提供元からのみインストールし、設定を確認してください。

チャット内の **権限** チップによって、エージェントが操作前に確認を求めるかどうかが決まります。**フルアクセス** では確認なしで実行され（友だちやチームメンバーへの通話やメッセージ送信も含まれます）、コンピュータに損害を与え得る変更の前だけ確認を求めます。[コマンド前に Enconvo が確認を求める理由](/ja/configuration/sandbox)を参照してください。

エージェントのシェルコマンドを作業フォルダ内に制限し、キーや保存済み認証情報、他のアプリから隔離するには、**サンドボックス** をオンにしてください。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。コンピューター操作から特定のアプリを除外するには、**設定 → コンピューター操作** の **アプリへのアクセス** を使います。[コンピューター操作](/ja/features/computer-use)を参照してください。

Web Fetch は公開ページによってあなたの Mac やローカルネットワークへリダイレクトされることはありません。

## サインインリンク

ウェブページ上のサインインリンクが、Enconvo のアカウントを勝手に切り替えることはありません。Enconvo 自身が開始したサインインでない限り、まず確認を求め、そのリンクが認証するアカウントと置き換えられるアカウントを表示します。エージェント、コーディングエージェント、スケジュールされたタスクはサインインを開始したりサインインリンクを開いたりできません。

## ローカル AI クライアント

[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) はオンにするまで無効になっており、ローカル接続のみを受け付けます。公開スイッチでどのナレッジベースを公開するかを選べます。ローカルクライアントは取得した内容を自身の AI プロバイダーへ送信する場合があるため、クライアント側の設定にも注意してください。

## 分析と診断

Enconvo は製品の使用状況イベントをアカウントではなくデバイス ID に紐づけて記録します。イベントにはメールアドレス、会話テキスト、メディアを含めない設計になっています。共有を停止するには、初回ガイドまたは **設定 → 一般** の **プライバシー** にある **匿名の製品分析データを共有** をオフにしてください。以前の選択はそのまま引き継がれます。クラッシュおよびフリーズレポートもこのスイッチがオンの間のみ送信され、ユーザーコンテンツは含まれません。

Enconvo はあなたの AI リクエスト、メッセージ、入力内容を Mac 上のログに保存しません。

診断ログは分析データとは別です。Enconvo がフリーズ、クラッシュ、または誤動作した場合は、メニューバーの **診断情報を送信…** または **設定 → 診断** から Enconvo チームへ送信できます。

- Mac から送信する前に、Enconvo はホームフォルダ名、ファイル名、メールアドレス、API キー、トークン、リンク、IP アドレス、プロンプトや返信のテキストなどの個人情報を除去します。
- レポートには診断専用に生成されたランダムな ID が付与され、アカウントやメールアドレスは含まれません。読めるのは Enconvo チームのみで、一定の日数が経過すると削除されます。
- ログには、使用したアプリ名、コマンド名、モデル名が含まれる場合があります。
- 設定ページで送信内容の正確な中身を確認でき、送信したレポートを取り下げて削除することもできます。

別の方法でログやスクリーンショットを共有する場合も、事前に内容を確認し、不要なプロンプト、パス、キー、アカウント情報、ドキュメント内容を削除してください。

## ローカルデータの保持と削除

チャット履歴、ナレッジベース、録音、認証情報など、各機能にはそれぞれ独自の管理機能があります。削除時の確認メッセージをよく読み、必要なデータはバックアップしてください。チャットを削除すると、別のチャットでも表示されていない限り、そのチャットに添付した画像やファイルも削除されます。

アプリを削除しても設定やデータがすべて消えるとは限りません。また、ローカルデータを削除しても外部サービスがすでに処理したコピーは削除されません。プロバイダー側の保持期間やアカウントポリシーについては各プロバイダーの規定を確認してください（このページでは Enconvo のデータフローのみを扱っています）。

Enconvo はデータを Mac に保存し、あなたが選んだ機能やプロバイダーのためにオンラインのサービスを使います。リクエストの送信先は、機能、選んだプロバイダー、オンにしたツール、接続した連携によって決まります。このページでは、それぞれの流れと、その管理方法を説明します。

## コンテンツの送信先

| 操作 | 送信される内容と送信先 |
| --- | --- |
| クラウド AI チャット | プロンプト、会話のコンテキスト、追加した添付ファイルが、モデルプロバイダーに送信されます |
| Enconvo Cloud のコンテンツチェック（2026 年 11 月 14 日から） | Cloud モデルに渡る前に、入力したばかりのテキストが、OpenAI のモデレーションモデルに送信されます |
| クラウド音声認識 | キャプチャした音声が、選んだ音声サービスに送信されます |
| クラウドのテキスト読み上げ | テキストが、選んだ音声サービスに送信されます |
| クラウドの埋め込みまたはリランキング | 検索に必要なドキュメントとクエリの内容 |
| ウェブ検索または取得 | 検索クエリまたは URL が、検索サービスまたはウェブサイトに送信されます |
| ローカルモデルの推論 | Mac の中にとどまります。ファイルをダウンロードしたあとは、モデルが Mac 上で動作します |
| ブラウザ操作またはコンピューター操作のツール | ツールに許可されたアクセスで可能な、あらゆる内容と操作 |
| IM チャンネル | 接続したメッセージングサービスとエージェントの間のメッセージ |
| 同期 | 同期をオンにすると、チャット、設定、ナレッジベース、アーティファクトが、Enconvo アカウントまたは iCloud に送信されます。API キーは、オンにした場合に限り、暗号化された状態でのみ Mac の外に出ます。 |

ローカルのチャットモデルを使うだけでは、すべてのツールがオフラインになるわけではありません。ウェブ検索、リモートの MCP ツール、クラウドの文字起こしプロバイダー、クラウドの埋め込みモデルでは、依然として内容がネットワークを通じて送信されます。

## Enconvo Cloud の利用ルール

2026 年 11 月 14 日から、Enconvo Cloud は、各メッセージが Cloud モデルに届く前に、[利用規約](https://www.enconvo.com/terms)に照らしてチェックします。チェックされるのは入力したばかりのテキストだけで、以前の会話、ファイル、画像は対象外です。自分の API キーやローカルモデルを使う場合は、何も変わりません。

- **保存されるもの:** メッセージが拒否またはフラグ付けされた場合、Enconvo はアカウント、時刻、モデル、スコアを最長 90 日間保存します。メッセージの文言は保存しません。
- **拒否されたメッセージ:** モデルには届かず、ポイントも消費されません。チャットに理由が表示されます。
- **繰り返しの拒否:** 繰り返されると、アカウントの Cloud AI が一時停止されることがあります。その場合でも、サインイン、サブスクリプションの管理や解約、アカウントの削除は行えます。サブスクリプションは、解約するまで続きます。
- **誤りだった場合:** support@enconvo.com までご連絡ください。

プロバイダーの安全対策が全員ではなく 1 つのアカウントにだけ適用されるように、Enconvo Cloud は、リクエストごとに、あなたのアカウントから作成した一方向の識別子も OpenAI と Anthropic に送信します。これはメールアドレスではありません。詳細は[プライバシーポリシー](https://www.enconvo.com/privacy)をご覧ください。

## 送信する内容を管理する

リクエストを送信する前に、添付ファイルとコンテキストを確認してください。Appshots、スクリーンショット、選択したテキスト、クリップボードの内容、ブラウザのページには、質問したい文以外の情報が含まれていることがあります。

コンテキストの取得元は、[コンテキスト認識](/ja/features/context-awareness)で選びます。[macOS の権限](/ja/configuration/permissions)は、使う機能に必要なものだけを許可し、不要になったらシステム設定で取り消してください。

## 認証情報

API キーとアカウントのサインインは、各プロバイダーの **認証** セクションと[認証情報の管理](/ja/configuration/credentials)で管理します。ローカルの Enconvo の設定、バックアップ、書き出した設定、サポート用ログは機密情報として扱い、キーやアカウントのトークンを、プロンプト、スクリーンショット、共有ファイルに含めないでください。

プロバイダープロファイルは、認証情報を複数の機能で共有できます。プロファイルを削除または置き換える前に、そのプロファイルを使うすべての機能を確認してください。

<Warning>
Enconvo からキーを削除しても、キーは無効になりません。キーが漏えいした場合は、プロバイダーのサイトで無効にしてください。
</Warning>

## ツールと連携

エージェントは、オンにしたツールを通じて動作できます。ブラウザ操作、コンピューター操作、シェルコマンド、ファイル編集、Gmail、外部の MCP サーバーは、それぞれ到達できるものが異なります。重要なデータを扱うときは、エージェントのツールと、エージェントが提案する操作を確認してください。

拡張機能を独自のワーカーで実行しても、ローカルファイルやネットワークへのアクセスは防げません。信頼できる提供元のツールをインストールし、その設定を確認してください。

チャットの **権限** チップは、エージェントが動作の前に確認するタイミングを決めます。**フルアクセス** では、友だちやチームメイトへの通話やメッセージを含め、確認なしで動作し、コンピューターに害を及ぼしうる変更の前にだけ確認します。[コマンドの前に Enconvo が確認する理由](/ja/configuration/sandbox)を参照してください。

エージェントのシェルコマンドを作業フォルダー内にとどめ、キー、保存済みの認証情報、他のアプリから遠ざけるには、その **サンドボックス** をオンにします。[エージェントのサンドボックス](/ja/configuration/sandbox)を参照してください。コンピューター操作を特定のアプリに触れさせないようにするには、**設定 → コンピューター操作** の **アプリへのアクセス** を使います。[コンピューター操作](/ja/features/computer-use)を参照してください。

ウェブ取得は、公開ページから、あなたの Mac やローカルネットワークにリダイレクトされることはありません。

## サインインリンク

ウェブページのサインインリンクが、Enconvo を勝手に別のアカウントに切り替えることはありません。Enconvo 自身がサインインを開始した場合を除き、先に確認が表示され、リンクが確認するアカウントと、置き換えられるアカウントが示されます。エージェント、コーディングエージェント、予約タスクは、サインインを開始したり、サインインリンクを開いたりできません。

## ローカルの AI クライアント

[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) は、オンにするまでオフで、ローカルからの接続を受け付けます。公開するナレッジベースは、表示のスイッチで選びます。ローカルのクライアントは、取得した内容を自身の AI プロバイダーに送信することがあるため、そのクライアントの設定にも注意してください。

## 分析データと診断情報

Enconvo は、アカウントではなくデバイス ID に紐づけて、製品の利用イベントを記録します。イベントには、メールアドレス、会話のテキスト、メディアが含まれないよう設計されています。共有を止めるには、初回起動ガイド、または **設定 → 一般** の **プライバシー** で、**匿名の製品分析データを共有** をオフにします。以前に選んだ設定は、そのまま維持されます。クラッシュとフリーズのレポートは、このスイッチがオンの間だけ送信され、コンテンツは含まれません。

Enconvo は、AI へのリクエスト、メッセージ、入力した内容のコピーを、Mac 上のログに保存しません。

診断ログは分析データとは別のものです。Enconvo がフリーズ、クラッシュ、または誤動作したときは、メニューバーのメニューの **診断情報を送信…**、または **設定 → 診断** から、Enconvo チームに送信できます。

- Mac の外に何かが出る前に、Enconvo は、ホームフォルダーの名前、ファイル名、メールアドレス、API キー、トークン、リンク、IP アドレス、プロンプトと返信のテキストなど、個人情報を取り除きます。
- レポートには、診断のためだけに作られたランダムな ID が付き、アカウントやメールアドレスは含まれません。読めるのは Enconvo チームだけで、一定の日数が経つと削除されます。
- ログには、使ったアプリ、コマンド、モデルの名前が含まれることがあります。
- ページには、送信された内容がそのまま表示され、各レポートを取り下げたり削除したりできます。

ログやスクリーンショットを別の方法で共有するときは、事前に確認し、不要な非公開のプロンプト、パス、キー、アカウントの詳細、ドキュメントの内容を削除してください。

## ローカルデータを残す、または削除する

データは機能ごとに管理されます。チャット履歴、ナレッジベース、録音、認証情報には、それぞれ専用の管理機能があります。削除の確認をよく読み、必要なものはバックアップを取ってください。チャットを削除すると、そのチャットに添付した画像やファイルも、他のチャットで表示されていない限り削除されます。

アプリを削除しても、その設定とデータが必ず削除されるとは限りません。ローカルデータを削除しても、外部のサービスがすでに処理したコピーは削除されません。プロバイダーのデータ保持とアカウントのポリシーについては、各プロバイダーをご確認ください。このページは、Enconvo のデータの流れについて説明するもので、プロバイダーのデータの流れは対象外です。

Enconvo はエージェントのセッションが終わったとき、Dynamic Island を開くか、macOS の通知を出すか、あるいはその両方で知らせることができます。設定は **設定 → 通知** で行い、邪魔されたくない時間帯には「おやすみ時間」を設定できます。

## 完了通知を設定する

1. **設定 → 通知** を開きます。
2. ページに **Enconvoの通知はオフになっています** と表示されている場合は、**有効にする** をクリックするか、**システム設定 → 通知** で Enconvo を許可します。
3. **セッション完了時** の各スイッチをオンまたはオフにします。各スイッチは独立して動作します。
4. 短いリクエストをエージェントに送って実行し、完了まで待ちます。

| 設定 | 動作 |
| --- | --- |
| **Dynamic Island を開く** | Dynamic Island から開始したセッションが終わると、Island が展開して結果を表示します。 |
| **システム通知を送信** | セッションが終わると、返答の冒頭を含む macOS 通知を表示します。通知をクリックすると、開始元のウィンドウでそのセッションを再び開きます。 |

これらのスイッチがオンでも、macOS の集中モードや通知設定によってバナーが非表示になることがあります。

## おやすみ時間

おやすみ時間中は、この Mac でもペアリング済みの iPhone でも、エージェントからの質問、メールアラート、完了したタスクの通知をおやすみ時間終了まで保留します。待機中にあなたの代わりに自動承認されることはありません。

1. **設定 → 通知** で **お知らせ** を開きます。
2. **おやすみ時間** をオンにし、**開始時刻** と **終了時刻** を設定します。
3. それでも通知を通す項目を選びます。

| 設定 | 動作 |
| --- | --- |
| **承認リクエストは通知する** | おやすみ時間中も承認リクエストだけは届けます。 |
| **質問は通知する** | おやすみ時間中もエージェントからの質問だけは届けます。 |

Enconvo のメニューバーメニューにも **おやすみ時間** と、一時的に休止できる **お知らせを1時間一時停止** があります。

メールアラートは **予約タスク → 重要なメール** でオンにするまでオフになっています。すでにオンや設定を済ませているメールアラートはそのまま動き続けます。そこにある **スマートフォン** スイッチをオンにすると、ペアリング済みの iPhone や Android スマートフォンへも通知を送れます。

## スケジュール実行の結果

システム通知は、予約タスクの結果を Telegram などのメッセージングチャットへ送信する設定とは別の機能です。結果の配信先は [予約タスク](/ja/workflows/scheduled-jobs) のエディタで設定します。

予約タスクには実行時に Mac 通知を出すオプション（**実行時に通知する**）もあり、こちらも **システム通知を送信** の設定に従います。タスクの実行履歴では、各実行が成功したか、結果が配信されたかを確認できます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| セッション終了時にバナーが出ない | **システム通知を送信** がオンになっていること、macOS で Enconvo の通知が許可されていること、集中モードで隠されていないことを確認してください。 |
| Dynamic Island が開かない | **Dynamic Island を開く** は、Dynamic Island から開始したセッションにのみ適用されます。 |
| 質問や完了通知が遅れて届いた | おやすみ時間で保留されていた可能性があります。**質問は通知する** をオンにするか、**開始時刻** と **終了時刻** を変更してください。 |

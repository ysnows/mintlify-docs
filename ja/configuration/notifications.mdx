Enconvo は、エージェントのセッションが完了したことを、Dynamic Island を開く、macOS の通知を表示する、またはその両方で知らせることができます。この設定は **設定 → 通知** で行い、中断されたくない時間帯のおやすみ時間もここで設定します。

## 完了の通知を設定する

1. **設定 → 通知** を開きます。
2. ページに **Enconvoの通知はオフになっています** と表示されている場合は、**有効にする** をクリックするか、**システム設定 → 通知** で Enconvo を許可します。
3. **セッション完了時** の下で、各スイッチをオンまたはオフにします。それぞれ独立して動作します。
4. 短いエージェントのリクエストを開始し、完了するまで待ちます。

| 設定 | 動作 |
| --- | --- |
| **Dynamic Island を開く** | Dynamic Island から開始したセッションが完了すると、アイランドが展開して結果を表示します。 |
| **システム通知を送信** | セッションが完了したときに、返信の冒頭を含む macOS の通知を表示します。通知をクリックすると、セッションを開始したウィンドウでそのセッションが再び開きます。 |

これらのスイッチがオンでも、macOS の集中モードや通知設定によって、バナーが表示されないことがあります。

## おやすみ時間

おやすみ時間中は、エージェントからの質問、メールアラート、完了したタスクが、この Mac とペアリングした iPhone で、おやすみ時間が終わるまで保留されます。保留中に、あなたの代わりに承認されることはありません。

1. **設定 → 通知** で **お知らせ** を探します。
2. **おやすみ時間** をオンにして、**開始時刻** と **終了時刻** を設定します。
3. 通知を受け取るものを選びます。

| 設定 | 動作 |
| --- | --- |
| **承認リクエストは通知する** | おやすみ時間中も、承認リクエストが届きます。 |
| **質問は通知する** | おやすみ時間中も、エージェントからの質問が届きます。 |

Enconvo のメニューバーのメニューにも **おやすみ時間** と、短い休憩のための **お知らせを1時間一時停止** があります。

メールアラートは、**予約タスク → 重要なメール** でオンにするまでオフです。すでにオンにした、または設定したメールアラートは、そのまま動作します。その **スマートフォン** スイッチをオンにすると、ペアリングした iPhone や Android スマートフォンにアラートが送られます。

## 予約タスクの結果

システム通知は、予約タスクの結果を Telegram などの IM チャットに送ることとは別のものです。結果の配信は、[予約タスク](/ja/workflows/scheduled-jobs)のエディタで設定します。

予約タスクは、実行時に独自の Mac 通知を表示することもできます（**実行時に通知する**）。この通知も **システム通知を送信** に従います。タスクの実行履歴には、各実行が成功したかどうかと、結果が配信されたかどうかが表示されます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| セッションが完了してもバナーが表示されない | **システム通知を送信** がオンになっていること、macOS が Enconvo からの通知を許可していること、集中モードで非表示になっていないことを確認してください。 |
| Dynamic Island が開かなかった | **Dynamic Island を開く** は、Dynamic Island から開始したセッションにのみ適用されます。 |
| 質問や完了したタスクの通知が遅れて届いた | おやすみ時間中に保留された可能性があります。**質問は通知する** をオンにするか、**開始時刻** と **終了時刻** を変更してください。 |

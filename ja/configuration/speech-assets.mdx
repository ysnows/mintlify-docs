---
title: "辞書と話者"
description: "音声機能に、あなたの言葉や表記を教え、録音の中の声に名前を付けます。"
---

辞書は、あなたが使う製品名、専門用語、略語、特殊な表記を、Enconvo の音声機能に教えます。話者は、録音の中で名前を付けた声の名前を保持するため、新しい録音では、その名前が自動で付きます。**設定 → 辞書**と**設定 → 話者**から開きます。

## 単語を追加する

1. **設定 → 辞書**を開き、**新しい単語**をクリックします。
2. 正しい表記を入力し、必要なら短い説明も入力します。
3. **聞き間違い**には、必要に応じて、音声入力がこの単語の代わりに書いてしまう言葉を、カンマで区切って入力します。
4. **保存**をクリックし、その単語を含む短い録音を試します。
5. 文字起こしを確認します。認識には、プロバイダーの対応状況と音質も影響します。

## 複数の単語をまとめて追加する

**辞書に追加**ウィンドウで**一括追加**に切り替え、1 行に 1 つの用語を入力します。説明は `|` で区切ります。

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 提案された表記を採用する

辞書には**表記の提案**が一覧表示されます。音声入力の直後に修正した単語や、あなたの言葉に対して音声入力が書き続けている表記が、**聞き間違い**の項目として提案されます。**採用**をクリックすると、次回から音声入力がその表記で書きます。不要な場合は**閉じる**をクリックします。

## 修正から学習する

**設定 → 辞書**の**自分の修正から学習**をオンにすると、音声入力した名前を手動で修正した場合に、次回のためにその名前が辞書に追加されます。Dynamic Island には、学習した内容が**元に戻す**とともに表示されます。学習した表記は、単語の下に**学習済み**と表示されます。そこから削除すると、Enconvo はその表記を再び学習しません。

## 単語を編集または削除する

検索と編集ボタンを使って、リストを最新に保ちます。複数の単語を削除するには、**選択**をクリックして単語を選び、**削除**をクリックして、確認します。

## 話者に名前を付ける

1. 複数の話者がいる録音を開きます。
2. 文字起こしの話者ラベルをクリックし、その人に名前を付けます。
3. Enconvo がその声を登録し、新しい録音で自動的に認識します。

話者の名前を変更する前に、録音内の話者の割り当てを確認してください。認識された声や話者分離のラベルは、特に人が重なって話しているときに、間違っていることがあります。

**設定 → 話者**には、名前を付けたすべての人が、登場する録音の数とともに一覧表示されます。そこで話者の名前を変更したり、削除したりできます。話者を削除すると、その人のラベルは話者番号に戻ります。録音は残ります。

## 適用される場所

[音声入力](/ja/features/dictation)、[会議の録音](/ja/features/meeting-recording)、[文字起こし](/ja/features/transcription)、[リアルタイム字幕](/ja/features/live-captioning)は、それぞれ独自の音声設定を使います。プロバイダーによって語彙の扱いが異なるため、言語のヒント、ホットワード、話者分離などのオプションは、各プロバイダーの設定で確認してください。

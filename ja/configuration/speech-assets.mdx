「辞書」では、あなたが使う製品名、専門用語、略語、特殊な表記を Enconvo の音声機能に覚えさせられます。「話者」では録音内で名前を付けた声を保持し、新しい録音でも自動でラベル付けできるようにします。それぞれ **設定 → 辞書** と **設定 → 話者** から開きます。

## 単語を追加する

1. **設定 → 辞書** を開いて **新しい単語** をクリックします。
2. 正しい表記と、必要であれば短い説明を入力します。
3. **聞き間違い** 欄には、音声入力がこの単語の代わりに誤って入力してしまう表記があればコンマ区切りで入力します（任意）。
4. **保存** をクリックし、その単語を含む短い音声で試してみます。
5. 文字起こしの結果を確認します。認識精度はプロバイダーの対応状況や音質にも左右されます。

## 一度に多くの単語を追加する

**辞書に追加** ウィンドウで **一括追加** に切り替え、1 行につき 1 用語を入力します。説明を添える場合は `|` で区切ります。

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 表記の提案を採用する

辞書には **表記の提案** が表示されます。これは、音声入力の直後にあなたが手で直した単語や、音声入力が繰り返し誤変換している表記を **聞き間違い** 候補として提案するものです。**採用** をクリックすると次回からその表記で出力されるようになり、不要な場合は **閉じる** をクリックします。

## 修正内容から学習する

**設定 → 辞書** で **自分の修正から学習** をオンにしておくと、音声入力後に手動で修正した固有名詞などが次回のために辞書へ追加されます。学習された内容は Dynamic Island に **元に戻す** 付きで表示されます。学習された表記はその単語の下に **学習済み** として表示され、そこで削除すると今後は同じ表記を自動学習しなくなります。

## 単語を編集・削除する

検索欄や編集ボタンを使って一覧を最新の状態に保てます。複数の単語をまとめて削除するには、**選択** をクリックして対象の単語を選び、**削除** をクリックして確定します。

## 話者に名前を付ける

1. 複数人が話している録音を開きます。
2. 文字起こし内の話者ラベルをクリックし、その人の名前を入力します。
3. Enconvo が声の特徴を登録し、以降の新しい録音でも自動で識別するようになります。

話者名を変更する前に、その録音での話者割り当てが合っているか確認してください。特に複数人の声が重なった場面では、音声識別や話者分離のラベルが誤っている場合があります。

**設定 → 話者** には名前を付けたすべての人物と、登場している録音数が一覧表示されます。ここで話者名の変更や削除ができます。話者を削除するとラベルは話者番号に戻りますが、録音自体は残ります。

## 適用される範囲

[音声入力](/ja/features/dictation)、[会議録音](/ja/features/meeting-recording)、[文字起こし](/ja/features/transcription)、[リアルタイム字幕](/ja/features/live-captioning) はそれぞれ独自の音声設定を持っています。プロバイダーによって語彙の扱いが異なるため、言語ヒント、ホットワード、話者分離などのオプションは各プロバイダーの設定を確認してください。

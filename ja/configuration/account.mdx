Enconvo アカウントには、プラン、Cloud ポイント、およびそれらを使用する Mac が紐づきます。サインインは**設定 → アカウント**から行います。設定サイドバーのその下にあるページでは、Teams、同期、ポイント使用量、使用状況の統計、友達を招待、コードを引き換えるを管理できます。ワークスペースは**設定 → ワークスペース**にあります。

この動画では、アカウント、Teams、ワークスペース、同期の順に使い方を説明しています。

<YouTubePlayer videoId="FnddgYQfcTc" title="How to Use Teams and Workspaces in Enconvo | Step-by-Step Tutorial" />

<Note>
Enconvo アカウント、プロバイダーの API キー、およびプロバイダーのサブスクリプションサインインはそれぞれ別の接続です。ご自身の API キーを使ったリクエストは、そのプロバイダーアカウントの課金と上限に従います。サブスクリプションサインインの使用状況は、Enconvo Cloud ポイントとは別に、各プロバイダーの設定ページに表示されます。詳しくは[認証情報](/ja/configuration/credentials)をご覧ください。
</Note>

## サインイン

1. **設定 → アカウント**を開きます。
2. **ログイン**をクリックするか、アカウントを作成する場合は**新規登録**をクリックします。
3. ブラウザでサインインを完了します。ブラウザですでにサインイン済みの場合は、どのアカウントを使うかウェブサイト上で確認されます。完了すると Enconvo に戻ります。
4. **プロフィール**に、サインイン中の名前とメールアドレスが表示されます。

サインイン処理が終わるまで、チャットウィンドウのサイドバーに進行状況を示すカードが表示され、アカウントの読み込みが完了するまで表示されます。ネットワークが遅い場合はその旨が表示され、読み込めない場合は**再試行**が表示されます。サインインに失敗したりキャンセルしたりした場合は、もう一度**ログイン**をクリックしてください。

サインアウトするには、ページ下部の**ログアウト**をクリックします。

### プロフィール写真を変更する

プロフィール写真は、友達、チームメンバー、カンファレンスの参加者に表示されます。Google でサインインした場合は、別の写真を選ぶまで Google の写真が表示されます。

1. **設定 → アカウント**で、写真の横にある**写真を変更**（写真がない場合は**写真を追加**）をクリックします。
2. **写真をアップロード…**を選び、画像を選択します。
3. 写真をドラッグして円の中に収め、スライダーで拡大・縮小を調整して**保存**をクリックします。

同じメニューに、Google の写真に戻す**Google の写真を使用**と、代わりにイニシャルを表示する**写真を削除**があります。

### メールアドレスやパスワードを追加する

**設定 → アカウント**の**サインイン**セクションには、アカウントのサインイン方法が表示されます。Apple でサインアップし「メールを非公開」を使った場合、メールアドレスは Apple によって非公開として表示されます。

1. **メールを追加**をクリックしてご自身のメールアドレスを入力し、そこに届いた認証コードを入力します。以降は、そのメールアドレスでもサインインできるようになります。
2. enconvo.com や Enconvo Feedback にメールアドレスとパスワードでサインインするには、**パスワードを設定**をクリックします。すでに設定済みの場合は**パスワードを再設定**と表示され、古いパスワードの入力は不要です。

同じセクションは iPhone アプリと Android アプリにもあります。

## プランとポイントを確認する

**設定 → アカウント**にはアカウントの保有内容が表示されます：

| セクション | 表示内容 |
| --- | --- |
| **ポイント** | **残高合計**。**使用状況を表示**でポイント使用量を開き、**チャージ**でポイントを追加購入します。 |
| **永久ライセンス** | ライセンスのティア（**Standard** または **Premium**）、購入日、アップデートとサポートの有効期間、利用中のデバイス。ライセンスがない場合は**買い切り版を購入**から選択肢を確認でき、無料の Standard トライアルが提供されている場合は**トライアルを開始**が表示されます。 |
| **Teams** | チーム管理者の場合、シート数と**チームを管理**が表示されます。 |
| **Enconvo Cloud** | Cloud ティア、請求期間、次回請求日、ポイントのリセット日、利用中のデバイス。プラン変更は **Cloud プランを入手**または**アップグレード**から行い、**料金を見る**でモデルとサービスのレートを確認できます。 |

一番下の**請求情報を管理**をクリックすると、ブラウザで請求詳細が開きます。永久購入がまだ返金可能な期間内であれば、ここにも**返金を申請**が表示されます。返金を行うとアカウントは無料プランに戻り、付与されたボーナスポイントは取り消されます。

### デバイス

各プランには利用できる Mac の台数上限があり、**デバイス**に現在の利用台数が表示されます。上限に達すると**デバイス数の上限に達しました**と表示され、この Mac ではコマンドを実行できなくなります。**デバイスを管理**をクリックして使わなくなった Mac を削除してからこの Mac を有効化するか、より多くのデバイスに対応したプランを選んでください。

## Teams

Teams ではシートを購入し、メールアドレスを指定して 1 人ずつ割り当てることができます。各自が自分のアカウントでサインインし、Cloud ポイントをメンバーと共有できます。設定サイドバーに **Teams** が表示されるのはチーム管理者だけです。

1. **設定 → Teams** を開きます。上部に**割り当て済みシート**、**空きシート**、**チャージポイント**が表示されます。
2. **シートを割り当てる**に相手が Enconvo へのサインインに使うメールアドレスを入力し、**割り当て**をクリックします。
3. 本人が初めて Enconvo にサインインするまでシートは**保留中**となり、サインインすると**有効**になります。

割り当てられたアカウントは、1 台の Mac で Premium 機能と永久アップデートを利用でき、自身のチャット、メモリ、ナレッジベースのプライバシーも保たれます。管理者から見えるのはシートとポイントの合計数だけです。

各メンバーの**シートの操作**メニューには以下があります：

| 操作 | 内容 |
| --- | --- |
| **ポイントを移行** | あなたのチャージ残高から相手の残高へポイントを移します。有効期限はありません。 |
| **ポイントを回収** | 相手がまだ使っていないポイントをあなたのチャージ残高に戻します。 |
| **シートの割り当てを解除** | 相手のアカウントをすぐに無料プランへ戻します。相手のデータは残り、移行したポイントはあなたに戻ります。あなた自身のシートの場合は**自分のシートを手放す**になります。 |

各シートは Mac 1 台分です。行の **+** をクリックすると、ご自身を含めそのアカウントでさらに多くの Mac にサインインできるようになります。シートを増やすには**シートを追加**をクリックします。

**チームのナレッジベース**には、チーム全員と共有されているナレッジベースが表示されます。共有するには、ナレッジベースの **⋯** メニューを開いてチームアクセスをオンにします。メンバーがチームと共有するまで、各人のナレッジベースは非公開のままです。

## ワークスペース

ワークスペースを使うと、クライアント案件や特定の仕事の作業を自分用の作業から分けておけます。各ワークスペースには専用のチャット、メモリ、ナレッジ、サインイン、設定があり、別のワークスペースの内容が混ざることはありません。ワークスペース側で変更していない設定は、自分用の**個人**ワークスペースの設定を引き継ぎます。

下の動画では、クライアント用のワークスペースを作成し、個人に切り替え、設定でワークスペースを管理する流れを紹介しています。

<YouTubePlayer videoId="fMHIhDRufXA" title="Workspaces in Enconvo" />

### ワークスペースを作成する

1. チャットウィンドウのサイドバー上部にあるワークスペースメニュー（**個人**と表示されています）をクリックし、**新規ワークスペース…**を選びます。**設定 → ワークスペース**の**新規ワークスペース…**からも作成できます。
2. 初回は簡単なガイド**ワークスペースとは**が表示され、**作業を分けておく**、**サイドバーの上部で切り替え**、**「個人」の設定から始まる**の 3 点が説明されます。**続ける**をクリックします。
3. 担当するクライアント名などの**ワークスペース名**を入力し、**作成**をクリックします。

新しいワークスペースでチャットウィンドウが開きます。チャット、メモリ、ナレッジは空の状態で始まり、個人のデータはここには表示されません。

### ワークスペースを切り替える

チャットウィンドウのサイドバー上部にあるワークスペースメニューをクリックして、ワークスペースを選びます。または **⌃⌘1** 〜 **⌃⌘9** を押します。数字は一覧内の順番に対応しているため、**⌃⌘1** は**個人**です。

各ウィンドウは 1 つのワークスペースで動作し、複数のワークスペースで同時に作業を進めることもできます。

### 分けて保持される内容

各ワークスペースは独自のチャット、メモリ、ナレッジ、サインイン、設定を持ちます。コーディングエージェントのチャットは開始したワークスペース内に留まり、新しく作った[スペース](/ja/features/spaces)もワークスペースごとに別々のデータを保持します。新しいワークスペースでは、そこで変更するまで個人の設定が使われます。

あるワークスペースでコネクタに別のアカウントを使わせるには、そのワークスペースに切り替えてプラグインページでコネクタを開き、アカウントの **⋯** メニューから**デフォルトにする**を選びます。アカウントに**デフォルト：**とワークスペース名が表示され、リクエストで別のアカウント名を指定しない限り、エージェントはそのワークスペースでそのアカウントを使います。

チーム管理者の場合、**Teams** ページで各メンバーを 1 つ以上のワークスペースに配置できます。配置すると、メンバーは同じワークスペースを共有するチームメイトだけを表示し、チャットや通話ができるようになります。

### ワークスペースの名前変更と削除

**設定 → ワークスペース**を開きます。**個人**は常に先頭にあり、その設定がすべてのワークスペースの基準になるため、名前変更や削除はできません。

その他のワークスペースの行には**名前を変更**と**削除**があります。ワークスペースを削除すると、その中のチャット、メモリ、ナレッジ、設定も一緒に削除されます。削除後 7 日間は**最近削除した項目**に残り、**復元**で元に戻せます。

エージェントに頼んでワークスペースの一覧表示、作成、名前変更、色変更、並べ替え、削除、復元を行わせることもできます。削除の前には確認が入ります。

## Mac 同士を同期する

同期をオンにすると、同じアカウントでサインインしているすべてのコンピュータでチャット、設定、スキル、プラグイン、ナレッジベース、アーティファクトが同じ状態に保たれます。Enconvo Cloud プランと永久ライセンスに含まれています。

1. 各コンピュータで同じ Enconvo アカウントにサインインします。
2. **設定 → 同期**を開き、**コンピュータ間で同期**をオンにします。
3. 同期データの保存先を尋ねられたら、**Enconvo アカウント**または **iCloud** を選びます。これはあとから**ストレージ**で変更できます。
4. **同期する内容**で、対象に含める項目を選びます。

| 項目 | 同期される内容 | このコンピュータに留まる内容 |
| --- | --- | --- |
| **チャット** | チャット履歴（画像やファイルを含む）、タイトル、プロジェクト、アーカイブ済みチャット | |
| **設定** | モデル、プロンプト、プラグイン環境設定、スニペット、自作の AI コマンド・エージェント・ワークフロー | サインイン情報、ホットキー、フォルダパス |
| **スキル** | インストールまたは作成したスキル、それぞれのオン／オフ状態。GitHub から入れたスキルはソースも保持されるため、他のコンピュータでも更新を確認します | プラグインに付属するスキルはそのプラグインに紐づきます |
| **プラグイン** | Enconvo ストア、GitHub、npm、またはリンクからインストールしたプラグイン。他のコンピュータでも同様にインストール・アンインストールされます | 組み込みプラグイン、開発中のプラグイン、コネクタ、サインイン情報 |
| **ナレッジベース** | ナレッジベースとメモリ、およびそのメモ、テキスト、Web ページ | インポートしたファイルと録音 |
| **アーティファクト** | ページ、ドキュメント、デザイン、スライド、ダッシュボード、画像、動画などすべてのバージョンの[アーティファクト](/ja/features/artifacts)。2 台の Mac で同時に変更した場合は両方のバージョンが残ります | 32 MB を超えるファイル、共有されたドキュメントやデザイン |
| **API キー** | 組み込みプロバイダーの API キー（このコンピュータを出る前に暗号化されます） | サインイン情報とカスタムプロバイダー |

パスワードとサインイン情報がコンピュータの外に出ることはありません。Enconvo アカウントをストレージに使う場合、新しいコンピュータが API キーを受け取れるのは他のコンピュータの 1 台が許可したあとだけです。両方に同じコードが表示されているのを確認し、**許可**をクリックしてください。他のコンピュータが手元にないときに API キーを取得するには、**バックアップ用パスフレーズ**を使います。iCloud の場合は、同じ iCloud にサインインしている Mac が自動的にキーを受け取ります。

**今すぐ同期**ですぐに同期を実行でき、**あなたのコンピュータ**には同期中のすべてのコンピュータが表示されます。**同期データを消去**を実行すると、アカウントまたは iCloud に同期されたすべてのデータが全コンピュータから削除されます。各コンピュータ上のローカルデータは残り、このコンピュータでは同期がオフに、他のコンピュータでは再度オンにするまで一時停止されます。

## ポイント使用量と使用状況の統計

**設定 → ポイント使用量**では Enconvo Cloud ポイントを確認できます：

- **残高合計**：今すぐ使えるすべてのポイント。サブスクリプションポイントから先に消費されます。
- **サブスクリプション残高**：月間または年間の付与枠で、更新のたびにプランの規定量にリセットされます。
- **チャージ残高**：追加購入パックや永久ライセンスによるポイント。有効期限はありません。
- モデル別の 1 日ごとの使用量グラフ、および各課金の**履歴**。

**履歴**では、**記録の種類**と**モデル**で絞り込んだり、**日付へ移動**で特定の日を選んだりして、日ごとのポイント消費量を確認できます。

**設定 → 使用状況の統計**では、ご自身のキーを含め、Enconvo が呼び出すあらゆる AI プロバイダーのコスト、トークン数、リクエスト数を確認できます。**コスト**、**トークン**、**リクエスト**を切り替え、期間を **24h**、**7d**、**30d**、**90d** から選び、モデル別、プロバイダー別、または機能別に内訳を見られます。コストは各プロバイダーの API 公式料金に基づく概算です。

## 友達を招待する

**設定 → 友達を招待**には、招待リンクと招待コードが表示されます。**リンクをコピー**または**コードをコピー**で共有してください。

招待コードは使い捨てメールアドレスやエージェント用メールアドレスからは利用できません。友達があなたの招待でサインアップし、Enconvo にとって新しいデバイス上の Enconvo アプリにサインインすると、双方にポイントが付与されます。招待できる人数に上限はありませんが、ウェブ上でのサインインのみでは対象になりません。**招待履歴**で参加した人と獲得ポイントを確認できます。

友達から招待された場合は、**招待コードをお持ちですか？**にコードを入力して**引き換える**をクリックします。

## コードを引き換える

1. **設定 → コードを引き換える**を開きます。
2. コード、またはコードが記載されたリンクを貼り付け、**続ける**をクリックします。

ライセンスコードとカード不要トライアルはアカウントですぐに有効になります。Teams ライセンスコードを使うと、そのアカウントがコードに含まれるシートのチーム管理者となり、1 シートあたり 50,000 Cloud ポイントが付与されます。詳しくは [Teams](#teams) をご覧ください。カードが必要なトライアルの場合はブラウザで決済画面が開き、確定前に更新条件が表示されます。

## あなたについて

エージェントにあなた自身の情報を伝えるには、**設定 → あなたについて**を開きます。ここに入力した内容はすべてのエージェント、音声通話、アバターで使われるため、応答のパーソナライズに使いたい情報だけを追加してください。

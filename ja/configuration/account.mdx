Enconvo アカウントには、プラン、Cloud ポイント、それらを使う Mac が紐づきます。サインインは **設定 → アカウント** で行います。設定サイドバーのその下のページでは、チーム、同期、ポイント使用量、使用状況の統計、アフィリエイト、コードを引き換えるを扱います。ワークスペースは **設定 → ワークスペース** にあります。

このビデオでは、アカウント、チーム、ワークスペース、同期を、この順に紹介します。

<YouTubePlayer videoId="FnddgYQfcTc" title="How to Use Teams and Workspaces in Enconvo | Step-by-Step Tutorial" />

<Note>
Enconvo アカウント、プロバイダーの API キー、プロバイダーのサブスクリプションのサインインは、それぞれ別の接続です。自分の API キーを使うリクエストには、プロバイダーのアカウントの課金と上限が適用されます。サブスクリプションのサインインの使用量は、Enconvo Cloud のポイントとは別に、プロバイダーの設定ページに表示されます。[認証情報](/ja/configuration/credentials)をご覧ください。
</Note>

## サインインする

1. **設定 → アカウント** を開きます。
2. **ログイン** をクリックするか、アカウントを作成するには **新規登録** をクリックします。
3. ブラウザでサインインを完了します。ブラウザがすでにサインインしている場合は、ウェブサイトがどのアカウントを使うかを尋ねます。Enconvo に戻ります。
4. **プロフィール** に、サインインしている名前とメールアドレスが表示されます。

サインインが完了するまで、チャットウィンドウのサイドバーのカードがアカウントの読み込みまで追いかけます。ネットワークが遅いときはそう表示され、アカウントが読み込まれないときは **再試行** が表示されます。サインインに失敗したりキャンセルしたりした場合は、もう一度 **ログイン** をクリックします。

サインアウトするには、ページ下部の **ログアウト** をクリックします。

### プロフィール写真を変更する

プロフィール写真は、友だち、チームメイト、会議の参加者に表示されます。Google でサインインした場合は、別の写真を選ぶまで Google の写真が表示されます。

1. **設定 → アカウント** で、写真の横の **写真を変更** をクリックします(写真がない場合は **写真を追加**)。
2. **写真をアップロード…** を選んで、画像を選びます。
3. 写真をドラッグして円の中の位置を決め、スライダーでズームして、**保存** をクリックします。

同じメニューには、Google の写真に戻す **Google の写真を使用** と、頭文字を表示する **写真を削除** があります。

### メールアドレスまたはパスワードを追加する

**設定 → アカウント** の **サインイン** セクションに、アカウントのサインイン方法が表示されます。Apple でサインアップして「メールを非公開」を使った場合、メールアドレスは Apple によって非公開と表示されます。

1. **メールを追加** をクリックし、自分のメールアドレスを入力して、そこに送られたコードを入力します。以後、そのメールアドレスでサインインできます。
2. **パスワードを設定** をクリックすると、enconvo.com と Enconvo Feedback で、メールアドレスとパスワードでサインインできます。すでにパスワードがある場合は、ボタンが **パスワードを再設定** になり、古いパスワードは求められません。

同じセクションが、iPhone アプリと Android アプリにもあります。

## プランとポイントを確認する

**設定 → アカウント** に、アカウントの内容が表示されます。

| セクション | 表示される内容 |
| --- | --- |
| **ポイント** | **残高合計**。**使用量を表示** でポイント使用量が開き、**チャージ** でポイントを追加購入できます。 |
| **永久ライセンス** | ライセンスの種類(**標準** または **プレミアム**)、購入日、アップデートとサポートの期間、デバイス。ライセンスがない場合は **買い切り版を購入** で選択肢が表示され、無料の標準トライアルがあるときは **トライアルを開始** が表示されます。 |
| **チーム** | チーム管理者の場合のシート。**チームを管理** があります。 |
| **Enconvo Cloud** | Cloud のプラン、請求期間、次回の請求日、ポイントのリセット日、デバイス。**Cloudプランを購入** や **アップグレード** で変更でき、**料金を表示** でモデルとサービスの料金が開きます。 |

下部の **請求情報を管理** で、ブラウザに請求の詳細が開きます。永久版の購入が返金可能な間は、ここに **返金を申請** も表示されます。返金すると、アカウントは無料プランに戻り、ボーナスポイントも取り消されます。

### デバイス

各プランには利用できる Mac の台数があり、**デバイス** に使用台数が表示されます。上限に達すると、ページに **デバイス数の上限に達しました** と表示され、この Mac ではコマンドを実行できません。**デバイスを管理** をクリックして、使っていない Mac を削除してからこの Mac を有効にするか、デバイス数の多いプランを選んでください。

## チーム

チームでは、シートを購入し、メールアドレスで 1 人ずつに割り当てられます。全員がそれぞれのアカウントでサインインし、Cloud ポイントを共有できます。設定サイドバーに **チーム** が表示されるのは、チーム管理者だけです。

1. **設定 → チーム** を開きます。上部に **割り当て済みシート**、**空きシート**、**チャージポイント** が表示されます。
2. **シートを割り当てる** で、その人が Enconvo にサインインするメールアドレスを入力し、**割り当てる** をクリックします。
3. シートは、その人が初めて Enconvo にサインインするまで **保留中**、サインイン後は **有効** と表示されます。

その人のアカウントでは、1 台の Mac でプレミアム機能と永久アップデートが使え、チャット、メモリ、ナレッジベースは非公開のままです。あなたに見えるのは、シートとポイントの合計だけです。

各メンバーの **シートの操作** メニューには、次の項目があります。

| 操作 | 内容 |
| --- | --- |
| **ポイントを移行** | あなたのチャージ残高からメンバーの残高へポイントを移します。ポイントは失効しません。 |
| **ポイントを回収** | メンバーが使っていないポイントを、あなたのチャージ残高に戻します。 |
| **シートの割り当てを解除** | メンバーのアカウントをすぐに無料プランに戻します。データはそのまま残り、移行したポイントはあなたに戻ります。自分のシートの場合は **自分のシートを手放す** です。 |

各シートは 1 台の Mac 用です。行の **+** をクリックすると、あなた自身を含め、そのアカウントがより多くの Mac でサインインできるようになります。**シートを追加** で、さらに購入できます。

**チームのナレッジベース** には、チームの全員と共有しているナレッジベースが一覧表示されます。共有するには、その **⋯** メニューを開いて、チームのアクセスをオンにします。メンバーのナレッジベースは、チームと共有するまで非公開のままです。

## ワークスペース

ワークスペースを使うと、クライアントや仕事ごとの作業を、自分の作業から分けられます。各ワークスペースには、専用のチャット、メモリ、ナレッジ、サインイン、設定があり、あるワークスペースの内容がほかに表示されることはありません。ワークスペースが変更していない設定は、自分の作業である **個人** に従います。

次のビデオでは、クライアント用のワークスペースを作り、個人に戻り、設定でワークスペースを管理します。

<YouTubePlayer videoId="fMHIhDRufXA" title="Workspaces in Enconvo" />

### ワークスペースを作成する

1. チャットウィンドウのサイドバー上部で、**個人** と表示されているワークスペースメニューをクリックし、**新規ワークスペース…** を選びます。**設定 → ワークスペース** の **新規ワークスペース…** をクリックしても作成できます。
2. 初回は、短いガイド **ワークスペースとは** が 3 つのことを説明します。**作業を分けておく**、**サイドバーの上部で切り替え**、**「個人」の設定から始まる** です。**続ける** をクリックします。
3. 勤務先のクライアント名など、**ワークスペース名** を入力して、**作成** をクリックします。

チャットウィンドウが新しいワークスペースで開きます。チャット、メモリ、ナレッジは空の状態から始まり、個人のものは何も表示されません。

### ワークスペースを切り替える

チャットウィンドウのサイドバー上部のワークスペースメニューをクリックして、ワークスペースを選びます。または **⌃⌘1** から **⌃⌘9** を押します。番号はリスト内のワークスペースの位置なので、**⌃⌘1** は個人です。

各ウィンドウは 1 つのワークスペースで動作し、複数のワークスペースでの作業を同時に実行できます。

### 分けられるもの

各ワークスペースには、専用のチャット、メモリ、ナレッジ、サインイン、設定があります。コーディングエージェントのチャットは、開始したワークスペースの中にとどまり、新しい[スペース](/ja/features/spaces)は、ワークスペースごとに別のデータを保持します。新しいワークスペースは、その中で何かを変更するまで、個人の設定を使います。

コネクタにワークスペース専用のアカウントを持たせるには、そのワークスペースに切り替え、プラグインページでコネクタを開き、アカウントの **⋯** メニューで **デフォルトにする** を選びます。アカウントに **デフォルト** とワークスペース名が表示され、リクエストで別のアカウントを指定しない限り、エージェントはそこでそのアカウントを使います。

チーム管理者の場合は、**チーム** ページで、各メンバーを 1 つ以上のワークスペースに追加できます。メンバーは、ワークスペースを共有するチームメイトだけを見られ、そのチームメイトとだけチャットや通話ができます。

### ワークスペースの名前を変更する、削除する

**設定 → ワークスペース** を開きます。**個人** は常に先頭にあり、その設定はすべてのワークスペースの出発点なので、名前の変更も削除もできません。

それ以外の各ワークスペースの行には、**名前を変更** と **削除** があります。ワークスペースを削除すると、そのチャット、メモリ、ナレッジ、設定も一緒に削除されます。7 日間は **最近削除した項目** に残り、**復元** で元に戻せます。

エージェントに、ワークスペースの一覧表示、作成、名前の変更、色の変更、並べ替え、削除、復元を頼むこともできます。削除する前に、エージェントが確認します。

## Mac を同期する

同期は、アカウントにサインインしているすべてのコンピュータで、チャット、設定、スキル、プラグイン、ナレッジベース、アーティファクトを同じ状態に保ちます。Enconvo Cloud プランと永久ライセンスに含まれています。

1. 各コンピュータで、同じ Enconvo アカウントでサインインします。
2. **設定 → 同期** を開き、**コンピュータ間で同期** をオンにします。
3. 同期するデータの保存先を尋ねられたら、**Enconvo アカウント** か **iCloud** を選びます。あとから **ストレージ** で変更できます。
4. **同期する内容** で、含めるものを選びます。

| 項目 | 同期されるもの | このコンピュータに残るもの |
| --- | --- | --- |
| **チャット** | 画像やファイルを含むチャット履歴、タイトル、プロジェクト、アーカイブしたチャット | |
| **設定** | モデル、プロンプト、プラグインの設定、スニペット、自分で作成した AI コマンド、エージェント、ワークフロー | サインイン、ホットキー、フォルダのパス |
| **スキル** | インストールまたは作成したスキルと、それぞれのオン・オフ。GitHub からインストールしたスキルはソースを保持するので、ほかのコンピュータでもアップデートを確認します | プラグインに付属するスキルは、そのプラグインとともに残ります |
| **プラグイン** | Enconvo ストア、GitHub、npm、リンクからインストールしたプラグイン。ほかのコンピュータにもインストールされ、アンインストールしたものはアンインストールされます | 組み込みのプラグイン、開発中のプラグイン、コネクタ、サインイン |
| **ナレッジベース** | ナレッジベースとメモリ(メモ、テキスト、ウェブページを含む) | インポートしたファイルと録音 |
| **アーティファクト** | すべてのバージョンを含む[アーティファクト](/ja/features/artifacts)(ページ、ドキュメント、デザイン、スライド、ダッシュボード、画像、動画)。2 台の Mac が同時に 1 つを変更した場合は、両方のバージョンが残ります | 32 MB を超えるファイル、共有ドキュメントとデザイン |
| **API キー** | 組み込みプロバイダーの API キー。このコンピュータを出る前に暗号化されます | サインインとカスタムプロバイダー |

パスワードとサインインが、コンピュータの外に出ることはありません。Enconvo アカウントを保存先にしている場合、新しいコンピュータが API キーを受け取れるのは、ほかのコンピュータのいずれかが許可した後だけです。両方に同じコードが表示されていることを確認して、**許可** をクリックします。**バックアップ用パスフレーズ** を設定すると、ほかのコンピュータが手元にないときでも、コンピュータが API キーを取得できます。iCloud の場合は、同じ iCloud にサインインしている Mac が、自動的にキーを受け取ります。

**今すぐ同期** はすぐに同期し、**あなたのコンピュータ** には同期しているすべてのコンピュータが一覧表示されます。**同期データを消去** は、アカウントまたは iCloud に同期されたすべてを、どのコンピュータからも削除します。コンピュータにあるものは残り、このコンピュータでは同期がオフになり、ほかのコンピュータでは、再びオンにするまで一時停止します。

## ポイント使用量と使用状況の統計

**設定 → ポイント使用量** に、Enconvo Cloud のポイントが表示されます。

- **残高合計**:いま使えるすべて。サブスクリプションのポイントが先に使われます。
- **サブスクリプション残高**:毎月または毎年の付与分。更新のたびにプランの量にリセットされます。
- **チャージ残高**:チャージパックと永久ライセンスのポイント。失効しません。
- モデル別の日次使用量グラフと、各課金の **履歴**。

**履歴** では、**記録の種類** と **モデル** で絞り込み、**日付へ移動** で日を選び、毎日の使用ポイントを確認できます。

**設定 → 使用状況の統計** には、自分のキーを含め、Enconvo が呼び出すすべての AI プロバイダーのコスト、トークン数、リクエスト数が表示されます。**コスト**、**トークン数**、**リクエスト** を切り替え、**24時間**、**7d**、**30d**、**90d** から選び、モデル、プロバイダー、機能別に内訳を確認できます。コストは、プロバイダーの API 定価に基づく概算です。

## アフィリエイト

**設定 → アフィリエイト** に、自分のリンクとコードが表示されます。メニューバーのメニューの **アフィリエイト…** からも開けます。以前のバージョンでは、このページは **友達を招待** と呼ばれていました。**リンクをコピー** または **コードをコピー** で共有します。リンクは 1 人につき 1 つで、`enconvo.com/i/<your code>` です。

- **友だち** は、あなたのリンクまたはコードでサインアップし、Enconvo を初めて使うデバイスの Enconvo アプリにサインインすると、250,000 Cloud ポイント(5 ドル)を受け取ります。ウェブでのサインインは対象外です。
- **あなた** は、友だちがサインアップから 30 日以内に支払うと、友だちの最初の支払いの 20% を Cloud ポイント(50,000 ポイント = 1 ドル)で受け取ります。年額プランは、年額を 12 で割った金額として計算されます。
- プランの分け前はすぐに付与されます。永久ライセンスの分け前は、返金期間である 30 日間待ち、その間に返金されると取り消されます。
- 対象になるのは支払いだけで、友だちが支払うデバイスやアプリは関係ありません。
- 友だちが支払い前にほかの人のリンクを開いた場合、最後に開いたリンクが特典を受け取ります。チェックアウトで入力したプロモーションコードはどのリンクよりも優先され、1 回の支払いでポイントとアフィリエイト報酬の両方が支払われることはありません。

招待コードは、使い捨てやエージェントのメールアドレスからは使えず、招待できる友だちの数に上限はありません。**招待履歴** には、各友だちと、あなたの分け前の状況が表示されます。最初の支払い待ち、返金期間中、獲得済みのいずれかです。

友だちに招待された場合は、**招待コードをお持ちですか?** の下にそのコードを入力して、**引き換える** をクリックします。

### 代わりに現金で受け取る

ブロガー、クリエイター、オーディエンスのいる方なら、アプリの有無にかかわらず、[アフィリエイトプログラム](https://www.enconvo.com/affiliate)に応募できます。承認されると、同じリンクで、紹介した人のすべての支払い(更新を含む)に対して 20% の現金報酬を獲得できます。サブスクリプションの報酬はすぐに支払い可能になり、永久ライセンスの報酬は 30 日間の返金期間のあとに支払い可能になります。支払いは毎月 1 日に PayPal または Wise で行われ、残高が 50 ドルに達した時点が対象で、それより少ない残高は繰り越されます。承認前に獲得したポイントはそのまま残ります。応募が承認されなかった場合は、60 日後に再応募できます。詳しい規約は[アフィリエイトプログラムの利用規約](https://www.enconvo.com/affiliate/terms)をご覧ください。

## コードを引き換える

1. **設定 → コードを引き換える** を開きます。
2. コード、またはコードが記載されたリンクを貼り付けて、**続ける** をクリックします。

ライセンスコードとカード不要のトライアルは、すぐにアカウントで有効になります。チームライセンスのコードを使うと、アカウントがそのコードのシートのチーム管理者になり、シート 1 つにつき 50,000 Cloud ポイントが付きます。[チーム](#チーム)をご覧ください。カードが必要なトライアルでは、ブラウザでチェックアウトが開き、確定する前に更新の条件が表示されます。

## あなたについて

エージェントに自分のことを伝えるには、**設定 → あなたについて** を開きます。すべてのエージェント、音声通話、アバターが、ここに書いた内容を使うので、返信のパーソナライズに使ってよい内容だけを追加してください。

利用するプロバイダーには、API キー、またはすでに契約しているプランへのサインインという認証情報が必要です。認証情報は各プロバイダーの設定ページで追加し、Enconvo はそのプロバイダーを使うすべての機能で共有されるプロバイダープロファイルとして保存します。**設定 → 認証情報管理** を開くと、すべての認証情報を一覧で確認できます。

## プロバイダーを追加する

<Steps>
  <Step title="カテゴリを開く">
    使いたい機能の設定ページ（**設定 → AI モデル**、**設定 → 画像生成**、**設定 → テキスト読み上げ** など）を開きます。
  </Step>
  <Step title="プロバイダーを選ぶ">
    プロバイダーを選択します。別のキーやアカウント用に 2 つ目の設定を作る場合は、**新規プロバイダーを追加** を選択します。
  </Step>
  <Step title="サインイン方法を選ぶ">
    **認証** で **API キー** を選択するか、契約中のプランを利用できる場合は **サブスクリプション** を選択します。
  </Step>
  <Step title="認証情報を入力する">
    API キーを貼り付けるか、プロバイダーのサインイン手続きを完了します。
  </Step>
  <Step title="動作を確認する">
    画面に **検証** ボタンが表示されていればクリックし、モデルを選んで短いリクエストを試します。
  </Step>
</Steps>

API キーを使用するとプロバイダーの API アカウントに課金されます。サブスクリプションでは契約プランに含まれる利用枠とその上限が使用されます。どちらを使用しているかは **認証** の下の説明に表示されます。

## 共有プロファイル

**OpenAI 2** のようなプロバイダープロファイルには、そのプロバイダーの API キーやサブスクリプションのサインイン情報が保持され、そのプロバイダーが対応するすべてのカテゴリに表示されます。プロファイル名を変更したり削除したりすると、現在のページだけでなく対応するすべてのカテゴリに変更が反映されます。

モデル、音声、生成設定はカテゴリごとに個別に保持されます。ただし、API キーを変更するとそのプロファイルを使うすべての機能に反映されるため、変更後は関連する機能をテストしてください。

プロバイダーが提供する機能はカテゴリによって異なります。AI チャットで使えるサインインであっても、同じプロバイダーのリアルタイム音声 API が含まれるとは限りません。API キーのみ対応しているカテゴリでは、その旨とサブスクリプションが使えるカテゴリが画面に表示されます。

## プランの使用量を確認する

サブスクリプションでサインインしている場合、アカウントとプランの残り利用枠が表示されます。**残り %** のような数値は残りの利用可能枠です。アカウントカードのメニューを開き、**使用量を更新** で最新の状態を取得するか、**再接続** で再度サインインできます。

Claude または Codex から無料の上限リセットが付与されている場合、Claude や ChatGPT のサブスクリプションカードに **無料リセット** として回数と有効期限が表示されます。**リセットを使用** をクリックして確認すると上限が補充されます。複数ある場合は一覧から使用するものを選択できます。

使用量が表示されない場合でも、利用が無制限であることを意味するわけではありません。

## 認証情報を管理する

**設定 → 認証情報管理** を開きます。リストはプロバイダープロファイルごとに認証情報をまとめ、その下にどのプロバイダーにも使われていない **未使用のキー** を表示します。

- **プロバイダーを検索...** に入力して検索します。
- **新しい認証情報を追加** をクリックして、指定したサービスの新しい認証情報を作成します。
- 認証情報を削除するには、項目にカーソルを合わせてゴミ箱アイコンをクリックします。API キーを使うコネクタがそのキーを使用している場合は確認画面に対象が表示され、**削除して接続を解除** を選ぶと別のキーを設定するまで接続が解除されます。
- リスト下部にある **整理** をクリックすると、未使用のキーをすべて一括削除できます。ボタンには件数が表示され、削除前に確認リストが表示されます。Enconvo が未使用のキーを自動で削除することはありません。

認証情報をクリックするとキーを追加または変更できます。**使用先** には **AI モデル** や **テキスト読み上げ** など、その認証情報を使用している機能が表示され、クリックすると該当の設定ページが開きます。

プロファイル固有の認証情報にはここでは削除ボタンがありません。プロバイダーを削除すると一緒に削除されます。

該当するものがある場合は、さらに 2 つのグループが表示されます。Enconvo に専用プロバイダーがないサービス用のキーを保存する **その他のサービス** と、保存したウェブサイトやアプリのサインイン情報を管理する **ログイン** です。

## Agent がキーを必要とするとき

タスクでサービスの API キーが必要になった場合、Agent はチャットにキーを貼り付けるよう求めるのではなく、**接続** カードをチャット内に表示します。入力されたキーは会話履歴ではなく認証情報管理に保存され、以降のチャットでは再入力なしで利用できます。

Enconvo に専用プロバイダーがないサービスの場合は、キーの送信先となるホストがカードに表示されます。キーは **その他のサービス** に保存され、Agent はそのホストへのリクエストでのみ使用できます。

Agent 自身がキーの中身を直接参照することはありません。保存された認証情報を識別子で指定するだけで、リクエストやコマンド出力にキーが含まれる箇所は `[redacted]` と表示されます。

iPhone チャットでは iPhone 上に **接続** カードが表示され、入力したキーは Mac 上の認証情報管理に保存されます。IM チャットでは、Agent がキーを直接尋ねることはなく、Enconvo でそのチャットを開くリンクを送信します。

メッセージ欄に誤って API キーをそのまま貼り付けた場合でも、Enconvo はそのキーを認証情報管理に保存し、保存されたチャット上では `[redacted]` に置き換えるため、以降のリクエストや他のデバイスにキーが渡ることはありません。すでにキーが保存されているサービスに対して新しいキーを貼り付けると、既存のキーが置き換わります。

## ウェブサイトとアプリのログイン

ブラウザ操作のタスクでサインインページに到達すると、ユーザー名とパスワードを一度だけ入力するカードが表示されます。Enconvo はそのサイトにのみ入力を行い、Agent がパスワードを見ることはありません。保存されたログイン情報は **ログイン** に表示されます。今回限りのサインインにしたい場合は **このログイン情報を記憶する** のチェックを外してください。

Mac アプリのサインインでパスワードが必要な場合は、カードに対象アプリ名が表示されます。Enconvo はそのアプリにのみユーザー名とパスワードを入力し、パスワードは入力内容を隠すパスワード欄にのみ入力します。

## カスタムエンドポイント

**OpenAI Compatible** と **Anthropic Compatible** プロバイダーには、独自サーバー用の API ベース URL 入力欄があります。一部のビルトインプロバイダーはエンドポイント設定を **認証情報管理** 内に保持しています。別のコンピュータ上のモデルサーバーに接続する場合は [ローカルモデル](/ja/ai/local-llm) を参照してください。

保存済みキーの送信先（プロバイダーや認証情報のアドレス、あるいは保存済みキーを使う MCP サーバーの設定）を変更できるのは Enconvo 自身のウィンドウのみです。ローカル API を使う外部プログラム、iPhone、および Agent からの変更は拒否されます。

## キーの保護方法

- 保存されたすべてのキーとサインイン情報は、この Mac のキーチェーンに保持される暗号化キーで暗号化されるため、Enconvo の設定フォルダを別のコンピュータにコピーしても読み取ることはできません。古いバージョンの Enconvo に戻した場合は、キーの再入力が必要になります。
- Enconvo の [ローカル API](/ja/advanced/cli-local-api) から設定を取得する外部プログラムには、各キーの代わりに `[hidden]` が返されます。ストアからインストールしたプラグインは、自身のキーと設定で選択された認証情報のみを使用できます。
- 保存されたキーを開けるのは、Enconvo がインストールし、かつ改変されていないコードのみです。設定画面では従来どおりキーの確認と検証を行えます。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 検証に失敗する | 選択しているプロファイル、認証方式、エンドポイント、およびプロバイダーのアカウントにアクセス権があるか確認してください。 |
| ある機能では動くが別の機能で失敗する | アカウントがその機能やモデルに対応しているか確認してください。API キーのみ対応しているカテゴリでは画面にその旨が表示されます。 |
| キーを変更したら別の機能が動かなくなった | プロファイルは共有されています。同じプロファイルを使う他のカテゴリもテストしてください。 |
| 使用量表示に **再接続** と出ている | サインインの有効期限が切れています。**再接続** をクリックして再度サインインしてください。 |

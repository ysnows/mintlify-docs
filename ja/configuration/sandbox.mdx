---
title: "エージェントのサンドボックス"
description: "エージェントのコマンドを作業フォルダー内に限定してキーや他のアプリから遠ざけ、コマンドの実行前に Enconvo が確認する理由を確認します。"
---

サンドボックスは、エージェントのシェルコマンドが到達できる範囲を制限します。オンにすると、コマンドが変更できるのはチャットの作業フォルダーと一時フォルダーだけになり、キーの読み取り、他のアプリの操作、Enconvo への接続は macOS が阻止します。1 つずつ見守りたくないコマンドを実行するエージェントには、オンにしておくと安心です。

サンドボックスは、エージェントの権限モードと組み合わせて働きます。権限モードは、操作の前に Enconvo が確認するタイミングを決め、サンドボックスは、実行されたコマンドにできることを制限します。

## サンドボックスをオンにする

1. チャットウィンドウ、SmartBar、Dynamic Island、アプリのサイドバー、またはプロジェクトのリードチャットで、エージェントとのチャットを開きます。
2. 実行モードの隣にある **権限** チップをクリックします。
3. **サンドボックス** をオンにします。

このスイッチはエージェントごとの設定なので、そのエージェントを使うすべてのウィンドウに適用されます。そのエージェントが呼び出すエージェントも、コマンドをサンドボックス内で実行します。

サンドボックスでエージェントのコマンドが到達できる範囲を確認するには、スイッチの下にある **サンドボックスの仕組み** をクリックします。そのエージェント自身のサンドボックスが図で表示されます。作業フォルダー、権限モード、コマンドが到達できる場所と到達できない場所が分かります。

## サンドボックス内のコマンドが到達できる範囲

| 場所 | サンドボックス内での扱い |
| --- | --- |
| 作業フォルダーと一時フォルダー | 読み取りと変更が可能 |
| それ以外のファイル | 読み取りは可能、変更は不可 |
| インターネット | 接続可能 |
| SSH キー、キーチェーン、Cookie などのキーやパスワード | 読み取り不可 |
| 保存済みの認証情報と Enconvo の設定 | 読み取り不可 |
| 他のアプリ | 開いたり操作したりできない |
| Enconvo | 接続できない |

コマンドが起動するすべてのプログラムも、サンドボックス内で実行されます。Enconvo は macOS 標準のサンドボックスを使います。App Store のアプリが使っているものと同じです。

## サンドボックスがコマンドを止めたとき

コマンドがサンドボックスで制限されているものにアクセスしようとすると、macOS が拒否し、ステップの下の行に、フォルダーへの書き込みやキーファイルの読み取りなど、何が止められたかが表示されます。

1. その行をクリックすると、何がなぜ止められたかが表示されます。
2. そのコマンドに実行させるには、**サンドボックス外で実行** をクリックします。コマンドは、あなたのフルアクセスで一度だけ実行され、他のコマンドと同じようにチャットに表示されます。許可は記憶されません。

**サンドボックス外で実行** は、実行中で、誰かがその実行を見守っているときにだけ表示されます。予約タスクなど、誰も見守っていない実行では、サンドボックスの外でコマンドが実行されることはありません。

## コマンドの前に Enconvo が確認する理由

何を確認するかは、サンドボックスの有無にかかわらず、エージェントの権限モードで決まります。[操作を承認する](/ja/ai/agents) を参照してください。

| モード | サンドボックスがオンの場合 |
| --- | --- |
| **承認を求める** | すべてのコマンドが、実行前に確認されます。サンドボックスは、許可したコマンドにできることを制限します。 |
| **自動で承認** | ファイルの削除や公開などのリスクのあるものを除き、確認なしでコマンドが実行されます。 |
| **フルアクセス** | 確認なしでコマンドが実行されます。コンピューターに害を及ぼしうる変更だけが確認されます。 |

Enconvo は各コマンドを部分ごとに読み取ります。そのため、引用符、入れ子、連結、パイプの中に害のあるステップが隠れていても確認が行われ、echo やフォルダーの一覧表示のような無害なものは確認されません。

**フルアクセス** であっても、重要なフォルダーの削除、シェルの起動ファイルや SSH キーの編集、保存済みパスワードの読み取りなど、コンピューターに害を及ぼしうる変更の前には、コマンドがパスをどう書いていても、Enconvo が **一度だけ許可** と **拒否** で確認します。

**自動で承認** では、ルールで判断できないコマンドは、あなたの依頼内容と照らして確認されます。コマンドが自動で実行されることを想定しにくい場合は、Enconvo が理由を添えて確認します。

各承認カードには、確認が行われた設定が表示されます。たとえば、「このプロジェクトが自動で承認に設定されているため確認しました」のように表示されます。

## 確認が行われるその他の操作

- [コンピューター操作](/ja/features/computer-use)では、クリックと同じように、削除、送信、支払い、アプリの終了、サインアウトを行うキーボードショートカットの前に確認します。
- プラグインページ自身のルートを呼び出すコマンドは、先に確認します。
- プラグインのツールを承認すると、そのツールが送信しようとする内容が表示されます。
- エージェントは、[友だち](/ja/features/friends)やチームメイトに電話やメッセージを送る前に確認します。**フルアクセス** では確認しません。
- エージェントは、自分の承認カードに答えたり、自分の権限を引き上げたり、プラグインのインストールやポイント上限など、あなた宛てのカードに答えたりすることはできません。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| コマンドが権限エラーで失敗する | サンドボックスが止めた可能性があります。ステップの下の行をクリックし、そのコマンドを信頼できる場合は **サンドボックス外で実行** を選んでください。 |
| エージェントがコマンドからアプリを開いたり操作したりできない | サンドボックス内のコマンドは他のアプリを操作できません。[コンピューター操作](/ja/features/computer-use)を使うか、このエージェントのサンドボックスをオフにしてください。 |
| Enconvo が確認してくると思ったのに、確認されなかった | **権限** チップで、そのエージェントの権限モードを確認してください。**フルアクセス** では、コンピューターに害を及ぼしうる変更の前にだけ確認されます。 |
| **サンドボックス** のスイッチが表示されない | チャットがエージェントモードになっているか確認し、Enconvo を更新してください。[アップデート](/ja/configuration/updates) を参照してください。 |

---
title: "設定リファレンス"
description: "設定サイドバーのすべての項目について、何を制御するかと、説明するガイドを紹介します。"
---

Enconvo の設定サイドバーのすべての項目を、サイドバーの順に、説明するガイドとともに紹介します。設定を開くには、メニューバーの Enconvo アイコンをクリックして **設定** を選びます。項目に移動するには、**設定を検索** に名前を入力するか、質問を入力して Return を押すと、設定の場所を AI に尋ねられます。

ガイドでは、**設定 → SmartBar** のように、以下の名前で設定のパスを表記します。

## グローバルプロバイダー設定

| 項目 | 制御する内容 |
| --- | --- |
| [AI モデル](/ja/providers/overview) | チャットモデル、自動ルート、プロバイダーのキーとプランのサインイン。バックグラウンドジョブ用の **タスクモデル** と、チャットのモデルが失敗したときの **フォールバック** モデルも含みます。 |
| [テキスト読み上げ](/ja/ai/text-to-speech) | テキストを読み上げる音声と、ボイスクローン。 |
| [ウェブ検索](/ja/ai/web-search) | エージェントが使う検索サービス。 |
| [画像生成](/ja/ai/image-generation) | 画像モデル。 |
| [動画生成](/ja/ai/video-generation) | 動画モデル。 |
| [Web ページを取得](/ja/ai/web-fetch) | ウェブページの読み取り方法。 |
| [OCR](/ja/ai/ocr) | 画像からテキストを読み取る方法。 |

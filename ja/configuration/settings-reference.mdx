---
title: "設定リファレンス"
description: "設定サイドバーにあるすべての項目、管理する内容、および解説ガイドの一覧です。"
---

Enconvo の設定サイドバーにあるすべての項目を、サイドバーの表示順に解説ガイドとあわせてまとめています。設定を開くには、メニューバーの Enconvo アイコンをクリックして **設定** を選びます。特定の項目にすぐ移動するには、**設定を検索** に項目名を入力するか、質問を入力して Return キーを押すと AI に設定場所を尋ねられます。

各ガイドでは、**設定 → SmartBar** のように以下の名前で設定パスを表記しています。

## グローバルプロバイダー設定

| 項目 | 管理する内容 |
| --- | --- |

| [テキスト読み上げ](/ja/ai/text-to-speech) | テキストを読み上げる音声と音声クローン。 |
| [ウェブ検索](/ja/ai/web-search) | エージェントが使用する検索サービス。 |
| [画像生成](/ja/ai/image-generation) | 画像モデル。 |
| [動画生成](/ja/ai/video-generation) | 動画モデル。 |
| [Web ページを取得](/ja/ai/web-fetch) | ウェブページの読み取り方法。 |
| [OCR](/ja/ai/ocr) | 画像からテキストを読み取る方法。 |

Enconvo では、アプリ本体と AI の利用料金が分かれています。ライセンスでアプリ本体がアンロックされ、AI には Enconvo Cloud ポイント、ご自身の API キー、サインインしたプロバイダーのプラン、または Mac 上のローカルモデルを利用でき、それぞれ別の場所で課金されます。現在アカウントで利用できるプランと料金は、**設定 → アカウント** および Enconvo のウェブサイトで確認してください。

## AI の支払い方法

| 利用方法 | 対象範囲 | 使用量の確認場所 |
| --- | --- | --- |
| Enconvo 永久ライセンス | アプリの機能へのアクセス | **設定 → アカウント** の **永久ライセンス** |
| Enconvo Cloud プラン | ポイントで支払うクラウドモデルとサービス | **設定 → ポイント使用量** |
| ご自身の API キー | 該当プロバイダーへのリクエスト | プロバイダー側の API アカウント |
| サインインしたプロバイダーのプラン | そのプランでサポートされる機能と上限 | 設定内のプロバイダーページ |
| ローカルモデル | Mac の計算リソース・メモリ・ストレージ、およびモデルのダウンロード | ご自身の Mac |

アプリライセンスを購入しても、各プロバイダーの有料 API クレジットは付与されません。また、プロバイダーのチャット向けプランには、そのプロバイダーのすべての API が含まれるわけではありません。

## Enconvo のプラン

- **永久ライセンス**: アプリの買い切りライセンスで、Standard と Premium の 2 つのティアがあり、ボーナスポイントが付与されます。ご自身の API キーを使えば、制限なく AI を利用できます。Teams は組織向けの永久ライセンスで、シートを購入してメールアドレスごとに割り当てます。詳しくは [Teams](/ja/configuration/account) をご覧ください。
- **Enconvo Cloud**: 月額または年額プランで、Plus、Pro、Max のティアがあります。毎月ポイントが付与され、API キー不要でクラウドモデルを利用できます。
- **Standard トライアル**: 無料アカウントでは、クレジットカード登録不要の 7 日間 Standard トライアルを 1 回利用できます。対象の場合、**設定 → アカウント** に **トライアルを開始** が表示されます。
- **コード**: ライセンスコードとトライアルコードは **設定 → コードを引き換える** で有効化します。Teams ライセンスコードを使うと、そのアカウントがコードのシートのチーム管理者となり、1 シートあたり 50,000 Cloud ポイントが付与されます。

永久ライセンスは常に Standard と Premium と呼ばれ、Cloud プランの Plus や Pro とは名前が異なります。

最新のプランと料金については以下をご覧ください。

- [Enconvo ウェブサイト](https://www.enconvo.com)
- [Enconvo Cloud プラン](https://www.enconvo.com/cloud-plan)
- [Cloud モデルの料金](https://www.enconvo.com/cloud-pricing)

## Cloud ポイントの消費方法

サブスクリプションポイントが先に消費され、更新のたびにプランの規定量にリセットされます。追加チャージや永久ライセンスで付与されたチャージポイントに有効期限はありません。

リクエストあたりの消費量は、モデルと、その機能が実際に使用するアクセス方法によって決まります。テキスト、画像、動画、文字起こし、埋め込み、リアルタイム音声は、それぞれ異なる料金設定になる場合があります。

## 予期しない使用量を確認する

1. Enconvo Cloud の場合は **設定 → ポイント使用量**、ご自身の API キーの場合は各プロバイダーの使用量ページを開きます。
2. **設定 → 使用状況の統計** を開き、モデル、プロバイダー、機能ごとの推定コスト、トークン数、リクエスト数を確認します。
3. 同じプロバイダープロファイルを共有しているスケジュールタスク、長時間実行タスク、検索、生成リクエストがないか確認します。

Enconvo では、アプリと、アプリが呼び出す AI を分けて扱います。ライセンスはアプリを使えるようにするものです。AI は、Enconvo Cloud のポイント、自分の API キー、サインインしたプロバイダーのプラン、Mac 上のモデルのいずれかから利用でき、それぞれ別の場所で課金されます。現在ご利用のアカウントで選べるプランと料金は、**設定 → アカウント** と Enconvo の Web サイトで確認してください。

## AI の支払い方法

| 利用方法 | 対象 | 使用状況の確認先 |
| --- | --- | --- |
| Enconvo の永久ライセンス | アプリの機能 | **設定 → アカウント** の **永久ライセンス** |
| Enconvo Cloud プラン | ポイントで支払うクラウドモデルとサービス | **設定 → ポイント使用量** |
| 自分の API キー | そのプロバイダーへのリクエスト | プロバイダー自身の API アカウント |
| サインインしたプロバイダーのプラン | プランが対応する機能と上限 | 設定内のプロバイダーのページ |
| ローカルモデル | Mac の演算能力、メモリ、ストレージ、およびモデルのダウンロード | お使いの Mac |

アプリのライセンスを購入しても、どのプロバイダーの API クレジットも付与されません。また、プロバイダーのチャットプランには、そのプロバイダーのすべての API が含まれるわけではありません。

## Enconvo のプラン

- **永久ライセンス**: アプリを一度だけ購入する形で、Standard と Premium の 2 つのティアがあり、ボーナスポイントが付きます。自分の API キーであれば AI を好きなだけ使えます。Teams は組織向けの永久ライセンスです。シートを購入し、メールアドレスごとに割り当てます。[Teams](/ja/configuration/account) を参照してください。
- **Enconvo Cloud**: Plus、Pro、Max のティアがある月額または年額のプランです。毎月ポイントが加算され、API キーなしで使えるクラウドモデルが利用できます。
- **Standard トライアル**: 無料アカウントでは、カード不要で 7 日間の Standard トライアルを一度だけ利用できます。利用できる場合は、**設定 → アカウント** に **トライアルを開始** が表示されます。
- **コード**: ライセンスコードとトライアルコードは **設定 → コードを引き換える** で有効にします。Teams ライセンスコードを使うと、あなたのアカウントがそのコードのシートのチーム管理者になり、シートごとに 50,000 のクラウドポイントが付与されます。

永久ライセンスの名称は常に Standard と Premium です。Cloud プランの Plus や Pro と名前が重ならないようにするためです。

最新のプランと料金は、こちらをご覧ください。

- [Enconvo の Web サイト](https://www.enconvo.com)
- [Enconvo Cloud プラン](https://www.enconvo.com/cloud-plan)
- [クラウドモデルの料金](https://www.enconvo.com/cloud-pricing)

## Cloud ポイントの使われ方

サブスクリプションのポイントが先に使われます。このポイントは、更新のたびにプランの付与量にリセットされます。チャージパックや永久ライセンスで得たチャージポイントは、期限なく使えます。

リクエストの費用は、機能が実際に使うモデルとアクセス方法によって決まります。テキスト、画像、動画、文字起こし、埋め込み、リアルタイム音声は、それぞれ価格が異なる場合があります。

## 想定外の使用量を調べる

1. Enconvo Cloud の場合は **設定 → ポイント使用量** を、自分の API キーの場合はプロバイダー自身の使用状況ページを開きます。
2. **設定 → 使用状況の統計** を開くと、モデル、プロバイダー、機能ごとの推定コスト、トークン数、リクエスト数を確認できます。
3. 同じプロバイダープロファイルを共有している、予約タスク、長時間実行タスク、検索、生成のリクエストに注目します。

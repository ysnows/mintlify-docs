---
title: "モデルを選ぶ"
description: "作業に合ったモデルを選び、Enconvo のデフォルトモデルがどこで設定されるかを確認します。"
---

毎回手動で選ぶ必要はありません。デフォルトモデルの [Auto Route](/ja/providers/auto-route) がメッセージごとに最適なモデルを選択します。特定のモデルを使いたいときは、このページを参考に選び、設定がどこに保存されるかを確認してください。

## タスク別に選ぶ

| タスク | 重視するポイント |
| --- | --- |
| ちょっとした書き換えや短い回答 | 高速で低コストなモデル |
| 複数ステップの Agent 作業 | 安定したツール呼び出しと推論サポート |
| スクリーンショットや画像についての質問 | 画像入力対応 |
| 長文のドキュメント | 長いコンテキストウィンドウ |
| Mac 内に留めたいプライバシー重視の作業 | [ローカルモデル](/ja/ai/local-llm)と、ほかのステップ用のローカルプロバイダー |
| 音声での会話 | 独自の音声設定を持つ [Live Talk](/ja/features/live-voice) |
| 画像や動画の作成 | チャットモデルではなく、[画像生成](/ja/ai/image-generation)または[動画生成](/ja/ai/video-generation)プロバイダー |

モデルピッカーには、お使いのプロバイダーが現在提供しているモデルが表示されます。高速モード（Fast mode）に対応しているモデルには Fast mode チップが表示され、高めの料金でより高速に動作させることができます。

## おすすめ表示を活用する

設定内のモデルピッカーでは、その作業向けにおすすめの 3 つ（**最適**、**最安**、**最高画質**）が先頭に表示されます。それぞれに簡単な理由と、入力・出力 1M トークンあたりの価格が載っています。設定の下には、選択したモデルがおすすめより何倍も高価な場合に注意書きが表示されます。

**新しい Agent** で Agent を作成すると、Enconvo が Agent の説明を読み取っておすすめのモデルを 1 つ提案し、その横に安価なモデルと高性能なモデルを並べて表示します。クリックするだけで適用できます。

## デフォルトが設定される場所

- **新しいチャット**：最上位の **新規チャット** で選んだモデルが Agent のデフォルトになります。
- **プロジェクト**：プロジェクト内の新しいチャットには、そのプロジェクト独自のモデルが使われます。
- **既存のチャット**：チャットが始まると、そのチャット内で変更するまで同じモデルと推論の強さが維持されます。
- **独自設定のないチャットや IM チャネル**：これらは Agent のデフォルト設定に従います。

別の場所でデフォルトを変更した後は、送信前にチャット画面に表示されているモデルを確認してください。

## 推論の強さ

推論の強さは、モデルが回答する前にどれだけ思考に時間をかけるかを決めます。強さを上げると難しい問題でより良い回答が得られることがありますが、時間がかかりトークン消費も増えます。選択できるレベルはモデルによって異なり、思考モードがないモデルにはこの設定がありません。

## コンテキストウィンドウ

コンテキストウィンドウは、モデルが一度に読み取れる会話の量です。チャットがこれを超えると、Enconvo が前半部分を要約・圧縮します。最大 1M トークンに対応した Claude モデルも初期値は 500K に設定されており、長いチャットでも早めに圧縮してコストを抑えられるようになっています。

モデルのコンテキストウィンドウを変更するには、**設定 → AI モデル** でプロバイダーを開き、**モデルを管理**（**モデル名** の横にある歯車アイコン）をクリックしてモデルを編集し、**コンテキストウィンドウ** を設定してください。

## バックグラウンド処理用のモデルを選ぶ

チャットタイトル、次のメッセージの提案、Live Talk、録音のタイトルと要約、録音の翻訳、アイデアのタイトルといった小さな処理は、バックグラウンドで安価なモデルを使って実行されます。デフォルトではいずれも **Auto** になっており、小型モデルが選ばれます。

- チャットタイトル、次のメッセージの提案、Live Talk には、そのチャット自身のプロバイダーの小型モデルが使われます。ご自身の API キーを使ったチャットでは、これらで Enconvo Cloud ポイントを消費しません。
- 録音関連とアイデアのタイトルには、デフォルトプロバイダーの小型モデルが使われます。
- Enconvo が認識している小型モデルがそのプロバイダーにない場合、Auto はチャットのモデルまたはデフォルトモデルを使用します。

自分でモデルを指定するには次のようにします。

<Steps>
  <Step title="タスクモデルを開く">
    **設定 → AI モデル** を開き、ページ上部の **タスクモデル** をクリックします。
  </Step>
  <Step title="タスクを選ぶ">
    タスクをクリックします。**Auto** ではプロバイダーごとにどのモデルが選ばれるかを確認できます。
  </Step>
  <Step title="モデルを選ぶ">
    **モデルを選択** をクリックし、プロバイダーを選んでからモデルを選択します。
  </Step>
</Steps>

各回答の後に次のメッセージ候補を出さないようにするには、**次のメッセージの提案** の横のスイッチをオフにします。**すべて Auto に戻す** をクリックすると、すべてのタスクが **Auto** に戻ります。

## バックアップモデルで会話を止めない

フォールバックを使うと、使用中のモデルが利用制限に達した、サインインやキーが無効になった、接続できなくなったといった場合でも返信を続けられます。返信は次のバックアップモデルで続行され、どのモデルがなぜ引き継いだかがチャットに表示されます。

<Steps>
  <Step title="フォールバックを開く">
    **設定 → AI モデル** を開き、ページ上部の **フォールバック** をクリックします。
  </Step>
  <Step title="バックアップを追加する">
    **バックアップモデルを追加** をクリックしてモデルを選びます。最大 3 つまで追加でき、ドラッグして順番を変更できます。
  </Step>
  <Step title="各バックアップの強さを設定する">
    推論レベルを持つモデルでは、それぞれの **推論の強さ** を設定します。各バックアップが個別に設定を保持します。
  </Step>
</Steps>

パネルには連携の順番が表示されます。最初に **使用中のモデル**、続いて番号付きのバックアップが並び、それぞれ **準備完了** または **一時停止中** の状態が表示されます。バックアップのモデル名をクリックすると、同じプロバイダーの別モデルに切り替えられます。プロバイダー一覧では、バックアップを含む各プロバイダーに順番を示す **backup N** タグが付きます。

| 設定 | 説明 |
| --- | --- |
| **サービスが混雑しているときも切り替える** | リトライ上限に達した後、レート制限やサーバーエラー時にも切り替えます。 |
| **モデルが再び使えるようになったら戻る** | 元のモデルが復旧したら、次のターンから元のモデルに戻します（ターンの途中で切り替わることはありません）。 |

安全性ポリシーによって拒否されたリクエストでは、モデルは切り替わりません。

## 2 つのモデルを比較する

同じ小さな実務タスクを両方に送ってみてください。回答が正しいか、ツールが完了したか、どれくらい時間とコストがかかったかを確認します。各返信の下にある **詳細** に、モデル、推論の強さ、トークン数、所要時間、ポイントまたはコストが表示されます。

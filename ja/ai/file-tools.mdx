title: "ファイルとフォルダ"
description: "Mac 上のファイルをエージェントが検索、読み取り、編集できるようにします。"
---

ファイルツールを使うと、エージェントがファイルを検索し、中身を調べ、読み取り、編集できます。フォルダやファイルを指定して普段どおりに依頼するだけで、エージェントが適切なツールを選び、使用した内容を表示します。

## 始める前に

- **作業フォルダ:** エージェント設定の**定義**セクションにある**作業フォルダ**が、相対パスの起点になります。
- **承認:** チャット内の**権限**チップによって、エージェントが事前に確認を求めるかどうかが決まります。**承認を求める**が選択されている場合、作業フォルダ外のファイルを編集する前に確認を求めます。読み取りや検索では確認を求めません。詳しくは[アクションの承認](/ja/ai/agents)をご覧ください。

## 読み取り専用タスクから始める

1. エージェントの設定で、ファイルツールと**作業フォルダ**を確認します。
2. チャットでフォルダ名を指定するか、使いたいファイルを添付します。
3. 「このプロジェクト内の Markdown ファイルを探して、README を要約して」のような範囲を限定した質問をします。
4. 変更を依頼する前に、エージェントが参照したファイルとツール出力を確認します。

## 各ツールの役割

| ツール | 内容 |
| --- | --- |
| Glob | `**/*.md` などのパスパターンでファイルを新しい順に検索します |
| Grep | ファイル内のテキストを、ファイルパターンや行番号付きで検索します |
| Read File | テキストファイルの読み取り、ドキュメントからのテキスト抽出、画像・音声・動画の読み取りを行います |
| Edit File | ファイル内の指定したテキストを正確に置換し、変更された行を報告します |
| Write File | ファイルの新規作成、または内容の全面的な置き換えを行います |

<Warning>
Write File は確認なしで既存のファイルを上書きすることがあります。重要なドキュメントはコピーを残すかバージョン管理を利用し、承認する前に保存先と変更内容を確認してください。チャット中にエージェントが変更したファイルは、サイドパネルの**変更**タブに一覧表示され、**元に戻す**で戻せます。
</Warning>

## ドキュメントとメディア

PDF、Office ドキュメント、画像、音声ファイル、動画を読み取る際、生のバイト列を返す代わりに解析、OCR、または文字起こしを実行する場合があります。音声や動画の場合、エージェントは文字起こし結果を読み取ります。スプレッドシートでは、数式セルはその計算値として読み取られ、一度も計算されていない場合は数式そのものが読み取られます。どの形式に対応するかは、インストールされているツールと設定したプロバイダーによって異なります。詳しくは [OCR](/ja/ai/ocr)、[文字起こし](/ja/features/transcription)、[ナレッジベース](/ja/ai/knowledge-base)をご覧ください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| アクセスエラーが出る | エージェントの**作業フォルダ**、**権限**チップ、および macOS のアクセス権限を確認してください |
| ドキュメントが空として読み込まれる | ファイル形式と解析可能かどうかを確認してください。スキャンされた PDF には OCR が必要な場合があります |
| 編集時に置換対象のテキストが見つからない | 編集前に、現在のファイルをもう一度読み取るようエージェントに依頼してください |

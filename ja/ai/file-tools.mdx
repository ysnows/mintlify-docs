ファイルツールを使うと、エージェントがファイルを探し、ファイルの中を検索し、読み込み、編集できます。エージェントにフォルダやファイルを指定して、普通の言葉で頼むと、適切なツールが選ばれ、使ったツールが表示されます。

## 始める前に

- **作業フォルダ:** エージェントの設定の **定義** にある **作業フォルダ** が、相対パスの起点になります。
- **承認:** チャットの **権限** チップが、エージェントが先に確認を求めるタイミングを決めます。**承認を求める** の場合、作業フォルダの外にあるファイルを編集する前に確認を求めます。読み取りと検索では、確認を求めません。[アクションを承認する](/ja/ai/agents)を参照してください。

## 読み取り専用のタスクから始める

1. エージェントの設定で、ファイルツールと **作業フォルダ** を確認します。
2. チャットで、フォルダ名を伝えるか、使いたいファイルを添付します。
3. 「このプロジェクトの Markdown ファイルを探して、README を要約して」のように、範囲を絞った質問をします。
4. 何かを変更するよう頼む前に、エージェントが使ったファイルとツールの出力を確認します。

## 各ツールの役割

| ツール | 内容 |
| --- | --- |
| Glob | `**/*.md` のようなパスのパターンでファイルを探し、新しいものから順に返します |
| Grep | ファイルの中のテキストを、ファイルパターンと行番号付きで検索します |
| Read File | テキストファイルを読み取り、ドキュメントからテキストを抽出し、画像、音声、動画を読み取ります |
| Edit File | ファイル内の正確なテキストを置き換え、変更した行を報告します |
| Write File | ファイルを作成するか、内容をすべて置き換えます |

<Warning>
Write File は、既存のファイルを警告なしに上書きすることがあります。重要なドキュメントは、コピーを残すかバージョン管理を使い、承認する前に保存先と変更内容を確認してください。チャットでエージェントが変更したファイルは、サイドパネルの **変更** タブに **元に戻す** 付きで一覧表示されます。
</Warning>

## ドキュメントとメディア

PDF、Office ドキュメント、画像、音声ファイル、動画を読み取ると、生のバイト列を返すのではなく、解析、OCR、文字起こしが実行されることがあります。音声と動画では、エージェントは文字起こしを読み取ります。スプレッドシートでは、数式のセルは、その値として読み取られます。一度も計算されていない場合は、数式そのものとして読み取られます。どの形式が使えるかは、インストールされているツールと、設定したプロバイダーによって決まります。[OCR](/ja/ai/ocr)、[文字起こし](/ja/features/transcription)、[ナレッジベース](/ja/ai/knowledge-base)を参照してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| アクセスエラー | エージェントの **作業フォルダ**、**権限** チップ、macOS の権限を確認してください |
| ドキュメントが空として読み取られる | ファイルの種類と、解析できるかどうかを確認してください。スキャンした PDF には OCR が必要なことがあります |
| 編集で、置き換えるべきテキストが見つからない | 編集する前に、現在のファイルをもう一度読み取るよう、エージェントに頼んでください |

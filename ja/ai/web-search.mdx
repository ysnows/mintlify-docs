---
title: "ウェブ検索"
description: "エージェントに Web を検索させて最新情報を取得し、出典を示させます。"
---

ウェブ検索を使うと、エージェントが Web から最新の検索結果を取得できます。どのエージェントでも検索できます。回答を書くモデルとは別に、使う検索サービスを選べます。

## 検索プロバイダーを選ぶ

1. **設定 → ウェブ検索** を開きます。
2. プロバイダーを選びます。Enconvo Cloud のオプションは API キーが不要です。その他のほとんどでは、そのサービスの API キーを追加します。
3. **デフォルトに設定** をクリックします。

| プロバイダー | 備考 |
| --- | --- |
| **自動** | チャットモデル自身の Web 検索で検索し、モデルに検索機能がない場合は別のプロバイダーに切り替えます。[モデル自身の検索を使う](#モデル自身の検索を使う)を参照してください。 |
| **Enconvo Cloud** | サインイン済みのすべてのアカウントで無料、API キー不要 |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud 経由の DeepSeek 検索。サインイン済みのすべてのアカウントで無料 |
| **Gemini** | Gemini モデルによる Google 検索でのグラウンディング |
| **Tavily**、**Bing**、**Brave**、**Google Custom**、**Exa** | 各サービスの自分のキーで検索 |
| **Parallel** | Parallel の AI 検索インデックス。各ページの最も関連性の高い箇所を返します。Parallel の API キーを使用 |
| **PipeLLM** | [PipeLLM](/ja/providers/pipellm) のキーで Google の結果を取得 |
| **DeepSeek** | DeepSeek の API キーで DeepSeek 検索 |
| **xAI X Search** | X の投稿、プロフィール、スレッドを検索。xAI の API キーまたは xAI のサインインを使用 |
| **xAI X Search (Enconvo Cloud)** | Enconvo Cloud プラン経由の X 検索 |

プロバイダーの一覧には、無料のオプションに印が付いています。全一覧は[プロバイダーカタログ](/ja/providers/catalog)を参照してください。一部のモデルには、各プロバイダーの設定内に、グラウンディングや検索のオプションが組み込まれているものもあります。

## モデル自身の検索を使う

**自動** では、チャットで使っているモデルに Web 検索機能がある場合、その検索が使われます。対象は OpenAI、Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、Z.ai、OpenRouter です。そのモデル用に接続したキーまたはサインインが使われ、料金はモデルの提供元に請求されます。

モデルに独自の検索機能がない場合や、検索が失敗した場合、自動は **代替検索** を使います。別のプロバイダーを選ばない限り、これは **Enconvo Cloud** です。

| 設定 | 内容 |
| --- | --- |
| **検索ルート** | チャットモデルでどの検索が実行されるか、失敗時にどうなるかを表示します。 |
| **モデル内蔵の検索を優先** | デフォルトでオンです。常に代替検索を使うには、オフにします。 |
| **代替検索** | モデルに検索機能がない場合や、検索が失敗した場合に使われるプロバイダーです。 |

チャットでは、各 Web 検索のステップに、どの検索が回答したかと、自動が代替に切り替えた場合はその理由が表示されます。

## Parallel を使う

1. [Parallel](https://platform.parallel.ai) で API キーを取得します。
2. **設定 → 認証情報の管理 → Parallel** に追加します。
3. **設定 → ウェブ検索** で **Parallel** を選び、**検索モード** を選びます。

| 検索モード | 用途 |
| --- | --- |
| **Turbo** | 最速で回答します。英語と日本語のクエリのみ読み取ります。 |
| **高速** | ほとんどの検索向けです。デフォルトです。 |
| **Basic** | 各ページからより長い箇所を取得します。 |
| **詳細設定** | 最も深い検索です。約 3 秒かかり、料金も高くなります。 |

Parallel の料金は、各検索ごとにあなたの Parallel アカウントに請求されます。

## エージェントで検索する

1. 具体的な質問をします。重要な場合は、期間や場所を含めてください。
2. エージェントが検索し、出典へのリンクを付けて回答します。
3. 引用された出典を開いて、回答の裏付けになっているか確認します。

例:

> このライブラリの最新の安定版の公式リリースノートを探して、破壊的変更をリンク付きで要約してください。

## 適切な Web 機能を選ぶ

| 必要なこと | 使うもの |
| --- | --- |
| 関連する情報源を探す | ウェブ検索 |
| URL が分かっているページを読む | [Web ページを取得](/ja/ai/web-fetch) |
| 結果をブラウザで開く | [クイックリンク](/ja/features/quick-links) |
| サインイン済みの Web サイトを操作する | [ブラウザを使用](/ja/features/browser-control) |
| X の投稿、プロフィール、スレッドを検索する | **xAI X Search** プロバイダー |

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 回答に出典がない | エージェントがモデルだけで回答せず、検索したかを確認してください。Web を検索するように頼んでください。 |
| プロバイダーがエラーを返す | プロバイダーの認証情報と、そのサービスでのアカウントの利用枠を確認してください。 |
| 自動が代替検索を使った | チャットモデルに独自の Web 検索機能がないか、検索が失敗しています。どちらかは、チャットの検索ステップに表示されます。 |
| 結果がログインの先や、操作が必要なページにある | [ブラウザを使用](/ja/features/browser-control)のような対応するブラウザ操作を使ってください。公開 URL を取得しても、サインイン済みのセッションにはアクセスできません。 |

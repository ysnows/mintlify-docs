---
title: "ウェブ検索"
description: "Agent にウェブ検索を行わせて最新情報を取得し、出典を明記させます。"
---

ウェブ検索を使うと、Agent がウェブから最新の検索結果を取得できます。どの Agent でも検索が可能で、回答を生成するモデルとは別に、使用する検索サービスを選択できます。

## 検索プロバイダーを選ぶ

1. **設定 → ウェブ検索** を開きます。
2. プロバイダーを選択します。Enconvo Cloud のオプションには API キーが不要です。それ以外の多くは、そのサービスのキーを追加します。
3. **デフォルトに設定** をクリックします。

| プロバイダー | 備考 |
| --- | --- |
| **Auto** | チャットモデルの独自ウェブ検索で検索し、モデルに検索機能がない場合は別のプロバイダーにフォールバックします。詳しくは[モデル内蔵の検索を使う](#モデル内蔵の検索を使う)をご覧ください。 |
| **Enconvo Cloud** | サインイン済みのすべてのアカウントで無料、API キー不要 |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud 経由の DeepSeek 検索。サインイン済みのすべてのアカウントで無料 |
| **Gemini** | Gemini モデルを通じた Google 検索グラウンディング |
| **Tavily**、**Bing**、**Brave**、**Google Custom**、**Exa** | 各サービスのご自身のキーで検索 |
| **Parallel** | ご自身の Parallel API キーを使い、各ページから最も関連性の高い抜粋を返す Parallel の AI 検索インデックス |
| **PipeLLM** | お使いの [PipeLLM](/ja/providers/pipellm) キー経由の Google 検索結果 |
| **DeepSeek** | ご自身の DeepSeek API キーを使った DeepSeek 検索 |
| **xAI X Search** | xAI API キーまたは xAI サインインを使って X の投稿、プロフィール、スレッドを検索 |
| **xAI X Search (Enconvo Cloud)** | Enconvo Cloud プラン経由の X 検索 |

プロバイダー一覧には無料のオプションにマークが付いています。全一覧は[プロバイダーカタログ](/ja/providers/catalog)をご覧ください。一部のモデルには、プロバイダー独自の設定内に組み込みのグラウンディングや検索オプションもあります。

## モデル内蔵の検索を使う

**Auto** を選ぶと、チャットで使用しているモデルに独自のウェブ検索機能がある場合にその検索を実行します（OpenAI、Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、Z.ai、OpenRouter が対象）。そのモデルに接続したキーまたはサインインが使われ、料金もそのモデルの提供元から請求されます。

モデルに独自の検索機能がない場合や検索に失敗した場合、Auto は **代替検索** を使用します。別のプロバイダーを選ばない限り、デフォルトは **Enconvo Cloud** です。

| 設定 | 説明 |
| --- | --- |
| **検索ルート** | チャットモデルに対してどの検索が実行されるか、および失敗時の動作を表示します。 |
| **モデル内蔵の検索を優先** | デフォルトでオンです。オフにすると常に代替検索を使用します。 |
| **代替検索** | モデルに検索機能がない場合、または検索に失敗した場合に使用するプロバイダーです。 |

チャットでは、各ウェブ検索ステップにどの検索が使われたかと、フォールバックが発生した理由が表示されます。

## Parallel を使う

1. [Parallel](https://platform.parallel.ai) から API キーを取得します。
2. **設定 → 認証情報の管理 → Parallel** にキーを追加します。
3. **設定 → ウェブ検索** で **Parallel** を選び、**検索モード** を選択します。

| 検索モード | 用途 |
| --- | --- |
| **Turbo** | 最も高速に回答します。英語と日本語のクエリのみ対応しています。 |
| **Fast** | ほとんどの検索に適しています。デフォルトです。 |
| **Basic** | 各ページからより長い抜粋を取得します。 |
| **Advanced** | 最も深い検索を行います。約 3 秒かかり、コストが高くなります。 |

Parallel の検索料金はご自身の Parallel アカウントに請求されます。

## Agent で検索する

1. 具体的な質問をします。重要な場合は日付範囲や場所も含めてください。
2. Agent が検索を実行し、出典リンク付きで回答します。
3. 引用された出典を開き、回答内容を裏付けているか確認してください。

例：

> Find the official release notes for this library's latest stable version and summarize breaking changes with links.

## 用途に合ったウェブ機能を選ぶ

| 目的 | 使用する機能 |
| --- | --- |
| 関連する情報源を探す | ウェブ検索 |
| 既知の URL を読む | [Web Fetch](/ja/ai/web-fetch) |
| ブラウザで結果を開く | [クイックリンク](/ja/features/quick-links) |
| ログイン済みサイトを操作する | [ブラウザ操作](/ja/features/browser-control) |
| X の投稿・プロフィール・スレッドを検索する | **xAI X Search** プロバイダー |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 回答に出典がない | Agent がモデルの知識だけで答えず検索を実行したか確認してください。ウェブ検索するよう明示的に指示してください。 |
| プロバイダーがエラーを返す | プロバイダーの認証情報と、そのサービスでのアカウント利用枠を確認してください。 |
| Auto が代替検索を使った | チャットモデルに独自のウェブ検索がないか、検索に失敗しています。チャットの検索ステップに詳細が表示されます。 |
| 結果がログイン先やインタラクティブページにある | [ブラウザ操作](/ja/features/browser-control)などの対応フローを使用してください。公開 URL の取得ではログイン済みセッションにアクセスできません。 |

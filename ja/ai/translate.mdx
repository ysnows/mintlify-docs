---
title: "翻訳"
description: "選択したテキスト、画面の一部、または音声入力の内容を翻訳します。"
---

Enconvo では、選択したテキストを **翻訳ツール**（Translator）で、画面上のテキストを **Screenshot Translate** で、さらに音声入力中の発話内容も翻訳できます。いずれも [ライティングツールキット](/ja/features/writing-tools) に含まれており、選択した AI モデルで動作します。

## 選択したテキストを翻訳する

1. 任意のアプリでテキストを選択します。
2. PopBar の **翻訳** をクリックするか、SmartBar を開いて **Translator** を実行します。
3. 翻訳結果を確認したら、**貼り付け** をクリックして元のテキストを置き換えるか、コピーします。

## 言語を設定する

**設定 → AI コマンド** を開き、**組み込み** の中から **Translator** を選んで **言語** セクションで設定します。

| 設定 | 動作 |
| --- | --- |
| **翻訳先の言語** | 翻訳ツールが出力する言語です。翻訳元の言語以外のすべての言語のテキストがこの言語に翻訳されます。**自動** の場合は応答言語（**設定 → あなたについて**）、それも自動の場合は Mac の言語が使われます |
| **翻訳元の言語** | 翻訳先とペアになる言語です。すでに翻訳先の言語で書かれているテキストは、この言語に翻訳されます。**自動** の場合は応答言語、それが翻訳先の言語と同じ場合は英語が使われます |

たとえば、翻訳先に英語、翻訳元に中国語を設定すると、中国語やフランス語のテキストは英語に、英語のテキストは中国語に翻訳されます。

## 翻訳スタイルを選ぶ

**設定 → AI コマンド** の Translator ページにある **翻訳スタイル** では、翻訳結果の文体を設定できます。Screenshot Translate にもこの設定が適用されます。変更は入力するとすぐ保存されます。

| スタイル | 翻訳の仕上がり |
| --- | --- |
| **標準** | 正確で原文に忠実な表現 |
| **ネイティブ風** | ネイティブスピーカーが書いたように自然に言い換えた表現 |
| **カスタム** | ボックスに記述したスタイルに従った表現 |

音声入力した内容には、音声入力専用の **翻訳スタイル** を設定できます。

## 画面の一部を翻訳する

1. SmartBar から **Screenshot Translate** を実行します。
2. 翻訳したい範囲をドラッグして選択します。
3. 翻訳結果が Dynamic Island に表示されます。クリックするとチャットが開き、スクリーンショットや翻訳結果について続けて質問できます。

Screenshot Translate は選択範囲を画像として Translator のモデルに送信します。先にお使いの OCR プロバイダーでテキストを読み取ってから翻訳したい場合は、**設定 → プラグイン → ライティングツールキット → Screenshot Translate** で **OCR が必要** をオンにしてください。その場合、OCR の誤認識で意味が変わることがあるため、画面と結果を照らし合わせて確認してください。プロバイダーの設定は [OCR](/ja/ai/ocr) を参照してください。

| 設定 | 動作 |
| --- | --- |
| **OCR が必要** | 翻訳する前に OCR プロバイダーでテキストを読み取ります。デフォルトではオフです |
| **フォローアップコマンド** | 翻訳後に送信したメッセージに応答するコマンドです |
| **閉じた後にクリア** | 翻訳結果に返信していない場合、閉じてから 10 秒後に Dynamic Island を空の入力欄に戻します |

## 話しながら翻訳する

音声入力時に **クリーンアップ** オプションで **翻訳** を選ぶと、話した内容が応答言語に翻訳されて入力されます（すでに応答言語で話している場合は英語に翻訳されます）。これは認識されたテキストを挿入前に処理する **Dictation Translate** コマンドです。詳しくは [音声入力](/ja/features/dictation) を参照してください。

リアルタイムで翻訳字幕を表示するには、[リアルタイム字幕](/ja/features/live-captioning) でライブ翻訳に対応した音声プロバイダーを選択してください。

## 用語を統一する

Translator は **設定 → AI コマンド → すべてのコマンド** で指定されたモデルで動作します。別のモデルを使いたい場合は、Translator のページで **AI モデル** を変更してください。

よく使う専門用語がある場合は、Translator のページで **カスタマイズ** をクリックするか、[エージェント](/ja/ai/agents) の指示に用語集を追加してください。固有名詞、技術的な識別子、引用箇所など、そのまま残すべき表現を明記します。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 意図しない言語に翻訳される | Translator の **翻訳先の言語** と **翻訳元の言語**、および **完了後のアクション** を確認してください |
| 翻訳が直訳すぎる、または意訳すぎる | Translator のページで **翻訳スタイル** を変更してください |
| テキストの一部が翻訳されない | 選択テキストの場合は「アクセシビリティ」権限を確認してください。**OCR が必要** をオンにした Screenshot Translate の場合は、OCR の読み取り結果を確認してください |
| Screenshot Translate で何もキャプチャされない | [権限](/ja/configuration/permissions) で「画面収録」権限を確認してください |

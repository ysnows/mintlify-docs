---
title: "翻訳"
description: "選択したテキスト、画面の一部、音声入力した内容を翻訳します。"
---

Enconvo は、選択したテキストを **翻訳ツール** で、画面上のテキストを **スクリーンショット翻訳** で、話した内容を音声入力時に翻訳します。いずれも[ライティングツール](/ja/features/writing-tools)の一部で、お使いの AI モデルで実行されます。

## 選択したテキストを翻訳する

1. 任意のアプリで文章を選択します。
2. PopBar で **翻訳** をクリックするか、SmartBar を開いて **翻訳ツール** を実行します。
3. 翻訳を確認し、**ペースト** をクリックして元の文章を置き換えるか、コピーします。

## 言語を選ぶ

**設定 → AI コマンド** を開き、**組み込み** から **翻訳ツール** を選んで、**言語** セクションで言語を設定します。

| 設定 | 内容 |
| --- | --- |
| **翻訳先の言語** | 翻訳ツールが出力する言語です。翻訳元の言語以外の言語のテキストは、この言語に翻訳されます。**自動** は、応答言語（**設定 → あなたについて**）を使い、それも自動の場合は Mac の言語を使います |
| **翻訳元の言語** | 翻訳先の言語と対になる言語です。すでに翻訳先の言語で書かれたテキストは、この言語に翻訳されます。**自動** は、応答言語を使い、それが翻訳先の言語の場合は英語を使います |

たとえば、翻訳先を英語、翻訳元を中国語にすると、中国語やフランス語のテキストは英語になり、英語のテキストは中国語になります。

## 翻訳スタイルを選ぶ

**設定 → AI コマンド** の翻訳ツールのページにある **翻訳スタイル** で、翻訳の読み味を設定します。スクリーンショット翻訳でも使われます。変更は入力と同時に保存されます。

| スタイル | 翻訳の読み味 |
| --- | --- |
| **標準** | 正確で、原文に近い |
| **ネイティブ風** | ネイティブスピーカーが書いたように、自由に言い換える |
| **カスタム** | ボックスに書いたスタイルに従う |

音声入力には、話した内容用の独自の **翻訳スタイル** があります。

## 画面の一部を翻訳する

1. SmartBar から **スクリーンショット翻訳** を実行します。
2. 翻訳したい範囲をドラッグして選びます。
3. 翻訳が Dynamic Island に表示されます。クリックするとチャットが開き、スクリーンショットとその翻訳について追加の質問ができます。

スクリーンショット翻訳は、選択範囲を画像として翻訳ツールのモデルに送ります。先に OCR プロバイダーでテキストを読み取り、そのテキストを翻訳したい場合は、**設定 → プラグイン → ライティングツール → スクリーンショット翻訳** で **OCR を使用** をオンにします。この場合、OCR の誤りで意味が変わることがあるため、結果を画面と見比べてください。プロバイダーの設定方法は [OCR](/ja/ai/ocr) を参照してください。

| 設定 | 内容 |
| --- | --- |
| **OCR を使用** | 翻訳する前に、OCR プロバイダーでテキストを読み取ります。デフォルトではオフです |
| **フォローアップコマンド** | 翻訳のあとに送るメッセージに回答するコマンドです |
| **閉じたあとにクリア** | 翻訳を閉じてから 10 秒後に、Dynamic Island を空の入力に戻します。ただし、翻訳に返信した場合は戻しません |

## 話しながら翻訳する

音声入力中に、音声入力の **クリーンアップ** オプションで **翻訳** を選ぶと、Enconvo は話した内容を、応答言語で入力します。すでにその言語で話している場合は英語で入力します。このオプションは **音声入力の翻訳** コマンドで、認識されたテキストに対して、挿入される前に動作します。[音声入力](/ja/features/dictation)を参照してください。

翻訳された字幕をリアルタイムで表示するには、[リアルタイム字幕](/ja/features/live-captioning)で、リアルタイム翻訳に対応した音声プロバイダーを選びます。

## 用語を統一する

翻訳ツールは、**設定 → AI コマンド → すべてのコマンド** で設定したモデルで実行されます。別のモデルを使うには、翻訳ツールのページで **AI モデル** を変更します。

よく使う用語がある場合は、翻訳ツールのページで **カスタマイズ** をクリックするか、[エージェント](/ja/ai/agents)の指示を書いて、用語集を追加します。名前、技術的な識別子、引用箇所など、そのままにしておくものを明記してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 翻訳が違う言語になる | 翻訳ツールの **翻訳先の言語** と **翻訳元の言語**、および **完了後のアクション** を確認してください |
| 翻訳が直訳すぎる、または自由すぎる | 翻訳ツールのページで **翻訳スタイル** を変更してください |
| 翻訳にテキストの抜けがある | 選択したテキストの場合は、アクセシビリティの権限を確認してください。**OCR を使用** をオンにしたスクリーンショット翻訳では、OCR が何を読み取ったかを確認してください |
| スクリーンショット翻訳で何も取り込まれない | [権限](/ja/configuration/permissions)で画面収録の権限を確認してください |

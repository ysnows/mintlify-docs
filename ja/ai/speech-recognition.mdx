Enconvo の各音声機能にはそれぞれ専用の音声モデル設定があるため、音声入力には高速なストリーミングモデルを、長いファイルには別のモデルを選ぶといった使い分けができます。実際に使っている機能の設定からモデルを選択してください。

| 機能 | 設定場所 | ガイド |
| --- | --- | --- |
| 音声でテキストを入力する | **設定 → 音声入力モデル** | [音声入力](/ja/features/dictation) |
| 音声コマンド | **設定 → 音声コマンド → 聞き取り** | [音声コマンド](/ja/features/dictation) |
| Live Talk 通話 | **設定 → Live Talk → 聞き取り** | [Live Talk](/ja/features/live-voice) |
| 会議や講義の録音 | **設定 → 録音モデル** | [会議の録音](/ja/features/meeting-recording) |
| 既存の音声・動画ファイル | **設定 → 文字起こしモデル** | [文字起こし](/ja/features/transcription) |
| リアルタイム字幕 | **設定 → 字幕生成モデル** | [リアルタイム字幕](/ja/features/live-captioning) |

## モデルを選ぶ

1. 上の表から使いたい機能の設定を開きます。
2. 音声入力モデル・録音モデル・文字起こしモデル・字幕生成モデルのページでは、**すべて**、**Enconvo Cloud**、**ローカル**、**カスタムプロバイダー** で一覧を絞り込めます。音声コマンドと Live Talk の **聞き取り** では、おすすめモデルが最初に表示され、その下に他の音声モデルが並びます。
3. モデルを選び、言語やモデルオプションを確認します。

**Enconvo Cloud** のモデルは API キー不要で Enconvo アカウントを使って動作します。Enconvo Cloud 独自の音声認識である **Enconvo Cloud Fast** は誰でも無料で使え、緑色の **無料** タグが表示されます。**カスタムプロバイダー** は各プロバイダーのご自身の API キーを使用します。**ローカル** モデル（MLX および Core ML）はモデルをダウンロードした後、Mac 上で音声認識を実行します。

[音声認識プロバイダーカタログ](/ja/providers/catalog)には、クラウドサービスやローカルの Parakeet・Qwen・Whisper・SenseVoice・Paraformer・Nemotron バリアントなど、対応するすべてのプロバイダーが一覧表示されています。対応状況や動作環境はランタイムとビルドによって異なります。

## 主なモデル

| モデル | 特徴 |
| --- | --- |
| ElevenLabs Scribe v3 Live | 1 秒未満で最初の単語をストリーミング出力し、中国語や雑音のある音声でも誤認識が少ないモデルです。ElevenLabs API キーまたは Enconvo Cloud を使い、音声入力とボイス入力で利用できます。中国語と日本語は単語間のスペースなしで出力されます。Live Talk で ElevenLabs を使う場合もこのモデルが使用されます。 |
| ElevenLabs Scribe v3 | ElevenLabs API キーまたは Enconvo Cloud を使ってファイルを文字起こしします。 |
| Enconvo Cloud Fast | 無料。リアルタイムモデルは話しながら文字を表示し、非同期モデルは録音ファイルを文字起こしします。 |
| Soniox | 音声入力、録音、文字起こし、字幕、Live Talk、会議字幕で Soniox の v6 モデルを使用します。以前に v5 モデルを選んでいた場合は自動で v6 へ移行されます（Soniox は 2026 年 12 月 15 日に v5 を終了します）。 |
| DeepSeek | 自分の DeepSeek API キー、またはキー不要の **DeepSeek (Enconvo Cloud)** を使って文字起こしと音声入力を行います。21 言語を自動判別します。 |
| Fluid Speech Pro by FluidVoice | Mac と iPhone 上で動作し、25 のヨーロッパ言語をオフラインで文字起こしします。Parakeet より誤認識が少なく、発話中のリアルタイム認識と発話後の認識の両方に対応します。macOS 15 または iOS 18 以降が必要です。 |

## タスクに合ったモデルを選ぶ

| 機能 | 知っておきたい点 |
| --- | --- |
| ストリーミング | 話している最中に途中のテキストを出力します。話しながら文字を出したい場合はリアルタイムモデルを選びます。 |
| バッチ文字起こし | 録音またはアップロードの完了後にファイル全体を処理します。 |
| 言語ヒント・ホットワード | プロバイダーが対応している場合、認識精度を高める手掛かりになります。 |
| 話者分離 | 声ごとに話者を分けますが、正しい人物名が自動で付くとは限りません。 |
| リアルタイム翻訳 | 原語と翻訳先言語を指定できる一部のプロバイダーとモデルのみ対応しています。 |
| タイムスタンプ・構造化出力 | プロバイダーと文字起こし出力形式によって対応が異なります。 |

## 短いサンプルで試す

長い会議を処理する前に、実際に使う言語・マイク・専門用語を含めた短いサンプルを録音して結果を確認してください。失敗する場合は、ファイルサイズ、形式、音声抽出、アカウント、ネットワークに関するエラー詳細を確認してください。

ローカルモデルのダウンロードはアプリ本体よりはるかに大きくなることがあります。必要なダウンロード容量と空き容量を確認してください（ローカル音声モデルごとに必要な容量は異なります）。

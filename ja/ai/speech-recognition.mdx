Enconvo の各音声機能には、それぞれ音声モデルの設定があります。そのため、音声入力には高速なストリーミングモデルを、長いファイルには別のモデルを選べます。実際に使っている機能の中で、モデルを選んでください。

| 機能 | 設定する場所 | ガイド |
| --- | --- | --- |
| 話した内容をテキストとして入力 | **設定 → 音声入力モデル** | [音声入力](/ja/features/dictation) |
| 音声コマンド | **設定 → 音声コマンド → 聞き取り** | [音声コマンド](/ja/features/dictation) |
| Live Talk の通話 | **設定 → Live Talk → 聞き取り** | [Live Talk](/ja/features/live-voice) |
| 会議や講義の録音 | **設定 → 録音モデル** | [会議の録音](/ja/features/meeting-recording) |
| 既存の音声ファイルや動画ファイル | **設定 → 文字起こしモデル** | [文字起こし](/ja/features/transcription) |
| リアルタイム字幕 | **設定 → 字幕生成モデル** | [リアルタイム字幕](/ja/features/live-captioning) |

## モデルを選ぶ

1. 上の表から、使う機能の設定を開きます。
2. 音声入力、録音、文字起こし、字幕生成のモデルのページでは、**すべて**、**Enconvo Cloud**、**ローカル**、**カスタムプロバイダー**でリストを絞り込めます。音声コマンドと Live Talk では、**聞き取り**に、おすすめのモデルが最初に表示され、そのあとにほかの音声モデルが続きます。
3. モデルを選び、その言語とモデルのオプションを確認します。

**Enconvo Cloud** のモデルは、API キーなしで、あなたの Enconvo アカウントを使います。Enconvo Cloud 独自の音声認識である **Enconvo Cloud Fast** は、誰でも無料で、緑の**無料**タグが表示されます。**カスタムプロバイダー**は、そのプロバイダーのあなた自身の API キーを使います。**ローカル**モデル(MLX と Core ML)は、モデルをダウンロードすると、Mac 上で音声を認識します。

[音声プロバイダーカタログ](/ja/providers/catalog)には、クラウドサービスや、ローカルの Parakeet、Qwen、Whisper、SenseVoice、Paraformer、Nemotron の各バリエーションを含め、宣言されているすべてのプロバイダーが一覧表示されます。ハードウェアと利用可否は、ランタイムとお使いのビルドによって異なります。

## 主なモデル

| モデル | 知っておくこと |
| --- | --- |
| ElevenLabs Scribe v3 Live | 最初の言葉を 1 秒未満でストリーミングし、中国語やノイズの多い音声での誤りが少なくなります。ElevenLabs の API キーまたは Enconvo Cloud で、音声入力と音声入力モードに使います。中国語と日本語は、単語の間にスペースなしで出力されます。Live Talk が ElevenLabs を使う場合は、Live Talk でも使われます。 |
| ElevenLabs Scribe v3 | ElevenLabs の API キーまたは Enconvo Cloud で、ファイルを文字起こしします。 |
| Enconvo Cloud Fast | 無料です。リアルタイムモデルは、話している間に言葉を表示し、非同期モデルは、録音済みのファイルを文字起こしします。 |
| Soniox | 音声入力、録音、文字起こし、字幕生成、Live Talk、カンファレンスの字幕で、Soniox の v6 モデルを使います。以前に選んだ v5 モデルは、自動的に v6 に移行されます。Soniox は 2026 年 12 月 15 日に v5 を終了します。 |
| DeepSeek | 自分の DeepSeek API キーを使うか、キー不要の **DeepSeek (Enconvo Cloud)** として、文字起こしと音声入力で文字起こしします。21 の言語を自動で検出します。 |
| Fluid Speech Pro by FluidVoice | Mac と iPhone 上で動作し、25 のヨーロッパ言語をオフラインで文字起こしします。Parakeet より誤りが少なく、話している間でも、話し終えてからでも使えます。macOS 15 または iOS 18 以降が必要です。 |

## タスクに合わせてモデルを選ぶ

| 機能 | 知っておくこと |
| --- | --- |
| ストリーミング | 話している間に、途中のテキストを出力します。話すそばから言葉を表示したいときは、リアルタイムモデルを使います。 |
| 一括の文字起こし | 録音やアップロードの後に、ファイルを処理します。 |
| 言語のヒントとホットワード | プロバイダーが対応している場合に、認識を助けます。 |
| 話者の分離 | 声を分けます。正しい人の名前になることは保証しません。 |
| ライブ翻訳 | 一部のプロバイダーとモデルだけが、元の言語と翻訳先の言語とともに提供します。 |
| タイムスタンプと構造化出力 | プロバイダーと、文字起こしの出力形式によって異なります。 |

## 短いサンプルでテストする

実際に使う言語、マイク、用語で短いサンプルを録音し、長い会議を処理する前に確認します。失敗した場合は、エラーを読んで、ファイルサイズ、形式、抽出、アカウント、ネットワークの詳細を確認します。

ローカルモデルのダウンロードは、アプリよりもかなり大きくなることがあります。実際のダウンロードサイズと空き容量を確認してください。ローカルの音声モデルは、すべてが同じ容量を必要とするわけではありません。

title: "Code Runner"
description: "Mac 上の本物のターミナルで、エージェントにシェルコマンド、スクリプト、ビルド、開発サーバーを実行させます。"
---

Code Runner は、あなたの Mac 上の本物のターミナルをエージェントに提供します。ビルド、テスト、スクリプト、パッケージツール、開発サーバーの起動に利用できます。実行できる内容は、インストール済みのプログラムとあなたのアカウントの権限によって決まります。

<Warning>
エージェントの **サンドボックス** をオンにしない限り、コマンドはあなたのアカウントのファイルおよびネットワーク権限を使って実際に実行されます。ソフトウェアのインストール、ファイル変更、オンラインサービスへの操作を行うコマンドは実行前に必ず確認してください。
</Warning>

## はじめる前に

- 使用するエージェントで Code Runner をオンにします。
- チャットの **権限** チップでエージェントが事前に確認を求めるタイミングを決めます。**承認を求める** ではコマンド実行前に毎回確認し、**自動で承認** では危険に見える操作の前だけ確認します。[操作の承認](/ja/ai/agents)を参照してください。
- エージェントのコマンドを作業フォルダ内に留め、キーや他のアプリへ触れさせない場合は、同じチップの **サンドボックス** をオンにしてください。[エージェントサンドボックス](/ja/configuration/sandbox)を参照してください。

## コマンドを実行する

エージェントにフォルダと具体的なタスクを伝えます。

> サンプルプロジェクトで既存のテストコマンドを実行し、結果を報告してください。ファイルは変更しないでください。

エージェントはコマンドの出力を表示し、終了したかまだ実行中かを伝えます。ファイルの読み取り・編集・検索には、代わりに[ファイルツール](/ja/ai/file-tools)を使用します。

## コマンドの実行方式

すべてのコマンドは疑似端末（pseudo-terminal）上で実行されるため、入力待ちになったコマンドへ新しいプロセスを起動せずに入力を返せます。

| モード | 用途 |
| --- | --- |
| **oneshot** | テスト、ビルド、スクリプトなど自動で終了するコマンド |
| **long_running** | サーバー、ウォッチャー、外部イベントを待ち続けるプロセス |
| **interactive** | REPL、ターミナルアプリ、対話型コマンドラインセッション |

結果に `status: running` と `session_id` が返った場合、プロセスは動き続けています。エージェントはその出力を **読み取り**、入力を **書き込み**、あるいは **停止** できます。プロンプトに答えるときはそのセッションへ書き込みます（別のコマンドを実行しても入力は渡りません）。

## 完了を待つ

ビルドの出力やサーバーの起動を待つ必要があるときは、エージェントはシェルのループではなく **Wait For** ツールを使います。コマンドを走らせたままにせず、次のいずれかを待機します。

- ファイルが作成されること
- ログファイルに特定の行が出ること
- プロセスまたはコマンドのセッションが終了すること
- ポートが開くこと、またはアドレスが応答すること

待機状況はチャットのバックグラウンドタスクに表示されます。条件を満たしたとき、失敗したとき、またはタイムアウトしたときにエージェントへ通知が届き、その間エージェントは別の作業を進められます。

## 作業フォルダと時間制限

コマンドはエージェントが `workDir` を指定した場合はそこで、指定しない場合はチャットの作業フォルダで実行されます。プロジェクトや Python 仮想環境が整ったあなたのシェルが使われます。別々に実行したコマンド同士は、同じセッションで動かさない限り一時的なシェル変数を共有しません。

最初の待機時間とコマンドの強制タイムアウトは別です。oneshot コマンドは最大 30 秒間結果を待ち、それ以降も実行中であれば、バックグラウンドで処理を続けながらその時点までの出力をエージェントに返します。デフォルトでは 30 分で強制終了されます。サーバーやウォッチャーには、oneshot が失敗したように扱うのではなく `long_running` モードを使ってください。

## 設定

**設定 → プラグイン → Code Runner** を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **Enable RTK** | 長いコマンド出力をエージェントが読む前に圧縮し、消費トークン数を抑えます。デフォルトでオンです。 |

圧縮された出力から必要な詳細が省かれている場合は、対象を絞ったコマンドやログの該当部分の表示を指示してください。途中で切れた出力はコマンドの成功を保証するものではありません。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| Command not found | プログラムがインストールされており、シェルから参照できるか確認してください。 |
| コマンドが入力待ちで止まっている | 同じセッション内でエージェントにプロンプトへ入力させてください。誰も答えられない入力待ちコマンドはすぐ終了します。 |
| Permission denied | 対象パスと macOS の権限を確認してください。サンドボックスがオンの場合は、ステップの下の行をクリックすると何がブロックされたかを確認できます。 |
| コマンドがタイムアウトした | 直前の出力を確認し、適切なモードを選んでから再実行してください。 |
| サーバーが起動したままになっている | 不要になったらエージェントにそのセッションを停止させてください。 |

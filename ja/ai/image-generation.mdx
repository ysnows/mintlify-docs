---
title: "画像生成"
description: "エージェントに画像の新規作成や、添付した画像の編集を依頼し、選んだ画像プロバイダーで生成します。"
---

チャットでエージェントに頼むと、新しい画像を作ったり、添付した画像を編集したりできます。Enconvo は**設定 → 画像生成**で選んだ画像プロバイダーにリクエストを送ります。これは会話に使うモデルとは別に設定されます。

## はじめる前に

1. **設定 → 画像生成**を開いてプロバイダーを選びます。
2. **認証プロバイダー**（使用するキーやアカウント）と**モデル名**を設定します。
3. **デフォルトに設定**をクリックします。

Enconvo Cloud のプロバイダーである **OpenAI (Enconvo Cloud)** と **Google Gemini (Enconvo Cloud)** は、ご自身の API キーなしで利用できます。

## 画像を作成する

1. エージェントとのチャットで、被写体、構図、スタイル、画像の用途を伝えます。
2. サイズ、アスペクト比、品質は、選んだモデルが対応している場合のみ指定します。
3. 生成を待ちます。通常のテキスト返信より時間がかかることがあります。
4. 生成された画像をクリックするとチャットの横に開き、そのまま続けて編集できます。

例：

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

新しいチャットのメッセージ欄の下にある**画像**を選ぶこともできます。モデルや設定、**除外要素**がメッセージ欄の下にピルとして表示されるため、送信前に調整できます。これまでに作ったすべての作品のライブラリ、キャラクターや被写体の保存、ワンクリック修正には[メディア](/ja/features/media)をお使いください。

## 画像を編集する

1. 元の画像をメッセージに添付するか、エージェントが作った画像をクリックして画像エディタで開きます。
2. 具体的な変更点と、変えずに残したい箇所を伝えます。
3. 意図しない変化が入っていないか結果を確認します。

画像編集または参照画像に対応したモデルをお使いください。

画像エディタの設定パネルには、選択中のモデルが対応している項目だけが表示されます：

| 設定 | 変更される内容 |
| --- | --- |
| 解像度、アスペクト比、品質 | 次のバージョンのサイズと精細さ |
| **除外要素** | ネガティブプロンプト対応モデルで、画像に含めない要素を指定 |
| バリエーション数 | 1 回のリクエストで生成する案の数。気に入ったものだけ残せます |
| **編集範囲**と**マークアップ** | 画像上を塗ってその部分だけを変更したり、指示の線を描き込んで誘導したりします |
| GIF と**フレーム数** | 言葉の指示から作成するアニメーション画像 |

編集のたびに新しいバージョンが作られ、すべての画像は[メディア](/ja/features/media)および `~/Enconvo/Media` に保存されます。画像を動かすには**動画を作成**をクリックします。

### GPT Image 2.6

GPT Image 2.6 Flare および Sunburst は、OpenAI、Enconvo Cloud、PipeLLM、OpenRouter から利用できます。複雑さ（低・中・高）の設定、描き込んだマークアップによる編集指示、SVG やアニメーション GIF の出力に対応しています。SVG と GIF は現在の画像を編集するのではなく、テキストの指示から新しい画像を作成します。

## プロバイダー

[画像プロバイダーカタログ](/ja/providers/catalog)には OpenAI、Gemini、xAI、OpenRouter、PipeLLM、Pollinations、Kie.ai、Topview、Azure、Together、および各社の Enconvo Cloud 版が含まれます。OpenAI プロバイダーでは、ChatGPT サインインを認証情報として使うこともできます。対応している機能はモデルによって異なるため、プロバイダー名だけで全編集モードが使えるとは限りません。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 画像が生成されない | プロバイダーへのアクセス権限とモデルを確認し、プロバイダーから返されたエラー内容を読んでください |
| 編集で添付画像が無視される | モデルが画像入力に対応しているか、ファイルがメッセージに添付されているか確認してください |
| 入力ファイルが拒否される | プロバイダーがそのファイル形式に対応しているか確認してください |
| ChatGPT サインインで GPT Image 2.6 が表示されない | OpenAI は ChatGPT プラン向けに提供していません。OpenAI API キーまたは Enconvo Cloud をお使いください |
| 使いたい設定がエディタに表示されない | 選択中のモデルがその設定に対応していません。別のモデルを選んでください |

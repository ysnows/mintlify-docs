---
title: "画像生成"
description: "選んだ画像プロバイダーで、エージェントに画像を作らせたり、添付した画像を編集させたりします。"
---

チャットでエージェントに、画像の作成や、添付した画像の編集を頼めます。Enconvo は、**設定 → 画像生成** で設定した画像プロバイダーにリクエストを送ります。これは、チャットで使うモデルとは別のものです。

## 始める前に

1. **設定 → 画像生成** を開き、プロバイダーを選びます。
2. その **認証情報の提供元**（使用するキーまたはアカウント）と **モデル名** を設定します。
3. **デフォルトに設定** をクリックします。

Enconvo Cloud のプロバイダー、**OpenAI (Enconvo Cloud)** と **Google Gemini (Enconvo Cloud)** は、自分の API キーが不要です。

## 画像を作成する

1. エージェントとのチャットで、被写体、構図、スタイル、画像の用途を説明します。
2. サイズ、アスペクト比、品質は、モデルが対応している場合にだけ指定します。
3. 画像ができるまで待ちます。生成には、テキストの返信より時間がかかることがあります。
4. 画像をクリックすると、チャットの横で開き、さらに編集できます。

例:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

新しいチャットのメッセージ欄の下で **画像** を選ぶこともできます。モデル、その設定、**除外** がメッセージ欄の下にピルとして表示されるので、送信前に設定できます。作成したものすべてのライブラリ、保存した被写体、ワンクリック修正は、[メディア](/ja/features/media)を使ってください。

## 画像を編集する

1. 元の画像をメッセージに添付するか、エージェントが作った画像をクリックして、画像エディタで開きます。
2. 具体的な変更内容を伝え、そのまま残したい部分も伝えます。
3. 頼んでいない変更が入っていないか、結果を確認します。

画像編集や参照画像に対応したモデルを使ってください。

画像エディタの設定パネルには、選んだモデルが受け付ける項目だけが表示されます。

| 設定 | 変更される内容 |
| --- | --- |
| 解像度、アスペクト比、品質 | 次のバージョンのサイズと精細さ |
| **除外** | ネガティブプロンプトを受け付けるモデルで、含めたくない要素 |
| バリエーション | 1 回のリクエストで作るテイクの数。気に入ったものを残せます |
| **編集範囲** と **マークアップ** | 絵の上に塗って、その部分だけを変更するか、描いて変更を誘導します |
| GIF と **フレーム** | 言葉から作る動くアニメーション画像 |

編集のたびに新しいバージョンが作られ、すべての画像は[メディア](/ja/features/media)と `~/Enconvo/Media` に保存されます。画像を動かすには、**動画を作成** をクリックします。

### GPT Image 2.6

GPT Image 2.6 Flare と Sunburst は、OpenAI、Enconvo Cloud、PipeLLM、OpenRouter から利用できます。複雑さの設定（低、中、高）、描いたマークアップによる編集の誘導、SVG またはアニメーション GIF の出力が追加されます。SVG と GIF は言葉から新しい画像を作るもので、現在の画像を編集するものではありません。

## プロバイダー

[画像プロバイダーのカタログ](/ja/providers/catalog)には、OpenAI、Gemini、xAI、OpenRouter、PipeLLM、Pollinations、Kie.ai、Topview、Azure、Together と、提供されている場合はその Enconvo Cloud 版が含まれます。OpenAI プロバイダーは、ChatGPT のサインインを認証情報として使うこともできます。プロバイダーができることはモデルによって異なります。プロバイダーの名前だけで、すべての編集モードに対応しているとは限りません。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 画像が生成されない | プロバイダーのアクセスとモデルを確認し、プロバイダーのエラーを読んでください |
| 編集で画像が無視される | モデルが画像入力に対応していること、ファイルがメッセージに添付されていることを確認してください |
| 入力ファイルが拒否される | プロバイダーがそのファイル形式に対応しているか確認してください |
| ChatGPT のサインインで GPT Image 2.6 が選べない | OpenAI は ChatGPT のプランには提供していません。OpenAI の API キーか Enconvo Cloud を使ってください |
| 使いたい設定がエディタにない | 選んだモデルがその設定に対応していません。別のモデルを選んでください |

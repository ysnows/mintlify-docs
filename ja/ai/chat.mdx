チャットウィンドウは、Enconvo で継続的な会話を行うためのメインスペースです。複数のやり取りが必要な作業に使います。エージェントを選び、必要な資料を追加して、関連するチャットをまとめて管理できます。**⌃⌘X** を押すと開きます。

他の用途には、ちょっとした質問やコマンド実行に [SmartBar](/ja/features/smartbar)、1 つのアプリと並べて作業するなら [App Sidebar](/ja/features/app-sidebar)、選択したテキストへの操作なら [PopBar](/ja/features/popbar)、画面上に常駐する小さな入口としては [Dynamic Island](/ja/features/dynamic-island) や [デスクトップペット](/ja/features/pet) をお使いください。すべての比較は[ウィンドウ管理](/ja/features/window-management)をご覧ください。

下の動画では、エージェントの選択、1 つのチャットに対するモデルと権限の切り替え、ファイルの追加、作成物の指定、質問とフォローアップ、チャットの再検索まで、チャットウィンドウの使い方を 2 分で紹介しています。

## 会話を始める

1. **⌃⌘X** を押すか、Enconvo から**チャットウィンドウ**を開きます。新しいチャットを始めるには**新規チャット**（**⌘N**）をクリックします。最後に選んだプロジェクトで開始されますが、通常のチャットにしたい場合はプロジェクト選択メニューで**プロジェクトなし**を選びます。
2. 応答する相手を選びます：入力欄の上にあるエージェントカード、またはチャット上部のエージェント名をクリックします。デフォルトは Mavis です。カードには Writer や Researcher などのエージェントや、Codex、Claude Code などのコーディングエージェントも並んでいます。
3. 入力欄の下のチップを確認します。モデルチップにはこのチャットで使うモデルが表示されており、クリックするとこのチャットだけ別のモデルに切り替えられます。盾のチップはエージェントが実行前に確認を求めるタイミングを設定します。**自動で承認**にすると、リスクのある手順の前だけ確認します。
4. **+** をクリックしてファイル、画像、またはスクリーンショットを追加します。特定の形式のものを作りたいときは、入力欄の下にある**何かを作る**行から種類を選びます：**スライド**、**ドキュメント**、**デザイン**、**モーション**、**ダッシュボード**、**Web ページ**、**画像**、または**動画**。プロジェクト内の新規チャットにもこの行があります。詳しくは[アーティファクト](/ja/features/artifacts)をご覧ください。
5. リクエストを入力して Return を押します。応答がチャットにストリーミング表示され、エージェントがツールを使う場合はその進行状況も返信内で確認できます。
6. 同じチャットで続けて質問できます。会話内容を覚えているため、「1 日版にして」のような短い指示だけで十分です。

ペアリング済みの別のコンピュータでチャットを始めるには、メッセージ欄の**実行先**チップからそのコンピュータを選びます。入力した内容も引き継がれます。詳しくは[他のコンピュータ](/ja/integrations/other-computers)をご覧ください。

期待する完成形をはっきり伝えましょう。「添付した提案書を箇条書き 5 点で要約し、未解決の課題も挙げてください」のように書くと、何を読んで何を返すべきかがエージェントに伝わります。

チャットのエージェントは、チャットヘッダーのエージェント名からあとで変更することもできます。SmartBar や App Sidebar にも同じ選択メニューがあります。[コーディングエージェント](/ja/ai/coding-agents)に会話を引き継ぐには、そのエージェントで新しいチャットを続けてください。チャットをフォークするときは、引き継ぐエージェントを選択できます。

### 送信前にリクエストを整える

リクエストを入力したら、マイクの横にある魔法の杖アイコン（**プロンプトを強化**）をクリックします。そのチャット自身のモデルがここまでの会話を踏まえて、より明確で充実したリクエストに書き直し、あなたしか知らない詳細部分は `[プレースホルダー]` として残します。元の文に戻すには**元に戻す**（または **⌘Z**）をクリックし、別の書き直しを試すには**もう一度試す**をクリックします。

別のチャットを見ている間も、各チャットの未送信テキストと添付ファイルはメッセージ欄に保持されるため、戻ってきたときに下書きがそのまま残っています。過去のメッセージを編集すると、画像やファイルもテキストと一緒にメッセージ欄へ戻るため、送信前に削除したり追加したりできます。

### Vim キーで編集する

**設定 → 一般**の**キーボード**にある **Vim モード**をオンにするか、メッセージ欄に `/vim` と入力します。マイクの横にモードを示すチップが表示され、Normal モードと Visual モードでは青くなります。これらのモードは英語キーボード配列で入力され、Insert モードに入ると直前に使っていた入力ソースに戻ります。

## 作業中のエージェントに話しかける

長いタスクが終わるまで待つ必要はありません。

| やりたいこと | 操作方法 |
| --- | --- |
| 実行中のタスクに指示を追加する | テキストを入力して Return を押します。文字を入力するかファイルを添付すると、**停止**ボタンが**送信**に戻ります。エージェントは次のステップでメッセージを読み取ります。 |
| タスク終了後に送るメッセージを予約する | **⌘Return** を押すか、**⌘** を押しながら**送信**をクリックします。 |
| タスクを停止する | **停止**をクリックするか、**Esc** を 2 回押します。うっかり 1 回押しただけでは止まりません。 |

Enconvo があなたのメッセージで方針を変えるべきか判断している間も、エージェントは記述やツール実行を続けるため、あとからでも対応できる追加指示で現在のステップが無駄になることはありません。実行中のタスクと無関係なリクエストはサブエージェントに渡され、エージェントが作業を続ける裏で並行処理されます。

サインイン、インストール、質問カードが表示されてもチャットは止まりません。カードに答える代わりにメッセージを送れば、チャットはそのまま進みます。

モデルが思考している間、返信欄には**思考中…**と経過時間が表示されます。

タスクが終わると、エージェントのまとめは結果から始まり、変更点、確認した内容、あなたの確認が必要な点を順に表示します。

## ゴールを設定する

エージェントに最終状態を指定すると、チェックで達成が確認されるまでターンを重ねて作業を続けます。

1. `/goal` に続けて作業完了時に満たされるべき状態を入力するか、**+** メニューから**ゴールを設定**を選びます。
2. 送信します。メッセージ欄の上にゴールと実行時間が表示されます。
3. ゴールバーを使って、ゴールの編集、クリア、再開ができます。ゴールが有効な間、**+** メニューには**ゴールを編集**が表示されます。

## 一時チャットを使う

残したくない単発の質問には、新しいチャットで破線吹き出しのスイッチ（**一時チャット**）をオンにします。App Sidebar と Dynamic Island にも同じスイッチがあります。オンの間はスイッチが青くなり、メッセージ欄は破線の枠と**一時チャット**タグが付いた状態になります。

一時チャットはチャット履歴に残らず、[メモリ](/ja/ai/memory)も保存されず、その画面を離れると削除されます。あとから残したくなった場合は、バナーの**チャットを保存**をクリックすると通常のチャットに変わります。

## 返信の見た目を選ぶ

各エージェントにはデフォルトの応答スタイルと、チャート・表・カードをどの程度積極的に使って答えるかを決める Intelligent UI レベルがあります。1 つのチャットだけ変更するには、**+** メニューを開いて**スタイルを使用**を選びます。**標準**などのスタイルや Intelligent UI レベルを選び、そのエージェントのデフォルトにしたい場合は、そのエージェントのすべてのチャットで**すべてに適用**を選びます。スタイルとレベルの一覧は[エージェント](/ja/ai/agents)をご覧ください。

返信内のリンクはサイトのアイコン付きカードとして表示されます。地図へのリンクは場所の名前が付いた実際の地図として表示され、複数の場所は番号付きの 1 つの地図にまとめられ、ルートは所要時間と距離とともに経路線で表示されます。詳しくは[ビジュアルアンサー](/ja/features/visual-answers)をご覧ください。

## 画面構成と移動方法

サイドバーは左側の細いアイコンレールと、それに連動する中央列で構成されています。

- レールの先頭には、あなたの確認を待っているチャット数をオレンジ色のバッジで示す**チャット**があり、続いて**予約タスク**、**ナレッジベース**、**プラグイン**が並びます。**ボード**、**アーティファクト**、**メディア**などは **···** メニューの中にあります。お使いのプラグインは区切り線の下に配置され、一番下にデバイススイッチャーと設定メニューがあります。設定メニューにはヘルプリンク、**新機能**、**サイドバーのショートカット**も入っています。
- レール上で場所を選ぶと、中央列にそのセクション、フィルター、主な操作が表示されます。**チャット**は前回開いていた場所に戻ります。スキルと MCP サーバーは**プラグイン**からウィンドウ内でそのまま開きます。
- **⌥⌘1** 〜 **⌥⌘9** を押すと、レールに並んでいる項目を上から順に開けます。**⌘B** でレールを残したまま中央列を隠せます。
- **戻る**と**進む**は、訪れた場所とそこで選んだセクションを記憶しています。**戻る**を長押しすると履歴一覧が出ます。

### サイドバーをカスタマイズする

**···** メニューを開くか、レール上のアイコンを右クリックして**サイドバーをカスタマイズ…**を選びます。レールに表示する項目を選び、ドラッグして順番を入れ替えます。プラグインを区切り線の上にドラッグして他の項目と並べたり、下に戻したり、項目やプラグインをピン留め・解除したりできます。

### クイックアクセス

よく開くページ、プロジェクト、リンクをサイドバーにピン留めできます。サイドバー最下部の設定メニューを開き、**サイドバーのショートカット**を選んで項目を追加してください。追加した項目は**クイックアクセス**グループに表示され、ドラッグによる並べ替え、名前の変更、削除ができます。

### デバイススイッチャー

サイドバーには一度に 1 台のコンピュータが表示されます。最下部のデバイススイッチャーから、このコンピュータとペアリング済みの他のコンピュータを切り替えたり、他のデバイスで待機中の内容を確認したり、別ウィンドウで開いたりできます。**デバイス**タイトルの横に**管理**があり、**デバイスを追加**からコンピュータのペアリング、SSH ホストの追加、スマートフォンのペアリングを行えます。詳しくは[他のコンピュータ](/ja/integrations/other-computers)、[スマートフォンをペアリング](/ja/integrations/pair-your-phone)、[コンピュータと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)をご覧ください。

アップデート後に初めて Enconvo を開くと、サイドバーのカードにそのバージョンのアップデート動画が表示されます。設定メニューの**新機能**から、**設定 → チュートリアル**ですべての動画をいつでも見られます。

### アーティファクト

**···** メニューの**アーティファクト**には、エージェントが作成したページ、ドキュメント、デザインが一覧表示されます。カードや行を右クリックすると、**開く**、**名前を変更**、**リンクをコピー**、作成したチャットを開く、**削除**ができます。**⌘**-クリックまたは **⇧**-クリックで複数選択してまとめて削除でき、**元に戻す**も可能です。何も書き込まれていない空のアーティファクトは一覧に表示されません。

ページアーティファクトを共有するには**公開**をクリックします。Enconvo Cloud 上のあなた専用の `name.site.enconvo.com` リンクでオンライン公開され、任意でパスワードも設定できます。エージェントにページやサイトフォルダの公開を頼むこともできます。

## チャットを整理する

サイドバーには最近のチャットが表示され、対応している場所ではプロジェクトごとに関連チャットをまとめられます。すべてのチャットは保存されており、サイドバーの**検索**（**⌘G**）をクリックして会話内容から探せます。チャットのメニューを開くと、**チャット名を変更**、**チャットをピン留め**、**プロジェクトに移動**、**チャットをアーカイブ**、**チャットを削除**を行えます。チャットの履歴を削除する際は確認メッセージをよくお読みください。

- 上部の**有効**グループには、あなたの操作待ち、実行中、または未読の結果やエラーがあるチャットだけがプロジェクト名や状態付きで集められます。行の操作は通常のチャット一覧と同じで、ホバーで**ピン留め**と**アーカイブ**、右クリックでメニュー、ダブルクリックで名前変更、トラックパッドのスワイプでアーカイブができます。グループにカーソルを合わせると**すべて既読にする**が表示されます。
- 一覧最下部の**iPhoneのチャット**には、iPhone または Android スマートフォンで始めたチャットが入ります。Mac 上でそのまま続きを行えますが、削除すると双方から削除されます。詳しくは [Phone chats](/ja/integrations/iphone-phone-chats) をご覧ください。
- エージェントが Codex や Claude Code、あるいは別のエージェントに協力を求めた際に開始したチャットは、一覧には表示されません。依頼元のチャット内の該当行から開けます。ただし、開いている間、ピン留めされている間、またはあなたの回答待ちの間は行が表示されます。
- 各[オートメーション](/ja/workflows/scheduled-jobs)の最新の実行は、開始されるとすぐに時計マーク付きで一覧に表示されます。
- **ピン留め済み**グループや worktree の行は折りたたむことができます。
- チャットの紫色のスピナーは、返信自体は完了しているものの、開始したサブエージェントやバックグラウンドタスクがまだ動いていることを示します。中に青い点がある場合は、未読の新しい返信があります。

### 複数のチャットをまとめて操作する

1. **⌘**-クリック、**Shift**-クリック、または行の**選択**でチャットを選びます。**⌘A** でグループ全体を選択できます。
2. 表示されるバーを使って、既読にする（**⇧⌘U**）、アーカイブする（**E**）、または削除する（**⌫**）を実行します。

削除時は確認ダイアログが出て対象チャットが一覧表示され、実行中のものは停止し、**代わりにアーカイブ**も選べます。既読への変更とアーカイブは元に戻せます。

### モデルの選択

プロジェクトに属さない**新規チャット**はエージェントのデフォルトモデルを設定できます。プロジェクト内の新規チャットは、そのプロジェクトのモデル設定を使います。さらに各チャットごとに独自のモデルや推論設定を上書き保持できます。他のチャットにも影響するデフォルト設定を変える前に、[モデル選択ガイド](/ja/ai/model-selection-guide)をお読みください。

チャットのモデルで Enconvo Cloud ポイントが尽きた場合は、チャットを Enconvo Cloud 以外のモデルに切り替え、ポイント不足カードの**再試行（モデル変更）**をクリックしてそのモデルでメッセージを再実行してください。自動でバックアップモデルに切り替えるには、**設定 → AI モデル**で**フォールバック**を設定します。詳しくは[バックアップモデルでチャットを続ける](/ja/ai/model-selection-guide)をご覧ください。

### worktree で作業する

git リポジトリのプロジェクトでは、チャットをメインチェックアウトと worktree の間で移動できます。チャットタイトルの後ろにあるチップを使うか、エージェントに頼んでください。チャットは変更したファイルと一緒に移動し、worktree をマージするとメインチェックアウトに戻ります。移動のたびに会話内に行が挿入されます。詳しくは[プロジェクト](/ja/ai/projects)をご覧ください。

## コンテキストとファイルを追加する

リクエストに必要なソースだけを追加してください。ファイル添付、画面キャプチャ、ナレッジベース検索、ブラウザページは、それぞれ異なる種類のコンテキストをエージェントに渡します。適切なソースの選び方は[コンテキスト認識](/ja/features/context-awareness)、エージェントがファイルに対して行える操作は[ファイルとフォルダ](/ja/ai/file-tools)をご覧ください。

- メッセージ欄には、**権限**の後ろに**ライブ画面**と[画面に描画](/ja/features/screen-doodle)のボタンがあります。ライブ画面はオンにしたウィンドウに紐づき、チップでオン状態が示され、クリックでオフにできます。
- `@` を入力すると、ファイル、エージェント、友達やチームメンバーをメンションできます。人を指定するとエージェントが誰を指しているか理解するため、本人に直接メッセージを送ったり、返信を読んだり、頼んだときに電話をかけたりできます。
- 大きな動画や音声ファイルは、文字起こしやメモとしてモデルに渡されます。フォルダや空のファイルは添付できません。

[メモリ](/ja/ai/memory)と[ナレッジベース](/ja/ai/knowledge-base)は役割が異なります。メモリはエージェントが再利用する事実を保持し、ナレッジベースはエージェントが調べる資料を保管します。どちらもサイドバーのレールにある**ナレッジベース**から開き、列上部の**ナレッジベース** / **メモリ**スイッチで切り替えます。

## 返信を読む・再利用する

返信の作業詳細を展開すると、各ツール呼び出しとその結果を確認できます。返信の下にある**コピー**、**読み上げ**、**その他**から操作できます。[ビジュアルアンサー](/ja/features/visual-answers)によって、返信内に図やインタラクティブなコンテンツが直接表示されることもあります。

コードブロックには**コピー**ボタンと折り返しボタンがあり、長い行を横スクロールせずに折り返して表示できます。すべての返信でコードを折り返すには、**設定 → 一般**の**外観**にある**コードを折り返す**をオンにしてください。

リンクでチャットを共有すると、チャットのアップロード中でもすぐにコピーできるリンクが発行されます。あとから**リンクを更新**を押すと、変更分だけが送信されます。

エージェントがあなたのために開いたページやファイルは、チャットの横のサイドパネルに表示されます。各チャットはパネルを開いたか閉じたかの状態を記憶しています。一度も開いたことがないチャットは**新規**タブから始まり、パネルのツールが提案されます。タブはドラッグで調整した幅を共有し、最後のタブを閉じるとパネルも閉じます。

| タブ | ショートカット | 表示内容 |
| --- | --- | --- |
| **プルリクエスト** | **⌃⇧P** | GitHub リポジトリで作業中のチャットで、ブランチのプルリクエストとチェック結果・レビュー・コメントを表示、または worktree チャットから新規作成します。 |
| **デバイス** | **⌃⇧M** | 1 回の初期設定のあと、チャットの横で iOS Simulator や Android Emulator を表示・操作できます。 |

入力の代わりに話すには、[音声入力](/ja/features/dictation)で音声から文字を入力するか、[Live Talk](/ja/features/live-voice) で双方向の音声会話を行います。

## Enconvo が再起動したとき

アップデート、終了、またはクラッシュによってタスクの途中でチャットが止まった場合、Enconvo が再び起動するとチャットは自動的に再開します。残りを進める前にすでに完了した内容を確認し、実行中だったサブエージェントも復帰させます。

## 設定

**設定 → チャットウィンドウ**を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **デフォルトエージェント** | チャットウィンドウで新しいチャットを開始するときに使われるエージェントです。そのエージェントを削除すると、新しいチャットは Mavis に戻ります。 |
| **外観** | **ライト**、**ダーク**、または**アプリに合わせる**。 |
| **ホットキー** | どのアプリからでもチャットウィンドウを開きます。デフォルトは **⌃⌘X** です。他のウィンドウの**チャットウィンドウで開く**ボタンにはここで設定したキーが表示されます。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 返信で意図しないモデルが使われている | エージェントのデフォルトだけでなく、このチャットでのモデル選択も確認してください。 |
| 別のモデルが引き継いだという表示が出る | このチャットのモデルが利用できない間、**設定 → AI モデル**のバックアップモデルが応答しました。元のモデルが使えるようになると自動的に戻ります。 |
| エージェントがファイルや画面を見られない | チャットの添付ファイルと[権限](/ja/configuration/permissions)を確認してください。 |
| ツールが使えない | 同じリクエストを言い換えてやり直すのではなく、エージェント設定の**ツールとスキル**を確認してください。詳しくは[エージェント](/ja/ai/agents)をご覧ください。 |
| 探しているチャットが一覧に見つからない | **有効**と**iPhoneのチャット**を確認するか、**検索**（**⌘G**）を使ってください。エージェントが内部的に開始したチャットは、依頼元のチャットから開けます。 |
| **このチャットを表示できませんでした**と表示される | **チャットを再読み込み**をクリックします。その間もチャット一覧とメッセージ欄は引き続き使えます。 |

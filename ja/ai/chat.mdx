チャットウィンドウは、継続的な会話のための Enconvo のメインの場所です。1 回の回答では終わらない作業に使います。エージェントを選び、必要な資料を追加し、関連するチャットをまとめておけます。**⌃⌘X** を押して開きます。

ほかの用途には、手早い質問やコマンドには [SmartBar](/ja/features/smartbar)、1 つのアプリの横で作業するには[アプリのサイドバー](/ja/features/app-sidebar)、選択したテキストを操作するには [PopBar](/ja/features/popbar)、画面に表示したままにできる小さな入口には [Dynamic Island](/ja/features/dynamic-island) や[デスクトップペット](/ja/features/pet)を使います。[ウィンドウ管理](/ja/features/window-management)で、すべてを比較できます。

下の動画では、チャットウィンドウを 2 分で紹介します。エージェントを選ぶ、1 つのチャットのモデルと権限を切り替える、ファイルを追加する、作るものを選ぶ、質問してフォローアップする、チャットをもう一度探す、という内容です。

## 会話を始める

1. **⌃⌘X** を押すか、Enconvo から **チャットウィンドウ** を開きます。新しいチャットには **新規チャット** (**⌘N**) をクリックします。最後に選んだプロジェクトの中で始まります。通常のチャットにするには、プロジェクトピッカーで **プロジェクトなし** を選びます。
2. 回答するエージェントを選びます。入力欄の上のエージェントカード、またはチャット上部のエージェント名をクリックします。デフォルトは Mavis です。カードには、Writer や Researcher などのエージェントや、Codex や Claude Code などのコーディングエージェントもあります。
3. 入力欄の下のチップを確認します。モデルチップには、このチャットのモデルが表示されます。クリックすると、このチャットだけ切り替えられます。盾のチップは、エージェントが実行前にあなたに確認するタイミングを設定します。**自動で承認** は、リスクのある手順の前だけ確認します。
4. **+** をクリックして、ファイル、画像、スクリーンショットを追加します。特定のものを作るには、入力欄の下の **何かを作る** 行で種類を選びます。**スライド**、**ドキュメント**、**デザイン**、**モーション**、**ダッシュボード**、**Web ページ**、**画像**、**動画** があります。プロジェクト内の新しいチャットにもこの行があります。[アーティファクト](/ja/features/artifacts)をご覧ください。
5. リクエストを入力して Return を押します。回答がチャットにストリーミングされます。エージェントがツールを使う場合は、返信の中でその進行状況を確認できます。
6. 同じチャットでフォローアップを質問します。会話を覚えているので、「1 日版にして」のような短いリクエストで十分です。

ペアリングしたほかのコンピューターでチャットを始めるには、メッセージ欄の **実行先** チップで選びます。入力した内容も一緒に移ります。[ほかのコンピューター](/ja/integrations/other-computers)をご覧ください。

完全な結果を求めましょう。「添付した提案書を 5 つの箇条書きで要約し、未解決の質問を挙げて」と書くと、何を読んで何を返すかの両方がエージェントに伝わります。

チャットのエージェントは、あとからチャットのヘッダーにあるエージェント名で変更できます。SmartBar とアプリのサイドバーにも同じピッカーがあります。会話を[コーディングエージェント](/ja/ai/coding-agents)に引き継ぐには、そのエージェントで新しいチャットを開いて続けます。チャットをフォークするときは、続きを担当するエージェントを選びます。

### 送信前にリクエストを改善する

リクエストを入力したら、マイクの横の魔法の杖 (**プロンプトを改善**) をクリックします。これまでの会話を踏まえて、そのチャット自身のモデルが、より明確で詳しいリクエストに書き直し、あなただけが知っている詳細は `[placeholders]` として残します。**元に戻す** (または **⌘Z**) をクリックすると元の文章に戻り、**もう一度試す** で別の書き直しになります。

メッセージ欄は、ほかのチャットを見ている間も、各チャットの未送信のテキストと添付ファイルを保持するので、戻ってきたときも下書きが残っています。以前のメッセージを編集すると、そのメッセージの画像とファイルがテキストと一緒にメッセージ欄に戻るので、送信前に 1 つ削除したり追加したりできます。

### Vim キーで編集する

**設定 → 一般** の **キーボード** にある **Vim モード** をオンにするか、メッセージ欄に `/vim` と入力します。マイクの横のチップにモードが表示され、ノーマルモードとビジュアルモードでは青くなります。これらのモードでは英語のキーボード配列で入力し、挿入モードでは使っていた入力ソースに戻ります。

## エージェントが作業している間に話しかける

長いタスクが終わるのを待つ必要はありません。

| 目的 | 操作 |
| --- | --- |
| 実行中のタスクに何かを追加する | 入力して Return を押します。入力または添付をすると、**停止** ボタンが **送信** に戻ります。エージェントは次のステップであなたのメッセージを読みます。 |
| タスクが終わったときのためにメッセージをキューに入れる | **⌘Return** を押すか、**⌘** を押しながら **送信** をクリックします。 |
| タスクを止める | **停止** をクリックするか、**ESC** を 2 回押します。誤って 1 回押しただけでは終わりません。 |

Enconvo があなたのメッセージで進路を変えるべきかを確認している間も、エージェントはツールの記述と実行を続けるので、待てるフォローアップによって現在のステップが無駄になることはありません。タスクと関係のないリクエストは、エージェントが作業を続けている間、バックグラウンドで動作するサブエージェントに渡されます。

ログイン、インストール、質問のカードがチャットをブロックすることはありません。回答する代わりにメッセージを送ると、チャットは先へ進みます。

モデルが考えている間、返信には **思考中…** とこれまでの経過時間が表示されます。

タスクが終わると、エージェントの要約は、まず結果から始まり、続いて変更内容、確認したこと、対応が必要なことが一覧表示されます。

## ゴールを設定する

エージェントに最終的な状態を伝えると、チェックでゴールの達成が確認されるまで、ターンを重ねて作業を続けます。

1. `/goal` に続けて、作業が終わったときに成り立っているべきことを入力するか、**+** メニューから **ゴールを設定** を選びます。
2. 送信します。ゴールが、経過時間とともにメッセージ欄の上に表示されます。
3. ゴールバーで、ゴールの編集、クリア、再開ができます。ゴールが有効な間は、**+** メニューに **ゴールを編集** が表示されます。

## 一時チャットを使う

残したくない 1 回限りの質問には、新しいチャットで、破線の吹き出しのスイッチ (**一時チャット**) をオンにします。アプリのサイドバーと Dynamic Island にも同じスイッチがあります。オンの間はスイッチが青くなり、メッセージ欄の縁が破線になって **一時チャット** のタグが付きます。

一時チャットは、チャット履歴に残らず、[メモリ](/ja/ai/memory)も保存されず、離れると削除されます。やはり残したい場合は、バナーの **チャットを保存** をクリックすると、通常のチャットになります。

## 返信の見た目を選ぶ

各エージェントには、デフォルトの応答スタイルと Intelligent UI レベルがあり、グラフ、表、カードでどれだけ積極的に答えるかを決めます。1 つのチャットだけ変更するには、**+** メニューを開き、**スタイルを使用** を選びます。**標準** などのスタイル、または Intelligent UI レベルを選び、**すべてに使用** を選ぶと、そのエージェントのすべてのチャットのデフォルトになります。スタイルとレベルについては、[エージェント](/ja/ai/agents)をご覧ください。

返信内のリンクは、サイトのアイコン付きのカードで表示されます。地図へのリンクは、場所の名前付きの実際の地図を表示します。複数の場所は番号付きの 1 つの地図に表示され、ルートは線と所要時間と距離が表示されます。[ビジュアル回答](/ja/features/visual-answers)をご覧ください。

## 画面の見方

サイドバーは、左側の細いアイコンレールと、それに連動する中央の列で構成されています。

- レールは、対応が必要なチャットの数をアンバー色で示す **チャット**、続いて **予約済み**、**ナレッジベース**、**プラグイン** で始まります。**ボード**、**アーティファクト**、**メディア**、そのほかの場所は **···** メニューにあります。プラグインは区切り線の下にあり、足元にはデバイススイッチャーと設定メニューがあります。設定メニューには、ヘルプのリンク、**新機能**、**サイドバーのショートカット** もあります。
- レールで場所を選ぶと、中央の列にそのセクション、フィルタ、主な操作が表示されます。**チャット** は、前回の続きの場所に戻ります。スキルと MCP サーバーは、**プラグイン** からウィンドウ内でそのまま開きます。
- **⌥⌘1** から **⌥⌘9** を押すと、レールに表示されているものを順番に開きます。**⌘B** は中央の列を隠し、レールは残します。
- **戻る** と **進む** は、訪れた場所と、それぞれで選んだセクションを記憶します。**戻る** を長押しすると、それらの一覧が表示されます。

### サイドバーをカスタマイズする

**···** メニューを開くか、レールのアイコンを右クリックして、**サイドバーをカスタマイズ…** を選びます。レールに表示する場所を選び、ドラッグして好きな順番に並べます。プラグインを区切り線の上にドラッグすると場所と並び、下に戻すこともできます。どの場所やプラグインも、ピン留めまたはピン留め解除できます。

### クイックアクセス

よく開くページ、プロジェクト、リンクをサイドバーにピン留めします。サイドバーの足元にある設定メニューを開き、**サイドバーのショートカット** を選んで、項目を追加します。**クイックアクセス** グループに表示され、ドラッグして並べ替えたり、名前を変更したり、削除したりできます。

### デバイススイッチャー

サイドバーには、一度に 1 台のコンピューターが表示されます。足元のデバイススイッチャーで、このコンピューターとペアリング済みのコンピューターを切り替えたり、ほかのコンピューターで待機中のものを確認したり、それぞれを専用のウィンドウで開いたりできます。**デバイス** のタイトルの横に **管理** があり、**デバイスを追加** で、コンピューターのペアリング、SSH ホストの追加、スマートフォンのペアリングができます。[ほかのコンピューター](/ja/integrations/other-computers)、[スマートフォンとペアリング](/ja/integrations/pair-your-phone)、[コンピューターと SSH ホスト](/ja/integrations/computers-and-ssh-hosts)をご覧ください。

アップデート後に初めて Enconvo を使うと、サイドバーのカードで、そのバージョンのアップデート動画が案内されます。設定メニューの **新機能** で、**設定 → チュートリアル** にすべての動画が開きます。

### アーティファクト

**···** メニューの **アーティファクト** には、エージェントが作ったページ、ドキュメント、デザインが一覧表示されます。カードまたは行を右クリックすると、**開く**、**名前を変更**、**リンクをコピー**、作成元のチャットを開く、**削除** ができます。**⌘** クリックまたは **⇧** クリックで複数を選び、まとめて削除でき、**元に戻す** も使えます。何も書き込まなかった空のアーティファクトは一覧に表示されません。

ページのアーティファクトを共有するには、**公開** をクリックします。Enconvo Cloud 上の、あなた専用の `name.site.enconvo.com` のリンクでオンラインに公開され、パスワードも任意で設定できます。エージェントにページやサイトフォルダの公開を頼むこともできます。

## チャットを整理する

サイドバーには最近のチャットが一覧表示され、プロジェクトは、利用できる場所で関連するチャットをまとめます。すべてのチャットは保存されています。サイドバーの **検索** (**⌘G**) をクリックすると、発言内容でチャットを探せます。チャットのメニューを開くと、**チャット名を変更**、**チャットをピン留め**、**プロジェクトに移動**、**チャットをアーカイブ**、**チャットを削除** ができます。チャットの履歴を削除する前に、確認の内容を読んでください。

- 先頭の **アクティブ** には、まだ対応が必要なチャット、実行中のチャット、開いていない結果や失敗があるチャットだけが、それぞれのプロジェクトと状態とともに集められます。行の操作はチャット一覧と同じです。ポインタを合わせると **ピン留め** と **アーカイブ** が表示され、右クリックでメニュー、ダブルクリックで名前の変更、トラックパッドのスワイプでアーカイブができます。グループにポインタを合わせると **すべて既読にする** が表示されます。
- 一覧の下にある **iPhoneのチャット** には、iPhone や Android スマートフォンで始めたチャットがあります。Mac で続けられ、削除すると両方で削除されます。[スマートフォンのチャット](/ja/integrations/iphone-phone-chats)をご覧ください。
- エージェントが Codex、Claude Code、ほかのエージェントに助けを求めたときに始まるチャットは、一覧に表示されません。質問したチャットの該当行から開きます。開いている間、ピン留めされている間、あなたの回答を待っている間は、行が表示されます。
- 各[予約タスク](/ja/workflows/scheduled-jobs)の最新の実行は、開始と同時に、時計のマーク付きで一覧に表示されます。
- **ピン留め済み** グループは折りたためます。ワークツリーの行も同様です。
- チャットの紫色のスピナーは、返信は完了していて、開始したサブエージェントやバックグラウンドタスクがまだ実行中であることを意味します。その中の青いドットは、読むべき新しい返信があることを意味します。

### 複数のチャットをまとめて操作する

1. **⌘** クリック、**Shift** クリック、または行の **選択** でチャットを選びます。**⌘A** でグループ全体を選べます。
2. 表示されたバーで、既読にする (**⇧⌘U**)、アーカイブする (**E**)、削除する (**⌫**) ができます。

削除する前には確認が表示され、チャットが一覧表示され、まだ実行中のものは停止され、**代わりにアーカイブ** も提案されます。既読にする操作とアーカイブは、元に戻せます。

### モデルの選択

トップレベルの **新規チャット** では、エージェントのデフォルトのモデルを設定できます。プロジェクト内の新しいチャットは、そのプロジェクトのモデル設定を使います。各チャットは、独自のモデルと推論の上書きを保持できます。ほかのチャットが使っているデフォルトを変更する前に、[モデルの選択](/ja/ai/model-selection-guide)をお読みください。

チャットのモデルが Enconvo Cloud のポイントを使い切った場合は、そのチャットを Enconvo Cloud 以外のモデルに切り替え、ポイント切れのカードの **再試行** をクリックして、そのモデルでメッセージをもう一度実行します。チャットが自動でバックアップモデルに切り替わるようにするには、**設定 → AI モデル** で **フォールバック** を設定します。[バックアップモデルでチャットを継続する](/ja/ai/model-selection-guide)をご覧ください。

### ワークツリーで作業する

git リポジトリであるプロジェクトでは、チャットはメインのチェックアウトとワークツリーの間を移動できます。チャットのタイトルの後ろのチップを使うか、そのエージェントに頼みます。チャットは、変更したファイルと一緒に移動し、ワークツリーをマージするとメインのチェックアウトに戻ります。会話には、移動のたびに 1 行が追加されます。[プロジェクト](/ja/ai/projects)をご覧ください。

## コンテキストとファイルを追加する

リクエストに必要な情報源だけを追加してください。ファイルの添付、画面キャプチャ、ナレッジベースの検索、ブラウザのページは、それぞれエージェントに別の種類のコンテキストを与えます。情報源の選び方は[コンテキスト認識](/ja/features/context-awareness)、エージェントがファイルで何をできるかは[ファイルとフォルダ](/ja/ai/file-tools)をご覧ください。

- メッセージ欄には、**権限** の後ろに **ライブ画面** と[画面に描画](/ja/features/screen-doodle)のボタンがあります。ライブ画面は、オンにしたウィンドウに紐づきます。そのチップでオンになっていることがわかり、クリックするとオフになります。
- `@` を入力すると、ファイル、エージェント、友達やチームメイトをメンションできます。人の名前を指定すると、エージェントが誰のことかを理解するので、頼めば、その人に個別にメッセージを送ったり、返信を読んだり、電話をかけたりできます。
- 大きな動画や音声のファイルは、文字起こしまたはメモとしてモデルに渡されます。フォルダや空のファイルは添付できません。

[メモリ](/ja/ai/memory)と[ナレッジベース](/ja/ai/knowledge-base)は役割が違います。メモリはエージェントが再利用する事実を保持し、ナレッジベースはエージェントが検索するための資料を保存します。どちらも、サイドバーのレールの **ナレッジベース** から開き、その列の上部に **ナレッジベース** / **メモリ** の切り替えがあります。

## 返信を読んで再利用する

返信の作業の詳細を展開すると、各ツールの呼び出しとその結果が表示されます。返信の下の **コピー**、**読み上げ**、**その他** で、返信を操作できます。[ビジュアル回答](/ja/features/visual-answers)は、図やインタラクティブなコンテンツを返信にそのまま置けます。

コードブロックには **コピー** と折り返しボタンがあり、長い行は横にスクロールする代わりに折り返せます。すべての返信でコードを折り返すには、**設定 → 一般** の **外観** にある **コードを折り返す** をオンにします。

チャットをリンクで共有すると、チャットのアップロード中でもすぐにリンクをコピーできます。その後は、**リンクを更新** で変更された部分だけが送られます。

エージェントがあなたのために開いたページやファイルは、チャットの横のサイドパネルに表示されます。各チャットは、パネルを開いたまま、または閉じたままにした状態を保持します。パネルを一度も開いたことのないチャットは、パネルのツールが表示される **新規** タブで始まります。タブはドラッグした幅を共有し、最後のタブを閉じるとパネルが閉じます。

| タブ | ショートカット | 表示される内容 |
| --- | --- | --- |
| **プルリクエスト** | **⌃⇧P** | GitHub リポジトリで作業しているチャットでは、チェック、レビュー、コメント付きのブランチのプルリクエスト、またはワークツリーのチャットからのプルリクエストの作成。 |
| **デバイス** | **⌃⇧M** | 一度だけ設定すると、チャットの隣で見て操作できる iOS シミュレータまたは Android エミュレータ。 |

入力する代わりに話すには、[音声入力](/ja/features/dictation)で声で作成するか、[Live Talk](/ja/features/live-voice) で双方向の音声会話を行います。

## Enconvo が再起動したとき

アップデート、終了、クラッシュでタスクの途中でチャットが止まった場合は、Enconvo が戻ると、チャットは自動で続行します。すでに行ったことを確認してから残りを実行し、実行中だったサブエージェントも元に戻します。

## 設定

**設定 → チャットウィンドウ** を開きます。

| 設定 | 変更される内容 |
| --- | --- |
| **デフォルトエージェント** | チャットウィンドウで新しいチャットが始まるときのエージェント。そのエージェントを削除すると、新しいチャットは Mavis に戻ります。 |
| **外観** | **ライト**、**ダーク**、**アプリに合わせる**。 |
| **ホットキー** | どのアプリからでもチャットウィンドウを開きます。デフォルトは **⌃⌘X** です。ほかのウィンドウの **チャットウィンドウで開く** ボタンには、設定したキーが表示されます。 |

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 返信が違うモデルを使っている | エージェントのデフォルトだけでなく、このチャットのモデル選択も確認してください。 |
| チャットに別のモデルが引き継いだと表示される | チャットのモデルが利用できない間、**設定 → AI モデル** のバックアップモデルが回答しました。チャットのモデルが使えるようになると、元に戻ります。 |
| エージェントがファイルや画面を見られない | チャットの添付ファイルと[権限](/ja/configuration/permissions)を確認してください。 |
| ツールが使えない | 同じリクエストを言い換えるのではなく、エージェントの設定の **ツールとスキル** を確認してください。[エージェント](/ja/ai/agents)をご覧ください。 |
| 探しているチャットが一覧にない | **アクティブ** と **iPhoneのチャット**、または **検索** (**⌘G**) を確認してください。エージェントが自分で始めたチャットは、質問したチャットから開きます。 |
| チャットに **このチャットを表示できませんでした** と表示される | **チャットを再読み込み** をクリックしてください。その間も、チャット一覧とメッセージ欄は使えます。 |

---
title: "ナレッジベース"
description: "ドキュメント、メモ、Web ページ、フォルダを集めて、検索したり、チャットで質問したりできます。"
---

ナレッジベースには、Enconvo に後から見つけてほしい資料を保管します。参考ドキュメント、プロジェクトのメモ、保存した Web ページ、音声メモなどです。エージェントは、あなたが指定したときや、質問に保管内容が必要なときに検索します。[メモリ](/ja/ai/memory)は別のものです。メモリには、エージェントがチャットをまたいであなたについて覚えておく短い情報が入ります。

## ナレッジベースを開く

- チャットウィンドウで、サイドバーの **ナレッジベース** をクリックします。
- または **設定 → ナレッジベース** を開き、ナレッジベースをクリックします。
- または Enconvo のメニューバーメニューから **ナレッジベースウィンドウを表示** を選びます。チャットウィンドウでナレッジベースが開きます。

あなたの[メモリ](/ja/ai/memory)もここにあります。ナレッジベース列の上部にある **ナレッジベース** / **メモリ** のスイッチで切り替えられます。メモリはナレッジベースの一覧には表示されません。

チャットウィンドウで上部のナレッジベース名をクリックすると、すべてのナレッジベースを一覧できます。各ナレッジベースのサイズ、今週追加された項目、対応が必要な項目、AI クライアントが検索できるかどうかが分かります。

## ナレッジベースを作成する

1. すべてのナレッジベースの概要または **設定 → ナレッジベース** で **新規ナレッジベース** をクリックするか、SmartBar で **ナレッジベースを作成** を検索します。
2. 分かりやすい **名前** を付けます。何を入れるかを **説明** に書いてください。エージェントはこの説明を読んで、いつそこを検索するか判断します。
3. **開始方法** で、**空**、**フォルダ**（インデックス化され、同期が保たれます）、**ファイル** のいずれかを選びます。
4. Claude や Cursor などの MCP クライアントから使えるようにするには、**AI クライアントに検索を許可** をオンにします。
5. **作成** をクリックします。フォルダやファイルを選んだ場合、ボタンは **作成してインポート** または **作成して追加** と表示されます。

関係のないプロジェクトは、別々のナレッジベースに分けておくと混ざりません。ナレッジベースの中では、フォルダで項目を整理できます。

## コンテンツを追加する

| 操作 | 用途 |
| --- | --- |
| **追加 → メモ** | 編集できる新しい Markdown メモ |
| **追加 → ファイル** | Mac 上の対応するドキュメント、画像、音声、動画 |
| **追加 → 単一のWebページ** | 1 つの URL の内容 |
| **追加 → YouTube 動画** | 動画とそのキャプション |
| **追加 → 投稿** | X、Reddit、Hacker News、Bluesky、知乎などの投稿 |
| **追加 → フォルダをインポート…** | 構造を保ったままのローカルフォルダ（同期を保つことも可能） |
| **追加 → 新規フォルダ…** | 項目を整理するためのフォルダ |
| ファイルをナレッジベースにドラッグまたは貼り付け | Finder からの素早いインポート |
| [クイックキャプチャ](/ja/features/quick-capture) | 現在のアプリの内容を保存 |
| [音声メモ](/ja/features/voice-notes) | 音声メモを録音して保存 |

ドキュメントローダーは、一般的なテキスト、Markdown、PDF、Office、EPUB、構造化データの形式に対応しています。画像は OCR で読み取られ、音声と動画は文字起こしされます。解析の品質と対応形式は、選択したローダーとプロバイダーによって異なります。スキップされたファイルや失敗したファイルは、インポートのプレビューと各項目のステータスで確認してください。

Web サイト全体を追加する場合、Enconvo はアドレスが指しているサイトの範囲（ドキュメントサイトの一部分など）に絞り、2 つのアドレスで見つかったページは 1 回だけインデックス化します。

## ナレッジベースを共有する

メールアドレスで指定した相手や、チーム全体とナレッジベースを共有できます。あなたも共有相手も、Enconvo アカウントにサインインしている必要があります。

<Steps>
  <Step title="共有を開く">
    ナレッジベースの **⋯** メニューを開き、**共有…** を選びます。
  </Step>
  <Step title="ユーザーまたはチームを追加する">
    **メールアドレスでユーザーを追加** を使うか、チームアクセスをオンにしてチーム全員と共有します。
  </Step>
  <Step title="各自の権限を選ぶ">
    **閲覧可能**、**追加可能**、**管理可能** から選びます。アクセスできるユーザーを変更できるのは、オーナーと管理可能なユーザーだけです。
  </Step>
</Steps>

共有すると、そのナレッジベースのコピーが Enconvo Cloud に置かれます。Mac から出るのはナレッジベースの中身だけで、メモリとチャット履歴は共有されません。誰かが追加した内容は数秒ですべての Mac に届き、各項目には追加した人が表示されます。各メンバーの Mac はそれぞれコピーとインデックスを持つため、オフラインでも検索できます。リンクされたフォルダは、他のメンバーは閲覧のみ可能です。**アクティビティ** で、何が誰によって変更されたかを確認できます。

共有をやめるには、ユーザーの **アクセス権を削除** を使うか、**チームとの共有を停止** を選びます。

## 項目を参照して探す

- **グリッド**、**リスト**、**マップ** で表示を切り替えます。リストは **種類**、**タグ**、**フォルダ**、**ステータス**、**追加済み** の列を持つ表です。マップでは、各項目が意味の近い項目とつながって表示されます。
- 項目の上にある **ライブラリ** メニューで、**すべての項目**、**最近追加した項目**、**タグなし**、**対応が必要** を件数付きで切り替えます。対応が必要なものがあると、点が表示されます。
- **フィルタ**、**タグ**、**種類** で表示を絞り込めます。
- リストでは、行にチェックを入れて、まとめて移動、タグ付け、再インデックス化、削除、チャットができます。

## リンクされたフォルダ

1. **追加 → フォルダをインポート…** を選びます。
2. ソースフォルダを選び、ファイル数とスキップされるファイルを確認して、確定します。
3. フォルダを選んで詳細を表示すると、ソースのパス、同期ステータス、各種コントロールが見られます。
4. **今すぐ同期** をクリックするか、**自動同期** をオンにすると、Enconvo の実行中は変更に追従します。

ソースフォルダはディスク上にそのまま残ります。新しいファイルと変更されたファイルがインポートされ、ソースから削除したファイルはナレッジベースからも削除されます。隠しファイル、未対応の形式、50 MB を超えるファイルはスキップされます。Enconvo のフォルダ同期がソースファイルを編集することはありません。

ソースのドライブが外れていたり、フォルダが移動されたりすると、フォルダには **ソースフォルダが見つかりません** と表示され、何も削除されません。ドライブを再接続するか、**再リンク…** をクリックして新しい場所を選んでください。処理や同期のトラブルシューティングについては、[ナレッジベースのしくみ](/ja/advanced/knowledge-base-advanced)を参照してください。

## ソースについて質問する

- **ナレッジベース内**: 上部の **項目** の横にある **質問** をクリックします。チャットウィンドウと同じチャットです。最初の質問にナレッジベースが添付され、追加の質問のたびに再び検索されます。チャットは他のチャットと一緒に保存されます。**新規** をクリックすると新しい質問を始められます。
- **任意のチャット**: **@** を入力して、一覧からナレッジベースまたはその項目を選びます。選んだものはメッセージ欄の上に残り、追加の質問でも使われます。そこから削除することもできます。チップをクリックすると、ナレッジベースで開きます。

例:

> 添付したプロジェクトのメモを使って、認証に関する決定事項を一覧にし、それぞれの出典を示してください。

エージェントは、必要な資料を検索して読み込みます。検索では、すべてのドキュメントを送るのではなく、関連する箇所が選ばれます。重要な詳細は、引用された項目を開いて確認してください。必要な箇所が見つからない場合は、その項目を具体的に指定するか、インデックス化が完了しているか確認してください。

## ナレッジベースの設定

ナレッジベースのヘッダーにある歯車（**ナレッジベースの設定**）をクリックします。

| セクション | 内容 |
| --- | --- |
| **一般** | ナレッジベースの **名前** と **説明** |
| **インデックスと検索** | 対応が必要な項目、検索モデル、インデックス全体を作り直す **再インデックス化…** |
| **ソースとキャプチャ** | **今すぐ同期**、**自動同期**、**再リンク…** を備えたリンク済みフォルダと、クイックキャプチャ、音声メモ、Chrome 拡張機能へのショートカット |
| **AI クライアント（MCP）** | AI クライアントがこのナレッジベースを検索できるかどうか。[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) を参照してください。 |
| **詳細設定** | **ナレッジベース ID** と **ナレッジベースを削除** |

デフォルトのナレッジベースとメモリは削除できません。

## 編集とメンテナンス

メモを開くと、Markdown を編集できます。項目やフォルダのメニューから、名前の変更、移動、タグ付け、削除ができます。削除の確認をよく読んでください。ナレッジベースから項目を削除することと、ソースファイルを削除することは別の操作です。リンクされたフォルダごと削除しても、ディスク上のファイルには一切触れません。

<Warning>
リンクされたフォルダから取り込まれた項目では、項目メニューに **ゴミ箱に移動** と表示されます。これはディスク上の実際のファイルをゴミ箱に移動し、その後で項目がナレッジベースから消えます。
</Warning>

項目が失敗した場合は、再試行する前に、抽出とインデックス化のどちらが失敗したかを確認してください。インデックス化が終わる前でも、ドキュメントが読める状態になっていることがあります。

すべてのナレッジベースは同じ検索モデルを使います。モデルは **設定 → メモリ** の **検索** で設定します。モデルは、この Mac または Enconvo Cloud で実行され、切り替えても検索インデックスは保持されます。**インデックスと検索** の **検索の設定…** から開けます。

## 他の AI アプリと連携する

**ナレッジベースの設定 → AI クライアント（MCP）** を開くと、ローカルの MCP クライアントに、選んだナレッジベースを検索させることができます。これは、別個の、オプトイン方式の、読み取り専用のサービスです。設定と共有の制御については、[ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) を参照してください。

## データの扱い

ナレッジベースのファイルとインデックスは、ローカルに保存されます。選択したクラウドの OCR、文字起こし、埋め込み、リランク、チャットのプロバイダーは、処理に必要な内容を受け取ることがあります。検索モデルを Enconvo Cloud で実行する場合、インデックス化または検索されるテキストがそこに送信されます。ファイルがローカルにあっても、プロバイダーの処理がオフラインで行われるわけではありません。機密性の高い資料をインポートする前に、[プライバシーとセキュリティ](/ja/configuration/privacy-security)とプロバイダーを確認してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 項目にインデックス化のエラーが表示される | **ライブラリ → 対応が必要** を開き、抽出とインデックス化のどちらが失敗したかを確認してから、その項目を再インデックス化します。 |
| リンクされたフォルダに **ソースフォルダが見つかりません** と表示される | ドライブを再接続するか、**再リンク…** をクリックしてフォルダの新しい場所を選びます。 |
| 回答にあるドキュメントが反映されない | ドキュメントのインデックス化が完了しているか確認してから、**@** で直接指定します。 |
| 新しいコンテンツがインデックス化されない | 検索モデルを Enconvo Cloud で実行している場合は、サインインしてください。サインインするまで、新しいコンテンツはインデックス化されず、検索では一致する単語しか見つかりません。 |

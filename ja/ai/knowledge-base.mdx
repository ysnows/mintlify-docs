---
title: "ナレッジベース"
description: "ドキュメント、メモ、ウェブページ、フォルダをまとめて収集し、検索したりチャットで質問したりできます。"
---

ナレッジベースには、参考資料、プロジェクトのメモ、保存したウェブページ、音声メモなど、あとで Enconvo に見つけてもらいたい資料を保存します。ナレッジベースを指定したときや、質問にその内容が必要なときに Agent が検索します。[メモリ](/ja/ai/memory) とは役割が異なり、メモリはチャットをまたいで Agent が覚えておくユーザーに関する短い事実を保持します。

## ナレッジベースを開く

- チャットウィンドウのサイドバーで **ナレッジベース** をクリックします。
- または **設定 → ナレッジベース** を開き、ナレッジベースをクリックします。
- またはメニューバーの Enconvo メニューから **ナレッジベースウィンドウを表示** を選択すると、チャットウィンドウ内でナレッジベースが開きます。

[メモリ](/ja/ai/memory) もここから確認できます。ナレッジベース列の上部にある **ナレッジベース** / **メモリ** の切り替えスイッチで移動してください。メモリはナレッジベースの一覧には含まれません。

チャットウィンドウで上部のナレッジベース名をクリックすると、すべてのナレッジベースの概要（各サイズ、今週追加された件数、要確認の件数、AI クライアントから検索可能かどうか）を確認できます。

## ナレッジベースを作成する

1. ナレッジベースの一覧画面または **設定 → ナレッジベース** で **新規ナレッジベース** をクリックするか、SmartBar で **Create Knowledge Base** を検索します。
2. 分かりやすい **名前** を付けます。中に入れる内容を **説明** に書いておくと、Agent がいつ検索すべきか判断する手がかりになります。
3. **開始方法** で **空のまま開始**、**フォルダ**（インデックス化して同期を維持）、または **ファイル** を選択します。
4. Claude や Cursor などの MCP クライアントからも検索できるようにする場合は **AI クライアントからの検索を許可** をオンにします。
5. **作成** をクリックします。フォルダまたはファイルを選んだ場合は **作成してインポート** または **作成して追加** になります。

無関係なプロジェクト同士を分けるには、別のナレッジベースを作成します。1 つのナレッジベース内ではフォルダを使って項目を整理します。

## コンテンツを追加する

| 項目 | 用途 |
| --- | --- |
| **追加 → ノート** | 新しく編集可能な Markdown ノート |
| **追加 → ファイル** | Mac 上の対応ドキュメント、画像、音声、動画ファイル |
| **追加 → 単一のウェブページ** | 1 つの URL のコンテンツ |
| **追加 → YouTube 動画** | 動画とその字幕 |
| **追加 → 投稿** | X、Reddit、Hacker News、Bluesky、知乎などの投稿 |
| **追加 → フォルダをインポート…** | 階層構造を保ったままローカルフォルダを追加（必要に応じて同期を維持） |
| **追加 → 新規フォルダ…** | 項目を整理するためのフォルダ |
| ナレッジベースへファイルをドラッグまたはペースト | Finder からの素早いインポート |
| [Quick Capture](/ja/features/quick-capture) | 手前のアプリのコンテンツを保存 |
| [Voice Note](/ja/features/voice-notes) | 話した内容を録音してメモとして保存 |

ドキュメントローダーは一般的なテキスト、Markdown、PDF、Office 文書、EPUB、および構造化データ形式に対応しています。画像は OCR で読み取られ、音声と動画は文字起こしされます。解析品質と対応形式は選択したローダーとプロバイダーによって異なります。スキップまたは失敗したファイルがないか、インポートのプレビューと各項目のステータスを確認してください。

ウェブサイト全体を追加する場合、Enconvo は指定された URL が指すサイト内のセクション（ドキュメントサイトの特定パートなど）に範囲を限定し、複数のアドレスで見つかった同一ページは 1 回だけインデックス化します。

## ナレッジベースを共有する

メールアドレスを指定して個人と共有したり、チーム全体と共有したりできます。あなたと共有相手の双方が Enconvo アカウントにサインインしている必要があります。

<Steps>
  <Step title="共有を開く">
    ナレッジベースの **⋯** メニューを開き、**共有…** を選択します。
  </Step>
  <Step title="メンバーまたはチームを追加する">
    **メールアドレスでユーザーを追加** を使うか、チームアクセスをオンにしてチーム全員と共有します。
  </Step>
  <Step title="権限を選ぶ">
    **閲覧可能**、**追加可能**、または **管理可能** を選択します。アクセス権を変更できるのは所有者と管理可能なユーザーのみです。
  </Step>
</Steps>

共有すると、そのナレッジベースのコピーが Enconvo Cloud に保存されます。Mac の外に出るのはその中身だけであり、メモリやチャット履歴が共有されることはありません。誰かが追加した内容は数秒以内にすべての Mac に届き、各項目には追加したユーザーが表示されます。各メンバーの Mac にもローカルのコピーとインデックスが保持されるため、オフラインでも検索できます。リンクされたフォルダについては他のメンバーは閲覧のみ可能です。**アクティビティ** には誰が何を変更したかが表示されます。

共有を停止するには、特定のユーザーの **アクセス権を削除** を選択するか、**チームとの共有を停止** を選択します。

## 項目を閲覧・検索する

- **グリッド**、**リスト**、**マップ** で表示を切り替えます。リストは **種類**、**タグ**、**フォルダ**、**ステータス**、**追加日時** の列を持つテーブルです。マップでは、意味が近い項目同士が線で結ばれて表示されます。
- 項目一覧の上にある **ライブラリ** メニューでは、**すべての項目**、**最近の追加**、**タグなし**、**要確認** を件数付きで切り替えられます。確認が必要な項目がある場合はドットが表示されます。
- **フィルター**、**タグ**、**種類** で表示を絞り込めます。
- リスト表示では行にチェックを入れて、まとめて移動・タグ付け・再インデックス・削除したり、選択項目についてチャットで質問したりできます。

## リンクされたフォルダ

1. **追加 → フォルダをインポート…** を選択します。
2. 元のフォルダを選び、ファイル数とスキップされるファイルを確認して確定します。
3. フォルダを選択して詳細を表示すると、元のパス、同期ステータス、操作ボタンを確認できます。
4. **今すぐ同期** をクリックするか、Enconvo の起動中に変更を追跡する **自動同期** をオンにします。

元のフォルダはディスク上にそのまま残ります。新しいファイルや変更されたファイルがインポートされ、元のフォルダから削除されたファイルはナレッジベースからも削除されます。隠しファイル、非対応形式、50 MB を超えるファイルはスキップされます。Enconvo のフォルダ同期が元のファイルを変更することはありません。

外付けドライブが抜かれたりフォルダが移動されたりすると、フォルダに **元のフォルダが見つかりません** と表示され、項目は削除されません。ドライブを接続し直すか、**再リンク…** をクリックして新しい場所を選択してください。処理や同期のトラブルシューティングについては [ナレッジベースの仕組み](/ja/advanced/knowledge-base-advanced) を参照してください。

## ソースについて質問する

- **ナレッジベース内から**: 上部の **項目** の横にある **質問** をクリックします。チャットウィンドウと同じチャットが開き、最初の質問にそのナレッジベースが添付され、続きの質問でも再検索されます。会話は他のチャットと同じように保存されます。新しい質問を始めるには **新規** をクリックします。
- **任意のチャットから**: **@** を入力し、一覧からナレッジベースまたはその中の項目を選択します。選択した項目はメッセージ欄の上に残り、続きの質問でも使われます（そこから外すこともできます）。チップをクリックするとナレッジベース内でその項目が開きます。

たとえば次のように試してみてください:

> 添付したプロジェクトメモをもとに、認証に関する決定事項を一覧にし、各決定事項の出典を示してください。

Agent が必要な資料を検索して読み込みます。検索ではすべての文書を丸ごと送るのではなく、関連する箇所が抽出されます。重要な詳細を確認するときは、引用元の項目を直接開いて確かめてください。必要な箇所が見つからない場合は、特定の項目を直接指定するか、その項目のインデックス作成が完了しているか確認してください。

## ナレッジベース設定

ナレッジベースのヘッダーにある歯車アイコン（**ナレッジベース設定**）をクリックします。

| セクション | 設定内容 |
| --- | --- |
| **一般** | ナレッジベースの **名前** と **説明** |
| **インデックスと検索** | 確認が必要な項目、検索モデル、およびインデックス全体を作り直す **再インデックス…** |
| **ソースとキャプチャ** | **今すぐ同期**、**自動同期**、**再リンク…** を備えたリンクフォルダ設定、および Quick Capture、Voice Note、Chrome 拡張機能へのショートカット |
| **AI クライアント（MCP）** | AI クライアントがこのナレッジベースを検索できるかどうか。詳しくは [ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) を参照してください。 |
| **詳細設定** | **ナレッジベース ID** と **ナレッジベースを削除** |

デフォルトのナレッジベースとメモリは削除できません。

## 編集とメンテナンス

ノートを開くと Markdown を直接編集できます。項目やフォルダのメニューから、名前変更・移動・タグ付け・削除を行えます。削除時の確認メッセージをよく確認してください。ナレッジベースから項目を取り除く操作と、元のファイルを削除する操作は別であり、リンクされたフォルダごと削除してもディスク上のファイルには一切触れません。

<Warning>
リンクされたフォルダから取り込まれた項目のメニューには **ゴミ箱に移動** と表示されます。これを実行すると、ディスク上の実際のファイルがゴミ箱に移動され、その後ナレッジベースからも項目が削除されます。
</Warning>

項目の処理に失敗した場合は、テキスト抽出とインデックス作成のどちらが失敗したかを確認してからやり直してください。検索インデックス作成が終わる前でも、ドキュメント自体は閲覧できる場合があります。

すべてのナレッジベースは共通の検索モデルを使用し、**設定 → メモリ** の **検索** で指定します。検索モデルはこの Mac 上または Enconvo Cloud 上で動作し、切り替えても検索インデックスは保持されます。**インデックスと検索** の **検索設定…** からこの画面を開けます。

## 別の AI アプリを接続する

**ナレッジベース設定 → AI クライアント（MCP）** を開くと、ローカルの MCP クライアントが選択したナレッジベースを検索できるように設定できます。これは個別にオプトインする読み取り専用のサービスです。設定手順と共有制御については [ナレッジベース MCP](/ja/advanced/knowledge-base-mcp) を参照してください。

## データの取り扱い

ナレッジベースのファイルとインデックスはローカルに保存されます。クラウド型の OCR、文字起こし、埋め込み、リランキング、またはチャットプロバイダーを選択した場合、処理に必要なコンテンツが各プロバイダーに送信されることがあります。検索モデルを Enconvo Cloud 上で実行している場合は、インデックス化または検索対象のテキストが Enconvo Cloud に送信されます。ファイルをローカルに保存していても、選択したプロバイダーの処理がオフラインとは限りません。機密資料をインポートする前に、[プライバシーとセキュリティ](/ja/configuration/privacy-security) と利用プロバイダーの方針を確認してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 項目にインデックスエラーが出ている | **ライブラリ → 要確認** を開き、抽出とインデックス作成のどちらで失敗したか確認してから再インデックスを実行してください。 |
| リンクされたフォルダに **元のフォルダが見つかりません** と出る | ドライブを接続し直すか、**再リンク…** をクリックしてフォルダの新しい場所を選択してください。 |
| 回答に特定のドキュメントが含まれない | ドキュメントのインデックス作成が完了しているか確認したうえで、**@** でその項目を直接指定してください。 |
| 新しいコンテンツがインデックスされない | 検索モデルを Enconvo Cloud で実行している場合はサインインしてください。サインインするまで新しいコンテンツはインデックスされず、検索は完全一致する単語のみを対象とします。 |

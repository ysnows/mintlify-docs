---
title: "テキスト読み上げ"
description: "Enconvo にテキストを読み上げさせたり、テキストを音声ファイルに変換したりします。"
---

Enconvo には、音声用のコマンドが 2 つあります。**読み上げ**は、Dynamic Island の読み上げプレーヤーでテキストを読み上げます。**TTS(Text To Speech)** は、選んだプロバイダーでテキストを音声ファイルに変換します。チャットの返信を、会話の中でそのまま読み上げさせることもできます。

## チャットの返信を読み上げる

返信の下にあるスピーカーボタンをクリックします。ボタンが、一時停止、再開、停止のついた小さなプレーヤーに変わり、読み上げ中の文が返信の中でハイライトされます。一度に読み上げられる返信は 1 つだけで、チャットを閉じると止まります。

すべての返信を読み上げるには、Smart Bar またはチャットウィンドウで、返信の読み上げをオンにします。各ウィンドウが、それぞれ設定を保持します。

## テキストを読み上げる

1. **設定 → テキスト読み上げ**を開き、プロバイダーと音声を設定します。
2. テキストを選択して**読み上げ**を実行します。
3. Dynamic Island のプレーヤーが、1 文ずつ読み上げます。一時停止、再開、停止、前後へのスキップ、速度や音声の変更、現在の文をハイライトしたテキストの表示ができます。
4. プロバイダーが対応している場合は、プロバイダーの設定で音声や速度を調整します。

[アバター](/ja/features/avatar)が開いているときは、アバターがリップシンクつきでテキストを読み上げ、プレーヤーは Dynamic Island でコンパクトなままです。

## 音声ファイルを作る

読み上げたいテキストを指定して、**TTS(Text To Speech)** を実行します。プロバイダー、音声、速度、出力形式を確認し、生成されたファイルを開いて、発音とテンポを確認します。

[TTS プロバイダーカタログ](/ja/providers/catalog)には、Enconvo Cloud、直接接続のサービス、macOS のシステム、ローカルの選択肢が一覧表示されます。**Enconvo Cloud Voice** は、Enconvo Cloud 独自の音声で、API キーなしで 60 を超える言語に対応します。DeepSeek は、あなた自身の DeepSeek API キーを使うか、**DeepSeek (Enconvo Cloud)** として、女性(Stella)または男性(Tide)の声でテキストを読み上げます。操作はプロバイダーごとに異なります。スタイルの指示や表現タグを受け付けるものもあれば、固定の音声リストを提供するものもあります。

## 声をクローンする

ElevenLabs、Fish Audio、Gemini、Qwen3 は、声をクローンできます。**設定 → テキスト読み上げ**のプロバイダー一覧に、バッジが表示されます。

1. **設定 → テキスト読み上げ**を開き、これらのプロバイダーのいずれかを選び、**ボイスクローン**タブを開きます。
2. 録音をアップロードするか、**録音**をクリックして、表示されたテキストを読み上げます。カウントダウンはキャンセルでき、レベルメーターはあなたの声に合わせて動き、1 回の録音は 5 分で自動的に終了します。
3. クローンした声を再生し、同じタブから、使う、名前を変更する、削除するのいずれかを行います。

これらのプロバイダーの**音声**メニューの横にある**ボイスをクローン**をクリックすることもできます。クローンした声は、**音声**メニューの先頭に表示され、そこでも名前の変更や削除ができます。

タブには、そのプロバイダーで残りのクラウドの音声がいくつあるかが表示されます。上限に達したら、1 つ削除すると別の声をクローンできます。録音中に設定ウィンドウを閉じると、録音は停止し、そこまでに録音した内容が保持されます。

## ローカルとクラウドの音声

ローカルのプロバイダーは Mac 上で動作し、対応するハードウェアとモデルファイルが必要です。Kokoro と Qwen3 は MLX で動作し、英語の音声である Phonon は、Apple シリコンと macOS 15 以降の Mac の Core ML で動作します。**システム**は、macOS に内蔵されている音声を使います。API キーが不要なものを含め、オンラインのプロバイダーは、テキストをネットワーク経由で送信します。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 音が出ない | システムの出力デバイスと、再生が一時停止になっていないかを確認します。 |
| 生成に失敗する | プロバイダーへのアクセスと、テキストの長さと形式を確認します。 |
| 読み上げが止まり、プロバイダーに API キーがないと表示される | **設定 → テキスト読み上げ**でキーを追加するか、Enconvo Cloud または Mac 上で動作する音声を選びます。 |
| 名前が正しく発音されない | もっと短いサンプルでテストし、プロバイダーの発音やスタイルの設定を試します。 |

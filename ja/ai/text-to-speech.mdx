---
title: "テキスト読み上げ"
description: "Enconvo にテキストを音読させたり、テキストから音声ファイルを作成したりできます。"
---

Enconvo には音声読み上げのための 2 つのコマンドがあります。**Read Aloud** は Dynamic Island 上の読み上げプレーヤーでテキストを読み上げます。**TTS(Text To Speech)** は選んだプロバイダーを使ってテキストを音声ファイルに変換します。チャット内の返信を会話画面のまま読み上げさせることもできます。

## チャットの返信を読み上げる

返信の下にあるスピーカーボタンをクリックします。ボタンが一時停止・再開・停止を備えた小さなプレーヤーに変わり、現在読み上げ中の文が返信内でハイライト表示されます。一度に読み上げられる返信は 1 つだけで、チャットを閉じると停止します。

すべての返信を自動で読み上げるようにするには、Smart Bar またはチャットウィンドウで返信の読み上げをオンにしてください。設定はウィンドウごとに保持されます。

## テキストを読み上げる

1. **設定 → テキスト読み上げ**を開き、プロバイダーと音声を設定します。
2. テキストを選択し、**Read Aloud** を実行します。
3. Dynamic Island のプレーヤーが文ごとに読み上げます。プレーヤーから一時停止・再開・停止、前後の文へのスキップ、再生速度や音声の変更、現在読み上げ中の文をハイライトしたテキストの表示が行えます。
4. 対応しているプロバイダーでは、プロバイダー設定で音声や読み上げ速度を調整できます。

[アバター](/ja/features/avatar)を開いているときは、アバターがリップシンクしながらテキストを読み上げ、Dynamic Island 上のプレーヤーはコンパクト表示になります。

## 音声ファイルを作成する

読み上げたいテキストを指定して **TTS(Text To Speech)** を実行します。プロバイダーが提供する音声、速度、出力形式を確認し、生成されたファイルを開いて発音やテンポを確かめてください。

[TTS プロバイダーカタログ](/ja/providers/catalog)には、Enconvo Cloud、各社 API の直接接続、macOS システム音声、ローカルモデルの一覧が載っています。**Enconvo Cloud Voice** は Enconvo Cloud 独自の音声で、API キー不要で 60 以上の言語に対応しています。DeepSeek はご自身の DeepSeek API キーまたは **DeepSeek (Enconvo Cloud)** を使い、女性（Stella）または男性（Tide）の声で読み上げます。プロバイダーによって操作項目は異なり、スタイル指示や感情タグを受け付けるものもあれば、固定の音声リストから選ぶものもあります。

## 声をクローンする

ElevenLabs、Fish Audio、Gemini、Qwen3 では声のクローンを作成できます。**設定 → テキスト読み上げ**のプロバイダー一覧にバッジが表示されます。

1. **設定 → テキスト読み上げ**を開いて該当するプロバイダーを選び、**声のクローン**タブを開きます。
2. 録音ファイルをアップロードするか、**録音**をクリックして表示されたテキストを読み上げます。カウントダウンはキャンセルでき、レベルメーターが声に合わせて動き、1 回の録音は 5 分で自動終了します。
3. クローンした声を再生して確認し、同じタブから利用、名前変更、削除を行えます。

これらのプロバイダーの**音声**メニュー横にある**声をクローン**をクリックして始めることもできます。クローンした声は**音声**メニューの最上部に表示され、そこからも名前変更や削除ができます。

タブには、そのプロバイダーで作成できる Cloud 音声の残り枠数が表示されます。上限に達した場合は、いずれかを削除してから新しくクローンしてください。録音中に設定ウィンドウを閉じると録音は停止し、そこまでの音声が保存されます。

## ローカル音声とクラウド音声

ローカルプロバイダーは Mac 上で動作するため、対応するハードウェアとモデルファイルが必要です。Kokoro と Qwen3 は MLX 上で動作し、英語音声の Phonon は Apple シリコン搭載 Mac（macOS 15 以降）の Core ML 上で動作します。**System** は macOS に組み込まれている音声を使用します。API キー不要のものを含め、オンラインプロバイダーはテキストをネットワーク経由で送信します。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| 音が出ない | システムの出力デバイスと、再生が一時停止になっていないか確認してください。 |
| 生成に失敗する | プロバイダーへのアクセス権限と、テキストの長さ・形式を確認してください。 |
| Read Aloud が停止し、プロバイダーに API キーがないと表示される | **設定 → テキスト読み上げ**でキーを追加するか、Enconvo Cloud または Mac 上で動く音声を選んでください。 |
| 固有名詞などの読み間違いがある | 短いサンプルで試し、プロバイダーの発音・スタイル設定がある場合は調整してください。 |

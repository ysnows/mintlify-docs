---
title: "Web Fetch"
description: "指定した URL からエージェントにウェブページを読み取らせたり、そのページをナレッジベースに保存したりします。"
---

すでに URL を持っていて、エージェントにそのページを読ませたいときに Web Fetch を使います。どのエージェントも渡されたリンクを読み取ることができ、どの取得サービスを使うかをここで選択します。まず関連ページを探す必要がある場合は[ウェブ検索](/ja/ai/web-search)を使ってください。

## プロバイダーを選ぶ

1. **設定 → Web Fetch** を開きます。
2. プロバイダーを選び、**デフォルトに設定**をクリックします。

| プロバイダー | 用途 |
| --- | --- |
| **Local Fetch** | Mac 上で無料かつローカルにページを取得します（ブラウザ連携による取得も選択可能） |
| **Jina AI Link Reader** | Jina 経由で読み取りやすい形式でコンテンツを取得します |
| **Firecrawl Link Reader** | Firecrawl 経由でコンテンツを取得します |
| **DeepSeek** | ご自身の DeepSeek API キーを使い、ページを Markdown として読み取ります |
| **DeepSeek (Enconvo Cloud)** | API キー不要で Enconvo Cloud 経由でページを Markdown として読み取ります |
| **Enconvo Cloud プラン** | Cloud のリンク読み取りサービスを利用します |

## ページを読み取る

1. 会話に URL を貼り付け、そのページについて具体的な質問をします。
2. 回答をそのまま信頼する前に、取得された内容と出典を確認してください。

## ログインが必要なページ

**Local Fetch** の**ブラウザ連携取得**（Browser-Assisted Fetching）を使うと、Enconvo Companion 拡張機能が入った Chromium 系ブラウザ経由でページを読み取れます。

| オプション | 働き |
| --- | --- |
| **自動**（デフォルト） | すでに開いている一致タブがあれば、ログイン状態と描画結果を含めてそのまま再利用します。直接取得に失敗した場合や JavaScript が必要なページでは、一時的なバックグラウンドタブを使います。 |
| **オフ** | 直接 HTTP リクエストのみを行います |
| **常時** | 常にブラウザ経由で取得します |

ブラウザが接続されていない場合、Local Fetch は直接 HTTP リクエストを行います。他のプロバイダーは公開 URL を取得するため、ログイン済みのブラウザセッションは引き継げません。操作を伴うページには[ブラウザ拡張機能](/ja/features/browser-extension)または [Browser Use](/ja/features/browser-control) を使ってください。

## ウェブ上のコンテンツを保存する

後で検索できるように残したい場合は、[ナレッジベース](/ja/ai/knowledge-base)で **追加 → 単一のWebページ** を使って URL を登録します。取り込み後に元のウェブページが更新される場合もあるため、取り込まれた内容とインデックス作成の状態を確認してください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 取得結果が空になる | 追加の操作なしで読めるページか確認するか、**Local Fetch** で**ブラウザ連携取得**を使用してください。ログイン画面、アクセスのブロック、動的読み込み、非対応サイトでは抽出できないことがあります。 |
| ページに書かれていないことまで回答に含まれる | 欠けている内容を推測で補うのではなく、実際に取得できた内容をそのまま表示するようエージェントに指示してください。 |

---
title: "Web ページを取得"
description: "エージェントに URL から Web ページを読ませたり、そのページをナレッジベースに保存したりできます。"
---

URL が分かっていて、エージェントにそのページを読ませたいときは、Web ページを取得を使います。どのエージェントでも、渡されたリンクを読めます。取得に使うサービスは選択できます。まず関連するページを探す必要があるときは、[ウェブ検索](/ja/ai/web-search)を使ってください。

## プロバイダーを選ぶ

1. **設定 → Web ページを取得** を開きます。
2. プロバイダーを選んで **デフォルトに設定** をクリックします。

| プロバイダー | 用途 |
| --- | --- |
| **Local Fetch** | Mac 上で無料でページを取得します。ブラウザを併用した取得も選べます |
| **Jina AI Link Reader** | Jina で読みやすい形式のコンテンツを取得します |
| **Firecrawl Link Reader** | Firecrawl でコンテンツを取得します |
| **DeepSeek** | DeepSeek の API キーでページを Markdown として読み込みます |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud 経由でページを Markdown として読み込みます。API キーは不要です |
| **Enconvo Cloud Plan** | Cloud のリンク読み取りサービスを使います |

## ページを読む

1. URL を会話に貼り付けて、そのページについて具体的な質問をします。
2. 回答を信頼する前に、取得された内容と出典を確認します。

## ログインが必要なページ

**Local Fetch** では、**ブラウザ支援の取得** により、Enconvo Companion 拡張機能が入った Chromium 系ブラウザ経由でページを読み込めます。

| オプション | 内容 |
| --- | --- |
| **自動**（デフォルト） | すでに開いている一致するタブを、完全に描画された状態でログインも含めて再利用します。直接の取得に失敗した場合や、ページに JavaScript が必要な場合は、一時的なバックグラウンドタブを使います。 |
| **オフ** | 直接の HTTP のみ |
| **常に** | 常にブラウザ経由で取得します |

接続されたブラウザがない場合、Local Fetch は直接の HTTP リクエストを行います。その他のプロバイダーは公開 URL を取得するため、あなたのサインイン済みのブラウザセッションは使えません。操作が必要なページには、[ブラウザ拡張機能](/ja/features/browser-extension)または[ブラウザを使用](/ja/features/browser-control)を使ってください。

## Web のコンテンツを保存する

後で見つけたいときは、[ナレッジベース](/ja/ai/knowledge-base)で **追加 → 単一のWebページ** を使って URL を追加します。インポートされたページとそのインデックス化のステータスを確認してください。Web ページは、インポートした後に変更されることがあります。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| コンテンツが空で返ってくる | ページが追加の操作なしで読めるか確認するか、**Local Fetch** の **ブラウザ支援の取得** を使ってください。ログイン画面、ブロックされたリクエスト、動的に読み込まれるコンテンツ、未対応のサイトでは、抽出できないことがあります。 |
| 回答に、ページにはない内容が書かれている | 足りない内容を推測させず、エージェントに実際に取得した内容を見せるよう頼んでください。 |

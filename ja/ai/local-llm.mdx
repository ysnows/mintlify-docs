---
title: "ローカルモデル"
description: "ご自身のハードウェアでモデルを実行し、タスク全体を Mac の中で完結させます。"
---

チャットを非公開にしたいとき、またはプロバイダーのアカウントなしで使いたいときは、Mac、またはお持ちの別のコンピューターでモデルを実行できます。Enconvo には内蔵エンジンがあり、Ollama と LM Studio にも接続できます。

## ランタイムを選ぶ

| ランタイム | 向いている用途 | セットアップ |
| --- | --- | --- |
| [Local LLM (MLX)](/ja/providers/mlx) | macOS 15 以降の Apple Silicon Mac で、Enconvo の中でモデルを実行する | 設定でモデルを選んでダウンロードする |
| [Ollama](/ja/providers/ollama) | この Mac またはサーバー上で、すでに Ollama で管理しているモデル | Ollama を起動してアドレスを設定する |
| [LM Studio](/ja/providers/lm-studio) | この Mac またはサーバー上で、すでに LM Studio で使っているモデル | LM Studio のサーバーを起動してアドレスを設定する |

## 小さく始める

1. ランタイムをセットアップし、モデルをダウンロードまたは読み込みます。
2. 短いテキストメッセージを送信します。
3. 動作したら、ドキュメントやツールを追加します。
4. より大きなモデルを試す前に、メモリ使用量と速度を確認します。**設定 → ローカルモデル** に、この Mac のモデルと、それぞれが使うメモリ量が表示されます。

モデルのサイズ、量子化、コンテキスト長、実行中の他のタスクは、すべてメモリに影響します。固定の目安ではなく、モデルピッカーに表示されるサイズを基準にしてください。

## タスク全体をローカルに保つ

ローカルのチャットモデルだけでは、すべてが Mac の中にとどまるわけではありません。音声認識、テキスト読み上げ、OCR、ドキュメントの解析、埋め込み、リランキング、検索、MCP ツールは、それぞれ専用のプロバイダーを使います。Enconvo には、そのいくつかに対応するローカルプロバイダーがあります。[プロバイダーカタログ](/ja/providers/catalog)に一覧があります。

**設定 → ローカルモデル** には、どの機能がこの Mac で動き、どの機能がクラウドで動くかが表示されます。ウェブ検索などのオンラインサービスにはインターネットが必要です。また、ローカルモデルが、内容を Mac の外に送るツールを呼び出すこともあります。

## 別のコンピューターのモデルサーバーを使う

サーバーがネットワーク接続を受け付けるように設定し、Enconvo の **BaseUrl** にそのコンピューターのアドレスを設定します。`localhost` は常に、Enconvo を実行している Mac を指します。macOS が接続をブロックする場合は、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク** で Enconvo をオンにします。

## 別のモデルサーバーを使う

llama.cpp、vLLM、KoboldCpp、text-generation-webui などのサーバーでは、**設定 → AI モデル** の下部にある **新しいプロバイダーを追加** をクリックし、**OpenAI 互換** を選びます。サーバーのアドレスをベース URL として貼り付けます。Enconvo は、`/v1` の有無にかかわらず、また完全なエンドポイントを貼り付けた場合でも受け付けます。サーバーが API キーを確認しない場合は、API キーを空のままにします。

## 小さなコンテキストでの長いチャット

ローカルサーバーは、モデルが許容するよりも小さいコンテキストでモデルを動かすことがよくあります。Enconvo は、Ollama、llama.cpp、LM Studio、KoboldCpp、text-generation-webui が実際に使っているコンテキストを読み取り、チャットをそれに収まるように圧縮します。コンテキストが小さい場合は、長いチャットを分割して要約します。モデルにより多くの余裕を与えるには、サーバー自身の設定でコンテキスト長を引き上げてください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 長いチャットの最初の部分をモデルが忘れる | サーバーが小さなコンテキストで動いています。サーバーの設定でコンテキスト長を引き上げるか、新しいチャットを始めます。 |
| モデルがツールや画像を無視する | モデルが対応していないため、Enconvo はそれらなしで回答します。ツール呼び出しまたは画像入力に対応したモデルを選びます。 |
| 接続に失敗する | エラーを読んでください。Enconvo はサーバー自身のメッセージを表示し、原因を示します。サーバーが起動していること、アドレスとポートが正しいことを確認します。 |

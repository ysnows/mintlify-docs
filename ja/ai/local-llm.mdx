---
title: "ローカルモデル"
description: "お使いのハードウェア上でモデルを実行し、タスク全体を Mac 内だけで完結させます。"
---

チャット内容をプライベートに保ちたい場合や、プロバイダーのアカウントなしで使いたい場合は、お使いの Mac または所有する別のコンピュータ上でモデルを実行できます。Enconvo は内蔵エンジンを備えており、Ollama や LM Studio にも接続できます。

## ランタイムを選ぶ

| ランタイム | 向いている用途 | セットアップ |
| --- | --- | --- |
| [Local LLM (MLX)](/ja/providers/mlx) | macOS 15 以降の Apple Silicon Mac 上で、Enconvo 内部でモデルを動かす | 設定画面でモデルを選んでダウンロード |
| [Ollama](/ja/providers/ollama) | この Mac やサーバー上で Ollama を使ってすでに管理しているモデル | Ollama を起動してアドレスを設定 |
| [LM Studio](/ja/providers/lm-studio) | この Mac やサーバー上で LM Studio を使ってすでに利用しているモデル | LM Studio のサーバーを起動してアドレスを設定 |

## 小さなモデルから始める

1. ランタイムを設定し、モデルをダウンロードまたは読み込みます。
2. 短いテキストメッセージを送信してみます。
3. 動作が確認できたら、ドキュメントやツールを追加します。
4. より大きなモデルを試す前に、メモリ使用量と速度を確認してください。**設定 → ローカルモデル**では、この Mac にあるモデルと各モデルのメモリ使用量を確認できます。

必要なメモリはモデルサイズ、量子化、コンテキスト長、他に動作しているタスクによって変わります。固定の目安ではなく、モデルピッカーに表示されるサイズを参考にしてください。

## タスク全体をローカルに保つ

チャットモデルをローカルにするだけでは、処理のすべてが Mac 内に留まるわけではありません。音声認識、テキスト読み上げ、OCR、ドキュメント解析、埋め込み、リランキング、検索、MCP ツールはそれぞれ別のプロバイダーを使用します。Enconvo にはこれらの多くに対応するローカルプロバイダーが用意されており、[プロバイダーカタログ](/ja/providers/catalog)に一覧があります。

**設定 → ローカルモデル**では、どの機能がこの Mac 上で動作し、どの機能がクラウドで動作するかを確認できます。ウェブ検索やその他のオンラインサービスには引き続きインターネット接続が必要であり、ローカルモデルであっても Mac の外へデータを送るツールを呼び出すことはあります。

## 別のコンピュータのモデルサーバーを使う

サーバー側でネットワーク接続を受け付けるよう設定し、Enconvo の **BaseUrl** にそのコンピュータのアドレスを指定します。`localhost` は常に Enconvo が動いているこの Mac 自身を指します。macOS によって接続が遮断される場合は、**システム設定 → プライバシーとセキュリティ → ローカルネットワーク**で Enconvo をオンにしてください。

## その他のモデルサーバーを使う

llama.cpp、vLLM、KoboldCpp、text-generation-webui などのサーバーを使う場合は、**設定 → AI モデル**の下部にある **新しいプロバイダーを追加** をクリックし、**OpenAI Compatible** を選択します。ベース URL 欄にサーバーのアドレスを貼り付けてください。末尾の `/v1` の有無や、完全なエンドポイント URL の貼り付けにも対応しています。サーバーが認証を行わない場合は API キーを空欄のままにしてください。

## 小さなコンテキストで長いチャットを続ける

ローカルサーバーでは、モデル本来の最大値より小さなコンテキスト長でモデルを動かしていることがよくあります。Enconvo は Ollama、llama.cpp、LM Studio、KoboldCpp、text-generation-webui が実際に使用しているコンテキスト長を読み取り、収まるようにチャットを圧縮します。コンテキストが小さい環境では、長いチャットを分割して要約します。モデルにより多くの記憶容量を持たせたい場合は、サーバー側の設定でコンテキスト長を増やしてください。

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 長いチャットで最初の内容を忘れてしまう | サーバーが小さなコンテキスト長で動作しています。サーバー側の設定でコンテキスト長を上げるか、新しいチャットを開始してください。 |
| モデルがツールや画像を無視する | そのモデルが対応していないため、Enconvo はそれらを使わずに回答しています。ツール呼び出しや画像入力に対応したモデルを選んでください。 |
| 接続に失敗する | エラー表示を確認してください。Enconvo はサーバーから返されたメッセージと原因を表示します。サーバーが起動していること、アドレスとポートが正しいことを確認してください。 |

コーディングエージェントとは、Claude Code や Codex のような普段使っている AI コーディングツールを Enconvo のチャット内で動かす機能です。プロジェクトフォルダ内のコードを扱う作業に適しており、差分でファイルを編集し、コマンドを実行し、操作前に確認を求めます。一方で、チャットやその履歴、承認操作はチャットウィンドウ、SmartBar、スマートフォン上で Enconvo が管理します。

| コーディングエージェント | 提供元 | 実行場所 |
| --- | --- | --- |
| **Claude Code** | Anthropic | Mac 上（Claude でログイン） |
| **Codex** | OpenAI | Mac 上（ChatGPT でログイン） |
| **Grok Build** | xAI | Mac 上（Grok でログイン） |
| **Antigravity** | Google | Mac 上（Google でログイン） |
| **Muse Code** | Meta | Mac 上（Meta でログイン、またはローカルモデルで実行） |
| **Grok Bot** | xAI | xAI のクラウド上（接続したルーティン経由） |

## はじめる前に

**設定 → エージェント一覧** に各コーディングエージェントの専用ページがあります。クリックして **ステータス** を確認してください。

1. **未インストール** と表示されている場合は **インストール** をクリックするか、表示されたコマンドをターミナルで実行して **再確認** をクリックします。バージョンが古い場合は **更新** と表示されます。
2. **アカウント** の下で **Claude でログイン**、**ChatGPT でログイン**、**Grok でログイン**、**Google でログイン**、または **Meta でログイン** をクリックします。Enconvo はターミナル上の各エージェント自身のコマンドラインと同じサインイン状態を使用します。

Claude Code または Codex のサインイン有効期限が 10 日以内になると、エージェントのページ、**Updates** リスト、プロジェクトのボードにその旨と **再度ログイン** が表示されます。コーディングエージェントがサインアウトしているボード上のタスクは **保留中** として待機し、サインインすると再開されます。

ローカルモデルで実行する Muse Code は Meta へのサインインが不要です。Grok Bot には代わりにルーティンが必要です。[Grok Bot を接続する](#grok-bot-を接続する) を参照してください。

## コーディングエージェントとチャットする

1. チャットウィンドウのエージェントカードまたはエージェントメニューからコーディングエージェントを選びます。
2. 作業対象のプロジェクトフォルダを選択します。
3. 依頼内容を入力して送信します。実行ステップ、差分、コマンドがチャットにストリーミング表示され、承認が必要な確認事項がカードとして表示されるので回答します。

チャットの承認動作は Enconvo の[権限モード](/ja/ai/agents)に従います。**フルアクセス** の場合、新しい Claude Code チャットは（Claude Code 側の設定で許可されていれば）**権限をバイパス** で、新しい Codex チャットは **フルアクセス** で開始されるため、どちらも操作前に確認を求めません。

worktree チャットでは、サイドパネルの **プルリクエスト** タブ（**⌃⇧P**）でそのブランチの GitHub プルリクエストを表示したり、新規作成したりできます。[チャットウィンドウ](/ja/ai/chat)を参照してください。

以前のセッションを引き継ぐには **以前のセッションを再開** を選びます。エージェント自身のコマンドラインから開始したセッションも、付けた名前で一覧に表示されます。

Mavis と始めたチャットをコーディングエージェントへ引き継ぎ、新しいチャットで続きを進めることもできます。他のエージェントがコーディングエージェントをサブエージェントとして使ったり、プロジェクトからタスクを割り当てたり、プロジェクトのリーダーに指定したりすることも可能です。[サブエージェント](/ja/ai/agents)と[プロジェクト](/ja/ai/projects)を参照してください。

### Claude Code：推論レベル、高速モード、Ultracode

Claude Code チャットの推論レベル選択メニューでは思考の深さを設定できます。セッションが対応している場合、メニューには **高速モード** と **Ultracode** スイッチも表示されます。Ultracode をオンにすると、どの推論レベルを選んでもそのセッションの残りでワークフローオーケストレーションが有効になり、途中で推論レベルを変えてもオンのまま維持されます。`/effort ultracode` と入力しても同じです。新しいチャットでは、最初のメッセージを送る前に高速モードと Ultracode を設定できます。

### Codex：警告

Codex の警告は会話本文には表示されません。一覧を見るには `/warnings` と入力します。

### Muse Code：ターミナルで続ける

Muse Code のチャットをターミナルで続けるには **Continue in Terminal** を選ぶか、**コマンドをコピー** でコマンドをコピーします。そのフォルダで `muse resume` を実行してチャットが開きます。ターミナルで Muse Code を終了してから Enconvo 側で再び送信すると、ターミナルで進めたターンがチャットに取り込まれます。

Muse Code の承認確認では、編集によって行われる変更内容が表示されます。ステップを拒否するときに **拒否** と一緒に入力したコメントは同じターン内で Muse Code に渡されるため、すぐに対応を進められます。スキルや `/compact` は `/` メニューから利用できます。

<Note>
Muse Code の Contributor モードはデフォルトでオンになっており、プロンプトやコードが Meta のモデル学習に使われる場合があります。Enconvo はこの設定を変更しないため、不要な場合は Muse Code 側の設定でオフにしてください。
</Note>

## コーディングエージェントが Enconvo 内で使える機能を選ぶ

コーディングエージェントはチャット内で Enconvo のプラグイン（他の Enconvo エージェントへのメッセージ送信、画像・動画生成、メモリ、ブラウザ、コンピューター操作など）を利用できます。**設定 → エージェント一覧** で対象エージェントのページを開き、**Enconvo の機能** の下で設定します。

- すべての Enconvo プラグインを使わせないようにするには、**Enconvo の機能** をオフにします。
- 個別に制限するには、**プラグイン** の横にある **カスタマイズ** をクリックしてプラグインを 1 つずつオフにします。オフにしたプラグインはそのエージェントから隠され、呼び出しも拒否されます。

この変更はすでに開いているチャットにも適用されます。クライアントのワークスペース内で行われているコーディングエージェントのチャットは、そのワークスペース内だけに完全に閉じられます。

## Grok Bot を接続する

Grok Bot は xAI のクラウド上で動作します。Enconvo は各メッセージをあなたが Grok Bot で作成した Webhook ルーティンへ送信し、応答が遅れて届いた場合でもチャットに表示します。

1. Grok Bot で Webhook トリガーを使ったルーティンを作成します。
2. **設定 → エージェント一覧** で **Grok Bot** を開き、**ルーティン用の指示** の横にある **コピー** をクリックしてルーティンに貼り付けます。
3. 同じページの認証情報としてそのルーティンの Webhook URL とキーを追加し、**テスト** をクリックします。テストは最大約 90 秒間、ルーティンからの応答を待ちます。

ルーティンが接続されるまで、エージェント選択欄では Grok Bot が **未設定** と表示されます。メッセージごとに Grok Bot プランの週間利用枠を消費します。**停止** を押しても Enconvo が応答を待つのを止めるだけで、クラウド側のルーティン実行自体は継続し、後から届いた応答もチャットに追加されます。

1 メッセージは最大 32,000 文字まで送信できます。添付したファイルや画像は Mac 上に留まり、テキストのみが送信されます。

### Grok Bot から Enconvo を呼び出せるようにする

Enconvo の MCP サーバーを使うと、Grok Bot からあなたのチャットへ返信したり、Mac やペアリング済みのスマートフォンへ通知を送ったり、Mac 上のエージェントにタスクの実行を依頼したりできます。

1. Grok Bot のページで **Grok Bot から Enconvo を呼び出す** の下にある **接続** をクリックします。Enconvo アカウントへのサインインが必要です。
2. Grok Bot 側で **Plugins** を開き、表示された **サーバー URL** を追加して、Grok Bot から求められたら Enconvo アカウントでサインインします。

Mac 上のエージェントへの各リクエストは、**ask_mac を常に許可** をオンにしない限りあなたの承認待ちになります。リクエストは **この Mac の Grok Bot** チャットに一覧表示されます。Grok Bot からの呼び出しを止めるには **接続を解除** をクリックします。接続を解除するか Mac がオフラインになると、待機中のリクエストは取り下げられます。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| エージェントがサインインしていないと表示される | **設定 → エージェント一覧** で対象エージェントのページを開き、**再度ログイン** をクリックしてください。そのエージェントを呼び出した Mavis のチャットやアプリにも同じサインインエラーが出て、ボードのタスクはサインインするまで **保留中** になります。 |
| **未インストール** またはバージョンが古いと表示される | 対象ページで **インストール** または **更新** をクリックし、続いて **再確認** をクリックしてください。 |
| Muse Code が Enconvo のアップデートを必要としている | 新しい Muse Code に対応するため Enconvo をアップデートしてください。 |
| Grok Bot が **未設定** と表示される | Grok Bot のページでルーティンの Webhook URL とキーを追加し、**テスト** をクリックしてください。 |
| Grok Bot のテストでメッセージが多すぎると表示される | ルーティンまたは Enconvo 側で一時的にメッセージ数を制限しています。しばらくしてから再試行してください。 |
| ターミナルで開いている Muse Code チャットから送信できない | ターミナル内の Muse Code を終了してやり取りをチャットへ戻してから、Enconvo から送信してください。 |

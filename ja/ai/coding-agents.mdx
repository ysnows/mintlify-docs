コーディングエージェントは、Claude Code や Codex など、普段お使いの AI コーディングツールを Enconvo のチャット内で動かすものです。プロジェクトフォルダ内のコードを扱う作業に向いています。ファイルを差分付きで編集し、コマンドを実行し、実行前に確認を求めます。Enconvo は、そのチャットと履歴、承認をチャットウィンドウ、SmartBar、iPhone で管理します。

| コーディングエージェント | 提供元 | 実行場所 |
| --- | --- | --- |
| **Claude Code** | Anthropic | お使いの Mac 上、Claude でログイン |
| **Codex** | OpenAI | お使いの Mac 上、ChatGPT でログイン |
| **Grok Build** | xAI | お使いの Mac 上、Grok でログイン |
| **Antigravity** | Google | お使いの Mac 上、Google でログイン |
| **Muse Code** | Meta | お使いの Mac 上、Meta でログイン、またはローカルモデル |
| **Grok Bot** | xAI | xAI のクラウド上、接続したルーティン経由 |

## はじめる前に

各コーディングエージェントには、**設定 → エージェント一覧**に専用のページがあります。クリックすると**ステータス**が表示されます。

1. **未インストール**と表示された場合は、**インストール**をクリックするか、表示されたコマンドを「ターミナル」で実行して**再確認**をクリックします。バージョンが古い場合は**更新**と表示されます。
2. **アカウント**で、**Claude でログイン**、**ChatGPT でログイン**、**Grok でログイン**、**Google でログイン**、**Meta でログイン**のいずれかをクリックします。Enconvo は、ターミナルでのエージェント自身のコマンドラインと同じログインを使います。

Claude Code または Codex のログインが 10 日以内に期限切れになる場合は、エージェントのページ、**アップデート**の一覧、プロジェクトの**ボード**にその旨が表示され、**再度ログイン**が選べます。コーディングエージェントがログアウトしているボードのタスクは**保留中**になり、ログインすると再び実行されます。

ローカルモデルで動かす Muse Code には、Meta でのログインは不要です。Grok Bot にはルーティンが必要です。[Grok Bot を接続する](#grok-bot-を接続する)をご覧ください。

## コーディングエージェントとチャットする

1. チャットウィンドウで、エージェントカードまたはエージェントメニューからコーディングエージェントを選びます。
2. エージェントが作業するプロジェクトフォルダを選びます。
3. リクエストを入力して送信します。ステップ、差分、コマンドがチャットにストリーミング表示され、承認の確認はカードとして表示されるので、そこで回答します。

チャットでの承認は、Enconvo の[権限モード](/ja/ai/agents)に従います。**フルアクセス**では、新しい Claude Code のチャットは（Claude Code 自身の設定で許可されている場合）**権限をバイパス**で、新しい Codex のチャットは**フルアクセス**で始まるため、どちらも実行前に確認しません。

ワークツリーのチャットでは、サイドパネルの**プルリクエスト**タブ（**⌃⇧P**）に、そのブランチの GitHub 上のプルリクエストが表示されます。ここからプルリクエストを作成することもできます。[チャットウィンドウ](/ja/ai/chat)をご覧ください。

以前のセッションを引き継ぐには、**以前のセッションを再開**を選びます。エージェント自身のコマンドラインで開始したセッションも、付けた名前で一覧に表示されます。

Mavis で始めたチャットは、新しいチャットでコーディングエージェントに引き継ぐこともできます。ほかのエージェントはコーディングエージェントをサブエージェントとして使え、プロジェクトではタスクを割り当てたり、1 つをプロジェクトのリードにしたりできます。[サブエージェント](/ja/ai/agents)と[プロジェクト](/ja/ai/projects)をご覧ください。

### Claude Code：エフォート、高速モード、Ultracode

Claude Code のチャットにあるエフォートピッカーで、推論エフォートを設定します。セッションが対応している場合、ピッカーには**高速モード**と **Ultracode** のスイッチも表示されます。Ultracode をオンにすると、選んだエフォートのまま、セッションの残りでワークフローオーケストレーションが有効になり、エフォートを変えてもオンのままです。`/effort ultracode` と入力しても同じ操作になります。新しいチャットでは、最初のメッセージの前に高速モードと Ultracode を設定できます。

### Codex：警告

Codex の警告は会話に表示されません。`/warnings` と入力すると一覧を表示します。

### Muse Code：ターミナルで続ける

Muse Code のチャットをターミナルで続けるには、**Continue in Terminal** を選ぶか、**コマンドをコピー**でコマンドをコピーします。チャットは、そのフォルダで `muse resume` を実行した状態で開きます。ターミナルで Muse Code を終了してから Enconvo で再び送信すると、ターミナルで行ったやり取りがチャットに戻ります。

Muse Code の承認の確認には、編集によって加えられる変更が表示されます。ステップを拒否するときに**拒否**と一緒に入力した内容は同じターンで Muse Code に渡されるため、すぐに反映されます。スキルと `/compact` は `/` メニューにあります。

<Note>
Muse Code の Contributor モードは、初期設定でオンになっており、Meta があなたのプロンプトとコードでモデルをトレーニングできるようになります。Enconvo はこの設定をそのままにしています。オフにするには、Muse Code 自身の設定で行ってください。
</Note>

## コーディングエージェントが Enconvo で使えるものを選ぶ

コーディングエージェントは、チャットの中で Enconvo のプラグインを使えます。たとえば、Enconvo のエージェントへのメッセージ送信、画像と動画の作成、メモリ、ブラウザ、コンピューター操作などです。**設定 → エージェント一覧**にあるエージェントのページの **Enconvo の機能**で、次のように設定します。

- **Enconvo の機能**をオフにすると、そのエージェントは Enconvo のプラグインをすべて使えなくなります。
- または、**プラグイン**の横の**カスタマイズ**をクリックして、プラグインを 1 つずつオフにします。オフにしたプラグインはそのエージェントから見えなくなり、呼び出しは拒否されます。

変更は、そのエージェントで開いているチャットにも反映されます。クライアントのワークスペース内のコーディングエージェントのチャットは、そのワークスペースの中だけで完結します。

## Grok Bot を接続する

Grok Bot は xAI のクラウドで動作します。Enconvo は、Grok Bot で作成した Webhook ルーティンに各メッセージを送り、返信が遅れて届いた場合でも、その返信をチャットに表示します。

1. Grok Bot で、Webhook トリガーを持つルーティンを作成します。
2. **設定 → エージェント一覧**の **Grok Bot** を開き、**ルーティン用の指示**の横の**コピー**をクリックして、その内容をルーティンに貼り付けます。
3. 同じページで、ルーティンの Webhook URL とキーを認証情報として追加し、**テスト**をクリックします。テストは、ルーティンの返信を最大約 90 秒間待ちます。

ルーティンを接続するまで、エージェントピッカーでは Grok Bot が**未設定**と表示されます。メッセージを送るたびに、Grok Bot プランの週間使用量が消費されます。**停止**は Enconvo が待つのをやめるだけです。ルーティンの実行はクラウドで続き、後から届いた返信もチャットに追加されます。

1 通のメッセージは最大 32,000 文字です。添付ファイルと画像はお使いの Mac に残り、送信されるのはテキストだけです。

### Grok Bot から Enconvo を呼び出せるようにする

Enconvo の MCP サーバーを使うと、Grok Bot はチャットへの返信、お使いの Mac とペアリング済みの iPhone への通知、Mac 上のエージェントへのタスク実行の依頼ができます。

1. Grok Bot のページの **Grok Bot から Enconvo を呼び出す**で、**接続**をクリックします。Enconvo アカウントにログインしている必要があります。
2. Grok Bot で**プラグイン**を開き、表示された**サーバー URL**を追加して、Grok Bot から求められたら Enconvo アカウントでログインします。

Mac 上のエージェントへのリクエストは、**ask_mac を常に許可**をオンにしない限り、そのたびにあなたの承認を待ちます。リクエストは **この Mac の Grok Bot** チャットに一覧表示されます。**接続を解除**をクリックすると、Grok Bot から Enconvo を呼び出せなくなります。接続を解除したときや Mac がオフラインになったときは、承認待ちのリクエストが取り下げられます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| チャットに、エージェントがログインしていないと表示される | **設定 → エージェント一覧**でエージェントのページを開き、**再度ログイン**をクリックします。そのエージェントを呼び出した Mavis のチャットやアプリにも同じログインエラーが表示され、そのボードのタスクはログインするまで**保留中**になります。 |
| エージェントが**未インストール**、またはバージョンが古いと表示される | ページで**インストール**または**更新**をクリックし、続けて**再確認**をクリックします。 |
| Muse Code から Enconvo の更新が必要と表示される | 新しい Muse Code に対応するため、Enconvo を更新してください。 |
| Grok Bot が**未設定**と表示される | Grok Bot のページでルーティンの Webhook URL とキーを追加し、**テスト**をクリックします。 |
| Grok Bot のテストで、メッセージが多すぎると表示される | ルーティンまたは Enconvo が、現在多くのメッセージを受け付けない状態です。しばらくしてからもう一度お試しください。 |
| ターミナルで開いている Muse Code のチャットが送信できない | ターミナルで Muse Code を終了してやり取りをチャットに戻し、Enconvo から送信します。 |

---
title: "OCR"
description: "画面の任意の範囲や画像からテキストをコピーします。読み取りは Mac 上でも、オンラインサービスでも行えます。"
---

OCR は、スクリーンショットや画像の中のテキストを読み取るので、コピー、ペースト、翻訳、質問ができます。画像、動画のフレーム、スキャンしたページなど、テキストを選択できないときに使ってください。テキストを Mac 上で読み取るか、オンラインサービスで読み取るかは、選べます。

## 始める前に

Enconvo が画面を取り込むには、画面収録の権限が必要です。[権限](/ja/configuration/permissions)を参照してください。

## 画面からテキストをコピーする

1. SmartBar から **スクリーンショット OCR** を実行します。
2. テキストのある範囲をドラッグして選びます。
3. テキストが Dynamic Island で開きます。**コピー** をクリックするか、**ペースト**（**⌘↩**）で使用中のアプリに入力します。

同じ結果から、**翻訳** や **AI に質問** もクリックできます。**⋯** メニューには、**元の改行を保持**、**画像をコピー**、**画像を保存…**、**範囲をもう一度選択**、**ナレッジベースに追加**、**OCR 設定…** があります。

別のプロバイダーでもう一度範囲を読み取るには、テキストの上にあるプロバイダー名をクリックして、別のものを選びます。プロバイダーが各行の位置を把握している場合は、画像表示に切り替えて、スクリーンショット上で行を選択し、**選択範囲をコピー** をクリックします。

## その他の OCR コマンド

| コマンド | 内容 |
| --- | --- |
| **スクリーンショット OCR** | 画面の範囲を読み取り、テキストを Dynamic Island で開きます |
| **サイレントスクリーンショット OCR** | 画面の範囲を読み取り、テキストをクリップボードにコピーします |
| **OCR** | 渡した画像の中のテキストを読み取ります |
| **スクリーンショット翻訳** | 画面の範囲を翻訳します。[翻訳](/ja/ai/translate)を参照してください |
| **スクリーンショットを説明** | 画面の範囲を説明します。[ライティングツール](/ja/features/writing-tools)を参照してください |

## プロバイダーを選ぶ

**設定 → OCR** を開き、プロバイダーを選んで、**デフォルトに設定** をクリックします。

| プロバイダー | テキストを読み取る場所 |
| --- | --- |
| **Apple Native OCR** | Mac 上で、Apple 独自のテキスト認識を使います |
| **PP-OCRv6 (MLX)** | Mac 上で、Apple シリコン向けの PaddleOCR の検出モデルと認識モデルを使います。データは Mac の外に出ません |
| **AI Model OCR** | 選んだ AI モデルが、その **指示** に従って読み取ります |
| **Mistral OCR** | Mistral のオンラインサービスが、あなたの Mistral のキーまたは Mistral のサインインで読み取ります |
| **Mistral OCR (Enconvo Cloud Plan)** | Mistral のオンラインサービスが、Enconvo Cloud プランを通じて読み取ります |

各 OCR コマンドは、それぞれ独自のプロバイダーを使うこともできます。**設定 → プラグイン → OCR** のコマンドの設定で、**OCR プロバイダ** を設定します。各プロバイダーの項目については、[プロバイダーカタログ](/ja/providers/catalog)を参照してください。

## より良い結果を得る

テキストが読みやすいサイズになるように、範囲を絞って取り込んでください。段組み、表、句読点、コードのインデント、似た形の文字は、手作業で確認してください。

PDF ファイルであっても、スキャンしたドキュメントには OCR が必要なことがあります。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 取り込みが空白、または開始しない | [権限](/ja/configuration/permissions)で画面収録の権限を確認してください |
| **テキストが見つかりません** | **範囲をもう一度選択** をクリックして、より狭い範囲を選んでください。手書き文字や装飾的な書体は、**AI モデル OCR を試す** のほうが読み取れることがあります |
| **読み取れませんでした** | **再試行** をクリックし、シンプルな画像で試して、プロバイダーのエラーを読んでください。**設定** で OCR 設定が開きます |
| 行が連結される、または誤った位置で折り返される | **⋯** メニューで **元の改行を保持** をオンまたはオフにするか、別のプロバイダーでもう一度範囲を読み取ってください |
| テキストをコピーするのではなく、画面上のものについて質問したい | [Appshots](/ja/features/appshots) または[画面に描画](/ja/features/screen-doodle)を使ってください |

---

OCR はスクリーンショットや画像内のテキストを読み取り、コピー、ペースト、翻訳、質問に使えるようにします。画像、動画のフレーム、スキャンしたページなど、テキストを直接選択できない場面で役立ちます。文字の読み取りを Mac 上で行うか、オンラインサービスで行うかを選択できます。

## 始める前に

画面をキャプチャするには、Enconvo に「画面収録」の権限が必要です。詳しくは[権限](/ja/configuration/permissions)をご覧ください。

## 画面からテキストをコピーする

1. SmartBar から **Screenshot OCR** を実行します。
2. テキストが含まれる範囲をドラッグして選択します。
3. Dynamic Island に読み取ったテキストが開きます。**コピー** をクリックするか、**ペースト**（**⌘↩**）で現在使っているアプリに貼り付けます。

同じ結果画面から **翻訳** や **AI に質問** をクリックすることもできます。**⋯** メニューには **元の改行を保持**、**画像をコピー**、**画像を保存…**、**範囲をもう一度選択**、**ナレッジベースに追加**、**OCR 設定…** があります。

別のプロバイダーで同じ範囲を読み取り直したい場合は、テキストの上にあるプロバイダー名をクリックして別のものを選択します。各行の位置を認識できるプロバイダーの場合は、画像ビューに切り替えてスクリーンショット上で直接行を選択し、**選択部分をコピー** をクリックできます。

## その他の OCR コマンド

| コマンド | 説明 |
| --- | --- |
| **Screenshot OCR** | 画面の範囲を読み取り、Dynamic Island でテキストを開きます |
| **Silent Screenshot OCR** | 画面の範囲を読み取り、クリップボードへテキストをコピーします |
| **OCR** | 指定した画像内のテキストを読み取ります |
| **Screenshot Translate** | 画面の範囲を翻訳します。詳しくは[翻訳](/ja/ai/translate)をご覧ください |
| **Screenshot Explain** | 画面の範囲を解説します。詳しくは[ライティングツールキット](/ja/features/writing-tools)をご覧ください |

## プロバイダーを選ぶ

**設定 → OCR** を開き、プロバイダーを選んで **デフォルトに設定** をクリックします。

| プロバイダー | テキストの読み取り場所 |
| --- | --- |
| **Apple Native OCR** | Mac 上で Apple 標準のテキスト認識を使用します |
| **PP-OCRv6 (MLX)** | Mac 上の Apple Silicon で PaddleOCR の検出・認識モデルを実行します。データは Mac の外へ送信されません |
| **AI Model OCR** | 選択した AI モデルが、その **Instruction** に従って読み取ります |
| **Mistral OCR** | お使いの Mistral キーまたは Mistral サインインを使って Mistral のオンラインサービスで処理します |
| **Mistral OCR (Enconvo Cloud Plan)** | Enconvo Cloud プランを通じて Mistral のオンラインサービスで処理します |

各 OCR コマンドに個別のプロバイダーを設定することもできます。**設定 → プラグイン → OCR** でそれぞれの設定から **OCR Provider** を指定してください。各プロバイダーの設定項目については[プロバイダーカタログ](/ja/providers/catalog)をご覧ください。

## より良い結果を得るには

文字が読みやすい大きさの状態で、必要な範囲だけをぴったりと囲んでキャプチャしてください。段組み、表、句読点、コードのインデント、似た形状の文字は目視でも確認することをおすすめします。

スキャンされたドキュメントは、PDF ファイルであっても OCR が必要になる場合があります。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| キャプチャが真っ白になる、または開始できない | [権限](/ja/configuration/permissions)で画面収録の権限を確認してください |
| **テキストが見つかりません** | **範囲をもう一度選択** をクリックし、より狭い範囲を指定してください。手書き文字や装飾書体は **AI モデル OCR を試す** でうまく読める場合があります |
| **読み取れませんでした** | **再試行** をクリックするか、シンプルな画像で試し、プロバイダーのエラー内容を確認してください。**設定** から OCR 設定を開けます |
| 行がつながったり変な位置で改行されたりする | **⋯** メニューの **元の改行を保持** をオンまたはオフにするか、別のプロバイダーで範囲を読み取り直してください |
| テキストのコピーではなく画面上の内容について質問したい | [Appshots](/ja/features/appshots) または [Screen Doodle](/ja/features/screen-doodle) をご利用ください |

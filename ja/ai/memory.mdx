メモリには、エージェントがチャットをまたいで保持する短い情報が入ります。たとえば、あなたの好み、あなたに関する事実、あなたが下した決定などです。すべてのエージェントが同じメモリを共有し、各チャットの開始時に、ピン留めされたものを先頭にして参照します。メモリは、チャットの記録や、ドキュメントを集めた[ナレッジベース](/ja/ai/knowledge-base)とは異なります。

この動画では、メモリ、あなたについて、ナレッジベース、クイックキャプチャを紹介しています。

あなたのメモリは[ナレッジベース](/ja/ai/knowledge-base)の中にあります。チャットウィンドウでサイドバーの **ナレッジベース** をクリックし、列の上部にある **ナレッジベース** / **メモリ** のスイッチで切り替えて表示します。メモリはナレッジベースの 1 つとしては一覧に表示されず、メモリへのリンクはナレッジベースをメモリの表示で開きます。

**設定 → メモリ** の上部には **エージェントが参照できるもの** が表示され、メモリ、チャット履歴、録音、ナレッジベースのそれぞれの件数が分かります。

## メモリが保存されるしくみ

エージェントは、あなたについて知るたびにメモリを保存します。**チャットから自動で学習** がオンの場合、Enconvo はチャットが静かになったあとに見直しを行います。最後のメッセージから 3 分後、または新しいメッセージが 6 件たまった時点です。今後のチャットで役立つ内容が残され、**設定 → メモリ** の **最近学習したもの** に、変更ごとに **元に戻す** 付きで一覧表示されます。

学習では、機密情報、グループチャット、一度きりのタスクはスキップされます。他の人が返信を読む IM のグループチャットでは、メモリは使われません。

自分で追加するには、**設定 → メモリ** を開いて **メモリを開く** をクリックし、**追加 → メモリ** を選びます。

## メモリを確認して編集する

1. **設定 → メモリ** を開いて **メモリを開く** をクリックするか、チャットウィンドウでナレッジベースを **メモリ** に切り替えます。
2. **フィルタ**、**タグ**、**種類** で一覧を絞り込むか、**グリッド**、**リスト**、**マップ** を切り替えます。
3. メモリを開いて、内容と、学習元になったチャットを確認します。
4. 不正確な情報や古い情報は、編集するか、確認画面を読んでから削除します。
5. すべてのチャットでエージェントにメモリを見せるには、メモリを右クリックして **ピン留め** を選びます。

項目は、簡潔に、事実に基づいて、誰または何に関するものかが具体的に分かるように書いてください。

## 概念とマップ

**メモリを開く** で **マップ** を選ぶと、メモリが、その対象である人、プロジェクト、場所、トピックごとにまとめて表示されます。これらはそれぞれ概念です。

1. 概念をクリックすると、概要、その概念のメモリ、関連する概念が表示されます。
2. **これについて質問** をクリックすると、その概念についてのチャットが始まります。
3. まだ整理待ちのメモリを整理するには、待機中の件数が表示された **今すぐ … を整理** ボタンをクリックします。**再構築** は、すべてのメモリをもう一度整理し直します。概念の名前は保持され、リンクは作り直され、空の概念は削除されます。
4. **概念を削除** は、概念とそのリンクを削除します。メモリは残ります。

メモリ整理は、新しいメモリや変更されたメモリを、バックグラウンドで概念ごとに整理します。概念について質問すると、エージェントはそれを丸ごと読み込み、チャットで訂正すると、概念の名前を変更したり削除したりします。また、想起では、質問とは言葉が異なっていても、あなたが挙げた人、プロジェクト、トピックの下に整理されたメモリも見つかります。

## 設定

**設定 → メモリ** を開きます。

| 設定 | 内容 |
| --- | --- |
| **メモリ**（上部のスイッチ） | すべてのエージェントでメモリのオンとオフを切り替えます。オフの間は、学習も整理も想起も行われず、メモリは再びオンにするまで保持されます。 |
| **チャットから自動で学習** | あなたに関する事実、好み、やり方の好みを保存します。**最近学習したもの** に、保持した内容が **元に戻す** 付きで一覧表示されます。 |
| **メモリを整理** | Mac がアイドル状態のときに、重複を統合し、食い違う 2 つのメモリのうち新しい方を残し、日付が過ぎた予定を更新し、エージェントが見落としてはならない内容をピン留めします。変更のたびに、以前のバージョンが保持されます。 |
| **頻度** | **毎日** または **毎週** 整理します。**今すぐ整理** はすぐに実行します。 |
| **以前の整理** | 過去 90 日間に整理で変更された内容を元に戻せます。 |
| **やり方を学習** | メモリが事実を学習するのと同じように、スキルがあなたの好みのやり方を学習できるようにします。変更はチャットに **元に戻す** 付きで表示され、メモリの見直しとメモリ整理はスキルも対象にします。[スキルに作業のやり方を学習させる](/ja/configuration/skills)を参照してください。 |
| **想起** | 返信にあなたの発言や保存した内容が必要なときに、エージェントが探す場所です。**メモリ**（常にオン）、**チャット履歴**、**録音**、**ナレッジベース** があります。 |
| **検索** | メモリ、チャット、録音、ナレッジベースをインデックス化する埋め込みモデルです。**このMac** または **Enconvo Cloud** を選べます。 |
| **メモリモデル** | 学習と整理に使われる軽量モデルです。料金は、そのプロバイダーでの他のリクエストと同じように請求されます。 |

## あなたについて

すべてのエージェントにあなた自身のことを伝えるには、**設定 → あなたについて** を開きます。すべてのエージェント、音声通話、アバターがこの情報を使います。

| 項目 | 用途 |
| --- | --- |
| **呼び名** | あなたの名前またはニックネームです。エージェントが何と呼べばよいか分かります。 |
| **プロフィールの説明** | あなたと仕事について少し書きます。返信のパーソナライズに使ってよい内容だけを書いてください。 |
| **応答言語** | エージェントが回答する言語です。特定のエージェントだけ別の言語にするには、そのエージェントの設定の **動作** で応答言語を変更します。 |

## メモリを意識して使う

自分の設定で **メモリを有効にする** をオフにしているエージェントは、メモリを使いません。ある情報が再利用されるか確かめるには、保存や想起がされたと思い込まず、新しいチャットを開いて、その情報が必要になる普通の質問をしてみてください。

もう一度入力する手間を省くために、認証情報や機密情報を保存するのはやめてください。エージェントとプロバイダーの設定によっては、モデルへのリクエストに想起されたメモリが含まれることがあります。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 回答に古い情報が使われている | 1 つの返信を訂正するだけでなく、**メモリを開く** でそのメモリを見つけて修正または削除してください。現在の会話のコンテキストも確認してください。 |
| エージェントが何も覚えていない | **設定 → メモリ** で **メモリ** がオンになっていること、そのエージェントの **メモリを有効にする** がオンになっていることを確認してください。IM のグループチャットではメモリは使われません。 |
| Enconvo が望まない内容を保存した | **設定 → メモリ** の **最近学習したもの** で **元に戻す** をクリックします。 |
| 整理で、残したかったメモリが変更された | **設定 → メモリ** の **以前の整理** を開き、変更を元に戻します。 |

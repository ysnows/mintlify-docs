メモリは、あなたの好み、あなたに関する事実、あなたが下した決定など、エージェントがチャットをまたいで保持する短い情報を保存します。すべてのエージェントが同じメモリを共有し、各チャットの開始時にピン留めされたものから順に参照します。メモリはチャットの履歴やドキュメント用の[ナレッジベース](/ja/ai/knowledge-base)とは異なる仕組みです。

メモリは[ナレッジベース](/ja/ai/knowledge-base)の中に保存されます。チャットウィンドウのサイドバーで **ナレッジベース** をクリックし、列上部の **ナレッジベース** / **メモリ** スイッチを切り替えて確認します。メモリはナレッジベースの一覧には含まれず、メモリへのリンクを開くとナレッジベースの「メモリ」ビューが開きます。

**設定 → メモリ** の上部には **エージェントが参照できるもの** が表示され、メモリ、チャット履歴、録音、ナレッジベースの各件数を確認できます。

## メモリが保存される仕組み

エージェントはあなたについて学ぶにつれてメモリを保存します。**チャットから自動で学習** がオンの場合、最後のメッセージから 3 分経過するか、新しいメッセージが 6 件たまると、Enconvo がチャットを見直します。今後のチャットでも役立つ情報が保存され、そのチャットの末尾に **元に戻す** ボタン付きのメモリカードが表示されます。

認証情報、グループチャット、その場限りの単発タスクは学習対象から除外されます。また、他の人も返信を読む IM グループチャットではメモリは使用されません。

自分で追加するには、**設定 → メモリ** を開き、**メモリを開く** をクリックして **追加 → メモリ** を選択します。

## メモリの確認と編集

1. **設定 → メモリ** を開いて **メモリを開く** をクリックするか、チャットウィンドウでナレッジベースを **メモリ** に切り替えます。
2. **フィルタ**、**タグ**、**種類** で一覧を絞り込んだり、**グリッド**、**リスト**、**マップ** 表示を切り替えたりできます。
3. メモリを開くと、内容と学習元のチャットを確認できます。
4. 不正確または古くなった情報を編集するか、確認画面の内容を確かめて削除します。
5. すべてのチャットでエージェントに必ず見せたいメモリは、右クリックして **ピン留め** を選びます。

内容は簡潔で事実に即し、誰・何についての情報かが明確に分かるように書いてください。

## 概念とマップ

**メモリを開く** で **マップ** を選ぶと、人物、プロジェクト、場所、トピックごとにグループ化されたメモリを確認できます。これらのグループをそれぞれ「概念（Concept）」と呼びます。

1. 概念をクリックすると、その概要、含まれるメモリ、関連する概念が表示されます。
2. **これについて質問** をクリックすると、その概念についてのチャットを開始できます。
3. 未分類のまま待機しているメモリを整理するには、待機件数が表示されている **今すぐ … 件を分類** ボタンをクリックします。**再構築** を実行するとすべてのメモリを再分類し、概念の名前は維持したままリンクを張り直して、空になった概念を削除します。
4. **概念を削除** を実行すると、その概念とリンクが削除されます（中のメモリは残ります）。

メモリの整理機能はバックグラウンドで新規・変更されたメモリを概念に分類します。概念について質問するとエージェントはその概念全体を読み取り、チャット内で訂正すると概念の名前変更や削除を行います。また、質問と表現が異なっていても、指定した人物・プロジェクト・トピックに分類されたメモリを思い出しやすくなります。

## 設定

**設定 → メモリ** を開きます。

| 設定 | 働き |
| --- | --- |
| **メモリ**（上部のスイッチ） | すべてのエージェントでメモリをオンまたはオフにします。オフにすると学習・整理・想起がすべて停止しますが、既存のメモリは再度オンにするまで保持されます。 |
| **チャットから自動で学習** | あなたに関する事実、好み、作業の進め方を保存します。**最近学習したもの** に保存された内容と **元に戻す** が表示されます。 |
| **メモリを整理** | Mac がアイドル状態のときに、重複の統合、矛盾する 2 つのメモリのうち新しい方の採用、日付を過ぎた予定の更新、エージェントが見落としてはならない内容のピン留めを行います。変更時は以前のバージョンが保持されます。 |
| **頻度** | 整理を **毎日** または **毎週** 実行します。**今すぐ整理** で即座に実行できます。 |
| **以前の整理** | 過去 90 日間に整理機能が変更した内容を元に戻せます。 |
| **作業手順を学習** | メモリが事実を学習するのと同じように、スキルがあなたの作業手順を学習できるようにします。変更ごとにチャットへ **元に戻す** 付きで表示され、メモリレビューやメモリ整理の対象にもなります。[作業の進め方をスキルに覚えさせる](/ja/configuration/skills)を参照してください。 |
| **想起対象** | 返信時に過去の発言や保存内容を参照する対象です。**メモリ**（常時オン）、**チャット履歴**、**録音**、**ナレッジベース** があります。 |
| **検索** | メモリ、チャット、録音、ナレッジベースをインデックス化する埋め込みモデルです。**この Mac** または **Enconvo Cloud** を選択します。 |
| **メモリモデル** | 学習や整理の実行に使われる軽量モデルです。他のリクエストと同様に各プロバイダーの料金が適用されます。 |

## あなたについて

すべてのエージェントに自分自身の基本情報を伝えるには、**設定 → あなたについて** を開きます。すべてのエージェント、音声通話、アバターがこの情報を参照します。

| 項目 | 用途 |
| --- | --- |
| **希望する呼び名** | エージェントがあなたを呼ぶときの名前やニックネーム。 |
| **プロフィール説明** | あなた自身や仕事についての簡単な説明。返信のパーソナライズに使ってよい情報だけを入力してください。 |
| **応答言語** | エージェントが回答に使う言語。特定のエージェントだけ別の言語にする場合は、そのエージェント設定の **動作** にある応答言語を変更します。 |

## メモリを意識的に活用する

自身の設定で **メモリを有効化** がオフになっているエージェントはメモリを使用しません。情報が正しく再利用されるか確認したいときは、保存や想起を前提に思い込むのではなく、新しいチャットを開いてその情報を必要とする普通の質問をしてみてください。

再入力の手間を省くためだけに認証情報や機密情報を保存しないでください。エージェントやプロバイダーの設定によっては、想起されたメモリがモデルへのリクエストに含まれる場合があります。

## メモリ・ナレッジ・キャプチャの使い分け

| 内容 | 最適な保存場所 |
| --- | --- |
| 繰り返し使える短い好みや事実 | メモリ |
| ドキュメントや参考資料 | [ナレッジベース](/ja/ai/knowledge-base) |
| 音声で素早く残すアイデア | [音声メモ](/ja/features/voice-notes) |
| 他のアプリに表示されている内容 | [クイックキャプチャ](/ja/features/quick-capture) |
| 一時的な相談や議論 | [チャット](/ja/ai/chat) |

## トラブルシューティング

| 問題 | 対処法 |
| --- | --- |
| 回答に古い情報が使われる | 1 回の返信を訂正するだけでなく、**メモリを開く** で該当メモリを探して修正または削除してください。現在の会話コンテキストもあわせて確認します。 |
| エージェントが何も覚えていない | **設定 → メモリ** で **メモリ** がオンになっていること、およびエージェントの **メモリを有効化** がオンになっていることを確認してください。IM グループチャットではメモリは使用されません。 |
| 保存したくない内容が保存された | チャット末尾のメモリカード、または **設定 → メモリ** の **最近学習したもの** で **元に戻す** をクリックします。 |
| 整理機能によって残したかったメモリが変更された | **設定 → メモリ** の **以前の整理** を開いて変更を元に戻します。 |

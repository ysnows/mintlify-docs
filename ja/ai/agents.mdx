エージェントは、特定の作業向けに指示、モデル、ツールを 1 つにまとめたものです。同じ指示を何度も入力している場合や、作業に特定のツール一式が必要な場合に作成してください。エージェントは **設定 → エージェント一覧** で管理します。

下の動画では、Mavis と組み込みエージェント、コーディングエージェント、エージェントの構成要素、そして自分だけのエージェントの作成方法を 2 分弱で紹介しています。

## 最初から使えるエージェント

**Mavis** はデフォルトのエージェントです。質問に答えるだけでなく、アプリの操作、ウェブ閲覧、ファイル作業も行えます。組み込みエージェントはそれぞれ専門の役割を持っています（**Writer**、**Planner**、**Reviewer**、**Advisor**、**Researcher**、**Designer**、**Coder**）。**Claude Code**、**Codex**、**Grok Build**、**Antigravity**、**Muse Code** はインストール済みのコーディングエージェントと連携してプロジェクトフォルダ内で作業し、**Grok Bot** はクラウド上の xAI エージェントとチャットします。詳しくは [コーディングエージェント](/ja/ai/coding-agents) を参照してください。

チャット上部のエージェントメニュー、またはチャットウィンドウの入力欄の上にあるカードからエージェントを選択できます。一覧には、最近チャットしたエージェントが上位に表示されます。

## エージェントの構成要素

**設定 → エージェント一覧** でエージェントをクリックすると設定ページが開きます。左側のセクションから各項目へ移動できます。

| セクション | 設定できる内容 |
| --- | --- |
| **指示** | すべての会話の前にエージェントへ渡される指示です。入力するとすぐ保存されます。 |
| **スタイル** | **応答スタイル** と **インテリジェント UI** のレベル（図表、表、カードをどの程度積極的に使うか）を設定します。詳しくは [スタイルを設定する](#スタイルを設定する) を参照してください。 |
| **モデル** | 応答の生成に使う AI モデルです。エージェントごとに異なるモデルを指定できます。 |
| **ツールとスキル** | 使用できるツールや残りのツールの見つけ方、スキルフォルダ、さらに専用スキルや作業対象ファイルを置く **作業フォルダ** を設定します。詳しくは [ツールとスキルを選ぶ](#ツールとスキルを選ぶ) を参照してください。 |
| **ナレッジ** | どのナレッジベースをどの順で参照するか、答えが見つからない場合にウェブ検索を行うかを設定します。詳しくは [ナレッジベースを選ぶ](#ナレッジベースを選ぶ) を参照してください。 |
| **メモリ** | 参照するメモリと、新しい事柄を記憶するかどうかを設定します。 |
| **音声** | 応答を読み上げるときに使う音声です。 |
| **動作** | **応答言語** や **Cloud ポイント実行上限** など、参照範囲、動作方法、応答方法を設定します。 |
| **利用元** | チャット以外でこのエージェントを起動するものと、**リンク・CLI・API** 行を表示します。 |

## エージェントを作成する

1. **設定 → エージェント一覧** で **新しいエージェント** をクリックするか、SmartBar から **Create Agent** を実行します。
2. **タイトル** を入力し、必要に応じて **アバター** と目的の **説明** を入力します。
3. **エージェントの指示** に、何を行うか、どんな入力が必要か、結果をどのように提示するかを記述します。
4. **使用できる機能** で、まず **日常**（すべての組み込みツール）、**コーディング**、**リサーチ**、**ライティング** のプリセットから選びます。あとから **ツールとスキル** で変更できます。
5. モデルを選びます。**おすすめのモデル** では、Enconvo が説明を読み取って Enconvo Cloud モデルを 1 つ提案し、その横に安価なモデルと高性能なモデルも表示します。**これを使う** をクリックするか、他のモデルを選んでください。詳しくは [おすすめのモデルを使う](/ja/ai/model-selection-guide) を参照してください。
6. **ボットを作成** をクリックします。その後エージェントを開き、スキルやナレッジを設定します。
7. 新しいチャットを開始して、代表的な小さなタスクでテストします。

画像をアップロードする代わりにアバターを生成したい場合は、作成時またはあとからエージェント設定のアバターピッカーで **生成** タブを開きます。スタイル（**フラット**、**3D**、**アニメ**、**写真**、**ライン**、**水彩**）を選んで **生成** をクリックすると、画像モデルがエージェントの名前と説明から 4 枚のアバターを描画します。詳細を追加して再生成するか、気に入ったものをクリックしてください。**生成** をクリックするまで描画は実行されません。

指示の例：

```text
Help me turn meeting notes into actionable follow-ups.
Separate decisions, open questions, and action items.
For action items, preserve the owner and due date if stated;
otherwise mark them as unspecified.
```

## スタイルを設定する

**スタイル** にある 2 つの設定で、エージェントの応答の読みやすさが決まります。チャット単体では、**+** メニューの **スタイルを使用** から別のスタイルを選ぶこともできます。

**応答スタイル** はトーン、長さ、形式を設定します。**標準**、**簡潔に**、**解説**、**フォーマル**、または独自のスタイルから選べます。**新しいスタイル** をクリックすると説明や自分の文章サンプルから作成でき、**管理** で作成したスタイルを編集できます。

**インテリジェント UI** は、明示的に指示しなくても図表・表・カードで回答する積極度を設定します。

| レベル | 動作 |
| --- | --- |
| **厳選** | データ、比較、計画のみ図解します。要約や説明はテキストのままにします。 |
| **積極的**（デフォルト） | 説明の中であっても、図表・表・カードの方が見やすい場合は追加します。 |
| **ビジュアル優先** | ビジュアルを中心に構成し、1 回の応答で複数使うこともあります。応答に少し時間がかかります。 |

ビジュアルを増やすと処理時間が長くなり、消費ポイントも増えます。メッセージングチャネルと音声応答はテキストのみになります。

## ツールとスキルを選ぶ

**ツールとスキル** で、エージェントが使用するツールの見つけ方を選びます。

- **自動検出**（推奨）は基本ツールから始め、タスクで必要になったときにインストール済みのスキル、プラグイン、コネクタ、MCP サーバーを自動で見つけます。意味で照合するため、ツールの説明と異なる言い回しや別の言語での依頼でも見つけられます。
- **選択したもののみ** はエージェントに固定のセットだけを与えます。使用を許可する組み込みツール、スキル、MCP サーバーを選択してください。それ以外のツールがタスクで必要になった場合、検索せず不足していることを伝えます。

**自動検出** を使っていても、このエージェントに触れてほしくない **組み込みツール** をオフにしたり、**ピン留めされたスキル** にスキルを固定してすべてのチャットで一覧に表示したり、**Enconvo ストアからのプラグイン提案** をオフにしてインストール提案を止めたりできます。**スキルフォルダ** では、このエージェントに対して個別のスキルをオフにできます。

エージェントには業務に必要なツールだけを与えてください。

| 目的 | 機能 |
| --- | --- |
| ドキュメントの閲覧・編集 | [ファイルツール](/ja/ai/file-tools) |
| 最新情報の検索 | [ウェブ検索](/ja/ai/web-search) と [Web ページを取得](/ja/ai/web-fetch) |
| ウェブサイトでの作業 | [ブラウザを使用](/ja/features/browser-control) |
| デスクトップアプリの操作 | [コンピューター操作](/ja/features/computer-use) |
| 自分の資料を検索 | [ナレッジベース](/ja/ai/knowledge-base) |
| 手順の再利用 | [スキル](/ja/configuration/skills) |
| 外部サービスの接続 | [MCP サーバー](/ja/features/mcp) |
| コードの実行 | [コードランナー](/ja/ai/code-runner) |
| 1 ステップで複数のツール呼び出し | [Code Mode](/ja/configuration/code-mode) |

使用するモデルは、選択したツールや入力形式に対応している必要があります。また、各ツールにはそれぞれ認証情報、アクセス権、セットアップが必要であり、指示文だけでエージェントが持っていない権限を与えることはできません。

## ナレッジベースを選ぶ

**ナレッジ** で、エージェントが参照する場所を選択します。

| オプション | 動作 |
| --- | --- |
| **すべてのナレッジベース** | 質問で必要なときに、いずれかのナレッジベースを検索します。 |
| **選んだものを先に** | 追加したナレッジベースを先に検索し、答えがなければ残りを検索します。 |
| **選んだものだけ** | 追加したナレッジベースのみを検索します。それ以外は `@` で指定したときだけ開きます。 |

**ナレッジベースを追加** をクリックして選択し、検索する順番にドラッグして並べ替えます。

## 操作を承認する

実行モードの横にある **権限** チップで、エージェントが操作の前に停止して確認を求めるタイミングを設定します。チャットウィンドウ、SmartBar、アプリのサイドバー、Dynamic Island のエージェントモードに表示されます。いずれの画面で変更しても同じエージェントの設定が変わるため、変更内容は他の画面にも反映されます。

| モード | 確認を求める操作 |
| --- | --- |
| **承認を求める** | コマンドの実行、作業フォルダ外のファイル編集、アプリ・ブラウザ・オンラインサービスでの操作 |
| **自動で承認**（デフォルト） | ファイル削除、メッセージ送信、公開、支払いなど、リスクがありそうな操作のみ |
| **フルアクセス** | なし。エージェントは確認せずに実行します |

ファイルの読み取り、検索、画面の参照で確認を求められることはありません。また **自動で承認** では、自分自身の `PATH` を設定するだけのコマンドや、一時フォルダ内に作成したファイルを削除するコマンドでは確認しませんが、それ以外の削除は確認を求めます。

エージェントが別のエージェントやコーディングエージェントに作業を渡すと、呼び出された側も会話中のエージェントと同じモードで動作します。各承認カードには、「このプロジェクトが自動で承認になっているため確認しています」のように、確認の理由となった設定が表示されます。コマンド実行後の制限については [エージェントサンドボックス](/ja/configuration/sandbox) を参照してください。

### 確認が表示される場所

確認はチャットを実行しているウィンドウに表示されます。そのウィンドウがチャットを表示していない場合（非表示になっている、またはインラインパネルの場合など）は、Dynamic Island に移動します。30 秒以内に応答がない場合、チャットウィンドウが開いたまま別アプリの背後にあっても、ペアリング済みの iPhone にリマインダー通知が届きます。

応答せずに Dynamic Island のカードを閉じた場合は、Dynamic Island のチャットにある待機中のステップをクリックすると選択肢を再表示できます。エージェントからの質問も同じ仕組みです。

### 応答方法

- **1 回だけ許可** はこの 1 回の操作のみ実行を許可します。
- **許可して今後確認しない** はそのチャットの残りの間許可し続け、Enconvo の再起動後も記憶されます。
- または、代わりにエージェントに行ってほしい内容をテキストで入力します。

チャットが待機中の間は、チャットウィンドウの一覧、SmartBar の最近のチャット、Dynamic Island で実行中ではなく **承認待ち** と表示されます。iPhone アプリのチャット一覧では **承認が必要** と表示されます。

サブエージェントは親チャット上で確認を求め、サブエージェントからの質問であることと担当タスク名が表示されます。予約タスク、ワークフロー、メッセージングチャネルは画面前で応答する人がいないため、確認なしで実行されます。

## サブエージェント

エージェントモードでは、エージェントがタスクを分割し、最大 6 つのサブエージェントを同時にそれぞれの会話として起動できます。すべてが報告を返したあとで回答をまとめます。これは複数の独立した検索など、分割が明確に有効な場合や、あなたが指示した場合にのみ行われます。レート制限などの AI エラーでサブエージェントが途中停止した場合でも、エージェントはそれまでに得られた結果を受け取り、エラー解消後に続行させられます。

サブエージェントを起動する際、エージェントは独自のモデル、推論の強さ、指示、名前を与えたり、現在の会話をフォークして引き継いだりできます。エージェントがモデルを自分で選ぶ場合は、素早い検索・読み取り・単純な反復作業はプロバイダーの小型モデルで実行し、高度な推論には高い推論の強さを割り当て、それ以外はあなたが選んだモデルをそのまま使います。サブエージェントはさらに最大 3 階層まで自分のサブエージェントを起動できます。

- **コーディングエージェントをサブエージェントとして使う:** Claude Code、Codex、Antigravity、Grok Build、Muse Code がサブエージェントとして動作できます。カードにはコーディングエージェントのアイコン、作業場所、使用したツール呼び出し数・時間・トークンが表示されます。
- **独立したワークツリー:** サブエージェントが別のサブエージェントと同時にファイルを変更する場合、お互いの作業を上書きしないよう専用の git ワークツリーが割り当てられます。変更がなかったワークツリーはサブエージェント終了時に削除されます。デザイン、ドキュメント、スライド、リサーチ、レビューのみを行うサブエージェントはワークツリーなしで動作するため、複数起動してもプロジェクトが人数分コピーされることはありません。
- **ほかのコンピュータ:** エージェントはペアリング済みの別のコンピュータ上でサブエージェントを実行し、そのコンピュータのエージェントやコーディングエージェントにタスクを渡せます。詳しくは [ほかのコンピュータ](/ja/integrations/other-computers) を参照してください。
- **指示の追加・制御:** エージェントは実行中のサブエージェントのタスクにメッセージを追加したり、中断したり、同じプロジェクト内の別エージェントのチャットへ連絡したりできます。チャットを停止すると、その配下のサブエージェントもすべて停止します。
- **パイプライン:** エージェントは、ファイル一覧に対する同一チェックなど、計画された一連のサブエージェントを 1 ステップで実行できます。途中で失敗した場合は、完了済みのサブエージェントを再実行せずに途中から再開します。

### 並列チャット

別タスクのために新しいチャットを開くようエージェントに頼むと、指定した推論の強さで新しいチャットが開き、Mac・iPhone・Android のチャット一覧にあなたが開始したチャットと同様に並びます。上部にはどのチャットから開始されたかの注記が表示されます。そのタスクのレビューやテストは、引き続きそのチャットのサブエージェントとして実行されます。エージェントが自分用に開いたチャットも、カードの操作からあなたのチャット一覧へ移動できます。

### サブエージェントの追跡と会話

チャット内のカードに各サブエージェントがタスクごとに一覧表示され、実行中・承認待ち・完了・失敗をアイコンで示します。実行中のサブエージェントの行には、現在の処理内容、実行中のモデルと推論の強さも表示されます。新しいサブエージェントは、カードが表示されると同時にメッセージボックス上のバックグラウンドトレイにも表示されます。

デザインやドキュメントなど、サブエージェントが作成したものは生成に合わせて行の下に表示されます。クリックするとチャット横に開き、エージェントは回答内のカードとして引き渡します。

- 行をクリックすると、そのサブエージェントの会話が開きます。ワークスペースパネルや `@` ファイル検索には、起動元チャットの作業フォルダが表示されます。SmartBar と Dynamic Island ではその場で作業内容が開きます。
- サブエージェントの会話に入力すると直接会話できます。その場で回答し、あなたに質問したり、その会話内で承認を求めたりしながら、同じフォルダで作業を続けます。親エージェントはその回答を待ってから最新の返答を受け取ります。すでに完了したサブエージェントにメッセージを送ると、別のサブエージェントが同じフォルダのファイルを変更中であっても即座に再開します。
- サブエージェントの会話では、各メッセージに送信元のエージェントが表示されます。親エージェントからのメッセージには、実行中のタスクを誘導したか、待機したか、中断したか、新しいターンを開始したかが示されます。
- チャット詳細の **系譜** には、3 階層までのサブエージェント全体のツリーが表示されます。コーディングエージェントのチャットでは、起動元の Enconvo チャットが表示されます。
- チャットウィンドウのサイドバーでは、チャットの配下にサブエージェントが一覧表示され、チャット行のボタンで折りたたむことができます。

### サブエージェントの役割

すべてのサブエージェントは次のいずれかの役割で開始します。

| 役割 | 動作 |
| --- | --- |
| **デフォルト** | 起動元エージェントと同一の指示、ツール、モデルで作業します |
| **Explorer** | ファイルの読み取り、検索、アプリの参照のみを行います。権限チップの設定にかかわらず、編集、変更を伴うコマンド実行、オンライン操作はできません |
| **あなたのエージェントの 1 つ** | そのエージェント自身の指示、ツール、モデルを使い、起動元チャットと同じ作業フォルダで実行します |
| **プロジェクトヘルパー** | 作業フォルダまたはリポジトリルートまでの上位フォルダにある `.claude/agents`、`.codex/agents`、`.enconvo/agents` で定義されます。起動元エージェントとして動作しつつ、ヘルパー独自の指示に従います。ファイルに列挙されたツールのみを使い、ファイル指定どおり読み取り専用で動作でき、プロバイダーが対応していればヘルパーのモデルを使用します |
| **ユーザー独自のヘルパー** | ホームフォルダの `~/.enconvo/agents`、`~/.claude/agents`、`~/.codex/agents` で定義され、すべてのチャットで利用できます。プロジェクトヘルパーと同様に動作します |

自分で役割を選びたい場合は、エージェントモードのチャットで `@` を入力し、**サブエージェント** グループからヘルパー、**Explorer**、または汎用の **サブエージェント** を選択します。エージェントはそのメッセージ用に該当サブエージェントを起動してタスクを渡し、報告が返ってから回答します。作成した独自のエージェントはメニュー内のエージェントグループに表示されます。

各エージェントの設定には説明を明確に書いておいてください。作業を分割するエージェントは、その説明を読んでどのエージェントがタスクに合うかを判断します。推論の強さを指定して自分のエージェントやコーディングエージェントにチームメイトとしてタスクを渡す方法は、[Agent Orchestrator](/ja/ai/agent-orchestrator) を参照してください。

### プロジェクトヘルパー

プロジェクトヘルパーとユーザー独自のヘルパーは、Claude Code のサブエージェントや Codex のエージェントロールと同じファイル形式を使うため、すでにこれらが置かれているリポジトリやホームフォルダでは追加設定なしで利用できます。

- Claude Code のファイル（frontmatter に `name` と `description` を持つ Markdown）は、`permissionMode: plan` が設定されているか、`Read`、`Grep`、`Glob` など読み取り系ツールのみが列挙されている場合、読み取り専用になります。
- Codex のファイル（`description` と `developer_instructions` を持つ TOML）は、`sandbox_mode = "read-only"` の場合に読み取り専用になります。
- プロバイダーがヘルパーのモデルを提供していない場合は、代わりにチャットのモデルを使用します。

Claude Code ファイルの `tools` と `disallowedTools` によって、エージェントのどのツールをヘルパーが使用できるかが決まります。Enconvo は各名称を対応する自身のツールに割り当てます。

| ヘルパーファイル内の指定 | ヘルパーができる操作 |
|---|---|
| `Read`, `Grep`, `Glob`, `LS` | ファイルの読み取りと検索 |
| `Edit`, `MultiEdit`, `Write` | ファイルの編集と作成 |
| `Bash` | 任意のシェルコマンドの実行 |
| `Bash(git diff:*)` | `git diff` で始まるコマンドのみの実行 |
| `WebSearch`, `WebFetch` | ウェブ検索とウェブページの読み込み |
| `mcp__github__get_issue`, `mcp__github` | 接続済み MCP サーバーの 1 つのツール、または全ツールの使用 |

`tools` 行がない場合、ヘルパーは `disallowedTools` に指定されたものを除くすべてのツールを使えます。許可リスト外の呼び出しは実行されず、ヘルパーには利用可能なツール一覧が通知されます。すべてのヘルパーは引き続きスキルを読み込んだり、あなたに質問したりできます。`.enconvo/agents` ファイルでは、`browser-use/*` のように Enconvo ツールを API パスで指定することも可能です。

Claude Code ファイルのスキル、MCP サーバー、ターン上限、バックグラウンド、ワークツリー設定もそのまま有効になります。

## エージェントを呼び出す方法

- [チャットウィンドウ](/ja/ai/chat)、[SmartBar](/ja/features/smartbar)、[アプリのサイドバー](/ja/features/app-sidebar)、または [Dynamic Island](/ja/features/dynamic-island) でチャットする。
- **音声コマンド** を設定して、選んだエージェントに音声で依頼を送る。詳しくは [音声入力](/ja/features/dictation) を参照してください。
- [Live Talk](/ja/features/live-voice) で会話したり、[アバター](/ja/features/avatar) でデスクトップキャラクターとして表示したりする。
- [メッセージングチャネル](/ja/integrations/messaging) でメッセージアプリと連携する。
- [予約タスク](/ja/workflows/scheduled-jobs) を使ってあとから実行する。
- リンク、ターミナルコマンド、API 呼び出しで Enconvo の外から実行する。詳しくは [リンクと CLI と API](#リンクと-cli-と-api) を参照してください。

### リンクと CLI と API

**設定 → エージェント一覧** でエージェントを開きます。**利用元** の下にある **リンク、CLI、API** 行に **表示** ボタンがあります。これをクリックすると、テキストやファイルを渡してこのエージェントを実行するためのディープリンク、ターミナルコマンド、API コールがコピー可能な状態で表示されます。AI コマンドにも同じ行があります。

## デフォルト設定と継続性

複数のチャットやチャネルで使われているエージェントを変更する前には、[デフォルトモデルのガイド](/ja/ai/model-selection-guide) を確認してください。再利用してほしい事実は [メモリ](/ja/ai/memory) に設定し、資料一式を指示欄に詰め込むのではなくナレッジベースに入れておきましょう。

## トラブルシューティング

| 問題 | 対処方法 |
| --- | --- |
| リクエストが失敗する | まずツールエラーの内容を確認するか、必要な入力が抜けていないか確認してください。 |
| モデルとツールのどちらが原因かわからない | オプションのツールをオフにして同じリクエストを試し、その後ツールを 1 つずつ戻して確認してください。 |
| 操作がファイルや外部サービスを変更しようとしている | 承認する前に変更先と影響範囲を確認してください。 |
| エージェントがツールやスキルが足りないと言う | **ツールとスキル** で **選択したもののみ** になっていないか、または組み込みツールがオフになっていないか確認してください。 |
| 応答の図表やカードが多すぎる、または時間がかかりすぎる | **スタイル** の **インテリジェント UI** を **厳選** に設定するか、1 つのチャットだけ **+** メニューの **スタイルを使用** から変更してください。 |

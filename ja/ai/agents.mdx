エージェントは、1 種類の作業のために、指示、モデル、ツールを組み合わせたものです。同じ指示を何度も出すときや、作業に特定のツールの組み合わせが必要なときに作ってください。エージェントは **設定 → エージェント一覧** で管理します。

## 最初から使えるエージェント

**Mavis** はデフォルトのエージェントです。回答するだけでなく、アプリを使ったり、Web を閲覧したり、ファイルを扱ったりもできます。組み込みのエージェントは、それぞれ 1 つの仕事のために作られています。**ライター**、**プランナー**、**レビュアー**、**アドバイザー**、**リサーチャー**、**デザイナー**、**コーダー** です。**Claude Code**、**Codex**、**Grok Build**、**Antigravity**、**Muse Code** は、インストール済みのコーディングエージェントと、プロジェクトフォルダで作業しながらチャットします。**Grok Bot** は、クラウド上の xAI のエージェントとチャットします。[コーディングエージェント](/ja/ai/coding-agents)を参照してください。

エージェントは、どのチャットでも上部のエージェントメニューから、またはチャットウィンドウの入力欄の上のカードから選べます。エージェントの一覧では、最近チャットしたエージェントが先頭に表示されます。

## エージェントの構成要素

**設定 → エージェント一覧** でエージェントをクリックすると、そのページが開きます。左側のセクションから、各部分に移動できます。

| セクション | 設定する内容 |
| --- | --- |
| **指示** | 毎回の会話の前にエージェントに伝える内容です。変更は入力と同時に保存されます。 |
| **スタイル** | **応答スタイル** と、**インテリジェント UI** のレベル（グラフ、表、カードでどのくらい積極的に回答するか）です。[スタイルを設定する](#スタイルを設定する)を参照してください。 |
| **モデル** | エージェントが文章を書くための AI モデルです。エージェントごとに別のモデルを使えます。 |
| **ツールとスキル** | 使えるものと、残りの見つけ方に加え、スキルフォルダと、専用のスキルや作業するファイルを置く **作業フォルダ** です。[ツールとスキルを選ぶ](#ツールとスキルを選ぶ)を参照してください。 |
| **ナレッジ** | どのナレッジベースを、どの順番で調べるか、答えがない場合に Web を検索するかどうかです。[ナレッジベースを選ぶ](#ナレッジベースを選ぶ)を参照してください。 |
| **メモリ** | どのメモリを読み取るか、新しいことを覚えるかどうかです。 |
| **音声** | 返信を読み上げる声です。 |
| **動作** | 何が見えるか、どう実行するか、どう返信するか。たとえば **応答言語** や **Cloud ポイントの実行上限** です。 |
| **利用元** | チャット以外で、このエージェントを起動するものと、**リンク、CLI、API** の行です。 |

## エージェントを作成する

1. **設定 → エージェント一覧** で **エージェントを新規作成** をクリックするか、SmartBar から **エージェントを作成** を実行します。
2. **タイトル** を入力し、必要に応じて **アバター** と、目的の **説明** も入力します。
3. **エージェントの指示** で、何をすべきか、どんな入力が必要か、結果をどう提示するかを説明します。
4. **何を使えますか？** で、プリセットから始めます。**日常**（すべての組み込みツール）、**コーディング**、**リサーチ**、**ライティング** があります。あとから **ツールとスキル** で変更できます。
5. モデルを選びます。**おすすめのモデル** の下で、Enconvo が説明を読んで、Enconvo Cloud のモデルを提案し、隣により安価なものとより高性能なものも示します。**これを使う** をクリックするか、他のものから選びます。[おすすめを活用する](/ja/ai/model-selection-guide)を参照してください。
6. **ボットを作成** をクリックします。そのあと、エージェントを開いて、スキルとナレッジを選びます。
7. そのエージェントで新しいチャットを始め、小さな典型的なタスクで試します。

アバターをアップロードする代わりに描画するには、ここで、またはあとからエージェントの設定で、アバターピッカーの **生成** タブを開きます。スタイル（**フラット**、**3D**、**アニメ**、**写真**、**線**、**水彩**）を選んで **生成** をクリックすると、画像モデルがエージェントの名前と説明から 4 つのアバターを描きます。詳細を追加してもう一度描くか、気に入ったものをクリックします。**生成** をクリックするまで、何も描かれません。

指示の例:

```text
Help me turn meeting notes into actionable follow-ups.
Separate decisions, open questions, and action items.
For action items, preserve the owner and due date if stated;
otherwise mark them as unspecified.
```

## スタイルを設定する

**スタイル** の下の 2 つの設定が、エージェントの返信の読み味を決めます。チャットでは、**+** メニューの **スタイルを使用** で、別のスタイルを自分用に選べます。

**応答スタイル** は、トーン、長さ、形式を設定します。**標準**、**簡潔に**、**解説**、**フォーマル**、または自分で作ったスタイルです。**新しいスタイル** をクリックすると、説明や自分の文章のサンプルからスタイルを作れます。**管理** で、自分のスタイルを編集できます。

**インテリジェント UI** は、頼まれなくても、グラフ、表、カードで回答する積極さを設定します。

| レベル | 内容 |
| --- | --- |
| **厳選** | データ、比較、計画を描画します。要約と説明はテキストのままです。 |
| **積極的**（デフォルト） | 説明の中でも、グラフ、表、カードのほうが読みやすいときは、いつでも追加します。 |
| **ビジュアル優先** | ビジュアルを先頭に置き、1 つの返信で複数使うこともできます。返信には、少し時間がかかります。 |

ビジュアルが多いほど、時間がかかり、ポイントも多く使います。IM チャネルと音声の返信は、テキストのままです。

## ツールとスキルを選ぶ

**ツールとスキル** で、エージェントが使うものの見つけ方を選びます。

- **自動検出**（推奨）は、必須のものから始め、タスクが必要とするときに、インストール済みのスキル、プラグイン、コネクタ、MCP サーバーを見つけます。意味で照合するため、ツールの説明と異なる言い回しや、別の言語で書かれたリクエストでも見つけられます。
- **選んだものだけ** は、エージェントに固定のセットを与えます。使ってよい組み込みツール、スキル、MCP サーバーを選びます。タスクに別のものが必要な場合は、探さずに、何が足りないかをあなたに伝えます。

**自動検出** でも、このエージェントが決して触れてはいけない **組み込みツール** をオフにしたり、**固定したスキル** でスキルを固定して、すべてのチャットで一覧に表示したり、**Enconvo ストアからプラグインを提案** をオフにして、インストールするプラグインの提案を止めたりできます。**スキルフォルダ** では、このエージェントに対して個別のスキルをオフにできます。

エージェントには、仕事に必要なツールだけを与えてください。

| 必要なこと | 機能 |
| --- | --- |
| ドキュメントを読んで編集する | [ファイルツール](/ja/ai/file-tools) |
| 最新の情報を探す | [ウェブ検索](/ja/ai/web-search)と [Web ページを取得](/ja/ai/web-fetch) |
| Web サイトで作業する | [ブラウザを使用](/ja/features/browser-control) |
| デスクトップアプリを操作する | [コンピューター操作](/ja/features/computer-use) |
| 自分の資料を検索する | [ナレッジベース](/ja/ai/knowledge-base) |
| 手順を再利用する | [スキル](/ja/configuration/skills) |
| 外部サービスに接続する | [MCP サーバー](/ja/features/mcp) |
| コードを実行する | [コードランナー](/ja/ai/code-runner) |
| 1 ステップで多数のツール呼び出しを行う | [コードモード](/ja/configuration/code-mode) |

モデルは、選んだツールと入力の種類に対応している必要があります。ツールには、それぞれの認証情報、アクセス、設定も必要で、指示によって、エージェントが持っていない権限を与えることはできません。

## ナレッジベースを選ぶ

**ナレッジ** で、エージェントが調べる場所を選びます。

| オプション | 内容 |
| --- | --- |
| **すべてのナレッジベース** | 質問に必要なとき、あなたのどのナレッジベースでも調べます。 |
| **選んだものを先に** | 追加したものを先に調べ、そこになければ残りを調べます。 |
| **選んだものだけ** | 追加したものだけを調べます。他のものは、`@` でメンションしたときにだけ開きます。 |

**ナレッジベースを追加** をクリックして選び、調べる順番にドラッグして並べます。

## アクションを承認する

実行モードの隣の **権限** チップは、エージェントが行動する前に止まって確認するタイミングを設定します。チャットウィンドウ、SmartBar、アプリのサイドバー、Dynamic Island のエージェントモードに表示されます。いずれも、そのエージェントの同じ設定を変更するため、1 か所での変更は、他にも反映されます。

| モード | 確認を求めるタイミング |
| --- | --- |
| **承認を求める** | コマンドの実行、作業フォルダの外にあるファイルの編集、アプリ、ブラウザ、オンラインサービスでの操作の前 |
| **自動で承認**（デフォルト） | ファイルの削除、メッセージの送信、公開、支払いなど、安全でない可能性のある操作のみ |
| **フルアクセス** | なし。エージェントは確認せずに行動します |

ファイルの読み取り、検索、画面の確認では、確認を求めません。**自動で承認** は、自分自身のためだけに `PATH` を設定するコマンドや、一時フォルダの下に自分で作ったものを削除するコマンドの前でも確認を求めません。それ以外を削除する場合は、確認を求めます。

エージェントが別のエージェントやコーディングエージェントに作業を渡すとき、呼び出された側は、あなたがチャットしているエージェントと同じモードで動作します。各承認カードには、どの設定によって確認を求めたかが表示されます。たとえば「このプロジェクトが「自動で承認」のため確認しました。」のようになります。コマンドの実行後に何が制限されるかは、[エージェントのサンドボックス](/ja/configuration/sandbox)を参照してください。

### 質問が表示される場所

質問は、チャットが実行されているウィンドウに表示されます。そのウィンドウにチャットが表示されていない場合（たとえば、非表示の場合や、インラインパネルの場合）は、質問が Dynamic Island に移ります。そこで 30 秒以内に誰も答えない場合は、ペアリングした iPhone にリマインダー通知が届きます。使用中のアプリの後ろで、チャットのウィンドウがまだ開いていても同様です。

回答せずに Dynamic Island のカードを閉じた場合は、Dynamic Island のチャットで待機中のステップをクリックすると、選択肢がもう一度表示されます。エージェントがあなたに尋ねる質問も、同じように動作します。

### 質問に答える

- **はい、今回のみ許可** は、この 1 回の操作だけを実行させます。
- **はい、今後は確認しない** は、そのチャットの残りの間、許可します。Enconvo を再起動しても記憶されます。
- または、代わりにエージェントにしてほしいことを入力します。

チャットが待機している間は、チャットウィンドウの一覧、SmartBar の最近のチャット、Dynamic Island で、実行中の代わりに **承認待ち** と表示されます。iPhone アプリのチャット一覧では **承認が必要** と表示されます。

サブエージェントは、親のチャットで確認を求め、質問には、サブエージェントが尋ねていることと、どのタスクに取り組んでいるかが表示されます。予約タスク、ワークフロー、IM チャネルは、回答するためにウィンドウの前にいる人がいないため、確認なしで実行されます。

## サブエージェント

エージェントモードでは、エージェントがタスクを分割して、最大 6 つのサブエージェントを、それぞれ独自の会話で同時に動かせます。報告が戻ってきてから、回答します。これは、複数の独立した検索など、分割が明らかに役立つ場合や、あなたが頼んだ場合にだけ行われます。レート制限などの AI エラーでサブエージェントが途中で止まった場合も、エージェントはそこまでの結果を受け取り、エラーが解消してから続行させることができます。

サブエージェントを起動するとき、エージェントは、専用のモデル、推論の強度、指示、名前を与えたり、現在の会話をそこに分岐させたりできます。エージェントがモデルを自分で選ぶ場合、簡単な調べもの、読み取り、単純な繰り返し作業は、プロバイダーの小型モデルで実行され、より難しい推論にはより高い強度が使われ、それ以外は、あなたが選んだモデルのままです。サブエージェントは、独自のサブエージェントを、最大 3 階層まで起動できます。

- **サブエージェントとしてのコーディングエージェント。** Claude Code、Codex、Antigravity、Grok Build、Muse Code は、サブエージェントとして動作できます。カードには、コーディングエージェントのアイコン、作業場所、使用したツール呼び出し、時間、トークンが表示されます。
- **個別のワークツリー。** あるサブエージェントがファイルを変更している間に、別のサブエージェントもファイルを変更する場合、それぞれに専用の git ワークツリーが与えられ、2 つのサブエージェントが互いの作業を上書きすることはありません。変更のないワークツリーは、サブエージェントが終了したときに削除されます。デザイン、ドキュメント、スライド、リサーチ、レビューだけを行うサブエージェントは、ワークツリーなしで動作するため、複数を起動しても、そのたびにプロジェクトがコピーされることはありません。
- **他のコンピューター。** エージェントは、ペアリングした別のコンピューターでサブエージェントを実行し、そのコンピューターのエージェントやコーディングエージェントにタスクを渡せます。[他のコンピューター](/ja/integrations/other-computers)を参照してください。
- **方向づけ。** エージェントは、実行中のサブエージェントのタスクにメッセージを追加したり、中断したり、同じプロジェクト内の別のエージェントのチャットに接続したりできます。チャットを停止すると、その下のすべてのサブエージェントが停止します。
- **パイプライン。** エージェントは、ファイルの一覧に対する同じチェックなど、計画されたサブエージェントのセットを 1 ステップで実行できます。失敗した実行は、終了したサブエージェントを再実行せずに再開されます。

### 並行するチャット

エージェントに、別のタスクのために新しいチャットを開くよう頼むと、頼んだ推論の強度で、新しいチャットが開き、自分で始めたチャットと同じように、Mac、iPhone、Android のチャット一覧に表示されます。上部のメモに、どのチャットが開始したかが表示されます。そのタスクのレビューとテストは、引き続きそのサブエージェントとして実行されます。エージェントが自分のために始めたチャットは、そのカードから、あなたのチャット一覧に移動できます。

### サブエージェントを追跡して話しかける

チャットのカードには、各サブエージェントがタスクごとに一覧表示され、アイコンで、実行中、あなたの承認待ち、完了、失敗のどれかが分かります。実行中のサブエージェントの行には、今何をしているかと、実行しているモデルと強度も表示されます。新しいサブエージェントは、カードが表示されるのと同時に、メッセージ欄の上のバックグラウンドトレイにも表示されます。

サブエージェントが作ったもの（デザインやドキュメントなど）は、作られるにつれて、その行の下に表示されます。クリックすると、チャットの横で開きます。エージェントは、回答の中のカードとして、それを渡します。

- 行をクリックすると、そのサブエージェントの会話が開きます。ワークスペースパネルと `@` のファイル検索には、それを開始したチャットの作業フォルダが表示されます。SmartBar と Dynamic Island では、その作業がその場で開きます。
- サブエージェントの会話に入力すると、話しかけられます。そこで答え、質問もでき、その会話で承認を求め、同じフォルダで作業を続けます。それを開始したエージェントは、あなたに答えている間は待機し、そのあと最新の回答を確認します。すでに終了したサブエージェントへのメッセージは、同じフォルダで別のサブエージェントがファイルを変更している間でも、すぐに再開されます。
- サブエージェントの会話では、各メッセージに、送信したエージェントが表示されます。親のエージェントからのメッセージには、実行中のタスクを方向づけたのか、待機したのか、中断したのか、新しいターンを開始したのかが表示されます。
- チャットの詳細にある **系譜** に、サブエージェントのツリー全体が、3 階層まで表示されます。コーディングエージェントのチャットでは、それを開始した Enconvo のチャットが表示されます。
- チャットウィンドウのサイドバーでは、チャットのサブエージェントがその下に一覧表示され、チャットの行のボタンで、一覧を折りたためます。

### サブエージェントのロール

すべてのサブエージェントは、ロールから始まります。

| ロール | 内容 |
| --- | --- |
| **デフォルト** | それを開始したエージェントとして、同じ指示、ツール、モデルで動作します |
| **Explorer** | ファイルの読み取り、検索、アプリの確認のみを行います。権限チップの設定にかかわらず、編集、何かを変更するコマンドの実行、オンラインでの操作はできません |
| **自分のエージェントの 1 つ** | そのエージェントとして、独自の指示、ツール、モデルで、それを開始したチャットと同じ作業フォルダで実行されます |
| **プロジェクトのヘルパー** | プロジェクトが、作業フォルダ、またはリポジトリのルートまでの上位のフォルダにある `.claude/agents`、`.codex/agents`、`.enconvo/agents` で定義します。それを開始したエージェントとして、ヘルパー自身の指示に従って動作します。ファイルに記載されたツールだけを使い、ファイルで指定されている場合は読み取りのみを行い、モデルプロバイダーが提供している場合はヘルパーのモデルを使います |
| **自分のヘルパー** | ホームフォルダの `~/.enconvo/agents`、`~/.claude/agents`、`~/.codex/agents` で定義し、すべてのチャットで使えます。プロジェクトのヘルパーと同じように動作します |

自分で選ぶには、エージェントモードのチャットで `@` を入力し、**サブエージェント** グループから選びます。このグループには、ヘルパー、**Explorer**、汎用の **サブエージェント** が一覧表示されます。エージェントは、そのメッセージのためにそのサブエージェントを起動し、タスクを書いて渡し、報告が戻ってから回答します。あなたのエージェントは、メニューのエージェントのグループに残ります。

各エージェントの設定に、わかりやすい説明を書いてください。作業を分割するエージェントは、その説明を読んで、タスクにどれが合うかを判断します。自分のエージェントやコーディングエージェントに、独自の推論の強度を持つチームメイトとしてタスクを渡すには、[エージェントオーケストレーター](/ja/ai/agent-orchestrator)を参照してください。

### プロジェクトのヘルパー

プロジェクトのヘルパーと自分のヘルパーは、Claude Code のサブエージェントや Codex のエージェントロールと同じファイルを使うため、すでにそれがあるリポジトリやホームフォルダでは、追加の設定は不要です。

- Claude Code のファイル（frontmatter に `name` と `description` を持つ Markdown）は、`permissionMode: plan` を設定している場合や、`Read`、`Grep`、`Glob` などの読み取りツールだけを列挙している場合、読み取り専用になります。
- Codex のファイル（`description` と `developer_instructions` を持つ TOML）は、`sandbox_mode = "read-only"` で読み取り専用になります。
- プロバイダーがヘルパーのモデルを提供していない場合、ヘルパーは代わりにチャットのモデルを使います。

Claude Code のファイルの `tools` と `disallowedTools` が、エージェントのどのツールをヘルパーが使えるかを決めます。Enconvo は、各名前を自身のツールに対応付けます。

| ヘルパーのファイル内 | ヘルパーができること |
|---|---|
| `Read`, `Grep`, `Glob`, `LS` | ファイルの読み取りと検索 |
| `Edit`, `MultiEdit`, `Write` | ファイルの編集と作成 |
| `Bash` | 任意のシェルコマンドの実行 |
| `Bash(git diff:*)` | `git diff` で始まるコマンドのみの実行 |
| `WebSearch`, `WebFetch` | Web の検索と Web ページの読み取り |
| `mcp__github__get_issue`, `mcp__github` | 接続済みの MCP サーバーの 1 つのツール、またはすべてのツールの使用 |

`tools` の行がない場合、ヘルパーは、`disallowedTools` に挙げられたもの以外のすべてのツールを持ちます。一覧にない呼び出しは実行されず、ヘルパーには、使えるツールが伝えられます。すべてのヘルパーは、引き続きスキルを読み込んだり、あなたに質問したりできます。`.enconvo/agents` のファイルでは、`browser-use/*` のように、Enconvo のツールを API パスで列挙することもできます。

Claude Code のファイルのスキル、MCP サーバー、ターン数の制限、バックグラウンド、ワークツリーの設定も有効になります。

## エージェントにアクセスする方法

- [チャットウィンドウ](/ja/ai/chat)、[SmartBar](/ja/features/smartbar)、[アプリのサイドバー](/ja/features/app-sidebar)、[Dynamic Island](/ja/features/dynamic-island) でチャットします。
- **音声コマンド** を設定して、選んだエージェントに音声でリクエストを送ります。[音声入力](/ja/features/dictation)を参照してください。
- [Live Talk](/ja/features/live-voice) で話したり、[アバター](/ja/features/avatar)でデスクトップキャラクターを与えたりします。
- [メッセージングチャネル](/ja/integrations/messaging)でメッセージングアプリを接続します。
- [予約タスク](/ja/workflows/scheduled-jobs)であとで実行します。
- リンク、ターミナルコマンド、API 呼び出しで、Enconvo の外から実行します。[リンク、CLI、API](#リンク、cli、api)を参照してください。

### リンク、CLI、API

**設定 → エージェント一覧** でエージェントを開きます。**利用元** の下の **リンク、CLI、API** の行に **表示** ボタンがあります。クリックすると、このエージェントをあなたのテキストとファイルで実行する Deeplink、ターミナルコマンド、API 呼び出しが、それぞれコピーできる状態で表示されます。AI コマンドにも、同じ行があります。

## デフォルトと継続性

複数のチャットやチャネルが使っているエージェントを変更する前に、[モデルのデフォルト](/ja/ai/model-selection-guide)を確認してください。エージェントが再利用すべき情報には[メモリ](/ja/ai/memory)を設定し、すべてを指示に詰め込まずに、ドキュメントはナレッジベースに保存してください。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| リクエストが失敗する | まず、ツールのエラーを読むか、不足している入力を探してください。 |
| モデルとツールのどちらが原因か分からない | 任意のツールをオフにして同じリクエストを試し、そのあと、ツールを 1 つずつ戻してください。 |
| 操作によってファイルや外部サービスが変更される | 承認する前に、対象と影響を確認してください。 |
| エージェントが、ツールやスキルがないと言う | **ツールとスキル** で、**選んだものだけ** に設定されていないか、組み込みツールがオフになっていないかを確認してください。 |
| 返信のグラフやカードが多すぎる、または時間がかかりすぎる | **スタイル** で **インテリジェント UI** を **厳選** に設定するか、1 つのチャットだけなら **+** メニューの **スタイルを使用** で設定してください。 |

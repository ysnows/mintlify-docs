---
title: "プラグイン"
description: "Enconvo に新しいコマンド、ツール、連携を追加するプラグインを、探してインストールし、管理します。"
---

プラグインは、Enconvo にコマンド、プロバイダ、ツール、API ルートを追加します。**設定 → プラグイン** を開くと、カタログを検索し、必要なものをインストールして、すでに持っているものを管理できます。

## プラグインを探してインストールする

<Steps>
  <Step title="プラグインを開く">
    **設定 → プラグイン** を開きます。**⌘K** を押すと、検索ボックスに移動します。
  </Step>
  <Step title="検索する">
    やりたいことまたはプラグインの名前で検索します。現在のタブに一致するものがない場合は、別のタブの結果が提案されます。
  </Step>
  <Step title="ページを開く">
    プラグインをクリックすると、説明、含まれるもの、必要なものを確認できます。
  </Step>
  <Step title="インストールして設定する">
    まだインストールされていない場合は **インストール** をクリックします。続いて、求められるプロバイダの認証情報やコマンドの設定を追加します。
  </Step>
  <Step title="使う">
    **今すぐ試す** をクリックするか、SmartBar からそのコマンドを実行するか、使わせたいエージェントにそのツールを有効にします。
  </Step>
</Steps>

プラグインのページには、そのコマンドと設定が一覧表示されます。Enconvo 内の別の場所からコマンドの設定を開くと、そのプラグイン内の該当するコマンドに移動します。

[メール](/ja/integrations/email) のように、チャットウィンドウにビューを持つプラグインでは、ページに **開く** ボタンがあり、そのビューを開きます。メールボックスの追加など、その中にある操作にワンクリックでアクセスできます。複数のビューを持つプラグインでは、代わりに **開く** メニューが表示されます。

## プラグインページ

| タブ | 表示内容 |
| --- | --- |
| **Enconvo** | カテゴリ別のカタログ。上部の **インストール済み** には、接続したコネクタと、インストールまたは作成したプラグインが一覧表示されます。**新着** には新しい項目が表示されます。 |
| **組み込み** | Enconvo に付属するプラグイン。**検索** には SmartBar から検索するリストが、**操作** にはコンピューター操作とブラウザを使用が含まれます。 |
| **Mac アプリ** | エージェントが使える、この Mac 上のアプリ (カレンダー、メール、メモなど)。接続時に求められるのはアカウントではなく、macOS の許可です。[Apple アプリ](/ja/integrations/apple-ecosystem) を参照してください。 |
| **PopBar** | [PopBar](/ja/features/popbar) にボタンを追加する、PopClip 互換の拡張機能。 |
| **個人** | 自分で作成または読み込んだプラグイン、および Enconvo ストアに公開したプラグイン。 |

カタログにないプラグインを取り込むには、**プラグインを作成** または **追加** メニューを使います。

| オプション | 動作 |
| --- | --- |
| **プラグインを作成** | 必要なことを説明すると、エージェントがプラグインを作成し、テストして、インストールします。 |
| **プラグインのアーカイブをアップロード…** | `.enconvo` ファイル、または Claude Code や Codex のプラグインの `.zip` をインストールします。 |
| **GitHub から追加…** | プラグインのリポジトリ、または Claude Code や Codex のマーケットプレイスからインストールします。 |
| **MCP サーバーを追加…** | [MCP サーバー](/ja/features/mcp) を開きます。 |
| **PopBar 拡張機能を追加…** と **PopClip から読み込む…** | PopClip の拡張機能を PopBar に追加します。 |
| **新規スキル…** | [スキル](/ja/configuration/skills) を開きます。 |

ストアのプラグインの中には、サービス全体のツールとガイダンスを提供するものもあります。

- **Shopify** は、Shopify の公式 CLI を使ってエージェントに Shopify ストアを管理させます。変更を行う前に、その内容が毎回表示されます。複数のストアにまたがって使えます。ストアを指定しない場合、エージェントはどのストアかを尋ね、表示するすべての変更にストア名を明記し、複数のストアを対象とする変更はストアごとに 1 回ずつ実行します。
- **Expo** は、以前の読み取り専用の Expo コネクタに代わって、Expo チームの公式スキルと Expo MCP サーバーを提供します。エージェントは、Expo と React Native のアプリのビルド、アップグレード、公開を行い、EAS のビルド、ログ、クラッシュ、レビューを読み取り、ビルドと申請は、それぞれ承認した後にのみ開始します。すでに行った Expo のサインインは引き継がれます。

**Obsidian**、**Tailscale**、**Cloudflare** もプラグインストアのプラグインです。プラグインページからインストールしてください。すでに持っているコピーは、そのまま動作し、自動で更新されます。エージェントは、Obsidian、Tailscale、Cloudflare、Shopify のプラグインのうち、どれをインストールしているかを最初から把握しています。

[組み込みコマンドカタログ](/ja/extensions/built-in-extensions) には、ドキュメント化されているコマンドファミリーが一覧表示されています。お使いのビルドのストアの項目やインストール済みのプラグインは、これと異なる場合があります。

## コマンド、プロバイダ、ツール

- **コマンド** は、実行するアクションです。
- **プロバイダ** は、モデルや音声などの機能を提供します。
- **ツール** は、エージェントが呼び出せるアクションです。

プラグインをインストールしても、そのプロバイダがデフォルトになるとは限らず、すべてのエージェントですべてのツールがオンになるとも限りません。

SmartBar では、コマンドピッカー (デフォルトは `@`) を使うか、コマンドのタイトルを検索します。`/` のアクションメニューは別の機能です。プラグイン名のプレフィックスではありません。

## コネクタで複数のアカウントを使う

Notion、Webflow、Linear など、Mac 上でサインインするコネクタは、複数のアカウントを保持できます。

- コネクタのページで **別のアカウントを接続** を選択して追加します。**接続済みのアカウント** にすべてが一覧表示されます。
- エージェントが送信や作成に使うアカウントで **デフォルトにする** を選択します。エージェントはすべてのアカウントから読み取ります。
- 「仕事用のアドレスから送って」のように、依頼でアカウントを指定すると、エージェントはそのアカウントを使います。
- **接続を解除** は 1 つのアカウントを削除し、**すべてのアカウントの接続を解除** はすべてを削除します。

クライアントのワークスペースでは、各コネクタが独自のデフォルトアカウントを保持し、**デフォルト** とワークスペース名が表示されます。別のアカウントを指定しない限り、エージェントはそこでそのクライアントのアカウントを使います。

## オフにする、更新する、削除する

プラグインのページでは次の操作ができます。

- スイッチでプラグインをオン・オフします。オフの間は、エージェントがそれを見つけたり使ったりできず、SmartBar にも表示されず、`@` で指定することもできません。設定は保持されます。
- **⋯** メニューには、**設定**、**アップデートを確認**、**アンインストール** があります。Enconvo に付属するプラグインはアンインストールできません。

プラグインをアンインストールする前に、それを使っているエージェント、ワークフロー、カスタムコマンドを確認してください。コマンドをリセットすると、その設定が復元されます。共有プロバイダをリセットすると、ほかの機能が使う認証情報も変更される場合があります。[認証情報](/ja/configuration/credentials) を参照してください。

## プラグインを共有する

自分で作成したプラグイン、またはフォルダがこの Mac にあるプラグインは、リンクを渡した相手がインストールできるように共有できます。

1. プラグインのページで **共有…** をクリックします。求められた場合は、Enconvo アカウントにサインインします。
2. **インストールできる人** で、**リンクを知っている全員** または **プラグインストア** を選びます。
3. **公開** をクリックし、**リンクをコピー** をクリックして、リンクを送ります。

Enconvo は、リンクからインストールされる前に、各バージョンを確認し、審査します。リンクは enconvo.com のプラグインのページを開きます。インストールした人はそれぞれ自分のコピーを持ち、そのデータ、あなたのキー、サインインは Mac に残ります。

共有したプラグインを変更するには、もう一度 **共有…** をクリックします。新しいバージョンを送る、**インストールできる人** を変更する、**共有を停止** をクリックする、のいずれかを行えます。リンクは使えなくなりますが、プラグインをインストールした人は自分のコピーを保持します。審査でバージョンが却下された場合は、**共有…** に理由が表示され、**チャットで修正** が提案されます。[スペース](/ja/features/spaces) を共有する方法は、[スペースを共有する](/ja/features/spaces) を参照してください。

## 自分で作る

[拡張機能の開発](/ja/extensions/developing) で、TypeScript SDK と CLI を使います。CLI では、ビルド、インストール、スキーマ生成、公開が `enconvo plugin` にまとめられています。公開すると、自分の開発環境の外でもプラグインを使えるようになります。

Enconvo は、Codex、Claude Code、およびポータブルなプラグインもインストールできます。[Plugin Formats](/extensions/plugin-formats) と [プラグインのインストール](/ja/extensions/installing-plugins) を参照してください。

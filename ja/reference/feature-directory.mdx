これらのドキュメントに含まれるすべてのガイドを、サイドバーと同じグループ構成でまとめています。目的に合う項目を見つけてガイドを開いてください。個別の組み込みコマンドについては[コマンドカタログ](/ja/extensions/built-in-extensions)、モデルや音声などのサービスについては[プロバイダーカタログ](/ja/providers/catalog)をご覧ください。

一部の機能は Beta チャンネルに先行して提供されます。お使いのアプリにない機能がガイドに記載されている場合は、[アップデートチャンネル](/ja/configuration/updates)をご確認ください。

## どこからでも AI に質問

| ガイド | できること |
| --- | --- |
| [SmartBar](/ja/features/smartbar) | 1 つのショートカットでどのアプリからでもエージェントに質問したりコマンドを実行したりでき、入力しながら計算・変換・天気やフライトの検索も行えます。 |
| [チャットウィンドウ](/ja/ai/chat) | エージェントと長い会話を続けたり、ファイルやコンテキストを追加したり、`/goal` で目標に向けて自律作業させたり、一時チャットで質問したり、プロンプト拡張で依頼を書き直したり、複数のチャットを一括操作したりできます。 |
| [スペース](/ja/features/spaces) | トラッカーやライブボードなど自分専用のページをエージェントに作ってもらい、チャットウィンドウのサイドバーやスマートフォンに保存しておけます。 |
| [Dynamic Island](/ja/features/dynamic-island) | 画面上部のコンパクトなパネルから、エージェントへの質問、ショートカットの実行、ホームでの計算、実行中タスクの確認・承認・既読化を行えます。 |
| [PopBar](/ja/features/popbar) | テキストを選択した場所に表示されるツールバーから、選択範囲の説明、翻訳、修正、検索、読み上げを行います。 |
| [クリップボード履歴・ブックマーク・ファイル検索](/ja/features/clipboard-history) | ホットキーや SmartBar から、以前にコピーした内容の貼り付け、ブラウザブックマークの起動、Mac 内のファイル検索を行います。 |
| [アプリのサイドバー](/ja/features/app-sidebar) | 作業中のアプリやウェブサイトの横にサイドバーを開いてエージェントとチャットし、返信やコミットメッセージをアプリに挿入したり、Finder のファイルに対してファイルジョブを実行したりできます。 |
| [デスクトップペット](/ja/features/pet) | デスクトップにアニメーション付きのマスコットを常駐させ、エージェントの作業状況を表示したり、クリックで Enconvo を開いたりできます。 |
| [ウィンドウ管理](/ja/features/window-management) | タスクに合った Enconvo ウィンドウを選び、それぞれを開くショートカットを設定し、結果を前面に保ち、ウィンドウを閉じた後も Dock にアイコンを残さないようにします。 |

このドキュメントのすべてのガイドを、サイドバーと同じ分類でまとめています。やりたいことを探して、そのガイドを開いてください。個々の組み込みコマンドについては、[コマンドカタログ](/ja/extensions/built-in-extensions)を参照してください。モデル、音声、その他のサービスについては、[プロバイダーカタログ](/ja/providers/catalog)を参照してください。

一部の機能は、まずベータ版チャンネルに提供されます。ガイドに書かれている内容がお使いのアプリにない場合は、[更新チャンネル](/ja/configuration/updates)を確認してください。

## どこでも AI に質問する

| ガイド | できること |
| --- | --- |
| [SmartBar](/ja/features/smartbar) | どのアプリからでも、ショートカット 1 つでエージェントに質問したりコマンドを実行したりできます。入力しながら、計算、単位の変換、天気やフライトの検索もできます。 |
| [チャットウィンドウ](/ja/ai/chat) | エージェントとじっくり会話し、ファイルやコンテキストを追加し、/goal でエージェントが目標に向かって作業し続けるようにし、一時チャットで質問し、プロンプトを改善でリクエストを書き直し、複数のチャットを同時に操作します。 |
| [スペース](/ja/features/spaces) | トラッカーやライブボードなど、自分専用のページをエージェントに作ってもらい、チャットウィンドウのサイドバーとスマートフォンに置いておきます。 |
| [Dynamic Island](/ja/features/dynamic-island) | 画面上部のコンパクトなパネルから、エージェントに質問し、ショートカットを実行し、ホームで計算し、実行中のタスクを確認、承認、既読にします。 |
| [PopBar](/ja/features/popbar) | テキストを選択した場所に表示されるツールバーから、選択したテキストの説明、翻訳、修正、検索、読み上げができます。 |
| [クリップボード履歴、ブックマーク、ファイル検索](/ja/features/clipboard-history) | 以前コピーしたものを貼り付けたり、ブラウザのブックマークを開いたり、Mac 上のファイルを探したりできます。ホットキーまたは SmartBar から使えます。 |
| [アプリのサイドバー](/ja/features/app-sidebar) | 作業中のアプリやウェブサイトの横にあるサイドバーでエージェントとチャットし、返信やコミットメッセージをアプリに挿入し、Finder のファイルに対してファイルジョブを実行します。 |
| [デスクトップペット](/ja/features/pet) | エージェントの動きを表示し、クリックすると Enconvo を開く、アニメーションのコンパニオンをデスクトップに置きます。 |
| [ウィンドウ管理](/ja/features/window-management) | 作業に合った Enconvo のウィンドウを選び、それぞれを開くショートカットを設定し、結果を表示したままにし、ウィンドウを閉じたあと Enconvo を Dock に表示させないようにします。 |

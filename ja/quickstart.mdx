このページでは、ダウンロードから最初の回答までを案内します。アプリをインストールし、Enconvo が AI に接続する方法を選んで、SmartBar から質問します。

<Steps>
  <Step title="Enconvo をインストールして開く">
    [enconvo.com](https://www.enconvo.com) から Enconvo をダウンロードし、DMG を開いて **Enconvo** を **アプリ** にドラッグします。そこから開いてください。Enconvo には macOS 14 以降が必要です。詳しくは[インストール](/ja/installation)をご覧ください。
  </Step>
  <Step title="Enconvo が AI に接続する方法を選ぶ">
    最も簡単な方法は、Enconvo アカウントにログインすることです。デフォルトのモデルである[自動ルーティング](/ja/providers/auto-route)が、[Enconvo Cloud](/ja/providers/enconvo) で回答します。いつでも切り替えられます。

    | オプション | 方法 |
    | --- | --- |
    | Enconvo Cloud | Enconvo アカウントにログインします。 |
    | すでに契約しているプラン | [ChatGPT](/ja/providers/openai_subscription)、[Claude](/ja/providers/anthropic_subscription)、[Grok](/ja/providers/xai)、[GitHub Copilot](/ja/providers/github-copilot) などでログインします。 |
    | ご自身の API キー | **設定 → AI モデル** を開き、プロバイダーを選んでキーを貼り付けます。 |
    | Mac 上のモデル | [ローカルモデル](/ja/ai/local-llm)を設定します。 |
  </Step>
  <Step title="最初の質問をする">
    **⌥Space** を押して SmartBar を開き、質問を入力します。たとえば、充実した朝を過ごすための 3 項目のチェックリストを頼んでみましょう。Return を押すと回答が表示されます。
  </Step>
  <Step title="自分のテキストで試す">
    任意のアプリで段落を選択します。隣に [PopBar](/ja/features/popbar) が表示されたら、**説明** または **翻訳** をクリックします。
  </Step>
</Steps>

<Tip>
SmartBar、チャットウィンドウ、音声入力、[下書き](/ja/features/dictation)、音声コマンド、PopBar、アプリのサイドバーを案内付きで体験するには、**設定 → 一般** を開き、**ガイドツアー** の横にある **ツアーを開始** をクリックします。ツアーは Enconvo の表示言語で進み、約 3 分で終わります。
</Tip>

Enconvo は起動時に macOS の権限を求めません。マイクや画面収録など、権限が必要な機能を初めて使うときに、Enconvo がその機能名を示して確認します。各権限で何が使えるようになるかは、[権限](/ja/configuration/permissions)をご覧ください。

## 何も起こらない場合

| 問題 | 対処方法 |
| --- | --- |
| **⌥Space** で SmartBar が開かない | **設定 → SmartBar** でホットキーを確認するか、メニューバーの Enconvo アイコンを使ってください。 |
| SmartBar は開くが回答が返ってこない | Enconvo アカウントにログインするか、**設定 → AI モデル** でプロバイダーを確認してください。 |
| PopBar が表示されない | アクセシビリティの権限を許可してください。[権限](/ja/configuration/permissions)をご覧ください。 |

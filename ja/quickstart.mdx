このページでは、ダウンロードから最初の回答を得るまでの流れを案内します。アプリをインストールし、Enconvo の AI 接続方法を選んで、SmartBar から質問してみましょう。

<Steps>
  <Step title="Enconvo をインストールして開く">
    [enconvo.com](https://www.enconvo.com) から Enconvo をダウンロードし、DMG を開いて **Enconvo** を **アプリケーション** フォルダへドラッグし、そこから起動します。Enconvo には macOS 14 以降が必要です。詳しくは[インストール](/ja/installation)を参照してください。
  </Step>
  <Step title="AI の接続方法を選ぶ">
    もっとも簡単なのは Enconvo アカウントへサインインする方法です。デフォルトモデルの [Auto Route](/ja/providers/auto-route) が [Enconvo Cloud](/ja/providers/enconvo) 上で回答します。接続方法はいつでも切り替えられます。

    | 選択肢 | 手順 |
    | --- | --- |
    | Enconvo Cloud | Enconvo アカウントにサインインします。 |
    | すでに契約しているプラン | [ChatGPT](/ja/providers/openai_subscription)、[Claude](/ja/providers/anthropic_subscription)、[Grok](/ja/providers/xai)、[GitHub Copilot](/ja/providers/github-copilot) などでサインインします。 |
    | 自分の API キー | **設定 → AI モデル** を開き、プロバイダーを選んでキーを貼り付けます。 |
    | Mac 上のモデル | [ローカルモデル](/ja/ai/local-llm)を設定します。 |
  </Step>
  <Step title="最初の質問をする">
    **⌥Space** を押して SmartBar を開き、「生産的な朝のための 3 項目のチェックリストを作って」などの質問を入力して Return を押すと、回答が表示されます。
  </Step>
  <Step title="手元のテキストで試す">
    任意のアプリで段落を 1 つ選択します。横に [PopBar](/ja/features/popbar) が表示されたら、**説明** または **翻訳** をクリックしてみてください。
  </Step>
</Steps>

<Tip>
SmartBar、チャットウィンドウ、音声入力、[音声下書き](/ja/features/dictation)、音声コマンド、PopBar、アプリのサイドバーを順番に体験できるガイドを利用するには、**設定 → 一般** を開き、**ガイドツアー** の横にある **ツアーを開始** をクリックします。ツアーは Enconvo の表示言語で進行し、所要時間は約 3 分です。
</Tip>

Enconvo は起動時に macOS の権限を一斉に求めることはありません。マイクや画面収録など、権限が必要な機能を初めて使うときに、その機能名を明示して許可を求めます。各権限の用途は[権限](/ja/configuration/permissions)を参照してください。

## 何も起きない場合

| 問題 | 対処方法 |
| --- | --- |
| **⌥Space** で SmartBar が開かない | **設定 → SmartBar** でホットキーを確認するか、メニューバーの Enconvo アイコンから開いてください。 |
| SmartBar は開くが回答が返らない | Enconvo アカウントにサインインするか、**設定 → AI モデル** でプロバイダーの設定を確認してください。 |
| PopBar が表示されない | アクセシビリティ権限を許可してください。[権限](/ja/configuration/permissions)を参照してください。 |

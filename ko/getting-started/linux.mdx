<Note>
Linux용 Enconvo는 베타이며 **베타** 업데이트 채널로 제공됩니다. 일상적으로 쓸 수 있도록 만들었지만, 빌드마다 내용이 바뀔 수 있습니다. 문제가 생기면 [피드백 사이트](https://feedback.enconvo.com)에 알려 주세요.
</Note>

**현재 베타: 2.5.13 베타 3**(`2.5.13-beta-3`). 사용 중인 버전은 **설정 → 일반 → 업데이트**에서 확인할 수 있습니다. 서버에서는 `enconvo update --check`로 출력됩니다.

## 실행 방식 선택하기

| 사용 환경 | 제공되는 것 | 시작하기 |
| --- | --- | --- |
| Linux 데스크톱(GNOME, KDE 등) | 채팅 창과 설정 창이 있는 Enconvo 앱 | [데스크톱에 설치하기](#데스크톱에-설치하기) |
| 데스크톱이 없는 서버나 클라우드 컴퓨터 | 백그라운드에서 실행되며, 내 컴퓨터의 브라우저에서 사용하는 Enconvo | [서버에 설치하기](#서버에-설치하기) |

## 요구 사항

- **64비트 Intel/AMD(x86-64).** 아직 ARM 빌드는 없습니다.
- **Ubuntu 22.04, Debian 12, RHEL 9, Amazon Linux 2023 또는 그 이후 버전.** Rocky Linux와 AlmaLinux 9는 RHEL 9로 봅니다. 이보다 오래된 시스템은 C 라이브러리가 너무 오래되어 Enconvo를 실행할 수 없습니다.
- **메모리:** 최소 2GB의 여유를 권장하며, 에이전트가 브라우저를 사용한다면 4GB를 권장합니다.
- **일반 사용자 계정.** 에이전트가 해당 사용자의 권한으로 명령을 실행하므로 Enconvo는 root가 아닌 본인 계정으로 실행하세요. 서버에서는 Enconvo 전용 사용자를 만드세요.

## 베타 다운로드

베타는 세 가지 형태로 제공됩니다. Debian과 Ubuntu용 `.deb`, Fedora, RHEL, Rocky, AlmaLinux, openSUSE용 `.rpm`, 그 밖의 환경을 위한 휴대용 `.tar.gz`입니다. 파일 이름에는 베타 버전 번호가 들어 있습니다. 2.5.13 베타 3의 파일은 다음과 같습니다.

- `enconvo_2.5.13~beta~3_amd64.deb`
- `enconvo-2.5.13~beta~3-1.x86_64.rpm`
- `Enconvo-2.5.13-beta-3-linux-x64.tar.gz`

아래 명령은 최신 베타를 찾아 다운로드합니다.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo_[^"]*\.deb')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Fedora, RHEL, Rocky, AlmaLinux, openSUSE">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo-[^"]*\.rpm')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="휴대용 .tar.gz">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'Enconvo-[^"]*\.tar\.gz')
    curl -fLO "$FEED/$FILE"
    tar xzf "$FILE"
    ```

    `Enconvo`라는 폴더가 풀립니다. 그 폴더에서 실행하고, 이 페이지에서 `enconvo`라고 쓴 곳에는 `./Enconvo/enconvo`를 사용하세요.
  </Tab>
</Tabs>

## 데스크톱에 설치하기

패키지 관리자는 앱 창에 필요한 GTK와 WebKitGTK도 함께 설치합니다.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    sudo apt install ./enconvo_*.deb
    ```
  </Tab>
  <Tab title="Fedora, openSUSE">
    ```bash
    sudo dnf install ./enconvo-*.rpm      # Fedora
    sudo zypper install ./enconvo-*.rpm   # openSUSE
    ```
  </Tab>
  <Tab title="휴대용 .tar.gz">
    배포판에서 GTK 3과 WebKitGTK 4.1을 설치한 다음, 해당 폴더에서 Enconvo를 시작하세요.

    ```bash
    ./Enconvo/enconvo
    ```
  </Tab>
</Tabs>

RHEL 9, Rocky Linux 9, AlmaLinux 9는 앱 창에 필요한 WebKitGTK 4.1을 제공하지 않으므로, 이런 시스템에서는 [서버처럼 Enconvo를 실행](#서버에-설치하기)하세요.

애플리케이션 메뉴에서 **Enconvo**를 열고, 로그인한 다음 [빠른 시작](/ko/quickstart)으로 이어가세요. 데스크톱에 시스템 트레이가 있다면 Enconvo 아이콘이 그곳에 나타납니다.

## 서버에 설치하기

서버에는 데스크톱 라이브러리가 필요하지 않으므로 설치하지 않습니다.

<Steps>
  <Step title="패키지 설치">
    <Tabs>
      <Tab title="Debian, Ubuntu">
        ```bash
        sudo apt install --no-install-recommends ./enconvo_*.deb
        ```
      </Tab>
      <Tab title="Fedora, RHEL, Rocky, AlmaLinux">
        ```bash
        sudo dnf install --setopt=install_weak_deps=False ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="openSUSE">
        ```bash
        sudo zypper install --no-recommends ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="휴대용 .tar.gz">
        설치할 것은 없습니다. 풀어 둔 `Enconvo` 폴더를 사용하세요.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Enconvo를 서비스로 시작">
    ```bash
    enconvo service install --web
    ```

    이제 Enconvo가 백그라운드에서 실행되며, 채팅 창과 설정을 이 컴퓨터에서만 접근할 수 있는 웹사이트(`127.0.0.1:54580`)로 제공합니다. 서버가 부팅되면 다시 시작됩니다. 로그인해 있는 동안에만 실행된다는 메시지가 나오면, 함께 출력된 `sudo loginctl enable-linger` 명령을 실행하세요.
  </Step>
  <Step title="로그인">
    ```bash
    enconvo login
    ```

    Enconvo가 짧은 코드를 출력합니다. 휴대폰이나 컴퓨터에서 `enconvo.com/device`를 열고, 페이지에 내 계정 이름이 표시되는지 확인한 다음 10분 안에 코드를 승인하세요.
  </Step>
  <Step title="내 컴퓨터에서 Enconvo 열기">
    내 컴퓨터에서 아래 명령을 실행하고 그대로 실행 상태로 두세요.

    ```bash
    ssh -N -L 54580:127.0.0.1:54580 you@your-server
    ```

    브라우저에서 [http://localhost:54580](http://localhost:54580)을 여세요. 데스크톱 앱과 같은 채팅 창과 설정이 나타납니다.
  </Step>
</Steps>

휴대폰의 Enconvo 앱에서 이 서버를 사용하려면 `enconvo companion pair --phone`을 실행하고 출력된 코드를 스캔하세요. [휴대폰과 페어링](/ko/integrations/pair-your-phone)을 참고하세요.

### SSH 터널 없이 접속하기

터널은 서버의 어떤 것도 네트워크에 열지 않으므로 가장 안전한 방법입니다. 웹사이트는 내 계정의 모든 권한을 가지며 서버의 파일에 접근할 수 있으므로, 웹사이트를 열 수 있는 사람은 누구나 둘 다 사용할 수 있습니다.

비공개 네트워크나 VPN 등에서 다른 컴퓨터가 직접 열 수 있게 하려면 다음을 실행하세요.

```bash
enconvo service install --web 0.0.0.0:54580
enconvo service url
```

`enconvo service url`은 연결 토큰이 포함된 주소를 출력합니다. 이 주소는 비공개로 유지하고, 이 포트를 인터넷에 노출하지 마세요.

공개 주소를 쓰려면 Enconvo 앞에 HTTPS를 지원하는 리버스 프록시를 두고, Enconvo에 서비스할 주소를 알려 주세요.

```bash
enconvo service install --web --web-url https://enconvo.example.com
```

HTTPS를 쓰면 웹사이트를 휴대폰이나 컴퓨터에 앱으로 설치할 수도 있습니다.

## 서버에서 브라우저 사용 기능 쓰기

에이전트는 화면이 없는 서버에서도 탐색할 수 있습니다. 에이전트가 처음 브라우저가 필요할 때 Enconvo가 Enconvo Browser라는 자체 헤드리스 브라우저를 시작합니다. 먼저 Chromium을 설치하세요.

<Tabs>
  <Tab title="Debian">
    ```bash
    sudo apt install chromium
    ```
  </Tab>
  <Tab title="Ubuntu">
    ```bash
    sudo snap install chromium
    ```
  </Tab>
  <Tab title="Fedora">
    ```bash
    sudo dnf install chromium
    ```
  </Tab>
  <Tab title="RHEL, Rocky, AlmaLinux">
    Chromium은 [EPEL](https://docs.fedoraproject.org/en-US/epel/)에서 제공됩니다.

    ```bash
    sudo dnf install epel-release
    sudo dnf install chromium
    ```
  </Tab>
</Tabs>

그런 다음 에이전트에게 요청하세요. 예를 들어 “news.ycombinator.com을 열고 맨 위 기사가 무엇인지 알려 주세요.”라고 말해 보세요.

Enconvo Browser는 자체 로그인 정보를 유지합니다. 로그인이나 확인 절차처럼 사이트에서 사용자가 직접 해야 할 일이 있으면, 에이전트가 브라우저에 페이지의 실시간 화면을 보여 주며, 그곳에서 직접 클릭하고 입력할 수 있습니다. 30분 동안 사용하지 않으면 닫히고, 다음에 열 때 탭을 복원합니다.

에이전트가 `localhost`에서 시작한 개발 서버처럼 서버에서만 접근할 수 있는 페이지도 채팅 옆에 실시간 화면으로 열리므로, SSH 터널을 통해서도 작동합니다.

## 환경별 지원 기능

| 기능 | Linux 데스크톱 | 서버 |
| --- | --- | --- |
| 채팅 창, 설정 | 예 | 예, 브라우저에서 |
| 에이전트, 도구, 파일, 문서, 아티팩트 | 예 | 예 |
| 브라우저 사용 | 예 | 예, Chromium 필요 |
| 지식 베이스, 메모리, 예약 작업, 워크플로 | 예 | 예 |
| Enconvo Cloud 모델, 웹 검색, OCR, 이미지 생성, 음성 | 예 | 예 |
| 컴퓨터 사용 | 예 | 아니요: 제어할 화면이 없습니다 |
| 전역 단축키, 받아쓰기, 음성 메모, 녹음, 화면 낙서, Appshots, 알림 | 예 | 아니요: 데스크톱이 필요합니다 |

Wayland에서는 앱에 전역 단축키를 제공하는 데스크톱 환경이어야 전역 단축키를 쓸 수 있습니다.

SmartBar, PopBar, Dynamic Island, 음성 명령, 아바타, 데스크톱 펫, 앱 사이드바, Live Talk, 자막은 Linux에서 지원되지 않습니다. SmartBar, PopBar, Dynamic Island, 음성 명령, 아바타, 데스크톱 펫은 [Windows 베타](/ko/getting-started/windows)에서 사용할 수 있습니다.

로컬 채팅 모델은 glibc 2.38 이상인 시스템에서 GGUF 파일로 실행됩니다. MLX 모델은 Mac이 필요합니다.

## Linux에서의 내 계정

내 계정에서 [iPhone 앱](/ko/integrations/iphone-app)도 사용한다면, 기본 채팅, 음성, 이미지 선택이 계정을 따라 이 컴퓨터에도 적용됩니다. 내 API 키로 실행되는 제공업체는 키가 복사되지 않으므로 따라오지 않습니다. 이 컴퓨터에서도 같은 제공업체를 쓰려면 이 컴퓨터의 **설정**에서 키를 추가하세요.

서버의 시계가 브라우저와 다른 시간대라면, Enconvo가 시간과 [예약 작업](/ko/workflows/scheduled-jobs)에 내 시간대를 사용할지 물어봅니다.

## 업데이트

베타 빌드는 베타 채널에 머뭅니다. 바꾸려면 **설정 → 일반**을 열고 **업데이트 채널**을 설정하세요. [업데이트](/ko/configuration/updates)를 참고하세요.

데스크톱에서는 채팅 창에 **업데이트**가 나타나면 클릭하세요. 휴대용 빌드는 스스로 교체됩니다. `.deb`나 `.rpm`은 Enconvo가 새 패키지를 다운로드 폴더에 받고, [데스크톱에 설치하기](#데스크톱에-설치하기)처럼 직접 설치하면 됩니다.

서버에서는 다음을 사용하세요.

```bash
enconvo update --check   # is there a newer version?
enconvo update           # download and check it
```

`.deb`나 `.rpm`을 설치했다면 `enconvo update`가 새 패키지를 다운로드하고 root로 설치하는 명령을 출력합니다. 그 명령을 실행한 다음 서비스를 다시 시작하세요.

```bash
systemctl --user restart enconvo
```

휴대용 `.tar.gz`를 사용한다면 `enconvo update`가 폴더를 교체하고 서비스를 대신 다시 시작합니다. 새 버전이 시작되지 않으면 이전 버전을 되돌려 놓습니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| `enconvo`가 데스크톱 앱에 GTK 3과 WebKitGTK 4.1이 필요하다고 알립니다 | 데스크톱에서는 안내된 패키지를 설치하세요. 서버나 RHEL 9에서는 `enconvo service install --web`을 사용하세요 |
| `GLIBC_2.34 not found` 또는 지원되는 시스템 목록이 담긴 메시지 | 시스템이 너무 오래되었습니다. [요구 사항](#요구-사항)에 있는 시스템을 사용하세요 |
| `dnf`가 `nothing provides libwebkit2gtk-4.1.so.0`이라고 표시합니다 | 오래된 패키지입니다. [서버 명령](#서버에-설치하기)으로 현재 베타를 설치하세요 |
| 서버에서 로그아웃하면 Enconvo가 멈추거나, 재부팅 후 시작되지 않습니다 | `sudo loginctl enable-linger "$USER"`를 실행하세요 |
| `localhost:54580`이 열리지 않습니다 | `ssh -L` 명령이 계속 실행 중인지, `systemctl --user status enconvo`가 active로 표시되는지 확인하세요 |
| 웹사이트가 토큰을 요구합니다 | 서버에서 `enconvo service url`을 실행하고 출력된 주소를 여세요 |
| 에이전트가 Enconvo Browser를 시작할 수 없다고 합니다 | [Chromium을 설치](#서버에서-브라우저-사용-기능-쓰기)하세요. Google Chrome 137 이상은 Enconvo Browser에 필요한 확장 프로그램을 불러올 수 없습니다 |
| 코드가 만료되었습니다 | `enconvo login`을 다시 실행해 새 코드를 받으세요 |

서버에서 Enconvo의 로그를 읽으려면 다음을 실행하세요.

```bash
journalctl --user -u enconvo -n 100
```

## Enconvo 제거

```bash
enconvo service uninstall
sudo apt remove enconvo     # Debian, Ubuntu
sudo dnf remove enconvo     # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper remove enconvo  # openSUSE
```

설정과 채팅은 `~/.config/enconvo`에 남습니다. 이 폴더를 삭제하면 함께 지워집니다.

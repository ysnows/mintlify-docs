<Note>
Linux용 Enconvo는 베타이며 **베타** 업데이트 채널로 배포됩니다. 일상 사용을 위해 만들어졌지만 빌드 사이에 바뀔 수 있습니다. 문제가 생기면 [피드백 사이트](https://feedback.enconvo.com)에서 알려 주세요.
</Note>

**현재 베타: 2.5.13 Beta 3** (`2.5.13-beta-3`). 가진 버전을 보려면 **설정 → 일반 → 업데이트**를 엽니다. 서버에서는 `enconvo update --check`가 출력합니다.

## 실행 방식 고르기

| 있는 것 | 얻는 것 | 시작 위치 |
| --- | --- | --- |
| Linux 데스크톱(GNOME, KDE 등) | 채팅 창과 설정 창이 있는 Enconvo 앱 | [데스크톱에 설치](/ko/getting-started/linux) |
| 데스크톱이 없는 서버나 클라우드 컴퓨터 | 백그라운드에서 실행되고 본인 컴퓨터의 브라우저에서 쓰는 Enconvo | [서버에 설치](/ko/getting-started/linux) |

## 요구 사항

- **64비트 Intel/AMD(x86-64).** ARM 빌드는 아직 없습니다.
- **Ubuntu 22.04, Debian 12, RHEL 9, Amazon Linux 2023 이상.** Rocky Linux와 AlmaLinux 9는 RHEL 9로 봅니다. 더 오래된 시스템은 Enconvo를 실행할 수 없습니다. C 라이브러리가 너무 오래되었습니다.
- **메모리:** 최소 2GB 여유를 권장하며, 에이전트가 브라우저를 쓰면 4GB입니다.
- **일반 사용자 계정.** root가 아니라 본인으로 Enconvo를 실행하세요. 에이전트가 그 사용자의 권한으로 명령을 실행합니다. 서버에서는 Enconvo 전용 사용자를 만듭니다.

## 베타 다운로드

베타는 세 가지입니다. Debian과 Ubuntu용 `.deb`, Fedora, RHEL, Rocky, AlmaLinux, openSUSE용 `.rpm`, 그 외용 휴대용 `.tar.gz`입니다. 각 파일 이름에 베타 버전 번호가 있습니다. 2.5.13 Beta 3의 경우:

- `enconvo_2.5.13~beta~3_amd64.deb`
- `enconvo-2.5.13~beta~3-1.x86_64.rpm`
- `Enconvo-2.5.13-beta-3-linux-x64.tar.gz`

이 명령은 최신 베타를 찾아 받습니다.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo_[^"]*\.deb')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Fedora, RHEL, Rocky, AlmaLinux, openSUSE">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo-[^"]*\.rpm')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="휴대용 .tar.gz">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'Enconvo-[^"]*\.tar\.gz')
    curl -fLO "$FEED/$FILE"
    tar xzf "$FILE"
    ```

    `Enconvo`라는 폴더가 풀립니다. 그곳에서 실행하고, 이 페이지가 `enconvo`라고 하는 곳에는 `./Enconvo/enconvo`를 씁니다.
  </Tab>
</Tabs>

## 데스크톱에 설치

패키지 관리자는 앱 창에 필요한 GTK와 WebKitGTK도 설치합니다.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    sudo apt install ./enconvo_*.deb
    ```
  </Tab>
  <Tab title="Fedora, openSUSE">
    ```bash
    sudo dnf install ./enconvo-*.rpm      # Fedora
    sudo zypper install ./enconvo-*.rpm   # openSUSE
    ```
  </Tab>
  <Tab title="휴대용 .tar.gz">
    배포판에서 GTK 3와 WebKitGTK 4.1을 설치한 다음 폴더에서 Enconvo를 시작합니다.

    ```bash
    ./Enconvo/enconvo
    ```
  </Tab>
</Tabs>

RHEL 9, Rocky Linux 9, AlmaLinux 9는 앱 창에 필요한 WebKitGTK 4.1을 제공하지 않으므로, 그 시스템에서는 [서버처럼 Enconvo를 실행](/ko/getting-started/linux)합니다.

애플리케이션 메뉴에서 **Enconvo**를 열고 로그인한 다음 [빠른 시작](/ko/quickstart)을 이어 갑니다. 데스크톱이 트레이를 보여 주면 Enconvo 아이콘이 시스템 트레이에 나타납니다.

## 서버에 설치

서버에는 데스크톱 라이브러리가 필요 없으므로 빼 둡니다.

<Steps>
  <Step title="패키지 설치">
    <Tabs>
      <Tab title="Debian, Ubuntu">
        ```bash
        sudo apt install --no-install-recommends ./enconvo_*.deb
        ```
      </Tab>
      <Tab title="Fedora, RHEL, Rocky, AlmaLinux">
        ```bash
        sudo dnf install --setopt=install_weak_deps=False ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="openSUSE">
        ```bash
        sudo zypper install --no-recommends ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="휴대용 .tar.gz">
        설치할 것이 없습니다. 푼 `Enconvo` 폴더를 씁니다.
      </Tab>
    </Tabs>
  </Step>
  <Step title="서비스로 Enconvo 시작">
    ```bash
    enconvo service install --web
    ```

    Enconvo가 백그라운드에서 실행되며, 이 기기에서만 `127.0.0.1:54580`의 웹사이트로 채팅 창과 설정을 제공합니다. 서버가 부팅되면 다시 시작합니다. 로그인한 동안에만 실행된다고 하면, 출력된 `sudo loginctl enable-linger` 명령을 실행합니다.
  </Step>
  <Step title="로그인">
    ```bash
    enconvo login
    ```

    Enconvo가 짧은 코드를 출력합니다. 휴대폰이나 컴퓨터에서 `enconvo.com/device`를 열고, 페이지가 계정을 가리키는지 확인한 다음 10분 안에 코드를 승인합니다.
  </Step>
  <Step title="본인 컴퓨터에서 Enconvo 열기">
    본인 컴퓨터에서 이것을 실행하고 그대로 둡니다.

    ```bash
    ssh -N -L 54580:127.0.0.1:54580 you@your-server
    ```

    브라우저에서 [http://localhost:54580](http://localhost:54580)을 엽니다. 데스크톱 앱과 같은 채팅 창과 설정을 얻습니다.
  </Step>
</Steps>

휴대폰의 Enconvo 앱에서 이 서버를 쓰려면 `enconvo companion pair --phone`을 실행하고 출력된 코드를 스캔합니다. [휴대폰과 페어링](/ko/integrations/pair-your-phone)을 보세요.

### SSH 터널 없이 접속

터널이 가장 안전한 방법입니다. 서버의 아무것도 네트워크에 열려 있지 않기 때문입니다. 웹사이트는 계정의 전체 권한을 가지며 서버 파일에 닿을 수 있으므로, 열 수 있는 사람은 둘 다 쓸 수 있습니다.

다른 컴퓨터에서 직접 열려면, 예를 들어 사설 네트워크나 VPN에서:

```bash
enconvo service install --web 0.0.0.0:54580
enconvo service url
```

`enconvo service url`은 연결 토큰이 있는 주소를 출력합니다. 그 주소를 비공개로 두고, 이 포트를 인터넷에 노출하지 마세요.

공개 주소가 필요하면 Enconvo 앞에 HTTPS 리버스 프록시를 두고, Enconvo에 제공하는 주소를 알립니다.

```bash
enconvo service install --web --web-url https://enconvo.example.com
```

HTTPS가 있으면 웹사이트를 휴대폰이나 컴퓨터에 앱으로 설치할 수도 있습니다.

## 서버에서 브라우저 사용

에이전트는 화면이 없는 서버에서도 탐색할 수 있습니다. 에이전트가 처음 필요할 때 Enconvo가 Enconvo Browser라는 자체 헤드리스 브라우저를 시작합니다. 먼저 Chromium을 설치합니다.

<Tabs>
  <Tab title="Debian">
    ```bash
    sudo apt install chromium
    ```
  </Tab>
  <Tab title="Ubuntu">
    ```bash
    sudo snap install chromium
    ```
  </Tab>
  <Tab title="Fedora">
    ```bash
    sudo dnf install chromium
    ```
  </Tab>
  <Tab title="RHEL, Rocky, AlmaLinux">
    Chromium은 [EPEL](https://docs.fedoraproject.org/en-US/epel/)에서 옵니다.

    ```bash
    sudo dnf install epel-release
    sudo dnf install chromium
    ```
  </Tab>
</Tabs>

그다음 에이전트에게 부탁합니다. 예: “news.ycombinator.com을 열고 상위 기사를 알려 줘.”

Enconvo Browser는 자체 로그인을 유지합니다. 로그인이나 확인처럼 당신이 필요할 때, 에이전트가 브라우저에 페이지의 실시간 보기를 주어 직접 클릭하고 입력할 수 있습니다. 30분 동안 유휴면 닫히고, 다음에 탭을 되돌립니다.

에이전트가 `localhost`에서 시작한 개발 서버처럼 서버만 닿을 수 있는 페이지도 채팅 옆에 실시간 보기로 열리므로 SSH 터널을 통해 됩니다.

## 어디서 무엇이 되는지

| 기능 | Linux 데스크톱 | 서버 |
| --- | --- | --- |
| 채팅 창, 설정 | 예 | 예, 브라우저에서 |
| 에이전트, 도구, 파일, 문서, 아티팩트 | 예 | 예 |
| 브라우저 사용 | 예 | 예, Chromium과 함께 |
| 지식 베이스, 메모리, 예약 작업, 워크플로 | 예 | 예 |
| Enconvo Cloud 모델, 웹 검색, OCR, 이미지 생성, 음성 | 예 | 예 |
| 컴퓨터 사용 | 예 | 아니요. 제어할 화면이 없습니다 |
| 전역 단축키, 받아쓰기, 음성 메모, 녹음, 화면 낙서, Appshots, 알림 | 예 | 아니요. 데스크톱이 필요합니다 |

Wayland에서는 전역 단축키에 앱에 단축키를 제공하는 데스크톱이 필요합니다.

이 기능은 Linux에 없습니다. SmartBar, PopBar, Dynamic Island, 음성 명령, 아바타, 데스크톱 펫, 앱 사이드바, Live Talk, 자막입니다. SmartBar, PopBar, Dynamic Island, 음성 명령, 아바타, 데스크톱 펫은 [Windows 베타](/ko/getting-started/windows)에 있습니다.

로컬 채팅 모델은 glibc 2.38 이상 시스템에서 GGUF 파일로 실행됩니다. MLX 모델은 Mac이 필요합니다.

## Linux의 계정

계정이 [iPhone 앱](/ko/integrations/iphone-app)도 쓰면, 기본 채팅, 음성, 이미지 선택이 이 컴퓨터로 따라옵니다. 본인 API 키로 실행되는 제공업체는 따라오지 않습니다. 키는 복사되지 않기 때문입니다. 같은 제공업체를 여기서 쓰려면 이 컴퓨터의 **설정**에서 키를 추가합니다.

서버 시계가 브라우저와 다른 시간대면, Enconvo가 시간과 [예약 작업](/ko/workflows/scheduled-jobs)에 본인 시간대를 쓸지 제안합니다.

## 업데이트

베타 빌드는 베타 채널에 남습니다. 바꾸려면 **설정 → 일반**을 열고 **업데이트 채널**을 설정합니다. [업데이트](/ko/configuration/updates)를 보세요.

데스크톱에서는 나타날 때 채팅 창의 **업데이트**를 씁니다. 휴대용 빌드는 스스로를 바꿉니다. `.deb`나 `.rpm`의 경우 Enconvo가 새 패키지를 다운로드 폴더에 받고, [데스크톱에 설치](/ko/getting-started/linux)와 같이 설치합니다.

서버에서:

```bash
enconvo update --check   # is there a newer version?
enconvo update           # download and check it
```

`.deb`나 `.rpm`을 설치했다면 `enconvo update`가 새 패키지를 받고 root로 설치할 명령을 출력합니다. 그 명령을 실행한 다음 서비스를 다시 시작합니다.

```bash
systemctl --user restart enconvo
```

휴대용 `.tar.gz`를 실행하면 `enconvo update`가 폴더를 바꾸고 서비스를 대신 다시 시작합니다. 새 버전이 시작되지 않으면 이전 버전을 되돌립니다.

## 문제 해결

| 보이는 것 | 해결 방법 |
| --- | --- |
| `enconvo`가 데스크톱 앱에 GTK 3와 WebKitGTK 4.1이 필요하다고 함 | 데스크톱에서는 이름이 나온 패키지를 설치합니다. 서버나 RHEL 9에서는 `enconvo service install --web`을 씁니다 |
| `GLIBC_2.34 not found`, 또는 지원 시스템을 나열하는 메시지 | 시스템이 너무 오래되었습니다. [요구 사항](/ko/getting-started/linux)의 시스템을 씁니다 |
| `dnf`가 `nothing provides libwebkit2gtk-4.1.so.0`이라고 함 | 더 오래된 패키지입니다. [서버 명령](/ko/getting-started/linux)으로 현재 베타를 설치합니다 |
| 서버에서 로그아웃하면 Enconvo가 멈추거나, 재부팅 후 시작하지 않음 | `sudo loginctl enable-linger "$USER"`를 실행합니다 |
| `localhost:54580`이 열리지 않음 | `ssh -L` 명령이 아직 실행 중인지, `systemctl --user status enconvo`가 active인지 확인합니다 |
| 웹사이트가 토큰을 요구함 | 서버에서 `enconvo service url`을 실행하고 출력된 주소를 엽니다 |
| 에이전트가 Enconvo Browser를 시작할 수 없다고 함 | [Chromium 설치](/ko/getting-started/linux). Google Chrome 137 이상은 Enconvo Browser에 필요한 확장을 불러올 수 없습니다 |
| 코드가 만료됨 | 새 코드를 받으려면 `enconvo login`을 다시 실행합니다 |

서버에서 Enconvo 로그를 읽으려면:

```bash
journalctl --user -u enconvo -n 100
```

## Enconvo 제거

```bash
enconvo service uninstall
sudo apt remove enconvo     # Debian, Ubuntu
sudo dnf remove enconvo     # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper remove enconvo  # openSUSE
```

설정과 채팅은 `~/.config/enconvo`에 남습니다. 그것도 제거하려면 그 폴더를 삭제합니다.

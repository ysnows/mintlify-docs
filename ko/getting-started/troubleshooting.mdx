아래에서 겪고 있는 문제를 찾고 오른쪽 열의 해결 방법을 시도해 보세요. 대부분의 문제는 제공업체 연결 끊김, macOS 권한 누락, 또는 구버전 앱 사용 때문에 발생합니다. 여기 안내로 해결되지 않으면 [진단 정보 보내기](#진단-정보-보내기)를 실행한 뒤 Discord에서 질문해 주세요.

## 먼저 시도해 볼 방법

1. **Enconvo를 종료했다가 다시 엽니다.** 메뉴 막대의 Enconvo 아이콘에서 **종료**를 선택한 뒤 **응용 프로그램**에서 Enconvo를 다시 실행하세요.
2. **업데이트합니다.** 메뉴 막대 아이콘에서 **업데이트 확인**을 선택하거나, **설정 → 일반 → 업데이트**에서 **업데이트 확인**을 클릭합니다.
3. **모델을 확인합니다.** **설정 → AI 모델**을 열고 사용 중인 제공업체가 연결되어 있는지 확인하세요. 어떤 모델을 써야 할지 모르겠다면 Enconvo 계정에 로그인한 뒤 [자동 라우팅](/ko/providers/auto-route)을 사용하세요.
4. **권한을 확인합니다.** **설정 → 권한**을 열고 해당 기능에 필요한 권한을 켭니다. [권한](/ko/configuration/permissions)을 참고하세요.

## 답변과 모델

| 문제 | 해결 방법 |
| --- | --- |
| 답변이 없거나 제공업체 관련 오류가 남 | **설정 → AI 모델**에서 해당 제공업체를 열고 **검증**을 클릭하세요. 요금제 로그인 방식이라면 계정 카드 메뉴를 열고 **다시 연결**을 클릭합니다. |
| 한도, 할당량 또는 포인트 관련 오류가 남 | 제공업체의 사용량 페이지나 Enconvo Cloud의 경우 **설정 → 포인트 사용량**을 확인하세요. 당분간 다른 제공업체로 전환해 사용하세요. |
| 모든 클라우드 제공업체가 실패함 | 인터넷 연결을 확인하세요. 프록시를 쓰고 있다면 **설정 → 일반**의 **네트워크 프록시** 아래에서 **시스템 네트워크 프록시 설정 사용**을 확인하세요. 이 옵션을 켜면 모델 요청, 웹 가져오기, 커넥터가 시스템 프록시를 거치며, 프록시 변경 사항이 Enconvo를 재시작하지 않아도 적용됩니다. LM Studio나 Ollama처럼 Mac과 로컬 네트워크에 있는 서버에는 계속 직접 연결됩니다. |
| 국가 또는 지역에서 지원되지 않는 모델이라고 나옴 | Enconvo 요청이 프록시를 거치도록 **시스템 네트워크 프록시 설정 사용**을 켜세요. |
| 답변 속도가 느림 | 더 작거나 빠른 모델을 선택하고, 컨텍스트 첨부를 줄이거나, 추론 강도를 낮추세요. 로컬 모델은 입력이 길수록 속도가 느려집니다. |
| 한 모델만 실패하고 다른 모델은 정상 동작함 | 해당 모델이나 제공업체 측 문제입니다. 채팅의 모델 선택기에서 다른 모델을 고르세요. |
| Ollama 또는 LM Studio가 연결되지 않음 | 서버가 실행 중인지와 **BaseUrl**이 서버 주소와 일치하는지 확인한 뒤 **모델 이름** 옆의 **새로고침**을 클릭하세요. [Ollama](/ko/providers/ollama) 또는 [LM Studio](/ko/providers/lm-studio)를 참고하세요. |

## 단축키와 창

| 문제 | 해결 방법 |
| --- | --- |
| 단축키를 눌러도 아무 반응이 없음 | Spotlight, Raycast, Alfred 같은 다른 앱이 같은 키 조합을 쓰고 있을 수 있습니다. **설정 → 단축키**에서 하나를 변경하세요. |
| 업데이트 후 단축키가 작동하지 않음 | Enconvo를 종료했다가 다시 실행하세요. 해결되지 않으면 시스템 설정에서 Enconvo의 손쉬운 사용 권한을 껐다가 다시 켜세요. |
| 앱을 찾을 수 없음 | 메뉴 막대나 Dock의 Enconvo 아이콘을 클릭하거나 **⌥Space**를 눌러 SmartBar를 여세요. |
| 기억하고 있던 SmartBar나 채팅 창 단축키가 작동하지 않음 | 기본값은 SmartBar가 **⌥Space**, 채팅 창이 **⌃⌘X**입니다. **설정 → 단축키**를 확인하세요. |

## 선택한 텍스트와 화면

| 문제 | 해결 방법 |
| --- | --- |
| PopBar가 나타나지 않거나 Enconvo가 선택한 텍스트를 읽지 못함 | **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켜세요. 이미 켜져 있다면 끄고 2초 기다린 뒤 다시 켜고 Enconvo를 재시작하세요. 보안 입력란과 일부 커스텀 편집기는 텍스트를 공유하지 않습니다. |
| 스크린샷, OCR 또는 화면 컨텍스트가 실패함 | **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 Enconvo를 켠 뒤 Enconvo를 재시작하세요. |
| 권한이 켜져 있는데도 업데이트 후 효과가 없음 | 시스템 설정의 해당 목록에서 **−** 버튼으로 Enconvo를 제거했다가 다시 추가하고 Enconvo를 재시작하세요. |
| 기능이 더 이상 권한을 요청하지 않음 | **다시 묻지 않음**에 체크했을 수 있습니다. **설정 → 권한**에서 각 권한의 **사용처** 목록을 확인하고 그곳에서 허용하세요. |

## 음성과 오디오

| 문제 | 해결 방법 |
| --- | --- |
| 받아쓰기가 아무 소리도 듣지 못함 | 마이크 권한과 **설정 → 받아쓰기**에서 선택한 마이크를 확인하세요. |
| 받아쓰기 결과가 부정확하거나 느림 | **설정 → 받아쓰기 모델**에서 다른 음성 모델을 시험해 보세요. 자주 쓰는 이름과 용어는 **설정 → 사전**에 추가하세요. |
| 소리 내어 읽기가 무음으로 나옴 | Mac의 음량과 출력 장치를 확인하세요. **설정 → 텍스트 음성 변환**에서 **시스템**을 사용해 보세요. API 키가 필요 없고 오프라인에서도 작동합니다. |

자세한 내용은 [받아쓰기](/ko/features/dictation)와 [음성 인식](/ko/ai/speech-recognition)을 참고하세요.

## 지식 베이스

| 문제 | 해결 방법 |
| --- | --- |
| 문서 인덱싱이 끝나지 않음 | **설정 → 지식 베이스**에서 임베딩 제공업체를 확인하고 파일 형식이 지원되는지 점검하세요. |
| 검색 결과가 아무것도 나오지 않음 | 지식 베이스가 채팅에 첨부되어 있는지 확인하세요. 지식 베이스 설정에서 점수 임계값을 낮추거나 결과 개수를 늘려 보세요. |
| 큰 지식 베이스가 느림 | 주제별로 더 작은 지식 베이스 여러 개로 나누거나 재순위화 모델(reranker)을 추가하세요. |

[지식 베이스](/ko/ai/knowledge-base)와 [지식 베이스 작동 원리](/ko/advanced/knowledge-base-advanced)를 참고하세요.

## 브라우저, 앱, 플러그인

| 문제 | 해결 방법 |
| --- | --- |
| Enconvo가 브라우저를 제어할 수 없음 | **설정 → 브라우저 사용**에서 Enconvo 도우미 확장 프로그램을 설치한 뒤 브라우저를 재시작하세요. [브라우저 확장 프로그램](/ko/features/browser-extension)을 참고하세요. |
| 에이전트가 앱을 사용할 수 없음 | **설정 → 컴퓨터 사용**이 요청하는 권한들을 켜 주세요. [컴퓨터 사용](/ko/features/computer-use)을 참고하세요. |
| 플러그인 명령이 실패함 | **설정 → 플러그인**을 열어 플러그인의 설정과 자격 증명을 확인하고 Enconvo를 업데이트하세요. |
| 에이전트의 명령이 권한 오류로 실패함 | 에이전트 샌드박스가 해당 명령을 차단했을 수 있습니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 참고하세요. |

## 진단 정보 보내기

Enconvo가 멈추거나 충돌하거나 계속 오작동할 때는 Enconvo 팀에 진단 로그를 보내세요. 메뉴 막대 아이콘에서 **진단 정보 제출…**을 선택하거나 **설정 → 진단**을 엽니다. Enconvo는 파일 이름, 이메일 주소, API 키, 프롬프트 텍스트 같은 개인 정보를 Mac을 떠나기 전에 모두 제거하며, 실제로 전송되는 내용을 화면에 정확히 보여 줍니다. [개인정보 보호 및 보안](/ko/configuration/privacy-security)을 참고하세요.

---

이 페이지는 [컨텍스트 인식](/ko/features/context-awareness)이 뒤에서 하는 일을 설명합니다. Enconvo가 Mac에서 읽을 수 있는 항목, 각 항목을 읽는 방식, 메시지에 무엇을 넣을지 고르는 방법입니다. 모델에 도달되는 내용을 제어하고 싶을 때, 또는 기대한 컨텍스트가 나오지 않을 때 읽으세요.

컨텍스트 인식은 배경에서 화면을 계속 보지 않습니다. SmartBar를 열 때, 또는 직접 항목을 추가할 때, 바로 전에 쓰던 앱에서 컨텍스트를 읽습니다.

## Enconvo가 읽을 수 있는 것

각 컨텍스트 종류는 메시지에 넣을 수 있는 항목입니다.

| 컨텍스트 항목 | 담는 내용 | Enconvo가 읽는 방식 |
|---|---|---|
| **선택한 텍스트** | 앱에서 선택한 텍스트 | 손쉬운 사용 |
| **현재 앱 내용** | 윈도우 제목과 텍스트, 앱이 제공하면 문서 주소, 윈도우 스크린샷 | 손쉬운 사용과 윈도우 캡처 |
| **브라우저 현재 탭 URL** | 앞쪽 탭의 주소, 제목, 페이지 텍스트 | Apple Events. 아래 브라우저 절 참고 |
| **Finder 선택 항목** | Finder에서 선택한 파일과 폴더의 경로 | Apple Events |
| **Finder 현재 디렉터리 URL** | 앞쪽 Finder 윈도우에 열린 폴더 | Apple Events |
| **클립보드 텍스트** | 클립보드의 텍스트 | 직접 추가할 때만 클립보드 |
| **사용자가 선택한 영역 스크린샷** | 직접 선택한 화면 영역 | 화면 캡처 |
| **현재 앱 스크린샷** | 사용 중이던 앱 | 화면 캡처 |
| **현재 화면 스크린샷** | 화면 전체 | 화면 캡처 |
| **실시간 화면 스크린샷** | Enconvo 윈도우를 제외한 지금 화면 | 화면 캡처 |

Finder 항목은 파일 내용이 아니라 경로만 읽습니다.

### 브라우저

- **주소와 제목**: Safari, Chrome, Edge, Arc와 기타 Chromium 브라우저에서 Apple Events로 읽습니다. Firefox는 탭 주소를 주지 않아 Enconvo가 읽을 수 없습니다.
- **페이지 텍스트**: Safari는 바로 줍니다. 다른 브라우저는 손쉬운 사용으로 윈도우를 읽으며, 브라우저가 맨 앞 앱일 때만 동작합니다.

### 다른 앱

코드 편집기, 텍스트 편집기, 그 밖 모든 앱은 **현재 앱 내용**을 받습니다. 윈도우 제목, 손쉬운 사용이 노출하는 텍스트, 앱이 주면 문서 주소, 윈도우 스크린샷입니다. 텍스트가 얼마나 오는지는 앱에 따라 다릅니다.

## SmartBar를 열 때

SmartBar를 열면 사용 중이던 앱에서 세 곳을 확인합니다. **설정 → 컨텍스트 인식**에서 각 소스를 어떻게 할지 정합니다.

| 소스 | 기본값 | 가져오는 내용 |
|---|---|---|
| **선택한 텍스트** | **자동 추가** | 사용 중이던 앱에서 선택한 텍스트 |
| **Finder 선택 항목** | **제안** | Finder에서 선택한 파일과 폴더 |
| **브라우저의 현재 페이지** | **제안** | Safari, Chrome, Arc, Edge 또는 다른 Chromium 브라우저에 열린 페이지 |

- **자동 추가**는 SmartBar가 열리자마자 입력창에 항목을 넣습니다.
- **제안**은 명령 위에 목록으로 보여 클릭 한 번으로 추가합니다. 제안된 페이지의 텍스트는 클릭할 때만 읽습니다.
- **끔**은 그 소스를 그대로 둡니다.

이 설정은 SmartBar에만 적용됩니다. 선택 항목에 실행하는 명령은 항상 선택한 텍스트를 받습니다.

## 컨텍스트를 직접 추가하기

1. SmartBar에서 `#`을 입력합니다.
2. 몇 글자를 입력해 컨텍스트 항목 목록을 걸러냅니다.
3. 하나를 고릅니다. Enconvo가 읽어 메시지에 넣습니다.

다른 문자를 쓰려면 **설정 → SmartBar**의 **검색** 아래에서 **컨텍스트**를 바꿉니다. 같은 그룹에서 명령은 `@`, 스킬은 `$`, 최근 작업은 `>`를 쓰는지 정합니다.

## 권한

| 권한 | 필요한 경우 |
|---|---|
| **손쉬운 사용** | 선택한 텍스트, 윈도우 내용, Safari가 아닌 브라우저의 페이지 텍스트 |
| **자동화** | Finder 항목과 브라우저 페이지. Enconvo가 각 앱을 처음 읽을 때 macOS가 묻니다 |
| **화면 기록** (화면 및 시스템 오디오 기록) | 스크린샷과 **현재 앱 내용**의 윈도우 캡처 |

**시스템 설정 → 개인 정보 보호 및 보안**에서 허용하세요. Enconvo는 손쉬운 사용 권한 변경을 스스로 알아착니다. 전체 목록은 [권한](/ko/configuration/permissions)을 보세요.

## 컨텍스트와 토큰

컨텍스트는 모델의 컨텍스트 창에 포함됩니다. 페이지 텍스트와 스크린샷이 가장 크며, 다음과 같은 영향이 있습니다.

- 답변이 느려집니다
- 클라우드 모델 비용이 늘어납니다
- 대화 기록에 남는 여유가 줄어듭니다

<Tip>
긴 채팅에서는 페이지나 스크린샷을 매번 붙이지 말고, 필요한 메시지에만 넣으세요.
</Tip>

## 개인 정보 보호와 데이터 흐름

캡처한 컨텍스트는 저장된 대화나 지식 베이스 항목의 일부가 될 수 있습니다. 모델 요청과 선택한 OCR, 임베딩, 음성 텍스트 변환, 그 밖 도구 제공업체가 관련 내용을 받을 수 있습니다. 로컬 저장과 제공업체 처리의 차이는 [개인 정보 보호 및 보안](/ko/configuration/privacy-security)을 보세요.

로컬 채팅 모델만으로 모든 도구가 오프라인이 되는 것은 아닙니다. 브라우저 접근, 캡처, 제공업체 기반 처리까지 전체 흐름을 확인하세요. macOS 권한은 사용 가능한 컨텍스트를 줄일 뿐, 제3자 앱의 모든 필드가 민감 정보로 분류된다는 보장은 아닙니다.

## 문제 해결

| 문제 | 할 일 |
|---|---|
| 선택한 텍스트나 윈도우 내용이 없음 | **시스템 설정 → 개인 정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켜세요. 일부 앱은 손쉬운 사용으로 텍스트를 노출하지 않습니다. 텍스트를 복사한 뒤 `#`으로 **클립보드 텍스트**를 추가하세요. |
| 브라우저 페이지나 Finder 항목이 없음 | **시스템 설정 → 개인 정보 보호 및 보안 → 자동화**에서 해당 앱에 대해 Enconvo를 켜세요. |
| Firefox에서 주소가 없음 | Firefox는 탭 주소를 주지 않습니다. 다른 브라우저를 쓰거나 주소를 복사하세요. |
| 페이지는 오는데 텍스트가 없음 | Safari가 아니면 페이지 텍스트는 브라우저가 맨 앞일 때만 읽습니다. 브라우저에서 SmartBar를 여세요. |
| 다른 앱의 컨텍스트가 옴 | 컨텍스트는 SmartBar를 열 때 사용 중이던 앱에서 옵니다. 원하는 앱이 앞에 온 뒤 SmartBar를 여세요. |
| 스크린샷이 실패함 | **시스템 설정 → 개인 정보 보호 및 보안 → 화면 및 시스템 오디오 기록**에서 Enconvo를 켜세요. |

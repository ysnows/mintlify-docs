이 페이지는 [컨텍스트 인식](/ko/features/context-awareness)의 내부를 설명합니다. Enconvo가 Mac에서 읽을 수 있는 항목, 각 항목을 읽는 방식, 메시지에 무엇을 포함할지 정하는 방법을 다룹니다. 모델에 전달되는 내용을 제어하고 싶거나 기대한 컨텍스트가 나타나지 않을 때 읽어 보세요.

컨텍스트 인식은 백그라운드에서 화면을 지켜보지 않습니다. SmartBar를 열 때, 또는 직접 항목을 추가할 때, 바로 직전에 사용하던 앱에서 컨텍스트를 읽습니다.

## Enconvo가 읽을 수 있는 것

각 종류의 컨텍스트는 메시지에 추가할 수 있는 항목입니다.

| 컨텍스트 항목 | 담는 내용 | Enconvo가 읽는 방식 |
|---|---|---|
| **선택한 텍스트** | 앱에서 선택한 텍스트 | 손쉬운 사용 |
| **Current Application Content** | 창의 제목과 텍스트, 앱이 제공하는 경우 문서의 주소, 창의 스크린샷 | 손쉬운 사용과 창 캡처 |
| **Browser Current Tab URL** | 맨 앞 탭의 주소, 제목, 페이지의 텍스트 | Apple Events. [브라우저](#브라우저) 참고 |
| **Finder Selected Items** | Finder에서 선택한 파일과 폴더(경로) | Apple Events |
| **Finder Current Directory URL** | 맨 앞 Finder 창에서 열려 있는 폴더 | Apple Events |
| **Clipboard Text** | 클립보드의 텍스트 | 클립보드. 직접 추가할 때만 읽습니다 |
| **User Select Area Screenshot** | 직접 선택한 화면 영역 | 화면 캡처 |
| **Current Application Screenshot** | 사용 중이던 앱 | 화면 캡처 |
| **Current Screen Screenshot** | 화면 전체 | 화면 캡처 |
| **Live Screen Screenshot** | Enconvo 창을 제외한 현재 화면 | 화면 캡처 |

Finder 항목은 파일 내용이 아니라 경로를 읽습니다.

### 브라우저

- **주소와 제목**: Safari, Chrome, Edge, Arc 및 다른 Chromium 브라우저에서 Apple Events로 읽습니다. Firefox는 탭 주소를 제공하지 않으므로 Enconvo가 읽을 수 없습니다.
- **페이지 텍스트**: Safari는 직접 제공합니다. 다른 브라우저는 Enconvo가 손쉬운 사용으로 창을 읽으며, 브라우저가 가장 앞에 있는 앱일 때만 동작합니다.

### 다른 앱

코드 편집기, 텍스트 편집기 및 그 외 모든 앱은 **Current Application Content**를 받습니다. 창의 제목, 손쉬운 사용이 제공하는 텍스트, 앱이 제공하는 경우 문서의 주소, 창의 스크린샷이 포함됩니다. 텍스트의 양은 앱에 따라 다릅니다.

## SmartBar가 열릴 때

SmartBar를 열면 사용 중이던 앱에서 세 가지 소스를 확인합니다. **설정 → 컨텍스트 인식**에서 각 소스를 어떻게 처리할지 정합니다.

| 소스 | 기본값 | 가져오는 것 |
|---|---|---|
| **선택한 텍스트** | **자동 추가** | 사용 중이던 앱에서 선택한 텍스트 |
| **Finder 선택 항목** | **제안** | Finder에서 선택한 파일과 폴더 |
| **브라우저의 현재 페이지** | **제안** | Safari, Chrome, Arc, Edge 또는 다른 Chromium 브라우저에서 열려 있는 페이지 |

- **자동 추가**는 SmartBar가 열리자마자 해당 항목을 입력에 추가합니다.
- **제안**은 명령 위에 항목을 나열하므로 한 번의 클릭으로 추가할 수 있습니다. 제안된 페이지의 텍스트는 클릭할 때만 읽습니다.
- **끔**은 해당 소스를 사용하지 않습니다.

이 설정은 SmartBar에서만 사용됩니다. 선택 영역에 실행하는 명령은 항상 선택한 텍스트를 받습니다.

## 직접 컨텍스트 추가하기

1. SmartBar에서 `#`을 입력하세요.
2. 몇 글자를 입력해 컨텍스트 항목 목록을 거르세요.
3. 하나를 선택하세요. Enconvo가 그 항목을 읽어 메시지에 추가합니다.

다른 문자를 쓰려면 **설정 → SmartBar**의 **검색**에서 **컨텍스트**를 변경하세요. 같은 그룹에서 명령용 `@`, 스킬용 `$`, 최근 작업용 `>`도 설정합니다.

## 권한

| 권한 | 필요한 기능 |
|---|---|
| **손쉬운 사용** | 선택한 텍스트, 창 내용, Safari 이외 브라우저의 페이지 텍스트 |
| **자동화** | Finder 항목과 브라우저 페이지. Enconvo가 각 앱을 처음 읽을 때 macOS가 묻습니다 |
| **화면 기록**(화면 및 시스템 오디오 기록) | 스크린샷과 **Current Application Content**의 창 캡처 |

**시스템 설정 → 개인정보 보호 및 보안**에서 허용하세요. Enconvo는 손쉬운 사용의 변경을 스스로 감지합니다. 전체 목록은 [권한](/ko/configuration/permissions)을 참고하세요.

## 컨텍스트와 토큰

컨텍스트는 모델의 컨텍스트 창을 소모합니다. 페이지 텍스트와 스크린샷이 가장 큰 항목이며, 다음과 같은 영향을 줄 수 있습니다.

- 응답이 느려질 수 있습니다
- 클라우드 모델에서는 비용이 더 들 수 있습니다
- 대화 기록에 쓸 수 있는 공간이 줄어듭니다

<Tip>
긴 채팅에서는 페이지나 스크린샷을 매번 첨부하지 말고, 필요한 메시지에만 추가하세요.
</Tip>

## 개인정보와 데이터 흐름

캡처된 컨텍스트는 저장된 대화나 지식 베이스 항목의 일부가 될 수 있습니다. 모델 요청과 선택한 OCR, 임베딩, 전사 또는 기타 도구 제공업체가 관련 콘텐츠를 받을 수 있습니다. 로컬 저장과 제공업체 처리의 차이는 [개인정보 보호 및 보안](/ko/configuration/privacy-security)을 확인하세요.

로컬 채팅 모델만 쓴다고 해서 모든 도구가 오프라인으로 동작하는 것은 아닙니다. 브라우저 접근, 캡처, 제공업체 기반 처리를 포함해 전체 흐름을 확인하세요. macOS 권한은 사용할 수 있는 컨텍스트를 줄여 줄 뿐이며, 서드파티 앱의 모든 필드를 민감 정보로 분류할 수 있다는 보장은 아닙니다.

## 문제 해결

| 문제 | 해결 방법 |
|---|---|
| 선택한 텍스트나 창 내용이 없음 | **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켜세요. 일부 앱은 손쉬운 사용으로 텍스트를 제공하지 않습니다. 대신 텍스트를 복사하고 `#`으로 **Clipboard Text**를 추가하세요. |
| 브라우저 페이지나 Finder 항목이 없음 | **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 해당 앱에 대해 Enconvo를 켜세요. |
| Firefox에서 주소를 가져오지 못함 | Firefox는 탭 주소를 제공하지 않습니다. 다른 브라우저를 사용하거나 주소를 복사하세요. |
| 페이지가 텍스트 없이 들어옴 | Safari 이외에는 브라우저가 가장 앞에 있을 때만 페이지 텍스트를 읽습니다. 브라우저에서 SmartBar를 여세요. |
| 엉뚱한 앱에서 컨텍스트를 가져옴 | 컨텍스트는 SmartBar가 열린 시점에 사용 중이던 앱에서 가져옵니다. 원하는 앱이 맨 앞에 올 때까지 기다린 다음 SmartBar를 여세요. |
| 스크린샷이 실패함 | **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록**에서 Enconvo를 켜세요. |

---

Enconvo는 같은 Mac의 MCP 호환 AI 클라이언트에 지식 베이스를 제공할 수 있습니다. 클라이언트는 사용자가 공유한 지식 베이스만 검색하고 읽을 수 있으며 그 외에는 접근할 수 없습니다. 액세스는 읽기 전용입니다. 이는 Enconvo의 에이전트에 외부 도구를 추가하는 **설정 → MCP 서버**와는 별개입니다.

## 클라이언트 연결

1. [지식 베이스](/ko/ai/knowledge-base)를 열고 톱니바퀴(**지식 베이스 설정**)를 클릭한 다음 **AI 클라이언트(MCP)**를 선택합니다.
2. **지식 베이스 MCP 활성화**를 켭니다. 기본값은 꺼짐이며, 꺼져 있는 동안에는 연결된 클라이언트가 거부됩니다.
3. 클라이언트가 볼 수 있는 항목을 선택합니다. **이 지식 베이스를 AI 클라이언트와 공유**는 지금 열어 둔 지식 베이스에 적용되고, **공유 지식 베이스**에는 모든 지식 베이스가 나열됩니다. 받아쓰기 기록과 메모리는 켜기 전까지 숨겨져 있습니다.
4. **클라이언트 연결**에서 사용하는 클라이언트(Claude Code, Cursor, Codex, Claude Desktop)를 선택하고 해당 설정을 복사합니다.
5. 클라이언트에게 지식 베이스 목록을 보여 달라고 한 다음, 하나를 검색하고 일치하는 항목을 읽어 보게 합니다.

로컬 엔드포인트는 다음과 같습니다.

```text
http://localhost:54535/knowledge_base/mcp
```

Streamable HTTP 전송을 사용합니다. 클라이언트가 사용하는 동안 Enconvo를 계속 실행해 두세요. Claude Desktop은 작은 브리지인 `mcp-remote`를 통해 연결되므로 설정에 Node.js가 필요합니다. 대화상자에 표시되는 클라이언트별 안내를 따르세요.

## 사용 가능한 도구

| 도구 | 용도 |
| --- | --- |
| `kb_list` | 보이는 지식 베이스 목록 표시 |
| `kb_search` | 보이는 지식 베이스 검색 |
| `item_list` | 보이는 지식 베이스의 항목 목록 표시 |
| `item_read` | 색인된 항목 텍스트를 페이지 단위로 읽기 |

이 도구들은 읽기 전용입니다. 이 엔드포인트는 일반 메모리나 녹음 도구를 제공하지 않습니다. 항목을 읽으면 메타데이터로 원본 경로나 URL이 반환될 수 있습니다.

## 액세스와 처리

서버는 루프백 연결만 허용하며 토큰을 요구하지 않습니다. 이를 켜면 로컬 프로세스가 사용자가 공유한 지식 베이스를 읽을 수 있습니다. 연결된 AI 클라이언트는 받은 내용을 자체 모델 제공업체로 보낼 수 있으므로 해당 클라이언트의 설정도 검토하세요.

검색에는 **설정 → 메모리**의 **검색**에서 지정한 임베딩 모델이 사용됩니다. 이 모델이 Enconvo Cloud에서 실행되면 검색 텍스트가 그곳으로 전송됩니다. "로컬 엔드포인트"라고 해서 검색과 답변의 모든 과정이 오프라인으로 실행된다는 뜻은 아닙니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결이 거부됨 | Enconvo와 로컬 API가 실행 중인지 확인하세요. |
| Forbidden / 403 | **지식 베이스 MCP 활성화**가 켜져 있는지, 클라이언트가 이 Mac에서 연결하는지, 클라이언트 구성이 대화상자의 내용과 일치하는지 확인하세요. |
| 지식 베이스를 찾을 수 없음 | **공유 지식 베이스**에서 해당 지식 베이스를 켜세요. 숨겨진 지식 베이스와 존재하지 않는 지식 베이스는 클라이언트에게 똑같이 보입니다. |
| 브라우저에서 URL을 열면 405가 표시됨 | 브라우저의 GET은 MCP 요청이 아닙니다. MCP 클라이언트로 연결하세요. |
| 긴 문서가 불완전하게 반환됨 | 클라이언트에게 `item_read`로 나머지 페이지를 요청하라고 하세요. |

모든 액세스를 중단하려면 **지식 베이스 MCP 활성화**를 끄세요. 클라이언트가 가져올 수 있는 범위를 좁히려면 **공유 지식 베이스**에서 개별 지식 베이스를 끄세요.

---

Enconvo는 같은 Mac에 있는 MCP 호환 AI 클라이언트에 지식 베이스를 제공할 수 있습니다. 클라이언트는 사용자가 공유한 지식 베이스만 검색하고 읽을 수 있으며 그 외에는 접근할 수 없는 읽기 전용 권한을 가집니다. 이는 Enconvo의 에이전트에 외부 도구를 추가하는 **설정 → MCP 서버**와는 별개입니다.

## 클라이언트 연결하기

1. [지식 베이스](/ko/ai/knowledge-base)를 열고 톱니바퀴 아이콘(**지식 베이스 설정**)을 클릭한 다음 **AI 클라이언트(MCP)**를 선택합니다.
2. **지식 베이스 MCP 활성화**를 켭니다. 기본값은 꺼짐이며, 꺼져 있는 동안에는 연결된 클라이언트의 요청이 거부됩니다.
3. 클라이언트가 볼 수 있는 항목을 선택합니다. **이 지식 베이스를 AI 클라이언트와 공유**는 현재 열린 지식 베이스를 다루며, **공유 지식 베이스**에는 전체 목록이 표시됩니다. 받아쓰기 기록과 메모리는 켜기 전까지 숨겨집니다.
4. **클라이언트 연결** 아래에서 사용 중인 클라이언트(Claude Code, Cursor, Codex 또는 Claude Desktop)를 선택하고 설정을 복사합니다.
5. 클라이언트에게 지식 베이스 목록을 조회한 뒤, 하나를 검색해 일치하는 항목을 읽어 보라고 요청합니다.

로컬 엔드포인트는 다음과 같습니다.

```text
http://localhost:54535/knowledge_base/mcp
```

이 엔드포인트는 Streamable HTTP 전송 방식을 사용합니다. 클라이언트가 사용하는 동안 Enconvo를 계속 실행해 두세요. Claude Desktop은 작은 브리지인 `mcp-remote`를 통해 연결되므로 설정에 Node.js가 필요합니다. 대화 상자에 표시되는 클라이언트별 안내를 따르세요.

## 사용 가능한 도구

| 도구 | 용도 |
| --- | --- |
| `kb_list` | 표시된 지식 베이스 목록 조회 |
| `kb_search` | 표시된 지식 베이스 검색 |
| `item_list` | 표시된 지식 베이스의 항목 목록 조회 |
| `item_read` | 색인된 항목 텍스트를 페이지 단위로 읽기 |

이 도구들은 읽기 전용입니다. 이 엔드포인트는 일반 메모리나 녹음 도구를 노출하지 않습니다. 항목을 읽을 때 메타데이터로 원본 경로 또는 URL이 반환될 수 있습니다.

## 접근 및 처리 방식

서버는 루프백 연결만 수락하며 토큰을 요구하지 않습니다. 이 기능을 켜면 로컬 프로세스가 사용자가 공유한 지식 베이스를 읽을 수 있습니다. 연결된 AI 클라이언트는 조회한 내용을 자체 모델 제공업체로 전송할 수 있으므로 해당 클라이언트의 설정도 함께 확인하세요.

검색은 **설정 → 메모리**의 **검색** 아래에 지정된 임베딩 모델을 사용합니다. Enconvo Cloud에서 실행될 때는 검색 텍스트가 Enconvo Cloud로 전송됩니다. "로컬 엔드포인트"라고 해서 검색과 응답 생성의 모든 과정이 오프라인으로 실행되는 것은 아닙니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결이 거부됨 | Enconvo와 Local API가 실행 중인지 확인하세요. |
| 금지됨 / 403 | **지식 베이스 MCP 활성화**가 켜져 있는지, 클라이언트가 이 Mac에서 연결하는지, 그리고 구성이 대화 상자의 내용과 일치하는지 확인하세요. |
| 지식 베이스를 찾을 수 없음 | **공유 지식 베이스** 아래에서 해당 지식 베이스를 켜세요. 숨겨진 지식 베이스와 존재하지 않는 지식 베이스는 클라이언트에 동일하게 보입니다. |
| 브라우저에서 URL을 열면 405가 표시됨 | 브라우저의 GET 요청은 MCP 요청이 아닙니다. MCP 클라이언트로 연결하세요. |
| 긴 문서가 불완전하게 반환됨 | 클라이언트에게 `item_read`로 후속 페이지를 요청하도록 지시하세요. |

모든 접근을 중단하려면 **지식 베이스 MCP 활성화**를 끄세요. 클라이언트가 검색할 수 있는 범위를 좁히려면 **공유 지식 베이스** 아래에서 개별 지식 베이스를 끄면 됩니다.

이 페이지는 터미널, 스크립트 또는 다른 앱에서 Enconvo를 제어하려는 개발자와 파워 유저를 위한 문서입니다. `enconvo` 명령은 별도 설치 없이 Enconvo 데스크톱 앱에 포함되어 있으며, 앱은 설치된 모든 플러그인의 라우트를 로컬 HTTP API로 제공합니다.

이 영상에서는 API 페이지, CLI 가이드, 훅을 다룹니다.

로컬 런타임을 사용하는 명령을 쓰려면 Enconvo를 계속 실행해 두세요.

## 명령 찾기

```bash
enconvo -h
enconvo knowledge_base -h
```

알아보려는 명령 뒤에 `-h`를 붙이면 현재 사용할 수 있는 하위 명령과 옵션이 표시됩니다.

**설정 → CLI 가이드**를 열면 CLI 명령을 제공하는 설치된 확장 프로그램을 볼 수 있습니다. 이름을 클릭하면 해당 `enconvo <name> -h` 명령이 복사됩니다. 앱이 지원하는 기능은 설치된 확장 프로그램 목록이 기준입니다.

셸에서 `enconvo`를 찾지 못하면 앱의 CLI 가이드를 열어 설치된 앱 버전과 명령줄 설정을 확인하세요.

## 로컬 API 호출하기

앱은 각 라우트를 `http://localhost:54535/api/<extension>/<route>`에서 제공합니다. JSON 본문과 함께 `POST`를 보내세요.

```bash
curl -X POST http://localhost:54535/api/enconvo/extension/available_list \
  -H "Content-Type: application/json" \
  -d '{}'
```

**설정 → API**를 열고 **API 확인**을 클릭하면 사용할 수 있는 라우트와 요청 스키마를 예시와 함께 확인할 수 있습니다. 연동을 작성할 때는 설치된 빌드의 스키마를 사용하세요. 확장 프로그램이 발전함에 따라 라우트 매개변수가 바뀔 수 있습니다.

## Enconvo 밖에서 에이전트 또는 AI 명령 실행하기

각 에이전트와 AI 명령의 설정에는 **링크, CLI 및 API** 행이 있습니다. 여기에는 입력한 텍스트와 파일로 실행하는 링크, `enconvo` 명령, 로컬 API 호출이 바로 복사할 수 있게 표시됩니다.

| 방식 | 동작 |
| --- | --- |
| 링크 | 새 채팅을 열고 그곳에서 에이전트 또는 AI 명령을 실행합니다 |
| CLI | 백그라운드에서 실행하고 답변을 출력합니다 |
| Local API | 백그라운드에서 실행하고 답변을 반환합니다 |

링크의 형식은 다음과 같습니다.

```text
enconvo://<extension>/<command>?input_text=<text>&window=<window>&files=<path>
```

- `input_text`는 보낼 텍스트입니다.
- `window`는 `chat_window` 또는 `dynamic_island`입니다. 생략하면 SmartBar에서 실행됩니다.
- `files`는 절대 경로 또는 `~/` 경로의 파일을 첨부합니다. 다른 앱이나 스크립트에서 이미지를 보내는 경우처럼 여러 파일을 보내려면 반복해서 지정하세요.

터미널에서는 다음과 같이 실행합니다.

```bash
enconvo agent call "What's on my calendar today?"
enconvo ai-command run 'writing_package|translate' --input-text "Bonjour" --files ~/Desktop/note.png
enconvo writing_package convert_to_list "eggs, milk, bread"
```

번역, 요약, 목록으로 변환 같은 글쓰기 명령은 텍스트를 인수로 받으며, 기록에 채팅을 추가하지 않고 답변합니다. `enconvo agent main`은 에이전트가 가장 최근 채팅에서 작업 중이면 새 채팅에서 답변합니다.

해당하는 로컬 API 라우트는 `agent/call`(`agentId`, `message`, `context_files`)과 `ai-command/run`(`command_key`, `input_text`, `files`)입니다.

### 실행 중인 채팅 확인하기

- `agent/session/list`는 모든 에이전트와 프로젝트에서 지금 실행 중인 채팅을 Claude Code와 Codex 채팅까지 포함해 각각의 제목, 에이전트, 프로젝트와 함께 나열합니다. 답변을 기다리는 채팅만 보려면 `filter: "waiting"`을, 둘 다 보려면 `"active"`를 전달하세요.
- `agent/session/status`는 `sessionId`로 채팅 하나를 확인합니다.
- `agent/session/steer`는 채팅이 지금 진행 중인 턴을 멈추지 않고 메시지를 추가합니다. 실행 중이 아닌 채팅은 `not_running`으로 응답하므로, 대신 `agent/call`로 새 턴을 시작하세요. 전체 접근 권한 미만으로 실행 중이면 Enconvo 턴을 조종할 수 없습니다.

## 안전하게 사용하기

지식 베이스 검색만 필요한 AI 클라이언트에는 일반 로컬 API를 노출하는 대신 전용 [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp) 연결을 사용하세요.

로컬 API와 셸 접근은 강력한 기능으로 다루세요. 명령은 구현에 따라 로컬 데이터를 읽거나 수정할 수 있습니다. 스크립트에서는 명령, 입력, 대상을 명시적으로 지정하세요.

프로그램이 로컬 API로 설정을 읽으면 저장된 API 키는 `[hidden]`으로 반환되며, 저장된 키가 전송되는 대상은 Enconvo 자체 창에서만 바꿀 수 있습니다. [자격 증명](/ko/configuration/credentials)을 참고하세요.

로컬 API로 설정하는 단축키에는 짧은 수정자 이름(`cmd`, `ctrl`, `alt`, `opt`, `fn`)이나 수정자 기호를 쓸 수 있습니다. Enconvo가 모르는 단어가 들어간 단축키는 등록되지 않으며, 글자를 입력하는 키에는 Command, Control, Option 또는 Function이 필요합니다.

## 활용하기

- [확장 프로그램 개발](/ko/extensions/developing): 나만의 명령과 라우트를 추가합니다. 플러그인의 `src/api/`에 있는 파일이 여기서 라우트가 됩니다.
- [확장 프로그램 API 레퍼런스](/extensions/extension-api-reference): SDK의 진입점입니다.
- [훅](/ko/configuration/hooks): 에이전트가 작업하는 중 정해진 시점에 직접 만든 명령을 실행합니다. 훅은 JSON 설정에서 가져오며, **설정 → 훅**에서 로드된 훅을 확인할 수 있습니다.
- [예약 작업](/ko/workflows/scheduled-jobs): 원하는 시간에 작업을 실행합니다.
- [Linux 서버에서 Enconvo 설정하기](/ko/advanced/linux-server): Mac에서 추가한 서버의 모델, 에이전트, 플러그인을 같은 `enconvo` 명령으로 설정합니다.

description: "단축키나 SmartBar에서 복사한 내용, 브라우저 북마크, Mac의 파일을 검색하세요."
---

클립보드 기록, 브라우저 북마크 검색, 파일 검색은 입력하면서 검색하는 세 가지 빠른 목록입니다. 클립보드 기록은 이전에 복사한 내용을 붙여 넣을 때, 북마크 검색은 저장한 페이지를 어떤 브라우저에서든 열 때, 파일 검색은 Finder 없이 파일을 열 때 사용하세요. 각각 자체 단축키로 열리며, SmartBar에서는 별칭으로 열 수 있습니다.

## 목록 열기

1. **설정 → 단축키**나 **설정 → 플러그인** 아래의 해당 목록 설정 페이지에서 목록의 단축키를 설정하세요.
2. 단축키를 누르세요. 기본값인 **단축키로 별도 창 열기**가 켜져 있으면 목록이 별도의 창에서 열리고 SmartBar는 그대로 유지됩니다.
3. 입력해서 목록을 걸러내고, 화살표 키로 항목으로 이동한 다음 Return을 누르세요.

대신 SmartBar 안에서 목록을 열려면 **별칭**을 설정하세요. SmartBar에 별칭과 공백을 입력하면 그곳에서 목록이 열립니다. SmartBar 검색에는 각 목록의 별칭이 표시됩니다.

채팅에서 목록을 `@`로 멘션할 수도 있으며, 그러면 에이전트가 그 목록을 대신 검색합니다.

## 클립보드 기록에서 붙여넣기

클립보드 기록은 복사한 텍스트, 이미지, 파일을 보관합니다. 즐겨찾기를 고정하고 링크, 이메일, 색상, 이미지, 파일별로 필터링할 수 있습니다.

1. 클립보드 기록을 여세요.
2. 복사한 내용에서 단어를 입력하세요.
3. Return을 눌러 사용하던 앱에 항목을 붙여 넣으세요. 대신 복사하려면 **⌘C**를 누르세요. **Return 키**를 복사로 설정했다면 **⌘Return**이 붙여 넣기입니다.

Enconvo의 창 위에서 목록을 열면 Return이 그 창의 메시지 상자에 붙여 넣습니다.

암호 관리자와 키체인 접근은 기본으로 제외되며, 암호처럼 앱이 숨김이나 임시로 표시한 복사본은 기록되지 않습니다.

## 북마크 열기

브라우저 북마크 검색은 Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox, Zen의 북마크를 읽으며, 직접 선택한 폴더에 보관된 Firefox와 Zen 프로필도 포함합니다. 검색은 폴더 이름도 일치시킵니다.

Return을 누르면 북마크를 가져온 브라우저에서 열고, **⌘O**를 누르면 기본 브라우저에서 엽니다. **Return 키**는 둘을 서로 바꿉니다.

## 파일 찾기

파일 검색은 기본적으로 Mac 전체를 찾습니다. 검색란의 드롭다운으로 이번 검색에 한해 **내 폴더**, **홈**, **다운로드** 같은 한 곳만 검색할 수 있습니다.

Return을 누르면 파일을 열고, **⌘Return**을 누르면 Finder에서 보여 줍니다. **Return 키**는 둘을 서로 바꿉니다.

## 설정

**설정 → 플러그인**을 열고 **클립보드 기록**, **브라우저 북마크**, **파일 검색**을 선택하세요.

| 설정 | 목록 | 바뀌는 내용 |
| --- | --- | --- |
| **별칭** | 세 가지 모두 | SmartBar에 입력하고 공백을 입력하면 그곳에서 목록이 열리는 단어입니다. |
| **단축키로 별도 창 열기** | 세 가지 모두 | 켜짐: 단축키가 목록을 별도의 창에서 엽니다. 꺼짐: 단축키가 SmartBar에서 엽니다. 기본으로 켜져 있습니다. |
| **Return 키** | 세 가지 모두 | Return의 동작입니다. 클립보드 기록: **맨 앞 앱에 붙여넣기** 또는 **클립보드에 복사**. 북마크: **저장한 브라우저에서 열기** 또는 **기본 브라우저에서 열기**. 파일: **열기** 또는 **Finder에서 보기**. |
| **클립보드 기록 저장** | 클립보드 기록 | 복사한 내용의 기록을 보관합니다. 끄면 이미 저장된 항목은 유지됩니다. |
| **기록 보관 기간** | 클립보드 기록 | 항목이 남아 있는 기간이며 **1일**부터 **영구**까지입니다. 기본값은 3개월입니다. 고정한 항목은 삭제되지 않습니다. |
| **무시할 앱** | 클립보드 기록 | 복사 내용을 기록하지 않는 앱이며, 번들 ID로 지정합니다. |
| **폴더 이름 표시** | 북마크 | 각 북마크의 폴더를 표시합니다. |
| **꺼 둔 브라우저** | 북마크 | 북마크를 제외할 브라우저입니다. |
| **검색 위치** | 파일 | 파일 검색이 열릴 때 찾는 위치입니다. **이 Mac**, **내 폴더**, **홈**, **데스크탑**, **문서**, **다운로드**, **앱** 중에서 고르세요. |
| **검색할 폴더** | 파일 | **내 폴더**가 검색하는 폴더입니다. 비어 있으면 데스크탑, 문서, 다운로드입니다. |
| **숨김 파일 표시** | 파일 | 이름이 점으로 시작하는 파일을 포함합니다. |
| **제외한 폴더** | 파일 | 내용이 표시되지 않는 폴더입니다. |

이 목록들의 이전 웹 버전에서 설정한 단축키나 별칭은 그대로 이어집니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키가 창 대신 SmartBar를 엽니다 | 해당 목록의 **단축키로 별도 창 열기**를 켜세요. |
| 클립보드 기록에 복사한 내용이 없습니다 | **클립보드 기록 저장**과 **무시할 앱**을 확인하세요. 암호처럼 숨김 처리된 복사본은 기록되지 않습니다. |
| 브라우저의 북마크가 없습니다 | **꺼 둔 브라우저**를 확인하세요. |
| 파일이 표시되지 않습니다 | **검색 위치**, **제외한 폴더**, **숨김 파일 표시**를 확인하세요. |

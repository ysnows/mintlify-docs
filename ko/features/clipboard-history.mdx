---

클립보드 기록, 브라우저 북마크 검색, 파일 검색은 입력하면서 검색하는 세 가지 빠른 목록입니다. 클립보드 기록은 예전에 복사한 것을 붙여 넣고, 북마크 검색은 저장한 페이지를 아무 브라우저에서나 열며, 파일 검색은 Finder 없이 파일을 엽니다. 각각 자체 단축키로 열거나, 별칭으로 SmartBar에서 엽니다.

## 목록 열기

1. **설정 → 단축키**에서 목록의 단축키를 설정하거나, **설정 → 플러그인** 아래 목록 자체 설정 페이지에서 설정합니다.
2. 단축키를 누릅니다. 기본값인 **단축키로 창 열기**가 켜져 있으면 목록이 자체 창에서 열리고 SmartBar는 그대로입니다.
3. 입력해 목록을 걸러내고, 화살표 키로 항목으로 이동한 다음 Return을 누릅니다.

대신 SmartBar 안에서 목록을 열려면 **별칭**을 설정합니다. SmartBar에 별칭과 공백을 입력하면 목록이 그곳에서 열립니다. SmartBar 검색은 각 목록의 별칭을 보여 줍니다.

채팅에서 목록을 `@`로 언급할 수도 있으며, 에이전트가 그 목록을 대신 검색합니다.

## 클립보드 기록에서 붙여 넣기

클립보드 기록은 복사한 텍스트, 이미지, 파일을 보관합니다. 즐겨찾기를 고정하고 링크, 이메일, 색, 이미지, 파일로 걸러낼 수 있습니다.

1. 클립보드 기록을 엽니다.
2. 복사한 내용의 단어를 입력합니다.
3. Return을 눌러 쓰던 앱에 항목을 붙여 넣습니다. **⌘C**를 누르면 대신 복사합니다. **Return 키**가 복사로 설정되어 있으면 **⌘Return**이 붙여 넣습니다.

Enconvo 자체 창 위에서 목록을 열면 Return이 그 창의 메시지 칸에 붙여 넣습니다.

비밀번호 관리자와 키체인 접근은 기본적으로 제외되며, 앱이 숨김이나 임시로 표시한 복사(비밀번호 등)는 기록되지 않습니다.

## 북마크 열기

브라우저 북마크 검색은 Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox, Zen의 북마크를 읽으며, 선택한 폴더에 있는 Firefox와 Zen 프로필도 포함합니다. 검색은 폴더 이름도 일치합니다.

Return을 눌러 북마크가 온 브라우저에서 열거나, **⌘O**로 기본 브라우저에서 엽니다. **Return 키**는 둘을 바꿉니다.

## 파일 찾기

파일 검색은 기본적으로 Mac 전체를 봅니다. 검색 칸의 드롭다운으로 이번 검색만 한 곳을 검색할 수 있습니다. **내 폴더**, **홈**, **다운로드** 등입니다.

Return을 눌러 파일을 열거나, **⌘Return**으로 Finder에 표시합니다. **Return 키**는 둘을 바꿉니다.

## 설정

**설정 → 플러그인**을 연 다음 **클립보드 기록**, **브라우저 북마크**, **파일 검색**을 엽니다.

| 설정 | 목록 | 바뀌는 것 |
| --- | --- | --- |
| **별칭** | 세 가지 모두 | SmartBar에서 입력한 다음 공백을 넣어 목록을 그곳에서 여는 단어입니다. |
| **단축키로 창 열기** | 세 가지 모두 | 켜면 단축키가 자체 창에서 목록을 엽니다. 끄면 SmartBar에서 엽니다. 기본은 켜짐입니다. |
| **Return 키** | 세 가지 모두 | Return이 하는 일입니다. 클립보드 기록: **앞 앱에 붙여 넣기** 또는 **클립보드에 복사**. 북마크: **저장한 브라우저에서 열기** 또는 **기본 브라우저에서 열기**. 파일: **열기** 또는 **Finder에서 보기**. |
| **클립보드 기록 기록** | 클립보드 기록 | 복사한 것의 기록을 보관합니다. 끄면 이미 저장된 항목은 남습니다. |
| **기록 보관 기간** | 클립보드 기록 | 항목이 남는 기간입니다. **1일**부터 **영구**까지입니다. 기본은 3개월입니다. 고정한 항목은 제거되지 않습니다. |
| **무시하는 앱** | 클립보드 기록 | 복사가 기록되지 않는 앱입니다. 번들 ID로 지정합니다. |
| **폴더 이름 표시** | 북마크 | 각 북마크의 폴더를 보여 줍니다. |
| **끈 브라우저** | 북마크 | 북마크를 빼는 브라우저입니다. |
| **검색 위치** | 파일 | 파일 검색이 열릴 때 보는 곳입니다. **이 Mac**, **내 폴더**, **홈**, **데스크탑**, **문서**, **다운로드**, **앱**입니다. |
| **검색 폴더** | 파일 | **내 폴더**가 검색하는 폴더입니다. 비어 있으면 데스크탑, 문서, 다운로드입니다. |
| **숨은 파일 표시** | 파일 | 이름이 점으로 시작하는 파일을 포함합니다. |
| **제외 폴더** | 파일 | 내용이 절대 나오지 않는 폴더입니다. |

이 목록의 이전 웹 버전에서 설정한 단축키나 별칭은 이어집니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키가 창 대신 SmartBar를 염 | 그 목록의 **단축키로 창 열기**를 켭니다. |
| 복사가 클립보드 기록에 없음 | **클립보드 기록 기록**과 **무시하는 앱**을 확인합니다. 비밀번호 같은 숨긴 복사는 기록되지 않습니다. |
| 브라우저의 북마크가 없음 | **끈 브라우저**를 확인합니다. |
| 파일이 나오지 않음 | **검색 위치**, **제외 폴더**, **숨은 파일 표시**를 확인합니다. |

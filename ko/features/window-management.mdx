title: "창 관리"
description: "작업에 알맞은 Enconvo 창을 고르고, 각 창을 여는 단축키를 설정하며, 결과를 계속 화면에 띄워 두세요."
---

Enconvo는 같은 일상 작업도 상황에 따라 여러 창으로 시작할 수 있게 해 줍니다. 작업에 필요한 공간과 컨텍스트에 맞춰 창을 고르고, 자주 쓰는 단축키를 설정하세요.

## 창 선택하기

| 창 | 용도 | 여는 방법 | 가이드 |
| --- | --- | --- | --- |
| SmartBar | 빠른 질문이나 명령 실행 | **⌥Space** | [SmartBar](/ko/features/smartbar) |
| 채팅 창 | 기록과 파일이 있는 긴 대화 | **⌃⌘X** | [채팅 창](/ko/ai/chat) |
| 앱 사이드바 | 다른 앱 옆에서 작업 | **⌃⌘E** 또는 앱 창 옆의 핸들 | [앱 사이드바](/ko/features/app-sidebar) |
| PopBar | 선택한 텍스트에 바로 작업 | 텍스트 선택 | [PopBar](/ko/features/popbar) |
| Dynamic Island | 화면 상단에서 빠른 요청과 세션 확인 | 화면 상단 중앙에 마우스 올리기 | [Dynamic Island](/ko/features/dynamic-island) |
| 데스크톱 펫 | 바탕화면에 두고 에이전트 활동 확인 | 펫 클릭 | [데스크톱 펫](/ko/features/pet) |
| 아바타 | 에이전트 캐릭터와 음성으로 대화 | 가이드 참고 | [아바타](/ko/features/avatar) |

## 창을 여는 단축키 설정하기

**설정 → 단축키** 또는 각 기능의 설정 페이지에서 지정된 키 조합과 작동 방식을 확인하세요. SmartBar, 채팅 창, 앱 사이드바에는 기본 단축키가 있으며, Dynamic Island와 PopBar는 직접 설정하기 전까지 기본 단축키가 없습니다.

전역 단축키는 macOS, 입력기(IME) 또는 다른 앱과 충돌할 수 있습니다. 단축키로 창이 열리지 않으면 다른 곳에서 쓰지 않는 조합으로 지정하세요. 자세한 내용은 [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 참고하세요.

## 결과를 화면에 계속 띄워 두기

현재 사용 중인 창의 고정 버튼이나 창 컨트롤을 활용하세요. 다른 앱으로 돌아가도 SmartBar가 항상 위에 떠 있게 하려면 **SmartBar 고정**을 실행하거나 SmartBar에서 **⌘P**를 누르세요.

작업을 마치면 Escape 키를 누르거나 창의 닫기 버튼을 사용하세요. 창을 닫아도 대화 내용은 삭제되지 않습니다.

## Dock 아이콘

채팅 창이나 설정을 닫아도 Dock에 Enconvo 아이콘이 남아 있어 언제든 다시 열 수 있습니다. 창을 닫을 때 Dock 아이콘도 함께 숨기려면 **설정 → 채팅 창**에서 **창을 닫으면 Dock 아이콘 숨기기**를 켜세요.

Dock 아이콘 배지에는 아직 확인하지 않은 결과나 오류, 사용자의 승인이나 답변을 기다리는 채팅, 친구에게 온 읽지 않은 메시지 등 확인이 필요한 채팅 수가 표시됩니다.

Enconvo 창을 잠시 숨기려면 **⌘H**(**Enconvo 숨기기**)를 누르세요. 다시 창을 열 때까지 화면에서 숨겨집니다.

## 여러 디스플레이 사용하기

각 창의 설정에서 디스플레이 옵션, 특히 Dynamic Island의 **표시할 화면** 설정을 확인하세요. 디스플레이 배치를 변경한 뒤에는 창을 다시 열어 원하는 화면에 뜨는지 확인하는 것이 좋습니다. 앱 사이드바는 연결된 앱 창을 따라가며, 권한 상태나 해당 앱의 창 동작 방식에 따라 부착 위치가 달라질 수 있습니다.

## 결과가 표시되는 위치

일부 명령에는 결과가 나타날 위치를 정하는 **창 모드** 또는 출력 설정이 있습니다. 음성 입력 결과는 현재 앞쪽에 있는 앱에 바로 붙여 넣어질 수 있으므로 받아쓰기를 시작하기 전에 커서 위치를 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 창이 열리지 않음 | 단축키와 활성 디스플레이 설정, 다른 앱 창 뒤에 가려져 있는지 확인하세요. |
| 알고 있던 단축키를 눌러도 열리지 않음 | 기본 단축키는 SmartBar가 **⌥Space**, 채팅 창이 **⌃⌘X**입니다. 직접 설정한 키가 있다면 설정한 키가 그대로 유지됩니다. |
| 창을 닫은 뒤 Dock 아이콘을 없애고 싶음 | **설정 → 채팅 창**에서 **창을 닫으면 Dock 아이콘 숨기기**를 켜세요. |
| 여전히 열리지 않거나 권한이 부족함 | [문제 해결](/ko/getting-started/troubleshooting)을 참고하세요. |

---

Enconvo는 같은 일상 작업을 여러 방법으로 시작할 수 있게 해 줍니다. 작업에 필요한 공간과 컨텍스트의 양에 따라 하나를 고르고, 가장 자주 쓸 단축키를 설정하세요.

## 창 고르기

| 창 | 용도 | 여는 방법 | 가이드 |
| --- | --- | --- | --- |
| SmartBar | 빠른 질문이나 명령 실행 | **⌥Space** | [SmartBar](/ko/features/smartbar) |
| 채팅 창 | 기록과 파일이 있는 이어지는 대화 | **⌃⌘X** | [채팅 창](/ko/ai/chat) |
| 앱 사이드바 | 다른 앱 옆에서 작업 | **⌃⌘E** 또는 앱 창 옆의 핸들 | [앱 사이드바](/ko/features/app-sidebar) |
| PopBar | 선택한 텍스트에 작업 | 텍스트 선택 | [PopBar](/ko/features/popbar) |
| Dynamic Island | 화면 상단에서 빠른 요청 입력과 세션 확인 | 화면 상단 중앙에 포인터 올리기 | [Dynamic Island](/ko/features/dynamic-island) |
| 펫 | 에이전트 활동을 보여 주는 캐릭터를 데스크톱에 두기 | 펫 클릭 | [데스크톱 펫](/ko/features/pet) |
| 아바타 | 에이전트 캐릭터와 음성으로 대화 | 해당 가이드 참고 | [아바타](/ko/features/avatar) |

## 창을 여는 단축키 설정하기

**설정 → 단축키**나 기능 자체의 설정 페이지를 열어 지정된 조합과 활성화 방식을 확인하세요. SmartBar, 채팅 창, 앱 사이드바에는 기본 단축키가 있습니다. Dynamic Island와 PopBar는 직접 설정하기 전에는 없습니다.

전역 단축키는 macOS, 입력기, 다른 앱과 충돌할 수 있습니다. 단축키가 창을 열지 않으면 다른 곳에서 쓰지 않는 조합을 고르세요. [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 참고하세요.

## 결과를 계속 보이게 두기

지금 있는 창의 고정 또는 창 컨트롤을 사용하세요. 다른 앱으로 돌아가는 동안 SmartBar를 맨 위에 유지하려면 **Pin SmartBar**를 실행하거나 SmartBar에서 **⌘P**를 누르세요.

끝나면 Escape를 누르거나 창의 닫기 컨트롤을 사용하세요. 창을 닫아도 대화는 삭제되지 않습니다.

## Dock 아이콘

채팅 창이나 설정을 닫아도 Enconvo는 Dock에 남아 있으므로 그곳에서 다시 열 수 있습니다. 그 창들을 닫을 때 Dock 아이콘이 사라지게 하려면 **설정 → 채팅 창**에서 **닫을 때 Dock 아이콘 숨기기**를 켜세요.

Dock 아이콘의 배지는 확인이 필요한 채팅 수를 표시합니다. 아직 열어 보지 않은 결과나 실패, 승인이나 답변을 기다리는 채팅, 그리고 친구의 읽지 않은 메시지가 포함됩니다.

Enconvo의 창을 잠시 숨기려면 **⌘H**(**Enconvo 가리기**)를 누르세요. 창 하나를 다시 열 때까지 숨겨져 있습니다.

## 여러 디스플레이

각 창 설정의 디스플레이 옵션, 특히 Dynamic Island의 **표시 위치**를 확인하세요. 디스플레이 배열을 바꾼 뒤에는 창을 다시 열어 예상한 화면에 있는지 확인하세요. 앱 사이드바는 연결된 앱 창을 따라가며, 권한과 앱 자체의 창 동작이 연결 방식에 영향을 줄 수 있습니다.

## 결과가 나타나는 곳

일부 명령에는 결과가 나타나는 위치를 정하는 **창 모드**나 출력 설정이 있습니다. 음성 입력은 맨 앞 앱에 붙여 넣을 수도 있으므로, 받아쓰기 전에 커서가 어디에 있는지 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 창이 열리지 않습니다 | 단축키, 활성 디스플레이, 다른 앱 뒤에 있지 않은지 확인하세요. |
| 알고 있던 단축키가 아무것도 열지 않습니다 | 기본값은 SmartBar가 **⌥Space**, 채팅 창이 **⌃⌘X**입니다. 직접 지정한 키는 지정한 그대로 유지됩니다. |
| 창을 닫은 뒤 Dock 아이콘이 사라지게 하고 싶습니다 | **설정 → 채팅 창**에서 **닫을 때 Dock 아이콘 숨기기**를 켜세요. |
| 그래도 열리지 않거나 권한이 없습니다 | [문제 해결](/ko/getting-started/troubleshooting)을 참고하세요. |

글쓰기 도구는 어느 앱에서든 선택한 텍스트에 클릭 한 번으로 실행할 수 있는 명령 모음입니다. 글쓰기 중인 앱을 벗어나지 않고도 오탈자를 고치고, 어조를 바꾸고, 길이를 늘이거나 줄이고, 설명·요약하거나 목록이나 표로 변환할 수 있습니다.

## 선택한 텍스트 편집하기

1. 글을 쓰는 앱에서 텍스트를 선택합니다.
2. [PopBar](/ko/features/popbar)에서 명령을 클릭하거나 [SmartBar](/ko/features/smartbar)를 열어 명령을 검색합니다.
3. 결과를 확인합니다. **수정 사항 강조**가 켜져 있으면 명령이 추가하거나 삭제한 부분이 표시됩니다.
4. **붙여넣기**를 클릭해 선택한 텍스트를 바꾸거나 결과를 복사합니다.

각 명령은 원래 텍스트의 언어를 유지하며 결과만 반환합니다. **설명** 역시 선택한 텍스트의 언어로 답하며, 이전 실행과 이어서 처리하지 않고 매 실행을 독립적으로 다룹니다. 선택한 텍스트가 질문이나 지시 형태여도 명령은 그 질문에 답하는 대신 해당 문장 자체를 편집합니다.

<Tip>
신뢰하는 명령에 **인라인 모드**를 켜 두면 창을 띄우지 않고 실행되어 선택한 텍스트 위에 결과를 바로 붙여 넣습니다. [명령 변경하기](#명령-변경하기)를 참고하세요.
</Tip>

## 명령 선택하기

| 목적 | 명령 |
| --- | --- |
| 오류 교정 | 맞춤법 및 문법 수정, 교정 |
| 문장 개선 | 글 개선, 다듬기, 다시 쓰기, 원어민처럼, AI 편집 |
| 길이 조절 | 길게 쓰기, 짧게 쓰기, 간결하게 |
| 어조 변경 | 어조 변경: 친근하게, 자신감 있게, 캐주얼하게, 전문적으로 |
| 내용 이해 | 설명, 요약, 핵심 요점 추출 |
| 서식 변환 | 목록으로 변환, 표로 변환 |
| 이메일 | 이메일 다듬기, 답장 초안 작성 |
| X 게시물 | X용으로 다듬기, 280자에 맞추기, 스레드로 변환, X 답글 제안, X 인용 코멘트 제안 |
| 번역 | 번역기, 스크린샷 번역([번역](/ko/ai/translate) 참고) |
| 화면 내용 | 스크린샷 설명 |
| 받아쓰기 | 받아쓰기 다듬기, 받아쓰기 번역, 받아쓰기 편집, 온디바이스 정리([받아쓰기](/ko/features/dictation) 참고) |
| 짧은 표현 | 이모지 |

**원어민처럼**은 같은 언어 내에서 원어민이 쓰는 자연스러운 표현으로 문장을 다시 작성합니다. **이메일 다듬기**는 본래의 인사말, 끝인사, 이름을 유지하며 서명을 덧붙이지 않습니다. **답장 초안 작성**은 선택한 이메일의 언어와 어조에 맞춰 답장을 작성하고, AI가 알 수 없는 이름·날짜·결정 사항 자리에는 대괄호로 짧은 자리 표시자를 남깁니다.

## 명령 변경하기

**설정 → AI 명령**을 열고 **기본 제공** 아래에서 명령을 선택합니다. 해당 페이지에서 명령의 동작을 확인하고 **사용해 보기**로 텍스트에 미리 실행해 볼 수 있습니다.

| 설정 | 변경되는 항목 |
| --- | --- |
| **PopBar** | PopBar에 명령을 추가하거나 제거합니다 |
| **수정 사항 강조** | 결과에서 명령이 추가하고 삭제한 부분을 표시합니다 |
| **단축키** | 어느 앱에서든 선택한 텍스트에 명령을 실행합니다 |
| **인라인 모드** | 창 없이 실행하고 선택한 텍스트 위에 결과를 바로 붙여 넣습니다 |
| **완료 후 동작** | 완료되었을 때 결과를 어떻게 처리할지 지정합니다 |
| **AI 모델** | 이 명령이 사용하는 모델입니다. 기본값은 모든 AI 명령에 설정된 모델을 따릅니다 |

기본 제공 명령의 지침은 읽기 전용입니다. **사용자 지정**을 클릭하면 자유롭게 수정할 수 있는 복사본이 만들어집니다.

글쓰기 도구는 명령별로 따로 지정하지 않는 한 **설정 → AI 명령 → 모든 명령**에 설정된 모델로 실행됩니다. 같은 명령들은 **설정 → 플러그인 → 글쓰기 도구**에서도 볼 수 있으며, 결과 창의 **설정** 버튼을 누르면 해당 결과를 만든 명령 설정이 열립니다.

## 안정적인 결과 얻기

여러 방향으로 고쳐 쓸 수 있는 문장이라면 대상 독자와 목적을 함께 적어 주세요. 이름, 날짜, 수치, 인용 문구처럼 바뀌면 안 되는 항목은 명시하는 것이 좋습니다.

전송하기 전에는 항상 원본과 결과를 대조해 보세요. 유려한 문장이라도 뜻이 달라질 수 있습니다.

반복해서 쓰는 지시가 있다면 나만의 [AI 명령](/ko/features/ai-commands)을 만들어 보세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| PopBar에 명령이 보이지 않음 | 공간이 부족해 숨겨진 버튼이 있는 PopBar 끝의 **⌄**를 클릭하거나, **설정 → AI 명령**의 해당 명령 페이지에서 **PopBar**를 켜세요 |
| PopBar가 나타나지 않음 | [PopBar 문제 해결](/ko/features/popbar)을 참고하세요 |
| 결과가 예상과 다른 언어로 나옴 | 설명은 선택한 텍스트의 언어로 답합니다. 요약은 **응답 언어**를 따로 지정하지 않는 한 원문 언어를 유지합니다. 나머지 명령도 원문 언어를 유지합니다 |
| 결과가 원래 의미를 바꿈 | 붙여넣기 전에 수정하거나 원본 텍스트로 명령을 다시 실행하세요 |

글쓰기 도구는 어떤 앱에서든 선택한 텍스트에 사용할 수 있는 원클릭 명령 모음입니다. 글을 쓰는 앱을 벗어나지 않고 실수를 고치고, 어조를 바꾸고, 더 짧게 또는 길게 만들고, 설명하거나 요약하고, 목록이나 표로 바꿀 수 있습니다.

## 선택한 텍스트 편집

1. 글을 쓰고 있는 앱에서 텍스트를 선택합니다.
2. [PopBar](/ko/features/popbar)에서 명령을 클릭하거나, [SmartBar](/ko/features/smartbar)를 열고 명령을 검색합니다.
3. 결과를 확인합니다. **수정 사항 강조**가 켜져 있으면 결과에 명령이 추가한 내용과 삭제한 내용이 표시됩니다.
4. **붙여넣기**를 클릭하여 선택한 내용을 바꾸거나, 결과를 복사합니다.

각 명령은 텍스트의 언어를 유지하며 결과만 답합니다. **설명**도 선택한 텍스트의 언어로 답하고, 각 실행을 이전 실행의 연속이 아닌 독립적으로 처리합니다. 선택한 텍스트가 질문하거나 지시하는 내용이어도 명령은 그 문장을 편집할 뿐, 거기에 답하지 않습니다.

<Tip>
믿고 쓰는 명령에는 **인라인 모드**를 켜세요. 창 없이 실행되어 결과를 선택한 텍스트 위에 바로 붙여넣습니다. [명령 변경](#명령-변경)을 참고하세요.
</Tip>

## 명령 선택

| 목표 | 명령 |
| --- | --- |
| 오류 바로잡기 | 맞춤법 및 문법 수정, 교정 |
| 표현 개선 | 글 개선, 다듬기, 다시 쓰기, 원어민처럼, AI 편집 |
| 길이 바꾸기 | 더 길게, 더 짧게, 간결하게 |
| 어조 바꾸기 | 어조 변경: 친근하게, 자신감 있게, 캐주얼하게, 전문적으로 |
| 내용 이해 | 설명, 요약, 핵심 추출 |
| 형식 바꾸기 | 목록으로 변환, 표로 변환 |
| 이메일 | 이메일 다듬기, 답장 초안 작성 |
| X 게시물 | X용으로 다듬기, 280자에 맞추기, 스레드로 만들기, X 답글 제안, X 인용 댓글 제안 |
| 번역 | 번역기, 스크린샷 번역([번역](/ko/ai/translate) 참고) |
| 화면에 있는 내용 | 스크린샷 설명 |
| 받아쓰기 | 받아쓰기 다듬기, 받아쓰기 번역, 받아쓰기 편집, 온디바이스 정리([받아쓰기](/ko/features/dictation) 참고) |
| 짧은 표현 | 이모지 |

**원어민처럼**은 같은 언어로 원어민이 쓸 법한 방식으로 텍스트를 다시 씁니다. **이메일 다듬기**는 사용자가 쓴 인사말, 맺음말, 이름을 그대로 두고 서명을 추가하지 않습니다. **답장 초안 작성**은 선택한 이메일의 언어와 어조로 답장을 작성하며, 이름, 날짜, 결정 사항처럼 알 수 없는 내용은 대괄호 안의 짧은 자리 표시자로 남겨 둡니다.

## 명령 변경

**설정 → AI 명령**을 열고 **기본 제공** 아래에서 명령을 선택합니다. 해당 페이지에는 명령의 기능이 표시되며, **사용해 보기**로 먼저 일부 텍스트에 실행해 볼 수 있습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **PopBar** | PopBar에 명령을 추가하거나 제거합니다 |
| **수정 사항 강조** | 결과에 명령이 추가하고 삭제한 내용을 표시합니다 |
| **단축키** | 어떤 앱에서든 선택한 텍스트에 명령을 실행합니다 |
| **인라인 모드** | 창 없이 실행하고 결과를 선택한 텍스트 위에 붙여넣습니다 |
| **완료 후 동작** | 명령이 끝났을 때 답변으로 수행할 동작입니다 |
| **AI 모델** | 이 명령이 사용하는 모델입니다. 기본적으로 모든 AI 명령의 모델을 따릅니다 |

기본 제공 명령의 지침은 읽기 전용입니다. **사용자 지정**을 클릭하면 자유롭게 변경할 수 있는 나만의 사본을 만들 수 있습니다.

글쓰기 도구는 명령이 자체 모델을 지정하지 않는 한 **설정 → AI 명령 → 모든 명령**에서 지정한 모델로 실행됩니다. 같은 명령이 **설정 → 플러그인 → 글쓰기 도구**에도 나열되며, 결과 창의 **설정** 버튼은 해당 결과를 만든 명령을 엽니다.

## 신뢰할 수 있는 결과 얻기

다시 쓰는 방식이 여러 가지일 수 있다면 텍스트의 독자가 누구이고 무엇을 위한 글인지 알려 주세요. 이름, 날짜, 수치, 인용한 표현처럼 그대로 유지해야 할 내용을 명시하세요.

보내기 전에 항상 결과를 원본과 비교하세요. 유창한 출력이라도 의미가 바뀔 수 있습니다.

반복해서 쓰는 지침은 나만의 [AI 명령](/ko/features/ai-commands)으로 만드세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 명령이 PopBar에 없음 | 들어가지 못한 버튼이 모이는 PopBar 끝의 **⌄**를 클릭하거나, **설정 → AI 명령**의 해당 명령 페이지에서 **PopBar**를 켜세요 |
| PopBar가 나타나지 않음 | [PopBar 문제 해결](/ko/features/popbar)을 참고하세요 |
| 결과가 예상치 못한 언어로 나옴 | 설명은 선택한 텍스트의 언어로 답합니다. 요약은 **응답 언어**를 지정하지 않으면 텍스트의 언어를 유지합니다. 다른 명령은 텍스트의 언어를 유지합니다 |
| 결과가 의미를 바꿈 | 붙여넣기 전에 수정하거나, 원본 텍스트로 명령을 다시 실행하세요 |

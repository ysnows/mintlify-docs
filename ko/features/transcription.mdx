---

인터뷰나 강의 영상처럼 이미 가지고 있는 미디어에는 음성 텍스트 변환을 사용하세요. 실시간으로 녹음하는 회의는 **녹음**에, 자막 세션은 **실시간 자막**에 저장됩니다. 세 가지는 같은 녹음 보기를 공유하지만 서로 다른 소스를 나열합니다.

## 파일 가져오기

1. **설정 → 음성 텍스트 변환 모델**에서 모델을 고릅니다.
2. **설정 → 음성 텍스트 변환**을 열고 **추가**를 클릭한 다음 **오디오** 또는 **동영상**을 선택합니다. 목록이 비어 있으면 **파일 가져오기**를 클릭하세요. 오디오 파일, 비디오 파일, 폴더를 페이지에 끌어다 놓을 수도 있습니다.
3. 추출과 전사가 끝날 때까지 기다립니다. 여러 파일은 백그라운드에서 하나씩 전사되며, 긴 오디오 파일을 변환하는 동안에도 Enconvo를 계속 사용할 수 있습니다.
4. 항목을 열어 전사 내용과 처리 상태를 검토합니다.
5. 결과를 사용하기 전에 중요한 화자 이름, 용어, 수치를 바로잡습니다.

**전사** 명령을 실행해도 됩니다. 설정에는 **출력 형식**, **화자 분리**, **음성 텍스트 변환 제공업체**가 있습니다.

## 전사 내용 활용하기

저장된 항목을 열면 전사 내용, 요약, **AI에게 질문**을 볼 수 있습니다. 요약은 녹음과 같은 방식으로 작동하며, 측면 패널 상단에서 출력 언어와 템플릿을 고릅니다. [회의 녹음](/ko/features/meeting-recording)을 참고하세요. 모든 세부 사항이 정확히 인식되었다고 가정하지 말고 전사 내용에 대해 질문하세요. 타임스탬프, 구조화된 출력, 화자 분리가 제공되는지는 사용하는 제공업체와 명령에 따라 달라집니다.

어휘와 화자 이름은 [사전과 화자](/ko/configuration/speech-assets)를 참고하세요. 나중에 다른 문서와 함께 전사 내용을 찾으려면 [지식 베이스](/ko/ai/knowledge-base)를 참고하세요.

## 전사가 실패했을 때

Enconvo는 전사 실패와 음성이 없는 파일을 구분합니다. 오류와 진단 세부 정보를 읽어 보세요. 실패는 오디오 추출, 제공업체의 파일 제한, 계정 접근 권한, 또는 서비스 자체에서 발생할 수 있습니다. 제목 생성과 검색 인덱싱은 전사와 별개로 실패할 수 있습니다.

전사 내용이 이미 저장되어 있다면 같은 파일을 다시 가져오기 전에 제목이나 인덱싱 단계만 실패했는지 확인하세요. 전사 내용을 확인하기 전까지는 원본 미디어를 보관하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 전사 실패 | 오류와 세부 정보를 읽으세요. Enconvo Cloud Fast는 최대 300분의 녹음을 처리하며 큰 파일은 업로드 전에 다시 인코딩합니다. 서비스에 비해 파일이 너무 크거나 길면 분할하거나 더 긴 파일을 지원하는 모델을 고르세요. 비디오의 오디오를 읽을 수 없으면 WAV나 MP3 파일로 내보낸 뒤 그 파일을 전사하세요. |
| 제목이나 검색 인덱싱만 실패함 | 전사 내용은 저장되어 있으므로 파일을 다시 가져오지 마세요. 인덱싱이 실패했다면 **인덱싱 재시도**를 사용하세요. |
| 화자가 구분되지 않음 | 화자 분리를 지원하는 제공업체를 고르거나 **전사** 명령에서 **화자 분리**를 켜세요. |
| **이 파일들은 이미 전사 목록에 있습니다** | 파일을 이전에 가져왔습니다. 기존 항목을 여세요. |

---

인터뷰나 강의 동영상처럼 이미 있는 미디어에는 음성 텍스트 변환을 쓰세요. 실시간으로 녹음하는 회의는 **녹음**에, 자막 세션은 **실시간 자막**에 있습니다. 셋은 같은 녹음 보기를 쓰지만 다른 소스를 나열합니다.

## 파일 가져오기

1. **설정 → 음성 텍스트 변환 모델**에서 모델을 고릅니다.
2. **설정 → 음성 텍스트 변환**을 열고 **추가**를 클릭한 다음 **오디오** 또는 **동영상**을 고릅니다. 빈 목록에서는 **파일 가져오기**를 클릭합니다. 오디오 파일, 동영상 파일, 폴더를 페이지에 놓을 수도 있습니다.
3. 추출과 음성 텍스트 변환이 끝나기를 기다립니다. 여러 파일은 백그라운드에서 한 번에 하나씩 변환되며, 긴 오디오 파일이 변환되는 동안에도 Enconvo를 쓸 수 있습니다.
4. 항목을 열고 대화 기록과 처리 상태를 검토합니다.
5. 결과를 쓰기 전에 중요한 화자 이름, 용어, 숫자를 고칩니다.

**Transcribe** 명령을 실행할 수도 있습니다. 설정에는 **출력 형식**, **화자 분리**, **음성 텍스트 변환 제공업체**가 있습니다.

## 대화 기록 사용

저장된 항목을 열어 대화 기록, 요약, **AI에게 묻기**를 읽습니다. 요약은 녹음과 같이 동작합니다. 옆 패널 위에서 출력 언어와 템플릿을 고르세요. [회의 녹음](/ko/features/meeting-recording)을 보세요. 모든 세부 사항이 정확히 인식됐다고 가정하지 말고 대화 기록에 대해 질문하세요. 타임스탬프, 구조화된 출력, 화자 분리를 받는지는 쓰는 제공업체와 명령이 결정합니다.

어휘와 화자 이름은 [사전과 화자](/ko/configuration/speech-assets)를 보세요. 나중에 다른 문서와 함께 대화 기록을 찾으려면 [지식 베이스](/ko/ai/knowledge-base)를 보세요.

## 음성 텍스트 변환이 실패할 때

Enconvo는 음성 텍스트 변환 실패와 음성이 없는 파일을 구분합니다. 오류와 진단 세부 정보를 읽으세요. 실패는 오디오 추출, 제공업체의 파일 제한, 계정 접근, 서비스 자체에서 올 수 있습니다. 제목 생성과 검색 색인은 음성 텍스트 변환과 따로 실패할 수 있습니다.

대화 기록이 이미 저장되어 있으면, 같은 파일을 다시 가져오기 전에 제목이나 색인 단계만 실패했는지 확인하세요. 대화 기록을 확인할 때까지 원본 미디어를 보관하세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 음성 텍스트 변환 실패 | 오류와 세부 정보를 읽으세요. Enconvo Cloud Fast는 최대 300분 녹음을 받고, 업로드 전에 큰 파일을 다시 인코딩합니다. 파일이 서비스에 너무 크거나 길면 나누거나 더 긴 파일을 지원하는 모델을 고르세요. 동영상의 오디오를 읽을 수 없으면 WAV나 MP3로 보낸 다음 그 파일을 변환하세요. |
| 제목이나 검색 색인만 실패 | 대화 기록은 저장되어 있으므로 파일을 다시 가져오지 마세요. 색인이 실패했으면 **색인 다시 시도**를 쓰세요. |
| 화자가 분리되지 않음 | 화자 분리를 지원하는 제공업체를 고르거나, **Transcribe** 명령에서 **화자 분리**를 켭니다. |
| **이 파일은 이미 음성 텍스트 변환에 있음** | 파일을 전에 가져왔습니다. 기존 항목을 엽니다. |

음성 메모는 말한 아이디어를 지식 베이스에 녹음해 두어 나중에 찾을 수 있게 합니다. 다른 앱에 텍스트를 입력하고 싶다면 [받아쓰기](/ko/features/dictation)를 사용하세요.

## 시작하기 전에

메모를 저장할 [지식 베이스](/ko/ai/knowledge-base)를 만들거나 고르세요. 음성 메모는 단축키를 설정하기 전까지는 단축키가 없습니다.

## 단축키 설정하기

1. **설정 → 음성 메모**를 엽니다.
2. **음성 메모 단축키**를 클릭하고 원하는 단축키를 누릅니다. 누르고 있을지 한 번 누를지 선택합니다.
3. **저장 위치**를 메모가 들어갈 지식 베이스로 설정합니다. 처음에는 **기본 지식 베이스**로 되어 있습니다.

## 메모 녹음하기

1. **음성 메모 단축키**를 누르고 짧은 메모를 말합니다. 누르고 있는 모드에서는 말하는 동안 단축키를 누른 채로 있습니다.
2. 단축키에서 손을 떼거나 녹음 컨트롤로 녹음을 끝냅니다. 메모가 저장됩니다.
3. 저장할 지식 베이스를 열어 저장된 항목과 전사 내용을 검토합니다.

## 메모를 더 쉽게 찾을 수 있게 하기

녹음에서 주제와 유용한 이름을 말하세요. 예를 들면 "Atlas 프로젝트: 디자이너에게 업데이트된 온보딩 아이콘을 요청하기." 중요한 이름, 숫자, 날짜는 의존하기 전에 전사 내용에서 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키가 아무 반응이 없음 | **음성 메모 단축키**를 설정하고 **설정 → 빠른 캡처**에서 **빠른 캡처 활성화**가 켜져 있는지 확인하세요. 이 스위치가 빠른 캡처와 음성 메모 단축키를 모두 켭니다. |
| 오디오가 없음 | 마이크 권한과 선택한 입력 장치를 확인하세요. |
| 메모가 예상한 곳에 없음 | **설정 → 음성 메모**의 **저장 위치**를 확인하세요. |
| 전사 실패 | 같은 메모를 다시 녹음하기 전에 오류를 읽고 설정된 음성 제공업체를 확인하세요. |

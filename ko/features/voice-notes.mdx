음성 메모는 말한 아이디어를 녹음해 지식 베이스에 저장하므로 나중에 다시 찾을 수 있습니다. 다른 앱에 텍스트를 바로 입력하려면 [받아쓰기](/ko/features/dictation)를 사용하세요.

## 시작하기 전에

메모를 저장할 [지식 베이스](/ko/ai/knowledge-base)를 만들거나 선택하세요. 단축키를 지정하기 전에는 음성 메모 단축키가 설정되어 있지 않습니다.

## 단축키 설정하기

1. **설정 → 음성 메모**를 엽니다.
2. **음성 메모 단축키**를 클릭하고 원하는 단축키를 누릅니다. 길게 누르기 방식과 한 번 누르기 방식 중 선택하세요.
3. 메모가 저장될 지식 베이스로 **저장 위치**를 설정합니다. 기본값은 **기본 지식 베이스**입니다.

## 메모 녹음하기

1. **음성 메모 단축키**를 누르고 짧은 메모를 말합니다. 길게 누르기 모드에서는 말하는 동안 단축키를 누르고 계세요.
2. 녹음을 마치려면 단축키에서 손을 떼거나 녹음 컨트롤을 사용합니다. 메모가 저장됩니다.
3. 대상 지식 베이스를 열어 저장된 항목과 음성 텍스트 변환 결과를 확인합니다.

## 메모를 더 쉽게 찾으려면

녹음할 때 주제와 유용한 이름을 함께 말하세요. 예를 들면 “Atlas 프로젝트: 디자이너에게 업데이트된 온보딩 아이콘 요청하기”처럼 말하면 좋습니다. 중요한 이름, 숫자, 날짜는 활용하기 전에 변환된 텍스트에서 정확히 맞는지 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키를 눌러도 아무 일도 일어나지 않음 | **음성 메모 단축키**를 설정하고 **설정 → 빠른 캡처**에서 **빠른 캡처 활성화**가 켜져 있는지 확인하세요. 이 스위치는 빠른 캡처와 음성 메모 단축키를 모두 켭니다. |
| 오디오가 입력되지 않음 | 마이크 권한과 선택한 입력 장치를 확인하세요. |
| 메모가 예상한 위치에 없음 | **설정 → 음성 메모**에서 **저장 위치**를 확인하세요. |
| 음성 텍스트 변환에 실패함 | 오류 메시지를 읽고 같은 메모를 다시 녹음하기 전에 구성된 음성 제공업체를 확인하세요. |

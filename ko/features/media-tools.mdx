---

미디어 유틸리티는 일상적인 미디어 작업을 위한 로컬 명령입니다. 이미지, 동영상, 오디오 파일을 작게 만들고, 동영상의 사운드트랙을 저장하거나, 웹 페이지에서 동영상을 받습니다. SmartBar나 **설정 → 플러그인**에서 찾습니다.

| 명령 | 하는 일 | 저장 위치 |
| --- | --- | --- |
| **이미지 압축** | 하나 이상의 이미지, 또는 폴더와 하위 폴더의 모든 이미지를 조정 가능한 품질로 압축합니다 | 원본 이미지를 바꿉니다 |
| **동영상 압축** | 동영상 파일을 작게 만듭니다 | `~/Downloads` |
| **오디오 압축** | 고른 품질로 오디오 파일을 작게 만들고 커버 아트를 유지합니다(MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **오디오 추출** | 동영상, 또는 폴더의 모든 동영상의 오디오 트랙을 M4A로 저장합니다(트랙을 복사할 수 없으면 MP3) | `~/.cache/enconvo/transcribe` |
| **온라인 동영상 다운로더** | YouTube, TikTok, Instagram, Reddit, X, Vimeo 같은 링크에서 동영상이나 오디오를 받습니다 | `~/Downloads` |

<Warning>
**이미지 압축**은 기본적으로 원본 이미지를 바꿉니다. 원본을 남기려면 먼저 설정에서 **원본 이미지 파일 덮어쓰기**를 끄세요. 그러면 압축본이 이미지 옆의 `enconvo-compressed-images` 폴더로 갑니다.
</Warning>

## 파일 압축 또는 오디오 추출

1. Finder에서 파일을 선택하거나 첨부합니다. 이미지 압축은 폴더도 고를 수 있습니다. 그 이미지와 하위 폴더의 이미지가 압축되며, 복사본은 같은 폴더 구조를 유지합니다.
2. SmartBar를 열고 명령을 실행합니다.
3. 출력을 열어 확인합니다.

압축 설정을 시험하는 동안 원본을 보관하세요. 각 명령의 설정은 **설정 → 플러그인**에 있습니다. 이미지 압축은 **Image Utils**, 나머지는 **Media Utils**입니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **품질** | 0에서 100까지입니다. 높을수록 품질이 높고 파일이 커집니다. 기본은 80입니다 |
| **대상 폴더 경로** | 압축 파일이 가는 곳입니다. 절대 경로이거나 파일 기준 상대 경로입니다 |
| **원본 … 파일 덮어쓰기** | 원본 파일을 바꿉니다. 이미지는 기본으로 켜져 있고, 동영상과 오디오는 꺼져 있습니다 |

## 동영상 받기

1. 브라우저에서 동영상 페이지를 열거나 링크를 복사합니다.
2. SmartBar에서 **온라인 동영상 다운로더**를 실행합니다. 브라우저의 활성 탭 링크를 쓰거나, 입력한 링크를 씁니다.
3. Dynamic Island에서 진행을 따르며 취소할 수 있습니다. 끝나면 **Finder에서 보기**를 클릭합니다.

다운로드는 채팅 기록에 저장되며, 이미 받은 파일은 다시 받지 않고 재사용됩니다. 사이트가 되는지는 사이트와 접근을 허용하는 범위에 따릅니다. 저장이 허용된 콘텐츠만 받으세요.

| 설정 | 바뀌는 것 |
| --- | --- |
| **출력 디렉터리** | 다운로드가 가는 곳입니다. 기본은 `~/Downloads`입니다 |
| **오디오만** | 오디오만 받습니다 |
| **선호 해상도** | 받을 해상도입니다. **최상**(기본)부터 144p까지입니다 |
| **호환 MP4로 강제 변환** | 어디서나 재생되는 MP4로 변환합니다. 기본은 켜짐이며 시간과 CPU가 더 듭니다 |
| **브라우저 쿠키 사용** | 본인만 볼 수 있는 동영상을 위해 브라우저 쿠키로 로그인합니다. **브라우저**에서 브라우저를 고릅니다 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **압축할 이미지가 없음** | Finder에서 이미지를 선택하거나 첨부한 다음 명령을 다시 실행합니다 |
| 변환 실패 | 파일 형식, 출력 폴더에 쓸 수 있는지, 디스크 여유 공간을 확인합니다 |
| 비공개 동영상이 받아지지 않음 | **브라우저 쿠키 사용**을 켜고 로그인한 브라우저를 고릅니다 |
| 사이트의 다운로드가 멈추고 작동하지 않음 | 오류를 읽고 플러그인을 업데이트한 다음 다시 시도합니다. 웹사이트는 형식과 접근 규칙을 바꿉니다 |

---

미디어 유틸리티는 일상적인 미디어 작업을 위한 로컬 명령입니다. 이미지, 동영상, 오디오 파일을 더 작게 만들고, 동영상의 사운드트랙을 저장하고, 웹페이지의 동영상을 다운로드할 수 있습니다. SmartBar 또는 **설정 → 플러그인**에서 찾을 수 있습니다.

| 명령 | 기능 | 저장 위치 |
| --- | --- | --- |
| **이미지 압축** | 하나 이상의 이미지 또는 폴더와 그 하위 폴더에 있는 모든 이미지를 품질을 조절하여 압축합니다 | 원본 이미지를 대체 |
| **동영상 압축** | 동영상 파일을 더 작게 만듭니다 | `~/Downloads` |
| **오디오 압축** | 선택한 품질에 맞춰 오디오 파일을 더 작게 만들고 커버 아트를 유지합니다(MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **오디오 추출** | 동영상 또는 폴더에 있는 모든 동영상의 오디오 트랙을 M4A로 저장합니다(트랙을 복사할 수 없으면 MP3) | `~/.cache/enconvo/transcribe` |
| **온라인 동영상 다운로더** | YouTube, TikTok, Instagram, Reddit, X, Vimeo 같은 링크의 동영상이나 오디오를 다운로드합니다 | `~/Downloads` |

<Warning>
**이미지 압축**은 기본적으로 원본 이미지를 대체합니다. 원본을 보관하려면 먼저 설정에서 **원본 이미지 파일 덮어쓰기**를 끄세요. 그러면 압축된 사본이 이미지 옆의 `enconvo-compressed-images` 폴더에 저장됩니다.
</Warning>

## 파일 압축 또는 오디오 추출

1. Finder에서 파일을 선택하거나 첨부합니다. 이미지 압축의 경우 폴더를 선택할 수도 있습니다. 해당 폴더와 하위 폴더의 이미지가 압축되며, 사본은 같은 폴더 구조를 유지합니다.
2. SmartBar를 열고 명령을 실행합니다.
3. 출력을 열어 확인합니다.

압축 설정을 시험해 보는 동안에는 원본을 보관하세요. 각 명령의 설정은 **설정 → 플러그인**에 있습니다. 이미지 압축은 **이미지 유틸리티**, 나머지는 **미디어 유틸리티**입니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **품질** | 0에서 100까지. 높을수록 품질이 더 유지되고 파일이 커집니다. 기본값은 80입니다 |
| **대상 폴더 경로** | 압축된 파일이 저장되는 위치. 절대 경로 또는 파일 기준 상대 경로 |
| **원본 … 파일 덮어쓰기** | 원본 파일을 대체합니다. 이미지는 기본값이 켜짐이고 동영상과 오디오는 꺼짐입니다 |

## 동영상 다운로드

1. 브라우저에서 동영상 페이지를 열거나 링크를 복사합니다.
2. SmartBar에서 **온라인 동영상 다운로더**를 실행합니다. 브라우저의 활성 탭에서 링크를 가져오거나, 입력한 링크를 사용합니다.
3. Dynamic Island에서 진행 상황을 확인하며, 여기서 취소할 수 있습니다. 완료되면 **Finder에서 보기**를 클릭합니다.

다운로드는 채팅 기록에 저장되며, 이미 다운로드한 파일은 다시 가져오지 않고 재사용합니다. 사이트가 작동하는지는 해당 사이트와 접근 허용 범위에 따라 다릅니다. 저장이 허용된 콘텐츠만 다운로드하세요.

| 설정 | 변경되는 내용 |
| --- | --- |
| **출력 디렉터리** | 다운로드가 저장되는 위치. 기본값은 `~/Downloads`입니다 |
| **오디오만** | 오디오만 다운로드합니다 |
| **선호 해상도** | 다운로드할 해상도. **최고**(기본값)부터 144p까지 |
| **호환 MP4로 강제 변환** | 동영상을 어디서나 재생되는 MP4로 변환합니다. 기본값은 켜짐이며 시간과 CPU가 더 필요합니다 |
| **브라우저 쿠키 사용** | 본인만 볼 수 있는 동영상을 위해 브라우저의 쿠키로 로그인합니다. **브라우저**에서 브라우저를 선택하세요 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **압축할 이미지가 없습니다** | Finder에서 이미지를 선택하거나 첨부한 다음 명령을 다시 실행하세요 |
| 변환이 실패함 | 파일 형식, 출력 폴더에 쓸 수 있는지, 디스크 여유 공간이 있는지 확인하세요 |
| 비공개 동영상이 다운로드되지 않음 | **브라우저 쿠키 사용**을 켜고 로그인한 브라우저를 선택하세요 |
| 특정 사이트에서 다운로드가 작동하지 않음 | 오류를 읽고 다시 시도하기 전에 플러그인을 업데이트하세요. 웹사이트는 형식과 접근 규칙을 바꿉니다 |

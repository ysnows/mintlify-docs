title: "실시간 자막"
description: "오디오가 재생되는 동안 실시간으로 자막을 보고, 자막 세션을 나중에 다시 확인하세요."
---

실시간 자막은 강연, 영상, 통화처럼 오디오가 재생되거나 캡처되는 동안 화면에 자막을 바로 보여 줍니다. 각 세션은 가져온 음성 변환 파일이나 회의 녹음과는 별도의 목록으로 저장됩니다.

## 자막 시작하기

1. **설정 → 자막 모델**을 열고 실시간 인식을 지원하는 모델을 선택합니다.
2. **설정 → 실시간 자막**을 열고 **추가**를 클릭한 뒤 **자막 시작**을 선택합니다. 목록이 비어 있다면 **자막 시작**을 바로 클릭하세요. **실시간 자막 시작** 명령을 실행하거나 Enconvo 메뉴 막대 메뉴에서 **실시간 자막 시작**을 선택할 수도 있습니다.
3. **자막 시작** 창에서 오디오 소스, 자막 막대가 열릴 위치, 표시할 화면을 선택합니다. macOS가 마이크 또는 시스템 오디오 접근 권한을 요청하면 허용하세요.
4. 따라 읽고 싶은 오디오를 재생하고 자막이 나타나는지 확인합니다.
5. 끝나면 자막을 중지한 뒤 **실시간 자막** 목록에서 저장된 세션을 열어 볼 수 있습니다.

단축키로 자막을 켜고 끄려면 **설정 → 단축키**의 **음성** 아래에서 실시간 자막 단축키를 설정하세요. 실행 중인 상태에서 같은 단축키를 누르면 자막이 중지됩니다.

## 자막 막대 위치 지정하기

자막 막대는 네 가지 위치 중 한 곳에 열립니다.

| 위치 | 형태 |
| --- | --- |
| **왼쪽** | 화면 왼쪽 가장자리에 세로 열 형태로 표시됩니다. 기본값입니다. |
| **오른쪽** | 화면 오른쪽 가장자리에 세로 열 형태로 표시됩니다. |
| **상단 중앙** | 화면 상단에 가로 줄 형태로 열리며, 넓은 자막 영역 옆에 제어 버튼이 놓입니다. |
| **하단 중앙** | 화면 하단에 자막처럼 가로 줄 형태로 표시됩니다. |

디스플레이가 여러 대라면 표시할 화면도 선택하거나 **포인터가 있는 화면**을 유지하세요. 세션 중에도 자막 막대를 마우스 오른쪽 버튼으로 클릭해 위치나 화면을 바꿀 수 있습니다. 어느 위치에서든 자막 영역의 가장자리를 드래그해 크기를 조절할 수 있습니다.

## 자막 번역하기

일부 음성 제공업체는 원본 언어와 대상 언어를 지정하거나 음성 번역까지 포함한 실시간 번역을 제공합니다. 선택한 자막 모델의 자체 설정에서 이 기능을 켜세요. Enconvo Cloud Fast와 Soniox에서는 **원본 언어**와 **번역 대상 언어**를 사용합니다. 모든 음성 모델이 실시간 번역을 지원하는 것은 아니며, 파일 변환을 지원하는 모델이라도 실시간 자막은 지원하지 않을 수 있습니다.

## 세션 다시 보기

저장된 세션을 열면 대화록과 처리 결과를 다시 검토할 수 있습니다. 정확도가 중요할 때는 오디오를 다시 들으며 이름, 숫자, 화자 표시를 확인하세요. 자주 쓰는 어휘와 화자 이름을 최신 상태로 유지하려면 [사전 및 화자](/ko/configuration/speech-assets)를 활용하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 자막이 나오지 않음 | 오디오 소스, 입력 음량, 캡처 권한, 선택한 모델을 확인하세요. |
| 중지한 뒤에야 텍스트가 나타남 | 실시간 스트리밍을 지원하는 모델을 선택하세요. |
| 다른 언어로 인식됨 | 모델 설정에서 인식 언어 또는 언어 힌트를 지정하세요. |
| 번역이 되지 않음 | 해당 모델이 번역을 지원하는지 확인하고 대상 언어를 설정하세요. |
| 세션에 처리 오류가 표시됨 | 저장된 항목의 오류 세부 내용을 확인하세요. 음성이 유실되었다고 단정 짓지 마세요. |

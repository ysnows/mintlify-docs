---

실시간 자막은 강연, 동영상, 통화처럼 오디오가 재생되거나 캡처되는 동안 자막을 보여 줍니다. 각 세션은 가져온 음성 텍스트 변환 파일과 회의 녹음과는 별도의 목록에 저장됩니다.

## 자막 시작하기

1. **설정 → 자막 생성 모델**을 열고 실시간 인식을 지원하는 모델을 선택합니다.
2. **설정 → 실시간 자막**을 열고 **추가**를 클릭한 다음 **자막 시작**을 선택합니다. 목록이 비어 있으면 **자막 시작**을 클릭하세요. **실시간 자막 시작** 명령을 실행하거나 Enconvo의 메뉴 막대 메뉴에서 **실시간 자막 시작**을 선택해도 됩니다.
3. **실시간 자막 시작** 창에서 오디오 소스, 자막 막대가 열릴 위치, 그리고 그 화면을 선택합니다. macOS가 요청하면 마이크 또는 시스템 오디오 접근을 허용하세요.
4. 따라가고 싶은 오디오를 재생하고 자막이 나타나는지 확인합니다.
5. 끝나면 자막을 중지한 다음 **실시간 자막** 목록에서 저장된 세션을 엽니다.

키로 자막을 시작하고 중지하려면 **설정 → 단축키**의 **음성**에서 실시간 자막의 단축키를 설정하세요. 같은 단축키가 실행 중인 자막도 중지합니다.

## 자막 막대 위치 정하기

자막 막대는 네 가지 위치 중 한 곳에서 열립니다.

| 위치 | 모양 |
| --- | --- |
| **왼쪽** | 화면 왼쪽 가장자리의 세로 열입니다. 기본값입니다. |
| **오른쪽** | 오른쪽 가장자리의 세로 열입니다. |
| **상단 중앙** | 상단의 가로 줄이며, 넓은 자막 영역 옆에 컨트롤이 있습니다. |
| **하단 중앙** | 하단의 가로 줄이며, 자막이 영화 자막처럼 정렬됩니다. |

디스플레이가 둘 이상이면 화면도 고르거나 **포인터가 있는 화면**을 유지하세요. 세션 중에 자막 막대를 마우스 오른쪽 버튼으로 클릭하면 위치나 화면을 바꿀 수 있습니다. 어느 위치에서든 자막 영역의 가장자리를 끌어 크기를 조절할 수 있습니다.

## 자막 번역하기

일부 음성 제공업체는 원본 언어와 대상 언어를 지정하는 실시간 번역이나 음성 번역을 제공합니다. 선택한 자막 생성 모델 자체의 설정에서 켜세요. Enconvo Cloud Fast와 Soniox는 **원본 언어**와 대상 언어 설정을 사용합니다. 모든 음성 모델이 실시간 번역을 지원하는 것은 아니며, 파일 전사를 지원한다고 해서 실시간 자막을 지원하는 것은 아닙니다.

## 세션 검토하기

저장된 세션을 열어 전사 내용과 처리 결과를 검토하세요. 정확도가 중요할 때는 이름, 숫자, 화자 라벨을 오디오와 대조해 확인하세요. [사전과 화자](/ko/configuration/speech-assets)로 어휘와 화자 이름을 최신 상태로 유지하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 자막이 없음 | 오디오 소스, 입력 레벨, 캡처 권한, 선택한 모델을 확인하세요. |
| 중지한 뒤에야 텍스트가 나타남 | 스트리밍 모델을 선택하세요. |
| 언어가 틀림 | 모델 설정에서 인식 언어나 언어 힌트를 지정하세요. |
| 번역이 없음 | 모델이 번역을 지원하는지 확인하고 대상 언어를 지정하세요. |
| 세션에 처리 오류가 표시됨 | 저장된 항목에서 오류 세부 정보를 읽으세요. 음성이 없다고 단정하지 마세요. |

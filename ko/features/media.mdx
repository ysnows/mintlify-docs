**미디어**는 Enconvo에서 만든 모든 이미지, 동영상, 오디오 클립의 한곳입니다. 여기서 만들었든 채팅의 에이전트가 만들었든 마찬가지입니다. 설정을 완전히 제어하며 그림과 클립을 생성하고, 사람이나 제품이 여러 결과에서 같게 보이게 하고, 만든 것을 고치거나 다시 쓰세요.

**설정 → 이미지 생성**과 **설정 → 동영상 생성**에 설정한 제공업체를 씁니다. 설정은 [이미지 생성](/ko/ai/image-generation)과 [동영상 생성](/ko/ai/video-generation)을 보세요.

## 미디어 열기

채팅 창 사이드바에서 **미디어**를 클릭합니다. 위에서 **이미지**, **동영상**, **오디오**를 고릅니다.

- **모두**, **즐겨찾기**, 폴더가 만든 것을 나눕니다. **새 폴더**를 클릭해 추가하고, 항목의 **폴더로 이동**으로 넣습니다.
- **미디어 검색**에 입력해 프롬프트의 단어로 항목을 찾습니다.
- 별을 클릭해 항목을 **즐겨찾기**에 추가합니다.

파일은 Mac의 `~/Enconvo/Media`에도 있습니다.

새 채팅의 메시지 상자 아래에서 **이미지**나 **동영상**을 고를 수도 있습니다. 모델, 설정, 피할 내용이 메시지 상자 아래 알약으로 나오며, 최근 이미지나 동영상과 그 아래 **미디어 열기** 링크가 있습니다.

## 이미지나 동영상 만들기

1. **이미지**나 **동영상**에서 아래 작성기에 원하는 것을 설명합니다.
2. 아래 알약을 확인합니다. 모델, **화면 비율**, **품질**, 이미지 수, **피하기**(빼야 할 것). 알약을 클릭해 바꾸거나, 나머지는 **설정 더 보기**를 씁니다. 고른 모델이 받는 설정만 나타납니다.
3. **생성**을 클릭합니다. 끝나는 대로 새 항목이 위에 나타납니다.

여러 시안을 요청하면 남길 것을 고릅니다.

### 동영상의 추가 제어

- **시작 프레임**과 **끝 프레임**: 클립이 시작하거나 끝나는 그림을 추가합니다.
- **샷 추가**: 동영상을 샷으로 나누고, 각 샷에 자체 프롬프트와 길이를 둡니다. Enconvo가 하나의 동영상으로 이어 붙입니다.
- **오디오 파일 추가**: 자신의 오디오, 또는 **오디오**의 클립을 씁니다.

## 주제나 스타일을 같게 유지

사람, 반려동물, 제품, 캐릭터의 사진 몇 장을 주제로 저장하거나, 원하는 모습의 그림 몇 장을 스타일로 저장합니다. 생성할 때 고르면 모든 그림과 동영상에서 같게 보입니다.

1. 작성기에서 **주제, 스타일 또는 참조 추가**를 클릭합니다.
2. **주제** 아래 **사진으로 새로 만들기**, 또는 **스타일** 아래 **새 스타일**을 고릅니다.
3. **이름**을 주고 **사진**을 추가하고, 원하면 **설명**합니다.
4. **저장**을 클릭합니다. 다음에 생성할 때 같은 메뉴에서 고릅니다.

## 만든 것 다듬기

항목을 클릭하면 세부 정보가 열립니다. 프롬프트와 사용한 모든 설정입니다. 거기서:

| 동작 | 하는 일 |
| --- | --- |
| **설정 다시 사용** | 같은 프롬프트와 설정으로 작성기를 채웁니다 |
| **동영상으로 바꾸기** | 이 그림으로 동영상을 시작합니다 |
| **업스케일** | 더 크고 선명한 사본을 만듭니다 |
| **배경 제거** | 주제를 오려 냅니다 |
| **조명 변경** | 빛과 분위기를 바꿉니다 |
| **부분 변경** | 바꿀 영역을 칠하는 편집기를 엽니다 |
| **수정 더 보기** | **오래된 사진 복원**, **각도 변경**, **캔버스 확장**, **변형** |
| **이와 비슷하게 더 만들기** | 같은 설정으로 새 시안을 만듭니다 |

각 수정은 새 버전을 만들며, 원본은 **버전** 아래에 남습니다. **편집기에서 열기**를 클릭해 이미지 또는 동영상 편집기에서 계속 편집합니다.

## 오디오 만들기

1. **오디오**를 열고 **음악**, **효과음**, **음성**을 고릅니다.
2. 스타일이나 소리를 설명하거나, 보이스오버의 말을 입력합니다. 음악은 가사가 있거나 **연주곡**일 수 있습니다.
3. **생성**을 클릭합니다. 가진 파일을 쓰려면 **오디오 파일 가져오기**를 클릭합니다.

동영상에 오디오를 넣으려면 동영상을 열고 **오디오 추가**를 클릭합니다. **내 오디오**에서 클립을 고르거나 **파일 가져오기**를 하고, **소리와 섞기** 또는 **소리 바꾸기**를 고른 다음 **동영상에 추가**를 클릭합니다.

<Warning>
모든 이미지, 동영상, 오디오 클립은 제공업체 크레딧이나 Enconvo Cloud 포인트를 씁니다. 동영상이 가장 비싸므로 짧은 것부터 시험하세요.
</Warning>

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 그림이 주제나 프레임으로 거부됨 | PNG, JPEG, WebP 그림을 쓰세요 |
| 원하는 설정이 보이지 않음 | 고른 모델이 받지 않습니다. 다른 모델을 고르세요 |
| 항목에 **다시 시도**가 표시됨 | 실패했습니다. 제공업체 접근을 확인한 다음 다시 시도하세요 |
| **오디오**에 음성이나 모델이 없음 | 그 종류의 오디오를 만드는 제공업체를 설정하세요. Enconvo Cloud는 음성만 만들며, 음악과 효과음에는 자신의 ElevenLabs 키가 필요합니다 |

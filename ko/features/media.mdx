**미디어**는 Enconvo에서 만드는 모든 이미지, 동영상, 오디오 클립을 모아 두는 단일 공간입니다. 여기서 직접 만들었든 에이전트가 채팅에서 만들었든 마찬가지입니다. 설정을 세밀하게 제어하면서 그림과 클립을 생성하고, 사람이나 제품이 여러 결과물에서 똑같이 보이도록 유지하고, 만든 결과물을 보정하거나 다시 활용할 수 있습니다.

**설정 → 이미지 생성**과 **설정 → 동영상 생성**에서 지정한 제공업체를 사용합니다. 설정 방법은 [이미지 생성](/ko/ai/image-generation)과 [동영상 생성](/ko/ai/video-generation)을 참고하세요.

## 미디어 열기

채팅 창 사이드바에서 **미디어**를 클릭합니다. 상단에서 **이미지**, **동영상**, **오디오**를 선택합니다.

- **전체**, **즐겨찾기**, 그리고 내 폴더로 만든 결과물을 분류합니다. **새 폴더**를 클릭하여 폴더를 추가하고, 항목의 **폴더로 이동**으로 정리합니다.
- **미디어 검색**에 입력하면 프롬프트의 단어로 항목을 찾습니다.
- 별을 클릭하면 항목이 **즐겨찾기**에 추가됩니다.

파일은 Mac의 `~/Enconvo/Media`에도 있습니다.

새 채팅의 메시지 입력란 아래에서 **이미지** 또는 **동영상**을 선택할 수도 있습니다. 모델, 설정, 제외할 내용이 메시지 입력란 아래에 알약 모양으로 표시되고, 그 아래에 최근 이미지나 동영상과 **미디어 열기** 링크가 나타납니다.

## 이미지 또는 동영상 만들기

1. **이미지** 또는 **동영상**에서 하단의 입력창에 원하는 내용을 설명합니다.
2. 그 아래의 알약을 확인합니다. 모델, **화면 비율**, **품질**, 이미지 수, **제외**(제외할 내용)입니다. 알약을 클릭하여 변경하거나, **설정 더 보기**로 나머지를 설정합니다. 선택한 모델이 지원하는 설정만 표시됩니다.
3. **생성**을 클릭합니다. 새 항목은 완료되는 대로 맨 위에 나타납니다.

여러 결과물을 요청했다면 남길 것을 선택하세요.

### 동영상을 위한 추가 제어

- **시작 프레임**과 **끝 프레임**: 클립이 시작하거나 끝나는 그림을 추가합니다.
- **샷 추가**: 동영상을 각각 고유한 프롬프트와 길이를 가진 샷으로 나눕니다. Enconvo가 이를 하나의 동영상으로 이어 붙입니다.
- **오디오 파일 추가**: 직접 가져온 오디오나 **오디오**의 클립을 사용합니다.

## 피사체나 스타일을 동일하게 유지

사람, 반려동물, 제품, 캐릭터의 사진 몇 장을 피사체로, 또는 원하는 분위기의 그림 몇 장을 스타일로 저장하세요. 생성할 때 선택하면 모든 그림과 동영상에서 똑같이 보입니다.

1. 입력창에서 **피사체, 스타일 또는 참조 이미지 추가**를 클릭합니다.
2. **피사체** 아래의 **사진으로 새로 만들기** 또는 **스타일** 아래의 **새 스타일**을 선택합니다.
3. **이름**을 지정하고 **사진**을 추가한 다음, 원하면 **설명으로 만들기**를 사용합니다.
4. **저장**을 클릭합니다. 다음에 생성할 때 같은 메뉴에서 선택하세요.

## 만든 결과물 다듬기

항목을 클릭하면 프롬프트와 사용된 모든 설정이 포함된 세부 정보가 열립니다. 여기서 다음을 할 수 있습니다.

| 동작 | 기능 |
| --- | --- |
| **설정 재사용** | 같은 프롬프트와 설정으로 입력창을 채웁니다 |
| **동영상으로 만들기** | 이 그림으로 동영상을 시작합니다 |
| **업스케일** | 더 크고 선명한 사본을 만듭니다 |
| **배경 제거** | 피사체를 오려 냅니다 |
| **조명 바꾸기** | 빛과 분위기를 바꿉니다 |
| **일부 바꾸기** | 편집기를 열어 바꿀 영역을 칠합니다 |
| **더 많은 보정** | **오래된 사진 복원**, **각도 바꾸기**, **캔버스 확장**, **변형** |
| **비슷한 것 더 만들기** | 같은 설정으로 새 결과물을 만듭니다 |

각 보정은 새 버전을 만들며, 원본은 **버전** 아래에 남습니다. **편집기에서 열기**를 클릭하면 이미지 또는 동영상 편집기에서 계속 편집할 수 있습니다.

## 오디오 만들기

1. **오디오**를 열고 **음악**, **효과음**, **음성** 중에서 선택합니다.
2. 스타일이나 소리를 설명하거나, 음성 해설의 경우 읽을 문구를 입력합니다. 음악에는 가사를 넣거나 **연주곡**으로 만들 수 있습니다.
3. **생성**을 클릭합니다. 가지고 있는 파일을 사용하려면 **오디오 파일 가져오기**를 클릭하세요.

동영상에 오디오를 넣으려면 동영상을 열고 **오디오 추가**를 클릭합니다. **내 오디오**에서 클립을 선택하거나 **파일 가져오기**를 사용하고, **원래 소리와 섞기** 또는 **원래 소리 바꾸기**를 선택한 다음 **동영상에 추가**를 클릭합니다.

<Warning>
모든 이미지, 동영상, 오디오 클립은 제공업체의 크레딧 또는 Enconvo Cloud 포인트를 사용합니다. 동영상은 비용이 가장 많이 들므로 짧은 것부터 먼저 시도해 보세요.
</Warning>

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 그림이 피사체나 프레임으로 거부됨 | PNG, JPEG, WebP 그림을 사용하세요 |
| 원하는 설정이 표시되지 않음 | 선택한 모델이 지원하지 않는 설정입니다. 다른 모델을 선택하세요 |
| 항목에 **다시 시도**가 표시됨 | 실패했습니다. 제공업체의 액세스 권한을 확인한 다음 다시 시도하세요 |
| **오디오**에 음성이나 모델이 없음 | 해당 종류의 오디오를 만드는 제공업체를 설정하세요. Enconvo Cloud는 음성만 만들며, 음악과 효과음에는 직접 발급받은 ElevenLabs 키가 필요합니다 |

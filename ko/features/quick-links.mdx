---
title: "퀵링크"
description: "SmartBar에서 한 명령으로 웹 검색, 웹사이트, 파일, 폴더, Deeplink를 엽니다."
---

퀵링크는 웹 검색, 웹 주소, 파일이나 폴더, 앱의 Deeplink를 SmartBar에서 실행하는 명령으로 바꿉니다. 자리 표시자는 입력한 것, 클립보드, 선택한 텍스트, 날짜로 링크를 채웁니다. Enconvo에는 Google, YouTube, X 검색이 바로 쓸 수 있게 들어 있습니다.

퀵링크는 목적지를 엽니다. [웹 검색](/ko/ai/web-search)은 검색 결과를 AI 답변에 가져오고, [브라우저 사용](/ko/features/browser-control)은 에이전트가 웹 페이지에서 작업하게 합니다.

## SmartBar에서 웹 검색

1. SmartBar를 열고 **브라우저에서 Google 검색**, **브라우저에서 YouTube 검색**, **브라우저에서 Twitter/X 검색**을 찾습니다.
2. 검색어를 명령 입력으로 넣습니다. 선택한 텍스트도 됩니다.
3. 명령을 실행합니다. 검색이 기본 브라우저에서 열립니다.

## 퀵링크 만들기

1. SmartBar에서 **퀵링크 만들기**를 실행합니다.
2. **이름**을 입력합니다. 예: GitHub 검색.
3. **링크**를 입력합니다. 웹 주소, 파일이나 폴더 경로, Deeplink입니다. **자리 표시자 삽입**을 클릭해 `https://github.com/search?q={argument}` 같은 것을 넣습니다.
4. 특정 앱에서 열려면 **다음으로 열기**에 Safari 같은 앱 이름, 앱 경로, 번들 ID를 입력합니다. 비워 두면 기본 앱을 씁니다.
5. **저장**을 클릭합니다. SmartBar에서 퀵링크 이름을 검색해 실행합니다.

퀵링크를 실행하면 입력하거나 선택한 텍스트가 첫 인수를 채웁니다. 필수 인수가 아직 비어 있으면 Enconvo가 링크를 열기 전에 묻습니다.

| 자리 표시자 | 채워지는 값 |
| --- | --- |
| `{argument name="Query"}` | 퀵링크가 열릴 때 입력하는 값 |
| `{clipboard}` | 클립보드의 텍스트 |
| `{selection}` | 쓰고 있는 앱에서 선택한 텍스트 |
| `{date}`, `{time}`, `{datetime}` | 현재 날짜, 시간, 또는 둘 다 |
| `{date format="yyyy-MM-dd"}` | 지정한 형식의 날짜 |
| `{uuid}` | 새 고유 ID |

새 링크는 공백과 문장 부호가 있는 평범한 텍스트로 먼저 시험하세요.

## 퀵링크 관리

SmartBar에서 **퀵링크 검색**을 실행하면 모든 퀵링크가 보입니다. 그곳에서 하나를 열거나, 편집하거나, 복제하거나, 삭제할 수 있고, **새로 만들기**를 클릭해 또 추가합니다.

**더 보기** 메뉴에는 Raycast 퀵링크와 설정보내기를 읽는 **퀵링크 가져오기…**와 **다운로드로 내보내기**가 있습니다. Raycast 설정보내기는 내보낼 때 고른 암호를 묻습니다.

## 설정

**설정 → 플러그인 → 퀵링크**를 엽니다. 각 검색 명령에도 `https://www.google.com/search?q={query}` 같은 자체 **링크**가 있으며 바꿀 수 있습니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **새로운 윈도우에서 열기** | 웹 퀵링크를 새 브라우저 창에서 엽니다. Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox, Zen에서 됩니다. Safari, Arc, Orion은 평소처럼 링크를 엽니다. 기본은 꺼짐입니다 |
| **선택한 텍스트가 없을 때** | 아무것도 선택되지 않았을 때 `{selection}` 링크가 하는 일입니다. **물어보기**(기본) 또는 **클립보드 사용**입니다 |
| **삭제 전에 확인** | 퀵링크를 삭제하기 전에 묻습니다. 기본은 켜짐입니다 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 잘못된 페이지가 열림 | 퀵링크의 **링크**와 자리 표시자를 확인한 다음 평범한 텍스트로 시험합니다 |
| 브라우저가 열리지 않음 | 기본 브라우저, 퀵링크의 **다음으로 열기**, 명령이 설치되었는지 확인합니다 |
| `{selection}` 링크가 텍스트를 물음 | 선택된 것이 없습니다. 먼저 텍스트를 선택하거나 **선택한 텍스트가 없을 때**를 **클립보드 사용**으로 설정합니다 |

description: "웹 검색, 웹사이트, 파일, 폴더, 딥링크를 SmartBar에서 명령 하나로 여세요."

빠른 링크는 웹 검색, 웹 주소, 파일이나 폴더, 앱의 딥링크를 SmartBar에서 실행하는 명령으로 바꿔 줍니다. 자리 표시자는 입력한 내용, 클립보드, 선택한 텍스트, 날짜로 링크를 채웁니다. Enconvo에는 Google, YouTube, X 검색이 바로 쓸 수 있게 포함되어 있습니다.

빠른 링크는 목적지를 엽니다. 반면 [웹 검색](/ko/ai/web-search)은 검색 결과를 AI 답변으로 가져오고, [브라우저 사용](/ko/features/browser-control)은 에이전트가 웹페이지에서 작업하게 합니다.

## SmartBar에서 웹 검색

1. SmartBar를 열고 **브라우저에서 Google 검색**, **브라우저에서 YouTube 검색**, **브라우저에서 Twitter/X 검색**을 찾습니다.
2. 명령의 입력으로 검색할 텍스트를 입력합니다. 선택한 텍스트도 사용할 수 있습니다.
3. 명령을 실행합니다. 기본 브라우저에서 검색이 열립니다.

## 빠른 링크 만들기

1. SmartBar에서 **퀵링크 만들기**를 실행합니다.
2. Search GitHub 같은 **이름**을 입력합니다.
3. **링크**를 입력합니다. 웹 주소, 파일 또는 폴더 경로, 딥링크가 가능합니다. **자리 표시자 삽입**을 클릭하여 `https://github.com/search?q={argument}` 같은 자리 표시자를 추가합니다.
4. 특정 앱에서 열려면 **다음으로 열기**에 Safari 같은 앱 이름, 앱 경로 또는 번들 ID를 입력합니다. 비워 두면 기본 앱을 사용합니다.
5. **저장**을 클릭합니다. SmartBar에서 빠른 링크의 이름을 검색하면 실행할 수 있습니다.

빠른 링크를 실행하면 입력하거나 선택한 텍스트가 첫 번째 인수를 채웁니다. 필수 인수가 여전히 비어 있으면 Enconvo가 링크를 열기 전에 물어봅니다.

| 자리 표시자 | 채워지는 값 |
| --- | --- |
| `{argument name="Query"}` | 빠른 링크를 열 때 입력하는 값 |
| `{clipboard}` | 클립보드의 텍스트 |
| `{selection}` | 사용 중인 앱에서 선택한 텍스트 |
| `{date}`, `{time}`, `{datetime}` | 현재 날짜, 시간 또는 둘 다 |
| `{date format="yyyy-MM-dd"}` | 지정한 형식의 날짜 |
| `{uuid}` | 새로운 고유 ID |

새 링크는 먼저 공백과 구두점이 포함된 일반 텍스트로 테스트해 보세요.

## 빠른 링크 관리

SmartBar에서 **빠른 링크 검색**을 실행하면 모든 빠른 링크를 볼 수 있습니다. 여기서 빠른 링크를 열거나, 편집하거나, 복제하거나, 삭제할 수 있고, **새로 만들기**를 클릭하여 새로 추가할 수 있습니다.

**더 보기** 메뉴에는 Raycast 빠른 링크와 설정 내보내기 파일을 읽는 **퀵링크 가져오기…**와 **다운로드로 내보내기**가 있습니다. Raycast 설정 내보내기 파일은 내보낼 때 정한 암호를 요구합니다.

## 설정

**설정 → 플러그인 → 빠른 링크**를 엽니다. 각 검색 명령에는 `https://www.google.com/search?q={query}` 같은 자체 **링크**도 있으며 이를 변경할 수 있습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **새로운 윈도우에서 열기** | 웹 빠른 링크를 새 브라우저 창에서 엽니다. Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox, Zen에서 작동하며, Safari, Arc, Orion은 링크를 평소처럼 엽니다. 기본값은 꺼짐입니다 |
| **선택한 텍스트가 없을 때** | 아무것도 선택하지 않았을 때 `{selection}` 링크의 동작: **입력 요청**(기본값) 또는 **클립보드 사용** |
| **삭제 전 확인** | 빠른 링크를 삭제하기 전에 확인합니다. 기본값은 켜짐입니다 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 엉뚱한 페이지가 열림 | 빠른 링크의 **링크**와 자리 표시자를 확인한 다음 일반 텍스트로 시도해 보세요 |
| 브라우저가 열리지 않음 | 기본 브라우저, 빠른 링크의 **다음으로 열기**, 명령이 설치되어 있는지 확인하세요 |
| `{selection}` 링크가 텍스트를 요청함 | 아무것도 선택되지 않았습니다. 먼저 텍스트를 선택하거나, **선택한 텍스트가 없을 때**를 **클립보드 사용**으로 설정하세요 |

에이전트에게 답을 보여 달라고 요청하면 대화 안에서 바로 시각 자료를 그려 줍니다. SVG 다이어그램, HTML 미리보기, 클릭하고 조정할 수 있는 대화형 위젯 등입니다. 그림, 차트, 작은 계산기가 여러 단락보다 더 잘 설명해 줄 때 사용하세요. 이를 위해 에이전트에게 시각 도구가 필요합니다.

시각적 답변은 대화 안에 머뭅니다. 슬라이드, 대시보드, 디자인, 문서처럼 보관하고, 편집하고, 발표하거나 공유하고 싶은 것이 있다면 대신 [아티팩트](/ko/features/artifacts)를 요청하세요.

## 시각 자료 요청

시각 자료가 어떤 질문에 답해야 하는지 말해 주세요.

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

차트나 계산기를 요청할 때는 데이터와 단위를 포함하세요. 잘 다듬어진 시각 자료라도 사실이나 계산이 틀릴 수 있으니 확인하세요.

## 답변 속 링크, 지도, 차트

요청하지 않아도 일부 답변은 시각적으로 바뀝니다.

- **링크**는 사이트 아이콘이 있는 카드로 표시됩니다.
- **위치**는 장소 이름과 함께 실제 지도에 표시됩니다. 여러 장소는 번호가 매겨진 하나의 지도에 함께 표시되고, 경로는 소요 시간과 거리와 함께 선으로 표시됩니다.
- 에이전트가 만든 **차트**는 색상을 검사하므로 색각 이상이 있어도, 밝은 모드와 어두운 모드 모두에서 각 계열이 구분됩니다. 숫자, 날짜, 상태 단어는 사용자의 언어로 표시됩니다.

## 시각 자료 사용 및 저장

1. 시각 자료가 다 그려질 때까지 기다린 다음 제공되는 컨트롤을 사용합니다. 일부 위젯은 후속 프롬프트를 채팅으로 보냅니다.
2. 완성된 시각 자료에 포인터를 올리고 오른쪽 위의 **⋯**를 클릭합니다.
3. **클립보드에 복사** 또는 **파일 다운로드**를 선택하고 파일 이름을 확인합니다. 앱의 자체 카드, 표, 차트로 그린 시각 자료는 대신 **이미지 다운로드**가 제공되며, 다운로드 폴더에 PNG를 저장합니다.

저장된 이미지는 시각 자료의 한 순간을 캡처한 것이며 대화형 컨트롤은 유지되지 않습니다. 위젯의 값을 변경한 후에는 같은 메뉴의 **값 재설정**으로 되돌릴 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 시각 자료 대신 코드가 나옴 | 에이전트의 활성화된 도구를 확인한 다음 결과를 대화에 표시해 달라고 요청하세요 |
| 위젯이 불완전해 보임 | 완료될 때까지 기다린 다음 더 단순한 버전을 요청하세요 |
| 채팅 위젯이 아니라 이미지 파일이 필요함 | [이미지 생성](/ko/ai/image-generation)을 사용하세요 |
| 차트를 보관해 두고 나중에 다시 보고 싶음 | [대시보드](/ko/features/dashboards)를 요청하세요 |

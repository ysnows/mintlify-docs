에이전트에게 답변을 시각적으로 보여 달라고 요청하면 대화 안에 SVG 다이어그램, HTML 미리보기, 직접 클릭하고 조절할 수 있는 대화형 위젯을 그려 줍니다. 줄글보다 그림이나 차트, 간단한 계산기로 설명하는 편이 훨씬 명확할 때 활용하세요. 이 기능을 사용하려면 에이전트에 시각화 도구가 활성화되어 있어야 합니다.

시각적 답변은 해당 대화 안에서 확인하는 용도입니다. 발표 자료, 대시보드, 디자인, 문서처럼 나중에 다시 열거나 편집, 발표, 공유해야 하는 결과물은 [아티팩트](/ko/features/artifacts)로 요청하세요.

## 시각적 답변 요청하기

시각 자료로 풀고 싶은 질문을 명확히 적어 주세요.

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

차트나 계산기를 만들 때는 데이터와 단위를 함께 알려 주세요. 깔끔하게 그려진 시각 자료라도 사실이나 계산이 틀릴 수 있으므로 직접 확인하는 것이 좋습니다.

## 답변 속 링크, 지도, 차트

따로 요청하지 않아도 일부 답변은 시각 형태로 표시됩니다.

- **링크**는 사이트 아이콘이 포함된 카드로 표시됩니다.
- **장소**는 장소 이름과 함께 실제 지도에 표시됩니다. 여러 장소는 번호가 매겨진 하나의 지도에 함께 나타나며, 경로를 물으면 선과 소요 시간, 거리까지 보여 줍니다.
- 에이전트가 만든 **차트**는 색맹 사용자가 보거나 라이트·다크 모드로 전환해도 각 계열이 뚜렷하게 구분되도록 색상을 점검해 표시합니다. 숫자, 날짜, 상태 문구도 사용자의 언어로 표시됩니다.

## 시각 자료 활용 및 저장하기

1. 시각 자료가 완전히 그려질 때까지 기다린 뒤 포함된 컨트롤을 조작해 보세요. 일부 위젯은 채팅으로 후속 프롬프트를 보내기도 합니다.
2. 완성된 시각 자료 위에 마우스를 올리고 오른쪽 위의 **⋯**을 클릭합니다.
3. **클립보드에 복사**를 선택하거나, **파일 다운로드**를 누른 뒤 파일 이름을 확인합니다. 앱 자체의 카드, 표, 차트로 그려진 시각 자료는 대신 **이미지 다운로드** 메뉴가 제공되며, 클릭하면 다운로드 폴더에 PNG 파일로 저장됩니다.

이미지로 저장하면 그 순간의 화면만 캡처되므로 대화형 조작 기능은 유지되지 않습니다. 위젯 값을 바꾼 뒤 원래대로 돌리려면 같은 메뉴에서 **값 재설정**을 선택하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 시각 자료 대신 코드가 나옴 | 에이전트에 활성화된 도구를 확인한 뒤 결과를 대화 안에 직접 보여 달라고 요청하세요. |
| 위젯이 미완성처럼 보임 | 그리기가 끝날 때까지 기다린 뒤 더 단순한 버전을 요청해 보세요. |
| 채팅 위젯이 아니라 이미지 파일 자체가 필요함 | [이미지 생성](/ko/ai/image-generation)을 사용하세요. |
| 차트를 보관하고 나중에 다시 보고 싶음 | [대시보드](/ko/features/dashboards)로 만들어 달라고 요청하세요. |

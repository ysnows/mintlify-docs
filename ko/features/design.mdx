디자인 캔버스는 에이전트가 무언가가 어떻게 보여야 하는지 보여 주는 곳입니다. 앱 화면, 와이어프레임, 두 가지 버전의 가격 페이지, 포스터, 이메일 등이 해당합니다. 각 결과물은 채팅 옆에서 이동, 확대, 선택, 편집할 수 있는 캔버스 위의 아트보드입니다. 무언가를 만들기 전에 모습을 정할 때 사용하세요.

## 디자인 만들기

1. 새 채팅을 시작하고 메시지 입력란 아래에서 **디자인**을 선택하거나, 어떤 채팅에서든 디자인을 요청합니다.
2. 화면이나 결과물, 대상 독자, 비교할 내용을 설명합니다. 스크린샷이나 스케치를 첨부하여 거기서 시작할 수 있습니다.
3. 보냅니다. 에이전트가 작업하는 동안 아트보드가 여러 개씩 캔버스에 그려집니다.

프로젝트 종류마다 고유한 크기와 레이아웃 규칙이 적용됩니다. 휴대폰 화면은 휴대폰 크기로, 포스터는 포스터 크기로, 이메일은 이메일 너비로 만들어집니다.

예시:

```text
Two options for a pricing page, side by side.
Three plans, monthly and yearly, with the middle plan highlighted.
```

## 디자인 변경

아이콘, 색상, 텍스트 한 줄처럼 바꿀 내용을 에이전트에게 요청하세요. 해당 부분만 변경되며, 변경된 아트보드만 다시 그려집니다.

직접 변경하려면 다음을 사용하세요.

- 요소를 선택하고 사이드 패널의 **속성**을 열어 레이아웃, 채우기, 테두리, 글꼴, 효과를 설정합니다. 디자인은 이 패널이 닫힌 상태로 열리며, 좁은 창에서는 캔버스 위에 시트로 열립니다.
- 아트보드가 제공하는 옵션에는 **조정**을, 레이어에는 **개요**를 사용합니다.
- 스페이스를 누르고 있거나 손 도구를 선택하면 이동합니다. 연필과 펜은 캔버스에 그립니다.
- 요소를 선택하고 **내보내기**를 사용하여 **PNG 내보내기** 또는 **JPEG 내보내기**로 저장합니다.

캔버스를 사람이나 팀과 공유하거나 이전 버전으로 돌아가려면 [아티팩트](/ko/features/artifacts)를 참고하세요.

## 디자인 시스템 사용

디자인 시스템은 캔버스나 슬라이드에 정확한 색상, 글꼴 스타일, 폰트, 컴포넌트를 제공합니다.

- **가져오기**: 에이전트에게 코드 폴더, 토큰 파일, npm 패키지를 디자인 시스템으로 바꿔 달라고 요청합니다. 정확한 값과 실제 컴포넌트가 그대로 유지되며, 시스템에 아직 부족한 부분을 알려 주는 검사도 실행됩니다.
- **스타일 전환**: 사이드 패널의 **테마** 탭을 열고 시스템을 선택합니다. 캔버스가 해당 시스템의 색상과 글꼴 스타일로 전환됩니다.
- **최신 상태 유지**: 디자인이 사용한 이후 시스템이 변경되었다면 **테마** 탭에 원본보다 뒤처져 있다고 표시됩니다. **동기화**를 클릭하면 변경 사항이 반영됩니다.

슬라이드는 자체 **디자인 시스템** 메뉴에서 디자인 시스템을 사용합니다. [슬라이드](/ko/features/slides)를 참고하세요.

## 디자인 프로젝트 가져오기

**아티팩트** 라이브러리에서 **가져오기**를 클릭하고 압축한 디자인의 프로젝트 폴더를 선택합니다. 폴더의 `assets/` 또는 `_blobs/`에 보관된 업로드 파일도 함께 가져옵니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 일부 아트보드에서 폰트가 다르게 보임 | 폰트는 이를 불러오는 아트보드에서만 표시됩니다. 에이전트에게 폰트를 불러오도록 요청하세요 |
| **테마** 탭에 시스템이 없음 | 에이전트에게 시스템을 추가하거나 가져오도록 요청하세요 |
| 시스템에서 원본을 찾을 수 없다고 함 | 시스템의 출처인 폴더나 패키지가 이동했습니다. 다시 가져오세요 |
| "hasn't finished drawing the export"와 함께 내보내기가 실패함 | Enconvo를 업데이트한 다음 다시 내보내세요 |

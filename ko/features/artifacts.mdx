아티팩트는 에이전트가 사용자를 위해 만들어 보관하는 결과물입니다. 문서, 슬라이드, 디자인 캔버스, 대시보드, 움직임, 웹 페이지, 다이어그램, 코드가 해당합니다. 채팅 옆 패널에서 열리고, 모든 버전을 보관하며, 채팅이 끝난 뒤에도 **아티팩트** 라이브러리에 남습니다. 결과를 다시 보거나, 편집하거나, 발표하거나, 공유할 때 사용하세요.

생성한 이미지, 동영상, 오디오는 대신 [미디어](/ko/features/media)에 보관됩니다.

## 새 채팅에서 아티팩트 시작

새 채팅에는 메시지 입력란 아래에 **만들기** 줄이 표시되며, 종류별 알약이 있습니다. **슬라이드**, **문서**, **디자인**, **움직임**, **대시보드**, **웹 페이지**, **이미지**, **동영상**입니다. 각 알약에는 짧은 설명이 있어 **움직임**(코드로 애니메이션)과 **동영상**(AI 영상)을 구분할 수 있습니다.

1. 알약을 클릭합니다. 아직 아무것도 전송되지 않으며, 메시지 입력란이 해당 종류로 전환됩니다.
2. 시작 방법을 선택합니다.
   - 세 가지 예시 중 하나를 클릭하면 메시지 입력란이 채워집니다.
   - **빈 슬라이드**, **빈 문서**, **빈 디자인** 등을 클릭하면 채팅 옆에서 빈 아티팩트가 열립니다.
   - **.pptx 열기**, **.docx 열기**, **스프레드시트 열기**를 클릭하면 파일에서 시작합니다.
   - **내 슬라이드**, **내 문서** 등을 클릭하면 이미 가지고 있는 항목이 열립니다.
3. 원하는 내용을 설명하고 보냅니다.

아티팩트는 채팅 옆에서 열리고 에이전트가 작업하는 동안 채워집니다. 어떤 채팅에서든 그냥 요청해도 됩니다. 티저, 설명 영상, 따라 하기 영상을 요청하면 [움직임](/ko/features/motion)이 만들어지고, 추적할 수치를 요청하면 [대시보드](/ko/features/dashboards)가 만들어집니다.

**이미지**와 **동영상**에는 최근 그림이나 클립과 **미디어 열기** 링크가 대신 표시됩니다. [미디어](/ko/features/media)를 참고하세요.

## 아티팩트 찾기

채팅 창 사이드바에서 **아티팩트**를 클릭합니다. 라이브러리는 최근에 변경된 순서로 정렬된 썸네일 격자로 열립니다.

- 상단에서 **격자 보기**와 **목록 보기**를 전환합니다.
- 종류별로 필터링합니다. **전체**, **페이지**, **디자인**, **대시보드**, **슬라이드**, **움직임**, **문서**, **다이어그램**, **코드**입니다.
- **아티팩트 검색**에 입력하면 제목으로 찾을 수 있으며, 문자 종류와 대소문자는 구분하지 않습니다.
- **새로 만들기**를 클릭하면 어떤 종류든 빈 아티팩트를 시작합니다.
- **가져오기**를 클릭하면 문서를 문서로, 또는 디자인이나 대시보드의 압축된 프로젝트 폴더를 가져옵니다.

항목을 마우스 오른쪽 버튼으로 클릭하거나 **⋯**를 클릭하면 **열기**, **이름 변경…**, **링크 복사**, **만든 채팅 열기**, 여러 개 **선택**, **삭제**를 사용할 수 있습니다. 여러 개를 한꺼번에 선택하려면 ⌘-클릭 또는 ⇧-클릭한 다음 함께 삭제합니다. 삭제하면 모든 버전과 아티팩트가 저장한 모든 것이 제거되며, 만든 채팅은 그대로 남습니다. 이어서 나타나는 알림에서 **실행 취소**를 클릭하면 되돌릴 수 있습니다.

아무것도 쓰지 않은 빈 아티팩트는 보관되지 않으며, 닫으면 버려집니다.

## 이전 버전으로 돌아가기

에이전트가 하는 모든 변경과 사용자가 저장하는 모든 편집은 새 버전이 됩니다.

1. 아티팩트 머리글에서 버전 번호(예: **v4**)를 클릭합니다.
2. **버전**에서 원하는 버전을 선택합니다.
3. **복원**을 클릭하거나, 그대로 두려면 **현재 버전으로 돌아가기**를 클릭합니다. 복원은 새 버전으로 저장되므로 잃는 것이 없습니다.

채팅에서 요청할 수도 있습니다. "색상을 바꾸기 전의 모습으로 슬라이드를 되돌려 줘." 에이전트는 디자인, 슬라이드, 대시보드의 해당 버전을 복원하고 나머지는 유지합니다.

변경을 요청하면 에이전트는 슬라이드 한 장, 차트 하나, 아트보드 하나처럼 사용자가 지정한 부분만 편집하고 나머지는 그대로 둡니다.

## 아티팩트 공유

문서, 디자인, 슬라이드, 대시보드, 움직임은 사람이나 팀과 공유할 수 있습니다. Enconvo 계정에 로그인해 있어야 합니다.

1. 아티팩트를 열고 **공유**를 클릭합니다.
2. **이메일로 사람 추가**에 이메일을 입력하고 **보기 가능**, **댓글 가능**, **편집 가능** 중에서 선택한 다음 **공유**를 클릭합니다.
3. 팀과 공유하려면 **팀 액세스**를 설정합니다. Enconvo에 로그인한 사람이면 누구나 열 수 있게 하려면 **일반 액세스**를 **링크가 있는 모든 사용자**로 설정한 다음 **링크 복사**를 클릭합니다.
4. **완료**를 클릭합니다.

공유하면 아티팩트가 Enconvo Cloud로 이동하므로, 추가한 사람들은 자신의 Mac에서 열어 새 버전이 나올 때마다 확인할 수 있습니다. `@Enconvo`로 시작하는 댓글에는 Enconvo가 답합니다.

## 페이지를 웹사이트로 게시

웹 페이지 아티팩트는 Enconvo Cloud에서 고유한 주소 `name.site.enconvo.com`으로 온라인에 공개할 수 있습니다. 게시는 Enconvo 계정에 포함되어 있습니다.

1. 페이지를 열고 머리글의 **게시**를 클릭합니다.
2. **사이트 이름**에 주소에 사용할 이름을 입력합니다. 소문자, 숫자, 하이픈으로 3자에서 40자입니다.
3. **볼 수 있는 사람**에서 **링크가 있는 모든 사용자**를 선택하거나, **비밀번호**를 선택하고 4자 이상의 비밀번호를 입력합니다.
4. **게시**를 클릭합니다. **사이트가 게시되었습니다**라고 표시되면 **열기**를 클릭하여 확인합니다.

이후 버튼에는 **게시됨**이라고 표시됩니다. 페이지를 변경하면 **업데이트**라고 표시되며, 이를 클릭한 다음 **업데이트**를 다시 클릭하면 최신 버전이 온라인에 반영됩니다. 같은 패널에서 **링크 복사**, 이전에 게시한 버전으로 **되돌리기**, 또는 사이트를 오프라인으로 전환하는 **게시 취소**를 할 수 있으며, 게시를 취소하면 모든 사용자에게 링크가 작동하지 않습니다.

에이전트에게 페이지를 온라인으로 공유해 달라고 요청할 수도 있으며, 그러면 페이지나 사이트 폴더를 대신 게시해 줍니다.

## 휴대폰에서 아티팩트 열기

슬라이드, 대시보드, 움직임은 iPhone과 Android 앱에서도 열 수 있습니다. 채팅이나 **아티팩트** 라이브러리에서 열고 댓글을 달거나, `@Enconvo`에게 질문하거나, 공유, 내보내기, 발표할 수 있습니다.

## 문서를 스킬로 사용

문서는 에이전트가 따르는 스킬로 사용할 수 있습니다. 문서를 열고 **스킬로 사용…**을 선택하세요. 다른 사람의 문서라면 사용자만 켤 수 있으며, Enconvo는 소유자가 에이전트가 따르는 내용을 여전히 변경할 수 있다고 알려 줍니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 이미지나 동영상이 라이브러리에 없음 | 이미지, 동영상, 오디오는 [미디어](/ko/features/media)에 보관됩니다 |
| **공유**에서 로그인하라고 함 | Mac에서 Enconvo에 로그인한 다음 다시 공유하세요 |
| 공유된 문서가 더 이상 열리지 않음 | 소유자가 사용자의 액세스 권한을 삭제했거나, 사용자가 라이브러리에서 제거했습니다 |
| 에이전트가 요청한 것보다 더 많이 다시 씀 | 변경할 부분을 지정하거나, 그 이전 버전을 복원하세요 |
| 게시된 페이지에 이전 버전이 표시됨 | 페이지 머리글에서 **업데이트**를 클릭한 다음 **업데이트**를 다시 클릭하세요 |

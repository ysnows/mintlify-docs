아티팩트는 에이전트가 계속 보관할 수 있도록 만들어 주는 결과물입니다. 문서, 슬라이드, 디자인 캔버스, 대시보드, 애니메이션, 웹 페이지, 다이어그램, 코드 등이 여기에 해당합니다. 채팅 옆 패널에서 바로 열리며, 모든 버전을 보존하고 대화가 끝난 뒤에도 **아티팩트** 보관함에 남아 있습니다. 결과를 나중에 다시 열어 보거나 편집, 발표, 공유해야 할 때 사용하세요.

생성한 이미지, 동영상, 오디오는 아티팩트 대신 [미디어](/ko/features/media)에 보관됩니다.

## 새 채팅에서 아티팩트 시작하기

새 채팅을 열면 메시지 입력창 아래에 **만들기** 줄이 나타나며, **슬라이드**, **문서**, **디자인**, **애니메이션**, **대시보드**, **웹 페이지**, **이미지**, **동영상** 알약 버튼이 표시됩니다. 각 버튼에는 짧은 설명이 붙어 있어 코드로 움직이는 **애니메이션**과 AI 영상인 **동영상**을 쉽게 구분할 수 있습니다.

1. 원하는 종류의 버튼을 클릭합니다. 아직 전송되지는 않으며, 메시지 입력창이 해당 유형으로 전환됩니다.
2. 시작 방법을 고릅니다.
   - 세 가지 예시 중 하나를 클릭해 메시지 입력창을 채웁니다.
   - **빈 슬라이드**, **빈 문서**, **빈 디자인** 등을 클릭해 채팅 옆에 빈 작업 공간을 엽니다.
   - **.pptx 열기**, **.docx 열기** 또는 **스프레드시트 열기**를 클릭해 파일에서 시작합니다.
   - **내 슬라이드**, **내 문서** 등을 클릭해 이미 가지고 있는 항목을 엽니다.
3. 원하는 내용을 설명하고 전송합니다.

채팅 옆에 아티팩트가 열리고 에이전트가 작업하는 동안 내용이 채워집니다. 어떤 채팅에서든 바로 요청할 수도 있습니다. 예를 들어 티저, 설명 영상 또는 안내 영상을 요청하면 [애니메이션](/ko/features/motion)이 만들어지고, 추적할 지표를 요청하면 [대시보드](/ko/features/dashboards)가 만들어집니다.

**이미지**와 **동영상**을 선택하면 대신 최근 그림이나 클립과 **미디어 열기** 링크가 나타납니다. 자세한 내용은 [미디어](/ko/features/media)를 참고하세요.

## 아티팩트 찾기

채팅 창 사이드바에서 **아티팩트**를 클릭합니다. 보관함이 썸네일 격자로 열리며 최근 수정된 항목이 먼저 표시됩니다.

- 상단에서 **격자 보기**와 **목록 보기**를 전환할 수 있습니다.
- 유형별로 필터링할 수 있습니다: **모두**, **페이지**, **디자인**, **대시보드**, **슬라이드**, **애니메이션**, **문서**, **다이어그램**, **코드**.
- **아티팩트 검색**에 입력하면 문자 종류나 대소문자에 상관없이 제목으로 검색할 수 있습니다.
- **새로 만들기**를 클릭해 원하는 유형의 빈 아티팩트를 새로 시작할 수 있습니다.
- **가져오기**를 클릭해 문서를 가져오거나 디자인·대시보드의 압축된 프로젝트 폴더를 불러올 수 있습니다.

항목을 마우스 오른쪽 버튼으로 클릭하거나 **⋯**을 클릭해 **열기**, **이름 변경…**, **링크 복사**, **만든 채팅 열기**, 여러 항목 **선택** 또는 **삭제**를 할 수 있습니다. 여러 개를 한꺼번에 고르려면 ⌘-클릭 또는 ⇧-클릭으로 선택한 뒤 함께 삭제하세요. 삭제하면 모든 버전과 아티팩트에 저장된 내용이 사라지지만, 이를 만든 채팅은 그대로 남습니다. 삭제 직후 뜨는 알림에서 **실행 취소**를 클릭하면 되돌릴 수 있습니다.

한 번도 내용을 쓰지 않은 빈 아티팩트는 보관되지 않고 닫을 때 버려집니다.

## 이전 버전으로 돌아가기

에이전트가 내용을 수정할 때마다, 그리고 사용자가 편집 내용을 저장할 때마다 새 버전이 생성됩니다.

1. 아티팩트 상단 헤더의 버전 번호(예: **v4**)를 클릭합니다.
2. **버전** 아래에서 원하는 버전을 선택합니다.
3. **복원**을 클릭하거나, 그대로 두려면 **현재 버전으로 돌아가기**를 클릭합니다. 복원해도 새 버전으로 저장되므로 기존 기록이 사라지지 않습니다.

채팅에서 "색상을 바꾸기 전 상태로 슬라이드를 되돌려 줘"처럼 말로 요청할 수도 있습니다. 에이전트가 디자인, 슬라이드 또는 대시보드의 해당 버전을 복원하고 나머지는 유지합니다.

수정을 요청하면 에이전트는 슬라이드 한 장, 차트 하나, 아트보드 하나처럼 사용자가 지정한 부분만 고치고 나머지는 그대로 둡니다.

## 아티팩트 공유하기

문서, 디자인, 슬라이드, 대시보드, 애니메이션은 다른 사람이나 팀과 공유할 수 있습니다. 공유하려면 Enconvo 계정에 로그인되어 있어야 합니다.

1. 아티팩트를 열고 **공유**를 클릭합니다.
2. **이메일로 사용자 추가** 아래에 이메일을 입력하고 **보기 가능**, **댓글 가능**, **편집 가능** 중 하나를 고른 뒤 **공유**를 클릭합니다.
3. 팀과 공유하려면 **팀 액세스**를 설정하세요. Enconvo에 로그인한 누구나 열 수 있게 하려면 **일반 액세스**를 **링크가 있는 모든 사용자**로 설정한 뒤 **링크 복사**를 클릭합니다.
4. **완료**를 클릭합니다.

공유하면 아티팩트가 Enconvo Cloud로 이동하므로 추가한 사람들이 각자의 Mac에서 열어 새 버전을 실시간으로 볼 수 있습니다. `@Enconvo`로 시작하는 댓글을 남기면 Enconvo가 답글을 달아 줍니다.

## 웹 페이지를 웹사이트로 게시하기

웹 페이지 아티팩트는 Enconvo Cloud의 고유 주소(`name.site.enconvo.com`)로 온라인에 게시할 수 있습니다. 게시는 Enconvo 계정에 포함되어 있습니다.

1. 페이지를 열고 헤더에서 **게시**를 클릭합니다.
2. **사이트 이름** 아래에 주소로 쓸 이름을 입력합니다(소문자, 숫자, 하이픈을 조합해 3~40자).
3. **볼 수 있는 사용자** 아래에서 **링크가 있는 모든 사용자**를 선택하거나, **비밀번호**를 선택해 4자 이상의 비밀번호를 입력합니다.
4. **게시**를 클릭합니다. **사이트가 게시되었습니다**가 표시되면 **열기**를 클릭해 확인하세요.

이후 버튼 이름이 **게시됨**으로 바뀝니다. 페이지를 수정하면 버튼이 **업데이트**로 바뀌며, 이를 클릭한 뒤 다시 **업데이트**를 누르면 최신 버전이 온라인에 반영됩니다. 같은 패널에서 **링크 복사**, 이전에 게시한 버전 **되돌리기**, 또는 **게시 취소**를 선택해 사이트를 내릴 수 있습니다(게시 취소 시 모든 사용자의 링크 접속이 중단됩니다).

에이전트에게 페이지를 온라인으로 공유해 달라고 요청하면 페이지나 사이트 폴더를 직접 게시해 줍니다.

## iPhone 및 Android에서 아티팩트 열기

슬라이드, 대시보드, 애니메이션은 iPhone 및 Android 앱에서도 열 수 있습니다. 채팅이나 **아티팩트** 보관함에서 연 뒤 댓글을 달고, `@Enconvo`에게 묻고, 공유, 내보내기 또는 발표까지 진행할 수 있습니다.

## 문서를 스킬로 사용하기

문서를 에이전트가 따르는 스킬로 활용할 수 있습니다. 문서를 열고 **스킬로 사용…**을 선택하세요. 다른 사람의 문서인 경우 본인만 켤 수 있으며, 문서 소유자가 변경할 경우 에이전트가 따르는 내용도 바뀔 수 있다는 안내가 표시됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 이미지나 동영상이 보관함에 없음 | 이미지, 동영상, 오디오는 [미디어](/ko/features/media)에 보관됩니다. |
| **공유**를 누르면 로그인하라고 나옴 | Mac에서 Enconvo에 로그인한 뒤 다시 공유하세요. |
| 공유받은 문서가 더 이상 열리지 않음 | 소유자가 접근 권한을 회수했거나 사용자가 보관함에서 제거한 경우입니다. |
| 에이전트가 요청한 것보다 더 많이 수정함 | 바꿀 부분을 구체적으로 지정하거나 수정 전 버전을 복원하세요. |
| 게시된 페이지에 예전 버전이 보임 | 페이지 헤더에서 **업데이트**를 클릭한 뒤 다시 **업데이트**를 클릭하세요. |

화상 회의는 Enconvo 안에서 사람들과 얼굴을 마주 보고 말하고 화면을 공유하게 합니다. 친구에게 걸고, 팀 전체에 걸고, 브라우저에서 열 수 있는 링크를 보냅니다. 자막은 자신의 언어로 번역될 수 있고, 노트는 통화를 녹음하고 그 안의 모두와 공유할 수 있는 노트 문서를 씁니다.

이 영상은 화상 회의를 다루고, 이어서 다른 앱의 회의 녹음, 파일 음성 텍스트 변환, 실시간 자막, 화자, 음성 노트를 다룹니다.

화상 회의에는 유료 플랜이 필요합니다. 초대 링크로 참여하는 손님은 Enconvo 계정도, 설치할 것도 필요 없습니다.

## 회의 시작

채팅 창 사이드바, Dynamic Island, 메뉴 막대 메뉴에서 **화상 회의**를 엽니다. 전화에서는 iPhone 또는 Android 앱에서 시작하거나 참여합니다([전화의 통화와 친구](/ko/integrations/phone-calls-and-friends) 참고). Mac에서는 화상 회의 홈이 열립니다.

- 위쪽 상자는 참여할 회의 링크, 또는 걸 친구나 팀원 이름을 받습니다. 입력하고 Return을 누르거나, 지금 회의를 시작합니다.
- **예정**은 예약한 회의를 나열합니다.
- **이전**은 지난달 통화와 녹음을 나열하고, **다시 전화**는 같은 사람들을 울립니다.
- **팀에 전화**는 모든 팀원을 한 번에 울립니다.

**설정 → 화상 회의**를 열고 **시작**을 클릭할 수도 있습니다.

## 사람 초대

통화에서 **사람**을 열고 친구, 팀원, 자신의 다른 기기를 울립니다. **모두 울리기**는 모든 팀원을 한 번에 울립니다. Enconvo에 로그인하지 않은 팀원은 **아직 Enconvo에 없음** 아래에 **초대 링크 복사**와 함께 나옵니다.

그 외 누구든 초대하려면 conference.enconvo.com의 회의 링크를 보냅니다. 웹 브라우저에서 손님으로 참여하고, 말하고, 채팅에 입력하고, 컴퓨터에서 화면을 공유할 수 있습니다.

통화에서만 아는 사람은 친구가 되거나 팀원이 되기 전까지 이름은 보지만 이메일 주소는 보지 못합니다.

## 친구에게 전화

홈 상자나 **설정 → 친구**에서 친구에게 전화하면([친구와 친구 채팅](/ko/features/friends) 참고) 회의 창에서 바로 울리며, 흐린 자신의 카메라 위에 상대 얼굴과 호출음이 나옵니다. 받으면 통화는 상대 그림만 보여 주고, **채팅**은 그 사람과의 채팅입니다. **사람 추가**를 클릭하면 끊김 없이 회의로 바뀝니다.

들어오는 벨에는 **거절**과 **수락**이 있습니다. 받지 못한 통화는 **메시지**와 **다시 전화**가 있는 카드를 남깁니다. 이미 통화 중이면 다른 기기는 계속 울리고, 거는 사람은 다른 통화 중이라는 말을 듣습니다. 통화 중에는 친구 메시지가 알림 대신 통화 안의 작은 알림으로 나옵니다.

## 링크로 참여

Mac이나 브라우저에서 회의 링크를 열면 들어가기 전 페이지가 나옵니다.

1. 카메라와 마이크를 확인하고 쓸 기기를 고릅니다.
2. 자막과 자막 언어, 배경을 고릅니다.
3. 음소거로 들어갈지 고릅니다. 이미 있는 사람도 보입니다.
4. 클릭해 참여합니다.

다섯 명 이상의 회의에서는 마이크가 꺼진 채로 시작되며, 이유를 말하는 메모가 있습니다. 전화 브라우저에서 손님이 다른 앱으로 전환하면 **자리 비움**으로 표시되고, 통화는 최대 5분 자리를 유지합니다.

## 회의 예약

1. **설정 → 화상 회의**에서 **회의 예약**을 클릭합니다.
2. **시작 시각**, **길이**, **반복**을 고릅니다. 한 번, 매일, 평일마다, 매주, 2주마다이며, 모두 한 링크입니다.
3. 사람이나 이메일을 추가하고, 제목을 주고, 저장합니다.

링크는 같게 유지되므로 지금 저장할 수 있습니다. 친구와 팀원은 달력 파일이 있는 이메일을 받습니다. 그 외 사람에게는 링크를 직접 보내세요. 나중에 시각, 길이, 제목, 손님을 바꾸면 각 사람이 업데이트를 받거나, 회의를 취소할 수 있습니다. 예약된 회의는 **예정** 아래에 나오며, 시작되면 **나중에**와 **참여**가 나옵니다.

## 통화 중

떠 있는 독에는 별도의 **마이크**, **카메라**, **자막** 버튼이 있습니다. 한 옆 패널에 **채팅**, **사람**, **자막** 탭이 있습니다.

- **레이아웃**: 갤러리는 사람이 참여해도 모양을 유지합니다. 화자 보기로 전환하거나, 누군가를 고정하거나, 클릭해 크게 만듭니다. 한 사람과만 하는 통화에서는 자신의 작은 그림을 아무 모서리로 끌거나 클릭해 바꿉니다.
- **말하는 사람**: 타일에 녹색 고리와 레벨 막대가 생깁니다.
- **채팅**: 메시지는 모두에게 가고, 읽지 않은 수가 나오며, 나중에 참여한 사람도 이전 내용을 읽을 수 있습니다. 최대 1 GB의 그림과 파일을 첨부, 붙여 넣기, 놓기할 수 있습니다. 통화의 누구든 클릭해 그 사람에게만 씁니다.
- **손과 반응**: 든 손은 든 순서대로 나열되고, 반응은 모두의 보기 위에 떠다닙니다.
- **음소거 중 말하기**: Space를 눌러 말합니다. 음소거 중에 말하면 알림이 **음소거 해제**를 제안합니다.
- **내 동영상**: **내 화면 숨기기** 또는 **내 화면 표시**, **내 동영상 좌우 반전**, **들어오는 동영상 중지**. 후자는 데이터 절약을 위해 다른 사람의 카메라를 멈추고, 음성과 공유 화면은 계속됩니다. 통화 중에 마이크, 스피커, 카메라를 고릅니다. 전화에서는 후면 카메라로 전환할 수 있습니다.
- **배경**: 참여 전이나 통화 중에 고르는 흐림, 장면, 패턴, 자신의 그림. 마스크가 얼굴을 잃으면 실수로 아무것도 보이지 않도록 전체 그림을 흐리게 합니다.

모든 버튼은 Tab으로 닿고, 메뉴는 화살표 키로 움직이며, Enter나 Space가 누군가를 크게 만듭니다.

느리거나 불안정한 연결에서는 소리가 깨지기 전에 그림이 멈추고, 각 사람은 연결에 맞는 그림 크기를 받습니다. 자신의 연결이 나쁘면 메모가 알려 줍니다. 최대 여덟 명의 통화에서 누군가 참여하거나 나가면 부드러운 소리가 납니다. 한동안 통화에 혼자 있으면 통화가 스스로 끝나기 전에 **아직 있나요?**가 묻습니다.

## 화면 공유

1. 독에서 공유를 클릭합니다. 트레이에 각 화면과 창의 그림이 나옵니다.
2. 하나를 고릅니다. 소리도 공유되며, Mac 앱과 브라우저 모두에서입니다.

Mac에서는 녹색 프레임이 공유하는 것을 표시하고, 공유 막대에 **그리기**, **음소거**, **소리 중지**, **공유 중지**가 있습니다. 작은 창이 말하는 사람을 보여 주며, 공유하는 내용에는 나타나지 않습니다. Enconvo의 선택기, 알림, 들어오는 통화 카드는 다른 사람이 보는 내용에서 빠지며, 전체 화면 통화에서 공유하면 전체 화면에서 나옵니다.

다른 사람은 공유 화면을 전체 화면으로 열고, iPhone에서 핀치로 확대할 수 있습니다. 누구든 Mac, iPhone, 브라우저에서 공유 화면에 그릴 수 있습니다. 획은 모두에게 같은 자리에 떨어지고, 그린 사람의 이름을 달고, 몇 초 뒤 사라집니다.

회의를 최소화하거나 화면을 공유하면 작은 떠 있는 창이 말하는 사람을 보여 주며, 음소거, 카메라, 나가기, 통화로 돌아가는 클릭이 있습니다.

## 자막

통화에서 **자막**이 켜거나 끕니다. 독 위의 띠가 각 줄을 보여 줍니다. 번역이 켜지면 번역을 크게, 원문을 작게 보여 주거나, 고른 언어의 번역만 보여 줍니다. 아직 오는 중인 번역에는 표시가 있습니다.

자막과 번역은 음성 엔진이 지원하는 모든 언어, 모두 예순 개를 다루며, 언어 메뉴에 이름으로 나열됩니다.

실시간 자막을 클릭하면 누가 언제 무엇을 말했는지 스크롤해 돌아가며, 원문 위에 번역이 있습니다. 최신 줄로 돌아가거나, 한 줄 또는 모두를 복사합니다. Mac, iPhone, Android에서 동작합니다.

## 노트와 녹음

노트는 통화를 녹음하고, 말하는 사람을 알아보며, AI 노트를 노트 문서에 씁니다. 통화의 모두는 노트가 켜져 있음을 보고 듣습니다. 각 사람은 독의 **노트**에서 자신의 노트를 켜거나 끄고, 자신의 노트 문서를 받습니다.

노트가 켜지면 노트 패널에 지금까지의 대화 기록이 나옵니다. **AI에게 묻기**로 통화를 요약하거나 질문에 답하고, 자신의 메모와 북마크(**⌘B**)를 추가하면 [녹음](/ko/features/meeting-recording)의 통화 항목에 들어갑니다.

노트는 담당자와 기한이 있는 각 할 일, 통화에서 에이전트가 만든 문서와 화이트보드, 에이전트가 공유 화면에서 본 것을 나열합니다.

주최자는 **회의 녹음**을 클릭해 통화를 자신의 컴퓨터에 동영상 파일로 저장할 수도 있습니다. 통화의 모두와 참여하려는 사람은 녹음 중임을 봅니다.

## 주최자 제어

회의를 시작한 사람이 주최자입니다. 할 수 있는 일:

| 제어 | 하는 일 |
| --- | --- |
| 음소거, **음소거 해제 요청**, **모두에게 음소거 해제 요청** | 누군가 또는 모두를 음소거합니다. 요청은 누구의 마이크도 대신 켜지 않습니다. |
| **모두에게 스포트라이트** | 한 사람을 모두에게 크게 만듭니다. 누구든 갤러리로 돌아갈 수 있습니다. |
| **공유 중지** | 누군가의 공유 화면을 중지합니다. |
| 제거 | 누군가를 회의에서 내보냅니다. |
| **회의 잠금** | 새 사람은 주최자가 들이거나 돌려보낼 때까지 대기실에서 기다립니다. |
| **손님은 참여를 요청** | 손님이 들어오기 전에 요청하게 합니다. |
| **주최자로 지정** | 누군가에게 같은 제어를 줍니다. |
| **모두에게 종료** | 모두의 회의를 끝냅니다. |

**모두에게 종료**와 제거는 **취소**에서 시작합니다. 통화에 주최자가 없으면 가장 오래 있던 사람이 **임시 주최자**로 서므로, 잠긴 문 앞의 사람도 들어올 수 있습니다.

## 회의의 에이전트

**사람**에서 에이전트를 회의에 들이거나, 고른 회의에 에이전트가 참여하게 할 수 있습니다. Google Meet나 Zoom 회의로 보낼 수도 있습니다. [통화의 에이전트](/ko/features/agents-in-calls)를 보세요.

## 통화가 끝날 때

마무리 페이지는 통화가 얼마나 길었는지, 누구와 말했는지, 무엇이 저장됐는지, 회의가 계속되는 동안 **다시 참여**를 보여 줍니다.

회의 창이 멈추면 통화가 멈췄다고 알리고 **다시 참여**와 **닫기**를 제공합니다. 연결이 끊기고 5분 안에 돌아오지 않으면 **다시 참여**가 나옵니다. Enconvo는 통화 동안 Mac 디스플레이를 켜 둡니다.

## 설정

**설정 → 화상 회의**를 엽니다.

| 설정 | 하는 일 |
| --- | --- |
| **마이크로 참여**, **카메라로 참여** | 회의에 참여하는 방식. 들어가기 전 페이지에서 여전히 바꿀 수 있습니다. |
| **참여할 때 자막 켜기** | 참여하자마자 자막을 보여 줍니다. 자신만 봅니다. 누군가 필요할 때 각 화자의 기기가 말을 씁니다. |
| **자막 번역** | 자막을 고른 언어로 번역합니다. **끔**은 말한 그대로 보여 줍니다. |
| **내 통화에 노트** | **끔**, **노트**, **노트와 녹음**. 시작, 응답, 참여하는 각 통화와 함께 시작합니다. |
| **녹음** | 노트를 켤 때 녹음이 시작하는 것. **오디오**, 또는 **오디오와 동영상**. |
| **화자로 목소리 알아보기** | 성문으로 말하는 사람의 이름을 붙입니다. 새 목소리는 고를 때만 추가됩니다. [사전과 화자](/ko/configuration/speech-assets)를 보세요. |
| **노트 문서를 공유할 대상** | **통화의 사람** 또는 **나만**. 문서를 소유하며 나중에 바꿀 수 있습니다. |
| **회의의 내 에이전트** | 고른 회의에 에이전트를 들입니다. [통화의 에이전트](/ko/features/agents-in-calls)를 보세요. |
| **아무 앱에서나 음소거 또는 해제** | 기본 **⌃⌥M**인 단축키로, 앞에 있는 앱과 관계없이 회의 중에 동작합니다. 메뉴 막대 아래에 짧은 알림이 나옵니다. 통화 밖에서는 키가 다른 앱에 남습니다. |
| **통화 방해 금지** | **1시간**, **내일까지**, **끌 때까지** 이 Mac에서 통화 벨을 멈춥니다. 메시지는 여전히 알리고, 통화를 시작하고 참여할 수 있습니다. **설정 → 친구**의 달에도 있습니다. |

## 다른 앱의 회의

Zoom, Teams, FaceTime, WeChat 통화에는 [회의 녹음](/ko/features/meeting-recording)을 쓰세요. **설정 → 녹음 → 새 녹음**이 마이크, 통화 오디오, 또는 둘 다를 실시간 대화 기록과 함께 녹음합니다. **새 녹음** 옆 화살표의 **회의 알림**은 그 통화 중 하나가 시작될 때 Dynamic Island에서 녹음할지 묻습니다.

에이전트가 대신 Google Meet나 Zoom 회의에 참여하게 하려면 [통화의 에이전트](/ko/features/agents-in-calls)를 보세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 카메라나 마이크가 허용되지 않음 | 메시지의 **시스템 설정 열기**를 클릭해 Enconvo를 허용한 다음 다시 시도합니다. |
| 참여할 때 마이크가 꺼짐 | 다섯 명 이상의 회의는 음소거로 시작합니다. **마이크**를 클릭하거나 Space를 눌러 말합니다. |
| 누군가 들어올 수 없음 | 회의가 잠겨 있거나 손님이 요청해야 합니다. 대기실에서 들이세요. |
| 다른 사람의 동영상이 멈춤 | 연결이 느리거나 **들어오는 동영상 중지**가 켜져 있습니다. 음성과 공유 화면은 계속됩니다. |
| 이 Mac에서 통화가 울리지 않음 | **설정 → 화상 회의**의 **통화 방해 금지**를 확인합니다. |
| 통화 창이 동작하지 않음 | 창의 메시지에서 **다시 참여**를 클릭합니다. |

SmartBar는 어떤 앱에서든 열어서 에이전트에게 질문하거나 명령을 실행하는 런처입니다. **⌥Space**를 누르고, 입력하고, Return을 누르세요. 빠른 답변이 필요할 때 사용하고, 곧바로 하던 일로 돌아가세요.

다른 용도에는 긴 대화와 파일에는 [채팅 창](/ko/ai/chat), 앱 하나 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에는 [PopBar](/ko/features/popbar), 화면에 계속 떠 있는 작은 진입점으로는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

## 질문하기

1. **⌥Space**를 누르거나, **설정 → SmartBar**에서 지정한 단축키를 누르세요.
2. 질문을 입력하세요. 다른 에이전트나 모델이 필요하면 먼저 선택하세요.
3. 에이전트에게 필요한 컨텍스트를 첨부하세요. 에이전트는 열려 있는 모든 앱을 보지는 못합니다. [컨텍스트 추가하기](#컨텍스트-추가하기)를 참고하세요.
4. Return을 누르고 답변이나 도구 진행 상황을 지켜보세요. 답변을 멈추려면 둥근 정지 버튼을 클릭하세요.
5. 결과를 복사하거나, 후속 질문을 입력해 대화를 이어가세요. 작업이 실행되는 동안 입력한 메시지는 바로 표시됩니다.

입력한 내용이 명령과 일치하면 Return이 강조 표시된 행을 실행합니다. 대신 에이전트에게 보내려면 **⌘Return**을 누르거나 **AI에게 보내기**를 클릭하세요. **⌥Return**은 행의 두 번째 동작을 실행합니다.

에이전트 모드에서는 **권한** 칩이 에이전트가 실행 전에 묻는 시점을 정하고, **샌드박스** 스위치는 에이전트의 명령을 작업 폴더 안으로 제한합니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 참고하세요.

## 트리거 문자로 검색하기

SmartBar에서 다음 문자 중 하나를 입력하면 한 종류의 항목을 검색합니다.

| 입력 | 용도 |
| --- | --- |
| `@` | 명령 검색 |
| `#` | 컨텍스트 추가 |
| `$` | 스킬 사용 |
| `>` | 최근 작업 표시 |
| `/` | 모델과 추론 선택 같은 동작 열기 |

처음 네 가지는 **설정 → SmartBar**의 **검색**에서 바꿀 수 있습니다. `/`는 바꿀 수 없습니다.

이름을 기억해서 입력하지 말고 열리는 목록에서 항목을 고르세요. 목록에는 실제로 사용할 수 있는 명령과 컨텍스트 소스가 표시됩니다. [글쓰기 도구](/ko/features/writing-tools), [빠른 링크](/ko/features/quick-links), [컨텍스트 인식](/ko/features/context-awareness)을 참고하세요.

일부 목록은 별칭으로 열립니다. 별칭을 입력하고 공백을 입력하면 [클립보드 기록, 북마크 검색, 파일 검색](/ko/features/clipboard-history)이 SmartBar 안에서 열립니다.

## 컨텍스트 추가하기

SmartBar는 열릴 때 선택한 텍스트, Finder 선택 항목, 현재 브라우저 페이지를 가져올 수 있습니다. **설정 → 컨텍스트 인식**에서 각 항목을 **자동 추가**, **제안**, **끔** 중에서 고르세요. 그 밖의 것을 추가하려면 `#`을 입력하고 소스를 고르세요.

## 레이아웃 선택하기

**설정 → SmartBar**의 **레이아웃**은 SmartBar를 열었을 때 보이는 모습을 정합니다.

| 레이아웃 | 열리는 화면 |
| --- | --- |
| **입력란만** | 입력란만 표시 |
| **입력란과 도구 막대** | 입력란과 함께 빠른 동작, 모델 선택기, 음성 컨트롤 표시 |
| **전체 패널** | 위의 모든 것과 입력란 아래의 목록 표시 |

**전체 패널**에서는 **초기 화면**이 입력하기 전에 목록에 표시할 내용을 정합니다. **추천 프롬프트** 또는 **명령어 목록** 중에서 고르세요. 모든 레이아웃에서 입력하거나 명령을 실행하면 목록과 결과가 나타납니다.

## 설정

**설정 → SmartBar**를 여세요.

| 설정 | 바뀌는 내용 |
| --- | --- |
| **단축키** | 어떤 앱에서든 SmartBar를 열고 닫습니다. 기본값은 **⌥Space**입니다. |
| **기본 에이전트** | 입력한 내용에 답하는 에이전트입니다. |
| **대화 자동 지우기** | SmartBar를 닫았다가 이 시간이 지난 뒤 열면 새 대화를 시작합니다. **안 함**부터 **열 때마다**까지 고를 수 있습니다. |
| **레이아웃** | SmartBar를 열었을 때 보이는 모습입니다(위 내용 참고). |
| **모양** | SmartBar와 앱 사이드바의 밝거나 어두운 글라스 효과, 또는 **앱 따르기**입니다. |
| **입력 소스 자동 전환** | SmartBar에서 입력하는 동안 이 입력 소스로 전환하고, 닫으면 원래대로 되돌립니다. |
| **탐색 키** | 목록과 텍스트 사이를 이동하는 Control 키 단축키입니다. **macOS**(⌃N ⌃P ⌃F ⌃B) 또는 **Vim**(⌃J ⌃K ⌃L ⌃H) 중에서 고르세요. |
| **검색** | 명령, 컨텍스트, 스킬, 최근 작업의 트리거 문자입니다. |
| **계산기** | 입력하는 동안 수식, 단위, 통화, 날짜, 시간대를 계산해 답합니다. 기본으로 켜져 있습니다. |
| **날씨와 항공편** | 어느 지역이든 날씨, 항공편, 현재 시각도 조회합니다. 기본으로 꺼져 있습니다. |

기본값을 바꿔도 기존 채팅이 모두 바뀌지는 않습니다. 각 채팅이 자신만의 모델과 추론 선택을 유지하는 방식은 [모델 선택](/ko/ai/model-selection-guide)에서 설명합니다.

## 음성과 계산

마이크를 클릭하면 [받아쓰기](/ko/features/dictation)로 질문을 말할 수 있습니다. 음성으로 주고받는 대화는 [Live Talk](/ko/features/live-voice)를 시작하세요. SmartBar에서 시작한 통화는 Dynamic Island로 옮겨 갑니다.

`2+3*4` 같은 산술식을 입력하면 SmartBar가 결과를 보여 줍니다. 계산기는 단위와 통화 변환, 날짜와 시간대 계산, `25% off $60 split by 3`처럼 합계 나누기도 지원합니다. 결과를 복사하기 전에 결과와 제안되는 동작을 확인하세요.

날씨, 항공편, 어느 지역의 현재 시각을 조회하려면 **설정 → SmartBar**에서 **날씨와 항공편**을 켜세요. 그런 다음 `weather in London`, `Tokyo feels like`, `BA008` 같은 항공편 번호, `time in Chernivtsi`를 입력하세요. 지역 이름이나 항공편 번호만 Open-Meteo, adsbdb, adsb.lol로 전송됩니다. **날씨와 항공편**은 [Dynamic Island](/ko/features/dynamic-island)의 계산기와 공유됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| SmartBar가 열리지 않습니다 | **설정 → SmartBar**의 **단축키**를 확인하고, 같은 단축키를 쓰는 다른 앱이 있는지 살펴보세요. 이전에 직접 키를 지정했다면 지정한 그대로 유지됩니다. |
| Return을 누르면 에이전트에게 묻지 않고 명령이 실행됩니다 | **⌘Return**을 누르거나 **AI에게 보내기**를 클릭하세요. |
| 계산이나 날씨 조회에 아무것도 표시되지 않습니다 | **설정 → SmartBar**의 **계산기**와 **날씨와 항공편**을 확인하세요. |
| 컨텍스트에 앱이나 선택한 텍스트가 없습니다 | [권한](/ko/configuration/permissions)과 **설정 → 컨텍스트 인식**을 확인하세요. |
| 요청이 실패합니다 | 선택한 제공업체를 확인하고 표시된 오류를 읽어 보세요. |
| 이 페이지에 나오는 컨트롤이 없습니다 | 사용 중인 빌드가 이 가이드보다 오래되었을 수 있습니다. [업데이트](/ko/configuration/updates)를 참고하세요. |

SmartBar는 어느 앱에서든 열어 에이전트에게 질문하거나 명령을 실행하는 런처입니다. **⌥Space**를 누르고, 입력한 다음 Return을 누릅니다. 빠른 답을 받고 하던 일로 돌아갈 때 씁니다.

다른 일에는 긴 대화와 파일은 [채팅 창](/ko/ai/chat), 한 앱 옆에서 일하려면 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에 대해 행동하려면 [PopBar](/ko/features/popbar), 화면에 남는 작은 입구는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 씁니다. [창 관리](/ko/features/window-management)가 모두를 비교합니다.

## 질문하기

1. **⌥Space**를 누르거나 **설정 → SmartBar**에서 설정한 단축키를 누릅니다.
2. 질문을 입력합니다. 필요하면 먼저 다른 에이전트나 모델을 고릅니다.
3. 에이전트에 필요한 컨텍스트를 첨부합니다. 열린 앱을 모두 보지는 않습니다. [컨텍스트 추가](/ko/features/smartbar)를 보세요.
4. Return을 누르고 답이나 도구 진행을 따릅니다. 답변을 멈추려면 둥근 정지 버튼을 클릭합니다.
5. 결과를 복사하거나, 이어서 입력해 대화를 이어 갑니다. 작업이 실행되는 동안 입력한 메시지는 바로 표시됩니다.

입력한 말이 명령과 맞으면 Return이 강조된 행을 실행합니다. 대신 에이전트에게 보내려면 **⌘Return**을 누르거나 **AI에게 보내기**를 클릭합니다. **⌥Return**은 행의 두 번째 동작을 실행합니다.

에이전트 모드에서 **권한** 칩은 에이전트가 행동하기 전에 언제 묻는지 정하고, **샌드박스** 스위치는 에이전트 명령을 작업 폴더로 제한합니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 보세요.

## 트리거 문자로 검색

SmartBar에 이 문자 중 하나를 입력하면 한 종류의 항목을 검색합니다.

| 입력 | 하는 일 |
| --- | --- |
| `@` | 명령 검색 |
| `#` | 컨텍스트 추가 |
| `$` | 스킬 사용 |
| `>` | 최근 작업 표시 |
| `/` | 모델과 추론 선택 같은 동작 열기 |

앞의 네 가지는 **설정 → SmartBar**의 **검색**에서 바꿀 수 있습니다. `/`는 바꿀 수 없습니다.

이름을 기억해서 입력하지 말고, 열리는 목록에서 고르세요. 목록은 실제로 있는 명령과 컨텍스트 소스를 보여 줍니다. [글쓰기 도구](/ko/features/writing-tools), [퀵링크](/ko/features/quick-links), [컨텍스트 인식](/ko/features/context-awareness)을 보세요.

일부 목록은 별칭으로 열립니다. 별칭과 공백을 입력하면 [클립보드 기록, 북마크 검색, 파일 검색](/ko/features/clipboard-history)이 SmartBar 안에서 열립니다.

## 컨텍스트 추가

SmartBar는 열릴 때 선택한 텍스트, Finder 선택, 현재 브라우저 페이지를 집어 올 수 있습니다. **설정 → 컨텍스트 인식**에서 각각 **첨부**, **제안**, **끔**을 고릅니다. 다른 것을 추가하려면 `#`를 입력하고 소스를 고릅니다.

## 레이아웃 고르기

**설정 → SmartBar**의 **레이아웃**은 SmartBar가 열릴 때 보이는 것을 정합니다.

| 레이아웃 | 열리는 것 |
| --- | --- |
| **입력란만** | 입력 칸만 |
| **입력란과 도구 막대** | 입력, 빠른 동작, 모델 선택, 음성 컨트롤 |
| **전체 패널** | 그 모두와 입력 아래 목록 |

**전체 패널**에서 **초기 화면**은 입력하기 전에 목록이 무엇을 보여 줄지 정합니다. **추천 프롬프트** 또는 **명령어 목록**입니다. 어느 레이아웃이든 입력하거나 명령을 실행하면 목록과 결과가 나타납니다.

## 설정

**설정 → SmartBar**를 엽니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **단축키** | 어느 앱에서든 SmartBar를 열고 닫습니다. 기본은 **⌥Space**입니다. |
| **기본 에이전트** | 입력에 답하는 에이전트입니다. |
| **대화 자동 지우기** | 이만큼 닫혀 있다가 SmartBar가 열리면 새 대화를 시작합니다. **안 함**부터 **열 때마다**까지입니다. |
| **레이아웃** | SmartBar가 열릴 때 보이는 것입니다(위 참고). |
| **모양** | SmartBar와 앱 사이드바의 밝은 유리 또는 어두운 유리, 또는 **앱 따르기**입니다. |
| **입력 소스 자동 전환** | SmartBar에 입력하는 동안 이 입력 소스로 바꾸고, 닫히면 되돌립니다. |
| **탐색 키** | 목록과 텍스트를 이동하는 Control 키 단축키입니다. **macOS**(⌃N ⌃P ⌃F ⌃B) 또는 **Vim**(⌃J ⌃K ⌃L ⌃H)입니다. |
| **검색** | 명령, 컨텍스트, 스킬, 최근 작업의 트리거 문자입니다. |
| **계산기** | 입력하면서 수학, 단위, 통화, 날짜, 시간대에 답합니다. 기본은 켜짐입니다. |
| **날씨와 항공편** | 날씨, 항공편, 어느 곳의 시간도 찾습니다. 기본은 꺼짐입니다. |

기본값을 바꿔도 기존 채팅이 모두 바뀌지는 않습니다. [모델 선택](/ko/ai/model-selection-guide)이 각 채팅이 자체 모델과 추론 선택을 어떻게 유지하는지 설명합니다.

## 음성과 계산

마이크를 클릭하면 [받아쓰기](/ko/features/dictation)로 질문을 말합니다. 말로 주고받으려면 [Live Talk](/ko/features/live-voice)를 시작합니다. SmartBar에서 시작한 통화는 Dynamic Island로 이동합니다.

`2+3*4` 같은 산술식을 입력하면 SmartBar가 결과를 보여 줍니다. 계산기는 단위와 통화를 변환하고, 날짜와 시간대를 다루며, `25% off $60 split by 3`처럼 합계를 나눕니다. 복사하기 전에 결과와 제공하는 동작을 확인하세요.

날씨, 항공편, 어느 곳의 시간을 찾으려면 **설정 → SmartBar**에서 **날씨와 항공편**을 켭니다. 그다음 `weather in London`, `Tokyo feels like`, `BA008` 같은 항공편 번호, `time in Chernivtsi`를 입력합니다. 장소 이름이나 항공편 번호만 Open-Meteo, adsbdb, adsb.lol로 보내집니다. **날씨와 항공편**은 [Dynamic Island](/ko/features/dynamic-island)의 계산기와 공유됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| SmartBar가 열리지 않음 | **설정 → SmartBar**의 **단축키**를 확인하고, 같은 단축키를 쓰는 다른 앱을 찾습니다. 예전에 직접 키를 설정했다면 그대로 유지됩니다. |
| Return이 에이전트에게 묻지 않고 명령을 실행함 | **⌘Return**을 누르거나 **AI에게 보내기**를 클릭합니다. |
| 합계나 날씨 조회가 아무것도 보여 주지 않음 | **설정 → SmartBar**의 **계산기**와 **날씨와 항공편**을 확인합니다. |
| 앱이나 선택한 텍스트가 컨텍스트에 없음 | [권한](/ko/configuration/permissions)과 **설정 → 컨텍스트 인식**을 확인합니다. |
| 요청 실패 | 선택한 제공업체를 확인하고 보고된 오류를 읽습니다. |
| 이 페이지의 컨트롤이 없음 | 빌드가 이 가이드보다 오래되었을 수 있습니다. [업데이트](/ko/configuration/updates)를 보세요. |

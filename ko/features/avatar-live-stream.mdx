---

[Live Photo 캐릭터](/ko/features/avatar)는 라이브 방송의 진행자가 될 수 있습니다. Enconvo는 OBS에 캐릭터의 움직이는 모습이 담긴 스테이지와 자막 페이지를 제공하며, 캐릭터는 방송의 채팅을 읽고 Agent를 통해 시청자에게 소리 내어 답할 수 있습니다.

## 시작하기 전에

- **설정 → 아바타**에서 Live Photo 캐릭터를 만들고 Agent에 연결하세요.
- OBS Studio를 설치하세요. 방송 패널의 **OBS Studio 받기**에서 링크로 이동할 수 있습니다.

<Note>
Atmee는 통화가 진행되는 동안, 방송 여부와 관계없이, 그리고 라이브 모드에서 캐릭터가 답변을 말하는 동안 캐릭터의 실시간 영상을 분 단위로 청구합니다.
</Note>

## 방송 패널 열기

1. **설정 → 아바타**를 열고 **Live Photo** 탭을 엽니다.
2. 캐릭터 카드에서 **방송 시작**을 클릭합니다.

방송 패널에는 캐릭터의 스테이지, 자막, 방향(**세로 9:16** 또는 **가로 16:9**), OBS의 방송 상태가 표시됩니다. 스테이지에는 아바타를 열어야 캐릭터가 나타납니다.

## OBS에 추가하기

1. OBS에서 **도구 → WebSocket 서버 설정**을 열고 **WebSocket 서버 사용**을 체크한 다음 **적용**을 클릭합니다.
2. **연결 정보 표시**를 클릭하고 서버 암호를 복사합니다.
3. 방송 패널에서 **OBS 연결**을 클릭하고 암호를 붙여 넣습니다. Enconvo는 암호를 다른 인증 정보와 함께 보관합니다.
4. **OBS에 추가**를 클릭합니다. Enconvo가 방송 크기에 맞춘 캐릭터 스테이지와 자막이 담긴 "Enconvo · *캐릭터 이름*"이라는 장면을 만듭니다.
5. OBS에서 방송을 시작하거나 패널의 **방송 시작**을 사용합니다. **방송 종료**를 누르면 멈춥니다.

방향을 바꾸면 **OBS에 추가**를 다시 클릭해 캐릭터 장면의 크기를 조정하세요. 장면을 직접 만들려면 패널의 투명 스테이지 페이지와 자막 페이지를 OBS에 **브라우저** 소스로 추가하세요.

## 캐릭터 배경 고르기

패널의 **백그라운드**에서 OBS가 캐릭터 뒤에 받을 배경을 고릅니다. OBS에는 스테이지 미리보기에 보이는 그대로 표시됩니다.

| 선택 | OBS가 받는 것 |
| --- | --- |
| **투명** | 알파 채널이 있는 캐릭터만 받습니다. OBS 장면이 캐릭터 뒤에 보입니다. |
| **색상** | **그린 스크린**이나 **사용자 지정 색상**처럼 한 가지 색으로 채운 전체 화면입니다. |
| **이미지** | 이 Mac에 보관된 내 이미지로 채운 전체 화면입니다. |
| **사진 흐리게** | 캐릭터 사진을 흐리게 처리해 채운 전체 화면입니다. |
| **원본 사진** | 캐릭터의 원본 사진입니다. |

프레임이 있는 **배경**으로 저장한 캐릭터는 자신의 사진과 프레임을 유지하며, 백그라운드 설정은 오려 낸 캐릭터에 적용됩니다.

## 라이브 채팅에 답하게 하기

1. 방송 패널에서 **Twitch 채널** 또는 **Kick 채널**을 입력하거나, YouTube Data API 키로 YouTube를 연결합니다.
2. 캐릭터가 누구에게 답할지 정합니다. 캐릭터를 언급한 시청자, `!ask`로 질문한 시청자, 또는 후원한 시청자입니다. 시청자별 대기 시간과 전체 대기 시간, 차단 단어를 설정하고, 질문을 하나씩 승인하려면 승인 후 처리 대기열을 켭니다.
3. **라이브 채팅 시작**을 클릭합니다.

캐릭터는 Agent를 통해 소리 내어 답합니다.

### 라이브 모드

패널에서 **라이브 모드**를 켜면 통화 없이도 캐릭터가 OBS 스테이지에서 입술을 움직이며 각 답변을 말합니다. 꺼져 있으면 답변이 이 Mac에서 소리 내어 읽힙니다.

## 소리

통화 중 스테이지에 캐릭터가 표시되는 동안에는 캐릭터의 음성이 OBS에서만 재생됩니다. **이 Mac에서도 재생**을 켜면 Mac에서도 들을 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 스테이지가 비어 있음 | 캐릭터의 아바타를 여세요. 통화 중에는 스테이지에 캐릭터가 실시간으로 표시됩니다. |
| OBS가 연결되지 않음 | OBS에서 **WebSocket 서버 사용**이 체크되어 있는지 확인하고 암호를 다시 붙여 넣으세요. |
| 캐릭터 장면의 크기가 맞지 않음 | 방향을 바꾼 뒤 **OBS에 추가**를 다시 클릭하세요. |
| 백그라운드가 바뀌지 않음 | 캐릭터가 프레임이 있는 **배경**으로 저장되어 있습니다. 백그라운드는 오려 낸 캐릭터에 적용됩니다. |
| 소리가 두 번 들리거나 전혀 안 들림 | **이 Mac에서도 재생**을 확인하세요. |

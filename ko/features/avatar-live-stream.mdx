---

[Live Photo 캐릭터](/ko/features/avatar)가 라이브 방송을 진행할 수 있습니다. Enconvo는 OBS에 움직이는 그림과 자막 페이지가 있는 무대를 주고, 방송 채팅을 읽어 에이전트를 통해 시청자에게 소리 내어 답할 수 있습니다.

## 시작하기 전에

- **설정 → 아바타**에서 Live Photo 캐릭터를 만들고 에이전트에 연결하세요.
- OBS Studio를 설치하세요. 방송 패널의 **OBS Studio 받기**가 그곳으로 연결됩니다.

<Note>
Atmee는 방송을 하든 하지 않든 통화가 실행되는 동안, 그리고 라이브 모드에서 답을 말하는 동안 라이브 영상을 분 단위로 청구합니다.
</Note>

## 방송 패널 열기

1. **설정 → 아바타**와 **Live Photo** 탭을 여세요.
2. 카드의 **방송 시작**을 클릭하세요.

방송 패널은 무대, 자막, 방향(**세로 9:16** 또는 **가로 16:9**), OBS 방송 상태를 보여 줍니다. 아바타가 열리면 무대에 캐릭터가 나타납니다.

## OBS에 추가

1. OBS에서 **도구 → WebSocket 서버 설정**을 열고 **WebSocket 서버 사용**을 선택한 뒤 **적용**을 클릭하세요.
2. **연결 정보 표시**를 클릭하고 서버 비밀번호를 복사하세요.
3. 방송 패널에서 **OBS 연결**을 클릭하고 비밀번호를 붙여 넣으세요. Enconvo는 다른 자격 증명과 함께 보관합니다.
4. **OBS에 추가**를 클릭하세요. Enconvo가 방송 크기에 맞춰 무대와 자막이 있는 “Enconvo · *이름*” 장면을 만듭니다.
5. OBS에서 방송을 시작하거나, 패널의 **방송 시작**으로 시작하세요. **방송 종료**가 멈춥니다.

방향을 바꾸면 **OBS에 추가**를 다시 클릭해 장면 크기를 맞추세요. 장면을 직접 만들려면 패널의 투명 무대 페이지와 자막 페이지를 OBS에 **브라우저** 소스로 추가하세요.

## 배경 고르기

패널의 **백그라운드** 아래에서 OBS가 캐릭터 뒤에 받는 것을 고르세요. OBS는 무대 미리보기가 보여 주는 그대로를 보여 줍니다.

| 선택 | OBS가 받는 것 |
| --- | --- |
| **투명** | 알파가 있는 캐릭터만. OBS 장면이 뒤에 보입니다. |
| **색상** | **그린 스크린**이나 **사용자 지정 색상**처럼 한 색의 전체 프레임. |
| **이미지** | 이 Mac에 보관된 본인 이미지의 전체 프레임. |
| **사진 흐리게** | 흐린 사진의 전체 프레임. |
| **원본 사진** | 원본 사진. |

프레임 **배경**으로 저장된 캐릭터는 자기 사진과 프레임을 유지합니다. 배경은 오려낸 캐릭터에 적용됩니다.

## 라이브 채팅에 답하게 하기

1. 방송 패널에 **Twitch 채널**이나 **Kick 채널**을 입력하거나, YouTube Data API 키로 YouTube를 연결하세요.
2. 누구의 말에 답할지 정하세요. 자신을 언급한 시청자, `!ask`로 묻는 사람, 또는 결제한 사람입니다. 시청자별·전체 대기 시간과 차단 단어를 정하고, 각 질문을 승인하려면 승인 우선 대기열을 켜세요.
3. **라이브 채팅 시작**을 클릭하세요.

에이전트를 통해 소리 내어 답합니다.

### 라이브 모드

패널에서 **라이브 모드**를 켜면 통화 없이 OBS 무대에서 입술을 움직이며 각 답을 말합니다. 끄면 이 Mac에서 답을 읽어 줍니다.

## 소리

통화 중 무대에 캐릭터가 보이면 목소리는 OBS에서만 나옵니다. Mac에서도 들으려면 **이 Mac에서도 재생**을 켜세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 무대가 비어 있음 | 아바타를 여세요. 통화 중에는 무대가 실시간으로 보여 줍니다. |
| OBS가 연결되지 않음 | OBS에서 **WebSocket 서버 사용**이 선택됐는지 확인하고, 비밀번호를 다시 붙여 넣으세요. |
| 장면 크기가 틀림 | 방향을 바꾼 뒤 **OBS에 추가**를 다시 클릭하세요. |
| 배경이 바뀌지 않음 | 캐릭터가 프레임 **배경**으로 저장됐습니다. 배경은 오려낸 캐릭터에 적용됩니다. |
| 두 번 들리거나 전혀 안 들림 | **이 Mac에서도 재생**을 확인하세요. |

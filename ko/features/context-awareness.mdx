컨텍스트란 질문과 함께 전달되는 정보입니다. 선택한 텍스트, Finder에서 선택한 파일, 브라우저에 열려 있는 페이지, 스크린샷 등이 여기에 해당합니다. SmartBar는 열릴 때 이 중 일부를 자동으로 가져올 수 있으며, `#`을 입력해 더 추가할 수도 있습니다. 그러면 에이전트가 별도 설명 없이도 지금 보고 있는 내용을 바탕으로 답변합니다.

## SmartBar가 가져올 항목 고르기

1. **설정 → 컨텍스트 인식**을 엽니다.
2. **Smart Bar를 열 때** 아래에서 각 소스를 **자동 추가**, **제안**, 또는 **끔**으로 설정합니다.
3. 다른 앱으로 전환해 무언가를 선택한 다음 SmartBar를 열어 결과를 확인합니다.

| 소스 | 추가되는 내용 | 기본값 |
| --- | --- | --- |
| **선택한 텍스트** | 사용 중이던 앱에서 선택한 텍스트 | **자동 추가** |
| **Finder 선택 항목** | Finder에서 선택한 파일과 폴더 | **제안** |
| **브라우저의 현재 페이지** | Safari, Chrome, Arc, Edge 또는 기타 Chromium 브라우저에 열려 있는 페이지 | **제안** |

**자동 추가**는 SmartBar가 열리자마자 입력창에 해당 소스를 바로 넣습니다. **제안**은 명령 목록 위에 표시해 클릭 한 번으로 추가할 수 있게 합니다. **끔**은 이를 포함하지 않습니다.

이 설정은 SmartBar에만 적용됩니다. 선택한 항목에 바로 실행하는 명령은 항상 선택한 텍스트를 전달받습니다. Finder나 브라우저 컨텍스트를 처음 추가할 때 macOS가 Enconvo의 해당 앱 제어 허용 여부를 묻습니다.

## #으로 컨텍스트 추가하기

1. SmartBar에서 `#`을 입력합니다.
2. `#screen`, `#finder`, `#clipboard`, `#browser`처럼 단어를 입력해 목록을 좁힙니다.
3. 소스를 고르면 메시지에 추가됩니다.
4. 질문을 입력하고 전송합니다.

| 소스 | 추가되는 내용 |
| --- | --- |
| **선택한 텍스트** | 현재 창에서 선택한 텍스트 |
| **클립보드 텍스트** | 클립보드에 복사된 텍스트 |
| **현재 애플리케이션 콘텐츠** | 맨 앞 앱의 텍스트 |
| **현재 애플리케이션 스크린샷** | 맨 앞 앱의 스크린샷 |
| **현재 화면 스크린샷** | 전체 화면의 스크린샷 |
| **라이브 화면 스크린샷** | Enconvo 창을 제외한 화면 스크린샷 |
| **사용자 지정 영역 스크린샷** | 사용자가 선택한 영역의 스크린샷 |
| **Finder 선택 항목** | Finder에서 선택한 파일과 폴더 |
| **Finder 현재 디렉토리 URL** | Finder에 열려 있는 폴더 |
| **브라우저 현재 탭 URL** | 브라우저의 현재 탭 주소 |

열려 있는 창들도 목록에 함께 표시되므로 다른 앱의 창을 추가할 수 있습니다. `#` 대신 다른 문자를 사용하려면 **설정 → SmartBar**의 **검색** 아래에서 **컨텍스트** 항목을 변경하세요.

## 무엇을 물어볼 수 있나요

브라우저 페이지가 첨부된 상태에서는 페이지를 요약하거나 번역하고 핵심 정보를 추출해 달라고 요청해 보세요. Finder 파일이 첨부된 상태에서는 파일 설명, 정리 방법 제안, 일괄 이름 변경 도움, 내용 분석을 요청할 수 있습니다.

<Note>
첨부한 컨텍스트는 응답하는 모델이나 이를 처리하는 제공업체로 전송됩니다. 민감한 내용을 다루기 전에 첨부된 항목과 제공업체 설정을 확인하세요.
</Note>

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 선택한 텍스트가 첨부되지 않음 | **선택한 텍스트**가 **자동 추가**로 설정되어 있는지 확인하고 [권한](/ko/configuration/permissions)을 점검하세요. |
| Finder 또는 브라우저 컨텍스트가 표시되지 않음 | macOS가 요청할 때 Enconvo의 해당 앱 제어를 허용하세요. 거절했다면 [권한](/ko/configuration/permissions)에서 허용할 수 있습니다. |
| `#`을 입력해도 목록이 열리지 않음 | **설정 → SmartBar**에서 **컨텍스트** 문자를 확인하세요. |

---

컨텍스트는 질문과 함께 전달되는 내용입니다. 선택한 텍스트, Finder에서 선택한 파일, 브라우저에 열린 페이지, 스크린샷 등이 해당됩니다. SmartBar는 열릴 때 일부를 자동으로 가져올 수 있으며, `#`을 입력해 더 추가할 수 있습니다. 그러면 Agent는 내가 설명하지 않아도 내가 보고 있는 것에 대해 답합니다.

## SmartBar가 가져올 내용 고르기

1. **설정 → 컨텍스트 인식**을 엽니다.
2. **Smart Bar를 열 때** 아래에서 각 소스를 **자동 추가**, **제안**, **끔** 중 하나로 설정합니다.
3. 다른 앱으로 전환해 무언가를 선택하고 SmartBar를 열어 결과를 확인합니다.

| 소스 | 추가되는 내용 | 기본값 |
| --- | --- | --- |
| **선택한 텍스트** | 사용 중이던 앱에서 선택한 텍스트 | **자동 추가** |
| **Finder 선택 항목** | Finder에서 선택한 파일과 폴더 | **제안** |
| **브라우저의 현재 페이지** | Safari, Chrome, Arc, Edge 또는 다른 Chromium 브라우저에 열린 페이지 | **제안** |

**자동 추가**는 SmartBar가 열리자마자 해당 소스를 입력란에 추가합니다. **제안**은 명령 위에 소스를 나열하여 한 번의 클릭으로 추가할 수 있게 합니다. **끔**은 제외합니다.

이 설정은 SmartBar에서만 사용됩니다. 선택 영역에 대해 실행하는 명령은 항상 선택한 텍스트를 받습니다. Finder나 브라우저 컨텍스트를 처음 추가할 때 macOS가 Enconvo가 해당 앱을 제어해도 되는지 묻습니다.

## #으로 컨텍스트 추가하기

1. SmartBar에서 `#`을 입력합니다.
2. `#screen`, `#finder`, `#clipboard`, `#browser`처럼 단어를 입력해 목록을 좁힙니다.
3. 소스를 고릅니다. 메시지에 추가됩니다.
4. 질문을 입력하고 보냅니다.

| 소스 | 추가되는 내용 |
| --- | --- |
| **Selected Text** | 현재 창에서 선택한 텍스트 |
| **Clipboard Text** | 클립보드에 있는 텍스트 |
| **Current Application Content** | 맨 앞에 있는 앱의 텍스트 |
| **Current Application Screenshot** | 맨 앞에 있는 앱의 스크린샷 |
| **Current Screen Screenshot** | 전체 화면의 스크린샷 |
| **Live Screen Screenshot** | Enconvo 창을 제외한 화면의 스크린샷 |
| **User Select Area Screenshot** | 내가 선택한 영역의 스크린샷 |
| **Finder Selected Items** | Finder에서 선택한 파일과 폴더 |
| **Finder Current Directory URL** | Finder에 열린 폴더 |
| **Browser Current Tab URL** | 브라우저의 현재 탭 주소 |

열려 있는 창도 나열되므로 다른 앱의 창을 추가할 수 있습니다. `#` 대신 다른 문자를 사용하려면 **설정 → SmartBar**의 **검색**에서 **컨텍스트**를 변경하세요.

## 무엇을 물어볼까

브라우저 페이지를 첨부한 상태에서는 Enconvo에게 페이지를 요약하거나, 번역하거나, 핵심 정보를 추출해 달라고 요청하세요. Finder 파일을 첨부한 상태에서는 파일을 설명하거나, 정리 방법을 제안하거나, 일괄 이름 변경을 돕거나, 내용을 분석해 달라고 요청하세요.

<Note>
첨부한 컨텍스트는 답하는 모델 또는 이를 처리하는 제공업체로 전송됩니다. 민감한 콘텐츠를 다루기 전에 첨부된 내용과 제공업체 설정을 검토하세요.
</Note>

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 선택한 텍스트가 첨부되지 않음 | **선택한 텍스트**가 **자동 추가**로 설정되어 있는지 확인하고 [권한](/ko/configuration/permissions)을 확인하세요. |
| Finder나 브라우저 컨텍스트가 없음 | macOS가 물을 때 Enconvo가 해당 앱을 제어하도록 허용하세요. 거절했다면 [권한](/ko/configuration/permissions)에서 허용하세요. |
| `#`을 입력해도 목록이 열리지 않음 | **설정 → SmartBar**의 **컨텍스트** 문자를 확인하세요. |

Dynamic Island는 화면 위쪽 가운데에 있습니다. 가리키면 홈이 열리고, 요청을 입력하거나 말하고, 컨텍스트를 첨부하고, 바로 가기를 실행하거나, 진행 중인 작업으로 돌아갈 수 있습니다. 창을 열지 않고 빠른 요청과 에이전트가 하는 일을 지켜볼 때 쓰세요.

다른 일에는 단축키로 빠른 질문이나 명령을 할 [SmartBar](/ko/features/smartbar), 긴 대화와 파일을 위한 [채팅 창](/ko/ai/chat), 한 앱 옆에서 일하는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에 행동하는 [PopBar](/ko/features/popbar), 바탕화면의 캐릭터인 [데스크톱 펫](/ko/features/pet)을 쓰세요. [창 관리](/ko/features/window-management)가 이들을 비교합니다.

## 요청 시작

1. **설정 → Dynamic Island**를 열고 **Dynamic Island 활성화**를 켜세요.
2. 화면 위쪽 가운데를 가리켜 홈을 여세요. 키보드로 열려면 먼저 **열기 및 표시** 탭에서 **단축키**를 설정하세요.
3. 요청을 입력하거나 **홈 바로 가기** 중 하나를 클릭하세요.
4. 보내기 전에 첨부된 컨텍스트를 확인하세요. [Appshots](/ko/features/appshots)와 [화면 낙서](/ko/features/screen-doodle)가 다른 앱에 대해 묻는 데 도움이 됩니다.
5. 진행을 따라가고, 작업이 끝나면 결과를 여세요. 답변을 멈추려면 **중지**를 클릭하거나 Esc를 누르세요.

작업이 실행되는 동안 입력한 메시지는 바로 보입니다. 채팅 창으로 옮기려면 아일랜드 위쪽 막대의 **채팅 창에서 열기**를 클릭하세요. 채팅이 시작되기 전이면 그곳에서 새 채팅을 열고 입력한 내용을 가져갑니다.

에이전트 모드에서 **권한** 칩은 에이전트가 행동하기 전에 언제 묻는지 정하고, **샌드박스** 스위치는 에이전트 명령을 작업 폴더로 제한합니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 보세요.

## 홈에서 계산하기

홈에 합, 변환, 시간을 입력하면 아일랜드 아래 카드에 답이 나타납니다. Return으로 복사하거나, **⌘Return**으로 대신 에이전트에게 물어보세요.

계산기는 수학, 단위, 통화, 날짜, 시간대를 다룹니다. 날씨, 항공편, 어느 곳의 시간도 보려면 **설정 → Dynamic Island → 홈**에서 **날씨와 항공편**을 켜세요. 장소 이름이나 항공편 번호만 Open-Meteo, adsbdb, adsb.lol로 전송됩니다. 이 스위치는 [SmartBar](/ko/features/smartbar)와 공유됩니다.

## 작업 따라가기

작업 목록은 실행 중이고, 승인이 필요하고, 실패했거나, 결과가 준비된 채팅을 보여 줍니다. 둘 이상의 작업이 실행되면 하나의 **작업** 칩으로 접힙니다.

1. 홈이나 노치의 작업 칩을 클릭하세요. 목록이 입력창 자리에 열립니다.
2. 그 줄에서 바로 승인을 허용하거나 거절하세요.
3. 다른 채팅을 클릭하면 시작된 창에서 열립니다.

읽지 않은 채팅을 찾으려면 **기록**을 열고 **읽지 않음**으로 거르세요. **모두 읽음으로 표시**가 모두 지우고, 마음이 바뀌면 **실행 취소**가 있습니다. 채팅 목록에는 **채팅 보관**과 **채팅 삭제**도 있습니다.

## 설정

**설정 → Dynamic Island**를 여세요. 설정은 세 탭에 있습니다.

### 홈

| 설정 | 바뀌는 것 |
| --- | --- |
| **홈 바로 가기** | 홈의 입력 옆 바로 가기 격자입니다. 바로 가기를 끌어 순서를 바꾸거나 다른 페이지로 옮기고, 가리킨 뒤 **×**를 클릭해 빼거나, **바로 가기 추가**로 더 넣으세요. |
| 날씨와 위젯 페이지 | 바로 가기 뒤에 **날씨 페이지 추가** 또는 **위젯 페이지 추가**. |
| **계산기** | 홈에 입력하는 대로 수학, 단위, 통화, 날짜, 시간대에 답합니다. |
| **날씨와 항공편** | 날씨, 항공편, 어느 곳의 시간도 찾습니다. SmartBar와 공유됩니다. |
| **기본 에이전트** | 홈에 입력한 것에 답하는 에이전트입니다. 빈 홈은 버튼이 보여 주는 기본 에이전트를 항상 실행합니다. 입력창에서 언제든 에이전트를 바꿀 수 있습니다. |

**홈을 기본값으로 재설정**은 홈의 기본 배치를 되돌립니다. 각 탭에 자기 재설정 버튼이 있습니다.

### 열기 및 표시

| 설정 | 바뀌는 것 |
| --- | --- |
| **포인터를 올리면 열기** | 열리기 전에 얼마나 가리키는지입니다. **즉시**, **잠깐 후**, **조금 오래 후**. |
| **포인터가 벗어나면 접기** | 포인터가 떠난 뒤 얼마나 열려 있는지입니다. **빠르게**(0.5초), **보통**, **천천히**. |
| **단축키** | 아무 앱에서 아일랜드를 보여 주거나, 열거나, 접습니다. |
| **포인터를 올릴 때까지 숨기기** | 화면 위쪽 가운데를 가리키거나 단축키를 누를 때까지 접힌 아일랜드를 숨깁니다. |
| **노치를 다른 앱에 양보** | 노치 자체를 가리켜도 아일랜드가 열리지 않아, 다른 노치 앱이 쓸 수 있습니다. |
| **바운스** | 열리고 접힐 때 아일랜드가 얼마나 튀는지입니다. |
| **표시 위치** | **모든 화면**, **마우스 따라가기**, 또는 고른 디스플레이 하나. |
| **전체 화면에서 숨기기** | 앱이 전체 화면인 디스플레이에서 쉬는 알약을 숨겨, 앱 위를 가리지 않습니다. 기본값은 켬입니다. 앱이 전체 화면이라고 보고하는 창만 해당하며, 최대화된 창은 아닙니다. 가리키거나 말하면 여전히 올라옵니다. |
| **스크린샷과 녹화에 표시** | 끄면 캡처하거나 공유하는 것에서 아일랜드를 뺍니다. |

### 캐릭터

| 설정 | 바뀌는 것 |
| --- | --- |
| **아일랜드에 캐릭터 표시** | 데스크톱 펫이나 기본 에이전트의 아바타가 접힌 아일랜드에 나타나 에이전트가 하는 일을 연기합니다. |
| **캐릭터** | **아바타** 또는 **펫**. |
| **움직임** | **항상**, **작업 중일 때**, **안 함**. |
| **에이전트 아이콘으로 사용** | 채팅 창에서 기본 에이전트 아이콘으로 캐릭터를 보여 줍니다. |

## 음성과 끝난 작업

음성 입력은 말한 것을 프롬프트로 바꿉니다. 말로 하는 대화는 [Live Talk](/ko/features/live-voice)를 쓰세요. SmartBar에서 시작한 Live Talk 통화는 Dynamic Island로 이동합니다.

그곳에서 시작한 작업이 끝날 때 아일랜드가 스스로 열리게 하려면 [알림](/ko/configuration/notifications)에서 **Dynamic Island 열기**를 켜세요. 이 설정은 macOS 알림과 별개입니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 다른 디스플레이에 나타남 | **표시 위치**를 확인하세요. |
| 앱이 전체 화면이면 사라짐 | 기본 동작입니다. 화면 위를 가리켜 열거나 **전체 화면에서 숨기기**를 끄세요. |
| 메뉴 막대가 스스로 숨으면 열리지 않음 | 화면 위쪽 가운데를 클릭하세요. |
| 홈에서 수학이나 조회가 아무것도 안 보임 | **홈** 탭의 **계산기**와 **날씨와 항공편**을 확인하세요. |
| 스크린샷이나 녹화에 없음 | 권한을 바꾸기 전에 **스크린샷과 녹화에 표시**를 켜세요. |
| 가리켜도 열리지 않음 | 단축키를 누르세요. 단축키로 열리면 **포인터를 올리면 열기**와 **노치를 다른 앱에 양보**를 확인하세요. 아무것도 열지 않으면 **Dynamic Island 활성화**를 확인하세요. |

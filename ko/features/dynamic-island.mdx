Dynamic Island는 화면 상단 중앙에 있습니다. 포인터를 올리면 홈이 열리며, 여기서 요청을 입력하거나 말하고, 컨텍스트를 첨부하고, 바로 가기를 실행하고, 진행 중인 작업으로 돌아갈 수 있습니다. 빠른 요청을 하거나, 창을 열지 않고 에이전트가 하는 일을 지켜볼 때 사용하세요.

다른 용도에는 단축키로 하는 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 긴 대화와 파일은 [채팅 창](/ko/ai/chat), 앱 하나 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에는 [PopBar](/ko/features/popbar), 데스크톱의 캐릭터는 [데스크톱 펫](/ko/features/pet)을 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

## 요청 시작하기

1. **설정 → Dynamic Island**를 열고 **Dynamic Island 활성화**를 켜세요.
2. 화면 상단 중앙에 포인터를 올려 홈을 여세요. 키보드로 열려면 먼저 **열기 및 표시** 탭에서 **단축키**를 설정하세요.
3. 요청을 입력하거나 **홈 바로 가기** 중 하나를 클릭하세요.
4. 보내기 전에 첨부된 컨텍스트를 확인하세요. [Appshots](/ko/features/appshots)와 [화면 낙서](/ko/features/screen-doodle)로 다른 앱에 대해 질문할 수 있습니다.
5. 진행 상황을 지켜보고, 작업이 끝나면 결과를 여세요. 답변을 멈추려면 **중지**를 클릭하거나 Esc를 누르세요.

작업이 실행되는 동안 입력한 메시지는 바로 표시됩니다. 채팅 창으로 옮기려면 아일랜드 상단 막대의 **채팅 창에서 열기**를 클릭하세요. 채팅이 시작되기 전에는 그곳에 새 채팅을 열고 입력한 내용을 함께 가져갑니다.

에이전트 모드에서는 **권한** 칩이 에이전트가 실행 전에 묻는 시점을 정하고, **샌드박스** 스위치는 에이전트의 명령을 작업 폴더 안으로 제한합니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 참고하세요.

## 홈에서 계산하기

홈에 합계, 변환, 시간을 입력하면 아일랜드 아래의 카드에 답이 나타납니다. Return을 눌러 복사하거나, **⌘Return**을 눌러 대신 에이전트에게 물어보세요.

계산기는 수식, 단위, 통화, 날짜, 시간대를 처리합니다. 날씨, 항공편, 어느 지역의 현재 시각도 조회하려면 **설정 → Dynamic Island → 홈**에서 **날씨와 항공편**을 켜세요. 지역 이름이나 항공편 번호만 Open-Meteo, adsbdb, adsb.lol로 전송됩니다. 이 스위치는 [SmartBar](/ko/features/smartbar)와 공유됩니다.

## 작업 따라가기

작업 목록에는 실행 중이거나, 승인이 필요하거나, 실패했거나, 결과가 준비된 채팅이 표시됩니다. 작업이 둘 이상 실행되면 하나의 **작업** 칩으로 접힙니다.

1. 홈이나 노치의 작업 칩을 클릭하세요. 입력란 자리에 목록이 열립니다.
2. 행에서 바로 승인을 허용하거나 거절하세요.
3. 다른 채팅을 클릭하면 그 채팅이 시작된 창에서 열립니다.

읽지 않은 채팅을 찾으려면 **기록**을 열고 **읽지 않음**으로 필터링하세요. **모두 읽음으로 표시**는 모두 지우며, 마음이 바뀌면 **실행 취소**할 수 있습니다. 채팅 목록에는 **채팅 보관**과 **채팅 삭제**도 있습니다.

## 설정

**설정 → Dynamic Island**를 여세요. 설정은 세 개의 탭에 있습니다.

### 홈

| 설정 | 바뀌는 내용 |
| --- | --- |
| **홈 바로 가기** | 홈의 입력란 옆에 있는 바로 가기 격자입니다. 바로 가기를 드래그해 순서를 바꾸거나 다른 페이지로 옮기고, 포인터를 올리고 **×**를 클릭해 제거하거나, **바로 가기 추가**를 클릭해 더 추가하세요. |
| 날씨 및 위젯 페이지 | 바로 가기 뒤에 **날씨 페이지 추가** 또는 **위젯 페이지 추가**를 할 수 있습니다. |
| **계산기** | 홈에서 입력하는 동안 수식, 단위, 통화, 날짜, 시간대에 답합니다. |
| **날씨와 항공편** | 어느 지역이든 날씨, 항공편, 현재 시각도 조회합니다. SmartBar와 공유됩니다. |
| **기본 에이전트** | 홈에서 입력한 내용에 답하는 에이전트입니다. 비어 있는 홈은 항상 버튼에 표시된 기본 에이전트를 실행합니다. 입력란에서 언제든 에이전트를 바꿀 수 있습니다. |

**홈을 기본값으로 재설정**은 홈의 기본 레이아웃을 되돌립니다. 각 탭에는 자체 재설정 버튼이 있습니다.

### 열기 및 표시

| 설정 | 바뀌는 내용 |
| --- | --- |
| **포인터를 올리면 열기** | 포인터를 올린 뒤 열릴 때까지의 시간입니다. **즉시**, **잠깐 후**, **조금 오래 후** 중에서 고르세요. |
| **포인터가 벗어나면 접기** | 포인터가 벗어난 뒤 열려 있는 시간입니다. **빠르게**(0.5초), **보통**, **천천히** 중에서 고르세요. |
| **단축키** | 어떤 앱에서든 아일랜드를 표시하거나, 열거나, 접습니다. |
| **포인터를 올릴 때까지 숨기기** | 화면 상단 중앙에 포인터를 올리거나 단축키를 누를 때까지 접힌 아일랜드를 보이지 않게 합니다. |
| **노치를 다른 앱에 양보** | 노치 자체에 포인터를 올려도 아일랜드가 열리지 않으므로, 다른 노치 앱이 노치를 사용할 수 있습니다. |
| **바운스** | 아일랜드가 열리고 접힐 때 튀어 오르는 정도입니다. |
| **표시 위치** | **모든 화면**, **마우스 따라가기**, 또는 직접 고른 디스플레이 하나입니다. |
| **전체 화면에서 숨기기** | 디스플레이의 앱이 전체 화면인 동안 아일랜드의 대기 알약 모양을 숨겨 앱 상단을 가리지 않게 합니다. 기본으로 켜져 있습니다. 앱이 전체 화면이라고 알리는 창만 해당하며, 최대화된 창은 해당하지 않습니다. 아일랜드에 포인터를 올리거나 말을 걸면 여전히 나타납니다. |
| **스크린샷 및 녹화에 표시** | 끄면 캡처하거나 공유하는 화면에 아일랜드가 나타나지 않습니다. |

### 캐릭터

| 설정 | 바뀌는 내용 |
| --- | --- |
| **아일랜드에 캐릭터 표시** | 데스크톱 펫이나 기본 에이전트의 아바타가 접힌 아일랜드에 나타나 에이전트가 하는 일을 연기합니다. |
| **캐릭터** | **아바타** 또는 **펫**입니다. |
| **움직임** | **항상**, **작업 중일 때**, **안 함**입니다. |
| **에이전트 아이콘으로 사용** | 채팅 창에서 캐릭터를 기본 에이전트의 아이콘으로 표시합니다. |

## 음성과 완료된 작업

음성 입력은 말한 내용을 프롬프트로 바꿉니다. 음성 대화는 [Live Talk](/ko/features/live-voice)를 사용하세요. SmartBar에서 시작한 Live Talk 통화는 Dynamic Island로 옮겨 갑니다.

아일랜드에서 시작한 작업이 끝났을 때 아일랜드가 저절로 열리게 하려면 [알림](/ko/configuration/notifications)에서 **Dynamic Island 열기**를 켜세요. 이 설정은 macOS 알림과 별개입니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 다른 디스플레이에 나타납니다 | **표시 위치**를 확인하세요. |
| 앱이 전체 화면이면 사라집니다 | 기본 동작입니다. 화면 상단에 포인터를 올려 열거나, **전체 화면에서 숨기기**를 끄세요. |
| 메뉴 막대가 자동으로 숨겨지는 동안 열리지 않습니다 | 화면 상단 중앙을 클릭하세요. |
| 홈에서 계산이나 조회 결과가 표시되지 않습니다 | **홈** 탭의 **계산기**와 **날씨와 항공편**을 확인하세요. |
| 스크린샷이나 녹화에 나타나지 않습니다 | 권한을 바꾸기 전에 **스크린샷 및 녹화에 표시**를 켜세요. |
| 포인터를 올려도 열리지 않습니다 | 단축키를 누르세요. 단축키로 열린다면 **포인터를 올리면 열기**와 **노치를 다른 앱에 양보**를 확인하세요. 아무것으로도 열리지 않는다면 **Dynamic Island 활성화**를 확인하세요. |

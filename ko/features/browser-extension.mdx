title: "브라우저 확장 프로그램"
description: "Enconvo Companion 확장 프로그램을 설치하면 Enconvo가 로그인 정보, 쿠키, 확장 프로그램이 그대로 있는 실제 브라우저에서 작업할 수 있습니다."
---

Enconvo 브라우저 확장 프로그램인 Enconvo Companion은 작업에 로그인된 브라우저 상태가 필요할 때 Enconvo가 실제 브라우저를 제어하게 해 줍니다. LinkedIn, Gmail, Salesforce, 대시보드, 사내 도구처럼 쿠키와 브라우저 확장 프로그램이 중요한 사이트에 사용하세요. 설정에서는 이를 **브라우저 도우미**라고 부릅니다.

공개 페이지, 로컬 미리보기, 개인 브라우저 프로필을 건드리면 안 되는 워크플로에는 격리된 브라우저 자동화를 대신 사용하세요.

## 확장 프로그램 설정

<Steps>
  <Step title="확장 프로그램 설치">
    **설정 → 브라우저 사용**을 열고 **브라우저 확장 프로그램**에서 **브라우저 연동 앱 설치**를 클릭하세요. 확장 프로그램의 Chrome 웹 스토어 페이지가 열립니다. 브라우저의 확장 프로그램 스토어에서 직접 설치해도 됩니다. Chrome, Edge, Brave, Arc, Vivaldi, Opera, Firefox에서 동작합니다. [컴퓨터 사용 동영상 튜토리얼](https://youtu.be/0CbQA7d8zqU?t=33)에서 Chrome에 설치하는 과정을 볼 수 있습니다.
  </Step>
  <Step title="브라우저를 열어 두기">
    확장 프로그램은 `ws://localhost:11225`를 통해 Enconvo에 자동으로 연결됩니다.
  </Step>
  <Step title="팝업 확인">
    확장 프로그램 아이콘을 클릭하세요. 팝업에 **Connected Chrome**, **Connected Edge**, **Connected Firefox** 또는 현재 사용 중인 브라우저의 이름이 표시됩니다.
  </Step>
  <Step title="브라우저 작업 시작">
    Enconvo에게 브라우저에서 읽기, 클릭, 입력, 스크린샷 찍기, 탭 관리를 요청하세요.
  </Step>
</Steps>

## 팝업

| 항목 | 표시되는 내용 |
| --- | --- |
| 연결 상태 | 이 브라우저의 확장 프로그램이 Enconvo에 연결되어 있는지 여부 |
| 현재 브라우저 | 이 확장 프로그램이 연결된 브라우저(Chrome, Edge, Brave, Firefox 등) |
| 연결된 브라우저 | 지금 Enconvo에 확장 프로그램이 연결되어 있는 다른 브라우저 |
| 버전 | 설치된 확장 프로그램 버전 |
| **자세히 알아보기** | 이 페이지를 엽니다 |

팝업에 연결이 끊겼다고 나오면 Enconvo를 다시 시작하고 브라우저를 새로고침하세요. 그래도 연결되지 않으면 확장 프로그램을 껐다가 다시 켜세요.

## 브라우저 여러 개 사용하기

Enconvo는 여러 브라우저에 동시에 연결할 수 있습니다. 작업에 브라우저를 지정하지 않으면 Enconvo는 다음 순서로 하나를 고릅니다.

1. 브라우저 사용 설정에서 고른 **기본 브라우저**(**설정 → 브라우저 사용**, 이어서 **⋯** 메뉴의 **설정**).
2. Mac의 기본 브라우저.
3. 가장 최근에 사용한 연결된 브라우저.

자동화 API에서도 브라우저를 지정할 수 있습니다.

```json
{
  "browser": "edge"
}
```

일반적인 값으로는 `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera`, `firefox`가 있습니다.

## 올바른 탭에 머무르기

브라우저 작업이 시작되면 Enconvo는 작업 중인 브라우저와 탭을 기억해 둡니다. 이후 단계는 페이지가 팝업을 열거나, 새로고침되거나, 포커스를 잃더라도 가능한 한 그 탭에 머무릅니다.

가장 좋은 결과를 얻으려면:

- 작업이 끝날 때까지 탭을 열어 두세요.
- 여러 브라우저가 연결되어 있다면 브라우저를 지정하세요.
- 지금 보고 있는 페이지에서 Enconvo가 동작하길 원하면 "현재 탭을 사용해"라고 말하세요.
- 페이지가 이동하거나 양식을 제출한 뒤에는 페이지를 다시 살펴보라고 요청하세요.

## 웹사이트 접근과 안전

웹 페이지에는 사용자가 작성하지 않은 지시가 들어 있을 수 있습니다. 민감한 페이지에서는 Enconvo가 계속하기 전에 사이트와 동작을 검토하세요.

확장 프로그램은 작업에 필요할 때 브라우저 권한을 사용해 페이지를 읽고, 클릭하고, 입력하고, 스크린샷을 찍고, 탭을 확인하고, 쿠키를 읽습니다. 로그인된 페이지, 방문 기록, 사내 도구는 민감한 데이터로 취급하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 팝업에 연결이 끊겼다고 나옴 | Enconvo가 실행 중인지 확인하고, 브라우저를 다시 시작한 다음 확장 프로그램을 껐다가 다시 켜세요. `localhost:11225`를 막는 것이 없는지 확인하세요. |
| 엉뚱한 브라우저가 제어됨 | 브라우저 사용 설정에서 **기본 브라우저**를 지정하거나, 브라우저 동작에 `edge`, `chrome`, `firefox` 같은 브라우저 값을 전달하세요. |
| 연결되었지만 페이지를 제어할 수 없음 | `chrome://` 같은 브라우저 페이지는 제어할 수 없습니다. 엄격한 콘텐츠 보안 정책, 닫힌 Shadow DOM, 브라우저 권한 요청 창도 방해가 될 수 있습니다. |
| 파일 업로드가 동작하지 않음 | 브라우저의 확장 프로그램 세부 정보 페이지에서 파일 URL에 대한 접근을 켜세요. 로컬 파일을 업로드하거나 파일 기반 페이지를 여는 작업에 필요합니다. |

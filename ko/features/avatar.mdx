아바타는 내 Agent 중 하나를 대표하는 데스크톱 캐릭터입니다. 음성 통화에서는 음성에 맞춰 움직이며 말하고, Agent는 평소의 지침과 도구를 그대로 유지합니다.

이 동영상은 먼저 아바타를 다루고, 이어서 메신저 채널과 인증 정보 관리를 다룹니다.

## 캐릭터 설정하기

1. **설정 → 아바타**를 엽니다.
2. **갤러리**에서 캐릭터를 찾아 **다운로드**를 클릭해 기본 패키지를 받습니다.
3. 다운로드가 끝나면 캐릭터가 대표할 Agent를 고르고 **아바타 연결**을 클릭합니다. 각 Agent에는 아바타가 하나씩 있고, 각 아바타는 하나의 Agent에 속합니다.
4. 캐릭터의 **품질**을 선택합니다.
5. **열기**를 클릭하면 Agent의 아바타가 데스크톱에 나타납니다.

아바타의 통화는 **설정 → Live Talk → 말하기**에서 정한 음성으로 말하며, 음성을 바꾸면 다음 통화부터 적용됩니다.

**선택적 다운로드**에는 해당 캐릭터의 추가 패키지가 나열되며, 제공되는 경우 고해상도 텍스처나 모션 등이 포함됩니다. 기본 패키지로 시작해서 내 Mac에 맞는 품질을 고르세요.

나만의 캐릭터를 만들려면 **캐릭터 만들기**를 클릭해 얼굴, 털, 이름을 고르거나, **파일 가져오기…**를 클릭해 OpenAvatar 캐릭터 파일을 추가하세요. 사진으로 만들려면 [Live Photo 캐릭터 만들기](#live-photo-캐릭터-만들기)를 참고하세요.

## Live Photo 캐릭터 만들기

Live Photo 캐릭터는 인물 사진을 데스크톱에서 서서 숨 쉬는 아바타로 바꾸며, 통화에서는 실시간 영상으로 나타납니다.

1. **설정 → 아바타**를 열고 **Live Photo** 탭을 엽니다.
2. **Live Photo 만들기**를 클릭합니다.
3. 사진으로 시작합니다. **사진 선택…**을 클릭해 통화에서 보고 싶은 얼굴의 JPG, PNG, WebP 사진 한 장(최대 10MB)을 고르세요. 또는 **설명으로 만들기**를 선택해 가상 캐릭터에 대한 설명을 입력하면 Enconvo가 고를 수 있는 인물 사진을 만들어 줍니다.
4. **인물 사진 구도 잡기**로 얼굴 위치를 정합니다. **배경**에서는 사진의 원래 배경을 둥근 프레임에 그대로 두거나, **제거**를 선택해 캐릭터만 오려 냅니다.
5. 사진이 본인이거나 해당 인물의 사용 허락을 받았음을 확인합니다.
6. **음성** 단계에서 목소리를 고른 뒤(아래 참고) 캐릭터를 만듭니다. 만드는 데 몇 분 걸리며, 그동안 창을 닫아도 됩니다.
7. 다른 아바타와 마찬가지로 캐릭터를 Agent에 연결하고 **열기**를 클릭합니다.

사진과 통화 오디오는 영상을 그리는 외부 서비스인 미국의 Atmee로 전송됩니다. 사진 캐릭터는 세 개까지 만들 수 있으며, 다른 캐릭터를 만들려면 하나를 삭제하세요.

### 목소리 고르기

**음성** 단계에서는 다음을 제공합니다.

- **음성 복제**: 그 자리에서 해당 인물을 녹음하거나, **대신 업로드**를 클릭해 그 사람의 오디오나 영상을 사용합니다. **복제 서비스**는 월 복제 횟수가 정해진 Enconvo Cloud의 ElevenLabs 또는 내 ElevenLabs API 키입니다.
- **음성 선택**: ElevenLabs 음성이나 내가 복제한 음성을 고릅니다.
- **통화 음성 따르기**: **설정 → Live Talk → 말하기**에서 정한 음성을 사용합니다.

나중에 바꾸려면 캐릭터 카드에서 **음성 변경**을 클릭하세요.

### 내 Atmee 계정 사용하기

기본적으로 Live Photo 캐릭터는 Enconvo의 Atmee 계정으로 실행되며, 일일 사용 시간과 캐릭터 세 개 제한이 있습니다. **내 Atmee 계정 사용**을 선택하고 Atmee Studio(**API 키**)의 API 키를 붙여 넣으세요. 그러면 새 캐릭터가 이러한 제한 없이 내 계정에 만들어지며, 내 Atmee 계정에 이미 있는 아바타를 가져올 수도 있습니다. 키는 [인증 정보 관리](/ko/configuration/credentials)에 보관됩니다.

### Live Photo 캐릭터와 통화하기

통화에서 캐릭터는 음성에 맞춰 입술이 움직이는 실시간 영상으로 나타납니다. 1분 동안 아무도 말하지 않으면 실시간 화면은 내가 다시 말할 때까지 쉽니다. 1분 30초가 지나면 캐릭터가 "아직 계신가요?"라고 묻고, 1분 뒤에 통화가 끊기며 다시 이어갈 수 있는 **계속** 버튼이 표시됩니다.

라이브 방송에 내보내려면 [Live Photo 캐릭터 방송하기](/ko/features/avatar-live-stream)를 참고하세요.

## 대화하고 상호작용하기

[Live Talk](/ko/features/live-voice)를 설정한 다음 아바타의 대화 컨트롤로 대화를 시작하세요. 캐릭터를 마우스 오른쪽 버튼으로 클릭하면 음성, 기록, 설정, 캐릭터 컨트롤이 나타납니다. 말풍선에는 대화 텍스트와 음성 활동이 표시됩니다.

캐릭터를 옮기고, 스크롤해서 회전시키고, Control을 누른 채 스크롤하거나 핀치해서 확대할 수 있습니다. 투명한 여백을 클릭하면 데스크톱으로 전달됩니다.

## 캐릭터 전환하기

데스크톱의 **캐릭터** 메뉴는 Agent를 다시 지정하지 않습니다. 다른 Agent에 지정된 캐릭터를 선택하면 해당 Agent의 아바타가 열립니다. 지정되지 않은 캐릭터는 메인 Agent를 통해 표시됩니다. 캐릭터가 속한 Agent를 바꾸려면 **설정 → 아바타**를 사용하세요.

메뉴 막대나 Dynamic Island의 아바타 전환은 지정된 캐릭터와 함께 메인 Agent를 엽니다.

## 설정

**설정 → 아바타**에서 다운로드한 각 캐릭터의 카드에는 다음 컨트롤이 있습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **에이전트** | 캐릭터가 대표하는 Agent입니다. 새 짝을 지정하면 이전 연결이 대체되며, 음성, 외형, 채팅 기록은 유지됩니다. |
| **품질** | 렌더링 품질입니다. 기본값인 **최소**는 GPU, CPU, 배터리를 가장 적게 사용합니다. **균형**과 **최고 화질**은 조명, 음영, 더 큰 텍스처를 추가하며 GPU를 더 많이 사용합니다. |
| **선택적 다운로드** | 캐릭터의 추가 패키지와 패키지 업데이트입니다. |

갤러리 위의 **자연스러운 립싱크**는 모든 아바타의 입술을 말하는 음성에 맞춰 만들어 주는 온디바이스 모델을 다운로드합니다. Apple 실리콘 Mac이 필요합니다.

그 아래의 **라이브 데스크톱**은 창 뒤에 Agent, 코딩 세션, 자동화가 하는 일을 보여 주는 보드를 놓고, 내가 필요하거나 문제가 생기면 반응하는 캐릭터를 함께 보여 줍니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **품질**을 바꿀 수 없음 | 먼저 캐릭터를 다운로드하고 Agent를 지정하세요. |
| **Live Photo 만들기**를 사용할 수 없음 | 사진 캐릭터가 세 개 있습니다. 하나를 삭제하거나 내 Atmee 계정을 사용하세요. |
| **설명으로 만들기**가 작동하지 않음 | AI 모델이 필요합니다. **설정 → AI 모델**에서 하나를 고른 뒤 다시 시도하세요. |
| 다운로드 실패 | 카드의 오류를 읽고, 연결 상태와 디스크 여유 공간을 확인한 다음 **재시도**를 클릭하세요. |
| 확대하면 캐릭터가 흐릿함 | 더 높은 **품질**을 선택하고 **선택적 다운로드**에서 텍스처를 확인하세요. |
| 통화가 시작되지 않음 | [Live Talk](/ko/features/live-voice) 설정과 macOS 마이크 접근 권한을 확인하세요. |
| 엉뚱한 Agent가 답함 | **설정 → 아바타**에서 캐릭터의 **에이전트**를 확인하세요. |

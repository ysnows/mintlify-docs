아바타는 에이전트 하나를 나타내는 데스크탑 캐릭터입니다. 음성 통화에서는 음성에 맞춰 애니메이션하며 말하고, 에이전트는 평소의 지침과 도구를 유지합니다.

이 영상은 아바타를 먼저 다루고, 이어서 메신저 채널과 자격 증명 관리를 다룹니다.

## 캐릭터 설정

1. **설정 → 아바타**를 엽니다.
2. **갤러리**에서 캐릭터를 찾고 **다운로드**를 클릭해 기본 패키지를 받습니다.
3. 다운로드가 끝나면 나타내는 에이전트를 고르고 **아바타 연결**을 클릭합니다. 각 에이전트에는 아바타가 하나이고, 각 아바타는 에이전트 하나에 속합니다.
4. 캐릭터의 **품질**을 고릅니다.
5. **열기**를 클릭해 에이전트의 아바타를 데스크탑에 표시합니다.

아바타 통화는 **설정 → Live Talk → 말하기**에 설정된 음성으로 말하며, 음성 변경은 다음 통화부터 적용됩니다.

**선택적 다운로드**는 그 캐릭터의 추가 패키지를 나열합니다. 더 높은 해상도의 텍스처나 동작이 있을 때입니다. 기본 패키지부터 시작하고 Mac에 맞는 품질을 고르세요.

자신의 캐릭터를 만들려면 **캐릭터 만들기**를 클릭하고 얼굴, 털, 이름을 고르거나, **파일 가져오기…**를 클릭해 OpenAvatar 캐릭터 파일을 추가합니다. 사진으로 만들려면 [라이브 포토 캐릭터 만들기](/ko/features/avatar)를 보세요.

## 라이브 포토 캐릭터 만들기

라이브 포토 캐릭터는 초상을 데스크탑에 서서 숨 쉬는 아바타로 바꾸고, 통화에서는 라이브 영상으로 나타납니다.

1. **설정 → 아바타**를 열고 **라이브 포토** 탭을 엽니다.
2. **라이브 포토 만들기**를 클릭합니다.
3. 사진으로 시작합니다. **사진 선택…**을 클릭하고 통화에서 보고 싶은 얼굴의 JPG, PNG, WebP 사진 하나를 고릅니다. 최대 10 MB입니다. 또는 **설명하기**를 고르고 만든 캐릭터를 설명하면 Enconvo가 고를 초상을 만듭니다.
4. **초상 프레임**으로 얼굴을 배치합니다. **배경** 아래에서 둥근 프레임에 사진의 배경을 유지하거나, **제거**를 골라 캐릭터를 오려 냅니다.
5. 사진이 자신이거나, 그 사람의 사용 허가가 있음을 확인합니다.
6. **음성** 단계에서 목소리를 고른 다음(아래 참고) 캐릭터를 만듭니다. 만드는 데 몇 분이 걸리며, 그동안 창을 닫아도 됩니다.
7. 다른 아바타와 같이 캐릭터를 에이전트에 연결하고 **열기**를 클릭합니다.

사진과 통화 오디오는 미국에서 영상을 그리는 외부 서비스 Atmee로 갑니다. 사진 캐릭터는 세 개까지 가질 수 있으며, 하나를 삭제해야 다른 것을 만들 수 있습니다.

### 목소리 고르기

**음성** 단계에는 다음이 있습니다.

- **음성 복제**: 그 사람을 그 자리에서 녹음하거나, **대신 업로드**를 클릭해 오디오나 동영상을 씁니다. **복제 제공**: 월별 복제 횟수가 있는 Enconvo Cloud의 ElevenLabs, 또는 자신의 ElevenLabs API 키.
- **음성 선택**: ElevenLabs 음성, 또는 복제한 음성을 고릅니다.
- **통화 음성 따르기**: **설정 → Live Talk → 말하기**에 설정된 음성을 씁니다.

나중에 바꾸려면 카드의 **음성 변경**을 클릭합니다.

### 자신의 Atmee 계정 사용

기본적으로 라이브 포토 캐릭터는 Enconvo의 Atmee 계정에서 실행되며, 일일 분과 세 캐릭터 제한이 있습니다. **자신의 Atmee 계정 사용**을 고르고 Atmee Studio의 API 키를 붙여 넣으세요(**API keys**). 그러면 새 캐릭터가 그 제한 없이 자신의 계정에서 만들어지며, Atmee 계정에 이미 있는 아바타를 가져올 수 있습니다. 키는 [자격 증명 관리](/ko/configuration/credentials)에 보관됩니다.

### 라이브 포토 캐릭터와의 통화

통화에서 그녀는 라이브 영상으로 나타나며, 입술이 음성을 따릅니다. 아무도 1분 동안 말하지 않으면 다시 말할 때까지 라이브 화면이 쉽니다. 1분 30초 뒤에는 “아직 있나요?”라고 묻고, 1분 뒤에는 **계속** 버튼과 함께 통화가 끊깁니다. 그 버튼으로 다시 이어 갑니다.

라이브 스트림에 올리려면 [라이브 포토 캐릭터 스트리밍](/ko/features/avatar-live-stream)을 보세요.

## 대화하고 상호작용하기

[Live Talk](/ko/features/live-voice)를 설정한 다음 아바타의 대화 제어로 말하기를 시작합니다. 캐릭터를 오른쪽 클릭하면 음성, 기록, 설정, 캐릭터 제어가 나옵니다. 말풍선은 대화 텍스트와 음성 활동을 보여 줍니다.

캐릭터를 옮기고, 스크롤로 회전하고, Control-스크롤이나 핀치로 확대할 수 있습니다. 투명한 여백의 클릭은 데스크탑으로 통과합니다.

## 캐릭터 전환

데스크탑 **캐릭터** 메뉴는 에이전트를 다시 할당하지 않습니다. 다른 에이전트에 할당된 캐릭터를 고르면 그 에이전트의 아바타가 열립니다. 할당되지 않은 캐릭터는 기본 에이전트를 통해 표시됩니다. 캐릭터가 속한 에이전트를 바꾸려면 **설정 → 아바타**를 쓰세요.

메뉴 막대나 Dynamic Island의 아바타 스위치는 할당된 캐릭터와 함께 기본 에이전트를 엽니다.

## 설정

**설정 → 아바타**에서 다운로드한 각 캐릭터 카드에는 다음 제어가 있습니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **에이전트** | 캐릭터가 나타내는 에이전트. 새 쌍을 할당하면 이전 연결이 바뀌며, 음성, 모양, 채팅 기록은 유지됩니다. |
| **품질** | 렌더링 품질. 기본인 **최소**는 GPU, CPU, 배터리를 가장 적게 씁니다. **균형**과 **최고 품질**은 조명, 음영, 더 큰 텍스처를 더하고 GPU를 더 씁니다. |
| **선택적 다운로드** | 캐릭터의 추가 패키지와 패키지 업데이트. |

갤러리 위의 **자연스러운 립싱크**는 말하는 음성으로 모든 아바타의 입술을 만드는 기기 내 모델을 다운로드합니다. Apple Silicon Mac이 필요합니다.

그 아래 **라이브 데스크탑**은 창 뒤에 보드를 두어 에이전트, 코딩 세션, 자동화가 하는 일을 보여 주고, 무언가가 필요하거나 잘못되면 반응하는 캐릭터를 둡니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **품질**을 바꿀 수 없음 | 먼저 캐릭터를 다운로드하고 에이전트를 할당하세요. |
| **라이브 포토 만들기**를 쓸 수 없음 | 사진 캐릭터가 세 개입니다. 하나를 삭제하거나 자신의 Atmee 계정을 쓰세요. |
| **설명하기**가 동작하지 않음 | AI 모델이 필요합니다. **설정 → AI 모델**에서 하나를 고른 다음 다시 시도하세요. |
| 다운로드 실패 | 카드의 오류를 읽고, 연결과 여유 디스크를 확인한 다음 **다시 시도**를 클릭하세요. |
| 확대하면 캐릭터가 흐림 | 더 높은 **품질**을 고르고, 텍스처는 **선택적 다운로드**를 확인하세요. |
| 통화가 시작되지 않음 | [Live Talk](/ko/features/live-voice) 설정과 macOS 마이크 접근을 확인하세요. |
| 잘못된 에이전트가 답함 | **설정 → 아바타**에서 캐릭터의 **에이전트**를 확인하세요. |

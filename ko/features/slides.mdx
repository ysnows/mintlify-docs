에이전트에게 슬라이드를 요청하면 채팅 옆 패널에 슬라이드를 작성합니다. 그곳에서 바로 발표하고, 직접 편집하고, 실제 텍스트 상자, 도형, 표, 발표자 노트, 섹션이 포함된 PowerPoint 또는 PDF로 다운로드할 수 있습니다. 발표하거나 전달할 슬라이드가 필요할 때마다 사용하세요.

## 슬라이드 만들기

1. 새 채팅을 시작하고 메시지 입력란 아래에서 **슬라이드**를 선택하거나, 어떤 채팅에서든 슬라이드를 요청합니다.
2. 발표 내용을 설명합니다. 대상 청중, 발표 시간, 다룰 내용입니다. PDF, 메모, `.pptx`를 첨부하여 거기서 시작할 수 있습니다.
3. 보냅니다. 에이전트가 작성하는 대로 슬라이드가 패널에 나타나며, 분량이 긴 슬라이드는 여러 장씩 나란히 작성됩니다.

예시:

```text
A 5-minute talk from this doc, with speaker notes.
Keep one idea per slide and end with three next steps.
```

에이전트는 작업을 마치면 레이아웃을 검사합니다. 머리글에 **슬라이드에 문제 없음** 또는 개수와 함께 **슬라이드에 문제 있음**이 표시됩니다. 문제를 클릭하면 내용을 볼 수 있습니다. 슬라이드를 벗어나거나, 잘리거나, 겹치는 텍스트, 낮은 대비, 작은 글자, 깨진 그림 등입니다. 에이전트에게 수정을 요청하세요.

## 발표

- **발표**를 클릭하면 빌드와 전환 효과가 적용된 상태로 전체 화면에서 슬라이드를 재생합니다.
- 그 옆의 **다른 발표 방식**을 열고 **이 슬라이드부터 발표**를 선택하거나, **발표자 보기**를 선택하여 시간, 다음 슬라이드, 노트를 확인합니다.
- 보조 디스플레이가 연결되어 있으면 발표자 보기에서 청중용 창이 그곳에 표시됩니다.

iPhone과 Android 앱에서도 슬라이드를 열고 발표할 수 있습니다. [아티팩트](/ko/features/artifacts)를 참고하세요.

## 슬라이드 편집

직접 변경하거나 에이전트에게 요청할 수 있습니다. 요청하면 에이전트는 사용자가 지정한 슬라이드만 변경하며, 패널은 현재 보고 있는 슬라이드를 유지한 채 해당 슬라이드를 제자리에서 갱신합니다.

- **텍스트**: 텍스트를 더블 클릭하여 다시 입력합니다. 선택 영역에 **굵게**, **기울임꼴**, **밑줄**, **텍스트 색상**, **서식 지우기**를 사용합니다.
- **레이아웃**: 요소를 끌어서 이동합니다.
- **발표자 노트**: **발표자 노트**를 클릭하고 슬라이드 아래에 입력합니다.
- **슬라이드**: **더 보기**를 열면 **슬라이드 복제**(복사본으로 이동), **슬라이드를 앞으로 이동**, **슬라이드를 뒤로 이동**, **슬라이드 삭제**가 있습니다. **실행 취소**를 누르면 삭제한 슬라이드가 돌아옵니다.
- **댓글**: **댓글**을 클릭한 다음 특정 위치, 선택한 단어, 또는 슬라이드 전체에 댓글을 답니다. 에이전트에게 질문하려면 댓글을 `@Enconvo`로 시작하세요.

## 디자인 시스템 사용

디자인 시스템은 모든 슬라이드에 같은 색상과 글꼴을 적용하며, 이는 PowerPoint의 테마에도 반영됩니다.

1. **더 보기 → 디자인 시스템**을 열고 시스템을 선택합니다.
2. 채팅에서 해당 시스템으로 슬라이드의 스타일을 바꿔 달라고 요청합니다. 문구는 그대로 유지됩니다.

슬라이드가 사용한 이후 시스템이 변경되었다면 메뉴에 원본보다 뒤처져 있다고 표시되며 **원본과 동기화**가 제공됩니다. 자신의 브랜드로 디자인 시스템을 만들려면 [디자인 캔버스](/ko/features/design)를 참고하세요.

에이전트는 약 1,500개의 아이콘 세트에서 아이콘을 골라 슬라이드에 배치할 수도 있습니다.

## 다운로드

**다운로드**를 클릭하고 **PowerPoint 다운로드** 또는 **PDF 다운로드**를 선택합니다. Enconvo가 파일을 저장하고 저장 위치를 알려 줍니다.

슬라이드를 사람이나 팀과 공유하려면 **공유**를 클릭하세요. [아티팩트](/ko/features/artifacts)를 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **슬라이드에 문제 있음**에 개수가 표시됨 | 클릭하여 각 문제를 확인한 다음 에이전트에게 수정을 요청하세요 |
| 입력한 변경 사항이 유지되지 않음 | 편집하는 동안 슬라이드가 바뀌었습니다. 변경을 다시 하세요 |
| 삭제한 슬라이드가 돌아오지 않음 | 그 사이 슬라이드가 변경되었습니다. 버전 메뉴에서 이전 버전을 여세요 |
| "hasn't finished drawing the export"와 함께 내보내기가 실패함 | Enconvo를 업데이트한 다음 다시 다운로드하세요 |

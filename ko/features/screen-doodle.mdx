화면 낙서를 사용하면 Agent에게 물어보기 전에 화면의 일부에 표시할 수 있습니다. 화살표, 원, 하이라이트, 메모를 그린 다음 보내세요. 표시한 스크린샷은 이미지로 채팅에 첨부되며, 방금 채팅 창 같은 다른 Enconvo 채팅을 사용하던 경우가 아니면 Dynamic Island로 전달됩니다.

## 화면에 표시하기

1. 질문하려는 콘텐츠를 맨 앞으로 가져옵니다.
2. 마우스 오른쪽 버튼을 두 번 클릭해 화면 낙서를 열거나, **설정 → 화면 낙서**에서 설정한 **단축키**를 누릅니다.
3. **먼저 영역 캡처**가 켜져 있으면 드래그해서 영역을 선택합니다. 그렇지 않으면 실시간 화면 위에 바로 그립니다.
4. 도구 모음에서 도구를 고르고 원하는 부분에 표시합니다.
5. **보내기**(종이비행기)를 클릭하거나 **⌘↩**를 누릅니다.
6. 첨부된 이미지를 확인하고 "강조 표시한 경고는 무슨 뜻이야?"처럼 요청을 입력합니다.

화면 낙서는 단축키를 설정하기 전까지는 단축키가 없습니다. 마우스 오른쪽 버튼 두 번 클릭은 바로 사용할 수 있습니다.

### 음성 라벨 추가하기

왼쪽 **Option** 키를 누른 채 말하면 방금 그린 도형을 설명할 수 있습니다. 말한 내용이 도형 옆에 텍스트로 나타납니다. 그리는 도형마다 화면 낙서가 듣게 하려면 도구 모음에서 **도형마다 음성 입력**을 켜고, 각 라벨을 마치려면 잠시 멈추세요.

## 도구

| 도구 또는 동작 | 키 |
| --- | --- |
| 화살표 | **A** |
| 선 | **L** |
| 펜 | **P** |
| 형광펜 | **H** |
| 사각형 | **R** |
| 원 | **O** |
| 카운터(번호 마커) | **N** |
| 텍스트 | **T** |
| 선택 | **V** |
| 지우개 | **E** |
| 색상 | **C** |
| 선 두께 | **⌘** + 스크롤 |
| 화이트보드 | **B** |
| 커서 하이라이트 | **K** |
| 다른 이름으로 저장… | **⌘S** |
| 보내기 | **⌘↩** |

도구 모음에는 **실행 취소**, **다시 실행**, **지우기**, **클립보드에 복사**, **닫기**도 있습니다.

## 설정

**설정 → 화면 낙서**를 엽니다.

| 설정 | 하는 일 |
| --- | --- |
| **먼저 영역 캡처** | 그리기 전에 영역을 선택합니다. 끄면 실시간 화면에 바로 그립니다. 기본으로 켜져 있습니다. |
| **단축키** | 화면 낙서를 열거나 닫습니다. 기본값은 비어 있습니다. |
| **마우스 오른쪽 버튼 두 번 클릭** | 빠르게 마우스 오른쪽 버튼을 두 번 클릭해 화면 낙서를 열거나 닫습니다. 기본으로 켜져 있습니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 오버레이가 열리지 않음 | **설정 → 화면 낙서**의 **단축키**와 **마우스 오른쪽 버튼 두 번 클릭**을 확인하고 [macOS 권한](/ko/configuration/permissions)을 확인하세요. |
| 앱 창 전체만 필요함 | 대신 [Appshots](/ko/features/appshots)를 사용하세요. |

화면 낙서는 에이전트에게 묻기 전에 화면 일부를 표시할 수 있게 합니다. 화살표, 원, 강조, 메모를 그린 뒤 보내세요. 표시한 스크린샷이 이미지로 채팅에 첨부됩니다. 방금 채팅 창 같은 다른 Enconvo 채팅을 쓰고 있지 않았다면 Dynamic Island로 갑니다.

## 화면에 표시하기

1. 묻고 싶은 내용을 맨 앞으로 가져오세요.
2. 마우스 오른쪽 버튼을 두 번 클릭해 화면 낙서를 열거나, **설정 → 화면 낙서**에서 정한 **단축키**를 누르세요.
3. **먼저 영역 캡처**가 켜져 있으면 드래그해 영역을 고르세요. 꺼져 있으면 실시간 화면 위에 바로 그립니다.
4. 도구 모음에서 도구를 고르고 가리키려는 곳을 표시하세요.
5. **보내기**(종이비행기)를 클릭하거나 **⌘↩**를 누르세요.
6. 첨부된 이미지를 확인하고, "강조한 경고는 무슨 뜻이야?"처럼 요청을 입력하세요.

화면 낙서는 단축키를 정하기 전에는 없습니다. 오른쪽 버튼 두 번 클릭은 바로 동작합니다.

### 말로 라벨 넣기

왼쪽 **Option** 키를 누른 채 말해 방금 그린 도형을 설명하세요. 말이 그 옆에 텍스트로 나타납니다. 도형을 그릴 때마다 듣게 하려면 도구 모음에서 **도형마다 음성 입력**를 켜고, 각 라벨을 끝낼 때 잠시 멈추세요.

## 도구

| 도구 또는 동작 | 키 |
| --- | --- |
| 화살표 | **A** |
| 선 | **L** |
| 펜 | **P** |
| 형광펜 | **H** |
| 사각형 | **R** |
| 원 | **O** |
| 번호(번호 마커) | **N** |
| 텍스트 | **T** |
| 선택 | **V** |
| 지우개 | **E** |
| 색상 | **C** |
| 선 두께 | **⌘** + 스크롤 |
| 화이트보드 | **B** |
| 커서 강조 | **K** |
| 다른 이름으로 저장… | **⌘S** |
| 보내기 | **⌘↩** |

도구 모음에는 **실행 취소**, **다시 실행**, **지우기**, **클립보드에 복사**, **닫기**도 있습니다.

## 설정

**설정 → 화면 낙서**를 여세요.

| 설정 | 하는 일 |
| --- | --- |
| **먼저 영역 캡처** | 그리기 전에 영역을 고릅니다. 끄면 실시간 화면에 바로 그립니다. 기본값은 켬입니다. |
| **단축키** | 화면 낙서를 열거나 닫습니다. 기본값은 비어 있습니다. |
| **마우스 오른쪽 버튼 두 번 클릭** | 오른쪽 버튼을 빠르게 두 번 클릭해 화면 낙서를 열거나 닫습니다. 기본값은 켬입니다. |

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 오버레이가 열리지 않음 | **설정 → 화면 낙서**에서 **단축키**와 **마우스 오른쪽 버튼 두 번 클릭**을 확인하고, [macOS 권한](/ko/configuration/permissions)을 확인하세요. |
| 앱 윈도우 전체만 필요함 | 대신 [Appshots](/ko/features/appshots)를 쓰세요. |

AI 명령은 반복해서 쓰는 프롬프트를 모델 및 설정과 함께 묶어, 어떤 텍스트에서든 한 번의 클릭으로 실행할 수 있게 해 줍니다. 지원 답변 다시 쓰기처럼 목적이 분명한 작업에 사용하세요. 도구를 사용하는 더 폭넓은 작업에는 [에이전트](/ko/ai/agents)를, 여러 단계로 이어지는 작업에는 [워크플로](/ko/workflows/introduction)를 사용하세요.

아래 동영상 튜토리얼은 회의 노트에서 실행 항목을 뽑아내는 명령을 2분 만에 만듭니다. 명령 설명하기, 내 텍스트로 시험해 보기, 내 말로 수정하기, PopBar에 추가하기, 단축키 지정하기, 다른 앱에서 실행하기를 다룹니다.

## 명령 만들기

1. **설정 → AI 명령**을 열거나 SmartBar에서 **AI 명령 만들기**를 실행한 다음 **새 AI 명령 만들기**를 클릭하세요.
2. 명령이 해야 할 일을 내 말로 설명한 다음 **초안 작성**을 클릭하세요. Enconvo가 제목, 아이콘, 지침을 작성하고 바로 예시에 실행해 봅니다.
3. 샘플에 내 텍스트 일부를 붙여넣고 **다시 시도**를 클릭해 실제 입력에서의 결과를 확인하세요.
4. 동작을 바꾸려면 **변경할 것이 있나요?**에 "담당자별로 묶어 줘"처럼 변경 내용을 입력하고 **다시 작성**을 클릭하세요. 지침에서 바뀐 줄이 표시되고, 샘플 결과가 다시 실행됩니다.
5. **사용할 위치**에서 **PopBar에 추가**를 켜 두면 텍스트를 선택할 때마다 PopBar 버튼이 나타나고, **단축키 추가**를 클릭해 원하는 키를 누를 수도 있습니다.
6. **저장**을 클릭하세요.

지침 예시:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## 명령 실행하기

- **PopBar에서:** 아무 앱에서나 텍스트를 선택하고 명령의 버튼을 클릭하세요. 결과가 준비되면 **붙여넣기**를 클릭해 선택한 텍스트를 바꾸세요.
- **단축키로:** 텍스트를 선택하고 명령의 단축키를 누르세요. 결과가 SmartBar에 열리고, 거기서 붙여넣을 수 있습니다.
- **SmartBar에서:** 명령의 제목을 검색해 현재 입력에 실행하세요.
- **에이전트에서:** 채팅에서 에이전트에게 명령을 실행해 달라고 요청하세요. 명령이 끝나면 에이전트가 채팅을 이어서 진행합니다.

번역 같은 기본 제공 명령과 직접 만든 명령을 포함해 AI 명령의 채팅은 채팅 창, Dynamic Island의 **기록**, SmartBar의 채팅 목록에 표시되지 않습니다.

## 명령 변경하기

**설정 → AI 명령**에서 명령을 열어 제목과 지침을 편집하세요. 변경 사항은 입력하는 대로 저장됩니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **PopBar** | 명령을 PopBar에 추가하거나 제거합니다. |
| **단축키** | 아무 앱에서나 선택한 텍스트에 명령을 실행하는 키입니다. |
| **인라인 모드** | 창 없이 실행하고 결과를 선택한 텍스트 위에 붙여넣습니다. |
| **완료 후 동작** | 명령이 끝난 뒤 답변으로 무엇을 할지 정합니다(제공되는 경우). |
| **AI 모델** | 명령이 모든 AI 명령의 모델을 따르는지, 해당 명령용으로 선택한 모델을 쓰는지 표시합니다. **변경**을 클릭해 선택하세요. |

### 모든 명령의 모델 선택하기

AI 명령은 다른 모델을 선택하지 않는 한 Enconvo Fast로 실행됩니다. 바꾸려면 **설정 → AI 명령**을 열고 **모든 명령**을 클릭하세요. **AI 모델** 아래의 모델은 글쓰기 도구, PopBar, 받아쓰기의 **다듬기**와 **번역**도 실행합니다. **추천 사용**은 Enconvo Fast로 되돌립니다. 자체 모델을 고른 명령은 이 모델이 바뀌어도 그대로 유지되며, **검토**를 클릭하면 해당 명령을 볼 수 있고 **모두 …로 사용**을 클릭하면 이 모델로 옮길 수 있습니다.

기본 제공 명령에는 **사용자 지정**이 대신 표시됩니다. 편집할 수 있는 내 사본을 만듭니다. 직접 만든 명령에는 **복제**와 **삭제**가 있는 **⋯** 메뉴가 있습니다. 명령을 삭제하면 PopBar에서도 제거되고 단축키가 해제됩니다.

## 변하는 컨텍스트 사용하기

필드가 변수를 지원하는 곳에서는 변수 선택기로 입력 텍스트, 선택한 텍스트, 활성 앱 또는 기타 컨텍스트를 포함할 수 있습니다. [변수](/ko/workflows/variables)를 참고하세요. 개인 문서에 명령을 사용하기 전에 확장된 컨텍스트를 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 명령이 보이지 않음 | 저장되었는지 확인한 다음 제목으로 검색하세요. |
| 출력이 선택한 텍스트를 무시함 | 명령의 입력 및 컨텍스트 설정과 [권한](/ko/configuration/permissions)의 손쉬운 사용을 확인하세요. |

AI 명령은 반복하는 프롬프트를 모델과 설정과 함께 묶어, 어떤 텍스트든 클릭 한 번으로 실행하게 합니다. 지원 답변을 다시 쓰는 것처럼 좁은 일에 쓰세요. 도구가 있는 더 넓은 일은 [에이전트](/ko/ai/agents)를, 단계의 순서는 [워크플로](/ko/workflows/introduction)를 쓰세요.

## 명령 만들기

1. **설정 → AI 명령**을 열거나 SmartBar에서 **AI 명령 만들기**를 실행하고 **새 AI 명령 만들기**를 클릭하세요.
2. 명령이 해야 할 일을 말로 설명한 뒤 **초안 작성**을 클릭하세요. Enconvo가 제목, 아이콘, 지침을 쓰고, 예시에서 바로 실행합니다.
3. 샘플에 본인 텍스트를 붙여 넣고 **다시 시도**를 클릭해 실제 입력의 결과를 보세요.
4. 동작을 바꾸려면 **변경할 것이 있나요?**에 예를 들어 "담당자별로 묶어"처럼 입력하고 **다시 작성**을 클릭하세요. 바뀐 줄이 지침에 표시되고, 샘플 결과가 다시 실행됩니다.
5. **사용할 위치** 아래에서 **PopBar에 추가**를 켜 두면 텍스트를 선택할 때마다 PopBar 버튼이 생깁니다. 또는 **단축키 추가**를 클릭하고 원하는 키를 누르세요.
6. **저장**을 클릭하세요.

지침 예:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## 명령 실행

- **PopBar에서:** 아무 앱에서 텍스트를 선택하고 명령 버튼을 클릭하세요. 결과가 준비되면 **붙여넣기**를 클릭해 선택을 바꿉니다.
- **단축키에서:** 텍스트를 선택하고 명령의 단축키를 누르세요. 결과가 SmartBar에 열리고, 거기서 붙여 넣을 수 있습니다.
- **SmartBar에서:** 명령 제목을 검색해 현재 입력에서 실행하세요.
- **에이전트에서:** 채팅의 에이전트에게 명령을 실행해 달라고 하세요. 명령이 끝나면 에이전트가 채팅을 이어갑니다.

번역 같은 기본 제공 명령과 본인 명령을 포함한 AI 명령 채팅은 채팅 창, Dynamic Island의 **기록**, SmartBar 채팅 목록에 나타나지 않습니다.

## 명령 바꾸기

**설정 → AI 명령**에서 명령을 열어 제목과 지침을 편집하세요. 입력하는 대로 저장됩니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **PopBar** | 명령을 PopBar에 올리거나 내립니다. |
| **단축키** | 아무 앱에서 선택한 텍스트에 명령을 실행하는 키입니다. |
| **인라인 모드** | 창 없이 실행하고 결과를 선택 위에 붙여 넣습니다. |
| **완료 후 동작** | 제공되는 경우, 끝난 뒤 명령이 답변으로 하는 일입니다. |
| **AI 모델** | 명령이 모든 AI 명령의 모델을 따르는지, 따로 고른 모델을 쓰는지 보여 줍니다. **변경**을 클릭해 고르세요. |

### 모든 명령의 모델 고르기

AI 명령은 다른 모델을 고르기 전까지 Enconvo Fast에서 실행됩니다. 바꾸려면 **설정 → AI 명령**을 열고 **모든 명령**을 클릭하세요. **AI 모델** 아래 모델은 글쓰기 도구, PopBar, 받아쓰기의 **다듬기**와 **번역**도 실행합니다. **추천 사용**은 Enconvo Fast로 돌아갑니다. 자기 모델을 고른 명령은 이것이 바뀌어도 유지됩니다. **검토**로 보거나, **모두에 … 사용**으로 이 모델로 옮기세요.

기본 제공 명령은 대신 **사용자 지정**을 보여 줍니다. 편집할 수 있는 본인 사본을 만듭니다. 본인 명령에는 **복제**와 **삭제**가 있는 **⋯** 메뉴가 있습니다. 명령을 삭제하면 PopBar에서도 빠지고 단축키가 풀립니다.

## 바뀌는 컨텍스트 쓰기

필드가 변수를 지원하면 변수 선택기로 입력 텍스트, 선택한 텍스트, 활성 앱, 그 밖 컨텍스트를 넣으세요. [변수](/ko/workflows/variables)를 보세요. 비공개 문서에 명령을 쓰기 전에 펼쳐진 컨텍스트를 확인하세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 명령이 없음 | 저장됐는지 확인한 뒤 제목을 검색하세요. |
| 출력이 선택한 텍스트를 무시함 | 명령의 입력과 컨텍스트 설정, 그리고 [권한](/ko/configuration/permissions)의 손쉬운 사용을 확인하세요. |

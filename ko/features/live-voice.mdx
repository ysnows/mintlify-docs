Live Talk는 에이전트와의 음성 통화입니다. 키를 누르지 않고 말하고, 에이전트는 소리 내어 답하며, 통화가 이어지는 동안 켠 도구로 작업을 시작할 수 있습니다. 말을 입력 텍스트로 바꾸려면 [받아쓰기](/ko/features/dictation)를 쓰세요.

## 시작하기 전에

Enconvo는 macOS의 마이크 접근이 필요합니다. 동작하는 마이크와 스피커를 고르세요. 통화가 쓰는 Cloud 서비스는 Enconvo Cloud 포인트를 씁니다. 본인 키와 Mac의 모델은 쓰지 않습니다.

## 통화 시작과 종료

1. 이야기할 에이전트와의 채팅을 여세요.
2. 마이크 옆 **Live Talk**를 클릭하세요. 통화가 연결될 때까지 기다리세요.
3. 말하세요. 누를 키는 없고, 언제든 에이전트 말에 끼어들어 멈추고 듣게 할 수 있습니다.
4. 더 큰 일에는 원하는 결과를 말하고 충분한 컨텍스트를 주세요. 일은 자기 채팅의 작업으로 실행됩니다. 작업 세부 정보를 펼쳐 진행이나 결과를 보세요.
5. 마이크 컨트롤로 음소거하거나, 끊기 컨트롤로 통화를 끝내세요. 끊은 뒤에도 작업은 계속 실행됩니다.

말한 턴은 일반 채팅 기록에 저장되므로, 채팅을 다시 열면 대화와 작업 세부 정보를 검토할 수 있습니다. 조용한 통화는 끊기 전까지 연결을 유지합니다. 채팅의 작업 링크는 통화로 다시 데려갑니다.

## 작업을 시작하지 않고 묻기

에이전트가 작업을 시작하지 않고 통화 안에서 바로 하는 일이 있습니다. 메모리와 지난 채팅 검색, 기억해 달라고 한 것 저장, 캘린더와 미리 알림 읽기, 메일 검색, MCP 서버의 읽기 전용 도구입니다. 설정의 **빠른 동작**에 더 있습니다.

긴 작업 중에는 에이전트가 지금까지 알아낸 것을 말해 줍니다.

## 에이전트를 조용히 하기

조용히 하거나 한동안 말하지 말라고 하세요. 아무것도 답하지 않고, 이름으로 부르거나, 다시 말해도 된다고 하거나, 입력하거나, **QUIET** 상태를 클릭할 때까지 소식을 붙들고 있습니다.

## 다른 통화 방법

작업이 사용자를 필요로 하면 에이전트가 iPhone 앱이나 전화번호로 전화할 수도 있습니다. 받으면 Live Talk가 시작됩니다. [에이전트 전화](/ko/features/agent-phone)를 보세요.

[아바타](/ko/features/avatar)에서 통화를 시작할 수도 있습니다. 그러면 화자로 나타납니다. [iPhone 앱](/ko/integrations/iphone-app)의 음성 채팅에서도 시작할 수 있습니다. iPhone이나 Android 앱의 통화 중 **원격 화면** 도구는 통화 위 작은 떠 있는 창에 컴퓨터 화면을 엽니다. [컴퓨터 화면 사용](/ko/integrations/iphone-app)을 보세요. **실시간 화면**을 켜면 통화 중 에이전트가 화면을 볼 수 있습니다.

## 설정

**설정 → Live Talk**를 여세요.

| 설정 | 바뀌는 것 |
| --- | --- |
| **듣기** | 통화가 듣는 방식입니다. **Enconvo Cloud Fast**(기본값)와 **ElevenLabs Scribe**(Scribe v3 Live)는 말하는 대로 단어를 듣습니다. Mac에서 도는 모델이나 아무 음성 모델도 고를 수 있습니다. |
| **생각** | 에이전트가 대화에 쓰는 모델입니다. **채팅과 동일**(기본값)은 채팅 제공업체의 빠른 모델을 쓰므로, 본인 API 키 채팅의 통화는 Enconvo Cloud 포인트를 쓰지 않습니다. Enconvo Cloud 채팅에서는 Enconvo Fast이며, DeepSeek V4.1 Flash로 답하고 보여 준 것도 보며, 그 모델로 청구됩니다. 유료 요금제나 체험의 통화는 무료로 남습니다. 더 큰 일은 에이전트로 가고, 그 채팅에 고른 모델에서 실행됩니다. |
| **말하기** | 에이전트가 답하는 목소리입니다. 기본값은 ElevenLabs v4 Turbo입니다. Phonon은 Mac에서 무료로 오프라인 실행되며 영어만 됩니다. 다음 통화부터 적용됩니다. |
| **음성 표현** | 대화에 맞게 각 답변의 어조가 얼마나 바뀔지입니다. **끔**, **은은하게**, **풍부하게**. ElevenLabs, Fish Audio, Gemini 목소리에서 동작합니다. |
| **새 대화 시작까지** | 마지막 통화 후 이 시간(분) 안의 통화는 아바타 통화를 포함해 이어서 갑니다. **0**은 항상 이어갑니다. |
| **빠른 동작** | **관리**는 **설정 → 빠른 동작**을 엽니다. 요청하면 작업을 시작하지 않고 에이전트가 바로 하는 일입니다. |

<Note>
Live Talk의 **생각** 모델은 여기서 정합니다. **설정 → AI 모델**의 **작업 모델** 아래에서도 고를 수 있습니다.
</Note>

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 통화가 연결되지 않음 | 연결 오류를 읽은 뒤 **듣기**, **생각**, **말하기** 선택을 확인하세요. Cloud 서비스는 **설정 → 포인트 사용량**에서 포인트를 확인하세요. |
| 마이크를 쓸 수 없음 | 진행 중인 받아쓰기나 녹음을 먼저 끝내고, macOS 마이크 접근을 확인하세요. |
| 에이전트가 동작을 수행하지 못함 | 그 에이전트의 도구와 권한을 검토하세요. 음성은 에이전트에게 없는 도구를 추가하지 않습니다. |
| 새 목소리가 쓰이지 않음 | 목소리 변경은 다음 통화부터 적용됩니다. |
| 통화가 "오디오 장치가 변경됨"으로 끝남 | 마이크나 스피커가 계속 다시 시작됩니다. **시스템 설정 → 사운드**에서 다른 장치를 고른 뒤 새 통화를 시작하세요. |
| 에이전트가 답을 멈춤 | 조용한 상태일 수 있습니다. 이름으로 부르거나 **QUIET** 상태를 클릭하세요. |

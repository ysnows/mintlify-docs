title: "Live Talk"
description: "Agent에게 전화를 걸어 이야기해 보세요. Agent가 듣고, 자신의 목소리로 답하며, 대화하는 동안 작업도 시작합니다."
---

Live Talk는 Agent와 하는 음성 통화입니다. 키를 누르지 않고 말하면 Agent가 소리 내어 답하고, 통화가 이어지는 동안 사용 가능한 도구로 작업을 시작할 수 있습니다. 음성을 타이핑된 텍스트로 바꾸려면 [받아쓰기](/ko/features/dictation)를 사용하세요.

## 시작하기 전에

Enconvo가 macOS에서 마이크에 접근할 수 있어야 합니다. 잘 작동하는 마이크와 스피커를 선택하세요. 통화에 사용되는 클라우드 서비스는 Enconvo Cloud 포인트를 소모하며, 내 Mac의 내 키와 모델은 소모하지 않습니다.

## 통화 시작과 종료

1. 대화하고 싶은 Agent와의 채팅을 엽니다.
2. 마이크 옆의 **Live Talk**를 클릭합니다. 연결될 때까지 기다립니다.
3. 말합니다. 누르고 있을 키는 없으며, Agent가 말하는 도중에 끼어들어 멈추고 듣게 할 수 있습니다.
4. 큰 작업은 원하는 결과를 말하고 충분한 맥락을 알려 주세요. 작업은 자체 채팅에서 태스크로 실행됩니다. 작업 세부 정보를 펼치면 진행 상황이나 결과를 볼 수 있습니다.
5. 마이크 컨트롤로 음소거하거나, 끊기 컨트롤로 통화를 종료합니다. 통화를 끊어도 작업은 계속 실행됩니다.

음성 대화는 일반 채팅 기록에 저장되므로 채팅을 다시 열면 대화와 작업 세부 정보를 확인할 수 있습니다. 조용한 통화는 끊을 때까지 연결이 유지됩니다. 채팅에 있는 작업 링크를 누르면 통화로 돌아옵니다.

## 작업을 시작하지 않고 물어보기

Agent는 일부 일을 작업을 시작하지 않고 통화 중에 바로 처리합니다. 메모리와 지난 채팅 검색, 기억해 달라고 한 내용 저장, 캘린더와 미리 알림 읽기, 메일 검색, MCP 서버의 읽기 전용 도구 사용 등입니다. 설정의 **빠른 동작**에 더 많은 항목이 나열되어 있습니다.

긴 작업 중에는 Agent가 지금까지 작업에서 찾은 내용을 알려 줍니다.

## Agent를 조용히 시키기

Agent에게 조용히 하라고 하거나 잠시 말을 멈추라고 하세요. Agent는 아무 대답도 하지 않고 소식을 보류하다가, 내가 이름을 부르거나, 다시 말해도 된다고 하거나, 입력해서 말을 걸거나, **조용히 있는 중** 상태를 클릭하면 다시 말합니다.

## 그 밖의 통화 방법

작업에 내가 필요할 때는 Agent가 iPhone 앱이나 내 전화번호로 전화를 걸 수도 있으며, 받으면 Live Talk가 시작됩니다. [에이전트 전화](/ko/features/agent-phone)를 참고하세요.

[아바타](/ko/features/avatar)에서 통화를 시작할 수도 있으며, 이 경우 아바타가 화자로 나타납니다. [iPhone 앱](/ko/integrations/iphone-app)의 음성 채팅에서도 시작할 수 있습니다. iPhone 또는 Android 앱에서 통화하는 동안 **원격 화면** 도구는 컴퓨터 화면을 통화 위의 작은 플로팅 창으로 엽니다. [컴퓨터 화면 사용하기](/ko/integrations/iphone-app)를 참고하세요. **실시간 화면**을 켜면 통화 중 Agent가 내 화면을 볼 수 있습니다.

## 설정

**설정 → Live Talk**를 엽니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **듣기** | 통화가 내 말을 듣는 방식입니다. **Enconvo Cloud Fast**(기본값)와 **ElevenLabs Scribe**(Scribe v3 Live)는 말하는 즉시 한 단어씩 인식합니다. 내 Mac에서 실행되는 모델이나 다른 음성 모델을 고를 수도 있습니다. |
| **생각** | Agent가 대화에 사용하는 모델입니다. **채팅과 동일**(기본값)은 채팅 자체 제공업체의 빠른 모델을 사용하므로, 내 API 키로 실행되는 채팅의 통화는 Enconvo Cloud 포인트를 소모하지 않습니다. Enconvo Cloud 채팅에서는 Enconvo Fast가 사용되며, DeepSeek V4.1 Flash로 답하고 내가 보여 주는 것도 볼 수 있으며 해당 모델로 요금이 청구됩니다. 유료 플랜이나 체험 기간의 통화는 계속 무료입니다. 더 큰 작업은 Agent에게 넘겨져 해당 채팅에 선택된 모델로 실행됩니다. |
| **말하기** | Agent가 답할 때 쓰는 음성이며, 기본값은 ElevenLabs v4 Turbo입니다. Phonon은 내 Mac에서 무료로 오프라인 실행되며 영어만 지원합니다. 다음 통화부터 적용됩니다. |
| **음성 표현** | 대화에 맞게 각 답변의 어조가 얼마나 달라질 수 있는지를 **끔**, **은은하게**, **풍부하게** 중에서 정합니다. ElevenLabs, Fish Audio, Gemini 음성에서 작동합니다. |
| **새 대화 시작까지** | 마지막 통화 후 이 시간(분) 안에 건 통화는 이전 대화를 이어서 합니다. 아바타 통화도 포함됩니다. **0**이면 항상 이어서 합니다. |
| **빠른 동작** | **관리**를 누르면 **설정 → 빠른 동작**이 열리며, 요청 시 작업을 시작하지 않고 Agent가 바로 처리하는 일들을 볼 수 있습니다. |

<Note>
Live Talk의 **생각** 모델은 여기에서 설정합니다. **설정 → AI 모델**의 **작업 모델**에서도 고를 수 있습니다.
</Note>

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 통화가 연결되지 않음 | 연결 오류를 읽고 **듣기**, **생각**, **말하기** 선택을 확인하세요. 클라우드 서비스라면 **설정 → 포인트 사용량**에서 포인트를 확인하세요. |
| 마이크를 사용할 수 없음 | 진행 중인 받아쓰기나 녹음을 먼저 끝내고 macOS 마이크 접근 권한을 확인하세요. |
| Agent가 작업을 수행하지 못함 | 해당 Agent의 도구와 권한을 확인하세요. 음성은 Agent에게 없는 도구를 추가해 주지 않습니다. |
| 새 음성이 적용되지 않음 | 음성 변경은 다음 통화부터 적용됩니다. |
| 통화가 "오디오 장치가 변경됨"으로 끝남 | 마이크나 스피커가 계속 다시 시작되고 있습니다. **시스템 설정 → 사운드**에서 다른 장치를 고른 다음 새 통화를 시작하세요. |
| Agent가 답하지 않음 | 조용히 있는 상태일 수 있습니다. 이름을 부르거나 **조용히 있는 중** 상태를 클릭하세요. |

PopBar는 어떤 앱에서든 텍스트를 선택하면 그 옆에 나타나는 작은 도구 막대입니다. 버튼을 눌러 선택한 텍스트를 설명, 번역, 편집, 검색, 복사하거나 소리 내어 읽을 수 있으며, [PopBar 확장 프로그램](#popbar-확장-프로그램)을 추가하면 웹 검색, 텍스트 변환, 다른 앱으로 보내기 등 더 많은 동작을 쓸 수 있습니다. 화면에 이미 나와 있는 글을 바로 다루고 싶을 때 사용하세요.

다른 작업에는 상황에 맞는 창을 쓰세요. 빠른 질문이나 명령에는 [SmartBar](/ko/features/smartbar), 긴 대화와 파일 작업에는 [채팅 창](/ko/ai/chat), 특정 앱 옆에 붙여 두고 일할 때는 [앱 사이드바](/ko/features/app-sidebar), 화면에 항상 작게 띄워 두는 진입점으로는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 쓸 수 있습니다. [창 관리](/ko/features/window-management)에서 모든 창을 비교해 볼 수 있습니다.

아래 동영상 튜토리얼에서는 6분 만에 PopBar를 처음부터 끝까지 설정하고 사용하는 법을 보여 줍니다. 기능 켜기, 표시 시점 고르기, 맞춤법 수정·번역·AI에게 질문 실행, 인라인 모드 쓰기, 버튼 추가·배치, 나만의 AI 명령 만들기, PopBar 확장 프로그램 설치 및 제작까지 모두 다룹니다.

## PopBar 사용하기

1. **설정 → PopBar**를 열고 **PopBar 활성화**를 켭니다.
2. 앱에서 짧은 문장을 선택합니다.
3. 도구 막대의 버튼을 클릭합니다.
4. 복사, 붙여넣기, 바꾸기 동작을 쓰기 전에 결과를 확인합니다.

단축키로 PopBar를 열 수도 있습니다. **Show PopBar**를 실행하거나 **표시 시점** 탭에서 **단축키**를 지정하세요. 도구 막대를 닫으려면 Escape 키를 누릅니다.

PopBar는 손쉬운 사용(Accessibility) 권한으로 선택한 텍스트를 읽으므로 앱에 따라 읽어오는 범위가 다릅니다. 보안 입력란이나 일부 커스텀 편집기는 텍스트를 외부에 공개하지 않습니다.

## 음성으로 질문하기

질문 패널이 열려 있고 입력란에 **선택한 텍스트에 대해 질문…**이 표시되어 있을 때는 타이핑 대신 말로 질문할 수 있습니다.

1. 입력란의 마이크 버튼을 클릭하거나 [음성 명령](/ko/features/dictation) 단축키를 누릅니다. 입력란에 **듣는 중…**이 표시되고 말하는 내용이 텍스트로 나타납니다.
2. 말을 마쳤으면 버튼을 다시 클릭하거나 누르고 있던 단축키에서 손을 뗍니다. 질문이 바로 전송됩니다.

전송하지 않고 듣기를 멈추려면 Escape 키를 누르세요. 말하기 전에 입력해 둔 텍스트가 있다면 음성으로 입력한 내용 앞에 그대로 남습니다.

## 버튼 고르기

PopBar 설정의 **버튼** 탭에서는 막대의 버튼들을 한 줄로 보여 줍니다. 버튼을 끌어 순서를 바꾸고, 마우스를 올려 **×**를 클릭해 빼거나, 클릭해 추가 옵션을 확인하세요. **기본값으로 재설정**을 누르면 기본 버튼 구성으로 돌아갑니다.

막대에 다 들어가지 않는 버튼은 끝의 **⌄** 아래에 있습니다. **⌄**를 클릭하면 **더 보기** 패널이 열려 나머지 버튼들과 모든 버튼·설정을 찾을 수 있는 검색창을 보여 줍니다. 버튼을 수정한 뒤에는 **PopBar 끄기** 아래에도 **기본값으로 재설정**이 나타나며, **실행 취소**와 함께 기본 버튼과 순서를 복원해 줍니다.

**버튼 추가**를 클릭하면 버튼 갤러리가 열립니다. AI에게 질문, 사이드바에서 묻기, 링크 열기, 검색, 복사, 번역, 설명, 맞춤법 수정, AI 편집, 소리 내어 읽기 등 다양한 기본 버튼과 [PopBar 확장 프로그램](#popbar-확장-프로그램)의 동작을 고를 수 있고, 나만의 [AI 명령](/ko/features/ai-commands)을 만들 수도 있습니다. [글쓰기 도구](/ko/features/writing-tools) 명령을 추가해 나만의 편집 흐름을 구성하는 것도 가능합니다. 추가한 버튼들이 도구 막대에 표시됩니다.

## 나타나는 위치와 조건 제어하기

**표시 시점** 탭에서 PopBar가 나타나는 조건을 정합니다.

| 설정 | 기능 |
| --- | --- |
| **어떤 텍스트** | 선택한 모든 텍스트에 PopBar를 표시할지, 외국어·코드·이메일처럼 도움이 될 만한 텍스트에만 표시할지 고릅니다. |
| **위치** | **다음을 제외한 모든 곳**을 선택하고 **앱 추가**나 **웹사이트 추가**로 특정 앱·사이트에서는 뜨지 않게 막습니다. 또는 **다음에서만**을 선택해 지정한 곳에서만 표시할 수 있습니다. |
| **텍스트를 선택하면 표시** | 이 옵션을 끄면 직접 부를 때만 PopBar가 나타납니다. **단축키 추가**를 클릭해 원하는 단축키를 지정하세요. |

터미널처럼 자동 도구 막대가 방해되는 앱은 제외해 두세요.

## 모양 바꾸기

**보기** 탭의 **레이아웃**에서는 버튼을 선택한 텍스트 위쪽에 한 줄로 둘지(**가로**), 마우스 포인터 옆에 세로로 둘지(**세로**) 고릅니다. 막대가 읽고 있는 글을 가린다면 **위치 미세 조정** 아래의 **X 오프셋**과 **Y 오프셋**으로 위치를 옮기세요.

## 인라인 모드

일부 버튼은 결과 창을 띄우지 않고 바로 동작할 수 있습니다. PopBar에서 **맞춤법 수정**을 오른쪽 클릭해 **인라인 모드**를 켜세요. 다음부터 텍스트를 선택하고 **맞춤법 수정**을 클릭하면 수정된 내용이 텍스트 자리에 바로 반영됩니다.

## 결과의 모델이나 설정 바꾸기

AI 모델 설정을 가진 명령의 결과 도구 막대에는 모델 제공업체 아이콘으로 된 모델 선택기가 표시됩니다. 여기서 모델을 바꾸면 이후 실행의 기본값도 함께 바뀝니다. 결과 창의 설정 버튼을 누르면 **플러그인 → 글쓰기 도구 → 설명**처럼 해당 결과를 만든 명령의 설정 화면이 열립니다.

## PopBar 확장 프로그램

PopBar 확장 프로그램은 각 동작이 PopBar 버튼이 되는 작은 추가 기능입니다. [PopClip](https://www.popclip.app)의 확장 형식을 사용하므로 PopClip용으로 만든 확장 프로그램도 Enconvo에 설치할 수 있습니다. PopBar 확장 프로그램을 쓰려면 Mac용 Enconvo가 필요합니다.

<Note>
Enconvo는 PopClip의 개발사인 Pilotmoon Software와 제휴 관계가 아닙니다.
</Note>

### Enconvo 카탈로그에서 설치하기

1. **플러그인**을 열고 **PopBar 확장 프로그램** 탭을 선택합니다.
2. 카테고리별로 카탈로그를 둘러보거나 검색창에 입력해 원하는 확장을 찾습니다.
3. 확장 옆의 **+**를 클릭한 뒤 **설치**를 누릅니다.
4. 이어서 뜨는 카드에 확장의 각 버튼과 표시 조건, 현재 위치가 나옵니다. 각 버튼마다 **막대에 표시**, **⌄ 더 보기에 표시**, **꺼짐** 중 하나를 고른 뒤 **완료**를 클릭하세요. **설정…**을 누르면 확장의 옵션이 열립니다.

새 버튼은 막대에 자리가 있으면 막대에 올라가고, 그렇지 않으면 PopBar의 **⌄ 더 보기** 패널 맨 앞에 들어갑니다. 패널을 열기 전까지 **⌄**에는 작은 점이 표시되며, 패널 안에는 새 버튼에 **NEW** 배지가 붙습니다.

Enconvo는 카탈로그에 등록하기 전에 모든 확장을 직접 검토하며, 검토한 바로 그 버전을 설치해 줍니다. 설치된 확장은 탭 맨 위에 표시됩니다. Enconvo가 더 새로운 버전을 검토해 등록하면 카탈로그의 해당 행에 **업데이트**가 표시됩니다. 버튼 갤러리의 **더 받기…**를 누르면 같은 탭이 열립니다.

웹에서도 [app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions)에서 카탈로그를 볼 수 있습니다. Mac에서는 확장의 **설치** 버튼을 누르면 Enconvo가 열리며, 실제로 설치하기 전에 그 확장이 무엇을 할 수 있는지 먼저 보여 줍니다.

### 다른 곳에서 확장 추가하기

**PopBar 확장 프로그램** 탭 또는 플러그인 페이지의 **추가** 메뉴에서 **PopBar 확장 프로그램 추가…**를 클릭한 뒤 다음 중 하나를 수행합니다.

- `.popclipextz` 패키지 링크를 붙여 넣습니다.
- `#popclip`으로 시작하는 짧은 텍스트 형식인 스니펫을 붙여 넣습니다.
- **파일 선택…**을 클릭해 Mac에 있는 `.popclipextz` 패키지나 `.popclipext` 폴더를 고릅니다.

**미리보기**를 클릭하면 Enconvo가 확장을 실행하지 않은 채 내용을 읽어 스크립트 실행, 인터넷 연결, 앱 열기, 키 입력 등 PopBar 밖에서 할 수 있는 동작들을 나열해 줍니다. **허용하고 설치**를 클릭하기 전까지는 아무것도 설치되지 않으며, 설치가 끝나면 카탈로그에서 설치했을 때와 같은 버튼 설정 카드가 나옵니다. Enconvo는 외부 확장을 검토하지 않으므로 신뢰할 수 있는 출처의 확장만 설치하세요.

어떤 앱에서든 스니펫을 선택하면 PopBar 맨 앞에 **확장 프로그램 설치** 버튼이 나타납니다. 이를 클릭해도 같은 미리보기 화면이 열립니다.

### PopClip에서 가져오기

PopClip을 쓰고 있다면 **PopBar 확장 프로그램** 탭에서 **PopClip에서 가져오기…**를 클릭하세요. Enconvo가 PopClip의 확장들과 설정을 PopClip에 있던 순서 그대로 복사해 PopBar에 추가합니다. 기존 PopClip 자체는 변경되지 않습니다.

- PopClip에서 꺼져 있던 확장은 설치되지만 PopBar에는 추가되지 않습니다.
- API 키와 비밀번호는 복사되지 않습니다. Enconvo가 키가 필요한 확장 목록을 알려 주므로 각 확장의 설정에서 다시 입력하세요.
- Enconvo 카탈로그에 있는 버전과 일치하는 확장은 검토된 확장으로 인식되어 카탈로그에서 업데이트를 받습니다.

### 설정, 업데이트, 제거

**PopBar 확장 프로그램** 탭에서 확장을 클릭하면 상세 페이지가 열립니다. **PopBar 버튼** 섹션에서 각 버튼과 표시 시점을 확인하고 막대에 둘지, **⌄ 더 보기**에 둘지, PopBar에서 끌지 선택할 수 있습니다. **PopBar 설정에서 모든 버튼 정렬**을 누르면 버튼 탭이 열립니다.

옵션이 있는 확장은 페이지 상단에 **설정**, 버튼 갤러리 카드에 **설정…**이 표시됩니다.

링크로 설치한 확장은 같은 링크를 통해 업데이트됩니다. 업데이트된 버전이 처음 허용했던 것보다 더 많은 권한을 요구하면 Enconvo가 새로 추가된 부분만 보여 주고 업데이트 전에 다시 동의를 구합니다.

확장을 제거하려면 **PopBar 확장 프로그램** 탭에서 해당 확장을 열고 제거하세요. 해당 확장의 버튼도 PopBar에서 함께 사라집니다.

### 아직 지원되지 않는 항목

- 계정에 로그인해야 하는 확장 프로그램
- 막대가 나타날 때마다 동적으로 동작 목록을 생성하는 확장 프로그램

확장이 이 중 하나를 사용하면 미리보기 단계에서 Enconvo가 미리 알려 줍니다.

### 확장 프로그램 제안하기

Enconvo 카탈로그는 [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions)에서 관리됩니다. 검토를 제안하고 싶은 확장이 있다면 그곳에 이슈나 풀 리퀘스트를 올려 주세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 도구 막대가 나타나지 않음 | **PopBar 활성화**, 손쉬운 사용 권한, **위치** 아래의 앱·웹사이트 설정을 확인하세요. |
| 엉뚱한 텍스트에 작동함 | 텍스트를 다시 선택한 뒤 PopBar를 여세요. |
| 특정 명령이 보이지 않음 | **버튼** 탭을 확인하고, 해당 명령의 플러그인이 설치되어 있는지 확인하세요. |
| 결과가 내 텍스트를 바꾸지 않음 | 해당 앱이 직접 대체를 허용하지 않을 수 있습니다. 결과를 복사해 편집 가능한 입력란에 붙여 넣으세요. |
| 확장 버튼이 나타나지 않음 | 새 버튼이 들어가는 PopBar 끝의 **⌄**를 클릭하거나, 플러그인의 확장 페이지에서 **꺼짐** 상태가 아닌지 확인하세요. **Base64 Decode**처럼 작업할 수 있는 텍스트일 때만 나타나는 버튼도 있습니다. 일반 텍스트를 선택하면 **Base64 Encode**만 보입니다. |
| 확장 버튼이 선택한 텍스트를 덮어씀 | 많은 확장이 PopClip에서와 마찬가지로 선택 영역에 결과를 바로 붙여 넣습니다. 편집할 수 없는 곳이라면 대신 결과가 복사됩니다. |
| 카탈로그가 불러와지지 않음 | 인터넷 연결을 확인한 뒤 **PopBar 확장 프로그램** 탭에서 **다시 시도**를 클릭하세요. |

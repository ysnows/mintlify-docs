PopBar는 어떤 앱에서든 선택한 텍스트 옆에 나타나는 작은 도구 막대입니다. 버튼으로 선택한 내용을 설명하고, 번역하고, 편집하고, 검색하고, 복사하고, 소리 내어 읽을 수 있으며, [PopBar 확장 프로그램](#popbar-확장-프로그램)으로 웹 검색, 텍스트 변환기, 선택한 내용을 다른 앱으로 보내기 같은 기능을 더할 수 있습니다. 작업하려는 텍스트가 이미 화면에 있을 때 사용하세요.

다른 용도에는 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 긴 대화와 파일은 [채팅 창](/ko/ai/chat), 앱 하나 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 화면에 계속 떠 있는 작은 진입점으로는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

아래 동영상 튜토리얼은 PopBar를 6분 동안 처음부터 끝까지 설정하고 사용합니다. 켜기, 표시 시점 고르기, 맞춤법 수정, 번역, AI에게 묻기 실행, 인라인 모드 사용, 버튼 추가와 정렬, 나만의 AI 명령 만들기, PopBar 확장 프로그램 받기와 만들기를 다룹니다.

## PopBar 사용하기

1. **설정 → PopBar**를 열고 **PopBar 활성화**를 켜세요.
2. 앱에서 짧은 구절을 선택하세요.
3. 도구 막대의 버튼을 클릭하세요.
4. 복사, 붙여넣기, 바꾸기 동작을 쓰기 전에 결과를 확인하세요.

단축키로도 PopBar를 열 수 있습니다. **Show PopBar**를 실행하거나 **표시 시점** 탭에서 **단축키**를 설정하세요. Escape를 누르면 도구 막대가 닫힙니다.

PopBar는 손쉬운 사용 권한으로 선택한 내용을 읽으며, 읽어 오는 내용은 앱에 따라 다릅니다. 보안 입력란과 일부 사용자 지정 편집기는 텍스트를 공개하지 않습니다.

## 음성으로 질문하기

질문 패널이 열려 있고 입력란에 **선택한 텍스트에 대해 질문…**이 표시되어 있을 때는 질문을 입력하는 대신 말할 수 있습니다.

1. 입력란의 마이크 버튼을 클릭하거나 [음성 명령](/ko/features/dictation) 단축키를 누르세요. 입력란에 **듣는 중…**과 말하는 대로 단어가 표시됩니다.
2. 끝나면 버튼을 다시 클릭하거나, 누르고 있던 단축키에서 손을 떼세요. 질문이 전송됩니다.

보내지 않고 듣기를 멈추려면 Escape를 누르세요. 말하기 전에 입력한 내용은 말한 단어 앞에 그대로 남습니다.

## 버튼 고르기

PopBar 설정의 **버튼** 탭에는 막대의 버튼이 한 줄로 표시됩니다. 버튼을 드래그해 순서를 바꾸거나, 포인터를 올리고 **×**를 클릭해 제거하거나, 클릭해서 더 많은 옵션을 볼 수 있습니다. **기본값으로 재설정**은 기본 버튼을 되돌립니다.

막대에 들어가지 않는 버튼은 끝의 **⌄** 아래에 있습니다. **⌄**를 클릭해 **더 보기** 패널을 여세요. 그 버튼들과 모든 버튼과 설정을 찾는 검색란이 나열됩니다. 버튼을 바꾸고 나면 **기본값으로 재설정**도 **PopBar 끄기** 아래에 나타나며, 기본 버튼과 순서를 되돌리고 **실행 취소**할 수 있습니다.

**버튼 추가**를 클릭하면 버튼 갤러리가 열립니다. AI에게 묻기, 사이드바에서 묻기, 링크 열기, 검색, 복사, 번역, 설명, 맞춤법 수정, AI 편집, 소리 내어 읽기 등이 있고, [PopBar 확장 프로그램](#popbar-확장-프로그램)의 동작과 나만의 [AI 명령](/ko/features/ai-commands)을 만드는 방법도 있습니다. 나만의 편집 작업 방식에 맞는 [글쓰기 도구](/ko/features/writing-tools) 명령도 추가할 수 있습니다. 도구 막대에는 추가한 버튼이 표시됩니다.

## 나타나는 위치 제어하기

**표시 시점** 탭은 PopBar가 나타나는 시점을 정합니다.

| 설정 | 동작 |
| --- | --- |
| **어떤 텍스트** | 선택한 모든 텍스트에 PopBar를 표시하거나, 외국어, 코드, 이메일처럼 도움이 될 수 있는 텍스트에만 표시합니다. |
| **위치** | **다음을 제외한 모든 곳**을 선택한 다음 **앱 추가** 또는 **웹사이트 추가**로 일부 앱이나 웹사이트에서 나타나지 않게 합니다. 또는 **다음에서만**을 선택해 나열한 곳에서만 표시합니다. |
| **텍스트를 선택하면 표시** | 끄면 요청할 때만 PopBar가 표시되며, **단축키 추가**를 클릭하고 단축키를 고르세요. |

터미널처럼 자동으로 나타나는 도구 막대가 방해가 되는 앱은 제외하세요.

## 모양 바꾸기

**보기** 탭에서 **레이아웃**은 버튼을 선택 영역 위의 한 줄(**가로**)이나 포인터 옆의 한 열(**세로**)로 배치합니다. 막대가 읽고 있는 내용을 가리면 **위치 미세 조정**의 **X 오프셋**과 **Y 오프셋**으로 옮기세요.

## 인라인 모드

일부 버튼은 결과 창 없이 작동할 수 있습니다. PopBar에서 **맞춤법 수정**을 오른쪽 클릭하고 **인라인 모드**를 켜세요. 다음에 텍스트를 선택하고 **맞춤법 수정**을 클릭하면 수정 결과가 텍스트에 바로 반영됩니다.

## 결과의 모델이나 설정 바꾸기

AI 모델 설정이 있는 명령에서는 결과 도구 막대에 모델 제공업체의 아이콘으로 표시되는 모델 선택기가 있습니다. 이를 바꾸면 이후 실행에 쓰이는 명령의 기본값도 바뀝니다. 결과 창의 설정 버튼은 **플러그인 → 글쓰기 도구 → 설명**처럼 결과를 만든 명령을 엽니다.

## PopBar 확장 프로그램

PopBar 확장 프로그램은 동작이 PopBar 버튼이 되는 작은 부가 기능입니다. [PopClip](https://www.popclip.app)의 확장 프로그램 형식을 사용하므로, PopClip용으로 만든 확장 프로그램도 Enconvo에 설치됩니다. PopBar 확장 프로그램은 Mac용 Enconvo가 필요합니다.

<Note>
Enconvo는 PopClip의 제작사인 Pilotmoon Software와 제휴 관계가 없습니다.
</Note>

### Enconvo 카탈로그에서 설치하기

1. **플러그인**을 열고 **PopBar 확장 프로그램** 탭을 선택하세요.
2. 카테고리별로 카탈로그를 둘러보거나, 검색란에 입력해 찾으세요.
3. 확장 프로그램 옆의 **+**를 클릭한 다음 **설치**를 클릭하세요.
4. 이어서 나타나는 카드에 확장 프로그램의 버튼, 각 버튼이 표시되는 시점, 위치가 나열됩니다. 각각 **막대에**, **⌄ 더 보기에**, **끔** 중에서 고른 다음 **완료**를 클릭하세요. **설정…**은 확장 프로그램의 옵션을 엽니다.

새 버튼은 PopBar의 **⌄ 더 보기** 패널 맨 앞으로 가거나, 공간이 있으면 막대에 들어갑니다. 패널을 열 때까지 **⌄**에 점이 표시되며, 패널에서는 새 버튼에 **NEW**가 표시됩니다.

Enconvo는 카탈로그의 모든 확장 프로그램을 등록하기 전에 검토하고, 검토한 버전을 그대로 설치합니다. 설치된 확장 프로그램은 탭 맨 위에 나열됩니다. Enconvo가 더 새로운 버전을 검토했다면 카탈로그의 해당 행에 **업데이트**가 표시됩니다. 버튼 갤러리의 **더 받기…**는 같은 탭을 엽니다.

카탈로그는 웹의 [app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions)에서도 둘러볼 수 있습니다. Mac에서 확장 프로그램의 **설치** 버튼은 Enconvo를 열고, 설치되기 전에 확장 프로그램이 할 수 있는 일을 보여 줍니다.

### 다른 곳의 확장 프로그램 추가하기

**PopBar 확장 프로그램** 탭이나 플러그인 페이지의 **추가** 메뉴에서 **PopBar 확장 프로그램 추가…**를 클릭하세요. 그런 다음 다음 중 하나를 하세요.

- `.popclipextz` 패키지 링크를 붙여 넣으세요.
- 스니펫을 붙여 넣으세요. `#popclip`으로 시작하는, 확장 프로그램의 짧은 텍스트 형태입니다.
- **파일 선택…**을 클릭해 Mac의 `.popclipextz` 패키지나 `.popclipext` 폴더를 고르세요.

**미리보기**를 클릭하세요. Enconvo가 확장 프로그램을 실행하지 않고 읽은 다음, 스크립트 실행, 인터넷 연결, 앱 열기, 키 누르기처럼 PopBar 밖에서 할 수 있는 일을 나열합니다. **허용하고 설치**를 클릭하기 전에는 아무것도 설치되지 않으며, 카탈로그에서 설치할 때와 같은 버튼 카드로 끝납니다. Enconvo는 카탈로그 밖의 확장 프로그램은 검토하지 않으므로, 신뢰하는 출처에서만 설치하세요.

어떤 앱에서든 스니펫을 선택하면 PopBar에 **확장 프로그램 설치** 버튼이 먼저 나타납니다. 클릭하면 같은 미리보기가 열립니다.

### PopClip에서 가져오기

PopClip을 사용한다면 **PopBar 확장 프로그램** 탭에서 **PopClip에서 가져오기…**를 클릭하세요. Enconvo가 PopClip의 확장 프로그램과 설정을 PopClip의 순서대로 복사하고, 그 동작을 PopBar에 추가합니다. PopClip 자체는 바뀌지 않습니다.

- PopClip에서 꺼져 있는 확장 프로그램은 설치되지만 PopBar에는 추가되지 않습니다.
- API 키와 암호는 복사되지 않습니다. Enconvo가 필요한 확장 프로그램을 나열하므로, 각 확장 프로그램의 설정에서 다시 입력하세요.
- Enconvo 카탈로그의 버전과 일치하는 확장 프로그램은 검토된 것으로 간주되며 카탈로그에서 업데이트됩니다.

### 설정, 업데이트, 제거

**PopBar 확장 프로그램** 탭에서 확장 프로그램을 열어 해당 페이지를 보세요. **PopBar 버튼** 섹션에는 각 버튼과 표시 시점이 나열되며, 막대에 두거나, **⌄ 더 보기**에 두거나, PopBar에서 뺄 수 있습니다. **PopBar 설정에서 모든 버튼 정렬**은 버튼 탭을 엽니다.

옵션이 있는 확장 프로그램은 페이지 맨 위에 **설정**이 표시되고, 버튼 갤러리의 카드에는 **설정…**이 표시됩니다.

링크로 설치한 확장 프로그램은 같은 링크에서 업데이트됩니다. 업데이트가 허용한 버전보다 더 많은 일을 할 수 있으면, Enconvo는 새로 추가된 내용만 보여 주고 업데이트하기 전에 다시 묻습니다.

확장 프로그램을 제거하려면 **PopBar 확장 프로그램** 탭에서 열고 제거하세요. 해당 버튼이 PopBar에서 사라집니다.

### 아직 지원하지 않는 것

- 계정에 로그인하는 확장 프로그램.
- 막대가 나타날 때마다 동작을 새로 만드는 확장 프로그램.

확장 프로그램이 이 중 하나를 사용하면 Enconvo가 미리보기 중에 알려 줍니다.

### 확장 프로그램 제안하기

Enconvo의 카탈로그는 [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions)에 있습니다. 그곳에 이슈나 풀 리퀘스트를 열어 검토할 확장 프로그램을 제안하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 도구 막대가 나타나지 않습니다 | **PopBar 활성화**, 손쉬운 사용 권한, **위치** 아래의 앱과 웹사이트를 확인하세요. |
| 엉뚱한 텍스트에 동작합니다 | 새로 선택한 다음 PopBar를 다시 여세요. |
| 명령이 없습니다 | **버튼** 탭과 해당 명령의 플러그인이 설치되어 있는지 확인하세요. |
| 결과가 텍스트를 바꾸지 않습니다 | 앱이 허용하지 않을 수 있습니다. 결과를 복사해 편집할 수 있는 입력란에 붙여 넣으세요. |
| 확장 프로그램 버튼이 나타나지 않습니다 | 새 버튼이 들어가는 PopBar 끝의 **⌄**를 클릭하거나, 플러그인에서 확장 프로그램 페이지를 확인하세요. **끔**인 버튼은 PopBar에 없습니다. 일부 버튼은 작업할 수 있는 텍스트에만 표시됩니다. 예를 들어 **Base64 Decode**는 Base64처럼 보이는 텍스트에만 표시되므로, 일반 텍스트를 선택하면 **Base64 Encode**만 표시됩니다. |
| 확장 프로그램 버튼이 선택한 텍스트를 바꿨습니다 | 많은 확장 프로그램이 PopClip에서처럼 결과를 선택 영역 위에 붙여 넣습니다. 텍스트를 편집할 수 없는 곳에서는 결과가 복사됩니다. |
| 카탈로그가 불러와지지 않습니다 | 연결을 확인한 다음 **PopBar 확장 프로그램** 탭에서 **다시 시도**를 클릭하세요. |

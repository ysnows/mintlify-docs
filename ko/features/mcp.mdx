[Model Context Protocol(MCP)](https://modelcontextprotocol.io)은 AI 모델이 외부 도구와 데이터를 사용할 수 있게 해 주는 개방형 표준입니다. 각 MCP 서버는 파일 읽기, 데이터베이스 조회, 메시지 보내기처럼 에이전트가 호출할 수 있는 도구를 제공합니다. Enconvo에 서버를 추가하면 작업에 필요할 때 에이전트가 알아서 그 도구를 사용합니다.

## 설정에서 서버 추가하기

<Steps>
  <Step title="MCP 서버 열기">
    메뉴 막대의 Enconvo 아이콘에서 **설정...**을 선택하거나 **⌘,**를 눌러 **설정**을 엽니다. 그런 다음 **설정 → MCP 서버**를 엽니다.
  </Step>
  <Step title="서버 추가하기">
    **서버 추가**를 클릭하고 **서버 이름**을 입력합니다. 전송 방식을 선택합니다. Mac에서 실행되는 명령은 **STDIO**, URL에 있는 서버는 **HTTP** 또는 **SSE**입니다. 필드를 채우고 **저장**을 클릭하세요.
  </Step>
  <Step title="연결되는지 확인하기">
    서버 옆의 점이 녹색으로 바뀌고, 서버 행에 도구 개수가 표시됩니다. 도구 개수를 클릭하면 도구 목록을 볼 수 있습니다.
  </Step>
  <Step title="도구를 적용할 범위 선택하기">
    서버 행의 스위치를 사용합니다. 켜면 어시스턴트가 답변을 준비할 때마다 Enconvo가 어디서나 서버의 도구를 포함합니다. 끄면 어디서나 로드되지는 않지만, SmartBar에서 서버를 추가하거나 앱 사이드바에서 특정 앱에 대해서만 켤 수 있습니다.
  </Step>
</Steps>

OAuth를 사용하는 서버는 처음 연결할 때 로그인 페이지가 열립니다. 서버에 **인증하기**가 표시되면 클릭하여 로그인을 마치세요. 연결된 서버가 로그인으로 받은 것보다 더 많은 접근 권한을 요청하면 **접근 권한 허용**이 나타납니다.

플러그인과 함께 제공되는 서버는 **플러그인에서** 아래에 표시됩니다.

<Tip>
설정 사이드바는 깁니다. 설정에서 **⌘F**를 누르고 "MCP"를 입력하면 해당 패널로 바로 이동하며, 딥링크 `enconvo://preference?pane=mcp_management`로 열 수도 있습니다.
</Tip>

## CLI로 서버 추가하기

```bash
# Add a stdio server
enconvo mcp add github --command npx --args "-y @modelcontextprotocol/server-github"

# Add an HTTP server
enconvo mcp add notion --transport http --url "https://mcp.notion.com/mcp"

# List servers
enconvo mcp servers list

# List tools
enconvo mcp tools list
```

## 다른 앱에서 서버 가져오기

Claude Desktop, Cursor 또는 다른 도구에서 이미 사용 중인 MCP 구성을 가져옵니다.

1. **설정 → MCP 서버**에서 **가져오기**를 클릭합니다.
2. **설정 형식**에서 **Claude Desktop** 또는 **Codex CLI**를 선택합니다.
3. **JSON 구성**에 설정을 붙여 넣습니다.
4. **가져오기**를 클릭합니다. 구성에 있는 모든 서버가 추가됩니다.

## MCP 번들 설치하기

MCP 번들은 Mac에서 실행할 서버를 담은 `.mcpb` 파일입니다. **설정 → MCP 서버**에서 **번들 설치**를 클릭하고 파일을 선택하세요. Finder에서 `.mcpb` 파일을 열어도 같은 화면으로 이동합니다.

번들의 서버는 사용자의 권한으로 Mac에서 실행되므로, 신뢰할 수 있는 사람이 만든 번들만 설치하세요. 번들을 업데이트하려면 더 새로운 `.mcpb` 파일을 설치합니다.

## 설치 링크 공유하기

설치 링크를 사용하면 클릭 한 번으로 Enconvo에 MCP 서버를 추가할 수 있습니다. 형식은 `mcp.json`과 같으며, 이름과 전송 방식 구성으로 이루어집니다.

```
https://enconvo.com/mcp/install?name=$NAME&config=$BASE64_ENCODED_CONFIG
```

| 구성 요소 | 설명 |
|-----------|-------------|
| `https://enconvo.com` | 웹 설치 페이지 |
| `/mcp/install` | 경로 |
| `name` | 서버 이름용 쿼리 매개변수 |
| `config` | base64로 인코딩한 JSON 구성용 쿼리 매개변수 |

웹 페이지는 `enconvo://` 딥링크를 열고, 앱이 열리지 않는 경우를 대비해 서버 구성을 보여 줍니다.

### 링크 만들기

1. 서버의 이름과 JSON 구성을 확인합니다.
2. 구성을 `JSON.stringify`한 다음 base64로 인코딩합니다.
3. `$NAME`과 `$BASE64_ENCODED_CONFIG`를 이름과 인코딩된 구성으로 바꿉니다.

예를 들어 다음 구성은

```json Single MCP server config
{
  "exa": {
    "url": "https://mcp.exa.ai/mcp"
  }
}
```

다음과 같은 결과가 됩니다.

| 형식 | 예시 |
|--------|---------|
| 텍스트 링크 | `https://enconvo.com/mcp/install?name=exa&config=eyJ1cmwiOiJodHRwczovL21jcC5leGEuYWkvbWNwIn0=` |

### 누군가 링크를 열면 일어나는 일

1. 링크를 클릭하거나 브라우저에 붙여 넣습니다.
2. Enconvo가 **MCP 서버 "name"을(를) 추가할까요?**라고 묻고, 서버가 실행하거나 연결하는 대상을 보여 줍니다. **추가**를 클릭합니다.
3. **설정 → MCP 서버**가 열리고 서버가 추가되어 연결을 시작합니다.
4. 연결되면 에이전트가 그 도구를 사용할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 서버가 시작되지 않습니다 | 명령과 인수를 확인하세요. STDIO 서버는 프로그램이 설치되어 있고 `PATH`에 있는지 확인합니다. Node.js 서버는 `npx` 또는 `node`를 사용할 수 있는지 확인합니다. |
| 도구가 나타나지 않습니다 | 서버의 점이 녹색인지 확인하세요. 일부 서버는 API 키가 있어야 도구를 제공합니다. 서버를 껐다가 다시 켜 보세요. |
| 서버에 **인증하기**가 표시됩니다 | 클릭한 다음 열리는 페이지에서 로그인을 마치세요. |
| 인증 오류 | API 키가 올바르고 만료되지 않았는지, 서버에 필요한 환경 변수가 설정되어 있는지 확인하세요. |

MCP 전체 사양은 [modelcontextprotocol.io](https://modelcontextprotocol.io)에서 확인할 수 있습니다.

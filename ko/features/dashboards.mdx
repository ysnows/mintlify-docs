---

대시보드는 에이전트가 사용자의 데이터로 만드는 수치와 차트 페이지로, 추적하거나 검토하거나 보고하는 수치에 사용합니다. 모든 수치가 출처가 된 행과 연결되어 있어 직접 확인할 수 있습니다. 수치를 다시 확인할 때 사용하세요. 일회성 답변이라면 채팅에서 그냥 물어보면 됩니다.

## 대시보드 만들기

1. 새 채팅을 시작하고 메시지 입력란 아래에서 **대시보드**를 선택하거나, 어떤 채팅에서든 요청합니다.
2. 데이터를 첨부합니다. CSV, TSV, JSON 파일을 첨부하거나, **만들기** 줄에서 **스프레드시트 열기**를 클릭합니다. 연결된 서비스, Mac의 파일, 웹 주소를 에이전트에게 알려 줄 수도 있습니다.
3. 무엇을 추적하고 어떻게 나눠 볼지 말합니다.

예시:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

대시보드는 채팅 옆에서 열립니다. 에이전트가 필터를 추가하면 각각 메뉴, 스위치, 입력란으로 상단에 표시됩니다.

## 수치 확인

1. 대시보드 머리글에서 **숫자 확인**을 클릭합니다.
2. 아무 수치나 클릭합니다.
3. Enconvo가 그 뒤에 있는 행, 출처, 둘이 일치하는지 여부를 보여 줍니다.

수치에 대해 질문하려면 해당 수치에 댓글을 다세요. 댓글을 `@Enconvo`로 시작하면 에이전트가 답합니다.

## 데이터 출처 확인

**소스**를 클릭합니다. 각 데이터 세트에 출처, 행 수, 마지막 변경 시점이 표시됩니다. 기한이 지난 데이터에는 **오래됨**이 표시됩니다. **CSV 다운로드**를 클릭하면 데이터 세트를 저장합니다.

## 수치를 최신 상태로 유지

연결된 서비스, Mac의 파일, 웹 주소로 만든 대시보드는 허용하면 스스로 업데이트할 수 있습니다.

1. 대시보드가 **이 숫자를 최신 상태로 유지할까요?**라고 물으면 각 소스가 무엇을 읽는지 확인한 다음 **허용**을 클릭합니다. **소스**에서 소스 옆의 **업데이트 허용**을 클릭해도 됩니다.
2. 수치는 에이전트가 설정한 일정(예: **매시간** 또는 **새로 고칠 때**)에 따라 업데이트됩니다. 지금 업데이트하려면 **새로고침**을 클릭하세요.
3. 중지하려면 소스 옆의 **업데이트 중지**를 클릭합니다.

업데이트가 실패하면 대시보드는 마지막 수치를 유지하고 이유를 알려 줍니다.

<Note>
데이터를 읽기만 한다고 밝히지 않은 소스는 **새로고침**을 클릭할 때만 실행됩니다. 공유된 대시보드에서는 모든 구성원이 소스가 읽는 내용을 볼 수 있습니다.
</Note>

## 대시보드 다운로드 또는 이동

**다운로드**를 클릭하고 선택합니다.

| 옵션 | 결과물 |
| --- | --- |
| **PDF 다운로드** | 페이지의 PDF |
| **이미지 다운로드** | 페이지의 그림 |
| **HTML 다운로드** | 어떤 브라우저에서나 열리는 HTML 파일 하나 |
| **프로젝트 다운로드(.zip)** | 다른 컴퓨터에서 가져올 수 있는 전체 프로젝트 |

프로젝트를 가져오려면 **아티팩트** 라이브러리에서 **가져오기**를 클릭하고 zip 파일을 선택하세요. 댓글도 함께 옮겨지며, 연결된 서비스의 업데이트는 그곳에서 다시 허용해야 합니다.

대시보드를 사람이나 팀과 공유하려면 **공유**를 클릭하세요. [아티팩트](/ko/features/artifacts)를 참고하세요. 대시보드는 iPhone과 Android 앱에서도 열립니다. [아티팩트](/ko/features/artifacts)를 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 수치와 해당 행이 일치하지 않음 | 댓글로 에이전트에게 물어보거나 계산을 고쳐 달라고 요청하세요 |
| 소스에 **오래됨**이 표시됨 | **새로고침**을 클릭하거나 해당 소스의 업데이트를 허용하세요 |
| **숫자를 업데이트할 수 없습니다** | 이유를 읽고 소스의 액세스 권한을 해결한 다음 **새로고침**을 클릭하세요 |
| 대시보드가 비어 있음 | 채팅에서 대시보드와 데이터를 설명하세요 |

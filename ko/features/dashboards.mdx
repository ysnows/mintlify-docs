---
title: "대시보드"
description: "에이전트가 데이터를 숫자와 차트의 페이지로 만들고, 각 숫자를 행과 대조해 확인하고, 최신으로 유지하게 합니다."
---

대시보드는 추적, 검토, 보고할 숫자를 위해 에이전트가 데이터로 만드는 숫자와 차트 페이지입니다. 모든 숫자는 나온 행에 묶여 있어 확인할 수 있습니다. 숫자에 다시 돌아올 때 쓰세요. 한 번의 답이면 채팅에서 그냥 물으면 됩니다.

## 대시보드 만들기

1. 새 채팅을 시작하고 메시지 상자 아래에서 **대시보드**를 고르거나, 아무 채팅에서나 요청합니다.
2. 데이터를 첨부합니다. CSV, TSV, JSON 파일, 또는 **만들기** 행의 **스프레드시트 열기**를 클릭합니다. 연결된 서비스, Mac의 파일, 웹 주소를 가리킬 수도 있습니다.
3. 무엇을 추적하고 어떻게 나눌지 말합니다.

예:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

대시보드가 채팅 옆에 열립니다. 에이전트가 필터를 추가하면 각각 위쪽에 메뉴, 스위치, 상자로 나타납니다.

## 숫자 확인

1. 대시보드 헤더에서 **숫자 확인**을 클릭합니다.
2. 아무 숫자나 클릭합니다.
3. Enconvo가 그 뒤의 행, 출처, 둘이 맞는지 보여 줍니다.

숫자에 대해 물으려면 댓글을 답니다. 댓글을 `@Enconvo`로 시작하면 에이전트의 답을 받습니다.

## 데이터 출처 보기

**출처**를 클릭합니다. 각 데이터 집합은 어디서 왔는지, 행이 몇 개인지, 마지막으로 언제 바뀌었는지를 보여 줍니다. 기한이 지난 데이터는 **오래됨**으로 표시됩니다. **CSV 다운로드**를 클릭해 데이터 집합을 저장합니다.

## 숫자를 최신으로 유지

연결된 서비스, Mac의 파일, 웹 주소로 만든 대시보드는 허용하면 스스로 업데이트할 수 있습니다.

1. 대시보드가 **이 숫자를 최신으로 유지할까요?**라고 물으면 각 출처가 읽는 것을 확인한 다음 **허용**을 클릭합니다. **출처**에서 출처 옆 **업데이트 허용**을 클릭할 수도 있습니다.
2. 숫자는 에이전트가 정한 일정으로 업데이트됩니다. **매시간**, 또는 **새로 고칠 때** 같은 것입니다. 지금 업데이트하려면 **새로 고침**을 클릭합니다.
3. 멈추려면 출처 옆 **업데이트 중지**를 클릭합니다.

업데이트가 실패하면 대시보드는 마지막 숫자를 유지하고 이유를 말합니다.

<Note>
읽기만 한다고 말하지 않는 출처는 **새로 고침**을 클릭할 때만 실행됩니다. 공유 대시보드에서는 그 안의 모두가 출처가 읽는 것을 봅니다.
</Note>

## 대시보드 다운로드 또는 이동

**다운로드**를 클릭하고 고릅니다.

| 옵션 | 받는 것 |
| --- | --- |
| **PDF 다운로드** | 페이지의 PDF |
| **이미지 다운로드** | 페이지의 그림 |
| **HTML 다운로드** | 아무 브라우저에서나 열리는 HTML 파일 하나 |
| **프로젝트 다운로드 (.zip)** | 다른 컴퓨터에서 가져올 전체 프로젝트 |

프로젝트를 가져오려면 **아티팩트** 라이브러리에서 **가져오기**를 클릭하고 zip을 고릅니다. 댓글도 함께 오며, 연결된 서비스의 업데이트는 거기서 다시 허용해야 합니다.

사람이나 팀과 대시보드를 공유하려면 **공유**를 클릭합니다. [아티팩트](/ko/features/artifacts)를 보세요. 대시보드는 iPhone과 Android 앱에서도 열립니다. [아티팩트](/ko/features/artifacts)를 보세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 숫자와 행이 맞지 않음 | 댓글에서 에이전트에게 묻거나, 계산을 고치라고 요청합니다 |
| 출처가 **오래됨**으로 표시됨 | **새로 고침**을 클릭하거나 그 출처의 업데이트를 허용합니다 |
| **숫자를 업데이트할 수 없음** | 이유를 읽고 출처 접근을 고친 다음 **새로 고침**을 클릭합니다 |
| 대시보드가 비어 있음 | 채팅에서 대시보드와 데이터를 설명합니다 |

앱 사이드바는 앱 창 옆에 Enconvo 대화를 엽니다. 그 앱의 컨텍스트를 쓰므로, 정보를 별도 채팅에 복사하지 않고 읽고 쓰고 작업할 수 있습니다. 질문이 앞에 있는 앱에 관한 것일 때 쓰세요.

다른 일에는 빠른 질문이나 명령에 [SmartBar](/ko/features/smartbar), 기록과 파일이 더 필요할 때 [채팅 창](/ko/ai/chat), 선택한 텍스트에 동작하려면 [PopBar](/ko/features/popbar), 화면에 남는 작은 진입점에는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 쓰세요. [창 관리](/ko/features/window-management)가 모두를 비교합니다.

아래 영상은 2.5.13의 앱 사이드바를 보여 줍니다. **⌃⌘E**로 Chrome 옆에 열고, 사이트에서 동작 방식을 설정하고, 동영상의 핵심 순간을 나열해 그곳으로 이동한 다음, Finder에서 선택한 사진을 압축합니다.

## 사이드바 열기

1. 도움을 받을 앱을 앞으로 가져옵니다.
2. **⌃⌘E**를 누르거나, Enconvo에서 **앱 사이드바 표시**를 실행하거나, 앱 창 옆 핸들을 클릭합니다.
3. 구체적인 질문을 하고, 보내기 전에 첨부된 컨텍스트를 확인합니다.

핸들은 포인터를 앱 창 오른쪽 가장자리 가까이 가져가기 전까지 숨겨져 있으며, 포인터가 도착하거나 떠나면 바로 나타나고 사라집니다. 핸들을 가리키면 보고 있는 페이지에 대한 카드가 나옵니다. 동영상 길이와 자막 같은 것입니다. 핸들을 항상 보이게 하려면 **설정 → 앱 사이드바** 또는 핸들의 오른쪽 클릭 메뉴에서 **창 가장자리에서만 핸들 표시**를 끄세요. Finder 데스크탑에서는 Finder 창이 열려 있든 없든 핸들이 나타납니다.

에이전트 모드에서는 **권한** 칩이 에이전트가 행동하기 전에 언제 묻는지 설정하고, **Sandbox** 스위치가 에이전트 명령을 작업 폴더 안에 가둡니다. [에이전트 Sandbox](/ko/configuration/sandbox)를 보세요.

단축키는 **설정 → 앱 사이드바**에서 설정합니다. 이전 버전은 **⇧⌘T**를 썼습니다. 한 번도 바꾸지 않았다면 Enconvo가 **⌃⌘E**로 옮겼습니다. 바꾸려면 [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 보세요.

## 사이드바가 볼 수 있는 것

사이드바가 받는 내용은 앱과 부여한 권한에 따라 달라집니다.

- 브라우저는 페이지 제목, URL, 내용을 제공할 수 있습니다.
- Finder는 선택한 파일을 제공할 수 있습니다.
- 다른 앱은 선택한 텍스트, 접근 가능한 창 내용, 스크린샷을 제공할 수 있습니다.

코드 편집기가 반드시 전체 프로젝트나 열린 모든 파일을 노출하지는 않습니다. 컨텍스트가 불완전하면 [Appshots](/ko/features/appshots)를 추가하거나 파일을 직접 첨부하세요.

“선택한 문단을 설명해 줘”, “이 초안을 더 간결하게 고쳐 줘”, “이 창에 보이는 것을 설명해 줘”처럼 물어 보세요.

### 페이지 카드와 시작 문구

웹 페이지에서는 새 사이드바 채팅이 그 페이지의 카드로 열립니다. 동영상 카드에는 길이, 자막 여부, 챕터 수가 나옵니다. 카드 아래에는 사이트용 시작 문구가 있습니다. YouTube에서는 **이 동영상 요약**, **타임스탬프와 함께 핵심 순간 나열**, **대화 내용 보기**입니다. 하나를 클릭하면 전송됩니다.

동영상에 대한 답변에서 각 시각은 텍스트와 타임라인 모두에서 링크입니다. 클릭하면 동영상이 그 순간으로 이동합니다. 카드의 동영상 챕터도 링크입니다.

카드에는 기사의 길이나 PDF 페이지 수처럼 다른 페이지에서 읽을 수 있는 것도 나오며, 사이드바는 첫 답이 더 빨리 시작되도록 페이지를 미리 읽습니다. 탭을 있는 그대로 읽습니다. 페이지를 다시 로드하거나 바꾸거나, 두 번째 탭을 열거나, 브라우저 디버깅 막대를 보여 주지 않습니다.

자막이 없는 YouTube 동영상은 **오디오 텍스트 변환**을 고르세요. Enconvo가 동영상 오디오를 텍스트로 바꾸고 타임스탬프와 함께 요약합니다.

채팅 중에 다른 페이지로 이동하면 **지금 보는 페이지** 행이 나타납니다. 클릭하면 새 페이지에 대해 물을 수 있습니다.

자체 시작 문구가 있는 기본 프로필은 YouTube, Bilibili, GitHub, Reddit, Hacker News, X, Amazon, Gmail, Outlook, Stack Overflow를 다룹니다. 답은 페이지가 제공하는 내용에 붙습니다.

### 확장 없는 Chromium 브라우저

[Enconvo Companion 확장](/ko/features/browser-control)이 없는 Chrome, Edge, Brave, Arc, 다른 Chromium 브라우저 옆에서는 사이드바에 **설치** 버튼이 있는 카드가 나옵니다. 확장이 연결되면 카드가 페이지 카드로 바뀝니다.

### 사이트 설정

카드의 알약은 사이트와 설정의 출처를 이름 붙입니다. **YouTube · 기본 제공** 같은 것입니다. 알약을 클릭하면 그 사이트에서 사이드바가 동작하는 방식을 바꿉니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **페이지 읽기** | 질문에 필요할 때 사이드바가 전체 페이지를 읽게 합니다. |
| **답변 언어** | **내 언어** 또는 **페이지 언어**. |
| **요약** | **기본**, **시간이 있는 챕터**, **짧은 문단**, **글머리 기호**. |
| **지침** | 이 사이트의 답에 대한 자신의 지침. |
| **시작 문구** | 카드 아래에 보이는 시작 문구. 하나를 제거하거나 **시작 문구 추가**에 새로 입력합니다. |

무언가를 바꾸면 알약이 **내 설정**으로 바뀝니다.

### Finder의 파일

Finder에서 파일을 선택한 다음 **⌃⌘E**를 누릅니다. 시작 문구는 선택한 것을 따릅니다. 이미지라면 **선택한 이미지 압축**, **선택한 이미지를 JPEG로 변환**, **선택한 이미지 크기 조정**입니다.

사이드바는 이미지를 압축, 변환, 크기 조정하고, PDF를 압축하고, 동영상과 오디오를 변환하고, 압축하고 풀고, 선택한 파일의 이름을 일괄 바꿀 수 있습니다. 각 작업은 원본 옆에 새 사본을 씁니다. 이름에 `-compressed`가 있는 사본 같은 것이며, 원본은 그대로 둡니다. 결과는 전후 크기와 **Finder에서 보기**가 있는 카드로 나옵니다. 같은 설정으로 이미 끝난 파일은 다시 하지 않고 **이미 완료**로 표시됩니다. 지원하지 않는 형식은 분명한 메시지를 받습니다.

### 앱에 삽입

Finder, WeCom과 Teams 같은 채팅 앱, SourceTree 같은 git 클라이언트, Windsurf 같은 코드 편집기, 터미널, 메모 앱, Pages, Word에는 자체 시작 문구가 있는 기본 프로필이 있습니다.

이 앱들에서 답변에 **삽입** 버튼이 있을 수 있습니다. 클릭하면 답, 커밋 메시지, 명령을 앱의 텍스트 필드에 넣습니다. 삽입은 보내거나 실행하지 않습니다. 확인한 뒤 Return을 직접 누릅니다. 사이드바가 삽입할 필드를 찾지 못하면 알려 줍니다.

### 앱별, 사이트별 프리셋

**설정 → 애플리케이션**에는 사이드바가 동작하는 각 앱의 프로필이 있습니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **스크린샷 첨부** | 앱 창의 스크린샷을 모든 앱 사이드바 메시지에 첨부합니다. 기본은 켜짐. |
| **전체 앱 상태 첨부** | 짧은 요약 대신 전체 손쉬운 사용 상태를 첨부합니다. 토큰을 훨씬 더 씁니다. |
| **스킬**, **MCP 서버**, **플러그인** | 이 앱의 프리셋이며, 앱이 앱 사이드바 대화를 호스트할 때 에이전트에 제공됩니다. |

**설정 → 웹사이트**에는 웹사이트의 같은 프리셋이 있으며, 브라우저가 일치하는 페이지에 있을 때 쓰입니다.

## 앱에서 대화하고 행동하기

대화를 이어 가거나, 새로 시작하거나, 창 제어로 사이드바를 가까이 두세요. 앱 컨텍스트는 에이전트가 읽을 정보를 줍니다. 앱에서 대신 클릭하거나 입력하려면 에이전트에 [컴퓨터 사용](/ko/features/computer-use) 또는 [브라우저 사용](/ko/features/browser-control) 도구가 필요합니다.

## 설정

**설정 → 앱 사이드바**를 엽니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **앱 사이드바 사용** | 앱 창 옆에 핸들을 표시하고 단축키를 켭니다. 끄면 둘 다 사라집니다. |
| **기본 에이전트** | 사이드바에서 답하는 에이전트. |
| **모든 앱에서 숨기기** | 모든 앱에서 사이드바 핸들을 숨깁니다. |
| **창 가장자리에서만 핸들 표시** | 포인터를 창 오른쪽 가장자리로 가져가기 전까지 핸들을 숨깁니다. 기본은 켜짐. |
| **아래 애플리케이션이 앞에 있을 때 앱 사이드바 핸들 숨기기** | 핸들이 숨겨지는 앱. |
| **단축키** | 앞에 있는 앱의 사이드바를 엽니다. 기본은 **⌃⌘E**. |

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 사이드바가 앱에 붙지 않음 | 앱 창을 앞으로 가져오고 사이드바를 다시 엽니다. |
| 핸들을 찾을 수 없음 | 포인터를 창 오른쪽 가장자리로 옮기거나 **창 가장자리에서만 핸들 표시**를 끕니다. |
| Chromium 브라우저에서 페이지 카드가 없음 | 카드의 **설치** 버튼으로 Enconvo Companion 확장을 설치합니다. |
| **삽입**이 제공되지 않음 | 사이드바가 식별할 수 있는 텍스트 필드가 앱에 없습니다. 답을 대신 복사하세요. |
| 앱의 텍스트가 없음 | [권한](/ko/configuration/permissions)의 손쉬운 사용, 핸들을 숨기는 앱, 첨부된 컨텍스트를 확인하세요. |
| 기록이나 파일에 더 많은 공간이 필요함 | [채팅 창](/ko/ai/chat)에서 이어 가세요. |

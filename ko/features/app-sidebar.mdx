앱 사이드바는 앱 창 옆에 Enconvo 대화를 엽니다. 그 앱의 컨텍스트를 사용하므로 정보를 별도의 채팅에 복사하지 않고도 읽고, 쓰고, 작업할 수 있습니다. 지금 보고 있는 앱에 대한 질문이 있을 때 사용하세요.

다른 용도에는 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 기록과 파일을 위한 더 넓은 공간이 필요할 때는 [채팅 창](/ko/ai/chat), 선택한 텍스트에는 [PopBar](/ko/features/popbar), 화면에 계속 떠 있는 작은 진입점으로는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

아래 영상은 2.5.13의 앱 사이드바를 보여 줍니다. **⌃⌘E**로 Chrome 옆에 열고, 사이트에서 동작하는 방식을 설정하고, 동영상의 주요 장면을 나열해 하나로 이동하고, Finder에서 선택한 사진을 압축합니다.

## 사이드바 열기

1. 도움을 받고 싶은 앱을 맨 앞으로 가져오세요.
2. **⌃⌘E**를 누르거나, Enconvo에서 **앱 사이드바 표시**를 실행하거나, 앱 창 옆의 핸들을 클릭하세요.
3. 구체적인 질문을 하고, 보내기 전에 첨부된 컨텍스트를 확인하세요.

핸들은 앱 창의 오른쪽 가장자리 근처로 포인터를 옮기기 전까지 숨겨져 있으며, 포인터가 도착하거나 떠나는 즉시 나타나고 사라집니다. 핸들에 포인터를 올리면 동영상의 길이와 자막처럼 현재 페이지에 대한 카드가 표시됩니다. 핸들을 항상 보이게 하려면 **설정 → 앱 사이드바**나 핸들의 오른쪽 클릭 메뉴에서 **창 가장자리에서만 핸들 표시**를 끄세요. Finder 데스크톱에서는 Finder 창이 열려 있든 없든 핸들이 나타납니다.

에이전트 모드에서는 **권한** 칩이 에이전트가 실행 전에 묻는 시점을 정하고, **샌드박스** 스위치는 에이전트의 명령을 작업 폴더 안으로 제한합니다. [에이전트 샌드박스](/ko/configuration/sandbox)를 참고하세요.

단축키는 **설정 → 앱 사이드바**에서 설정합니다. 이전 버전은 **⇧⌘T**를 사용했으며, 바꾼 적이 없다면 Enconvo가 **⌃⌘E**로 옮겼습니다. 바꾸려면 [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 참고하세요.

## 사이드바가 볼 수 있는 것

사이드바가 가져오는 내용은 앱과 허용한 권한에 따라 다릅니다.

- 브라우저는 페이지 제목, URL, 콘텐츠를 제공할 수 있습니다.
- Finder는 선택한 파일을 제공할 수 있습니다.
- 다른 앱은 선택한 텍스트, 접근 가능한 창 콘텐츠, 스크린샷을 제공할 수 있습니다.

코드 편집기가 프로젝트 전체나 열려 있는 모든 파일을 공개하지는 않을 수 있습니다. 컨텍스트가 불완전하면 [Appshots](/ko/features/appshots)를 추가하거나 파일을 직접 첨부하세요.

“선택한 문단을 설명해 줘”, “이 초안을 더 간결하게 다시 쓰도록 도와줘”, “이 창에 보이는 내용을 설명해 줘”처럼 물어보세요.

### 페이지 카드와 시작 제안

웹 페이지에서는 새 사이드바 채팅이 그 페이지의 카드로 열립니다. 동영상의 카드에는 길이, 자막 유무, 챕터 수가 표시됩니다. 카드 아래에는 사이트에 맞춘 시작 제안이 있습니다. YouTube에서는 **이 동영상을 요약해 주세요**, **주요 장면을 타임스탬프와 함께 나열해 주세요**, **스크립트를 보여 주세요**입니다. 하나를 클릭하면 전송됩니다.

동영상에 대한 답변에서는 텍스트와 타임라인 모두에서 각 시간이 링크입니다. 클릭하면 동영상이 그 시점으로 이동합니다. 카드에 있는 동영상의 챕터도 링크입니다.

카드에는 기사의 분량이나 PDF의 페이지 수처럼 다른 페이지에서 읽을 수 있는 내용도 표시되며, 사이드바가 페이지를 미리 읽어 두므로 첫 답변이 더 빨리 시작됩니다. 탭을 있는 그대로 읽습니다. 페이지를 새로 고치거나 바꾸지 않고, 두 번째 탭을 열지 않으며, 브라우저의 디버깅 막대도 표시하지 않습니다.

자막이 없는 YouTube 동영상은 **오디오 받아쓰기**를 선택하세요. Enconvo가 동영상의 오디오를 받아 적고 타임스탬프와 함께 요약합니다.

채팅 도중 다른 페이지로 이동하면 **현재 페이지** 행이 나타납니다. 클릭해서 새 페이지에 대해 질문하세요.

시작 제안이 있는 기본 프로필은 YouTube, Bilibili, GitHub, Reddit, Hacker News, X, Amazon, Gmail, Outlook, Stack Overflow를 지원합니다. 그 답변은 페이지가 제공하는 콘텐츠에 충실합니다.

### 확장 프로그램이 없는 Chromium 브라우저

[Enconvo Companion 확장 프로그램](/ko/features/browser-control)이 없는 Chrome, Edge, Brave, Arc 또는 다른 Chromium 브라우저 옆에서는 사이드바에 **설치** 버튼이 있는 카드가 표시됩니다. 확장 프로그램이 연결되면 카드가 페이지 카드로 바뀝니다.

### 사이트별 설정

카드의 알약은 사이트와 설정의 출처를 표시합니다(예: **YouTube · 기본 제공**). 알약을 클릭하면 그 사이트에서 사이드바가 동작하는 방식을 바꿀 수 있습니다.

| 설정 | 바뀌는 내용 |
| --- | --- |
| **페이지 읽기** | 질문에 필요할 때 사이드바가 페이지 전체를 읽도록 허용합니다. |
| **답변 언어** | **내 언어** 또는 **페이지 언어**입니다. |
| **요약** | **기본값**, **시간이 표시된 챕터**, **짧은 단락**, **글머리 기호** 중에서 고르세요. |
| **지침** | 이 사이트의 답변에 적용할 내 지침입니다. |
| **시작 제안** | 카드 아래에 표시되는 시작 제안입니다. 하나를 제거하거나 **시작 제안 추가**에 새로 입력하세요. |

무언가를 바꾸면 알약에 **내 명령**이 표시됩니다.

### Finder의 파일

Finder에서 파일을 선택한 다음 **⌃⌘E**를 누르세요. 시작 제안은 선택한 항목에 맞춰집니다. 이미지에서는 **선택한 이미지 압축하기**, **선택한 이미지를 JPEG로 변환하기**, **선택한 이미지 크기 조절하기**입니다.

사이드바는 선택한 파일의 이미지 압축, 변환, 크기 조절, PDF 압축, 비디오와 오디오 변환, 압축과 압축 해제, 일괄 이름 변경을 할 수 있습니다. 각 작업은 원본 옆에 이름에 `-compressed`가 붙은 사본 같은 새 사본을 만들고 원본은 그대로 둡니다. 결과는 전후 크기와 **Finder에서 보기**가 있는 카드로 표시됩니다. 같은 설정으로 이미 처리된 파일은 다시 처리하지 않고 유지되며 **이미 완료**로 표시됩니다. 지원하지 않는 형식에는 명확한 메시지가 표시됩니다.

### 앱에 삽입하기

Finder, WeCom과 Teams 같은 채팅 앱, SourceTree 같은 git 클라이언트, Windsurf 같은 코드 편집기, 터미널, 메모 앱, Pages, Word에는 자체 시작 제안이 있는 기본 프로필이 있습니다.

이런 앱에서는 답변에 **삽입** 버튼이 있을 수 있습니다. 클릭하면 답장, 커밋 메시지, 명령을 앱의 텍스트 필드에 넣습니다. 삽입은 전송하거나 실행하지 않습니다. 확인한 다음 직접 Return을 누르세요. 사이드바가 삽입할 필드를 찾지 못하면 알려 줍니다.

### 앱별, 사이트별 프리셋

**설정 → 앱**에는 사이드바가 작동하는 각 앱의 프로필이 있습니다.

| 설정 | 바뀌는 내용 |
| --- | --- |
| **스크린샷 첨부** | 모든 앱 사이드바 메시지에 앱 창의 스크린샷을 첨부합니다. 기본으로 켜져 있습니다. |
| **전체 앱 상태 첨부** | 간략한 요약 대신 전체 손쉬운 사용 상태를 첨부합니다. 토큰을 훨씬 많이 사용합니다. |
| **스킬**, **MCP 서버**, **플러그인** | 이 앱의 프리셋이며, 앱이 앱 사이드바 대화를 호스팅할 때 에이전트에게 제공됩니다. |

**설정 → 웹사이트**에는 웹사이트용 같은 프리셋이 있으며, 브라우저가 일치하는 페이지에 있을 때 사용됩니다.

## 앱에서 채팅하고 작업하기

대화를 이어가거나, 새로 시작하거나, 창 컨트롤로 사이드바를 가까이 두세요. 앱 컨텍스트는 에이전트에게 읽을 정보를 제공합니다. 에이전트가 앱에서 대신 클릭하거나 입력하려면 [컴퓨터 사용](/ko/features/computer-use)이나 [브라우저 사용](/ko/features/browser-control) 도구가 필요합니다.

## 설정

**설정 → 앱 사이드바**를 여세요.

| 설정 | 바뀌는 내용 |
| --- | --- |
| **앱 사이드바 활성화** | 앱 창 옆에 핸들을 표시하고 단축키를 켭니다. 끄면 둘 다 사라집니다. |
| **기본 에이전트** | 사이드바에서 답하는 에이전트입니다. |
| **모든 앱에서 숨기기** | 모든 앱에서 사이드바의 핸들을 숨깁니다. |
| **창 가장자리에서만 핸들 표시** | 포인터를 창의 오른쪽 가장자리로 옮길 때까지 핸들을 숨깁니다. 기본으로 켜져 있습니다. |
| **아래 앱이 맨 앞에 있을 때 앱 사이드바 핸들 숨기기** | 핸들이 계속 숨겨져 있는 앱입니다. |
| **단축키** | 맨 앞 앱에 대한 사이드바를 엽니다. 기본값은 **⌃⌘E**입니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 사이드바가 앱에 연결되지 않습니다 | 앱 창을 맨 앞으로 가져오고 사이드바를 다시 여세요. |
| 핸들을 찾을 수 없습니다 | 창의 오른쪽 가장자리로 포인터를 옮기거나 **창 가장자리에서만 핸들 표시**를 끄세요. |
| Chromium 브라우저에서 페이지 카드가 없습니다 | 카드의 **설치** 버튼으로 Enconvo Companion 확장 프로그램을 설치하세요. |
| **삽입**이 제공되지 않습니다 | 사이드바가 식별할 수 있는 텍스트 필드가 앱에 없습니다. 대신 답변을 복사하세요. |
| 앱의 텍스트가 없습니다 | [권한](/ko/configuration/permissions)의 손쉬운 사용, 핸들을 숨기는 앱, 첨부된 컨텍스트를 확인하세요. |
| 기록이나 파일을 위한 공간이 더 필요합니다 | [채팅 창](/ko/ai/chat)에서 이어가세요. |

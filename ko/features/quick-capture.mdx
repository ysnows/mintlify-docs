빠른 캡처는 현재 앱의 콘텐츠를 나중을 위해 지식 베이스에 저장합니다. 각 캡처에는 창의 스크린샷과 텍스트가 담기며, 브라우저는 페이지 내용을, YouTube 동영상은 자막을 담습니다. [Appshots](/ko/features/appshots)는 지금 하는 질문에 앱 창을 첨부하고, 빠른 캡처는 계속 보관하는 지식 베이스 항목을 만듭니다.

## 보관할 만한 내용 캡처하기

1. 콘텐츠가 있는 앱을 맨 앞으로 가져옵니다.
2. 빠른 캡처 단축키를 누르거나, [Dynamic Island](/ko/features/dynamic-island)를 열고 **빠른 캡처**를 클릭합니다. 빠른 캡처는 **설정 → 빠른 캡처**의 **단축키**에서 설정하기 전까지는 단축키가 없습니다.
3. 단축키를 누르는 순간 Enconvo가 화면을 캡처하고 알약을 표시한 다음, **저장 위치**에 설정된 지식 베이스(다른 곳을 고르지 않았다면 기본 지식 베이스)에 캡처를 저장합니다. 짧은 셔터 소리가 재생됩니다.
4. 알림에 무엇이 어디에 저장되었는지 표시됩니다. **열기**를 클릭하면 지식 베이스에서 확인하고, **실행 취소**를 클릭하면 캡처를 취소합니다.

저장에 실패하면 알림에 **재시도**와 **닫기**가 표시됩니다. [음성 메모](/ko/features/voice-notes)에도 같은 **실행 취소**, **재시도**, **닫기**가 있습니다.

인덱싱과 요약은 항목이 나타난 뒤 조금 더 있다가 끝날 수 있습니다.

## 설정

**설정 → 빠른 캡처**를 엽니다.

| 설정 | 하는 일 |
| --- | --- |
| **빠른 캡처 활성화** | 단축키로 현재 앱을 저장할 수 있게 합니다. [음성 메모](/ko/features/voice-notes) 단축키도 함께 켜고 끕니다. 기본으로 켜져 있습니다. |
| **저장 위치** | 캡처가 저장되는 지식 베이스입니다. 캡처는 메모리에 저장할 수 없습니다. |
| **소리 녹음** | 캡처가 저장될 때 짧은 셔터 소리를 재생합니다. |
| **자동 요약** | AI로 각 캡처를 요약합니다. 요약은 항목의 미리보기에 표시되며 검색할 수 있습니다. |
| **단축키** | 현재 앱을 저장하는 단축키입니다. 기본값은 없습니다. 오른쪽 **Shift** 키 같은 보조 키를 두 번 누르는 방식이나 일반 단축키를 사용할 수 있습니다. |

**자동 요약**은 캡처한 텍스트를 내 AI 모델로 보냅니다. 캡처한 콘텐츠가 어디에서 처리되는지 제어하려면 모델과 제공업체 설정을 검토하세요.

### X 게시물

같은 페이지의 **X** 섹션은 Enconvo [브라우저 확장 프로그램](/ko/features/browser-extension)이 x.com에서 작동하는 방식을 설정합니다.

| 설정 | 하는 일 |
| --- | --- |
| **카드 스타일** | 저장된 게시물을 **게시** 또는 **스크린샷**으로 표시합니다. 전환하면 이전에 저장한 게시물도 바뀝니다. |
| **X에서 북마크할 때** | X 자체 북마크 버튼의 동작입니다. **X에서 북마크**, **북마크하고 Enconvo에 저장**, **Enconvo에만 저장** 중에서 고릅니다. 선택하기 전에는 처음 북마크할 때 Enconvo가 묻습니다. 북마크를 삭제해도 게시물은 Enconvo에 남습니다. |
| **‘Enconvo에 묻기’ 버튼** | 각 게시물 머리글의 Grok 옆에 Enconvo 버튼을 표시해 게시물과 댓글에 대해 질문할 수 있게 합니다. |
| **X 게시물 자동 요약** | AI로 저장된 각 게시물과 스레드를 요약합니다. |
| **저장한 게시물 자동 분류** | 저장된 각 게시물에 해당 주제 태그를 붙입니다. 로그인이 필요합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 콘텐츠가 없거나 불완전함 | [권한](/ko/configuration/permissions)을 확인하고, 의도한 앱을 맨 앞으로 가져온 다음, 작고 뚜렷하게 보이는 예시로 시험해 보세요. |
| 캡처를 찾을 수 없음 | **저장 위치**를 확인한 다음 해당 지식 베이스를 여세요. 인덱싱과 요약은 항목이 처음 나타난 뒤에 끝날 수 있습니다. |
| 단축키가 아무 반응이 없음 | **빠른 캡처 활성화**가 켜져 있고 **단축키**가 설정되어 있는지 확인하세요. |

빠른 캡처는 현재 앱의 콘텐츠를 나중에 활용할 수 있도록 지식 베이스에 저장합니다. 캡처할 때마다 창 스크린샷과 텍스트가 함께 보관되며, 브라우저에서는 페이지 내용이, YouTube 동영상에서는 자막이 저장됩니다. [Appshots](/ko/features/appshots)가 지금 묻는 질문에 앱 창을 첨부하는 기능이라면, 빠른 캡처는 계속 보관할 지식 베이스 항목을 만듭니다.

## 간직할 내용 캡처하기

1. 보관할 콘텐츠가 있는 앱을 맨 앞으로 가져옵니다.
2. 빠른 캡처 단축키를 누르거나, [Dynamic Island](/ko/features/dynamic-island)를 열어 **빠른 캡처**를 클릭합니다. **설정 → 빠른 캡처**의 **단축키**에서 설정하기 전까지는 기본 단축키가 없습니다.
3. 단축키를 누르는 즉시 Enconvo가 화면을 찍고 알약(pill) UI를 표시한 뒤, **저장 위치**에 지정된 지식 베이스(따로 고르지 않았다면 기본 지식 베이스)에 캡처를 저장합니다. 이때 짧은 셔터 소리가 납니다.
4. 알림에 무엇이 어디에 저장되었는지 표시됩니다. 지식 베이스에서 보려면 **열기**를, 캡처를 취소하려면 **실행 취소**를 클릭하세요.

저장에 실패하면 알림에 **재시도**와 **닫기**가 표시됩니다. [음성 메모](/ko/features/voice-notes)에도 동일한 **실행 취소**, **재시도**, **닫기**가 제공됩니다.

인덱싱과 요약은 항목이 나타난 직후에 뒤이어 완료될 수 있습니다.

## 설정

**설정 → 빠른 캡처**를 엽니다.

| 설정 | 기능 |
| --- | --- |
| **빠른 캡처 활성화** | 단축키로 현재 앱을 저장할 수 있게 합니다. [음성 메모](/ko/features/voice-notes) 단축키의 활성화 여부도 함께 제어합니다. 기본값은 켜짐입니다. |
| **저장 위치** | 캡처가 저장되는 지식 베이스입니다. 캡처는 메모리로 보낼 수 없습니다. |
| **소리 녹음** | 캡처가 저장될 때 짧은 셔터 소리를 재생합니다. |
| **자동 요약** | 각 캡처를 AI로 요약합니다. 요약은 항목 미리보기에 표시되며 검색할 수 있습니다. |
| **단축키** | 현재 앱을 저장하는 단축키입니다. 기본값은 없음입니다. 오른쪽 **Shift** 키를 두 번 누르는 것처럼 보조 키 더블 탭이나 일반 단축키를 지정할 수 있습니다. |

**자동 요약**은 캡처된 텍스트를 AI 모델로 전송합니다. 캡처된 콘텐츠가 처리되는 위치를 제어하려면 모델 및 제공업체 설정을 확인하세요.

### X 게시물

같은 페이지의 **X** 섹션에서는 x.com에서 Enconvo [브라우저 확장 프로그램](/ko/features/browser-extension)이 동작하는 방식을 설정합니다.

| 설정 | 기능 |
| --- | --- |
| **카드 스타일** | 저장한 게시물을 **게시물** 또는 **스크린샷** 형태로 보여 줍니다. 전환하면 이전에 저장한 게시물도 함께 바뀝니다. |
| **X에서 북마크할 때** | X 자체 북마크 버튼을 눌렀을 때의 동작입니다: **X에서 북마크**, **북마크하고 Enconvo에 저장**, 또는 **Enconvo에만 저장**. 선택하기 전까지는 첫 북마크 시 Enconvo가 물어봅니다. 북마크를 해제해도 Enconvo에 저장된 게시물은 유지됩니다. |
| **‘Enconvo에 묻기’ 버튼** | 각 게시물 상단에서 Grok 옆에 Enconvo 버튼을 표시해 게시물과 답글에 대해 질문할 수 있게 합니다. |
| **X 게시물 자동 요약** | 저장한 게시물과 스레드를 AI로 요약합니다. |
| **저장한 게시물 자동 분류** | 저장한 각 게시물에 관련 주제 태그를 자동으로 붙입니다. 로그인이 필요합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 콘텐츠가 누락되거나 불완전함 | [권한](/ko/configuration/permissions)을 확인하고, 대상 앱을 맨 앞으로 가져온 뒤, 작고 선명하게 보이는 예제로 시도해 보세요. |
| 캡처한 항목을 찾을 수 없음 | **저장 위치**를 확인한 뒤 해당 지식 베이스를 여세요. 인덱싱과 요약은 항목이 처음 나타난 뒤에 완료될 수 있습니다. |
| 단축키를 눌러도 아무 일도 일어나지 않음 | **빠른 캡처 활성화**가 켜져 있고 **단축키**가 설정되어 있는지 확인하세요. |

---
title: "회의 녹음"
description: "회의나 강의를 녹음한 다음 대화 기록, 요약, 후속 조치를 검토합니다."
---

녹음은 마이크, 통화 오디오, 또는 둘 다에서 회의나 강의를 캡처하고, 사람들이 말하는 동안 대화 기록을 씁니다. 이후 요약을 읽고, 화자를 이름 붙이고, 말한 내용에 대해 질문할 수 있습니다. 녹음 모델은 받아쓰기와 파일 음성 텍스트 변환 모델과 따로 설정합니다.

## 시작하기 전에

- **설정 → 녹음 모델**에서 음성 텍스트 변환 모델을 고릅니다.
- macOS는 처음 녹음할 때 마이크와 시스템 오디오 접근을 묻습니다. 쓰는 소스에 둘 다 허용하세요.

<Note>
참가자가 녹음을 알고 있는지 확인하고, 회의에 적용되는 요구 사항을 따르세요.
</Note>

## 회의 녹음

<Steps>
  <Step title="새 녹음 열기">
    **설정 → 녹음**을 열고 **새 녹음**을 클릭하거나, **녹음 시작 (회의/강의)**를 실행합니다.
  </Step>
  <Step title="오디오 소스 고르기">
    **마이크**를 고른 다음 녹음할 **통화 오디오**를 고릅니다. **끔**은 마이크만, **모든 앱**은 Mac이 재생하는 모든 것, **한 앱**은 회의 앱의 소리만 녹음합니다. 고르려면 먼저 회의 앱을 엽니다. **음성 텍스트 변환** 모델을 확인하고, 모델이 제공하면 **실시간 번역**을 켭니다.
  </Step>
  <Step title="녹음 시작">
    **녹음 시작**을 클릭하고, 실시간 대화 기록에 단어가 나타나는지 확인합니다.
  </Step>
  <Step title="중지">
    끝나면 **중지**를 클릭한 다음 **녹음** 아래 저장된 항목을 엽니다.
  </Step>
</Steps>

녹음하는 동안 일시 중지하고 다시 시작하고, 메모를 추가하고, **⌘B**로 순간에 북마크를 남길 수 있습니다. 녹음은 진행하면서 저장되므로 Enconvo가 종료되어도 잃지 않습니다.

나중에 소스를 바꾸려면 **새 녹음** 옆 화살표를 클릭하고 **오디오 소스 선택…**을 고릅니다. 같은 메뉴의 **회의 알림**은 Zoom, Teams, FaceTime, WeChat 통화가 시작될 때 Dynamic Island에서 녹음할지 묻습니다.

## 결과 검토

녹음을 열면 **대화 기록** 옆에 **요약**, **할 일**, **메모** 탭과 **AI에게 묻기**가 있는 옆 패널이 있습니다.

- **대화 기록**: 특히 목소리가 겹치는 곳에서 누가 말했는지 확인합니다. 화자 레이블을 클릭해 그 화자의 이름을 붙입니다. 그러면 Enconvo가 새 녹음에서 그 목소리를 알아봅니다. 반복되는 용어는 [사전](/ko/configuration/speech-assets)을 쓰세요.
- **요약**: **회의 요약**은 개요, 핵심, 결정, 숫자, 시각을 누르면 녹음의 그 순간으로 가는 타임라인을 줍니다. 화자가 둘 이상이면 **발화 시간**이 각 화자의 대화 비중을 보여 줍니다.
- **할 일**: 녹음에서 찾은 작업. 하면서 체크합니다.
- **메모**: 녹음하면서 추가한 메모와 북마크. **번역 표시**를 켜면 각 메모 아래에 녹음의 출력 언어로 번역이 추가됩니다. 메모는 쓴 그대로 남습니다.
- **AI에게 묻기**: 녹음에 대해 묻습니다. 후속 조치를 물을 때는 회의가 말한 곳에만 담당자와 기한을 요청하세요.

긴 요약을 위해 옆 패널의 왼쪽 가장자리를 끌어 넓히고, 가장자리를 두 번 클릭하면 기본 너비로 돌아갑니다. 너비는 모든 녹음에 유지됩니다. 모든 탭에서 텍스트를 선택하고 복사할 수 있습니다.

## 요약 언어와 템플릿 고르기

녹음 옆 패널 위에서 요약, 할 일, 템플릿 결과가 쓰이는 **출력 언어**와 템플릿을 고릅니다. 대화 기록과 자신의 메모는 원래 언어로 남습니다.

**회의 요약** 외에 기본 템플릿은 **강의 노트**와 **인터뷰 하이라이트**입니다. 녹음을 템플릿 사이에서 원하는 만큼 바꿀 수 있으며, 각 템플릿의 결과는 유지됩니다.

자신의 템플릿을 쓰려면:

<Steps>
  <Step title="템플릿 시작">
    옆 패널 위의 템플릿 메뉴를 열고 **새 템플릿…**을 고릅니다.
  </Step>
  <Step title="뽑아낼 내용 말하기">
    **이름**을 주고, 녹음에서 무엇을 뽑아낼지 평범한 말로 설명합니다. **레이아웃**을 고릅니다. **스마트 레이아웃**은 카드, 표, 체크리스트, 플래시카드, 퀴즈, 차트를 쓸 수 있고, **일반 텍스트**는 다른 곳에 복사하기 쉬운 Markdown을 씁니다.
  </Step>
  <Step title="시험">
    **이 녹음에서 시험**을 클릭해 무엇을 주는지 봅니다. 녹음의 내용은 바뀌지 않습니다.
  </Step>
  <Step title="저장">
    찾은 작업이 **할 일** 탭에 보여야 하면 **작업을 할 일로 보내기**를 켠 다음 **템플릿 저장**을 클릭합니다.
  </Step>
</Steps>

모든 새 녹음이 쓸 출력 언어와 템플릿을 설정하고, 템플릿을 편집하거나 삭제하려면 **녹음** 페이지의 **새 녹음** 옆 **요약 설정**을 클릭합니다.

## 통화 검토

Mac에서 녹음한 각 Enconvo [회의](/ko/features/video-conference) 통화는 같은 방을 쓰더라도 **녹음**에 자체 항목을 갖습니다. 메모가 켜진 통화는 대화 기록, 참석자, 동영상, 메모 문서를 보여 줍니다.

통화 페이지는 **회의** 개요로 열립니다.

- **요약**과 **할 일**. 각 항목을 누가 맡았는지, 기한이 언제인지. 항목의 **미리 알림에 추가**를 클릭하면 담당자와 기한과 함께 Apple 미리 알림에 넣습니다.
- **이 통화에서 만든 것**: 통화 중 에이전트가 만든 문서와 화이트보드.
- **화면**: 에이전트가 공유 화면에서 본 것.
- **이 회의에 묻기**: 통화에 대해 질문합니다.

에이전트는 채팅에서 이전 통화에 대한 질문에도 답할 수 있으며, 각 답이 어느 회의에서 왔는지 말합니다.

에이전트가 걸거나 받은 통화도 여기로 올 수 있습니다. **설정 → 에이전트 전화**에서 **통화 녹음**을 켜면 각 에이전트 통화가 대화 기록과 함께 **녹음**에 저장됩니다. [에이전트 전화](/ko/features/agent-phone)를 보세요.

## 단계가 실패할 때

음성 텍스트 변환, 제목 생성, 검색 색인은 별도 단계입니다. 나중 단계의 오류가 오디오나 대화 기록을 잃었다는 뜻은 아닙니다. 긴 녹음은 몇 분이 걸리며, 페이지를 떠나도 처리는 계속됩니다. Enconvo Cloud Fast에서는 최대 300분 녹음이 전체 파일에서 텍스트로 바뀝니다.

네트워크가 끊겨 실시간 자막이 멈추면 다시 연결되며, 저장된 대화 기록은 여전히 전체 녹음을 다룹니다.

녹음의 처리 상태를 읽고, 실패한 단계에서 **음성 텍스트 변환 다시 시도** 또는 **색인 다시 시도**를 쓰세요. 문제를 보고할 때 **지원용 세부 정보 복사**는 녹음 없이 지원이 요청하는 참조와 로그 위치를 복사합니다. 보내기 전에 개인 정보가 있는지 확인하세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 오디오가 없음 | 선택한 소스와 macOS 캡처 권한을 확인하세요. |
| 마이크가 사용 중 | 녹음을 시작하기 전에 받아쓰기나 Live Talk을 끝냅니다. |
| **준비된 음성 텍스트 변환 모델이 없음** | **설정 → 녹음 모델**에서 모델을 고릅니다. |
| 처리 단계 실패 | 녹음의 처리 상태에서 그 단계를 다시 시도합니다. |
| 요약이 잘못된 언어 | 옆 패널 위에서 **출력 언어**를 고릅니다. 새 녹음은 **요약 설정**에서 설정합니다. |
| 할 일이 없음 | **회의 요약**을 쓰거나, **작업을 할 일로 보내기**가 켜진 템플릿을 씁니다. |

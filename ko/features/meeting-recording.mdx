---
title: "회의 녹음"
description: "회의나 강의를 녹음하고 전사 내용, 요약, 후속 작업을 검토하세요."
---

녹음은 마이크, 통화 오디오, 또는 둘 다에서 회의나 강의를 캡처하며, 사람들이 말하는 동안 전사 내용을 작성합니다. 이후에는 요약을 읽고, 화자에 이름을 붙이고, 오간 이야기에 대해 질문할 수 있습니다. 녹음 모델은 받아쓰기 및 파일 음성 텍스트 변환 모델과 별도로 설정합니다.

## 시작하기 전에

- **설정 → 녹음 모델**에서 전사 모델을 고르세요.
- macOS는 처음 녹음할 때 마이크와 시스템 오디오 접근 권한을 묻습니다. 사용하는 소스에 대해 둘 다 허용하세요.

<Note>
참가자들이 녹음 사실을 알고 있는지 확인하고, 내 회의에 적용되는 요건을 따르세요.
</Note>

## 회의 녹음하기

<Steps>
  <Step title="새 녹음 열기">
    **설정 → 녹음**을 열고 **새 녹음**을 클릭하거나, **녹음 시작 (회의/강의)**를 실행합니다.
  </Step>
  <Step title="오디오 소스 선택">
    **마이크**를 고른 다음 녹음할 **통화 오디오**를 고릅니다. **끔**은 마이크만 녹음하고, **모든 앱**은 Mac에서 재생되는 모든 소리를 녹음하며, **앱 하나**는 회의 앱의 소리만 녹음합니다. 고르려면 먼저 회의 앱을 여세요. **음성 텍스트 변환** 모델을 확인하고, 모델이 지원하면 **실시간 번역**을 켭니다.
  </Step>
  <Step title="녹음 시작">
    **녹음 시작**을 클릭하고 실시간 전사에 단어가 나타나는지 확인합니다.
  </Step>
  <Step title="중지">
    끝나면 **중지**를 클릭한 다음 **녹음** 아래에서 저장된 항목을 엽니다.
  </Step>
</Steps>

녹음하는 동안 일시 정지하고 재개하고, 메모를 추가하고, **⌘B**를 눌러 순간을 북마크할 수 있습니다. 녹음은 진행되는 대로 저장되므로 Enconvo가 종료되어도 아무것도 사라지지 않습니다.

나중에 소스를 바꾸려면 **새 녹음** 옆의 화살표를 클릭하고 **오디오 소스 선택…**을 고르세요. 같은 메뉴의 **회의 알림**은 Zoom, Teams, FaceTime, WeChat 통화가 시작될 때 Dynamic Island에서 녹음할지 묻습니다.

## 결과 검토하기

녹음을 열면 **전사 내용**이 **요약**, **할 일 목록**, **메모** 탭과 **AI에게 질문**이 있는 측면 패널 옆에 표시됩니다.

- **전사 내용**: 특히 목소리가 겹치는 곳에서 누가 무슨 말을 했는지 확인하세요. 화자 라벨을 클릭해 그 화자에 이름을 붙이면 Enconvo가 새 녹음에서 그 목소리를 인식합니다. 반복되는 용어에는 [사전](/ko/configuration/speech-assets)을 사용하세요.
- **요약**: **회의 요약**은 개요, 핵심 사항, 결정 사항, 수치, 그리고 시간을 누르면 녹음의 해당 순간으로 이동하는 타임라인을 제공합니다. 화자가 두 명 이상이면 **통화 시간**에 각 화자가 대화에서 차지한 비율이 표시됩니다.
- **할 일 목록**: 녹음에서 찾은 작업입니다. 완료하는 대로 체크하세요.
- **메모**: 녹음하는 동안 추가한 메모와 북마크입니다. **번역 표시**를 켜면 각 메모 아래에 녹음의 출력 언어로 번역이 추가되며, 내 메모는 쓴 그대로 유지됩니다.
- **AI에게 질문**: 녹음에 대해 질문합니다. 후속 작업을 요청할 때는 회의에서 명시된 경우에만 담당자와 기한을 요청하세요.

측면 패널의 왼쪽 가장자리를 끌어서 긴 요약을 볼 수 있도록 넓히고, 가장자리를 더블 클릭하면 기본 너비로 돌아갑니다. 너비는 모든 녹음에 유지됩니다. 모든 탭에서 텍스트를 선택하고 복사할 수 있습니다.

## 요약 언어와 템플릿 선택하기

녹음의 측면 패널 상단에서 요약, 할 일 목록, 템플릿 결과가 작성될 **출력 언어**와 템플릿을 고르세요. 전사 내용과 내 메모는 원래 언어로 유지됩니다.

**회의 요약** 외에도 기본 제공 템플릿으로 **강의 노트**와 **인터뷰 하이라이트**가 있습니다. 녹음의 템플릿은 몇 번이든 바꿀 수 있으며, 각 템플릿의 결과가 보관됩니다.

나만의 템플릿을 만들려면 다음과 같이 하세요.

<Steps>
  <Step title="템플릿 시작">
    측면 패널 상단의 템플릿 메뉴를 열고 **새 템플릿…**을 선택합니다.
  </Step>
  <Step title="무엇을 뽑아낼지 설명">
    **이름**을 정하고, 녹음에서 무엇을 뽑아내야 하는지 쉬운 말로 설명합니다. **레이아웃**을 고릅니다. **스마트 레이아웃**은 카드, 표, 체크리스트, 플래시카드, 퀴즈, 차트를 사용할 수 있고, **일반 텍스트**는 다른 곳에 복사하기 쉬운 Markdown으로 작성합니다.
  </Step>
  <Step title="시험해 보기">
    **이 녹음으로 실행해 보기**를 클릭하면 결과를 볼 수 있습니다. 녹음에는 아무 변경도 없습니다.
  </Step>
  <Step title="저장">
    찾은 작업이 **할 일 목록** 탭에 표시되길 원하면 **작업을 실행 항목에 추가**를 켠 다음 **템플릿 저장**을 클릭합니다.
  </Step>
</Steps>

모든 새 녹음이 사용할 출력 언어와 템플릿을 설정하고 내 템플릿을 편집하거나 삭제하려면 **녹음** 페이지의 **새 녹음** 옆 **요약 설정**을 클릭하세요.

## 통화 검토하기

Mac에서 녹음한 각 Enconvo [회의](/ko/features/video-conference) 통화는 같은 방을 사용하더라도 **녹음**에 별도 항목이 만들어집니다. 메모가 켜진 통화에는 전사 내용, 참석자, 비디오, 메모 문서가 표시됩니다.

통화 페이지는 **회의** 개요로 열립니다.

- **요약**과 **할 일 목록**에는 각 항목을 맡은 사람과 기한이 표시됩니다. 항목의 **미리 알림에 추가**를 클릭하면 담당자와 기한이 포함된 채로 Apple 미리 알림에 추가됩니다.
- **이 통화에서 만든 항목**: 통화 중 Agent가 만든 문서와 화이트보드입니다.
- **화면에 표시된 내용**: Agent가 공유 화면에서 본 내용입니다.
- **이 회의에 질문**: 통화에 대해 질문합니다.

Agent는 채팅에서 이전 통화에 대한 질문에도 답할 수 있으며, 각 답변이 어느 회의에서 나왔는지 알려 줍니다.

Agent가 걸거나 받은 통화도 여기에 저장될 수 있습니다. **설정 → 에이전트 전화**에서 **통화 녹음하기**를 켜면 각 Agent 통화가 전사 내용과 함께 **녹음**에 저장됩니다. [에이전트 전화](/ko/features/agent-phone)를 참고하세요.

## 단계가 실패했을 때

전사, 제목 생성, 검색 인덱싱은 별도의 단계입니다. 이후 단계의 오류가 오디오나 전사 내용이 사라졌다는 뜻은 아닙니다. 긴 녹음은 몇 분이 걸리며, 페이지를 떠나도 처리는 계속됩니다. Enconvo Cloud Fast에서는 최대 300분의 녹음이 파일 전체로 전사됩니다.

네트워크가 끊겨 실시간 자막이 멈추면 다시 연결되며, 저장된 전사 내용은 여전히 녹음 전체를 포함합니다.

녹음의 처리 상태를 읽고 실패한 단계에서 **전사 재시도** 또는 **인덱싱 재시도**를 사용하세요. 문제를 신고할 때는 **지원용 세부 정보 복사**로 지원팀이 요청하는 참조 정보와 로그 위치를 복사할 수 있으며, 녹음은 포함되지 않습니다. 보내기 전에 개인 정보가 없는지 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 오디오가 없음 | 선택한 소스와 macOS 캡처 권한을 확인하세요. |
| 마이크가 사용 중임 | 녹음을 시작하기 전에 받아쓰기나 Live Talk를 끝내세요. |
| **준비된 전사 모델이 없음** | **설정 → 녹음 모델**에서 모델을 고르세요. |
| 처리 단계가 실패함 | 녹음의 처리 상태에서 해당 단계를 다시 시도하세요. |
| 요약이 엉뚱한 언어로 작성됨 | 측면 패널 상단에서 **출력 언어**를 고르세요. 새 녹음의 경우 **요약 설정**에서 지정하세요. |
| 할 일이 없음 | **회의 요약**을 사용하거나, **작업을 실행 항목에 추가**가 켜진 템플릿을 사용하세요. |

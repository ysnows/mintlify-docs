받아쓰기는 어떤 앱에서든 타이핑하는 자리에 말한 내용을 텍스트로 바꿔 줍니다. 음성 명령은 말한 내용을 Agent에게 보내고, Agent는 소리 내어 답하며 대신 작업도 할 수 있습니다. 주고받는 음성 대화가 필요하면 [Live Talk](/ko/features/live-voice)를 사용하세요.

아래 동영상 튜토리얼은 5분 안에 받아쓰기의 전 과정을 보여 줍니다. 오른쪽 Command 키를 누르거나 한 번 눌러서 말하기, 화면에 보이는 이름 읽어 오기, 사전에 이름 알려 주기, 말한 내용 정리·번역하기, 내 Mac에서 실행되는 모델을 포함한 음성 모델 선택까지 다룹니다.

## 시작하기 전에

Enconvo가 음성을 들으려면 마이크 권한이 필요합니다. 다른 앱에 텍스트를 입력하려면 손쉬운 사용 권한도 필요할 수 있습니다. [권한](/ko/configuration/permissions)을 참고하세요.

## 앱에 받아쓰기

1. 아무 앱에서나 텍스트를 넣고 싶은 입력란을 클릭합니다.
2. 오른쪽 **Command** 키를 누른 채 말합니다. 작은 알약 모양 표시가 받아쓰기가 듣고 있음을 알려 줍니다.
3. 말을 마치면 키에서 손을 뗍니다. 커서 위치에 텍스트가 입력됩니다.
4. 입력된 텍스트, 특히 이름, 날짜, 숫자를 확인합니다.

기본값은 말하는 동안 오른쪽 Command 키를 누르고 있는 방식입니다. 한 번 눌러서 필요한 만큼 말하고 싶다면 **설정 → 받아쓰기 → 받아쓰기 단축키**에서 누르는 방식을 바꾸세요. 이 경우 단축키를 다시 누르거나 알약의 체크 표시를 눌러 끝냅니다.

받아쓰기는 중국어, 일본어, 태국어를 제외하고 단어 앞이나 뒤에 필요한 공백을 넣어 줍니다. 내 스니펫의 이름이나 키워드만 단독으로 말하면 해당 단어 대신 스니펫의 텍스트가 입력됩니다.

### 받아쓰기 카드 사용하기

받아쓰는 동안 알약에 포인터를 올리면 카드로 확장되어 컨트롤 위에 내가 한 말이 표시됩니다. 카드에서 마이크를 바꾸고, 받아쓴 내용을 **초안 작성**으로 바꾸고, **정리** 옵션을 고르고, 멈추지 않고도 **Return으로 삽입 후 보내기**와 **실시간 전사**를 켜거나 끌 수 있습니다. 멈춘 뒤에는 카드에 정리 진행 상황이 표시됩니다.

알약을 작게 유지하려면 **실시간 전사**를 끄세요. 그러면 알약에는 버튼과 파형만 표시됩니다.

### Return으로 보내기

받아쓰는 동안 **Return**을 누르면 멈추고, 텍스트를 삽입하고, 채팅 메시지처럼 바로 보내기까지 한 번에 처리됩니다. 단축키나 체크 표시로 멈추면 텍스트만 삽입됩니다. 이 기능은 **설정 → 받아쓰기 → 삽입 → Return으로 삽입 후 보내기**에서 끌 수 있습니다.

아무것도 누르지 않고 모든 받아쓰기를 보내려면 같은 섹션에서 **삽입 후 보내기**를 켜세요.

### 일시 정지와 재개

탭해서 시작한 경우에는 일시 정지할 수 있습니다. 알약의 레벨 표시에 포인터를 올리고 **일시 정지**를 클릭하거나 **⌥P**를 누르세요. 마이크가 꺼지지만 말한 내용은 그대로 남습니다. **이어서 실행**을 클릭하거나 같은 키를 다시 누르면 계속되며, 평소처럼 단축키나 체크 표시로 끝냅니다. 키를 누르고 있는 방식의 받아쓰기에는 일시 정지가 없습니다.

키를 바꾸려면 **설정 → 받아쓰기 → 일시 정지 / 재개**를 여세요. 키 조합, **스페이스** 같은 단일 키, 또는 한 번 누르거나 두 번 누르거나 길게 누르는 보조 키 하나를 지정할 수 있습니다. 길게 누르면 손을 뗄 때까지 일시 정지됩니다.

### 회의 중 음소거 유지하기

Zoom, Microsoft Teams, Google Meet 통화, Mac용 Telegram 앱의 통화, 또는 Enconvo [Conference](/ko/features/video-conference)에서는 받아쓰기를 시작하면 통화 중 마이크가 음소거되고, 받아쓰기를 끝내거나 일시 정지하면 음소거가 해제됩니다. 앱과 브라우저 탭 모두에서 작동합니다. 직접 음소거한 통화는 계속 음소거 상태로 유지됩니다. Enconvo가 통화의 음소거 버튼을 찾지 못하면 직접 음소거하라고 한 번 알려 줍니다. 이 기능은 **설정 → 받아쓰기 → 받아쓰기 중 회의 마이크 음소거**에서 끌 수 있습니다.

## 음성으로 초안 작성하기

말한 내용을 그대로 받아쓰는 대신, 쓰고 싶은 내용을 말하면 받아쓰기가 초안을 작성하고, 무엇이든 입력되기 전에 내가 검토할 수 있습니다.

1. 답장을 작성 중인 입력란 같은 텍스트 입력란을 클릭합니다.
2. 오른쪽 **Command** 키와 **Shift** 키를 함께 누른 채, 텍스트에 담을 내용을 말합니다. 예를 들어 "목요일 2시 좋다고 전하고, 새 화면은 전날까지 보내달라고 해 줘."
3. 손을 뗍니다. 초안이 작성되는 대로 받아쓰기 알약 위의 패널에 나타납니다.
4. **Return**을 눌러 붙여 넣거나 **ESC**를 눌러 버립니다.

**Return**은 항상 초안을 시작한 앱에 붙여 넣으며, 다른 앱이 앞에 있으면 먼저 그 앱을 앞으로 가져옵니다. 패널 머리글에 해당 앱의 이름이 표시됩니다.

받아쓰는 도중에 초안으로 바꿀 수도 있습니다. 받아쓰는 동안 **Shift**를 한 번 누르면(받아쓰기 키에서 손을 뗀 뒤여도 됩니다) 지금까지 말한 내용이 초안의 지시문이 됩니다.

초안이 열려 있는 상태에서 받아쓰기 키만 누르고 수정할 내용을 말하면 초안을 다듬을 수 있습니다. 텍스트 입력란에서 초안 작성을 다시 사용하면 이미 있는 텍스트에 이어서 씁니다.

### 선택한 텍스트 고쳐 쓰거나 답하기

초안을 시작하기 전에 텍스트를 선택하고 어떻게 바꿀지 말하세요. 초안 작성은 선택 영역을 바꾸기 전에 변경 내용을 보여 줍니다.

받은 메시지나 웹 페이지 일부처럼 선택한 내용을 편집할 수 없는 경우, 초안 작성은 이를 참고 자료로 삼아 새 텍스트를 쓰고, **Return**을 누르면 돌아간 입력란에 붙여 넣습니다. 이 동작은 **선택한 텍스트 보내기**에서 끌 수 있습니다.

**앱 컨텍스트 보내기**를 켜면 지금 쓰고 있는 앱을 바탕으로 초안이 작성되어 작업에 맞는 내용이 됩니다. 예를 들어 이메일에 답장할 때는 답하려는 메시지의 세부 내용을 반영할 수 있습니다.

다음 항목은 **설정 → 받아쓰기 → 초안 작성**에 있습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **초안 보조 키** | 받아쓰기 단축키와 함께 눌러 초안을 시작하거나, 받아쓰는 중에 단독으로 탭하는 키입니다. 기본값은 **Shift**입니다. |
| **변경 내용 표시** | 초안이 텍스트를 편집할 때 추가되거나 삭제된 단어를 표시합니다. 끄면 결과만 표시됩니다. |
| **앱 컨텍스트 보내기** | 앱의 창 제목, 웹 주소, 보이는 텍스트를 모델에 전달합니다. 기본으로 켜져 있습니다. |
| **스크린샷 포함** | 앱 창의 이미지도 함께 보냅니다. 화면 기록 권한과 이미지를 읽을 수 있는 모델이 필요합니다. |
| **선택한 텍스트 보내기** | 선택했지만 편집할 수 없는 텍스트(메시지나 웹 페이지 등)를 참고 자료로 모델에 전달합니다. 기본으로 켜져 있습니다. |
| **초안 모델** | 각 초안을 작성하고 편집하는 모델입니다. |
| **초안 프롬프트** | 모델이 각 초안을 작성하고 편집하는 방식입니다. |

## 화면에 보이는 이름 활용하기

**설정 → 받아쓰기 → 현재 앱 내용 감지**를 켜면 받아쓰기가 지금 받아쓰는 앱을 읽어, 답장 중인 메시지의 보낸 사람 이름처럼 그곳에 표시된 대로 이름의 철자를 맞춥니다. 이 설정은 기본으로 켜져 있습니다.

## 말하면서 정리하거나 번역하기

녹음 알약의 **정리** 아이콘을 클릭하면 말한 내용이 삽입되기 전에 어떻게 처리할지 고를 수 있습니다.

- **다듬기**는 군더더기 말과 말 바꿈을 없애고, 오타와 구두점을 고쳐 내 말투를 살려 줍니다.
- **번역**은 말한 내용을 응답 언어로 입력하며, 이미 그 언어를 말한다면 영어로 입력합니다.
- **온디바이스 정리**는 내 Mac의 모델로 오프라인에서 텍스트를 정리합니다. Mac이 실행할 수 있을 때 나타나며, 모델은 한 번 다운로드됩니다.

**정리** 칩에는 선택한 옵션의 아이콘이 표시되며, 포인터를 올리면 이름이 보입니다. 다시 클릭하면 다음 옵션으로 넘어가며, **⌃⌥⌘I**(**받아쓰는 중 전환**)를 눌러도 됩니다. 처음에 선택되어 있을 옵션을 고르거나 이름, 프롬프트, 모델을 갖춘 나만의 옵션을 추가하려면 **설정 → 받아쓰기**를 열고 **정리** 섹션을 사용하세요.

번역과 맞춤법·문법 수정은 음, 어, 말더듬, 말 바꿈도 제거하므로 결과가 글로 쓴 텍스트처럼 읽힙니다. 이들의 **군더더기 말 제거** 옵션은 기본으로 켜져 있습니다.

앱에서 정리 옵션을 전환하면 그 받아쓰기에만 적용됩니다. 그 선택을 앱에 계속 적용하려면 카드의 **항상 …만 사용**을 클릭하세요. **실행 취소**도 있습니다. 이미 규칙이 있는 앱에서는 카드에 **규칙으로 설정**과 **규칙으로 되돌리기**가 표시됩니다.

### 번역 스타일 선택하기

**번역**이 결과를 표현하는 방식을 바꾸려면 **설정 → 받아쓰기**의 **정리**로 가서 **번역** 행의 화살표를 클릭한 다음 **스타일**을 고르세요.

- **표준**은 정확하고 말한 내용에 가깝게 옮깁니다.
- **원어민처럼**은 원어민이 쓴 것처럼 자유롭게 다시 표현합니다.
- **사용자 지정**은 내가 설명한 스타일을 따릅니다.

선택한 스타일은 **번역** 행에 배지로 표시됩니다. 이미 대상 언어로 말한 텍스트는 스타일과 관계없이 다른 쪽 언어로 번역됩니다.

## 특정 앱에 규칙 설정하기

**설정 → 받아쓰기 → 앱별 규칙**에서 앱이나 웹사이트별로 받아쓰기의 **정리**, **언어**, **Return 키**를 바꿀 수 있습니다. 규칙에서 번역을 사용할 때 **번역할 언어**를 선택하면 해당 앱에서만 다른 언어로 번역됩니다. 예를 들어 한 채팅 앱에서는 영어로 번역하고, 다른 모든 곳에서는 번역이 평소 쓰는 언어를 유지하도록 할 수 있습니다.

- Discord, Slack, Notion, Telegram, WhatsApp, ChatGPT, Claude, Linear, Figma, Teams에 만든 규칙은 해당 웹사이트에도 적용됩니다.
- 마지막 행은 규칙이 없는 모든 앱에 적용되는 설정을 보여 주며, 이는 받아쓰기 설정에서 가져옵니다.
- **자주 받아쓰기하는 앱**은 추가할 만한 앱을 제안합니다.

Enconvo 자체 메시지 입력란에서 마이크로 받아쓰면 정리와 언어에 대해 Enconvo의 앱 규칙을 따릅니다.

<Note>
다듬기, 번역, 내가 추가한 옵션은 내 AI 모델을 사용하므로, 음성 인식이 Mac에서 실행되었더라도 인식된 텍스트는 해당 모델 제공업체로 전송됩니다. 온디바이스 정리는 텍스트를 Mac 안에만 둡니다.
</Note>

## 음성 모델 선택하기

1. **설정 → 받아쓰기**를 열고 **음성 모델** 옆의 **변경**을 클릭합니다.
2. 클라우드 모델, 내 Mac에서 실행되는 모델, 내 API 키를 사용하는 모델 중에서 고릅니다.
3. **로컬**을 클릭하면 온디바이스 모델이 표시됩니다. 오프라인에서 작동하며 내 음성이 Mac 밖으로 나가지 않습니다.
4. 모델을 선택합니다. 로컬 모델은 몇 초 만에 로드됩니다.

**설정 → 받아쓰기 모델**을 바로 열 수도 있습니다. 받아쓰기, 음성 명령, Live Talk, 회의 녹음, 파일 전사, 실시간 자막은 각각 별도의 음성 모델 설정을 가지고 있습니다. 파일 일괄 처리에 적합한 제공업체가 스트리밍 입력에는 최선이 아닐 수 있습니다. [음성 인식](/ko/ai/speech-recognition)과 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

## 이름 알려 주기

화면에 없는 이름은 여전히 잘못 인식될 수 있습니다. 예를 들어 "Lumyn"이라는 프로젝트가 "Lumen"으로 나오는 경우입니다.

1. **설정 → 사전**을 열고 **새 단어**를 클릭합니다.
2. 올바른 단어를 입력하고, **잘못 인식된 표기**에 받아쓰기가 대신 인식한 내용을 입력합니다.
3. **저장**을 클릭한 다음 그 이름을 다시 받아써 봅니다.

사용자 지정 어휘와 제공업체의 언어 및 핫워드 설정에 대한 자세한 내용은 [사전과 화자](/ko/configuration/speech-assets)를 참고하세요.

## 지난 받아쓰기 확인하기

**설정 → 음성 입력 기록**을 열면 지난 인식 텍스트를 다시 볼 수 있습니다. 여기서 검색하고, 복사하고, 녹음을 재생하고, 받아쓰기를 다시 전사하고, 사전에 단어를 추가할 수 있습니다.

전사하지 못했거나, 너무 오래 걸렸거나, 중간에 끊긴 받아쓰기는 녹음과 함께 기록에 남습니다. **재시도**를 클릭하면 다시 전사합니다.

## 음성 명령으로 Agent와 대화하기

음성 명령은 Agent용 푸시투토크입니다. Dynamic Island에 표시되고 소리 내어 답하며, 앱 열기 같은 간단한 일은 즉시 처리하고 더 큰 요청은 작업으로 Agent에게 넘깁니다. 정해진 문구와 일치시키는 것이 아니라 내가 무엇을 요청했는지 파악합니다.

<Steps>
  <Step title="키를 누른 채 말하기">
    오른쪽 **Option** 키를 누른 채 필요한 내용을 말합니다. 말한 내용이 Dynamic Island에 표시됩니다. 키를 한 번 눌러서 시작할 수도 있습니다.
  </Step>
  <Step title="보내기">
    키에서 손을 떼거나, 눌러서 시작했다면 다시 한 번 누릅니다.
  </Step>
  <Step title="답변 받기">
    답변은 내 말 아래에 표시되며, **답변 읽어주기**가 켜져 있으면 소리 내어 읽어 줍니다. 시작된 작업은 해당 Agent의 모델과 도구로 실행됩니다.
  </Step>
</Steps>

답변을 멈추려면 키를 다시 누르고, 아직 말하는 중에 취소하려면 **ESC**를 누르세요. Dynamic Island의 마이크 버튼으로도 됩니다.

**설정 → 음성 명령**에서 설정합니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **단축키** | 누르고 있거나 탭하는 키입니다. 기본값은 오른쪽 Option 키입니다. |
| **듣기** | 내 말을 듣는 음성 모델(기본값은 **Enconvo Cloud Fast**)과 **마이크**, **언어**입니다. 직접 고르지 않으면 받아쓰기 설정을 따릅니다. |
| **생각** | 답변하는 모델입니다. **채팅과 동일**(기본값)은 채팅이 Enconvo Cloud에서 실행되면 Enconvo Fast를, 그렇지 않으면 채팅 자체 제공업체의 빠른 모델을 사용하므로, 내 API 키를 쓰는 경우 Enconvo Cloud 포인트가 소모되지 않습니다. 시작된 작업은 해당 채팅에 선택된 모델로 실행됩니다. |
| **답변** | **답변 읽어주기**와 답변에 쓸 음성입니다. **답변 읽어주기**를 끄면 답변이 Dynamic Island에만 표시됩니다. |
| **스크린샷 보내기** | 요청마다 현재 화면을 함께 보내 Agent가 내가 보는 것을 볼 수 있게 합니다. Enconvo 창은 제외됩니다. |
| **빠른 동작** | **관리**를 누르면 **설정 → 빠른 동작**이 열립니다. 음성 명령과 Live Talk가 즉시 처리하는 작업을 확인하고, 끄거나 직접 만들 수 있습니다. |

## 설정

다음 항목은 **설정 → 받아쓰기**에 있습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **받아쓰기 단축키** | 받아쓰기를 시작하는 키와, 누르고 있을지 탭할지를 정합니다. 기본값은 누르고 있기입니다. |
| **효과음 재생** | 받아쓰기가 시작되고 끝날 때 짧은 알림음을 재생합니다. |
| **마이크** | 받아쓰기가 녹음하는 마이크입니다. **테스트**를 클릭하면 소리가 들리는지 확인합니다. 연결되어 있지 않으면 이전에 사용한 마이크로 녹음합니다. |
| **받아쓰기 언어** | **기본값**은 음성 모델 자체의 설정을 유지하고, **자동 감지**는 언어를 인식하게 합니다. |
| **녹음 중 다른 소리 끄기** | 받아쓰는 동안 다른 앱의 소리를 일시 정지하거나 음소거하고, 끝나면 다시 켭니다. **무음 처리 방식**에서 일시 정지, 음소거, 또는 둘 다를 고릅니다. |
| **받아쓰기 중 회의 마이크 음소거** | 받아쓰는 동안 회의 통화에서 나를 음소거합니다. 기본으로 켜져 있습니다. |
| **일시 정지 / 재개** | 받아쓰기를 일시 정지하고 재개하는 키입니다. 기본값은 **⌥P**입니다. |
| **현재 앱 내용 감지** | 지금 사용 중인 앱을 읽어 이름과 용어의 철자를 맞추고, 다듬기, 번역, 초안 작성에 컨텍스트를 제공합니다. |
| **실시간 전사 표시** | 말하는 대로 내용을 표시합니다. 끄면 컨트롤과 파형만 남습니다. |
| **Return으로 삽입 후 보내기** | 받아쓰는 동안 **Return**을 누르면 멈추고, 텍스트를 삽입하고, 보냅니다. 기본으로 켜져 있습니다. |
| **삽입 후 보내기** | Return을 누르지 않아도 받아쓰기가 끝나면 텍스트를 보냅니다. 기본값은 꺼짐입니다. |
| **받아쓴 텍스트를 클립보드에 복사** | 인식된 텍스트를 클립보드에도 복사합니다. |
| **이름으로 스니펫 삽입** | 스니펫의 이름이나 키워드만 단독으로 말하면 해당 텍스트가 입력됩니다. |
| **받아쓰는 중에 앱을 전환하면** | 받아쓰기가 끝났을 때 다른 앱이 앞에 있는 경우 텍스트를 어디에 넣을지 정합니다. 기본값은 묻기입니다. |
| **앱별 규칙** | 특정 앱이나 웹사이트에 대해 위 단계를 바꿉니다. |
| **받아쓰기 기록 저장** | **기록 보관 기간**에 정한 기간 동안 각 받아쓰기의 녹음과 텍스트를 보관합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 마이크 입력이 없음 | 알림에 마이크 이름이 나오고 소리가 전달되지 않는다고 하면, 다른 마이크를 고르거나 **설정 → 받아쓰기**의 **마이크** 옆 **테스트**를 클릭하세요. 마이크 권한도 확인하세요. |
| 텍스트는 나타나지만 삽입되지 않음 | 손쉬운 사용 권한을 확인하고, 텍스트 입력란을 클릭하고, 앱이 붙여넣기를 허용하는지 확인하세요. |
| **Return**으로 보내지지 않음 | **설정 → 받아쓰기 → 삽입**의 **Return으로 삽입 후 보내기**와 해당 앱 규칙의 **Return 키** 열을 확인하세요. |
| 받아쓰기가 실패했거나 중간에 끊김 | **설정 → 음성 입력 기록**을 열고 해당 항목의 **재시도**를 클릭하세요. |
| 인식 후 텍스트가 잘못됨 | 사용 중인 **정리** 옵션, **받아쓰기 언어**, [사전](/ko/configuration/speech-assets)을 확인하세요. |
| 멈춘 뒤 결과가 느림 | 일괄 처리 모델은 녹음 전체를 기다립니다. 스트리밍 모델을 선택하세요. |
| 다른 기능이 마이크를 사용 중 | 먼저 Live Talk나 녹음을 끝내세요. |

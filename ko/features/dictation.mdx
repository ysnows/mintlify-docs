받아쓰기는 어떤 앱에서든 지금 입력 중인 위치에 말한 내용을 텍스트로 입력합니다. 음성 명령은 말한 내용을 에이전트에게 전달해 음성으로 답변받고 작업을 수행하게 합니다. 서로 주고받는 음성 대화를 하려면 [실시간 대화](/ko/features/live-voice)를 사용하세요.

아래 동영상 튜토리얼에서는 5분 안에 받아쓰기의 처음부터 끝까지 다룹니다. 오른쪽 Command 키를 길게 누르거나 한 번 눌러 말하기, 화면의 이름 읽기, 사전에 단어 등록하기, 말한 내용 다듬기 또는 번역하기, Mac에서 실행되는 로컬 모델을 포함한 음성 모델 선택까지 살펴봅니다.

## 시작하기 전에

Enconvo가 음성을 들으려면 마이크 권한이 필요합니다. 다른 앱에 텍스트를 입력하려면 손쉬운 사용 권한도 필요할 수 있습니다. [권한](/ko/configuration/permissions)을 참고하세요.

## 앱에 받아쓰기 입력하기

1. 텍스트를 입력하려는 앱의 입력란을 클릭합니다.
2. 오른쪽 **Command** 키를 누른 상태에서 말합니다. 작은 알약 모양 막대가 받아쓰기 중임을 표시합니다.
3. 말이 끝나면 키에서 손을 뗍니다. 커서 위치에 텍스트가 입력됩니다.
4. 입력된 텍스트, 특히 이름, 날짜, 숫자를 확인합니다.

말하는 동안 오른쪽 Command 키를 누르고 있는 것이 기본 설정입니다. 대신 한 번 눌러 시작하고 원하는 만큼 길게 말하려면 **설정 → 받아쓰기 → 받아쓰기 단축키**를 열어 누르는 방식을 바꾸세요. 이 경우 단축키를 다시 누르거나 막대의 체크 표시를 눌러 마칩니다.

받아쓰기는 중국어, 일본어, 태국어를 제외하고 필요한 곳에 앞뒤 공백을 자동으로 넣습니다. 등록한 스니펫의 이름이나 키워드만 단독으로 말하면 그 말 대신 스니펫 텍스트가 입력됩니다.

### 받아쓰기 카드 사용하기

받아쓰는 동안 알약 모양 막대에 마우스 포인터를 올리면 카드로 커지며, 컨트롤 위에 인식된 단어가 표시됩니다. 카드에서는 받아쓰기를 멈추지 않고도 마이크를 전환하거나, 받아쓰기를 **초안**으로 바꾸거나, **정리** 옵션을 고르거나, **Return으로 삽입 후 보내기**와 **실시간 전사**를 켜고 끌 수 있습니다. 말을 멈춘 뒤에는 카드에 정리 진행 상태가 표시됩니다.

막대를 작게 유지하려면 **실시간 전사**를 끄세요. 그러면 버튼과 파형만 표시됩니다.

### Return으로 보내기

받아쓰는 동안 **Return**을 누르면 받아쓰기를 멈추고 텍스트를 삽입한 뒤 한 번에 전송까지 실행합니다(예: 채팅 메시지). 단축키나 체크 표시로 멈추면 텍스트만 삽입합니다. 이 기능을 끄려면 **설정 → 받아쓰기 → 삽입 → Return으로 삽입 후 보내기**를 사용하세요.

키를 누르지 않고도 모든 받아쓰기를 바로 전송하려면 같은 섹션에서 **삽입 후 보내기**를 켜세요.

### 일시 정지 및 재개

한 번 눌러 시작하는 모드에서는 일시 정지할 수 있습니다. 막대의 레벨 표시기에 포인터를 올리고 **일시 정지**를 클릭하거나 **⌥P**를 누르세요. 마이크가 꺼지고 지금까지 말한 내용은 그대로 남습니다. 계속하려면 **재개**를 클릭하거나 키를 다시 누르고, 평소처럼 단축키나 체크 표시로 마칩니다. 키를 길게 누르는 받아쓰기에는 일시 정지가 없습니다.

키를 바꾸려면 **설정 → 받아쓰기 → 일시 정지 / 재개**를 여세요. 키 조합, **Space** 같은 단일 키, 또는 한 번 누르기·두 번 누르기·길게 누르기로 쓰는 보조 키 하나를 지정할 수 있습니다. 길게 누르면 키를 뗄 때까지 일시 정지됩니다.

### 회의 중 마이크 음소거 유지하기

Zoom, Microsoft Teams, Google Meet 통화, Mac용 Telegram 앱 통화 또는 Enconvo [화상 회의](/ko/features/video-conference) 중에 받아쓰기를 시작하면 통화의 내 마이크가 음소거되고, 받아쓰기를 마치거나 일시 정지하면 음소거가 해제됩니다. 전용 앱과 브라우저 탭 모두에서 작동합니다. 사용자가 직접 음소거한 통화는 음소거 상태가 유지됩니다. Enconvo가 통화의 음소거 버튼을 찾지 못하면 직접 음소거하도록 한 번 안내합니다. 이 기능을 끄려면 **설정 → 받아쓰기 → 받아쓰는 동안 회의 마이크 음소거**를 사용하세요.

## 음성으로 초안 작성하기

말한 그대로 입력하는 대신 쓰고 싶은 내용을 말로 지시하면, 받아쓰기가 초안을 작성해 삽입 전에 검토할 수 있게 해 줍니다.

1. 답장 입력창 같은 텍스트 필드를 클릭합니다.
2. 오른쪽 **Command** 키와 **Shift**를 함께 누른 채 작성할 내용을 말합니다(예: "목요일 오후 2시가 좋다고 전하고, 하루 전에 새 화면 시안을 보내 달라고 부탁해 줘").
3. 키에서 손을 뗍니다. 초안이 작성되면서 받아쓰기 막대 위 패널에 나타납니다.
4. **Return**을 눌러 붙여 넣거나, **Esc**를 눌러 버립니다.

**Return**은 항상 초안을 시작한 앱에 붙여 넣으며, 그사이 다른 앱이 앞으로 나와 있으면 원래 앱을 먼저 앞으로 가져옵니다. 패널 상단 헤더에 해당 앱 이름이 표시됩니다.

받아쓰기를 하는 도중에도 초안으로 전환할 수 있습니다. 받아쓰기 중(받아쓰기 키를 놓은 뒤에도 가능) **Shift**를 한 번 누르면 지금까지 말한 내용이 초안 지시사항이 됩니다.

초안이 열린 상태에서 받아쓰기 키만 누르고 수정할 내용을 말하면 초안을 다듬을 수 있습니다. 텍스트 필드에 이미 글이 있을 때 초안을 다시 사용하면 기존 내용에 이어서 작성합니다.

### 선택한 텍스트 다시 쓰기 또는 답장하기

초안을 시작하기 전에 텍스트를 선택한 다음 어떻게 바꿀지 말하세요. 초안은 선택 영역을 바꾸기 전에 변경 내용을 보여 줍니다.

받은 메시지나 웹 페이지 일부처럼 편집할 수 없는 텍스트를 선택했다면 초안이 이를 참고 자료로 삼아 새 텍스트를 작성하며, **Return**을 누르면 돌아갈 입력 필드에 붙여 넣습니다. 이 기능을 끄려면 **선택한 텍스트 보내기**를 끄세요.

**앱 컨텍스트 보내기**가 켜져 있으면 현재 사용 중인 앱의 맥락을 바탕으로 초안을 작성하므로 작업에 잘 맞습니다. 예를 들어 이메일에 답장할 때 답장 대상 메시지의 세부 내용을 반영할 수 있습니다.

이 설정은 **설정 → 받아쓰기 → 초안**에 있습니다.

| 설정 | 변경 내용 |
| --- | --- |
| **초안 보조 키** | 받아쓰기 단축키와 함께 눌러 초안을 시작하거나, 받아쓰기 중 단독으로 눌러 전환하는 키입니다. 기본값은 **Shift**입니다. |
| **변경 사항을 diff로 표시** | 초안이 텍스트를 편집할 때 추가되고 삭제된 단어를 표시합니다. 끄면 결과만 표시합니다. |
| **앱 컨텍스트 보내기** | 모델에 앱의 창 제목, 웹 주소 및 화면에 보이는 텍스트를 전달합니다. 기본값은 켜짐입니다. |
| **스크린샷 포함** | 앱 창 이미지도 함께 전송합니다. 화면 기록 권한과 이미지를 읽을 수 있는 모델이 필요합니다. |
| **선택한 텍스트 보내기** | 메시지나 웹 페이지처럼 편집할 수 없지만 선택한 텍스트를 참고용으로 모델에 전달합니다. 기본값은 켜짐입니다. |
| **초안용 모델** | 각 초안을 작성하고 편집하는 모델입니다. |
| **초안용 프롬프트** | 모델이 각 초안을 작성하고 편집하는 방식입니다. |

## 화면에 있는 이름 활용하기

**설정 → 받아쓰기 → 현재 앱 콘텐츠 감지**가 켜져 있으면 받아쓰기가 현재 입력 중인 앱을 읽어 답장하는 메시지의 발신자 이름 같은 고유명사를 화면에 표시된 철자 그대로 맞춥니다. 이 설정은 기본적으로 켜져 있습니다.

## 말하면서 다듬기 또는 번역하기

녹음 막대의 **정리** 아이콘을 클릭해 말한 내용이 입력되기 전에 어떻게 처리할지 선택하세요.

- **다듬기**는 원래 표현을 유지하면서 군더더기 말과 말더듬을 없애고 오타와 문장 부호를 바로잡습니다.
- **번역**은 말한 내용을 응답 언어로 입력합니다. 이미 응답 언어로 말했다면 영어로 번역합니다.
- **온디바이스 정리**는 Mac의 로컬 모델로 오프라인 상태에서 텍스트를 다듬습니다. Mac에서 실행할 수 있는 경우 표시되며 모델은 한 번 다운로드됩니다.

**정리** 칩에는 선택한 옵션의 아이콘이 표시되며, 포인터를 올리면 이름이 보입니다. 다시 클릭하면 다음 옵션으로 넘어가며, **⌃⌥⌘I**(**받아쓰는 중 전환**)를 눌러도 됩니다. 기본으로 선택될 옵션을 고르거나 이름, 프롬프트, 모델을 지정해 나만의 옵션을 추가하려면 **설정 → 받아쓰기**를 열고 **정리** 섹션을 사용하세요.

번역과 맞춤법 및 문법 교정도 "음", "어", 말더듬, 말머뭇거림을 제거해 글로 쓴 듯한 자연스러운 결과를 만듭니다. 해당 기능의 **추임새 제거** 옵션은 기본적으로 켜져 있습니다.

특정 앱에서 정리 옵션을 전환하면 해당 받아쓰기에 적용됩니다. 카드에서 **항상 … 사용**을 클릭하면 그 앱의 규칙으로 저장할 수 있으며 **실행 취소**도 가능합니다. 이미 규칙이 있는 앱에서는 카드에 **규칙으로 지정**과 **규칙으로 돌아가기**가 표시됩니다.

### 번역 스타일 선택하기

**번역**이 문장을 다듬는 방식을 바꾸려면 **설정 → 받아쓰기**를 열고 **정리**로 이동한 뒤 **번역** 행의 펼침 화살표를 클릭하세요. 그런 다음 **스타일**을 고릅니다.

- **표준**: 정확하며 말한 내용에 가깝게 번역합니다.
- **원어민처럼**: 원어민이 쓴 것처럼 자연스럽게 의역합니다.
- **사용자 지정**: 사용자가 설명한 스타일을 따릅니다.

선택한 스타일은 **번역** 행에 배지로 표시됩니다. 이미 대상 언어로 말한 텍스트는 어느 스타일을 선택했든 사용자의 다른 언어로 번역됩니다.

## 특정 앱별 규칙 정하기

**설정 → 받아쓰기 → 앱별 규칙**에서는 특정 앱이나 웹사이트 하나에 대해 **정리**, **언어**, **Return 키** 동작을 따로 지정할 수 있습니다. 규칙에서 번역을 사용하는 경우 **번역할 언어**를 선택해 그 앱에서만 다른 언어로 번역할 수 있습니다(예: 다른 모든 곳에서는 평소 언어를 유지하면서 특정 채팅 앱에서만 영어로 번역).

- Discord, Slack, Notion, Telegram, WhatsApp, ChatGPT, Claude, Linear, Figma, Teams용 규칙은 해당 웹사이트도 함께 포함합니다.
- 마지막 행에는 규칙이 없는 모든 앱에 적용되는 설정이 표시되며, 이는 기본 받아쓰기 설정을 따릅니다.
- **받아쓰기를 자주 사용하는 앱**에서는 추가할 만한 앱을 추천해 줍니다.

Enconvo 자체 메시지 입력란의 마이크 버튼으로 받아쓸 때는 정리와 언어에 Enconvo의 앱별 규칙이 적용됩니다.

<Note>
다듬기, 번역 및 직접 추가한 옵션은 AI 모델을 사용하므로, 음성 인식이 Mac에서 실행되었더라도 인식된 텍스트는 해당 모델 제공업체로 전송됩니다. 온디바이스 정리는 모든 처리를 Mac 안에서만 유지합니다.
</Note>

## 음성 모델 선택하기

1. **설정 → 받아쓰기**를 열고 **음성 모델** 옆의 **변경**을 클릭합니다.
2. 클라우드 모델, Mac에서 실행되는 모델, 개인 API 키를 사용하는 모델 중에서 고릅니다.
3. 온디바이스 모델을 보려면 **로컬**을 클릭합니다. 오프라인에서도 작동하며 음성이 Mac 밖으로 나가지 않습니다.
4. 모델을 선택합니다. 로컬 모델은 몇 초 안에 로드됩니다.

**설정 → 받아쓰기 모델**을 바로 열 수도 있습니다. 받아쓰기, 음성 명령, 실시간 대화, 회의 녹음, 파일 전사 및 실시간 자막은 각각 별도의 음성 모델 설정을 가집니다. 일괄 파일 처리에 적합한 제공업체가 실시간 스트리밍 입력에는 최선이 아닐 수 있습니다. [음성 인식](/ko/ai/speech-recognition)과 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

## 단어 가르치기

화면에 나타나지 않는 이름은 여전히 잘못 인식될 수 있습니다(예: 프로젝트 이름 "Lumyn"이 "Lumen"으로 인식되는 경우).

1. **설정 → 사전**을 열고 **새 단어**를 클릭합니다.
2. 올바른 단어를 입력한 다음, **잘못 인식된 표기**에 받아쓰기가 잘못 들은 표현을 입력합니다.
3. **저장**을 클릭하고 이름을 다시 받아써 보세요.

사용자 지정 어휘와 제공업체별 언어 및 핫워드 설정에 대한 자세한 내용은 [사전 및 화자](/ko/configuration/speech-assets)를 참고하세요.

## 이전 받아쓰기 다시 보기

**설정 → 음성 입력 기록**을 열면 이전에 인식된 텍스트를 다시 볼 수 있습니다. 여기에서 검색, 복사, 녹음 재생, 받아쓰기 재실행, 사전에 단어 추가를 할 수 있습니다.

전사에 실패했거나 시간이 초과되었거나 중간에 끊긴 받아쓰기도 녹음과 함께 기록에 남습니다. **재시도**를 클릭하면 다시 전사할 수 있습니다.

## 음성 명령으로 에이전트와 대화하기

음성 명령은 에이전트를 위한 무전기(push-to-talk) 방식 기능입니다. Dynamic Island에 답을 띄우고 소리 내어 읽어 주며, 앱 열기 같은 간단한 일은 즉시 처리하고 큰 요청은 작업으로 에이전트에게 넘깁니다. 정해진 문장 패턴만 인식하는 것이 아니라 사용자가 무엇을 요청했는지 파악해 처리합니다.

<Steps>
  <Step title="키를 누른 채 말하기">
    오른쪽 **Option** 키를 누른 상태에서 필요한 내용을 말합니다. 말한 내용이 Dynamic Island에 표시됩니다. 키를 한 번 눌러 시작할 수도 있습니다.
  </Step>
  <Step title="전송">
    키에서 손을 떼거나, 한 번 눌러 시작했다면 다시 한 번 누릅니다.
  </Step>
  <Step title="답변 받기">
    말한 내용 아래에 답변이 표시되며, **답변 읽어주기**가 켜져 있으면 소리 내어 읽어 줍니다. 음성 명령으로 시작된 작업은 해당 에이전트 자체 모델과 도구를 사용합니다.
  </Step>
</Steps>

답변을 멈추려면 키를 다시 누르고, 아직 말하는 도중에 취소하려면 **Esc**를 누르세요. Dynamic Island의 마이크 버튼도 똑같이 작동합니다.

설정은 **설정 → 음성 명령**에서 구성합니다.

| 설정 | 변경 내용 |
| --- | --- |
| **단축키** | 길게 누르거나 한 번 누를 키입니다. 기본값은 오른쪽 Option 키입니다. |
| **듣기** | 음성을 듣는 음성 모델(기본값 **Enconvo Cloud Fast**)과 **마이크** 및 **언어** 설정입니다. 따로 선택하지 않으면 받아쓰기 설정을 따릅니다. |
| **생각** | 답변을 생성하는 모델입니다. **채팅과 동일**(기본값)은 채팅이 Enconvo Cloud에서 실행 중일 때 Enconvo Fast를 쓰고, 그렇지 않으면 채팅 제공업체의 빠른 모델을 사용하므로 개인 API 키를 쓸 때 Enconvo Cloud 포인트를 쓰지 않습니다. 이를 통해 시작된 작업은 해당 채팅에 선택된 모델에서 실행됩니다. |
| **답변** | **답변 읽어주기** 켜기/끄기와 읽어 줄 음성을 설정합니다. **답변 읽어주기**를 끄면 답변이 Dynamic Island에만 표시됩니다. |
| **스크린샷 전송** | 매 요청마다 현재 보고 있는 화면을 함께 보내 에이전트가 화면을 볼 수 있게 합니다. Enconvo 창은 제외됩니다. |
| **빠른 동작** | **관리**를 누르면 **설정 → 빠른 동작**이 열립니다. 여기에서 음성 명령과 실시간 대화가 즉시 실행하는 작업을 확인하고 끄거나 직접 만들 수 있습니다. |

## 설정

다음 설정은 **설정 → 받아쓰기**에 있습니다.

| 설정 | 변경 내용 |
| --- | --- |
| **받아쓰기 단축키** | 받아쓰기를 시작하는 키와 길게 누르기·한 번 누르기 방식입니다. 기본값은 길게 누르기입니다. |
| **효과음 재생** | 받아쓰기를 시작하고 마칠 때 짧은 알림음을 재생합니다. |
| **마이크** | 받아쓰기가 녹음할 마이크입니다. **테스트**를 클릭해 소리가 잘 들어오는지 확인하세요. 연결이 끊어졌을 때는 이전에 사용한 마이크에서 녹음합니다. |
| **받아쓰기 언어** | **기본값**은 음성 모델 자체 설정을 유지하고, **자동 감지**는 언어를 자동으로 인식합니다. |
| **녹음 중 다른 오디오 음소거** | 받아쓰는 동안 다른 앱의 오디오를 일시 정지하거나 음소거하고, 끝나면 원래대로 되돌립니다. **음소거 방식**에서 일시 정지, 음소거 또는 둘 다 중 고릅니다. |
| **받아쓰는 동안 회의 마이크 음소거** | 받아쓰는 동안 회의 통화의 내 마이크를 음소거합니다. 기본값은 켜짐입니다. |
| **일시 정지 / 재개** | 받아쓰기를 일시 정지하고 재개하는 키입니다. 기본값은 **⌥P**입니다. |
| **현재 앱 콘텐츠 감지** | 사용 중인 앱을 읽어 이름과 용어를 정확히 표기하고 다듬기, 번역, 초안에 맥락을 제공합니다. |
| **실시간 전사 표시** | 말하는 동안 단어를 실시간으로 보여 줍니다. 끄면 컨트롤과 파형만 남습니다. |
| **Return으로 삽입 후 보내기** | 받아쓰는 동안 **Return**을 누르면 멈추고 텍스트를 삽입한 뒤 전송합니다. 기본값은 켜짐입니다. |
| **삽입 후 보내기** | 받아쓰기가 끝나면 Return을 누르지 않아도 텍스트를 바로 전송합니다. 기본값은 꺼짐입니다. |
| **받아쓴 텍스트를 클립보드에 복사** | 인식된 텍스트를 클립보드에도 함께 복사합니다. |
| **이름으로 스니펫 삽입** | 스니펫의 이름이나 키워드만 단독으로 말하면 해당 텍스트를 입력합니다. |
| **받아쓰는 중 앱을 전환할 때** | 받아쓰기가 끝났을 때 다른 앱이 앞에 나와 있으면 텍스트를 어디에 입력할지 정합니다. 기본값은 묻기입니다. |
| **앱별 규칙** | 특정 앱이나 웹사이트에 대해 위 단계들의 동작을 다르게 설정합니다. |
| **받아쓰기 기록 저장** | **기록 보관 기간**에 설정한 기간 동안 각 받아쓰기의 녹음과 텍스트를 보관합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 마이크 입력이 없음 | 알림에 마이크 이름과 소리가 들어오지 않는다는 안내가 뜨면 다른 마이크를 고르거나 **설정 → 받아쓰기**의 **마이크** 옆에서 **테스트**를 클릭하세요. 마이크 권한도 확인하세요. |
| 텍스트가 보이는데 입력되지 않음 | 손쉬운 사용 권한을 확인하고, 텍스트 필드를 클릭했으며 앱이 붙여넣기를 허용하는지 확인하세요. |
| **Return**으로 전송되지 않음 | **설정 → 받아쓰기 → 삽입**의 **Return으로 삽입 후 보내기**와 해당 앱 규칙의 **Return 키** 열을 확인하세요. |
| 받아쓰기가 실패하거나 중간에 끊김 | **설정 → 음성 입력 기록**을 열고 해당 항목에서 **재시도**를 클릭하세요. |
| 인식 후 텍스트가 잘못됨 | 사용 중인 **정리** 옵션, **받아쓰기 언어** 및 [사전](/ko/configuration/speech-assets)을 확인하세요. |
| 멈춘 뒤 결과가 늦게 나옴 | 일괄(batch) 모델은 녹음이 끝날 때까지 기다립니다. 스트리밍을 지원하는 모델을 선택하세요. |
| 다른 기능이 마이크를 점유하고 있음 | 먼저 실시간 대화나 녹음을 종료하세요. |

컴퓨터 사용을 통해 Enconvo는 텍스트 이상의 조작이 필요할 때 Mac의 앱을 직접 다룰 수 있습니다. 앞쪽에 열린 앱을 보고 화면의 컨트롤을 찾아 필드에 입력하거나 클릭하고, 목록을 스크롤하고, 항목을 드래그하고, 파일을 고르고, 앱 메뉴를 사용하며, 다음 단계로 넘어가기 전에 앱이 응답할 때까지 기다립니다.

다음과 같은 데스크톱 작업에 활용하세요.

- Mac 앱의 양식 채우기
- 파일 선택기에서 파일 고르기
- 설정 창 이동하며 조작하기
- 도구 모음 버튼이나 메뉴 항목 클릭하기
- 여러 단계로 이루어진 앱 작업 처리하기
- 현재 창에 보이는 내용 읽기

웹사이트의 경우 브라우저 사용이 Enconvo 브라우저 확장 프로그램(Browser Companion)을 통해 사용자의 브라우저 안에서 직접 작동합니다. Safari처럼 확장 프로그램이 없는 브라우저에서는 대신 컴퓨터 사용이 화면 위에서 클릭과 입력을 수행합니다.

아래 5분짜리 동영상 튜토리얼에서는 컴퓨터 사용과 브라우저 사용을 처음부터 끝까지 설정하고 쓰는 법을 보여 줍니다. 기능을 켜고 두 가지 권한을 허용하고, Chrome에 브라우저 확장 프로그램을 추가하고, 오른쪽 Option 키를 누른 채 요청한 뒤, Safari, Chrome, Mac 앱에서 작동하는 모습과 전체 작업을 처리하는 과정을 살펴봅니다.

## 컴퓨터 사용 켜기

컴퓨터 사용에는 두 가지 macOS 권한이 필요합니다. 클릭과 입력을 위한 손쉬운 사용 권한과, 화면을 보기 위한 화면 기록 권한입니다.

<Steps>
  <Step title="컴퓨터 사용 설정 열기">
    **설정 → 컴퓨터 사용**을 열고 스위치가 켜져 있는지 확인하세요.
  </Step>
  <Step title="두 권한 확인하기">
    **손쉬운 사용**과 **화면 기록**이 모두 **활성화됨**으로 표시되어야 합니다.
  </Step>
  <Step title="누락된 권한 허용하기">
    어느 하나가 **필수**로 표시되면 그 옆의 **열기**를 클릭한 뒤 **시스템 설정 → 개인정보 보호 및 보안**의 해당 권한에서 Enconvo를 켜세요. Enconvo로 돌아와 **새로고침**을 클릭합니다. 그래도 상태가 바뀌지 않으면 Enconvo를 종료했다가 다시 여세요.
  </Step>
</Steps>

## 브라우저 확장 프로그램 추가

<Steps>
  <Step title="브라우저 사용 설정 열기">
    **설정 → 브라우저 사용**을 엽니다. **브라우저 확장 프로그램**에 확장 프로그램이 설치된 브라우저와 연결 상태가 표시됩니다.
  </Step>
  <Step title="Browser Companion 설치하기">
    **Browser Companion 설치**를 클릭합니다. Chrome 웹 스토어에서 확장 프로그램 페이지가 열립니다.
  </Step>
  <Step title="확장 프로그램 추가하기">
    **Chrome에 추가**, 이어서 **확장 프로그램 추가**를 클릭합니다. 브라우저의 확장 프로그램 메뉴를 열어 도구 모음에 계속 표시되도록 고정하세요.
  </Step>
  <Step title="연결 확인하기">
    **설정 → 브라우저 사용**으로 돌아오면 브라우저 상태가 **연결됨**으로 표시됩니다. Edge, Arc, Brave도 같은 방식으로 설정합니다.
  </Step>
</Steps>

확장 프로그램 팝업, 지원 브라우저, 문제 해결은 [브라우저 확장 프로그램](/ko/features/browser-extension)을 참고하세요.

## 작업 실행하기

클릭 순서를 일일이 나열하지 말고 원하는 최종 결과를 요청하세요.

<Steps>
  <Step title="대상 앱 열기">
    Enconvo가 작업할 앱이나 창을 맨 앞으로 가져옵니다.
  </Step>
  <Step title="오른쪽 Option 키를 누른 채 요청하기">
    오른쪽 **Option** 키를 누르고 필요한 내용을 말한 뒤 키를 놓으세요. 예를 들어 "Safari에서 이 페이지의 가장 싼 직항편을 찾아 줘" 또는 "설정 패널을 열고 로그인 시 실행을 꺼 줘"처럼 앱과 페이지를 함께 말하세요. 에이전트에게 요청을 텍스트로 입력해도 됩니다.
  </Step>
  <Step title="작업 과정 지켜보기">
    Enconvo가 작업 중인 창 테두리를 따라 부드러운 빛이 흐르고, 클릭할 때마다 빛 파동이 퍼지며, Dynamic Island에 각 단계가 표시됩니다. 창이 시야 밖에 있을 때는 화면 모서리의 [화면 속 화면](/ko/features/picture-in-picture) 창에 작업 모습이 실시간으로 나타납니다. 언제든 직접 조작을 넘겨받거나 작업을 중지할 수 있습니다.
  </Step>
  <Step title="민감한 단계 확인하기">
    삭제, 결제, 계정 변경, 권한 변경 같은 작업에서는 Enconvo가 계속 진행하기 전에 승인을 요청합니다. 이는 키보드 단축키에도 적용됩니다. Enconvo는 삭제, 전송, 결제, 앱 종료 또는 로그아웃을 실행하는 단축키를 누르기 전에 먼저 묻습니다.
  </Step>
  <Step title="결과 받기">
    Enconvo는 앱을 살피고 행동하고 결과를 기다리며 작업이 끝나거나 확인이 필요할 때까지 이어 갑니다. 작업이 완료되면 결과를 알려 줍니다.
  </Step>
</Steps>

### 브라우저에서

> "후지산과 레이니어산의 Wikipedia 페이지를 열고 어느 쪽이 더 높은지 알려 줘."

확장 프로그램이 연결되면 브라우저 사용은 백그라운드에서 별도의 탭을 여므로 사용자가 보던 페이지는 그대로 유지됩니다. 확장 프로그램이 작업하는 동안 브라우저 페이지 상단에 표시줄이 나타나며, 이를 취소하지 마세요. 에이전트의 턴이 끝나면 열었던 탭은 닫힙니다. 결과로 건넨 페이지, 사용자에게 넘긴 탭, 고정한 탭, 현재 보고 있는 탭은 열려 있으며 사용자가 원래 열어 둔 탭은 절대 닫히지 않습니다.

## 컴퓨터 사용이 할 수 있는 작업

| 작업 | 예시 |
|--------|----------|
| **앱 상태 살펴보기** | 현재 창, 컨트롤, 메뉴 항목, 선택한 텍스트, 화면에 보이는 필드 읽기 |
| **클릭 및 두 번 클릭** | 버튼, 사이드바 행, 도구 모음 항목, 메뉴 명령, 좌표 클릭 |
| **입력 및 키 누르기** | 필드 채우기, 양식 제출, **⌘S** 같은 단축키 사용 |
| **스크롤** | 목록, 표, 설정 창, 긴 문서 이동 |
| **드래그** | 앱이 지원하는 경우 파일, 행, 슬라이더, 선택 핸들 드래그 |
| **파일 선택기 사용** | 열기 및 저장 대화 상자에서 파일과 폴더 선택 |
| **동작 후 대기** | 클릭, 이동 또는 로딩 단계 이후 앱 다시 확인 |
| **앱 로그인** | 에이전트에게 비밀번호를 노출하지 않고 저장된 사용자 이름과 비밀번호를 앱 로그인 창에 입력([자격 증명](/ko/configuration/credentials) 참고) |

서로 다른 앱에서 작업하는 하위 에이전트처럼 여러 에이전트가 동시에 컴퓨터 사용을 쓸 수 있습니다. 각 에이전트는 각자의 앱에서 동시에 작동하며, 같은 앱에서 일하는 에이전트끼리만 차례를 번갈아 가집니다. 앱의 다른 창이 앞에 나와 있더라도 동작은 에이전트가 지정한 창으로 전달됩니다.

## 사용할 수 있는 앱 선택

**설정 → 컴퓨터 사용 → 앱 접근**에서 컴퓨터 사용이 보고 다룰 수 있는 앱을 정합니다. **모드**를 선택하세요.

- **다음 앱 제외 모두**: 컴퓨터 사용이 **차단된 앱** 아래의 앱만 건드리지 않고 나머지 앱을 모두 사용합니다.
- **이 앱만**: 컴퓨터 사용이 **허용된 앱** 아래의 앱만 사용합니다. **에이전트가 다른 앱을 필요로 할 때** 아래에서 에이전트가 요청할 때마다 "컴퓨터 사용이 이 앱을 사용하도록 허용할까요?"를 묻는 **나에게 묻기** 또는 **거부**를 선택하세요.

**앱 추가**를 클릭해 현재 열려 있는 앱이나 응용 프로그램 폴더에서 앱을 추가하세요. 차단된 앱은 스크린샷에서 제외됩니다. 암호 관리자와 시스템 로그인 프롬프트는 항상 차단되며 **비밀번호 및 시스템 프롬프트**로 표시됩니다. PopBar, 선택한 텍스트, 받아쓰기는 각자의 설정을 따릅니다.

## 예시

| 요청 | Enconvo가 하는 일 |
| --- | --- |
| "이 파일 선택기에서 데스크톱의 가장 최신 스크린샷을 골라 줘." | 파일 선택기를 살펴보고 폴더로 이동해 파일을 선택한 뒤 대화 상자를 확인합니다. |
| "이 앱의 환경설정을 열고 알림을 꺼 줘." | 앱 메뉴를 이용해 설정을 찾고 끈 뒤 결과를 확인합니다. |
| "시계 앱의 세계 시계에 도쿄와 런던을 추가해 줘." | 각 도시를 찾아 목록에 추가하고 둘 다 들어갔는지 확인합니다. |
| "내 이력서를 찾아서 이 채용 공고에 지원해 줘." | 파일을 찾고 양식의 모든 칸을 채우고 파일을 첨부해 제출합니다. 제출하기 전에 양식을 확인하세요. |
| "Mail에서 인증 코드를 복사해 로그인 창에 붙여넣어 줘." | 보이는 창들을 읽고 창을 전환하며 텍스트를 복사해 필드에 붙여넣습니다. |

## 안전하게 사용하기

<Warning>
컴퓨터 사용은 실제 앱과 실제 데이터를 다룹니다. Enconvo가 양식을 제출하거나 계정 설정을 바꾸거나 파일을 삭제하거나 구매 또는 메시지를 전송하도록 허용하기 전에 화면을 확인하세요.
</Warning>

- 가능하면 대상 창을 화면에 띄워 두세요.
- 구체적인 목표와 제한 조건을 함께 알려 주세요.
- 비공개 페이지나 금융 페이지에서 행동하기 전에는 내용을 검토하세요.
- 화면에 진행되는 내용이 요청한 바가 아니면 작업을 중지하세요.

## 설정

| 설정 | 위치 | 변경 내용 |
| --- | --- | --- |
| **앱 접근** | **설정 → 컴퓨터 사용** | 컴퓨터 사용이 보고 사용할 수 있는 앱을 정합니다([사용할 수 있는 앱 선택](#사용할-수-있는-앱-선택) 참고). |
| **화면 속 화면 창** | **설정 → 컴퓨터 사용** | 화면 모서리에 앱 창의 실시간 보기를 띄우는 조건을 정합니다: **항상**(기본값), **내가 필요할 때만**, **끔**([화면 속 화면](/ko/features/picture-in-picture) 참고). |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| Enconvo가 앱 컨트롤을 보지 못함 | Enconvo에 손쉬운 사용 권한이 있는지 확인한 뒤 Enconvo와 해당 앱을 재시작하세요. 일부 앱은 노출하는 컨트롤이 적을 수 있으며, 이 경우에도 스크린샷과 위치 기반 클릭은 작동할 수 있습니다. |
| 클릭이 잘못된 앱으로 감 | 시작하기 전에 대상 앱을 맨 앞으로 가져오세요. 창이 여러 개 열려 있다면 요청에 앱이나 창 이름을 적으세요. |
| 파일 선택기에서 파일 선택이 실패함 | 파일이 실제로 존재하고 선택기가 해당 파일 형식을 허용하는지 확인하세요. iCloud나 네트워크 드라이브의 파일은 다운로드가 끝날 때까지 기다리세요. |
| 에이전트가 앱을 사용할 수 없다고 말함 | **설정 → 컴퓨터 사용 → 앱 접근**에서 해당 앱이 차단되었거나 허용 목록에 없습니다. 목록을 바꾸거나 에이전트가 요청할 때 허용하세요. |
| 작업이 너무 빨리 다음 단계로 넘어감 | "저장 버튼이 활성화될 때까지 기다려 줘" 또는 "표가 다시 로드된 뒤에 계속해 줘"처럼 화면에서 확인할 수 있는 조건을 기다리라고 요청하세요. |

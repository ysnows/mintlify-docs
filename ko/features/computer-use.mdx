컴퓨터 사용을 켜면 텍스트만으로는 부족한 작업에서 Enconvo가 Mac의 앱을 직접 조작합니다. 맨 앞의 앱을 보고, 보이는 컨트롤을 찾아 클릭하거나 입력란에 입력하고, 목록을 스크롤하고, 항목을 드래그하고, 파일을 선택하고, 앱 메뉴를 사용하며, 앱이 반응할 때까지 기다린 뒤 다음 단계로 넘어갑니다.

다음과 같은 데스크탑 작업에 사용하세요.

- Mac 앱의 양식 채우기
- 파일 선택 창에서 파일 고르기
- 설정 창 안에서 이동하기
- 도구 모음 버튼이나 메뉴 항목 클릭하기
- 여러 단계로 이루어진 앱 작업 처리하기
- 현재 창에 보이는 내용 읽기

웹사이트의 경우 브라우저 사용이 Enconvo 브라우저 확장 프로그램(브라우저 도우미)을 통해 사용자의 브라우저 안에서 동작합니다. Safari처럼 확장 프로그램이 없는 브라우저에서는 컴퓨터 사용이 화면에서 직접 클릭하고 입력합니다.

아래 동영상 튜토리얼은 5분 안에 컴퓨터 사용과 브라우저 사용을 설정하고 처음부터 끝까지 사용해 봅니다. 기능을 켜고 두 가지 권한을 허용하고, Chrome에 브라우저 확장 프로그램을 추가하고, 오른쪽 Option 키를 누른 채 요청하고, Safari와 Chrome과 Mac 앱에서 작업하는 모습을 보고, 전체 작업을 맡겨 봅니다.

## 컴퓨터 사용 켜기

컴퓨터 사용에는 두 가지 macOS 권한이 필요합니다. 클릭하고 입력하기 위한 손쉬운 사용과, 화면을 보기 위한 화면 기록입니다.

<Steps>
  <Step title="컴퓨터 사용 설정 열기">
    **설정 → 컴퓨터 사용**을 열고 스위치가 켜져 있는지 확인하세요.
  </Step>
  <Step title="두 권한 확인">
    **손쉬운 사용**과 **화면 기록**이 모두 **활성화됨**으로 표시되어야 합니다.
  </Step>
  <Step title="빠진 권한 허용">
    하나가 **필수**로 표시되면 옆의 **열기**를 클릭한 다음, **시스템 설정 → 개인정보 보호 및 보안**에서 해당 권한 아래의 Enconvo를 켜세요. Enconvo로 돌아와 **새로고침**을 클릭하세요. 상태가 여전히 바뀌지 않으면 Enconvo를 종료했다가 다시 여세요.
  </Step>
</Steps>

## 브라우저 확장 프로그램 추가

<Steps>
  <Step title="브라우저 사용 설정 열기">
    **설정 → 브라우저 사용**을 여세요. **브라우저 확장 프로그램**에 확장 프로그램이 설치된 브라우저가 연결 상태와 함께 표시됩니다.
  </Step>
  <Step title="브라우저 연동 앱 설치">
    **브라우저 연동 앱 설치**를 클릭하세요. Chrome 웹 스토어에서 확장 프로그램 페이지가 열립니다.
  </Step>
  <Step title="확장 프로그램 추가">
    **Chrome에 추가**를 클릭한 다음 **확장 프로그램 추가**를 클릭하세요. 브라우저의 확장 프로그램 메뉴를 열고 확장 프로그램을 고정해 도구 모음에 남겨 두세요.
  </Step>
  <Step title="연결 확인">
    **설정 → 브라우저 사용**으로 돌아가면 브라우저가 **연결됨**으로 표시됩니다. Edge, Arc, Brave도 같은 방식으로 설정합니다.
  </Step>
</Steps>

확장 프로그램의 팝업, 지원 브라우저, 문제 해결은 [브라우저 확장 프로그램](/ko/features/browser-extension)을 참고하세요.

## 작업 실행하기

클릭 목록이 아니라 원하는 결과를 요청하세요.

<Steps>
  <Step title="대상 앱 열기">
    Enconvo가 작업할 앱이나 창을 맨 앞으로 가져오세요.
  </Step>
  <Step title="오른쪽 Option 키를 누른 채 요청하기">
    오른쪽 **Option** 키를 누른 채 필요한 일을 말한 다음 손을 떼세요. 앱과 페이지를 지정하세요. 예: "Safari에서 이 페이지의 가장 저렴한 직항 항공편을 찾아 줘" 또는 "설정 패널을 열고 로그인 시 실행을 꺼 줘." 에이전트에게 요청을 직접 입력해도 됩니다.
  </Step>
  <Step title="작업 지켜보기">
    Enconvo가 작업 중인 창의 가장자리를 따라 은은한 빛이 흐르고, 클릭할 때마다 빛의 물결이 퍼져 나가며, Dynamic Island에 각 단계가 표시됩니다. 창이 보이지 않을 때는 [화면 속 화면](/ko/features/picture-in-picture) 창이 화면 구석에서 그 모습을 실시간으로 보여 줍니다. 언제든 직접 이어받거나 작업을 중지할 수 있습니다.
  </Step>
  <Step title="민감한 단계 확인">
    삭제, 금융, 계정, 권한 변경에 해당하는 동작은 Enconvo가 계속하기 전에 해당 단계를 확인하세요. 키보드 단축키도 마찬가지입니다. 삭제, 전송, 결제, 앱 종료, 로그아웃을 하는 단축키 전에는 Enconvo가 먼저 묻습니다.
  </Step>
  <Step title="결과 받기">
    Enconvo는 앱을 보고, 동작하고, 결과를 기다리며, 작업이 끝나거나 사용자의 확인이 필요할 때까지 계속합니다. 끝나면 결과를 알려 줍니다.
  </Step>
</Steps>

### 브라우저에서

> "후지산과 레이니어산의 위키백과 페이지를 열고, 어느 쪽이 더 높은지 알려 줘."

확장 프로그램이 연결되어 있으면 브라우저 사용이 백그라운드에서 자체 탭을 열기 때문에 지금 보고 있는 페이지는 그대로 유지됩니다. 확장 프로그램이 작업하는 동안 브라우저에는 페이지 위쪽에 막대가 표시되는데, 이를 취소하지 마세요. 에이전트의 턴이 끝나면 에이전트가 연 탭은 닫힙니다. 결과로 넘겨준 페이지, 사용자에게 넘긴 탭, 고정해 둔 탭, 지금 보고 있는 탭은 열려 있으며, 사용자의 탭은 절대 닫히지 않습니다.

## 컴퓨터 사용으로 할 수 있는 일

| 동작 | 예시 |
|--------|----------|
| **앱 상태 확인** | 현재 창, 컨트롤, 메뉴 항목, 선택한 텍스트, 보이는 입력란 읽기 |
| **클릭 및 더블클릭** | 버튼, 사이드바 행, 도구 모음 항목, 메뉴 명령, 좌표 클릭 |
| **입력 및 키 누르기** | 입력란 채우기, 양식 제출, **⌘S** 같은 단축키 사용 |
| **스크롤** | 목록, 표, 설정 패널, 긴 문서 넘겨 보기 |
| **드래그** | 앱이 지원하는 경우 파일, 행, 슬라이더, 선택 핸들 드래그 |
| **파일 선택 창 사용** | 열기 및 저장 대화상자에서 파일과 폴더 선택 |
| **동작 후 대기** | 클릭, 이동, 로딩 단계 후 앱을 다시 확인 |
| **앱에 로그인** | 에이전트가 암호를 보지 못한 채, 저장된 사용자 이름과 암호를 앱의 로그인 화면에 입력. [자격 증명](/ko/configuration/credentials)을 참고하세요. |

서로 다른 앱에서 작업하는 하위 에이전트처럼, 여러 에이전트가 동시에 컴퓨터 사용을 쓸 수 있습니다. 각자 자기 앱에서 동시에 동작하며, 같은 앱에서 작업하는 에이전트끼리만 순서를 지킵니다. 앱의 다른 창이 앞에 있어도 동작은 에이전트가 의도한 창으로 전달됩니다.

## 사용할 수 있는 앱 고르기

**설정 → 컴퓨터 사용 → 앱 접근**에서 컴퓨터 사용이 보고 사용할 수 있는 앱을 정합니다. **모드**를 고르세요.

- **다음을 제외한 모든 앱**: 컴퓨터 사용은 **차단된 앱**에 있는 앱은 건드리지 않고 나머지 앱은 모두 사용합니다.
- **이 앱만**: 컴퓨터 사용은 **허용된 앱**에 있는 앱만 사용합니다. **에이전트가 다른 앱이 필요할 때**에서 **나에게 묻기**를 고르면 에이전트가 다른 앱이 필요할 때 "컴퓨터 사용이 이 앱을 사용하도록 허용할까요?"라는 질문에 답하게 되고, **거부**를 고르면 거부합니다.

**앱 추가**를 클릭하면 지금 열려 있는 앱이나 응용 프로그램 폴더에서 앱을 추가할 수 있습니다. 차단된 앱은 스크린샷에서 제외됩니다. 암호 관리자와 시스템 로그인 창은 항상 차단되며 **암호와 시스템 확인 창**으로 표시됩니다. PopBar, 선택한 텍스트, 받아쓰기는 각자의 설정을 따로 유지합니다.

## 예시

| 요청 | Enconvo가 하는 일 |
| --- | --- |
| "이 파일 선택 창에서 데스크탑의 가장 최근 스크린샷을 선택해 줘." | 파일 선택 창을 보고, 폴더로 이동해 파일을 선택하고, 대화상자를 확인합니다. |
| "이 앱의 환경설정을 열고 알림을 꺼 줘." | 앱의 메뉴를 사용해 설정을 찾고, 끄고, 결과를 확인합니다. |
| "시계 앱에서 세계 시계에 도쿄와 런던을 추가해 줘." | 각 도시를 찾아 목록에 추가하고, 둘 다 추가되었는지 확인합니다. |
| "내 이력서를 찾아서 이 채용 공고에 지원해 줘." | 파일을 찾고, 양식의 모든 입력란을 채우고, 파일을 첨부하고, 제출합니다. 제출하도록 두기 전에 양식을 검토하세요. |
| "Mail에서 인증 코드를 복사해 로그인 창에 붙여넣어 줘." | 보이는 창을 읽고, 창 사이를 전환하고, 텍스트를 복사해 입력란에 붙여넣습니다. |

## 안전하게 사용하기

<Warning>
컴퓨터 사용은 실제 앱과 실제 데이터에서 동작합니다. Enconvo가 양식을 제출하거나, 계정 설정을 바꾸거나, 파일을 삭제하거나, 구매하거나, 메시지를 보내기 전에 화면을 확인하세요.
</Warning>

- 가능하면 대상 창이 보이도록 두세요.
- 구체적인 목표와 제한 사항을 알려 주세요.
- 개인 정보나 금융 관련 페이지에서 Enconvo가 동작하기 전에 검토하세요.
- 화면에 보이는 내용이 요청한 것과 더 이상 맞지 않으면 작업을 중지하세요.

## 설정

| 설정 | 위치 | 변경되는 내용 |
| --- | --- | --- |
| **앱 접근** | **설정 → 컴퓨터 사용** | 컴퓨터 사용이 보고 사용할 수 있는 앱입니다. [사용할 수 있는 앱 고르기](#사용할-수-있는-앱-고르기)를 참고하세요. |
| **화면 속 화면 창** | **설정 → 컴퓨터 사용** | 앱 창의 실시간 화면을 화면 구석에 표시하는 시점입니다. **항상**(기본값), **내가 필요할 때만**, **끔** 중에서 고릅니다. [화면 속 화면](/ko/features/picture-in-picture)을 참고하세요. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| Enconvo가 앱의 컨트롤을 볼 수 없음 | Enconvo에 손쉬운 사용 권한이 있는지 확인한 다음 Enconvo와 앱을 다시 시작하세요. 일부 앱은 다른 앱보다 컨트롤을 덜 노출하지만, 스크린샷과 위치 기반 클릭은 여전히 동작할 수 있습니다. |
| 클릭이 엉뚱한 앱으로 감 | 시작하기 전에 앱을 맨 앞으로 가져오세요. 창이 여러 개 열려 있으면 요청에 앱이나 창을 지정하세요. |
| 파일 선택 창에서 파일 선택이 실패함 | 파일이 존재하고 선택 창이 해당 파일 형식을 허용하는지 확인하세요. iCloud나 네트워크 드라이브의 파일은 다운로드가 끝날 때까지 기다리세요. |
| 에이전트가 앱을 사용할 수 없다고 함 | 앱이 **설정 → 컴퓨터 사용 → 앱 접근**에서 차단되었거나 허용 목록에 없습니다. 목록을 바꾸거나, 에이전트가 앱 사용을 요청할 때 질문에 답하세요. |
| 작업이 너무 빨리 넘어감 | "저장 버튼이 활성화될 때까지 기다려" 또는 "표가 다시 로드된 후에 계속해"처럼 눈에 보이는 것을 기준으로 Enconvo에게 기다리라고 요청하세요. |

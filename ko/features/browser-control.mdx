---
title: "브라우저 사용"
description: "브라우저에 이미 로그인된 상태 그대로, 에이전트가 실제 브라우저 탭을 읽고 작업하도록 하세요."
---

브라우저 사용을 켜면 에이전트가 Enconvo Companion 확장 프로그램이 연결된 브라우저 탭에서 작업할 수 있습니다. 페이지를 읽고, 컨트롤을 클릭하고, 입력란을 채우고, 결과를 확인하고, 탭을 관리하며, 이 모든 작업에 브라우저에 이미 로그인된 상태가 그대로 쓰입니다. 로그인해 둔 웹사이트가 필요한 작업에 사용하세요.

## 설정

<Steps>
  <Step title="확장 프로그램 설치">
    지원되는 Chromium 기반 브라우저에서 [Chrome 웹 스토어의 Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd)을 설치하거나, **설정 → 브라우저 사용**에서 **브라우저 연동 앱 설치**를 클릭하세요. 다른 브라우저에서는 해당 브라우저용으로 만든 확장 프로그램 패키지를 사용하세요.
  </Step>
  <Step title="두 앱을 계속 실행">
    Enconvo와 브라우저를 열어 두세요.
  </Step>
  <Step title="연결 확인">
    확장 프로그램 아이콘을 클릭하세요. 팝업에 **연결됨**과 브라우저 이름이 표시됩니다.
  </Step>
  <Step title="접근 확인">
    사용할 에이전트에 브라우저 도구가 있는지 확인하고, 확장 프로그램이 묻는 웹사이트는 승인하세요.
  </Step>
  <Step title="읽기 전용 작업으로 시도">
    "이 페이지를 읽고 핵심 내용을 요약해 줘."처럼 아무것도 바꾸지 않는 작업부터 시작하세요.
  </Step>
</Steps>

Safari는 Chromium 확장 프로그램을 사용하지 않습니다. Safari에서는 [컴퓨터 사용](/ko/features/computer-use)이 화면에서 직접 클릭하고 입력하므로, 모든 브라우저에서 같은 작업을 할 수 있는 것은 아닙니다. 팝업, 연결된 브라우저, 탭 지정, 웹사이트 승인은 [브라우저 확장 프로그램](/ko/features/browser-extension)을 참고하세요.

## 특정 탭에서 작업하기

요청에 브라우저와 페이지를 지정하세요.

> Edge에서 현재 열린 문서 탭을 읽고 설정 단계 세 가지를 나열해 줘. 페이지는 열어 둬.

에이전트는 페이지를 읽고, 요소를 고르고, 동작한 뒤, 무엇이 바뀌었는지 확인합니다. 페이지 이동이나 실시간 업데이트 후에는 페이지 요소가 바뀔 수 있습니다. 에이전트가 요소를 놓치면 페이지를 다시 살펴보라고 요청하세요.

에이전트가 보이지 않는 탭에서 작업하는 동안에는 [화면 속 화면](/ko/features/picture-in-picture) 창이 화면 구석에서 그 모습을 실시간으로 보여 줍니다. 클릭하면 해당 탭으로 이동해 직접 이어받을 수 있습니다.

## 작업이 끝나면

에이전트가 연 탭은 해당 턴이 끝나면 닫힙니다. 다음 탭은 그대로 열려 있습니다.

- 에이전트가 결과로 넘겨준 페이지
- 에이전트가 사용자에게 넘긴 탭
- 고정해 둔 탭
- 지금 보고 있는 탭

사용자의 탭은 절대 닫히지 않습니다.

## 할 수 있는 일

| 영역 | 예시 |
| --- | --- |
| 이동 | URL 열기, 뒤로 또는 앞으로 가기, 새로고침, 조건이 충족될 때까지 대기 |
| 읽기 | 페이지 상태, 보이는 텍스트, 속성, 스크린샷, 선택한 내용 |
| 상호작용 | 클릭, 입력, 채우기, 선택, 키 누르기, 스크롤, 드래그 |
| 브라우저 정리 | 탭, 창, 연결된 세션 보기 및 관리 |
| 고급 도구 | 페이지 평가, 쿠키, 스토리지, 방문 기록, 브라우저별 검사 |

### 페이지 전체 캡처

"이 페이지 전체를 스크린샷으로 데스크탑에 저장해 줘."처럼 웹 페이지 전체를 캡처해 달라고 요청하세요. 요청한 위치에 페이지 고유의 해상도로, 에이전트의 커서 없이 PNG 파일로 저장됩니다.

### 로그인과 사람 확인

작업이 사이트의 로그인 페이지에 이르면 카드가 사용자 이름과 암호를 한 번 물어봅니다. Enconvo가 해당 사이트에서만 이를 입력하며, 에이전트는 암호를 볼 수 없습니다. [자격 증명](/ko/configuration/credentials)을 참고하세요. 페이지에 사람 확인이 나타나면 에이전트가 탭을 사용자에게 넘길 수 있습니다. 해당 탭에서 로그인하거나 확인을 통과한 다음 **에이전트에게 돌려주기**를 클릭해 다시 넘기세요.

무엇이 가능한지는 브라우저, 페이지, 확장 프로그램 버전, 켜 둔 도구에 따라 다릅니다. `chrome://` 같은 브라우저 페이지와 기타 제한된 콘텐츠는 접근할 수 없을 수 있습니다.

<Warning>
브라우저 사용은 실제 계정에서 동작합니다. 작업이 초안만 준비해야 하는지, 제출까지 해야 하는지 알려 주세요.
</Warning>

## 설정

| 설정 | 위치 | 변경되는 내용 |
| --- | --- | --- |
| **기본 브라우저** | **설정 → 브라우저 사용**, 이어서 **⋯** 메뉴의 **설정** | 브라우저를 지정하지 않았을 때 작업에 사용되는 브라우저입니다. **자동(시스템 기본값)**은 Mac의 기본 브라우저를 따릅니다. |
| **브라우저 확장 프로그램** | **설정 → 브라우저 사용** | 확장 프로그램이 설치된 브라우저를 **연결됨** 또는 **연결 해제됨** 상태와 함께 보여 줍니다. |
| **화면 속 화면 창** | **설정 → 브라우저 사용** | 에이전트 탭의 실시간 화면을 화면 구석에 표시하는 시점입니다. **항상**(기본값), **내가 필요할 때만**, **끔** 중에서 고릅니다. [화면 속 화면](/ko/features/picture-in-picture)을 참고하세요. |

작업 요청에 브라우저 이름을 직접 적을 수도 있습니다.

개발자를 위해, `browser-use/status` Local API 경로가 연결 상태를 알려 주며, **설정 → API**에서 설치된 경로와 스키마를 확인할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결되지 않음 | 확장 프로그램이 켜져 있고 Enconvo가 실행 중인지 확인하고 팝업을 살펴보세요. 확장 프로그램은 11225 포트를 통해 이 Mac의 Enconvo에 연결됩니다. |
| 브라우저나 탭이 다름 | 브라우저와 페이지를 지정하고, 페이지를 다시 살펴보라고 요청하세요. |
| 클릭이나 입력이 실패함 | 지금 상태의 페이지를 살펴보세요. 대화상자, 페이지 이동, 임베드된 프레임 때문에 대상이 옮겨졌을 수 있습니다. |
| 스크린샷이 비어 있음 | 탭을 앞으로 가져오고 페이지 로딩이 끝날 때까지 기다리세요. |
| 웹사이트가 로그인을 요구함 | 평소처럼 사이트에 로그인하세요. 브라우저에 로그인되어 있다고 해서 모든 사이트의 세션이 아직 유효한 것은 아닙니다. |

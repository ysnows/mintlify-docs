---
title: "브라우저 사용"
description: "브라우저에 이미 있는 로그인으로, 에이전트가 실제 브라우저 탭을 읽고 작업하게 합니다."
---

브라우저 사용은 에이전트가 Enconvo Companion 확장이 연결된 브라우저 탭에서 작업하게 합니다. 페이지를 읽고, 컨트롤을 클릭하고, 칸을 채우고, 결과를 확인하며, 탭을 관리할 수 있습니다. 모두 브라우저에 이미 있는 로그인으로 합니다. 로그인한 웹사이트가 필요한 작업에 씁니다.

## 설정

<Steps>
  <Step title="확장 설치">
    지원되는 Chromium 브라우저에 [Chrome 웹 스토어에서 Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd)을 설치하거나, **설정 → 브라우저 사용**에서 **브라우저 연동 앱 설치**를 클릭합니다. 다른 브라우저는 그 브라우저용 확장 패키지를 씁니다.
  </Step>
  <Step title="둘 다 실행 유지">
    Enconvo와 브라우저를 열어 둡니다.
  </Step>
  <Step title="연결 확인">
    확장 아이콘을 클릭합니다. 팝업에 **연결됨**과 브라우저 이름이 표시됩니다.
  </Step>
  <Step title="접근 확인">
    쓸 에이전트에 브라우저 도구가 있는지 확인하고, 확장이 묻는 웹사이트를 승인합니다.
  </Step>
  <Step title="읽기 전용 작업으로 시험">
    “이 페이지를 읽고 요점을 요약해 줘.”처럼 아무것도 바꾸지 않는 일로 시작합니다.
  </Step>
</Steps>

Safari는 Chromium 확장을 쓰지 않습니다. Safari에서는 [컴퓨터 사용](/ko/features/computer-use)이 화면을 클릭하고 입력하므로, 모든 브라우저가 같은 일을 할 수 있는 것은 아닙니다. 팝업, 연결된 브라우저, 탭 지정, 웹사이트 승인은 [브라우저 확장](/ko/features/browser-extension)을 보세요.

## 특정 탭에서 작업

요청에 브라우저와 페이지를 지정합니다.

> Edge에서 현재 문서 탭을 읽고 설정 단계 세 가지를 나열해 줘. 페이지는 열어 둬.

에이전트는 페이지를 읽고, 요소를 고르고, 행동한 다음 무엇이 바뀌었는지 확인합니다. 페이지 요소는 이동이나 실시간 업데이트 뒤에 바뀔 수 있습니다. 에이전트가 요소를 놓치면 페이지를 다시 봐 달라고 하세요.

에이전트가 보이지 않는 탭에서 작업하는 동안 [화면 속 화면](/ko/features/picture-in-picture) 창이 화면 모서리에 실시간으로 보여 줍니다. 클릭하면 그 탭으로 가서 직접 맡을 수 있습니다.

## 작업이 끝나면

에이전트가 연 탭은 차례가 끝나면 닫힙니다. 다음은 열려 있습니다.

- 에이전트가 결과로 건넨 페이지
- 당신에게 넘긴 탭
- 고정한 탭
- 보고 있는 탭

본인 탭은 닫히지 않습니다.

## 할 수 있는 일

| 영역 | 예 |
| --- | --- |
| 탐색 | URL 열기, 뒤로 또는 앞으로, 새로고침, 조건까지 대기 |
| 읽기 | 페이지 상태, 보이는 텍스트, 속성, 스크린샷, 선택한 내용 |
| 상호작용 | 클릭, 입력, 채우기, 선택, 키 누르기, 스크롤, 드래그 |
| 브라우저 정리 | 탭, 창, 연결된 세션을 보고 관리 |
| 고급 도구 | 페이지 평가, 쿠키, 저장소, 기록, 브라우저별 검사 |

### 페이지 전체 캡처

“이 페이지 전체를 스크린샷으로 데스크톱에 저장해 줘.”처럼 웹 페이지 전체를 캡처하라고 에이전트에게 부탁합니다. 요청한 곳에 PNG 파일로 저장하며, 페이지 자체 해상도이고 에이전트 커서는 없습니다.

### 로그인과 사람 확인

작업이 사이트의 로그인 페이지에 닿으면 카드가 사용자 이름과 비밀번호를 한 번 묻습니다. Enconvo는 그 사이트에만 채우며, 에이전트는 비밀번호를 보지 않습니다. [인증 정보](/ko/configuration/credentials)를 보세요. 페이지에 사람 확인이 나오면 에이전트가 탭을 넘길 수 있습니다. 그 탭에서 로그인하거나 확인을 푼 다음 **에이전트에게 돌려주기**를 클릭해 다시 넘깁니다.

무엇이 되는지는 브라우저, 페이지, 확장 버전, 켠 도구에 따릅니다. `chrome://` 같은 브라우저 페이지와 다른 제한된 콘텐츠는 닿지 못할 수 있습니다.

<Warning>
브라우저 사용은 실제 계정에서 동작합니다. 작업이 초안만 준비해야 하는지, 제출까지 해야 하는지 말하세요.
</Warning>

## 설정

| 설정 | 위치 | 바뀌는 것 |
| --- | --- | --- |
| **기본 브라우저** | **설정 → 브라우저 사용**, 그다음 **⋯** 메뉴의 **설정** | 지정하지 않았을 때 작업이 쓰는 브라우저입니다. **자동(시스템 기본)**은 Mac의 기본 브라우저를 따릅니다. |
| **브라우저 확장 프로그램** | **설정 → 브라우저 사용** | 확장이 있는 브라우저를 나열하며, 각각 **연결됨** 또는 **연결 해제됨**입니다. |
| **화면 속 화면 창** | **설정 → 브라우저 사용** | 에이전트 탭의 실시간 보기가 화면 모서리에 언제 나오는지입니다. **항상**(기본), **내가 필요할 때만**, **끔**입니다. [화면 속 화면](/ko/features/picture-in-picture)을 보세요. |

작업 자체에서 브라우저를 지정할 수도 있습니다.

개발자의 경우 `browser-use/status` Local API 라우트가 연결 상태를 보고하고, **설정 → API**가 설치된 라우트와 스키마를 나열합니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결되지 않음 | 확장이 켜져 있고 Enconvo가 실행 중인지 확인하고 팝업을 봅니다. 확장은 이 Mac의 Enconvo에 포트 11225로 연결됩니다. |
| 잘못된 브라우저나 탭 | 브라우저와 페이지를 지정하고 페이지를 다시 봐 달라고 합니다. |
| 클릭이나 채우기 실패 | 지금 페이지를 봅니다. 대화상자, 이동, 임베드된 프레임이 대상을 옮겼을 수 있습니다. |
| 스크린샷이 비어 있음 | 탭을 앞으로 가져오고 페이지가 로드될 때까지 기다립니다. |
| 웹사이트가 로그인을 요구함 | 평소처럼 사이트에 로그인합니다. 브라우저에 로그인했다고 모든 사이트 세션이 유효한 것은 아닙니다. |

title: "Appshots"
description: "단축키 하나로 맨 앞의 앱 창을 다음 질문에 추가하세요."
---

Appshots는 맨 앞에 있는 앱의 창을 컨텍스트로 채팅에 추가합니다. 지식 베이스에 저장하지 않고 화면에 있는 내용에 대해 질문하고 싶을 때 사용하세요.

## 앱 창 캡처하기

1. 질문하려는 앱을 맨 앞으로 가져옵니다.
2. Appshots 단축키를 누릅니다. Appshots는 **설정 → Appshots**의 **단축키**에서 설정하기 전까지는 단축키가 없습니다.
3. SmartBar, 채팅 창, 앱 사이드바 중 하나가 앞에 열려 있으면 창이 그곳으로 전달됩니다. 그렇지 않으면 Dynamic Island로 전달됩니다. 짧은 셔터 소리가 재생됩니다.
4. 첨부된 창을 확인한 다음 "이 창의 오류를 설명해 줘."처럼 구체적인 질문을 합니다.

## 설정

**설정 → Appshots**를 엽니다.

| 설정 | 하는 일 |
| --- | --- |
| **Appshots 활성화** | 단축키로 맨 앞의 앱 창을 추가할 수 있게 합니다. 기본으로 켜져 있습니다. |
| **소리 녹음** | Appshot이 추가될 때 짧은 셔터 소리를 재생합니다. 소리는 캡처를 알려 주는 것이며, 보내기 전에 첨부된 내용을 확인하세요. |
| **단축키** | 창을 추가하는 단축키입니다. 기본값은 없습니다. 양쪽 **Option** 키를 함께 누르는 것 같은 보조 키 조합이나 일반 단축키를 사용할 수 있습니다. |

## 알맞은 캡처 도구 고르기

| 목적 | 사용할 기능 |
| --- | --- |
| 현재 앱 창에 대해 질문 | Appshots |
| 질문하기 전에 영역을 강조 | [화면 낙서](/ko/features/screen-doodle) |
| 나중에 검색할 수 있도록 현재 앱의 콘텐츠 저장 | [빠른 캡처](/ko/features/quick-capture) |
| 이미지에서 텍스트 추출 | [OCR](/ko/ai/ocr) |

캡처한 콘텐츠는 요청에 사용하는 모델로 전송될 수 있습니다. 컨텍스트를 추가하는 다른 방법은 [컨텍스트 인식](/ko/features/context-awareness)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 컨텍스트가 나타나지 않음 | **설정 → 권한**, 특히 화면 기록과 손쉬운 사용을 확인하세요. |
| 엉뚱한 창이 캡처됨 | 대상 앱을 다시 맨 앞으로 가져오세요. Appshots는 다른 앱의 창을 캡처하며 설정 같은 Enconvo 자체의 창은 캡처하지 않습니다. |
| 단축키가 아무 반응이 없음 | **Appshots 활성화**가 켜져 있고 **단축키**가 설정되어 있는지 확인하세요. |
| 단축키가 다른 동작을 함 | 다른 앱이 같은 키를 사용합니다. **설정 → Appshots**에서 **단축키**를 바꾸세요. |

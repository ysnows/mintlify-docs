---

Appshots는 맨 앞에 있는 앱 창을 채팅 컨텍스트로 추가합니다. 지식 베이스에 저장하지 않고 화면에 보이는 내용에 대해 바로 질문하고 싶을 때 사용하세요.

## 앱 창 캡처하기

1. 질문하고 싶은 앱을 맨 앞으로 가져옵니다.
2. Appshots 단축키를 누릅니다. **설정 → Appshots**의 **단축키**에서 지정하기 전까지는 기본 단축키가 없습니다.
3. SmartBar, 채팅 창, 앱 사이드바 중 하나가 맨 앞에 열려 있으면 해당 창으로 전달되고, 그렇지 않으면 Dynamic Island로 전달됩니다. 이때 짧은 셔터 소리가 재생됩니다.
4. 창이 첨부되었는지 확인한 뒤 "이 창의 오류를 설명해 줘"처럼 구체적인 질문을 입력하세요.

## 설정

**설정 → Appshots**를 엽니다.

| 설정 | 기능 |
| --- | --- |
| **Appshots 활성화** | 단축키로 맨 앞 앱 창을 추가할 수 있게 합니다. 기본값은 켜짐입니다. |
| **소리 녹음** | Appshot이 추가될 때 짧은 셔터 소리를 재생합니다. 소리는 캡처 여부를 알려 주지만, 전송 전에 첨부 상태를 한 번 더 확인하세요. |
| **단축키** | 창을 추가하는 단축키입니다. 기본값은 없음입니다. 양쪽 **Option** 키를 동시에 누르는 조합이나 일반 단축키를 지정할 수 있습니다. |

## 상황에 맞는 캡처 도구 고르기

| 목적 | 사용할 도구 |
| --- | --- |
| 현재 앱 창에 대해 질문하기 | Appshots |
| 질문하기 전에 특정 영역에 표시하기 | [화면 낙서](/ko/features/screen-doodle) |
| 나중에 검색할 수 있도록 현재 앱의 내용 저장하기 | [빠른 캡처](/ko/features/quick-capture) |
| 이미지에서 텍스트 추출하기 | [OCR](/ko/ai/ocr) |

캡처된 콘텐츠는 요청에 사용하는 모델로 전송될 수 있습니다. 컨텍스트를 추가하는 다른 방법은 [컨텍스트 인식](/ko/features/context-awareness)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 컨텍스트가 나타나지 않음 | **설정 → 권한**에서 특히 화면 기록과 손쉬운 사용 권한을 확인하세요. |
| 잘못된 창이 캡처됨 | 대상 앱을 다시 맨 앞으로 가져오세요. Appshots는 설정 창 같은 Enconvo 자체 창이 아니라 다른 앱의 창을 캡처합니다. |
| 단축키를 눌러도 아무 일도 일어나지 않음 | **Appshots 활성화**가 켜져 있고 **단축키**가 설정되어 있는지 확인하세요. |
| 단축키가 다른 동작을 실행함 | 다른 앱이 같은 키 조합을 사용하고 있습니다. **설정 → Appshots**에서 **단축키**를 변경하세요. |

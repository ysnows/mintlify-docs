데스크톱 펫은 데스크톱에 있는 작은 애니메이션 캐릭터입니다. 에이전트가 하는 일을 그대로 보여 주고, 실시간 세션 카드를 표시할 수 있으며, 주의가 필요한 세션으로 안내합니다. 클릭하면 질문하거나 Enconvo를 열 수 있습니다. 에이전트에게 대화를 위한 캐릭터와 목소리를 주는 [아바타](/ko/features/avatar)와는 별개입니다.

다른 용도에는 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 긴 대화와 파일은 [채팅 창](/ko/ai/chat), 앱 하나 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에는 [PopBar](/ko/features/popbar), 화면 상단의 간결한 입력창은 [Dynamic Island](/ko/features/dynamic-island)를 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

## 펫 고르기

1. **설정 → 펫**을 여세요.
2. **내 반려동물**에서 캐릭터를 고르거나 **갤러리**에서 찾으세요.
3. **펫 깨우기**를 클릭해 데스크톱에 표시하세요.
4. **탭하면 열기**를 펫을 클릭했을 때 띄울 항목으로 설정하세요.
5. **세션 카드 표시**를 켜거나 끄고 **펫 크기**를 조절하세요.
6. 데스크톱으로 돌아가 펫을 클릭하세요. 4단계에서 고른 항목이 열립니다.

## 설정

| 설정 | 바뀌는 내용 |
| --- | --- |
| **펫 깨우기** / **펫 숨기기** | 데스크톱에서 펫을 표시하거나 숨깁니다. |
| **탭하면 열기** | 펫을 클릭하면 띄우는 항목입니다. **질문 상자**(기본값), **Dynamic Island**, **채팅 창**, **Smart Bar** 중에서 고르세요. |
| **답변할 에이전트** | 펫에게 물은 내용에 답하는 에이전트입니다. 질문 상자에서도 바꿀 수 있습니다. |
| **세션 카드** | 펫 아래에 표시되는 실시간 세션 상태 카드입니다. |
| **펫 크기** | 펫의 크기입니다. |

## 사용자 지정 펫

**내 반려동물** 탭의 **사용자 지정 펫**에는 펫 패키지를 보관하는 폴더가 표시됩니다. **폴더 열기**를 클릭하고, 지원되는 형식의 펫 패키지를 추가한 다음, **내 반려동물**에서 펫을 선택하세요. 캐릭터 이미지만으로는 애니메이션 펫 패키지가 아닙니다.

펫을 제거하려면 카드의 **제거**를 클릭하세요. 라이브러리에서 패키지가 삭제되며, 갤러리에서 다시 설치할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 펫이 데스크톱에 없습니다 | **펫 깨우기**를 클릭하고, **내 반려동물**에서 펫이 선택되어 있는지, **펫 크기**를 확인하세요. |
| 펫을 클릭하면 엉뚱한 창이 열립니다 | **탭하면 열기**를 바꾸세요. |
| 음성 대화나 에이전트 하나를 위한 캐릭터가 필요합니다 | 대신 [아바타](/ko/features/avatar)를 사용하세요. |

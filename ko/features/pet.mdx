데스크톱 펫은 바탕화면에 띄워 두는 작은 애니메이션 캐릭터입니다. 에이전트가 무엇을 하고 있는지 반영하고 실시간 세션 카드를 보여 줄 수 있으며, 주의가 필요한 세션으로 바로 이동시켜 줍니다. 클릭하면 질문을 입력하거나 Enconvo를 엽니다. 이는 대화용 캐릭터와 음성을 에이전트에 부여하는 [아바타](/ko/features/avatar)와는 별개의 기능입니다.

다른 작업에는 빠른 질문이나 명령용 [SmartBar](/ko/features/smartbar), 긴 대화와 파일 작업용 [채팅 창](/ko/ai/chat), 특정 앱 옆에서 작업하는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에 바로 실행하는 [PopBar](/ko/features/popbar), 화면 상단의 컴팩트한 입력창인 [Dynamic Island](/ko/features/dynamic-island)를 사용하세요. [창 관리](/ko/features/window-management)에서 모든 방식을 비교할 수 있습니다.

## 펫 고르기

1. **설정 → 펫**을 엽니다.
2. **내 반려동물**에서 캐릭터를 고르거나 **갤러리**에서 찾습니다.
3. **펫 깨우기**를 클릭해 바탕화면에 표시합니다.
4. **탭하면 열기**를 펫을 클릭했을 때 나타날 창으로 설정합니다.
5. **세션 카드 표시**를 켜거나 끄고 **펫 크기**를 조절합니다.
6. 바탕화면으로 돌아가 펫을 클릭하면 4단계에서 고른 창이 열립니다.

## 설정

| 설정 | 변경되는 항목 |
| --- | --- |
| **펫 깨우기** / **펫 숨기기** | 바탕화면에 펫을 표시하거나 숨깁니다. |
| **탭하면 열기** | 펫을 클릭했을 때 열리는 창: **질문 상자**(기본값), **Dynamic Island**, **채팅 창**, 또는 **Smart Bar**. |
| **답변할 에이전트** | 펫에게 물어본 내용에 답할 에이전트입니다. 질문 상자에서도 변경할 수 있습니다. |
| **세션 카드 표시** | 펫 아래에 표시되는 실시간 세션 상태 카드입니다. |
| **펫 크기** | 펫의 크기입니다. |

## 사용자 지정 펫

**내 반려동물** 탭의 **사용자 지정 펫**에는 펫 패키지가 저장되는 폴더가 표시됩니다. **폴더 열기**를 클릭해 지원 형식의 펫 패키지를 추가한 뒤 **내 반려동물**에서 해당 펫을 선택하세요. 단순 캐릭터 이미지만으로는 애니메이션 펫 패키지로 동작하지 않습니다.

펫을 삭제하려면 해당 카드에서 **제거**를 클릭하세요. 라이브러리에서 팩이 삭제되며, 갤러리에서 언제든 다시 설치할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 펫이 바탕화면에 보이지 않음 | **펫 깨우기**를 클릭하고 **내 반려동물**에서 펫이 선택되었는지, **펫 크기**가 적절한지 확인하세요. |
| 펫을 클릭했을 때 다른 창이 열림 | **탭하면 열기** 설정을 변경하세요. |
| 음성 대화나 특정 에이전트용 캐릭터를 원함 | 대신 [아바타](/ko/features/avatar)를 사용하세요. |

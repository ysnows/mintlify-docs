스페이스는 나만의 페이지입니다. 구독 트래커나 여러 사이트에서 모은 특가 보드처럼 무엇을 보여 줄지 말하면, 에이전트가 만들어서 채팅 창 사이드바의 아이콘 레일에 구분선 아래로 보관합니다. 나중에 바꾸려면 요청하면 됩니다.

아래 영상은 구독 트래커를 스페이스로 만들고, 요청으로 바꾸고, 스페이스의 메뉴와 플러그인 페이지의 **스페이스** 탭을 보여 줍니다.

## 스페이스 만들기

1. 채팅 창 사이드바의 아이콘 레일 끝에 있는 **스페이스 만들기**를 클릭하세요. 레일의 **···** 메뉴에서 **새 스페이스**를 선택하거나, 플러그인 페이지의 **스페이스** 탭에서 **새 스페이스**를 클릭해도 됩니다.
2. `Create a Space that`이 미리 입력된 새 채팅이 열리고, 커서 뒤에 구독 추적 같은 흐릿한 제안이 표시됩니다. **Tab**이나 **→**를 눌러 제안을 사용하거나, 직접 문장을 완성하세요. 페이지에 무엇을 나열하고, 무엇을 합산하고, 무엇을 먼저 보여 줄지 쓰면 됩니다. 예를 들면 다음과 같습니다.

   ```text
   Create a Space that tracks my subscriptions. Call it Subscriptions. Netflix $15.49 renews Dec 3, Spotify $11.99 renews Nov 21, iCloud+ $2.99 renews Nov 28. Show the monthly total at the top and the next renewal first.
   ```

3. 보내세요. 에이전트가 스페이스를 만드는 데 1분 정도 걸립니다.
4. 스페이스가 레일의 구분선 아래에 나타납니다. 클릭해서 여세요.

레일에서 스페이스를 드래그해 원하는 순서로 놓으세요. 휴대폰도 같은 순서를 사용합니다. 스페이스를 장소들 사이로 올리려면 **···** 메뉴에서 **사이드바 사용자화…**를 여세요. Email처럼 자체 탐색이 있는 스페이스는 제목 표시줄 없이 표시되며, 사이드바에 이름과 탐색이 표시됩니다.

## 요청할 수 있는 것

원하는 페이지를 설명하면 에이전트가 만드는 방법을 정합니다.

- **직접 채우는 페이지**(기록, 트래커, 일일 점수 등): 에이전트는 데이터를 어디서 가져올지 묻지 않고 만듭니다. 점수는 계산 방식을 보여 주고, 기록이 없는 날은 그렇게 표시합니다.
- **실시간 값**(주식 시세 등): 각 값에 출처가 설정한 시점과 시장 휴장 여부가 표시되며, 상승과 하락은 내 지역의 방식대로 색으로 표시됩니다.
- **날짜와 청구서**(구독 등): 스페이스는 갱신 전에 Apple 미리 알림에 알림을 추가하고, 에이전트가 읽도록 허용한 메일함의 영수증을 읽을 수 있습니다.
- **여러 출처의 항목**(여러 포럼의 특가 등): 스페이스가 접근할 수 없는 출처는 맨 위에 표시되며, 그 출처의 이전 항목은 그대로 남습니다.

휴대폰에서는 숫자 목록이 비좁은 표 대신 각 항목을 짧은 두 줄로 표시합니다.

## 스페이스 바꾸기

스페이스를 열고 페이지의 **Ask about** 상자에 바꾸고 싶은 내용을 입력한 다음 보내세요. 예를 들면 `Add Figma, $15 a month, renewing Dec 2.`와 같습니다.

에이전트는 어느 스페이스인지, 파일이 어디에 있는지 알고 변경합니다. 열려 있는 스페이스와 채팅 옆의 스페이스는 몇 초 뒤에 스스로 업데이트됩니다. 스페이스가 보여 주는 내용에 대해 질문할 수도 있으며, 에이전트는 스페이스를 바탕으로 답합니다.

기록이나 트래커처럼 직접 채우는 스페이스는 페이지에서 한 모든 변경을 바로 저장합니다.

## 스페이스 메뉴 사용하기

레일에서 스페이스를 오른쪽 클릭하세요.

| 메뉴 항목 | 동작 |
| --- | --- |
| **플러그인 설정** | 플러그인 페이지에서 스페이스의 설정을 엽니다. |
| **공유…** | 다른 사람이 설치할 수 있는 링크를 보내거나, 스페이스를 플러그인 스토어에 등록합니다. [스페이스 공유하기](#스페이스-공유하기)를 참고하세요. |
| **사이드바에서 제거** | 레일에서 스페이스를 뺍니다. **···** 메뉴에는 남아 있으며, **사이드바에 고정**으로 다시 넣을 수 있습니다. |
| **사이드바 사용자화…** | 레일에 표시할 항목과 순서를 고릅니다. |

## 스페이스 공유하기

1. 레일에서 스페이스를 오른쪽 클릭하고 **공유…**를 선택하세요. Enconvo가 요청하면 Enconvo 계정에 로그인하세요.
2. **설치할 수 있는 사람**에서 **링크가 있는 모든 사용자** 또는 **플러그인 스토어**를 선택하세요.
3. **게시**를 클릭한 다음 **링크 복사**를 클릭하고 링크를 보내세요.

Enconvo는 링크로 설치되기 전에 각 버전을 검토합니다. 스페이스를 설치한 사람은 각자 자신의 사본을 갖게 됩니다. 스페이스의 데이터, 내 키, 내 로그인 정보는 내 Mac에만 남습니다.

Enconvo의 검토에서 새 버전이 거부되면 **공유…**에 이유가 표시되고 **채팅에서 수정**이 제안됩니다.

공유한 스페이스를 바꾸려면 **공유…**를 다시 여세요. **링크 업데이트**는 최신 버전을 검토용으로 보내고, **공유 중지**는 링크를 끕니다. 이미 스페이스를 설치한 사람은 자신의 사본을 그대로 유지합니다.

## 내 스페이스 모두 찾기

플러그인 페이지의 **스페이스** 탭에는 내가 만든 모든 스페이스가 나열됩니다. **새 스페이스** 버튼은 사이드바의 **스페이스 만들기**와 같이 새 스페이스를 시작합니다.

새 스페이스는 각 [작업 공간](/ko/configuration/account)에 데이터를 따로 보관하므로, 고객의 작업 공간에서 사용해도 내 항목이 표시되거나 덮어쓰이지 않습니다.

## 휴대폰의 스페이스

iPhone과 Android 앱은 친구 위의 사이드바에 스페이스를 표시합니다. 스페이스를 보려면 앱을 업데이트하세요.

- 스페이스를 탭하면 전체 화면으로 열립니다. **Ask about** 상자로 Mac에서와 같이 바꿀 수 있습니다.
- 스페이스를 길게 누른 다음 새 위치로 드래그하세요. Mac에도 새 순서가 유지됩니다.
- 스페이스 메뉴의 **새로고침**은 Mac에서 최신 항목을 가져온 다음 다시 표시합니다.
- 스페이스 메뉴의 **공유**는 휴대폰의 공유 시트로 링크를 보냅니다. 아직 공유하지 않은 스페이스는 Mac에서 **공유…**가 열립니다.
- **새 스페이스**는 휴대폰에서 새 스페이스를 시작하며, `Create a Space that`이 완성할 수 있게 준비되어 있습니다.

스페이스는 Mac에서 실행됩니다. 휴대폰은 마지막으로 본 상태를 보여 준 다음 Mac에서 최신 데이터를 가져옵니다. 마지막으로 연 스페이스들은 준비된 상태로 유지되므로 다시 가면 바로 표시됩니다. Mac이 꺼져 있으면 사이드바에는 마지막으로 확인한 스페이스가 표시됩니다. 먼저 휴대폰을 페어링하세요. [iPhone 앱](/ko/integrations/iphone-app)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 요청한 변경이 스페이스에 표시되지 않습니다 | 업데이트될 때까지 몇 초 기다리세요. 그래도 표시되지 않으면 사이드바에서 스페이스를 다시 클릭하세요. |
| 사이드바에 스페이스가 없습니다 | 레일에서 제거된 것입니다. 레일의 **···** 메뉴를 열고 스페이스 옆의 **사이드바에 고정**을 클릭하거나, 플러그인 페이지의 **스페이스** 탭에서 찾으세요. |
| 여러 사이트에서 모으는 스페이스의 맨 위에 출처가 표시됩니다 | 에이전트가 그 출처에 접근하지 못했습니다. 스페이스는 이전에 그 출처에서 가져온 항목을 유지합니다. |
| **공유…**가 로그인을 요청합니다 | 공유에는 Enconvo 계정이 필요합니다. 링크와 스페이스는 내 계정에 속합니다. |
| **공유…**에 검토에서 버전이 거부되었다고 표시됩니다 | 이유를 읽은 다음 **채팅에서 수정**을 클릭해 에이전트가 고치게 하고, 링크를 다시 업데이트하세요. |

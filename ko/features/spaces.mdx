스페이스는 나만의 페이지입니다. 구독 추적기나 여러 사이트에서 모은 거래 보드처럼 무엇을 보여 줄지 말하면, 에이전트가 만들고 채팅 창 사이드바 아이콘 레일의 선 아래에 둡니다. 나중에 바꾸려면 다시 부탁하면 됩니다.

아래 동영상은 구독 추적기를 스페이스로 만들고, 부탁으로 바꾸고, 스페이스 메뉴와 플러그인 페이지의 **스페이스** 탭을 보여 줍니다.

## 스페이스 만들기

1. 채팅 창 사이드바의 아이콘 레일 끝에서 **스페이스 만들기**를 클릭합니다. 레일의 **···** 메뉴에서 **새 스페이스**를 고르거나, 플러그인 페이지의 **스페이스** 탭에서 **새 스페이스**를 클릭해도 됩니다.
2. `Create a Space that`이 이미 입력된 새 채팅이 열리고, 커서 뒤에 구독 추적 같은 흐린 제안이 있습니다. **Tab** 또는 **→**로 제안을 받아들이거나, 페이지가 나열하는 것, 합계, 무엇이 먼저인지 문장을 직접 끝냅니다. 예:

   ```text
   Create a Space that tracks my subscriptions. Call it Subscriptions. Netflix $15.49 renews Dec 3, Spotify $11.99 renews Nov 21, iCloud+ $2.99 renews Nov 28. Show the monthly total at the top and the next renewal first.
   ```

3. 보냅니다. 에이전트가 스페이스를 만들며, 1분 정도 걸립니다.
4. 스페이스가 선 아래 레일에 나타납니다. 클릭하면 열립니다.

레일에서 스페이스를 끌어 원하는 순서로 둡니다. 휴대폰도 같은 순서를 씁니다. 스페이스를 장소들 사이로 올리려면 **···** 메뉴에서 **사이드바 사용자화…**를 엽니다. 이메일처럼 자체 탐색이 있는 스페이스는 제목 표시줄 없이 표시되고, 사이드바에 이름과 탐색이 나옵니다.

## 무엇을 부탁할지

원하는 페이지를 설명하면 에이전트가 만드는 방법을 고릅니다.

- **직접 채우는 페이지**, 기록, 추적기, 하루 점수 같은 것: 에이전트는 데이터를 어디서 가져올지 묻지 않고 만듭니다. 점수는 어떻게 계산됐는지 보여 주고, 기록이 없는 날은 그렇다고 말합니다.
- **실시간 값**, 주가 같은 것: 각 값은 소스가 설정한 시각과 시장이 닫혔는지를 보여 주고, 오르내림은 지역의 방식으로 색이 칠해집니다.
- **날짜와 청구**, 구독 같은 것: 스페이스는 갱신 전에 Apple 미리 알림에 알림을 추가할 수 있고, 에이전트가 읽도록 허용한 메일함에서 영수증을 읽습니다.
- **여러 소스의 항목**, 여러 포럼의 거래 같은 것: 스페이스가 닿지 못하는 소스는 위에 이름이 나오고, 이전 항목은 남습니다.

휴대폰에서는 숫자 목록이 압축된 표 대신 항목마다 짧은 두 줄로 표시됩니다.

## 스페이스 바꾸기

스페이스를 열고 페이지의 **물어보기** 칸에 바꾸고 싶은 것을 입력한 다음 보냅니다. 예: `Add Figma, $15 a month, renewing Dec 2.`

에이전트는 어느 스페이스인지, 파일이 어디인지 알고 바꿉니다. 열린 스페이스와 채팅 옆의 스페이스는 몇 초 뒤 스스로 업데이트됩니다. 스페이스가 보여 주는 것에 대해 물어볼 수도 있으며, 에이전트가 그것을 바탕으로 답합니다.

기록이나 추적기처럼 직접 채우는 스페이스는 페이지에서 한 변경을 바로 저장합니다.

## 스페이스 메뉴 사용

레일에서 스페이스를 오른쪽 클릭합니다.

| 메뉴 항목 | 하는 일 |
| --- | --- |
| **플러그인 설정** | 플러그인 페이지에서 스페이스 설정을 엽니다. |
| **공유…** | 다른 사람이 설치할 수 있는 링크를 보내거나, 플러그인 스토어에 스페이스를 올립니다. [스페이스 공유](/ko/features/spaces)를 보세요. |
| **사이드바에서 제거** | 레일에서 스페이스를 뺍니다. **···** 메뉴에 남고, **사이드바에 고정**으로 되돌립니다. |
| **사이드바 사용자화…** | 레일에 무엇이 어떤 순서로 나올지 고릅니다. |

## 스페이스 공유

1. 레일에서 스페이스를 오른쪽 클릭하고 **공유…**를 고릅니다. Enconvo가 물으면 Enconvo 계정에 로그인합니다.
2. **설치할 수 있는 사람**에서 **링크가 있는 사람** 또는 **플러그인 스토어**를 고릅니다.
3. **게시**를 클릭한 다음 **링크 복사**를 클릭하고 링크를 보냅니다.

Enconvo는 링크가 설치하기 전에 각 버전을 검토합니다. 설치한 사람은 각자 복사본을 받습니다. 데이터, 키, 로그인은 Mac에 남습니다.

검토가 새 버전을 거절하면 **공유…**가 이유를 보여 주고 **채팅에서 고치기**를 제안합니다.

공유한 스페이스를 바꾸려면 **공유…**를 다시 엽니다. **링크 업데이트**는 최신 버전을 검토에 보내고, **공유 중지**는 링크를 끕니다. 이미 설치한 사람은 복사본을 유지합니다.

## 모든 스페이스 찾기

플러그인 페이지의 **스페이스** 탭이 만든 모든 스페이스를 나열합니다. **새 스페이스** 버튼은 사이드바의 **스페이스 만들기**와 같이 새 것을 시작합니다.

새 스페이스는 각 [작업 공간](/ko/configuration/account)에서 데이터를 따로 두므로, 고객의 작업 공간에서 써도 본인 항목이 보이거나 덮어쓰이지 않습니다.

## 휴대폰의 스페이스

iPhone과 Android 앱은 사이드바에서 친구 위에 스페이스를 보여 줍니다. 앱을 업데이트하면 사용할 수 있습니다.

- 스페이스를 탭하면 전체 화면으로 열립니다. **물어보기** 칸이 Mac과 같이 바꿉니다.
- 스페이스를 길게 터치한 다음 새 위치로 끕니다. Mac이 새 순서를 유지합니다.
- 스페이스 메뉴의 **새로고침**은 Mac에서 최신 항목을 모은 다음 다시 보여 줍니다.
- 스페이스 메뉴의 **공유**는 휴대폰의 공유 시트로 링크를 보냅니다. 아직 공유하지 않은 스페이스는 Mac에서 **공유…**를 엽니다.
- **새 스페이스**는 휴대폰에서 새 스페이스를 시작하며, `Create a Space that`이 끝낼 준비로 있습니다.

스페이스는 Mac에서 실행됩니다. 휴대폰은 마지막으로 본 모습을 보여 준 다음 Mac의 최신 데이터를 가져옵니다. 마지막으로 연 스페이스는 준비되어 있어 돌아가면 바로 보입니다. Mac이 멀리 있으면 사이드바는 마지막으로 본 스페이스를 보여 줍니다. 먼저 휴대폰을 페어링하세요. [iPhone 앱](/ko/integrations/iphone-app)을 보세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 부탁한 변경이 스페이스에 보이지 않음 | 업데이트될 때까지 몇 초 기다립니다. 그래도 안 되면 사이드바에서 스페이스를 다시 클릭합니다. |
| 사이드바에 스페이스가 없음 | 레일에서 제거되었습니다. 레일의 **···** 메뉴를 열고 스페이스 옆의 **사이드바에 고정**을 클릭하거나, 플러그인 페이지의 **스페이스** 탭에서 찾습니다. |
| 여러 사이트에서 모으는 스페이스가 위에 소스를 표시함 | 에이전트가 그 소스에 닿지 못했습니다. 스페이스는 예전에 받은 항목을 유지합니다. |
| **공유…**가 로그인을 요구함 | 공유에는 Enconvo 계정이 필요합니다. 링크와 스페이스는 계정 아래에 남습니다. |
| **공유…**가 검토가 버전을 거절했다고 함 | 이유를 읽고 **채팅에서 고치기**를 클릭해 에이전트가 고치게 한 다음 링크를 다시 업데이트합니다. |

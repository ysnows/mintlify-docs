title: "에이전트 전화"
description: "작업에 내가 필요할 때 Agent가 전화를 걸고, 나를 대신해 사람과 Enconvo 친구에게 전화하고, 놓친 전화를 대신 받게 하세요."
---

에이전트 전화는 Agent가 전화를 사용할 수 있게 해 줍니다. Agent는 작업이 내 입력을 기다릴 때 내게 전화를 걸고, 채팅에서 내가 지정한 사람이나 업체에 전화하고, 나를 대신해 Enconvo 친구와 팀원에게 전화하고, 내가 받지 않은 iPhone 전화를 대신 받을 수 있습니다. 모든 통화의 대화 내용은 채팅으로 돌아옵니다.

## 시작하기 전에

**설정 → 에이전트 전화**를 열고 전화를 거는 방법을 하나 이상 설정하세요.

| 방법 | 하는 일 | 비용 |
| --- | --- | --- |
| **내 iPhone** | iPhone이 근처에 있는 동안 이 Mac이 내 번호로 iPhone의 전화를 걸고 받습니다. **내 전화 대신 받기**에 필요합니다. | 요금제에 따라 무료입니다. |
| **전화 제공업체** | Agent가 내 Twilio 또는 Telnyx 계정의 번호로 전화를 겁니다. | 제공업체가 통화마다 요금을 청구합니다. |
| **EnConvo 모바일 앱** | Agent가 휴대전화의 EnConvo 앱을 전화처럼 울립니다. 받으면 [Live Talk](/ko/features/live-voice)가 시작됩니다. Android에서는 벨 알림이나 잠금 화면에서 받으면 잠금 해제나 앱 실행 없이 연결됩니다. 나에게 거는 통화에서만 사용됩니다. | Wi-Fi나 모바일 데이터로 무료입니다. |

## 내 iPhone 설정하기

1. **내 iPhone**에서 **설정**을 클릭합니다. 그림 위주의 안내가 한 단계씩 알려 주며 각 단계에 맞는 곳을 열어 줍니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켜서, macOS의 통화 안내창에서 Enconvo가 통화와 종료를 누를 수 있게 합니다.
3. **FaceTime → 설정 → 일반**에서 **iPhone으로 통화**를 켭니다.
4. **시스템 설정 → 알림**에서 전화와 FaceTime의 **알림 허용**과 **데스크탑**을 켭니다. macOS는 각 통화를 알림으로 표시합니다.
5. iPhone과 이 Mac이 같은 Apple 계정을 사용하는지 확인합니다. iPhone에서 **설정 → 앱 → 전화 → 다른 기기에서 전화 걸기**를 열고 이 Mac을 허용합니다.
6. iPhone을 이 Mac 가까이에 두고 같은 Wi-Fi에 연결합니다.
7. **Enconvo Audio 추가**를 클릭하고 macOS가 요청하면 Mac 로그인 암호를 입력합니다. Enconvo Audio는 마이크나 스피커를 사용하지 않고 Agent의 음성을 통화로, 상대방의 음성을 다시 가져옵니다.
8. **오디오 확인**을 클릭합니다. Enconvo Audio로 짧은 신호음을 재생하고 그 소리를 듣습니다. 전화는 걸리지 않습니다.

**준비됨**으로 표시되면 Agent는 내 iPhone 번호로 전화를 걸며, 전화를 받는 사람에게는 내 번호가 표시됩니다. iPhone이 근처에 없을 때는 전화 제공업체를 설정해 두었다면 제공업체가 대신 전화를 겁니다.

## 전화 제공업체 설정하기

1. **전화 제공업체**에서 Twilio나 Telnyx 옆의 **설정** 또는 **연결**을 클릭합니다. Enconvo가 플러그인을 추가하고 로그인이나 API 키를 요청합니다.
2. **발신 번호**에서 전화를 걸 번호를 고릅니다.
3. **테스트 전화**를 클릭해 시험해 봅니다.

Agent는 기본 제공업체를 사용하며, 채팅에서 내가 요청했거나 기본 제공업체로 전화를 걸 수 없을 때만 다른 제공업체를 사용합니다. Telnyx 통화는 Enconvo가 내 계정에 추가하는 Enconvo Agent Phone이라는 TeXML 애플리케이션을 거칩니다. Twilio 체험 계정은 Twilio에서 인증한 번호에만 전화할 수 있습니다.

Twilio와 Telnyx를 통한 통화는 키패드 키를 누를 수 있으므로 Agent가 자동 응답 메뉴와 내선 번호를 통과할 수 있습니다. 내 iPhone을 통한 통화도 마찬가지입니다.

## 작업에 내가 필요할 때 전화 받기

**에이전트 전화 설정 → 내 입력을 기다리는 작업**에서 Mac을 떠나 있을 때 Agent가 나에게 연락하는 방법을 고릅니다.

1. EnConvo 모바일 앱이 페어링되어 있으면 먼저 바로 울립니다.
2. 응답이 없으면 내 전화번호로 전화합니다. 번호를 설정하고 **발신 회선**을 **내 iPhone**, Twilio, Telnyx 중에서 고릅니다.

전화는 Agent의 이름으로 울립니다. 같은 채팅에서 대기 중인 요청은 한 통화로 묶이며, 거절한 통화는 다시 시도하지 않습니다. **알림 지연**은 작업이 내게 알리기 전에 기다리는 시간을 정합니다. **작업 세부 정보 포함**은 전화번호로 거는 통화에서 작업 내용을 소리 내어 읽어 줍니다. 꺼져 있으면 채팅 제목만 안내하며 전화로는 승인할 수 없습니다.

채팅에서 Agent에게 앱, 내 iPhone, Twilio, Telnyx 중 하나로 전화해 달라고 요청할 수도 있습니다. 내가 요청한 통화는 항상 울립니다.

## Agent가 누군가에게 전화하게 하기

1. **에이전트 전화 설정**에서 **나를 대신한 발신 전화**를 켭니다.
2. 채팅에서 Agent에게 사람이나 업체에 전화하라고 요청하고 전화의 용건을 말합니다.
3. 통화 카드에 번호와 통화에서 전할 내용이 표시됩니다. **전화 걸기**를 클릭합니다. 전체 접근 권한으로 실행되는 채팅에서는 Agent가 기다리지 않고 바로 전화를 겁니다.
4. 카드에서 통화를 따라가거나 **통화 종료**를 클릭합니다. 통화가 끝나면 결과 카드에 양쪽이 한 말이 표시됩니다.

전화 회선이 설정되어 있지 않으면 통화 카드에서 채팅을 떠나지 않고 내 iPhone이나 Telnyx를 설정할 수 있으며, 준비되면 통화가 연결됩니다.

## Agent가 친구에게 전화하게 하기

Agent에게 Enconvo [친구](/ko/features/friends)나 팀원에게 전화하라고 하고 할 말을 알려 주세요. Agent는 먼저 상대의 Enconvo 앱을 울리고, 나를 대신해 대화하고, 상대의 답변과 통화 내용을 내 채팅으로 가져옵니다. 내가 전화 통화를 요청했거나 Enconvo 통화가 닿지 않을 때만 상대의 전화번호로 겁니다.

Agent는 내 친구와 팀원에게만 연락하며, 통화에서만 만난 사람에게는 연락하지 않습니다. 예약된 작업도 내가 허용한 친구에게 메시지를 보내고 전화할 수 있습니다. 예를 들어 자정에 누군가에게 보고서를 보내고, 답이 없으면 아침에 전화할 수 있습니다.

## 통화 녹음하기

**통화 녹음하기**를 켜면 전화 앱이나 전화번호로 나에게 또는 다른 사람에게 거는 모든 Agent 통화가 대화 내용과 함께 이 Mac의 [녹음](/ko/features/meeting-recording)에 저장됩니다. **최근 통화**의 녹음된 통화마다 녹음 버튼이 있습니다. Agent가 전화하는 친구는 통화가 녹음된다는 것을 듣고 볼 수 있으며, 원하지 않는다고 하면 녹음이 저장되지 않습니다.

<Warning>
일부 지역에서는 통화를 녹음하기 전에 모든 참가자의 동의가 필요합니다. Agent가 전화하는 상대를 녹음해도 되는지 확인하세요.
</Warning>

## Agent가 놓친 전화를 받게 하기

**내 전화 대신 받기**는 내 iPhone이 필요합니다. iPhone으로 온 전화를 받지 않으면 Agent가 Mac에서 대신 받아 메시지를 남기게 하고, 요약과 대화 내용을 업데이트로 보냅니다.

1. **내 iPhone**에서 **내 전화 대신 받기**를 켭니다. 요청이 오면 연락처를 허용해 Enconvo가 연락처에 저장된 발신자를 알아보게 합니다.
2. **내가 받지 않을 때**를 고릅니다. 벨이 몇 번 울린 뒤이며 기본값은 5초입니다.
3. 어떤 전화를 받을지 고릅니다. **연락처에 없는 번호** 또는 **모두**입니다. **방해 금지 시간에는 바로 받기**는 알림에서 설정한 방해 금지 시간에는 기다리지 않습니다.
4. **말해도 되는 내용**에 누구로서 응대하고 발신자에게 무엇을 알려도 되는지 적습니다. Agent는 메시지를 받기만 하고 나를 대신해 무엇에도 동의하지 않습니다.
5. Mac이 여러 대라면 **먼저 받기**로 먼저 받을 Mac을 고릅니다. 다른 Mac은 그 Mac이 오프라인일 때만 받습니다.

각 통화가 끝나면 휴대전화에 누가 전화했는지, 용건이 무엇인지 한 문장으로, 그리고 급한지 여부가 담긴 알림이 옵니다. 급한 통화는 집중 모드를 뚫고 알립니다. 알림에는 **다시 걸기**와 **열기**가 있습니다. 사기로 보이는 통화에는 **사기 의심** 배지와 경고가 표시됩니다.

발신자는 내 Agent가 행동하게 만들 수 없습니다. 통화에서 Agent는 도구, 채팅, 메모리, 파일 없이 말하고 메시지를 받기만 합니다. 요약도 도구 없이 작성됩니다. 통화의 채팅에서는 내가 답하기 전까지 아무것도 실행되지 않으며, 전체 접근 권한이어도 보내기, 결제, 삭제, 명령 실행 같은 동작은 먼저 나에게 묻습니다. 설정의 **발신자가 접근할 수 있는 범위**에서 이러한 제한을 확인할 수 있습니다.

### 작업을 맡길 수 있는 번호

**작업을 맡길 수 있는 번호**에 내 다른 번호를 추가하세요. 이 번호에서 온 전화는 내 Agent와 대화하고 작업을 맡길 수 있으며, 그 외의 사람은 메시지만 남길 수 있습니다. 위조된 발신자 번호가 이 번호로 둔갑할 수 있으므로 **암호 문구 요구**를 켜세요. 발신자가 암호 문구를 말하기 전까지는 메시지만 받습니다.

## 통화 확인하기

채팅 창 사이드바의 **통화** 섹션은 Agent가 받은 통화를 다른 채팅과 구분해 보관합니다. 급하거나, 다시 전화해 달라고 하거나, 아직 읽지 않은 통화를 표시하고, 각 통화가 울린 시각과 발신자의 번호 또는 연락처 이름을 보여 줍니다. **다시 걸기** 또는 **완료로 표시**를 클릭하세요. iPhone과 Android 앱에도 같은 섹션이 있습니다.

**설정 → 에이전트 전화** 맨 아래의 **최근 통화**에는 Agent가 걸거나 받은 모든 통화가 결과와 함께 나열됩니다.

## 설정

| 설정 | 변경되는 내용 |
| --- | --- |
| **내 iPhone** | 이 Mac을 통해 내 iPhone 번호로 거는 전화와 **내 전화 대신 받기**입니다. |
| **전화 제공업체** | Twilio와 Telnyx 계정, 기본 제공업체, **발신 번호**입니다. |
| **EnConvo 앱 울리기** | Agent가 페어링된 휴대전화를 울리게 합니다. **휴대전화 페어링**으로 추가합니다. |
| **내 입력을 기다리는 작업** | 작업이 대기 중일 때 Agent가 나에게 연락하는 방법입니다. 앱, 그다음 내 번호 순이며 **발신 회선**, **알림 지연**, **작업 세부 정보 포함**이 있습니다. |
| **나를 대신한 발신 전화** | Agent가 채팅에서 내가 지정한 사람에게 전화하게 합니다. |
| **통화 녹음하기** | Agent 통화와 대화 내용을 녹음에 저장합니다. |
| **내 전화 대신 받기** | 내가 받지 않은 iPhone 전화를 Agent가 대신 받습니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **Enconvo Audio가 없음** | macOS 업데이트로 사라질 수 있습니다. **다시 추가**를 클릭하고 macOS가 표시하는 창에 Mac 로그인 암호를 입력하세요. 다른 창 뒤에 가려져 있을 수 있습니다. |
| **손쉬운 사용이 꺼져 있음** | **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켜세요. |
| **통화 소리를 들을 수 없음** | **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**의 **시스템 오디오 녹음 전용**에서 Enconvo를 허용한 다음 **오디오 확인**을 클릭하세요. |
| **알림이 꺼져 있음** | 전화와 FaceTime의 **알림 허용**과 **데스크탑**을 켜세요. 그전까지는 통화가 전화 제공업체를 통해 연결됩니다. |
| **iPhone이 근처에 없음** | 같은 Wi-Fi에서 iPhone을 이 Mac 가까이에 두세요. 그전까지는 통화가 전화 제공업체를 통해 연결됩니다. |
| Twilio 통화가 연결되지 않음 | 체험 계정은 인증된 번호에만 전화할 수 있습니다. Twilio에서 번호를 인증하거나 계정을 업그레이드하세요. |
| **내 전화 대신 받기**가 연락처를 알아보지 못함 | Enconvo에 연락처를 허용하거나, 연락처를 읽을 수 있는 Mac이 먼저 받게 하세요. |

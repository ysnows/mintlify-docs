---

에이전트 전화는 에이전트가 전화를 쓰게 합니다. 작업이 입력을 기다릴 때 사용자에게 전화하고, 채팅에서 이름 붙인 사람이나 업체에 전화하고, Enconvo 친구와 팀원에게 대신 전화하며, iPhone으로 온 전화 중 받지 않은 것을 대신 받습니다. 모든 통화의 대화 기록은 채팅으로 돌아옵니다.

## 시작하기 전에

**설정 → 에이전트 전화**를 열고 전화하는 방법을 하나 이상 설정하세요.

| 방법 | 하는 일 | 비용 |
| --- | --- | --- |
| **내 iPhone** | iPhone이 근처에 있는 동안 이 Mac이 자신의 번호로 iPhone에서 전화를 걸고 받습니다. **내 전화 받기**에 필요합니다. | 전화 요금제에 포함되어 무료. |
| **전화 제공업체** | 자신의 Twilio 또는 Telnyx 계정 번호로 에이전트가 전화합니다. | 제공업체가 통화마다 청구. |
| **EnConvo 모바일 앱** | 에이전트가 전화의 EnConvo 앱을 전화처럼 울립니다. 받으면 [Live Talk](/ko/features/live-voice)가 시작됩니다. Android에서는 잠금 화면이나 벨 알림에서 받으면 잠금을 풀거나 앱을 열지 않고 연결됩니다. 사용자에게 거는 전화에만 해당. | Wi-Fi나 모바일 데이터로 무료. |

## 내 iPhone 설정

1. **내 iPhone** 아래에서 **설정**을 클릭합니다. 그림으로 이끄는 안내가 한 단계씩 진행하며 각 단계의 올바른 위치를 엽니다.
2. Enconvo가 macOS 통화 프롬프트에서 통화와 종료를 누를 수 있도록 **시스템 설정 → 개인 정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켭니다.
3. **FaceTime → 설정 → 일반**에서 **iPhone에서 걸려 온 통화**를 켭니다.
4. **시스템 설정 → 알림**에서 전화와 FaceTime의 **알림 허용**과 **데스크탑**을 켭니다. macOS는 각 통화를 알림으로 보여 줍니다.
5. iPhone과 이 Mac이 같은 Apple 계정을 쓰는지 확인합니다. iPhone에서 **설정 → 앱 → 전화 → 다른 기기에서 통화**를 열고 이 Mac을 허용합니다.
6. iPhone을 이 Mac 가까이, 같은 Wi-Fi에 둡니다.
7. **Enconvo Audio 추가**를 클릭하고 macOS가 물으면 Mac 로그인 암호를 입력합니다. Enconvo Audio는 마이크나 스피커를 쓰지 않고 에이전트 음성을 통화로 넣고 상대 음성을 돌려줍니다.
8. **오디오 확인**을 클릭합니다. Enconvo Audio로 짧은 음을 재생하고 그 음을 듣습니다. 아무것도 울리지 않습니다.

**준비됨**이라고 나오면 에이전트는 iPhone 번호로 전화하고, 받는 사람에게 사용자의 번호가 보입니다. iPhone이 근처에 없으면 설정한 전화 제공업체가 대신 전화합니다.

## 전화 제공업체 설정

1. **전화 제공업체** 아래에서 Twilio 또는 Telnyx 옆 **설정** 또는 **연결**을 클릭합니다. Enconvo가 플러그인을 추가하고 로그인 또는 API 키를 요청합니다.
2. **발신 번호**에서 전화가 나가는 번호를 고릅니다.
3. **테스트 통화**를 클릭해 시험합니다.

에이전트는 기본 제공업체를 쓰고, 채팅에서 요청하거나 기본 제공업체가 전화를 걸 수 없을 때만 다른 제공업체를 씁니다. Telnyx 통화는 Enconvo가 계정에 추가하는 Enconvo Agent Phone이라는 TeXML 애플리케이션을 거칩니다. Twilio 체험 계정은 Twilio에서 확인한 번호에만 전화합니다.

Twilio와 Telnyx를 통한 통화는 키패드를 누를 수 있어, 에이전트가 자동 전화 메뉴와 내선을 통과합니다. 내 iPhone을 통한 통화도 가능합니다.

## 작업에 사용자가 필요할 때 전화 받기

**에이전트 통화 설정 → 입력을 기다리는 작업**에서 Mac을 떠나 있는 동안 에이전트가 닿는 방법을 고르세요.

1. 페어링되어 있으면 EnConvo 모바일 앱이 바로 울립니다.
2. 받지 않으면 전화 번호로 전화합니다. 번호를 설정하고 **발신**: **내 iPhone**, Twilio, Telnyx 중 하나를 고릅니다.

전화는 에이전트 이름으로 울립니다. 같은 채팅의 대기 요청은 한 통화로 묶이며, 거절한 통화는 다시 시도하지 않습니다. **알림 지연**은 작업이 알려지기 전에 기다리는 시간을 설정합니다. **작업 세부 정보 포함**은 전화 번호 통화에서 작업을 소리 내어 읽습니다. 끄면 채팅 제목만 알려지고 전화로 승인할 수 없습니다.

채팅에서 에이전트에게 앱, 내 iPhone, Twilio, Telnyx를 통해 전화하라고 요청할 수도 있습니다. 요청한 통화는 매번 울립니다.

## 에이전트에게 누군가에게 전화하게 하기

1. **에이전트 통화 설정**에서 **대신 거는 발신 통화**를 켭니다.
2. 채팅에서 사람이나 업체에 전화하라고 하고, 통화 목적을 말합니다.
3. 통화 카드에 번호와 말할 내용이 나옵니다. **전화 걸기**를 클릭합니다. 전체 접근으로 실행되는 채팅에서는 에이전트가 기다리지 않고 겁니다.
4. 카드에서 통화를 따라가거나 **통화 종료**를 클릭합니다. 끝나면 결과 카드에 양쪽이 말한 내용이 나옵니다.

전화 회선이 없으면 통화 카드에서 채팅 안에서 바로 내 iPhone이나 Telnyx를 설정할 수 있고, 준비되면 통화가 연결됩니다.

## 에이전트에게 친구에게 전화하게 하기

에이전트에게 Enconvo [친구](/ko/features/friends)나 팀원에게 전화하고 할 말을 알려 주세요. 먼저 상대의 Enconvo 앱을 울리고, 대신 대화한 뒤 답과 통화 기록을 채팅으로 가져옵니다. 전화 통화를 요청하거나 Enconvo 통화가 닿지 않을 때만 전화 번호로 전화합니다.

에이전트는 친구와 팀원에게만 닿으며, 통화에서만 만난 사람에게는 닿지 않습니다. 예약된 작업은 닿도록 허용한 친구에게 메시지를 보내고 전화할 수 있습니다. 예를 들어 자정에 보고서를 보내고, 아침에 답이 없으면 전화할 수 있습니다.

## 통화 녹음

**통화 녹음**을 켜면 사용자에게 건 통화와 다른 사람에게 건 통화, 전화 앱이나 전화 번호로 건 모든 에이전트 통화가 대화 기록과 함께 이 Mac의 [녹음](/ko/features/meeting-recording)에 저장됩니다. **최근 통화**의 녹음된 통화마다 녹음 버튼이 있습니다. 에이전트가 전화한 친구는 녹음 중임을 듣고 보며, 원하지 않는다고 하면 녹음은 보관되지 않습니다.

<Warning>
일부 지역에서는 녹음 전에 통화의 모든 사람이 동의해야 합니다. 에이전트가 전화하는 사람을 녹음해도 되는지 확인하세요.
</Warning>

## 받지 못한 전화를 에이전트가 받게 하기

**내 전화 받기**에는 내 iPhone이 필요합니다. iPhone으로 온 전화를 받지 않으면 에이전트가 Mac에서 받고, 메시지를 받아 요약과 대화 기록을 업데이트로 보냅니다.

1. **내 iPhone** 아래에서 **내 전화 받기**를 켭니다. 물으면 연락처를 허용해, Enconvo가 연락처에 저장된 발신자를 알아보게 합니다.
2. **받지 않을 때**를 고릅니다. 몇 번 울린 뒤이며, 기본은 5초입니다.
3. 받을 통화를 고릅니다. **연락처에 없는 번호** 또는 **모두**. **방해 금지 시간에는 바로 받기**는 알림에 설정한 방해 금지 시간 동안 대기를 건너뜁니다.
4. **말할 수 있는 내용**에 누구로 받는지, 발신자에게 무엇을 말해도 되는지를 씁니다. 메시지를 받을 뿐, 사용자를 대신해 무엇에도 동의하지 않습니다.
5. Mac이 여러 대면 **먼저 받는** Mac을 고릅니다. 다른 Mac은 그것이 오프라인일 때만 받습니다.

각 통화 뒤 전화에 누가 걸었는지, 한 문장으로 무엇을 원하는지, 급한지가 담긴 알림이 옵니다. 급한 통화는 집중 모드를 뚫습니다. 알림에는 **다시 전화**와 **열기**가 있습니다. 사기로 보이는 통화에는 **사기 가능성** 배지와 경고가 붙습니다.

발신자는 에이전트를 행동하게 할 수 없습니다. 통화에서는 말하고 메시지만 받으며, 도구, 채팅, 메모리, 파일은 없습니다. 요약도 도구 없이 작성됩니다. 통화 채팅에서는 답하기 전까지 아무것도 실행되지 않으며, 보내기, 결제, 삭제, 명령 실행은 전체 접근이어도 먼저 묻습니다. 설정의 **발신자가 닿을 수 있는 것**에 이 제한이 나옵니다.

### 작업을 줄 수 있는 번호

**작업을 줄 수 있는 번호** 아래에 자신의 다른 번호를 추가하세요. 그 번호에서 온 통화는 에이전트와 대화하고 작업을 줄 수 있습니다. 그 외에는 메시지만 남깁니다. 위조된 발신자 ID가 이 번호로 통과할 수 있으므로 **암호 구문 묻기**를 켜세요. 발신자가 말할 때까지 통화는 메시지만 받습니다.

## 통화 검토

채팅 창 사이드바의 **통화** 섹션은 에이전트가 받은 통화를 다른 채팅과 따로 둡니다. 급하거나, 다시 전화를 원하거나, 아직 읽지 않은 통화를 표시하고, 각 통화가 울린 시각과 발신자 번호 또는 연락처 이름을 보여 줍니다. **다시 전화** 또는 **완료로 표시**를 클릭합니다. 같은 섹션이 iPhone과 Android 앱에도 있습니다.

**설정 → 에이전트 전화** 아래의 **최근 통화**는 에이전트가 걸거나 받은 모든 통화와 결과를 나열합니다.

## 설정

| 설정 | 바뀌는 것 |
| --- | --- |
| **내 iPhone** | 이 Mac을 통해 자신의 iPhone 번호로 거는 통화와 **내 전화 받기**. |
| **전화 제공업체** | Twilio와 Telnyx 계정, 기본 제공업체, **발신 번호**. |
| **EnConvo 앱 울리기** | 에이전트가 페어링된 전화를 울리게 합니다. **전화 페어링**으로 추가합니다. |
| **입력을 기다리는 작업** | 작업이 기다릴 때 에이전트가 닿는 방법. 앱, 그다음 번호. **발신**, **알림 지연**, **작업 세부 정보 포함**. |
| **대신 거는 발신 통화** | 채팅에서 이름 붙인 사람에게 에이전트가 전화하게 합니다. |
| **통화 녹음** | 에이전트 통화와 대화 기록을 녹음에 저장합니다. |
| **내 전화 받기** | 받지 않은 iPhone 전화를 에이전트가 받습니다. |

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **Enconvo Audio가 없음** | macOS 업데이트가 제거할 수 있습니다. **다시 추가**를 클릭하고 macOS가 보여 주는 창에 Mac 로그인 암호를 입력하세요. 다른 창 뒤에 있을 수 있습니다. |
| **손쉬운 사용이 꺼짐** | **시스템 설정 → 개인 정보 보호 및 보안 → 손쉬운 사용**에서 Enconvo를 켭니다. |
| **통화를 들을 수 없음** | **시스템 설정 → 개인 정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**의 **시스템 오디오 녹음만**에서 Enconvo를 허용한 다음 **오디오 확인**을 클릭합니다. |
| **알림이 꺼짐** | 전화와 FaceTime의 **알림 허용**과 **데스크탑**을 켭니다. 그때까지 통화는 전화 제공업체를 거칩니다. |
| **iPhone이 근처에 없음** | 같은 Wi-Fi에서 이 Mac 가까이로 가져옵니다. 그때까지 통화는 전화 제공업체를 거칩니다. |
| Twilio 통화가 연결되지 않음 | 체험 계정은 확인된 번호에만 전화합니다. Twilio에서 번호를 확인하거나 계정을 업그레이드하세요. |
| **내 전화 받기**가 연락처를 알아보지 못함 | Enconvo에 연락처를 허용하거나, 연락처를 읽을 수 있는 Mac이 먼저 받게 하세요. |

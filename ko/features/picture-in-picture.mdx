에이전트가 보이지 않는 브라우저 탭이나 앱 윈도우에서 일할 때, 화면 모서리의 작은 화면 속 화면 윈도우가 실시간으로 보여 줍니다. 자기 앱에서 계속 일하면서 에이전트가 하는 일을 보고, 필요할 때 바로 들어갈 수 있습니다.

Mac의 [브라우저 사용](/ko/features/browser-control)과 [컴퓨터 사용](/ko/features/computer-use)에서 동작합니다.

## 에이전트가 일하는 모습 보기

브라우저 사용이나 컴퓨터 사용을 쓰는 작업을 시작하세요. 에이전트가 화면 밖에서 일하는 동안 실시간 보기가 화면 모서리에 나타납니다. 탭은 초당 약 세 번 갱신되고, 앱 윈도우는 부드럽게 스트리밍됩니다.

여러 작업이 동시에 기다리면 카드가 쌓이고, **모두 보기**가 개수를 알려 줍니다. 더미를 열면 위쪽 막대가 실행 중인 개수를 말하고, **접기**로 카드를 다시 하나로 접고 **닫기**로 윈도우를 숨깁니다. 각 카드는 앱 아이콘과 작업 상태를 나타내는 점을 보여 줍니다. 윈도우를 끌면 카드도 함께 움직입니다.

다른 확장의 위젯이 있어 보여 줄 수 없는 페이지는 실시간 미리보기가 없다고 말합니다.

## 에이전트가 필요할 때 들어가기

에이전트가 사용자를 부르면 윈도우가 호박색으로 바뀌고 무엇이 필요한지 말합니다.

1. 화면 속 화면 윈도우를 클릭하세요. Enconvo가 해당 탭이나 앱 윈도우로 데려갑니다.
2. 에이전트가 필요한 일을 하세요.
3. **에이전트에게 돌려주기**를 클릭해 제어를 넘기세요. 에이전트는 그 지점부터 이어갑니다.

에이전트가 물을 때만이 아니라 언제든 윈도우를 클릭해 맡을 수 있습니다.

## 설정

윈도우가 언제 보이는지, 각각 따로 고르세요.

| 설정 | 옵션 |
| --- | --- |
| **설정 → 브라우저 사용 → 화면 속 화면 창** | **항상**(기본값), **내가 필요할 때만**, **끔** |
| **설정 → 컴퓨터 사용 → 화면 속 화면 창** | **항상**(기본값), **내가 필요할 때만**, **끔** |

**내가 필요할 때만**은 에이전트가 부를 때까지 윈도우를 숨깁니다.

에이전트가 보이지 않는 브라우저 탭이나 앱 창에서 작업하면, 화면 구석의 작은 화면 속 화면 창이 그 모습을 실시간으로 보여 줍니다. 사용자는 자신의 앱에서 계속 작업하면서 에이전트가 하는 일을 힐끗 보고, 필요한 순간에 바로 개입할 수 있습니다.

Mac에서 [브라우저 사용](/ko/features/browser-control) 및 [컴퓨터 사용](/ko/features/computer-use)과 함께 동작합니다.

## 에이전트의 작업 지켜보기

브라우저 사용이나 컴퓨터 사용을 쓰는 작업을 시작하세요. 에이전트가 보이지 않는 곳에서 작업하는 동안 실시간 화면이 화면 구석에 표시됩니다. 탭은 초당 약 세 번 갱신되고, 앱 창은 부드럽게 스트리밍됩니다.

여러 작업이 동시에 대기 중이면 카드가 겹쳐 쌓이고, **모두 보기**에 개수가 표시됩니다. 스택을 열면 위쪽 막대에 실행 중인 작업 수가 나타나며, **접기**로 카드를 다시 하나로 접고 **닫기**로 창을 숨길 수 있습니다. 각 카드에는 해당 앱의 아이콘과 작업 상태를 나타내는 점이 표시됩니다. 창을 드래그하면 카드도 함께 움직입니다.

다른 확장 프로그램의 위젯이 있어 표시할 수 없는 페이지는 실시간 미리보기가 없다고 알려 줍니다.

## 에이전트가 필요로 할 때 개입하기

에이전트가 사용자를 찾으면 창이 주황색으로 바뀌고 필요한 내용을 알려 줍니다.

1. 화면 속 화면 창을 클릭하세요. Enconvo가 해당 탭이나 앱 창으로 이동시켜 줍니다.
2. 에이전트에게 필요한 일을 하세요.
3. **에이전트에게 돌려주기**를 클릭해 다시 넘기세요. 에이전트가 거기서부터 이어서 진행합니다.

에이전트가 요청할 때만이 아니라 언제든지 창을 클릭해 직접 이어받을 수 있습니다.

## 설정

창이 표시되는 시점을 각각 따로 고를 수 있습니다.

| 설정 | 옵션 |
| --- | --- |
| **설정 → 브라우저 사용 → 화면 속 화면 창** | **항상**(기본값), **내가 필요할 때만**, **끔** |
| **설정 → 컴퓨터 사용 → 화면 속 화면 창** | **항상**(기본값), **내가 필요할 때만**, **끔** |

**내가 필요할 때만**은 에이전트가 사용자를 찾을 때까지 창을 숨겨 둡니다.

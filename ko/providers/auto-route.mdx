자동 라우팅은 가벼운 대화에는 빠른 모델을, 어려운 문제에는 더 강력한 모델을 적용하는 등 작업 유형별로 지정한 모델에서 각 메시지를 실행합니다. 별도 모델을 선택하지 않은 사용자의 기본 AI 모델이며, **AI 모델** 목록 맨 위에 자리하고 있습니다.

## 동작 방식

몇 가지 라우트를 설정하면 각 라우트가 처리할 작업 유형과 사용할 모델을 지정하게 됩니다. 메시지가 입력될 때마다 Enconvo가 가장 적합한 라우트를 고르고 해당 라우트의 모델로 메시지를 보냅니다. 라우팅 선택 자체는 무료이며 Enconvo 계정에 로그인되어 있어야 합니다.

기본 라우트는 모두 Enconvo Cloud에서 실행됩니다.

| 라우트 | 용도 | 기본 모델 |
| --- | --- | --- |
| **간단한 작업** | 인사, 짧은 사실 답변, 예/아니오 질문, 단일 단계 작업 | Enconvo Fast |
| **글쓰기 및 질의응답** | 채팅, 질문 답변, 초안 작성, 고쳐 쓰기, 번역, 요약 | Enconvo Fast |
| **중간 작업** | 작은 코드 수정, 파일이나 페이지 읽기, 옵션 비교, 계획 세우기 | Enconvo Balanced |
| **복잡한 작업** | 규모가 큰 코드 작업, 설계 결정, 다수 출처 조사, 긴 문서 처리 | Enconvo Ultra |

어느 라우트에도 해당하지 않는 메시지는 **대체**로 표시된 라우트에서 실행되며, 기본값은 **간단한 작업**이거나 이를 삭제한 경우 첫 번째 라우트입니다.

대화가 이미 진행 중인 상태에서 더 저렴한 모델로 전환하면 전체 비용이 오히려 늘 수 있는 경우, 자동 라우팅은 현재 모델을 그대로 유지합니다. 다른 모델로 바꾸면 프롬프트 캐시를 잃어 전환 비용이 유지 비용보다 커질 수 있기 때문입니다.

## 라우트 변경하기

<Steps>
  <Step title="자동 라우팅 열기">
    **설정 → AI 모델 → 자동 라우팅**을 열고 **모델 라우트**를 찾습니다.
  </Step>
  <Step title="라우트 편집하기">
    라우트를 클릭해 이름, **이 라우트가 맡는 작업**, **모델**, **추론 강도**를 변경합니다. 직접 등록한 API 키를 포함해 설정된 모든 제공업체의 모델을 사용할 수 있습니다.
  </Step>
  <Step title="라우트 추가 또는 삭제하기">
    새 작업 유형을 만들려면 **라우트 추가**를 클릭하고, 지우려면 **라우트 삭제**를 클릭하세요. **재설정**을 누르면 기본 라우트로 돌아갑니다.
  </Step>
</Steps>

각 라우트가 맡는 작업은 일상적인 말로 명확히 적으세요. 설명이 분명할수록 메시지가 알맞은 모델에 더 정확히 배정됩니다.

## 어떤 라우트가 답했는지 보기

응답 아래의 **세부 정보**를 클릭하면 추론 강도, 포인트 또는 비용, 토큰, 소요 시간과 함께 사용된 모델과 이를 선택한 자동 라우팅 라우트를 확인할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 자동 라우팅이 로그인을 요청함 | 라우트를 선택하려면 Enconvo 계정이 필요합니다. **설정 → 계정**에서 로그인하세요. |
| 메시지가 엉뚱한 모델로 전달됨 | 라우트들의 **이 라우트가 맡는 작업** 설명을 서로 더 명확하게 구분해 주세요. |
| 특정 라우트의 모델이 실패함 | 해당 라우트를 열어 모델의 제공업체를 확인하거나 다른 모델을 선택하세요. |

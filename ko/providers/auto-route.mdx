title: "Auto Route"

---

Auto Route는 각 메시지를 그 작업 종류에 맞게 지정한 모델에서 실행합니다. 가벼운 대화에는 빠른 모델을, 어려운 문제에는 더 강력한 모델을 씁니다. 모델을 고르지 않은 사용자에게는 기본 AI 모델이며 **AI 모델** 목록의 맨 위에 있습니다.

## 작동 방식

라우트 몇 개를 설정합니다. 각 라우트는 작업의 종류를 설명하고 그 작업을 맡을 모델을 지정합니다. 메시지마다 Enconvo가 가장 잘 맞는 라우트를 고르고 그 라우트의 모델로 메시지를 보냅니다. 라우트 선택은 무료이며 Enconvo 계정에 로그인되어 있어야 합니다.

기본 라우트는 모두 Enconvo Cloud에서 실행됩니다.

| 라우트 | 용도 | 기본 모델 |
| --- | --- | --- |
| **간단한 작업** | 인사, 짧은 사실 답변, 예/아니오 질문, 한 단계 동작 | Enconvo Fast |
| **글쓰기 및 Q&A** | 대화, 질문 답변, 초안 작성, 다시 쓰기, 번역, 요약 | Enconvo Fast |
| **중간 작업** | 작은 코드 변경, 파일이나 페이지 읽기, 선택지 비교, 계획 세우기 | Enconvo Balanced |
| **복잡한 작업** | 만만치 않은 코드, 설계 결정, 여러 출처에 걸친 조사, 긴 문서 | Enconvo Ultra |

어느 라우트에도 맞지 않는 메시지는 **대체**로 표시된 라우트에서 실행됩니다. 기본값은 **간단한 작업**이며, 그 라우트를 삭제하면 첫 번째 라우트입니다.

채팅이 진행 중일 때는 더 저렴한 모델로 바꾸는 것이 전체적으로 비용이 더 드는 경우 Auto Route가 현재 모델을 유지합니다. 다른 모델로 옮기면 프롬프트 캐시가 사라져서 바꾸는 편이 머무는 것보다 비용이 더 들 수 있습니다.

## 라우트 변경

<Steps>
  <Step title="Auto Route 열기">
    **설정 → AI 모델 → Auto Route**를 열고 **모델 라우트**를 찾습니다.
  </Step>
  <Step title="라우트 편집">
    라우트를 클릭해 이름, **이 라우트가 맡는 작업**, **모델**, **추론 강도**를 변경합니다. 모델은 설정해 둔 어느 제공업체에서든 가져올 수 있으며, 직접 발급한 API 키도 포함됩니다.
  </Step>
  <Step title="라우트 추가 또는 삭제">
    새로운 종류의 작업에는 **라우트 추가**를, 삭제하려면 **라우트 삭제**를 클릭합니다. **재설정**을 누르면 기본 라우트로 돌아갑니다.
  </Step>
</Steps>

각 라우트의 작업을 쉬운 말로 설명하세요. 설명이 분명할수록 메시지가 알맞은 모델에 더 잘 연결됩니다.

## 어느 라우트가 답했는지 확인

답변 아래의 **세부 정보**를 클릭하면 모델과 그 모델을 선택한 Auto Route 라우트, 그리고 추론 강도, 포인트 또는 비용, 토큰, 시간을 볼 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| Auto Route가 로그인하라고 합니다 | 라우트를 선택하려면 Enconvo 계정이 필요합니다. **설정 → 계정**에서 로그인하세요. |
| 메시지가 엉뚱한 모델로 갑니다 | 라우트의 **이 라우트가 맡는 작업** 설명이 더 뚜렷하게 구분되도록 고치세요. |
| 라우트의 모델이 실패합니다 | 해당 라우트를 열어 모델의 제공업체를 확인하거나 다른 모델을 선택하세요. |

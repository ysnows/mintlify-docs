---

Enconvo Cloud는 Enconvo 계정을 통해 여러 회사의 모델과 음성, 이미지, 동영상, 웹 도구를 제공합니다. 관리할 API 키가 없습니다. 요청은 플랜의 포인트를 씁니다. 시작하는 가장 빠른 방법입니다.

## 설정

<Steps>
  <Step title="로그인">
    Enconvo 계정에 로그인합니다. [계정](/ko/configuration/account)을 보세요.
  </Step>
  <Step title="Enconvo Cloud 고르기">
    하려는 일의 설정 페이지를 엽니다. **AI 모델**, **텍스트 음성 변환**, **이미지 생성** 등입니다. **Enconvo Cloud** 또는 **Enconvo Cloud Plan**으로 표시된 제공업체를 고릅니다.
  </Step>
  <Step title="모델이나 음성 고르기">
    모델이나 음성을 고르고 짧은 요청을 실행합니다.
  </Step>
</Steps>

기능마다 제공업체 선택이 따로 있습니다. 채팅에 Enconvo Cloud를 골라도 음성, 이미지, 동영상, 임베딩, 재순위, 웹 도구는 바뀌지 않습니다. 각각 원하는 곳에서 설정하세요.

## Enconvo 자체 모델

Enconvo Cloud에는 맞는 일에 따라 이름 붙인 자체 모델이 세 개 있습니다.

| 모델 | 쓰는 곳 |
| --- | --- |
| **Enconvo Fast** | 빠른 차례입니다. 짧은 답, 다시 쓰기, 작은 동작입니다. **Enconvo Cloud Plan**이 시작하는 모델이며, AI 명령의 기본입니다. |
| **Enconvo Balanced** | 단계가 몇 개인 일상 작업입니다. |
| **Enconvo Ultra** | 깊은 추론이 필요한 어려운 작업입니다. |

**Enconvo Cloud Plan** 아래에 먼저 나열되며, [Auto Route](/ko/providers/auto-route)가 기본 경로에 씁니다.

## 선택기에서 모델 찾기

**Enconvo Cloud Plan** 목록은 공급업체별로 모델을 묶습니다. Enconvo 자체 모델이 먼저이고, 그다음 Anthropic, OpenAI, Google, 나머지이며 각각 개수가 있습니다. 공급업체는 최신 모델 네 개를 보여 줍니다. **이전 모델 N개 보기**를 클릭하면 나머지가 보입니다. 검색은 모든 일치를 나열하고, 채팅이 쓰는 모델은 항상 표시됩니다. Claude 모델은 **Sonnet 5.5**, **Opus 5.5**처럼 "Claude" 접두어 없이 나열됩니다.

채팅 창의 모델 선택기에서 Cloud 모델에 태그가 있을 수 있습니다.

| 태그 | 의미 |
| --- | --- |
| **New** | 지난 14일 안에 추가되었습니다. |
| **50% OFF** 같은 할인 | 지금은 모델 비용이 더 낮습니다. 행을 가리키거나 화살표 키로 가면 정가가 보입니다. |
| **Free** | 모델이 포인트를 쓰지 않습니다. |
| **Preview** | 모델의 초기 버전입니다. |
| 날짜 | 모델이 Enconvo Cloud에서 떠나는 날입니다. |

태그는 Enconvo Cloud가 설정하므로 앱 업데이트 없이 바뀝니다.

## 포인트와 사용량

모델마다 포인트 수가 다릅니다. 설정은 각 모델과 제공업체 옆에 Cloud 가격을 보여 주고, 이번 달에 남은 무료 시간처럼 플랜에 포함된 것도 보여 줍니다. 현재 플랜과 요금은 [Cloud Plan](https://www.enconvo.com/cloud-plan)과 [Cloud 가격](https://www.enconvo.com/cloud-pricing) 페이지를 보세요. 쓴 것을 보려면 **설정 → 포인트 사용량**을 엽니다.

기본 모델인 [Auto Route](/ko/providers/auto-route)는 Enconvo Cloud 모델에서 실행됩니다. 메시지마다 경로를 고르는 것은 무료이고, 답하는 모델이 포인트를 씁니다.

일부 Cloud 서비스는 로그인한 모든 계정에 무료입니다.

- **Enconvo Cloud**와 **DeepSeek (Enconvo Cloud)**로 하는 웹 검색입니다. [웹 검색](/ko/ai/web-search)을 보세요.
- **Enconvo Cloud Fast**로 하는 음성 인식입니다. [음성 인식](/ko/ai/speech-recognition)을 보세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 요청이 로그인을 요구함 | **설정 → 계정**에서 로그인합니다. |
| 요청이 포인트나 잔액 오류로 실패함 | **설정 → 포인트 사용량**을 확인한 다음 [Cloud Plan](https://www.enconvo.com/cloud-plan) 페이지에서 플랜을 확인합니다. |
| 모델이 없음 | 선택기는 플랜에 포함된 것을 보여 줍니다. **모델 이름** 옆의 **새로고침**을 클릭합니다. |

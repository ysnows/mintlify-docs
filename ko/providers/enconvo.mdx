---

Enconvo Cloud는 Enconvo 계정을 통해 여러 회사의 모델과 음성, 이미지, 비디오, 웹 도구를 제공합니다. 관리할 API 키가 없고 요청에는 요금제의 포인트가 사용됩니다. 가장 빠르게 시작하는 방법입니다.

## 설정

<Steps>
  <Step title="로그인">
    Enconvo 계정에 로그인합니다. [계정](/ko/configuration/account)을 참고하세요.
  </Step>
  <Step title="Enconvo Cloud 선택">
    **AI 모델**, **텍스트 음성 변환**, **이미지 생성**처럼 하려는 일의 설정 페이지를 열고 **Enconvo Cloud** 또는 **Enconvo Cloud Plan**이라는 제공업체를 선택합니다.
  </Step>
  <Step title="모델 또는 음성 선택">
    모델이나 음성을 고르고 짧은 요청을 실행합니다.
  </Step>
</Steps>

각 기능에는 자체 제공업체 선택이 있습니다. 채팅에 Enconvo Cloud를 선택해도 음성, 이미지, 비디오, 임베딩, 재순위 지정, 웹 도구는 바뀌지 않으므로 각각 원하는 곳에서 설정하세요.

## Enconvo 자체 모델

Enconvo Cloud에는 어울리는 작업에 따라 이름 붙인 자체 모델이 세 가지 있습니다.

| 모델 | 용도 |
| --- | --- |
| **Enconvo Fast** | 빠른 응답: 짧은 답변, 다시 쓰기, 작은 동작. **Enconvo Cloud Plan**이 처음 사용하는 모델이며 AI 명령의 기본값입니다. |
| **Enconvo Balanced** | 몇 단계가 필요한 일상적인 작업. |
| **Enconvo Ultra** | 깊은 추론이 필요한 어려운 작업. |

이 모델들은 **Enconvo Cloud Plan** 아래에 가장 먼저 나열되며, [Auto Route](/ko/providers/auto-route)가 기본 라우트에 사용합니다.

## 선택기에서 모델 찾기

**Enconvo Cloud Plan** 목록은 모델을 업체별로 묶어 보여 줍니다. Enconvo 자체 모델이 먼저 나오고, 그다음에 Anthropic, OpenAI, Google 등이 이어지며 각각 개수가 표시됩니다. 업체에는 최신 모델 네 개가 표시되며, **이전 모델 N개 보기**를 클릭하면 나머지를 볼 수 있습니다. 검색하면 일치하는 모든 모델이 나열되고, 채팅에서 사용하는 모델은 항상 표시됩니다. Claude 모델은 **Sonnet 5.5**, **Opus 5.5**처럼 "Claude" 접두사 없이 나열됩니다.

채팅 창의 모델 선택기에서 Cloud 모델에는 태그가 붙을 수 있습니다.

| 태그 | 의미 |
| --- | --- |
| **New** | 최근 14일 안에 추가되었습니다. |
| **50% OFF** 같은 할인 | 당분간 모델 비용이 더 저렴합니다. 행에 포인터를 올리거나 화살표 키로 이동하면 정가를 볼 수 있습니다. |
| **Free** | 모델이 포인트를 사용하지 않습니다. |
| **Preview** | 모델의 초기 버전입니다. |
| 날짜 | 모델이 Enconvo Cloud에서 제공 종료되는 날입니다. |

태그는 Enconvo Cloud가 지정하므로 앱 업데이트 없이 바뀝니다.

## 포인트와 사용량

모델마다 비용이 다른 포인트로 책정됩니다. 설정에는 각 모델과 제공업체 옆에 Cloud 가격이 표시되며, 이번 달 남은 무료 시간처럼 요금제에 포함된 내용도 함께 나옵니다. 현재 요금제와 요율은 [Cloud Plan](https://www.enconvo.com/cloud-plan) 및 [Cloud 가격](https://www.enconvo.com/cloud-pricing) 페이지를 참고하세요. 사용량을 확인하려면 **설정 → 포인트 사용량**을 엽니다.

기본 모델인 [Auto Route](/ko/providers/auto-route)는 Enconvo Cloud 모델에서 실행됩니다. 메시지마다 라우트를 고르는 것은 무료이며, 답하는 모델이 포인트를 사용합니다.

일부 Cloud 서비스는 로그인한 모든 계정에 무료입니다.

- **Enconvo Cloud**와 **DeepSeek (Enconvo Cloud)**를 사용한 웹 검색. [웹 검색](/ko/ai/web-search)을 참고하세요.
- **Enconvo Cloud Fast**를 사용한 음성 인식. [음성 인식](/ko/ai/speech-recognition)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 요청이 로그인하라고 합니다 | **설정 → 계정**에서 로그인하세요. |
| 포인트나 잔액 오류로 요청이 실패합니다 | **설정 → 포인트 사용량**을 확인한 다음 [Cloud Plan](https://www.enconvo.com/cloud-plan) 페이지에서 요금제를 확인하세요. |
| 모델이 없습니다 | 선택기에는 요금제에 포함된 모델이 표시됩니다. **모델 이름** 옆의 **새로고침**을 클릭하세요. |

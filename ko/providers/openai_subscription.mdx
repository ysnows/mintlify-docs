---
title: "ChatGPT 구독"
description: "ChatGPT 요금제로 로그인해 API 키 없이 Enconvo에서 OpenAI 모델을 사용합니다."
---

ChatGPT를 결제 중이라면 API 키를 만드는 대신 그 요금제로 로그인하세요. 요청은 요금제의 사용 한도를 사용하며, Enconvo가 남은 양을 보여 줍니다.

## 연결

<Steps>
  <Step title="구독 선택">
    **설정 → AI 모델 → OpenAI**를 엽니다. **인증**에서 **ChatGPT 구독**을 선택합니다.
  </Step>
  <Step title="로그인">
    **연결**을 클릭하고 브라우저에서 ChatGPT 계정에 로그인한 다음 접근을 허용합니다. 브라우저에서 완료되었다고 표시되면 Enconvo로 돌아옵니다.
  </Step>
  <Step title="모델 선택">
    계정 카드에 올바른 계정이 표시되는지 확인하고, **모델 이름**에서 모델을 고른 다음 짧은 메시지를 보내 보세요.
  </Step>
</Steps>

Enconvo가 백그라운드에서 로그인을 갱신하므로 며칠마다 다시 로그인할 필요가 없습니다.

## 사용량 확인

계정 카드에는 각 사용량 구간에서 남은 양(**% 남음**)과 초기화 시점, 요금제가 갱신되거나 종료되는 시점이 표시됩니다. 카드 메뉴를 열면 다음을 사용할 수 있습니다.

- **사용량 새로고침**: 최신 수치를 가져옵니다.
- **다시 연결**: 계정을 바꾸는 등의 이유로 다시 로그인합니다.

OpenAI가 사용량을 알려 주지 않으면 카드에 **사용량을 확인할 수 없음**이 이유와 함께 표시됩니다. 요금제에 한도가 없다는 뜻은 아닙니다.

### 무료 초기화 사용

Codex에서 무료 한도 초기화를 받으면 카드에 **무료 초기화**가 표시됩니다. 남은 개수와 만료 시점을 볼 수 있습니다. **초기화 사용**을 클릭하고 확인하면 한도가 바로 다시 채워집니다. 초기화는 되돌릴 수 없습니다.

## 요금제가 포함하는 범위

ChatGPT 로그인은 OpenAI 이미지 생성과 음성 텍스트 변환에도 사용할 수 있습니다. 해당 페이지의 **인증**에서 **ChatGPT 구독**을 선택하세요. OpenAI 텍스트 음성 변환과 임베딩에는 API 키가 필요하며, Live Talk 음성은 별도로 설정합니다.

## iPhone에서

iPhone 앱에는 휴대전화 채팅용 자체 ChatGPT 로그인이 있습니다. iPhone에서 **설정 → AI 모델 → OpenAI**를 열고 **인증**에서 ChatGPT 카드를 선택한 다음 **ChatGPT로 로그인**을 탭하세요. 그러면 페이지에 요금제, 5시간 및 주간 한도의 남은 양, 각각의 초기화 시점이 표시됩니다. 이 로그인은 iPhone에만 유지되며 Mac은 자체 로그인을 따로 유지합니다. [iPhone 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 로그인에 실패합니다 | OpenAI가 알려 준 오류를 읽고 **연결**을 다시 클릭하세요. 요금제가 있는 계정으로 로그인하는지 확인하세요. |
| 모델이 없습니다 | 요금제에 따라 모델이 정해집니다. **모델 이름** 옆의 **새로고침**을 클릭하세요. |
| 채팅에 사용 한도에 도달했다고 표시됩니다 | 카드에 무료 초기화가 있으면 사용하거나, 계정 카드에 표시된 초기화 시각까지 기다리거나, 당분간 **인증**을 **API 키**로 바꾸세요. |
| 시간이 지나면 채팅이 작동하지 않습니다 | 계정 카드의 메뉴를 열고 **다시 연결**을 클릭하세요. |

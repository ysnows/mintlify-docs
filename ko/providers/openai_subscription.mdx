---
title: "ChatGPT 구독"
description: "API 키 없이 Enconvo에서 OpenAI 모델을 쓰려면 ChatGPT 요금제로 로그인하세요."
---

ChatGPT를 결제 중이면 API 키를 만드는 대신 그 요금제로 로그인하세요. 요청은 요금제 허용량을 쓰고, Enconvo가 남은 양을 보여 줍니다.

## 연결

<Steps>
  <Step title="구독 고르기">
    **설정 → AI 모델 → OpenAI**를 여세요. **인증** 아래에서 **ChatGPT 구독**을 고르세요.
  </Step>
  <Step title="로그인">
    **연결**을 클릭하고 브라우저에서 ChatGPT 계정에 로그인한 뒤 접근을 허용하세요. 브라우저가 끝났다고 하면 Enconvo로 돌아오세요.
  </Step>
  <Step title="모델 고르기">
    계정 카드가 맞는 계정을 보여 주는지 확인하고, **모델 이름**에서 모델을 고른 뒤 짧은 메시지를 보내세요.
  </Step>
</Steps>

Enconvo는 배경에서 로그인을 갱신하므로, 며칠마다 다시 로그인할 필요는 없습니다.

## 사용량 확인

계정 카드는 각 사용 창이 얼마나 남았는지(**% 남음**)와 언제 초기화되는지, 요금제가 언제 갱신되거나 끝나는지를 보여 줍니다. 카드 메뉴에서:

- **사용량 새로고침**: 최신 숫자를 가져옵니다.
- **다시 연결**: 다시 로그인합니다. 예를 들어 계정을 바꿀 때입니다.

OpenAI가 사용량을 보고하지 않으면 카드가 이유와 함께 **사용량을 확인할 수 없음**이라고 말합니다. 요금제에 한도가 없다는 뜻은 아닙니다.

### 무료 초기화 쓰기

Codex가 무료 한도 초기화를 주면 카드에 **무료 초기화**가 나열됩니다. 남은 횟수와 만료 시각입니다. **초기화 사용**을 클릭한 뒤 확인하면 한도가 바로 채워집니다. 초기화는 되돌릴 수 없습니다.

## 요금제가 포함하는 것

ChatGPT 로그인은 OpenAI 이미지 생성과 음성 텍스트 변환에도 동작합니다. 그 페이지의 **인증** 아래에서 **ChatGPT 구독**을 고르세요. OpenAI 텍스트 음성 변환과 임베딩은 API 키가 필요하고, Live Talk 목소리는 따로 설정합니다.

## iPhone에서

iPhone 앱에는 Phone chats용 ChatGPT 로그인이 따로 있습니다. iPhone에서 **설정 → AI 모델 → OpenAI**를 열고, **인증** 아래 ChatGPT 카드를 고른 뒤 **ChatGPT로 로그인**을 탭하세요. 그러면 페이지가 요금제, 5시간 한도와 주간 한도가 얼마나 남았는지, 각각 언제 초기화되는지를 보여 줍니다. 그 로그인은 iPhone에 남고, Mac은 자기 로그인을 유지합니다. [Phone Chats](/ko/integrations/iphone-phone-chats)를 보세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 로그인 실패 | OpenAI가 준 오류를 읽은 뒤 **연결**을 다시 클릭하세요. 요금제가 있는 계정으로 로그인하는지 확인하세요. |
| 모델이 없음 | 요금제가 모델을 정합니다. **모델 이름** 옆 **새로고침**을 클릭하세요. |
| 채팅이 사용량 한도에 도달했다고 함 | 카드에 있으면 무료 초기화를 쓰거나, 계정 카드의 초기화 시각을 기다리거나, 당분간 **인증**을 **API 키**로 바꾸세요. |
| 한동안 지나면 채팅이 멈춤 | 계정 카드 메뉴를 열고 **다시 연결**을 클릭하세요. |

GitHub Copilot 요금제를 Enconvo의 AI 모델 제공업체로 사용하세요. 요금제가 있는 GitHub 계정으로 로그인하며 API 키는 필요하지 않습니다. 프리미엄 모델은 요금제의 프리미엄 요청 횟수에 포함됩니다.

## 연결

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델 → GitHub Copilot**을 엽니다.
  </Step>
  <Step title="로그인 시작">
    **인증**에서 **연결**을 클릭합니다.
  </Step>
  <Step title="GitHub에서 코드 입력">
    브라우저에서 GitHub의 기기 페이지가 열리고, Enconvo가 그곳에 입력할 코드를 보여 줍니다. 코드를 입력하고 로그인을 승인하세요.
  </Step>
  <Step title="계정 확인">
    Enconvo로 돌아와 의도한 GitHub 계정이 연결되었는지 확인합니다.
  </Step>
  <Step title="모델 선택">
    모델을 선택하고 짧은 요청을 시도해 보세요.
  </Step>
</Steps>

승인하기 전에 Enconvo의 코드 대화상자를 닫으면 로그인이 취소됩니다.

## 모델과 옵션

모델 목록에는 Copilot 요금제에서 사용할 수 있는 모델만 표시되며, Copilot 자체의 채팅 기본값이 맨 앞에 나옵니다. Copilot Free는 유료 요금제보다 제공하는 모델이 적으므로 다른 곳에서 본 모델이 목록에 없을 수 있습니다. 각 모델은 Copilot이 해당 모델에 제공하는 추론 강도 단계를 사용합니다.

## iPhone에서

iPhone 앱도 휴대전화 채팅을 위해 GitHub Copilot에 로그인할 수 있습니다. [iPhone 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 로그인이 끝나지 않습니다 | 코드가 만료되기 전에 GitHub 페이지에 입력한 다음 **연결**을 다시 클릭해 새 코드를 받으세요. |
| 원하는 모델이 목록에 없습니다 | Copilot 요금제에 포함되지 않은 모델입니다. 다른 모델을 고르거나 요금제를 업그레이드하세요. |
| 요청이 모델 오류로 실패합니다 | 현재 목록에서 모델을 고르세요. 요금제가 바뀌기 전에 선택한 기본값은 더 이상 제공되지 않을 수 있습니다. |
| 속도 또는 사용 한도 | 요금제의 프리미엄 요청 횟수와 GitHub의 속도 제한입니다. |

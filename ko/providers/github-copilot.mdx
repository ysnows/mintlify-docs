Enconvo에서 GitHub Copilot 요금제를 AI 모델 제공업체로 사용할 수 있습니다. API 키 없이 요금제가 있는 GitHub 계정으로 로그인하면 됩니다. 프리미엄 모델을 사용하면 요금제의 프리미엄 요청 횟수가 차감됩니다.

## 연결하기

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델 → GitHub Copilot**을 엽니다.
  </Step>
  <Step title="로그인 시작하기">
    **인증**에서 **연결**을 클릭합니다.
  </Step>
  <Step title="GitHub에 코드 입력하기">
    브라우저에서 GitHub 기기 인증 페이지가 열리고, Enconvo 화면에 입력할 코드가 표시됩니다. 코드를 입력하고 로그인을 승인하세요.
  </Step>
  <Step title="계정 확인하기">
    Enconvo로 돌아와 원하는 GitHub 계정이 제대로 연결되었는지 확인합니다.
  </Step>
  <Step title="모델 선택하기">
    모델을 선택하고 짧은 요청을 보내 봅니다.
  </Step>
</Steps>

승인하기 전에 Enconvo의 코드 대화상자를 닫으면 로그인이 취소됩니다.

## 모델 및 옵션

모델 목록에는 Copilot 요금제에서 사용할 수 있는 모델만 표시되며, Copilot 기본 채팅 모델이 맨 위에 옵니다. Copilot Free는 유료 요금제보다 제공하는 모델 수가 적으므로 다른 곳에서 본 모델이 목록에 없을 수 있습니다. 각 모델은 Copilot이 해당 모델에 제공하는 추론 강도 수준을 사용합니다.

## iPhone에서 사용하기

iPhone 앱에서도 GitHub Copilot에 로그인해 폰 채팅에서 사용할 수 있습니다. [폰 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 로그인이 완료되지 않음 | 코드가 만료되기 전에 GitHub 페이지에 입력하세요. 만료되었다면 **연결**을 다시 클릭해 새 코드를 받으세요. |
| 원하는 모델이 목록에 없음 | 사용 중인 Copilot 요금제에 해당 모델이 포함되어 있지 않습니다. 다른 모델을 선택하거나 요금제를 업그레이드하세요. |
| 모델 오류로 요청이 실패함 | 현재 목록에서 모델을 다시 선택하세요. 요금제가 변경되기 전에 선택한 기본 모델은 더 이상 제공되지 않을 수 있습니다. |
| 요청 빈도 또는 사용 한도 오류 | 요금제의 프리미엄 요청 한도와 GitHub의 요청 빈도 제한을 확인하세요. |

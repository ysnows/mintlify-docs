---
title: "Soniox"
description: "Enconvo에서 받아쓰기, 녹음, 파일 음성 텍스트 변환에 Soniox 음성을 텍스트로 씁니다."
---

Soniox는 많은 언어로 실시간과 파일에서 음성을 텍스트로 바꾸며, 녹음하면서 실시간 자막을 번역할 수 있습니다. 키 없이 Enconvo Cloud를 통해 쓰거나, 자신의 Soniox API 키로 씁니다.

<Note>
**Soniox (Enconvo Cloud)**에는 API 키가 필요 없으며, Soniox 받아쓰기는 Cloud Plan, Lifetime, 체험 회원에게 무료입니다.
</Note>

## 연결

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="제공업체 고르기">
        **설정 → 받아쓰기 모델**을 열고 **Soniox (Enconvo Cloud)**를 고릅니다.
      </Step>
      <Step title="시험">
        짧은 문장을 받아씁니다. 말하는 동안 텍스트가 나타나야 합니다.
      </Step>
    </Steps>
  </Tab>
  <Tab title="자신의 API 키">
    <Steps>
      <Step title="API 키 받기">
        [Soniox Console](https://console.soniox.com)에서 프로젝트를 열고 API 키를 만듭니다.
      </Step>
      <Step title="Enconvo에 추가">
        **설정 → 받아쓰기 모델**을 열고 **Soniox**를 고릅니다. 키를 Soniox 자격 증명에 붙여 넣은 다음 **검증**을 클릭합니다.
      </Step>
      <Step title="시험">
        짧은 문장을 받아씁니다. 말하는 동안 텍스트가 나타나야 합니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

녹음이나 파일에도 Soniox를 쓰려면 **설정 → 녹음 모델** 또는 **설정 → 음성 텍스트 변환 모델**에서 고릅니다. 각 페이지는 자신의 선택을 유지합니다.

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델** | Soniox 모델. **Soniox STT Realtime v5**(기본) 같은 실시간 모델은 말하는 동안 텍스트를 쓰고, **Soniox STT Async v5** 같은 비동기 모델은 끝난 파일을 변환합니다. [Soniox 모델](https://soniox.com/docs/stt/models)을 보세요. |
| **언어 힌트** | 우선할 언어. 기본은 영어와 중국어입니다. 말하면서 언어를 바꾸면 여러 개를 추가합니다. |
| **실시간 번역** | 녹음하면서 실시간 자막을 번역합니다. 저장된 녹음은 원어 대화 기록을 유지합니다. 기본은 꺼짐. |
| **번역 원본** | 오디오의 언어. **자동**은 Soniox가 감지하게 합니다. |
| **번역 대상** | 번역된 자막의 언어. |
| **번역 읽어 주기** | 기본 음성으로 번역된 자막을 소리 내어 읽습니다. 기본은 꺼짐. |

Soniox에는 **설정 → 텍스트 음성 변환** 아래에 자신의 키 또는 Enconvo Cloud의 텍스트 음성 변환 제공업체도 있습니다.

Soniox는 클라우드에서 오디오를 처리합니다. 음성을 Mac에 두려면 Parakeet MLX, Qwen3 MLX, Whisper MLX 같은 로컬 제공업체를 대신 쓰세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **검증** 실패 | 여분의 공백 없이 Soniox Console에서 키를 다시 복사하고, 올바른 프로젝트에 속하는지 확인합니다. |
| 말하는 동안 텍스트가 나타나지 않음 | 실시간 모델을 고른 다음 받아쓰기를 다시 시작합니다. |
| 단어가 잘못된 언어로 나옴 | **언어 힌트**를 실제로 말하는 언어로 설정합니다. |
| 파일이 대화 기록을 주지 않음 | MP3, WAV, FLAC, M4A 같은 흔한 형식을 시도하고 Soniox 사용량과 청구를 확인합니다. |

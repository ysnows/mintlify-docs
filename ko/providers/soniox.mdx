---
title: "Soniox"
description: "Enconvo에서 받아쓰기, 녹음, 파일 음성 텍스트 변환에 Soniox 음성 인식을 사용하세요."
---

Soniox는 여러 언어의 음성을 실시간으로, 또는 파일에서 텍스트로 변환하며, 녹음하는 동안 실시간 자막을 번역할 수도 있습니다. 키 없이 Enconvo Cloud를 통해 사용하거나, 본인의 Soniox API 키로 사용할 수 있습니다.

<Note>
**Soniox (Enconvo Cloud)**는 API 키가 필요 없으며, Cloud Plan, Lifetime, 체험 회원은 Soniox 받아쓰기를 무료로 사용할 수 있습니다.
</Note>

## 연결

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="제공업체 선택">
        **설정 → 받아쓰기 모델**을 열고 **Soniox (Enconvo Cloud)**를 선택하세요.
      </Step>
      <Step title="테스트">
        짧은 문장을 받아쓰기로 말해 보세요. 말하는 대로 텍스트가 나타나야 합니다.
      </Step>
    </Steps>
  </Tab>
  <Tab title="내 API 키">
    <Steps>
      <Step title="API 키 받기">
        [Soniox 콘솔](https://console.soniox.com)에서 프로젝트를 열고 API 키를 만드세요.
      </Step>
      <Step title="Enconvo에 추가">
        **설정 → 받아쓰기 모델**을 열고 **Soniox**를 선택하세요. Soniox 자격 증명에 키를 붙여넣고 **검증**을 클릭하세요.
      </Step>
      <Step title="테스트">
        짧은 문장을 받아쓰기로 말해 보세요. 말하는 대로 텍스트가 나타나야 합니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

녹음이나 파일에도 Soniox를 사용하려면 **설정 → 녹음 모델** 또는 **설정 → 음성 텍스트 변환 모델**에서 선택하세요. 각 페이지는 자체 선택을 유지합니다.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델** | Soniox 모델입니다. **Soniox STT Realtime v5**(기본값) 같은 실시간 모델은 말하는 대로 텍스트를 쓰고, **Soniox STT Async v5** 같은 비동기 모델은 완성된 파일을 변환합니다. [Soniox 모델](https://soniox.com/docs/stt/models)을 참고하세요. |
| **Language Hints** | 우선할 언어입니다. 기본값은 영어와 중국어입니다. 말하는 도중 언어를 바꾼다면 여러 개를 추가하세요. |
| **실시간 번역** | 녹음하는 동안 실시간 자막을 번역합니다. 저장된 녹음에는 원본 언어의 대본이 그대로 남습니다. 기본값은 꺼짐입니다. |
| **원본 언어** | 오디오의 언어입니다. **자동**을 선택하면 Soniox가 감지합니다. |
| **Translate To** | 번역된 자막의 언어입니다. |
| **Speak Translation** | 번역된 자막을 기본 음성으로 소리 내어 읽습니다. 기본값은 꺼짐입니다. |

Soniox는 **설정 → 텍스트 음성 변환**에서 선택할 수 있는 텍스트 음성 변환 제공업체도 갖추고 있으며, 본인의 키나 Enconvo Cloud로 사용할 수 있습니다.

Soniox는 오디오를 클라우드에서 처리합니다. 음성을 Mac 안에 두려면 대신 Parakeet MLX, Qwen3 MLX, Whisper MLX 같은 로컬 제공업체를 사용하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | Soniox 콘솔에서 키를 공백 없이 다시 복사하고, 올바른 프로젝트의 키인지 확인하세요. |
| 말하는 동안 텍스트가 나타나지 않음 | 실시간 모델을 고른 다음 받아쓰기를 다시 시작하세요. |
| 단어가 엉뚱한 언어로 나옴 | **Language Hints**를 실제로 사용하는 언어로 설정하세요. |
| 파일에서 대본이 나오지 않음 | MP3, WAV, FLAC, M4A 같은 일반적인 형식을 시도하고, Soniox 사용량과 결제를 확인하세요. |

제공업체는 Enconvo 기능의 배후에 있는 서비스입니다. 채팅에 답하는 모델, 소리 내어 읽어 주는 음성, 웹을 검색하는 엔진 등이 해당합니다. 기능마다 하나씩 선택하며 섞어서 사용할 수 있습니다.

아래 영상은 **설정 → AI 모델**을 2분 동안 안내합니다. Auto Route, Cloud 요금제, ChatGPT, Claude, GitHub Copilot, Antigravity, Grok 요금제로 로그인하기, API 키, Mac의 모델, Ollama와 LM Studio, 나만의 제공업체 추가를 다룹니다.

## 연결 방법 선택

| 원하는 것 | 사용할 것 | 시작하기 |
| --- | --- | --- |
| 키 없이 바로 시작 | Enconvo 계정을 통한 Enconvo Cloud | [Enconvo Cloud](/ko/providers/enconvo) |
| 메시지마다 Enconvo가 모델을 선택 | 기본 모델인 Auto Route | [Auto Route](/ko/providers/auto-route) |
| 이미 결제 중인 요금제 사용 | ChatGPT, Claude, Grok, Mistral, GitHub Copilot, Antigravity로 로그인 | [요금제로 로그인](#요금제로-로그인) |
| 제공업체에 직접 결제 | 직접 발급한 API 키 | [인기 제공업체](#인기-제공업체) |
| 키 하나로 여러 회사의 모델 이용 | OpenRouter나 PipeLLM 같은 게이트웨이 | [OpenRouter](/ko/providers/openrouter), [PipeLLM](/ko/providers/pipellm) |
| 채팅을 Mac에 보관 | 로컬 모델 | [로컬 모델](/ko/ai/local-llm) |
| Ollama나 LM Studio에서 이미 실행 중인 모델 사용 | **Ollama** 또는 **LM Studio** 제공업체 | [Ollama](/ko/providers/ollama), [LM Studio](/ko/providers/lm-studio) |
| iPhone 앱 자체 채팅에서 모델 사용 | 휴대전화 채팅 | [휴대전화 채팅](/ko/integrations/iphone-phone-chats) |

## 채팅 모델 선택

<Steps>
  <Step title="AI 모델 열기">
    **설정 → AI 모델**을 엽니다. 가운데 열에 모든 제공업체가 나열됩니다. 맨 위에 **Auto Route**와 **Enconvo Cloud Plan**이 있고, 그다음에 각 회사, 로컬 모델, 나머지 모든 제공업체가 이어집니다.
  </Step>
  <Step title="제공업체를 선택하고 연결">
    제공업체를 클릭합니다. 둘 다 제공되는 경우 직접 발급한 키로 요청마다 제공업체에 비용을 내려면 **API 키**를, 로그인해서 요금제에 포함된 사용량을 쓰려면 구독 옵션(예: **ChatGPT 구독**)을 선택하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고, 제공업체에 있으면 **추론 강도**도 고릅니다.
  </Step>
  <Step title="기본값으로 지정">
    **기본값으로 설정**을 클릭합니다. 자체 모델을 지정하지 않은 채팅과 기능이 이제 이 모델을 사용합니다.
  </Step>
</Steps>

목록에 없는 서비스를 추가하려면 목록 하단의 **새 제공업체 추가**를 클릭하고 **OpenAI 호환** 또는 **Anthropic 호환**을 선택하세요.

제공업체는 언제든 바꿀 수 있으며, 채팅이 특정 회사에 묶이지 않습니다.

**설정 → AI 모델** 상단에는 채팅 제목과 제안을 만드는 작은 모델을 위한 **작업 모델**과, 채팅의 모델을 쓸 수 없을 때 대신하는 백업 모델을 위한 **대체**도 있습니다. [모델 선택](/ko/ai/model-selection-guide)을 참고하세요.

## 기능별로 제공업체 지정

각 기능에는 자체 설정 페이지가 있습니다. **AI 모델**, **텍스트 음성 변환**, **웹 검색**, **이미지 생성**, **동영상 생성**, **웹페이지 가져오기**, **OCR**입니다. 음성 인식에는 **받아쓰기 모델**, **녹음 모델**, **음성 텍스트 변환 모델**, **자막 생성 모델**이라는 별도의 페이지가 있습니다. 임베딩과 재순위 지정은 지식 베이스에서 설정합니다.

채팅 모델을 고른다고 해서 음성, 이미지, 검색 제공업체가 바뀌지는 않습니다. 각각 원하는 곳에서 설정하세요.

## 프로필

제공업체 프로필에는 키 또는 로그인 하나가 들어 있습니다. 회사 계정처럼 두 번째 프로필을 두려면 제공업체 페이지에서 **새 제공업체 추가**를 클릭하세요. 일부 프로필은 여러 기능에서 쓰입니다. OpenAI 프로필 하나가 채팅, 임베딩, 텍스트 음성 변환, 이미지, 음성 텍스트 변환을 모두 다루므로 키를 바꾸면 모두 바뀝니다. [자격 증명 및 프로필](/ko/configuration/credentials)을 참고하세요.

기본 모델이 설정되는 위치와 각 채팅이 자신의 모델을 유지하는 방식은 [모델 선택](/ko/ai/model-selection-guide)에 있습니다.

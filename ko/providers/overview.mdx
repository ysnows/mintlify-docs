제공업체는 Enconvo 기능 뒤에서 실제로 동작하는 서비스입니다. 채팅에 답하는 모델, 소리 내어 읽어 주는 음성, 웹을 검색하는 엔진 등이 여기에 해당하며, 기능마다 하나씩 선택해 조합할 수 있습니다.

아래 동영상은 **설정 → AI 모델**을 2분 만에 안내합니다. 자동 라우팅, Cloud 요금제, ChatGPT·Claude·GitHub Copilot·Antigravity·Grok 요금제 로그인, API 키, Mac의 로컬 모델, Ollama 및 LM Studio, 사용자 지정 제공업체 추가까지 다룹니다.

## 연결 방식 선택하기

| 원하는 방식 | 사용할 항목 | 시작하기 |

| 메시지마다 Enconvo가 모델을 고르게 하기 | 기본 모델인 자동 라우팅 | [자동 라우팅](/ko/providers/auto-route) |
| 이미 결제 중인 요금제 활용하기 | ChatGPT, Claude, Grok, Mistral, GitHub Copilot 또는 Antigravity로 로그인 | [요금제로 로그인하기](#요금제로-로그인하기) |

| iPhone 앱 자체 채팅에서 모델 사용하기 | 휴대폰 채팅 | [휴대폰 채팅](/ko/integrations/iphone-phone-chats) |

## 채팅 모델 선택하기

<Steps>
  <Step title="AI 모델 열기">
    **설정 → AI 모델**을 엽니다. 가운데 열에 모든 제공업체가 나열됩니다. 맨 위에 **자동 라우팅**과 **Enconvo Cloud 요금제**가 있고, 그 아래에 각 회사, 로컬 모델 및 기타 제공업체가 이어집니다.
  </Step>
  <Step title="제공업체 선택 및 연결">
    제공업체를 클릭합니다. 두 방식을 모두 지원하는 경우 보유한 키로 요청당 과금되는 **API 키** 또는 요금제 혜택을 쓰는 구독 옵션(예: **ChatGPT Subscription**)을 선택해 로그인합니다.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고, 해당 제공업체가 지원한다면 **추론 강도**도 선택합니다.
  </Step>
  <Step title="기본값으로 지정">
    **기본값으로 설정**을 클릭합니다. 이제 별도 모델을 지정하지 않은 채팅과 기능이 이 모델을 사용합니다.
  </Step>
</Steps>

목록에 없는 서비스를 추가하려면 목록 하단의 **새 제공업체 추가**를 클릭하고 **OpenAI 호환** 또는 **Anthropic 호환**을 선택하세요.

제공업체는 언제든 바꿀 수 있으며, 채팅이 특정 회사에 묶이지 않습니다.

**설정 → AI 모델** 상단에는 채팅 제목과 제안을 담당하는 소형 모델을 설정하는 **작업 모델**과, 채팅 모델이 동작하지 않을 때 대신 이어받는 백업 모델을 설정하는 **대체(Fallback)**도 있습니다. [모델 선택하기](/ko/ai/model-selection-guide)를 참고하세요.

## 기능별로 제공업체 설정하기

각 기능에는 자체 설정 페이지가 있습니다: **AI 모델**, **텍스트 음성 변환**, **웹 검색**, **이미지 생성**, **동영상 생성**, **웹페이지 가져오기**, **OCR**. 음성 인식은 **받아쓰기 모델**, **녹음 모델**, **음성 텍스트 변환 모델**, **자막 생성 모델** 페이지로 나뉘어 있습니다. 임베딩과 리랭킹은 지식 베이스에서 설정합니다.

채팅 모델을 바꾼다고 해서 음성, 이미지, 검색 제공업체까지 바뀌지는 않습니다. 각 기능에서 원하는 제공업체를 따로 설정하세요.

## 프로필

제공업체 프로필에는 하나의 키 또는 로그인 정보가 저장됩니다. 업무용 계정처럼 두 번째 프로필을 유지하려면 제공업체 페이지에서 **새 제공업체 추가**를 클릭하세요. 일부 프로필은 여러 기능을 함께 담당합니다. 예를 들어 하나의 OpenAI 프로필이 채팅, 임베딩, 텍스트 음성 변환, 이미지, 음성 텍스트 변환을 모두 맡으므로 해당 키를 바꾸면 이 기능들이 함께 바뀝니다. [자격 증명 및 프로필](/ko/configuration/credentials)을 참고하세요.

기본 모델 설정 위치와 각 채팅이 자체 모델을 유지하는 방식은 [모델 선택하기](/ko/ai/model-selection-guide)에서 확인할 수 있습니다.

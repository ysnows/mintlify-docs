title: "Cerebras"
description: "자신의 Cerebras API 키를 사용해 Enconvo에서 Cerebras 모델과 대화하세요."
---

Cerebras는 API 키를 통해 모델을 제공합니다. Enconvo에 키를 추가하면 채팅, 에이전트, AI 명령에서 해당 모델을 사용할 수 있습니다. 사용량은 본인 Cerebras 계정으로 청구됩니다. 설정에서는 **Cerebras AI**로 표시됩니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    [Cerebras](https://cerebras.ai/)에서 키를 생성합니다.
  </Step>
  <Step title="Enconvo에 키 추가하기">
    **설정 → AI 모델 → Cerebras AI**를 엽니다. **인증** 아래의 **API 키**에 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보내 봅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

업무용 등 두 번째 Cerebras 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델 및 옵션

| 설정 | 설명 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용할 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴 아이콘)에서는 모델을 추가하거나 복원할 수 있습니다. |

한 채팅에서만 다른 모델을 사용하려면 해당 채팅의 모델 선택기에서 선택하세요.

모델 세부 정보와 제한 사항은 [Cerebras 추론 문서](https://inference-docs.cerebras.ai/openai)를 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 Cerebras 계정에서 키가 활성화되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭해 목록을 다시 불러오세요. 모델을 직접 추가하려면 **모델 관리**를 사용하세요. |
| 이미지나 도구 호출이 실패함 | 이미지 입력 또는 도구 호출을 지원하는 모델을 선택하세요. |
| 요청 빈도 또는 사용 한도 오류 | Cerebras 계정에서 사용량과 한도를 확인하거나 당분간 다른 제공업체로 전환하세요. |
| 응답이 느림 | 더 작은 모델을 선택하거나 입력 길이를 줄이거나 추론 강도를 낮춰 보세요. |

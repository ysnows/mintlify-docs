title: "OpenClaw"
description: "Enconvo에서 OpenClaw 에이전트를 OpenAI 호환 모델로 사용하세요"
---

OpenClaw는 채팅, 메신저 채널, 도구, 스킬, 자동화 전반에서 어시스턴트를 운영하는 셀프 호스팅 AI 에이전트 플랫폼입니다.

OpenClaw는 OpenAI 호환 게이트웨이로 에이전트를 제공할 수 있습니다. 게이트웨이를 활성화하면 Enconvo가 채팅, Enconvo 에이전트, 모델 기반 기능을 포함해 OpenClaw 에이전트를 다른 AI 모델처럼 사용할 수 있습니다.

OpenClaw의 게이트웨이는 `/v1/models`, `/v1/chat/completions`, `/v1/responses` 같은 OpenAI 호환 엔드포인트를 제공합니다. Enconvo의 OpenClaw 제공업체는 Chat Completions API(`/v1/chat/completions`)를 사용합니다.

<Note>
  Enconvo는 이 제공업체에서 OpenClaw Responses API를 사용하지 않습니다. OpenClaw를 OpenAI 호환 Chat Completions 게이트웨이로 구성하세요.
</Note>

OpenClaw가 처음이라면 [OpenClaw 시작 가이드](https://docs.openclaw.ai/start/getting-started)부터 시작한 다음, 여기로 돌아와 Enconvo에 연결하세요.

게이트웨이 엔드포인트 전체 레퍼런스는 [OpenClaw 게이트웨이 문서](https://docs.openclaw.ai/gateway#openai-compatible-endpoints)를 참고하세요.

## 시작하기 전에

- 게이트웨이를 실행할 컴퓨터에 OpenClaw가 설치되어 있어야 합니다
- 접근 가능한 호스트와 포트에서 OpenClaw 게이트웨이가 실행 중이어야 합니다
- Chat Completions 게이트웨이 엔드포인트가 활성화되어 있어야 합니다
- `~/.openclaw/openclaw.json`의 게이트웨이 토큰이 필요합니다
- OpenClaw AI 모델 제공업체가 활성화된 Enconvo가 필요합니다

## 자동으로 설정

**설정 → AI 모델 → OpenClaw**를 여세요. 설정 카드에서 로컬 OpenClaw 게이트웨이를 시작, 중지, 구성할 수 있습니다.

OpenClaw가 Enconvo와 같은 Mac에 설치되어 있다면 **자동 설정**을 사용하세요. Enconvo는 다음을 수행합니다.

<Steps>
  <Step title="OpenClaw 찾기">
    이 Mac에 `openclaw` CLI가 있는지 확인합니다.
  </Step>
  <Step title="Chat Completions 활성화">
    `openclaw config set gateway.http.endpoints.chatCompletions.enabled true`를 실행합니다.
  </Step>
  <Step title="게이트웨이 토큰 준비">
    `~/.openclaw/openclaw.json`에서 `gateway.auth.token`을 읽고, 없으면 새로 만듭니다.
  </Step>
  <Step title="게이트웨이 시작">
    OpenClaw 게이트웨이 서비스를 시작하거나 다시 시작합니다.
  </Step>
  <Step title="API 확인">
    `/health`와 `/v1/models`로 게이트웨이를 점검합니다.
  </Step>
  <Step title="자격 증명 저장">
    기본 URL과 게이트웨이 토큰을 Enconvo의 OpenClaw 자격 증명에 저장합니다.
  </Step>
</Steps>

설정 카드에는 **실행 중** 또는 **중지됨** 같은 런타임 배지가 표시됩니다. 카드가 보이는 동안 Enconvo는 이 상태를 주기적으로 새로 고치고, 카드가 보이지 않으면 새로 고침을 멈춥니다.

## OpenClaw 게이트웨이 켜기

OpenClaw에게 게이트웨이 정보를 준비해 달라고 요청할 수 있습니다.

```text
enable openai-compatible api and give me the token and baseurl
```

돌려받은 기본 URL과 토큰을 Enconvo의 OpenClaw 자격 증명 설정에 사용하세요.

<Steps>
  <Step title="Chat Completions 활성화">
    OpenAI 호환 chat completions 엔드포인트를 한 번 활성화하세요.

    ```bash
    openclaw config set gateway.http.endpoints.chatCompletions.enabled true
    ```
  </Step>
  <Step title="바인드 모드 선택">
    로컬에서만 접근하려면 기본 루프백 바인드를 유지하세요. LAN의 다른 기기에서 게이트웨이에 접근하려면 LAN에 바인딩하세요.

    ```bash
    openclaw config set gateway.bind lan
    ```
  </Step>
  <Step title="게이트웨이 다시 시작">
    구성 변경을 적용하세요.

    ```bash
    openclaw gateway restart
    ```
  </Step>
  <Step title="게이트웨이 상태 확인">
    게이트웨이가 실행 중인지 확인하세요.

    ```bash
    openclaw gateway status
    ```
  </Step>
</Steps>

## OpenClaw를 직접 연결

**설정 → AI 모델 → OpenClaw**를 연 다음 자격 증명 제공업체를 구성하세요.

| 설정 | 값 |
|---------|-------|
| **OpenClaw Base URL** | `http://<gateway-host>:<port>/v1` |
| **Gateway Token** | `~/.openclaw/openclaw.json`의 `gateway.auth.token` |

Enconvo는 OpenClaw에 자동으로 Chat Completions API를 사용합니다.

전체 `/v1/chat/completions` 엔드포인트가 아니라 `/v1`로 끝나는 기본 URL을 사용하세요. 예를 들어 엔드포인트가 `http://192.168.1.18:18789/v1/chat/completions`라면 `http://192.168.1.18:18789/v1`을 입력하세요.

기본 OpenClaw 구성 파일에서 게이트웨이 토큰을 읽으려면 다음과 같이 하세요.

```bash
jq -r '.gateway.auth.token' ~/.openclaw/openclaw.json
```

Enconvo는 이 값을 다음과 같이 보냅니다.

```http
Authorization: Bearer <gateway-token>
```

기본 URL과 토큰을 입력한 뒤 **검증**을 클릭하세요.

## 요청과 첨부 파일의 처리 방식

Enconvo는 OpenAI 호환 Chat Completions를 통해 OpenClaw에 요청을 보냅니다.

```http
POST /v1/chat/completions
```

`openclaw:main` 또는 OpenClaw 에이전트 목록이 알려 주는 다른 모델 이름을 사용하세요.

<Warning>
  Enconvo는 이미지 첨부 파일을 OpenClaw에 보내지 않습니다. Enconvo에서는 OpenClaw 제공업체를 텍스트/채팅 제공업체로 취급하세요. 이미지 작업에는 비전을 지원하는 모델 제공업체를 사용하거나, 텍스트를 OpenClaw에 보내기 전에 OCR이나 이미지 분석을 먼저 실행하세요.
</Warning>

## OpenClaw를 AI 모델로 사용

설정이 끝나면 OpenClaw가 모델 선택기에 나타납니다. **OpenClaw**를 고르고 `openclaw:main` 같은 에이전트 기반 모델을 선택하세요.

Enconvo의 일반 인터페이스를 유지하면서 대화, 명령, 기능을 OpenClaw 에이전트로 실행하고 싶을 때 이 방식을 사용하세요.

<Steps>
  <Step title="모델 선택기 열기">
    채팅이나 모델 기반의 다른 Enconvo 기능에서 현재 모델 이름을 클릭하세요.
  </Step>
  <Step title="OpenClaw 선택">
    제공업체 목록에서 **OpenClaw**를 선택하세요.
  </Step>
  <Step title="OpenClaw 에이전트 모델 선택">
    모델 목록에서 `openclaw:main` 또는 다른 OpenClaw 에이전트를 고르세요.
  </Step>
  <Step title="기능을 평소처럼 실행">
    질문하거나 Enconvo 기능을 실행하세요. 선택한 OpenClaw 에이전트가 모델 호출을 내부에서 처리합니다.
  </Step>
</Steps>

Enconvo는 `openclaw agents list`에서 OpenClaw 모델을 불러옵니다. 로컬에서 OpenClaw CLI를 사용할 수 없으면 Enconvo는 `openclaw:main`으로 대체합니다.

## OpenClaw용 에이전트 만들기

OpenClaw 에이전트를 조율하는 Enconvo 에이전트를 만들 수도 있습니다. 특정 OpenClaw 에이전트를 중심으로 Enconvo 쪽 워크플로, 도구 세트, 프롬프트를 두고 싶을 때 유용합니다.

<Steps>
  <Step title="에이전트 만들기 열기">
    SmartBar를 열고 **에이전트 만들기**를 검색하세요.
  </Step>
  <Step title="에이전트 이름 정하기">
    `OpenClaw Main`처럼 알아보기 쉬운 제목을 지정하세요.
  </Step>
  <Step title="조율 지침 작성">
    Enconvo 에이전트가 OpenClaw와 어떻게 일해야 하는지 설명하는 지침을 작성하세요.

    ```markdown
    You coordinate the OpenClaw Main agent for the user.

    Use OpenClaw for agentic work, automation, and tasks that should run through the user's OpenClaw setup.
    Summarize what OpenClaw did, surface any blockers, and ask before destructive or irreversible actions.
    ```
  </Step>
  <Step title="OpenClaw 모델 선택">
    에이전트의 모델 설정에서 **OpenClaw**를 선택하고 `openclaw:main`을 고르세요.
  </Step>
  <Step title="저장하고 에이전트 사용">
    새 Enconvo 에이전트와 대화를 시작하세요. 구성한 Enconvo 에이전트 인터페이스와 도구를 유지하면서 선택한 OpenClaw 에이전트 모델을 사용합니다.
  </Step>
</Steps>

## 문제 해결

<AccordionGroup>
  <Accordion title="모델 선택기에 OpenClaw가 나타나지 않음">
    **설정 → AI 모델**에서 OpenClaw 제공업체가 활성화되어 있는지 확인하세요. 모델 목록이 비어 있다면 로컬에서 `openclaw agents list`가 작동하는지 확인하거나 기본값인 `openclaw:main`을 사용하세요.
  </Accordion>
  <Accordion title="검증이 unauthorized로 실패함">
    게이트웨이 토큰을 다시 확인하세요. Enconvo는 `gateway.auth.token`의 값을 기대하며 이를 Bearer 토큰으로 보냅니다.
  </Accordion>
  <Accordion title="연결에 실패함">
    `openclaw gateway status`로 게이트웨이가 실행 중인지 확인하세요. Enconvo가 다른 기기에 있다면 `gateway.bind`를 `lan`으로 설정하고 게이트웨이를 다시 시작한 다음, 기본 URL에 호스트의 LAN IP를 사용하세요.
  </Accordion>
  <Accordion title="시작은 성공했지만 Enconvo가 잠시 확인이 필요하다고 표시함">
    OpenClaw는 HTTP 게이트웨이가 준비되기 전에 LaunchAgent가 다시 시작되었다고 보고할 수 있습니다. 몇 초 기다렸다가 설정 카드의 런타임 배지를 다시 확인하세요. `openclaw gateway status`와 `curl http://127.0.0.1:18789/health`로 직접 확인할 수도 있습니다.
  </Accordion>
  <Accordion title="게이트웨이는 실행 중인데 `/v1/models`가 실패함">
    Enconvo가 `~/.openclaw/openclaw.json`의 `gateway.auth.token`과 같은 토큰을 사용하는지 확인하세요. 설정 상태는 `/health`로 실행 중인 게이트웨이를 감지할 수 있지만, 모델 검증에는 Bearer 토큰이 필요합니다.
  </Accordion>
  <Accordion title="이미지 첨부 파일이 무시됨">
    Enconvo의 OpenClaw 제공업체는 현재 텍스트 전용입니다. Enconvo는 이미지 첨부 파일을 OpenClaw에 보내지 않으므로, 이미지를 직접 입력하려면 비전을 지원하는 제공업체를 고르세요.
  </Accordion>
  <Accordion title="기본 URL이 잘못됨">
    `http://<gateway-host>:<port>/v1`을 입력하세요. Enconvo 기본 URL 필드에 `/chat/completions`를 포함하지 마세요.
  </Accordion>
</AccordionGroup>

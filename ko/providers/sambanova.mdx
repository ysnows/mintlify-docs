---
title: "SambaNova"
description: "보유한 SambaNova API 키를 사용해 Enconvo에서 SambaNova 모델과 대화합니다."
---

SambaNova는 API 키를 통해 자사 모델을 제공합니다. Enconvo에 키를 추가해 채팅, 에이전트, AI 명령에서 해당 모델들을 사용하세요. 사용량은 본인의 SambaNova 계정으로 청구됩니다. 설정에는 **Sambanova AI**로 표시됩니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    [SambaNova Cloud](https://cloud.sambanova.ai/apis)에서 키를 생성합니다.
  </Step>
  <Step title="Enconvo에 추가하기">
    **설정 → AI 모델 → Sambanova AI**를 엽니다. **인증** 아래의 **API 키**에 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보냅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

업무용 등 두 번째 SambaNova 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델 및 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**으로 목록을 다시 불러오고, **모델 관리**(톱니바퀴)로 모델을 추가하거나 복원합니다. |

한 채팅에서만 다른 모델을 쓰려면 해당 채팅의 모델 선택기에서 고르세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 SambaNova 계정에서 활성화되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭해 목록을 다시 불러오세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 이미지나 도구 사용이 실패함 | 이미지 입력이나 도구 호출을 지원하는 모델을 선택하세요. |
| 속도 또는 사용량 제한 오류 | SambaNova 계정에서 사용량과 한도를 확인하거나 당분간 다른 제공업체로 전환하세요. |
| 응답이 느림 | 더 작은 모델, 더 짧은 입력, 또는 더 낮은 추론 강도를 사용해 보세요. |

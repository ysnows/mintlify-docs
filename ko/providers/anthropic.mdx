채팅, 에이전트, AI 명령에서 Anthropic의 Claude 모델을 사용하세요. 요청마다 Anthropic이 요금을 청구하는 Anthropic API 키로 연결하거나, Claude 플랜으로 로그인할 수 있습니다.

## 연결

<Steps>
  <Step title="API 키 받기">
    [Anthropic Console](https://console.anthropic.com/)에서 키를 만드세요.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → Anthropic**을 여세요. **인증**에서 **API 키**를 선택하고 키를 붙여넣은 다음 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답장이 오면 연결이 정상입니다.
  </Step>
</Steps>

<Tip>
Claude 플랜이 있나요? **인증**에서 **Claude Subscription**을 선택하고 **연결**을 클릭하세요. [Claude Subscription](/ko/providers/anthropic_subscription)을 참고하세요.
</Tip>

두 번째 Anthropic 키를 두려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **API 기본 URL** | 자격 증명에 있습니다. 기본값은 `https://api.anthropic.com`입니다. Anthropic 호환 서비스를 사용할 때만 변경하세요. |

채팅의 추론 설정은 선택한 모델에 따라 달라집니다. Anthropic의 가장 강력한 모델인 Claude Fable 5.2는 추론 강도를 **낮음**부터 **최대**까지 지정할 수 있고, API 키를 쓰면 빠른 모드도 제공합니다. 최대 1M 토큰을 처리할 수 있는 Claude 모델은 컨텍스트 500K로 시작하며, **모델 관리**에서 늘릴 수 있습니다. 한 채팅에서만 다른 모델을 쓰려면 그 채팅의 모델 선택기에서 고르세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여넣고, Anthropic Console에서 키가 활성 상태인지 확인하세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 속도 또는 사용량 한도 오류 | Anthropic Console에서 사용량과 한도를 확인하거나, 당분간 다른 제공업체로 전환하세요. |
| 응답이 느림 | 더 작은 모델, 더 짧은 입력, 더 낮은 추론 강도를 시도해 보세요. |

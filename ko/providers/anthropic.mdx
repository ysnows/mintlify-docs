채팅, 에이전트, AI 명령에서 Anthropic의 Claude 모델을 사용하세요. 요청당 요금이 청구되는 Anthropic API 키로 연결하거나, 보유한 Claude 요금제로 로그인할 수 있습니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    [Anthropic Console](https://console.anthropic.com/)에서 키를 생성합니다.
  </Step>
  <Step title="Enconvo에 추가하기">
    **설정 → AI 모델 → Anthropic**을 엽니다. **인증** 아래에서 **API 키**를 선택하고 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보냅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

<Tip>
Claude 요금제를 이용 중이신가요? **인증** 아래에서 **Claude Subscription**을 선택하고 **연결**을 클릭하세요. 자세한 내용은 [Claude Subscription](/ko/providers/anthropic_subscription)을 참고하세요.
</Tip>

두 번째 Anthropic 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델 및 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**으로 목록을 다시 불러오고, **모델 관리**(톱니바퀴)로 모델을 추가하거나 복원합니다. |
| **API 기본 URL** | 자격 증명에 포함됩니다. 기본값은 `https://api.anthropic.com`입니다. Anthropic 호환 서비스를 사용할 때만 변경하세요. |

채팅의 추론 제어 옵션은 선택한 모델에 따라 달라집니다. Anthropic의 최고 성능 모델인 Claude Fable 5.2는 **낮음(Low)**부터 **최대(Max)**까지의 추론 강도를 지원하며, API 키 사용 시 Fast 모드를 제공합니다. 최대 1M 토큰을 지원하는 Claude 모델은 500K 컨텍스트로 시작하며, **모델 관리**에서 이를 늘릴 수 있습니다. 한 채팅에서만 다른 모델을 쓰려면 해당 채팅의 모델 선택기에서 고르세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 Anthropic Console에서 활성화되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 속도 또는 사용량 제한 오류 | Anthropic Console에서 사용량과 한도를 확인하거나 당분간 다른 제공업체로 전환하세요. |
| 응답이 느림 | 더 작은 모델, 더 짧은 입력, 또는 더 낮은 추론 강도를 사용해 보세요. |

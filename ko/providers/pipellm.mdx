PipeLLM은 게이트웨이 서비스입니다. PipeLLM API 키 하나로 Claude, GPT, Gemini, Grok, Qwen, Kimi, GLM 등 여러 회사의 모델에 연결할 수 있습니다. 여러 공급업체의 사용량을 하나의 청구서로 관리하고 싶을 때 사용하세요. 사용 요금은 PipeLLM이 본인 계정에 청구합니다.

같은 키로 이미지 생성, 동영상 생성, 웹 검색도 이용할 수 있습니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    [PipeLLM](https://pipellm.ai) 계정에서 키를 생성합니다.
  </Step>
  <Step title="Enconvo에 추가하기">
    **설정 → AI 모델 → PipeLLM**을 엽니다. **인증** 아래에서 **API 키**에 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보냅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

두 번째 PipeLLM 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델 및 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**으로 목록을 다시 불러오고, **모델 관리**(톱니바퀴)로 모델을 추가하거나 복원합니다. |

PipeLLM 키는 아래 기능에서도 작동합니다. 각 페이지에서 제공업체로 **PipeLLM**을 선택하세요.

| 기능 | 위치 | 제공 내용 |
| --- | --- | --- |
| 이미지 생성 | **설정 → 이미지 생성** | GPT Image, Nano Banana, Seedream 등의 모델로 이미지를 생성하고 편집합니다. |
| 동영상 생성 | **설정 → 동영상 생성** | Seedance, Veo, Kling, Sora 등의 동영상 모델입니다. |
| 웹 검색 | **설정 → 웹 검색** | 스니펫이 포함된 Google 검색 결과입니다. PipeLLM은 결과를 반환하는 각 검색마다 요금을 청구합니다. |

모든 기능이 하나의 인증 정보를 공유하므로 한 곳에서 키를 변경하면 다른 곳에도 모두 적용됩니다. iPhone 및 Android 앱의 AI 모델 설정에서도 PipeLLM을 사용할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 PipeLLM 계정에서 활성화되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 이미지나 도구가 작동하지 않음 | 이미지 입력이나 도구 호출을 지원하는 모델을 선택하세요. |
| 속도, 잔액 또는 사용량 오류 | PipeLLM 계정에서 잔액과 한도를 확인하거나 당분간 다른 제공업체로 전환하세요. |

PipeLLM은 게이트웨이입니다. PipeLLM API 키 하나로 Claude, GPT, Gemini, Grok, Qwen, Kimi, GLM을 비롯한 여러 회사의 모델을 사용할 수 있습니다. 여러 벤더를 한 청구서로 쓰고 싶을 때 사용하세요. 사용 요금은 PipeLLM이 본인 계정에 청구합니다.

같은 키로 이미지 생성, 동영상 생성, 웹 검색도 이용할 수 있습니다.

## 연결

<Steps>
  <Step title="API 키 받기">
    [PipeLLM](https://pipellm.ai) 계정에서 키를 만드세요.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → PipeLLM**을 여세요. **인증**에서 키를 **API 키**에 붙여넣고 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답장이 오면 연결이 정상입니다.
  </Step>
</Steps>

두 번째 PipeLLM 키를 두려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |

PipeLLM 키는 다음 기능에서도 사용할 수 있습니다. 각 페이지에서 제공업체로 **PipeLLM**을 고르세요.

| 기능 | 위치 | 제공 내용 |
| --- | --- | --- |
| 이미지 생성 | **설정 → 이미지 생성** | GPT Image, Nano Banana, Seedream 같은 모델로 이미지를 생성하고 편집합니다. |
| 동영상 생성 | **설정 → 동영상 생성** | Seedance, Veo, Kling, Sora 같은 동영상 모델입니다. |
| 웹 검색 | **설정 → 웹 검색** | 스니펫이 포함된 Google 검색 결과입니다. PipeLLM은 결과가 반환된 검색마다 요금을 청구합니다. |

이 기능들은 하나의 자격 증명을 공유하므로 한 곳에서 키를 바꾸면 모두에 적용됩니다. iPhone과 Android 앱에서도 AI 모델 설정에서 PipeLLM을 사용할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여넣고, PipeLLM 계정에서 키가 활성 상태인지 확인하세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 이미지나 도구가 실패함 | 이미지 입력 또는 도구 호출을 지원하는 모델을 고르세요. |
| 속도, 잔액 또는 사용량 오류 | PipeLLM 계정에서 잔액과 한도를 확인하거나, 당분간 다른 제공업체로 전환하세요. |

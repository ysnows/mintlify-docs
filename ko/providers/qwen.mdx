채팅, 에이전트, AI 명령에서 Alibaba의 Qwen 모델을 사용하세요. Alibaba Cloud Model Studio의 API 키로 연결하며, 사용 요금은 Alibaba Cloud가 본인 계정에 청구합니다. 중국 본토 서비스(Bailian)는 [DashScope](/ko/providers/dashscope)를 사용하세요.

## 연결

<Steps>
  <Step title="API 키 받기">
    [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/)에서 키를 만드세요.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → Qwen**을 여세요. **인증**에서 키를 **API 키**에 붙여넣고 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답장이 오면 연결이 정상입니다.
  </Step>
</Steps>

Qwen은 API 키로만 연결됩니다.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **Base Url** | 자격 증명에 있습니다. 기본값은 국제 엔드포인트인 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`입니다. 키가 다른 리전에 속한다면 변경하세요. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키와 **Base Url**이 같은 리전에 속하는지 확인한 다음, 키 전체를 다시 붙여넣으세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 속도 또는 사용량 한도 오류 | Model Studio에서 사용량과 할당량을 확인하거나, 당분간 다른 제공업체로 전환하세요. |

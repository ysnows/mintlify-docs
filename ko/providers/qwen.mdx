---
title: "Qwen"
description: "Alibaba Cloud Model Studio API 키로 Enconvo에서 Qwen 모델과 대화합니다."
---

채팅, 에이전트, AI 명령에서 Alibaba의 Qwen 모델을 씁니다. Alibaba Cloud Model Studio의 API 키로 연결하며, Alibaba Cloud가 사용량을 계정에 청구합니다. 중국 본토 서비스(Bailian)는 [DashScope](/ko/providers/dashscope)를 쓰세요.

## 연결

<Steps>
  <Step title="API 키 받기">
    [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/)에서 키를 만듭니다.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → Qwen**을 엽니다. **인증** 아래에서 키를 **API Key**에 붙여 넣은 다음 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 고르기">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보냅니다. 답장이 오면 연결이 동작합니다.
  </Step>
</Steps>

Qwen은 API 키로만 연결됩니다.

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델 이름** | 이 제공업체가 쓰는 모델. 옆 **새로 고침**이 목록을 다시 불러오고, **모델 관리**(톱니)가 모델을 추가하거나 복원합니다. |
| **Base Url** | 자격 증명에 있습니다. 기본은 국제 엔드포인트 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`입니다. 키가 다른 지역에 속하면 바꿉니다. |

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **검증** 실패 | 키와 **Base Url**이 같은 지역에 속하는지 확인한 다음 키 전체를 다시 붙여 넣습니다. |
| 모델이 없음 | **모델 이름** 옆 **새로 고침**을 클릭합니다. 직접 추가하려면 **모델 관리**를 씁니다. |
| 속도 또는 사용 제한 오류 | Model Studio에서 사용량과 할당량을 확인하거나, 당분간 다른 제공업체로 전환합니다. |

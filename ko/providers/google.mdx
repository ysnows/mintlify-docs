채팅, 에이전트, AI 명령에서 Google의 Gemini 모델을 사용하세요. Google AI Studio에서 받은 Gemini API 키로 연결하며, 사용 요금은 Google이 본인 계정에 청구합니다. 설정에는 **Google Gemini AI**로 표시됩니다.

<Note>
Google Gemini는 API 키로만 연결됩니다. Google이 개인 Google 계정의 Gemini 로그인 지원을 중단해, Enconvo는 2.5.8에서 Google 계정 옵션을 없앴습니다. Google 로그인으로 모델을 사용하려면 [Antigravity](/ko/providers/antigravity)를 참고하세요.
</Note>

## 연결

<Steps>
  <Step title="API 키 받기">
    [Google AI Studio](https://aistudio.google.com/apikey)에서 키를 만드세요.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → Google Gemini AI**를 여세요. **인증**에서 키를 **API 키**에 붙여넣고 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답장이 오면 연결이 정상입니다.
  </Step>
</Steps>

두 번째 Gemini 키를 두려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **Google Search Tool** | Google 검색 결과를 근거로 답하고, 확인할 수 있는 출처를 함께 보여 줍니다. 기본값은 꺼짐입니다. |
| **URL Context Tool** | 메시지에 포함된 링크의 페이지를 모델이 읽을 수 있게 합니다. 기본값은 꺼짐입니다. |
| **Show thoughts** | 답변과 함께 모델의 생각 요약을 보여 줍니다. 기본값은 꺼짐입니다. |

생각 기능이 있는 Gemini 모델에서는 추론 강도로 생각하는 시간을 정할 수 있습니다. Gemini 4 Carbon은 **낮음**, **보통**(기본값), **높음**을 제공하며 유료 API 등급이 필요합니다. 일상적인 코딩과 에이전트 작업에 적합한 빠른 모델인 Gemini 4 Hydrogen은 **낮음**, **보통**, **높음**(기본값), **매우 높음**을 제공하며, **매우 높음**은 어려운 다단계 작업에서 가장 오래 생각합니다. 무료 등급에서도 사용할 수 있습니다.

같은 Google Gemini 프로필이 Gemini 텍스트 음성 변환, 이미지 생성, 음성 텍스트 변환, 동영상 생성, 웹 검색에도 사용되므로 키를 바꾸면 해당 기능에도 영향이 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여넣고, Google AI Studio에서 키가 활성 상태인지 확인하세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 최근 소식에 대한 답변이 오래됨 | **Google Search Tool**을 켜세요. |
| 속도 또는 사용량 한도 오류 | Google AI Studio에서 할당량을 확인하거나, 당분간 다른 제공업체로 전환하세요. |

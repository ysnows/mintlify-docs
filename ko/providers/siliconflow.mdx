---
title: "SiliconFlow"
description: "자신의 SiliconFlow API 키로 Enconvo에서 SiliconFlow 모델과 대화합니다."
---

SiliconFlow는 하나의 API 키 뒤에 많은 오픈 모델을 호스트합니다. 키를 Enconvo에 추가하면 채팅, 에이전트, AI 명령에서 그 모델을 씁니다. SiliconFlow는 사용량을 자신의 계정에 청구합니다.

## 연결

<Steps>
  <Step title="API 키 받기">
    [SiliconFlow 계정](https://cloud.siliconflow.cn/account/ak)에서 키를 만듭니다.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → SiliconFlow**을 엽니다. **인증** 아래에서 키를 **API Key**에 붙여 넣은 다음 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 고르기">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보냅니다. 답장이 오면 연결이 동작합니다.
  </Step>
</Steps>

두 번째 SiliconFlow 키, 예를 들어 업무용을 보관하려면 **새 제공업체 추가**를 클릭하고 다른 프로필을 만듭니다.

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델 이름** | 이 제공업체가 쓰는 모델. 옆 **새로 고침**이 목록을 다시 불러오고, **모델 관리**(톱니)가 모델을 추가하거나 복원합니다. |

한 채팅에서 다른 모델을 쓰려면 그 채팅의 모델 선택기에서 고릅니다.

SiliconFlow는 지식 베이스용 임베딩과 재순위 모델도 제공합니다. 지식 베이스 설정에서 고르며, 같은 SiliconFlow 키를 씁니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **검증** 실패 | 키 전체를 다시 붙여 넣고 SiliconFlow 계정에서 활성인지 확인합니다. |
| 모델이 없음 | **모델 이름** 옆 **새로 고침**을 클릭해 목록을 다시 불러옵니다. 직접 추가하려면 **모델 관리**를 씁니다. |
| 이미지나 도구 실패 | 이미지 입력이나 도구 호출을 지원하는 모델을 고릅니다. |
| 속도 또는 사용 제한 오류 | SiliconFlow 계정에서 사용량과 제한을 확인하거나, 당분간 다른 제공업체로 전환합니다. |
| 답장이 느림 | 더 작은 모델, 더 짧은 입력, 더 낮은 추론 노력을 시도합니다. |

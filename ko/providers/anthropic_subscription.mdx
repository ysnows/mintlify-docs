---
title: "Claude 구독"
description: "Claude 요금제로 로그인해 API 키 없이 Enconvo에서 Claude 모델을 사용합니다."
---

Claude를 결제 중이라면 API 키를 만드는 대신 그 요금제로 로그인하세요. 요청은 요금제의 사용 한도를 사용하며, Enconvo가 남은 양을 보여 줍니다.

## 연결

<Steps>
  <Step title="구독 선택">
    **설정 → AI 모델 → Anthropic**을 엽니다. **인증**에서 **Claude 구독**을 선택합니다.
  </Step>
  <Step title="로그인">
    **연결**을 클릭하고 브라우저에서 Claude 계정에 로그인한 다음 접근을 허용합니다. 브라우저에서 완료되었다고 표시되면 Enconvo로 돌아옵니다.
  </Step>
  <Step title="모델 선택">
    계정 카드에 올바른 계정이 표시되는지 확인하고, **모델 이름**에서 모델을 고른 다음 짧은 메시지를 보내 보세요.
  </Step>
</Steps>

## 사용량 확인

계정 카드에는 5시간 및 주간 사용 한도에서 남은 양(**% 남음**)이 표시됩니다. Anthropic이 알려 주면 모델별로 표시되며 각각의 초기화 시점도 나옵니다. 주간 Claude Fable 한도처럼 자체 한도가 있는 모델은 다른 항목 옆에 함께 표시됩니다. 같은 카드가 채팅의 모델 선택기에도 나타납니다. 카드 메뉴를 열면 다음을 사용할 수 있습니다.

- **사용량 새로고침**: 최신 수치를 가져옵니다.
- **다시 연결**: 계정을 바꾸는 등의 이유로 다시 로그인합니다.

Anthropic이 사용량을 알려 주지 않으면 카드에 **사용량을 확인할 수 없음**이 이유와 함께 표시됩니다. 요금제에 한도가 없다는 뜻은 아닙니다.

### 무료 초기화 사용

Claude에서 무료 한도 초기화를 받으면 카드에 **무료 초기화**가 표시됩니다. 남은 개수와 만료 시점을 볼 수 있습니다. **초기화 사용**을 클릭하고 확인하면 한도가 바로 다시 채워집니다. 초기화는 되돌릴 수 없습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 로그인에 실패합니다 | Anthropic이 알려 준 오류를 읽고 **연결**을 다시 클릭하세요. 요금제가 있는 계정으로 로그인하는지 확인하세요. |
| 채팅에 사용 한도에 도달했다고 표시됩니다 | 메시지에 한도와 초기화 시점이 나옵니다. 카드에 무료 초기화가 있으면 사용하거나, 기다리거나, 당분간 **인증**을 **API 키**로 바꾸세요. |
| Enconvo가 잠시 후 다시 시도하라고 합니다 | Anthropic이 로그인을 갱신하느라 바빴던 것입니다. 잠시 기다렸다가 다시 보내세요. 다시 연결할 필요는 없습니다. |
| 모델이 없습니다 | 요금제에 따라 모델이 정해집니다. **모델 이름** 옆의 **새로고침**을 클릭하세요. |

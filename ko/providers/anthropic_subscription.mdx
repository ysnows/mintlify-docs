---
title: "Claude 구독"
description: "API 키 없이 Claude 요금제로 로그인해 Enconvo에서 Claude 모델을 사용하세요."
---

Claude 유료 요금제를 이용하고 있다면 API 키를 발급받는 대신 해당 요금제로 로그인할 수 있습니다. 요청 시 요금제의 사용량이 차감되며, Enconvo에서 남은 사용량을 바로 확인할 수 있습니다.

## 연결하기

<Steps>
  <Step title="구독 방식 선택하기">
    **설정 → AI 모델 → Anthropic**을 엽니다. **인증** 아래에서 **Claude 구독**을 선택합니다.
  </Step>
  <Step title="로그인하기">
    **연결**을 클릭하고 브라우저에서 Claude 계정에 로그인한 뒤 접근 권한을 허용합니다. 브라우저에 완료 메시지가 표시되면 Enconvo로 돌아옵니다.
  </Step>
  <Step title="모델 선택하기">
    계정 카드에 올바른 계정이 표시되는지 확인한 뒤 **모델 이름**에서 모델을 선택하고 짧은 메시지를 보내 봅니다.
  </Step>
</Steps>

## 사용량 확인하기

계정 카드에는 5시간 및 주간 사용량의 잔여 비율(**남은 비율(%)**)이 표시되며, Anthropic이 모델별 사용량을 제공하는 경우 모델별 잔여량과 초기화 시점도 함께 표시됩니다. 주간 Claude Fable 한도처럼 별도 한도가 있는 모델은 다른 항목 옆에 함께 나타납니다. 채팅의 모델 선택기에서도 같은 카드를 볼 수 있습니다. 카드 메뉴를 열면 다음 작업을 할 수 있습니다.

- **사용량 새로고침**: 최신 사용량을 불러옵니다.
- **다시 연결**: 계정을 전환하는 등 다시 로그인해야 할 때 사용합니다.

Anthropic이 사용량 정보를 제공하지 않으면 카드에 **사용량을 확인할 수 없음**과 함께 사유가 표시됩니다. 이는 요금제에 한도가 없다는 뜻이 아닙니다.

### 무료 초기화 사용하기

Claude에서 무료 한도 초기화를 제공한 경우 카드에 남은 횟수와 만료일이 포함된 **무료 초기화** 항목이 표시됩니다. **초기화 사용**을 클릭하고 확인하면 한도를 즉시 채울 수 있습니다. 한 번 사용한 초기화는 되돌릴 수 없습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 로그인에 실패함 | Anthropic이 반환한 오류 메시지를 확인한 뒤 **연결**을 다시 클릭합니다. 유료 요금제가 있는 계정으로 로그인했는지 확인하세요. |
| 채팅에 사용 한도 도달 메시지가 표시됨 | 메시지에 한도 종류와 초기화 시간이 표시됩니다. 카드에 무료 초기화가 있다면 사용하거나, 초기화될 때까지 기다리거나, 당분간 **인증**을 **API 키**로 전환하세요. |
| 잠시 후 다시 시도하라는 안내가 나옴 | Anthropic이 로그인 세션을 갱신하는 중입니다. 잠시 기다렸다가 다시 전송하세요. 다시 연결할 필요는 없습니다. |
| 모델이 목록에 보이지 않음 | 사용 중인 요금제에 따라 제공되는 모델이 다릅니다. **모델 이름** 옆의 **새로고침**을 클릭하세요. |

---

LM Studio를 사용하면 이 Mac이나 네트워크상의 다른 컴퓨터 등 내 하드웨어에서 직접 모델을 실행할 수 있습니다. Enconvo가 채팅 요청을 LM Studio 서버로 보내므로 별도의 제공업체 계정이 필요하지 않습니다.

## 이 Mac에서 연결하기

<Steps>
  <Step title="LM Studio 시작하기">
    [LM Studio](https://lmstudio.ai/)에서 모델을 불러온 뒤 로컬 API 서버를 시작합니다.
  </Step>
  <Step title="Enconvo 연결 설정하기">
    **설정 → AI 모델 → LM Studio**를 엽니다. **인증** 아래에서 LM Studio의 포트를 변경하지 않았다면 **BaseUrl**을 `http://127.0.0.1:1234/v1`로 유지합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보내 봅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

## 다른 컴퓨터에 연결하기

1. 다른 컴퓨터의 LM Studio에서 자기 자신뿐 아니라 네트워크에서 오는 연결을 허용하도록 설정합니다.
2. Enconvo에서 포트와 경로는 유지한 채 **BaseUrl**을 해당 컴퓨터의 네트워크 주소로 변경합니다. `127.0.0.1`과 `localhost`는 항상 Enconvo가 실행 중인 Mac을 가리킵니다.
3. macOS가 연결을 차단하는 경우 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 켭니다.

서버는 신뢰할 수 있는 네트워크에만 여세요.

## 모델 및 옵션

| 설정 | 설명 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용할 모델입니다. 옆의 **새로고침**을 클릭하면 서버에서 목록을 다시 불러옵니다. |
| **응답 시간 제한** | 서버가 응답을 시작하거나 이어갈 때까지 기다리는 시간입니다. 기본값은 **제한 없음**이며, 내 하드웨어에서는 긴 프롬프트의 첫 단어가 나오기까지 몇 분이 걸릴 수도 있습니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결이 거부됨 | LM Studio가 실행 중인지, **BaseUrl**의 주소와 포트가 맞는지 확인하세요. 다른 컴퓨터라면 네트워크 연결을 허용하도록 설정되어 있는지 확인하세요. |
| 네트워크에 연결할 수 없음 | 네트워크 상태와 시스템 설정의 **로컬 네트워크** 권한을 확인하세요. |
| 모델 목록이 비어 있음 | LM Studio에서 모델을 다운로드하거나 불러온 뒤 **새로고침**을 클릭하세요. |
| 응답이 중간에 끊김 | **응답 시간 제한**을 더 길게 설정하거나 **제한 없음**으로 설정하세요. |
| 도구 호출이나 이미지 입력이 실패함 | 도구 호출 또는 이미지 입력을 지원하는 모델을 선택하세요. |
| 메모리 부족 | 더 작은 모델을 선택하거나 입력 길이를 줄이세요. |

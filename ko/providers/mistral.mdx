---
title: "Mistral AI"
description: "Mistral API 키 또는 Mistral 계정으로 Enconvo에서 Mistral 모델과 대화합니다."
---

채팅, 에이전트, AI 명령에서 Mistral 모델을 씁니다. Mistral API 키를 붙여 넣거나, Mistral 계정으로 로그인해 Enconvo가 키를 만들게 합니다. 어느 쪽이든 Mistral이 사용량을 계정에 청구합니다.

## 연결

<Tabs>
  <Tab title="Mistral로 로그인">
    <Steps>
      <Step title="제공업체 열기">
        **설정 → AI 모델 → Mistral AI**를 엽니다.
      </Step>
      <Step title="로그인">
        **인증** 아래에서 Mistral 계정 로그인을 고르고 **연결**을 클릭합니다. Mistral 계정으로 로그인하고 워크스페이스를 고릅니다. 로그인은 Mistral Vibe가 로그인하는 방식과 같습니다. 그 워크스페이스의 API 키를 만들므로 복사할 것이 없습니다.
      </Step>
      <Step title="모델 고르기">
        **모델 이름**에서 모델을 고르고 짧은 메시지를 보냅니다.
      </Step>
    </Steps>
  </Tab>
  <Tab title="API 키 사용">
    <Steps>
      <Step title="API 키 받기">
        [Mistral 콘솔](https://console.mistral.ai/api-keys/)에서 키를 만듭니다.
      </Step>
      <Step title="Enconvo에 추가">
        **설정 → AI 모델 → Mistral AI**를 엽니다. **인증** 아래에서 키를 **API Key**에 붙여 넣은 다음 **검증**을 클릭합니다.
      </Step>
      <Step title="모델 고르기">
        **모델 이름**에서 모델을 고르고 짧은 메시지를 보냅니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

로그인하면 계정 카드에 플랜, 키, 분당 제한의 남은 양이 나옵니다.

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델 이름** | 이 제공업체가 쓰는 모델. 옆 **새로 고침**이 목록을 다시 불러오고, **모델 관리**(톱니)가 모델을 추가하거나 복원합니다. |
| **추론 노력** (채팅에서) | Mistral Large 4, Medium 3.5, Small 4: **없음**은 생각하지 않고 답하고, **높음**은 먼저 생각합니다. Large 4는 기본적으로 생각합니다. |

Voxtral 음성 텍스트 변환과 Mistral OCR은 같은 로그인이나 키를 쓸 수 있습니다.

## iPhone에서

iPhone 앱도 전화 채팅에서 Le Chat 플랜을 쓸 수 있습니다. iPhone에서 **설정 → AI 모델 → Mistral**을 열고 **인증** 아래 Le Chat 카드를 고른 다음 **Mistral로 로그인**을 탭합니다. [전화 채팅](/ko/integrations/iphone-phone-chats)을 보세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **검증** 실패 | 키 전체를 다시 붙여 넣고 Mistral 콘솔에서 활성인지 확인합니다. |
| 로그인이 동작하지 않음 | 계정 카드 메뉴를 열고 **다시 연결**을 클릭합니다. |
| 모델이 없음 | **모델 이름** 옆 **새로 고침**을 클릭합니다. 직접 추가하려면 **모델 관리**를 씁니다. |
| 속도 제한 오류 | 워크스페이스의 분당 제한이 소진됐습니다. 1분 기다리거나 Mistral 콘솔에서 제한을 확인합니다. |

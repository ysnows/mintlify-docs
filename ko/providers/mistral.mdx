---
title: "Mistral AI"
description: "Mistral API 키 또는 Mistral 계정으로 Enconvo에서 Mistral 모델과 대화하세요."
---

채팅, 에이전트, AI 명령에서 Mistral의 모델을 사용하세요. Mistral API 키를 붙여넣거나, Mistral 계정으로 로그인해 Enconvo가 키를 대신 만들게 할 수 있습니다. 어느 쪽이든 사용 요금은 Mistral이 본인 계정에 청구합니다.

## 연결

<Tabs>
  <Tab title="Mistral로 로그인">
    <Steps>
      <Step title="제공업체 열기">
        **설정 → AI 모델 → Mistral AI**를 여세요.
      </Step>
      <Step title="로그인">
        **인증**에서 Mistral 계정 로그인을 선택하고 **연결**을 클릭하세요. Mistral 계정으로 로그인한 다음 워크스페이스를 고르세요. 이 로그인은 Mistral Vibe의 로그인 방식과 같아서 해당 워크스페이스의 API 키를 대신 만들어 주므로 복사할 것이 없습니다.
      </Step>
      <Step title="모델 선택">
        **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요.
      </Step>
    </Steps>
  </Tab>
  <Tab title="API 키 사용">
    <Steps>
      <Step title="API 키 받기">
        [Mistral 콘솔](https://console.mistral.ai/api-keys/)에서 키를 만드세요.
      </Step>
      <Step title="Enconvo에 추가">
        **설정 → AI 모델 → Mistral AI**를 여세요. **인증**에서 키를 **API 키**에 붙여넣고 **검증**을 클릭하세요.
      </Step>
      <Step title="모델 선택">
        **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요.
      </Step>
    </Steps>
  </Tab>
</Tabs>

로그인하면 계정 카드에 플랜, 키, 분당 한도의 남은 양이 표시됩니다.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **추론 강도**(채팅에서) | Mistral Large 4, Medium 3.5, Small 4에서 **없음**은 생각 없이 답하고, **높음**은 먼저 생각합니다. Large 4는 기본적으로 생각합니다. |

Voxtral 음성 텍스트 변환과 Mistral OCR도 같은 로그인이나 키를 사용할 수 있습니다.

## iPhone에서

iPhone 앱의 iPhone 채팅에서도 Le Chat 플랜을 사용할 수 있습니다. iPhone에서 **설정 → AI 모델 → Mistral**을 열고 **인증**의 Le Chat 카드를 선택한 다음 **Mistral로 로그인**을 탭하세요. [iPhone 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여넣고, Mistral 콘솔에서 키가 활성 상태인지 확인하세요. |
| 로그인이 작동하지 않음 | 계정 카드의 메뉴를 열고 **다시 연결**을 클릭하세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 속도 제한 오류 | 워크스페이스의 분당 한도를 다 썼습니다. 1분 기다리거나 Mistral 콘솔에서 한도를 확인하세요. |

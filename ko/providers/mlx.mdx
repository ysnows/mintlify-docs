---
title: "로컬 LLM(MLX)"
description: "Enconvo에 내장된 MLX 엔진으로 Mac에서 언어 모델을 실행합니다."
---

로컬 LLM은 계정이나 API 키 없이 Mac의 Apple Silicon에서 언어 모델을 실행합니다. 모델을 받은 뒤 그와의 채팅은 Mac에 남습니다. macOS 15 이상이 필요합니다.

## 설정

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델 → Local LLM (MLX)**를 엽니다.
  </Step>
  <Step title="모델 고르기">
    **모델** 목록을 엽니다. Enconvo가 Mac에 맞는 모델을 제안하고, Hugging Face에서 다른 모델을 검색할 수 있습니다. 목록은 가장 큰 모델을 먼저 보여 줍니다.
  </Step>
  <Step title="다운로드">
    다운로드를 시작하고 끝날 때까지 기다립니다. Enconvo는 먼저 디스크 여유 공간을 확인하고, 재시작이나 네트워크 끊김 뒤에 다운로드가 이어집니다.
  </Step>
  <Step title="시험">
    짧은 메시지를 보냅니다. 모델이 메모리에 올라가는 동안 첫 답변은 더 걸립니다.
  </Step>
</Steps>

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델** | 이 제공업체가 실행하는 로컬 모델입니다. |
| **사고** | 사고 모드가 있는 모델용입니다. **끔**(기본)은 바로 답하고, **켬**은 먼저 추론합니다. **낮음**, **중간**, **높음**은 gpt-oss 모델이 얼마나 오래 추론하는지 정합니다. 다른 모델은 이를 **켬**으로 봅니다. |

로컬 모델이 쓰는 메모리와 디스크를 보거나 하나를 삭제하려면 **설정 → 로컬 모델**을 엽니다. 기능이 필요할 때 모델이 다시 로드됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 다운로드가 시작되지 않음 | 디스크 공간을 확보합니다. Enconvo는 받기 전에 확인합니다. |
| 모델이 **미완료**로 표시됨 | 다운로드가 중간에 끊겨 일부 파일이 없습니다. 다시 받아 끝내거나 삭제합니다. |
| 모델이 로드되지 않거나 Mac이 느려짐 | 더 작은 모델을 고르거나 무거운 앱을 닫습니다. **설정 → 로컬 모델**이 메모리 사용을 보여 줍니다. |
| 답변이 느림 | 더 작은 모델을 고르거나 **사고**를 끕니다. |
| 도구나 이미지가 실패함 | 도구 호출이나 이미지 입력을 지원하는 모델을 고릅니다. |

---
title: "Local LLM (MLX)"
description: "Enconvo의 내장 MLX 엔진으로 Mac에서 언어 모델을 실행하세요."
---

Local LLM은 계정이나 API 키 없이 Mac의 Apple Silicon에서 언어 모델을 실행합니다. 모델을 다운로드하고 나면 해당 모델과의 채팅은 Mac 안에 머뭅니다. macOS 15 이상이 필요합니다.

## 설정

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델 → Local LLM (MLX)**를 여세요.
  </Step>
  <Step title="모델 선택">
    **모델** 목록을 여세요. Enconvo가 내 Mac에 맞는 모델을 추천하며, Hugging Face에서 다른 모델을 검색할 수도 있습니다. 목록에는 큰 모델이 먼저 표시됩니다.
  </Step>
  <Step title="다운로드">
    다운로드를 시작하고 끝날 때까지 기다리세요. Enconvo는 먼저 남은 디스크 공간을 확인하며, 다시 시작하거나 네트워크가 끊겨도 다운로드가 이어집니다.
  </Step>
  <Step title="테스트">
    짧은 메시지를 보내세요. 모델이 메모리에 로드되는 동안 첫 답장은 더 오래 걸립니다.
  </Step>
</Steps>

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델** | 이 제공업체가 실행하는 로컬 모델입니다. |
| **사고** | 사고 모드가 있는 모델용입니다. **끔**(기본값)은 바로 답하고, **켬**은 먼저 추론합니다. **낮음**, **보통**, **높음**은 gpt-oss 모델이 추론하는 시간을 정하며, 다른 모델은 이를 **켬**으로 취급합니다. |

로컬 모델이 사용하는 메모리와 디스크 용량을 확인하거나 모델을 삭제하려면 **설정 → 로컬 모델**을 여세요. 기능이 필요로 할 때 모델은 다시 로드됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 다운로드가 시작되지 않음 | 디스크 공간을 확보하세요. Enconvo는 다운로드 전에 이를 확인합니다. |
| 모델에 **불완전**이라고 표시됨 | 다운로드가 중간에 끊겨 일부 파일이 없습니다. 다시 다운로드해 완료하거나 삭제하세요. |
| 모델이 로드되지 않거나 Mac이 느려짐 | 더 작은 모델을 고르거나 다른 무거운 앱을 닫으세요. **설정 → 로컬 모델**에서 메모리 사용량을 볼 수 있습니다. |
| 응답이 느림 | 더 작은 모델을 고르거나 **사고**를 끄세요. |
| 도구나 이미지가 실패함 | 도구 호출이나 이미지 입력을 지원하는 모델을 고르세요. |

title: "xAI (Grok)"
description: "xAI API 키 또는 Grok 요금제로 Enconvo에서 Grok 모델과 대화하세요."
---

채팅, 에이전트, AI 명령에서 xAI의 Grok 모델을 사용할 수 있습니다. 요청당 과금되는 xAI API 키로 연결하거나 Grok 요금제로 로그인해 사용하세요. 설정에서는 **X.AI-GROK**으로 표시됩니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    xAI 콘솔에서 키를 생성합니다. 방법은 [xAI 빠른 시작 가이드](https://docs.x.ai/docs/quickstart#creating-an-api-key)를 참고하세요.
  </Step>
  <Step title="Enconvo에 키 추가하기">
    **설정 → AI 모델 → X.AI-GROK**을 엽니다. **인증** 아래에서 **API 키**를 선택하고 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보내 봅니다. 응답이 오면 정상적으로 연결된 것입니다.
  </Step>
</Steps>

<Tip>
Grok 요금제를 이용 중이라면 **인증**에서 **Grok 구독**을 선택하고 **연결**을 클릭하세요.
</Tip>

xAI 키를 하나 더 보관하려면 **새 제공업체 추가**를 클릭해 별도 프로필을 만들 수 있습니다.

## 모델 및 옵션

| 설정 | 설명 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용할 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴 아이콘)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **API 기본 URL** | 인증 정보 안에 있습니다. 기본값은 `https://api.x.ai/v1`입니다. |

xAI는 텍스트 음성 변환, 이미지 생성, 음성 텍스트 변환, 동영상 생성, X 검색용 제공업체도 별도로 제공합니다. 이들 기능은 이 프로필의 키 또는 Grok 로그인을 공유하며, 각 기능의 설정 페이지에서 선택할 수 있습니다.

## iPhone에서 사용하기

iPhone 앱의 폰 채팅에서도 Grok 요금제를 사용할 수 있습니다. iPhone에서 **설정 → AI 모델 → xAI**를 열고 **인증** 아래에서 Grok 카드를 선택한 뒤 **Grok으로 로그인**을 탭하세요. 자세한 내용은 [폰 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 xAI 콘솔에서 해당 키가 활성화되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 모델을 직접 추가하려면 **모델 관리**를 사용하세요. |
| Grok 로그인이 작동하지 않음 | 계정 카드의 메뉴를 열고 **다시 연결**을 클릭하세요. |
| 요청 빈도 또는 사용 한도 오류 | xAI 계정에서 사용량을 확인하거나 당분간 다른 제공업체로 전환하세요. |

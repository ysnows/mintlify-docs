title: "xAI (Grok)"
description: "xAI API 키 또는 Grok 플랜으로 Enconvo에서 Grok 모델과 대화하세요."
---

채팅, 에이전트, AI 명령에서 xAI의 Grok 모델을 사용하세요. 요청마다 xAI가 요금을 청구하는 xAI API 키로 연결하거나, Grok 플랜으로 로그인할 수 있습니다. 설정에는 **X.AI-GROK**으로 표시됩니다.

## 연결

<Steps>
  <Step title="API 키 받기">
    xAI 콘솔에서 키를 만드세요. 방법은 [xAI 퀵스타트](https://docs.x.ai/docs/quickstart#creating-an-api-key)에 나와 있습니다.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → X.AI-GROK**을 여세요. **인증**에서 **API 키**를 선택하고 키를 붙여넣은 다음 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 선택">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답장이 오면 연결이 정상입니다.
  </Step>
</Steps>

<Tip>
Grok 플랜이 있나요? **인증**에서 **Grok Subscription**을 선택하고 **연결**을 클릭하세요.
</Tip>

두 번째 xAI 키를 두려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델과 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**은 목록을 다시 불러오고, **모델 관리**(톱니바퀴)에서는 모델을 추가하거나 복원할 수 있습니다. |
| **API 기본 URL** | 자격 증명에 있습니다. 기본값은 `https://api.x.ai/v1`입니다. |

xAI는 텍스트 음성 변환, 이미지 생성, 음성 텍스트 변환, 동영상 생성, X 검색을 위한 제공업체도 따로 갖추고 있습니다. 이들은 이 프로필의 키 또는 Grok 로그인을 공유하며, 각각 해당 설정 페이지에서 선택합니다.

## iPhone에서

iPhone 앱의 iPhone 채팅에서도 Grok 플랜을 사용할 수 있습니다. iPhone에서 **설정 → AI 모델 → xAI**를 열고 **인증**의 Grok 카드를 선택한 다음 **Sign in with Grok**을 탭하세요. [iPhone 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여넣고, xAI 콘솔에서 키가 활성 상태인지 확인하세요. |
| 모델이 보이지 않음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| Grok 로그인이 작동하지 않음 | 계정 카드의 메뉴를 열고 **다시 연결**을 클릭하세요. |
| 속도 또는 사용량 한도 오류 | xAI 계정에서 사용량을 확인하거나, 당분간 다른 제공업체로 전환하세요. |

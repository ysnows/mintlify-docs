---
title: "DeepSeek"
description: "본인 DeepSeek API 키로 Enconvo에서 DeepSeek 모델과 채팅하세요."
---

DeepSeek는 API 키로 모델을 제공합니다. 키를 Enconvo에 추가하면 채팅, 에이전트, AI 명령에서 그 모델을 쓸 수 있습니다. 사용량은 본인 계정으로 청구됩니다. 설정에서는 **Deep Seek**로 표시됩니다.

## 연결

<Steps>
  <Step title="API 키 받기">
    [DeepSeek 플랫폼](https://platform.deepseek.com/api_keys)에서 키를 만드세요.
  </Step>
  <Step title="Enconvo에 추가">
    **설정 → AI 모델 → Deep Seek**를 여세요. **인증** 아래에서 키를 **API 키**에 붙여 넣은 뒤 **검증**을 클릭하세요.
  </Step>
  <Step title="모델 고르기">
    **모델 이름**에서 모델을 고르고 짧은 메시지를 보내세요. 답변이 오면 연결이 된 것입니다.
  </Step>
</Steps>

두 번째 DeepSeek 키, 예를 들어 업무용 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

같은 키는 다른 기능의 DeepSeek에도 쓸 수 있습니다. **설정 → 텍스트 음성 변환**, **설정 → 웹 검색**, **설정 → 웹 가져오기**, **설정 → OCR**(**DeepSeek OCR**로 표시), 그리고 음성 인식의 **받아쓰기 모델**이나 **음성 텍스트 변환 모델**에서 제공업체로 **DeepSeek**를 고르세요. 각각 키가 필요 없고 Enconvo 계정으로 실행되는 **DeepSeek (Enconvo Cloud)** 옵션도 있습니다.

## 모델과 옵션

| 설정 | 하는 일 |
| --- | --- |
| **모델 이름** | 이 제공업체가 쓰는 모델입니다. 옆의 **새로고침**이 목록을 다시 불러오고, **모델 관리**(톱니바퀴)가 모델을 추가하거나 복원합니다. |

한 채팅에서 다른 모델을 쓰려면 그 채팅의 모델 선택기에서 고르세요.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **검증**이 실패함 | 키 전체를 다시 붙여 넣고 DeepSeek 계정에서 활성인지 확인하세요. |
| 모델이 없음 | **모델 이름** 옆 **새로고침**을 클릭해 목록을 다시 불러오세요. 직접 추가하려면 **모델 관리**를 쓰세요. |
| 이미지나 도구가 실패함 | 이미지 입력이나 도구 호출을 지원하는 모델을 고르세요. |
| 속도나 사용량 한도 오류 | DeepSeek 계정에서 사용량과 한도를 확인하거나, 당분간 다른 제공업체로 바꾸세요. |
| 답변이 느림 | 더 작은 모델, 더 짧은 입력, 또는 더 낮은 추론 강도를 써 보세요. |

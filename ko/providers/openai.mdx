---

채팅, 에이전트, AI 명령에서 OpenAI의 GPT 모델을 사용하세요. 요청당 요금이 청구되는 OpenAI API 키로 연결하거나, ChatGPT 요금제로 로그인해 보유한 사용량을 쓸 수 있습니다.

## 연결하기

<Steps>
  <Step title="API 키 발급받기">
    [OpenAI 플랫폼](https://platform.openai.com/api-keys)에서 키를 생성합니다.
  </Step>
  <Step title="Enconvo에 추가하기">
    **설정 → AI 모델 → OpenAI**를 엽니다. **인증** 아래에서 **API 키**를 선택하고 키를 붙여 넣은 뒤 **검증**을 클릭합니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 이름**에서 모델을 선택하고 짧은 메시지를 보냅니다. 응답이 오면 연결이 완료된 것입니다.
  </Step>
</Steps>

<Tip>
ChatGPT 요금제를 이용 중이신가요? 대신 **인증** 아래에서 **ChatGPT Subscription**을 선택하고 **연결**을 클릭하세요. 자세한 내용은 [ChatGPT Subscription](/ko/providers/openai_subscription)을 참고하세요.
</Tip>

업무용 등 두 번째 OpenAI 키를 보관하려면 **새 제공업체 추가**를 클릭해 다른 프로필을 만드세요.

## 모델 및 옵션

| 설정 | 기능 |
| --- | --- |
| **모델 이름** | 이 제공업체가 사용하는 모델입니다. 옆의 **새로고침**으로 목록을 다시 불러오고, **모델 관리**(톱니바퀴)로 모델을 추가하거나 복원합니다. |
| **API 유형** | 인증 정보에 포함됩니다. **Responses API**(기본값) 또는 **Completions API** 중 선택합니다. 호환 서비스에서 Completions가 필요한 경우가 아니라면 Responses를 유지하세요. |
| **API 기본 URL** | 인증 정보에 포함됩니다. 기본값은 `https://api.openai.com/v1`입니다. OpenAI 호환 서비스를 사용할 때만 변경하세요. |

동일한 OpenAI 프로필은 OpenAI 임베딩, 음성 합성, 이미지 생성, 음성 텍스트 변환에도 함께 사용되므로 키를 변경하면 해당 기능에도 영향을 미칩니다. 한 채팅에서만 다른 모델을 쓰려면 해당 채팅의 모델 선택기에서 고르세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **검증**에 실패함 | 키 전체를 다시 붙여 넣고 OpenAI 플랫폼에서 활성화되어 있으며 결제가 설정되어 있는지 확인하세요. |
| 모델이 목록에 없음 | **모델 이름** 옆의 **새로고침**을 클릭하세요. 직접 모델을 추가하려면 **모델 관리**를 사용하세요. |
| 호환 서비스가 실패함 | **API 기본 URL**을 확인한 뒤 **API 유형**을 **Completions API**로 변경해 보세요. |
| 속도 또는 사용량 제한 오류 | OpenAI 플랫폼에서 사용량과 한도를 확인하거나 당분간 다른 제공업체로 전환하세요. |

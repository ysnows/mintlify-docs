## 시작하기

<AccordionGroup>
  <Accordion title="Enconvo는 어떤 Mac에서 실행되나요?">
    Apple Silicon과 Intel의 macOS 14 이상입니다. [로컬 LLM (MLX)](/ko/providers/mlx) 같은 일부 기기 내 기능은 Apple Silicon이 필요합니다. [설치](/ko/installation)를 보세요.
  </Accordion>
  <Accordion title="API 키가 필요한가요?">
    아니요. Enconvo 계정에 로그인하면 [Enconvo Cloud](/ko/providers/enconvo)가 키 없이 동작합니다. ChatGPT나 Claude처럼 이미 결제 중인 플랜으로 로그인하거나, 자신의 API 키를 추가하거나, Mac에서 모델을 실행할 수도 있습니다. [제공업체](/ko/providers/overview)를 보세요.
  </Accordion>
  <Accordion title="Enconvo 결제와 AI 결제는 어떻게 다른가요?">
    라이선스는 앱을 잠금 해제합니다. AI 요금은 실행되는 곳에서 청구됩니다. Enconvo Cloud 포인트, 제공업체 계정, 또는 자신의 Mac입니다. [플랜과 가격](/ko/pricing)을 보세요.
  </Accordion>
  <Accordion title="내 언어로 Enconvo를 쓸 수 있나요?">
    예. **설정 → 일반 → 언어**의 **앱 언어**에서 우크라이나어와 러시아어를 포함한 열두 가지 인터페이스 언어 중 하나를 고르세요. 에이전트는 같은 곳에서 설정하는 **응답 언어**로 답합니다. [언어, 모양, 설정 검색](/ko/configuration/appearance-language)을 보세요.
  </Accordion>
  <Accordion title="기능을 쓸 때 왜 권한을 묻나요?">
    Enconvo는 실행 시 macOS 권한을 묻지 않습니다. 권한이 필요한 기능을 처음 쓸 때 그 기능 이름을 밝히며 묻습니다. 기능이 다시 묻지 않게 하려면 **다시 묻지 않음**을 선택하세요. [macOS 권한](/ko/configuration/permissions)을 보세요.
  </Accordion>
  <Accordion title="문서에 있는 기능이 앱에 없습니다. 왜인가요?">
    일부 기능은 베타 채널에 먼저 나옵니다. 버전과 [업데이트 채널](/ko/configuration/updates)을 확인한 다음 [기능 디렉터리](/ko/reference/feature-directory)에서 기능을 찾아 보세요.
  </Accordion>
</AccordionGroup>

## 모델

<AccordionGroup>
  <Accordion title="어떤 모델을 써야 하나요?">
    잘 모르겠다면 [자동 경로](/ko/providers/auto-route)를 그대로 두세요. 메시지마다 모델을 고릅니다. 직접 고르려면 [모델 선택](/ko/ai/model-selection-guide)을 보세요.
  </Accordion>
  <Accordion title="기본 모델을 바꿨는데 채팅은 왜 예전 모델을 쓰나요?">
    채팅은 그 채팅에서 바꾸기 전까지 시작한 모델을 유지합니다. 프로젝트와 에이전트에도 각자의 기본값이 있습니다. [모델 선택](/ko/ai/model-selection-guide)을 보세요.
  </Accordion>
  <Accordion title="로컬 모델은 모든 것을 오프라인으로 유지하나요?">
    로컬 제공업체에서 실행되는 단계만 그렇습니다. 웹 검색, 원격 MCP 서버, 클라우드 음성, 클라우드 임베딩은 여전히 Mac 밖으로 데이터를 보냅니다. [로컬 모델](/ko/ai/local-llm)과 [개인정보 보호 및 보안](/ko/configuration/privacy-security)을 보세요.
  </Accordion>
</AccordionGroup>

## 음성

<AccordionGroup>
  <Accordion title="받아쓰기, 음성 명령, Live Talk의 차이는 무엇인가요?">
    [받아쓰기](/ko/features/dictation)는 말한 내용을 사용 중인 앱에 입력합니다. 음성 명령은 말한 내용을 요청으로 에이전트에 보냅니다. [Live Talk](/ko/features/live-voice)는 에이전트와 말로 주고받는 대화입니다.
  </Accordion>
  <Accordion title="Enconvo가 회의를 녹음하고 텍스트로 바꿀 수 있나요?">
    예. [회의 녹음](/ko/features/meeting-recording)은 진행하면서 녹음하고 텍스트로 바꾸며, [음성 텍스트 변환](/ko/features/transcription)은 이미 있는 오디오와 동영상 파일에 동작합니다.
  </Accordion>
</AccordionGroup>

## 컨텍스트와 지식

<AccordionGroup>
  <Accordion title="Appshots와 빠른 캡처의 차이는 무엇인가요?">
    [Appshots](/ko/features/appshots)는 보고 있는 앱 창을 질문에 첨부합니다. [빠른 캡처](/ko/features/quick-capture)는 화면에 있는 것을 나중에 쓰기 위해 지식 베이스에 저장합니다.
  </Accordion>
  <Accordion title="메모리와 지식 베이스의 차이는 무엇인가요?">
    [메모리](/ko/ai/memory)는 에이전트가 사용자에 대해 배우고 다시 쓰는 사실을 담습니다. [지식 베이스](/ko/ai/knowledge-base)는 추가한 문서를 담고, 에이전트가 답을 찾기 위해 검색합니다. 둘 다 지식 베이스에 있습니다. 열 위쪽의 **지식 베이스** / **메모리** 스위치로 오갑니다.
  </Accordion>
  <Accordion title="다른 AI 앱이 내 Enconvo 지식 베이스를 쓸 수 있나요?">
    예. [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)를 통해 가능하며, 선택한 지식 베이스로 제한해 켭니다.
  </Accordion>
</AccordionGroup>

## 에이전트와 자동화

<AccordionGroup>
  <Accordion title="에이전트가 다른 앱과 서비스의 도구를 쓸 수 있나요?">
    예. [플러그인](/ko/extensions/overview), [스킬](/ko/configuration/skills), [MCP 서버](/ko/features/mcp)를 통해 가능합니다. 허용하면 [브라우저](/ko/features/browser-control)와 [앱](/ko/features/computer-use)도 쓸 수 있습니다.
  </Accordion>
  <Accordion title="에이전트 명령이 닿는 범위를 제한할 수 있나요?">
    예. 에이전트의 **권한** 칩에서 **Sandbox**를 켜면 명령은 작업 폴더와 temp만 바꿀 수 있고, 키를 읽거나 다른 앱을 제어할 수 없습니다. [에이전트 Sandbox](/ko/configuration/sandbox)를 보세요.
  </Accordion>
  <Accordion title="자리를 비운 동안 작업이 실행될 수 있나요?">
    예. [자동화](/ko/workflows/scheduled-jobs)는 Enconvo가 실행 중이고 Mac이 깨어 있는 동안 일정에 따라 실행됩니다. 결과를 채팅 앱으로 받으려면 [메신저 채널](/ko/integrations/messaging)을 연결하세요.
  </Accordion>
</AccordionGroup>

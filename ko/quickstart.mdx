---
title: "빠른 시작"
description: "약 5분 만에 Enconvo를 설치하고, 모델을 연결하고, 첫 질문을 해 보세요."
---

이 페이지는 다운로드부터 첫 답변까지 안내합니다. 앱을 설치하고, Enconvo가 AI에 연결되는 방식을 고른 뒤, SmartBar에서 질문해 보세요.

<Steps>
  <Step title="Enconvo 설치하고 열기">
    [enconvo.com](https://www.enconvo.com)에서 Enconvo를 다운로드하고, DMG를 열어 **Enconvo**를 **앱** 폴더로 드래그하세요. 그곳에서 앱을 여세요. Enconvo는 macOS 14 이상이 필요합니다. 자세한 내용은 [설치](/ko/installation)를 참고하세요.
  </Step>
  <Step title="Enconvo가 AI에 연결되는 방식 고르기">
    가장 간단한 방법은 Enconvo 계정으로 로그인하는 것입니다. 그러면 기본 모델인 [자동 라우트](/ko/providers/auto-route)가 [Enconvo Cloud](/ko/providers/enconvo)에서 답변합니다. 언제든 바꿀 수 있습니다.

    | 방법 | 설정 |
    | --- | --- |
    | Enconvo Cloud | Enconvo 계정으로 로그인합니다. |
    | 이미 결제 중인 플랜 | [ChatGPT](/ko/providers/openai_subscription), [Claude](/ko/providers/anthropic_subscription), [Grok](/ko/providers/xai), [GitHub Copilot](/ko/providers/github-copilot) 등으로 로그인합니다. |
    | 내 API 키 | **설정 → AI 모델**을 열고 제공업체를 고른 뒤 키를 붙여 넣습니다. |
    | Mac의 모델 | [로컬 모델](/ko/ai/local-llm)을 설정합니다. |
  </Step>
  <Step title="첫 질문 하기">
    **⌥Space**를 눌러 SmartBar를 열고, 생산적인 아침을 위한 체크리스트 세 가지를 알려 달라는 식의 질문을 입력한 다음 Return을 눌러 답변을 확인하세요.
  </Step>
  <Step title="내 텍스트에 써 보기">
    아무 앱에서나 문단 하나를 선택하세요. 옆에 [PopBar](/ko/features/popbar)가 나타나면 **설명** 또는 **번역**을 클릭하세요.
  </Step>
</Steps>

<Tip>
SmartBar, 채팅 창, 받아쓰기, [초안](/ko/features/dictation), 음성 명령, PopBar, 앱 사이드바를 안내하는 둘러보기를 보려면 **설정 → 일반**을 열고 **가이드 둘러보기** 옆의 **둘러보기 시작**을 클릭하세요. 둘러보기는 Enconvo의 언어로 진행되며 약 3분이 걸립니다.
</Tip>

Enconvo는 실행할 때 macOS 권한을 요청하지 않습니다. 마이크나 화면 기록처럼 권한이 필요한 기능을 처음 사용할 때 Enconvo가 해당 기능을 알려 주고 그때 요청합니다. 각 권한이 허용하는 기능은 [권한](/ko/configuration/permissions)을 참고하세요.

## 아무 일도 일어나지 않는다면

| 문제 | 해결 방법 |
| --- | --- |
| **⌥Space**를 눌러도 SmartBar가 열리지 않습니다 | **설정 → SmartBar**에서 단축키를 확인하거나, 메뉴 막대의 Enconvo 아이콘을 사용하세요. |
| SmartBar는 열리지만 답변이 없습니다 | Enconvo 계정에 로그인하거나, **설정 → AI 모델**에서 제공업체를 확인하세요. |
| PopBar가 나타나지 않습니다 | 손쉬운 사용 권한을 허용하세요. [권한](/ko/configuration/permissions)을 참고하세요. |

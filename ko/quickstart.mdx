---
title: "빠른 시작"
description: "약 5분 만에 Enconvo를 설치하고 모델을 연결한 뒤 첫 번째 질문을 해 보세요."
---

이 페이지에서는 다운로드부터 첫 번째 답변을 받기까지의 과정을 안내합니다. 앱을 설치하고 Enconvo가 AI에 연결하는 방식을 선택한 다음, SmartBar에서 질문해 봅니다.

<Steps>
  <Step title="Enconvo 설치 및 실행">
    [enconvo.com](https://www.enconvo.com)에서 Enconvo를 다운로드해 DMG를 열고 **Enconvo**를 **응용 프로그램** 폴더로 드래그하세요. 그 위치에서 앱을 실행합니다. Enconvo에는 macOS 14 이상이 필요합니다. 자세한 내용은 [설치](/ko/installation)를 참고하세요.
  </Step>
  <Step title="Enconvo의 AI 연결 방식 선택">
    가장 간단한 방법은 Enconvo 계정에 로그인하는 것입니다. 그러면 기본 모델인 [자동 라우팅](/ko/providers/auto-route)이 [Enconvo Cloud](/ko/providers/enconvo)에서 답변을 제공합니다. 언제든 다른 방식으로 전환할 수 있습니다.

    | 옵션 | 방법 |
    | --- | --- |
    | Enconvo Cloud | Enconvo 계정에 로그인합니다. |
    | 이미 구독 중인 요금제 | [ChatGPT](/ko/providers/openai_subscription), [Claude](/ko/providers/anthropic_subscription), [Grok](/ko/providers/xai), [GitHub Copilot](/ko/providers/github-copilot) 등으로 로그인합니다. |
    | 자체 API 키 | **설정 → AI 모델**을 열고 제공업체를 선택한 뒤 키를 붙여 넣습니다. |
    | Mac의 로컬 모델 | [로컬 모델](/ko/ai/local-llm)을 설정합니다. |
  </Step>
  <Step title="첫 번째 질문하기">
    **⌥Space**를 눌러 SmartBar를 열고 생산적인 아침을 위한 3가지 체크리스트와 같은 질문을 입력한 뒤 Return을 눌러 답변을 확인하세요.
  </Step>
  <Step title="내 텍스트에 직접 사용해 보기">
    어느 앱에서나 문단 하나를 선택합니다. 옆에 [PopBar](/ko/features/popbar)가 나타나면 **설명** 또는 **번역**을 클릭하세요.
  </Step>
</Steps>

<Tip>
SmartBar, 채팅 창, 받아쓰기, [초안](/ko/features/dictation), 음성 명령, PopBar, 앱 사이드바를 안내에 따라 둘러보려면 **설정 → 일반**을 열고 **가이드 둘러보기** 옆의 **둘러보기 시작**을 클릭하세요. 둘러보기는 Enconvo의 언어로 제공되며 약 3분이 걸립니다.
</Tip>

Enconvo는 실행 시 바로 macOS 권한을 요청하지 않습니다. 마이크나 화면 기록 등 권한이 필요한 기능을 처음 사용할 때 해당 기능 이름을 알려 주며 요청합니다. 각 권한으로 활성화되는 기능은 [macOS 권한](/ko/configuration/permissions)을 참고하세요.

## 아무 일도 일어나지 않는 경우

| 문제 | 해결 방법 |
| --- | --- |
| **⌥Space**로 SmartBar가 열리지 않음 | **설정 → SmartBar**에서 단축키를 확인하거나 메뉴 막대의 Enconvo 아이콘을 사용하세요. |
| SmartBar는 열리지만 답변이 나오지 않음 | Enconvo 계정에 로그인하거나 **설정 → AI 모델**에서 제공업체를 확인하세요. |
| PopBar가 나타나지 않음 | 손쉬운 사용 권한을 허용하세요. [macOS 권한](/ko/configuration/permissions)을 참고하세요. |

title: "설치"

---

Enconvo는 Apple 실리콘과 Intel Mac 모두에서 macOS 14 이상에서 실행됩니다. [로컬 LLM(MLX)](/ko/providers/mlx) 같은 일부 온디바이스 기능은 Apple 실리콘이 필요하며, 로컬 모델에는 충분한 메모리와 디스크 공간도 필요합니다.

Windows 10과 11(x64)에서는 베타가 데스크톱 앱으로 실행됩니다. [Windows(베타)](/ko/getting-started/windows)를 참고하세요.

Linux에서는 베타가 데스크톱과 서버에서 실행됩니다. [Linux(베타)](/ko/getting-started/linux)를 참고하세요.

## 설치하기

<Steps>
  <Step title="다운로드">
    [enconvo.com](https://www.enconvo.com)에서 사용 중인 Mac의 프로세서에 맞는 DMG를 받으세요.
  </Step>
  <Step title="앱 폴더로 옮기기">
    DMG를 열고 **Enconvo**를 **앱** 폴더로 드래그하세요.
  </Step>
  <Step title="Enconvo 열기">
    **앱** 폴더에 있는 Enconvo를 열고 시작 안내를 따르세요. 그다음 [빠른 시작](/ko/quickstart)으로 이어가세요.
  </Step>
</Steps>

**앱** 폴더에 있는 사본만 두세요. 단축키, 권한, 업데이트는 모두 한 사본을 기준으로 동작하며, 다른 곳에 둔 두 번째 사본은 실제로 쓰는 사본에 없는 권한을 받을 수 있습니다.

## 업데이트

메뉴 막대의 Enconvo 아이콘에서 **업데이트 확인**을 선택하거나, **설정 → 일반 → 업데이트**에서 클릭하세요. 새 기능을 더 빨리 받으려면 **설정 → 일반**을 열고 **업데이트 채널**을 **베타** 또는 **개발**로 바꾸세요. 기본값은 **프로덕션**입니다. [업데이트](/ko/configuration/updates)를 참고하세요.

앱과 내장 플러그인은 따로 업데이트됩니다. 기능이 없거나 다르게 동작하면 둘 다 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 앱이 열리지 않습니다 | Mac이 macOS 14 이상인지, 다운로드가 끝까지 완료되었는지 확인하세요. |
| 권한은 켜져 있는데 기능이 여전히 사용하지 못합니다 | Enconvo를 종료하고 **앱** 폴더에서 다시 여세요. 이전 사본이 실행 중이지 않은지 확인하세요. |
| 로컬 모델이 다운로드되지 않습니다 | 디스크 공간과 연결 상태, 그리고 모델이 사용 중인 Mac을 지원하는지 확인하세요. |
| 앱 창을 찾을 수 없습니다 | 메뉴 막대나 Dock의 Enconvo 아이콘을 클릭하거나, **⌥Space**를 눌러 SmartBar를 여세요. |
| macOS가 다운로드한 파일이 손상되었거나 확인할 수 없다고 표시합니다 | [enconvo.com](https://www.enconvo.com)에서 새로 다운로드하세요. macOS 보안 설정을 끄지 마세요. |

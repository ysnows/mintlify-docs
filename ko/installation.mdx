---

Enconvo는 Apple Silicon과 Intel Mac의 macOS 14 이상에서 실행됩니다. [Local LLM (MLX)](/ko/providers/mlx) 같은 일부 온디바이스 기능은 Apple Silicon이 필요하며, 로컬 모델은 충분한 메모리와 디스크 공간도 필요합니다.

Windows 10 및 11(x64)에서는 베타 버전을 데스크톱 앱으로 실행할 수 있습니다. [Windows (베타)](/ko/getting-started/windows)를 참고하세요.

Linux에서는 베타 버전을 데스크톱과 서버에서 실행할 수 있습니다. [Linux (베타)](/ko/getting-started/linux)를 참고하세요.

## 설치

<Steps>
  <Step title="다운로드">
    [enconvo.com](https://www.enconvo.com)에서 사용 중인 Mac 프로세서에 맞는 DMG를 받습니다.
  </Step>
  <Step title="응용 프로그램으로 이동">
    DMG를 열고 **Enconvo**를 **응용 프로그램** 폴더로 드래그합니다.
  </Step>
  <Step title="Enconvo 실행">
    **응용 프로그램**에 있는 복사본을 열고 환영 안내를 따릅니다. 이어서 [빠른 시작](/ko/quickstart)을 진행하세요.
  </Step>
</Steps>

**응용 프로그램** 폴더에 있는 복사본 하나만 유지하세요. 단축키, 권한, 업데이트가 모두 단일 앱을 가리키므로 다른 위치에 두 번째 복사본이 있으면 실행 중인 앱에 권한이 적용되지 않을 수 있습니다.

## 업데이트

Enconvo 메뉴 막대 아이콘에서 **업데이트 확인**을 선택하거나 **설정 → 일반 → 업데이트**에서 클릭하세요. 새 기능을 더 빨리 받아 보려면 **설정 → 일반**에서 **업데이트 채널**을 **베타** 또는 **개발**로 설정하세요. 기본값은 **프로덕션**입니다. 자세한 내용은 [업데이트](/ko/configuration/updates)를 참고하세요.

앱과 내장 플러그인은 별도로 업데이트됩니다. 기능이 보이지 않거나 다르게 동작하면 두 가지 모두 업데이트를 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 앱이 열리지 않음 | Mac이 macOS 14 이상을 실행 중인지, 다운로드가 완료되었는지 확인하세요. |
| 권한이 켜져 있는데도 기능이 작동하지 않음 | Enconvo를 종료한 뒤 **응용 프로그램**에서 다시 실행하세요. 이전 복사본이 실행 중이지 않은지 확인하세요. |
| 로컬 모델이 다운로드되지 않음 | 디스크 공간과 네트워크 연결, 그리고 해당 모델이 사용 중인 Mac을 지원하는지 확인하세요. |
| 앱 창을 찾을 수 없음 | 메뉴 막대나 Dock에서 Enconvo 아이콘을 클릭하거나 **⌥Space**를 눌러 SmartBar를 여세요. |
| macOS에서 다운로드가 손상되었거나 확인할 수 없다고 표시함 | [enconvo.com](https://www.enconvo.com)에서 새 파일을 다시 다운로드하세요. macOS 보안 설정을 끄지 마세요. |

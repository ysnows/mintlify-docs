예약 작업은 매번 직접 시작하지 않아도 대신 일을 해 줍니다. 에이전트에게 무언가를 시키거나, 저장해 둔 워크플로를 실행하거나, 셸 명령어를 실행합니다. 일정에 따라(한 번 또는 반복해서), 새 이메일이나 폴더에 파일이 생기는 것과 같은 일이 생겼을 때, 또는 직접 시작할 때 실행됩니다. 아침 뉴스 브리핑, 주간 계획, 가격 확인 등에 사용하세요.

실행할 때마다 자체 대화가 시작되고 결과는 예약 작업에 표시됩니다. Mac에서 Enconvo가 알림을 보내게 하거나, 결과를 메신저 채팅으로 보내거나, GitHub에서 답글을 달거나, 들은 내용을 프로젝트의 아이디어 보드에 추가하게 할 수도 있습니다.

각 예약 작업은 세 부분으로 구성되며, 각 부분을 그 자리에서 직접 또는 말로 바꿀 수 있습니다.

| 부분 | 담고 있는 내용 |
| --- | --- |
| **언제** | 일정, 이벤트, 또는 직접 시작 |
| **단계** | 실행할 에이전트와 지침, 워크플로 또는 셸 명령어 |
| **그다음** | 결과를 보낼 곳과 결과를 알려 주는 방식 |

실행 기록은 아래에 막대로 표시되므로, 무엇이 실행되었고 무엇이 실패했는지 한눈에 볼 수 있습니다.

이 영상은 예약 작업, 워크플로, 변수, 그리고 알림과 방해 금지 시간으로 결과를 확인하는 방법을 다룹니다.

## 채팅으로 예약 작업 설정하기

<Steps>
  <Step title="예약 작업 열기">
    **채팅 창** 사이드바에서 **예약 작업**을 선택한 다음 **새 예약 작업**을 선택합니다.
  </Step>
  <Step title="무엇을 언제 할지 말하기">
    입력창에 작업과 시점을 설명하세요. 예: "평일 8시마다 가장 중요한 AI 뉴스를 링크와 함께 다섯 줄로 브리핑해 줘." 또는 시작 예시 중 하나를 고르면 입력창이 채워지며, 보내기 전에 조정할 수 있습니다.

    저장된 워크플로가 있으면 **일정에 따라 워크플로 실행** 아래에 몇 개가 표시됩니다. 하나를 고르면 그 워크플로를 매일 9시에 실행하는 요청이 채워지며, 보내기 전에 시간을 바꾸거나 입력 값을 추가할 수 있습니다.
  </Step>
  <Step title="초안 확인하기">
    Enconvo가 작업을 설정하고 채팅에 카드로 보여 준 뒤, 언제 실행되는지를 쉬운 말과 현지 시간으로 답합니다. 시간을 말하지 않으면 적당한 시간을 골라 그렇게 알려 줍니다. 어떤 제품을 지켜볼지처럼 답이 없으면 작업이 성립하지 않을 때만 질문합니다.
  </Step>
  <Step title="켜기">
    새 예약 작업은 꺼진 상태로 시작하며 채팅 옆에 **초안**으로 표시됩니다. 내용을 확인하고 **켜기**를 선택하세요. 켜기 전에는 아무것도 실행되지 않습니다. 작업은 대화 위의 **이 채팅에서 설정**과 작업 목록에 나타납니다. 계속 채팅하면 작업을 바꾸거나, 일시 정지하거나, 다시 시작할 수 있습니다.
  </Step>
</Steps>

작업은 완전한 지침으로 작성하세요. 실행할 때마다 새 대화가 시작되며 설정한 채팅의 내용을 볼 수 없으므로, "내일 다시 해 줘"보다 "오늘의 AI 주요 뉴스를 링크와 함께 다섯 줄로 요약해 줘"가 더 잘 작동합니다.

## 예정된 작업과 실행된 작업 확인하기

예약 작업 맨 위의 **오늘**에는 다음에 실행될 작업과 이미 실행된 모든 작업이 각 실행의 결과와 함께 표시됩니다. 실행을 선택하면 결과를 읽거나, 실패한 실행을 다시 시도할 수 있습니다.

각 예약 작업의 최근 실행은 시작하는 즉시 사이드바의 **채팅**에도 시계 표시와 함께 나타납니다. 이전 실행은 해당 실행의 채팅에서 한 번의 클릭으로 볼 수 있습니다.

### 예약 채팅으로 돌아가기

예약 채팅은 보관되지만 사이드바의 **채팅**에는 표시되지 않습니다. Enconvo가 답을 기다리는 채팅처럼 예약 채팅으로 돌아가려면, 대화 위의 채팅 이름을 선택하고 **예약 작업 채팅**에서 해당 채팅을 고르세요. 여기서 채팅을 삭제할 수도 있으며, 그 채팅에서 설정한 작업은 계속 실행됩니다.

### 어떤 채팅에서든 요청하기

아무 채팅에서나 "내일 9시에 청구서 보내라고 알려 줘" 또는 "매주 월요일 아침에 이번 주 마감일을 나열해 줘"처럼 요청할 수도 있습니다. 에이전트가 같은 종류의 작업을 설정하고 카드를 보여 준 뒤 언제 실행되는지 확인해 줍니다. 카드에서 **열기**를 선택하면 **예약 작업**에서 볼 수 있습니다. 오래된 채팅의 카드에는 그 뒤에 작업이 일시 중지되었는지, 완료되었는지, 삭제되었는지가 표시됩니다.

## 이벤트로 또는 직접 시작하기

예약 작업은 시간 대신 어떤 일이 생겼을 때 시작할 수도 있습니다. 예약 작업 채팅에서 무엇이 시작해야 하는지 설명하면 Enconvo가 트리거를 설정합니다.

| 시작 조건 | 실행 시점 |
| --- | --- |
| 일정 | 설정한 시간 |
| 직접 | **실행**을 선택할 때. 입력한 텍스트가 있으면 그 텍스트로 작업합니다. **PopBar에 표시**를 켜면 선택한 텍스트로 실행할 수 있고, **Dynamic Island 홈에 표시**를 켜면 Dynamic Island에 버튼이 생깁니다. |
| 폴더 변경 | 폴더에 파일이 추가, 변경, 삭제될 때마다 |
| 앱 | 앱이 열리거나, 종료되거나, 맨 앞으로 오거나, 일정 시간 맨 앞에 머물 때 |
| Discord 또는 Telegram 메시지 | 연결된 봇이 읽을 수 있는 메시지마다 |
| 새 이메일 | 에이전트가 읽을 수 있게 허용한 [이메일](/ko/integrations/email) 플러그인 사서함의 새 이메일마다(1분마다 확인), Apple 메일(메일이 열려 있는 동안 2분마다), 또는 Gmail 커넥터를 통한 Gmail(약 5분마다) |
| GitHub | 연결한 저장소에서 이슈나 풀 리퀘스트가 열리거나, 이슈에 라벨이 붙거나, 댓글에서 사용자를 언급하거나, CI가 실패하거나, 릴리스가 게시될 때. [GitHub 트리거](#github-트리거)를 참고하세요. |
| MCP 이벤트 | 연결된 MCP 서버가 보고하는 이벤트마다 |
| 전사된 녹음 | Enconvo가 전사를 마친 녹음마다 |
| 웹 페이지와 피드 | 새 피드 항목마다, 또는 페이지의 텍스트가 바뀔 때마다 |
| 복사 | 클립보드 기록이 무시하지 않는 앱에서 복사하는 항목마다 |
| Mac 이벤트 | Mac이 깨어나거나, 잠금 해제되거나, 전원이 연결 또는 해제될 때, 또는 Mac을 떠나거나 돌아왔을 때 |
| 캘린더 이벤트 | 캘린더 이벤트가 시작되기 전 또는 끝날 때 |
| 회의 | Zoom, Teams, FaceTime 또는 WeChat 통화에서 회의가 시작될 때 |
| 로그인 | 로그인한 뒤 Enconvo가 시작될 때마다 한 번 |
| 웹훅 요청 | 예약 작업 자체 주소로 요청이 올 때마다. 주소는 작업 페이지에 복사 버튼과 함께 표시됩니다 |

Enconvo는 실행 중일 때 Mac에서 발생하는 이벤트를 감시합니다. Enconvo가 종료되어 있는 동안 발생한 이벤트가 어떻게 처리되는지는 작업의 트리거 행에 표시됩니다.

### GitHub 트리거

<Steps>
  <Step title="GitHub 연결하기">
    **시점**에서 GitHub를 선택하고 **GitHub 연결**을 선택합니다. Enconvo 계정에 로그인되어 있어야 합니다.
  </Step>
  <Step title="저장소와 이벤트 고르기">
    **저장소**(직접 입력하려면 **다른 저장소…**)와 **이벤트**를 선택합니다. 라벨이 붙은 이슈는 **라벨** 또는 **모든 라벨**을 고르세요. 저장소를 감시하려면 해당 저장소의 관리자 권한이 필요합니다.
  </Step>
  <Step title="시작할 수 있는 사람 선택하기">
    **나만**, **누구나**를 고르거나, 이벤트가 작업을 시작해야 하는 사람들의 GitHub 사용자 이름을 추가하세요.
  </Step>
</Steps>

GitHub 이벤트는 Enconvo Cloud를 거쳐 Mac에 전달되며, 여기서 외부 트리거를 허용하기 전까지는 이 Mac에 대해 봉인된 상태로 남습니다. 요청이 나타나면 **이 Mac에서 허용**을 선택하세요. **이 Mac에서 외부 트리거 중지**를 선택하면 다시 중지되며, 이벤트는 Enconvo Cloud에서 대기합니다.

이벤트 트리거에는 자신의 말로 쓴 조건도 걸 수 있습니다. AI가 실행 전에 각 이벤트를 조건과 비교하며, 일치하지 않는 이벤트는 건너뜁니다. 건너뛴 이벤트에서도 **그래도 실행**을 선택할 수 있습니다. 확인할 때마다 유료 AI 호출이 사용됩니다. **최근 이벤트로 시험**을 선택하면 아무것도 실행하지 않고 최근 이벤트 중 어느 것에 실행되었을지 볼 수 있습니다.

## 예약 작업 관리하기

목록에서 예약 작업을 선택하면 활성, 일시 중지됨 또는 확인 필요 상태와 함께 **언제**, **단계**, **그다음** 부분 및 실행 기록이 표시됩니다.

마지막 실행이 실패했거나 결과가 전송되지 않은 경우, 이름 아래의 메모에 이유와 해결 방법이 표시됩니다.

- **채팅으로 수정**(에이전트 또는 워크플로 작업)은 오류를 지정해 수정을 요청하는 메시지와 함께 작업의 채팅을 열며, **다시 실행**은 한 번 더 실행합니다.
- **다시 보내기**는 결과 전송을 재시도하고, **결과 저장 위치 변경**은 결과 선택기를 엽니다. 여기서 **Enconvo만**을 선택하면 전송되지 않은 결과에 대한 메모도 사라집니다.
- 스스로 시작하는 작업은 연속으로 5번 실행에 실패하면 일시 중지됩니다. 문제를 해결한 뒤 **켜기**를 선택하세요.

| 컨트롤 | 기능 |
| --- | --- |
| **지금 실행** | 작업을 즉시 한 번 실행합니다. 실제로 실행되므로 에이전트가 도구나 포인트를 사용할 수 있습니다. 직접 시작하는 작업에는 대신 **실행**이 있습니다. |
| **채팅에 따라 변경** | 에이전트 작업의 경우 작업을 설정한 채팅을 다시 엽니다(없으면 새로 시작합니다). "7시 30분으로 옮겨 줘"나 "날씨도 추가해 줘"처럼 변경 내용을 설명할 수 있습니다. |
| **작업 이름** | 이름을 선택하면 작업 이름을 바꿀 수 있습니다. Return을 누르면 저장하고 Esc를 누르면 취소합니다. |
| **일정** | 작업이 실행되는 시간과 다음 실행을 표시합니다. 일정은 **매일 09:00 및 18:00**, **매년 1월 1일 03:00**처럼 쉬운 말로 표시되며, 목록, 설정, 채팅 카드에서 모두 같습니다. 선택하면 그 자리에서 시간을 바꿀 수 있습니다. **한 번**, **매일**, **매주**, **월간**, **간격**, **Cron** 중에서 고르고, 다음 실행을 확인한 뒤 **저장**을 선택하세요. 옆의 스위치는 작업을 삭제하지 않고 이후 실행을 일시 중지합니다. |
| **지침** → **편집** | 에이전트에게 요청하는 내용(셸 명령어 작업은 명령어)을 그 자리에서 바꿉니다. **⌘↩**을 누르거나 **저장**을 선택하세요. Esc는 취소입니다. |
| **결과** | 각 실행의 결과가 가는 곳을 표시합니다. 선택한 뒤 메신저 채널로 에이전트와 대화한 채팅을 고르거나, 결과를 각 실행의 대화에만 두려면 **Enconvo만**을 고르세요. 변경 사항은 즉시 저장됩니다. **다른 채팅…**은 채팅 ID를 입력하는 편집기를 엽니다. |
| **실행 시 알림 받기** | 실행이 끝나면 결과의 첫 줄과 함께 Mac 알림을 표시합니다. 클릭하면 작업이 열립니다. |
| **…** → **세부 정보 편집** | 에이전트, 설명, 최대 실행 횟수를 포함한 모든 필드를 한 번에 편집하는 양식 편집기를 엽니다. |
| **…** → **복제** | 사본을 만들어 초안으로 열므로, 켜기 전에 변경할 수 있습니다. |
| **…** → **모든 실행 기록** | 필터가 있는 전체 실행 기록을 엽니다. |
| **…** → **삭제** | 예약 작업과 실행 기록을 삭제합니다. 실행 중인 작업을 삭제하면 그 실행도 중지됩니다. |

실행 막대를 선택하면 해당 실행의 결과나 오류를 읽고, 그 대화에서 이어서 진행하고, 복사하고, 전송되지 않았다면 결과를 다시 보낼 수 있습니다.

### 고급 설정

예약 작업에서 **고급 설정**을 열어 어디까지 허용할지 설정하세요.

| 설정 | 기능 |
| --- | --- |
| **실행 횟수 제한** | 전체 실행 횟수입니다. 완료된 예약 작업에 여기서 실행 횟수를 더 줄 수 있습니다. |
| **시간 제한** | 한 번의 실행에 허용되는 시간으로, 15분에서 8시간까지입니다. 실행이 제한에 도달하면 더 긴 제한(**… 허용하고 다시 실행**)을 제안하므로, 한 번의 클릭으로 시간을 더 주고 다시 실행할 수 있습니다. |

### 예약 작업 찾기

이름, 지침, 명령어, 워크플로로 목록을 검색하세요. 목록은 예약 작업을 **확인 필요**(마지막 실행이 실패했거나 결과가 전송되지 않음), 예정됨, **일시 중지됨**, **완료됨**(실행을 마친 일회성 예약 작업)으로 묶어 보여 줍니다. 예약 작업이 여러 방식으로 시작되는 경우, 목록 위의 버튼이 시작 조건별로 필터링하며 **전체**를 누르면 모두 다시 표시됩니다.

작업을 열지 않고 조작하려면 목록에서 작업을 가리키고 **…**를 선택하거나 Control 키를 누른 채 클릭한 다음, **지금 실행**, **일시 정지** 또는 **이어서 실행**, **세부 정보 편집**, **삭제** 중에서 고르세요. **작업 검색**에서 ↓를 누르면 첫 번째 작업으로 이동하며, 이후 ↑와 ↓로 작업 사이를 이동합니다.

## 양식 편집기 사용하기

새 작업 화면에서 **대신 양식으로 작업 설정**을, 작업에서는 **세부 정보 편집**을 선택하면 모든 필드를 직접 채울 수 있습니다.

<Frame caption="에이전트 지침과 평일 일정이 있는 작업 편집기.">
  <img src="/images/guides/scheduled-task-editor.jpg" alt="에이전트, 지침, 월요일부터 금요일 09:00의 주간 일정이 있는 예약 작업 편집 대화상자" />
</Frame>

1. 작업의 이름을 정하고 하는 일을 선택합니다. 에이전트와 지침이 있는 **에이전트에게 질문**, 저장한 [워크플로](/ko/workflows/introduction) 중 하나를 실행하는 **워크플로 실행**, Mac의 스크립트를 위한 **셸 명령어 실행**이 있습니다. 워크플로는 받아야 할 입력을 채우세요. 비워 둔 입력은 워크플로의 기본값을 사용합니다.
2. **시점**에서 **한 번**, **매일**, **매주**, **월간**, **간격**, **Cron** 중에서 고르고 **다음 실행 시간(현지 시간)** 미리보기를 확인합니다. **Cron**에서는 표현식 아래의 줄이 입력하는 동안 그 의미를 알려 줍니다. 예를 들어 `0 9-17 * * 1-5`는 **평일 09:00부터 17:00까지 매시간**으로 표시됩니다.
3. **결과 보내기**에서 **각 결과를 채팅으로 보내기**를 켜면 결과를 메신저 채팅으로 전달합니다. 채팅이 선택기에 나타나도록 먼저 해당 채팅에서 에이전트와 대화해야 할 수 있습니다.
4. **추가 옵션**에서 설명과 최대 실행 횟수를 추가할 수 있습니다.
5. **저장**(또는 **작업 만들기**)을 선택합니다. **테스트 실행**은 작업을 저장하고 즉시 실행합니다.

셸 명령어 작업과 채팅 ID로 결과를 보내는 설정은 이 편집기에서만 할 수 있으며, 예약 채팅은 에이전트와 워크플로 작업을 처리합니다. 이벤트로 시작하는 작업의 경우 양식으로는 트리거를 바꿀 수 없습니다. 예약 작업 채팅에서 시작 조건을 바꾸세요.

셸 명령어 작업은 몇 분마다 실행되는 경우가 많으므로, 실행이 실패할 때만(**실패 시 알림 받기**) 알려 줍니다.

## 워크플로 예약하기

워크플로 작업은 워크플로 편집기에서 **실행**을 선택하는 것과 같이 저장된 워크플로를 선택한 시간에 실행합니다. 편집기에서 **워크플로 실행**을 고르거나 예약 채팅에 "평일 9시마다 Content Pipeline을 주제 AI 뉴스로 실행해 줘"처럼 요청하세요. 이름으로 워크플로를 찾고, 말한 입력을 채우며, 나머지는 기본값으로 둡니다.

각 실행의 결과는 워크플로의 마지막 단계의 출력이므로, 다른 결과와 마찬가지로 채팅으로 보내거나 알림으로 표시할 수 있습니다. 단계가 실패하면 그 단계의 오류와 함께 실행이 실패로 표시됩니다.

- 작업의 세부 정보에는 워크플로와 입력이 표시됩니다. **열기**를 선택하면 워크플로가 열리고, **변경**을 선택하면 다른 워크플로를 고르거나 입력을 바꿀 수 있습니다.
- 펼친 실행 아래에서 **실행 열기**를 선택하면 **워크플로**에서 해당 실행의 각 단계를 볼 수 있습니다. 마지막 실행이 실패하면 작업 이름 아래의 메모에 **실패한 실행 열기**가 표시됩니다.
- 실행은 예약 작업의 **시간 제한**에서 중지됩니다([고급 설정](#고급-설정) 참고). 승인 단계에서 사용자의 답을 기다리는 시간은 포함되지 않습니다.
- 워크플로가 삭제되면 작업이 일시 중지되고 그 사실이 표시됩니다. **워크플로 선택**을 선택해 다른 워크플로를 지정하거나, **삭제**를 선택해 작업을 제거하세요.

## 설정에서 많은 작업 관리하기

**설정 → 예약 작업**에는 셸 명령어 작업을 포함한 모든 작업이 표로 나열됩니다. **활성**, **일시 중지됨**, **확인 필요**로 필터링하거나 검색할 수 있고, 여러 작업을 선택해 한꺼번에 일시 중지, 재개 또는 삭제할 수 있습니다. 작업의 기록에는 각 실행의 상태가 표시됩니다.

| 상태 | 확인할 내용 |
| --- | --- |
| 실패 | 지침, 에이전트의 도구, 셸 종료 상태 또는 오류 세부 정보 |
| 성공 / 전달되지 않음 | 작업은 실행되었지만 메신저 채널이나 채팅을 확인해야 합니다 |
| 완료 · 더 이상 실행 없음 | 일회성 작업이 끝났습니다 |
| 일시 중지됨 | 이후 실행을 원하면 다시 켜세요 |

기록에서 **대화 열기**는 에이전트 실행을 열고, **결과 복사**는 출력을 복사하며, **다시 보내기**는 결과를 설정된 채팅에 실제 메시지로 다시 보냅니다.

## 실행 후

결과를 채팅으로 보내고 알림을 받는 것 외에도 **그다음**에는 두 가지 옵션이 더 있습니다.

- **GitHub에서 답글**: GitHub 이벤트로 시작하는 예약 작업의 경우, Enconvo는 실행을 시작한 이슈나 풀 리퀘스트에 답을 댓글로 게시하기 전에 먼저 사용자에게 묻습니다. 하루 안에 아무도 승인하지 않은 답은 게시되지 않습니다.
- **Ideas에 추가**: 예약 작업이 받은 GitHub 이슈, Discord 또는 Telegram 메시지, 이메일, 웹훅 요청이 각각 프로젝트의 Ideas 보드에 아이디어로 추가됩니다. 프로젝트의 리드는 버그를 재현하고 수정 계획을 세우거나, 요청을 조사한 뒤 이유와 함께 닫거나 계획할 수 있으며, 무엇이든 바꾸기 전에 사용자에게 묻습니다. [프로젝트](/ko/ai/projects)를 참고하세요.

## 결과 확인하기

- 워크플로는 단계와 에이전트를 연결해 다시 실행할 수 있는 작업으로 만듭니다. [워크플로 예약하기](#워크플로-예약하기)에서 하나를 고르거나 [워크플로](/ko/workflows/introduction)에서 만드세요.
- [변수](/ko/workflows/variables)는 오늘 날짜나 선택한 텍스트처럼 매번 달라지는 값을 프롬프트와 지침에 넣어 줍니다.
- **설정 → 알림**에서 실행이 끝났음을 알려 주는 방식을 선택합니다. **방해 금지 시간**을 켜면 에이전트의 질문과 완료된 작업을 아침까지 보류하고, 승인 요청은 계속 받으려면 **승인 요청은 계속 알림**을 켜세요. [알림](/ko/configuration/notifications)을 참고하세요.

## 알아 두면 좋은 점

- 예약 작업은 Mac에서 실행되므로 Enconvo가 실행 중이고 Mac이 깨어 있어야 합니다. 잠자기 상태이거나 오프라인인 Mac은 실행하지 않으므로 항상 켜져 있는 스케줄러로 의존하지 마세요.
- 시간은 Mac의 현지 시간대를 따릅니다. 여행이나 시간대 변경 후에는 다음 실행 시간을 확인하세요.
- 일회성 작업에는 미래의 시간이 필요하며, 실행된 뒤에는 **완료됨**으로 이동합니다.
- 에이전트에게 나중에 Apple 메시지를 보내 달라고 요청하면 일회성 예약 작업이 설정되므로, 예약된 메시지를 예약 작업에서 확인하거나 취소할 수 있습니다.
- 29일부터 31일까지 매월 실행하는 작업은 해당 날짜가 없는 달에는 건너뜁니다.
- Mac 알림은 [알림](/ko/configuration/notifications)의 **시스템 알림 보내기**와 macOS 집중 모드도 따릅니다. 이미 해당 실행을 보고 있는 경우에는 알림이 생략됩니다.
- 실행 기록에는 작업마다 최근 100회의 실행이 보관되며, 더 오래된 실행과 그 대화는 삭제됩니다. 작업을 삭제하기 전에 중요한 내용은 복사해 두세요.

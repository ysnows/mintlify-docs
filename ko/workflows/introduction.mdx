워크플로는 정보를 읽고, 변환하고, 모델에 묻고, 에이전트에게 작업을 넘기거나, 설치된 도구를 호출하는 단계로 저장한 반복 가능한 프로세스입니다. 여러 단계로 된 같은 작업을 계속 반복하고 각 단계가 무엇을 만들어 냈는지 보고 싶을 때 사용하세요. **설정 → 워크플로 → 관리**를 열면 워크플로와 실행 기록을 둘러볼 수 있습니다.

<Tip>
워크플로가 처음이신가요? 2분 30초 분량의 영상 튜토리얼 [첫 워크플로 만들기](/ko/workflows/build-your-first-workflow)를 보고 워크플로를 처음부터 끝까지 만들고, 편집하고, 실행해 보세요.
</Tip>

## 알맞은 도구 고르기

| 하고 싶은 일 | 사용할 것 |
| --- | --- |
| 선택한 텍스트에 프롬프트 재사용하기 | [AI 명령](/ko/features/ai-commands) |
| 어시스턴트가 어떤 도구를 쓸지 결정하게 하기 | [에이전트](/ko/ai/agents) |
| 확인 가능한 출력이 있는 반복 가능한 순서 정의하기 | 워크플로 |
| 정해진 시간에 에이전트 지시, 워크플로, 스크립트 실행하기 | [예약 작업](/ko/workflows/scheduled-jobs) |

## 워크플로의 구성

워크플로는 세 부분으로 이루어집니다.

- `inputs`: 주제나 텍스트처럼 실행에 필요한 값.
- `jobs`: 이름이 붙은 단계 그룹. `needs`로 한 작업이 다른 작업을 기다리게 하지 않는 한 작업은 병렬로 시작됩니다.
- `steps`: 각 작업 안의 순서 있는 목록. 한 작업 안의 단계는 차례로 실행됩니다.

현재 워크플로는 `jobs` 맵이 있는 `version: agent-workflow/v1`을 사용하며, 각 작업에는 `steps` 목록이 있습니다.

```yaml
version: agent-workflow/v1
title: Quick Summary
description: Summarize supplied text into three bullets.
inputs:
  text:
    type: string
    default: "A sample paragraph to summarize."
jobs:
  main:
    steps:
      - id: summarize
        prompt: "Summarize in three bullets: {{ inputs.text }}"
```

<Note>
이전의 최상위 `tasks` 형식은 더 이상 허용되지 않습니다. 각 순서를 `jobs.<name>.steps`로 옮기고, 단계에 명시적인 ID를 지정하세요. 한 작업 안에서는 `steps.<id>.output`을, 작업 사이에서는 `jobs.<job>.<step>.output`을 사용하세요.
</Note>

## 단계가 할 수 있는 일

각 단계는 다음 중 정확히 하나를 수행합니다.

| 단계 | 필드 | 결과 |
| --- | --- | --- |
| 셸 | `command` 또는 `run` | `stdout`, `stderr`, `exitCode`를 포함한 명령 출력 |
| 프롬프트 | `prompt` | 모델의 응답. 구조화된 데이터에는 출력 스키마를 사용하세요 |
| 에이전트 | `agent`와 `message` | 선택한 에이전트의 응답 |
| 도구 | `tool`과 `with` | 설치된 Local API 엔드포인트의 결과 |
| 변환 | `uses: transform`과 `value` | 템플릿으로 만든 값 |
| 하위 워크플로 | `workflowId` 또는 `workflow`가 있는 `uses: workflow` | 하위 워크플로 실행 결과 |
| 승인 | `uses: approval`과 `message` | 내 답변: 승인, 또는 선택적 피드백과 함께 거절 |
| 판단 | `uses: judge`와 `question` | Enconvo Cloud의 빠른 판단 모델인 Jev가 내린 예 또는 아니요와 그 확률 |
| 분류 | `uses: classify`, `question`, `options` | Jev가 고른 옵션과 그 신뢰도 |

단계는 조건이 충족될 때만 실행하거나, 목록을 반복하거나, 재시도하거나, 구조화된 데이터를 반환할 수도 있습니다. [고급 워크플로](/ko/workflows/advanced-workflows)를 참고하세요.

## 워크플로 실행하기

- **워크플로**에서 워크플로를 열고 **입력**을 설정한 다음 **실행**을 선택하세요.
- SmartBar에서 저장된 워크플로를 검색하세요. 런처 텍스트는 `inputs.input_text`로 사용할 수 있습니다.
- 채팅에서 `@`로 사용 가능한 워크플로를 언급하면 에이전트가 사용할 수 있습니다.
- [예약 작업](/ko/workflows/scheduled-jobs)으로 일정에 맞춰 실행하세요.

## 워크플로가 저장되는 곳

각 워크플로는 `~/.enconvo/workflows/<id>.yaml`에 있는 파일 하나입니다. 파일 이름이 워크플로 ID입니다. 실행 기록과의 연결을 유지하려면 이 ID를 그대로 두세요.

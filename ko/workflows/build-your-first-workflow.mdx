워크플로는 프롬프트, 에이전트, 도구를 연결해 반복 가능한 하나의 실행으로 만듭니다. 이 튜토리얼에서는 처음부터 끝까지 하나를 만듭니다. **단계 종류 둘러보기** 템플릿으로 만들고, 단계를 직접 추가하고, 워크플로 어시스턴트가 다른 단계를 추가하게 한 다음, 실행해서 모든 단계의 출력을 읽어 봅니다.

<YouTubePlayer videoId="g02LJwso1yk" title="How to Build a Workflow in Enconvo | Step-by-Step Tutorial" />

영상 길이는 2분 24초입니다. 아래 글로 된 단계는 같은 순서를 따르며, 각 단계에 해당하는 타임스탬프가 있습니다.

## 만들게 될 것

**단계 종류 둘러보기** 템플릿은 처음부터 바로 실행됩니다. 튜토리얼이 진행되면서 작은 콘텐츠 파이프라인으로 커집니다.

| 단계 | 유형 | 하는 일 |
| --- | --- | --- |
| 오늘 날짜 가져오기 | 셸 | 오늘 날짜를 출력합니다 |
| 저장된 워크플로 나열 | 도구 | 기존 워크플로를 나열합니다(날짜와 병렬로 실행) |
| 모델에게 아이디어 묻기 | 프롬프트 | `topic` 입력에 대한 새 자동화 하나를 제안합니다 |
| 에이전트가 확장하게 하기 | 에이전트 | 아이디어를 3단계 계획으로 바꿉니다 |
| 트윗 쓰기 | 프롬프트 | 직접 추가: 계획을 인상적인 트윗 하나로 바꿉니다 |
| 트윗을 일본어로 번역 | 프롬프트 | 어시스턴트가 추가: 트윗을 번역합니다 |

## 따라 하기

<Steps>
  <Step title="워크플로 만들기 (0:07)">
    **설정 → 워크플로 → 관리**를 열고 **새 워크플로**를 선택하세요. **또는 템플릿으로 시작**에서 **단계 종류 둘러보기**를 선택합니다. 워크플로가 만들어지고 편집기가 **시각화** 모드로 열립니다. 영상은 **새 워크플로** 대화상자가 생기기 전에 녹화되어, 영상에서는 시작 템플릿 이름이 *Starter Workflow*입니다.
  </Step>
  <Step title="그래프 읽기 (0:18)">
    그래프를 위에서부터 읽으세요. **입력** 노드는 실행에 필요한 것을 선언하며, 여기서는 `topic` 하나입니다. 처음 두 단계는 서로 다른 작업에 속하므로 나란히 놓이고 병렬로 실행됩니다. 이후 각 결과는 아래 단계로 흘러가 순서대로 실행됩니다.
  </Step>
  <Step title="단계 편집하기 (0:28)">
    단계를 선택하면 인스펙터에서 열리며, ID, 제목, 프롬프트를 바꿀 수 있습니다. 이중 중괄호는 값을 단계로 가져옵니다. `{{ inputs.topic }}`은 실행 입력을, `{{ steps.idea.output }}`은 앞선 단계의 결과를 읽습니다. 이렇게 단계들이 서로 이야기합니다.
  </Step>
  <Step title="단계 추가하기 (0:37)">
    마지막 단계 아래의 **+**를 선택하고 프롬프트, 에이전트, 셸, 도구 같은 단계 유형을 고르세요. 새 프롬프트 단계에 ID `tweet`, 제목 "트윗 쓰기", 그리고 다음 프롬프트를 지정하세요.

    ```text wrap
    Turn this plan into one punchy tweet: {{ steps.plan.output }}
    ```

    <Tip>
    단계 ID의 이름을 바꾼 뒤에는 다음 필드로 넘어가기 전에 Return을 누르세요.
    </Tip>
  </Step>
  <Step title="또는 워크플로 어시스턴트에게 요청하기 (0:57)">
    직접 편집하는 대신 도구 모음에서 **어시스턴트**를 선택하고 캔버스 옆에 열리는 패널에 변경 내용을 설명하세요.

    ```text wrap
    Add a final step that translates the tweet into Japanese
    ```

    어시스턴트가 그래프를 편집하고 변경한 단계를 나열합니다. 결과가 마음에 들지 않으면 어시스턴트의 답변에서 **되돌리기**를 선택하세요. 영상에서는 프롬프트가 `{{ steps.tweet.output }}`을 읽는 `translate_ja` 단계를 추가합니다. 저장하기 전에 새 단계를 검토하세요. 어시스턴트의 편집은 **저장**을 선택하기 전까지 저장되지 않은 상태로 남습니다.
  </Step>
  <Step title="YAML 보기 (1:16)">
    도구 모음에서 **YAML**을 선택하면 같은 워크플로를 소스로 볼 수 있습니다. 각 워크플로는 `~/.enconvo/workflows/<id>.yaml`에 저장된 하나의 일반 파일이므로 읽고, 비교하고, 공유하기 쉽습니다. **시각화**를 선택하면 그래프로 돌아갑니다. 전체 파일은 아래 [완성된 워크플로](#완성된-워크플로)에 있습니다.
  </Step>
  <Step title="실행하고 출력 확인하기 (1:28)">
    **입력**을 선택하고 실행 값을 설정한 다음(영상에서는 `{"topic": "matcha"}`를 사용합니다) **실행**을 선택하세요. 실행 중인 단계는 파랗게 빛나고 끝난 단계는 초록색으로 바뀝니다. 에이전트 단계는 다른 단계보다 오래 걸립니다.

    실행이 끝나면 아무 단계나 선택하고 **출력** 탭을 열어 정확히 무엇이 만들어졌는지 확인하세요. 마지막 단계는 복사해서 붙여넣기 없이 트윗을 받아 번역했습니다.
  </Step>
  <Step title="지난 실행 찾기 (2:05)">
    모든 실행은 도구 모음의 **실행 기록**에 보관되므로 나중에 어떤 결과든 다시 볼 수 있습니다.
  </Step>
</Steps>

<Note>
워크플로를 실행하면 실제 모델과 도구가 호출됩니다. 공급자 크레딧이 사용될 수 있으며, 셸 또는 도구 단계는 Mac 계정의 권한으로 동작합니다. 실행하기 전에 워크플로의 단계를 검토하세요.
</Note>

## 완성된 워크플로

영상에서 만든 워크플로를 YAML로 적은 것입니다. **YAML** 보기에서는 형식이 조금 다를 수 있습니다.

```yaml
version: agent-workflow/v1
title: Starter Workflow
description: "Starter workflow showing parallel jobs and the four executors: command (shell), prompt (LLM), agent, and tool (Local API)."
tags:
  - demo
inputs:
  topic:
    type: string
    description: Topic to brainstorm an automation for
    default: coffee
jobs:
  date:
    steps:
      - id: today
        name: Get today's date
        command: 'date "+%Y-%m-%d"'
  catalog:
    steps:
      - id: my_workflows
        name: List saved workflows (tool)
        tool: workflow/list
        with:
          limit: 5
  ideate:
    needs: [date, catalog]
    steps:
      - id: idea
        name: Ask the model for an idea
        prompt: "Today is {{ jobs.date.today.output.stdout | trim }}. Existing workflows: {{ jobs.catalog.my_workflows.output.summaries | dump }}. Suggest ONE new automation about {{ inputs.topic }} that is not in the list, in one sentence."
      - id: plan
        name: Let the agent expand it
        agent: agent/main
        message: "Expand this automation idea into a three-step execution plan: {{ steps.idea.output }}"
      - id: tweet
        name: Write a tweet
        prompt: "Turn this plan into one punchy tweet: {{ steps.plan.output }}"
      - id: translate_ja
        name: Translate the tweet into Japanese
        prompt: "Translate this tweet into natural, fluent Japanese. Keep hashtags, emojis, and links intact. Reply with only the translated tweet: {{ steps.tweet.output }}"
```

`ideate` 작업은 `needs`로 `date`와 `catalog`를 기다리므로 `jobs.<job>.<step>.output`으로 그 결과를 읽을 수 있습니다. 한 작업 안에서는 뒤의 단계가 `steps.<id>.output`으로 앞의 단계를 읽습니다.

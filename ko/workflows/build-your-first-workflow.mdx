워크플로는 프롬프트, 에이전트, 도구를 하나의 반복 가능한 실행으로 연결합니다. 이 튜토리얼에서는 처음부터 끝까지 워크플로를 만들어 봅니다. **단계 종류 둘러보기** 템플릿으로 시작해 단계를 직접 하나 추가하고, 워크플로 어시스턴트로 또 하나를 추가한 뒤 실행하여 각 단계의 출력을 확인합니다.

<YouTubePlayer videoId="g02LJwso1yk" title="Enconvo에서 워크플로 만들기 | 단계별 튜토리얼" />

동영상 길이는 2분 24초입니다. 아래의 단계별 안내는 동영상과 같은 순서로 진행되며 각 단계의 타임스탬프를 함께 표시했습니다.

## 만들게 될 워크플로

**단계 종류 둘러보기** 템플릿은 별도 설정 없이 바로 실행할 수 있습니다. 튜토리얼을 따라가며 작은 콘텐츠 파이프라인으로 확장해 봅니다.

| 단계 | 유형 | 하는 일 |
| --- | --- | --- |
| 오늘 날짜 가져오기 | Shell | 오늘 날짜를 출력합니다 |
| 저장된 워크플로 목록 | Tool | 기존 워크플로 목록을 가져옵니다(날짜 단계와 병렬로 실행) |
| 모델에게 아이디어 요청하기 | Prompt | `topic` 입력에 관한 새 자동화 아이디어 하나를 제안합니다 |
| 에이전트에게 확장 맡기기 | Agent | 아이디어를 3단계 실행 계획으로 확장합니다 |
| 트윗 작성하기 | Prompt | 직접 추가: 계획을 임팩트 있는 트윗 하나로 바꿉니다 |
| 트윗을 일본어로 번역하기 | Prompt | 어시스턴트로 추가: 트윗을 번역합니다 |

## 따라 해 보기

<Steps>
  <Step title="워크플로 만들기 (0:07)">
    **설정 → 워크플로 → 관리**를 열고 **새 워크플로**를 선택합니다. **또는 템플릿으로 시작** 아래에서 **단계 종류 둘러보기**를 선택하면 워크플로가 생성되고 편집기가 **시각화** 모드로 열립니다. 이 동영상은 **새 워크플로** 대화 상자가 생기기 전에 촬영되어 시작 템플릿 이름이 *Starter Workflow*로 표시됩니다.
  </Step>
  <Step title="그래프 읽기 (0:18)">
    위에서 아래로 그래프를 읽습니다. **입력** 노드는 실행에 필요한 값을 선언하며, 여기서는 `topic` 하나만 받습니다. 첫 두 단계는 서로 다른 작업(job)에 속하므로 나란히 배치되어 병렬로 실행됩니다. 각 결과는 아래의 단계들로 전달되어 순서대로 실행됩니다.
  </Step>
  <Step title="단계 편집하기 (0:28)">
    단계를 선택해 검사기에서 ID, 제목, 프롬프트를 변경합니다. 이중 중괄호를 사용하면 값을 단계로 끌어올 수 있습니다. `{{ inputs.topic }}`은 실행 입력을 읽고, `{{ steps.idea.output }}`은 이전 단계의 결과를 읽습니다. 이런 식으로 단계들이 서로 데이터를 주고받습니다.
  </Step>
  <Step title="단계 추가하기 (0:37)">
    마지막 단계 아래의 **+**를 선택하고 Prompt, Agent, Shell, Tool 중 단계 유형을 고릅니다. 새 Prompt 단계에 ID는 `tweet`, 제목은 "Write a tweet", 프롬프트는 다음 내용을 넣으세요.

    ```text wrap
    Turn this plan into one punchy tweet: {{ steps.plan.output }}
    ```

    <Tip>
    단계 ID의 이름을 바꾼 뒤에는 다음 입력란으로 이동하기 전에 Return 키를 누르세요.
    </Tip>
  </Step>
  <Step title="또는 워크플로 어시스턴트에게 요청하기 (0:57)">
    직접 편집하는 대신 도구 막대에서 **어시스턴트**를 선택하고 캔버스 옆에 열리는 패널에 원하는 변경 사항을 설명합니다.

    ```text wrap
    Add a final step that translates the tweet into Japanese
    ```

    어시스턴트가 그래프를 수정하고 변경된 단계 목록을 보여 줍니다. 결과가 마음에 들지 않으면 응답의 **되돌리기**를 선택하세요. 동영상에서는 `{{ steps.tweet.output }}`을 읽는 `translate_ja` 단계를 추가합니다. 어시스턴트의 수정 내용은 **저장**을 누르기 전까지 저장되지 않으므로 저장 전에 새 단계를 검토하세요.
  </Step>
  <Step title="YAML 보기 (1:16)">
    도구 막대에서 **YAML**을 선택하면 같은 워크플로를 소스로 볼 수 있습니다. 각 워크플로는 `~/.enconvo/workflows/<id>.yaml`에 저장되는 단일 일반 텍스트 파일이므로 읽고 비교하고 공유하기 쉽습니다. 그래프로 돌아가려면 **시각화**를 선택하세요. 전체 파일은 아래 [완성된 워크플로](#완성된-워크플로)에 나와 있습니다.
  </Step>
  <Step title="실행하고 출력 확인하기 (1:28)">
    **입력**을 선택해 실행 값을 설정한 뒤(동영상에서는 `{"topic": "matcha"}` 사용) **실행**을 선택합니다. 실행 중인 단계는 파란색으로 빛나고 완료된 단계는 초록색으로 바뀝니다. Agent 단계는 다른 단계보다 시간이 더 걸립니다.

    실행이 끝나면 아무 단계나 선택하고 **출력** 탭을 열어 실제로 생성된 내용을 확인하세요. 마지막 단계가 복사·붙여넣기 없이 앞 단계의 트윗을 받아 번역한 것을 볼 수 있습니다.
  </Step>
  <Step title="이전 실행 찾기 (2:05)">
    모든 실행 기록은 도구 막대의 **실행 기록** 아래에 보관되므로 나중에 언제든 결과를 다시 확인할 수 있습니다.
  </Step>
</Steps>

<Note>
워크플로를 실행하면 실제 모델과 도구가 호출됩니다. 제공업체 크레딧이 사용될 수 있으며 Shell이나 Tool 단계는 Mac 계정의 권한으로 동작합니다. 실행하기 전에 워크플로의 단계들을 검토하세요.
</Note>

## 완성된 워크플로

동영상에서 만든 워크플로를 YAML로 옮긴 전체 코드입니다. **YAML** 보기에서는 서식이 약간 다르게 표시될 수 있습니다.

```yaml
version: agent-workflow/v1
title: Starter Workflow
description: "Starter workflow showing parallel jobs and the four executors: command (shell), prompt (LLM), agent, and tool (Local API)."
tags:
  - demo
inputs:
  topic:
    type: string
    description: Topic to brainstorm an automation for
    default: coffee
jobs:
  date:
    steps:
      - id: today
        name: Get today's date
        command: 'date "+%Y-%m-%d"'
  catalog:
    steps:
      - id: my_workflows
        name: List saved workflows (tool)
        tool: workflow/list
        with:
          limit: 5
  ideate:
    needs: [date, catalog]
    steps:
      - id: idea
        name: Ask the model for an idea
        prompt: "Today is {{ jobs.date.today.output.stdout | trim }}. Existing workflows: {{ jobs.catalog.my_workflows.output.summaries | dump }}. Suggest ONE new automation about {{ inputs.topic }} that is not in the list, in one sentence."
      - id: plan
        name: Let the agent expand it
        agent: agent/main
        message: "Expand this automation idea into a three-step execution plan: {{ steps.idea.output }}"
      - id: tweet
        name: Write a tweet
        prompt: "Turn this plan into one punchy tweet: {{ steps.plan.output }}"
      - id: translate_ja
        name: Translate the tweet into Japanese
        prompt: "Translate this tweet into natural, fluent Japanese. Keep hashtags, emojis, and links intact. Reply with only the translated tweet: {{ steps.tweet.output }}"
```

`ideate` 작업은 `needs`를 통해 `date`와 `catalog`를 기다리므로 `jobs.<job>.<step>.output`으로 두 작업의 결과를 읽을 수 있습니다. 같은 작업 안에서는 뒤쪽 단계가 앞쪽 단계의 결과를 `steps.<id>.output`으로 읽습니다.

변수는 SmartBar에 입력한 텍스트, 다른 앱에서 선택한 텍스트, 오늘 날짜처럼 매번 달라지는 값을 채워 줍니다. 템플릿을 지원하는 프롬프트와 환경설정에서 사용하면 AI 명령, 에이전트 지침, 워크플로 하나로 지금 눈앞에 있는 어떤 내용에도 작업할 수 있습니다. **설정 → 변수**를 열면 사용할 수 있는 변수를 확인할 수 있습니다.

## 사용할 수 있는 변수

| 변수 | 제공되는 값 |
| --- | --- |
| Input Text | 현재 SmartBar 입력 |
| Selection Text | 현재 앱에서 선택한 텍스트 |
| Latest Clipboard | 가장 최근 클립보드 내용 |
| Active Application | 맨 앞에 있는 앱의 정보 |
| Active Application Screenshot | 맨 앞 창의 이미지 |
| Active Screen Screenshot | 활성 화면의 이미지 |
| Focused Window Content | 포커스된 창에서 추출한 내용 |
| Browser Active Tab | 활성 탭의 URL과 사용 가능한 페이지 내용 |
| Current Folder | Finder에서 열려 있는 폴더 |
| Selected Files | Finder에서 선택한 파일 |
| History Messages | 현재 대화 기록 |
| Now | 현재 날짜와 시간 |
| Your Language | 사용자가 읽는 언어: **응답 언어**, 자동일 때는 시스템 언어 |
| Opened Applications | 실행 중인 앱의 정보 |
| Opened Application Names | 실행 중인 앱의 이름 |

## 변수 사용하기

1. 사용자 지정하려는 AI 명령, 에이전트 지침 또는 워크플로 필드를 엽니다.
2. 필드가 변수를 지원하는지 확인합니다. 선택기가 있으면 선택기를 사용하세요.
3. 필요한 값을 삽입하고 문제가 없는 샘플 내용으로 테스트합니다.
4. 입력이 비어 있거나 권한이 없을 때 결과가 달라지는지 확인합니다.

텍스트 프롬프트에서는 다음과 같이 지원되는 템플릿 이름을 사용할 수 있습니다.

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

사용할 수 있는 변수는 명령과 컨텍스트에 따라 다르며, 모든 텍스트 필드가 템플릿을 처리하는 것은 아닙니다. 스크린샷과 앱 내용에는 macOS 권한이 필요할 수 있고, 해당 종류의 입력을 받을 수 있는 모델이 필요합니다.

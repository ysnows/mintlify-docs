---
title: "플러그인"
description: "Enconvo에 새 명령, 도구, 연결을 추가하는 플러그인을 찾고 설치하며 관리하세요."
---

플러그인은 Enconvo에 명령, 제공업체, 도구 및 API 라우트를 추가합니다. **설정 → 플러그인**을 열어 카탈로그를 검색하고 필요한 플러그인을 설치하며 이미 설치한 플러그인을 관리할 수 있습니다.

## 플러그인 찾기 및 설치하기

<Steps>
  <Step title="플러그인 열기">
    **설정 → 플러그인**을 엽니다. **⌘K**를 누르면 검색 상자로 바로 이동합니다.
  </Step>
  <Step title="검색하기">
    작업 내용이나 플러그인 이름으로 검색합니다. 현재 탭에 일치하는 항목이 없으면 다른 탭의 결과를 안내합니다.
  </Step>
  <Step title="페이지 열기">
    플러그인을 클릭해 설명, 포함된 기능, 필요한 설정을 확인합니다.
  </Step>
  <Step title="설치 및 설정하기">
    아직 설치되지 않았다면 **설치**를 클릭합니다. 그런 다음 필요한 제공업체 인증 정보나 명령 설정을 추가합니다.
  </Step>
  <Step title="사용하기">
    **지금 사용해 보기**를 클릭하거나 SmartBar에서 명령을 실행하거나, 사용할 에이전트에서 해당 도구를 활성화하세요.
  </Step>
</Steps>

플러그인 페이지에는 포함된 명령과 설정이 나열됩니다. Enconvo의 다른 곳에서 명령 설정을 열면 해당 플러그인 안의 명령으로 이동합니다.

[이메일](/ko/integrations/email)처럼 채팅 창 안에 전용 보기가 있는 플러그인은 페이지에 **열기** 버튼이 있어, 사서함 추가 같은 내부 작업을 클릭 한 번으로 바로 열 수 있습니다. 보기가 여러 개인 플러그인에는 **열기** 메뉴가 표시됩니다.

## 플러그인 페이지 구성

| 탭 | 표시 내용 |
| --- | --- |
| **Enconvo** | 카테고리별 카탈로그입니다. 상단의 **설치됨**에는 연결한 커넥터와 설치하거나 직접 만든 플러그인이 나열됩니다. **최근 추가**에는 새 항목이 표시됩니다. |
| **기본 제공** | Enconvo에 기본 포함된 플러그인입니다. **검색**에는 SmartBar에서 검색하는 목록이 있고, **제어**에는 Computer Use와 Browser Use가 있습니다. |
| **Mac 앱** | 캘린더, Mail, 메모 등 에이전트가 사용할 수 있는 이 Mac의 앱입니다. 연결할 때는 계정이 아니라 macOS 권한을 요청합니다. [Apple 앱](/ko/integrations/apple-ecosystem)을 참고하세요. |
| **PopBar** | [PopBar](/ko/features/popbar)에 버튼을 추가하는 PopClip 호환 확장 프로그램입니다. |
| **개인** | 직접 만들었거나 가져온 플러그인과 Enconvo 스토어에 게시한 플러그인입니다. |

카탈로그 외부에서 플러그인을 가져오려면 **플러그인 만들기** 또는 **추가** 메뉴를 사용하세요.

| 옵션 | 역할 |
| --- | --- |
| **플러그인 만들기** | 필요한 기능을 설명하면 에이전트가 플러그인을 작성하고 테스트한 뒤 설치합니다. |
| **플러그인 압축 파일 업로드…** | `.enconvo` 파일이나 Claude Code 또는 Codex 플러그인 `.zip`을 설치합니다. |
| **GitHub에서 추가…** | 플러그인 저장소나 Claude Code 또는 Codex 마켓플레이스에서 설치합니다. |
| **MCP 서버 추가…** | [MCP 서버](/ko/features/mcp)를 엽니다. |
| **PopBar 확장 프로그램 추가…** 및 **PopClip에서 가져오기…** | PopBar에 PopClip 확장 프로그램을 추가합니다. |
| **새 스킬…** | [스킬](/ko/configuration/skills)을 엽니다. |

## 작업에 맞는 기능 찾기

| 작업 | 가이드 |
| --- | --- |
| 텍스트 다듬기 또는 번역 | [글쓰기 도구](/ko/features/writing-tools), [번역](/ko/ai/translate) |
| 웹 검색 및 읽기 | [웹 검색](/ko/ai/web-search), [웹 페이지 읽기](/ko/ai/web-fetch) |
| 파일 작업 또는 터미널 사용 | [파일 도구](/ko/ai/file-tools), [코드 러너](/ko/ai/code-runner) |
| 이미지, 동영상 또는 음성 생성 | [제공업체 카탈로그](/ko/providers/catalog) |
| Mail, 캘린더, 메모 또는 미리 알림 작업 | [Apple 앱](/ko/integrations/apple-ecosystem) |
| 외부 도구 연결 | [MCP 서버](/ko/features/mcp) |
| 재사용 가능한 에이전트 지침 추가 | [스킬](/ko/configuration/skills) |

스토어의 일부 플러그인은 서비스 전체의 도구와 가이드를 함께 제공합니다.

- **Shopify**는 에이전트가 Shopify 공식 CLI로 Shopify 스토어를 관리할 수 있게 하며, 변경 사항을 적용하기 전에 각 변경 내용을 보여 줍니다. 여러 스토어에서도 작동합니다. 스토어를 지정하지 않으면 에이전트가 어느 스토어인지 묻고, 표시하는 모든 변경 사항에 스토어 이름을 적으며, 여러 스토어에 적용할 변경은 스토어별로 한 번씩 실행합니다.
- **Expo**는 기존의 읽기 전용 Expo 커넥터 대신 Expo 팀의 공식 스킬과 Expo MCP 서버를 제공합니다. 에이전트가 Expo 및 React Native 앱을 빌드·업그레이드·출시하고, EAS 빌드·로그·크래시·리뷰를 읽으며, 사용자가 각 항목을 승인한 후에만 빌드와 제출을 시작합니다. 이미 로그인한 Expo 계정은 그대로 이어집니다.

**Obsidian**, **Tailscale**, **Cloudflare**도 플러그인 스토어 플러그인입니다. 플러그인 페이지에서 설치할 수 있습니다. 이미 사용 중이던 사본도 계속 작동하며 자동으로 업데이트됩니다. 에이전트는 Obsidian, Tailscale, Cloudflare, Shopify 플러그인 중 어떤 것이 설치되어 있는지 처음부터 파악하고 있습니다.

[기본 제공 명령 카탈로그](/ko/extensions/built-in-extensions)에는 문서화된 명령 제품군이 정리되어 있습니다. 스토어 항목과 사용 중인 빌드에 설치된 플러그인은 이와 다를 수 있습니다.

## 명령, 제공업체 및 도구

- **명령**은 사용자가 직접 실행하는 작업입니다.
- **제공업체**는 모델이나 음성 같은 기능을 공급합니다.
- **도구**는 에이전트가 호출할 수 있는 작업입니다.

플러그인을 설치한다고 해서 해당 제공업체가 자동으로 기본값으로 설정되거나 모든 에이전트에서 모든 도구가 켜지는 것은 아닙니다.

SmartBar에서는 명령 선택기(기본값 `@`)를 사용하거나 명령 제목으로 검색하세요. `/` 작업 메뉴는 다른 용도이며 플러그인 이름의 접두사가 아닙니다.

## 커넥터에서 여러 계정 사용하기

Notion, Webflow, Linear처럼 Mac에서 로그인하는 커넥터는 여러 계정을 보관할 수 있습니다.

- 커넥터 페이지에서 **다른 계정 연결**을 선택해 계정을 추가합니다. **연결된 계정**에 모든 계정이 나열됩니다.
- 에이전트가 전송하거나 생성할 때 사용할 계정에 **기본으로 설정**을 선택합니다. 읽기는 연결된 모든 계정에서 가능합니다.
- 요청할 때 "업무용 주소로 보내 줘"처럼 계정을 지정하면 에이전트가 해당 계정을 사용합니다.
- **연결 해제**는 계정 하나를 제거하고, **모든 계정 연결 해제**는 모두 제거합니다.

클라이언트의 워크스페이스 안에서는 각 커넥터가 자체 기본 계정을 유지하며, **다음에서 기본값** 뒤에 워크스페이스 이름이 함께 표시됩니다. 해당 공간에서는 다른 계정을 지정하지 않는 한 그 클라이언트의 계정을 사용합니다.

## 끄기, 업데이트 또는 제거

플러그인 페이지에서 다음 작업을 할 수 있습니다.

- 스위치는 플러그인을 켜거나 끕니다. 꺼 두면 에이전트가 플러그인을 찾거나 사용할 수 없고, SmartBar에도 나타나지 않으며 `@`로 호출할 수 없습니다. 설정은 그대로 유지됩니다.
- **⋯** 메뉴에는 **설정**, **업데이트 확인**, **제거**가 있습니다. Enconvo에 기본 포함된 플러그인은 제거할 수 없습니다.

플러그인을 제거하기 전에 해당 플러그인을 사용하는 에이전트, 워크플로 및 사용자 지정 명령을 확인하세요. 명령을 재설정하면 설정이 기본값으로 돌아갑니다. 공유 제공업체를 재설정하면 다른 기능에서 사용하는 인증 정보도 변경될 수 있습니다. [인증 정보](/ko/configuration/credentials)를 참고하세요.

## 플러그인 공유하기

직접 만든 플러그인이나 폴더가 이 Mac에 있는 플러그인은 링크를 받은 사람 누구나 설치할 수 있도록 공유할 수 있습니다.

1. 플러그인 페이지에서 **공유…**를 클릭합니다. 요청이 나타나면 Enconvo 계정에 로그인합니다.
2. **설치할 수 있는 사람** 아래에서 **링크가 있는 모든 사용자** 또는 **플러그인 스토어**를 선택합니다.
3. **게시**를 클릭한 다음 **링크 복사**를 눌러 링크를 보냅니다.

Enconvo는 링크로 설치하기 전에 각 버전을 검사하고 검토하며, 링크는 enconvo.com의 플러그인 페이지를 엽니다. 설치하는 사람 각자에게 별도의 사본이 생성되며, 데이터, 키 및 로그인 정보는 사용자의 Mac에만 남습니다.

공유한 플러그인을 변경하려면 **공유…**를 다시 클릭해 새 버전을 보내거나, **설치할 수 있는 사람**을 바꾸거나, **공유 중지**를 클릭하세요. 링크는 더 이상 작동하지 않지만 이미 설치한 사람의 사본은 유지됩니다. 검토에서 버전이 거절되면 **공유…**에 사유가 표시되고 **채팅에서 수정**이 제공됩니다. [스페이스](/ko/features/spaces)를 공유하려면 [스페이스 공유하기](/ko/features/spaces)를 참고하세요.

## 직접 만들기

[확장 프로그램 개발](/ko/extensions/developing)의 TypeScript SDK와 CLI를 사용하세요. CLI는 빌드, 설치, 스키마 생성 및 게시를 `enconvo plugin` 아래에 묶어 제공합니다. 게시하면 개인 개발 환경 밖에서도 플러그인을 사용할 수 있습니다.

Enconvo는 Codex, Claude Code 및 포터블 플러그인도 설치할 수 있습니다. [플러그인 형식](/extensions/plugin-formats) 및 [플러그인 설치](/ko/extensions/installing-plugins)를 참고하세요.

---
title: "플러그인"
description: "Enconvo에 새로운 명령어, 도구, 연결을 더해 주는 플러그인을 찾고, 설치하고, 관리합니다."
---

플러그인은 Enconvo에 명령어, 공급자, 도구, API 경로를 추가합니다. **설정 → 플러그인**을 열어 카탈로그를 검색하고, 필요한 것을 설치하고, 이미 가진 플러그인을 관리하세요.

## 플러그인 찾아 설치하기

<Steps>
  <Step title="플러그인 열기">
    **설정 → 플러그인**을 엽니다. **⌘K**를 누르면 검색창으로 바로 이동합니다.
  </Step>
  <Step title="검색">
    작업 내용이나 플러그인 이름으로 검색하세요. 현재 탭에 일치하는 항목이 없으면 다른 탭의 결과를 보여 줍니다.
  </Step>
  <Step title="플러그인 페이지 열기">
    플러그인을 클릭하면 설명, 포함된 항목, 필요한 항목을 읽을 수 있습니다.
  </Step>
  <Step title="설치하고 설정하기">
    아직 설치하지 않았다면 **설치**를 클릭합니다. 그런 다음 플러그인이 요구하는 공급자 자격 증명이나 명령어 설정을 추가하세요.
  </Step>
  <Step title="사용하기">
    **지금 사용해 보기**를 클릭하거나, SmartBar에서 플러그인의 명령어를 실행하거나, 이 플러그인을 사용할 에이전트에 도구를 활성화하세요.
  </Step>
</Steps>

플러그인 페이지에는 명령어와 각 설정이 나열되어 있습니다. Enconvo의 다른 곳에서 명령어 설정을 열면 해당 플러그인 안의 그 명령어로 이동합니다.

[이메일](/ko/integrations/email)처럼 플러그인에 채팅 창의 뷰가 있으면, 플러그인 페이지에 해당 뷰를 여는 **열기** 버튼이 있어 사서함 추가처럼 그 안에 있는 기능을 클릭 한 번으로 사용할 수 있습니다. 뷰가 여러 개인 플러그인에는 **열기** 메뉴가 표시됩니다.

## 플러그인 페이지

| 탭 | 표시되는 내용 |
| --- | --- |
| **Enconvo** | 카테고리별 카탈로그입니다. 맨 위의 **설치됨**에는 연결한 커넥터와 설치했거나 만든 플러그인이 나열됩니다. **새로 추가됨**에는 새 항목이 표시됩니다. |
| **기본 제공** | Enconvo에 포함된 플러그인입니다. **검색**에는 SmartBar에서 검색하는 목록이, **제어**에는 컴퓨터 사용과 브라우저 사용이 있습니다. |
| **Mac 앱** | 에이전트가 사용할 수 있는 이 Mac의 앱으로, 캘린더, 메일, 메모 등이 있습니다. 앱을 연결할 때는 계정이 아니라 macOS의 권한을 요청합니다. [Apple 앱](/ko/integrations/apple-ecosystem)을 참고하세요. |
| **PopBar** | [PopBar](/ko/features/popbar)에 버튼을 추가하는 PopClip 호환 확장 프로그램입니다. |
| **개인** | 직접 만들었거나 가져온 플러그인, 그리고 Enconvo 스토어에 게시한 플러그인입니다. |

카탈로그 밖의 플러그인을 가져오려면 **플러그인 만들기** 또는 **추가** 메뉴를 사용하세요.

| 옵션 | 기능 |
| --- | --- |
| **플러그인 만들기** | 필요한 내용을 설명하면 에이전트가 플러그인을 작성하고, 테스트하고, 설치합니다. |
| **플러그인 압축 파일 업로드…** | `.enconvo` 파일 또는 Claude Code나 Codex 플러그인 `.zip`을 설치합니다. |
| **GitHub에서 추가…** | 플러그인 저장소 또는 Claude Code나 Codex 마켓플레이스에서 설치합니다. |
| **MCP 서버 추가…** | [MCP 서버](/ko/features/mcp)를 엽니다. |
| **PopBar 확장 프로그램 추가…** 및 **PopClip에서 가져오기…** | PopBar에 PopClip 확장 프로그램을 추가합니다. |
| **새 스킬…** | [스킬](/ko/configuration/skills)을 엽니다. |

| 작업 | 가이드 |

| 웹 검색 및 읽기 | [웹 검색](/ko/ai/web-search), [웹 페이지 읽기](/ko/ai/web-fetch) |
| 파일이나 터미널 작업 | [파일 도구](/ko/ai/file-tools), [코드 실행기](/ko/ai/code-runner) |
| 이미지, 영상, 음성 생성 | [공급자 카탈로그](/ko/providers/catalog) |
| 메일, 캘린더, 메모, 미리 알림 작업 | [Apple 앱](/ko/integrations/apple-ecosystem) |

스토어에 있는 일부 플러그인은 서비스 하나의 도구와 안내를 통째로 제공합니다.

- **Shopify**를 사용하면 에이전트가 Shopify 공식 CLI로 Shopify 스토어를 관리하며, 변경 사항을 적용하기 전에 매번 보여 줍니다. 여러 스토어에서 작동합니다. 스토어를 지정하지 않으면 에이전트가 어느 스토어인지 묻고, 보여 주는 모든 변경 사항에 스토어 이름을 밝히며, 여러 스토어를 대상으로 한 변경은 스토어마다 한 번씩 실행합니다.
- **Expo**는 예전의 읽기 전용 Expo 커넥터를 대신해 Expo 팀의 공식 스킬과 Expo MCP Server를 제공합니다. 에이전트가 Expo와 React Native 앱을 빌드하고, 업그레이드하고, 배포하며, EAS 빌드, 로그, 충돌, 리뷰를 읽고, 빌드와 제출은 매번 사용자가 승인한 뒤에만 시작합니다. 이미 만들어 둔 Expo 로그인은 그대로 이어집니다.

**Obsidian**, **Tailscale**, **Cloudflare**도 플러그인 스토어 플러그인이므로 플러그인 페이지에서 설치하세요. 이미 가지고 있던 사본은 계속 작동하며 스스로 업데이트됩니다. 에이전트는 Obsidian, Tailscale, Cloudflare, Shopify 플러그인 중 어느 것이 설치되어 있는지 처음부터 알고 있습니다.

[기본 제공 명령어 카탈로그](/ko/extensions/built-in-extensions)에는 문서화된 명령어 계열이 나열되어 있습니다. 사용 중인 빌드의 스토어 항목과 설치된 플러그인은 이와 다를 수 있습니다.

## 명령어, 공급자, 도구

- **명령어**는 실행하는 동작입니다.
- **공급자**는 모델이나 음성 같은 기능을 제공합니다.
- **도구**는 에이전트가 호출할 수 있는 동작입니다.

플러그인을 설치한다고 해서 항상 그 공급자가 기본값이 되거나 모든 에이전트에 모든 도구가 켜지는 것은 아닙니다.

SmartBar에서는 명령어 선택기(기본값은 `@`)를 사용하거나 명령어의 제목을 검색하세요. `/` 동작 메뉴는 다른 용도이며, 플러그인 이름 앞에 붙이는 접두사가 아닙니다.

## 커넥터에서 여러 계정 사용하기

Notion, Webflow, Linear처럼 Mac에서 로그인하는 커넥터는 계정을 두 개 이상 가질 수 있습니다.

- 커넥터 페이지에서 **다른 계정 연결**을 선택해 계정을 추가합니다. **연결된 계정**에 모든 계정이 나열됩니다.
- 에이전트가 보내거나 만들 때 사용할 계정에서 **기본으로 설정**을 선택하세요. 에이전트는 모든 계정에서 읽습니다.
- "회사 주소로 보내 줘"처럼 요청에서 계정을 지정하면 에이전트가 해당 계정을 사용합니다.
- **연결 해제**는 계정 하나를, **모든 계정 연결 해제**는 모든 계정을 제거합니다.

클라이언트의 워크스페이스에서는 각 커넥터가 자체 기본 계정을 유지하며, **기본 사용 위치**와 워크스페이스 이름이 표시됩니다. 다른 계정을 지정하지 않으면 에이전트는 그곳에서 해당 클라이언트의 계정을 사용합니다.

## 끄기, 업데이트, 제거

플러그인 페이지에서는 다음을 할 수 있습니다.

- 스위치로 플러그인을 켜거나 끕니다. 꺼져 있는 동안에는 에이전트가 플러그인을 찾거나 사용할 수 없고, SmartBar에도 표시되지 않으며 `@`로 지정할 수도 없습니다. 설정은 유지됩니다.
- **⋯** 메뉴에는 **설정**, **업데이트 확인**, **제거**가 있습니다. Enconvo에 포함된 플러그인은 제거할 수 없습니다.

플러그인을 제거하기 전에 해당 플러그인을 사용하는 에이전트, 워크플로, 사용자 지정 명령어를 확인하세요. 명령어를 초기화하면 설정이 복원됩니다. 공유 공급자를 초기화하면 다른 기능이 사용하는 자격 증명도 바뀔 수 있습니다. [자격 증명](/ko/configuration/credentials)을 참고하세요.

## 플러그인 공유하기

직접 만든 플러그인이나 폴더가 이 Mac에 있는 플러그인을 링크로 공유할 수 있으며, 링크를 받은 누구나 설치할 수 있습니다.

1. 플러그인 페이지에서 **공유…**를 클릭합니다. Enconvo가 요청하면 Enconvo 계정에 로그인하세요.
2. **설치할 수 있는 사람**에서 **링크가 있는 모든 사용자** 또는 **플러그인 스토어**를 선택합니다.
3. **게시**를 클릭한 다음 **링크 복사**를 눌러 링크를 보냅니다.

Enconvo는 링크로 설치되기 전에 각 버전을 확인하고 검토하며, 링크는 enconvo.com의 플러그인 페이지로 연결됩니다. 설치한 사람은 각자 자신의 사본을 받으며, 플러그인의 데이터, 사용자의 키, 로그인 정보는 사용자의 Mac에만 남습니다.

공유한 플러그인을 변경하려면 **공유…**를 다시 클릭하세요. 새 버전을 보내거나, **설치할 수 있는 사람**을 바꾸거나, **공유 중지**를 클릭할 수 있습니다. 그러면 링크가 작동하지 않게 되지만, 이미 플러그인을 설치한 사람은 사본을 계속 사용합니다. 검토에서 버전이 거부되면 **공유…**에 이유가 표시되고 **채팅에서 수정**이 제공됩니다. [스페이스](/ko/features/spaces)를 공유하려면 [스페이스 공유하기](/ko/features/spaces)를 참고하세요.

## 직접 만들기

[확장 프로그램 개발](/ko/extensions/developing)에 있는 TypeScript SDK와 CLI를 사용하세요. CLI는 빌드, 설치, 스키마 생성, 게시를 `enconvo plugin` 아래에 모아 둡니다. 게시하면 자신의 개발 환경 밖에서도 플러그인을 사용할 수 있습니다.

Enconvo는 Codex, Claude Code, 이식 가능한 플러그인도 설치합니다. [플러그인 형식](/extensions/plugin-formats)과 [플러그인 설치하기](/ko/extensions/installing-plugins)를 참고하세요.

Enconvo는 앱과 앱이 호출하는 AI를 별개로 다룹니다. 라이선스는 앱을 활성화합니다. AI는 Enconvo Cloud 포인트, 직접 발급한 API 키, 로그인해서 쓰는 제공업체 요금제, Mac의 모델 중에서 가져올 수 있으며, 각각 별도의 곳에서 비용이 청구됩니다. 지금 계정에서 이용할 수 있는 요금제와 가격은 **설정 → 계정**과 Enconvo 웹사이트에서 확인하세요.

## AI 비용을 지불하는 방법

| 이용 방식 | 포함 범위 | 사용량 확인 위치 |
| --- | --- | --- |
| Enconvo 평생 라이선스 | 앱 기능 이용 | **설정 → 계정**의 **평생 라이선스** |
| Enconvo Cloud 요금제 | 포인트로 결제하는 Cloud 모델과 서비스 | **설정 → 포인트 사용량** |
| 직접 발급한 API 키 | 해당 제공업체로 가는 요청 | 제공업체의 API 계정 |
| 로그인해서 쓰는 제공업체 요금제 | 요금제가 지원하는 기능과 한도 | 설정의 제공업체 페이지 |
| 로컬 모델 | Mac의 연산 능력, 메모리, 저장 공간과 모델 다운로드 | 사용자의 Mac |

앱 라이선스를 구매해도 어떤 제공업체의 유료 API 크레딧도 추가되지 않습니다. 제공업체의 채팅 요금제에 그 제공업체의 모든 API가 포함되는 것도 아닙니다.

## Enconvo 요금제

- **평생 라이선스**: 앱을 한 번 구매하는 방식이며 Standard와 Premium 등급이 있고 보너스 포인트가 포함됩니다. 직접 발급한 API 키로 AI를 마음껏 사용할 수 있습니다. Teams는 조직을 위한 평생 라이선스입니다. 시트를 구매하고 이메일로 각 시트를 배정합니다. [Teams](/ko/configuration/account)를 참고하세요.
- **Enconvo Cloud**: Plus, Pro, Max 등급의 월간 또는 연간 요금제입니다. 매월 포인트가 추가되며 API 키 없이 사용할 수 있는 Cloud 모델이 제공됩니다.
- **Standard 체험**: 무료 계정은 카드 없이 1회 한정 7일 Standard 체험을 받을 수 있습니다. 제공되는 경우 **설정 → 계정**에 **체험 시작**이 나타납니다.
- **코드**: 라이선스 코드와 체험 코드는 **설정 → 코드 사용**에서 활성화합니다. Teams License 코드를 사용하면 해당 코드의 시트에 대해 내 계정이 Team 관리자가 되며, 시트당 50,000 Cloud 포인트가 제공됩니다.

평생 라이선스는 항상 Standard와 Premium으로 부르므로 Plus, Pro Cloud 요금제와 이름이 겹치지 않습니다.

현재 요금제와 가격은 다음에서 확인하세요.

- [Enconvo 웹사이트](https://www.enconvo.com)
- [Enconvo Cloud Plan](https://www.enconvo.com/cloud-plan)
- [Cloud 모델 가격](https://www.enconvo.com/cloud-pricing)

## Cloud 포인트 사용 방식

구독 포인트가 먼저 사용됩니다. 구독 포인트는 갱신될 때마다 요금제의 포인트 양으로 초기화됩니다. 충전 팩과 평생 라이선스로 받은 충전 포인트는 만료되지 않습니다.

요청 비용은 기능이 실제로 사용하는 모델과 접근 방식에 따라 달라집니다. 텍스트, 이미지, 비디오, 음성 인식, 임베딩, 실시간 음성은 각각 가격이 다를 수 있습니다.

## 예상치 못한 사용량 확인

1. Enconvo Cloud는 **설정 → 포인트 사용량**을, 직접 발급한 API 키는 제공업체의 사용량 페이지를 엽니다.
2. **설정 → 사용량 통계**를 열어 모델, 제공업체, 기능별 예상 비용, 토큰, 요청 수를 확인합니다.
3. 같은 제공업체 프로필을 공유하는 예약 작업, 장시간 실행 작업, 검색, 생성 요청이 있는지 살펴봅니다.

Enconvo는 앱과 호출하는 AI를 따로 둡니다. 라이선스는 앱을 엽니다. AI는 Enconvo Cloud 포인트, 본인 API 키, 로그인한 제공업체 요금제, 또는 Mac의 모델에서 올 수 있고, 각각 자기 곳에서 청구됩니다. 지금 계정에서 받을 수 있는 요금제와 가격은 **설정 → 계정**과 Enconvo 웹사이트를 확인하세요.

## AI 비용을 내는 방법

| 접근 | 포함하는 것 | 사용량이 보이는 곳 |
| --- | --- | --- |
| Enconvo 평생 라이선스 | 앱 기능 접근 | **설정 → 계정**의 **평생 라이선스** |
| Enconvo Cloud 요금제 | 포인트로 내는 클라우드 모델과 서비스 | **설정 → 포인트 사용량** |
| 본인 API 키 | 해당 제공업체 요청 | 제공업체 자체의 API 계정 |
| 로그인한 제공업체 요금제 | 요금제가 지원하는 기능과 한도 | 설정의 해당 제공업체 페이지 |
| 로컬 모델 | Mac의 연산, 메모리, 저장 공간에서 실행하며, 모델 다운로드도 포함 | 사용자의 Mac |

앱 라이선스를 사도 어떤 제공업체의 유료 API 크레딧이 추가되지는 않습니다. 제공업체의 채팅 요금제가 그 제공업체의 모든 API를 포함하는 것도 아닙니다.

## Enconvo 요금제

- **평생 라이선스**: 앱을 한 번 구매합니다. Standard와 Premium 등급이 있고 보너스 포인트가 있습니다. 본인 API 키로 AI를 원하는 만큼 쓸 수 있습니다. Teams는 조직용 평생 라이선스입니다. Seats를 사고 각 자리를 이메일로 지정합니다. [Teams](/ko/configuration/account)를 보세요.
- **Enconvo Cloud**: Plus, Pro, Max 등급의 월간 또는 연간 요금제입니다. 매달 포인트와 API 키가 필요 없는 Cloud 모델이 추가됩니다.
- **Standard 체험**: 무료 계정은 카드 없이 한 번의 7일 Standard 체험을 받을 수 있습니다. 제공되면 **설정 → 계정**에 **체험 시작**이 나타납니다.
- **코드**: 라이선스 코드와 체험 코드는 **설정 → 코드 사용**에서 활성화합니다. Teams 라이선스 코드는 계정을 그 코드의 Seats에 대한 Team 관리자로 만들고, Seat마다 Cloud 포인트 50,000을 줍니다.

평생 라이선스는 항상 Standard와 Premium이라고 부르므로, Plus와 Pro Cloud 요금제와 이름을 공유하지 않습니다.

현재 요금제와 가격:

- [Enconvo 웹사이트](https://www.enconvo.com)
- [Enconvo Cloud 요금제](https://www.enconvo.com/cloud-plan)
- [Cloud 모델 가격](https://www.enconvo.com/cloud-pricing)

## Cloud 포인트가 쓰이는 방식

구독 포인트가 먼저 쓰입니다. 갱신할 때마다 요금제 양으로 초기화됩니다. 충전 팩과 평생 라이선스에서 온 충전 포인트는 만료되지 않습니다.

요청 비용은 모델과 기능이 실제로 쓰는 접근 방식에 따라 다릅니다. 텍스트, 이미지, 동영상, 음성 텍스트 변환, 임베딩, 실시간 음성은 각각 가격이 다를 수 있습니다.

## 예상 밖 사용량 확인

1. Enconvo Cloud는 **설정 → 포인트 사용량**을, 본인 API 키는 제공업체 자체의 사용량 페이지를 여세요.
2. **설정 → 사용 통계**에서 모델, 제공업체, 기능별 예상 비용, 토큰, 요청을 보세요.
3. 같은 제공업체 프로필을 공유하는 예약 작업, 오래 실행되는 작업, 검색, 생성 요청을 찾아보세요.

Enconvo의 창과 음성 기능은 각각 단축키로 열립니다. **설정 → 단축키**에는 Enconvo가 사용하는 모든 단축키와 실행되는 명령이 나열되므로 단축키를 바꾸거나 키 조합이 무엇을 하는지 확인할 수 있습니다. Mac에 저장된 단축키는 이 안내의 기본값보다 항상 우선합니다.

이 영상은 단축키를 다룬 다음 Enconvo를 Mac에 맞추는 다른 설정인 컨텍스트 인식, Appshots, 로컬 모델, 권한, 잠자기 방지를 소개합니다.

## 기본 단축키

| 동작 | 기본값 |
| --- | --- |
| SmartBar 표시 | **⌥Space** |
| 채팅 창 표시 | **⌃⌘X** |
| 앱 사이드바 표시 | **⌃⌘E** |
| 설정 열기 (Enconvo 안에서) | **⌘,** |
| 받아쓰기 시작 | **오른쪽 ⌘** |
| 음성 명령 시작 | **오른쪽 ⌥** |
| 오디오 일시정지/재개 | **⌥P** |

이 기본값은 직접 키를 지정한 적이 없을 때만 적용되며, 직접 지정한 키는 그대로 유지됩니다. 빠른 캡처와 Appshots에는 기본 단축키가 없으므로 사용하기 전에 해당 설정 페이지에서 지정하세요.

## 단축키 변경

1. **설정 → 단축키**를 엽니다. **핵심** 탭에는 주요 기능이, **기타 단축키**에는 AI 명령, 플러그인, 설정, 다른 페이지에 나오지 않는 명령이, **전체**에는 둘 다 표시됩니다.
2. **이름으로 필터…**에 입력해서 명령을 찾습니다. 키 조합에 해당하는 명령을 찾으려면 **단축키로 찾기**를 클릭하고 그 키를 누르세요.
3. 명령의 단축키 필드를 클릭하고 새 조합을 누릅니다.
4. 그 키가 이미 다른 명령을 실행하면 필드에 알려 줍니다. **여기서 사용**을 선택해 키를 이 명령으로 옮기거나, 제안하는 사용 가능한 단축키 중 하나를 고르세요.
5. 다른 앱으로 전환해서 단축키를 시험해 보세요.

단축키의 키를 비우려면 명령에서 단축키를 제거하세요. **실행 취소**가 있는 메시지로 되돌릴 수 있습니다.

**로컬** 배지는 SmartBar 고정처럼 Enconvo 안에서만 작동하는 단축키를 나타냅니다.

## 누르는 방식

오른쪽 ⌘처럼 보조 키 하나만 기록하면 필드에 **누르는 방식**이 표시됩니다.

| 옵션 | 명령이 실행되는 때 |
| --- | --- |
| **길게 누르기 또는 한 번 누르기** | 키를 길게 누르거나, 한 번 눌러서 전환할 때 |
| **한 번 누르기** | 키를 한 번 눌러 시작하고 다시 눌러 중지할 때 |
| **길게 누르기** | 키를 누르고 있는 동안에만 작동할 때 |
| **두 번 누르기** | 키를 빠르게 두 번 누를 때 |

보조 키를 두 개 이상 동시에 누르면 하나의 단축키로 취급됩니다. 각 필드에는 그 명령이 지원하는 종류만 표시되며, 옆의 설명에 해당 기능이 어떻게 반응하는지 나와 있습니다.

## 각 기능의 단축키 위치

단축키 페이지 외에도 각 기능의 단축키는 해당 설정 페이지에 있습니다.

| 기능 | 설정 페이지 |
| --- | --- |
| SmartBar | **설정 → SmartBar** |
| Dynamic Island | **설정 → Dynamic Island** |
| PopBar | **설정 → PopBar** |
| 앱 사이드바 | **설정 → 앱 사이드바** |
| 받아쓰기 | **설정 → 받아쓰기** |
| 음성 명령 | **설정 → 음성 명령** |
| Appshots | **설정 → Appshots** |
| 화면 낙서 | **설정 → 화면 낙서** |
| 음성 메모 | **설정 → 음성 메모** |
| 빠른 캡처 | **설정 → 빠른 캡처** |
| 개별 명령 | **단축키** 필드가 있는 경우 해당 명령의 설정 |

## SmartBar 안에서

SmartBar에 트리거 문자를 입력하면 한 종류의 항목을 검색할 수 있습니다.

| 문자 | 여는 항목 |
| --- | --- |
| **@** | 명령 |
| **#** | 메시지에 추가할 컨텍스트 |
| **$** | 스킬 |
| **>** | 최근 작업 |

이 문자는 **설정 → SmartBar**의 **검색**에서 바꿀 수 있습니다. 슬래시 메뉴에는 모델과 추론 선택 같은 동작이 있습니다.

키보드로 목록을 이동하려면 **설정 → SmartBar**에서 **탐색 키**를 선택하세요. **macOS**는 **⌃N** **⌃P** **⌃F** **⌃B**를, **Vim**은 **⌃J** **⌃K** **⌃L** **⌃H**를 사용합니다.

## Enconvo를 Mac에 맞추기

같은 설정 창에 영상에서 안내하는 다른 선택 항목도 있습니다.

| 설정 페이지 | 기능 |
| --- | --- |
| **컨텍스트 인식** | SmartBar가 직전에 사용한 앱에서 가져올 대상을 선택합니다. 선택한 텍스트, Finder 선택 항목, 브라우저의 페이지가 해당됩니다. **자동 추가**는 SmartBar가 열리자마자 추가하고, **제안**은 한 번 클릭으로 추가하도록 제안합니다. [컨텍스트 인식](/ko/features/context-awareness)을 참고하세요. |
| **Appshots** | 단축키로 현재 앞에 있는 창을 대화에 추가합니다. [Appshots](/ko/features/appshots)를 참고하세요. |
| **로컬 모델** | 이 Mac에서 실행 중인 AI, 사용하는 메모리와 디스크, 각 기능이 실행되는 위치를 보여 줍니다. [로컬 모델](/ko/ai/local-llm)을 참고하세요. |
| **권한** | macOS가 Enconvo에 허용하는 것과 그 이유를 나열하며, 빠진 권한은 **권한 허용**으로 해결합니다. [macOS 권한](/ko/configuration/permissions)을 참고하세요. |
| **잠자기 방지** | 자리를 비운 동안 이 Mac이 잠들지 않게 하여 iPhone에서도 계속 접근할 수 있게 합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키가 Enconvo 안에서만 작동합니다 | **로컬** 배지가 있는지 확인하세요. 없다면 [macOS 권한](/ko/configuration/permissions)에서 입력 모니터링과 손쉬운 사용을 확인하고, 다른 앱이 같은 키를 사용하는지 확인하세요. |
| 단축키를 누르면 다른 동작이 실행됩니다 | **단축키로 찾기**를 사용하세요. 그 키를 사용하는 Enconvo 명령이 없다면 다른 앱이나 macOS가 사용 중입니다. |
| 보조 키 단축키가 작동하지 않습니다 | 단축키를 열어 **누르는 방식**을 확인하세요. 길게 누르기, 한 번 누르기, 두 번 누르기, 동시에 누르기가 있습니다. |
| 영상이나 다른 Mac의 단축키가 작동하지 않습니다 | 단축키가 다를 수 있습니다. **설정 → 단축키**에서 현재 단축키를 확인하세요. |

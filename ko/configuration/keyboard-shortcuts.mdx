Enconvo의 각 창과 음성 기능은 단축키로 바로 열 수 있습니다. **설정 → 단축키**에서는 Enconvo가 사용하는 모든 단축키와 연결된 명령을 확인하고, 조합을 바꾸거나 특정 키 조합이 무슨 명령을 실행하는지 조회할 수 있습니다. Mac에 저장된 단축키는 항상 이 가이드의 기본값보다 우선합니다.

이 영상에서는 단축키를 비롯해 Enconvo를 Mac에 맞게 맞추는 컨텍스트 인식, Appshots, 로컬 모델, 권한, 잠자기 방지 설정을 다룹니다.

## 기본 단축키

| 동작 | 기본값 |
| --- | --- |
| SmartBar 열기 | **⌥Space** |
| 채팅 창 열기 | **⌃⌘X** |
| 앱 사이드바 열기 | **⌃⌘E** |
| Enconvo 안에서 설정 열기 | **⌘,** |
| 받아쓰기 시작 | **Right ⌘** |
| 음성 명령 시작 | **Right ⌥** |
| 오디오 일시 중지/재개 | **⌥P** |

이 기본값은 사용자가 직접 키를 지정하지 않았을 때만 적용되며, 직접 설정한 키는 그대로 유지됩니다. 빠른 캡처와 Appshots는 기본 단축키가 없으므로 사용하기 전에 각 설정 페이지에서 지정하세요.

## 단축키 변경하기

1. **설정 → 단축키**를 엽니다. **핵심** 탭에는 주요 기능이, **기타 단축키**에는 AI 명령·플러그인·설정 및 다른 페이지에 나오지 않는 명령이, **전체**에는 둘 모두가 표시됩니다.
2. **이름으로 필터…**에 입력해 명령을 찾습니다. 특정 키 조합에 연결된 명령을 찾으려면 **단축키로 찾기**를 클릭하고 해당 키를 누르세요.
3. 명령의 단축키 입력 칸을 클릭하고 새 키 조합을 누릅니다.
4. 그 키를 이미 다른 명령이 쓰고 있다면 안내가 표시됩니다. **여기서 사용**을 선택해 이 명령으로 옮기거나, 추천되는 빈 단축키 중 하나를 고르세요.
5. 다른 앱으로 전환해 단축키가 잘 작동하는지 시험해 봅니다.

단축키 할당을 비우려면 해당 명령에서 키를 제거하세요. 이어서 뜨는 알림의 **실행 취소**로 되돌릴 수 있습니다.

**로컬** 배지가 붙은 단축키는 SmartBar 고정처럼 Enconvo 안에서만 작동합니다.

## 누르는 방식 정하기

오른쪽 ⌘처럼 보조 키 하나만 단독으로 기록하면 **누르는 방식**을 묻습니다.

| 옵션 | 명령이 실행되는 조건 |
| --- | --- |
| **길게 누르기 또는 한 번 누르기** | 키를 길게 누르거나, 한 번 눌러 켜고 끕니다 |
| **한 번 누르기** | 키를 한 번 눌러 시작하고, 다시 한 번 눌러 멈춥니다 |
| **길게 누르기** | 키를 누르고 있는 동안에만 작동합니다 |
| **두 번 누르기** | 키를 빠르게 두 번 누릅니다 |

보조 키 두 개 이상을 동시에 누르면 하나의 단축키 조합으로 인식됩니다. 각 입력 칸에는 해당 명령이 지원하는 방식만 표시되며, 옆의 설명에 기능이 어떻게 반응하는지 적혀 있습니다.

## 각 기능의 단축키 위치

단축키 페이지 외에도 각 기능의 단축키는 해당 설정 페이지에 들어 있습니다.

| 기능 | 설정 페이지 |
| --- | --- |
| SmartBar | **설정 → SmartBar** |
| Dynamic Island | **설정 → Dynamic Island** |
| PopBar | **설정 → PopBar** |
| 앱 사이드바 | **설정 → 앱 사이드바** |
| 받아쓰기 | **설정 → 받아쓰기** |
| 음성 명령 | **설정 → 음성 명령** |
| Appshots | **설정 → Appshots** |
| 화면 낙서 | **설정 → 화면 낙서** |
| 음성 메모 | **설정 → 음성 메모** |
| 빠른 캡처 | **설정 → 빠른 캡처** |
| 개별 명령 | **단축키** 필드가 있는 해당 명령의 설정 |

## SmartBar 안에서 사용하기

SmartBar에서 트리거 문자를 입력하면 특정 종류의 항목만 검색할 수 있습니다.

| 문자 | 열리는 항목 |
| --- | --- |
| **@** | 명령 |
| **#** | 메시지에 추가할 컨텍스트 |
| **$** | 스킬 |
| **>** | 최근 작업 |

이 문자들은 **설정 → SmartBar**의 **검색** 아래에서 변경할 수 있습니다. 슬래시 메뉴에는 모델 및 추론 선택 같은 동작이 들어 있습니다.

키보드로 목록을 이동하려면 **설정 → SmartBar**에서 **탐색 키**를 고르세요. **macOS**는 **⌃N** **⌃P** **⌃F** **⌃B**를, **Vim**은 **⌃J** **⌃K** **⌃L** **⌃H**를 사용합니다.

## Mac 환경에 맞추기

같은 설정 창에서 영상이 안내하는 다른 옵션도 조절할 수 있습니다.

| 설정 페이지 | 설명 |
| --- | --- |
| **컨텍스트 인식** | SmartBar가 직전에 있던 앱에서 가져올 항목(선택한 텍스트, Finder 선택 항목, 브라우저 페이지)을 정합니다. **첨부**는 SmartBar가 열리자마자 바로 추가하고, **제안**은 클릭 한 번으로 넣을 수 있게 띄워 줍니다. [컨텍스트 인식](/ko/features/context-awareness)을 참고하세요. |
| **Appshots** | 단축키로 현재 앞에 있는 창을 대화에 바로 추가합니다. [Appshots](/ko/features/appshots)를 참고하세요. |
| **로컬 모델** | 이 Mac에서 실행 중인 AI, 사용 중인 메모리와 디스크, 각 기능이 실행되는 위치를 보여 줍니다. [로컬 모델](/ko/ai/local-llm)을 참고하세요. |
| **권한** | macOS가 Enconvo에 허용한 권한과 이유를 보여 줍니다. **권한 허용**으로 빠진 권한을 채울 수 있습니다. [macOS 권한](/ko/configuration/permissions)을 참고하세요. |
| **잠자기 방지** | 자리를 비운 동안 Mac이 잠자기 상태로 들어가지 않도록 막아 iPhone에서도 계속 연결할 수 있게 합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 단축키가 Enconvo 안에서만 작동함 | **로컬** 배지가 붙어 있는지 확인하세요. 아니라면 [macOS 권한](/ko/configuration/permissions)에서 입력 모니터링과 손쉬운 사용 권한이 켜져 있는지, 다른 앱이 같은 키를 쓰고 있지 않은지 확인하세요. |
| 단축키를 누르면 다른 동작이 실행됨 | **단축키로 찾기**를 사용해 보세요. Enconvo 명령 중 쓰는 것이 없다면 다른 앱이나 macOS가 그 키를 사용하고 있는 것입니다. |
| 보조 키 단축키가 작동하지 않음 | 해당 단축키를 열어 **누르는 방식**이 길게 누르기, 한 번 누르기, 두 번 누르기, 동시 누름 중 무엇으로 되어 있는지 확인하세요. |
| 영상이나 다른 Mac에서 본 단축키가 안 됨 | 내 Mac의 단축키 설정이 다를 수 있습니다. **설정 → 단축키**에서 현재 설정을 확인하세요. |

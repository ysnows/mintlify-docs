Enconvo 계정은 요금제, Cloud 포인트, 이를 사용하는 Mac 목록을 보관합니다. 로그인은 **설정 → 계정**에서 진행합니다. 설정 사이드바에서 그 아래에 있는 페이지들은 팀, 동기화, 포인트 사용량, 사용량 통계, 친구 초대, 코드 사용을 다룹니다. 작업 공간은 **설정 → 작업 공간**에 있습니다.

이 동영상에서는 계정, 팀, 작업 공간, 동기화를 순서대로 안내합니다.

<YouTubePlayer videoId="FnddgYQfcTc" title="How to Use Teams and Workspaces in Enconvo | Step-by-Step Tutorial" />

<Note>
Enconvo 계정, 제공업체 API 키, 제공업체 구독 로그인은 각각 별개의 연결입니다. 내 API 키로 보낸 요청은 해당 제공업체 계정의 결제와 한도를 따릅니다. 구독 로그인은 Enconvo Cloud 포인트와 별개로 해당 제공업체의 설정 페이지에 자체 사용량이 표시됩니다([자격 증명](/ko/configuration/credentials) 참고).
</Note>

## 로그인

1. **설정 → 계정**을 엽니다.
2. **로그인**을 클릭하거나 계정을 만들려면 **회원가입**을 클릭합니다.
3. 브라우저에서 로그인을 완료합니다. 브라우저에 이미 로그인되어 있다면 웹사이트에서 사용할 계정을 선택하도록 요청합니다. 그 뒤 Enconvo로 다시 돌아옵니다.
4. **프로필**에 로그인된 이름과 이메일이 표시됩니다.

로그인이 완료되는 동안 채팅 창 사이드바의 카드가 계정을 불러올 때까지 상태를 따라갑니다. 네트워크가 느리면 이를 알리고, 계정이 로드되지 않으면 **다시 시도**를 제공합니다. 로그인이 실패하거나 취소했다면 **로그인**을 다시 클릭하세요.

로그아웃하려면 페이지 하단의 **로그아웃**을 클릭하세요.

### 프로필 사진 변경

프로필 사진은 친구, 팀원, 회의 참가자에게 표시됩니다. Google로 로그인했다면 다른 사진을 고르기 전까지 Google 사진이 표시됩니다.

1. **설정 → 계정**에서 사진 옆의 **사진 변경**을 클릭하거나, 사진이 없다면 **사진 추가**를 클릭합니다.
2. **사진 업로드…**를 선택하고 이미지를 고릅니다.
3. 사진을 드래그해 원 안에 맞추고 슬라이더로 확대한 뒤 **저장**을 클릭합니다.

같은 메뉴에서 **Google 사진 사용**을 누르면 Google 사진으로 돌아가고, **사진 제거**를 누르면 대신 이니셜이 표시됩니다.

### 이메일 또는 비밀번호 추가

**설정 → 계정**의 **로그인** 섹션에는 계정의 로그인 방식이 표시됩니다. Apple로 가입하며 '나의 이메일 가리기'를 사용했다면 이메일이 Apple에 의해 가려진 것으로 표시됩니다.

1. **이메일 추가**를 클릭하고 본인 이메일을 입력한 뒤, 해당 이메일로 전송된 코드를 입력합니다. 이후 해당 이메일로 로그인할 수 있습니다.
2. **비밀번호 설정**을 클릭하면 enconvo.com과 Enconvo Feedback에서 이메일과 비밀번호로 로그인할 수 있습니다. 이미 비밀번호가 있다면 버튼 이름이 **비밀번호 재설정**으로 표시되며 기존 비밀번호는 묻지 않습니다.

같은 섹션이 iPhone 및 Android 앱에도 있습니다.

## 요금제 및 포인트 확인

**설정 → 계정**에는 계정이 보유한 내역이 표시됩니다.

| 섹션 | 표시 내용 |
| --- | --- |
| **포인트** | **총 잔액**이 표시됩니다. **사용량 보기**는 포인트 사용량을 열고, **충전**은 포인트를 추가 구매합니다. |
| **평생 라이선스** | 라이선스 등급(**Standard** 또는 **Premium**), 구매 시점, 업데이트 및 지원 기간, 등록된 기기를 보여 줍니다. 라이선스가 없으면 **평생 라이선스 받기**로 옵션을 볼 수 있고, 무료 Standard 체험이 제공될 때는 **체험 시작**이 표시됩니다. |
| **팀** | 팀 관리자인 경우 보유 시트와 **팀 관리**가 표시됩니다. |
| **Enconvo Cloud** | Cloud 등급, 결제 주기, 다음 결제일, 포인트 초기화 시점, 등록된 기기를 보여 줍니다. **Cloud 요금제 받기** 또는 **업그레이드**로 변경하고, **요금 보기**로 모델 및 서비스 요금을 확인할 수 있습니다. |

하단의 **결제 관리**를 누르면 브라우저에서 결제 세부 정보가 열립니다. 평생 라이선스 구매가 아직 환불 가능한 기간이라면 **환불 요청**도 그곳에 나타납니다. 환불하면 계정은 무료 요금제로 돌아가고 보너스 포인트도 회수됩니다.

### 기기

각 요금제는 정해진 수의 Mac을 지원하며, **기기** 섹션에서 현재 사용 중인 대수를 확인할 수 있습니다. 한도에 도달하면 **기기 한도 도달**이 표시되며 이 Mac에서는 명령을 실행할 수 없습니다. **기기 관리**를 클릭해 더 이상 쓰지 않는 Mac을 제거한 뒤 이 Mac을 활성화하거나, 더 많은 기기를 지원하는 요금제를 선택하세요.

## 팀

팀 기능을 사용하면 시트를 구매해 이메일로 각 사용자에게 배정할 수 있습니다. 각 구성원은 자기 계정으로 로그인하며, 팀원에게 Cloud 포인트를 나눠 줄 수 있습니다. 설정 사이드바에서 **팀**은 팀 관리자에게만 보입니다.

1. **설정 → 팀**을 엽니다. 상단에 **배정된 시트**, **남은 시트**, **충전 포인트**가 표시됩니다.
2. **시트 배정** 아래에 상대방이 Enconvo 로그인에 사용하는 이메일을 입력하고 **배정**을 클릭합니다.
3. 상대방이 Enconvo에 처음 로그인하기 전까지 시트는 **대기 중**으로 표시되다가 로그인하면 **활성**으로 바뀝니다.

상대방의 계정은 Mac 1대에서 Premium 기능과 평생 업데이트를 받게 되며, 채팅, 메모리, 지식 베이스는 비공개로 유지됩니다. 관리자에게는 시트 상태와 포인트 합계만 보입니다.

각 구성원의 **시트 작업** 메뉴에는 다음 항목이 있습니다.

| 작업 | 기능 |
| --- | --- |
| **포인트 전송** | 관리자의 충전 포인트 잔액에서 해당 구성원에게 포인트를 옮깁니다. 이 포인트는 만료되지 않습니다. |
| **포인트 회수** | 구성원이 아직 쓰지 않은 포인트를 관리자의 충전 잔액으로 되돌립니다. |
| **시트 배정 해제** | 해당 계정을 즉시 무료 요금제로 되돌립니다. 계정 데이터는 유지되며 전송된 포인트는 관리자에게 돌아옵니다. 본인 시트의 경우 메뉴 이름이 **내 시트 반납**입니다. |

시트 하나는 Mac 1대 기준입니다. 행에서 **+**를 클릭하면 관리자 본인을 포함해 해당 계정이 더 많은 Mac에서 로그인할 수 있도록 허용합니다. **시트 추가**로 시트를 더 구매할 수 있습니다.

**팀 지식 베이스**에는 팀 전체와 공유된 지식 베이스 목록이 표시됩니다. 지식 베이스를 공유하려면 해당 지식 베이스의 **⋯** 메뉴를 열고 팀 접근을 켜세요. 구성원이 직접 팀과 공유하기 전까지 각자의 지식 베이스는 비공개로 유지됩니다.

## 작업 공간

작업 공간은 클라이언트나 특정 업무를 개인 작업과 분리해 관리합니다. 각 작업 공간은 자체 채팅, 메모리, 지식, 로그인 정보, 설정을 가지며, 한 작업 공간의 내용이 다른 공간에 나타나지 않습니다. 작업 공간에서 바꾸지 않은 설정은 개인 공간인 **개인**의 설정을 따릅니다.

아래 동영상에서는 클라이언트용 작업 공간을 만들고, 개인으로 돌아가고, 설정에서 작업 공간을 관리하는 과정을 보여 줍니다.

<YouTubePlayer videoId="fMHIhDRufXA" title="Workspaces in Enconvo" />

### 작업 공간 만들기

1. 채팅 창 사이드바 상단에서 **개인**이 표시된 작업 공간 메뉴를 클릭하고 **새 작업 공간…**을 선택합니다. **설정 → 작업 공간**에서 **새 작업 공간…**을 클릭해도 됩니다.
2. 처음 사용할 때는 **작업 공간이란?** 안내가 나타나 **업무 분리**, **사이드바 상단에서 전환**, **개인 설정에서 시작**의 세 가지를 설명합니다. **계속**을 클릭하세요.
3. 작업할 클라이언트 이름 등 **작업 공간 이름**을 입력하고 **만들기**를 클릭합니다.

새 작업 공간에서 채팅 창이 열립니다. 채팅, 메모리, 지식은 빈 상태로 시작하며 **개인**의 내용은 전혀 보이지 않습니다.

### 작업 공간 전환

채팅 창 사이드바 상단의 작업 공간 메뉴를 클릭해 작업 공간을 고르세요. 또는 **⌃⌘1**부터 **⌃⌘9**까지 누를 수도 있습니다. 숫자는 목록의 순서를 뜻하므로 **⌃⌘1**은 **개인**입니다.

창마다 하나의 작업 공간에서 작동하며, 여러 작업 공간의 작업을 동시에 실행할 수 있습니다.

### 분리되는 항목

각 작업 공간은 자체 채팅, 메모리, 지식, 로그인 정보, 설정을 따로 가집니다. 코딩 에이전트 채팅은 시작한 작업 공간 안에 머물며, 새 [스페이스](/ko/features/spaces)도 작업 공간마다 별도의 데이터를 보관합니다. 새 작업 공간은 그 안에서 설정을 바꾸기 전까지 **개인** 설정을 그대로 사용합니다.

작업 공간별로 커넥터 계정을 따로 두려면 해당 작업 공간으로 전환한 뒤 플러그인 페이지에서 커넥터를 열고, 계정의 **⋯** 메뉴에서 **기본값으로 지정**을 선택하세요. 해당 계정에 **다음에서 기본값**과 작업 공간 이름이 표시되며, 요청 시 다른 계정을 명시하지 않는 한 에이전트는 그 계정을 사용합니다.

팀 관리자라면 **팀** 페이지에서 각 구성원을 하나 이상의 작업 공간에 배정할 수 있습니다. 그러면 구성원은 같은 작업 공간을 공유하는 팀원만 보고, 채팅하고, 전화를 걸 수 있습니다.

### 작업 공간 이름 바꾸기 또는 삭제

**설정 → 작업 공간**을 여세요. **개인**은 항상 맨 위에 있으며 모든 작업 공간의 기본 설정 기준이므로 이름을 바꾸거나 삭제할 수 없습니다.

다른 작업 공간의 행에는 **이름 바꾸기**와 **삭제**가 있습니다. 작업 공간을 삭제하면 그 안의 채팅, 메모리, 지식, 설정도 함께 삭제됩니다. 삭제된 작업 공간은 7일간 **최근 삭제된 항목**에 머무르며, **복원**으로 되살릴 수 있습니다.

에이전트에게 작업 공간 목록 조회, 생성, 이름 바꾸기, 색상 변경, 순서 변경, 삭제, 복원을 요청할 수도 있습니다. 삭제하기 전에는 확인을 받습니다.

## Mac 간 동기화

동기화는 같은 계정으로 로그인된 모든 컴퓨터에서 채팅, 설정, 스킬, 플러그인, 지식 베이스, 아티팩트를 동일하게 유지합니다. Enconvo Cloud 요금제와 평생 라이선스에 포함되어 있습니다.

1. 각 컴퓨터에서 같은 Enconvo 계정으로 로그인합니다.
2. **설정 → 동기화**를 열고 **컴퓨터 간 동기화**를 켭니다.
3. Enconvo가 동기화 데이터를 저장할 위치를 물으면 **Enconvo 계정** 또는 **iCloud**를 선택합니다. 나중에 **저장 공간** 아래에서 바꿀 수 있습니다.
4. **동기화 항목** 아래에서 포함할 항목을 고릅니다.

| 항목 | 동기화되는 내용 | 이 컴퓨터에만 남는 내용 |
| --- | --- | --- |
| **채팅** | 이미지와 파일을 포함한 채팅 기록, 제목, 프로젝트, 보관된 채팅 | |
| **설정** | 모델, 프롬프트, 플러그인 환경설정, 스니펫, 직접 만든 AI 명령·에이전트·워크플로 | 로그인 정보, 단축키, 폴더 경로 |
| **스킬** | 설치하거나 직접 만든 스킬과 각 스킬의 활성화 여부. GitHub에서 설치한 스킬은 출처도 유지되어 다른 컴퓨터에서도 업데이트를 확인함 | 플러그인에 포함되어 온 스킬은 해당 플러그인을 따름 |
| **플러그인** | Enconvo 스토어, GitHub, npm 또는 링크에서 설치한 플러그인: 다른 컴퓨터에서도 설치되며 한쪽에서 제거하면 함께 제거됨 | 내장 플러그인, 개발 중인 플러그인, 커넥터, 로그인 정보 |
| **지식 베이스** | 메모, 텍스트, 웹 페이지를 포함한 지식 베이스 및 메모리 | 가져온 파일과 녹음 |
| **아티팩트** | 페이지, 문서, 디자인, 슬라이드, 대시보드, 이미지, 동영상을 포함한 모든 버전의 [아티팩트](/ko/features/artifacts). 두 Mac이 동시에 수정하면 두 버전 모두 보관됨 | 32MB를 초과하는 파일, 공유된 문서 및 디자인 |
| **API 키** | 내장 제공업체의 API 키(이 컴퓨터를 떠나기 전에 암호화됨) | 로그인 정보 및 사용자 지정 제공업체 |

비밀번호와 로그인 정보는 컴퓨터 밖으로 나가지 않습니다. 저장 공간으로 Enconvo 계정을 쓰는 경우, 새 컴퓨터가 API 키를 받으려면 다른 컴퓨터 중 한 대가 허용해야 합니다. 양쪽 화면에 같은 코드가 표시되는지 확인한 뒤 **허용**을 클릭하세요. 근처에 다른 컴퓨터가 없을 때는 **백업 암호 문구**로 API 키를 복구할 수 있습니다. iCloud를 사용하면 같은 iCloud에 로그인된 Mac끼리 자동으로 키를 주고받습니다.

**지금 동기화**를 누르면 즉시 동기화되며, **내 컴퓨터**에는 동기화 중인 모든 컴퓨터가 나열됩니다. **동기화된 데이터 지우기**를 누르면 계정이나 iCloud에 동기화된 모든 데이터가 모든 컴퓨터에서 삭제됩니다. 각 컴퓨터에 이미 저장된 데이터는 남으며, 이 컴퓨터에서는 동기화가 꺼지고 다른 컴퓨터에서는 다시 켤 때까지 일시 중지됩니다.

## 포인트 사용량 및 사용량 통계

**설정 → 포인트 사용량**에서 Enconvo Cloud 포인트를 확인할 수 있습니다.

- **총 잔액**: 지금 쓸 수 있는 전체 포인트입니다. 구독 포인트가 먼저 사용됩니다.
- **구독 잔액**: 월간 또는 연간 제공량으로, 매 갱신 시 요금제 수량으로 초기화됩니다.
- **충전 잔액**: 충전 팩이나 평생 라이선스에서 받은 포인트입니다. 만료되지 않습니다.
- 모델별 일일 사용량 차트와 각 차감 내역의 **기록**을 볼 수 있습니다.

**기록**에서는 **기록 유형**과 **모델**로 필터링하고 **날짜로 이동**으로 특정 날짜를 골라 하루에 사용한 포인트를 확인할 수 있습니다.

**설정 → 사용량 통계**에서는 개인 API 키를 포함해 Enconvo가 호출한 모든 AI 제공업체의 비용, 토큰, 요청 수를 보여 줍니다. **비용**, **토큰**, **요청** 사이를 전환하고 **24시간**, **7일**, **30일**, **90일**을 선택한 뒤 모델, 제공업체, 기능별로 세부 수치를 나눌 수 있습니다. 비용은 제공업체의 API 공시 가격 기준 추정치입니다.

## 친구 초대

**설정 → 친구 초대**에서 초대 링크와 코드를 받을 수 있습니다. **링크 복사** 또는 **코드 복사**로 공유하세요.

초대 코드는 임시 이메일이나 에이전트용 이메일 주소에서는 사용할 수 없습니다. 친구가 내 초대로 가입한 뒤 Enconvo에서 처음 쓰는 기기의 Enconvo 앱에 로그인하면 두 사람 모두 포인트를 받습니다. 초대할 수 있는 친구 수에는 제한이 없으며, 웹에서만 로그인하는 경우는 인정되지 않습니다. **내 초대**에서 누가 가입했고 얼마나 적립되었는지 확인할 수 있습니다.

친구의 초대를 받았다면 **초대 코드가 있나요?** 아래에 코드를 입력하고 **사용**을 클릭하세요.

## 코드 사용

1. **설정 → 코드 사용**을 엽니다.
2. 코드나 코드가 담긴 링크를 붙여넣고 **계속**을 클릭합니다.

라이선스 코드와 카드 없는 체험 코드는 계정에 즉시 적용됩니다. 팀 라이선스 코드를 입력하면 내 계정이 해당 시트들의 팀 관리자가 되며 시트당 50,000 Cloud 포인트가 지급됩니다([팀](#팀) 참고). 카드 등록이 필요한 체험은 브라우저에서 결제 화면을 열어 확인 전에 갱신 조건을 보여 줍니다.

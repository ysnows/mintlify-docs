Enconvo 계정에는 플랜, Cloud 포인트, 이를 사용하는 Mac이 담겨 있습니다. **설정 → 계정**에서 로그인합니다. 설정 사이드바에서 그 아래에 있는 페이지는 팀, 동기화, 포인트 사용량, 사용량 통계, 제휴 프로그램, 코드 사용을 다룹니다. 작업 공간은 **설정 → 작업 공간**에 있습니다.

이 동영상은 계정, 팀, 작업 공간, 동기화를 이 순서대로 안내합니다.

<YouTubePlayer videoId="FnddgYQfcTc" title="How to Use Teams and Workspaces in Enconvo | Step-by-Step Tutorial" />

<Note>
Enconvo 계정, 제공업체 API 키, 제공업체 구독 로그인은 서로 별개의 연결입니다. 내 API 키로 보낸 요청은 제공업체 계정의 청구와 한도를 따릅니다. 구독 로그인은 Enconvo Cloud 포인트와 별도로 제공업체의 설정 페이지에 자체 사용량을 표시합니다. [자격 증명](/ko/configuration/credentials)을 참고하세요.
</Note>

## 로그인

1. **설정 → 계정**을 여세요.
2. **로그인**을 클릭하거나, 계정을 만들려면 **회원가입**을 클릭하세요.
3. 브라우저에서 로그인을 마치세요. 브라우저가 이미 로그인되어 있으면 웹사이트가 어떤 계정을 사용할지 묻습니다. 그다음 Enconvo로 돌아옵니다.
4. **프로필**에 로그인한 이름과 이메일이 표시됩니다.

로그인이 끝나는 동안 채팅 창 사이드바의 카드가 계정이 로드될 때까지 따라갑니다. 네트워크가 느리면 알려 주고, 계정이 로드되지 않으면 **재시도**를 제공합니다. 로그인에 실패하거나 취소했다면 **로그인**을 다시 클릭하세요.

로그아웃하려면 페이지 아래쪽의 **로그아웃**을 클릭하세요.

### 프로필 사진 변경

프로필 사진은 친구, 팀원, 회의 참가자에게 표시됩니다. Google로 로그인했다면 다른 사진을 고르기 전까지 Google 사진이 표시됩니다.

1. **설정 → 계정**에서 사진 옆의 **사진 변경**을 클릭하세요. 사진이 없으면 **사진 추가**를 클릭하세요.
2. **사진 업로드…**를 고르고 사진을 선택하세요.
3. 사진을 드래그해 원 안에 맞추고, 슬라이더로 확대한 다음 **저장**을 클릭하세요.

같은 메뉴에 Google 사진으로 돌아가는 **Google 사진 사용**과, 대신 이니셜을 표시하는 **사진 삭제**가 있습니다.

### 이메일 또는 비밀번호 추가

**설정 → 계정**의 **로그인** 섹션에는 계정이 로그인하는 방식이 표시됩니다. Apple로 가입하고 이메일 가리기를 사용했다면 이메일이 Apple에 의해 숨겨진 것으로 표시됩니다.

1. **이메일 추가**를 클릭하고, 내 이메일을 입력한 다음 그곳으로 전송된 코드를 입력하세요. 이후 그 이메일로 로그인할 수 있습니다.
2. **비밀번호 설정**을 클릭하면 enconvo.com과 Enconvo Feedback에서 이메일과 비밀번호로 로그인할 수 있습니다. 이미 비밀번호가 있다면 버튼이 **비밀번호 재설정**이며, 이전 비밀번호를 묻지 않습니다.

같은 섹션이 iPhone 및 Android 앱에도 있습니다.

## 플랜과 포인트 확인

**설정 → 계정**에는 계정이 가진 것이 표시됩니다.

| 섹션 | 표시되는 내용 |
| --- | --- |
| **포인트** | **총잔액**. **사용량 보기**는 포인트 사용량을 열고, **충전**은 포인트를 더 구매합니다. |
| **평생 라이선스** | 라이선스 등급(**표준** 또는 **프리미엄**), 구매 시점, 업데이트와 지원이 지속되는 기간, 내 기기. 라이선스가 없으면 **평생 이용권 구매**가 선택지를 보여 주고, 무료 표준 체험이 제공될 때는 **체험 시작**이 나타납니다. |
| **팀** | 팀 관리자인 경우 내 좌석과 **팀 관리**. |
| **Enconvo Cloud** | Cloud 등급, 결제 주기, 다음 결제일, 포인트가 초기화되는 시점, 내 기기. **Cloud 요금제 가입** 또는 **업그레이드**로 변경하고, **가격 보기**는 모델과 서비스 요금을 엽니다. |

아래쪽의 **결제 관리**는 브라우저에서 결제 정보를 엽니다. 평생 이용권 구매를 아직 환불할 수 있는 동안에는 여기에 **환불 요청**도 나타납니다. 환불하면 계정이 무료 플랜으로 돌아가고 보너스 포인트가 취소됩니다.

### 기기

각 플랜은 정해진 수의 Mac을 지원하며, **기기**에는 사용 중인 수가 표시됩니다. 한도에 도달하면 페이지에 **기기 수 제한에 도달했습니다**가 표시되고 이 Mac은 명령을 실행할 수 없습니다. **기기 관리**를 클릭하고, 더 이상 사용하지 않는 Mac을 제거한 다음 이 Mac을 활성화하거나, 기기가 더 많은 플랜을 고르세요.

## 팀

팀을 사용하면 좌석을 구매해 각 좌석을 이메일로 사람에게 할당할 수 있습니다. 모든 사람이 자기 계정으로 로그인하며, Cloud 포인트를 공유할 수 있습니다. 팀 관리자에게만 설정 사이드바에 **팀**이 표시됩니다.

1. **설정 → 팀**을 여세요. 위쪽에 **할당된 좌석**, **남은 좌석**, **충전 포인트**가 표시됩니다.
2. **좌석 할당**에서 그 사람이 Enconvo에 로그인하는 이메일을 입력하고 **할당**을 클릭하세요.
3. 좌석은 그 사람이 처음 Enconvo에 로그인할 때까지 **대기 중**으로 표시되다가 이후 **활성**이 됩니다.

그 사람의 계정은 Mac 한 대에서 프리미엄 기능과 평생 업데이트를 받으며, 채팅, 메모리, 지식 베이스는 비공개로 유지됩니다. 사용자는 좌석과 포인트 합계만 볼 수 있습니다.

각 구성원의 **좌석 작업** 메뉴에는 다음이 있습니다.

| 작업 | 기능 |
| --- | --- |
| **포인트 이전** | 내 충전 잔액에서 그 사람의 잔액으로 포인트를 옮깁니다. 만료되지 않습니다. |
| **포인트 회수** | 그 사람이 쓰지 않은 포인트를 내 충전 잔액으로 되돌립니다. |
| **좌석 할당 해제** | 그 사람의 계정을 즉시 무료로 되돌립니다. 데이터는 유지되고 이전된 포인트는 나에게 돌아옵니다. 내 좌석의 경우 **내 좌석 반납**입니다. |

각 좌석은 Mac 한 대입니다. 행의 **+**를 클릭하면 그 계정(내 계정 포함)이 더 많은 Mac에 로그인할 수 있습니다. **사용자 좌석 추가**로 더 구매합니다.

**팀 지식 베이스**에는 팀의 모든 사람과 공유된 지식 베이스가 나열됩니다. 공유하려면 지식 베이스의 **⋯** 메뉴를 열고 팀 접근을 켜세요. 구성원의 지식 베이스는 그 구성원이 팀과 공유하기 전까지 비공개로 유지됩니다.

## 작업 공간

작업 공간은 고객이나 업무를 위한 작업을 내 개인 작업과 분리해 둡니다. 각 작업 공간에는 고유한 채팅, 메모리, 지식, 로그인, 설정이 있으며, 한 작업 공간의 내용이 다른 곳에 나타나지 않습니다. 작업 공간이 바꾸지 않은 설정은 내 개인 작업인 **개인**을 따릅니다.

아래 동영상은 고객을 위한 작업 공간을 만들고, 개인으로 돌아가고, 설정에서 작업 공간을 관리합니다.

<YouTubePlayer videoId="fMHIhDRufXA" title="Workspaces in Enconvo" />

### 작업 공간 만들기

1. 채팅 창 사이드바 위쪽에서 **개인**이 표시된 작업 공간 메뉴를 클릭하고 **새 작업 공간…**을 고르세요. **설정 → 작업 공간**에서 **새 작업 공간…**을 클릭해도 됩니다.
2. 처음에는 짧은 안내인 **작업 공간이란?**이 세 가지를 설명합니다. **작업을 분리해 두기**, **사이드바 상단에서 전환**, **'개인' 설정에서 시작**입니다. **계속**을 클릭하세요.
3. 일하는 고객의 이름 같은 **작업 공간 이름**을 입력하고 **만들기**를 클릭하세요.

채팅 창이 새 작업 공간에서 열립니다. 채팅, 메모리, 지식은 비어 있는 상태로 시작하며, 개인의 어떤 내용도 그곳에 나타나지 않습니다.

### 작업 공간 전환

채팅 창 사이드바 위쪽의 작업 공간 메뉴를 클릭하고 작업 공간을 고르세요. 또는 **⌃⌘1**부터 **⌃⌘9**를 누르세요. 번호는 목록에서 작업 공간의 순서이므로 **⌃⌘1**은 개인입니다.

각 창은 하나의 작업 공간에서 작업하며, 여러 작업 공간의 작업이 동시에 실행될 수 있습니다.

### 분리되는 것

각 작업 공간에는 고유한 채팅, 메모리, 지식, 로그인, 설정이 있습니다. 코딩 에이전트 채팅은 시작된 작업 공간 안에 머물고, 새 [스페이스](/ko/features/spaces)는 각 작업 공간에 별도의 데이터를 보관합니다. 새 작업 공간은 그 안에서 하나를 바꾸기 전까지 개인 설정을 사용합니다.

작업 공간에서 커넥터에 자체 계정을 지정하려면 해당 작업 공간으로 전환하고, 플러그인 페이지에서 커넥터를 열고, 계정의 **⋯** 메뉴에서 **기본으로 설정**을 고르세요. 계정에 **기본 사용 위치**와 작업 공간 이름이 표시되며, 요청에서 다른 계정을 지정하지 않는 한 에이전트가 그곳에서 이를 사용합니다.

팀 관리자라면 **팀** 페이지에서 각 구성원을 하나 이상의 작업 공간에 넣을 수 있습니다. 그러면 구성원은 자신과 작업 공간을 공유하는 팀원만 보고, 채팅하고, 통화할 수 있습니다.

### 작업 공간 이름 변경 또는 삭제

**설정 → 작업 공간**을 여세요. **개인**은 항상 맨 위에 있으며, 모든 작업 공간이 시작하는 기준이 되는 설정이고 이름을 바꾸거나 삭제할 수 없습니다.

다른 각 작업 공간의 행에는 **이름 변경**과 **삭제**가 있습니다. 작업 공간을 삭제하면 채팅, 메모리, 지식, 설정이 함께 삭제됩니다. 삭제된 작업 공간은 7일 동안 **최근 삭제됨**에 남아 있으며, **복원**으로 되돌릴 수 있습니다.

에이전트에게 작업 공간을 나열, 생성, 이름 변경, 색상 변경, 순서 변경, 삭제, 복원하도록 요청할 수도 있습니다. 삭제하기 전에는 확인을 묻습니다.

## Mac 동기화

동기화는 내 계정에 로그인한 모든 컴퓨터에서 채팅, 설정, 스킬, 플러그인, 지식 베이스, 아티팩트를 동일하게 유지합니다. Enconvo Cloud 플랜과 평생 라이선스에 포함됩니다.

1. 각 컴퓨터에서 같은 Enconvo 계정으로 로그인하세요.
2. **설정 → 동기화**를 열고 **컴퓨터 간 동기화**를 켜세요.
3. Enconvo가 동기화하는 항목을 어디에 보관할지 물으면 **Enconvo 계정** 또는 **iCloud**를 고르세요. 나중에 **저장 공간**에서 바꿀 수 있습니다.
4. **동기화 항목**에서 포함할 항목을 고르세요.

| 항목 | 동기화되는 내용 | 이 컴퓨터에 남는 내용 |
| --- | --- | --- |
| **채팅** | 사진과 파일이 포함된 채팅 기록, 제목, 프로젝트, 보관된 채팅 | |
| **설정** | 모델, 프롬프트, 플러그인 환경설정, 내 스니펫, 내가 만든 AI 명령, 에이전트, 워크플로 | 로그인, 단축키, 폴더 경로 |
| **스킬** | 설치했거나 만든 스킬과 각각의 켜짐 여부. GitHub에서 설치한 스킬은 출처를 유지하므로 다른 컴퓨터도 업데이트를 확인합니다 | 플러그인과 함께 제공되는 스킬은 플러그인에 남음 |
| **플러그인** | Enconvo 스토어, GitHub, npm, 링크에서 설치한 플러그인. 다른 컴퓨터도 이를 설치하고, 내가 삭제하는 것은 삭제합니다 | 기본 제공 플러그인, 개발 중인 플러그인, 커넥터, 로그인 |
| **지식 베이스** | 메모, 텍스트, 웹 페이지가 포함된 지식 베이스와 메모리 | 가져온 파일과 녹음 |
| **아티팩트** | 모든 버전이 포함된 [아티팩트](/ko/features/artifacts): 페이지, 문서, 디자인, 슬라이드, 대시보드, 사진, 동영상. 두 Mac이 동시에 하나를 바꾸면 두 버전이 모두 유지됩니다 | 32MB를 넘는 파일, 공유된 문서와 디자인 |
| **API 키** | 기본 제공 제공업체의 API 키. 이 컴퓨터를 떠나기 전에 암호화됩니다 | 로그인과 사용자 지정 제공업체 |

암호와 로그인은 컴퓨터를 떠나지 않습니다. Enconvo 계정을 저장 공간으로 사용하면 새 컴퓨터는 내 다른 컴퓨터 중 하나가 허용한 뒤에만 API 키를 받습니다. 두 컴퓨터에 같은 코드가 표시되는지 확인하고 **허용**을 클릭하세요. **백업 암호 문구**가 있으면 다른 컴퓨터가 가까이에 없을 때도 컴퓨터가 API 키를 받을 수 있습니다. iCloud를 사용하면 같은 iCloud에 로그인한 Mac이 알아서 키를 받습니다.

**지금 동기화**는 즉시 동기화하고, **내 컴퓨터**에는 동기화하는 모든 컴퓨터가 나열됩니다. **동기화된 데이터 지우기**는 내 계정이나 iCloud에 동기화된 모든 것을 모든 컴퓨터에서 삭제합니다. 컴퓨터에 있는 내용은 남으며, 이 컴퓨터에서는 동기화가 꺼지고 다른 컴퓨터에서는 다시 켤 때까지 일시 중지됩니다.

## 포인트 사용량과 사용량 통계

**설정 → 포인트 사용량**에는 Enconvo Cloud 포인트가 표시됩니다.

- **총잔액**: 지금 사용할 수 있는 전체입니다. 구독 포인트가 먼저 사용됩니다.
- **구독 잔액**: 월간 또는 연간 제공량이며, 갱신할 때마다 플랜 금액으로 초기화됩니다.
- **충전 잔액**: 충전 팩과 평생 라이선스의 포인트입니다. 만료되지 않습니다.
- 모델별 일일 사용량 차트와 각 차감의 **기록**.

**기록**에서는 **기록 유형**과 **모델**로 필터링하고, **날짜로 이동**으로 날짜를 고르고, 매일 사용한 포인트를 확인할 수 있습니다.

**설정 → 사용량 통계**에는 내 키를 포함해 Enconvo가 호출하는 모든 AI 제공업체의 비용, 토큰, 요청이 표시됩니다. **비용**, **토큰 수**, **요청**을 전환하고, **24시간**, **7d**, **30d**, **90d**를 고르고, 모델, 제공업체, 기능별로 수치를 나눠 볼 수 있습니다. 비용은 제공업체의 API 정가 기준 추정치입니다.

## 제휴 프로그램

**설정 → 제휴 프로그램**에서 내 링크와 코드를 확인할 수 있으며, 메뉴 막대 메뉴의 **제휴 프로그램…**으로도 열 수 있습니다. 이전 버전에서는 이 페이지를 **친구 초대**라고 불렀습니다. **링크 복사** 또는 **코드 복사**로 공유하세요. 사람마다 링크가 하나 있으며 `enconvo.com/i/<your code>`입니다.

- **친구**는 내 링크나 코드로 가입한 다음 Enconvo를 처음 쓰는 기기에서 Enconvo 앱에 로그인하면 250,000 Cloud 포인트($5)를 받습니다. 웹에서 로그인하는 것은 해당되지 않습니다.
- **나**는 친구가 가입한 지 30일 안에 결제하면 친구의 첫 결제 금액의 20%를 Cloud 포인트(50,000포인트 = $1)로 받습니다. 연간 플랜은 연간 가격을 12로 나눈 금액으로 계산합니다.
- 플랜의 몫은 바로 적립됩니다. 평생 라이선스의 몫은 환불 기간인 30일 동안 보류되며, 그 기간에 환불하면 취소됩니다.
- 결제만 인정되며, 친구가 결제하는 기기나 앱은 상관없습니다.
- 친구가 결제하기 전에 다른 사람의 링크를 열었다면 마지막으로 연 링크가 보상을 받습니다. 결제 시 입력한 프로모션 코드는 어떤 링크보다 우선하며, 한 번의 결제로 포인트와 제휴 수수료가 모두 지급되지는 않습니다.

초대 코드는 임시 이메일 주소나 에이전트 이메일 주소로는 사용할 수 없으며, 초대할 수 있는 친구 수에는 제한이 없습니다. **내 초대 내역**에는 각 친구와 내 몫의 진행 상황이 표시됩니다. 첫 결제 대기 중, 환불 기간 중, 또는 적립 완료입니다.

친구가 나를 초대했다면 **초대 코드가 있나요?**에 그 코드를 입력하고 **사용하기**를 클릭하세요.

### 대신 현금으로 받기

블로거, 크리에이터, 청중이 있는 누구나 앱 사용 여부와 상관없이 [제휴 프로그램](https://www.enconvo.com/affiliate)에 신청할 수 있습니다. 승인되면 같은 링크로 내가 추천한 사람들의 모든 결제(갱신 포함)에서 20% 현금 수수료를 받습니다. 구독 수수료는 바로 지급할 수 있고, 평생 라이선스 수수료는 30일의 환불 기간 이후에 지급됩니다. 지급은 잔액이 $50에 이르면 매월 1일에 PayPal 또는 Wise로 이루어지며, 그보다 적은 잔액은 이월됩니다. 승인 전에 받은 포인트는 그대로 내 것입니다. 신청이 승인되지 않으면 60일 후에 다시 신청할 수 있습니다. 전체 규정은 [제휴 프로그램 약관](https://www.enconvo.com/affiliate/terms)에 있습니다.

## 코드 사용

1. **설정 → 코드 사용**을 여세요.
2. 코드나 코드가 담긴 링크를 붙여넣고 **계속**을 클릭하세요.

라이선스 코드와 카드가 필요 없는 체험은 계정에서 바로 활성화됩니다. 팀 라이선스 코드를 사용하면 내 계정이 해당 코드의 좌석에 대한 팀 관리자가 되며, 좌석마다 50,000 Cloud 포인트가 제공됩니다. [팀](#팀)을 참고하세요. 카드가 필요한 체험은 브라우저에서 결제 화면을 열고 확인하기 전에 갱신 조건을 보여 줍니다.

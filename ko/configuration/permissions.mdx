---

Enconvo의 일부 기능은 화면 보기나 다른 앱에 입력하기처럼 macOS의 승인이 필요한 접근 권한을 요구합니다. **설정 → 권한**에는 각 권한과 그 권한으로 동작하는 기능, 허용 여부가 나열됩니다. 텍스트 채팅에는 권한이 필요 없으므로 Enconvo는 실행할 때 권한을 요청하지 않습니다. 권한이 필요한 기능을 처음 사용할 때 어느 기능이 요청하는지 알려 주며 요청합니다.

## Enconvo가 권한을 요청하는 때

아직 허용하지 않은 권한이 필요한 기능을 사용하면 Enconvo가 권한 창을 열고 기능 이름을 알려 주며 **시스템 설정 열기**를 제공합니다. **나중에**를 선택할 수도 있습니다.

기능이 더 이상 요청하지 않게 하려면 창에서 해당 기능의 **다시 묻지 않기**를 선택하세요. 그러면 권한 페이지에서 바꿀 때까지 그 기능은 요청하지 않습니다. 화면 기록은 다시 시작해야 접근이 적용되는 경우 창에 **다시 시작**이 표시됩니다.

## 권한 허용

1. **설정 → 권한**을 엽니다.
2. 권한을 찾아 **권한 허용**을 클릭합니다.
3. macOS가 안내 창을 표시하거나 **시스템 설정 → 개인정보 보호 및 보안**에서 해당 항목을 엽니다. 손쉬운 사용과 입력 모니터링은 해당 항목에서 Enconvo의 스위치를 직접 켜야 합니다.
4. macOS가 요청하면 Enconvo를 종료한 뒤 다시 엽니다.
5. Enconvo로 돌아오면 해당 행에 **허용됨**이 표시됩니다. 기능을 다시 시도해 보세요.

이 페이지는 다시 돌아오면 자동으로 다시 확인합니다. 바로 확인하려면 **새로고침**을 클릭하세요.

## 권한을 사용하는 기능 확인

각 권한 아래의 **사용처**에는 그 권한이 필요한 기능과 각 기능이 요청할지 여부가 나열됩니다.

| 상태 | 의미 |
| --- | --- |
| **사용할 때 물음** | 다음에 기능을 사용할 때 권한을 요청합니다. |
| **거절됨 · 단축키를 누를 때 물음** | 거절한 상태입니다. 해당 기능의 단축키를 누를 때만 다시 요청합니다. |
| **묻지 않음** | **다시 묻지 않기**를 선택한 상태입니다. 클릭하면 **사용할 때 물음**으로 돌아갑니다. |
| **끔** 또는 **플러그인 꺼짐** | 기능 또는 그 기능이 속한 플러그인이 꺼져 있습니다. |

## 각 권한의 용도

| 권한 | 용도 |
| --- | --- |
| 손쉬운 사용 | 앱 인터페이스 읽기, 클릭, 입력, 창 제어: 컴퓨터 사용, PopBar, 선택한 텍스트, 텍스트 삽입 |
| 화면 기록 | 에이전트가 앱 내용을 볼 수 있게 하는 스크린샷: 컴퓨터 사용, Appshots, 화면 컨텍스트, OCR 캡처. macOS에서는 화면 및 시스템 오디오 기록이라고 부를 수 있으며 시스템 오디오 캡처도 포함합니다. |
| 입력 모니터링 | 다른 앱이 앞에 있을 때 PopBar, 단축키, 보조 키 두 번 누르기 트리거에 쓰이는 전역 키보드 입력 |
| 마이크 | 받아쓰기, 음성 명령, 음성 메모, 회의 녹음, 실시간 자막, Live Talk |
| 알림 | 에이전트 세션이 끝나거나 사용자의 확인이 필요할 때 보내는 macOS 알림 |
| 카메라 | SmartBar 카메라 토글에서 찍는 실시간 카메라 사진 |
| 위치 | Dynamic Island의 현지 날씨와 에이전트를 위한 위치 컨텍스트 |
| 자동화 | Apple 이벤트로 다른 앱 제어: 브라우저 탭, Finder 선택 항목, Mail, 메시지, System Events 읽기 |
| 로컬 네트워크 | 네트워크의 다른 컴퓨터에 있는 모델 서버에 연결. 권한 페이지에는 없으며 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 찾을 수 있습니다. |

캘린더, 미리 알림, 메모, Mail 등 다른 Apple 앱은 **플러그인** 페이지에서 연결합니다. [Apple 앱](/ko/integrations/apple-ecosystem)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 권한이 켜져 있는데도 캡처가 실패합니다 | Enconvo를 종료했다가 다시 열고 다시 시도하세요. 이전 사본이 아니라 지금 실행 중인 Enconvo 앱을 켰는지 확인하세요. |
| 기능이 필요한 권한을 전혀 요청하지 않습니다 | **사용처**에서 해당 행을 확인하세요. **묻지 않음**으로 되어 있으면 클릭하거나 **권한 허용**으로 권한을 허용하세요. |
| 화면 기록이 허용으로 표시되는데도 캡처가 실패합니다 | 권한 창에서 **다시 시작**을 클릭하거나 Enconvo를 종료했다가 다시 여세요. |
| 받아쓰기에 텍스트가 표시되지만 삽입되지 않습니다 | 손쉬운 사용을 확인하고, 대상 입력란이 입력이나 붙여넣기를 받는지 확인하세요. |
| 단축키가 Enconvo 안에서만 작동합니다 | 입력 모니터링과 손쉬운 사용을 확인하세요. 다른 앱과 충돌하는 단축키는 [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 참고하세요. |
| 다른 컴퓨터의 모델 서버에 연결되지 않습니다 | 로컬 네트워크를 확인하고, 서버가 네트워크 주소에서 수신 대기 중인지 확인하세요. |
| 에이전트가 끝나도 배너가 표시되지 않습니다 | 여기의 알림, macOS 집중 모드, [알림](/ko/configuration/notifications)의 **시스템 알림 보내기**를 확인하세요. |

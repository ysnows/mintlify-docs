title: "macOS 권한"
description: "Enconvo가 사용하는 macOS 권한을 확인하고, 기능에 필요한 권한을 허용하며, 화면 캡처나 입력이 멈췄을 때 해결하세요."
---

일부 Enconvo 기능은 화면을 보거나 다른 앱에 텍스트를 입력하는 것처럼 macOS에서 사용자의 승인이 필요한 권한을 사용합니다. **설정 → 권한**에서는 각 권한과 해당 권한이 지원하는 기능, 허용 여부를 한눈에 볼 수 있습니다. 일반 텍스트 채팅에는 권한이 필요하지 않으므로 Enconvo는 실행 시 바로 권한을 묻지 않고, 권한이 필요한 기능을 처음 쓸 때 어떤 기능이 요청하는지 알려 주며 묻습니다.

## Enconvo가 권한을 요청할 때

아직 허용하지 않은 권한이 필요한 기능을 실행하면 Enconvo가 권한 창을 열어 기능 이름을 알려 주고 **시스템 설정 열기** 버튼을 표시합니다. 원하지 않으면 **나중에**를 선택할 수도 있습니다.

특정 기능에서 다시 묻지 않게 하려면 창에서 해당 기능의 **다시 묻지 않기**를 체크하세요. 그러면 권한 페이지에서 설정을 바꾸기 전까지 묻지 않습니다. 화면 기록 권한의 경우 앱을 다시 시작하기만 하면 바로 적용되는 상태일 때 창에 **다시 시작** 버튼이 표시됩니다.

## 권한 허용하기

1. **설정 → 권한**을 엽니다.
2. 필요한 권한을 찾아 **권한 허용**을 클릭합니다.
3. macOS가 확인 창을 띄우거나 **시스템 설정 → 개인정보 보호 및 보안**의 해당 항목을 엽니다. 손쉬운 사용과 입력 모니터링은 그 창에서 Enconvo 스위치를 직접 켜 주어야 합니다.
4. macOS가 재시동을 요청하면 Enconvo를 종료했다가 다시 엽니다.
5. Enconvo로 돌아와 해당 행이 **허용됨**으로 바뀌었는지 확인한 뒤 기능을 다시 사용해 봅니다.

설정 창으로 돌아오면 자동으로 다시 확인하며, 바로 확인하려면 **새로고침**을 클릭하세요.

## 어떤 기능이 권한을 쓰는지 보기

각 권한 아래의 **사용 위치**에는 그 권한이 필요한 기능 목록과 다음 사용 시 요청 여부가 표시됩니다.

| 상태 | 의미 |
| --- | --- |
| **사용할 때 물음** | 다음에 이 기능을 사용할 때 권한을 요청합니다. |
| **거부됨 · 단축키 입력 시 물음** | 거부한 상태입니다. 단축키를 눌렀을 때만 다시 묻습니다. |
| **묻지 않음** | **다시 묻지 않기**를 선택한 상태입니다. 클릭하면 **사용할 때 물음**으로 돌아갑니다. |
| **꺼짐** 또는 **플러그인 꺼짐** | 해당 기능이나 그 기능이 속한 플러그인이 꺼져 있습니다. |

## 각 권한의 용도

| 권한 | 용도 |
| --- | --- |
| 손쉬운 사용 | 앱 인터페이스 읽기, 클릭, 입력, 창 제어: 컴퓨터 사용, PopBar, 선택한 텍스트 읽기, 텍스트 삽입 |
| 화면 기록 | 에이전트가 앱 화면을 볼 수 있도록 찍는 스크린샷: 컴퓨터 사용, Appshots, 화면 컨텍스트, OCR 캡처. macOS에서는 '화면 및 시스템 오디오 녹음'으로 표시될 수 있으며 시스템 오디오 캡처도 포함됩니다. |
| 입력 모니터링 | 다른 앱이 앞에 있을 때 PopBar, 전역 단축키, 보조 키 두 번 누르기 트리거를 감지하는 전역 키보드 입력 |
| 마이크 | 받아쓰기, 음성 명령, 음성 메모, 회의 녹음, 실시간 자막, Live Talk |
| 알림 | 에이전트 세션이 끝나거나 사용자 확인이 필요할 때 띄우는 macOS 알림 |
| 카메라 | SmartBar 카메라 토글에서 찍는 실시간 카메라 사진 |
| 위치 | Dynamic Island의 현지 날씨, 에이전트용 위치 컨텍스트 |
| 자동화 | Apple Events로 다른 앱 제어: 브라우저 탭, Finder 선택 항목, Mail, 메시지, 시스템 이벤트 읽기 |
| 로컬 네트워크 | 같은 네트워크의 다른 컴퓨터에 있는 모델 서버에 연결. 권한 페이지에는 나오지 않으며 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에 있습니다. |

캘린더, 미리 알림, 메모, Mail 등의 Apple 앱은 권한 페이지 대신 **플러그인** 페이지에서 연결합니다. [Apple 앱](/ko/integrations/apple-ecosystem)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 권한이 켜져 있는데도 캡처가 실패함 | Enconvo를 완전히 종료했다가 다시 연 뒤 시도하세요. 예전 복사본이 아니라 현재 실행 중인 Enconvo 앱이 켜져 있는지도 확인하세요. |
| 기능이 필요한 권한을 묻지 않음 | **사용 위치** 아래의 해당 기능 행을 확인하세요. **묻지 않음**으로 되어 있다면 클릭해 바꾸거나 **권한 허용**으로 권한을 바로 허용하세요. |
| 화면 기록이 허용됨인데도 캡처가 안 됨 | 권한 창에서 **다시 시작**을 클릭하거나 Enconvo를 종료했다가 다시 여세요. |
| 받아쓰기에 텍스트는 뜨는데 입력이 안 됨 | 손쉬운 사용 권한을 확인하고, 대상 입력 칸이 타이핑이나 붙여넣기를 허용하는지 확인하세요. |
| 단축키가 Enconvo 안에서만 작동함 | 입력 모니터링과 손쉬운 사용 권한을 확인하세요. 다른 앱과의 단축키 충돌은 [키보드 단축키](/ko/configuration/keyboard-shortcuts)를 참고하세요. |
| 다른 컴퓨터의 모델 서버에 연결되지 않음 | 로컬 네트워크 권한을 확인하고, 서버가 네트워크 주소에서 연결을 수락하는지 확인하세요. |
| 에이전트가 끝나도 알림 배너가 안 뜸 | 여기의 알림 권한, macOS 집중 모드, [알림](/ko/configuration/notifications)의 **시스템 알림 보내기**를 확인하세요. |

사용하는 모든 제공업체에는 자격 증명이 필요합니다. API 키이거나 이미 결제 중인 요금제에 대한 로그인입니다. 제공업체의 설정 페이지에서 추가하면 Enconvo는 그 제공업체를 쓰는 모든 기능이 공유하는 제공업체 프로필에 저장합니다. **설정 → 인증 정보 관리**에서 모든 자격 증명을 한곳에서 볼 수 있습니다.

이 영상은 Avatar와 IM Channels 다음에 인증 정보 관리로 끝납니다.

## 제공업체 추가

<Steps>
  <Step title="카테고리 열기">
    사용하려는 항목의 설정 페이지를 엽니다. 예를 들어 **설정 → AI 모델**, **설정 → 이미지 생성**, **설정 → 텍스트 음성 변환**입니다.
  </Step>
  <Step title="제공업체 선택">
    제공업체를 선택합니다. 다른 키나 계정을 위해 같은 제공업체를 하나 더 설정하려면 **새 제공업체 추가**를 선택하세요.
  </Step>
  <Step title="로그인 방식 선택">
    **인증**에서 **API 키**를 선택하거나, 제공업체가 결제 중인 요금제를 쓰게 해 주는 경우 **구독**을 선택합니다.
  </Step>
  <Step title="자격 증명 추가">
    API 키를 붙여넣거나 제공업체의 로그인을 완료합니다.
  </Step>
  <Step title="테스트">
    페이지에 **검증**이 보이면 클릭하고, 모델을 선택한 뒤 짧은 요청을 보내 보세요.
  </Step>
</Steps>

API 키는 제공업체의 API 계정으로 비용이 청구됩니다. 구독은 요금제에 포함된 사용량과 한도를 사용합니다. 페이지가 어느 쪽을 쓰는지는 **인증** 아래 안내 문구에 나와 있습니다.

## 공유 프로필

**OpenAI 2** 같은 제공업체 프로필에는 제공업체의 API 키와 구독 로그인이 들어 있으며, 그 제공업체가 지원하는 모든 카테고리에 나타납니다. 프로필의 이름을 바꾸거나 삭제하면 지금 보고 있는 페이지뿐 아니라 해당하는 모든 카테고리에 반영됩니다.

각 카테고리는 모델, 음성, 생성 설정을 따로 유지합니다. 하지만 새 API 키는 그 프로필을 쓰는 모든 기능에 적용되므로, 키를 바꾼 뒤에는 해당 기능을 테스트하세요.

제공업체가 제공하는 범위는 카테고리마다 다릅니다. AI 채팅에서 로그인이 된다고 해서 제공업체의 실시간 음성 API까지 포함되는 것은 아닙니다. 카테고리가 API 키만 받는 경우 해당 페이지에 그렇게 안내되며, 구독이 작동하는 카테고리도 함께 표시됩니다.

## 요금제 사용량 확인

구독 로그인에는 계정과 요금제의 남은 사용량이 표시됩니다. **% 남음** 같은 값은 남아 있는 사용 가능량입니다. 계정 카드의 메뉴를 열고 **사용량 새로고침**을 선택하면 갱신되고, **다시 연결**을 선택하면 다시 로그인할 수 있습니다.

Claude 또는 Codex에서 무료 한도 초기화를 받았다면 Claude나 ChatGPT 구독 카드에 **무료 한도 초기화**가 표시됩니다. 보유 개수와 기한을 볼 수 있습니다. **초기화 사용**을 클릭하고 확인하면 한도가 다시 채워집니다. 여러 개가 있으면 카드에 목록이 나타나며 고른 것을 사용합니다.

사용량이 표시되지 않는다고 해서 사용량이 무제한이라는 뜻은 아닙니다.

## 자격 증명 관리

**설정 → 인증 정보 관리**를 엽니다. 목록은 제공업체 프로필별로 자격 증명을 묶어 보여 주고, 그 아래에 어떤 제공업체도 쓰지 않는 키인 **사용하지 않는 키**를 보여 줍니다.

- **제공업체 검색...**에 입력해서 찾습니다.
- **새 인증 정보 추가**를 클릭하면 선택한 서비스의 자격 증명을 추가로 만듭니다.
- 자격 증명을 삭제하려면 항목에 마우스를 올리고 휴지통 아이콘을 클릭합니다. API 키 Connector가 그 키를 사용 중이면 확인 창에 이름이 표시되며, **삭제 및 연결 해제**를 누르면 다른 키를 지정할 때까지 해당 Connector의 연결이 해제됩니다.
- 목록 하단의 **정리**를 클릭하면 사용하지 않는 키를 한 번에 모두 삭제합니다. 버튼에 개수가 표시되고, 확인 창에서 먼저 목록을 보여 줍니다. Enconvo가 사용하지 않는 키를 자동으로 삭제하는 일은 없습니다.

자격 증명을 클릭하면 키를 추가하거나 변경할 수 있습니다. **사용처**에는 **AI 모델**이나 **텍스트 음성 변환**처럼 그 자격 증명을 쓰는 기능이 나열되며, 하나를 클릭하면 해당 설정 페이지가 열립니다.

프로필 자체의 자격 증명에는 여기에 삭제 버튼이 없습니다. 제공업체를 삭제하면 함께 사라집니다.

해당하는 경우 두 그룹이 더 나타납니다. Enconvo에 제공업체가 없는 서비스의 키를 담는 **기타 서비스**와 저장한 웹사이트 및 앱 로그인을 담는 **로그인 정보**입니다.

## 에이전트에 키가 필요할 때

작업에 서비스의 API 키가 필요하면 에이전트는 키를 붙여넣으라고 요청하는 대신 채팅에 **연결** 카드를 표시합니다. 키는 대화가 아니라 인증 정보 관리에 저장되며, 이후 채팅에서는 다시 묻지 않고 사용합니다.

Enconvo에 제공업체가 없는 서비스라면 카드에 키가 전송될 호스트가 표시됩니다. 키는 **기타 서비스**에 저장되며, 에이전트는 그 호스트로 가는 요청에서만 사용할 수 있습니다.

에이전트는 키 자체를 갖지 않습니다. 저장된 자격 증명의 이름만 지정하고, 요청이나 명령에 키가 드러날 자리에는 `[redacted]`가 표시됩니다.

Phone 채팅에서는 **연결** 카드가 iPhone에 표시되고 키는 Mac의 인증 정보 관리에 저장됩니다. IM 채팅에서는 에이전트가 키를 요청하지 않고 Enconvo에서 채팅을 여는 링크를 보냅니다.

그래도 메시지에 API 키를 붙여넣으면 Enconvo는 그 키를 인증 정보 관리에 저장하고 저장된 채팅에서는 `[redacted]`로 바꿉니다. 그래서 이후 요청과 다른 기기에는 키가 전달되지 않습니다. 이미 키가 있는 서비스에 새 키를 붙여넣으면 저장된 키가 교체됩니다.

## 웹사이트 및 앱 로그인

브라우저 작업이 로그인 페이지에 이르면 카드가 사용자 이름과 비밀번호를 한 번 요청합니다. Enconvo는 해당 사이트에서만 이를 입력하며 에이전트는 비밀번호를 보지 못합니다. 저장된 로그인은 **로그인 정보**에 나타납니다. **이 로그인 정보 기억하기**를 해제하면 이번 로그인에만 사용합니다.

Mac 앱의 로그인에 비밀번호가 필요하면 카드에 앱 이름이 표시됩니다. Enconvo는 그 앱에만 사용자 이름과 비밀번호를 입력하며, 비밀번호는 입력 내용을 숨기는 필드에만 입력합니다.

## 사용자 지정 엔드포인트

**OpenAI 호환**과 **Anthropic 호환** 제공업체에는 직접 운영하는 서버를 위한 API 기본 URL 필드가 있습니다. 일부 기본 제공업체는 엔드포인트 설정을 **인증 정보 관리**에 둡니다. 다른 컴퓨터의 모델 서버는 [로컬 모델](/ko/ai/local-llm)을 참고하세요.

저장된 키가 전송되는 위치(제공업체나 자격 증명의 주소, MCP 서버의 저장된 키 사용)는 Enconvo 자체 창에서만 변경할 수 있습니다. 로컬 API를 사용하는 다른 프로그램, 휴대폰, 에이전트의 변경 요청은 거부됩니다.

## 키 보관 방식

- 저장된 각 키와 로그인은 이 Mac의 키체인에 보관되는 키로 암호화되므로 Enconvo 설정 폴더를 복사해도 다른 컴퓨터에서는 읽을 수 없습니다. 이전 버전의 Enconvo로 돌아가면 키를 다시 입력해야 합니다.
- 다른 프로그램이 Enconvo의 [로컬 API](/ko/advanced/cli-local-api)에 설정을 요청하면 각 키 자리에 `[hidden]`이 반환됩니다. 스토어의 플러그인은 자신의 키와 설정에서 선택한 자격 증명만 사용할 수 있습니다.
- Enconvo가 설치했고 변경되지 않은 코드만 저장된 키를 열 수 있습니다. 설정에서는 이전과 같이 키를 보고 확인할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 검증에 실패합니다 | 선택한 프로필, 인증 방식, 엔드포인트를 확인하고 제공업체 계정에 접근 권한이 있는지 확인하세요. |
| 한 기능은 작동하는데 다른 기능은 실패합니다 | 계정이 해당 기능과 모델을 지원하는지 확인하세요. 카테고리가 API 키만 받는 경우 페이지에 안내됩니다. |
| 키를 바꾼 뒤 작동이 멈췄습니다 | 프로필은 공유됩니다. 그 프로필을 쓰는 다른 카테고리도 테스트하세요. |
| 사용량 영역에 **다시 연결**이 표시됩니다 | 로그인이 만료되었습니다. **다시 연결**을 클릭하고 다시 로그인하세요. |

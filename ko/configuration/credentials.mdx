사용하는 모든 제공업체에는 API 키 또는 이미 구독 중인 요금제 로그인 같은 인증 정보가 필요합니다. 각 제공업체의 설정 페이지에서 추가하면 Enconvo가 이를 제공업체 프로필에 저장하며, 해당 제공업체를 쓰는 모든 기능이 이를 공유합니다. **설정 → 인증 정보 관리**에서는 모든 인증 정보를 한곳에서 확인할 수 있습니다.

이 동영상은 아바타와 메신저 채널을 다룬 뒤 인증 정보 관리 화면으로 마무리됩니다.

## 제공업체 추가하기

<Steps>
  <Step title="카테고리 열기">
    **설정 → AI 모델**, **설정 → 이미지 생성**, **설정 → 텍스트 음성 변환** 등 사용하려는 기능의 설정 페이지를 엽니다.
  </Step>
  <Step title="제공업체 선택">
    제공업체를 선택합니다. 다른 키나 계정을 위해 같은 제공업체를 하나 더 설정하려면 **새 제공업체 추가**를 선택하세요.
  </Step>
  <Step title="로그인 방식 선택">
    **인증** 아래에서 **API 키**를 선택하거나, 구독 중인 요금제를 사용할 수 있는 제공업체라면 **구독**을 선택합니다.
  </Step>
  <Step title="인증 정보 추가">
    API 키를 붙여 넣거나 제공업체의 로그인 절차를 완료합니다.
  </Step>
  <Step title="테스트">
    페이지에 **검증** 버튼이 있으면 클릭하고, 모델을 선택한 뒤 짧은 요청을 시험해 보세요.
  </Step>
</Steps>

API 키는 제공업체의 API 계정에 과금됩니다. 구독은 요금제에 포함된 사용량과 한도를 사용합니다. **인증** 아래의 안내 문구에서 현재 페이지가 어떤 방식을 사용하는지 확인할 수 있습니다.

## 공유 프로필

**OpenAI 2** 같은 제공업체 프로필은 해당 제공업체의 API 키와 구독 로그인을 보관하며, 그 제공업체가 지원하는 모든 카테고리에 표시됩니다. 프로필 이름을 바꾸거나 삭제하면 현재 페이지뿐 아니라 모든 카테고리에서 함께 바뀝니다.

각 카테고리는 자체 모델, 음성 및 생성 설정을 별도로 유지합니다. 다만 새 API 키를 입력하면 해당 프로필을 사용하는 모든 기능에 적용되므로, 키를 바꾼 뒤에는 해당 기능들을 테스트해 보세요.

제공업체가 지원하는 범위는 카테고리마다 다릅니다. AI 채팅에서 작동하는 구독 로그인이더라도 해당 제공업체의 실시간 음성 API까지 포함된다는 뜻은 아닙니다. API 키만 지원하는 카테고리라면 페이지에 그 사실이 안내되며 구독이 작동하는 카테고리도 함께 표시됩니다.

## 요금제 사용량 확인하기

구독 로그인은 계정과 요금제 잔여량을 함께 보여 줍니다. **% left** 같은 값은 남아 있는 사용량 비율입니다. 계정 카드의 메뉴를 열고 **사용량 새로 고침**을 선택해 최신 상태로 갱신하거나, **다시 연결**을 선택해 다시 로그인할 수 있습니다.

Claude 또는 Codex에서 무료 한도 초기화를 제공한 경우 Claude 또는 ChatGPT 구독 카드에 **무료 한도 초기화** 횟수와 만료 기한이 표시됩니다. **초기화 사용**을 클릭하고 확인하면 한도가 다시 채워집니다. 초기화 권한이 여러 개라면 카드에 목록이 표시되며 원하는 항목을 골라 사용할 수 있습니다.

사용량이 표시되지 않는다고 해서 무제한으로 사용할 수 있다는 뜻은 아닙니다.

## 인증 정보 관리하기

**설정 → 인증 정보 관리**를 엽니다. 목록은 제공업체 프로필별로 인증 정보를 묶어 보여 준 뒤, 어느 제공업체도 쓰지 않는 키인 **사용하지 않는 키**를 표시합니다.

- **제공업체 검색...**에 입력해 원하는 항목을 찾으세요.
- **새 인증 정보 추가**를 클릭해 선택한 서비스의 인증 정보를 새로 만들 수 있습니다.
- 인증 정보를 삭제하려면 항목 위로 마우스를 가져가 휴지통 아이콘을 클릭하세요. API 키 기반 커넥터가 해당 키를 사용 중이라면 확인 창에 그 이름이 표시되며, **삭제 및 연결 해제**를 누르면 새 키를 입력할 때까지 연결이 해제됩니다.
- 목록 맨 아래에서 **정리**를 클릭하면 사용하지 않는 키를 한꺼번에 삭제할 수 있습니다. 버튼에는 개수가 표시되고 확인 창에 목록이 먼저 나타납니다. Enconvo는 사용하지 않는 키를 자동으로 삭제하지 않습니다.

인증 정보를 클릭해 키를 추가하거나 수정하세요. **사용처**에는 **AI 모델**이나 **텍스트 음성 변환**처럼 이 키를 참조하는 기능이 나열되며, 항목을 클릭하면 해당 설정 페이지로 이동합니다.

프로필 자체의 인증 정보에는 여기에서 삭제 버튼이 표시되지 않습니다. 해당 제공업체를 삭제할 때 함께 제거됩니다.

해당 항목이 있을 때는 두 개의 그룹이 더 나타납니다. Enconvo에 전용 제공업체가 없는 서비스의 키를 담는 **기타 서비스**와, 저장한 웹사이트 및 앱 로그인을 담는 **로그인 정보**입니다.

## 에이전트가 키를 필요로 할 때

작업에 특정 서비스의 API 키가 필요할 때 에이전트는 채팅에 키를 붙여 달라고 요구하지 않고 **연결** 카드를 보여 줍니다. 키는 대화가 아니라 인증 정보 관리에 저장되며, 이후 채팅에서는 다시 묻지 않고 그대로 사용합니다.

Enconvo에 전용 제공업체가 없는 서비스의 경우 카드에 키가 전송될 호스트가 표시됩니다. 키는 **기타 서비스** 아래에 저장되며, 에이전트는 해당 호스트로 보내는 요청에서만 이를 사용할 수 있습니다.

에이전트 자체는 키 값을 직접 보지 못합니다. 저장된 인증 정보의 이름만 가리키며, 요청이나 명령에서 키가 보일 위치에는 `[redacted]`로 표시됩니다.

휴대전화 채팅에서는 iPhone에 **연결** 카드가 나타나고, 키는 Mac의 인증 정보 관리에 저장됩니다. 메신저 채팅에서는 에이전트가 키를 묻지 않고 대신 Enconvo에서 해당 채팅을 여는 링크를 보냅니다.

그래도 메시지에 API 키를 직접 붙여 넣으면 Enconvo가 이를 인증 정보 관리에 저장한 뒤 저장된 채팅에서는 `[redacted]`로 대체하므로, 이후 요청이나 다른 기기에는 키가 남지 않습니다. 이미 키가 저장된 서비스에 새 키를 붙여 넣으면 기존 키가 새 키로 교체됩니다.

## 웹사이트 및 앱 로그인

브라우저 작업이 로그인 페이지에 도달하면 카드가 한 번 사용자 이름과 비밀번호를 묻습니다. Enconvo는 해당 사이트에서만 이를 입력하며 에이전트는 비밀번호를 볼 수 없습니다. 저장된 로그인은 **로그인 정보** 아래에 나타납니다. 이번 로그인에만 사용하고 저장하지 않으려면 **이 로그인 정보 기억하기**를 선택 해제하세요.

Mac 앱 로그인에 비밀번호가 필요하면 카드에 해당 앱 이름이 표시됩니다. Enconvo는 그 앱에만 사용자 이름과 비밀번호를 입력하며, 비밀번호는 입력 내용을 가리는 필드에만 입력합니다.

## 사용자 지정 엔드포인트

**OpenAI 호환** 및 **Anthropic 호환** 제공업체에는 자체 서버를 위한 API 기본 URL 필드가 있습니다. 일부 기본 제공 제공업체는 엔드포인트 설정을 **인증 정보 관리**에 보관합니다. 다른 컴퓨터의 모델 서버에 연결하려면 [로컬 모델](/ko/ai/local-llm)을 참고하세요.

저장된 키가 전송되는 대상(제공업체나 인증 정보의 주소, 또는 MCP 서버의 저장된 키 사용)은 Enconvo 자체 창에서만 바꿀 수 있습니다. Local API, 휴대전화 또는 에이전트를 사용하는 다른 프로그램의 변경 시도는 거부됩니다.

## 키 보관 방식

- 저장된 모든 키와 로그인 정보는 이 Mac의 키체인에 남는 키로 암호화되므로, Enconvo 설정 폴더를 복사하더라도 다른 컴퓨터에서는 읽을 수 없습니다. 이전 버전의 Enconvo로 되돌아가면 키를 다시 입력해야 합니다.
- Enconvo의 [Local API](/ko/advanced/cli-local-api)로 설정을 조회하는 다른 프로그램에는 각 키 대신 `[hidden]`이 반환됩니다. 스토어에서 설치한 플러그인은 자체 키와 설정에서 선택된 인증 정보만 사용할 수 있습니다.
- Enconvo가 설치했고 변경되지 않은 코드만 저장된 키를 열 수 있습니다. 설정 화면에서의 키 조회 및 확인은 이전과 동일하게 작동합니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 검증 실패 | 선택한 프로필, 인증 방식, 엔드포인트 및 제공업체 계정의 접근 권한을 확인하세요. |
| 한 기능은 작동하는데 다른 기능은 실패함 | 계정이 해당 기능과 모델을 지원하는지 확인하세요. API 키만 받는 카테고리인지 페이지 안내를 확인하세요. |
| 키를 변경한 뒤 다른 기능이 작동하지 않음 | 프로필이 공유되기 때문입니다. 같은 프로필을 쓰는 다른 카테고리도 테스트하세요. |
| 사용량 영역에 **다시 연결**이 표시됨 | 로그인이 만료되었습니다. **다시 연결**을 클릭하고 다시 로그인하세요. |

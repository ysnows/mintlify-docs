사전은 Enconvo의 음성 기능에 제품 이름, 기술 용어, 약어, 특이한 표기를 가르칩니다. 화자는 녹음에서 이름을 붙인 목소리의 이름을 보관해, 새 녹음에서 자동으로 표시하게 합니다. **설정 → 사전**과 **설정 → 화자**에서 엽니다.

## 단어 추가

1. **설정 → 사전**을 열고 **새 단어**를 클릭합니다.
2. 선호하는 표기를 입력하고, 도움이 되면 짧은 설명을 넣습니다.
3. **잘못 인식된 표기**에, 받아쓰기가 이 단어 대신 쓰는 표기를 쉼표로 구분해 선택적으로 입력합니다.
4. **저장**을 클릭한 다음, 그 단어가 들어간 짧은 녹음으로 시험합니다.
5. 변환 결과를 검토합니다. 제공업체 지원과 오디오 품질도 인식에 영향을 줍니다.

## 여러 단어를 한 번에 추가

**사전에 추가** 창에서 **일괄 추가**로 전환하고 한 줄에 용어 하나를 입력합니다. 설명은 `|`로 구분합니다.

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 추천 표기 수락

사전에는 **추천 표기**가 있습니다. 받아쓴 직후 고친 단어와, 받아쓰기가 계속 쓰는 표기이며 **잘못 인식된 표기** 항목으로 제안됩니다. **수락**을 클릭하면 다음부터 받아쓰기가 그렇게 쓰고, **닫기**를 클릭하면 무시합니다.

## 수정에서 학습

**설정 → 사전**에서 **내 수정에서 학습**이 켜져 있으면, 손으로 고친 받아쓰기 이름이 다음을 위해 사전에 추가됩니다. Dynamic Island에 학습된 내용이 **실행 취소**와 함께 표시됩니다. 학습된 표기는 단어 아래에 **학습함**으로 표시됩니다. 그곳에서 제거하면 Enconvo가 다시 학습하지 않습니다.

## 단어 편집 또는 삭제

검색과 편집 버튼으로 목록을 최신 상태로 유지합니다. 여러 단어를 삭제하려면 **선택**을 클릭하고 단어를 고른 다음 **삭제**를 클릭하고 확인합니다.

## 화자 이름 지정

1. 화자가 여러 명인 녹음을 엽니다.
2. 트랜스크립트의 화자 라벨을 클릭하고 그 사람에게 이름을 줍니다.
3. Enconvo가 목소리를 등록하고 새 녹음에서 자동으로 인식합니다.

화자 이름을 바꾸기 전에 녹음의 화자 할당을 검토하세요. 인식된 목소리나 화자 분리 라벨은 틀릴 수 있으며, 사람들이 겹쳐 말할 때 특히 그렇습니다.

**설정 → 화자**에는 이름을 붙인 모든 사람과, 몇 개의 녹음에 나오는지가 나열됩니다. 그곳에서 화자 이름을 바꾸거나 삭제할 수 있습니다. 화자를 삭제하면 라벨이 화자 번호로 돌아가며, 녹음은 남습니다.

## 적용되는 곳

[받아쓰기](/ko/features/dictation), [회의 녹음](/ko/features/meeting-recording), [음성 텍스트 변환](/ko/features/transcription), [실시간 자막](/ko/features/live-captioning)은 각각 자체 음성 설정을 씁니다. 제공업체마다 어휘를 다루는 방식이 다르므로, 언어 힌트, 핫워드, 화자 분리, 기타 옵션은 각 제공업체 설정을 확인하세요.

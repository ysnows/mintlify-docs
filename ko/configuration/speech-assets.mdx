사전은 Enconvo의 음성 기능에 내가 쓰는 제품 이름, 전문 용어, 약어, 특이한 표기를 가르쳐 줍니다. 화자는 녹음에서 이름을 붙인 목소리를 기억해 두었다가 새 녹음에서 자동으로 이름을 표시해 줍니다. **설정 → 사전**과 **설정 → 화자**에서 열 수 있습니다.

## 단어 추가하기

1. **설정 → 사전**을 열고 **새 단어**를 클릭합니다.
2. 선호하는 표기를 입력하고, 도움이 된다면 짧은 설명도 입력합니다.
3. **잘못 인식된 표기**에는 받아쓰기가 이 단어 대신 적는 내용을 쉼표로 구분해 선택적으로 입력합니다.
4. **저장**을 클릭한 다음 그 단어가 들어간 짧은 녹음을 시험해 봅니다.
5. 전사 결과를 검토합니다. 제공업체 지원과 오디오 품질도 여전히 인식에 영향을 줍니다.

## 여러 단어 한꺼번에 추가하기

**사전에 추가** 창에서 **일괄 추가**로 전환하고 한 줄에 용어 하나를 입력하세요. 설명은 `|`로 구분합니다.

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 추천 표기 수락하기

사전에는 **추천 표기**가 나열됩니다. 받아쓴 직후 내가 고친 단어와, 받아쓰기가 내 단어에 대해 계속 적는 표기를 **잘못 인식된 표기** 항목으로 제안한 것입니다. **수락**을 클릭하면 다음부터 받아쓰기가 그렇게 적으며, **닫기**를 클릭하면 제안이 사라집니다.

## 내 수정에서 배우기

**설정 → 사전**에서 **내 수정에서 학습**을 켜면, 받아쓴 이름을 직접 고쳤을 때 다음을 위해 그 이름이 사전에 추가됩니다. Dynamic Island에 학습한 내용이 **실행 취소**와 함께 표시됩니다. 학습한 표기는 해당 단어 아래에 **학습함**으로 표시되며, 거기서 삭제하면 Enconvo가 다시 학습하지 않습니다.

## 단어 편집 또는 삭제하기

검색과 편집 버튼으로 목록을 최신 상태로 유지하세요. 여러 단어를 삭제하려면 **선택**을 클릭하고, 단어를 고르고, **삭제**를 클릭한 다음 확인합니다.

## 화자 이름 붙이기

1. 여러 화자가 있는 녹음을 엽니다.
2. 전사 내용에서 화자 라벨을 클릭하고 그 사람의 이름을 붙입니다.
3. Enconvo가 해당 목소리를 등록하고 새 녹음에서 자동으로 인식합니다.

화자 이름을 바꾸기 전에 녹음의 화자 지정을 검토하세요. 인식된 목소리나 화자 분리 라벨이 틀릴 수 있으며, 특히 사람들이 동시에 말할 때 그렇습니다.

**설정 → 화자**에는 이름을 붙인 모든 사람이 등장하는 녹음 수와 함께 나열됩니다. 여기서 화자의 이름을 바꾸거나 삭제할 수 있습니다. 화자를 삭제하면 해당 라벨이 다시 화자 번호로 바뀌며, 녹음은 그대로 남습니다.

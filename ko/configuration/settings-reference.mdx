---
title: "설정 참고"
description: "설정 사이드바의 항목마다 무엇을 조정하는지, 그리고 설명하는 가이드입니다."
---

Enconvo 설정 사이드바의 항목을 사이드바 순서대로, 설명하는 가이드와 함께 나열합니다. 설정을 열려면 메뉴 막대의 Enconvo 아이콘을 클릭하고 **설정**을 선택합니다. 항목으로 이동하려면 **설정 검색**에 이름을 입력하거나, 질문을 입력하고 Return을 눌러 AI에게 설정 위치를 물어보세요.

가이드는 아래 이름으로 설정 경로를 쓰며, 예를 들면 **설정 → SmartBar**입니다.

## 전역 제공업체 설정

| 항목 | 조정하는 것 |
| --- | --- |
| [AI 모델](/ko/providers/overview) | 채팅 모델, Auto Route, 제공업체 키와 플랜 로그인, 그리고 백그라운드 작업용 **Task models**와 채팅 모델이 실패했을 때의 **대체** 모델입니다. |
| [텍스트 음성 변환](/ko/ai/text-to-speech) | 텍스트를 소리 내어 읽는 음성과 음성 복제입니다. |
| [웹 검색](/ko/ai/web-search) | 에이전트가 사용하는 검색 서비스입니다. |
| [이미지 생성](/ko/ai/image-generation) | 이미지 모델입니다. |

**설정 → 일반**에는 Enconvo의 모양과 사용 언어를 바꾸는 항목이 있습니다. 이 페이지에서 인터페이스 언어를 전환하고, Enconvo를 더 읽기 쉽게 만들고, 설정이 어디 있는지 몰라도 찾을 수 있습니다.

## 인터페이스 언어 변경

1. **설정 → 일반**을 열고 **언어**를 찾습니다.
2. **앱 언어**에서 언어를 선택합니다. **시스템 설정 따르기**는 Mac의 언어를 사용합니다.
3. Enconvo가 **응답 언어**도 같은 언어로 바꿀지 물어봅니다. 에이전트도 새 언어로 답하게 하려면 수락하세요.

**앱 언어**는 이 기기의 메뉴, 버튼, 설정을 바꿉니다. 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어, 독일어, 프랑스어, 이탈리아어, 포르투갈어, 우크라이나어, 러시아어를 지원합니다. iPhone과 Android 앱도 각 앱의 설정에서 같은 언어를 제공합니다.

**응답 언어**는 별개입니다. 에이전트, 음성 통화, 아바타가 이 언어로 답하고 번역기는 이 언어로 번역합니다.

## 모양 조정

**설정 → 일반**을 열고 **모양**을 찾습니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| **대비** | Enconvo 전체에서 테두리, 구분선, 보조 텍스트를 더 진하게 또는 더 연하게 합니다. |
| **채팅 너비** | 큰 창에서 메시지와 입력창이 넓어지는 정도입니다. **편안하게**, **넓게**, **전체** 중에서 선택합니다. |
| **코드 줄바꿈** | 코드 블록의 긴 줄을 옆으로 스크롤하지 않고 줄바꿈합니다. |

## 설정 찾기

설정 사이드바 맨 위의 검색 필드에 입력하세요. 입력하는 동안 일치하는 설정이 표시되며, 클릭하면 해당 설정으로 이동합니다.

대신 설정에 대해 질문하려면 다음과 같이 하세요.

1. 검색 필드에 질문을 입력하고 Return 키를 누르거나 **AI에게 질문**을 클릭합니다.
2. 사이드바 옆에 답변이 열리고, 언급된 설정의 카드가 함께 표시됩니다.
3. 카드의 **설정에서 보기**를 클릭하면 해당 설정으로 이동하며, 카드에서 바로 스위치를 켜고 끌 수도 있습니다.
4. **추가 질문하기…**에 후속 질문을 입력하거나, **채팅에서 계속**을 클릭해 채팅 창에서 이어 갑니다.

AI에게 질문은 기본 AI 모델을 사용합니다. 설정된 모델이 없으면 **AI 모델 설정 열기**가 표시됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 언어를 바꿨는데 일부 텍스트가 영어로 남아 있습니다 | Enconvo를 업데이트한 다음, 메뉴 막대 메뉴의 **피드백**으로 남은 부분을 알려 주세요. |
| 에이전트가 인터페이스와 다른 언어로 답합니다 | **설정 → 일반 → 언어**에서 **응답 언어**를 설정하세요. |
| AI에게 질문이 답하지 않습니다 | **설정 → AI 모델**에서 모델을 설정하세요. |
| 텍스트가 읽기 어렵습니다 | **설정 → 일반 → 모양**에서 **대비**를 높이세요. |

**설정 → 일반**에는 Enconvo의 모습과 사용하는 언어를 바꾸는 선택지가 있습니다. 이 페이지에서 인터페이스 언어를 바꾸고, 읽기 쉽게 조정하고, 어디에 있는지 몰라도 설정을 찾을 수 있습니다.

## 인터페이스 언어 바꾸기

1. **설정 → 일반**을 열고 **언어**를 찾습니다.
2. **앱 언어**에서 언어를 고릅니다. **시스템 설정 따르기**는 Mac의 언어를 사용합니다.
3. Enconvo가 **응답 언어**도 맞출지 물어봅니다. 에이전트도 새 언어로 답하게 하려면 수락하세요.

**앱 언어**는 이 기기의 메뉴, 버튼, 설정을 바꿉니다. 영어, 간체 중국어, 번체 중국어, 일본어, 한국어, 스페인어, 독일어, 프랑스어, 이탈리아어, 포르투갈어, 우크라이나어, 러시아어가 있습니다. iPhone과 Android 앱도 자체 설정에서 같은 언어를 제공합니다.

**응답 언어**는 별도입니다. 에이전트, 음성 통화, 아바타가 이 언어로 답하고, 번역기가 이 언어로 번역합니다.

## Enconvo의 모습 조정

**설정 → 일반**을 열고 **모양**을 찾습니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **대비** | Enconvo 전체에서 테두리, 구분선, 보조 텍스트를 더 또렷하거나 더 부드럽게 만듭니다. |
| **채팅 너비** | 큰 창에서 메시지와 입력창이 얼마나 넓어지는지입니다. **편안하게**, **넓게**, **전체**가 있습니다. |
| **코드 줄바꿈** | 코드 블록의 긴 줄을 가로로 스크롤하지 않고 줄바꿈합니다. |

## 설정 찾기

설정 사이드바 위쪽의 검색 칸에 입력합니다. 입력하는 동안 일치하는 설정이 나타나며, 하나를 클릭하면 그곳으로 이동합니다.

설정에 대해 질문하려면 다음을 따르세요.

1. 검색 칸에 질문을 입력하고 Return을 누르거나 **AI에게 질문**을 클릭합니다.
2. 사이드바 옆에 답이 열리고, 언급된 설정 카드가 함께 나옵니다.
3. 카드의 **설정에서 보기**를 클릭해 그 설정으로 이동하거나, 카드에서 바로 스위치를 켜거나 끕니다.
4. **추가 질문하기…**에 이어서 입력하거나, **채팅에서 계속**을 클릭해 채팅 창에서 이어 갑니다.

AI에게 질문은 기본 AI 모델을 사용합니다. 설정된 모델이 없으면 **AI 모델 설정 열기**를 제안합니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 언어를 바꾼 뒤에도 일부 텍스트가 영어로 남음 | Enconvo를 업데이트한 다음, 메뉴 막대 메뉴의 **피드백**으로 남은 부분을 알려 주세요. |
| 에이전트가 인터페이스와 다른 언어로 답함 | **설정 → 일반 → 언어**에서 **응답 언어**를 설정합니다. |
| AI에게 질문이 답하지 않음 | **설정 → AI 모델**에서 모델을 설정합니다. |
| 텍스트가 읽기 어려움 | **설정 → 일반 → 모양**에서 **대비**를 높입니다. |

Enconvo는 백그라운드에서 새 버전을 확인하고, 업데이트 채널에 더 새로운 빌드가 있으면 **업데이트** 버튼을 표시합니다. 대부분의 사용자는 프로덕션을 사용하며, 모두에게 출시되기 전에 새 기능을 써 보려면 베타로 전환하세요.

![타이틀바의 업데이트 버튼](/img/update-button-titlebar.png)

## 업데이트 채널

| 채널 | 적합한 대상 | 받는 내용 |
|---------|----------|------------------|
| **프로덕션** | 대부분의 사용자 | 베타 테스트를 거친 안정 릴리스 |
| **베타** | 얼리 테스터 | 프로덕션으로 승격되기 전의 새 빌드 |
| **개발** | 개발 테스트 | 베타와 별개로 더 자주 나오는 개발 빌드 |

<Tip>
새 기능을 미리 테스트하고 싶은 경우가 아니라면 **프로덕션**을 사용하세요. 릴리스 테스트를 돕고 있거나 안정 릴리스가 게시되기 전에 수정 사항이 필요하다면 **베타**를 사용하세요.
</Tip>

## 업데이트 채널 변경

<Steps>
  <Step title="설정 열기">
    앱 메뉴에서 Enconvo 설정을 열거나 **⌘,**를 누릅니다.
  </Step>
  <Step title="일반으로 이동">
    설정 사이드바에서 **일반**을 엽니다.
  </Step>
  <Step title="업데이트 찾기">
    **업데이트** 섹션까지 스크롤합니다.
  </Step>
  <Step title="채널 선택">
    **업데이트 채널**을 **프로덕션**, **베타**, **개발** 중 하나로 설정합니다.
  </Step>
</Steps>

새로 설치한 개발 버전은 개발 채널에서 시작하며, 이전에 선택한 채널은 그대로 유지됩니다. 채널을 바꾼다고 해서 이미 설치한 더 새로운 빌드가 반드시 다운그레이드되는 것은 아닙니다.

## 업데이트 설치

채널에 새 버전이 있으면 다음 위치에 **업데이트** 버튼이 나타납니다.

- **채팅 창** 타이틀바
- **SmartBar** 타이틀바
- **Dynamic Island**

**업데이트**를 클릭하세요. Enconvo가 새 버전을 보여 주고 다운로드, 설치, 다시 시작까지 안내합니다.

Enconvo는 채팅 창, SmartBar, Dynamic Island를 열 때 확인합니다. 네트워크 요청이 반복되지 않도록 10분 안에는 이 확인을 다시 하지 않습니다.

<Note>
자동 업데이트 다운로드는 기본적으로 꺼져 있습니다. Enconvo는 아무것도 다운로드하기 전에 업데이트가 있다는 것을 알려 주고 버튼을 표시할 수 있습니다.
</Note>

## 지금 확인

1. **설정 → 일반**을 열고 **업데이트**까지 스크롤합니다. 현재 사용 중인 버전이 표시됩니다.
2. **업데이트 확인**을 클릭합니다. 결과가 바로 그 자리에 표시됩니다.
3. 채널에 더 새로운 버전이 있으면 업데이트 안내를 따릅니다.

메뉴 막대의 Enconvo 아이콘에서 **업데이트 확인**을 선택할 수도 있습니다. 업데이트 창이 나타나지 않으면 채널에서 이미 최신 버전일 수 있습니다. **설정 → 정보**에는 버전, 빌드, 그리고 해당 채널을 사용 중일 때 **베타** 또는 **개발**이 표시됩니다.

## 새로운 기능 보기

**설정 → 튜토리얼**에서는 업데이트 영상과 단계별 안내를 Enconvo 안에서 재생하며, 아직 보지 않은 항목에는 **새 항목** 표시가 붙습니다. 채팅 창의 설정 메뉴에 있는 **새로운 기능**으로도 열 수 있습니다. 업데이트 후 Enconvo를 처음 사용하면 채팅 창 사이드바의 카드에서 해당 버전의 업데이트 영상을 볼 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 베타를 사용 중인데 베타 업데이트가 보이지 않습니다 | **설정 → 일반 → 업데이트 → 업데이트 채널**이 **베타**인지 확인한 다음 채팅 창이나 SmartBar를 다시 여세요. 백그라운드 확인은 실행 간격이 10분이므로, 방금 확인했다면 몇 분 기다려 보세요. |
| 프로덕션으로 돌아왔는데 최신 빌드가 없습니다 | 프로덕션에는 안정 채널에 게시된 빌드만 표시됩니다. 아직 베타 전용인 빌드는 프로덕션으로 승격되면 나타납니다. |
| **업데이트** 버튼이 사라졌습니다 | 업데이트가 이미 설치되었거나 닫혔거나 더 이상 채널과 맞지 않을 수 있습니다. **설정 → 일반 → 업데이트**에서 **업데이트 확인**을 클릭해 확인하세요. |
| 업데이트 안내가 열리지 않습니다 | Enconvo를 종료했다가 다시 열고 **업데이트 확인**을 다시 실행하세요. 네트워크가 Enconvo의 릴리스 서버에 접속할 수 있는지도 확인하세요. |

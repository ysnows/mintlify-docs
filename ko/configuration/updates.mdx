Enconvo는 배경에서 새 버전을 확인하고, 업데이트 채널에 더 새 빌드가 있으면 **업데이트** 버튼을 보여 줍니다. 대부분은 프로덕션에 머뭅니다. 모두에게 나오기 전에 새 기능을 쓰려면 베타로 바꾸세요.

![제목 표시줄의 업데이트 버튼](/img/update-button-titlebar.png)

## 업데이트 채널

| 채널 | 적합한 경우 | 받는 것 |
|---------|----------|------------------|
| **프로덕션** | 대부분의 사용자 | 베타 테스트 뒤의 안정 릴리스 |
| **베타** | 얼리 테스터 | 프로덕션으로 승격되기 전의 새 빌드 |
| **개발** | 개발 테스트 | 베타와 별개인, 더 자주 나오는 개발 빌드 |

<Tip>
새 기능을 일찍 시험하고 싶지 않다면 **프로덕션**을 쓰세요. 릴리스 테스트를
돕거나 안정 릴리스가 나오기 전에 수정이 필요하면 **베타**를 쓰세요.
</Tip>

## 업데이트 채널 바꾸기

<Steps>
  <Step title="설정 열기">
    앱 메뉴에서 Enconvo 설정을 열거나 **⌘,**를 누르세요.
  </Step>
  <Step title="일반으로 이동">
    설정 사이드바에서 **일반**을 엽니다.
  </Step>
  <Step title="업데이트 찾기">
    **업데이트** 섹션까지 스크롤합니다.
  </Step>
  <Step title="채널 고르기">
    **업데이트 채널**을 **프로덕션**, **베타**, **개발** 중 하나로 설정합니다.
  </Step>
</Steps>

새로 설치한 개발 빌드는 개발 채널에서 시작합니다. 이전에 고른 채널은 그대로 유지됩니다. 채널을 바꿔도 이미 가진 더 새 빌드가 반드시 내려가지는 않습니다.

## 업데이트 설치

채널에 새 버전이 있으면 **업데이트** 버튼이 다음에 나타납니다.

- **채팅 창** 제목 표시줄
- **SmartBar** 제목 표시줄
- **Dynamic Island**

**업데이트**를 클릭하세요. Enconvo가 새 버전을 보여 주고 다운로드, 설치, 다시 실행을 안내합니다.

Enconvo는 채팅 창, SmartBar, Dynamic Island를 열 때 확인합니다. 네트워크 요청이 반복되지 않도록, 10분에 한 번보다 자주 확인하지는 않습니다.

<Note>
자동 업데이트 다운로드는 기본적으로 꺼져 있습니다. Enconvo는 아무것도 받기 전에
업데이트가 있다고 알리고 버튼을 보여 줄 수 있습니다.
</Note>

## 지금 확인

1. **설정 → 일반**을 열고 **업데이트**까지 스크롤하세요. 현재 버전이 표시됩니다.
2. **업데이트 확인**을 클릭하세요. 결과가 그 자리에 나옵니다.
3. 채널에 더 새 버전이 있으면 업데이트 안내를 따르세요.

메뉴 막대의 Enconvo 아이콘에서 **업데이트 확인**을 골라도 됩니다. 업데이트 창이 안 열리면 이미 해당 채널의 최신 버전일 수 있습니다. **설정 → 정보**에 버전, 빌드, 그리고 해당 채널이면 **베타** 또는 **개발**이 표시됩니다.

## 새로운 내용 보기

**설정 → 튜토리얼**은 Enconvo 안에서 업데이트 영상과 단계별 안내를 재생하고, 아직 안 본 항목에 **새로운 기능**을 표시합니다. 채팅 창 설정 메뉴의 **새로운 기능**으로도 열 수 있습니다. 업데이트 뒤 Enconvo를 처음 쓰면 채팅 창 사이드바 카드가 그 버전의 업데이트 영상을 제안합니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 베타인데 베타 업데이트가 안 보임 | **설정 → 일반 → 업데이트 → 업데이트 채널**이 **베타**인지 확인한 뒤 채팅 창이나 SmartBar를 다시 여세요. 배경 확인은 실행 사이 10분을 기다리므로, 방금 확인했다면 몇 분 주세요. |
| 프로덕션으로 돌아왔는데 최신 빌드가 없음 | 프로덕션은 안정 채널에 게시된 빌드만 보여 줍니다. 아직 베타 전용인 빌드는 프로덕션으로 승격된 뒤에 나타납니다. |
| **업데이트** 버튼이 사라짐 | 이미 설치됐거나 닫혔거나, 더 이상 채널과 맞지 않을 수 있습니다. **설정 → 일반 → 업데이트**에서 **업데이트 확인**을 클릭해 확인하세요. |
| 업데이트 안내가 열리지 않음 | Enconvo를 종료했다가 다시 연 뒤 **업데이트 확인**을 다시 실행하세요. 네트워크가 Enconvo 릴리스 서버에 닿는지도 확인하세요. |

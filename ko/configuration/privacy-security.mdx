Enconvo는 데이터를 Mac에 저장하고, 선택한 기능과 제공업체를 위해 온라인 서비스를 사용합니다. 요청이 어디로 가는지는 기능, 선택한 제공업체, 켜 둔 도구, 연결한 통합에 따라 달라집니다. 이 페이지에서는 각 흐름과 그에 대한 제어 방법을 보여 줍니다.

## 내 콘텐츠가 전송되는 곳

| 동작 | 전송되는 내용과 대상 |
| --- | --- |
| 클라우드 AI 채팅 | 프롬프트, 대화 컨텍스트, 첨부한 파일을 모델 제공업체로 전송 |
| Enconvo Cloud 콘텐츠 검사 (2026년 11월 14일부터) | Cloud 모델이 받기 전에, 방금 작성한 텍스트를 OpenAI의 검수 모델로 전송 |
| 클라우드 음성 인식 | 캡처한 오디오를 선택한 음성 서비스로 전송 |
| 클라우드 텍스트 음성 변환 | 텍스트를 선택한 음성 서비스로 전송 |
| 클라우드 임베딩 또는 재순위 지정 | 검색에 필요한 문서와 쿼리 내용 |
| 웹 검색 또는 가져오기 | 검색어나 URL을 검색 서비스 또는 웹사이트로 전송 |
| 로컬 모델 추론 | Mac에 머무름: 모델 파일을 다운로드하면 모델이 Mac에서 실행됨 |
| 브라우저 또는 컴퓨터 도구 | 도구에 허용된 접근 권한이 허용하는 모든 콘텐츠와 동작 |
| IM 채널 | 연결된 메시징 서비스와 에이전트 사이의 메시지 |
| 동기화 | 동기화를 켜면 채팅, 설정, 지식 베이스, 아티팩트를 Enconvo 계정이나 iCloud로 전송합니다. API 키는 켠 경우에만 암호화된 상태로 Mac을 떠납니다. |

로컬 채팅 모델만 쓴다고 해서 모든 도구가 오프라인으로 작동하는 것은 아닙니다. 웹 검색, 원격 MCP 도구, 클라우드 음성 인식 제공업체, 클라우드 임베딩 모델은 여전히 네트워크로 콘텐츠를 전송합니다.

## Enconvo Cloud 이용 규칙

2026년 11월 14일부터 Enconvo Cloud는 각 메시지가 Cloud 모델에 도달하기 전에 [이용약관](https://www.enconvo.com/terms)에 맞는지 검사합니다. 방금 작성한 텍스트만 검사하며, 이전 대화, 파일, 이미지는 검사하지 않습니다. 직접 발급한 API 키나 로컬 모델을 사용할 때는 달라지는 것이 없습니다.

- **보관되는 정보:** 메시지가 거부되거나 표시되면 Enconvo는 계정, 시간, 모델, 점수를 최대 90일 동안 보관하며 메시지 내용은 보관하지 않습니다.
- **거부된 메시지:** 모델에 전달되지 않고 포인트도 차감되지 않습니다. 채팅에 이유가 표시됩니다.
- **반복된 거부:** 계정의 Cloud AI가 일시 중지될 수 있습니다. 로그인, 구독 관리 또는 취소, 계정 삭제는 계속할 수 있습니다. 구독은 취소하기 전까지 계속 유지됩니다.
- **잘못 판단했다면:** support@enconvo.com으로 문의해 주세요.

제공업체의 안전 조치가 모든 사용자가 아닌 한 계정에만 적용되도록, Enconvo Cloud는 요청마다 OpenAI와 Anthropic에 계정에서 만든 단방향 식별자도 함께 보냅니다. 이메일 주소가 아닙니다. 자세한 내용은 [개인정보 처리방침](https://www.enconvo.com/privacy)을 참고하세요.

## 전송할 내용 제어

요청을 보내기 전에 첨부 파일과 컨텍스트를 살펴보세요. Appshots, 스크린샷, 선택한 텍스트, 클립보드 내용, 브라우저 페이지에는 질문하려는 문장보다 더 많은 정보가 들어 있을 수 있습니다.

컨텍스트 소스는 [컨텍스트 인식](/ko/features/context-awareness)에서 선택합니다. [macOS 권한](/ko/configuration/permissions)은 사용하는 기능에만 허용하고, 더 이상 필요하지 않으면 시스템 설정에서 해제하세요.

## 자격 증명

API 키와 계정 로그인은 각 제공업체의 **인증** 섹션과 [인증 정보 관리](/ko/configuration/credentials)에서 관리합니다. 로컬 Enconvo 구성, 백업, 내보낸 설정, 지원용 로그는 민감한 정보로 취급하고, 키와 계정 토큰이 프롬프트, 스크린샷, 공유 파일에 들어가지 않게 하세요.

제공업체 프로필은 자격 증명을 여러 기능에서 공유할 수 있습니다. 프로필을 삭제하거나 교체하기 전에 그 프로필을 쓰는 모든 기능을 확인하세요.

<Warning>
Enconvo에서 키를 삭제해도 키가 폐기되지는 않습니다. 키가 유출되었다면 제공업체의 사이트에서 직접 폐기하세요.
</Warning>

## 도구 및 통합

에이전트는 사용자가 켜 둔 도구를 통해 동작할 수 있습니다. 브라우저 제어, 컴퓨터 사용, 셸 명령, 파일 편집, Gmail, 외부 MCP 서버는 각각 접근하는 대상이 다릅니다. 중요한 데이터를 다룰 때는 에이전트의 도구와 에이전트가 제안하는 동작을 확인하세요.

확장 프로그램을 자체 워커에서 실행하더라도 로컬 파일이나 네트워크에 접근하는 것까지 막지는 못합니다. 신뢰할 수 있는 출처의 도구를 설치하고 구성을 확인하세요.

채팅의 **권한** 칩은 에이전트가 동작하기 전에 언제 확인을 요청할지 정합니다. **전체 접근**에서는 친구와 팀원에게 거는 전화와 보내는 메시지를 포함해 확인 없이 동작하며, 컴퓨터에 해를 끼칠 수 있는 변경 전에만 확인을 요청합니다. [명령 전에 Enconvo가 확인하는 이유](/ko/configuration/sandbox)를 참고하세요.

에이전트의 셸 명령을 작업 폴더 안에 두고 키, 저장된 자격 증명, 다른 앱에서 떨어뜨려 놓으려면 에이전트의 **샌드박스**를 켜세요. [에이전트 샌드박스](/ko/configuration/sandbox)를 참고하세요. 컴퓨터 사용이 특정 앱에 접근하지 못하게 하려면 **설정 → 컴퓨터 사용**의 **앱 접근**을 사용하세요. [컴퓨터 사용](/ko/features/computer-use)을 참고하세요.

웹 페이지 가져오기는 공개 페이지가 사용자의 Mac이나 로컬 네트워크로 리디렉션할 수 없습니다.

## 로그인 링크

웹 페이지의 로그인 링크가 스스로 Enconvo를 다른 계정으로 전환할 수는 없습니다. Enconvo가 직접 시작한 로그인이 아니면 먼저 확인을 요청하며, 링크가 확인하는 계정과 교체될 계정을 보여 줍니다. 에이전트, 코딩 에이전트, 예약 작업은 로그인을 시작하거나 로그인 링크를 열 수 없습니다.

## 로컬 AI 클라이언트

[Knowledge Base MCP](/ko/advanced/knowledge-base-mcp)는 켜기 전까지 꺼져 있으며 로컬 연결을 받습니다. 공개 스위치로 어떤 지식 베이스를 노출할지 선택합니다. 로컬 클라이언트는 검색한 내용을 자체 AI 제공업체로 보낼 수 있으므로 그 클라이언트도 신중하게 설정하세요.

## 분석 및 진단

Enconvo는 계정이 아닌 기기 ID로 제품 사용 이벤트를 기록합니다. 이벤트에는 이메일 주소, 대화 텍스트, 미디어가 포함되지 않도록 설계되어 있습니다. 공유를 중지하려면 첫 실행 안내 또는 **설정 → 일반**의 **개인정보 보호**에서 **익명 제품 분석 데이터 공유**를 끄세요. 이전에 선택한 내용은 그대로 유지됩니다. 충돌 및 멈춤 보고서는 이 스위치가 켜져 있을 때만 전송되며 사용자의 콘텐츠는 포함되지 않습니다.

Enconvo는 AI 요청, 메시지, 입력한 내용의 사본을 Mac의 로그에 보관하지 않습니다.

진단 로그는 분석과 별개입니다. Enconvo가 멈추거나, 충돌하거나, 오작동할 때 메뉴 막대 메뉴의 **진단 정보 제출…** 또는 **설정 → 진단**에서 Enconvo 팀에 보낼 수 있습니다.

- 무엇이든 Mac을 떠나기 전에 Enconvo는 홈 폴더 이름, 파일 이름, 이메일 주소, API 키, 토큰, 링크, IP 주소, 프롬프트와 답변 텍스트 같은 개인 정보를 제거합니다.
- 보고서에는 진단용으로만 만든 무작위 ID가 포함되며 계정이나 이메일은 포함되지 않습니다. Enconvo 팀만 읽을 수 있고, 정해진 일수가 지나면 삭제됩니다.
- 로그에는 사용한 앱, 명령, 모델의 이름이 여전히 포함될 수 있습니다.
- 페이지에서 전송된 내용을 정확히 볼 수 있으며, 각 보고서를 철회하거나 삭제할 수 있습니다.

다른 방식으로 로그나 스크린샷을 공유할 때는 먼저 살펴보고, 필요하지 않은 비공개 프롬프트, 경로, 키, 계정 정보, 문서 내용을 제거하세요.

## 로컬 데이터 보관 또는 삭제

각 기능은 자체 데이터를 관리합니다. 채팅 기록, 지식 베이스, 녹음, 자격 증명에는 각각 별도의 제어 기능이 있습니다. 삭제 확인 내용을 읽고, 필요한 것은 백업해 두세요. 채팅을 삭제하면 다른 채팅에서 여전히 표시하는 경우를 제외하고, 첨부한 사진과 파일도 함께 삭제됩니다.

앱을 삭제해도 구성과 데이터가 항상 함께 삭제되는 것은 아닙니다. 로컬 데이터를 삭제해도 외부 서비스가 이미 처리한 사본은 삭제되지 않습니다. 제공업체의 보관 및 계정 정책은 해당 제공업체를 확인하세요. 이 페이지는 제공업체가 아닌 Enconvo의 데이터 흐름을 다룹니다.

Enconvo는 데이터를 Mac에 저장하고, 선택한 기능과 제공업체를 위해 온라인 서비스를 사용합니다. 요청이 어디로 가는지는 기능, 고른 제공업체, 켠 도구, 연결한 연동에 따라 달라집니다. 이 페이지는 각 흐름과 그 제어를 보여 줍니다.

## 콘텐츠가 가는 곳

| 동작 | 무엇이 어디로 보내지는지 |
| --- | --- |
| 클라우드 AI 채팅 | 프롬프트, 대화 컨텍스트, 첨부한 파일이 모델 제공업체로 |
| Enconvo Cloud 콘텐츠 검사, 2026년 11월 14일부터 | 방금 쓴 텍스트가 클라우드 모델에 가기 전에 OpenAI 조정 모델로 |
| 클라우드 음성 인식 | 캡처한 오디오가 고른 음성 서비스로 |
| 클라우드 텍스트 음성 변환 | 텍스트가 고른 음성 서비스로 |
| 클라우드 임베딩 또는 재순위 | 검색에 필요한 문서와 질의 내용 |
| 웹 검색 또는 가져오기 | 검색어나 URL이 검색 서비스 또는 웹사이트로 |
| 로컬 모델 추론 | Mac에 남음. 파일을 내려받은 뒤 모델이 그 Mac에서 실행됨 |
| 브라우저 또는 컴퓨터 도구 | 도구에 허용된 접근이 허락하는 콘텐츠와 동작 |
| 메신저 채널 | 연결된 메시징 서비스와 에이전트 사이의 메시지 |
| 동기화 | 동기화를 켜면 채팅, 설정, 지식 베이스, 아티팩트가 Enconvo 계정 또는 iCloud로. API 키는 켠 뒤에만, 암호화된 채로 Mac을 떠남. |

로컬 채팅 모델만으로는 모든 도구가 오프라인이 되지 않습니다. 웹 검색, 원격 MCP 도구, 클라우드 음성 텍스트 변환 제공업체, 클라우드 임베딩 모델은 여전히 네트워크로 콘텐츠를 보냅니다.

## Enconvo Cloud 이용 규칙

2026년 11월 14일부터 Enconvo Cloud는 각 메시지를 클라우드 모델에 보내기 전에 [이용 약관](https://www.enconvo.com/terms)과 대조합니다. 검사되는 것은 방금 쓴 텍스트뿐이며, 이전 대화, 파일, 이미지는 검사하지 않습니다. 자신의 API 키나 로컬 모델을 쓰면 달라지는 것은 없습니다.

- **보관되는 것:** 메시지가 거부되거나 표시되면 Enconvo는 계정, 시각, 모델, 점수를 최대 90일 보관하며, 단어는 보관하지 않습니다.
- **거부된 메시지:** 모델에 도달하지 않으며 포인트도 쓰지 않습니다. 채팅에 이유가 표시됩니다.
- **반복 거부:** 계정의 클라우드 AI가 일시 중지될 수 있습니다. 로그인, 구독 관리나 취소, 계정 삭제는 계속할 수 있습니다. 구독은 취소할 때까지 유지됩니다.
- **잘못 판단된 경우:** support@enconvo.com으로 쓰세요.

제공업체의 안전 조치가 모든 사람이 아니라 한 계정에 적용되도록, Enconvo Cloud는 각 요청과 함께 계정에서 만든 단방향 식별자를 OpenAI와 Anthropic에 보냅니다. 이메일 주소가 아닙니다. 자세한 내용은 [개인정보 처리방침](https://www.enconvo.com/privacy)에 있습니다.

## 보내는 내용 제어

요청을 보내기 전에 첨부와 컨텍스트를 살펴보세요. Appshots, 스크린샷, 선택한 텍스트, 클립보드, 브라우저 페이지에는 묻고 싶은 문장보다 많은 내용이 들어 있을 수 있습니다.

컨텍스트 출처는 [컨텍스트 인식](/ko/features/context-awareness)에서 고르세요. [macOS 권한](/ko/configuration/permissions)은 쓰는 기능에만 부여하고, 더 이상 필요 없으면 시스템 설정에서 철회하세요.

## 자격 증명

API 키와 계정 로그인은 각 제공업체의 **인증** 섹션과 [자격 증명 관리](/ko/configuration/credentials)에서 관리합니다. 로컬 Enconvo 설정, 백업, 내보낸 설정, 지원 로그를 민감한 정보로 다루고, 키와 계정 토큰을 프롬프트, 스크린샷, 공유 파일에 넣지 마세요.

제공업체 프로필은 여러 기능에서 자격 증명을 공유할 수 있습니다. 삭제하거나 바꾸기 전에 그 프로필을 쓰는 모든 기능을 확인하세요.

<Warning>
Enconvo에서 키를 제거해도 키가 폐기되지는 않습니다. 키가 유출되면 제공업체 사이트에서 폐기하세요.
</Warning>

## 도구와 연동

에이전트는 켠 도구를 통해 행동할 수 있습니다. 브라우저 제어, 컴퓨터 사용, 쉘 명령, 파일 편집, Gmail, 외부 MCP 서버는 각각 다른 곳에 닿습니다. 중요한 데이터를 다룰 때는 에이전트의 도구와 제안하는 동작을 확인하세요.

확장을 자체 워커에서 실행해도 로컬 파일이나 네트워크에 닿는 것을 막지는 않습니다. 신뢰하는 출처에서 도구를 설치하고 설정을 확인하세요.

채팅의 **권한** 칩은 에이전트가 행동하기 전에 언제 묻는지 결정합니다. **전체 접근**에서는 묻지 않고 행동하며, 친구와 팀원에게 전화와 메시지를 보내는 것도 포함되고, 컴퓨터를 해칠 수 있는 변경 전에만 묻습니다. [명령 전에 Enconvo가 묻는 이유](/ko/configuration/sandbox)를 보세요.

에이전트의 쉘 명령을 작업 폴더 안에 가두고 키, 저장된 자격 증명, 다른 앱에서 떨어뜨리려면 **Sandbox**를 켜세요. [에이전트 Sandbox](/ko/configuration/sandbox)를 보세요. 컴퓨터 사용을 특정 앱에서 막으려면 **설정 → 컴퓨터 사용**의 **앱 접근**을 쓰세요. [컴퓨터 사용](/ko/features/computer-use)을 보세요.

웹 가져오기는 공개 페이지가 Mac이나 로컬 네트워크로 리다이렉트할 수 없습니다.

## 로그인 링크

웹 페이지의 로그인 링크만으로는 Enconvo가 다른 계정으로 바뀌지 않습니다. Enconvo가 직접 로그인을 시작하지 않았다면, 먼저 묻고 링크가 확인하는 계정과 바꿀 계정을 보여 줍니다. 에이전트, 코딩 에이전트, 예약된 작업은 로그인을 시작하거나 로그인 링크를 열 수 없습니다.

## 로컬 AI 클라이언트

[지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)는 켜기 전까지 꺼져 있으며, 로컬 연결만 받습니다. 표시 스위치로 어떤 지식 베이스를 노출할지 고릅니다. 로컬 클라이언트는 가져온 내용을 자신의 AI 제공업체로 보낼 수 있으므로, 그 클라이언트도 신중히 설정하세요.

## 분석과 진단

Enconvo는 계정이 아니라 기기 ID로 제품 사용 이벤트를 기록합니다. 이벤트는 이메일 주소, 대화 텍스트, 미디어를 빼도록 설계되어 있습니다. 공유를 멈추려면 첫 실행 가이드에서, 또는 **설정 → 일반**의 **개인정보**에서 **익명 제품 분석 공유**를 끄세요. 이전에 한 선택은 그대로 유지됩니다. 충돌과 멈춤 보고는 그 스위치가 켜져 있을 때만 보내지며, 콘텐츠는 포함하지 않습니다.

Enconvo는 Mac의 로그에 AI 요청, 메시지, 입력한 내용의 사본을 보관하지 않습니다.

진단 로그는 분석과 별개입니다. Enconvo가 멈추거나 충돌하거나 이상하게 동작하면 메뉴 막대 메뉴의 **진단 제출…**, 또는 **설정 → 진단**에서 Enconvo 팀에 보내세요.

- Mac을 떠나기 전에 Enconvo는 홈 폴더 이름, 파일 이름, 이메일 주소, API 키, 토큰, 링크, IP 주소, 프롬프트와 답변 텍스트 같은 개인 정보를 제거합니다.
- 보고에는 진단용으로만 만든 임의 ID가 실리며, 계정이나 이메일은 아닙니다. Enconvo 팀만 읽을 수 있고, 정해진 날수가 지나면 삭제됩니다.
- 로그에는 사용한 앱, 명령, 모델 이름이 남을 수 있습니다.
- 페이지에는 보낸 내용이 그대로 보이며, 각 보고를 철회하거나 삭제할 수 있습니다.

다른 방법으로 로그나 스크린샷을 공유할 때는 먼저 살펴보고, 필요 없는 비공개 프롬프트, 경로, 키, 계정 정보, 문서 내용을 지우세요.

## 로컬 데이터 유지 또는 삭제

각 기능은 자신의 데이터를 관리합니다. 채팅 기록, 지식 베이스, 녹음, 자격 증명은 각자 제어가 있습니다. 삭제 확인을 읽고, 필요한 것은 백업하세요. 채팅을 삭제하면 다른 채팅이 아직 보여 주지 않는 한, 그 채팅에 첨부한 그림과 파일도 삭제됩니다.

앱을 제거해도 설정과 데이터가 항상 지워지지는 않습니다. 로컬 데이터를 제거해도 외부 서비스가 이미 처리한 사본은 삭제되지 않습니다. 제공업체의 보관과 계정 정책은 해당 제공업체를 보세요. 이 페이지는 Enconvo의 데이터 흐름을 다루며, 제공업체의 흐름은 다루지 않습니다.

---

코드 모드를 사용하면 에이전트가 원래 여러 단계가 필요한 일을 한 단계에 처리할 수 있습니다. 에이전트는 여러 도구 호출을 나란히 또는 순서대로 수행하는 짧은 스크립트를 작성하고, 결과만 읽어 옵니다. 페이지 목록 확인이나 여러 서비스의 결과 수집처럼 같은 호출을 많은 항목에 반복하는 작업에 사용하면 작업이 더 빨라지고, 중간 결과가 채팅을 가득 채우지도 않습니다.

코드 모드를 직접 호출할 필요는 없습니다. 켜져 있으면 에이전트가 작업에 맞을 때마다 사용하며, 채팅에는 스크립트가 수행한 호출이 담긴 카드가 표시됩니다.

## 코드 모드 설정하기

1. **설정 → 코드 모드**를 여세요. 플러그인 페이지의 **기본 제공** 탭에서 **코드 모드**를 열 수도 있습니다.
2. **스크립트 접근**에서 스크립트가 호출할 수 있는 항목을 켜세요. 각 호출은 채팅의 [권한 모드](/ko/ai/agents)에 따라 여전히 사용자에게 먼저 묻습니다.
3. 스크립트를 작성할 수 있는 모델, 채팅에 표시할 내용, 스크립트가 오래 걸릴 때의 동작을 선택하세요.

## 설정

**스크립트 접근**에는 스크립트가 호출할 수 있는 항목이 나열됩니다.

| 접근 | 허용하는 것 | 기본값 |
| --- | --- | --- |
| **플러그인** | 검색, 지식 베이스, 문서 및 기타 플러그인 라우트 | 켜짐 |
| **Connector 및 MCP** | 연결된 계정과 MCP 도구 | 켜짐 |
| **파일** | 파일 읽기와 쓰기 | 켜짐 |
| **셸 명령** | 터미널에서 명령 실행 | 켜짐 |
| **브라우저** | 내 브라우저에서의 [브라우저 사용](/ko/features/browser-control) | 켜짐 |
| **앱** | 앱 접근 목록 범위 내의 [컴퓨터 사용](/ko/features/computer-use) | 켜짐 |
| **다른 에이전트** | 하위 에이전트 시작 또는 메시지 보내기 | 꺼짐 |
| **모델 호출** | 항목을 요약하거나 판단하는 작은 모델 | 켜짐 |

기타 옵션:

| 옵션 | 선택지 |
| --- | --- |
| **사용 대상** | **코드를 잘 쓰는 모델**(다른 모델은 호출을 하나씩 수행) 또는 **모든 모델**. |
| **채팅에 표시** | **호출** 또는 **호출과 코드**. |
| **스크립트가 오래 걸릴 때** | 백그라운드에서 **최대 2시간까지 계속** 또는 **10분 후 중지**. |

## 채팅 밖의 코드 모드

자동화처럼 채팅 밖에서 스크립트를 실행하면 읽기만 하는 도구만 호출합니다. 기본 제공 검색과 읽기, 공개 웹 페이지, 일반 파일, 무언가를 변경한다고 밝히지 않은 MCP 도구가 해당합니다. Enconvo는 각 호출을 실행하기 직전에 다시 확인합니다.

## 스킬에서 스크립트 사용하기

스킬은 코드 모드 스크립트를 자체 `scripts` 폴더에 두고 단계 중 하나로 실행할 수 있습니다. [스킬](/ko/configuration/skills)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 에이전트가 호출을 하나씩 수행함 | **사용 대상**을 확인하세요. **코드를 잘 쓰는 모델**이면 다른 모델은 코드 모드를 사용하지 않습니다. |
| 스크립트가 도구에 접근하지 못함 | **스크립트 접근**에서 해당 종류의 접근을 켜세요. 채팅 밖에서는 스크립트가 읽기만 합니다. |
| 긴 스크립트가 중단됨 | **10분 후 중지**이면 더 긴 스크립트는 종료됩니다. **최대 2시간까지 계속**을 선택하세요. |

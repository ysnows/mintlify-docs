코드 모드를 사용하면 에이전트가 여러 단계에 걸쳐 해야 할 일을 한 번에 처리할 수 있습니다. 여러 도구를 나란히 또는 순서대로 호출하는 짧은 스크립트를 직접 작성해 실행하고, 최종 결과만 돌려받습니다. 페이지 목록을 일일이 확인하거나 여러 서비스에서 결과를 모으는 것처럼 같은 호출을 반복하는 작업에서 속도를 높이고 중간 결과로 채팅창이 가득 차는 것을 막고 싶을 때 유용합니다.

코드 모드는 사용자가 직접 호출하는 기능이 아닙니다. 켜 두면 작업에 어울릴 때 에이전트가 알아서 사용하며, 채팅에는 스크립트가 호출한 도구 목록 카드가 표시됩니다.

## 코드 모드 설정하기

1. **설정 → 코드 모드**를 엽니다. 플러그인 페이지의 **내장** 탭에서도 **코드 모드**를 열 수 있습니다.
2. **스크립트 접근** 아래에서 스크립트가 호출할 수 있는 항목을 켭니다. 각 호출은 여전히 채팅의 [권한 모드](/ko/ai/agents)에 따라 사용자에게 확인을 요청합니다.
3. 어떤 모델이 스크립트를 쓸 수 있는지, 채팅에 무엇을 표시할지, 스크립트가 오래 실행될 때 어떻게 처리할지 고릅니다.

## 설정

**스크립트 접근**에는 스크립트가 호출할 수 있는 대상이 나열됩니다.

| 접근 대상 | 허용되는 작업 | 기본값 |
| --- | --- | --- |
| **플러그인** | 검색, 지식 베이스, 문서 및 기타 플러그인 라우트 | 켜짐 |
| **커넥터 및 MCP** | 연결된 계정 및 MCP 도구 | 켜짐 |
| **파일** | 파일 읽기 및 쓰기 | 켜짐 |
| **셸 명령** | 터미널에서 명령 실행 | 켜짐 |
| **브라우저** | 본인 브라우저에서 [브라우저 사용](/ko/features/browser-control) 실행 | 켜짐 |
| **앱** | 앱 접근 목록 내에서의 [컴퓨터 사용](/ko/features/computer-use) | 켜짐 |
| **다른 에이전트** | 하위 에이전트 시작 또는 메시지 전송 | 꺼짐 |
| **모델 호출** | 항목을 요약하거나 판단하는 소형 모델 호출 | 켜짐 |

그 밖의 옵션:

| 옵션 | 선택 항목 |
| --- | --- |
| **사용 대상** | **코드를 잘 작성하는 모델**(나머지는 도구를 하나씩 호출) 또는 **모든 모델**. |
| **채팅에 표시** | **호출 목록** 또는 **호출 목록 및 코드**. |
| **스크립트 실행이 길어질 때** | 백그라운드에서 **계속 실행(최대 2시간)** 또는 **10분 후 중지**. |

## 채팅 밖에서의 코드 모드

자동화처럼 채팅 밖에서 스크립트가 실행될 때는 읽기 전용 도구만 호출합니다: 내장 검색 및 읽기, 공개 웹 페이지, 일반 파일, 변경 작업을 수행한다고 명시되지 않은 MCP 도구만 허용됩니다. Enconvo는 실행 직전에 각 호출을 다시 한 번 검사합니다.

## 스킬에서 스크립트 사용하기

스킬의 자체 `scripts` 폴더에 코드 모드 스크립트를 보관하고 스킬의 단계 중 하나로 실행할 수 있습니다. [스킬](/ko/configuration/skills)을 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 에이전트가 도구를 하나씩 호출함 | **사용 대상**을 확인하세요. **코드를 잘 작성하는 모델**로 되어 있으면 다른 모델은 코드 모드를 사용하지 않습니다. |
| 스크립트가 도구에 접근하지 못함 | **스크립트 접근** 아래에서 해당 접근 권한을 켜세요. 채팅 밖에서는 읽기만 허용됩니다. |
| 오래 걸리는 스크립트가 멈춤 | **10분 후 중지**가 선택되어 있으면 그보다 긴 스크립트는 종료됩니다. **계속 실행(최대 2시간)**을 선택하세요. |

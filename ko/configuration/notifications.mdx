Enconvo는 에이전트 세션이 끝나면 Dynamic Island를 열거나, macOS 알림을 보내거나, 둘 다로 알려 줄 수 있습니다. **설정 → 알림**에서 이를 설정하며, 방해받고 싶지 않은 시간을 위한 방해 금지 시간도 여기서 정합니다.

## 완료 알림 설정

1. **설정 → 알림**을 엽니다.
2. 페이지에 **Enconvo 알림이 꺼져 있습니다**라고 표시되면 **활성화**를 클릭하거나 **시스템 설정 → 알림**에서 Enconvo를 허용합니다.
3. **세션 완료 시**에서 각 스위치를 켜거나 끕니다. 스위치는 서로 독립적으로 작동합니다.
4. 짧은 에이전트 요청을 시작하고 끝날 때까지 기다립니다.

| 설정 | 기능 |
| --- | --- |
| **Dynamic Island 열기** | Dynamic Island에서 시작한 세션이 끝나면 아일랜드가 확장되어 결과를 보여 줍니다. |
| **시스템 알림 보내기** | 세션이 끝나면 답변의 앞부분을 담은 macOS 알림을 보냅니다. 알림을 클릭하면 세션을 시작한 창에서 세션이 다시 열립니다. |

이 스위치가 켜져 있어도 macOS 집중 모드와 알림 설정 때문에 배너가 표시되지 않을 수 있습니다.

## 방해 금지 시간

방해 금지 시간에는 에이전트의 질문, Mail 알림, 완료된 작업이 이 Mac과 페어링한 iPhone에서 방해 금지 시간이 끝날 때까지 보류됩니다. 보류되는 동안 사용자 대신 승인되는 것은 없습니다.

1. **설정 → 알림**에서 **소식**을 찾습니다.
2. **방해 금지 시간**을 켜고 **시작 시간**과 **종료 시간**을 설정합니다.
3. 계속 알림을 받을 항목을 선택합니다.

| 설정 | 기능 |
| --- | --- |
| **승인 요청은 계속 알림** | 방해 금지 시간에도 승인 요청이 계속 전달됩니다. |
| **질문은 계속 알림** | 방해 금지 시간에도 에이전트의 질문이 계속 전달됩니다. |

Enconvo 메뉴 막대 메뉴에도 **방해 금지 시간**과, 잠시 쉴 수 있는 **소식 1시간 일시 중지**가 있습니다.

Mail 알림은 **예약 작업 → 중요한 메일**에서 켜기 전까지 꺼져 있습니다. 이미 켜 두었거나 설정해 둔 Mail 알림은 계속 작동합니다. 해당 알림의 **휴대전화** 스위치는 페어링한 iPhone이나 Android 휴대전화로 알림을 보냅니다.

## 예약 작업 결과

시스템 알림은 예약 작업의 결과를 Telegram이나 다른 IM 채팅으로 보내는 것과 다릅니다. 결과 전달은 [예약 작업](/ko/workflows/scheduled-jobs)의 편집기에서 설정합니다.

예약 작업은 실행될 때 자체 Mac 알림을 보낼 수도 있습니다(**실행 시 알림 받기**). 이 알림도 **시스템 알림 보내기**를 따릅니다. 작업의 실행 기록에는 각 실행이 성공했는지, 결과가 전달되었는지 표시됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 세션이 끝나도 배너가 표시되지 않습니다 | **시스템 알림 보내기**가 켜져 있는지, macOS가 Enconvo의 알림을 허용하는지, 집중 모드가 알림을 숨기고 있지 않은지 확인하세요. |
| Dynamic Island가 열리지 않았습니다 | **Dynamic Island 열기**는 Dynamic Island에서 시작한 세션에만 적용됩니다. |
| 질문이나 완료된 작업이 늦게 도착했습니다 | 방해 금지 시간이 보류했을 수 있습니다. **질문은 계속 알림**을 켜거나 **시작 시간**과 **종료 시간**을 변경하세요. |

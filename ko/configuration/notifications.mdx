Enconvo는 에이전트 세션이 끝나면 Dynamic Island를 열거나 macOS 알림을 보내거나 둘 다 할 수 있습니다. **설정 → 알림**에서 설정하며, 방해받고 싶지 않은 시간에는 방해 금지도 둘 수 있습니다.

## 완료 알림 설정

1. **설정 → 알림**을 엽니다.
2. 페이지에 **Enconvo의 알림이 꺼져 있습니다**라고 나오면 **사용**을 클릭하거나, **시스템 설정 → 알림**에서 Enconvo를 허용합니다.
3. **세션 완료 시** 아래에서 각 스위치를 켜거나 끕니다. 서로 독립적으로 동작합니다.
4. 짧은 에이전트 요청을 시작하고 끝날 때까지 기다립니다.

| 설정 | 하는 일 |
| --- | --- |
| **Dynamic Island 열기** | Dynamic Island에서 시작한 세션이 끝나면 아일랜드가 펼쳐져 결과를 보여 줍니다. |
| **시스템 알림 보내기** | 세션이 끝나면 답변 앞부분과 함께 macOS 알림을 보냅니다. 알림을 클릭하면 세션이 시작된 창에서 다시 열립니다. |

이 스위치가 켜져 있어도 macOS 집중 모드와 알림 설정이 배너를 숨길 수 있습니다.

## 방해 금지 시간

방해 금지 시간은 에이전트 질문, 메일 알림, 끝난 작업을 방해 금지 시간이 끝날 때까지 이 Mac과 페어링된 iPhone에서 보류합니다. 기다리는 동안 대신 승인되지는 않습니다.

1. **설정 → 알림**에서 **업데이트 (연락)**를 찾습니다.
2. **방해 금지 시간**을 켠 다음 **시작**과 **종료**를 설정합니다.
3. 그래도 통과할 항목을 고릅니다.

| 설정 | 하는 일 |
| --- | --- |
| **승인 요청은 통과** | 방해 금지 시간에도 승인 요청이 도착합니다. |
| **질문은 통과** | 방해 금지 시간에도 에이전트 질문이 도착합니다. |

Enconvo 메뉴 막대 메뉴에도 **방해 금지 시간**이 있고, 짧은 휴식에는 **업데이트를 1시간 일시 중지**가 있습니다.

메일 알림은 **자동화 → 중요 메일**에서 켜기 전까지 꺼져 있습니다. 이미 켜거나 설정한 메일 알림은 계속 동작합니다. **전화** 스위치는 페어링된 iPhone이나 Android 전화로 알림을 보냅니다.

## 예약된 결과

시스템 알림은 예약된 작업의 결과를 Telegram이나 다른 메신저 채팅으로 보내는 것과 다릅니다. 결과 전달은 [예약된 작업](/ko/workflows/scheduled-jobs) 편집기에서 설정합니다.

예약된 작업은 실행될 때 자체 Mac 알림을 보낼 수도 있습니다(**실행되면 알림**). 그 알림도 **시스템 알림 보내기**를 따릅니다. 작업의 실행 기록에는 각 실행이 성공했는지, 결과가 전달됐는지가 나옵니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 세션이 끝나도 배너가 없음 | **시스템 알림 보내기**가 켜져 있는지, macOS가 Enconvo 알림을 허용하는지, 집중 모드가 숨기고 있지 않은지 확인하세요. |
| Dynamic Island가 열리지 않음 | **Dynamic Island 열기**는 Dynamic Island에서 시작한 세션에만 적용됩니다. |
| 질문이나 끝난 작업이 늦게 도착함 | 방해 금지 시간이 보류했을 수 있습니다. **질문은 통과**를 켜거나 **시작**과 **종료**를 바꾸세요. |

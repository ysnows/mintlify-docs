Sandbox는 에이전트의 쉘 명령이 닿을 수 있는 범위를 제한합니다. 켜면 명령은 채팅의 작업 폴더와 temp만 바꿀 수 있고, macOS가 키를 읽거나 다른 앱을 제어하거나 Enconvo에 연결하는 것을 막습니다. 명령을 하나씩 지켜보지 않을 에이전트에 켜세요.

Sandbox는 에이전트의 권한 모드와 함께 동작합니다. 모드는 동작 전에 Enconvo가 언제 묻는지 결정하고, Sandbox는 명령이 실행된 뒤 할 수 있는 일을 제한합니다.

## Sandbox 켜기

1. 채팅 창, SmartBar, Dynamic Island, 앱 사이드바, 또는 프로젝트의 리드 채팅에서 에이전트와 채팅을 엽니다.
2. 실행 모드 옆 **권한** 칩을 클릭합니다.
3. **Sandbox**를 켭니다.

이 스위치는 에이전트에 속하므로, 그 에이전트를 쓰는 모든 창에 적용됩니다. 그 에이전트가 부르는 에이전트의 명령도 Sandbox 안에서 실행됩니다.

에이전트 명령이 닿을 수 있는 범위를 보려면 스위치 아래 **Sandbox 작동 방식**을 클릭하세요. 그 에이전트만의 Sandbox를 그립니다. 작업 폴더, 권한 모드, 명령이 닿을 수 있는 곳과 없는 곳이 나옵니다.

## 샌드박스된 명령이 닿을 수 있는 곳

| 위치 | Sandbox 안 |
| --- | --- |
| 작업 폴더와 temp | 읽고 바꿀 수 있음 |
| 다른 파일 | 읽을 수 있고 바꿀 수 없음 |
| 인터넷 | 연결할 수 있음 |
| SSH 키, 키체인, 쿠키 같은 키와 암호 | 읽을 수 없음 |
| 저장된 자격 증명과 Enconvo 설정 | 읽을 수 없음 |
| 다른 앱 | 열거나 제어할 수 없음 |
| Enconvo | 연결할 수 없음 |

명령이 시작한 모든 프로그램도 Sandbox 안에서 실행됩니다. Enconvo는 App Store 앱이 쓰는 macOS 자체 샌드박스를 사용합니다.

## Sandbox가 명령을 막을 때

명령이 Sandbox가 막는 곳에 닿으려 하면 macOS가 거부하고, 단계 아래 줄에 폴더 쓰기나 키 파일 읽기처럼 무엇이 막혔는지 나옵니다.

1. 줄을 클릭해 무엇이 왜 막혔는지 봅니다.
2. 그 명령을 허용하려면 **밖에서 실행**을 클릭합니다. 명령이 전체 접근으로 한 번 실행된 뒤, 다른 명령처럼 채팅에 표시됩니다. 기억되지는 않습니다.

**밖에서 실행**은 실행이 진행 중이고 누군가 보고 있을 때만 제공됩니다. 예약된 작업과 아무도 보지 않는 다른 실행은 Sandbox 밖에서 명령을 실행하지 않습니다.

## 명령 전에 Enconvo가 묻는 이유

Sandbox 여부와 관계없이, 무엇을 물을지는 에이전트의 권한 모드가 결정합니다. [동작 승인](/ko/ai/agents)을 보세요.

| 모드 | Sandbox가 켜져 있을 때 |
| --- | --- |
| **승인 요청** | 모든 명령이 실행 전에 여전히 묻습니다. Sandbox는 허용한 명령이 할 수 있는 일을 제한합니다. |
| **나를 위해 승인** | 파일 삭제나 게시처럼 위험한 명령을 제외하고 묻지 않고 실행됩니다. |
| **전체 접근** | 묻지 않고 실행됩니다. 컴퓨터를 해칠 수 있는 변경만 묻습니다. |

Enconvo는 명령을 부분별로 읽으므로, 따옴표, 중첩, 연결, 파이프 안에 숨은 해로운 단계도 여전히 묻고, echo나 폴더 목록처럼 무해한 것은 묻지 않습니다.

**전체 접근**에서도 중요한 폴더 삭제, 쉘 시작 파일이나 SSH 키 편집, 저장된 암호 읽기처럼 컴퓨터를 해칠 수 있는 변경 전에는 경로를 어떻게 쓰든 **한 번 허용**과 **거부**로 묻습니다.

**나를 위해 승인**에서는 규칙으로 판단할 수 없는 명령을 요청 내용과 대조합니다. 스스로 실행될 것이라고 기대하지 않을 때 Enconvo가 이유를 밝히며 묻습니다.

각 승인 카드에는 "이 프로젝트가 나를 위해 승인으로 되어 있어 물었습니다."처럼 묻게 만든 설정이 나옵니다.

## 묻는 다른 동작

- [컴퓨터 사용](/ko/features/computer-use)은 삭제, 보내기, 결제, 앱 종료, 로그아웃하는 키보드 단축키 전에 클릭과 마찬가지로 묻습니다.
- 플러그인 페이지의 자체 경로를 호출하는 명령은 먼저 묻습니다.
- 플러그인 도구를 승인하면 그 도구가 보내려는 내용이 보입니다.
- 에이전트는 [친구](/ko/features/friends)와 팀원에게 전화하거나 메시지를 보내기 전에 묻습니다. **전체 접근**에서는 묻지 않습니다.
- 에이전트는 자신의 승인 카드에 답하거나, 자신의 권한을 올리거나, 플러그인 설치나 포인트 한도처럼 사용자를 위한 카드에 답할 수 없습니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 명령이 권한 오류로 실패함 | Sandbox가 막았을 수 있습니다. 단계 아래 줄을 클릭한 다음, 명령을 신뢰하면 **밖에서 실행**을 누르세요. |
| 에이전트가 명령으로 앱을 열거나 제어할 수 없음 | Sandbox 안의 명령은 다른 앱을 제어할 수 없습니다. [컴퓨터 사용](/ko/features/computer-use)을 쓰거나 이 에이전트의 Sandbox를 끄세요. |
| Enconvo가 물을 줄 알았는데 묻지 않음 | **권한** 칩에서 에이전트의 권한 모드를 확인하세요. **전체 접근**은 컴퓨터를 해칠 수 있는 변경 전에만 묻습니다. |
| **Sandbox** 스위치가 없음 | 채팅이 에이전트 모드인지 확인하고 Enconvo를 업데이트하세요. [업데이트](/ko/configuration/updates)를 보세요. |

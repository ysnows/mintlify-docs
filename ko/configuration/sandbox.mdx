---

샌드박스는 에이전트의 셸 명령이 접근할 수 있는 범위를 제한합니다. 샌드박스를 켜면 명령은 채팅의 작업 폴더와 임시 폴더만 변경할 수 있고, macOS가 키 읽기, 다른 앱 제어, Enconvo 연결을 막습니다. 명령을 하나하나 지켜보고 싶지 않은 에이전트에 켜 두세요.

샌드박스는 에이전트의 권한 모드와 함께 작동합니다. 모드는 Enconvo가 동작 전에 언제 확인할지를 정하고, 샌드박스는 명령이 실행된 뒤 할 수 있는 일을 제한합니다.

## 샌드박스 켜기

1. 채팅 창, SmartBar, Dynamic Island, 앱 사이드바 또는 프로젝트의 리드 채팅에서 에이전트와 채팅을 엽니다.
2. 실행 모드 옆의 **권한** 칩을 클릭합니다.
3. **샌드박스**를 켭니다.

이 스위치는 에이전트에 속하므로 그 에이전트를 사용하는 모든 창에 적용됩니다. 해당 에이전트가 호출하는 에이전트들의 명령도 샌드박스에서 실행됩니다.

샌드박스가 에이전트의 명령에 허용하는 범위를 보려면 스위치 아래의 **샌드박스 작동 방식**을 클릭하세요. 에이전트의 작업 폴더, 권한 모드, 명령이 접근할 수 있거나 없는 각 위치가 그림으로 표시됩니다.

## 샌드박스 안의 명령이 접근할 수 있는 범위

| 위치 | 샌드박스 안에서 |
| --- | --- |
| 작업 폴더와 임시 폴더 | 읽고 변경할 수 있음 |
| 그 밖의 파일 | 읽을 수 있고 변경할 수 없음 |
| 인터넷 | 연결할 수 있음 |
| SSH 키, 키체인, 쿠키 같은 키와 비밀번호 | 읽을 수 없음 |
| 저장된 자격 증명과 Enconvo 설정 | 읽을 수 없음 |
| 다른 앱 | 열거나 제어할 수 없음 |
| Enconvo | 연결할 수 없음 |

명령이 시작하는 모든 프로그램도 샌드박스 안에서 실행됩니다. Enconvo는 App Store 앱이 사용하는 macOS 자체 샌드박스를 사용합니다.

## 샌드박스가 명령을 막을 때

명령이 샌드박스가 막아 둔 대상에 접근하려 하면 macOS가 거부하고, 단계 아래의 한 줄에 폴더 쓰기나 키 파일 읽기처럼 무엇이 막혔는지 표시됩니다.

1. 그 줄을 클릭하면 무엇이 왜 막혔는지 볼 수 있습니다.
2. 명령이 그 동작을 하도록 허용하려면 **샌드박스 밖에서 실행**을 클릭합니다. 명령은 전체 접근 권한으로 한 번 실행되고 다른 명령처럼 채팅에 표시됩니다. 선택은 기억되지 않습니다.

**샌드박스 밖에서 실행**은 실행이 진행 중이고 누군가 지켜보고 있을 때만 제공됩니다. 예약 작업처럼 아무도 지켜보지 않는 실행은 샌드박스 밖에서 명령을 실행하지 않습니다.

## 명령 전에 Enconvo가 확인하는 이유

샌드박스 사용 여부와 관계없이 에이전트의 권한 모드가 무엇을 확인할지 정합니다. [동작 승인](/ko/ai/agents)을 참고하세요.

| 모드 | 샌드박스를 켰을 때 |
| --- | --- |
| **승인 요청** | 모든 명령이 실행 전에 여전히 확인을 요청합니다. 샌드박스는 허용한 명령이 할 수 있는 일을 제한합니다. |
| **대신 승인** | 파일 삭제나 게시 같은 위험한 명령을 제외하고 확인 없이 실행됩니다. |
| **전체 접근** | 확인 없이 실행됩니다. 컴퓨터에 해를 끼칠 수 있는 변경만 확인을 요청합니다. |

Enconvo는 각 명령을 부분별로 읽으므로 따옴표, 중첩, 연결, 파이프 안에 숨은 위험한 단계도 확인을 요청하고, echo나 폴더 목록 보기 같은 무해한 명령은 요청하지 않습니다.

**전체 접근**에서도 Enconvo는 핵심 폴더 삭제, 셸 시작 파일이나 SSH 키 편집, 저장된 비밀번호 읽기처럼 컴퓨터에 해를 끼칠 수 있는 변경 전에는 경로를 어떻게 쓰든 **한 번만 허용**과 **거부**로 확인을 요청합니다.

**대신 승인**에서는 규칙으로 판단할 수 없는 명령을 사용자가 요청한 내용과 대조해 확인합니다. 스스로 실행되리라 예상하기 어려운 경우에는 Enconvo가 이유와 함께 사용자에게 묻습니다.

각 승인 카드에는 "이 프로젝트가 대신 승인으로 설정되어 있어서 요청했습니다."처럼 확인을 요청하게 만든 설정이 표시됩니다.

## 확인을 요청하는 그 밖의 동작

- [컴퓨터 사용](/ko/features/computer-use)은 클릭할 때처럼 삭제, 전송, 결제, 앱 종료, 로그아웃을 하는 키보드 단축키 전에 확인을 요청합니다.
- 플러그인 페이지 자체의 라우트를 호출하는 명령은 먼저 확인을 요청합니다.
- 플러그인의 도구를 승인할 때는 도구가 보내려는 내용이 표시됩니다.
- 에이전트는 [친구](/ko/features/friends)와 팀원에게 전화하거나 메시지를 보내기 전에 확인을 요청합니다. 단, **전체 접근**에서는 요청하지 않습니다.
- 에이전트는 자신의 승인 카드에 답하거나, 자신의 권한을 높이거나, 플러그인 설치나 포인트 상한처럼 사용자에게 오는 카드에 답할 수 없습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 명령이 권한 오류로 실패합니다 | 샌드박스가 막았을 수 있습니다. 단계 아래의 줄을 클릭하고, 명령을 신뢰한다면 **샌드박스 밖에서 실행**을 선택하세요. |
| 에이전트가 명령으로 앱을 열거나 제어할 수 없습니다 | 샌드박스 안의 명령은 다른 앱을 제어할 수 없습니다. [컴퓨터 사용](/ko/features/computer-use)을 이용하거나 이 에이전트의 샌드박스를 끄세요. |
| Enconvo가 확인을 요청할 줄 알았는데 요청하지 않았습니다 | **권한** 칩에서 에이전트의 권한 모드를 확인하세요. **전체 접근**은 컴퓨터에 해를 끼칠 수 있는 변경 전에만 확인을 요청합니다. |
| **샌드박스** 스위치가 보이지 않습니다 | 채팅이 에이전트 모드인지 확인하고 Enconvo를 업데이트하세요. [업데이트](/ko/configuration/updates)를 참고하세요. |

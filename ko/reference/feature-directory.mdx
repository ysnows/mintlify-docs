이 문서의 모든 가이드를 사이드바와 같은 방식으로 묶었습니다. 하고 싶은 일을 찾아 해당 가이드를 여세요. 개별 기본 제공 명령은 [명령 카탈로그](/ko/extensions/built-in-extensions)를, 모델, 음성, 그 밖의 서비스는 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

일부 기능은 베타 채널에 먼저 출시됩니다. 가이드에 설명된 기능이 앱에 없다면 [업데이트 채널](/ko/configuration/updates)을 확인하세요.

## 시작하기

| 가이드 | 도와주는 일 |
| --- | --- |
| [설치](/ko/installation) | Mac에 Enconvo를 설치하고, 최신 상태로 유지하며, 설치 문제를 해결합니다. |
| [Windows (베타)](/ko/getting-started/windows) | Windows에 Enconvo 베타를 설치하고, 로그인하고, 최신 상태로 유지하며, 어떤 기능이 작동하는지 확인합니다. |
| [Linux (베타)](/ko/getting-started/linux) | Linux 데스크톱이나 서버에 Enconvo 베타를 설치하고, 로그인하고, 브라우저에서 사용합니다. |
| [빠른 시작](/ko/quickstart) | 약 5분 안에 Enconvo를 설치하고, 모델을 연결하고, 첫 질문을 합니다. |
| [문제 해결](/ko/getting-started/troubleshooting) | 답변, 단축키, 음성, 권한, 통합에서 자주 생기는 문제를 해결하고, 막혔을 때 진단 정보를 보냅니다. |

## 어디서나 AI에게 질문하기

| 가이드 | 도와주는 일 |
| --- | --- |
| [SmartBar](/ko/features/smartbar) | 단축키 하나로 어떤 앱에서든 에이전트에게 질문하거나 명령을 실행하고, 입력하는 동안 계산, 변환, 날씨와 항공편 조회를 합니다. |
| [채팅 창](/ko/ai/chat) | 에이전트와 더 긴 대화를 나누고, 파일과 컨텍스트를 추가하고, /goal로 에이전트가 목표를 향해 계속 작업하게 하고, 임시 채팅으로 질문하고, 프롬프트 개선으로 요청을 다시 쓰고, 여러 채팅을 동시에 다룹니다. |
| [스페이스](/ko/features/spaces) | 트래커나 실시간 보드처럼 나만의 페이지를 에이전트에게 요청하고, 채팅 창 사이드바와 휴대전화에 보관합니다. |
| [Dynamic Island](/ko/features/dynamic-island) | 화면 상단의 간결한 패널에서 에이전트에게 질문하고, 바로가기를 실행하고, 홈에서 계산하고, 실행 중인 작업을 따라가거나 승인하거나 읽음으로 표시합니다. |
| [PopBar](/ko/features/popbar) | 선택한 위치에 나타나는 도구 모음에서 선택한 텍스트를 설명하고, 번역하고, 고치고, 검색하고, 읽어 줍니다. |
| [클립보드 기록, 북마크, 파일 검색](/ko/features/clipboard-history) | 이전에 복사한 내용을 붙여넣고, 브라우저 북마크를 열고, Mac의 파일을 단축키나 SmartBar에서 찾습니다. |
| [앱 사이드바](/ko/features/app-sidebar) | 작업 중인 앱이나 웹사이트 옆 사이드바에서 에이전트와 채팅하고, 답변이나 커밋 메시지를 앱에 삽입하고, Finder 파일에 파일 작업을 실행합니다. |
| [데스크톱 펫](/ko/features/pet) | 에이전트가 하는 일을 보여 주고 클릭하면 Enconvo를 여는 애니메이션 동반자를 데스크톱에 둡니다. |
| [창 관리](/ko/features/window-management) | 작업에 맞는 Enconvo 창을 고르고, 각 창을 여는 단축키를 설정하고, 결과를 계속 보이게 두고, 창을 닫은 뒤에도 Enconvo가 Dock에 나타나지 않게 합니다. |

이 문서의 모든 가이드를 사이드바와 같은 기준으로 묶어 정리했습니다. 원하는 작업을 찾은 뒤 해당 가이드를 열어 보세요. 개별 기본 제공 명령은 [명령 카탈로그](/ko/extensions/built-in-extensions)를, 모델·음성 및 기타 서비스는 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

일부 기능은 Beta 채널에 먼저 제공됩니다. 가이드에 설명된 기능이 앱에 없다면 [업데이트 채널](/ko/configuration/updates)을 확인하세요.

## 시작하기

| 가이드 | 도움말 내용 |
| --- | --- |
| [설치](/ko/installation) | Mac에 Enconvo를 설치하고, 최신 상태로 유지하며, 설치 문제를 해결합니다. |
| [Windows (Beta)](/ko/getting-started/windows) | Windows에 Enconvo Beta를 설치하고 로그인하며 최신 상태로 유지하고 사용 가능한 기능을 확인합니다. |
| [Linux (Beta)](/ko/getting-started/linux) | Linux 데스크톱이나 서버에 Enconvo Beta를 설치하고 로그인한 뒤 브라우저에서 사용합니다. |
| [빠른 시작](/ko/quickstart) | 약 5분 만에 Enconvo를 설치하고 모델을 연결해 첫 질문을 해 봅니다. |
| [문제 해결](/ko/getting-started/troubleshooting) | 답변, 단축키, 음성, 권한, 연동의 흔한 문제를 해결하고, 막힐 때 진단 정보를 보냅니다. |

## 어디서든 AI에게 묻기

| 가이드 | 도움말 내용 |
| --- | --- |
| [SmartBar](/ko/features/smartbar) | 단축키 하나로 어떤 앱에서든 에이전트에게 질문하거나 명령을 실행하고, 입력하는 동안 계산, 단위 변환, 날씨 및 항공편 조회를 바로 수행합니다. |
| [채팅 창](/ko/ai/chat) | 에이전트와 긴 대화를 나누고, 파일과 컨텍스트를 추가하며, `/goal`로 에이전트가 목표를 향해 계속 작업하게 하고, 임시 채팅으로 질문하며, 프롬프트 개선으로 요청을 다듬고, 여러 채팅을 한 번에 다룹니다. |
| [스페이스](/ko/features/spaces) | 에이전트에게 트래커나 실시간 보드 같은 나만의 페이지를 요청해 채팅 창 사이드바와 휴대폰에 보관합니다. |
| [Dynamic Island](/ko/features/dynamic-island) | 화면 상단의 작은 패널에서 에이전트에게 묻고, 단축키를 실행하며, 홈에서 계산하고, 실행 중인 작업을 따라가거나 승인하거나 읽음으로 표시합니다. |
| [PopBar](/ko/features/popbar) | 텍스트를 선택한 자리 옆에 뜨는 도구 막대에서 선택한 텍스트를 설명, 번역, 수정, 검색하거나 소리 내어 읽습니다. |
| [클립보드 기록, 북마크, 파일 검색](/ko/features/clipboard-history) | 단축키나 SmartBar에서 이전에 복사한 내용을 붙여 넣거나 브라우저 북마크를 열고 Mac의 파일을 찾습니다. |
| [앱 사이드바](/ko/features/app-sidebar) | 작업 중인 앱이나 웹사이트 옆 사이드바에서 에이전트와 채팅하고, 답장이나 커밋 메시지를 앱에 바로 넣으며, Finder 파일에 대한 파일 작업을 실행합니다. |
| [데스크톱 펫](/ko/features/pet) | 에이전트가 무엇을 하는지 보여 주고 클릭하면 Enconvo를 열어 주는 움직이는 동반자를 데스크톱에 둡니다. |
| [창 관리](/ko/features/window-management) | 작업에 맞는 Enconvo 창을 고르고 각 창을 여는 단축키를 설정하며, 결과를 화면에 유지하고 창을 닫은 뒤 Dock에 Enconvo가 남지 않게 합니다. |

## 음성

| 가이드 | 도움말 내용 |
| --- | --- |
| [받아쓰기와 음성 명령](/ko/features/dictation) | 어떤 앱에서든 목소리로 입력하고, 초안 작성으로 원하는 내용을 말하여 글을 쓰거나 다듬으며, Return 키로 전송하고, 일시 정지·재개하며, 회의 중 음소거를 유지하고, 앱별 규칙을 정하거나, 키를 누른 채 에이전트에게 작업을 요청합니다. |
| [Live Talk](/ko/features/live-voice) | 에이전트에게 전화를 걸어 이야기를 나눕니다. 에이전트가 듣고 자신의 목소리로 답하며 대화 중에 작업을 시작합니다. |
| [에이전트 전화](/ko/features/agent-phone) | 작업에 확인이 필요할 때 에이전트가 사용자에게 전화를 걸고, 사용자를 대신해 지인이나 Enconvo 친구에게 전화하며, 놓친 iPhone 전화를 대신 받게 합니다. |
| [아바타](/ko/features/avatar) | 데스크톱에서 에이전트에게 캐릭터를 부여하거나 사진·설명만으로 만든 라이브 포토 캐릭터가 음성 통화에서 함께 대화하게 합니다. |
| [라이브 포토 캐릭터 스트리밍](/ko/features/avatar-live-stream) | 자막과 함께 OBS 방송에 라이브 포토 캐릭터를 띄우고 Twitch, Kick, YouTube 실시간 채팅에 목소리로 답하게 합니다. |
| [음성 인식](/ko/ai/speech-recognition) | 각 음성 기능이 사용할 음성 모델을 Enconvo Cloud, 개인 API 키, 또는 Mac의 로컬 모델 중에서 선택합니다. |
| [텍스트 음성 변환](/ko/ai/text-to-speech) | Enconvo가 텍스트나 채팅 답변을 소리 내어 읽게 하거나, 텍스트를 오디오 파일로 만들고, 목소리를 복제합니다. |
| [사전 및 화자](/ko/configuration/speech-assets) | 음성 기능에 자주 쓰는 단어와 철자를 가르치고, 받아쓰기가 직접 고친 이름을 학습하게 하며, 녹음 속 화자의 이름을 지정합니다. |

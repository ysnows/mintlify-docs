title: "다른 컴퓨터"
description: "Enconvo가 실행 중인 컴퓨터들을 페어링하면, 한 컴퓨터에서 다른 컴퓨터의 채팅, 터미널, 화면, 에이전트를 사용하면서 작업도 그곳에서 계속 실행할 수 있습니다."
---

Enconvo가 실행 중인 두 컴퓨터를 페어링하면 한 컴퓨터에서 다른 컴퓨터의 작업을 다룰 수 있습니다. 페어링된 컴퓨터에서 연 채팅은 그 컴퓨터의 파일, 키, 모델, 에이전트를 사용해 그쪽에서 실행되며, 창에서 눈을 돌려도 계속 동작합니다. 또한 상대 컴퓨터의 화면을 보거나 조작하고, 파일을 보내고, 여기 있는 에이전트가 상대 컴퓨터에 작업을 넘길 수도 있습니다.

Enconvo가 실행되지 않는 서버에 연결하려면 대신 SSH 호스트로 추가하세요. [컴퓨터 및 SSH 호스트](/ko/integrations/computers-and-ssh-hosts)를 참고하세요.

## 시작하기 전에

- 두 컴퓨터 모두에 Enconvo를 설치하고 같은 Enconvo 계정으로 로그인합니다.
- 두 컴퓨터 모두 온라인 상태여야 하며 Enconvo가 실행 중이어야 합니다. 상대 컴퓨터는 Enconvo가 실행 중인 동안에만 연결할 수 있습니다.
- Free 요금제에서는 컴퓨터 한 대를 다른 컴퓨터와 페어링할 수 있습니다. 계정의 기기 시트(Device seat)는 둘 중 한 대에 배정됩니다. 다른 컴퓨터에서 시트가 있는 컴퓨터로 들어가 작업할 수 있으며, 반대로 시트가 있는 컴퓨터에서는 상대 컴퓨터의 채팅을 읽고 파일을 보낼 수 있습니다.

## 컴퓨터 페어링하기

페어링할 때는 항상 어느 컴퓨터가 제어하고 어느 컴퓨터가 제어받는지 표시됩니다. 어느 쪽에서든 시작할 수 있습니다.

<Steps>
  <Step title="페어링 시작하기">
    채팅 창 사이드바 하단의 기기 전환기를 클릭한 뒤 **기기 추가 → 컴퓨터 페어링**을 선택합니다. 또는 **설정 → 연결**을 열고 **컴퓨터** 아래에서 **컴퓨터 페어링**을 클릭하세요.
  </Step>
  <Step title="제어할 컴퓨터 고르기">
    온라인 상태인 다른 컴퓨터가 목록에 표시됩니다. 지금 사용하는 컴퓨터에서 제어할 대상을 선택하고 접근 범위를 고릅니다. 양방향으로 제어하려면 반대 방향으로도 이 컴퓨터를 제어할 수 있게 하는 옵션을 함께 켜세요.
  </Step>
  <Step title="다른 컴퓨터에서 허용하기">
    다른 컴퓨터의 Dynamic Island에 번호와 함께 요청이 표시됩니다. 두 컴퓨터에 같은 번호가 표시되는지 확인한 뒤 **허용**을 클릭합니다.
  </Step>
  <Step title="열기 방식 설정하기">
    짧은 안내 화면에서 해당 컴퓨터를 채팅 창 안에서 열지 별도 창에서 열지 묻고, 어느 앱에서나 불러올 수 있는 단축키를 설정할 수 있게 하며, 할 수 있는 작업을 보여 줍니다. 이 안내는 컴퓨터의 **⋯** 메뉴 → **사용 방법**에서 언제든 다시 열 수 있습니다.
  </Step>
</Steps>

컴퓨터들이 서로를 찾지 못할 때는 **링크로 페어링**을 사용하세요. 제어하려는 컴퓨터에서 링크를 복사한 뒤 지금 사용하는 컴퓨터에 붙여 넣습니다. 링크는 1회용이며 5분 동안 유효합니다.

다른 컴퓨터가 이 컴퓨터와 페어링되면 그 컴퓨터가 여기서 무엇을 사용할 수 있는지 안내가 표시됩니다. **변경**을 클릭해 조정할 수 있습니다.

## 컴퓨터가 접근할 수 있는 항목 선택하기

페어링을 허용할 때와 나중에 **설정 → 연결**의 해당 컴퓨터 페이지에서, 상대 컴퓨터가 이 컴퓨터에서 제어할 수 있는 항목을 고릅니다.

| 선택 항목 | 상대 컴퓨터가 여기서 할 수 있는 작업 |
| --- | --- |
| **채팅** | 여기서 채팅을 열고 계속 실행합니다. |
| **채팅과 도구** | **터미널**, **화면**, **파일**도 함께 사용해 상대 에이전트가 여기서 명령을 실행할 수 있습니다. |
| **전체** | 상대 에이전트가 여기서 채팅을 시작하고 이 화면도 사용할 수 있습니다. |

하나씩 따로 설정하려면 **개별 스위치**를 선택하세요.

| 스위치 | 허용되는 기능 |
| --- | --- |
| **채팅** | 여기서 채팅을 열고 계속 실행합니다. |
| **터미널** | 셸을 열고 상대 에이전트가 명령을 실행하도록 허용합니다. |
| **화면** | 이 화면을 보고 제어합니다. |
| **파일** | 여기의 다운로드 폴더로 파일을 보냅니다. |
| **에이전트** | 상대 에이전트가 여기서 채팅을 시작할 수 있도록 허용합니다. 직접 켜기 전까지는 꺼져 있습니다. |
| **에이전트 제어** | 상대 에이전트가 이 화면과 브라우저를 직접 사용할 수 있도록 허용합니다. 사용 시 화면에 표시되며 언제든 중지할 수 있습니다. 직접 켜기 전까지는 꺼져 있습니다. |

## 컴퓨터의 채팅 열기

채팅 창 사이드바에는 한 번에 한 컴퓨터의 목록만 표시됩니다. 하단의 기기 전환기로 이 컴퓨터와 페어링된 컴퓨터 사이를 오가며, 다른 컴퓨터에서 대기 중인 항목을 확인하고, 각 컴퓨터를 별도 창으로 열 수 있습니다.

- 각 컴퓨터의 목록에는 해당 컴퓨터의 채팅과 프로젝트가 진행 중인 항목·확인 필요 상태와 함께 표시되며 그 자리에서 바로 열립니다.
- 각 컴퓨터에는 고유 색상이 지정됩니다. 컴퓨터의 **⋯** 메뉴 → **색상**에서 바꿀 수 있습니다.
- 다른 컴퓨터의 에이전트가 시작한 채팅에는 표시가 붙으며, 채팅 창의 검색 기능은 해당 컴퓨터의 채팅도 찾아 줍니다.
- 다른 컴퓨터에서 응답이 준비되거나 에이전트가 사용자의 답변을 기다릴 때 Enconvo가 알림을 보냅니다.

다른 컴퓨터에서 새 채팅을 시작하려면 새 채팅의 메시지 상자에서 **실행 위치** 칩을 사용하세요. 입력하던 내용도 함께 넘어갑니다. 컴퓨터 간 전환은 **⌃1**~**⌃9** 단축키로 할 수 있습니다.

다른 컴퓨터에 있는 슬라이드(Decks), 디자인, 대시보드는 읽기 전용으로 열리며, 다른 컴퓨터의 채팅에서는 **소리 내어 읽기**를 제공하지 않습니다.

### 별도 창에서 열기

컴퓨터의 **⋯** 메뉴에서 **별도 창에서 열기**를 선택하면 해당 컴퓨터 색상으로 된 자체 Dock 아이콘을 가진 별도 창에서 채팅이 열립니다. 같은 메뉴에서 **Dock에 유지**를 켜 두면 아이콘이 Dock에 남아 나중에 바로 열 수 있습니다.

이를 기본값으로 설정하려면 **설정 → 연결**을 열고 해당 컴퓨터를 클릭한 뒤 **채팅** 아래에서 **채팅 창** 또는 **별도 창**을 선택하세요. **단축키**는 어느 앱에서나 그 컴퓨터를 불러오는 키를 설정합니다.

### 컴퓨터가 오프라인일 때

오프라인 컴퓨터의 채팅도 계속 읽을 수 있습니다. **이 Mac에서 계속**을 클릭해 화면의 내용으로 여기서 새 채팅을 시작하거나 **돌아오면 알림**을 클릭하세요.

## 화면 사용하기

컴퓨터 페이지에 상대 화면이 표시됩니다. 화면을 지켜보거나 제어를 가져와 내 마우스와 키보드로 조작할 수 있습니다.

전체 화면 버튼을 클릭하거나 **⌃⌥F**(Mac에서는 **⌃⌘F**도 동작)를 누르면 화면 전체에 표시됩니다. 마우스 포인터를 위쪽 가장자리로 옮기면 컨트롤이 다시 나타납니다. 나가려면 같은 키를 다시 누르거나, 보기만 하는 중이라면 **Esc**를 누르세요. 옆의 **보기 영역 채우기** 버튼은 검은 여백 없이 보기를 꽉 채우도록 화면을 확대하며, 맞지 않는 가장자리는 잘립니다.

다른 컴퓨터를 제어하는 동안 그쪽에서 복사한 내용이 내 클립보드로 전달됩니다. 화면의 안내 문구에서 제어를 끝내는 방법을 볼 수 있습니다.

## 파일 보내기

컴퓨터 페이지에서 **파일 보내기**를 클릭합니다. 파일은 상대 컴퓨터의 **다운로드 → Enconvo** 폴더에 저장되며, 이미 있는 파일을 덮어쓰지 않고 연결이 끊겼다가 복구되면 이어서 전송합니다.

다른 컴퓨터의 채팅에 첨부하는 파일도 파일당 최대 2GB까지 진행률 막대와 함께 전송됩니다.

## 다른 컴퓨터에 작업 넘기기

해당 컴퓨터에서 **에이전트**가 켜져 있으면 여기 있는 에이전트가 그쪽에서 채팅을 시작하고 결과를 받아올 수 있습니다. 채팅에서 `@`로 컴퓨터를 멘션하거나 에이전트에게 그 컴퓨터를 쓰라고 요청하세요. 에이전트가 상대 컴퓨터에서 무언가 실행하려 할 때는 먼저 상대 컴퓨터에서 승인을 요청하며, 채팅에도 상대 컴퓨터가 무엇을 기다리는지 표시됩니다.

**에이전트 제어**가 켜져 있으면 다른 컴퓨터의 에이전트가 변경 사항을 바로 다시 테스트하는 등 이 Mac의 화면과 브라우저를 직접 사용할 수 있습니다. 이때 누가 제어 중인지 알리는 오버레이가 표시되며, 직접 제어를 넘겨받거나 중지할 수 있습니다.

에이전트가 다른 컴퓨터를 사용하는 동안 채팅 상단의 띠와 메시지 상자 위의 알약(pill)에 상대 화면의 최신 스크린샷과 **중지** 버튼이 표시됩니다. 실행이 끝나면 단계와 스크린샷이 담긴 하나의 카드로 표시됩니다.

다른 컴퓨터에서 명령을 실행하는 방법은 [컴퓨터 및 SSH 호스트](/ko/integrations/computers-and-ssh-hosts)를 참고하세요.

## 컴퓨터 제거하기

**설정 → 연결**에서 컴퓨터를 클릭하고 **제거**를 선택하거나, 사이드바의 **⋯** 메뉴에서 **페어링 해제…**를 선택합니다. 채팅 기록은 해당 컴퓨터에 그대로 남습니다. 다시 사용하려면 새로 페어링하면 됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 페어링 목록에 다른 컴퓨터가 보이지 않음 | 온라인 상태인지, Enconvo가 실행 중인지, 같은 계정으로 로그인되어 있는지 확인하세요. 또는 **링크로 페어링**을 사용하세요. |
| 다른 컴퓨터에 페어링 요청이 뜨지 않음 | 다른 컴퓨터의 Dynamic Island를 확인하세요. 앱이 종료되었거나 연결이 끊겼다면 페어링을 다시 시작하세요. |
| 컴퓨터 페이지의 스위치가 흐리게 비활성화됨 | 상대 컴퓨터에서 허용하지 않은 상태입니다. 그쪽 컴퓨터에서 이 컴퓨터에 대한 권한을 켜 주세요. |
| 화면이나 채팅에서 컴퓨터에 연결할 수 없다고 나옴 | 상대 컴퓨터가 깨어 있고 Enconvo가 실행 중인지 확인하세요. **돌아오면 알림**을 누르면 복구되었을 때 알림을 받을 수 있습니다. |

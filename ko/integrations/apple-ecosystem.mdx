---

에이전트는 Mac에 기본으로 들어 있는 앱에서 작업할 수 있습니다. 일정을 확인하고, 미리 알림을 추가하고, 전화번호를 찾고, 메모를 저장하고, 메일을 정리하고, iMessage를 보냅니다. 일상적인 말로 요청하면 에이전트가 대신 앱을 사용합니다.

각 앱은 **설정 → 플러그인**의 **Mac 앱** 탭에 있는 플러그인입니다. 앱을 연결할 때는 계정이 아니라 macOS 권한을 요청합니다. Enconvo는 에이전트가 필요로 할 때만 앱을 읽으며, 백그라운드에서 동기화되는 것은 없습니다. 읽은 내용은 해당 채팅에 선택한 AI 모델로 전달됩니다.

## 앱 연결

<Steps>
  <Step title="Mac 앱 열기">
    **설정 → 플러그인**을 열고 **Mac 앱** 탭을 클릭하세요.
  </Step>
  <Step title="앱 연결">
    앱을 클릭한 다음 **연결**을 클릭하세요. 연결의 의미를 읽고 **계속**을 클릭하세요.
  </Step>
  <Step title="접근 허용">
    macOS가 Enconvo가 해당 앱을 사용해도 되는지 묻습니다. 허용하세요. 일부 앱은 macOS가 물을 수 있도록 Enconvo가 백그라운드에서 앱을 엽니다.
  </Step>
  <Step title="사용해 보기">
    앱에 **이 Mac에서 연결됨**이 표시됩니다. **지금 사용해 보기**를 클릭하거나 아래 예시 중 하나를 에이전트에게 요청해 보세요.
  </Step>
</Steps>

## 에이전트가 할 수 있는 일

| 앱 | 에이전트가 할 수 있는 일 | macOS 권한 |
| --- | --- | --- |
| 캘린더 | 캘린더에 설정된 모든 계정에서 원하는 기간의 캘린더와 일정을 읽습니다. 일정을 추가하고, 시간, 장소, 메모를 바꾸고, 삭제합니다. | **캘린더** |
| 미리 알림 | 목록을 한 번에 하나씩 읽고, 해야 할 미리 알림과 완료된 미리 알림을 읽습니다. 미리 알림을 추가하고, 기한과 메모를 바꾸고, 완료 또는 미완료로 표시하고, 다른 목록으로 옮기고, 삭제합니다. | **미리 알림** |
| 연락처 | 이름, 전화번호, 이메일 주소로 사람을 찾고 연락처를 한 번에 한 페이지씩 읽습니다. 에이전트는 연락처를 바꿀 수 없습니다. | **자동화**, 그다음 **연락처** |
| 메모 | 폴더와 첨부 파일이 있는 메모를 검색하고 읽습니다. 메모를 추가하고, 내용을 덧붙이거나 다시 쓰고, 폴더 사이로 옮기고, 삭제합니다. 잠긴 메모는 잠긴 채로 유지됩니다. | **자동화** |
| Mail | Mail에 설정된 모든 계정의 편지함을 검색하고, 메시지와 첨부 파일을 읽습니다. 초안을 작성하고, 보내고, 답장하고, 전달하고, 메시지를 이동하거나 깃발을 달거나 삭제합니다. | **자동화** |
| 메시지 | 읽지 않은 메시지와 그룹 채팅, 미국 외 번호를 포함한 대화 기록을 읽습니다. iMessage를 바로 보내거나, 나중에 확인하거나 취소할 수 있는 일회성 [자동화](/ko/workflows/scheduled-jobs)로 보냅니다. | **자동화**, 그리고 기록을 읽으려면 **전체 디스크 접근 권한** |
| 음악 | 보관함이나 Apple Music 카탈로그의 노래, 앨범, 아티스트, 플레이리스트를 재생합니다. 일시정지, 건너뛰기, 볼륨 설정, 셔플, 반복을 하고 재생 중인 곡을 확인합니다. | **자동화** |

**Mac 앱** 탭에는 Spotify도 있으며 같은 방식으로 동작합니다. Mac에 Spotify 앱이 있고 내 계정으로 로그인되어 있어야 합니다.

<Warning>
에이전트는 먼저 묻지 않고 일정, 미리 알림, 메모, 메일을 바꾸거나 삭제하고 메일을 보낼 수 있습니다. 검토하고 싶다면 계획이나 초안을 요청하세요. 메시지 앱에서 메시지를 보내기 전에는 에이전트가 받는 사람과 문구를 확인합니다.
</Warning>

## 앱 연결 해제

**Mac 앱** 탭에서 앱을 열고 **연결 해제**를 클릭하세요. Enconvo에서 해당 앱이 꺼집니다. macOS 접근도 제거하려면 **시스템 설정 → 개인정보 보호 및 보안**에서 표에 나온 해당 앱의 권한 아래에 있는 Enconvo를 끄세요.

## 앱별 예시

### Mail

Mail은 iCloud, Gmail, Outlook, Exchange를 포함해 Mail 앱에 설정된 모든 계정에서 동작합니다. 에이전트는 편지함을 관리하고, Mail 규칙을 켜거나 끄고, 첨부 파일을 저장하고, 읽지 않은 메일 수를 셀 수도 있습니다.

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### 미리 알림

미리 알림에는 기한 날짜와 시간, 메모, 우선순위(없음, 낮음, 보통, 높음), 반복 규칙, 도착하거나 떠날 때 알려 주는 위치를 설정할 수 있습니다. 반복 규칙은 매일, 매주, 매월, 매년 중 하나이며 하나 이상의 주기마다(예: 2주마다) 적용되고 종료일을 지정할 수 있습니다.

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### 캘린더

일정은 종일 일정으로 만들 수 있고, 장소, 메모, 링크를 가질 수 있으며, 시작 몇 분 전에 울리는 알람을 설정하고, 바쁨, 한가함, 미정, 부재중으로 표시하고, 종료일까지 또는 정해진 횟수만큼 매일, 매주, 매월, 매년 반복할 수 있습니다. 반복 일정을 삭제할 때는 에이전트가 모든 반복을 삭제할 수 있습니다.

**기본 일정:**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**종일 일정:**
```
"Block off next Friday as a personal day"
```

**반복 일정:**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**알람:**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**여러 캘린더:**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 연락처

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### 메시지

메시지는 전화번호, 이메일 주소, 그룹 채팅으로 iMessage를 보냅니다. iMessage로 전달되려면 메시지 앱이 Apple 계정으로 로그인되어 있어야 합니다. 메시지가 **전달되지 않음**으로 표시되면 에이전트는 보냈다고 말하는 대신 그 사실을 알려 줍니다.

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### 메모

에이전트는 메모 앱에서 선택한 메모도 읽을 수 있어서 "이걸 요약해 줘"나 "이걸 번역해 줘" 같은 요청에 알맞습니다.

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### 지도

에이전트는 Apple 지도를 열어 장소를 검색하고, 자동차, 도보, 대중교통 길찾기를 보여 주고, 핀을 꽂고, 가이드를 만듭니다. 결과는 채팅이 아니라 지도에 표시됩니다. 장소를 즐겨찾기에 저장하거나 가이드에 추가하려면 에이전트가 장소를 열고 사용자가 지도에서 마지막 단계를 마칩니다.

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### 단축어

에이전트는 단축어를 실행하지 않습니다. Enconvo에서 단축어를 실행하려면 **설정 → 빠른 동작**의 빠른 동작에 **단축어 실행** 단계를 추가하세요.

## 권한

각 앱은 위 표에 나온 자체 macOS 권한을 사용합니다.

- 캘린더와 미리 알림은 **시스템 설정 → 개인정보 보호 및 보안**의 **캘린더**와 **미리 알림** 목록을 사용합니다.
- 연락처, 메모, Mail, 메시지, 음악은 **자동화**를 사용하며, macOS가 Enconvo가 각 앱을 제어해도 되는지 묻습니다. 연락처는 연락처 접근 권한도 요청합니다.
- 메시지는 기록을 보호된 파일에 보관하므로 이를 읽으려면 Enconvo에 **전체 디스크 접근 권한**이 필요합니다.

권한 요청을 거부하면 해당 앱은 Enconvo에서 동작하지 않습니다. 캘린더, 미리 알림, 연락처는 **Mac 앱** 탭에서 앱을 다시 연결하면 macOS가 다시 묻습니다. macOS가 연결된 앱을 차단하면 **Mac 앱** 탭의 해당 행에 **설정 열기**가 표시되며, 올바른 스위치로 이동시켜 줍니다. 이 권한들은 나중에 **시스템 설정 → 개인정보 보호 및 보안**에서 언제든 바꿀 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| Mail이 동작하지 않음 | Mail 앱에 이메일 계정이 하나 이상 있는지 확인하세요. **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 Mail에 대해 Enconvo가 켜져 있는지 확인하세요. |
| 캘린더 접근이 거부됨 | **시스템 설정 → 개인정보 보호 및 보안 → 캘린더**에서 Enconvo가 목록에 있고 켜져 있는지 확인하세요. 허용한 뒤 Enconvo를 다시 시작하세요. |
| 미리 알림이 나타나지 않음 | **시스템 설정 → 개인정보 보호 및 보안 → 미리 알림**에서 Enconvo에 접근 권한이 있는지, 그리고 미리 알림이 미리 알림 앱에 표시되는지 확인하세요. |
| 메시지가 기록을 읽을 수 없음 | **시스템 설정 → 개인정보 보호 및 보안**에서 Enconvo에 **전체 디스크 접근 권한**을 켜세요. |
| 연결된 앱에 **설정 열기**가 표시됨 | macOS가 Enconvo를 차단하고 있습니다. **설정 열기**를 클릭하고 Enconvo를 켜세요. |

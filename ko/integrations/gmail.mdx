---

Gmail 커넥터는 이메일을 Enconvo로 가져옵니다. 에이전트에게 중요한 메일을 찾고, 스레드를 요약하고, 답장 초안을 쓰고, 받은 편지함을 정리해 달라고 요청하면 에이전트가 대신 Gmail을 사용합니다. Google 계정은 Enconvo 계정을 통해 한 번만 연결하며, 설정할 Google Cloud 프로젝트나 API 키는 없습니다.

여기서 연결한 Gmail 계정은 [이메일](/ko/integrations/email)에도 표시되며, 그곳에서 직접 읽고, 분류하고, 답장할 수 있습니다.

## 시작하기 전에

**설정 → 계정**에서 Enconvo 계정에 로그인하세요. 커넥터는 모든 플랜에서 무료이지만 Enconvo 계정이 필요합니다.

## Gmail 연결

<Steps>
  <Step title="Gmail 찾기">
    **설정 → 플러그인**을 열고 **Enconvo** 탭에서 **Gmail**을 검색하세요. 클릭하면 해당 페이지가 열립니다.
  </Step>
  <Step title="연결">
    **연결**을 클릭하세요. 브라우저에서 Google 로그인 화면이 열립니다.
  </Step>
  <Step title="접근 허용">
    Google 계정을 고르고, 허용하기 전에 요청하는 접근 권한을 검토하세요. Google의 동의 화면에는 Enconvo의 통합 파트너인 Composio가 표시됩니다.
  </Step>
  <Step title="결과 확인">
    Enconvo로 돌아오면 **계정** 아래에 내 주소가 표시됩니다. **지금 사용해 보기**를 클릭하거나, "오늘 받은 편지함의 읽지 않은 이메일을 요약해 줘."처럼 읽기 전용 질문을 먼저 에이전트에게 해 보세요.
  </Step>
</Steps>

Gmail을 연결하기 전에 에이전트에게 메일에 대해 물으면 채팅에 연결을 안내하는 카드가 표시됩니다.

## 에이전트가 할 수 있는 일

| 영역 | 에이전트가 할 수 있는 일 |
| --- | --- |
| 읽기 | 메일 검색, 메시지와 스레드 열기, 첨부 파일 다운로드, 라벨과 임시 보관함 목록 보기 |
| 정리 | 라벨 추가 및 제거, 보관, 메시지를 휴지통으로 이동하고 복원 |
| 쓰기 | 초안 작성 및 발송, 새 메일 보내기, 답장, 전달 |

검색에는 `from:john@example.com`, `subject:invoice`, `after:2024/01/01` 같은 Gmail 자체의 검색 구문이 사용됩니다.

에이전트가 메일을 쓰거나 보낼 때는 받는 사람, 참조, 숨은 참조를 지정하고, 일반 텍스트나 HTML 본문을 작성하고, 기존 스레드 안에서 답장하고, Mac의 파일을 최대 10개까지, 각각 최대 95MB까지 첨부할 수 있습니다. 메일 한 통이 담을 수 있는 용량(합계 25MB)을 넘는 파일은 대신 file.enconvo.com의 다운로드 링크로 전달되며, 링크가 있는 사람은 누구나 파일을 내려받을 수 있습니다.

<Warning>
에이전트는 먼저 묻지 않고 메일을 보낼 수 있습니다. 검토하고 싶다면 초안을 요청하세요. Enconvo는 메일을 영구 삭제하지 않으며, 삭제하면 휴지통으로 이동합니다.
</Warning>

## 옵션

계정이 연결되면 Gmail 페이지에 다음 옵션이 표시됩니다.

| 옵션 | 변경되는 내용 |
| --- | --- |
| **모든 채팅에서 사용 가능** | 켜면 에이전트가 모든 대화에서 Gmail을 사용할 수 있습니다. 끄면 사용자가 `@`로 멘션하거나 프로필에 포함된 경우에만 사용합니다. |
| **메일 알림** | 중요한 메일이 도착하면 Dynamic Island와 휴대전화로 알려 줍니다. **예약 작업 → 중요한 메일**에서 켜기 전까지는 꺼져 있으며, **휴대전화** 스위치는 페어링된 iPhone이나 Android 휴대전화로 알림을 보냅니다. 중요도를 판단하기 위해 새 메일마다 발신자, 제목, 본문 시작 부분이 Enconvo Cloud로 전송되므로 Enconvo는 켜기 전에 먼저 묻습니다. 메일은 그곳에 저장되지 않습니다. |
| **다른 계정 연결** | 다른 Gmail 주소를 최대 5개까지 추가합니다. |

계정이 여러 개이면 에이전트는 모두에서 읽고, "회사 주소로 보내 줘"처럼 다른 계정을 지정하지 않는 한 기본 계정으로 메일을 보내거나 만듭니다. 기본 계정을 바꾸려면 계정 메뉴에서 **기본으로 설정**을 고르세요.

## 채팅에서 Gmail 사용하기

Gmail이 연결되면 필요한 것을 요청하세요. 에이전트가 알맞은 Gmail 도구를 고릅니다.

**검색 및 요약:**
```
"Find all emails from John in the last week and summarize them"
```

**답장 초안:**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**받은 편지함 정리:**
```
"Archive all newsletters from the past month"
```

**라벨 관리:**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**오래된 메일 정리(휴지통으로 이동):**
```
"Delete all promotional emails older than 6 months"
```

## 워크플로 아이디어

Gmail은 [워크플로](/ko/workflows/introduction)와 [예약 작업](/ko/workflows/scheduled-jobs)에서도 사용할 수 있습니다.

| 아이디어 | 하는 일 |
| --- | --- |
| **일일 이메일 요약** | 읽지 않은 이메일을 검색하고, 요약하고, 아침 브리핑으로 보여 줍니다 |
| **자동 분류** | 새 이메일을 검색하고 내용에 따라 라벨을 적용합니다 |
| **후속 알림** | 답장을 기다리는 이메일을 찾아 미리 알림을 만듭니다 |
| **보고서 생성** | 조건에 맞는 이메일을 검색해 요약 보고서로 정리합니다 |

## 개인정보 보호

- **Enconvo Cloud와 Composio를 통해**: 메일은 요청한 작업을 수행하기 위해서만 Enconvo Cloud와 Composio를 거치며 저장되지 않습니다.
- **암호는 Google에 남음**: Google 자체 페이지에서 로그인하므로 Enconvo는 Google 암호를 볼 수 없습니다.
- **필요 시**: 에이전트는 작업에 필요할 때만 Gmail을 읽습니다. 예외는 **메일 알림**으로, 켜면 새 메일이 도착할 때마다 확인합니다.
- **철회 가능**: Gmail 페이지에서 **연결 해제**를 클릭하면 모든 기기에서 접근이 제거됩니다. [Google 계정 권한](https://myaccount.google.com/permissions)에서도 접근을 제거할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| **연결**이 회색으로 비활성화됨 | 먼저 **설정 → 계정**에서 Enconvo 계정에 로그인하세요. |
| Gmail에 **다시 연결**이 표시됨 | 접근 권한이 만료되었습니다. **다시 연결**을 클릭하고 Google에 다시 로그인하세요. |
| 에이전트가 Gmail을 사용하지 않음 | Gmail이 연결되어 있는지 확인하세요. **모든 채팅에서 사용 가능**이 꺼져 있다면 채팅에서 Gmail을 `@`로 멘션하세요. |
| 검색 결과가 없음 | `from:john`처럼 더 간단한 검색어를 먼저 시도하고, 메일이 연결된 계정에 있는지 확인하세요. Gmail 검색은 Gmail 웹사이트에서와 똑같이 동작합니다. |
| 첨부 파일이 전송되지 않음 | 파일 경로가 올바른지, 그리고 파일이 Mac에 있는지 확인하세요. |

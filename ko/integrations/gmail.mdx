description: "Gmail을 한 번 연결하면 에이전트가 아무 채팅에서나 메일을 검색하고 읽고 정리하고 보냅니다."
---

Gmail 커넥터는 이메일을 Enconvo로 가져옵니다. 에이전트에게 중요한 메일을 찾고, 스레드를 요약하고, 답장을 초안하고, 받은편지함을 정리하라고 하면 Gmail을 대신 씁니다. Google 계정을 Enconvo 계정을 통해 한 번 연결합니다. 설정할 Google Cloud 프로젝트나 API 키는 없습니다.

여기서 연결한 Gmail 계정은 [이메일](/ko/integrations/email)에도 나타나며, 거기서 직접 읽고 분류하고 답할 수 있습니다.

## 시작하기 전에

**설정 → 계정**에서 Enconvo 계정에 로그인합니다. 커넥터는 모든 플랜에서 무료이지만 Enconvo 계정이 필요합니다.

## Gmail 연결

<Steps>
  <Step title="Gmail 찾기">
    **설정 → 플러그인**을 열고 **Enconvo** 탭에서 **Gmail**을 검색합니다. 클릭해 페이지를 엽니다.
  </Step>
  <Step title="연결">
    **연결**을 클릭합니다. 브라우저에 Google 로그인이 열립니다.
  </Step>
  <Step title="접근 허용">
    Google 계정을 고르고 허용하기 전에 요청하는 접근을 검토합니다. Google 동의 화면에는 Enconvo의 연동 파트너인 Composio가 나옵니다.
  </Step>
  <Step title="결과 확인">
    Enconvo로 돌아오면 **계정** 아래에 주소가 나옵니다. **지금 시도**를 클릭하거나, 먼저 “오늘 받은편지함의 읽지 않은 이메일을 요약해 줘.”처럼 읽기 전용 질문을 에이전트에게 합니다.
  </Step>
</Steps>

Gmail이 연결되기 전에 에이전트에게 메일에 대해 물으면 채팅에 연결 카드가 나옵니다.

## 에이전트가 할 수 있는 일

| 영역 | 에이전트가 할 수 있는 일 |
| --- | --- |
| 읽기 | 메일 검색, 메시지와 스레드 열기, 첨부 다운로드, 라벨과 초안 나열 |
| 정리 | 라벨 추가와 제거, 보관, 메시지를 휴지통으로 옮기고 복원 |
| 쓰기 | 초안 만들고 보내기, 새 메일 보내기, 답장, 전달 |

검색은 Gmail 자체 검색 문법을 씁니다. `from:john@example.com`, `subject:invoice`, `after:2024/01/01` 같은 것입니다.

에이전트가 메일을 쓰거나 보낼 때 받는 사람, 참조, 숨은 참조를 설정하고, 일반 텍스트나 HTML 본문을 쓰고, 기존 스레드 안에서 답장하고, Mac의 파일을 첨부할 수 있습니다. 최대 10개 파일, 각각 최대 95 MB입니다. 한 이메일이 담을 수 있는 것(합쳐 25 MB)을 넘는 파일은 file.enconvo.com의 다운로드 링크로 가며, 링크가 있는 누구나 파일을 받을 수 있습니다.

<Warning>
에이전트는 먼저 묻지 않고 메일을 보낼 수 있습니다. 검토하려면 초안을 요청하세요. Enconvo는 메일을 영구 삭제하지 않습니다. 삭제는 휴지통으로 옮깁니다.
</Warning>

## 옵션

계정이 연결되면 Gmail 페이지에 나타납니다.

| 옵션 | 바뀌는 것 |
| --- | --- |
| **모든 채팅에서 사용 가능** | 켜면 에이전트가 모든 대화에서 Gmail을 쓸 수 있습니다. 끄면 `@`로 언급하거나 프로필에 포함할 때만 씁니다. |
| **메일 알림** | 중요한 메일이 도착하면 Dynamic Island와 전화에서 알립니다. **자동화 → 중요 메일**에서 켜기 전까지 꺼져 있으며, **전화** 스위치는 페어링된 iPhone이나 Android 전화로 알림을 보냅니다. 켜기 전에 Enconvo가 묻습니다. 각 새 메일의 보낸 사람, 제목, 시작이 중요도를 판단하기 위해 Enconvo Cloud로 가기 때문입니다. 메일은 거기에 저장되지 않습니다. |
| **다른 계정 연결** | 다른 Gmail 주소를 추가합니다. 최대 5개. |

계정이 여러 개면 에이전트는 모두에서 읽고, 다른 계정을 이름 붙이지 않는 한 기본 계정으로 보내거나 만듭니다. “회사 주소에서 보내 줘.” 같은 것입니다. 기본을 바꾸려면 계정 메뉴에서 **기본으로 설정**을 고릅니다.

## 채팅에서 Gmail 사용

Gmail이 연결되면 필요한 것을 요청하세요. 에이전트가 맞는 Gmail 도구를 고릅니다.

**검색과 요약:**
```
"Find all emails from John in the last week and summarize them"
```

**답장 초안:**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**받은편지함 정리:**
```
"Archive all newsletters from the past month"
```

**라벨 관리:**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**오래된 메일 비우기 (휴지통으로 감):**
```
"Delete all promotional emails older than 6 months"
```

## 워크플로 아이디어

Gmail은 [워크플로](/ko/workflows/introduction)와 [예약된 작업](/ko/workflows/scheduled-jobs)에서도 동작합니다.

| 아이디어 | 하는 일 |
| --- | --- |
| **일일 이메일 다이제스트** | 읽지 않은 이메일을 검색하고 요약해 아침 브리핑을 제시합니다 |
| **자동 분류** | 새 이메일을 검색하고 내용에 따라 라벨을 적용합니다 |
| **후속 알림** | 답장을 기다리는 이메일을 찾아 알림을 만듭니다 |
| **보고서 생성** | 조건에 맞는 이메일을 검색하고 요약 보고서를 모읍니다 |

## 개인정보

- **Enconvo Cloud와 Composio를 통해**: 메일은 요청한 일을 하기 위해서만 Enconvo Cloud와 Composio를 지나며, 저장되지 않습니다.
- **암호는 Google에 남음**: Google 자체 페이지에서 로그인하므로 Enconvo는 Google 암호를 보지 않습니다.
- **필요할 때**: 에이전트는 작업에 필요할 때만 Gmail을 읽습니다. 예외는 **메일 알림**으로, 켜면 새 메일이 도착할 때마다 확인합니다.
- **철회 가능**: Gmail 페이지의 **연결 해제**를 클릭하면 모든 기기에서 접근이 제거됩니다. [Google 계정 권한](https://myaccount.google.com/permissions)에서도 접근을 제거할 수 있습니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| **연결**이 회색 | 먼저 **설정 → 계정**에서 Enconvo 계정에 로그인합니다. |
| Gmail이 **다시 연결**을 표시 | 접근이 만료됐습니다. **다시 연결**을 클릭하고 Google로 다시 로그인합니다. |
| 에이전트가 Gmail을 쓰지 않음 | Gmail이 연결됐는지 확인합니다. **모든 채팅에서 사용 가능**이 꺼져 있으면 채팅에서 Gmail을 `@`로 언급합니다. |
| 검색이 아무것도 찾지 못함 | 먼저 `from:john`처럼 더 단순한 질의를 시도하고, 메일이 연결된 계정에 있는지 확인합니다. Gmail 검색은 Gmail 웹사이트와 같습니다. |
| 첨부가 보내지지 않음 | 파일 경로가 맞고 파일이 Mac에 있는지 확인합니다. |

메신저 채널을 사용하면 Telegram이나 Discord에서 Enconvo 에이전트와 대화할 수 있습니다. 각 채널은 에이전트 하나에 연결된 봇입니다. 들어오는 메시지는 그 에이전트로 전달되고, 에이전트가 답장을 씁니다. 에이전트 하나가 여러 채널을 담당할 수 있지만, 각 채널은 최대 하나의 에이전트만 담당합니다. **설정 → 메신저 채널**에서 설정하세요.

이 동영상은 아바타와 자격 증명 관리를 살펴보는 사이에 Telegram 채널을 설정합니다.

<YouTubePlayer videoId="O5rNJwqlisg" title="How to Use Avatars, IM Channels and Credentials in Enconvo | Step-by-Step Tutorial" />

## 시작하기 전에

- 해당 플랫폼에서 봇을 만들고 봇 토큰을 복사하세요(아래 [Telegram](#telegram)과 [Discord](#discord) 참고).
- 봇이 대기하는 동안 Enconvo를 실행하고 Mac을 온라인 상태로 유지하세요.

<Note>
무료 플랜에서는 메신저 봇을 한 번에 하나만 실행할 수 있습니다. Enconvo Cloud 플랜이나 평생 라이선스에서는 더 많이 실행할 수 있습니다. [요금제 및 가격](/ko/pricing)을 참고하세요.
</Note>

## 채널 추가

<Steps>
  <Step title="채널 추가">
    **설정 → 메신저 채널**을 열고 **새 채널 추가**를 클릭한 다음 **Telegram** 또는 **Discord**를 고르세요.
  </Step>
  <Step title="이름 지정">
    알아보기 쉬운 채널 이름을 지정하세요.
  </Step>
  <Step title="봇 토큰 붙여넣기">
    플랫폼의 봇 토큰을 **Bot Token**에 붙여넣으세요.
  </Step>
  <Step title="에이전트 고르기">
    **bind agent**에서 들어오는 메시지를 처리할 에이전트를 고르세요.
  </Step>
  <Step title="켜기">
    봇을 사용할 수 있는 대상을 검토하고(Telegram은 **Access Control**), **Enable Channel**을 켜세요.
  </Step>
  <Step title="테스트">
    **연결 확인**을 클릭하고 채널이 **연결됨**으로 표시되는지 확인하세요. 그런 다음 허용된 계정에서 테스트 메시지를 보내세요.
  </Step>
</Steps>

연결된 에이전트의 모델과 도구가 봇이 답할 수 있는 범위를 결정합니다.

## Telegram

Telegram의 **BotFather**로 봇을 만들고 봇 토큰을 복사하세요. 채널을 켜기 전에 **Access Control**을 여세요.

| 컨트롤 | 기능 |
| --- | --- |
| **정책** | **페어링 필요**(기본값): 새 사용자가 페어링 코드를 공유하고 승인을 기다립니다. **공개(모든 사용자)**: 봇을 찾은 사람은 누구나 사용할 수 있습니다. |
| **대기 중인 요청** | 페어링을 요청한 각 사용자를 **승인** 또는 **거부**합니다. 의도한 사람만 승인하세요. |
| **허용된 사용자** | 승인한 사용자입니다. **제거**를 클릭하면 목록에서 빠지며, 봇을 사용하려면 다시 페어링해야 합니다. |

봇이 1:1 채팅에서는 동작하지만 그룹에서는 동작하지 않는다면 채널의 접근 정책뿐 아니라 Telegram의 봇 개인정보 보호 설정과 그룹 권한도 확인하세요. 토큰만으로는 봇이 모든 대화에 접근할 수 없습니다.

## Discord

Discord Developer Portal에서 애플리케이션과 봇을 만드세요. 봇을 서버에 초대하고, 원하는 메시지를 받고 보내는 데 필요한 권한과 인텐트를 부여하세요. 봇 토큰을 Discord 채널에 붙여넣고 에이전트를 연결하세요.

연결은 되지만 답하지 않는다면 Discord의 채널 권한과 봇이 해당 유형의 메시지를 받는지 확인하세요. 봇은 의도한 서버와 채널로만 제한하세요.

## 세션과 답장

들어오는 대화마다 연결된 에이전트와 고유한 채팅 세션이 만들어집니다. 답장은 해당 대화를 따르며, 연결된 사용자끼리 하나의 대화 기록을 공유하지 않습니다. 연결된 에이전트를 바꾸면 채널이 다시 시작되며, 이후 메시지는 새 에이전트로 전달됩니다.

에이전트에 메시지를 보내는 대신 대화를 제어하려면 채팅에 봇 명령을 입력하세요. `/new`는 새 채팅 세션을 시작하고, `/stop`은 직전에 보낸 메시지를 포함해 진행 중인 답변을 중지합니다. 봇 명령은 Telegram과 Discord에서 동작하며, 첨부 파일과 함께 보낸 명령도 명령으로 실행됩니다.

공개 봇이나 팀 봇에는 알맞은 지침과 도구를 갖춘 전용 에이전트를 사용하세요. 다른 사람이 접근하게 하기 전에 그 에이전트가 사용할 수 있는 도구를 검토하세요.

## 예약 전송

[예약 작업](/ko/workflows/scheduled-jobs)은 결과를 설정해 둔 메신저 채팅으로 보낼 수 있습니다. 전송 대상은 직접 고르고, 작업의 실행 기록을 보고 실행 실패와 전송 실패를 구분하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 연결 끊김 | 봇 토큰, 네트워크, **Enable Channel**이 켜져 있는지, Enconvo가 실행 중인지 확인하세요. 연결이 조용히 끊긴 Discord 봇은 스스로 다시 연결됩니다. |
| 연결되었지만 응답이 없음 | 연결된 에이전트, 에이전트의 모델 제공업체, 플랫폼의 권한, 페어링 정책을 확인하세요. |
| 봇이 엉뚱하게 답함 | 연결된 에이전트의 지침, 도구, 모델을 확인하세요. |
| Telegram 사용자가 연결할 수 없음 | **대기 중인 요청**에서 해당 사용자의 페어링 요청을 찾고 **허용된 사용자**를 확인하세요. |
| 두 번째 봇이 시작되지 않음 | 무료 플랜에서는 메신저 봇을 한 번에 하나만 실행할 수 있습니다. 다른 봇을 끄거나 업그레이드하세요. |
| Enconvo를 종료하면 답장이 멈춤 | 봇은 Mac의 Enconvo를 통해 대기하므로 앱이 계속 실행 중이어야 합니다. |

메신저 채널은 Telegram과 Discord만 설정합니다. 다른 플러그인이나 MCP 서버로 Slack이나 Feishu를 사용한다면 해당 통합의 자체 가이드를 따르세요.

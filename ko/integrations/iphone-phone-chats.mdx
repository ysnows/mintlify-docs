휴대폰 채팅은 iPhone 앱 자체의 채팅입니다. 휴대폰에서 실행되며 Mac에서 실행되지 않으므로 페어링된 Mac 없이도 됩니다. 각 휴대폰 채팅은 Enconvo Cloud 포인트, 본인 API 키, 또는 iPhone에서 로그인한 플랜을 통해 모델을 씁니다. 휴대폰 채팅과 개인 지침은 Enconvo 계정을 통해 동기화됩니다.

대신 Mac에서 실행되는 채팅을 이어 가려면 [iPhone 앱](/ko/integrations/iphone-app)을 보세요.

## 기본 모델 고르기

1. iPhone에서 **설정 → AI 모델**을 엽니다.
2. **기본 모델**을 탭하고 모델을 고릅니다. 새 채팅이 그것으로 시작합니다.
3. 한 채팅의 모델을 바꾸려면 그 채팅의 모델 선택기를 씁니다.

Mac의 Enconvo는 Mac에 그 제공업체가 있을 때 같은 모델로 시작합니다. Mac의 모델을 iPhone에서 쓸 수 없으면 페이지가 **기본 모델** 아래에 그렇게 말하고, 무엇을 추가하거나 로그인할지 제안합니다.

## 키나 제공업체 추가

**AI 모델**은 Enconvo Cloud와 휴대폰에서 쓸 수 있는 모든 제공업체를 나열하며 PipeLLM도 포함됩니다.

1. 제공업체를 탭한 다음 **API 키 추가**를 탭하고 제공업체 사이트에서 만든 키를 붙여 넣습니다.
2. 목록에 없는 제공업체를 추가하려면 **제공업체 추가**를 탭하고 제공업체, **OpenAI 호환**, **Anthropic 호환**을 고릅니다. 호환 제공업체는 OpenAI의 Chat Completions 또는 Responses API, 또는 Anthropic의 Messages API를 말하는 서버 주소가 필요합니다.
3. 제공업체가 필요한 모델을 나열하지 않으면 그 페이지에서 **ID로 모델 추가**를 탭합니다.

키는 iCloud 키체인에 남고, 속한 제공업체에만 보내집니다.

## 플랜으로 로그인

다섯 제공업체가 API 키와 Cloud 포인트 없이, 이미 결제하는 플랜으로 휴대폰 채팅을 쓰게 합니다.

| 제공업체 | 플랜 | 버튼 |
| --- | --- | --- |
| OpenAI | ChatGPT | **ChatGPT로 로그인** |
| xAI | Grok | **Grok로 로그인** |
| Mistral | Le Chat | **Mistral로 로그인** |
| GitHub Copilot | Copilot | **GitHub로 로그인** |
| Antigravity | Antigravity (Google) | **Google로 로그인** |

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델**에서 제공업체를 탭합니다. OpenAI, xAI, Mistral은 **인증** 아래 플랜 카드를 고릅니다. 다른 카드는 **API 키**이며, **사용 중**이 지금 휴대폰 채팅이 쓰는 것을 표시합니다.
  </Step>
  <Step title="로그인">
    로그인 버튼을 탭하고 열리는 페이지에서 로그인을 마칩니다. 플랜이 있는 계정을 씁니다.
  </Step>
  <Step title="결과 확인">
    제공업체 페이지로 돌아오면 플랜, 계정, 플랜에 있는 모델 수가 보입니다. 모델을 고르거나 **기본으로 설정**을 탭해 새 채팅을 그것으로 시작합니다.
  </Step>
</Steps>

플랜 로그인은 이 iPhone에 남습니다. iCloud나 Mac으로 동기화되지 않으며, Mac은 자체 로그인을 유지합니다. 플랜 자체의 사용 한도가 적용됩니다.

### GitHub Copilot

**GitHub로 로그인** 뒤에 앱이 GitHub 코드를 보여 줍니다. **계속**이 코드를 복사하고 GitHub 페이지를 열며, 그곳에서 붙여 넣고 Enconvo를 승인합니다. GitHub 페이지가 열려 있는 동안 코드가 화면에 남으므로 다시 복사할 수 있습니다.

모델 목록은 Copilot 플랜이 쓸 수 있는 모델만 보여 줍니다. Copilot Free는 유료 플랜보다 모델이 적습니다.

### Antigravity

로그인 전에 앱이 **Antigravity에 로그인하기 전에**를 보여 줍니다. Enconvo는 Antigravity 앱 자체의 Google 클라이언트로 로그인하며, Google은 Antigravity 밖에서 쓰인다고 보는 Antigravity 계정을 정지할 수 있습니다. 잃어도 되는 계정을 쓰세요. **동의**는 Google 로그인으로 이어지고, **취소**는 모든 것을 그대로 둡니다.

Antigravity는 플랜의 Gemini와 Claude 모델을 제공하며, 각각 Antigravity가 가진 추론 노력 수준이 있습니다.

### ChatGPT 사용량

OpenAI 페이지는 ChatGPT 플랜의 5시간 한도와 주간 한도가 얼마나 남았는지, 각 한도가 언제 초기화되는지, 플랜이 언제 갱신되는지를 보여 줍니다. 계정 메뉴의 **사용량 새로고침**을 탭해 업데이트합니다. 한도가 다하면 초기화될 때까지 페이지가 그렇게 말합니다.

### 로그아웃

제공업체를 열고 계정 메뉴에서 **로그아웃**을 고릅니다. 플랜을 쓰는 채팅은 로그아웃 후 다른 모델이 필요합니다. Mistral의 경우 로그인이 만든 키는 Mistral 작업 공간에 남습니다.

## 앱을 떠난 뒤에도 답변 이어 가기

Enconvo Cloud 모델이면 앱을 떠나거나 휴대폰을 잠근 뒤에도 답변이 이어질 수 있습니다. 메시지 칸의 **Cloud 도구**에서 **클라우드에서 실행**을 켭니다. 본인 키의 채팅은 항상 휴대폰에서 답합니다.

## 컴퓨터에서 이어 가기

휴대폰 채팅을 페어링된 컴퓨터로 옮겨 그 컴퓨터의 에이전트, 파일, 도구로 이어 갑니다. 답변이 아직 실행 중일 때도 됩니다.

1. 채팅 메뉴를 열거나 사이드바에서 채팅을 길게 누르고 **컴퓨터에서 계속**을 고릅니다. 메뉴는 기본적으로 가는 컴퓨터를 이름 짓습니다.
2. 컴퓨터와 에이전트를 고르고 확인합니다.

채팅이 그 컴퓨터로 옮겨 그곳에서 이어집니다. 공유 채팅의 링크를 열어도 어디서 이어 갈지 묻습니다.

## 동작 버튼의 음성 채팅

동작 버튼이 음성 채팅을 시작하면 Dynamic Island가 **Enconvo가 화면을 보게 할까요?**라고 묻습니다. **음성만**을 고르거나, 읽고 있는 것을 Enconvo가 보게 **화면 공유**를 고릅니다. 통화 컨트롤의 **화면 공유** 버튼은 통화 중에 공유를 시작하거나 멈춥니다.

## 추론 노력

생각하는 모델을 고르면 선택기가 그 추론 노력으로 이어집니다. 모델에 고른 노력은 채팅 헤더의 제공업체 옆에 표시되고 그 모델의 모든 채팅에 적용됩니다. 플랜 페이지는 플랜이 제공하는 수준만 나열합니다.

## 긴 채팅

긴 채팅이 모델의 컨텍스트 창에 가까워지면 Mac과 같이 같은 모델이 이전 메시지를 요약합니다. 채팅은 모든 메시지를 유지하고, **컨텍스트 압축됨** 표시가 요약이 시작하는 곳을 보여 줍니다. 항상 켜져 있습니다.

## 문제 해결

| 보이는 것 | 해결 방법 |
| --- | --- |
| **ChatGPT 로그인이 끝나지 않음**(또는 Grok, Mistral, GitHub Copilot, Antigravity) | **다시 로그인**을 탭하고 열리는 페이지에서 로그인을 마칩니다. |
| **플랜이 모델을 제공하지 않음** | 플랜 목록에서 다른 모델을 고릅니다. Copilot Free에서는 일부 모델만 제공됩니다. |
| **모델 나열 중…**이 끝나지 않음 | iPhone의 네트워크 연결을 확인한 다음 제공업체 페이지를 나갔다가 다시 엽니다. |
| Mac의 기본 모델이 iPhone에 없음 | **기본 모델** 아래 안내처럼 제공업체 키를 추가하거나 플랜에 로그인합니다. |

iPhone 채팅은 iPhone 앱 자체의 채팅입니다. Mac이 아니라 휴대전화에서 실행되므로 페어링된 Mac이 없어도 사용할 수 있습니다. 각 iPhone 채팅은 Enconvo Cloud 포인트, 내 API 키, 또는 iPhone에서 로그인한 플랜을 통해 모델을 사용합니다. iPhone 채팅과 개인 지침은 Enconvo 계정을 통해 동기화됩니다.

대신 Mac에서 실행되는 채팅을 이어서 사용하려면 [iPhone 앱](/ko/integrations/iphone-app)을 참고하세요.

## 기본 모델 고르기

1. iPhone에서 **설정 → AI 모델**을 여세요.
2. **기본 모델**을 탭하고 모델을 고르세요. 새 채팅은 이 모델로 시작합니다.
3. 채팅 하나의 모델을 바꾸려면 해당 채팅의 모델 선택기를 사용하세요.

Mac에 해당 제공업체가 있으면 Mac의 Enconvo도 같은 모델로 시작합니다. Mac의 모델을 iPhone에서 사용할 수 없으면 페이지가 **기본 모델** 아래에 그 사실을 알려 주고 무엇을 추가하거나 로그인해야 하는지 제안합니다.

## 키 또는 제공업체 추가

**AI 모델**에는 Enconvo Cloud와 휴대전화에서 사용할 수 있는 모든 제공업체가 PipeLLM을 포함해 나열됩니다.

1. 제공업체를 탭한 다음 **API 키 추가**를 탭하고, 제공업체 사이트에서 만든 키를 붙여넣으세요.
2. 목록에 없는 제공업체를 추가하려면 **제공업체 추가**를 탭하고 제공업체, **OpenAI 호환**, 또는 **Anthropic 호환**을 고르세요. 호환 제공업체에는 OpenAI의 Chat Completions 또는 Responses API나 Anthropic의 Messages API를 지원하는 서버의 주소가 필요합니다.
3. 제공업체가 필요한 모델을 목록에 표시하지 않으면 해당 페이지에서 **ID로 모델 추가**를 탭하세요.

키는 iCloud 키체인에 보관되며 해당하는 제공업체에만 전송됩니다.

## 플랜으로 로그인

다섯 제공업체는 API 키나 Cloud 포인트 없이, 이미 결제 중인 플랜을 iPhone 채팅에서 사용하도록 해 줍니다.

| 제공업체 | 플랜 | 버튼 |
| --- | --- | --- |
| OpenAI | ChatGPT | **ChatGPT로 로그인** |
| xAI | Grok | **Grok로 로그인** |
| Mistral | Le Chat | **Mistral로 로그인** |
| GitHub Copilot | Copilot | **GitHub로 로그인** |
| Antigravity | Antigravity (Google) | **Google로 로그인** |

<Steps>
  <Step title="제공업체 열기">
    **설정 → AI 모델**에서 제공업체를 탭하세요. OpenAI, xAI, Mistral은 **인증**에서 플랜 카드를 고르세요. 다른 카드는 **API 키**이며, **사용 중**은 iPhone 채팅이 지금 사용하는 쪽을 표시합니다.
  </Step>
  <Step title="로그인">
    로그인 버튼을 탭하고 열리는 페이지에서 로그인을 마치세요. 플랜이 있는 계정을 사용하세요.
  </Step>
  <Step title="결과 확인">
    제공업체 페이지로 돌아오면 플랜, 계정, 플랜에서 사용할 수 있는 모델 수가 표시됩니다. 모델을 고르거나 **기본값으로 설정**을 탭해 새 채팅을 그 모델로 시작하세요.
  </Step>
</Steps>

플랜 로그인은 이 iPhone에만 남습니다. iCloud나 Mac으로 동기화되지 않으며, Mac은 자체 로그인을 유지합니다. 플랜 자체의 사용량 한도가 적용됩니다.

### GitHub Copilot

**GitHub로 로그인** 후 앱에 GitHub 코드가 표시됩니다. **계속**을 누르면 코드가 복사되고 GitHub 페이지가 열리며, 거기에 붙여넣고 Enconvo를 승인하세요. GitHub 페이지가 열려 있는 동안 코드가 화면에 남아 있으므로 다시 복사할 수 있습니다.

모델 목록에는 Copilot 플랜에서 사용할 수 있는 모델만 표시됩니다. Copilot Free는 유료 플랜보다 제공하는 모델이 적습니다.

### Antigravity

로그인할 때마다 앱에 **Antigravity에 로그인하기 전에**가 표시됩니다. Enconvo는 Antigravity 앱 자체의 Google 클라이언트로 로그인하며, Google은 Antigravity 밖에서 사용되는 것이 확인된 Antigravity 계정을 정지할 수 있습니다. 잃어도 괜찮은 계정을 사용하세요. **동의**를 누르면 Google 로그인으로 진행하고, **취소**를 누르면 모든 것이 그대로 유지됩니다.

Antigravity는 플랜에서 Gemini와 Claude 모델을 제공하며, 각 모델에는 Antigravity가 지원하는 추론 강도 수준이 있습니다.

### ChatGPT 사용량

OpenAI 페이지에는 ChatGPT 플랜의 5시간 및 주간 한도가 얼마나 남았는지, 각 한도가 초기화되는 시점, 플랜이 갱신되는 시점이 표시됩니다. 계정 메뉴의 **사용량 새로고침**을 탭하면 업데이트됩니다. 한도가 소진되면 초기화될 때까지 페이지에 그 사실이 표시됩니다.

### 로그아웃

제공업체를 열고 계정 메뉴에서 **로그아웃**을 고르세요. 로그아웃하면 해당 플랜을 사용하던 채팅에는 다른 모델이 필요합니다. Mistral의 경우 로그인으로 만들어진 키는 Mistral 워크스페이스에 남습니다.

## 앱을 떠난 뒤에도 계속 답장받기

Enconvo Cloud 모델에서는 앱을 떠나거나 휴대전화를 잠근 뒤에도 답장이 계속 진행될 수 있습니다. 메시지 입력란의 **Cloud 도구**에서 **클라우드에서 실행**을 켜세요. 내 키를 사용하는 채팅은 항상 휴대전화에서 답합니다.

## 컴퓨터에서 계속

iPhone 채팅을 페어링된 컴퓨터로 옮기면 그 컴퓨터의 에이전트, 파일, 도구로 이어서 진행할 수 있습니다. 답장이 아직 진행 중일 때도 가능합니다.

1. 채팅 메뉴를 열거나 사이드바에서 채팅을 길게 누르고 **컴퓨터에서 계속**을 고르세요. 메뉴에는 기본으로 보낼 컴퓨터의 이름이 표시됩니다.
2. 컴퓨터와 에이전트를 고르고 확인하세요.

채팅이 그 컴퓨터로 옮겨져 그곳에서 계속됩니다. 공유된 채팅의 링크를 열 때도 어디서 이어갈지 묻습니다.

## 동작 버튼으로 음성 채팅

동작 버튼으로 음성 채팅을 시작하면 Dynamic Island가 **Enconvo가 화면을 보게 할까요?**라고 묻습니다. **음성만**을 고르거나, Enconvo가 읽고 있는 내용을 볼 수 있도록 **화면 보여주기**를 고르세요. 통화 컨트롤의 **화면 보여주기** 버튼으로 통화 중에 공유를 시작하거나 중지할 수 있습니다.

## 추론 강도

생각하는 모델을 고르면 선택기가 추론 강도로 이어집니다. 모델에 대해 고른 강도는 채팅 헤더의 제공업체 옆에 표시되며 해당 모델을 쓰는 모든 채팅에 적용됩니다. 플랜 페이지에는 플랜이 제공하는 수준만 나열됩니다.

## 긴 채팅

긴 채팅이 모델의 컨텍스트 창에 가까워지면 Mac에서처럼 같은 모델이 오래된 메시지를 요약합니다. 채팅은 모든 메시지를 유지하며, **컨텍스트 압축됨** 표시가 요약이 시작되는 지점을 알려 줍니다. 이 기능은 항상 켜져 있습니다.

## 문제 해결

| 표시되는 내용 | 해결 방법 |
| --- | --- |
| **ChatGPT 로그인을 완료하지 못했습니다**(또는 Grok, Mistral, GitHub Copilot, Antigravity) | **다시 로그인**을 탭하고 열리는 페이지에서 로그인을 마치세요. |
| **플랜에서 제공하지 않는** 모델 | 플랜의 목록에서 다른 모델을 고르세요. Copilot Free에서는 일부 모델만 제공됩니다. |
| **모델 목록을 가져오는 중…**이 끝나지 않음 | iPhone의 네트워크 연결을 확인한 다음 제공업체 페이지를 나갔다가 다시 여세요. |
| Mac의 기본 모델이 iPhone에 없음 | **기본 모델** 아래 안내에 따라 제공업체의 키를 추가하거나 해당 플랜에 로그인하세요. |

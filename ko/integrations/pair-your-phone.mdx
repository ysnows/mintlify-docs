---
title: "휴대폰과 페어링"
description: "Enconvo iPhone 또는 Android 앱을 Mac, Windows PC, Linux 데스크톱, 터미널만 있는 Linux 서버와 페어링합니다."
---

휴대폰의 Enconvo 앱은 각 컴퓨터와 페어링하므로, 그 프로젝트와 채팅이 휴대폰에 있습니다. 휴대폰에서 연 채팅은 그 컴퓨터에서 계속 실행되며, 파일, 앱, 에이전트를 씁니다. 휴대폰은 Enconvo 릴레이를 통해 컴퓨터에 닿고, 메시지는 종단 간 암호화됩니다. 휴대폰과 컴퓨터가 같은 네트워크에 있으면 앱이 직접 연결하므로 집이나 사무실에서 더 빨리 연결되고 답합니다.

각 컴퓨터는 휴대폰과 따로 페어링됩니다. 컴퓨터 둘을 서로 페어링해도(예: Linux 노트북과 Mac) 어느 쪽도 휴대폰에 추가되지 않습니다. 휴대폰에서 쓸 컴퓨터마다 휴대폰과 페어링하세요.

## 시작하기 전에

- **앱을 받습니다.** iPhone: [TestFlight](https://testflight.apple.com/join/MJQuEN28). Android: Google Play 또는 APK. 컴퓨터의 **설정 → 연결**에 있는 **휴대폰 앱 받기**에 각각의 다운로드 코드가 있습니다. Mobile Companion 플러그인의 **휴대폰 앱 받기** 버튼도 엽니다.
- **계정을 하나로 씁니다.** 휴대폰 앱과 컴퓨터를 같은 Enconvo 계정에 로그인합니다. 계정의 휴대폰만 페어링할 수 있습니다. 무료 계정도 페어링할 수 있고, 휴대폰에서 컴퓨터의 채팅과 원격 화면을 쓸 수 있습니다.
- **컴퓨터를 켜 두고 Enconvo를 실행합니다.** 휴대폰은 Enconvo가 그곳에서 실행 중일 때만 컴퓨터에 닿습니다.

## Mac, Windows, Linux 데스크톱

세 곳 모두 단계가 같습니다.

<Steps>
  <Step title="컴퓨터에 페어링 코드 표시">
    사이드바 아래의 기기 전환기를 클릭한 다음 **기기 추가 → 휴대폰 페어링**을 고릅니다. 또는 **설정 → 연결**을 열고 **페어링 코드 표시**를 선택합니다. QR 코드가 나타납니다. 한 번만 되며 5분 동안 유효합니다.
  </Step>
  <Step title="휴대폰으로 스캔">
    Enconvo 앱에서 **원격**을 열고 **컴퓨터 페어링**을 탭한 다음 카메라를 코드에 맞춥니다. iPhone 카메라, Android 카메라, Google Lens로도 스캔할 수 있습니다. 코드가 Enconvo를 열고 그곳에서 컴퓨터를 확인합니다. 앱이 아직 없으면 코드의 링크가 설치한 다음 페어링하도록 돕습니다.
  </Step>
  <Step title="휴대폰에서 컴퓨터 사용">
    휴대폰이 잠시 후 페어링되고 컴퓨터를 보여 줍니다. 페어링된 컴퓨터가 둘 이상이면 **원격**에서 전환합니다.
  </Step>
</Steps>

코드가 만료되면 **새 코드 표시**를 선택하고 다시 스캔합니다.

## 터미널만 있는 Linux 서버

서버에는 코드를 보여 줄 창이 없으므로 명령줄이 출력합니다. Enconvo 2.5.15 Beta 1 이상이 필요합니다. 먼저 [서버에 설치](/ko/getting-started/linux)를 따릅니다.

<Steps>
  <Step title="서버 로그인">
    ```bash
    enconvo login
    ```
    출력된 코드를 `enconvo.com/device`에서 승인합니다.
  </Step>
  <Step title="Enconvo를 계속 실행">
    ```bash
    enconvo service install
    ```
    휴대폰은 Enconvo가 그곳에서 실행 중일 때만 서버에 닿습니다.
  </Step>
  <Step title="페어링 코드 출력">
    ```bash
    enconvo companion pair --phone
    ```
    터미널에 QR 코드를 그리고 아래에 링크를 두며, 만료 시각을 말합니다. 코드는 한 번만 되며 5분 동안 유효합니다.
  </Step>
  <Step title="스캔하거나 링크 열기">
    휴대폰 카메라로 코드를 스캔하거나 휴대폰에서 링크를 엽니다. Enconvo 앱에서 확인하면 서버가 휴대폰에 나타납니다.
  </Step>
</Steps>

- **SSH를 통해**: 코드는 본인 터미널에 그려지므로 SSH에서도 됩니다. 줄이 넘어가면 창을 넓히거나 대신 링크를 엽니다.
- **로그인**: 본인 터미널에 입력한 코드는 휴대폰 앱도 로그인시키므로, 본인 휴대폰에만 보내세요. 파이프하거나 저장한 출력, 또는 에이전트가 실행한 명령은 앱을 로그인시키지 않는 링크만 출력합니다. 먼저 앱을 같은 계정에 로그인하세요.
- **만료**: `enconvo companion pair --phone`을 다시 실행합니다.

## 페어링된 휴대폰 관리

각 컴퓨터의 **설정 → 연결**이 페어링된 휴대폰을 나열합니다.

| 하려는 일 | 하는 방법 |
|---|---|
| 다른 휴대폰 페어링 | 새 코드를 표시하고 그 휴대폰으로 스캔합니다. 컴퓨터는 페어링된 휴대폰을 최대 10대까지 둘 수 있습니다. |
| 휴대폰 이름 바꾸기 | 휴대폰을 클릭한 다음 이름 옆의 **휴대폰 이름 바꾸기**를 클릭합니다. |
| 휴대폰 제거 | 옆의 **제거**를 선택합니다. 그 휴대폰은 더 이상 이 컴퓨터에 닿을 수 없습니다. |
| 처음부터 | **연결 초기화**를 선택합니다. 모든 휴대폰이 제거되고 다시 페어링해야 합니다. |

## 문제 해결

| 문제 | 해결 |
|---|---|
| 컴퓨터가 휴대폰에 없음 | 그 컴퓨터 자체와 휴대폰을 페어링합니다. 다른 컴퓨터와 페어링해도 추가되지 않습니다. |
| **이 코드는 만료되었습니다** | 새 코드를 표시하거나 명령을 다시 실행하고 5분 안에 스캔합니다. |
| **휴대폰을 페어링하려면 로그인하세요** | 컴퓨터를 Enconvo에 로그인합니다. 서버에서는 `enconvo login`을 실행합니다. |
| 서버가 로그인되지 않았다고 함 | `enconvo login`을 실행한 다음 `enconvo companion pair --phone`을 다시 실행합니다. |
| 휴대폰이 서버를 오프라인으로 표시함 | Enconvo가 그곳에서 실행 중인지 확인합니다. `enconvo service install`, 로그아웃하면 멈추면 `sudo loginctl enable-linger "$USER"`입니다. |

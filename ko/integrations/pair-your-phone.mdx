---
title: "휴대전화 페어링"
description: "Enconvo iPhone 또는 Android 앱을 Mac, Windows PC, Linux 데스크탑, 또는 터미널만 있는 Linux 서버와 페어링하세요."
---

휴대전화의 Enconvo 앱은 내 컴퓨터 각각과 페어링되어 그 컴퓨터의 프로젝트와 채팅이 휴대전화에 표시됩니다. 휴대전화에서 연 채팅은 그 컴퓨터의 파일, 앱, 에이전트와 함께 그곳에서 계속 실행됩니다. 휴대전화는 Enconvo 릴레이를 통해 컴퓨터에 연결되며 메시지는 종단 간 암호화됩니다. 휴대전화와 컴퓨터가 같은 네트워크에 있으면 앱이 컴퓨터에 직접 연결하므로 집이나 사무실에서는 더 빠르게 연결되고 응답합니다.

각 컴퓨터는 휴대전화와 따로 페어링됩니다. 컴퓨터끼리 페어링하는 것(예를 들어 Linux 노트북과 Mac)은 어느 쪽도 휴대전화에 추가하지 않습니다. 휴대전화에서 사용하려는 컴퓨터마다 휴대전화를 페어링하세요.

## 시작하기 전에

- **앱 받기.** iPhone: [TestFlight](https://testflight.apple.com/join/MJQuEN28). Android: Google Play 또는 APK. 컴퓨터의 **설정 → 연결**에 있는 **휴대폰 앱 받기**에 각각의 다운로드 코드가 있으며, 모바일 컴패니언 플러그인의 **휴대폰 앱 받기** 버튼으로도 열 수 있습니다.
- **계정 하나 사용.** 휴대전화 앱과 컴퓨터를 같은 Enconvo 계정으로 로그인하세요. 내 계정의 휴대전화만 페어링할 수 있습니다. 무료 계정도 페어링할 수 있고, 휴대전화에서 컴퓨터의 채팅과 원격 화면을 사용할 수 있습니다.
- **컴퓨터를 켜 두고 Enconvo 실행 유지.** 휴대전화는 컴퓨터에서 Enconvo가 실행 중일 때만 그 컴퓨터에 접근할 수 있습니다.

## Mac, Windows 또는 Linux 데스크탑

세 가지 모두 단계가 같습니다.

<Steps>
  <Step title="컴퓨터에 페어링 코드 표시">
    사이드바 아래쪽의 기기 전환기를 클릭한 다음 **기기 추가 → 휴대전화 페어링**을 클릭하세요. 또는 **설정 → 연결**을 열고 **페어링 코드 표시**를 선택하세요. QR 코드가 나타나며, 한 번만 사용할 수 있고 5분 동안 유효합니다.
  </Step>
  <Step title="휴대전화로 스캔">
    Enconvo 앱에서 **원격**을 열고 **컴퓨터 페어링**을 탭한 다음 카메라를 코드에 맞추세요. iPhone 카메라, Android 카메라, Google 렌즈로 스캔해도 됩니다. 코드가 Enconvo를 열고, 거기서 컴퓨터를 확인합니다. 앱이 아직 설치되어 있지 않다면 코드의 링크가 설치한 다음 페어링하는 것을 도와줍니다.
  </Step>
  <Step title="휴대전화에서 컴퓨터 사용">
    휴대전화가 곧바로 페어링되고 컴퓨터가 표시됩니다. 컴퓨터가 둘 이상 페어링되어 있으면 **원격**에서 전환하세요.
  </Step>
</Steps>

코드가 만료되면 **새 코드 표시**를 선택하고 다시 스캔하세요.

## 터미널만 있는 Linux 서버

서버에는 코드를 표시할 창이 없으므로 명령줄이 코드를 출력합니다. Enconvo 2.5.15 Beta 1 이상이 필요합니다. 먼저 [서버에 설치](/ko/getting-started/linux)를 따라 하세요.

<Steps>
  <Step title="서버 로그인">
    ```bash
    enconvo login
    ```
    출력되는 코드를 `enconvo.com/device`에서 승인하세요.
  </Step>
  <Step title="Enconvo 계속 실행">
    ```bash
    enconvo service install
    ```
    휴대전화는 서버에서 Enconvo가 실행 중일 때만 서버에 접근할 수 있습니다.
  </Step>
  <Step title="페어링 코드 출력">
    ```bash
    enconvo companion pair --phone
    ```
    터미널에 QR 코드가 그려지고 그 아래에 링크가 나오며 만료 시점을 알려 줍니다. 코드는 한 번만 사용할 수 있고 5분 동안 유효합니다.
  </Step>
  <Step title="스캔하거나 링크 열기">
    휴대전화 카메라로 코드를 스캔하거나 휴대전화에서 링크를 여세요. Enconvo 앱에서 확인하면 서버가 휴대전화에 나타납니다.
  </Step>
</Steps>

- **SSH로**: 코드는 내 터미널에 그려지므로 SSH로도 동작합니다. 줄이 넘어가면 창을 넓히거나 링크를 대신 여세요.
- **로그인**: 내 터미널에 입력한 경우 코드는 휴대전화 앱도 로그인시키므로 내 휴대전화에만 보내세요. 파이프로 넘기거나 저장한 출력, 에이전트가 실행한 명령은 링크만 출력하며 이 링크는 앱을 로그인시키지 않습니다. 먼저 앱을 같은 계정으로 로그인하세요.
- **만료됨**: `enconvo companion pair --phone`을 다시 실행하세요.

## 페어링된 휴대전화 관리

각 컴퓨터의 **설정 → 연결**에 페어링된 휴대전화가 나열됩니다.

| 작업 | 방법 |
|---|---|
| 다른 휴대전화 페어링 | 새 코드를 표시하고 그 휴대전화로 스캔하세요. 컴퓨터 한 대에 최대 10대의 휴대전화를 페어링할 수 있습니다. |
| 휴대전화 이름 바꾸기 | 휴대전화를 클릭한 다음 이름 옆의 **휴대폰 이름 바꾸기**를 클릭하세요. |
| 휴대전화 제거 | 옆의 **제거**를 선택하세요. 그 휴대전화는 더 이상 이 컴퓨터에 접근할 수 없습니다. |
| 처음부터 다시 시작 | **연결 재설정**을 선택하세요. 모든 휴대전화가 제거되며 다시 페어링해야 합니다. |

## 문제 해결

| 문제 | 해결 방법 |
|---|---|
| 컴퓨터가 휴대전화에 없음 | 그 컴퓨터 자체와 휴대전화를 페어링하세요. 다른 컴퓨터와 페어링해도 추가되지 않습니다. |
| **이 코드가 만료되었습니다** | 새 코드를 표시하거나 명령을 다시 실행하고 5분 안에 스캔하세요. |
| **로그인하여 휴대폰 페어링** | 컴퓨터를 Enconvo에 로그인하세요. 서버에서는 `enconvo login`을 실행하세요. |
| 서버가 로그인되어 있지 않다고 나옴 | `enconvo login`을 실행한 다음 `enconvo companion pair --phone`을 다시 실행하세요. |
| 휴대전화에 서버가 오프라인으로 표시됨 | 그곳에서 Enconvo가 실행 중인지 확인하세요. `enconvo service install`을 실행하고, 로그아웃하면 멈추는 경우 `sudo loginctl enable-linger "$USER"`를 실행하세요. |

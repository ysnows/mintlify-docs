title: "iPhone 앱"

---

Enconvo iPhone 앱은 Mac과 페어링되어 Mac의 프로젝트와 채팅이 휴대전화에 표시됩니다. 휴대전화에서 연 모든 채팅은 Mac의 파일, 앱, 에이전트와 함께 Mac에서 계속 실행됩니다. 이 가이드는 로그인, Mac에 페어링 코드 표시, iPhone으로 스캔까지 휴대전화 페어링을 처음부터 끝까지 안내합니다.

<Note>
iPhone 앱은 베타입니다. [TestFlight](https://testflight.apple.com/join/MJQuEN28)에서 설치하거나, Mac의 **설정 → 연결**에 있는 **휴대폰 앱 받기** 아래의 TestFlight 코드를 스캔하세요. 페어링하려면 Mac에 Enconvo 2.5.6 베타 이상이 필요합니다. TestFlight의 iPhone 앱과 Google Play의 Android 앱은 아메리카, 유럽, 중동, 일본, 한국, 동남아시아에서 사용할 수 있습니다. Android APK는 어디서나 설치할 수 있습니다.
</Note>

## iPhone 페어링

Windows PC, Linux 데스크탑 또는 터미널만 있는 Linux 서버와 페어링하려면 [휴대전화 페어링](/ko/integrations/pair-your-phone)을 참고하세요.

<Steps>
  <Step title="iPhone에서 로그인">
    iPhone 앱을 설치하고 Mac과 같은 Enconvo 계정으로 로그인하세요. Apple, Google 또는 이메일로 받은 6자리 코드로 로그인할 수 있습니다. 내 계정에 로그인한 휴대전화만 페어링할 수 있습니다. 무료 계정도 페어링할 수 있고, Mac의 채팅과 원격 화면을 사용하고, 아바타를 사용할 수 있습니다.
  </Step>
  <Step title="페어링 코드 표시">
    Mac에서 **설정 → 연결**을 열고 **페어링 코드 표시**를 선택하세요. QR 코드는 5분 동안 유효합니다. 만료되면 **새 코드 표시**를 선택하세요.
  </Step>
  <Step title="iPhone으로 스캔">
    휴대전화에서 **원격**을 열고 **컴퓨터 페어링**을 탭한 다음 카메라를 Mac의 코드에 맞추세요. iPhone 카메라로도 됩니다. Enconvo가 열리고 거기서 Mac을 확인합니다. 두 기기가 곧바로 페어링됩니다. 휴대전화는 Enconvo 릴레이를 통해 Mac에 연결되며 메시지는 종단 간 암호화됩니다.
  </Step>
  <Step title="내 Mac을 휴대전화에서">
    원격에서 Mac이 **온라인**으로 표시되면 Mac의 프로젝트와 채팅이 바로 휴대전화에 나타납니다.
  </Step>
  <Step title="채팅 열기">
    아무 채팅이나 열어 중단한 곳에서 이어가세요. 채팅은 여전히 Mac에서 실행되므로 그 Mac의 파일, 앱, 에이전트를 사용할 수 있습니다.
  </Step>
  <Step title="계속 접근 가능하게 유지">
    **연결**(또는 **설정 → 잠자기 방지**)에서 **이 Mac의 잠자기 방지**를 켜세요. 배터리로 작동할 때도 Mac이 잠자지 않아 휴대전화가 항상 접근할 수 있습니다. 화면을 켜 두거나, 정해진 시간 후 꺼지게 하거나, 덮개를 닫은 채 Mac을 깨어 있게 할 수도 있습니다(이 경우 관리자 암호를 한 번 묻습니다).
  </Step>
  <Step title="휴대전화 제거">
    휴대전화를 잃어버렸나요? **연결 → 페어링된 휴대전화**에서 옆의 **제거**를 선택하세요. 그 휴대전화는 더 이상 Mac에 접근할 수 없습니다. 다시 사용하려면 새 코드로 페어링하세요.
  </Step>
</Steps>

코드 아래에 Mac이 안내하는 경우, 코드를 스캔하면 iPhone도 Enconvo 계정에 로그인됩니다. 이런 코드는 내 iPhone으로만 스캔하세요.

## 휴대전화에서 할 수 있는 일

페어링하면 다음을 할 수 있습니다.

- Mac의 프로젝트와 채팅을 둘러보고 어떤 채팅이든 이어서 사용합니다.
- 에이전트가 Mac에서 작업하는 동안 묻는 질문에 답합니다.
- 채팅이 끝나면 알림을 받고 알림에서 바로 답장합니다.
- **원격 화면**으로 Mac의 화면을 보고 제어합니다.
- 휴대전화 자체에서 Enconvo Cloud 포인트, 내 API 키, 로그인한 플랜(ChatGPT, Grok, Le Chat, GitHub Copilot, Antigravity)으로 AI 모델과 채팅합니다. [iPhone 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.
- 친구, 팀원과 채팅하고 통화하며 화상 회의에 참여합니다. [휴대전화의 통화와 친구](/ko/integrations/phone-calls-and-friends)를 참고하세요.

앱은 페어링된 Mac, Windows PC, Linux 컴퓨터를 **컴퓨터**라고 부릅니다. Android 앱은 별도로 언급하지 않는 한 같은 방식으로 동작합니다.

## 컴퓨터의 채팅에서 작업하기

컴퓨터의 채팅은 그곳에서와 똑같이 보이고 동작하며, 백그라운드 작업, 하위 에이전트, 방향 지시도 지원합니다.

- **홈**은 메시지 입력란 바로 위에 활성 채팅을 보여 줍니다. 카드의 손잡이를 위로 쓸어 올리거나 **전체**를 탭하면 모든 활성 채팅이 내가 처리할 것, 실행 중인 것, 결과가 있는 것으로 묶여 표시됩니다.
- 사이드바의 **활성** 그룹에는 내 응답을 기다리거나, 실패했거나, 아직 실행 중이거나, 읽지 않은 결과가 있는 채팅이 모입니다. 파란 점은 아무도 읽지 않은 결과를, 돌아가는 링은 실행 중인 채팅을 나타냅니다. **고정됨**과 **최근**은 접을 수 있습니다.
- 답변이 실행되는 동안 보낸 내용은 Mac에서 Return을 누를 때처럼 실행 중인 작업의 방향을 지시합니다. 그동안 입력란에는 "실행 중인 작업에 방향 지시…"가 표시됩니다.
- 하위 에이전트를 탭하면 채팅 위의 시트에 그 단계가 열립니다. 가장 최신 단계에서 열리고 새 출력을 따라갑니다. 아래로 쓸어 내리면 닫힙니다.
- 승인 질문에는 Mac에서처럼 에이전트 자체의 선택지가 제공됩니다.
- 채팅의 에이전트를 바꾸려면 채팅 제목 아래의 에이전트를 탭하세요. **여기에서 분기**를 사용하면 분기할 에이전트를 고를 수 있습니다.
- 모델 시트에는 구독 플랜, 5시간 및 주간 한도와 남은 양과 초기화 시점, 그리고 각 모델 행에 모델 자체의 한도가 표시됩니다.
- 사진 보관함의 사진과 동영상을 첨부하세요. 동영상은 원본 그대로 컴퓨터로 전송됩니다.
- 앱의 **설정 → 아바타**에서 메시지 입력란의 통화 버튼에 아바타를 표시할지 음성 막대 아이콘을 표시할지 고르세요.

컴퓨터가 오프라인이거나 다시 연결 중일 때도 보낼 수 있습니다. 휴대전화가 질문이나 웹 검색처럼 할 수 있는 것은 직접 답하고, 컴퓨터가 필요한 메시지는 연결되면 전송합니다.

휴대전화에서 열 수 없는 문서나 링크는 컴퓨터에서 열라고 안내합니다.

## 컴퓨터의 화면 사용하기

**홈** 오른쪽 위의 디스플레이 아이콘이나 채팅 메뉴의 **원격 화면**을 탭하면 컴퓨터의 화면을 보고 제어할 수 있습니다.

| 모드 | 터치하면 |
| --- | --- |
| **트랙패드** | 아무 곳이나 밀어 포인터를 움직이고, 탭하면 포인터가 있는 곳을 클릭합니다. 사용하는 동안 힌트가 제스처를 알려 줍니다. |
| **터치** | 클릭하려는 곳을 탭합니다. |
| **보기만 하기** | 아무 일도 없습니다. 보기만 합니다. |

모드 버튼에는 현재 모드의 이름이 표시됩니다. 핀치로 확대할 수 있으며, **트랙패드**에서는 화면이 포인터를 중심으로 확대되고 포인터를 따라갑니다.

다른 일을 하는 동안에도 화면을 띄워 두려면 왼쪽 위의 화면 속 화면 버튼을 탭하거나 핀치로 오므리세요. 화면이 채팅 위에, 그리고 Enconvo를 떠나면 다른 앱 위에 떠 있습니다.

Live Talk 통화 중에 **원격 화면** 도구는 통화 위의 작은 플로팅 창에 화면을 엽니다. 트랙패드처럼 동작하며, **터치**나 **보기만 하기**로 바꾸는 모드 칩, 컴퓨터에 입력하는 키보드 버튼, 일반 보기로 여는 **전체 화면**이 있습니다.

## 알림

- 완료된 답장의 알림에는 답장의 앞부분이 표시됩니다. 앱을 열지 않고 답하려면 알림의 **답장**을 사용하세요.
- 앱이 열려 있거나 Mac을 사용 중일 때는 알림이 오지 않습니다. 단, 그 메시지를 휴대전화에서 보낸 경우는 예외입니다.
- 한 기기에서 완료된 채팅을 읽으면 다른 기기의 알림이 사라집니다. 답을 기다리는 질문은 남아 있습니다.
- Android 14 이상에서 Android가 끈 경우 앱 설정에서 **전체 화면 알림**을 켜세요.

## Enconvo로 공유

다른 앱에서 페이지, 사진, 파일을 Enconvo로 공유하면 **보낼 곳** 시트에서 새 채팅이나 최근 채팅을 고를 수 있습니다. 이 질문을 건너뛰려면 시트 또는 앱 설정에서 **항상 새 채팅으로 공유**를 켜세요.

## 프로젝트와 아티팩트

- 프로젝트의 **아이디어**와 **보드**를 열고, 설정을 바꾸고, **새 프로젝트**를 시작하고, 작업 계획 카드에서 응답, 병합, 작업 시작 또는 재시도, 풀 리퀘스트 열기, 아이디어 기록 및 시작을 할 수 있습니다.
- `@` 메뉴에는 프로젝트의 구성원, 워크플로, 참여할 수 있는 에이전트가 나열됩니다.
- 슬라이드, 대시보드, Motion 영상은 채팅이나 아티팩트 라이브러리에서 열리며, 댓글을 달고, @Enconvo에게 묻고, 공유하고, 내보내고, 발표할 수 있습니다.

## Android 앱

Android 앱도 같은 방식으로 페어링되고 동작합니다. Google 또는 이메일로 받은 6자리 코드로 로그인하세요. 메시지 입력란은 한 줄에 있으며 카메라 버튼, 컴퓨터, 프로젝트, **스킬**에 대한 빠른 칩, 최근 사진과 동영상이 있는 플러스 패널이 있습니다.

enconvo.com에서 내려받은 Android 앱은 열 때마다 업데이트를 확인합니다. **Skip This Version**은 더 새로운 버전이 나올 때까지 해당 버전을 숨기고, **나중에**는 다음에 앱을 열 때까지 알림을 숨깁니다.

## 페어링된 휴대전화 관리

**설정 → 연결**에 페어링된 모든 휴대전화와 지금 휴대전화가 이 Mac에 접근할 수 있는지가 표시됩니다.

| 작업 | 방법 |
| --- | --- |
| 다른 휴대전화 페어링 | **다른 휴대전화 페어링**을 선택하고 새 코드를 스캔하세요. Mac 한 대에 최대 10대의 휴대전화를 페어링할 수 있습니다. |
| 휴대전화 이름 바꾸기 | 휴대전화를 클릭한 다음 이름 옆의 **휴대폰 이름 바꾸기**를 클릭하세요. |
| 휴대전화 제거 | **페어링된 휴대전화**에서 옆의 **제거**를 선택하세요. |
| 처음부터 다시 시작 | **연결 재설정**을 선택하세요. Enconvo가 새 연결 키를 만들고 페어링된 모든 휴대전화를 제거합니다. 이후 각 휴대전화가 새 코드를 스캔합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 휴대전화가 Mac에 접근할 수 없음 | Mac이 켜져 있고, 로그인되어 있고, 온라인인지, 그리고 **연결**에 **온라인**으로 표시되는지 확인하세요. **이 Mac의 잠자기 방지**를 켜서 계속 접근할 수 있게 하세요. |
| 휴대전화에서 Mac이 메시지, 화면 또는 터미널을 거부했다고 나옴 | Mac에 이에 대한 기기 접근 권한이 없습니다. 휴대전화에 표시되는 단계를 따르세요. |
| 코드에 **이 코드가 만료되었습니다**라고 나옴 | **새 코드 표시**를 선택하고 5분 안에 다시 스캔하세요. |
| Mac에 **로그인하여 휴대폰 페어링**이 표시됨 | **로그인**을 클릭하고 Mac에서 로그인하세요. iPhone과 Mac은 같은 Enconvo 계정을 사용해야 합니다. |
| Mac에 **새 연결 키가 필요**하다고 나옴 | 예를 들어 백업에서 복원한 경우처럼 릴레이에 이 Mac의 다른 키가 있습니다. **연결 재설정**을 선택한 다음 각 휴대전화를 다시 페어링하세요. |
| **Companion 접근이 꺼졌습니다** | 내 기기 중 하나에서 접근이 꺼졌으며, **접근 다시 켜기**를 선택하기 전까지는 어떤 휴대전화도 Mac에 접근할 수 없습니다. |

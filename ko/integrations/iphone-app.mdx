Enconvo iPhone 앱을 Mac과 페어링하면 Mac의 프로젝트와 채팅을 휴대전화에서도 그대로 볼 수 있습니다. 휴대전화에서 연 모든 채팅은 해당 Mac의 파일, 앱 및 에이전트와 함께 Mac에서 계속 실행됩니다. 이 튜토리얼에서는 로그인, Mac에 페어링 코드 표시, iPhone으로 스캔까지 페어링 전 과정을 안내합니다.

<YouTubePlayer videoId="rYhgz_SjnNs" title="How to Pair Your iPhone with Your Mac in Enconvo | Step-by-Step Tutorial" />

동영상 길이는 1분 12초입니다. 아래 글 단계는 동영상과 같은 순서로 구성되어 있으며 각 단계의 타임스탬프가 함께 적혀 있습니다.

<Note>
iPhone 앱은 현재 베타 버전입니다. [TestFlight](https://testflight.apple.com/join/MJQuEN28)에서 설치하거나 Mac의 **설정 → 연결**의 **휴대폰 앱 받기** 아래에 있는 TestFlight 코드를 스캔하세요. 페어링하려면 Mac에 Enconvo 2.5.6 beta 이상이 필요합니다. TestFlight의 iPhone 앱과 Google Play의 Android 앱은 미주, 유럽, 중동, 일본, 한국 및 동남아시아에서 이용할 수 있습니다. Android APK는 어디서나 설치할 수 있습니다.
</Note>

## iPhone 페어링하기

Windows PC, Linux 데스크톱 또는 터미널만 있는 Linux 서버와 페어링하려면 [휴대전화와 페어링](/ko/integrations/pair-your-phone)을 참고하세요.

<Steps>
  <Step title="iPhone에서 로그인하기 (0:07)">
    iPhone 앱을 설치하고 Apple, Google 또는 이메일로 받은 6자리 코드를 사용해 Mac과 같은 Enconvo 계정으로 로그인합니다. 같은 계정으로 로그인한 휴대전화만 페어링할 수 있습니다. 무료 계정으로도 페어링, Mac의 채팅 및 원격 화면 사용, 아바타 사용이 가능합니다.
  </Step>
  <Step title="페어링 코드 표시하기 (0:16)">
    Mac에서 **설정 → 연결**을 열고 **페어링 코드 표시**를 선택합니다. QR 코드는 5분 동안 유효합니다. 시간이 만료되면 **새 코드 표시**를 선택하세요.
  </Step>
  <Step title="iPhone으로 스캔하기 (0:22)">
    휴대전화에서 **원격**을 열고 **컴퓨터 페어링**(동영상에서는 **Mac 페어링**)을 탭한 뒤 Mac의 코드에 카메라를 비춥니다. iPhone 카메라 앱으로도 스캔할 수 있으며, Enconvo가 열리면 그곳에서 Mac을 확인합니다. 잠시 후 두 기기가 페어링됩니다. 휴대전화는 Enconvo 릴레이를 통해 Mac에 연결되며 메시지는 종단 간 암호화됩니다.
  </Step>
  <Step title="휴대전화에서 Mac 사용하기 (0:34)">
    원격에서 Mac이 **온라인**으로 표시되면 해당 Mac의 프로젝트와 채팅이 휴대전화에 바로 나타납니다.
  </Step>
  <Step title="원하는 채팅 열기 (0:40)">
    채팅을 열어 중단했던 지점부터 이어서 대화하세요. 채팅은 여전히 Mac에서 실행되므로 Mac의 파일, 앱 및 에이전트를 그대로 사용할 수 있습니다.
  </Step>
  <Step title="연결 유지하기 (0:47)">
    **연결**(또는 **설정 → 잠자기 방지**)에서 **이 Mac의 잠자기 방지**를 켭니다. 배터리 사용 중에도 Mac이 잠자기 상태에 들어가지 않아 휴대전화에서 언제든 연결할 수 있습니다. 화면을 계속 켜 두거나 지정한 시간 뒤에 끄거나, 덮개를 닫은 상태에서도 깨어 있도록 설정할 수 있습니다(덮개 닫힘 유지는 관리자 비밀번호를 한 번 요청합니다).
  </Step>
  <Step title="휴대전화 제거하기 (0:52)">
    휴대전화를 분실했나요? **연결 → 페어링된 휴대전화**에서 해당 기기 옆의 **제거**를 선택하세요. 그 휴대전화는 더 이상 Mac에 연결할 수 없습니다. 다시 사용하려면 새 코드로 페어링해야 합니다.
  </Step>
</Steps>

Mac의 코드 아래에 해당 안내가 표시되면, 코드를 스캔할 때 iPhone이 사용자의 Enconvo 계정에 자동으로 로그인되기도 합니다. 이러한 코드는 반드시 본인 소유의 iPhone으로만 스캔하세요.

## 휴대전화에서 할 수 있는 일

페어링되면 다음 작업을 할 수 있습니다.

- Mac의 프로젝트와 채팅을 탐색하고 어떤 채팅이든 이어서 진행할 수 있습니다.
- Mac에서 작업 중인 에이전트가 묻는 질문에 답할 수 있습니다.
- 채팅이 끝나면 알림을 받고 알림에서 바로 답장할 수 있습니다.
- **원격 화면**으로 Mac 화면을 보고 조작할 수 있습니다.
- Enconvo Cloud 포인트, 개인 API 키 또는 로그인한 구독 요금제(ChatGPT, Grok, Le Chat, GitHub Copilot, Antigravity)를 사용해 휴대전화 자체에서 AI 모델과 대화할 수 있습니다. [휴대전화 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.
- 친구 및 팀원과 채팅하거나 통화하고 화상 회의에 참여할 수 있습니다. [휴대전화에서의 통화 및 친구](/ko/integrations/phone-calls-and-friends)를 참고하세요.

앱에서는 페어링된 Mac, Windows PC 또는 Linux 머신을 **컴퓨터**라고 부릅니다. Android 앱도 별도 안내가 없는 한 동일하게 작동합니다.

## 컴퓨터의 채팅에서 작업하기

컴퓨터에서 가져온 채팅은 백그라운드 작업, 서브에이전트, 방향 지시까지 Mac과 똑같이 보이고 작동합니다.

- **홈**의 메시지 입력창 바로 위에 활성 채팅이 표시됩니다. 카드의 손잡이를 위로 스와이프하거나 **전체**를 탭하면 확인 필요, 실행 중, 결과 있음 기준으로 묶인 모든 활성 채팅을 볼 수 있습니다.
- 사이드바의 **활성** 그룹에는 사용자의 응답을 기다리거나, 실패했거나, 아직 실행 중이거나, 읽지 않은 결과가 있는 채팅이 모입니다. 파란 점은 읽지 않은 결과를, 회전하는 링은 실행 중인 채팅을 나타냅니다. **고정됨**과 **최근**은 접을 수 있습니다.
- 답변이 실행되는 동안 메시지를 보내면 Mac에서 Return을 누를 때처럼 실행 중인 작업에 방향을 지시합니다. 그동안 입력창에는 “실행 중인 작업에 방향 지시…”가 표시됩니다.
- 서브에이전트를 탭하면 채팅 위 시트에 단계 목록이 열립니다. 가장 최신 단계에서 시작해 새 출력을 따라가며, 아래로 스와이프해 닫을 수 있습니다.
- 승인 요청에는 Mac과 동일하게 에이전트가 제시한 선택지가 표시됩니다.
- 채팅의 에이전트를 바꾸려면 채팅 제목 아래의 에이전트를 탭하세요. **여기에서 분기**를 사용하면 분기된 채팅의 에이전트를 고를 수 있습니다.
- 모델 시트에는 구독 요금제, 5시간 및 주간 한도의 잔여량과 초기화 시각, 각 모델의 개별 한도가 행별로 표시됩니다.
- 사진 보관함에서 사진과 동영상을 첨부할 수 있습니다. 동영상은 변환 없이 그대로 컴퓨터로 전송됩니다.
- 앱의 **설정 → 아바타**에서 메시지 입력창의 통화 버튼에 아바타를 표시할지 음성 막대 아이콘을 표시할지 선택할 수 있습니다.

컴퓨터가 오프라인이거나 다시 연결 중일 때도 메시지를 보낼 수 있습니다. 휴대전화는 질문이나 웹 조회처럼 직접 처리할 수 있는 요청을 답변하고, 컴퓨터가 필요한 메시지는 연결되는 대로 전송합니다.

휴대전화에서 열 수 없는 문서나 링크는 컴퓨터에서 열도록 안내합니다.

## 컴퓨터 화면 사용하기

**홈** 오른쪽 상단의 디스플레이 아이콘이나 채팅 메뉴의 **원격 화면**을 탭하면 컴퓨터 화면을 보고 제어할 수 있습니다.

| 모드 | 터치 동작 |
| --- | --- |
| **트랙패드** | 아무 곳이나 밀어 포인터를 움직이고, 탭해 포인터 위치에서 클릭합니다. 사용하는 동안 제스처 힌트가 표시됩니다. |
| **터치** | 클릭하려는 위치를 직접 탭합니다. |
| **보기만 하기** | 아무 동작도 하지 않고 화면만 봅니다. |

모드 버튼에 현재 모드 이름이 표시됩니다. 두 손가락으로 핀치해 확대/축소하며, **트랙패드** 모드에서는 포인터 주변을 확대하고 포인터를 따라 화면이 움직입니다.

다른 일을 하면서 화면을 계속 띄워 두려면 왼쪽 상단의 화면 속 화면(PiP) 버튼을 탭하거나 안쪽으로 핀치하세요. 화면이 채팅 위에 떠 있으며 Enconvo 밖의 다른 앱을 사용할 때도 위에 유지됩니다.

실시간 대화 통화 중 **원격 화면** 도구를 사용하면 통화 위에 작은 플로팅 창으로 화면이 열립니다. 트랙패드처럼 작동하며, **터치**나 **보기만 하기**로 바꾸는 모드 칩, 컴퓨터에 입력하는 키보드 버튼, 일반 보기로 여는 **전체 화면** 버튼이 함께 제공됩니다.

## 알림

- 완료된 답변 알림에는 답변 앞부분이 표시됩니다. 앱을 열지 않고 알림의 **답장**으로 바로 응답할 수 있습니다.
- 휴대전화에서 보낸 메시지가 아니라면 앱을 열었거나 Mac을 사용 중일 때는 알림이 오지 않습니다.
- 한 기기에서 완료된 채팅을 읽으면 다른 기기의 알림도 사라집니다. 아직 답변을 기다리는 질문 알림은 유지됩니다.
- Android 14 이상에서 Android가 **전체 화면 알림**을 끈 경우 앱 설정에서 다시 켜세요.

## Enconvo로 공유하기

다른 앱에서 페이지, 사진 또는 파일을 Enconvo로 공유하면 **보낼 위치** 시트에서 새 채팅이나 최근 채팅을 고를 수 있습니다. 이 질문을 건너뛰려면 시트나 앱 설정에서 **항상 새 채팅으로 공유**를 켜세요.

## 프로젝트와 아티팩트

- 프로젝트의 **아이디어**와 **보드**를 열고, 설정을 변경하며, **새 프로젝트**를 시작하고, 작업 계획 카드에서 응답, 병합, 작업 시작·재시도, 풀 리퀘스트 열기 또는 아이디어 작성 및 시작을 실행할 수 있습니다.
- `@` 메뉴에는 프로젝트의 멤버, 워크플로 및 참여할 수 있는 에이전트가 나열됩니다.
- 슬라이드, 대시보드 및 애니메이션 영상은 채팅이나 아티팩트 보관함에서 열 수 있으며, 댓글 작성, `@Enconvo`에게 요청, 공유, 내보내기 및 발표를 할 수 있습니다.

## Android 앱

Android 앱도 같은 방식으로 페어링하고 작동합니다. Google 계정이나 이메일로 받은 6자리 코드로 로그인하세요. 메시지 입력창은 한 줄에 배치되며 카메라 버튼, 컴퓨터·프로젝트·**스킬**용 빠른 칩, 최근 사진과 동영상이 담긴 플러스 패널이 제공됩니다.

enconvo.com에서 다운로드한 Android 앱은 열 때마다 업데이트를 확인합니다. **이 버전 건너뛰기**를 누르면 새 버전이 나올 때까지 숨기며, **나중에**를 누르면 다음에 앱을 열 때까지 알림을 숨깁니다.

## 페어링된 휴대전화 관리하기

**설정 → 연결**에는 페어링된 모든 휴대전화가 나열되며 지금 휴대전화가 이 Mac에 연결할 수 있는지도 표시됩니다.

| 작업 | 방법 |
| --- | --- |
| 다른 휴대전화 페어링 | **다른 휴대전화 페어링**을 선택하고 새 코드를 스캔합니다. Mac 하나에 최대 10대의 휴대전화를 페어링할 수 있습니다. |
| 휴대전화 이름 바꾸기 | 휴대전화를 클릭한 다음 이름 옆의 **휴대전화 이름 바꾸기**를 클릭합니다. |
| 휴대전화 제거 | **페어링된 휴대전화**에서 해당 기기 옆의 **제거**를 선택합니다. |
| 처음부터 다시 설정 | **연결 재설정**을 선택합니다. Enconvo가 새 연결 키를 만들고 페어링된 모든 휴대전화를 제거합니다. 이후 각 휴대전화에서 새 코드를 스캔해야 합니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 휴대전화가 Mac에 연결할 수 없음 | Mac이 깨어 있고 로그인 및 온라인 상태인지, **연결**에 **온라인**으로 표시되는지 확인하세요. 계속 연결할 수 있도록 **이 Mac의 잠자기 방지**를 켜세요. |
| 휴대전화에서 Mac이 메시지, 화면 또는 터미널을 거부했다고 표시됨 | Mac에 해당 기기의 기기 접근 권한이 없습니다. 휴대전화에 표시되는 안내 단계를 따르세요. |
| 코드에 **이 코드가 만료되었습니다** 표시 | **새 코드 표시**를 선택하고 5분 안에 다시 스캔하세요. |
| Mac에 **휴대전화를 페어링하려면 로그인하세요** 표시 | **로그인**을 클릭해 Mac에서 로그인하세요. iPhone과 Mac이 같은 Enconvo 계정을 사용해야 합니다. |
| Mac에 **새 연결 키가 필요합니다** 표시 | 백업에서 복원한 경우처럼 릴레이에 저장된 이 Mac의 키가 다릅니다. **연결 재설정**을 선택한 뒤 각 휴대전화를 다시 페어링하세요. |
| **Companion 접근이 꺼졌습니다** | 다른 기기 중 하나에서 접근을 끈 상태입니다. **접근 다시 켜기**를 선택하기 전까지 어떤 휴대전화도 Mac에 연결할 수 없습니다. |

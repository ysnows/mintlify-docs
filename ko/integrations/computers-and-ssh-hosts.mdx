에이전트는 이 Mac 밖에서도 작업할 수 있습니다. SSH로 로그인할 수 있는 서버를 추가하고 채팅에서 멘션하면 이 Mac에 대해 묻듯이 요청할 수 있습니다. 에이전트가 해당 서버에서 명령을 실행하고 결과를 여기에서 알려 줍니다. 서버에는 아무것도 설치하지 않습니다. Enconvo가 실행 중인 다른 컴퓨터도 같은 방식으로 페어링할 수 있습니다.

아래 동영상에서는 SSH config에서 SSH 호스트를 추가하고, 에이전트에게 해당 호스트의 로그를 읽도록 요청하며, 이 Mac에 접근할 수 있는 기기를 확인하는 과정을 보여 줍니다.

## 시작하기 전에

- 이 Mac에서 `ssh`로 로그인할 수 있는 서버가 필요합니다(`~/.ssh/config`에 등록된 호스트 또는 `user@host` 형태로 입력할 수 있는 주소). Enconvo는 이 Mac의 자체 `ssh`와 키를 사용합니다. 서버가 비밀번호나 암호 문구를 요구하면 `ssh`가 Enconvo를 통해 묻고, Enconvo는 이를 저장하지 않습니다.
- 로컬 네트워크에 있는 서버의 경우 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 허용하세요.

## 연결 목록 구성

**설정 → 연결**을 열면 세 개의 목록이 나타납니다.

| 목록 | 포함 항목 |
| --- | --- |
| **휴대전화** | 이 Mac과 페어링된 iPhone 및 Android 앱입니다. [iPhone 앱](/ko/integrations/iphone-app)을 참고하세요. |
| **컴퓨터** | 이 Mac과 페어링된, Enconvo가 실행 중인 다른 컴퓨터입니다. 각 컴퓨터는 제어 방식과 함께 한 번씩 표시됩니다. 추가하려면 **컴퓨터 페어링**을 클릭하세요. [다른 컴퓨터](/ko/integrations/other-computers)를 참고하세요. |
| **SSH 호스트** | 서버 측 설치 없이 에이전트가 SSH로 연결하는 서버입니다. |

휴대전화나 컴퓨터를 클릭하면 이 Mac에서 수행할 수 있는 작업이 표시된 전용 페이지가 열립니다.

채팅 창에서 호스트를 추가하거나 컴퓨터·휴대전화를 페어링할 수도 있습니다. 사이드바 하단의 기기 전환기를 클릭한 다음 **기기 추가**를 선택하세요.

## SSH 호스트 추가하기

1. **설정 → 연결**을 열고 **SSH 호스트** 아래에서 **호스트 추가**를 클릭합니다.
2. 목록에 `~/.ssh/config`의 호스트가 표시됩니다. `build-server`처럼 하나를 선택하거나 `user@host`(또는 `user@host:port`)를 직접 입력합니다.
3. **연결**을 클릭합니다. Enconvo가 호스트에 접속하고 호스트 키를 확인하며 로그인한 뒤 명령을 실행해 연결을 테스트합니다.
4. **각 명령 전**에서 에이전트가 해당 호스트에서 명령을 실행하기 전에 어떻게 물어볼지 선택합니다.
   - **채팅 따르기**: 채팅의 권한 모드 설정에 따라 묻습니다. [작업 승인](/ko/ai/agents)을 참고하세요.
   - **항상 묻기**: 모든 명령을 실행하기 전에 묻습니다.
5. **호스트 추가**를 클릭합니다.

이제 호스트가 **SSH 호스트** 아래와 모든 채팅의 `@` 메뉴에 나타납니다.

Enconvo가 서버의 호스트 키를 처음 확인하는 경우 서버 관리자에게 키가 맞는지 확인한 뒤 **신뢰하고 연결**을 클릭하세요. Linux 서버에서는 대화 상자에 **그곳에 Enconvo도 설치** 옵션도 함께 표시되며, 이를 선택하면 서버를 컴퓨터로 페어링합니다. 아무것도 설치하지 않으려면 꺼 두세요.

## 에이전트에게 호스트에서 작업 요청하기

1. 채팅에서 `@`를 입력하고 호스트 이름 앞부분을 적습니다. 컴퓨터와 SSH 호스트는 **컴퓨터** 아래에 나열됩니다.
2. 호스트를 선택합니다. 메시지 입력창에 칩으로 추가됩니다.
3. 해당 호스트에서 처리할 작업을 요청하고 전송합니다. 예:

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

에이전트는 해당 호스트에 설정한 방식에 따라 먼저 확인을 구한 뒤 SSH를 통해 호스트에서 명령을 실행합니다. 각 명령 단계에는 실행된 호스트 이름이 표시되며, 답변은 채팅에 표시됩니다.

실행 내용을 보려면 답변 위의 **작업 시간**을 클릭하세요. 펼쳐진 영역에 각 명령이 나열됩니다.

페어링된 컴퓨터도 같은 방식으로 멘션할 수 있습니다. 에이전트는 해당 컴퓨터 자체의 에이전트에게 작업을 넘기거나, 그 컴퓨터가 이 Mac에 터미널 사용을 허용한 경우 직접 명령을 실행합니다.

채팅에서 호스트나 다른 컴퓨터에서 실행된 명령은 **명령 실행함**으로 표시되며, 각 단계에 해당 기기 이름이 함께 나옵니다.

## 페어링된 컴퓨터에서 에이전트 작업 허용하기

**설정 → 연결**의 **컴퓨터** 아래에서 컴퓨터를 클릭해 해당 페이지를 엽니다. 두 개의 스위치가 이 Mac의 채팅에서 에이전트가 그 컴퓨터에 무엇을 할 수 있는지 결정합니다.

| 스위치 | 역할 |
| --- | --- |
| **에이전트** | 해당 컴퓨터의 에이전트를 프로젝트에 추가하거나 채팅을 넘깁니다. 작업은 그 컴퓨터에서 실행되며, 에이전트가 수행하려는 작업은 먼저 그곳에서 승인을 요청합니다. |
| **명령** | 이 Mac의 채팅에서 에이전트가 채팅의 권한 모드에 따라 확인을 거친 뒤 해당 컴퓨터에서 명령을 실행할 수 있습니다. |

스위치가 비활성화되어 있다면 다른 컴퓨터가 이를 허용하지 않은 것입니다. 해당 컴퓨터에서 이 Mac에 대한 **에이전트** 또는 **터미널**을 켜세요. **명령**을 끄면 같은 컴퓨터를 가리키는 SSH 호스트를 통한 명령 실행도 중지됩니다.

다른 컴퓨터의 에이전트가 이 Mac의 화면과 브라우저를 직접 사용하도록 허용하려면 이 Mac의 해당 컴퓨터 페이지에서 **에이전트 제어**를 켜세요. [다른 컴퓨터](/ko/integrations/other-computers)를 참고하세요.

## 호스트 설정 변경하기

**SSH 호스트** 아래에서 호스트를 클릭해 페이지를 엽니다.

| 설정 | 역할 |
| --- | --- |
| **에이전트 사용 가능** | 끄면 호스트는 목록에 남지만 모든 채팅에서 제외됩니다. |
| **각 명령 전** | **채팅 따르기** 또는 **항상 묻기** 중 선택합니다. |
| **파일 복사** | 에이전트가 `scp`로 호스트와 파일을 주고받을 수 있게 합니다. |
| **시작 위치** | 명령이 시작되는 폴더입니다. 비워 두면 로그인 폴더에서 시작합니다. |

페이지의 **⋯** 메뉴에는 **연결 테스트**와 **호스트 제거…**가 있습니다. 호스트를 제거해도 Enconvo 목록에서만 지워질 뿐 `~/.ssh/config`와 서버는 그대로 유지됩니다.

## 이 Mac에 접근할 수 있는 기기 확인하기

**설정 → 연결**의 **이 Mac에 접근할 수 있는 기기**에는 이 Mac에 연결할 수 있는 휴대전화와 컴퓨터의 수가 표시됩니다.

모두 한꺼번에 차단하려면 **모든 접근 중지**를 클릭하고 확인하세요. 휴대전화와 다른 컴퓨터는 더 이상 사용자의 모든 Mac에 접근할 수 없으며, 해당 기기에서 실행 중이던 작업도 중지됩니다. 다시 허용하려면 **접근 다시 켜기**를 클릭하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 테스트에서 로컬 네트워크의 서버에 연결할 수 없음 | macOS가 로컬 네트워크 권한 때문에 연결을 보류하고 있습니다. **Enconvo에 로컬 네트워크 허용**을 클릭하거나 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 켠 다음 다시 시도하세요. |
| 테스트에서 서버가 키를 거부함 | `~/.ssh/config`에서 해당 호스트의 `IdentityFile`을 확인하거나 `ssh-add`로 키를 추가하세요. |
| 서버가 다른 호스트 키로 응답함 | 서버가 재구축되었거나 중간에 다른 장치가 있을 수 있습니다. 서버가 재구축된 것이 맞다면 터미널에서 `ssh-keygen -R` 뒤에 서버 주소를 입력해 이전 키를 삭제한 다음 다시 시도하세요. |
| 호스트가 `@` 메뉴에 보이지 않음 | 호스트 페이지를 열고 **에이전트 사용 가능**을 켜세요. |
| 잘못된 비밀번호 또는 암호 문구 | 입력 상자가 다시 열리며 실패했다고 안내합니다. 다시 입력하세요. |
| 한 컴퓨터에 SSH 호스트가 두 개 있음 | 첫 번째 호스트가 해당 컴퓨터에 연결된 상태로 유지되며 페이지에도 그 호스트가 표시됩니다. 이를 제거하면 다른 호스트가 연결됩니다. |
| `~/.ssh/config`에 호스트가 없음 | **호스트 추가**에서 주소를 `user@host` 형식으로 직접 입력하세요. |

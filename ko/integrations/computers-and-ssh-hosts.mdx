에이전트는 이 Mac 말고도 작업할 수 있습니다. SSH로 로그인하는 서버를 추가하고, 채팅에서 멘션한 다음 내 Mac에 물어보듯 요청하세요. 에이전트가 그곳에서 명령을 실행하고 답은 여기로 돌아옵니다. 서버에는 아무것도 설치되지 않습니다. Enconvo가 실행 중인 다른 컴퓨터도 같은 방식으로 페어링할 수 있습니다.

아래 동영상은 SSH 설정에서 SSH 호스트를 추가하고, 에이전트에게 그곳의 로그를 읽어 달라고 요청하고, 이 Mac에 접근할 수 있는 대상을 확인하는 과정을 보여 줍니다.

<YouTubePlayer videoId="ojtTTtqTod4" title="Computers and SSH Hosts in Enconvo" />

## 시작하기 전에

- 이 Mac에서 `ssh`로 로그인할 수 있는 서버가 필요합니다. `~/.ssh/config`에 있는 호스트이거나 `user@host` 형태로 입력할 수 있는 주소여야 합니다. Enconvo는 이 Mac의 `ssh`와 키를 그대로 사용합니다. 서버가 암호나 암호문을 요구하면 `ssh`가 Enconvo를 통해 묻고, Enconvo는 아무것도 저장하지 않습니다.
- 로컬 네트워크의 서버라면 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 허용하세요.

## 연결 목록

**설정 → 연결**을 여세요. 세 가지 목록이 있습니다.

| 목록 | 담기는 내용 |
| --- | --- |
| **휴대전화** | 이 Mac과 페어링된 iPhone 및 Android 앱입니다. [iPhone 앱](/ko/integrations/iphone-app)을 참고하세요. |
| **컴퓨터** | 이 Mac과 페어링된 Enconvo 실행 중인 다른 컴퓨터입니다. 각 컴퓨터는 한 번만 표시되며 어느 쪽이 제어하는지도 나타납니다. **컴퓨터 페어링**을 클릭해 추가하세요. [내 다른 컴퓨터](/ko/integrations/other-computers)를 참고하세요. |
| **SSH 호스트** | 에이전트가 SSH로 접속하는 서버이며, 그곳에는 아무것도 설치되지 않습니다. |

휴대전화나 컴퓨터를 클릭하면 이 Mac에서 할 수 있는 일이 담긴 해당 기기의 페이지가 열립니다.

채팅 창에서도 호스트를 추가하거나, 컴퓨터 또는 휴대전화를 페어링할 수 있습니다. 사이드바 아래쪽의 기기 전환기를 클릭한 다음 **기기 추가**를 클릭하세요.

## SSH 호스트 추가

1. **설정 → 연결**을 열고 **SSH 호스트**에서 **호스트 추가**를 클릭하세요.
2. 목록에 `~/.ssh/config`의 호스트가 표시됩니다. `build-server` 같은 호스트를 고르거나 `user@host`(또는 `user@host:port`)를 입력하세요.
3. **연결**을 클릭하세요. Enconvo가 연결을 테스트합니다. 호스트에 접속하고, 호스트 키를 확인하고, 로그인하고, 명령을 실행합니다.
4. **각 명령 전**에서 에이전트가 그곳에서 명령을 실행하기 전에 어떻게 물을지 고르세요.
   - **채팅 따르기**: 채팅의 권한 모드에 따라 묻습니다. [동작 승인](/ko/ai/agents)을 참고하세요.
   - **항상 묻기**: 모든 명령 전에 묻습니다.
5. **호스트 추가**를 클릭하세요.

이제 호스트가 **SSH 호스트** 아래와 모든 채팅의 `@` 메뉴에 표시됩니다.

Enconvo가 서버의 호스트 키를 처음 볼 때는 서버를 운영하는 사람에게 키를 확인한 다음 **신뢰하고 연결**을 클릭하세요. Linux 서버의 경우 대화상자에 **그곳에 Enconvo도 설치** 옵션도 나타나며, 이를 선택하면 서버가 컴퓨터로 페어링됩니다. 아무것도 설치하지 않으려면 끈 채로 두세요.

## 에이전트에게 호스트에서 작업시키기

1. 채팅에서 `@`와 호스트 이름의 첫 글자들을 입력하세요. 컴퓨터와 SSH 호스트가 **컴퓨터** 아래에 표시됩니다.
2. 호스트를 고르세요. 메시지에 칩으로 들어갑니다.
3. 그곳에서 할 일을 요청하고 보내세요. 예를 들면 다음과 같습니다.

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

에이전트는 SSH로 호스트에서 명령을 실행하며, 그 호스트에 대해 선택한 방식대로 먼저 묻습니다. 각 명령 단계에는 실행된 호스트의 이름이 표시됩니다. 답은 채팅으로 돌아옵니다.

실행된 내용을 보려면 답변 위의 **작업 시간**을 클릭하세요. 펼쳐진 목록에 각 명령이 나옵니다.

페어링된 컴퓨터도 같은 방식으로 멘션할 수 있습니다. 에이전트는 그 컴퓨터 자체의 에이전트에게 작업을 넘기거나, 그 컴퓨터가 이 Mac에 터미널을 허용한 경우 그곳에서 명령을 실행합니다.

채팅에서 호스트나 다른 컴퓨터에서 실행한 명령은 **명령 실행함**으로 표시되며, 각 단계에 해당 기기 이름이 나옵니다.

## 페어링된 컴퓨터에서 에이전트 작업시키기

**설정 → 연결**에서 **컴퓨터** 아래의 컴퓨터를 클릭해 해당 페이지를 여세요. 두 스위치가 여기 채팅의 에이전트가 그 컴퓨터로 할 수 있는 일을 정합니다.

| 스위치 | 기능 |
| --- | --- |
| **에이전트** | 그 컴퓨터의 에이전트를 프로젝트에 추가하거나 채팅을 넘깁니다. 작업은 그 컴퓨터에서 실행되며, 그 컴퓨터의 에이전트가 하려는 모든 동작은 먼저 그곳에서 사용자에게 묻습니다. |
| **명령어** | 여기 채팅의 에이전트가 그 컴퓨터에서 명령을 실행할 수 있으며, 채팅의 권한 모드에 따라 묻습니다. |

스위치가 흐리게 보이면 다른 컴퓨터가 이를 허용하지 않은 것입니다. 그 컴퓨터에서 이 Mac에 대해 **에이전트** 또는 **터미널**을 켜세요. **명령어**를 끄면 같은 컴퓨터에 대한 SSH 호스트를 통한 명령도 중단됩니다.

다른 컴퓨터의 에이전트가 이 Mac의 화면과 브라우저를 직접 사용하게 하려면, 여기 그 컴퓨터 페이지에서 **에이전트 제어**를 켜세요. [내 다른 컴퓨터](/ko/integrations/other-computers)를 참고하세요.

## 호스트 설정 변경

**SSH 호스트**에서 호스트를 클릭해 해당 페이지를 여세요.

| 설정 | 기능 |
| --- | --- |
| **에이전트 사용 가능** | 끄면 호스트는 목록에 남지만 모든 채팅에서 제외됩니다. |
| **각 명령 전** | **채팅 따르기** 또는 **항상 묻기**. |
| **파일 복사** | 에이전트가 `scp`로 호스트와 파일을 주고받을 수 있게 합니다. |
| **시작 위치** | 명령이 시작되는 폴더입니다. 비워 두면 로그인 폴더입니다. |

페이지의 **⋯** 메뉴에는 **연결 테스트**와 **호스트 제거…**가 있습니다. 호스트를 제거하면 Enconvo에서만 잊힙니다. `~/.ssh/config`와 서버는 그대로 남습니다.

## 이 Mac에 접근할 수 있는 대상 확인

**설정 → 연결**의 **이 Mac에 접근할 수 있는 기기**는 이 Mac에 접근할 수 있는 휴대전화와 컴퓨터의 수를 보여 줍니다.

모두 한꺼번에 차단하려면 **모든 접근 중지**를 클릭하고 확인하세요. 휴대전화와 다른 컴퓨터가 더 이상 어떤 Mac에도 접근할 수 없게 되며, 그곳에서 실행 중이던 작업도 중지됩니다. 다시 허용하려면 **접근 다시 켜기**를 클릭하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 테스트에서 로컬 네트워크의 서버에 접속할 수 없음 | macOS가 로컬 네트워크 권한 때문에 연결을 막고 있습니다. **Enconvo의 로컬 네트워크 접근 허용**을 클릭하거나 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 켠 다음 다시 시도하세요. |
| 테스트에서 서버가 키를 거부했다고 나옴 | `~/.ssh/config`에서 해당 호스트의 `IdentityFile`을 확인하거나 `ssh-add`로 키를 추가하세요. |
| 서버가 다른 호스트 키로 응답함 | 서버가 다시 구축되었거나 중간에 무언가 끼어 있을 수 있습니다. 다시 구축된 경우 터미널에서 `ssh-keygen -R` 다음에 서버 주소를 붙여 실행해 이전 키를 제거한 뒤 다시 시도하세요. |
| 호스트가 `@` 메뉴에 없음 | 호스트 페이지를 열고 **에이전트 사용 가능**을 켜세요. |
| 암호나 암호문이 틀림 | 입력창이 다시 열리고 맞지 않았다고 알려 줍니다. 다시 입력하세요. |
| 컴퓨터 하나에 SSH 호스트가 두 개 있음 | 첫 번째 호스트가 컴퓨터에 연결된 채로 남으며, 컴퓨터 페이지에는 그 호스트가 표시됩니다. 그 호스트를 제거하면 다른 호스트가 연결됩니다. |
| `~/.ssh/config`에 호스트가 없음 | **호스트 추가**에 주소를 `user@host`로 입력하세요. |

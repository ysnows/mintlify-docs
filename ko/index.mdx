## AI 선택하기

설정이 필요 없는 [Enconvo Cloud](/ko/providers/enconvo)로 시작하거나, ChatGPT나 Claude처럼 이미 결제 중인 플랜으로 로그인하거나, 직접 API 키를 추가하거나, Mac에서 모델을 실행할 수 있습니다. [제공업체](/ko/providers/overview)에서 각 방법을 비교해 보세요.

## 어디서나 사용하기

[iPhone 앱](/ko/integrations/iphone-app)은 Mac의 에이전트와 대화하고, [전화 채팅](/ko/integrations/iphone-phone-chats)은 iPhone에서 직접 실행됩니다.

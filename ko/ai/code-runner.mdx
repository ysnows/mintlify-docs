Code Runner는 에이전트에게 Mac의 실제 터미널을 줍니다. 빌드, 테스트, 스크립트, 패키지 도구, 개발 서버에 쓰세요. 실행 가능 범위는 설치된 프로그램과 계정 권한이 결정합니다.

<Warning>
명령은 실제로 실행되며, 에이전트의 **Sandbox**를 켜지 않으면 파일과 네트워크에 계정 권한으로 접근합니다. 소프트웨어를 설치하거나 파일을 바꾸거나 온라인 서비스에 영향을 주는 명령은 실행 전에 확인하세요.
</Warning>

## 시작하기 전에

- 사용 중인 에이전트에서 Code Runner를 켜세요.
- 채팅의 **권한** 칩이 에이전트가 먼저 물어보는 시점을 결정합니다. **승인 후 실행**은 명령을 실행하기 전에 물어보고, **나를 위해 승인**은 안전하지 않아 보이는 동작에만 물어봅니다. [동작 승인](/ko/ai/agents)을 보세요.
- 에이전트 명령을 작업 폴더 안으로 가두고 키와 다른 앱에서 떨어뜨려면 같은 칩에서 **Sandbox**를 켜세요. [에이전트 Sandbox](/ko/configuration/sandbox)를 보세요.

## 명령 실행

에이전트에게 폴더와 구체적인 작업을 주세요.

> 내 샘플 프로젝트에서 있는 테스트 명령을 실행하고 결과를 보고해 줘. 파일은 바꾸지 마세요.

에이전트는 명령 출력을 보여 주고, 끝났는지 아직 실행 중인지 알려 줍니다. 파일을 읽고 고치고 검색할 때는 [파일 도구](/ko/ai/file-tools)를 쓰세요.

## 명령이 실행되는 방식

모든 명령은 의사 터미널에서 실행되므로, 입력을 묻는 명령도 새 프로세스를 띄우지 않고 답할 수 있습니다.

| 모드 | 쓸 때 |
| --- | --- |
| **oneshot** | 테스트, 빌드, 스크립트처럼 스스로 끝나는 명령 |
| **long_running** | 서버, 감시 프로세스, 외부 이벤트를 기다리는 프로세스 |
| **interactive** | REPL, 터미널 앱, 대화형 명령줄 세션 |

결과에 `status: running`과 `session_id`가 있으면 프로세스가 계속 실행 중입니다. 에이전트는 출력을 **읽고**, 입력을 **쓰고**, 프로세스를 **중지**할 수 있습니다. 프롬프트에 답하려면 그 세션에 쓰세요. 다른 명령을 시작해도 그 프롬프트에는 답하지 않습니다.

## 끝날 때까지 기다리기

빌드가 출력을 쓰거나 서버가 시작되기를 기다려야 할 때, 에이전트는 쉘 루프 대신 **Wait For** 도구를 씁니다. 명령을 실행하지 않고 다음 중 하나를 기다립니다.

- 파일이 나타나기
- 로그 파일의 한 줄
- 프로세스나 명령 세션이 끝나기
- 포트가 열리거나 주소가 응답하기

대기는 채팅의 백그라운드 작업에 보입니다. 조건이 만족되거나 실패하거나 시간이 다 되면 에이전트에게 알려지며, 그 사이에 다른 일을 할 수 있습니다.

## 작업 폴더와 시간 제한

에이전트가 `workDir`를 지정하면 그 폴더에서, 그렇지 않으면 채팅의 작업 폴더에서 명령이 실행됩니다. 사용자의 쉘을 쓰며 프로젝트와 Python 가상 환경이 잡혀 있습니다. 같은 세션에서 실행하지 않는 한, 따로 나온 명령은 임시 쉘 변수를 공유하지 않습니다.

첫 번째 대기는 명령의 강제 시간 제한과 별개입니다. oneshot 명령은 결과를 최대 30초 기다립니다. 그때까지 실행 중이면 에이전트는 지금까지의 출력을 받고 작업은 계속됩니다. 기본적으로 30분 뒤에 명령이 중지됩니다. 서버나 감시 프로세스는 실패한 oneshot으로 보지 말고 long_running 모드를 쓰세요.

## 설정

**설정 → 플러그인 → Code Runner**를 엽니다.

| 설정 | 바뀌는 것 |
| --- | --- |
| **Enable RTK** | 에이전트가 읽기 전에 긴 명령 출력을 압축해 토큰을 줄입니다. 기본은 켜짐 |

압축된 출력에 필요한 내용이 없으면, 더 좁은 명령이나 로그의 해당 부분을 요청하세요. 잘린 출력이 명령 성공을 증명하지는 않습니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| Command not found | 프로그램이 설치되어 있고 쉘에서 사용할 수 있는지 확인하세요 |
| 명령이 입력을 기다림 | 같은 세션에서 프롬프트에 답하도록 하세요. 누구도 줄 수 없는 입력을 기다리는 명령은 곧바로 끝납니다 |
| Permission denied | 대상 경로와 macOS 권한을 확인하세요. Sandbox가 켜져 있으면 단계 아래 줄을 클릭해 무엇을 막았는지 보세요 |
| 명령이 시간 초과됨 | 마지막 출력을 읽고, 다시 실행하기 전에 맞는 모드를 고르세요 |
| 서버가 계속 실행됨 | 더 이상 필요 없으면 에이전트가 세션을 중지하게 하세요 |

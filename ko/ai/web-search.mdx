웹 검색은 에이전트에게 웹의 최신 결과를 제공합니다. 모든 에이전트가 검색할 수 있으며, 답변을 작성하는 모델과는 별도로 사용할 검색 서비스를 선택합니다.

## 검색 제공업체 선택

1. **설정 → 웹 검색**을 엽니다.
2. 제공업체를 선택합니다. Enconvo Cloud 옵션은 API 키가 필요 없으며, 대부분의 다른 옵션은 해당 서비스의 키를 추가해야 합니다.
3. **기본값으로 설정**을 클릭합니다.

| 제공업체 | 참고 |
| --- | --- |
| **자동** | 채팅 모델 자체의 웹 검색으로 검색하며, 모델에 웹 검색이 없으면 다른 제공업체로 대체합니다. [모델 자체 검색으로 검색하기](#모델-자체-검색으로-검색하기)를 참고하세요. |
| **Enconvo Cloud** | 로그인한 모든 계정에 무료이며 API 키가 필요 없음 |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud를 통한 DeepSeek Search로, 로그인한 모든 계정에 무료 |
| **Gemini** | Gemini 모델을 통한 Google Search 그라운딩 |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | 해당 서비스의 자체 키로 검색 |
| **Parallel** | 각 페이지에서 가장 관련성 높은 구절을 반환하는 Parallel의 AI 검색 색인이며, Parallel API 키 사용 |
| **PipeLLM** | [PipeLLM](/ko/providers/pipellm) 키를 통한 Google 결과 |
| **DeepSeek** | DeepSeek API 키를 사용한 DeepSeek Search |
| **xAI X Search** | xAI API 키 또는 xAI 로그인으로 X의 게시물, 프로필, 스레드를 검색 |
| **xAI X Search (Enconvo Cloud)** | Enconvo Cloud 플랜을 통한 X 검색 |

제공업체 목록에는 무료 옵션이 표시됩니다. 전체 목록은 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요. 일부 모델은 해당 제공업체 설정에 자체 그라운딩 또는 검색 옵션도 있습니다.

## 모델 자체 검색으로 검색하기

**자동**을 선택하면 채팅에 사용하는 모델에 웹 검색이 있는 경우 각 검색이 그 모델의 웹 검색으로 실행됩니다. 해당하는 모델은 OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai, OpenRouter입니다. 이 모델에 연결한 키 또는 로그인을 사용하며, 해당 모델의 공급업체가 비용을 청구합니다.

모델에 자체 검색이 없거나 검색이 실패하면 자동은 **대체 검색**을 사용하며, 다른 제공업체를 고르지 않으면 **Enconvo Cloud**입니다.

| 설정 | 기능 |
| --- | --- |
| **검색 경로** | 채팅 모델에 어떤 검색이 실행되는지, 실패하면 어떻게 되는지 보여 줍니다. |
| **모델 자체 검색 우선** | 기본으로 켜져 있습니다. 끄면 항상 대체 검색을 사용합니다. |
| **대체 검색** | 모델에 검색이 없거나 검색이 실패할 때 사용하는 제공업체입니다. |

채팅에서는 각 웹 검색 단계에 어떤 검색이 답했는지, 그리고 자동이 대체했다면 그 이유가 표시됩니다.

## Parallel 사용하기

1. [Parallel](https://platform.parallel.ai)에서 API 키를 받습니다.
2. **설정 → 인증 정보 관리 → Parallel**에 키를 추가합니다.
3. **설정 → 웹 검색**에서 **Parallel**을 선택하고 **검색 모드**를 고릅니다.

| 검색 모드 | 용도 |
| --- | --- |
| **Turbo** | 가장 빠른 답변. 영어와 일본어 쿼리만 읽습니다. |
| **빠름** | 대부분의 검색. 기본값입니다. |
| **Basic** | 각 페이지에서 더 긴 구절을 가져옵니다. |
| **고급** | 가장 깊은 검색. 약 3초가 걸리고 비용이 더 많이 듭니다. |

Parallel은 각 검색을 사용자의 Parallel 계정에 청구합니다.

## 에이전트로 검색하기

1. 구체적인 질문을 합니다. 필요하면 기간이나 장소를 포함하세요.
2. 에이전트가 검색하고 출처 링크와 함께 답합니다.
3. 인용된 출처를 열어 답변을 뒷받침하는지 확인합니다.

## 알맞은 웹 기능 선택

| 필요한 것 | 사용할 기능 |
| --- | --- |
| 관련 출처 찾기 | 웹 검색 |
| 알고 있는 URL 읽기 | [웹페이지 가져오기](/ko/ai/web-fetch) |
| 브라우저에서 결과 열기 | [빠른 링크](/ko/features/quick-links) |
| 로그인한 웹사이트와 상호작용 | [브라우저 사용](/ko/features/browser-control) |
| X의 게시물, 프로필, 스레드 검색 | **xAI X Search** 제공업체 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변에 출처가 없음 | 에이전트가 모델만으로 답하지 않고 검색했는지 확인하세요. 웹을 검색하라고 요청하세요. |
| 제공업체에서 오류가 보고됨 | 제공업체의 인증 정보와 해당 서비스에서 사용자 계정의 허용량을 확인하세요. |
| 자동이 대체 검색을 사용함 | 채팅 모델에 자체 웹 검색이 없거나 검색이 실패했습니다. 채팅의 검색 단계에 이유가 표시됩니다. |
| 결과가 로그인 뒤에 있거나 대화형 페이지에 있음 | [브라우저 사용](/ko/features/browser-control) 같은 지원되는 브라우저 흐름을 사용하세요. 공개 URL을 가져오는 것으로는 로그인한 세션에 접근할 수 없습니다. |

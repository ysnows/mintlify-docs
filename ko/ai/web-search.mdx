웹 검색을 사용하면 에이전트가 웹에서 최신 검색 결과를 가져올 수 있습니다. 모든 에이전트가 검색할 수 있으며, 답변을 쓰는 모델과는 별개로 검색에 사용할 서비스를 직접 고를 수 있습니다.

## 검색 제공업체 고르기

1. **설정 → 웹 검색**을 엽니다.
2. 제공업체를 선택합니다. Enconvo Cloud 옵션은 API 키가 필요 없으며, 대부분의 다른 제공업체는 해당 서비스의 키를 추가해야 합니다.
3. **기본값으로 설정**을 클릭합니다.

| 제공업체 | 참고 |
| --- | --- |
| **자동** | 채팅 모델 자체의 웹 검색을 먼저 사용하고, 모델에 검색 기능이 없으면 다른 제공업체로 대체합니다. [모델 자체 검색으로 검색하기](#모델-자체-검색으로-검색하기)를 참고하세요. |
| **Enconvo Cloud** | 로그인한 모든 계정에 무료 제공, API 키 불필요 |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud를 통한 DeepSeek 검색, 로그인한 모든 계정에 무료 제공 |
| **Gemini** | Gemini 모델을 통한 Google 검색 그라운딩 |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | 해당 서비스의 본인 키로 검색 |
| **Parallel** | Parallel API 키를 사용해 각 페이지에서 가장 관련성 높은 단락을 반환하는 Parallel AI 검색 인덱스 |
| **PipeLLM** | [PipeLLM](/ko/providers/pipellm) 키를 통한 Google 검색 결과 |
| **DeepSeek** | 본인 DeepSeek API 키를 사용한 DeepSeek 검색 |
| **xAI X Search** | xAI API 키 또는 xAI 로그인으로 X 게시물, 프로필, 스레드 검색 |
| **xAI X Search (Enconvo Cloud)** | Enconvo Cloud 요금제를 통한 X 검색 |

제공업체 목록에는 무료 옵션이 표시됩니다. 전체 목록은 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요. 일부 모델은 자체 제공업체 설정 안에 내장 그라운딩이나 검색 옵션도 가지고 있습니다.

## 모델 자체 검색으로 검색하기

**자동**을 선택하면 OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai, OpenRouter처럼 자체 웹 검색이 있는 모델에서는 해당 모델의 웹 검색으로 검색이 실행됩니다. 이때 해당 모델에 연결한 키나 로그인을 사용하며, 과금도 모델 제공업체에서 이루어집니다.

모델에 자체 검색 기능이 없거나 검색에 실패하면 자동 모드는 **대체 검색**을 사용합니다. 다른 제공업체를 고르지 않았다면 기본 대체 검색은 **Enconvo Cloud**입니다.

| 설정 | 기능 |
| --- | --- |
| **검색 경로** | 채팅 모델에 어떤 검색이 실행되는지, 실패 시 어떻게 처리되는지 보여 줍니다. |
| **모델 자체 검색 우선** | 기본으로 켜져 있습니다. 끄면 항상 대체 검색을 사용합니다. |
| **대체 검색** | 모델에 검색 기능이 없거나 실패했을 때 사용할 제공업체입니다. |

채팅에서는 각 웹 검색 단계마다 어떤 검색이 답을 찾았는지, 자동 모드가 대체 검색을 썼다면 왜 전환했는지를 표시해 줍니다.

## Parallel 사용하기

1. [Parallel](https://platform.parallel.ai)에서 API 키를 발급받습니다.
2. **설정 → 인증 정보 관리 → Parallel**에 키를 추가합니다.
3. **설정 → 웹 검색**에서 **Parallel**을 선택하고 **검색 모드**를 고릅니다.

| 검색 모드 | 추천 용도 |
| --- | --- |
| **Turbo** | 가장 빠른 응답. 영어와 일본어 검색어만 지원합니다. |
| **Fast** | 대부분의 검색. 기본값입니다. |
| **Basic** | 각 페이지에서 더 긴 본문 단락을 가져옵니다. |
| **Advanced** | 가장 깊이 있는 검색. 약 3초가 걸리며 비용이 더 높습니다. |

Parallel은 각 검색 비용을 본인 Parallel 계정에 청구합니다.

## 에이전트로 검색하기

1. 구체적인 질문을 던지세요. 중요하다면 날짜 범위나 장소를 함께 적으세요.
2. 에이전트가 검색을 수행한 뒤 출처 링크와 함께 답변합니다.
3. 인용된 출처를 열어 답변 내용을 뒷받침하는지 확인하세요.

## 상황에 맞는 웹 기능 고르기

| 필요한 작업 | 사용할 기능 |
| --- | --- |
| 관련 출처 찾기 | 웹 검색 |
| 이미 알고 있는 URL 읽기 | [웹 페이지 가져오기](/ko/ai/web-fetch) |
| 브라우저에서 결과 열기 | [빠른 링크](/ko/features/quick-links) |
| 로그인된 웹사이트와 상호작용하기 | [브라우저 사용](/ko/features/browser-control) |
| X 게시물, 프로필, 스레드 검색 | **xAI X Search** 제공업체 |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변에 출처가 없음 | 에이전트가 검색하지 않고 모델 지식만으로 답했는지 확인하고, 웹에서 검색해 달라고 요청하세요. |
| 제공업체가 오류를 반환함 | 제공업체의 인증 정보와 해당 서비스 계정의 잔여 한도를 확인하세요. |
| 자동 모드가 대체 검색을 사용함 | 채팅 모델에 자체 웹 검색이 없거나 검색이 실패한 경우입니다. 채팅의 검색 단계에서 원인을 확인할 수 있습니다. |
| 결과가 로그인 뒤나 대화형 페이지에 있음 | [브라우저 사용](/ko/features/browser-control) 같은 브라우저 기능을 이용하세요. 공개 URL 가져오기에서는 로그인 세션을 사용할 수 없습니다. |

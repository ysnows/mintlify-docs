---
title: "번역"
description: "선택한 텍스트, 화면의 특정 영역, 또는 음성으로 받아쓰는 내용을 번역하세요."
---

Enconvo는 선택한 텍스트를 **Translator**로, 화면의 텍스트를 **Screenshot Translate**로, 말하는 내용을 받아쓰기와 함께 실시간으로 번역합니다. 이 기능들은 모두 [글쓰기 도구](/ko/features/writing-tools)에 포함되어 있으며 설정한 AI 모델로 동작합니다.

## 선택한 텍스트 번역하기

1. 아무 앱에서나 번역할 문장을 선택하세요.
2. PopBar에서 **번역**을 클릭하거나 SmartBar를 열어 **Translator**를 실행하세요.
3. 번역문을 확인한 뒤 **붙여넣기**를 클릭해 원문을 바꾸거나 복사하세요.

## 언어 선택하기

**설정 → AI 명령**을 열고 **기본 제공** 아래에서 **Translator**를 선택한 뒤 **언어** 섹션에서 언어를 설정하세요.

| 설정 | 기능 |
| --- | --- |
| **대상 언어** | Translator가 결과물을 작성할 언어입니다. 원본 언어 외의 다른 언어로 된 텍스트는 이 언어로 번역됩니다. **자동**으로 두면 응답 언어(**설정 → 내 정보**)를 따르며, 그 역시 자동이면 Mac의 시스템 언어를 따릅니다. |
| **원본 언어** | 대상 언어와 짝을 이루는 언어입니다: 이미 대상 언어로 적힌 텍스트를 이 언어로 번역합니다. **자동**으로 두면 응답 언어를 따르며, 대상 언어가 응답 언어와 같으면 영어로 번역합니다. |

예를 들어 대상 언어를 영어, 원본 언어를 중국어로 두면 중국어나 프랑스어 텍스트는 영어로, 영어 텍스트는 중국어로 번역됩니다.

## 번역 스타일 선택하기

**설정 → AI 명령**의 Translator 페이지에 있는 **번역 스타일**은 번역문의 문체를 결정합니다. Screenshot Translate에도 동일하게 적용됩니다. 변경 내용은 입력하는 즉시 저장됩니다.

| 스타일 | 번역 결과의 느낌 |
| --- | --- |
| **표준** | 원문에 충실하고 정확하게 번역합니다. |
| **원어민처럼** | 원어민이 직접 쓴 것처럼 자연스럽게 의역합니다. |
| **사용자 지정** | 입력란에 적은 스타일 설명을 따릅니다. |

받아쓰기에는 받아쓴 내용을 번역할 때 쓰는 별도의 **번역 스타일** 설정이 있습니다.

## 화면 일부 번역하기

1. SmartBar에서 **Screenshot Translate**를 실행하세요.
2. 번역할 영역을 드래그하세요.
3. 번역 결과가 Dynamic Island에 나타납니다. 클릭하면 채팅이 열려 스크린샷과 번역 결과에 대해 추가 질문을 할 수 있습니다.

Screenshot Translate는 기본적으로 지정한 영역을 이미지 그대로 Translator 모델에 보냅니다. OCR 제공업체로 먼저 텍스트를 읽은 뒤 그 텍스트를 번역하려면 **설정 → 플러그인 → 글쓰기 도구 → Screenshot Translate**에서 **OCR 필요**를 켜세요. 이 경우 OCR 오인식으로 의미가 달라질 수 있으므로 화면 내용과 대조해 확인하는 것이 좋습니다. 제공업체 설정은 [OCR](/ko/ai/ocr)을 참고하세요.

| 설정 | 기능 |
| --- | --- |
| **OCR 필요** | 번역 전에 OCR 제공업체로 텍스트를 먼저 읽습니다. 기본값은 꺼짐입니다. |
| **후속 명령** | 번역 후 이어서 보내는 메시지에 응답할 명령입니다. |
| **닫은 후 지우기** | 번역 창을 닫은 뒤 답변을 이어가지 않으면 10초 후 Dynamic Island를 빈 입력창으로 되돌립니다. |

## 말하면서 번역하기

받아쓰기 중 **정리** 옵션에서 **번역**을 선택하면, Enconvo가 말한 내용을 응답 언어로(이미 응답 언어로 말하고 있다면 영어로) 변환해 입력해 줍니다. 이 옵션은 인식된 텍스트가 삽입되기 전에 처리하는 **Dictation Translate** 명령으로 동작합니다. [받아쓰기](/ko/features/dictation)를 참고하세요.

실시간 번역 자막이 필요하면 [실시간 자막](/ko/features/live-captioning)에서 실시간 번역을 지원하는 음성 제공업체를 선택하세요.

## 용어 일관성 유지하기

Translator는 **설정 → AI 명령 → 모든 명령**에 지정된 모델을 사용합니다. 다른 모델을 쓰려면 Translator 페이지에서 **AI 모델**을 변경하세요.

자주 쓰는 전문 용어가 있다면 Translator 페이지에서 **사용자 지정**을 클릭하거나 [에이전트](/ko/ai/agents) 지침을 작성해 용어집을 추가하세요. 고유명사, 기술 식별자, 인용구 등 번역하지 말고 그대로 두어야 할 항목을 명시하면 좋습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 잘못된 언어로 번역됨 | Translator의 **대상 언어**, **원본 언어**와 **후속 동작** 설정을 확인하세요. |
| 번역이 너무 직역이거나 의역이 과함 | Translator 페이지에서 **번역 스타일**을 변경하세요. |
| 번역에서 일부 텍스트가 누락됨 | 선택한 텍스트 번역이라면 손쉬운 사용 권한을 확인하세요. **OCR 필요**가 켜진 Screenshot Translate라면 OCR이 텍스트를 어떻게 읽었는지 확인하세요. |
| Screenshot Translate가 아무것도 캡처하지 못함 | [권한](/ko/configuration/permissions)에서 화면 기록 권한을 확인하세요. |

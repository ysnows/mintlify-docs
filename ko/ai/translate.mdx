---
title: "번역"
description: "선택한 텍스트, 화면의 일부, 받아쓰기한 내용을 번역하세요."
---

Enconvo는 선택한 텍스트는 **번역기**로, 화면의 텍스트는 **스크린샷 번역**으로, 받아쓰기하는 음성은 받아쓰기로 번역합니다. 모두 [글쓰기 도구](/ko/features/writing-tools)의 일부이며 사용자의 AI 모델에서 실행됩니다.

## 선택한 텍스트 번역

1. 아무 앱에서나 구절을 선택합니다.
2. PopBar에서 **번역**을 클릭하거나, SmartBar를 열고 **번역기**를 실행합니다.
3. 번역을 확인한 다음 **붙여넣기**를 클릭하여 원문을 바꾸거나, 번역을 복사합니다.

## 언어 선택

**설정 → AI 명령**을 열고 **기본 제공** 아래에서 **번역기**를 선택한 다음 **언어** 섹션에서 언어를 지정합니다.

| 설정 | 기능 |
| --- | --- |
| **대상 언어** | 번역기가 출력하는 언어입니다. 원본 언어가 아닌 다른 모든 언어의 텍스트가 이 언어로 번역됩니다. **자동**은 응답 언어(**설정 → 내 정보**)를 사용하며, 이것도 자동이면 Mac의 언어를 사용합니다 |
| **원본 언어** | 대상 언어와 짝을 이루는 언어입니다. 이미 대상 언어로 된 텍스트는 이 언어로 번역됩니다. **자동**은 응답 언어를 사용하며, 응답 언어가 대상 언어이면 영어를 사용합니다 |

예를 들어 대상 언어가 영어이고 원본 언어가 중국어이면, 중국어나 프랑스어 텍스트는 영어로 바뀌고 영어 텍스트는 중국어로 바뀝니다.

## 번역 스타일 선택

**설정 → AI 명령**의 번역기 페이지에서 **번역 스타일**로 번역이 읽히는 방식을 정합니다. 스크린샷 번역에도 이 설정이 사용됩니다. 변경 사항은 입력하는 대로 저장됩니다.

| 스타일 | 번역이 읽히는 방식 |
| --- | --- |
| **표준** | 정확하며 원문에 가까움 |
| **원어민처럼** | 원어민이 쓴 것처럼 자유롭게 다시 표현함 |
| **사용자 지정** | 입력란에 설명한 스타일을 따름 |

받아쓰기에는 받아쓰는 내용을 위한 별도의 **번역 스타일**이 있습니다.

## 화면의 일부 번역

1. SmartBar에서 **스크린샷 번역**을 실행합니다.
2. 번역할 영역 위로 드래그합니다.
3. 번역이 Dynamic Island에 나타납니다. 클릭하면 채팅이 열리며, 스크린샷과 번역에 대해 추가로 질문할 수 있습니다.

스크린샷 번역은 해당 영역을 이미지로 번역기의 모델에 보냅니다. 먼저 OCR 제공업체로 텍스트를 읽고 그 텍스트를 번역하려면 **설정 → 플러그인 → 글쓰기 도구 → 스크린샷 번역**에서 **OCR 필요**를 켜세요. 그러면 OCR 오류가 의미를 바꿀 수 있으니 결과를 화면과 비교하세요. 제공업체 설정은 [OCR](/ko/ai/ocr)을 참고하세요.

| 설정 | 기능 |
| --- | --- |
| **OCR 필요** | 번역하기 전에 OCR 제공업체로 텍스트를 읽습니다. 기본값은 꺼짐입니다 |
| **후속 명령** | 번역 후에 보내는 메시지에 답하는 명령입니다 |
| **닫은 후 지우기** | 번역에 답장하지 않았다면, 번역을 닫고 10초 후에 Dynamic Island를 빈 입력 상태로 되돌립니다 |

## 말하는 동안 번역

받아쓰기하는 동안 받아쓰기의 **정리** 옵션에서 **번역**을 선택하면, Enconvo가 말한 내용을 응답 언어로 입력하며, 이미 그 언어로 말하고 있다면 영어로 입력합니다. 이 옵션은 **받아쓰기 번역** 명령으로, 인식된 텍스트를 삽입하기 전에 처리합니다. [받아쓰기](/ko/features/dictation)를 참고하세요.

실시간 번역 자막을 사용하려면 [실시간 자막](/ko/features/live-captioning)에서 실시간 번역을 제공하는 음성 제공업체를 선택하세요.

## 용어 일관성 유지

번역기는 **설정 → AI 명령 → 모든 명령**에서 지정한 모델로 실행됩니다. 다른 모델을 사용하려면 번역기 페이지에서 **AI 모델**을 변경하세요.

자주 쓰는 용어가 있다면 번역기 페이지에서 **사용자 지정**을 클릭하거나 [에이전트](/ko/ai/agents) 지침을 작성하고 용어집을 추가하세요. 이름, 기술 식별자, 인용 구절처럼 그대로 두어야 할 내용을 알려 주세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 번역이 엉뚱한 언어로 나옴 | 번역기의 **대상 언어**, **원본 언어**와 **완료 후 동작**을 확인하세요 |
| 번역이 너무 직역이거나 너무 자유로움 | 번역기 페이지에서 **번역 스타일**을 변경하세요 |
| 번역에 텍스트가 빠짐 | 선택한 텍스트라면 손쉬운 사용 권한을 확인하세요. **OCR 필요**를 켠 스크린샷 번역이라면 OCR이 읽은 내용을 확인하세요 |
| 스크린샷 번역이 아무것도 캡처하지 않음 | [권한](/ko/configuration/permissions)에서 화면 기록 권한을 확인하세요 |

코딩 에이전트는 Claude Code나 Codex처럼 이미 쓰는 AI 코딩 도구를 Enconvo 채팅 안에서 실행하는 것입니다. 프로젝트 폴더의 코드 작업에 쓰세요. 차이로 파일을 고치고, 명령을 실행하고, 행동하기 전에 묻습니다. Enconvo는 채팅, 기록, 승인을 채팅 창, SmartBar, 휴대폰에 둡니다.

| 코딩 에이전트 | 만든 곳 | 실행 위치 |
| --- | --- | --- |
| **Claude Code** | Anthropic | Mac에서, Claude로 로그인 |
| **Codex** | OpenAI | Mac에서, ChatGPT로 로그인 |
| **Grok Build** | xAI | Mac에서, Grok로 로그인 |
| **Antigravity** | Google | Mac에서, Google로 로그인 |
| **Muse Code** | Meta | Mac에서 Meta로 로그인하거나, 로컬 모델에서 |
| **Grok Bot** | xAI | 연결한 루틴을 통해 xAI 클라우드에서 |

## 시작하기 전에

코딩 에이전트마다 **설정 → 에이전트 목록**에 페이지가 있습니다. 클릭하면 **상태**가 보입니다.

1. **설치되지 않음**이면 **설치**를 클릭하거나, 터미널에 나온 명령을 실행한 뒤 **다시 확인**을 클릭하세요. 버전이 너무 오래되면 **업데이트**가 표시됩니다.
2. **계정** 아래에서 **Claude로 로그인**, **ChatGPT로 로그인**, **Grok로 로그인**, **Google로 로그인**, **Meta로 로그인**을 클릭하세요. Enconvo는 터미널의 해당 에이전트 명령줄과 같은 로그인을 씁니다.

Claude Code나 Codex 로그인이 열흘 안에 끝나면, 에이전트 페이지, **업데이트** 목록, 프로젝트의 보드가 그렇게 말하고 **다시 로그인**을 보여 줍니다. 코딩 에이전트가 로그아웃된 보드 작업은 **보류됨**으로 기다리다가, 로그인하면 다시 실행됩니다.

로컬 모델에서 도는 Muse Code는 Meta 로그인이 필요 없습니다. Grok Bot은 루틴이 필요합니다. 아래 Grok Bot 연결을 보세요.

## 코딩 에이전트와 채팅

1. 채팅 창에서 에이전트 카드나 에이전트 메뉴로 코딩 에이전트를 고르세요.
2. 작업할 프로젝트 폴더를 고르세요.
3. 요청을 입력하고 보내세요. 단계, 차이, 명령이 채팅으로 흘러 들어오고, 승인 질문은 답할 카드로 나타납니다.

채팅의 승인은 Enconvo의 [권한 모드](/ko/ai/agents)를 따릅니다. **전체 접근**에서는 새 Claude Code 채팅이 **권한 우회**(Claude Code 자체 설정이 허용할 때)로, 새 Codex 채팅이 **전체 접근**으로 시작해, 행동하기 전에 묻지 않습니다.

워크트리 채팅에서 사이드 패널의 **풀 리퀘스트** 탭(**⌃⇧P**)은 GitHub의 브랜치 풀 리퀘스트를 보여 주거나 만듭니다. [채팅 창](/ko/ai/chat)을 보세요.

이전 세션을 이어가려면 **이전 세션 이어서 하기**를 고르세요. 에이전트 자체 명령줄에서 시작한 세션도, 붙인 이름 아래에 나열됩니다.

Mavis와 시작한 채팅을 코딩 에이전트와 새 채팅으로 이어 넘길 수도 있습니다. 다른 에이전트는 코딩 에이전트를 하위 에이전트로 쓸 수 있고, 프로젝트는 작업을 맡기거나 한 명이 프로젝트를 이끌게 할 수 있습니다. [하위 에이전트](/ko/ai/agents)와 [프로젝트](/ko/ai/projects)를 보세요.

### Claude Code: 노력, 빠른 모드, Ultracode

Claude Code 채팅의 노력 선택기는 추론 노력을 정합니다. 세션이 지원하면 선택기에 **빠른 모드**와 **Ultracode** 스위치도 보입니다. Ultracode는 고른 노력과 관계없이 세션이 끝날 때까지 워크플로 조율을 켜고, 노력을 바꿔도 유지됩니다. `/effort ultracode`를 입력해도 같습니다. 새 채팅에서는 첫 메시지 전에 빠른 모드와 Ultracode를 설정할 수 있습니다.

### Codex: 경고

Codex 경고는 대화에 나오지 않습니다. `/warnings`를 입력해 목록을 보세요.

### Muse Code: 터미널에서 이어가기

Muse Code 채팅을 터미널에서 이어가려면 **터미널에서 계속**을 고르거나, **명령 복사**로 복사하세요. 채팅은 그 폴더에서 `muse resume`로 열립니다. 그곳에서 Muse Code를 종료하고 Enconvo에서 다시 보내면, 터미널에서 돌린 턴이 채팅으로 돌아옵니다.

Muse Code의 승인 질문은 편집이 만들 변화를 보여 줍니다. 단계를 거부하면 **거부**와 함께 입력한 내용이 같은 턴에 Muse Code로 가므로, 바로 그에 따라 행동할 수 있습니다. 스킬과 `/compact`는 `/` 메뉴에 있습니다.

<Note>
Muse Code의 Contributor 모드는 기본적으로 켜져 있어, Meta가 프롬프트와 코드로 모델을 학습할 수 있습니다. Enconvo는 이를 그대로 둡니다. Muse Code 자체 설정에서 끄세요.
</Note>

## 코딩 에이전트가 Enconvo에서 쓸 수 있는 것 고르기

코딩 에이전트는 채팅에서 Enconvo 플러그인을 쓸 수 있습니다. Enconvo 에이전트에 메시지 보내기, 이미지와 동영상 만들기, 메모리, 브라우저, 컴퓨터 사용 등입니다. **설정 → 에이전트 목록**의 에이전트 페이지에서 **Enconvo 기능** 아래를 보세요.

- **Enconvo 기능**을 끄면 그 에이전트가 Enconvo 플러그인 전체를 쓰지 못합니다.
- 또는 **플러그인** 옆 **사용자 지정**을 클릭해 플러그인을 하나씩 끄세요. 꺼진 플러그인은 그 에이전트에게 숨겨지고, 호출은 거부됩니다.

변경은 열려 있는 채팅에도 적용됩니다. 클라이언트의 Workspace 안 코딩 에이전트 채팅은 그 Workspace 안에만 남습니다.

## Grok Bot 연결

Grok Bot은 xAI 클라우드에서 실행됩니다. Enconvo는 각 메시지를 Grok Bot에서 만든 Webhook 루틴으로 보내고, 늦게 도착해도 답변을 채팅에 보여 줍니다.

1. Grok Bot에서 Webhook 트리거가 있는 루틴을 만드세요.
2. **설정 → 에이전트 목록**에서 **Grok Bot**을 열고, **루틴 지침** 옆 **복사**를 클릭해 루틴에 붙여 넣으세요.
3. 같은 페이지의 자격 증명으로 루틴의 webhook URL과 키를 추가한 뒤 **테스트**를 클릭하세요. 테스트는 루틴 답변을 최대 약 90초 기다립니다.

루틴이 연결되기 전에는 에이전트 선택기에 Grok Bot이 **설정 안 됨**으로 보입니다. 모든 메시지는 Grok Bot 요금제의 주간 사용량을 씁니다. **중지**는 Enconvo가 기다리는 것만 멈춥니다. 루틴 실행은 클라우드에서 이어지고, 나중에 온 답변도 채팅에 추가됩니다.

메시지는 최대 32,000자입니다. 첨부 파일과 이미지는 Mac에 남고, 텍스트만 전송됩니다.

### Grok Bot이 Enconvo를 호출하게 하기

Enconvo의 MCP 서버가 있으면 Grok Bot은 채팅에 답하고, Mac과 페어링된 휴대폰에 알리고, Mac의 에이전트에게 작업을 실행하라고 요청할 수 있습니다.

1. Grok Bot 페이지의 **Grok Bot에서 Enconvo 호출** 아래에서 **연결**을 클릭하세요. Enconvo 계정에 로그인되어 있어야 합니다.
2. Grok Bot에서 **플러그인**을 열고, 표시된 **Server URL**을 추가한 뒤 Grok Bot이 물으면 Enconvo 계정으로 로그인하세요.

Mac의 에이전트에 대한 각 요청은 **ask_mac 항상 허용**을 켜지 않는 한 승인을 기다립니다. 요청은 **이 Mac의 Grok Bot** 채팅에 남습니다. **연결 해제**를 클릭하면 Grok Bot이 Enconvo를 호출하지 못합니다. 연결을 끊거나 Mac이 오프라인이 되면 아직 기다리는 요청은 철회됩니다.

## 문제 해결

| 문제 | 할 일 |
| --- | --- |
| 채팅이 에이전트가 로그인되지 않았다고 함 | **설정 → 에이전트 목록**에서 에이전트 페이지를 열고 **다시 로그인**을 클릭하세요. 에이전트를 호출한 Mavis 채팅이나 앱도 같은 로그인 오류를 받고, 보드 작업은 로그인할 때까지 **보류됨**으로 기다립니다. |
| 에이전트가 **설치되지 않음**이거나 버전이 너무 오래됨 | 페이지에서 **설치** 또는 **업데이트**를 클릭한 뒤 **다시 확인**을 누르세요. |
| Muse Code가 Enconvo 업데이트가 필요하다고 함 | 더 새 Muse Code와 맞추려면 Enconvo를 업데이트하세요. |
| Grok Bot이 **설정 안 됨**으로 보임 | Grok Bot 페이지에 루틴의 webhook URL과 키를 추가하고 **테스트**를 클릭하세요. |
| Grok Bot 테스트가 메시지가 너무 많다고 함 | 루틴이나 Enconvo가 지금은 너무 많은 메시지를 거절하고 있습니다. 나중에 다시 시도하세요. |
| 터미널에 열린 Muse Code 채팅이 보내지 않음 | 터미널에서 Muse Code를 종료해 턴을 되돌린 뒤 Enconvo에서 보내세요. |

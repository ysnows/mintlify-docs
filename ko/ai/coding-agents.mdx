코딩 에이전트는 Claude Code나 Codex처럼 이미 쓰고 계신 AI 코딩 도구를 Enconvo 채팅 안에서 실행하는 것입니다. 프로젝트 폴더의 코드를 다루는 작업이라면 코딩 에이전트를 사용하세요. 코딩 에이전트는 diff와 함께 파일을 수정하고, 명령을 실행하며, 실행 전에 먼저 물어봅니다. Enconvo는 채팅과 기록, 승인을 채팅 창, SmartBar, 휴대폰에서 계속 이어서 관리합니다.

| 코딩 에이전트 | 개발사 | 실행 위치 |
| --- | --- | --- |
| **Claude Code** | Anthropic | Mac에서 실행, Claude로 로그인 |
| **Codex** | OpenAI | Mac에서 실행, ChatGPT로 로그인 |
| **Grok Build** | xAI | Mac에서 실행, Grok로 로그인 |
| **Antigravity** | Google | Mac에서 실행, Google로 로그인 |
| **Muse Code** | Meta | Mac에서 실행, Meta로 로그인하거나 로컬 모델 사용 |
| **Grok Bot** | xAI | 연결한 루틴을 통해 xAI 클라우드에서 실행 |

## 시작하기 전에

각 코딩 에이전트에는 **설정 → 에이전트 목록**에 전용 페이지가 있습니다. 페이지를 클릭해 **상태**를 확인하세요.

1. **설치되지 않음**으로 표시되면 **설치**를 클릭하거나, 표시된 명령을 터미널에서 실행한 다음 **다시 확인**을 클릭하세요. 버전이 너무 오래되었다면 **업데이트**가 표시됩니다.
2. **계정**에서 **Claude로 로그인**, **ChatGPT로 로그인**, **Grok로 로그인**, **Google로 로그인**, **Meta로 로그인** 중 하나를 클릭하세요. Enconvo는 터미널에서 사용하는 에이전트의 명령줄과 같은 로그인을 사용합니다.

Claude Code 또는 Codex의 로그인이 10일 이내에 만료되면 에이전트 페이지, **업데이트** 목록, 프로젝트의 보드에 이 사실이 **다시 로그인**과 함께 표시됩니다. 코딩 에이전트가 로그아웃된 보드 작업은 **보류됨**으로 대기하다가 로그인하면 다시 실행됩니다.

로컬 모델로 실행하는 Muse Code는 Meta 로그인이 필요 없습니다. Grok Bot은 루틴이 필요합니다. [Grok Bot 연결](#grok-bot-연결)을 참고하세요.

## 코딩 에이전트와 대화하기

1. 채팅 창에서 에이전트 카드 또는 에이전트 메뉴로 코딩 에이전트를 선택하세요.
2. 에이전트가 작업할 프로젝트 폴더를 선택하세요.
3. 요청을 입력하고 전송하세요. 에이전트의 단계, diff, 명령이 채팅에 실시간으로 표시되고, 승인 질문은 카드로 나타나 답할 수 있습니다.

채팅의 승인은 Enconvo의 [권한 모드](/ko/ai/agents)를 따릅니다. **전체 접근**에서는 새 Claude Code 채팅이 **권한 우회**(Claude Code 자체 설정이 허용하는 경우)로, 새 Codex 채팅이 **전체 접근**으로 시작되므로 어느 쪽도 실행 전에 묻지 않습니다.

워크트리 채팅에서는 사이드 패널의 **풀 리퀘스트** 탭(**⌃⇧P**)에 브랜치의 GitHub 풀 리퀘스트가 표시되며, 여기서 새로 만들 수도 있습니다. [채팅 창](/ko/ai/chat)을 참고하세요.

이전 세션을 이어가려면 **이전 세션 이어서 하기**를 선택하세요. 에이전트의 명령줄에서 시작한 세션도 직접 지정한 이름으로 함께 표시됩니다.

Mavis로 시작한 채팅을 코딩 에이전트와 새 채팅에서 이어가는 방식으로 코딩 에이전트에게 넘길 수도 있습니다. 다른 에이전트는 코딩 에이전트를 하위 에이전트로 사용할 수 있고, 프로젝트에서는 코딩 에이전트에게 작업을 맡기거나 코딩 에이전트 하나가 프로젝트를 이끌게 할 수 있습니다. [하위 에이전트](/ko/ai/agents)와 [프로젝트](/ko/ai/projects)를 참고하세요.

### Claude Code: 노력 수준, 빠른 모드, Ultracode

Claude Code 채팅의 노력 수준 선택기는 추론 노력 수준을 설정합니다. 세션이 지원하면 선택기에 **빠른 모드**와 **Ultracode** 스위치도 표시됩니다. Ultracode는 선택한 노력 수준을 그대로 유지한 채 세션이 끝날 때까지 워크플로 오케스트레이션을 켜며, 노력 수준을 바꿔도 켜진 상태로 유지됩니다. `/effort ultracode`를 입력해도 같은 효과가 있습니다. 새 채팅에서는 첫 메시지를 보내기 전에 빠른 모드와 Ultracode를 설정할 수 있습니다.

### Codex: 경고

Codex의 경고는 대화에 표시되지 않습니다. `/warnings`를 입력하면 목록을 볼 수 있습니다.

### Muse Code: 터미널에서 이어가기

Muse Code 채팅을 터미널에서 이어가려면 **터미널에서 계속하기**를 선택하거나, **명령 복사**로 명령을 복사하세요. 해당 폴더에서 `muse resume`으로 채팅이 열립니다. 터미널에서 Muse Code를 종료하고 Enconvo에서 다시 전송하면 터미널에서 진행한 대화 내용이 채팅으로 돌아옵니다.

Muse Code의 승인 질문에는 편집이 적용할 변경 내용이 표시됩니다. 단계를 거부할 때 **거부**와 함께 입력한 내용은 같은 턴에서 Muse Code에 전달되므로 Muse Code가 바로 반영할 수 있습니다. Muse Code의 스킬과 `/compact`는 `/` 메뉴에 있습니다.

<Note>
Muse Code의 기여자 모드는 기본으로 켜져 있어, Meta가 사용자의 프롬프트와 코드로 자사 모델을 학습시킬 수 있습니다. Enconvo는 이 설정을 건드리지 않으므로, 끄려면 Muse Code 자체 설정에서 끄세요.
</Note>

## Enconvo에서 코딩 에이전트가 사용할 수 있는 기능 선택하기

코딩 에이전트는 채팅에서 Enconvo 에이전트에게 메시지 보내기, 이미지·동영상 생성, 메모리, 브라우저, 컴퓨터 사용 같은 Enconvo 플러그인을 사용할 수 있습니다. **설정 → 에이전트 목록**의 해당 에이전트 페이지에서 **Enconvo 기능** 아래를 확인하세요.

- **Enconvo 기능**을 끄면 해당 에이전트가 모든 Enconvo 플러그인을 사용할 수 없습니다.
- 또는 **플러그인** 옆의 **사용자 지정**을 클릭해 플러그인을 하나씩 끌 수 있습니다. 꺼진 플러그인은 해당 에이전트에게 보이지 않으며, 호출도 거부됩니다.

변경 내용은 에이전트의 열려 있는 채팅에도 적용됩니다. 클라이언트 워크스페이스의 코딩 에이전트 채팅은 해당 워크스페이스 안에서만 유지됩니다.

## Grok Bot 연결

Grok Bot은 xAI 클라우드에서 실행됩니다. Enconvo는 Grok Bot에서 만든 Webhook 루틴으로 메시지를 보내고, 답변이 늦게 도착하더라도 채팅에 표시합니다.

1. Grok Bot에서 Webhook 트리거가 있는 루틴을 만드세요.
2. **설정 → 에이전트 목록**에서 **Grok Bot**을 열고 **루틴 지침** 옆의 **복사**를 클릭한 다음, 루틴에 붙여넣으세요.
3. 같은 페이지에서 루틴의 웹훅 URL과 키를 자격 증명으로 추가한 다음 **테스트**를 클릭하세요. 테스트는 루틴의 답변을 최대 약 90초 동안 기다립니다.

루틴이 연결되기 전까지 에이전트 선택기에는 Grok Bot이 **설정 안 됨**으로 표시됩니다. 모든 메시지는 Grok Bot 요금제의 주간 사용량을 소모합니다. **중지**는 Enconvo가 기다리는 것만 멈춥니다. 루틴의 실행은 클라우드에서 계속되며, 나중에 도착한 답변도 채팅에 추가됩니다.

메시지는 최대 32,000자까지 보낼 수 있습니다. 첨부한 파일과 이미지는 Mac에 남아 있고 텍스트만 전송됩니다.

### Grok Bot이 Enconvo를 호출하도록 하기

Enconvo의 MCP 서버를 사용하면 Grok Bot이 채팅에 답하고, Mac과 페어링된 휴대폰에 알림을 보내고, Mac의 에이전트에게 작업 실행을 요청할 수 있습니다.

1. Grok Bot 페이지의 **Grok Bot에서 Enconvo 호출** 아래에서 **연결**을 클릭하세요. Enconvo 계정에 로그인되어 있어야 합니다.
2. Grok Bot에서 **플러그인**을 열고 표시된 **서버 URL**을 추가한 다음, Grok Bot이 요청하면 Enconvo 계정으로 로그인하세요.

Mac의 에이전트에 대한 각 요청은 **ask_mac 항상 허용**을 켜지 않는 한 사용자의 승인을 기다립니다. 요청은 **이 Mac의 Grok Bot** 채팅에 계속 목록으로 남습니다. Grok Bot이 Enconvo를 호출하지 못하게 하려면 **연결 해제**를 클릭하세요. 연결을 해제하거나 Mac이 오프라인이 되면 대기 중인 요청은 철회됩니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 채팅에 에이전트가 로그인되지 않았다고 표시됨 | **설정 → 에이전트 목록**에서 에이전트 페이지를 열고 **다시 로그인**을 클릭하세요. 에이전트를 호출한 Mavis 채팅이나 앱에도 같은 로그인 오류가 표시되며, 해당 보드 작업은 로그인할 때까지 **보류됨**으로 대기합니다. |
| 에이전트가 **설치되지 않음**이거나 버전이 너무 오래됨으로 표시됨 | 에이전트 페이지에서 **설치** 또는 **업데이트**를 클릭한 다음 **다시 확인**을 클릭하세요. |
| Muse Code가 Enconvo 업데이트가 필요하다고 표시함 | 더 새로운 Muse Code와 함께 사용하려면 Enconvo를 업데이트하세요. |
| Grok Bot이 **설정 안 됨**으로 표시됨 | Grok Bot 페이지에서 루틴의 웹훅 URL과 키를 추가하고 **테스트**를 클릭하세요. |
| Grok Bot 테스트에서 메시지가 너무 많다고 표시됨 | 루틴 또는 Enconvo가 현재 너무 많은 메시지를 거부하고 있습니다. 나중에 다시 시도하세요. |
| 터미널에서 열려 있는 Muse Code 채팅이 전송되지 않음 | 터미널에서 Muse Code를 종료해 대화 내용을 가져온 다음, Enconvo에서 전송하세요. |

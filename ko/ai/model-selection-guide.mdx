title: "모델 선택"
description: "작업에 맞는 모델을 고르고, Enconvo의 기본 모델이 설정되는 위치를 알아봅니다."
---

꼭 고를 필요는 없습니다. 기본 모델인 [Auto Route](/ko/providers/auto-route)가 메시지마다 모델을 골라 줍니다. 특정 모델을 쓰고 싶을 때 이 페이지에서 모델을 고르는 방법과 선택이 저장되는 위치를 알 수 있습니다.

## 작업별로 고르기

| 작업 | 찾아볼 것 |
| --- | --- |
| 빠른 다시 쓰기와 짧은 답변 | 빠르고 저렴한 모델 |
| 여러 단계로 이루어진 에이전트 작업 | 안정적인 도구 호출과 추론 지원 |
| 스크린샷이나 이미지에 대한 질문 | 이미지 입력 |
| 긴 문서 | 긴 컨텍스트 창 |
| Mac에서만 처리하는 비공개 작업 | [로컬 모델](/ko/ai/local-llm)과 나머지 단계를 위한 로컬 제공업체 |
| 음성 대화 | 자체 음성 설정이 있는 [Live Talk](/ko/features/live-voice) |
| 이미지나 비디오 생성 | 채팅 모델이 아닌 [이미지](/ko/ai/image-generation) 또는 [비디오](/ko/ai/video-generation) 제공업체 |

모델 선택기에는 지금 제공업체가 제공하는 모델이 표시됩니다. Fast 모드를 지원하는 모델에는 Fast 모드 칩이 표시되며, 더 높은 가격으로 더 빠르게 실행합니다.

## 추천 활용

설정의 모델 선택기는 해당 작업에 대한 세 가지 제안으로 시작합니다. **가장 적합**, **최저 비용**, **최고 품질**입니다. 각 제안에는 짧은 이유와 입력 및 출력의 100만 토큰당 가격이 표시됩니다. 설정 아래에는 선택한 모델이 추천 모델보다 몇 배 더 비쌀 때 알려 주는 안내가 나옵니다.

**새 에이전트 만들기**로 에이전트를 만들면 Enconvo가 에이전트의 설명을 읽고 모델을 제안하며, 더 저렴한 모델과 더 강력한 모델도 함께 보여 줍니다. 하나를 클릭하면 그 모델을 사용합니다.

## 기본값이 설정되는 위치

- **새 채팅**: 최상위 **새 채팅**에서 고르는 모델이 에이전트의 기본값이 됩니다.
- **프로젝트**: 프로젝트 안의 새 채팅은 프로젝트 자체의 모델을 사용합니다.
- **기존 채팅**: 채팅이 시작되면 해당 채팅에서 바꾸기 전까지 모델과 추론 강도를 유지합니다.
- **자체 선택이 없는 채팅과 메신저 채널**: 에이전트의 기본값을 따릅니다.

다른 곳에서 기본값을 바꾼 뒤에는 보내기 전에 채팅에 표시된 모델을 확인하세요.

## 추론 강도

추론 강도는 모델이 답하기 전에 얼마나 오래 생각하는지를 정합니다. 강도가 높으면 어려운 문제에 더 좋은 답을 줄 수 있지만 시간이 더 걸리고 토큰도 더 많이 사용합니다. 단계는 모델에 따라 다르며, 사고 모드가 없는 모델에는 강도 설정이 없습니다.

## 컨텍스트 창

컨텍스트 창은 모델이 한 번에 읽는 대화의 양입니다. 채팅이 그보다 길어지면 Enconvo는 앞부분을 압축합니다. 최대 100만 토큰까지 받을 수 있는 Claude 모델은 50만 토큰에서 시작하므로 긴 채팅이 더 일찍 압축되고 비용이 줄어듭니다.

모델의 컨텍스트 창을 바꾸려면 **설정 → AI 모델**에서 제공업체를 열고, **모델 이름** 옆의 톱니바퀴인 **모델 관리**를 클릭한 다음 모델을 편집해 **컨텍스트 창**을 설정하세요.

## 백그라운드 작업용 모델 선택

작은 작업은 저렴한 모델로 백그라운드에서 실행됩니다. 채팅 제목, 다음 메시지 제안, Live Talk, 녹음 제목과 요약, 녹음 번역, 아이디어 제목이 해당합니다. 기본적으로 각각 작은 모델을 쓰는 **자동**으로 설정되어 있습니다.

- 채팅 제목, 다음 메시지 제안, Live Talk는 채팅 자체 제공업체의 작은 모델을 사용합니다. 직접 발급한 API 키로 하는 채팅은 이 작업에 Enconvo Cloud 포인트를 쓰지 않습니다.
- 녹음과 아이디어 제목은 기본 제공업체의 작은 모델을 사용합니다.
- 제공업체에 Enconvo가 아는 작은 모델이 없으면 자동은 채팅의 모델이나 기본 모델을 사용합니다.

직접 모델을 고르려면 다음과 같이 하세요.

<Steps>
  <Step title="작업 모델 열기">
    **설정 → AI 모델**을 열고 페이지 상단의 **작업 모델**을 클릭합니다.
  </Step>
  <Step title="작업 선택">
    작업을 클릭합니다. **자동**에는 각 제공업체에서 어떤 모델을 고르는지 표시됩니다.
  </Step>
  <Step title="모델 선택">
    **모델 선택**을 클릭하고 제공업체를 고른 다음 모델을 고릅니다.
  </Step>
</Steps>

**다음 메시지 제안** 옆 스위치를 끄면 답변마다 다음 메시지를 제안하지 않습니다. **모두 자동으로 재설정**을 누르면 모든 작업이 **자동**으로 돌아갑니다.

## 백업 모델로 채팅 이어 가기

대체는 사용 한도에 도달하거나, 로그인이나 키를 잃거나, 연결할 수 없는 등 답변을 만드는 모델을 쓸 수 없을 때 답변을 이어 가게 해 줍니다. 답변은 다음 백업 모델에서 계속되며, 채팅에 어떤 모델이 왜 이어받았는지 표시됩니다.

<Steps>
  <Step title="대체 열기">
    **설정 → AI 모델**을 열고 페이지 상단의 **대체**를 클릭합니다.
  </Step>
  <Step title="백업 추가">
    **백업 모델 추가**를 클릭하고 모델을 고릅니다. 최대 세 개까지 추가할 수 있으며 끌어서 순서를 바꿀 수 있습니다.
  </Step>
  <Step title="각 백업의 강도 설정">
    추론 단계가 있는 모델은 **추론 강도**를 선택합니다. 각 백업은 자신의 값을 유지합니다.
  </Step>
</Steps>

패널에는 작동하는 체인이 표시됩니다. **사용 중인 모델**이 먼저 나오고, 그다음에 번호가 붙은 백업이 이어지며 각각 **준비됨** 또는 **일시 중지됨**으로 표시됩니다. 백업의 모델 이름을 클릭하면 같은 제공업체의 다른 모델로 바꿀 수 있습니다. 제공업체 목록에서는 백업을 가진 각 제공업체에 체인에서의 순서를 나타내는 **backup N** 태그가 표시됩니다.

| 설정 | 기능 |
| --- | --- |
| **서비스가 혼잡할 때도 전환** | 재시도가 모두 소진된 뒤 속도 제한과 서버 오류에서도 전환합니다. |
| **모델을 다시 사용할 수 있으면 돌아가기** | 채팅의 원래 모델이 다시 작동하면 다음 턴부터 원래 모델로 되돌립니다. 턴 도중에는 되돌리지 않습니다. |

안전 정책으로 거부된 요청은 모델을 전환하지 않습니다.

## 두 모델 비교

작고 실제적인 같은 작업을 두 모델에 보내 보세요. 답이 정확한지, 도구가 끝까지 실행되었는지, 시간이 얼마나 걸렸고 비용이 얼마인지 확인하세요. 각 답변 아래의 **세부 정보**에는 모델, 강도, 토큰, 시간, 포인트 또는 비용이 표시됩니다.

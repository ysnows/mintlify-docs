title: "모델 선택 가이드"
description: "작업에 알맞은 모델을 선택하고, Enconvo의 기본 모델이 어디에 저장되는지 알아보세요."
---

직접 고르지 않아도 기본 모델인 [자동 라우팅](/ko/providers/auto-route)이 메시지마다 알맞은 모델을 선택해 줍니다. 특정 모델을 직접 쓰고 싶다면 이 가이드에서 목적에 맞는 모델을 고르고 설정이 저장되는 위치를 확인하세요.

## 작업별로 고르기

| 작업 | 살펴볼 기준 |
| --- | --- |
| 빠른 문장 다듬기와 짧은 답변 | 빠르고 비용이 낮은 모델 |
| 여러 단계의 에이전트 작업 | 안정적인 도구 호출과 추론 지원 |
| 스크린샷이나 이미지에 관한 질문 | 이미지 입력 지원 |
| 긴 문서 처리 | 긴 컨텍스트 창 |
| Mac 안에서 처리하는 비공개 작업 | [로컬 모델](/ko/ai/local-llm) 및 다른 단계용 로컬 제공업체 |
| 음성 대화 | 별도 음성 설정이 있는 [Live Talk](/ko/features/live-voice) |
| 이미지나 동영상 제작 | 채팅 모델이 아닌 [이미지](/ko/ai/image-generation) 또는 [동영상](/ko/ai/video-generation) 제공업체 |

모델 선택기에는 현재 제공업체에서 이용할 수 있는 모델이 표시됩니다. 빠른 모드를 지원하는 모델에는 빠른 모드 칩이 나타나며, 더 높은 요금으로 빠르게 응답합니다.

## 추천 모델 활용하기

설정의 모델 선택기 상단에는 해당 작업에 맞춘 세 가지 추천이 표시됩니다: **가장 적합**, **최저 비용**, **최고 품질**. 각 항목에는 짧은 추천 이유와 입력·출력 1M 토큰당 가격이 함께 표시됩니다. 설정 아래쪽에는 내가 고른 모델이 추천 모델보다 몇 배 더 비쌀 때 알려 주는 안내가 표시됩니다.

**새 에이전트**에서 에이전트를 만들면 Enconvo가 에이전트 설명을 읽고 기본 모델과 함께 더 저렴한 모델, 더 강력한 모델을 나란히 제안합니다. 원하는 항목을 클릭해 바로 선택하세요.

## 기본값이 저장되는 위치

- **새 채팅**: 최상위 **새 채팅**에서 선택한 모델이 해당 에이전트의 기본 모델이 됩니다.
- **프로젝트**: 프로젝트 안의 새 채팅은 해당 프로젝트 자체 모델을 사용합니다.
- **기존 채팅**: 한 번 시작한 채팅은 그 채팅 안에서 바꾸기 전까지 처음의 모델과 추론 강도를 유지합니다.
- **별도 설정이 없는 채팅 및 메신저 채널**: 에이전트의 기본 설정을 따릅니다.

다른 곳에서 기본값을 바꾼 뒤에는 메시지를 보내기 전에 채팅 창에 표시된 모델을 확인하세요.

## 추론 강도

추론 강도는 모델이 답하기 전에 얼마나 오래 생각할지를 정합니다. 강도를 높이면 어려운 문제에서 더 나은 답을 얻을 수 있지만 시간이 오래 걸리고 토큰도 더 많이 사용합니다. 선택할 수 있는 단계는 모델마다 다르며, 추론 모드가 없는 모델에는 이 설정이 나타나지 않습니다.

## 컨텍스트 창

컨텍스트 창은 모델이 한 번에 읽을 수 있는 대화의 분량입니다. 대화가 이 크기를 넘어서면 Enconvo가 앞부분을 압축합니다. 최대 1M 토큰까지 지원하는 Claude 모델도 기본값은 500K로 시작해 긴 대화가 더 일찍 압축되고 비용을 아낄 수 있습니다.

모델의 컨텍스트 창을 변경하려면 **설정 → AI 모델**에서 해당 제공업체를 열고 **모델 관리**(**모델 이름** 옆의 톱니바퀴)를 클릭한 뒤 모델을 편집해 **컨텍스트 창**을 설정하세요.

## 백그라운드 작업용 모델 고르기

채팅 제목, 다음 메시지 제안, Live Talk, 녹음 제목 및 요약, 녹음 번역, 아이디어 제목 같은 작은 작업은 백그라운드에서 저렴한 모델로 실행됩니다. 기본값은 모두 **자동**으로, 소형 모델을 사용합니다.

- 채팅 제목, 다음 메시지 제안, Live Talk는 해당 채팅 제공업체의 소형 모델을 사용합니다. 본인 API 키를 쓰는 채팅에서는 이 작업에 Enconvo Cloud 포인트가 쓰이지 않습니다.
- 녹음과 아이디어 제목은 기본 제공업체의 소형 모델을 사용합니다.
- 제공업체에 Enconvo가 알고 있는 소형 모델이 없을 때는 자동으로 해당 채팅 모델이나 기본 모델을 사용합니다.

직접 모델을 지정하려면:

<Steps>
  <Step title="작업 모델 열기">
    **설정 → AI 모델**을 열고 페이지 상단에서 **작업 모델**을 클릭합니다.
  </Step>
  <Step title="작업 선택하기">
    작업을 클릭합니다. **자동**을 선택하면 제공업체별로 어떤 모델이 골라지는지 확인할 수 있습니다.
  </Step>
  <Step title="모델 선택하기">
    **모델 선택**을 클릭하고 제공업체를 고른 뒤 모델을 선택합니다.
  </Step>
</Steps>

매 답변 뒤에 다음 메시지를 제안받지 않으려면 **다음 메시지 제안** 옆의 스위치를 끄세요. **모두 자동으로 재설정**을 누르면 모든 작업이 다시 **자동**으로 돌아갑니다.

## 백업 모델로 대화 이어 가기

대체 기능은 사용량 한도에 도달하거나 로그인·키가 만료되거나 연결이 끊겨 현재 모델을 사용할 수 없을 때 답변이 멈추지 않게 해 줍니다. 다음 백업 모델로 답변을 이어 가며, 채팅에는 어떤 모델이 왜 대신 답했는지 표시됩니다.

<Steps>
  <Step title="대체 설정 열기">
    **설정 → AI 모델**을 열고 페이지 상단에서 **대체**를 클릭합니다.
  </Step>
  <Step title="백업 모델 추가하기">
    **백업 모델 추가**를 클릭하고 모델을 고릅니다. 최대 세 개까지 추가할 수 있으며 드래그해 순서를 바꿀 수 있습니다.
  </Step>
  <Step title="각 백업의 추론 강도 설정하기">
    추론 단계를 지원하는 모델이라면 **추론 강도**를 선택합니다. 각 백업 모델은 자신만의 설정을 유지합니다.
  </Step>
</Steps>

패널에는 현재 체인의 작동 상태가 표시됩니다: 맨 위에 **사용 중인 모델**, 그 아래로 번호가 매겨진 백업들이 각각 **준비됨** 또는 **일시 중지됨** 상태로 나타납니다. 백업의 모델 이름을 클릭하면 같은 제공업체의 다른 모델로 바꿀 수 있습니다. 제공업체 목록에서는 백업이 설정된 제공업체마다 체인에서의 순서를 나타내는 **backup N** 태그가 표시됩니다.

| 설정 | 기능 |
| --- | --- |
| **서비스가 혼잡할 때도 전환** | 재시도 횟수를 모두 소진한 뒤 요청 빈도 제한이나 서버 오류가 발생해도 전환합니다. |
| **모델을 다시 사용할 수 있으면 돌아가기** | 원래 모델이 복구되면 다음 턴부터 원래 채팅 모델로 돌아갑니다. 턴 중간에는 전환하지 않습니다. |

안전 정책에 의해 거부된 요청에서는 모델을 전환하지 않습니다.

## 두 모델 비교하기

두 모델에 작고 실제적인 작업을 똑같이 보내 보세요. 답이 정확한지, 도구가 끝까지 실행되었는지, 시간과 비용이 얼마나 들었는지 확인합니다. 각 답변 아래의 **세부 정보**에서 모델, 추론 강도, 토큰 수, 소요 시간, 포인트 또는 비용을 볼 수 있습니다.

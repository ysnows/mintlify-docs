Enconvo의 음성 기능마다 음성 모델 설정이 따로 있어, 받아쓰기에는 빠른 스트리밍 모델을, 긴 파일에는 다른 모델을 고를 수 있습니다. 실제로 쓰는 기능에서 모델을 고르세요.

| 기능 | 설정 위치 | 안내 |
| --- | --- | --- |
| 말로 입력하는 텍스트 | **설정 → 받아쓰기 모델** | [받아쓰기](/ko/features/dictation) |
| 음성 명령 | **설정 → 음성 명령 → 듣기** | [음성 명령](/ko/features/dictation) |
| Live Talk 통화 | **설정 → Live Talk → 듣기** | [Live Talk](/ko/features/live-voice) |
| 회의나 강의 녹음 | **설정 → 녹음 모델** | [회의 녹음](/ko/features/meeting-recording) |
| 기존 오디오나 동영상 파일 | **설정 → 음성 텍스트 변환 모델** | [음성 텍스트 변환](/ko/features/transcription) |
| 실시간 자막 | **설정 → 자막 모델** | [실시간 자막](/ko/features/live-captioning) |

## 모델 고르기

1. 위 표에서 해당 기능의 설정을 엽니다.
2. 받아쓰기, 녹음, 음성 텍스트 변환, 자막 모델 페이지에서는 **전체**, **Enconvo Cloud**, **로컬**, **사용자 지정 제공업체**로 목록을 거릅니다. 음성 명령과 Live Talk의 **듣기**는 추천 모델을 먼저 보여 준 뒤 다른 음성 모델을 보여 줍니다.
3. 모델을 고른 다음 언어와 모델 옵션을 확인하세요.

**Enconvo Cloud** 모델은 API 키 없이 Enconvo 계정을 씁니다. Enconvo Cloud의 자체 음성 인식인 **Enconvo Cloud Fast**는 누구나 무료이며 초록색 **무료** 태그가 붙습니다. **사용자 지정 제공업체**는 해당 제공업체의 본인 API 키를 씁니다. **로컬** 모델(MLX와 Core ML)은 모델을 받은 뒤 Mac에서 음성을 인식합니다.

[음성 제공업체 카탈로그](/ko/providers/catalog)에는 클라우드 서비스와 로컬 Parakeet, Qwen, Whisper, SenseVoice, Paraformer, Nemotron 변형을 포함해 선언된 모든 제공업체가 있습니다. 하드웨어와 제공 여부는 런타임과 빌드에 따라 다릅니다.

## 눈에 띄는 모델

| 모델 | 알아둘 점 |
| --- | --- |
| ElevenLabs Scribe v3 Live | 첫 단어를 1초 안에 스트리밍하고, 중국어와 소음이 있는 오디오에서 오류가 적습니다. ElevenLabs API 키 또는 Enconvo Cloud로 받아쓰기와 음성 입력에 쓰세요. 중국어와 일본어는 단어 사이 공백 없이 나옵니다. Live Talk가 ElevenLabs를 쓰면 Live Talk도 이를 씁니다. |
| ElevenLabs Scribe v3 | ElevenLabs API 키 또는 Enconvo Cloud로 파일을 받아씁니다. |
| Enconvo Cloud Fast | 무료입니다. 실시간 모델은 말하는 동안 단어를 보여 주고, 비동기 모델은 녹음 파일을 변환합니다. |
| Soniox | 받아쓰기, 녹음, 음성 텍스트 변환, 자막, Live Talk, 회의 자막에서 Soniox v6 모델을 씁니다. 이전에 고른 v5 모델은 자동으로 v6로 옮겨집니다. Soniox는 2026년 12월 15일에 v5를 종료합니다. |
| DeepSeek | 본인 DeepSeek API 키, 또는 키 없이 **DeepSeek (Enconvo Cloud)**로 음성 텍스트 변환과 받아쓰기를 합니다. 21개 언어를 스스로 감지합니다. |
| Fluid Speech Pro by FluidVoice | Mac과 iPhone에서 실행되며 25개 유럽 언어를 오프라인으로 변환합니다. Parakeet보다 오류가 적고, 말하는 동안 또는 끝난 뒤에 변환합니다. macOS 15 또는 iOS 18 이상이 필요합니다. |

## 작업에 모델 맞추기

| 능력 | 알아둘 점 |
| --- | --- |
| 스트리밍 | 말하는 동안 부분 텍스트를 만듭니다. 말하는 대로 단어가 보이게 하려면 실시간 모델을 쓰세요. |
| 일괄 변환 | 캡처나 업로드 뒤에 파일을 처리합니다. |
| 언어 힌트와 핫워드 | 제공업체가 지원하면 인식을 안내합니다. |
| 화자 분리 | 목소리를 나눕니다. 사람 이름이 맞다는 보장은 아닙니다. |
| 실시간 번역 | 일부 제공업체와 모델만 제공하며, 원본 언어와 대상 언어가 있습니다. |
| 타임스탬프와 구조화된 출력 | 제공업체와 음성 텍스트 변환 출력 형식에 따라 다릅니다. |

## 짧은 샘플로 시험하기

실제로 쓰는 언어, 마이크, 용어로 짧은 샘플을 녹음하고, 긴 회의를 처리하기 전에 검토하세요. 실패하면 오류에서 파일 크기, 형식, 추출, 계정, 네트워크 정보를 읽으세요.

로컬 모델 다운로드는 앱보다 훨씬 클 수 있습니다. 실제 다운로드 크기와 남은 공간을 확인하세요. 로컬 음성 모델이 모두 같은 용량을 필요로 하지는 않습니다.

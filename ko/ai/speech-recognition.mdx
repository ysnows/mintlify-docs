Enconvo의 음성 기능에는 각각 자체 음성 모델 설정이 있어서, 받아쓰기에는 빠른 스트리밍 모델을, 긴 파일에는 다른 모델을 고를 수 있습니다. 실제로 사용하는 기능에서 모델을 선택하세요.

| 기능 | 설정 위치 | 가이드 |
| --- | --- | --- |
| 음성을 텍스트로 입력 | **설정 → 받아쓰기 모델** | [받아쓰기](/ko/features/dictation) |
| 음성 명령 | **설정 → 음성 명령 → 듣기** | [음성 명령](/ko/features/dictation) |
| Live Talk 통화 | **설정 → Live Talk → 듣기** | [Live Talk](/ko/features/live-voice) |
| 회의나 강의 녹음 | **설정 → 녹음 모델** | [회의 녹음](/ko/features/meeting-recording) |
| 기존 오디오 또는 비디오 파일 | **설정 → 음성 텍스트 변환 모델** | [음성 텍스트 변환](/ko/features/transcription) |
| 실시간 자막 | **설정 → 자막 생성 모델** | [실시간 자막](/ko/features/live-captioning) |

## 모델 고르기

1. 위 표에서 사용할 기능의 설정을 엽니다.
2. 받아쓰기, 녹음, 음성 텍스트 변환, 자막 생성 모델 페이지에서는 **전체**, **Enconvo Cloud**, **로컬**, **사용자 지정 제공업체**로 목록을 필터링합니다. 음성 명령과 Live Talk의 **듣기**에서는 추천 모델이 먼저 표시되고, 그다음에 다른 음성 모델이 표시됩니다.
3. 모델을 고른 다음 언어와 모델 옵션을 확인합니다.

**Enconvo Cloud** 모델은 API 키 없이 내 Enconvo 계정을 사용합니다. Enconvo Cloud 자체 음성 인식인 **Enconvo Cloud Fast**는 모든 사람에게 무료이며 초록색 **무료** 태그가 표시됩니다. **사용자 지정 제공업체**는 해당 제공업체의 내 API 키를 사용합니다. **로컬** 모델(MLX와 Core ML)은 모델을 다운로드하면 내 Mac에서 음성을 인식합니다.

[음성 제공업체 카탈로그](/ko/providers/catalog)에는 클라우드 서비스와 로컬 Parakeet, Qwen, Whisper, SenseVoice, Paraformer, Nemotron 변형을 포함해 선언된 모든 제공업체가 나열되어 있습니다. 하드웨어와 사용 가능 여부는 런타임과 내 빌드에 따라 달라집니다.

## 주요 모델

| 모델 | 알아 둘 점 |
| --- | --- |
| ElevenLabs Scribe v3 Live | 1초 안에 첫 단어를 스트리밍하며 중국어와 잡음이 있는 오디오에서 오류가 적습니다. 내 ElevenLabs API 키나 Enconvo Cloud로 받아쓰기와 음성 입력에 사용하세요. 중국어와 일본어는 단어 사이에 공백 없이 출력됩니다. Live Talk가 ElevenLabs를 사용할 때는 Live Talk도 이 모델을 사용합니다. |
| ElevenLabs Scribe v3 | 내 ElevenLabs API 키나 Enconvo Cloud로 파일을 전사합니다. |
| Enconvo Cloud Fast | 무료입니다. 실시간 모델은 말하는 대로 내용을 보여 주고, 비동기 모델은 녹음된 파일을 전사합니다. |
| Soniox | 받아쓰기, 녹음, 음성 텍스트 변환, 자막 생성, Live Talk, 회의 자막에서 Soniox의 v6 모델을 사용합니다. 이전에 고른 v5 모델은 자동으로 v6으로 바뀌며, Soniox는 2026년 12월 15일에 v5를 종료합니다. |
| DeepSeek | 내 DeepSeek API 키 또는 키 없이 **DeepSeek (Enconvo Cloud)**로 음성 텍스트 변환과 받아쓰기를 처리합니다. 21개 언어를 자동으로 감지합니다. |
| FluidVoice의 Fluid Speech Pro | 내 Mac과 iPhone에서 실행되며 유럽 언어 25개를 오프라인으로 전사합니다. Parakeet보다 오류가 적고, 말하는 동안 실시간으로 또는 끝난 뒤에 처리합니다. macOS 15 또는 iOS 18 이상이 필요합니다. |

## 작업에 맞는 모델 고르기

| 기능 | 알아 둘 점 |
| --- | --- |
| 스트리밍 | 말하는 동안 부분 텍스트를 만들어 냅니다. 말하는 대로 단어가 나타나길 원하면 실시간 모델을 사용하세요. |
| 일괄 전사 | 녹음하거나 업로드한 뒤에 파일을 처리합니다. |
| 언어 힌트와 핫워드 | 제공업체가 지원하면 인식을 안내합니다. |
| 화자 분리 | 목소리를 구분합니다. 올바른 사람의 이름까지 보장하지는 않습니다. |
| 실시간 번역 | 일부 제공업체와 모델에서만 제공되며 원본 언어와 대상 언어를 지정합니다. |
| 타임스탬프와 구조화된 출력 | 제공업체와 전사 출력 형식에 따라 다릅니다. |

## 짧은 샘플로 테스트하기

긴 회의를 처리하기 전에 실제로 사용하는 언어, 마이크, 용어로 짧은 샘플을 녹음하고 결과를 검토하세요. 실패하면 오류에서 파일 크기, 형식, 추출, 계정, 네트워크에 관한 세부 정보를 읽어 보세요.

로컬 모델 다운로드는 앱보다 훨씬 클 수 있습니다. 실제 다운로드 크기와 여유 공간을 확인하세요. 로컬 음성 모델이 모두 같은 용량을 필요로 하지는 않습니다.

---

채팅에서 에이전트에게 이미지를 만들거나 첨부한 이미지를 수정해 달라고 요청하세요. Enconvo는 요청을 **설정 → 이미지 생성**에서 지정한 이미지 제공업체로 보내며, 이는 채팅에 사용하는 모델과 별개입니다.

## 시작하기 전에

1. **설정 → 이미지 생성**을 열고 제공업체를 선택합니다.
2. **자격 증명 제공자**(사용하는 키 또는 계정)와 **모델 이름**을 설정합니다.
3. **기본값으로 설정**을 클릭합니다.

Enconvo Cloud 제공업체인 **OpenAI (Enconvo Cloud)**와 **Google Gemini (Enconvo Cloud)**는 별도의 API 키가 필요 없습니다.

## 이미지 만들기

1. 에이전트와의 채팅에서 대상, 구도, 스타일, 이미지의 용도를 설명합니다.
2. 크기, 가로세로 비율, 품질은 모델이 지원할 때만 요청합니다.
3. 이미지가 만들어질 때까지 기다립니다. 생성에는 텍스트 답변보다 시간이 더 걸릴 수 있습니다.
4. 이미지를 클릭하면 채팅 옆에서 열리며, 계속 편집할 수 있습니다.

예시:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

새 채팅의 메시지 입력란 아래에서 **이미지**를 선택할 수도 있습니다. 모델, 모델 설정, **제외**가 메시지 입력란 아래에 알약 모양으로 표시되므로 보내기 전에 설정할 수 있습니다. 만든 모든 결과물, 저장한 대상, 원클릭 보정을 모아 둔 라이브러리는 [미디어](/ko/features/media)를 사용하세요.

## 이미지 편집

1. 메시지에 원본 이미지를 첨부하거나, 에이전트가 만든 이미지를 클릭하여 이미지 편집기에서 엽니다.
2. 구체적인 변경 사항을 설명하고, 그대로 유지할 부분을 알려 줍니다.
3. 요청하지 않은 변경이 없는지 결과를 확인합니다.

이미지 편집이나 참조 이미지를 지원하는 모델을 사용하세요.

이미지 편집기의 설정 패널에는 선택한 모델이 지원하는 항목만 표시됩니다.

| 설정 | 변경되는 내용 |
| --- | --- |
| 해상도, 가로세로 비율, 품질 | 다음 버전의 크기와 디테일 |
| **제외** | 네거티브 프롬프트를 지원하는 모델에서 제외할 내용 |
| 변형 | 요청마다 만들 결과물 수. 원하는 것만 남깁니다 |
| **편집 영역**과 **마크업** | 그림 위에 칠하여 그 부분만 바꾸거나, 그려서 변경을 안내합니다 |
| GIF와 **프레임** | 설명만으로 만든 애니메이션 그림 |

모든 편집은 새 버전이 되며, 모든 그림은 [미디어](/ko/features/media)와 `~/Enconvo/Media`에 보관됩니다. 그림을 애니메이션으로 만들려면 **동영상 만들기**를 클릭하세요.

### GPT Image 2.6

GPT Image 2.6 Flare와 Sunburst는 OpenAI, Enconvo Cloud, PipeLLM, OpenRouter를 통해 사용할 수 있습니다. 복잡도 설정(낮음, 중간, 높음), 직접 그린 마크업으로 안내하는 편집, SVG 또는 애니메이션 GIF 출력이 추가되었습니다. SVG와 GIF는 설명만으로 새 그림을 만들며, 현재 그림을 편집하지는 않습니다.

## 제공업체

[이미지 제공업체 카탈로그](/ko/providers/catalog)에는 OpenAI, Gemini, xAI, OpenRouter, PipeLLM, Pollinations, Kie.ai, Topview, Azure, Together와 제공되는 경우 Enconvo Cloud 버전이 포함됩니다. OpenAI 제공업체는 ChatGPT 로그인을 자격 증명으로 사용할 수도 있습니다. 제공업체가 할 수 있는 일은 모델에 따라 다르며, 제공업체 이름만으로 모든 편집 모드가 보장되지는 않습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 이미지가 생성되지 않음 | 제공업체의 액세스 권한과 모델을 확인한 다음 제공업체의 오류를 읽어 보세요 |
| 편집이 이미지를 무시함 | 모델이 이미지 입력을 지원하는지, 파일이 메시지에 첨부되었는지 확인하세요 |
| 입력 파일이 거부됨 | 제공업체가 해당 파일 형식을 지원하는지 확인하세요 |
| ChatGPT 로그인으로 GPT Image 2.6이 제공되지 않음 | OpenAI가 ChatGPT 플랜에는 제공하지 않습니다. OpenAI API 키 또는 Enconvo Cloud를 사용하세요 |
| 원하는 설정이 편집기에 없음 | 선택한 모델이 지원하지 않는 설정입니다. 다른 모델을 선택하세요 |

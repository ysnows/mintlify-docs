파일 도구를 사용하면 에이전트가 파일을 찾고, 파일 안을 검색하고, 읽고, 편집할 수 있습니다. 에이전트에게 폴더나 파일을 알려 주고 평소 쓰는 말로 요청하면, 알맞은 도구를 골라 사용하고 무엇을 썼는지 보여 줍니다.

## 시작하기 전에

- **작업 폴더:** 에이전트 설정의 **정의** 부분에 있는 **작업 폴더**가 상대 경로의 시작점입니다.
- **승인:** 채팅의 **권한** 칩이 에이전트가 언제 먼저 물어볼지 결정합니다. **승인 요청**을 선택하면 작업 폴더 밖의 파일을 편집하기 전에 물어봅니다. 읽기와 검색은 묻지 않습니다. [작업 승인](/ko/ai/agents)을 참고하세요.

## 읽기 전용 작업으로 시작하기

1. 에이전트 설정에서 파일 도구와 **작업 폴더**를 확인합니다.
2. 채팅에서 사용할 폴더를 지정하거나 파일을 첨부합니다.
3. "이 프로젝트에서 Markdown 파일을 찾아 README를 요약해 줘"처럼 범위가 정해진 질문을 합니다.
4. 무언가를 변경해 달라고 요청하기 전에, 에이전트가 사용한 파일과 도구 출력을 확인합니다.

## 각 도구의 기능

| 도구 | 기능 |
| --- | --- |
| Glob | `**/*.md` 같은 경로 패턴으로 파일을 최신순으로 찾습니다 |
| Grep | 파일 패턴과 줄 번호와 함께 파일 안의 텍스트를 검색합니다 |
| Read File | 텍스트 파일을 읽고, 문서에서 텍스트를 추출하고, 이미지, 오디오, 동영상을 읽습니다 |
| Edit File | 파일에서 정확히 일치하는 텍스트를 바꾸고 변경한 줄을 보고합니다 |
| Write File | 파일을 만들거나 내용 전체를 바꿉니다 |

<Warning>
Write File은 경고 없이 기존 파일을 덮어쓸 수 있습니다. 중요한 문서는 사본을 보관하거나 버전 관리를 사용하고, 승인하기 전에 대상과 변경 내용을 확인하세요. 에이전트가 채팅에서 변경한 파일은 사이드 패널의 **변경 사항** 탭에 **실행 취소**와 함께 나열됩니다.
</Warning>

## 문서와 미디어

PDF, Office 문서, 이미지, 오디오 파일, 동영상을 읽을 때는 원시 바이트를 반환하지 않고 구문 분석, OCR, 음성 변환이 실행될 수 있습니다. 오디오와 동영상은 에이전트가 전사본을 읽습니다. 스프레드시트에서는 수식 셀이 그 값으로 읽히며, 한 번도 계산되지 않은 경우에는 수식 자체로 읽힙니다. 어떤 형식이 작동하는지는 설치된 도구와 설정한 제공업체에 따라 다릅니다. [OCR](/ko/ai/ocr), [음성 텍스트 변환](/ko/features/transcription), [지식 베이스](/ko/ai/knowledge-base)를 참고하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 액세스 오류 | 에이전트의 **작업 폴더**, **권한** 칩, macOS 권한을 확인하세요 |
| 문서가 비어 있는 것으로 읽힘 | 파일 형식과 구문 분석이 가능한지 확인하세요. 스캔한 PDF에는 OCR이 필요할 수 있습니다 |
| 편집이 바꿔야 할 텍스트를 찾지 못함 | 에이전트에게 편집하기 전에 현재 파일을 다시 읽도록 요청하세요 |

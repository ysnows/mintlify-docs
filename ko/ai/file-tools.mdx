title: "파일과 폴더"
description: "에이전트가 Mac에 있는 파일을 찾고, 읽고, 편집하게 합니다."
---

파일 도구는 에이전트가 파일을 찾고, 안을 검색하고, 읽고, 편집하게 합니다. 폴더나 파일을 지정한 다음 평이한 말로 부탁하면, 에이전트가 맞는 도구를 고르고 어떤 도구를 썼는지 보여 줍니다.

## 시작하기 전에

- **작업 폴더:** 에이전트 설정의 **정의** 영역에 있는 **작업 폴더**가 상대 경로의 시작점입니다.
- **승인:** 채팅의 **권한** 칩이 에이전트가 먼저 물어보는지 결정합니다. **승인 요청**이면 작업 폴더 밖의 파일을 편집하기 전에 물어봅니다. 읽기와 검색은 물어보지 않습니다. [작업 승인](/ko/ai/agents)을 보세요.

## 읽기 전용 작업부터 시작

1. 에이전트 설정에서 파일 도구와 **작업 폴더**를 확인합니다.
2. 채팅에서 폴더를 지정하거나 쓸 파일을 첨부합니다.
3. “이 프로젝트의 Markdown 파일을 찾아 README를 요약해 줘.”처럼 범위가 분명한 질문을 합니다.
4. 뭔가를 바꾸기 전에, 에이전트가 사용한 파일과 도구 출력을 확인합니다.

## 도구별 할 일

| 도구 | 할 일 |
| --- | --- |
| Glob | `**/*.md` 같은 경로 패턴으로 파일을 찾습니다. 최신 파일이 먼저 나옵니다 |
| Grep | 파일 안의 텍스트를 검색합니다. 파일 패턴과 줄 번호를 함께 보여 줍니다 |
| Read File | 텍스트 파일을 읽고, 문서에서 텍스트를 뽑어내며, 이미지·오디오·동영상을 읽습니다 |
| Edit File | 파일의 정확한 텍스트를 바꾸고 바뀐 줄을 보고합니다 |
| Write File | 파일을 만들거나 내용 전체를 바꿉니다 |

<Warning>
Write File은 경고 없이 기존 파일을 덮어쓸 수 있습니다. 중요한 문서는 복사본을 남거나 버전 관리를 쓰고, 승인하기 전에 대상과 변경을 확인하세요. 채팅에서 에이전트가 바꾼 파일은 사이드 패널의 **변경 사항** 탭에 **실행 취소**와 함께 나열됩니다.
</Warning>

## 문서와 미디어

PDF, Office 문서, 이미지, 오디오, 동영상을 읽으면 원본 바이트를 그대로 돌려주는 대신 구문 분석, OCR, 음성 텍스트 변환이 실행될 수 있습니다. 오디오와 동영상은 트랜스크립트를 읽습니다. 스프레드시트에서 수식 셀은 계산된 값으로 읽히고, 한 번도 계산되지 않았으면 수식 자체로 읽힙니다. 어떤 형식이 되는지는 설치된 도구와 설정한 제공업체에 따릅니다. [OCR](/ko/ai/ocr), [음성 텍스트 변환](/ko/features/transcription), [지식 베이스](/ko/ai/knowledge-base)를 보세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 액세스 오류 | 에이전트의 **작업 폴더**, **권한** 칩, macOS 권한을 확인합니다 |
| 문서가 비어 있음 | 파일 형식과 구문 분석 가능 여부를 확인합니다. 스캔한 PDF는 OCR이 필요할 수 있습니다 |
| 편집이 바꿀 텍스트를 찾지 못함 | 편집하기 전에 현재 파일을 다시 읽도록 에이전트에게 부탁합니다 |

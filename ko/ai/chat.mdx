채팅 창은 이어지는 대화를 위한 Enconvo의 주요 공간입니다. 답변 한 번으로 끝나지 않는 작업에 사용하세요. 에이전트를 고르고, 필요한 자료를 추가하고, 관련된 채팅을 한곳에 모아 둘 수 있습니다. **⌃⌘X**를 눌러 여세요.

다른 용도에는 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 앱 하나 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에는 [PopBar](/ko/features/popbar), 화면에 계속 떠 있는 작은 진입점으로는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 사용하세요. [창 관리](/ko/features/window-management)에서 모두 비교해 볼 수 있습니다.

아래 영상은 채팅 창을 2분 동안 둘러봅니다. 에이전트 고르기, 채팅 하나의 모델과 권한 바꾸기, 파일 추가, 만들 결과물 고르기, 질문과 후속 질문, 채팅 다시 찾기를 보여 줍니다.

## 대화 시작하기

1. **⌃⌘X**를 누르거나 Enconvo에서 **채팅 창**을 여세요. 새 채팅은 **새 채팅**(**⌘N**)을 클릭하세요. 새 채팅은 마지막으로 선택한 프로젝트에서 시작되며, 일반 채팅은 프로젝트 선택기에서 **프로젝트 없음**을 고르세요.
2. 누가 답할지 고르세요. 입력란 위의 에이전트 카드나 채팅 상단의 에이전트 이름을 클릭하세요. Mavis가 기본이며, 카드에는 Writer, Researcher 같은 에이전트와 Codex, Claude Code 같은 코딩 에이전트도 있습니다.
3. 입력란 아래의 칩을 확인하세요. 모델 칩은 이 채팅의 모델을 보여 주며, 클릭하면 이 채팅에 한해 바꿀 수 있습니다. 방패 칩은 에이전트가 실행 전에 확인을 구하는 시점을 정합니다. **대신 승인**은 위험한 단계 전에만 묻습니다.
4. **+**를 클릭해 파일, 이미지, 스크린샷을 추가하세요. 특정 결과물을 만들려면 입력란 아래의 **만들기** 행에서 종류를 고르세요. **슬라이드**, **문서**, **디자인**, **움직임**, **대시보드**, **웹 페이지**, **이미지**, **동영상**이 있습니다. 프로젝트 안의 새 채팅에도 이 행이 있습니다. [아티팩트](/ko/features/artifacts)를 참고하세요.
5. 요청을 입력하고 Return을 누르세요. 답변이 채팅에 실시간으로 표시되며, 에이전트가 도구를 사용하면 답변에서 진행 상황을 볼 수 있습니다.
6. 같은 채팅에서 후속 질문을 하세요. 대화를 기억하므로 “하루짜리 버전으로 만들어 줘” 같은 짧은 요청이면 충분합니다.

페어링한 다른 컴퓨터에서 채팅을 시작하려면 메시지 상자의 **실행 위치** 칩에서 컴퓨터를 고르세요. 입력해 둔 내용도 함께 옮겨집니다. [다른 컴퓨터](/ko/integrations/other-computers)를 참고하세요.

완성된 결과를 요청하세요. “첨부한 제안서를 다섯 개의 글머리 기호로 요약하고 남은 질문을 나열해 줘”라고 하면 에이전트가 무엇을 읽고 무엇을 돌려줘야 하는지 모두 알 수 있습니다.

나중에 채팅의 헤더에 있는 에이전트 이름에서 채팅의 에이전트를 바꿀 수 있으며, SmartBar와 앱 사이드바에도 같은 선택기가 있습니다. 대화를 [코딩 에이전트](/ko/ai/coding-agents)에게 넘기려면 그 에이전트와 새 채팅에서 이어가세요. 채팅을 분기하면 이어갈 에이전트를 고릅니다.

### 보내기 전에 요청 다듬기

요청을 입력하면 마이크 옆의 요술봉(**프롬프트 개선**)을 클릭하세요. 채팅의 모델이 지금까지의 대화를 바탕으로 요청을 더 명확하고 충실하게 다시 쓰며, 나만 아는 세부 사항은 `[placeholders]`로 남겨 둡니다. 원래 문장으로 돌아가려면 **실행 취소**(또는 **⌘Z**)를 클릭하고, 다른 버전을 원하면 **다시 시도**를 클릭하세요.

메시지 상자는 다른 채팅을 보는 동안에도 각 채팅의 보내지 않은 텍스트와 첨부 파일을 유지하므로, 돌아오면 작성하던 내용이 그대로 있습니다. 이전 메시지를 편집하면 그 메시지의 이미지와 파일도 텍스트와 함께 메시지 상자로 돌아오므로, 보내기 전에 하나를 제거하거나 다른 것을 추가할 수 있습니다.

### Vim 키로 편집하기

**설정 → 일반**의 **키보드** 아래에서 **Vim 모드**를 켜거나, 메시지 상자에 `/vim`을 입력하세요. 마이크 옆의 칩이 현재 모드를 표시하며 Normal과 Visual 모드에서는 파란색으로 바뀝니다. 이 모드들은 영어 키보드 배열로 입력하고, Insert 모드는 사용 중이던 입력 소스로 되돌립니다.

## 에이전트가 작업하는 동안 말 걸기

긴 작업이 끝나기를 기다릴 필요는 없습니다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 실행 중인 작업에 내용 추가 | 입력하고 Return을 누르세요. 입력하거나 첨부하면 **중지** 버튼이 다시 **보내기**로 바뀝니다. 에이전트는 다음 단계에서 메시지를 읽습니다. |
| 작업이 끝났을 때 보낼 메시지 대기열에 넣기 | **⌘Return**을 누르거나, **⌘**를 누른 채 **보내기**를 클릭하세요. |
| 작업 중지 | **중지**를 클릭하거나 **ESC**를 두 번 누르세요. 실수로 한 번 눌러서는 끝나지 않습니다. |

에이전트는 Enconvo가 내 메시지로 방향을 바꿔야 하는지 확인하는 동안에도 계속 쓰고 도구를 실행하므로, 기다려도 되는 후속 메시지가 현재 단계를 버리게 만들지 않습니다. 작업과 관련 없는 요청은 에이전트가 계속 일하는 동안 백그라운드에서 작업하는 하위 에이전트에게 전달됩니다.

로그인, 설치, 질문 카드는 채팅을 막지 않습니다. 카드에 답하지 않고 메시지를 보내면 채팅이 계속 진행됩니다.

모델이 생각하는 동안 답변에 **생각 중…**과 지금까지 걸린 시간이 표시됩니다.

작업이 끝나면 에이전트의 요약은 결과로 시작해서, 바뀐 내용, 확인한 내용, 주의가 필요한 내용을 차례로 나열합니다.

## 목표 설정하기

에이전트에게 최종 상태를 알려 주면, 점검에서 목표가 달성된 것으로 확인될 때까지 계속 턴을 이어가며 작업합니다.

1. `/goal` 다음에 작업이 끝났을 때 참이어야 할 내용을 입력하거나, **+** 메뉴에서 **목표 설정**을 선택하세요.
2. 보내세요. 목표가 경과 시간과 함께 메시지 상자 위에 표시됩니다.
3. 목표 막대에서 목표를 편집하거나, 지우거나, 다시 시작하세요. 목표가 진행 중일 때는 **+** 메뉴에 **목표 편집**이 나타납니다.

## 임시 채팅 사용하기

보관하고 싶지 않은 일회성 질문은 새 채팅에서 점선 말풍선 스위치(**임시 채팅**)를 켜세요. 앱 사이드바와 Dynamic Island에도 같은 스위치가 있습니다. 켜져 있는 동안 스위치는 파란색이고, 메시지 상자에는 점선 테두리와 **임시 채팅** 태그가 표시됩니다.

임시 채팅은 채팅 기록에 남지 않고, [메모리](/ko/ai/memory)를 저장하지 않으며, 떠나면 삭제됩니다. 그래도 보관하려면 배너의 **채팅 보관하기**를 클릭하세요. 일반 채팅이 됩니다.

## 답변 모양 고르기

각 에이전트에는 기본 응답 스타일과 Intelligent UI 수준이 있으며, 이는 차트, 표, 카드로 얼마나 쉽게 답할지를 정합니다. 채팅 하나에 대해 바꾸려면 **+** 메뉴를 열고 **스타일 사용**을 선택하세요. **보통** 같은 스타일이나 Intelligent UI 수준을 고르고, 그 에이전트의 모든 채팅에 기본값으로 쓰려면 **모두에 사용**을 선택하세요. 스타일과 수준은 [에이전트](/ko/ai/agents)를 참고하세요.

답변 속 링크는 사이트 아이콘이 있는 카드로 표시됩니다. 지도 링크는 장소 이름이 있는 실제 지도를 보여 주고, 여러 장소는 번호가 매겨진 지도 하나를 공유하며, 경로는 소요 시간과 거리가 있는 선으로 표시됩니다. [시각적 답변](/ko/features/visual-answers)을 참고하세요.

## 둘러보기

사이드바는 왼쪽의 얇은 아이콘 레일과 그 옆의 가운데 열로 구성됩니다.

- 레일은 확인이 필요한 채팅 수를 주황색으로 표시하는 **채팅**으로 시작하고, 이어서 **예약됨**, **지식 베이스**, **플러그인**이 있습니다. **보드**, **아티팩트**, **미디어**와 다른 장소는 **···** 메뉴에 있습니다. 플러그인은 구분선 아래에 있고, 기기 전환기와 설정 메뉴는 맨 아래에 있습니다. 설정 메뉴에는 도움말 링크, **새로운 기능**, **사이드바 바로가기**도 있습니다.
- 레일에서 장소를 고르면 가운데 열에 해당 장소의 섹션, 필터, 주요 동작이 표시됩니다. **채팅**은 마지막으로 보던 위치로 돌아옵니다. 스킬과 MCP 서버는 **플러그인**에서 바로 창 안에 열립니다.
- **⌥⌘1**부터 **⌥⌘9**까지 눌러 레일에 표시된 순서대로 열 수 있습니다. **⌘B**는 가운데 열을 숨기고 레일은 유지합니다.
- **뒤로**와 **앞으로**는 방문한 장소와 각 장소에서 고른 섹션을 기억합니다. **뒤로**를 길게 누르면 목록이 표시됩니다.

### 사이드바 사용자화

**···** 메뉴를 열거나 레일의 아이콘을 오른쪽 클릭하고 **사이드바 사용자화…**를 선택하세요. 레일에 표시할 장소를 고르고 원하는 순서로 드래그하세요. 플러그인을 구분선 위로 드래그하면 장소들 사이에 놓이고, 아래로 다시 드래그하면 되돌아갑니다. 장소나 플러그인은 고정하거나 고정 해제할 수 있습니다.

### 빠른 접근

가장 자주 여는 페이지, 프로젝트, 링크를 사이드바에 고정하세요. 사이드바 맨 아래의 설정 메뉴를 열고 **사이드바 바로가기**를 선택해 항목을 추가하세요. 항목은 **빠른 접근** 그룹에 표시되며, 드래그해 순서를 바꾸거나, 이름을 바꾸거나, 제거할 수 있습니다.

### 기기 전환기

사이드바에는 한 번에 컴퓨터 한 대가 표시됩니다. 맨 아래의 기기 전환기는 이 컴퓨터와 페어링한 컴퓨터 사이를 이동하고, 다른 컴퓨터에서 대기 중인 항목을 보여 주며, 각 컴퓨터를 별도의 창에서 엽니다. **관리**는 **기기** 제목 옆에 있고, **기기 추가**는 컴퓨터를 페어링하거나, SSH 호스트를 추가하거나, 휴대폰을 페어링합니다. [다른 컴퓨터](/ko/integrations/other-computers), [휴대폰 페어링](/ko/integrations/pair-your-phone), [컴퓨터와 SSH 호스트](/ko/integrations/computers-and-ssh-hosts)를 참고하세요.

업데이트 후 Enconvo를 처음 사용하면 사이드바의 카드가 해당 버전의 업데이트 영상을 안내합니다. 설정 메뉴의 **새로운 기능**은 모든 영상을 **설정 → 튜토리얼**에서 엽니다.

### 아티팩트

**···** 메뉴의 **아티팩트**는 에이전트가 만든 페이지, 문서, 디자인을 나열합니다. 카드나 행을 오른쪽 클릭해 **열기**, **이름 변경**, **링크 복사**, 만들어진 채팅 열기, **삭제**를 할 수 있습니다. **⌘** 클릭이나 **⇧** 클릭으로 여러 개를 골라 한 번에 삭제할 수 있으며 **실행 취소**도 가능합니다. 아무것도 쓰지 않은 빈 아티팩트는 나열되지 않습니다.

페이지 아티팩트를 공유하려면 **게시**를 클릭하세요. Enconvo Cloud에서 내 `name.site.enconvo.com` 링크로 온라인에 게시되며, 선택적으로 암호를 설정할 수 있습니다. 에이전트에게 페이지나 사이트 폴더를 대신 게시해 달라고 요청할 수도 있습니다.

## 채팅 정리하기

사이드바에는 최근 채팅이 나열되고, 프로젝트를 사용할 수 있는 곳에서는 프로젝트가 관련 채팅을 함께 보관합니다. 모든 채팅은 저장됩니다. 사이드바의 **검색**(**⌘G**)을 클릭해 나눈 이야기로 채팅을 찾으세요. 채팅의 메뉴를 열어 **채팅 이름 변경**, **채팅 고정**, **프로젝트로 이동**, **채팅 보관**, **채팅 삭제**를 할 수 있습니다. 채팅 기록을 삭제하기 전에 확인 메시지를 읽어 보세요.

- 맨 위의 **활성**은 아직 확인이 필요하거나, 실행 중이거나, 아직 열어 보지 않은 결과나 실패가 있는 채팅만 모아 프로젝트와 상태와 함께 보여 줍니다. 행은 채팅 목록과 같은 방식으로 동작합니다. 마우스를 올리면 **고정**과 **보관**이 나타나고, 오른쪽 클릭으로 메뉴를 열고, 더블클릭으로 이름을 바꾸고, 트랙패드에서 쓸어 넘겨 보관할 수 있습니다. 그룹에 마우스를 올리면 **모두 읽음으로 표시**를 사용할 수 있습니다.
- 목록 맨 아래의 **iPhone 채팅**에는 iPhone이나 Android 휴대폰에서 시작한 채팅이 있습니다. Mac에서 이어갈 수 있으며, 하나를 삭제하면 양쪽에서 삭제됩니다. [휴대폰 채팅](/ko/integrations/iphone-phone-chats)을 참고하세요.
- 에이전트가 Codex, Claude Code 또는 다른 에이전트에게 도움을 요청하며 시작하는 채팅은 목록에 나타나지 않습니다. 요청한 채팅에 있는 해당 줄에서 여세요. 열려 있거나, 고정되어 있거나, 내 답변을 기다리는 동안에는 행이 표시됩니다.
- 각 [예약 작업](/ko/workflows/scheduled-jobs)의 최근 실행은 시작되자마자 시계 표시와 함께 목록에 나타납니다.
- **고정됨** 그룹은 접을 수 있으며, 워크트리의 행도 마찬가지입니다.
- 채팅의 보라색 스피너는 답변은 끝났지만 그 채팅이 시작한 하위 에이전트나 백그라운드 작업이 아직 실행 중이라는 뜻입니다. 그 안의 파란색 점은 읽지 않은 새 답변이 있다는 뜻입니다.

### 여러 채팅에 한꺼번에 작업하기

1. **⌘** 클릭, **Shift** 클릭 또는 행의 **선택**으로 채팅을 고르세요. **⌘A**는 그룹 전체를 선택합니다.
2. 나타나는 막대로 읽음으로 표시(**⇧⌘U**), 보관(**E**), 삭제(**⌫**)를 할 수 있습니다.

삭제하기 전에 먼저 묻고, 채팅을 나열하고, 아직 실행 중인 채팅을 중지하며, **대신 보관**을 제안합니다. 읽음 표시와 보관은 실행 취소할 수 있습니다.

### 모델 선택

최상위 **새 채팅**은 에이전트의 기본 모델을 설정할 수 있습니다. 프로젝트 안의 새 채팅은 그 프로젝트의 모델 설정을 사용합니다. 각 채팅은 자신만의 모델과 추론 재정의를 유지할 수 있습니다. 다른 채팅이 쓰는 기본값을 바꾸기 전에 [모델 선택](/ko/ai/model-selection-guide)을 읽어 보세요.

채팅의 모델이 Enconvo Cloud 포인트를 모두 소진하면, 채팅을 Enconvo Cloud 외부의 모델로 바꾸고 포인트 소진 카드의 **다음으로 다시 시도**를 클릭해 그 모델로 메시지를 다시 실행하세요. 채팅이 스스로 대체 모델로 전환되게 하려면 **설정 → AI 모델**에서 **대체**를 설정하세요. [대체 모델로 채팅 이어가기](/ko/ai/model-selection-guide)를 참고하세요.

### 워크트리에서 작업하기

git 저장소인 프로젝트에서는 채팅이 메인 체크아웃과 워크트리 사이를 오갈 수 있습니다. 채팅 제목 뒤의 칩을 사용하거나 에이전트에게 요청하세요. 채팅은 변경한 파일과 함께 이동하며, 워크트리를 병합하면 메인 체크아웃으로 돌아옵니다. 이동할 때마다 대화에 한 줄이 추가됩니다. [프로젝트](/ko/ai/projects)를 참고하세요.

## 컨텍스트와 파일 추가하기

요청에 필요한 소스만 추가하세요. 파일 첨부, 화면 캡처, 지식 베이스 조회, 브라우저 페이지는 각각 에이전트에게 다른 종류의 컨텍스트를 제공합니다. 소스를 고르려면 [컨텍스트 인식](/ko/features/context-awareness)을, 에이전트가 내 파일로 할 수 있는 일은 [파일과 폴더](/ko/ai/file-tools)를 참고하세요.

- 메시지 상자에는 **권한** 뒤에 **실시간 화면**과 [화면 낙서](/ko/features/screen-doodle) 버튼이 있습니다. 실시간 화면은 켠 창에만 적용되며, 칩이 켜져 있음을 표시하고 클릭하면 꺼집니다.
- `@`를 입력해 파일, 에이전트, 친구와 팀원을 멘션하세요. 사람을 지정하면 에이전트가 누구를 가리키는지 알기 때문에, 요청에 따라 그 사람에게 비공개로 메시지를 보내거나, 답장을 읽거나, 전화를 걸 수 있습니다.
- 큰 비디오나 오디오 파일은 대본이나 메모로 모델에 전달됩니다. 폴더나 빈 파일은 첨부할 수 없습니다.

[메모리](/ko/ai/memory)와 [지식 베이스](/ko/ai/knowledge-base)는 하는 일이 다릅니다. 메모리는 에이전트가 다시 쓰는 사실을 보관하고, 지식 베이스는 에이전트가 찾아볼 자료를 저장합니다. 둘 다 사이드바 레일의 **지식 베이스**에서 열리며, 열 맨 위에 **지식 베이스** / **메모리** 스위치가 있습니다.

## 답변 읽고 다시 활용하기

답변의 작업 세부 정보를 펼치면 각 도구 호출과 결과를 볼 수 있습니다. 답변 아래의 **복사**, **소리 내어 읽기**, **더 보기**는 해당 답변에 대해 동작합니다. [시각적 답변](/ko/features/visual-answers)은 다이어그램과 인터랙티브 콘텐츠를 답변 안에 바로 넣을 수 있습니다.

코드 블록에는 **복사**와 줄바꿈 버튼이 있어, 긴 줄을 옆으로 스크롤하는 대신 줄바꿈할 수 있습니다. 모든 답변에서 코드를 줄바꿈하려면 **설정 → 일반**의 **모양**에서 **코드 줄바꿈**을 켜세요.

채팅을 링크로 공유하면 채팅이 업로드되는 동안에도 링크를 바로 복사할 수 있습니다. 나중에 **링크 업데이트**는 바뀐 내용만 보냅니다.

에이전트가 열어 주는 페이지와 파일은 채팅 옆의 사이드 패널에 표시됩니다. 각 채팅은 패널을 마지막으로 둔 상태 그대로 열거나 닫아 둡니다. 패널을 한 번도 열지 않은 채팅은 패널의 도구를 제공하는 **새로 만들기** 탭에서 시작합니다. 탭은 드래그해 정한 너비를 공유하며, 마지막 탭을 닫으면 패널이 닫힙니다.

| 탭 | 단축키 | 표시되는 내용 |
| --- | --- | --- |
| **풀 리퀘스트** | **⌃⇧P** | GitHub 저장소에서 작업 중인 채팅에서: 점검, 리뷰, 댓글이 있는 브랜치의 풀 리퀘스트, 또는 워크트리 채팅에서 풀 리퀘스트 만들기. |
| **기기** | **⌃⇧M** | 한 번 설정하면 채팅 옆에서 보고 제어할 수 있는 iOS 시뮬레이터나 Android 에뮬레이터. |

타이핑 대신 말하려면 [받아쓰기](/ko/features/dictation)로 음성으로 작성하거나, [Live Talk](/ko/features/live-voice)로 음성 양방향 대화를 하세요.

## Enconvo가 다시 시작될 때

업데이트, 종료, 충돌로 작업 도중에 채팅이 멈추면, Enconvo가 다시 돌아온 뒤 채팅이 스스로 이어집니다. 이미 한 일을 확인한 다음 나머지를 하고, 실행 중이던 하위 에이전트를 복원합니다.

## 설정

**설정 → 채팅 창**을 여세요.

| 설정 | 바뀌는 내용 |
| --- | --- |
| **기본 에이전트** | 채팅 창의 새 채팅이 시작할 때 사용하는 에이전트입니다. 그 에이전트를 삭제하면 새 채팅은 Mavis로 돌아갑니다. |
| **모양** | **라이트**, **다크**, **앱 따르기**입니다. |
| **단축키** | 어떤 앱에서든 채팅 창을 엽니다. 기본값은 **⌃⌘X**입니다. 다른 창의 **채팅 창에서 열기** 버튼에는 지정한 키가 표시됩니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변이 잘못된 모델을 사용합니다 | 에이전트의 기본값뿐 아니라 이 채팅의 모델 선택도 확인하세요. |
| 채팅에 다른 모델이 대신했다고 표시됩니다 | 채팅의 모델을 사용할 수 없는 동안 **설정 → AI 모델**의 대체 모델이 답했습니다. 모델이 다시 작동하면 채팅은 원래 모델로 돌아갑니다. |
| 에이전트가 파일이나 화면을 볼 수 없습니다 | 채팅의 첨부 파일과 [권한](/ko/configuration/permissions)을 확인하세요. |
| 도구를 사용할 수 없습니다 | 같은 요청을 말만 바꿔 반복하지 말고, 에이전트 설정의 **도구 및 스킬**을 확인하세요. [에이전트](/ko/ai/agents)를 참고하세요. |
| 찾는 채팅이 목록에 없습니다 | **활성**과 **iPhone 채팅**, 또는 **검색**(**⌘G**)을 확인하세요. 에이전트가 스스로 시작하는 채팅은 요청한 채팅에서 열립니다. |
| 채팅에 **이 채팅을 표시할 수 없습니다**가 표시됩니다 | **채팅 다시 불러오기**를 클릭하세요. 그동안 채팅 목록과 메시지 상자는 계속 작동합니다. |

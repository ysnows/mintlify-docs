채팅 창은 연속적인 대화를 나누는 Enconvo의 기본 공간입니다. 한 번 이상의 답변이 필요한 작업일 때 사용하세요. 에이전트를 고르고 필요한 자료를 추가하며 관련 채팅을 한데 모아 관리할 수 있습니다. **⌃⌘X**를 눌러 열 수 있습니다.

다른 작업에는 상황에 맞는 창을 쓰세요. 빠른 질문이나 명령은 [SmartBar](/ko/features/smartbar), 특정 앱 옆에서 작업할 때는 [앱 사이드바](/ko/features/app-sidebar), 선택한 텍스트에 바로 실행할 때는 [PopBar](/ko/features/popbar), 화면에 작게 띄워 두고 쓸 때는 [Dynamic Island](/ko/features/dynamic-island)와 [데스크톱 펫](/ko/features/pet)을 사용할 수 있습니다. 전체 비교는 [창 관리](/ko/features/window-management)를 참고하세요.

아래 2분짜리 동영상에서 채팅 창의 핵심 기능을 둘러볼 수 있습니다. 에이전트 선택, 채팅별 모델과 권한 전환, 파일 추가, 제작 항목 선택, 질문과 후속 요청, 이전 채팅 다시 찾기까지 순서대로 살펴봅니다.

## 대화 시작하기

1. **⌃⌘X**를 누르거나 Enconvo에서 **채팅 창**을 엽니다. 새 대화를 시작하려면 **새 채팅**(**⌘N**)을 클릭하세요. 마지막으로 선택했던 프로젝트에서 시작되며, 일반 채팅으로 시작하려면 프로젝트 선택기에서 **프로젝트 없음**을 선택하세요.
2. 답변할 대상을 선택합니다. 입력창 위의 에이전트 카드나 채팅 상단의 에이전트 이름을 클릭하세요. 기본값은 Mavis이며, 카드에는 Writer와 Researcher 같은 에이전트는 물론 Codex와 Claude Code 같은 코딩 에이전트도 있습니다.
3. 입력창 아래의 칩을 확인합니다. 모델 칩은 이 채팅에 쓰이는 모델을 보여 주며 클릭해 이 채팅에만 다른 모델을 고를 수 있습니다. 방패 칩은 에이전트가 행동하기 전에 사용자에게 확인할 기준을 정합니다. **자동 승인**은 위험한 단계 전에만 묻습니다.
4. **+**를 클릭해 파일, 이미지 또는 스크린샷을 추가하세요. 특정 결과물을 만들려면 입력창 아래 **만들기** 행에서 **슬라이드**, **문서**, **디자인**, **모션**, **대시보드**, **웹 페이지**, **이미지** 또는 **동영상**을 선택하세요. 프로젝트 안에서 시작한 새 채팅에도 이 행이 나타납니다([아티팩트](/ko/features/artifacts) 참고).
5. 요청을 입력하고 Return 키를 누릅니다. 답변이 채팅에 실시간으로 스트리밍되며, 에이전트가 도구를 사용하면 답변 속에서 진행 상황을 따라갈 수 있습니다.
6. 같은 채팅에서 후속 요청을 이어 가세요. 대화 맥락을 기억하므로 "하루짜리 일정으로 줄여 줘"처럼 짧게 말해도 충분합니다.

페어링된 다른 컴퓨터에서 채팅을 시작하려면 메시지 상자의 **실행 위치** 칩에서 해당 컴퓨터를 선택하세요. 입력한 내용도 함께 전달됩니다([다른 컴퓨터](/ko/integrations/other-computers) 참고).

원하는 결과물 전체를 구체적으로 요청하세요. "첨부한 제안서를 다섯 개의 글머리 기호로 요약하고 미해결 질문을 정리해 줘"라고 하면 에이전트가 무엇을 읽고 무엇을 반환해야 하는지 명확히 알 수 있습니다.

채팅 상단 헤더의 에이전트 이름을 눌러 나중에 채팅의 에이전트를 바꿀 수도 있습니다. SmartBar와 앱 사이드바에도 같은 선택기가 있습니다. 대화를 [코딩 에이전트](/ko/ai/coding-agents)에게 넘기려면 해당 에이전트로 새 채팅을 열어 이어 가세요. 채팅을 분기(fork)할 때는 이어 갈 에이전트를 직접 선택할 수 있습니다.

### 보내기 전에 요청 다듬기

요청을 입력한 뒤 마이크 옆의 마술봉 아이콘(**프롬프트 향상**)을 클릭하세요. 채팅에 설정된 모델이 지금까지의 대화 내용을 바탕으로 요청을 더 명확하고 구체적으로 다시 작성하며, 사용자만 아는 세부 정보 자리는 `[placeholders]`로 남겨 둡니다. **실행 취소**를 클릭하거나 **⌘Z**를 누르면 원래 문구로 돌아가고, **다시 시도**를 누르면 다른 버전으로 다시 작성합니다.

다른 채팅을 보고 와도 메시지 상자는 각 채팅에 입력하던 미전송 텍스트와 첨부 파일을 그대로 보관하므로 돌아왔을 때 초안이 유지됩니다. 이전 메시지를 수정하면 그 메시지에 있던 이미지와 파일도 텍스트와 함께 메시지 상자로 돌아오므로 보내기 전에 첨부를 빼거나 더할 수 있습니다.

### Vim 키로 편집하기

**설정 → 일반**의 **키보드** 아래에서 **Vim 모드**를 켜거나 메시지 상자에 `/vim`을 입력하세요. 마이크 옆 칩에 현재 모드가 표시되며 Normal 및 Visual 모드에서는 파란색으로 바뀝니다. 이 두 모드에서는 영어 키보드 레이아웃으로 입력되고, Insert 모드로 전환하면 사용 중이던 입력 소스로 돌아갑니다.

## 작업 중인 에이전트에게 말 걸기

긴 작업이 끝날 때까지 기다릴 필요가 없습니다.

| 하려는 작업 | 방법 |
| --- | --- |
| 실행 중인 작업에 내용 추가하기 | 입력한 뒤 Return을 누르세요. 텍스트를 입력하거나 파일을 첨부하면 **중지** 버튼이 다시 **보내기**로 바뀝니다. 에이전트는 다음 단계에서 메시지를 읽습니다. |
| 작업이 끝난 뒤 실행할 메시지 대기열에 넣기 | **⌘Return**을 누르거나 **⌘**를 누른 채 **보내기**를 클릭하세요. |
| 작업 중지하기 | **중지**를 클릭하거나 **Esc**를 두 번 누르세요. 한 번 잘못 눌러도 중단되지 않습니다. |

Enconvo가 새 메시지로 방향을 바꿀지 판단하는 동안에도 에이전트는 기존 작성과 도구 실행을 멈추지 않으므로, 기다릴 수 있는 후속 요청 때문에 현재 단계가 버려지지 않습니다. 진행 중인 작업과 무관한 요청은 백그라운드 하위 에이전트로 넘겨져 본 에이전트가 작업을 이어 가는 동안 따로 처리됩니다.

로그인, 설치 또는 질문 카드가 채팅을 막지 않습니다. 카드에 답하지 않고 메시지를 보내면 채팅은 그대로 계속됩니다.

모델이 생각하는 동안 답변 영역에는 **생각 중…**과 지금까지 걸린 시간이 표시됩니다.

작업이 끝나면 에이전트 요약은 먼저 결과를 알린 뒤, 변경된 내용, 확인된 내용, 사용자의 확인이 필요한 사항을 차례로 정리해 줍니다.

## 목표 설정하기

에이전트에게 최종 목표 상태를 지정하면 확인 결과 목표가 달성될 때까지 턴을 거듭하며 계속 작업합니다.

1. `/goal` 뒤에 작업이 끝났을 때 충족되어야 할 조건을 입력하거나, **+** 메뉴에서 **목표 설정**을 선택하세요.
2. 전송합니다. 메시지 상자 위에 목표와 경과 시간이 표시됩니다.
3. 목표 막대에서 목표를 수정, 지우기 또는 재개할 수 있습니다. 목표가 활성화되어 있는 동안에는 **+** 메뉴에 **목표 편집**이 표시됩니다.

## 임시 채팅 사용하기

기록을 남기고 싶지 않은 일회성 질문에는 새 채팅에서 점선 말풍선 스위치(**임시 채팅**)를 켜세요. 앱 사이드바와 Dynamic Island에도 같은 스위치가 있습니다. 켜져 있는 동안 스위치는 파란색이 되고 메시지 상자는 점선 테두리와 함께 **임시 채팅** 태그가 표시됩니다.

임시 채팅은 채팅 기록에 남지 않고 [메모리](/ko/ai/memory)도 저장하지 않으며, 채팅을 떠나면 삭제됩니다. 나중에 남기고 싶어졌다면 배너에서 **채팅 유지**를 클릭하세요. 일반 채팅으로 전환됩니다.

## 답변 표시 방식 선택하기

각 에이전트에는 기본 응답 스타일과 Intelligent UI 수준이 있어 차트, 표, 카드로 답할 빈도를 결정합니다. 한 채팅에서만 이를 바꾸려면 **+** 메뉴를 열고 **스타일 사용**을 선택하세요. **일반** 같은 스타일이나 Intelligent UI 수준을 고른 뒤, 해당 에이전트의 기본값으로 삼으려면 **모두에 사용**을 선택합니다. 스타일과 수준에 대한 자세한 내용은 [에이전트](/ko/ai/agents)를 참고하세요.

답변 속 링크는 사이트 아이콘이 있는 카드로 표시됩니다. 지도 링크는 장소 이름이 표시된 실제 지도를 보여 주며, 여러 장소는 번호가 매겨진 하나의 지도에 함께 표시되고 경로는 소요 시간 및 거리와 함께 선으로 나타납니다([Visual Answers](/ko/features/visual-answers) 참고).

## 화면 둘러보기

사이드바는 왼쪽의 얇은 아이콘 레일과 그에 따라 내용이 바뀌는 가운데 열로 구성됩니다.

- 레일은 주의가 필요한 채팅 수를 주황색 숫자로 보여 주는 **채팅**으로 시작해 **예약됨**, **지식 베이스**, **플러그인** 순서로 이어집니다. **보드**, **아티팩트**, **미디어** 등 다른 공간은 **···** 메뉴에 있습니다. 설치한 플러그인은 구분선 아래에 놓이며, 기기 전환기와 설정 메뉴는 맨 아래에 있습니다. 설정 메뉴에는 도움말 링크, **새로운 기능**, **사이드바 단축키**도 들어 있습니다.
- 레일에서 항목을 고르면 가운데 열에 해당 섹션, 필터, 주요 작업이 표시됩니다. **채팅**은 마지막으로 보던 위치로 돌아갑니다. 스킬과 MCP 서버는 **플러그인**에서 창을 벗어나지 않고 바로 열립니다.
- **⌥⌘1**부터 **⌥⌘9**까지 눌러 레일에 표시된 항목을 순서대로 열 수 있습니다. **⌘B**는 레일만 남기고 가운데 열을 숨깁니다.
- **뒤로**와 **앞으로**는 방문했던 위치와 각 위치에서 선택했던 섹션을 기억합니다. **뒤로**를 길게 누르면 방문 목록이 열립니다.

### 사이드바 사용자화

**···** 메뉴를 열거나 레일의 아이콘을 마우스 오른쪽 버튼으로 클릭해 **사이드바 사용자화…**를 선택하세요. 레일에 표시할 항목을 고르고 드래그해 순서를 바꿀 수 있습니다. 플러그인을 구분선 위로 드래그해 기본 항목들 사이에 두거나 다시 아래로 내릴 수 있으며, 모든 항목이나 플러그인을 고정하거나 고정 해제할 수 있습니다.

### 빠른 접근

가장 자주 여는 페이지, 프로젝트, 링크를 사이드바에 고정하세요. 사이드바 맨 아래의 설정 메뉴를 열고 **사이드바 단축키**를 선택한 뒤 항목을 추가하면 됩니다. 추가된 항목은 **빠른 접근** 그룹에 표시되며, 드래그해서 순서를 바꾸거나 이름을 변경하고 제거할 수 있습니다.

### 기기 전환기

사이드바는 한 번에 한 대의 컴퓨터만 보여 줍니다. 맨 아래의 기기 전환기를 사용하면 이 컴퓨터와 페어링된 다른 컴퓨터 사이를 오가고, 다른 컴퓨터에서 대기 중인 작업을 확인하며, 각 컴퓨터를 별도 창으로 열 수 있습니다. **기기** 제목 옆에 **관리**가 있으며, **기기 추가**로 컴퓨터를 페어링하거나 SSH 호스트 또는 휴대폰을 추가할 수 있습니다([다른 컴퓨터](/ko/integrations/other-computers), [휴대폰 페어링](/ko/integrations/pair-your-phone), [컴퓨터 및 SSH 호스트](/ko/integrations/computers-and-ssh-hosts) 참고).

업데이트 후 Enconvo를 처음 열면 사이드바 카드가 해당 버전의 업데이트 동영상을 안내합니다. 설정 메뉴의 **새로운 기능**을 누르면 **설정 → 튜토리얼**에서 모든 업데이트 동영상을 볼 수 있습니다.

### 아티팩트

**···** 메뉴의 **아티팩트**에는 에이전트가 만든 페이지, 문서, 디자인 목록이 표시됩니다. 카드나 행을 마우스 오른쪽 버튼으로 클릭해 **열기**, **이름 바꾸기**, **링크 복사**, 만든 채팅 열기 또는 **삭제**를 선택할 수 있습니다. **⌘**-클릭이나 **⇧**-클릭으로 여러 개를 한꺼번에 선택해 삭제할 수 있으며 **실행 취소**도 가능합니다. 아무 내용도 쓰지 않은 빈 아티팩트는 목록에 표시되지 않습니다.

페이지 아티팩트를 공유하려면 **게시**를 클릭하세요. Enconvo Cloud의 고유한 `name.site.enconvo.com` 링크로 온라인에 게시되며 필요 시 비밀번호를 설정할 수 있습니다. 에이전트에게 페이지나 사이트 폴더를 게시해 달라고 요청할 수도 있습니다.

## 채팅 정리하기

사이드바에는 최근 채팅 목록이 표시되며, 프로젝트를 사용할 수 있는 환경에서는 프로젝트별로 관련 채팅을 묶어 둡니다. 모든 채팅은 저장되므로 사이드바의 **검색**(**⌘G**)을 클릭해 대화 내용으로 찾을 수 있습니다. 채팅 메뉴를 열어 **채팅 이름 바꾸기**, **채팅 고정**, **프로젝트로 이동**, **채팅 보관** 또는 **채팅 삭제**를 선택하세요. 채팅 기록을 삭제하기 전에는 확인 안내를 꼭 읽어 보세요.

- 상단의 **활성** 그룹은 사용자의 확인을 기다리거나 실행 중이거나 아직 열어 보지 않은 결과 또는 실패가 있는 채팅만 프로젝트 및 상태와 함께 모아 보여 줍니다. 각 행은 일반 채팅 목록과 동일하게 작동합니다. 마우스를 올려 **고정** 및 **보관**을 누르거나, 마우스 오른쪽 버튼을 클릭해 메뉴를 열거나, 두 번 클릭해 이름을 바꾸거나, 트랙패드에서 스와이프해 보관할 수 있습니다. 그룹 위에 마우스를 올리면 **모두 읽음으로 표시**가 나타납니다.
- 목록 맨 아래의 **iPhone 채팅**에는 iPhone이나 Android 휴대폰에서 시작한 채팅이 모입니다. Mac에서 대화를 이어 갈 수 있으며, 한쪽에서 삭제하면 양쪽 모두에서 삭제됩니다([휴대폰 채팅](/ko/integrations/iphone-phone-chats) 참고).
- 에이전트가 Codex, Claude Code 또는 다른 에이전트에게 도움을 요청할 때 시작하는 채팅은 기본 목록에 표시되지 않습니다. 요청한 원래 채팅의 해당 줄에서 열어 보세요. 단, 열려 있거나 고정되었거나 사용자의 답변을 기다리는 동안에는 목록에 행이 표시됩니다.
- 각 [자동화](/ko/workflows/scheduled-jobs)의 최신 실행은 시작되자마자 시계 아이콘과 함께 목록에 표시됩니다.
- **고정됨** 그룹과 워크트리 행은 접거나 펼 수 있습니다.
- 채팅 옆의 보라색 스피너는 해당 채팅의 답변은 끝났지만 거기서 시작한 하위 에이전트나 백그라운드 작업이 아직 실행 중임을 뜻합니다. 그 안의 파란색 점은 읽어야 할 새 답변이 있음을 의미합니다.

### 여러 채팅 한꺼번에 처리하기

1. **⌘**-클릭, **Shift**-클릭 또는 행의 **선택**으로 채팅을 고릅니다. **⌘A**는 그룹 전체를 선택합니다.
2. 나타나는 막대에서 읽음으로 표시(**⇧⌘U**), 보관(**E**) 또는 삭제(**⌫**)를 실행합니다.

삭제를 누르면 먼저 확인을 요청하며 대상 채팅 목록을 보여 주고, 실행 중인 채팅은 중지시키며, **대신 보관** 옵션을 함께 제공합니다. 읽음 표시와 보관은 실행 취소할 수 있습니다.

### 모델 선택

최상위의 **새 채팅**에서는 에이전트의 기본 모델을 설정할 수 있습니다. 프로젝트 내부의 새 채팅은 해당 프로젝트의 모델 기본 설정을 따릅니다. 각 채팅은 자체 모델과 추론 설정을 따로 유지할 수 있습니다. 다른 채팅에도 영향을 주는 기본값을 바꾸기 전에 [모델 선택](/ko/ai/model-selection-guide)을 읽어 보세요.

채팅의 모델이 Enconvo Cloud 포인트를 모두 소진하면 해당 채팅을 Enconvo Cloud 외의 모델로 전환한 뒤 포인트 부족 카드에서 **다음으로 다시 시도**를 클릭해 그 모델로 메시지를 다시 실행하세요. 채팅이 자동으로 백업 모델로 넘어가게 하려면 **설정 → AI 모델**에서 **대체(Fallback)**를 설정하세요([백업 모델로 채팅 이어 가기](/ko/ai/model-selection-guide) 참고).

### 워크트리에서 작업하기

git 저장소인 프로젝트에서는 채팅을 메인 체크아웃과 워크트리 사이에서 이동할 수 있습니다. 채팅 제목 뒤의 칩을 사용하거나 에이전트에게 요청하세요. 채팅은 변경된 파일과 함께 이동하며, 워크트리를 병합하면 다시 메인 체크아웃으로 돌아옵니다. 이동할 때마다 대화 내용에 안내 줄이 남습니다([프로젝트](/ko/ai/projects) 참고).

## 컨텍스트와 파일 추가하기

요청에 꼭 필요한 출처만 추가하세요. 파일 첨부, 화면 캡처, 지식 베이스 검색, 브라우저 페이지는 각각 에이전트에게 서로 다른 종류의 컨텍스트를 제공합니다. 어떤 출처를 고를지는 [컨텍스트 인식](/ko/features/context-awareness), 에이전트가 파일로 할 수 있는 작업은 [파일 및 폴더](/ko/ai/file-tools)를 참고하세요.

- 메시지 상자에는 **권한** 뒤에 **실시간 화면**과 [화면 낙서](/ko/features/screen-doodle) 버튼이 있습니다. 실시간 화면은 켠 창에 종속되며, 켜져 있으면 칩이 표시되고 클릭하면 꺼집니다.
- `@`를 입력해 파일, 에이전트, 친구 및 팀원을 멘션할 수 있습니다. 사람을 지정하면 에이전트가 누구를 말하는지 알기 때문에 비공개 메시지를 보내거나 답장을 읽거나 요청 시 전화를 걸 수 있습니다.
- 큰 동영상이나 오디오 파일은 전사 텍스트나 메모 형태로 모델에 전달됩니다. 폴더나 빈 파일은 첨부할 수 없습니다.

[메모리](/ko/ai/memory)와 [지식 베이스](/ko/ai/knowledge-base)는 역할이 다릅니다. 메모리는 에이전트가 재사용하는 사실을 보관하고, 지식 베이스는 찾아볼 자료를 저장합니다. 둘 다 사이드바 레일의 **지식 베이스**에서 열리며, 열 상단의 **지식 베이스** / **메모리** 스위치로 전환합니다.

## 답변 읽고 재사용하기

답변의 작업 세부 정보를 펼치면 각 도구 호출과 결과를 볼 수 있습니다. 답변 아래의 **복사**, **소리 내어 읽기**, **더 보기**로 후속 작업을 할 수 있습니다. [Visual Answers](/ko/features/visual-answers)는 답변 안에 다이어그램과 대화형 콘텐츠를 바로 띄워 줍니다.

코드 블록에는 **복사**와 줄 바꿈 버튼이 있어 긴 줄을 가로 스크롤 대신 줄 바꿈해 볼 수 있습니다. 모든 답변에서 코드를 줄 바꿈하려면 **설정 → 일반**의 **외관** 아래에서 **코드 줄 바꿈**을 켜세요.

채팅을 링크로 공유하면 채팅이 업로드되는 동안 바로 복사할 수 있는 링크가 준비됩니다. 나중에 **링크 업데이트**를 누르면 바뀐 부분만 전송합니다.

에이전트가 열어 준 페이지와 파일은 채팅 옆의 측면 패널에 표시됩니다. 각 채팅은 사용자가 열어 두거나 닫아 둔 상태를 기억합니다. 패널을 한 번도 열지 않은 채팅은 패널의 도구들을 안내하는 **새 탭**에서 시작합니다. 탭들은 사용자가 드래그해 맞춘 너비를 공유하며, 마지막 탭을 닫으면 패널이 닫힙니다.

| 탭 | 단축키 | 표시 내용 |
| --- | --- | --- |
| **풀 리퀘스트** | **⌃⇧P** | GitHub 저장소에서 작업하는 채팅의 경우: 체크, 리뷰, 댓글이 포함된 브랜치의 풀 리퀘스트를 보거나 워크트리 채팅에서 새 풀 리퀘스트를 생성합니다. |
| **기기** | **⌃⇧M** | 일회성 설정 후 채팅 옆에서 보고 제어할 수 있는 iOS 시뮬레이터 또는 Android 에뮬레이터입니다. |

입력 대신 말로 대화하려면 음성으로 작성하는 [받아쓰기](/ko/features/dictation)나 양방향 음성 대화를 나누는 [Live Talk](/ko/features/live-voice)를 사용하세요.

## Enconvo가 재시작될 때

업데이트, 종료 또는 충돌로 작업 도중 채팅이 멈추더라도 Enconvo가 다시 켜지면 채팅이 스스로 작업을 이어 갑니다. 나머지 작업을 진행하기 전에 이미 마친 부분을 먼저 확인하고, 실행 중이던 하위 에이전트도 다시 불러옵니다.

## 설정

**설정 → 채팅 창**을 여세요.

| 설정 | 변경 내용 |
| --- | --- |
| **기본 에이전트** | 채팅 창에서 새 채팅을 열 때 시작하는 에이전트입니다. 해당 에이전트를 삭제하면 새 채팅은 다시 Mavis로 시작합니다. |
| **외관** | **라이트**, **다크** 또는 **앱 따르기** 중 선택합니다. |
| **단축키** | 어느 앱에서든 채팅 창을 엽니다. 기본값은 **⌃⌘X**입니다. 다른 창의 **채팅 창에서 열기** 버튼에는 여기서 설정한 키가 표시됩니다. |

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변에 잘못된 모델이 사용됨 | 에이전트의 기본 모델뿐 아니라 이 채팅의 모델 선택도 확인하세요. |
| 다른 모델이 대신 답했다는 안내가 표시됨 | 채팅의 모델을 사용할 수 없는 동안 **설정 → AI 모델**의 백업 모델이 응답한 것입니다. 원래 모델이 작동하면 다시 돌아옵니다. |
| 에이전트가 파일이나 화면을 보지 못함 | 채팅의 첨부 파일과 [권한](/ko/configuration/permissions)을 확인하세요. |
| 도구를 사용할 수 없음 | 같은 요청을 다시 표현하기 전에 에이전트 설정의 **도구 및 스킬**을 확인하세요([에이전트](/ko/ai/agents) 참고). |
| 찾는 채팅이 목록에 없음 | **활성**과 **iPhone 채팅** 또는 **검색**(**⌘G**)을 확인하세요. 에이전트가 자체적으로 시작한 채팅은 요청한 원래 채팅에서 열 수 있습니다. |
| 채팅에 **이 채팅을 표시할 수 없습니다**가 뜸 | **채팅 다시 불러오기**를 클릭하세요. 그사이 채팅 목록과 메시지 상자는 계속 작동합니다. |

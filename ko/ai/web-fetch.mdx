---
title: "웹페이지 가져오기"
description: "에이전트가 URL에서 웹페이지를 읽거나 지식 베이스에 페이지를 보관하도록 합니다."
---

이미 URL을 알고 있고 에이전트가 해당 페이지를 읽기를 원할 때 웹페이지 가져오기를 사용하세요. 모든 에이전트는 전달받은 링크를 읽을 수 있으며, 페이지를 가져오는 데 사용할 서비스는 직접 선택할 수 있습니다. 먼저 관련 페이지를 찾아야 한다면 [웹 검색](/ko/ai/web-search)을 사용하세요.

## 제공업체 선택하기

1. **설정 → 웹페이지 가져오기**를 엽니다.
2. 제공업체를 선택하고 **기본값으로 설정**을 클릭합니다.

| 제공업체 | 용도 |
| --- | --- |
| **Local Fetch** | 선택적 브라우저 지원 가져오기를 통해 Mac에서 무료로 페이지 가져오기 |
| **Jina AI Link Reader** | Jina를 통해 읽기 가능한 콘텐츠 가져오기 |
| **Firecrawl Link Reader** | Firecrawl을 통해 콘텐츠 가져오기 |
| **DeepSeek** | 보유한 DeepSeek API 키로 페이지를 Markdown으로 읽기 |
| **DeepSeek (Enconvo Cloud)** | API 키 없이 Enconvo Cloud를 통해 페이지를 Markdown으로 읽기 |
| **Enconvo Cloud Plan** | Cloud 링크 읽기 서비스 사용 |

## 페이지 읽기

1. 대화에 URL을 붙여 넣고 그에 관한 구체적인 질문을 입력합니다.
2. 답변을 신뢰하기 전에 가져온 내용과 출처를 확인하세요.

## 로그인이 필요한 페이지

**Local Fetch**에서는 **브라우저 지원 가져오기** 기능을 통해 Enconvo Companion 확장 프로그램이 설치된 Chromium 계열 브라우저로 페이지를 읽을 수 있습니다.

| 옵션 | 동작 방식 |
| --- | --- |
| **자동** (기본값) | 이미 열려 있고 로그인되어 완전히 렌더링된 일치하는 탭을 재사용합니다. 직접 가져오기가 실패하거나 페이지에 JavaScript가 필요할 때는 임시 백그라운드 탭을 사용합니다. |
| **끔** | 직접 HTTP 요청만 사용 |
| **항상** | 항상 브라우저를 통해 가져오기 |

연결된 브라우저가 없으면 Local Fetch는 직접 HTTP 요청을 보냅니다. 다른 제공업체들은 공개 URL을 가져오므로 로그인된 브라우저 세션에 접근할 수 없습니다. 상호작용이 필요한 페이지라면 [브라우저 확장 프로그램](/ko/features/browser-extension)이나 [브라우저 사용](/ko/features/browser-control)을 사용하세요.

## 웹 콘텐츠 보관하기

나중에 다시 찾고 싶은 페이지는 [지식 베이스](/ko/ai/knowledge-base)에서 **추가 → 단일 웹페이지**로 URL을 등록해 두세요. 웹페이지는 가져온 뒤에도 내용이 바뀔 수 있으므로 가져온 페이지와 인덱싱 상태를 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 내용이 비어 있음 | 추가 상호작용 없이 읽을 수 있는 페이지인지 확인하거나, **Local Fetch**의 **브라우저 지원 가져오기**를 사용하세요. 로그인 화면, 차단된 요청, 동적 로딩 콘텐츠, 미지원 사이트에서는 추출이 되지 않을 수 있습니다. |
| 답변이 페이지에 없는 내용을 설명함 | 없는 내용을 추측하지 않도록 에이전트에게 실제로 가져온 내용을 보여 달라고 요청하세요. |

---

URL을 이미 알고 있고 에이전트가 그 페이지를 읽게 하려면 웹페이지 가져오기를 사용하세요. 모든 에이전트가 사용자가 알려 준 링크를 읽을 수 있으며, 링크를 가져오는 서비스는 사용자가 선택합니다. 먼저 관련 페이지를 찾아야 한다면 [웹 검색](/ko/ai/web-search)을 사용하세요.

## 제공업체 선택

1. **설정 → 웹페이지 가져오기**를 엽니다.
2. 제공업체를 선택하고 **기본값으로 설정**을 클릭합니다.

| 제공업체 | 용도 |
| --- | --- |
| **Local Fetch** | Mac에서 무료로 페이지를 가져오며, 브라우저를 이용한 가져오기도 선택할 수 있음 |
| **Jina AI Link Reader** | Jina를 통해 읽기 좋은 콘텐츠를 가져옴 |
| **Firecrawl Link Reader** | Firecrawl을 통해 콘텐츠를 가져옴 |
| **DeepSeek** | DeepSeek API 키로 페이지를 Markdown으로 읽음 |
| **DeepSeek (Enconvo Cloud)** | Enconvo Cloud를 통해 페이지를 Markdown으로 읽으며 API 키가 필요 없음 |
| **Enconvo Cloud Plan** | Cloud 링크 읽기 서비스를 사용 |

## 페이지 읽기

1. 대화에 URL을 붙여넣고 그 페이지에 대해 구체적으로 질문합니다.
2. 답변에 의존하기 전에 가져온 콘텐츠와 출처를 확인합니다.

## 로그인이 필요한 페이지

**Local Fetch**에서는 **브라우저 지원 가져오기**가 Enconvo Companion 확장 프로그램이 설치된 Chromium 계열 브라우저를 통해 페이지를 읽을 수 있습니다.

| 옵션 | 기능 |
| --- | --- |
| **자동**(기본값) | 이미 열려 있는, 일치하는 탭을 완전히 렌더링되고 로그인된 상태 그대로 다시 사용합니다. 직접 가져오기가 실패하거나 페이지에 JavaScript가 필요하면 임시 백그라운드 탭을 사용합니다. |
| **끔** | 직접 HTTP만 사용 |
| **항상** | 항상 브라우저를 통해 가져옴 |

연결된 브라우저가 없으면 Local Fetch는 직접 HTTP 요청을 보냅니다. 다른 제공업체는 공개 URL을 가져오며 사용자가 로그인한 브라우저 세션에는 접근할 수 없습니다. 대화형 페이지에는 [브라우저 확장 프로그램](/ko/features/browser-extension) 또는 [브라우저 사용](/ko/features/browser-control)을 이용하세요.

## 웹 콘텐츠 보관

나중에 찾으려면 [지식 베이스](/ko/ai/knowledge-base)에서 **추가 → 단일 웹페이지**로 URL을 추가하세요. 가져온 페이지와 색인 상태를 확인하세요. 웹페이지는 가져온 뒤에 바뀔 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 콘텐츠가 비어 있음 | 추가 상호작용 없이 페이지를 읽을 수 있는지 확인하거나, **Local Fetch**와 **브라우저 지원 가져오기**를 사용하세요. 로그인 화면, 차단된 요청, 동적으로 불러오는 콘텐츠, 지원되지 않는 사이트는 추출을 막을 수 있습니다. |
| 답변이 페이지에 없는 내용을 설명함 | 빠진 콘텐츠를 추측하지 말고, 에이전트에게 실제로 가져온 내용을 보여 달라고 요청하세요. |

OCR은 스크린샷이나 이미지의 텍스트를 읽어서 복사하고, 붙여넣고, 번역하거나, 그에 대해 질문할 수 있게 해 줍니다. 이미지, 동영상 프레임, 스캔한 페이지처럼 텍스트를 선택할 수 없을 때 사용하세요. 텍스트를 Mac에서 읽을지 온라인 서비스로 읽을지는 사용자가 선택합니다.

## 시작하기 전에

Enconvo가 화면을 캡처하려면 화면 기록 권한이 필요합니다. [권한](/ko/configuration/permissions)을 참고하세요.

## 화면에서 텍스트 복사

1. SmartBar에서 **스크린샷 OCR**을 실행합니다.
2. 텍스트가 있는 영역 위로 드래그합니다.
3. 텍스트가 Dynamic Island에서 열립니다. **복사**를 클릭하거나, **붙여넣기**(**⌘↩**)로 사용 중인 앱에 넣습니다.

같은 결과에서 **번역**이나 **AI에게 질문**을 클릭할 수도 있습니다. **⋯** 메뉴에는 **원래 줄바꿈 유지**, **이미지 복사**, **이미지 저장…**, **영역 다시 선택**, **지식 베이스에 추가**, **OCR 설정…**이 있습니다.

다른 제공업체로 영역을 다시 읽으려면 텍스트 위의 제공업체 이름을 클릭하고 하나를 선택하세요. 제공업체가 각 줄의 위치를 알고 있다면 이미지 보기로 전환하여 스크린샷에서 줄을 선택한 다음 **선택 항목 복사**를 클릭합니다.

## 다른 OCR 명령

| 명령 | 기능 |
| --- | --- |
| **스크린샷 OCR** | 화면 영역을 읽고 텍스트를 Dynamic Island에서 엽니다 |
| **무음 스크린샷 OCR** | 화면 영역을 읽고 텍스트를 클립보드에 복사합니다 |
| **OCR** | 사용자가 제공한 이미지의 텍스트를 읽습니다 |
| **스크린샷 번역** | 화면 영역을 번역합니다. [번역](/ko/ai/translate)을 참고하세요 |
| **스크린샷 설명** | 화면 영역을 설명합니다. [글쓰기 도구](/ko/features/writing-tools)를 참고하세요 |

## 제공업체 선택

**설정 → OCR**을 열고 제공업체를 선택한 다음 **기본값으로 설정**을 클릭합니다.

| 제공업체 | 텍스트를 읽는 위치 |
| --- | --- |
| **Apple Native OCR** | Mac에서 Apple 자체 텍스트 인식으로 |
| **PP-OCRv6 (MLX)** | Mac에서 Apple 실리콘의 PaddleOCR 감지 및 인식 모델로. 아무것도 Mac 밖으로 나가지 않습니다 |
| **AI Model OCR** | 사용자가 선택한 AI 모델이 **지침**에 따라 |
| **Mistral OCR** | Mistral의 온라인 서비스로, Mistral 키 또는 Mistral 로그인 사용 |
| **Mistral OCR (Enconvo Cloud Plan)** | Mistral의 온라인 서비스로, Enconvo Cloud 플랜을 통해 |

각 OCR 명령은 자체 제공업체를 사용할 수도 있습니다. **설정 → 플러그인 → OCR**의 명령 설정에서 **OCR 제공자**를 지정하세요. 각 제공업체의 필드는 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

## 더 나은 결과 얻기

텍스트를 읽기 쉬운 크기로, 필요한 부분만 좁고 선명하게 캡처하세요. 열, 표, 구두점, 코드 들여쓰기, 모양이 비슷한 문자는 직접 확인하세요.

PDF 파일이라도 스캔한 문서에는 OCR이 필요할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 캡처가 비어 있거나 시작되지 않음 | [권한](/ko/configuration/permissions)에서 화면 기록 권한을 확인하세요 |
| **텍스트를 찾을 수 없음** | **영역 다시 선택**을 클릭하고 더 좁은 영역을 선택하세요. 필기체나 장식적인 글꼴은 **AI 모델 OCR 사용해 보기**로 더 잘 읽힐 수 있습니다 |
| **읽을 수 없음** | **재시도**를 클릭하고 단순한 이미지를 시도해 보며 제공업체의 오류를 읽어 보세요. **설정**을 누르면 OCR 설정이 열립니다 |
| 줄이 붙거나 엉뚱한 곳에서 끊김 | **⋯** 메뉴에서 **원래 줄바꿈 유지**를 켜거나 끄거나, 다른 제공업체로 영역을 다시 읽으세요 |
| 텍스트를 복사하지 않고 화면에 있는 것에 대해 질문하고 싶음 | [Appshots](/ko/features/appshots) 또는 [화면 낙서](/ko/features/screen-doodle)를 사용하세요 |

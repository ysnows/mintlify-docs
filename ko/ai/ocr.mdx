OCR은 스크린샷이나 이미지 속 텍스트를 읽어 복사, 붙여넣기, 번역, 질문에 활용할 수 있게 해 줍니다. 이미지, 동영상 프레임, 스캔한 문서처럼 텍스트를 직접 선택할 수 없을 때 사용하세요. 텍스트 인식을 Mac 안에서 처리할지 온라인 서비스를 이용할지도 직접 고를 수 있습니다.

## 시작하기 전에

화면을 캡처하려면 Enconvo에 화면 기록 권한이 필요합니다. [권한](/ko/configuration/permissions)을 참고하세요.

## 화면에서 텍스트 복사하기

1. SmartBar에서 **Screenshot OCR**을 실행합니다.
2. 텍스트가 있는 영역을 드래그해 선택합니다.
3. 텍스트가 Dynamic Island에 열립니다. **복사**를 클릭하거나 **붙여넣기**(**⌘↩**)를 눌러 사용 중이던 앱에 바로 넣으세요.

같은 결과 창에서 **번역**이나 **AI에게 묻기**도 바로 클릭할 수 있습니다. **⋯** 메뉴에는 **원래 줄바꿈 유지**, **이미지 복사**, **이미지 저장…**, **영역 다시 선택**, **지식 베이스에 추가**, **OCR 설정…**이 있습니다.

다른 제공업체로 같은 영역을 다시 읽으려면 텍스트 위의 제공업체 이름을 클릭해 원하는 항목을 선택하세요. 제공업체가 각 줄의 위치를 인식하는 경우 이미지 보기로 전환해 스크린샷 위에서 줄을 직접 선택한 뒤 **선택 항목 복사**를 클릭할 수 있습니다.

## 다른 OCR 명령

| 명령 | 기능 |
| --- | --- |
| **Screenshot OCR** | 화면 영역을 읽어 Dynamic Island에 텍스트를 엽니다 |
| **Silent Screenshot OCR** | 화면 영역을 읽어 클립보드에 복사합니다 |
| **OCR** | 전달한 이미지 속 텍스트를 읽습니다 |
| **Screenshot Translate** | 화면 영역을 번역합니다. [번역](/ko/ai/translate)을 참고하세요 |
| **Screenshot Explain** | 화면 영역을 설명합니다. [글쓰기 도구](/ko/features/writing-tools)를 참고하세요 |

## 제공업체 선택하기

**설정 → OCR**을 열고 제공업체를 고른 뒤 **기본값으로 설정**을 클릭합니다.

| 제공업체 | 텍스트가 처리되는 곳 |
| --- | --- |
| **Apple Native OCR** | Apple 자체 텍스트 인식 기능으로 Mac 안에서 처리 |
| **PP-OCRv6 (MLX)** | Apple silicon의 PaddleOCR 감지 및 인식 모델로 Mac 안에서 처리. 외부로 전송되지 않음 |
| **AI Model OCR** | 사용자가 선택한 AI 모델이 **지침**에 따라 처리 |
| **Mistral OCR** | 본인 Mistral 키 또는 Mistral 로그인으로 Mistral 온라인 서비스에서 처리 |
| **Mistral OCR (Enconvo Cloud Plan)** | Enconvo Cloud 요금제를 통해 Mistral 온라인 서비스에서 처리 |

각 OCR 명령마다 개별 제공업체를 지정할 수도 있습니다. **설정 → 플러그인 → OCR** 아래의 해당 명령 설정에서 **OCR 제공업체**를 지정하세요. 제공업체별 설정 항목은 [제공업체 카탈로그](/ko/providers/catalog)를 참고하세요.

## 더 나은 결과 얻기

텍스트가 선명하게 읽힐 만한 크기로, 필요한 영역만 좁게 잡아 캡처하세요. 다단 구성, 표, 문장 부호, 코드 들여쓰기, 비슷하게 생긴 글자는 직접 한 번 더 확인하는 것이 좋습니다.

스캔한 문서는 PDF 파일이라도 OCR이 필요할 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 캡처 화면이 비어 있거나 시작되지 않음 | [권한](/ko/configuration/permissions)에서 화면 기록 권한을 확인하세요. |
| **텍스트를 찾을 수 없음** | **영역 다시 선택**을 클릭해 범위를 좁혀 보세요. 손글씨나 장식적인 글꼴은 **AI Model OCR 시도**를 쓰면 더 잘 읽힐 수 있습니다. |
| **읽을 수 없음** | **다시 시도**를 누르거나 단순한 이미지로 시험해 보고 제공업체 오류 메시지를 확인하세요. **설정**을 누르면 OCR 설정으로 이동합니다. |
| 줄이 붙어 나오거나 엉뚱한 곳에서 끊김 | **⋯** 메뉴에서 **원래 줄바꿈 유지**를 켜거나 끄고, 또는 다른 제공업체로 다시 읽어 보세요. |
| 텍스트 복사가 아니라 화면 내용을 물어보고 싶음 | [Appshots](/ko/features/appshots)나 [화면 낙서](/ko/features/screen-doodle)를 사용하세요. |

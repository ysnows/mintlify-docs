지식 베이스에는 Enconvo가 나중에 찾아야 할 자료를 보관합니다. 참고 문서, 프로젝트 메모, 저장한 웹페이지, 음성 메모 등이 여기에 해당합니다. 에이전트는 사용자가 지정하거나 질문에 지식 베이스의 내용이 필요할 때 이를 검색합니다. [메모리](/ko/ai/memory)는 다릅니다. 메모리에는 에이전트가 채팅 전반에 걸쳐 기억하는 사용자에 관한 짧은 사실이 담깁니다.

## 지식 베이스 열기

- 채팅 창의 사이드바에서 **지식 베이스**를 클릭합니다.
- 또는 **설정 → 지식 베이스**를 열고 지식 베이스를 클릭합니다.
- 또는 Enconvo 메뉴 막대 메뉴에서 **지식 베이스 창 표시**를 선택합니다. 채팅 창에서 지식 베이스가 열립니다.

[메모리](/ko/ai/memory)도 여기에 있습니다. 지식 베이스 열 상단의 **지식 베이스** / **메모리** 스위치로 둘 사이를 오갈 수 있습니다. 메모리는 지식 베이스 목록에 표시되지 않습니다.

채팅 창에서 상단의 지식 베이스 이름을 클릭하면 모든 지식 베이스를 볼 수 있습니다. 각 지식 베이스의 크기, 이번 주에 추가된 항목, 확인이 필요한 항목, AI 클라이언트가 검색할 수 있는 지식 베이스가 표시됩니다.

## 지식 베이스 만들기

1. 모든 지식 베이스 개요 또는 **설정 → 지식 베이스**에서 **새 지식 베이스**를 클릭하거나, SmartBar에서 **지식 베이스 만들기**를 검색합니다.
2. 알아보기 쉬운 **이름**을 지정합니다. 무엇을 담을지 **설명**을 추가하세요. 에이전트는 이 설명을 읽고 언제 이곳을 검색할지 판단합니다.
3. **시작 방법**에서 **비어 있음**, **폴더**(색인되어 동기화 상태 유지), **파일** 중 하나를 선택합니다.
4. Claude나 Cursor 같은 MCP 클라이언트가 접근하게 하려면 **AI 클라이언트의 검색 허용**을 켭니다.
5. **만들기**를 클릭합니다. 폴더나 파일을 선택한 경우 버튼에는 **만들고 가져오기** 또는 **만들고 추가**라고 표시됩니다.

서로 관련 없는 프로젝트는 지식 베이스를 따로 만들어 구분하세요. 지식 베이스 안에서는 폴더로 항목을 정리합니다.

## 콘텐츠 추가

| 항목 | 용도 |
| --- | --- |
| **추가 → 메모** | 새로운 편집 가능한 Markdown 메모 |
| **추가 → 파일** | Mac에 있는 지원 문서, 이미지, 오디오, 비디오 |
| **추가 → 단일 웹페이지** | URL 하나의 콘텐츠 |
| **추가 → YouTube 동영상** | 동영상과 자막 |
| **추가 → 게시** | X, Reddit, Hacker News, Bluesky, Zhihu 등의 게시물 |
| **추가 → 폴더 가져오기…** | 구조가 유지된 로컬 폴더(선택적으로 동기화 상태 유지) |
| **추가 → 새 폴더…** | 항목을 정리할 폴더 |
| 지식 베이스에 파일 끌어다 놓기 또는 붙여넣기 | Finder에서 빠르게 가져오기 |
| [빠른 캡처](/ko/features/quick-capture) | 현재 앱의 콘텐츠 저장 |
| [음성 메모](/ko/features/voice-notes) | 음성 메모 녹음 및 저장 |

문서 로더는 일반 텍스트, Markdown, PDF, Office, EPUB, 구조화된 데이터 형식을 지원합니다. 이미지는 OCR로 읽고, 오디오와 비디오는 텍스트로 변환합니다. 구문 분석 품질과 지원 형식은 선택한 로더와 제공업체에 따라 달라집니다. 건너뛰거나 실패한 파일은 가져오기 미리보기와 각 항목의 상태에서 확인하세요.

웹사이트 전체를 추가하면 Enconvo는 주소가 가리키는 사이트의 구역(예: 문서 사이트의 한 부분) 안에서만 수집하며, 두 개의 주소로 찾을 수 있는 페이지는 한 번만 색인합니다.

## 지식 베이스 공유

이메일로 사람들과 공유하거나 팀 전체와 공유할 수 있습니다. 사용자와 공유받는 사람 모두 Enconvo 계정에 로그인해 있어야 합니다.

<Steps>
  <Step title="공유 열기">
    지식 베이스의 **⋯** 메뉴를 열고 **공유…**를 선택합니다.
  </Step>
  <Step title="사람 또는 팀 추가">
    **이메일로 사람 추가**를 사용하거나, 팀 액세스를 켜서 팀의 모든 구성원과 공유합니다.
  </Step>
  <Step title="각자의 권한 선택">
    **보기 가능**, **추가 가능**, **관리 가능** 중에서 선택합니다. 소유자와 관리 권한이 있는 사람만 액세스 권한을 변경할 수 있습니다.
  </Step>
</Steps>

공유하면 해당 지식 베이스의 사본이 Enconvo Cloud에 저장됩니다. 지식 베이스에 담긴 내용만 Mac 밖으로 나가며, 메모리와 채팅 기록은 공유되지 않습니다. 누군가 추가한 내용은 몇 초 안에 모든 Mac에 반영되고, 각 항목에는 추가한 사람이 표시됩니다. 각 구성원의 Mac에는 자체 사본과 색인이 있으므로 오프라인에서도 검색할 수 있습니다. 연결된 폴더는 다른 사람이 볼 수만 있습니다. **활동**에서는 무엇이 누구에 의해 바뀌었는지 확인할 수 있습니다.

공유를 중단하려면 해당 사람에게 **액세스 권한 삭제**를 사용하거나 **팀과 공유 중지**를 사용하세요.

## 항목 둘러보기 및 찾기

- **그리드**, **목록**, **지도**로 보기를 전환합니다. 목록은 **유형**, **태그**, **폴더**, **상태**, **추가됨** 열이 있는 표입니다. 지도에는 각 항목이 의미상 가장 가까운 항목과 연결되어 표시됩니다.
- 항목 위의 **라이브러리** 메뉴에서 **모든 항목**, **최근 추가**, **태그 없음**, **확인 필요**를 개수와 함께 전환할 수 있습니다. 확인이 필요한 항목이 있으면 점이 표시됩니다.
- **필터**, **태그**, **유형**으로 표시할 항목을 좁힙니다.
- 목록에서 행을 선택하면 여러 항목을 한꺼번에 이동하거나, 태그를 달거나, 다시 색인하거나, 삭제하거나, 함께 채팅할 수 있습니다.

## 연결된 폴더

1. **추가 → 폴더 가져오기…**를 선택합니다.
2. 원본 폴더를 선택하고, 파일 수와 건너뛴 파일을 확인한 다음 확정합니다.
3. 폴더를 선택하고 세부 정보를 표시하여 원본 경로, 동기화 상태, 제어 항목을 확인합니다.
4. **지금 동기화**를 클릭하거나, **자동 동기화**를 켜서 Enconvo가 실행되는 동안 변경 사항을 따라가게 합니다.

원본 폴더는 디스크에 그대로 남습니다. 새 파일과 변경된 파일은 가져오고, 원본에서 삭제한 파일은 지식 베이스에서도 제거됩니다. 숨김 파일, 지원되지 않는 형식, 50MB가 넘는 파일은 건너뜁니다. Enconvo의 폴더 동기화는 원본 파일을 수정하지 않습니다.

원본 드라이브의 연결이 끊겼거나 폴더가 이동된 경우 폴더에 **원본 폴더를 찾을 수 없습니다**라고 표시되며 아무것도 제거되지 않습니다. 드라이브를 다시 연결하거나 **다시 연결…**을 클릭하고 새 위치를 선택하세요. 처리 및 동기화 문제 해결은 [지식 베이스의 작동 방식](/ko/advanced/knowledge-base-advanced)을 참고하세요.

## 소스에 대해 질문하기

- **지식 베이스에서**: 상단의 **항목** 옆에 있는 **질문**을 클릭합니다. 채팅 창과 같은 채팅입니다. 첫 질문에 지식 베이스가 첨부되고 후속 질문에서도 다시 검색되며, 이 채팅은 다른 채팅과 함께 저장됩니다. **새로 만들기**를 클릭하면 새 질문을 시작합니다.
- **모든 채팅에서**: **@**를 입력하고 목록에서 지식 베이스나 그 안의 항목을 선택합니다. 선택한 항목은 후속 질문을 위해 메시지 입력란 위에 남아 있으며 거기서 제거할 수 있습니다. 칩을 클릭하면 지식 베이스에서 열립니다.

다음과 같이 해 보세요.

> 첨부한 프로젝트 메모를 바탕으로 인증에 관한 결정 사항을 정리하고, 각 결정의 출처를 밝혀 주세요.

에이전트는 필요한 자료를 검색하고 읽습니다. 모든 문서를 보내는 대신, 관련 있는 구절을 골라서 가져옵니다. 중요한 내용은 인용된 항목을 열어 확인하세요. 구절이 빠져 있다면 해당 항목을 직접 언급하거나, 색인이 끝났는지 확인하세요.

## 지식 베이스 설정

지식 베이스 머리글의 톱니바퀴(**지식 베이스 설정**)를 클릭합니다.

| 섹션 | 내용 |
| --- | --- |
| **일반** | 지식 베이스의 **이름**과 **설명** |
| **색인 및 검색** | 확인이 필요한 항목, 검색 모델, 전체 색인을 다시 만드는 **다시 색인…** |
| **소스 및 캡처** | **지금 동기화**, **자동 동기화**, **다시 연결…**이 있는 연결된 폴더와 빠른 캡처, 음성 메모, Chrome 확장 프로그램 바로가기 |
| **AI 클라이언트(MCP)** | AI 클라이언트가 이 지식 베이스를 검색할 수 있는지 여부. [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)를 참고하세요. |
| **고급** | **지식 베이스 ID**와 **지식 베이스 삭제** |

기본 지식 베이스와 메모리는 삭제할 수 없습니다.

## 편집 및 관리

메모를 열어 Markdown을 편집합니다. 항목 및 폴더 메뉴를 사용하여 콘텐츠의 이름을 바꾸거나, 이동하거나, 태그를 달거나, 제거할 수 있습니다. 제거 확인 메시지를 읽어 보세요. 지식 베이스에서 항목을 제거하는 것과 원본 파일을 삭제하는 것은 서로 다른 작업이며, 연결된 폴더 전체를 제거해도 디스크의 파일은 건드리지 않습니다.

<Warning>
연결된 폴더에서 가져온 항목의 메뉴에는 **휴지통으로 이동**이라고 표시됩니다. 디스크에 있는 실제 파일이 휴지통으로 이동하고, 그 후 항목이 지식 베이스에서 사라집니다.
</Warning>

항목이 실패하면 다시 시도하기 전에 추출이 실패했는지 색인이 실패했는지 확인하세요. 문서는 검색 색인이 끝나기 전에도 읽을 수 있는 경우가 있습니다.

모든 지식 베이스는 **설정 → 메모리**의 **검색**에서 지정한 동일한 검색 모델을 사용합니다. 이 모델은 이 Mac 또는 Enconvo Cloud에서 실행되며, 둘 사이를 전환해도 검색 색인은 유지됩니다. **색인 및 검색**의 **검색 설정…**을 누르면 해당 설정이 열립니다.

## 다른 AI 앱 연결

**지식 베이스 설정 → AI 클라이언트(MCP)**를 열어 로컬 MCP 클라이언트가 선택한 지식 베이스를 검색하게 할 수 있습니다. 이는 별도로 제공되는, 직접 켜야 하는 읽기 전용 서비스입니다. 설정과 공유 제어는 [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)를 따라 진행하세요.

## 데이터 처리

지식 베이스 파일과 색인은 로컬에 저장됩니다. 선택한 클라우드 OCR, 음성 변환, 임베딩, 재순위화, 채팅 제공업체는 작업에 필요한 콘텐츠를 받을 수 있습니다. 검색 모델이 Enconvo Cloud에서 실행될 때는 색인하거나 검색하는 텍스트가 그곳으로 전송됩니다. 파일을 로컬에 저장한다고 해서 제공업체의 처리가 오프라인으로 이루어지는 것은 아닙니다. 민감한 자료를 가져오기 전에 [개인정보 보호 및 보안](/ko/configuration/privacy-security)과 사용 중인 제공업체를 검토하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 항목에 색인 오류가 표시됨 | **라이브러리 → 확인 필요**를 열어 추출이 실패했는지 색인이 실패했는지 확인한 다음 해당 항목을 다시 색인하세요. |
| 연결된 폴더에 **원본 폴더를 찾을 수 없습니다**라고 표시됨 | 드라이브를 다시 연결하거나 **다시 연결…**을 클릭하고 폴더의 새 위치를 선택하세요. |
| 답변에 어떤 문서가 빠져 있음 | 해당 문서의 색인이 끝났는지 확인한 다음 **@**로 직접 언급하세요. |
| 새 콘텐츠가 색인되지 않음 | 검색 모델이 Enconvo Cloud에서 실행된다면 로그인하세요. 로그인하기 전에는 새 콘텐츠가 색인되지 않으며 검색에서는 일치하는 단어만 찾을 수 있습니다. |

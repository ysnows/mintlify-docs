지식 베이스에는 참고 문서, 프로젝트 메모, 저장한 웹 페이지, 음성 메모 등 나중에 Enconvo가 다시 찾길 원하는 자료가 보관됩니다. 사용자가 지정하거나 질문에 해당 내용이 필요할 때 에이전트가 이를 검색합니다. [메모리](/ko/ai/memory)와는 다릅니다. 메모리는 에이전트가 채팅 전반에서 사용자에 대해 기억하는 짧은 사실을 보관합니다.

## 지식 베이스 열기

- 채팅 창 사이드바에서 **지식 베이스**를 클릭합니다.
- 또는 **설정 → 지식 베이스**를 열고 지식 베이스를 클릭합니다.
- 또는 Enconvo 메뉴 막대 메뉴에서 **지식 베이스 창 표시**를 선택하면 채팅 창에서 지식 베이스가 열립니다.

[메모리](/ko/ai/memory)도 여기에 있습니다. 지식 베이스 열 상단의 **지식 베이스** / **메모리** 전환 버튼으로 이동하세요. 메모리는 지식 베이스 목록에는 포함되지 않습니다.

채팅 창 상단의 지식 베이스 이름을 클릭하면 전체 지식 베이스를 한눈에 볼 수 있습니다. 각 지식 베이스의 크기, 이번 주에 추가된 항목, 확인이 필요한 항목, AI 클라이언트가 검색할 수 있는 항목을 확인할 수 있습니다.

## 지식 베이스 만들기

1. 전체 지식 베이스 개요나 **설정 → 지식 베이스**에서 **새 지식 베이스**를 클릭하거나, SmartBar에서 **지식 베이스 만들기**를 검색합니다.
2. 알아보기 쉬운 **이름**을 입력합니다. 에이전트가 언제 이곳을 검색할지 판단할 수 있도록 어떤 내용이 들어가는지 **설명**도 추가하세요.
3. **시작 방법** 아래에서 **비어 있음**, **폴더**(색인 및 동기화 유지) 또는 **파일** 중 하나를 선택합니다.
4. Claude나 Cursor 같은 MCP 클라이언트가 검색할 수 있게 하려면 **AI 클라이언트의 검색 허용**을 켭니다.
5. **만들기**를 클릭합니다. 폴더나 파일을 선택한 경우 버튼이 **만들고 가져오기** 또는 **만들고 추가**로 표시됩니다.

서로 관련 없는 프로젝트는 별도의 지식 베이스로 나누어 보관하세요. 지식 베이스 안에서는 폴더로 항목을 정리할 수 있습니다.

## 콘텐츠 추가하기

| 항목 | 용도 |
| --- | --- |
| **추가 → 메모** | 편집 가능한 새 Markdown 메모 |
| **추가 → 파일** | 이 Mac에 있는 지원되는 문서, 이미지, 오디오 또는 동영상 |
| **추가 → 단일 웹페이지** | 웹페이지 URL 하나의 콘텐츠 |
| **추가 → YouTube 동영상** | 동영상과 자막 |
| **추가 → 게시물** | X, Reddit, Hacker News, Bluesky, Zhihu 등의 게시물 |
| **추가 → 폴더 가져오기…** | 구조를 유지한 채 가져오는 로컬 폴더(자동 동기화 선택 가능) |
| **추가 → 새 폴더…** | 항목을 정리하기 위한 폴더 |
| 지식 베이스로 파일 드래그 또는 붙여넣기 | Finder에서 빠르게 가져오기 |
| [빠른 캡처](/ko/features/quick-capture) | 현재 앱의 콘텐츠 저장 |
| [음성 메모](/ko/features/voice-notes) | 음성 메모를 녹음하고 저장 |

문서 로더는 일반 텍스트, Markdown, PDF, Office, EPUB 및 구조화된 데이터 형식을 지원합니다. 이미지는 OCR로 읽고, 오디오와 동영상은 텍스트로 전사됩니다. 파싱 품질과 지원 형식은 선택한 로더 및 제공업체에 따라 달라집니다. 건너뛰었거나 실패한 파일이 있는지 가져오기 미리 보기와 각 항목의 상태를 확인하세요.

웹사이트 전체를 추가할 때 Enconvo는 해당 주소가 가리키는 섹션(예: 문서 사이트의 특정 영역) 안에서만 수집하며, 두 개의 주소로 발견된 동일 페이지는 한 번만 색인합니다.

## 지식 베이스 공유하기

이메일로 특정 사람에게 공유하거나 팀 전체와 공유할 수 있습니다. 사용자 본인과 공유받는 사람 모두 Enconvo 계정에 로그인되어 있어야 합니다.

<Steps>
  <Step title="공유 열기">
    지식 베이스의 **⋯** 메뉴를 열고 **공유…**를 선택합니다.
  </Step>
  <Step title="사용자 또는 팀 추가">
    **이메일로 사용자 추가**를 사용하거나, 팀원 모두와 공유하려면 팀 접근을 켭니다.
  </Step>
  <Step title="권한 선택">
    **보기 가능**, **추가 가능** 또는 **관리 가능** 중 선택합니다. 소유자와 관리 가능한 사용자만 접근 권한을 변경할 수 있습니다.
  </Step>
</Steps>

공유하면 해당 지식 베이스의 사본이 Enconvo Cloud에 저장됩니다. 그 지식 베이스에 담긴 내용만 Mac 밖으로 나가며, 메모리와 채팅 기록은 절대 공유되지 않습니다. 누군가 항목을 추가하면 몇 초 안에 모든 Mac에 반영되며 각 항목에 추가한 사람이 표시됩니다. 각 구성원의 Mac에 사본과 색인이 유지되므로 오프라인에서도 검색할 수 있습니다. 다른 사용자는 연결된 폴더를 보기만 할 수 있습니다. **활동**에는 무엇이 바뀌었고 누가 바꾸었는지 표시됩니다.

공유를 중지하려면 특정 사용자에 대해 **접근 권한 제거**를 사용하거나 **팀과 공유 중지**를 선택하세요.

## 항목 탐색 및 찾기

- **격자**, **목록**, **지도** 보기를 전환할 수 있습니다. 목록은 **유형**, **태그**, **폴더**, **상태**, **추가일** 열로 구성된 표입니다. 지도는 각 항목이 의미상 가장 가까운 항목들과 연결된 모습을 보여 줍니다.
- 항목 위의 **보관함** 메뉴에서 **모든 항목**, **최근 추가**, **태그 없음**, **확인 필요**를 개수와 함께 전환할 수 있습니다. 확인이 필요한 항목이 있으면 점이 표시됩니다.
- **필터**, **태그**, **유형**으로 표시 범위를 좁힐 수 있습니다.
- 목록에서 행을 체크해 이동, 태그 지정, 다시 색인, 삭제하거나 함께 묶어 채팅으로 질문할 수 있습니다.

## 연결된 폴더

1. **추가 → 폴더 가져오기…**를 선택합니다.
2. 원본 폴더를 선택하고 파일 수와 건너뛴 파일을 확인한 뒤 확정합니다.
3. 폴더를 선택해 세부 정보를 열면 원본 경로, 동기화 상태 및 제어 버튼이 표시됩니다.
4. **지금 동기화**를 클릭하거나, Enconvo가 실행되는 동안 변경 사항을 따라가도록 **자동 동기화**를 켭니다.

원본 폴더는 디스크에 그대로 남습니다. 새 파일과 변경된 파일은 가져오고, 원본에서 삭제한 파일은 지식 베이스에서도 제거됩니다. 숨김 파일, 지원되지 않는 형식, 50 MB를 넘는 파일은 건너뜁니다. Enconvo의 폴더 동기화는 원본 파일을 절대 수정하지 않습니다.

외장 드라이브가 분리되었거나 폴더가 이동된 경우 폴더에 **원본 폴더를 찾을 수 없습니다**가 표시되며 아무 항목도 삭제되지 않습니다. 드라이브를 다시 연결하거나 **다시 연결…**을 클릭해 새 위치를 선택하세요. 처리 및 동기화 문제 해결은 [지식 베이스 작동 방식](/ko/advanced/knowledge-base-advanced)을 참고하세요.

## 자료에 대해 질문하기

- **지식 베이스 안에서**: 상단의 **항목** 옆에서 **질문하기**를 클릭합니다. 채팅 창과 같은 채팅으로 열리며, 첫 질문에 지식 베이스가 첨부되고 후속 질문에서도 다시 검색되며 대화는 다른 채팅과 함께 저장됩니다. 새 질문을 시작하려면 **새 채팅**을 클릭하세요.
- **어떤 채팅에서든**: **@**를 입력하고 목록에서 지식 베이스나 그 안의 항목 하나를 선택합니다. 후속 질문을 이어 가는 동안에도 메시지 입력창 위에 유지되며 필요하면 제거할 수 있습니다. 칩을 클릭하면 지식 베이스에서 해당 항목이 열립니다.

예시:

> 첨부한 프로젝트 메모를 바탕으로 인증 관련 결정을 나열하고, 각 결정의 출처를 인용해 줘.

에이전트는 필요한 자료를 검색해 읽습니다. 검색 단계에서는 모든 문서를 통째로 보내는 대신 관련 단락을 골라냅니다. 중요한 세부 정보는 인용된 항목을 열어 직접 확인하세요. 특정 단락이 빠진 것 같다면 해당 항목을 직접 멘션하거나 색인이 완료되었는지 확인하세요.

## 지식 베이스 설정

지식 베이스 헤더의 톱니바퀴(**지식 베이스 설정**)를 클릭합니다.

| 섹션 | 포함 항목 |
| --- | --- |
| **일반** | 지식 베이스의 **이름** 및 **설명** |
| **색인 및 검색** | 확인이 필요한 항목, 검색 모델 및 전체 색인을 다시 만드는 **다시 색인…** |
| **소스 및 캡처** | **지금 동기화**, **자동 동기화**, **다시 연결…**이 있는 연결된 폴더와 빠른 캡처, 음성 메모, Chrome 확장 프로그램 바로 가기 |
| **AI 클라이언트 (MCP)** | AI 클라이언트가 이 지식 베이스를 검색할 수 있는지 여부. [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)를 참고하세요. |
| **고급** | **지식 베이스 ID** 및 **지식 베이스 삭제** |

기본 지식 베이스와 메모리는 삭제할 수 없습니다.

## 편집 및 유지 관리

메모를 열면 Markdown을 편집할 수 있습니다. 항목 및 폴더 메뉴에서 이름 변경, 이동, 태그 지정 또는 콘텐츠 제거를 할 수 있습니다. 제거 확인 안내를 잘 읽고 진행하세요. 지식 베이스에서 항목을 제거하는 것과 원본 파일을 삭제하는 것은 다른 작업이며, 연결된 폴더 전체를 제거해도 디스크의 파일은 건드리지 않습니다.

<Warning>
연결된 폴더에서 가져온 항목의 경우 항목 메뉴에 **휴지통으로 이동**이 표시됩니다. 이 작업을 실행하면 디스크의 실제 파일이 휴지통으로 이동한 뒤 지식 베이스에서도 항목이 사라집니다.
</Warning>

항목 처리에 실패하면 다시 시도하기 전에 추출에 실패했는지, 색인에 실패했는지 확인하세요. 검색 색인이 끝나기 전에도 문서를 읽을 수 있는 상태일 수 있습니다.

모든 지식 베이스는 **설정 → 메모리**의 **검색**에 설정된 동일한 검색 모델을 사용합니다. 이 Mac 또는 Enconvo Cloud에서 실행되며, 둘 사이를 전환해도 검색 색인은 유지됩니다. **색인 및 검색**의 **검색 설정…**을 누르면 해당 설정으로 이동합니다.

## 다른 AI 앱 연결하기

**지식 베이스 설정 → AI 클라이언트 (MCP)**를 열면 로컬 MCP 클라이언트가 선택한 지식 베이스를 검색하도록 허용할 수 있습니다. 이는 별도로 선택해 켜는 읽기 전용 서비스입니다. 설정과 공유 제어는 [지식 베이스 MCP](/ko/advanced/knowledge-base-mcp)를 따르세요.

## 데이터 처리

지식 베이스 파일과 색인은 로컬에 저장됩니다. 사용자가 선택한 클라우드 OCR, 음성 전사, 임베딩, 리랭킹 또는 채팅 제공업체는 해당 작업을 수행하는 데 필요한 콘텐츠를 받을 수 있습니다. 검색 모델이 Enconvo Cloud에서 실행될 때는 색인되거나 검색되는 텍스트가 그곳으로 전송됩니다. 파일을 로컬에 저장한다고 해서 제공업체 처리까지 오프라인으로 이루어지는 것은 아닙니다. 민감한 자료를 가져오기 전에 [개인정보 보호 및 보안](/ko/configuration/privacy-security)과 사용 중인 제공업체를 확인하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 항목에 색인 오류 표시 | **보관함 → 확인 필요**를 열어 추출 실패인지 색인 실패인지 확인한 뒤 항목을 다시 색인하세요. |
| 연결된 폴더에 **원본 폴더를 찾을 수 없습니다** 표시 | 드라이브를 다시 연결하거나 **다시 연결…**을 클릭해 폴더의 새 위치를 선택하세요. |
| 답변에서 특정 문서가 누락됨 | 문서 색인이 끝났는지 확인한 뒤 **@**로 해당 문서를 직접 멘션하세요. |
| 새 콘텐츠가 색인되지 않음 | 검색 모델이 Enconvo Cloud에서 실행 중이라면 로그인하세요. 로그인하기 전에는 새 콘텐츠가 색인되지 않으며 검색도 일치하는 단어만 찾습니다. |

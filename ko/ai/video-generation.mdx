**Text to Video**는 설명으로 클립을 만들고, **Image to Video**는 이미지에 생명을 불어넣습니다. 둘 다 **설정 → 동영상 생성**에서 지정한 동영상 제공업체를 사용하며, 이는 이미지 생성이나 채팅에 사용하는 모델과 별개입니다.

동영상 생성은 AI 영상을 만듭니다. 티저나 따라 하기 영상처럼 정확한 문구, 가격, 날짜, 인터페이스를 보여 줘야 하는 동영상은 대신 [움직임](/ko/features/motion)을 요청하세요.

<Warning>
각 클립은 제공업체의 크레딧 또는 Cloud 포인트를 사용하며 시간이 걸릴 수 있습니다. 새 제공업체를 써 볼 때는 짧은 클립부터 시작하세요.
</Warning>

## 시작하기 전에

1. **설정 → 동영상 생성**을 열고 제공업체를 선택합니다.
2. **자격 증명 제공자**(사용하는 키 또는 계정)와 **모델 이름**을 설정합니다.
3. **기본값으로 설정**을 클릭합니다.

Enconvo Cloud 제공업체인 **xAI (Enconvo Cloud)**와 **Google Gemini (Enconvo Cloud)**는 별도의 API 키가 필요 없습니다.

## 텍스트로 클립 만들기

1. SmartBar를 열고 설명을 입력한 다음 **Text to Video**를 실행합니다. 대상, 동작, 카메라 움직임, 장면을 설명하세요.
2. **Generating video...**가 표시되는 동안 기다립니다.
3. 결과에서 클립을 미리 보고, 붙여넣거나 복사하거나 Finder에서 표시합니다.

## 이미지를 애니메이션으로 만들기

1. 원본 이미지를 첨부하고, 무엇이 움직이고 무엇이 그대로인지 설명합니다.
2. **Image to Video**를 실행합니다. 설명과 이미지가 하나 이상 모두 필요합니다.
3. 클립을 미리 보고 저장합니다.

모델이 이미지 한 장 또는 제한된 길이만 지원한다면 그 한도에 맞춰 요청을 작성하세요.

## 채팅 옆에서 클립 편집

채팅에서 에이전트에게 클립을 요청하거나, 새 채팅의 메시지 입력란 아래에서 **동영상**을 선택합니다. 모델, 모델 설정, **제외**가 메시지 입력란 아래에 알약 모양으로 표시됩니다. 에이전트가 만든 클립을 클릭하면 채팅 옆의 동영상 편집기에서 열리며, 이어서 다음 변경 사항을 설명하면 됩니다.

- 설정 패널에는 길이, 해상도, 가로세로 비율, **제외**(제외할 내용)처럼 선택한 모델이 지원하는 항목만 표시됩니다.
- 타임라인의 프레임을 마우스 오른쪽 버튼으로 클릭하고 **시작 프레임으로 사용**, **끝 프레임으로 사용**, **이미지로 저장** 중에서 선택합니다.
- 모든 변경은 새 버전이 되며, 모든 클립은 [미디어](/ko/features/media)와 `~/Enconvo/Media`에 보관됩니다.

[미디어](/ko/features/media)에서는 각각 고유한 프롬프트와 길이를 가진 여러 샷으로 동영상을 구성하고 직접 가져온 오디오를 추가할 수도 있습니다.

## 제공업체와 옵션

[동영상 제공업체 카탈로그](/ko/providers/catalog)에는 xAI, Gemini, OpenRouter, PipeLLM, Kie.ai, Topview와 해당 Enconvo Cloud 버전이 포함됩니다. 모델마다 지원하는 입력과 해상도가 다릅니다. 예를 들어 Grok Imagine Video 1.5에는 기본 Grok Imagine Video 모델에 없는 1080p 옵션이 있고, Google Gemini의 기본 모델인 Gemini Omni 1.2 Flash는 최대 4K까지 3초에서 15초 길이의 동영상을 만듭니다.

**Text to Video**와 **Image to Video**는 모델의 기본 길이와 해상도를 사용합니다. 길이와 해상도를 직접 고르려면 채팅에서 에이전트에게 클립을 만들게 하고, 모델이 지원하는 옵션만 요청하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 요청이 제출되지 않음 | 제공업체의 액세스 권한과 요청한 옵션을 확인하세요 |
| 클립이 아직 처리 중임 | 유료 생성을 또 시작하기 전에 상태를 확인하세요 |
| 실패한 클립에 도움이 필요함 | 입력 내용과 반환된 오류 또는 상태를 보관하고, 자격 증명은 제외하고 공유하세요 |

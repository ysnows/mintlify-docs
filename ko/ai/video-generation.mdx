**Text to Video**는 설명을 바탕으로 클립을 만들고, **Image to Video**는 이미지에 움직임을 더합니다. 두 기능 모두 **설정 → 동영상 생성**에서 지정한 동영상 제공업체를 사용하며, 이는 이미지 생성이나 채팅 모델과는 별도로 설정됩니다.

동영상 생성은 AI 영상을 생성합니다. 티저나 워크스루처럼 정확한 문구, 가격, 날짜, 인터페이스를 보여줘야 하는 동영상이라면 대신 [Motion](/ko/features/motion)을 요청하세요.

<Warning>
클립을 생성할 때마다 제공업체의 크레딧이나 Enconvo Cloud 포인트가 소모되며 시간이 걸릴 수 있습니다. 새 제공업체를 테스트할 때는 짧은 클립부터 시작하세요.
</Warning>

## 시작하기 전에

1. **설정 → 동영상 생성**을 열고 제공업체를 선택합니다.
2. **자격 증명 제공자**(사용할 키 또는 계정)와 **모델 이름**을 설정합니다.
3. **기본값으로 설정**을 클릭합니다.

Enconvo Cloud 제공업체인 **xAI (Enconvo Cloud)**와 **Google Gemini (Enconvo Cloud)**는 별도의 API 키 없이 사용할 수 있습니다.

## 텍스트로 클립 만들기

1. SmartBar를 열고 설명을 입력한 뒤 **Text to Video**를 실행합니다. 피사체, 동작, 카메라 움직임, 장면을 구체적으로 적으세요.
2. **Generating video...**가 표시되는 동안 기다립니다.
3. 결과에서 클립을 미리 본 다음 붙여넣기, 복사 또는 Finder에서 보기를 선택할 수 있습니다.

## 이미지 애니메이션화하기

1. 원본 이미지를 첨부하고 무엇이 움직이고 무엇이 고정되는지 설명합니다.
2. **Image to Video**를 실행합니다. 설명과 최소 한 장 이상의 이미지가 필요합니다.
3. 클립을 미리 보고 저장합니다.

모델이 이미지 1장만 받거나 길이 제한이 있다면 그 범위 안에서 요청을 작성하세요.

## 채팅 옆에서 클립 편집하기

채팅에서 에이전트에게 클립을 요청하거나, 새 채팅의 메시지 상자 아래에서 **동영상**을 선택하세요. 선택한 모델, 설정, **제외** 항목이 메시지 상자 아래에 알약(pill) 형태로 표시됩니다. 에이전트가 만든 클립을 클릭하면 채팅 옆의 동영상 편집기가 열리며, 이어서 다음 수정 사항을 설명할 수 있습니다.

- 설정 패널에는 길이, 해상도, 화면 비율, **제외**(피할 요소) 등 선택한 모델이 지원하는 옵션만 표시됩니다.
- 타임라인의 프레임을 오른쪽 클릭해 **시작 프레임으로 사용**, **끝 프레임으로 사용**, 또는 **이미지로 저장**을 선택할 수 있습니다.
- 수정할 때마다 새 버전이 만들어지며, 모든 클립은 [미디어](/ko/features/media)와 `~/Enconvo/Media`에 보관됩니다.

[미디어](/ko/features/media)에서는 각자 프롬프트와 길이를 가진 여러 샷으로 동영상을 구성하고 직접 오디오를 추가할 수도 있습니다.

## 제공업체 및 옵션

[동영상 제공업체 카탈로그](/ko/providers/catalog)에는 xAI, Gemini, OpenRouter, PipeLLM, Kie.ai, Topview 및 각 Enconvo Cloud 버전이 포함되어 있습니다. 모델마다 지원하는 입력과 해상도가 다릅니다. 예를 들어 Grok Imagine Video 1.5는 기본 Grok Imagine Video 모델에 없는 1080p 옵션을 지원하며, 기본 Google Gemini 모델인 Gemini Omni 1.2 Flash는 최대 4K 해상도로 3~15초 길이의 동영상을 생성합니다.

**Text to Video**와 **Image to Video**는 모델의 기본 길이와 해상도를 사용합니다. 이를 직접 지정하려면 채팅에서 에이전트에게 클립 생성을 요청하되 해당 모델이 지원하는 옵션만 요청하세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 요청이 제출되지 않음 | 제공업체의 접근 권한과 요청한 옵션을 확인하세요 |
| 클립이 계속 처리 중임 | 다른 유료 생성을 시작하기 전에 현재 상태를 먼저 확인하세요 |
| 실패한 클립에 대한 도움이 필요함 | 입력 내용과 반환된 오류 또는 상태를 보관해 두고 자격 증명 정보를 제외하여 공유하세요 |

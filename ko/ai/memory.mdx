메모리는 사용자의 취향, 사용자에 관한 정보, 내린 결정 등 에이전트가 채팅을 넘어 계속 간직하는 짧은 사실들을 저장합니다. 모든 에이전트가 같은 메모리를 공유하며 매 채팅이 시작될 때 고정된 항목부터 우선 확인합니다. 메모리는 채팅 대화록이나 문서를 담는 [지식 베이스](/ko/ai/knowledge-base)와는 다릅니다.

이 동영상에서는 메모리, 내 정보, 지식 베이스, 빠른 캡처를 소개합니다.

<YouTubePlayer videoId="zvr6DJaZuJo" title="Enconvo에서 메모리와 지식 베이스 사용하기 | 단계별 튜토리얼" />

메모리는 [지식 베이스](/ko/ai/knowledge-base) 안에 보관됩니다. 채팅 창 사이드바에서 **지식 베이스**를 클릭한 뒤 열 상단의 **지식 베이스** / **메모리** 전환 스위치를 누르면 메모리를 볼 수 있습니다. 메모리는 일반 지식 베이스 목록에는 나타나지 않으며, 메모리 링크를 누르면 지식 베이스의 메모리 화면으로 바로 열립니다.

**설정 → 메모리** 상단에는 **에이전트가 활용할 수 있는 것** 항목으로 메모리, 채팅 기록, 녹음, 지식 베이스가 각각의 개수와 함께 표시됩니다.

## 메모리가 저장되는 방식

에이전트는 사용자에 대해 알게 된 내용을 바탕으로 메모리를 저장합니다. **채팅에서 자동으로 학습**이 켜져 있으면 Enconvo는 대화가 잠잠해진 시점(마지막 메시지 후 3분 경과 또는 새 메시지 6개가 대기 중일 때)에 채팅을 검토합니다. 이후 채팅에서도 유용한 정보만 추려 저장하며, 해당 채팅 끝에 **실행 취소** 버튼이 달린 메모리 카드가 나타납니다.

비밀 정보, 그룹 채팅, 일회성 작업은 학습에서 제외됩니다. 특히 다른 사람들이 답장을 함께 보는 메신저 그룹 채팅에는 메모리가 적용되지 않습니다.

직접 추가하려면 **설정 → 메모리**를 열고 **메모리 열기**를 클릭한 뒤 **추가 → 메모리**를 선택하세요.

## 메모리 검토 및 편집하기

1. **설정 → 메모리**에서 **메모리 열기**를 클릭하거나, 채팅 창에서 지식 베이스를 **메모리**로 전환합니다.
2. **필터**, **태그**, **유형**으로 목록을 좁히거나 **그리드**, **목록**, **지도** 보기 간에 전환합니다.
3. 메모리를 열어 내용과 학습된 원본 채팅을 확인합니다.
4. 부정확하거나 오래된 사실을 수정하거나, 확인 창을 거친 뒤 삭제합니다.
5. 모든 채팅에서 에이전트에게 항상 보여 줄 메모리는 오른쪽 클릭 후 **고정**을 선택하세요.

항목은 누구 또는 무엇에 관한 내용인지 분명하게 드러나도록 간결하고 사실 위주로 유지하세요.

## 개념과 지도 보기

**메모리 열기**에서 **지도**를 선택하면 메모리가 사람, 프로젝트, 장소, 주제별로 묶여 표시됩니다. 이 각각의 묶음을 개념(Concept)이라고 합니다.

1. 개념을 클릭하면 개요, 포함된 메모리, 관련 개념을 볼 수 있습니다.
2. **이것에 대해 질문**을 클릭하면 해당 개념에 대한 채팅이 바로 시작됩니다.
3. 아직 분류 대기 중인 메모리를 정리하려면 대기 개수가 표시된 **지금 … 분류** 버튼을 클릭하세요. **다시 만들기**는 모든 메모리를 처음부터 다시 분류합니다. 개념 이름은 유지되고 연결이 새로 맺어지며 빈 개념은 사라집니다.
4. **개념 제거**는 개념과 연결만 삭제하며, 포함된 메모리는 그대로 남습니다.

메모리 정리는 새로 생기거나 바뀐 메모리를 백그라운드에서 알맞은 개념 아래로 분류합니다. 사용자가 개념에 대해 물으면 에이전트가 해당 개념 전체를 읽으며, 채팅에서 수정 사항을 말하면 개념 이름을 바꾸거나 제거합니다. 또한 불러오기(Recall)는 질문의 단어와 다르더라도 사용자가 언급한 사람, 프로젝트, 주제 아래 분류된 메모리를 찾아냅니다.

## 설정

**설정 → 메모리**를 엽니다.

| 설정 | 기능 |
| --- | --- |
| **메모리** (상단 스위치) | 모든 에이전트에 대해 메모리를 켜거나 끕니다. 끄면 학습, 정리, 불러오기가 모두 중단되지만 기존 메모리는 다시 켤 때까지 그대로 보관됩니다. |
| **채팅에서 자동으로 학습** | 사용자에 관한 사실, 선호도, 작업 방식을 저장합니다. **최근 학습한 내용**에 저장된 항목과 **실행 취소** 버튼이 표시됩니다. |
| **메모리 정리** | Mac이 유휴 상태일 때 중복 항목을 합치고, 서로 어긋나는 두 메모리 중 더 최신 항목을 남기며, 날짜가 지난 계획을 갱신하고, 에이전트가 놓쳐서는 안 될 항목을 고정합니다. 모든 변경은 이전 버전을 보관합니다. |
| **빈도** | **매일** 또는 **매주** 정리합니다. **지금 정리**를 누르면 즉시 실행됩니다. |
| **이전 정리** | 최근 90일 동안 정리가 바꾼 모든 내용을 되돌릴 수 있습니다. |
| **방법 학습** | 메모리가 사실을 학습하는 것처럼 스킬도 사용자의 작업 방식을 학습할 수 있게 합니다. 각 변경 사항은 **실행 취소**와 함께 채팅에 표시되며, 메모리 검토 및 메모리 정리가 스킬도 함께 관리합니다. [스킬이 작업 방식을 학습하게 하기](/ko/configuration/skills)를 참고하세요. |
| **불러오기** | 답변에 사용자가 말하거나 저장한 내용이 필요할 때 에이전트가 찾아보는 대상입니다: **메모리**(항상 켜짐), **채팅 기록**, **녹음**, **지식 베이스**. |
| **검색** | 메모리, 채팅, 녹음, 지식 베이스를 인덱싱하는 임베딩 모델입니다: **이 Mac** 또는 **Enconvo Cloud**. |
| **메모리 모델** | 학습과 정리를 수행하는 경량 모델로, 해당 제공업체의 일반 요청과 동일하게 과금됩니다. |

## 내 정보

모든 에이전트에게 나에 대해 알려 주려면 **설정 → 내 정보**를 여세요. 모든 에이전트, 음성 통화, 아바타가 이 정보를 사용합니다.

| 항목 | 용도 |
| --- | --- |
| **선호하는 이름** | 에이전트가 사용자를 부를 이름 또는 별명입니다. |
| **프로필 설명** | 사용자와 하는 일에 대한 간단한 설명입니다. 응답 개인화에 사용되길 원하는 내용만 적으세요. |
| **응답 언어** | 에이전트가 답변하는 언어입니다. 특정 에이전트에만 다른 언어를 지정하려면 해당 에이전트 설정의 **동작** 아래에서 응답 언어를 바꾸세요. |

## 메모리를 의도적으로 활용하기

자체 설정에서 **메모리 활성화**가 꺼져 있는 에이전트는 메모리를 사용하지 않습니다. 어떤 사실이 실제로 활용되는지 확인하려면 저장·회상을 막연히 가정하지 말고 새 채팅을 열어 그 사실이 필요한 평범한 질문을 던져 보세요.

다시 입력하기 번거롭다는 이유로 자격 증명이나 민감한 정보를 저장하지 마세요. 에이전트와 제공업체 설정에 따라 불러온 메모리가 모델 요청에 포함될 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변이 오래된 사실을 사용함 | 한 답변만 바로잡지 말고 **메모리 열기**에서 해당 메모리를 찾아 수정하거나 삭제하세요. 현재 대화의 컨텍스트도 함께 확인하세요. |
| 에이전트가 아무것도 기억하지 못함 | **설정 → 메모리**에서 **메모리**가 켜져 있는지, 해당 에이전트의 **메모리 활성화**가 켜져 있는지 확인하세요. 메신저 그룹 채팅에서는 메모리를 사용하지 않습니다. |
| Enconvo가 원하지 않는 내용을 저장함 | 채팅 끝에 있는 메모리 카드나 **설정 → 메모리**의 **최근 학습한 내용** 아래에서 **실행 취소**를 클릭하세요. |
| 정리가 원하던 메모리를 바꿈 | **설정 → 메모리**에서 **이전 정리**를 열어 변경을 되돌리세요. |

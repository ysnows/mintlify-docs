메모리에는 에이전트가 채팅 전반에 걸쳐 기억하는 짧은 사실이 담깁니다. 선호하는 방식, 사용자에 관한 사실, 내린 결정 등이 그 예입니다. 모든 에이전트가 같은 메모리를 공유하며, 각 채팅이 시작될 때 고정된 메모리를 먼저 보여 줍니다. 메모리는 채팅 기록과도, 문서로 이루어진 [지식 베이스](/ko/ai/knowledge-base)와도 다릅니다.

이 동영상에서는 메모리, 내 정보, 지식 베이스, 빠른 캡처를 보여 줍니다.

메모리는 [지식 베이스](/ko/ai/knowledge-base) 안에 있습니다. 채팅 창의 사이드바에서 **지식 베이스**를 클릭하고, 열 상단의 **지식 베이스** / **메모리** 스위치로 메모리를 확인합니다. 메모리는 지식 베이스 목록에 표시되지 않으며, 메모리로 연결되는 링크는 메모리가 선택된 지식 베이스를 엽니다.

**설정 → 메모리** 상단에는 **에이전트가 활용할 수 있는 것**이 표시됩니다. 메모리, 채팅 기록, 녹음, 지식 베이스와 각각의 개수입니다.

## 메모리가 저장되는 방식

에이전트는 사용자에 대해 알게 되는 대로 메모리를 저장합니다. **채팅에서 자동으로 학습**을 켜면 Enconvo는 채팅이 잠잠해진 뒤, 즉 마지막 메시지 3분 후 또는 새 메시지 6개가 쌓인 시점에 채팅을 검토합니다. 이후 채팅에서 중요해질 내용을 보관하며, **설정 → 메모리**의 **최근 학습한 내용**에는 각 변경 사항이 **실행 취소**와 함께 나열됩니다.

학습할 때는 비밀 정보, 그룹 채팅, 일회성 작업을 건너뜁니다. 다른 사람들이 답변을 읽는 IM 그룹 채팅에서는 메모리를 사용하지 않습니다.

직접 추가하려면 **설정 → 메모리**를 열고 **메모리 열기**를 클릭한 다음 **추가 → 메모리**를 선택합니다.

## 메모리 검토 및 편집

1. **설정 → 메모리**를 열고 **메모리 열기**를 클릭하거나, 채팅 창에서 지식 베이스를 **메모리**로 전환합니다.
2. **필터**, **태그**, **유형**으로 목록을 좁히거나 **그리드**, **목록**, **지도** 사이를 전환합니다.
3. 메모리를 열어 내용과 그 메모리를 학습한 채팅을 확인합니다.
4. 부정확하거나 오래된 사실은 수정하거나, 확인 메시지를 검토한 뒤 삭제합니다.
5. 모든 채팅에서 에이전트에게 메모리를 보여 주려면 메모리를 마우스 오른쪽 버튼으로 클릭하고 **고정**을 선택합니다.

항목은 간결하고 사실에 근거하며, 누구 또는 무엇에 관한 것인지 구체적으로 작성하세요.

## 개념과 지도

**메모리 열기**에서 **지도**를 선택하면 메모리가 그 대상인 사람, 프로젝트, 장소, 주제별로 묶여 표시됩니다. 이러한 각각을 개념이라고 합니다.

1. 개념을 클릭하면 개요, 해당 메모리, 관련 개념을 볼 수 있습니다.
2. **이것에 대해 질문**을 클릭하면 그 개념에 대한 채팅이 시작됩니다.
3. 아직 분류를 기다리는 메모리를 정리하려면 대기 중인 개수가 표시된 **지금 … 정리** 버튼을 클릭합니다. **다시 만들기**는 모든 메모리를 다시 분류합니다. 개념의 이름은 유지되고, 링크는 다시 만들어지며, 비어 있는 개념은 사라집니다.
4. **개념 제거**는 개념과 그 링크를 제거합니다. 해당 메모리는 그대로 남습니다.

메모리 정리는 새 메모리와 변경된 메모리를 백그라운드에서 개념별로 분류합니다. 개념에 대해 질문하면 에이전트가 그 개념 전체를 읽고, 채팅에서 개념을 바로잡으면 이름을 바꾸거나 제거합니다. 또한 불러오기는 질문과 표현이 달라도, 사용자가 언급한 사람, 프로젝트, 주제로 분류된 메모리를 찾아냅니다.

## 설정

**설정 → 메모리**를 엽니다.

| 설정 | 기능 |
| --- | --- |
| **메모리**(상단 스위치) | 모든 에이전트에 대해 메모리를 켜거나 끕니다. 꺼져 있으면 아무것도 학습하거나, 정리하거나, 불러오지 않으며, 다시 켤 때를 위해 메모리는 보존됩니다. |
| **채팅에서 자동으로 학습** | 사용자에 관한 사실, 선호하는 방식, 일을 처리하는 방식을 저장합니다. **최근 학습한 내용**에 저장된 내용이 **실행 취소**와 함께 나열됩니다. |
| **메모리 정리** | Mac이 유휴 상태일 때 중복을 합치고, 서로 어긋나는 두 메모리 중 더 새로운 쪽을 유지하고, 날짜가 지난 계획을 업데이트하고, 에이전트가 절대 놓치면 안 되는 내용을 고정합니다. 모든 변경은 이전 버전을 보존합니다. |
| **빈도** | **매일** 또는 **매주** 정리합니다. **지금 정리**를 누르면 즉시 실행합니다. |
| **이전 정리** | 최근 90일 이내에 정리가 변경한 내용을 되돌립니다. |
| **방법 학습** | 메모리가 사실을 학습하듯, 스킬이 사용자가 선호하는 작업 방식을 학습하게 합니다. 각 변경은 채팅에 **실행 취소**와 함께 표시되며, 메모리 검토와 메모리 정리는 스킬도 함께 관리합니다. [스킬이 내 작업 방식을 학습하게 하기](/ko/configuration/skills)를 참고하세요. |
| **불러오기** | 답변에 사용자가 말했거나 저장한 내용이 필요할 때 에이전트가 찾아보는 위치: **메모리**(항상 켜짐), **채팅 기록**, **녹음**, **지식 베이스**. |
| **검색** | 메모리, 채팅, 녹음, 지식 베이스를 색인하는 임베딩 모델: **이 Mac** 또는 **Enconvo Cloud**. |
| **메모리 모델** | 학습과 정리를 실행하는 경량 모델이며, 해당 제공업체의 다른 요청과 같은 방식으로 청구됩니다. |

## 내 정보

모든 에이전트에게 자신에 대해 알리려면 **설정 → 내 정보**를 여세요. 모든 에이전트, 음성 통화, 아바타가 이 정보를 사용합니다.

| 필드 | 용도 |
| --- | --- |
| **선호하는 이름** | 에이전트가 어떻게 불러야 할지 알 수 있도록 이름 또는 별명을 입력합니다. |
| **프로필 설명** | 자신과 하는 일에 대한 간단한 소개입니다. 답변을 맞춤화하는 데 사용하려는 내용만 추가하세요. |
| **응답 언어** | 에이전트가 답하는 언어입니다. 특정 에이전트에 다른 언어를 지정하려면 해당 에이전트 설정의 **동작**에서 응답 언어를 변경하세요. |

## 메모리를 의도적으로 사용하기

자체 설정에서 **메모리 사용**이 꺼져 있는 에이전트는 메모리를 사용하지 않습니다. 사실이 다시 사용되는지 확인하려면 저장되었거나 불러와졌을 것이라고 가정하지 말고, 새 채팅을 시작해 그 사실이 필요한 일반적인 질문을 해 보세요.

다시 입력하기 번거롭다는 이유로 인증 정보나 민감한 정보를 저장하지 마세요. 에이전트와 제공업체 설정에 따라 모델 요청에 불러온 메모리가 포함될 수 있습니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 답변에 오래된 사실이 사용됨 | 답변 하나만 바로잡지 말고 **메모리 열기**에서 해당 메모리를 찾아 수정하거나 삭제하세요. 현재 대화의 컨텍스트도 확인하세요. |
| 에이전트가 아무것도 기억하지 못함 | **설정 → 메모리**에서 **메모리**가 켜져 있는지, 그리고 해당 에이전트의 **메모리 사용**이 켜져 있는지 확인하세요. IM 그룹 채팅에서는 메모리를 전혀 사용하지 않습니다. |
| Enconvo가 원치 않는 내용을 저장함 | **설정 → 메모리**의 **최근 학습한 내용**에서 **실행 취소**를 클릭하세요. |
| 정리가 원하던 메모리를 변경함 | **설정 → 메모리**에서 **이전 정리**를 열고 변경을 되돌리세요. |

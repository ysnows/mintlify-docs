Enconvo에는 음성을 위한 두 가지 명령이 있습니다. **소리 내어 읽기**는 Dynamic Island의 소리 내어 읽기 플레이어에서 텍스트를 읽어 줍니다. **TTS(Text To Speech)**는 선택한 제공업체로 텍스트를 오디오 파일로 만듭니다. 대화 안에서 채팅 답변을 바로 읽어 주게 할 수도 있습니다.

## 채팅 답변 소리 내어 읽기

답변 아래의 스피커 버튼을 클릭하세요. 버튼이 일시 정지, 재개, 정지가 있는 작은 플레이어로 바뀌고, 읽고 있는 문장이 답변에서 강조 표시됩니다. 한 번에 하나의 답변만 읽으며, 채팅을 닫으면 멈춥니다.

모든 답변을 소리 내어 읽게 하려면 Smart Bar나 채팅 창에서 답변 읽어주기를 켜세요. 각 창은 자체 설정을 유지합니다.

## 텍스트 소리 내어 읽기

1. **설정 → 텍스트 음성 변환**을 열고 제공업체와 음성을 설정합니다.
2. 텍스트를 선택하고 **소리 내어 읽기**를 실행합니다.
3. Dynamic Island의 플레이어가 문장 단위로 읽습니다. 일시 정지, 재개, 정지, 앞뒤로 건너뛰기, 속도나 음성 변경, 현재 문장을 강조 표시한 텍스트 보기를 사용할 수 있습니다.
4. 제공업체가 지원하면 제공업체 설정에서 음성이나 속도를 조정하세요.

[아바타](/ko/features/avatar)가 열려 있으면 립싱크와 함께 텍스트를 읽으며, 플레이어는 Dynamic Island에서 작게 유지됩니다.

## 오디오 파일 만들기

읽게 할 텍스트로 **TTS(Text To Speech)**를 실행하세요. 제공업체가 제공하는 음성, 속도, 출력 형식을 확인한 다음 생성된 파일을 열어 발음과 속도를 확인하세요.

[TTS 제공업체 카탈로그](/ko/providers/catalog)에는 Enconvo Cloud, 직접 연결 서비스, macOS 시스템, 로컬 옵션이 나열되어 있습니다. **Enconvo Cloud Voice**는 Enconvo Cloud 자체 음성으로, API 키 없이 60개가 넘는 언어를 지원합니다. DeepSeek은 내 DeepSeek API 키 또는 **DeepSeek (Enconvo Cloud)**로 여성(Stella) 또는 남성(Tide) 음성으로 텍스트를 읽습니다. 제어 기능은 제공업체마다 다릅니다. 스타일 지침이나 표현 태그를 받는 곳도 있고, 고정된 음성 목록만 제공하는 곳도 있습니다.

## 음성 복제하기

ElevenLabs, Fish Audio, Gemini, Qwen3는 음성을 복제할 수 있습니다. **설정 → 텍스트 음성 변환**의 제공업체 목록에 배지가 표시됩니다.

1. **설정 → 텍스트 음성 변환**을 열고 이 제공업체 중 하나를 고른 다음 **음성 복제** 탭을 엽니다.
2. 녹음 파일을 업로드하거나 **녹음**을 클릭하고 표시되는 텍스트를 읽습니다. 카운트다운은 취소할 수 있고, 레벨 미터가 목소리를 따라가며, 한 번의 녹음은 5분 후 자동으로 끝납니다.
3. 복제된 음성을 재생해 보고, 같은 탭에서 사용하거나 이름을 바꾸거나 삭제합니다.

이 제공업체의 **음성** 메뉴 옆에 있는 **음성 복제**를 클릭해도 됩니다. 복제한 음성은 **음성** 메뉴 맨 위에 표시되며, 여기서도 이름을 바꾸거나 삭제할 수 있습니다.

탭에는 해당 제공업체에서 남은 클라우드 음성 수가 표시됩니다. 한도에 도달하면 하나를 삭제해야 다른 음성을 복제할 수 있습니다. 녹음 중에 설정 창을 닫으면 녹음이 멈추고 그때까지 녹음된 내용은 유지됩니다.

## 로컬 음성과 클라우드 음성

로컬 제공업체는 내 Mac에서 실행되며 지원되는 하드웨어와 모델 파일이 필요합니다. Kokoro와 Qwen3는 MLX에서 실행되고, 영어 음성인 Phonon은 Apple 실리콘과 macOS 15 이상이 있는 Mac의 Core ML에서 실행됩니다. **시스템**은 macOS에 내장된 음성을 사용합니다. API 키가 필요 없는 곳을 포함해 온라인 제공업체는 텍스트를 네트워크로 전송합니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 소리가 나지 않음 | 시스템 출력 장치와 재생이 일시 정지되어 있지 않은지 확인하세요. |
| 생성 실패 | 제공업체 접근 권한과 텍스트의 길이 및 형식을 확인하세요. |
| 소리 내어 읽기가 멈추고 제공업체에 API 키가 없다고 표시됨 | **설정 → 텍스트 음성 변환**에서 키를 추가하거나, Enconvo Cloud나 내 Mac에서 실행되는 음성을 고르세요. |
| 이름이 잘못 발음됨 | 더 짧은 샘플로 테스트하고 제공업체의 발음 또는 스타일 제어를 사용해 보세요. |

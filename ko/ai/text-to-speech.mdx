description: "Enconvo가 텍스트를 소리 내어 읽게 하거나, 텍스트를 오디오 파일로 만듭니다."
---

Enconvo에는 음성용 명령이 두 가지 있습니다. **소리 내어 읽기**는 Dynamic Island의 소리 내어 읽기 플레이어에서 텍스트를 읽어 줍니다. **TTS(Text To Speech)**는 선택한 제공업체로 텍스트를 오디오 파일로 만듭니다. 채팅 답변도 대화 안에서 바로 들을 수 있습니다.

## 채팅 답변을 소리 내어 듣기

답변 아래의 스피커 버튼을 클릭합니다. 버튼이 일시 정지, 재생, 정지가 있는 작은 플레이어로 바뀌고, 읽고 있는 문장이 답변 안에서 강조됩니다. 한 번에 하나의 답변만 읽히며, 채팅을 닫으면 읽기가 멈춥니다.

모든 답변을 소리 내어 듣으려면 SmartBar 또는 채팅 창에서 답변 소리 내어 읽기를 켜세요. 창마다 설정이 따로 있습니다.

## 텍스트를 소리 내어 읽기

1. **설정 → 텍스트 음성 변환**을 열고 제공업체와 음성을 설정합니다.
2. 텍스트를 선택하고 **소리 내어 읽기**를 실행합니다.
3. Dynamic Island의 플레이어가 문장마다 읽습니다. 일시 정지, 재생, 정지, 뒤로 또는 앞으로 건너뛰기, 속도나 음성 바꾸기, 현재 문장이 강조된 텍스트 보기에 사용합니다.
4. 제공업체가 지원하면 설정에서 음성이나 속도를 조정합니다.

[아바타](/ko/features/avatar)가 열려 있으면 입 싱크에 맞춰 텍스트를 읽고, 플레이어는 Dynamic Island에 압축되어 남습니다.

## 오디오 파일 만들기

음성으로 말하고 싶은 텍스트로 **TTS(Text To Speech)**를 실행합니다. 제공하는 제공업체, 음성, 속도, 출력 형식을 확인한 다음, 생성된 파일을 열어 발음과 어조를 확인합니다.

[TTS 제공업체 카탈로그](/ko/providers/catalog)는 Enconvo Cloud, 직접 서비스, macOS 시스템, 로컬 옵션을 나열합니다. **Enconvo Cloud Voice**는 Enconvo Cloud 자체 음성으로, API 키 없이 60개 이상의 언어를 지원합니다. DeepSeek는 여성(Stella) 또는 남성(Tide) 음성으로 텍스트를 읽으며, 본인의 DeepSeek API 키를 쓰거나 **DeepSeek (Enconvo Cloud)**로 사용합니다. 제어는 제공업체마다 다릅니다. 어떤 제공업체는 스타일 지시나 표현 태그를 받고, 다른 제공업체는 고정된 음성 목록만 제공합니다.

## 음성 복제

ElevenLabs, Fish Audio, Gemini, Qwen3는 음성을 복제할 수 있습니다. **설정 → 텍스트 음성 변환**의 제공업체 목록에 배지가 표시됩니다.

1. **설정 → 텍스트 음성 변환**을 열고 이 제공업체 중 하나를 선택한 다음 **음성 복제** 탭을 엽니다.
2. 녹음을 업로드하거나 **녹음**을 클릭하고 화면에 나온 텍스트를 읽습니다. 카운트다운은 취소할 수 있고, 레벨 미터가 목소리를 따르며, 한 번의 녹음은 5분 후 자동으로 끝납니다.
3. 복제한 음성을 재생한 다음, 같은 탭에서 사용하거나 이름을 바꾸거나 삭제합니다.

이 제공업체의 **음성** 메뉴 옆에 있는 **음성 복제**를 클릭해도 됩니다. 복제한 음성은 **음성** 메뉴 위에 나오며, 그곳에서도 이름을 바꾸거나 삭제할 수 있습니다.

탭은 해당 제공업체에서 남은 Cloud 음성 수를 보여 줍니다. 한도에 도달하면 하나를 삭제해야 다시 복제할 수 있습니다. 녹음 중에 설정 창을 닫으면 녹음이 멈추고 그때까지 녹음된 내용이 남습니다.

## 로컬 음성과 클라우드 음성

로컬 제공업체는 Mac에서 실행되며 지원되는 하드웨어와 모델 파일이 필요합니다. Kokoro와 Qwen3는 MLX에서 실행되고, 영어 음성인 Phonon은 Apple silicon이 있고 macOS 15 이상인 Mac에서 Core ML로 실행됩니다. **시스템**은 macOS에 내장된 음성을 사용합니다. API 키가 필요 없는 것을 포함해 온라인 제공업체는 텍스트를 네트워크로 보냅니다.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 소리가 없음 | 시스템 출력 장치와 재생이 일시 정지되었는지 확인합니다. |
| 생성 실패 | 제공업체 접근 권한과 텍스트 길이·형식을 확인합니다. |
| 소리 내어 읽기가 멈추며 제공업체에 API 키가 없다고 함 | **설정 → 텍스트 음성 변환**에서 키를 추가하거나, Enconvo Cloud나 Mac에서 실행되는 음성을 고릅니다. |
| 이름 발음이 잘못됨 | 더 짧은 샘플로 시험하고, 제공업체의 발음이나 스타일 제어를 시도해 보세요. |

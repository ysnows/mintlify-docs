채팅 내용을 비공개로 유지하거나 제공업체 계정 없이 작업하고 싶을 때는 Mac이나 소유한 다른 컴퓨터에서 모델을 실행하세요. Enconvo에는 내장 엔진이 포함되어 있으며, Ollama 및 LM Studio와도 연결할 수 있습니다.

## 런타임 선택

| 런타임 | 적합한 용도 | 설정 방법 |
| --- | --- | --- |
| [Local LLM (MLX)](/ko/providers/mlx) | macOS 15 이상의 Apple Silicon Mac에서 Enconvo 내부에서 모델 실행 | 설정에서 모델을 선택하고 다운로드 |
| [Ollama](/ko/providers/ollama) | 이 Mac이나 서버에서 이미 Ollama로 관리 중인 모델 사용 | Ollama를 실행하고 주소 설정 |
| [LM Studio](/ko/providers/lm-studio) | 이 Mac이나 서버에서 이미 LM Studio로 사용 중인 모델 사용 | LM Studio 서버를 실행하고 주소 설정 |

## 작게 시작하기

1. 런타임을 설정하고 모델을 다운로드하거나 불러옵니다.
2. 짧은 텍스트 메시지를 보내 봅니다.
3. 정상 동작을 확인한 뒤 문서나 도구를 추가합니다.
4. 더 큰 모델을 시도하기 전에 메모리 사용량과 속도를 확인하세요. **설정 → 로컬 모델**에서 이 Mac에 있는 모델과 메모리 사용량을 볼 수 있습니다.

모델 크기, 양자화(quantization), 컨텍스트 길이, 실행 중인 다른 작업이 모두 메모리에 영향을 줍니다. 고정된 기준 대신 모델 선택기에 표시되는 용량을 참고하세요.

## 전체 작업을 로컬로 유지하기

로컬 채팅 모델만으로는 모든 작업이 Mac 안에 머무르지 않습니다. 음성 인식, 텍스트 음성 변환, OCR, 문서 파싱, 임베딩, 리랭킹, 검색, MCP 도구는 각각 자체 제공업체를 사용합니다. Enconvo는 이 중 여러 기능에 대해 로컬 제공업체를 지원하며, [제공업체 카탈로그](/ko/providers/catalog)에서 목록을 확인할 수 있습니다.

**설정 → 로컬 모델**에서는 어떤 기능이 이 Mac에서 실행되고 어떤 기능이 클라우드에서 실행되는지 보여 줍니다. 웹 검색 등 온라인 서비스는 여전히 인터넷이 필요하며, 로컬 모델도 Mac 밖으로 콘텐츠를 보내는 도구를 호출할 수 있습니다.

## 다른 컴퓨터의 모델 서버 사용하기

서버가 네트워크 연결을 허용하도록 설정한 뒤, Enconvo의 **BaseUrl**에 해당 컴퓨터의 주소를 입력합니다. `localhost`는 항상 Enconvo가 실행 중인 Mac을 가리킵니다. macOS가 연결을 차단하면 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Enconvo를 허용하세요.

## 다른 모델 서버 사용하기

llama.cpp, vLLM, KoboldCpp, text-generation-webui 같은 서버를 연결하려면 **설정 → AI 모델** 하단에서 **새 제공업체 추가**를 클릭하고 **OpenAI 호환**을 선택하세요. 기본 URL에 서버 주소를 붙여 넣으면 `/v1` 포함 여부나 전체 엔드포인트 주소 모두 Enconvo가 인식합니다. 서버가 키를 확인하지 않는다면 API 키는 비워 두세요.

## 작은 컨텍스트에서의 긴 채팅

로컬 서버는 모델이 지원하는 최대치보다 작은 컨텍스트 크기로 모델을 실행하는 경우가 많습니다. Enconvo는 Ollama, llama.cpp, LM Studio, KoboldCpp, text-generation-webui가 실제로 실행 중인 컨텍스트 크기를 읽어 이에 맞게 채팅을 압축합니다. 컨텍스트가 작을 때는 긴 채팅을 부분적으로 요약합니다. 모델에 더 많은 여유를 주려면 서버 자체 설정에서 컨텍스트 길이를 높이세요.

## 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 모델이 긴 채팅의 앞부분을 잊어버림 | 서버가 작은 컨텍스트로 실행 중입니다. 서버 설정에서 컨텍스트 길이를 높이거나 새 채팅을 시작하세요. |
| 모델이 도구나 이미지를 무시함 | 해당 모델이 도구 호출이나 이미지 입력을 지원하지 않으므로 Enconvo가 이를 제외하고 응답합니다. 도구 호출이나 이미지 입력을 지원하는 모델을 선택하세요. |
| 연결이 실패함 | 오류 메시지를 확인하세요. Enconvo는 서버가 반환한 메시지와 원인을 그대로 표시합니다. 서버가 실행 중인지, 주소와 포트가 올바른지 확인하세요. |

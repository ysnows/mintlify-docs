Enconvo kann dir sagen, wenn eine Agenten-Sitzung endet, indem es Dynamic Island öffnet, eine macOS-Mitteilung sendet oder beides. Das richtest du unter **Einstellungen → Mitteilungen** ein, zusammen mit Ruhezeiten für die Zeiten, in denen du nicht unterbrochen werden willst.

## Hinweise zum Abschluss einrichten

1. Öffne **Einstellungen → Mitteilungen**.
2. Wenn die Seite **Mitteilungen sind für Enconvo ausgeschaltet** sagt, klicke auf **Aktivieren** oder erlaube Enconvo unter **Systemeinstellungen → Mitteilungen**.
3. Schalte unter **Bei Sitzungsende** jeden Schalter ein oder aus. Sie wirken unabhängig voneinander.
4. Starte eine kurze Agenten-Anfrage und warte, bis sie fertig ist.

| Einstellung | Wirkung |
| --- | --- |
| **Dynamic Island öffnen** | Wenn eine Sitzung endet, die du aus Dynamic Island gestartet hast, klappt die Insel auf und zeigt das Ergebnis. |
| **Systemmitteilung senden** | Sendet eine macOS-Mitteilung mit dem Anfang der Antwort, wenn eine Sitzung endet. Klicke auf die Mitteilung, um die Sitzung in dem Fenster wieder zu öffnen, in dem sie begonnen hat. |

Fokus und die Mitteilungseinstellungen von macOS können Banner ausblenden, auch wenn diese Schalter an sind.

## Ruhezeiten

Ruhezeiten halten Fragen von Agenten, E-Mail-Benachrichtigungen und erledigte Aufgaben zurück, bis die Ruhezeit endet, auf diesem Mac und auf deinem gekoppelten iPhone. Während sie warten, wird nichts für dich freigegeben.

1. Suche unter **Einstellungen → Mitteilungen** nach **Neuigkeiten**.
2. Schalte **Ruhezeiten** ein und setze dann **Beginn** und **Ende**.
3. Wähle, was trotzdem durchkommt:

| Einstellung | Wirkung |
| --- | --- |
| **Freigaben trotzdem melden** | Freigabeanfragen erreichen dich auch in den Ruhezeiten. |
| **Fragen trotzdem melden** | Fragen von Agenten erreichen dich auch in den Ruhezeiten. |

Das Menü von Enconvo in der Menüleiste hat ebenfalls **Ruhezeiten** und **Neuigkeiten 1 Stunde pausieren** für eine kurze Pause.

E-Mail-Benachrichtigungen sind aus, bis du sie unter **Geplante Aufgaben → Wichtige Mails** einschaltest. E-Mail-Benachrichtigungen, die du schon eingeschaltet oder eingerichtet hast, bleiben aktiv. Ihr Schalter **Telefon** sendet Hinweise an ein gekoppeltes iPhone oder Android-Telefon.

## Geplante Ergebnisse

Eine Systemmitteilung ist etwas anderes, als das Ergebnis einer geplanten Aufgabe an Telegram oder einen anderen IM-Chat zu senden. Die Zustellung des Ergebnisses stellst du im Editor der [geplanten Aufgabe](/de/workflows/scheduled-jobs) ein.

Eine geplante Aufgabe kann auch eine eigene Mac-Mitteilung senden, wenn sie läuft (**Bei Ausführung benachrichtigen**). Diese Mitteilung folgt ebenfalls **Systemmitteilung senden**. Der Verlauf der Aufgabe zeigt, ob jeder Lauf geklappt hat und ob das Ergebnis zugestellt wurde.

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Kein Banner, wenn eine Sitzung endet | Prüfe, dass **Systemmitteilung senden** an ist, dass macOS Mitteilungen von Enconvo erlaubt und dass Fokus sie nicht ausblendet. |
| Dynamic Island hat sich nicht geöffnet | **Dynamic Island öffnen** gilt nur für Sitzungen, die du aus Dynamic Island gestartet hast. |
| Eine Frage oder erledigte Aufgabe kam verspätet | Ruhezeiten haben sie vielleicht zurückgehalten. Schalte **Fragen trotzdem melden** ein oder ändere **Beginn** und **Ende**. |

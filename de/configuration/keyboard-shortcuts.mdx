Die Fenster und Sprachfunktionen von Enconvo öffnen sich jeweils mit einem Tastenkürzel. **Einstellungen → Tastenkürzel** listet jedes Tastenkürzel, das Enconvo nutzt, und den Befehl, den es ausführt, damit du eines ändern oder herausfinden kannst, was eine Tastenkombination tut. Die auf deinem Mac gespeicherten Tastenkürzel gewinnen immer über die Standards in dieser Anleitung.

Dieses Video behandelt Tastenkürzel und dann die anderen Einstellungen, die Enconvo an deinen Mac anpassen: Kontextverständnis, Appshots, lokale Modelle, Berechtigungen und Ruhezustand verhindern.

## Standardkürzel

| Aktion | Standard |
| --- | --- |
| SmartBar anzeigen | **⌥Space** |
| Chatfenster anzeigen | **⌃⌘X** |
| App-Seitenleiste anzeigen | **⌃⌘E** |
| Einstellungen öffnen, aus Enconvo heraus | **⌘,** |
| Diktat starten | **Rechte ⌘** |
| Sprachbefehl starten | **Rechte ⌥** |
| Audio pausieren/fortsetzen | **⌥P** |

Diese Standards gelten nur, wenn du nie eine eigene Taste gesetzt hast; eine gesetzte Taste bleibt, wie sie ist. Schnellerfassung und Appshots haben kein Standardkürzel: Setze eines auf ihren Einstellungsseiten, bevor du sie nutzt.

## Ein Tastenkürzel ändern

1. Öffne **Einstellungen → Tastenkürzel**. Der Tab **Kernfunktionen** hält die Hauptfunktionen, **Weitere Tastenkürzel** hält KI-Befehle, Plugins, Einstellungen und Befehle, die keine andere Seite zeigt, und **Alle** zeigt beides.
2. Tippe in **Nach Namen filtern…**, um einen Befehl zu finden. Um den Befehl hinter einer Tastenkombination zu finden, klicke auf **Nach Tastenkürzel suchen** und drücke sie.
3. Klicke das Tastenkürzelfeld des Befehls und drücke die neue Kombination.
4. Führen diese Tasten schon einen anderen Befehl aus, sagt das das Feld. Wähle **Hier verwenden**, um die Tasten auf diesen Befehl zu legen, oder wähle eines der freien Tastenkürzel, die es vorschlägt.
5. Wechsle in eine andere App und probiere das Tastenkürzel.

Um die Tasten eines Kürzels freizugeben, entferne es vom Befehl. Eine Meldung mit **Widerrufen** lässt dich das zurücknehmen.

Ein Abzeichen **Lokal** markiert ein Tastenkürzel, das nur innerhalb von Enconvo wirkt, etwa SmartBar anheften.

## Wie du es drückst

Wenn du eine einzelne Modifikatortaste aufnimmst, etwa die rechte ⌘, fragt das Feld **Wie sie gedrückt wird**:

| Option | Der Befehl läuft, wenn du |
| --- | --- |
| **Halten oder Tippen** | Die Taste hältst oder tippst, um umzuschalten |
| **Tippen** | Die Taste tippst, um zu starten, und erneut tippst, um zu stoppen |
| **Halten** | Die Taste gedrückt hältst; es wirkt, solange du sie hältst |
| **Doppeltippen** | Die Taste zweimal schnell tippst |

Zwei oder mehr gleichzeitig gedrückte Modifikatortasten zählen als ein Tastenkürzel. Jedes Feld zeigt nur die Arten, die sein Befehl unterstützt, und die Beschreibung daneben sagt, wie diese Funktion reagiert.

## Wo das Tastenkürzel jeder Funktion liegt

Neben der Seite Tastenkürzel hat jede Funktion ihr Kürzel auf ihrer eigenen Einstellungsseite:

| Funktion | Einstellungsseite |
| --- | --- |
| SmartBar | **Einstellungen → SmartBar** |
| Dynamic Island | **Einstellungen → Dynamic Island** |
| PopBar | **Einstellungen → PopBar** |
| App-Seitenleiste | **Einstellungen → App-Seitenleiste** |
| Diktat | **Einstellungen → Diktat** |
| Sprachbefehl | **Einstellungen → Sprachbefehl** |
| Appshots | **Einstellungen → Appshots** |
| Bildschirmzeichnung | **Einstellungen → Bildschirmzeichnung** |
| Sprachnotiz | **Einstellungen → Sprachnotiz** |
| Schnellerfassung | **Einstellungen → Schnellerfassung** |
| Ein einzelner Befehl | Die Einstellungen dieses Befehls, wenn er ein Feld **Tastenkürzel** hat |

## In der SmartBar

Tippe ein Auslösezeichen in der SmartBar, um eine Art von Eintrag zu suchen:

| Zeichen | Öffnet |
| --- | --- |
| **@** | Befehle |
| **#** | Kontext, den du deiner Nachricht hinzufügst |
| **$** | Fähigkeiten |
| **>** | Letzte Aufgaben |

Ändere diese Zeichen unter **Suche** in **Einstellungen → SmartBar**. Das Schrägstrichmenü hält Aktionen wie Modell- und Reasoning-Auswahl.

Um Listen mit der Tastatur zu durchlaufen, wähle **Navigationstasten** unter **Einstellungen → SmartBar**: **macOS** nutzt **⌃N** **⌃P** **⌃F** **⌃B**, und **Vim** nutzt **⌃J** **⌃K** **⌃L** **⌃H**.

## Enconvo an deinen Mac anpassen

Dasselbe Einstellungsfenster hält die anderen Entscheidungen, die das Video durchgeht:

| Einstellungsseite | Was sie tut |
| --- | --- |
| **Kontextverständnis** | Wählt, was die SmartBar aus der App mitnimmt, in der du warst: den markierten Text, deine Finder-Auswahl oder die Seite im Browser. **Anhängen** fügt es hinzu, sobald die SmartBar sich öffnet, und **Vorschlagen** bietet es für einen Klick an. Siehe [Kontextverständnis](/de/features/context-awareness). |
| **Appshots** | Fügt das Fenster vor dir mit einem Tastenkürzel dem Gespräch hinzu. Siehe [Appshots](/de/features/appshots). |
| **Lokale Modelle** | Zeigt die KI, die auf diesem Mac läuft, den Speicher und die Platte, die sie nutzt, und wo jede Funktion läuft. Siehe [Lokale Modelle](/de/ai/local-llm). |
| **Berechtigungen** | Listet, was macOS Enconvo erlaubt und warum; **Gewähren** behebt eine fehlende. Siehe [macOS-Berechtigungen](/de/configuration/permissions). |
| **Ruhezustand verhindern** | Hält diesen Mac wach, während du weg bist, damit du ihn vom iPhone aus noch erreichst. |

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Ein Tastenkürzel wirkt nur innerhalb von Enconvo | Prüfe, ob es ein Abzeichen **Lokal** hat. Wenn nicht, prüfe Eingabeüberwachung und Bedienungshilfen unter [macOS-Berechtigungen](/de/configuration/permissions) und ob eine andere App dieselben Tasten nutzt. |
| Das Drücken eines Tastenkürzels tut etwas anderes | Nutze **Nach Tastenkürzel suchen**. Nutzt kein Enconvo-Befehl die Tasten, tut es eine andere App oder macOS. |
| Ein Modifikatortasten-Kürzel löst nicht aus | Öffne das Tastenkürzel und prüfe **Wie sie gedrückt wird**: halten, tippen, doppeltippen oder Tasten zusammen. |
| Ein Kürzel aus einem Video oder von einem anderen Mac wirkt nicht | Deine Tastenkürzel können abweichen. Schau das aktuelle unter **Einstellungen → Tastenkürzel** nach. |

Die Fenster und Sprachfunktionen von Enconvo öffnen sich jeweils mit einem Tastenkürzel. Unter **Einstellungen → Tastenkürzel** steht jedes Tastenkürzel, das Enconvo nutzt, zusammen mit dem Befehl, den es ausführt. So kannst du eines ändern oder herausfinden, was eine Tastenkombination bewirkt. Die auf deinem Mac gespeicherten Tastenkürzel haben immer Vorrang vor den Standardwerten in dieser Anleitung.

Dieses Video behandelt die Tastenkürzel und danach die weiteren Einstellungen, die Enconvo an deinen Mac anpassen: Kontextverständnis, Appshots, Lokale Modelle, Berechtigungen und Ruhezustand verhindern.

## Standardkürzel

| Aktion | Standard |
| --- | --- |
| SmartBar anzeigen | **⌥Space** |
| Chatfenster anzeigen | **⌃⌘X** |
| App-Seitenleiste anzeigen | **⌃⌘E** |
| Einstellungen öffnen, aus Enconvo heraus | **⌘,** |
| Diktat starten | **Rechte ⌘-Taste** |
| Sprachbefehl starten | **Rechte ⌥-Taste** |
| Audio pausieren/fortsetzen | **⌥P** |

Diese Standardwerte gelten nur, wenn du nie eine eigene Taste festgelegt hast; eine von dir festgelegte Taste bleibt, wie sie ist. Schnellerfassung und Appshots haben kein Standard-Tastenkürzel: Lege eines auf ihren Einstellungsseiten fest, bevor du sie nutzt.

## Ein Tastenkürzel ändern

1. Öffne **Einstellungen → Tastenkürzel**. Der Tab **Kernfunktionen** enthält die Hauptfunktionen, **Weitere Tastenkürzel** enthält KI-Befehle, Plugins, Einstellungen und Befehle, die keine andere Seite zeigt, und **Alle** zeigt beides.
2. Gib in **Nach Name filtern…** etwas ein, um einen Befehl zu finden. Um den Befehl hinter einer Tastenkombination zu finden, klicke auf **Nach Tastenkürzel suchen** und drücke sie.
3. Klicke auf das Tastenkürzel-Feld des Befehls und drücke die neue Kombination.
4. Wenn diese Tasten bereits einen anderen Befehl ausführen, sagt dir das Feld das. Wähle **Hier verwenden**, um die Tasten diesem Befehl zuzuweisen, oder wähle eines der freien Tastenkürzel, die es vorschlägt.
5. Wechsle in eine andere App und probiere das Tastenkürzel aus.

Um die Tasten eines Tastenkürzels freizugeben, entferne es vom Befehl. Eine Meldung mit **Rückgängig** lässt dich das zurücknehmen.

Ein Abzeichen **Lokal** kennzeichnet ein Tastenkürzel, das nur innerhalb von Enconvo funktioniert, etwa „SmartBar anheften“.

## Wie sie gedrückt wird

Wenn du eine einzelne Modifikatortaste aufzeichnest, etwa die rechte ⌘-Taste, fragt das Feld **Wie sie gedrückt wird**:

| Option | Der Befehl läuft, wenn du |
| --- | --- |
| **Halten oder Tippen** | die Taste hältst oder sie zum Umschalten antippst |
| **Tippen** | die Taste zum Starten antippst und zum Beenden erneut antippst |
| **Halten** | die Taste gedrückt hältst; er funktioniert, solange du sie hältst |
| **Doppeltippen** | die Taste zweimal schnell antippst |

Zwei oder mehr gleichzeitig gedrückte Modifikatortasten zählen als ein Tastenkürzel. Jedes Feld zeigt nur die Arten, die sein Befehl unterstützt, und die Beschreibung daneben sagt, wie diese Funktion reagiert.

## Wo das Tastenkürzel jeder Funktion zu finden ist

Neben der Seite „Tastenkürzel“ hat jede Funktion ihr Tastenkürzel auf ihrer eigenen Einstellungsseite:

| Funktion | Einstellungsseite |
| --- | --- |
| SmartBar | **Einstellungen → SmartBar** |
| Dynamic Island | **Einstellungen → Dynamic Island** |
| PopBar | **Einstellungen → PopBar** |
| App-Seitenleiste | **Einstellungen → App-Seitenleiste** |
| Diktat | **Einstellungen → Diktat** |
| Sprachbefehl | **Einstellungen → Sprachbefehl** |
| Appshots | **Einstellungen → Appshots** |
| Bildschirmzeichnung | **Einstellungen → Bildschirmzeichnung** |
| Sprachnotiz | **Einstellungen → Sprachnotiz** |
| Schnellerfassung | **Einstellungen → Schnellerfassung** |
| Ein einzelner Befehl | Die Einstellungen dieses Befehls, wenn er ein Feld **Tastenkürzel** hat |

## In der SmartBar

Tippe in der SmartBar ein Auslösezeichen, um nach einer Art von Einträgen zu suchen:

| Zeichen | Öffnet |
| --- | --- |
| **@** | Befehle |
| **#** | Kontext, den du deiner Nachricht hinzufügst |
| **$** | Fähigkeiten |
| **>** | Letzte Aufgaben |

Diese Zeichen änderst du unter **Suchen** in **Einstellungen → SmartBar**. Das Slash-Menü enthält Aktionen wie die Auswahl von Modell und Reasoning.

Um mit der Tastatur durch Listen zu navigieren, wähle **Navigationstasten** in **Einstellungen → SmartBar**: **macOS** nutzt **⌃N** **⌃P** **⌃F** **⌃B**, und **Vim** nutzt **⌃J** **⌃K** **⌃L** **⌃H**.

## Enconvo an deinen Mac anpassen

Dasselbe Einstellungsfenster enthält die weiteren Optionen, die das Video durchgeht:

| Einstellungsseite | Was sie bewirkt |
| --- | --- |
| **Kontextverständnis** | Legt fest, was die SmartBar aus der App übernimmt, in der du warst: den markierten Text, deine Auswahl im Finder oder die Seite in deinem Browser. **Anhängen** fügt es hinzu, sobald die SmartBar sich öffnet, und **Vorschlagen** bietet es zum Anklicken an. Siehe [Kontextverständnis](/de/features/context-awareness). |
| **Appshots** | Fügt das Fenster vor dir per Tastenkürzel zur Unterhaltung hinzu. Siehe [Appshots](/de/features/appshots). |
| **Lokale Modelle** | Zeigt die KI, die auf diesem Mac läuft, den Arbeitsspeicher und Speicherplatz, den sie nutzt, und wo jede Funktion läuft. Siehe [Lokale Modelle](/de/ai/local-llm). |
| **Berechtigungen** | Listet auf, was macOS Enconvo erlaubt und warum; **Gewähren** behebt eine fehlende. Siehe [macOS-Berechtigungen](/de/configuration/permissions). |
| **Ruhezustand verhindern** | Hält diesen Mac vom Ruhezustand ab, während du weg bist, damit du ihn weiterhin von deinem iPhone aus erreichen kannst. |

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Ein Tastenkürzel funktioniert nur innerhalb von Enconvo | Prüfe, ob es ein Abzeichen **Lokal** hat. Wenn nicht, prüfe Eingabeüberwachung und Bedienungshilfen unter [macOS-Berechtigungen](/de/configuration/permissions) und ob eine andere App dieselben Tasten nutzt. |
| Ein Tastenkürzel löst etwas anderes aus | Nutze **Nach Tastenkürzel suchen**. Wenn kein Enconvo-Befehl die Tasten nutzt, tut es eine andere App oder macOS. |
| Ein Tastenkürzel mit Modifikatortaste löst nicht aus | Öffne das Tastenkürzel und prüfe **Wie sie gedrückt wird**: halten, tippen, doppeltippen oder gemeinsam gedrückte Tasten. |
| Ein Kürzel aus einem Video oder von einem anderen Mac funktioniert nicht | Deine Tastenkürzel können abweichen. Schlage das aktuelle unter **Einstellungen → Tastenkürzel** nach. |

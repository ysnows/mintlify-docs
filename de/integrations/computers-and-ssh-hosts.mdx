Deine Agenten können auf mehr als diesem Mac arbeiten. Füge einen Server hinzu, bei dem du dich per SSH anmeldest, erwähne ihn in einem Chat und frage, so wie du nach deinem eigenen Mac fragen würdest: Der Agent führt die Befehle dort aus und antwortet hier. Auf dem Server wird nichts installiert. Deine anderen Computer, auf denen Enconvo läuft, lassen sich genauso koppeln.

Das Video unten fügt einen SSH-Host aus deiner SSH-Konfiguration hinzu, bittet den Agenten, auf ihm ein Log zu lesen, und zeigt, wer diesen Mac erreichen kann.

## Bevor du anfängst

- Du brauchst einen Server, bei dem du dich von diesem Mac aus mit `ssh` anmelden kannst: einen Host in `~/.ssh/config` oder eine Adresse, die du als `user@host` eintippen kannst. Enconvo verwendet das `ssh` und die Schlüssel dieses Macs. Fragt der Server nach einem Passwort oder einer Passphrase, fragt `ssh` über Enconvo, und Enconvo speichert nichts davon.
- Erlaube Enconvo bei einem Server in deinem lokalen Netzwerk unter **Systemeinstellungen → Datenschutz & Sicherheit → Lokales Netzwerk**.

## Was Verbindungen auflistet

Öffne **Einstellungen → Verbindungen**. Dort gibt es drei Listen:

| Liste | Was sie enthält |
| --- | --- |
| **Telefone** | Die iPhone- und Android-Apps, die mit diesem Mac gekoppelt sind. Siehe [iPhone-App](/de/integrations/iphone-app). |
| **Computer** | Deine anderen Computer, auf denen Enconvo läuft und die mit diesem Mac gekoppelt sind. Jeder steht einmal in der Liste, mit der Richtung, in die er steuert. Klicke auf **Computer koppeln**, um einen hinzuzufügen. Siehe [Deine anderen Computer](/de/integrations/other-computers). |
| **SSH-Hosts** | Server, die deine Agenten über SSH erreichen, ohne dass dort etwas installiert ist. |

Klicke auf ein Telefon oder einen Computer, um seine eigene Seite zu öffnen, mit dem, was er auf diesem Mac tun kann.

Du kannst auch im Chatfenster einen Host hinzufügen, einen Computer koppeln oder ein Telefon koppeln: Klicke unten in der Seitenleiste auf den Geräteumschalter und dann auf **Gerät hinzufügen**.

## Einen SSH-Host hinzufügen

1. Öffne **Einstellungen → Verbindungen** und klicke unter **SSH-Hosts** auf **Host hinzufügen**.
2. Die Liste zeigt die Hosts aus deiner `~/.ssh/config`. Wähle einen aus, etwa `build-server`, oder tippe `user@host` (oder `user@host:port`) ein.
3. Klicke auf **Verbinden**. Enconvo testet die Verbindung: Es erreicht den Host, prüft den Host-Schlüssel, meldet sich an und führt einen Befehl aus.
4. Wähle unter **Vor jedem Befehl**, wie der Agent nachfragt, bevor er dort einen Befehl ausführt:
   - **Dem Chat folgen**: Fragt so nach, wie es der Berechtigungsmodus des Chats vorgibt. Siehe [Aktionen freigeben](/de/ai/agents).
   - **Immer fragen**: Fragt vor jedem Befehl nach.
5. Klicke auf **Host hinzufügen**.

Der Host erscheint nun unter **SSH-Hosts** und im `@`-Menü jedes Chats.

Sieht Enconvo den Host-Schlüssel eines Servers zum ersten Mal, prüfe den Schlüssel bei der Person, die den Server betreibt, und klicke dann auf **Vertrauen und verbinden**. Bei einem Linux-Server bietet der Dialog außerdem **Dort auch Enconvo installieren** an, wodurch der Server als Computer gekoppelt wird. Lass die Option aus, um nichts zu installieren.

## Den Agenten auf einem Host arbeiten lassen

1. Tippe in einem Chat `@` und den Anfang des Host-Namens. Deine Computer und SSH-Hosts stehen unter **Computer**.
2. Wähle den Host aus. Er kommt als Chip in die Nachricht.
3. Frage, was dort erledigt werden soll, und sende ab. Zum Beispiel:

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

Der Agent führt die Befehle über SSH auf dem Host aus und fragt vorher so nach, wie du es für diesen Host gewählt hast. Jeder Befehlsschritt nennt den Host, auf dem er lief. Die Antwort kommt im Chat zurück.

Um zu sehen, was er ausgeführt hat, klicke über der Antwort auf **Gearbeitet für**. Die Einblendung listet jeden Befehl auf.

Einen gekoppelten Computer kannst du genauso erwähnen. Der Agent übergibt die Aufgabe an den eigenen Agenten dieses Computers oder führt dort Befehle aus, wenn dieser Computer das Terminal für diesen Mac erlaubt.

Im Chat heißt ein auf einem Host oder einem anderen Computer ausgeführter Befehl **Befehl ausgeführt**, und jeder Schritt nennt die Maschine.

## Agenten auf einem gekoppelten Computer arbeiten lassen

Klicke in **Einstellungen → Verbindungen** unter **Computer** auf einen Computer, um seine Seite zu öffnen. Zwei Schalter legen fest, was Agenten in Chats hier mit ihm tun dürfen:

| Schalter | Was er bewirkt |
| --- | --- |
| **Agenten** | Seine Agenten zu Projekten hinzufügen oder einen Chat an einen übergeben. Die Aufgabe läuft auf diesem Computer, und alles, was sein Agent tun will, fragt dich dort zuerst. |
| **Befehle** | Agenten in Chats hier dürfen auf ihm Befehle ausführen und fragen so nach, wie es der Berechtigungsmodus des Chats vorgibt. |

Ein abgeblendeter Schalter heißt, dass der andere Computer es nicht erlaubt hat: Schalte auf jenem Computer **Agenten** oder **Terminal** für diesen Mac ein. Schaltest du **Befehle** aus, stoppt das auch Befehle über einen SSH-Host für denselben Computer.

Damit die Agenten eines anderen Computers den Bildschirm und den Browser dieses Macs direkt verwenden dürfen, schalte auf der Seite dieses Computers hier die **Agent-Steuerung** ein. Siehe [Deine anderen Computer](/de/integrations/other-computers).

## Die Einstellungen eines Hosts ändern

Klicke unter **SSH-Hosts** auf einen Host, um seine Seite zu öffnen:

| Einstellung | Was sie bewirkt |
| --- | --- |
| **Agenten dürfen ihn nutzen** | Ausgeschaltet bleibt der Host in der Liste, steht aber in keinem Chat zur Verfügung. |
| **Vor jedem Befehl** | **Dem Chat folgen** oder **Immer fragen**. |
| **Dateien kopieren** | Erlaubt Agenten, Dateien mit `scp` zum und vom Host zu kopieren. |
| **Startet in** | Der Ordner, in dem Befehle starten. Leer bedeutet den Anmeldeordner. |

Das Menü **⋯** der Seite enthält **Verbindung testen** und **Host entfernen…**. Beim Entfernen eines Hosts vergisst Enconvo ihn. Deine `~/.ssh/config` und der Server bleiben, wie sie sind.

## Sehen, wer diesen Mac erreichen kann

**Wer diesen Mac erreichen kann** in **Einstellungen → Verbindungen** zeigt, wie viele Telefone und Computer diesen Mac erreichen können.

Um alle auf einmal auszusperren, klicke auf **Jeden Zugriff stoppen** und bestätige. Deine Telefone und anderen Computer können dann keinen deiner Macs mehr erreichen, und was sie dort ausführen, stoppt. Klicke auf **Zugriff wieder aktivieren**, wenn du sie zurückhaben möchtest.

## Fehlerbehebung

| Problem | Was zu tun ist |
| --- | --- |
| Der Test erreicht einen Server in deinem lokalen Netzwerk nicht | macOS hält die Verbindung wegen der Berechtigung für das lokale Netzwerk zurück. Klicke auf **Lokales Netzwerk für Enconvo erlauben** oder schalte Enconvo unter **Systemeinstellungen → Datenschutz & Sicherheit → Lokales Netzwerk** ein und versuche es dann erneut. |
| Der Test meldet, der Server habe deinen Schlüssel abgelehnt | Prüfe `IdentityFile` für den Host in `~/.ssh/config` oder füge den Schlüssel mit `ssh-add` hinzu. |
| Der Server antwortete mit einem anderen Host-Schlüssel | Er wurde möglicherweise neu aufgesetzt, oder etwas befindet sich zwischen dir und ihm. Wurde er neu aufgesetzt, entferne den alten Schlüssel im Terminal mit `ssh-keygen -R`, gefolgt von der Adresse des Servers, und versuche es dann erneut. |
| Der Host steht nicht im `@`-Menü | Öffne die Seite des Hosts und schalte **Agenten dürfen ihn nutzen** ein. |
| Ein falsches Passwort oder eine falsche Passphrase | Das Feld öffnet sich erneut und meldet, dass es nicht geklappt hat. Tippe sie noch einmal ein. |
| Ein Computer hat zwei SSH-Hosts | Der erste Host bleibt mit dem Computer verknüpft, und seine Seite zeigt diesen. Entfernst du ihn, wird der andere verknüpft. |
| `~/.ssh/config` enthält keine Hosts | Tippe die Adresse bei **Host hinzufügen** als `user@host` ein. |

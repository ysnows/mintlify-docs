Plugins fügen Enconvo Befehle, Anbieter, Tools und API-Routen hinzu. Öffne **Einstellungen → Plugins**, um den Katalog zu durchsuchen, zu installieren, was du brauchst, und zu verwalten, was du bereits hast.

## Ein Plugin finden und installieren

<Steps>
  <Step title="Plugins öffnen">
    Öffne **Einstellungen → Plugins**. Drücke **⌘K**, um zum Suchfeld zu springen.
  </Step>
  <Step title="Suchen">
    Suche nach der Aufgabe oder dem Namen des Plugins. Wenn im aktuellen Tab nichts passt, bietet die Seite die Ergebnisse in einem anderen Tab an.
  </Step>
  <Step title="Seite des Plugins öffnen">
    Klicke auf das Plugin, um seine Beschreibung, seinen Umfang und seine Voraussetzungen zu lesen.
  </Step>
  <Step title="Installieren und einrichten">
    Klicke auf **Installieren**, falls es noch nicht installiert ist. Füge dann die Zugangsdaten des Anbieters oder Befehlseinstellungen hinzu, nach denen es fragt.
  </Step>
  <Step title="Verwenden">
    Klicke auf **Jetzt ausprobieren**, führe einen seiner Befehle über SmartBar aus oder aktiviere seine Tools für den Agenten, der es nutzen soll.
  </Step>
</Steps>

Die Seite eines Plugins listet seine Befehle und deren Einstellungen auf. Wenn du die Einstellungen eines Befehls von einer anderen Stelle in Enconvo öffnest, landest du bei diesem Befehl innerhalb seines Plugins.

Hat ein Plugin eine Ansicht im Chatfenster, etwa [E-Mail](/de/integrations/email), hat seine Seite eine Taste **Öffnen**, die diese Ansicht dort öffnet, sodass alles darin, etwa das Hinzufügen eines Postfachs, nur einen Klick entfernt ist. Ein Plugin mit mehreren Ansichten erhält stattdessen ein Menü **Öffnen**.

## Die Seite „Plugins“

| Tab | Was er zeigt |
| --- | --- |
| **Enconvo** | Der Katalog nach Kategorien. **Installiert** oben listet die Connectors, die du verbunden hast, und die Plugins, die du installiert oder erstellt hast. **Neu hinzugefügt** zeigt neue Einträge. |
| **Integriert** | Plugins, die mit Enconvo mitgeliefert werden: **Suchen** enthält die Listen, in denen du über SmartBar suchst, und **Steuerung** enthält Computernutzung und Browsernutzung. |
| **Mac-Apps** | Apps auf diesem Mac, die Agenten verwenden können, etwa Kalender, Mail und Notizen. Beim Verbinden einer App fragt macOS nach einer Berechtigung, nicht nach einem Konto. Siehe [Apple-Apps](/de/integrations/apple-ecosystem). |
| **PopBar** | PopClip-kompatible Erweiterungen, die [PopBar](/de/features/popbar) Tasten hinzufügen. |
| **Persönlich** | Plugins, die du erstellt oder importiert hast, und die, die du im Enconvo-Store veröffentlicht hast. |

Um ein Plugin von außerhalb des Katalogs einzubinden, verwende **Plugin erstellen** oder das Menü **Hinzufügen**:

| Option | Was sie bewirkt |
| --- | --- |
| **Plugin erstellen** | Beschreibe, was du brauchst, und der Agent schreibt, testet und installiert das Plugin. |
| **Plugin-Archiv hochladen…** | Installiert eine `.enconvo`-Datei oder ein Plugin-`.zip` von Claude Code oder Codex. |
| **Von GitHub hinzufügen…** | Installiert aus einem Plugin-Repository oder einem Marketplace von Claude Code oder Codex. |
| **MCP-Server hinzufügen…** | Öffnet [MCP-Server](/de/features/mcp). |
| **PopBar-Erweiterung hinzufügen …** und **Aus PopClip importieren …** | Fügen PopBar PopClip-Erweiterungen hinzu. |
| **Neue Fähigkeit…** | Öffnet [Fähigkeiten](/de/configuration/skills). |

| Aufgabe | Anleitung |

Einige Plugins im Store bringen die Tools und die Anleitung eines ganzen Dienstes mit:

- **Shopify** lässt den Agenten deinen Shopify-Shop mit Shopifys offiziellem CLI verwalten und zeigt dir jede Änderung, bevor er sie vornimmt. Es funktioniert über mehrere Shops hinweg. Der Agent fragt, welcher Shop gemeint ist, wenn du keinen nennst, nennt den Shop bei jeder angezeigten Änderung und führt eine für mehrere Shops gedachte Änderung einmal pro Shop aus.
- **Expo** bringt die offiziellen Fähigkeiten des Expo-Teams und den Expo-MCP-Server mit, anstelle des älteren schreibgeschützten Expo-Connectors. Der Agent erstellt, aktualisiert und veröffentlicht Expo- und React-Native-Apps, liest deine EAS-Builds, Protokolle, Abstürze und Rezensionen und startet Builds und Einreichungen erst, nachdem du jede genehmigt hast. Eine bereits vorhandene Expo-Anmeldung wird übernommen.

**Obsidian**, **Tailscale** und **Cloudflare** sind ebenfalls Plugins aus dem Plugin-Store: Installiere sie auf der Seite „Plugins“. Eine Kopie, die du schon hattest, funktioniert weiter und aktualisiert sich selbst. Agenten wissen von Anfang an, welche der Plugins Obsidian, Tailscale, Cloudflare und Shopify du installiert hast.

Der [Katalog der integrierten Befehle](/de/extensions/built-in-extensions) listet die dokumentierten Befehlsfamilien auf. Die Store-Einträge und installierten Plugins in deiner Version können davon abweichen.

## Befehle, Anbieter und Tools

- Ein **Befehl** ist eine Aktion, die du ausführst.
- Ein **Anbieter** stellt eine Fähigkeit bereit, etwa ein Modell oder eine Stimme.
- Ein **Tool** ist eine Aktion, die ein Agent aufrufen kann.

Die Installation eines Plugins macht seinen Anbieter nicht immer zum Standard und aktiviert auch nicht jedes Tool für jeden Agenten.

Verwende in SmartBar die Befehlsauswahl (standardmäßig `@`) oder suche nach dem Titel eines Befehls. Das Aktionsmenü `/` tut etwas anderes; es ist kein Präfix für Plugin-Namen.

## Mehrere Konten in einem Connector verwenden

Connectors, die sich auf deinem Mac anmelden, etwa Notion, Webflow und Linear, können mehr als ein Konto halten.

- Wähle auf der Seite des Connectors **Weiteres Konto verbinden**, um eines hinzuzufügen. **Verbundene Konten** listet alle auf.
- Wähle **Als Standard** bei dem Konto, mit dem Agenten senden oder erstellen sollen. Agenten lesen aus jedem Konto.
- Nenne ein Konto in einer Anfrage, etwa „sende es von meiner Arbeitsadresse“, und der Agent verwendet dieses.
- **Trennen** entfernt ein Konto; **Alle Konten trennen** entfernt alle.

In einem Workspace eines Kunden behält jeder Connector sein eigenes Standardkonto, angezeigt als **Standard in** und der Name des Workspace. Der Agent verwendet dort das Konto dieses Kunden, sofern du kein anderes nennst.

## Ausschalten, aktualisieren oder entfernen

Auf der Seite eines Plugins:

- Der Schalter schaltet das Plugin ein oder aus. Solange es aus ist, können Agenten es nicht finden oder verwenden, und SmartBar listet es nicht auf und lässt dich es nicht per `@` aufrufen. Seine Einstellungen bleiben erhalten.
- Das Menü **⋯** enthält **Einstellungen**, **Nach Updates suchen** und **Deinstallieren**. Plugins, die mit Enconvo mitgeliefert werden, lassen sich nicht deinstallieren.

Prüfe vor dem Deinstallieren eines Plugins die Agenten, Workflows und eigenen Befehle, die es verwenden. Das Zurücksetzen eines Befehls stellt seine Einstellungen wieder her. Das Zurücksetzen eines gemeinsam genutzten Anbieters kann auch Zugangsdaten ändern, die andere Funktionen verwenden; siehe [Zugangsdaten](/de/configuration/credentials).

## Ein Plugin teilen

Du kannst ein Plugin, das du erstellt hast, oder eines, dessen Ordner auf diesem Mac liegt, mit einem Link teilen, den jeder, dem du ihn gibst, installieren kann.

1. Klicke auf der Seite des Plugins auf **Teilen…**. Melde dich bei deinem Enconvo-Konto an, falls Enconvo danach fragt.
2. Wähle unter **Wer installieren kann** **Jeder mit dem Link** oder **Plugin-Store**.
3. Klicke auf **Veröffentlichen**, dann auf **Link kopieren** und sende den Link.

Enconvo prüft und begutachtet jede Version, bevor der Link sie installiert, und der Link öffnet die Seite des Plugins auf enconvo.com. Jede Person, die es installiert, erhält eine eigene Kopie; seine Daten, deine Schlüssel und deine Anmeldungen bleiben auf deinem Mac.

Um ein geteiltes Plugin zu ändern, klicke erneut auf **Teilen…**: Sende eine neuere Version, ändere **Wer installieren kann** oder klicke auf **Teilen beenden**. Der Link funktioniert dann nicht mehr, und Personen, die das Plugin installiert haben, behalten ihre Kopie. Lehnt die Prüfung eine Version ab, zeigt **Teilen…** den Grund und bietet **Im Chat beheben** an. Wie du einen [Space](/de/features/spaces) teilst, steht unter [Einen Space teilen](/de/features/spaces).

## Eigene erstellen

Verwende das TypeScript-SDK und das CLI unter [Erweiterungen entwickeln](/de/extensions/developing). Das CLI fasst Build, Installation, Schema-Erzeugung und Veröffentlichung unter `enconvo plugin` zusammen. Mit dem Veröffentlichen wird ein Plugin außerhalb deiner eigenen Entwicklungsumgebung verfügbar.

Enconvo installiert außerdem Plugins von Codex, Claude Code und portable Plugins. Siehe [Plugin-Formate](/extensions/plugin-formats) und [Plugins installieren](/de/extensions/installing-plugins).

<Note>
Enconvo für Windows befindet sich in der Beta und erscheint im Update-Kanal **Beta**. Es ist für den täglichen Gebrauch gedacht, aber zwischen einzelnen Builds kann sich noch etwas ändern. Wenn etwas nicht funktioniert, sag es uns auf der [Feedback-Seite](https://feedback.enconvo.com).
</Note>

**Aktuelle Beta: 2.5.13 Beta 3** (`2.5.13-beta-3`). Welche Version du hast, siehst du unter **Einstellungen → Allgemein → Updates**.

## Voraussetzungen

- **Windows 10 Version 2004 (Build 19041) oder neuer, oder Windows 11.**
- **64-Bit Intel/AMD (x64).** Für Windows on Arm gibt es noch keinen Build.
- **Microsoft Edge WebView2 Runtime.** Die Fenster von Enconvo laufen darauf. Windows 11 bringt sie von Haus aus mit. Bleiben die Fenster unter Windows 10 leer, siehe [Fehlerbehebung](#fehlerbehebung).

## Die Beta herunterladen

Die Beta kommt als Installationsprogramm, `Enconvo-<version>-win32-x64-setup.exe`. Der Dateiname enthält die Versionsnummer der Beta.

Für die aktuelle Beta, 2.5.13 Beta 3, lade [Enconvo-2.5.13-beta-3-win32-x64-setup.exe](https://file.enconvo.com/win32-x64/beta/Enconvo-2.5.13-beta-3-win32-x64-setup.exe) herunter.

Um immer die neueste Beta zu erhalten, führe dies in PowerShell aus. Es liest den Beta-Feed, lädt das Installationsprogramm in deinen Ordner „Downloads“ und prüft, dass die Datei unversehrt angekommen ist.

```powershell
$feed = "https://file.enconvo.com/win32-x64/beta"
$latest = Invoke-RestMethod "$feed/latest.json"
$file = $latest.files.exe.url
$out = "$env:USERPROFILE\Downloads\$file"
$ProgressPreference = "SilentlyContinue"   # downloads much faster in Windows PowerShell
Invoke-WebRequest "$feed/$file" -OutFile $out
if ((Get-FileHash $out -Algorithm SHA256).Hash -eq $latest.files.exe.sha256) {
  "Downloaded Enconvo $($latest.version) to $out"
} else {
  "The download is damaged. Delete it and run this again."
}
```

## Installieren

<Steps>
  <Step title="Das Installationsprogramm ausführen">
    Öffne die heruntergeladene `.exe`-Datei. Zeigt Windows **Der PC wurde durch Windows geschützt** an, klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. SmartScreen zeigt dies für Apps an, die es noch nicht kennt.
  </Step>
  <Step title="Einen Ordner wählen">
    Enconvo wird nur für dein Konto installiert und braucht keine Administratorrechte. Der Standardordner ist `%LOCALAPPDATA%\Programs\Enconvo`. Wählst du einen anderen, muss er leer sein oder bereits Enconvo enthalten.
  </Step>
  <Step title="Enconvo öffnen">
    Lass auf der letzten Seite **Enconvo öffnen** angehakt oder öffne **Enconvo** später über das Startmenü. Das Symbol erscheint im Infobereich der Taskleiste.
  </Step>
  <Step title="Anmelden">
    Melde dich mit deinem Enconvo-Konto an und mach dann mit dem [Schnellstart](/de/quickstart) weiter.
  </Step>
</Steps>

Läuft Enconvo bei der Installation, bittet dich das Installationsprogramm zuerst, es zu schließen.

## Aktualisieren

Ein Beta-Build bleibt im Beta-Kanal. Um das zu ändern, öffne **Einstellungen → Allgemein** und stelle **Update-Kanal** um. Siehe [Updates](/de/configuration/updates).

Enconvo sucht selbstständig nach einer neuen Version. Ist eine bereit, klicke im Chatfenster auf **Aktualisieren**. Du kannst auch jederzeit unter **Einstellungen → Allgemein → Updates** nachsehen.

Das Update wird direkt installiert: Enconvo schließt sich, zeigt den Fortschritt des Installationsprogramms und öffnet sich mit der neuen Version erneut.

## Fehlerbehebung

| Was du siehst | Was du tun kannst |
| --- | --- |
| **Der PC wurde durch Windows geschützt**, wenn du das Installationsprogramm öffnest | Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen** |
| **Enconvo benötigt 64-Bit-Windows** | Enconvo läuft nicht unter 32-Bit-Windows |
| Das Installationsprogramm verwendet den gewählten Ordner nicht | Wähle einen leeren Ordner oder den Ordner, in dem Enconvo bereits liegt |
| Die Fenster von Enconvo bleiben leer oder öffnen sich nicht | Installiere die [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) und öffne Enconvo dann erneut |
| Ein Klick auf eine Enconvo-Benachrichtigung bewirkt nichts | Öffne Enconvo normal, nicht mit **Als Administrator ausführen** |

## Enconvo entfernen

Öffne **Einstellungen → Apps → Installierte Apps** (unter Windows 10 **Einstellungen → Apps → Apps & Features**), suche **Enconvo** und wähle **Deinstallieren**.

Deine Einstellungen und Chats bleiben im Ordner `.config\enconvo` in deinem Benutzerordner (`%USERPROFILE%\.config\enconvo`). Lösche diesen Ordner, um sie ebenfalls zu entfernen.

Schreibwerkzeuge sind Befehle mit einem Klick für den Text, den du in einer beliebigen App markierst. Korrigiere Fehler, ändere den Ton, mach ihn kürzer oder länger, erkläre oder fasse ihn zusammen oder mach daraus eine Liste oder eine Tabelle, ohne die App zu verlassen, in der du schreibst.

## Markierten Text bearbeiten

1. Markiere Text in der App, in der du schreibst.
2. Klicke einen Befehl in der [PopBar](/de/features/popbar) oder öffne die [SmartBar](/de/features/smartbar) und suche den Befehl.
3. Lies das Ergebnis. Ist **Änderungen hervorheben** an, markiert das Ergebnis, was der Befehl hinzugefügt und entfernt hat.
4. Klicke auf **Einfügen**, um deine Auswahl zu ersetzen, oder kopiere das Ergebnis.

Jeder Befehl behält die Sprache deines Textes und antwortet nur mit dem Ergebnis. **Erklären** antwortet ebenfalls in der Sprache des markierten Textes und behandelt jeden Lauf für sich, nicht als Teil eines früheren. Wenn der markierte Text eine Frage stellt oder eine Anweisung gibt, bearbeitet der Befehl diese Wörter; er beantwortet sie nicht.

<Tip>
Schalte **Inline-Modus** für einen Befehl ein, dem du vertraust, und er läuft ohne Fenster und fügt das Ergebnis direkt über deine Auswahl ein. Siehe [Einen Befehl ändern](/de/features/writing-tools).
</Tip>

## Einen Befehl wählen

| Ziel | Befehle |
| --- | --- |
| Fehler korrigieren | Rechtschreibung und Grammatik korrigieren, Korrekturlesen |
| Formulierung verbessern | Schreiben verbessern, Überarbeiten, Umschreiben, Muttersprachlich, KI-Bearbeitung |
| Länge ändern | Länger machen, Kürzer machen, Knapp machen |
| Ton ändern | Ton ändern: Freundlich, Selbstbewusst, Locker oder Professionell |
| Inhalt verstehen | Erklären, Zusammenfassen, Kernpunkte extrahieren |
| Neu formatieren | In Liste umwandeln, In Tabelle umwandeln |
| E-Mail | E-Mail überarbeiten, Antwort entwerfen |
| Beiträge auf X | Für X überarbeiten, In 280 Zeichen passen, In einen Thread verwandeln, Eine Antwort auf X vorschlagen, Einen Zitatkommentar auf X vorschlagen |
| Übersetzen | Übersetzer, Bildschirmfoto übersetzen (siehe [Übersetzung](/de/ai/translate)) |
| Etwas auf dem Bildschirm | Bildschirmfoto erklären |
| Diktat | Diktat überarbeiten, Diktat übersetzen, Diktat bearbeiten, Bereinigung auf dem Gerät (siehe [Diktat](/de/features/dictation)) |
| Kurzer Ausdruck | Emoji |

**Muttersprachlich** schreibt deinen Text so um, wie eine Muttersprachlerin oder ein Muttersprachler ihn schreiben würde, in derselben Sprache. **E-Mail überarbeiten** behält deine eigene Anrede, Verabschiedung und deinen Namen und fügt keine Signatur hinzu. **Antwort entwerfen** schreibt eine Antwort auf die markierte E-Mail in ihrer Sprache und ihrem Ton und lässt einen kurzen Platzhalter in eckigen Klammern für einen Namen, ein Datum oder eine Entscheidung, die es nicht wissen kann.

## Einen Befehl ändern

Öffne **Einstellungen → KI-Befehle** und wähle den Befehl unter **Integriert**. Seine Seite zeigt, was der Befehl tut, mit **Probier es aus**, um ihn zuerst an etwas Text auszuführen.

| Einstellung | Was sie ändert |
| --- | --- |
| **PopBar** | Legt den Befehl auf die PopBar oder nimmt ihn herunter |
| **Änderungen hervorheben** | Markiert, was der Befehl im Ergebnis hinzugefügt und entfernt hat |
| **Tastenkürzel** | Führt den Befehl auf den Text aus, den du in einer beliebigen App markierst |
| **Inline-Modus** | Läuft ohne Fenster und fügt das Ergebnis über deine Auswahl ein |
| **Folgeaktion** | Was der Befehl mit der Antwort macht, wenn er fertig ist |
| **KI-Modell** | Das Modell, das dieser Befehl nutzt. Standardmäßig folgt er dem Modell für alle KI-Befehle |

Die Anweisungen eines integrierten Befehls sind schreibgeschützt. Klicke auf **Anpassen**, um eine eigene Kopie zu machen, die du frei ändern kannst.

Schreibwerkzeuge laufen auf dem Modell unter **Einstellungen → KI-Befehle → Alle Befehle**, außer ein Befehl wählt sein eigenes. Dieselben Befehle stehen auch unter **Einstellungen → Plugins → Schreibwerkzeuge**, und die Schaltfläche **Einstellungen** in einem Ergebnisfenster öffnet den Befehl, der es erzeugt hat.

## Verlässliche Ergebnisse bekommen

Wenn eine Umschreibung mehrere Wege gehen könnte, sag, für wen der Text ist und was er tun soll. Nenne, was gleich bleiben muss, etwa Namen, Daten, Zahlen und zitierte Formulierungen.

Vergleiche das Ergebnis immer mit deinem Original, bevor du es sendest. Flüssige Ausgabe kann die Bedeutung trotzdem ändern.

Für eine Anweisung, die du wiederholst, mach deinen eigenen [KI-Befehl](/de/features/ai-commands).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Ein Befehl fehlt auf der PopBar | Klicke auf **⌄** am Ende der PopBar, wo die Schaltflächen hingehen, die nicht passen, oder schalte **PopBar** auf der Seite des Befehls unter **Einstellungen → KI-Befehle** ein |
| Die PopBar erscheint nicht | Siehe [Fehlerbehebung der PopBar](/de/features/popbar) |
| Das Ergebnis ist in einer unerwarteten Sprache | Erklären antwortet in der Sprache des markierten Textes. Zusammenfassen behält die Sprache des Textes, außer du setzt seine **Antwortsprache**. Die anderen Befehle behalten die Sprache des Textes |
| Das Ergebnis hat die Bedeutung geändert | Bearbeite es, bevor du einfügst, oder führe den Befehl erneut mit deinem Originaltext aus |

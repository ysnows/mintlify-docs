title: "Appshots"

Appshots fügt das Fenster der vordersten App deinem Chat als Kontext hinzu. Nutze es, wenn du etwas auf dem Bildschirm fragen willst, ohne es in einer Wissensdatenbank zu speichern.

## Ein App-Fenster aufnehmen

1. Bringe die App, zu der du fragen willst, nach vorn.
2. Drücke deinen Appshots-Hotkey. Appshots hat keinen Hotkey, bis du unter **Hotkey** in **Einstellungen → Appshots** einen festlegst.
3. Das Fenster geht an die SmartBar, das Chatfenster oder die App-Seitenleiste, wenn eines davon vorn geöffnet ist. Sonst geht es an die Dynamic Island. Ein kurzer Auslöserton ertönt.
4. Prüfe das angehängte Fenster und stelle dann eine konkrete Frage, etwa „Erkläre den Fehler in diesem Fenster.“

## Einstellungen

Öffne **Einstellungen → Appshots**.

| Einstellung | Was sie tut |
| --- | --- |
| **Appshots aktivieren** | Lässt den Hotkey das vorderste App-Fenster hinzufügen. Standardmäßig an. |
| **Aufnahmeton** | Spielt einen kurzen Auslöserton, wenn ein Appshot hinzugefügt wird. Der Ton bestätigt die Aufnahme; prüfe den Anhang trotzdem, bevor du sendest. |
| **Hotkey** | Der Kurzbefehl, der das Fenster hinzufügt. Standardmäßig keiner. Es kann eine Kombination von Modifikatortasten sein, etwa beide **Option**-Tasten zusammen, oder ein gewöhnlicher Kurzbefehl. |

## Das passende Aufnahmewerkzeug wählen

| Ziel | Nutzen |
| --- | --- |
| Zum aktuellen App-Fenster fragen | Appshots |
| Vor der Frage auf einen Bereich hinweisen | [Bildschirmzeichnung](/de/features/screen-doodle) |
| Den Inhalt der aktuellen App für die spätere Suche speichern | [Schnellerfassung](/de/features/quick-capture) |
| Text aus einem Bild ziehen | [OCR](/de/ai/ocr) |

Aufgenommener Inhalt kann an das Modell gesendet werden, das du für die Anfrage nutzt. Siehe [Kontextverständnis](/de/features/context-awareness) für weitere Wege, Kontext hinzuzufügen.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Es erscheint kein Kontext | Prüfe **Einstellungen → Berechtigungen**, vor allem Bildschirmaufnahme und Bedienungshilfen. |
| Das falsche Fenster wird aufgenommen | Bringe die Ziel-App erneut nach vorn. Appshots nimmt das Fenster einer anderen App auf, nicht die eigenen Fenster von Enconvo wie Einstellungen. |
| Der Hotkey tut nichts | Stelle sicher, dass **Appshots aktivieren** an ist und ein **Hotkey** gesetzt ist. |
| Der Hotkey tut etwas anderes | Eine andere App nutzt dieselben Tasten. Ändere den **Hotkey** unter **Einstellungen → Appshots**. |

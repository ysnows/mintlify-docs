Appshots fügt das Fenster der App im Vordergrund als Kontext zu deinem Chat hinzu. Nutze es, wenn du etwas fragen möchtest, das auf dem Bildschirm zu sehen ist, ohne es in einer Wissensdatenbank zu speichern.

## Ein App-Fenster erfassen

1. Hol die App, zu der du etwas fragen möchtest, in den Vordergrund.
2. Drücke deinen Appshots-Kurzbefehl. Appshots hat keinen Kurzbefehl, bis du unter **Tastenkürzel** in **Einstellungen → Appshots** einen festlegst.
3. Das Fenster geht an die SmartBar, das Chatfenster oder die App-Seitenleiste, wenn eines davon vorn geöffnet ist. Andernfalls geht es an die Dynamic Island. Ein kurzes Auslösegeräusch erklingt.
4. Prüfe das angehängte Fenster und stelle dann eine konkrete Frage, etwa „Erkläre den Fehler in diesem Fenster."

## Einstellungen

Öffne **Einstellungen → Appshots**.

| Einstellung | Was sie tut |
| --- | --- |
| **Appshots aktivieren** | Lässt den Kurzbefehl das App-Fenster im Vordergrund hinzufügen. Standardmäßig an. |
| **Ton aufnehmen** | Spielt ein kurzes Auslösegeräusch ab, wenn ein Appshot hinzugefügt wird. Der Ton bestätigt die Aufnahme; prüfe den Anhang trotzdem, bevor du sendest. |
| **Tastenkürzel** | Der Kurzbefehl, der das Fenster hinzufügt. Standardmäßig keiner. Es kann eine Gruppe von Sondertasten sein, etwa beide Tasten **Wahl** zusammen, oder ein gewöhnlicher Kurzbefehl. |

## Das richtige Erfassungswerkzeug wählen

| Ziel | Nutze |
| --- | --- |
| Zum aktuellen App-Fenster fragen | Appshots |
| Vor dem Fragen die Aufmerksamkeit auf einen Bereich lenken | [Bildschirmzeichnung](/de/features/screen-doodle) |
| Den Inhalt der aktuellen App für die spätere Suche speichern | [Schnellerfassung](/de/features/quick-capture) |
| Text aus einem Bild extrahieren | [OCR](/de/ai/ocr) |

Erfasste Inhalte können an das Modell gesendet werden, das du für die Anfrage nutzt. Weitere Möglichkeiten, Kontext hinzuzufügen, findest du unter [Kontextverständnis](/de/features/context-awareness).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Es erscheint kein Kontext | Prüfe **Einstellungen → Berechtigungen**, besonders Bildschirmaufnahme und Bedienungshilfen. |
| Das falsche Fenster wird erfasst | Hol die Ziel-App erneut in den Vordergrund. Appshots erfasst das Fenster einer anderen App, nicht die eigenen Fenster von Enconvo wie die Einstellungen. |
| Der Kurzbefehl tut nichts | Stelle sicher, dass **Appshots aktivieren** an ist und ein **Tastenkürzel** festgelegt ist. |
| Der Kurzbefehl tut etwas anderes | Eine andere App nutzt dieselben Tasten. Ändere das **Tastenkürzel** in **Einstellungen → Appshots**. |

Quicklinks machen aus einer Websuche, einer Webadresse, einer Datei oder einem Ordner oder dem Deeplink einer App einen Befehl, den du aus SmartBar ausführst. Platzhalter füllen den Link mit dem, was du tippst, der Zwischenablage, dem markierten Text oder dem Datum. Enconvo bringt Google-, YouTube- und X-Suchen fertig mit.

Quicklinks öffnen ein Ziel. [Websuche](/de/ai/web-search) holt Suchergebnisse stattdessen in eine KI-Antwort, und [Browsernutzung](/de/features/browser-control) lässt einen Agenten in Webseiten arbeiten.

## Im Web aus SmartBar suchen

1. Öffne SmartBar und finde **Google Search in Browser**, **YouTube Search in Browser** oder **Twitter/X Search in Browser**.
2. Tippe deinen Suchtext als Eingabe des Befehls. Markierter Text funktioniert ebenfalls.
3. Führe den Befehl aus. Die Suche öffnet sich in deinem Standardbrowser.

## Einen Quicklink anlegen

1. Führe **Quicklink erstellen** aus SmartBar aus.
2. Gib einen **Namen** ein, etwa GitHub durchsuchen.
3. Gib den **Link** ein: eine Webadresse, einen Datei- oder Ordnerpfad oder einen Deeplink. Klicke auf **Platzhalter einfügen**, um einen hinzuzufügen, etwa `https://github.com/search?q={argument}`.
4. Um ihn in einer bestimmten App zu öffnen, gib unter **Öffnen mit** einen App-Namen wie Safari, einen App-Pfad oder eine Bundle-ID ein. Lass es leer, um die Standard-App zu nutzen.
5. Klicke auf **Speichern**. Suche in SmartBar nach dem Namen des Quicklinks, um ihn auszuführen.

Wenn du einen Quicklink ausführst, füllt der getippte oder markierte Text sein erstes Argument. Wenn ein erforderliches Argument noch leer ist, fragt Enconvo danach, bevor es den Link öffnet.

| Platzhalter | Gefüllt mit |
| --- | --- |
| `{argument name="Query"}` | Ein Wert, den du tippst, wenn der Quicklink sich öffnet |
| `{clipboard}` | Der Text in der Zwischenablage |
| `{selection}` | Der in der genutzten App markierte Text |
| `{date}`, `{time}`, `{datetime}` | Das aktuelle Datum, die Uhrzeit oder beides |
| `{date format="yyyy-MM-dd"}` | Das Datum im Format, das du angibst |
| `{uuid}` | Eine neue eindeutige ID |

Teste einen neuen Link zuerst mit gewöhnlichem Text, einschließlich Leerzeichen und Satzzeichen.

## Deine Quicklinks verwalten

Führe **Quicklinks durchsuchen** aus SmartBar aus, um jeden Quicklink zu sehen. Von dort kannst du einen öffnen, bearbeiten, duplizieren oder löschen und auf **Neu** klicken, um einen weiteren hinzuzufügen.

Das Menü **Mehr** hat **Quicklinks importieren …**, das Raycast-Exporte von Quicklinks und Einstellungen liest, und **In Downloads exportieren**. Ein Raycast-Einstellungsexport fragt nach der Passphrase, die du beim Export gewählt hast.

## Einstellungen

Öffne **Einstellungen → Plugins → Quicklinks**. Jeder Suchbefehl hat auch seinen eigenen **Link**, etwa `https://www.google.com/search?q={query}`, den du ändern kannst.

| Einstellung | Was sie ändert |
| --- | --- |
| **In neuem Fenster öffnen** | Öffnet Web-Quicklinks in einem neuen Browserfenster. Funktioniert mit Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox und Zen; Safari, Arc und Orion öffnen den Link wie gewohnt. Standardmäßig aus |
| **Wenn kein Text markiert ist** | Was ein `{selection}`-Link tut, wenn nichts markiert ist: **Danach fragen** (Standard) oder **Zwischenablage nutzen** |
| **Vor dem Löschen bestätigen** | Fragt, bevor du einen Quicklink löschst. Standardmäßig an |

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Die falsche Seite öffnet sich | Prüfe den **Link** des Quicklinks und seine Platzhalter und probiere ihn mit einfachem Text |
| Der Browser öffnet sich nicht | Prüfe deinen Standardbrowser, **Öffnen mit** des Quicklinks und dass der Befehl installiert ist |
| Ein `{selection}`-Link fragt nach Text | Nichts war markiert. Markiere zuerst den Text oder setze **Wenn kein Text markiert ist** auf **Zwischenablage nutzen** |

Das Desktop-Haustier ist eine kleine animierte Figur auf deinem Schreibtisch. Es spiegelt wider, was deine Agenten tun, kann Live-Sitzungskarten zeigen und führt dich zu der Sitzung, die Aufmerksamkeit braucht. Klicke darauf, um eine Frage zu stellen oder Enconvo zu öffnen. Es ist getrennt von einem [Avatar](/de/features/avatar), der einem Agenten eine Figur und eine Stimme für Unterhaltungen gibt.

Für andere Aufgaben gibt es [SmartBar](/de/features/smartbar) für eine schnelle Frage oder einen Befehl, das [Chatfenster](/de/ai/chat) für lange Unterhaltungen und Dateien, die [App-Seitenleiste](/de/features/app-sidebar), um neben einer App zu arbeiten, [PopBar](/de/features/popbar), um auf markierten Text zu reagieren, oder die [Dynamic Island](/de/features/dynamic-island) für eine kompakte Eingabe am oberen Bildschirmrand. Die [Fensterverwaltung](/de/features/window-management) vergleicht sie alle.

## Ein Haustier wählen

1. Öffne **Einstellungen → Haustier**.
2. Wähle eine Figur unter **Meine Haustiere** oder finde eine in der **Galerie**.
3. Klicke auf **Haustier wecken**, um es auf deinem Schreibtisch anzuzeigen.
4. Stelle **Beim Tippen öffnen** auf das ein, was ein Klick auf das Haustier öffnen soll.
5. Schalte **Sitzungskarten anzeigen** ein oder aus und passe die **Größe des Haustiers** an.
6. Gehe zurück zum Schreibtisch und klicke auf das Haustier. Was du in Schritt 4 gewählt hast, öffnet sich.

## Einstellungen

| Einstellung | Was sie ändert |
| --- | --- |
| **Haustier wecken** / **Haustier wegschicken** | Zeigt oder verbirgt das Haustier auf deinem Schreibtisch. |
| **Beim Tippen öffnen** | Was ein Klick auf das Haustier öffnet: **Fragefeld** (Voreinstellung), **Dynamic Island**, **Chatfenster** oder **SmartBar**. |
| **Antworten mit** | Der Agent, der auf das antwortet, was du das Haustier fragst. Du kannst ihn auch im Fragefeld ändern. |
| **Sitzungskarten** | Live-Statuskarten der Sitzungen unter dem Haustier. |
| **Größe des Haustiers** | Wie groß das Haustier ist. |

## Eigene Haustiere

**Benutzerdefinierte Haustiere** auf dem Tab **Meine Haustiere** zeigt den Ordner, der deine Haustier-Pakete enthält. Klicke auf **Ordner öffnen**, füge ein Haustier-Paket im unterstützten Format hinzu und wähle das Haustier dann unter **Meine Haustiere** aus. Ein Figurenbild allein ist kein animiertes Haustier-Paket.

Um ein Haustier zu entfernen, klicke auf seiner Karte auf **Entfernen**. Dadurch wird das Paket aus deiner Bibliothek gelöscht; du kannst es aus der Galerie erneut installieren.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Das Haustier ist nicht auf dem Schreibtisch | Klicke auf **Haustier wecken**, prüfe, dass unter **Meine Haustiere** ein Haustier ausgewählt ist, und prüfe die **Größe des Haustiers**. |
| Ein Klick auf das Haustier öffnet das falsche Fenster | Ändere **Beim Tippen öffnen**. |
| Du willst Sprachunterhaltungen oder eine Figur für einen Agenten | Nutze stattdessen einen [Avatar](/de/features/avatar). |

---

Das Desktop-Haustier ist eine kleine animierte Figur auf dem Schreibtisch. Es spiegelt, was die Agenten tun, kann Live-Sitzungskarten zeigen und bringt dich zur Sitzung, die Aufmerksamkeit braucht. Klicke es an, um eine Frage zu stellen oder Enconvo zu öffnen. Es ist getrennt von einem [Avatar](/de/features/avatar), der einem Agenten eine Figur und eine Stimme für Gespräche gibt.

Für andere Aufgaben nutze [SmartBar](/de/features/smartbar) für eine schnelle Frage oder einen Befehl, das [Chatfenster](/de/ai/chat) für lange Gespräche und Dateien, die [App-Seitenleiste](/de/features/app-sidebar), um neben einer App zu arbeiten, [PopBar](/de/features/popbar) für markierten Text oder die [Dynamic Island](/de/features/dynamic-island) für eine kompakte Eingabe oben am Bildschirm. [Fensterverwaltung](/de/features/window-management) vergleicht sie alle.

## Ein Haustier wählen

1. Öffne **Einstellungen → Haustier**.
2. Wähle eine Figur unter **Meine Haustiere** oder finde eine in der **Galerie**.
3. Klicke **Haustier wecken**, um es auf dem Schreibtisch zu zeigen.
4. Setze **Beim Tippen öffnen** auf das, was ein Klick auf das Haustier bringen soll.
5. Schalte **Sitzungskarten zeigen** ein oder aus und passe die **Haustiergröße** an.
6. Geh zurück zum Schreibtisch und klicke das Haustier. Was du in Schritt 4 gewählt hast, öffnet sich.

## Einstellungen

| Einstellung | Was sie ändert |
| --- | --- |
| **Haustier wecken** / **Haustier weglegen** | Zeigt oder verbirgt das Haustier auf dem Schreibtisch. |
| **Beim Tippen öffnen** | Was ein Klick auf das Haustier bringt: **Fragefeld** (Standard), **Dynamic Island**, **Chatfenster** oder **Smart Bar**. |
| **Antworten mit** | Der Agent, der beantwortet, was du das Haustier fragst. Du kannst ihn auch im Fragefeld wechseln. |
| **Sitzungskarten** | Live-Statuskarten der Sitzungen unter dem Haustier. |
| **Haustiergröße** | Wie groß das Haustier ist. |

## Eigene Haustiere

**Eigene Haustiere**, im Tab **Meine Haustiere**, zeigt den Ordner mit deinen Haustierpaketen. Klicke **Ordner öffnen**, lege ein Haustierpaket im unterstützten Format ab und wähle das Haustier unter **Meine Haustiere**. Ein einzelnes Figurenbild ist kein animiertes Haustierpaket.

Um ein Haustier zu entfernen, klicke **Entfernen** auf seiner Karte. Das löscht das Paket aus der Bibliothek; du kannst es aus der Galerie erneut installieren.

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Das Haustier ist nicht auf dem Schreibtisch | Klicke **Haustier wecken**, prüfe, ob unter **Meine Haustiere** eines gewählt ist, und prüfe die **Haustiergröße**. |
| Ein Klick auf das Haustier öffnet das falsche Fenster | Ändere **Beim Tippen öffnen**. |
| Du willst Sprachgespräche oder eine Figur für einen Agenten | Nutze stattdessen einen [Avatar](/de/features/avatar). |

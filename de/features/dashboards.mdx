Ein Dashboard ist eine Seite mit Zahlen und Grafiken, die ein Agent aus deinen Daten baut, für Kennzahlen, die du verfolgst, prüfst oder berichtest. Jede Zahl ist mit der Zeile verknüpft, aus der sie stammt, sodass du sie überprüfen kannst. Nutze es, wenn du auf die Zahlen zurückkommen wirst; für eine einmalige Antwort frage einfach im Chat.

## Ein Dashboard erstellen

1. Starte einen neuen Chat und wähle unter dem Nachrichtenfeld **Dashboard** oder bitte in einem beliebigen Chat darum.
2. Hänge die Daten an: eine CSV-, TSV- oder JSON-Datei, oder klicke in der Zeile **Etwas erstellen** auf **Tabelle öffnen**. Du kannst den Agenten auch auf einen verbundenen Dienst, eine Datei auf deinem Mac oder eine Webadresse verweisen.
3. Sage, was verfolgt werden soll und wie es aufgeschlüsselt wird.

Beispiel:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

Das Dashboard öffnet sich neben dem Chat. Wenn der Agent Filter hinzufügt, erscheint jeder oben als Menü, Schalter oder Feld.

## Eine Zahl prüfen

1. Klicke in der Kopfzeile des Dashboards auf **Zahl prüfen**.
2. Klicke auf eine beliebige Zahl.
3. Enconvo zeigt die Zeile dahinter, woher sie stammt und ob beide übereinstimmen.

Um nach einer Zahl zu fragen, kommentiere sie. Beginne den Kommentar mit `@Enconvo`, um eine Antwort vom Agenten zu erhalten.

## Sehen, woher die Daten kommen

Klicke auf **Quellen**. Jeder Datensatz zeigt, woher er stammt, wie viele Zeilen er hat und wann er sich zuletzt geändert hat. Überfällige Daten zeigen **Veraltet**. Klicke auf **CSV herunterladen**, um einen Datensatz zu speichern.

## Die Zahlen aktuell halten

Ein Dashboard, das aus einem verbundenen Dienst, einer Datei auf deinem Mac oder einer Webadresse gebaut wurde, kann sich selbst aktualisieren, sobald du es erlaubst.

1. Wenn das Dashboard fragt **Diese Zahlen aktuell halten?**, prüfe, was jede Quelle liest, und klicke dann auf **Erlauben**. Du kannst auch unter **Quellen** neben einer Quelle auf **Aktualisierungen erlauben** klicken.
2. Die Zahlen werden nach dem Zeitplan aktualisiert, den der Agent festgelegt hat, etwa **Stündlich** oder **Beim Aktualisieren**. Klicke auf **Aktualisieren**, um sie sofort zu aktualisieren.
3. Um das zu beenden, klicke neben der Quelle auf **Aktualisierung stoppen**.

Schlägt eine Aktualisierung fehl, behält das Dashboard die letzten Zahlen und nennt den Grund.

<Note>
Eine Quelle, die nicht angibt, dass sie nur Daten liest, läuft nur, wenn du auf **Aktualisieren** klickst. In einem geteilten Dashboard sieht jeder darin, was die Quelle liest.
</Note>

## Ein Dashboard herunterladen oder verschieben

Klicke auf **Herunterladen** und wähle:

| Option | Was du bekommst |
| --- | --- |
| **PDF herunterladen** | Ein PDF der Seite |
| **Bild herunterladen** | Ein Bild der Seite |
| **HTML herunterladen** | Eine HTML-Datei, die sich in jedem Browser öffnet |
| **Projekt laden (.zip)** | Das ganze Projekt, zum Importieren auf einem anderen Computer |

Um ein Projekt einzubringen, klicke in der Bibliothek **Artefakte** auf **Importieren** und wähle die ZIP-Datei. Kommentare kommen mit; Aktualisierungen aus einem verbundenen Dienst müssen dort erneut erlaubt werden.

Um das Dashboard mit anderen Personen oder deinem Team zu teilen, klicke auf **Teilen**. Siehe [Artefakte](/de/features/artifacts). Das Dashboard öffnet sich auch in den Apps für iPhone und Android; siehe [Artefakte](/de/features/artifacts).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Eine Zahl und ihre Zeile stimmen nicht überein | Frage den Agenten in einem Kommentar danach oder bitte ihn, die Berechnung zu korrigieren |
| Eine Quelle zeigt **Veraltet** | Klicke auf **Aktualisieren** oder erlaube Aktualisierungen dafür |
| **Die Zahlen konnten nicht aktualisiert werden** | Lies den Grund, behebe den Zugriff der Quelle und klicke dann auf **Aktualisieren** |
| Das Dashboard ist leer | Beschreibe das Dashboard und seine Daten in einem Chat |

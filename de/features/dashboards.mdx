Ein Dashboard ist eine Seite mit Zahlen und Diagrammen, die ein Agent aus deinen Daten baut, für Werte, die du verfolgst, prüfst oder berichtest. Jede Zahl ist an die Zeile gebunden, aus der sie kommt, damit du sie prüfen kannst. Nutze es, wenn du zu den Zahlen zurückkommst; für eine einmalige Antwort frag einfach im Chat.

## Ein Dashboard erstellen

1. Starte einen neuen Chat und wähle **Dashboard** unter dem Nachrichtenfeld, oder bitte in einem beliebigen Chat darum.
2. Hänge die Daten an: eine CSV-, TSV- oder JSON-Datei, oder klicke **Eine Tabelle öffnen** in der Zeile **Etwas erstellen**. Du kannst den Agenten auch auf einen verbundenen Dienst, eine Datei auf dem Mac oder eine Webadresse zeigen.
3. Sag, was verfolgt und wie es aufgeschlüsselt werden soll.

Beispiel:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

Das Dashboard öffnet sich neben dem Chat. Fügt der Agent Filter hinzu, erscheint jeder oben als Menü, Schalter oder Feld.

## Eine Zahl prüfen

1. Klicke **Eine Zahl prüfen** in der Kopfzeile des Dashboards.
2. Klicke eine Zahl.
3. Enconvo zeigt die Zeile dahinter, woher sie kommt und ob beides übereinstimmt.

Um nach einer Zahl zu fragen, kommentiere sie. Beginne den Kommentar mit `@Enconvo`, um eine Antwort vom Agenten zu bekommen.

## Sehen, woher die Daten kommen

Klicke **Quellen**. Jeder Datensatz zeigt, woher er kommt, wie viele Zeilen er hat und wann er sich zuletzt geändert hat. Überfällige Daten zeigen **Veraltet**. Klicke **CSV herunterladen**, um einen Datensatz zu speichern.

## Die Zahlen aktuell halten

Ein Dashboard aus einem verbundenen Dienst, einer Datei auf dem Mac oder einer Webadresse kann sich selbst aktualisieren, sobald du es erlaubst.

1. Wenn das Dashboard fragt **Diese Zahlen aktuell halten?**, prüfe, was jede Quelle liest, und klicke **Erlauben**. Du kannst auch neben einer Quelle unter **Quellen** auf **Updates erlauben** klicken.
2. Die Zahlen aktualisieren sich nach dem Zeitplan, den der Agent gesetzt hat, etwa **Jede Stunde** oder **Beim Aktualisieren**. Klicke **Aktualisieren**, um sie jetzt zu aktualisieren.
3. Zum Stoppen klicke neben der Quelle auf **Aktualisieren stoppen**.

Schlägt ein Update fehl, behält das Dashboard die letzten Zahlen und sagt warum.

<Note>
Eine Quelle, die nicht angibt, nur zu lesen, läuft nur, wenn du auf **Aktualisieren** klickst. In einem geteilten Dashboard sieht jeder darin, was die Quelle liest.
</Note>

## Ein Dashboard herunterladen oder verschieben

Klicke **Herunterladen** und wähle:

| Option | Was du bekommst |
| --- | --- |
| **PDF herunterladen** | Ein PDF der Seite |
| **Bild herunterladen** | Ein Bild der Seite |
| **HTML herunterladen** | Eine HTML-Datei, die in jedem Browser öffnet |
| **Projekt herunterladen (.zip)** | Das ganze Projekt, zum Import auf einem anderen Computer |

Um ein Projekt hereinzuholen, klicke **Importieren** in der Bibliothek **Artefakte** und wähle die Zip. Kommentare kommen mit; Updates aus einem verbundenen Dienst musst du dort erneut erlauben.

Um das Dashboard mit Personen oder deinem Team zu teilen, klicke **Teilen**. Siehe [Artefakte](/de/features/artifacts). Das Dashboard öffnet sich auch in den iPhone- und Android-Apps; siehe [Artefakte](/de/features/artifacts).

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Eine Zahl und ihre Zeile passen nicht | Frag den Agenten in einem Kommentar danach oder bitte ihn, die Berechnung zu korrigieren |
| Eine Quelle zeigt **Veraltet** | Klicke **Aktualisieren** oder erlaube Updates dafür |
| **Zahlen konnten nicht aktualisiert werden** | Lies den Grund, behebe den Zugang der Quelle und klicke **Aktualisieren** |
| Das Dashboard ist leer | Beschreibe das Dashboard und seine Daten in einem Chat |

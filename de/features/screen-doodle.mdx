Mit der Bildschirmzeichnung markierst du einen Teil des Bildschirms, bevor du deinen Agent dazu fragst. Zeichne Pfeile, Kreise, Hervorhebungen oder Notizen und sende dann. Das markierte Bildschirmfoto wird als Bild an deinen Chat angehängt, in der Dynamic Island, es sei denn, du hast gerade einen anderen Enconvo-Chat wie das Chatfenster benutzt.

## Deinen Bildschirm markieren

1. Hol den Inhalt, zu dem du etwas fragen möchtest, in den Vordergrund.
2. Klicke doppelt mit der rechten Maustaste, um die Bildschirmzeichnung zu öffnen, oder drücke das **Tastenkürzel**, das du unter **Einstellungen → Bildschirmzeichnung** festgelegt hast.
3. Ist **Zuerst einen Bereich erfassen** an, zieh, um den Bereich auszuwählen. Andernfalls zeichnest du direkt über den Live-Bildschirm.
4. Wähle in der Werkzeugleiste ein Werkzeug und markiere die gemeinte Stelle.
5. Klicke auf **Senden** (das Papierflugzeug) oder drücke **⌘↩**.
6. Prüfe das angehängte Bild und tippe eine Anfrage, etwa „Was bedeutet die hervorgehobene Warnung?"

Die Bildschirmzeichnung hat keinen Kurzbefehl, bis du einen festlegst. Der doppelte Rechtsklick funktioniert sofort.

### Eine gesprochene Beschriftung hinzufügen

Halte die linke Taste **Wahl** gedrückt und sprich, um die Form zu beschreiben, die du gerade gezeichnet hast. Deine Worte erscheinen als Text daneben. Damit die Bildschirmzeichnung nach jeder gezeichneten Form zuhört, aktiviere **Nach jeder Form sprechen** in der Werkzeugleiste und mache eine Pause, um jede Beschriftung abzuschließen.

## Werkzeuge

| Werkzeug oder Aktion | Taste |
| --- | --- |
| Pfeil | **A** |
| Linie | **L** |
| Stift | **P** |
| Textmarker | **H** |
| Rechteck | **R** |
| Kreis | **O** |
| Zähler (nummerierte Markierungen) | **N** |
| Text | **T** |
| Auswählen | **V** |
| Radierer | **E** |
| Farbe | **C** |
| Linienstärke | **⌘** + Scrollen |
| Whiteboard | **B** |
| Cursor-Hervorhebung | **K** |
| Sichern unter … | **⌘S** |
| Senden | **⌘↩** |

Die Werkzeugleiste hat außerdem **Rückgängig**, **Wiederholen**, **Löschen**, **In die Zwischenablage kopieren** und **Schließen**.

## Einstellungen

Öffne **Einstellungen → Bildschirmzeichnung**.

| Einstellung | Was sie tut |
| --- | --- |
| **Zuerst einen Bereich erfassen** | Wähle vor dem Zeichnen einen Bereich. Schalte es aus, um direkt auf dem Live-Bildschirm zu zeichnen. Standardmäßig an. |
| **Tastenkürzel** | Öffnet oder schließt die Bildschirmzeichnung. Standardmäßig leer. |
| **Doppelter Rechtsklick** | Öffnet oder schließt die Bildschirmzeichnung mit einem schnellen doppelten Rechtsklick. Standardmäßig an. |

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Das Overlay öffnet sich nicht | Prüfe das **Tastenkürzel** und den **Doppelten Rechtsklick** in **Einstellungen → Bildschirmzeichnung** sowie die [macOS-Berechtigungen](/de/configuration/permissions). |
| Du brauchst nur das ganze App-Fenster | Nutze stattdessen [Appshots](/de/features/appshots). |

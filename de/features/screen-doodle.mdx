Mit Bildschirmzeichnung markierst du einen Teil des Bildschirms, bevor du deinen Agenten dazu fragst. Zeichne Pfeile, Kreise, Markierungen oder Notizen und sende sie. Der markierte Screenshot wird deinem Chat als Bild angehängt, in der Dynamic Island, es sei denn, du hast gerade einen anderen Enconvo-Chat genutzt, etwa das Chatfenster.

## Den Bildschirm markieren

1. Hole den Inhalt, zu dem du fragen willst, nach vorn.
2. Klicke doppelt mit der rechten Maustaste, um Bildschirmzeichnung zu öffnen, oder drücke den **Hotkey**, den du unter **Einstellungen → Bildschirmzeichnung** gesetzt hast.
3. Wenn **Zuerst Bereich aufnehmen** an ist, ziehe, um den Bereich auszuwählen. Sonst zeichne direkt über den Live-Bildschirm.
4. Wähle ein Werkzeug in der Symbolleiste und markiere die Stelle, die du meinst.
5. Klicke auf **Senden** (das Papierflugzeug) oder drücke **⌘↩**.
6. Prüfe das angehängte Bild und tippe eine Anfrage, etwa „Was bedeutet die markierte Warnung?“

Bildschirmzeichnung hat keinen Hotkey, bis du einen setzt. Ein doppelter Rechtsklick funktioniert sofort.

### Eine gesprochene Beschriftung hinzufügen

Halte die linke **Option**-Taste und sprich, um die Form zu beschreiben, die du gerade gezeichnet hast. Deine Worte erscheinen daneben als Text. Damit Bildschirmzeichnung nach jeder gezeichneten Form zuhört, schalte **Nach jeder Form sprechen** in der Symbolleiste ein und mache eine Pause, um jede Beschriftung abzuschließen.

## Werkzeuge

| Werkzeug oder Aktion | Taste |
| --- | --- |
| Pfeil | **A** |
| Linie | **L** |
| Stift | **P** |
| Textmarker | **H** |
| Rechteck | **R** |
| Kreis | **O** |
| Zähler (nummerierte Markierungen) | **N** |
| Text | **T** |
| Auswählen | **V** |
| Radierer | **E** |
| Farbe | **C** |
| Linienstärke | **⌘** + Scrollen |
| Whiteboard | **B** |
| Cursor-Hervorhebung | **K** |
| Sichern unter… | **⌘S** |
| Senden | **⌘↩** |

Die Symbolleiste hat außerdem **Rückgängig**, **Wiederholen**, **Löschen**, **In die Zwischenablage kopieren** und **Schließen**.

## Einstellungen

Öffne **Einstellungen → Bildschirmzeichnung**.

| Einstellung | Was sie tut |
| --- | --- |
| **Zuerst Bereich aufnehmen** | Wähle einen Bereich, bevor du zeichnest. Schalte es aus, um direkt auf den Live-Bildschirm zu zeichnen. Standardmäßig an. |
| **Hotkey** | Öffnet oder schließt Bildschirmzeichnung. Standardmäßig leer. |
| **Doppelter Rechtsklick** | Öffnet oder schließt Bildschirmzeichnung mit einem schnellen doppelten Rechtsklick. Standardmäßig an. |

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Das Overlay öffnet sich nicht | Prüfe **Hotkey** und **Doppelter Rechtsklick** unter **Einstellungen → Bildschirmzeichnung** und die [macOS-Berechtigungen](/de/configuration/permissions). |
| Du brauchst nur das ganze App-Fenster | Nutze stattdessen [Appshots](/de/features/appshots). |

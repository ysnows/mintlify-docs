---
title: "Visuelle Antworten"
description: "Erhalte ein Diagramm, eine Grafik oder ein interaktives Widget direkt im Chat statt reinem Text."
---

Bitte einen Agenten, seine Antwort zu zeigen, und er zeichnet das Visuelle direkt in die Unterhaltung: ein SVG-Diagramm, eine HTML-Vorschau oder ein interaktives Widget, das du anklicken und anpassen kannst. Nutze es, wenn ein Bild, eine Grafik oder ein kleiner Rechner mehr erklärt als ganze Absätze. Der Agent braucht dafür seine visuellen Werkzeuge.

Eine visuelle Antwort lebt in der Unterhaltung. Wenn du etwas behalten, bearbeiten, präsentieren oder teilen möchtest, etwa eine Präsentation, ein Dashboard, ein Design oder ein Dokument, bitte stattdessen um ein [Artefakt](/de/features/artifacts).

## Um ein Visual bitten

Sage, welche Frage das Visual beantworten soll:

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

Gib bei einer Grafik oder einem Rechner die Daten und ihre Einheiten an. Auch ein ansprechendes Visual kann falsche Fakten oder Rechnungen enthalten, prüfe sie also.

## Links, Karten und Grafiken in Antworten

Manche Antworten werden von selbst visuell:

- **Links** erscheinen als Karten mit dem Symbol der Website.
- **Orte** erscheinen auf einer echten Karte mit dem Namen des Ortes. Mehrere Orte teilen sich eine nummerierte Karte, und eine Route zeigt ihre Linie mit Zeit und Entfernung.
- Bei **Grafiken**, die der Agent erstellt, werden die Farben geprüft, sodass jede Datenreihe auch bei Farbenblindheit und im hellen wie im dunklen Erscheinungsbild unterscheidbar bleibt. Zahlen, Daten und Statuswörter erscheinen in deiner Sprache.

## Ein Visual verwenden und speichern

1. Warte, bis das Visual fertig gezeichnet ist, und nutze dann seine Bedienelemente. Manche Widgets senden einen Folgeprompt zurück in den Chat.
2. Zeige auf das fertige Visual und klicke oben rechts auf **⋯**.
3. Wähle **In die Zwischenablage kopieren** oder **Datei herunterladen** und bestätige den Dateinamen. Visuals, die mit den eigenen Karten, Tabellen und Grafiken der App gezeichnet sind, bieten stattdessen **Bild herunterladen** an, was ein PNG in deinen Ordner „Downloads“ speichert.

Ein gespeichertes Bild hält einen Moment des Visuals fest; seine interaktiven Bedienelemente bleiben nicht erhalten. Nachdem du die Werte eines Widgets geändert hast, setzt **Werte zurücksetzen** im selben Menü sie zurück.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Du bekommst Code statt eines Visuals | Prüfe die aktivierten Werkzeuge des Agenten und bitte ihn dann, das Ergebnis in der Unterhaltung zu zeigen |
| Ein Widget wirkt unvollständig | Warte, bis es fertig ist, und bitte dann um eine einfachere Version |
| Du brauchst eine Bilddatei, kein Chat-Widget | Nutze die [Bilderzeugung](/de/ai/image-generation) |
| Du möchtest die Grafik behalten und später wiederkommen | Bitte um ein [Dashboard](/de/features/dashboards) |

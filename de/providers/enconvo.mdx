title: "Enconvo Cloud"
description: "Nutze Modelle, Stimmen und Medienwerkzeuge über dein Enconvo-Konto, ohne Anbieterschlüssel."
---

Enconvo Cloud gibt dir Modelle mehrerer Unternehmen plus Sprache, Bild, Video und Web-Werkzeuge über dein Enconvo-Konto. Es gibt keine API-Schlüssel zu verwalten: Anfragen nutzen die Punkte deines Plans. Das ist der schnellste Weg zum Start.

## Einrichten

<Steps>
  <Step title="Anmelden">
    Melde dich bei deinem Enconvo-Konto an. Siehe [Konto](/de/configuration/account).
  </Step>
  <Step title="Enconvo Cloud wählen">
    Öffne die Einstellungsseite für das, was du tun willst, etwa **KI-Modell**, **Text-zu-Sprache** oder **Bilderzeugung**, und wähle den Anbieter mit der Bezeichnung **Enconvo Cloud** oder **Enconvo Cloud Plan**.
  </Step>
  <Step title="Ein Modell oder eine Stimme wählen">
    Wähle ein Modell oder eine Stimme und führe eine kurze Anfrage aus.
  </Step>
</Steps>

Jede Funktion hat ihre eigene Anbieterwahl. Enconvo Cloud für den Chat zu wählen schaltet Sprache, Bilder, Video, Embeddings, Reranking oder Web-Werkzeuge nicht um. Setze jedes dort, wo du es willst.

## Enconvos eigene Modelle

Enconvo Cloud hat drei eigene Modelle, benannt nach der Arbeit, für die sie passen:

| Modell | Nutze es für |
| --- | --- |
| **Enconvo Fast** | Schnelle Züge: kurze Antworten, Umschreibungen, kleine Aktionen. Das ist das Modell, mit dem **Enconvo Cloud Plan** startet, und die Vorgabe für KI-Befehle. |
| **Enconvo Balanced** | Alltägliche Arbeit mit ein paar Schritten. |
| **Enconvo Ultra** | Schwere Aufgaben, die tiefes Denken brauchen. |

Sie stehen zuerst unter **Enconvo Cloud Plan**, und [Auto Route](/de/providers/auto-route) nutzt sie für seine Standardrouten.

## Ein Modell in der Auswahl finden

Die Liste **Enconvo Cloud Plan** gruppiert Modelle nach Anbieter: zuerst Enconvos eigene Modelle, dann Anthropic, OpenAI, Google und der Rest, jeweils mit einer Zahl. Ein Anbieter zeigt seine vier neuesten Modelle. Klicke auf **N frühere Modelle anzeigen**, um die anderen zu sehen. Die Suche listet jeden Treffer, und das Modell, das dein Chat nutzt, wird immer angezeigt. Claude-Modelle stehen ohne das Präfix „Claude“, etwa **Sonnet 5.5** und **Opus 5.5**.

In der Modellauswahl des Chatfensters kann ein Cloud-Modell ein Kennzeichen tragen:

| Kennzeichen | Bedeutung |
| --- | --- |
| **Neu** | In den letzten 14 Tagen hinzugefügt. |
| Ein Rabatt, etwa **50% OFF** | Das Modell kostet vorerst weniger. Zeige auf die Zeile oder erreiche sie mit den Pfeiltasten, um den regulären Preis zu sehen. |
| **Kostenlos** | Das Modell verbraucht keine Punkte. |
| **Vorschau** | Eine frühe Version des Modells. |
| Ein Datum | Der Tag, an dem das Modell Enconvo Cloud verlässt. |

Enconvo Cloud setzt die Kennzeichen, sodass sie sich ohne App-Update ändern.

## Punkte und Nutzung

Modelle kosten unterschiedlich viele Punkte. Die Einstellungen zeigen den Cloud-Preis neben jedem Modell und Anbieter, zusammen mit dem, was dein Plan enthält, etwa die freien Minuten, die du diesen Monat noch hast. Siehe die Seiten [Cloud-Plan](https://www.enconvo.com/cloud-plan) und [Cloud-Preise](https://www.enconvo.com/cloud-pricing) für aktuelle Pläne und Tarife. Um zu sehen, was du genutzt hast, öffne **Einstellungen → Punktenutzung**.

[Auto Route](/de/providers/auto-route), das Standardmodell, läuft auf Enconvo-Cloud-Modellen. Die Route für jede Nachricht zu wählen ist kostenlos. Das Modell, das antwortet, verbraucht Punkte.

Manche Cloud-Dienste sind für jedes angemeldete Konto kostenlos:

- Websuche mit **Enconvo Cloud** und **DeepSeek (Enconvo Cloud)**. Siehe [Websuche](/de/ai/web-search).
- Spracherkennung mit **Enconvo Cloud Fast**. Siehe [Spracherkennung](/de/ai/speech-recognition).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Anfragen bitten dich, dich anzumelden | Melde dich unter **Einstellungen → Konto** an. |
| Anfragen schlagen mit einem Punkte- oder Saldo-Fehler fehl | Prüfe **Einstellungen → Punktenutzung**, dann deinen Plan auf der Seite [Cloud-Plan](https://www.enconvo.com/cloud-plan). |
| Ein Modell fehlt | Die Auswahl zeigt, was dein Plan enthält. Klicke neben **Modellname** auf **Aktualisieren**. |

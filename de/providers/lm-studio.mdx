title: "LM Studio"
description: "Mit Modellen chatten, die LM Studio auf dem Mac oder einem anderen Computer bereitstellt."
---

Nutze LM Studio, um Modelle auf eigener Hardware auszuführen, auf diesem Mac oder einem anderen Computer im Netzwerk. Enconvo schickt Chats an den LM-Studio-Server, deshalb ist kein Anbieterkonto nötig.

## Auf diesem Mac verbinden

<Steps>
  <Step title="LM Studio starten">
    Lade in [LM Studio](https://lmstudio.ai/) ein Modell und starte den lokalen API-Server.
  </Step>
  <Step title="Enconvo darauf richten">
    Öffne **Einstellungen → KI-Modell → LM Studio**. Unter **Authentifizierung** lasse **BaseUrl** bei `http://127.0.0.1:1234/v1`, außer du hast den Port von LM Studio geändert.
  </Step>
  <Step title="Modell wählen">
    Wähle ein Modell unter **Modellname** und sende eine kurze Nachricht. Eine Antwort bedeutet, dass die Verbindung funktioniert.
  </Step>
</Steps>

## Mit einem anderen Computer verbinden

1. Stelle auf dem anderen Computer LM Studio so ein, dass es Verbindungen aus deinem Netzwerk annimmt, nicht nur von sich selbst.
2. Setze in Enconvo **BaseUrl** auf die Netzwerkadresse dieses Computers, mit Port und Pfad. `127.0.0.1` und `localhost` meinen immer den Mac, auf dem Enconvo läuft.
3. Blockiert macOS die Verbindung, schalte Enconvo unter **Systemeinstellungen → Datenschutz & Sicherheit → Lokales Netzwerk** ein.

Öffne den Server nur für Netzwerke, denen du vertraust.

## Modelle und Optionen

| Einstellung | Was sie tut |
| --- | --- |
| **Modellname** | Das Modell, das dieser Anbieter nutzt. **Aktualisieren** daneben lädt die Liste vom Server neu. |
| **Response Timeout** | Wie lange auf den Start oder die Fortsetzung einer Antwort gewartet wird. Die Vorgabe ist **Kein Limit**; lange Prompts können auf eigener Hardware viele Minuten bis zum ersten Wort brauchen. |

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Verbindung abgelehnt | Prüfe, ob LM Studio läuft und **BaseUrl** die richtige Adresse und den richtigen Port hat. Bei einem anderen Computer prüfe, ob er Netzwerkverbindungen annimmt. |
| Netzwerk nicht erreichbar | Prüfe das Netzwerk und die Berechtigung **Lokales Netzwerk** in den Systemeinstellungen. |
| Die Modellliste ist leer | Lade ein Modell in LM Studio herunter oder ein und klicke dann auf **Aktualisieren**. |
| Eine Antwort bricht unterwegs ab | Setze **Response Timeout** auf einen längeren Wert oder **Kein Limit**. |
| Werkzeuge oder Bilder schlagen fehl | Wähle ein Modell, das Tool-Aufrufe oder Bildeingabe unterstützt. |
| Nicht genug Speicher | Wähle ein kleineres Modell oder kürze die Eingabe. |

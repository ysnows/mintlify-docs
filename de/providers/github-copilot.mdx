---
title: "GitHub Copilot"
description: "Melde dich mit einem GitHub-Konto an, das einen Copilot-Plan hat, und chatte mit den Modellen deines Plans."
---

Nutze deinen GitHub-Copilot-Plan als KI-Modell-Anbieter in Enconvo. Du meldest dich mit dem GitHub-Konto an, das den Plan hat; ein API-Schlüssel ist nicht dabei. Premium-Modelle zählen zu den Premium-Anfragen deines Plans.

## Verbinden

<Steps>
  <Step title="Anbieter öffnen">
    Öffne **Einstellungen → KI-Modell → GitHub Copilot**.
  </Step>
  <Step title="Anmeldung starten">
    Klicke unter **Authentifizierung** auf **Verbinden**.
  </Step>
  <Step title="Code bei GitHub eingeben">
    Dein Browser öffnet die Geräteseite von GitHub, und Enconvo zeigt den Code, den du dort eingibst. Gib den Code ein und genehmige die Anmeldung.
  </Step>
  <Step title="Konto prüfen">
    Kehre zu Enconvo zurück und prüfe, dass das gemeinte GitHub-Konto verbunden ist.
  </Step>
  <Step title="Modell wählen">
    Wähle ein Modell und probiere eine kurze Anfrage.
  </Step>
</Steps>

Wenn du den Code-Dialog von Enconvo schließt, bevor du genehmigst, bricht die Anmeldung ab.

## Modelle und Optionen

Die Modellliste zeigt nur die Modelle, die dein Copilot-Plan nutzen kann, mit dem eigenen Chat-Standard von Copilot zuerst. Copilot Free bietet weniger Modelle als die bezahlten Pläne, deshalb kann ein Modell, das du anderswo gesehen hast, fehlen. Jedes Modell nutzt die Reasoning-Stufen, die Copilot dafür anbietet.

## Auf dem iPhone

Die iPhone-App kann sich ebenfalls bei GitHub Copilot anmelden, für Phone-Chats auf dem Telefon. Siehe [Phone-Chats](/de/integrations/iphone-phone-chats).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Die Anmeldung wird nicht fertig | Gib den Code auf der GitHub-Seite ein, bevor er abläuft, und klicke dann erneut auf **Verbinden**, um einen neuen Code zu bekommen. |
| Das gewünschte Modell fehlt | Dein Copilot-Plan enthält es nicht; wähle ein anderes Modell oder erweitere den Plan. |
| Eine Anfrage schlägt mit einem Modellfehler fehl | Wähle ein Modell aus der aktuellen Liste; ein Standard, der gewählt wurde, bevor sich dein Plan geändert hat, wird vielleicht nicht mehr angeboten. |
| Rate oder Nutzungslimit | Die Premium-Anfragen deines Plans und die Rate-Limits von GitHub. |

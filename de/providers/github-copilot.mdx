---
title: "GitHub Copilot"
description: "Melde dich mit einem GitHub-Konto an, das einen Copilot-Tarif hat, und chatte mit den Modellen deines Tarifs."
---

Nutze deinen GitHub-Copilot-Tarif als KI-Modell-Anbieter in Enconvo. Du meldest dich mit dem GitHub-Konto an, das den Tarif hat; ein API-Schlüssel ist nicht beteiligt. Premium-Modelle zählen auf die Premium-Anfragen deines Tarifs.

## Verbinden

<Steps>
  <Step title="Den Anbieter öffnen">
    Öffne **Einstellungen → KI-Modell → GitHub Copilot**.
  </Step>
  <Step title="Die Anmeldung starten">
    Klicke unter **Authentifizierung** auf **Verbinden**.
  </Step>
  <Step title="Den Code auf GitHub eingeben">
    Dein Browser öffnet die Geräteseite von GitHub, und Enconvo zeigt den Code, den du dort eingeben sollst. Gib den Code ein und autorisiere die Anmeldung.
  </Step>
  <Step title="Das Konto prüfen">
    Kehre zu Enconvo zurück und prüfe, ob das gewünschte GitHub-Konto verbunden ist.
  </Step>
  <Step title="Ein Modell wählen">
    Wähle ein Modell und probiere eine kurze Anfrage aus.
  </Step>
</Steps>

Wenn du den Code-Dialog von Enconvo schließt, bevor du autorisierst, wird die Anmeldung abgebrochen.

## Modelle und Optionen

Die Modellliste zeigt nur die Modelle, die dein Copilot-Tarif nutzen kann, mit dem eigenen Chat-Standard von Copilot an erster Stelle. Copilot Free bietet weniger Modelle als die kostenpflichtigen Tarife, ein Modell, das du anderswo gesehen hast, ist hier also möglicherweise nicht aufgelistet. Jedes Modell nutzt die Stufen des Denkaufwands, die Copilot dafür anbietet.

## Auf dem iPhone

Die iPhone-App kann sich ebenfalls bei GitHub Copilot anmelden, für Telefon-Chats auf dem Telefon. Siehe [Telefon-Chats](/de/integrations/iphone-phone-chats).

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Die Anmeldung wird nicht abgeschlossen | Gib den Code auf der Seite von GitHub ein, bevor er abläuft, und klicke dann erneut auf **Verbinden**, um einen neuen Code zu erhalten. |
| Das gewünschte Modell ist nicht aufgelistet | Dein Copilot-Tarif enthält es nicht; wähle ein anderes Modell oder wechsle den Tarif. |
| Eine Anfrage schlägt mit einem Modellfehler fehl | Wähle ein Modell aus der aktuellen Liste; ein Standard, den du vor einer Änderung deines Tarifs gewählt hast, wird möglicherweise nicht mehr angeboten. |
| Raten- oder Nutzungslimit | Die Premium-Anfragen deines Tarifs und die Ratenlimits von GitHub. |

Nutze Alibabas Qwen-Modelle in Chats, Agenten und KI-Befehlen. Verbinde dich mit einem API-Schlüssel von Alibaba Cloud Model Studio; Alibaba Cloud rechnet die Nutzung auf dein Konto ab. Für den Dienst in Festlandchina (Bailian) nutze [DashScope](/de/providers/dashscope).

## Verbinden

<Steps>
  <Step title="Einen API-Schlüssel holen">
    Erstelle einen Schlüssel in [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="In Enconvo hinzufügen">
    Öffne **Einstellungen → KI-Modell → Qwen**. Füge unter **Authentifizierung** den Schlüssel in **API-Schlüssel** ein und klicke auf **Prüfen**.
  </Step>
  <Step title="Ein Modell wählen">
    Wähle ein Modell unter **Modellname** und sende eine kurze Nachricht. Eine Antwort bedeutet, die Verbindung funktioniert.
  </Step>
</Steps>

Qwen verbindet sich nur mit einem API-Schlüssel.

## Modelle und Optionen

| Einstellung | Was sie bewirkt |
| --- | --- |
| **Modellname** | Das Modell, das dieser Anbieter nutzt. **Aktualisieren** daneben lädt die Liste neu; **Modelle verwalten** (das Zahnrad) fügt Modelle hinzu oder stellt sie wieder her. |
| **Base Url** | In der Anmeldedaten. Der Standard ist der internationale Endpunkt, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Ändere ihn, wenn dein Schlüssel zu einer anderen Region gehört. |

## Fehlerbehebung

| Problem | Was du tust |
| --- | --- |
| **Prüfen** schlägt fehl | Prüfe, dass Schlüssel und **Base Url** zur selben Region gehören, und füge dann den ganzen Schlüssel erneut ein. |
| Ein Modell fehlt | Klicke neben **Modellname** auf **Aktualisieren**. Um selbst ein Modell hinzuzufügen, nutze **Modelle verwalten**. |
| Fehler zu Rate oder Nutzungslimit | Prüfe Nutzung und Kontingent in Model Studio oder wechsle vorerst zu einem anderen Anbieter. |

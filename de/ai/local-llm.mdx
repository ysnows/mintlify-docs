title: "Lokale Modelle"
description: "Führe Modelle auf deiner eigenen Hardware aus und behalte eine ganze Aufgabe auf deinem Mac."
---

Führe Modelle auf deinem Mac oder auf einem anderen Computer aus, der dir gehört, wenn Chats privat bleiben oder ohne Anbieterkonto funktionieren sollen. Enconvo hat eine eingebaute Engine und verbindet sich außerdem mit Ollama und LM Studio.

## Eine Laufzeitumgebung wählen

| Laufzeitumgebung | Am besten für | Einrichtung |
| --- | --- | --- |
| [Local LLM (MLX)](/de/providers/mlx) | Modelle innerhalb von Enconvo auf einem Apple-Silicon-Mac mit macOS 15 oder neuer ausführen | Wähle in den Einstellungen ein Modell und lade es herunter |
| [Ollama](/de/providers/ollama) | Modelle, die du bereits mit Ollama verwaltest, auf diesem Mac oder einem Server | Starte Ollama und lege seine Adresse fest |
| [LM Studio](/de/providers/lm-studio) | Modelle, die du bereits in LM Studio nutzt, auf diesem Mac oder einem Server | Starte den Server von LM Studio und lege seine Adresse fest |

## Klein anfangen

1. Richte die Laufzeitumgebung ein und lade ein Modell herunter oder in den Speicher.
2. Sende eine kurze Textnachricht.
3. Sobald das funktioniert, füge Dokumente oder Werkzeuge hinzu.
4. Beobachte Speichernutzung und Geschwindigkeit, bevor du ein größeres Modell ausprobierst. **Einstellungen → Lokale Modelle** zeigt die Modelle auf diesem Mac und wie viel Speicher sie belegen.

Modellgröße, Quantisierung, Kontextlänge und andere laufende Aufgaben beeinflussen alle den Speicherbedarf. Orientiere dich an der Größe, die die Modellauswahl anzeigt, statt an einer festen Faustregel.

## Die ganze Aufgabe lokal halten

Ein lokales Chatmodell allein hält nicht alles auf deinem Mac. Spracherkennung, Text-to-Speech, OCR, Dokumentenanalyse, Embeddings, Reranking, Suche und MCP-Werkzeuge nutzen jeweils einen eigenen Anbieter. Enconvo hat lokale Anbieter für mehrere davon; der [Anbieterkatalog](/de/providers/catalog) listet sie auf.

**Einstellungen → Lokale Modelle** zeigt, welche Funktionen auf diesem Mac laufen und welche in der Cloud. Websuche und andere Online-Dienste brauchen weiterhin das Internet, und ein lokales Modell kann trotzdem Werkzeuge aufrufen, die Inhalte von deinem Mac senden.

## Einen Modellserver auf einem anderen Computer nutzen

Stelle den Server so ein, dass er Netzwerkverbindungen annimmt, und setze **BaseUrl** in Enconvo auf die Adresse dieses Computers. `localhost` bedeutet immer den Mac, auf dem Enconvo läuft. Blockiert macOS die Verbindung, schalte Enconvo unter **Systemeinstellungen → Datenschutz & Sicherheit → Lokales Netzwerk** ein.

## Einen anderen Modellserver nutzen

Für einen Server wie llama.cpp, vLLM, KoboldCpp oder text-generation-webui klicke unten in **Einstellungen → KI-Modell** auf **Neuen Anbieter hinzufügen** und wähle **OpenAI-kompatibel**. Füge die Adresse des Servers als Basis-URL ein; Enconvo akzeptiert sie mit oder ohne `/v1` und auch als vollständig eingefügten Endpunkt. Lass den API-Schlüssel leer, wenn der Server keinen prüft.

## Lange Chats bei kleinem Kontext

Lokale Server führen ein Modell oft mit einem kleineren Kontext aus, als das Modell erlaubt. Enconvo liest den Kontext aus, mit dem Ollama, llama.cpp, LM Studio, KoboldCpp und text-generation-webui tatsächlich laufen, und verdichtet den Chat entsprechend. Bei kleinem Kontext fasst es einen langen Chat in Teilen zusammen. Damit das Modell mehr Platz hat, erhöhe die Kontextlänge in den eigenen Einstellungen des Servers.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Das Modell vergisst den Anfang eines langen Chats | Der Server läuft mit kleinem Kontext. Erhöhe die Kontextlänge in den Einstellungen des Servers oder starte einen neuen Chat. |
| Das Modell ignoriert Werkzeuge oder Bilder | Es unterstützt sie nicht, daher antwortet Enconvo ohne sie. Wähle ein Modell, das Tool-Aufrufe oder Bildeingabe unterstützt. |
| Die Verbindung schlägt fehl | Lies den Fehler: Enconvo zeigt die eigene Meldung des Servers an und nennt die Ursache. Prüfe, ob der Server läuft und Adresse und Port stimmen. |

---
title: "OCR"
description: "Kopiere den Text aus einem beliebigen Teil deines Bildschirms oder aus einem Bild, gelesen auf deinem Mac oder von einem Online-Dienst."
---

OCR liest den Text in einem Screenshot oder Bild, sodass du ihn kopieren, einfügen, übersetzen oder danach fragen kannst. Greife darauf zurück, wenn du den Text nicht markieren kannst, etwa in einem Bild, einem Videoframe oder einer gescannten Seite. Du wählst, ob der Text auf deinem Mac oder von einem Online-Dienst gelesen wird.

## Bevor du loslegst

Enconvo braucht die Berechtigung für die Bildschirmaufnahme, um deinen Bildschirm zu erfassen. Siehe [Berechtigungen](/de/configuration/permissions).

## Text vom Bildschirm kopieren

1. Führe **Screenshot OCR** über die SmartBar aus.
2. Ziehe über den Bereich mit dem Text.
3. Der Text öffnet sich in der Dynamic Island. Klicke auf **Kopieren** oder auf **Einfügen** (**⌘↩**), um ihn in die App einzufügen, die du gerade nutzt.

Im selben Ergebnis kannst du auch auf **Übersetzen** oder **KI fragen** klicken. Das Menü **⋯** enthält **Ursprüngliche Zeilenumbrüche beibehalten**, **Bild kopieren**, **Bild speichern…**, **Bereich erneut auswählen**, **Zur Wissensdatenbank hinzufügen** und **OCR-Einstellungen…**.

Um den Bereich mit einem anderen Anbieter erneut zu lesen, klicke über dem Text auf den Namen des Anbieters und wähle einen aus. Wenn der Anbieter weiß, wo jede Zeile liegt, wechsle zur Bildansicht, um Zeilen auf dem Screenshot auszuwählen, und klicke dann auf **Auswahl kopieren**.

## Weitere OCR-Befehle

| Befehl | Was er bewirkt |
| --- | --- |
| **Screenshot OCR** | Liest einen Bildschirmbereich und öffnet den Text in der Dynamic Island |
| **Silent Screenshot OCR** | Liest einen Bildschirmbereich und kopiert den Text in die Zwischenablage |
| **OCR** | Liest den Text in einem Bild, das du ihm gibst |
| **Screenshot Translate** | Übersetzt einen Bildschirmbereich. Siehe [Übersetzung](/de/ai/translate) |
| **Screenshot Explain** | Erklärt einen Bildschirmbereich. Siehe [Schreibwerkzeuge](/de/features/writing-tools) |

## Einen Anbieter wählen

Öffne **Einstellungen → OCR**, wähle einen Anbieter und klicke auf **Als Standard festlegen**.

| Anbieter | Wo der Text gelesen wird |
| --- | --- |
| **Apple Native OCR** | Auf deinem Mac, mit Apples eigener Texterkennung |
| **PP-OCRv6 (MLX)** | Auf deinem Mac, mit PaddleOCR-Detektions- und Erkennungsmodellen auf Apple Silicon. Nichts verlässt deinen Mac |
| **AI Model OCR** | Durch das KI-Modell, das du wählst, gemäß seiner **Anweisung** |
| **Mistral OCR** | Durch den Online-Dienst von Mistral, mit deinem Mistral-Schlüssel oder deiner Mistral-Anmeldung |
| **Mistral OCR (Enconvo Cloud Plan)** | Durch den Online-Dienst von Mistral, über deinen Enconvo-Cloud-Tarif |

Jeder OCR-Befehl kann auch einen eigenen Anbieter verwenden: Lege **OCR-Anbieter** in seinen Einstellungen unter **Einstellungen → Plugins → OCR** fest. Die Felder jedes Anbieters findest du im [Anbieterkatalog](/de/providers/catalog).

## Bessere Ergebnisse erzielen

Erfasse einen engen, lesbaren Bereich in einer Größe, in der der Text gut zu lesen ist. Prüfe Spalten, Tabellen, Satzzeichen, Code-Einrückungen und ähnlich aussehende Zeichen von Hand.

Ein gescanntes Dokument kann OCR brauchen, auch wenn es eine PDF-Datei ist.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Die Aufnahme ist leer oder startet nicht | Prüfe die Berechtigung für die Bildschirmaufnahme unter [Berechtigungen](/de/configuration/permissions) |
| **Kein Text gefunden** | Klicke auf **Bereich erneut auswählen** und wähle einen engeren Bereich. Handschrift oder ausgefallene Schrift lässt sich mit **KI-Modell-OCR versuchen** womöglich besser lesen |
| **Nicht lesbar** | Klicke auf **Erneut versuchen**, probiere ein einfaches Bild und lies die Fehlermeldung des Anbieters. **Einstellungen** öffnet die OCR-Einstellungen |
| Zeilen laufen ineinander oder brechen an falschen Stellen um | Schalte **Ursprüngliche Zeilenumbrüche beibehalten** im Menü **⋯** an oder aus oder lies den Bereich mit einem anderen Anbieter erneut |
| Du möchtest etwas auf dem Bildschirm erfragen, nicht seinen Text kopieren | Nutze [Appshots](/de/features/appshots) oder die [Bildschirmzeichnung](/de/features/screen-doodle) |

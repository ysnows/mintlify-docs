---
title: "Webinhalt abrufen"
description: "Lass deinen Agenten eine Webseite über ihre URL lesen oder die Seite in einer Wissensdatenbank aufbewahren."
---

Nutze Webinhalt abrufen, wenn du bereits eine URL hast und der Agent die Seite lesen soll. Jeder Agent kann einen Link lesen, den du ihm gibst; den Dienst, der ihn abruft, wählst du. Nutze die [Websuche](/de/ai/web-search), wenn du zuerst relevante Seiten finden musst.

## Einen Anbieter wählen

1. Öffne **Einstellungen → Webinhalt abrufen**.
2. Wähle einen Anbieter und klicke auf **Als Standard festlegen**.

| Anbieter | Verwendung |
| --- | --- |
| **Local Fetch** | Seiten kostenlos auf deinem Mac abrufen, optional mit browsergestütztem Abruf |
| **Jina AI Link Reader** | Lesbare Inhalte über Jina abrufen |
| **Firecrawl Link Reader** | Inhalte über Firecrawl abrufen |
| **DeepSeek** | Seiten als Markdown lesen, mit deinem DeepSeek-API-Schlüssel |
| **DeepSeek (Enconvo Cloud)** | Seiten als Markdown über Enconvo Cloud lesen, kein API-Schlüssel nötig |
| **Enconvo Cloud Plan** | Den Link-Lesedienst der Cloud nutzen |

## Eine Seite lesen

1. Füge die URL in deine Unterhaltung ein und stelle eine konkrete Frage dazu.
2. Prüfe den abgerufenen Inhalt und die Quelle, bevor du dich auf die Antwort verlässt.

## Seiten hinter einem Login

Mit **Local Fetch** kann der **browsergestützte Abruf** eine Seite über einen Browser der Chromium-Familie lesen, der die Enconvo-Companion-Erweiterung hat.

| Option | Was sie bewirkt |
| --- | --- |
| **Automatisch** (Standard) | Verwendet einen passenden Tab wieder, den du bereits geöffnet hast, vollständig gerendert und mit deinem Login. Nutzt einen temporären Hintergrund-Tab, wenn ein direkter Abruf fehlschlägt oder die Seite JavaScript braucht. |
| **Aus** | Nur direktes HTTP |
| **Immer** | Ruft immer über den Browser ab |

Ohne verbundenen Browser sendet Local Fetch eine direkte HTTP-Anfrage. Die anderen Anbieter rufen die öffentliche URL ab und haben deine angemeldete Browsersitzung nicht. Für interaktive Seiten nutze die [Browsererweiterung](/de/features/browser-extension) oder die [Browsernutzung](/de/features/browser-control).

## Webinhalte aufbewahren

Füge eine URL mit **Hinzufügen → Einzelne Webseite** in einer [Wissensdatenbank](/de/ai/knowledge-base) hinzu, wenn du sie später finden möchtest. Prüfe die importierte Seite und ihren Indizierungsstatus; Webseiten können sich nach dem Import ändern.

## Fehlerbehebung

| Problem | Was du tun kannst |
| --- | --- |
| Der Inhalt kommt leer zurück | Prüfe, ob die Seite ohne zusätzliche Interaktion lesbar ist, oder nutze **Local Fetch** mit **browsergestütztem Abruf**. Login-Bildschirme, blockierte Anfragen, dynamisch geladene Inhalte und nicht unterstützte Websites können die Extraktion verhindern. |
| Die Antwort beschreibt Dinge, die nicht auf der Seite stehen | Bitte den Agenten zu zeigen, was er tatsächlich abgerufen hat, statt fehlende Inhalte zu erraten. |

---
title: "Webabruf"
description: "Den Agenten eine Webseite über ihre URL lesen lassen oder die Seite in einer Wissensdatenbank behalten."
---

Nutze den Webabruf, wenn du schon eine URL hast und der Agent die Seite lesen soll. Jeder Agent kann einen Link lesen, den du ihm gibst; du wählst den Dienst, der sie abruft. Nutze die [Websuche](/de/ai/web-search), wenn du zuerst passende Seiten finden musst.

## Einen Anbieter wählen

1. Öffne **Einstellungen → Webinhalt abrufen**.
2. Wähle einen Anbieter und klicke **Als Standard festlegen**.

| Anbieter | Nutzen |
| --- | --- |
| **Local Fetch** | Seiten auf dem Mac kostenlos abrufen, optional mit Browserhilfe |
| **Jina AI Link Reader** | Lesbaren Inhalt über Jina holen |
| **Firecrawl Link Reader** | Inhalt über Firecrawl holen |
| **DeepSeek** | Seiten als Markdown mit deinem DeepSeek-API-Schlüssel lesen |
| **DeepSeek (Enconvo Cloud)** | Seiten als Markdown über Enconvo Cloud lesen, ohne API-Schlüssel |
| **Enconvo Cloud Plan** | Den Cloud-Dienst zum Linklesen nutzen |

## Eine Seite lesen

1. Füge die URL ins Gespräch ein und stelle eine konkrete Frage dazu.
2. Prüfe den abgerufenen Inhalt und die Quelle, bevor du dich auf die Antwort verlässt.

## Seiten hinter einer Anmeldung

Mit **Local Fetch** kann **Browsergestützter Abruf** eine Seite über einen Chromium-Browser lesen, der die Enconvo-Companion-Erweiterung hat.

| Option | Was sie tut |
| --- | --- |
| **Auto** (Standard) | Nutzt einen passenden Tab, den du schon offen hast, voll gerendert und mit deiner Anmeldung. Nutzt einen temporären Hintergrund-Tab, wenn ein direkter Abruf scheitert oder die Seite JavaScript braucht. |
| **Aus** | Nur direktes HTTP |
| **Immer** | Ruft immer über den Browser ab |

Ohne verbundenen Browser macht Local Fetch eine direkte HTTP-Anfrage. Die anderen Anbieter holen die öffentliche URL und haben deine angemeldete Browser-Sitzung nicht. Für interaktive Seiten nutze die [Browser-Erweiterung](/de/features/browser-extension) oder [Browsernutzung](/de/features/browser-control).

## Webinhalte behalten

Füge eine URL mit **Hinzufügen → Einzelne Webseite** in einer [Wissensdatenbank](/de/ai/knowledge-base) hinzu, wenn du sie später finden willst. Prüfe die importierte Seite und den Indexstatus; Webseiten können sich nach dem Import ändern.

## Fehlerbehebung

| Problem | Was tun |
| --- | --- |
| Der Inhalt kommt leer zurück | Prüfe, ob die Seite ohne weitere Interaktion lesbar ist, oder nutze **Local Fetch** mit **Browsergestütztem Abruf**. Anmeldeseiten, blockierte Anfragen, dynamisch geladener Inhalt und nicht unterstützte Sites können die Extraktion verhindern. |
| Die Antwort beschreibt Dinge, die nicht auf der Seite stehen | Bitte den Agenten, zu zeigen, was er wirklich abgerufen hat, statt fehlenden Inhalt zu raten. |

---
title: "Variablen"
description: "Füge deine aktuelle Eingabe, markierten Text, App-Kontext oder das Datum in Prompts und andere Felder ein, die Vorlagen annehmen."
---

Variablen füllen Werte, die sich jedes Mal ändern, etwa den Text, den du in der SmartBar getippt hast, den in einer anderen App markierten Text oder das heutige Datum. Nutze sie in Prompts und Einstellungen, die Vorlagen unterstützen, damit ein KI-Befehl, eine Agenten-Anweisung oder ein Workflow mit dem funktioniert, was gerade vor dir liegt. Öffne **Einstellungen → Variablen**, um die verfügbaren Variablen zu durchsuchen.

## Verfügbare Variablen

| Variable | Gelieferter Wert |
| --- | --- |
| Eingabetext | Aktuelle SmartBar-Eingabe |
| Markierter Text | In der aktuellen App markierter Text |
| Neueste Zwischenablage | Neuester Inhalt der Zwischenablage |
| Aktive Anwendung | Informationen zur vordersten App |
| Screenshot der aktiven Anwendung | Bild des vordersten Fensters |
| Screenshot des aktiven Bildschirms | Bild des aktiven Bildschirms |
| Inhalt des fokussierten Fensters | Aus dem fokussierten Fenster extrahierter Inhalt |
| Aktiver Browser-Tab | URL des aktiven Tabs und verfügbarer Seiteninhalt |
| Aktueller Ordner | Der in Finder geöffnete Ordner |
| Ausgewählte Dateien | In Finder ausgewählte Dateien |
| Verlaufsnachrichten | Verlauf der aktuellen Unterhaltung |
| Jetzt | Aktuelles Datum und aktuelle Uhrzeit |
| Deine Sprache | Die Sprache, in der du liest: deine **Antwortsprache**, oder die Systemsprache, wenn sie auf Automatisch steht |
| Geöffnete Anwendungen | Informationen zu laufenden Apps |
| Namen geöffneter Anwendungen | Namen der laufenden Apps |

## Eine Variable nutzen

1. Öffne den KI-Befehl, die Agenten-Anweisung oder das Workflow-Feld, das du anpassen willst.
2. Prüfe, ob das Feld Variablen unterstützt; nutze seinen Auswähler, wenn es einen hat.
3. Füge den Wert ein, den du brauchst, und teste mit harmlosem Beispielinhalt.
4. Prüfe, ob eine leere Eingabe oder eine fehlende Berechtigung das Ergebnis ändert.

Ein Text-Prompt kann unterstützte Vorlagennamen so nutzen:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Welche Variablen du nutzen kannst, hängt vom Befehl und vom Kontext ab, und nicht jedes Textfeld wertet Vorlagen aus. Screenshots und App-Inhalt können macOS-Berechtigungen und ein Modell brauchen, das diese Art von Eingabe annimmt.

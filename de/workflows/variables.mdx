---
title: "Variablen"
description: "Füge deine aktuelle Eingabe, markierten Text, App-Kontext oder das Datum in Prompts und andere Felder ein, die Vorlagen unterstützen."
---

Variablen füllen Werte ein, die sich jedes Mal ändern, etwa den Text, den du in SmartBar getippt hast, den in einer anderen App markierten Text oder das heutige Datum. Verwende sie in Prompts und Einstellungen, die Vorlagen unterstützen, damit ein KI-Befehl, eine Agent-Anweisung oder ein Workflow mit dem arbeitet, was gerade vor dir liegt. Öffne **Einstellungen → Variablen**, um die verfügbaren Variablen zu durchsuchen.

## Verfügbare Variablen

| Variable | Gelieferter Wert |
| --- | --- |
| Input Text | Aktuelle SmartBar-Eingabe |
| Selection Text | In der aktuellen App markierter Text |
| Latest Clipboard | Zuletzt kopierter Inhalt der Zwischenablage |
| Active Application | Informationen zur App im Vordergrund |
| Active Application Screenshot | Bild des vordersten Fensters |
| Active Screen Screenshot | Bild des aktiven Bildschirms |
| Focused Window Content | Aus dem fokussierten Fenster extrahierter Inhalt |
| Browser Active Tab | URL des aktiven Tabs und verfügbarer Seiteninhalt |
| Current Folder | Der im Finder geöffnete Ordner |
| Selected Files | Im Finder ausgewählte Dateien |
| History Messages | Aktueller Gesprächsverlauf |
| Now | Aktuelles Datum und aktuelle Uhrzeit |
| Your Language | Die Sprache, die du liest: deine **Antwortsprache** oder die Systemsprache, wenn sie auf Automatisch steht |
| Opened Applications | Informationen zu laufenden Apps |
| Opened Application Names | Namen der laufenden Apps |

## Eine Variable verwenden

1. Öffne das Feld des KI-Befehls, der Agent-Anweisung oder des Workflows, das du anpassen möchtest.
2. Prüfe, ob das Feld Variablen unterstützt; verwende seine Auswahl, wenn es eine hat.
3. Füge den gewünschten Wert ein und teste mit harmlosem Beispielinhalt.
4. Prüfe, ob eine leere Eingabe oder eine fehlende Berechtigung das Ergebnis verändert.

Ein Text-Prompt kann unterstützte Vorlagennamen verwenden, etwa:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Welche Variablen du verwenden kannst, hängt vom Befehl und vom Kontext ab, und nicht jedes Textfeld wertet Vorlagen aus. Screenshots und App-Inhalte können macOS-Berechtigungen und ein Modell erfordern, das diese Art von Eingabe akzeptiert.

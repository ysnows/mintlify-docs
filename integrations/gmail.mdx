title: "Gmail"
description: "Connect your Gmail once so agents can search, read, organize, and send your mail from any chat."

The Gmail Connector brings your email into Enconvo. Ask an agent to find important mail, summarize a thread, draft a reply, or clean up your inbox, and it uses Gmail for you. You connect your Google account once, through your Enconvo account; there's no Google Cloud project or API key to set up.

## Before you start

Sign in to your Enconvo account in **Settings → Account**. Connectors are free on every plan, but they need an Enconvo account.

## Connect Gmail

<Steps>
  <Step title="Find Gmail">
    Open **Settings → Plugins** and search for **Gmail** on the **Enconvo** tab. Click it to open its page.
  </Step>
  <Step title="Connect">
    Click **Connect**. Your browser opens Google's sign-in.
  </Step>
  <Step title="Allow access">
    Choose your Google account and review the access it asks for before you allow it. Google's consent screen shows Composio, Enconvo's integration partner.
  </Step>
  <Step title="Check the result">
    Back in Enconvo, your address shows under **Account**. Click **Try now**, or ask an agent a read-only question first, such as "Summarize the unread emails in my inbox from today."
  </Step>
</Steps>

If you ask an agent about your mail before Gmail is connected, the chat shows a card to connect it.

## What agents can do

| Area | What agents can do |
| --- | --- |
| Read | Search mail, open messages and threads, download attachments, list labels and drafts |
| Organize | Add and remove labels, archive, move messages to Trash and restore them |
| Write | Create and send drafts, send new mail, reply, and forward |

Search uses Gmail's own search syntax, such as `from:john@example.com`, `subject:invoice`, or `after:2024/01/01`.

When agents write or send mail, they can set To, CC, and BCC, write a plain-text or HTML body, reply inside an existing thread, and attach files from your Mac: up to 10 files, each up to 95 MB. Files past what one email can carry (25 MB together) go as download links on file.enconvo.com instead, and anyone with a link can download the file.

<Warning>
Agents can send mail without asking first. Ask for a draft when you want to review it. Enconvo never deletes mail permanently; deleting moves it to Trash.
</Warning>

## Options

These appear on Gmail's page once an account is connected.

| Option | What it changes |
| --- | --- |
| **Available in all chats** | On: agents can use Gmail in every conversation. Off: agents use it only when you `@` mention it or a Profile includes it. |
| **Mail Alerts** | Alerts you on the Dynamic Island and your iPhone when important mail arrives. Enconvo asks before turning it on, because the sender, subject, and start of each new mail go to Enconvo Cloud to judge how important it is. Mail is never stored there. |
| **Connect another account** | Adds another Gmail address, up to 5. |

With several accounts, agents read from all of them, and send or create mail with the default account unless you name another, such as "send it from my work address." Choose **Make default** in an account's menu to change the default.

## Use Gmail in chats

Once Gmail is connected, ask for what you need. The agent picks the right Gmail tools.

**Search and summarize:**
```
"Find all emails from John in the last week and summarize them"
```

**Draft a reply:**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**Clean up the inbox:**
```
"Archive all newsletters from the past month"
```

**Manage labels:**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**Clear out old mail (it goes to Trash):**
```
"Delete all promotional emails older than 6 months"
```

## Ideas for workflows

Gmail works in [workflows](/workflows/introduction) and [scheduled tasks](/workflows/scheduled-jobs) too:

| Idea | What it does |
| --- | --- |
| **Daily Email Digest** | Search for unread emails, summarize them, and present a morning briefing |
| **Auto-Categorize** | Search for new emails and apply labels based on their content |
| **Follow-Up Reminder** | Find emails waiting for a reply and create reminders |
| **Report Generation** | Search for emails that match your criteria and compile a summary report |

## Privacy

- **Through Enconvo Cloud and Composio**: Your mail passes through Enconvo Cloud and Composio only to do what you ask, and isn't stored.
- **Your password stays with Google**: You sign in on Google's own page, so Enconvo never sees your Google password.
- **On demand**: Agents read Gmail only when a task needs it. The one exception is **Mail Alerts**, which, when you turn it on, checks each new mail as it arrives.
- **Revocable**: Click **Disconnect** on Gmail's page to remove access on all your devices. You can also remove access in your [Google Account permissions](https://myaccount.google.com/permissions).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Connect** is grayed out | Sign in to your Enconvo account in **Settings → Account** first. |
| Gmail shows **Reconnect** | Its access ran out. Click **Reconnect** and sign in with Google again. |
| The agent doesn't use Gmail | Check that Gmail is connected. If **Available in all chats** is off, `@` mention Gmail in the chat. |
| A search finds nothing | Try a simpler query first, such as `from:john`, and check that the mail is in a connected account. Gmail search works the same as on the Gmail website. |
| An attachment doesn't send | Check that the file paths are correct and the files exist on your Mac. |

---
title: "GitHub Copilot"
description: "Accedi con un account GitHub che ha un piano Copilot e chatta con i modelli del tuo piano."
---

Usa il tuo piano GitHub Copilot come fornitore di Modello di IA in Enconvo. Accedi con l'account GitHub che ha il piano; non è coinvolta nessuna chiave API. I modelli premium vengono conteggiati nelle richieste premium del tuo piano.

## Collegamento

<Steps>
  <Step title="Apri il fornitore">
    Apri **Impostazioni → Modello di IA → GitHub Copilot**.
  </Step>
  <Step title="Avvia l'accesso">
    In **Autenticazione**, fai clic su **Connetti**.
  </Step>
  <Step title="Inserisci il codice su GitHub">
    Il browser apre la pagina dei dispositivi di GitHub, ed Enconvo mostra il codice da inserire lì. Inserisci il codice e autorizza l'accesso.
  </Step>
  <Step title="Controlla l'account">
    Torna a Enconvo e verifica che sia collegato l'account GitHub corretto.
  </Step>
  <Step title="Scegli un modello">
    Seleziona un modello e prova una richiesta breve.
  </Step>
</Steps>

Chiudere la finestra del codice di Enconvo prima di autorizzare annulla l'accesso.

## Modelli e opzioni

L'elenco dei modelli mostra solo i modelli che il tuo piano Copilot può usare, con il modello di chat predefinito di Copilot per primo. Copilot Free offre meno modelli dei piani a pagamento, quindi un modello che hai visto altrove potrebbe non essere elencato. Ogni modello usa i livelli di sforzo di ragionamento che Copilot offre per quel modello.

## Su iPhone

Anche l'app per iPhone può accedere a GitHub Copilot, per le Chat del telefono sul telefono. Vedi [Chat del telefono](/it/integrations/iphone-phone-chats).

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| L'accesso non si completa | Inserisci il codice nella pagina di GitHub prima che scada, poi fai di nuovo clic su **Connetti** per ottenere un nuovo codice. |
| Il modello che vuoi non è elencato | Il tuo piano Copilot non lo include; scegli un altro modello o passa a un piano superiore. |
| Una richiesta fallisce con un errore del modello | Scegli un modello dall'elenco attuale; un predefinito scelto prima che il tuo piano cambiasse potrebbe non essere più offerto. |
| Limite di frequenza o di utilizzo | Le richieste premium del tuo piano e i limiti di frequenza di GitHub. |

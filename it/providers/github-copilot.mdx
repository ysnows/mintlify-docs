---
title: "GitHub Copilot"
description: "Accedi con un account GitHub che ha un piano Copilot e chatta con i modelli del piano."
---

Usa il tuo piano GitHub Copilot come fornitore di Modello di IA in Enconvo. Accedi con l’account GitHub che ha il piano; non serve una chiave API. I modelli premium contano nelle richieste premium del piano.

## Collega

<Steps>
  <Step title="Apri il fornitore">
    Apri **Impostazioni → Modello di IA → GitHub Copilot**.
  </Step>
  <Step title="Avvia l’accesso">
    In **Autenticazione**, fai clic su **Connetti**.
  </Step>
  <Step title="Inserisci il codice su GitHub">
    Il browser apre la pagina del dispositivo di GitHub ed Enconvo mostra il codice da inserire lì. Inserisci il codice e autorizza l’accesso.
  </Step>
  <Step title="Controlla l’account">
    Torna a Enconvo e verifica che sia collegato l’account GitHub previsto.
  </Step>
  <Step title="Scegli un modello">
    Seleziona un modello e prova una richiesta breve.
  </Step>
</Steps>

Chiudere la finestra del codice di Enconvo prima di autorizzare annulla l’accesso.

## Modelli e opzioni

L’elenco dei modelli mostra solo quelli che il tuo piano Copilot può usare, con il predefinito di chat di Copilot per primo. Copilot Free offre meno modelli dei piani a pagamento, quindi un modello visto altrove potrebbe non comparire. Ogni modello usa i livelli di sforzo di ragionamento che Copilot offre per quello.

## Su iPhone

L’app per iPhone può accedere a GitHub Copilot anche per le chat del telefono. Vedi [Chat del telefono](/it/integrations/iphone-phone-chats).

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| L’accesso non si conclude | Inserisci il codice sulla pagina di GitHub prima che scada, poi fai di nuovo clic su **Connetti** per un nuovo codice. |
| Il modello che vuoi non è in elenco | Il tuo piano Copilot non lo include; scegline un altro o aggiorna il piano. |
| Una richiesta fallisce con un errore del modello | Scegli un modello dall’elenco attuale; un predefinito scelto prima che il piano cambiasse potrebbe non essere più offerto. |
| Limite di frequenza o di utilizzo | Le richieste premium del piano e i limiti di frequenza di GitHub. |

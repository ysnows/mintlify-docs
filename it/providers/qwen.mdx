Usa i modelli Qwen di Alibaba nelle chat, negli Agenti e nei Comandi IA. Collegati con una chiave API di Alibaba Cloud Model Studio; Alibaba Cloud addebita l’utilizzo sul tuo account. Per il servizio della Cina continentale (Bailian), usa [DashScope](/it/providers/dashscope).

## Collega

<Steps>
  <Step title="Ottieni una chiave API">
    Crea una chiave in [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Aggiungila a Enconvo">
    Apri **Impostazioni → Modello IA → Qwen**. Sotto **Autenticazione**, incolla la chiave in **Chiave API**, poi fai clic su **Convalida**.
  </Step>
  <Step title="Scegli un modello">
    Scegli un modello in **Nome modello** e invia un messaggio breve. Una risposta significa che la connessione funziona.
  </Step>
</Steps>

Qwen si collega solo con una chiave API.

## Modelli e opzioni

| Impostazione | Cosa fa |
| --- | --- |
| **Nome modello** | Il modello che usa questo fornitore. **Aggiorna** accanto ricarica l’elenco; **Gestisci modelli** (l’ingranaggio) aggiunge o ripristina i modelli. |
| **Base Url** | Nella credenziale. Il predefinito è l’endpoint internazionale, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Cambialo se la chiave appartiene a un’altra regione. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| **Convalida** fallisce | Controlla che la chiave e **Base Url** appartengano alla stessa regione, poi incolla di nuovo l’intera chiave. |
| Manca un modello | Fai clic su **Aggiorna** accanto a **Nome modello**. Per aggiungere un modello tu stesso, usa **Gestisci modelli**. |
| Errori di limite di frequenza o di utilizzo | Controlla utilizzo e quota in Model Studio, oppure passa per ora a un altro fornitore. |

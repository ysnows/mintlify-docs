Usa i modelli Qwen di Alibaba nelle chat, negli Agenti e nei Comandi IA. Collegati con una chiave API di Alibaba Cloud Model Studio; Alibaba Cloud addebita l'utilizzo al tuo account. Per il servizio della Cina continentale (Bailian), usa [DashScope](/it/providers/dashscope).

## Connessione

<Steps>
  <Step title="Ottieni una chiave API">
    Crea una chiave in [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Aggiungila a Enconvo">
    Apri **Impostazioni → Modello di IA → Qwen**. In **Autenticazione** incolla la chiave in **Chiave API**, poi fai clic su **Convalida**.
  </Step>
  <Step title="Scegli un modello">
    Scegli un modello in **Nome del modello** e invia un breve messaggio. Se ricevi una risposta, la connessione funziona.
  </Step>
</Steps>

Qwen si collega solo con una chiave API.

## Modelli e opzioni

| Impostazione | Cosa fa |
| --- | --- |
| **Nome del modello** | Il modello usato da questo fornitore. **Aggiorna** accanto al campo ricarica l'elenco; **Gestisci i modelli** (l'ingranaggio) aggiunge o ripristina modelli. |
| **URL di base** | Nella credenziale. Il valore predefinito è l'endpoint internazionale, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Cambialo se la tua chiave appartiene a un'altra regione. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| **Convalida** non riesce | Controlla che la chiave e l'**URL di base** appartengano alla stessa regione, poi incolla di nuovo l'intera chiave. |
| Manca un modello | Fai clic su **Aggiorna** accanto a **Nome del modello**. Per aggiungere un modello a mano, usa **Gestisci i modelli**. |
| Errori di limite di frequenza o di utilizzo | Controlla l'utilizzo e la quota in Model Studio, oppure passa per ora a un altro fornitore. |

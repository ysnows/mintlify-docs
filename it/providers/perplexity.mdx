title: "Perplexity"
description: "Chatta con i modelli Perplexity in Enconvo usando la tua chiave API Perplexity."
---

I modelli Sonar di Perplexity cercano sul web mentre rispondono. Aggiungi la tua chiave a Enconvo per usare questi modelli nelle chat, negli Agenti e nei Comandi IA. Perplexity addebita l'utilizzo al tuo account.

## Connessione

<Steps>
  <Step title="Ottieni una chiave API">
    Crea una chiave nelle [impostazioni API di Perplexity](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="Aggiungila a Enconvo">
    Apri **Impostazioni → Modello di IA → Perplexity**. In **Autenticazione** incolla la chiave in **Chiave API**, poi fai clic su **Convalida**.
  </Step>
  <Step title="Scegli un modello">
    Scegli un modello in **Nome del modello** e invia un breve messaggio. Se ricevi una risposta, la connessione funziona.
  </Step>
</Steps>

Per tenere una seconda chiave Perplexity, per esempio una per il lavoro, fai clic su **Aggiungi un nuovo fornitore** e crea un altro profilo.

## Modelli e opzioni

| Impostazione | Cosa fa |
| --- | --- |
| **Nome del modello** | Il modello usato da questo fornitore. **Aggiorna** accanto al campo ricarica l'elenco; **Gestisci i modelli** (l'ingranaggio) aggiunge o ripristina modelli. |
| **frequencyPenalty** | Riduce la probabilità di parole ripetute. Il valore predefinito è 1. |

Per usare un modello diverso in una sola chat, sceglilo dal selettore dei modelli di quella chat.

Questo fornitore di chat è separato da **Impostazioni → Ricerca web**: sceglierlo qui non cambia il fornitore di ricerca usato dai tuoi Agenti. Quando una risposta riguarda l'attualità, apri le fonti che cita.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| **Convalida** non riesce | Incolla di nuovo l'intera chiave e controlla che sia attiva nel tuo account Perplexity. |
| Manca un modello | Fai clic su **Aggiorna** accanto a **Nome del modello** per ricaricare l'elenco. Per aggiungere un modello a mano, usa **Gestisci i modelli**. |
| Immagini o strumenti non funzionano | Scegli un modello che supporti l'input di immagini o le chiamate agli strumenti. |
| Errori di limite di frequenza o di utilizzo | Controlla l'utilizzo e i limiti nel tuo account Perplexity, oppure passa per ora a un altro fornitore. |
| Le risposte sono lente | Prova un modello più piccolo, un input più breve o uno sforzo di ragionamento minore. |

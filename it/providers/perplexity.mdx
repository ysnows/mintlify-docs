---
title: "Perplexity"
description: "Chatta con i modelli Perplexity in Enconvo usando la tua chiave API di Perplexity."
---

I modelli Sonar di Perplexity cercano sul web mentre rispondono. Aggiungi la chiave a Enconvo per usare quei modelli nelle chat, negli Agenti e nei Comandi IA. Perplexity addebita l’utilizzo sul tuo account.

## Collega

<Steps>
  <Step title="Ottieni una chiave API">
    Crea una chiave nelle [impostazioni API di Perplexity](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="Aggiungila a Enconvo">
    Apri **Impostazioni → Modello IA → Perplexity**. Sotto **Autenticazione**, incolla la chiave in **Chiave API**, poi fai clic su **Convalida**.
  </Step>
  <Step title="Scegli un modello">
    Scegli un modello in **Nome modello** e invia un messaggio breve. Una risposta significa che la connessione funziona.
  </Step>
</Steps>

Per tenere una seconda chiave Perplexity, per esempio una per il lavoro, fai clic su **Aggiungi nuovo fornitore** e crea un altro profilo.

## Modelli e opzioni

| Impostazione | Cosa fa |
| --- | --- |
| **Nome modello** | Il modello che usa questo fornitore. **Aggiorna** accanto ricarica l’elenco; **Gestisci modelli** (l’ingranaggio) aggiunge o ripristina i modelli. |
| **frequencyPenalty** | Riduce la probabilità di parole ripetute. Il predefinito è 1. |

Per usare un modello diverso in una sola chat, sceglilo dal selettore di modelli di quella chat.

Questo fornitore di chat è separato da **Impostazioni → Ricerca web**: scegliere Perplexity qui non cambia il fornitore di ricerca che usano i tuoi Agenti. Quando una risposta riguarda fatti attuali, apri le fonti che cita.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| **Convalida** fallisce | Incolla di nuovo l’intera chiave e controlla che sia attiva nel tuo account Perplexity. |
| Manca un modello | Fai clic su **Aggiorna** accanto a **Nome modello** per ricaricare l’elenco. Per aggiungere un modello tu stesso, usa **Gestisci modelli**. |
| Immagini o strumenti falliscono | Scegli un modello che supporta l’input di immagini o le chiamate agli strumenti. |
| Errori di limite di frequenza o di utilizzo | Controlla utilizzo e limiti nel tuo account Perplexity, oppure passa per ora a un altro fornitore. |
| Le risposte sono lente | Prova un modello più piccolo, un input più corto o uno sforzo di ragionamento più basso. |

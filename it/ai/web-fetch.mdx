---
title: "Recupera contenuti web"
description: "Fai leggere al tuo Agente una pagina web a partire dal suo URL, oppure conserva la pagina in una base di conoscenza."
---

Usa Recupera contenuti web quando hai già un URL e vuoi che l'Agente legga la pagina. Ogni Agente può leggere un link che gli dai; tu scegli il servizio che lo recupera. Usa la [Ricerca web](/it/ai/web-search) quando prima devi trovare le pagine pertinenti.

## Scegli un provider

1. Apri **Impostazioni → Recupera contenuti web**.
2. Scegli un provider e fai clic su **Imposta come predefinito**.

| Provider | Uso |
| --- | --- |
| **Local Fetch** | Recupera le pagine sul tuo Mac gratuitamente, con recupero assistito dal browser facoltativo |
| **Jina AI Link Reader** | Recupera contenuti leggibili tramite Jina |
| **Firecrawl Link Reader** | Recupera contenuti tramite Firecrawl |
| **DeepSeek** | Legge le pagine come Markdown con la tua chiave API di DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Legge le pagine come Markdown tramite Enconvo Cloud, nessuna chiave API necessaria |
| **Enconvo Cloud Plan** | Usa il servizio di lettura dei link del Cloud |

## Leggi una pagina

1. Incolla l'URL nella conversazione e fai una domanda specifica al riguardo.
2. Controlla il contenuto recuperato e la fonte prima di fare affidamento sulla risposta.

## Pagine dietro un login

Con **Local Fetch**, il **Recupero assistito dal browser** può leggere una pagina tramite un browser della famiglia Chromium con l'estensione Enconvo Companion.

| Opzione | Cosa fa |
| --- | --- |
| **Automatico** (predefinito) | Riutilizza una scheda corrispondente che hai già aperto, completamente renderizzata e con il tuo login. Usa una scheda temporanea in background quando un recupero diretto non riesce o la pagina richiede JavaScript. |
| **Disattivato** | Solo HTTP diretto |
| **Sempre** | Recupera sempre tramite il browser |

Senza un browser collegato, Local Fetch effettua una richiesta HTTP diretta. Gli altri provider recuperano l'URL pubblico e non hanno la sessione del tuo browser con accesso effettuato. Per le pagine interattive, usa l'[Estensione del browser](/it/features/browser-extension) o l'[Uso del browser](/it/features/browser-control).

## Conserva i contenuti web

Aggiungi un URL con **Aggiungi → Singola pagina web** in una [Base di conoscenza](/it/ai/knowledge-base) quando vuoi ritrovarlo in seguito. Controlla la pagina importata e il suo stato di indicizzazione; le pagine web possono cambiare dopo averle importate.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| Il contenuto risulta vuoto | Controlla che la pagina sia leggibile senza ulteriore interazione, oppure usa **Local Fetch** con il **Recupero assistito dal browser**. Schermate di login, richieste bloccate, contenuti caricati dinamicamente e siti non supportati possono impedire l'estrazione. |
| La risposta descrive cose che non sono nella pagina | Chiedi all'Agente di mostrare ciò che ha effettivamente recuperato, invece di tirare a indovinare sui contenuti mancanti. |

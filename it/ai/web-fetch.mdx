---
title: "Web Fetch"
description: "Fai leggere a un Agente una pagina web dal suo URL, oppure tienila in una base di conoscenza."
---

Usa Web Fetch quando hai già un URL e vuoi che l’Agente legga la pagina. Ogni Agente può leggere un link che gli dai; tu scegli il servizio che la recupera. Usa la [Ricerca web](/it/ai/web-search) quando devi prima trovare le pagine pertinenti.

## Scegliere un fornitore

1. Apri **Impostazioni → Web Fetch**.
2. Scegli un fornitore e fai clic su **Imposta come predefinito**.

| Fornitore | Uso |
| --- | --- |
| **Local Fetch** | Recupera le pagine sul Mac, gratis, con recupero assistito dal browser opzionale |
| **Jina AI Link Reader** | Recupera contenuto leggibile tramite Jina |
| **Firecrawl Link Reader** | Recupera contenuto tramite Firecrawl |
| **DeepSeek** | Legge le pagine come Markdown con la tua chiave API DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Legge le pagine come Markdown tramite Enconvo Cloud, senza chiave API |
| **Enconvo Cloud Plan** | Usa il servizio Cloud di lettura dei link |

## Leggere una pagina

1. Incolla l’URL nella conversazione e fai una domanda precisa sulla pagina.
2. Controlla il contenuto recuperato e la fonte prima di fidarti della risposta.

## Pagine dietro un accesso

Con **Local Fetch**, **Browser-Assisted Fetching** può leggere una pagina tramite un browser della famiglia Chromium che ha l’estensione Enconvo Companion.

| Opzione | Cosa fa |
| --- | --- |
| **Auto** (predefinito) | Riusa una scheda corrispondente già aperta, completamente renderizzata e con il tuo accesso. Usa una scheda temporanea in background quando un recupero diretto fallisce o la pagina ha bisogno di JavaScript. |
| **Off** | Solo HTTP diretto |
| **Always** | Recupera sempre tramite il browser |

Senza un browser collegato, Local Fetch fa una richiesta HTTP diretta. Gli altri fornitori recuperano l’URL pubblico e non hanno la sessione del browser con cui hai effettuato l’accesso. Per le pagine interattive, usa l’[Estensione del browser](/it/features/browser-extension) o l’[Uso del browser](/it/features/browser-control).

## Conservare il contenuto web

Aggiungi un URL con **Aggiungi → Singola pagina web** in una [Base di conoscenza](/it/ai/knowledge-base) quando vuoi ritrovarlo dopo. Controlla la pagina importata e lo stato di indicizzazione: le pagine web possono cambiare dopo l’importazione.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| Il contenuto torna vuoto | Controlla che la pagina sia leggibile senza interazioni extra, oppure usa **Local Fetch** con **Browser-Assisted Fetching**. Schermate di accesso, richieste bloccate, contenuto caricato dinamicamente e siti non supportati possono impedire l’estrazione. |
| La risposta descrive cose che non sono sulla pagina | Chiedi all’Agente di mostrare ciò che ha davvero recuperato, invece di indovinare il contenuto mancante. |

Ogni funzione vocale di Enconvo ha la propria impostazione del modello vocale, così puoi scegliere un modello in streaming veloce per la Dettatura e uno diverso per i file lunghi. Scegli il modello nella funzione che stai usando davvero.

| Funzione | Dove impostarlo | Guida |
| --- | --- | --- |
| Voce digitata come testo | **Impostazioni → Modelli di dettatura** | [Dettatura](/it/features/dictation) |
| Comando vocale | **Impostazioni → Comando vocale → Ascolto** | [Comando vocale](/it/features/dictation) |
| Chiamate Live Talk | **Impostazioni → Live Talk → Ascolto** | [Live Talk](/it/features/live-voice) |
| Registrazione di riunione o lezione | **Impostazioni → Modelli di registrazione** | [Registrazione riunione](/it/features/meeting-recording) |
| Un file audio o video esistente | **Impostazioni → Modelli di trascrizione** | [Trascrizione](/it/features/transcription) |
| Sottotitoli in tempo reale | **Impostazioni → Modello di sottotitolazione** | [Sottotitolazione in tempo reale](/it/features/live-captioning) |

## Scegli un modello

1. Apri l’impostazione della tua funzione dalla tabella sopra.
2. In una pagina di modello di Dettatura, Registrazione, Trascrizione o Sottotitolazione, filtra l’elenco con **Tutti**, **Enconvo Cloud**, **Locale** o **Fornitori personalizzati**. In Comando vocale e Live Talk, **Ascolto** mostra prima i modelli consigliati, poi gli altri modelli vocali.
3. Scegli un modello, poi rivedi lingua e opzioni del modello.

I modelli **Enconvo Cloud** usano il tuo account Enconvo, senza chiave API. **Enconvo Cloud Fast**, il riconoscimento vocale di Enconvo Cloud, è gratuito per tutti e mostra un’etichetta verde **Gratuito**. I **Fornitori personalizzati** usano la tua chiave API con quel fornitore. I modelli **Locali** (MLX e Core ML) riconoscono la voce sul Mac una volta scaricato il modello.

Il [catalogo dei fornitori vocali](/it/providers/catalog) elenca ogni fornitore dichiarato, inclusi i servizi cloud e le varianti locali Parakeet, Qwen, Whisper, SenseVoice, Paraformer e Nemotron. Hardware e disponibilità dipendono dal runtime e dalla build.

## Modelli da notare

| Modello | Cosa sapere |
| --- | --- |
| ElevenLabs Scribe v3 Live | Trasmette le prime parole in meno di un secondo, con meno errori in cinese e nell’audio rumoroso. Usalo per Dettatura e input vocale con la tua chiave API ElevenLabs o Enconvo Cloud. Cinese e giapponese escono senza spazi tra le parole. Live Talk lo usa quando Live Talk usa ElevenLabs. |
| ElevenLabs Scribe v3 | Trascrive i file, con la tua chiave API ElevenLabs o Enconvo Cloud. |
| Enconvo Cloud Fast | Gratuito. Il modello in tempo reale mostra le parole mentre parli, e il modello asincrono trascrive i file registrati. |
| Soniox | Usa i modelli v6 di Soniox in Dettatura, Registrazione, Trascrizione, Sottotitolazione, Live Talk e sottotitoli delle conferenze. Un modello v5 scelto in precedenza passa a v6 per te; Soniox ritira la v5 il 15 dicembre 2026. |
| DeepSeek | Trascrive per Trascrizione e Dettatura, con la tua chiave API DeepSeek oppure come **DeepSeek (Enconvo Cloud)** senza chiave. Riconosce da solo 21 lingue. |
| Fluid Speech Pro by FluidVoice | Gira sul Mac e sull’iPhone e trascrive 25 lingue europee offline, con meno errori di Parakeet, in diretta mentre parli o al termine. Richiede macOS 15 o iOS 18 o versioni successive. |

## Abbina il modello al compito

| Capacità | Cosa sapere |
| --- | --- |
| Streaming | Produce testo parziale mentre parli. Usa un modello in tempo reale quando vuoi che le parole compaiano mentre parli. |
| Trascrizione in batch | Elabora un file dopo l’acquisizione o il caricamento. |
| Suggerimenti di lingua e parole chiave | Guidano il riconoscimento quando il fornitore li supporta. |
| Diarizzazione dei parlanti | Separa le voci. Non garantisce il nome giusto della persona. |
| Traduzione in diretta | Offerta solo da alcuni fornitori e modelli, con lingue di origine e di destinazione. |
| Timestamp e output strutturato | Dipendono dal fornitore e dal formato di output della trascrizione. |

## Prova con un campione breve

Registra un campione breve con la lingua, il microfono e i termini che usi davvero, e rivedilo prima di elaborare una riunione lunga. Se fallisce, leggi l’errore per dettagli su dimensione del file, formato, estrazione, account o rete.

I download dei modelli locali possono essere molto più grandi dell’app. Controlla la dimensione reale del download e lo spazio libero; i modelli vocali locali non hanno tutti le stesse esigenze.

Ogni funzione vocale di Enconvo ha la propria impostazione del modello vocale, così puoi scegliere un modello in streaming veloce per la Dettatura e uno diverso per i file lunghi. Scegli il modello nella funzione che stai effettivamente usando.

| Funzione | Dove impostarlo | Guida |
| --- | --- | --- |
| Parlato scritto come testo | **Impostazioni → Modelli di dettatura** | [Dettatura](/it/features/dictation) |
| Comando vocale | **Impostazioni → Comando vocale → Ascolto** | [Comando vocale](/it/features/dictation) |
| Chiamate Live Talk | **Impostazioni → Live Talk → Ascolto** | [Live Talk](/it/features/live-voice) |
| Registrazione di riunioni o lezioni | **Impostazioni → Modelli di registrazione** | [Registrazione riunione](/it/features/meeting-recording) |
| Un file audio o video esistente | **Impostazioni → Modelli di trascrizione** | [Trascrizione](/it/features/transcription) |
| Sottotitoli in tempo reale | **Impostazioni → Modello di sottotitolazione** | [Sottotitolazione in tempo reale](/it/features/live-captioning) |

## Scegliere un modello

1. Apri l'impostazione della tua funzione dalla tabella qui sopra.
2. In una pagina dei modelli di Dettatura, Registrazione, Trascrizione o Sottotitolazione, filtra l'elenco con **Tutti**, **Enconvo Cloud**, **Locale** o **Provider personalizzati**. In Comando vocale e Live Talk, **Ascolto** mostra prima i modelli consigliati, poi qualsiasi altro modello vocale.
3. Scegli un modello, poi controlla le sue opzioni di lingua e di modello.

I modelli **Enconvo Cloud** usano il tuo account Enconvo, senza chiave API. **Enconvo Cloud Fast**, il riconoscimento vocale proprio di Enconvo Cloud, è gratuito per tutti e mostra un'etichetta verde **Gratuito**. I **Provider personalizzati** usano la tua chiave API con quel provider. I modelli **Locale** (MLX e Core ML) riconoscono il parlato sul tuo Mac una volta scaricato il loro modello.

Il [catalogo dei provider vocali](/it/providers/catalog) elenca ogni provider dichiarato, inclusi i servizi cloud e le varianti locali di Parakeet, Qwen, Whisper, SenseVoice, Paraformer e Nemotron. L'hardware e la disponibilità dipendono dal runtime e dalla tua build.

## Modelli degni di nota

| Modello | Cosa sapere |
| --- | --- |
| ElevenLabs Scribe v3 Live | Trasmette le prime parole in meno di un secondo, con meno errori in cinese e con audio rumoroso. Usalo per la Dettatura e l'Input vocale con la tua chiave API di ElevenLabs o con Enconvo Cloud. Cinese e giapponese escono senza spazi tra le parole. Live Talk lo usa quando Live Talk usa ElevenLabs. |
| ElevenLabs Scribe v3 | Trascrive file, con la tua chiave API di ElevenLabs o con Enconvo Cloud. |
| Enconvo Cloud Fast | Gratuito. Il suo modello in tempo reale mostra le tue parole mentre parli e il suo modello asincrono trascrive i file registrati. |
| Soniox | Usa i modelli v6 di Soniox in Dettatura, Registrazione, Trascrizione, Sottotitolazione, Live Talk e sottotitoli delle conferenze. Un modello v5 che avevi scelto prima passa automaticamente a v6; Soniox ritira v5 il 15 dicembre 2026. |
| DeepSeek | Trascrive per Trascrizione e Dettatura, con la tua chiave API di DeepSeek o come **DeepSeek (Enconvo Cloud)** senza chiave. Riconosce da solo 21 lingue. |
| Fluid Speech Pro di FluidVoice | Gira sul tuo Mac e sul tuo iPhone e trascrive 25 lingue europee offline, con meno errori di Parakeet, dal vivo mentre parli o a registrazione finita. Richiede macOS 15 o iOS 18 o successivi. |

## Scegliere il modello adatto al compito

| Funzionalità | Cosa sapere |
| --- | --- |
| Streaming | Produce testo parziale mentre parli. Usa un modello in tempo reale quando vuoi che le parole compaiano mentre parli. |
| Trascrizione in batch | Elabora un file dopo l'acquisizione o il caricamento. |
| Suggerimenti di lingua e parole chiave | Guidano il riconoscimento quando il provider li supporta. |
| Diarizzazione dei parlanti | Separa le voci. Non garantisce il nome della persona giusta. |
| Traduzione dal vivo | Offerta solo da alcuni provider e modelli, con lingue di origine e di destinazione. |
| Timestamp e output strutturato | Dipendono dal provider e dal formato di output della trascrizione. |

## Provare con un breve campione

Registra un breve campione con la lingua, il microfono e i termini che usi davvero e controllalo prima di elaborare una riunione lunga. Se non riesce, leggi l'errore per i dettagli su dimensione del file, formato, estrazione, account o rete.

I download dei modelli locali possono essere molto più grandi dell'app. Controlla la dimensione effettiva del download e il tuo spazio libero; i modelli vocali locali non richiedono tutti lo stesso spazio.

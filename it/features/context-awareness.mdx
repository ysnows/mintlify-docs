---
title: "Comprensione del contesto"
description: "Scegli cosa raccoglie SmartBar dall'app che stavi usando e aggiungi altro contesto con #."
---

Il contesto è ciò che accompagna la tua domanda: il testo che hai selezionato, i file selezionati nel Finder, la pagina aperta nel browser o uno screenshot. SmartBar può raccoglierne una parte all'apertura e puoi aggiungerne altro digitando `#`. L'Agent risponde così su ciò che stai guardando, senza che tu debba spiegarlo.

## Scegliere cosa raccoglie SmartBar

1. Apri **Impostazioni → Comprensione del contesto**.
2. In **All'apertura della Smart Bar**, imposta ogni sorgente su **Allega**, **Suggerisci** o **Disattivato**.
3. Passa a un'altra app, seleziona qualcosa e apri SmartBar per vedere il risultato.

| Sorgente | Cosa aggiunge | Predefinito |
| --- | --- | --- |
| **Testo selezionato** | Il testo selezionato nell'app che stavi usando | **Allega** |
| **Selezione del Finder** | File e cartelle selezionati nel Finder | **Suggerisci** |
| **Pagina corrente del browser** | La pagina aperta in Safari, Chrome, Arc, Edge o un altro browser basato su Chromium | **Suggerisci** |

**Allega** aggiunge la sorgente all'input appena SmartBar si apre. **Suggerisci** la elenca sopra i comandi, così la aggiungi con un clic. **Disattivato** la esclude.

Solo SmartBar usa queste impostazioni. I comandi che esegui su una selezione ricevono sempre il testo selezionato. La prima volta che aggiungi il contesto del Finder o del browser, macOS chiede se Enconvo può controllare quell'app.

## Aggiungere contesto con #

1. In SmartBar, digita `#`.
2. Digita una parola per restringere l'elenco, come `#screen`, `#finder`, `#clipboard` o `#browser`.
3. Scegli una sorgente. Viene aggiunta al tuo messaggio.
4. Scrivi la tua domanda e inviala.

| Sorgente | Cosa aggiunge |
| --- | --- |
| **Selected Text** | Il testo selezionato nella finestra corrente |
| **Clipboard Text** | Il testo negli appunti |
| **Current Application Content** | Il testo dell'app in primo piano |
| **Current Application Screenshot** | Uno screenshot dell'app in primo piano |
| **Current Screen Screenshot** | Uno screenshot dell'intero schermo |
| **Live Screen Screenshot** | Uno screenshot dello schermo senza le finestre di Enconvo |
| **User Select Area Screenshot** | Uno screenshot di una regione che selezioni |
| **Finder Selected Items** | I file e le cartelle selezionati nel Finder |
| **Finder Current Directory URL** | La cartella aperta nel Finder |
| **Browser Current Tab URL** | L'indirizzo della scheda corrente del browser |

Sono elencate anche le tue finestre aperte, così puoi aggiungere una finestra di un'altra app. Per usare un carattere diverso da `#`, cambia **Contesto** in **Cerca** in **Impostazioni → SmartBar**.

## Cosa chiedere

Con la pagina del browser allegata, chiedi a Enconvo di riassumere la pagina, tradurla o estrarre le informazioni chiave. Con i file del Finder allegati, chiedi di descrivere i file, suggerire come organizzarli, aiutare a rinominarli in blocco o analizzarne il contenuto.

<Note>
Il contesto che alleghi va al modello che risponde, o al provider che lo elabora. Controlla ciò che è allegato e le impostazioni del tuo provider prima di lavorare con contenuti sensibili.
</Note>

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| Il testo selezionato non viene allegato | Controlla che **Testo selezionato** sia impostato su **Allega** e controlla le [Autorizzazioni](/it/configuration/permissions). |
| Manca il contesto del Finder o del browser | Consenti a Enconvo di controllare quell'app quando macOS lo chiede. Se hai rifiutato, consentilo nelle [Autorizzazioni](/it/configuration/permissions). |
| Digitare `#` non apre l'elenco | Controlla il carattere **Contesto** in **Impostazioni → SmartBar**. |

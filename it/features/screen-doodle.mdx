Il Disegno sullo schermo ti permette di annotare una parte dello schermo prima di chiederne al tuo Agente. Disegna frecce, cerchi, evidenziazioni o note, poi invia. La schermata annotata viene allegata alla chat come immagine, nella Dynamic Island, a meno che tu non stessi usando un’altra chat di Enconvo come la Finestra di chat.

## Annota lo schermo

1. Porta in primo piano il contenuto di cui vuoi chiedere.
2. Fai un doppio clic destro per aprire il Disegno sullo schermo, oppure premi la **Scorciatoia da tastiera** impostata in **Impostazioni → Disegno sullo schermo**.
3. Se **Prima acquisisci un'area** è attivo, trascina per selezionare l’area. Altrimenti disegna direttamente sullo schermo dal vivo.
4. Scegli uno strumento nella barra e segna l’area che intendi.
5. Fai clic su **Invia** (l’aeroplanino) o premi **⌘↩**.
6. Rivedi l’immagine allegata e scrivi una richiesta, per esempio «Cosa significa l’avviso evidenziato?»

Il Disegno sullo schermo non ha una scorciatoia finché non ne imposti una. Il doppio clic destro funziona subito.

### Aggiungi un’etichetta parlata

Tieni premuto il tasto **Option** sinistro e parla per descrivere la forma che hai appena disegnato. Le tue parole compaiono accanto come testo. Perché il Disegno sullo schermo ascolti dopo ogni forma, attiva **Parla dopo ogni forma** nella barra e fai una pausa per chiudere ogni etichetta.

## Strumenti

| Strumento o azione | Tasto |
| --- | --- |
| Freccia | **A** |
| Linea | **L** |
| Penna | **P** |
| Evidenziatore | **H** |
| Rettangolo | **R** |
| Cerchio | **O** |
| Contatore (segni numerati) | **N** |
| Testo | **T** |
| Selezione | **V** |
| Gomma | **E** |
| Colore | **C** |
| Spessore della linea | **⌘** + scorrimento |
| Lavagna | **B** |
| Evidenzia cursore | **K** |
| Salva con nome… | **⌘S** |
| Invia | **⌘↩** |

La barra ha anche **Annulla**, **Ripeti**, **Cancella**, **Copia negli appunti** e **Chiudi**.

## Impostazioni

Apri **Impostazioni → Disegno sullo schermo**.

| Impostazione | Cosa fa |
| --- | --- |
| **Prima acquisisci un'area** | Seleziona un’area prima di disegnare. Disattivala per disegnare direttamente sullo schermo dal vivo. Attivo per impostazione predefinita. |
| **Scorciatoia da tastiera** | Apre o chiude il Disegno sullo schermo. Vuota per impostazione predefinita. |
| **Doppio clic destro** | Apre o chiude il Disegno sullo schermo con un doppio clic destro rapido. Attivo per impostazione predefinita. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| La sovrapposizione non si apre | Controlla **Scorciatoia da tastiera** e **Doppio clic destro** in **Impostazioni → Disegno sullo schermo**, e le [autorizzazioni di macOS](/it/configuration/permissions). |
| Ti serve solo l’intera finestra dell’app | Usa invece [Appshots](/it/features/appshots). |

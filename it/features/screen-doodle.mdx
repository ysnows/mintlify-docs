Il Disegno sullo schermo ti permette di annotare una parte dello schermo prima di fare una domanda al tuo Agent. Disegna frecce, cerchi, evidenziazioni o note, poi invia. Lo screenshot annotato viene allegato alla tua chat come immagine, nella Dynamic Island a meno che tu non stessi appena usando un'altra chat di Enconvo come la Finestra di chat.

## Annotare lo schermo

1. Porta in primo piano il contenuto su cui vuoi fare la domanda.
2. Fai doppio clic con il tasto destro per aprire il Disegno sullo schermo, oppure premi la **Scorciatoia da tastiera** che hai impostato in **Impostazioni → Disegno sullo schermo**.
3. Se **Prima acquisisci un'area** è attivo, trascina per selezionare l'area. Altrimenti disegna direttamente sullo schermo dal vivo.
4. Scegli uno strumento nella barra degli strumenti e segna l'area che intendi.
5. Fai clic su **Invia** (l'aeroplano di carta) oppure premi **⌘↩**.
6. Controlla l'immagine allegata e scrivi una richiesta, come "Cosa significa l'avviso evidenziato?"

Il Disegno sullo schermo non ha alcuna scorciatoia finché non ne imposti una. Il doppio clic destro funziona subito.

### Aggiungere un’etichetta parlata

Tieni premuto il tasto **Opzione** sinistro e parla per descrivere la forma che hai appena disegnato. Le tue parole compaiono accanto ad essa come testo. Perché il Disegno sullo schermo ascolti dopo ogni forma che disegni, attiva **Parla dopo ogni forma** nella barra degli strumenti e fai una pausa per concludere ogni etichetta.

## Strumenti

| Strumento o azione | Tasto |
| --- | --- |
| Freccia | **A** |
| Linea | **L** |
| Penna | **P** |
| Evidenziatore | **H** |
| Rettangolo | **R** |
| Cerchio | **O** |
| Contatore (indicatori numerati) | **N** |
| Testo | **T** |
| Seleziona | **V** |
| Gomma | **E** |
| Colore | **C** |
| Spessore della linea | **⌘** + scorrimento |
| Lavagna | **B** |
| Evidenzia cursore | **K** |
| Salva con nome… | **⌘S** |
| Invia | **⌘↩** |

La barra degli strumenti ha anche **Annulla**, **Ripeti**, **Cancella**, **Copia negli appunti** e **Chiudi**.

## Impostazioni

Apri **Impostazioni → Disegno sullo schermo**.

| Impostazione | Cosa fa |
| --- | --- |
| **Prima acquisisci un'area** | Seleziona un'area prima di disegnare. Disattivala per disegnare direttamente sullo schermo dal vivo. Attiva per impostazione predefinita. |
| **Scorciatoia da tastiera** | Apre o chiude il Disegno sullo schermo. Vuota per impostazione predefinita. |
| **Doppio clic destro** | Apre o chiude il Disegno sullo schermo con un rapido doppio clic destro. Attivo per impostazione predefinita. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| L'overlay non si apre | Controlla la **Scorciatoia da tastiera** e il **Doppio clic destro** in **Impostazioni → Disegno sullo schermo** e controlla le [autorizzazioni di macOS](/it/configuration/permissions). |
| Ti serve solo l'intera finestra dell'app | Usa invece [Appshots](/it/features/appshots). |

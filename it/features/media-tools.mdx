Le Utilità multimediali sono comandi locali per le faccende quotidiane con i contenuti multimediali: rendere più piccoli file di immagini, video o audio, salvare la colonna sonora di un video o scaricare un video da una pagina web. Le trovi in SmartBar, oppure in **Impostazioni → Plugin**.

| Comando | Cosa fa | Salva in |
| --- | --- | --- |
| **Image Compress** | Comprime una o più immagini, o ogni immagine in una cartella e nelle sue sottocartelle, con qualità regolabile | Sostituisce le immagini originali |
| **Video Compress** | Rende più piccolo un file video | `~/Downloads` |
| **Audio Compress** | Rende più piccolo un file audio in base alla qualità scelta e ne conserva la copertina (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Salva la traccia audio di un video, o di ogni video in una cartella, come M4A (MP3 quando la traccia non può essere copiata) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Scarica il video o l'audio da un link, come YouTube, TikTok, Instagram, Reddit, X o Vimeo | `~/Downloads` |

<Warning>
**Image Compress** sostituisce per impostazione predefinita le immagini originali. Per conservarle, disattiva prima **Overwrite Original Image File** nelle sue impostazioni; le copie compresse vanno poi in una cartella `enconvo-compressed-images` accanto alle immagini.
</Warning>

## Comprimi un file o estrai il suo audio

1. Seleziona i file nel Finder, oppure allegali. Per Image Compress puoi anche scegliere una cartella: le sue immagini e quelle nelle sue sottocartelle vengono compresse, e le copie mantengono la stessa struttura di cartelle.
2. Apri SmartBar ed esegui il comando.
3. Apri l'output e controllalo.

Conserva l'originale mentre provi le impostazioni di compressione. Le impostazioni di ogni comando si trovano in **Impostazioni → Plugin**: **Image Utils** per Image Compress e **Media Utils** per gli altri.

| Impostazione | Cosa cambia |
| --- | --- |
| **Qualità** | Da 0 a 100; un valore più alto mantiene più qualità e crea un file più grande. 80 per impostazione predefinita |
| **Percorso della cartella di destinazione** | Dove va il file compresso: un percorso assoluto, o un percorso relativo al file |
| **Overwrite Original … File** | Sostituisce il file originale. Attivo per impostazione predefinita per le immagini, disattivato per video e audio |

## Scarica un video

1. Apri la pagina del video nel browser, oppure copia il suo link.
2. Esegui **Online Video Downloader** da SmartBar. Prende il link dalla scheda attiva del browser, oppure da un link che digiti.
3. Segui l'avanzamento nella Dynamic Island, dove puoi annullare. Quando ha finito, fai clic su **Mostra nel Finder**.

Il download viene salvato nella cronologia delle chat, e un file già scaricato viene riutilizzato invece di essere recuperato di nuovo. Il funzionamento con un sito dipende dal sito e da ciò a cui ti permette di accedere. Scarica solo contenuti che hai il permesso di salvare.

| Impostazione | Cosa cambia |
| --- | --- |
| **Output Directory** | Dove vanno i download. `~/Downloads` per impostazione predefinita |
| **Audio Only** | Scarica solo l'audio |
| **Favorite Resolution** | La risoluzione da scaricare, da **Best** (predefinita) fino a 144p |
| **Force Convert to Compatible MP4** | Converte il video in un MP4 che si riproduce ovunque. Attivo per impostazione predefinita; richiede tempo e CPU aggiuntivi |
| **Use Browser Cookies** | Accede con i cookie del tuo browser, per i video che solo tu puoi vedere. Scegli il browser in **Browser** |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| **No images to compress** | Seleziona le immagini nel Finder o allegale, poi esegui di nuovo il comando |
| Una conversione non riesce | Controlla il formato del file, che la cartella di output sia scrivibile e che ci sia spazio libero su disco |
| Un video privato non si scarica | Attiva **Use Browser Cookies** e scegli il browser con cui hai effettuato l'accesso |
| I download da un sito smettono di funzionare | Leggi l'errore e aggiorna il plugin prima di riprovare. I siti web cambiano i loro formati e le regole di accesso |

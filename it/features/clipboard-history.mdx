---
title: "Cronologia degli appunti, segnalibri e ricerca file"
description: "Cerca ciò che hai copiato, i segnalibri del browser e i file sul tuo Mac da una scorciatoia da tastiera o da SmartBar."
---

Cronologia appunti, Segnalibri del browser e Ricerca file sono tre elenchi rapidi in cui cerchi mentre scrivi. Usa la Cronologia appunti per incollare qualcosa che hai copiato in precedenza, la Ricerca segnalibri per aprire una pagina salvata in qualsiasi browser e la Ricerca file per aprire un file senza passare dal Finder. Ognuno si apre con una propria scorciatoia da tastiera, oppure da SmartBar con un alias.

## Apri un elenco

1. Imposta una scorciatoia da tastiera per l'elenco in **Impostazioni → Scorciatoia**, oppure nella pagina delle impostazioni dell'elenco stesso in **Impostazioni → Plugin**.
2. Premi la scorciatoia. Con **La scorciatoia apre una finestra** attivo, che è il valore predefinito, l'elenco si apre in una finestra propria e SmartBar resta com'è.
3. Scrivi per filtrare l'elenco, raggiungi un elemento con i tasti freccia e premi Invio.

Per aprire invece un elenco dentro SmartBar, imposta il suo **Alias**. Scrivi l'alias e uno spazio in SmartBar, e l'elenco si apre lì. La ricerca di SmartBar mostra l'alias di ogni elenco.

Puoi anche menzionare un elenco con `@` in una chat, e l'Agente cerca in quell'elenco per te.

## Incolla dalla Cronologia appunti

La Cronologia appunti conserva i testi, le immagini e i file che copi. Puoi fissare i preferiti e filtrare per link, email, colori, immagini o file.

1. Apri la Cronologia appunti.
2. Scrivi una parola di ciò che hai copiato.
3. Premi Invio per incollare l'elemento nell'app che stavi usando. Premi **⌘C** per copiarlo invece. Con **Tasto Invio** impostato su copia, **⌘Invio** incolla.

Quando apri l'elenco sopra una delle finestre di Enconvo, Invio incolla nella casella del messaggio di quella finestra.

I gestori di password e Accesso Portachiavi sono esclusi per impostazione predefinita, e le copie che le app contrassegnano come nascoste o temporanee, come le password, non vengono mai registrate.

## Apri un segnalibro

Segnalibri del browser legge i segnalibri di Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox e Zen, compresi i profili di Firefox e Zen conservati in una cartella che hai scelto. Una ricerca trova corrispondenze anche nei nomi delle cartelle.

Premi Invio per aprire il segnalibro nel browser da cui proviene, oppure **⌘O** per aprirlo nel tuo browser predefinito. **Tasto Invio** scambia le due azioni.

## Trova un file

Ricerca file cerca su tutto il tuo Mac per impostazione predefinita. Usa il menu a discesa nel suo campo di ricerca per cercare in un solo luogo, solo per questa ricerca, come **Le mie cartelle**, **Home** o **Download**.

Premi Invio per aprire il file, oppure **⌘Invio** per mostrarlo nel Finder. **Tasto Invio** scambia le due azioni.

## Impostazioni

Apri **Impostazioni → Plugin**, poi **Cronologia appunti**, **Segnalibri del browser** o **Ricerca file**.

| Impostazione | Elenco | Cosa cambia |
| --- | --- | --- |
| **Alias** | Tutti e tre | La parola che scrivi, seguita da uno spazio, in SmartBar per aprire lì l'elenco. |
| **La scorciatoia apre una finestra** | Tutti e tre | Attivo: la scorciatoia apre l'elenco in una finestra propria. Disattivato: la scorciatoia lo apre in SmartBar. Attivo per impostazione predefinita. |
| **Tasto Invio** | Tutti e tre | Cosa fa Invio. Cronologia appunti: **Incolla nell'app in primo piano** o **Copia negli appunti**. Segnalibri: **Apri nel suo browser** o **Apri nel browser predefinito**. File: **Apri** o **Mostra nel Finder**. |
| **Registra la cronologia degli appunti** | Cronologia appunti | Conserva una cronologia di ciò che copi. Disattivarlo mantiene gli elementi già salvati. |
| **Conserva la cronologia per** | Cronologia appunti | Per quanto tempo restano gli elementi, da **1 giorno** a **Per sempre**. 3 mesi per impostazione predefinita. Gli elementi fissati non vengono mai rimossi. |
| **App ignorate** | Cronologia appunti | App le cui copie non vengono mai registrate, indicate tramite bundle ID. |
| **Mostra i nomi delle cartelle** | Segnalibri | Mostra la cartella di ogni segnalibro. |
| **Browser disattivati** | Segnalibri | Browser i cui segnalibri vengono esclusi. |
| **Cerca in** | File | Dove cerca Ricerca file quando si apre: **Questo Mac**, **Le mie cartelle**, **Home**, **Scrivania**, **Documenti**, **Download** o **Applicazioni**. |
| **Cartelle di ricerca** | File | Le cartelle in cui cerca **Le mie cartelle**. Scrivania, Documenti e Download se vuoto. |
| **Mostra i file nascosti** | File | Include i file i cui nomi iniziano con un punto. |
| **Cartelle escluse** | File | Cartelle il cui contenuto non compare mai. |

Una scorciatoia o un alias impostati nelle precedenti versioni web di questi elenchi vengono mantenuti.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| La scorciatoia apre SmartBar invece di una finestra | Attiva **La scorciatoia apre una finestra** per quell'elenco. |
| Una copia manca dalla Cronologia appunti | Controlla **Registra la cronologia degli appunti** e **App ignorate**. Le copie nascoste, come le password, non vengono mai registrate. |
| I segnalibri di un browser non ci sono | Controlla **Browser disattivati**. |
| Un file non compare | Controlla **Cerca in**, **Cartelle escluse** e **Mostra i file nascosti**. |

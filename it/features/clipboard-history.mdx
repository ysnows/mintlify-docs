---
title: "Cronologia degli appunti, segnalibri e ricerca file"
description: "Cerca ciò che hai copiato, i segnalibri del browser e i file del Mac da una scorciatoia o da Smart Bar."
---

Cronologia degli appunti, Cerca segnalibri del browser e Cerca file sono tre elenchi rapidi che filtri mentre scrivi. Usa Cronologia degli appunti per incollare qualcosa copiato prima, la ricerca segnalibri per aprire una pagina salvata in qualsiasi browser e la ricerca file per aprire un file senza Finder. Ciascuno si apre dalla propria scorciatoia, o da Smart Bar con un alias.

## Aprire un elenco

1. Imposta una scorciatoia per l’elenco in **Impostazioni → Scorciatoia**, oppure nella pagina delle impostazioni dell’elenco in **Impostazioni → Plugin**.
2. Premi la scorciatoia. Con **La scorciatoia apre una finestra** attivo, che è il predefinito, l’elenco si apre in una finestra propria e Smart Bar resta com’è.
3. Scrivi per filtrare l’elenco, spostati su una voce con le frecce e premi Invio.

Per aprire un elenco dentro Smart Bar, imposta il suo **Alias**. Scrivi l’alias e uno spazio in Smart Bar e l’elenco si apre lì. La ricerca di Smart Bar mostra l’alias di ogni elenco.

Puoi anche menzionare un elenco con `@` in una chat, e l’Agente lo cerca per te.

## Incollare dalla Cronologia degli appunti

Cronologia degli appunti tiene il testo, le immagini e i file che copi. Puoi fissare i preferiti e filtrare per link, email, colori, immagini o file.

1. Apri Cronologia degli appunti.
2. Scrivi una parola di ciò che hai copiato.
3. Premi Invio per incollare la voce nell’app che stavi usando. Premi **⌘C** per copiarla invece. Con **Tasto Invio** impostato su copia, **⌘Return** incolla.

Quando apri l’elenco sopra una finestra di Enconvo, Invio incolla nella casella del messaggio di quella finestra.

I gestori di password e Accesso Portachiavi sono esclusi per impostazione predefinita, e le copie che le app segnano come nascoste o temporanee, come le password, non vengono mai registrate.

## Aprire un segnalibro

Cerca segnalibri del browser legge i segnalibri di Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox e Zen, compresi i profili di Firefox e Zen tenuti in una cartella che hai scelto. Una ricerca trova anche i nomi delle cartelle.

Premi Invio per aprire il segnalibro nel browser da cui proviene, o **⌘O** per aprirlo nel browser predefinito. **Tasto Invio** scambia i due.

## Trovare un file

Cerca file guarda tutto il Mac per impostazione predefinita. Usa il menu nel campo di ricerca per cercare un solo posto per questa ricerca, come **Le mie cartelle**, **Home** o **Download**.

Premi Invio per aprire il file, o **⌘Return** per mostrarlo nel Finder. **Tasto Invio** scambia i due.

## Impostazioni

Apri **Impostazioni → Plugin**, poi **Cronologia degli appunti**, **Segnalibri del browser** o **Cerca file**.

| Impostazione | Elenco | Cosa cambia |
| --- | --- | --- |
| **Alias** | Tutti e tre | La parola che scrivi, poi uno spazio, in Smart Bar per aprire lì l’elenco. |
| **La scorciatoia apre una finestra** | Tutti e tre | Attivo: la scorciatoia apre l’elenco nella sua finestra. Disattivo: la scorciatoia lo apre in Smart Bar. Attivo per impostazione predefinita. |
| **Tasto Invio** | Tutti e tre | Cosa fa Invio. Cronologia degli appunti: **Incolla nell’app in primo piano** o **Copia negli appunti**. Segnalibri: **Apri nel suo browser** o **Apri nel browser predefinito**. File: **Apri** o **Mostra nel Finder**. |
| **Registra la cronologia degli appunti** | Cronologia degli appunti | Tiene una cronologia di ciò che copi. Disattivarla conserva le voci già salvate. |
| **Conserva la cronologia per** | Cronologia degli appunti | Quanto restano le voci, da **1 giorno** a **Per sempre**. 3 mesi per impostazione predefinita. Le voci fissate non vengono mai rimosse. |
| **App ignorate** | Cronologia degli appunti | App le cui copie non vengono mai registrate, per bundle ID. |
| **Mostra i nomi delle cartelle** | Segnalibri | Mostra la cartella di ogni segnalibro. |
| **Browser disattivati** | Segnalibri | Browser i cui segnalibri sono esclusi. |
| **Cerca in** | File | Dove guarda Cerca file all’apertura: **Questo Mac**, **Le mie cartelle**, **Home**, **Scrivania**, **Documenti**, **Download** o **Applicazioni**. |
| **Cartelle di ricerca** | File | Le cartelle che **Le mie cartelle** cerca. Scrivania, Documenti e Download se è vuoto. |
| **Mostra i file nascosti** | File | Include i file il cui nome inizia con un punto. |
| **Cartelle escluse** | File | Cartelle il cui contenuto non compare mai. |

Una scorciatoia o un alias impostato sulle versioni web più vecchie di questi elenchi viene conservato.

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| La scorciatoia apre Smart Bar invece di una finestra | Attiva **La scorciatoia apre una finestra** per quell’elenco. |
| Manca una copia nella Cronologia degli appunti | Controlla **Registra la cronologia degli appunti** e **App ignorate**. Le copie nascoste, come le password, non vengono mai registrate. |
| Mancano i segnalibri di un browser | Controlla **Browser disattivati**. |
| Un file non compare | Controlla **Cerca in**, **Cartelle escluse** e **Mostra i file nascosti**. |

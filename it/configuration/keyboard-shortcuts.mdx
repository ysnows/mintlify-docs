Le finestre e le funzioni vocali di Enconvo si aprono ciascuna con una scorciatoia. **Impostazioni → Scorciatoia** elenca ogni scorciatoia usata da Enconvo e il comando che esegue, così puoi cambiarne una o scoprire cosa fa una combinazione di tasti. Le scorciatoie salvate sul tuo Mac hanno sempre la precedenza su quelle predefinite di questa guida.

Questo video copre le Scorciatoie, poi le altre impostazioni che adattano Enconvo al tuo Mac: Comprensione del contesto, Appshots, Modelli locali, Autorizzazioni e Impedisci lo stato di stop.

## Scorciatoie predefinite

| Azione | Predefinita |
| --- | --- |
| Mostra SmartBar | **⌥Space** |
| Mostra la Finestra di chat | **⌃⌘X** |
| Mostra la Barra laterale dell'app | **⌃⌘E** |
| Apri le Impostazioni, dall'interno di Enconvo | **⌘,** |
| Avvia la Dettatura | **⌘ destro** |
| Avvia il Comando vocale | **⌥ destro** |
| Pausa/Riprendi audio | **⌥P** |

Queste impostazioni predefinite valgono solo se non hai mai impostato un tasto tuo; un tasto che hai impostato resta com'è. Acquisizione rapida e Appshots non hanno una scorciatoia predefinita: impostane una nelle rispettive pagine Impostazioni prima di usarle.

## Cambiare una scorciatoia

1. Apri **Impostazioni → Scorciatoia**. La scheda **Principali** contiene le funzioni principali, **Altre scorciatoie** contiene i comandi IA, i plugin, le impostazioni e i comandi che nessun'altra pagina mostra, e **Tutti** mostra entrambe.
2. Scrivi in **Filtra per nome…** per trovare un comando. Per trovare il comando associato a una combinazione di tasti, fai clic su **Cerca per scorciatoia** e premila.
3. Fai clic sul campo della scorciatoia del comando e premi la nuova combinazione.
4. Se quei tasti eseguono già un altro comando, il campo te lo dice. Scegli **Usala qui** per spostare i tasti su questo comando, oppure scegli una delle scorciatoie libere che propone.
5. Passa a un'altra app e prova la scorciatoia.

Per liberare i tasti di una scorciatoia, rimuovila dal comando. Un messaggio con **Annulla** ti permette di tornare indietro.

Un badge **Locale** indica una scorciatoia che funziona solo dentro Enconvo, come Fissa SmartBar.

## Come premerlo

Quando registri un solo tasto modificatore, come ⌘ destro, il campo chiede **Come premerlo**:

| Opzione | Il comando viene eseguito quando |
| --- | --- |
| **Tieni premuto o tocca** | Tieni premuto il tasto, o lo tocchi per attivare e disattivare |
| **Tocco** | Tocchi il tasto per iniziare e lo tocchi di nuovo per fermare |
| **Tieni premuto** | Tieni premuto il tasto; funziona finché lo tieni premuto |
| **Doppio tocco** | Tocchi il tasto due volte in rapida successione |

Due o più tasti modificatori premuti contemporaneamente contano come un'unica scorciatoia. Ogni campo mostra solo i tipi supportati dal suo comando, e la descrizione accanto spiega come reagisce quella funzione.

## Dove si trova la scorciatoia di ogni funzione

Oltre alla pagina Scorciatoia, ogni funzione ha la propria scorciatoia nella sua pagina Impostazioni:

| Funzione | Pagina Impostazioni |
| --- | --- |
| SmartBar | **Impostazioni → SmartBar** |
| Dynamic Island | **Impostazioni → Dynamic Island** |
| PopBar | **Impostazioni → PopBar** |
| Barra laterale dell'app | **Impostazioni → Barra laterale dell’app** |
| Dettatura | **Impostazioni → Dettatura** |
| Comando vocale | **Impostazioni → Comando vocale** |
| Appshots | **Impostazioni → Appshots** |
| Disegno sullo schermo | **Impostazioni → Disegno sullo schermo** |
| Nota vocale | **Impostazioni → Nota vocale** |
| Acquisizione rapida | **Impostazioni → Acquisizione rapida** |
| Un singolo comando | Le impostazioni di quel comando, quando ha un campo **Scorciatoia da tastiera** |

## Dentro SmartBar

Scrivi un carattere di attivazione in SmartBar per cercare un tipo di elemento:

| Carattere | Apre |
| --- | --- |
| **@** | Comandi |
| **#** | Contesto da aggiungere al tuo messaggio |
| **$** | Competenze |
| **>** | Attività recenti |

Cambia questi caratteri sotto **Cerca** in **Impostazioni → SmartBar**. Il menu con la barra obliqua contiene azioni come la scelta del modello e del ragionamento.

Per spostarti negli elenchi con la tastiera, scegli **Tasti di navigazione** in **Impostazioni → SmartBar**: **macOS** usa **⌃N** **⌃P** **⌃F** **⌃B**, e **Vim** usa **⌃J** **⌃K** **⌃L** **⌃H**.

## Adattare Enconvo al tuo Mac

La stessa finestra Impostazioni contiene le altre scelte illustrate nel video:

| Pagina Impostazioni | Cosa fa |
| --- | --- |
| **Comprensione del contesto** | Sceglie cosa SmartBar raccoglie dall'app in cui ti trovavi: il testo selezionato, la selezione del Finder o la pagina nel tuo browser. **Allega** lo aggiunge appena SmartBar si apre, e **Suggerisci** lo propone con un solo clic. Vedi [Comprensione del contesto](/it/features/context-awareness). |
| **Appshots** | Aggiunge alla conversazione la finestra che hai davanti con una scorciatoia. Vedi [Appshots](/it/features/appshots). |
| **Modelli locali** | Mostra l'IA in esecuzione su questo Mac, la memoria e il disco che usa e dove viene eseguita ogni funzione. Vedi [Modelli locali](/it/ai/local-llm). |
| **Autorizzazioni** | Elenca ciò che macOS permette a Enconvo di fare e perché; **Concedi** risolve quelle mancanti. Vedi [Autorizzazioni di macOS](/it/configuration/permissions). |
| **Impedisci lo stato di stop** | Impedisce a questo Mac di andare in stop mentre sei via, così puoi comunque raggiungerlo dal tuo iPhone. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| Una scorciatoia funziona solo dentro Enconvo | Controlla se ha un badge **Locale**. In caso contrario, controlla Monitoraggio input e Accessibilità in [Autorizzazioni di macOS](/it/configuration/permissions) e se un'altra app usa gli stessi tasti. |
| Premendo una scorciatoia succede qualcos'altro | Usa **Cerca per scorciatoia**. Se nessun comando di Enconvo usa quei tasti, li usa un'altra app o macOS. |
| La scorciatoia con un tasto modificatore non scatta | Apri la scorciatoia e controlla **Come premerlo**: tenere premuto, toccare, doppio tocco o tasti premuti insieme. |
| Una scorciatoia di un video o di un altro Mac non funziona | Le tue scorciatoie potrebbero essere diverse. Cerca quella attuale in **Impostazioni → Scorciatoia**. |

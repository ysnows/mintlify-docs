Le finestre e le funzioni vocali di Enconvo si aprono ciascuna con una scorciatoia. **Impostazioni → Scorciatoia** elenca ogni scorciatoia usata da Enconvo e il comando che esegue, così puoi cambiarne una o scoprire cosa fa una combinazione di tasti. Le scorciatoie salvate sul Mac prevalgono sempre sui predefiniti di questa guida.

Questo video copre le scorciatoie, poi le altre impostazioni che adattano Enconvo al Mac: Comprensione del contesto, Appshots, modelli locali, permessi e Resta sveglio.

## Scorciatoie predefinite

| Azione | Predefinito |
| --- | --- |
| Mostra SmartBar | **⌥Space** |
| Mostra la Finestra di chat | **⌃⌘X** |
| Mostra la Barra laterale dell’app | **⌃⌘E** |
| Apri Impostazioni, da dentro Enconvo | **⌘,** |
| Avvia la Dettatura | **⌘ destro** |
| Avvia il Comando vocale | **⌥ destro** |
| Metti in pausa/riprendi l’audio | **⌥P** |

Questi predefiniti valgono solo se non hai mai impostato un tasto tuo; un tasto che imposti resta com’è. Acquisizione rapida e Appshots non hanno una scorciatoia predefinita: impostane una nelle loro pagine delle Impostazioni prima di usarle.

## Cambia una scorciatoia

1. Apri **Impostazioni → Scorciatoia**. La scheda **Principali** contiene le funzioni principali, **Altre scorciatoie** contiene comandi IA, plugin, impostazioni e comandi che nessuna altra pagina mostra, e **Tutti** mostra entrambi.
2. Scrivi in **Filtra per nome…** per trovare un comando. Per trovare il comando dietro una combinazione, fai clic su **Cerca per scorciatoia** e premila.
3. Fai clic sul campo della scorciatoia del comando e premi la nuova combinazione.
4. Se quei tasti eseguono già un altro comando, il campo te lo dice. Scegli **Usala qui** per spostare i tasti su questo comando, oppure scegli una delle scorciatoie libere che propone.
5. Passa a un’altra app e prova la scorciatoia.

Per liberare i tasti di una scorciatoia, rimuovila dal comando. Un messaggio con **Annulla** consente di tornare indietro.

Un badge **Locale** indica una scorciatoia che funziona solo dentro Enconvo, come Fissa SmartBar.

## Come premerlo

Quando registri un solo tasto modificatore, come ⌘ destro, il campo chiede **Come premerlo**:

| Opzione | Il comando parte quando |
| --- | --- |
| **Tieni premuto o tocca** | Tieni premuto il tasto, oppure toccalo per attivare/disattivare |
| **Tocco** | Tocca il tasto per iniziare e tocca di nuovo per fermare |
| **Tieni premuto** | Tieni premuto il tasto; funziona mentre lo tieni |
| **Doppio tocco** | Tocca il tasto due volte in fretta |

Due o più tasti modificatore premuti insieme contano come una sola scorciatoia. Ogni campo mostra solo i tipi che il suo comando supporta, e la descrizione accanto dice come reagisce quella funzione.

## Dove sta la scorciatoia di ogni funzione

Oltre alla pagina Scorciatoia, ogni funzione ha la sua scorciatoia nella propria pagina delle Impostazioni:

| Funzione | Pagina delle Impostazioni |
| --- | --- |
| SmartBar | **Impostazioni → SmartBar** |
| Dynamic Island | **Impostazioni → Dynamic Island** |
| PopBar | **Impostazioni → PopBar** |
| Barra laterale dell’app | **Impostazioni → Barra laterale dell’app** |
| Dettatura | **Impostazioni → Dettatura** |
| Comando vocale | **Impostazioni → Comando vocale** |
| Appshots | **Impostazioni → Appshots** |
| Disegno sullo schermo | **Impostazioni → Disegno sullo schermo** |
| Nota vocale | **Impostazioni → Nota vocale** |
| Acquisizione rapida | **Impostazioni → Acquisizione rapida** |
| Un singolo comando | Le impostazioni di quel comando, quando ha un campo **Scorciatoia** |

## Dentro SmartBar

Digita un carattere di trigger in SmartBar per cercare un tipo di elemento:

| Carattere | Apre |
| --- | --- |
| **@** | Comandi |
| **#** | Contesto da aggiungere al messaggio |
| **$** | Competenze |
| **>** | Compiti recenti |

Cambia questi caratteri sotto **Cerca** in **Impostazioni → SmartBar**. Il menu slash contiene azioni come la scelta del modello e del ragionamento.

Per muoverti negli elenchi con la tastiera, scegli **Tasti di navigazione** in **Impostazioni → SmartBar**: **macOS** usa **⌃N** **⌃P** **⌃F** **⌃B**, e **Vim** usa **⌃J** **⌃K** **⌃L** **⌃H**.

## Adatta Enconvo al Mac

La stessa finestra Impostazioni contiene le altre scelte che il video percorre:

| Pagina delle Impostazioni | Cosa fa |
| --- | --- |
| **Comprensione del contesto** | Sceglie cosa SmartBar prende dall’app in cui eri: il testo selezionato, la selezione del Finder o la pagina nel browser. **Allega** lo aggiunge appena si apre SmartBar, e **Suggerisci** lo propone con un clic. Vedi [Comprensione del contesto](/it/features/context-awareness). |
| **Appshots** | Aggiunge la finestra davanti a te alla conversazione con una scorciatoia. Vedi [Appshots](/it/features/appshots). |
| **Modelli locali** | Mostra l’IA che gira su questo Mac, la memoria e il disco che usa, e dove gira ogni funzione. Vedi [Modelli locali](/it/ai/local-llm). |
| **Permessi** | Elenca cosa macOS consente a Enconvo e perché; **Concedi** sistema un permesso mancante. Vedi [Permessi di macOS](/it/configuration/permissions). |
| **Resta sveglio** | Impedisce a questo Mac di andare in stop mentre sei via, così puoi raggiungerlo dall’iPhone. |

## Risoluzione dei problemi

| Problema | Cosa fare |
| --- | --- |
| Una scorciatoia funziona solo dentro Enconvo | Controlla se ha un badge **Locale**. Se no, controlla Monitoraggio input e Accessibilità in [Permessi di macOS](/it/configuration/permissions), e se un’altra app usa gli stessi tasti. |
| Premere una scorciatoia fa qualcos’altro | Usa **Cerca per scorciatoia**. Se nessun comando Enconvo usa i tasti, lo fa un’altra app o macOS. |
| Una scorciatoia con tasto modificatore non parte | Apri la scorciatoia e controlla **Come premerlo**: tieni premuto, tocco, doppio tocco o tasti premuti insieme. |
| Una scorciatoia di un video o di un altro Mac non funziona | Le tue scorciatoie possono differire. Cerca quella attuale in **Impostazioni → Scorciatoia**. |

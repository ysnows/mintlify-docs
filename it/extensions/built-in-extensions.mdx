Le funzioni integrate sono raggruppate qui sotto in base all'attività che supportano. La disponibilità dipende dalle estensioni installate e dalla versione dell'app. Le implementazioni dei provider sono elencate a parte nel [Catalogo delle funzioni dei provider](/it/providers/catalog).

Usa SmartBar per trovare un comando dal titolo. Apri **Impostazioni → Plugin** per rivedere le estensioni installate e le impostazioni dei loro comandi. Gli strumenti degli Agenti possono essere selezionati nelle impostazioni dell'Agente invece di comparire come comandi autonomi del launcher.

## Servizi di supporto

Alcune estensioni forniscono infrastruttura invece di un comando che avvii direttamente: API locali, configurazione, instradamento delle credenziali, analisi dei documenti, runtime dei modelli, archiviazione dei messaggi, indicizzazione della ricerca, gestione dei plugin e consegna dei canali. Usa la guida all'attività per la funzione che supportano, oppure [CLI e API locali](/it/advanced/cli-local-api) per il lavoro di integrazione.

Il Mobile Companion collega l'app Enconvo per iPhone (beta) al tuo Mac; vedi [App per iPhone](/it/integrations/iphone-app) per associare un telefono. Per l'accesso tramite le app di messaggistica, usa [Canali di messaggistica istantanea](/it/integrations/messaging).

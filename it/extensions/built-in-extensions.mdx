Le capacità integrate sono raggruppate sotto per il compito che supportano. La disponibilità dipende dalle estensioni installate e dalla build dell’app. Le implementazioni dei fornitori sono elencate a parte nel [Catalogo delle capacità dei fornitori](/it/providers/catalog).

Usa SmartBar per trovare un comando dal titolo. Apri **Impostazioni → Plugin** per rivedere le estensioni installate e le impostazioni dei loro comandi. Gli strumenti degli Agenti si scelgono nelle impostazioni dell’Agente invece di comparire come comandi autonomi del launcher.

## Servizi di supporto

Alcune estensioni forniscono infrastruttura invece di un comando che avvii direttamente: API locali, configurazione, instradamento delle credenziali, analisi dei documenti, runtime dei modelli, archivio dei messaggi, indicizzazione della ricerca, gestione dei plugin e consegna sui canali. Usa la guida del compito per la funzione che supportano, oppure [CLI e API locali](/it/advanced/cli-local-api) per il lavoro di integrazione.

Il Mobile Companion collega l’app iPhone di Enconvo (beta) al Mac; vedi [App iPhone](/it/integrations/iphone-app) per associare un telefono. Per l’accesso tramite app di messaggistica, usa i [Canali di messaggistica](/it/integrations/messaging).

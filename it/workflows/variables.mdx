title: "Variabili"
description: "Inserisci nei prompt e negli altri campi che accettano template il tuo input attuale, il testo selezionato, il contesto dell'app o la data."
---

Le variabili inseriscono valori che cambiano ogni volta, come il testo che hai scritto in SmartBar, il testo selezionato in un'altra app o la data di oggi. Usale nei prompt e nelle preferenze che supportano i template, così un unico Comando IA, un'istruzione per un Agente o un workflow funziona su qualsiasi cosa tu abbia davanti. Apri **Impostazioni → Variabili** per vedere le variabili disponibili.

## Variabili disponibili

| Variabile | Valore fornito |
| --- | --- |
| Input Text | Input attuale di SmartBar |
| Selection Text | Testo selezionato nell'app corrente |
| Latest Clipboard | Contenuto più recente degli appunti |
| Active Application | Informazioni sull'app in primo piano |
| Active Application Screenshot | Immagine della finestra in primo piano |
| Active Screen Screenshot | Immagine dello schermo attivo |
| Focused Window Content | Contenuto estratto dalla finestra attiva |
| Browser Active Tab | URL della scheda attiva e contenuto della pagina disponibile |
| Current Folder | La cartella aperta nel Finder |
| Selected Files | I file selezionati nel Finder |
| History Messages | Cronologia della conversazione attuale |
| Now | Data e ora correnti |
| Your Language | La lingua che leggi: la tua **Lingua delle risposte**, oppure la lingua di sistema quando è su Automatica |
| Opened Applications | Informazioni sulle app in esecuzione |
| Opened Application Names | Nomi delle app in esecuzione |

## Usare una variabile

1. Apri il campo del Comando IA, dell'istruzione per l'Agente o del workflow che vuoi personalizzare.
2. Controlla che il campo supporti le variabili; usa il suo selettore se ne ha uno.
3. Inserisci il valore che ti serve e prova con contenuti di esempio innocui.
4. Controlla se un input vuoto o un permesso mancante cambia il risultato.

Un prompt di testo può usare nomi di template supportati come:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Le variabili che puoi usare dipendono dal comando e dal contesto, e non tutti i campi di testo valutano i template. Gli screenshot e il contenuto delle app possono richiedere permessi di macOS e un modello che accetti quel tipo di input.

---
title: "Variabili"
description: "Inserisci l’input attuale, il testo selezionato, il contesto dell’app o la data nei prompt e negli altri campi che accettano i modelli."
---

Le variabili inseriscono valori che cambiano ogni volta, come il testo digitato in SmartBar, il testo selezionato in un’altra app o la data di oggi. Usale nei prompt e nelle preferenze che supportano i modelli, così un Comando IA, un’istruzione di un Agente o un flusso di lavoro funziona su ciò che hai davanti. Apri **Impostazioni → Variabili** per sfogliare le variabili disponibili.

## Variabili disponibili

| Variabile | Valore fornito |
| --- | --- |
| Testo di input | Input attuale di SmartBar |
| Testo selezionato | Testo selezionato nell’app attuale |
| Appunti più recenti | Contenuto più recente degli appunti |
| Applicazione attiva | Informazioni sull’app in primo piano |
| Schermata dell’applicazione attiva | Immagine della finestra in primo piano |
| Schermata dello schermo attivo | Immagine dello schermo attivo |
| Contenuto della finestra focalizzata | Contenuto estratto dalla finestra focalizzata |
| Scheda attiva del browser | URL della scheda attiva e contenuto della pagina, se disponibile |
| Cartella attuale | La cartella aperta nel Finder |
| File selezionati | File selezionati nel Finder |
| Messaggi della cronologia | Cronologia della conversazione attuale |
| Adesso | Data e ora attuali |
| La tua lingua | La lingua in cui leggi: la tua **Lingua delle risposte**, oppure la lingua di sistema quando è Auto |
| Applicazioni aperte | Informazioni sulle app in esecuzione |
| Nomi delle applicazioni aperte | Nomi delle app in esecuzione |

## Usa una variabile

1. Apri il Comando IA, l’istruzione dell’Agente o il campo del flusso di lavoro che vuoi personalizzare.
2. Verifica che il campo supporti le variabili; usa il selettore, se c’è.
3. Inserisci il valore che ti serve e prova con un contenuto di esempio innocuo.
4. Controlla se un input vuoto o un’autorizzazione mancante cambia il risultato.

Un prompt di testo può usare nomi di modello supportati, come:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Quali variabili puoi usare dipende dal comando e dal contesto, e non ogni campo di testo valuta i modelli. Schermate e contenuto delle app possono richiedere le autorizzazioni di macOS e un modello che accetta quel tipo di input.

Questa pagina è per sviluppatori e utenti esperti che vogliono controllare Enconvo dal Terminale, da uno script o da un'altra app. Il comando `enconvo` è incluso nell'app desktop di Enconvo, senza bisogno di un'installazione separata, e l'app espone le route di ogni plugin installato tramite un'API HTTP locale.

Questo video illustra la pagina API, la Guida alla CLI e gli Hook.

Tieni Enconvo in esecuzione per i comandi che usano il suo runtime locale.

## Trovare i comandi

```bash
enconvo -h
enconvo knowledge_base -h
```

Aggiungi `-h` al comando che stai esplorando per vedere i suoi sottocomandi e le sue opzioni attuali.

Apri **Impostazioni → Guida alla CLI** per vedere le estensioni installate che espongono comandi CLI. Fai clic su un nome per copiare il relativo comando `enconvo <name> -h`. L'elenco delle estensioni installate è la fonte di riferimento per ciò che la tua app supporta.

Se la shell non trova `enconvo`, apri la Guida alla CLI dell'app e controlla la versione dell'app installata e la configurazione della riga di comando.

## Chiamare la Local API

L'app espone ogni route all'indirizzo `http://localhost:54535/api/<extension>/<route>`. Invia una `POST` con un corpo JSON:

```bash
curl -X POST http://localhost:54535/api/enconvo/extension/available_list \
  -H "Content-Type: application/json" \
  -d '{}'
```

Apri **Impostazioni → API** e fai clic su **Controlla le API** per consultare le route disponibili e gli schemi delle richieste, con un esempio per ciascuna. Usa lo schema della tua build installata quando scrivi un'integrazione: i parametri delle route possono cambiare con l'evolversi delle estensioni.

## Eseguire un agente o un comando IA dall’esterno di Enconvo

Le impostazioni di ogni agente e di ogni comando IA hanno una riga **Link, CLI e API**. Mostra il link, il comando `enconvo` e la chiamata alla Local API che lo eseguono con il tuo testo e i tuoi file, pronti da copiare.

| Modo | Cosa fa |
| --- | --- |
| Link | Apre una nuova chat e vi esegue l'agente o il comando IA |
| CLI | Lo esegue in background e stampa la risposta |
| Local API | Lo esegue in background e restituisce la risposta |

Un link ha questa forma:

```text
enconvo://<extension>/<command>?input_text=<text>&window=<window>&files=<path>
```

- `input_text` è il testo da inviare.
- `window` è `chat_window` o `dynamic_island`. Omettilo per eseguire nella SmartBar.
- `files` allega il file indicato da un percorso assoluto o che inizia con `~/`. Ripetilo per più file, ad esempio per inviare immagini da un'altra app o da uno script.

Dal Terminale:

```bash
enconvo agent call "What's on my calendar today?"
enconvo ai-command run 'writing_package|translate' --input-text "Bonjour" --files ~/Desktop/note.png
enconvo writing_package convert_to_list "eggs, milk, bread"
```

I comandi di scrittura come Traduci, Riassumi e Converti in elenco ricevono il testo come argomento e rispondono senza aggiungere una chat alla cronologia. `enconvo agent main` risponde in una nuova chat quando l'agente è occupato nell'ultima.

Le route della Local API corrispondenti sono `agent/call` (`agentId`, `message`, `context_files`) e `ai-command/run` (`command_key`, `input_text`, `files`).

### Controllare le chat in corso

- `agent/session/list` elenca le chat in esecuzione in questo momento per ogni agente e Progetto, comprese le chat di Claude Code e Codex, con il titolo, l'agente e il Progetto di ciascuna. Passa `filter: "waiting"` per le chat in attesa della tua risposta, oppure `"active"` per entrambe.
- `agent/session/status` controlla una singola chat tramite il suo `sessionId`.
- `agent/session/steer` aggiunge un messaggio al turno che una chat sta eseguendo, senza interromperla. Una chat che non è in esecuzione risponde `not_running`; avvia invece un nuovo turno con `agent/call`. Un'esecuzione al di sotto di Accesso completo non può guidare un turno di Enconvo.

## Usarla in sicurezza

Per un client IA che ha bisogno solo del recupero dalla base di conoscenza, usa la connessione dedicata [Knowledge Base MCP](/it/advanced/knowledge-base-mcp) invece di esporre la Local API generale.

Considera la Local API e l'accesso alla shell come capacità potenti: i comandi possono leggere o modificare i dati locali in base alla loro implementazione. Mantieni gli script espliciti su comando, input e destinazione.

Le chiavi API salvate tornano come `[hidden]` quando un programma legge le impostazioni tramite la Local API, e solo le finestre di Enconvo possono cambiare dove viene inviata una chiave salvata. Vedi [Credenziali](/it/configuration/credentials).

Una scorciatoia da tastiera impostata tramite la Local API può usare nomi brevi dei modificatori (`cmd`, `ctrl`, `alt`, `opt`, `fn`) oppure i simboli dei modificatori. Una scorciatoia con una parola che Enconvo non conosce non viene registrata, e un tasto che digita richiede Comando, Controllo, Opzione o Funzione.

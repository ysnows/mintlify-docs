部分功能会先在测试版渠道推出。如果某篇指南介绍的内容在你的应用里没有，请检查你的[更新渠道](/zh/configuration/updates)。

## 随处问 AI

| 指南 | 可以帮你 |
| --- | --- |
| [SmartBar](/zh/features/smartbar) | 在任意应用中用一个快捷键向智能体提问或运行命令，并在输入时进行计算、换算或查询天气与航班。 |
| [聊天窗口](/zh/ai/chat) | 与智能体进行更长的对话，添加文件和上下文，用 /goal 让智能体持续朝着目标工作，在临时对话中提问，用增强提示词改写请求，并一次操作多个聊天。 |
| [空间](/zh/features/spaces) | 让智能体为你创建一个专属页面（如追踪器或实时看板），并将它保存在聊天窗口侧边栏和你的手机上。 |
| [灵动岛](/zh/features/dynamic-island) | 从屏幕顶部的紧凑面板向智能体提问、运行快捷键、在首页计算，以及跟进、批准或将运行中的任务标为已读。 |
| [PopBar](/zh/features/popbar) | 选中文字后，在出现于选中位置的工具栏中解释、翻译、修正、搜索或朗读它。 |
| [剪贴板历史、书签与文件搜索](/zh/features/clipboard-history) | 通过热键或 SmartBar 粘贴之前复制的内容、打开浏览器书签，或查找 Mac 上的文件。 |
| [应用侧边栏](/zh/features/app-sidebar) | 在你正在使用的应用或网站旁边的侧边栏中与智能体聊天，向应用中插入回复或提交信息，并对 Finder 文件执行文件处理任务。 |
| [桌面宠物](/zh/features/pet) | 在桌面上放一个动画伙伴，展示智能体正在做什么，并在点击时打开 Enconvo。 |
| [窗口管理](/zh/features/window-management) | 选择适合任务的 Enconvo 窗口，设置打开各个窗口的快捷键，让结果保持可见，并在关闭窗口后不让 Enconvo 显示在程序坞中。 |

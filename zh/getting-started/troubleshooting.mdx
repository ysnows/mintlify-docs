在下面找到你遇到的问题，按右栏的方法尝试修复。大多数问题都归结为服务提供商未连接、缺少 macOS 权限，或应用版本过旧。如果这里的办法都不管用，请[发送诊断信息](#发送诊断信息)并到 Discord 提问。

## 先试试这些

1. **退出并重新打开 Enconvo。** 在 Enconvo 菜单栏图标中选择 **退出**，然后从 **应用程序** 中打开 Enconvo。
2. **更新。** 在菜单栏图标中选择 **检查更新**，或在 **设置 → 通用 → 更新** 中点击 **检查更新**。
3. **检查模型。** 打开 **设置 → AI 模型**，确认你使用的服务提供商已连接。如果不确定，就登录你的 Enconvo 账户并使用 [Auto Route](/zh/providers/auto-route)。
4. **检查权限。** 打开 **设置 → 权限**，打开该功能需要的权限。参见[权限](/zh/configuration/permissions)。

## 回答与模型

| 问题 | 解决办法 |
| --- | --- |
| 没有回答，或出现与服务提供商有关的错误 | 在 **设置 → AI 模型** 中打开该服务提供商，点击 **验证**。如果是套餐登录，打开账户卡片的菜单，点击 **重新连接**。 |
| 出现与限额、配额或点数有关的错误 | 查看服务提供商的用量页面；如果用的是 Enconvo Cloud，查看 **设置 → 点数用量**。暂时换用另一个服务提供商。 |
| 所有云端服务提供商都失败 | 检查网络连接。如果使用代理，请在 **设置 → 通用** 的 **网络代理** 下勾选 **使用系统网络代理设置**。开启后，模型请求、网页读取和连接器都会经过系统代理，且代理变更无需重启 Enconvo 即可生效。你 Mac 和局域网内的服务器（如 LM Studio 和 Ollama）仍会直接连接。 |
| 某模型提示在你所在的国家或地区不可用 | 开启 **使用系统网络代理设置**，让 Enconvo 的请求通过你的代理发送。 |
| 回答很慢 | 换一个更小或更快的模型、少附加一些上下文，或降低推理强度。本地模型在输入较长时会变慢。 |
| 某个模型失败，其他模型正常 | 问题出在该模型或服务提供商。在聊天的模型选择器中换一个模型。 |
| Ollama 或 LM Studio 连接不上 | 确认服务器正在运行，且 **BaseUrl** 与它的地址一致，然后点击 **模型名称** 旁的 **刷新**。参见 [Ollama](/zh/providers/ollama) 或 [LM Studio](/zh/providers/lm-studio)。 |

## 快捷键与窗口

| 问题 | 解决办法 |
| --- | --- |
| 快捷键没有反应 | 可能有其他应用占用了相同的按键，例如 Spotlight、Raycast 或 Alfred。在 **设置 → 快捷键** 中修改其中一个。 |
| 更新后快捷键失效 | 退出并重新打开 Enconvo。如果还不行，在系统设置中为 Enconvo 关闭再打开辅助功能权限。 |
| 找不到应用 | 点击菜单栏或程序坞中的 Enconvo 图标，或按 **⌥Space** 打开 SmartBar。 |
| 你记得的 SmartBar 或聊天窗口快捷键没有反应 | SmartBar 的默认快捷键是 **⌥Space**，聊天窗口的默认快捷键是 **⌃⌘X**。请在 **设置 → 快捷键** 中查看。 |

## 选中的文字与屏幕

| 问题 | 解决办法 |
| --- | --- |
| PopBar 没有出现，或 Enconvo 读不到选中的文字 | 在 **系统设置 → 隐私与安全性 → 辅助功能** 中为 Enconvo 打开权限。如果已经打开，先关闭，等两秒再打开，然后重新打开 Enconvo。安全输入框和部分自定义编辑器不会共享其中的文字。 |
| 截图、OCR 或屏幕上下文失败 | 在 **系统设置 → 隐私与安全性 → 录屏与系统录音** 中打开 Enconvo，然后重新打开 Enconvo。 |
| 更新后权限已打开却不起作用 | 在系统设置的对应列表中用 **−** 移除 Enconvo，再重新添加，然后重新打开 Enconvo。 |
| 某项功能不再询问权限 | 你可能勾选了 **不再询问**。**设置 → 权限** 会显示每项权限的 **使用方** 列表，你可以在那里授权。 |

## 语音与音频

| 问题 | 解决办法 |
| --- | --- |
| 听写听不到声音 | 检查麦克风权限，以及 **设置 → 听写** 中选择的麦克风。 |
| 听写结果有误或很慢 | 在 **设置 → 听写模型** 中换一个语音模型。把人名和术语添加到 **设置 → 词典**。 |
| 朗读没有声音 | 检查 Mac 的音量和输出设备。在 **设置 → 文本转语音** 中试试 **系统**；它不需要密钥，也能离线使用。 |

更多内容参见[听写](/zh/features/dictation)和[语音识别](/zh/ai/speech-recognition)。

## 知识库

| 问题 | 解决办法 |
| --- | --- |
| 文档索引一直完不成 | 在 **设置 → 知识库** 中检查嵌入服务提供商，并确认文件类型受支持。 |
| 搜索什么都找不到 | 确认知识库已附加到聊天中。在知识库设置中降低分数阈值，或增加结果数量。 |
| 大型知识库很慢 | 按主题拆分成几个较小的知识库。 |

参见[知识库](/zh/ai/knowledge-base)和[知识库设置](/zh/advanced/knowledge-base-advanced)。

## 浏览器、应用与插件

| 问题 | 解决办法 |
| --- | --- |
| Enconvo 无法控制你的浏览器 | 在 **设置 → 使用浏览器** 中安装 Enconvo Companion 扩展，然后重启浏览器。参见[浏览器扩展](/zh/features/browser-extension)。 |
| 智能体无法使用你的应用 | 打开 **设置 → 电脑操作** 要求的权限。参见[电脑操作](/zh/features/computer-use)。 |
| 插件命令失败 | 打开 **设置 → 插件**，检查该插件的设置和凭据，并更新 Enconvo。 |
| 智能体的命令因权限错误而失败 | 可能是智能体的沙盒阻止了它。参见[智能体沙盒](/zh/configuration/sandbox)。 |

## 发送诊断信息

当 Enconvo 卡死、崩溃或反复出现异常时，请把诊断日志发送给 Enconvo 团队。在菜单栏图标中选择 **提交诊断信息…**，或打开 **设置 → 诊断**。在任何内容离开你的 Mac 之前，Enconvo 会移除文件名、电子邮件地址、密钥和提示词文本等个人信息，并向你展示实际发送的内容。参见[隐私与安全](/zh/configuration/privacy-security)。

- 查看[常见问题](/zh/faq)获取快速解答。

## 入门

<AccordionGroup>
  <Accordion title="Enconvo 支持哪些 Mac？">
    macOS 14 或更高版本，支持 Apple 芯片和 Intel 芯片。部分在设备端运行的功能（例如 [Local LLM (MLX)](/zh/providers/mlx)）需要 Apple 芯片。请参阅[安装](/zh/installation)。
  </Accordion>
  <Accordion title="我需要 API 密钥吗？">
    不需要。登录你的 Enconvo 账户后，[Enconvo Cloud](/zh/providers/enconvo) 无需密钥即可使用。你也可以用已经付费的订阅（例如 ChatGPT 或 Claude）登录，添加自己的 API 密钥，或者在 Mac 上运行模型。请参阅[服务提供商](/zh/providers/overview)。
  </Accordion>
  <Accordion title="为 Enconvo 付费和为 AI 付费有什么区别？">
    许可证用于解锁应用。AI 则在哪里运行就在哪里计费：Enconvo Cloud 点数、你的服务提供商账户，或者你自己的 Mac。请参阅[套餐与价格](/zh/pricing)。
  </Accordion>
  <Accordion title="我可以使用自己的语言使用 Enconvo 吗？">
    可以。在 **设置 → 通用 → 语言** 中的 **应用语言** 里，可以从十二种界面语言中任选一种，包括乌克兰语和俄语。智能体会使用你在同一位置设置的 **回复语言** 进行回答。请参阅[语言、外观与设置搜索](/zh/configuration/appearance-language)。
  </Accordion>
  <Accordion title="为什么在我使用某个功能时，Enconvo 会请求权限？">
    Enconvo 不会在启动时请求 macOS 权限。它只会在你第一次使用需要某项权限的功能时发起请求，并说明是哪个功能在请求。勾选 **不再询问** 可让该功能不再提示。请参阅[macOS 权限](/zh/configuration/permissions)。
  </Accordion>
  <Accordion title="文档中介绍的某个功能在我的应用里没有，为什么？">
    部分功能会先在测试版渠道推出。请检查你的版本和[更新渠道](/zh/configuration/updates)，然后在[功能目录](/zh/reference/feature-directory)中查找该功能。
  </Accordion>
</AccordionGroup>

## 模型

<AccordionGroup>
  <Accordion title="我应该使用哪个模型？">
    如果不确定，就保留 [Auto Route](/zh/providers/auto-route)：它会为每条消息挑选模型。如果想自己选择，请参阅[选择模型](/zh/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="我更改了默认模型，为什么聊天仍在使用旧模型？">
    聊天会一直使用它开始时的模型，直到你在该聊天中更改。项目和智能体也有各自的默认模型。请参阅[选择模型](/zh/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="使用本地模型就能完全离线吗？">
    只有在本地服务提供商上运行的步骤才会离线。网页搜索、远程 MCP 服务器、云端语音和云端嵌入仍会把数据发送到 Mac 之外。请参阅[本地模型](/zh/ai/local-llm)和[隐私与安全](/zh/configuration/privacy-security)。
  </Accordion>
</AccordionGroup>

## 语音

<AccordionGroup>
  <Accordion title="听写、语音命令和 Live Talk 有什么区别？">
    [听写](/zh/features/dictation)会把你说的话输入到你正在使用的应用中。语音命令会把你说的话作为请求发送给智能体。[Live Talk](/zh/features/live-voice) 则是与智能体进行的一来一回的语音对话。
  </Accordion>
  <Accordion title="Enconvo 能录制并转写会议吗？">
    可以。[会议录音](/zh/features/meeting-recording)会边录边转写，[语音转写](/zh/features/transcription)则适用于你已有的音频和视频文件。
  </Accordion>
</AccordionGroup>

## 上下文与知识

<AccordionGroup>
  <Accordion title="Appshots 和快速捕捉有什么区别？">
    [Appshots](/zh/features/appshots) 会把你正在查看的应用窗口附加到问题中。[快速捕捉](/zh/features/quick-capture)会把屏幕上的内容保存到知识库，供以后使用。
  </Accordion>
  <Accordion title="记忆和知识库有什么区别？">
    [记忆](/zh/ai/memory)保存智能体了解到的关于你的信息，并在之后重复使用。[知识库](/zh/ai/knowledge-base)保存你添加的文档，智能体会搜索这些文档来回答问题。两者都位于知识库中：栏顶部的 **知识库** / **记忆** 开关可以在两者之间切换。
  </Accordion>
  <Accordion title="其他 AI 应用能使用我的 Enconvo 知识库吗？">
    可以，通过 [Knowledge Base MCP](/zh/advanced/knowledge-base-mcp)。你需要手动开启它，并限定可访问的知识库。
  </Accordion>
</AccordionGroup>

## 智能体与自动化

<AccordionGroup>
  <Accordion title="智能体能使用其他应用和服务的工具吗？">
    可以，通过[插件](/zh/extensions/overview)、[技能](/zh/configuration/skills)和 [MCP 服务器](/zh/features/mcp)。在你允许的情况下，智能体还可以使用你的[浏览器](/zh/features/browser-control)和[应用](/zh/features/computer-use)。
  </Accordion>
  <Accordion title="我可以限制智能体的命令能够访问的内容吗？">
    可以。在智能体的 **权限** 标签中开启 **沙盒**，它的命令就只能修改工作目录和临时目录，并且无法读取你的密钥或控制其他应用。请参阅[智能体沙盒](/zh/configuration/sandbox)。
  </Accordion>
  <Accordion title="我不在的时候任务也能运行吗？">
    可以。只要 Enconvo 在运行且 Mac 处于唤醒状态，[自动化](/zh/workflows/scheduled-jobs)就会按计划运行。连接一个[即时通讯渠道](/zh/integrations/messaging)，即可在聊天应用中收到结果。
  </Accordion>
</AccordionGroup>

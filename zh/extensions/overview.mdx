插件为 Enconvo 添加命令、服务提供商、工具和 API 路由。打开 **设置 → 插件**，即可搜索插件目录、安装所需插件并管理已有插件。

## 查找并安装插件

<Steps>
  <Step title="打开插件页面">
    打开 **设置 → 插件**。按 **⌘K** 可直接跳到搜索框。
  </Step>
  <Step title="搜索">
    按任务需求或插件名称搜索。如果当前标签页没有匹配项，页面会提示其他标签页上的搜索结果。
  </Step>
  <Step title="打开插件页面">
    点击插件以查看其介绍、包含的功能以及所需的条件。
  </Step>
  <Step title="安装并配置">
    如果尚未安装，点击 **安装**。随后按要求添加服务提供商凭据或配置命令设置。
  </Step>
  <Step title="开始使用">
    点击 **立即体验**，从 SmartBar 运行其命令，或为需要使用它的智能体启用对应工具。
  </Step>
</Steps>

插件页面会列出它包含的命令及其设置。当你从 Enconvo 的其他位置打开某个命令的设置时，也会跳转到该插件内的对应命令。

当插件在聊天窗口中有专属视图时（例如[邮件](/zh/integrations/email)），它的页面上会有一个 **打开** 按钮，点击即可在聊天窗口中打开该视图，让添加邮箱等内部操作一步直达。包含多个视图的插件则会显示一个 **打开** 菜单。

## “插件”页面

| 标签页 | 显示内容 |
| --- | --- |
| **Enconvo** | 按分类浏览插件目录。顶部的 **已安装** 列出你已连接的连接器，以及你安装或创建的插件。**新上架** 显示新增条目。 |
| **内置** | Enconvo 自带的插件：**搜索** 存放你在 SmartBar 中搜索的列表，**控制** 存放电脑操作与使用浏览器。 |
| **Mac 应用** | 这台 Mac 上可供智能体使用的应用，例如日历、邮件和备忘录。连接应用会向 macOS 请求权限，而无需登录账号。参见 [Apple 应用](/zh/integrations/apple-ecosystem)。 |
| **PopBar** | 兼容 PopClip 的扩展，用于向 [PopBar](/zh/features/popbar) 添加按钮。 |
| **个人** | 你创建或导入的插件，以及你发布到 Enconvo 商店的插件。 |

要从目录以外引入插件，请使用 **创建插件** 或 **添加** 菜单：

| 选项 | 作用 |
| --- | --- |
| **创建插件** | 描述你的需求，智能体会为你编写、测试并安装该插件。 |
| **上传插件压缩包…** | 安装 `.enconvo` 文件，或 Claude Code / Codex 插件的 `.zip` 压缩包。 |
| **从 GitHub 添加…** | 从插件仓库，或 Claude Code / Codex 插件市场安装。 |
| **添加 MCP 服务器…** | 打开 [MCP 服务器](/zh/features/mcp)。 |
| **添加 PopBar 扩展…** 与 **从 PopClip 导入…** | 向 PopBar 添加 PopClip 扩展。 |
| **新建技能…** | 打开[技能](/zh/configuration/skills)。 |

## 找到合适的能力

| 任务 | 指南 |
| --- | --- |
| 润色或翻译文本 | [写作工具包](/zh/features/writing-tools)、[翻译](/zh/ai/translate) |
| 搜索并阅读网页 | [联网搜索](/zh/ai/web-search)、[读取网页](/zh/ai/web-fetch) |
| 处理文件或使用终端 | [文件工具](/zh/ai/file-tools)、[代码运行器](/zh/ai/code-runner) |
| 生成图片、视频或语音 | [服务提供商目录](/zh/providers/catalog) |
| 操作邮件、日历、备忘录或提醒事项 | [Apple 应用](/zh/integrations/apple-ecosystem) |
| 连接外部工具 | [MCP 服务器](/zh/features/mcp) |
| 添加可复用的智能体指令 | [技能](/zh/configuration/skills) |

商店中的部分插件会提供一整套服务工具与操作指引：

- **Shopify** 让智能体使用 Shopify 官方 CLI 管理你的 Shopify 商店，并在每次执行变更前向你展示改动内容。它支持同时跨多个商店操作。如果你未指定商店，智能体会询问你要操作哪一个；在展示的每项变更中都会注明商店名称；对于需要应用到多个商店的变更，则会按商店逐一运行。
- **Expo** 带来了 Expo 团队的官方技能和 Expo MCP Server，取代了旧版只读的 Expo 连接器。智能体可以构建、升级和发布 Expo 与 React Native 应用，读取你的 EAS 构建、日志、崩溃记录和审核信息，并仅在你逐项批准后才启动构建和提交。你之前完成过的 Expo 登录状态会自动保留。

**Obsidian**、**Tailscale** 和 **Cloudflare** 也属于插件商店插件：请从“插件”页面安装。你之前已经安装的版本会继续正常工作并自动更新。智能体从一开始就知道你已安装了 Obsidian、Tailscale、Cloudflare 和 Shopify 中的哪些插件。

[内置命令目录](/zh/extensions/built-in-extensions)列出了已编入文档的命令系列。商店条目以及你当前版本中已安装的插件可能与目录有所不同。

## 命令、服务提供商与工具

- **命令** 是由你触发运行的操作。
- **服务提供商** 提供某项能力，例如模型或语音。
- **工具** 是可供智能体调用的操作。

安装一个插件并不一定会将其服务提供商设为默认，也不一定会为所有智能体自动开启它的所有工具。

在 SmartBar 中，使用命令选择器（默认为 `@`）或直接搜索命令标题。`/` 操作菜单另有他用，它不是插件名称的前缀。

## 在一个连接器中使用多个账号

在你的 Mac 上登录的连接器（例如 Notion、Webflow 和 Linear）支持保存多个账号。

- 在连接器页面上，选择 **连接其他账号** 即可添加新账号。**已连接的账号** 会列出全部账号。
- 在智能体发信或创建内容时应使用的账号上选择 **设为默认**。智能体会从所有账号中读取信息。
- 在请求中直接指定账号，例如“用我的工作邮箱发送”，智能体就会使用该账号。
- **断开连接** 会移除单个账号；**断开所有账号的连接** 会移除全部账号。

在客户端的工作区中，每个连接器都会保留各自的默认账号，显示为 **默认账号** 后接工作区名称。除非你另行指定，智能体在该工作区中会使用该客户端对应的账号。

## 停用、更新或移除

在插件页面上：

- 开关用于启用或停用插件。停用期间，智能体无法找到或使用它，SmartBar 也不会列出它或允许你 `@` 它，但设置会被保留。
- **⋯** 菜单包含 **设置**、**检查更新** 和 **卸载**。Enconvo 自带的内置插件无法卸载。

卸载插件前，请先检查哪些智能体、工作流和自定义命令用到了它。重置命令会恢复其默认设置。重置共享的服务提供商还可能更改其他功能正在使用的凭据；参见[凭据](/zh/configuration/credentials)。

## 分享插件

你可以将自己制作的插件，或文件夹保存在这台 Mac 上的插件，通过链接分享给任何人安装。

1. 在插件页面上点击 **分享…**。如果 Enconvo 提示，请登录你的 Enconvo 账户。
2. 在 **谁可以安装** 下，选择 **知道链接的任何人** 或 **插件商店**。
3. 点击 **发布**，然后点击 **复制链接** 并发送链接。

Enconvo 会在链接生效安装前检查并审核每个版本，链接会打开该插件在 enconvo.com 上的页面。每位安装它的人都会获得一份自己的副本；插件内的数据、你的密钥以及你的登录状态都会留在你的 Mac 上。

要修改已分享的插件，请再次点击 **分享…**：你可以发送新版本、更改 **谁可以安装**，或点击 **停止分享**。停止分享后，链接会失效，已经安装过该插件的用户会保留他们已有的副本。如果审核未通过某个版本，**分享…** 会显示原因并提供 **在聊天中修复**。要分享[空间](/zh/features/spaces)，请参见[分享空间](/zh/features/spaces)。

## 自行开发插件

请参考[开发扩展](/zh/extensions/developing)中的 TypeScript SDK 和 CLI。CLI 将构建、安装、Schema 生成和发布归集在 `enconvo plugin` 下。发布后，你的插件就能在你自己的开发环境之外供他人使用。

Enconvo 也可以安装 Codex、Claude Code 和通用便携插件。参见 [Plugin Formats](/extensions/plugin-formats) 和[安装插件](/zh/extensions/installing-plugins)。

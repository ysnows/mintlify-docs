你的智能体不仅可以在这台 Mac 上工作。添加一台可以通过 SSH 登录的服务器，在聊天中提及它，然后像询问你自己的 Mac 一样提出要求：智能体会在那台服务器上运行命令，并把结果带回这里。服务器上无需安装任何东西。你运行着 Enconvo 的其他电脑也可以用同样的方式配对。

下面的视频演示了从你的 SSH 配置中添加一台 SSH 主机、让智能体读取上面的日志，以及查看谁可以访问这台 Mac。

## 开始之前

- 你需要一台能从这台 Mac 用 `ssh` 登录的服务器：可以是 `~/.ssh/config` 中的主机，也可以是能以 `user@host` 形式输入的地址。Enconvo 会使用这台 Mac 自己的 `ssh` 和密钥。如果服务器要求输入密码或口令短语，`ssh` 会通过 Enconvo 弹出询问，Enconvo 不会保存这些凭据。
- 对于局域网内的服务器，请在 **系统设置 → 隐私与安全性 → 本地网络** 中允许 Enconvo 访问。

## 连接页面中的列表

打开 **设置 → 连接**。其中包含三个列表：

| 列表 | 包含内容 |
| --- | --- |
| **手机** | 与这台 Mac 配对的 iPhone 和 Android 应用。参阅 [iPhone 应用](/zh/integrations/iphone-app)。 |
| **电脑** | 与这台 Mac 配对的、运行 Enconvo 的其他电脑。每台电脑只列出一次，并显示它的控制方式。点击 **配对电脑** 即可添加。参阅[你的其他电脑](/zh/integrations/other-computers)。 |
| **SSH 主机** | 智能体通过 SSH 访问的服务器，无需在服务器上安装任何软件。 |

点击一部手机或一台电脑可以打开它的专属页面，查看它在这台 Mac 上能执行的操作。

你也可以从聊天窗口添加主机、配对电脑或配对手机：点击侧边栏底部的设备切换器，然后点击 **添加设备**。

## 添加 SSH 主机

1. 打开 **设置 → 连接**，在 **SSH 主机** 下点击 **添加主机**。
2. 列表会显示你 `~/.ssh/config` 中的主机。选择一个（例如 `build-server`），或输入 `user@host`（或 `user@host:port`）。
3. 点击 **连接**。Enconvo 会测试连接：连通主机、检查主机密钥、登录并运行一条命令。
4. 在 **每条命令前** 下，选择智能体在那里运行命令前如何询问：
   - **跟随对话**：按照聊天当前的权限模式询问。参阅[批准操作](/zh/ai/agents)。
   - **每次询问**：运行每条命令前都询问。
5. 点击 **添加主机**。

该主机现在会显示在 **SSH 主机** 下，以及每个聊天的 `@` 菜单中。

Enconvo 首次看到一台服务器的主机密钥时，请向服务器管理员核对密钥，然后点击 **信任并连接**。在 Linux 服务器上，该弹窗还会提供 **同时在那里安装 Enconvo** 选项，用于将服务器配对为一台电脑。保持关闭即可不安装任何内容。

## 让智能体在主机上工作

1. 在聊天中输入 `@` 和主机名称的开头。你的电脑和 SSH 主机都会列在 **电脑** 分组下。
2. 选择该主机，它会以标签形式插入消息框。
3. 说明你想在那里完成什么任务，然后发送。例如：

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

智能体会通过 SSH 在主机上运行命令，并按你为该主机设置的方式先征求同意。每个命令步骤都会标明它运行在哪台主机上，回答则会回到当前聊天中。

要查看具体运行了什么，点击回答上方的 **处理了**。展开后即可看到每条命令。

你也可以用同样的方式提及一台已配对的电脑。智能体会把任务交给那台电脑自己的智能体，或者当那台电脑为这台 Mac 开启了终端权限时，直接在那里运行命令。

在聊天中，在主机或另一台电脑上运行的命令会显示 **已运行一条命令**，每个步骤都会标明对应的机器名称。

## 允许智能体在已配对的电脑上工作

在 **设置 → 连接** 中，点击 **电脑** 下的某台电脑打开它的页面。两个开关决定了这里的聊天中的智能体可以对它做什么：

| 开关 | 作用 |
| --- | --- |
| **智能体** | 将它的智能体添加到项目中，或把聊天交给它的某个智能体处理。任务会在那台电脑上运行，智能体想执行任何操作前都会先在那里询问你。 |
| **命令** | 这里聊天中的智能体可以在那台电脑上运行命令，并按照聊天当前的权限模式询问。 |

开关变灰表示对方电脑尚未允许该项操作：请在对方电脑上为这台 Mac 开启 **智能体** 或 **终端**。关闭 **命令** 也会一并禁止通过同一台电脑的 SSH 主机运行命令。

要允许另一台电脑的智能体直接使用这台 Mac 的屏幕和浏览器，请在这台 Mac 上打开该电脑的页面，并开启 **Agent 控制**。参阅[你的其他电脑](/zh/integrations/other-computers)。

## 更改主机设置

在 **SSH 主机** 下，点击一台主机打开它的页面：

| 设置 | 作用 |
| --- | --- |
| **智能体可以使用** | 关闭后主机仍保留在列表中，但不会出现在任何聊天里。 |
| **每条命令前** | **跟随对话** 或 **每次询问**。 |
| **复制文件** | 允许智能体使用 `scp` 与该主机互相复制文件。 |
| **起始目录** | 命令开始运行的文件夹。留空表示登录后的默认主目录。 |

页面右上角的 **⋯** 菜单包含 **测试连接** 和 **移除主机…**。移除主机只会让 Enconvo 忘记它，你的 `~/.ssh/config` 和服务器本身都不会受影响。

## 查看谁可以访问这台 Mac

**设置 → 连接** 中的 **谁可以访问这台 Mac** 会显示有多少部手机和电脑可以访问这台 Mac。

要立即切断所有连接，点击 **停止所有访问** 并确认。你的手机和其他电脑将无法再访问你的任何一台 Mac，它们在上面正在运行的任务也会停止。想恢复时，点击 **重新开启访问** 即可。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 测试无法连上局域网中的服务器 | macOS 正在等待“本地网络”权限。点击 **允许 Enconvo 访问本地网络**，或在 **系统设置 → 隐私与安全性 → 本地网络** 中开启 Enconvo，然后重试。 |
| 测试提示服务器拒绝了你的密钥 | 检查 `~/.ssh/config` 中该主机的 `IdentityFile` 设置，或用 `ssh-add` 添加密钥。 |
| 服务器返回了不同的主机密钥 | 服务器可能重装过，或者你与服务器之间存在中间设备。如果确实是重装过，请在终端运行 `ssh-keygen -R` 加上服务器地址移除旧密钥，然后重试。 |
| 主机没有出现在 `@` 菜单中 | 打开该主机的页面，开启 **智能体可以使用**。 |
| 密码或口令短语输入错误 | 输入框会再次打开并提示未通过。重新输入即可。 |
| 一台电脑对应了两个 SSH 主机 | 第一台主机会保持与该电脑的关联，并在其页面中显示。移除它之后，另一台就会自动关联。 |
| `~/.ssh/config` 中没有主机 | 在 **添加主机** 中直接输入 `user@host` 格式的地址。 |

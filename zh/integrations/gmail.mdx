title: "Gmail"
description: "只需连接一次 Gmail，智能体就能在任何聊天中搜索、阅读、整理和发送你的邮件。"
---

Gmail 连接器把你的电子邮件带进 Enconvo。让智能体查找重要邮件、总结邮件会话、起草回复或清理收件箱，它就会替你使用 Gmail。你只需通过 Enconvo 账户连接一次 Google 账户，无需设置 Google Cloud 项目或 API 密钥。

在这里连接的 Gmail 账户也会显示在[邮件](/zh/integrations/email)中，你可以直接在那里自己阅读、整理和回复邮件。

## 开始之前

在 **设置 → 账户** 中登录你的 Enconvo 账户。连接器在所有套餐中都免费，但需要一个 Enconvo 账户。

## 连接 Gmail

<Steps>
  <Step title="找到 Gmail">
    打开 **设置 → 插件**，在 **Enconvo** 标签页中搜索 **Gmail**，点击它打开详情页。
  </Step>
  <Step title="连接">
    点击**连接**，浏览器会打开 Google 登录页面。
  </Step>
  <Step title="允许访问">
    选择你的 Google 账户，在允许之前查看它请求的访问权限。Google 的授权页面会显示 Composio，它是 Enconvo 的集成合作伙伴。
  </Step>
  <Step title="检查结果">
    回到 Enconvo 后，你的邮箱地址会显示在**账户**下。点击**立即体验**，或先问智能体一个只读的问题，例如“总结一下我收件箱里今天的未读邮件”。
  </Step>
</Steps>

如果你在连接 Gmail 之前就向智能体询问邮件，聊天中会显示一张卡片引导你连接。

## 智能体能做什么

| 方面 | 智能体能做什么 |
| --- | --- |
| 阅读 | 搜索邮件，打开邮件和邮件会话，下载附件，列出标签和草稿 |
| 整理 | 添加和移除标签，归档，将邮件移到垃圾箱并恢复 |
| 撰写 | 创建并发送草稿，发送新邮件、回复和转发 |

搜索使用 Gmail 自己的搜索语法，例如 `from:john@example.com`、`subject:invoice` 或 `after:2024/01/01`。

智能体撰写或发送邮件时，可以设置收件人、抄送和密送，撰写纯文本或 HTML 正文，在已有的邮件会话中回复，并附上你 Mac 上的文件：最多 10 个文件，每个最大 95 MB。超出单封邮件容量（合计 25 MB）的文件会改为 file.enconvo.com 上的下载链接发送，任何拿到链接的人都可以下载该文件。

<Warning>
智能体可以直接发送邮件，不会事先询问。如果你想先检查，请让它先写草稿。Enconvo 从不永久删除邮件，删除只会把邮件移到垃圾箱。
</Warning>

## 选项

连接账户后，这些选项会出现在 Gmail 的详情页中。

| 选项 | 作用 |
| --- | --- |
| **在所有聊天中可用** | 打开：智能体可以在每个对话中使用 Gmail。关闭：只有当你用 `@` 提及它，或某个 Profile 包含它时，智能体才会使用。 |
| **邮件提醒** | 重要邮件到达时，在灵动岛和你的手机上提醒你。该功能默认关闭，直到你在 **自动化 → 重要邮件** 中开启，它的 **手机** 开关会把提醒发送到已配对的 iPhone 或 Android 手机。开启前 Enconvo 会先询问你，因为每封新邮件的发件人、主题和开头部分会发送到 Enconvo Cloud 来判断其重要程度。邮件从不存储在那里。 |
| **连接其他账户** | 添加另一个 Gmail 地址，最多 5 个。 |

连接多个账户时，智能体会从所有账户中读取邮件；发送或创建邮件时使用默认账户，除非你指定另一个，例如“用我的工作邮箱发送”。在某个账户的菜单中选择**设为默认**即可更改默认账户。

## 在聊天中使用 Gmail

连接 Gmail 后，直接说出你的需求，智能体会选用合适的 Gmail 工具。

**搜索并总结：**
```
"Find all emails from John in the last week and summarize them"
```

**起草回复：**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**清理收件箱：**
```
"Archive all newsletters from the past month"
```

**管理标签：**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**清除旧邮件（移到垃圾箱）：**
```
"Delete all promotional emails older than 6 months"
```

## 工作流创意

Gmail 也可以用在[工作流](/zh/workflows/introduction)和[定时任务](/zh/workflows/scheduled-jobs)中：

| 创意 | 作用 |
| --- | --- |
| **每日邮件摘要** | 搜索未读邮件并总结，生成一份晨间简报 |
| **自动分类** | 搜索新邮件，并根据内容添加标签 |
| **跟进提醒** | 找出等待回复的邮件并创建提醒事项 |
| **生成报告** | 搜索符合条件的邮件，并汇总成一份报告 |

## 隐私

- **经由 Enconvo Cloud 和 Composio**：你的邮件只为完成你的请求而经过 Enconvo Cloud 和 Composio，不会被存储。
- **密码只留在 Google**：你在 Google 自己的页面上登录，因此 Enconvo 从不会看到你的 Google 密码。
- **按需读取**：只有任务需要时，智能体才会读取 Gmail。唯一的例外是**邮件提醒**：开启后，它会在每封新邮件到达时进行检查。
- **可随时撤销**：在 Gmail 的详情页点击**断开连接**，即可在你所有设备上移除访问权限。你也可以在 [Google 账户权限](https://myaccount.google.com/permissions)中移除访问权限。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **连接**按钮显示为灰色 | 先在 **设置 → 账户** 中登录你的 Enconvo 账户。 |
| Gmail 显示**重新连接** | 访问权限已过期。点击**重新连接**，再次登录 Google。 |
| 智能体没有使用 Gmail | 检查 Gmail 是否已连接。如果**在所有聊天中可用**已关闭，请在聊天中用 `@` 提及 Gmail。 |
| 搜索没有结果 | 先试一个更简单的查询，例如 `from:john`，并确认邮件在已连接的账户中。Gmail 搜索的用法与 Gmail 网站上相同。 |
| 附件发不出去 | 检查文件路径是否正确，以及文件是否存在于你的 Mac 上。 |

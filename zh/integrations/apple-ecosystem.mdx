title: "Apple 应用"
description: "让智能体操作你 Mac 上的日历、提醒事项、通讯录、备忘录、邮件、信息、音乐和地图。"
---

智能体可以操作你 Mac 自带的应用：查看日程、添加提醒事项、查询电话号码、保存备忘录、整理邮件以及发送 iMessage 信息。你只需要用日常语言提出要求，智能体就会代你操作对应的应用。

每个应用都是 **设置 → 插件** 的 **Mac 应用** 标签页中的一个插件。连接应用会向 macOS 请求权限，而无需登录账号。Enconvo 只在智能体需要时才会读取应用内容，后台不会进行任何同步。读取到的内容会发送给你为该聊天选择的 AI 模型。

## 连接应用

<Steps>
  <Step title="打开 Mac 应用">
    打开 **设置 → 插件**，然后点击 **Mac 应用** 标签页。
  </Step>
  <Step title="连接该应用">
    点击目标应用，再点击 **连接**。阅读连接说明后，点击 **继续**。
  </Step>
  <Step title="允许访问">
    macOS 会询问是否允许 Enconvo 使用该应用，请点击允许。对于某些应用，Enconvo 会在后台先打开该应用，以便 macOS 弹出授权提示。
  </Step>
  <Step title="立即体验">
    此时该应用会显示 **已在这台 Mac 上连接**。点击 **立即体验**，或用下方示例中的话向智能体提问。
  </Step>
</Steps>

## 智能体可以做什么

| 应用 | 智能体可以做什么 | macOS 权限 |
| --- | --- | --- |
| 日历 | 读取在“日历”中已配置的所有账户下、任意日期范围内的日历和日程。添加日程，修改时间、地点和备注，以及删除日程。 | **日历** |
| 提醒事项 | 逐个列表读取你的列表，以及尚未完成或已完成的提醒事项。添加提醒事项，修改其截止日期和备注，标记为已完成或未完成，移动到其他列表，以及删除。 | **提醒事项** |
| 通讯录 | 按姓名、电话号码或电子邮件地址查找联系人，并分页读取你的通讯录。智能体无法修改你的联系人。 | **自动化**，以及 **通讯录** |
| 备忘录 | 搜索和读取备忘录及其文件夹和附件。添加备忘录、追加或改写内容、在文件夹间移动以及删除。已加锁的备忘录仍保持锁定。 | **自动化** |
| 邮件 | 搜索“邮件”中所有已配置账户的邮箱，读取邮件及其附件。撰写草稿、发送、回复、转发，以及移动、标记或删除邮件。 | **自动化** |
| 信息 | 读取未读信息和对话历史，包括群聊以及美国以外地区的号码。立即发送 iMessage 信息，或将其设为你可以查看或取消的一次性[自动化](/zh/workflows/scheduled-jobs)稍后发送。 | **自动化**，读取历史还需要 **完全磁盘访问权限** |
| 音乐 | 播放资料库或 Apple Music 目录中的歌曲、专辑、艺人和播放列表。暂停、跳过、调节音量、随机播放、重复播放，并查看正在播放的内容。 | **自动化** |

**Mac 应用** 标签页中还有 Spotify，连接方式相同。它需要你 Mac 上装有 Spotify 应用并已登录你的账户。

<Warning>
智能体可以在不提前询问的情况下修改和删除日程、提醒事项、备忘录和邮件，以及发送邮件。如果你想先审核内容，请让它先给出计划或草稿。在“信息”中发送消息前，智能体会向你确认收件人和消息内容。
</Warning>

## 断开应用连接

在 **Mac 应用** 标签页中打开该应用并点击 **断开连接**，即可在 Enconvo 中关闭它。如果想同时撤回 macOS 系统权限，请前往 **系统设置 → 隐私与安全性**，在上表列出的对应权限下关闭 Enconvo。

## 按应用列举的示例

### 邮件

邮件支持你在“邮件”应用中配置的所有账户，包括 iCloud、Gmail、Outlook 和 Exchange。智能体还可以管理邮箱、开启或关闭邮件规则、保存附件以及统计未读邮件数。

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### 提醒事项

一条提醒事项可以包含截止日期和时间、备注、优先级（无、低、中或高）、重复规则，以及在你到达或离开时触发的地点条件。重复规则可以是每天、每周、每月或每年，每隔一个或多个周期（例如每 2 周），并可设置结束日期。

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### 日历

日程可以是全天日程，可以包含地点、备注和链接，设置开始前若干分钟的提醒闹钟，将你的状态设为忙碌、空闲、暂定或无空，并可按每天、每周、每月或每年重复，直到指定结束日期或重复指定次数。删除重复日程时，智能体可以删除全部重复出现项。

**基本日程：**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**全天日程：**
```
"Block off next Friday as a personal day"
```

**重复日程：**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**提醒闹钟：**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**多个日历：**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 通讯录

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### 信息

信息可以向电话号码、电子邮件地址或群聊发送 iMessage 信息。信息应用必须登录你的 Apple 账户，才能通过 iMessage 发送。当信息应用将某条消息标记为 **未送达** 时，智能体会如实告诉你，而不会说已发送。

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### 备忘录

智能体还可以读取你在“备忘录”中当前选中的那条笔记，非常适合用于“总结这条笔记”或“翻译这条笔记”等请求。

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### 地图

智能体会打开 Apple 地图来搜索地点、显示驾车、步行或公共交通路线、放置大头针以及创建指南。结果会显示在“地图”应用中，而不是显示在聊天里。要将地点保存为收藏或添加到指南中，智能体会先为你打开它，再由你在“地图”中完成最后一步。

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### 快捷指令

智能体不会直接运行快捷指令。想从 Enconvo 运行某条快捷指令，请在 **设置 → 快捷操作** 中为某个快捷操作添加 **运行快捷指令** 步骤。

## 权限

每个应用都会使用各自对应的 macOS 权限（见上表）：

- 日历和提醒事项使用 **系统设置 → 隐私与安全性** 中的 **日历** 和 **提醒事项** 列表。
- 通讯录、备忘录、邮件、信息和音乐使用 **自动化**，macOS 会询问是否允许 Enconvo 控制每个应用。通讯录还会额外请求访问你的联系人。
- 信息会将你的对话历史保存在受保护的文件中，因此读取历史需要为 Enconvo 开启 **完全磁盘访问权限**。

如果你拒绝了某个权限提示，对应应用就无法与 Enconvo 配合工作。对于日历、提醒事项和通讯录，在 **Mac 应用** 标签页中重新连接该应用，可以让 macOS 再次向你弹出授权请求。当 macOS 拦截某个已连接的应用时，它在 **Mac 应用** 标签页的对应行会显示 **打开设置**，点击即可直达对应的系统开关。你之后也可以随时在 **系统设置 → 隐私与安全性** 中修改这些权限。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 邮件无法使用 | 确认“邮件”应用中至少已添加一个邮箱账户，并检查 **系统设置 → 隐私与安全性 → 自动化** 中“邮件”下的 Enconvo 开关已打开。 |
| 日历访问被拒绝 | 在 **系统设置 → 隐私与安全性 → 日历** 中，确认已列出 Enconvo 并处于开启状态。允许后请重启 Enconvo。 |
| 看不到提醒事项 | 检查 **系统设置 → 隐私与安全性 → 提醒事项** 中 Enconvo 是否已获得访问权限，并确认提醒事项在“提醒事项”应用中正常显示。 |
| 信息无法读取历史记录 | 在 **系统设置 → 隐私与安全性** 中为 Enconvo 开启 **完全磁盘访问权限**。 |
| 已连接的应用显示 **打开设置** | macOS 正在拦截 Enconvo。点击 **打开设置** 并启用 Enconvo。 |

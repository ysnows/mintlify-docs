即时通讯渠道让其他人可以通过 Telegram 或 Discord 与 Enconvo 智能体对话。每个渠道都是一个绑定到某个智能体的机器人：收到的消息会交给该智能体，由它撰写回复。一个智能体可以服务多个渠道，但每个渠道最多只服务一个智能体。在 **设置 → 即时通讯渠道** 中进行设置。

下面的视频会在介绍虚拟形象和凭据管理之间，演示如何设置 Telegram 渠道。

## 开始之前

- 在对应平台上创建机器人，并复制它的 Bot Token（参见下文的 [Telegram](#telegram) 和 [Discord](#discord)）。
- 机器人监听消息期间，请保持 Enconvo 运行、Mac 联网。

<Note>
免费套餐同一时间只能运行一个即时通讯机器人。Enconvo Cloud 套餐或终身许可证可以运行更多。参见[套餐与价格](/zh/pricing)。
</Note>

## 添加渠道

<Steps>
  <Step title="添加渠道">
    打开 **设置 → 即时通讯渠道**，点击**添加新频道**，然后选择 **Telegram** 或 **Discord**。
  </Step>
  <Step title="命名">
    给渠道起一个你能认出来的名称。
  </Step>
  <Step title="粘贴 Bot Token">
    把平台提供的 Bot Token 粘贴到 **Bot Token** 中。
  </Step>
  <Step title="选择智能体">
    在**绑定智能体**中，选择负责处理收到的消息的智能体。
  </Step>
  <Step title="开启渠道">
    检查谁可以使用这个机器人（Telegram 在**访问控制**中设置），然后打开**启用频道**。
  </Step>
  <Step title="测试">
    点击**检查连接**，确认渠道显示**已连接**。然后用一个已获允许的账户发送一条测试消息。
  </Step>
</Steps>

机器人能回答什么，取决于所绑定智能体的模型和工具。

## Telegram

用 Telegram 的 **BotFather** 创建机器人，并复制它的 Bot Token。在开启渠道之前，先打开它的**访问控制**：

| 控制项 | 作用 |
| --- | --- |
| **政策** | **需要配对**（默认）：新用户需要提供配对码，并等待你批准。**开放（所有人）**：任何找到这个机器人的人都可以使用它。 |
| **待处理的请求** | 对每个申请配对的用户选择**批准**或**拒绝**。只批准你确实想让其使用的人。 |
| **允许的用户** | 你已批准的用户。**移除**会把某个用户从列表中删去，对方需要重新配对才能使用机器人。 |

如果机器人在私聊中正常，在群组中却不工作，除了渠道的访问政策外，还要检查 Telegram 的机器人隐私设置和群组权限。仅有 Token 并不能让机器人访问所有对话。

## Discord

在 Discord Developer Portal 中创建一个应用和一个机器人。把机器人邀请到你的服务器，并授予它接收和发送你所需消息必须的权限和 Intents。把它的 Bot Token 粘贴到 Discord 渠道中，并绑定一个智能体。

如果已连接却没有回复，请检查 Discord 上该频道的权限，以及机器人是否能接收这类消息。请把机器人限制在你指定的服务器和频道内。

## 会话与回复

每个传入的对话都会与绑定的智能体建立各自独立的聊天会话。回复只在对应的对话中进行，已连接的用户不会共用同一份聊天记录。更改绑定的智能体会重启渠道，之后的消息会交给新的智能体。

在聊天中输入机器人命令可以直接控制对话，而不会把消息发给智能体：`/new` 开启新的聊天会话，`/stop` 停止正在进行的回复，包括在它之前刚发送的消息。机器人命令适用于 Telegram 和 Discord，附带附件发送的命令同样会作为命令运行。

对于公开机器人或团队机器人，请使用一个专门的智能体，并为它配置合适的指令和工具。在让其他人使用它之前，先检查它能使用哪些工具。

## 定时发送

[自动化](/zh/workflows/scheduled-jobs)可以把结果发送到你设置好的即时通讯聊天中。发送目标请自行选择，并通过任务的运行历史区分是运行失败还是发送失败。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 已断开连接 | 检查 Bot Token、网络、**启用频道**是否已打开，以及 Enconvo 是否在运行。连接无响应的 Discord 机器人会自动重新连接。 |
| 已连接但没有回复 | 检查绑定的智能体、智能体的模型服务提供商、平台权限和配对政策。 |
| 机器人的回答不对 | 检查绑定智能体的指令、工具和模型。 |
| Telegram 用户无法连接 | 在**待处理的请求**中查找对方的配对请求，并检查**允许的用户**。 |
| 第二个机器人无法启动 | 免费套餐同一时间只能运行一个即时通讯机器人。请关闭另一个机器人，或升级套餐。 |
| 退出 Enconvo 后不再回复 | 机器人通过你 Mac 上的 Enconvo 监听消息，因此应用必须保持运行。 |

即时通讯渠道只支持设置 Telegram 和 Discord。如果你通过其他插件或 MCP 服务器连接 Slack 或飞书，请参照该集成自己的指南。

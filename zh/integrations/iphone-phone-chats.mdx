---

手机聊天是 iPhone 应用自己的聊天。它们在手机上运行，而不是在 Mac 上，因此不需要配对 Mac 也能使用。每个手机聊天会通过 Enconvo Cloud 点数、你自己的 API 密钥，或你在 iPhone 上登录的套餐来使用模型。手机聊天和个人指令会通过你的 Enconvo 账户同步。

如果要继续在 Mac 上运行的聊天，请参阅 [iPhone 应用](/zh/integrations/iphone-app)。

## 选择默认模型

1. 在 iPhone 上打开 **设置 → AI 模型**。
2. 轻点**默认模型**并选择一个模型。新聊天会使用它开始。
3. 要更改某个聊天的模型，请在该聊天中使用模型选择器。

如果 Mac 上配置了相同的服务提供商，Mac 上的 Enconvo 也会以同一模型开始。如果 Mac 上的模型在 iPhone 上不可用，页面会在**默认模型**下方说明，并建议你需要添加或登录什么。

## 添加密钥或服务提供商

**AI 模型**列出了 Enconvo Cloud 以及你可以在手机上使用的所有服务提供商，包括 PipeLLM。

1. 轻点一个服务提供商，然后轻点**添加 API 密钥**，粘贴你在服务提供商网站上创建的密钥。
2. 要添加不在列表中的服务提供商，请轻点**添加提供商**，然后选择一个服务提供商、**兼容 OpenAI** 或**兼容 Anthropic**。兼容类服务提供商需要一个服务器地址，该服务器需支持 OpenAI 的 Chat Completions 或 Responses API，或 Anthropic 的 Messages API。
3. 如果某个服务提供商没有列出你需要的模型，请在它的页面上轻点**按 ID 添加模型**。

密钥保存在你的 iCloud 钥匙串中，只会发送给对应的服务提供商。

## 使用套餐登录

有五个服务提供商允许手机聊天使用你已经付费的套餐，无需 API 密钥，也不消耗 Cloud 点数：

| 服务提供商 | 套餐 | 按钮 |
| --- | --- | --- |
| OpenAI | ChatGPT | **使用 ChatGPT 登录** |
| xAI | Grok | **使用 Grok 登录** |
| Mistral | Le Chat | **使用 Mistral 登录** |
| GitHub Copilot | Copilot | **使用 GitHub 登录** |
| Antigravity | Antigravity（Google） | **使用 Google 登录** |

<Steps>
  <Step title="打开服务提供商">
    在 **设置 → AI 模型** 中轻点该服务提供商。对于 OpenAI、xAI 和 Mistral，请在**身份验证**下选择套餐卡片。另一张卡片是 **API 密钥**，**使用中**标出手机聊天当前使用的是哪一个。
  </Step>
  <Step title="登录">
    轻点登录按钮，在打开的页面上完成登录。请使用拥有该套餐的账户。
  </Step>
  <Step title="检查结果">
    回到服务提供商的页面，你会看到你的套餐、账户，以及套餐包含多少个模型。选择一个模型，或轻点**设为默认**，让新聊天使用它开始。
  </Step>
</Steps>

套餐登录只保存在这部 iPhone 上。它不会同步到 iCloud 或你的 Mac，Mac 会保留自己的登录。套餐本身的用量限制同样适用。

### GitHub Copilot

轻点**使用 GitHub 登录**后，应用会显示一个 GitHub 代码。**继续**会复制该代码并打开 GitHub 的页面，你在那里粘贴代码并授权 Enconvo。GitHub 页面打开期间，代码会一直显示在屏幕上，方便你再次复制。

模型列表只显示你的 Copilot 套餐可以使用的模型。Copilot Free 提供的模型比付费套餐少。

### Antigravity

每次登录前，应用都会显示**登录 Antigravity 之前**。Enconvo 使用 Antigravity 应用自己的 Google 客户端登录，如果 Google 发现 Antigravity 账户在 Antigravity 之外被使用，可能会暂停该账户。请使用一个即使丢失也无妨的账户。**同意**会继续进入 Google 登录，**取消**则保持一切不变。

Antigravity 提供你套餐中的 Gemini 和 Claude 模型，每个模型都带有 Antigravity 为其提供的推理强度级别。

### ChatGPT 用量

OpenAI 的页面会显示你的 ChatGPT 套餐在 5 小时和每周限额中还剩多少、每项限额何时重置，以及套餐何时续订。在账户菜单中轻点**刷新用量**即可更新。限额用完时，页面会一直提示，直到限额重置。

### 退出登录

打开服务提供商，在账户菜单中选择**退出登录**。退出后，使用该套餐的聊天需要换用其他模型。对于 Mistral，登录时创建的密钥会保留在你的 Mistral 工作区中。

## 离开应用后继续回复

使用 Enconvo Cloud 模型时，即使你离开应用或锁屏，回复也能继续进行。在消息框的 **云端工具** 中开启 **在云端运行**。使用你自己的密钥的聊天始终在手机本地作答。

## 在电脑上继续

将手机聊天移到已配对的电脑上，即可在那里使用该电脑的智能体、文件和工具继续对话。即使回复仍在生成中也可以这样做。

1. 打开聊天菜单，或在侧边栏中长按该聊天，选择 **在电脑上继续**。菜单会写明默认转移到的电脑。
2. 选择电脑和智能体，然后确认。

聊天会转移到该电脑并在那里继续。打开分享的聊天链接时也会询问要在哪台设备上继续。

## 通过操作按钮发起语音聊天

通过操作按钮发起语音聊天时，灵动岛会询问 **要让 Enconvo 看屏幕吗？** 选择 **只说话**，或选择 **看屏幕** 让 Enconvo 看到你正在阅读的内容。通话控制栏中的 **看屏幕** 按钮可以在通话中途开启或关闭屏幕共享。

## 推理强度

当你选择一个会思考的模型时，选择器会接着展示它的推理强度。你为某个模型选择的强度会显示在聊天标题栏中的服务提供商旁边，并适用于所有使用该模型的聊天。套餐页面只列出你的套餐提供的级别。

## 长聊天

当一个长聊天接近模型的上下文窗口时，同一模型会总结较早的消息，与 Mac 上的做法相同。聊天会保留每条消息，并用**上下文已压缩**标记总结开始的位置。此功能始终开启。

## 故障排除

| 你看到的情况 | 解决方法 |
| --- | --- |
| **ChatGPT 登录未完成**（或 Grok、Mistral、GitHub Copilot、Antigravity） | 轻点**重新登录**，在打开的页面上完成登录。 |
| 提示某个模型**你的套餐不提供** | 从套餐的列表中选择其他模型。Copilot Free 只提供部分模型。 |
| **正在列出模型…**一直不结束 | 检查 iPhone 的网络连接，然后离开服务提供商的页面再重新打开。 |
| Mac 的默认模型在 iPhone 上不可用 | 按照**默认模型**下方提示的建议，添加该服务提供商的密钥，或登录它的套餐。 |

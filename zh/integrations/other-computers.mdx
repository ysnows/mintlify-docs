---
title: "你的其他电脑"
description: "将运行 Enconvo 的电脑配对，然后从一台电脑使用另一台电脑的聊天、终端、屏幕和智能体，工作会在对方电脑上持续运行。"
---

将两台运行 Enconvo 的电脑配对后，你就可以从其中一台操作另一台。你在已配对电脑上发起的聊天会在那台电脑上运行，使用它的文件、密钥、模型和智能体，即使你切走去做别的事，任务也会继续运行。你还可以查看或控制它的屏幕、向它发送文件，并让当前电脑上的智能体把工作交给它处理。

要连接没有运行 Enconvo 的服务器，请改用添加 SSH 主机的方式。参见[电脑与 SSH 主机](/zh/integrations/computers-and-ssh-hosts)。

## 开始之前

- 在两台电脑上都安装 Enconvo，并登录同一个 Enconvo 账户。
- 保持两台电脑都在线且 Enconvo 处于运行状态。只有对方电脑上运行着 Enconvo 时才能连接它。
- 在免费方案中，你可以将一台电脑与另一台配对。账户的设备席位留在其中一台上：你可以从另一台操作这台电脑，而在它上面可以查看另一台电脑的聊天并向其发送文件。

## 配对电脑

配对时会明确显示哪台电脑负责控制、哪台被控制。你可以从任意一端发起配对。

<Steps>
  <Step title="开始配对">
    点按聊天窗口侧边栏底部的设备切换器，然后选择 **添加设备 → 配对电脑**。或者打开 **设置 → 连接**，在 **电脑** 下点按 **配对电脑**。
  </Step>
  <Step title="选择要控制的电脑">
    你的其他在线电脑会显示在列表中。选择你想从当前电脑控制的那一台，并选择它允许访问的内容。如果想双向控制，也可以同时开启允许对方反过来控制这台电脑的选项。
  </Step>
  <Step title="在另一台电脑上允许">
    另一台电脑的灵动岛会显示带有数字的配对请求。确认两台电脑显示的数字一致，然后点按 **允许**。
  </Step>
  <Step title="设置打开方式">
    简短的使用引导会询问这台电脑是在聊天窗口中打开还是在独立窗口中打开，并提供一个可从任意应用呼出它的快捷键，同时介绍你可以在它上面做什么。你可以随时从该电脑的 **⋯** 菜单 → **使用指南** 重新打开这个引导。
  </Step>
</Steps>

当两台电脑无法互相发现时，请使用 **通过链接配对**：在你想控制的电脑上复制链接，然后粘贴到你当前使用的电脑上。链接仅限使用一次，有效期为 5 分钟。

当另一台电脑与你的电脑配对后，界面上的提示会说明它能在这里使用哪些功能。点按 **更改** 即可调整。

## 选择电脑可访问的范围

在你允许配对时，以及之后在 **设置 → 连接** 中该电脑的页面上，都可以选择另一台电脑能在这里控制哪些内容：

| 选项 | 另一台电脑可以在这里做什么 |
| --- | --- |
| **聊天** | 在这里打开聊天并让它们持续运行。 |
| **对话和工具** | 还可以使用 **终端**、**屏幕** 和 **文件**，让它的智能体可以在这里运行命令。 |
| **全部** | 它的智能体还可以在这里发起聊天并使用这个屏幕。 |

选择 **每个开关** 可以逐项单独设置：

| 开关 | 允许的内容 |
| --- | --- |
| **聊天** | 在这里打开聊天并让它们持续运行。 |
| **终端** | 打开 Shell，并允许它的智能体运行命令。 |
| **屏幕** | 查看此屏幕并进行控制。 |
| **文件** | 将文件发送到这里的“下载”文件夹。 |
| **智能体** | 允许它的智能体在这里发起聊天。默认关闭，直到你手动开启。 |
| **Agent 控制** | 允许它的智能体直接使用此屏幕和浏览器。使用时会显示提示，你也可以随时停止。默认关闭，直到你手动开启。 |

## 打开另一台电脑的聊天

聊天窗口侧边栏一次只列出某一台电脑的内容。底部的设备切换器可以在本机与已配对电脑之间切换，显示其他电脑上有哪些等待你处理的事项，也可以在独立窗口中打开其中任意一台。

- 每台电脑的列表都会显示它的聊天和项目，包括正在运行的内容和需要你处理的事项，并可就地打开。
- 每台电脑都有自己的颜色。可以在该电脑的 **⋯** 菜单 → **颜色** 中修改。
- 由另一台电脑的智能体发起的聊天会带有标记，聊天窗口的搜索也能找到那台电脑的聊天。
- 当另一台电脑上的回复已就绪，或它的智能体需要你回答时，Enconvo 会通知你。

要在另一台电脑上发起新聊天，请使用新聊天输入框中的 **运行于** 标签。你已经输入的内容会一并带过去。按 **⌃1** 到 **⌃9** 可以在电脑之间切换。

另一台电脑上的演示文稿、设计和仪表盘会以只读方式打开，且另一台电脑的聊天中不提供 **朗读** 功能。

### 在独立窗口中打开

在该电脑的 **⋯** 菜单中选择 **在独立窗口中打开**，它的聊天就会在一个带有对应颜色程序坞图标的独立窗口中打开。同一菜单中的 **在程序坞中保留** 可以把该图标留在程序坞中，方便日后直接打开。

要将其设为默认行为，请打开 **设置 → 连接**，点按该电脑，在 **聊天** 下选择 **聊天窗口** 或 **独立窗口**。**快捷键** 用于设置从任意应用呼出该电脑的按键。

### 当电脑离线时

离线电脑的聊天记录仍然可以阅读。点按 **在这台 Mac 上继续**，即可带着屏幕上当前的内容在这里发起一个新聊天；或选择 **恢复时通知我**。

## 使用对方的屏幕

电脑页面会显示它的屏幕画面。你可以只观看，也可以接管控制，用自己的鼠标和键盘来操作它。

点按全屏按钮，或按 **⌃⌥F**（在 Mac 上也可以用 **⌃⌘F**），即可让画面铺满整个显示器。将指针移到屏幕顶部边缘即可重新显示控制栏。按同样的快捷键即可退出全屏，仅观看时也可以按 **Esc** 退出。旁边的 **填满视图** 按钮会将画面缩放以铺满视图、不留黑边，并裁切超出视图的部分边缘。

当你控制另一台电脑时，对方复制的内容会同步到你的剪贴板。屏幕上的一行提示会告诉你如何停止控制。

## 发送文件

在该电脑的页面上，点按 **发送文件**。文件会保存到另一台电脑的 **下载 → Enconvo** 中，绝不会覆盖已有文件，且在连接中断后支持断点续传。

你在另一台电脑的聊天中附加的文件也会一并传输过去，单个文件上限为 2 GB，并带有进度条。

## 把工作交给另一台电脑

为某台电脑开启 **智能体** 后，你这里的智能体就可以在那里发起聊天并读取回答。在聊天中用 `@` 提及该电脑，或让智能体使用它即可。智能体想在那边执行任何操作时，都会先在那台电脑上征求你的同意，并且聊天中会显示对方电脑正在等待批准以及批准的具体内容。

开启 **Agent 控制** 后，另一台电脑上的智能体可以直接使用这台 Mac 的屏幕和浏览器，例如立即重新测试某项改动。屏幕上的浮层会标明当前由谁在控制，并让你可以随时接管或停止它。

当你的智能体在使用另一台电脑时，聊天顶部的一条横栏和输入框上方的一个胶囊按钮会显示对方的最新截图，并附带 **停止** 按钮。运行结束后，整个过程会汇总为一张卡片，展示其中的步骤和截图。

关于在另一台电脑上运行命令，参见[电脑与 SSH 主机](/zh/integrations/computers-and-ssh-hosts)。

## 移除电脑

在 **设置 → 连接** 中，点按该电脑并选择 **移除**，或在侧边栏中打开它的 **⋯** 菜单选择 **取消配对…**。它的聊天会保留在那台电脑上。如需再次使用，重新配对即可。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 配对列表中没有另一台电脑 | 检查对方是否在线、正在运行 Enconvo，且登录了同一个账户。或者改用 **通过链接配对**。 |
| 另一台电脑上没有出现配对请求 | 查看另一台电脑的灵动岛。如果它已退出或断开了连接，请重新发起配对。 |
| 电脑页面上的某个开关是灰色的 | 对方电脑尚未允许该权限。请在对方电脑上为本机开启该开关。 |
| 屏幕或聊天提示无法连接到该电脑 | 检查对方电脑是否处于唤醒状态且正在运行 Enconvo。使用 **恢复时通知我** 可在它上线时收到提醒。 |

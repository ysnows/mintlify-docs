---
title: "与手机配对"
description: "将 Enconvo iPhone 或 Android 应用与 Mac、Windows 电脑、Linux 桌面设备或只有终端的 Linux 服务器配对。"
---

手机上的 Enconvo 应用可以与你的每一台电脑配对，这样它们的项目和聊天就会显示在手机上。你从手机上打开的聊天会继续在那台电脑上运行，使用那台电脑上的文件、应用和智能体。手机通过 Enconvo 中继与电脑通信，消息全程端到端加密。当手机和电脑处于同一网络时，应用会直接连接电脑，因此在家里或办公室里连接和响应会更快。

每台电脑都需要单独与手机配对。把两台电脑互相配对（例如把 Linux 笔记本和 Mac 配对）并不会把它们任何一台添加到手机上：你想在手机上使用哪台电脑，就把它与手机配对。

## 开始之前

- **获取应用。** iPhone：[TestFlight](https://testflight.apple.com/join/MJQuEN28)。Android：Google Play 或 APK 安装包。电脑上 **设置 → 连接** 中的 **获取手机 App** 提供了两者的下载二维码；Mobile Companion 插件中的 **获取手机 App** 按钮也会打开它。
- **使用同一个账户。** 在手机应用和电脑上登录同一个 Enconvo 账户。只有登录你本人账户的手机才能配对。免费账户同样可以配对，并在手机上使用电脑的聊天和远程屏幕。
- **保持电脑开机并运行 Enconvo。** 手机只能在电脑运行 Enconvo 时连接到它。

## Mac、Windows 或 Linux 桌面设备

三者的配对步骤相同。

<Steps>
  <Step title="在电脑上显示配对码">
    点击侧边栏底部的设备切换器，然后选择 **添加设备 → 配对手机**。或者打开 **设置 → 连接**，选择 **显示配对码**。屏幕上会出现一个二维码，它是一次性的，有效期为五分钟。
  </Step>
  <Step title="用手机扫描">
    在 Enconvo 应用中打开 **远程**，轻点 **配对电脑**，然后把摄像头对准二维码。你也可以用 iPhone 相机、Android 相机或 Google Lens 扫描：二维码会唤起 Enconvo，你在应用里确认连接那台电脑即可。如果手机尚未安装应用，二维码里的链接会引导你先安装再配对。
  </Step>
  <Step title="在手机上使用电脑">
    手机片刻即可配对成功并显示这台电脑。配对了多台电脑时，可在 **远程** 中切换。
  </Step>
</Steps>

如果配对码过期了，选择 **显示新代码** 后重新扫描即可。

## 只有终端的 Linux 服务器

服务器没有图形窗口来展示二维码，因此改由命令行输出。这需要 Enconvo 2.5.15 Beta 1 或更高版本。请先按照[在服务器上安装](/zh/getting-started/linux)完成安装。

<Steps>
  <Step title="登录服务器">
    ```bash
    enconvo login
    ```
    在 `enconvo.com/device` 上确认并批准它输出的代码。
  </Step>
  <Step title="保持 Enconvo 运行">
    ```bash
    enconvo service install
    ```
    手机只能在服务器运行 Enconvo 时连接到它。
  </Step>
  <Step title="输出配对码">
    ```bash
    enconvo companion pair --phone
    ```
    命令会在终端中画出一个二维码，并在下方附上链接和过期时间。该配对码只能使用一次，有效期为五分钟。
  </Step>
  <Step title="扫码或打开链接">
    用手机摄像头扫描二维码，或在手机上打开该链接。在 Enconvo 应用中确认后，这台服务器就会出现在手机上。
  </Step>
</Steps>

- **通过 SSH**：二维码会直接画在你自己的终端里，因此通过 SSH 也能正常使用。如果二维码发生折行，拉宽终端窗口或直接打开下方链接即可。
- **登录凭证**：在你自己的终端中直接运行该命令时，生成的配对码还会顺便登录手机应用，因此请只发给自己的手机。如果是通过管道、保存输出或由智能体运行的命令，则只会输出不带登录凭证的链接：此时请先在手机应用上登录同一账户。
- **已过期**：重新运行 `enconvo companion pair --phone` 即可。

## 管理已配对的手机

每台电脑上的 **设置 → 连接** 都会列出已与它配对的手机。

| 操作 | 方法 |
|---|---|
| 再配对一部手机 | 显示新的配对码并用那部手机扫描。每台电脑最多可配对 10 部手机。 |
| 重命名手机 | 点击该手机，然后点击名称旁的 **重命名手机**。 |
| 移除手机 | 选择该手机旁的 **移除**。那部手机将无法再连接这台电脑。 |
| 重新开始 | 选择 **重置连接**。所有手机都会被移除，需要重新配对。 |

## 故障排除

| 问题 | 解决方法 |
|---|---|
| 手机上看不到某台电脑 | 请将手机直接与那台电脑配对。把它配对到另一台电脑并不会添加这台电脑。 |
| **此代码已过期** | 显示新代码，或重新运行命令，并在五分钟内完成扫描。 |
| **登录后即可配对手机** | 在电脑上登录 Enconvo。在服务器上请运行 `enconvo login`。 |
| 服务器提示尚未登录 | 运行 `enconvo login`，然后再重新运行 `enconvo companion pair --phone`。 |
| 手机显示服务器离线 | 检查服务器上的 Enconvo 是否正在运行：`enconvo service install`；如果退出登录即停止运行，请执行 `sudo loginctl enable-linger "$USER"`。 |

title: "iPhone 应用"
description: "将 Enconvo iPhone 应用与你的 Mac 配对，在手机上继续 Mac 上的聊天。"
---

Enconvo iPhone 应用与你的 Mac 配对后，Mac 上的项目和聊天就会出现在手机上。你从手机上打开的每个聊天仍在 Mac 上运行，可以使用 Mac 上的文件、应用和智能体。本指南从头到尾演示如何配对手机：登录、在 Mac 上显示配对码，然后用 iPhone 扫描。

<Note>
iPhone 应用目前处于测试阶段。请从 [TestFlight](https://testflight.apple.com/join/MJQuEN28) 安装，或在 Mac 上 **设置 → 连接** 的 **获取手机 App** 下扫描 TestFlight 二维码。配对要求 Mac 上的 Enconvo 为 2.5.6 beta 或更高版本。TestFlight 上的 iPhone 应用和 Google Play 上的 Android 应用在美洲、欧洲、中东、日本、韩国和东南亚提供。Android APK 在任何地区都可以安装。
</Note>

## 配对你的 iPhone

如果要配对 Windows PC、Linux 桌面电脑或只有终端的 Linux 服务器，请参阅[与手机配对](/zh/integrations/pair-your-phone)。

<Steps>
  <Step title="在 iPhone 上登录">
    安装 iPhone 应用，并登录与 Mac 相同的 Enconvo 账户：可通过 Apple、Google 或发送到你邮箱的 6 位验证码登录。只有登录了你账户的手机才能与它配对。免费账户也能配对，并使用 Mac 上的聊天、远程屏幕和虚拟形象。
  </Step>
  <Step title="显示配对码">
    在 Mac 上打开 **设置 → 连接**，选择 **显示配对码**。二维码的有效期为五分钟。如果过期，请选择 **显示新代码**。
  </Step>
  <Step title="用 iPhone 扫描">
    在手机上打开 **远程**，轻点 **配对电脑**，然后将摄像头对准 Mac 上的配对码。也可以直接用 iPhone 相机扫描：它会打开 Enconvo，你在应用中确认这台 Mac 即可。片刻即可完成配对。手机通过 Enconvo 中继连接到 Mac，消息全程端到端加密。
  </Step>
  <Step title="手机上的 Mac">
    当 Mac 在“远程”中显示为 **在线** 后，它的项目和聊天就会出现在你的手机上。
  </Step>
  <Step title="打开任意聊天">
    打开任意聊天，从上次停下的地方继续。聊天仍在 Mac 上运行，因此可以使用那台 Mac 上的文件、应用和智能体。
  </Step>
  <Step title="保持可连接">
    在 **连接**（或 **设置 → 保持唤醒**）中，打开 **防止这台 Mac 进入睡眠**。它会阻止 Mac 进入睡眠（使用电池时也一样），让手机始终能连接到它。你还可以让屏幕保持常亮、在设定时间后关闭屏幕，或在合上盖子时保持 Mac 唤醒（此项需要输入一次管理员密码）。
  </Step>
  <Step title="移除手机">
    手机丢了？在 **连接 → 已配对的手机** 中，选择它旁边的 **移除**。那部手机将无法再连接你的 Mac。如果要重新使用它，请用新的配对码重新配对。
  </Step>
</Steps>

如果 Mac 在配对码下方注明，扫描该码还会让 iPhone 登录你的 Enconvo 账户。这种配对码只能用你自己的 iPhone 扫描。

## 在手机上能做什么

配对后，你可以：

- 浏览 Mac 上的项目和聊天，并继续任意聊天。
- 回答智能体在 Mac 上工作时提出的问题。
- 在聊天完成时收到通知，并可直接从通知中回复。
- 使用 **远程屏幕** 查看并控制你的 Mac 屏幕。
- 在手机本地与 AI 模型聊天，使用 Enconvo Cloud 点数、你自己的 API 密钥，或你登录的套餐（ChatGPT、Grok、Le Chat、GitHub Copilot 或 Antigravity）。参见[手机聊天](/zh/integrations/iphone-phone-chats)。
- 与好友和队友聊天、通话，并加入视频会议。参见[手机上的通话与好友](/zh/integrations/phone-calls-and-friends)。

该应用将已配对的 Mac、Windows PC 或 Linux 电脑统称为你的 **电脑**。除非某个章节另有说明，否则 Android 应用的工作方式相同。

## 处理电脑上的聊天

来自电脑的聊天在手机上的外观与行为都和电脑上一致，同样支持后台任务、子代理和任务引导。

- **首页** 会在消息框正上方显示你当前活跃的聊天。向上轻扫卡片的抓手，或轻点 **全部**，即可按“等待你处理”、“运行中”和“已有结果”分组查看所有活跃聊天。
- 侧边栏的 **活跃** 分组会汇集正在等你回复、失败、仍在运行或有未读结果的聊天。蓝色圆点表示有尚未阅读的结果，旋转圆环表示聊天正在运行。**置顶** 和 **最近** 可以折叠。
- 当回复正在运行时发送的内容会引导正在执行的任务，效果与在 Mac 上按 Return 相同。此时输入框会显示“引导运行中的任务…”。
- 轻点子代理可在聊天上方的弹出面板中查看其步骤。它会打开在最新一步，并持续跟随新输出。向下轻扫即可关闭。
- 审批提问会提供智能体自己的选项，与在 Mac 上一致。
- 要更换聊天使用的智能体，轻点聊天标题下方的智能体名称。**从这里创建分支** 可让你为分支聊天选择智能体。
- 模型选择面板会显示你订阅的套餐、5 小时和每周限额的剩余额度及重置时间，以及各模型在自己行上显示的限额。
- 可以从照片图库附加照片和视频。视频会按原样发送到电脑。
- 在应用的 **设置 → 虚拟形象** 中，可以选择消息框上的通话按钮显示虚拟形象还是语音条图标。

当你的电脑离线或仍在重连时，你依然可以发送消息：手机会自行回答它能处理的内容（例如提问和网页查询），并在电脑连上后再发送需要电脑处理的请求。

手机无法打开的文档或链接会提示你在电脑上打开。

## 使用电脑屏幕

轻点 **首页** 右上角的显示器图标，或在聊天菜单中选择 **远程屏幕**，即可查看并控制电脑的屏幕。

| 模式 | 触控操作的效果 |
| --- | --- |
| **触控板** | 在任意位置滑动以移动指针，轻点以在指针所在位置点击。使用过程中会有提示教你手势。 |
| **触控** | 直接轻点你想点击的位置。 |
| **仅观看** | 不进行任何操作：仅观看屏幕。 |

模式按钮上会显示当前模式的名称。双指捏合即可缩放；在 **触控板** 模式下，画面会围绕指针放大并跟随指针移动。

要在做其他事情时让屏幕保持浮窗显示，请轻点左上角的画中画按钮，或双指捏合缩小。屏幕会浮在聊天上方，离开 Enconvo 时也会浮在其他应用上方。

在 Live Talk 通话期间，**远程屏幕** 工具会在通话上方以小浮窗形式打开屏幕。它的操作方式与触控板一致，带有用于切换到 **触控** 或 **仅观看** 的模式标签、用于在电脑上打字的键盘按钮，以及用于打开常规视图的 **全屏** 按钮。

## 通知

- 已完成回复的通知会显示回复的开头内容。使用通知上的 **回复**，即可无需打开应用直接回复。
- 当应用处于打开状态，或你正在使用 Mac 时，不会收到通知，除非那条消息是你从手机发出的。
- 当你在某一台设备上阅读了已完成的聊天后，该通知会从你的其他设备上消失。仍在等待回答的提问会保留。
- 在 Android 14 及更高版本上，如果系统关闭了 **全屏通知**，请在应用的设置中将其打开。

## 分享到 Enconvo

从其他应用把网页、照片或文件分享到 Enconvo 时，**发送给** 面板会让你选择新建聊天或任意最近聊天。在面板中或应用的设置里开启 **始终分享到新聊天**，即可跳过这一询问。

## 项目与工件

- 打开项目的 **Ideas** 和 **看板**、更改项目设置、发起 **新建项目**，并在工作计划卡片上进行操作：回答、合并、启动或重试任务、打开 Pull Request，或记下并启动一个想法。
- `@` 菜单会列出项目成员、工作流以及可以加入的智能体。
- 演示文稿、数据看板和动画影片可以从聊天或工件库中打开，并在其中评论、向 @Enconvo 提问、分享、导出和演示。

## Android 应用

Android 应用的配对与使用方式相同。可使用 Google 或发送到你邮箱的 6 位验证码登录。消息输入框集中在同一行，配有相机按钮、用于电脑、项目和 **技能** 的快捷标签，以及包含最近照片和视频的加号面板。

从 enconvo.com 下载的 Android 应用每次打开时都会检查更新。**跳过此版本** 会在新版本发布前隐藏当前版本提示；**稍后** 会在你下次打开应用前隐藏提示。

## 管理已配对的手机

**设置 → 连接** 会列出所有已配对的手机，并显示手机当前能否连接到这台 Mac。

| 任务 | 方法 |
| --- | --- |
| 配对另一部手机 | 选择 **配对另一部手机** 并扫描新的配对码。一台 Mac 最多可配对 10 部手机。 |
| 重命名手机 | 点按该手机，然后点按其名称旁的 **重命名手机**。 |
| 移除手机 | 在 **已配对的手机** 中选择它旁边的 **移除**。 |
| 重新开始 | 选择 **重置连接**。Enconvo 会创建新的连接密钥并移除所有已配对的手机，之后每部手机都需要扫描新的配对码。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 手机连不上 Mac | 确认 Mac 处于唤醒状态、已登录且已联网，并且 **连接** 中显示为 **在线**。打开 **防止这台 Mac 进入睡眠**，让它保持可连接。 |
| 手机提示 Mac 拒绝了消息、屏幕或终端 | Mac 尚未为其开启设备访问权限。按照手机上显示的步骤操作。 |
| 配对码显示 **此代码已过期** | 选择 **显示新代码**，并在五分钟内重新扫描。 |
| Mac 显示 **登录后即可配对手机** | 点击 **登录** 并在 Mac 上登录。iPhone 和 Mac 需要使用同一个 Enconvo 账户。 |
| Mac 提示它 **需要新的连接密钥** | 中继服务器上保存的这台 Mac 的密钥与本机不同，例如你从备份恢复了这台 Mac。选择 **重置连接**，然后重新配对每部手机。 |
| **已关闭 Companion 访问权限** | 你的某台设备关闭了访问权限，在你选择 **重新开启访问** 之前，任何手机都无法连接你的 Mac。 |

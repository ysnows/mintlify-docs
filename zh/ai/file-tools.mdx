title: "文件与文件夹"
description: "让智能体查找、阅读和编辑 Mac 上的文件。"

文件工具让智能体可以查找文件、搜索文件内容、阅读并编辑文件。把智能体指向某个文件夹或文件，用平常的话提问即可；它会选择合适的工具，并告诉你它用了哪些工具。

## 开始之前

- **工作文件夹：** 智能体设置中 **定义** 部分的 **工作文件夹** 是相对路径的起点。
- **批准：** 聊天中的 **权限** 标签决定智能体何时先征求你的同意。选择 **请求批准** 时，它在编辑工作文件夹以外的文件前会先询问。阅读和搜索从不询问。参阅[批准操作](/zh/ai/agents)。

## 从只读任务开始

1. 在智能体的设置中，检查它的文件工具和 **工作文件夹**。
2. 在聊天中，说出一个文件夹，或附上你要使用的文件。
3. 提一个范围明确的问题，例如“找出这个项目里的 Markdown 文件，并总结 README。”
4. 在让它修改任何内容之前，先看看智能体用到了哪些文件和工具输出。

## 各工具的作用

| 工具 | 作用 |
| --- | --- |
| Glob | 按路径模式查找文件，例如 `**/*.md`，最新的排在前面 |
| Grep | 搜索文件中的文字，支持文件模式，并返回行号 |
| Read File | 阅读文本文件、提取文档中的文字，并能读取图片、音频和视频 |
| Edit File | 替换文件中的指定文字，并报告修改了哪些行 |
| Write File | 创建文件，或替换文件的全部内容 |

<Warning>
Write File 可能会在没有任何警告的情况下覆盖现有文件。重要文档请保留副本或使用版本控制，并在批准前检查目标位置和修改内容。智能体在聊天中修改的文件会列在侧边面板的 **更改** 标签页中，并提供 **撤销**。
</Warning>

## 文档与媒体

阅读 PDF、Office 文档、图片、音频或视频时，可能会进行解析、OCR 或转写，而不是返回原始字节。对于音频和视频，智能体读取的是转录文本。在电子表格中，公式单元格会读取其计算结果，如果从未计算过，则读取公式本身。支持哪些格式取决于已安装的工具和你设置的服务提供商。参阅 [OCR](/zh/ai/ocr)、[语音转写](/zh/features/transcription)和[知识库](/zh/ai/knowledge-base)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 出现访问错误 | 检查智能体的 **工作文件夹**、**权限** 标签以及 macOS 权限 |
| 文档读出来是空的 | 检查文件类型以及它能否被解析。扫描版 PDF 可能需要 OCR |
| 编辑时找不到要替换的文字 | 让智能体在编辑前重新读取当前文件 |

记忆保存智能体在各个聊天间保留的简短事实，例如你的偏好、关于你的信息，以及你做过的决定。所有智能体共享同一份记忆，并在每个聊天开始时看到它们，置顶的记忆排在最前面。记忆不同于聊天记录，也不同于存放文档的[知识库](/zh/ai/knowledge-base)。

这段视频介绍了记忆、“关于你”、知识库以及快速捕捉。

你的记忆位于[知识库](/zh/ai/knowledge-base)内。在聊天窗口中，点按侧边栏里的 **知识库**，并使用该栏顶部的 **知识库** / **记忆** 开关即可查看。记忆不会列在你的知识库列表中，指向记忆的链接会在知识库中打开记忆。

**设置 → 记忆** 的顶部显示了 **智能体可调用的内容**：你的记忆、聊天记录、录音和知识库，以及各自的数量。

## 记忆如何保存

智能体在了解你的过程中保存记忆。打开 **自动从聊天中学习** 后，Enconvo 会在聊天安静下来时回顾这段聊天：最后一条消息三分钟后，或累积了六条新消息时。它会保留对之后的聊天有用的内容，**设置 → 记忆** 中的 **最近学到的** 会列出每项更改，并提供 **撤销**。

学习会跳过机密信息、群聊和一次性任务。记忆不会用于即时通讯群聊，因为其他人也会看到回复。

要自己添加一条，打开 **设置 → 记忆**，点按 **打开记忆**，然后选择 **添加 → 记忆**。

## 查看和编辑记忆

1. 打开 **设置 → 记忆** 并点按 **打开记忆**，或在聊天窗口中将知识库切换为 **记忆**。
2. 使用 **筛选**、**标签** 和 **类型** 缩小列表范围，或在 **网格**、**列表** 和 **地图** 之间切换。
3. 打开一条记忆，查看它的内容以及它是从哪个聊天中学到的。
4. 编辑不准确或过时的事实，或在确认后将其删除。
5. 要让某条记忆在每个聊天中都对智能体可见，右键点按它并选择 **置顶**。

记忆条目应简洁、客观，并明确说明涉及的人或事。

## 概念与地图

在 **打开记忆** 中选择 **地图**，可以看到记忆按其涉及的人物、项目、地点和主题分组显示。每一个这样的分组就是一个概念。

1. 点按一个概念，查看它的概览、所属记忆和相关概念。
2. 点按 **就此提问**，开始一个关于它的聊天。
3. 要归档仍在等待的记忆，点按显示等待数量的 **File … now** 按钮。**重建** 会重新归档每一条记忆：概念保留名称，关联重新建立，空的概念会被移除。
4. **移除概念** 会移除该概念及其关联，其中的记忆会保留。

记忆整理会在后台把新增和修改过的记忆归档到概念下。当你就某个概念提问时，智能体会完整阅读它；当你在聊天中更正某个概念时，它们会重命名或移除它。召回还能找到归档在你提到的人物、项目或主题下的记忆，即使它们的措辞和你的问题不同。

## 设置

打开 **设置 → 记忆**。

| 设置 | 作用 |
| --- | --- |
| **记忆**（顶部开关） | 为所有智能体开启或关闭记忆。关闭时不会学习、整理或召回任何内容，你的记忆会保留到你重新开启时。 |
| **自动从聊天中学习** | 保存关于你的事实、你的偏好以及你喜欢的做事方式。**最近学到的** 列出它保留的内容，并提供 **撤销**。 |
| **整理记忆** | 在 Mac 空闲时合并重复项，在两条相互矛盾的记忆中保留较新的一条，更新已过日期的计划，并置顶智能体绝不能遗漏的内容。每次更改都会保留之前的版本。 |
| **频率** | **每天** 或 **每周** 整理一次。**立即整理** 会马上运行。 |
| **更早的整理** | 撤销整理在过去 90 天内做出的任何更改。 |
| **学习操作方法** | 让技能像记忆学习事实那样，学习你喜欢的任务完成方式。每次更改都会在聊天中显示 **撤销**，记忆审查和记忆整理也会照顾到技能。参阅[让技能学习你的工作方式](/zh/configuration/skills)。 |
| **召回** | 当回复需要用到你说过或保存过的内容时，智能体查找的范围：**记忆**（始终开启）、**聊天记录**、**录音** 和 **知识库**。 |
| **搜索** | 为记忆、聊天、录音和知识库建立索引的嵌入模型：**这台 Mac** 或 **Enconvo Cloud**。 |
| **记忆模型** | 学习和整理所用的轻量模型，在其服务提供商处按普通请求计费。 |

## 关于你

要向所有智能体介绍你自己，请打开 **设置 → 关于你**。你的所有智能体、语音通话和虚拟形象都会使用这些信息。

| 字段 | 用途 |
| --- | --- |
| **首选称呼** | 你的名字或昵称，让智能体知道如何称呼你。 |
| **个人简介** | 关于你和你工作的简短介绍。只添加你希望用于个性化回复的内容。 |
| **回复语言** | 智能体回答所使用的语言。要为单个智能体指定其他语言，请在其设置的 **行为** 下更改 **回复语言**。 |

## 有意识地使用记忆

如果某个智能体在自己的设置中关闭了 **Enable Memory**（启用记忆），它就不会使用记忆。要测试某个事实是否会被重新使用，请开始一个新聊天，提一个需要用到它的普通问题，而不要想当然地认为它已被保存或召回。

不要为了省去重复输入而存储凭据或敏感信息。根据智能体和服务提供商的设置，模型请求中可能会包含召回的记忆。

## 记忆、知识与捕捉

| 内容 | 最佳位置 |
| --- | --- |
| 可反复使用的简短偏好或事实 | 记忆 |
| 文档和参考资料 | [知识库](/zh/ai/knowledge-base) |
| 一个随口说出的想法 | [语音笔记](/zh/features/voice-notes) |
| 其他应用中可见的内容 | [快速捕捉](/zh/features/quick-capture) |
| 临时的讨论 | [聊天](/zh/ai/chat) |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 回答用到了过时的事实 | 在 **打开记忆** 中找到这条记忆并更正或删除它，而不只是更正某一条回复。同时检查当前对话的上下文。 |
| 智能体什么都不记得 | 确认 **设置 → 记忆** 中的 **记忆** 已开启，并且该智能体的 **Enable Memory** 已打开。即时通讯群聊从不使用记忆。 |
| Enconvo 保存了你不想保存的内容 | 在 **设置 → 记忆** 的 **最近学到的** 中点按 **撤销**。 |
| 整理改动了你想保留的记忆 | 在 **设置 → 记忆** 中打开 **更早的整理**，撤销该更改。 |

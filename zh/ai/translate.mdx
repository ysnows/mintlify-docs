---
title: "翻译"
description: "翻译你选中的文字、屏幕的某个区域，或你口述的内容。"
---

Enconvo 用 **Translator** 翻译你选中的文字，用 **Screenshot Translate** 翻译屏幕上的文字，并在你听写时翻译你说的话。它们都属于[写作工具](/zh/features/writing-tools)，并使用你的 AI 模型运行。

## 翻译选中的文字

1. 在任意应用中选中一段文字。
2. 在 PopBar 中点按 **翻译**，或打开 SmartBar 运行 **Translator**。
3. 阅读译文，然后点按 **粘贴** 替换原文，或复制译文。

## 选择语言

打开 **设置 → AI 命令**，在 **内置** 下选择 **Translator**，然后在 **语言** 部分设置语言。

| 设置 | 作用 |
| --- | --- |
| **目标语言** | Translator 输出的语言。除源语言以外的任何语言的文字都会译成它。**自动** 使用你的回复语言（**设置 → 关于你**）；如果回复语言也是自动，则使用 Mac 的系统语言 |
| **源语言** | 与目标语言配对的语言：已经是目标语言的文字会被译成它。**自动** 使用你的回复语言；如果回复语言就是目标语言，则使用英语 |

例如，目标语言设为英语、源语言设为中文时，中文或法语文字会译成英语，英语文字则会译成中文。

## 选择翻译风格

在 **设置 → AI 命令** 中打开 Translator 页面，其中的 **翻译风格** 可设置译文的表达方式。Screenshot Translate 也会使用这项设置。修改会在输入时自动保存。

| 风格 | 译文效果 |
| --- | --- |
| **标准** | 准确且贴近原文 |
| **地道自然** | 自由改写，宛如母语者撰写 |
| **自定义** | 遵循你在输入框中描述的风格 |

听写有单独的 **翻译风格** 设置，用于处理口述内容。

## 翻译屏幕的某个区域

1. 在 SmartBar 中运行 **Screenshot Translate**。
2. 拖动鼠标，框选你要翻译的区域。
3. 译文会显示在灵动岛中。点按它可以打开聊天，在那里就截图和译文继续提问。

Screenshot Translate 会把该区域作为图片发送给 Translator 的模型。如果想先用你的 OCR 服务提供商识别文字，再翻译这些文字，请在 **设置 → 插件 → 写作工具 → Screenshot Translate** 中打开 **Need OCR**。此时 OCR 的识别错误可能会改变含义，请把结果与屏幕内容对照。设置服务提供商请参阅 [OCR](/zh/ai/ocr)。

| 设置 | 作用 |
| --- | --- |
| **Need OCR** | 翻译前先用你的 OCR 服务提供商识别文字。默认关闭 |
| **Follow-up Command** | 用来回答你在译文之后发送的消息的命令 |
| **Clear After Closing** | 关闭译文 10 秒后，把灵动岛恢复为空输入框，除非你已经回复过 |

## 边说边翻译

听写时，在听写的 **清理** 选项中选择 **翻译**，Enconvo 就会用你的回复语言输入你说的话；如果你说的已经是回复语言，则用英语输入。这个选项就是 **Dictation Translate** 命令，它会在识别出的文字插入之前对其进行处理。参阅[听写](/zh/features/dictation)。

如需实时翻译字幕，请在[实时字幕](/zh/features/live-captioning)中选择支持实时翻译的语音服务提供商。

## 保持术语一致

Translator 使用 **设置 → AI 命令 → 全部命令** 中设置的模型。如果想用另一个模型，请在 Translator 的页面上修改 **AI 模型**。

对于经常使用的术语，可以在 Translator 的页面上点按 **自定义**，或编写一条[智能体](/zh/ai/agents)指令，并加入术语表。说明哪些内容必须保持原样，例如名称、技术标识符或引用的段落。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 译文的语言不对 | 检查 Translator 的 **目标语言** 和 **源语言**，以及任何 **完成后操作** |
| 译文听起来太生硬或太随意 | 在 Translator 页面中更改 **翻译风格** |
| 译文缺少部分文字 | 对于选中的文字，检查辅助功能权限。对于打开了 **Need OCR** 的 Screenshot Translate，检查 OCR 识别出的内容 |
| Screenshot Translate 什么都没截到 | 在[权限](/zh/configuration/permissions)中检查屏幕录制权限 |

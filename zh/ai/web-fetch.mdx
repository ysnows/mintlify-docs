---
title: "获取网页"
description: "让智能体根据 URL 阅读网页，或把网页保存到知识库。"
---

当你已经有一个 URL，并希望智能体阅读该网页时，就使用获取网页。每个智能体都能阅读你给它的链接；由哪个服务来获取由你选择。如果需要先找到相关网页，请使用[网页搜索](/zh/ai/web-search)。

## 选择服务提供商

1. 打开 **设置 → 获取网页**。
2. 选择一个服务提供商，然后点按 **设为默认**。

| 服务提供商 | 用途 |
| --- | --- |
| **Local Fetch** | 在你的 Mac 上免费获取网页，可选用浏览器辅助获取 |
| **Jina AI Link Reader** | 通过 Jina 获取可读内容 |
| **Firecrawl Link Reader** | 通过 Firecrawl 获取内容 |
| **DeepSeek** | 使用你的 DeepSeek API 密钥，以 Markdown 形式阅读网页 |
| **DeepSeek (Enconvo Cloud)** | 通过 Enconvo Cloud 以 Markdown 形式阅读网页，无需 API 密钥 |
| **Enconvo Cloud Plan** | 使用云端链接阅读服务 |

## 阅读网页

1. 把 URL 粘贴到对话中，并就它提一个具体的问题。
2. 在依赖回答之前，先检查获取到的内容和来源。

## 需要登录的网页

使用 **Local Fetch** 时，**Browser-Assisted Fetching**（浏览器辅助获取）可以通过安装了 Enconvo Companion 扩展的 Chromium 系浏览器来阅读网页。

| 选项 | 作用 |
| --- | --- |
| **自动**（默认） | 复用你已打开的匹配标签页，内容完整渲染且带有你的登录状态。当直接获取失败或网页需要 JavaScript 时，使用一个临时的后台标签页。 |
| **关闭** | 仅使用直接 HTTP 请求 |
| **始终** | 始终通过浏览器获取 |

没有连接浏览器时，Local Fetch 会发出直接 HTTP 请求。其他服务提供商获取的是公开 URL，无法使用你已登录的浏览器会话。对于交互式网页，请使用[浏览器扩展](/zh/features/browser-extension)或[使用浏览器](/zh/features/browser-control)。

## 保存网页内容

如果想以后再找到某个网页，可在[知识库](/zh/ai/knowledge-base)中用 **添加 → 单个网页** 添加其 URL。请检查导入的网页及其索引状态；网页在导入后可能还会变化。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 返回的内容为空 | 确认该网页无需额外交互即可阅读，或使用开启了 **Browser-Assisted Fetching** 的 **Local Fetch**。登录页面、被拦截的请求、动态加载的内容以及不受支持的网站，都可能导致无法提取内容。 |
| 回答描述了网页上没有的内容 | 让智能体展示它实际获取到的内容，而不是猜测缺失的部分。 |

---
title: "知识库"
description: "收集文档、笔记、网页和文件夹，然后搜索它们，并在聊天中就它们提问。"
---

知识库用来存放你希望 Enconvo 日后能找到的资料：参考文档、项目笔记、保存的网页和语音笔记。当你指定知识库，或问题需要其中的内容时，智能体就会搜索它。[记忆](/zh/ai/memory)则不同：它保存的是智能体在各个聊天中记住的关于你的简短事实。

## 打开知识库

- 在聊天窗口中，点按侧边栏里的 **知识库**。
- 或打开 **设置 → 知识库**，点按某个知识库。
- 或在 Enconvo 的菜单栏菜单中选择 **显示知识库窗口**，它会在聊天窗口中打开知识库。

你的[记忆](/zh/ai/memory)也在这里：使用知识库栏顶部的 **知识库** / **记忆** 开关即可在两者之间切换。记忆不会列在你的知识库列表中。

在聊天窗口中，点按顶部的知识库名称即可查看所有知识库：每个知识库的大小、本周新增的内容、需要处理的条目，以及哪些知识库可以被 AI 客户端搜索。

## 创建知识库

1. 在所有知识库的概览中或 **设置 → 知识库** 中点按 **新建知识库**，或在 SmartBar 中搜索 **创建知识库**。
2. 给它一个清晰的 **名称**。在 **描述** 中写明里面放什么内容；智能体会阅读描述来决定何时在这里搜索。
3. 在 **开始方式** 下，选择 **空**、**一个文件夹**（建立索引并保持同步）或 **文件**。
4. 如果希望 Claude 或 Cursor 等 MCP 客户端也能访问它，请打开 **允许 AI 客户端搜索**。
5. 点按 **创建**。选择文件夹或文件时，按钮会显示为 **创建并导入** 或 **创建并添加**。

用不同的知识库把互不相关的项目分开。在同一个知识库内，用文件夹整理条目。

## 添加内容

| 入口 | 用途 |
| --- | --- |
| **添加 → 笔记** | 新建一篇可编辑的 Markdown 笔记 |
| **添加 → 文件** | 来自 Mac 的受支持文档、图片、音频或视频 |
| **添加 → 单个网页** | 某个 URL 的内容 |
| **添加 → Youtube 视频** | 一个视频及其字幕 |
| **添加 → 帖子** | 来自 X、Reddit、Hacker News、Bluesky、知乎等平台的帖子 |
| **添加 → 导入文件夹…** | 保留目录结构的本地文件夹，可选择保持同步 |
| **添加 → 新建文件夹…** | 用于整理条目的文件夹 |
| 把文件拖入或粘贴到知识库 | 从 Finder 快速导入 |
| [快速捕捉](/zh/features/quick-capture) | 保存当前应用的内容 |
| [语音笔记](/zh/features/voice-notes) | 录制并保存一条口述笔记 |

文档加载器支持常见的文本、Markdown、PDF、Office、EPUB 和结构化数据格式。图片通过 OCR 读取，音频和视频会被转写。解析质量和支持的格式取决于所选的加载器和服务提供商。请在导入预览和每个条目的状态中查看被跳过或失败的文件。

添加整个网站时，Enconvo 只会保留该网址所指向的站点部分（例如文档站点的某一部分），而且即使同一个页面出现在两个网址下，也只会建立一次索引。

## 共享知识库

通过电子邮件与特定联系人共享知识库，或与整个团队共享。你和接收共享的人都需要登录 Enconvo 账户。

<Steps>
  <Step title="打开共享">
    打开知识库的 **⋯** 菜单，选择 **共享…**。
  </Step>
  <Step title="添加联系人或你的团队">
    使用 **通过电子邮件添加人员**，或开启团队访问权限以与团队中的所有人共享。
  </Step>
  <Step title="选择每个人的权限">
    选择 **可查看**、**可添加** 或 **可管理**。只有所有者和有管理权限的人可以更改访问权限。
  </Step>
</Steps>

共享会将该知识库的副本放到 Enconvo Cloud 中。只有其中的内容会离开你的 Mac；记忆和聊天记录从不共享。任何人添加的内容都会在几秒钟内同步到每台 Mac，每个条目都会显示由谁添加。每位成员的 Mac 都会保留自己的副本和索引，因此搜索可以离线使用。其他人只能查看关联文件夹中的内容。**动态** 会显示更改的内容以及修改者。

要停止共享，请对某位联系人使用 **移除访问权限**，或使用 **停止与团队共享**。

## 浏览和查找条目

- **网格**、**列表** 和 **地图** 用于切换视图。列表是一张表格，包含 **类型**、**标签**、**文件夹**、**状态** 和 **已添加** 列。地图会把每个条目与含义最接近的条目连在一起。
- 条目上方的 **资料库** 菜单可在 **所有项目**、**最近添加**、**无标签** 和 **需要处理** 之间切换，并显示各自的数量。有条目需要处理时会显示一个小圆点。
- **筛选**、**标签** 和 **类型** 用于缩小显示范围。
- 在列表中勾选多行，即可一起移动、添加标签、重新索引、删除，或就它们聊天。

## 关联文件夹

1. 选择 **添加 → 导入文件夹…**。
2. 选择一个源文件夹，查看文件数量和被跳过的文件，然后确认。
3. 选中该文件夹并显示其详细信息，可以看到源路径、同步状态和控制项。
4. 点按 **立即同步**，或打开 **自动同步**，在 Enconvo 运行期间跟随变化。

源文件夹仍保留在磁盘上。新增和修改的文件会被导入，从源文件夹中删除的文件也会从知识库中移除。隐藏文件、不支持的格式以及超过 50 MB 的文件会被跳过。Enconvo 的文件夹同步从不修改源文件。

如果源磁盘被拔出或文件夹被移动，文件夹会显示 **找不到源文件夹**，并且不会移除任何内容。重新连接磁盘，或点按 **重新关联…** 并选择新的位置。有关处理和同步的故障排除，请参阅[知识库工作原理](/zh/advanced/knowledge-base-advanced)。

## 就资料提问

- **在知识库中**：点按顶部 **项目** 旁边的 **提问**。它和聊天窗口是同一个聊天：知识库会附加到你的第一个问题中，追问时会再次搜索，聊天也会和你的其他聊天一起保存。点按 **新建** 开始一个新问题。
- **在任意聊天中**：输入 **@**，从列表中选择一个知识库或其中的某个条目。它会停留在消息框上方，供后续提问使用，你也可以在那里将其移除。点按它的标签即可在知识库中打开它。

试试：

> 根据附上的项目笔记，列出与身份验证相关的决定，并为每个决定注明出处。

智能体会搜索并阅读它需要的资料。检索只会挑选相关段落，而不是发送所有文档。请打开引用的条目核实重要细节。如果缺少某个段落，请直接提及具体条目，或确认它已完成索引。

## 知识库设置

点按知识库顶部的齿轮图标（**知识库设置**）。

| 分区 | 内容 |
| --- | --- |
| **通用** | 知识库的 **名称** 和 **描述** |
| **索引与搜索** | 需要处理的条目、搜索模型，以及用于重建整个索引的 **重新索引…** |
| **来源与捕捉** | 关联文件夹及其 **立即同步**、**自动同步** 和 **重新关联…**，以及快速捕捉、语音笔记和 Chrome 扩展的快捷入口 |
| **AI 客户端（MCP）** | AI 客户端能否搜索这个知识库。参阅[知识库 MCP](/zh/advanced/knowledge-base-mcp)。 |
| **高级** | **知识库 ID** 和 **删除知识库** |

默认知识库和记忆不能删除。

## 编辑与维护

打开一篇笔记即可编辑其 Markdown。使用条目和文件夹菜单来重命名、移动、添加标签或移除内容。请仔细阅读移除确认提示：从知识库中移除条目和删除源文件是不同的操作，而移除整个关联文件夹绝不会影响磁盘上的文件。

<Warning>
对于来自关联文件夹的条目，条目菜单中显示的是 **移到废纸篓**。它会把磁盘上的真实文件移到废纸篓，然后该条目也会离开知识库。
</Warning>

当某个条目失败时，重试前先确认是提取还是索引失败了。文档可能在搜索索引完成之前就已可以阅读。

所有知识库使用同一个搜索模型，在 **设置 → 记忆** 的 **搜索** 下设置。它在这台 Mac 上或在 Enconvo Cloud 上运行，在两者之间切换会保留你的搜索索引。**索引与搜索** 中的 **搜索设置…** 可以打开这项设置。

## 连接其他 AI 应用

打开 **知识库设置 → AI 客户端（MCP）**，即可让本地 MCP 客户端搜索你选定的知识库。这是一项独立的、需要手动开启的只读服务。设置方法和共享控制请参阅[知识库 MCP](/zh/advanced/knowledge-base-mcp)。

## 数据处理

知识库文件和索引保存在本地。你选择的云端 OCR、转写、嵌入、重排序或聊天服务提供商，可能会收到它们工作所需的内容。搜索模型在 Enconvo Cloud 上运行时，正在索引或搜索的文字会发送到 Enconvo Cloud。文件保存在本地，并不代表服务提供商的处理是离线进行的。导入敏感资料之前，请先查看[隐私与安全](/zh/configuration/privacy-security)以及你的服务提供商。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 条目显示索引错误 | 打开 **资料库 → 需要处理**，确认是提取还是索引失败，然后重新索引该条目。 |
| 关联文件夹显示 **找不到源文件夹** | 重新连接磁盘，或点按 **重新关联…** 并选择文件夹的新位置。 |
| 回答遗漏了某个文档 | 确认该文档已完成索引，然后用 **@** 直接提及它。 |
| 新内容没有被索引 | 如果搜索模型在 Enconvo Cloud 上运行，请登录。登录之前，新内容不会被索引，搜索也只能找到字面匹配的内容。 |

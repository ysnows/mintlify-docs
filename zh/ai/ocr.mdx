title: "OCR"

---

OCR 会识别截图或图片中的文字，让你可以复制、粘贴、翻译这些文字，或就它们提问。当文字无法直接选中时，例如在图片、视频画面或扫描页中，就可以用它。文字在 Mac 本机识别还是交由在线服务识别，由你决定。

## 开始之前

Enconvo 需要屏幕录制权限才能截取你的屏幕。参阅[权限](/zh/configuration/permissions)。

## 从屏幕复制文字

1. 在 SmartBar 中运行 **Screenshot OCR**。
2. 拖动鼠标，框选包含文字的区域。
3. 识别出的文字会在灵动岛中打开。点按 **复制**，或点按 **粘贴**（**⌘↩**）把它放入你正在使用的应用。

在同一结果中，你还可以点按 **翻译** 或 **询问 AI**。**⋯** 菜单中有 **保留原始换行**、**复制图像**、**保存图片…**、**重新框选区域**、**添加到知识库** 和 **OCR 设置…**。

要换一个服务提供商重新识别该区域，点按文字上方的服务提供商名称并选择一个。如果服务提供商能定位每一行文字的位置，可以切换到图片视图，在截图上选择文字行，然后点按 **复制所选**。

## 其他 OCR 命令

| 命令 | 作用 |
| --- | --- |
| **Screenshot OCR** | 识别屏幕区域，并在灵动岛中打开文字 |
| **Silent Screenshot OCR** | 识别屏幕区域，并把文字复制到剪贴板 |
| **OCR** | 识别你提供的图片中的文字 |
| **Screenshot Translate** | 翻译屏幕区域。参阅[翻译](/zh/ai/translate) |
| **Screenshot Explain** | 解释屏幕区域。参阅[写作工具](/zh/features/writing-tools) |

## 选择服务提供商

打开 **设置 → OCR**，选择一个服务提供商，然后点按 **设为默认**。

| 服务提供商 | 文字在哪里识别 |
| --- | --- |
| **Apple Native OCR** | 在你的 Mac 上，使用 Apple 自己的文字识别 |
| **PP-OCRv6 (MLX)** | 在你的 Mac 上，使用运行在 Apple 芯片上的 PaddleOCR 检测与识别模型。数据不会离开你的 Mac |
| **AI Model OCR** | 由你选择的 AI 模型按照其 **指令** 识别 |
| **Mistral OCR** | 由 Mistral 的在线服务识别，使用你的 Mistral 密钥或登录 Mistral |
| **Mistral OCR (Enconvo Cloud Plan)** | 由 Mistral 的在线服务识别，通过你的 Enconvo Cloud 套餐 |

每个 OCR 命令也可以使用自己的服务提供商：在 **设置 → 插件 → OCR** 中该命令的设置里设置 **OCR 提供商**。各服务提供商的字段请参阅[服务提供商目录](/zh/providers/catalog)。

## 获得更好的结果

框选一个紧凑、清晰的区域，并确保文字大小易于阅读。分栏、表格、标点、代码缩进以及形似的字符，请手动核对。

即使是 PDF 文件，扫描件也可能需要 OCR。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 截图一片空白或无法开始 | 在[权限](/zh/configuration/permissions)中检查屏幕录制权限 |
| **未找到文字** | 点按 **重新框选区域**，选一个更紧凑的区域。手写或艺术字体用 **试试 AI 模型识别** 可能效果更好 |
| **无法识别** | 点按 **重试**，换一张简单的图片试试，并阅读服务提供商返回的错误。**设置** 会打开 OCR 设置 |
| 文字行连在一起或在错误的位置换行 | 在 **⋯** 菜单中打开或关闭 **保留原始换行**，或换一个服务提供商重新识别该区域 |
| 你想就屏幕上的内容提问，而不是复制其中的文字 | 使用 [Appshots](/zh/features/appshots) 或[屏幕涂鸦](/zh/features/screen-doodle) |

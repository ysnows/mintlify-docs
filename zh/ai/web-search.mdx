网页搜索为智能体提供来自网络的最新结果。每个智能体都能搜索；它使用哪个搜索服务由你选择，与撰写回答的模型分开设置。

## 选择搜索服务提供商

1. 打开 **设置 → 网页搜索**。
2. 选择一个服务提供商。Enconvo Cloud 选项无需 API 密钥；其他大多数服务需要添加你在该服务的密钥。
3. 点按 **设为默认**。

| 服务提供商 | 说明 |
| --- | --- |
| **Auto** | 使用聊天模型自带的网页搜索进行搜索；当该模型没有自带搜索时，回退到另一个服务提供商。参见[使用模型自带的搜索](#使用模型自带的搜索)。 |
| **Enconvo Cloud** | 对所有已登录账户免费，无需 API 密钥 |
| **DeepSeek (Enconvo Cloud)** | 通过 Enconvo Cloud 使用 DeepSeek 搜索，对所有已登录账户免费 |
| **Gemini** | 通过 Gemini 模型使用 Google 搜索进行 grounding |
| **Tavily**、**Bing**、**Brave**、**Google Custom**、**Exa** | 使用你在该服务的密钥进行搜索 |
| **Parallel** | Parallel 的 AI 搜索索引，使用你的 Parallel API 密钥返回每个网页中最相关的段落 |
| **PipeLLM** | 通过你的 [PipeLLM](/zh/providers/pipellm) 密钥获取 Google 搜索结果 |
| **DeepSeek** | 使用你的 DeepSeek API 密钥进行 DeepSeek 搜索 |
| **xAI X Search** | 搜索 X 的帖子、个人资料和串文，使用 xAI API 密钥或登录 xAI |
| **xAI X Search (Enconvo Cloud)** | 通过 Enconvo Cloud 套餐搜索 X |

服务提供商列表会标出免费选项。完整列表请参阅[服务提供商目录](/zh/providers/catalog)。部分模型在各自的服务提供商设置中也带有内置的 grounding 或搜索选项。

## 使用模型自带的搜索

选择 **Auto** 时，每次搜索会优先使用当前聊天所用模型自带的网页搜索（当该模型具备时）：OpenAI、Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、Z.ai 和 OpenRouter。它会使用你为该模型连接的密钥或登录账户，并由该模型的厂商计费。

当模型没有自带搜索，或其搜索失败时，Auto 会使用 **回退搜索**；除非你另选其他服务提供商，否则默认使用 **Enconvo Cloud**。

| 设置 | 作用 |
| --- | --- |
| **搜索路线** | 显示当前聊天模型会运行哪个搜索，以及失败时的处理方式。 |
| **优先用模型自带的搜索** | 默认开启。关闭后将始终使用回退搜索。 |
| **回退搜索** | 当模型没有自带搜索或搜索失败时使用的服务提供商。 |

在聊天中，每次网页搜索步骤都会说明是哪个搜索做出了回答，以及在发生回退时 Auto 为何会回退。

## 使用 Parallel

1. 从 [Parallel](https://platform.parallel.ai) 获取 API 密钥。
2. 在 **设置 → 凭据管理 → Parallel** 中添加该密钥。
3. 在 **设置 → 网页搜索** 中选择 **Parallel**，并选择一个 **搜索模式**：

| 搜索模式 | 适用场景 |
| --- | --- |
| **Turbo** | 速度最快的回答。仅支持英文和日文查询。 |
| **Fast** | 大多数搜索场景。默认选项。 |
| **Basic** | 从每个网页获取更长的段落。 |
| **Advanced** | 最深入的搜索。耗时约 3 秒且费用更高。 |

Parallel 会将每次搜索计入你的 Parallel 账户。

## 让智能体搜索

1. 提一个具体的问题。如果时间范围或地点很重要，请一并写上。
2. 智能体会进行搜索，并在回答中附上来源链接。
3. 打开引用的来源，确认它们确实支持该回答。

> 找到这个库最新稳定版的官方发布说明，总结其中的破坏性变更并附上链接。

## 选择合适的网络功能

| 需求 | 使用 |
| --- | --- |
| 发现相关来源 | 网页搜索 |
| 阅读已知 URL | [获取网页](/zh/ai/web-fetch) |
| 在浏览器中打开结果 | [快捷链接](/zh/features/quick-links) |
| 操作已登录的网站 | [使用浏览器](/zh/features/browser-control) |
| 搜索 X 的帖子、个人资料或串文 | **xAI X Search** 服务提供商 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 回答没有来源 | 确认智能体确实进行了搜索，而不是仅凭模型作答。让它到网上搜索。 |
| 服务提供商报错 | 检查该服务提供商的凭据，以及你在该服务的账户额度。 |
| Auto 使用了回退搜索 | 当前聊天模型没有自带网页搜索，或其搜索失败。聊天中的搜索步骤会说明具体原因。 |
| 结果需要登录，或位于交互式页面上 | 使用[使用浏览器](/zh/features/browser-control)等受支持的浏览器流程。获取公开 URL 无法访问你已登录的会话。 |

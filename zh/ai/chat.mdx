聊天窗口是 Enconvo 进行持续对话的主要场所。当一项工作需要不止一个回答时就用它：选择一个智能体，添加它需要的资料，并把相关的聊天放在一起。按 **⌃⌘X** 打开它。

其他场景：快速提问或运行命令用 [SmartBar](/zh/features/smartbar)，在某个应用旁边工作用[应用侧边栏](/zh/features/app-sidebar)，处理选中的文字用 [PopBar](/zh/features/popbar)，想要一个常驻屏幕的小入口则用[灵动岛](/zh/features/dynamic-island)和[桌面宠物](/zh/features/pet)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

下面的视频用 2 分钟带你浏览聊天窗口：选择智能体、为单个聊天切换模型与权限、添加文件、选择要创作的内容、提问与追问，以及重新找到你的聊天。

## 开始对话

1. 按 **⌃⌘X**，或在 Enconvo 中打开 **聊天窗口**。点击 **新建聊天**（**⌘N**）开始新对话。它会默认放在你上次选择的项目中；在项目选择器中选择 **无项目** 即可创建普通聊天。
2. 选择由谁作答：点击输入框上方的智能体卡片，或点击聊天顶部的智能体名称。默认是 Mavis；卡片中还有 Writer、Researcher 等智能体，以及 Codex、Claude Code 等编程智能体。
3. 检查输入框下方的标签。模型标签显示当前聊天使用的模型；点击它可以仅为当前聊天切换模型。盾牌标签用于设置智能体在行动前何时向你确认：**替我批准** 只在执行有风险的步骤前询问。
4. 点击 **+** 添加文件、图片或截图。如果想制作特定类型的成果，可以在输入框下方的 **做点什么** 一行中选择类型：**幻灯片**、**文档**、**设计**、**动画**、**仪表盘**、**网页**、**图片** 或 **视频**。项目内新建的聊天也会显示这一行。参见[作品](/zh/features/artifacts)。
5. 输入你的请求并按 Return。回答会流式显示在聊天中；如果智能体使用了工具，可以在回复中查看它们的进度。
6. 在同一个聊天中继续追问。它会记住之前的对话，所以像“把它改成一天版本”这样简短的要求就足够了。

如果想在另一台已配对的电脑上开启这个聊天，请用消息框中的 **运行于** 标签选择那台电脑；你已经输入的内容会一并带过去。参见[其他电脑](/zh/integrations/other-computers)。

请提出完整的要求。“用五个要点总结附件中的提案，并列出待解决的问题”既告诉智能体要读什么，也告诉它要返回什么。

你之后随时可以从聊天顶部的智能体名称切换当前聊天的智能体；SmartBar 和应用侧边栏里也有同样的选择器。想把对话交给[编程智能体](/zh/ai/coding-agents)，可以用它开启一个新聊天继续。当你分叉（Fork）一个聊天时，可以选择由哪个智能体接着处理。

### 发送前优化你的请求

输入请求后，点击麦克风旁边的魔法棒图标（**增强提示词**）。当前聊天自身的模型会结合已有对话，把它改写得更清晰、更完整，并把只有你知道的细节留作 `[placeholders]` 占位符。点击 **撤销**（或按 **⌘Z**）可以恢复原话，点击 **重试** 可以重新生成一版改写。

在你切换查看其他聊天时，消息框会保留每个聊天未发送的文字和附件，切回来时草稿依然还在。当你编辑之前的某条消息时，它附带的图片和文件也会连同文字一起回到消息框中，方便你在发送前删除或增补附件。

### 用 Vim 快捷键编辑

在 **设置 → 通用** 的 **键盘** 下打开 **Vim 模式**，或在消息框中输入 `/vim`。麦克风旁边会显示一个模式标签，在 Normal 和 Visual 模式下会变为蓝色。这两种模式会使用英文键盘布局进行输入，切回 Insert 模式时则会恢复你原本使用的输入法。

## 在智能体工作时与它对话

你不必干等一个耗时较长的任务全部完成。

| 目标 | 操作方式 |
| --- | --- |
| 向正在运行的任务补充内容 | 直接输入并按 Return。你开始输入或添加附件后，**停止** 按钮会变回 **发送**。智能体会在下一步读取你的消息。 |
| 排入一条消息，等任务结束后再发 | 按 **⌘Return**，或按住 **⌘** 点击 **发送**。 |
| 停止任务 | 点击 **停止**，或连按两次 **Esc**。单次误按不会中止任务。 |

智能体在继续输出并运行工具的同时，Enconvo 会判断你的新消息是否需要改变当前方向，因此可以延后处理的追问不会打断并丢弃正在进行的步骤。与当前任务无关的请求会交给一个子代理在后台处理，主智能体则继续手头的工作。

登录、安装或提问卡片不会卡住聊天：如果你没有回答它而是直接发送新消息，聊天会继续进行。

模型思考时，回复区域会显示 **正在思考…** 以及已用时间。

任务结束时，智能体的总结会先给出最终结果，再列出改动内容、检查结果以及需要你留意的事项。

## 设定目标

为智能体指定一个最终目标状态，它会一轮接一轮地持续推进，直到检查确认目标已经达成。

1. 输入 `/goal` 后接上任务完成时应达到的状态，或从 **+** 菜单中选择 **设定目标**。
2. 发送消息。目标连同已运行时间会显示在消息框上方。
3. 使用目标栏可以编辑、清除或继续该目标。目标生效期间，**+** 菜单中会提供 **修改目标**。

## 使用临时对话

对于不想保留记录的一次性提问，可以在新建聊天中打开虚线气泡开关（**临时对话**）。应用侧边栏和灵动岛中也有相同的开关。开启时，开关呈蓝色，消息框会显示虚线边框并带有 **临时对话** 标签。

临时对话不会进入你的聊天历史，不会保存任何[记忆](/zh/ai/memory)，离开后就会被删除。如果你后来还是想留下来，点击横幅上的 **保留对话**，它就会变为普通聊天。

## 选择回复的呈现方式

每个智能体都有默认的回复风格和智能界面（Intelligent UI）等级，决定它以图表、表格和卡片形式回答的倾向程度。想为当前聊天单独更改，打开 **+** 菜单并选择 **使用风格**。选择一种风格（例如 **标准**）或智能界面等级；如果希望将其设为该智能体的默认设置，可选择 **用于所有** 该智能体的聊天。风格和等级的说明参见[智能体](/zh/ai/agents)。

回复中的链接会以带有网站图标的卡片显示。地图链接会展示带有地点名称的真实地图；多个地点会合在一张带编号的地图上，路线则会绘出线路并标明时间和距离。参见[可视化回答](/zh/features/visual-answers)。

## 熟悉界面布局

侧边栏左侧是一条细长的图标栏，中间栏会随图标栏的选择而切换内容。

- 图标栏顶部是 **聊天**（会以琥珀色数字显示需要你处理的聊天数量），随后是 **定时任务**、**知识库** 和 **插件**。**看板**、**作品**、**媒体** 等其他入口则在 **···** 菜单中。你的插件位于一条分隔线下方，底部则是设备切换器和“设置”菜单。“设置”菜单里还包含帮助链接、**新功能** 和 **侧边栏快捷入口**。
- 在图标栏中选择一个入口，中间栏就会显示对应的分区、筛选器和主要操作。**聊天** 会回到你上次停留的位置。技能和 MCP 服务器会从 **插件** 中直接在窗口内打开。
- 按 **⌥⌘1** 到 **⌥⌘9** 可按顺序打开图标栏上的入口。按 **⌘B** 可隐藏中间栏，只保留图标栏。
- **后退** 和 **前进** 会记住你访问过的位置以及在每个位置选中的分区。按住 **后退** 可查看历史列表。

### 自定义侧边栏

打开 **···** 菜单，或右键点击图标栏上的任意图标，选择 **自定义侧栏…**。勾选要在图标栏显示的入口并拖拽排序。你还可以把插件拖到分隔线上方与常用入口并列，或拖回下方，以及固定或取消固定任意入口或插件。

### 快捷入口

把最常打开的页面、项目和链接固定到侧边栏。打开侧边栏底部的“设置”菜单，选择 **侧边栏快捷入口** 并添加条目。它们会显示在 **快捷入口** 分组中，你可以拖拽排序、重命名或移除它们。

### 设备切换器

侧边栏一次只显示一台电脑。底部的设备切换器可以在本机与你已配对的其他电脑之间切换，显示其他电脑上正在等待处理的事项，并在独立窗口中打开其中任意一台。**管理** 位于 **设备** 标题旁，**添加设备** 可以配对电脑、添加 SSH 主机或配对手机。参见[其他电脑](/zh/integrations/other-computers)、[配对手机](/zh/integrations/pair-your-phone)和[电脑与 SSH 主机](/zh/integrations/computers-and-ssh-hosts)。

每次更新后首次使用 Enconvo 时，侧边栏中的卡片会提供该版本的更新介绍视频。“设置”菜单中的 **新功能** 会在 **设置 → 教程** 中打开全部视频。

### 作品

**···** 菜单中的 **作品** 列出了智能体为你创建的网页、文档和设计。右键点击卡片或列表行，可以 **打开**、**重命名**、**复制链接**、打开创建它的聊天，或 **删除**。按住 **⌘** 或 **⇧** 点击可以多选并一起删除，且支持 **撤销**。从未写入内容的空白作品不会列入其中。

要分享网页作品，点击 **发布**。它会通过 Enconvo Cloud 上线到你专属的 `name.site.enconvo.com` 链接，并可选择设置访问密码。你也可以直接让智能体替你发布一个页面或整个站点文件夹。

## 整理你的聊天

侧边栏列出你最近的聊天；在支持项目的地方，项目会把相关的聊天放在一起。每个聊天都会保存：点击侧边栏中的 **搜索**（**⌘G**），即可按对话内容查找历史聊天。打开某个聊天的菜单，可以 **重命名聊天**、**置顶聊天**、**移动到项目**、**归档聊天** 或 **删除聊天记录**。删除聊天记录前，请先看清确认提示。

- 顶部的 **进行中** 只汇聚仍在等待你、正在运行中、或有你尚未打开的结果或失败提示的聊天，并标注各自所属的项目与状态。它的每一行操作方式与聊天列表相同：悬停显示 **置顶** 和 **归档**，右键打开菜单，双击重命名，或在触控板上轻扫归档。悬停该分组标题可点击 **全部标为已读**。
- 列表底部的 **手机聊天记录** 存放你在 iPhone 或 Android 手机上发起的聊天。你可以在 Mac 上继续对话；删除其中一条记录会在两端同时删除。参见[手机聊天](/zh/integrations/iphone-phone-chats)。
- 智能体向 Codex、Claude Code 或其他智能体求助时开启的聊天不会直接列在列表中。你可以从发起求助的聊天内对应行打开它。只要它处于打开、置顶或等待你回答的状态，它仍会占有一行。
- 每个[自动化](/zh/workflows/scheduled-jobs)的最近一次运行会在启动后立即带时钟标记显示在列表中。
- **已置顶** 分组可以折叠，Worktree 所在的行也可以折叠。
- 聊天旁出现紫色旋转图标表示它的主回复已完成，但由它启动的子代理或后台任务仍在运行；其中的蓝色圆点表示有新的回复待阅读。

### 批量操作多个聊天

1. 按住 **⌘** 点击、按住 **Shift** 点击，或点击行内的 **选择** 来选中聊天。**⌘A** 可全选整个分组。
2. 使用随即出现的工具栏将它们标为已读（**⇧⌘U**）、归档（**E**）或删除（**⌫**）。

删除前会先弹出确认窗口，列出选中的聊天，停止仍在运行的任务，并提供 **改为归档** 选项。标为已读和归档都可以撤销。

### 模型选择

顶层的 **新建聊天** 可以设置智能体的默认模型。项目内新建的聊天使用该项目的模型偏好。每个聊天都可以保留自己的模型和推理设置。更改其他聊天也在用的默认值之前，请先阅读[模型选择](/zh/ai/model-selection-guide)。

如果某个聊天的模型用完了 Enconvo Cloud 点数，可以将该聊天切换到 Enconvo Cloud 以外的模型，然后点击点数耗尽卡片上的 **用 … 重试**，用新模型重新运行该消息。如果想让聊天在出错或受限时自动切换到备用模型，请在 **设置 → AI 模型** 中设置 **兜底**；参见[用备用模型保持对话不中断](/zh/ai/model-selection-guide)。

### 在 Worktree 中工作

在作为 Git 仓库的项目中，聊天可以在主工作区和 Worktree 之间切换。使用聊天标题后的标签即可切换，或者直接让智能体处理。聊天会带着它修改的文件一起移动，合并 Worktree 后改动会回到主工作区。每次移动都会在对话中留下一条记录。参见[项目](/zh/ai/projects)。

## 添加上下文和文件

只添加请求需要的来源。文件附件、屏幕截取、知识库检索和浏览器页面，各自为智能体提供不同类型的上下文。选择来源请参见[上下文感知](/zh/features/context-awareness)，智能体能对你的文件做什么请参见[文件和文件夹](/zh/ai/file-tools)。

- 消息框在 **权限** 之后提供了 **实时屏幕** 和[屏幕涂鸦](/zh/features/screen-doodle)按钮。实时屏幕归属于你开启它的那个窗口；它的标签会显示已开启状态，再点一下即可关闭。
- 输入 `@` 可以提及文件、智能体，或你的朋友与团队成员。当你点名某个人时，智能体就知道你指的是谁，从而可以在你要求时给对方发私信、读取回复或拨打电话。
- 较大的视频或音频文件会以转写文稿或笔记的形式传给模型。文件夹和空文件无法作为附件添加。

[记忆](/zh/ai/memory)和[知识库](/zh/ai/knowledge-base)的用途不同：记忆保存智能体会反复用到的事实，知识库存放供它查阅的资料。两者都可以从侧边栏图标栏的 **知识库** 打开，栏顶部有 **知识库** / **记忆** 切换开关。

## 阅读和复用回复

展开回复的工作详情，可以看到每次工具调用及其结果。回复下方的 **复制**、**朗读** 和 **更多** 可对该回复进行操作。[可视化回答](/zh/features/visual-answers)可以把图表和交互内容直接放进回复里。

代码块提供 **复制** 和自动换行按钮，让长行可以直接折行而无需横向滚动。如果想让所有回复中的代码块默认折行，请在 **设置 → 通用** 的 **外观** 下开启 **代码自动换行**。

通过链接分享聊天时，在聊天上传的过程中链接就可以立即复制。之后点击 **更新链接** 只会发送有改动的部分。

智能体为你打开的网页和文件会显示在聊天旁的侧边面板中。每个聊天都会保持你上次离开时的面板展开或收起状态。从未打开过面板的聊天会先停在 **新建** 标签页，里面提供面板的各种工具。面板内的所有标签页共用你拖拽设定的宽度；关闭最后一个标签页时，面板也会随之关闭。

| 标签页 | 快捷键 | 显示内容 |
| --- | --- | --- |
| **拉取请求** | **⌃⇧P** | 在 GitHub 仓库中工作的聊天里：显示当前分支的 Pull Request、检查状态、审阅与评论，或从 Worktree 聊天直接创建 PR。 |
| **设备** | **⌃⇧M** | 经过一次简单设置后，在聊天旁实时查看和控制 iOS 模拟器或 Android 模拟器。 |

想用说代替打字，可以用[听写](/zh/features/dictation)用语音撰写内容，或用 [Live Talk](/zh/features/live-voice) 进行双向语音对话。

## 当 Enconvo 重启时

如果因为更新、退出或崩溃导致某个聊天在任务中途中断，Enconvo 重新打开后该聊天会自动恢复继续。它会先检查自己已经完成了哪些步骤再做剩下的部分，并把之前正在运行的子代理也带回来。

## 设置

打开 **设置 → 聊天窗口**。

| 设置 | 作用 |
| --- | --- |
| **默认智能体** | 聊天窗口中新聊天启动时使用的智能体。如果你删除了该智能体，新聊天会退回到 Mavis。 |
| **外观** | **浅色**、**深色** 或 **跟随应用**。 |
| **快捷键** | 在任意应用中打开聊天窗口。默认为 **⌃⌘X**。其他窗口中的 **在聊天窗口中打开** 按钮也会显示你设定的快捷键。 |

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 回复用错了模型 | 检查这个聊天的模型选择，以及智能体的默认模型。 |
| 聊天提示由另一个模型接管了 | 当聊天原本的模型不可用时，**设置 → AI 模型** 中的备用模型代为作答。原模型恢复后，聊天会自动切回原模型。 |
| 智能体看不到文件或屏幕 | 检查聊天的附件和[权限](/zh/configuration/permissions)。 |
| 某个工具不可用 | 检查该智能体设置中的 **工具与技能**，而不是换个说法重复同一请求。参见[智能体](/zh/ai/agents)。 |
| 列表中找不到你要找的聊天 | 查看 **进行中** 和 **手机聊天记录**，或使用 **搜索**（**⌘G**）。智能体自行发起的聊天需要从发起求助的那个聊天中打开。 |
| 聊天显示 **无法显示此对话** | 点击 **重新加载对话**。在此期间，聊天列表和消息框仍可正常使用。 |

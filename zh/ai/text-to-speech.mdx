---
title: "文本转语音"
description: "让 Enconvo 朗读文字，或把文字转换成音频文件。"
---

Enconvo 有两个与语音相关的命令。**朗读** 通过灵动岛上的朗读播放器把文字读给你听。**TTS(Text To Speech)** 用你选择的服务提供商把文字转换成音频文件。你也可以直接在对话中让聊天回复朗读给你听。

## 朗读聊天回复

点击回复下方的扬声器按钮。该按钮会变成一个包含暂停、继续和停止的小型播放器，正在朗读的句子会在回复中高亮显示。同一时间只会朗读一条回复，关闭聊天即可停止播放。

如需自动朗读每条回复，请在 SmartBar 或聊天窗口中开启自动朗读回复。每个窗口各自保留此设置。

## 朗读文字

1. 打开 **设置 → 文本转语音**，设置服务提供商和声音。
2. 选中文字并运行 **朗读**。
3. 灵动岛上的播放器会逐句朗读。你可以用它暂停、继续或停止，后退或前进，更改语速或声音，并显示高亮当前句子的文字。
4. 如果服务提供商支持，可以在其设置中调整声音或语速。

当[虚拟形象](/zh/features/avatar)处于打开状态时，它会带着口型同步朗读文字，播放器则以紧凑形式留在灵动岛上。

## 生成音频文件

用你想朗读的文字运行 **TTS(Text To Speech)**。检查它提供的服务提供商、声音、语速和输出格式，然后打开生成的文件，检查发音和节奏。

[TTS 服务提供商目录](/zh/providers/catalog)列出了 Enconvo Cloud、直连服务、macOS 系统语音和本地选项。**Enconvo Cloud Voice** 是 Enconvo Cloud 自有的语音服务，支持 60 多种语言，无需 API 密钥。DeepSeek 提供女声（Stella）或男声（Tide）朗读文本，可使用你自己的 DeepSeek API 密钥或 **DeepSeek (Enconvo Cloud)**。各家的控制项不同：有些提供商接受风格指令或情感标签，有些则只提供固定的声音列表。

## 克隆声音

ElevenLabs、Fish Audio、Gemini 和 Qwen3 支持克隆声音。它们会在 **设置 → 文本转语音** 的服务提供商列表中显示相应的标记。

1. 打开 **设置 → 文本转语音**，选择这些服务提供商之一，然后打开其 **声音克隆** 标签页。
2. 上传一段录音，或点击 **录制** 并朗读屏幕上显示的文字。倒计时可以取消，音量表会跟随你的声音变化，单次录制会在 5 分钟后自动结束。
3. 试听你克隆的声音，然后在该标签页中使用、重命名或删除它。

你也可以点击这些服务提供商的 **声音** 菜单旁的 **克隆声音**。你克隆的声音会显示在 **声音** 菜单的顶部，在那里同样可以重命名或删除。

该标签页会显示你在这个服务提供商下还剩多少个 Cloud 声音额度。达到上限时，删除一个即可克隆新的声音。如果在录制期间关闭设置窗口，录制会停止并保留已录下的内容。

## 本地声音与云端声音

本地提供商在你的 Mac 上运行，需要受支持的硬件和模型文件：Kokoro 和 Qwen3 运行在 MLX 上，英语声音 Phonon 则在配备 Apple 芯片、运行 macOS 15 或更高版本的 Mac 上通过 Core ML 运行。**系统** 使用 macOS 内置的声音。在线提供商（包括不需要 API 密钥的）会通过网络发送你的文字。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 没有声音 | 检查系统输出设备，以及播放是否已暂停。 |
| 朗读停止并提示服务提供商没有 API 密钥 | 在 **设置 → 文本转语音** 中添加密钥，或改选运行在 Enconvo Cloud 或你 Mac 上的声音。 |
| 生成失败 | 检查你对该服务提供商的访问权限，以及文字的长度和格式。 |
| 名字发音不对 | 用更短的样本测试，并尝试提供商的发音或风格控制项。 |

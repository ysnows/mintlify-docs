编程智能体是你在 Enconvo 聊天中运行、且平时已经在使用的 AI 编程工具，例如 Claude Code 和 Codex。当工作涉及项目文件夹中的代码时可以使用它：它会以差异对比的形式编辑文件、运行命令，并在执行操作前询问你；同时，Enconvo 会在聊天窗口、SmartBar 和你的手机上保存这些对话、历史记录和审批请求。

| 编程智能体 | 开发者 | 运行位置 |
| --- | --- | --- |
| **Claude Code** | Anthropic | 在你的 Mac 上，使用 Claude 登录 |
| **Codex** | OpenAI | 在你的 Mac 上，使用 ChatGPT 登录 |
| **Grok Build** | xAI | 在你的 Mac 上，使用 Grok 登录 |
| **Antigravity** | Google | 在你的 Mac 上，使用 Google 登录 |
| **Muse Code** | Meta | 在你的 Mac 上，使用 Meta 登录，或在其本地模型上运行 |
| **Grok Bot** | xAI | 在 xAI 云端，通过你连接的例程运行 |

## 开始之前

每个编程智能体在 **设置 → 智能体列表** 中都有自己的页面。点击它即可查看其 **状态**：

1. 如果显示 **未安装**，请点击 **安装**，或在终端中运行显示的命令，然后点击 **重新检查**。版本过旧时会显示 **更新**。
2. 在 **账户** 下，点击 **使用 Claude 登录**、**使用 ChatGPT 登录**、**使用 Grok 登录**、**使用 Google 登录** 或 **使用 Meta 登录**。Enconvo 使用与该智能体在终端中自身命令行相同的登录状态。

当 Claude Code 或 Codex 的登录将在十天内过期时，智能体页面、**更新** 列表和项目的看板都会给出提示，并显示 **重新登录**。如果编程智能体已退出登录，看板任务会等待并显示为 **已挂起**，重新登录后会再次运行。

在本地模型上运行的 Muse Code 无需登录 Meta。Grok Bot 则需要连接一个例程；参见[连接 Grok Bot](#连接-grok-bot)。

## 与编程智能体对话

1. 在聊天窗口中，从智能体卡片或智能体菜单中选择一个编程智能体。
2. 选择它要工作的项目文件夹。
3. 输入你的请求并发送。它的步骤、差异对比和命令会实时流式显示在聊天中，审批问题也会以卡片形式显示供你回答。

聊天的审批遵循 Enconvo 的[权限模式](/zh/ai/agents)。在 **完全访问** 下，新的 Claude Code 聊天会以 **绕过权限** 启动（在 Claude Code 自身设置允许的情况下），新的 Codex 聊天则会以 **完全访问** 启动，因此两者在执行操作前都不会询问。

在工作树聊天中，侧边栏面板的 **拉取请求** 标签页（**⌃⇧P**）会显示该分支在 GitHub 上的拉取请求，或者创建一个新的拉取请求。参见[聊天窗口](/zh/ai/chat)。

要接续之前的会话，请选择 **继续之前的会话**。你在智能体自身命令行中启动的会话也会按你命名的名称列出。

你也可以将与 Mavis 开始的聊天交给编程智能体，只需用它开启一个新聊天继续即可。其他智能体可以将编程智能体用作子代理，项目也可以给它们分配任务，或让其中一个担任项目负责人。参见[子代理](/zh/ai/agents)和[项目](/zh/ai/projects)。

### Claude Code：推理强度、快速模式和 Ultracode

Claude Code 聊天中的推理强度选择器用于设置其推理强度。当会话支持时，选择器还会显示 **快速模式** 和一个 **Ultracode** 开关。Ultracode 会为该会话的其余部分开启工作流编排（无论你选择哪种推理强度），并在你更改推理强度时保持开启。输入 `/effort ultracode` 也有相同效果。在新聊天中，你可以在发送第一条消息前设置快速模式和 Ultracode。

### Codex：警告

Codex 的警告不会混入对话中。输入 `/warnings` 即可列出这些警告。

### Muse Code：在终端中继续

要在终端中继续 Muse Code 聊天，请选择 **在终端中继续**，或点击 **复制命令** 来复制命令。聊天会在其文件夹中通过 `muse resume` 打开。当你在终端中退出 Muse Code 并再次从 Enconvo 发送消息时，你在终端中运行的回合会回到聊天中。

Muse Code 的审批问题会显示编辑将带来的更改。当你拒绝某个步骤时，你在点击 **拒绝** 时输入的内容会在同一回合中发送给 Muse Code，以便它立即据此采取行动。它的技能和 `/compact` 位于 `/` 菜单中。

<Note>
Muse Code 的 Contributor 模式默认开启，Meta 可用你的提示词和代码训练其模型。Enconvo 不会更改这项设置；请在 Muse Code 自己的设置中关闭。
</Note>

## 选择编程智能体在 Enconvo 中可以使用的内容

编程智能体可以在其聊天中使用 Enconvo 的插件，例如给你的 Enconvo 智能体发消息、图像和视频生成、记忆、浏览器以及电脑操作。在 **设置 → 智能体列表** 中打开该智能体的页面，在 **Enconvo 能力** 下：

- 关闭 **Enconvo 能力**，即可禁止该智能体使用 Enconvo 的所有插件。
- 或者点击 **插件** 旁的 **自定义**，逐个关闭不需要的插件。被关闭的插件会对该智能体隐藏，其调用也会被拒绝。

此更改也会应用于该智能体已打开的聊天。客户工作区中的编程智能体聊天会完全保留在该工作区内。

## 连接 Grok Bot

Grok Bot 运行在 xAI 的云端。Enconvo 会把每条消息发送到你在 Grok Bot 中创建的 Webhook 例程，并在聊天中显示回复，即使回复送达较晚也是如此。

1. 在 Grok Bot 中创建一个使用 Webhook 触发器的例程。
2. 在 **设置 → 智能体列表** 中打开 **Grok Bot**，点击 **例程说明** 旁的 **复制**，并将其粘贴到例程中。
3. 在同一页面上将例程的 Webhook URL 和密钥添加为凭据，然后点击 **测试**。测试会等待例程的回复，最长约 90 秒。

在连接例程之前，智能体选择器会将 Grok Bot 显示为 **未设置**。每条消息都会消耗你 Grok Bot 方案的每周用量。**停止** 只会让 Enconvo 不再等待：例程仍在云端继续运行，之后收到的回复仍会添加到聊天中。

每条消息最多可包含 32,000 个字符。附加的文件和图片会留在你的 Mac 上；只有文本会被发送。

### 让 Grok Bot 调用 Enconvo

借助 Enconvo 的 MCP 服务器，Grok Bot 可以回复你的聊天、向你的 Mac 和已配对的手机发送通知，并请你的 Mac 上的智能体运行任务。

1. 在 Grok Bot 页面上的 **让 Grok Bot 调用 Enconvo** 下，点击 **连接**。你需要先登录你的 Enconvo 账户。
2. 在 Grok Bot 中打开 **插件**，添加显示的 **服务器 URL**，并在 Grok Bot 提示时使用你的 Enconvo 账户登录。

向你 Mac 上的智能体发出的每个请求都会等待你的批准，除非你开启 **始终允许 ask_mac**。请求会保留在 **这台 Mac 上的 Grok Bot** 聊天列表中。点击 **断开连接** 即可停止 Grok Bot 调用 Enconvo；断开连接或你的 Mac 离线时，仍在等待的请求会被撤回。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 聊天提示智能体未登录 | 在 **设置 → 智能体列表** 中打开该智能体的页面并点击 **重新登录**。调用该智能体的 Mavis 聊天或应用也会收到同样的登录错误，其看板任务会等待并显示为 **已挂起**，直到你登录为止。 |
| 智能体显示 **未安装** 或版本过旧 | 在其页面上点击 **安装** 或 **更新**，然后点击 **重新检查**。 |
| Muse Code 提示需要更新 Enconvo | 更新 Enconvo 以适配较新版本的 Muse Code。 |
| Grok Bot 显示 **未设置** | 在 Grok Bot 页面上添加例程的 Webhook URL 和密钥，然后点击 **测试**。 |
| Grok Bot 测试提示消息过多 | 例程或 Enconvo 目前正在限制过多的消息请求。请稍后再试。 |
| 在终端中打开的 Muse Code 聊天无法发送消息 | 在终端中退出 Muse Code 以将对话回合同步回来，然后再从 Enconvo 发送。 |

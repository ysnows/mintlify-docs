---
title: "变量"
description: "在提示词和其他支持模板的字段中插入当前输入、选中的文本、应用上下文或日期。"
---

变量会填入每次都会变化的值，例如你在 SmartBar 中输入的文本、在其他应用中选中的文本，或今天的日期。在支持模板的提示词和偏好设置中使用变量，同一个 AI 命令、智能体指令或工作流就能处理你眼前的任何内容。打开**设置 → 变量**即可浏览可用的变量。

## 可用变量

| 变量 | 提供的值 |
| --- | --- |
| Input Text | 当前的 SmartBar 输入 |
| Selection Text | 当前应用中选中的文本 |
| Latest Clipboard | 最近的剪贴板内容 |
| Active Application | 最前方应用的信息 |
| Active Application Screenshot | 最前方窗口的图像 |
| Active Screen Screenshot | 当前活动屏幕的图像 |
| Focused Window Content | 从当前聚焦窗口中提取的内容 |
| Browser Active Tab | 当前标签页的 URL 以及可获取的页面内容 |
| Current Folder | Finder 中打开的文件夹 |
| Selected Files | Finder 中选中的文件 |
| History Messages | 当前对话的历史记录 |
| Now | 当前日期和时间 |
| Your Language | 你阅读所用的语言：即你的**回复语言**，设为“自动”时则为系统语言 |
| Opened Applications | 正在运行的应用信息 |
| Opened Application Names | 正在运行的应用名称 |

## 使用变量

1. 打开你要自定义的 AI 命令、智能体指令或工作流字段。
2. 确认该字段支持变量；如果它有选择器，就使用选择器。
3. 插入所需的值，并用无害的示例内容测试。
4. 检查输入为空或缺少权限时，结果是否会改变。

文本提示词可以使用受支持的模板名称，例如：

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

能使用哪些变量取决于命令和上下文，并非每个文本字段都会解析模板。截图和应用内容可能需要 macOS 权限，也需要模型支持相应类型的输入。

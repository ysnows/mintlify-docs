本页按侧边栏顺序列出 Enconvo 设置侧边栏中的每一项，并附上对应的说明指南。要打开设置，请点击菜单栏中的 Enconvo 图标并选择 **设置**。要跳转到某一项，在 **搜索设置** 中输入它的名称，或者输入问题并按 Return 键让 AI 告诉你设置在哪里。

各指南中的设置路径使用下面的名称，例如 **设置 → SmartBar**。

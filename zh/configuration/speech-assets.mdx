词典用来教 Enconvo 的语音功能认识你常用的产品名、技术术语、缩写和特殊拼写。说话人保存你在录音中命名过的声音，这样新的录音会自动为它们加上标签。在 **设置 → 词典** 和 **设置 → 说话人** 中打开它们。

## 添加词条

1. 打开 **设置 → 词典**，点击 **新词**。
2. 输入你希望使用的拼写，如果有帮助，再加一句简短说明。
3. 在 **误识别为** 中，可以选填听写会把这个词误写成的内容，用逗号分隔。
4. 点击 **保存**，然后录一段包含这个词的简短语音试试。
5. 检查转写结果。服务提供商的支持程度和音频质量仍会影响识别效果。

## 一次添加多个词条

在 **添加到词典** 窗口中切换到 **批量添加**，每行输入一个词条。用 `|` 分隔说明：

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 采纳建议的拼写

词典会列出 **建议的拼写**：你听写后立即修正的词，以及听写持续为你的词条写错的拼写——它会建议将这些错写添加为 **误识别为** 条目。点击 **采纳**，听写下次就会这样写；或点击 **关闭**。

## 从你的修正中学习

在 **设置 → 词典** 中开启 **从我的修正中学习** 后，你手动修正的听写名称会自动加入词典以供下次使用。灵动岛会显示已学习的内容，并附带 **撤销** 按钮。已学习的拼写会显示在对应词条下方的 **已学习** 中；在那里将其移除后，Enconvo 将不再学习该拼写。

## 编辑或删除词条

使用搜索和编辑按钮让列表保持最新。要删除多个词条，点击 **选择**，选中这些词条，点击 **删除** 并确认。

## 为说话人命名

1. 打开一段有多位说话人的录音。
2. 点击转录文本中的某个说话人标签，给这个人起个名字。
3. Enconvo 会登记这个声音，并在新的录音中自动识别它。

在重命名某个说话人之前，先检查录音中的说话人分配。识别出的声音或说话人分离标签可能有误，尤其是在多人同时说话时。

**设置 → 说话人** 列出了你命名过的所有人，以及他们出现在多少段录音中。你可以在那里重命名或删除说话人。删除说话人后，他们的标签会恢复为说话人编号；录音本身会保留。

## 适用范围

[听写](/zh/features/dictation)、[会议录音](/zh/features/meeting-recording)、[语音转写](/zh/features/transcription)和[实时字幕](/zh/features/live-captioning)各自使用自己的语音设置。请在每个服务提供商的设置中检查语言提示、热词、说话人分离和其他选项，因为不同提供商对词汇的处理方式并不相同。

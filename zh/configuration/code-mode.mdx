---
title: "代码模式"
description: "让智能体编写一段简短的脚本，一次性发起多次工具调用并只读回最终结果。"
---

代码模式让智能体能够一步完成原本需要多步的工作：它会编写一段简短脚本，并行或按顺序发起多次工具调用，并只把最终结果读回来。当任务需要对大量项目重复同样的调用（例如检查一系列网页，或从多个服务汇总结果）时，它尤其适用，既能让工作更快完成，也不会让聊天被所有中间结果填满。

你不需要自己去调用代码模式。开启后，只要任务合适，智能体就会自动使用它，并在聊天中显示一张卡片，列出脚本执行过的调用。

## 设置代码模式

1. 打开 **设置 → 代码模式**。你也可以在插件页面的 **内置** 标签页中打开 **代码模式**。
2. 在 **脚本可用范围** 下，开启允许脚本调用的功能。每次调用仍会按照聊天的[权限模式](/zh/ai/agents)向你确认。
3. 选择哪些模型可以编写脚本、聊天中显示什么内容，以及脚本运行时间较长时如何处理。

## 设置项

**脚本可用范围** 列出了脚本可以调用的内容：

| 访问权限 | 允许的操作 | 默认 |
| --- | --- | --- |
| **插件** | 搜索、知识库、文档以及其他插件路由 | 开启 |
| **Connector 和 MCP** | 你关联的账户和 MCP 工具 | 开启 |
| **文件** | 读取和写入文件 | 开启 |
| **Shell 命令** | 在终端中运行命令 | 开启 |
| **浏览器** | 在你自己的浏览器中使用[使用浏览器](/zh/features/browser-control) | 开启 |
| **应用** | 在其应用访问列表范围内使用[电脑操作](/zh/features/computer-use) | 开启 |
| **其他 Agent** | 启动子代理或向其发送消息 | 关闭 |
| **模型调用** | 调用轻量模型来总结或判断项目 | 开启 |

其他选项：

| 选项 | 可选值 |
| --- | --- |
| **用于** | **写代码可靠的模型**（其余模型会逐个发起调用），或 **所有模型**。 |
| **聊天里显示** | **调用**，或 **调用和代码**。 |
| **脚本跑得久时** | 在后台 **继续跑，最多 2 小时**，或 **10 分钟后停下**。 |

## 在聊天之外使用代码模式

当脚本在聊天之外运行（例如在自动化中）时，它只能调用只读类工具：内置搜索和读取、公开网页、普通文件，以及未声明会修改内容的 MCP 工具。Enconvo 会在每次调用实际运行前再次进行检查。

## 在技能中使用脚本

技能可以将代码模式脚本保存在自己的 `scripts` 文件夹中，并将其作为步骤之一来运行。参见[技能](/zh/configuration/skills)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 智能体仍然逐个发起调用 | 检查 **用于** 设置。设为 **写代码可靠的模型** 时，其他模型不会使用代码模式。 |
| 脚本无法调用某个工具 | 在 **脚本可用范围** 下开启对应的权限。在聊天之外运行时，脚本仅限只读操作。 |
| 运行时间长的脚本中途停下了 | 设为 **10 分钟后停下** 时，更长的脚本会被终止。请改选 **继续跑，最多 2 小时**。 |

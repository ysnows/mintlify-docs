你使用的每个服务提供商都需要一个凭据：API 密钥，或你已付费套餐的登录。你在服务提供商自己的设置页面添加凭据，Enconvo 会把它保存在一个服务提供商配置中，所有使用该服务提供商的功能都共用这个配置。**设置 → 凭据管理** 会在一个地方显示你的所有凭据。

## 添加服务提供商

<Steps>
  <Step title="打开一个类别">
    打开你想使用的功能对应的设置页面，例如 **设置 → AI 模型**、**设置 → 图像生成**或 **设置 → 文本转语音**。
  </Step>
  <Step title="选择服务提供商">
    选择一个服务提供商。如果要为它再设置一份副本（用于另一个密钥或账户），请选择**添加新提供商**。
  </Step>
  <Step title="选择登录方式">
    在**身份验证**下选择 **API 密钥**；如果服务提供商允许使用你付费的套餐，也可以选择**订阅**。
  </Step>
  <Step title="添加凭据">
    粘贴你的 API 密钥，或完成服务提供商的登录。
  </Step>
  <Step title="测试">
    如果页面上有**验证**，请点击它，然后选择一个模型并发送一个简短的请求试试。
  </Step>
</Steps>

API 密钥按服务提供商的 API 账户计费。订阅使用你套餐内含的用量及其限额。**身份验证**下方的文字会告诉你当前页面使用的是哪一种。

## 共用配置

服务提供商配置（例如 **OpenAI 2**）保存着该服务提供商的 API 密钥和订阅登录，并出现在该服务提供商支持的每个类别中。重命名或删除配置会影响所有这些类别，而不只是你当前所在的页面。

每个类别保留自己的模型、声音和生成设置。但新的 API 密钥会应用到所有使用该配置的功能，因此更改后请测试这些功能。

服务提供商在不同类别中提供的内容各不相同。一个可用于 AI 聊天的登录，并不意味着包含该服务提供商的实时语音 API。当某个类别只接受 API 密钥时，它的页面会说明这一点，并列出可以使用订阅的类别。

## 查看套餐用量

订阅登录会显示你的账户以及套餐还剩多少。诸如**剩余 %** 之类的数值表示你剩余的额度。打开账户卡片的菜单，选择**刷新用量**可以更新数据，选择**重新连接**可以重新登录。

当 Claude 或 Codex 为你赠送了免费额度重置次数时，Claude 或 ChatGPT 订阅卡片会显示 **免费额度重置**：你拥有的次数和有效期。点击 **使用重置** 并确认即可补充你的额度。如果有多个可用重置，卡片会列出它们，你可以使用你选择的那个。

没有显示用量并不代表你的用量不受限制。

## 管理你的凭据

打开 **设置 → 凭据管理**。列表按服务提供商配置分组显示凭据，然后显示**未使用的密钥**：没有任何服务提供商使用的密钥。

- 在**搜索提供商...**中输入内容来查找。
- 点击**添加新凭证**，为你选择的服务创建另一个凭据。
- 要删除凭据，请将鼠标悬停在它上方并点击垃圾桶图标。如果有 API 密钥类连接器使用该密钥，确认对话框会列出它的名称，**删除并断开连接**会断开该连接器，直到你为它提供另一个密钥。
- 点击列表底部的**清理**，可一次删除所有未使用的密钥。按钮会显示密钥数量，确认对话框会先列出它们。Enconvo 从不会自行删除未使用的密钥。

点击一个凭据即可添加或更改其密钥。**使用者** 会列出依赖它的功能，例如 **AI 模型** 或 **文本转语音**；点击其中一项即可打开对应的设置页面。

配置自己的凭据在这里没有删除按钮，它们会在你删除服务提供商时一并删除。

当你拥有以下两类凭据时，还会出现另外两个分组：**其他服务**，用于 Enconvo 没有为其内置服务提供商的服务的密钥；以及 **登录信息**，用于你保存的网站和应用登录凭据。

## 当智能体需要密钥时

当某个任务需要一项服务的 API 密钥时，智能体会在聊天中显示一张 **连接** 卡片，而不是让你直接粘贴密钥。密钥会存入凭据管理，而不会留在对话里，之后的聊天也能直接使用，无需再次询问。

对于 Enconvo 没有内置服务提供商的服务，卡片会显示该密钥将被发送到的主机。密钥保存在 **其他服务** 下，智能体只能在向该主机发起的请求中使用它。

智能体本身从不持有密钥：它只引用已保存的凭据名称，任何请求或命令中本来会显示密钥的位置，都会显示为 `[redacted]`。

在手机聊天中，**连接** 卡片会显示在你的 iPhone 上，密钥则保存在 Mac 的凭据管理中。在即时通讯聊天中，智能体从不直接索要密钥，而是发送一个在 Enconvo 中打开该聊天的链接。

即使你仍然把 API 密钥粘贴到了消息中，Enconvo 也会将它保存到凭据管理，并在保存的聊天记录中将它替换为 `[redacted]`，这样后续请求和你的其他设备就不会携带它。如果你为已有密钥的服务粘贴了新密钥，新密钥会替换已保存的密钥。

## 网站和应用登录

当浏览器任务进入登录页面时，一张卡片会请求输入一次用户名和密码。Enconvo 只会在该网站填入这些信息，智能体永远看不到密码。已保存的登录会出现在 **登录信息** 下。取消勾选 **记住此登录** 则只用于本次登录。

当某个 Mac 应用的登录需要密码时，卡片会标明该应用的名称。Enconvo 只会将用户名和密码输入到该应用中，且密码只会输入到隐藏输入内容的字段中。

## 自定义端点

**兼容 OpenAI** 和**兼容 Anthropic** 服务提供商有一个 API Base URL 字段，可以填写你自己的服务器。部分内置服务提供商的端点设置位于**凭据管理**中。如果模型服务器在另一台电脑上，请参阅[本地模型](/zh/ai/local-llm)。

只有 Enconvo 自己的窗口可以更改已保存密钥的发送目标：服务提供商或凭据的地址，或 MCP 服务器对已保存密钥的使用。其他使用本地 API 的程序、手机和智能体都会被拒绝。

## 密钥的保存方式

- 每个保存的密钥和登录信息都会使用保留在这台 Mac 钥匙串中的密钥加密，因此即使复制 Enconvo 的设置文件夹，也无法在另一台电脑上读取。如果你回退到旧版本的 Enconvo，需要重新输入你的密钥。
- 其他向 Enconvo 的[本地 API](/zh/advanced/cli-local-api)请求设置的程序，在每个密钥的位置只会拿到 `[hidden]`。来自商店的插件只能使用它自己的密钥和在其设置中选定的凭据。
- 只有由 Enconvo 安装且未经修改的代码才能打开已保存的密钥。设置页面仍会像以前一样显示并检查密钥。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 验证失败 | 检查所选的配置、身份验证方式、端点，以及你的服务提供商账户是否有访问权限。 |
| 一个功能正常，另一个失败 | 检查该账户是否支持这个功能和模型。当某个类别只接受 API 密钥时，页面会说明。 |
| 更改密钥后某些功能不能用了 | 配置是共用的。请测试使用该配置的其他类别。 |
| 用量区域显示**重新连接** | 登录已过期。点击**重新连接**并重新登录。 |

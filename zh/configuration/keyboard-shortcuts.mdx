Enconvo 的各个窗口和语音功能都可以用快捷键打开。**设置 → 快捷键** 列出了 Enconvo 使用的所有快捷键及其运行的命令，方便你更改快捷键或查明某个组合键的作用。你 Mac 上保存的快捷键始终优先于本指南中的默认值。

这段视频依次介绍了快捷键，以及让 Enconvo 贴合你 Mac 的其他设置：上下文感知、Appshots、本地模型、权限和保持唤醒。

## 默认快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 显示 SmartBar | **⌥Space** |
| 显示聊天窗口 | **⌃⌘X** |
| 显示应用侧边栏 | **⌃⌘E** |
| 在 Enconvo 内部打开设置 | **⌘,** |
| 开始听写 | **右侧 ⌘** |
| 启动语音命令 | **右侧 ⌥** |
| 暂停/恢复音频 | **⌥P** |

这些默认值仅在你从未设置过自己的快捷键时生效；你设置过的快捷键会保持原样。快速捕捉和 Appshots 没有默认快捷键：使用前请在各自的设置页面上设置。

## 更改快捷键

1. 打开 **设置 → 快捷键**。**核心**标签页包含主要功能，**其他快捷键**包含 AI 命令、插件、设置以及其他页面未显示的命令，**全部**则同时显示两者。
2. 在**按名称筛选…**中输入内容来查找命令。要查找某个组合键对应的命令，请点击**按快捷键查找**并按下该组合键。
3. 点击命令的快捷键字段，按下新的组合键。
4. 如果这些按键已经用于其他命令，字段会提示你。选择**在这里使用**可将这些按键移到当前命令，或选择它建议的某个空闲快捷键。
5. 切换到其他应用，试一下快捷键。

要释放某个快捷键占用的按键，请将它从命令中移除。随后出现的提示中有**撤销**，可以恢复。

**本地**标记表示该快捷键只在 Enconvo 内部有效，例如固定 SmartBar。

## 按键方式

当你单独录制一个修饰键（例如右侧 ⌘）时，字段会询问**按键方式**：

| 选项 | 命令在以下情况运行 |
| --- | --- |
| **按住或单击** | 按住该键，或单击它来切换 |
| **单击** | 单击该键开始，再单击一次停止 |
| **按住** | 按住该键，按住期间持续生效 |
| **双击** | 快速连按该键两次 |

同时按下的两个或更多修饰键算作一个快捷键。每个字段只显示其命令支持的方式，旁边的说明会告诉你该功能如何响应。

## 各功能快捷键的设置位置

除了快捷键页面，每个功能在自己的设置页面上也有快捷键设置：

| 功能 | 设置页面 |
| --- | --- |
| SmartBar | **设置 → SmartBar** |
| 灵动岛 | **设置 → 灵动岛** |
| PopBar | **设置 → PopBar** |
| 应用侧边栏 | **设置 → 应用侧边栏** |
| 听写 | **设置 → 听写** |
| 语音命令 | **设置 → 语音命令** |
| Appshots | **设置 → Appshots** |
| 屏幕涂鸦 | **设置 → 屏幕涂鸦** |
| 语音笔记 | **设置 → 语音笔记** |
| 快速捕捉 | **设置 → 快速捕捉** |
| 单个命令 | 该命令的设置（如果有**快捷键**字段） |

## 在 SmartBar 中

在 SmartBar 中输入触发字符，可以搜索某一类项目：

| 字符 | 打开 |
| --- | --- |
| **@** | 命令 |
| **#** | 要添加到消息中的上下文 |
| **$** | 技能 |
| **>** | 最近的任务 |

在 **设置 → SmartBar** 的**搜索**下可以更改这些字符。斜杠菜单包含选择模型和推理强度等操作。

要用键盘在列表中移动，请在 **设置 → SmartBar** 中选择**导航快捷键**：**macOS** 使用 **⌃N** **⌃P** **⌃F** **⌃B**，**Vim** 使用 **⌃J** **⌃K** **⌃L** **⌃H**。

## 让 Enconvo 贴合你的 Mac

同一个设置窗口中还包含视频里介绍的其他选项：

| 设置页面 | 作用 |
| --- | --- |
| **上下文感知** | 选择 SmartBar 从你刚才使用的应用中获取哪些内容：选中的文本、访达中的选中项或浏览器中的页面。**附加** 会在 SmartBar 打开时立即添加，**建议** 则提供一键添加按钮。参见[上下文感知](/zh/features/context-awareness)。 |
| **Appshots** | 用一个快捷键把你眼前的窗口添加到对话中。参见 [Appshots](/zh/features/appshots)。 |
| **本地模型** | 显示这台 Mac 上运行的 AI、它占用的内存和磁盘空间，以及每项功能的运行位置。参见[本地模型](/zh/ai/local-llm)。 |
| **权限** | 列出 macOS 允许 Enconvo 执行哪些操作以及原因；**授权** 可以修复缺少的权限。参见 [macOS 权限](/zh/configuration/permissions)。 |
| **保持唤醒** | 在你离开时阻止这台 Mac 休眠，以便你仍能从 iPhone 访问它。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 快捷键只在 Enconvo 内部有效 | 检查它是否有**本地**标记。如果没有，请在 [macOS 权限](/zh/configuration/permissions)中检查输入监控和辅助功能权限，并检查是否有其他应用占用了相同的按键。 |
| 按下快捷键后执行了别的操作 | 使用**按快捷键查找**。如果没有 Enconvo 命令使用这些按键，就是其他应用或 macOS 占用了它们。 |
| 修饰键快捷键没有反应 | 打开该快捷键，检查**按键方式**：按住、单击、双击，还是同时按下多个键。 |
| 视频里或另一台 Mac 上的快捷键不起作用 | 你的快捷键可能不同。请在 **设置 → 快捷键** 中查看当前的快捷键。 |

Enconvo 把你的数据存储在你的 Mac 上，并为你选择的功能和服务提供商使用在线服务。请求发往哪里，取决于具体功能、你选择的服务提供商、你开启的工具以及你连接的集成。本页说明每种数据流向及其对应的控制方式。

## 你的内容会发往哪里

| 操作 | 发送什么，发往哪里 |
| --- | --- |
| 云端 AI 聊天 | 你的提示词、对话上下文和你添加的附件，发送给模型服务提供商 |
| Enconvo Cloud 内容检查（2026 年 11 月 14 日起） | 你刚刚写下的文字，在 Cloud 模型收到之前发送给 OpenAI 的审核模型 |
| 云端语音识别 | 录制的音频，发送给你选择的语音服务 |
| 云端文本转语音 | 文本，发送给你选择的语音服务 |
| 云端嵌入或重排序 | 检索所需的文档和查询内容 |
| 网页搜索或网页读取 | 搜索词或 URL，发送给搜索服务或网站 |
| 本地模型推理 | 留在你的 Mac 上：模型文件下载完成后，模型在本机运行 |
| 浏览器或电脑操作工具 | 该工具获得的访问权限所允许的任何内容和操作 |
| 即时通讯渠道 | 在已连接的即时通讯服务与智能体之间传递的消息 |
| 同步 | 你打开同步后，你的聊天、设置、知识库和作品会发送到你的 Enconvo 账户或 iCloud。API 密钥只在你开启后才会以加密形式离开你的 Mac。 |

仅使用本地聊天模型，并不会让所有工具都离线运行。网页搜索、远程 MCP 工具、云端语音转写服务或云端嵌入模型仍会通过网络发送内容。

## Enconvo Cloud 的使用规则

从 2026 年 11 月 14 日起，Enconvo Cloud 会在每条消息到达 Cloud 模型之前，按照我们的[使用条款](https://www.enconvo.com/terms)进行检查。只检查你刚刚写下的文字，不检查之前的对话、你的文件或图片。使用你自己的 API 密钥或本地模型时，一切照旧。

- **保留哪些信息：**如果某条消息被拒绝或被标记，Enconvo 会保留账户、时间、模型和评分，最长 90 天，但绝不保留消息内容。
- **被拒绝的消息：**它不会到达模型，也不消耗点数。聊天中会显示拒绝原因。
- **多次被拒绝：**可能会导致你账户的 Cloud AI 被暂停。你仍然可以登录、管理或取消订阅，以及删除账户。订阅会一直持续，直到你取消。
- **如果我们判断错了：**请发送邮件至 support@enconvo.com。

为了让服务提供商的安全措施只作用于单个账户，而不是所有人，Enconvo Cloud 还会在每次请求中向 OpenAI 和 Anthropic 发送一个由你的账户生成的单向标识符。它不是你的电子邮件地址。详情请参阅[隐私政策](https://www.enconvo.com/privacy)。

## 控制你发送的内容

发送请求前，请检查附件和上下文。Appshots、截图、选中的文本、剪贴板内容和浏览器页面包含的信息，可能比你想问的那句话多得多。

在[上下文感知](/zh/features/context-awareness)中选择上下文来源。只为你使用的功能授予 [macOS 权限](/zh/configuration/permissions)，不再需要时在系统设置中撤销。

## 凭据

你可以在各服务提供商的**身份验证**部分以及[凭据管理](/zh/configuration/credentials)中管理 API 密钥和账户登录。请把本地 Enconvo 配置、备份、导出的设置和支持日志视为敏感信息，不要把密钥和账户令牌放进提示词、截图或共享文件中。

一个服务提供商配置可以在多个功能之间共用凭据。删除或替换配置之前，请检查所有使用它的功能。

<Warning>
从 Enconvo 中移除密钥并不会吊销它。如果密钥泄露，请在服务提供商自己的网站上吊销它。
</Warning>

## 工具与集成

智能体可以通过你开启的工具执行操作。浏览器控制、电脑操作、Shell 命令、文件编辑、Gmail 和外部 MCP 服务器各自能触及不同的内容。当智能体处理重要数据时，请检查它的工具以及它提议的操作。

在独立的 worker 中运行扩展，并不能阻止它访问你的本地文件或网络。请只从你信任的来源安装工具，并检查它们的配置。

聊天中的 **权限** 标签决定智能体何时在行动前先询问。处于 **完全访问** 时，它会直接行动而不询问，包括向你的好友和队友打电话或发消息，仅在可能损害电脑的更改前询问。参见 [Enconvo 为何在命令运行前询问](/zh/configuration/sandbox)。

要将智能体的 shell 命令限制在工作文件夹内，远离你的密钥、已保存的凭据和其他应用，请开启它的 **沙盒**。参见[智能体沙盒](/zh/configuration/sandbox)。要阻止电脑操作访问特定应用，请使用 **设置 → 电脑操作** 中的 **应用访问**；参见[电脑操作](/zh/features/computer-use)。

网页读取无法被公开页面重定向到你的 Mac 或本地网络。

## 登录链接

来自网页的登录链接无法自行将 Enconvo 切换到另一个账户。除非登录是由 Enconvo 自己发起的，否则它会先向你询问，并显示该链接将确认的账户以及它将替换的账户。智能体、编程智能体和定时任务都无法发起登录或打开登录链接。

## 本地 AI 客户端

[知识库 MCP](/zh/advanced/knowledge-base-mcp) 在你开启之前始终关闭，并且只接受本地连接。它的可见性开关决定公开哪些知识库。本地客户端可能会把检索到的内容发送给它自己的 AI 服务提供商，因此设置该客户端时也请谨慎。

## 分析数据与诊断

Enconvo 以设备 ID（而不是你的账户）记录产品使用事件。这些事件在设计上不包含电子邮件地址、对话文本和媒体。如果不想分享，请在首次引导中关闭 **分享匿名产品分析数据**，或在 **设置 → 通用** 的 **隐私** 下关闭 **分享匿名产品分析数据**。你之前做出的选择会保持不变。崩溃和卡死报告仅在该开关打开时发送，且不包含你的任何内容。

Enconvo 不会在你的 Mac 上的日志中保留你的 AI 请求、消息或输入内容的副本。

诊断日志与分析数据是分开的。当 Enconvo 卡死、崩溃或行为异常时，可以通过菜单栏菜单中的**提交诊断信息…**或在 **设置 → 诊断** 中，把日志发送给 Enconvo 团队：

- 在任何内容离开你的 Mac 之前，Enconvo 会先去除个人信息，例如你的用户文件夹名称、文件名、电子邮件地址、API 密钥、令牌、链接、IP 地址，以及提示词和回复的文本。
- 报告携带一个专为诊断生成的随机 ID，而不是你的账户或电子邮件。只有 Enconvo 团队可以查看，并会在一定天数后删除。
- 日志仍可能包含你使用过的应用、命令和模型的名称。
- 页面会准确显示发送了什么，并允许你撤回或删除每份报告。

当你通过其他方式分享日志或截图时，请先检查一遍，删去不必要的私人提示词、路径、密钥、账户信息和文档内容。

## 保留或移除本地数据

每个功能各自管理自己的数据：聊天记录、知识库、录音和凭据都有各自的控制项。请仔细阅读删除确认提示，并备份你需要的内容。删除聊天记录也会同时删除你附加到其中的图片和文件，除非其他聊天中仍在使用它们。

卸载应用并不总是会删除它的配置和数据。删除本地数据也不会删除外部服务已经处理过的副本。关于服务提供商的数据保留和账户政策，请查看该服务提供商的说明：本页只介绍 Enconvo 的数据流向，而不是它们的。

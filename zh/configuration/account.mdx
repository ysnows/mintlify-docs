你的 Enconvo 账户保存着你的套餐、Cloud 点数以及使用它们的 Mac。你在 **设置 → 账户** 中登录。设置侧边栏中它下方的页面包括团队、同步、点数用量、用量统计、邀请好友和兑换代码。工作区位于 **设置 → 工作区**。

这段视频依次介绍了你的账户、团队、工作区和同步。

<Note>
Enconvo 账户、服务提供商 API 密钥和服务提供商订阅登录是各自独立的连接。使用你自己 API 密钥的请求，按该服务提供商账户的计费和限额执行。订阅登录会在服务提供商的设置页面上显示自己的用量，与 Enconvo Cloud 点数分开计算。参见[凭据](/zh/configuration/credentials)。
</Note>

## 登录

1. 打开 **设置 → 账户**。
2. 点击 **登录**，或点击 **注册** 创建账户。
3. 在浏览器中完成登录。如果浏览器中已经登录，网页会询问你要使用哪个账户。随后 Enconvo 会带你回到应用。
4. **个人资料** 会显示你登录所用的名称和电子邮件。

在登录完成之前，聊天窗口侧边栏中的卡片会持续跟踪登录进度，直到你的账户加载完成。如果网络较慢，卡片会给出提示；如果账户未能加载，则会提供 **重试**。如果登录失败或被你取消，请再次点击 **登录**。

要退出登录，请点击页面底部的 **退出登录**。

### 更换个人头像

你的个人头像会展示给好友、团队成员以及会议中的其他人。如果你使用 Google 登录，在更换其他头像之前会一直显示你的 Google 头像。

1. 在 **设置 → 账户** 中，点击头像旁边的 **更换头像**；如果还没有头像，则点击 **添加头像**。
2. 选择 **上传照片…** 并选取一张图片。
3. 拖动照片使其位于圆圈内，用滑块调整缩放，然后点击 **保存**。

同一菜单中还有 **使用 Google 头像**（可恢复为你的 Google 头像）和 **移除头像**（改为显示你的首字母）。

### 添加邮箱或密码

**设置 → 账户** 中的 **登录方式** 部分会显示你账户当前的登录方式。如果你使用 Apple 登录并启用了隐藏邮件地址，邮箱会显示为已被 Apple 隐藏。

1. 点击 **添加邮箱**，输入你自己的邮箱地址，然后输入发送给它的验证码。之后你就可以用该邮箱登录。
2. 点击 **设置密码**，以便在 enconvo.com 和 Enconvo 反馈页面上使用邮箱和密码登录。如果你已经设置了密码，按钮会显示为 **重设密码**，且无需输入旧密码。

iPhone 和 Android 应用中也有同样的设置项。

## 查看套餐和点数

**设置 → 账户** 会显示你的账户拥有的内容：

| 区域 | 显示内容 |
| --- | --- |
| **点数** | 你的 **总余额**。**查看用量** 会打开点数用量，**充值** 可以购买更多点数。 |
| **终身许可证** | 你的许可证等级（**Standard** 或 **Premium**）、购买时间、更新和支持的有效期，以及你的设备。没有许可证时，**获取终身版** 会显示可选方案；提供免费 Standard 试用时，会出现 **开始试用**。 |
| **团队** | 当你是团队管理员时，显示你的席位和 **管理团队**。 |
| **Enconvo Cloud** | 你的 Cloud 等级、计费周期、下次扣费日期、点数重置时间和你的设备。**获取 Cloud 套餐** 或 **升级** 可以更改套餐，**查看价格** 会打开模型和服务的费率。 |

页面底部的 **管理账单** 会在浏览器中打开你的账单详情。如果终身版购买仍可退款，那里还会出现 **申请退款**。退款后，账户会恢复为免费套餐，并扣回赠送的点数。

### 设备

每个套餐可用于一定数量的 Mac，**设备** 会显示你已经使用了多少台。达到上限时，页面会显示 **已达到设备数量上限**，这台 Mac 将无法运行命令。点击 **管理设备**，移除一台不再使用的 Mac，然后激活这一台，或选择支持更多设备的套餐。

## 团队

团队让你可以购买席位，并通过电子邮件把每个席位分配给一个人。每个人都用自己的账户登录，你可以与他们共享 Cloud 点数。只有团队管理员能在设置侧边栏中看到 **团队**。

1. 打开 **设置 → 团队**。顶部会显示 **已分配席位**、**空闲席位** 和 **充值点数**。
2. 在 **分配席位** 下，输入对方登录 Enconvo 所用的电子邮件，然后点击 **分配**。
3. 在对方首次登录 Enconvo 之前，席位会显示 **待生效**，之后显示 **已激活**。

对方的账户会在一台 Mac 上获得 Premium 功能和终身更新，其聊天、记忆和知识库保持私密。你只能看到席位和点数总额。

每位成员的 **席位操作** 菜单包含：

| 操作 | 作用 |
| --- | --- |
| **转入点数** | 将点数从你的充值余额转到对方的余额。这些点数永不过期。 |
| **收回点数** | 将对方尚未使用的点数转回你的充值余额。 |
| **取消分配席位** | 立即将对方的账户恢复为免费版。账户数据会保留，转入的点数会退回给你。对于你自己的席位，此项为 **放弃你的席位**。 |

每个席位对应一台 Mac。点击某一行上的 **+**，可让该账户（包括你自己的）在更多 Mac 上登录。**增加席位** 可以购买更多席位。

**团队知识库** 列出了与团队中所有人共享的知识库。要共享一个知识库，打开它的 **⋯** 菜单并开启团队访问。成员自己的知识库在他们主动与团队共享之前会保持私密。

## 工作区

工作区把客户或工作任务与你自己的日常事务分开。每个工作区都有自己独立的聊天、记忆、知识、登录信息和设置，不同工作区之间互不显示。如果工作区中某项设置从未修改过，它会跟随你自己的 **个人** 工作区。

### 创建工作区

1. 在聊天窗口侧边栏顶部，点击工作区菜单（显示为 **个人**），然后选择 **新建工作区…**。你也可以在 **设置 → 工作区** 中点击 **新建工作区…**。
2. 首次使用时，一段简短引导 **什么是工作空间？** 会说明三件事：**工作互不干扰**、**在侧边栏顶部切换**，以及 **从“个人”开始**。点击 **继续**。
3. 输入 **工作区名称**（例如你服务的客户名称），然后点击 **创建**。

聊天窗口会在新工作区中打开。它的聊天、记忆和知识库最初为空，个人工作区中的任何内容都不会出现在这里。

### 切换工作区

点击聊天窗口侧边栏顶部的工作区菜单并选择一个工作区。或者按 **⌃⌘1** 到 **⌃⌘9**：数字对应工作区在列表中的位置，因此 **⌃⌘1** 就是个人工作区。

每个窗口在各自的工作区中运行，多个工作区的任务可以同时进行。

### 哪些内容会隔离

每个工作区都有自己独立的聊天、记忆、知识、登录信息和设置。编程智能体聊天会留在它们启动时所在的工作区中，而新建的[空间](/zh/features/spaces)也会在每个工作区中保留各自的数据。新建的工作区会沿用你个人工作区中的设置，直到你在该工作区中修改它。

如果想为某个工作区中的连接器指定专用账户，请先切换到该工作区，在插件页面中打开该连接器，然后在对应账户的 **⋯** 菜单中选择 **设为默认**。该账户会显示 **……的默认账号** 及工作区名称，除非你在请求中另外指定其他账户，否则智能体在该工作区中都会使用这个账户。

如果你是团队管理员，可以在 **团队** 页面中将每位成员放入一个或多个工作区。之后成员就只能看到、联系并呼叫与自己处于同一工作区中的队友。

### 重命名或删除工作区

打开 **设置 → 工作区**。**个人** 始终排在第一位：它是每个工作区起始设置的来源，且无法重命名或删除。

其他每个工作区所在的行都提供 **重命名** 和 **删除**。删除工作区会一并移除其中的聊天、记忆、知识和设置。已删除的工作区会在 **最近删除** 中保留 7 天，你可以在那里点击 **恢复** 把它找回。

你也可以让智能体列出、创建、重命名、更改颜色、调整顺序、删除或恢复你的工作区。它在删除前会先向你确认。

## 同步你的 Mac

同步会让登录你账户的每台电脑上的聊天、设置、技能、插件、知识库和作品保持一致。它包含在 Enconvo Cloud 套餐和终身许可证中。

1. 在每台电脑上登录同一个 Enconvo 账户。
2. 打开 **设置 → 同步**，打开 **多台电脑同步**。
3. 如果 Enconvo 询问同步内容的存放位置，请选择你的 **Enconvo 账户** 或 **iCloud**。你以后可以在 **存储** 下更改。
4. 在 **同步内容** 下，选择要包含的内容。

| 项目 | 同步的内容 | 保留在这台电脑上的内容 |
| --- | --- | --- |
| **聊天** | 聊天记录及其中的图片和文件、标题、项目和已归档的聊天 | |
| **设置** | 模型、提示词、插件偏好设置、你的片段，以及你创建的 AI 命令、智能体和工作流 | 登录信息、快捷键和文件夹路径 |
| **技能** | 你安装或创建的技能，以及每项技能是否开启。从 GitHub 安装的技能会保留其来源，以便你的其他电脑也能检查更新 | 随插件附带的技能仍随插件保留 |
| **插件** | 你从 Enconvo 商店、GitHub、npm 或链接安装的插件：你的其他电脑也会安装它们，并在你卸载时同步卸载 | 内置插件、你正在开发的插件、连接器和登录信息 |
| **知识库** | 你的知识库和记忆，包括其中的笔记、文本和网页 | 导入的文件和录音 |
| **作品** | 你的[作品](/zh/features/artifacts)及其所有版本：页面、文档、设计、幻灯片、仪表盘、图片和视频。当两台 Mac 同时修改同一项时，两个版本都会保留 | 超过 32 MB 的文件，以及共享文档和设计 |
| **API 密钥** | 内置服务提供商的 API 密钥，离开这台电脑前会先加密 | 登录信息和自定义服务提供商 |

密码和登录信息永远不会离开电脑。以 Enconvo 账户作为存储时，新电脑必须得到你其他某台电脑的允许，才能获取你的 API 密钥：确认两台电脑显示的代码相同，然后点击 **允许**。设置 **备用密码短语** 后，即使手边没有你的其他电脑，也能让新电脑获取 API 密钥。使用 iCloud 时，登录同一 iCloud 的 Mac 会自动获取密钥。

**立即同步** 会马上进行同步，**你的电脑** 列出了所有参与同步的电脑。**清除同步数据** 会从所有电脑上删除同步到你账户或 iCloud 的全部内容。你电脑上的内容会保留，这台电脑上的同步会关闭，其他电脑上的同步会暂停，直到你重新打开。

## 点数用量和用量统计

**设置 → 点数用量** 显示你的 Enconvo Cloud 点数：

- **总余额**：你现在可以使用的全部点数。订阅点数会优先使用。
- **订阅余额**：你每月或每年的额度，每次续订时重置为套餐额度。
- **充值余额**：来自充值包和终身许可证的点数，永不过期。
- 按模型划分的每日用量图表，以及每笔扣费的 **历史记录**。

在 **历史记录** 中，可以按 **记录类型** 和 **模型** 筛选，使用 **跳到日期** 跳转到某一天，并查看每天消耗的点数。

**设置 → 用量统计** 显示 Enconvo 调用的所有 AI 服务提供商（包括你自己的密钥）的费用、Token 数和请求数。你可以在 **费用**、**Token 数** 和 **请求** 之间切换，选择 **24h**、**7d**、**30d** 或 **90d**，并按模型、服务提供商或功能细分数据。费用是按服务提供商 API 标价估算的。

## 邀请好友

**设置 → 邀请好友** 会给你一个邀请链接和邀请码。用 **复制链接** 或 **复制代码** 分享它们。

临时邮箱或智能体邮箱无法使用邀请码。当好友通过你的邀请注册，并在一台从未使用过 Enconvo 的设备上登录 Enconvo 应用后，你们双方都会获得点数。邀请好友的数量没有上限，在网页端登录不计入。**你的邀请记录** 会显示谁已加入，以及你获得的奖励。

如果有好友邀请了你，请在 **有邀请码吗？** 下输入对方的邀请码，然后点击 **兑换**。

## 兑换代码

1. 打开 **设置 → 兑换代码**。
2. 粘贴代码或包含代码的链接，然后点击 **继续**。

许可证代码和无需绑卡的试用会立即在你的账户上生效。团队许可证代码会让你的账户成为该代码所含席位的团队管理员，每个席位附带 50,000 Cloud 点数；参见[团队](#团队)。需要绑卡的试用会在浏览器中打开结账页面，并在你确认之前显示续订条款。

## 关于你

要让智能体了解你，请打开 **设置 → 关于你**。你所有的智能体、语音通话和虚拟形象都会使用你在这里写下的内容，因此只添加你希望用于个性化回复的内容。

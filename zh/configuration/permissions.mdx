---
title: "macOS 权限"
description: "了解 Enconvo 使用哪些 macOS 权限，授予功能所需的权限，并解决截屏或输入失效的问题。"
---

Enconvo 的一些功能需要经你在 macOS 中批准的访问权限，例如查看屏幕或在其他应用中输入文字。**设置 → 权限** 列出了每项权限、它支持的功能，以及是否已授权。文字聊天不需要任何权限。因此 Enconvo 不会在启动时索要权限：它会在你第一次使用需要权限的功能时请求，并说明是哪个功能在请求。

## Enconvo 何时请求权限

当你使用需要尚未授予的权限的功能时，Enconvo 会打开权限窗口，点名是哪个功能需要该权限，并提供 **打开系统设置**。你也可以选择 **暂不**。

要停止让某个功能继续询问，请在窗口中勾选该功能对应的 **不再询问**。此后该功能将不再请求，直到你在权限页面中更改它。对于屏幕录制，如果权限只是等待重新启动应用即可生效，窗口会提供 **重新打开**。

## 授予权限

1. 打开 **设置 → 权限**。
2. 找到该权限并点击**授权**。
3. macOS 会弹出提示，或打开 **系统设置 → 隐私与安全性** 中对应的面板。对于辅助功能和输入监控，请在该面板中自行打开 Enconvo 的开关。
4. 如果 macOS 要求，请退出并重新打开 Enconvo。
5. 回到 Enconvo 后，该行会显示**已授权**。再试一次该功能。

你回到这个页面时，它会自动重新检查。点击**刷新**可立即检查。

## 查看哪些功能使用某项权限

在每项权限下方，**使用方** 列出了需要该权限的功能，以及每个功能是否会发起询问：

| 状态 | 含义 |
| --- | --- |
| **使用时询问** | 下次使用该功能时请求权限。 |
| **已拒绝 · 按快捷键时询问** | 你之前拒绝了请求；只有当你按下该功能的快捷键时，它才会再次询问。 |
| **不会询问** | 你选择了 **不再询问**。点击即可恢复为 **使用时询问**。 |
| **已关闭** 或 **插件已关闭** | 该功能或其所属插件已被关闭。 |

## 各项权限的用途

| 权限 | 用于 |
| --- | --- |
| 辅助功能 | 读取应用界面、点击、输入和窗口控制：电脑操作、PopBar、选中文本和插入文本 |
| 屏幕录制 | 让智能体看到应用内容的截图：电脑操作、Appshots、屏幕上下文和 OCR 截取。macOS 可能称其为“录屏与系统录音”，它同时涵盖系统音频录制。 |
| 输入监控 | 在其他应用位于前台时，为 PopBar、快捷键和双击修饰键触发接收全局键盘输入 |
| 麦克风 | 听写、语音命令、语音笔记、会议录音、实时字幕和 Live Talk |
| 通知 | 在智能体会话完成或需要你处理时发送 macOS 通知 |
| 相机 | 通过 SmartBar 的相机开关拍摄实时照片 |
| 位置 | 灵动岛中的本地天气，以及提供给智能体的位置上下文 |
| 自动化 | 通过 Apple 事件控制其他应用：读取浏览器标签页、访达中的选中项、邮件、信息和 System Events |
| 本地网络 | 连接局域网内另一台电脑上的模型服务器。它不在权限页面上，请在**系统设置 → 隐私与安全性 → 本地网络**中找到它。 |

日历、提醒事项、备忘录、邮件和其他 Apple 应用则在**插件**页面中连接。参见 [Apple 应用](/zh/integrations/apple-ecosystem)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 权限已打开，但截取仍然失败 | 退出并重新打开 Enconvo，然后再试一次。确认你打开的是正在运行的 Enconvo 应用，而不是旧的副本。 |
| 某个功能从不请求其所需的权限 | 在 **使用方** 下查看它所在的行。如果显示 **不会询问**，请点击它，或使用 **授权** 授予该权限。 |
| 屏幕录制显示已授权但截取仍然失败 | 在权限窗口中点击 **重新打开**，或退出并重新打开 Enconvo。 |
| 听写显示了文字但没有插入 | 检查辅助功能权限，并确认目标输入框接受输入或粘贴。 |
| 快捷键只在 Enconvo 内部有效 | 检查输入监控和辅助功能权限。如果快捷键与其他应用冲突，请参阅[键盘快捷键](/zh/configuration/keyboard-shortcuts)。 |
| 无法连接另一台电脑上的模型服务器 | 检查本地网络权限，并确认服务器在其网络地址上监听。 |
| 智能体完成时没有横幅通知 | 检查这里的通知权限、macOS 的专注模式，以及[通知](/zh/configuration/notifications)中的**发送系统通知**。 |

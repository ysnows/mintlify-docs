title: "智能体沙盒"
description: "将智能体的 shell 命令限制在工作文件夹内，远离你的密钥和其他应用，并了解 Enconvo 为何在运行命令前询问。"
---

沙盒（Sandbox）会限制智能体的 shell 命令可以访问的范围。开启后，命令只能修改聊天的工作文件夹和临时文件夹，macOS 会阻止它读取你的密钥、控制其他应用或连接 Enconvo。当智能体需要运行你不想逐条盯着的命令时，就可以开启它。

沙盒与智能体的权限模式配合工作。权限模式决定 Enconvo 何时在行动前先询问；沙盒则限制命令一旦运行起来能做什么。

## 开启沙盒

1. 在聊天窗口、SmartBar、灵动岛、应用侧边栏或项目的主对话中打开与该智能体的聊天。
2. 点击运行模式旁的 **权限** 标签。
3. 开启 **沙盒**。

这个开关属于该智能体，因此你在任何窗口中使用这个智能体时都会生效。它调用的其他智能体也会在沙盒中运行命令。

要查看沙盒允许该智能体的命令访问哪些位置，请点击开关下方的 **沙盒的工作原理**。它会绘制出该智能体自己的沙盒：它的工作文件夹、它的权限模式，以及命令可以或不能访问的每一处位置。

## 沙盒中的命令可以访问什么

| 位置 | 在沙盒内 |
| --- | --- |
| 工作文件夹和临时文件夹 | 可以读取和修改 |
| 你的其他文件 | 可以读取，不能修改 |
| 互联网 | 可以连接 |
| 密钥和密码，例如 SSH 密钥、钥匙串和 Cookie | 无法读取 |
| 已保存的凭据和 Enconvo 的设置 | 无法读取 |
| 其他应用 | 无法打开或控制 |
| Enconvo | 无法连接 |

命令启动的每一个程序也都会在沙盒内运行。Enconvo 使用的是 macOS 自带的沙盒，与 App Store 应用使用的是同一种机制。

## 当沙盒阻止某条命令时

当命令试图访问沙盒禁止的内容时，macOS 会拒绝，并且在该步骤下方会有一行提示说明被阻止了什么，例如向某个文件夹写入或读取某个密钥文件。

1. 点击这行提示，查看被阻止的内容和原因。
2. 要允许该命令执行，点击 **在沙盒外运行**。命令会以你的完整权限运行一次，然后像其他命令一样显示在聊天中。此选择不会被记住。

只有在当前运行仍在进行且有人值守查看时，才会提供 **在沙盒外运行**。定时任务和其他无人值守的运行绝不会在沙盒外执行命令。

## Enconvo 为何在命令运行前询问

无论是否开启沙盒，都由智能体的权限模式决定什么时候需要询问。参阅[批准操作](/zh/ai/agents)。

| 模式 | 开启沙盒时 |
| --- | --- |
| **请求批准** | 每条命令运行前仍会询问。沙盒限制的是你允许的命令能做什么。 |
| **替我批准** | 命令无需询问即可运行，但删除文件或发布等有风险的操作除外。 |
| **完全访问** | 命令无需询问即可运行。只有可能损害电脑的更改才会询问。 |

Enconvo 会逐段解析每条命令，因此隐藏在引号、嵌套、串联或管道中的危险步骤仍会询问，而输出文本或列出文件夹这类无害操作则不会。

即使在 **完全访问** 模式下，在执行可能损害电脑的更改（例如删除关键文件夹、编辑你的 shell 启动文件或 SSH 密钥，或读取已保存的密码）之前，无论命令如何书写路径，Enconvo 都会通过 **仅允许一次** 和 **拒绝** 向你确认。

在 **替我批准** 模式下，规则无法直接判断的命令会对照你的要求进行检查。当它看起来不像你预期会自动执行的操作时，Enconvo 会询问你并说明原因。

每张批准卡片都会写明触发询问的设置，例如“因为此项目处于‘替我批准’模式而询问”。

## 其他会询问的操作

- [电脑操作](/zh/features/computer-use)在按下会删除、发送、付款、退出应用或登出的键盘快捷键之前会询问，就像点击这类按钮时一样。
- 调用插件页面自身路由的命令会先询问。
- 批准插件的工具时，会显示该工具即将发送的内容。
- 智能体在给你的[好友](/zh/features/friends)和队友打电话或发消息前会询问，处于 **完全访问** 模式时除外。
- 智能体无法自己回应批准卡片、提升自己的权限，也无法回应原本应由你决定的卡片（例如插件安装或点数上限）。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 命令因权限错误而失败 | 可能是沙盒阻止了它。点击步骤下方的提示行，如果你信任该命令，再点击 **在沙盒外运行**。 |
| 智能体无法通过命令打开或控制某个应用 | 沙盒中的命令不能控制其他应用。请改用[电脑操作](/zh/features/computer-use)，或为该智能体关闭沙盒。 |
| 你以为 Enconvo 会询问，但它没有 | 在 **权限** 标签中检查智能体的权限模式。**完全访问** 只在可能损害电脑的更改前询问。 |
| 找不到 **沙盒** 开关 | 确认当前聊天处于智能体模式，并更新 Enconvo。参阅[更新](/zh/configuration/updates)。 |

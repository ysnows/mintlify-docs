智能体会话完成时，Enconvo 可以通过展开灵动岛、发送 macOS 通知，或两者兼用来通知你。你可以在 **设置 → 通知** 中进行设置，还可以为不想被打扰的时间设置安静时段。

## 设置完成提醒

1. 打开 **设置 → 通知**。
2. 如果页面显示 **Enconvo 的通知已关闭**，请点击**启用**，或在**系统设置 → 通知**中允许 Enconvo。
3. 在**会话结束时**下，打开或关闭各个开关。它们互不影响。
4. 发起一个简短的智能体请求，等待它完成。

| 设置 | 作用 |
| --- | --- |
| **打开灵动岛** | 当你从灵动岛发起的会话完成时，灵动岛会展开显示结果。 |
| **发送系统通知** | 会话完成时发送一条带有回复开头的 macOS 通知。点击通知会在会话发起时所在的窗口中重新打开该会话。 |

即使这些开关已打开，macOS 的专注模式和通知设置仍可能隐藏横幅。

## 安静时段

安静时段会把智能体的提问、邮件提醒和已完成的任务暂缓到安静时间结束，在这台 Mac 和已配对的 iPhone 上都是如此。等待期间，不会有任何内容被代你批准。

1. 在 **设置 → 通知** 中找到**动态**。
2. 打开**安静时段**，然后设置**开始时间**和**结束时间**。
3. 选择哪些内容仍然可以通过：

| 设置 | 作用 |
| --- | --- |
| **批准请求照常提醒** | 安静时段内，批准请求仍会发送给你。 |
| **提问照常提醒** | 安静时段内，智能体的提问仍会发送给你。 |

Enconvo 的菜单栏菜单中也有**安静时段**，以及用于短暂休息的**暂停动态 1 小时**。

邮件提醒默认关闭，直到你在 **自动化 → 重要邮件** 中将其开启。你此前已经开启或设置过的邮件提醒会继续工作。其中的 **手机** 开关会将提醒发送到已配对的 iPhone 或 Android 手机。

## 定时任务结果

系统通知与把定时任务的结果发送到 Telegram 或其他即时通讯聊天是两回事。结果的发送方式在[定时任务](/zh/workflows/scheduled-jobs)的编辑器中设置。

定时任务在运行时也可以发送自己的 Mac 通知（**运行时通知我**）。这条通知同样受**发送系统通知**控制。任务的运行历史会显示每次运行是否成功，以及结果是否已送达。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 会话完成时没有横幅通知 | 确认**发送系统通知**已打开，macOS 允许 Enconvo 发送通知，并且专注模式没有隐藏它们。 |
| 灵动岛没有展开 | **打开灵动岛**只适用于你从灵动岛发起的会话。 |
| 提问或已完成的任务来得晚了 | 可能被安静时段暂缓了。打开**提问照常提醒**，或更改**开始时间**和**结束时间**。 |

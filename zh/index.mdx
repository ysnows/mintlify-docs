Enconvo 让你在 Mac 上的每个应用里，一个快捷键就能用上 AI。提问、口述一条消息、改写选中的文字，或把整项任务交给智能体，都无需离开手头的工作。

## 选择你的 AI

想零配置，就从 [Enconvo Cloud](/zh/providers/enconvo) 开始；也可以用已付费的套餐（如 ChatGPT 或 Claude）登录、添加自己的 API 密钥，或在 Mac 上运行模型。[服务提供商](/zh/providers/overview)一页对比了这些选项。

## 随身带着走

[iPhone 应用](/zh/integrations/iphone-app)可以与 Mac 上的智能体对话，而[手机聊天](/zh/integrations/iphone-phone-chats)直接在 iPhone 上运行。

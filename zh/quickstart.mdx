description: "大约五分钟内安装 Enconvo、连接模型，并提出第一个问题。"
---

本页带你从下载走到第一个回答。你将安装应用、选择 Enconvo 连接 AI 的方式，并在 SmartBar 中提出一个问题。

<Steps>
  <Step title="安装并打开 Enconvo">
    从 [enconvo.com](https://www.enconvo.com) 下载 Enconvo，打开 DMG，把 **Enconvo** 拖到 **应用程序** 中，再从那里打开它。Enconvo 需要 macOS 14 或更高版本。详情参见[安装](/zh/installation)。
  </Step>
  <Step title="选择 Enconvo 连接 AI 的方式">
    最简单的方式是登录你的 Enconvo 账户。默认模型 [Auto Route](/zh/providers/auto-route) 随即通过 [Enconvo Cloud](/zh/providers/enconvo) 作答。你可以随时切换：

    | 方式 | 操作 |
    | --- | --- |
    | Enconvo Cloud | 登录你的 Enconvo 账户。 |
    | 你已付费的套餐 | 用 [ChatGPT](/zh/providers/openai_subscription)、[Claude](/zh/providers/anthropic_subscription)、[Grok](/zh/providers/xai)、[GitHub Copilot](/zh/providers/github-copilot) 等账户登录。 |
    | 你自己的 API 密钥 | 打开 **设置 → AI 模型**，选择一个服务提供商，粘贴密钥。 |
    | Mac 上的模型 | 设置一个[本地模型](/zh/ai/local-llm)。 |
  </Step>
  <Step title="提出第一个问题">
    按 **⌥Space** 打开 SmartBar，输入一个问题，比如让它列一份三项的高效早晨清单，然后按 Return 查看回答。
  </Step>
  <Step title="在你自己的文字上试试">
    在任意应用中选中一段文字。[PopBar](/zh/features/popbar) 出现在旁边后，点击 **解释** 或 **翻译**。
  </Step>
</Steps>

<Tip>
想跟着引导体验 SmartBar、聊天窗口、听写、[语音草稿](/zh/features/dictation)、语音命令、PopBar 和应用侧边栏，请打开 **设置 → 通用**，点击 **指南导览** 旁的 **开始导览**。导览使用 Enconvo 的界面语言，全程大约三分钟。
</Tip>

Enconvo 不会在启动时请求 macOS 权限。当你第一次使用需要权限的功能（例如麦克风或屏幕录制）时，Enconvo 会说明该功能的名称并届时向你请求。每项权限的用途参见[权限](/zh/configuration/permissions)。

## 如果没有反应

| 问题 | 解决办法 |
| --- | --- |
| 按 **⌥Space** 打不开 SmartBar | 在 **设置 → SmartBar** 中检查快捷键，或使用 Enconvo 菜单栏图标。 |
| SmartBar 打开了，但没有回答 | 登录你的 Enconvo 账户，或在 **设置 → AI 模型** 中检查服务提供商。 |
| PopBar 没有出现 | 授予辅助功能权限。参见[权限](/zh/configuration/permissions)。 |

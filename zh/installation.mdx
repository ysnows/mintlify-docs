---
title: "安装"
description: "在 Mac 上安装 Enconvo、保持更新，并解决安装问题。"
---

Enconvo 可在 macOS 14 或更高版本上运行，支持 Apple 芯片和 Intel 芯片的 Mac。部分本地功能（例如[本地 LLM（MLX）](/zh/providers/mlx)）需要 Apple 芯片，本地模型还需要足够的内存和磁盘空间。

在 Windows 10 和 11（x64）上，Beta 版可作为桌面应用运行。参见 [Windows（Beta）](/zh/getting-started/windows)。

在 Linux 上，Beta 版可在桌面端和服务器上运行。参见 [Linux（Beta）](/zh/getting-started/linux)。

## 安装

<Steps>
  <Step title="下载">
    从 [enconvo.com](https://www.enconvo.com) 下载适合你 Mac 处理器的 DMG。
  </Step>
  <Step title="移到“应用程序”文件夹">
    打开 DMG，把 **Enconvo** 拖到 **应用程序** 中。
  </Step>
  <Step title="打开 Enconvo">
    打开 **应用程序** 中的那一份，按照欢迎步骤操作。然后继续阅读[快速开始](/zh/quickstart)。
  </Step>
</Steps>

只保留 **应用程序** 中的那一份。快捷键、权限和更新都指向同一份应用，放在其他位置的第二份可能拿到了你正在使用的那份没有的权限。

## 更新

在 Enconvo 菜单栏图标中选择 **检查更新**，或在 **设置 → 通用 → 更新** 中点击它。想更早用上新功能，请打开 **设置 → 通用**，把 **更新渠道** 设为 **测试版** 或 **开发**；默认为 **生产环境**。参见[更新](/zh/configuration/updates)。

应用和它内置的插件分别更新。如果某项功能缺失或表现不同，两者都要检查。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 应用打不开 | 确认你的 Mac 运行 macOS 14 或更高版本，并且下载已经完成。 |
| 权限已经打开，但功能仍然用不了 | 退出 Enconvo，再从 **应用程序** 中重新打开。确保没有旧版本在运行。 |
| 本地模型无法下载 | 检查磁盘空间和网络连接，并确认该模型支持你的 Mac。 |
| 找不到应用窗口 | 点击菜单栏或程序坞中的 Enconvo 图标，或按 **⌥Space** 打开 SmartBar。 |
| macOS 提示下载的文件已损坏或无法验证 | 从 [enconvo.com](https://www.enconvo.com) 重新下载一份。不要关闭 macOS 的安全设置。 |

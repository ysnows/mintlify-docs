---

**媒体** 集中存放你在 Enconvo 中制作的所有图像、视频和音频片段，无论是你在这里生成的，还是智能体在聊天中为你生成的。你可以用它对生成设置进行全面控制以创作图片和视频片段，让人物或产品在不同画面中保持一致的外观，并修复或复用已有作品。

它使用你在 **设置 → 图像生成** 和 **设置 → 视频生成** 中配置的服务提供商。配置方法请参阅[图像生成](/zh/ai/image-generation)和[视频生成](/zh/ai/video-generation)。

## 打开媒体

在聊天窗口侧边栏中点按 **媒体**。在顶部选择 **图像**、**视频** 或 **音频**。

- **全部**、**收藏** 以及你自己的文件夹用于整理作品。点按 **新建文件夹** 可添加文件夹，在项目上使用 **移到文件夹** 可将其归档。
- 在 **搜索你的媒体** 中输入提示词里的词语，即可查找对应作品。
- 点按星标即可将作品加入 **收藏**。

这些文件也保存在你的 Mac 上的 `~/Enconvo/Media` 中。

你也可以在新聊天输入框下方选择 **图片** 或 **视频**。模型、设置以及要避免的内容会以胶囊按钮的形式显示在输入框下方，下面还会列出你最近生成的图片或视频，以及一个 **打开媒体** 链接。

## 生成图片或视频

1. 在 **图像** 或 **视频** 页面底部的输入框中描述你想要的内容。
2. 检查输入框下方的胶囊选项：模型、**宽高比**、**质量**、生成数量，以及 **避免**（要排除的内容）。点按任意胶囊即可修改，或点按 **更多设置** 调整其余选项。界面只会显示所选模型支持的参数。
3. 点按 **生成**。新生成的作品完成后会显示在最上方。

一次生成多个版本时，挑选你想保留的作品即可。

### 视频的进阶控制

- **起始帧** 和 **结束帧**：添加片段开头或结尾所使用的图片。
- **添加镜头**：将视频拆分为多个镜头，每个镜头有各自的提示词和时长。Enconvo 会将它们合成为一段完整视频。
- **添加音频文件**：使用你自己的音频，或从 **音频** 中挑选一段片段。

## 保持主体或风格一致

将同一个人、宠物、产品或角色的几张照片保存为一个主体，或将几张具有目标画风的图片保存为一种风格。生成时选用它们，它们就会在每一张图片和每一段视频中保持一致的外观。

1. 在输入框中，点按 **添加主体、风格或参考图**。
2. 在 **主体** 下选择 **从照片新建**，或在 **样式** 下选择 **新建风格**。
3. 填写 **名称**，添加 **照片**，也可以选填 **描述一下**。
4. 点按 **保存**。下次生成时，从同一菜单中选择它即可。

## 精修作品

点按任意作品即可打开详情，查看它使用的提示词和每一项参数。在这里你可以进行以下操作：

| 操作 | 作用 |
| --- | --- |
| **复用设置** | 将相同的提示词和参数填入输入框 |
| **变成视频** | 以这张图片为起点生成一段视频 |
| **放大** | 生成更大、更清晰的副本 |
| **去除背景** | 抠出画面主体 |
| **重新打光** | 改变光线和氛围 |
| **修改局部** | 打开编辑器，涂抹想要修改的区域 |
| **更多修复** | **修复老照片**、**更改角度**、**扩展画布** 和 **变体** |
| **再生成几个类似的** | 用相同的配置重新生成新版本 |

每次修复都会生成一个新版本；原图会保留在 **版本** 下。点按 **在编辑器中打开** 即可在图像或视频编辑器中继续编辑。

## 生成音频

1. 打开 **音频**，选择 **音乐**、**音效** 或 **语音**。
2. 描述想要的风格或声音，或者输入旁白台词。音乐可以包含歌词，也可以设为 **纯音乐**。
3. 点按 **生成**。如需使用现有文件，请点按 **导入音频文件**。

要为视频配音，打开该视频并点按 **添加音频**。从 **你的音频** 中选择一个片段，或点按 **导入文件**，选择 **与原声混合** 或 **替换原声**，然后点按 **添加到视频**。

<Warning>
每一张图片、每一段视频和每一个音频片段都会消耗服务提供商的额度或你的 Enconvo Cloud 点数。视频消耗最多，建议先试着生成较短的片段。
</Warning>

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 图片作为主体或参考帧时被拒绝 | 请使用 PNG、JPEG 或 WebP 格式的图片 |
| 看不到想要的某个设置 | 所选模型不支持该参数；请换一个模型 |
| 某项显示 **重试** | 生成失败；请检查服务提供商的访问权限后再重试 |
| **音频** 中没有语音或模型 | 请先配置支持该音频类型的服务提供商；Enconvo Cloud 仅支持语音生成，音乐和音效需要使用你自己的 ElevenLabs 密钥 |

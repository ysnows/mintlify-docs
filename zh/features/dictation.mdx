听写会把你说的话变成文字，输入到你正在打字的任何应用中。语音命令会把你说的话发送给智能体，智能体会出声回答，并能替你执行操作。如果想进行一来一回的语音对话，请改用 [Live Talk](/zh/features/live-voice)。

下面的视频教程用不到 5 分钟完整讲解了听写：按住或轻点右侧 Command 键说话、让它从屏幕上读取名字、在词典里教它一个名字、润色或翻译你说的话，以及选择语音模型（包括可在 Mac 上运行的模型）。

## 开始之前

Enconvo 需要麦克风权限才能听到你说话。要把文字输入到其他应用中，它可能还需要辅助功能权限。参见[权限](/zh/configuration/permissions)。

## 听写到应用中

1. 在任意应用中，点击你想输入文字的文本框。
2. 按住右侧 **Command** 键说话。会出现一个小型胶囊条，表示听写正在收音。
3. 说完后松开按键。文字会输入到光标处。
4. 检查插入的文字，尤其是名字、日期和数字。

默认按住右侧 Command 键说话。如果想改为轻点一次后想说多久说多久，请打开 **设置 → 听写 → 听写快捷键** 并更改按键方式。之后再次按下快捷键或点击胶囊上的对勾即可完成。

听写会在适当位置自动在词句前后添加空格（中文、日文和泰文除外）。单独说出某个文本片段的名称或关键词，就会直接插入该片段的文本，而不是你说的那几个词。

### 使用听写卡片

听写时把鼠标指针移到胶囊上，它会展开成一张卡片，上方显示你的话，下方是控制按钮。在卡片中你可以直接切换麦克风、将此次听写转为 **起草**、选择 **清理** 选项，以及在不中断听写的情况下开关 **按回车插入并发送** 和 **实时转写**。停止后，卡片会显示清理的进度。

如果想保持胶囊小巧，请关闭 **实时转写**。此时胶囊只显示按钮和波形。

### 按 Return 发送

听写过程中按 **Return**，即可在一次按键中停止听写、插入文字并发送（例如聊天消息）。用快捷键或对勾结束则只会插入文字。可在 **设置 → 听写 → 插入 → 按回车插入并发送** 中关闭此功能。

如果想在每次听写结束时不按任何键就自动发送，请在同一个位置开启 **插入后自动发送**。

### 暂停与继续

当你通过轻点方式开始听写时，可以随时暂停：将鼠标指向胶囊上的电平指示并点击 **暂停**，或按 **⌥P**。麦克风会关闭，你之前说的内容会保留。点击 **继续** 或再次按下快捷键即可继续说话，然后像往常一样用快捷键或对勾结束。按住按键进行的听写不支持暂停。

要更改按键，请打开 **设置 → 听写 → 暂停 / 继续**。它可以是一个组合键、单个按键（如 **Space**），或一个轻点、双击或按住的修饰键。按住该键会一直暂停，直到松开为止。

### 在会议中保持静音

在 Zoom、Microsoft Teams 或 Google Meet 通话、Mac 版 Telegram 应用通话，或 Enconvo [会议](/zh/features/video-conference)中，开始听写会自动将你在通话中的麦克风静音，结束或暂停时再取消静音。这在桌面应用和浏览器标签页中均有效。如果你自己原本就静音了，则仍保持静音。如果 Enconvo 找不到通话中的静音按钮，它会提示你一次让你手动静音。可在 **设置 → 听写 → 听写时将会议麦克风静音** 中关闭此功能。

## 用语音撰写草稿

你不必口述正文内容，只需说出想写什么，听写就会为你写好草稿，供你在插入前检查。

1. 点击一个文本框，例如你正在写的回复框。
2. 同时按住右侧 **Command** 键和 **Shift** 键，说出需要表达的内容，例如“告诉她周四下午两点可以，并请她提前一天发一下新的界面稿。”
3. 松开按键。草稿在生成时会显示在听写胶囊上方的一个面板中。
4. 按 **Return** 粘贴它，或按 **Esc** 放弃。

**Return** 始终会粘贴到开始起草时的那个应用中；如果当前另一个应用在最前面，它会先切回原应用。面板顶部会显示该应用的名称。

你也可以在听写中途转成草稿：在听写时轻点一次 **Shift**（即使在松开听写键之后也可以），你前面说的话就会成为草稿的指令。

草稿面板还开着时，单独按听写键并说出要修改的地方，即可进一步完善草稿。在文本框中再次使用起草功能，可以接着文本框中已有的内容继续写。

### 改写或回复选中的文字

开始起草前先选中一段文字，再说出要如何修改。在替换选中内容之前，草稿会显示改动的对比。

当选中的文字无法编辑时（例如你收到的消息或网页上的某段文字），起草功能会将其作为参考并写出新文本，按 **Return** 时会粘贴到你切回的输入框中。可在 **发送选中的文字** 中关闭此功能。

开启 **发送 App 上下文** 后，草稿会结合你当前所在的应用来撰写，因此更贴合你正在处理的内容：例如回复邮件时，它能读取你正在回复的那封邮件中的细节。

这些设置位于 **设置 → 听写 → 起草**：

| 设置 | 作用 |
| --- | --- |
| **草稿修饰键** | 与听写快捷键同时按住以启动起草，或在听写途中单独轻点的按键。默认为 **Shift**。 |
| **标出改动** | 当草稿编辑现有文本时，标出添加和删除的词句。关闭则只显示最终结果。 |
| **发送 App 上下文** | 向模型提供应用窗口标题、网页地址和可见文本。默认开启。 |
| **附带截图** | 同时发送应用窗口的画面。需要屏幕录制权限和支持识图的模型。 |
| **发送选中的文字** | 将你选中但无法编辑的文本（如消息或网页）作为参考提供给模型。默认开启。 |
| **草稿模型** | 用于撰写和编辑每份草稿的模型。 |
| **草稿提示词** | 控制模型如何撰写和编辑每份草稿。 |

## 使用屏幕上的名字

打开 **设置 → 听写 → 感知当前应用内容** 后，听写会读取你正在输入的应用，并按照其中的写法拼写名字，比如你正在回复的消息中发件人的名字。该设置默认打开。

## 边说边润色或翻译

点击录音胶囊上的 **清理** 图标，选择你的话在插入前要经过哪种处理：

- **润色** 会去掉口头禅和说错重来的部分，并修正错别字和标点，同时保留你自己的措辞。
- **翻译** 会把你说的话以你的回复语言输入；如果你说的已经是回复语言，则输入英文。
- **本地润色** 用 Mac 上的模型离线润色文字。只有当你的 Mac 能运行它时才会出现，其模型只需下载一次。

**清理** 图标会显示当前所选选项的图标；将鼠标悬停在上面可查看名称。再次点击该图标切换到下一个选项，或按 **⌃⌥⌘I**（**听写时切换**）。要选择默认选中的选项，或用名称、提示词和模型添加你自己的选项，请打开 **设置 → 听写**，使用 **清理** 部分。

翻译和修正拼写和语法也会去除“嗯”、“啊”、结巴和说错重来的部分，使结果读起来像书面文字。它们的 **去除口头禅** 选项默认开启。

当你在某个应用中切换清理选项时，该更改只对本次听写生效。点击卡片上的 **始终使用 …** 可为该应用保留此选择，并提供 **撤销**。在已有规则的应用中，卡片会提供 **设为规则** 和 **恢复规则**。

### 选择翻译风格

要更改 **翻译** 的措辞方式，请打开 **设置 → 听写**，前往 **清理**，点击 **翻译** 这一行上的箭头，然后选择一个 **样式**：

- **标准** 准确贴近你的原话。
- **地道自然** 会自由改写，读起来就像母语者写的一样。
- **自定义** 遵循你描述的风格。

你选择的风格会以徽章形式显示在 **翻译** 这一行上。无论选择哪种风格，你说出的本身就是目标语言的文本，都会被翻译成你的另一种语言。

## 为特定应用设置规则

**设置 → 听写 → 应用规则** 可以为单个应用或网站修改听写的 **清理**、**语言** 和 **Return 键**。当规则使用翻译时，可以选择 **翻译成**，仅在该应用中翻译成另一种语言；例如在某个聊天应用中翻译成英文，而在其他地方继续保留你的常用语言。

- 为 Discord、Slack、Notion、Telegram、WhatsApp、ChatGPT、Claude、Linear、Figma 或 Teams 设置的规则同样适用于其网页版。
- 最后一行显示所有未设规则的应用使用的配置，即来自你的听写设置。
- **常听写的应用** 会建议你添加常用的应用。

在 Enconvo 自己的消息输入框中使用麦克风听写时，同样遵循 Enconvo 的应用规则（针对清理和语言）。

<Note>
润色、翻译以及你添加的选项会使用你的 AI 模型，因此即使识别是在 Mac 上完成的，识别出的文字也会发送给该模型的服务提供商。本地润色则让文字留在你的 Mac 上。
</Note>

## 选择语音模型

1. 打开 **设置 → 听写**，点击 **语音模型** 旁的 **更改**。
2. 从云端模型、在 Mac 上运行的模型以及使用你自己 API 密钥的模型中挑选。
3. 点击 **本地** 查看本地模型。它们可以离线工作，你的声音不会离开 Mac。
4. 选择一个模型。本地模型几秒钟就能加载完成。

你也可以直接打开 **设置 → 听写模型**。听写、语音命令、Live Talk、会议录音、文件转写和实时字幕各自有独立的语音模型设置。适合批量处理文件的服务提供商不一定适合流式输入。参见[语音识别](/zh/ai/speech-recognition)和[服务提供商目录](/zh/providers/catalog)。

## 教它一个名字

不在屏幕上的名字仍可能被识别错，比如一个叫“Lumyn”的项目被写成“Lumen”。

1. 打开 **设置 → 词典**，点击 **新词**。
2. 输入正确的词，然后在 **误识别为** 中输入听写实际听成的内容。
3. 点击 **保存**，然后再听写一次这个名字。

更多关于自定义词汇以及服务提供商语言和热词设置的内容，请参见[词典与说话人](/zh/configuration/speech-assets)。

## 查看过往听写

打开 **设置 → 语音输入历史记录** 可以查看过往识别的文字。在这里你可以搜索、复制、播放录音、重新转写某次听写，或把一个词添加到词典。

未能转写、耗时过长或被中断的听写会连同录音一起保留在历史记录中。点击 **重试** 即可重新转写。

## 用语音命令和智能体对话

语音命令就是智能体的对讲机。它在灵动岛上并出声回答，立即完成打开应用这类快速操作，并把较大的请求作为任务交给智能体。它不会去匹配固定的说法，而是理解你想要什么。

<Steps>
  <Step title="按住按键说话">
    按住右侧 **Option** 键，说出你的需求。你说的话会显示在灵动岛上。你也可以轻点一下按键开始。
  </Step>
  <Step title="发送">
    松开按键；如果是轻点开始的，就再轻点一次。
  </Step>
  <Step title="获取回答">
    回答显示在你的话下方，并在 **朗读回复** 打开时被朗读出来。它发起的任务会使用该智能体自己的模型和工具运行。
  </Step>
</Steps>

再按一次按键可以停止回答，还在说话时按 **Esc** 可以取消。灵动岛上的麦克风按钮也可以使用。

在 **设置 → 语音命令** 中进行设置：

| 设置 | 作用 |
| --- | --- |
| **快捷键** | 你按住或轻点的按键。默认为右侧 Option 键。 |
| **收音** | 听你说话的语音模型（默认为 **Enconvo Cloud Fast**），以及 **麦克风** 和 **语言**，除非你另行选择，否则它们与听写保持一致。 |
| **思考** | 回答你的模型。**与当前聊天相同**（默认）会在聊天使用 Enconvo Cloud 时调用 Enconvo Fast，否则调用该聊天所属服务提供商的快速模型，因此使用你自己的 API 密钥时不会消耗 Enconvo Cloud 点数。它发起的任务会使用为该聊天选择的模型运行。 |
| **回答** | **朗读回复** 以及回答所用的声音。关闭 **朗读回复** 后，回答只显示在灵动岛上。 |
| **发送截图** | 每次请求都附上你当前的屏幕，让智能体看到你看到的内容。Enconvo 的窗口不会包含在内。 |
| **快捷操作** | **管理** 会打开 **设置 → 快捷操作**，其中列出了语音命令和 Live Talk 会立即执行的操作，你可以关闭它们或创建自己的操作。 |

## 设置

以下设置位于 **设置 → 听写**：

| 设置 | 作用 |
| --- | --- |
| **听写快捷键** | 启动听写的按键，以及是按住还是轻点。默认为按住。 |
| **播放提示音** | 听写开始和结束时播放简短提示音。 |
| **麦克风** | 听写录音所用的麦克风。点击 **测试** 检查它能否听到你。当该麦克风未连接时，听写会使用你之前用过的麦克风。 |
| **听写语言** | **默认** 沿用语音模型自己的设置；**自动检测** 让它自行识别语言。 |
| **录音时静音其他声音** | 听写时暂停或静音其他应用，结束后恢复它们的声音。**静音方式** 可选择暂停、静音或两者同时。 |
| **听写时将会议麦克风静音** | 听写时自动将你在会议通话中的麦克风静音。默认开启。 |
| **暂停 / 继续** | 用于暂停和继续听写的按键。默认为 **⌥P**。 |
| **感知当前应用内容** | 读取你所在的应用来拼写名字和术语，并为润色、翻译和起草提供上下文。 |
| **显示实时转写** | 说话时实时显示文字。关闭后只显示控制按钮和波形。 |
| **按回车插入并发送** | 听写期间按 **Return** 会停止、插入文字并发送。默认开启。 |
| **插入后自动发送** | 听写结束时无需按 Return 即自动发送文字。默认关闭。 |
| **将听写文字复制到剪贴板** | 同时复制识别出的文字。 |
| **按名称插入片段** | 单独说出某个片段的名称或关键词，即可直接插入该片段的文本。 |
| **听写时切换了应用** | 听写结束时如果前台已换成另一个应用，文字要输入到哪里。默认会询问你。 |
| **应用规则** | 为特定应用或网站更改以上任意步骤。 |
| **保存听写历史** | 保留每次听写的录音和文字，保留时长由 **历史保留时长** 决定。 |

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 没有麦克风输入 | 当提示指明某个麦克风没有声音输入时，请换选另一个麦克风，或在 **设置 → 听写** 中点击 **麦克风** 旁的 **测试**。同时检查麦克风权限。 |
| 文字出现了但没有插入 | 检查辅助功能权限，点击文本框，并确认该应用允许粘贴。 |
| 按 **Return** 没有发送 | 检查 **设置 → 听写 → 插入** 中的 **按回车插入并发送**，以及该应用对应应用规则中的 **Return 键** 列。 |
| 听写失败或被中断 | 打开 **设置 → 语音输入历史记录** 并点击该条记录上的 **重试**。 |
| 识别后文字有误 | 检查正在使用的 **清理** 选项、**听写语言** 和你的[词典](/zh/configuration/speech-assets)。 |
| 停止后出结果很慢 | 批量模型要等整段录音结束才处理。请选择支持流式识别的模型。 |
| 其他功能占用了麦克风 | 先结束 Live Talk 或录音。 |

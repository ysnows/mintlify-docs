屏幕涂鸦让你在向智能体提问前，先在屏幕的某个部分做标注。画上箭头、圈、高亮或注释后发送即可。标注后的截图会作为图片附加到聊天中：默认发送到灵动岛，除非你刚刚在使用聊天窗口等其他 Enconvo 聊天。

## 在屏幕上标注

1. 把你想提问的内容切到前台。
2. 双击右键打开屏幕涂鸦，或按下你在 **设置 → 屏幕涂鸦** 中设置的 **快捷键**。
3. 如果 **先截取区域** 已打开，拖动鼠标选择区域；否则直接在实时屏幕上绘制。
4. 在工具栏中选择一个工具，标出你想指的区域。
5. 点按 **发送**（纸飞机图标）或按 **⌘↩**。
6. 查看附加的图片并输入请求，例如“高亮的这条警告是什么意思？”

在你设置之前，屏幕涂鸦没有快捷键。双击右键则开箱即用。

### 添加语音标签

按住左侧 **Option** 键并说话，描述你刚画的图形。你说的话会以文字形式显示在图形旁边。如果想让屏幕涂鸦在你每画完一个图形后都开始听，请在工具栏中打开 **画完图形后自动语音输入**，停顿一下即可结束当前标签。

## 工具

| 工具或操作 | 按键 |
| --- | --- |
| 箭头 | **A** |
| 直线 | **L** |
| 画笔 | **P** |
| 荧光笔 | **H** |
| 矩形 | **R** |
| 圆形 | **O** |
| 计数器（编号标记） | **N** |
| 文字 | **T** |
| 选择 | **V** |
| 橡皮擦 | **E** |
| 颜色 | **C** |
| 线条粗细 | **⌘** + 滚动 |
| 白板 | **B** |
| 光标高亮 | **K** |
| 另存为… | **⌘S** |
| 发送 | **⌘↩** |

工具栏中还有 **撤销**、**重做**、**清除**、**复制到剪贴板** 和 **关闭**。

## 设置

打开 **设置 → 屏幕涂鸦**。

| 设置 | 作用 |
| --- | --- |
| **先截取区域** | 绘制前先选择一个区域。关闭后可直接在实时屏幕上绘制。默认打开。 |
| **快捷键** | 打开或关闭屏幕涂鸦。默认为空。 |
| **双击右键** | 快速双击右键即可打开或关闭屏幕涂鸦。默认打开。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 叠加层打不开 | 检查 **设置 → 屏幕涂鸦** 中的 **快捷键** 和 **双击右键**，并检查 [macOS 权限](/zh/configuration/permissions)。 |
| 你只需要整个应用窗口 | 改用 [Appshots](/zh/features/appshots)。 |

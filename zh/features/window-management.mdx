title: "窗口管理"
description: "为任务挑选合适的 Enconvo 窗口，设置打开各个窗口的快捷键，并让结果保持可见。"

同样的日常工作，Enconvo 提供了多个入口。根据任务需要多少空间和上下文来选择，并设置好你最常用的快捷键。

## 选择窗口

| 窗口 | 用途 | 打开方式 | 指南 |
| --- | --- | --- | --- |
| SmartBar | 快速提问或运行命令 | **⌥Space** | [SmartBar](/zh/features/smartbar) |
| 聊天窗口 | 进行带历史记录和文件的持续对话 | **⌃⌘X** | [聊天窗口](/zh/ai/chat) |
| 应用侧边栏 | 在另一个应用旁边工作 | **⌃⌘E**，或应用窗口旁的拉手 | [应用侧边栏](/zh/features/app-sidebar) |
| PopBar | 处理选中的文字 | 选中文字 | [PopBar](/zh/features/popbar) |
| 灵动岛 | 在屏幕顶部快速输入请求并跟进会话 | 将指针移到屏幕顶部正中 | [灵动岛](/zh/features/dynamic-island) |
| 宠物 | 在桌面上放一个展示智能体动态的角色 | 点击宠物 | [桌面宠物](/zh/features/pet) |
| 虚拟形象 | 用语音和智能体角色交谈 | 见其指南 | [虚拟形象](/zh/features/avatar) |

## 设置打开它们的快捷键

打开 **设置 → 快捷键** 或该功能自己的设置页，检查已分配的组合键和触发方式。SmartBar、聊天窗口和应用侧边栏都有默认快捷键。灵动岛和 PopBar 在你设置之前没有快捷键。

全局快捷键可能与 macOS、输入法和其他应用冲突。如果某个快捷键打不开对应的窗口，请换一个没有被占用的组合。参见[键盘快捷键](/zh/configuration/keyboard-shortcuts)。

## 让结果保持可见

使用当前窗口的固定或窗口控件。要在切回其他应用时让 SmartBar 保持在最前面，可以运行 **固定 SmartBar**，或在 SmartBar 中按 **⌘P**。

用完后按 Escape 或使用窗口的关闭控件。关闭窗口不会删除对话。

## 程序坞图标

关闭聊天窗口或设置后，Enconvo 仍会留在程序坞中，方便你从那里再次打开。如果希望在关闭这些窗口后隐藏程序坞图标，请在 **设置 → 聊天窗口** 中开启 **关闭时隐藏程序坞图标**。

程序坞图标的角标会统计需要你处理的聊天：尚未打开的结果或失败任务、正在等待你批准或回复的聊天，以及来自好友的未读消息。

要暂时隐藏 Enconvo 的窗口，请按 **⌘H**（**隐藏 Enconvo**）。它们会一直保持隐藏，直到你再次打开其中一个窗口。

## 多显示器

检查各个窗口设置中的显示选项，尤其是灵动岛的 **显示在**。更改显示器排列后，重新打开窗口，确认它出现在你预期的屏幕上。应用侧边栏跟随它所附着的应用窗口，权限和该应用自身的窗口行为都可能影响它的附着方式。

## 结果显示在哪里

有些命令有 **窗口模式** 或输出设置，决定结果显示在哪里。语音输入也可能粘贴到前台应用中，所以听写前请先确认光标的位置。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 窗口打不开 | 检查它的快捷键和当前显示器，并看看它是否被其他应用挡住。 |
| 你记忆中的快捷键打不开窗口 | SmartBar 的默认快捷键是 **⌥Space**，聊天窗口是 **⌃⌘X**。你自己设置过的快捷键会保持不变。 |
| 希望关闭窗口后程序坞图标消失 | 在 **设置 → 聊天窗口** 中开启 **关闭时隐藏程序坞图标**。 |
| 还是打不开，或缺少某项权限 | 参见[故障排除](/zh/getting-started/troubleshooting)。 |

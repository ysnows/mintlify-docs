---
title: "语音转写"
description: "把你已有的音频或视频文件转成可搜索的转录文本。"
---

语音转写适用于你手头已有的媒体文件，例如一段采访或一节讲座视频。实时录制的会议在 **录音** 中，字幕会话在 **实时字幕** 中。三者共用同一个录音视图，但各自列出不同来源的内容。

## 导入文件

1. 在 **设置 → 语音转写模型** 中选择一个模型。
2. 打开 **设置 → 语音转写**，点按 **添加**，然后选择 **音频** 或 **视频**。列表为空时，点按 **导入文件**。你也可以把音频文件、视频文件或文件夹直接拖到页面上。
3. 等待提取和转写完成。多个文件会在后台逐个转写，并且在转换较长的音频文件时 Enconvo 仍可正常使用。
4. 打开条目，查看转录文本及其处理状态。
5. 使用结果之前，先更正重要的说话人姓名、术语和数字。

你也可以运行 **转写** 命令。它的设置包括 **输出格式**、**说话人分离** 和 **Transcription Provider**（转写服务提供商）。

## 使用转录文本

打开已保存的条目，即可阅读转录文本、摘要，并使用 **询问 AI**。摘要的用法与录音相同：在侧边栏顶部选择它的输出语言和模板，参见[会议录音](/zh/features/meeting-recording)。与其默认每个细节都识别正确，不如直接就转录文本提问。能否得到时间戳、结构化输出和说话人分离，取决于你使用的服务提供商和命令。

关于词汇和说话人姓名，请参阅[词典与说话人](/zh/configuration/speech-assets)。要在之后和其他文档一起找到这份转录文本，请参阅[知识库](/zh/ai/knowledge-base)。

## 转写失败时

Enconvo 会区分转写失败和文件中没有语音这两种情况。请阅读错误信息及其诊断详情。失败可能来自音频提取、服务提供商的文件限制、账户权限，或服务本身。标题生成和搜索索引也可能独立于转写单独失败。

如果转录文本已经保存，再次导入同一文件之前，先确认是不是只有标题或索引步骤失败了。在核对完转录文本之前，请保留原始媒体文件。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 转写失败 | 阅读错误信息及其详情。Enconvo Cloud Fast 支持最长 300 分钟的录音，并在上传前重新编码大文件。如果文件对该服务来说太大或太长，请将其拆分，或选择支持更长文件的模型。如果无法读取视频的音频，请将其导出为 WAV 或 MP3 文件后再转写。 |
| 只有标题或搜索索引失败 | 转录文本已经保存，无需再次导入文件。索引失败时，使用 **重试索引**。 |
| 说话人没有区分开 | 选择支持说话人分离的服务提供商，或在 **转写** 命令中打开 **说话人分离**。 |
| **这些文件已在语音转写中** | 这些文件之前已导入过，请打开已有的条目。 |

作品（Artifact）是智能体为你制作并保存下来的成果：文档、幻灯片、设计画布、仪表盘、动画、网页、图表或代码。它会在聊天旁边的面板中打开，保留每一个版本，并在聊天结束后继续存放在 **作品** 资料库中。当你需要反复查看、编辑、演示或分享结果时，就可以使用它。

你生成的图片、视频和音频则保存在[媒体](/zh/features/media)中。

## 从新聊天开始制作作品

新聊天的消息框下方会显示一行 **做点什么** 选项，每种类型对应一个胶囊按钮：**幻灯片**、**文档**、**设计**、**动画**、**仪表盘**、**网页**、**图片** 和 **视频**。每个按钮都附有简短说明，方便你区分 **动画**（用代码制作的动画）和 **视频**（AI 生成的影像）。

1. 点击一个按钮。此时还不会发送任何内容：消息框会切换到该类型。
2. 选择开始方式：
   - 点击三个示例之一，直接填入消息框。
   - 点击 **空白幻灯片**、**空白文档**、**空白设计** 等，在聊天旁边打开一个空白作品。
   - 点击 **打开 .pptx**、**打开 .docx** 或 **打开表格**，从现有文件开始。
   - 点击 **你的幻灯片**、**你的文档** 等，打开你已有的作品。
3. 描述你想要的内容并发送。

作品会在聊天旁边打开，并随着智能体的工作逐步填充内容。你也可以直接在任意聊天中提出需求：要求制作预告片、解说视频或演示视频会生成[动画](/zh/features/motion)，要求跟踪数据指标则会生成[仪表盘](/zh/features/dashboards)。

**图片** 和 **视频** 则会显示你最近的图片或片段，并提供一个 **打开媒体** 链接。参见[媒体](/zh/features/media)。

## 查找你的作品

点击聊天窗口侧边栏中的 **作品**。资料库会以缩略图网格形式打开，按最近修改时间排序。

- 在顶部切换 **网格视图** 和 **列表视图**。
- 按类型筛选：**全部**、**页面**、**设计**、**仪表盘**、**幻灯片**、**动画**、**文档**、**图表** 或 **代码**。
- 在 **搜索作品** 中输入内容，即可按标题搜索，支持任意文字和大小写。
- 点击 **新建**，新建任意类型的空白作品。
- 点击 **导入**，将文档导入为作品文档，或导入设计或仪表盘的压缩项目文件夹。

右键点击某个条目，或点击其 **⋯**，可以 **打开** 它、**重命名…**、**复制链接**、**打开创建它的对话**、**选择** 多个条目，或 **删除** 它。要一次选中多个条目，可按住 ⌘ 点击或按住 ⇧ 点击，然后一起删除。删除操作会移除该作品的所有版本及其保存的全部内容；创建它的对话会保留。点击随后提示中的 **撤销** 可以恢复它。

从未写入内容的空白作品不会保留：关闭时会自动丢弃。

## 回到之前的版本

智能体所做的每次修改，以及你保存的每次编辑，都会生成一个新的版本。

1. 点击作品顶部栏中的版本号（例如 **v4**）。
2. 在 **版本** 下选择你想要的版本。
3. 点击 **恢复**，或点击 **回到当前版本** 保持原样。恢复操作会保存为一个新版本，因此不会丢失任何内容。

你也可以直接在聊天中提出要求，例如：“把幻灯片恢复到改颜色之前的样子。”智能体会恢复设计、幻灯片或仪表盘的该版本，并保留其他部分。

当你要求修改时，智能体只会编辑你指定的那一部分，例如某一张幻灯片、某一个图表或某一个画板，其余部分保持不变。

## 分享作品

文档、设计、幻灯片、仪表盘和动画可以分享给个人或你的团队。你需要先登录自己的 Enconvo 账户。

1. 打开作品并点击 **分享**。
2. 在 **通过邮箱添加成员** 下输入邮箱，选择 **可查看**、**可评论** 或 **可编辑**，然后点击 **分享**。
3. 要与团队分享，请设置 **团队访问**。要让任何已登录 Enconvo 的人都能打开，请将 **常规访问权限** 设为 **任何拥有链接的人**，然后点击 **复制链接**。
4. 点击 **完成**。

分享会将作品移至 Enconvo Cloud，这样你添加的人就能在自己的 Mac 上打开它，并看到每一次新版本。以 `@Enconvo` 开头的评论会收到来自 Enconvo 的回复。

## 将网页发布为网站

网页作品可以在 Enconvo Cloud 上以专属地址 `name.site.enconvo.com` 发布上线。你的 Enconvo 账户已包含发布功能。

1. 打开该网页，点击顶部栏中的 **发布**。
2. 在 **网站名称** 下输入地址名称：3 到 40 个小写字母、数字或连字符。
3. 在 **谁可以查看** 下，选择 **任何拥有链接的人**，或选择 **密码** 并输入至少 4 个字符的密码。
4. 点击 **发布**。当提示 **你的网站已上线** 时，点击 **打开** 即可查看。

此时按钮会变为 **已发布**。当你修改页面后，按钮会变为 **更新**：点击它，再点击 **更新**，即可将最新版本上线。在同一面板中，你还可以 **复制链接**、**恢复** 之前发布过的版本，或点击 **取消发布** 让网站下线，使链接对所有人失效。

你也可以让智能体把网页分享到网上，它会替你发布该网页或站点文件夹。

## 在手机上打开作品

幻灯片、仪表盘和动画也可以在 iPhone 和 Android 应用中打开。从聊天或 **作品** 资料库中打开一个作品，即可评论、向 `@Enconvo` 提问、分享、导出或演示。

## 将文档作为技能使用

文档可以作为你的智能体遵循的技能来使用。打开文档并选择 **作为技能使用…**。当该文档属于其他人时，只有你可以开启它，且 Enconvo 会提示你该文档的拥有者仍可更改你的智能体所遵循的内容。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 图片或视频不在资料库中 | 图片、视频和音频保存在[媒体](/zh/features/media)中 |
| **分享** 提示你登录 | 在 Mac 上登录 Enconvo，然后重新分享 |
| 已分享的文档无法再打开 | 其拥有者移除了你的访问权限，或者你已将它从自己的资料库中移除 |
| 智能体改写了超出你要求的内容 | 指明要更改的部分，或恢复到它之前的版本 |
| 已发布的页面显示的是旧版本 | 点击页面顶部栏中的 **更新**，然后点击 **更新** |

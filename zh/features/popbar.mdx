PopBar 是一个小工具栏，在任意应用中选中文字时出现在旁边。它的按钮可以对选中的内容进行解释、翻译、编辑、搜索、复制或朗读，[PopBar 扩展](#popbar-扩展)还能添加更多功能，比如网页搜索、文本转换，或把选中内容发送到另一个应用。当你要处理的文字已经在屏幕上时，就用它。

其他场景：快速提问或运行命令用 [SmartBar](/zh/features/smartbar)，长对话和处理文件用[聊天窗口](/zh/ai/chat)，在某个应用旁边工作用[应用侧边栏](/zh/features/app-sidebar)，想要一个常驻屏幕的小入口则用[灵动岛](/zh/features/dynamic-island)和[桌面宠物](/zh/features/pet)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

下面的视频教程用 6 分钟完整演示了 PopBar 的设置与使用：打开它、选择何时显示、运行修正拼写、翻译和询问 AI、使用内联模式、添加和排列按钮、创建自己的 AI 命令，以及获取或制作 PopBar 扩展。

## 使用 PopBar

1. 打开 **设置 → PopBar**，打开 **启用 PopBar**。
2. 在某个应用中选中一小段文字。
3. 点击工具栏上的一个按钮。
4. 在使用复制、粘贴或替换操作之前，先检查结果。

你也可以用快捷键打开 PopBar：运行 **显示 PopBar**，或在 **何时显示** 标签页上设置一个 **快捷键**。按 Escape 关闭工具栏。

PopBar 通过辅助功能权限读取选中的内容，能读到什么取决于具体应用。安全输入框和部分自定义编辑器不会公开其中的文字。

## 通过语音提问

打开“询问”面板、输入框显示 **就选中的文字提问…** 时，你可以直接说出问题，而不必打字。

1. 点击输入框里的麦克风按钮，或按下你的[语音命令](/zh/features/dictation)快捷键。输入框会显示 **正在聆听…** 并实时出现你说的话。
2. 说完后再次点击该按钮，或松开按住的快捷键，问题就会发送。

按 Escape 可停止聆听而不发送。说话前输入的内容会保留在语音转写的文字前面。

## 选择按钮

PopBar 设置的 **按钮** 标签页把工具栏的按钮显示在一条中。拖动按钮可调整顺序，将指针移到按钮上并点击 **×** 可将其移除，点击按钮可查看更多选项。**恢复默认** 可恢复默认按钮。

工具栏上放不下的按钮会收在末尾的 **⌄** 中。点击 **⌄** 打开 **更多** 面板：它列出这些按钮，并提供一个可搜索所有按钮和设置的搜索框。更改过按钮后，这里的 **关闭 PopBar** 下方也会出现 **恢复默认**，它会恢复默认按钮及其顺序，并提供 **撤销**。

点击 **添加按钮** 打开按钮库。其中有询问 AI、在侧边栏中询问、打开链接、搜索、复制、翻译、解释、修正拼写、AI 编辑、朗读等，还有你的 [PopBar 扩展](#popbar-扩展)提供的操作，以及创建自己的 [AI 命令](/zh/features/ai-commands)的入口。你也可以添加一个[写作工具](/zh/features/writing-tools)命令，用于你自己的编辑流程。工具栏会显示你添加的按钮。

## 控制出现的位置

**何时显示** 标签页决定 PopBar 何时出现：

| 设置 | 作用 |
| --- | --- |
| **哪些文字** | 对你选中的任何文字都显示 PopBar，或只对它能帮上忙的文字显示，比如外语、代码或电子邮件。 |
| **位置** | 用 **除以下位置外的所有地方**，再点 **添加应用** 或 **添加网站**，让它不在某些应用或网站中出现。或者选择 **仅在以下位置**，让它只在你列出的地方显示。 |
| **选中文字时显示** | 关闭后，PopBar 只在你主动调用时显示，然后点击 **添加快捷键** 选择一个快捷键。 |

在自动弹出工具栏会碣事的应用中（例如终端），把它排除在外。

## 更改外观

在 **查看** 标签页上，**布局** 可以把按钮排成一行放在选中内容上方（**横排**），或排成一列放在指针旁边（**竖排**）。如果工具栏挡住了你正在读的内容，可以用 **微调位置** 下的 **X 偏移** 和 **Y 偏移** 移动它。

## 内联模式

有些按钮可以不弹出结果窗口直接工作。右键点击 PopBar 上的 **修正拼写**，打开 **内联模式**。下次选中文字并点击 **修正拼写** 时，修正结果会直接写进你的文字里。

## 更改结果所用的模型或设置

对于带有 AI 模型设置的命令，结果工具栏会提供模型选择器，显示为模型服务提供商的图标。在这里更改模型，也会更新该命令以后运行时的默认模型。结果窗口的设置按钮会打开生成该结果的命令，例如 **插件 → 写作工具 → 解释**。

## PopBar 扩展

PopBar 扩展是小型附加组件，它们的操作会成为 PopBar 上的按钮。它们采用 [PopClip](https://www.popclip.app) 的扩展格式，因此为 PopClip 编写的扩展也能安装在 Enconvo 中。PopBar 扩展需要 Mac 版 Enconvo。

<Note>
Enconvo 与 PopClip 的开发商 Pilotmoon Software 没有关联。
</Note>

### 从 Enconvo 目录安装

1. 打开 **插件**，选择 **PopBar 扩展** 标签页。
2. 按类别浏览目录，或在搜索框中输入关键词查找。
3. 点击扩展旁边的 **+**，然后点击 **安装**。
4. 接下来的卡片列出了该扩展的按钮、每个按钮何时显示以及放在哪里。为每个按钮选择 **在栏上**、**在 ⌄ 更多中** 或 **关闭**，然后点击 **完成**。**设置…** 会打开该扩展的选项。

新按钮会放在 PopBar **⌄ 更多** 面板的最前面；如果工具栏还有空间，则放在栏上。在你打开面板之前，**⌄** 上会显示一个小圆点，面板里的新按钮会标有 **新**。

Enconvo 会在上架前审核目录中的每个扩展，并且只安装它审核过的那个版本。已安装的扩展列在标签页顶部。当 Enconvo 审核了某个扩展的新版本时，它在目录中的那一行会显示 **更新**。在按钮库中，**获取更多…** 会打开同一个标签页。

你也可以在网页上浏览目录：[app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions)。在 Mac 上，点击扩展的 **安装** 按钮会打开 Enconvo，它会在安装任何内容之前先展示该扩展能做什么。

### 从其他来源添加扩展

在 **PopBar 扩展** 标签页上，或在插件页面的 **添加** 菜单中，点击 **添加 PopBar 扩展…**。然后执行以下任一操作：

- 粘贴一个 `.popclipextz` 安装包的链接。
- 粘贴一段片段（snippet），即以 `#popclip` 开头的扩展简短文本形式。
- 点击 **选择文件…**，在 Mac 上选择一个 `.popclipextz` 安装包或 `.popclipext` 文件夹。

点击 **预览**。Enconvo 会在不运行扩展的前提下读取它，并列出它在 PopBar 之外还能做的事，比如运行脚本、连接互联网、打开应用或模拟按键。在你点击 **允许并安装** 之前不会安装任何内容，安装完成后会出现与从目录安装时相同的按钮卡片。Enconvo 不审核目录之外的扩展，因此请只从你信任的来源安装。

当你在任意应用中选中一段扩展片段时，PopBar 会先显示一个 **安装扩展程序** 按钮。点击它会打开同样的预览。

### 从 PopClip 导入

如果你在用 PopClip，可以在 **PopBar 扩展** 标签页上点击 **从 PopClip 导入…**。Enconvo 会按 PopClip 中的顺序复制你的 PopClip 扩展及其设置，并把它们的操作添加到 PopBar。PopClip 本身不会被更改。

- 在 PopClip 中已关闭的扩展会被安装，但不会添加到 PopBar。
- API 密钥和密码不会被复制。Enconvo 会列出需要它们的扩展，请在各扩展的设置中重新输入。
- 与 Enconvo 目录中某个版本一致的扩展视为已审核，并从目录更新。

### 设置、更新与移除

在 **PopBar 扩展** 标签页中打开一个扩展，查看它的页面。其中的 **PopBar 按钮** 部分列出了每个按钮及其显示时机，你可以把它放在栏上、放进 **⌄ 更多**，或从 PopBar 上关闭。**在 PopBar 设置中排列所有按钮** 会打开按钮标签页。

有选项的扩展会在页面顶部显示 **设置**，并在按钮库中的卡片上显示 **设置…**。

从链接安装的扩展会从同一链接更新。当更新后的版本能做的事超出你之前允许的范围时，Enconvo 只展示新增的部分，并在更新前再次征求你的同意。

要移除某个扩展，在 **PopBar 扩展** 标签页中打开它并卸载。它的按钮会从 PopBar 上移除。

### 暂不支持的内容

- 需要登录账户的扩展。
- 每次工具栏出现时动态生成操作的扩展。

如果某个扩展用到了其中一项，Enconvo 会在预览时告诉你。

### 推荐扩展

Enconvo 的目录托管在 [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions)。在那里提交 issue 或 pull request，即可推荐扩展供审核。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 工具栏没有出现 | 检查 **启用 PopBar**、辅助功能权限，以及 **位置** 下的应用和网站。 |
| 它处理了错误的文字 | 重新选中文字，再次打开 PopBar。 |
| 缺少某个命令 | 检查 **按钮** 标签页，并确认该命令所属的插件已安装。 |
| 结果没有替换你的文字 | 该应用可能不允许替换。复制结果，再粘贴到可编辑的字段中。 |
| 扩展按钮没有出现 | 点击 PopBar 末尾的 **⌄**，新按钮会放在那里；或在插件中查看该扩展的页面：设为 **关闭** 的按钮不会出现在 PopBar 上。有些按钮只对它们能处理的文字显示：例如 **Base64 Decode** 只在文字看起来像 Base64 时显示，所以选中普通文字时只会显示 **Base64 Encode**。 |
| 扩展按钮替换了选中的文字 | 许多扩展会把结果粘贴到选中内容上，就像在 PopClip 中一样。在文字无法编辑的地方，结果会改为复制到剪贴板。 |
| 目录加载不出来 | 检查网络连接，然后在 **PopBar 扩展** 标签页上点击 **重试**。 |

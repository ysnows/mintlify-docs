---
title: "Appshots"
description: "一键把前台应用窗口添加到你的下一个问题中。"
---

Appshots 会把前台应用的窗口作为上下文添加到聊天中。当你想就屏幕上的内容提问，又不需要把它存进知识库时，就可以使用它。

## 捕捉应用窗口

1. 把你想提问的应用切到前台。
2. 按下 Appshots 快捷键。Appshots 默认没有快捷键，需在 **设置 → Appshots** 的 **快捷键** 中设置。
3. 如果 SmartBar、聊天窗口或应用侧边栏正在前台打开，窗口会发送到其中；否则发送到灵动岛。同时会播放一声短促的快门声。
4. 检查附加的窗口，然后提出具体的问题，例如“解释一下这个窗口里的错误。”

## 设置

打开 **设置 → Appshots**。

| 设置 | 作用 |
| --- | --- |
| **启用 Appshots** | 允许快捷键添加最前方的应用窗口。默认打开。 |
| **录制声音** | 添加 Appshot 时播放一声短促的快门声。这个声音表示已捕捉；发送前仍请检查附件。 |
| **快捷键** | 用于添加窗口的快捷键。默认无快捷键。可以是一组修饰键，例如同时按下两个 **Option** 键，也可以是普通快捷键。 |

## 选择合适的捕捉工具

| 目标 | 使用 |
| --- | --- |
| 就当前应用窗口提问 | Appshots |
| 提问前先标出某个区域 | [屏幕涂鸦](/zh/features/screen-doodle) |
| 保存当前应用的内容以便之后搜索 | [快速捕捉](/zh/features/quick-capture) |
| 从图片中提取文字 | [OCR](/zh/ai/ocr) |

捕捉的内容可能会发送给你处理该请求所用的模型。添加上下文的其他方式，请参阅[上下文感知](/zh/features/context-awareness)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 没有出现上下文 | 检查 **设置 → 权限**，尤其是屏幕录制和辅助功能权限。 |
| 捕捉到了错误的窗口 | 重新把目标应用切到前台。Appshots 捕捉的是其他应用的窗口，不包括设置等 Enconvo 自己的窗口。 |
| 按快捷键没有反应 | 确认 **启用 Appshots** 已打开，并且已设置 **快捷键**。 |
| 快捷键触发了别的操作 | 另一个应用占用了相同的按键。请在 **设置 → Appshots** 中更改 **快捷键**。 |

---
title: "Live Photo 角色直播"
description: "将 Live Photo 角色和字幕添加到 OBS 直播中，并让她在 Twitch、Kick 或 YouTube 直播聊天中开口回答观众。"
---

[Live Photo 角色](/zh/features/avatar)可以担任直播主持人。Enconvo 会为 OBS 提供包含她动态画面的舞台页面和字幕页面，她还可以通过所绑定的智能体阅读直播间的聊天消息，并出声回答观众。

## 开始之前

- 在 **设置 → 虚拟形象** 中创建一个 Live Photo 角色，并将其绑定到一个智能体。
- 安装 OBS Studio。直播面板上的 **获取 OBS Studio** 提供了下载链接。

<Note>
通话进行期间，以及她在直播模式下开口回答时，Atmee 会按分钟对她的实时视频计费，无论你是否正在推流直播。
</Note>

## 打开直播面板

1. 打开 **设置 → 虚拟形象**，切换到 **Live Photo** 标签页。
2. 点击她卡片上的 **开始直播**。

直播面板会显示她的舞台、字幕、画面方向（**竖幅 9:16** 或 **横幅 16:9**）以及 OBS 的推流状态。打开她的虚拟形象后，舞台上就会显示她的画面。

## 将她添加到 OBS

1. 在 OBS 中，打开 **工具 → WebSocket 服务器设置**，勾选 **启用 WebSocket 服务器**，然后点击 **应用**。
2. 点击 **显示连接信息** 并复制服务器密码。
3. 在直播面板上，点击 **连接 OBS** 并粘贴密码。Enconvo 会将其与其他凭据一起安全保存。
4. 点击 **添加到 OBS**。Enconvo 会创建一个名为“Enconvo · *她的名字*”的场景，其中包含她的舞台和字幕，并按你的直播画面尺寸调整好大小。
5. 在 OBS 中开始推流，或使用面板上的 **开始直播**。点击 **结束直播** 即可停止。

如果你更改了画面方向，请再次点击 **添加到 OBS** 以重新调整场景尺寸。如果你想自己搭建场景，可以把面板中的透明舞台页面和字幕页面作为 **浏览器** 来源添加到 OBS。

## 选择她的背景

在面板的 **背景** 下，选择发送给 OBS 的角色背景画面。OBS 中显示的内容与舞台预览完全一致。

| 选项 | OBS 收到的画面 |
| --- | --- |
| **透明** | 只有角色本身，带透明通道。你自己的 OBS 场景会显示在她背后。 |
| **颜色** | 纯色背景的完整画面，例如 **绿幕** 或 **自定义颜色**。 |
| **图片** | 以你自己的图片为背景的完整画面，图片保存在这台 Mac 本地。 |
| **虚化照片** | 将她的原始照片虚化后作为完整画面的背景。 |
| **原照片** | 她的原始照片。 |

保存时带有相框 **背景**（Backdrop）的角色会保留她自己的照片和相框；背景选项仅适用于抠图角色。

## 让她回答你的直播弹幕

1. 在直播面板上，输入你的 **Twitch 频道** 或 **Kick 频道**，或者使用你的 YouTube Data API 密钥连接 YouTube。
2. 设置她要回答谁的消息：@提及她的观众、使用 `!ask` 提问的观众或付费观众。设置单名观众与全局的冷却时间、屏蔽词，如果需要逐条审核问题，请开启先审核队列。
3. 点击 **开启直播弹幕**。

她会通过自己的智能体出声回答观众。

### 直播模式

开启面板上的 **直播模式** 后，无需处于通话中，她就会在 OBS 舞台上伴随着口型动画说出每一条回答。关闭时，回答会在这台 Mac 上朗读播放。

## 声音

通话期间，只要舞台正在显示她，她的声音就只会从 OBS 播放。开启 **同时在这台 Mac 上播放**，即可同时在 Mac 上听到她的声音。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 舞台是空的 | 打开她的虚拟形象。在通话中时，舞台会实时显示她。 |
| OBS 无法连接 | 确认 OBS 中已勾选 **启用 WebSocket 服务器**，然后重新粘贴密码。 |
| 她的场景尺寸不对 | 更改画面方向后，再次点击 **添加到 OBS**。 |
| 背景没有变化 | 她的角色保存时带有相框 **背景**（Backdrop）。背景选项仅适用于抠图角色。 |
| 听到重音或完全听不到声音 | 检查 **同时在这台 Mac 上播放** 开关。 |

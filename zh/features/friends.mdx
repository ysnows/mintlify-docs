description: "通过邮箱或二维码添加好友，给好友和团队成员发消息、发送文件和语音消息、发起群聊，并立即呼叫他们。"

好友是你在 Enconvo 中发消息和通话的对象。通过邮箱或二维码添加对方后，就可以与他们聊天，发送文件、语音消息、AI 回答和作品，或者一键发起通话。你的团队成员会显示在好友旁边，因此你也可以用同样的方式联系他们。

## 开始之前

在 **设置 → 账户** 中登录你的 Enconvo 账户。使用好友和好友聊天功能需要登录账户，你添加的好友也需要拥有各自的 Enconvo 账户。

## 添加好友

1. 在聊天窗口侧边栏中，找到项目上方的 **好友**，点击 **+**，然后选择 **添加好友…**。
2. 在 **通过邮箱添加** 下输入对方的邮箱并按 Return。或者让对方扫描 **你的二维码**，也可以点击 **复制链接** 并把链接发给对方。
3. 对方会收到一条好友请求。一旦对方接受，就会显示在侧边栏的 **好友** 下。

发送给你的请求会连同数量一起显示在侧边栏中。点击 **接受** 或 **暂不**。**换一个** 会替换你的二维码和链接，旧的二维码和链接将随即失效。

## 管理好友

将指针移到侧边栏中的 **好友** 上，点击 **+** 旁的齿轮图标 **管理好友**，即可打开好友页面。**设置 → 好友**、菜单栏菜单中的 **好友** 以及 SmartBar 中的 **好友** 命令也可以打开该页面。

| 标签页 | 显示内容 |
| --- | --- |
| **全部** | 你的好友，带有 **消息** 和 **呼叫** 按钮。 |
| **请求** | 等待你回复的请求，以及你发送的请求。 |
| **群组** | 你的群聊。 |
| **团队** | 你的团队成员。 |
| **已阻止** | 你屏蔽的人，带有 **取消屏蔽** 按钮。 |

好友的 **⋯** 菜单包含 **消息**、**呼叫**、**发送文件…**、**预约一场会议**、**免打扰**、**保留在侧边栏**、**删除好友** 和 **屏蔽**。

如果你所在的团队使用了客户工作区，每位队友都会显示在你们共享的工作区的好友列表中。参见[工作区](/zh/configuration/account)。

## 与好友聊天

点击侧边栏中的一位好友即可打开你们的聊天。回复会在到达时即时显示，当聊天未打开时，你会收到通知。Enconvo 程序坞图标会显示你有多少条未读的好友消息。它会统计在任意设备上已读的聊天，并排除设为免打扰的聊天。

在消息框中，你可以：

- **发送文件**：拖放、粘贴或选取文件，每个最大 1 GB。离开当前聊天时文件仍会继续发送，网络断开重连后也会从断点继续传输。
- **录制语音消息**：点击语音按钮并说话，最长一分钟。可以作为语音消息直接发送，或选择 **以文字发送** 先将其转为可编辑的文字。语音消息可在聊天中直接播放，点击 **显示文本** 可阅读其文字内容。
- **添加表情符号**：点击 **表情符号** 搜索表情。它会使用你在 Mac 的表情符号选择器中选取的肤色。

视频会显示第一帧画面和时长，并在气泡中播放。PDF 或文本文件点击一次即可打开。**存储为…** 可以保存任意文件的副本。

### 回复与回应

将指针移到一条消息上，或右键点击它，可以用快速表情或任意表情进行回应，也可以引用并 **回复**。点击回应即可添加或移除你的回应，点击引用即可跳转到原消息。好友通话中的 **聊天** 标签页会显示相同的引用和回应，你也可以在那里回应和回复。

### 多选消息

1. 从某条消息的菜单中选择 **选择**，或从聊天菜单中选择 **多选消息**。
2. 点击消息以选中它们。按住 Shift 点击可选中一个范围。
3. 一起 **复制**、**转发** 或 **删除** 它们，或者点击 **新建聊天**，用这些消息开启一个智能体对话。选择项目，告诉智能体如何处理这些消息，然后点击 **创建对话**。

## 发起群聊

1. 点击侧边栏中 **好友** 旁的 **+**，选择 **新建群组…**。你也可以在好友页面上点击 **新建群组**，或在聊天详情中点击 **添加成员**。
2. 选择群组成员，如果需要，可以设置 **群组名称** 和群头像。
3. 点击 **创建群组**。

在群组中输入 `@` 可以提及某人。**已读** 会显示谁看过你的消息。打开群组详情，可以重命名群组、更换群头像、设置 **通知**（**全部**、**提及** 或 **关闭**）、添加或移除成员、**设为群主** 以移交群主身份，或 **退出群组**。

## 向好友发送 AI 回答和作品

点击 AI 回答下方的 **发送给好友**，或点击[作品](/zh/features/artifacts)顶部的 **发送给好友**。选择一位或多位好友，如需附言可添加备注，然后点击 **发送**。作品会以只读副本的形式发送给对方。

好友发来的回答或作品绝不会从网络加载图片，也不会自行跳转到网页。

## 呼叫好友

点击侧边栏中、好友页面上或聊天中好友旁的 **呼叫**。通话会在[视频会议](/zh/features/video-conference)中打开。好友菜单中的 **预约一场会议** 可以预约稍后的会议。

## 让智能体给你的好友发消息

让 Mavis 或任意智能体给好友发消息、打电话或发送文件，阅读好友聊天，回复好友请求，或添加、移除、屏蔽、免打扰或置顶某人。在聊天中输入 `@` 并选择对方即可指明联系人：智能体会知道你指的是谁。在低于完全访问权限的模式下，智能体会在读取聊天或联系好友前先询问你，审批卡片会显示对象和要发送的内容。在完全访问权限下，智能体会直接执行。

当智能体呼叫好友时，它会让对方的 Enconvo 应用响铃，替你与对方交谈，并把对方的回答和通话转录文本带回你的聊天。智能体只会联系你的好友和队友。参见[智能体电话](/zh/features/agent-phone)。

## 举报或屏蔽他人

在聊天菜单中选择 **举报…**，或右键点击他人的消息并选择 **举报…**。填写原因后点击 **发送举报**。Enconvo 团队会进行审核，Enconvo 也会提供屏蔽该用户的选项。

要在不举报的情况下屏蔽某人，请在对方的菜单中选择 **屏蔽**。如需取消屏蔽，请在好友页面的 **已阻止** 标签页中操作。

## 你的个人头像

默认显示你的 Google 头像。要更换头像，请打开 **设置 → 账户** 并点击 **更换头像**：**上传头像…** 可让你选取并裁剪自己的图片，**使用 Google 头像** 会切换回原头像，**移除头像** 则会移除头像。

## 手机上的好友

iPhone 和 Android 应用同样提供好友聊天，支持发送文件、图片和通话：参见[手机上的通话和好友](/zh/integrations/phone-calls-and-friends)。群聊、消息回应和语音消息同样可用：

- 在好友列表中轻点 **+** 即可发起群组，支持 `@` 提及、**已读** 以及与 Mac 相同的群组详情设置。
- 长按一条消息即可回应或回复。轻点回应可添加或移除你的回应，轻点引用可跳转到原消息。在 iPhone 上，长按某个回应可查看是谁作出的回应。
- 按住 **按住说话** 可录制最长一分钟的语音消息，松开即可发送。滑向 **取消** 可丢弃，滑向 **文字** 可先转为文字编辑。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **好友** 显示 **登录以添加好友** | 在 **设置 → 账户** 中登录。 |
| 对方的二维码无法使用 | 对方生成了新的二维码。请向对方索取新的二维码或链接。 |
| 文件无法发送 | 每个文件最大 1 GB。更大的文件会被拒绝。 |
| 消息显示 **未发送** | 点击 **重试**。网络恢复后，消息也会自动重发。 |
| 收不到某个聊天的通知 | 该聊天已设为免打扰。请在聊天菜单中选择 **取消免打扰**，或检查群组的 **通知** 设置。 |

title: "浏览器扩展"
description: "安装 Enconvo Companion 扩展，让 Enconvo 能在你真实的浏览器中工作，沿用你的登录状态、Cookie 和扩展。"
---

Enconvo 浏览器扩展 Enconvo Companion 让 Enconvo 在任务需要你浏览器中的登录状态时，控制你真实的浏览器。可以将它用于 LinkedIn、Gmail、Salesforce、数据看板或内部工具等网站，这些地方需要用到你的 Cookie 和浏览器扩展。设置中称它为**浏览器助手**。

对于公开页面、本地预览，或不应触及你个人浏览器配置文件的工作流，请改用隔离的浏览器自动化。

## 设置扩展

<Steps>
  <Step title="安装扩展">
    打开**设置 → 使用浏览器**，在**浏览器扩展**中点按**安装浏览器配套程序**。扩展的 Chrome 网上应用店页面会随即打开。你也可以从浏览器的扩展商店安装。它适用于 Chrome、Edge、Brave、Arc、Vivaldi、Opera 和 Firefox。[电脑操作视频教程](https://youtu.be/0CbQA7d8zqU?t=33)演示了在 Chrome 中的安装过程。
  </Step>
  <Step title="保持浏览器打开">
    扩展会通过 `ws://localhost:11225` 自动连接到 Enconvo。
  </Step>
  <Step title="查看弹出窗口">
    点按扩展图标。弹出窗口会显示 **Connected Chrome**、**Connected Edge**、**Connected Firefox**，或你所用浏览器的名称。
  </Step>
  <Step title="开始浏览器任务">
    让 Enconvo 在浏览器中阅读、点按、输入、截图或管理标签页。
  </Step>
</Steps>

## 弹出窗口

| 项目 | 显示内容 |
| --- | --- |
| 连接状态 | 此浏览器的扩展是否已连接到 Enconvo |
| 当前浏览器 | 此扩展以哪个浏览器的身份连接，例如 Chrome、Edge、Brave 或 Firefox |
| 已连接的浏览器 | 当前扩展已连接到 Enconvo 的其他浏览器 |
| 版本 | 已安装的扩展版本 |
| **Learn more** | 打开本页 |

如果弹出窗口显示未连接，请重启 Enconvo 并刷新浏览器。如果仍无法连接，请关闭扩展后再重新开启。

## 使用多个浏览器

Enconvo 可以同时连接多个浏览器。当任务没有指定浏览器时，Enconvo 按以下顺序选择：

1. 你在使用浏览器设置中选择的**默认浏览器**（**设置 → 使用浏览器**，然后在 **⋯** 菜单中选择**设置**）。
2. Mac 的默认浏览器。
3. 你最近使用过的已连接浏览器。

自动化 API 也可以指定浏览器：

```json
{
  "browser": "edge"
}
```

常用的值包括 `chrome`、`google_chrome`、`edge`、`brave_browser`、`arc`、`vivaldi`、`opera` 和 `firefox`。

## 停留在正确的标签页

浏览器任务开始时，Enconvo 会记下它所使用的浏览器和标签页。之后的步骤会尽可能停留在该标签页上，即使页面打开了弹出窗口、重新加载或失去焦点。

为获得最佳效果：

- 任务完成前保持标签页打开。
- 连接了多个浏览器时，请指定浏览器。
- 希望 Enconvo 操作你眼前的页面时，请说“使用当前标签页”。
- 页面跳转或你提交表单后，请让它重新查看页面。

## 网站访问与安全

网页中可能包含不是你写的指令。在敏感页面上，请先检查网站和操作，再让 Enconvo 继续。

扩展会在任务需要时使用浏览器权限来阅读页面、点按、输入、截图、查看标签页和读取 Cookie。请将已登录的页面、浏览历史和内部工具视为敏感数据。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 弹出窗口显示未连接 | 确保 Enconvo 正在运行，重启浏览器，然后关闭扩展再重新开启。检查是否有东西阻止了 `localhost:11225`。 |
| 控制了错误的浏览器 | 在使用浏览器设置中设置**默认浏览器**，或在浏览器操作中传入 `edge`、`chrome` 或 `firefox` 等浏览器值。 |
| 已连接，但某个页面无法控制 | `chrome://` 等浏览器页面无法控制。内容安全策略严格的页面、封闭的 Shadow DOM 以及浏览器权限提示也可能造成阻碍。 |
| 文件上传不起作用 | 在浏览器中扩展的详情页面上，开启对文件网址的访问权限。上传本地文件或打开基于文件的页面的任务需要它。 |

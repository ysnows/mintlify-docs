语音笔记会把你口述的想法录进知识库，方便以后查找。如果你想把文字输入到其他应用中，请改用[听写](/zh/features/dictation)。

## 开始之前

为你的笔记新建或选择一个[知识库](/zh/ai/knowledge-base)。在你设置快捷键之前，语音笔记没有快捷键。

## 设置快捷键

1. 打开 **设置 → 语音笔记**。
2. 点按 **语音笔记快捷键**，然后按下你想用的快捷键。选择是按住还是按一下。
3. 将 **保存到** 设为笔记要存入的知识库。默认是 **默认知识库**。

## 录制笔记

1. 按下 **语音笔记快捷键**，说一段简短的笔记。在按住模式下，说话时一直按住快捷键。
2. 松开快捷键或使用录音控制按钮结束录音，笔记随即保存。
3. 打开目标知识库，查看已保存的条目及其转写内容。

## 让笔记更容易找到

录音时说出主题和有用的名称，例如：“Atlas 项目：找设计师要更新后的新手引导图标。”在依赖转写内容之前，先核对其中重要的名称、数字和日期。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 按快捷键没有反应 | 设置 **语音笔记快捷键**，并确认 **设置 → 快速捕捉** 中的 **启用快速捕捉** 已打开。这个开关同时控制快速捕捉和语音笔记的快捷键。 |
| 没有声音 | 检查麦克风权限和所选的输入设备。 |
| 笔记没有出现在预期的位置 | 检查 **设置 → 语音笔记** 中的 **保存到**。 |
| 转写失败 | 阅读错误信息，并检查所配置的语音服务提供商，然后再重新录制同一条笔记。 |

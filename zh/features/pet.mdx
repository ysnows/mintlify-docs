桌面宠物是桌面上的一个小动画角色。它会反映智能体正在做的事，可以显示实时会话卡片，并带你前往需要处理的会话。点击它即可提问或打开 Enconvo。它与[虚拟形象](/zh/features/avatar)不同，后者为智能体提供一个用于对话的角色和声音。

其他场景：快速提问或运行命令用 [SmartBar](/zh/features/smartbar)，长对话和处理文件用[聊天窗口](/zh/ai/chat)，在某个应用旁边工作用[应用侧边栏](/zh/features/app-sidebar)，处理选中的文字用 [PopBar](/zh/features/popbar)，想在屏幕顶部有一个紧凑的输入框则用[灵动岛](/zh/features/dynamic-island)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

## 选择宠物

1. 打开 **设置 → 宠物**。
2. 在 **我的宠物** 中选择一个角色，或在 **图库** 中找一个。
3. 点击 **唤醒宠物**，让它出现在桌面上。
4. 设置 **轻点时打开**，决定点击宠物时打开什么。
5. 打开或关闭 **显示会话卡片**，并调整 **宠物大小**。
6. 回到桌面点击宠物，就会打开你在第 4 步中选择的内容。

## 设置

| 设置 | 作用 |
| --- | --- |
| **唤醒宠物** / **收起宠物** | 在桌面上显示或隐藏宠物。 |
| **轻点时打开** | 点击宠物时打开什么：**提问框**（默认）、**灵动岛**、**聊天窗口** 或 **Smart Bar**。 |
| **回答所用智能体** | 回答你向宠物提问的智能体。你也可以在提问框中更改。 |
| **会话卡片** | 宠物下方的实时会话状态卡片。 |
| **宠物大小** | 宠物显示的大小。 |

## 自定义宠物

**我的宠物** 标签页上的 **自定义宠物** 显示存放你宠物包的文件夹。点击 **打开文件夹**，放入一个符合支持格式的宠物包，然后在 **我的宠物** 中选择该宠物。单独一张角色图片并不是动画宠物包。

要移除某个宠物，点击它卡片上的 **移除**。这会把该宠物包从你的资料库中删除；你可以从图库重新安装它。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 桌面上没有宠物 | 点击 **唤醒宠物**，确认 **我的宠物** 中已选中一个宠物，并检查 **宠物大小**。 |
| 点击宠物打开了错误的窗口 | 更改 **轻点时打开**。 |
| 你想要语音对话，或为某个智能体配一个角色 | 改用[虚拟形象](/zh/features/avatar)。 |

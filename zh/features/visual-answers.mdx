---
title: "可视化回答"
description: "直接在聊天中得到图示、图表或交互式小组件，而不只是纯文字。"
---

让智能体把答案“画”出来，它就会直接在对话中绘制可视化内容：SVG 图示、HTML 预览，或你可以点按和调整的交互式小组件。当一张图、一个图表或一个小计算器比大段文字更能说明问题时，就可以使用它。智能体需要启用它的可视化工具才能做到这一点。

可视化回答保存在对话中。如果你需要一个可以保留、编辑、演示或分享的成果，例如幻灯片、仪表盘、设计或文档，请改为请求制作[作品](/zh/features/artifacts)。

## 请求可视化内容

说明这个可视化内容要回答什么问题：

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

如果要生成图表或计算器，请提供数据及其单位。即使可视化内容看起来很精美，其中的事实或计算也可能有误，请加以核对。

## 回复中的链接、地图和图表

有些回答无需你要求就会自动以可视化形式呈现：

- **链接** 会显示为带有网站图标的卡片。
- **地点** 会显示在带有地点名称的真实地图上。多个地点会共用一张带编号的地图，路线则会显示线条以及时间与距离。
- 智能体制作的 **图表** 会经过配色检查，确保每个系列在色盲视角以及浅色、深色外观下都清晰可辨。数字、日期和状态词都会按你的语言显示。

## 使用和保存可视化内容

1. 等可视化内容绘制完成后，再使用其中的控件。部分小组件会把后续提示发回聊天。
2. 把指针移到绘制完成的可视化内容上，点按右上角的 **⋯**。
3. 选择 **复制到剪贴板**，或选择 **下载文件** 并确认文件名。用 App 自带的卡片、表格和图表绘制的可视化内容会提供 **下载图片**，它会把 PNG 保存到你的“下载”文件夹。

保存的图片只记录可视化内容某一时刻的样子，不会保留交互控件。修改小组件的数值后，可以用同一菜单中的 **重置数值** 恢复原值。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 得到的是代码而不是可视化内容 | 检查智能体启用的工具，然后让它把结果直接显示在对话中 |
| 小组件显示不完整 | 等它绘制完成，然后让智能体生成一个更简单的版本 |
| 你需要的是图片文件，而不是聊天小组件 | 使用[图像生成](/zh/ai/image-generation) |
| 你想保留图表并日后查看 | 请求制作一个[仪表盘](/zh/features/dashboards) |

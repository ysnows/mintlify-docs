设计画布是智能体用来展示外观效果的地方：应用界面、线框图、两版对比的定价页面、海报或邮件。每一件设计都是画布上的一个画板，你可以在聊天旁边平移、缩放、选中和编辑它们。当你在正式开发前敲定视觉方案时，就可以使用它。

## 创建设计

1. 新建一个聊天并在消息框下方选择 **设计**，或者在任意聊天中直接要求创建设计。
2. 描述界面或设计作品的内容、面向的对象以及要对比的方案。也可以附上截图或草图作为起点。
3. 发送请求。智能体工作时，画板会陆续绘制在画布上，每次可以同时生成多个画板。

不同类型的项目会采用各自对应的尺寸和排版规则：手机界面按手机尺寸输出，海报按海报尺寸输出，邮件按邮件宽度输出。

示例：

```text
Two options for a pricing page, side by side.
Three plans, monthly and yearly, with the middle plan highlighted.
```

## 修改设计

直接向智能体说明要改哪里，例如图标、颜色或一行文字。它只会修改指定的那一部分，并且只重绘受到影响的画板。

如果你想自己修改：

- 选中一个元素并在侧面板中打开 **属性**，即可调整它的布局、填充、边框、排版和效果。打开设计时该面板默认关闭；在较窄的窗口中，它会作为浮层表单覆盖在画布上方。
- 使用 **调整** 调节画板提供的选项，使用 **大纲** 查看它的图层。
- 按住 Space 键或选择抓手工具来平移画布。铅笔和钢笔工具可以直接在画布上绘制。
- 选中一个元素并使用 **导出**，将其保存为 **导出 PNG** 或 **导出 JPEG**。

要将画布分享给其他人或你的团队，或回到之前的版本，请参阅[作品](/zh/features/artifacts)。

## 使用设计系统

设计系统能为画布或幻灯片套用你完全一致的颜色、字体样式、字号字重和组件。

- **导入设计系统**：让智能体把你的代码文件夹、tokens 文件或 npm 包转换成一个设计系统。它会保留精确的数值和真实组件，然后运行检查，列出该系统目前还缺少什么。
- **切换外观**：打开侧面板中的 **主题** 标签页并选择一个设计系统。画布会随即将颜色和文字样式切换过去。
- **保持最新**：当设计系统在设计使用它之后发生过更新时，**主题** 标签页会提示它落后于来源。点击 **同步** 即可把更改同步进来。

幻灯片通过各自菜单中的 **设计系统** 使用设计系统。参见[幻灯片](/zh/features/slides)。

## 导入设计项目

在 **作品** 库中点击 **导入**，然后选择压缩为 zip 的设计项目文件夹。保存在文件夹 `assets/` 或 `_blobs/` 中的上传文件会一并导入。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 字体在某些画板上看起来不一样 | 该字体只会在已加载它的画板上正确显示；请让智能体加载该字体 |
| **主题** 标签页里没有设计系统 | 请让智能体添加或导入一个设计系统 |
| 提示找不到设计系统的来源 | 它原本所在的文件夹或包已被移动；请重新导入一次 |
| 导出失败并提示“hasn't finished drawing the export” | 请更新 Enconvo，然后再试一次导出 |

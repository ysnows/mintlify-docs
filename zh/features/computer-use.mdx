当任务不只是处理文本时，电脑操作（Computer Use）可以让 Enconvo 直接操作你 Mac 上的应用。它会查看最前面的应用界面、识别可见控件、点击或向输入框填写内容、滚动列表、拖拽项目、选择文件、操作应用菜单，并在执行下一步之前等待应用响应。

适用于这类桌面任务：

- 在 Mac 应用中填写表单
- 在文件选择器中选取文件
- 浏览并调整设置窗口
- 点击工具栏按钮或菜单项
- 在应用中完成多步骤操作
- 读取当前窗口中可见的内容

对于网页内容，使用浏览器（Browser Use）会通过 Enconvo 浏览器扩展（Browser Companion）直接操作你自己的浏览器。在未安装该扩展的浏览器（例如 Safari）中，电脑操作会改为在屏幕上进行点击和输入。

下面的视频教程在 5 分钟内完整演示了电脑操作与使用浏览器的配置与使用：开启功能并授予两项权限、在 Chrome 中添加浏览器扩展、按住右侧 Option 键提问、观看它在 Safari、Chrome 和 Mac 应用中的操作，以及将整项任务交给它完成。

## 开启电脑操作

电脑操作需要两项 macOS 权限：用于点击和输入的“辅助功能”，以及用于查看屏幕的“屏幕录制”。

<Steps>
  <Step title="打开电脑操作设置">
    打开 **设置 → 电脑操作**，确认开关已打开。
  </Step>
  <Step title="检查两项权限">
    **辅助功能** 和 **屏幕录制** 都应显示 **已启用**。
  </Step>
  <Step title="授予缺失的权限">
    如果有哪项显示 **必需**，点击旁边的 **打开**，然后在 **系统设置 → 隐私与安全性** 的对应权限下打开 Enconvo。回到 Enconvo 后点击 **刷新**。如果状态仍未更新，请退出并重新打开 Enconvo。
  </Step>
</Steps>

## 添加浏览器扩展

<Steps>
  <Step title="打开使用浏览器设置">
    打开 **设置 → 使用浏览器**。**浏览器扩展** 会列出已安装扩展的浏览器及其连接状态。
  </Step>
  <Step title="安装浏览器配套程序">
    点击 **安装浏览器配套程序**，Chrome Web Store 中的扩展页面随即打开。
  </Step>
  <Step title="添加扩展">
    点击 **添加至 Chrome**，再点击 **添加扩展程序**。打开浏览器的扩展菜单并将其固定，使它保持在工具栏中可见。
  </Step>
  <Step title="检查连接状态">
    回到 **设置 → 使用浏览器**，对应浏览器应显示 **已连接**。Edge、Arc 和 Brave 的配置方式相同。
  </Step>
</Steps>

有关扩展弹出面板、支持的浏览器及故障排除，请参见[浏览器扩展](/zh/features/browser-extension)。

## 运行任务

直接说明你希望得到的结果，而不需要列出一连串点击步骤。

<Steps>
  <Step title="打开目标应用">
    将你希望 Enconvo 操作的应用或窗口置于最前。
  </Step>
  <Step title="按住右侧 Option 键提问">
    按住右侧 **Option** 键，说出你的需求，然后松开。尽量指明应用与页面，例如：“在 Safari 的这个页面里，找出最便宜的直飞航班”或“打开设置面板并关闭开机启动”。你也可以直接打字向智能体提出请求。
  </Step>
  <Step title="观察执行过程">
    Enconvo 正在操作的窗口边缘会流动着柔和的光晕，每次点击都会泛起光波涟漪，灵动岛也会显示每一步。当窗口不在视线内时，[画中画](/zh/features/picture-in-picture)窗口会在屏幕角落实时显示它。你可以随时接管或停止任务。
  </Step>
  <Step title="确认敏感步骤">
    涉及破坏性操作、资金交易、账户变更或修改权限的步骤时，请先确认再让 Enconvo 继续。这也包括键盘快捷键：在执行删除、发送、付款、退出应用或登出账户的快捷键之前，Enconvo 都会先询问你。
  </Step>
  <Step title="获取结果">
    Enconvo 会查看应用状态、执行操作、等待结果，并持续推进直到任务完成或需要你确认。完成后，它会把结果告诉你。
  </Step>
</Steps>

### 在你的浏览器中

> “打开富士山和雷尼尔山的维基百科页面，告诉我哪座山更高。”

连接扩展后，使用浏览器会在后台打开自己的标签页，你当前所在的页面不会变动。扩展工作期间，浏览器会在页面顶部显示一个提示栏，请不要取消它。当智能体的这一轮任务结束时，它打开的标签页会自动关闭。作为结果交给你查看的页面、已移交给你的标签页、你固定的标签页以及你正在看的标签页会保持打开，你自己的标签页绝不会被关闭。

## 电脑操作能做什么

| 操作 | 示例 |
|--------|----------|
| **检查应用状态** | 读取当前窗口、控件、菜单项、选中的文本以及可见字段 |
| **点击与双击** | 点击按钮、侧边栏行、工具栏项目、菜单命令以及指定坐标 |
| **输入与按键** | 填写字段、提交表单、使用快捷键（如 **⌘S**） |
| **滚动** | 浏览列表、表格、设置面板或长文档 |
| **拖拽** | 在应用支持时拖拽文件、列表行、滑块或选区手柄 |
| **使用文件选择器** | 在打开和保存对话框中选择文件与文件夹 |
| **操作后等待** | 在点击、跳转或加载步骤后再次检查应用界面 |
| **登录应用** | 将保存的用户名和密码输入到应用的登录界面，同时不让智能体看到密码。参见[凭据](/zh/configuration/credentials)。 |

多个智能体可以同时使用电脑操作，例如在不同应用中工作的子代理。每个子代理都在各自的应用中同时操作；只有操作同一个应用的智能体才会轮流进行。即使该应用的另一个窗口在最前面，操作也会准确发往智能体所指的窗口。

## 选择可用应用

**设置 → 电脑操作 → 应用访问** 用于设置电脑操作可以查看和使用的应用。选择一种 **模式**：

- **所有应用，除了**：电脑操作会跳过 **已屏蔽的应用** 中的应用，可以使用其他所有应用。
- **仅这些应用**：电脑操作只使用 **允许的应用** 中的应用。在 **当智能体需要其他应用时** 下，选择 **让我确认**，以便在智能体需要某个应用时回答“允许电脑操作使用此应用吗？”，或选择 **拒绝**。

点击 **添加应用**，即可从当前打开的应用或“应用程序”文件夹中添加应用。已屏蔽的应用不会出现在截图中。密码管理器和系统登录提示始终处于屏蔽状态，显示为 **密码与系统提示**。PopBar、选中文本和听写保留各自独立的设置。

## 示例

| 请求 | Enconvo 的操作 |
| --- | --- |
| “在这个文件选择器里，选中桌面上最新的一张截图。” | 查看文件选择器，前往该文件夹，选中文件并确认对话框。 |
| “打开这个应用的偏好设置并关闭通知。” | 操作应用菜单，找到对应设置，关闭它并核对结果。 |
| “在时钟应用中，把东京和伦敦添加到世界时钟。” | 查找各个城市，依次添加到列表，并核对两者均已添加。 |
| “找到我的简历并申请这个职位。” | 找到文件，填写表单中的每一项，附上文件并提交。提交前请先核对表单内容。 |
| “从邮件里复制验证码并粘贴到登录窗口。” | 读取可见窗口，在窗口间切换，复制文本并粘贴到输入框中。 |

## 注意安全

<Warning>
电脑操作处理的是真实应用与真实数据。在允许 Enconvo 提交表单、修改账户设置、删除文件、付款或发送消息前，请先核对屏幕内容。
</Warning>

- 尽量让目标窗口保持可见。
- 给出明确的目标与边界限制。
- 在 Enconvo 操作隐私或财务页面前先进行确认。
- 如果屏幕上正在发生的操作与你的要求不符，请立即停止任务。

## 设置

| 设置 | 位置 | 作用 |
| --- | --- | --- |
| **应用访问** | **设置 → 电脑操作** | 电脑操作可以查看和使用哪些应用；参见[选择可用应用](#选择可用应用)。 |
| **画中画窗口** | **设置 → 电脑操作** | 何时在屏幕角落显示应用窗口的实时画面：**始终**（默认）、**仅在需要我时** 或 **关闭**。参见[画中画](/zh/features/picture-in-picture)。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| Enconvo 无法识别某个应用的控件 | 检查 Enconvo 是否已获得辅助功能权限，然后重启 Enconvo 和该应用。部分应用暴露给系统的控件较少，但截图和按坐标点击通常仍可使用。 |
| 点击到了错误的应用 | 开始前先将目标应用置于最前。当打开了多个窗口时，请在请求中指明应用或窗口名称。 |
| 在文件选择器中选取文件失败 | 确认文件确实存在且选择器支持该文件格式。对于存储在 iCloud 或网络驱动器上的文件，请先等待其下载完成。 |
| 智能体表示无法使用某个应用 | 该应用在 **设置 → 电脑操作 → 应用访问** 中被屏蔽或未加入允许列表。请调整列表，或在智能体请求使用该应用时通过提示授权。 |
| 任务推进得太快 | 让 Enconvo 等待你能看到的状态变化，例如“等到保存按钮变为可用后再继续”或“等表格重新加载后再继续”。 |

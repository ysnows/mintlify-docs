title: "Live Talk"

Live Talk 是你与智能体之间的语音通话。无需按住任何按键即可直接说话，智能体会出声作答，并在通话进行期间调用它已启用的工具为你启动任务。如果你只想把语音转成输入的文字，请使用[听写](/zh/features/dictation)。

## 开始之前

Enconvo 需要在 macOS 中获得麦克风权限。请选择可正常工作的麦克风与扬声器。通话中使用的 Cloud 服务会消耗 Enconvo Cloud 点数；使用你自己的密钥以及在 Mac 上运行的本地模型则不会消耗。

## 开始和结束通话

1. 打开与你想通话的智能体的聊天。
2. 点击麦克风旁的 **Live Talk**，等待通话接通。
3. 直接说话。无需按住按键，你可以在任何时候开口打断智能体，让它停下来听你说。
4. 如果是比较大的工作，说明你想要的最终结果并给出足够的背景信息。该工作会作为一项任务在它自己的聊天中运行。展开工作详情即可查看进度或结果。
5. 使用麦克风控制按钮静音，或使用挂断按钮结束通话。挂断后，已启动的任务仍会继续运行。

通话中的语音轮次会保存在常规的聊天记录中，因此重新打开聊天就能回看对话和工作详情。即使没有说话，通话也会保持连接直到你挂断。聊天中任务的链接可以带你回到通话中。

## 直接提问，无需发起任务

有些事情智能体可以在通话中直接完成，无需发起任务：搜索你的记忆和过往聊天、保存你让它记住的内容、读取你的日历和提醒事项、搜索邮件，以及使用你 MCP 服务器的只读工具。设置中的 **快捷操作** 列出了更多可用项。

在执行较长的任务时，智能体会告诉你任务目前为止的发现。

## 让智能体保持安静

告诉智能体安静一会儿或先不要说话。它不会回应任何内容，也会暂存新消息，直到你叫它的名字、说可以继续说话了、给它打字，或点击 **安静中** 状态。

## 其他通话方式

当任务需要你时，智能体也可以通过 iPhone 应用或你的电话号码给你打电话；接听即可开始 Live Talk。参见[智能体电话](/zh/features/agent-phone)。

你也可以从[虚拟形象](/zh/features/avatar)发起通话，此时它会作为说话者出现；或在 [iPhone 应用](/zh/integrations/iphone-app)的语音聊天中发起。在 iPhone 或 Android 应用上通话时，**远程屏幕** 工具会在通话界面上方的小悬浮窗中打开你电脑的屏幕；参见[使用你电脑的屏幕](/zh/integrations/iphone-app)。打开 **实时屏幕**，可以让智能体在通话中看到你的屏幕。

## 设置

打开 **设置 → Live Talk**：

| 设置 | 作用 |
| --- | --- |
| **收音** | 通话如何听你说话。**Enconvo Cloud Fast**（默认）和 **ElevenLabs Scribe**（Scribe v3 Live）会在你说出每个词时就听到它。你也可以选择在 Mac 上运行的模型，或任意语音模型。 |
| **思考** | 智能体交谈所用的模型。**与聊天相同**（默认）会使用该聊天所属服务提供商的快速模型，因此在使用你自己 API 密钥的聊天中通话不会消耗 Enconvo Cloud 点数。在基于 Enconvo Cloud 的聊天中，它会使用 Enconvo Fast，由 DeepSeek V4.1 Flash 作答，也能看到你展示的内容，并按该模型计费；付费套餐或试用期间的通话仍然免费。较大的工作会交给你的智能体，并使用为该聊天选择的模型运行。 |
| **说话** | 智能体回答时使用的声音，默认为 ElevenLabs v4 Turbo。Phonon 可在你的 Mac 上免费离线运行，但仅支持英文。更改将在下一次通话生效。 |
| **语气表现** | 每次回复的语气可以根据对话情境变化到什么程度：**关闭**、**轻微** 或 **丰富**。支持 ElevenLabs、Fish Audio 和 Gemini 语音。 |
| **多久后开始新对话** | 在上一次通话结束后的这段分钟数内再次发起通话，会从上次停顿的地方继续，虚拟形象通话也包含在内。设为 **0** 则始终继续对话。 |
| **快捷操作** | **管理** 会打开 **设置 → 快捷操作**，其中列出了当你要求时智能体无需启动任务即可立即执行的操作。 |

<Note>
Live Talk 的 **思考** 模型在这里设置。你也可以在 **设置 → AI 模型** 的 **任务模型** 下选择它。
</Note>

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 通话无法接通 | 查看连接错误信息，然后检查你的 **收音**、**思考** 和 **说话** 选项。如果使用 Cloud 服务，请在 **设置 → 点数用量** 中检查你的点数。 |
| 麦克风不可用 | 先结束正在进行的听写或录音，并检查 macOS 的麦克风权限。 |
| 智能体无法执行某项操作 | 检查该智能体的工具与权限设置。语音通话不会为智能体增加它原本没有的工具。 |
| 新切换的声音没有生效 | 声音更改会从下一次通话开始生效。 |
| 通话以“音频设备已更改”结束 | 你的麦克风或扬声器在反复重启。请在 **系统设置 → 声音** 中选择另一个设备，然后发起新通话。 |
| 智能体不再回答 | 它可能处于安静状态。叫它的名字，或点击 **安静中** 状态。 |

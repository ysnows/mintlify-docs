---
title: "使用浏览器"
description: "让智能体在你真实的浏览器标签页中阅读和操作，并沿用浏览器中已有的登录状态。"
---

使用浏览器功能让智能体在连接了 Enconvo Companion 扩展的浏览器标签页中工作。它可以阅读页面、点按控件、填写字段、检查结果并管理标签页，全程沿用你浏览器中已有的登录状态。当任务需要用到你已登录的网站时，就可以使用它。

## 开始设置

<Steps>
  <Step title="安装扩展">
    在受支持的 Chromium 浏览器中[从 Chrome 网上应用店安装 Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd)，或在**设置 → 使用浏览器**中点按**安装浏览器配套程序**。对于其他浏览器，请使用为该浏览器制作的扩展安装包。
  </Step>
  <Step title="保持两者运行">
    保持 Enconvo 和浏览器处于打开状态。
  </Step>
  <Step title="检查连接">
    点按扩展图标。弹出窗口会显示 **Connected** 和浏览器名称。
  </Step>
  <Step title="检查访问权限">
    确保你要使用的智能体拥有浏览器工具，并批准扩展询问的任何网站。
  </Step>
  <Step title="先试一个只读任务">
    从不会改变任何内容的任务开始，例如“阅读这个页面并总结要点。”
  </Step>
</Steps>

Safari 不使用 Chromium 扩展。在 Safari 中，改由[电脑操作](/zh/features/computer-use)在屏幕上点按和输入，因此并非每个浏览器都能做同样的事。有关弹出窗口、已连接的浏览器、标签页定位和网站审批，请参见[浏览器扩展](/zh/features/browser-extension)。

## 在指定标签页中工作

在请求中说明浏览器和页面：

> 在 Edge 中，阅读当前的文档标签页，列出三个设置步骤。保持页面打开。

智能体会阅读页面、选取元素、执行操作并检查发生了什么变化。页面元素可能在页面跳转或实时更新后发生变化。如果智能体找不到某个元素，请让它重新查看页面。

当智能体在你看不到的标签页中工作时，一个[画中画](/zh/features/picture-in-picture)窗口会在屏幕角落实时显示该标签页。点按它即可前往该标签页并接管控制。

## 任务结束时

智能体打开的标签页会在它的回合结束时关闭。以下标签页会保持打开：

- 智能体作为结果交给你的页面
- 它交给你接管的标签页
- 你固定的标签页
- 你当前正在查看的标签页

你自己的标签页绝不会被关闭。

## 它能做什么

| 类别 | 示例 |
| --- | --- |
| 导航 | 打开 URL、后退或前进、重新加载、等待某个条件 |
| 阅读 | 页面状态、可见文本、属性、截图、选中的内容 |
| 交互 | 点按、输入、填写、选择、按键、滚动、拖动 |
| 浏览器管理 | 查看和管理标签页、窗口和已连接的会话 |
| 高级工具 | 页面求值、Cookie、存储、历史记录以及特定于浏览器的检查 |

### 截取整张网页

让智能体截取整张网页，例如“把这整个页面的截图保存到我的桌面”。它会在你指定的位置保存一个 PNG 文件，分辨率与页面本身一致，且不会包含智能体的光标。

### 登录与人机验证

当任务到达网站的登录页面时，一张卡片会向你询问一次用户名和密码。Enconvo 只会在该网站填入这些信息，智能体永远看不到密码；参见[凭据](/zh/configuration/credentials)。当页面出现人机验证时，智能体可以把标签页交给你。在该标签页中完成登录或验证后，点按 **交还给智能体** 即可将控制权交回。

具体能做什么取决于浏览器、页面、扩展版本以及你开启的工具。`chrome://` 等浏览器页面和其他受限内容可能无法访问。

<Warning>
使用浏览器会操作你的真实账户。请说明任务是只准备草稿，还是也要提交。
</Warning>

## 设置项

| 设置 | 位置 | 作用 |
| --- | --- | --- |
| **默认浏览器** | **设置 → 使用浏览器**，然后在 **⋯** 菜单中选择**设置** | 未指定浏览器时任务使用的浏览器。**自动（系统默认）**会跟随 Mac 的默认浏览器。 |
| **浏览器扩展** | **设置 → 使用浏览器** | 列出安装了该扩展的浏览器，每个显示为**已连接**或**已断开连接**。 |
| **画中画窗口** | **设置 → 使用浏览器** | 智能体标签页的实时画面何时显示在屏幕角落：**始终**（默认）、**仅在需要我时** 或 **关闭**。参见[画中画](/zh/features/picture-in-picture)。 |

你也可以直接在任务中指定浏览器。

面向开发者：Local API 路由 `browser-use/status` 会报告连接状态，**设置 → API** 会列出已安装的路由及其 schema。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 未连接 | 检查扩展是否已开启、Enconvo 是否正在运行，并查看弹出窗口。扩展通过端口 11225 连接到这台 Mac 上的 Enconvo。 |
| 浏览器或标签页不对 | 说明浏览器和页面，并让它重新查看页面。 |
| 点按或填写失败 | 查看页面当前的状态。对话框、页面跳转或嵌入的框架可能让目标发生了变化。 |
| 截图是空白的 | 将标签页切到前台，并等待页面加载完成。 |
| 网站要求你登录 | 像平常一样登录该网站。登录了浏览器并不代表每个网站的会话仍然有效。 |

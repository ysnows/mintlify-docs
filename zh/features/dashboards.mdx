---
title: "仪表盘"
description: "让智能体把你的数据变成一个可保存的数字和图表页面，核对每个数字对应的原始行，并让数据保持最新。"
---

仪表盘是由智能体根据你的数据生成的数字和图表页面，适合用于持续跟踪、审阅或汇报的数据指标。每个数字都与它所来自的原始行关联，方便你随时核对。当你需要反复查看这些数字时可以使用它；如果只是一次性的问题，直接在聊天中提问即可。

## 制作仪表盘

1. 开始一个新聊天并在消息框下方选择 **仪表盘**，或在任意聊天中直接要求创建一个仪表盘。
2. 附加数据：CSV、TSV 或 JSON 文件，或者点击 **做点什么** 行中的 **打开表格**。你也可以让智能体读取已连接的服务、Mac 上的文件或某个网址。
3. 说明需要跟踪的内容以及如何拆分数据。

示例：

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

仪表盘会在聊天旁边打开。如果智能体添加了筛选器，每个筛选器都会以菜单、开关或输入框的形式显示在顶部。

## 核对数字

1. 点击仪表盘顶部栏中的 **核对数字**。
2. 点击任意数字。
3. Enconvo 会显示它背后的原始行、数据来源，以及两者是否一致。

要针对某个数字提问，可以对它发表评论。以 `@Enconvo` 开头的评论会收到来自智能体的回复。

## 查看数据来源

点击 **来源**。每组数据都会显示它的来源、包含的行数以及上次更新时间。已过期的数据会显示 **已过期**。点击 **下载 CSV** 可以保存某组数据。

## 让数字保持最新

基于已连接的服务、Mac 上的文件或网址构建的仪表盘，在你允许后可以自动更新。

1. 当仪表盘询问 **要让这些数字保持最新吗？** 时，检查每个来源读取的内容，然后点击 **允许**。你也可以在 **来源** 中点击某个来源旁的 **允许更新**。
2. 数字会按照智能体设定的时间表更新，例如 **每小时** 或 **刷新时**。点击 **刷新** 可立即更新。
3. 要停止自动更新，请点击来源旁的 **停止更新**。

当更新失败时，仪表盘会保留上一次的数字并说明原因。

<Note>
未说明仅读取数据的来源，只会在你点击 **刷新** 时运行。在共享的仪表盘中，所有人都能看到来源读取了什么内容。
</Note>

## 下载或迁移仪表盘

点击 **下载** 并选择：

| 选项 | 导出内容 |
| --- | --- |
| **下载 PDF** | 该页面的 PDF 文件 |
| **下载图片** | 该页面的图片 |
| **下载 HTML** | 可在任意浏览器中打开的单个 HTML 文件 |
| **下载项目 (.zip)** | 整个项目，便于导入到另一台电脑 |

要导入项目，请在 **作品** 资料库中点击 **导入** 并选择该 zip 文件。评论会一并保留；来自已连接服务的更新需要在新电脑上重新允许。

要与个人或团队分享仪表盘，请点击 **分享**。参见[作品](/zh/features/artifacts)。仪表盘也可以在 iPhone 和 Android 应用中打开；参见[作品](/zh/features/artifacts)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 某个数字与其原始行不一致 | 在评论中向智能体询问原因，或让它修正计算方式 |
| 某个来源显示 **已过期** | 点击 **刷新**，或为它允许自动更新 |
| **无法更新数字** | 查看原因并修复该来源的访问权限，然后点击 **刷新** |
| 仪表盘为空 | 在聊天中描述仪表盘及其数据 |

title: "智能体电话"
description: "让你的智能体在任务需要你时给你打电话、代你拨打他人或 Enconvo 好友的电话，并替你接听未接来电。"
---

智能体电话让你的智能体可以使用电话功能。智能体可以在任务等待你输入时给你打电话、在聊天中拨打你指定的人或商家的电话、替你呼叫 Enconvo 好友和团队成员，以及接听你没有接起的 iPhone 来电。每次通话的文字记录都会回到聊天中。

## 开始之前

打开 **设置 → 智能体电话**，至少设置一种通话方式：

| 方式 | 作用 | 费用 |
| --- | --- | --- |
| **你的 iPhone** | 当你的 iPhone 在附近时，这台 Mac 会通过你自己的号码在你的 iPhone 上拨打和接听电话。开启 **替我接听来电** 必须使用此方式。 | 按你的手机套餐资费（无额外费用）。 |
| **电话服务商** | 智能体使用你自己的 Twilio 或 Telnyx 账户中的号码拨打电话。 | 由服务商按通话计费。 |
| **EnConvo 移动应用** | 智能体像打电话一样呼叫你手机上的 EnConvo 应用。接听后即进入 [Live Talk](/zh/features/live-voice)。在 Android 上，从响铃通知或锁屏界面直接接听即可接通，无需解锁或打开应用。仅适用于呼叫你本人。 | 通过 Wi-Fi 或移动数据免费通话。 |

## 设置你的 iPhone

1. 在 **你的 iPhone** 下点击 **设置**。图形引导会一步步带你完成配置，并为你打开每一步对应的设置界面。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中打开 Enconvo，以便 Enconvo 能够在 macOS 的通话弹窗中按下呼叫和挂断按钮。
3. 在 **FaceTime → 设置 → 通用** 中开启 **来自 iPhone 的通话**。
4. 在 **系统设置 → 通知** 中为“电话”和“FaceTime 通话”开启 **允许通知** 和 **桌面**。macOS 会以通知形式显示每通来电。
5. 确认你的 iPhone 和这台 Mac 使用同一个 Apple 账户。在 iPhone 上打开 **设置 → App → 电话 → 在其他设备上通话**，并允许这台 Mac。
6. 让你的 iPhone 靠近这台 Mac，并连接在同一 Wi-Fi 下。
7. 点击 **添加 Enconvo Audio**，在 macOS 提示时输入你的 Mac 登录密码。Enconvo Audio 负责把智能体的声音送入通话并将对方的声音传回，不会占用你的麦克风或扬声器。
8. 点击 **检查音频**。它会通过 Enconvo Audio 播放一段短提示音并进行检测；不会实际拨号响铃。

当状态显示为 **已就绪** 时，智能体就会通过你的 iPhone 号码拨打电话，对方看到的也是你的号码。如果此时你的 iPhone 不在附近，且你配置了电话服务商，则会改由电话服务商呼出。

## 设置电话服务商

1. 在 **电话服务商** 下，点击 Twilio 或 Telnyx 旁边的 **设置** 或 **连接**。Enconvo 会添加对应插件并提示你登录或输入 API 密钥。
2. 在 **来电号码** 中选择用于呼出的号码。
3. 点击 **测试来电** 试用。

智能体默认使用首选服务商，只有在你在聊天中特别指定，或默认服务商无法拨打时，才会改用另一家。Telnyx 通话通过名为 Enconvo Agent Phone 的 TeXML 应用进行，Enconvo 会自动将其添加到你的账户中。Twilio 试用账户只能拨打你在 Twilio 中验证过的号码。

通过 Twilio 和 Telnyx 拨出的电话支持按拨号键，因此智能体可以通过自动语音菜单和分机号。通过 **你的 iPhone** 拨出的电话同样支持。

## 任务需要你时来电通知

在 **智能体来电设置 → 等待你处理的任务** 下，选择你不在 Mac 前时智能体如何联系你：

1. 如果已配对，会立即呼叫 EnConvo 移动应用。
2. 如果未接听，则会拨打你的电话号码。设置好号码，并选择 **拨出线路**：**你的 iPhone**、Twilio 或 Telnyx。

来电时会显示智能体的名称。同一聊天中等待处理的请求会合并为一通电话，如果你拒接，则不会重复呼叫。**通知延迟** 用于设置任务等待多久后再通知你。**包含任务详情** 会在拨打手机号码时朗读任务内容；关闭时只会播报聊天标题，且无法通过电话直接批准操作。

你也可以在聊天中直接让智能体给你打电话，并指定通过应用、你的 iPhone、Twilio 或 Telnyx 拨出。你主动请求的来电每次都会响铃。

## 让智能体代你致电他人

1. 在 **智能体来电设置** 下开启 **代你拨出电话**。
2. 在聊天中让智能体给某个人或商家打电话，并说明通话目的。
3. 通话卡片会显示号码以及将要转达的内容。点击 **确认拨打**。在以完全访问权限运行的聊天中，智能体会直接拨号而不等待确认。
4. 你可以在卡片上关注通话进展，或点击 **结束通话**。通话结束后，结果卡片会展示双方的对话内容。

如果尚未配置电话线路，通话卡片会让你直接在聊天中设置 **你的 iPhone** 或 Telnyx，准备就绪后即可自动接通。

## 让智能体呼叫好友

让智能体呼叫一位 Enconvo [好友](/zh/features/friends)或团队成员，并告诉它要说的话。它会先呼叫对方的 Enconvo 应用，代你与对方沟通，然后把对方的答复和通话文字记录带回你的聊天中。只有当你明确要求拨打普通电话，或 Enconvo 通话未能接通时，它才会拨打对方的电话号码。

智能体只会联系你的好友和团队成员，绝不会联系仅在通话中遇到过的人。定时任务也可以向你允许联系的好友发送消息和拨打电话。例如，它可以在午夜给某人发送一份报告，如果对方到早上还没回复，就打电话提醒。

## 录制通话

开启 **录制通话** 后，每一通智能体通话（无论是打给你还是打给其他人，无论是通过应用还是电话号码）都会连同文字记录一起保存到这台 Mac 上的[录音](/zh/features/meeting-recording)中。**最近通话** 中每条已录制的通话都有一个录音按钮。智能体呼叫好友时，对方会听到并看到通话正在录制中；如果对方表示不希望被录制，则不会保留录音。

<Warning>
部分地区要求通话中的所有人都同意后才能录音。请确保你有权对智能体呼叫的对象进行录音。
</Warning>

## 让智能体替你接听未接来电

**替我接听来电** 需要配合 **你的 iPhone** 使用。当你没有接听 iPhone 上的来电时，智能体会直接在你的 Mac 上接听、记下留言，并将摘要和文字记录发送到 **动态**。

1. 在 **你的 iPhone** 下开启 **替我接听来电**。按提示允许访问通讯录，这样 Enconvo 就能识别通讯录中保存的联系人。
2. 设置 **你没有接听时**：响铃几声后接听，默认为 5 秒。
3. 选择要接听哪些来电：**不在通讯录中的号码** 或 **所有人**。开启 **安静时段内立即接听** 后，在“通知”中设定的安静时段内会跳过等待时间直接接听。
4. 在 **可以说的内容** 中，写明它以什么身份接听以及可以告诉来电者什么信息。它只会记下留言，绝不会替你答应任何事。
5. 如果你有多台 Mac，选择 **优先接听** 的那一台。你的其他 Mac 只有在它离线时才会接听。

每通电话结束后，你的手机都会收到一条通知，包含来电者是谁、一句话概括的来电目的，以及是否紧急。紧急来电会穿透专注模式提醒你。通知上带有 **回拨** 和 **打开** 按钮。疑似诈骗的来电会带有 **疑似诈骗** 标记和警告提示。

来电者无法命令你的智能体执行操作。通话过程中它只会交谈并记下留言，无法访问工具、聊天记录、记忆或文件。摘要也是在不使用工具的情况下生成的。在本次通话对应的聊天中，除非你亲自回复，否则不会运行任何操作；涉及发送、付款、删除或运行命令的操作也会先征求你的同意，即使开启了完全访问权限也是如此。设置中的 **来电者可访问范围** 会列出这些限制。

### 可以布置任务的号码

在 **可以布置任务的号码** 下添加你自己的其他电话号码。这些号码打来时可以直接与你的智能体对话并布置任务；其他任何号码只能留言。由于伪造的来电显示可能冒充这些号码，建议开启 **要求提供口令**：在来电者说出正确口令之前，通话只会记录留言。

## 查看通话记录

聊天窗口侧边栏中的 **通话** 分区会将智能体接听的来电与你的其他聊天分开保存。它会标出紧急、需要回拨或尚未阅读的来电，并显示每通来电的响铃时间以及来电号码或联系人姓名。点击 **回拨** 或 **标记为已完成** 即可处理。iPhone 和 Android 应用中也有同样的分区。

**设置 → 智能体电话** 底部的 **最近通话** 列出了智能体拨出或接听的每一通电话及其结果。

## 设置

| 设置 | 作用 |
| --- | --- |
| **你的 iPhone** | 通过这台 Mac 使用你自己的 iPhone 号码通话，以及 **替我接听来电**。 |
| **电话服务商** | Twilio 和 Telnyx 账户、默认服务商以及 **来电号码**。 |
| **呼叫 EnConvo 应用** | 允许智能体呼叫你已配对的手机。**配对手机** 可添加设备。 |
| **等待你处理的任务** | 任务等待时智能体如何联系你：先呼叫应用，再拨打你的号码，可设置 **拨出线路**、**通知延迟** 和 **包含任务详情**。 |
| **代你拨出电话** | 允许智能体拨打你在聊天中指定联系人的电话。 |
| **录制通话** | 将智能体通话及其文字记录保存到录音中。 |
| **替我接听来电** | 让智能体替你接听你没有接起的 iPhone 来电。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **缺少 Enconvo Audio** | macOS 更新有时会将其移除。点击 **重新添加**，并在 macOS 弹出的窗口中输入你的 Mac 登录密码；该窗口有时可能被挡在其他窗口后面。 |
| **辅助功能未开启** | 在 **系统设置 → 隐私与安全性 → 辅助功能** 中打开 Enconvo。 |
| **听不到通话声音** | 在 **系统设置 → 隐私与安全性 → 录屏与系统录音** 的 **仅系统录音** 下允许 Enconvo，然后点击 **检查音频**。 |
| **通知已关闭** | 为“电话”和“FaceTime 通话”开启 **允许通知** 和 **桌面**。在此之前，来电通知与通话将改用你的电话服务商。 |
| **你的 iPhone 不在附近** | 将 iPhone 带到这台 Mac 附近并连接同一 Wi-Fi。在此之前，通话将改用你的电话服务商。 |
| Twilio 电话打不通 | 试用账户只能拨打已验证过的号码。请在 Twilio 中验证该号码，或升级账户。 |
| **替我接听来电** 无法识别联系人 | 为 Enconvo 开启通讯录权限，或让可以读取通讯录的 Mac **优先接听**。 |

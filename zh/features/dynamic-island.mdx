灵动岛位于屏幕顶部正中。将指针移到它上面即可打开首页，在这里你可以输入或说出请求、附加上下文、运行快捷操作，或回到进行中的任务。用它快速发出请求，也用它在不打开窗口的情况下留意智能体的工作。

其他场景：用快捷键快速提问或运行命令用 [SmartBar](/zh/features/smartbar)，长对话和处理文件用[聊天窗口](/zh/ai/chat)，在某个应用旁边工作用[应用侧边栏](/zh/features/app-sidebar)，处理选中的文字用 [PopBar](/zh/features/popbar)，想在桌面上放一个角色则用[桌面宠物](/zh/features/pet)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

## 发起请求

1. 打开 **设置 → 灵动岛**，打开 **启用灵动岛**。
2. 将指针移到屏幕顶部正中打开首页。如果想用键盘打开，先在 **打开与显示** 标签页上设置一个 **快捷键**。
3. 输入请求，或点击某个 **首页快捷操作**。
4. 发送前检查附加的上下文。[Appshots](/zh/features/appshots) 和[屏幕涂鸦](/zh/features/screen-doodle)可以帮你就其他应用提问。
5. 查看进度，任务完成后打开结果。要停止回复，点击 **停止** 或按 Esc。

任务运行期间你输入的消息会立即显示。要切换到聊天窗口，请点击灵动岛顶部栏中的 **在聊天窗口中打开**；在聊天开始前点击它，会在聊天窗口中开启新聊天并带上你已输入的内容。

在智能体模式下，**权限** 标签决定智能体何时在行动前先询问，它的 **沙盒** 开关则把智能体的命令限制在工作文件夹内。参见[智能体沙盒](/zh/configuration/sandbox)。

## 在首页计算

在首页输入算式、换算或时间，答案会显示在灵动岛下方的卡片中。按 Return 复制，或按 **⌘Return** 改为向你的智能体提问。

计算器支持数学运算、单位、货币、日期和时区换算。如果想同时查询任意地点的天气、航班和当地时间，请在 **设置 → 灵动岛 → 首页** 中打开 **天气和航班**。系统只会将地名或航班号发送给 Open-Meteo、adsbdb 和 adsb.lol。该开关与 [SmartBar](/zh/features/smartbar) 共用。

## 跟进你的任务

任务列表会显示正在运行、需要你批准、失败或已出结果的聊天。当有两个或更多任务同时运行时，它们会折叠为一个 **任务** 标签。

1. 点击首页或刘海区域的任务标签。列表会就地替换输入框打开。
2. 直接在对应行中允许或拒绝批准请求。
3. 点击其他任意聊天，即可在它发起时的窗口中打开。

要查找未读聊天，请打开 **历史记录** 并按 **未读** 筛选。**全部标为已读** 会一次性清除所有未读状态，如果你改变主意，还可以点击 **撤销**。聊天列表还提供 **归档聊天** 和 **删除聊天记录**。

## 设置

打开 **设置 → 灵动岛**。它的设置分布在三个标签页上。

### 首页

| 设置 | 作用 |
| --- | --- |
| **首页快捷操作** | 首页输入框旁的快捷操作网格。拖动快捷操作可调整顺序或移到另一页，将指针移到它上面点击 **×** 可将其移除，或点击 **添加快捷操作** 添加更多。 |
| 天气和小组件页面 | 在快捷操作之后 **添加天气页** 或 **添加小组件页**。 |
| **计算器** | 在首页输入时回答数学运算、单位、货币、日期和时区问题。 |
| **天气和航班** | 同时查询任意地点的天气、航班和当地时间。与 SmartBar 共用。 |
| **默认智能体** | 回答你在首页输入内容的智能体。空白的首页始终运行其按钮上显示的默认智能体。你可以随时在输入框中切换智能体。 |

**将首页恢复默认** 可恢复首页的默认布局。每个标签页都有自己的重置按钮。

### 打开与显示

| 设置 | 作用 |
| --- | --- |
| **指向时打开** | 指针停留多久后打开：**立即**、**稍作停顿** 或 **较长停顿**。 |
| **移开时收起** | 指针离开后它保持打开多久：**很快**（半秒）、**标准** 或 **较慢**。 |
| **快捷键** | 在任意应用中显示、打开或收起灵动岛。 |
| **指向前保持隐藏** | 收起的灵动岛保持隐藏，直到你将指针移到屏幕顶部正中或按下快捷键。 |
| **把刘海区域留给其他应用** | 指向刘海本身不会打开灵动岛，这样其他刘海应用就能使用它。 |
| **弹性** | 灵动岛打开和收起时的回弹幅度。 |
| **显示在** | **所有屏幕**、**跟随鼠标**，或你选择的某一台显示器。 |
| **全屏时隐藏** | 当某台显示器上有应用处于全屏时，在该显示器上隐藏灵动岛的常驻胶囊条，以免遮挡应用顶部。默认开启。只有应用报告为全屏的窗口才算数，最大化窗口不算。将指针移到灵动岛上或对它说话仍会唤出它。 |
| **在截图和录屏中显示** | 关闭后，你截取或共享的内容中将不包含灵动岛。 |

### 角色

| 设置 | 作用 |
| --- | --- |
| **在灵动岛上显示角色** | 你的桌面宠物或默认智能体的虚拟形象会出现在收起的灵动岛中，并用动作表现智能体正在做的事。 |
| **角色** | **虚拟形象** 或 **宠物**。 |
| **动作** | **始终**、**工作时** 或 **从不**。 |
| **用作智能体图标** | 在聊天窗口中把该角色显示为默认智能体的图标。 |

## 语音与已完成的任务

语音输入会把你说的话变成提示词。要进行语音对话，请使用 [Live Talk](/zh/features/live-voice)；从 SmartBar 发起的 Live Talk 通话会移到灵动岛上。

如果希望在灵动岛中发起的任务完成时灵动岛自动打开，请在[通知](/zh/configuration/notifications)中打开 **打开灵动岛**。该设置与 macOS 通知相互独立。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 它出现在另一台显示器上 | 检查 **显示在**。 |
| 应用全屏时它消失了 | 这是默认行为。将指针移到屏幕顶部即可打开它，或关闭 **全屏时隐藏**。 |
| 菜单栏自动隐藏时它打不开 | 点击屏幕顶部正中。 |
| 首页上的计算或查询没有显示结果 | 检查 **首页** 标签页中的 **计算器** 和 **天气和航班**。 |
| 截图或录屏中没有它 | 在更改任何权限之前，先打开 **在截图和录屏中显示**。 |
| 指向它时不会打开 | 按它的快捷键。如果快捷键能打开，检查 **指向时打开** 和 **把刘海区域留给其他应用**。如果怎么都打不开，检查 **启用灵动岛**。 |

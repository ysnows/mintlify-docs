快速捕捉会把当前应用的内容保存到知识库，供以后使用。每次捕捉都会保留窗口截图和其中的文字：浏览器保存网页内容，YouTube 视频则保存字幕。[Appshots](/zh/features/appshots) 是把应用窗口附加到你正在问的问题上；快速捕捉则会生成一个长期保留的知识库条目。

## 捕捉值得保留的内容

1. 把包含该内容的应用切到前台。
2. 按下快速捕捉快捷键，或打开[灵动岛](/zh/features/dynamic-island)并点按 **快速捕捉**。快速捕捉默认没有快捷键，需在 **设置 → 快速捕捉** 的 **快捷键** 中设置后才会启用。
3. 按下快捷键的瞬间，Enconvo 就会截下画面并显示其胶囊提示，然后把捕捉内容保存到 **保存到** 中设置的知识库；除非你选择了其他知识库，否则就是默认知识库。同时会播放一声短促的快门声。
4. 通知会显示保存了什么以及保存到哪里。点按 **打开** 可在知识库中查看，或点按 **撤销** 撤回这次捕捉。

如果保存失败，通知会提供 **重试** 和 **关闭**。[语音笔记](/zh/features/voice-notes)也提供相同的 **撤销**、**重试** 和 **关闭**。

条目出现后，索引和摘要可能还要稍等片刻才会完成。

## 设置

打开 **设置 → 快速捕捉**。

| 设置 | 作用 |
| --- | --- |
| **启用快速捕捉** | 允许快捷键保存当前应用。它也同时开启或关闭[语音笔记](/zh/features/voice-notes)快捷键。默认打开。 |
| **保存到** | 捕捉内容存入的知识库。捕捉内容不能存入记忆。 |
| **录制声音** | 保存捕捉内容时播放一声短促的快门声。 |
| **自动摘要** | 用 AI 为每次捕捉生成摘要。摘要显示在条目预览中，并且可以被搜索。 |
| **快捷键** | 用于保存当前应用的快捷键。默认无快捷键。可以是双击某个修饰键，例如右侧 **Shift** 键，也可以是普通快捷键。 |

**自动摘要** 会把捕捉到的文字发送给你的 AI 模型。如果你想控制捕捉内容在哪里处理，请检查模型和服务提供商设置。

### X 帖子

同一页面上的 **X** 部分用于设置 Enconvo [浏览器扩展](/zh/features/browser-extension)在 x.com 上的行为。

| 设置 | 作用 |
| --- | --- |
| **卡片样式** | 把已保存的帖子显示为 **帖子** 或 **截图**。切换后，之前保存的帖子也会一并改变。 |
| **在 X 上添加书签时** | X 自带的书签按钮的行为：**在 X 上添加书签**、**添加书签并保存到 Enconvo** 或 **仅保存到 Enconvo**。在你做出选择之前，Enconvo 会在你第一次添加书签时询问。移除书签不会删除 Enconvo 中的帖子。 |
| **“询问 Enconvo”按钮** | 在每条帖子标题栏的 Grok 旁边显示 Enconvo 按钮，用来就帖子及其回复提问。 |
| **自动总结 X 帖子** | 用 AI 总结每条已保存的帖子及其串文。 |
| **自动为已保存的帖子分类** | 按主题为每条已保存的帖子添加标签。需要登录。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 内容缺失或不完整 | 检查[权限](/zh/configuration/permissions)，把目标应用切到前台，并用一个简单、清晰可见的例子试试。 |
| 找不到捕捉内容 | 检查 **保存到**，然后打开对应的知识库。条目刚出现时，索引和摘要可能还未完成。 |
| 按快捷键没有反应 | 确认 **启用快速捕捉** 已打开，并且已设置 **快捷键**。 |

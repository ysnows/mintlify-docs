title: "剪贴板历史、书签与文件搜索"
description: "通过热键或 SmartBar 搜索你复制过的内容、浏览器书签以及 Mac 上的文件。"
---

剪贴板历史、搜索浏览器书签和搜索文件是三个输入即搜的快捷列表。用剪贴板历史粘贴之前复制过的内容，用书签搜索在任意浏览器中打开保存的网页，用文件搜索无需打开 Finder 就能快速打开文件。它们既可以通过各自的热键打开，也可以通过别名在 SmartBar 中呼出。

## 打开列表

1. 在 **设置 → 快捷键** 中，或在 **设置 → 插件** 下对应列表的设置页面，为列表设置热键。
2. 按下热键。默认开启 **快捷键打开独立窗口**，此时列表会在独立窗口中打开，SmartBar 保持原样。
3. 输入内容筛选列表，用方向键移动到目标项目，然后按 Return。

如果想改在 SmartBar 内打开列表，请为它设置 **别名**。在 SmartBar 中输入该别名加一个空格，列表就会在那里打开。SmartBar 搜索结果也会显示每个列表的别名。

你也可以在聊天中用 `@` 提及某个列表，智能体就会为你搜索该列表。

## 从剪贴板历史粘贴

剪贴板历史会保存你复制过的文本、图片和文件。你可以置顶常用项，也可以按链接、电子邮件、颜色、图片或文件筛选。

1. 打开剪贴板历史。
2. 输入你复制过的内容中的某个关键词。
3. 按 Return 将该项目粘贴到你刚才使用的应用中；或者按 **⌘C** 改为仅复制它。当 **Return 键** 设为仅复制时，按 **⌘Return** 会执行粘贴。

如果你在 Enconvo 自己的某个窗口上方打开该列表，按 Return 会直接粘贴到该窗口的消息框中。

密码管理器和“钥匙串访问”默认被排除在外，应用标记为隐藏或临时的复制内容（例如密码）绝不会被记录。

## 打开书签

搜索浏览器书签可以读取 Safari、Chrome、Edge、Brave、Arc、Dia、Vivaldi、Opera、Chromium、Comet、Firefox 和 Zen 的书签，包括存放在你自选文件夹中的 Firefox 和 Zen 配置文件。搜索也会匹配文件夹名称。

按 Return 会在该书签所属的浏览器中打开它，按 **⌘O** 则会在默认浏览器中打开。**Return 键** 设置可以对调这两种行为。

## 查找文件

搜索文件默认搜索整台 Mac。使用搜索框中的下拉菜单，可以仅对本次搜索限定范围，例如 **我的文件夹**、**个人主目录** 或 **下载**。

按 Return 会打开文件，按 **⌘Return** 会在 Finder 中显示它。**Return 键** 设置可以对调这两种行为。

## 设置

打开 **设置 → 插件**，然后选择 **剪贴板历史**、**浏览器书签** 或 **文件搜索**。

| 设置 | 适用列表 | 作用 |
| --- | --- | --- |
| **别名** | 全部三项 | 在 SmartBar 中输入该词再加一个空格，即可在 SmartBar 内打开对应列表。 |
| **快捷键打开独立窗口** | 全部三项 | 开启：热键在独立窗口中打开列表。关闭：热键在 SmartBar 中打开列表。默认开启。 |
| **Return 键** | 全部三项 | Return 键的行为。剪贴板历史：**粘贴到前台应用** 或 **复制到剪贴板**。书签：**在其所属浏览器中打开** 或 **在默认浏览器中打开**。文件：**打开** 或 **在 Finder 中显示**。 |
| **记录剪贴板历史** | 剪贴板历史 | 持续记录你复制的内容。关闭该选项会保留已经保存的历史条目。 |
| **历史保留时长** | 剪贴板历史 | 条目保留多久，从 **1 天** 到 **永久** 不等。默认为 3 个月。已置顶的条目绝不会被自动删除。 |
| **忽略的 App** | 剪贴板历史 | 按 bundle ID 列出，这些应用中的复制操作绝不会被记录。 |
| **显示文件夹名称** | 书签 | 显示每个书签所在的文件夹。 |
| **已关闭的浏览器** | 书签 | 排除这些浏览器的书签。 |
| **搜索范围** | 文件 | 打开文件搜索时的默认搜索位置：**这台 Mac**、**我的文件夹**、**个人主目录**、**桌面**、**文稿**、**下载** 或 **应用程序**。 |
| **搜索文件夹** | 文件 | **我的文件夹** 所搜索的目录。留空时默认搜索桌面、文稿和下载。 |
| **显示隐藏文件** | 文件 | 包含文件名以点开头的隐藏文件。 |
| **排除的文件夹** | 文件 | 其中的内容绝不会出现在搜索结果中的文件夹。 |

你在这些列表的旧版网页界面中设置过的快捷键或别名会自动沿用过来。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 热键打开了 SmartBar 而不是独立窗口 | 为该列表开启 **快捷键打开独立窗口**。 |
| 剪贴板历史中缺少某次复制的内容 | 检查 **记录剪贴板历史** 和 **忽略的 App**。密码等受保护内容绝不会被记录。 |
| 缺少某个浏览器的书签 | 检查 **已关闭的浏览器**。 |
| 找不到某个文件 | 检查 **搜索范围**、**排除的文件夹** 和 **显示隐藏文件**。 |

---
title: "会议录音"
description: "录下会议或讲座，然后查看转录文本、摘要和待办事项。"
---

录音功能可以从麦克风、通话音频或两者同时录下会议或讲座，并在大家说话时实时写出转录文本。结束后，你可以阅读摘要、为说话人命名，并就会上说过的内容提问。录音所用的模型与听写和文件语音转写的模型分开设置。

## 开始之前

- 在 **设置 → 录音模型** 中选择一个转写模型。
- 第一次录制麦克风和系统音频时，macOS 会请求相应的访问权限。请为你要使用的来源授予这两项权限。

<Note>
请确保与会者知道会议正在录音，并遵守适用于该会议的相关要求。
</Note>

## 录制会议

<Steps>
  <Step title="新建录音">
    打开 **设置 → 录音** 并点按 **新建录音**，或运行 **开始录音（会议／讲座）**。
  </Step>
  <Step title="选择音频来源">
    选择 **麦克风**，然后选择要录制哪些 **通话音频**：**关闭** 只录你的麦克风，**所有应用** 录下 Mac 播放的所有声音，**单个应用** 只录会议应用的声音。要选择会议应用，请先打开它。检查 **语音转写** 模型；如果模型支持，还可以打开 **实时翻译**。
  </Step>
  <Step title="开始录音">
    点按 **开始录音**，并确认实时转录中有文字出现。
  </Step>
  <Step title="停止">
    结束时点按 **停止**，然后在 **录音** 下打开已保存的条目。
  </Step>
</Steps>

录音过程中，你可以暂停和继续、添加备注，或按 **⌘B** 为某个时刻添加书签。录音会边录边保存，即使 Enconvo 意外退出也不会丢失内容。

之后要更改音频来源，点按 **新建录音** 旁边的箭头，选择 **选择音频来源…**。在同一菜单中，**会议提醒** 会在 Zoom、Teams、FaceTime 或微信通话开始时，在灵动岛上询问你是否录音。

## 查看结果

打开一条录音，可以看到 **转录文本**，旁边是一个包含 **摘要**、**行动项** 和 **笔记** 标签页的侧边栏，以及 **询问 AI**。

- **转录文本**：核对每句话是谁说的，尤其是声音重叠的地方。点按说话人标签即可为该说话人命名，之后 Enconvo 会在新的录音中认出这个声音。对于反复出现的术语，请使用[词典](/zh/configuration/speech-assets)。
- **摘要**：**会议摘要** 提供概览、要点、决定、数字，以及一个时间点可跳转至录音对应位置的时间线。当有两位或以上说话人时，**发言时长** 会显示每位说话人在对话中所占的比例。
- **行动项**：从录音中找出的任务。完成后可以逐一勾选。
- **笔记**：你在录音时添加的笔记和书签。开启 **显示翻译** 可在每条笔记下方添加录音输出语言的译文；你的笔记仍按原样保留。
- **询问 AI**：就这条录音提问。要求列出待办事项时，只在会议明确提到负责人和截止日期的地方，才让它写出负责人和截止日期。

拖动侧边栏的左边缘可以加宽以查看较长的摘要，双击边缘可恢复默认宽度。该宽度会应用到所有录音。你可以在每个标签页中选中并复制文字。

## 选择摘要语言和模板

在录音侧边栏顶部，选择摘要、行动项和模板结果所用的 **输出语言**，以及要使用的模板。转录文本和你自己的笔记仍保留它们原本的语言。

除了 **会议摘要**，内置模板还有 **讲座笔记** 和 **面试重点**。你可以随时在模板之间切换一条录音；每个模板的结果都会保留。

要编写自己的模板：

<Steps>
  <Step title="新建模板">
    打开侧边栏顶部的模板菜单，选择 **新建模板…**。
  </Step>
  <Step title="说明需要提取的内容">
    输入一个 **名称**，用自然语言描述它应该从录音中提取什么。选择一种 **布局**：**智能布局** 可以使用卡片、表格、清单、抽认卡、测验和图表，而 **纯文本** 会生成方便复制到其他地方的 Markdown。
  </Step>
  <Step title="试用">
    点按 **在此录音上试用** 查看生成结果。录音本身不会有任何改动。
  </Step>
  <Step title="保存">
    如果它找出的任务应该显示在 **行动项** 标签页中，请开启 **将任务发送到行动项**，然后点按 **保存模板**。
  </Step>
</Steps>

要设置每条新录音默认使用的输出语言和模板，以及编辑或删除你的模板，请点按 **录音** 页面上 **新建录音** 旁边的 **摘要设置**。

## 回顾通话

你在 Mac 上录制的每一次 Enconvo [视频会议](/zh/features/video-conference)通话都会在 **录音** 中拥有自己的条目，即使多次通话使用的是同一个房间。开启了笔记的通话会显示它的转录文本、参与者、视频以及笔记文档。

通话页面打开时会显示一个 **会议** 概览：

- **摘要** 和 **行动项**，包含每项任务的负责人和截止日期。点按任务上的 **添加到提醒事项**，即可连同负责人和截止日期一起添加到 Apple 提醒事项中。
- **本次通话生成**：智能体在通话期间创建的文档和白板。
- **屏幕内容**：智能体在共享屏幕上看到的内容。
- **询问本次会议**：就这次通话提出问题。

你的智能体还可以在聊天中回答关于你以往通话的问题，并说明每个回答来自哪场会议。

智能体拨打或接听的电话也可以保存到这里：在 **设置 → 智能体电话** 中开启 **通话录音**，每次智能体通话都会连同其转录文本一起保存到 **录音** 中。参见[智能体电话](/zh/features/agent-phone)。

## 某个步骤失败时

转写、标题生成和搜索索引是彼此独立的阶段。后面某个阶段出错，并不代表音频或转录文本丢失了。较长的录音需要几分钟处理，离开页面后处理也会继续。使用 Enconvo Cloud Fast 时，最长 300 分钟的录音会直接从完整文件进行转写。

如果实时字幕在网络中断期间停止，它会自动重连，保存的转录文本仍会覆盖整段录音。

查看录音的处理状态，在失败的步骤上使用 **重新转录** 或 **重试索引**。报告问题时，**复制诊断信息** 会复制支持团队需要的参考编号和日志位置，但不包含录音本身。发送前请检查其中是否有隐私信息。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 缺少音频 | 检查所选的音频来源和 macOS 的录制权限。 |
| 麦克风被占用 | 先结束听写或 Live Talk，再开始录音。 |
| **没有可用的转写模型** | 在 **设置 → 录音模型** 中选择一个模型。 |
| 某个处理步骤失败 | 在录音的处理状态中重试该步骤。 |
| 摘要的语言不对 | 在侧边栏顶部选择 **输出语言**。对于新录音，请在 **摘要设置** 中设置。 |
| 没有行动项 | 使用 **会议摘要**，或使用开启了 **将任务发送到行动项** 的模板。 |

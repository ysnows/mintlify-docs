视频会议让你直接在 Enconvo 中与他人面对面交谈并共享屏幕。你可以呼叫好友、呼叫整个团队，或发送任何人在浏览器中都能打开的链接。字幕可以翻译成你的语言，纪要功能还会录制通话并撰写一份可与通话中所有人共享的纪要文档。

下面的视频依次介绍了视频会议、录制其他应用中的会议、转写文件、实时字幕、说话人和语音笔记。

<Note>
视频会议需要付费套餐。通过邀请链接加入的访客无需 Enconvo 账户，也无需安装任何应用。
</Note>

## 发起会议

在聊天窗口侧边栏、灵动岛或菜单栏菜单中打开 **视频会议**。在手机上，可以通过 iPhone 或 Android 应用发起或加入会议（参见[手机上的通话与好友](/zh/integrations/phone-calls-and-friends)）。在 Mac 上，这会打开视频会议首页：

- 顶部的输入框可以填入要加入的会议链接，或输入好友、队友的名字来呼叫。输入后按 Return，或立即发起一场会议。
- **即将开始** 列出你已预约的会议。
- **更早** 列出过去一个月的通话及其录音，点击 **重新呼叫** 可再次呼叫同一批人。
- **呼叫你的团队** 会同时呼叫所有队友。

你也可以打开 **设置 → 视频会议** 并点击 **开始**。

## 邀请他人

在通话中打开 **成员**，即可呼叫好友、队友或你自己的其他设备。**全部呼叫** 会同时呼叫所有队友。尚未登录 Enconvo 的队友会显示在 **尚未使用 Enconvo** 下方，并带有 **复制邀请链接**。

要邀请其他人，发送位于 conference.enconvo.com 的会议链接即可。对方可以作为访客从网页浏览器加入，进行语音交谈、在聊天中输入消息，还可以从电脑共享屏幕。

仅通过通话认识你的人在你们成为好友或队友之前，只能看到你的名字，看不到你的电子邮件地址。

## 呼叫好友

从会议首页输入框或 **设置 → 好友**（参见[好友与好友聊天](/zh/features/friends)）呼叫好友时，会议窗口会立即响铃，界面会在你模糊处理的摄像头画面上显示对方的头像并播放回铃音。对方接听后，通话只显示对方的画面，其中的 **聊天** 就是你与对方的私聊。点击 **添加成员** 即可在不中断画面和通话的情况下把它变成一场会议。

来电响铃会显示 **拒绝** 和 **接受**。未接来电会留下一张带有 **发消息** 和 **回拨** 的卡片。当你已经在通话中时，你的其他设备仍会继续响铃，呼叫方也会听到你正在另一通电话中的提示。通话期间，好友发来的消息会作为小提示显示在通话界面内，而不会弹出系统通知。

## 通过链接加入

在 Mac 上或浏览器中打开会议链接后，进入会议前会先显示一个准备页面：

1. 检查你的摄像头和麦克风，并选择要使用的设备。
2. 选择是否开启字幕、字幕语言以及背景。
3. 选择加入时是否静音。你也可以看到里面已经有谁。
4. 点击加入。

在已有五人或更多人的会议中，你的麦克风在加入时会默认关闭，并附带一条说明原因的提示。在手机浏览器上，如果访客切换到其他应用，状态会显示为 **离开**，通话会为其保留席位最多 5 分钟。

## 预约会议

1. 在 **设置 → 视频会议** 中，点击 **预约会议**。
2. 选择 **开始时间**、**时长** 和 **频率**：单次、每天、每个工作日、每周或每 2 周，均共用同一个链接。
3. 添加成员或输入电子邮件地址，填写标题，然后保存。

链接保持不变，因此大家现在就可以保存下来。好友和队友会收到一封附带日历文件的邮件；其他人请自行将链接发给他们。之后修改时间、时长、标题或受邀人时，每个人都会收到更新通知；你也可以取消该会议。已预约的会议会显示在 **即将开始** 下方，会议开始时会弹出 **暂不** 和 **加入**。

## 通话中

悬浮工具栏上有独立的 **麦克风**、**摄像头** 和 **字幕** 按钮。同一个侧边面板中集成了 **聊天**、**成员** 和 **字幕** 标签页。

- **布局**：有人加入时，图库视图会保持现有排列形状。可以切换到演讲者视图、固定某人画面，或点击某人将其放大。在只有一位对方的通话中，把你自己的小画面拖到任意角落，或点击它与对方画面互换。
- **谁在说话**：说话人的画面方格会亮起绿环并显示音量条。
- **聊天**：消息会发给所有人，未读数量会显示出来，后加入的人也能向上翻看历史消息。支持附加、粘贴或拖入最大 1 GB 的图片和文件。点击通话中的任意一人即可单独给他发私信。
- **举手与互动**：举起的手会按举手顺序排列，表情互动会漂浮在所有人的画面上方。
- **静音时说话**：按住 Space 即可说话。如果你在静音状态下开口说话，系统会弹出 **取消静音** 提醒。
- **你的视频**：提供 **隐藏我的画面** 或 **显示我的画面**、**镜像我的画面**，以及 **停止接收视频**——关闭其他人的摄像头画面以节省流量，同时保留语音和共享屏幕。通话期间可以随时切换麦克风、扬声器和摄像头；在手机上还可以切换至后置摄像头。
- **背景**：模糊背景、场景、图案或你自己的图片，可在加入前或通话中选择。面具效果一旦跟丢你的面部，就会模糊你的整个画面，避免意外露脸。

每个按钮都可以通过 Tab 键切换焦点，菜单可用方向键移动，按 Enter 或 Space 即可将某人画面放大。

当网络较慢或不稳定时，系统会先暂停视频画面以保证声音不会中断，并为每个人分配适配其网速的画面清晰度。你自己的网络较差时会有提示。在最多八人的通话中，有人加入或离开时会播放轻柔的提示音。如果你独自在通话中待了一段时间，系统会询问 **还在吗？**，之后自动结束通话。

## 共享屏幕

1. 点击工具栏中的共享按钮。托盘会显示每个屏幕和窗口的缩略图。
2. 选择其中一个。无论从 Mac 应用还是浏览器共享，声音都可以一并共享。

在 Mac 上，你共享的内容周围会有绿色边框标示，共享控制栏提供 **画**、**静音**、**停止声音** 和 **停止分享**。一个小窗口会显示当前谁在说话，且不会出现在你共享的画面中。Enconvo 自身的选择器、提示框和来电卡片都不会被其他人看到；从全屏通话发起共享时会自动退出全屏。

其他人可以将共享屏幕全屏打开，在 iPhone 上还可以双指捏合缩放。任何人都可以从 Mac、iPhone 或浏览器在共享屏幕上标注：笔画会落到每个人画面上的同一位置，带有绘制者的名字，并在几秒后淡出。

最小化会议窗口或共享屏幕时，一个小型悬浮窗会显示谁在说话，并提供静音、摄像头、离开按钮以及点击返回通话的入口。

## 字幕

通话中点击 **字幕** 即可开启或关闭字幕。工具栏上方的一条字幕带会显示每一句话；开启翻译后，可以大字显示译文、小字显示原文，或仅显示译文，翻译为你选择的语言。仍在生成中的译文会有一个标记提示。

字幕和翻译涵盖语音引擎支持的所有语言，共六十种，均在语言菜单中按名称列出。

点击实时字幕可以向上回看谁在什么时候说了什么，译文显示在原话上方。你可以一键跳回最新一行，或复制单行或全部内容。该功能支持 Mac、iPhone 和 Android。

## 纪要和录制

纪要功能会录制通话、识别说话人，并将 AI 生成的纪要写入一份纪要文档。通话中的所有人都能看到并听到纪要已开启。每个人都可以从工具栏中的 **纪要** 自行开启或关闭自己的纪要，并获得各自的纪要文档。

开启纪要后，纪要面板会显示截至当前的转录文本。使用 **询问 AI** 可以总结通话或回答关于通话的问题，也可以添加你自己的笔记和书签（**⌘B**），它们都会归入[会议录音](/zh/features/meeting-recording)中该通话的条目里。

纪要会列出每一项待办事项及其负责人和截止日期、智能体在通话中制作的文档和白板，以及智能体在共享屏幕上看到的内容。

组织者还可以点击 **录制会议**，将通话保存为自己电脑上的视频文件。通话中的每个人以及即将加入的人都会看到会议正在录制。

## 组织者控制项

发起会议的人就是会议的组织者。他们可以：

| 控制项 | 作用 |
| --- | --- |
| 静音、**请求取消静音**、**请求所有人取消静音** | 将某人或所有人静音。请求取消静音绝不会擅自替对方打开麦克风。 |
| **为所有人聚焦** | 为所有人放大某一个人的画面。任何人都可以切回图库视图。 |
| **停止分享** | 停止某个人的屏幕共享。 |
| 移除 | 将某人移出会议。 |
| **锁定会议** | 新加入的人会在等候室等待，直到组织者准许进入或拒绝。 |
| **访客需请求加入** | 让访客在进入前必须先请求加入。 |
| **设为组织者** | 授予某人相同的控制权限。 |
| **为所有人结束** | 为所有人结束会议。 |

**为所有人结束** 和移除确认默认选中 **取消**。当通话中没有组织者时，在会时间最长的人会临时担任 **代理组织者**，让在锁定会议外等待的人仍然可以进入。

## 会议中的智能体

你可以从 **成员** 将智能体拉入会议，或让你的智能体自动加入你选择的会议。你也可以派它进入 Google Meet 或 Zoom 会议。参见[通话中的智能体](/zh/features/agents-in-calls)。

## 通话结束时

总结页面会显示通话持续了多久、你和谁交谈过、保存了哪些内容，以及在会议仍在进行时提供 **重新加入**。

如果会议窗口停止工作，它会提示通话已停止，并提供 **重新加入** 和 **关闭**。如果连接中断且在五分钟内未能恢复，界面会提供 **重新加入**。通话期间 Enconvo 会保持 Mac 屏幕常亮。

## 设置

打开 **设置 → 视频会议**：

| 设置 | 作用 |
| --- | --- |
| **入会时打开麦克风**、**入会时打开摄像头** | 加入会议时的默认状态。你仍然可以在加入前的准备页面中修改。 |
| **入会时打开字幕** | 加入后立即显示字幕。只有你自己看得到。只有在有人需要字幕时，每位发言人的设备才会转写其发言。 |
| **翻译字幕** | 将字幕翻译为你选择的语言。设为 **关闭** 时按原话显示。 |
| **在我的通话中记录纪要** | **关闭**、**纪要** 或 **纪要和录制**。会在你发起、接听或加入的每次通话开始时自动启用。 |
| **录制** | 开启纪要时录制的默认内容：**音频** 或 **音频和视频**。 |
| **用说话人识别声音** | 根据声纹标注发言人的名字。只有在你选择时才会添加新声音。参见[词典与说话人](/zh/configuration/speech-assets)。 |
| **纪要文档共享给** | **通话中的人** 或 **仅我**。你是该文档的所有者，之后随时可以更改。 |
| **智能体自动入会** | 将你的智能体带入你选择的会议。参见[通话中的智能体](/zh/features/agents-in-calls)。 |
| **在任意 App 中静音或取消静音** | 一个默认为 **⌃⌥M** 的快捷键，只要你在会议中，无论当前前台是哪个应用都有效。菜单栏下方会显示一条简短提示。不在通话中时，该快捷键会留给其他应用使用。 |
| **通话勿扰** | 在 **1 小时**、**直到明天** 或 **直到我关闭** 期间阻止来电在这台 Mac 上响铃。消息仍会通知你，你也可以照常发起和加入通话。也可以在 **设置 → 好友** 中的月亮图标处开关。 |

## 其他应用中的会议

对于 Zoom、Teams、FaceTime 或微信通话，请使用[会议录音](/zh/features/meeting-recording)：**设置 → 录音 → 新建录音** 可以录制你的麦克风、通话音频或两者同时录制，并提供实时转录。**新建录音** 旁边的箭头菜单里有 **会议提醒**，当上述通话开始时，会在灵动岛上询问是否录制。

要让你的智能体代你加入 Google Meet 或 Zoom 会议，请参阅[通话中的智能体](/zh/features/agents-in-calls)。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 未允许使用摄像头或麦克风 | 点击提示中的 **打开系统设置** 并允许 Enconvo 访问，然后重试。 |
| 加入时麦克风处于关闭状态 | 五人及以上的会议默认以静音状态加入。点击 **麦克风**，或按住 Space 说话。 |
| 有人无法进入会议 | 会议已锁定或访客必须请求加入。请从等候室准入对方。 |
| 其他人的视频画面停止了 | 你的网络连接较慢，或者已开启 **停止接收视频**。语音和共享屏幕会继续进行。 |
| 这台 Mac 收不到来电响铃 | 检查 **设置 → 视频会议** 中的 **通话勿扰**。 |
| 通话窗口停止工作 | 点击窗口提示中的 **重新加入**。 |

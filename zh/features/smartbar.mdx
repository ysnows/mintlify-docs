SmartBar 是一个可以在任意应用中打开的启动器，用来向智能体提问或运行命令。按 **⌥Space**，输入内容，再按 Return。当你想快速得到答案、然后回到手头的工作时，就用它。

其他场景：长对话和处理文件用[聊天窗口](/zh/ai/chat)，在某个应用旁边工作用[应用侧边栏](/zh/features/app-sidebar)，处理选中的文字用 [PopBar](/zh/features/popbar)，想要一个常驻屏幕的小入口则用[灵动岛](/zh/features/dynamic-island)和[桌面宠物](/zh/features/pet)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

## 提问

1. 按 **⌥Space**，或你在 **设置 → SmartBar** 中设置的快捷键。
2. 输入你的问题。如果需要，先换一个智能体或模型。
3. 附加智能体需要的上下文。它看不到所有打开的应用；参见[添加上下文](#添加上下文)。
4. 按 Return，然后查看回答或工具的执行进度。要停止回复，点击圆形停止按钮。
5. 复制结果，或输入追问继续对话。任务运行期间你输入的消息会立即显示。

当你的输入匹配某个命令时，按 Return 会运行高亮显示的行。如果想把你的话改发给智能体，请按 **⌘Return** 或点击 **发送给 AI**。**⌥Return** 会运行该行的第二个操作。

在智能体模式下，**权限** 标签决定智能体何时在行动前先询问，它的 **沙盒** 开关则把智能体的命令限制在工作文件夹内。参见[智能体沙盒](/zh/configuration/sandbox)。

## 用触发字符搜索

在 SmartBar 中输入下列字符之一，即可搜索某一类项目：

| 输入 | 用途 |
| --- | --- |
| `@` | 搜索命令 |
| `#` | 添加上下文 |
| `$` | 使用技能 |
| `>` | 显示最近的任务 |
| `/` | 打开操作，例如选择模型和推理强度 |

前四个可以在 **设置 → SmartBar** 的 **搜索** 下修改。`/` 不能修改。

从弹出的列表里选择项目，不要凭记忆输入名称：列表里显示的是你实际拥有的命令和上下文来源。参见[写作工具](/zh/features/writing-tools)、[快捷链接](/zh/features/quick-links)和[上下文感知](/zh/features/context-awareness)。

有些列表通过别名打开：输入别名加一个空格，就会在 SmartBar 中打开[剪贴板历史、书签搜索或文件搜索](/zh/features/clipboard-history)。

## 添加上下文

SmartBar 打开时可以自动获取选中的文字、访达中选中的项目以及当前的浏览器页面。在 **设置 → 上下文感知** 中为每一项选择 **自动添加**、**建议** 或 **关闭**。要添加其他内容，输入 `#` 并选择一个来源。

**设置 → SmartBar** 中的 **布局** 决定 SmartBar 打开时你看到的内容：

| 布局 | 打开时显示 |
| --- | --- |
| **仅输入框** | 只有输入框 |
| **输入框和工具栏** | 输入框，加上快捷操作、模型选择器和语音控件 |
| **完整面板** | 以上全部，再加上输入框下方的列表 |

使用 **完整面板** 时，**初始视图** 决定你输入之前列表显示什么：**推荐提示词** 或 **命令列表**。无论哪种布局，只要你开始输入或运行命令，列表和结果都会出现。

## 设置

打开 **设置 → SmartBar**。

| 设置 | 作用 |
| --- | --- |
| **快捷键** | 在任意应用中打开或关闭 SmartBar。默认为 **⌥Space**。 |
| **默认智能体** | 回答你输入内容的智能体。 |
| **自动清空对话** | SmartBar 关闭超过设定时长后再打开，就开始新对话，可选范围从 **从不** 到 **每次打开时**。 |
| **布局** | SmartBar 打开时你看到的内容（见上文）。 |
| **外观** | SmartBar 和应用侧边栏使用浅色或深色玻璃效果，或 **跟随应用**。 |
| **自动切换输入法** | 在 SmartBar 中输入时切换到该输入法，关闭后再切回来。 |
| **导航快捷键** | 用 Control 组合键在列表和文本中移动：**macOS**（⌃N ⌃P ⌃F ⌃B）或 **Vim**（⌃J ⌃K ⌃L ⌃H）。 |
| **搜索** | 命令、上下文、技能和最近任务的触发字符。 |
| **计算器** | 在输入时直接回答数学计算、单位换算、货币汇率、日期和时区问题。默认开启。 |
| **天气和航班** | 同时查询任意地点的天气、航班以及当地时间。默认关闭。 |

更改默认值不会影响所有已有的聊天。[模型选择](/zh/ai/model-selection-guide)说明了每个聊天如何保留自己的模型和推理选择。

## 语音与计算

点击麦克风，用[听写](/zh/features/dictation)说出你的问题。想要一来一回的语音对话，就开启 [Live Talk](/zh/features/live-voice)；从 SmartBar 发起的通话会移到灵动岛上。

输入一个算术表达式，例如 `2+3*4`，SmartBar 会显示结果。计算器还支持单位和货币换算、日期和时区计算，以及分摊总额（例如 `25% off $60 split by 3`）。复制之前，请先核对结果和它提供的操作。

要查询天气、航班或某个地点的时间，请在 **设置 → SmartBar** 中打开 **天气和航班**。然后输入 `weather in London`、`Tokyo feels like`、航班号（如 `BA008`）或 `time in Chernivtsi`。系统只会将地名或航班号发送给 Open-Meteo、adsbdb 和 adsb.lol。**天气和航班** 与[灵动岛](/zh/features/dynamic-island)的计算器共用此开关。

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| SmartBar 打不开 | 检查 **设置 → SmartBar** 中的 **快捷键**，并看看是否有其他应用占用了同一快捷键。如果你之前自己设置过按键，它会保持你的设置不变。 |
| 按 Return 运行了命令，而不是向智能体提问 | 按 **⌘Return**，或点击 **发送给 AI**。 |
| 算式或天气查询没有显示结果 | 检查 **设置 → SmartBar** 中的 **计算器** 和 **天气和航班**。 |
| 上下文中缺少某个应用或选中的文字 | 检查[权限](/zh/configuration/permissions)和 **设置 → 上下文感知**。 |
| 请求失败 | 检查所选的服务提供商，并阅读它报告的错误。 |
| 找不到本页提到的某个控件 | 你的版本可能比本指南旧。参见[更新](/zh/configuration/updates)。 |

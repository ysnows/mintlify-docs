应用侧边栏会在应用窗口旁边打开一个 Enconvo 对话。它使用该应用的上下文，让你无需把信息复制到单独的聊天里就能阅读、写作或工作。当你的问题与前台应用有关时，就用它。

其他场景：快速提问或运行命令用 [SmartBar](/zh/features/smartbar)，需要更多空间查看历史记录和文件时用[聊天窗口](/zh/ai/chat)，处理选中的文字用 [PopBar](/zh/features/popbar)，想要一个常驻屏幕的小入口则用[灵动岛](/zh/features/dynamic-island)和[桌面宠物](/zh/features/pet)。[窗口管理](/zh/features/window-management)对它们做了全面比较。

下面的视频展示了 2.5.13 版本中的应用侧边栏：按 **⌃⌘E** 在 Chrome 旁打开它、设置它在某个网站上的工作方式、列出视频的关键时刻并跳转过去，然后压缩在访达中选中的照片。

## 打开侧边栏

1. 把你需要帮助的应用切到前台。
2. 按 **⌃⌘E**，在 Enconvo 中运行 **显示应用侧边栏**，或点击应用窗口旁的拉手。
3. 提出一个具体的问题，发送前检查附加的上下文。

在你将指针移到应用窗口右边缘附近之前，拉手会保持隐藏；指针移入或移出时，它会立即显示或隐藏。将指针停在拉手上，可以看到一张关于当前页面的卡片，例如视频的时长和字幕情况。若要让拉手始终保持可见，请在 **设置 → 应用侧边栏** 或拉手的右键菜单中关闭 **仅在窗口边缘显示把手**。在访达桌面上，无论是否打开访达窗口，拉手都会显示。

在智能体模式下，**权限** 标签用于设置智能体在行动前何时询问你，而它的 **沙盒** 开关会将智能体的命令限制在工作文件夹内。参见[智能体沙盒](/zh/configuration/sandbox)。

快捷键在 **设置 → 应用侧边栏** 中设置。早期版本使用 **⇧⌘T**；如果你从未修改过它，Enconvo 已将其改为 **⌃⌘E**。要修改它，请参见[键盘快捷键](/zh/configuration/keyboard-shortcuts)。

## 侧边栏能看到什么

侧边栏能获取到什么，取决于具体应用以及你授予的权限：

- 浏览器可以提供页面标题、URL 和内容。
- 访达可以提供选中的文件。
- 其他应用可能提供选中的文字、可访问的窗口内容或一张截图。

代码编辑器不一定会公开整个项目或每个打开的文件。当上下文不完整时，添加 [Appshots](/zh/features/appshots) 或自己附加文件。

可以试着问“解释选中的段落”“帮我把这篇草稿改得更简洁”或“描述这个窗口中可见的内容”。

### 页面卡片与开场建议

在网页上，新的侧边栏聊天会附带一张当前页面的卡片。视频卡片会显示视频时长、是否有字幕以及有多少个章节。卡片下方是针对该网站定制的开场建议。在 YouTube 上，它们分别是 **总结这段视频**、**列出带时间戳的关键时刻** 和 **显示转录文本**。点击其中一项即可发送。

在关于视频的回答中，无论是正文中还是时间线里的每一个时间都是链接。点击它，视频就会跳转到那一刻。卡片上的视频章节同样是链接。

在其他页面上，卡片也会显示可读取的内容，例如文章长度或 PDF 页数；侧边栏还会预先读取页面，让第一次回答更快开始。它会按当前标签页的原样读取：绝不会重新加载或修改页面、打开第二个标签页，或显示浏览器的调试栏。

对于没有字幕的 YouTube 视频，可以选择 **转写音频**。Enconvo 会转写视频音频并附带时间戳进行总结。

如果在聊天过程中你切换到了另一个页面，界面会出现一行 **当前位于**。点击它即可针对新页面提问。

内置的配置文件为 YouTube、Bilibili、GitHub、Reddit、Hacker News、X、Amazon、Gmail、Outlook 和 Stack Overflow 提供了各自的开场建议。它们的回答只依据页面本身提供的内容。

### 未安装扩展的 Chromium 浏览器

在没有安装 [Enconvo Companion 扩展](/zh/features/browser-control)的 Chrome、Edge、Brave、Arc 或其他 Chromium 浏览器旁边，侧边栏会显示一张带有 **安装** 按钮的卡片。一旦扩展连接成功，卡片就会变成页面卡片。

### 网站设置

卡片上的标签显示了网站名称以及它的设置来源，例如 **YouTube · 内置**。点击该标签即可更改侧边栏在该网站上的工作方式：

| 设置 | 作用 |
| --- | --- |
| **读取网页** | 允许侧边栏在问题需要时读取整个页面。 |
| **回答语言** | **我的语言** 或 **网页的语言**。 |
| **摘要风格** | **默认**、**带时间的章节**、**一小段话** 或 **要点列表**。 |
| **指令** | 你为该网站上的回答设置的自定义指令。 |
| **开场建议** | 显示在卡片下方的开场建议。你可以移除其中一项，或在 **添加开场建议** 中输入新的一条。 |

一旦你修改了任何设置，标签就会显示为 **自定义**。

### 访达中的文件

在访达中选中文件，然后按 **⌃⌘E**。开场建议会根据你选中的内容变化。对于图片，它们分别是 **压缩选中的图片**、**将选中的图片转换为 JPEG** 和 **调整选中的图片大小**。

侧边栏可以压缩、转换和调整图片大小、压缩 PDF、转换视频和音频、压缩和解压文件，以及批量重命名选中的文件。每项任务都会在原文件旁写入新副本，例如名称中带有 `-compressed` 的副本，而原文件会保持原样。结果会显示在一张卡片中，列出处理前后的大小以及 **在 Finder 中显示**。已经用相同设置处理过的文件会被保留并标记为 **已处理**，不会重复处理。不支持的格式会给出明确的提示。

### 插入到应用中

访达、企业微信和 Teams 等聊天应用、SourceTree 等 Git 客户端、Windsurf 等代码编辑器、终端、备忘录类应用、Pages 和 Word 都有内置配置和各自的开场建议。

在这些应用中，回答可能会带有一个 **插入** 按钮。点击它即可将回复、提交信息或命令填入应用的文本框中。插入绝不会替你发送或运行：由你自己检查后再按 Return。当侧边栏找不到可以插入的文本框时，它会告诉你需要如何处理。

### 按应用和网站预设

**设置 → 应用** 为侧边栏支持的每个应用保存一份配置：

| 设置 | 作用 |
| --- | --- |
| **附加截图** | 每条应用侧边栏消息都附上该应用窗口的截图。默认打开。 |
| **附加完整界面状态** | 附加完整的辅助功能状态，而不是精简摘要。会消耗多得多的 token。 |
| **技能**、**MCP 服务器**、**插件** | 为该应用预设，当该应用中有应用侧边栏对话时提供给智能体。 |

**设置 → 网站** 为网站保存同样的预设，在浏览器打开匹配的页面时使用。

## 在应用中聊天和操作

继续一个对话、开始新对话，或用窗口控件让侧边栏保持在手边。应用上下文只是给智能体阅读的信息。要让智能体替你在应用中点击或输入，它需要[电脑操作](/zh/features/computer-use)或[使用浏览器](/zh/features/browser-control)工具。

## 设置

打开 **设置 → 应用侧边栏**。

| 设置 | 作用 |
| --- | --- |
| **启用应用侧边栏** | 在应用窗口旁显示拉手，并启用快捷键。关闭后，两者都会消失。 |
| **默认智能体** | 在侧边栏中作答的智能体。 |
| **对所有应用隐藏** | 在所有应用中隐藏侧边栏的拉手。 |
| **仅在窗口边缘显示把手** | 保持拉手隐藏，直到你将指针移到窗口右边缘才显示。默认开启。 |
| **以下应用在前台时隐藏应用侧边栏拉手** | 拉手始终隐藏的应用。 |
| **快捷键** | 为前台应用打开侧边栏。默认为 **⌃⌘E**。 |

## 故障排除

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有附着到应用上 | 把应用窗口切到前台，再次打开侧边栏。 |
| 找不到拉手 | 将指针移到窗口右边缘，或关闭 **仅在窗口边缘显示把手**。 |
| Chromium 浏览器中缺少页面卡片 | 点击卡片上的 **安装** 按钮安装 Enconvo Companion 扩展。 |
| 没有出现 **插入** 按钮 | 该应用没有侧边栏可识别的文本框。请改用复制回答。 |
| 缺少应用中的文字 | 检查[权限](/zh/configuration/permissions)中的辅助功能、隐藏拉手的应用，以及附加的上下文。 |
| 需要更多空间查看历史记录或文件 | 在[聊天窗口](/zh/ai/chat)中继续。 |

---
title: "实时字幕"
description: "在音频播放时实时阅读字幕，之后还能回看每一次字幕会话。"
---

实时字幕会在音频播放或录制时显示字幕，例如一场演讲、一段视频或一次通话。每次会话都保存在单独的列表中，与导入的语音转写文件和会议录音分开。

## 开始生成字幕

1. 打开 **设置 → 字幕生成模型**，选择一个支持实时识别的模型。
2. 打开 **设置 → 实时字幕**，点按 **添加**，然后选择 **开始生成字幕**。列表为空时，点按 **开始生成字幕**。你也可以运行 **开始实时字幕** 命令，或在 Enconvo 的菜单栏菜单中选择 **开始实时字幕**。
3. 在 **开始实时字幕** 窗口中，选择音频来源、字幕栏出现的位置以及所在屏幕。macOS 请求麦克风或系统音频权限时，请予以授权。
4. 播放你要跟随的音频，确认字幕已经出现。
5. 结束后停止生成字幕，然后在 **实时字幕** 列表中打开已保存的会话。

要使用快捷键开始和停止字幕，请在 **设置 → 快捷键** 的 **语音** 下为实时字幕设置快捷键。按同一个快捷键即可停止正在运行的字幕。

## 放置字幕栏

字幕栏可以显示在四个位置之一：

| 位置 | 显示效果 |
| --- | --- |
| **左侧** | 屏幕左边缘的一列，为默认位置。 |
| **右侧** | 右边缘的一列。 |
| **顶部居中** | 顶部的一行，控制按钮旁是宽幅字幕区。 |
| **底部居中** | 底部的一行，字幕像常规字幕一样排列。 |

有多个显示器时，还可以选择显示屏幕，或保持 **鼠标所在的屏幕**。会话期间，右键点击字幕栏可更改位置或屏幕。无论在哪个位置，拖动字幕区域的边缘都可以调整大小。

## 翻译字幕

部分语音服务提供商支持实时翻译，可以设置源语言和目标语言，或输出语音翻译。请在所选字幕生成模型自己的设置中打开这些选项；Enconvo Cloud Fast 和 Soniox 使用 **源语言** 和 **目标语言**。并非所有语音模型都支持实时翻译；一个模型支持文件转写，也不代表它支持实时字幕。

## 回看会话

打开已保存的会话，查看转录文本和处理结果。对准确性要求较高时，请对照音频核对姓名、数字和说话人标签。使用[词典与说话人](/zh/configuration/speech-assets)让词汇和说话人姓名保持最新。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 没有字幕 | 检查音频来源、输入音量、录制权限和所选模型。 |
| 停止后才出现文字 | 选择支持流式识别的模型。 |
| 语言不对 | 在模型的设置中设定识别语言或语言提示。 |
| 没有翻译 | 确认模型支持翻译，并设置目标语言。 |
| 会话显示处理错误 | 在已保存的条目中阅读错误详情。不要因此认为语音内容丢失了。 |

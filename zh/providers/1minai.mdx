title: "1min AI"
description: "使用你自己的 1min AI API 密钥，在 Enconvo 中与 1min AI 模型聊天。"
---

1min AI 通过 API 密钥提供其模型。把你的密钥添加到 Enconvo，即可在聊天、智能体和 AI 命令中使用这些模型。1min AI 会把用量计入你自己的账户。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在 [1min AI 应用](https://app.1min.ai/)中创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → 1min AI**。在 **身份验证** 下，将密钥粘贴到 **API 密钥** 中，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

如果想再保存一个 1min AI 密钥（例如工作用的），点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **最大 Token 数** | 模型单次回复的最大长度。 |

如果想在某个聊天中使用其他模型，请在该聊天的模型选择器中选择。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在你的 1min AI 账户中确认密钥有效。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新** 重新加载列表。如果要自己添加模型，请使用 **管理模型**。 |
| 图片或工具调用失败 | 选择支持图像输入或工具调用的模型。 |
| 速率或用量限制错误 | 在你的 1min AI 账户中查看用量和限额，或暂时切换到其他服务提供商。 |
| 回复很慢 | 尝试更小的模型、更短的输入，或更低的推理强度。 |

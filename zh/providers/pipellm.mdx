PipeLLM 是一个模型网关：一个 PipeLLM API 密钥即可访问多家公司的模型，包括 Claude、GPT、Gemini、Grok、Qwen、Kimi 和 GLM。如果你想用一张账单统一结算多家厂商的用量，就可以使用它。PipeLLM 会将用量计入你自己的账户。

同一个密钥还同时支持图像生成、视频生成和网页搜索。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在你的 [PipeLLM](https://pipellm.ai) 账户中创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → PipeLLM**。在 **身份验证** 下，将密钥粘贴到 **API 密钥** 中，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

如果想保存第二个 PipeLLM 密钥，点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |

这个 PipeLLM 密钥还适用于以下功能，在对应页面中选择 **PipeLLM** 作为服务提供商即可：

| 功能 | 位置 | 支持的能力 |
| --- | --- | --- |
| 图像生成 | **设置 → 图像生成** | 使用 GPT Image、Nano Banana 和 Seedream 等模型生成与编辑图片。 |
| 视频生成 | **设置 → 视频生成** | 使用 Seedance、Veo、Kling 和 Sora 等视频模型。 |
| 网页搜索 | **设置 → 网页搜索** | 获取 Google 搜索结果及其摘要。PipeLLM 会按每次返回结果的搜索计费。 |

由于这些功能共用同一份凭据，在一处更改密钥会同步更新所有相关功能。iPhone 和 Android 应用的 AI 模型设置中也可以使用 PipeLLM。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在你的 PipeLLM 账户中确认密钥处于有效状态。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自行添加模型，请使用 **管理模型**。 |
| 图片或工具调用失败 | 选择支持图像输入或工具调用的模型。 |
| 速率、余额或用量错误 | 在你的 PipeLLM 账户中检查余额和限额，或暂时切换到其他服务提供商。 |

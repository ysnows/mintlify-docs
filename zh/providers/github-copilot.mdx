---
title: "GitHub Copilot"
description: "使用拥有 Copilot 订阅的 GitHub 账户登录，与订阅中的模型聊天。"
---

在 Enconvo 中把你的 GitHub Copilot 订阅用作 AI 模型服务提供商。你只需用拥有该订阅的 GitHub 账户登录，不涉及 API 密钥。高级模型会计入你订阅中的高级请求次数。

## 连接

<Steps>
  <Step title="打开服务提供商">
    打开 **设置 → AI 模型 → GitHub Copilot**。
  </Step>
  <Step title="开始登录">
    在 **身份验证** 中点击 **连接**。
  </Step>
  <Step title="在 GitHub 上输入代码">
    浏览器会打开 GitHub 的设备页面，Enconvo 会显示需要在该页面输入的代码。输入代码并授权登录。
  </Step>
  <Step title="确认账户">
    回到 Enconvo，确认连接的是你想用的 GitHub 账户。
  </Step>
  <Step title="选择模型">
    选择一个模型，并发送一个简短的请求试试。
  </Step>
</Steps>

在授权之前关闭 Enconvo 的代码对话框，会取消本次登录。

## 模型与选项

模型列表只显示你的 Copilot 订阅可以使用的模型，并把 Copilot 自己的默认聊天模型排在第一位。Copilot Free 提供的模型比付费订阅少，因此你在别处见过的模型可能不在列表中。每个模型使用 Copilot 为其提供的推理强度级别。

## 在 iPhone 上

iPhone 应用也可以登录 GitHub Copilot，用于手机上的手机聊天。请参阅[手机聊天](/zh/integrations/iphone-phone-chats)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 登录无法完成 | 在代码过期前到 GitHub 页面输入；如已过期，再次点击 **连接** 获取新代码。 |
| 你想要的模型不在列表中 | 你的 Copilot 订阅不包含该模型；请选择其他模型，或升级订阅。 |
| 请求因模型错误而失败 | 从当前列表中选择模型；订阅变更前选定的默认模型可能已不再提供。 |
| 速率或用量限制 | 受你订阅的高级请求次数和 GitHub 速率限制约束。 |

title: "Qwen"
description: "使用阿里云 Model Studio API 密钥，在 Enconvo 中与 Qwen 模型聊天。"
---

在聊天、智能体和 AI 命令中使用阿里巴巴的 Qwen 模型。通过阿里云 Model Studio 的 API 密钥连接；阿里云会将用量计入你的账户。如需使用中国大陆服务（百炼），请前往 [DashScope](/zh/providers/dashscope)。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在[阿里云 Model Studio](https://modelstudio.console.alibabacloud.com/) 中创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → Qwen**。在 **身份验证** 下，将密钥粘贴到 **API 密钥** 中，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

Qwen 仅支持通过 API 密钥连接。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **基础 URL** | 位于凭据设置中。默认为国际版端点 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。如果你的密钥属于其他区域，请更改此项。 |

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 检查密钥和 **基础 URL** 是否属于同一区域，然后重新粘贴完整的密钥。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自己添加模型，请使用 **管理模型**。 |
| 速率或用量限制错误 | 在 Model Studio 中查看用量和配额，或暂时切换到其他服务提供商。 |

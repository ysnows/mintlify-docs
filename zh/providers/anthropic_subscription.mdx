---
title: "Claude 订阅"
description: "使用你的 Claude 订阅登录，无需 API 密钥即可在 Enconvo 中使用 Claude 模型。"
---

如果你已经为 Claude 付费，可以直接用该订阅登录，而不必创建 API 密钥。请求会消耗订阅中的额度，Enconvo 会显示剩余多少。

## 连接

<Steps>
  <Step title="选择订阅">
    打开 **设置 → AI 模型 → Anthropic**。在 **身份验证** 下选择 **Claude 订阅**。
  </Step>
  <Step title="登录">
    点击 **连接**，在浏览器中登录你的 Claude 账户并允许访问。浏览器提示完成后，回到 Enconvo。
  </Step>
  <Step title="选择模型">
    确认账户卡片显示的是正确的账户，在 **模型名称** 中选择一个模型，然后发送一条简短的消息。
  </Step>
</Steps>

## 查看用量

账户卡片会显示五小时额度和每周额度还剩多少（**% 剩余**），在 Anthropic 提供时还会按模型分别显示，以及各自的重置时间。有独立额度的模型（例如每周 Claude Fable 额度）会在其他额度旁边单独显示。同一张卡片也会出现在聊天的模型选择器中。打开卡片的菜单可以使用：

- **刷新用量**：获取最新数据。
- **重新连接**：重新登录，例如用于切换账户。

如果 Anthropic 没有提供用量数据，卡片会显示 **用量不可用** 及原因。这并不表示订阅没有限额。

### 使用赠送的重置

当 Claude 向你发放免费的限额重置次数时，卡片会列出 **赠送的重置**：你还有几次以及何时过期。点击 **使用重置** 并确认，即可立即补满你的限额。重置操作无法撤销。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 登录失败 | 查看 Anthropic 给出的错误信息，然后再次点击 **连接**。确保登录的是拥有该订阅的账户。 |
| 聊天提示已达到用量限制 | 提示中会写明是哪项限额以及何时重置。如果卡片列出了赠送的重置，可以使用一次，也可以等待，或暂时将 **身份验证** 切换为 **API 密钥**。 |
| Enconvo 让你稍后再试 | Anthropic 正忙于续期登录状态。稍等片刻后重新发送即可，不需要重新连接。 |
| 找不到某个模型 | 可用模型由你的订阅决定。点击 **模型名称** 旁边的 **刷新**。 |

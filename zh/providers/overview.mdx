服务提供商是 Enconvo 各项功能背后的服务：回答聊天的模型、朗读文字的语音、搜索网页的引擎。你可以为每项功能分别选择，也可以混合搭配。

下面的 2 分钟视频会带你快速了解 **设置 → AI 模型**：Auto Route、Cloud 套餐、使用 ChatGPT、Claude、GitHub Copilot、Antigravity 或 Grok 套餐登录、API 密钥、Mac 上的本地模型、Ollama 和 LM Studio，以及添加你自己的服务提供商。

## 选择连接方式

| 如果你想 | 使用 | 从这里开始 |
| --- | --- | --- |
| 无需密钥，立即开始 | 通过 Enconvo 账户使用 Enconvo Cloud | [Enconvo Cloud](/zh/providers/enconvo) |
| 让 Enconvo 为每条消息挑选模型 | Auto Route，即默认模型 | [Auto Route](/zh/providers/auto-route) |
| 使用已经付费的订阅 | 使用 ChatGPT、Claude、Grok、Mistral、GitHub Copilot 或 Antigravity 登录 | [使用订阅登录](#使用订阅登录) |
| 直接向服务提供商付费 | 你自己的 API 密钥 | [热门服务提供商](#热门服务提供商) |
| 通过单个密钥访问多家公司的模型 | OpenRouter 或 PipeLLM 等网关 | [OpenRouter](/zh/providers/openrouter)、[PipeLLM](/zh/providers/pipellm) |
| 让聊天留在 Mac 上 | 本地模型 | [本地模型](/zh/ai/local-llm) |
| 使用你已经在 Ollama 或 LM Studio 中运行的模型 | **Ollama** 或 **LM Studio** 服务提供商 | [Ollama](/zh/providers/ollama)、[LM Studio](/zh/providers/lm-studio) |
| 在 iPhone 应用自己的聊天中使用模型 | 手机聊天 | [手机聊天](/zh/integrations/iphone-phone-chats) |

## 选择你的聊天模型

<Steps>
  <Step title="打开 AI 模型">
    打开 **设置 → AI 模型**。中间一栏列出了所有服务提供商：顶部是 **Auto Route** 和 **Enconvo Cloud 套餐**，接着是各家公司、本地模型以及其他所有服务提供商。
  </Step>
  <Step title="选择服务提供商并连接">
    点击一个服务提供商。在同时提供两种方式的提供商下，选择 **API 密钥** 即可用你自己的密钥按请求付费，或选择订阅选项（例如 **ChatGPT 订阅**）登录并使用你的套餐所包含的额度。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 下选择一个模型，如果该服务提供商支持推理强度，再选择一个 **推理强度**。
  </Step>
  <Step title="设为默认">
    点击 **设为默认**。之后没有单独指定模型的聊天和功能都会使用它。
  </Step>
</Steps>

要添加未列出的服务，请点击列表底部的 **添加新提供商**，然后选择 **兼容 OpenAI** 或 **兼容 Anthropic**。

你可以随时切换服务提供商；聊天不会绑定在某一家公司上。

**设置 → AI 模型** 顶部还提供 **任务模型**（用于设置聊天标题和建议等背后使用的小模型）以及 **兜底**（用于添加在当前聊天模型不可用时接管的备用模型）。参见[选择模型](/zh/ai/model-selection-guide)。

## 为每项功能设置服务提供商

每项功能都有自己的设置页面：**AI 模型**、**文本转语音**、**网页搜索**、**图像生成**、**视频生成**、**获取网页** 和 **OCR**。语音识别分为几个独立的页面：**听写模型**、**录音模型**、**语音转写模型** 和 **字幕生成模型**。嵌入和重排序在知识库中设置。

选择聊天模型不会改变你的语音、图像或搜索服务提供商。请在各自的位置分别设置。

## 服务提供商配置

一个服务提供商配置保存一个密钥或一次登录。在服务提供商页面上点击 **添加新提供商**，即可再保存一个配置，例如工作账户。有些配置会同时服务多项功能：一个 OpenAI 配置涵盖聊天、嵌入、文本转语音、图像和语音转写，因此更改它的密钥会影响所有这些功能。请参阅[凭据与配置](/zh/configuration/credentials)。

默认模型在哪里设置，以及每个聊天如何保留自己的模型，请参阅[选择模型](/zh/ai/model-selection-guide)。

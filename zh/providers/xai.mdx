---
title: "xAI (Grok)"
description: "使用 xAI API 密钥或你的 Grok 订阅，在 Enconvo 中与 Grok 模型聊天。"
---

在聊天、智能体和 AI 命令中使用 xAI 的 Grok 模型。你可以用 xAI API 密钥连接（xAI 按请求计费），也可以用你的 Grok 订阅登录。它在设置中显示为 **X.AI-GROK**。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在 xAI 控制台中创建一个密钥；[xAI 快速入门](https://docs.x.ai/docs/quickstart#creating-an-api-key)介绍了具体步骤。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → X.AI-GROK**。在 **身份验证** 下选择 **API 密钥**，粘贴密钥，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

<Tip>
有 Grok 订阅？可以改为在 **身份验证** 下选择 **Grok 订阅**，然后点击 **连接**。
</Tip>

如果想再保存一个 xAI 密钥，点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **API 基础地址** | 位于凭据中。默认值为 `https://api.x.ai/v1`。 |

xAI 还为文本转语音、图像生成、语音转写、视频生成和 X Search 提供了各自的服务提供商。它们共享此配置的密钥或 Grok 登录；请在各自的设置页面中分别选择。

## 在 iPhone 上

iPhone 应用也可以在手机聊天中使用 Grok 订阅。在 iPhone 上打开 **设置 → AI 模型 → xAI**，在 **身份验证** 下选择 Grok 卡片，然后轻点 **使用 Grok 登录**。请参阅[手机聊天](/zh/integrations/iphone-phone-chats)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在 xAI 控制台中确认密钥有效。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自己添加模型，请使用 **管理模型**。 |
| Grok 登录失效 | 打开账户卡片的菜单，点击 **重新连接**。 |
| 速率或用量限制错误 | 在你的 xAI 账户中查看用量，或暂时切换到其他服务提供商。 |

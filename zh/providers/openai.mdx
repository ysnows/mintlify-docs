在聊天、智能体和 AI 命令中使用 OpenAI 的 GPT 模型。你可以用 OpenAI API 密钥连接（OpenAI 按请求计费），也可以用你的 ChatGPT 订阅登录并使用其额度。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在 [OpenAI 平台](https://platform.openai.com/api-keys)上创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → OpenAI**。在 **身份验证** 下选择 **API 密钥**，粘贴密钥，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

<Tip>
有 ChatGPT 订阅？可以改为在 **身份验证** 下选择 **ChatGPT 订阅**，然后点击 **连接**。请参阅 [ChatGPT 订阅](/zh/providers/openai_subscription)。
</Tip>

如果想再保存一个 OpenAI 密钥（例如工作用的），点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **API 类型** | 位于凭据中。可选 **Responses API**（默认）或 **Completions API**。除非某个兼容服务需要 Completions，否则请保持 Responses。 |
| **API 基础地址** | 位于凭据中。默认值为 `https://api.openai.com/v1`。仅在使用兼容 OpenAI 的服务时才需要更改。 |

同一个 OpenAI 配置还服务于 OpenAI 嵌入、文本转语音、图像生成和语音转写，因此更改它的密钥也会影响这些功能。如果想在某个聊天中使用其他模型，请在该聊天的模型选择器中选择。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在 OpenAI 平台上确认密钥有效且已设置付款方式。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自己添加模型，请使用 **管理模型**。 |
| 兼容服务调用失败 | 检查 **API 基础地址**，然后尝试将 **API 类型** 设为 **Completions API**。 |
| 速率或用量限制错误 | 在 OpenAI 平台上查看用量和限额，或暂时切换到其他服务提供商。 |

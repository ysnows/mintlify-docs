Enconvo Cloud 通过你的 Enconvo 账户提供来自多家公司的模型，以及语音、图像、视频和网页工具。你无需管理 API 密钥：请求消耗的是你套餐中的点数。这是最快的上手方式。

## 设置

<Steps>
  <Step title="登录">
    登录你的 Enconvo 账户。请参阅[账户](/zh/configuration/account)。
  </Step>
  <Step title="选择 Enconvo Cloud">
    打开你要使用的功能的设置页面，例如 **AI 模型**、**文本转语音** 或 **图像生成**，然后选择标有 **Enconvo Cloud** 或 **Enconvo Cloud Plan** 的服务提供商。
  </Step>
  <Step title="选择模型或语音">
    选择一个模型或语音，并发送一个简短的请求试试。
  </Step>
</Steps>

每项功能都单独选择服务提供商。为聊天选择 Enconvo Cloud，不会同时切换语音、图像、视频、嵌入、重排序或网页工具；请在各自的位置分别设置。

## Enconvo 自有模型

Enconvo Cloud 拥有三个自有模型，以它们适合的工作命名：

| 模型 | 适用场景 |
| --- | --- |
| **Enconvo Fast** | 快速交互：简短回答、改写、轻量操作。它是 **Enconvo Cloud Plan** 的初始模型，也是 AI 命令的默认模型。 |
| **Enconvo Balanced** | 包含几个步骤的日常工作。 |
| **Enconvo Ultra** | 需要深度推理的复杂任务。 |

它们会排在 **Enconvo Cloud Plan** 列表的最前面，[Auto Route](/zh/providers/auto-route) 也使用它们作为默认路由。

## 在选择器中查找模型

**Enconvo Cloud Plan** 列表按厂商对模型分组：Enconvo 自有模型排在最前，然后是 Anthropic、OpenAI、Google 等等，每组都带有数量统计。每个厂商默认显示最新的四个模型；点击 **显示另外 N 个较早的模型** 可以查看其余模型。搜索会列出所有匹配项，而你当前聊天正在使用的模型始终会显示。Claude 模型不带“Claude”前缀列出，例如 **Sonnet 5.5** 和 **Opus 5.5**。

在聊天窗口的模型选择器中，Cloud 模型可能会带有标签：

| 标签 | 含义 |
| --- | --- |
| **New** | 最近 14 天内新添加的模型。 |
| 折扣，例如 **50% OFF** | 该模型目前限时优惠。将鼠标悬停在该行上，或用方向键选中它，即可查看原价。 |
| **免费** | 该模型不消耗点数。 |
| **预览** | 该模型的早期预览版本。 |
| 日期 | 该模型从 Enconvo Cloud 下线的日期。 |

这些标签由 Enconvo Cloud 下发，因此无需更新应用即可变化。

## 点数与用量

不同模型消耗的点数不同。设置中会在每个模型和服务提供商旁边显示 Cloud 价格，以及你的套餐所包含的额度（例如本月剩余的免费分钟数）。当前的套餐和费率请参阅 [Cloud Plan](https://www.enconvo.com/cloud-plan) 和 [Cloud 价格](https://www.enconvo.com/cloud-pricing)页面。要查看你的使用情况，请打开 **设置 → 点数用量**。

默认模型 [Auto Route](/zh/providers/auto-route) 运行在 Enconvo Cloud 的模型上。为每条消息挑选路由是免费的；负责回答的模型会消耗点数。

部分 Cloud 服务对所有已登录账户免费：

- 使用 **Enconvo Cloud** 和 **DeepSeek (Enconvo Cloud)** 进行网页搜索。请参阅[网页搜索](/zh/ai/web-search)。
- 使用 **Enconvo Cloud Fast** 进行语音识别。请参阅[语音识别](/zh/ai/speech-recognition)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 请求要求你登录 | 在 **设置 → 账户** 中登录。 |
| 请求因点数或余额错误而失败 | 查看 **设置 → 点数用量**，然后在 [Cloud Plan](https://www.enconvo.com/cloud-plan) 页面查看你的套餐。 |
| 找不到某个模型 | 选择器会显示你的套餐包含的模型。点击 **模型名称** 旁边的 **刷新**。 |

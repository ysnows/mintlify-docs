---
title: "ChatGPT 订阅"
description: "使用你的 ChatGPT 订阅登录，无需 API 密钥即可在 Enconvo 中使用 OpenAI 模型。"
---

如果你已经为 ChatGPT 付费，可以直接用该订阅登录，而不必创建 API 密钥。请求会消耗订阅中的额度，Enconvo 会显示剩余多少。

## 连接

<Steps>
  <Step title="选择订阅">
    打开 **设置 → AI 模型 → OpenAI**。在 **身份验证** 下选择 **ChatGPT 订阅**。
  </Step>
  <Step title="登录">
    点击 **连接**，在浏览器中登录你的 ChatGPT 账户并允许访问。浏览器提示完成后，回到 Enconvo。
  </Step>
  <Step title="选择模型">
    确认账户卡片显示的是正确的账户，在 **模型名称** 中选择一个模型，然后发送一条简短的消息。
  </Step>
</Steps>

Enconvo 会在后台续期登录状态，因此你不必每隔几天就重新登录。

## 查看用量

账户卡片会显示每个用量周期还剩多少（**% 剩余**）、何时重置，以及订阅何时续费或到期。打开卡片的菜单可以使用：

- **刷新用量**：获取最新数据。
- **重新连接**：重新登录，例如用于切换账户。

如果 OpenAI 没有提供用量数据，卡片会显示 **用量不可用** 及原因。这并不表示订阅没有限额。

### 使用赠送的重置

当 Codex 向你发放免费的限额重置次数时，卡片会列出 **赠送的重置**：你还有几次以及何时过期。点击 **使用重置** 并确认，即可立即补满你的限额。重置操作无法撤销。

## 订阅涵盖的功能

ChatGPT 登录同样适用于 OpenAI 图像生成和语音转写；在这些页面的 **身份验证** 下选择 **ChatGPT 订阅** 即可。OpenAI 文本转语音和嵌入需要 API 密钥，Live Talk 的语音则另行设置。

## 在 iPhone 上

iPhone 应用有自己的 ChatGPT 登录，用于手机聊天。在 iPhone 上打开 **设置 → AI 模型 → OpenAI**，在 **身份验证** 下选择 ChatGPT 卡片，然后轻点 **使用 ChatGPT 登录**。之后页面会显示你的订阅、其 5 小时限额和每周限额各剩多少，以及各自的重置时间。该登录只保留在 iPhone 上，Mac 使用自己的登录。请参阅[手机聊天](/zh/integrations/iphone-phone-chats)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 登录失败 | 查看 OpenAI 给出的错误信息，然后再次点击 **连接**。确保登录的是拥有该订阅的账户。 |
| 找不到某个模型 | 可用模型由你的订阅决定。点击 **模型名称** 旁边的 **刷新**。 |
| 聊天提示已达到用量限制 | 如果卡片列出了赠送的重置，可以使用一次，也可以等待账户卡片上显示的重置时间，或暂时将 **身份验证** 切换为 **API 密钥**。 |
| 聊天在一段时间后无法使用 | 打开账户卡片的菜单，点击 **重新连接**。 |

---
title: "Mistral AI"
description: "使用 Mistral API 密钥或你的 Mistral 账户，在 Enconvo 中与 Mistral 模型聊天。"
---

在聊天、智能体和 AI 命令中使用 Mistral 的模型。你可以粘贴 Mistral API 密钥，也可以登录你的 Mistral 账户，让 Enconvo 为你创建密钥。无论哪种方式，Mistral 都会把用量计入你的账户。

## 连接

<Tabs>
  <Tab title="使用 Mistral 登录">
    <Steps>
      <Step title="打开服务提供商">
        打开 **设置 → AI 模型 → Mistral AI**。
      </Step>
      <Step title="登录">
        在 **身份验证** 下选择 Mistral 账户登录，然后点击 **连接**。用你的 Mistral 账户登录并选择一个工作区。这种登录方式与 Mistral Vibe 的登录方式相同：它会为该工作区创建一个 API 密钥，因此你无需复制任何内容。
      </Step>
      <Step title="选择模型">
        在 **模型名称** 中选择一个模型，并发送一条简短的消息。
      </Step>
    </Steps>
  </Tab>
  <Tab title="使用 API 密钥">
    <Steps>
      <Step title="获取 API 密钥">
        在 [Mistral 控制台](https://console.mistral.ai/api-keys/)中创建一个密钥。
      </Step>
      <Step title="添加到 Enconvo">
        打开 **设置 → AI 模型 → Mistral AI**。在 **身份验证** 下，将密钥粘贴到 **API 密钥** 中，然后点击 **验证**。
      </Step>
      <Step title="选择模型">
        在 **模型名称** 中选择一个模型，并发送一条简短的消息。
      </Step>
    </Steps>
  </Tab>
</Tabs>

登录后，账户卡片会显示你的套餐、密钥，以及每分钟限额还剩多少。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **推理强度**（在聊天中） | 适用于 Mistral Large 4、Medium 3.5 和 Small 4：**无** 表示不思考直接回答，**高** 表示先思考再回答。Large 4 默认会思考。 |

Voxtral 语音转写和 Mistral OCR 可以使用同一个登录或密钥。

## 在 iPhone 上

iPhone 应用也可以在手机聊天中使用你的 Le Chat 订阅。在 iPhone 上打开 **设置 → AI 模型 → Mistral**，在 **身份验证** 下选择 Le Chat 卡片，然后轻点 **使用 Mistral 登录**。请参阅[手机聊天](/zh/integrations/iphone-phone-chats)。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在 Mistral 控制台中确认密钥有效。 |
| 登录失效 | 打开账户卡片的菜单，点击 **重新连接**。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自己添加模型，请使用 **管理模型**。 |
| 速率限制错误 | 你的工作区的每分钟限额已用完。等待一分钟，或在 Mistral 控制台中查看限额。 |

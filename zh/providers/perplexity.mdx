---
title: "Perplexity"
description: "使用你自己的 Perplexity API 密钥，在 Enconvo 中与 Perplexity 模型聊天。"
---

Perplexity 的 Sonar 模型会在回答问题时进行网页搜索。把你的密钥添加到 Enconvo，即可在聊天、智能体和 AI 命令中使用这些模型。Perplexity 会把用量计入你自己的账户。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在 [Perplexity API 设置](https://www.perplexity.ai/settings/api) 中创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → Perplexity**。在 **身份验证** 下，将密钥粘贴到 **API 密钥** 中，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

如果想再保存一个 Perplexity 密钥（例如工作用的），点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **frequencyPenalty** | 降低词语重复的概率。默认值为 1。 |

如果想在某个聊天中使用其他模型，请在该聊天的模型选择器中选择。

此聊天服务提供商与 **设置 → 网页搜索** 相互独立：在此处选择 Perplexity 不会更改智能体所使用的搜索服务提供商。当回答涉及时事时，请打开其引用的来源进行核实。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在你的 Perplexity 账户中确认密钥有效。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新** 重新加载列表。如果要自己添加模型，请使用 **管理模型**。 |
| 图片或工具调用失败 | 选择支持图像输入或工具调用的模型。 |
| 速率或用量限制错误 | 在你的 Perplexity 账户中查看用量和限额，或暂时切换到其他服务提供商。 |
| 回复很慢 | 尝试更小的模型、更短的输入，或更低的推理强度。 |

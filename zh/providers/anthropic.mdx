在聊天、智能体和 AI 命令中使用 Anthropic 的 Claude 模型。你可以用 Anthropic API 密钥连接（Anthropic 按请求计费），也可以用你的 Claude 订阅登录。

## 连接

<Steps>
  <Step title="获取 API 密钥">
    在 [Anthropic Console](https://console.anthropic.com/) 中创建一个密钥。
  </Step>
  <Step title="添加到 Enconvo">
    打开 **设置 → AI 模型 → Anthropic**。在 **身份验证** 下选择 **API 密钥**，粘贴密钥，然后点击 **验证**。
  </Step>
  <Step title="选择模型">
    在 **模型名称** 中选择一个模型，并发送一条简短的消息。收到回复就说明连接正常。
  </Step>
</Steps>

<Tip>
有 Claude 订阅？可以改为在 **身份验证** 下选择 **Claude 订阅**，然后点击 **连接**。请参阅 [Claude 订阅](/zh/providers/anthropic_subscription)。
</Tip>

如果想再保存一个 Anthropic 密钥，点击 **添加新提供商** 并创建另一个配置。

## 模型与选项

| 设置 | 作用 |
| --- | --- |
| **模型名称** | 此服务提供商使用的模型。旁边的 **刷新** 会重新加载列表；**管理模型**（齿轮图标）可以添加或恢复模型。 |
| **API 基础地址** | 位于凭据中。默认值为 `https://api.anthropic.com`。仅在使用兼容 Anthropic 的服务时才需要更改。 |

聊天中的推理控制取决于你选择的模型。Anthropic 最强的模型 Claude Fable 5.2 支持从 **低** 到 **最高** 的推理强度，并在使用 API 密钥时提供快速模式。支持最高 1M Token 的 Claude 模型默认从 500K 上下文开始；你可以在 **管理模型** 中调高它。如果想在某个聊天中使用其他模型，请在该聊天的模型选择器中选择。

## 故障排除

| 问题 | 解决方法 |
| --- | --- |
| **验证** 失败 | 重新粘贴完整的密钥，并在 Anthropic Console 中确认密钥有效。 |
| 找不到某个模型 | 点击 **模型名称** 旁边的 **刷新**。如果要自己添加模型，请使用 **管理模型**。 |
| 速率或用量限制错误 | 在 Anthropic Console 中查看用量和限额，或暂时切换到其他服务提供商。 |
| 回复很慢 | 尝试更小的模型、更短的输入，或更低的推理强度。 |

Enconvo 把应用本身和它调用的 AI 分开计费。许可证用于解锁应用。AI 可以来自 Enconvo Cloud 点数、你自己的 API 密钥、你登录的服务提供商套餐，或你 Mac 上的模型，每种方式都在各自的地方计费。请在 **设置 → 账户** 和 Enconvo 网站上查看你的账户当前可以购买的套餐和价格。

## AI 的付费方式

| 使用方式 | 涵盖内容 | 用量显示位置 |
| --- | --- | --- |
| Enconvo 终身许可证 | 应用功能的使用权 | **设置 → 账户** 中的**终身许可证** |
| Enconvo Cloud 套餐 | 云端模型和服务，用点数支付 | **设置 → 点数用量** |
| 你自己的 API 密钥 | 对该服务提供商的请求 | 服务提供商自己的 API 账户 |
| 你登录的服务提供商套餐 | 该套餐支持的功能和限额 | 设置中该服务提供商的页面 |
| 本地模型 | 在你 Mac 上运行，占用其算力、内存和存储空间，另加模型下载 | 你的 Mac |

购买应用许可证不会给任何服务提供商增加付费 API 额度。服务提供商的聊天套餐也不一定包含该服务提供商的所有 API。

## Enconvo 套餐

- **终身许可证**：一次性买断应用，分为 Standard 和 Premium 两个等级，并赠送点数。使用你自己的 API 密钥时可以不限量使用 AI。Teams 是面向组织的终身许可证：你购买席位，并通过电子邮件分配每个席位。参见[团队](/zh/configuration/account)。
- **Enconvo Cloud**：按月或按年订阅的套餐，分为 Plus、Pro 和 Max 三个等级。它每月发放点数，并提供无需 API 密钥的 Cloud 模型。
- **Standard 试用**：免费账户可以获得一次 7 天的 Standard 试用，无需绑卡。提供试用时，**设置 → 账户** 中会出现**开始试用**。
- **代码**：许可证代码和试用代码在 **设置 → 兑换代码** 中激活。Teams 许可证代码会让你的账户成为该代码所含席位的团队管理员，每个席位包含 50,000 Cloud 点数。

终身许可证始终称为 Standard 和 Premium，不会与 Plus 和 Pro 的 Cloud 套餐重名。

查看当前的套餐和价格：

- [Enconvo 网站](https://www.enconvo.com)
- [Enconvo Cloud 套餐](https://www.enconvo.com/cloud-plan)
- [Cloud 模型价格](https://www.enconvo.com/cloud-pricing)

## Cloud 点数如何使用

订阅点数会优先使用，每次续订时重置为套餐的额度。充值点数（来自充值包和终身许可证）永不过期。

一次请求的花费取决于该功能实际使用的模型和调用方式。文本、图像、视频、语音转写、嵌入和实时语音的定价各不相同。

## 排查异常用量

1. 打开 **设置 → 点数用量** 查看 Enconvo Cloud 的用量，或到服务提供商自己的用量页面查看你自己 API 密钥的用量。
2. 打开 **设置 → 用量统计**，按模型、服务提供商和功能查看估算费用、Token 数和请求数。
3. 检查使用同一服务提供商配置的定时任务、长时间运行的任务、检索请求和生成请求。

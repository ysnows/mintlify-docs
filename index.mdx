## Choose how to work

| You want to… | Start here |
| --- | --- |
| Ask a quick question from any app | [SmartBar](/features/smartbar) |
| Keep an ongoing conversation | [Chat](/ai/chat) |
| Keep the assistant near the top of the screen | [Dynamic Island](/features/dynamic-island) |
| Improve selected text | [PopBar](/features/popbar) and [Writing Toolkit](/features/writing-tools) |
| Ask about something on screen | [Appshots](/features/appshots) or [Screen Doodle](/features/screen-doodle) |
| Search personal documents | [Knowledge Base](/ai/knowledge-base) |
| Speak naturally and hear answers | [Live Voice](/features/live-voice) |
| Create images, video, or audio | [Image Generation](/ai/image-generation), [Video Generation](/ai/video-generation), [Text-to-Speech](/ai/text-to-speech) |
| Connect an external AI client | [Knowledge Base MCP](/advanced/knowledge-base-mcp) |
| Configure a model or API key | [Providers](/providers/overview) and [Credentials](/configuration/credentials) |

## Find the right instructions for your build

These guides cover current Enconvo features, including features available first in Beta or Dev. If an entry is missing from your app, check its version and [update channel](/configuration/updates). Screenshots show an example configuration; your models, shortcuts, and installed tools may differ.

Use [Settings Reference](/configuration/settings-reference) to find a setting and [Troubleshooting](/getting-started/troubleshooting) when a task fails.

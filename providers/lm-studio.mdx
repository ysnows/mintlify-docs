---
title: "LM Studio"
description: "Connect Enconvo to LM Studio on your Mac or local network."
---

Use LM Studio to serve models locally or from another computer on your network. The model server must be running and have a compatible model available.

## Connect on the same Mac

1. Load a model in LM Studio and start its local API server.
2. Open **Settings → AI Model → LM Studio**.
3. Configure its credential/server URL. The default preset uses `http://127.0.0.1:1234/v1`.
4. Select a model from the available list and try a short text-only request.
5. Select that model in an Agent or conversation when you want to use it.

## Connect to another computer

Use the server computer’s LAN address instead of `127.0.0.1` or `localhost`; those names always refer to the computer running Enconvo. Configure the model server to accept connections on its local-network interface, and enable Enconvo under **System Settings → Privacy & Security → Local Network** if macOS blocks access.

Keep the port and API path appropriate to your server. Allow access only on networks and interfaces you intend to use.

## Troubleshooting

| Error | Check |
| --- | --- |
| Connection refused | Server is running, address/port are correct, and LAN listening is enabled if remote |
| Host/network unreachable | Network reachability and macOS Local Network permission |
| Empty model list | Model is downloaded/loaded and server endpoint is compatible |
| Tool calls or images fail | The selected model supports those capabilities |
| Out of memory | Choose a smaller model or reduce context and concurrent workloads |

Local model inference does not make remote tools offline. See [Local Models](/ai/local-llm) for the full processing chain.

PipeLLM is a gateway: one PipeLLM API key reaches models from many companies, including Claude, GPT, Gemini, Grok, Qwen, Kimi, and GLM. Use it when you want several vendors on one bill. PipeLLM bills the usage to your own account.

The same key also serves image generation, video generation, and web search.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in your [PipeLLM](https://pipellm.ai) account.
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → PipeLLM**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

To keep a second PipeLLM key, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |

The PipeLLM key also works in these features. Pick **PipeLLM** as the provider on each page:

| Feature | Where | What you get |
| --- | --- | --- |
| Image generation | **Settings → Image Generation** | Image generation and editing with models such as GPT Image, Nano Banana, and Seedream. |
| Video generation | **Settings → Video Generation** | Video models such as Seedance, Veo, Kling, and Sora. |
| Web search | **Settings → Web Search** | Google results with their snippets. PipeLLM charges each search that returns results. |

Changing the key in one place changes it for all of them, because they share one credential. The iPhone and Android apps can use PipeLLM in their AI model settings too.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in your PipeLLM account. |
| A model is missing | Click **Refresh** beside **Model Name**. To add a model yourself, use **Manage Models**. |
| Images or tools fail | Pick a model that supports image input or tool calls. |
| Rate, balance, or usage errors | Check your balance and limits in your PipeLLM account, or switch to another provider for now. |

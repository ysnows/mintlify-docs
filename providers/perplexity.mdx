---
title: "Perplexity"
description: "Chat with Perplexity models in Enconvo using your own Perplexity API key."
---

Perplexity's Sonar models search the web as they answer. Add your key to Enconvo to use those models in chats, Agents, and AI Commands. Perplexity bills the usage to your own account.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in the [Perplexity API settings](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → Perplexity**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

To keep a second Perplexity key, for example one for work, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |
| **frequencyPenalty** | Lowers the chance of repeated words. The default is 1. |

To use a different model in one chat, pick it from that chat's model picker.

This chat provider is separate from **Settings → Web Search**: choosing Perplexity here doesn't change the search provider your Agents use. When an answer is about current events, open the sources it cites.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in your Perplexity account. |
| A model is missing | Click **Refresh** beside **Model Name** to reload the list. To add a model yourself, use **Manage Models**. |
| Images or tools fail | Pick a model that supports image input or tool calls. |
| Rate or usage limit errors | Check usage and limits in your Perplexity account, or switch to another provider for now. |
| Replies are slow | Try a smaller model, a shorter input, or lower reasoning effort. |

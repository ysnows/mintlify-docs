---

Use your GitHub Copilot plan as an AI Model provider in Enconvo. You sign in with the GitHub account that has the plan; no API key is involved. Premium models count toward your plan's premium requests.

## Connect

<Steps>
  <Step title="Open the provider">
    Open **Settings → AI Model → GitHub Copilot**.
  </Step>
  <Step title="Start the sign-in">
    In **Authentication**, click **Connect**.
  </Step>
  <Step title="Enter the code on GitHub">
    Your browser opens GitHub's device page, and Enconvo shows the code to enter there. Enter the code and authorize the sign-in.
  </Step>
  <Step title="Check the account">
    Return to Enconvo and check that the intended GitHub account is connected.
  </Step>
  <Step title="Pick a model">
    Select a model and try a short request.
  </Step>
</Steps>

Closing Enconvo's code dialog before you authorize cancels the sign-in.

## Models and options

The model list shows only the models your Copilot plan can use, with Copilot's own chat default first. Copilot Free offers fewer models than the paid plans, so a model you saw elsewhere may not be listed. Each model uses the reasoning effort levels Copilot offers for it.

## On the iPhone

The iPhone app can sign in to GitHub Copilot too, for Phone chats on the phone. See [Phone Chats](/integrations/iphone-phone-chats).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The sign-in doesn't finish | Enter the code on GitHub's page before it expires, then click **Connect** again for a new code. |
| The model you want isn't listed | Your Copilot plan doesn't include it; pick another model or upgrade the plan. |
| A request fails with a model error | Pick a model from the current list; a default chosen before your plan changed may no longer be offered. |
| Rate or usage limit | Your plan's premium requests and GitHub's rate limits. |

Use OpenAI's GPT models in chats, Agents, and AI Commands. Connect with an OpenAI API key, which OpenAI bills per request, or sign in with your ChatGPT plan and use its allowance.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key on the [OpenAI platform](https://platform.openai.com/api-keys).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → OpenAI**. Under **Authentication**, choose **API Key**, paste the key, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

<Tip>
Have a ChatGPT plan? Choose **ChatGPT Subscription** under **Authentication** instead and click **Connect**. See [ChatGPT Subscription](/providers/openai_subscription).
</Tip>

To keep a second OpenAI key, for example one for work, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |
| **API Type** | In the credential. **Responses API** (the default) or **Completions API**. Keep Responses unless a compatible service needs Completions. |
| **API Base Url** | In the credential. The default is `https://api.openai.com/v1`. Change it only to use an OpenAI-compatible service. |

The same OpenAI profile also serves OpenAI embeddings, text-to-speech, image generation, and transcription, so changing its key affects those features too. To use a different model in one chat, pick it from that chat's model picker.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active and has billing set up on the OpenAI platform. |
| A model is missing | Click **Refresh** beside **Model Name**. To add a model yourself, use **Manage Models**. |
| A compatible service fails | Check **API Base Url**, then try **Completions API** as the **API Type**. |
| Rate or usage limit errors | Check usage and limits on the OpenAI platform, or switch to another provider for now. |

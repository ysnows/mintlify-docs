---
title: "SiliconFlow"
description: "Chat with SiliconFlow models in Enconvo using your own SiliconFlow API key."
---

SiliconFlow hosts many open models behind one API key. Add your key to Enconvo to use those models in chats, Agents, and AI Commands. SiliconFlow bills the usage to your own account.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in the [SiliconFlow account](https://cloud.siliconflow.cn/account/ak).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → SiliconFlow**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

To keep a second SiliconFlow key, for example one for work, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |

To use a different model in one chat, pick it from that chat's model picker.

SiliconFlow also offers embedding and reranking models for the Knowledge Base. Pick them in the Knowledge Base settings; they use the same SiliconFlow key.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in your SiliconFlow account. |
| A model is missing | Click **Refresh** beside **Model Name** to reload the list. To add a model yourself, use **Manage Models**. |
| Images or tools fail | Pick a model that supports image input or tool calls. |
| Rate or usage limit errors | Check usage and limits in your SiliconFlow account, or switch to another provider for now. |
| Replies are slow | Try a smaller model, a shorter input, or lower reasoning effort. |

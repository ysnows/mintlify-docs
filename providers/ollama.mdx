title: "Ollama"
description: "Chat with models that Ollama serves on your Mac or on another computer."
---

Use Ollama to run models on your own hardware, on this Mac or on another computer on your network. Enconvo sends chats to the Ollama server, so no provider account is needed.

## Connect on this Mac

<Steps>
  <Step title="Start Ollama">
    Install [Ollama](https://ollama.ai/), start it, and download a model with Ollama's own tools.
  </Step>
  <Step title="Point Enconvo at it">
    Open **Settings → AI Model → Ollama**. Under **Authentication**, keep **BaseUrl** at `http://127.0.0.1:11434` unless you changed Ollama's port.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

## Connect to another computer

1. On the other computer, set Ollama to accept connections from your network, not only from itself.
2. In Enconvo, set **BaseUrl** to that computer's network address, keeping the port and path. `127.0.0.1` and `localhost` always mean the Mac running Enconvo.
3. If macOS blocks the connection, turn on Enconvo in **System Settings → Privacy & Security → Local Network**.

Only open the server to networks you trust.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list from the server. |
| **Response Timeout** | How long to wait for the server to start or continue a reply. The default is **No limit**; long prompts can take many minutes on your own hardware before the first word. |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Connection refused | Check that Ollama is running and that **BaseUrl** has the right address and port. For another computer, check that it accepts network connections. |
| Network unreachable | Check the network, and the **Local Network** permission in System Settings. |
| The model list is empty | Load or download a model in Ollama, then click **Refresh**. |
| A reply gives up partway | Set **Response Timeout** to a longer value or **No limit**. |
| Tools or images fail | Pick a model that supports tool calls or image input. |
| Out of memory | Pick a smaller model, or shorten the input. |

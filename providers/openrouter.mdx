---
title: "OpenRouter"
description: "Chat with OpenRouter models in Enconvo using your own OpenRouter API key."
---

OpenRouter routes one API key to models from many companies. Add your key to Enconvo to use those models in chats, Agents, and AI Commands. OpenRouter bills the usage to your own account.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in the [OpenRouter](https://openrouter.ai/).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → OpenRouter**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

To keep a second OpenRouter key, for example one for work, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |
| **Google Search Tool** | Lets Gemini models ground answers in Google Search. Off by default. |
| **URL Context Tool** | Lets Gemini models read the pages at links in your message. Off by default. |

To use a different model in one chat, pick it from that chat's model picker.

Image and video generation have their own OpenRouter providers under **Settings → Image Generation** and **Settings → Video Generation**. Tool calls and image input depend on the model you pick.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in your OpenRouter account. |
| A model is missing | Click **Refresh** beside **Model Name** to reload the list. To add a model yourself, use **Manage Models**. |
| Images or tools fail | Pick a model that supports image input or tool calls. |
| Rate or usage limit errors | Check usage and limits in your OpenRouter account, or switch to another provider for now. |
| Replies are slow | Try a smaller model, a shorter input, or lower reasoning effort. |

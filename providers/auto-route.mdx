Auto Route runs each message on the model you set for that kind of work: a quick model for small talk, a stronger one for hard problems. It's the default AI model for anyone who hasn't chosen one, and it's first in the **AI Model** list.

## How it works

You set a few routes. Each route describes a kind of work and names the model that does it. For every message, Enconvo picks the route that fits best and sends the message to that route's model. Picking is free, and needs you to be signed in to your Enconvo account.

The default routes all run on Enconvo Cloud:

| Route | Used for | Default model |
| --- | --- | --- |
| **Simple tasks** | Greetings, short factual answers, yes-or-no questions, single-step actions | Claude Haiku 5.5 |
| **Writing & Q&A** | Chatting, answering questions, drafting, rewriting, translating, summarizing | Claude Haiku 5.5 |
| **Medium tasks** | Small code changes, reading a file or page, comparing options, making a plan | Claude Sonnet 5.5 |
| **Complex tasks** | Non-trivial code, design decisions, research across many sources, long documents | Claude Opus 5.5 |

A message that fits no route runs on the route marked **Fallback**: **Simple tasks**, or the first route if you remove that one.

## Change the routes

<Steps>
  <Step title="Open Auto Route">
    Open **Settings → AI Model → Auto Route** and find **Model Routes**.
  </Step>
  <Step title="Edit a route">
    Click a route to change its name, **Work this route takes**, **Model**, and **Effort**. The model can come from any provider you've set up, including your own API keys.
  </Step>
  <Step title="Add or remove routes">
    Click **Add Route** for a new kind of work, or **Remove route** to delete one. **Reset** brings back the default routes.
  </Step>
</Steps>

Describe each route's work in plain words. The clearer the description, the better messages land on the right model.

## See which route answered

Click **Details** under a reply to see the model and the Auto Route route that picked it, along with effort, points or cost, tokens, and time.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Auto Route asks you to sign in | Picking a route needs your Enconvo account. Sign in under **Settings → Account**. |
| Messages land on the wrong model | Make the routes' **Work this route takes** descriptions more distinct. |
| A route's model fails | Open that route and check its model's provider, or pick another model. |

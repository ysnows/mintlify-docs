Use Alibaba's Qwen models in chats, Agents, and AI Commands. Connect with an API key from Alibaba Cloud Model Studio; Alibaba Cloud bills the usage to your account. For the mainland China service (Bailian), use [DashScope](/providers/dashscope).

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → Qwen**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

Qwen connects with an API key only.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |
| **Base Url** | In the credential. The default is the international endpoint, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Change it if your key belongs to another region. |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Check that the key and **Base Url** belong to the same region, then paste the whole key again. |
| A model is missing | Click **Refresh** beside **Model Name**. To add a model yourself, use **Manage Models**. |
| Rate or usage limit errors | Check usage and quota in Model Studio, or switch to another provider for now. |

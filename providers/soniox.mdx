---

Soniox turns speech into text in real time and from files, in many languages, and can translate live captions as you record. Use it through Enconvo Cloud with no key, or with your own Soniox API key.

<Note>
**Soniox (Enconvo Cloud)** needs no API key, and Soniox dictation is free for Cloud Plan, Lifetime, and trial members.
</Note>

## Connect

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="Choose the provider">
        Open **Settings → Dictation Models** and choose **Soniox (Enconvo Cloud)**.
      </Step>
      <Step title="Test it">
        Dictate a short sentence. Text should appear as you speak.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Your own API key">
    <Steps>
      <Step title="Get an API key">
        In the [Soniox Console](https://console.soniox.com), open your project and create an API key.
      </Step>
      <Step title="Add it to Enconvo">
        Open **Settings → Dictation Models** and choose **Soniox**. Paste the key into the Soniox credential, then click **Validate**.
      </Step>
      <Step title="Test it">
        Dictate a short sentence. Text should appear as you speak.
      </Step>
    </Steps>
  </Tab>
</Tabs>

To use Soniox for recordings or files too, choose it under **Settings → Recording Models** or **Settings → Transcription Models**. Each page keeps its own choice.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model** | The Soniox model. Realtime models such as **Soniox STT Realtime v5** (the default) write text as you speak; async models such as **Soniox STT Async v5** transcribe finished files. See [Soniox models](https://soniox.com/docs/stt/models). |
| **Language Hints** | Languages to favor, English and Chinese by default. Add several if you switch languages while you talk. |
| **Live Translation** | Translates live captions while you record. The saved recording keeps the original-language transcript. Off by default. |
| **Translate From** | The language of the audio. **Auto** lets Soniox detect it. |
| **Translate To** | The language of the translated captions. |
| **Speak Translation** | Reads the translated captions aloud with your default voice. Off by default. |

Soniox also has text-to-speech providers, with your own key or on Enconvo Cloud, under **Settings → Text-to-Speech**.

Soniox processes audio in the cloud. To keep speech on your Mac, use a local provider such as Parakeet MLX, Qwen3 MLX, or Whisper MLX instead.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Copy the key again from the Soniox Console without extra spaces, and check it belongs to the right project. |
| Text doesn't appear while you speak | Pick a realtime model, then start dictation again. |
| Words come out in the wrong language | Set **Language Hints** to the languages you actually speak. |
| A file gives no transcript | Try a common format such as MP3, WAV, FLAC, or M4A, and check your Soniox usage and billing. |

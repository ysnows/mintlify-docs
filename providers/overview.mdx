A provider is the service behind an Enconvo feature: the model that answers a chat, the voice that reads aloud, the engine that searches the web. You choose one for each feature, and you can mix them.

## Choose how to connect

| If you want to | Use | Start here |
| --- | --- | --- |
| Start right away, with no keys | Enconvo Cloud, through your Enconvo account | [Enconvo Cloud](/providers/enconvo) |
| Let Enconvo pick a model per message | Auto Route, the default model | [Auto Route](/providers/auto-route) |
| Use a plan you already pay for | Sign in with ChatGPT, Claude, Grok, Mistral, GitHub Copilot, or Antigravity | [Sign in with a plan](#sign-in-with-a-plan) |
| Pay a provider directly | Your own API key | [Popular providers](#popular-providers) |
| Keep chats on your Mac | A local model | [Local models](/ai/local-llm) |
| Use models in the iPhone app's own chats | Phone chats | [Phone Chats](/integrations/iphone-phone-chats) |

## Set a provider for each feature

Each feature has its own Settings page: **AI Model**, **Text-to-Speech**, **Web Search**, **Image Generation**, **Video Generation**, **Web Fetch**, and **OCR**. Speech recognition has separate pages for **Dictation Models**, **Recording Models**, **Transcription Models**, and **Captioning Model**. Embeddings and reranking are set in the Knowledge Base.

Choosing a chat model doesn't change your speech, image, or search provider. Set each one where you want it.

## Profiles

A provider profile holds one key or sign-in. Click **Add New Provider** on a provider's page to keep a second one, for example a work account. Some profiles serve several features: one OpenAI profile covers chat, embeddings, text-to-speech, images, and transcription, so changing its key changes all of them. See [Credentials and profiles](/configuration/credentials).

Where your default model is set, and how each chat keeps its own, is in [Choose a model](/ai/model-selection-guide).

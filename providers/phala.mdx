title: "Phala"
description: "Chat with Phala models in Enconvo using your own Phala API key."
---

Phala runs models in confidential computing hardware. Use a **Confidential AI** API key. Add your key to Enconvo to use those models in chats, Agents, and AI Commands. Phala bills the usage to your own account.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in the [Phala Cloud](https://cloud.phala.ai).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → Phala**. Under **Authentication**, paste the key into **API Key**, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

To keep a second Phala key, for example one for work, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |

To use a different model in one chat, pick it from that chat's model picker.

**Validate** sends a minimal chat request, up to one output token. Enconvo sets the endpoint for you. Vision and tool calls depend on the model; one model supporting them doesn't mean the others do.

For model details and limits, see the [Phala Confidential AI docs](https://docs.phala.com/phala-cloud/confidential-ai/confidential-model/confidential-ai-api).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in your Phala account. |
| A model is missing | Click **Refresh** beside **Model Name** to reload the list. To add a model yourself, use **Manage Models**. |
| Images or tools fail | Pick a model that supports image input or tool calls. |
| Rate or usage limit errors | Check usage and limits in your Phala account, or switch to another provider for now. |
| Replies are slow | Try a smaller model, a shorter input, or lower reasoning effort. |

Connect your supported Google Gemini AI account through Enconvo’s provider Authentication controls. Available capabilities and limits depend on your account and the service’s current access rules.

## Connect

1. Open **Settings → AI Model → Google Gemini AI**.
2. In **Authentication**, select **Google Account**.
3. Click **Connect** and complete the account’s sign-in and authorization flow.
4. Return to Enconvo and check that the intended account is connected.
5. Select an available model and try a short request.

## Account status and usage

Use the account card’s menu to **Reconnect** or **Refresh usage** when those actions are available. **% left** describes remaining allowance; a reset countdown indicates when the reported window resets. Unavailable usage data is not a promise of unlimited access.

Google Account authentication applies to the Gemini AI Model connection. Other Gemini capabilities use the API key shared by the provider profile.

## Troubleshooting

If sign-in fails, follow the provider’s error and check that you connected the intended account. If a model or capability is unavailable, confirm it appears for that account in the current picker. If a usage window is exhausted, wait for its reported reset or choose another access method you have configured.

A subscription connection is distinct from an API key. Switching Authentication changes the access method used by that provider. See [Credentials](/configuration/credentials) for shared profiles and [Pricing](/pricing) for the difference between app licensing, Cloud usage, and provider billing.

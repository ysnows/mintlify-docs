Enconvo Cloud gives you models from several companies, plus speech, image, video, and web tools, through your Enconvo account. There are no API keys to manage: requests use your plan's points. It's the quickest way to start.

## Set up

<Steps>
  <Step title="Sign in">
    Sign in to your Enconvo account. See [Account](/configuration/account).
  </Step>
  <Step title="Choose Enconvo Cloud">
    Open the Settings page for what you want to do, such as **AI Model**, **Text-to-Speech**, or **Image Generation**, and choose the provider labeled **Enconvo Cloud** or **Enconvo Cloud Plan**.
  </Step>
  <Step title="Pick a model or voice">
    Choose a model or voice and run a short request.
  </Step>
</Steps>

Each feature has its own provider choice. Choosing Enconvo Cloud for chat doesn't switch speech, images, video, embeddings, reranking, or web tools; set each one where you want it.

## Enconvo's own models

Enconvo Cloud has three models of its own, named for the work they suit:

| Model | Use it for |
| --- | --- |
| **Enconvo Fast** | Quick turns: short answers, rewrites, small actions. It's the model **Enconvo Cloud Plan** starts on, and the default for AI Commands. |
| **Enconvo Balanced** | Everyday work with a few steps. |
| **Enconvo Ultra** | Hard tasks that need deep reasoning. |

They're listed first under **Enconvo Cloud Plan**, and [Auto Route](/providers/auto-route) uses them for its default routes.

## Find a model in the picker

The **Enconvo Cloud Plan** list groups models by vendor: Enconvo's own models first, then Anthropic, OpenAI, Google, and the rest, each with a count. A vendor shows its four newest models; click **Show N earlier models** to see the others. Search lists every match, and the model your chat uses always shows. Claude models are listed without the "Claude" prefix, such as **Sonnet 5.5** and **Opus 5.5**.

In the Chat Window's model picker, a Cloud model can carry a tag:

| Tag | Meaning |
| --- | --- |
| **New** | Added in the last 14 days. |
| A discount, such as **50% OFF** | The model costs less for now. Point at the row, or reach it with the arrow keys, to see the regular price. |
| **Free** | The model uses no points. |
| **Preview** | An early version of the model. |
| A date | The day the model leaves Enconvo Cloud. |

Enconvo Cloud sets the tags, so they change without an app update.

## Points and usage

Models cost different numbers of points. Settings shows the Cloud price next to each model and provider, along with what your plan includes, such as the free minutes you have left this month. See the [Cloud Plan](https://www.enconvo.com/cloud-plan) and [Cloud pricing](https://www.enconvo.com/cloud-pricing) pages for current plans and rates. To see what you've used, open **Settings → Points Usage**.

[Auto Route](/providers/auto-route), the default model, runs on Enconvo Cloud models. Picking the route for each message is free; the model that answers uses points.

Some Cloud services are free for every signed-in account:

- Web search with **Enconvo Cloud** and **DeepSeek (Enconvo Cloud)**. See [Web Search](/ai/web-search).
- Speech recognition with **Enconvo Cloud Fast**. See [Speech recognition](/ai/speech-recognition).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Requests ask you to sign in | Sign in under **Settings → Account**. |
| Requests fail with a points or balance error | Check **Settings → Points Usage**, then your plan on the [Cloud Plan](https://www.enconvo.com/cloud-plan) page. |
| A model is missing | The picker shows what your plan includes. Click **Refresh** beside **Model Name**. |

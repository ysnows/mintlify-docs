Enconvo Cloud gives you models from several companies, plus speech, image, video, and web tools, through your Enconvo account. There are no API keys to manage: requests use your plan's points. It's the quickest way to start.

## Set up

<Steps>
  <Step title="Sign in">
    Sign in to your Enconvo account. See [Account](/configuration/account).
  </Step>
  <Step title="Choose Enconvo Cloud">
    Open the Settings page for what you want to do, such as **AI Model**, **Text-to-Speech**, or **Image Generation**, and choose the provider labeled **Enconvo Cloud** or **Enconvo Cloud Plan**.
  </Step>
  <Step title="Pick a model or voice">
    Choose a model or voice and run a short request.
  </Step>
</Steps>

Each feature has its own provider choice. Choosing Enconvo Cloud for chat doesn't switch speech, images, video, embeddings, reranking, or web tools; set each one where you want it.

## Points and usage

Models cost different numbers of points. See the [Cloud Plan](https://www.enconvo.com/cloud-plan) and [Cloud pricing](https://www.enconvo.com/cloud-pricing) pages for current plans and rates. To see what you've used, open **Settings → Points Usage**.

[Auto Route](/providers/auto-route), the default model, runs on Enconvo Cloud models. Picking the route for each message is free; the model that answers uses points.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Requests ask you to sign in | Sign in under **Settings → Account**. |
| Requests fail with a points or balance error | Check **Settings → Points Usage**, then your plan on the [Cloud Plan](https://www.enconvo.com/cloud-plan) page. |
| A model is missing | The picker shows what your plan includes. Click **Refresh** beside **Model Name**. |

Enconvo Cloud Plan provides model and media services through your Enconvo account. Choose a provider labeled **Enconvo Cloud** or **Enconvo Cloud Plan** in the capability you want to use.

## Set up

1. Sign in to your Enconvo account.
2. Open a category such as **AI Model**, **Image Generation**, **Text-to-Speech**, or the relevant speech-model settings.
3. Select the Cloud provider and choose a model or voice.
4. Run a short request and check the output.
5. Review **Settings → Account → Points Usage** for Cloud consumption.

AI chat, speech, images, video, embeddings, reranking, and web tools use different provider configurations. Choosing Cloud for chat does not automatically select it for every other category.

## Models and usage

The current model picker and your account determine availability. Review the [Cloud Plan](https://www.enconvo.com/cloud-plan) and [Cloud pricing](https://www.enconvo.com/cloud-pricing) pages for current terms instead of assuming all model requests use the same number of points.

If a request fails, check account access, available balance or allowance, the selected model, and the reported error. BYOK and supported subscription connections are alternatives configured through [Credentials](/configuration/credentials).

Use Anthropic's Claude models in chats, Agents, and AI Commands. Connect with an Anthropic API key, which Anthropic bills per request, or sign in with your Claude plan.

## Connect

<Steps>
  <Step title="Get an API key">
    Create a key in the [Anthropic Console](https://console.anthropic.com/).
  </Step>
  <Step title="Add it to Enconvo">
    Open **Settings → AI Model → Anthropic**. Under **Authentication**, choose **API Key**, paste the key, then click **Validate**.
  </Step>
  <Step title="Pick a model">
    Choose a model in **Model Name** and send a short message. A reply means the connection works.
  </Step>
</Steps>

<Tip>
Have a Claude plan? Choose **Claude Subscription** under **Authentication** instead and click **Connect**. See [Claude Subscription](/providers/anthropic_subscription).
</Tip>

To keep a second Anthropic key, click **Add New Provider** and create another profile.

## Models and options

| Setting | What it does |
| --- | --- |
| **Model Name** | The model this provider uses. **Refresh** beside it reloads the list; **Manage Models** (the gear) adds or restores models. |
| **API Base Url** | In the credential. The default is `https://api.anthropic.com`. Change it only to use an Anthropic-compatible service. |

Reasoning controls in the chat depend on the model you pick. To use a different model in one chat, pick it from that chat's model picker.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Validate** fails | Paste the whole key again and check that it is active in the Anthropic Console. |
| A model is missing | Click **Refresh** beside **Model Name**. To add a model yourself, use **Manage Models**. |
| Rate or usage limit errors | Check usage and limits in the Anthropic Console, or switch to another provider for now. |
| Replies are slow | Try a smaller model, a shorter input, or lower reasoning effort. |

本頁說明[上下文感知](/zh-hant/features/context-awareness)背後的機制：Enconvo 可以從你的 Mac 讀取哪些項目、各自如何讀取，以及你如何控制哪些資訊會進入訊息中。當你想掌控傳送給模型的內容，或預期的上下文沒有出現時，可以參考本頁。

上下文感知不會在背景持續監看你的螢幕。它只會在你開啟 SmartBar 或自行加入項目時，從你剛才使用的應用程式讀取上下文。

## Enconvo 可以讀取的內容

每一種上下文都是可以加入到訊息中的項目。

| 上下文項目 | 包含內容 | Enconvo 如何讀取 |
|---|---|---|
| **選取的文字** | 在應用程式中反白選取的文字 | 輔助使用（Accessibility） |
| **目前應用程式內容** | 視窗標題與文字、應用程式提供的文件位址，以及該視窗的螢幕截圖 | 輔助使用與視窗擷取 |
| **瀏覽器目前分頁 URL** | 最前景分頁的網址、標題與網頁文字 | Apple Events；請參閱[瀏覽器](#瀏覽器) |
| **Finder 選取項目** | 在 Finder 中選取的檔案與資料夾路徑 | Apple Events |
| **Finder 目前目錄 URL** | 最前景 Finder 視窗開啟的資料夾 | Apple Events |
| **剪貼簿文字** | 剪貼簿上的文字 | 剪貼簿，僅在你手動加入時讀取 |
| **自訂選取區域截圖** | 你在螢幕上框選的區域 | 螢幕擷取 |
| **目前應用程式截圖** | 你剛才使用的應用程式畫面 | 螢幕擷取 |
| **目前螢幕截圖** | 整個螢幕畫面 | 螢幕擷取 |
| **即時螢幕截圖** | 當下的螢幕畫面，不含 Enconvo 的視窗 | 螢幕擷取 |

對於 Finder 項目，Enconvo 只會讀取路徑，不會讀取檔案內容。

### 瀏覽器

- **網址與標題**：透過 Apple Events 從 Safari、Chrome、Edge、Arc 及其他 Chromium 瀏覽器讀取。Firefox 未對外提供分頁網址，因此 Enconvo 無法讀取。
- **網頁文字**：Safari 會直接提供網頁文字。其他瀏覽器則是透過輔助使用讀取視窗內容，因此只有當該瀏覽器位於最前景時才能讀取。

### 其他應用程式

程式碼編輯器、文字編輯器與其他所有應用程式會取得**目前應用程式內容**：視窗標題、透過輔助使用揭露的文字、應用程式提供的文件位址，以及視窗截圖。能取得多少文字取決於各應用程式本身的實作。

## 開啟 SmartBar 時

當你開啟 SmartBar 時，它會檢查你剛才使用的應用程式中的三個來源。**設定 → 上下文感知**決定每個來源的處理方式：

| 來源 | 預設值 | 取得內容 |
|---|---|---|
| **選取的文字** | **自動加入** | 在剛才使用的應用程式中選取的文字 |
| **Finder 選取項目** | **建議** | 在 Finder 中選取的檔案與資料夾 |
| **瀏覽器目前網頁** | **建議** | 在 Safari、Chrome、Arc、Edge 或其他 Chromium 瀏覽器中開啟的網頁 |

- **自動加入**：開啟 SmartBar 時立即將該項目加入輸入框。
- **建議**：將項目列在指令上方，點一下即可加入。建議的網頁文字只有在你點擊後才會讀取。
- **關閉**：不讀取該來源。

只有 SmartBar 會使用這些設定。針對選取文字執行的指令一律會接收到選取的文字。

## 手動加入上下文

1. 在 SmartBar 中輸入 `#`。
2. 輸入幾個字母來篩選上下文項目列表。
3. 選擇一個項目。Enconvo 隨即讀取並將其加入你的訊息。

若要改用其他字元，請在**設定 → SmartBar** 的**搜尋**底下變更**上下文**的觸發字元。同一組設定也控制指令（`@`）、技能（`$`）與最近任務（`>`）。

## 權限

| 權限 | 用途 |
|---|---|
| **輔助使用** | 選取的文字、視窗內容，以及 Safari 以外瀏覽器的網頁文字 |
| **自動化** | Finder 項目與瀏覽器網頁。Enconvo 首次讀取每個應用程式時，macOS 會跳出詢問 |
| **螢幕錄製**（螢幕與系統音訊錄製） | 螢幕截圖以及**目前應用程式內容**中的視窗擷取 |

請在**系統設定 → 隱私權與安全性**中授予權限。Enconvo 會自動偵測輔助使用權限的變更。完整清單請參閱[權限](/zh-hant/configuration/permissions)。

## 上下文與 Token

上下文會計入模型的上下文視窗上限。網頁文字與截圖是佔用空間最大的項目，可能會造成：

- 回覆速度變慢
- 使用雲端模型時消耗較多費用
- 留給對話歷史的空間減少

<Tip>
在長對話中，建議只在需要該網頁或截圖的那則訊息中加入，而不要每次傳送都附加。
</Tip>

## 隱私與資料流向

擷取的上下文可能會成為已儲存對話或知識庫項目的一部分。模型請求以及你選用的 OCR、嵌入、轉寫或其他工具供應商都可能會收到相關內容。本機儲存與供應商處理的差異請參閱[隱私與安全性](/zh-hant/configuration/privacy-security)。

僅使用本機聊天模型並不代表所有工具都處於離線狀態。請檢視整體流程，包含瀏覽器存取、畫面擷取與透過雲端供應商處理的步驟。macOS 權限可限縮能讀取的上下文範圍，但無法保證所有第三方應用程式中的欄位都能被自動識別為敏感資料。

## 疑難排解

| 問題 | 解決方式 |
|---|---|
| 無法取得選取的文字或視窗內容 | 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo。部分應用程式未透過輔助使用提供文字；請改為複製文字後使用 `#` 加入**剪貼簿文字**。 |
| 無法取得瀏覽器網頁或 Finder 項目 | 在**系統設定 → 隱私權與安全性 → 自動化**中為該應用程式開啟 Enconvo 的存取權。 |
| 無法從 Firefox 取得網址 | Firefox 不會對外提供分頁網址。請改用其他瀏覽器，或手動複製網址。 |
| 取得網頁時沒有包含網頁文字 | Safari 以外的瀏覽器只能在位於最前景時讀取網頁文字。請在瀏覽器處於最前景時開啟 SmartBar。 |
| 上下文來自錯誤的應用程式 | 上下文取自你開啟 SmartBar 當下正在使用的應用程式。請先切換到目標應用程式並待其位於最前景後，再開啟 SmartBar。 |
| 螢幕截圖失敗 | 在**系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製**中開啟 Enconvo。 |

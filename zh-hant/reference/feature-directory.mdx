本文件中的每篇指南，都依側邊欄的方式分組。找到你想做的事，然後開啟對應的指南。個別內建指令請參閱[內建指令目錄](/zh-hant/extensions/built-in-extensions)。模型、語音和其他服務請參閱[服務供應商目錄](/zh-hant/providers/catalog)。

部分功能會先在 Beta 頻道推出。如果某篇指南介紹的內容在你的 App 裡沒有，請檢查你的[更新頻道](/zh-hant/configuration/updates)。

## 隨處問 AI

| 指南 | 可以幫你做什麼 |
| --- | --- |
| [SmartBar](/zh-hant/features/smartbar) | 在任何 App 中用一個快速鍵向代理程式提問或執行指令，並在輸入時進行計算、換算或查詢天氣與航班。 |
| [聊天視窗](/zh-hant/ai/chat) | 與代理程式進行更長的對話，加入檔案和上下文，用 /goal 讓代理程式持續朝目標執行，在臨時對話中提問，用增強提示詞改寫請求，並一次操作多個對話。 |
| [空間](/zh-hant/features/spaces) | 讓代理程式為你建立一個專屬頁面（例如追蹤器或即時看板），並將它保留在聊天視窗側邊欄和你的手機上。 |
| [動態島](/zh-hant/features/dynamic-island) | 從螢幕頂端的精簡面板向代理程式提問、執行快速鍵、在首頁計算，以及追蹤、核准或將執行中的任務標示為已讀。 |
| [PopBar](/zh-hant/features/popbar) | 選取文字後，在出現在選取處的工具列中解釋、翻譯、修正、搜尋或朗讀。 |
| [剪貼簿歷史、書籤與檔案搜尋](/zh-hant/features/clipboard-history) | 透過快速鍵或 SmartBar 貼上先前複製的內容、開啟瀏覽器書籤，或尋找 Mac 上的檔案。 |
| [App 側邊欄](/zh-hant/features/app-sidebar) | 在你正在使用的 App 或網站旁的側邊欄中與代理程式聊天，向 App 中插入回覆或提交訊息，並對 Finder 檔案執行檔案處理任務。 |
| [桌面寵物](/zh-hant/features/pet) | 在桌面上放一個動畫夥伴，顯示代理程式正在做什麼，並在點擊時開啟 Enconvo。 |
| [視窗管理](/zh-hant/features/window-management) | 選擇適合任務的 Enconvo 視窗，設定開啟各視窗的快速鍵，讓結果保持顯示，並在關閉視窗後不讓 Enconvo 出現在 Dock 中。 |

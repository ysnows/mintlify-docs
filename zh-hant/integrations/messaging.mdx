即時通訊管道讓使用者可以從 Telegram 或 Discord 與 Enconvo 代理程式對話。每個管道都是一個綁定到單一代理程式的機器人：傳入的訊息會交給該代理程式處理，並由它撰寫回覆。一個代理程式可以服務多個管道，但每個管道最多只能綁定一個代理程式。請前往**設定 → 即時通訊管道**進行設定。

這支影片在介紹虛擬形象與憑證管理之間，示範了如何設定 Telegram 管道。

## 開始之前

- 在對應平台建立機器人並複製其 Bot Token（請參閱下方的 [Telegram](#telegram) 與 [Discord](#discord) 說明）。
- 當機器人正在監聽訊息時，請保持 Enconvo 執行中且你的 Mac 處於連線狀態。

<Note>
免費方案一次可執行一個即時通訊機器人。Enconvo Cloud 方案或終身授權則可同時執行更多個。請參閱[方案與定價](/zh-hant/pricing)。
</Note>

## 新增管道

<Steps>
  <Step title="新增管道">
    開啟**設定 → 即時通訊管道**，點擊**新增頻道**，並選擇 **Telegram** 或 **Discord**。
  </Step>
  <Step title="命名">
    為這個管道取一個好辨識的名稱。
  </Step>
  <Step title="貼上 Bot Token">
    將平台的機器人權杖貼到 **Bot Token** 欄位中。
  </Step>
  <Step title="選擇代理程式">
    在 **bind agent** 中選擇要負責處理傳入訊息的代理程式。
  </Step>
  <Step title="開啟管道">
    確認誰可以使用此機器人（Telegram 請檢查**存取控制**），然後開啟**啟用管道**。
  </Step>
  <Step title="測試">
    點擊**檢查連線**，確認管道顯示為**已連接**。接著從允許使用的帳號傳送一則測試訊息。
  </Step>
</Steps>

綁定的代理程式所使用的模型與工具，決定了機器人能夠回答哪些問題。

## Telegram

透過 Telegram 的 **BotFather** 建立機器人並複製其 Bot Token。在開啟管道之前，請先開啟它的**存取控制**：

| 控制項 | 功能說明 |
| --- | --- |
| **政策** | **需要配對**（預設）：新使用者必須提供配對碼並等待你的核准。**開放（所有人）**：任何找到該機器人的人都能使用。 |
| **待處理的請求** | 針對每位請求配對的使用者進行**核准**或**拒絕**。請只核准你打算授權的對象。 |
| **允許的使用者** | 已獲你核准的使用者清單。點擊**移除**可將其移出清單；他們必須重新配對才能再次使用機器人。 |

如果機器人在私人聊天室可正常運作，但在群組中沒有反應，請同時檢查 Telegram 的機器人隱私設定、群組權限以及管道的存取政策。單憑權杖並不會讓機器人自動取得所有對話的存取權。

## Discord

在 Discord Developer Portal 中建立應用程式與機器人。將機器人邀請至你的伺服器，並授予它接收與傳送所需訊息的權限與 intents。將其 Bot Token 貼入 Discord 管道設定並綁定代理程式。

如果連線成功卻沒有回覆，請檢查機器人在 Discord 該頻道中的權限，以及是否開啟接收該類型訊息的設定。請將機器人的權限限制在你實際打算使用的伺服器與頻道內。

## 對話與回覆

每個傳入的對話都會與綁定的代理程式建立獨立的聊天工作階段。回覆會跟隨各自的對話脈絡；不同連線的使用者不會共用同一份對話記錄。更換綁定的代理程式會重新啟動管道，之後的訊息將改由新的代理程式處理。

在聊天中輸入機器人指令即可控制對話，而不會當成訊息傳送給代理程式：`/new` 會開啟全新的聊天工作階段，`/stop` 則會中止正在進行的回覆（包含剛才在它之前傳送的訊息）。機器人指令在 Telegram 與 Discord 皆可使用，且附帶附件傳送指令時仍會視為指令執行。

若要建立公開或團隊共用的機器人，請使用具備合適指示與工具的專用代理程式。開放他人使用前，請先檢視該代理程式能存取哪些工具。

## 排程傳送

[排程工作](/zh-hant/workflows/scheduled-jobs)可將執行結果傳送到你設定的即時通訊聊天室。請自行選擇目標聊天室，並透過任務的執行歷史記錄區分是任務執行失敗，還是訊息傳送失敗。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 顯示未連線 | 檢查 Bot Token、網路連線、是否已開啟**啟用管道**，以及 Enconvo 是否正在執行。連線中斷的 Discord 機器人會自動重新連線。 |
| 已連接但沒有回覆 | 檢查綁定的代理程式、該代理程式的模型供應商、平台權限以及配對政策。 |
| 機器人的回答方式不對 | 檢查綁定代理程式的指示詞、工具與模型設定。 |
| Telegram 使用者無法連線 | 查看**待處理的請求**中是否有對方的配對申請，並檢查**允許的使用者**清單。 |
| 第二個機器人無法啟動 | 免費方案一次只能執行一個即時通訊機器人。請關閉另一個機器人，或升級方案。 |
| 結束 Enconvo 後機器人停止回覆 | 機器人是透過你 Mac 上的 Enconvo 進行監聽，因此應用程式必須保持執行狀態。 |

即時通訊管道僅用於設定 Telegram 與 Discord。如果你透過其他外掛程式或 MCP 伺服器連接 Slack 或飛書，請參閱該整合功能自己的說明文件。

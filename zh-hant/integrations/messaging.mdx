即時通訊管道讓人們可以從 Telegram 或 Discord 與 Enconvo 代理程式對話。每個頻道都是綁定到一個代理程式的機器人：傳入的訊息會交給該代理程式，並由它撰寫回覆。一個代理程式可以服務多個頻道，但每個頻道最多只服務一個代理程式。請在 **設定 → 即時通訊管道** 中設定。

這段影片在介紹虛擬形象與憑證管理之間，設定了一個 Telegram 頻道。

## 開始之前

- 在平台上建立機器人，並複製它的機器人權杖（請見下方的 [Telegram](#telegram) 和 [Discord](#discord)）。
- 在機器人監聽期間，請保持 Enconvo 執行且 Mac 在線上。

<Note>
免費方案一次只能執行一個即時通訊機器人。Enconvo Cloud 方案或終身授權可以執行更多。請參閱[方案與價格](/zh-hant/pricing)。
</Note>

## 加入頻道

<Steps>
  <Step title="加入頻道">
    開啟 **設定 → 即時通訊管道**，點擊 **新增頻道**，並選擇 **Telegram** 或 **Discord**。
  </Step>
  <Step title="命名">
    為頻道取一個你認得的名稱。
  </Step>
  <Step title="貼上機器人權杖">
    將平台的機器人權杖貼到 **機器人權杖**。
  </Step>
  <Step title="選擇代理程式">
    在 **綁定代理程式** 中，選擇處理傳入訊息的代理程式。
  </Step>
  <Step title="開啟">
    檢視誰可以使用機器人（Telegram 為 **存取控制**），然後開啟 **啟用頻道**。
  </Step>
  <Step title="測試">
    點擊 **檢查連線**，並確認頻道顯示 **已連接**。然後用允許的帳號傳送一則測試訊息。
  </Step>
</Steps>

機器人能回答什麼，取決於所綁定代理程式的模型和工具。

## Telegram

用 Telegram 的 **BotFather** 建立機器人，並複製它的機器人權杖。在開啟頻道之前，先開啟它的 **存取控制**：

| 控制項 | 作用 |
| --- | --- |
| **政策** | **需要配對**（預設）：新使用者分享配對碼並等待你的核准。**開放（所有人）**：任何找到機器人的人都可以使用。 |
| **待處理的請求** | 對每位要求配對的使用者選擇 **核准** 或 **拒絕**。請只核准你想核准的人。 |
| **允許的使用者** | 你已核准的使用者。**移除** 會將其從清單中移除；他們需要重新配對才能使用機器人。 |

如果機器人在私人對話中可以運作，但在群組中不行，除了頻道的存取政策之外，也請檢查 Telegram 的機器人隱私設定與群組權限。光有權杖並不會讓機器人能存取每個對話。

## Discord

在 Discord 開發者入口網站中建立一個應用程式和機器人。將機器人邀請到你的伺服器，並賦予它接收和傳送你想要的訊息所需的權限和 Intent。將它的機器人權杖貼到 Discord 頻道中，並綁定一個代理程式。

如果它已連線但沒有回覆，請檢查 Discord 上頻道的權限，以及機器人是否會收到該類型的訊息。請將機器人限制在你想要的伺服器和頻道內。

## 工作階段與回覆

每個傳入的對話都會與所綁定的代理程式建立各自的聊天工作階段。回覆會跟隨該對話；已連線的使用者不會共用同一份對話記錄。變更所綁定的代理程式會重新啟動頻道，因此之後的訊息會交給新的代理程式。

在對話中輸入機器人指令，即可控制對話，而不是傳送訊息給代理程式：`/new` 會開始新的聊天工作階段，`/stop` 會停止正在進行的回覆，包含在它之前剛傳送的訊息。機器人指令在 Telegram 和 Discord 中都可使用，附帶附件傳送的指令仍會作為指令執行。

對於公開或團隊的機器人，請使用專用的代理程式，並設定合適的指示和工具。在讓其他人接觸它之前，請檢視它可以使用哪些工具。

## 排程傳送

[排程工作](/zh-hant/workflows/scheduled-jobs)可以將結果傳送到你設定的即時通訊對話。請自行選擇目的地，並利用任務的執行記錄來分辨是執行失敗還是傳送失敗。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 已中斷連線 | 檢查機器人權杖、網路、**啟用頻道** 是否開啟，以及 Enconvo 是否正在執行。連線沒有回應的 Discord 機器人會自行重新連線。 |
| 已連接但沒有回應 | 檢查所綁定的代理程式、該代理程式的模型供應商、平台的權限，以及配對政策。 |
| 機器人的回答方式不對 | 檢查所綁定代理程式的指示、工具和模型。 |
| Telegram 使用者無法連線 | 在 **待處理的請求** 下查看他們的配對請求，並檢查 **允許的使用者**。 |
| 第二個機器人無法啟動 | 免費方案一次只能執行一個即時通訊機器人。請關閉另一個機器人，或升級。 |
| 結束 Enconvo 後回覆就停止了 | 機器人透過你 Mac 上的 Enconvo 監聽，因此 App 必須持續執行。 |

即時通訊管道只能設定 Telegram 和 Discord。如果你透過其他外掛程式或 MCP 伺服器連接 Slack 或飛書，請遵循該整合自己的指南。

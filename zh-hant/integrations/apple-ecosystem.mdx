---

代理程式可以在你 Mac 內建的 App 中工作：查看你的行程、新增提醒事項、查詢電話號碼、儲存備忘錄、歸檔郵件，以及傳送 iMessage。你用平常的語言提出需求，代理程式就會替你使用該 App。

每個 App 都是 **設定 → 外掛程式** 中 **Mac App** 分頁上的一個外掛程式。連接時，macOS 會要求權限，而不是要求帳號。只有在代理程式需要時，Enconvo 才會讀取 App，也不會在背景同步任何東西。讀取到的內容會傳送給你為該對話選擇的 AI 模型。

## 連接 App

<Steps>
  <Step title="開啟 Mac App">
    開啟 **設定 → 外掛程式**，並點擊 **Mac App** 分頁。
  </Step>
  <Step title="連接 App">
    點擊該 App，然後點擊 **連接**。閱讀連接的意義，然後點擊 **繼續**。
  </Step>
  <Step title="允許存取">
    macOS 會詢問 Enconvo 是否可以使用該 App。請允許。對於某些 App，Enconvo 會在背景開啟該 App，以便 macOS 詢問。
  </Step>
  <Step title="試試看">
    該 App 會顯示 **已在這台 Mac 上連接**。點擊 **立即體驗**，或對代理程式提出下方範例中的某個需求。
  </Step>
</Steps>

## 代理程式可以做什麼

| App | 代理程式可以做什麼 | macOS 權限 |
| --- | --- | --- |
| 行事曆 | 讀取任何日期範圍內你的行事曆和活動，涵蓋「行事曆」中設定的每個帳號。新增活動、變更其時間、地點和備註，以及刪除活動。 | **行事曆** |
| 提醒事項 | 一次讀取一個清單，以及仍待完成或已完成的提醒事項。新增提醒事項、變更其到期日和備註、標記為完成或未完成、移到另一個清單，以及刪除。 | **提醒事項** |
| 聯絡人 | 依姓名、電話號碼或電子郵件地址尋找聯絡人，並一次讀取一頁你的聯絡人。代理程式無法變更你的聯絡人。 | **自動化**，然後是 **聯絡人** |
| 備忘錄 | 搜尋並讀取備忘錄，包含其資料夾和附件。新增備忘錄、在其中補充或改寫、在資料夾之間移動，以及刪除。已鎖定的備忘錄會保持鎖定。 | **自動化** |
| 郵件 | 搜尋你的信箱，涵蓋「郵件」中設定的每個帳號，並讀取郵件及其附件。撰寫草稿、傳送、回覆、轉寄，以及移動、加旗標或刪除郵件。 | **自動化** |
| 訊息 | 讀取未讀訊息和對話記錄，包含群組對話和美國以外的號碼。立即傳送 iMessage，或稍後以你可以查看或取消的一次性[自動化](/zh-hant/workflows/scheduled-jobs)傳送。 | **自動化**，另加讀取記錄所需的 **完整磁碟取用權限** |
| 音樂 | 播放你資料庫或 Apple Music 目錄中的歌曲、專輯、演出者和播放列表。暫停、跳過、設定音量、隨機播放和重複播放，並查看正在播放的內容。 | **自動化** |

**Mac App** 分頁上還有 Spotify，運作方式相同。它需要你 Mac 上有已登入你帳號的 Spotify App。

<Warning>
代理程式可以在不先詢問的情況下變更和刪除活動、提醒事項、備忘錄與郵件，也可以傳送郵件。若你想先檢視，請要求提供計畫或草稿。在「訊息」中傳送訊息之前，代理程式會確認收件人和內容。
</Warning>

## 中斷 App 的連線

在 **Mac App** 分頁上開啟該 App，並點擊 **中斷連線**。這會在 Enconvo 中將該 App 關閉。若也要移除 macOS 的存取權限，請在 **系統設定 → 隱私權與安全性** 中，於上表為該 App 列出的權限下關閉 Enconvo。

## 各 App 範例

### 郵件

「郵件」可搭配「郵件」App 中設定的每個帳號，包含 iCloud、Gmail、Outlook 和 Exchange。代理程式還可以管理信箱、開啟或關閉郵件規則、儲存附件，以及計算未讀郵件數量。

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### 提醒事項

提醒事項可以有到期日期和時間、備註、優先順序（無、低、中或高）、重複規則，以及在你抵達或離開時觸發它的地點。重複規則可以是每天、每週、每月或每年，每隔一個或多個週期（例如每 2 週），並可設定結束日期。

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### 行事曆

活動可以是全天活動、可以有地點、備註和連結，可以設定在開始前若干分鐘的鬧鐘，可以將你顯示為忙碌、有空、暫定或不在，並可每天、每週、每月或每年重複，直到結束日期或重複指定的次數。當你刪除重複活動時，代理程式可以刪除每一次出現。

**基本活動：**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**全天活動：**
```
"Block off next Friday as a personal day"
```

**重複活動：**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**鬧鐘：**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**多個行事曆：**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 聯絡人

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### 訊息

「訊息」可以傳送 iMessage 給電話號碼、電子郵件地址或群組對話。「訊息」App 必須登入你的 Apple 帳號才能傳遞 iMessage。當「訊息」將某則訊息標示為 **未送達** 時，代理程式會告訴你，而不是說它已傳送。

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### 備忘錄

代理程式也可以讀取你在「備忘錄」中選取的備忘錄，適合「摘要這個」或「翻譯這個」之類的請求。

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### 地圖

代理程式會開啟 Apple 地圖來搜尋地點、顯示開車、步行或搭乘大眾運輸的路線、放置大頭針，以及建立指南。結果會顯示在「地圖」中，而不是在對話中。若要將地點儲存為我的最愛或加入指南，代理程式會開啟它，由你在「地圖」中完成該步驟。

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### 捷徑

代理程式不會執行「捷徑」。若要從 Enconvo 執行，請在 **設定 → 快捷操作** 中，為快捷操作加入 **執行捷徑** 步驟。

## 權限

每個 App 都使用自己的 macOS 權限，已列在上表中：

- 「行事曆」和「提醒事項」使用 **系統設定 → 隱私權與安全性** 中的 **行事曆** 與 **提醒事項** 清單。
- 「聯絡人」、「備忘錄」、「郵件」、「訊息」和「音樂」使用 **自動化**，macOS 會在其中詢問 Enconvo 是否可以控制各個 App。「聯絡人」還會要求存取你的聯絡人。
- 「訊息」將你的記錄保存在受保護的檔案中，因此讀取它需要 Enconvo 的 **完整磁碟取用權限**。

如果你拒絕了權限提示，該 App 就無法與 Enconvo 搭配使用。對於「行事曆」、「提醒事項」和「聯絡人」，在 **Mac App** 分頁上重新連接該 App，macOS 就會再次詢問你。當 macOS 封鎖了已連接的 App 時，它在 **Mac App** 分頁上的那一列會顯示 **開啟設定**，帶你前往正確的開關。你之後隨時可以在 **系統設定 → 隱私權與安全性** 中變更這些權限。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 「郵件」無法運作 | 確認「郵件」App 至少有一個電子郵件帳號。檢查 Enconvo 在 **系統設定 → 隱私權與安全性 → 自動化** 中對「郵件」是開啟的。 |
| 行事曆存取被拒絕 | 在 **系統設定 → 隱私權與安全性 → 行事曆** 中，確認 Enconvo 已列出且已開啟。允許後請重新啟動 Enconvo。 |
| 提醒事項沒有出現 | 檢查 Enconvo 在 **系統設定 → 隱私權與安全性 → 提醒事項** 中是否具有存取權限，並確認提醒事項有顯示在「提醒事項」App 中。 |
| 「訊息」無法讀取你的記錄 | 在 **系統設定 → 隱私權與安全性** 中，為 Enconvo 開啟 **完整磁碟取用權限**。 |
| 已連接的 App 顯示 **開啟設定** | macOS 正在封鎖 Enconvo。點擊 **開啟設定** 並開啟 Enconvo。 |

description: "讓代理程式在你 Mac 上的行事曆、提醒事項、聯絡人、備忘錄、郵件、訊息、音樂與地圖中為你工作。"

代理程式可以直接使用你 Mac 內建的應用程式：查看行程、新增提醒事項、查詢電話號碼、儲存備忘錄、整理郵件以及傳送 iMessage。你只需要用自然語言提出要求，代理程式就會代你操作這些應用程式。

每個應用程式都是**設定 → 外掛程式**中 **Mac App** 分頁裡的一個外掛程式。連接時向你要求的是 macOS 系統權限，而不是帳號密碼。Enconvo 只會在代理程式需要時才讀取應用程式內容，不會在背景同步任何資料。它讀取的內容會傳送給你在該聊天中所選擇的 AI 模型。

## 連接應用程式

<Steps>
  <Step title="開啟 Mac App">
    開啟**設定 → 外掛程式**並點擊 **Mac App** 分頁。
  </Step>
  <Step title="連接應用程式">
    點擊該應用程式，再點擊**連接**。閱讀連接說明後，點擊**繼續**。
  </Step>
  <Step title="允許存取">
    macOS 會詢問是否允許 Enconvo 使用該應用程式。請允許它。對於部分應用程式，Enconvo 會在背景開啟它，以便 macOS 跳出授權詢問。
  </Step>
  <Step title="立即體驗">
    該應用程式會顯示**已在這台 Mac 上連接**。點擊**立即體驗**，或從下方範例中挑選一項請代理程式執行。
  </Step>
</Steps>

## 代理程式能做什麼

| 應用程式 | 代理程式能做什麼 | macOS 權限 |
| --- | --- | --- |
| 行事曆 | 讀取你在「行事曆」中設定的所有帳號之行事曆與任意日期範圍的行程。新增行程，修改時間、地點與附註，以及刪除行程。 | **行事曆** |
| 提醒事項 | 每次讀取一個列表，查看尚未完成或已完成的提醒事項。新增提醒事項、更改到期日與附註、標記完成或未完成、移動至其他列表，以及刪除它們。 | **提醒事項** |
| 聯絡人 | 依姓名、電話號碼或電子郵件地址尋找人員，並分頁讀取你的聯絡人資料。代理程式無法更改你的聯絡人。 | **自動化**，接著是**聯絡人** |
| 備忘錄 | 搜尋與讀取備忘錄，包含其檔案夾與附件。新增備忘錄、追加內容或改寫、在檔案夾之間移動，以及刪除備忘錄。已鎖定的備忘錄仍會保持鎖定。 | **自動化** |
| 郵件 | 搜尋你在「郵件」中設定的所有帳號之信箱，並讀取郵件與附件。撰寫草稿、傳送、回覆、轉寄，以及移動、加上旗標或刪除郵件。 | **自動化** |
| 訊息 | 讀取未讀訊息與對話歷史記錄，包含群組聊天與美國以外的號碼。立即傳送 iMessage，或設定為稍後執行的一次性[排程工作](/zh-hant/workflows/scheduled-jobs)，隨時可檢視或取消。 | **自動化**，另外需要**完整磁碟取用權限**以讀取歷史記錄 |
| 音樂 | 播放你資料庫或 Apple Music 目錄中的歌曲、專輯、藝人與播放列表。暫停、跳過、調整音量、隨機播放與重複播放，以及查看目前播放內容。 | **自動化** |

**Mac App** 分頁中還包含 Spotify，連接方式相同。它需要在你 Mac 上安裝並登入你帳號的 Spotify 應用程式。

<Warning>
代理程式不需先詢問即可修改及刪除行程、提醒事項、備忘錄與郵件，並傳送郵件。若想先看過內容，請要求提供計畫或草稿。透過「訊息」傳送訊息前，代理程式會先向你確認收件人與文字內容。
</Warning>

## 中斷應用程式連線

在 **Mac App** 分頁中開啟該應用程式並點擊**中斷連線**。這會在 Enconvo 中關閉該應用程式。若要一併移除 macOS 存取權限，請在**系統設定 → 隱私權與安全性**中，依照上表所列的對應權限關閉 Enconvo。

## 各應用程式範例

### 郵件

「郵件」支援在郵件 App 中設定的所有帳號，包括 iCloud、Gmail、Outlook 與 Exchange。代理程式也能管理信箱、開啟或關閉郵件規則、儲存附件，以及統計未讀郵件數量。

```
"Show me my unread emails"
"Send an email to alice@example.com about the project deadline"
"Archive all emails from notifications@github.com"
"What did Bob say in his last email?"
```

### 提醒事項

提醒事項可以包含到期日期與時間、附註、優先順序（無、低、中、高）、重複規則，以及在抵達或離開某個地點時觸發的位置條件。重複規則支援每日、每週、每月或每年，可設定間隔一或多個週期（例如每 2 週），並可選填結束日期。

```
"Remind me to call the dentist tomorrow at 2pm"
"Add a reminder for the team standup every weekday at 9am"
```

```
"Create a high-priority reminder to submit the report by Friday"
```

```
"Set a recurring reminder to review expenses on the first of every month"
```

```
"Remind me to buy groceries when I arrive at the store"
```

```
"What did I complete in my Work list this week?"
"Move the dentist reminder to my Personal list"
```

### 行事曆

行程可設為整日行程，包含地點、附註與連結，設定在開始前幾分鐘觸發的提示，顯示你的狀態為忙碌、空閒、暫定或無法出席，並設定每日、每週、每月或每年重複，直到結束日期或重複特定次數。刪除重複行程時，代理程式可以一併刪除所有重複場次。

**基本行程：**
```
"Schedule a team meeting tomorrow at 3pm for one hour"
"Add a dentist appointment on March 25th from 10am to 11am at 123 Main St"
```

**整日行程：**
```
"Block off next Friday as a personal day"
```

**重複行程：**
```
"Create a weekly team standup every Monday at 9am"
"Schedule a monthly review on the first of each month"
```

**提示：**
```
"Schedule a meeting at 2pm with a 15-minute reminder"
"Add a 1-hour warning alarm to my flight tomorrow"
```

**多個行事曆：**
```
"Add this event to my Work calendar"
"Show me events from all calendars for the next week"
```

### 聯絡人

```
"What is Alice's phone number?"
"Get Bob's email address"
```

### 訊息

「訊息」會將 iMessage 傳送給電話號碼、電子郵件地址或群組聊天。「訊息」App 必須登入你的 Apple 帳號才能發送 iMessage。當「訊息」將訊息標記為**尚未傳送**時，代理程式會告訴你，而不會回報傳送成功。

```
"Send a text to Alice saying I'll be 10 minutes late"
"Message Bob 'meeting pushed to 3pm'"
```

### 備忘錄

代理程式也能讀取你在「備忘錄」中選取的項目，非常適合「摘要這份備忘錄」或「翻譯這段內容」這類請求。

```
"Create a note titled 'Trip Checklist' with my packing list"
"Add today's meeting notes to my 'Work' folder"
"Summarize the note I have open"
```

### 地圖

代理程式會開啟 Apple「地圖」來搜尋地點，提供開車、步行或大眾運輸路線，放置大頭針以及建立指南。結果會顯示在地圖 App 中，而不是聊天裡。若要將地點儲存為喜好項目或加入指南，代理程式會先開啟該地點，再由你在「地圖」中完成最後一步。

```
"Where is 1 Infinite Loop?"
"Directions from my office to SFO by car"
```

### 捷徑

代理程式不會直接執行捷徑。若要從 Enconvo 執行某個捷徑，請在**設定 → 快捷操作**中為快捷操作加入**執行捷徑**步驟。

## 權限

每個應用程式都會使用對應的 macOS 權限，如上方表格所示：

- 「行事曆」與「提醒事項」使用**系統設定 → 隱私權與安全性**中的**行事曆**與**提醒事項**列表。
- 「聯絡人」、「備忘錄」、「郵件」、「訊息」與「音樂」使用**自動化**，macOS 會詢問 Enconvo 是否可以控制每個應用程式。「聯絡人」另外還會請求取用你的聯絡人。
- 「訊息」將歷史記錄儲存在受保護的檔案中，因此讀取歷史記錄需要為 Enconvo 開啟**完整磁碟取用權限**。

如果你拒絕了權限提示，該應用程式將無法與 Enconvo 搭配運作。針對「行事曆」、「提醒事項」與「聯絡人」，在 **Mac App** 分頁重新連接一次，就能讓 macOS 再次詢問你。當 macOS 封鎖某個已連接的應用程式時，它在 **Mac App** 分頁的列表列會顯示**開啟設定**，帶你直接跳轉至對應開關。你之後隨時可以在**系統設定 → 隱私權與安全性**中更改任何權限。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 郵件無法運作 | 確認「郵件」App 中至少設定了一個電子郵件帳號。檢查**系統設定 → 隱私權與安全性 → 自動化**中 Enconvo 的郵件開關是否已開啟。 |
| 行事曆存取被拒 | 在**系統設定 → 隱私權與安全性 → 行事曆**中，確認 Enconvo 在列表中且已開啟。允許後請重新啟動 Enconvo。 |
| 找不到提醒事項 | 檢查 Enconvo 在**系統設定 → 隱私權與安全性 → 提醒事項**中是否有權限，且該提醒事項確實顯示在「提醒事項」App 中。 |
| 訊息無法讀取歷史記錄 | 在**系統設定 → 隱私權與安全性**中為 Enconvo 開啟**完整磁碟取用權限**。 |
| 已連接的應用程式顯示**開啟設定** | macOS 正在封鎖 Enconvo。點擊**開啟設定**並開啟 Enconvo。 |

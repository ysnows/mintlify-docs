你的代理程式能處理的不只是這台 Mac。加入一台你用 SSH 登入的伺服器，在對話中提及它並提出需求，就像詢問你自己的 Mac 一樣：代理程式會在那裡執行指令，並在這裡回覆。伺服器上不需要安裝任何東西。你其他執行 Enconvo 的電腦也可以用同樣的方式配對。

下方的影片會從你的 SSH 設定加入一台 SSH 主機，請代理程式讀取上面的記錄檔，並展示誰可以存取這台 Mac。

## 開始之前

- 你需要一台能從這台 Mac 用 `ssh` 登入的伺服器：`~/.ssh/config` 中的主機，或是你能以 `user@host` 輸入的位址。Enconvo 使用這台 Mac 本身的 `ssh` 和金鑰。如果伺服器要求密碼或通行密語，`ssh` 會透過 Enconvo 詢問，而 Enconvo 不會保留其中任何內容。
- 對於區域網路中的伺服器，請在 **系統設定 → 隱私權與安全性 → 區域網路** 中允許 Enconvo。

## 連線列出的內容

開啟 **設定 → 連線**。它有三個清單：

| 清單 | 內容 |
| --- | --- |
| **手機** | 與這台 Mac 配對的 iPhone 和 Android App。請參閱 [iPhone App](/zh-hant/integrations/iphone-app)。 |
| **電腦** | 與這台 Mac 配對、執行 Enconvo 的其他電腦。每一台只列出一次，並標示控制的方向。點擊 **配對電腦** 即可新增。請參閱[你的其他電腦](/zh-hant/integrations/other-computers)。 |
| **SSH 主機** | 你的代理程式透過 SSH 存取的伺服器，上面不安裝任何東西。 |

點擊手機或電腦即可開啟它自己的頁面，查看它在這台 Mac 上能做什麼。

你也可以從聊天視窗加入主機、配對電腦或配對手機：點擊側邊欄底部的裝置切換器，然後點擊 **加入裝置**。

## 加入 SSH 主機

1. 開啟 **設定 → 連線**，在 **SSH 主機** 下點擊 **加入主機**。
2. 清單會顯示你 `~/.ssh/config` 中的主機。挑選一台，例如 `build-server`，或輸入 `user@host`（或 `user@host:port`）。
3. 點擊 **連接**。Enconvo 會測試連線：連到主機、檢查主機金鑰、登入並執行一個指令。
4. 在 **每條指令前** 下，選擇代理程式在那裡執行指令前如何詢問：
   - **跟隨對話**：依對話的權限模式詢問。請參閱[核准動作](/zh-hant/ai/agents)。
   - **每次詢問**：每個指令之前都會詢問。
5. 點擊 **加入主機**。

主機現在會顯示在 **SSH 主機** 下，以及每個對話的 `@` 選單中。

第一次看到伺服器的主機金鑰時，請與管理該伺服器的人核對金鑰，然後點擊 **信任並連線**。在 Linux 伺服器上，對話框還會提供 **同時在那裡安裝 Enconvo**，這會將該伺服器配對為電腦。保持關閉則不會安裝任何東西。

## 請代理程式在主機上工作

1. 在對話中輸入 `@` 和主機名稱的開頭。你的電腦和 SSH 主機會列在 **電腦** 下。
2. 挑選主機。它會以標籤的形式放入訊息中。
3. 說明你要在那裡完成的事並送出。例如：

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

代理程式會透過 SSH 在主機上執行指令，並依你為該主機所選的方式先詢問。每個指令步驟都會標明它在哪台主機上執行。答案會回到對話中。

若要查看它執行了什麼，請點擊答案上方的 **已工作**。展開的內容會列出每個指令。

你可以用同樣的方式提及已配對的電腦。代理程式會將任務交給那台電腦自己的代理程式，或在那台電腦允許這台 Mac 使用終端機時，直接在那裡執行指令。

在對話中，於主機或其他電腦上執行的指令會顯示為 **執行了一個指令**，每個步驟都會標明機器名稱。

## 讓代理程式在已配對的電腦上工作

在 **設定 → 連線** 中，點擊 **電腦** 下的某台電腦以開啟它的頁面。兩個開關決定這裡對話中的代理程式可以對它做什麼：

| 開關 | 作用 |
| --- | --- |
| **代理程式** | 將它的代理程式加入專案，或將對話交給其中一個。任務會在那台電腦上執行，而它的代理程式想做的任何事都會先在那裡詢問你。 |
| **指令** | 這裡對話中的代理程式可以在它上面執行指令，並依對話的權限模式詢問。 |

開關呈灰色表示另一台電腦尚未允許：請在那台電腦上為這台 Mac 開啟 **代理程式** 或 **終端機**。關閉 **指令** 也會停止透過同一台電腦的 SSH 主機執行指令。

若要讓另一台電腦的代理程式直接使用這台 Mac 的螢幕和瀏覽器，請在這裡該電腦的頁面上開啟 **Agent 控制**。請參閱[你的其他電腦](/zh-hant/integrations/other-computers)。

## 變更主機的設定

在 **SSH 主機** 下，點擊某台主機以開啟它的頁面：

| 設定 | 作用 |
| --- | --- |
| **代理程式可以使用** | 關閉後，主機仍會留在清單中，但不會出現在任何對話裡。 |
| **每條指令前** | **跟隨對話** 或 **每次詢問**。 |
| **複製檔案** | 讓代理程式以 `scp` 在主機之間複製檔案。 |
| **起始目錄** | 指令開始執行的資料夾。留空表示登入資料夾。 |

頁面的 **⋯** 選單中有 **測試連線** 和 **移除主機…**。移除主機只會讓 Enconvo 忘記它。你的 `~/.ssh/config` 和伺服器都維持原樣。

## 查看誰可以存取這台 Mac

**設定 → 連線** 中的 **誰可以存取這台 Mac** 會顯示有多少支手機和電腦可以存取這台 Mac。

若要一次切斷所有存取，請點擊 **停止所有存取** 並確認。你的手機和其他電腦就無法再存取你的任何 Mac，而它們在那裡執行的內容也會停止。想要恢復時，點擊 **重新開啟存取**。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 測試無法連到區域網路中的伺服器 | macOS 因區域網路權限而攔住了連線。點擊 **允許 Enconvo 存取區域網路**，或在 **系統設定 → 隱私權與安全性 → 區域網路** 中開啟 Enconvo，然後再試一次。 |
| 測試顯示伺服器拒絕了你的金鑰 | 檢查 `~/.ssh/config` 中該主機的 `IdentityFile`，或用 `ssh-add` 加入金鑰。 |
| 伺服器回應了不同的主機金鑰 | 它可能被重建了，或是你與它之間有東西介入。如果是被重建，請在「終端機」中用 `ssh-keygen -R` 加上伺服器位址移除舊金鑰，然後再試一次。 |
| 主機沒有出現在 `@` 選單中 | 開啟該主機的頁面並開啟 **代理程式可以使用**。 |
| 密碼或通行密語錯誤 | 輸入框會再次開啟並說明未成功。請重新輸入。 |
| 一台電腦有兩台 SSH 主機 | 第一台主機會維持與該電腦連結，其頁面也會顯示那一台。移除它後，就會連結到另一台。 |
| `~/.ssh/config` 中沒有主機 | 在 **加入主機** 中以 `user@host` 輸入位址。 |

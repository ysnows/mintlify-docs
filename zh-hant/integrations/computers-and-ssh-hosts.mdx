你的代理程式不只可以在這台 Mac 上工作。加入你能透過 SSH 登入的伺服器，在對話中提及它並提出需求，就像對自己這台 Mac 提問一樣：代理程式會在那台伺服器上執行指令，並把結果回傳到這裡。伺服器上不需要安裝任何軟體。你執行 Enconvo 的其他電腦也能以相同方式配對使用。

下方影片示範如何從你的 SSH 設定加入一台 SSH 主機、請代理程式讀取其上的日誌，並示範如何查看誰能連線到這台 Mac。

## 開始之前

- 你需要一台能從這台 Mac 透過 `ssh` 登入的伺服器：可以是 `~/.ssh/config` 中列出的主機，或能以 `user@host` 格式輸入的位址。Enconvo 會使用這台 Mac 自己的 `ssh` 與金鑰。如果伺服器要求輸入密碼或金鑰通行密碼，`ssh` 會透過 Enconvo 向你詢問，而 Enconvo 不會保存任何密碼。
- 若伺服器位於區域網路內，請在 **系統設定 → 隱私權與安全性 → 區域網路** 中允許 Enconvo。

## 連線頁面的清單

開啟 **設定 → 連線**。頁面中有三個清單：

| 清單 | 包含內容 |
| --- | --- |
| **手機** | 與這台 Mac 配對的 iPhone 與 Android App。請參閱 [iPhone App](/zh-hant/integrations/iphone-app)。 |
| **電腦** | 你執行 Enconvo 並與這台 Mac 配對的其他電腦。每台電腦會列出一筆，並顯示其控制方式。點選 **配對電腦** 即可新增。請參閱[你的其他電腦](/zh-hant/integrations/other-computers)。 |
| **SSH 主機** | 代理程式透過 SSH 連線的伺服器，遠端不需要安裝任何程式。 |

點選任何一支手機或一台電腦即可開啟它的專屬頁面，查看它能在這台 Mac 上執行哪些操作。

你也可以從聊天視窗新增主機、配對電腦或配對手機：點選側邊欄底部的裝置切換器，然後選擇 **新增裝置**。

## 加入 SSH 主機

1. 開啟 **設定 → 連線**，在 **SSH 主機** 下方點選 **加入主機**。
2. 清單會列出 `~/.ssh/config` 中的主機。挑選其中一個（例如 `build-server`），或直接輸入 `user@host`（或 `user@host:port`）。
3. 點選 **連線**。Enconvo 會測試連線：連上該主機、檢查主機金鑰、登入並執行一個指令。
4. 在 **每次執行指令前** 下方，選擇代理程式在那台主機執行指令前要如何詢問：
   - **跟隨對話**：依照該對話的權限模式詢問。請參閱[核准操作](/zh-hant/ai/agents)。
   - **一律詢問**：每次執行指令前都先詢問。
5. 點選 **加入主機**。

現在這台主機就會出現在 **SSH 主機** 清單，以及每個對話的 `@` 選單中。

Enconvo 第一次看到某台伺服器的主機金鑰時，請向該伺服器的管理者核對金鑰指紋，然後點選 **信任並連線**。如果是 Linux 伺服器，對話方塊還會提供 **同時在該處安裝 Enconvo** 的選項，讓你可以將該伺服器配對為一般電腦；保持關閉則不會在遠端安裝任何東西。

## 請代理程式在主機上工作

1. 在對話中輸入 `@` 及主機名稱的開頭。你的電腦與 SSH 主機會列在 **電腦** 分類下。
2. 挑選該主機。它會以標籤形式加入你的訊息中。
3. 說明你想在那台主機上完成什麼任務並送出。例如：

   ```text
   @build-server What errors are in ~/app/logs/app.log? Just read it, don't change anything.
   ```

代理程式會透過 SSH 在該主機上執行指令，並依照你為該主機設定的規則事先詢問。每個指令步驟都會標明它是在哪一台主機上執行的，結果則會回到這個對話中。

想查看它實際執行了什麼，請點選回答上方的 **工作時間**，展開後即可看到每一個執行的指令。

你也可以用同樣的方式提及已配對的電腦。代理程式會將任務交給那台電腦自己的代理程式處理，或是在那台電腦允許這台 Mac 使用終端機時直接在該電腦上執行指令。

在對話中，於主機或其他電腦上執行的指令步驟會顯示 **執行了指令**，並標出對應的機器名稱。

## 讓代理程式在配對的電腦上工作

在 **設定 → 連線** 中，點選 **電腦** 底下的任一台電腦以開啟其專屬頁面。兩個開關決定這台 Mac 對話中的代理程式能對它做什麼：

| 開關 | 作用 |
| --- | --- |
| **代理程式** | 將該電腦的代理程式加入專案，或將對話轉交給它。任務會在那台電腦上執行，其代理程式想執行的動作也會先在當地向你確認。 |
| **指令** | 這台 Mac 對話中的代理程式可以在該電腦上執行指令，並依照對話的權限模式詢問確認。 |

如果某個開關呈現灰色停用狀態，代表另一台電腦尚未開放權限：請到那台電腦上為這台 Mac 開啟 **代理程式** 或 **終端機**。關閉 **指令** 也會一併停止透過 SSH 主機在該電腦上執行指令。

若想讓另一台電腦的代理程式直接操作這台 Mac 的螢幕與瀏覽器，請在本機該電腦的頁面開啟 **代理程式控制**。請參閱[你的其他電腦](/zh-hant/integrations/other-computers)。

## 變更主機設定

在 **SSH 主機** 下方點選任一主機以開啟其頁面：

| 設定 | 作用 |
| --- | --- |
| **代理程式可使用** | 關閉後主機仍留在清單中，但不會出現在任何對話裡。 |
| **每次執行指令前** | **跟隨對話** 或 **一律詢問**。 |
| **複製檔案** | 允許代理程式透過 `scp` 與該主機互相複製檔案。 |
| **起始目錄** | 指令啟動時所在的資料夾。留空代表登入後預設的資料夾。 |

該頁面的 **⋯** 選單包含 **測試連線** 與 **移除主機…**。移除主機會從 Enconvo 中忘記這台主機，你的 `~/.ssh/config` 與遠端伺服器本身都不會受到影響。

## 查看誰可以連上這台 Mac

**設定 → 連線** 中的 **誰能存取這台 Mac** 會顯示目前有多少支手機與多少台電腦可以連線到這台 Mac。

如果想一次切斷所有連線，請點選 **停止所有存取** 並確認。你的手機與其他電腦都將無法再連上你的任何 Mac，上面正在進行的遠端任務也會停止。需要恢復連線時，點選 **重新開啟存取** 即可。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 測試時無法連上區域網路內的伺服器 | macOS 正在等待你授予區域網路權限。請點選 **允許 Enconvo 存取區域網路**，或前往 **系統設定 → 隱私權與安全性 → 區域網路** 開啟 Enconvo，然後再試一次。 |
| 測試顯示伺服器拒絕你的金鑰 | 檢查 `~/.ssh/config` 中該主機的 `IdentityFile` 設定，或使用 `ssh-add` 加入金鑰。 |
| 伺服器回傳了不同的主機金鑰 | 該伺服器可能已重建，或者你與伺服器之間存在攔截。若確認伺服器已重建，請在終端機執行 `ssh-keygen -R` 加上伺服器位址移除舊金鑰，然後再試一次。 |
| `@` 選單裡找不到這台主機 | 開啟該主機的頁面並打開 **代理程式可使用**。 |
| 密碼或金鑰通行密碼錯誤 | 輸入框會重新開啟並提示驗證失敗，請重新輸入。 |
| 同一台電腦有兩個 SSH 主機設定 | 第一個主機會持續與該電腦關聯，且電腦頁面會顯示該主機。移除它之後便會改為關聯另一個。 |
| `~/.ssh/config` 裡沒有任何主機 | 在 **加入主機** 中直接以 `user@host` 格式輸入位址。 |

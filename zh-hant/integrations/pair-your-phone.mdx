---
title: "配對手機"
description: "將 Enconvo iPhone 或 Android App 與 Mac、Windows PC、Linux 桌面電腦或純終端機 Linux 伺服器配對。"
---

手機上的 Enconvo App 可分別與你的每一台電腦配對，讓這些電腦上的專案與對話都能在手機上使用。你從手機開啟的對話會在對應的電腦上繼續執行，並可直接使用該電腦的檔案、應用程式與代理程式。手機會透過 Enconvo 中繼服務連線至電腦，所有訊息皆經過端對端加密。當手機與電腦位於同一個區域網路時，App 會改為直接連線，因此在家中或辦公室時的連線與回覆速度都會更快。

每台電腦都需要單獨與手機配對。將兩台電腦彼此配對（例如將 Linux 筆電與你的 Mac 配對）並不會將其中任何一台加入到手機中：請將手機分別與每一台你想從手機使用的電腦進行配對。

## 開始之前

- **取得 App**：iPhone 請使用 [TestFlight](https://testflight.apple.com/join/MJQuEN28)；Android 請從 Google Play 下載或使用 APK。電腦上**設定 → 連線**中的**取得手機 App** 提供各自的下載條碼；Mobile Companion 外掛程式中的**取得手機 App** 按鈕也能開啟下載頁面。
- **使用同一個帳號**：在手機 App 與電腦上登入同一個 Enconvo 帳號。只有登入同一帳號的手機才能配對。免費帳號同樣可以進行配對，並從手機使用電腦上的對話與遠端螢幕。
- **保持電腦開機且 Enconvo 執行中**：只有當該電腦上的 Enconvo 處於執行狀態時，手機才能連線到它。

## Mac、Windows 或 Linux 桌面電腦

這三個平台的步驟完全相同。

<Steps>
  <Step title="在電腦上顯示配對碼">
    點擊側邊欄底部的裝置切換器，接著選擇**加入裝置 → 配對手機**；或開啟**設定 → 連線**並選擇**顯示配對碼**。畫面上會出現一個 QR Code，僅限使用一次，有效期限為五分鐘。
  </Step>
  <Step title="使用手機掃描">
    在 Enconvo App 中開啟**遠端**，點擊**配對電腦**，並將相機對準 QR Code。你也可以直接使用 iPhone 相機、Android 相機或 Google Lens 掃描：條碼會開啟 Enconvo，接著在 App 中確認該電腦即可。若尚未安裝 App，條碼對應的連結會引導你先完成安裝再進行配對。
  </Step>
  <Step title="從手機使用電腦">
    手機會在片刻內完成配對並顯示該電腦。若配對了多台電腦，可在**遠端**頁面中切換不同電腦。
  </Step>
</Steps>

若配對碼已過期，請選擇**顯示新的配對碼**並重新掃描。

## 純終端機介面的 Linux 伺服器

伺服器沒有圖形視窗可以顯示條碼，因此會透過命令列印出。此功能需要 Enconvo 2.5.15 Beta 1 或更新版本。請先依照[在伺服器上安裝](/zh-hant/getting-started/linux)完成安裝。

<Steps>
  <Step title="登入伺服器">
    ```bash
    enconvo login
    ```
    前往 `enconvo.com/device` 並核准畫面上印出的驗證碼。
  </Step>
  <Step title="保持 Enconvo 執行">
    ```bash
    enconvo service install
    ```
    只有當該伺服器上的 Enconvo 處於執行狀態時，手機才能連線到它。
  </Step>
  <Step title="印出配對碼">
    ```bash
    enconvo companion pair --phone
    ```
    終端機會在畫面中繪製一個 QR Code，下方附帶一組連結並標示有效期限。此配對碼僅限使用一次，有效期限為五分鐘。
  </Step>
  <Step title="掃描條碼或開啟連結">
    使用手機相機掃描 QR Code，或在手機上開啟該連結。在 Enconvo App 中確認後，該伺服器就會顯示在手機上。
  </Step>
</Steps>

- **透過 SSH 操作**：QR Code 會直接繪製在你自己的終端機中，因此透過 SSH 連線時同樣適用。如果條碼發生折行，請加寬視窗或改為開啟下方的連結。
- **登入權杖**：在你自己的終端機直接輸入指令時，產生的配對碼也會同時登入手機 App，因此請僅將它傳送給自己的手機。若是透過管線導向、儲存輸出，或是由代理程式執行的指令，則只會印出不會自動登入 App 的連結：請先在手機 App 登入同一帳號再進行配對。
- **已過期**：重新執行 `enconvo companion pair --phone` 即可。

## 管理已配對的手機

每台電腦的**設定 → 連線**都會列出已與它配對的手機。

| 操作 | 步驟 |
|---|---|
| 配對另一支手機 | 顯示新的配對碼並使用該手機掃描。每台電腦最多可配對 10 支手機。 |
| 重新命名手機 | 點擊該手機，再點擊名稱旁的**重新命名手機**。 |
| 移除手機 | 在該手機旁選擇**移除**。該手機將無法再連線至此電腦。 |
| 全部重新開始 | 選擇**重設連線**。所有已配對的手機都會被移除並必須重新配對。 |

## 疑難排解

| 問題 | 解決方式 |
|---|---|
| 某台電腦沒有出現在手機上 | 請將手機直接與該台電腦配對。將該電腦與另一台電腦配對並不會自動把它加入手機。 |
| **此代碼已過期** | 顯示新的配對碼，或重新執行指令，並在五分鐘內完成掃描。 |
| **登入後即可配對手機** | 請先在電腦上登入 Enconvo。在伺服器上請執行 `enconvo login`。 |
| 伺服器顯示尚未登入 | 執行 `enconvo login`，然後再次執行 `enconvo companion pair --phone`。 |
| 手機顯示伺服器離線 | 確認伺服器上的 Enconvo 正在執行：`enconvo service install`；若登出後服務停止，請執行 `sudo loginctl enable-linger "$USER"`。 |

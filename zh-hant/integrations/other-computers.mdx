---
title: "你的其他電腦"
description: "配對你執行 Enconvo 的電腦，然後從另一台電腦使用其對話、終端機、螢幕與代理程式，工作則持續在原電腦上執行。"
---

將兩台執行 Enconvo 的電腦配對後，你就能從其中一台操作另一台。你在已配對電腦上開啟的對話會在那台電腦上執行，使用那台電腦的檔案、金鑰、模型與代理程式，即使你離開也會持續執行。你還可以觀看或控制它的螢幕、傳送檔案給它，並讓這裡的代理程式把工作交給它。

若要連到沒有執行 Enconvo 的伺服器，請改為將它加入為 SSH 主機。請參閱[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

## 開始之前

- 在兩台電腦上都安裝 Enconvo，並登入同一個 Enconvo 帳號。
- 讓兩台電腦都保持上線並執行 Enconvo。電腦只有在 Enconvo 於該處執行時才能被連到。
- 在免費方案中，你可以將一台電腦與另一台配對。帳號的裝置席位只會留在兩者之一：你可以從另一台操作那一台，而從那一台則可以讀取另一台電腦的對話並傳送檔案給它。

## 配對電腦

配對時一定會顯示哪一台電腦負責控制、哪一台被控制。你可以從任何一端開始。

<Steps>
  <Step title="開始配對">
    點擊聊天視窗側邊欄底部的裝置切換器，然後點擊 **加入裝置 → 配對電腦**。或者開啟 **設定 → 連線**，在 **電腦** 下點擊 **配對電腦**。
  </Step>
  <Step title="挑選要控制的電腦">
    你其他已上線的電腦會顯示在清單中。挑選你想從這台控制的電腦，並選擇它可以存取的範圍。若要雙向控制，也請開啟讓它反過來控制這台電腦的選項。
  </Step>
  <Step title="在另一台電腦上允許">
    另一台電腦的動態島會顯示帶有一組數字的請求。確認兩台電腦顯示相同的數字，然後點擊 **允許**。
  </Step>
  <Step title="設定開啟方式">
    一份簡短的指南會詢問該電腦要在聊天視窗中開啟，還是在它自己的視窗中開啟，並提供可從任何 App 叫出它的快速鍵，同時說明你可以在它上面做什麼。隨時都可以從該電腦的 **⋯** 選單 → **使用指南** 再次開啟指南。
  </Step>
</Steps>

當電腦彼此看不到對方時，請使用 **透過連結配對**：在你想控制的電腦上複製連結，然後貼到你目前使用的電腦上。連結只能使用一次，有效期限為五分鐘。

另一台電腦與你的電腦配對後，會有一則通知說明它在這裡可以使用什麼。點擊 **變更** 即可調整。

## 選擇電腦可以存取的範圍

在你允許配對時，以及之後在 **設定 → 連線** 中該電腦的頁面上，你可以選擇另一台電腦能在這裡控制什麼：

| 選項 | 另一台電腦在這裡可以做什麼 |
| --- | --- |
| **聊天** | 在這裡開啟對話並讓它們持續執行。 |
| **對話和工具** | 還包含 **終端機**、**螢幕** 和 **檔案**，讓它的代理程式可以在這裡執行指令。 |
| **全部** | 它的代理程式還可以在這裡開始對話並使用這個螢幕。 |

選擇 **每個開關** 即可逐一設定：

| 開關 | 允許的內容 |
| --- | --- |
| **聊天** | 在這裡開啟對話並讓它們持續執行。 |
| **終端機** | 開啟 shell，並讓它的代理程式執行指令。 |
| **螢幕** | 查看並控制這個螢幕。 |
| **檔案** | 傳送檔案到這裡的「下載項目」。 |
| **代理程式** | 讓它的代理程式在這裡開始對話。在你開啟之前都是關閉的。 |
| **Agent 控制** | 讓它的代理程式使用這個螢幕和瀏覽器。它們使用時你會看到，也可以讓它們停止。在你開啟之前都是關閉的。 |

## 開啟電腦的對話

聊天視窗的側邊欄一次只列出一台電腦。位於底部的裝置切換器可在這台電腦與已配對的電腦之間切換，顯示其他電腦上有什麼在等你，並可將其中任何一台開啟在它自己的視窗中。

- 每台電腦的清單會顯示它的對話與專案，以及哪些正在執行、哪些需要你，並可就地開啟。
- 每台電腦都有自己的顏色。從該電腦的 **⋯** 選單 → **顏色** 變更。
- 由另一台電腦的代理程式開始的對話會帶有標記，聊天視窗的搜尋也能找到那台電腦的對話。
- 當另一台電腦上的回覆準備好，或它的代理程式需要你回答時，Enconvo 會通知你。

若要在另一台電腦上開始新的對話，請使用新對話訊息框中的 **執行於** 標籤。你輸入的內容會一併帶過去。按 **⌃1** 到 **⌃9** 可在電腦之間切換。

另一台電腦上的簡報、設計和儀表板會以唯讀方式開啟，另一台電腦的對話中也不提供 **朗讀**。

### 在獨立視窗中

在電腦的 **⋯** 選單中選擇 **在獨立視窗中開啟**，它的對話就會在一個有自己 Dock 圖示的視窗中開啟，圖示採用該電腦的顏色。在同一個選單中開啟 **保留在 Dock 中**，即可將圖示留在那裡，以便稍後開啟。

若要將此設為預設，請開啟 **設定 → 連線**，點擊該電腦，並在 **聊天** 下選擇 **聊天視窗** 或 **獨立視窗**。**快捷鍵** 可設定從任何 App 叫出該電腦的按鍵。

### 當電腦離線時

離線電腦的對話仍可閱讀。點擊 **在這台 Mac 上繼續**，即可帶著螢幕上的內容在這裡開始新的對話，或點擊 **恢復時通知我**。

## 使用它的螢幕

電腦的頁面會顯示它的螢幕。你可以只是觀看，或接手控制，用你自己的滑鼠和鍵盤操作它。

點擊全螢幕按鈕，或按 **⌃⌥F**（在 Mac 上 **⌃⌘F** 也有效），即可讓畫面佔滿整個顯示器。將指標移到上方邊緣即可叫回控制項。按相同的按鍵即可離開，若你只是觀看則可按 **Esc**。旁邊的 **填滿顯示區域** 按鈕會縮放畫面以填滿顯示區域而不留黑邊，並裁掉放不下的邊緣。

在你控制另一台電腦時，它所複製的內容會進入你的剪貼簿。螢幕上有一行文字說明如何停止控制它。

## 傳送檔案

在該電腦的頁面上，點擊 **傳送檔案**。檔案會放到另一台電腦的 **下載項目 → Enconvo** 中，絕不會取代那裡已有的檔案，且在連線中斷後會繼續傳送。

你附加在另一台電腦對話中的檔案也會一併傳過去，每個檔案最大 2 GB，並顯示進度列。

## 將工作交給另一台電腦

當某台電腦的 **代理程式** 為開啟狀態時，這裡的代理程式可以在那裡開始對話並讀取答案。在對話中用 `@` 提及該電腦，或請代理程式使用它。代理程式想在那裡做的任何事，都會先在那台電腦上詢問你，而對話也會說明另一台電腦何時在等待核准，以及是為了什麼。

當 **Agent 控制** 為開啟狀態時，另一台電腦的代理程式可以直接使用這台 Mac 的螢幕和瀏覽器，例如立即重新測試某項變更。這裡會有一個覆蓋層標示誰正在控制，並讓你接手或停止。

當你的代理程式使用另一台電腦時，對話頂端的橫條和訊息框上方的膠囊會顯示來自那裡的最新螢幕截圖，並附有 **停止** 按鈕。完成的執行會以單一卡片顯示它的步驟和螢幕截圖。

關於在另一台電腦上執行指令，請參閱[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

## 移除電腦

在 **設定 → 連線** 中，點擊該電腦並選擇 **移除**，或在側邊欄中該電腦的 **⋯** 選單中選擇 **取消配對…**。它的對話會留在那台電腦上。若要再次使用，請重新配對。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 另一台電腦不在配對清單中 | 確認它已上線、正在執行 Enconvo，並登入同一個帳號。或使用 **透過連結配對**。 |
| 配對請求沒有顯示在另一台電腦上 | 到另一台電腦的動態島上找找看。如果它已結束或失去連線，請重新開始配對。 |
| 電腦頁面上的某個開關呈灰色 | 另一台電腦尚未允許。請在那台電腦上為這台電腦開啟。 |
| 螢幕或對話顯示無法連到該電腦 | 確認電腦處於喚醒狀態且 Enconvo 在那裡執行。使用 **恢復時通知我** 以便在它回來時收到通知。 |

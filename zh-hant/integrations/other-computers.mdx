---

將兩台執行 Enconvo 的電腦配對後，你就可以從其中一台操作另一台。你在已配對電腦上開啟的聊天會在那台電腦上執行，使用它的檔案、金鑰、模型和代理程式，即使你切走去做別的事，任務也會繼續執行。你還可以觀看或控制它的螢幕、傳送檔案給它，並讓目前這台電腦上的代理程式把工作交給它處理。

要連線到沒有執行 Enconvo 的伺服器，請改為將它新增為 SSH 主機。參閱[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

## 開始之前

- 在兩台電腦上都安裝 Enconvo，並登入同一個 Enconvo 帳號。
- 保持兩台電腦都上線且 Enconvo 處於執行狀態。只有對方電腦上執行著 Enconvo 時才能連線。
- 在 Free 方案中，你可以將一台電腦與另一台配對。帳號的裝置席位留在其中一台上：你可以從另一台操作這台電腦，而在它上面可以查看另一台電腦的聊天並向其傳送檔案。

## 配對電腦

配對時會明確顯示哪台電腦負責控制、哪台被控制。你可以從任一端發起配對。

<Steps>
  <Step title="開始配對">
    點擊聊天視窗側邊欄底部的裝置切換器，然後選擇 **加入裝置 → 配對電腦**。或者開啟 **設定 → 連線**，在 **電腦** 下點擊 **配對電腦**。
  </Step>
  <Step title="選擇要控制的電腦">
    你的其他上線電腦會顯示在列表中。挑選你想從目前這台電腦控制的那一台，並選擇它允許存取的內容。如果想雙向控制，也可以同時開啟允許對方反過來控制這台電腦的選項。
  </Step>
  <Step title="在另一台電腦上允許">
    另一台電腦的動態島會顯示帶有數字的配對請求。確認兩台電腦顯示的數字一致，然後點擊 **允許**。
  </Step>
  <Step title="設定開啟方式">
    簡短的使用指南會詢問這台電腦是在聊天視窗中開啟還是在獨立視窗中開啟，並提供一個可從任意 App 呼叫它的快速鍵，同時介紹你可以在它上面做什麼。你可以隨時從該電腦的 **⋯** 選單 → **使用指南** 重新開啟這個指南。
  </Step>
</Steps>

當兩台電腦無法互相發現時，請使用 **透過連結配對**：在你想控制的電腦上複製連結，然後貼到你目前使用的電腦上。連結僅限使用一次，有效期限為五分鐘。

當另一台電腦與你的電腦配對後，畫面上的提示會說明它能在這裡使用哪些功能。點擊 **變更** 即可調整。

## 選擇電腦可存取的範圍

在你允許配對時，以及之後在 **設定 → 連線** 中該電腦的頁面上，都可以選擇另一台電腦能在這裡控制哪些內容：

| 選項 | 另一台電腦可以在這裡做什麼 |
| --- | --- |
| **對話** | 在這裡開啟聊天並讓它們持續執行。 |
| **對話和工具** | 還可以使用 **終端機**、**螢幕** 和 **檔案**，讓它的代理程式可以在這裡執行指令。 |
| **全部** | 它的代理程式還可以在這裡啟動聊天並使用這個螢幕。 |

選擇 **每個開關** 可以逐項單獨設定：

| 開關 | 允許的內容 |
| --- | --- |
| **對話** | 在這裡開啟聊天並讓它們持續執行。 |
| **終端機** | 開啟 shell，並允許它的代理程式執行指令。 |
| **螢幕** | 查看此螢幕並進行控制。 |
| **檔案** | 將檔案傳送到這裡的「下載項目」資料夾。 |
| **代理程式** | 允許它的代理程式在這裡啟動聊天。預設關閉，直到你手動開啟。 |
| **Agent 控制** | 允許它的代理程式直接使用此螢幕和瀏覽器。使用時會顯示提示，你也可以隨時停止。預設關閉，直到你手動開啟。 |

## 開啟另一台電腦的聊天

聊天視窗側邊欄一次只列出某一台電腦的內容。底部的裝置切換器可以在這台電腦與已配對電腦之間切換，顯示其他電腦上有哪些等待你處理的事項，也可以在獨立視窗中開啟其中任一台。

- 每台電腦的列表都會顯示它的聊天和專案，包括正在執行的內容和需要你處理的事項，並可就地開啟。
- 每台電腦都有自己的顏色。可以在該電腦的 **⋯** 選單 → **顏色** 中更改。
- 由另一台電腦的代理程式啟動的聊天會帶有標記，聊天視窗的搜尋也能找到那台電腦的聊天。
- 當另一台電腦上的回覆已就緒，或它的代理程式需要你回答時，Enconvo 會通知你。

要在另一台電腦上開始新聊天，請使用新聊天訊息框中的 **執行於** 標籤。你已經輸入的內容會一併帶過去。按 **⌃1** 到 **⌃9** 可以在電腦之間切換。

另一台電腦上的簡報、設計和儀表板會以唯讀方式開啟，且另一台電腦的聊天中不提供 **朗讀** 功能。

### 在獨立視窗中開啟

在該電腦的 **⋯** 選單中選擇 **在獨立視窗中開啟**，它的聊天就會在一個帶有對應顏色 Dock 圖示的獨立視窗中開啟。同一選單中的 **保留在 Dock 中** 可以把該圖示留在 Dock 中，方便日後直接開啟。

要將其設為預設行為，請開啟 **設定 → 連線**，點擊該電腦，在 **對話** 下選擇 **聊天視窗** 或 **獨立視窗**。**快速鍵** 用於設定從任意 App 呼叫該電腦的按鍵。

### 當電腦離線時

離線電腦的聊天記錄仍然可以閱讀。點擊 **在這台 Mac 上繼續**，即可帶著螢幕上目前的內容在這裡開始一個新聊天；或選擇 **恢復時通知我**。

## 使用對方的螢幕

電腦頁面會顯示它的螢幕畫面。你可以只觀看，也可以接管控制，用自己的滑鼠和鍵盤來操作它。

點擊全螢幕按鈕，或按 **⌃⌥F**（在 Mac 上也可以用 **⌃⌘F**），即可讓畫面鋪滿整個顯示器。將游標移到螢幕頂端邊緣即可重新顯示控制列。按同樣的快速鍵即可離開全螢幕，僅觀看時也可以按 **Esc** 離開。旁邊的 **填滿顯示區域** 按鈕會將畫面縮放以填滿檢視區域、不留黑邊，並裁切超出檢視區域的部分邊緣。

當你控制另一台電腦時，對方複製的內容會同步到你的剪貼簿。螢幕上的一行提示會告訴你如何停止控制。

## 傳送檔案

在該電腦的頁面上，點擊 **傳送檔案**。檔案會儲存到另一台電腦的 **下載項目 → Enconvo** 中，絕不會覆蓋已有檔案，且在連線中斷後支援續傳。

你在另一台電腦的聊天中附加的檔案也會一併傳送過去，單一檔案上限為 2 GB，並帶有進度列。

## 把工作交給另一台電腦

為某台電腦開啟 **代理程式** 後，你這裡的代理程式就可以在那裡啟動聊天並讀取回答。在聊天中用 `@` 提及該電腦，或讓代理程式使用它即可。代理程式想在那邊執行任何操作時，都會先在那台電腦上徵求你的同意，並且聊天中會顯示對方電腦正在等待核准以及核准的具體內容。

開啟 **Agent 控制** 後，另一台電腦上的代理程式可以直接使用這台 Mac 的螢幕和瀏覽器，例如立即重新測試某項改動。螢幕上的浮層會標明目前由誰在控制，並讓你可以隨時接管或停止它。

當你的代理程式在使用另一台電腦時，聊天頂端的一條橫列和訊息框上方的一個膠囊按鈕會顯示對方的最新截圖，並附帶 **停止** 按鈕。執行結束後，整個過程會彙整為一張卡片，展示其中的步驟和截圖。

關於在另一台電腦上執行指令，參閱[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

## 移除電腦

在 **設定 → 連線** 中，點擊該電腦並選擇 **移除**，或在側邊欄中開啟它的 **⋯** 選單選擇 **取消配對…**。它的聊天會保留在那台電腦上。如需再次使用，重新配對即可。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 配對列表中沒有另一台電腦 | 檢查對方是否上線、正在執行 Enconvo，且登入了同一個帳號。或者改用 **透過連結配對**。 |
| 另一台電腦上沒有出現配對請求 | 查看另一台電腦的動態島。如果它已結束或斷開了連線，請重新發起配對。 |
| 電腦頁面上的某個開關呈現暗色 | 對方電腦尚未允許該權限。請在對方電腦上為本機開啟該開關。 |
| 螢幕或聊天提示無法連線到該電腦 | 檢查對方電腦是否處於喚醒狀態且正在執行 Enconvo。使用 **恢復時通知我** 可在它上線時收到提醒。 |

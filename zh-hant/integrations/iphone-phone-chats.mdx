手機聊天是 iPhone 應用程式專屬的對話。它們直接在手機上運行，而非你的 Mac 上，因此不需配對 Mac 就能使用。每個手機聊天會透過 Enconvo Cloud 點數、你自己的 API 金鑰，或你在 iPhone 上登入的方案來呼叫模型。手機聊天記錄與個人指示會透過你的 Enconvo 帳號同步。

若要接續在 Mac 上運行的對話，請參閱 [iPhone 應用程式](/zh-hant/integrations/iphone-app)。

## 選擇預設模型

1. 在 iPhone 上，開啟**設定 → AI 模型**。
2. 點一下**預設模型**並挑選一個模型。新聊天都會使用它開始。
3. 若要更改單一聊天的模型，請使用該聊天中的模型選擇器。

當你的 Mac 上有該服務供應商時，Mac 上的 Enconvo 也會使用相同的模型開始對話。如果 Mac 的模型在 iPhone 上無法使用，頁面會在**預設模型**下方說明，並建議要新增或登入哪個項目。

## 新增金鑰或服務供應商

**AI 模型**會列出 Enconvo Cloud 以及所有可以在手機上使用的服務供應商，包含 PipeLLM。

1. 點一下某個服務供應商，接著點一下**新增 API 金鑰**，貼上你在該服務供應商網站建立的金鑰。
2. 若要新增不在列表中的服務供應商，點一下**新增服務供應商**並選擇一個服務供應商、**相容 OpenAI** 或**相容 Anthropic**。相容的服務供應商需要支援 OpenAI Chat Completions 或 Responses API，或 Anthropic Messages API 的伺服器網址。
3. 如果某個服務供應商沒有列出你需要的模型，請在該頁面點一下**依 ID 新增模型**。

金鑰會保存在你的 iCloud 鑰匙圈中，且只會傳送給所屬的服務供應商。

## 使用訂閱方案登入

有五個服務供應商讓手機聊天可以直接使用你已付費的方案，不需 API 金鑰也不消耗 Cloud 點數：

| 服務供應商 | 方案 | 按鈕 |
| --- | --- | --- |
| OpenAI | ChatGPT | **使用 ChatGPT 登入** |
| xAI | Grok | **使用 Grok 登入** |
| Mistral | Le Chat | **使用 Mistral 登入** |
| GitHub Copilot | Copilot | **使用 GitHub 登入** |
| Antigravity | Antigravity (Google) | **使用 Google 登入** |

<Steps>
  <Step title="開啟服務供應商">
    在**設定 → AI 模型**中點一下該服務供應商。對於 OpenAI、xAI 與 Mistral，請在**身分驗證**下方選擇方案卡片。另一張卡片是 **API 金鑰**，標有**使用中**的則是手機聊天目前使用的驗證方式。
  </Step>
  <Step title="登入">
    點一下登入按鈕，並在開啟的頁面中完成登入。請使用擁有該方案的帳號。
  </Step>
  <Step title="確認結果">
    回到服務供應商頁面後，你會看見你的方案、你的帳號，以及方案包含多少個模型。選擇一個模型，或點一下**設為預設**來用它開始新聊天。
  </Step>
</Steps>

方案的登入狀態只會留在這支 iPhone 上，不會同步到 iCloud 或你的 Mac，Mac 上也保有自己的登入狀態。使用時套用該方案自身的用量限制。

### GitHub Copilot

點一下**使用 GitHub 登入**後，應用程式會顯示一組 GitHub 代碼。點擊**繼續**會複製該代碼並開啟 GitHub 頁面，請在頁面中貼上代碼並授權 Enconvo。GitHub 頁面開啟期間代碼會留在畫面上，方便你再次複製。

模型列表只會顯示你的 Copilot 方案可使用的模型。Copilot Free 提供的模型比付費方案少。

### Antigravity

每次登入前，應用程式都會顯示**登入 Antigravity 之前**的提示。Enconvo 使用 Antigravity 應用程式自己的 Google 用戶端進行登入，而 Google 可能會停權在 Antigravity 以外使用的 Antigravity 帳號。請使用你能承擔風險的帳號。點擊**同意**會繼續前往 Google 登入，點擊**取消**則維持原狀。

Antigravity 提供你方案中的 Gemini 與 Claude 模型，並各有 Antigravity 所支援的推理強度等級。

### ChatGPT 用量

OpenAI 的頁面會顯示你的 ChatGPT 方案在 5 小時與每週限額中還剩餘多少額度、各限額何時重置，以及方案何時續訂。在帳號選單中點一下**重新整理用量**即可更新。當某項限額用盡時，頁面會持續顯示該狀態直到重置為止。

### 登出

開啟該服務供應商，並在帳號選單中選擇**登出**。登出後，原本使用該方案的聊天需要改選其他模型。對於 Mistral，登入時建立的金鑰仍會留在你的 Mistral 工作區中。

## 離開應用程式後繼續回覆

使用 Enconvo Cloud 模型時，即使離開應用程式或鎖定手機，回覆仍可繼續產生。在訊息框的 **Cloud 工具**中開啟**在雲端執行**。使用你自己的金鑰的聊天則一律在手機上回應。

## 在電腦上繼續

將手機聊天移至已配對的電腦，就能用那台電腦的代理程式、檔案與工具繼續對話。即使回覆還在進行中也能這麼做。

1. 開啟聊天選單，或在側邊欄長按該聊天，選擇**在電腦上繼續**。選單會顯示預設前往的電腦名稱。
2. 選擇電腦與代理程式並確認。

該聊天就會移至那台電腦並在該處繼續。開啟分享聊天的連結時，系統也會詢問要在哪裡接續對話。

## 透過動作按鈕進行語音聊天

當透過動作按鈕啟動語音聊天時，動態島會詢問**要讓 Enconvo 看螢幕嗎？**選擇**只說話**，或選擇**看螢幕**讓 Enconvo 看見你正在閱讀的畫面。通話期間也可以透過通話控制列中的**看螢幕**按鈕隨時開始或停止分享螢幕畫面。

## 推理強度

當你選擇支援思考的模型時，選擇器會接著讓你挑選推理強度。你為某個模型挑選的推理強度會顯示在聊天標題列的服務供應商旁，並套用到使用該模型的所有聊天。方案頁面只會列出你方案提供的等級。

## 長對話

當長對話接近模型的上下文視窗上限時，相同的模型會自動摘要較早的訊息，作法與 Mac 上相同。聊天會保留每一則訊息，並在摘要開始處顯示**上下文已壓縮**標記。這項功能會常駐開啟。

## 疑難排解

| 你看到的畫面 | 處理方式 |
| --- | --- |
| **ChatGPT 登入未完成**（或 Grok、Mistral、GitHub Copilot、Antigravity） | 點一下**重新登入**並在開啟的頁面中完成登入。 |
| **你的方案未提供**某個模型 | 從方案列表中挑選另一個模型。Copilot Free 僅提供部分模型。 |
| **正在列出模型…**一直無法完成 | 檢查 iPhone 的網路連線，然後離開該服務供應商頁面並重新開啟。 |
| Mac 的預設模型不在 iPhone 上 | 依照**預設模型**下方的提示，新增該服務供應商的金鑰或登入其方案。 |

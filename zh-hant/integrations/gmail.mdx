---

Gmail 連接器會將你的電子郵件帶入 Enconvo。請代理程式尋找重要郵件、摘要討論串、草擬回覆或整理收件匣，它就會替你使用 Gmail。你只需透過 Enconvo 帳號連接一次 Google 帳號；不需要設定 Google Cloud 專案或 API 金鑰。

你在這裡連接的 Gmail 帳號也會顯示在[郵件](/zh-hant/integrations/email)中，你可以在那裡自己閱讀、整理並回覆。

## 開始之前

在 **設定 → 帳號** 中登入你的 Enconvo 帳號。連接器在每個方案中都免費，但需要有 Enconvo 帳號。

## 連接 Gmail

<Steps>
  <Step title="尋找 Gmail">
    開啟 **設定 → 外掛程式**，在 **Enconvo** 分頁中搜尋 **Gmail**。點擊它以開啟它的頁面。
  </Step>
  <Step title="連接">
    點擊 **連接**。你的瀏覽器會開啟 Google 的登入頁面。
  </Step>
  <Step title="允許存取">
    選擇你的 Google 帳號，並在允許之前檢視它要求的存取權限。Google 的同意畫面會顯示 Composio，也就是 Enconvo 的整合夥伴。
  </Step>
  <Step title="檢查結果">
    回到 Enconvo 後，你的位址會顯示在 **帳號** 下。點擊 **立即體驗**，或先向代理程式提出唯讀的問題，例如「摘要我今天收件匣中的未讀郵件。」
  </Step>
</Steps>

如果你在連接 Gmail 之前向代理程式詢問有關郵件的事，對話中會顯示一張卡片讓你連接。

## 代理程式可以做什麼

| 範圍 | 代理程式可以做什麼 |
| --- | --- |
| 讀取 | 搜尋郵件、開啟郵件和討論串、下載附件、列出標籤和草稿 |
| 整理 | 新增和移除標籤、封存、將郵件移到垃圾桶並還原 |
| 撰寫 | 建立並傳送草稿、傳送新郵件、回覆與轉寄 |

搜尋使用 Gmail 自己的搜尋語法，例如 `from:john@example.com`、`subject:invoice` 或 `after:2024/01/01`。

當代理程式撰寫或傳送郵件時，可以設定收件人、副本與密件副本，撰寫純文字或 HTML 內容，在現有討論串中回覆，並附加你 Mac 上的檔案：最多 10 個檔案，每個最大 95 MB。超出單封電子郵件可承載量（合計 25 MB）的檔案，會改為 file.enconvo.com 上的下載連結，任何持有連結的人都可以下載該檔案。

<Warning>
代理程式可以在不先詢問的情況下傳送郵件。若你想先檢視，請要求提供草稿。Enconvo 絕不會永久刪除郵件；刪除只是將它移到垃圾桶。
</Warning>

## 選項

帳號連接後，這些選項會顯示在 Gmail 的頁面上。

| 選項 | 作用 |
| --- | --- |
| **適用於所有聊天** | 開啟：代理程式可以在每個對話中使用 Gmail。關閉：代理程式只有在你用 `@` 提及它，或設定檔包含它時才會使用。 |
| **郵件提醒** | 在重要郵件到達時，於動態島和你的手機上提醒你。在你於 **排程工作 → 重要郵件** 中開啟之前，它是關閉的，其 **手機** 開關會將提醒傳送到已配對的 iPhone 或 Android 手機。開啟前 Enconvo 會先詢問，因為每封新郵件的寄件者、主旨和開頭會傳送到 Enconvo Cloud 以判斷其重要性。郵件絕不會儲存在那裡。 |
| **連接其他帳號** | 加入另一個 Gmail 位址，最多 5 個。 |

有多個帳號時，代理程式會從所有帳號讀取，並以預設帳號傳送或建立郵件，除非你指定另一個，例如「從我的工作信箱寄出」。在帳號的選單中選擇 **設為預設** 即可變更預設帳號。

## 在對話中使用 Gmail

連接 Gmail 之後，直接說出你的需求。代理程式會挑選合適的 Gmail 工具。

**搜尋與摘要：**
```
"Find all emails from John in the last week and summarize them"
```

**草擬回覆：**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**整理收件匣：**
```
"Archive all newsletters from the past month"
```

**管理標籤：**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**清除舊郵件（會移到垃圾桶）：**
```
"Delete all promotional emails older than 6 months"
```

## 工作流程的點子

Gmail 也適用於[工作流程](/zh-hant/workflows/introduction)和[排程任務](/zh-hant/workflows/scheduled-jobs)：

| 點子 | 作用 |
| --- | --- |
| **每日郵件摘要** | 搜尋未讀郵件、加以摘要，並呈現晨間簡報 |
| **自動分類** | 搜尋新郵件，並依內容套用標籤 |
| **追蹤提醒** | 找出等待回覆的郵件並建立提醒事項 |
| **報告產生** | 搜尋符合你條件的郵件，並彙整成摘要報告 |

## 隱私

- **透過 Enconvo Cloud 和 Composio**：你的郵件只為了完成你的要求而經過 Enconvo Cloud 和 Composio，且不會被儲存。
- **你的密碼留在 Google**：你在 Google 自己的頁面上登入，因此 Enconvo 絕不會看到你的 Google 密碼。
- **按需**：代理程式只在任務需要時才會讀取 Gmail。唯一的例外是 **郵件提醒**，在你開啟後，它會在每封新郵件到達時進行檢查。
- **可撤銷**：在 Gmail 的頁面上點擊 **中斷連線**，即可移除所有裝置上的存取權限。你也可以在你的 [Google 帳戶權限](https://myaccount.google.com/permissions)中移除存取權限。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **連接** 呈灰色 | 請先在 **設定 → 帳號** 中登入你的 Enconvo 帳號。 |
| Gmail 顯示 **重新連線** | 它的存取權限已失效。點擊 **重新連線** 並再次以 Google 登入。 |
| 代理程式不使用 Gmail | 確認 Gmail 已連接。如果 **適用於所有聊天** 為關閉，請在對話中用 `@` 提及 Gmail。 |
| 搜尋沒有找到任何結果 | 先嘗試較簡單的查詢，例如 `from:john`，並確認郵件位於已連接的帳號中。Gmail 搜尋的運作方式與 Gmail 網站相同。 |
| 附件沒有傳送 | 檢查檔案路徑是否正確，以及檔案是否存在於你的 Mac 上。 |

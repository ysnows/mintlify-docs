Enconvo iPhone App 會與你的 Mac 配對，因此 Mac 上的專案和對話都會出現在你的手機上。你從手機開啟的每個對話都會繼續在 Mac 上執行，使用它的檔案、App 和代理程式。本指南從頭到尾說明如何配對手機：登入、在 Mac 上顯示配對碼，並用 iPhone 掃描。

<Note>
iPhone App 目前為 Beta 版。請從 [TestFlight](https://testflight.apple.com/join/MJQuEN28) 安裝，或掃描 Mac 上 **設定 → 連線** 中 **取得手機 App** 下的 TestFlight 代碼。配對需要 Mac 上為 Enconvo 2.5.6 beta 或更新版本。TestFlight 上的 iPhone App 與 Google Play 上的 Android App，提供於美洲、歐洲、中東、日本、韓國和東南亞。Android APK 在任何地方都可以安裝。
</Note>

## 配對你的 iPhone

若要與 Windows 電腦、Linux 桌面，或只有終端機的 Linux 伺服器配對，請參閱[與你的手機配對](/zh-hant/integrations/pair-your-phone)。

<Steps>
  <Step title="在你的 iPhone 上登入">
    安裝 iPhone App，並以與你 Mac 相同的 Enconvo 帳號登入：使用 Apple、Google，或寄到你信箱的 6 位數代碼。只有登入你帳號的手機才能與它配對。免費帳號也可以配對，使用 Mac 的對話和遠端螢幕，以及使用虛擬形象。
  </Step>
  <Step title="顯示配對碼">
    在 Mac 上，開啟 **設定 → 連線** 並選擇 **顯示配對碼**。QR code 的有效期限為五分鐘。如果過期，請選擇 **顯示新程式碼**。
  </Step>
  <Step title="用你的 iPhone 掃描">
    在手機上，開啟 **遠端** 並點一下 **配對電腦**，然後將相機對準 Mac 上的代碼。iPhone 相機也可以：它會開啟 Enconvo，你再於其中確認 Mac。兩者很快就會完成配對。你的手機透過 Enconvo 中繼連到 Mac，訊息採用端對端加密。
  </Step>
  <Step title="你的 Mac，在你的手機上">
    當 Mac 在「遠端」中顯示為 **線上**，它的專案和對話就直接出現在你的手機上。
  </Step>
  <Step title="開啟任何對話">
    開啟任何對話，從你上次停下的地方繼續。對話仍然在你的 Mac 上執行，因此可以使用那台 Mac 的檔案、App 和代理程式。
  </Step>
  <Step title="保持可連線">
    在 **連線**（或 **設定 → 保持喚醒**）中，開啟 **防止這台 Mac 進入睡眠**。它會讓 Mac 不進入睡眠，使用電池時也一樣，讓你的手機隨時都能連到它。你也可以讓螢幕保持開啟、讓它在設定的時間後關閉，或在闔上螢幕時讓 Mac 保持喚醒（這會要求一次管理員密碼）。
  </Step>
  <Step title="移除手機">
    手機遺失了嗎？在 **連線 → 已配對的手機** 中，選擇它旁邊的 **移除**。那支手機就無法再連到你的 Mac。若要再次使用，請用新的代碼配對。
  </Step>
</Steps>

當 Mac 在代碼下方這樣說明時，掃描它也會讓 iPhone 登入你的 Enconvo 帳號。這類代碼請只用你自己的 iPhone 掃描。

## 你可以從手機做什麼

配對之後，你可以：

- 瀏覽 Mac 上的專案和對話，並繼續任何對話。
- 回答代理程式在你的 Mac 上工作時提出的問題。
- 在對話完成時收到通知，並從通知中回覆。
- 以 **遠端螢幕** 查看並控制你 Mac 的螢幕。
- 在手機本身與 AI 模型對話，使用 Enconvo Cloud 點數、你自己的 API 金鑰，或你登入的方案（ChatGPT、Grok、Le Chat、GitHub Copilot 或 Antigravity）。請參閱[手機聊天記錄](/zh-hant/integrations/iphone-phone-chats)。
- 與好友和團隊成員聊天與通話，並加入視訊會議。請參閱[手機上的通話與好友](/zh-hant/integrations/phone-calls-and-friends)。

App 將已配對的 Mac、Windows 電腦或 Linux 機器稱為你的 **電腦**。除非某個段落另有說明，否則 Android App 的運作方式相同。

## 在電腦的對話中工作

來自電腦的對話，外觀和運作方式與在電腦上相同，包含背景任務、子代理和引導。

- **首頁** 會在訊息框正上方顯示你進行中的對話。向上滑動卡片的握把，或點一下 **全部**，即可查看所有進行中的對話，並依需要你處理的、正在執行的和已有結果的分組。
- 側邊欄的 **進行中** 群組會彙整等待你處理、失敗、仍在執行或有未讀結果的對話。藍點標示尚未被讀取的結果，旋轉的圓環則標示正在執行的對話。**已釘選** 與 **最近** 可以收合。
- 在回覆執行期間傳送的內容會引導正在執行的任務，就像在 Mac 上按下 Return 一樣。這段時間訊息框會顯示「引導執行中的任務…」。
- 點一下子代理，即可在對話上方的面板中開啟它的步驟。它會從最新的步驟開啟，並跟隨新的輸出。向下滑動即可關閉。
- 核准的問題會提供代理程式自己的選項，與在 Mac 上相同。
- 若要變更對話的代理程式，請點一下對話標題下方的代理程式。**從這裡建立分支** 讓你為分支挑選代理程式。
- 模型面板會顯示你訂閱方案的名稱、它的 5 小時與每週限額（含剩餘量與重設時間），以及該列上模型自己的限額。
- 從照片圖庫附加照片和影片。影片會原封不動地傳到電腦。
- 在 App 的 **設定 → 虛擬形象** 中，選擇訊息框的通話按鈕要顯示虛擬形象，還是語音波形圖示。

當你的電腦離線或仍在重新連線時，你還是可以傳送：手機會回答它能回答的內容，例如問題和網路查詢，並在連上電腦後傳送需要電腦處理的訊息。

手機無法開啟的文件或連結，會提示你在電腦上開啟。

## 使用電腦的螢幕

點一下 **首頁** 右上角的顯示器圖示，或對話選單中的 **遠端螢幕**，即可查看並控制你電腦的螢幕。

| 模式 | 觸碰的作用 |
| --- | --- |
| **觸控板** | 在任何地方滑動即可移動指標，點一下即可在指標所在位置點擊。你使用時會有提示教你手勢。 |
| **觸碰** | 點一下你想點擊的位置。 |
| **僅觀看** | 沒有任何作用：你只能觀看。 |

模式按鈕會顯示目前模式的名稱。用兩指縮放；在 **觸控板** 模式中，畫面會以指標為中心縮放並跟隨它。

若要在做其他事情時讓螢幕保持浮動，請點一下左上角的子母畫面按鈕，或用兩指向內捏合。螢幕會浮在你的對話上方，當你離開 Enconvo 時也會浮在其他 App 上方。

在 Live Talk 通話期間，**遠端螢幕** 工具會在通話上方的小型浮動視窗中開啟螢幕。它的運作像觸控板，並有一個模式標籤可切換到 **觸碰** 或 **僅觀看**、一個可在電腦上輸入的鍵盤按鈕，以及 **全螢幕** 可開啟一般檢視。

## 通知

- 完成回覆的通知會顯示回覆的開頭。使用通知上的 **回覆**，即可不開啟 App 直接回答。
- App 開啟時，或你正在使用 Mac 時，不會有通知，除非該訊息是你從手機傳送的。
- 當你在一個裝置上讀過已完成的對話，它的通知就會從你其他裝置上消失。仍在等待回答的問題則會保留。
- 在 Android 14 及更新版本中，如果 Android 關閉了全螢幕通知，請在 App 的設定中開啟 **全螢幕通知**。

## 分享到 Enconvo

從其他 App 將網頁、照片或檔案分享到 Enconvo，**傳送給** 面板會讓你選擇新對話或任何最近的對話。在面板中或 App 的設定中開啟 **一律分享到新聊天**，即可略過這個詢問。

## 專案與成品

- 開啟專案的 **想法** 與 **看板**、變更它的設定、開始 **新增專案**，並對 Work 計畫卡片採取動作：回答、合併、開始或重試任務、開啟 pull request，或寫下並開始一個想法。
- `@` 選單會列出專案的成員、工作流程和可以加入的代理程式。
- 簡報、儀表板和 Motion 影片可從對話或成品資料庫中開啟，你可以在那裡留言、詢問 @Enconvo、分享、匯出和簡報。

## Android App

Android App 的配對與運作方式相同。請使用 Google 登入，或使用寄到你信箱的 6 位數代碼。訊息框位於單一橫列，有相機按鈕、用於電腦、專案和 **技能** 的快速標籤，以及附有最近照片和影片的加號面板。

從 enconvo.com 下載的 Android App 在你每次開啟時都會檢查更新。**略過此版本** 會隱藏某個版本，直到有更新的版本推出；**稍後** 則會隱藏提示，直到你下次開啟 App。

## 管理已配對的手機

**設定 → 連線** 會列出每支已配對的手機，並顯示目前手機是否可以連到這台 Mac。

| 工作 | 方式 |
| --- | --- |
| 配對另一支手機 | 選擇 **配對另一支手機** 並掃描新的代碼。一台 Mac 最多可有 10 支已配對的手機。 |
| 重新命名手機 | 點擊該手機，然後點擊名稱旁的 **重新命名手機**。 |
| 移除手機 | 在 **已配對的手機** 中，選擇它旁邊的 **移除**。 |
| 重新開始 | 選擇 **重設連線**。Enconvo 會建立新的連線金鑰，並移除所有已配對的手機。接著每支手機都要掃描新的代碼。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 手機無法連到你的 Mac | 確認 Mac 處於喚醒、已登入且在線上，並確認 **連線** 顯示它為 **線上**。開啟 **防止這台 Mac 進入睡眠** 以保持可連線。 |
| 手機顯示 Mac 拒絕了訊息、螢幕或終端機 | Mac 沒有為它開放裝置存取權限。請依照手機顯示的步驟操作。 |
| 代碼顯示 **此代碼已過期** | 選擇 **顯示新程式碼**，並在五分鐘內重新掃描。 |
| Mac 顯示 **登入後即可配對手機** | 點擊 **登入** 並在 Mac 上登入。你的 iPhone 和 Mac 必須使用同一個 Enconvo 帳號。 |
| Mac 顯示它 **需要新的連線金鑰** | 中繼為這台 Mac 保存了不同的金鑰，例如在你從備份還原之後。請選擇 **重設連線**，然後將每支手機重新配對。 |
| **已關閉 Companion 存取權限** | 存取權限已從你的某個裝置關閉，在你選擇 **重新開啟存取** 之前，沒有任何手機能連到你的 Mac。 |

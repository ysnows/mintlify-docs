本頁帶你從下載一路走到第一個答案。你將安裝 App、選擇 Enconvo 連接 AI 的方式，並從 SmartBar 提出問題。

<Steps>
  <Step title="安裝並開啟 Enconvo">
    從 [enconvo.com](https://www.enconvo.com) 下載 Enconvo，開啟 DMG，並將 **Enconvo** 拖曳到**應用程式**，然後從那裡開啟。Enconvo 需要 macOS 14 或更新版本。詳情請參閱[安裝](/zh-hant/installation)。
  </Step>
  <Step title="選擇 Enconvo 連接 AI 的方式">
    最簡單的方式是登入你的 Enconvo 帳號。預設模型 [Auto Route](/zh-hant/providers/auto-route) 之後會透過 [Enconvo Cloud](/zh-hant/providers/enconvo) 回答。你可以隨時切換：

    | 選項 | 做法 |
    | --- | --- |
    | Enconvo Cloud | 登入你的 Enconvo 帳號。 |
    | 你已訂閱的方案 | 使用 [ChatGPT](/zh-hant/providers/openai_subscription)、[Claude](/zh-hant/providers/anthropic_subscription)、[Grok](/zh-hant/providers/xai)、[GitHub Copilot](/zh-hant/providers/github-copilot) 等帳號登入。 |
    | 你自己的 API 金鑰 | 開啟**設定 → AI 模型**，選擇服務供應商，並貼上金鑰。 |
    | Mac 上的模型 | 設定[本機模型](/zh-hant/ai/local-llm)。 |
  </Step>
  <Step title="問出你的第一個問題">
    按下 **⌥Space** 開啟 SmartBar，輸入一個問題，例如請它列出三項讓早晨更有效率的清單，然後按下 Return 查看答案。
  </Step>
  <Step title="用在你自己的文字上">
    在任何 App 中選取一段文字。當 [PopBar](/zh-hant/features/popbar) 出現在文字旁邊時，按一下**解釋**或**翻譯**。
  </Step>
</Steps>

<Tip>
若想透過導覽認識 SmartBar、聊天視窗、聽寫、[草稿](/zh-hant/features/dictation)、語音指令、PopBar 與 App 側邊欄，請開啟**設定 → 一般**，並按一下**指南導覽**旁的**開始導覽**。導覽會使用 Enconvo 的語言，約需三分鐘。
</Tip>

Enconvo 在啟動時不會要求 macOS 權限。你第一次使用需要權限的功能時（例如麥克風或螢幕錄製），Enconvo 才會指出是哪項功能並提出要求。請參閱[權限](/zh-hant/configuration/permissions)了解每項權限啟用哪些功能。

## 如果沒有反應

| 問題 | 解決方式 |
| --- | --- |
| **⌥Space** 無法開啟 SmartBar | 在**設定 → SmartBar** 中檢查快速鍵，或使用 Enconvo 選單列圖示。 |
| SmartBar 開啟了，但沒有答案 | 登入你的 Enconvo 帳號，或在**設定 → AI 模型**中檢查服務供應商。 |
| PopBar 沒有出現 | 授予輔助使用權限。請參閱[權限](/zh-hant/configuration/permissions)。 |

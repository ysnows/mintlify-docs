本頁將帶你從下載安裝一路走到獲得第一個 AI 回覆。你將安裝應用程式、選擇 Enconvo 連接 AI 的方式，並透過 SmartBar 提出第一個問題。

<Steps>
  <Step title="安裝並開啟 Enconvo">
    從 [enconvo.com](https://www.enconvo.com) 下載 Enconvo，開啟 DMG 映像檔並將 **Enconvo** 拖入**應用程式**資料夾，然後從中開啟。Enconvo 需要 macOS 14 或以上版本。詳情請參閱[安裝指南](/zh-hant/installation)。
  </Step>
  <Step title="選擇 Enconvo 連接 AI 的方式">
    最簡單的方式是登入你的 Enconvo 帳號。接著預設模型 [Auto Route](/zh-hant/providers/auto-route) 便會透過 [Enconvo Cloud](/zh-hant/providers/enconvo) 為你回答問題。你隨時可以切換成其他方式：

    | 選項 | 設定方式 |
    | --- | --- |
    | Enconvo Cloud | 登入你的 Enconvo 帳號。 |
    | 你已付費訂閱的方案 | 使用 [ChatGPT](/zh-hant/providers/openai_subscription)、[Claude](/zh-hant/providers/anthropic_subscription)、[Grok](/zh-hant/providers/xai)、[GitHub Copilot](/zh-hant/providers/github-copilot) 等帳號登入。 |
    | 你自己的 API 金鑰 | 開啟**設定 → AI 模型**，選擇供應商並貼上金鑰。 |
    | 在 Mac 上執行的模型 | 設定[本機模型](/zh-hant/ai/local-llm)。 |
  </Step>
  <Step title="提出你的第一個問題">
    按下 **⌥Space** 開啟 SmartBar，輸入問題（例如請它提供一份包含三項要點的高效早晨檢查清單），然後按 Return 查看回答。
  </Step>
  <Step title="對你自己的文字試試看">
    在任何應用程式中選取一段文字。當 [PopBar](/zh-hant/features/popbar) 出現在文字旁時，點擊**解釋**或**翻譯**。
  </Step>
</Steps>

<Tip>
若想依序體驗 SmartBar、聊天視窗、聽寫、[語音撰寫草稿](/zh-hant/features/dictation)、語音指令、PopBar 與 App 側邊欄的引導教學，請開啟**設定 → 一般**，在**指南導覽**旁點擊**開始導覽**。導覽會以 Enconvo 的介面語言進行，大約需要三分鐘。
</Tip>

Enconvo 不會在啟動時一次要求所有 macOS 權限。只有當你首次使用需要特定權限的功能（例如麥克風或螢幕錄製）時，Enconvo 才會說明該功能並於當下向你請求權限。各項權限的用途請參閱[權限說明](/zh-hant/configuration/permissions)。

## 如果沒有反應

| 問題 | 解決方式 |
| --- | --- |
| 按 **⌥Space** 無法開啟 SmartBar | 檢查**設定 → SmartBar** 中的快速鍵設定，或直接點擊選單列上的 Enconvo 圖示。 |
| SmartBar 開啟了但沒有回應 | 請先登入你的 Enconvo 帳號，或檢查**設定 → AI 模型**中的供應商設定。 |
| PopBar 沒有出現 | 授予輔助使用（Accessibility）權限。請參閱[權限說明](/zh-hant/configuration/permissions)。 |

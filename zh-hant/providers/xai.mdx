---
title: "xAI (Grok)"
description: "在 Enconvo 中使用 xAI API 金鑰或你的 Grok 方案與 Grok 模型聊天。"
---

在聊天、代理程式和 AI 指令中使用 xAI 的 Grok 模型。你可以用 xAI API 金鑰連接（xAI 依每次請求計費），也可以登入你的 Grok 方案。它在設定中顯示為 **X.AI-GROK**。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 xAI 控制台建立金鑰；[xAI 快速入門](https://docs.x.ai/docs/quickstart#creating-an-api-key)說明了做法。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → X.AI-GROK**。在**身分驗證**下選擇 **API 金鑰**，貼上金鑰，然後按一下**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。收到回覆就代表連線成功。
  </Step>
</Steps>

<Tip>
有 Grok 方案嗎？請改在**身分驗證**下選擇 **Grok Subscription**，然後按一下**連接**。
</Tip>

若要另外保存第二把 xAI 金鑰，請按一下**新增供應商**並建立另一個設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **API 基礎網址** | 位於憑證中。預設為 `https://api.x.ai/v1`。 |

xAI 另有自己專屬的供應商，提供文字轉語音、圖片生成、語音轉寫、影片生成和 X Search。它們與此設定檔共用金鑰或 Grok 登入；請在各自的設定頁面中選擇。

## 在 iPhone 上

iPhone App 也能在手機聊天記錄中使用 Grok 方案。在 iPhone 上開啟**設定 → AI 模型 → xAI**，在**身分驗證**下選擇 Grok 卡片，然後輕點**使用 Grok 登入**。請參閱[手機聊天記錄](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認它在 xAI 控制台中已啟用。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**。若要自行新增模型，請使用**管理模型**。 |
| Grok 登入失效 | 開啟帳號卡片的選單，然後按一下**重新連線**。 |
| 出現速率或用量限制錯誤 | 到你的 xAI 帳號檢查用量，或暫時改用其他供應商。 |

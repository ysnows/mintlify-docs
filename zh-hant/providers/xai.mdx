---
title: "xAI (Grok)"
description: "使用 xAI API 金鑰或你的 Grok 方案在 Enconvo 中與 Grok 模型對話。"
---

在對話、代理程式與 AI 指令中使用 xAI 的 Grok 模型。你可以連接依請求計費的 xAI API 金鑰，或是登入你的 Grok 方案。它在設定中列為 **X.AI-GROK**。

## 連線設定

<Steps>
  <Step title="取得 API 金鑰">
    在 xAI 控制台中建立金鑰；[xAI 快速入門](https://docs.x.ai/docs/quickstart#creating-an-api-key)有操作說明。
  </Step>
  <Step title="加入至 Enconvo">
    開啟 **設定 → AI 模型 → X.AI-GROK**。在 **身分驗證** 下方選擇 **API 金鑰**，貼上金鑰後點選 **驗證**。
  </Step>
  <Step title="挑選模型">
    在 **模型名稱** 中挑選一個模型並送出簡短訊息。收到回覆即代表連線成功。
  </Step>
</Steps>

<Tip>
已經有 Grok 方案嗎？在 **身分驗證** 下方改選 **Grok 訂閱**，然後點選 **連接** 即可。
</Tip>

若想保留第二組 xAI 金鑰，請點選 **新增供應商** 來建立另一份設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **API Base Url** | 位於憑證設定中。預設為 `https://api.x.ai/v1`。 |

xAI 也提供文字轉語音、圖片生成、語音轉寫、影片生成與 X Search 的專屬服務供應商。它們會共用這份設定檔的金鑰或 Grok 登入狀態；只要到各自的功能設定頁面挑選即可。

## 在 iPhone 上使用

iPhone App 也能在手機對話中使用 Grok 方案。在 iPhone 上開啟 **設定 → AI 模型 → xAI**，在 **身分驗證** 下方選擇 Grok 卡片，然後點一下 **使用 Grok 登入**。請參閱[手機對話](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 重新貼上完整金鑰，並檢查它在 xAI 控制台中是否處於啟用狀態。 |
| 找不到某個模型 | 點選 **模型名稱** 旁的 **重新整理**。若要自行新增模型，請使用 **管理模型**。 |
| Grok 登入突然無法使用 | 開啟帳號卡片的選單並點選 **重新連線**。 |
| 速率或用量上限錯誤 | 檢查你 xAI 帳號中的用量，或暫時切換到其他服務供應商。 |

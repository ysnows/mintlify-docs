---
title: "Fireworks"
description: "在 Enconvo 中使用你自己的 Fireworks API 金鑰與 Fireworks 模型對話。"
---

Fireworks 透過單一 API 金鑰代管多種開放權重模型。將你的金鑰加入 Enconvo 後，即可在對話、代理程式與 AI 指令中使用這些模型。Fireworks 會直接向你自己的帳號計費。

## 連接設定

<Steps>
  <Step title="取得 API 金鑰">
    在你的 [Fireworks 帳號](https://fireworks.ai/account/api-keys)中建立一組金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → Fireworks**。在**身分驗證**底下將金鑰貼入 **API 金鑰**，然後點擊**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型並傳送一則簡短訊息。收到回覆即代表連線成功。
  </Step>
</Steps>

若要保留第二組 Fireworks 金鑰（例如工作專用金鑰），請點擊**新增供應商**並建立另一個設定檔。

## 模型與選項

| 設定 | 功能說明 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |

若要在單一對話中使用其他模型，請直接從該對話的模型選擇器挑選。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認該金鑰在你的 Fireworks 帳號中為啟用狀態。 |
| 列表中缺少某個模型 | 點擊**模型名稱**旁的**重新整理**重新載入列表。若要自行加入模型，請使用**管理模型**。 |
| 圖片或工具呼叫失敗 | 請改選支援圖片輸入或工具呼叫的模型。 |
| 發生速率或用量上限錯誤 | 檢查你 Fireworks 帳號中的用量與額度限制，或暫時切換至其他供應商。 |
| 回覆速度較慢 | 嘗試換成較小的模型、縮短輸入內容，或調低推理強度。 |

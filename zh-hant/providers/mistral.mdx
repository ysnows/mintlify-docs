---
title: "Mistral AI"
description: "在 Enconvo 中使用 Mistral API 金鑰或你的 Mistral 帳號與 Mistral 模型聊天。"
---

在聊天、代理程式和 AI 指令中使用 Mistral 的模型。你可以貼上 Mistral API 金鑰，也可以登入你的 Mistral 帳號，讓 Enconvo 替你建立金鑰。無論哪種方式，Mistral 都會將用量計入你的帳號。

## 連接

<Tabs>
  <Tab title="使用 Mistral 登入">
    <Steps>
      <Step title="開啟供應商">
        開啟**設定 → AI 模型 → Mistral AI**。
      </Step>
      <Step title="登入">
        在**身分驗證**下，選擇 Mistral 帳號登入並按一下**連接**。使用你的 Mistral 帳號登入並選擇工作區。此登入方式與 Mistral Vibe 的登入方式相同：它會為該工作區建立 API 金鑰，所以不需要複製任何內容。
      </Step>
      <Step title="選擇模型">
        在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。
      </Step>
    </Steps>
  </Tab>
  <Tab title="使用 API 金鑰">
    <Steps>
      <Step title="取得 API 金鑰">
        在 [Mistral 控制台](https://console.mistral.ai/api-keys/)建立金鑰。
      </Step>
      <Step title="加入 Enconvo">
        開啟**設定 → AI 模型 → Mistral AI**。在**身分驗證**下，將金鑰貼到 **API 金鑰**，然後按一下**驗證**。
      </Step>
      <Step title="選擇模型">
        在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。
      </Step>
    </Steps>
  </Tab>
</Tabs>

登入後，帳號卡片會顯示你的方案、金鑰，以及每分鐘限額的剩餘量。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **推理強度**（在聊天中） | 適用於 Mistral Large 4、Medium 3.5 和 Small 4：**無**會不經思考直接回答，**高**會先思考。Large 4 預設會思考。 |

Voxtral 語音轉寫和 Mistral OCR 可以使用同一個登入或金鑰。

## 在 iPhone 上

iPhone App 也能在手機聊天記錄中使用你的 Le Chat 方案。在 iPhone 上開啟**設定 → AI 模型 → Mistral**，在**身分驗證**下選擇 Le Chat 卡片，然後輕點**使用 Mistral 登入**。請參閱[手機聊天記錄](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認它在 Mistral 控制台中已啟用。 |
| 登入失效 | 開啟帳號卡片的選單，然後按一下**重新連線**。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**。若要自行新增模型，請使用**管理模型**。 |
| 出現速率限制錯誤 | 你的工作區每分鐘限額已用完。請等待一分鐘，或到 Mistral 控制台檢查限額。 |

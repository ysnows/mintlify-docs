---
title: "Mistral AI"
description: "使用 Mistral API Key 或你的 Mistral 帳號，在 Enconvo 中與 Mistral 模型聊天。"
---

在聊天、代理程式與 AI 指令中使用 Mistral 的模型。你可以貼上 Mistral API Key，或直接使用 Mistral 帳號登入，讓 Enconvo 自動為你建立金鑰。無論哪種方式，Mistral 都會將用量計入你的帳號。

## 連線

<Tabs>
  <Tab title="使用 Mistral 登入">
    <Steps>
      <Step title="開啟服務供應商">
        開啟 **設定 → AI 模型 → Mistral AI**。
      </Step>
      <Step title="登入">
        在 **身分驗證** 下方選擇 Mistral 帳號登入並點擊 **連線**。使用你的 Mistral 帳號登入並選擇一個工作區。這種登入方式與 Mistral Vibe 相同：它會為該工作區建立一組 API Key，因此你無需手動複製金鑰。
      </Step>
      <Step title="選擇模型">
        在 **模型名稱** 中選擇一個模型並傳送一則簡短訊息。
      </Step>
    </Steps>
  </Tab>
  <Tab title="使用 API Key">
    <Steps>
      <Step title="取得 API Key">
        在 [Mistral 主控台](https://console.mistral.ai/api-keys/)建立一組金鑰。
      </Step>
      <Step title="新增至 Enconvo">
        開啟 **設定 → AI 模型 → Mistral AI**。在 **身分驗證** 下方將金鑰貼入 **API Key**，然後點擊 **驗證**。
      </Step>
      <Step title="選擇模型">
        在 **模型名稱** 中選擇一個模型並傳送一則簡短訊息。
      </Step>
    </Steps>
  </Tab>
</Tabs>

登入後，帳號卡片會顯示你的方案、金鑰，以及每分鐘限額的剩餘用量。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **推理強度**（在聊天中） | 適用於 Mistral Large 4、Medium 3.5 與 Small 4：**None** 會直接回答而不先思考，**High** 會先進行思考。Large 4 預設會先思考。 |

Voxtral 語音轉寫與 Mistral OCR 也可以使用同一組登入或金鑰。

## 在 iPhone 上使用

iPhone App 也可以在「手機聊天」中使用你的 Le Chat 方案。在 iPhone 上開啟 **設定 → AI 模型 → Mistral**，在 **身分驗證** 下方選擇 Le Chat 卡片，然後點一下 **使用 Mistral 登入**。參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 再次貼上完整的金鑰，並確認它在 Mistral 主控台中處於啟用狀態。 |
| 登入停止運作 | 開啟帳號卡片的選單並點擊 **重新連線**。 |
| 缺少某個模型 | 點擊 **模型名稱** 旁的 **重新整理**。若要自行新增模型，請使用 **管理模型**。 |
| 速率限制錯誤 | 你的工作區每分鐘限額已用完。請稍候一分鐘，或在 Mistral 主控台中查看限制。 |

---
title: "DeepSeek"
description: "使用你自己的 DeepSeek API Key，在 Enconvo 中與 DeepSeek 模型聊天。"
---

DeepSeek 透過 API Key 提供其模型服務。將你的金鑰加入 Enconvo，即可在聊天、代理程式與 AI 指令中使用這些模型。DeepSeek 會將用量計入你自己的帳號。在設定中此項目顯示為 **Deep Seek**。

## 連線

<Steps>
  <Step title="取得 API Key">
    在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)建立一組金鑰。
  </Step>
  <Step title="新增至 Enconvo">
    開啟 **設定 → AI 模型 → Deep Seek**。在 **身分驗證** 下方將金鑰貼入 **API Key**，然後點擊 **驗證**。
  </Step>
  <Step title="選擇模型">
    在 **模型名稱** 中選擇一個模型並傳送一則簡短訊息。收到回覆即代表連線正常。
  </Step>
</Steps>

若要保留第二組 DeepSeek 金鑰（例如一組專門用於工作），點擊 **新增供應商** 並建立另一個設定檔即可。

同一組金鑰也適用於其他支援 DeepSeek 的功能。在 **設定 → 文字轉語音**、**設定 → 網頁搜尋**、**設定 → 擷取網頁** 與 **設定 → OCR**（顯示為 **DeepSeek OCR**），以及用於語音辨識的 **聽寫模型** 或 **轉寫模型** 中，都可以選擇 **DeepSeek** 作為服務供應商。這些功能也都提供 **DeepSeek (Enconvo Cloud)** 選項，不需金鑰即可透過你的 Enconvo 帳號使用。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |

若要在單一聊天中使用其他模型，從該聊天的模型選擇器中挑選即可。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 再次貼上完整的金鑰，並確認它在你的 DeepSeek 帳號中處於啟用狀態。 |
| 缺少某個模型 | 點擊 **模型名稱** 旁的 **重新整理** 以重新載入列表。若要自行新增模型，請使用 **管理模型**。 |
| 圖片或工具呼叫失敗 | 請選擇支援圖片輸入或工具呼叫的模型。 |
| 速率或用量上限錯誤 | 檢查你 DeepSeek 帳號中的用量與限制，或先暫時切換至其他服務供應商。 |
| 回覆速度緩慢 | 改用較小的模型、縮短輸入內容，或調低推理強度。 |

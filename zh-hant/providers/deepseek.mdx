---
title: "DeepSeek"
description: "在 Enconvo 中使用你自己的 DeepSeek API 金鑰與 DeepSeek 模型聊天。"
---

DeepSeek 透過 API 金鑰提供其模型。將你的金鑰加入 Enconvo，即可在聊天、代理程式和 AI 指令中使用這些模型。DeepSeek 會將用量計入你自己的帳號。它在設定中顯示為 **Deep Seek**。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)建立金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → Deep Seek**。在**身分驗證**下，將金鑰貼到 **API 金鑰**，然後按一下**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。收到回覆就代表連線成功。
  </Step>
</Steps>

若要另外保存第二把 DeepSeek 金鑰（例如工作用的金鑰），請按一下**新增供應商**並建立另一個設定檔。

同一把金鑰也適用於其他功能中的 DeepSeek。請在**設定 → 文字轉語音**、**設定 → 網頁搜尋**、**設定 → 擷取網頁**和**設定 → OCR**（顯示為 **DeepSeek OCR**）中選擇 **DeepSeek** 作為供應商，並在**聽寫模型**或**語音轉寫模型**中將它用於語音辨識。這些位置也都有 **DeepSeek (Enconvo Cloud)** 選項，不需要金鑰，直接使用你的 Enconvo 帳號。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |

若只想在某個聊天中使用不同的模型，請從該聊天的模型選擇器中選取。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認它在你的 DeepSeek 帳號中已啟用。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**以重新載入清單。若要自行新增模型，請使用**管理模型**。 |
| 圖片或工具無法使用 | 請選擇支援圖片輸入或工具呼叫的模型。 |
| 出現速率或用量限制錯誤 | 到你的 DeepSeek 帳號檢查用量與限制，或暫時改用其他供應商。 |
| 回覆很慢 | 試試較小的模型、較短的輸入，或較低的推理強度。 |

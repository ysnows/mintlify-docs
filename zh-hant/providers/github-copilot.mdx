---
title: "GitHub Copilot"
description: "使用具備 Copilot 方案的 GitHub 帳號登入，並與方案內的模型對話。"
---

在 Enconvo 中將你的 GitHub Copilot 方案作為 AI 模型服務供應商使用。你只需要登入具備該方案的 GitHub 帳號即可，完全不需要 API 金鑰。進階模型（Premium models）會計入你方案中的進階請求額度。

## 連線設定

<Steps>
  <Step title="開啟服務供應商">
    開啟 **設定 → AI 模型 → GitHub Copilot**。
  </Step>
  <Step title="開始登入">
    在 **身分驗證** 中點選 **連接**。
  </Step>
  <Step title="在 GitHub 輸入驗證碼">
    瀏覽器會開啟 GitHub 的裝置驗證頁面，同時 Enconvo 會顯示一組要輸入的驗證碼。輸入驗證碼並授權登入。
  </Step>
  <Step title="確認帳號">
    返回 Enconvo，確認已連接到你預期的 GitHub 帳號。
  </Step>
  <Step title="挑選模型">
    選擇一個模型並送出簡短請求測試。
  </Step>
</Steps>

在完成授權前關閉 Enconvo 的驗證碼視窗會取消這次登入。

## 模型與選項

模型清單只會顯示你的 Copilot 方案有權使用的模型，並將 Copilot 預設的對話模型排在第一位。Copilot Free 提供的模型比付費方案少，因此你在其他地方看過的模型不一定會出現在清單中。每個模型都會採用 Copilot 為它提供的推理強度等級。

## 在 iPhone 上使用

iPhone App 也能登入 GitHub Copilot，用於手機上的「手機對話」。請參閱[手機對話](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 登入沒有完成 | 請在驗證碼過期前於 GitHub 頁面完成輸入，若已過期請再次點選 **連接** 取得新驗證碼。 |
| 清單裡沒有你要的模型 | 你的 Copilot 方案未包含該模型；請改選其他模型或升級方案。 |
| 請求失敗並回傳模型錯誤 | 請從目前的清單重新挑選模型；若是在變更方案前選的預設模型，現在可能已不再提供。 |
| 速率或用量上限 | 受限於你的方案進階請求額度與 GitHub 的速率限制。 |

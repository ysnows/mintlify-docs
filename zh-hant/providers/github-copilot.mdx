---
title: "GitHub Copilot"
description: "使用擁有 Copilot 方案的 GitHub 帳號登入，並與你方案中的模型聊天。"
---

在 Enconvo 中將你的 GitHub Copilot 方案作為 AI 模型服務供應商使用。你以擁有該方案的 GitHub 帳號登入，不涉及 API 金鑰。進階模型會計入你方案的進階請求次數。

## 連接

<Steps>
  <Step title="開啟服務供應商">
    開啟 **設定 → AI 模型 → GitHub Copilot**。
  </Step>
  <Step title="開始登入">
    在 **身分驗證** 中，點按 **連接**。
  </Step>
  <Step title="在 GitHub 上輸入代碼">
    你的瀏覽器會開啟 GitHub 的裝置頁面，而 Enconvo 會顯示要在那裡輸入的代碼。輸入代碼並授權登入。
  </Step>
  <Step title="檢查帳號">
    回到 Enconvo，確認已連接的是你想要的 GitHub 帳號。
  </Step>
  <Step title="挑選模型">
    選擇一個模型並試著送出簡短的請求。
  </Step>
</Steps>

在你授權之前關閉 Enconvo 的代碼對話框，會取消登入。

## 模型與選項

模型清單只會顯示你的 Copilot 方案可以使用的模型，並以 Copilot 自己的聊天預設值排在最前面。Copilot Free 提供的模型比付費方案少，因此你在其他地方看到的模型可能不會列出。每個模型使用 Copilot 為它提供的推理強度等級。

## 在 iPhone 上

iPhone App 也可以登入 GitHub Copilot，用於手機上的手機聊天。請參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 登入沒有完成 | 在代碼過期前於 GitHub 的頁面輸入代碼，然後再次點按 **連接** 以取得新的代碼。 |
| 你想要的模型沒有列出 | 你的 Copilot 方案不包含它；請改選其他模型或升級方案。 |
| 請求因模型錯誤而失敗 | 請從目前的清單中挑選模型；在你的方案變更之前所選的預設值，可能已不再提供。 |
| 速率或用量上限 | 你方案的進階請求次數與 GitHub 的速率限制。 |

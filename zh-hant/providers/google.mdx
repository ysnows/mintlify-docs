---
title: "Google Gemini"
description: "在 Enconvo 中使用 Gemini API 金鑰與 Gemini 模型聊天。"
---

在聊天、代理程式和 AI 指令中使用 Google 的 Gemini 模型。使用來自 Google AI Studio 的 Gemini API 金鑰連接；Google 會將用量計入你自己的帳號。它在設定中顯示為 **Google Gemini AI**。

<Note>
Google Gemini 僅支援以 API 金鑰連接。Google 已停止支援個人 Google 帳號的 Gemini 登入，因此 Enconvo 在 2.5.8 版移除了 Google 帳號選項。若要透過 Google 登入使用模型，請參閱 [Antigravity](/zh-hant/providers/antigravity)。
</Note>

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 [Google AI Studio](https://aistudio.google.com/apikey) 建立金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → Google Gemini AI**。在**身分驗證**下，將金鑰貼到 **API 金鑰**，然後按一下**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。收到回覆就代表連線成功。
  </Step>
</Steps>

若要另外保存第二把 Gemini 金鑰，請按一下**新增供應商**並建立另一個設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **Google Search Tool** | 以 Google 搜尋結果作為回答依據，並附上可供查證的來源。預設為關閉。 |
| **URL Context Tool** | 讓模型讀取你訊息中連結所指向的網頁。預設為關閉。 |
| **Show thoughts** | 在回答的同時顯示模型思考過程的摘要。預設為關閉。 |

具備思考能力的 Gemini 模型可讓你設定思考的時間長短，也就是它們的推理強度。Gemini 4 Carbon 提供**低**、**中等**（預設）和**高**，且需要付費的 API 層級。Gemini 4 Hydrogen 是適合日常程式開發與代理工作的快速模型，提供**低**、**中等**、**高**（預設）和**超高**；其中**超高**在處理困難的多步驟任務時思考得最久，免費層級也能使用。

同一個 Google Gemini 設定檔也供 Gemini 的文字轉語音、圖片生成、語音轉寫、影片生成和網頁搜尋使用，因此更改它的金鑰也會影響這些功能。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認它在 Google AI Studio 中已啟用。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**。若要自行新增模型，請使用**管理模型**。 |
| 有關時事的回答已經過時 | 開啟 **Google Search Tool**。 |
| 出現速率或用量限制錯誤 | 到 Google AI Studio 檢查你的配額，或暫時改用其他供應商。 |

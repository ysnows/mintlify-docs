---
title: "Qwen"
description: "使用阿里雲 Model Studio API Key，在 Enconvo 中與 Qwen 模型聊天。"
---

在聊天、代理程式與 AI 指令中使用阿里巴巴的 Qwen 模型。透過阿里雲 Model Studio 的 API Key 進行連線；阿里雲會將用量計入你的帳號。若為中國大陸地區服務（百煉），請改用 [DashScope](/zh-hant/providers/dashscope)。

## 連線

<Steps>
  <Step title="取得 API Key">
    在[阿里雲 Model Studio](https://modelstudio.console.alibabacloud.com/)建立一組金鑰。
  </Step>
  <Step title="新增至 Enconvo">
    開啟 **設定 → AI 模型 → Qwen**。在 **身分驗證** 下方將金鑰貼入 **API Key**，然後點擊 **驗證**。
  </Step>
  <Step title="選擇模型">
    在 **模型名稱** 中選擇一個模型並傳送一則簡短訊息。收到回覆即代表連線正常。
  </Step>
</Steps>

Qwen 僅支援使用 API Key 連線。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **Base Url** | 位於憑證設定中。預設為國際端點 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。若你的金鑰屬於其他地區，請修改此網址。 |

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 確認金鑰與 **Base Url** 屬於相同地區，然後再次貼上完整的金鑰。 |
| 缺少某個模型 | 點擊 **模型名稱** 旁的 **重新整理**。若要自行新增模型，請使用 **管理模型**。 |
| 速率或用量上限錯誤 | 在 Model Studio 中檢查用量與配額，或先暫時切換至其他服務供應商。 |

---
title: "Qwen"
description: "在 Enconvo 中使用 Alibaba Cloud Model Studio API 金鑰與 Qwen 模型聊天。"
---

在聊天、代理程式和 AI 指令中使用阿里巴巴的 Qwen 模型。使用來自 Alibaba Cloud Model Studio 的 API 金鑰連接；Alibaba Cloud 會將用量計入你的帳號。若要使用中國大陸的服務（百煉），請使用 [DashScope](/zh-hant/providers/dashscope)。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/) 建立金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → Qwen**。在**身分驗證**下，將金鑰貼到 **API 金鑰**，然後按一下**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。收到回覆就代表連線成功。
  </Step>
</Steps>

Qwen 僅支援以 API 金鑰連接。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |
| **基礎 URL** | 位於憑證中。預設為國際端點 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。如果你的金鑰屬於其他區域，請更改它。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 確認金鑰與**基礎 URL**屬於同一個區域，然後重新貼上完整的金鑰。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**。若要自行新增模型，請使用**管理模型**。 |
| 出現速率或用量限制錯誤 | 到 Model Studio 檢查用量與配額，或暫時改用其他供應商。 |

PipeLLM 是一個閘道：一把 PipeLLM API 金鑰就能使用許多公司的模型，包括 Claude、GPT、Gemini、Grok、Qwen、Kimi 和 GLM。當你想把多家廠商集中在同一張帳單上時，就適合使用它。PipeLLM 會將用量計入你自己的帳號。

同一把金鑰也可用於圖片生成、影片生成和網頁搜尋。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在你的 [PipeLLM](https://pipellm.ai) 帳號中建立金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → PipeLLM**。在**身分驗證**下，將金鑰貼到 **API 金鑰**，然後按一下**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型，並傳送一則簡短訊息。收到回覆就代表連線成功。
  </Step>
</Steps>

若要另外保存第二把 PipeLLM 金鑰，請按一下**新增供應商**並建立另一個設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**會重新載入清單；**管理模型**（齒輪圖示）可新增或還原模型。 |

PipeLLM 金鑰也適用於下列功能。請在各頁面中選擇 **PipeLLM** 作為供應商：

| 功能 | 位置 | 你會得到什麼 |
| --- | --- | --- |
| 圖片生成 | **設定 → 圖片生成** | 使用 GPT Image、Nano Banana 和 Seedream 等模型進行圖片生成與編輯。 |
| 影片生成 | **設定 → 影片生成** | Seedance、Veo、Kling 和 Sora 等影片模型。 |
| 網頁搜尋 | **設定 → 網頁搜尋** | 附有摘要的 Google 搜尋結果。PipeLLM 對每次有回傳結果的搜尋收費。 |

在其中一處更改金鑰，其他地方也會一併更改，因為它們共用同一份憑證。iPhone 和 Android App 也可以在其 AI 模型設定中使用 PipeLLM。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認它在你的 PipeLLM 帳號中已啟用。 |
| 找不到某個模型 | 按一下**模型名稱**旁的**重新整理**。若要自行新增模型，請使用**管理模型**。 |
| 圖片或工具無法使用 | 請選擇支援圖片輸入或工具呼叫的模型。 |
| 出現速率、餘額或用量錯誤 | 到你的 PipeLLM 帳號檢查餘額與限制，或暫時改用其他供應商。 |

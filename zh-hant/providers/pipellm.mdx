PipeLLM 是一個模型閘道服務：一組 PipeLLM API 金鑰即可存取來自多家公司的模型，包含 Claude、GPT、Gemini、Grok、Qwen、Kimi 與 GLM。當你想把多家模型供應商整合在同一張帳單中時最適合使用。PipeLLM 會直接向你自己的帳號計費。

同一組金鑰也同時支援圖片生成、影片生成與網頁搜尋。

## 連接設定

<Steps>
  <Step title="取得 API 金鑰">
    在你的 [PipeLLM](https://pipellm.ai) 帳號中建立一組金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → PipeLLM**。在**身分驗證**底下將金鑰貼入 **API 金鑰**，然後點擊**驗證**。
  </Step>
  <Step title="選擇模型">
    在**模型名稱**中選擇一個模型並傳送一則簡短訊息。收到回覆即代表連線成功。
  </Step>
</Steps>

若要保留第二組 PipeLLM 金鑰，請點擊**新增供應商**並建立另一個設定檔。

## 模型與選項

| 設定 | 功能說明 |
| --- | --- |
| **模型名稱** | 此供應商使用的模型。旁邊的**重新整理**可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |

這組 PipeLLM 金鑰也可以用於以下功能。請在各功能頁面中選擇 **PipeLLM** 作為供應商：

| 功能 | 設定位置 | 可用功能 |
| --- | --- | --- |
| 圖片生成 | **設定 → 圖片生成** | 使用 GPT Image、Nano Banana、Seedream 等模型生成與編輯圖片。 |
| 影片生成 | **設定 → 影片生成** | 使用 Seedance、Veo、Kling、Sora 等影片生成模型。 |
| 網頁搜尋 | **設定 → 網頁搜尋** | 取得 Google 搜尋結果與摘要片段。PipeLLM 會針對每次有回傳結果的搜尋計費。 |

由於它們共用同一組憑證，在任一處修改金鑰都會套用至所有功能。iPhone 與 Android App 也能在各自的 AI 模型設定中使用 PipeLLM。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並確認該金鑰在你的 PipeLLM 帳號中為啟用狀態。 |
| 列表中缺少某個模型 | 點擊**模型名稱**旁的**重新整理**。若要自行加入模型，請使用**管理模型**。 |
| 圖片或工具呼叫失敗 | 請改選支援圖片輸入或工具呼叫的模型。 |
| 發生速率、餘額或用量錯誤 | 檢查你 PipeLLM 帳號中的餘額與額度限制，或暫時切換至其他供應商。 |

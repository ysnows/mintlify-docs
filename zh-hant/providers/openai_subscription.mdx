---
title: "ChatGPT 訂閱"
description: "使用你的 ChatGPT 方案登入，即可在 Enconvo 中使用 OpenAI 模型，無需 API 金鑰。"
---

如果你有付費使用 ChatGPT，請用該方案登入，而不必建立 API 金鑰。請求會使用你方案的額度，Enconvo 會顯示剩餘多少。

## 連接

<Steps>
  <Step title="選擇訂閱">
    開啟 **設定 → AI 模型 → OpenAI**。在 **身分驗證** 下，選擇 **ChatGPT 訂閱**。
  </Step>
  <Step title="登入">
    點按 **連接**，在瀏覽器中登入你的 ChatGPT 帳號並允許存取。待瀏覽器顯示完成後，回到 Enconvo。
  </Step>
  <Step title="挑選模型">
    確認帳號卡片顯示的是正確的帳號，在 **模型名稱** 中選擇模型，並傳送一則簡短的訊息。
  </Step>
</Steps>

Enconvo 會在背景更新登入狀態，因此你不需要每隔幾天就重新登入。

## 查看你的用量

帳號卡片會顯示每個用量視窗還剩多少（**% 剩餘**）以及重設時間，另外還有方案續訂或到期的時間。開啟卡片的選單可使用：

- **重新整理用量**：取得最新的數字。
- **重新連線**：重新登入，例如切換帳號。

當 OpenAI 沒有回報用量時，卡片會顯示 **無法取得用量** 及原因。這並不表示該方案沒有上限。

### 使用免費重置

當 Codex 提供你免費的額度重設時，卡片會列出 **贈送的重置**：你還剩幾次以及何時到期。點按 **使用重置** 並確認，即可立即補滿你的額度。重置無法復原。

## 方案涵蓋的範圍

ChatGPT 登入也適用於 OpenAI 圖片生成與語音轉寫；請在這些頁面的 **身分驗證** 下選擇 **ChatGPT 訂閱**。OpenAI 的文字轉語音與嵌入需要 API 金鑰，Live Talk 語音則另外設定。

## 在 iPhone 上

iPhone App 為手機聊天提供自己的 ChatGPT 登入。在 iPhone 上，開啟 **設定 → AI 模型 → OpenAI**，在 **身分驗證** 下選擇 ChatGPT 卡片，並輕點 **使用 ChatGPT 登入**。頁面接著會顯示你的方案、它的 5 小時與每週額度還剩多少，以及各自何時重設。該登入只留在 iPhone 上；Mac 則保有它自己的登入。請參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 登入失敗 | 閱讀 OpenAI 給出的錯誤訊息，然後再次點按 **連接**。請確認你登入的是擁有該方案的帳號。 |
| 找不到某個模型 | 模型取決於你的方案。請點按 **模型名稱** 旁的 **重新整理**。 |
| 聊天顯示已達用量上限 | 若卡片列出免費重置，請使用它；或等待帳號卡片上的重設時間，或暫時將 **身分驗證** 切換為 **API 金鑰**。 |
| 聊天在一段時間後停止運作 | 開啟帳號卡片的選單並點按 **重新連線**。 |

---
title: "ChatGPT 訂閱"
description: "使用你的 ChatGPT 方案登入，不需 API Key 即可在 Enconvo 中使用 OpenAI 模型。"
---

如果你有付費訂閱 ChatGPT，可以直接使用該方案登入，而不必另外建立 API Key。請求會使用你方案中的額度，且 Enconvo 會顯示目前的剩餘用量。

## 連線

<Steps>
  <Step title="選擇訂閱方案">
    開啟 **設定 → AI 模型 → OpenAI**。在 **身分驗證** 下方選擇 **ChatGPT 訂閱**。
  </Step>
  <Step title="登入">
    點擊 **連線**，在瀏覽器中登入你的 ChatGPT 帳號並允許存取。當瀏覽器顯示完成後，回到 Enconvo。
  </Step>
  <Step title="選擇模型">
    確認帳號卡片顯示的是正確的帳號，在 **模型名稱** 中選擇一個模型，並傳送一則簡短訊息。
  </Step>
</Steps>

Enconvo 會在背景自動更新登入狀態，因此你不需要每隔幾天就重新登入一次。

## 查看用量

帳號卡片會顯示每個用量視窗的剩餘比例（**剩餘 %**）與重置時間，以及方案的續訂或到期日期。開啟卡片的選單即可進行以下操作：

- **重新整理用量**：取得最新數據。
- **重新連線**：重新登入，例如要切換帳號時。

當 OpenAI 未回報用量時，卡片會顯示 **無法取得用量** 及原因。這並不代表該方案沒有用量上限。

### 使用贈送的重置

當 Codex 提供你免費的額度重置次數時，卡片會列出 **贈送的重置**：包含剩餘次數與到期時間。點擊 **使用重置** 並確認，即可立即補充你的額度。重置一旦使用便無法復原。

## 方案涵蓋範圍

此 ChatGPT 登入也適用於 OpenAI 圖片生成與語音轉寫功能；在這些頁面上的 **身分驗證** 下方選擇 **ChatGPT 訂閱** 即可。OpenAI 文字轉語音與嵌入模型仍需要 API Key，而 Live Talk 語音則需另外設定。

## 在 iPhone 上使用

iPhone App 在「手機聊天」中有自己獨立的 ChatGPT 登入。在 iPhone 上開啟 **設定 → AI 模型 → OpenAI**，在 **身分驗證** 下方選擇 ChatGPT 卡片，然後點一下 **使用 ChatGPT 登入**。頁面接著會顯示你的方案、5 小時與每週額度的剩餘比例，以及各自的重置時間。該登入僅保留在 iPhone 上；Mac 會保留自己的登入狀態。參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 登入失敗 | 查看 OpenAI 回傳的錯誤訊息，然後再次點擊 **連線**。請確認你登入的是擁有該訂閱方案的帳號。 |
| 缺少某個模型 | 你的訂閱方案決定了可用的模型。點擊 **模型名稱** 旁的 **重新整理**。 |
| 聊天提示已達用量上限 | 若卡片上有顯示次數，可使用贈送的重置、等待帳號卡片上的重置時間，或暫時將 **身分驗證** 切換為 **API Key**。 |
| 使用一段時間後聊天無法運作 | 開啟帳號卡片的選單並點擊 **重新連線**。 |

title: "Kimi"
description: "在 Enconvo 中使用你自己的 Kimi API 金鑰，與 Kimi 模型對話。"
---

Kimi 是 Moonshot AI 推出的模型系列。將金鑰加入 Enconvo 後，即可在聊天、代理程式和 AI 指令中使用這些模型。Kimi 會將使用量計入你自己的帳號。它在設定中顯示為 **kimi.ai**。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 [Kimi 平台](https://platform.kimi.ai/docs/overview) 建立一個金鑰。
  </Step>
  <Step title="加入到 Enconvo">
    開啟 **設定 → AI 模型 → kimi.ai**。在 **身分驗證** 下將金鑰貼入 **API Key**，然後點擊 **驗證**。
  </Step>
  <Step title="選擇模型">
    在 **模型名稱** 中選擇一個模型並傳送簡短訊息。收到回覆即表示連接成功。
  </Step>
</Steps>

如需保留第二組 Kimi 金鑰（例如工作專用），請點擊 **Add New Provider** 建立另一個設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入清單；**管理模型**（齒輪圖示）可新增或恢復模型。 |
| **API Base Url** | 位於憑證設定中。除非你的金鑰屬於中國大陸端點，否則請保留預設值；該欄位說明中列出了兩個端點位址。 |

若想在單一對話中使用其他模型，請從該對話的模型選擇器中挑選。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 請重新貼上完整金鑰，並確認該金鑰在你的 Kimi 帳號中處於啟用狀態。 |
| 找不到某個模型 | 點擊 **模型名稱** 旁的 **重新整理** 重新載入清單。如需手動加入模型，請使用 **管理模型**。 |
| 圖片或工具呼叫失敗 | 請選擇支援圖片輸入或工具呼叫的模型。 |
| 出現速率或用量限制錯誤 | 在你的 Kimi 帳號中檢查用量與限額，或暫時切換到其他服務供應商。 |
| 回覆速度較慢 | 嘗試換成較小的模型、縮短輸入內容，或調低推理強度。 |

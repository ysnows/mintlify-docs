使用貴組織部署在 Azure 上的 OpenAI 模型。Enconvo 會直接與你的 Azure 資源通訊，因此存取權限、配額與計費都遵循你的 Azure 訂閱方案。

## 開始之前

你需要一個已建立至少一個模型部署的 Azure OpenAI 資源。從 Azure 入口網站複製該資源的**金鑰（key）**、**端點（endpoint）**，以及你為模型設定的**部署名稱（deployment name）**。如果尚未建立資源，請參閱 [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview)。

## 連接

<Steps>
  <Step title="加入憑證">
    開啟**設定 → AI 模型 → Azure OpenAI**。在**身分驗證**下方填寫 **API Key**、**Endpoint** 與 **API Version**，然後點擊**驗證**。端點格式類似於 `https://<resource>.cognitiveservices.azure.com/`。
  </Step>
  <Step title="設定部署名稱">
    在 **Azure OpenAI Api Deployment Name** 中輸入你的部署名稱。請填寫 Azure 資源中的部署名稱，它可能與模型本身的名稱不同。
  </Step>
  <Step title="進行測試">
    傳送一則簡短的訊息。收到回覆即表示連線正常。
  </Step>
</Steps>

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | 此服務供應商呼叫的 Azure 部署名稱。 |
| **Streaming** | 在回覆產生的同時即時顯示內容。預設開啟；如果你的部署不支援串流輸出，請將它關閉。 |
| **API Version** | 位於憑證設定中。預設值為 `2025-01-01-preview`。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 確認金鑰與 **Endpoint** 來自同一個 Azure 資源。 |
| 找不到部署 | 從 Azure 入口網站原封不動地複製完整的部署名稱。 |
| 回覆一直沒有出現 | 關閉 **Streaming** 後再試一次。 |
| 發生速率或配額錯誤 | 在 Azure 中提高該部署的配額，或暫時切換至其他服務供應商。 |

---

Enconvo Cloud 讓你透過自己的 Enconvo 帳號即可使用多家公司的模型，以及語音、圖片、影片與網頁工具。不需要管理任何 API 金鑰：請求會消耗你方案中的點數。這是最快速的上手方式。

## 設定

<Steps>
  <Step title="登入">
    登入你的 Enconvo 帳號。參閱[帳號](/zh-hant/configuration/account)。
  </Step>
  <Step title="選擇 Enconvo Cloud">
    開啟你想使用的功能設定頁面（例如 **AI 模型**、**文字轉語音**或**圖片生成**），並選擇標示為 **Enconvo Cloud** 或 **Enconvo Cloud Plan** 的服務供應商。
  </Step>
  <Step title="挑選模型或語音">
    選擇一個模型或語音，送出一小段請求測試。
  </Step>
</Steps>

每項功能都各自設定服務供應商。在聊天中選用 Enconvo Cloud 並不會自動切換語音、圖片、影片、嵌入、重新排序或網頁工具；請在需要的地方分別設定。

## Enconvo 自家模型

Enconvo Cloud 提供三款自有模型，依適用的工作命名：

| 模型 | 適用場景 |
| --- | --- |
| **Enconvo Fast** | 快速回應：簡短解答、文字改寫、小型操作。它是 **Enconvo Cloud Plan** 預設啟動的模型，也是 AI 指令的預設模型。 |
| **Enconvo Balanced** | 包含數個步驟的日常工作。 |
| **Enconvo Ultra** | 需要深度推理的困難任務。 |

這三款模型會排在 **Enconvo Cloud Plan** 清單最前面，而 [Auto Route](/zh-hant/providers/auto-route) 也會使用它們作為預設路由。

## 在選擇器中尋找模型

**Enconvo Cloud Plan** 清單會依供應商分組顯示模型：最上方是 Enconvo 自家模型，接著是 Anthropic、OpenAI、Google 與其他供應商，並標示各自的數量。每個供應商會顯示最新的四款模型；點擊**顯示更早的 N 個模型**即可查看其餘模型。搜尋會列出所有符合的結果，且你聊天正在使用的模型永遠都會顯示出來。Claude 系列模型會省略「Claude」前綴，例如 **Sonnet 5.5** 與 **Opus 5.5**。

在聊天視窗的模型選擇器中，Cloud 模型可能會帶有標籤：

| 標籤 | 意義 |
| --- | --- |
| **New** | 最近 14 天內新增。 |
| 折扣標記，例如 **50% OFF** | 該模型目前享有優惠價。將游標移至該列或使用方向鍵選取即可查看原價。 |
| **免費版** | 此模型不消耗點數。 |
| **預覽** | 模型的早期預覽版本。 |
| 日期 | 該模型從 Enconvo Cloud 下線的日期。 |

標籤由 Enconvo Cloud 端設定，因此不需更新應用程式就會自動更新。

## 點數與用量

不同模型消耗的點數不同。設定頁面會在每個模型與服務供應商旁標示 Cloud 價格，以及你方案包含的項目（例如本月剩餘的免費分鐘數）。請參閱 [Cloud Plan](https://www.enconvo.com/cloud-plan) 與 [Cloud pricing](https://www.enconvo.com/cloud-pricing) 頁面了解目前的方案與費率。若要查看已消耗的點數，請開啟**設定 → 點數用量**。

預設模型 [Auto Route](/zh-hant/providers/auto-route) 會在 Enconvo Cloud 模型上運行。為每則訊息挑選路由是免費的，實際回答的該模型才會消耗點數。

部分 Cloud 服務對所有已登入帳號免費開放：

- 使用 **Enconvo Cloud** 與 **DeepSeek (Enconvo Cloud)** 進行網頁搜尋。參閱[網頁搜尋](/zh-hant/ai/web-search)。
- 使用 **Enconvo Cloud Fast** 進行語音辨識。參閱[語音辨識](/zh-hant/ai/speech-recognition)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 請求要求你登入 | 在**設定 → 帳號**底下登入。 |
| 請求因點數或餘額錯誤而失敗 | 檢查**設定 → 點數用量**，並前往 [Cloud Plan](https://www.enconvo.com/cloud-plan) 頁面確認方案狀態。 |
| 清單中缺少某個模型 | 選擇器只會顯示你方案包含的模型。點擊**模型名稱**旁的**重新整理**。 |

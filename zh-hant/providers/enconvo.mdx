Enconvo Cloud 透過你的 Enconvo 帳號，提供多家公司的模型，以及語音、圖片、影片與網路工具。無需管理 API 金鑰：請求使用你方案的點數。這是最快上手的方式。

## 設定

<Steps>
  <Step title="登入">
    登入你的 Enconvo 帳號。請參閱[帳號](/zh-hant/configuration/account)。
  </Step>
  <Step title="選擇 Enconvo Cloud">
    開啟你想使用之功能的設定頁面，例如 **AI 模型**、**文字轉語音** 或 **圖片生成**，並選擇標示為 **Enconvo Cloud** 或 **Enconvo Cloud Plan** 的服務供應商。
  </Step>
  <Step title="挑選模型或語音">
    選擇模型或語音，並執行一個簡短的請求。
  </Step>
</Steps>

每個功能各有自己的服務供應商選擇。為聊天選擇 Enconvo Cloud，並不會切換語音、圖片、影片、嵌入、重新排序或網路工具；請在你想要的地方分別設定。

## Enconvo 自家的模型

Enconvo Cloud 有三個自家的模型，依其適合的工作命名：

| 模型 | 用途 |
| --- | --- |
| **Enconvo Fast** | 快速回合：簡短回答、改寫、小動作。它是 **Enconvo Cloud Plan** 起始使用的模型，也是 AI 指令的預設模型。 |
| **Enconvo Balanced** | 有幾個步驟的日常工作。 |
| **Enconvo Ultra** | 需要深度推理的困難任務。 |

它們列在 **Enconvo Cloud Plan** 下的最前面，[自動路由](/zh-hant/providers/auto-route)的預設路由也使用它們。

## 在挑選器中尋找模型

**Enconvo Cloud Plan** 清單依廠商將模型分組：先是 Enconvo 自家的模型，然後是 Anthropic、OpenAI、Google 與其他廠商，每個都附有數量。每個廠商顯示其最新的四個模型；點按 **顯示 N 個較早的模型** 可查看其他模型。搜尋會列出所有符合的項目，而你的聊天所使用的模型一律會顯示。Claude 模型在列出時沒有「Claude」前綴，例如 **Sonnet 5.5** 與 **Opus 5.5**。

在聊天視窗的模型挑選器中，雲端模型可能帶有標籤：

| 標籤 | 意義 |
| --- | --- |
| **新增** | 最近 14 天內新增。 |
| 折扣，例如 **50% OFF** | 該模型目前價格較低。將游標指向該列，或用方向鍵移到該列，即可查看原價。 |
| **免費版** | 該模型不使用點數。 |
| **預覽** | 該模型的早期版本。 |
| 日期 | 該模型離開 Enconvo Cloud 的日期。 |

標籤由 Enconvo Cloud 設定，因此不需 App 更新就會變動。

## 點數與用量

不同模型花費的點數不同。設定會在每個模型與服務供應商旁顯示雲端價格，並顯示你的方案所含內容，例如你本月剩餘的免費分鐘數。目前的方案與費率，請參閱[雲端方案](https://www.enconvo.com/cloud-plan)與[雲端價格](https://www.enconvo.com/cloud-pricing)頁面。若要查看你的用量，請開啟 **設定 → 點數用量**。

[自動路由](/zh-hant/providers/auto-route)這個預設模型，在 Enconvo Cloud 模型上執行。為每則訊息挑選路由是免費的；回答的模型則會使用點數。

部分雲端服務對每個已登入的帳號都是免費的：

- 使用 **Enconvo Cloud** 與 **DeepSeek (Enconvo Cloud)** 的網頁搜尋。請參閱[網頁搜尋](/zh-hant/ai/web-search)。
- 使用 **Enconvo Cloud Fast** 的語音辨識。請參閱[語音辨識](/zh-hant/ai/speech-recognition)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 請求要求你登入 | 在 **設定 → 帳號** 下登入。 |
| 請求因點數或餘額錯誤而失敗 | 檢查 **設定 → 點數用量**，然後到[雲端方案](https://www.enconvo.com/cloud-plan)頁面檢查你的方案。 |
| 找不到某個模型 | 挑選器會顯示你的方案所含的內容。請點按 **模型名稱** 旁的 **重新整理**。 |

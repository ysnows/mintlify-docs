服務供應商是 Enconvo 各項功能背後的服務：回答聊天的模型、朗讀的語音、搜尋網路的引擎。你可以為每項功能分別選擇一個服務供應商，也可以混搭使用。

下方影片會在兩分鐘內帶你瀏覽 **設定 → AI 模型**：Auto Route、Cloud 方案、使用 ChatGPT、Claude、GitHub Copilot、Antigravity 或 Grok 方案登入、API 金鑰、Mac 上的模型、Ollama 與 LM Studio，以及新增自訂服務供應商。

## 選擇連線方式

| 如果你想 | 使用 | 從這裡開始 |
| --- | --- | --- |
| 立即開始，無需任何金鑰 | 透過你的 Enconvo 帳號使用 Enconvo Cloud | [Enconvo Cloud](/zh-hant/providers/enconvo) |
| 讓 Enconvo 為每則訊息挑選模型 | 預設模型 Auto Route | [Auto Route](/zh-hant/providers/auto-route) |
| 使用你已經付費的方案 | 使用 ChatGPT、Claude、Grok、Mistral、GitHub Copilot 或 Antigravity 登入 | [使用方案登入](#使用方案登入) |
| 直接向服務供應商付費 | 你自己的 API 金鑰 | [常用服務供應商](#常用服務供應商) |
| 用一個金鑰存取多家公司的模型 | 閘道服務，例如 OpenRouter 或 PipeLLM | [OpenRouter](/zh-hant/providers/openrouter)、[PipeLLM](/zh-hant/providers/pipellm) |
| 把聊天留在你的 Mac 上 | 本機模型 | [本機模型](/zh-hant/ai/local-llm) |
| 使用你已在 Ollama 或 LM Studio 中執行的模型 | **Ollama** 或 **LM Studio** 服務供應商 | [Ollama](/zh-hant/providers/ollama)、[LM Studio](/zh-hant/providers/lm-studio) |
| 在 iPhone App 自己的聊天中使用模型 | 手機聊天 | [手機聊天](/zh-hant/integrations/iphone-phone-chats) |

## 選擇你的聊天模型

<Steps>
  <Step title="開啟 AI 模型">
    開啟 **設定 → AI 模型**。中間欄列出了每個服務供應商：最上方是 **Auto Route** 和 **Enconvo Cloud 方案**，接著是各家廠商、本機模型及其他所有服務供應商。
  </Step>
  <Step title="挑選服務供應商並連線">
    點擊一個服務供應商。如果它同時提供兩種方式，可選擇 **API 金鑰** 以用自己的金鑰按請求付費，或選擇訂閱選項（例如 **ChatGPT 訂閱**）登入並使用你方案包含的額度。
  </Step>
  <Step title="選擇模型">
    在 **模型名稱** 下挑選一個模型，如果該服務供應商支援，也可以選擇 **推理強度**。
  </Step>
  <Step title="設為預設">
    點擊 **設為預設**。沒有各自指定模型的聊天和功能現在都會使用它。
  </Step>
</Steps>

若要新增未列出的服務，請點擊列表底部的 **新增供應商**，並選擇 **相容 OpenAI** 或 **相容 Anthropic**。

你可以隨時切換服務供應商；沒有任何設定會把你的聊天綁定在單一家公司上。

**設定 → AI 模型** 的頂端還包含 **任務模型**（用於產生聊天標題和建議的小型模型），以及 **後備**（當聊天的模型無法使用時接手的備援模型）。參閱[選擇模型](/zh-hant/ai/model-selection-guide)。

## 為每項功能設定服務供應商

每項功能都有各自的設定頁面：**AI 模型**、**文字轉語音**、**網頁搜尋**、**圖片生成**、**影片生成**、**擷取網頁** 與 **OCR**。語音辨識則分別有 **聽寫模型**、**錄音模型**、**語音轉寫模型** 與 **字幕產生模型** 的設定頁面。嵌入模型與重排序模型在知識庫中設定。

更改聊天模型不會影響你的語音、圖片或搜尋服務供應商，請在各自的位置分別設定。

## 設定檔

每個服務供應商設定檔保存一組金鑰或登入資訊。在服務供應商頁面上點擊 **新增供應商** 可以保留第二組設定，例如工作帳號。部分設定檔會服務多項功能：一個 OpenAI 設定檔同時涵蓋聊天、嵌入、文字轉語音、圖片與轉寫，因此修改它的金鑰會同時更新這幾項功能。參閱[憑證與設定檔](/zh-hant/configuration/credentials)。

預設模型在哪裡設定，以及每個聊天如何各自保留模型，請參閱[選擇模型](/zh-hant/ai/model-selection-guide)。

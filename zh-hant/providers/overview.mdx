服務供應商是 Enconvo 功能背後的服務：回答聊天的模型、朗讀的語音、搜尋網路的引擎。你為每個功能各選一個，也可以混合搭配。

下方影片用 2 分鐘介紹 **設定 → AI 模型**：自動路由、雲端方案、使用 ChatGPT、Claude、GitHub Copilot、Antigravity 或 Grok 方案登入、API 金鑰、你 Mac 上的模型、Ollama 與 LM Studio，以及新增你自己的服務供應商。

## 選擇連接方式

| 如果你想要 | 使用 | 從這裡開始 |
| --- | --- | --- |
| 立即開始，無需金鑰 | 透過你的 Enconvo 帳號使用 Enconvo Cloud | [Enconvo Cloud](/zh-hant/providers/enconvo) |
| 讓 Enconvo 為每則訊息挑選模型 | 自動路由，也就是預設模型 | [自動路由](/zh-hant/providers/auto-route) |
| 使用你已付費的方案 | 使用 ChatGPT、Claude、Grok、Mistral、GitHub Copilot 或 Antigravity 登入 | [使用方案登入](#使用方案登入) |
| 直接向服務供應商付費 | 你自己的 API 金鑰 | [熱門服務供應商](#熱門服務供應商) |
| 用一組金鑰使用多家公司的模型 | OpenRouter 或 PipeLLM 這類閘道 | [OpenRouter](/zh-hant/providers/openrouter)、[PipeLLM](/zh-hant/providers/pipellm) |
| 讓聊天留在你的 Mac 上 | 本機模型 | [本機模型](/zh-hant/ai/local-llm) |
| 使用你已在 Ollama 或 LM Studio 中執行的模型 | **Ollama** 或 **LM Studio** 服務供應商 | [Ollama](/zh-hant/providers/ollama)、[LM Studio](/zh-hant/providers/lm-studio) |
| 在 iPhone App 自己的聊天中使用模型 | 手機聊天 | [手機聊天](/zh-hant/integrations/iphone-phone-chats) |

## 選擇你的聊天模型

<Steps>
  <Step title="開啟 AI 模型">
    開啟 **設定 → AI 模型**。中間欄會列出所有服務供應商：頂端是 **自動路由** 與 **Enconvo Cloud Plan**，接著是各家公司、本機模型，以及所有其他服務供應商。
  </Step>
  <Step title="選擇服務供應商並連接">
    點按一個服務供應商。若它兩者皆提供，請選擇 **API 金鑰**，以你自己的金鑰向服務供應商按請求付費；或選擇訂閱選項（例如 **ChatGPT 訂閱**），登入後使用你的方案所含內容。
  </Step>
  <Step title="選擇模型">
    在 **模型名稱** 下選擇模型；若服務供應商提供，也可選擇 **推理強度**。
  </Step>
  <Step title="設為預設">
    點按 **設為預設**。沒有指定自己模型的聊天與功能，現在都會使用它。
  </Step>
</Steps>

若要新增未列出的服務，請點按清單底部的 **新增供應商**，並選擇 **相容 OpenAI** 或 **相容 Anthropic**。

你可以隨時切換服務供應商；你的聊天不會綁定在某一家公司。

**設定 → AI 模型** 頂端還有 **任務模型**（用於聊天標題與建議背後的小型模型），以及 **後備**（當聊天的模型無法使用時接手的備用模型）。請參閱[選擇模型](/zh-hant/ai/model-selection-guide)。

## 為每個功能設定服務供應商

每個功能都有自己的設定頁面：**AI 模型**、**文字轉語音**、**網頁搜尋**、**圖片生成**、**影片生成**、**擷取網頁** 與 **OCR**。語音辨識則有獨立的頁面：**聽寫模型**、**錄音模型**、**語音轉寫模型** 與 **字幕產生模型**。嵌入與重新排序則在知識庫中設定。

選擇聊天模型不會改變你的語音、圖片或搜尋服務供應商。請在你想要的地方分別設定。

## 設定檔

一個服務供應商設定檔保存一組金鑰或登入。在服務供應商的頁面上點按 **新增供應商**，即可再保留一個，例如工作帳號。有些設定檔服務多個功能：一個 OpenAI 設定檔涵蓋聊天、嵌入、文字轉語音、圖片與語音轉寫，因此更改它的金鑰會同時更改全部。請參閱[憑證與設定檔](/zh-hant/configuration/credentials)。

預設模型的設定位置，以及每個聊天如何保有自己的模型，請見[選擇模型](/zh-hant/ai/model-selection-guide)。

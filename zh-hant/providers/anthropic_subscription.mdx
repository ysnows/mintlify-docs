---
title: "Claude 訂閱"
description: "登入你的 Claude 方案，無須 API 金鑰即可在 Enconvo 中使用 Claude 模型。"
---

如果你已經付費訂閱 Claude，可以直接登入該方案來使用，而不必另外建立 API 金鑰。請求會消耗你訂閱方案的額度，Enconvo 也會顯示還剩多少額度可用。

## 連線設定

<Steps>
  <Step title="選擇訂閱方案">
    開啟 **設定 → AI 模型 → Anthropic**。在 **身分驗證** 下方選擇 **Claude 訂閱**。
  </Step>
  <Step title="登入">
    點選 **連接**，在瀏覽器中登入你的 Claude 帳號並允許存取。瀏覽器顯示完成後再回到 Enconvo。
  </Step>
  <Step title="挑選模型">
    確認帳號卡片顯示的是正確帳號，在 **模型名稱** 中選擇一個模型，然後送出一則簡短訊息。
  </Step>
</Steps>

## 查看你的用量

帳號卡片會顯示五小時與每週額度的剩餘比例（**剩餘 %**），當 Anthropic 有回報各模型用量時也會分模型顯示，並標明各自的重設時間。擁有獨立上限的模型（例如每週的 Claude Fable 額度）會並列顯示於旁。對話的模型選擇器中也能看到這張卡片。開啟卡片選單可進行以下操作：

- **重新整理用量**：取得最新的額度數字。
- **重新連線**：重新登入，例如要切換帳號時使用。

當 Anthropic 未回報用量時，卡片會顯示 **無法取得用量** 並說明原因。這不代表該方案沒有用量限制。

### 使用贈送的重置

當 Claude 贈送你免費的額度重設次數時，卡片會列出 **贈送的重置**：顯示剩餘次數與到期時間。點選 **使用重置** 並確認，即可立即補滿額度。重設一旦執行便無法復原。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 登入失敗 | 閱讀 Anthropic 傳回的錯誤訊息，然後再次點選 **連接**。請確認你登入的是擁有訂閱方案的帳號。 |
| 對話提示已達到用量上限 | 訊息會說明觸及的是哪個上限以及何時重設。如果卡片上列有贈送的重置次數可以直接使用，否則請等待重設，或暫時將 **身分驗證** 切換為 **API 金鑰**。 |
| Enconvo 請你稍後再試 | Anthropic 當時正忙於更新登入權杖。稍等片刻後重新送出即可，不需要重新連線。 |
| 找不到某個模型 | 可用模型取決於你的訂閱方案。請點選 **模型名稱** 旁的 **重新整理**。 |

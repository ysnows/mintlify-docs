---
title: "Claude 訂閱"
description: "使用你的 Claude 方案登入，即可在 Enconvo 中使用 Claude 模型，無需 API 金鑰。"
---

如果你有付費使用 Claude，請用該方案登入，而不必建立 API 金鑰。請求會使用你方案的額度，Enconvo 會顯示剩餘多少。

## 連接

<Steps>
  <Step title="選擇訂閱">
    開啟 **設定 → AI 模型 → Anthropic**。在 **身分驗證** 下，選擇 **Claude 訂閱**。
  </Step>
  <Step title="登入">
    點按 **連接**，在瀏覽器中登入你的 Claude 帳號並允許存取。待瀏覽器顯示完成後，回到 Enconvo。
  </Step>
  <Step title="挑選模型">
    確認帳號卡片顯示的是正確的帳號，在 **模型名稱** 中選擇模型，並傳送一則簡短的訊息。
  </Step>
</Steps>

## 查看你的用量

帳號卡片會顯示五小時與每週額度還剩多少（**% 剩餘**）；當 Anthropic 有回報時會按模型顯示，同時也顯示各自何時重設。擁有自己額度的模型，例如每週的 Claude Fable 額度，會顯示在其他額度旁邊。聊天的模型挑選器中也會出現同一張卡片。開啟卡片的選單可使用：

- **重新整理用量**：取得最新的數字。
- **重新連線**：重新登入，例如切換帳號。

當 Anthropic 沒有回報用量時，卡片會顯示 **無法取得用量** 及原因。這並不表示該方案沒有上限。

### 使用免費重置

當 Claude 提供你免費的額度重設時，卡片會列出 **贈送的重置**：你還剩幾次以及何時到期。點按 **使用重置** 並確認，即可立即補滿你的額度。重置無法復原。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 登入失敗 | 閱讀 Anthropic 給出的錯誤訊息，然後再次點按 **連接**。請確認你登入的是擁有該方案的帳號。 |
| 聊天顯示已達用量上限 | 訊息會指出是哪個上限以及何時重設。若卡片列出免費重置，請使用它，或稍候，或暫時將 **身分驗證** 切換為 **API 金鑰**。 |
| Enconvo 要求你稍後再試 | Anthropic 正忙於更新登入狀態。請稍候片刻再傳送；你不需要重新連線。 |
| 找不到某個模型 | 模型取決於你的方案。請點按 **模型名稱** 旁的 **重新整理**。 |

title: "MiniMax"
description: "使用你自己的 MiniMax API 金鑰在 Enconvo 中與 MiniMax 模型對話。"
---

MiniMax 透過 API 金鑰提供模型服務。將你的金鑰加入 Enconvo，即可在對話、代理程式與 AI 指令中使用這些模型。MiniMax 會依實際用量向你自己的帳號計費。它在設定中列為 **Minimax AI**。

## 連線設定

<Steps>
  <Step title="取得 API 金鑰">
    前往 [MiniMax 使用者中心](https://platform.minimax.io/user-center/basic-information)建立一組金鑰。
  </Step>
  <Step title="加入至 Enconvo">
    開啟 **設定 → AI 模型 → Minimax AI**。在 **身分驗證** 下方將金鑰貼入 **API 金鑰**，然後點選 **驗證**。
  </Step>
  <Step title="挑選模型">
    在 **模型名稱** 中挑選一個模型並送出簡短訊息。收到回覆即代表連線成功。
  </Step>
</Steps>

若想保留第二組 MiniMax 金鑰（例如一組專門用於工作），請點選 **新增供應商** 來建立另一份設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的 **重新整理** 可重新載入列表；**管理模型**（齒輪圖示）可新增或還原模型。 |

若要在單一對話中改用不同模型，從該對話的模型選擇器挑選即可。

MiniMax 也提供文字轉語音服務供應商，可在 **設定 → 文字轉語音** 中選擇。

模型詳情與用量限制請參閱 [MiniMax API 參考文件](https://platform.minimax.io/docs/api-reference/api-overview)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| **驗證** 失敗 | 重新貼上完整金鑰，並檢查它在你的 MiniMax 帳號中是否處於啟用狀態。 |
| 找不到某個模型 | 點選 **模型名稱** 旁的 **重新整理** 重新載入清單。若要自行新增模型，請使用 **管理模型**。 |
| 圖片或工具呼叫失敗 | 請改選支援圖片輸入或工具呼叫的模型。 |
| 速率或用量上限錯誤 | 檢查你 MiniMax 帳號中的用量與上限，或暫時切換到其他服務供應商。 |
| 回覆速度較慢 | 改試較小的模型、縮短輸入內容，或調低推理強度。 |

---
title: "Soniox"
description: "在 Enconvo 中使用 Soniox 語音轉文字，進行聽寫、錄音和檔案語音轉寫。"
---

Soniox 能即時以及從檔案將語音轉成文字，支援多種語言，並能在你錄音時翻譯即時字幕。你可以透過 Enconvo Cloud 免金鑰使用，也可以使用你自己的 Soniox API 金鑰。

<Note>
**Soniox (Enconvo Cloud)** 不需要 API 金鑰，且 Cloud Plan、Lifetime 和試用會員可免費使用 Soniox 聽寫。
</Note>

## 連接

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="選擇供應商">
        開啟**設定 → 聽寫模型**並選擇 **Soniox (Enconvo Cloud)**。
      </Step>
      <Step title="測試">
        說一句簡短的話進行聽寫。文字應該會隨著你說話出現。
      </Step>
    </Steps>
  </Tab>
  <Tab title="你自己的 API 金鑰">
    <Steps>
      <Step title="取得 API 金鑰">
        在 [Soniox Console](https://console.soniox.com) 中開啟你的專案並建立 API 金鑰。
      </Step>
      <Step title="加入 Enconvo">
        開啟**設定 → 聽寫模型**並選擇 **Soniox**。將金鑰貼到 Soniox 憑證中，然後按一下**驗證**。
      </Step>
      <Step title="測試">
        說一句簡短的話進行聽寫。文字應該會隨著你說話出現。
      </Step>
    </Steps>
  </Tab>
</Tabs>

若也要將 Soniox 用於錄音或檔案，請在**設定 → 錄音模型**或**設定 → 語音轉寫模型**下選擇它。每個頁面各自保留自己的選擇。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型** | Soniox 模型。**Soniox STT Realtime v5**（預設）等即時模型會在你說話時寫出文字；**Soniox STT Async v5** 等非同步模型則用來轉寫已完成的檔案。請參閱 [Soniox 模型](https://soniox.com/docs/stt/models)。 |
| **Language Hints** | 優先辨識的語言，預設為英文和中文。如果你說話時會切換語言，可以加入多種語言。 |
| **即時翻譯** | 在你錄音時翻譯即時字幕。儲存的錄音會保留原始語言的逐字稿。預設為關閉。 |
| **來源語言** | 音訊的語言。選擇**自動**會讓 Soniox 自行偵測。 |
| **Translate To** | 翻譯後字幕的語言。 |
| **Speak Translation** | 以你的預設語音朗讀翻譯後的字幕。預設為關閉。 |

Soniox 也有文字轉語音供應商，可使用你自己的金鑰或透過 Enconvo Cloud，位於**設定 → 文字轉語音**下。

Soniox 在雲端處理音訊。若要讓語音留在你的 Mac 上，請改用 Parakeet MLX、Qwen3 MLX 或 Whisper MLX 等本機供應商。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 從 Soniox Console 重新複製金鑰，不要帶有多餘的空格，並確認它屬於正確的專案。 |
| 說話時沒有出現文字 | 請選擇即時模型，然後重新開始聽寫。 |
| 辨識出的字詞語言不對 | 將 **Language Hints** 設為你實際使用的語言。 |
| 檔案沒有產生逐字稿 | 請試試 MP3、WAV、FLAC 或 M4A 等常見格式，並檢查你的 Soniox 用量和帳單。 |

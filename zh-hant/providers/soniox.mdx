---

Soniox 支援多國語言的即時語音轉文字與檔案轉寫，並能在錄音的同時即時翻譯字幕。你可以不需金鑰直接透過 Enconvo Cloud 使用它，或是搭配你自己的 Soniox API 金鑰。

<Note>
**Soniox (Enconvo Cloud)** 不需要 API 金鑰，而且對於 Cloud 方案、終身授權與試用會員，Soniox 聽寫皆免費使用。
</Note>

## 連接

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="選擇服務供應商">
        開啟**設定 → 聽寫模型**，並選擇 **Soniox (Enconvo Cloud)**。
      </Step>
      <Step title="進行測試">
        使用聽寫唸出一句簡短的話。文字應該會在你說話的同時顯示出來。
      </Step>
    </Steps>
  </Tab>
  <Tab title="你自己的 API 金鑰">
    <Steps>
      <Step title="取得 API 金鑰">
        在 [Soniox Console](https://console.soniox.com) 中開啟你的專案並建立一組 API 金鑰。
      </Step>
      <Step title="加入 Enconvo">
        開啟**設定 → 聽寫模型**並選擇 **Soniox**。將金鑰貼入 Soniox 憑證欄位，然後點擊**驗證**。
      </Step>
      <Step title="進行測試">
        使用聽寫唸出一句簡短的話。文字應該會在你說話的同時顯示出來。
      </Step>
    </Steps>
  </Tab>
</Tabs>

若也想將 Soniox 用於錄音或檔案轉寫，請在**設定 → 錄音模型**或**設定 → 語音轉寫模型**中選擇它。每個頁面都會保留各自的選擇。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型** | 要使用的 Soniox 模型。即時模型如 **Soniox STT Realtime v5**（預設）會在你說話時即時輸出文字；非同步模型如 **Soniox STT Async v5** 則用來轉寫已完成的檔案。參閱 [Soniox 模型列表](https://soniox.com/docs/stt/models)。 |
| **語言提示** | 優先辨識的語言，預設為英文與中文。如果你在說話時會切換語言，可加入多種語言。 |
| **即時翻譯** | 在你錄音時同步翻譯即時字幕。儲存下來的錄音仍會保留原本語言的逐字稿。預設關閉。 |
| **來源語言** | 音訊本身的語言。選擇**自動**會由 Soniox 自動偵測。 |
| **目標語言** | 翻譯後字幕所使用的語言。 |
| **朗讀翻譯** | 使用你的預設語音朗讀翻譯後的字幕。預設關閉。 |

在**設定 → 文字轉語音**下，Soniox 也提供了文字轉語音服務供應商，可使用你自己的金鑰或透過 Enconvo Cloud 使用。

Soniox 會在雲端處理音訊。若希望語音資料留在你的 Mac 上，請改用本機服務供應商，例如 Parakeet MLX、Qwen3 MLX 或 Whisper MLX。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 從 Soniox Console 重新複製一次金鑰並確保沒有多餘空格，並確認它屬於正確的專案。 |
| 說話時沒有出現文字 | 選擇一個即時（realtime）模型，然後重新開始聽寫。 |
| 辨識出來的字詞語言不對 | 將**語言提示**設為你實際使用的語言。 |
| 檔案轉寫沒有產生逐字稿 | 改用常見格式（如 MP3、WAV、FLAC 或 M4A）試試，並檢查你的 Soniox 用量與帳單狀態。 |

---
title: "OpenRouter"
description: "在 Enconvo 中使用你自己的 OpenRouter API 金鑰與 OpenRouter 模型對話。"
---

OpenRouter 透過單一 API 金鑰即可路由存取來自多家公司的模型。將你的金鑰加入 Enconvo，就能在聊天、代理程式與 AI 指令中使用這些模型。OpenRouter 會直接向你自己的帳號計費。

## 連接

<Steps>
  <Step title="取得 API 金鑰">
    在 [OpenRouter](https://openrouter.ai/) 中建立一組金鑰。
  </Step>
  <Step title="加入 Enconvo">
    開啟**設定 → AI 模型 → OpenRouter**。在**身分驗證**下方將金鑰貼入 **API Key**，然後點擊**驗證**。
  </Step>
  <Step title="挑選模型">
    在**模型名稱**中選擇一個模型並傳送簡短的訊息。收到回覆即表示連線正常。
  </Step>
</Steps>

若想另外保留第二組 OpenRouter 金鑰（例如一組專門用於工作），可點擊**新增供應商**來建立另一個設定檔。

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型名稱** | 此服務供應商使用的模型。旁邊的**重新整理**可重新載入清單；**管理模型**（齒輪圖示）可手動加入或還原模型。 |
| **Google Search Tool** | 讓 Gemini 模型能依據 Google 搜尋結果提供回答。預設關閉。 |
| **URL Context Tool** | 讓 Gemini 模型能讀取你訊息中連結所指向的網頁內容。預設關閉。 |

若要在單一聊天中改用不同模型，可直接從該聊天的模型選擇器中挑選。

圖片與影片生成各自在**設定 → 圖片生成**與**設定 → 影片生成**下設有獨立的 OpenRouter 服務供應商設定。是否支援工具呼叫與圖片輸入則取決於你挑選的模型。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **驗證**失敗 | 重新貼上完整的金鑰，並檢查該金鑰在你的 OpenRouter 帳號中是否為啟用狀態。 |
| 清單中缺少某個模型 | 點擊**模型名稱**旁的**重新整理**來重新載入清單。若要自行加入模型，請使用**管理模型**。 |
| 圖片或工具呼叫失敗 | 請改選支援圖片輸入或工具呼叫的模型。 |
| 發生速率或用量上限錯誤 | 檢查你 OpenRouter 帳號中的用量與限額，或暫時切換至其他服務供應商。 |
| 回覆速度較慢 | 嘗試改用較小的模型、縮短輸入內容，或調低推理強度。 |

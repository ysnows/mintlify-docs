---
title: "Local LLM (MLX)"
description: "使用 Enconvo 內建的 MLX 引擎在你的 Mac 上執行語言模型。"
---

Local LLM 直接在 Mac 的 Apple Silicon 晶片上執行語言模型，不需要任何帳號或 API Key。模型下載完成後，與它的對話都會保留在你的 Mac 本機。此功能需要 macOS 15 或更新版本。

## 設定

<Steps>
  <Step title="開啟服務供應商">
    開啟 **設定 → AI 模型 → Local LLM (MLX)**。
  </Step>
  <Step title="選擇模型">
    開啟 **模型** 列表。Enconvo 會推薦適合你 Mac 規格的模型，你也可以搜尋 Hugging Face 上的其他模型。列表會優先顯示規模較大的模型。
  </Step>
  <Step title="下載模型">
    開始下載並等待完成。Enconvo 會先檢查可用的磁碟空間，若重新啟動或網路中斷，下載也會自動續傳。
  </Step>
  <Step title="測試模型">
    傳送一則簡短訊息。初次回覆時需要將模型載入記憶體，耗時會稍長一些。
  </Step>
</Steps>

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型** | 此服務供應商執行的本機模型。 |
| **思考** | 適用於具備思考模式的模型。**關閉**（預設）會直接回答；**開啟** 會先進行推理。**低**、**中** 與 **高** 可設定 gpt-oss 模型的推理長度；其他模型則將這三個選項視為 **開啟**。 |

若要查看本機模型佔用了多少記憶體與磁碟空間，或刪除某個模型，請開啟 **設定 → 本機模型**。當功能需要時，模型會再次自動載入。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 無法開始下載 | 請先釋出磁碟空間；Enconvo 在下載前會先檢查剩餘空間。 |
| 模型顯示 **未完成** | 因下載中斷而遺失部分檔案。請重新下載以完成，或將其刪除。 |
| 模型載入失敗或 Mac 變慢 | 改選較小的模型，或關閉其他高負載的 App。**設定 → 本機模型** 會顯示記憶體使用量。 |
| 回覆速度緩慢 | 改選較小的模型，或關閉 **思考**。 |
| 工具呼叫或圖片失敗 | 請選擇支援工具呼叫或圖片輸入的模型。 |

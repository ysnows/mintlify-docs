---
title: "本機 LLM（MLX）"
description: "使用 Enconvo 內建的 MLX 引擎，在你的 Mac 上執行語言模型。"
---

本機 LLM 在你 Mac 的 Apple 晶片上執行語言模型，不需要帳號或 API 金鑰。模型下載完成後，與它的聊天都會留在你的 Mac 上。需要 macOS 15 或更新版本。

## 設定

<Steps>
  <Step title="開啟供應商">
    開啟**設定 → AI 模型 → 本機 LLM（MLX）**。
  </Step>
  <Step title="選擇模型">
    開啟**模型**清單。Enconvo 會建議適合你 Mac 的模型，你也可以在 Hugging Face 上搜尋其他模型。清單會先顯示最大的模型。
  </Step>
  <Step title="下載模型">
    開始下載並等待完成。Enconvo 會先檢查可用的磁碟空間，下載在重新啟動或網路中斷後會自動接續。
  </Step>
  <Step title="測試">
    傳送一則簡短訊息。模型載入記憶體時，第一次回覆會比較久。
  </Step>
</Steps>

## 模型與選項

| 設定 | 作用 |
| --- | --- |
| **模型** | 此供應商執行的本機模型。 |
| **思考** | 適用於具備思考模式的模型。**關閉**（預設）會立即回答；**開啟**會先推理。**低**、**中等**和**高**可設定 gpt-oss 模型推理的時間長短；其他模型會將它們視為**開啟**。 |

若要查看本機模型佔用多少記憶體和磁碟空間，或要刪除某個模型，請開啟**設定 → 本機模型**。當功能需要時，模型會再次載入。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 下載無法開始 | 請釋出一些磁碟空間；Enconvo 會在下載前檢查。 |
| 某個模型顯示**不完整** | 因為下載中途中斷，它缺少部分檔案。請重新下載以完成，或將它刪除。 |
| 模型無法載入，或 Mac 變慢 | 請選擇較小的模型，或關閉其他耗用大量資源的 App。**設定 → 本機模型**會顯示記憶體用量。 |
| 回覆很慢 | 請選擇較小的模型，或將**思考**關閉。 |
| 工具或圖片無法使用 | 請選擇支援工具呼叫或圖片輸入的模型。 |

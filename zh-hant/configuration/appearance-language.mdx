---
title: "語言、外觀與設定搜尋"
description: "選擇 Enconvo 的介面語言、調整對比度與聊天寬度，並透過搜尋或詢問 AI 找到任何設定。"
---

**設定 → 一般** 包含改變 Enconvo 外觀與使用語言的選項。你可以透過本頁切換介面語言、讓 Enconvo 更容易閱讀，並在不知道設定位置的情況下找到它。

## 變更介面語言

1. 開啟 **設定 → 一般**，找到 **語言**。
2. 在 **App 語言** 中選擇語言。**跟隨系統** 會使用你 Mac 的語言。
3. Enconvo 會提議將你的 **回覆語言** 一併改成相同語言。如果你希望代理程式也用新語言回覆，請接受。

**App 語言** 會變更這台裝置上的選單、按鈕與設定：英文、簡體中文、繁體中文、日文、韓文、西班牙文、德文、法文、義大利文、葡萄牙文、烏克蘭文與俄文。iPhone 與 Android App 在它們自己的設定中提供相同的語言。

**回覆語言** 則是獨立的：代理程式、語音通話與虛擬形象會以它回覆，翻譯工具也會翻譯成這個語言。

## 調整 Enconvo 的外觀

開啟 **設定 → 一般**，找到 **外觀**。

| 設定 | 變更內容 |
| --- | --- |
| **對比度** | 讓整個 Enconvo 的邊框、分隔線與次要文字更明顯或更柔和。 |
| **聊天寬度** | 在大視窗中，訊息與輸入框能延伸到多寬：**適中**、**寬** 或 **全寬**。 |
| **程式碼自動換行** | 讓程式碼區塊中的長行自動換行，而不是橫向捲動。 |

## 尋找設定

在設定側邊欄頂端的搜尋欄位中輸入。符合的設定會隨著輸入顯示；點按其中一項即可前往。

若要改為詢問有關設定的問題：

1. 在搜尋欄位中輸入問題，然後按下 Return，或點按 **詢問 AI**。
2. 答案會在側邊欄旁開啟，並附上它所提到設定的卡片。
3. 點按卡片上的 **在設定中顯示** 即可前往該設定，或直接在卡片中開啟或關閉開關。
4. 在 **繼續提問…** 中輸入後續問題，或點按 **在聊天中繼續**，在聊天視窗中繼續。

詢問 AI 使用你的預設 AI 模型。如果尚未設定，它會提供 **開啟 AI 模型設定**。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 切換語言後，部分文字仍是英文 | 更新 Enconvo，然後透過選單列選單中的 **意見回饋** 回報剩下的部分。 |
| 代理程式使用的回覆語言與介面不同 | 在 **設定 → 一般 → 語言** 中設定 **回覆語言**。 |
| 詢問 AI 沒有回答 | 在 **設定 → AI 模型** 中設定模型。 |
| 文字難以閱讀 | 在 **設定 → 一般 → 外觀** 中提高 **對比度**。 |

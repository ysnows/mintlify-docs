title: "語言、外觀與設定搜尋"
description: "選擇 Enconvo 的介面語言、調整對比度與聊天寬度，並透過搜尋或詢問 AI 快速找到任何設定。"
---

**設定 → 一般** 中包含變更 Enconvo 外觀與使用語言的相關選項。使用本頁說明來切換介面語言、讓 Enconvo 更容易閱讀，以及在不確定設定位置時快速找到設定。

## 變更介面語言

1. 開啟 **設定 → 一般** 並找到 **語言**。
2. 在 **App 語言** 中選擇一種語言。**跟隨系統** 會使用你 Mac 的系統語言。
3. Enconvo 會詢問是否一併變更 **回覆語言** 以保持一致。若希望代理程式也改用新語言回覆，請選擇接受。

**App 語言** 會變更此裝置上的選單、按鈕與設定：支援英文、簡體中文、繁體中文、日文、韓文、西班牙文、德文、法文、義大利文、葡萄牙文、烏克蘭文與俄文。iPhone 與 Android App 也在各自的設定中提供相同的語言選項。

**回覆語言** 則是獨立設定：代理程式、語音通話與虛擬形象會使用此語言回覆，而 Translator 也會翻譯成此語言。

## 調整 Enconvo 外觀

開啟 **設定 → 一般** 並找到 **外觀**。

| 設定 | 變更內容 |
| --- | --- |
| **對比度** | 增強或柔和化 Enconvo 中的邊框、分隔線與次要文字。 |
| **聊天寬度** | 在大型視窗中訊息與輸入框可擴展的寬度：**適中**、**寬** 或 **全寬**。 |
| **程式碼自動換行** | 讓程式碼區塊中的過長行自動換行，而不需水平捲動。 |

## 尋找設定

在設定側邊欄頂端的搜尋欄中輸入關鍵字。相符的設定會在輸入時即時顯示；點擊即可前往。

若想改為針對設定提出問題：

1. 在搜尋欄中輸入問題，然後按下 Return 或點擊 **詢問 AI**。
2. 回答會開啟在側邊欄旁，並附上它所提及設定的卡片。
3. 點擊卡片中的 **在設定中顯示** 即可前往該設定，或直接在卡片上開啟或關閉開關。
4. 在 **提出後續問題…** 中輸入追問，或點擊 **在聊天中繼續**，將對話延續至聊天視窗中。

「詢問 AI」會使用你的預設 AI 模型。若尚未設定任何模型，它會提示 **開啟 AI 模型設定**。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 切換語言後仍有部分文字維持英文 | 更新 Enconvo，然後透過選單列選單中的 **意見回饋** 回報尚未翻譯的文字。 |
| 代理程式回覆的語言與介面語言不同 | 前往 **設定 → 一般 → 語言** 設定 **回覆語言**。 |
| 「詢問 AI」沒有回應 | 在 **設定 → AI 模型** 中設定一個模型。 |
| 文字難以閱讀 | 在 **設定 → 一般 → 外觀** 中提高 **對比度**。 |

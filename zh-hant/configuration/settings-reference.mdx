以下依側邊欄順序列出 Enconvo 設定側邊欄中的每個項目，並附上對應的說明指南。若要開啟設定，請點擊 Enconvo 選單列圖示並選擇 **設定**。若要跳至某個項目，請在 **搜尋設定** 中輸入名稱，或輸入問題並按下 Return 讓 AI 告訴你設定所在的位置。

各指南中的設定路徑會使用下方名稱，例如 **設定 → SmartBar**。

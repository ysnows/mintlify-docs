title: "設定參考"
description: "設定側邊欄中的每個項目、它控制什麼，以及說明它的指南。"
---

Enconvo 設定側邊欄中的每個項目，依側邊欄順序排列，並附上說明它的指南。若要開啟設定，請點擊 Enconvo 選單列圖示並選擇 **設定**。若要跳到某個項目，請在 **搜尋設定** 中輸入它的名稱，或輸入問題並按 Return，詢問 AI 某項設定在哪裡。

各指南都使用下列名稱來標示設定路徑，例如 **設定 → SmartBar**。

## 全域服務供應商設定

| 項目 | 它控制什麼 |
| --- | --- |
| [AI 模型](/zh-hant/providers/overview) | 聊天模型、自動路由、供應商金鑰與方案登入，以及用於背景工作的 **任務模型** 和在對話模型失敗時使用的 **後備** 模型。 |
| [文字轉語音](/zh-hant/ai/text-to-speech) | 朗讀文字的聲音，以及聲音複製。 |
| [網頁搜尋](/zh-hant/ai/web-search) | 代理程式使用的搜尋服務。 |
| [圖像生成](/zh-hant/ai/image-generation) | 圖像模型。 |
| [影片生成](/zh-hant/ai/video-generation) | 影片模型。 |
| [網頁擷取](/zh-hant/ai/web-fetch) | 網頁的讀取方式。 |
| [OCR](/zh-hant/ai/ocr) | 從圖像中讀取文字的方式。 |

Enconvo 將你的資料儲存在你的 Mac 上，並針對你選擇的功能與服務供應商使用線上服務。請求送往何處，取決於功能、你選擇的服務供應商、你開啟的工具，以及你連接的整合。本頁說明每一種流向及其控制方式。

## 你的內容送往何處

| 動作 | 傳送的內容與目的地 |
| --- | --- |
| 雲端 AI 聊天 | 你的提示詞、對話上下文與你加入的附件，傳送給模型服務供應商 |
| Enconvo Cloud 內容檢查（自 2026 年 11 月 14 日起） | 你剛寫下的文字，會先傳送給 OpenAI 的審核模型，之後雲端模型才會收到 |
| 雲端語音辨識 | 擷取的音訊，傳送給你選擇的語音服務 |
| 雲端文字轉語音 | 文字，傳送給你選擇的語音服務 |
| 雲端嵌入或重新排序 | 檢索所需的文件與查詢內容 |
| 網頁搜尋或擷取 | 搜尋查詢或 URL，傳送給搜尋服務或網站 |
| 本機模型推論 | 留在你的 Mac 上：模型檔案下載完成後，便在本機執行 |
| 瀏覽器或電腦工具 | 該工具所獲授予的存取權限所允許的任何內容與動作 |
| 即時通訊管道 | 已連接的訊息服務與代理程式之間的訊息 |
| 同步 | 你開啟同步後，你的聊天、設定、知識庫與作品會傳送到你的 Enconvo 帳號或 iCloud。API 金鑰開啟後，只會以加密形式離開你的 Mac。 |

僅使用本機聊天模型，並不會讓每項工具都離線。網頁搜尋、遠端 MCP 工具、雲端轉寫服務供應商或雲端嵌入模型，仍會透過網路傳送內容。

## Enconvo Cloud 的使用規則

自 2026 年 11 月 14 日起，Enconvo Cloud 會在每則訊息送達雲端模型之前，依據我們的[使用條款](https://www.enconvo.com/terms)進行檢查。只會檢查你剛寫下的文字，不包括先前的對話、你的檔案或你的圖片。使用你自己的 API 金鑰或本機模型時，一切維持不變。

- **保留的內容：** 如果訊息被拒絕或標記，Enconvo 會將帳號、時間、模型與分數保留最多 90 天，絕不保留文字內容。
- **被拒絕的訊息：** 它不會送達模型，也不會花費點數。你的聊天會顯示原因。
- **重複被拒絕：** 可能會暫停你帳號的雲端 AI。你仍可登入、管理或取消訂閱，以及刪除你的帳號。訂閱會持續到你取消為止。
- **如果我們判斷有誤：** 請來信 support@enconvo.com。

為了讓服務供應商的安全措施只套用於單一帳號而非所有人，Enconvo Cloud 也會在每次請求中，向 OpenAI 與 Anthropic 傳送一個由你的帳號產生的單向識別碼。它不是你的電子郵件地址。詳情請見[隱私權政策](https://www.enconvo.com/privacy)。

## 控制你傳送的內容

送出請求前，請先檢查附件與上下文。Appshots、螢幕截圖、選取的文字、剪貼簿內容與瀏覽器頁面所包含的內容，可能比你想詢問的那句話更多。

在[上下文感知](/zh-hant/features/context-awareness)中選擇你的上下文來源。只為你使用的功能授予 [macOS 權限](/zh-hant/configuration/permissions)，不再需要時請到系統設定中撤銷。

## 憑證

你可以在每個服務供應商的 **身分驗證** 區段與[憑證管理](/zh-hant/configuration/credentials)中管理 API 金鑰與帳號登入。請將你本機的 Enconvo 設定、備份、匯出的設定與支援記錄視為敏感資料，並避免讓金鑰與帳號權杖出現在提示詞、螢幕截圖與共用檔案中。

服務供應商設定檔可以在多個功能之間共用其憑證。刪除或取代設定檔之前，請檢查每個使用它的功能。

<Warning>
從 Enconvo 移除金鑰並不會撤銷它。如果金鑰外洩，請到該服務供應商自己的網站撤銷。
</Warning>

## 工具與整合

代理程式可以透過你開啟的工具採取行動。瀏覽器控制、電腦操作、shell 指令、檔案編輯、Gmail 與外部 MCP 伺服器，各自能接觸到不同的內容。處理重要資料時，請檢查代理程式的工具與它提議的動作。

讓擴充功能在自己的 worker 中執行，並不會使它無法存取你的本機檔案或網路。請從你信任的來源安裝工具，並檢查它們的設定。

聊天中的 **權限** 標籤決定代理程式在行動前何時詢問。在 **完整取用** 下，它不經詢問就會行動，包括對你的好友與隊友撥打電話與傳送訊息，只有在可能損害你電腦的變更之前才會詢問。請參閱[Enconvo 為何會在指令執行前詢問](/zh-hant/configuration/sandbox)。

若要讓代理程式的 shell 指令只限於它的工作資料夾，並遠離你的金鑰、已儲存的憑證與其他 App，請開啟它的 **沙盒**。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。若要讓電腦操作不接觸特定 App，請使用 **設定 → 電腦操作** 中的 **App 存取**；請參閱[電腦操作](/zh-hant/features/computer-use)。

公開網頁無法將網頁擷取重新導向到你的 Mac 或你的區域網路。

## 登入連結

網頁上的登入連結無法自行將 Enconvo 切換到另一個帳號。除非是 Enconvo 自己發起的登入，否則它會先詢問，並顯示該連結所確認的帳號，以及它將取代的帳號。代理程式、程式碼代理程式與排程任務無法發起登入或開啟登入連結。

## 本機 AI 用戶端

[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp) 在你開啟之前是關閉的，並接受本機連線。它的可見性開關決定要公開哪些知識庫。本機用戶端可能會將它檢索到的內容傳送給它自己的 AI 服務供應商，因此也請謹慎設定該用戶端。

## 分析與診斷

Enconvo 以裝置 ID（而非你的帳號）記錄產品使用事件。這些事件設計上不包含電子郵件地址、對話文字與媒體。若要停止分享，請在首次執行指南中，或在 **設定 → 一般** 的 **隱私** 下，關閉 **分享匿名產品分析資料**。你先前做的選擇會維持不變。當該開關開啟時才會傳送當機與凍結報告，且不含你的任何內容。

Enconvo 不會在你 Mac 上的記錄中保留你的 AI 請求、你的訊息或你輸入內容的副本。

診斷記錄與分析是分開的。當 Enconvo 凍結、當機或行為異常時，可透過選單列選單中的 **提交診斷資訊…**，或從 **設定 → 診斷** 將它們傳送給 Enconvo 團隊：

- 在任何內容離開你的 Mac 之前，Enconvo 會移除個人資料，例如你的家目錄名稱、檔案名稱、電子郵件地址、API 金鑰、權杖、連結、IP 位址，以及提示詞與回覆的文字。
- 報告帶有一個僅用於診斷的隨機 ID，而不是你的帳號或電子郵件。只有 Enconvo 團隊能讀取它，並會在固定天數後刪除。
- 記錄仍可能指出你使用過的 App、指令與模型。
- 頁面會顯示確切傳送了什麼，並讓你撤回或刪除每份報告。

當你以其他方式分享記錄或螢幕截圖時，請先檢查，並移除不需要的私人提示詞、路徑、金鑰、帳號資訊與文件內容。

## 保留或移除本機資料

每個功能各自管理自己的資料：聊天記錄、知識庫、錄音與憑證都有各自的控制項。請閱讀刪除確認，並為你需要的內容保留備份。刪除聊天時，也會一併刪除你附加到該聊天的圖片與檔案，除非其他聊天仍顯示它們。

移除 App 並不一定會移除它的設定與資料。移除本機資料也不會刪除外部服務已處理過的副本。關於服務供應商的保留與帳號政策，請參閱該服務供應商：本頁涵蓋的是 Enconvo 的資料流向，而不是它們的。

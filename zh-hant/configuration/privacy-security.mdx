Enconvo 會將你的資料儲存在你的 Mac 上，並僅針對你選擇的功能與服務供應商使用線上服務。請求會傳送至何處，取決於所使用的功能、你選擇的供應商、啟用的工具以及連接的整合服務。本頁說明各項資料流向與對應的控制選項。

## 你的內容去向

| 操作 | 傳送內容與傳送對象 |
| --- | --- |
| 雲端 AI 聊天 | 你的提示詞、對話情境與附加檔案，傳送至該模型供應商 |
| Enconvo Cloud 內容檢查（自 2026 年 11 月 14 日起） | 你剛輸入的文字，在送交雲端模型前傳送至 OpenAI 的審核模型 |
| 雲端語音辨識 | 擷取的音訊，傳送至你選擇的語音服務 |
| 雲端文字轉語音 | 文字內容，傳送至你選擇的語音服務 |
| 雲端嵌入（Embeddings）或重排序（Reranking） | 檢索所需的文件與查詢內容 |
| 網頁搜尋或網頁擷取 | 搜尋查詢詞或網址，傳送至搜尋服務或目標網站 |
| 本機模型推論 | 完全留在你的 Mac 上：下載模型檔案後即在本機執行 |
| 瀏覽器或電腦操作工具 | 依該工具獲授權範圍存取的網頁或螢幕內容與操作 |
| 即時通訊管道 | 連接的通訊服務與代理程式之間往來的訊息 |
| 同步 | 啟用同步後，你的聊天記錄、設定、知識庫與產出物會傳送至你的 Enconvo 帳號或 iCloud。只有當你開啟同步金鑰選項時，API 金鑰才會以加密形式離開你的 Mac。 |

僅使用本機聊天模型並不代表所有工具都處於離線狀態。網頁搜尋、遠端 MCP 工具、雲端轉寫供應商或雲端嵌入模型仍會透過網路傳送內容。

## Enconvo Cloud 的使用規範

自 2026 年 11 月 14 日起，Enconvo Cloud 會在訊息送達雲端模型前，依據我們的[使用條款](https://www.enconvo.com/terms)進行檢查。系統僅檢查你剛輸入的文字，不包含先前的對話歷史、你的檔案或圖片。若使用你自己的 API 金鑰或本機模型，一切維持不變，不會經過此檢查。

- **保留的紀錄**：如果訊息遭到拒絕或標記，Enconvo 最多會保留帳號、時間、模型與評分紀錄 90 天，但絕不會保留你的文字內容。
- **被拒絕的訊息**：該訊息不會送達模型，也不會消耗點數。聊天中會顯示拒絕原因。
- **反覆遭拒**：可能會導致你的帳號暫停使用雲端 AI。你仍可登入、管理或取消訂閱，以及刪除帳號。訂閱在取消前會持續有效。
- **如果系統誤判**：請來信至 support@enconvo.com。

為了讓供應商的安全處置僅針對單一帳號生效而不會影響所有使用者，Enconvo Cloud 也會在每次請求時向 OpenAI 與 Anthropic 傳送一組由你帳號生成的單向識別碼，而非你的電子郵件地址。詳情請參閱[隱私權政策](https://www.enconvo.com/privacy)。

## 控制你傳送的內容

傳送請求前請先檢查附加的檔案與情境。Appshots、螢幕截圖、選取文字、剪貼簿內容與瀏覽器頁面可能包含比你原本想詢問的句子更多的資訊。

請在[上下文感知](/zh-hant/features/context-awareness)中選擇你的情境來源，僅為你使用的功能授予 [macOS 權限](/zh-hant/configuration/permissions)，並在不再需要時於系統設定中撤銷。

## 憑證

你可以在各服務供應商的**身分驗證**區塊以及[憑證管理](/zh-hant/configuration/credentials)中管理 API 金鑰與帳號登入。請妥善保管本機 Enconvo 設定檔、備份、匯出的設定與支援記錄，切勿將金鑰或帳號權杖放入提示詞、截圖或分享的檔案中。

單一供應商設定檔可能會在多個功能間共用憑證。刪除或取代設定檔前，請先確認所有使用該設定檔的功能。

<Warning>
從 Enconvo 移除金鑰並不會撤銷該金鑰。如果金鑰外洩，請立即前往供應商網站將其撤銷。
</Warning>

## 工具與整合

代理程式可以透過你開啟的工具執行操作。瀏覽器控制、電腦操作、Shell 指令、檔案編輯、Gmail 與外部 MCP 伺服器各自能觸及不同的資源。處理重要資料時，請仔細確認代理程式啟用的工具以及它提議執行的動作。

即使外掛程式在獨立的工作執行緒中執行，也不代表它無法存取你的本機檔案或網路。請僅從信任的來源安裝工具，並檢查其設定。

聊天中的**權限**標籤決定代理程式在採取行動前何時需要詢問你。在**完整取用**模式下，它會直接執行而不再詢問（包含撥打電話與傳送訊息給你的好友與團隊成員），僅在可能損害電腦的變更前才會詢問。請參閱[為什麼 Enconvo 會在執行指令前詢問](/zh-hant/configuration/sandbox)。

若要將代理程式的 Shell 指令限制在工作資料夾內，並隔離你的金鑰、已儲存憑證與其他 App，請開啟**沙盒**。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。若要禁止電腦操作存取特定應用程式，請使用**設定 → 電腦操作**中的 **App 存取**；請參閱[電腦操作](/zh-hant/features/computer-use)。

Web Fetch（網頁擷取）無法被公開網頁重新導向至你的 Mac 本機或區域網路位址。

## 登入連結

網頁上的登入連結無法單方面將 Enconvo 切換至其他帳號。除非是由 Enconvo 自己發起的登入流程，否則系統會先向你確認，並顯示該連結對應的帳號以及將被取代的目前帳號。代理程式、程式設計代理程式與排程任務均無法發起登入或開啟登入連結。

## 本機 AI 用戶端

[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp) 在你手動開啟前預設為關閉，且僅接受本機連線。其可見性開關可決定要對外開放哪些知識庫。本機用戶端可能會將檢索到的內容傳送至它自己的 AI 供應商，因此請同樣謹慎設定該用戶端。

## 分析資料與診斷

Enconvo 會以裝置 ID（而非你的帳號）記錄產品使用事件，這些事件在設計上會排除電子郵件地址、對話文字與媒體內容。若要停止分享這些資料，請在首次使用引導中關閉**分享匿名產品分析資料**，或在**設定 → 一般**的**隱私**底下關閉。你先前的選擇會維持原樣。當機與當停報告僅在該開關開啟時才會傳送，且不包含你的任何內容。

Enconvo 不會在你 Mac 的記錄檔中留存你的 AI 請求、訊息或輸入內容。

診斷記錄與產品分析分開管理。當 Enconvo 凍結、當機或運作異常時，你可以透過選單列選單的**提交診斷資訊…**，或前往**設定 → 診斷**將診斷資訊傳送給 Enconvo 團隊：

- 任何資料離開你的 Mac 前，Enconvo 會移除個人詳細資訊，例如你的家目錄名稱、檔案名稱、電子郵件地址、API 金鑰、權杖、連結、IP 位址，以及提示詞和回覆的文字。
- 每份報告只會攜帶專為診斷產生的隨機 ID，不含你的帳號或電子郵件。只有 Enconvo 團隊可以讀取，且會在固定天數後自動刪除。
- 記錄檔中仍可能包含你使用過的應用程式、指令與模型名稱。
- 診斷頁面會完整顯示已傳送的內容，並允許你撤回或刪除每份報告。

當你透過其他方式分享記錄檔或截圖時，請先檢視內容，並移除不需要的私人提示詞、路徑、金鑰、帳號詳情與文件內容。

## 保留或移除本機資料

每項功能各自管理自己的資料：聊天歷史記錄、知識庫、錄音與憑證均有獨立的管理控制項。刪除前請仔細閱讀確認提示，並為重要資料保留備份。刪除聊天記錄時，除非該圖片或檔案同時存在於其他聊天中，否則附加的圖片與檔案也會一併刪除。

移除應用程式並不一定會清除所有設定與資料。移除本機資料也不會刪除外部服務已經處理過的副本。有關供應商的資料保留與帳號政策，請參閱該供應商的說明：本頁僅說明 Enconvo 本身的資料流向，不涵蓋第三方服務。

---

Enconvo 會在背景檢查新版本，當你所選的更新頻道有較新的建置版本時，會顯示 **更新** 按鈕。大多數使用者都會留在 Production 頻道；若想在功能正式向所有人發佈前搶先體驗，可以切換至 Beta 頻道。

![標題列中的更新按鈕](/img/update-button-titlebar.png)

## 更新頻道

| 頻道 | 適合對象 | 你會收到 |
|---------|----------|------------------|
| **Production** | 大多數使用者 | 經過 Beta 測試後的穩定發行版本 |
| **Beta** | 早期測試者 | 晉升至 Production 前的新建置版本 |
| **Dev** | 開發測試 | 更頻繁的開發建置版本，與 Beta 分開發行 |

<Tip>
除非你想搶先測試新功能，否則建議使用 **Production**。如果你正在協助測試新版本，或在穩定版發佈前需要某個修復，請使用 **Beta**。
</Tip>

## 變更更新頻道

<Steps>
  <Step title="開啟設定">
    從 App 選單開啟 Enconvo 設定，或按下 **⌘,**。
  </Step>
  <Step title="前往一般">
    在設定側邊欄中開啟 **一般**。
  </Step>
  <Step title="找到更新">
    捲動至 **更新** 區段。
  </Step>
  <Step title="選擇頻道">
    將 **更新頻道** 設為 **Production**、**Beta** 或 **Dev**。
  </Step>
</Steps>

全新安裝的 Dev 版本預設位於 Dev 頻道，而你先前選擇的頻道設定會持續保留。切換頻道不一定會將你已安裝的較新建置降級。

## 安裝更新

當你的頻道有新版本時，**更新** 按鈕會出現在：

- **聊天視窗** 標題列
- **SmartBar** 標題列
- **動態島**

點擊 **更新**。Enconvo 會顯示新版本資訊，並引導你完成下載、安裝與重新啟動。

Enconvo 會在你開啟聊天視窗、SmartBar 或動態島時進行檢查。為避免重複發出網路請求，每 10 分鐘內不會重複檢查超過一次。

<Note>
自動下載更新預設為關閉。Enconvo 會在下載任何內容前先通知你有更新可用並顯示按鈕。
</Note>

## 立即檢查

1. 開啟 **設定 → 一般** 並捲動至 **更新**，這裡會顯示你目前的版本。
2. 點擊 **檢查更新**，結果會直接顯示在該處。
3. 若你的頻道有較新版本，請依照更新提示操作。

你也可以從選單列的 Enconvo 圖示選擇 **檢查更新**。若未跳出更新視窗，代表你目前使用的可能已經是該頻道的最新版本。**設定 → 關於** 會顯示版本與組建編號，若你位於 Beta 或 Dev 頻道，也會顯示 **Beta** 或 **Dev**。

## 查看新功能

**設定 → 教學** 可在 Enconvo 內播放更新影片與逐步導覽，並將尚未觀看過的項目加上 **New** 標記。聊天視窗設定選單中的 **新功能** 也會開啟同一頁面。每次更新後初次使用 Enconvo 時，聊天視窗側邊欄中的卡片也會提供該版本的更新影片。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 已切換至 Beta 卻看不到 Beta 更新 | 確認 **設定 → 一般 → 更新 → 更新頻道** 設為 **Beta**，然後重新開啟聊天視窗或 SmartBar。背景檢查每次會間隔 10 分鐘，如果你剛檢查過，請稍候幾分鐘再試。 |
| 切回 Production 後找不到最新的建置版本 | Production 僅會顯示已發佈至穩定頻道的建置版本。僅存在於 Beta 的版本需等正式晉升至 Production 後才會出現。 |
| **更新** 按鈕消失了 | 更新可能已安裝完成或被關閉，或已不再符合你目前的頻道。請在 **設定 → 一般 → 更新** 中點擊 **檢查更新** 確認。 |
| 無法開啟更新提示 | 結束並重新開啟 Enconvo，然後再次執行 **檢查更新**。同時請確認你的網路可以連線至 Enconvo 的發行伺服器。 |

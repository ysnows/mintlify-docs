沙盒會限制代理程式的 shell 指令能存取的範圍。開啟後，指令只能變更聊天的工作資料夾與暫存資料夾，而 macOS 會阻止它讀取你的金鑰、控制其他 App，或連接到 Enconvo。若某個代理程式會執行你不想逐一查看的指令，請為它開啟沙盒。

沙盒與代理程式的權限模式搭配運作。權限模式決定 Enconvo 在動作之前何時詢問；沙盒則限制指令一旦執行後能做什麼。

## 開啟沙盒

1. 在聊天視窗、SmartBar、動態島、App 側邊欄，或專案的主導聊天中，開啟與該代理程式的聊天。
2. 點按執行模式旁的 **權限** 標籤。
3. 開啟 **沙盒**。

這個開關屬於代理程式，因此在你使用該代理程式的每個視窗中都會生效。它呼叫的其他代理程式，其指令也會在沙盒中執行。

若要查看沙盒讓代理程式的指令能存取哪些內容，請點按開關下方的 **沙盒的運作方式**。它會畫出該代理程式自己的沙盒：它的工作資料夾、它的權限模式，以及指令可以與不可以存取的每個位置。

## 沙盒內的指令能存取什麼

| 位置 | 在沙盒內 |
| --- | --- |
| 工作資料夾與暫存資料夾 | 可讀取與變更 |
| 你的其他檔案 | 可讀取，不可變更 |
| 網際網路 | 可連線 |
| 金鑰與密碼，例如 SSH 金鑰、鑰匙圈與 Cookie | 不可讀取 |
| 已儲存的憑證與 Enconvo 的設定 | 不可讀取 |
| 其他 App | 不可開啟或控制 |
| Enconvo | 不可連接 |

指令啟動的每個程式也都在沙盒內執行。Enconvo 使用的是 macOS 自己的沙盒，也就是 App Store App 所使用的那一種。

## 當沙盒阻止指令時

當指令嘗試存取沙盒不允許的內容時，macOS 會拒絕，步驟下方會出現一行文字，說明被阻止的內容，例如寫入某個資料夾或讀取金鑰檔案。

1. 點按該行文字，查看被阻止的內容與原因。
2. 若要讓指令照做，請點按 **在沙盒外執行**。指令會以你的完整存取權限執行一次，然後和其他指令一樣顯示在聊天中。系統不會記住這項選擇。

**在沙盒外執行** 只會在執行進行中且有人在查看時提供。排程任務與其他無人看管的執行，絕不會在沙盒外執行指令。

## Enconvo 為何會在指令執行前詢問

無論是否開啟沙盒，都由代理程式的權限模式決定什麼會詢問。請參閱[核准動作](/zh-hant/ai/agents)。

| 模式 | 開啟沙盒時 |
| --- | --- |
| **請求核准** | 每個指令仍會在執行前詢問。沙盒限制你允許的指令能做什麼。 |
| **替我核准** | 指令不經詢問直接執行，但有風險的除外，例如刪除檔案或發佈。 |
| **完整取用** | 指令不經詢問直接執行。只有可能損害你電腦的變更才會詢問。 |

Enconvo 會逐段讀取每個指令，因此藏在引號、巢狀、串接或管線指令中的有害步驟仍會詢問，而無害的步驟（例如 echo 或列出資料夾）則不會。

即使在 **完整取用** 下，Enconvo 仍會在可能損害你電腦的變更之前，以 **僅允許一次** 與 **拒絕** 詢問，例如刪除關鍵資料夾、編輯你的 shell 啟動檔案或 SSH 金鑰，或讀取已儲存的密碼，無論指令如何書寫路徑。

在 **替我核准** 下，規則無法判斷的指令，會與你的要求比對檢查。當你不預期它會自行執行時，Enconvo 會詢問你並說明原因。

每張核准卡片都會指出讓它詢問的設定，例如「因為此專案設為替我核准而詢問。」

## 其他會詢問的動作

- [電腦操作](/zh-hant/features/computer-use)在執行會刪除、傳送、付款、結束 App 或登出的鍵盤快速鍵之前會詢問，點按也是如此。
- 呼叫外掛程式頁面自身路由的指令，會先詢問。
- 核准外掛程式的工具時，會顯示該工具即將傳送的內容。
- 代理程式在呼叫或傳訊給你的[好友](/zh-hant/features/friends)與隊友之前會詢問，但在 **完整取用** 下不會詢問。
- 代理程式無法回答自己的核准卡片、提高自己的權限，或回答要給你的卡片，例如外掛程式安裝或點數上限。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 指令因權限錯誤而失敗 | 可能是沙盒阻止了它。點按步驟下方的那行文字；若你信任該指令，再點按 **在沙盒外執行**。 |
| 代理程式無法透過指令開啟或控制 App | 沙盒中的指令無法控制其他 App。請使用[電腦操作](/zh-hant/features/computer-use)，或為此代理程式關閉沙盒。 |
| 你預期 Enconvo 會詢問，但它沒有 | 在 **權限** 標籤中檢查代理程式的權限模式。**完整取用** 只會在可能損害你電腦的變更之前詢問。 |
| 找不到 **沙盒** 開關 | 確認聊天處於代理程式模式，並更新 Enconvo。請參閱[更新](/zh-hant/configuration/updates)。 |

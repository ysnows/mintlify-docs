沙盒會限制代理程式的 shell 指令能觸及的範圍。開啟後，指令只能更改聊天的工作資料夾與暫存資料夾，macOS 會阻止它讀取你的金鑰、控制其他 App 或連線至 Enconvo。當代理程式執行你不想逐一盯著看的指令時，就可以開啟它。

沙盒會搭配代理程式的權限模式一起運作。權限模式決定 Enconvo 何時在行動前先詢問；沙盒則限制指令一旦執行起來能做什麼。

## 開啟沙盒

1. 在聊天視窗、SmartBar、動態島、App 側邊欄或專案的主導者聊天中，開啟與該代理程式的聊天。
2. 點擊執行模式旁的 **權限** 標籤。
3. 開啟 **沙盒**。

這個開關屬於該代理程式，因此在任何視窗中使用它時都會套用。它呼叫的其他代理程式也會在沙盒中執行指令。

若要查看沙盒允許該代理程式的指令觸及哪些位置，請點擊開關下方的 **沙盒的運作方式**。它會繪製出該代理程式專屬的沙盒：包含它的工作資料夾、權限模式，以及指令可觸及或無法觸及的每個位置。

## 沙盒中的指令可觸及的範圍

| 位置 | 在沙盒內 |
| --- | --- |
| 工作資料夾與暫存資料夾 | 可讀取與更改 |
| 你的其他檔案 | 可讀取，無法更改 |
| 網際網路 | 可連線 |
| 金鑰與密碼，例如 SSH 金鑰、鑰匙圈與 Cookie | 無法讀取 |
| 已儲存的憑證與 Enconvo 的設定 | 無法讀取 |
| 其他 App | 無法開啟或控制 |
| Enconvo | 無法連線 |

指令啟動的每個程式也都會在沙盒內執行。Enconvo 使用的是 macOS 內建的沙盒，與 App Store App 所採用的機制相同。

## 當沙盒阻止某個指令時

當指令嘗試觸及沙盒禁止的內容時，macOS 會拒絕，步驟下方會出現一列文字說明被阻止的動作，例如寫入某個資料夾或讀取某個金鑰檔案。

1. 點擊該列查看被阻止的內容與原因。
2. 若要允許該指令執行，點擊 **在沙盒外執行**。指令會以你的完整權限執行一次，接著像其他指令一樣顯示在聊天中。此選擇不會被記住。

只有當執行仍在進行且有人盯著看時，才會提供 **在沙盒外執行**。排程任務與其他無人值守的執行絕不會在沙盒外執行指令。

## 為何 Enconvo 會在指令執行前詢問

無論是否開啟沙盒，都由代理程式的權限模式決定何時詢問。參閱[核准操作](/zh-hant/ai/agents)。

| 模式 | 開啟沙盒時 |
| --- | --- |
| **請求核准** | 每個指令執行前仍會詢問。沙盒限制你所允許的指令能做什麼。 |
| **替我核准** | 指令無需詢問即可執行，但刪除檔案或發佈等高風險操作除外。 |
| **完整取用** | 指令無需詢問即可執行。僅有會損害電腦的變更才會詢問。 |

Enconvo 會逐段解析每條指令，因此藏在引號、巢狀、串連或管線中的危險步驟仍會詢問，而單純的輸出（echo）或列出資料夾等無害步驟則不會。

即使在 **完整取用** 模式下，在執行可能損害電腦的變更之前（例如刪除重要資料夾、編輯你的 shell 啟動檔或 SSH 金鑰，或讀取已儲存的密碼），無論指令如何拼寫路徑，Enconvo 仍會以 **僅允許一次** 與 **拒絕** 向你確認。

在 **替我核准** 模式下，規則無法直接判斷的指令會對照你的請求進行檢查。當該指令看來不像是你預期它會自行執行的操作時，Enconvo 就會詢問你並給出原因。

每張核准卡片都會註明觸發詢問的設定，例如「因專案設為『替我核准』而詢問」。

## 其他會詢問的操作

- [電腦操作](/zh-hant/features/computer-use)在按下會刪除、傳送、付款、結束 App 或登出的鍵盤快速鍵之前會先詢問，與點擊動作相同。
- 呼叫外掛程式頁面自身路由的指令會先詢問。
- 核准外掛程式的工具時，會顯示該工具即將傳送的內容。
- 代理程式在致電或傳訊給你的[好友](/zh-hant/features/friends)和團隊成員前會先詢問，除非處於 **完整取用** 模式，該模式下不會詢問。
- 代理程式無法自行回應自己的核准卡片、提升自己的權限，也無法回應原本應由你決定的卡片（例如外掛程式安裝或點數上限）。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 指令因權限錯誤而失敗 | 可能是沙盒阻止了它。點擊步驟下方的提示列，若你信任該指令，點擊 **在沙盒外執行**。 |
| 代理程式無法從指令中開啟或控制 App | 沙盒中的指令無法控制其他 App。請改用[電腦操作](/zh-hant/features/computer-use)，或為此代理程式關閉沙盒。 |
| 你預期 Enconvo 會詢問，但它沒有 | 在 **權限** 標籤中檢查代理程式的權限模式。**完整取用** 僅會在可能損害電腦的變更前詢問。 |
| 找不到 **沙盒** 開關 | 確認聊天處於代理模式，並更新 Enconvo。參閱[更新](/zh-hant/configuration/updates)。 |

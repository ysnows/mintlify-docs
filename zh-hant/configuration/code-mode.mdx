---
title: "程式碼模式"
description: "讓代理程式撰寫一支簡短腳本一次執行多個工具呼叫，並只回傳最終結果。"
---

程式碼模式讓代理程式用一個步驟完成原本需要許多步驟的工作：它會撰寫一支簡短腳本，平行或依序呼叫多個工具，最後只把結果讀回對話中。當任務需要對許多項目重複相同的呼叫時（例如檢查一長串網頁或從多項服務蒐集資料），程式碼模式能大幅加快速度，也不會讓對話被一大堆中間結果塞滿。

你不需要自己呼叫程式碼模式。只要開啟此功能，代理程式就會在適合的任務中自動使用它，對話裡也會顯示一張卡片列出腳本執行的呼叫。

## 設定程式碼模式

1. 開啟 **設定 → 程式碼模式**。你也可以從外掛程式頁面的 **內建** 分頁開啟 **程式碼模式**。
2. 在 **Script Access** 下方，開啟允許腳本呼叫的項目。每次呼叫仍會依照對話的[權限模式](/zh-hant/ai/agents)決定是否向你詢問。
3. 選擇哪些模型可以撰寫腳本、對話中要顯示什麼內容，以及腳本執行時間過長時的處理方式。

## 設定項目

**Script Access** 列出腳本可以呼叫的項目：

| 存取權限 | 允許的操作 | 預設 |
| --- | --- | --- |
| **外掛程式** | 搜尋、知識庫、文件以及其他外掛程式路由 | 開啟 |
| **連接器與 MCP** | 你連接的帳號與 MCP 工具 | 開啟 |
| **檔案** | 讀取與寫入檔案 | 開啟 |
| **Shell 指令** | 在終端機中執行指令 | 開啟 |
| **瀏覽器** | 在你自己的瀏覽器中使用[使用瀏覽器](/zh-hant/features/browser-control) | 開啟 |
| **App** | 在「App 存取權限」清單允許的範圍內使用[電腦操作](/zh-hant/features/computer-use) | 開啟 |
| **其他代理程式** | 啟動子代理或向其傳送訊息 | 關閉 |
| **模型呼叫** | 使用小型模型進行摘要或判斷項目 | 開啟 |

其他選項：

| 選項 | 可選項目 |
| --- | --- |
| **搭配使用對象** | **擅長寫程式碼的模型**（其他模型仍會逐一呼叫工具），或 **所有模型**。 |
| **在對話中顯示** | **呼叫紀錄**，或 **呼叫紀錄與程式碼**。 |
| **當腳本執行時間過長時** | **在背景繼續執行，最長 2 小時**，或 **10 分鐘後停止**。 |

## 對話之外的程式碼模式

當腳本在對話之外執行時（例如在排程工作內），它只會呼叫純讀取的工具：包含內建的搜尋與讀取功能、公開網頁、一般檔案，以及未標明會修改資料的 MCP 工具。Enconvo 會在每個呼叫實際執行前再次檢查。

## 在技能中使用腳本

技能可以在自己的 `scripts` 資料夾中保存程式碼模式腳本，並將它作為步驟之一來執行。請參閱[技能](/zh-hant/configuration/skills)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 代理程式仍逐一呼叫工具 | 檢查 **搭配使用對象** 設定。若設為 **擅長寫程式碼的模型**，其他模型不會使用程式碼模式。 |
| 腳本無法呼叫某個工具 | 到 **Script Access** 下方開啟對應類型的存取權限。在對話之外執行時，腳本只允許讀取操作。 |
| 執行時間較長的腳本中途停止 | 若設為 **10 分鐘後停止**，超過時間的腳本會終止。請改選 **在背景繼續執行，最長 2 小時**。 |

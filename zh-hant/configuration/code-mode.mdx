---
title: "程式碼模式"
description: "讓代理程式撰寫一段簡短的指令碼，一次發出許多工具呼叫，並且只讀回結果。"
---

程式碼模式讓代理程式用一個步驟完成原本需要許多步驟的工作：它會撰寫一段簡短的指令碼，同時或依序發出許多工具呼叫，並且只讀回結果。當任務要對許多項目重複同樣的呼叫時，例如檢查一份頁面清單，或從數個服務收集結果，就適合使用它，這樣工作更快，聊天也不會被每個中間結果塞滿。

你不需要自己呼叫程式碼模式。開啟後，代理程式會在任務適合時使用它，聊天中會顯示一張卡片，列出指令碼所發出的呼叫。

## 設定程式碼模式

1. 開啟 **設定 → 程式碼模式**。你也可以從外掛程式頁面的 **內建** 分頁開啟 **程式碼模式**。
2. 在 **指令碼存取權限** 下，開啟指令碼可以呼叫的項目。每個呼叫仍會依聊天的[權限模式](/zh-hant/ai/agents)詢問你。
3. 選擇哪些模型可以撰寫指令碼、聊天中顯示什麼，以及指令碼執行太久時該怎麼處理。

## 設定

**指令碼存取權限** 列出指令碼可以呼叫的項目：

| 存取權限 | 允許的內容 | 預設 |
| --- | --- | --- |
| **外掛程式** | 搜尋、知識庫、文件和其他外掛程式路由 | 開啟 |
| **連接器和 MCP** | 你已連結的帳號和 MCP 工具 | 開啟 |
| **檔案** | 讀取和寫入檔案 | 開啟 |
| **Shell 指令** | 在終端機中執行指令 | 開啟 |
| **瀏覽器** | 在你自己的瀏覽器中使用[瀏覽器控制](/zh-hant/features/browser-control) | 開啟 |
| **應用程式** | 在其 App 存取清單範圍內使用[電腦操作](/zh-hant/features/computer-use) | 開啟 |
| **其他代理程式** | 啟動子代理或傳訊息給子代理 | 關閉 |
| **模型呼叫** | 用小型模型來彙整或評判項目 | 開啟 |

其他選項：

| 選項 | 選擇 |
| --- | --- |
| **適用於** | **擅長寫程式的模型**（其他模型會逐一發出呼叫），或 **所有模型**。 |
| **在聊天中顯示** | **呼叫**，或 **呼叫和程式碼**。 |
| **指令碼執行太久時** | 在背景 **持續執行，最長 2 小時**，或 **10 分鐘後停止**。 |

## 聊天以外的程式碼模式

當指令碼在聊天以外執行時，例如在排程工作中，它只會呼叫讀取類的工具：內建的搜尋和讀取、公開網頁、一般檔案，以及未聲明會變更任何內容的 MCP 工具。Enconvo 會在每個呼叫執行之前再次檢查它。

## 在技能中使用指令碼

技能可以把程式碼模式指令碼存放在自己的 `scripts` 資料夾中，並將它作為步驟之一執行。請參閱[技能](/zh-hant/configuration/skills)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 代理程式逐一發出呼叫 | 檢查 **適用於**。若選擇 **擅長寫程式的模型**，其他模型不會使用程式碼模式。 |
| 指令碼無法存取某個工具 | 在 **指令碼存取權限** 下開啟該類存取權限。在聊天以外，指令碼只能讀取。 |
| 長時間執行的指令碼停止了 | 選擇 **10 分鐘後停止** 時，較長的指令碼會結束。請選擇 **持續執行，最長 2 小時**。 |

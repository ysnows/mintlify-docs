Enconvo 的各個視窗與語音功能都能用快速鍵開啟。**設定 → 快捷鍵** 會列出 Enconvo 使用的所有快速鍵以及對應執行的指令，方便你修改按鍵或找出某組按鍵的用途。你在這台 Mac 上自行儲存的快速鍵一律優先於本指南所列的預設值。

這支影片先介紹快捷鍵，接著帶你瀏覽讓 Enconvo 貼合你 Mac 使用習慣的其他設定：上下文感知、Appshots、本機模型、權限與保持喚醒。

## 預設快速鍵

| 動作 | 預設值 |
| --- | --- |
| 顯示 SmartBar | **⌥Space** |
| 顯示聊天視窗 | **⌃⌘X** |
| 顯示 App 側邊欄 | **⌃⌘E** |
| 在 Enconvo 內開啟設定 | **⌘,** |
| 開始聽寫 | **右側 ⌘** |
| 開始語音指令 | **右側 ⌥** |
| 暫停 / 繼續音訊 | **⌥P** |

只有在你從未自行設定過按鍵時才會套用這些預設值；你自己設定過的按鍵會維持不變。快速擷取與 Appshots 沒有預設快速鍵：使用前請先到它們各自的設定頁面進行綁定。

## 變更快速鍵

1. 開啟 **設定 → 快捷鍵**。**核心** 分頁收錄主要功能，**其他快速鍵** 收錄 AI 指令、外掛程式、設定及未在其他頁面顯示的指令，**全部** 則會同時顯示兩者。
2. 在 **依名稱篩選…** 中輸入文字以尋找指令。如果想查詢某個按鍵組合對應哪一個指令，請點選 **依快速鍵尋找** 並按下該組按鍵。
3. 點一下該指令的快速鍵欄位，然後按下新的按鍵組合。
4. 如果該組按鍵已經用於另一個指令，欄位會直接提示你。選擇 **改用於此** 可將按鍵移交給這個指令，或從它建議的空閒快速鍵中挑選一組。
5. 切換到另一個 App 試按看看新的快速鍵。

如果想釋放某個快速鍵佔用的按鍵，從該指令中將它移除即可。畫面上出現的通知提供 **復原** 按鈕讓你隨時收回剛才的變更。

帶有 **本機（Local）** 徽章的快速鍵代表只在 Enconvo 視窗內有效，例如「釘選 SmartBar」。

## 按鍵方式

當你只錄製單一個修飾鍵時（例如右側 ⌘），欄位會詢問 **按鍵方式**：

| 選項 | 指令何時執行 |
| --- | --- |
| **按住或單擊** | 按住按鍵執行，或單擊一下切換開關 |
| **單擊** | 按一下開始，再按一下停止 |
| **按住** | 按住期間持續運作，放開即結束 |
| **雙擊** | 快速連按兩下 |

同時按下兩個或以上修飾鍵會視為一組組合快速鍵。每個欄位只會顯示該指令支援的觸發類型，旁邊的說明文字也會指出該功能的實際反應方式。

## 各功能自己的快速鍵所在位置

除了快捷鍵總覽頁面之外，每個功能也在自己的設定頁面中提供了快速鍵設定：

| 功能 | 設定頁面 |
| --- | --- |
| SmartBar | **設定 → SmartBar** |
| 動態島 | **設定 → 動態島** |
| PopBar | **設定 → PopBar** |
| App 側邊欄 | **設定 → App 側邊欄** |
| 聽寫 | **設定 → 聽寫** |
| 語音指令 | **設定 → 語音指令** |
| Appshots | **設定 → Appshots** |
| 螢幕塗鴉 | **設定 → 螢幕塗鴉** |
| 語音筆記 | **設定 → 語音筆記** |
| 快速擷取 | **設定 → 快速擷取** |
| 單一指令 | 當該指令提供 **快速鍵** 欄位時，位於該指令的設定中 |

## 在 SmartBar 內使用

在 SmartBar 中輸入觸發字元即可搜尋特定類型的項目：

| 字元 | 開啟項目 |
| --- | --- |
| **@** | 指令 |
| **#** | 要加入訊息的上下文 |
| **$** | 技能 |
| **>** | 最近任務 |

你可以在 **設定 → SmartBar** 的 **搜尋** 底下更改這些字元。斜線選單（`/`）則提供切換模型與推理強度等動作。

若要用鍵盤上下瀏覽列表，請在 **設定 → SmartBar** 選擇 **導覽快速鍵**：**macOS** 使用 **⌃N** **⌃P** **⌃F** **⌃B**，而 **Vim** 使用 **⌃J** **⌃K** **⌃L** **⌃H**。

## 讓 Enconvo 貼合你的 Mac

同一個設定視窗中也包含影片中示範的其他常用設定：

| 設定頁面 | 作用 |
| --- | --- |
| **上下文感知** | 決定 SmartBar 會從你剛剛使用的 App 擷取什麼內容：選取的文字、Finder 選取的項目或瀏覽器中的網頁。**附加** 會在開啟 SmartBar 時自動加入，**建議** 則會以一鍵按鈕提供給你選用。請參閱[上下文感知](/zh-hant/features/context-awareness)。 |
| **Appshots** | 用一組快速鍵將你眼前的視窗畫面加入對話中。請參閱 [Appshots](/zh-hant/features/appshots)。 |
| **本機模型** | 顯示這台 Mac 上正在執行的 AI、消耗的記憶體與磁碟空間，以及各功能分別在何處執行。請參閱[本機模型](/zh-hant/ai/local-llm)。 |
| **權限** | 列出 macOS 允許 Enconvo 執行的項目與原因；若缺少項目，點選 **授權** 即可補齊。請參閱 [macOS 權限](/zh-hant/configuration/permissions)。 |
| **保持喚醒** | 防止這台 Mac 在你離開時進入睡眠，讓你隨時能從 iPhone 連上它。 |

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 快速鍵只在 Enconvo 視窗內有效 | 檢查它是否帶有 **本機** 徽章。若無，請到 [macOS 權限](/zh-hant/configuration/permissions)確認輸入監控與輔助使用權限，並檢查是否有其他 App 佔用了同一組按鍵。 |
| 按下快速鍵時觸發了其他動作 | 使用 **依快速鍵尋找** 查詢。如果沒有任何 Enconvo 指令使用這組按鍵，代表被另一個 App 或 macOS 佔用了。 |
| 單獨修飾鍵的快速鍵沒有反應 | 點開該快速鍵並檢查 **按鍵方式**：是設定為按住、單擊、雙擊，還是需同時按下的組合鍵。 |
| 影片裡或另一台 Mac 上的快速鍵按了沒反應 | 你這台 Mac 的快速鍵設定可能不同。請至 **設定 → 快捷鍵** 查詢目前綁定的按鍵。 |

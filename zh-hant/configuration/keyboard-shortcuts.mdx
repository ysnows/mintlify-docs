Enconvo 的視窗與語音功能都各自以快速鍵開啟。**設定 → 快捷鍵** 會列出 Enconvo 使用的每個快速鍵及其執行的指令，讓你可以變更其中一個，或查出某組按鍵的作用。儲存在你 Mac 上的快速鍵永遠優先於本指南中的預設值。

這支影片先介紹快捷鍵，接著介紹其他讓 Enconvo 貼合你 Mac 的設定：上下文感知、Appshots、本機模型、權限與保持喚醒。

## 預設快捷鍵

| 動作 | 預設值 |
| --- | --- |
| 顯示 SmartBar | **⌥Space** |
| 顯示聊天視窗 | **⌃⌘X** |
| 顯示 App 側邊欄 | **⌃⌘E** |
| 在 Enconvo 內開啟設定 | **⌘,** |
| 開始聽寫 | **右側 ⌘** |
| 開始語音指令 | **右側 ⌥** |
| 暫停／繼續音訊 | **⌥P** |

這些預設值只在你從未設定自己的按鍵時適用；你設定過的按鍵會維持不變。快速擷取與 Appshots 沒有預設快速鍵：使用前請先在它們的設定頁面設定一個。

## 變更快速鍵

1. 開啟 **設定 → 快捷鍵**。**核心** 分頁包含主要功能，**其他快速鍵** 包含 AI 指令、外掛程式、設定，以及其他頁面不會顯示的指令，**全部** 則同時顯示兩者。
2. 在 **依名稱篩選…** 中輸入文字以找到指令。若要找出某組按鍵背後的指令，請點按 **依快速鍵尋找** 並按下該組按鍵。
3. 點按該指令的快速鍵欄位，然後按下新的組合。
4. 如果這些按鍵已用於另一個指令，欄位會告訴你。選擇 **在這裡使用** 可將按鍵移到這個指令，或從它建議的空閒快速鍵中挑選一個。
5. 切換到另一個 App，試試快速鍵。

若要釋放某個快速鍵的按鍵，請將它從指令中移除。帶有 **還原** 的訊息可讓你撤銷此動作。

標有 **本機** 徽章的快速鍵只在 Enconvo 內有效，例如固定 SmartBar。

## 按鍵方式

當你單獨錄製一個修飾鍵（例如右側 ⌘）時，欄位會詢問 **按鍵方式**：

| 選項 | 指令在你這樣做時執行 |
| --- | --- |
| **按住或單擊** | 按住該鍵，或單擊以切換 |
| **單擊** | 單擊該鍵開始，再單擊一次停止 |
| **按住** | 按住該鍵；按住期間有效 |
| **雙擊** | 快速連按該鍵兩次 |

同時按下兩個或更多修飾鍵，視為一個快速鍵。每個欄位只會顯示其指令支援的類型，旁邊的說明會告訴你該功能如何反應。

## 各功能的快速鍵位置

除了快捷鍵頁面之外，每個功能也在它自己的設定頁面中有自己的快速鍵：

| 功能 | 設定頁面 |
| --- | --- |
| SmartBar | **設定 → SmartBar** |
| 動態島 | **設定 → 動態島** |
| PopBar | **設定 → PopBar** |
| App 側邊欄 | **設定 → App 側邊欄** |
| 聽寫 | **設定 → 聽寫** |
| 語音指令 | **設定 → 語音指令** |
| Appshots | **設定 → Appshots** |
| 螢幕塗鴉 | **設定 → 螢幕塗鴉** |
| 語音筆記 | **設定 → 語音筆記** |
| 快速擷取 | **設定 → 快速擷取** |
| 單一指令 | 該指令的設定（當它有 **快速鍵** 欄位時） |

## 在 SmartBar 中

在 SmartBar 中輸入觸發字元，即可搜尋某一類項目：

| 字元 | 開啟 |
| --- | --- |
| **@** | 指令 |
| **#** | 要加入訊息的上下文 |
| **$** | 技能 |
| **>** | 最近的任務 |

這些字元可在 **設定 → SmartBar** 的 **搜尋** 下變更。斜線選單包含模型與推理選擇等動作。

若要用鍵盤在清單中移動，請在 **設定 → SmartBar** 中選擇 **導覽快速鍵**：**macOS** 使用 **⌃N** **⌃P** **⌃F** **⌃B**，**Vim** 則使用 **⌃J** **⌃K** **⌃L** **⌃H**。

## 讓 Enconvo 貼合你的 Mac

同一個設定視窗還包含影片中介紹的其他選項：

| 設定頁面 | 功能 |
| --- | --- |
| **上下文感知** | 選擇 SmartBar 從你先前所在的 App 擷取什麼：選取的文字、你在 Finder 的選取項目，或瀏覽器中的頁面。**自動加入** 會在 SmartBar 一開啟時就加入，**建議** 則提供一鍵即可加入的選項。請參閱[上下文感知](/zh-hant/features/context-awareness)。 |
| **Appshots** | 以快速鍵將你面前的視窗加入對話。請參閱 [Appshots](/zh-hant/features/appshots)。 |
| **本機模型** | 顯示這台 Mac 上執行的 AI、它使用的記憶體與磁碟，以及各功能在哪裡執行。請參閱[本機模型](/zh-hant/ai/local-llm)。 |
| **權限** | 列出 macOS 允許 Enconvo 做什麼及原因；**授權** 可修復缺少的權限。請參閱 [macOS 權限](/zh-hant/configuration/permissions)。 |
| **保持喚醒** | 在你不在時讓這台 Mac 不進入睡眠，讓你仍能從 iPhone 連上它。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 快速鍵只在 Enconvo 內有效 | 檢查它是否有 **本機** 徽章。若沒有，請檢查 [macOS 權限](/zh-hant/configuration/permissions)中的輸入監控與輔助使用，以及是否有其他 App 使用相同的按鍵。 |
| 按下快速鍵卻執行了別的動作 | 使用 **依快速鍵尋找**。如果沒有任何 Enconvo 指令使用這些按鍵，就是其他 App 或 macOS 在使用。 |
| 修飾鍵快速鍵沒有觸發 | 開啟該快速鍵並檢查 **按鍵方式**：按住、單擊、雙擊，或同時按下多個按鍵。 |
| 影片或另一台 Mac 上的快速鍵無法使用 | 你的快速鍵可能不同。請在 **設定 → 快捷鍵** 中查詢目前的設定。 |

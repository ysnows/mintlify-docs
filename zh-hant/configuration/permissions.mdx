title: "macOS 權限"
description: "查看 Enconvo 使用了哪些 macOS 權限、授予功能所需的權限，以及修復畫面擷取或輸入失效的問題。"
---

部分 Enconvo 功能需要你核准 macOS 權限，例如查看你的螢幕畫面或在其他 App 中輸入文字。**設定 → 權限** 會列出每一項權限、它支援的功能，以及目前是否已授權。純文字對話不需要任何權限，因此 Enconvo 不會在啟動時一次向你索取：只有當你首次使用某項需要權限的功能時，它才會詢問並說明是哪個功能需要這項權限。

## 當 Enconvo 詢問權限時

當你使用需要權限但尚未授權的功能時，Enconvo 會開啟權限視窗、指出該功能名稱，並提供 **開啟系統設定** 按鈕。你也可以選擇 **暫不**。

如果想讓該功能停止詢問，請在視窗中勾選不再詢問該功能。之後除非你到「權限」頁面修改設定，否則該功能不會再彈出詢問。對於螢幕錄製，若權限已開啟但只需要重新啟動 App 才會生效，視窗會提供 **重新開啟** 按鈕。

## 授予權限

1. 開啟 **設定 → 權限**。
2. 找到該權限並點選 **授權**。
3. macOS 會顯示提示視窗，或打開 **系統設定 → 隱私權與安全性** 中的對應項目。針對「輔助使用」與「輸入監控」，請自行在該頁面開啟 Enconvo 的開關。
4. 如果 macOS 要求重新啟動，請結束並重新開啟 Enconvo。
5. 回到 Enconvo，該列就會顯示 **已授權**。請再試一次原本的功能。

當你切回「權限」頁面時，畫面會自動重新檢查權限狀態。點選 **重新整理** 則可立即檢查。

## 查看哪些功能使用某項權限

在每一項權限下方，**使用方** 會列出需要該權限的功能，以及每個功能是否會主動詢問：

| 狀態 | 含義 |
| --- | --- |
| **使用時詢問** | 下次使用該功能時會詢問權限。 |
| **已拒絕 · 按下快速鍵時詢問** | 你先前已拒絕；只有當你按下該功能的快速鍵時才會再次詢問。 |
| **不再詢問** | 你選擇了不再詢問。點選該狀態即可切換回 **使用時詢問**。 |
| **已關閉** 或 **外掛程式已關閉** | 該功能或它所屬的外掛程式目前處於關閉狀態。 |

## 各項權限的用途

| 權限 | 用途 |
| --- | --- |
| 輔助使用 | 讀取 App 介面、點擊、輸入文字與視窗控制：電腦操作、PopBar、取得選取文字與插入文字 |
| 螢幕錄製 | 擷取畫面讓代理程式看見 App 內容：電腦操作、Appshots、螢幕上下文與 OCR 截圖。macOS 可能稱之為「螢幕與系統音訊錄製」，它也涵蓋系統音訊擷取。 |
| 輸入監控 | 當其他 App 在前景時，接收 PopBar、快速鍵與雙擊修飾鍵觸發的全域鍵盤輸入 |
| 麥克風 | 聽寫、語音指令、語音筆記、會議錄音、即時字幕與 Live Talk |
| 通知 | 當代理程式工作階段完成或需要你留意時顯示 macOS 通知 |
| 相機 | 從 SmartBar 相機開關拍攝即時相機照片 |
| 位置 | 動態島上的當地天氣，以及提供給代理程式的所在位置上下文 |
| 自動化 | 透過 Apple Events 控制其他 App：讀取瀏覽器分頁、Finder 選取項目、郵件、訊息與 System Events |
| 區域網路 | 連線到同一網路中另一台電腦上的模型伺服器。此項目不在「權限」頁面中；請前往 **系統設定 → 隱私權與安全性 → 區域網路** 設定。 |

行事曆、提醒事項、備忘錄、郵件與其他 Apple App 則是在 **外掛程式** 頁面進行連接。請參閱 [Apple 生態整合](/zh-hant/integrations/apple-ecosystem)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 權限已開啟，但擷取依然失敗 | 結束並重新開啟 Enconvo，再試一次。確認你開啟開關的是目前正在執行的 Enconvo，而不是舊版本副本。 |
| 功能完全不會詢問它需要的權限 | 檢查 **使用方** 底下該功能的狀態列。如果顯示 **不再詢問**，請點選它切換回來，或直接使用 **授權** 授予權限。 |
| 螢幕錄製顯示已授權但擷取仍失敗 | 在權限視窗點選 **重新開啟**，或結束並重新開啟 Enconvo。 |
| 聽寫能辨識出文字但無法插入 | 檢查輔助使用權限，並確認目標輸入欄位支援鍵盤輸入或貼上動作。 |
| 快速鍵只在 Enconvo 視窗內有效 | 檢查輸入監控與輔助使用權限。若快速鍵與其他 App 衝突，請參閱[鍵盤快速鍵](/zh-hant/configuration/keyboard-shortcuts)。 |
| 另一台電腦上的模型伺服器連不上 | 檢查區域網路權限，並確認該伺服器正在監聽其網路位址。 |
| 代理程式完成時沒有通知橫幅 | 檢查此處的通知權限、macOS 專注模式，以及[通知](/zh-hant/configuration/notifications)中的 **傳送系統通知**。 |

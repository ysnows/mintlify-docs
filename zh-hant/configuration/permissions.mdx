---
title: "macOS 權限"
description: "查看 Enconvo 使用哪些 macOS 權限、授予功能所需的權限，並修復停止運作的擷取或輸入功能。"
---

部分 Enconvo 功能需要 macOS 要求你核准的存取權限，例如查看你的螢幕或在其他 App 中輸入文字。**設定 → 權限** 會列出每一項權限、它支援的功能，以及是否已授權。文字聊天不需要其中任何一項，因此 Enconvo 不會在啟動時詢問：它會在你第一次使用需要權限的功能時才詢問，並說明是哪個功能提出要求。

## Enconvo 何時詢問

當你使用的功能需要尚未授予的權限時，Enconvo 會開啟它的權限視窗，指出該功能，並提供 **開啟系統設定**。你也可以選擇 **暫不**。

若要讓某個功能不再詢問，請在視窗中勾選該功能的 **不再詢問**。之後除非你在權限頁面變更，否則該功能不會再詢問。對於螢幕錄製，若存取權限只是在等待重新啟動，視窗會提供 **重新開啟**。

## 授予權限

1. 開啟 **設定 → 權限**。
2. 找到該權限並點按 **授權**。
3. macOS 會顯示它的提示，或在 **系統設定 → 隱私權與安全性** 中開啟對應的面板。對於輔助使用與輸入監控，請自行在該面板中開啟 Enconvo 的開關。
4. 如果 macOS 要求，請結束並重新開啟 Enconvo。
5. 回到 Enconvo 後，該列會顯示 **已授權**。再試一次該功能。

當你回到此頁面時，它會自動重新檢查。點按 **重新整理** 可立即檢查。

## 查看哪些功能使用某項權限

在每項權限下方，**使用方** 會列出需要它的功能，以及各功能是否會詢問：

| 狀態 | 意義 |
| --- | --- |
| **使用時詢問** | 該功能會在你下次使用時詢問權限。 |
| **已拒絕 · 按快速鍵時詢問** | 你已拒絕；該功能只有在你按下它的快速鍵時才會再次詢問。 |
| **不會詢問** | 你選擇了 **不再詢問**。點按它即可回到 **使用時詢問**。 |
| **關閉** 或 **外掛已關閉** | 該功能或它所屬的外掛程式已關閉。 |

## 各項權限的用途

| 權限 | 用途 |
| --- | --- |
| 輔助使用 | 讀取 App 介面、點按、輸入與視窗控制：電腦操作、PopBar、選取的文字，以及插入文字 |
| 螢幕錄製 | 讓代理程式看見 App 內容的螢幕截圖：電腦操作、Appshots、螢幕上下文與 OCR 擷取。macOS 可能稱之為「螢幕與系統音訊錄製」，它也涵蓋系統音訊的擷取。 |
| 輸入監控 | 在其他 App 位於前景時，為 PopBar、快速鍵與雙擊修飾鍵觸發提供全域鍵盤輸入 |
| 麥克風 | 聽寫、語音指令、語音筆記、會議錄音、即時字幕與 Live Talk |
| 通知 | 在代理程式工作階段結束或需要你注意時，顯示 macOS 通知 |
| 相機 | 使用 SmartBar 相機切換開關拍攝即時相機照片 |
| 位置 | 動態島中的當地天氣，以及提供給代理程式的位置上下文 |
| 自動化 | 以 Apple 事件控制其他 App：讀取瀏覽器分頁、Finder 選取項目、郵件、訊息與 System Events |
| 區域網路 | 連接到你網路中另一台電腦上的模型伺服器。它不在權限頁面上，請到 **系統設定 → 隱私權與安全性 → 區域網路** 尋找。 |

行事曆、提醒事項、備忘錄、郵件與其他 Apple App 則是在 **外掛程式** 頁面連接。請參閱 [Apple App](/zh-hant/integrations/apple-ecosystem)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 權限已開啟，但擷取仍然失敗 | 結束並重新開啟 Enconvo，然後再試一次。請確認你開啟的是正在執行的 Enconvo App，而不是舊的副本。 |
| 某個功能從未詢問它需要的權限 | 在 **使用方** 下檢查它的那一列。若顯示 **不會詢問**，請點按它，或使用 **授權** 授予權限。 |
| 螢幕錄製顯示已授權，但擷取仍然失敗 | 在權限視窗中點按 **重新開啟**，或結束並重新開啟 Enconvo。 |
| 聽寫顯示了文字但沒有插入 | 檢查輔助使用，並確認目標欄位接受輸入或貼上。 |
| 快速鍵只在 Enconvo 內有效 | 檢查輸入監控與輔助使用。快速鍵與其他 App 衝突的情況，請參閱[鍵盤快速鍵](/zh-hant/configuration/keyboard-shortcuts)。 |
| 無法連接另一台電腦上的模型伺服器 | 檢查區域網路，並確認伺服器在其網路位址上監聽。 |
| 代理程式完成時沒有橫幅通知 | 檢查此處的通知、macOS 專注模式，以及[通知](/zh-hant/configuration/notifications)中的 **傳送系統通知**。 |

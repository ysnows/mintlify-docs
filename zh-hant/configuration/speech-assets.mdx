「詞典」能讓 Enconvo 的語音功能學會你常使用的產品名稱、技術詞彙、縮寫與特殊拼法。「說話者」則會記住你在錄音中命名過的人聲，讓新的錄音自動為你標註說話者。可從 **設定 → 詞典** 與 **設定 → 說話者** 開啟這兩項功能。

## 新增詞彙

1. 開啟 **設定 → 詞典** 並點擊 **新增詞彙**。
2. 輸入偏好的拼寫方式，若有幫助也可加上簡短說明。
3. 在 **誤辨識為** 中，可選填聽寫時常將此詞誤寫成的詞彙，多個項目以逗號分隔。
4. 點擊 **儲存**，然後試著錄一段包含該詞彙的簡短語音。
5. 檢查語音轉寫結果。服務供應商的支援程度與音訊品質仍會影響辨識效果。

## 一次新增多個詞彙

在 **新增至詞典** 視窗中，切換至 **批次新增** 並每行輸入一個詞彙。使用 `|` 分隔說明文字：

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 接受建議的寫法

詞典會列出 **建議的寫法**：你在聽寫後立刻手動修正過的詞彙，以及聽寫反覆將你的詞彙寫成的拼法，系統會建議將它們加入 **誤辨識為** 項目。點擊 **接受**，下次聽寫就會改寫成正確拼法；或點擊 **忽略**。

## 從你的修改中學習

在 **設定 → 詞典** 中開啟 **從我的修改中學習** 後，當你手動修正聽寫出來的名稱時，系統會將它加入詞典以便下次使用。動態島會顯示學到的內容並提供 **復原**。學到的拼法會在該詞彙下方標示為 **已學習**；在該處移除後，Enconvo 就不會再次學習它。

## 編輯或刪除詞彙

使用搜尋與編輯按鈕保持清單最新。若要刪除多個詞彙，點擊 **選取**、勾選詞彙、點擊 **刪除** 並確認即可。

## 為說話者命名

1. 開啟一段包含多位說話者的錄音。
2. 在逐字稿中點擊某個說話者標籤並為該人命名。
3. Enconvo 會登錄該聲音，並在新的錄音中自動辨識。

在重新命名說話者前，請先檢查錄音中的說話者標註。辨識出的聲音或說話者區分標籤可能會出錯，特別是在多人同時講話時。

**設定 → 說話者** 會列出你命名過的每個人，並顯示他們出現在多少筆錄音中。你可以在該處重新命名或刪除說話者。刪除說話者會將其標籤恢復為說話者編號，錄音本身仍會保留。

## 適用範圍

[聽寫](/zh-hant/features/dictation)、[會議錄音](/zh-hant/features/meeting-recording)、[語音轉寫](/zh-hant/features/transcription)與[即時字幕](/zh-hant/features/live-captioning)各自擁有獨立的語音設定。請查看各服務供應商的語言提示、熱詞（hot words）、說話者區分與其他選項，因為不同服務供應商處理詞彙的方式並不相同。

詞典會教 Enconvo 的語音功能認識你使用的產品名稱、技術術語、縮寫和特殊拼寫。說話者則會保存你在錄音中命名過的聲音名稱，讓新的錄音自動為它們加上標籤。請從**設定 → 詞典**和**設定 → 說話者**開啟。

## 新增字詞

1. 開啟**設定 → 詞典**並點選**新詞**。
2. 輸入偏好的拼寫，若有幫助，也可加上簡短說明。
3. 在**誤辨識為**中，可選擇性輸入聽寫會寫成什麼而不是這個字詞，多個之間以逗號分隔。
4. 點選**儲存**，然後試著錄一小段包含該字詞的錄音。
5. 檢視轉錄結果。辨識結果仍會受到供應商支援程度和音質影響。

## 一次新增多個字詞

在**加入字典**視窗中，切換到**批次新增**，每行輸入一個詞彙。說明以 `|` 分隔：

```text
Enconvo | AI assistant for macOS
Project Atlas | Internal project name
PostgreSQL
```

## 採納建議的寫法

詞典會列出**建議的寫法**：包括你在聽寫後立刻修正的字詞，以及聽寫一再為你的字詞寫成的某種拼寫，它會把這些作為**誤辨識為**項目提出建議。點選**採納**，聽寫下次就會照這樣寫，或點選**關閉**。

## 從你的修改中學習

在**設定 → 詞典**中開啟**從我的修改中學習**後，你手動修正的聽寫名稱會加入詞典，供下次使用。動態島會顯示學到了什麼，並附有**還原**。學會的拼寫會在其字詞下方標示為**已學會**；在那裡移除後，Enconvo 就不會再學一次。

## 編輯或刪除字詞

使用搜尋和編輯按鈕讓清單保持最新。若要刪除多個字詞，請點選**選取**、選擇字詞、點選**刪除**，然後確認。

## 為說話者命名

1. 開啟一段有多位說話者的錄音。
2. 在逐字稿中點選說話者標籤，並為這個人命名。
3. Enconvo 會登錄這個聲音，並在新的錄音中自動辨識。

重新命名說話者之前，請先檢查錄音中的說話者指派。辨識出的聲音或說話者分離標籤可能有誤，尤其是在大家同時說話時。

**設定 → 說話者**列出你命名過的每個人，以及他們出現在多少段錄音中。你可以在那裡重新命名或刪除說話者。刪除說話者會讓他們的標籤變回說話者編號；錄音則會保留。

## 適用範圍

[聽寫](/zh-hant/features/dictation)、[會議錄音](/zh-hant/features/meeting-recording)、[語音轉寫](/zh-hant/features/transcription)和[即時字幕](/zh-hant/features/live-captioning)各自使用自己的語音設定。請檢查各供應商的設定中的語言提示、熱詞、說話者分離和其他選項，因為各供應商處理詞彙的方式並不相同。

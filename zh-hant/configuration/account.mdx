你的 Enconvo 帳號保存了你的方案、你的 Cloud 點數，以及使用它們的 Mac。你在 **設定 → 帳號** 登入。設定側邊欄中位於其下的頁面涵蓋團隊、同步、點數用量、用量統計、推廣聯盟和兌換代碼。工作區位於 **設定 → 工作區**。

這段影片依序介紹你的帳號、團隊、工作區和同步。

<Note>
Enconvo 帳號、供應商 API 金鑰，以及供應商訂閱登入是各自獨立的連線。使用你自己 API 金鑰的請求，採用供應商帳號的計費和限額。訂閱登入會在供應商的設定頁面上顯示它自己的用量，與 Enconvo Cloud 點數分開。請參閱[憑證](/zh-hant/configuration/credentials)。
</Note>

## 登入

1. 開啟 **設定 → 帳號**。
2. 點擊 **登入**，或點擊 **註冊** 建立帳號。
3. 在你的瀏覽器中完成登入。如果瀏覽器已經登入，網站會詢問要使用哪個帳號。Enconvo 會帶你回來。
4. **個人資料** 會顯示你登入所用的名稱和電子郵件。

在登入完成期間，聊天視窗側邊欄中的一張卡片會跟隨它，直到你的帳號載入完成。網路速度慢時它會說明，若帳號沒有載入，則提供 **重試**。如果登入失敗或你取消了，請再次點擊 **登入**。

若要登出，請點擊頁面底部的 **登出**。

### 更換你的頭像

你的頭像會顯示給好友、團隊成員和會議中的人。如果你使用 Google 登入，在你挑選其他圖片之前，會顯示你的 Google 頭像。

1. 在 **設定 → 帳號** 中，點擊頭像旁的 **更換頭像**，如果還沒有頭像則點擊 **新增頭像**。
2. 選擇 **上傳照片…** 並挑選一張圖片。
3. 拖曳照片以在圓圈中定位，用滑桿縮放，然後點擊 **儲存**。

同一個選單中有 **使用 Google 頭像**，可回到你的 Google 頭像，以及 **移除頭像**，改為顯示你的姓名縮寫。

### 新增電子郵件或密碼

**設定 → 帳號** 中的 **登入方式** 區段會顯示你的帳號如何登入。如果你使用 Apple 註冊並選擇了「隱藏我的電子郵件地址」，你的電子郵件會顯示為已由 Apple 隱藏。

1. 點擊 **新增電子郵件**，輸入你自己的電子郵件，並輸入寄到該信箱的代碼。之後你就可以用該電子郵件登入。
2. 點擊 **設定密碼**，即可在 enconvo.com 和 Enconvo Feedback 上以電子郵件和密碼登入。如果你已經有密碼，按鈕會是 **重設密碼**，而且不會要求輸入舊密碼。

iPhone 和 Android App 中也有相同的區段。

## 查看你的方案和點數

**設定 → 帳號** 會顯示你的帳號擁有什麼：

| 區段 | 顯示內容 |
| --- | --- |
| **點數** | 你的 **總餘額**。**查看用量** 會開啟點數用量，**儲值** 則購買更多點數。 |
| **終身授權** | 你的授權等級，**標準** 或 **進階版**、購買時間、更新和支援的期限，以及你的裝置。沒有授權時，**取得終身版** 會顯示各種選項，當提供免費標準版試用時，會出現 **開始試用**。 |
| **團隊** | 你的席次，當你是團隊管理員時顯示，附有 **管理團隊**。 |
| **Enconvo Cloud** | 你的 Cloud 等級、計費期間、下次計費日期、點數重設時間，以及你的裝置。**取得 Cloud 方案** 或 **升級** 可變更它，**檢視價格** 則開啟模型和服務的費率。 |

在底部，**管理帳單** 會在瀏覽器中開啟你的帳單詳細資料。當終身購買仍可退款時，那裡也會出現 **申請退款**。退款會讓帳號回到免費方案，並撤銷其贈送的點數。

### 裝置

每個方案涵蓋一定數量的 Mac，**裝置** 會顯示你使用了多少。達到上限時，頁面會顯示 **已達裝置數量上限**，這台 Mac 就無法執行指令。請點擊 **管理裝置**，移除你不再使用的 Mac，然後啟用這一台，或選擇裝置數量更多的方案。

## 團隊

團隊讓你購買席次，並以電子郵件將每個席次分配給一個人。每個人都用自己的帳號登入，你也可以與他們共用 Cloud 點數。只有團隊管理員會在設定側邊欄中看到 **團隊**。

1. 開啟 **設定 → 團隊**。頂端會顯示 **已分配席次**、**空閒席次** 和 **儲值點數**。
2. 在 **分配席次** 下，輸入該人登入 Enconvo 所用的電子郵件，並點擊 **分配**。
3. 在他們第一次登入 Enconvo 之前，席次會顯示 **待生效**，之後則顯示 **已啟用**。

他們的帳號會獲得進階版功能，以及一台 Mac 的終身更新，並讓他們的對話、記憶和知識庫保持私密。你只能看到席次和點數總額。

每位成員的 **席次操作** 選單有：

| 操作 | 作用 |
| --- | --- |
| **轉入點數** | 將點數從你的儲值餘額轉到他們的餘額。這些點數永不過期。 |
| **收回點數** | 將他們尚未花掉的點數移回你的儲值餘額。 |
| **取消分配席次** | 立即讓他們的帳號回到免費方案。它會保留自己的資料，轉入的點數會回到你這裡。對於你自己的席次，這是 **放棄你的席次**。 |

每個席次對應一台 Mac。點擊某一列上的 **+**，即可讓該帳號（包含你的帳號）在更多 Mac 上登入。**增加席次** 可購買更多。

**團隊知識庫** 會列出與你團隊中每個人共享的知識庫。若要共享一個，請開啟它的 **⋯** 選單並開啟團隊存取。成員的知識庫在他們與團隊共享之前會保持私密。

## 工作區

工作區讓客戶或某項工作的內容與你自己的工作分開。每個工作區都有自己的對話、記憶、知識、登入資料和設定，其中任何內容都不會出現在另一個工作區。工作區從未更改的設定會跟隨 **個人**，也就是你自己的工作。

### 建立工作區

1. 在聊天視窗側邊欄頂端，點擊顯示 **個人** 的工作區選單，並選擇 **新增工作區…**。你也可以在 **設定 → 工作區** 中點擊 **新增工作區…**。
2. 第一次時，一份簡短的指南 **什麼是工作區？** 會說明三件事：**工作互不干擾**、**在側邊欄頂部切換**，以及 **從「個人」開始**。點擊 **繼續**。
3. 輸入 **工作區名稱**，例如你替其工作的客戶，並點擊 **建立**。

聊天視窗會在新的工作區中開啟。它的對話、記憶和知識一開始是空的，「個人」中的任何內容都不會出現在那裡。

### 切換工作區

點擊聊天視窗側邊欄頂端的工作區選單並挑選一個工作區。或按 **⌃⌘1** 到 **⌃⌘9**：數字是該工作區在清單中的位置，所以 **⌃⌘1** 是「個人」。

每個視窗在一個工作區中運作，多個工作區中的工作可以同時執行。

### 哪些內容保持分開

每個工作區都有自己的對話、記憶、知識、登入資料和設定。程式開發代理程式的對話會留在它們開始時所在的工作區內，而新的[空間](/zh-hant/features/spaces)會在每個工作區中保有各自獨立的資料。新的工作區在你於其中變更某項設定之前，會使用你「個人」的設定。

若要在工作區中為連接器指定它自己的帳號，請切換到該工作區，在外掛程式頁面上開啟該連接器，並在帳號的 **⋯** 選單中選擇 **設為預設**。該帳號會顯示 **預設用於** 和工作區的名稱，代理程式會在那裡使用它，除非你在請求中指定另一個帳號。

如果你是團隊管理員，**團隊** 頁面讓你將每位成員放入你的一個或多個工作區。成員接著只會看到、聊天和通話於與他們共享工作區的團隊成員。

### 重新命名或刪除工作區

開啟 **設定 → 工作區**。**個人** 永遠在最前面：它的設定是每個工作區的起點，而且無法重新命名或刪除。

其他每個工作區的那一列都有 **重新命名** 和 **刪除**。刪除工作區會連同它的對話、記憶、知識和設定一併帶走。它會在 **最近刪除** 下保留 7 天，**還原** 可以將它找回。

你也可以請代理程式列出、建立、重新命名、重新著色、重新排序、刪除或還原你的工作區。它在刪除之前會先確認。

## 同步你的 Mac

同步會讓登入你帳號的每台電腦上的對話、設定、技能、外掛程式、知識庫和成品保持一致。它是 Enconvo Cloud 方案和終身授權的一部分。

1. 在每台電腦上以同一個 Enconvo 帳號登入。
2. 開啟 **設定 → 同步** 並開啟 **多台電腦同步**。
3. 如果 Enconvo 詢問要將同步的內容保存在哪裡，請選擇你的 **Enconvo 帳號** 或 **iCloud**。你之後可以在 **儲存空間** 下變更。
4. 在 **同步內容** 下，選擇要包含哪些項目。

| 項目 | 同步的內容 | 留在這台電腦上的內容 |
| --- | --- | --- |
| **聊天** | 附有圖片和檔案的聊天記錄、標題、專案，以及已封存的對話 | |
| **設定** | 模型、提示、外掛程式偏好設定、你的片語，以及你建立的 AI 指令、代理程式和工作流程 | 登入資料、快速鍵和資料夾路徑 |
| **技能** | 你安裝或製作的技能，以及每個技能是否開啟。從 GitHub 安裝的技能會保留它的來源，因此你的其他電腦也會檢查它的更新 | 隨外掛程式提供的技能會留在外掛程式中 |
| **外掛程式** | 你從 Enconvo 商店、GitHub、npm 或連結安裝的外掛程式：你的其他電腦也會安裝它們，並解除安裝你解除安裝的項目 | 內建外掛程式、你正在開發的外掛程式、連接器和登入資料 |
| **知識庫** | 你的知識庫和記憶，連同其中的筆記、文字和網頁 | 匯入的檔案和錄音 |
| **作品** | 你的[作品](/zh-hant/features/artifacts)及其每個版本：頁面、文件、設計、簡報、儀表板、圖片和影片。當兩台 Mac 同時變更同一個作品時，兩個版本都會保留 | 超過 32 MB 的檔案，以及共享的文件和設計 |
| **API 金鑰** | 內建供應商的 API 金鑰，在離開這台電腦之前會先加密 | 登入資料和自訂供應商 |

密碼和登入資料絕不會離開電腦。以你的 Enconvo 帳號作為儲存空間時，新電腦只有在你的另一台電腦允許後，才會取得你的 API 金鑰：確認兩者顯示相同的代碼，然後點擊 **允許**。**備用密碼短語** 讓電腦在你的其他電腦都不在手邊時，也能取得你的 API 金鑰。使用 iCloud 時，登入同一個 iCloud 的 Mac 會自行取得金鑰。

**立即同步** 會馬上同步，**你的電腦** 則列出每台進行同步的電腦。**清除同步資料** 會刪除所有同步到你帳號或 iCloud 的內容，涵蓋每台電腦。你電腦上的內容會保留，同步會在這台電腦上關閉，並在其他電腦上暫停，直到你再次開啟。

## 點數用量與用量統計

**設定 → 點數用量** 會顯示你的 Enconvo Cloud 點數：

- **總餘額**：你現在可以花用的全部點數。訂閱點數會優先使用。
- **訂閱餘額**：你的每月或每年額度，在每次續訂時重設為方案的額度。
- **儲值餘額**：來自儲值包和終身授權的點數。它們永不過期。
- 依模型區分的每日用量圖表，以及每筆扣款的 **歷史記錄**。

在 **歷史記錄** 中，可依 **記錄類型** 和 **模型** 篩選，用 **跳到日期** 挑選某一天，並查看每天使用的點數。

**設定 → 用量統計** 會顯示 Enconvo 呼叫的每個 AI 供應商（包含你自己的金鑰）的費用、Token 和請求。可在 **費用**、**Token 數** 和 **請求** 之間切換，挑選 **24h**、**7d**、**30d** 或 **90d**，並依模型、供應商或功能細分數字。費用是依供應商 API 定價所做的估算。

## 推廣聯盟

**設定 → 推廣聯盟** 會提供你的連結和代碼；選單列選單中的 **推廣聯盟…** 也會開啟它。舊版本將此頁面稱為 **邀請好友**。用 **複製連結** 或 **複製程式碼** 來分享。每個人都有一個連結，`enconvo.com/i/<your code>`。

- **你的朋友** 在以你的連結或代碼註冊，然後在對 Enconvo 而言是新裝置的裝置上登入 Enconvo App 後，會獲得 250,000 Cloud 點數（5 美元）。在網頁上登入不算。
- **你** 在朋友於註冊後 30 天內付款時，會獲得朋友首次付款的 20%，以 Cloud 點數計算（50,000 點 = 1 美元）。年度方案以其年費除以 12 計算。
- 方案的分潤會立即入帳。終身授權的分潤會等待 30 天，也就是它的退款期；在這段期間內退款會取消它。
- 只有付款才算，朋友從哪個裝置或 App 付款並不重要。
- 如果你的朋友在付款前開啟了別人的連結，則最後開啟的連結會獲得獎勵。結帳時輸入的促銷代碼優先於任何連結，而且一筆付款絕不會同時支付點數和推廣聯盟佣金。

邀請碼無法用於臨時或代理程式的電子郵件地址，邀請好友的人數也沒有上限。**你的邀請紀錄** 會顯示每位朋友，以及你的分潤進度：等待他們首次付款、在退款期內，或已賺取。

如果有朋友邀請了你，請在 **有邀請碼嗎？** 下輸入他們的代碼並點擊 **兌換**。

### 改賺現金

部落客、創作者，以及任何擁有受眾的人，都可以申請[推廣聯盟計畫](https://www.enconvo.com/affiliate)，無論有沒有使用 App。獲准後，同一個連結會對你推薦的人的每筆付款（包含續訂）賺取 20% 的現金佣金。訂閱佣金可立即支付，終身授權佣金則在 30 天退款期之後支付。款項在每月 1 日以 PayPal 或 Wise 發放，一旦你的餘額達到 50 美元；較小的餘額會順延。你在獲准前賺到的點數仍屬於你。如果你的申請未獲核准，可以在 60 天後再次申請。完整規則請見[推廣聯盟計畫條款](https://www.enconvo.com/affiliate/terms)。

## 兌換代碼

1. 開啟 **設定 → 兌換代碼**。
2. 貼上代碼，或它所附的連結，並點擊 **繼續**。

授權碼和免信用卡的試用會立即在你的帳號上啟用。團隊授權碼會讓你的帳號成為該代碼所含席次的團隊管理員，每個席次含 50,000 Cloud 點數；請參閱[團隊](#團隊)。需要信用卡的試用會在你的瀏覽器中開啟結帳，並在你確認之前顯示它的續訂條款。

## 關於你

若要向你的代理程式介紹你自己，請開啟 **設定 → 關於你**。你所有的代理程式、語音通話和虛擬形象都會使用你在那裡寫的內容，因此請只加入你想用來個人化它們回覆的內容。

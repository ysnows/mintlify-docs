你的 Enconvo 帳號保存了你的方案、Cloud 點數以及使用它們的 Mac。你可以在**設定 → 帳號**登入。設定側邊欄中它下方的頁面涵蓋了團隊、同步、點數用量、用量統計、邀請好友與兌換代碼。工作區則位於**設定 → 工作區**。

這部影片依序介紹了你的帳號、團隊、工作區與同步功能。

<YouTubePlayer videoId="FnddgYQfcTc" title="如何在 Enconvo 中使用團隊與工作區 | 分步教學" />

<Note>
Enconvo 帳號、服務供應商 API 金鑰與服務供應商訂閱登入是各自獨立的連線。使用你自己的 API 金鑰發送的請求會套用該服務供應商帳號的計費與限額。訂閱登入會在該服務供應商的設定頁面顯示自己的用量，與 Enconvo Cloud 點數分開計算。參閱[憑證](/zh-hant/configuration/credentials)。
</Note>

## 登入

1. 開啟**設定 → 帳號**。
2. 點擊**登入**，或點擊**註冊**建立帳號。
3. 在瀏覽器中完成登入。如果瀏覽器已經登入，網站會詢問要使用哪個帳號。完成後 Enconvo 會帶你回到應用程式。
4. **個人資料**會顯示你登入所使用的名稱與電子郵件。

在登入完成之前，聊天視窗側邊欄中的卡片會持續追蹤進度直到你的帳號載入完成。網路較慢時會顯示提示；若帳號未能載入，卡片會提供**重試**。如果登入失敗或你取消了登入，請再次點擊**登入**。

若要登出，請點擊頁面底部的**登出**。

### 更換個人頭像

你的個人頭像會顯示給好友、團隊成員以及會議中的其他人。如果你使用 Google 登入，在選擇其他照片前會先顯示你的 Google 頭像。

1. 在**設定 → 帳號**上，點擊頭像旁的**更換頭像**；若尚未設定頭像，請點擊**新增頭像**。
2. 選擇**上傳照片…**並挑選一張圖片。
3. 拖曳照片將其置於圓圈內，用滑桿縮放比例，然後點擊**儲存**。

同一個選單中也提供**使用 Google 頭像**（可恢復使用 Google 頭像）與**移除頭像**（改為顯示你的名字縮寫）。

### 新增電子郵件或密碼

**設定 → 帳號**上的**登入方式**區段會顯示你的帳號如何登入。如果你使用 Apple 登入並啟用了隱藏我的電子郵件，你的電子郵件會顯示為由 Apple 隱藏。

1. 點擊**新增電子郵件**，輸入你自己的電子郵件，並填入寄送到該信箱的驗證碼。之後就能使用該電子郵件登入。
2. 點擊**設定密碼**，即可使用電子郵件與密碼登入 enconvo.com 與 Enconvo 意見回饋頁面。如果你已經設定過密碼，按鈕會顯示為**重設密碼**，且不會要求輸入舊密碼。

iPhone 與 Android 應用程式中也有相同的區段。

## 查看方案與點數

**設定 → 帳號**會顯示你帳號擁有的項目：

| 區段 | 顯示內容 |
| --- | --- |
| **點數** | 你的**總餘額**。**查看用量**會開啟點數用量，**儲值**可購買更多點數。 |
| **終身授權** | 你的授權等級（**標準**或 **Premium**）、購買時間、更新與支援的有效期限，以及你的裝置。沒有授權時會顯示**取得終身版**以檢視選項；若有提供免費標準版試用，則會出現**開始試用**。 |
| **團隊** | 當你是團隊管理員時，顯示你的席次與**管理團隊**。 |
| **Enconvo Cloud** | 你的 Cloud 等級、計費週期、下次扣款日期、點數重置時間與你的裝置。**取得 Cloud 方案**或**升級**可變更方案，**檢視價格**則開啟模型與服務的費率。 |

在頁面底部，**管理帳單**會在瀏覽器中開啟你的帳單詳細資料。當終身授權購買仍可退款時，該處也會出現**申請退款**。退款會將帳號退回免費方案，並扣回其贈送點數。

### 裝置

每個方案都涵蓋固定數量的 Mac，**裝置**會顯示你目前使用了幾台。達到上限時，頁面會顯示**已達裝置數量上限**，這台 Mac 將無法執行指令。點擊**管理裝置**，移除一台不再使用的 Mac 然後啟用這一台，或是選擇包含更多裝置的方案。

## 團隊

團隊功能讓你可以購買席次，並透過電子郵件將每個席次分配給一位成員。每個人都以自己的帳號登入，而且你可以與他們共享 Cloud 點數。只有團隊管理員會在設定側邊欄看見**團隊**。

1. 開啟**設定 → 團隊**。頂部會顯示**已分配席次**、**空閒席次**與**儲值點數**。
2. 在**分配席次**下方輸入對方登入 Enconvo 使用的電子郵件，然後點擊**分配**。
3. 在對方首次登入 Enconvo 之前，席次會顯示**待生效**，之後便會顯示為**已啟用**。

對方的帳號會在一台 Mac 上獲得 Premium 功能與終身更新，同時保有各自聊天、記憶與知識庫的隱私。你只會看到席次與點數總額。

每位成員的**席次操作**選單包含：

| 操作 | 作用 |
| --- | --- |
| **轉入點數** | 將點數從你的儲值餘額轉給對方。這些點數永不過期。 |
| **收回點數** | 將對方尚未使用的點數轉回你的儲值餘額。 |
| **取消分配席次** | 立即將對方的帳號恢復為免費版。該帳號的資料會保留，轉入的點數則會退回給你。針對你自己的席次，此項目為**放棄你的席次**。 |

每個席次對應一台 Mac。點擊列表列上的 **+** 可讓該帳號（包含你自己的）登入更多台 Mac。**增加席次**可購買更多席次。

**團隊知識庫**列出與團隊中所有人共享的知識庫。若要分享某個知識庫，請開啟它的 **⋯** 選單並開啟團隊存取權限。在成員主動與團隊分享之前，他們自己的知識庫會維持私密。

## 工作區

工作區能將客戶或特定工作的內容與你自己的日常事務區隔開來。每個工作區都有各自獨立的聊天、記憶、知識、登入狀態與設定，彼此之間互不出現。某個工作區未曾更動過的設定，會跟隨你的**個人**工作區。

下方影片示範為客戶建立工作區、切回個人工作區，以及在設定中管理工作區。

### 建立工作區

1. 在聊天視窗側邊欄頂部，點擊顯示為**個人**的工作區選單，選擇**新建工作區…**。你也可以在**設定 → 工作區**中點擊**新建工作區…**。
2. 首次使用時，名為**什麼是工作空間？**的簡短引導會說明三件事：**將工作分開**、**在側邊欄頂部切換**，以及**從個人開始**。點擊**繼續**。
3. 輸入**工作區名稱**（例如你的客戶名稱），然後點擊**建立**。

聊天視窗會在新工作區中開啟。裡面的聊天、記憶與知識最初為空，來自個人的任何內容都不會出現在此處。

### 切換工作區

點擊聊天視窗側邊欄頂部的工作區選單並選擇一個工作區。或者按下 **⌃⌘1** 到 **⌃⌘9**：數字代表工作區在列表中的順序，因此 **⌃⌘1** 就是個人。

每個視窗在單一工作區中運作，而多個工作區中的工作可以同時進行。

### 哪些項目會保持獨立

每個工作區都有自己的聊天、記憶、知識、登入狀態與設定。程式開發代理程式的聊天會留在啟動時所在的工作區內，新建的[空間](/zh-hant/features/spaces)也會在每個工作區中分開保存資料。新工作區會沿用你的個人設定，直到你在其中修改某一項為止。

若要讓連接器在某個工作區中使用專屬帳號，請先切換到該工作區，在外掛程式頁面開啟該連接器，並在對應帳號的 **⋯** 選單中選擇**設為預設**。該帳號會顯示為該工作區的預設帳號，除非你在請求中另外指定其他帳號，否則代理程式在該工作區都會使用它。

如果你是團隊管理員，**團隊**頁面可讓你將每位成員加入一個或多個工作區。之後成員只會看到、聯絡並呼叫與自己共用同一個工作區的隊友。

### 重新命名或刪除工作區

開啟**設定 → 工作區**。**個人**永遠排在第一位：它的設定是每個工作區起始時的基準，無法重新命名或刪除。

其他每個工作區的列表列上都有**重新命名**與**刪除**。刪除工作區會將其中的聊天、記憶、知識與設定一併帶走。它會在**最近刪除**中保留 7 天，點擊**還原**即可復原。

你也可以請代理程式列出、建立、重新命名、變更顏色、調整順序、刪除或還原你的工作區。在刪除之前它會先向你確認。

## 同步你的 Mac

同步功能會讓登入你帳號的每台電腦上的聊天、設定、技能、外掛程式、知識庫與作品保持一致。它包含在 Enconvo Cloud 方案與終身授權中。

1. 在每台電腦上使用相同的 Enconvo 帳號登入。
2. 開啟**設定 → 同步**，並開啟**多台電腦同步**。
3. 如果 Enconvo 詢問要將同步資料存放在哪裡，請選擇你的 **EnConvo 帳號**或 **iCloud**。你之後可以在**儲存空間**底下更改。
4. 在**同步內容**底下選擇要包含的項目。

| 項目 | 同步的內容 | 留在此電腦上的內容 |
| --- | --- | --- |
| **聊天** | 包含圖片與檔案的聊天歷史記錄、標題、專案與已封存的聊天 | |
| **設定** | 模型、提示詞、外掛程式偏好設定、你的文字片段，以及你建立的 AI 指令、代理程式與工作流程 | 登入資訊、快速鍵與資料夾路徑 |
| **技能** | 你安裝或製作的技能，以及各自是否開啟。從 GitHub 安裝的技能會保留來源，讓你的其他電腦也能檢查更新 | 隨外掛程式附帶的技能仍留在外掛程式中 |
| **外掛程式** | 你從 Enconvo 商店、GitHub、npm 或連結安裝的外掛程式：你的其他電腦也會安裝它們，並同步解除安裝你移除的項目 | 內建外掛程式、你正在開發中的外掛程式、連接器與登入資訊 |
| **知識庫** | 你的知識庫與記憶，包含其中的筆記、文字與網頁 | 匯入的檔案與錄音 |
| **作品** | 你的[作品](/zh-hant/features/artifacts)及其所有版本：網頁、文件、設計、投影片、儀表板、圖片與影片。當兩台 Mac 同時編輯同一個作品時，兩個版本都會保留 | 超過 32 MB 的檔案，以及共享文件與設計 |
| **API 金鑰** | 內建服務供應商的 API 金鑰，在離開此電腦前會先經過加密 | 登入資訊與自訂服務供應商 |

密碼與登入資訊永遠不會離開電腦。使用你的 Enconvo 帳號作為儲存空間時，新電腦只有在獲得你其他任一台電腦允許後才能取得 API 金鑰：確認兩台電腦顯示的驗證碼相同，再點擊**允許**。**備用密碼短語**則能讓電腦在身邊沒有其他電腦時取回 API 金鑰。使用 iCloud 時，登入同一個 iCloud 的各台 Mac 會自行取得金鑰。

**立即同步**會馬上進行同步，**你的電腦**會列出每一台參與同步的電腦。**清除同步資料**會從所有電腦中刪除同步至你帳號或 iCloud 的所有資料。原本在你電腦上的資料會保留下來，此電腦上的同步會關閉，其他電腦上的同步則會暫停，直到你再次開啟為止。

## 點數用量與用量統計

**設定 → 點數用量**顯示你的 Enconvo Cloud 點數：

- **總餘額**：目前可立即使用的所有點數。會優先扣抵訂閱點數。
- **訂閱餘額**：你的每月或每年額度，會在每次續訂時重置為方案額度。
- **儲值餘額**：來自儲值包與終身授權的點數。永不過期。
- 依模型劃分的每日用量圖表，以及每筆扣款的**歷史記錄**。

在**歷史記錄**中，可依**記錄類型**與**模型**篩選，用**跳到日期**指定某一天，並查看每天使用的點數。

**設定 → 用量統計**顯示 Enconvo 呼叫過的所有 AI 服務供應商（包含你自己的金鑰）之費用、Token 數與請求數。可在**費用**、**Token 數**與**請求**之間切換，選擇 **24h**、**7d**、**30d** 或 **90d**，並依模型、服務供應商或功能細分數據。費用是以各服務供應商的 API 牌價估算。

## 邀請好友

**設定 → 邀請好友**會提供你一組邀請連結與代碼。點擊**複製連結**或**複製程式碼**即可分享。

臨時信箱或代理程式電子郵件地址無法使用邀請碼。當好友透過你的邀請註冊，接著在一台對 Enconvo 而言是全新的裝置上登入 Enconvo 應用程式後，你們雙方各會獲得點數。邀請好友數量沒有上限，但僅在網頁上登入不予計算。**你的邀請紀錄**會顯示誰已加入以及你獲得的獎勵。

如果有好友邀請了你，請在**有邀請碼嗎？**底下輸入對方的代碼並點擊**兌換**。

## 兌換代碼

1. 開啟**設定 → 兌換代碼**。
2. 貼上代碼或包含代碼的連結，然後點擊**繼續**。

授權代碼與免綁卡試用會立即在你的帳號生效。團隊授權代碼會使你的帳號成為該代碼所含席次的團隊管理員，每個席次附帶 50,000 點 Cloud 點數；參閱[團隊](#團隊)。需要綁卡的試用會在瀏覽器開啟結帳頁面，並在你確認之前顯示續訂條款。

## 關於你

要讓你的代理程式更了解你，請開啟**設定 → 關於你**。你所有的代理程式、語音通話與虛擬形象都會參考你寫在那裡的內容，因此請只加入你希望用來個人化回覆的資訊。

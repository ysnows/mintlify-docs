Enconvo 可以在代理程式工作階段結束時透過展開動態島、發送 macOS 通知，或同時透過兩者來通知你。你可以在 **設定 → 通知** 中進行設定，並設定不希望被打擾的安靜時段。

## 設定完成通知

1. 開啟 **設定 → 通知**。
2. 若頁面提示 **Enconvo 的通知功能已關閉**，請點擊 **啟用**，或在 **系統設定 → 通知** 中允許 Enconvo 傳送通知。
3. 在 **工作階段結束時** 下方開啟或關閉各個開關。兩者獨立運作。
4. 發起一個簡短的代理程式請求並等待它完成。

| 設定 | 作用 |
| --- | --- |
| **開啟動態島** | 當你從動態島發起的工作階段結束時，動態島會自動展開顯示結果。 |
| **傳送系統通知** | 在工作階段結束時發送包含回覆開頭內容的 macOS 通知。點擊通知即可在原本發起的視窗中重新開啟該工作階段。 |

即使開啟這些開關，macOS 的「專注模式」與通知設定仍可能會隱藏橫幅。

## 安靜時段

安靜時段會將代理程式的提問、郵件提醒與已完成的任務暫緩至安靜時段結束為止，適用於這台 Mac 以及你配對的 iPhone。在等待期間不會替你核准任何操作。

1. 在 **設定 → 通知** 中找到 **Updates (Outreach)**。
2. 開啟 **安靜時段**，然後設定 **開始** 與 **結束** 時間。
3. 選擇哪些通知仍可照常傳達：

| 設定 | 作用 |
| --- | --- |
| **核准請求照常提醒** | 核准請求在安靜時段期間仍會通知你。 |
| **提問照常提醒** | 代理程式的提問在安靜時段期間仍會通知你。 |

Enconvo 選單列選單中也提供 **安靜時段** 與適合短暫休息的 **暫停通知 1 小時**。

郵件提醒預設為關閉，直到你在 **排程工作 → 重要郵件** 中開啟它。你先前已開啟或設定好的郵件提醒仍會繼續運作。其中的 **手機** 開關會將提醒傳送至已配對的 iPhone 或 Android 手機。

## 排程任務的結果

系統通知與將排程任務的結果傳送至 Telegram 或其他即時通訊聊天不同。結果的傳送方式請在[排程任務](/zh-hant/workflows/scheduled-jobs)的編輯器中設定。

排程任務也可以在執行時發送自己的 Mac 通知（**執行時通知我**）。該通知同樣遵循 **傳送系統通知** 設定。任務的執行紀錄會顯示每次執行是否成功以及結果是否已送達。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 工作階段結束時沒有看到通知橫幅 | 確認 **傳送系統通知** 已開啟、macOS 允許 Enconvo 的通知，且未因「專注模式」而被隱藏。 |
| 動態島沒有展開 | **開啟動態島** 僅適用於你從動態島發起的工作階段。 |
| 提問或已完成任務延遲送達 | 可能是被安靜時段暫緩了。開啟 **提問照常提醒**，或調整 **開始** 與 **結束** 時間。 |

Enconvo 可以在代理程式工作階段結束時通知你：開啟動態島、發出 macOS 通知，或兩者並用。你在 **設定 → 通知** 中設定這些，並可設定安靜時段，避免在你不想被打擾的時間受到干擾。

## 設定完成提醒

1. 開啟 **設定 → 通知**。
2. 如果頁面顯示 **Enconvo 的通知已關閉**，請點按 **啟用**，或在 **系統設定 → 通知** 中允許 Enconvo。
3. 在 **工作階段結束時** 下，開啟或關閉各個開關。它們彼此獨立運作。
4. 發出一個簡短的代理程式請求，並等待它完成。

| 設定 | 功能 |
| --- | --- |
| **開啟動態島** | 當你從動態島開始的工作階段結束時，動態島會展開顯示結果。 |
| **傳送系統通知** | 當工作階段結束時，發出一則帶有回覆開頭的 macOS 通知。點按該通知，即可在該工作階段開始時所在的視窗中重新開啟它。 |

即使這些開關已開啟，macOS 的專注模式與通知設定仍可能隱藏橫幅。

## 安靜時段

安靜時段會暫時保留代理程式的提問、郵件提醒與已完成的任務，直到安靜時間結束，在這台 Mac 與你配對的 iPhone 上皆是如此。等待期間不會替你核准任何事項。

1. 在 **設定 → 通知** 中找到 **動態**。
2. 開啟 **安靜時段**，然後設定 **開始時間** 與 **結束時間**。
3. 選擇哪些仍然可以通過：

| 設定 | 功能 |
| --- | --- |
| **核准請求照常提醒** | 核准請求在安靜時段仍會送達你。 |
| **提問照常提醒** | 代理程式的提問在安靜時段仍會送達你。 |

Enconvo 選單列選單中也有 **安靜時段**，以及用於短暫休息的 **暫停動態 1 小時**。

郵件提醒預設關閉，直到你在 **排程工作 → 重要郵件** 中開啟。你先前已開啟或已設定的郵件提醒會繼續運作。它們的 **手機** 開關會將提醒傳送到已配對的 iPhone 或 Android 手機。

## 排程結果

系統通知與將排程任務的結果傳送到 Telegram 或其他即時通訊聊天是不同的。結果的傳送方式在[排程任務](/zh-hant/workflows/scheduled-jobs)的編輯器中設定。

排程任務在執行時也可以發出它自己的 Mac 通知（**執行時通知我**）。該通知同樣遵循 **傳送系統通知**。任務的執行紀錄會顯示每次執行是否成功，以及結果是否已送達。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 工作階段結束時沒有橫幅 | 確認 **傳送系統通知** 已開啟、macOS 允許 Enconvo 的通知，且專注模式沒有隱藏它們。 |
| 動態島沒有開啟 | **開啟動態島** 只適用於你從動態島開始的工作階段。 |
| 提問或已完成的任務延遲送達 | 可能是安靜時段暫時保留了它。開啟 **提問照常提醒**，或變更 **開始時間** 與 **結束時間**。 |

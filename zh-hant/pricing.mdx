Enconvo 將應用程式本身與它呼叫的 AI 服務分開計費。授權用來解鎖應用程式功能；AI 服務則可來自 Enconvo Cloud 點數、你自己的 API 金鑰、你登入的服務供應商方案，或運行在你 Mac 上的本機模型，各自在對應處結算。請查看**設定 → 帳號**與 Enconvo 網站，了解你帳號目前適用的方案與價格。

## AI 服務的付費方式

| 存取方式 | 涵蓋範圍 | 用量顯示位置 |
| --- | --- | --- |
| Enconvo 終身授權 | 應用程式功能使用權 | **設定 → 帳號**中的**終身授權** |
| Enconvo Cloud 方案 | Cloud 模型與服務，以點數計費 | **設定 → 點數用量** |
| 你自己的 API 金鑰 | 傳送給該服務供應商的請求 | 該服務供應商自己的 API 帳號 |
| 你登入的服務供應商方案 | 該方案支援的功能與限額 | 設定中該服務供應商的頁面 |
| 本機模型 | 消耗你 Mac 的運算資源、記憶體與儲存空間，以及下載的模型檔案 | 你的 Mac |

購買應用程式授權並不會附加任何服務供應商的付費 API 額度；同樣地，服務供應商的聊天訂閱方案也不會包含該供應商的所有 API 服務。

## Enconvo 方案

- **終身授權**：單次買斷應用程式，分為標準版（Standard）與 Premium 版，並附贈點數。你可以不限次數地搭配自己的 API 金鑰使用 AI。Teams 是專為組織設計的終身授權：你可以購買席次，並透過電子郵件將每個席次分配給成員。參閱[團隊](/zh-hant/configuration/account)。
- **Enconvo Cloud**：提供 Plus、Pro 與 Max 等級的月繳或年繳方案，每月提供點數以及不需 API 金鑰即可使用的 Cloud 模型。
- **標準版試用**：免費帳號可獲得一次性的 7 天標準版免綁卡試用。符合資格時，**設定 → 帳號**中會顯示**開始試用**。
- **代碼**：授權代碼與試用代碼可在**設定 → 兌換代碼**中啟用。團隊授權代碼會使你的帳號成為該代碼所含席次的團隊管理員，每個席次附帶 50,000 點 Cloud 點數。

終身授權一律稱為標準版（Standard）與 Premium 版，不會與 Cloud 方案的 Plus、Pro 等級名稱重複。

- [Enconvo Cloud 方案](https://www.enconvo.com/cloud-plan)
- [Cloud 模型定價](https://www.enconvo.com/cloud-pricing)

## Cloud 點數的扣除方式

會優先使用訂閱點數，訂閱點數會在每次續訂時重置為你的方案額度。儲值點數（來自儲值包與終身授權）永不過期。

單次請求的點數消耗取決於所使用的模型，以及該功能實際採用的存取方式。文字、圖片、影片、語音轉寫、嵌入與即時語音各自有不同的費率。

## 檢查異常的用量

1. 若使用的是 Enconvo Cloud，請開啟**設定 → 點數用量**；若使用的是自己的 API 金鑰，請查看該服務供應商自己的用量頁面。
2. 開啟**設定 → 用量統計**，依模型、服務供應商與功能檢視估算費用、Token 數與請求次數。
3. 檢查是否有共用同一個服務供應商設定檔的排程工作、長時間執行的任務、知識庫檢索或生成請求。

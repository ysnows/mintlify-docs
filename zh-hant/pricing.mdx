Enconvo 將 App 與其呼叫的 AI 分開計費。授權用來解鎖 App；AI 則可以來自 Enconvo Cloud 點數、你自己的 API 金鑰、你登入的服務供應商方案，或你 Mac 上的模型，每一種都在各自的地方計費。你的帳號目前可取得的方案與價格，請查看 **設定 → 帳號** 與 Enconvo 官方網站。

## AI 的付費方式

| 方式 | 涵蓋內容 | 用量查看位置 |
| --- | --- | --- |
| Enconvo 終身授權 | App 功能使用權 | **設定 → 帳號** 中的 **終身授權** |
| Enconvo Cloud 方案 | 以點數付費的雲端模型與服務 | **設定 → 點數用量** |
| 自備 API 金鑰 | 對該服務供應商發出的請求 | 該服務供應商自己的 API 帳號 |
| 你登入的服務供應商方案 | 該方案支援的功能與額度 | 設定中該服務供應商的頁面 |
| 本機模型 | 使用你 Mac 的運算、記憶體與儲存空間，以及模型下載 | 你的 Mac |

購買 App 授權並不會為任何服務供應商增加付費的 API 額度。服務供應商的聊天方案也不包含該服務供應商的所有 API。

## Enconvo 方案

- **終身授權**：一次性購買 App，分為 Standard 與 Premium 兩個等級，並附贈點數。你可以盡情搭配自己的 API 金鑰使用 AI。Teams 是供組織使用的終身授權：你購買席次，並以電子郵件逐一指派。請參閱 [Teams](/zh-hant/configuration/account)。
- **Enconvo Cloud**：按月或按年訂閱的方案，分為 Plus、Pro 與 Max 等級。每月加發點數，並提供無需 API 金鑰的雲端模型。
- **Standard 試用**：免費帳號可取得一次性的 7 天 Standard 試用，無需信用卡。提供試用時，**設定 → 帳號** 中會出現 **開始試用**。
- **代碼**：授權碼與試用碼可在 **設定 → 兌換代碼** 啟用。Teams 授權碼會讓你的帳號成為該代碼所含席次的 團隊管理員，每個席次附 50,000 雲端點數。

終身授權一律稱為 Standard 與 Premium，以免與 Plus 和 Pro 雲端方案同名。

如需最新的方案與價格：

- [Enconvo 官方網站](https://www.enconvo.com)
- [Enconvo Cloud 方案](https://www.enconvo.com/cloud-plan)
- [雲端模型價格](https://www.enconvo.com/cloud-pricing)

## 雲端點數的使用方式

會優先使用訂閱點數，並在每次續訂時重設為你方案的額度。儲值點數（來自儲值包與終身授權）永不過期。

一次請求的費用取決於功能實際使用的模型與存取方式。文字、圖片、影片、語音轉寫、嵌入與即時語音的計價可能各不相同。

## 檢查異常用量

1. 開啟 **設定 → 點數用量** 查看 Enconvo Cloud 的用量；若使用自備 API 金鑰，則查看該服務供應商自己的用量頁面。
2. 開啟 **設定 → 用量統計**，依模型、服務供應商與功能查看預估費用、Token 與請求數。
3. 留意共用同一個服務供應商設定檔的排程任務、長時間執行的任務、檢索與生成請求。

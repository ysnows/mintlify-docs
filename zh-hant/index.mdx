Enconvo 讓你在 Mac 的每個 App 中，只要按一下快速鍵就能使用 AI。提出問題、聽寫訊息、改寫你選取的文字，或是把整個任務交給代理程式，完全不必離開手邊的工作。

## 選擇你的 AI

你可以從免設定的 [Enconvo Cloud](/zh-hant/providers/enconvo) 開始、使用你已訂閱的方案（例如 ChatGPT 或 Claude）登入、加入你自己的 API 金鑰，或是在 Mac 上執行模型。[服務供應商](/zh-hant/providers/overview)頁面比較了各種選項。

## 隨身攜帶

[iPhone App](/zh-hant/integrations/iphone-app) 能與你 Mac 上的代理程式對話，而[手機聊天](/zh-hant/integrations/iphone-phone-chats)則直接在 iPhone 上執行。

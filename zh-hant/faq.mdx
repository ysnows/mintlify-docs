## 開始使用

<AccordionGroup>
  <Accordion title="Enconvo 支援哪些 Mac？">
    macOS 14 或更新版本，Apple Silicon 與 Intel 機型皆可。部分裝置端功能（例如 [Local LLM (MLX)](/zh-hant/providers/mlx)）需要 Apple Silicon。參閱[安裝](/zh-hant/installation)。
  </Accordion>
  <Accordion title="我需要 API 金鑰嗎？">
    不需要。登入你的 Enconvo 帳號後，不需 API 金鑰就能使用 [Enconvo Cloud](/zh-hant/providers/enconvo)。你也可以登入自己原本就有付費的方案（例如 ChatGPT 或 Claude）、加入自己的 API 金鑰，或在 Mac 上本機執行模型。參閱[服務供應商](/zh-hant/providers/overview)。
  </Accordion>
  <Accordion title="付費購買 Enconvo 與付費使用 AI 有什麼不同？">
    授權會解鎖應用程式功能。AI 費用則依執行地點計費：Enconvo Cloud 點數、你自己的服務供應商帳號，或你自己的 Mac。參閱[方案與定價](/zh-hant/pricing)。
  </Accordion>
  <Accordion title="我可以使用自己的語言來操作 Enconvo 嗎？">
    可以。在**設定 → 一般 → 語言**下的 **App 語言**中，可從十二種介面語言（包含烏克蘭文與俄文）中選擇。代理程式則會使用你在同一處設定的**回覆語言**回答你。參閱[語言、外觀與設定搜尋](/zh-hant/configuration/appearance-language)。
  </Accordion>
  <Accordion title="為什麼 Enconvo 會在用到某個功能時才請求權限？">
    Enconvo 不會在啟動時一次請求所有 macOS 權限。它只會在你第一次用到需要某項權限的功能時才向你詢問，並說明是哪個功能需要該權限。勾選**不再詢問**即可停止該功能再次跳出詢問。參閱[macOS 權限](/zh-hant/configuration/permissions)。
  </Accordion>
  <Accordion title="文件裡介紹的功能在我的應用程式中找不到，為什麼？">
    部分功能會優先在 Beta 頻道推出。請檢查你的應用程式版本與[更新頻道](/zh-hant/configuration/updates)，並在[功能目錄](/zh-hant/reference/feature-directory)中查詢該功能。
  </Accordion>
</AccordionGroup>

## 模型

<AccordionGroup>
  <Accordion title="我該使用哪一個模型？">
    如果不確定該選哪個，維持使用 [Auto Route](/zh-hant/providers/auto-route) 即可：它會為每則訊息挑選合適的模型。若想自行挑選，請參閱[選擇模型](/zh-hant/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="我更改了預設模型，為什麼我的聊天還是在用舊的模型？">
    既有聊天會保留開始對話時使用的模型，直到你在該聊天中手動更改為止。專案與代理程式也各自保有自己的預設模型。參閱[選擇模型](/zh-hant/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="使用本機模型能讓所有資料完全離線嗎？">
    只有運行於本機服務供應商的步驟會保持離線。網頁搜尋、遠端 MCP 伺服器、雲端語音與雲端嵌入模型仍會透過網路傳送資料離開你的 Mac。參閱[本機模型](/zh-hant/ai/local-llm)與[隱私權與安全性](/zh-hant/configuration/privacy-security)。
  </Accordion>
</AccordionGroup>

## 語音

<AccordionGroup>
  <Accordion title="聽寫、語音指令與 Live Talk 有什麼差別？">
    [聽寫](/zh-hant/features/dictation)會把你說的話直接打進你正在使用的應用程式。語音指令會將你說的內容作為請求傳送給代理程式。[Live Talk](/zh-hant/features/live-voice) 則是與代理程式進行的雙向語音對話。
  </Accordion>
  <Accordion title="Enconvo 可以錄製與轉寫會議嗎？">
    可以。[會議錄音](/zh-hant/features/meeting-recording)能夠邊錄邊轉寫，而[語音轉寫](/zh-hant/features/transcription)則能處理你現有的音訊與影片檔案。
  </Accordion>
</AccordionGroup>

## 上下文與知識

<AccordionGroup>
  <Accordion title="Appshots 與快速擷取有什麼差別？">
    [Appshots](/zh-hant/features/appshots) 會將你眼前正在看的應用程式視窗附加到提問中。[快速擷取](/zh-hant/features/quick-capture)則會將螢幕上的內容儲存到知識庫中供日後查閱。
  </Accordion>
  <Accordion title="記憶與知識庫有什麼差別？">
    [記憶](/zh-hant/ai/memory)儲存代理程式認識你的事實並重複使用。[知識庫](/zh-hant/ai/knowledge-base)存放你加入的文件，由代理程式搜尋其中內容以回答問題。兩者皆位於知識庫分頁中：欄位頂部的**知識庫** / **記憶**切換開關可在兩者間切換。
  </Accordion>
  <Accordion title="其他 AI 應用程式也能使用我的 Enconvo 知識庫嗎？">
    可以，透過[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp) 即可實現。你可以自行開啟此功能，並限制只開放你挑選的知識庫。
  </Accordion>
</AccordionGroup>

## 代理程式與自動化

<AccordionGroup>
  <Accordion title="代理程式可以使用其他應用程式和服務的工具嗎？">
    可以，透過[外掛程式](/zh-hant/extensions/overview)、[技能](/zh-hant/configuration/skills)與 [MCP 伺服器](/zh-hant/features/mcp)即可。只要你允許，代理程式也能操作你的[瀏覽器](/zh-hant/features/browser-control)與[應用程式](/zh-hant/features/computer-use)。
  </Accordion>
  <Accordion title="我可以限制代理程式的指令能接觸哪些範圍嗎？">
    可以。在代理程式的**權限**標籤中開啟**沙盒**，它的指令就只能修改工作資料夾與暫存目錄，且無法讀取你的金鑰或控制其他應用程式。參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。
  </Accordion>
  <Accordion title="我不在電腦前時任務也能執行嗎？">
    可以。只要 Enconvo 正在運行且你的 Mac 處於喚醒狀態，[排程工作](/zh-hant/workflows/scheduled-jobs)就會按排程執行。連接[即時通訊管道](/zh-hant/integrations/messaging)即可在聊天應用程式中接收結果。
  </Accordion>
</AccordionGroup>

  </Accordion>
</AccordionGroup>

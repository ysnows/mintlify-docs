## 開始使用

<AccordionGroup>
  <Accordion title="Enconvo 可以在哪些 Mac 上執行？">
    macOS 14 或更新版本，支援 Apple Silicon 與 Intel。部分裝置端功能（例如[本機 LLM (MLX)](/zh-hant/providers/mlx)）需要 Apple Silicon。請參閱[安裝](/zh-hant/installation)。
  </Accordion>
  <Accordion title="我需要 API 金鑰嗎？">
    不需要。登入你的 Enconvo 帳號後，[Enconvo Cloud](/zh-hant/providers/enconvo) 無需金鑰即可使用。你也可以使用你已付費的方案（例如 ChatGPT 或 Claude）登入、新增自己的 API 金鑰，或在你的 Mac 上執行模型。請參閱[服務供應商](/zh-hant/providers/overview)。
  </Accordion>
  <Accordion title="為 Enconvo 付費與為 AI 付費有何不同？">
    授權用來解鎖 App。AI 則在它執行的地方計費：Enconvo Cloud 點數、你的服務供應商帳號，或你自己的 Mac。請參閱[方案與價格](/zh-hant/pricing)。
  </Accordion>
  <Accordion title="我可以用自己的語言使用 Enconvo 嗎？">
    可以。在 **設定 → 一般 → 語言** 的 **App 語言** 中，從十二種介面語言（包含烏克蘭文與俄文）中選擇一種。代理程式會以你的 **回覆語言** 回覆，該設定位於同一處。請參閱[語言、外觀與設定搜尋](/zh-hant/configuration/appearance-language)。
  </Accordion>
  <Accordion title="為什麼我使用某個功能時，Enconvo 會要求權限？">
    Enconvo 不會在啟動時要求 macOS 權限。它會在你第一次使用需要權限的功能時才詢問，並指出是哪個功能。勾選 **不再詢問** 即可讓某個功能不再詢問。請參閱 [macOS 權限](/zh-hant/configuration/permissions)。
  </Accordion>
  <Accordion title="這些文件中的某個功能在我的 App 裡找不到。為什麼？">
    有些功能會先在測試版頻道推出。請檢查你的版本與[更新頻道](/zh-hant/configuration/updates)，然後在[功能目錄](/zh-hant/reference/feature-directory)中查詢該功能。
  </Accordion>
</AccordionGroup>

## 模型

<AccordionGroup>
  <Accordion title="我該使用哪個模型？">
    如果你不確定，請保留[自動路由](/zh-hant/providers/auto-route)：它會為每則訊息挑選一個模型。若想自己選擇，請參閱[選擇模型](/zh-hant/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="我更改了預設模型，為什麼我的聊天仍使用舊的模型？">
    聊天會保留它開始時使用的模型，直到你在該聊天中更改為止。專案與代理程式也有各自的預設值。請參閱[選擇模型](/zh-hant/ai/model-selection-guide)。
  </Accordion>
  <Accordion title="使用本機模型就能讓一切都保持離線嗎？">
    只有在本機服務供應商上執行的步驟才會離線。網頁搜尋、遠端 MCP 伺服器、雲端語音與雲端嵌入，仍會將資料傳出你的 Mac。請參閱[本機模型](/zh-hant/ai/local-llm)與[隱私與安全](/zh-hant/configuration/privacy-security)。
  </Accordion>
</AccordionGroup>

## 語音

<AccordionGroup>
  <Accordion title="聽寫、語音指令與 Live Talk 有什麼不同？">
    [聽寫](/zh-hant/features/dictation)會將你說的話輸入到你正在使用的 App 中。語音指令會將你說的話作為請求傳送給代理程式。[Live Talk](/zh-hant/features/live-voice) 則是與代理程式來回進行的口語對話。
  </Accordion>
  <Accordion title="Enconvo 可以錄製並轉寫會議嗎？">
    可以。[會議錄音](/zh-hant/features/meeting-recording)會邊進行邊錄製並轉寫，而[語音轉寫](/zh-hant/features/transcription)則適用於你已有的音訊與影片檔案。
  </Accordion>
</AccordionGroup>

## 上下文與知識

<AccordionGroup>
  <Accordion title="Appshots 與快速擷取有什麼不同？">
    [Appshots](/zh-hant/features/appshots) 會將你正在看的 App 視窗附加到問題中。[快速擷取](/zh-hant/features/quick-capture)則會將螢幕上的內容儲存到知識庫，供日後使用。
  </Accordion>
  <Accordion title="記憶與知識庫有什麼不同？">
    [記憶](/zh-hant/ai/memory)保存代理程式了解到並重複使用的、關於你的事實。[知識庫](/zh-hant/ai/knowledge-base)則保存你新增的文件，代理程式會搜尋它們來找出答案。兩者都在知識庫中：其欄位頂端的 **知識庫** / **記憶** 開關可在兩者之間切換。
  </Accordion>
  <Accordion title="其他 AI App 可以使用我的 Enconvo 知識庫嗎？">
    可以，透過[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp)，由你開啟，並限制在你選擇的知識庫。
  </Accordion>
</AccordionGroup>

## 代理程式與自動化

<AccordionGroup>
  <Accordion title="代理程式可以使用其他 App 與服務的工具嗎？">
    可以，透過[外掛程式](/zh-hant/extensions/overview)、[技能](/zh-hant/configuration/skills)與 [MCP 伺服器](/zh-hant/features/mcp)。在你允許時，代理程式也可以使用你的[瀏覽器](/zh-hant/features/browser-control)與 [App](/zh-hant/features/computer-use)。
  </Accordion>
  <Accordion title="我可以限制代理程式的指令能接觸什麼嗎？">
    可以。在代理程式的 **權限** 標籤中開啟 **沙盒**，它的指令就只能變更工作資料夾與暫存資料夾，且無法讀取你的金鑰或控制其他 App。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。
  </Accordion>
  <Accordion title="我不在時，任務可以執行嗎？">
    可以。[排程工作](/zh-hant/workflows/scheduled-jobs)會在 Enconvo 執行且你的 Mac 保持喚醒時依排程執行。連接[即時通訊管道](/zh-hant/integrations/messaging)，即可在聊天 App 中收到結果。
  </Accordion>
</AccordionGroup>

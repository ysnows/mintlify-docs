---
title: "安裝"
description: "在 Mac 上安裝 Enconvo、保持最新版本，並排解安裝問題。"
---

Enconvo 需要 macOS 14 或更新版本，支援 Apple Silicon 與 Intel Mac。部分裝置端功能（例如 [本機 LLM (MLX)](/zh-hant/providers/mlx)）需要 Apple Silicon，本機模型也需要足夠的記憶體與磁碟空間。

在 Windows 10 與 11 (x64) 上，測試版以桌面 App 的形式執行。請參閱 [Windows（測試版）](/zh-hant/getting-started/windows)。

在 Linux 上，測試版可於桌面與伺服器上執行。請參閱 [Linux（測試版）](/zh-hant/getting-started/linux)。

## 安裝

<Steps>
  <Step title="下載">
    從 [enconvo.com](https://www.enconvo.com) 下載適合你 Mac 處理器的 DMG。
  </Step>
  <Step title="移到「應用程式」">
    開啟 DMG，將 **Enconvo** 拖曳到**應用程式**。
  </Step>
  <Step title="開啟 Enconvo">
    開啟**應用程式**中的 Enconvo，並依照歡迎畫面的步驟操作。接著繼續閱讀[快速入門](/zh-hant/quickstart)。
  </Step>
</Steps>

只保留**應用程式**中的那一份。快速鍵、權限與更新都對應到同一份 App，若其他位置還有第二份，它可能會取得你正在使用的那份所沒有的權限。

## 更新

從 Enconvo 選單列圖示選擇**檢查更新**，或在**設定 → 一般 → 更新**中按一下該選項。若想更早取得新功能，請開啟**設定 → 一般**，將**更新頻道**設為**測試版**或**開發**；預設為**正式環境**。請參閱[更新](/zh-hant/configuration/updates)。

App 與其內建外掛程式是分開更新的。如果缺少某項功能，或功能的行為不同，請兩者都檢查一下。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| App 無法開啟 | 確認你的 Mac 執行 macOS 14 或更新版本，且下載已完成。 |
| 權限已開啟，但功能仍無法使用 | 結束 Enconvo，再從**應用程式**重新開啟。確認沒有舊的副本正在執行。 |
| 本機模型無法下載 | 檢查磁碟空間與網路連線，並確認該模型支援你的 Mac。 |
| 找不到 App 視窗 | 按一下選單列或 Dock 中的 Enconvo 圖示，或按 **⌥Space** 開啟 SmartBar。 |
| macOS 顯示下載的檔案已損毀或無法檢查 | 從 [enconvo.com](https://www.enconvo.com) 重新下載。請勿關閉 macOS 的安全性設定。 |

---
title: "安裝"
description: "在 Mac 上安裝 Enconvo、保持最新版本並解決安裝問題。"
---

Enconvo 可在搭載 Apple Silicon 或 Intel 處理器的 Mac 上執行，系統需求為 macOS 14 或更新版本。部分本機端功能（例如 [Local LLM (MLX)](/zh-hant/providers/mlx)）需要 Apple Silicon，且本機模型也需要足夠的記憶體與磁碟空間。

在 Windows 10 與 11 (x64) 上，Beta 版已提供桌面應用程式。請參閱 [Windows (Beta)](/zh-hant/getting-started/windows)。

在 Linux 上，Beta 版支援桌面環境與伺服器。請參閱 [Linux (Beta)](/zh-hant/getting-started/linux)。

## 安裝

<Steps>
  <Step title="下載">
    從 [enconvo.com](https://www.enconvo.com) 下載符合你 Mac 處理器架構的 DMG 安裝檔。
  </Step>
  <Step title="移至應用程式資料夾">
    開啟 DMG 並將 **Enconvo** 拖曳到 **應用程式**（Applications）資料夾中。
  </Step>
  <Step title="開啟 Enconvo">
    開啟 **應用程式** 資料夾中的 Enconvo 並依照歡迎步驟完成設定，接著繼續閱讀[快速開始](/zh-hant/quickstart)。
  </Step>
</Steps>

請只在 **應用程式** 資料夾中保留一份 Enconvo。所有快捷鍵、系統權限和更新都會指向同一份程式；若在其他位置保留第二份副本，系統權限可能會授與給另一個你實際並未使用的副本。

## 更新

從選單列的 Enconvo 圖示選擇 **檢查更新**，或在 **設定 → 一般 → 更新** 中點擊更新。若想搶先取得新功能，請開啟 **設定 → 一般** 並將 **更新頻道** 設為 **Beta** 或 **Dev**；預設為 **正式環境**。詳見[更新](/zh-hant/configuration/updates)。

主程式與內建外掛程式會分開更新。如果某個功能找不到或行為與平常不同，請檢查兩者是否皆有更新。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| App 無法開啟 | 確認你的 Mac 執行 macOS 14 或更新版本，且安裝檔已完整下載。 |
| 權限已開啟但功能仍無法使用 | 結束 Enconvo，再從 **應用程式** 資料夾重新開啟。確認沒有較舊的副本仍在背景執行。 |
| 本機模型無法下載 | 檢查磁碟空間與網路連線，並確認該模型支援你的 Mac。 |
| 找不到 App 視窗 | 點擊選單列或 Dock 中的 Enconvo 圖示，或按下 **⌥Space** 開啟 SmartBar。 |
| macOS 顯示檔案已損毀或無法驗證 | 請從 [enconvo.com](https://www.enconvo.com) 重新下載全新副本。切勿關閉 macOS 安全設定。 |

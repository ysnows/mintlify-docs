App 側邊欄會在應用程式視窗旁開啟一個 Enconvo 對話。它會自動讀取該應用程式的情境，讓你不必複製貼上內容到獨立視窗，就能直接閱讀、撰寫或處理工作。當你的問題與眼前的應用程式相關時，最適合使用它。

其他情境下，快速提問或執行指令可使用 [SmartBar](/zh-hant/features/smartbar)，需要更多空間檢視歷史記錄與檔案時可使用[聊天視窗](/zh-hant/ai/chat)，處理選取文字可使用 [PopBar](/zh-hant/features/popbar)，而需要常駐螢幕的小型入口則可使用[動態島](/zh-hant/features/dynamic-island)與[桌面寵物](/zh-hant/features/pet)。[視窗管理](/zh-hant/features/window-management)比較了所有介面入口。

下方影片展示了 2.5.13 版中的 App 側邊欄：在 Chrome 旁按 **⌃⌘E** 開啟側邊欄、設定網站上的運作方式、列出影片重點時間軸並跳轉至指定片段，接著壓縮在 Finder 中選取的照片。

## 開啟側邊欄

1. 將需要協助的應用程式切換至前景。
2. 按下 **⌃⌘E**、從 Enconvo 執行**顯示應用程式側邊欄**，或點擊應用程式視窗旁的把手。
3. 提出具體問題，並在傳送前確認附加的情境資訊。

把手平時會保持隱藏，直到你將指標移至應用程式視窗的右側邊緣才會顯示，移開後隨即隱藏。將指標停在把手上可以預覽目前所在頁面的資訊卡片，例如影片長度與字幕狀態。若想讓把手永遠保持顯示，請在**設定 → App 側邊欄**中或把手的右鍵選單裡關閉**僅在視窗邊緣顯示把手**。在 Finder 桌面上，無論是否有開啟 Finder 視窗都會顯示把手。

在代理程式模式下，**權限**標籤決定代理程式在採取行動前何時需要詢問你，而**沙盒**開關則將代理程式的指令限制在工作資料夾內。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

快速鍵可在**設定 → App 側邊欄**中設定。較早版本預設使用 **⇧⌘T**；如果你從未修改過，Enconvo 已將其調整為 **⌃⌘E**。若要變更請參閱[鍵盤快速鍵](/zh-hant/configuration/keyboard-shortcuts)。

## 側邊欄能看到什麼

側邊欄能取得的內容取決於應用程式本身以及你授予的權限：

- 瀏覽器可提供網頁標題、網址與頁面內容。
- Finder 可提供選取的檔案。
- 其他應用程式可提供選取的文字、透過輔助使用讀取的視窗內容，或螢幕截圖。

程式碼編輯器不一定會公開整個專案或所有開啟的檔案。當情境資訊不完整時，請自行加入 [Appshots](/zh-hant/features/appshots) 或附加相關檔案。

試著詢問：「解釋選取的段落」、「幫我把這份草稿改寫得更精簡」，或「描述這個視窗中顯示的內容」。

### 網頁卡片與開場建議

在網頁上，開啟新的側邊欄對話時會先顯示一張該頁面的卡片。影片卡片會顯示影片長度、是否有字幕以及章節數量。卡片下方提供針對該網站設計的開場建議。在 YouTube 上包括**總結這段影片**、**列出附時間戳記的重點時刻**與**顯示逐字稿**，點擊即可直接傳送。

在關於影片的回答中，無論是在內文還是時間軸裡，每個時間點都是一個連結。點擊後影片就會直接跳轉到該時間點。卡片上的影片章節同樣可以直接點擊跳轉。

其他網頁的卡片也會顯示可讀取的資訊，例如文章字數或 PDF 頁數，而且側邊欄會預先讀取網頁內容，讓第一則回覆更快開始。它會直接讀取你目前分頁的內容，絕不會重新載入或更動網頁、開啟第二個分頁，或顯示瀏覽器的偵錯列。

對於沒有字幕的 YouTube 影片，可選擇**轉寫音訊**。Enconvo 會將影片音訊轉寫為文字，並產生附帶時間戳記的摘要。

如果你在對話過程中切換到了另一個網頁，畫面上會出現**目前位於**列，點擊即可改為針對新頁面提問。

內建設定檔已針對 YouTube、Bilibili、GitHub、Reddit、Hacker News、X、Amazon、Gmail、Outlook 與 Stack Overflow 提供專屬開場建議，回答會嚴格依據頁面提供的內容。

### 未安裝擴充功能的 Chromium 瀏覽器

在未安裝 [Enconvo Companion 擴充功能](/zh-hant/features/browser-control)的 Chrome、Edge、Brave、Arc 或其他 Chromium 瀏覽器旁，側邊欄會顯示一張帶有**安裝**按鈕的卡片。擴充功能連線成功後，卡片就會變成網頁卡片。

### 網站專屬設定

卡片上的膠囊標籤會顯示網站名稱與設定來源，例如 **YouTube · 內建**。點擊該膠囊即可修改側邊欄在該網站的運作方式：

| 設定 | 變更內容 |
| --- | --- |
| **讀取網頁** | 允許側邊欄在問題需要時讀取整個網頁內容。 |
| **回答語言** | **我的語言**或**網頁的語言**。 |
| **摘要** | **預設**、**附時間的章節**、**一小段文字**或**重點清單**。 |
| **指令** | 你為這個網站自訂的回答指示。 |
| **開場建議** | 卡片下方顯示的開場建議。可移除既有項目，或在**新增開場建議**中輸入新項目。 |

一旦你修改了任何設定，膠囊標籤就會顯示為**我的**。

### Finder 中的檔案

在 Finder 中選取檔案，然後按下 **⌃⌘E**。開場建議會依你選取的檔案類型而變化。例如選取圖片時，會出現**壓縮選取的圖片**、**將選取的圖片轉換為 JPEG** 與**調整選取的圖片大小**。

側邊欄可以壓縮、轉檔與調整圖片大小，壓縮 PDF，轉換影片與音訊格式，壓縮與解壓縮檔案，以及批次重新命名選取的檔案。每項工作都會在原始檔案旁產生新副本（例如在檔名加上 `-compressed`），並保持原始檔案不變。處理結果會以卡片顯示前後檔案大小與**在 Finder 中顯示**按鈕。若檔案先前已使用相同設定處理過，系統會保留它並標示為**已完成**，不會重複處理。不支援的格式則會顯示明確的提示訊息。

### 插入到應用程式中

Finder、企業微信與 Teams 等聊天 App、SourceTree 等 Git 用戶端、Windsurf 等程式碼編輯器、終端機、筆記 App、Pages 以及 Word，都擁有內建設定檔與專屬開場建議。

在這些應用程式中，回答可能會附帶一個**插入**按鈕。點擊它就能將回覆、提交訊息或指令直接填入應用程式的文字欄位中。插入操作絕不會自動傳送或執行：由你確認無誤後自行按下 Return。如果側邊欄找不到可插入的文字欄位，它會提示你。

### 各應用程式與各網站的預設配置

**設定 → 應用程式**保存了側邊欄支援的每個應用程式設定檔：

| 設定 | 變更內容 |
| --- | --- |
| **附加截圖** | 在每則 App 側邊欄訊息中附帶應用程式視窗的截圖。預設為開啟。 |
| **附加完整介面狀態** | 附加完整的輔助使用介面狀態，而非精簡摘要。這會消耗多出許多的 token。 |
| **技能**、**MCP 伺服器**、**外掛程式** | 為該應用程式預先配置的工具組合，當此應用程式開啟 App 側邊欄對話時提供給代理程式使用。 |

**設定 → 網站**則保存了網站的相同預設配置，當瀏覽器停留在符合的網頁時套用。

## 在應用程式中對話與操作

你可以繼續現有對話、開啟新對話，或使用視窗控制項將側邊欄保持在旁。應用程式情境提供了代理程式可閱讀的資訊；若要讓代理程式替你在應用程式中點擊或輸入，則需要啟用[電腦操作](/zh-hant/features/computer-use)或[使用瀏覽器](/zh-hant/features/browser-control)工具。

## 設定

開啟**設定 → App 側邊欄**。

| 設定 | 變更內容 |
| --- | --- |
| **啟用 App 側邊欄** | 在應用程式視窗旁顯示把手並啟用快速鍵。關閉時兩者皆會停用。 |
| **預設代理程式** | 在側邊欄中負責回答的代理程式。 |
| **對所有 App 隱藏** | 在所有應用程式中隱藏側邊欄把手。 |
| **僅在視窗邊緣顯示把手** | 保持把手隱藏，直到你將指標移到視窗右側邊緣才顯示。預設為開啟。 |
| **當以下應用程式在前景時隱藏 App 側邊欄把手** | 指定永遠不顯示把手的應用程式。 |
| **快速鍵** | 為前景應用程式開啟側邊欄的快速鍵。預設為 **⌃⌘E**。 |

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 側邊欄沒有貼附到應用程式 | 將該應用程式視窗切換至前景，然後重新開啟側邊欄。 |
| 找不到把手 | 將指標移至視窗右側邊緣，或關閉**僅在視窗邊緣顯示把手**。 |
| Chromium 瀏覽器中沒有顯示網頁卡片 | 點擊卡片上的**安裝**按鈕安裝 Enconvo Companion 擴充功能。 |
| 沒有提供**插入**按鈕 | 該應用程式沒有側邊欄可識別的文字欄位。請改用複製回答內容。 |
| 無法讀取應用程式中的文字 | 檢查[權限](/zh-hant/configuration/permissions)中的輔助使用權限、隱藏把手的應用程式清單，以及附加的情境資訊。 |
| 需要更多空間檢視歷史記錄或檔案 | 切換至[聊天視窗](/zh-hant/ai/chat)繼續對話。 |

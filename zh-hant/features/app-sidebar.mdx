App 側邊欄會在 App 視窗旁開啟一個 Enconvo 對話。它會使用該 App 的上下文，讓你不必把資訊複製到另外的聊天中，就能閱讀、寫作或工作。當你的問題與眼前的 App 有關時，就用它。

其他情況請使用：[SmartBar](/zh-hant/features/smartbar) 處理快速提問或指令、需要更多空間放歷史記錄與檔案時使用[聊天視窗](/zh-hant/ai/chat)、[PopBar](/zh-hant/features/popbar) 處理選取的文字，或是[動態島](/zh-hant/features/dynamic-island)與[桌面寵物](/zh-hant/features/pet)這類常駐螢幕的小型入口。[視窗管理](/zh-hant/features/window-management)會將它們全部做比較。

下方的影片展示 2.5.13 中的 App 側邊欄：用 **⌃⌘E** 在 Chrome 旁開啟它、設定它在某個網站上的運作方式、列出影片的重點時刻並跳到其中一個，然後壓縮在 Finder 中選取的照片。

## 開啟側邊欄

1. 將你想尋求協助的 App 移到最前面。
2. 按下 **⌃⌘E**、從 Enconvo 執行**顯示 App 側邊欄**，或按一下 App 視窗旁的把手。
3. 提出具體的問題，並在傳送前檢查附加的上下文。

把手會一直隱藏，直到你將游標移到 App 視窗右側邊緣附近，游標一到就顯示、一離開就隱藏。將游標指向把手，可以看到有關你所在頁面的卡片，例如影片的長度與字幕。若要讓把手一直顯示，請在**設定 → App 側邊欄**或把手的右鍵選單中，關閉**僅在視窗邊緣顯示把手**。在 Finder 桌面上，無論有沒有開啟 Finder 視窗，把手都會出現。

在代理程式模式下，**權限**標籤用來設定代理程式在行動前何時詢問，其**沙盒**開關則會將代理程式的指令限制在工作資料夾內。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

快速鍵在**設定 → App 側邊欄**中設定。較早的版本使用 **⇧⌘T**；如果你從未變更過，Enconvo 已將它改為 **⌃⌘E**。若要變更，請參閱[鍵盤快速鍵](/zh-hant/configuration/keyboard-shortcuts)。

## 側邊欄能看到什麼

側邊欄能取得什麼，取決於 App 以及你授予的權限：

- 瀏覽器可以提供頁面標題、URL 與內容。
- Finder 可以提供選取的檔案。
- 其他 App 可能提供選取的文字、可存取的視窗內容，或螢幕截圖。

程式碼編輯器不一定會提供整個專案或每個開啟的檔案。當上下文不完整時，請加入 [Appshots](/zh-hant/features/appshots)，或自行附加檔案。

試著問問「解釋選取的段落」、「幫我把這份草稿改寫得更簡潔」，或「描述這個視窗中看得到的內容」。

### 頁面卡片與開場建議

在網頁上，新的側邊欄聊天會從該頁面的卡片開始。影片的卡片會顯示它的長度、有沒有字幕，以及有多少個章節。卡片下方是為該網站準備的開場建議。在 YouTube 上，它們是**總結這段影片**、**列出重點時刻與時間戳記**，以及**顯示逐字稿**。按一下其中一個即可傳送。

在有關影片的答案中，每個時間都是連結，無論在文字或時間軸中皆然。按一下它，影片就會跳到該時刻。卡片上影片的章節也是連結。

卡片也會顯示其他頁面上可以讀取的內容，例如文章的長度或 PDF 的頁數，而側邊欄會預先讀取頁面，讓第一個答案更快開始。它會依原樣讀取你的分頁：不會重新載入或變更頁面、不會開啟第二個分頁，也不會顯示瀏覽器的偵錯列。

對於沒有字幕的 YouTube 影片，請選擇**轉錄音訊**。Enconvo 會轉錄影片的音訊，並附上時間戳記進行摘要。

如果你在聊天期間移到另一個頁面，會出現**目前在**一列。按一下它即可詢問有關新頁面的內容。

內建的設定檔有各自的開場建議，涵蓋 YouTube、Bilibili、GitHub、Reddit、Hacker News、X、Amazon、Gmail、Outlook 與 Stack Overflow。它們的答案僅限於頁面所提供的內容。

### 未安裝擴充功能的 Chromium 瀏覽器

在 Chrome、Edge、Brave、Arc 或其他未安裝 [Enconvo Companion 擴充功能](/zh-hant/features/browser-control)的 Chromium 瀏覽器旁，側邊欄會顯示一張附有**安裝**按鈕的卡片。擴充功能連線後，卡片就會變成頁面卡片。

### 網站的設定

卡片上的標籤會顯示網站名稱及其設定的來源，例如 **YouTube · 內建**。按一下該標籤，即可變更側邊欄在該網站上的運作方式：

| 設定 | 變更的內容 |
| --- | --- |
| **讀取網頁** | 當問題需要時，讓側邊欄讀取整個頁面。 |
| **回答語言** | **我的語言**或**網頁的語言**。 |
| **摘要** | **預設**、**附時間的章節**、**一小段文字**或**重點清單**。 |
| **指令** | 你自己針對此網站上答案的指令。 |
| **開場建議** | 顯示在卡片下方的開場建議。可移除其中一個，或在**新增開場建議**中輸入新的。 |

一旦你變更了任何設定，標籤就會顯示**我的**。

### Finder 中的檔案

在 Finder 中選取檔案，然後按 **⌃⌘E**。開場建議會依你選取的內容而定。對於圖片，它們是**壓縮選取的圖片**、**將選取的圖片轉換為 JPEG**，以及**調整選取圖片的大小**。

側邊欄可以壓縮、轉換與調整圖片大小、壓縮 PDF、轉換影片與音訊、壓縮與解壓縮，以及批次重新命名選取的檔案。每項工作都會在原始檔案旁寫入新的副本，例如名稱帶有 `-compressed` 的副本，原始檔案則維持原樣。結果會顯示在卡片中，附上處理前後的大小與**在 Finder 中顯示**。已用相同設定處理過的檔案會被保留並標示為**已完成**，而不會重複處理。不支援的格式會得到清楚的訊息。

### 插入到 App 中

Finder、企業微信與 Teams 等聊天 App、SourceTree 等 git 用戶端、Windsurf 等程式碼編輯器、終端機、筆記 App、Pages 與 Word，都有內建的設定檔與各自的開場建議。

在這些 App 中，答案可能會有**插入**按鈕。按一下它，即可將回覆、提交訊息或指令放進 App 的文字欄位。插入絕不會傳送或執行它：你要自己檢查並按下 Return。當側邊欄找不到可插入的欄位時，它會告訴你。

### 各 App 與各網站的預設值

**設定 → 應用程式**為側邊欄支援的每個 App 提供一個設定檔：

| 設定 | 變更的內容 |
| --- | --- |
| **附加截圖** | 在每則 App 側邊欄訊息中附加 App 視窗的截圖。預設為開啟。 |
| **附加完整介面狀態** | 附加完整的輔助使用狀態，而不是精簡的摘要。會使用多出許多的 token。 |
| **技能**、**MCP 伺服器**、**外掛程式** | 針對此 App 預設，並在該 App 承載 App 側邊欄對話時提供給代理程式。 |

**設定 → 網站**為網站提供相同的預設值，在瀏覽器位於相符頁面時使用。

## 在 App 中聊天與操作

你可以繼續對話、開始新的對話，或使用視窗控制項將側邊欄保持在附近。App 上下文為代理程式提供可閱讀的資訊。若要讓代理程式替你在 App 中點按或輸入，它需要[電腦操作](/zh-hant/features/computer-use)或[使用瀏覽器](/zh-hant/features/browser-control)工具。

## 設定

開啟**設定 → App 側邊欄**。

| 設定 | 變更的內容 |
| --- | --- |
| **啟用 App 側邊欄** | 在 App 視窗旁顯示把手並開啟快速鍵。關閉時，兩者都會消失。 |
| **預設代理程式** | 在側邊欄中回答的代理程式。 |
| **在所有 App 中隱藏** | 在每個 App 中隱藏側邊欄的把手。 |
| **僅在視窗邊緣顯示把手** | 讓把手保持隱藏，直到你將游標移到視窗的右側邊緣。預設為開啟。 |
| **當下列 App 位於最前方時隱藏 App 側邊欄把手** | 把手保持隱藏的 App。 |
| **快速鍵** | 為最前方的 App 開啟側邊欄。預設為 **⌃⌘E**。 |

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 側邊欄沒有附加到 App | 將 App 視窗移到最前面，並再次開啟側邊欄。 |
| 找不到把手 | 將游標移到視窗的右側邊緣，或關閉**僅在視窗邊緣顯示把手**。 |
| Chromium 瀏覽器中沒有頁面卡片 | 從卡片的**安裝**按鈕安裝 Enconvo Companion 擴充功能。 |
| 沒有提供**插入** | 該 App 沒有側邊欄能辨識的文字欄位。請改為複製答案。 |
| 缺少 App 中的文字 | 檢查[權限](/zh-hant/configuration/permissions)中的輔助使用、隱藏把手的 App，以及附加的上下文。 |
| 需要更多空間放歷史記錄或檔案 | 在[聊天視窗](/zh-hant/ai/chat)中繼續。 |

動態島位於螢幕頂端正中央。將指標移向它即可開啟首頁，你可以輸入或說出請求、附加情境資訊、執行快捷操作，或回到進行中的任務。需要快速發出請求，或想在不開啟視窗的情況下隨時留意代理程式的進度時，最適合使用動態島。

其他情境下，透過快速鍵快速提問或執行指令可使用 [SmartBar](/zh-hant/features/smartbar)，處理長篇對話與檔案可使用[聊天視窗](/zh-hant/ai/chat)，在特定 App 旁工作可使用 [App 側邊欄](/zh-hant/features/app-sidebar)，處理選取文字可使用 [PopBar](/zh-hant/features/popbar)，想要桌面上常駐一個互動角色則可使用[桌面寵物](/zh-hant/features/pet)。[視窗管理](/zh-hant/features/window-management)比較了所有介面入口。

## 發起請求

1. 開啟**設定 → 動態島**並開啟**啟用動態島**。
2. 將指標移到螢幕頂端正中央開啟首頁。若想透過鍵盤開啟，請先在**開啟與顯示**分頁設定一個**快捷鍵**。
3. 輸入請求，或點擊任一個**首頁快捷操作**。
4. 傳送前檢查附加的情境資訊。[Appshots](/zh-hant/features/appshots) 與[螢幕塗鴉](/zh-hant/features/screen-doodle)能協助你就其他 App 提問。
5. 追蹤執行進度，並在任務完成後開啟結果。若要中止回覆，請點擊**停止**或按 Esc。

任務執行期間你輸入的訊息會立即顯示。若要切換至聊天視窗，請點擊動態島頂部列的**在聊天視窗中開啟**；若在對話尚未開始前點擊，則會在聊天視窗開啟一個新對話並帶入你已輸入的文字。

在代理程式模式下，**權限**標籤決定代理程式在行動前何時詢問你，而**沙盒**開關則將代理程式的指令限制在工作資料夾內。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

## 在首頁進行計算

在首頁直接輸入算式、單位換算或時間查詢，答案會立即顯示在動態島下方的卡片中。按 Return 可複製結果，或按 **⌘Return** 改為向你的代理程式提問。

計算機支援數學運算、單位、貨幣、日期與時區換算。若想同時查詢任何地點的天氣、航班與當地時間，請在**設定 → 動態島 → 首頁**中開啟**天氣和航班**。系統只會將地點名稱或航班編號傳送給 Open-Meteo、adsbdb 與 adsb.lol。此開關與 [SmartBar](/zh-hant/features/smartbar) 共用。

## 追蹤你的任務

任務列表會顯示正在執行、需要你核准、失敗或已有結果的對話。當有兩個或更多任務同時執行時，它們會收合為單一**任務**標籤。

1. 點擊首頁或瀏海處的任務標籤，列表會原地取代輸入框展開。
2. 直接在對應列中允許或拒絕核准請求。
3. 點擊其他任意對話，即可在該對話最初發起的視窗中開啟。

若要尋找尚未閱讀的對話，請開啟**歷史記錄**並依**未讀**篩選。點擊**全部標為已讀**可一次清除所有未讀狀態，若改變心意還可按**還原**。對話列表也提供**封存聊天**與**刪除聊天記錄**。

## 設定

開啟**設定 → 動態島**，設定分為三個分頁。

### 首頁

| 設定 | 變更內容 |
| --- | --- |
| **首頁快捷操作** | 首頁輸入框旁的快捷操作格線。拖曳快捷操作可重新排列或移至另一頁，將指標移上去並點擊 **×** 可移除，或點擊**新增快捷操作**加入更多項目。 |
| 天氣與小工具頁面 | 在快捷操作之後**新增天氣頁面**或**新增小工具頁面**。 |
| **計算機** | 在首頁輸入時即時解答數學、單位、貨幣、日期與時區問題。 |
| **天氣和航班** | 同時查詢任何地點的天氣、航班與當地時間。與 SmartBar 共用。 |
| **預設代理程式** | 負責回答你在首頁輸入內容的代理程式。空白的首頁一律執行其按鈕顯示的預設代理程式。你可以隨時在輸入框中切換代理程式。 |

點擊**將首頁恢復預設**可還原首頁的預設版面配置。每個分頁都有各自的重置按鈕。

### 開啟與顯示

| 設定 | 變更內容 |
| --- | --- |
| **指向時開啟** | 指標停留多久後開啟：**立即**、**稍作停頓**或**較長停頓**。 |
| **移開時收合** | 指標移開後停留多久再收合：**很快**（半秒）、**標準**或**較慢**。 |
| **快捷鍵** | 從任何 App 中顯示、開啟或收合動態島。 |
| **指向前保持隱藏** | 在你將指標移到螢幕頂端正中央或按下快捷鍵之前，保持收合狀態隱藏不顯示。 |
| **把瀏海區域留給其他 App** | 將指標移到瀏海本身不會開啟動態島，讓其他瀏海 App 可以正常使用該區域。 |
| **彈性** | 動態島展開與收合時的彈跳動畫幅度。 |
| **顯示於** | **所有螢幕**、**跟隨滑鼠**，或你指定的單一顯示器。 |
| **全螢幕時隱藏** | 當某個顯示器上的 App 進入全螢幕時，隱藏該螢幕上處於待機狀態的動態島膠囊，以免遮擋 App 頂部。預設為開啟。僅適用於 App 回報為全螢幕的視窗；單純最大化的視窗不會隱藏。將指標移向動態島或對它說話仍會將它叫出。 |
| **在截圖和錄影中顯示** | 關閉即可避免動態島出現在你擷取或分享的畫面中。 |

### 角色

| 設定 | 變更內容 |
| --- | --- |
| **在動態島上顯示角色** | 你的桌面寵物或預設代理程式的虛擬形象會出現在收合的動態島中，並透過動作反映代理程式目前的狀態。 |
| **角色** | **虛擬形象**或**寵物**。 |
| **動作** | **永遠**、**工作時**或**永不**。 |
| **用作代理程式圖示** | 在聊天視窗中將該角色顯示為預設代理程式的圖示。 |

## 語音與已完成的任務

語音輸入會將你說的話轉成提示詞。若想進行語音對話，請使用 [Live Talk](/zh-hant/features/live-voice)；從 SmartBar 發起的 Live Talk 通話會移至動態島顯示。

若想讓在動態島發起的任務完成時自動開啟動態島，請在[通知](/zh-hant/configuration/notifications)中開啟**開啟動態島**。此設定與 macOS 系統通知分開控制。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 動態島出現在另一個螢幕上 | 檢查**顯示於**設定。 |
| App 全螢幕時動態島消失 | 這是預設行為。將指標移到螢幕頂端即可開啟，或關閉**全螢幕時隱藏**。 |
| 選單列自動隱藏時無法開啟動態島 | 點擊螢幕頂端正中央。 |
| 在首頁輸入算式或查詢沒有反應 | 檢查**首頁**分頁上的**計算機**與**天氣和航班**開關。 |
| 截圖或錄影中看不到動態島 | 請在調整任何權限前，先開啟**在截圖和錄影中顯示**。 |
| 指向時沒有開啟動態島 | 按下它的快捷鍵。如果快捷鍵可以開啟，請檢查**指向時開啟**與**把瀏海區域留給其他 App**。如果完全無法開啟，請檢查**啟用動態島**是否已開啟。 |

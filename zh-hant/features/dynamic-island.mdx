動態島位於螢幕頂端中央。將游標指向它即可開啟首頁，你可以在那裡輸入或口述要求、附加上下文、執行快捷操作，或回到進行中的任務。它適合用來提出快速要求，並在不開啟視窗的情況下掌握你的代理程式正在做什麼。

其他情況請使用：[SmartBar](/zh-hant/features/smartbar) 以快速鍵處理快速提問或指令、[聊天視窗](/zh-hant/ai/chat)處理長時間對話與檔案、[App 側邊欄](/zh-hant/features/app-sidebar)在某個 App 旁工作、[PopBar](/zh-hant/features/popbar) 處理選取的文字，或[桌面寵物](/zh-hant/features/pet)在桌面上放一個角色。[視窗管理](/zh-hant/features/window-management)會將它們全部做比較。

## 開始提出要求

1. 開啟**設定 → 動態島**，並開啟**啟用動態島**。
2. 將游標指向螢幕頂端中央以開啟首頁。若要用鍵盤開啟，請先在**開啟與顯示**分頁中設定**快捷鍵**。
3. 輸入要求，或按一下其中一個**首頁快捷操作**。
4. 傳送前，請檢查所有附加的上下文。[Appshots](/zh-hant/features/appshots) 與[螢幕塗鴉](/zh-hant/features/screen-doodle)可協助你詢問有關其他 App 的內容。
5. 追蹤進度，並在任務完成時開啟結果。若要停止回覆，請按一下**停止**或按 Esc。

任務執行期間輸入的訊息會立即顯示。若要切換到聊天視窗，請按一下動態島頂端列中的**在聊天視窗中開啟**；在聊天開始之前，它會在那裡開啟新的聊天，並帶上你已輸入的內容。

在代理程式模式下，**權限**標籤用來設定代理程式在行動前何時詢問，其**沙盒**開關則會將代理程式的指令限制在工作資料夾內。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

## 在首頁計算

在首頁輸入算式、換算或時間，答案會顯示在動態島下方的卡片中。按下 Return 複製答案，或按 **⌘Return** 改為詢問你的代理程式。

計算機可處理數學、單位、貨幣、日期與時區。若也要查詢天氣、航班與任何地點的時間，請在**設定 → 動態島 → 首頁**中開啟**天氣和航班**。只有地點名稱或航班編號會被傳送，傳送對象為 Open-Meteo、adsbdb 與 adsb.lol。這個開關與 [SmartBar](/zh-hant/features/smartbar) 共用。

## 追蹤你的任務

任務清單會顯示正在執行、需要你核准、已失敗，或已有結果的聊天。當有兩個或更多任務執行時，它們會合併成一個**任務**標籤。

1. 按一下首頁或瀏海區域中的任務標籤。清單會取代輸入框而開啟。
2. 直接在該列中允許或拒絕核准要求。
3. 按一下任何其他聊天，即可在它開始時所在的視窗中開啟。

若要找出尚未閱讀的聊天，請開啟**歷史記錄**並以**未讀**篩選。**全部標為已讀**會清除所有未讀，若你改變主意，可以**還原**。聊天清單也有**封存聊天**與**刪除聊天記錄**。

## 設定

開啟**設定 → 動態島**。它的設定分成三個分頁。

### 首頁

| 設定 | 變更的內容 |
| --- | --- |
| **首頁快捷操作** | 首頁上輸入框旁的快捷操作格。拖曳快捷操作可重新排序或移到另一頁，指向它並按一下 **×** 可移除，或按一下**新增快捷操作**加入更多。 |
| 天氣與小工具頁面 | 在你的快捷操作之後**新增天氣頁面**或**新增小工具頁面**。 |
| **計算機** | 在你於首頁輸入時回答數學、單位、貨幣、日期與時區的問題。 |
| **天氣和航班** | 同時查詢天氣、航班與任何地點的時間。與 SmartBar 共用。 |
| **預設代理程式** | 回答你在首頁輸入內容的代理程式。空白的首頁一律執行其按鈕所顯示的預設代理程式。你隨時可以在輸入框中切換代理程式。 |

**將首頁恢復預設**會還原首頁的預設版面配置。每個分頁都有自己的重設按鈕。

### 開啟與顯示

| 設定 | 變更的內容 |
| --- | --- |
| **指向時開啟** | 游標指向多久後開啟：**立即**、**稍作停頓**或**較長停頓**。 |
| **移開時收合** | 游標離開後保持開啟多久：**很快**（半秒）、**標準**或**較慢**。 |
| **快捷鍵** | 從任何 App 顯示、開啟或收合動態島。 |
| **指向前保持隱藏** | 讓收合的動態島保持隱藏，直到你指向螢幕頂端中央或按下快捷鍵。 |
| **把瀏海區域留給其他 App** | 指向瀏海本身時不會開啟動態島，讓其他瀏海 App 可以使用。 |
| **彈性** | 動態島在開啟與收合時的彈跳程度。 |
| **顯示於** | **所有螢幕**、**跟隨滑鼠**，或你選擇的某個顯示器。 |
| **全螢幕時隱藏** | 當顯示器上的 App 處於全螢幕時，隱藏動態島在該顯示器上的靜止膠囊，避免它遮住 App 的頂端。預設為開啟。只有 App 回報為全螢幕的視窗才算；最大化的視窗不算。指向動態島或對它說話，仍然會叫出它。 |
| **在截圖和錄影中顯示** | 關閉後，動態島就不會出現在你擷取或分享的內容中。 |

### 角色

| 設定 | 變更的內容 |
| --- | --- |
| **在動態島上顯示角色** | 你的桌面寵物或預設代理程式的虛擬形象會出現在收合的動態島中，並演出你的代理程式正在做的事。 |
| **角色** | **虛擬形象**或**寵物**。 |
| **動作** | **永遠**、**工作時**或**永不**。 |
| **用作代理程式圖示** | 在聊天視窗中，將該角色顯示為預設代理程式的圖示。 |

## 語音與完成的任務

語音輸入會將你說的話轉成提示詞。若要進行口語對話，請使用 [Live Talk](/zh-hant/features/live-voice)；從 SmartBar 啟動的 Live Talk 通話會移到動態島。

若要讓你在動態島啟動的任務完成時，動態島自動開啟，請在[通知](/zh-hant/configuration/notifications)中開啟**開啟動態島**。該設定與 macOS 通知是分開的。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 它出現在另一個顯示器上 | 檢查**顯示於**。 |
| App 全螢幕時它消失了 | 這是預設行為。將游標指向螢幕頂端即可開啟，或關閉**全螢幕時隱藏**。 |
| 選單列自動隱藏時它無法開啟 | 按一下螢幕頂端中央。 |
| 首頁上的計算或查詢沒有顯示任何內容 | 檢查**首頁**分頁上的**計算機**與**天氣和航班**。 |
| 截圖或錄影中沒有它 | 在你變更任何權限之前，先開啟**在截圖和錄影中顯示**。 |
| 指向它時不會開啟 | 按下它的快捷鍵。如果快捷鍵能開啟它，請檢查**指向時開啟**與**把瀏海區域留給其他 App**。如果任何方式都無法開啟，請檢查**啟用動態島**。 |

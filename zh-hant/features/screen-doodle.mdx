螢幕塗鴉讓你在詢問 Agent 之前，先在螢幕的一部分上做標記。畫上箭頭、圓圈、螢光標示或註解，然後送出。標記後的截圖會以圖片的形式附加到你的對話中，除非你剛才使用的是另一個 Enconvo 對話（例如聊天視窗），否則會附加在動態島中。

## 在螢幕上做標記

1. 將你想詢問的內容帶到最前面。
2. 按兩下滑鼠右鍵開啟螢幕塗鴉，或按下你在**設定 → 螢幕塗鴉**中設定的**快速鍵**。
3. 如果**先擷取區域**已開啟，請拖曳選取區域。否則直接在即時畫面上繪圖。
4. 在工具列中挑選一個工具，並標記你指的區域。
5. 點選**傳送**（紙飛機）或按 **⌘↩**。
6. 檢查附加的圖片並輸入請求，例如「標示出來的警告是什麼意思？」

在你設定之前，螢幕塗鴉沒有快速鍵。按兩下滑鼠右鍵則可立即使用。

### 加入語音標籤

按住左側 **Option** 鍵並說話，來描述你剛畫好的圖形。你說的話會以文字的形式顯示在它旁邊。若想讓螢幕塗鴉在你每畫完一個圖形後都聆聽，請開啟工具列中的**畫完圖形後自動語音輸入**，並在每個標籤說完時停頓。

## 工具

| 工具或動作 | 按鍵 |
| --- | --- |
| 箭頭 | **A** |
| 直線 | **L** |
| 鋼筆 | **P** |
| 螢光筆 | **H** |
| 矩形 | **R** |
| 圓形 | **O** |
| 計數器（編號標記） | **N** |
| 文字 | **T** |
| 選取 | **V** |
| 橡皮擦 | **E** |
| 顏色 | **C** |
| 線條粗細 | **⌘** + 捲動 |
| 白板 | **B** |
| 游標醒目標示 | **K** |
| 儲存為… | **⌘S** |
| 傳送 | **⌘↩** |

工具列還有**還原**、**重做**、**清除**、**複製到剪貼簿**和**關閉**。

## 設定

開啟**設定 → 螢幕塗鴉**。

| 設定 | 作用 |
| --- | --- |
| **先擷取區域** | 在繪圖前先選取區域。關閉後可直接在即時畫面上繪圖。預設為開啟。 |
| **快速鍵** | 開啟或關閉螢幕塗鴉。預設為空白。 |
| **按兩下滑鼠右鍵** | 以快速按兩下滑鼠右鍵開啟或關閉螢幕塗鴉。預設為開啟。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 覆蓋層沒有開啟 | 檢查**設定 → 螢幕塗鴉**中的**快速鍵**和**按兩下滑鼠右鍵**，並檢查 [macOS 權限](/zh-hant/configuration/permissions)。 |
| 你只需要整個 App 視窗 | 請改用 [Appshots](/zh-hant/features/appshots)。 |

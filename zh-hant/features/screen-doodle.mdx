螢幕塗鴉讓你在向代理程式提問前，先直接在螢幕畫面上做標記。畫上箭頭、圓圈、螢光標記或加上文字註解，然後傳送。標記後的截圖會以圖片形式附加到你的聊天中——預設會送到動態島，除非你剛才正在使用其他 Enconvo 聊天（例如聊天視窗）。

## 在螢幕上做標記

1. 將你想詢問的內容切換到螢幕最前方。
2. 快速按兩下右鍵開啟螢幕塗鴉，或按下你在**設定 → 螢幕塗鴉**中設定的**快速鍵**。
3. 若開啟了**先擷取區域**，拖曳框選要擷取的範圍；否則直接對即時螢幕畫面作畫。
4. 在工具列挑選工具，標記出你想指明的區域。
5. 點擊**傳送**（紙飛機圖示）或按下 **⌘↩**。
6. 確認附加的圖片並輸入你的請求，例如「反白的警告訊息是什麼意思？」

螢幕塗鴉在自行設定之前沒有預設快速鍵，但雙擊右鍵可以立即使用。

### 用說的加上標籤

按住左側 **Option** 鍵並開口描述你剛畫的形狀，你說的話就會以文字形式出現在該圖形旁。若想讓螢幕塗鴉在每次畫完一個圖形後自動聆聽，請在工具列開啟**畫完圖形後自動語音輸入**，並在說完每個標籤後稍作停頓以完成輸入。

## 工具

| --- | --- |
| 箭頭 | **A** |
| 直線 | **L** |
| 畫筆 | **P** |

| 文字 | **T** |

## 設定

開啟**設定 → 螢幕塗鴉**。

| 設定 | 作用 |
| --- | --- |
| **先擷取區域** | 作畫前先框選區域。關閉即可直接在即時螢幕畫面上繪製。預設開啟。 |
| **快速鍵** | 開啟或關閉螢幕塗鴉。預設為空。 |
| **按兩下滑鼠右鍵** | 快速按兩下滑鼠右鍵即可開啟或關閉螢幕塗鴉。預設開啟。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 塗鴉覆蓋層沒有開啟 | 檢查**設定 → 螢幕塗鴉**中的**快速鍵**與**按兩下滑鼠右鍵**，並檢查 [macOS 權限](/zh-hant/configuration/permissions)。 |
| 只需要整個應用程式視窗 | 改用 [Appshots](/zh-hant/features/appshots)。 |

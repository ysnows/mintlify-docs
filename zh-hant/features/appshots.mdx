---

Appshots 會將目前最前方的 App 視窗作為上下文加入你的聊天中。當你想針對螢幕上的內容提問，但又不想將它儲存到知識庫時，可以使用這個功能。

## 擷取 App 視窗

1. 將你想詢問的 App 帶到最前方。
2. 按下你的 Appshots 快捷鍵。在 **設定 → Appshots** 中的 **快捷鍵** 欄位設定之前，Appshots 預設沒有快捷鍵。
3. 如果 SmartBar、聊天視窗或 App 側邊欄其中之一正開啟在最前方，視窗就會送到那裡；否則會送到動態島，同時會播放一聲簡短的快門聲。
4. 確認已附加的視窗，接著提出具體問題，例如「解釋這個視窗中的錯誤」。

## 設定

開啟 **設定 → Appshots**。

| 設定 | 作用 |
| --- | --- |
| **啟用 Appshots** | 允許使用快捷鍵加入最前方的 App 視窗。預設為開啟。 |
| **錄製聲音** | 加入 Appshot 時播放簡短的快門聲。音效代表已擷取，但送出前仍請確認附件是否正確。 |
| **快捷鍵** | 用於加入視窗的快捷鍵。預設為無。你可以設為一組修飾鍵（例如同時按下兩個 **Option** 鍵），或一般的快捷鍵組合。 |

## 選擇合適的擷取工具

| 目標 | 使用 |
| --- | --- |
| 詢問目前 App 視窗的內容 | Appshots |
| 提問前先圈選標示特定區域 | [螢幕塗鴉](/zh-hant/features/screen-doodle) |
| 儲存目前 App 的內容以便日後搜尋 | [快速擷取](/zh-hant/features/quick-capture) |
| 從圖片中擷取文字 | [OCR](/zh-hant/ai/ocr) |

擷取的內容可能會傳送給處理該請求的模型。如需其他加入上下文的方式，請參閱[上下文感知](/zh-hant/features/context-awareness)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 沒有出現任何上下文 | 檢查 **設定 → 權限**，特別是螢幕錄製和輔助使用權限。 |
| 擷取到了錯誤的視窗 | 重新將目標 App 帶到最前方。Appshots 擷取的是其他 App 的視窗，而不是 Enconvo 自己的視窗（例如設定視窗）。 |
| 按快捷鍵沒有任何反應 | 確認 **啟用 Appshots** 已開啟，且已設定 **快捷鍵**。 |
| 按快捷鍵觸發了其他功能 | 其他 App 使用了相同的按鍵組合。請在 **設定 → Appshots** 中更改 **快捷鍵**。 |

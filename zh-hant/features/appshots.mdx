title: "Appshots"
description: "用一個快速鍵，將最前面的 App 視窗加入你的下一個問題。"
---

Appshots 會把最前面的 App 視窗作為上下文加入你的對話。當你想詢問螢幕上的某個內容，又不想把它儲存到知識庫時，就可以使用它。

## 擷取 App 視窗

1. 將你想詢問的 App 帶到最前面。
2. 按下你的 Appshots 快速鍵。在你於**設定 → Appshots** 的**快速鍵**下設定之前，Appshots 沒有快速鍵。
3. 如果 SmartBar、聊天視窗或 App 側邊欄其中之一開啟在最前面，視窗會送到它那裡。否則會送到動態島。同時會播放一聲簡短的快門聲。
4. 檢查附上的視窗，然後提出具體的問題，例如「說明這個視窗中的錯誤。」

## 設定

開啟**設定 → Appshots**。

| 設定 | 作用 |
| --- | --- |
| **啟用 Appshots** | 讓快速鍵加入最前面的 App 視窗。預設為開啟。 |
| **錄製聲音** | 在加入 Appshot 時播放簡短的快門聲。聲音只是確認已擷取；送出之前仍請檢查附件。 |
| **快速鍵** | 加入視窗的快速鍵。預設為無。它可以是一組修飾鍵，例如同時按下兩個 **Option** 鍵，或是一般的快速鍵。 |

## 選擇合適的擷取工具

| 目標 | 使用 |
| --- | --- |
| 詢問目前的 App 視窗 | Appshots |
| 在提問前將注意力引導到某個區域 | [螢幕塗鴉](/zh-hant/features/screen-doodle) |
| 儲存目前 App 的內容以便日後搜尋 | [快速擷取](/zh-hant/features/quick-capture) |
| 從圖片中擷取文字 | [OCR](/zh-hant/ai/ocr) |

擷取的內容可能會傳送給你用於該請求的模型。其他加入上下文的方式，請參閱[上下文感知](/zh-hant/features/context-awareness)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有出現任何上下文 | 檢查**設定 → 權限**，特別是螢幕錄製和輔助使用。 |
| 擷取到錯誤的視窗 | 再次將目標 App 帶到最前面。Appshots 擷取的是其他 App 的視窗，而不是 Enconvo 自己的視窗，例如設定。 |
| 快速鍵沒有反應 | 確認**啟用 Appshots** 已開啟，並且已設定**快速鍵**。 |
| 快速鍵觸發了別的功能 | 另一個 App 使用了相同的按鍵。請在**設定 → Appshots** 中更改**快速鍵**。 |

title: "上下文感知"

---

上下文是隨你的問題一起送出的內容：你選取的文字、在 Finder 中選取的檔案、瀏覽器中開啟的頁面，或一張截圖。SmartBar 可以在開啟時自動擷取其中一部分，你也可以輸入 `#` 加入更多。這樣 Agent 就能針對你正在看的內容回答，不需要你再解釋。

## 選擇 SmartBar 擷取什麼

1. 開啟**設定 → 上下文感知**。
2. 在**開啟 Smart Bar 時**下，將每個來源設為**自動加入**、**建議**或**關閉**。
3. 切換到另一個 App，選取一些內容，然後開啟 SmartBar 查看結果。

| 來源 | 加入的內容 | 預設值 |
| --- | --- | --- |
| **選取的文字** | 你原本使用的 App 中選取的文字 | **自動加入** |
| **Finder 選取項目** | 在 Finder 中選取的檔案和資料夾 | **建議** |
| **瀏覽器目前網頁** | 在 Safari、Chrome、Arc、Edge 或其他 Chromium 瀏覽器中開啟的頁面 | **建議** |

**自動加入**會在 SmartBar 一開啟就把該來源加入輸入內容。**建議**會把它列在指令上方，讓你點一下就能加入。**關閉**則不加入。

只有 SmartBar 會使用這些設定。你對選取內容執行的指令，一律會收到選取的文字。第一次加入 Finder 或瀏覽器上下文時，macOS 會詢問是否允許 Enconvo 控制該 App。

## 用 # 加入上下文

1. 在 SmartBar 中輸入 `#`。
2. 輸入一個字詞來縮小清單範圍，例如 `#screen`、`#finder`、`#clipboard` 或 `#browser`。
3. 挑選一個來源。它會加入你的訊息。
4. 輸入你的問題並送出。

| 來源 | 加入的內容 |
| --- | --- |
| **Selected Text** | 目前視窗中選取的文字 |
| **Clipboard Text** | 剪貼簿上的文字 |
| **Current Application Content** | 最前面 App 的文字 |
| **Current Application Screenshot** | 最前面 App 的截圖 |
| **Current Screen Screenshot** | 整個螢幕的截圖 |
| **Live Screen Screenshot** | 不含 Enconvo 視窗的螢幕截圖 |
| **User Select Area Screenshot** | 你選取的區域的截圖 |
| **Finder Selected Items** | 在 Finder 中選取的檔案和資料夾 |
| **Finder Current Directory URL** | 在 Finder 中開啟的資料夾 |
| **Browser Current Tab URL** | 瀏覽器目前分頁的網址 |

你開啟的視窗也會列出，所以你可以加入另一個 App 的視窗。若想使用 `#` 以外的字元，請在**設定 → SmartBar** 的**搜尋**下更改**上下文**。

## 可以問什麼

附上瀏覽器頁面後，可以請 Enconvo 摘要頁面、翻譯它，或擷取重要資訊。附上 Finder 檔案後，可以請它描述這些檔案、建議如何整理、協助批次重新命名，或分析它們的內容。

<Note>
你附上的上下文會傳送給回答的模型，或處理它的供應商。在處理敏感內容之前，請檢查附上的內容和你的供應商設定。
</Note>

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 選取的文字沒有被附上 | 檢查**選取的文字**是否設為**自動加入**，並檢查[權限](/zh-hant/configuration/permissions)。 |
| 缺少 Finder 或瀏覽器上下文 | macOS 詢問時，請允許 Enconvo 控制該 App。如果你拒絕了，請在[權限](/zh-hant/configuration/permissions)中允許。 |
| 輸入 `#` 沒有開啟清單 | 檢查**設定 → SmartBar** 中的**上下文**字元。 |

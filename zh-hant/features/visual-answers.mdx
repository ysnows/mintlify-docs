---
title: "視覺化回答"
description: "直接在對話中取得圖表、示意圖或互動式小工具，而不只是純文字。"
---

請代理程式「把答案畫出來」或視覺化呈現，它就會直接在對話中繪製出來：包含 SVG 示意圖、HTML 預覽，或是可點擊調整的互動式小工具。當一張圖、一張統計圖表或一個小型計算機比好幾段文字更好懂時，就很適合使用。代理程式需要開啟對應的視覺化工具才能做到這一點。

視覺化回答存在於對話流中。如果你需要一份可以長期保留、編輯、簡報或分享的成品（例如簡報、儀表板、設計或文件），請改為要求建立[作品](/zh-hant/features/artifacts)。

## 要求視覺化呈現

說明這份視覺化內容應該回答什麼問題：

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

如果是圖表或計算機，請一併提供數據與單位。看起來精美的視覺化內容仍可能有誤植的事實或算術錯誤，請務必自行核對。

## 回覆中的連結、地圖與圖表

部分回答不必特別要求就會自動以視覺化方式呈現：

- **連結** 會顯示為附帶網站圖示的卡片。
- **地點** 會標註地名顯示在真實地圖上。多個地點會共用同一張編號地圖，路線則會畫出路徑並標明時間與距離。
- 代理程式製作的 **圖表** 會經過色彩檢查，確保在色覺障礙檢視與淺色、深色外觀下，各組數列依然清晰可辨。數字、日期與狀態詞彙也會以你的語言顯示。

## 操作與儲存視覺化內容

1. 等待視覺化內容繪製完成，接著即可使用上面的任何控制項。部分小工具還能將後續提示詞送回對話中。
2. 將游標移到完成的視覺化內容上，點選右上角的 **⋯**。
3. 選擇 **拷貝到剪貼簿**，或選擇 **下載檔案** 並確認檔名。若該視覺化內容是使用 App 內建的卡片、表格與圖表繪製而成，選單會提供 **下載圖片**，將 PNG 圖片存進你的「下載項目」資料夾。

儲存成圖片只會擷取該視覺化內容當下的畫面，不會保留互動控制項。調整過小工具的數值後，同一個選單中的 **重設數值** 可以將數值恢復為初始狀態。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 得到程式碼而不是視覺化畫面 | 檢查代理程式啟用的工具，然後請它直接在對話中顯示結果 |
| 小工具看起來沒有畫完 | 等待它繪製完成，或請它改做一個較精簡的版本 |
| 你需要的是一張圖片檔，而不是對話小工具 | 請改用[圖片生成](/zh-hant/ai/image-generation) |
| 你想長期保留圖表並隨時回來查看 | 請要求建立[儀表板](/zh-hant/features/dashboards) |

---
title: "視覺化回答"
description: "直接在聊天中取得圖表、圖解或互動式小工具，而不只是純文字。"
---

請代理程式把它的回答呈現出來，它就會直接在對話中繪製視覺內容：SVG 圖解、HTML 預覽，或是你可以點按與調整的互動式小工具。當一張圖、一個圖表或一個小型計算機比幾段文字更能說明問題時，就可以使用它。代理程式需要啟用它的視覺化工具才能做到這一點。

視覺化回答存在於對話之中。如果你想要保留、編輯、簡報或分享某些內容，例如簡報、儀表板、設計或文件，請改為要求製作[作品](/zh-hant/features/artifacts)。

## 要求視覺化內容

請說明這個視覺內容應該回答什麼問題：

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

對於圖表或計算機，請附上資料及其單位。即使是精美的視覺內容，仍可能有錯誤的事實或計算，因此請加以檢查。

## 回覆中的連結、地圖與圖表

有些回答不需要你要求就會變成視覺化的形式：

- **連結**會顯示為附有網站圖示的卡片。
- **地點**會顯示在附有地點名稱的真實地圖上。多個地點會共用一張編號的地圖，而路線則會顯示其路徑，並附上時間與距離。
- 代理程式製作的**圖表**會檢查其色彩，讓各個數列在色盲情況下，以及淺色與深色外觀中都能清楚區分。數字、日期與狀態用語會以你的語言顯示。

## 使用與儲存視覺內容

1. 等待視覺內容繪製完成，然後使用它所具備的任何控制項。有些小工具會將後續提示詞傳回聊天中。
2. 將指標移到完成的視覺內容上，並點按其右上角的 **⋯**。
3. 選擇**拷貝到剪貼簿**，或**下載檔案**並確認檔案名稱。以 App 自有的卡片、表格與圖表繪製的視覺內容，則會改為提供**下載圖片**，它會將 PNG 儲存到你的下載項目資料夾。

儲存的圖片只會擷取視覺內容的某一個瞬間；它不會保留其互動控制項。在你變更小工具的數值之後，同一個選單中的**重設數值**會將它們還原。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 你得到的是程式碼而不是視覺內容 | 檢查代理程式已啟用的工具，然後請它在對話中呈現結果 |
| 小工具看起來不完整 | 等它完成，然後要求較簡單的版本 |
| 你需要的是圖片檔案，而不是聊天小工具 | 使用[圖片生成](/zh-hant/ai/image-generation) |
| 你想保留圖表並日後再回來查看 | 要求製作[儀表板](/zh-hant/features/dashboards) |

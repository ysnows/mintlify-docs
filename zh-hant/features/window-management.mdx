Enconvo 提供多種入口來處理相同的日常工作。請依任務需要的空間與上下文多寡來選擇，並設定你最常用的快捷鍵。

## 選擇視窗

| 視窗 | 用途 | 開啟方式 | 指南 |
| --- | --- | --- | --- |
| SmartBar | 提出快速問題或執行指令 | **⌥Space** | [SmartBar](/zh-hant/features/smartbar) |
| 聊天視窗 | 進行有歷史記錄與檔案的持續對話 | **⌃⌘X** | [聊天視窗](/zh-hant/ai/chat) |
| App 側邊欄 | 在另一個 App 旁工作 | **⌃⌘E**，或 App 視窗旁的把手 | [App 側邊欄](/zh-hant/features/app-sidebar) |
| PopBar | 處理選取的文字 | 選取文字 | [PopBar](/zh-hant/features/popbar) |
| 動態島 | 在螢幕頂端輸入快速要求並追蹤工作階段 | 將游標指向螢幕頂端中央 | [動態島](/zh-hant/features/dynamic-island) |
| 寵物 | 在桌面上放一個顯示代理程式活動的角色 | 點按寵物 | [桌面寵物](/zh-hant/features/pet) |
| 虛擬形象 | 以語音與代理程式角色對話 | 請參閱其指南 | [虛擬形象](/zh-hant/features/avatar) |

## 設定開啟它們的快捷鍵

開啟**設定 → 快捷鍵**，或該功能自己的設定頁面，檢查已指派的組合與啟動模式。SmartBar、聊天視窗與 App 側邊欄有預設的快捷鍵。動態島與 PopBar 在你設定之前沒有快捷鍵。

全域快捷鍵可能與 macOS、輸入法及其他 App 衝突。如果某個快捷鍵無法開啟它的視窗，請選擇沒有其他東西使用的組合。請參閱[鍵盤快速鍵](/zh-hant/configuration/keyboard-shortcuts)。

## 讓結果保持在視野內

使用你所在視窗的釘選或視窗控制項。若要在你回到另一個 App 時讓 SmartBar 保持在最上層，請執行**釘選 SmartBar**，或在 SmartBar 中按 **⌘P**。

完成後，請按 Escape 或使用視窗的關閉控制項。關閉視窗不會刪除對話。

## Dock 圖示

關閉聊天視窗或設定後，Enconvo 仍會停留在 Dock 中，讓你可以從那裡再次開啟。若要在這些視窗關閉時讓 Dock 圖示消失，請在**設定 → 聊天視窗**中開啟**關閉時隱藏 Dock 圖示**。

Dock 圖示上的徽章會計算需要你處理的聊天數量：你尚未開啟的結果或失敗、等待你核准或回答的聊天，以及朋友傳來的未讀訊息。

若要暫時隱藏 Enconvo 的視窗，請按 **⌘H**（**隱藏 Enconvo**）。它們會保持隱藏，直到你再次開啟其中一個。

## 多個顯示器

請檢查每個視窗設定中的顯示器選項，尤其是動態島的**顯示於**。變更顯示器排列後，請再次開啟視窗，並確認它位於你預期的螢幕上。App 側邊欄會跟隨它所附加的 App 視窗，而權限與 App 自身的視窗行為可能會影響它的附加方式。

## 結果出現的位置

有些指令有**視窗模式**或輸出設定，決定結果出現在哪裡。語音輸入也可以貼到最前方的 App 中，因此在聽寫之前，請先確認你的游標在哪裡。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 視窗無法開啟 | 檢查它的快捷鍵與使用中的顯示器，以及它是否在另一個 App 後面。 |
| 你原本熟悉的快捷鍵沒有開啟任何東西 | 預設值為 SmartBar 使用 **⌥Space**，聊天視窗使用 **⌃⌘X**。你自己設定的按鍵會維持你的設定。 |
| 你希望關閉視窗後 Dock 圖示消失 | 在**設定 → 聊天視窗**中開啟**關閉時隱藏 Dock 圖示**。 |
| 仍然無法開啟，或缺少權限 | 請參閱[疑難排解](/zh-hant/getting-started/troubleshooting)。 |

---
title: "語音轉寫"
description: "將你已有的音訊或影片檔案轉換為可搜尋的逐字稿。"
---

當你手邊已經有媒體檔案（例如訪談錄音或課程影片）時，請使用語音轉寫功能。即時錄製的會議存於**錄音**，即時字幕工作階段則存於**即時字幕**。這三者共用相同的錄音檢視介面，但各自列出不同來源的項目。

## 匯入檔案

1. 在**設定 → 語音轉寫模型**中選擇一個模型。
2. 開啟**設定 → 語音轉寫**，點擊**新增**，然後選擇**音訊**或**影片**。若列表為空，請點擊**匯入檔案**。你也可以直接將音訊檔、影片檔或資料夾拖放進該頁面。
3. 等待音軌擷取與轉寫完成。多個檔案會在背景依序逐一轉寫，轉換長音訊檔期間你仍可正常使用 Enconvo。
4. 開啟該項目並檢視逐字稿與處理狀態。
5. 使用結果前，請先修正重要說話者的姓名、專有名詞與數字。

你也可以直接執行 **Transcribe** 指令。它的設定包含**輸出格式**、**說話人分離**與 **Transcription Provider**。

## 使用逐字稿

點開已儲存的項目即可閱讀逐字稿、摘要與使用**詢問 AI**。摘要的操作方式與會議錄音相同：在側邊面板頂端選擇輸出語言與範本。請參閱[會議錄音](/zh-hant/features/meeting-recording)。對逐字稿細節有疑問時請直接提問查證，不要假設每個字詞都辨識無誤。是否提供時間戳記、結構化輸出與說話人分離，取決於你所使用的供應商與指令。

若要設定專有名詞與說話人姓名，請參閱[詞典與說話人](/zh-hant/configuration/speech-assets)。若想日後將逐字稿與其他文件一起搜尋，請參閱[知識庫](/zh-hant/ai/knowledge-base)。

## 當轉寫失敗時

Enconvo 會明確區分轉寫失敗與檔案中無人聲兩種情況。請閱讀錯誤訊息與診斷詳情。失敗可能來自音軌擷取異常、供應商的檔案大小或長度限制、帳號權限或服務本身問題。標題產生與搜尋索引失敗與轉寫本身是分開的。

如果逐字稿已經成功儲存，在重新匯入同一個檔案之前，請先確認是否只有產生標題或建立索引的步驟失敗。確認逐字稿完整無誤前，請保留原始媒體檔案。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 轉寫失敗 | 閱讀錯誤訊息與詳細資訊。Enconvo Cloud Fast 支援最長 300 分鐘的錄音，並會在上傳前重新編碼大型檔案。若檔案對該服務來說過大或過長，請先分割檔案或改選支援更長音訊的模型。若影片的音軌無法讀取，請先匯出為 WAV 或 MP3 檔案再進行轉寫。 |
| 只有標題產生或搜尋索引失敗 | 逐字稿已經儲存完成，無需重新匯入檔案。若索引失敗，請點擊**重試索引**。 |
| 說話人沒有分開標示 | 選擇支援說話人分離的供應商，或在 **Transcribe** 指令中開啟**說話人分離**。 |
| **這些檔案已在語音轉寫中** | 這些檔案先前已經匯入過。直接開啟既有的項目即可。 |

---
title: "語音轉寫"
description: "把你已有的音訊或影片檔案轉成可搜尋的逐字稿。"
---

語音轉寫適用於你已有的媒體，例如訪談或講座影片。你即時錄製的會議位於**錄音**，字幕工作階段則位於**即時字幕**。這三者共用相同的錄音檢視，但列出不同的來源。

## 匯入檔案

1. 在**設定 → 語音轉寫模型**中選擇一個模型。
2. 開啟**設定 → 語音轉寫**，點選**新增**，並選擇**音訊**或**影片**。在空白的清單中，點選**匯入檔案**。你也可以把音訊檔案、影片檔案或資料夾拖放到頁面上。
3. 等待擷取和轉錄完成。多個檔案會在背景中逐一轉錄，而在長音訊檔案轉換期間，Enconvo 仍可正常使用。
4. 開啟該項目，檢視逐字稿和它的處理狀態。
5. 在使用結果之前，先修正重要的說話者姓名、術語和數據。

你也可以執行**轉寫**指令。它的設定包括**輸出格式**、**說話人分離**和**語音轉寫供應商**。

## 使用逐字稿

開啟已儲存的項目，即可閱讀逐字稿、它的摘要和**詢問 AI**。摘要的運作方式與錄音相同：在側邊面板頂端選擇它的輸出語言和範本。請參閱[會議錄音](/zh-hant/features/meeting-recording)。請針對逐字稿提問，而不要假設每個細節都已被正確辨識。你使用的供應商和指令，會決定你是否能得到時間戳記、結構化輸出和說話人分離。

關於詞彙和說話者姓名，請參閱[詞典和說話者](/zh-hant/configuration/speech-assets)。若想之後連同你的其他文件一起找到逐字稿，請參閱[知識庫](/zh-hant/ai/knowledge-base)。

## 當轉錄失敗時

Enconvo 會區分轉錄失敗與沒有語音的檔案。請閱讀錯誤訊息和它的診斷詳細資料。失敗可能來自音訊擷取、供應商的檔案限制、帳號存取權限，或服務本身。標題產生和搜尋索引可能與轉錄各自獨立失敗。

如果逐字稿已經儲存，在再次匯入同一個檔案之前，先檢查是否只有標題或索引步驟失敗。在確認逐字稿之前，請保留原始媒體。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 轉錄失敗 | 閱讀錯誤訊息和詳細資料。Enconvo Cloud Fast 可處理長達 300 分鐘的錄音，並會在上傳前重新編碼大型檔案。如果檔案對該服務而言太大或太長，請將它分割，或選擇支援較長檔案的模型。如果無法讀取影片的音訊，請將它匯出為 WAV 或 MP3 檔案後再轉錄。 |
| 只有標題或搜尋索引失敗 | 逐字稿已儲存，所以請不要再次匯入檔案。索引失敗時請使用**重試索引**。 |
| 說話者沒有被區分 | 選擇支援說話人分離的供應商，或在**轉寫**指令中開啟**說話人分離**。 |
| **這些檔案已在語音轉寫中** | 這些檔案先前已匯入。請開啟現有的項目。 |

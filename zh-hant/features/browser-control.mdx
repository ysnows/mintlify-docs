---
title: "使用瀏覽器"
description: "讓代理程式在你真實的瀏覽器分頁中讀取並操作，沿用瀏覽器已有的登入狀態。"
---

「使用瀏覽器」讓代理程式能在已連接 Enconvo Companion 擴充功能的瀏覽器分頁中工作。它可以讀取頁面、點擊控制項、填寫欄位、檢查結果，以及管理分頁，全程沿用瀏覽器已有的登入狀態。當任務需要用到你已登入的網站時，就適合使用它。

## 設定

<Steps>
  <Step title="安裝擴充功能">
    在支援的 Chromium 瀏覽器中安裝 [Chrome 線上應用程式商店的 Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd)，或在 **設定 → 使用瀏覽器** 中點擊 **安裝瀏覽器配套程式**。若使用其他瀏覽器，請使用為該瀏覽器製作的擴充功能套件。
  </Step>
  <Step title="保持兩者執行">
    保持 Enconvo 與瀏覽器開啟。
  </Step>
  <Step title="檢查連線">
    點擊擴充功能的圖示。彈出視窗會顯示 **已連接** 以及瀏覽器的名稱。
  </Step>
  <Step title="檢查存取權限">
    確認你要使用的代理程式具備瀏覽器工具，並核准擴充功能詢問的任何網站。
  </Step>
  <Step title="嘗試唯讀任務">
    先從不會變更任何內容的任務開始，例如「讀取這個頁面並摘要重點。」
  </Step>
</Steps>

Safari 不使用 Chromium 擴充功能。在 Safari 中，[電腦操作](/zh-hant/features/computer-use)會改為在螢幕上點擊和輸入，因此並非每個瀏覽器都能做到相同的事。彈出視窗、已連接的瀏覽器、分頁指定與網站核准，請參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。

## 在指定的分頁中工作

在請求中指明瀏覽器與頁面：

> 在 Edge 中，讀取目前的說明文件分頁，並列出三個設定步驟。請保持頁面開啟。

代理程式會讀取頁面、挑選元素、執行動作，並檢查變化。頁面元素可能在換頁或即時更新後改變。如果代理程式找不到元素，請要求它重新查看頁面。

當代理程式在你看不到的分頁中工作時，[子母畫面](/zh-hant/features/picture-in-picture)視窗會在螢幕角落即時顯示。點擊它即可前往該分頁並接手操作。

## 任務結束時

代理程式開啟的分頁會在它的這一輪結束時關閉。以下分頁會保持開啟：

- 代理程式交給你作為結果的頁面
- 已交給你的分頁
- 你已釘選的分頁
- 你正在查看的分頁

你自己的分頁永遠不會被關閉。

## 它能做什麼

| 範圍 | 範例 |
| --- | --- |
| 導覽 | 開啟網址、上一頁或下一頁、重新載入、等待條件成立 |
| 讀取 | 頁面狀態、可見文字、屬性、螢幕截圖、選取的內容 |
| 互動 | 點擊、輸入、填寫、選取、按鍵、捲動、拖曳 |
| 瀏覽器整理 | 查看並管理分頁、視窗與已連接的工作階段 |
| 進階工具 | 頁面評估、Cookie、儲存空間、歷史記錄，以及瀏覽器專屬的檢查功能 |

### 擷取整個頁面

請代理程式擷取整個網頁，例如「將這個頁面的完整螢幕截圖儲存到我的桌面。」它會將 PNG 檔案儲存到你指定的位置，以頁面本身的解析度，且不含代理程式的游標。

### 登入與人機驗證

當任務來到網站的登入頁面時，會出現一張卡片，請你輸入一次使用者名稱和密碼。Enconvo 只會在該網站填入，代理程式不會看到密碼；請參閱[憑證](/zh-hant/configuration/credentials)。當頁面出現人機驗證時，代理程式可以把分頁交給你。請在該分頁中登入或完成驗證，然後點擊 **交還給代理程式** 將它交回。

能做到什麼取決於瀏覽器、頁面、擴充功能版本，以及你開啟的工具。`chrome://` 等瀏覽器頁面和其他受限制的內容可能無法存取。

<Warning>
「使用瀏覽器」會在你真實的帳號上執行動作。請說明任務只需要準備草稿，還是也要送出。
</Warning>

## 設定項目

| 設定 | 位置 | 作用 |
| --- | --- | --- |
| **預設瀏覽器** | **設定 → 使用瀏覽器**，然後在 **⋯** 選單中選擇 **設定** | 未指定瀏覽器時任務使用的瀏覽器。**自動（系統預設）** 會跟隨你 Mac 的預設瀏覽器。 |
| **瀏覽器擴充功能** | **設定 → 使用瀏覽器** | 列出已安裝擴充功能的瀏覽器，並標示各自為 **已連接** 或 **已中斷連線**。 |
| **子母畫面視窗** | **設定 → 使用瀏覽器** | 代理程式分頁的即時畫面何時顯示在螢幕角落：**永遠**（預設）、**僅在需要我時** 或 **關閉**。請參閱[子母畫面](/zh-hant/features/picture-in-picture)。 |

你也可以直接在任務中指定瀏覽器。

對開發人員而言，`browser-use/status` Local API 路由會回報連線狀態，**設定 → API** 則列出已安裝的路由及其結構。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 未連接 | 確認擴充功能已開啟且 Enconvo 正在執行，並查看彈出視窗。擴充功能會透過連接埠 11225 連接到這台 Mac 上的 Enconvo。 |
| 瀏覽器或分頁不對 | 指明瀏覽器與頁面，並要求重新查看頁面。 |
| 點擊或填寫失敗 | 查看頁面目前的樣子。對話框、換頁或內嵌的框架可能讓目標移位了。 |
| 螢幕截圖是空白的 | 將分頁移到最前面，並等待頁面載入完成。 |
| 網站要求你登入 | 像平常一樣登入該網站。瀏覽器已登入，並不代表每個網站的工作階段仍然有效。 |

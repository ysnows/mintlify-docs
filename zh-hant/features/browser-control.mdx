---
title: "使用瀏覽器"
description: "讓代理程式在你真實的瀏覽器分頁中讀取與操作，並沿用瀏覽器既有的登入狀態。"
---

「使用瀏覽器」讓代理程式能夠在已連接 Enconvo Companion 擴充功能的瀏覽器分頁中工作。它可以讀取頁面、點擊控制項、填寫欄位、檢查結果並管理分頁，全程使用瀏覽器既有的登入狀態。當任務需要存取你已經登入的網站時，這項功能就能派上用場。

## 設定

<Steps>
  <Step title="安裝擴充功能">
    在支援的 Chromium 瀏覽器中安裝[Chrome 線上應用程式商店的 Enconvo Companion](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd)，或在 **設定 → 使用瀏覽器** 中點擊 **安裝瀏覽器配套程式**。若是其他瀏覽器，請使用專為該瀏覽器製作的擴充功能套件。
  </Step>
  <Step title="保持兩者執行">
    讓 Enconvo 與瀏覽器維持開啟狀態。
  </Step>
  <Step title="檢查連線">
    點擊擴充功能的圖示。彈出視窗會顯示 **已連線** 以及瀏覽器名稱。
  </Step>
  <Step title="確認存取權限">
    確認你將使用的代理程式具備瀏覽器工具，並核准擴充功能詢問的任何網站。
  </Step>
  <Step title="嘗試唯讀任務">
    先從不會修改任何內容的任務開始，例如：「讀取這個頁面並整理重點。」
  </Step>
</Steps>

Safari 不支援 Chromium 擴充功能。在 Safari 中，[電腦操作](/zh-hant/features/computer-use)會改為直接點擊和輸入螢幕上的介面，因此並非每個瀏覽器都能做到相同的操作。關於彈出視窗、已連線的瀏覽器、分頁指定與網站核准，請參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。

## 在指定分頁中作業

在你的請求中說明瀏覽器與頁面：

> 在 Edge 中，讀取目前的文件分頁並列出三個設定步驟。保留該頁面開啟。

代理程式會讀取頁面、挑選元素、執行動作並檢查變更。頁面元素在導覽或即時更新後可能會改變。如果代理程式找不到原本的元素，請要求它重新檢視頁面。

當代理程式在你看不見的分頁中作業時，螢幕角落會出現一個[子母畫面](/zh-hant/features/picture-in-picture)視窗即時顯示該分頁的運作情況。點擊它即可前往該分頁並接手操作。

## 當任務結束時

代理程式開啟的分頁會在其回合結束時關閉。以下分頁會保留開啟：

- 代理程式作為結果交給你的頁面
- 它交給你處理的分頁
- 你釘選的分頁
- 你目前正在查看的分頁

你自己的分頁絕不會被關閉。

## 它能做什麼

| 類別 | 範例 |
| --- | --- |
| 導覽 | 開啟網址、上一頁或下一頁、重新整理、等待條件達成 |
| 讀取 | 頁面狀態、可見文字、屬性、螢幕截圖、選取的內容 |
| 互動 | 點擊、輸入、填寫、選取、按下按鍵、捲動、拖曳 |
| 瀏覽器整理 | 查看與管理分頁、視窗與已連線的工作階段 |
| 進階工具 | 頁面程式碼求值、Cookie、儲存空間、瀏覽記錄與瀏覽器專屬檢查 |

### 擷取整張網頁

你可以請代理程式擷取整張網頁，例如：「將這個完整頁面的螢幕截圖存到我的桌面。」它會以頁面本身的解析度將 PNG 檔案儲存在你指定的位置，且畫面中不會出現代理程式的游標。

### 登入與人機驗證

當任務進入網站的登入頁面時，一張卡片會請你輸入一次使用者名稱與密碼。Enconvo 僅會在該網站填入它們，而代理程式永遠看不到密碼；參閱[憑證](/zh-hant/configuration/credentials)。當頁面出現人機驗證時，代理程式可將該分頁交給你。在該分頁完成登入或通過驗證後，點擊 **交回代理程式** 即可交還給它。

實際可用的功能取決於瀏覽器、網頁本身、擴充功能版本以及你啟用的工具。諸如 `chrome://` 等瀏覽器內部頁面與其他受限內容可能無法存取。

<Warning>
使用瀏覽器會操作你真實的帳號。請明確說明任務應該只準備草稿，還是要一併送出。
</Warning>

## 設定

| 設定 | 位置 | 變更內容 |
| --- | --- | --- |
| **預設瀏覽器** | **設定 → 使用瀏覽器**，然後點選 **⋯** 選單中的 **設定** | 當你未指定瀏覽器時任務預設使用的瀏覽器。**自動（系統預設）** 會跟隨你 Mac 的預設瀏覽器。 |
| **瀏覽器擴充功能** | **設定 → 使用瀏覽器** | 列出已安裝擴充功能的瀏覽器，各自顯示為 **已連線** 或 **未連線**。 |
| **子母畫面視窗** | **設定 → 使用瀏覽器** | 決定何時在螢幕角落顯示代理程式分頁的即時畫面：**一律顯示**（預設）、**僅在需要我時** 或 **關閉**。參閱[子母畫面](/zh-hant/features/picture-in-picture)。 |

你也可以在任務中直接指明瀏覽器。

對開發者而言，`browser-use/status` Local API 路由會回報連線狀態，而 **設定 → API** 會列出已安裝的路由與其結構定義（schema）。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 未連線 | 確認擴充功能已開啟且 Enconvo 正在執行，並查看彈出視窗。擴充功能透過連接埠 11225 連線至這台 Mac 上的 Enconvo。 |
| 選錯瀏覽器或分頁 | 指明瀏覽器與頁面，並要求代理程式重新檢視頁面。 |
| 點擊或填寫失敗 | 重新確認目前的頁面。對話框、頁面導覽或嵌入式框架可能已移動目標元素。 |
| 螢幕截圖為空白 | 將該分頁帶到最前面，並等待頁面載入完成。 |
| 網站要求重新登入 | 像平常一樣登入該網站。瀏覽器整體處於登入狀態不代表每個網站的連線工作階段仍然有效。 |

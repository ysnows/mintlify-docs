---
title: "Live Photo 角色直播"
description: "將 Live Photo 角色與字幕放到 OBS 直播中，並讓她開口回覆你的 Twitch、Kick 或 YouTube 直播聊天室。"
---

[Live Photo 角色](/zh-hant/features/avatar)可以擔任直播主。Enconvo 會為 OBS 提供包含她動態畫面與字幕頁面的舞台，她也能閱讀你的直播聊天室並透過她的代理程式開口回覆觀眾。

## 開始之前

- 在**設定 → 虛擬形象**中建立一個 Live Photo 角色並將她綁定至代理程式。
- 安裝 OBS Studio。直播面板上的**取得 OBS Studio** 會連至下載頁面。

<Note>
在通話進行期間（無論你是否有在直播），以及她在直播模式下開口說出回答時，Atmee 都會依她的即時影像使用分鐘數計費。
</Note>

## 開啟直播面板

1. 開啟**設定 → 虛擬形象**並切換至 **Live Photo** 分頁。
2. 在她的卡片上點擊**開始直播**。

直播面板會顯示她的舞台、字幕、畫面方向（**直式 9:16** 或**橫式 16:9**）以及 OBS 的直播狀態。開啟她的虛擬形象後，舞台就會顯示她的畫面。

## 將她加入 OBS

1. 在 OBS 中開啟**工具 → WebSocket 伺服器設定**，勾選**啟用 WebSocket 伺服器**，然後點擊**套用**。
2. 點擊**顯示連線資訊**並複製伺服器密碼。
3. 在直播面板上點擊**連接 OBS** 並貼上密碼。Enconvo 會將密碼與你的其他憑證一起安全保存。
4. 點擊**加入 OBS**。Enconvo 會建立一個名為「Enconvo · *她的名稱*」的場景，內含已依你的直播比例調整好大小的舞台與字幕。
5. 在 OBS 中開始直播，或直接點擊面板上的**開始直播**。點擊**結束直播**即可停止。

如果你更改了畫面方向，請再次點擊**加入 OBS** 以重新調整她的場景大小。若想自行建立場景，請將面板上的透明舞台頁面與字幕頁面作為**瀏覽器**來源加入 OBS。

## 選擇她的背景

在面板的**背景**底下，選擇要傳送給 OBS 的後方背景畫面。OBS 會完全依照舞台預覽顯示的樣子呈現。

| 選項 | OBS 收到的畫面 |
| --- | --- |
| **透明** | 只有角色本身，帶有 Alpha 透明通道。後方會顯示你自己的 OBS 場景。 |
| **顏色** | 單一純色滿版畫面，例如**綠幕**或**自訂顏色**。 |
| **圖片** | 使用儲存在這台 Mac 上、你自己的圖片作為滿版畫面。 |
| **模糊照片** | 將她的原始照片進行模糊處理作為滿版畫面。 |
| **原始照片** | 她的原始照片。 |

儲存時已附帶邊框**背景**的角色會保留她原本的照片與邊框；此背景設定僅套用於去背角色。

## 讓她回覆你的直播聊天室

1. 在直播面板上輸入你的 **Twitch 頻道**或 **Kick 頻道**，或使用你的 YouTube Data API 金鑰連接 YouTube。
2. 設定她要回覆的對象：提及她的觀眾、使用 `!ask` 提問的觀眾，或是付費贊助的觀眾。你可以設定單一觀眾與整體冷卻時間及封鎖字詞，若想逐一審核每個問題，也可開啟先核准後回答的佇列。
3. 點擊**開啟直播彈幕**。

她會透過她的代理程式開口回答問題。

### 直播模式

開啟面板上的**直播模式**後，她不需要在通話中也能直接在 OBS 舞台上以對嘴動作說出每個回答。關閉時，回答則會在這台 Mac 上朗讀播放。

## 聲音

在通話期間且舞台正顯示她時，她的聲音只會從 OBS 輸出。若想同時在這台 Mac 上聽到她的聲音，請開啟**同時在這台 Mac 上播放**。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 舞台畫面是空的 | 開啟她的虛擬形象。在通話中時，她的舞台會即時顯示她的畫面。 |
| OBS 無法連線 | 確認 OBS 中已勾選**啟用 WebSocket 伺服器**，並重新貼上密碼。 |
| 她的場景尺寸不對 | 變更畫面方向後，請再次點擊**加入 OBS**。 |
| 變更背景沒有效果 | 她的角色在儲存時帶有邊框**背景**。背景設定僅適用於去背角色。 |
| 聽到重複的聲音或完全沒聲音 | 檢查**同時在這台 Mac 上播放**設定。 |

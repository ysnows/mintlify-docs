---
title: "直播 Live Photo 角色"
description: "讓 Live Photo 角色帶著字幕上 OBS 直播，並大聲回答你在 Twitch、Kick 或 YouTube 直播聊天室中的留言。"
---

[Live Photo 角色](/zh-hant/features/avatar)可以主持直播。Enconvo 會為 OBS 提供一個放有她動態畫面的舞台和一個字幕頁面，她還能讀取你直播的聊天室，並透過她的 Agent 大聲回答觀眾。

## 開始之前

- 在**設定 → 虛擬形象**中建立一個 Live Photo 角色，並將它綁定到一位 Agent。
- 安裝 OBS Studio。直播面板上的**取得 OBS Studio**會連到它。

<Note>
Atmee 會在通話進行期間，以及她在直播模式下說出回答時，按分鐘對她的即時影片計費，無論你是否正在直播。
</Note>

## 開啟直播面板

1. 開啟**設定 → 虛擬形象**和 **Live Photo** 分頁。
2. 點選她卡片上的**開始直播**。

直播面板會顯示她的舞台、她的字幕、畫面方向（**直式 9:16**或**橫式 16:9**），以及 OBS 的直播狀態。她的虛擬形象開啟後，舞台才會顯示她。

## 將她加入 OBS

1. 在 OBS 中，開啟**工具 → WebSocket 伺服器設定**，勾選**啟用 WebSocket 伺服器**，並點選**套用**。
2. 點選**顯示連線資訊**並拷貝伺服器密碼。
3. 在直播面板上，點選**連接 OBS** 並貼上密碼。Enconvo 會將它與你的其他憑證一起保存。
4. 點選**加入 OBS**。Enconvo 會建立一個名為「Enconvo · *她的名字*」的場景，內含她的舞台和字幕，並依你的直播調整尺寸。
5. 在 OBS 中開始直播，或使用面板上的**開始直播**。**結束直播**會停止直播。

如果你更改了畫面方向，請再次點選**加入 OBS** 以調整她的場景尺寸。若要自己建立場景，請將面板上的透明舞台頁面和字幕頁面，以**瀏覽器**來源加入 OBS。

## 選擇她的背景

在面板的**背景**下，選擇 OBS 要在她後方放什麼。OBS 顯示的內容與舞台預覽完全相同。

| 選項 | OBS 得到的內容 |
| --- | --- |
| **透明** | 只有她，帶有 alpha 通道。你的 OBS 場景會顯示在她後方。 |
| **顏色** | 單一顏色的完整畫面，例如**綠幕**或**自訂顏色**。 |
| **圖片** | 以你自己的圖片作為完整畫面，圖片保存在這台 Mac 上。 |
| **模糊照片** | 以她的照片模糊後作為完整畫面。 |
| **原始照片** | 她的原始照片。 |

若角色儲存時帶有框住的**背景**，就會保留她自己的照片和框；背景設定適用於去背的角色。

## 讓她回答你的直播聊天室

1. 在直播面板上，輸入你的 **Twitch 頻道**或 **Kick 頻道**，或使用你的 YouTube Data API 金鑰連接 YouTube。
2. 設定她回答的對象：提及她、使用 `!ask` 提問，或付費的觀眾。設定每位觀眾和整體的冷卻時間以及封鎖字詞，若想逐一核准每個問題，請開啟先核准再回答的佇列。
3. 點選**開啟直播彈幕**。

她會透過她的 Agent 大聲回答。

### 直播模式

在面板上開啟**直播模式**後，她會在她的 OBS 舞台上說出每個回答，嘴唇同步動作，不需要通話。關閉時，回答會在這台 Mac 上朗讀。

## 聲音

通話期間，只要有舞台顯示她，她的聲音就只會從 OBS 播放。開啟**同時在這台 Mac 上播放**，即可也在 Mac 上聽到她。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 舞台是空的 | 開啟她的虛擬形象。通話中，她的舞台會即時顯示她。 |
| OBS 無法連線 | 檢查 OBS 中是否已勾選**啟用 WebSocket 伺服器**，並重新貼上密碼。 |
| 她的場景尺寸不對 | 更改畫面方向後，請再次點選**加入 OBS**。 |
| 背景沒有變化 | 她的角色儲存時帶有框住的**背景**。背景設定適用於去背的角色。 |
| 聽到她的聲音重複，或完全聽不到 | 檢查**同時在這台 Mac 上播放**。 |

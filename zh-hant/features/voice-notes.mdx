語音筆記（Voice Note）可將口述的想法錄製並儲存到知識庫中，方便日後檢索。若想改為在其他應用程式中用說的輸入文字，請使用[聽寫](/zh-hant/features/dictation)。

## 開始之前

先建立或挑選一個用來存放筆記的[知識庫](/zh-hant/ai/knowledge-base)。語音筆記在設定之前預設沒有快捷鍵。

## 設定快捷鍵

1. 開啟**設定 → 語音筆記**。
2. 點擊**語音筆記快捷鍵**並按下你想使用的按鍵組合，然後選擇按住錄音或單擊開關。
3. 將**儲存至**設為你要存放筆記的知識庫。預設值為**預設知識庫**。

## 錄製筆記

1. 按下你的**語音筆記快捷鍵**並說出簡短筆記。在按住模式下，說話期間請按住該快捷鍵不放。
2. 放開快捷鍵，或使用錄音控制項結束錄音，筆記隨即儲存完成。
3. 開啟目標知識庫，檢視已儲存的項目與轉寫文字。

## 讓筆記更容易被搜尋到

錄音時可清楚說出主題與相關名稱，例如：「Project Atlas：請設計師提供更新後的引導頁圖示。」在正式採用內容前，請先檢查逐字稿中的重要人名、數字與日期是否正確。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 按下快捷鍵沒有反應 | 請先設定**語音筆記快捷鍵**，並確認**設定 → 快速擷取**中的**啟用快速擷取**已開啟。該開關同時控制快速擷取與語音筆記的快捷鍵。 |
| 沒有聲音輸入 | 檢查麥克風權限與目前選擇的輸入裝置。 |
| 筆記沒有出現在預期的位置 | 檢查**設定 → 語音筆記**中的**儲存至**設定。 |
| 轉寫失敗 | 閱讀錯誤訊息並檢查已設定的語音供應商，確認沒問題後再重新錄製筆記。 |

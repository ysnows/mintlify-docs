語音筆記會把你說出的想法錄進知識庫，讓你之後能找到它。若你想把文字輸入到其他 App 中，請改用[聽寫](/zh-hant/features/dictation)。

## 開始之前

為你的筆記建立或選擇一個[知識庫](/zh-hant/ai/knowledge-base)。在你設定之前，語音筆記沒有快速鍵。

## 設定快速鍵

1. 開啟**設定 → 語音筆記**。
2. 點選**語音筆記快捷鍵**並按下你想要的快速鍵。選擇要按住還是按一下。
3. 將**儲存至**設為你的筆記要存入的知識庫。它一開始是**預設知識庫**。

## 錄製筆記

1. 按下你的**語音筆記快捷鍵**並說出一段簡短的筆記。在按住模式下，說話時請按住快速鍵。
2. 放開快速鍵，或使用錄音控制項，來結束錄音。筆記就會儲存。
3. 開啟目的地知識庫，檢視已儲存的項目和它的轉錄內容。

## 讓筆記更容易找到

在錄音中說出主題和有用的名稱，例如：「Atlas 專案：請設計師提供更新後的新手引導圖示。」在依賴重要的名稱、數字和日期之前，請先在逐字稿中確認。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 快速鍵沒有反應 | 設定**語音筆記快捷鍵**，並確認**設定 → 快速擷取**中的**啟用快速擷取**已開啟。該開關會同時啟用快速擷取和語音筆記的快速鍵。 |
| 沒有聲音 | 檢查麥克風權限和所選的輸入裝置。 |
| 筆記不在你預期的地方 | 檢查**設定 → 語音筆記**中的**儲存至**。 |
| 轉錄失敗 | 在再次錄製同一則筆記之前，請閱讀錯誤訊息並檢查已設定的語音供應商。 |

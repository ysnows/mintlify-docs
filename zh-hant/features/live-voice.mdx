title: "Live Talk"
description: "打電話給你的 Agent，把事情聊清楚：它會聆聽、用自己的聲音回答，並在你說話的同時啟動任務。"
---

Live Talk 是與你的 Agent 進行的語音通話。你不必按住任何按鍵就能說話，Agent 會出聲回答，並能在通話進行的同時，使用已啟用的工具啟動任務。若想把語音轉成打字的文字，請改用[聽寫](/zh-hant/features/dictation)。

## 開始之前

Enconvo 需要 macOS 的麥克風存取權限。請選擇可正常運作的麥克風和喇叭。通話所使用的雲端服務會消耗 Enconvo Cloud 點數；你自己的金鑰和在 Mac 上執行的模型則不會。

## 開始和結束通話

1. 開啟與你想交談的 Agent 的對話。
2. 點選麥克風旁的 **Live Talk**，等待通話連線。
3. 開始說話。不需要按住任何按鍵，你也隨時可以打斷 Agent，讓它停下來聆聽。
4. 若是較大的工作，請說明你想要的結果並提供足夠的背景。這項工作會以任務的形式在它自己的對話中執行。展開工作詳情即可查看進度或結果。
5. 使用麥克風控制項可靜音，使用掛斷控制項可結束通話。掛斷後任務仍會繼續執行。

語音輪流的內容會存入一般的對話記錄，因此重新開啟該對話，就能回顧對話內容和工作詳情。安靜的通話會一直保持連線，直到你掛斷。對話中任務的連結可讓你回到通話。

## 不啟動任務也能提問

有些事 Agent 直接在通話中就能完成，不需要啟動任務：搜尋你的記憶和過往對話、儲存你要它記住的事、讀取你的行事曆和提醒事項、搜尋你的郵件，以及使用你的 MCP 伺服器中的唯讀工具。設定中的**快捷操作**列出了更多項目。

在長時間的任務進行期間，Agent 會告訴你任務目前為止的發現。

## 讓 Agent 安靜

告訴 Agent 安靜一下，或暫時別說話。它不會回答任何事，並會把消息留著，直到你叫它的名字、說它可以再說話了、對它打字，或點選**安靜中**狀態。

## 其他通話方式

當任務需要你時，Agent 也可以透過 iPhone App 或你的電話號碼打給你；接聽後便會啟動 Live Talk。請參閱[代理程式電話](/zh-hant/features/agent-phone)。

你也可以從[虛擬形象](/zh-hant/features/avatar)發起通話，這時它會作為說話者出現；或是從 [iPhone App](/zh-hant/integrations/iphone-app) 的語音聊天發起。在 iPhone 或 Android App 上通話期間，**遠端螢幕**工具會在通話上方的小型浮動視窗中開啟你電腦的螢幕；請參閱[使用你電腦的螢幕](/zh-hant/integrations/iphone-app)。開啟**即時螢幕**可讓 Agent 在通話期間看到你的螢幕。

## 設定

開啟**設定 → Live Talk**：

| 設定 | 作用 |
| --- | --- |
| **收音** | 通話如何聽到你。**Enconvo Cloud Fast**（預設）和 **ElevenLabs Scribe**（Scribe v3 Live）會在你說出每個字的同時就聽到。你也可以選擇在 Mac 上執行的模型，或任何語音模型。 |
| **思考** | Agent 對話時使用的模型。**與對話相同**（預設）會使用該對話自己供應商的快速模型，因此在使用你自己 API 金鑰的對話中通話，不會消耗 Enconvo Cloud 點數。在使用 Enconvo Cloud 的對話中，它是 Enconvo Fast，以 DeepSeek V4.1 Flash 回答、也能看到你展示給它的內容，並依該模型計費；付費方案或試用期間的通話仍免費。較大的工作會交給你的 Agent，並使用該對話所選的模型執行。 |
| **說話** | Agent 回答時使用的聲音，預設為 ElevenLabs v4 Turbo。Phonon 在你的 Mac 上執行，免費且可離線使用，僅支援英文。自下一次通話起生效。 |
| **語氣表現** | 每則回覆的語氣可依對話調整的程度：**關閉**、**輕微**或**豐富**。適用於 ElevenLabs、Fish Audio 和 Gemini 的聲音。 |
| **多久後開始新對話** | 在上一次通話後這麼多分鐘內再通話，會接續上次中斷的地方，虛擬形象通話也包含在內。**0** 表示一律接續。 |
| **快捷操作** | **管理**會開啟**設定 → 快捷操作**，也就是你提出要求時，Agent 不啟動任務就能立即完成的事項。 |

<Note>
Live Talk 的**思考**模型在此設定。你也可以在**設定 → AI 模型**的**任務模型**下選擇。
</Note>

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 通話無法連線 | 閱讀連線錯誤訊息，然後檢查你的**收音**、**思考**和**說話**選擇。若使用雲端服務，請在**設定 → 點數用量**中檢查你的點數。 |
| 麥克風無法使用 | 請先結束進行中的聽寫或錄音，並檢查 macOS 的麥克風存取權限。 |
| Agent 無法執行某個動作 | 檢查該 Agent 的工具和權限。語音不會為 Agent 增加它沒有的工具。 |
| 沒有使用新的聲音 | 聲音的變更自下一次通話起生效。 |
| 通話結束並顯示「The audio device changed」 | 你的麥克風或喇叭一直在重新啟動。請在**系統設定 → 聲音**中選擇另一個，然後開始新的通話。 |
| Agent 不再回答 | 它可能處於安靜狀態。請叫它的名字，或點選**安靜中**狀態。 |

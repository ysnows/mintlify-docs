Live Talk 是與你的代理程式進行的語音通話。你說話時不需要按住任何按鍵，代理程式會直接開口回答，也能在通話進行期間使用它啟用的工具展開任務。如果你只想把語音轉成打字輸入的文字，請使用[聽寫](/zh-hant/features/dictation)。

## 開始之前

Enconvo 需要在 macOS 中取得麥克風權限。請先選擇運作正常的麥克風與揚聲器。通話所使用的 Cloud 服務會消耗 Enconvo Cloud 點數；使用你自己的金鑰與 Mac 本機模型則不會。

## 開始與結束通話

1. 開啟與你想對話的代理程式之聊天視窗。
2. 點擊麥克風旁的 **Live Talk**，等待通話接通。
3. 直接開口說話。不需按住任何按鍵，而且隨時插話就能讓代理程式停下來聆聽你說話。
4. 遇到較大的任務時，說明你想要的結果並提供足夠的背景資訊。任務會在獨立聊天中執行，展開工作細節就能查看進度或結果。
5. 使用麥克風控制按鈕可切換靜音，點擊掛斷按鈕則可結束通話。掛斷後任務仍會繼續運行。

語音對話的每一輪內容都會儲存在一般聊天歷史記錄中，重新開啟該聊天即可回顧對話與工作細節。安靜無聲的通話會保持連線直到你掛斷。聊天中的任務連結也能帶你回到通話畫面。

## 不另開任務直接提問

有些事情代理程式會在通話中直接完成，而不需要額外啟動任務：搜尋你的記憶與過去的聊天、記下你請它記住的資訊、讀取你的行事曆與提醒事項、搜尋你的郵件，以及使用你 MCP 伺服器的唯讀工具。設定中的**快捷操作**列出了更多項目。

在執行耗時的任務期間，代理程式也會告訴你目前已經找到了什麼結果。

## 讓代理程式保持安靜

請代理程式安靜或先暫停說話一會兒。它就不會回答，並保留新消息直到你呼喚它的名字、說它可以再說話、打字給它，或點擊**安靜中**狀態為止。

## 其他通話方式

當任務需要你介入時，代理程式也能撥打電話給你——透過 iPhone 應用程式或你的手機號碼；接聽後就會進入 Live Talk。參閱 [Agent Phone](/zh-hant/features/agent-phone)。

你也可以從[虛擬形象](/zh-hant/features/avatar)發起通話（該角色會成為說話者），或從 [iPhone 應用程式](/zh-hant/integrations/iphone-app)中的語音聊天開始。在 iPhone 或 Android 應用程式上通話時，**遠端螢幕**工具會在通話畫面上方的小型浮動視窗中顯示你電腦的螢幕；參閱[使用你的電腦螢幕](/zh-hant/integrations/iphone-app)。開啟**即時螢幕**即可讓代理程式在通話中看見你的螢幕畫面。

## 設定

開啟**設定 → Live Talk**：

| 設定 | 作用 |
| --- | --- |
| **收音** | 通話如何聽取你的聲音。**Enconvo Cloud Fast**（預設）與 **ElevenLabs Scribe**（Scribe v3 Live）能即時逐字辨識你說的話。你也可以挑選在 Mac 上本機運行的模型，或任何語音模型。 |
| **思考** | 代理程式對話所使用的模型。**與聊天相同**（預設）會使用該聊天所屬服務供應商的快速模型，因此使用你自己 API 金鑰的聊天不會消耗 Enconvo Cloud 點數。在 Enconvo Cloud 聊天中則會使用 Enconvo Fast（由 DeepSeek V4.1 Flash 回答，也能看見你展示的畫面，並依該模型費率計費；付費方案或試用期間通話維持免費）。較大的工作會交給你的代理程式，並以該聊天選定的模型執行。 |
| **說話** | 代理程式回答時使用的聲音，預設為 ElevenLabs v4 Turbo。Phonon 可在你的 Mac 上免費離線運行，僅支援英文。變更會在下一次通話套用。 |
| **語氣表現** | 每則回覆的語氣隨對話情境變化的幅度：**關閉**、**輕微**或**豐富**。適用於 ElevenLabs、Fish Audio 與 Gemini 語音。 |
| **多久後開始新對話** | 在距離上次通話的這段分鐘數內重新通話（含虛擬形象通話），會從上次結束的地方繼續。設為 **0** 則永遠接續對話。 |
| **快捷操作** | 點擊**管理**會開啟**設定 → 快捷操作**，列出代理程式能在你要求時立即完成、不需另外啟動任務的項目。 |

<Note>
Live Talk 的**思考**模型在此設定。你也可以在**設定 → AI 模型**的**任務模型**底下選擇它。
</Note>

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 通話無法接通 | 閱讀連線錯誤訊息，然後檢查**收音**、**思考**與**說話**的選擇。若使用 Cloud 服務，請在**設定 → 點數用量**檢查點數餘額。 |
| 無法使用麥克風 | 請先結束進行中的聽寫或錄音，並檢查 macOS 的麥克風存取權限。 |
| 代理程式無法執行某項操作 | 檢查該代理程式的工具與權限。語音通話不會為代理程式增加原本沒有的工具。 |
| 沒有套用新選擇的聲音 | 語音變更會從下一次通話開始生效。 |
| 通話因「The audio device changed」而結束 | 你的麥克風或揚聲器持續重新啟動。請在**系統設定 → 聲音**中改選另一個裝置，再開始新的通話。 |
| 代理程式停止回答 | 它可能正處於安靜模式。呼喚它的名字，或點擊**安靜中**狀態。 |

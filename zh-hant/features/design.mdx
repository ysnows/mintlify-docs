設計畫布是代理程式展示某樣東西應該長什麼樣子的地方：App 畫面、線框圖、兩個版本的定價頁、海報或電子郵件。每一件作品都是畫布上的一個畫板，你可以在聊天旁平移、縮放、選取與編輯。當你在任何東西開發之前要決定外觀時，就適合使用它。

## 製作設計

1. 開啟新聊天並在訊息輸入框下方選擇**設計**，或在任何聊天中要求製作設計。
2. 描述畫面或作品、它是給誰看的，以及要比較什麼。可以附上截圖或草圖作為起點。
3. 送出。畫板會隨著代理程式的工作繪製到畫布上，一次繪製多個。

每種專案類型都有各自的尺寸與版面規則：手機畫面會以手機尺寸輸出，海報以海報尺寸，電子郵件則以電子郵件的寬度。

範例：

```text
Two options for a pricing page, side by side.
Three plans, monthly and yearly, with the middle plan highlighted.
```

## 變更設計

告訴代理程式要變更什麼，例如一個圖示、一種顏色或一行文字。它只會變更那個部分，也只有受到影響的畫板會重新繪製。

若要自行變更：

- 選取一個元素，並在側邊面板中開啟**屬性**，設定它的版面配置、填色、邊框、文字與效果。設計開啟時，此面板是關閉的；在較窄的視窗中，它會以覆蓋在畫布上的面板形式開啟。
- 使用**調整**來設定畫板提供的選項，並使用**大綱**查看它的圖層。
- 按住空白鍵，或選擇手形工具，即可平移。鉛筆與鋼筆可在畫布上繪圖。
- 選取一個元素並使用**匯出**，將它儲存為**匯出 PNG** 或**匯出 JPEG**。

若要與他人或你的團隊分享畫布，或回到較早的版本，請參閱[作品](/zh-hant/features/artifacts)。

## 使用設計系統

設計系統會為畫布或簡報提供你專屬的顏色、文字樣式、字型與元件。

- **匯入設計系統**：請代理程式將你的程式碼資料夾、權杖檔案或 npm 套件轉換為設計系統。它會保留確切的數值與真正的元件，然後執行檢查，說明該系統仍缺少什麼。
- **切換外觀**：在側邊面板中開啟**主題**分頁並選擇一個系統。畫布會切換為它的顏色與文字樣式。
- **保持最新**：當系統自設計使用它之後已有變更時，**主題**分頁會顯示它落後於來源。點按**同步**即可帶入變更。

簡報則使用其自己的**設計系統**選單中的設計系統。請參閱[投影片](/zh-hant/features/slides)。

## 匯入設計專案

點按**作品**資料庫中的**匯入**，並選擇設計的專案資料夾（已壓縮）。保存在該資料夾 `assets/` 或 `_blobs/` 中的上傳內容也會一併匯入。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 某些畫板上的字型看起來不同 | 字型只會顯示在有載入它的畫板上；請代理程式載入它 |
| **主題**分頁中沒有系統 | 請代理程式新增或匯入一個 |
| 系統顯示找不到它的來源 | 它所來自的資料夾或套件已被移動；請重新匯入 |
| 匯出失敗，並顯示「hasn't finished drawing the export」 | 更新 Enconvo，然後再次匯出 |

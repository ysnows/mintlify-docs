設計畫布是代理程式展示視覺外觀的空間：App 畫面、線框稿、兩個版本的定價頁面、海報或電子郵件。每個作品都是畫布上的一個畫板，你可以在聊天視窗旁自由平移、縮放、選取與編輯。當你想在實際開發前決定整體視覺風格時最適合使用。

## 建立設計

1. 開啟新對話並在輸入框下方選擇**設計**，或在任意對話中請代理程式製作設計。
2. 描述需要的畫面或設計內容、目標受眾，以及想比較的方案。你也可以附上螢幕截圖或草圖作為參考起點。
3. 傳送訊息。隨著代理程式工作，多個畫板會同步繪製在畫布上。

每種專案類型都會自動採用合適的尺寸與版面規則：手機介面會以手機尺寸呈現，海報會使用海報比例，電子郵件則會採用郵件寬度。

範例：

```text
並排製作兩個版本的定價頁面。
包含三種方案，支援月繳與年繳切換，並突顯中間的方案。
```

## 修改設計

你可以請代理程式修改任何細節，例如圖示、顏色或某一行文字。它只會修改指定部分，並僅重新繪製受影響的畫板。

若想親自調整：

- 選取元素並在側邊面板開啟**屬性**，即可設定版面配置、填色、邊框、文字樣式與效果。開啟設計時此面板預設收合；在較窄的視窗中，它會以浮動面板覆蓋在畫布上方開啟。
- 使用**調整**切換畫板提供的設計參數，並透過**大綱**檢視圖層結構。
- 按住空白鍵或選擇手形工具即可平移畫布。鉛筆與鋼筆工具可在畫布上繪圖。
- 選取元素後使用**匯出**，即可儲存為**匯出 PNG** 或**匯出 JPEG**。

若要將畫布分享給其他人或你的團隊，或回復到先前的版本，請參閱[作品](/zh-hant/features/artifacts)。

## 使用設計系統

設計系統能為畫布或簡報套用你確切的品牌色彩、字型樣式、字體與元件。

- **匯入設計系統**：請代理程式將你的程式碼資料夾、tokens 檔案或 npm 套件轉換為設計系統。它會保留精確的數值與實際元件，隨後執行檢查以指出系統中仍缺少哪些項目。
- **切換外觀**：在側邊面板開啟**主題**分頁並挑選設計系統。整個畫布會隨即切換為該系統的配色與文字樣式。
- **保持最新**：當來源設計系統自上次套用後有所更新時，**主題**分頁會提示目前落後於來源。點擊**同步**即可匯入最新變更。

簡報則是透過各自的**設計系統**選單套用設計系統。請參閱[簡報](/zh-hant/features/slides)。

## 匯入設計專案

在**作品**資料庫中點擊**匯入**，並選擇壓縮後的設計專案資料夾。儲存在資料夾 `assets/` 或 `_blobs/` 中的上傳檔案也會一併匯入。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 某些畫板上的字體看起來不一樣 | 字體只會在有載入該字體的畫板上顯示；請要求代理程式為其載入該字體 |
| **主題**分頁中沒有設計系統 | 請代理程式新增或匯入一個設計系統 |
| 系統提示找不到來源 | 原始資料夾或套件的位置已移動；請重新匯入一次 |
| 匯出時出現「hasn't finished drawing the export」錯誤 | 更新 Enconvo 後再次匯出 |

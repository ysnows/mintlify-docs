---

「剪貼簿歷史記錄」、「搜尋瀏覽器書籤」與「搜尋檔案」是三個隨打即搜的快速列表。使用「剪貼簿歷史記錄」可貼上先前複製過的內容，使用「書籤搜尋」可在任何瀏覽器中開啟已儲存的網頁，使用「檔案搜尋」則無需打開 Finder 就能開啟檔案。每項功能都可透過各自的快捷鍵開啟，或在 SmartBar 中搭配別名開啟。

## 開啟列表

1. 在 **設定 → 快速鍵** 中，或在 **設定 → 外掛程式** 下方該列表的專屬設定頁面中，為列表設定快捷鍵。
2. 按下該快捷鍵。預設開啟 **快捷鍵開啟獨立視窗** 時，列表會在獨立視窗中開啟，而 SmartBar 會維持原樣。
3. 輸入文字以篩選列表、使用方向鍵移動至項目，然後按下 Return。

若想改在 SmartBar 中開啟列表，請為它設定 **別名**。在 SmartBar 中輸入別名加上一個空白鍵，列表就會在該處開啟。SmartBar 搜尋結果會顯示每個列表的別名。

你也可以在聊天中以 `@` 提及列表，代理程式便會為你搜尋該列表。

## 從剪貼簿歷史記錄貼上

剪貼簿歷史記錄會保留你複製的文字、圖片與檔案。你可以釘選常用項目，並依連結、電子郵件、顏色、圖片或檔案進行篩選。

1. 開啟「剪貼簿歷史記錄」。
2. 輸入你複製過內容中的某個字詞。
3. 按下 Return 將項目貼到你正在使用的 App 中，或按下 **⌘C** 改為僅複製。當 **Return 鍵** 設為複製時，**⌘Return** 則執行貼上。

當你在 Enconvo 自己的視窗上方開啟該列表時，按下 Return 會直接貼到該視窗的訊息框中。

密碼管理工具與「鑰匙圈存取」預設會被排除在外，且各 App 標記為隱藏或暫時性的複製內容（例如密碼）絕不會被記錄。

## 開啟書籤

「搜尋瀏覽器書籤」會讀取 Safari、Chrome、Edge、Brave、Arc、Dia、Vivaldi、Opera、Chromium、Comet、Firefox 與 Zen 的書籤，包含存放在你所選資料夾中的 Firefox 與 Zen 設定檔。搜尋時也會比對資料夾名稱。

按下 Return 會在該書籤原本所屬的瀏覽器中開啟它，或按下 **⌘O** 在你的預設瀏覽器中開啟。**Return 鍵** 可對調這兩項行為。

## 尋找檔案

「搜尋檔案」預設會搜尋你的整台 Mac。使用其搜尋欄中的下拉式選單，可僅針對該次搜尋縮小範圍，例如 **我的資料夾**、**個人專屬（Home）** 或 **下載項目**。

按下 Return 會開啟檔案，或按下 **⌘Return** 在 Finder 中顯示它。**Return 鍵** 可對調這兩項行為。

## 設定

開啟 **設定 → 外掛程式**，然後選擇 **剪貼簿歷史記錄**、**瀏覽器書籤** 或 **檔案搜尋**。

| 設定 | 適用列表 | 變更內容 |
| --- | --- | --- |
| **別名** | 全部三項 | 在 SmartBar 中輸入該詞再加一個空白鍵，即可在該處開啟列表。 |
| **快捷鍵開啟獨立視窗** | 全部三項 | 開啟：快捷鍵會在獨立視窗中開啟列表。關閉：快捷鍵會在 SmartBar 中開啟列表。預設為開啟。 |
| **Return 鍵** | 全部三項 | Return 鍵的動作。剪貼簿歷史記錄：**貼到前景 App** 或 **複製到剪貼簿**。書籤：**在其所屬瀏覽器中打開** 或 **在預設瀏覽器中打開**。檔案：**開啟** 或 **在 Finder 中顯示**。 |
| **記錄剪貼簿歷史** | 剪貼簿歷史記錄 | 保留你複製內容的歷史記錄。關閉後仍會保留已儲存的項目。 |
| **歷史記錄保留時間** | 剪貼簿歷史記錄 | 項目保留的時間，從 **1 天** 到 **永久**。預設為 3 個月。已釘選的項目絕不會被移除。 |
| **忽略的 App** | 剪貼簿歷史記錄 | 依 Bundle ID 列出絕不記錄複製內容的 App。 |
| **顯示資料夾名稱** | 書籤 | 顯示每個書籤所屬的資料夾。 |
| **停用的瀏覽器** | 書籤 | 排除其書籤的瀏覽器。 |
| **搜尋範圍** | 檔案 | 「檔案搜尋」開啟時搜尋的位置：**這台 Mac**、**我的資料夾**、**個人專屬（Home）**、**桌面**、**文件**、**下載項目** 或 **應用程式**。 |
| **搜尋資料夾** | 檔案 | **我的資料夾** 所搜尋的資料夾。空白時預設搜尋「桌面」、「文件」與「下載項目」。 |
| **顯示隱藏檔案** | 檔案 | 包含名稱以點開頭的檔案。 |
| **排除的資料夾** | 檔案 | 內容絕不會出現在搜尋結果中的資料夾。 |

你在這些列表較早期的網頁版中所設定的快捷鍵或別名都會自動沿用。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 快捷鍵開啟的是 SmartBar 而非獨立視窗 | 為該列表開啟 **快捷鍵開啟獨立視窗**。 |
| 剪貼簿歷史記錄遺漏了複製內容 | 檢查 **記錄剪貼簿歷史** 與 **忽略的 App**。諸如密碼等隱藏複製內容絕不會被記錄。 |
| 遺漏了某個瀏覽器的書籤 | 檢查 **停用的瀏覽器**。 |
| 找不到某個檔案 | 檢查 **搜尋範圍**、**排除的資料夾** 與 **顯示隱藏檔案**。 |

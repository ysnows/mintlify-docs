---
title: "剪貼簿歷史、書籤與檔案搜尋"
description: "用快速鍵或 SmartBar 搜尋你複製過的內容、瀏覽器書籤，以及 Mac 上的檔案。"
---

剪貼簿歷史、搜尋瀏覽器書籤與搜尋檔案，是三個邊輸入邊搜尋的快速清單。用剪貼簿歷史貼上你先前複製的內容、用書籤搜尋在任何瀏覽器中開啟已儲存的頁面，並用檔案搜尋在不開啟 Finder 的情況下開啟檔案。每一個都可以用自己的快速鍵開啟，或在 SmartBar 中以別名開啟。

## 開啟清單

1. 在**設定 → 快捷鍵**，或在**設定 → 外掛程式**下該清單自己的設定頁面中，為清單設定快速鍵。
2. 按下快速鍵。在**快速鍵打開獨立視窗**開啟（預設）的情況下，清單會在它自己的視窗中開啟，SmartBar 則維持原樣。
3. 輸入文字篩選清單，用方向鍵移到某個項目，然後按下 Return。

若要改為在 SmartBar 內開啟清單，請設定它的**別名**。在 SmartBar 中輸入別名再加一個空格，清單就會在那裡開啟。SmartBar 搜尋會顯示每個清單的別名。

你也可以在聊天中用 `@` 提及某個清單，代理程式就會為你搜尋該清單。

## 從剪貼簿歷史貼上

剪貼簿歷史會保留你複製的文字、圖片與檔案。你可以釘選常用項目，並依連結、電子郵件、顏色、圖片或檔案篩選。

1. 開啟剪貼簿歷史。
2. 輸入你所複製內容中的一個字詞。
3. 按下 Return，將項目貼到你剛才使用的 App 中。按 **⌘C** 則改為複製它。當 **Return 鍵**設為複製時，**⌘Return** 會貼上。

當你在 Enconvo 自己的視窗上開啟清單時，Return 會貼到該視窗的訊息框中。

密碼管理程式與「鑰匙圈存取」預設會被排除，而 App 標記為隱藏或暫時的複製內容（例如密碼）則一律不會被記錄。

## 開啟書籤

搜尋瀏覽器書籤會讀取 Safari、Chrome、Edge、Brave、Arc、Dia、Vivaldi、Opera、Chromium、Comet、Firefox 與 Zen 的書籤，包括存放在你所選資料夾中的 Firefox 與 Zen 設定檔。搜尋也會比對資料夾名稱。

按下 Return 會在書籤所屬的瀏覽器中開啟，或按 **⌘O** 在你的預設瀏覽器中開啟。**Return 鍵**可將兩者對調。

## 尋找檔案

搜尋檔案預設會搜尋你整台 Mac。使用搜尋欄位中的下拉選單，可僅針對這次搜尋選擇單一位置，例如**我的資料夾**、**個人資料夾**或**下載**。

按下 Return 開啟檔案，或按 **⌘Return** 在 Finder 中顯示。**Return 鍵**可將兩者對調。

## 設定

開啟**設定 → 外掛程式**，然後選擇**剪貼簿歷史**、**瀏覽器書籤**或**檔案搜尋**。

| 設定 | 清單 | 變更的內容 |
| --- | --- | --- |
| **別名** | 三個清單皆適用 | 在 SmartBar 中輸入、後面加一個空格，即可在那裡開啟清單的字詞。 |
| **快速鍵打開獨立視窗** | 三個清單皆適用 | 開啟：快速鍵會在清單自己的視窗中開啟它。關閉：快速鍵會在 SmartBar 中開啟它。預設為開啟。 |
| **Return 鍵** | 三個清單皆適用 | Return 的作用。剪貼簿歷史：**貼到最前方的 App**或**拷貝到剪貼簿**。書籤：**在其所屬瀏覽器中開啟**或**在預設瀏覽器中開啟**。檔案：**開啟**或**在 Finder 中顯示**。 |
| **記錄剪貼簿歷史** | 剪貼簿歷史 | 保留你複製內容的歷史記錄。關閉後，已儲存的項目會保留。 |
| **歷史保留時長** | 剪貼簿歷史 | 項目保留多久，從 **1 天**到**永久**。預設為 3 個月。已釘選的項目永遠不會被移除。 |
| **忽略的 App** | 剪貼簿歷史 | 以 bundle ID 指定，其複製內容永遠不會被記錄的 App。 |
| **顯示資料夾名稱** | 書籤 | 顯示每個書籤所在的資料夾。 |
| **已關閉的瀏覽器** | 書籤 | 其書籤會被排除的瀏覽器。 |
| **搜尋範圍** | 檔案 | 檔案搜尋開啟時查找的位置：**這台 Mac**、**我的資料夾**、**個人資料夾**、**桌面**、**文件**、**下載**或**應用程式**。 |
| **搜尋資料夾** | 檔案 | **我的資料夾**所搜尋的資料夾。留空時為桌面、文件與下載。 |
| **顯示隱藏檔案** | 檔案 | 包含名稱以句點開頭的檔案。 |
| **排除的資料夾** | 檔案 | 其內容永遠不會出現的資料夾。 |

你在這些清單較舊的網頁版本上設定的快捷鍵或別名會沿用。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 快速鍵開啟的是 SmartBar，而不是視窗 | 為該清單開啟**快速鍵打開獨立視窗**。 |
| 剪貼簿歷史中缺少某次複製 | 檢查**記錄剪貼簿歷史**與**忽略的 App**。隱藏的複製內容（例如密碼）一律不會被記錄。 |
| 缺少某個瀏覽器的書籤 | 檢查**已關閉的瀏覽器**。 |
| 找不到某個檔案 | 檢查**搜尋範圍**、**排除的資料夾**與**顯示隱藏檔案**。 |

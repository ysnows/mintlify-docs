---
title: "會議錄音"
description: "錄製會議或講座，然後檢視它的逐字稿、摘要和後續事項。"
---

錄音會從你的麥克風、通話的音訊或兩者擷取會議或講座，並在大家說話時寫出逐字稿。之後你可以閱讀摘要、為說話者命名，並針對所說的內容提問。錄音模型與你的聽寫和檔案語音轉寫模型是分開設定的。

## 開始之前

- 在**設定 → 錄音模型**中選擇語音轉寫模型。
- macOS 會在你第一次錄製時要求麥克風和系統音訊的存取權限。請為你使用的來源兩者都允許。

<Note>
請確保參與者知道正在錄音，並遵守適用於你的會議的相關規定。
</Note>

## 錄製會議

<Steps>
  <Step title="開啟新的錄音">
    開啟**設定 → 錄音**並點選**新增錄音**，或執行**開始錄音（會議／講座）**。
  </Step>
  <Step title="選擇音訊來源">
    選擇**麥克風**，再選擇要錄製哪種**通話音訊**：**關閉**只錄你的麥克風，**所有應用程式**會錄下你的 Mac 播放的所有聲音，**單一應用程式**則只錄會議 App 的聲音。請先開啟會議 App 再選取它。檢查**語音轉寫**模型，若模型提供，可開啟**即時翻譯**。
  </Step>
  <Step title="開始錄音">
    點選**開始錄音**，並確認即時逐字稿中有字詞出現。
  </Step>
  <Step title="停止">
    結束時點選**停止**，然後開啟**錄音**下儲存的項目。
  </Step>
</Steps>

錄音時，你可以暫停和繼續、新增備註，並按 **⌘B** 為某個時刻加上書籤。錄音會邊錄邊儲存，所以即使 Enconvo 結束也不會遺失任何內容。

若要之後更改來源，請點選**新增錄音**旁的箭頭並選擇**選擇音訊來源…**。在同一個選單中，**會議提醒**會在 Zoom、Teams、FaceTime 或微信通話開始時，於動態島上詢問是否要錄音。

## 檢視結果

開啟一段錄音，即可看到**轉錄文字**，旁邊的側邊面板有**摘要**、**待辦事項**和**備註**分頁，以及**詢問 AI**。

- **轉錄文字**：檢查誰說了什麼，尤其是聲音重疊之處。點選說話者標籤可為該說話者命名；Enconvo 之後就會在新的錄音中辨識這個聲音。對於反覆出現的術語，請使用[詞典](/zh-hant/configuration/speech-assets)。
- **摘要**：**會議摘要**提供概覽、重點、決定、數據，以及一份時間軸，其中的時間可跳到錄音中的該時刻。有兩位以上說話者時，**通話時長**會顯示每位說話者在對話中所占的比例。
- **待辦事項**：在錄音中找到的任務。做完後可勾選。
- **備註**：你在錄音時加入的備註和書籤。開啟**顯示譯文**，可在每則備註下方加上以錄音輸出語言寫成的翻譯；你的備註仍保持你寫的樣子。
- **詢問 AI**：詢問關於這段錄音的問題。要求後續事項時，只有在會議中明確提到負責人和期限時，才要求列出它們。

拖曳側邊面板的左邊緣可將它加寬，以便閱讀較長的摘要，連點兩下邊緣則會恢復預設寬度。這個寬度會套用到每一段錄音。每個分頁中的文字都可以選取和拷貝。

## 選擇摘要語言和範本

在錄音側邊面板的頂端，選擇摘要、待辦事項和範本結果所使用的**輸出語言**，以及範本。逐字稿和你自己的備註會保持原本的語言。

除了**會議摘要**之外，內建範本還有**課程筆記**和**訪談重點**。你可以隨時在不同範本之間切換同一段錄音；每個範本的結果都會保留。

若要撰寫你自己的範本：

<Steps>
  <Step title="開始建立範本">
    開啟側邊面板頂端的範本選單，並選擇**新增範本…**。
  </Step>
  <Step title="說明它該擷取什麼">
    為它取一個**名稱**，並用白話描述它該從錄音中擷取什麼。選擇**版面配置**：**智慧版面**可使用卡片、表格、檢查清單、字卡、測驗和圖表，而**純文字**則寫出容易拷貝到其他地方的 Markdown。
  </Step>
  <Step title="試試看">
    點選**在這段錄音上試執行**，看看它的成果。錄音上的任何內容都不會改變。
  </Step>
  <Step title="儲存">
    若它找到的任務應該顯示在**待辦事項**分頁中，請開啟**將任務加入待辦事項**，然後點選**儲存範本**。
  </Step>
</Steps>

若要設定每段新錄音採用的輸出語言和範本，以及編輯或刪除你的範本，請點選**錄音**頁面上**新增錄音**旁的**摘要設定**。

## 檢視通話

你在 Mac 上錄製的每一通 Enconvo [Conference](/zh-hant/features/video-conference) 通話，在**錄音**中都有自己的項目，即使通話使用同一個會議室也一樣。開啟紀要的通話會顯示它的逐字稿、出席的人、它的影片，以及它的紀要文件。

通話頁面會以**會議**概覽開啟：

- **摘要**和**待辦事項**，附有每個項目由誰負責以及何時到期。點選項目上的**加入提醒事項**，可將它連同負責人和到期日放進 Apple 提醒事項。
- **本次通話中建立**：Agent 在通話期間建立的文件和白板。
- **螢幕上的內容**：Agent 在分享的螢幕上看到的內容。
- **就這次會議提問**：詢問關於這通通話的問題。

你的 Agent 也能在對話中回答關於你先前通話的問題，並說明每個答案出自哪一場會議。

你的 Agent 撥出或接聽的通話也可能出現在這裡：在**設定 → 代理程式電話**中開啟**錄製通話**，每一通 Agent 通話都會連同逐字稿儲存到**錄音**。請參閱[代理程式電話](/zh-hant/features/agent-phone)。

## 當某個步驟失敗時

語音轉寫、標題產生和搜尋索引是各自獨立的階段。較後面階段的錯誤，並不表示音訊或逐字稿已經遺失。長時間的錄音需要幾分鐘，即使你離開頁面，處理仍會繼續。使用 Enconvo Cloud Fast 時，長達 300 分鐘的錄音會從整個檔案轉錄。

如果即時字幕在網路中斷時停止，它們會重新連線，而儲存的逐字稿仍會涵蓋整段錄音。

請閱讀錄音的處理狀態，並對失敗的步驟使用**重新轉錄**或**重試索引**。回報問題時，**複製診斷資訊**會拷貝支援團隊要求的參考編號和記錄位置，但不包含錄音。傳送之前請先檢查其中是否有私人資訊。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有音訊 | 檢查所選的來源和 macOS 的擷取權限。 |
| 麥克風忙碌中 | 開始錄音之前，請先結束聽寫或 Live Talk。 |
| **沒有可用的語音轉寫模型** | 在**設定 → 錄音模型**中選擇一個模型。 |
| 某個處理步驟失敗 | 從錄音的處理狀態重試該步驟。 |
| 摘要的語言不對 | 在側邊面板頂端選擇**輸出語言**。對於新的錄音，請在**摘要設定**中設定。 |
| 沒有待辦事項 | 使用**會議摘要**，或使用已開啟**將任務加入待辦事項**的範本。 |

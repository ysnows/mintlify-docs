視訊會議讓你直接在 Enconvo 中與他人面對面通話並共享螢幕。你可以呼叫好友、呼叫整個團隊，或傳送連結讓任何人在瀏覽器中開啟加入。字幕能即時翻譯成你的語言，「紀要」功能會錄製通話並撰寫一份可與所有與會者分享的紀要文件。

這部影片先介紹視訊會議，接著說明在其他 App 中錄製會議、轉寫檔案、即時字幕、說話者與語音筆記。

<Note>
視訊會議需要付費方案。透過邀請連結加入的訪客無需擁有 Enconvo 帳號，也不用安裝任何軟體。
</Note>

## 開始一場會議

在聊天視窗側邊欄、動態島或選單列選單中開啟**視訊會議**。在手機上，可從 iPhone 或 Android App 發起或加入會議（請參閱[手機上的通話與好友](/zh-hant/integrations/phone-calls-and-friends)）。在 Mac 上這會開啟視訊會議首頁：

- 頂部的輸入框可輸入要加入的會議連結，或輸入好友或團隊成員的名稱進行呼叫。輸入後按 Return，或立即開始一場新會議。
- **即將開始**列出你預約的會議。
- **提前**（近期通話）列出過去一個月的通話及其錄製內容，點擊**重新撥打**可再次呼叫同一批人。
- **呼叫你的團隊**可一次呼叫所有團隊成員。

你也可以開啟**設定 → 視訊會議**並點擊**開始**。

## 邀請他人

在通話中開啟**成員**，即可呼叫你的好友、團隊成員或你自己的其他裝置。**全部呼叫**可一次呼叫所有團隊成員。尚未登入 Enconvo 的團隊成員會顯示在**尚未使用 Enconvo** 下方，並附有**複製邀請連結**按鈕。

若要邀請其他任何人，請傳送位於 conference.enconvo.com 的會議連結。他們可以透過網頁瀏覽器以訪客身分加入、說話、在聊天室打字，以及從電腦共享螢幕。

僅透過通話認識你的人會看到你的名稱，但在成為好友或團隊成員之前，不會看到你的電子郵件地址。

## 呼叫好友

從首頁輸入框或**設定 → 好友**（請參閱[好友與好友聊天](/zh-hant/features/friends)）呼叫好友時，會議視窗會立即響鈴，對方頭像顯示在你模糊化的相機畫面之上並播放回鈴音。對方接聽後，通話畫面只會顯示對方的影像，且**聊天**就是你與對方的對話。點擊**新增成員**即可無縫將其轉為多人會議。

來電響鈴時會顯示**拒絕**與**採納**（接聽）。未接來電會留下一張帶有**訊息**與**回撥**按鈕的卡片。當你已經在通話中時，你的其他裝置仍會響鈴，來電者則會聽到提示得知你正在另一通電話中。通話期間，好友傳來的訊息會以小提示顯示在通話畫面中，而不會彈出系統通知。

## 透過連結加入

無論在 Mac 上或在瀏覽器中開啟會議連結，進入前都會先顯示準備頁面：

1. 檢查你的攝影機與麥克風，並選擇要使用的裝置。
2. 選擇是否開啟字幕、字幕語言與背景效果。
3. 選擇加入時是否靜音。你也可以看到目前已經有哪些人在場。
4. 點擊加入會議。

在五人以上的會議中，你的麥克風預設會關閉，並附上說明提示。在手機瀏覽器中，若訪客切換至其他 App，狀態會顯示為**暫時離開**，會議最多為其保留席位 5 分鐘。

## 預約會議

1. 在**設定 → 視訊會議**中點擊**預約會議**。
2. 選擇**開始時間**、**時長**與**頻率**：一次、每天、每個平日、每週或每 2 週，全程共用同一個連結。
3. 新增與會者或輸入電子郵件地址、填寫會議標題並儲存。

連結會保持不變，因此大家現在就可以先保存。好友與團隊成員會收到附有行事曆檔案的電子郵件；其他人則由你自行傳送連結邀請。之後若修改時間、長度、標題或與會者，每個人都會收到更新通知，你也可以取消該場會議。預約的會議會顯示在**即將開始**底下，會議開始時你會收到附有**暫不**與**加入**的通知。

## 通話中操作

浮動工具列上有獨立的**麥克風**、**相機**與**字幕**按鈕。側邊面板則包含**聊天**、**成員**與**字幕**三個分頁。

- **版面配置**：隨人數增加，圖庫檢視會自動維持整齊排列。可切換為發言者檢視、釘選某人，或點擊某人將其畫面放大。在只有一對一的通話中，可將你自己的小視窗拖曳到任一角落，或點擊它來互換畫面。
- **誰在說話**：說話者的視窗會顯示綠色外框與音量條。
- **聊天**：訊息會傳送給所有人，未讀數量會即時顯示，較晚加入的人也能往前閱讀訊息。可附加、貼上或拖放最大 1 GB 的圖片與檔案。點擊通話中的任何人即可單獨傳送私訊給對方。
- **舉手與表情回應**：舉手的成員會依舉手先後順序排列，表情回應則會浮動顯示在所有人的畫面上。
- **靜音時說話**：按住空白鍵即可暫時發言。若你在靜音狀態下說話，畫面會跳出提示提供**取消靜音**按鈕。
- **你的視訊**：提供**隱藏我的畫面**或**顯示我的畫面**、**鏡像我的畫面**，以及**停止接收影片**（在節省流量時停止載入他人的攝影機畫面，同時保持語音與螢幕共享正常進行）。通話期間可隨時切換麥克風、揚聲器與攝影機；在手機上還可以切換至後置鏡頭。
- **背景**：可在加入前或通話期間選擇模糊、場景、圖案或自訂圖片。若偵測不到你的臉部，遮罩會自動模糊整個畫面，避免意外露出背景。

每個按鈕都可以使用 Tab 鍵選取，選單可用方向鍵移動，按 Enter 或空白鍵即可將某人的畫面放大。

在網路較慢或不穩定時，系統會優先維持語音清晰再暫停視訊畫面，並為每位與會者調整符合其連線品質的畫質。當你自己的網路連線不佳時，畫面會出現提示。在八人以下的通話中，有人加入或離開時會播放輕柔的提示音。如果你獨自留在通話中一段時間，系統會先詢問**還在嗎？**，之後才會自動結束通話。

## 共享你的螢幕

1. 點擊工具列上的分享按鈕。選擇列會顯示每個螢幕與視窗的預覽圖。
2. 選擇一個目標。無論從 Mac App 還是從瀏覽器分享，聲音也會一併共享。

在 Mac 上，綠色外框會標示你正在共享的範圍，分享列上則有**畫**（塗鴉）、**靜音**、**停止聲音**與**停止分享**按鈕。一個小視窗會顯示目前說話的人，且不會出現在你共享的畫面中。Enconvo 自己的選擇器、警告視窗與來電卡片也不會讓其他人看到；若從全螢幕會議中開始共享螢幕，系統會自動退出全螢幕模式。

其他人可以將共享螢幕放大至全螢幕，在 iPhone 上還能雙指縮放。任何人都可以從 Mac、iPhone 或瀏覽器在共享畫面上塗鴉：筆畫會精準落在所有人畫面的相同位置上、標示繪製者的名稱，並在幾秒後淡出。

當你縮小會議視窗或正在共享螢幕時，一個小浮動視窗會顯示目前說話者，並附有靜音、相機、離開與點擊返回通話的按鈕。

## 字幕

在通話中，點擊**字幕**即可開啟或關閉字幕。工具列上方的長條會顯示每句話；開啟翻譯後，會以大字顯示譯文並以小字顯示原文，或僅顯示你所選語言的譯文。還在翻譯中的句子會顯示標記。

字幕與翻譯涵蓋語音引擎支援的所有語言，共六十種，並在語言選單中依名稱列出。

點擊即時字幕即可向上捲動回顧誰在何時說了什麼，譯文顯示在原文上方。可一鍵跳回最新一句，或複製單句或全部字幕。此功能在 Mac、iPhone 與 Android 上皆可使用。

## 紀要與錄製

「紀要」會錄製通話、辨識說話者，並將 AI 筆記寫入一份紀要文件中。通話中的每個人都會看到並聽到紀要已開啟。每個人都可以從工具列的**紀要**按鈕獨立開啟或關閉自己的紀要功能，並取得自己的紀要文件。

開啟紀要後，紀要面板會顯示目前的逐字稿。使用**詢問 AI** 來總結通話或針對內容提問，並加入你自己的筆記與書籤（**⌘B**），這些內容都會儲存到該通話在[錄音](/zh-hant/features/meeting-recording)中的項目裡。

紀要會列出每項待辦事項及其負責人與截止日期、代理程式在通話中建立的文件與白板，以及代理程式在共享螢幕上看到的內容。

組織者還可以點擊**錄製會議**，將整場通話儲存為自己電腦上的影片檔。通話中的所有人以及準備加入的人都會看到會議正在錄製的提示。

## 組織者控制項

發起會議的人即為該場會議的組織者，他們可以：

| 控制項 | 作用 |
| --- | --- |
| 靜音、**請求取消靜音**、**請求所有人取消靜音** | 將單一成員或所有人靜音。發出請求絕不會強制替對方開啟麥克風。 |
| **為所有人聚焦** | 為所有與會者將某人的畫面放大。任何人都可以隨時切換回圖庫檢視。 |
| **停止分享** | 中止某位成員的螢幕共享。 |
| 移除 | 將某人移出會議。 |
| **鎖定會議** | 新加入的人會在等候室等待，直到組織者核准進入或拒絕。 |
| **訪客需請求加入** | 要求訪客必須先請求核准才能進入會議。 |
| **設為組織者** | 賦予某位成員相同的組織者控制權限。 |
| **為所有人結束** | 為所有與會者結束這場會議。 |

**為所有人結束**與移除操作預設聚焦在**取消**按鈕上以防誤觸。當會議中沒有組織者在場時，在場時間最久的成員會暫代**代理組織者**，確保在鎖定會議門口等候的人仍能獲准進入。

## 會議中的代理程式

你可以從**成員**將代理程式帶入會議，或設定讓你的代理程式自動加入你指定的會議。你也可以派它進入 Google Meet 或 Zoom 會議。請參閱[通話中的代理程式](/zh-hant/features/agents-in-calls)。

## 通話結束時

結束總結頁面會顯示通話持續時間、與會對象、已儲存的內容，以及在會議尚未結束時顯示**重新加入**按鈕。

如果會議視窗發生異常停止運作，畫面會提示通話已中斷並提供**重新加入**與**關閉**按鈕。若你的網路斷線且在五分鐘內未恢復連線，畫面也會顯示**重新加入**。通話期間，Enconvo 會保持 Mac 螢幕恆亮。

## 設定

開啟**設定 → 視訊會議**：

| 設定 | 作用 |
| --- | --- |
| **加入時開啟麥克風**、**加入時開啟攝影機** | 加入會議時的預設狀態。你仍可在進入會議前的準備頁面調整。 |
| **加入時開啟字幕** | 加入會議後立即顯示字幕。僅你自己看得到。當有人需要字幕時，每位發言者的裝置會轉寫自己的語音。 |
| **翻譯字幕** | 將字幕翻譯成你選擇的語言。設為**關閉**則顯示原音文字。 |
| **在我的通話中記錄紀要** | 選擇**關閉**、**紀要**或**紀要與錄製**。在你每次發起、接聽或加入通話時自動啟動。 |
| **錄製** | 開啟紀要時錄製的內容類型：**音訊**或**音訊和影片**。 |
| **用說話者辨識聲音** | 透過聲紋辨識發言者名稱。只有當你主動選擇時才會新增新的聲音。請參閱[辭典與說話者](/zh-hant/configuration/speech-assets)。 |
| **紀要文件共享給** | **通話中的人**或**僅我**。你擁有該份文件，之後仍可更改權限。 |
| **Agent 自動入會** | 讓你的代理程式加入你選擇的會議。請參閱[通話中的代理程式](/zh-hant/features/agents-in-calls)。 |
| **在任何 App 中靜音或取消靜音** | 預設為 **⌃⌥M** 的快捷鍵，在會議期間無論哪個 App 在前景都能使用。選單列下方會顯示簡短提示。非通話期間，此組合鍵會保留給其他 App 使用。 |
| **通話勿擾** | 停止讓這台 Mac 響起通話鈴聲，可選**1 小時**、**直到明天**或**直到我關閉**。訊息仍會通知你，你也可以照常發起或加入通話。也可透過**設定 → 好友**中的月亮圖示切換。 |

## 其他 App 中的會議

對於 Zoom、Teams、FaceTime 或微信通話，請使用[會議錄音](/zh-hant/features/meeting-recording)：**設定 → 錄音 → 新增錄音**可錄製你的麥克風、通話音訊或兩者同時錄製，並提供即時逐字稿。**新增錄音**旁的箭頭包含**會議提醒**功能，當這類通話開始時會在動態島上詢問是否要開始錄音。

若要讓你的代理程式替你加入 Google Meet 或 Zoom 會議，請參閱[通話中的代理程式](/zh-hant/features/agents-in-calls)。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 未允許使用攝影機或麥克風 | 點擊提示訊息上的**開啟系統設定**並允許 Enconvo，然後再試一次。 |
| 加入時麥克風被關閉 | 五人以上的會議在加入時會預設為靜音。點擊**麥克風**，或按住空白鍵說話。 |
| 有人無法進入會議 | 會議已鎖定或要求訪客必須先請求。請從等候室核准他們加入。 |
| 其他人的視訊畫面停止 | 你的網路連線較慢，或已開啟**停止接收影片**。語音與共享螢幕仍會正常運作。 |
| 通話不會在這台 Mac 上響鈴 | 請檢查**設定 → 視訊會議**中的**通話勿擾**設定。 |
| 通話視窗停止運作 | 點擊視窗訊息上的**重新加入**。 |

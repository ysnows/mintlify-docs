視訊會議讓你直接在 Enconvo 中與人面對面交談並分享螢幕。你可以呼叫好友、呼叫整個團隊，或傳送一個任何人都能在瀏覽器中開啟的連結。字幕可以翻譯成你的語言，紀要則會錄下通話並寫出一份紀要文件，你可以與通話中的每個人分享。

這支影片先介紹視訊會議，接著介紹在其他 App 中錄製會議、轉錄檔案、即時字幕、說話者和語音筆記。

<Note>
視訊會議需要付費方案。透過邀請連結加入的訪客不需要 Enconvo 帳號，也不必安裝任何東西。
</Note>

## 開始會議

從聊天視窗側邊欄、動態島或選單列選單開啟**視訊會議**。在手機上，可從 iPhone 或 Android App 開始或加入會議（請參閱[手機上的通話和好友](/zh-hant/integrations/phone-calls-and-friends)）。在 Mac 上，這會開啟視訊會議首頁：

- 最上方的輸入框可輸入要加入的會議連結，或要呼叫的好友或團隊成員的名字。輸入後按 Return，或立即開始會議。
- **即將開始**列出你已排程的會議。
- **較早**列出過去一個月的通話及其錄影，**重新撥打**會呼叫相同的人。
- **呼叫你的團隊**會一次呼叫所有團隊成員。

你也可以開啟**設定 → 視訊會議**並點選**開始**。

## 邀請成員

在通話中，開啟**成員**，呼叫你的好友、團隊成員或你自己的其他裝置。**全部呼叫**會一次呼叫所有團隊成員。尚未登入 Enconvo 的團隊成員會顯示在**尚未使用 Enconvo**下，並附有**複製邀請連結**。

若要邀請其他任何人，請傳送 conference.enconvo.com 上的會議連結。他們可以透過網頁瀏覽器以訪客身分加入、交談、在聊天室中打字，並從電腦分享螢幕。

你只在通話中認識的人會看到你的名字，但在你們成為好友或團隊成員之前，看不到你的電子郵件地址。

## 呼叫好友

從首頁輸入框或從**設定 → 好友**（請參閱[好友和好友聊天](/zh-hant/features/friends)）呼叫好友，會立即在會議視窗中響鈴，對方的臉會顯示在你模糊的相機畫面上方，並有回鈴音。對方接聽後，通話只會顯示對方的畫面，而它的**聊天**就是你與對方的對話。點選**新增成員**即可無縫地把它變成會議。

來電響鈴時有**拒絕**和**接聽**。你錯過的來電會留下一張卡片，有**訊息**和**回撥**。當你已在通話中時，你的其他裝置會繼續響鈴，而來電者會聽到你正在另一通電話中。在你通話期間，好友的訊息會以小提示的形式顯示在通話中，而不是通知。

## 從連結加入

在 Mac 上或瀏覽器中開啟會議連結，會在你進入之前先顯示一個頁面：

1. 檢查你的相機和麥克風，並選擇要使用的裝置。
2. 選擇字幕和字幕語言，以及背景。
3. 選擇是否以靜音加入。你也能看到已經有誰在裡面。
4. 點選加入。

在有五人以上的會議中，你的麥克風一開始是關閉的，並有說明原因的提示。在手機瀏覽器上，切換到其他 App 的訪客會顯示為**暫時離開**，通話最多會為他們保留位置 5 分鐘。

## 預約會議

1. 在**設定 → 視訊會議**中，點選**預約會議**。
2. 選擇**開始時間**、**時長**和**頻率**：一次、每天、每個工作日、每週或每 2 週，全都使用同一個連結。
3. 新增成員或電子郵件，為它命名，然後儲存。

連結保持不變，所以大家現在就可以先存下來。好友和團隊成員會收到附有行事曆檔案的電子郵件；其他人則需要你自己傳送連結。之後若更改時間、時長、標題或賓客，每個人都會收到更新，你也可以取消會議。已排程的會議會顯示在**即將開始**下，開始時你會看到**暫不**和**加入**。

## 通話中

浮動工具列有獨立的**麥克風**、**相機**和**字幕**按鈕。一個側邊面板包含**聊天**、**成員**和**字幕**分頁。

- **版面配置**：隨著人員加入，圖庫會保持其形狀。可切換到發言者檢視、釘選某人，或點選某人讓他放大。在只有另一個人的通話中，可將你自己的小畫面拖曳到任一角落，或點一下來交換。
- **誰在說話**：他們的畫面會出現綠色外框和音量條。
- **聊天**：訊息會傳給所有人，計數會顯示你還沒讀的內容，稍後加入的人可以回頭閱讀。可附加、貼上或拖放最大 1 GB 的圖片和檔案。點選通話中的任何人，可只寫給他們。
- **舉手和表情**：舉手的人會依舉手順序列出，表情則會飄過每個人的畫面。
- **靜音時說話**：按住 Space 說話。如果你在靜音時說話，提醒會提供**取消靜音**。
- **你的影像**：**隱藏我的畫面**或**顯示我的畫面**、**鏡像我的畫面**，以及**停止接收影片**，它會停止接收其他人的相機影像以節省數據，而聲音和分享的螢幕仍會繼續。你可以在通話期間選擇麥克風、喇叭和相機；在手機上可切換到後置相機。
- **背景**：模糊、場景、圖案，或你自己的圖片，可在加入前或通話期間選擇。如果遮罩失去你的臉，會把你的整個畫面模糊，這樣就不會意外露出任何東西。

每個按鈕都能用 Tab 到達，選單可用方向鍵移動，按 Enter 或 Space 可讓某人放大。

在速度慢或不穩定的連線上，畫面會先暫停，聲音才會中斷，而且每個人會得到符合其連線的畫面大小。當你自己的連線不佳時會有提示。在最多八人的通話中，有人加入或離開時會播放輕柔的聲音。如果你在通話中獨自待了一段時間，通話自動結束之前會先問你**還在嗎？**

## 分享你的螢幕

1. 點選工具列中的分享。托盤會顯示每個螢幕和視窗的畫面。
2. 選擇一個。聲音也會一併分享，Mac App 和瀏覽器都可以。

在 Mac 上，綠色外框會標示你分享的內容，分享列則有**畫**、**靜音**、**停止聲音**和**停止分享**。一個小視窗會顯示正在說話的人，而不會出現在你分享的內容中。Enconvo 自己的選擇器、提示和來電卡片不會出現在別人看到的畫面中，從全螢幕通話分享時會退出全螢幕。

其他人可以全螢幕開啟分享的螢幕，在 iPhone 上可用兩指縮放。任何人都可以從 Mac、iPhone 或瀏覽器在分享的螢幕上畫圖：筆畫會對每個人出現在同一個位置，帶有畫的人的名字，並在幾秒後淡出。

當你將會議最小化或分享你的螢幕時，一個小型浮動視窗會顯示誰在說話，並有靜音、相機、離開，以及點一下回到通話的功能。

## 字幕

通話中，**字幕**可開啟或關閉。工具列上方的橫條會顯示每一行；開啟翻譯後，會以大字顯示翻譯、小字顯示原文，或只顯示翻譯，語言由你挑選。尚未產生的翻譯會顯示標記。

字幕和翻譯涵蓋語音引擎支援的每一種語言，共六十種，在語言選單中依名稱列出。

點選即時字幕，可往回捲動查看誰在何時說了什麼，翻譯顯示在原文上方。你可以跳回最新一行，或拷貝單行或全部。這在 Mac、iPhone 和 Android 上都可使用。

## 紀要和錄製

紀要會錄下通話、辨識誰在說話，並把 AI 紀要寫入一份紀要文件。通話中的每個人都會看到並聽到紀要已開啟。每個人從工具列的**紀要**各自開啟或關閉自己的紀要，並得到自己的紀要文件。

開啟紀要後，紀要面板會顯示到目前為止的逐字稿。使用**詢問 AI**可摘要通話或回答關於通話的問題，並可加入你自己的備註和書籤（**⌘B**），它們會進入該通話在[錄音](/zh-hant/features/meeting-recording)中的項目。

紀要會列出每個待辦事項及其負責人和到期日、Agent 在通話中建立的文件和白板，以及 Agent 在分享的螢幕上看到的內容。

組織者也可以點選**錄製會議**，將通話以影片檔案儲存在自己的電腦上。通話中的每個人，以及即將加入的人，都會看到它正在錄製。

## 組織者控制項

開始會議的人就是它的組織者。他們可以：

| 控制項 | 作用 |
| --- | --- |
| 靜音、**請求取消靜音**、**請求所有人取消靜音** | 將某人或所有人靜音。請求絕不會替任何人開啟麥克風。 |
| **為所有人聚焦** | 讓一個人對所有人放大。任何人都可以退回圖庫。 |
| **停止分享** | 停止某人分享的螢幕。 |
| 移除 | 將某人移出會議。 |
| **鎖定會議** | 新加入的人會在等候室等待，直到組織者讓他們進入或拒絕。 |
| **訪客需請求加入** | 讓訪客必須先請求才能進入。 |
| **設為組織者** | 賦予某人相同的控制權限。 |
| **為所有人結束** | 為所有人結束會議。 |

**為所有人結束**和移除一開始都停在**取消**上。當通話中沒有組織者時，待得最久的人會擔任**代理組織者**，讓在鎖定的門外等待的人仍能進入。

## 會議中的 Agent

你可以從**成員**讓 Agent 加入會議，或讓你的 Agent 加入你選定的會議。你也可以派它進入 Google Meet 或 Zoom 會議。請參閱[通話中的 Agent](/zh-hant/features/agents-in-calls)。

## 通話結束時

結束頁面會顯示通話持續了多久、你與誰交談、儲存了什麼，並在會議仍在進行時顯示**重新加入**。

如果會議視窗停止運作，它會告訴你通話已停止，並提供**重新加入**和**關閉**。如果你的連線中斷且五分鐘內沒有恢復，你會看到**重新加入**。通話期間，Enconvo 會讓 Mac 的顯示器保持開啟。

## 設定

開啟**設定 → 視訊會議**：

| 設定 | 作用 |
| --- | --- |
| **加入時開啟麥克風**、**加入時開啟攝影機** | 你加入會議的方式。你仍可在加入前於頁面上更改。 |
| **加入時開啟字幕** | 加入後立即顯示字幕。只有你看得到。每位說話者的裝置會在有人需要時寫出他們的話。 |
| **翻譯字幕** | 將字幕翻譯成你挑選的語言。**關閉**則依說話內容顯示。 |
| **在我的通話中記錄紀要** | **關閉**、**紀要**或**紀要和錄製**。每次你開始、接聽或加入的通話都會依此開始。 |
| **錄製** | 開啟紀要時，錄製以什麼方式開始：**音訊**，或**音訊和影片**。 |
| **用說話者辨識聲音** | 依聲紋為說話的人命名。新的聲音只有在你選擇時才會加入。請參閱[詞典和說話者](/zh-hant/configuration/speech-assets)。 |
| **紀要文件共享給** | **通話中的人**或**僅我**。文件由你擁有，之後可以更改。 |
| **Agent 自動入會** | 讓你的 Agent 加入你選定的會議。請參閱[通話中的 Agent](/zh-hant/features/agents-in-calls)。 |
| **在任何 App 中靜音或取消靜音** | 一個快速鍵，預設為 **⌃⌥M**，只要你在會議中就有效，無論哪個 App 在最前面。選單列下方會顯示簡短提示。不在通話中時，這些按鍵會留給其他 App 使用。 |
| **通話勿擾** | 讓通話在 **1 小時**、**直到明天**或**直到我關閉**之前不會讓這台 Mac 響鈴。訊息仍會通知你，你也仍可開始和加入通話。**設定 → 好友**中的月亮圖示也有同樣功能。 |

## 其他 App 中的會議

對於 Zoom、Teams、FaceTime 或微信通話，請使用[會議錄音](/zh-hant/features/meeting-recording)：**設定 → 錄音 → 新增錄音**會錄下你的麥克風、通話的音訊，或兩者，並附有即時逐字稿。**新增錄音**旁的箭頭有**會議提醒**，當這些通話開始時，它會在動態島上詢問是否要錄音。

若要讓你的 Agent 代你加入 Google Meet 或 Zoom 會議，請參閱[通話中的 Agent](/zh-hant/features/agents-in-calls)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 你的相機或麥克風未獲允許 | 點選訊息上的**開啟系統設定**並允許 Enconvo，然後再試一次。 |
| 你加入時麥克風是關閉的 | 五人以上的會議會讓你以靜音開始。點選**麥克風**，或按住 Space 說話。 |
| 有人無法進入 | 會議已鎖定，或訪客必須先請求。請從等候室讓他們進入。 |
| 其他人的影像停止了 | 你的連線很慢，或**停止接收影片**已開啟。聲音和分享的螢幕仍會繼續。 |
| 通話不會讓這台 Mac 響鈴 | 檢查**設定 → 視訊會議**中的**通話勿擾**。 |
| 通話視窗停止運作 | 點選視窗中訊息上的**重新加入**。 |

當任務需要的不只是文字時，「電腦操作」讓 Enconvo 能操作你 Mac 上的 App。它會查看最前面的 App，找出看得到的控制項，點擊或在欄位中輸入、捲動清單、拖曳項目、選擇檔案、使用 App 選單，並在下一步之前等待 App 回應。

適合用於以下桌面任務：

- 在 Mac App 中填寫表單
- 在檔案選擇器中選取檔案
- 在設定視窗中切換操作
- 點擊工具列按鈕或選單項目
- 完成需要多個步驟的 App 任務
- 讀取目前視窗中可見的內容

至於網站，「使用瀏覽器」會透過 Enconvo 瀏覽器擴充功能（瀏覽器助手）在你自己的瀏覽器中運作。在沒有安裝擴充功能的瀏覽器（例如 Safari）中，「電腦操作」則改為在螢幕上點擊和輸入。

下方的影片教學會在 5 分鐘內設定並完整使用「電腦操作」與「使用瀏覽器」：開啟功能並授予兩項權限、將瀏覽器擴充功能加入 Chrome、按住右側 Option 鍵提出需求，觀看它在 Safari、Chrome 和 Mac App 中工作，並交給它一整個任務。

## 開啟電腦操作

「電腦操作」需要兩項 macOS 權限：「輔助使用」用於點擊和輸入，「螢幕錄製」用於查看螢幕。

<Steps>
  <Step title="開啟電腦操作設定">
    開啟 **設定 → 電腦操作**，並確認開關已開啟。
  </Step>
  <Step title="檢查兩項權限">
    **輔助使用** 與 **螢幕錄製** 都應顯示 **已啟用**。
  </Step>
  <Step title="授予缺少的權限">
    如果有一項顯示 **必填**，請點擊旁邊的 **開啟**，然後在 **系統設定 → 隱私權與安全性** 中，於該權限下開啟 Enconvo。回到 Enconvo 後，點擊 **重新整理**。如果狀態仍未改變，請結束並重新開啟 Enconvo。
  </Step>
</Steps>

## 新增瀏覽器擴充功能

<Steps>
  <Step title="開啟使用瀏覽器設定">
    開啟 **設定 → 使用瀏覽器**。**瀏覽器擴充功能** 會列出已安裝擴充功能的瀏覽器及其連線狀態。
  </Step>
  <Step title="安裝瀏覽器配套程式">
    點擊 **安裝瀏覽器配套程式**。接著會在 Chrome 線上應用程式商店開啟該擴充功能的頁面。
  </Step>
  <Step title="加入擴充功能">
    點擊 **加到 Chrome**，再點擊 **新增擴充功能**。開啟瀏覽器的擴充功能選單，並釘選該擴充功能，讓它固定顯示在工具列上。
  </Step>
  <Step title="檢查連線">
    回到 **設定 → 使用瀏覽器**，該瀏覽器會顯示 **已連接**。Edge、Arc 和 Brave 的設定方式相同。
  </Step>
</Steps>

擴充功能的彈出視窗、支援的瀏覽器與疑難排解，請參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。

## 執行任務

請說明你想要的結果，而不是列出一連串點擊動作。

<Steps>
  <Step title="開啟目標 App">
    將你要 Enconvo 操作的 App 或視窗移到最前面。
  </Step>
  <Step title="按住右側 Option 鍵並提出需求">
    按住右側的 **Option** 鍵，說出你的需求，然後放開。請指明 App 和頁面，例如：「在 Safari 的這個頁面上，找出最便宜的直飛航班」或「開啟設定面板，並關閉登入時啟動。」你也可以用輸入的方式向代理程式提出請求。
  </Step>
  <Step title="觀看它工作">
    Enconvo 正在操作的視窗邊緣會有柔和的光芒流動，每次點擊都會泛起一圈光波，動態島則會顯示每個步驟。當視窗不在視線內時，[子母畫面](/zh-hant/features/picture-in-picture)視窗會在螢幕角落即時顯示。你可以隨時接手或停止任務。
  </Step>
  <Step title="確認敏感步驟">
    對於具破壞性、涉及金錢、帳號或變更權限的動作，請在 Enconvo 繼續之前確認該步驟。這也包含鍵盤快速鍵：在執行會刪除、傳送、付款、結束 App 或登出的快速鍵之前，Enconvo 會先詢問。
  </Step>
  <Step title="取得結果">
    Enconvo 會查看 App、執行動作、等待結果，並持續進行，直到任務完成或需要你確認。完成後，它會告訴你結果。
  </Step>
</Steps>

### 在你的瀏覽器中

> 「開啟富士山與雷尼爾山的維基百科頁面，並告訴我哪一座比較高。」

在擴充功能已連接的情況下，「使用瀏覽器」會在背景開啟自己的分頁，因此你正在看的頁面不會被打擾。擴充功能運作時，瀏覽器會在頁面頂端顯示一條橫幅；請不要取消它。當代理程式的這一輪結束時，它開啟的分頁會關閉。它交給你作為結果的頁面、交給你的分頁、你已釘選的分頁，以及你正在查看的分頁會保持開啟，而你自己的分頁永遠不會被關閉。

## 電腦操作能做什麼

| 動作 | 範例 |
|--------|----------|
| **檢視 App 狀態** | 讀取目前的視窗、控制項、選單項目、選取的文字與可見的欄位 |
| **點擊與按兩下** | 點擊按鈕、側邊欄列、工具列項目、選單指令與座標 |
| **輸入與按鍵** | 填寫欄位、送出表單、使用 **⌘S** 等快速鍵 |
| **捲動** | 瀏覽清單、表格、設定面板或長文件 |
| **拖曳** | 在 App 支援時，拖曳檔案、列、滑桿或選取控點 |
| **使用檔案選擇器** | 在「開啟」與「儲存」對話框中選擇檔案和資料夾 |
| **動作後等待** | 在點擊、換頁或載入步驟之後再次檢查 App |
| **登入 App** | 在 App 的登入畫面輸入已儲存的使用者名稱和密碼，而代理程式不會看到密碼。請參閱[憑證](/zh-hant/configuration/credentials)。 |

多個代理程式可以同時使用「電腦操作」，例如在不同 App 中工作的子代理程式。每個代理程式會同時在各自的 App 中操作；只有在同一個 App 中工作的代理程式才需要輪流。即使 App 的另一個視窗在最前面，動作也會送到代理程式所指的視窗。

## 選擇它可以使用哪些 App

**設定 → 電腦操作 → App 存取** 用來設定「電腦操作」可以查看與使用哪些 App。請選擇一個 **模式**：

- **所有 App，除了**：「電腦操作」不會碰 **已封鎖的 App** 下的 App，其餘的都可以使用。
- **僅這些 App**：「電腦操作」只會使用 **允許的 App** 下的 App。在 **當代理需要其他 App 時** 下，選擇 **讓我確認**，即可在代理程式需要某個 App 時回答「要讓「電腦操作」使用這個 App 嗎？」，或選擇 **拒絕**。

點擊 **新增 App**，從目前開啟的 App 或「應用程式」資料夾中加入 App。已封鎖的 App 不會出現在螢幕截圖中。密碼管理工具與系統登入提示一律會被封鎖，顯示為 **密碼與系統提示**。PopBar、選取的文字與聽寫則保有各自的設定。

## 範例

| 請求 | Enconvo 的動作 |
| --- | --- |
| 「在這個檔案選擇器中，選取桌面上最新的螢幕截圖。」 | 查看檔案選擇器，前往該資料夾，選取檔案，並確認對話框。 |
| 「開啟這個 App 的偏好設定並停用通知。」 | 使用 App 的選單，找到該設定，將它關閉，並檢查結果。 |
| 「在「時鐘」中，將東京與倫敦加入世界時鐘。」 | 找到每個城市，加入清單，並檢查兩者都已加入。 |
| 「找出我的履歷，並應徵這份職缺。」 | 找到檔案，填寫表單的每個欄位，附上檔案並送出。請在讓它送出之前檢查表單。 |
| 「從「郵件」複製確認碼，並貼到登入視窗中。」 | 讀取可見的視窗，在它們之間切換，複製文字並貼到欄位中。 |

## 安全使用

<Warning>
「電腦操作」處理的是真實的 App 和真實的資料。在讓 Enconvo 送出表單、變更帳號設定、刪除檔案、進行購買或傳送訊息之前，請先檢查螢幕。
</Warning>

- 盡可能讓目標視窗保持可見。
- 提供明確的目標與任何限制。
- 在 Enconvo 對私人或財務頁面執行動作之前先檢查。
- 如果螢幕上的內容與你的要求不再相符，請停止任務。

## 設定項目

| 設定 | 位置 | 作用 |
| --- | --- | --- |
| **App 存取** | **設定 → 電腦操作** | 「電腦操作」可以查看與使用哪些 App；請參閱[選擇它可以使用哪些 App](#選擇它可以使用哪些-app)。 |
| **子母畫面視窗** | **設定 → 電腦操作** | App 視窗的即時畫面何時顯示在螢幕角落：**永遠**（預設）、**僅在需要我時** 或 **關閉**。請參閱[子母畫面](/zh-hant/features/picture-in-picture)。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| Enconvo 看不到 App 的控制項 | 確認 Enconvo 具有「輔助使用」權限，然後重新啟動 Enconvo 和該 App。有些 App 提供的控制項較少；螢幕截圖和依位置點擊仍然可以運作。 |
| 點擊落在錯誤的 App 上 | 開始前先將 App 移到最前面。開啟了多個視窗時，請在請求中指明 App 或視窗。 |
| 在檔案選擇器中選取檔案失敗 | 確認檔案存在，且選擇器接受該檔案類型。若檔案位於 iCloud 或網路磁碟機上，請等待它下載完成。 |
| 代理程式說它無法使用某個 App | 該 App 已被封鎖，或不在 **設定 → 電腦操作 → App 存取** 的允許清單中。請修改清單，或在代理程式要求使用該 App 時回應提示。 |
| 任務進行得太快 | 請 Enconvo 等待你看得到的事物，例如「等到「儲存」按鈕可用為止」或「表格重新載入後再繼續」。 |

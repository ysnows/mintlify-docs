當任務需要的操作超越純文字處理時，電腦操作讓 Enconvo 能夠直接操作你 Mac 上的應用程式。它會查看前景的應用程式、辨識畫面上的控制項、點擊或輸入欄位、捲動列表、拖曳項目、挑選檔案、使用應用程式選單，並在執行下一步前等待應用程式回應。

適用於以下桌面任務：

- 在 Mac 應用程式中填寫表單
- 在檔案選擇器中挑選檔案
- 在設定視窗中切換與操作
- 點擊工具列按鈕或選單項目
- 在應用程式中完成多步驟的任務
- 讀取目前視窗中的可見內容

對於網站操作，使用瀏覽器會透過 Enconvo 瀏覽器擴充功能（Browser Companion）在你自己的瀏覽器內運作。在沒有安裝擴充功能的瀏覽器（例如 Safari）中，電腦操作則會改以在螢幕上點擊和輸入的方式操作。

## 開啟電腦操作

電腦操作需要兩項 macOS 權限：「輔助使用」用來點擊和輸入，「螢幕錄製」用來查看螢幕畫面。

<Steps>
  <Step title="開啟電腦操作設定">
    開啟**設定 → 電腦操作**，並確認開關已開啟。
  </Step>
  <Step title="檢查兩項權限">
    **輔助使用**與**螢幕錄製**都應該顯示為**已啟用**。
  </Step>
  <Step title="授予缺少的權限">
    若其中一項顯示為**必需**，點擊旁邊的**開啟**，接著在**系統設定 → 隱私權與安全性**的該權限底下開啟 Enconvo。回到 Enconvo 後點擊**重新整理**。如果狀態仍未更新，請結束並重新開啟 Enconvo。
  </Step>
</Steps>

## 新增瀏覽器擴充功能

<Steps>
  <Step title="開啟使用瀏覽器設定">
    開啟**設定 → 使用瀏覽器**。**瀏覽器擴充功能**會列出裝有該擴充功能的瀏覽器及其連線狀態。
  </Step>
  <Step title="安裝瀏覽器配套程式">
    點擊**安裝瀏覽器配套程式**。Chrome 線上應用程式商店中的擴充功能頁面將會開啟。
  </Step>
  <Step title="新增擴充功能">
    點擊**加到 Chrome**，再點擊**新增擴充功能**。開啟瀏覽器的擴充功能選單並將它釘選，讓它常駐於工具列中。
  </Step>
  <Step title="檢查連線">
    回到**設定 → 使用瀏覽器**，該瀏覽器應會顯示**已連接**。Edge、Arc 與 Brave 的設定方式相同。
  </Step>
</Steps>

關於擴充功能的彈出視窗、支援的瀏覽器與疑難排解，請參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。

## 執行任務

告訴它你想要的結果，而不是一連串點擊步驟。

<Steps>
  <Step title="開啟目標應用程式">
    將你想讓 Enconvo 操作的應用程式或視窗切換到最前方。
  </Step>
  <Step title="按住右側 Option 鍵並提問">
    按住右側 **Option** 鍵，說出你的需求，然後放開。請指明應用程式與頁面，例如：「在 Safari 的這個頁面中，找出最便宜的直飛航班」或「開啟設定面板並關閉登入時啟動」。你也可以直接打字向代理程式提出要求。
  </Step>
  <Step title="觀察運作過程">
    Enconvo 正在操作的視窗邊緣會有一道柔和光線流過，每次點擊都會泛起光波漣漪，動態島也會顯示每一個步驟。當視窗不在視線內時，[畫中畫](/zh-hant/features/picture-in-picture)視窗會在螢幕角落即時顯示該畫面。你可以隨時接手或停止任務。
  </Step>
  <Step title="確認敏感步驟">
    遇到破壞性操作、金融交易、帳號設定或權限變更等動作時，請先確認該步驟再讓 Enconvo 繼續。這也包含鍵盤快速鍵：Enconvo 會在執行刪除、傳送、付款、結束應用程式或登出的快速鍵前詢問你。
  </Step>
  <Step title="取得結果">
    Enconvo 會查看應用程式狀態、執行操作、等待結果，並持續推進直到任務完成或需要你的確認。任務結束後，它會向你回報結果。
  </Step>
</Steps>

### 在你的瀏覽器中

> 「開啟富士山和雷尼爾山的維基百科頁面，並告訴我哪一座比較高。」

連接擴充功能後，使用瀏覽器會在背景開啟它自己的分頁，你目前檢視的頁面不會受到影響。擴充功能作業期間，瀏覽器會在頁面頂部顯示一則提示列；請勿取消它。當代理程式的這一輪工作結束時，它開啟的分頁會自動關閉。作為結果交給你的頁面、已移交給你的分頁、你釘選的分頁，以及你正在查看的分頁都會保持開啟，而你自己的分頁絕對不會被關閉。

## 電腦操作能做什麼

| 操作 | 範例 |
|--------|----------|
| **檢查應用程式狀態** | 讀取目前視窗、控制項、選單項目、選取的文字與可見欄位 |
| **點擊與雙擊** | 點擊按鈕、側邊欄列表列、工具列項目、選單指令與指定座標 |
| **輸入與按鍵** | 填寫欄位、送出表單、使用如 **⌘S** 等快速鍵 |
| **捲動** | 在列表、表格、設定面板或長文件中上下捲動 |
| **拖曳** | 在應用程式支援時拖曳檔案、列表列、滑桿或選取範圍控制點 |
| **使用檔案選擇器** | 在開啟與儲存對話框中選擇檔案與資料夾 |
| **操作後等待** | 在點擊、頁面切換或載入步驟後再次檢查應用程式 |
| **登入應用程式** | 將已儲存的使用者名稱與密碼輸入應用程式的登入畫面，且不讓代理程式看見密碼。參閱[憑證](/zh-hant/configuration/credentials)。 |

多個代理程式可以同時使用電腦操作，例如在不同應用程式中各自運作的子代理。每個代理程式會在各自負責的應用程式中同步行動；只有操作同一個應用程式的代理程式才需要輪流執行。即使該應用程式的其他視窗位於最前方，操作也會準確送達代理程式所指定的視窗。

## 選擇可用應用程式

**設定 → 電腦操作 → App 存取**設定了電腦操作可以查看與使用的應用程式。選擇一種**模式**：

- **所有 App，除了**：電腦操作會避開**已封鎖的 App** 中的應用程式，而使用其他任何應用程式。
- **僅這些 App**：電腦操作只會使用**允許的 App** 中的應用程式。在**當代理需要其他 App 時**下方，選擇**讓我確認**以便在代理程式需要某個應用程式時回答「允許電腦操作使用此 App 嗎？」，或是選擇**拒絕**。

點擊**新增 App**，即可從目前開啟的應用程式或「應用程式」資料夾中加入項目。已封鎖的應用程式不會出現在螢幕截圖中。密碼管理員與系統登入提示永遠會被封鎖，顯示為**密碼與系統提示**。PopBar、選取的文字與聽寫則保留各自的獨立設定。

## 範例

| 請求 | Enconvo 的動作 |
| --- | --- |
| 「在這個檔案選擇器中，選擇我桌面上最新的截圖。」 | 查看檔案選擇器、前往該資料夾、選取檔案並確認對話框。 |
| 「開啟這個 App 的偏好設定並關閉通知。」 | 操作應用程式選單、找到該設定、將其關閉並檢查結果。 |
| 「在時鐘中，將東京和倫敦加到世界時鐘。」 | 尋找各個城市、將它們加入列表，並確認兩者皆已加入。 |
| 「找到我的履歷並應徵這份職缺。」 | 找到檔案、填寫表單中的每一欄、附上檔案並送出。送出前請先檢查表單內容。 |
| 「從郵件複製驗證碼並貼到登入視窗中。」 | 讀取可見視窗、在視窗之間切換、複製文字並貼入欄位。 |

## 保持安全

<Warning>
電腦操作處理的是真實的應用程式與真實的資料。在讓 Enconvo 送出表單、變更帳號設定、刪除檔案、進行購買或傳送訊息前，請先確認螢幕上的內容。
</Warning>

- 盡可能讓目標視窗保持在可視範圍內。
- 提供明確的目標以及任何限制條件。
- 在 Enconvo 操作私人或財務相關頁面之前，請先仔細檢查。
- 若螢幕上進行中的動作已不符合你的需求，請立即停止任務。

## 設定

| 設定 | 位置 | 作用 |
| --- | --- | --- |
| **App 存取** | **設定 → 電腦操作** | 電腦操作可以查看與使用哪些應用程式；參閱[選擇可用應用程式](#選擇可用應用程式)。 |
| **畫中畫視窗** | **設定 → 電腦操作** | 應用程式視窗的即時畫面何時顯示在螢幕角落：**永遠**（預設）、**僅在需要我時**或**關閉**。參閱[畫中畫](/zh-hant/features/picture-in-picture)。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| Enconvo 看不見某個應用程式的控制項 | 檢查 Enconvo 是否具備輔助使用權限，然後重新啟動 Enconvo 與該應用程式。部分應用程式開放給系統的控制項較少，但截圖與依座標點擊通常仍可運作。 |
| 點擊到錯誤的應用程式 | 開始前先將目標應用程式切換到最前方。開啟多個視窗時，請在請求中明確說出應用程式或視窗名稱。 |
| 在檔案選擇器中選取檔案失敗 | 確認該檔案存在且選擇器支援該檔案類型。若是儲存在 iCloud 或網路磁碟上的檔案，請先等待它下載完成。 |
| 代理程式表示無法使用某個應用程式 | 該應用程式在**設定 → 電腦操作 → App 存取**中被封鎖或未列入允許清單。請調整清單，或在代理程式請求使用該應用程式時於提示中同意。 |
| 任務進行得太快 | 請要求 Enconvo 等待你能看見的畫面條件，例如「等到儲存按鈕啟用後再繼續」或「等表格重新載入後再繼續」。 |

代理程式電話讓你的代理程式能夠使用電話功能。當任務等待你的輸入時，代理程式可以打電話給你；可以在聊天中依你的指定撥打電話給個人或商家；可以替你呼叫你的 Enconvo 好友與團隊成員；還可以代你接聽你沒有接起的 iPhone 來電。每通電話的逐字稿都會回傳到聊天中。

## 開始之前

開啟**設定 → 代理程式電話**並設定至少一種通話方式：

| 方式 | 作用 | 費用 |
| --- | --- | --- |
| **你的 iPhone** | 當你的 iPhone 在附近時，這台 Mac 會透過你自己的門號在 iPhone 上撥出與接聽電話。使用**替我接聽來電**必須設定此項。 | 依你的電信資費計算（無額外費用）。 |
| **電話服務商** | 代理程式使用你自己 Twilio 或 Telnyx 帳號中的號碼撥打電話。 | 由服務商依通話計費。 |
| **EnConvo 行動 App** | 代理程式會像來電一樣呼叫你手機上的 EnConvo App。接聽即開始 [Live Talk](/zh-hant/features/live-voice)。在 Android 上，從來電通知或鎖定畫面接聽即可直接連線，無需解鎖或開啟 App。僅限撥打給你本人。 | 透過 Wi-Fi 或行動數據免費使用。 |

## 設定你的 iPhone

1. 在**你的 iPhone** 底下點擊**設定**。圖片引導指南會一步一步帶你操作，並為每個步驟開啟對應的設定頁面。
2. 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo，讓 Enconvo 能在 macOS 的通話提示中按下撥打與結束按鈕。
3. 在 **FaceTime → 設定 → 一般**中開啟**來自 iPhone 的通話**。
4. 在**系統設定 → 通知**中，為「電話」與「FaceTime」開啟**允許通知**與**桌面**通知樣式。macOS 會以通知形式顯示每通電話。
5. 確認你的 iPhone 與這台 Mac 使用同一個 Apple 帳號。在 iPhone 上開啟**設定 → App → 電話 → 在其他裝置上通話**並允許這台 Mac。
6. 將你的 iPhone 放在這台 Mac 附近，並連上同一個 Wi-Fi。
7. 點擊**加入 Enconvo Audio**，並在 macOS 詢問時輸入你的 Mac 登入密碼。Enconvo Audio 負責將代理程式的聲音送入通話並傳回對方的聲音，不會佔用你的麥克風或揚聲器。
8. 點擊**檢查音訊**。它會透過 Enconvo Audio 播放一段短提示音並進行監聽；不會真的撥號響鈴。

當狀態顯示**已就緒**時，代理程式就會使用你 iPhone 的門號撥打電話，接聽方看到的也會是你的號碼。當你的 iPhone 不在附近時，如果你有設定電話服務商，系統會改用電話服務商撥出。

## 設定電話服務商

1. 在**電話服務商**底下，點擊 Twilio 或 Telnyx 旁的**設定**或**連接**。Enconvo 會安裝外掛程式並請你登入或輸入 API 金鑰。
2. 在**來電號碼**（撥出號碼）中選擇撥出電話使用的號碼。
3. 點擊**測試來電**進行測試。

代理程式預設使用預設的電話服務商，只有在你在聊天中特別指定，或預設服務商無法撥號時才會使用另一個。Telnyx 通話會透過名為 Enconvo Agent Phone 的 TeXML 應用程式進行，Enconvo 會自動將它加入你的帳號。Twilio 試用帳號僅能撥打你在 Twilio 中驗證過的號碼。

透過 Twilio 與 Telnyx 撥出的通話支援按鍵輸入，因此代理程式能通過自動語音選單與分機轉接。透過「你的 iPhone」撥出的通話同樣支援此功能。

## 在任務需要你時接收來電

在**代理程式來電設定 → 等待你處理的任務**中，選擇當你離開 Mac 時代理程式如何聯繫你：

1. 若已配對手機，會優先立即呼叫 EnConvo 行動 App。
2. 若無人接聽，則會撥打你的電話號碼。設定號碼並選擇**撥出線路**：**你的 iPhone**、Twilio 或 Telnyx。

來電會顯示代理程式的名稱。同一個聊天中等待處理的請求會合併為同一通電話，你拒接的來電不會再次重撥。**通知延遲**可設定任務等待多久後才通知你。**包含任務詳情**會在撥打電話號碼的通話中唸出任務內容；關閉時只會唸出聊天標題，且無法在電話中直接給予核准。

你也可以在聊天中直接要求代理程式打電話給你，透過 App、你的 iPhone、Twilio 或 Telnyx 皆可。你主動要求的通話每次都會響鈴。

## 讓代理程式代你致電他人

1. 在**代理程式來電設定**底下開啟**代你撥出電話**。
2. 在聊天中請代理程式撥打電話給某人或某個商家，並說明這通電話的目的。
3. 通話卡片會顯示號碼以及通話將說明的內容。點擊**確認撥打**。在以**完整取用**執行的聊天中，代理程式會直接撥號而不等待確認。
4. 在卡片上即時關注通話進度，或點擊**結束通話**。通話結束後，結果卡片會顯示雙方的對話內容。

如果尚未設定電話線路，通話卡片會讓你在聊天中直接設定「你的 iPhone」或 Telnyx，準備就緒後隨即撥出。

## 讓代理程式致電好友

在聊天中請代理程式致電 Enconvo [好友](/zh-hant/features/friends)或團隊成員，並告訴它要轉達什麼內容。它會先呼叫對方的 Enconvo App、替你與對方對話，並將對方的回答和通話逐字稿帶回你的聊天中。只有當你明確要求撥打電話號碼，或 Enconvo 通話無法聯繫到對方時，它才會改撥對方的手機號碼。

代理程式只會聯繫你的好友與團隊成員，絕不會聯繫僅在會議通話中見過的人。排程任務也可以向你允許聯繫的好友傳送訊息或撥打電話，例如在午夜將報告傳送給某人，若對方到早上仍未回覆就打電話提醒。

## 錄製通話

開啟**錄製通話**後，代理程式撥打給你或其他人的每一通電話（無論透過手機 App 還是電話號碼），都會連同逐字稿儲存到這台 Mac 的[錄音](/zh-hant/features/meeting-recording)中。**最近通話**中每筆已錄製的通話旁都有一個錄音按鈕。代理程式呼叫的好友會聽到並看到通話正在錄製的提示，如果對方表示不希望錄製，系統就不會保留任何錄音。

<Warning>
部分地區要求通話雙方都必須同意才能進行錄音。請確保你有權錄製代理程式撥打對象的通話內容。
</Warning>

## 讓代理程式接聽你的未接來電

**替我接聽來電**需要設定「你的 iPhone」。當你沒有接聽 iPhone 的來電時，代理程式會在你的 Mac 上替你接聽、記錄留言，並將摘要與逐字稿傳送到「更新」。

1. 在**你的 iPhone** 底下開啟**替我接聽來電**。當系統詢問時請允許存取「聯絡人」，讓 Enconvo 能辨識已儲存在聯絡人中的來電者。
2. 選擇**你沒有接聽時**的等待時間：響鈴幾聲後接聽，預設為 5 秒。
3. 選擇要代接哪些來電：**不在聯絡人中的號碼**或**所有人**。**安靜時段內立即接聽**會在「通知」設定的安靜時段內略過等待直接接聽。
4. 在**可以說的內容**中，寫下它應以什麼身分接聽，以及可以告訴來電者什麼資訊。它只負責記錄留言，絕不會替你答應任何承諾。
5. 若有多台 Mac，請選擇哪一台**優先接聽**。其他 Mac 只會在該台電腦離線時才會代接。

每通電話結束後，你的手機會收到通知，說明誰打來、對方想找你做什麼（一句話摘要），以及是否緊急。緊急來電會突破專注模式通知你。通知附有**回撥**與**開啟**按鈕。疑似詐騙的來電會帶有**疑似詐騙**標記與警告提示。

來電者無法操控你的代理程式執行操作。在通話中，代理程式僅能交談與記錄留言，無法存取任何工具、聊天、記憶或檔案。通話摘要也是在不使用工具的情況下撰寫的。進入該通話的聊天後，在你回覆之前不會執行任何動作；即使在「完整取用」模式下，任何涉及傳送、付款、刪除或執行指令的操作仍會先向你確認。設定中的**來電者可觸及的範圍**會顯示這些限制。

### 可以指派任務的號碼

在**可以指派任務的號碼**底下新增你自己的其他號碼。來自這些號碼的來電可以與代理程式對話並指派任務給它；其他所有來電者都只能留言。由於來電顯示號碼有可能被偽造來冒充這些號碼，請開啟**要求通關密語**：在來電者說出密語之前，通話只會記錄留言。

## 檢視通話記錄

聊天視窗側邊欄的**通話**區塊會將代理程式代接的來電與你的其他聊天分開管理。它會標記緊急來電、需要回電或尚未閱讀的通話，並顯示每通電話的來電時間以及來電者的號碼或聯絡人名稱。點擊**回撥**或**標記為已完成**即可處理。iPhone 與 Android App 中也有相同的區塊。

**設定 → 代理程式電話**底部的**最近通話**會列出代理程式撥出或接聽的每一通電話及其結果。

## 設定

| 設定 | 變更內容 |
| --- | --- |
| **你的 iPhone** | 透過這台 Mac 使用你自己的 iPhone 號碼撥打電話，以及**替我接聽來電**。 |
| **電話服務商** | Twilio 與 Telnyx 帳號、預設服務商，以及**來電號碼**。 |
| **呼叫 EnConvo App** | 讓代理程式呼叫你已配對的手機。**配對手機**可新增裝置。 |
| **等待你處理的任務** | 當任務等待時代理程式如何聯繫你：先透過 App，再撥打你的號碼，可設定**撥出線路**、**通知延遲**與**包含任務詳情**。 |
| **代你撥出電話** | 允許代理程式撥打電話給你在聊天中指定的人。 |
| **錄製通話** | 將代理程式通話及其逐字稿儲存至「錄音」。 |
| **替我接聽來電** | 讓代理程式接聽你未接起的 iPhone 來電。 |

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| **找不到 Enconvo Audio** | macOS 更新可能會移除它。點擊**重新加入**並在 macOS 顯示的視窗中輸入你的 Mac 登入密碼；該視窗可能會被其他視窗擋在後方。 |
| **輔助使用權限已關閉** | 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo。 |
| **聽不到通話聲音** | 在**系統設定 → 隱私權與安全性 → 螢幕與系統錄音**的**僅系統錄音**底下允許 Enconvo，然後點擊**檢查音訊**。 |
| **通知已關閉** | 為「電話」與「FaceTime」開啟**允許通知**與**桌面**通知樣式。在此之前，通話會改用電話服務商撥出。 |
| **你的 iPhone 不在附近** | 將 iPhone 帶到這台 Mac 附近並連上同一個 Wi-Fi。在此之前，通話會改用電話服務商撥出。 |
| Twilio 通話無法撥出 | 試用帳號僅能撥打已驗證的號碼。請在 Twilio 中驗證該號碼，或升級帳號。 |
| **替我接聽來電**無法辨識聯絡人 | 允許 Enconvo 存取「聯絡人」，或設定讓可讀取聯絡人的 Mac 優先接聽。 |

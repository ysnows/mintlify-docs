---
title: "代理程式電話"
description: "讓你的 Agent 在任務需要你時打給你、代你打給其他人和 Enconvo 好友，並接聽你錯過的來電。"
---

代理程式電話讓你的 Agent 能使用電話。Agent 可以在任務等待你輸入時打給你、打給你在對話中指名的人或商家、代你打給你的 Enconvo 好友和團隊成員，並接聽你沒有接的 iPhone 來電。每通電話的逐字稿都會回到對話中。

## 開始之前

開啟**設定 → 代理程式電話**，並至少設定一種撥打方式：

| 方式 | 作用 | 費用 |
| --- | --- | --- |
| **你的 iPhone** | 這台 Mac 會在你的 iPhone 在附近時，用你自己的號碼透過 iPhone 撥出和接聽來電。**替我接聽來電**需要此方式。 | 包含在你的電信方案中，不需額外付費。 |
| **電話服務商** | Agent 使用你自己的 Twilio 或 Telnyx 帳號中的號碼撥出。 | 由服務商對每通電話計費。 |
| **EnConvo 行動 App** | Agent 會像電話一樣讓你手機上的 EnConvo App 響鈴。接聽後會啟動 [Live Talk](/zh-hant/features/live-voice)。在 Android 上，從來電通知或鎖定畫面接聽時，不需解鎖或開啟 App 就能接通。僅適用於打給你的來電。 | 透過 Wi-Fi 或行動數據免費。 |

## 設定你的 iPhone

1. 在**你的 iPhone**下，點選**設定**。一份以圖片為主的引導會一步一步帶你操作，並為每一步開啟正確的位置。
2. 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo，讓 Enconvo 能在 macOS 的來電提示中按下「撥打」和「結束」。
3. 在 **FaceTime → 設定 → 一般**中開啟**來自 iPhone 的通話**。
4. 在**系統設定 → 通知**中，為「手機」和 FaceTime 開啟**允許通知**和**桌面**。macOS 會以通知顯示每一通來電。
5. 確認你的 iPhone 和這台 Mac 使用相同的 Apple 帳號。在 iPhone 上開啟**設定 → App → 電話 → 在其他裝置上通話**，並允許這台 Mac。
6. 讓你的 iPhone 靠近這台 Mac，並連接同一個 Wi-Fi。
7. 點選**加入 Enconvo Audio**，並在 macOS 要求時輸入你的 Mac 登入密碼。Enconvo Audio 會把你 Agent 的聲音送入通話，並把對方的聲音傳回來，不會用到你的麥克風或喇叭。
8. 點選**檢查音訊**。它會透過 Enconvo Audio 播放一小段提示音並偵聽；不會有任何電話響鈴。

當顯示**已就緒**時，Agent 會用你 iPhone 的號碼撥出，被撥打的人會看到你的號碼。當你的 iPhone 不在附近時，若你已設定電話服務商，就會改由電話服務商撥出。

## 設定電話服務商

1. 在**電話服務商**下，點選 Twilio 或 Telnyx 旁的**設定**或**連接**。Enconvo 會加入外掛程式，並要求你登入或提供 API 金鑰。
2. 在**來電號碼**中選擇撥出時使用的號碼。
3. 點選**測試來電**試試看。

Agent 使用預設的服務商，只有在你於對話中要求，或預設服務商無法撥出時，才會使用另一個。Telnyx 的通話會透過名為 Enconvo Agent Phone 的 TeXML 應用程式進行，Enconvo 會將它加入你的帳號。Twilio 試用帳號只能撥打你已在 Twilio 驗證過的號碼。

透過 Twilio 和 Telnyx 的通話可以按下撥號鍵，因此 Agent 能通過自動語音選單和分機。透過你的 iPhone 的通話也可以。

## 在任務需要你時接到來電

在**代理程式來電設定 → 等待你處理的任務**下，選擇 Agent 在你離開 Mac 時如何聯絡你：

1. EnConvo 行動 App 會立即響鈴（若已配對）。
2. 若沒有人接聽，就會撥打你的電話號碼。請設定號碼並選擇**撥出線路**：**你的 iPhone**、Twilio 或 Telnyx。

來電會以該 Agent 的名稱響鈴。同一個對話中待處理的請求會合併成一通電話，而你拒接的來電不會再重撥。**通知延遲**設定任務在通知你之前要等多久。**包含任務詳情**會在撥打電話號碼的來電中朗讀任務內容；關閉時，只會報出對話標題，並且無法透過電話進行核准。

你也可以在對話中要求 Agent 打給你，透過 App、你的 iPhone、Twilio 或 Telnyx。你要求的來電每次都會響鈴。

## 讓 Agent 打給某人

1. 在**代理程式來電設定**下開啟**代你撥出電話**。
2. 在對話中，要求 Agent 打給某個人或商家，並說明這通電話的目的。
3. 通話卡片會顯示號碼以及通話將要說的內容。點選**確認撥打**。在以完整存取權限執行的對話中，Agent 會直接撥出而不等待。
4. 在卡片上追蹤通話，或點選**結束通話**。通話結束後，結果卡片會顯示雙方各說了什麼。

如果尚未設定任何電話線路，通話卡片讓你直接在對話中設定你的 iPhone 或 Telnyx，準備好後通話就會接通。

## 讓 Agent 打給好友

要求 Agent 打給某位 Enconvo [好友](/zh-hant/features/friends)或團隊成員，並告訴它要說什麼。它會先讓對方的 Enconvo App 響鈴，代你與對方交談，並把對方的回答和通話逐字稿帶回你的對話。只有在你要求打電話，或 Enconvo 通話聯絡不到對方時，它才會撥打對方的電話號碼。

Agent 只會聯絡你的好友和團隊成員，絕不會聯絡你只在通話中認識的人。排程任務可以傳訊息和打電話給你允許它聯絡的好友。例如，它可以在午夜傳一份報告給某人，並在對方還沒回覆時於早上打給他們。

## 錄製通話

開啟**錄製通話**後，每一通 Agent 的通話，無論是打給你或其他人、透過電話 App 或電話號碼，都會連同逐字稿存入這台 Mac 上的[錄音](/zh-hant/features/meeting-recording)。**最近通話**中每一通已錄製的通話都有一個錄音按鈕。你的 Agent 所打給的好友會聽到並看到這通電話正在錄音，而如果對方表示不想被錄音，就不會保留任何錄音。

<Warning>
有些地方要求通話中所有人都同意後才能錄音。請確認你有權錄下你的 Agent 所撥打的對象。
</Warning>

## 讓 Agent 接聽你錯過的來電

**替我接聽來電**需要你的 iPhone。當你沒有接聽 iPhone 的來電時，Agent 會在你的 Mac 上接聽、留下訊息，並將摘要和逐字稿傳送到「更新」。

1. 在**你的 iPhone**下，開啟**替我接聽來電**。出現提示時請允許「聯絡人」，讓 Enconvo 能辨識已儲存在聯絡人中的來電者。
2. 選擇**你沒有接聽時**：響幾聲後接聽，預設為 5 秒。
3. 選擇它要接聽哪些來電：**不在聯絡人中的號碼**或**所有人**。**安靜時段內立即接聽**會在「通知」中設定的安靜時段內略過等待。
4. 在**可以說的內容**中，寫下它以什麼身分接聽，以及可以告訴來電者哪些事。它只會留下訊息，絕不會替你同意任何事。
5. 有多台 Mac 時，選擇由哪一台**優先接聽**。你的其他 Mac 只有在它離線時才會接聽。

每通電話結束後，你的手機會收到通知，內容包含是誰打來、對方想做什麼（一句話），以及是否緊急。緊急來電會突破專注模式。通知中有**回撥**和**開啟**。看起來像詐騙的來電會帶有**疑似詐騙**徽章和警告。

來電者無法讓你的 Agent 採取行動。在通話中，它只會交談並留下訊息，沒有工具、對話、記憶或檔案可用。摘要是在沒有工具的情況下寫成的。在該通話的對話中，在你回覆之前不會執行任何動作，而且傳送、付款、刪除或執行指令的動作，即使有完整存取權限也會先詢問你。設定中的**來電者能接觸的範圍**會顯示這些限制。

### 可以指派任務的號碼

在**可以指派任務的號碼**下新增你自己的其他號碼。來自這些號碼的來電會與你的 Agent 交談，並能指派任務給它；其他所有人只能留言。由於偽造的來電顯示可能冒充這些號碼之一，請開啟**要求通關密語**：在來電者說出密語之前，通話只會留下訊息。

## 檢視通話

聊天視窗側邊欄中的**通話**區段，會將你的 Agent 接聽的來電與你的其他對話分開。它會標示緊急、需要回撥或仍未讀的通話，並顯示每通電話響起的時間，以及來電者的號碼或聯絡人姓名。點選**回撥**，或**標記為已完成**。iPhone 和 Android App 中也有相同的區段。

**設定 → 代理程式電話**底部的**最近通話**會列出 Agent 撥出或接聽的每一通電話及其結果。

## 設定

| 設定 | 作用 |
| --- | --- |
| **你的 iPhone** | 透過這台 Mac 使用你自己的 iPhone 號碼撥出，以及**替我接聽來電**。 |
| **電話服務商** | Twilio 和 Telnyx 帳號、預設服務商，以及**來電號碼**。 |
| **呼叫 EnConvo App** | 讓 Agent 呼叫你已配對的手機。**配對手機**可新增一支。 |
| **等待你處理的任務** | 任務在等待時，Agent 如何聯絡你：先用 App，再撥你的號碼，並有**撥出線路**、**通知延遲**和**包含任務詳情**。 |
| **代你撥出電話** | 讓 Agent 打給你在對話中指名的人。 |
| **錄製通話** | 將 Agent 的通話及其逐字稿存入錄音。 |
| **替我接聽來電** | 由 Agent 接聽你沒有接的 iPhone 來電。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **缺少 Enconvo Audio** | macOS 更新可能會將它移除。點選**重新加入**，並在 macOS 顯示的視窗中輸入你的 Mac 登入密碼；該視窗可能被其他視窗擋住。 |
| **輔助使用未開啟** | 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo。 |
| **聽不到通話聲音** | 在**系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製**的**僅限系統音訊錄製**下允許 Enconvo，然後點選**檢查音訊**。 |
| **通知已關閉** | 為「手機」和 FaceTime 開啟**允許通知**和**桌面**。在此之前，通話會透過你的電話服務商進行。 |
| **你的 iPhone 不在附近** | 讓它靠近這台 Mac，並連接同一個 Wi-Fi。在此之前，通話會透過你的電話服務商進行。 |
| Twilio 通話無法接通 | 試用帳號只能撥打已驗證的號碼。請在 Twilio 驗證該號碼，或升級帳號。 |
| **替我接聽來電**無法辨識某位聯絡人 | 允許 Enconvo 存取「聯絡人」，或讓能讀取聯絡人的 Mac 優先接聽。 |

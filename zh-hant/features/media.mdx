**媒體**是你在 Enconvo 中製作的每一張圖片、影片與音訊片段的集中之處，無論是你在這裡製作的，還是代理程式在聊天中製作的。你可以用它完整掌控各項設定來生成圖片與片段、讓某個人物或產品在其中保持一致的外觀，並修復或重複使用你製作的內容。

它使用你在**設定 → 圖片生成**與**設定 → 影片生成**中設定的供應商。請參閱[圖片生成](/zh-hant/ai/image-generation)與[影片生成](/zh-hant/ai/video-generation)進行設定。

## 開啟媒體

點按聊天視窗側邊欄中的**媒體**。在頂端選擇**圖片**、**影片**或**音訊**。

- **全部**、**收藏**與你的資料夾可將你製作的內容分類。點按**新增資料夾**即可新增一個，並對項目使用**移到資料夾**來歸檔。
- 在**搜尋你的媒體**中輸入，即可依提示詞中的字詞找到項目。
- 點按星號即可將項目加入**收藏**。

這些檔案也在你的 Mac 上，位於 `~/Enconvo/Media`。

你也可以在新聊天的訊息輸入框下方選擇**圖片**或**影片**。模型、設定與要避免的內容會以標籤的形式顯示在訊息輸入框下方，其下方則有你最近的圖片或影片，以及一個**開啟媒體**連結。

## 製作圖片或影片

1. 在**圖片**或**影片**中，於底部的輸入區描述你想要的內容。
2. 檢查它下方的標籤：模型、**長寬比**、**品質**、圖片數量，以及**避免**（要排除的內容）。點按標籤即可變更，或點按**更多設定**查看其餘項目。只會顯示所選模型能接受的設定。
3. 點按**產生**。新的項目會在完成時出現在頂端。

當你要求多個版本時，請挑選要保留的。

### 影片的更多控制

- **起始影格**與**結束影格**：加入片段開始或結束時所停留的圖片。
- **加入鏡頭**：將影片分成多個鏡頭，每個鏡頭有各自的提示詞與長度。Enconvo 會將它們接成一部影片。
- **加入音訊檔案**：使用你自己的音訊，或**音訊**中的片段。

## 讓主體或風格保持一致

將某個人物、寵物、產品或角色的幾張照片儲存為主體，或將幾張你想要風格的圖片儲存為風格。在生成時選擇它，它在每張圖片與每部影片中都會保持相同的外觀。

1. 在輸入區中，點按**加入主體、風格或參考圖**。
2. 在**主體**下選擇**從照片新增**，或在**風格**下選擇**新增風格**。
3. 為它命名**名稱**、加入它的**照片**，並可選擇性地**描述一下**。
4. 點按**儲存**。下次生成時，從同一個選單中選擇它。

## 精修你製作的內容

點按項目即可開啟其詳細資料：提示詞以及它使用的每項設定。從這裡可以：

| 動作 | 作用 |
| --- | --- |
| **重複使用設定** | 以相同的提示詞與設定填入輸入區 |
| **變成影片** | 以這張圖片開始製作影片 |
| **放大** | 製作較大、較清晰的副本 |
| **移除背景** | 將主體摳出 |
| **重新打光** | 變更光線與氛圍 |
| **修改局部** | 開啟編輯器，塗繪要變更的區域 |
| **更多修復** | **修復舊照片**、**變更角度**、**擴展畫布**與**變體** |
| **再產生幾個類似的** | 以相同的設定製作新的版本 |

每次修復都會產生新的版本；原始版本會保留在**版本**之下。點按**在編輯器中開啟**，即可在圖片或影片編輯器中繼續編輯。

## 製作音訊

1. 開啟**音訊**並選擇**音樂**、**音效**或**語音**。
2. 描述風格或聲音，或輸入旁白的文字。音樂可以有歌詞，也可以是**純音樂**。
3. 點按**產生**。若要使用你現有的檔案，請點按**匯入音訊檔案**。

若要將音訊加到影片上，請開啟影片並點按**加入音訊**。從**你的音訊**中挑選片段，或選擇**匯入檔案**，選擇**與原聲混合**或**取代原聲**，然後點按**加入影片**。

<Warning>
每一張圖片、影片與音訊片段都會使用供應商的額度或你的 Enconvo Cloud 點數。影片的費用最高，因此請先試試簡短的片段。
</Warning>

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 圖片被拒絕作為主體或影格 | 使用 PNG、JPEG 或 WebP 圖片 |
| 你想要的設定沒有顯示 | 所選模型不支援它；請選擇其他模型 |
| 項目顯示**再試一次** | 它失敗了；請檢查供應商的存取權限，然後再試一次 |
| **音訊**中沒有聲音或模型 | 請設定能製作該類音訊的供應商；Enconvo Cloud 只能製作語音，音樂與音效需要你自己的 ElevenLabs 金鑰 |

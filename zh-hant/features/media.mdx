**媒體** 集中管理你在 Enconvo 中製作的每張圖片、每段影片與每個音訊片段，無論是由你親自製作，還是由代理程式在聊天中生成。你可以透過它全面控制設定來生成圖片和片段，讓人物或產品在各個畫面中維持一致的外觀，並修復或重複使用已經創作的內容。

它會使用你在 **設定 → 圖片生成** 與 **設定 → 影片生成** 中指定的服務供應商。設定方式請參閱[圖片生成](/zh-hant/ai/image-generation)與[影片生成](/zh-hant/ai/video-generation)。

## 開啟媒體

在聊天視窗側邊欄中點擊 **媒體**。在頂部選擇 **圖片**、**影片** 或 **音訊**。

- **全部**、**我的最愛** 與你的資料夾會為你整理作品。點擊 **新增資料夾** 可建立資料夾，在項目上使用 **移至資料夾** 可將它歸類。
- 在 **搜尋你的媒體** 中輸入提示詞裡的字詞，即可尋找對應項目。
- 點擊星號即可將項目加入 **我的最愛**。

這些檔案同時也會儲存在你的 Mac 上的 `~/Enconvo/Media`。

你也可以在新聊天的訊息框下方選擇 **圖片** 或 **影片**。模型、設定與要避開的內容會以膠囊按鈕顯示在訊息框下方，再下方則是你最近製作的圖片或影片與一個 **開啟媒體** 連結。

## 製作圖片或影片

1. 在 **圖片** 或 **影片** 頁面底部的創作框中描述你想要的內容。
2. 檢查下方的膠囊選項：模型、**長寬比**、**畫質**、圖片數量與 **避開**（要排除的內容）。點擊膠囊即可修改，或點擊 **更多設定** 查看其餘選項。系統只會顯示所選模型支援的設定。
3. 點擊 **生成**。完成後新項目會顯示在頂部。

一次生成多個版本時，挑選你想保留的項目即可。

### 更多影片控制選項

- **起始影格** 與 **結束影格**：加入片段開頭或結尾使用的圖片。
- **加入鏡頭**：將影片拆分為多個鏡頭，每個鏡頭各自設定提示詞與長度。Enconvo 會將它們合併成一段影片。
- **加入音訊檔案**：使用你自己的音訊，或從 **音訊** 中選取一段片段。

## 保持主體或風格一致

將同一個人、寵物、產品或角色的幾張照片儲存為主體，或將幾張符合目標外觀的圖片儲存為風格。生成時選擇它，就能在每張圖片與每段影片中維持一致的樣貌。

1. 在創作框中，點擊 **加入主體、風格或參考圖**。
2. 在 **主體** 下方選擇 **從照片新增**，或在 **樣式** 下方選擇 **新增風格**。
3. 輸入 **名稱**、加入 **照片**，並可選填 **描述**。
4. 點擊 **儲存**。下次生成時，從同一個選單中選取它即可。

## 精修你的作品

點擊項目即可開啟詳細資料：包含提示詞以及它所採用的每項設定。從這裡你可以進行以下操作：

| 操作 | 作用 |
| --- | --- |
| **重複使用設定** | 將相同的提示詞與設定填入創作框 |
| **變成影片** | 以這張圖片作為起點製作影片 |
| **放大** | 製作更大、更清晰的副本 |
| **移除背景** | 擷取出畫面主體 |
| **重新打光** | 改變光線與氛圍 |
| **修改局部** | 開啟編輯器，塗抹要修改的區域 |
| **更多修復** | **修復舊照片**、**變更角度**、**擴展畫布** 與 **變體** |
| **再產生幾個類似的** | 以相同的配置重新製作新版本 |

每次修復都會建立一個新版本；原檔會保留在 **版本** 下方。點擊 **在編輯器中開啟** 即可在圖片或影片編輯器中繼續編輯。

## 製作音訊

1. 開啟 **音訊** 並選擇 **音樂**、**音效** 或 **語音**。
2. 描述想要的風格或聲音，或輸入旁白的文字。音樂可以有歌詞，也可以選擇 **純音樂**。
3. 點擊 **生成**。若要使用現有檔案，點擊 **匯入音訊檔案**。

若要為影片加上音訊，開啟該影片並點擊 **加入音訊**。從 **你的音訊** 中挑選片段或點擊 **匯入檔案**，選擇 **與原聲混合** 或 **取代原聲**，然後點擊 **加入影片**。

<Warning>
每張圖片、每段影片與每個音訊片段都會消耗服務供應商的額度或你的 Enconvo Cloud 點數。影片消耗的點數最多，建議先試著生成較短的片段。
</Warning>

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 圖片作為主體或影格時遭到拒絕 | 請使用 PNG、JPEG 或 WebP 格式的圖片 |
| 找不到你想要的設定 | 所選模型不接受該設定；請改選其他模型 |
| 某個項目顯示 **再試一次** | 生成失敗；請檢查服務供應商的存取權限，然後再試一次 |
| **音訊** 中沒有語音或模型 | 請先設定能製作該類型音訊的服務供應商；Enconvo Cloud 僅製作語音，音樂與音效需要你自己的 ElevenLabs 金鑰 |

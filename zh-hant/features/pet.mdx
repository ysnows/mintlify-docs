桌面寵物是桌面上的一個小型動畫角色。它會反映你的代理程式正在做什麼、可以顯示即時的工作階段卡片，並帶你前往需要注意的工作階段。點按它即可提問或開啟 Enconvo。它與[虛擬形象](/zh-hant/features/avatar)是分開的，虛擬形象是為代理程式提供對話用的角色與聲音。

其他情況請使用：[SmartBar](/zh-hant/features/smartbar) 處理快速提問或指令、[聊天視窗](/zh-hant/ai/chat)處理長時間對話與檔案、[App 側邊欄](/zh-hant/features/app-sidebar)在某個 App 旁工作、[PopBar](/zh-hant/features/popbar) 處理選取的文字，或是[動態島](/zh-hant/features/dynamic-island)在螢幕頂端提供精簡的輸入框。[視窗管理](/zh-hant/features/window-management)會將它們全部做比較。

## 選擇寵物

1. 開啟**設定 → 寵物**。
2. 在**我的寵物**中選擇一個角色，或在**圖庫**中尋找。
3. 按一下**喚醒寵物**，讓它顯示在你的桌面上。
4. 將**點一下時開啟**設為點按寵物時要叫出的內容。
5. 開啟或關閉**顯示對話卡片**，並調整**寵物大小**。
6. 回到桌面並點按寵物。第 4 步所選的內容就會開啟。

## 設定

| 設定 | 變更的內容 |
| --- | --- |
| **喚醒寵物** / **收起寵物** | 在桌面上顯示或隱藏寵物。 |
| **點一下時開啟** | 點按寵物時叫出的內容：**提問框**（預設）、**動態島**、**聊天視窗**或 **Smart Bar**。 |
| **回答所用代理程式** | 回答你向寵物提問的代理程式。你也可以在提問框中變更它。 |
| **工作階段卡片** | 寵物下方的即時工作階段狀態卡片。 |
| **寵物大小** | 寵物的大小。 |

## 自訂寵物

**我的寵物**分頁上的**自訂寵物**會顯示存放你寵物套件的資料夾。按一下**開啟資料夾**，加入支援格式的寵物套件，然後在**我的寵物**中選取該寵物。單獨的角色圖片不是動畫寵物套件。

若要移除寵物，請按一下它卡片上的**移除**。這會從你的資料庫刪除該套件；你可以從圖庫重新安裝它。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 桌面上沒有寵物 | 按一下**喚醒寵物**，確認已在**我的寵物**中選取寵物，並檢查**寵物大小**。 |
| 點按寵物開啟了錯誤的視窗 | 變更**點一下時開啟**。 |
| 你想要語音對話，或為單一代理程式設定角色 | 請改用[虛擬形象](/zh-hant/features/avatar)。 |

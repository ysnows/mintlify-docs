桌面寵物是桌面上的小型動畫角色。它會即時反映代理程式正在執行的工作、可顯示即時工作階段卡片，並帶你前往需要處理的對話。點擊它就能提問或開啟 Enconvo。它與[虛擬形象](/zh-hant/features/avatar)不同，後者是為代理程式提供用於對話的角色形象與聲音。

針對其他需求，快速提問或執行指令可使用 [SmartBar](/zh-hant/features/smartbar)、長對話與處理檔案可使用[聊天視窗](/zh-hant/ai/chat)、搭配單一 App 作業可使用 [App 側邊欄](/zh-hant/features/app-sidebar)、處理選取的文字可使用 [PopBar](/zh-hant/features/popbar)，或在螢幕頂端保留精巧的輸入框則可使用[動態島](/zh-hant/features/dynamic-island)。[視窗管理](/zh-hant/features/window-management)比較了所有方式。

## 選擇寵物

1. 開啟 **設定 → 寵物**。
2. 在 **我的寵物** 中挑選一個角色，或在 **圖庫** 中尋找新角色。
3. 點擊 **喚醒寵物**，讓它出現在桌面上。
4. 設定 **點一下時開啟**，決定點擊寵物時要開啟的介面。
5. 開啟或關閉 **顯示對話卡片**，並調整 **寵物大小**。
6. 回到桌面並點擊寵物，就會開啟你在第 4 步中選擇的項目。

## 設定

| 設定 | 作用 |
| --- | --- |
| **喚醒寵物** / **收起寵物** | 在桌面上顯示或隱藏寵物。 |
| **點一下時開啟** | 點擊寵物時要開啟的介面：**提問框**（預設）、**動態島**、**聊天視窗** 或 **Smart Bar**。 |
| **回答所用代理程式** | 負責回答你向寵物提問的代理程式。你也可以在提問框中切換。 |
| **工作階段卡片** | 顯示在寵物下方的即時工作階段狀態卡片。 |
| **寵物大小** | 寵物顯示的尺寸大小。 |

## 自訂寵物

**我的寵物** 分頁上的 **自訂寵物** 會顯示存放寵物套件的資料夾。點擊 **開啟資料夾**、放入支援格式的寵物套件，然後在 **我的寵物** 中選取該寵物。單純的一張角色圖片並不是動畫寵物套件。

若要移除寵物，請點擊該寵物卡片上的 **移除**。這會將該套件從你的收藏庫中刪除；日後仍可從「圖庫」重新安裝。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 桌面上沒有出現寵物 | 點擊 **喚醒寵物**，確認 **我的寵物** 中已選取寵物，並檢查 **寵物大小**。 |
| 點擊寵物開啟了錯誤的視窗 | 更改 **點一下時開啟** 的設定。 |
| 你想要語音對話，或為單一代理程式配置角色 | 請改用[虛擬形象](/zh-hant/features/avatar)。 |

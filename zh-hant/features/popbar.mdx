PopBar 是一個小型工具列，在任意 App 中選取文字時出現在旁邊。它的按鈕可以對選取的內容進行解釋、翻譯、編輯、搜尋、複製或朗讀，[PopBar 擴充功能](#popbar-擴充功能)還能新增更多功能，例如網頁搜尋、文字轉換，或把選取內容傳送到另一個 App。當你要處理的文字已經在螢幕上時，就用它。

其他工作情境：快速提問或執行指令用 [SmartBar](/zh-hant/features/smartbar)，長對話和處理檔案用[聊天視窗](/zh-hant/ai/chat)，在某個 App 旁工作用 [App 側邊欄](/zh-hant/features/app-sidebar)，想要常駐螢幕的小入口則用[動態島](/zh-hant/features/dynamic-island)和[桌面寵物](/zh-hant/features/pet)。[視窗管理](/zh-hant/features/window-management)對它們做了全面比較。

下方的影片教學會在 6 分鐘內完整示範 PopBar 的設定與使用：開啟它、選擇何時顯示、執行 Fix Spelling、Translate 和 Ask AI、使用行內模式、新增和排列按鈕、製作自己的 AI 指令，以及取得或建置 PopBar 擴充功能。

## 使用 PopBar

1. 開啟 **設定 → PopBar**，開啟 **啟用 PopBar**。
2. 在某個 App 中選取一小段文字。
3. 點擊工具列上的一個按鈕。
4. 在使用複製、貼上或取代操作之前，先檢查結果。

你也可以用快速鍵開啟 PopBar：執行 **顯示 PopBar**，或在 **何時顯示** 分頁上設定一個 **快速鍵**。按 Escape 關閉工具列。

PopBar 透過輔助使用權限讀取選取的內容，能讀到什麼取決於具體 App。安全輸入欄位和部分自訂編輯器不會公開其中的文字。

## 透過語音提問

開啟「詢問」面板、欄位顯示 **Ask about the selected text…** 時，你可以直接說出問題，而不必打字。

1. 點擊欄位裡的麥克風按鈕，或按下你的[語音指令](/zh-hant/features/dictation)快速鍵。欄位會顯示 **Listening…** 並即時出現你說的話。
2. 說完後再次點擊該按鈕，或放開按住的快速鍵，問題就會送出。

按 Escape 可停止聆聽而不送出。說話前輸入的內容會保留在語音轉寫的文字前面。

## 選擇按鈕

PopBar 設定的 **按鈕** 分頁把工具列的按鈕顯示成一排。拖曳按鈕可調整順序，將游標移到按鈕上並點擊 **×** 可將其移除，點擊按鈕可檢視更多選項。**恢復預設** 可恢復預設按鈕。

工具列上放不下的按鈕會收在末尾的 **⌄** 中。點擊 **⌄** 開啟 **更多** 面板：它列出這些按鈕，並提供一個可搜尋所有按鈕和設定的搜尋欄位。更改過按鈕後，這裡的 **Turn Off PopBar** 下方也會出現 **恢復預設**，它會恢復預設按鈕及其順序，並提供 **復原**。

點擊 **新增按鈕** 開啟按鈕庫。其中有 Ask AI、Ask in Sidebar、Open Link、Search、Copy、Translate、Explain、Fix Spelling、AI Edit、Read Aloud 等，還有你的 [PopBar 擴充功能](#popbar-擴充功能)提供的操作，以及建立自己的 [AI 指令](/zh-hant/features/ai-commands)的入口。你也可以加入一個[寫作工具](/zh-hant/features/writing-tools)指令，用於你自己的編輯工作流程。工具列會顯示你加入的按鈕。

## 控制出現的位置

**何時顯示** 分頁決定 PopBar 何時出現：

| 設定 | 作用 |
| --- | --- |
| **哪些文字** | 對你選取的任何文字都顯示 PopBar，或只對它能幫上忙的文字顯示，例如外語、程式碼或電子郵件。 |
| **位置** | 用 **除以下位置外的所有地方**，再點 **加入 App** 或 **加入網站**，讓它不在某些 App 或網站中出現。或者選擇 **僅在以下位置**，讓它只在你列出的地方顯示。 |
| **選取文字時顯示** | 關閉後，PopBar 只在你主動呼叫時顯示，然後點擊 **加入快速鍵** 選擇一個快速鍵。 |

在自動彈出工具列會造成干擾的 App 中（例如終端機），將它排除在外。

## 更改外觀

在 **查看** 分頁上，**版面配置** 可以把按鈕排成一列放在選取內容上方（**橫排**），或排成一欄放在游標旁邊（**直排**）。如果工具列擋住了你正在讀的內容，可以用 **微調位置** 下的 **X 偏移** 和 **Y 偏移** 移動它。

## 行內模式

有些按鈕可以不彈出結果視窗直接運作。右鍵點擊 PopBar 上的 **Fix Spelling**，開啟 **行內模式**。下次選取文字並點擊 **Fix Spelling** 時，修正結果會直接寫進你的文字裡。

## 更改結果所用的模型或設定

對於帶有 AI 模型設定的指令，結果工具列會提供模型選擇器，顯示為模型服務供應商的圖示。在這裡更改模型，也會更新該指令以後執行時的預設模型。結果視窗的設定按鈕會開啟產生該結果的指令，例如 **外掛程式 → 寫作工具 → Explain**。

## PopBar 擴充功能

PopBar 擴充功能是小型附加元件，它們的操作會成為 PopBar 上的按鈕。它們採用 [PopClip](https://www.popclip.app) 的擴充功能格式，因此為 PopClip 撰寫的擴充功能也能安裝在 Enconvo 中。PopBar 擴充功能需要 Mac 版 Enconvo。

<Note>
Enconvo 與 PopClip 的開發商 Pilotmoon Software 沒有關聯。
</Note>

### 從 Enconvo 目錄安裝

1. 開啟 **外掛程式**，選擇 **PopBar 擴充功能** 分頁。
2. 依分類瀏覽目錄，或在搜尋欄位中輸入關鍵字尋找。
3. 點擊擴充功能旁的 **+**，然後點擊 **安裝**。
4. 接下來的卡片列出了該擴充功能的按鈕、每個按鈕何時顯示以及放在哪裡。為每個按鈕選擇 **On Bar**、**In ⌄ More** 或 **關閉**，然後點擊 **完成**。**設定…** 會開啟該擴充功能的選項。

新按鈕會放在 PopBar **⌄ 更多** 面板的最前面；如果工具列還有空間，則放在工具列上。在你開啟面板之前，**⌄** 上會顯示一個小圓點，面板裡的新按鈕會標有 **NEW**。

Enconvo 會在列於目錄前審核每個擴充功能，並且只安裝它審核過的版本。已安裝的擴充功能列在分頁頂端。當 Enconvo 審核了某個擴充功能的新版本時，它在目錄中的那一列會顯示 **更新**。在按鈕庫中，**取得更多…** 會開啟同一個分頁。

你也可以在網頁上瀏覽目錄：[app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions)。在 Mac 上，點擊擴充功能的 **安裝** 按鈕會開啟 Enconvo，它會在安裝任何內容之前先展示該擴充功能能做什麼。

### 從其他來源加入擴充功能

在 **PopBar 擴充功能** 分頁上，或在外掛程式頁面的 **加入** 選單中，點擊 **加入 PopBar 擴充功能…**。然後執行以下任一操作：

- 貼上一個 `.popclipextz` 安裝套件的連結。
- 貼上一段片段（snippet），即以 `#popclip` 開頭的擴充功能簡短文字形式。
- 點擊 **選擇檔案…**，在 Mac 上選擇一個 `.popclipextz` 安裝套件或 `.popclipext` 資料夾。

點擊 **預覽**。Enconvo 會在不執行擴充功能的前提下讀取它，並列出它在 PopBar 之外還能做的事，例如執行指令碼、連線網際網路、開啟 App 或模擬按鍵。在你點擊 **允許並安裝** 之前不會安裝任何內容，安裝完成後會出現與從目錄安裝時相同的按鈕卡片。Enconvo 不審核目錄之外的擴充功能，因此請只從你信任的來源安裝。

當你在任意 App 中選取一段擴充功能片段時，PopBar 會先顯示一個 **安裝擴充功能** 按鈕。點擊它會開啟同樣的預覽。

### 從 PopClip 匯入

如果你有使用 PopClip，可以在 **PopBar 擴充功能** 分頁上點擊 **從 PopClip 匯入…**。Enconvo 會依 PopClip 中的順序複製你的 PopClip 擴充功能及其設定，並把它們的操作加入 PopBar。PopClip 本身不會被更改。

- 在 PopClip 中已關閉的擴充功能會被安裝，但不會加入 PopBar。
- API 金鑰和密碼不會被複製。Enconvo 會列出需要它們的擴充功能，請在各擴充功能的設定中重新輸入。
- 與 Enconvo 目錄中某個版本相符的擴充功能視為已審核，並從目錄更新。

### 設定、更新與移除

在 **PopBar 擴充功能** 分頁中開啟一個擴充功能，檢視它的頁面。其中的 **PopBar 按鈕** 區塊列出了每個按鈕及其顯示時機，你可以把它放在工具列上、放進 **⌄ 更多**，或從 PopBar 上關閉。**在 PopBar 設定中排列所有按鈕** 會開啟按鈕分頁。

有選項的擴充功能會在頁面頂端顯示 **設定**，並在按鈕庫中的卡片上顯示 **設定…**。

從連結安裝的擴充功能會從同一連結更新。當更新後的版本能做的事超出你之前允許的範圍時，Enconvo 只展示新增的部分，並在更新前再次徵求你的同意。

要移除某個擴充功能，在 **PopBar 擴充功能** 分頁中開啟它並解除安裝。它的按鈕會從 PopBar 上移除。

### 尚未支援的內容

- 需要登入帳號的擴充功能。
- 每次工具列出現時動態產生操作的擴充功能。

如果某個擴充功能用到了其中一項，Enconvo 會在預覽時告訴你。

### 推薦擴充功能

Enconvo 的目錄託管於 [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions)。在那裡提交 issue 或 pull request，即可推薦擴充功能供審核。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 工具列沒有出現 | 檢查 **啟用 PopBar**、輔助使用權限，以及 **位置** 下的 App 和網站。 |
| 它處理了錯誤的文字 | 重新選取文字，再次開啟 PopBar。 |
| 缺少某個指令 | 檢查 **按鈕** 分頁，並確認該指令所屬的外掛程式已安裝。 |
| 結果沒有取代你的文字 | 該 App 可能不允許取代。複製結果，再貼到可編輯的欄位中。 |
| 擴充功能按鈕沒有出現 | 點擊 PopBar 末尾的 **⌄**，新按鈕會放在那裡；或在外掛程式中檢視該擴充功能的頁面：設為 **關閉** 的按鈕不會出現在 PopBar 上。有些按鈕只對它們能處理的文字顯示：例如 **Base64 Decode** 只在文字看起來像 Base64 時顯示，所以選取普通文字時只會顯示 **Base64 Encode**。 |
| 擴充功能按鈕取代了選取的文字 | 許多擴充功能會把結果貼到選取內容上，就像在 PopClip 中一樣。在文字無法編輯的地方，結果會改為複製到剪貼簿。 |
| 目錄無法載入 | 檢查網路連線，然後在 **PopBar 擴充功能** 分頁上點擊 **再試一次**。 |

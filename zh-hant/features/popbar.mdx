PopBar 是一個小型工具列，會出現在你於任何 App 中選取的文字旁邊。它的按鈕可以解釋、翻譯、編輯、搜尋、複製，或朗讀選取的內容，而 [PopBar 擴充功能](#popbar-擴充功能)還能新增更多，例如網頁搜尋、文字轉換器，或將選取的內容傳送到另一個 App。當你想處理的文字已經在螢幕上時，就用它。

其他情況請使用：[SmartBar](/zh-hant/features/smartbar) 處理快速提問或指令、[聊天視窗](/zh-hant/ai/chat)處理長時間對話與檔案、[App 側邊欄](/zh-hant/features/app-sidebar)在某個 App 旁工作，或是[動態島](/zh-hant/features/dynamic-island)與[桌面寵物](/zh-hant/features/pet)這類常駐螢幕的小型入口。[視窗管理](/zh-hant/features/window-management)會將它們全部做比較。

## 使用 PopBar

1. 開啟**設定 → PopBar**，並開啟**啟用 PopBar**。
2. 在 App 中選取一小段文字。
3. 按一下工具列上的按鈕。
4. 在使用結果的複製、貼上或取代動作之前，請先檢查結果。

你也可以用快速鍵開啟 PopBar：執行**顯示 PopBar**，或在**何時顯示**分頁中設定**快速鍵**。按 Escape 可關閉工具列。

PopBar 透過輔助使用權限讀取選取的內容，能取得什麼取決於 App。安全欄位與部分自訂編輯器不會提供它們的文字。

## 用語音提問

當詢問面板開啟、欄位中顯示**就選取的文字提問…**時，你可以用說的取代輸入問題。

1. 按一下欄位中的麥克風按鈕，或按下你的[語音指令](/zh-hant/features/dictation)快速鍵。欄位會顯示**正在聆聽…**，以及你說話時的文字。
2. 說完後，再按一次按鈕，或放開按住的快速鍵。你的問題就會送出。

按 Escape 可停止聆聽而不送出。你在說話前輸入的任何內容，都會保留在口述文字的前面。

## 選擇按鈕

PopBar 設定的**按鈕**分頁會以一條橫列顯示工具列的按鈕。拖曳按鈕可重新排序，指向它並按一下 **×** 可移除，或按一下它查看更多選項。**恢復預設**會還原預設的按鈕。

放不進工具列的按鈕會收在工具列末端的 **⌄** 之下。按一下 **⌄** 開啟**更多**面板：它會列出那些按鈕，並附有可搜尋每個按鈕與設定的搜尋欄位。在你變更過按鈕之後，**恢復預設**也會出現在那裡的**關閉 PopBar**下方，並可還原預設的按鈕與順序，同時提供**還原**。

按一下**新增按鈕**開啟按鈕圖庫。裡面有詢問 AI、在側邊欄中詢問、開啟連結、搜尋、複製、翻譯、解釋、修正拼字、AI 編輯、朗讀等，以及你的 [PopBar 擴充功能](#popbar-擴充功能)的動作，還有製作你自己的 [AI 指令](/zh-hant/features/ai-commands)的方式。你也可以為你自己的編輯流程加入[寫作工具](/zh-hant/features/writing-tools)指令。工具列會顯示你加入的按鈕。

## 控制出現的位置

**何時顯示**分頁設定 PopBar 何時出現：

| 設定 | 作用 |
| --- | --- |
| **哪些文字** | 對你選取的任何文字顯示 PopBar，或僅對它能提供協助的文字顯示，例如外語、程式碼或電子郵件。 |
| **位置** | 用**除以下位置外的所有地方**讓它避開某些 App 或網站，然後按**新增 App**或**新增網站**。或選擇**僅在以下位置**，讓它只在你列出的地方顯示。 |
| **選取文字時顯示** | 關閉後，PopBar 只會在你要求時才顯示，接著按一下**新增快速鍵**並選擇快捷鍵。 |

請排除自動出現的工具列會造成妨礙的 App，例如「終端機」。

## 變更外觀

在**外觀**分頁中，**版面配置**可將按鈕放在選取內容上方的一列（**橫排**），或放在游標旁的一欄（**直排**）。如果工具列遮住了你正在閱讀的內容，請在**微調位置**下用 **X 偏移**與 **Y 偏移**移動它。

## 行內模式

有些按鈕不需要結果視窗就能運作。在 PopBar 上對**修正拼字**按右鍵，並開啟**行內模式**。下次你選取文字並按一下**修正拼字**時，修正結果會直接出現在你的文字中。

## 變更結果的模型或設定

對於有 AI 模型設定的指令，結果工具列會提供模型選擇器，以模型服務供應商的圖示顯示。變更它也會更新該指令之後執行時的預設值。結果視窗的設定按鈕會開啟產生該結果的指令，例如**外掛程式 → 寫作工具 → 解釋**。

## PopBar 擴充功能

PopBar 擴充功能是小型附加元件，它們的動作會變成 PopBar 按鈕。它們使用 [PopClip](https://www.popclip.app) 的擴充功能格式，因此為 PopClip 撰寫的擴充功能也能安裝到 Enconvo。PopBar 擴充功能需要 Enconvo for Mac。

<Note>
Enconvo 與 PopClip 的開發商 Pilotmoon Software 沒有任何關係。
</Note>

### 從 Enconvo 的目錄安裝

1. 開啟**外掛程式**，並選擇 **PopBar 擴充功能**分頁。
2. 依類別瀏覽目錄，或在搜尋欄位中輸入以尋找擴充功能。
3. 按一下擴充功能旁的 **+**，再按**安裝**。
4. 接著出現的卡片會列出該擴充功能的按鈕、每個按鈕何時顯示，以及它的位置。為每一個選擇**在工具列上**、**在 ⌄ 更多中**或**關閉**，然後按一下**完成**。**設定…**會開啟該擴充功能的選項。

新按鈕會排在 PopBar 的 **⌄ 更多**面板最前面，或在工具列還有空間時直接放到工具列上。在你開啟面板之前，**⌄** 會顯示一個圓點，面板中的新按鈕會標示為**新**。

Enconvo 會在列入目錄前審查目錄中的每個擴充功能，並安裝它所審查的那個版本。已安裝的擴充功能會列在分頁頂端。當 Enconvo 審查過其中某個擴充功能的較新版本時，它在目錄中的那一列會顯示**更新**。在按鈕圖庫中，**取得更多…**會開啟相同的分頁。

你也可以在網頁上瀏覽目錄：[app.enconvo.com/popbar-extensions](https://app.enconvo.com/popbar-extensions)。在你的 Mac 上，擴充功能的**安裝**按鈕會開啟 Enconvo，並在安裝任何東西之前顯示該擴充功能能做什麼。

### 從其他地方加入擴充功能

在 **PopBar 擴充功能**分頁，或外掛程式頁面的**新增**選單中，按一下**加入 PopBar 擴充功能…**。然後擇一操作：

- 貼上 `.popclipextz` 套件的連結。
- 貼上片段，也就是以 `#popclip` 開頭、擴充功能的簡短文字形式。
- 按一下**選擇檔案…**，在你的 Mac 上選取 `.popclipextz` 套件或 `.popclipext` 資料夾。

按一下**預覽**。Enconvo 會在不執行擴充功能的情況下讀取它，並列出它除了 PopBar 之外還能做什麼，例如執行指令碼、連上網際網路、開啟 App 或按下按鍵。在你按一下**允許並安裝**之前，不會安裝任何東西，之後會停在與從目錄安裝相同的按鈕卡片。Enconvo 不會審查目錄以外的擴充功能，因此請只從你信任的來源安裝。

當你在任何 App 中選取片段時，PopBar 會先顯示**安裝擴充功能**按鈕。按一下它會開啟相同的預覽。

### 從 PopClip 匯入

如果你使用 PopClip，請在 **PopBar 擴充功能**分頁按一下**從 PopClip 匯入…**。Enconvo 會依 PopClip 的順序複製你的 PopClip 擴充功能與其設定，並將它們的動作加入 PopBar。PopClip 本身不會被更動。

- 在 PopClip 中已關閉的擴充功能會被安裝，但不會加入 PopBar。
- API 金鑰與密碼不會被複製。Enconvo 會列出需要它們的擴充功能，請在各擴充功能的設定中重新輸入。
- 與 Enconvo 目錄中某個版本相符的擴充功能視為已審查，並會從目錄更新。

### 設定、更新與移除

從 **PopBar 擴充功能**分頁開啟擴充功能即可查看它的頁面。它的 **PopBar 按鈕**區段會列出每個按鈕及其顯示時機，並讓你將它放在工具列上、**⌄ 更多**中，或從 PopBar 移除。**在 PopBar 設定中排列所有按鈕**會開啟按鈕分頁。

有選項的擴充功能，會在其頁面頂端顯示**設定**，並在按鈕圖庫的卡片上顯示**設定…**。

從連結安裝的擴充功能會從同一個連結更新。當更新能做的事比你允許的版本更多時，Enconvo 只會顯示新增的部分，並在更新前再次詢問。

若要移除擴充功能，請從 **PopBar 擴充功能**分頁開啟它並解除安裝。它的按鈕會從 PopBar 消失。

### 目前尚未支援的項目

- 需要登入帳號的擴充功能。
- 每次工具列出現時才建立動作的擴充功能。

當擴充功能使用其中一項時，Enconvo 會在預覽期間告訴你。

### 推薦擴充功能

Enconvo 的目錄位於 [github.com/Enconvo/popbar-extensions](https://github.com/Enconvo/popbar-extensions)。請在那裡開啟 issue 或 pull request，推薦要審查的擴充功能。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 沒有出現工具列 | 檢查**啟用 PopBar**、輔助使用權限，以及**位置**下的 App 與網站。 |
| 它對錯誤的文字動作 | 重新選取一次，再開啟 PopBar。 |
| 缺少某個指令 | 檢查**按鈕**分頁，並確認該指令的外掛程式已安裝。 |
| 結果沒有取代你的文字 | App 可能不允許這麼做。請複製結果並貼到可編輯的欄位。 |
| 沒有出現擴充功能的按鈕 | 按一下 PopBar 末端的 **⌄**（新按鈕會放在那裡），或檢查外掛程式中該擴充功能的頁面：標示為**關閉**的按鈕不在 PopBar 上。有些按鈕只會對它們能處理的文字顯示：例如 **Base64 Decode** 只會對看起來像 Base64 的文字顯示，所以選取純文字時只會顯示 **Base64 Encode**。 |
| 擴充功能的按鈕取代了選取的文字 | 許多擴充功能會把結果貼到選取內容上，就像它們在 PopClip 中一樣。在文字無法編輯的地方，則會改為複製結果。 |
| 目錄無法載入 | 檢查你的連線，然後在 **PopBar 擴充功能**分頁按一下**再試一次**。 |

作品是代理程式為你製作、供你保存的內容：文件、投影片、設計畫布、儀表板、動作、網頁、圖表或程式碼。它會在聊天旁的面板中開啟，保留每個版本，並在聊天結束後仍留在**作品**資料庫中。當你之後會回頭查看、編輯、簡報或分享成果時，就適合使用作品。

你所生成的圖片、影片與音訊則放在[媒體](/zh-hant/features/media)中。

## 從新聊天開始建立作品

新聊天的訊息輸入框下方會顯示**做點什麼**這一列，其中每一種類型都有一個標籤：**投影片**、**文件**、**設計**、**動作**、**儀表板**、**網頁**、**圖片**與**影片**。每個標籤都附有簡短說明，讓你分辨**動作**（以程式碼製作動畫）與**影片**（AI 影像）。

1. 點按某個標籤。此時還不會送出任何內容：訊息輸入框會切換為該類型。
2. 選擇開始的方式：
   - 點按三個範例之一，將它填入訊息輸入框。
   - 點按**空白投影片**、**空白文件**、**空白設計**等，在聊天旁開啟一個空白的作品。
   - 點按**開啟 .pptx**、**開啟 .docx**或**開啟試算表**，從檔案開始。
   - 點按**你的投影片**、**你的文件**等，開啟你已有的作品。
3. 描述你想要的內容並送出。

作品會在聊天旁開啟，並隨著代理程式的工作逐步填入內容。你也可以直接在任何聊天中提出要求：要求製作預告片、說明影片或操作導覽影片，會產生[動作](/zh-hant/features/motion)；要求追蹤數據，則會產生[儀表板](/zh-hant/features/dashboards)。

**圖片**與**影片**則會顯示你最近的圖片或片段，以及一個**開啟媒體**連結。請參閱[媒體](/zh-hant/features/media)。

## 尋找你的作品

點按聊天視窗側邊欄中的**作品**。資料庫會以縮圖網格開啟，最近變更的排在最前面。

- 在頂端切換**格狀檢視**與**列表檢視**。
- 依類型篩選：**全部**、**頁面**、**設計**、**儀表板**、**投影片**、**動作**、**文件**、**圖表**或**程式碼**。
- 在**搜尋作品**中輸入，即可依標題找到作品，不分字母種類與大小寫。
- 點按**新增**即可建立任何類型的空白作品。
- 點按**匯入**即可將文件匯入為文件，或匯入設計或儀表板的壓縮專案資料夾。

在項目上按一下滑鼠右鍵，或點按它的 **⋯**，即可**開啟**、**重新命名…**、**複製連結**、**打開建立它的對話**、**選取**多個項目，或**刪除**。若要一次挑選多個，請按住 ⌘ 或 ⇧ 點按，然後一起刪除。刪除會移除每個版本以及作品儲存的所有內容；建立它的聊天則會保留。點按隨後出現的通知中的**還原**即可將它找回。

你從未寫入任何內容的空白作品不會被保留：關閉時會被捨棄。

## 回到較早的版本

代理程式所做的每項變更，以及你儲存的每次編輯，都會成為新的版本。

1. 點按作品標題列中的版本編號（例如 **v4**）。
2. 在**版本**下，挑選你想要的版本。
3. 點按**還原**，或點按**回到目前版本**以維持現狀。還原會儲存為新的版本，因此不會遺失任何內容。

你也可以在聊天中提出要求：「把簡報恢復成更換顏色之前的樣子。」代理程式會還原設計、簡報或儀表板的該版本，並保留其餘部分。

當你要求變更時，代理程式只會編輯你指明的部分，例如某一張投影片、某一個圖表或某一個畫板，其餘部分則維持原狀。

## 分享作品

文件、設計、簡報、儀表板與動作都可以與他人或你的團隊分享。你需要登入 Enconvo 帳號。

1. 開啟作品並點按**分享**。
2. 在**透過電子郵件加入成員**下輸入電子郵件，選擇**可檢視**、**可留言**或**可編輯**，然後點按**分享**。
3. 若要與你的團隊分享，請設定**團隊存取**。若要讓任何登入 Enconvo 的人都能開啟，請將**一般存取權**設為**任何擁有連結的人**，然後點按**複製連結**。
4. 點按**完成**。

分享會將作品移到 Enconvo Cloud，因此你加入的成員可在自己的 Mac 上開啟它，並看到每個新版本。以 `@Enconvo` 開頭的留言會得到 Enconvo 的回覆。

## 將網頁發布為網站

網頁作品可以在 Enconvo Cloud 上以專屬網址 `name.site.enconvo.com` 上線。發布功能已包含在你的 Enconvo 帳號中。

1. 開啟該網頁並點按其標題列中的**發佈**。
2. 在**網站名稱**下，輸入網址所用的名稱：3 到 40 個小寫字母、數字或連字號。
3. 在**誰可以檢視**下，選擇**任何擁有連結的人**，或選擇**密碼**並輸入至少 4 個字元的密碼。
4. 點按**發佈**。當畫面顯示**你的網站已上線**時，點按**開啟**即可查看。

此後按鈕會顯示為**已發布**。當你變更網頁時，它會顯示為**更新**：點按它，再點按**更新**，即可讓最新版本上線。在同一個面板中，你可以**複製連結**、**還原**較早發布的版本，或**取消發布**以讓網站下線，這會使連結對所有人失效。

你也可以請代理程式將網頁分享到網路上，它會為你發布該網頁或網站的資料夾。

## 在手機上開啟作品

簡報、儀表板與動作也可以在 iPhone 與 Android App 中開啟。從聊天或**作品**資料庫開啟後，即可留言、詢問 `@Enconvo`、分享、匯出或簡報。

## 將文件作為技能使用

文件可以作為你的代理程式所遵循的技能。開啟文件並選擇**作為技能使用…**。如果該文件屬於他人，只有你能將它開啟，且 Enconvo 會註明其擁有者仍可變更你的代理程式所遵循的內容。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 資料庫中沒有圖片或影片 | 圖片、影片與音訊放在[媒體](/zh-hant/features/media)中 |
| **分享**要求你登入 | 在你的 Mac 上登入 Enconvo，然後再次分享 |
| 已分享的文件無法再開啟 | 其擁有者已移除你的存取權限，或你已將它從資料庫中移除 |
| 代理程式改寫的範圍超出你的要求 | 指明要變更的部分，或還原到它之前的版本 |
| 已發布的網頁顯示舊版本 | 點按網頁標題列中的**更新**，再點按**更新** |

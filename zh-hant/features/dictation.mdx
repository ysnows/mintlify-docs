## 開始之前

Enconvo 需要麥克風權限才能聽見你的聲音。若要在其他 App 中輸入文字，也可能需要輔助使用權限。請參閱[權限](/zh-hant/configuration/permissions)。

## 在 App 中聽寫輸入

1. 在任何 App 中點一下要輸入文字的欄位。
2. 按住右側的 **Command** 鍵並說話。畫面上會出現一個小膠囊，顯示聽寫正在聆聽。
3. 說完後放開按鍵，文字就會輸入到游標位置。
4. 檢查插入的文字，特別是人名、日期與數字。

預設方式是按住右側 Command 鍵說話。如果你想改為按一下就開始、不限時間地說話，請開啟 **設定 → 聽寫 → 聽寫快速鍵** 並調整按鍵方式。調整後，只要再按一次快速鍵或點選膠囊上的勾選圖示即可結束。

除了中文、日文與泰文之外，聽寫會在單字前後自動加上應有的空格。只要單獨唸出你設定的某個文字片段名稱或關鍵字，就會直接插入該片段的內容，而非原話。

### 使用聽寫卡片

聽寫時將游標移到小膠囊上，它就會展開成一張卡片，上方顯示你的文字，下方提供各種控制項。在卡片上你可以切換麥克風、將聽寫轉為 **草擬**、選擇 **清理** 選項，以及在不中斷的情況下開啟或關閉 **按 Return 插入並傳送** 與 **即時轉寫**。停止聽寫後，卡片會顯示清理處理的進度。

若想讓膠囊保持精簡小巧，可以關閉 **即時轉寫**。此時膠囊只會顯示按鈕與音訊波形。

### 按 Return 傳送

聽寫期間按下 **Return**，即可在一次按鍵內同時停止聽寫、插入文字並傳送（例如送出聊天訊息）。使用快速鍵或勾選按鈕停止時，則只會插入文字。若要關閉此行為，請至 **設定 → 聽寫 → 插入 → 按 Return 插入並傳送**。

若想讓每次聽寫都無須按任何鍵就自動傳送，請在同一個區塊開啟 **插入後自動傳送**。

### 暫停與繼續

使用單擊開始聽寫時，你可以隨時暫停：將游標移到膠囊的音量條上並點選 **暫停**，或按 **⌥P**。麥克風會暫時關閉，已說出的文字則會保留。點選 **繼續** 或再按一次該按鍵即可繼續聽寫，並像平常一樣以快速鍵或勾選按鈕結束。按住按鍵進行的聽寫不支援暫停。

若要變更此按鍵，請開啟 **設定 → 聽寫 → 暫停 / 繼續**。它可以是一組組合鍵、單一按鍵（例如 **Space**），或是單擊、連按兩下或長按單一修飾鍵。設定為長按時，按住期間會暫停，放開即繼續。

### 在會議中保持靜音

在 Zoom、Microsoft Teams 或 Google Meet 通話中、Mac 版 Telegram App 的通話裡，或是 Enconvo [視訊會議](/zh-hant/features/video-conference)中開始聽寫時，系統會自動將你在通話中的麥克風靜音，並在結束或暫停聽寫時為你取消靜音。無論在桌面 App 或瀏覽器分頁中都能運作。若通話原本就是你自己手動靜音的，則會保持靜音。當 Enconvo 找不到通話的靜音按鈕時，會提醒你一次請你手動靜音。若要關閉此功能，請至 **設定 → 聽寫 → 聽寫時將會議麥克風靜音**。

## 用語音寫草稿

與其逐字唸出內容，不如直接說出你想寫的意思，讓聽寫先為你寫好一份草稿，確認無誤後再送出。

1. 在文字欄位中點一下，例如你正在回覆的訊息框。
2. 同時按住右側 **Command** 鍵與 **Shift** 鍵，說出文字應該表達的內容，例如：「告訴她星期四下午兩點可以，並請她在前一天把新畫面寄給我。」
3. 放開按鍵。草稿寫好時會顯示在聽寫膠囊上方的面板中。
4. 按 **Return** 貼上，或按 **Esc** 捨棄。

**Return** 一律會貼到當初開始草擬的 App 中；如果目前前景是另一個 App，會先切換回原本的 App。面板標題列會顯示該 App 的名稱。

你也可以在聽寫到一半時轉為草擬：聽寫過程中按一下 **Shift** 鍵（即使已經放開聽寫鍵也有效），你到目前為止說的話就會成為草擬的指示。

草稿面板仍開著時，單獨按下聽寫鍵並說出想修改的地方，即可微調內容。在已有文字的欄位中再次使用草擬，則會接續該段文字繼續撰寫。

### 改寫或回覆選取的文字

先選取文字再開始草擬，然後說出要如何修改。在取代選取內容之前，草稿會先標示出修改之處。

當選取的文字無法直接編輯時（例如收到的訊息或網頁內容），草擬會將它當作參考並寫出新文字，按 **Return** 後便會貼回你原本的輸入欄位。若要關閉此功能，請關閉 **傳送選取文字**。

開啟 **傳送 App 上下文** 時，草稿會根據你所在的 App 來撰寫，使內容更貼合當下情境：例如回覆電子郵件時，它能參考你正在回覆的信件細節。

這些選項位於 **設定 → 聽寫 → 草擬**：

| 設定 | 作用 |
| --- | --- |
| **草擬修飾鍵** | 搭配聽寫快速鍵按住以開始草擬，或在聽寫時單獨按一下的按鍵。預設為 **Shift**。 |
| **以差異標示顯示變更** | 草稿編輯文字時，標出新增與移除的字詞。關閉時僅顯示結果。 |
| **傳送 App 上下文** | 將 App 的視窗標題、網址與可見文字提供給模型。預設開啟。 |
| **包含螢幕截圖** | 一併傳送 App 視窗的畫面圖片。需要螢幕錄製權限，以及支援圖片輸入的模型。 |
| **傳送選取文字** | 將你選取但無法編輯的文字（如訊息或網頁）作為參考提供給模型。預設開啟。 |
| **草擬模型** | 用於撰寫與編輯每份草稿的模型。 |
| **草擬提示詞** | 控制模型如何撰寫與編輯每份草稿。 |

## 使用螢幕上的名稱

開啟 **設定 → 聽寫 → 感知目前 App 內容** 時，聽寫會讀取你正在輸入的 App 畫面，依照畫面上的拼法來拼寫名稱，例如你正在回覆的訊息中的寄件者姓名。此設定預設為開啟。

## 邊說邊潤飾或翻譯

點選錄音膠囊上的 **清理** 圖示，即可選擇文字在插入前要進行的處理：

- **潤飾**：移除贅字與說錯重講的片段，並修正錯字與標點符號，保留你自己的表達方式。
- **翻譯**：將你說的話輸入為你的回覆語言；如果你本來就用該語言說話，則會翻譯成英文。
- **本地潤色**：使用 Mac 上的本機模型離線清理文字。當你的 Mac 支援執行時會顯示此選項，其模型只會在首次使用時下載一次。

**清理** 標籤會顯示目前所選選項的圖示；將游標移上去可查看名稱。再點一下可切換到下一個選項，或按 **⌃⌥⌘I**（**聽寫時切換**）。若要設定預設選取的選項，或使用自訂名稱、提示詞與模型新增選項，請開啟 **設定 → 聽寫** 中的 **清理** 區塊。

「翻譯」與「修正拼字與文法」同樣會移除「嗯」、「啊」、結巴與口誤，讓結果讀起來像書面文字。它們的 **移除贅字** 選項預設為開啟。

在某個 App 中切換清理選項時，該變更僅套用於該次聽寫。點選卡片上的 **一律使用 …** 即可為該 App 保留該選擇，並可點選 **復原**。在已有規則的 App 中，卡片會提供 **設為規則** 與 **恢復規則**。

### 選擇翻譯風格

若要調整 **翻譯** 的措辭風格，請開啟 **設定 → 聽寫**，前往 **清理**，並點選 **翻譯** 那一列右側的箭頭，接著選擇 **風格**：

- **標準**：準確且貼近你的原話。
- **道地自然**：自由改寫，讀起來如同母語人士所寫。
- **自訂**：依照你描述的風格進行翻譯。

你選擇的風格會以徽章顯示在 **翻譯** 那一列上。無論選擇哪種風格，當你說的內容已經是目標語言時，系統都會將它翻譯成你的另一種語言。

## 為特定 App 設定規則

**設定 → 聽寫 → App 規則** 可針對單一 App 或網站設定專屬的聽寫行為：包含 **清理**、**語言** 與 **Return 鍵**。當規則使用翻譯時，選擇 **翻譯成** 即可只為該 App 翻譯成不同語言，例如只在某個聊天 App 中翻譯成英文，而在其他地方維持你常用的語言。

- 為 Discord、Slack、Notion、Telegram、WhatsApp、ChatGPT、Claude、Linear、Figma 或 Teams 設定的規則，也會一併套用到它們的網頁版。
- 最後一列顯示所有未設定專屬規則的 App 會採用的設定，其內容來自你的聽寫預設設定。
- **你常聽寫的 App** 會推薦可加入規則的應用程式。

在 Enconvo 自己的訊息輸入框中使用麥克風聽寫時，會套用 Enconvo 自身的清理與語言規則。

<Note>
潤飾、翻譯與你自訂的選項會使用你的 AI 模型，因此即使語音辨識是在你的 Mac 上執行，辨識後的文字仍會傳送給該模型的服務供應商。本地潤色則會讓所有資料留在你的 Mac 上。
</Note>

## 選擇語音模型

1. 開啟 **設定 → 聽寫**，點選 **語音模型** 旁的 **變更**。
2. 你可以選擇雲端模型、在 Mac 上本機執行的模型，或使用你自己 API 金鑰的模型。
3. 點選 **本機** 即可查看裝置端模型。它們支援離線使用，且你的語音資料不會離開你的 Mac。
4. 選擇一個模型。本機模型會在幾秒內載入完成。

你也可以直接開啟 **設定 → 聽寫模型**。聽寫、語音指令、Live Talk、會議錄音、檔案轉寫與即時字幕各有獨立的語音模型設定。適合批次處理檔案的服務供應商，未必是即時串流輸入的最佳選擇。請參閱[語音辨識](/zh-hant/ai/speech-recognition)與[服務供應商目錄](/zh-hant/providers/catalog)。

## 教它辨識專有名詞

沒有出現在螢幕上的名稱有時還是會辨識錯誤，例如把專案名稱「Lumyn」聽成「Lumen」。

1. 開啟 **設定 → 詞典**，點選 **新增詞彙**。
2. 輸入正確的詞彙，並在 **常被聽成** 欄位填寫聽寫誤判的字詞。
3. 點選 **儲存**，然後再試著聽寫該名稱一次。

關於自訂詞庫與服務供應商的語言及熱詞設定，請參閱[詞典與說話者](/zh-hant/configuration/speech-assets)。

## 檢視過去的聽寫紀錄

開啟 **設定 → 語音輸入記錄** 即可回顧過去辨識過的文字。在這裡你可以搜尋、複製、播放錄音、重新轉寫某段聽寫，以及將詞彙加入詞典。

無法轉寫、逾時或被中斷的聽寫也會連同錄音保留在紀錄中。點選 **重試** 即可再次轉寫。

## 用語音指令與代理程式對話

語音指令是專為代理程式設計的按鍵通話（push-to-talk）功能。它會在動態島上顯示並朗讀回答，立即處理開啟 App 等快速操作，並將較大的請求作為任務交給代理程式執行。它不是死板地比對固定指令句，而是直接理解你的需求。

<Steps>
  <Step title="按住按鍵並說話">
    按住右側 **Option** 鍵並說出需求。你說的話會即時顯示在動態島上。你也可以單擊一下按鍵來開始。
  </Step>
  <Step title="傳送">
    放開按鍵；如果是單擊開始，則再按一下結束。
  </Step>
  <Step title="取得回答">
    回答會顯示在你的語音文字下方，若開啟了 **朗讀回覆** 也會大聲唸出來。它啟動的任務會使用該代理程式自己的模型與工具執行。
  </Step>
</Steps>

再按一次該按鍵可停止朗讀回答；仍在說話時按 **Esc** 則可取消。動態島上的麥克風按鈕也有相同功能。

你可以在 **設定 → 語音指令** 中進行設定：

| 設定 | 作用 |
| --- | --- |
| **快速鍵** | 按住或單擊的按鍵。預設為右側 Option 鍵。 |
| **聆聽** | 負責聽取語音的模型（預設為 **Enconvo Cloud Fast**），以及 **麥克風** 與 **語言**（除非另外指定，否則跟隨聽寫設定）。 |
| **思考** | 負責回答你的模型。**與對話相同**（預設）在對話使用 Enconvo Cloud 時會採用 Enconvo Fast，否則採用該對話所屬服務供應商的快速模型，因此使用自己的 API 金鑰時不會消耗 Enconvo Cloud 點數。由它啟動的任務則會使用該對話選定的模型。 |
| **回答** | **朗讀回覆** 以及使用的語音聲音。關閉 **朗讀回覆** 時，回答只會顯示在動態島上。 |
| **傳送螢幕截圖** | 每次請求一併傳送目前所在的螢幕畫面，讓代理程式看見你看到的內容。Enconvo 本身的視窗會排除在外。 |
| **快捷操作** | **管理** 會開啟 **設定 → 快捷操作**，列出語音指令與 Live Talk 會立即執行的動作，讓你可以關閉或自訂操作。 |

## 設定

這些選項位於 **設定 → 聽寫**：

| 設定 | 作用 |
| --- | --- |
| **聽寫快速鍵** | 啟動聽寫的按鍵，以及要按住還是單擊切換。預設為按住。 |
| **播放音效** | 聽寫開始與結束時播放簡短提示音。 |
| **麥克風** | 聽寫用來收音的麥克風。點選 **測試** 可確認是否正常收音。當選定的麥克風未連接時，聽寫會改用上一次使用的麥克風。 |
| **聽寫語言** | **預設** 會保留語音模型本身的設定；**自動偵測** 則讓模型自行辨識語言。 |
| **錄音時將其他音訊靜音** | 聽寫期間暫停或靜音其他 App 的聲音，結束後恢復播放。**靜音方式** 可選擇暫停、靜音或兩者皆用。 |
| **聽寫時將會議麥克風靜音** | 聽寫期間在會議通話中將你靜音。預設開啟。 |
| **暫停 / 繼續** | 用來暫停與繼續聽寫的按鍵。預設為 **⌥P**。 |
| **感知目前 App 內容** | 讀取目前所在的 App 以正確拼寫名稱與術語，並為潤飾、翻譯和草擬提供上下文。 |
| **顯示即時轉寫** | 說話時即時顯示辨識出的文字。關閉時僅保留控制按鈕與音訊波形。 |
| **按 Return 插入並傳送** | 聽寫期間按 **Return** 會停止、插入文字並送出。預設開啟。 |
| **插入後自動傳送** | 聽寫結束時直接傳送文字，無需再按 Return。預設關閉。 |
| **將聽寫文字複製到剪貼簿** | 插入文字的同時也複製到剪貼簿。 |
| **依名稱插入文字片段** | 單獨唸出文字片段的名稱或關鍵字，即可插入該片段內容。 |
| **聽寫期間切換 App 時** | 當聽寫結束前另一個 App 切到前景時，文字要放在哪裡。預設為詢問。 |
| **App 規則** | 針對特定 App 或網站覆寫上述設定。 |
| **儲存聽寫紀錄** | 依 **紀錄保留時間** 的設定，保存每次聽寫的錄音與文字。 |

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 麥克風沒有輸入 | 若通知指出某個麥克風沒有傳送聲音，請改選其他麥克風，或在 **設定 → 聽寫** 中點選 **麥克風** 旁的 **測試**。也請檢查麥克風權限。 |
| 文字有出現但無法插入 | 檢查輔助使用權限，點一下目標文字欄位，並確認該 App 支援貼上動作。 |
| 按 **Return** 沒有傳送 | 檢查 **設定 → 聽寫 → 插入** 中的 **按 Return 插入並傳送**，以及該 App 規則中的 **Return 鍵** 欄位。 |
| 某次聽寫失敗或被截斷 | 開啟 **設定 → 語音輸入記錄**，在該筆紀錄上點選 **重試**。 |
| 辨識後的文字有誤 | 檢查目前使用的 **清理** 選項、**聽寫語言**，以及你的[詞典](/zh-hant/configuration/speech-assets)。 |
| 停止後很久才出現結果 | 批次模型會等待整段錄音結束才處理。請改選支援串流的模型。 |
| 麥克風被其他功能佔用 | 請先結束 Live Talk 或目前的錄音。 |

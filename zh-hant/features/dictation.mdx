聽寫會把你說的話轉成文字，輸入到你正在打字的任何 App 中。語音指令則會把你說的話傳給你的 Agent，由它出聲回答，並能代你執行操作。若想進行你一句我一句的語音對話，請改用 [Live Talk](/zh-hant/features/live-voice)。

## 開始之前

Enconvo 需要麥克風權限才能聽到你說話。若要將文字輸入到其他 App，還可能需要輔助使用權限。請參閱[權限](/zh-hant/configuration/permissions)。

## 聽寫到 App 中

1. 在任何 App 中，點一下你想輸入文字的文字欄位。
2. 按住右側 **Command** 鍵並開始說話。一個小膠囊會顯示聽寫正在收音。
3. 說完後放開按鍵。文字會輸入到游標所在位置。
4. 檢查插入的文字，尤其是名字、日期和數字。

預設是說話時按住右側 Command 鍵。如果你想改成點一下就開始、想說多久都可以，請開啟**設定 → 聽寫 → 聽寫快速鍵**，變更按鍵方式。之後再按一次快速鍵，或點膠囊上的勾號即可結束。

聽寫會在你的字詞前後加上適當的空格，中文、日文和泰文除外。單獨說出某個片段的名稱或關鍵字，就會插入該片段的內容，而不是這些字詞。

### 使用聽寫卡片

聽寫時將游標移到膠囊上，它會展開成卡片，你說的話顯示在控制項上方。在卡片上，你可以切換麥克風、將聽寫轉為**草擬**、選擇**清理**選項，並能在不中斷的情況下開啟或關閉**按 Return 插入並傳送**和**即時轉寫**。停止後，卡片會顯示清理的進度。

若想讓膠囊保持小巧，請關閉**即時轉寫**。膠囊就只會顯示按鈕和波形。

### 按 Return 傳送

聽寫時按下 **Return**，即可一次完成停止、插入文字並傳送，例如傳送聊天訊息。用快速鍵或勾號停止則只會插入文字。若要關閉此功能，請前往**設定 → 聽寫 → 插入 → 按 Return 插入並傳送**。

若想讓每次聽寫都不需按任何鍵就自動傳送，請在同一區段開啟**插入後自動傳送**。

### 暫停和繼續

如果你是以點一下的方式開始，就可以暫停：將游標移到膠囊的音量條上並點選**暫停**，或按 **⌥P**。麥克風會關閉，你說過的話會保留。點選**繼續執行**或再按一次該鍵即可繼續，結束時照常使用快速鍵或勾號。按住按鍵的聽寫沒有暫停功能。

若要更改此按鍵，請前往**設定 → 聽寫 → 暫停 / 繼續**。它可以是組合鍵、單一按鍵（例如 **Space**），或是一個你點一下、連點兩下或按住的修飾鍵。按住時會暫停，直到你放開。

### 開會時保持靜音

在 Zoom、Microsoft Teams 或 Google Meet 通話、Mac 版 Telegram App 中的通話，或 Enconvo [Conference](/zh-hant/features/video-conference) 中，開始聽寫會讓你在通話中的麥克風靜音，結束或暫停時則會取消靜音。這在 App 和瀏覽器分頁中都有效。你自己設為靜音的通話會維持靜音。當 Enconvo 找不到通話的靜音按鈕時，會提醒你一次，請你自行在該處靜音。若要關閉此功能，請前往**設定 → 聽寫 → 聽寫時將會議麥克風靜音**。

## 用語音撰寫草稿

與其聽寫文字本身，你也可以說出你想寫什麼，聽寫就會寫出一份草稿，讓你確認後才會輸入。

1. 點一下文字欄位，例如你正在撰寫的回覆。
2. 同時按住右側 **Command** 鍵和 **Shift** 鍵，說出文字要表達的內容，例如「告訴她週四下午 2 點可以，並請她前一天把新的畫面傳過來。」
3. 放開按鍵。草稿會在撰寫的同時顯示在聽寫膠囊上方的面板中。
4. 按 **Return** 貼上，或按 **Esc** 捨棄。

**Return** 一律會貼到草稿開始時所在的 App，若有其他 App 在前面，會先把該 App 帶回前景。面板標題會顯示該 App 的名稱。

你也可以在聽寫到一半時轉為草稿：聽寫時輕點一下 **Shift**，即使已經放開聽寫鍵也可以，到目前為止你說的內容就會成為草稿的指示。

草稿仍開啟時，單獨按下聽寫鍵並說出要修改的地方，即可進一步調整。在文字欄位中再次使用草擬，可接續已有的文字繼續寫。

### 改寫或回答選取的文字

在開始草稿前先選取文字，再說出要如何修改。草擬會先顯示它的變更，才會取代選取的內容。

當選取的內容無法編輯時，例如收到的訊息或網頁的一部分，草擬會把它當作參考並撰寫新文字，按 **Return** 會貼到你回去的那個欄位。若要關閉此功能，請關閉**傳送選取的文字**。

開啟**傳送 App 上下文**時，草稿會依你所在的 App 撰寫，更貼近你正在做的事：例如回覆電子郵件時，它能從你要回覆的郵件中擷取細節。

這些選項位於**設定 → 聽寫 → 草擬**：

| 設定 | 作用 |
| --- | --- |
| **草稿修飾鍵** | 與聽寫快速鍵一起按住以開始草稿的按鍵，或是聽寫時單獨點一下的按鍵。預設為 **Shift**。 |
| **標出變更** | 草稿編輯文字時，標出新增和刪除的字詞。關閉則只顯示結果。 |
| **傳送 App 上下文** | 將 App 的視窗標題、網址和可見文字提供給模型。預設開啟。 |
| **附帶截圖** | 同時傳送 App 視窗的圖片。需要螢幕錄製權限，以及能讀取圖片的模型。 |
| **傳送選取的文字** | 將你選取但無法編輯的文字（例如訊息或網頁）作為參考提供給模型。預設開啟。 |
| **草稿模型** | 負責撰寫和編輯每份草稿的模型。 |
| **草稿提示詞** | 模型撰寫和編輯每份草稿的方式。 |

## 使用螢幕上的名稱

開啟**設定 → 聽寫 → 感知目前 App 內容**後，聽寫會讀取你正在聽寫的 App，並依名稱在該處出現的寫法來拼寫，例如你要回覆的訊息中的寄件者姓名。此設定預設為開啟。

## 邊說邊清理或翻譯

點選錄音膠囊上的**清理**圖示，選擇文字在插入前要如何處理：

- **潤飾**會去除贅詞和說到一半重來的部分，並修正錯字和標點，同時保留你自己的措辭。
- **翻譯**會以你的回應語言輸入你所說的內容；若你本來就說英文，則以英文輸入。
- **本地潤色**會用你 Mac 上的模型離線清理文字。只有在你的 Mac 能執行時才會出現，其模型只需下載一次。

**清理**晶片會顯示所選選項的圖示，將游標移上去即可看到名稱。再點一次可切換到下一個選項，或按 **⌃⌥⌘I**（**聽寫時切換**）。若要選擇預設選取的選項，或新增你自己的選項（包含名稱、提示詞和模型），請開啟**設定 → 聽寫**並使用**清理**區段。

翻譯和修正拼寫與文法也會去除「嗯」、「啊」、口吃和說到一半重來的部分，讓結果讀起來像書面文字。它們的**移除贅詞**選項預設為開啟。

在 App 中切換清理時，變更只會套用於該次聽寫。點選卡片上的**一律使用…**，即可為該 App 保留這個選擇，並可使用**還原**。若該 App 已有規則，卡片會提供**設為規則**和**恢復規則**。

### 選擇翻譯樣式

若要改變**翻譯**的措辭風格，請開啟**設定 → 聽寫**，前往**清理**，並點選**翻譯**列上的箭頭。然後選擇**樣式**：

- **標準**準確且貼近你說的內容。
- **道地自然**會自由改寫，彷彿由母語人士寫成。
- **自訂**會依你描述的風格處理。

你選的樣式會以徽章顯示在**翻譯**列上。無論哪種樣式，你說的內容若已是目標語言，就會翻譯成你的另一種語言。

## 為特定 App 設定規則

**設定 → 聽寫 → App 規則**可為單一 App 或網站調整聽寫：它的**清理**、**語言**和 **Return 鍵**。當規則使用翻譯時，選擇**翻譯成**即可只在該 App 中翻譯成不同的語言，例如在某個聊天 App 中翻成英文，而其他地方的翻譯仍使用你平常的語言。

- Discord、Slack、Notion、Telegram、WhatsApp、ChatGPT、Claude、Linear、Figma 或 Teams 的規則，也會涵蓋其網站。
- 最後一列顯示所有沒有規則的 App 所使用的設定，它來自你的聽寫設定。
- **常聽寫的應用程式**會建議可加入的 App。

在 Enconvo 自己的訊息框中用麥克風聽寫時，會依循 Enconvo 這個 App 的規則來決定清理和語言。

<Note>
潤飾、翻譯和你新增的選項會使用你的 AI 模型，因此即使辨識是在你的 Mac 上完成，辨識出的文字也會傳送給該模型的供應商。本地潤色則會把文字留在你的 Mac 上。
</Note>

## 選擇語音模型

1. 開啟**設定 → 聽寫**，點選**語音模型**旁的**變更**。
2. 從雲端模型、在你 Mac 上執行的模型，以及使用你自己 API 金鑰的模型中挑選。
3. 點選**本機**即可查看裝置端模型。它們可離線運作，你的聲音只會留在你的 Mac 上。
4. 選取一個模型。本機模型只需幾秒即可載入。

你也可以直接開啟**設定 → 聽寫模型**。聽寫、語音指令、Live Talk、會議錄音、檔案轉錄和即時字幕，各自有獨立的語音模型設定。適合批次處理檔案的供應商，未必是串流輸入的最佳選擇。請參閱[語音辨識](/zh-hant/ai/speech-recognition)和[供應商目錄](/zh-hant/providers/catalog)。

## 教它一個名字

不在你螢幕上的名字仍可能辨識錯誤，例如把名為「Lumyn」的專案聽成「Lumen」。

1. 開啟**設定 → 詞典**並點選**新詞**。
2. 輸入正確的字詞，然後在**誤辨識為**中輸入聽寫聽到的內容。
3. 點選**儲存**，再聽寫一次這個名字。

關於自訂詞彙，以及供應商的語言和熱詞設定，請參閱[詞典和說話者](/zh-hant/configuration/speech-assets)。

## 檢視過去的聽寫

開啟**設定 → 語音輸入記錄**，即可回顧過去辨識出的文字。你可以在此搜尋、拷貝、播放錄音、重新轉錄聽寫內容，並將字詞加入你的詞典。

無法轉錄、耗時過長或被中斷的聽寫，會連同錄音保留在記錄中。點選**重試**即可重新轉錄。

## 用語音指令與你的 Agent 對話

語音指令是為你的 Agent 設計的按鍵說話功能。它會在動態島上顯示並出聲回答，能立刻處理像開啟 App 這類的小事，並把較大的請求當作任務交給你的 Agent。它不是比對固定的一組片語，而是理解你要求的是什麼。

<Steps>
  <Step title="按住按鍵並說話">
    按住右側 **Option** 鍵並說出你的需求。你的話會顯示在動態島上。你也可以點一下按鍵來開始。
  </Step>
  <Step title="傳送">
    放開按鍵；如果你是點一下開始的，則再點一次。
  </Step>
  <Step title="取得回答">
    回答會顯示在你的話下方，並在**朗讀回覆**開啟時朗讀出來。它啟動的任務會使用該 Agent 自己的模型和工具執行。
  </Step>
</Steps>

再按一次按鍵可停止回答，或在你還在說話時按 **Esc** 取消。動態島上的麥克風按鈕也有同樣效果。

請在**設定 → 語音指令**中進行設定：

| 設定 | 作用 |
| --- | --- |
| **快速鍵** | 你按住或點一下的按鍵。預設為右側 Option 鍵。 |
| **收音** | 負責聽你說話的語音模型（預設為 **Enconvo Cloud Fast**），以及**麥克風**和**語言**，除非你自行選擇，否則會沿用聽寫的設定。 |
| **思考** | 回答你的模型。**與對話相同**（預設）在對話使用 Enconvo Cloud 時會使用 Enconvo Fast，否則使用該對話自己供應商的快速模型，所以使用你自己的 API 金鑰時不會消耗 Enconvo Cloud 點數。它啟動的任務會使用該對話所選的模型執行。 |
| **回答** | **朗讀回覆**，以及它回答時使用的聲音。關閉**朗讀回覆**後，回答只會顯示在動態島上。 |
| **傳送截圖** | 每次請求都傳送你目前所在的螢幕，讓 Agent 看到你所看到的。Enconvo 的視窗不會包含在內。 |
| **快捷操作** | **管理**會開啟**設定 → 快捷操作**，列出語音指令和 Live Talk 能立即執行的事項，並可讓你關閉它們或建立自己的。 |

## 設定

這些選項位於**設定 → 聽寫**：

| 設定 | 作用 |
| --- | --- |
| **聽寫快速鍵** | 啟動聽寫的按鍵，以及要按住還是點一下。預設為按住。 |
| **播放提示音** | 在聽寫開始和結束時播放簡短的提示音。 |
| **麥克風** | 聽寫所使用的麥克風。點選**測試**可確認它是否收得到聲音。當它未連接時，聽寫會使用你先前使用的麥克風。 |
| **聽寫語言** | **預設**沿用語音模型本身的設定；**自動偵測**則由它自行辨識語言。 |
| **錄音時靜音其他聲音** | 在你聽寫時暫停或靜音其他 App，結束後恢復它們的聲音。**靜音方式**可選擇暫停、靜音或兩者。 |
| **聽寫時將會議麥克風靜音** | 聽寫時在會議通話中將你靜音。預設開啟。 |
| **暫停 / 繼續** | 暫停和繼續聽寫的按鍵。預設為 **⌥P**。 |
| **感知目前 App 內容** | 讀取你所在的 App 以拼寫名稱和術語，並為潤飾、翻譯和草擬提供上下文。 |
| **顯示即時轉寫** | 在你說話時顯示你的話。關閉則只保留控制項和波形。 |
| **按 Return 插入並傳送** | 聽寫時，**Return** 會停止、插入文字並傳送。預設開啟。 |
| **插入後自動傳送** | 聽寫結束時不需按 Return 就傳送文字。預設關閉。 |
| **將聽寫文字拷貝到剪貼簿** | 同時拷貝辨識出的文字。 |
| **依名稱插入片段** | 單獨說出片段的名稱或關鍵字，就會插入其內容。 |
| **聽寫時切換了 App** | 聽寫結束時若有其他 App 在前面，文字要送到哪裡。預設為詢問。 |
| **App 規則** | 為特定 App 或網站更改上述任一步驟。 |
| **儲存聽寫歷史** | 依**歷史保留時長**所設定的期間，保留每次聽寫的錄音和文字。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有麥克風輸入 | 當通知指出你的麥克風沒有傳送任何聲音時，請選擇另一個麥克風，或在**設定 → 聽寫**中點選**麥克風**旁的**測試**。同時請檢查麥克風權限。 |
| 文字出現了但沒有插入 | 檢查輔助使用權限，點一下文字欄位，並確認該 App 接受貼上。 |
| **Return** 沒有傳送 | 檢查**設定 → 聽寫 → 插入**中的**按 Return 插入並傳送**，以及該 App 任何規則的 **Return 鍵**欄。 |
| 聽寫失敗或被中斷 | 開啟**設定 → 語音輸入記錄**並對該筆點選**重試**。 |
| 辨識後的文字不正確 | 檢查目前使用的**清理**選項、**聽寫語言**和你的[詞典](/zh-hant/configuration/speech-assets)。 |
| 停止後結果很慢出現 | 批次模型會等整段錄音結束。請選擇支援串流的模型。 |
| 另一個功能占用了麥克風 | 請先結束 Live Talk 或錄音。 |

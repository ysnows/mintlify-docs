虛擬形象是一個代表你某個代理程式的桌面角色。在語音通話中，它會配合說話聲音呈現同步動畫，而代理程式依然保留它原有的指令與工具。

這部影片首先介紹虛擬形象，接著介紹即時通訊管道與憑證管理。

## 設定角色

1. 開啟**設定 → 虛擬形象**。
2. 在**圖庫**中找到一個角色，點擊**下載**取得其基礎套件。
3. 下載完成後，選擇它要代表的代理程式並點擊**綁定虛擬形象**。每個代理程式只能綁定一個虛擬形象，每個虛擬形象也只屬於一個代理程式。
4. 選擇角色的**品質**。
5. 點擊**開啟**，在桌面上顯示該代理程式的虛擬形象。

虛擬形象通話時使用的語音由**設定 → Live Talk → 說話**決定，更換語音會在下一次通話生效。

**選用下載項目**列出了該角色的額外資源包，例如可用時的高解析度材質或更多動作。建議先從基礎套件開始，並依照你 Mac 的效能選擇合適的畫質。

若要自行打造角色，點擊**建立一個角色**並挑選臉部、毛色與名稱，或點擊**匯入檔案…**加入 OpenAvatar 角色檔案。若要從照片製作角色，請參閱[建立 Live Photo 角色](#建立-live-photo-角色)。

## 建立 Live Photo 角色

Live Photo 角色能將一張肖像照片變成會在桌面上站立並呼吸的虛擬形象，並在通話時以即時影片形式出現。

1. 開啟**設定 → 虛擬形象**並切換到 **Live Photo** 分頁。
2. 點擊**建立 Live Photo**。
3. 從照片開始：點擊**選擇照片…**，挑選一張包含你想在通話中看見的臉孔的 JPG、PNG 或 WebP 照片，大小上限為 10 MB。或者選擇**描述一下**並輸入虛構角色的描述；Enconvo 會生成幾張肖像供你挑選。
4. 使用**調整取景**擺放臉孔位置。在**背景**下方，可以將照片原背景保留在圓角框內，或選擇**移除**將角色去背。
5. 確認照片是你本人，或你已獲得當事人授權使用。
6. 在**語音**步驟中選擇她的聲音（見下文），接著建立角色。建置過程需要幾分鐘；期間你可以先關閉視窗。
7. 將該角色綁定至一個代理程式並點擊**開啟**，作法與其他虛擬形象相同。

照片與通話音訊會傳送至位於美國的外部服務 Atmee 進行影片繪製。你最多可以建立三個照片角色；刪除其中一個即可建立新的角色。

### 選擇她的聲音

**語音**步驟提供以下選項：

- **複製聲音**：現場錄製該人選的聲音，或點擊**改為上傳**使用他們的音訊或影片檔案。**複製服務商**可選擇透過 Enconvo Cloud 上的 ElevenLabs（每月有固定複製次數額度），或使用你自己的 ElevenLabs API 金鑰。
- **選擇聲音**：挑選一個 ElevenLabs 語音，或你複製好的聲音。
- **跟隨通話聲音**：使用在**設定 → Live Talk → 說話**中設定的語音。

之後想更改時，點擊她卡片上的**更換聲音**即可。

### 使用你自己的 Atmee 帳戶

預設情況下，Live Photo 角色在 Enconvo 的 Atmee 帳號上運作，受每日分鐘數與三個角色的上限限制。選擇**使用你自己的 Atmee 帳戶**，並貼上來自 Atmee Studio（**API keys**）的 API 金鑰。之後新建立的角色就會在你的帳號內生成，不受上述限制，而且你還能匯入你 Atmee 帳號中既有的虛擬形象。該金鑰會保存在[憑證管理](/zh-hant/configuration/credentials)中。

### 與 Live Photo 角色通話

在通話中，她會以即時影片呈現，嘴唇動作會跟隨聲音。當長達一分鐘沒人說話時，她的即時畫面會進入靜止休息狀態，直到你再次開口。一分半鐘後她會詢問「Still there?」，再過一分鐘通話便會掛斷並留下**繼續**按鈕讓你接續對話。

若要將她放上直播畫面，請參閱[串流 Live Photo 角色](/zh-hant/features/avatar-live-stream)。

## 對話與互動

設定好 [Live Talk](/zh-hant/features/live-voice) 後，即可使用虛擬形象的對話控制項開始交談。在角色上點擊右鍵可存取語音、歷史記錄、設定與角色控制選項。對話氣泡會顯示交談文字與語音活動狀態。

你可以移動角色位置、透過捲動旋轉它，以及按住 Control 捲動或雙指捏合來縮放大小。點擊透明邊緣處會直接穿透至桌面。

## 切換角色

桌面上的**角色**選單不會重新指派代理程式。選擇指派給其他代理程式的角色時，會開啟那個代理程式的虛擬形象。未指派的角色則會透過主代理程式顯示。若要更改某個角色屬於哪個代理程式，請使用**設定 → 虛擬形象**。

選單列或動態島中的虛擬形象開關，會開啟主代理程式及其指派的角色。

## 設定

**設定 → 虛擬形象**中每個已下載角色的卡片都包含以下控制項：

| 設定 | 作用 |
| --- | --- |
| **代理程式** | 此角色所代表的代理程式。建立新的配對會取代雙方的舊綁定關係；語音、外觀與聊天歷史記錄都會保留。 |
| **品質** | 算圖品質。預設的**最低**消耗最少的 GPU、CPU 與電池電力。**均衡**與**最佳畫質**會增加光影、著色與更高解析度的材質，並使用較多 GPU 資源。 |
| **選用下載項目** | 該角色的額外資源包與套件更新。 |

圖庫上方的**自然對嘴同步**會下載一個裝置端模型，讓所有虛擬形象的唇形能依據說話語音自然變化。這項功能需要搭載 Apple silicon 的 Mac。

圖庫下方的**動態桌面**會在你所有視窗後方放置一個看板，顯示你的代理程式、程式開發工作階段與排程工作正在做什麼，並且有個角色會在需要你介入或發生狀況時做出反應。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 無法變更**品質** | 請先下載角色並指派一個代理程式。 |
| 無法使用**建立 Live Photo** | 你已有三個照片角色。請先刪除一個，或使用你自己的 Atmee 帳戶。 |
| **描述一下**無法使用 | 此功能需要 AI 模型。請先在**設定 → AI 模型**中挑選一個模型，再試一次。 |
| 下載失敗 | 檢視卡片上的錯誤訊息，確認網路連線與剩餘磁碟空間，然後點擊**重試**。 |
| 角色放大後顯得模糊 | 選擇較高的**品質**，並檢查**選用下載項目**中是否有更高畫質的材質包。 |
| 無法開始通話 | 檢查你的 [Live Talk](/zh-hant/features/live-voice) 設定與 macOS 麥克風存取權限。 |
| 回答的是錯誤的代理程式 | 在**設定 → 虛擬形象**中檢查該角色的**代理程式**設定。 |

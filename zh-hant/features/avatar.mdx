虛擬形象是代表你其中一位 Agent 的桌面角色。在語音通話中，它會以與聲音同步的動畫說話，而 Agent 仍保有它原本的指示和工具。

## 設定角色

1. 開啟**設定 → 虛擬形象**。
2. 在**圖庫**中找到一個角色，點選**下載**以取得它的基本套件。
3. 下載完成後，選擇它所代表的 Agent，並點選**綁定虛擬形象**。每位 Agent 只有一個虛擬形象，每個虛擬形象也只屬於一位 Agent。
4. 選擇角色的**品質**。
5. 點選**開啟**，在你的桌面上顯示該 Agent 的虛擬形象。

虛擬形象的通話會使用**設定 → Live Talk → 說話**中設定的聲音，聲音的變更會在下一次通話生效。

**選用下載項目**列出該角色的其他套件，例如在提供時可用的更高解析度材質或動作。建議先從基本套件開始，並選擇適合你 Mac 的品質。

若要製作自己的角色，請點選**建立一個角色**，並挑選它的臉、毛色和名字，或點選**匯入檔案…**來加入 OpenAvatar 角色檔案。若要用照片製作，請參閱[建立 Live Photo 角色](#建立-live-photo-角色)。

## 建立 Live Photo 角色

Live Photo 角色會把一張肖像變成站在你桌面上、會呼吸的虛擬形象，並在通話中以即時影片呈現。

1. 開啟**設定 → 虛擬形象**，並開啟 **Live Photo** 分頁。
2. 點選**建立 Live Photo**。
3. 先從照片開始：點選**選擇照片…**，選取一張你想在通話中看到的臉孔照片，格式為 JPG、PNG 或 WebP，大小上限 10 MB。或選擇**描述一下**，輸入一個虛構角色的描述；Enconvo 會產生肖像供你挑選。
4. 使用**調整取景**來擺放臉部位置。在**背景**下，可將照片本身的背景保留在圓角框中，或選擇**移除**把角色去背。
5. 確認這張照片是你本人，或你已取得對方同意使用。
6. 在**語音**步驟中，選擇她的聲音（見下文），然後建立角色。製作需要幾分鐘；期間你可以關閉視窗。
7. 將角色綁定到一位 Agent 並點選**開啟**，與任何虛擬形象相同。

照片和通話音訊會傳送給 Atmee，這是位於美國的外部服務，由它繪製影片。你最多可以有三個照片角色；刪除一個才能再建立另一個。

### 選擇她的聲音

**語音**步驟提供：

- **複製聲音**：直接錄下該人的聲音，或點選**改為上傳**使用他們的音訊或影片。**複製服務商**可選擇 Enconvo Cloud 上的 ElevenLabs（每月有複製次數上限），或你自己的 ElevenLabs API 金鑰。
- **選擇聲音**：選擇一個 ElevenLabs 聲音，或你複製的聲音。
- **跟隨通話聲音**：使用**設定 → Live Talk → 說話**中設定的聲音。

之後若要更改，請點選她卡片上的**更換聲音**。

### 使用你自己的 Atmee 帳戶

預設情況下，Live Photo 角色是在 Enconvo 的 Atmee 帳戶上執行，有每日分鐘數和三個角色的限制。選擇**使用你自己的 Atmee 帳戶**，並貼上來自 Atmee Studio 的 API 金鑰（**API 金鑰**）。之後新角色會在你的帳戶中製作，不受這些限制，你也可以匯入已存在於你 Atmee 帳戶中的虛擬形象。金鑰會保存在[憑證管理](/zh-hant/configuration/credentials)中。

### 與 Live Photo 角色通話

通話中她會以即時影片出現，嘴唇會跟著她的聲音動作。當一分鐘沒有人說話時，她的即時畫面會靜止，直到你再次開口。一分半鐘後她會問「還在嗎？」，再過一分鐘通話就會掛斷，並出現**繼續**按鈕讓你重新接上。

若要讓她上直播，請參閱[直播 Live Photo 角色](/zh-hant/features/avatar-live-stream)。

## 交談與互動

先設定 [Live Talk](/zh-hant/features/live-voice)，再使用虛擬形象的對話控制項開始交談。在角色上按右鍵，可使用聲音、記錄、設定和角色控制項。對話氣泡會顯示對話文字和語音活動。

你可以移動角色、捲動來旋轉它，並以 Control 加捲動或兩指縮放來放大縮小。點選透明邊緣的操作會穿透到桌面。

## 切換角色

桌面上的**角色**選單不會重新指派 Agent。選取已指派給另一位 Agent 的角色，會開啟該 Agent 的虛擬形象。未指派的角色則透過主要 Agent 顯示。若要更改角色屬於哪位 Agent，請使用**設定 → 虛擬形象**。

選單列或動態島上的虛擬形象切換，會開啟主要 Agent 及其已指派的角色。

## 設定

**設定 → 虛擬形象**中，每個已下載角色的卡片都有這些控制項：

| 設定 | 作用 |
| --- | --- |
| **Agent** | 角色所代表的 Agent。指派新的配對會取代它們先前的綁定；聲音、外觀和對話記錄都會保留。 |
| **品質** | 繪製品質。預設的**最低**使用最少的 GPU、CPU 和電量。**均衡**和**最佳畫質**會加入光照、陰影和更大的材質，並使用更多 GPU。 |
| **選用下載項目** | 角色的額外套件，以及套件更新。 |

圖庫上方的**自然對嘴同步**會下載一個裝置端模型，依每個虛擬形象所使用的聲音來塑造它的嘴唇動作。需要搭載 Apple 晶片的 Mac。

其下的**動態桌面**會在你的視窗後方放置一塊看板，顯示你的 Agent、程式設計工作階段和自動化正在做什麼，並有一個角色會在有事需要你或出問題時做出反應。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 無法更改**品質** | 請先下載角色並指派一位 Agent。 |
| 無法使用**建立 Live Photo** | 你已有三個照片角色。請刪除一個，或使用你自己的 Atmee 帳戶。 |
| **描述一下**無法使用 | 它需要一個 AI 模型。請在**設定 → AI 模型**中選擇一個，然後再試一次。 |
| 下載失敗 | 閱讀卡片上的錯誤訊息，檢查你的網路連線和可用磁碟空間，然後點選**重試**。 |
| 角色放大後很模糊 | 選擇較高的**品質**，並到**選用下載項目**檢查是否有材質可下載。 |
| 通話無法開始 | 檢查你的 [Live Talk](/zh-hant/features/live-voice) 設定和 macOS 麥克風存取權限。 |
| 回答的 Agent 不對 | 在**設定 → 虛擬形象**中檢查角色的 **Agent**。 |

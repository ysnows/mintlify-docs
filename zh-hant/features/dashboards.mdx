title: "儀表板"
description: "讓代理程式將你的資料變成一頁你可以保存的數字與圖表，將每個數字對照其資料列檢查，並讓它保持最新。"
---

儀表板是代理程式根據你的資料建立的一頁數字與圖表，適用於你追蹤、檢視或回報的數據。每個數字都與它的來源資料列相連，因此你可以核對。當你之後會回頭查看這些數字時，就適合使用它；若只是一次性的回答，直接在聊天中詢問即可。

## 製作儀表板

1. 開啟新聊天並在訊息輸入框下方選擇**儀表板**，或在任何聊天中要求製作一個。
2. 附上資料：CSV、TSV 或 JSON 檔案，或點按**做點什麼**這一列中的**開啟試算表**。你也可以讓代理程式指向已連接的服務、你 Mac 上的檔案或網址。
3. 說明要追蹤什麼，以及如何細分。

範例：

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

儀表板會在聊天旁開啟。當代理程式加入篩選器時，每一個都會在頂端顯示為選單、開關或輸入框。

## 核對數字

1. 點按儀表板標題列中的**核對數字**。
2. 點按任何一個數字。
3. Enconvo 會顯示它背後的資料列、它的來源，以及兩者是否相符。

若要詢問某個數字，請在它上面留言。以 `@Enconvo` 開頭的留言可得到代理程式的回答。

## 查看資料的來源

點按**來源**。每組資料都會顯示它的來源、有多少資料列，以及上次變更的時間。已逾期的資料會顯示**已過期**。點按**下載 CSV** 即可儲存一組資料。

## 讓數字保持最新

由已連接的服務、你 Mac 上的檔案或網址建立的儀表板，在你允許之後可以自行更新。

1. 當儀表板詢問**要讓這些數字保持最新嗎？**時，請檢查每個來源讀取的內容，然後點按**允許**。你也可以點按**來源**中某個來源旁的**允許更新**。
2. 數字會依代理程式設定的排程更新，例如**每小時**或**重新整理時**。點按**重新整理**即可立即更新。
3. 若要停止，請點按該來源旁的**停止更新**。

當更新失敗時，儀表板會保留最後一次的數字，並說明原因。

<Note>
未聲明只會讀取資料的來源，只會在你點按**重新整理**時執行。在共用的儀表板上，其中的每個人都能看到該來源讀取的內容。
</Note>

## 下載或移動儀表板

點按**下載**並選擇：

| 選項 | 你會得到 |
| --- | --- |
| **下載 PDF** | 頁面的 PDF |
| **下載圖片** | 頁面的圖片 |
| **下載 HTML** | 一個可在任何瀏覽器中開啟的 HTML 檔案 |
| **下載專案 (.zip)** | 整個專案，可在另一台電腦上匯入 |

若要匯入專案，請點按**作品**資料庫中的**匯入**並選擇該 zip 檔。留言會一併帶入；來自已連接服務的更新則需要在那裡重新允許。

若要與他人或你的團隊分享儀表板，請點按**分享**。請參閱[作品](/zh-hant/features/artifacts)。儀表板也可以在 iPhone 與 Android App 中開啟；請參閱[作品](/zh-hant/features/artifacts)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 數字與它的資料列不相符 | 在留言中向代理程式詢問，或請它修正計算 |
| 某個來源顯示**已過期** | 點按**重新整理**，或允許它更新 |
| **無法更新數字** | 閱讀原因，修正該來源的存取權限，然後點按**重新整理** |
| 儀表板是空的 | 在聊天中描述儀表板及其資料 |

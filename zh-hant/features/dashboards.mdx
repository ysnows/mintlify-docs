儀表板（Dashboard）是代理程式根據你的資料建立的數據與圖表頁面，適合用於你會持續追蹤、檢視或報告的指標數字。每個數字都與它所屬的資料列相連結，方便你隨時核對。當你會反覆回來查看這些數字時適合使用儀表板；如果只是問一個一次性問題，直接在聊天中提問即可。

## 建立儀表板

1. 開啟新聊天並在訊息框下方挑選 **Dashboard**，或在任何聊天中要求製作儀表板。
2. 附上資料：CSV、TSV 或 JSON 檔案，或在 **製作內容** 列點擊 **開啟試算表**。你也可以指向已連接的服務、Mac 上的檔案或網址。
3. 說明要追蹤的指標與拆分方式。

範例：

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

儀表板會在聊天旁開啟。當代理程式加入篩選條件時，每個條件都會在頂部顯示為選單、開關或輸入框。

## 核對數字

1. 點擊儀表板標頭中的 **核對數字**。
2. 點擊任何一個數字。
3. Enconvo 會顯示該數字背後的資料列、它的來源，以及兩者是否相符。

若想針對某個數字提問，可以在上面加上留言。以 `@Enconvo` 開頭的留言會取得代理程式的回覆。

## 查看資料來源

點擊 **來源**。每組資料都會顯示它的來源位置、共有多少列，以及最後一次更新的時間。逾時未更新的資料會顯示 **已過期**。點擊 **下載 CSV** 可儲存一組資料。

## 讓數字保持最新

由已連接服務、Mac 上的檔案或網址建立的儀表板，經你允許後可以自動更新。

1. 當儀表板詢問 **要讓這些數字保持最新嗎？** 時，請檢查每個來源會讀取的內容，然後點擊 **允許**。你也可以在 **來源** 中點擊某個來源旁的 **允許更新**。
2. 數字會依代理程式設定的排程更新，例如 **每小時** 或 **重新整理時**。點擊 **重新整理** 可立即更新它們。
3. 若要停止自動更新，點擊該來源旁的 **停止更新**。

當更新失敗時，儀表板會保留上次的數字並說明原因。

<Note>
未標明僅讀取資料的來源只會在你點擊 **重新整理** 時執行。在共用的儀表板上，所有成員都能看到來源所讀取的內容。
</Note>

## 下載或移轉儀表板

點擊 **下載** 並選擇：

| 選項 | 你會取得 |
| --- | --- |
| **下載 PDF** | 該頁面的 PDF 檔案 |
| **下載圖片** | 該頁面的圖片 |
| **下載 HTML** | 可在任何瀏覽器中開啟的單一 HTML 檔案 |
| **下載專案（.zip）** | 整個專案，可供匯入到另一台電腦 |

若要匯入專案，在 **作品** 資料庫中點擊 **匯入** 並選擇該 zip 檔案。留言會一併匯入；來自已連接服務的自動更新則需在該裝置上重新允許。

若要與其他人或你的團隊分享儀表板，請點擊 **分享**。參閱[作品](/zh-hant/features/artifacts)。儀表板也能在 iPhone 與 Android App 中開啟；參閱[作品](/zh-hant/features/artifacts)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 數字與其資料列不相符 | 在留言中向代理程式提問，或請它修正計算方式 |
| 來源顯示 **已過期** | 點擊 **重新整理**，或為它允許自動更新 |
| **無法更新數字** | 閱讀失敗原因、修復該來源的存取權限，然後點擊 **重新整理** |
| 儀表板是空白的 | 在聊天中描述你希望呈現的儀表板與資料內容 |

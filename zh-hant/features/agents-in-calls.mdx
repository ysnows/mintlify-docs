---
title: "通話中的 Agent"
description: "讓你的 Agent 加入 Enconvo 會議，或派它進入 Google Meet 或 Zoom 會議，回答問題並使用你的工具做事。"
---

你的 Agent 可以陪你一起參加通話。在 Enconvo 會議中，它會以看得見的參與者身分加入，任何人都可以開啟它或指名詢問它，它也能建立讓整場通話一起編輯的文件或白板。在 Google Meet 或 Zoom 會議中，它會以訪客身分加入、跟著閱讀，並在會議的聊天室中回應你的請求。

## 讓 Agent 加入會議

1. 加入會議。你必須先進入通話，才能讓 Agent 加入。
2. 開啟**成員**並點選**新增代理程式**，然後選擇該 Agent。
3. 選擇它如何回答，以及有訪客加入時它要做什麼（請參閱[選項](#選項)）。

Agent 會以處於關閉狀態的參與者身分出現在通話中。只有在有人開啟它，或在聊天室中指名寫給它時，它才會聆聽：在聊天室輸入 `@` 即可詢問它。之後它就會回答，並使用你的工具做事。

當你以外的人要求它做事時，你會收到核准卡片。**一律允許**會讓該人在通話剩餘時間內都能要求它做事，不必每次詢問你；**只這一次**只允許這次請求；**暫不**則是拒絕。

iPhone App 的運作方式相同：從**成員**以相同的選項讓 Agent 加入，並在手機上回應它的核准卡片。

## 一起在舞台上工作

當會議中的 Agent 在通話期間建立文件或白板時，它會在通話旁邊的舞台上開啟。通話中所有已登入的人都能看到並一邊交談一邊一起編輯。**關閉舞台**會再次將它隱藏。

## 讓你的 Agent 參加你的會議

你的 Agent 可以自行加入你選定的會議。

1. 開啟**設定 → 視訊會議**，找到 **Agent 自動入會**。
2. 開啟**讓 … 加入我建立的會議**。
3. 若要包含你受邀參加的會議，請開啟**也包含我受邀的會議**。**讀取行事曆**會在你 Mac 的行事曆事件中尋找 Enconvo、Google Meet 和 Zoom 的連結，並略過你已拒絕的事件。若 Enconvo 要求，請點選**允許取用行事曆**。

Agent 會在你加入後以關閉狀態加入。若只想讓它加入某一場會議，或不讓它加入某一場，請使用**即將開始**下該會議那一列的**加入**開關。Enconvo 開啟期間，由這台 Mac 帶領 Agent 入會。

## 派你的 Agent 進入 Google Meet 或 Zoom

在對話中請你的 Agent 加入會議並給它連結，或在**即將開始**下的 Google Meet 或 Zoom 事件上開啟**加入**開關。

Agent 會以「*Agent 名稱* (Enconvo)」的名義加入，鏡頭和麥克風都是關閉的。它會讀取會議的字幕和聊天室，並在會議的聊天室中回應你的請求。在做任何事之前，它會先在你的 Mac 或 iPhone 上詢問你。會議結束後，它的筆記會歸檔到[錄音](/zh-hant/features/meeting-recording)中。

<Note>
Agent 透過你 Mac 上的瀏覽器加入，需要 Google Chrome、Microsoft Edge 或其他 Chromium 瀏覽器。主持人可能需要讓它進入。
</Note>

## 選項

| 選項 | 選擇 |
| --- | --- |
| **怎麼回答** | **寫在聊天裡**（預設）或**說出來**。 |
| **有訪客加入時** | **離開會議**、**保持安靜直到他們離開**或**照常**。 |

請在**設定 → 視訊會議**的 **Agent 自動入會**下，為自動加入的 Agent 設定預設值。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| Agent 在會議中沒有回答 | 它一開始是關閉的。請在**成員**中開啟它，或在聊天室中寫下 `@` 和它的名字。 |
| Agent 顯示**正在等待准入** | 請會議的主持人讓它進入。 |
| **此會議要求訪客登入** | 點選**登入它的瀏覽器**，並在會議結束後登入。 |
| 它在 Google Meet 或 Zoom 中只讀得到聊天室 | 會議的字幕是關閉的。請在會議中開啟字幕。 |
| Agent 沒有加入已排程的會議 | 檢查**即將開始**下的**加入**開關，並讓 Enconvo 在這台 Mac 上保持開啟。 |

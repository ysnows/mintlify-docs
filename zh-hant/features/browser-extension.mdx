Enconvo 瀏覽器擴充功能 Enconvo Companion，讓 Enconvo 在任務需要你已登入的瀏覽器狀態時控制你真實的瀏覽器。LinkedIn、Gmail、Salesforce、儀表板或內部工具等網站，都需要用到你的 Cookie 與瀏覽器擴充功能，適合使用它。設定中稱之為 **瀏覽器助手**。

若是公開頁面、本機預覽，或不該碰到你個人瀏覽器設定檔的工作流程，請改用隔離的瀏覽器自動化。

## 設定擴充功能

<Steps>
  <Step title="安裝擴充功能">
    開啟 **設定 → 使用瀏覽器**，在 **瀏覽器擴充功能** 中點擊 **安裝瀏覽器配套程式**。接著會開啟該擴充功能在 Chrome 線上應用程式商店的頁面。你也可以從瀏覽器的擴充功能商店安裝。它支援 Chrome、Edge、Brave、Arc、Vivaldi、Opera 與 Firefox。[電腦操作影片教學](https://youtu.be/0CbQA7d8zqU?t=33)示範了在 Chrome 中的安裝方式。
  </Step>
  <Step title="保持瀏覽器開啟">
    擴充功能會透過 `ws://localhost:11225` 自動連接到 Enconvo。
  </Step>
  <Step title="檢查彈出視窗">
    點擊擴充功能的圖示。彈出視窗會顯示 **已連接 Chrome**、**已連接 Edge**、**已連接 Firefox**，或你所用瀏覽器的名稱。
  </Step>
  <Step title="開始瀏覽器任務">
    請 Enconvo 在瀏覽器中讀取、點擊、輸入、擷取螢幕截圖或管理分頁。
  </Step>
</Steps>

## 彈出視窗

| 項目 | 顯示內容 |
| --- | --- |
| 連線狀態 | 這個瀏覽器的擴充功能是否已連接到 Enconvo |
| 目前的瀏覽器 | 這個擴充功能所連接的瀏覽器，例如 Chrome、Edge、Brave 或 Firefox |
| 已連接的瀏覽器 | 目前已連接到 Enconvo 的其他瀏覽器 |
| 版本 | 已安裝的擴充功能版本 |
| **瞭解更多** | 開啟本頁 |

如果彈出視窗顯示已中斷連線，請重新啟動 Enconvo 並重新整理瀏覽器。若仍然無法連接，請將擴充功能關閉後再開啟。

## 使用多個瀏覽器

Enconvo 可以同時連接多個瀏覽器。當任務未指定瀏覽器時，Enconvo 會依下列順序挑選：

1. 你在「使用瀏覽器」設定中選擇的 **預設瀏覽器**（**設定 → 使用瀏覽器**，然後在 **⋯** 選單中選擇 **設定**）。
2. 你 Mac 的預設瀏覽器。
3. 你最近使用過的已連接瀏覽器。

自動化 API 也可以指定瀏覽器：

```json
{
  "browser": "edge"
}
```

常見的值包括 `chrome`、`google_chrome`、`edge`、`brave_browser`、`arc`、`vivaldi`、`opera` 與 `firefox`。

## 停留在正確的分頁

瀏覽器任務開始時，Enconvo 會記下它所使用的瀏覽器與分頁。後續步驟會盡可能停留在該分頁，即使頁面開啟了彈出視窗、重新載入或失去焦點。

為獲得最佳效果：

- 在任務完成前保持分頁開啟。
- 連接了多個瀏覽器時，請指明瀏覽器。
- 想讓 Enconvo 對你眼前的頁面操作時，請說「使用目前的分頁」。
- 頁面換頁或你送出表單後，請要求重新查看頁面。

## 網站存取與安全

網頁可能包含不是你寫的指示。在敏感頁面上，請先檢視網站與動作，再讓 Enconvo 繼續。

擴充功能會在任務需要時，使用瀏覽器權限來讀取頁面、點擊、輸入、擷取螢幕截圖、查看分頁，以及讀取 Cookie。請將已登入的頁面、瀏覽器歷史記錄與內部工具視為敏感資料。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 彈出視窗顯示已中斷連線 | 確認 Enconvo 正在執行，重新啟動瀏覽器，然後將擴充功能關閉再開啟。檢查是否有任何東西封鎖 `localhost:11225`。 |
| 控制到錯誤的瀏覽器 | 在「使用瀏覽器」設定中設定 **預設瀏覽器**，或在瀏覽器動作中傳入 `edge`、`chrome` 或 `firefox` 等瀏覽器值。 |
| 已連接，但無法控制某個頁面 | `chrome://` 等瀏覽器頁面無法控制。內容安全政策嚴格的頁面、封閉的 Shadow DOM 與瀏覽器權限提示也可能造成妨礙。 |
| 檔案上傳無法運作 | 在瀏覽器中該擴充功能的詳細資料頁面，開啟檔案網址的存取權限。上傳本機檔案或開啟檔案型頁面的任務需要此權限。 |

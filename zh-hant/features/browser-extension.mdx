Enconvo 瀏覽器擴充功能 Enconvo Companion 能讓 Enconvo 在任務需要你的已登入瀏覽器狀態時，控制你真實的瀏覽器。它適合用在 LinkedIn、Gmail、Salesforce、儀表板或內部工具等需要你的 Cookie 和瀏覽器擴充功能的網站。在設定中它稱為 **瀏覽器助手**。

對於公開網頁、本機預覽或不應觸及個人瀏覽器設定檔的工作流程，請改用隔離的瀏覽器自動化。

## 設定擴充功能

<Steps>
  <Step title="安裝擴充功能">
    開啟 **設定 → 使用瀏覽器**，在 **瀏覽器擴充功能** 中點擊 **安裝瀏覽器配套程式**，系統會開啟該擴充功能的 Chrome 線上應用程式商店頁面。你也可以從瀏覽器的擴充功能商店安裝。它支援 Chrome、Edge、Brave、Arc、Vivaldi、Opera 與 Firefox。[電腦操作影片教學](https://youtu.be/0CbQA7d8zqU?t=33)示範了在 Chrome 中的安裝過程。
  </Step>
  <Step title="保持瀏覽器開啟">
    擴充功能會透過 `ws://localhost:11225` 自動連線到 Enconvo。
  </Step>
  <Step title="檢查彈出視窗">
    點擊擴充功能的圖示。彈出視窗會顯示 **Connected Chrome**、**Connected Edge**、**Connected Firefox**，或你所在瀏覽器的名稱。
  </Step>
  <Step title="開始瀏覽器任務">
    請 Enconvo 在瀏覽器中閱讀、點擊、輸入、截圖或管理分頁。
  </Step>
</Steps>

## 彈出視窗

| 項目 | 顯示內容 |
| --- | --- |
| 連線狀態 | 此瀏覽器的擴充功能是否已連線到 Enconvo |
| 目前瀏覽器 | 此擴充功能目前連線代表的瀏覽器，例如 Chrome、Edge、Brave 或 Firefox |
| 已連線的瀏覽器 | 目前其他擴充功能已連線到 Enconvo 的瀏覽器 |
| 版本 | 已安裝的擴充功能版本 |
| **Learn more** | 開啟本頁面 |

如果彈出視窗顯示未連線，請重新啟動 Enconvo 並重新整理瀏覽器。如果仍然無法連線，請將擴充功能停用後再重新啟用。

## 同時使用多個瀏覽器

Enconvo 可以同時連線到多個瀏覽器。當任務沒有指明瀏覽器時，Enconvo 會依以下順序挑選一個：

1. 你在使用瀏覽器設定中選擇的 **預設瀏覽器**（**設定 → 使用瀏覽器**，然後點擊 **⋯** 選單中的 **設定**）。
2. 你 Mac 上的預設瀏覽器。
3. 你最近一次使用過的已連線瀏覽器。

自動化 API 也可以指明瀏覽器：

```json
{
  "browser": "edge"
}
```

常見的值包括 `chrome`、`google_chrome`、`edge`、`brave_browser`、`arc`、`vivaldi`、`opera` 與 `firefox`。

## 停留在正確的分頁

當瀏覽器任務開始時，Enconvo 會記錄它正在操作的瀏覽器與分頁。後續步驟會盡可能停留在該分頁上，即使頁面開啟了彈出視窗、重新載入或失去焦點。

為了獲得最佳效果：

- 在任務完成前保持該分頁開啟。
- 同時有多個瀏覽器連線時，指明要使用的瀏覽器。
- 當你想讓 Enconvo 操作眼前顯示的頁面時，說「使用目前分頁」。
- 在頁面跳轉或送出表單後，要求重新讀取頁面狀態。

## 網站存取與安全性

網頁中可能包含並非由你撰寫的指令。在敏感頁面上，請先檢查網站與操作內容，再讓 Enconvo 繼續。

擴充功能會使用瀏覽器權限，在任務需要時讀取頁面、點擊、輸入、截圖、檢視分頁以及讀取 Cookie。請將已登入的頁面、瀏覽記錄與內部工具視為敏感資料。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 彈出視窗顯示未連線 | 確認 Enconvo 正在執行，重新啟動瀏覽器，然後將擴充功能關閉再重新開啟。檢查沒有任何程式阻擋 `localhost:11225`。 |
| 控制了錯誤的瀏覽器 | 在使用瀏覽器設定中設定 **預設瀏覽器**，或在瀏覽器操作中傳入 `edge`、`chrome` 或 `firefox` 等瀏覽器值。 |
| 已連線，但無法控制某個頁面 | 無法控制 `chrome://` 這類瀏覽器內部頁面。採用嚴格內容安全原則（CSP）、封閉 Shadow DOM 的頁面以及瀏覽器權限提示也可能造成阻礙。 |
| 檔案上傳無法運作 | 在瀏覽器中該擴充功能的詳細資訊頁面上，開啟對檔案網址（file URLs）的存取權限。上傳本機檔案或開啟本機檔案頁面的任務需要這項權限。 |

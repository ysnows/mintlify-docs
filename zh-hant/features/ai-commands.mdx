AI 指令將你重複使用的提示詞連同其模型與設定包裝起來，讓你只需按一下就能對任何文字執行該指令。適合用於像改寫客服回覆這類單一明確的工作。若需要搭配工具處理更廣泛的工作，請使用[代理程式](/zh-hant/ai/agents)；若要串接多個步驟，請使用[工作流程](/zh-hant/workflows/introduction)。

## 建立指令

1. 開啟**設定 → AI 指令**，或從 SmartBar 執行**建立 AI 指令**，然後點擊**新增 AI 指令**。
2. 用你自己的話描述這個指令應該做什麼，再點擊**草擬**。Enconvo 會寫好標題、圖示與指示，並立即用一段範例測試執行。
3. 將你自己的文字貼進範例框並點擊**再試一次**，查看在真實輸入上的效果。
4. 若想調整行為，在**有什麼要改的嗎？**中輸入修改方向（例如「依負責人分組」），再點擊**重新草擬**。變動的行數會在指示中標示出來，範例結果也會再次執行。
5. 在**在哪裡使用**下方，保持開啟**加入 PopBar** 以便在任何地方選取文字時出現 PopBar 按鈕，或點擊**新增快速鍵**並按下你想使用的按鍵組合。
6. 點擊**儲存**。

指令指示範例：

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## 執行指令

- **從 PopBar：** 在任何應用程式中選取文字並點擊該指令的按鈕。結果產生後，點擊**貼上**即可取代選取的文字。
- **透過快速鍵：** 選取文字並按下該指令的快速鍵。結果會在 SmartBar 中開啟，供你直接貼上。
- **從 SmartBar：** 搜尋指令名稱並對目前輸入的內容執行。
- **從代理程式：** 在聊天中請代理程式為你執行某個指令。指令完成後，代理程式會接著繼續你的聊天。

由 AI 指令產生的聊天——包括內建指令（如翻譯）與你自建的指令——不會出現在聊天視窗、動態島的**歷史記錄**，或 SmartBar 的聊天列表中。

## 修改指令

在**設定 → AI 指令**中開啟該指令，即可編輯它的標題與指示。所做的修改會即時自動儲存。

| 設定 | 作用 |
| --- | --- |
| **PopBar** | 將該指令放上 PopBar，或從 PopBar 移除。 |
| **快速鍵** | 在任何應用程式中對選取文字執行該指令的按鍵組合。 |
| **行內模式** | 不開啟視窗直接執行，並將結果貼上覆蓋你選取的文字。 |
| **完成後操作** | 指令完成取得回答後要執行的後續動作（僅於支援的指令顯示）。 |
| **AI 模型** | 顯示該指令是跟隨所有 AI 指令共用的模型，還是使用為它單獨指定的模型。點擊**更改**即可選擇。 |

### 為所有指令選擇模型

除非你另行指定模型，否則 AI 指令預設會使用 Enconvo Fast。若要更改，請開啟**設定 → AI 指令**並點擊**全部指令**。**AI 模型**底下選定的模型也會同時負責寫作工具、PopBar，以及聽寫的**潤飾**與**翻譯**。點擊**使用推薦**可切回 Enconvo Fast。有單獨指定模型的指令不會隨這項設定改變；點擊**檢視**可查看這些指令，或點擊**全部改用 …** 將它們一併切換到此模型。

內建指令會顯示**自訂**而非直接修改：它會建立一份屬於你的副本供你編輯。你自己的指令在 **⋯** 選單中會有**複製**與**刪除**。刪除指令也會同時將它從 PopBar 移除並釋放其快速鍵。

## 使用動態變化的上下文

在支援變數的欄位中，可以使用變數選擇器帶入輸入文字、選取文字、目前使用中的應用程式或其他上下文。參閱[變數](/zh-hant/workflows/variables)。對私人文件執行指令前，請先確認展開後的上下文內容。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 找不到某個指令 | 確認指令是否已儲存，然後搜尋它的標題。 |
| 輸出結果忽略了選取的文字 | 檢查該指令的輸入與上下文設定，以及[權限](/zh-hant/configuration/permissions)中的輔助使用權限。 |

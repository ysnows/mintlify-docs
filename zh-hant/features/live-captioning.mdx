---
title: "即時字幕"
description: "在音訊播放時即時閱讀字幕，並在之後回顧每一次字幕工作階段。"
---

即時字幕會在音訊播放或被擷取時顯示字幕，例如演講、影片或通話。每個工作階段都會儲存在它自己的清單中，與匯入的語音轉寫檔案和會議錄音分開。

## 開始產生字幕

1. 開啟**設定 → 字幕產生模型**，並選擇支援即時辨識的模型。
2. 開啟**設定 → 即時字幕**，點選**新增**，並選擇**開始產生字幕**。在空白的清單中，點選**開始產生字幕**。你也可以執行**開始即時字幕**指令，或在 Enconvo 的選單列選單中選擇**開始即時字幕**。
3. 在**開始即時字幕**視窗中，選擇音訊來源、字幕列開啟的位置及其所在的螢幕。macOS 詢問時，請授予麥克風或系統音訊的存取權限。
4. 開始播放你想跟著看的音訊，並確認字幕出現。
5. 結束時停止字幕，然後從**即時字幕**清單中開啟已儲存的工作階段。

若要用按鍵開始和停止字幕，請在**設定 → 快捷鍵**的**語音**下，為即時字幕設定快速鍵。同一個快速鍵也會停止正在執行的字幕。

## 放置字幕列

字幕列會在四個位置之一開啟：

| 位置 | 外觀 |
| --- | --- |
| **左側** | 螢幕左邊緣的一欄。預設值。 |
| **右側** | 右邊緣的一欄。 |
| **頂部置中** | 頂部的一列，控制項位於寬廣的字幕區域旁邊。 |
| **底部置中** | 底部的一列，字幕會像影片字幕一樣排列。 |

有多個顯示器時，也請選擇它的螢幕，或維持**滑鼠所在的螢幕**。在工作階段期間，於字幕列上按右鍵可更改位置或螢幕。無論在哪個位置，都可以拖曳字幕區域的邊緣來調整大小。

## 翻譯字幕

部分語音供應商提供即時翻譯，包含來源語言和目標語言，或語音翻譯。請在所選字幕模型自己的設定中開啟這些功能；Enconvo Cloud Fast 和 Soniox 使用**來源語言**和**目標語言**。並非每個語音模型都支援即時翻譯，而且支援檔案轉錄並不代表模型支援即時字幕。

## 檢視工作階段

開啟已儲存的工作階段，即可檢視它的逐字稿和處理結果。在準確度很重要時，請對照音訊檢查名稱、數字和說話者標籤。使用[詞典和說話者](/zh-hant/configuration/speech-assets)讓詞彙和說話者姓名保持最新。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有字幕 | 檢查音訊來源、輸入音量、擷取權限和所選的模型。 |
| 文字只在你停止後才出現 | 選擇支援串流的模型。 |
| 語言不對 | 在模型的設定中設定辨識語言或語言提示。 |
| 沒有翻譯 | 確認模型支援翻譯，並設定目標語言。 |
| 工作階段顯示處理錯誤 | 在已儲存的項目中閱讀錯誤詳細資料。不要假設語音遺失了。 |

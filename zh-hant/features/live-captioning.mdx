---
title: "即時字幕"
description: "在音訊播放時即時顯示字幕，並於事後重新檢視每一次的字幕工作階段。"
---

即時字幕會在播放或擷取音訊時即時顯示字幕，例如演講、影片或通話。每一次工作階段都會獨立儲存在自己的清單中，與匯入的轉寫檔案及會議錄音分開管理。

## 開始即時字幕

1. 開啟 **設定 → 字幕產生模型**，選擇一個支援即時辨識的模型。
2. 開啟 **設定 → 即時字幕**，點選 **新增**，然後選擇 **開始產生字幕**。若清單為空，請直接點選 **開始產生字幕**。你也可以執行 **開始即時字幕** 指令，或在 Enconvo 的選單列選單選擇 **開始即時字幕**。
3. 在 **開始即時字幕** 視窗中，選擇音訊來源、字幕列開啟的位置以及顯示的螢幕。當 macOS 詢問時，請授予麥克風或系統音訊存取權限。
4. 開始播放你想追蹤的音訊，確認畫面上出現字幕。
5. 結束後停止字幕功能，接著即可從 **即時字幕** 清單開啟已儲存的工作階段。

若想用按鍵開始與停止字幕，請到 **設定 → 快捷鍵** 的 **語音** 下方為即時字幕設定快速鍵。使用同一個快速鍵即可停止正在執行的字幕。

## 調整字幕列位置

字幕列可開啟於四個位置之一：

| 位置 | 顯示樣式 |
| --- | --- |
| **左側** | 螢幕左邊緣的直向欄位。預設位置。 |
| **右側** | 螢幕右邊緣的直向欄位。 |
| **頂部置中** | 螢幕頂端的橫向列，控制按鈕位於寬廣字幕區旁。 |
| **底部置中** | 螢幕底端的橫向列，字幕會像影片字幕般排列。 |

若連接了多台顯示器，也可以指定要顯示的螢幕，或維持 **滑鼠所在的螢幕**。工作階段進行中，在字幕列按右鍵即可切換位置或螢幕。在任何位置下，拖曳字幕區的邊緣都能自由調整大小。

## 翻譯字幕

部分語音服務供應商提供即時翻譯，可設定來源語言與目標語言，或輸出語音翻譯。請在所選字幕產生模型自己的設定中開啟這些選項；Enconvo Cloud Fast 與 Soniox 使用的是 **來源語言** 與 **翻譯為**。並非所有語音模型都支援即時翻譯，而支援檔案轉寫的模型也不一定支援即時字幕。

## 檢視工作階段紀錄

打開已儲存的工作階段即可檢視逐字稿與處理結果。對準確度有嚴格要求時，請對照音訊檢查人名、數字與說話者標記。你可以使用[詞典與說話者](/zh-hant/configuration/speech-assets)來維持詞彙與說話者名稱的準確度。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 沒有出現字幕 | 檢查音訊來源、輸入音量、擷取權限與所選的模型。 |
| 停止後文字才一次出現 | 請改選支援即時串流的模型。 |
| 辨識出來的語言不對 | 在該模型的設定中指定辨識語言或語言提示。 |
| 沒有進行翻譯 | 確認該模型支援翻譯，並已設定目標語言。 |
| 工作階段顯示處理錯誤 | 在已儲存的項目中查看錯誤詳情，先不要認定語音資料遺失。 |

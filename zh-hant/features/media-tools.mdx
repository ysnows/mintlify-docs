媒體工具是處理日常媒體雜務的本機指令：縮小圖片、影片或音訊檔案、儲存影片的配樂，或從網頁下載影片。你可以在 SmartBar 中找到它們，或在**設定 → 外掛程式**之下。

| 指令 | 作用 | 儲存位置 |
| --- | --- | --- |
| **圖片壓縮** | 壓縮一張或多張圖片，或資料夾及其子資料夾中的每張圖片，品質可調整 | 取代原始圖片 |
| **影片壓縮** | 縮小影片檔案 | `~/Downloads` |
| **音訊壓縮** | 依你選擇的品質縮小音訊檔案，並保留其封面圖片（MP3、WAV、M4A、AAC、OGG、FLAC） | `~/Downloads` |
| **擷取音訊** | 將影片或資料夾中每部影片的音軌儲存為 M4A（若無法直接複製音軌則為 MP3） | `~/.cache/enconvo/transcribe` |
| **線上影片下載器** | 從連結下載影片或音訊，例如 YouTube、TikTok、Instagram、Reddit、X 或 Vimeo | `~/Downloads` |

<Warning>
**圖片壓縮**預設會取代你的原始圖片。若要保留它們，請先在其設定中關閉**覆寫原始圖片檔案**；壓縮後的副本會改存到圖片旁邊的 `enconvo-compressed-images` 資料夾。
</Warning>

## 壓縮檔案或擷取其音訊

1. 在 Finder 中選取檔案，或將它們附加進來。對於圖片壓縮，你也可以選擇資料夾：其中的圖片與子資料夾中的圖片都會被壓縮，而副本會維持相同的資料夾結構。
2. 開啟 SmartBar 並執行該指令。
3. 開啟輸出內容並檢查。

在嘗試壓縮設定時，請保留原始檔案。每個指令的設定位於**設定 → 外掛程式**之下：圖片壓縮在 **Image Utils**，其他指令在 **Media Utils**。

| 設定 | 變更的內容 |
| --- | --- |
| **品質** | 從 0 到 100；越高保留的品質越多，檔案也越大。預設為 80 |
| **目標資料夾路徑** | 壓縮後檔案存放的位置：絕對路徑，或相對於該檔案的路徑 |
| **覆寫原始 … 檔案** | 取代原始檔案。圖片預設為開啟，影片與音訊預設為關閉 |

## 下載影片

1. 在瀏覽器中開啟影片的頁面，或複製它的連結。
2. 從 SmartBar 執行**線上影片下載器**。它會從瀏覽器目前的分頁取得連結，或使用你輸入的連結。
3. 在動態島中查看進度，你可以在那裡取消。完成後，點按**在 Finder 中顯示**。

下載的內容會儲存在你的聊天記錄中，而你已下載過的檔案會被重複使用，而不是再次擷取。某個網站是否可行，取決於該網站以及它允許你存取的內容。請只下載你有權儲存的內容。

| 設定 | 變更的內容 |
| --- | --- |
| **輸出目錄** | 下載內容存放的位置。預設為 `~/Downloads` |
| **僅音訊** | 只下載音訊 |
| **偏好解析度** | 要下載的解析度，從**最佳**（預設）到 144p |
| **強制轉換為相容的 MP4** | 將影片轉換為可在任何地方播放的 MP4。預設為開啟；會花費額外的時間與 CPU |
| **使用瀏覽器 Cookie** | 使用你瀏覽器的 Cookie 登入，適用於只有你能看到的影片。在**瀏覽器**中選擇瀏覽器 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| **沒有可壓縮的圖片** | 在 Finder 中選取圖片或將它們附加進來，然後再次執行指令 |
| 轉換失敗 | 檢查檔案的格式、輸出資料夾是否可寫入，以及你是否還有可用的磁碟空間 |
| 私人影片無法下載 | 開啟**使用瀏覽器 Cookie**，並選擇你已登入的瀏覽器 |
| 某個網站的下載不再運作 | 在重試之前，先閱讀錯誤訊息並更新外掛程式。網站會變更其格式與存取規則 |

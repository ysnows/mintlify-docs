寫作工具是一組一鍵指令，作用於你在任意 App 中選取的文字。修正錯誤、調整語氣、縮短或擴寫、解釋或摘要，或是將文字轉成列表或表格，都無需離開你正在寫作的 App。

## 編輯選取的文字

1. 在你正在寫作的 App 中選取文字。
2. 在 [PopBar](/zh-hant/features/popbar) 中點擊一個指令，或開啟 [SmartBar](/zh-hant/features/smartbar) 搜尋該指令。
3. 閱讀結果。開啟 **醒目標示修改** 時，結果會標出指令新增和移除的內容。
4. 點擊 **貼上** 取代你選取的文字，或複製結果。

每個指令都會保留原文的語言，並且只回覆結果本身。**Explain** 也會用選取文字的語言作答，並且每次執行都獨立處理，不會接續先前的內容。如果選取的文字是一個問題或一條指令，指令會編輯這些文字，而不會去回答它們。

<Tip>
為你信得過的指令開啟 **行內模式**，它就會在不彈出視窗的情況下執行，並把結果直接貼到選取的文字上。參閱[更改指令](#更改指令)。
</Tip>

## 選擇指令

| 目標 | 指令 |
| --- | --- |
| 修正錯誤 | Fix Spelling & Grammar、Proofread |
| 改進措辭 | Improve Writing、Polish、Rewrite、Sound Native、AI Edit |
| 調整長度 | Make Longer、Make Shorter、Make Concise |
| 調整語氣 | Change Tone Friendly、Confident、Casual 或 Professional |
| 理解內容 | Explain、Summarize、Extract Key Points |
| 重新排版 | Convert to List、Convert to Table |
| 電子郵件 | Polish Email、Draft a Reply |
| X 貼文 | Polish for X、Fit in 280 Characters、Turn into a Thread、Suggest a Reply on X、Suggest a Quote Comment on X |
| 翻譯 | Translator、Screenshot Translate（參閱[翻譯](/zh-hant/ai/translate)） |
| 螢幕上的內容 | Screenshot Explain |
| 聽寫 | Dictation Polish、Dictation Translate、Dictation Edit、On-Device Cleanup（參閱[聽寫](/zh-hant/features/dictation)） |
| 簡短表達 | Emoji |

**Sound Native** 會用同一種語言，依母語者的寫法重寫你的文字。**Polish Email** 會保留你自己的問候語、結尾語和署名，不會加上郵件簽名。**Draft a Reply** 會依所選郵件的語言和語氣撰寫回覆，對它無法得知的姓名、日期或決定，會用方括號留下簡短的預留位置。

## 更改指令

開啟 **設定 → AI 指令**，在 **內建** 下選擇指令。它的頁面會說明這個指令的作用，並提供 **試試看**，可以先用一段文字試執行。

| 設定 | 作用 |
| --- | --- |
| **PopBar** | 把指令加入 PopBar，或從中移除 |
| **醒目標示修改** | 在結果中標出指令新增和移除的內容 |
| **快速鍵** | 對你在任意 App 中選取的文字執行該指令 |
| **行內模式** | 不彈出視窗直接執行，並把結果貼到選取的文字上 |
| **完成後操作** | 指令完成後如何處理答案 |
| **AI 模型** | 該指令使用的模型。預設跟隨所有 AI 指令的模型 |

內建指令的指令碼說明為唯讀。點擊 **自訂** 可以建立一份屬於你的副本，並自由修改。

寫作工具使用 **設定 → AI 指令 → 全部指令** 中設定的模型，除非某個指令選擇了自己的模型。同樣的指令也列在 **設定 → 外掛程式 → 寫作工具** 下，結果視窗中的 **設定** 按鈕會開啟產生該結果的指令。

## 獲得可靠的結果

當改寫有多種可能的方向時，說明文字是寫給誰的、要達到什麼目的。指明哪些內容必須保持不變，例如姓名、日期、數字和引用的原話。

傳送前，務必將結果與原文對照一遍。行文流暢的輸出也可能改變了原意。

對於經常重複的指令，可以建立你自己的 [AI 指令](/zh-hant/features/ai-commands)。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 某個指令不在 PopBar 上 | 點擊 PopBar 末尾的 **⌄**，放不下的按鈕都在那裡；或在 **設定 → AI 指令** 中該指令的頁面開啟 **PopBar** |
| PopBar 沒有出現 | 參閱 [PopBar 疑難排解](/zh-hant/features/popbar) |
| 結果的語言不符合預期 | Explain 用選取文字的語言作答。Summarize 保留原文語言，除非你設定了它的 **回覆語言**。其他指令都保留原文語言 |
| 結果改變了原意 | 貼上前先編輯，或用原文重新執行指令 |

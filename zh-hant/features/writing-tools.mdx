寫作工具是一組針對你在任何 App 中選取的文字所設計的一鍵指令。你可以修正錯誤、改變語氣、讓文字變短或變長、加以解釋或摘要，或將它轉成清單或表格，而無需離開你正在撰寫的 App。

## 編輯選取的文字

1. 在你正在撰寫的 App 中選取文字。
2. 在 [PopBar](/zh-hant/features/popbar) 中點按某個指令，或開啟 [SmartBar](/zh-hant/features/smartbar) 並搜尋該指令。
3. 閱讀結果。開啟**醒目標示修改**時，結果會標示出該指令新增與移除的內容。
4. 點按**貼上**以取代你的選取內容，或複製結果。

每個指令都會保留你文字所用的語言，並且只回覆結果。**解釋**也會以所選文字的語言回答，並將每次執行視為獨立的一次，而不是先前那次的延續。當所選文字本身是一個問題或一項指示時，指令會編輯那些文字，而不會去回答它們。

<Tip>
對於你信任的指令，請開啟**行內模式**，它會在沒有視窗的情況下執行，並直接將結果貼在你的選取內容上。請參閱[變更指令](#變更指令)。
</Tip>

## 選擇指令

| 目標 | 指令 |
| --- | --- |
| 修正錯誤 | 修正拼字與文法、校對 |
| 改善措辭 | 改善寫作、潤飾、改寫、道地自然、AI 編輯 |
| 改變長度 | 加長、縮短、精簡 |
| 改變語氣 | 將語氣改為親切、自信、輕鬆或專業 |
| 理解內容 | 解釋、摘要、擷取重點 |
| 重新排版 | 轉換為清單、轉換為表格 |
| 電子郵件 | 潤飾電子郵件、草擬回覆 |
| X 上的貼文 | 為 X 潤飾、縮減至 280 字元內、改成串文、建議 X 上的回覆、建議 X 上的引用評論 |
| 翻譯 | 翻譯器、截圖翻譯（請參閱[翻譯](/zh-hant/ai/translate)） |
| 螢幕上的內容 | 截圖解釋 |
| 聽寫 | 聽寫潤飾、聽寫翻譯、聽寫編輯、本地潤色（請參閱[聽寫](/zh-hant/features/dictation)） |
| 簡短表達 | 表情符號 |

**道地自然**會以母語人士的寫法，用相同的語言改寫你的文字。**潤飾電子郵件**會保留你自己的問候語、結尾敬辭與姓名，也不會加上簽名檔。**草擬回覆**會以所選電子郵件的語言與語氣撰寫回覆，並在姓名、日期或決定等它無法得知的地方，留下方括號中的簡短預留文字。

## 變更指令

開啟**設定 → AI 指令**，並在**內建**下選擇該指令。它的頁面會說明指令的作用，並提供**試試看**，讓你先用一些文字試跑。

| 設定 | 變更的內容 |
| --- | --- |
| **PopBar** | 將指令加入 PopBar 或從中移除 |
| **醒目標示修改** | 在結果中標示指令新增與移除的內容 |
| **快速鍵** | 對你在任何 App 中選取的文字執行該指令 |
| **行內模式** | 在沒有視窗的情況下執行，並將結果貼在你的選取內容上 |
| **完成後操作** | 指令完成後如何處理回答 |
| **AI 模型** | 此指令使用的模型。預設會跟隨所有 AI 指令使用的模型 |

內建指令的說明內容為唯讀。點按**自訂**即可建立你自己的副本，並可自由修改。

寫作工具會使用在**設定 → AI 指令 → 全部指令**中設定的模型，除非某個指令選擇了自己的模型。這些指令也同樣列在**設定 → 外掛程式 → 寫作工具**之下，而結果視窗中的**設定**按鈕會開啟產生該結果的指令。

## 取得可靠的結果

當改寫可能有多種方向時，請說明這段文字是寫給誰看的，以及它應該達成什麼目的。並指出哪些內容必須保持不變，例如名稱、日期、數字與引用的字句。

在送出之前，務必將結果與你的原文比對。即使行文流暢，也可能改變原意。

對於你重複使用的指示，請建立你自己的 [AI 指令](/zh-hant/features/ai-commands)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 指令不在 PopBar 上 | 點按 PopBar 末端的 **⌄**（放不下的按鈕會收在那裡），或在**設定 → AI 指令**中該指令的頁面上開啟 **PopBar** |
| PopBar 沒有出現 | 請參閱 [PopBar 疑難排解](/zh-hant/features/popbar) |
| 結果使用了意料之外的語言 | 解釋會以所選文字的語言回答。摘要會保留文字的語言，除非你設定其**回覆語言**。其他指令則會保留文字的語言 |
| 結果改變了原意 | 在貼上之前先編輯它，或用你的原文再次執行該指令 |

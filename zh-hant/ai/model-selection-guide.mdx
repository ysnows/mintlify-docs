你不必每次自己挑選：預設模型 [自動路由（Auto Route）](/zh-hant/providers/auto-route) 會為每一則訊息挑選合適的模型。當你想指定特定模型時，本頁能協助你選擇，並說明這項選擇會儲存在哪裡。

## 依任務選擇

| 任務 | 挑選重點 |
| --- | --- |
| 快速改寫與簡短回答 | 速度快、費用低的模型 |
| 多步驟代理程式作業 | 可靠的工具呼叫與推理能力 |
| 針對螢幕截圖或圖片提問 | 支援圖片輸入 |
| 長篇文件 | 較大的上下文視窗 |
| 保留在 Mac 本機的私密工作 | [本機模型](/zh-hant/ai/local-llm)，搭配本機執行的其他步驟服務供應商 |
| 語音對話 | [Live Talk](/zh-hant/features/live-voice)，擁有獨立的語音設定 |
| 生成圖片或影片 | 使用[圖片](/zh-hant/ai/image-generation)或[影片](/zh-hant/ai/video-generation)服務供應商，而非對話模型 |

模型選擇器會顯示你所選服務供應商目前提供的所有模型。支援極速模式（Fast mode）的模型會顯示 Fast mode 標籤，以較高的價格換取更快的執行速度。

## 使用推薦選項

設定中的模型選擇器會在最上方為該類任務提供三個建議：**最佳契合**、**最低成本** 與 **最佳品質**。每個建議都附帶簡短原因，以及每 100 萬輸入與輸出 tokens 的價格。在設定項目下方，如果目前選用的模型成本遠高於推薦模型，畫面還會顯示一行提示提醒你。

在 **新增代理程式** 中建立代理程式時，Enconvo 會閱讀代理程式的說明並推薦一個模型，同時在旁列出一個更便宜的模型與一個更強大的模型。點選即可套用。

## 預設模型的設定位置

- **新對話**：你在最上層的 **新對話** 中挑選的模型會成為該代理程式的預設模型。
- **專案**：在專案內開啟的新對話會使用該專案自己的模型。
- **現有對話**：對話一旦開始，除非你在該對話中手動切換，否則會維持原本的模型與推理強度。
- **未指定模型的對話與即時通訊管道**：會跟隨該代理程式的預設設定。

如果你在其他地方更改了預設值，送出訊息前請先確認對話裡目前顯示的模型名稱。

## 推理強度

推理強度決定模型在回答前思考多久。較高的強度面對難題時能給出更好的答案，但需要更長的時間並消耗更多 tokens。可選等級視模型而定；不具思考模式的模型則沒有強度設定。

## 上下文視窗

上下文視窗決定模型一次能讀取多少對話內容。當對話超過上限時，Enconvo 會將較早的部分壓縮。最高可容納 1M tokens 的 Claude 模型預設從 500K 開始，讓長對話能提早壓縮並節省費用。

若要變更某個模型的上下文視窗，請在 **設定 → AI 模型** 中開啟該服務供應商，點選 **模型名稱** 旁的 **管理模型**（齒輪圖示），編輯該模型並設定 **上下文視窗**。

## 選擇背景工作的模型

標題與摘要等小型背景工作會使用較輕量便宜的模型執行：包含對話標題、下一則建議、Live Talk、錄音標題與摘要、錄音翻譯與點子標題。預設情況下每個項目都設為 **自動（Auto）**，會採用小型模型：

- 對話標題、下一則建議與 Live Talk 會使用該對話所屬服務供應商的小型模型。因此使用你自己的 API 金鑰進行對話時，這些工作不會消耗 Enconvo Cloud 點數。
- 錄音與點子標題會使用你預設服務供應商的小型模型。
- 當服務供應商沒有 Enconvo 認識的小型模型時，Auto 會改用該對話的模型或你的預設模型。

如果你想親自挑選模型：

<Steps>
  <Step title="開啟任務模型">
    開啟 **設定 → AI 模型**，點選頁面頂端的 **任務模型**。
  </Step>
  <Step title="選擇任務">
    點選任一項任務。**自動（Auto）** 會顯示它針對每個服務供應商會選用的模型。
  </Step>
  <Step title="挑選模型">
    點選 **選擇模型**，挑選一個服務供應商，再選擇模型。
  </Step>
</Steps>

關閉 **下一則建議** 旁的開關，即可停止在每則回答後提供下一則訊息的建議。**全部重設為自動** 會將所有任務恢復為 **自動**。

## 用備用模型維持對話不中斷

當正在使用的模型無法使用時（例如達到用量上限、登入或金鑰失效，或無法連線），**後備** 能讓回覆接續完成。回覆會改由你的下一個備用模型繼續產生，對話中也會說明接手的模型與原因。

<Steps>
  <Step title="開啟後備">
    開啟 **設定 → AI 模型**，點選頁面頂端的 **後備**。
  </Step>
  <Step title="加入備用模型">
    點選 **新增備用模型** 並挑選一個模型。最多可加入三個，並可拖曳調整順序。
  </Step>
  <Step title="設定各備用模型的推理強度">
    對於支援推理等級的模型，選擇它的 **推理強度**。每個備用模型都會各自保留這項設定。
  </Step>
</Steps>

面板會呈現這條備援鏈的運作狀態：**使用中的模型** 排在第一，接著是你編號的備用模型，各別標示為 **就緒** 或 **已暫停**。點選任一備用模型的名稱即可改選同一服務供應商的另一個模型。在服務供應商清單中，設有備用模型的供應商會顯示 **備用 N** 標籤標明它在鏈中的順序。

| 設定 | 作用 |
| --- | --- |
| **服務繁忙時也切換** | 當重試次數用盡仍遇到速率限制與伺服器錯誤時，也會自動切換。 |
| **模型恢復正常後切回** | 一旦原本的模型恢復可用，就從下一輪對話起切回該模型，絕不在同一輪進行到一半時切換。 |

遭安全政策拒絕的請求絕不會觸發模型切換。

## 比較兩個模型

將同一項小而真實的任務分別交給兩個模型執行。檢查答案是否正確、工具是否確實完成，以及各自花費的時間與成本。每則回答下方的 **詳細資訊** 會顯示實際使用的模型、推理強度、token 數、耗時以及點數或費用。

---
title: "選擇模型"
description: "為工作挑選合適的模型，並了解 Enconvo 的預設模型在哪裡設定。"
---

你不必自己選擇：[自動路由](/zh-hant/providers/auto-route)這個預設模型，會為每則訊息挑選一個。當你想使用特定模型時，本頁協助你選擇，並說明選擇會儲存在哪裡。

## 依任務選擇

| 任務 | 尋找 |
| --- | --- |
| 快速改寫與簡短回答 | 快速、低成本的模型 |
| 多步驟的代理程式工作 | 可靠的工具呼叫與推理支援 |
| 關於螢幕截圖或圖片的問題 | 支援圖片輸入 |
| 長篇文件 | 較長的上下文視窗 |
| 留在你 Mac 上的私密工作 | [本機模型](/zh-hant/ai/local-llm)，其他步驟也使用本機服務供應商 |
| 語音對話 | [Live Talk](/zh-hant/features/live-voice)，它有自己的語音設定 |
| 建立圖片或影片 | [圖片](/zh-hant/ai/image-generation)或[影片](/zh-hant/ai/video-generation)服務供應商，而不是聊天模型 |

模型挑選器會顯示你的服務供應商目前提供的模型。支援快速模式的模型會顯示快速模式標籤，它能讓模型更快執行，但價格較高。

## 使用推薦

設定中的模型挑選器會先針對該類工作提供三項建議：**最合適**、**最省** 與 **最高品質**。每一項都會顯示簡短的理由，以及每 100 萬個 Token 的價格（輸入與輸出）。在設定下方，當你選擇的模型比推薦模型貴上許多倍時，會有一行文字告訴你。

當你在 **新增代理程式** 中建立代理程式時，Enconvo 會讀取代理程式的描述並建議一個模型，旁邊還附有一個較便宜與一個更強的選項。點按其中一個即可使用。

## 預設值在哪裡設定

- **新聊天**：你在頂層 **新增聊天** 中選擇的模型，會成為該代理程式的預設值。
- **專案**：專案內的新聊天會使用該專案自己的模型。
- **既有聊天**：聊天一旦開始，就會保留它的模型與推理強度，直到你在該聊天中變更為止。
- **沒有自己選擇的聊天，以及即時通訊管道**：這些會遵循代理程式的預設值。

在其他地方變更預設值之後，請在送出前檢查聊天中顯示的模型。

## 推理強度

推理強度決定模型在回答前思考多久。較高的強度能為困難的問題帶來更好的答案，但耗時較長，也會使用更多 Token。可用的等級取決於模型；沒有思考模式的模型沒有強度設定。

## 上下文視窗

上下文視窗是模型一次能讀取多少對話內容。當聊天超出它時，Enconvo 會壓縮較早的部分。可處理最高 1M Token 的 Claude 模型從 500K 開始，因此長聊天會更早壓縮，成本也更低。

若要變更模型的上下文視窗，請在 **設定 → AI 模型** 中開啟服務供應商，點按 **管理模型**（**模型名稱** 旁的齒輪），編輯該模型，並設定 **上下文視窗**。

## 為背景工作選擇模型

小型工作會在背景以便宜的模型執行：聊天標題、下一則訊息建議、Live Talk、錄音標題與摘要、錄音翻譯，以及想法標題。預設情況下，每一項都設為 **自動**，會使用小型模型：

- 聊天標題、下一則訊息建議與 Live Talk，使用該聊天自己服務供應商的小型模型。使用你自己 API 金鑰的聊天，不會為它們花費 Enconvo Cloud 點數。
- 錄音與想法標題，使用你預設服務供應商的小型模型。
- 當服務供應商沒有 Enconvo 已知的小型模型時，自動會使用該聊天的模型或你的預設模型。

若要自己挑選模型：

<Steps>
  <Step title="開啟任務模型">
    開啟 **設定 → AI 模型**，點按頁面頂端的 **任務模型**。
  </Step>
  <Step title="選擇任務">
    點按一項任務。**自動** 會顯示它為每個服務供應商挑選哪個模型。
  </Step>
  <Step title="挑選模型">
    點按 **選擇模型**，挑選服務供應商，再挑選模型。
  </Step>
</Steps>

關閉 **下一則建議** 旁的開關，就不會在每次回答後建議你的下一則訊息。**全部重設為自動** 會讓每項任務回到 **自動**。

## 以備用模型讓聊天持續進行

當回覆的模型無法使用時，例如達到使用上限、失去登入或金鑰，或無法連線，後備會讓回覆繼續進行。回覆會在你的下一個備用模型上繼續，聊天會說明是哪個模型接手以及原因。

<Steps>
  <Step title="開啟後備">
    開啟 **設定 → AI 模型**，點按頁面頂端的 **後備**。
  </Step>
  <Step title="新增備用模型">
    點按 **新增備用模型** 並挑選一個模型。最多可新增三個，並可拖曳來變更順序。
  </Step>
  <Step title="設定每個備用模型的強度">
    對於有推理等級的模型，請選擇它的 **推理強度**。每個備用模型各自保留自己的設定。
  </Step>
</Steps>

面板會顯示運作中的鏈：先是 **正在使用的模型**，然後是你編號的備用模型，每一個都標示 **已就緒** 或 **已暫停**。點按備用模型的名稱，即可將它切換為該服務供應商的另一個模型。在服務供應商清單中，每個擁有備用模型的服務供應商，會顯示一個 **備用 N** 標籤，標明它在鏈中的位置。

| 設定 | 功能 |
| --- | --- |
| **服務繁忙時也切換** | 在重試用盡後，遇到速率限制與伺服器錯誤時也會切換。 |
| **模型恢復後切換回去** | 在該模型恢復運作後，從下一回合起讓聊天回到它自己的模型，絕不會在回合進行中切換。 |

被安全政策拒絕的請求絕不會切換模型。

## 比較兩個模型

將同一個小而真實的任務送給兩者。檢查答案是否正確、工具是否完成，以及花了多少時間與費用。每則回覆下方的 **詳細資訊** 會顯示模型、強度、Token、時間，以及點數或費用。

---
title: "擷取網頁"
description: "讓你的代理程式根據網址讀取網頁，或將網頁儲存到知識庫中。"
---

當你已經有網址、想讓代理程式讀取網頁內容時，請使用「擷取網頁」。每個代理程式都能讀取你提供的連結；你可以自由選擇負責擷取的服務。如果你需要先搜尋相關網頁，請使用[網頁搜尋](/zh-hant/ai/web-search)。

## 選擇服務供應商

1. 開啟 **設定 → 擷取網頁**。
2. 挑選一個服務供應商並點擊 **設為預設**。

| 服務供應商 | 用途 |
| --- | --- |
| **Local Fetch** | 在你的 Mac 上免費擷取網頁，可選擇搭配瀏覽器輔助擷取 |
| **Jina AI Link Reader** | 透過 Jina 取得可讀內容 |
| **Firecrawl Link Reader** | 透過 Firecrawl 取得內容 |
| **DeepSeek** | 使用你自己的 DeepSeek API 金鑰將網頁讀取為 Markdown |
| **DeepSeek (Enconvo Cloud)** | 透過 Enconvo Cloud 將網頁讀取為 Markdown，無需 API 金鑰 |
| **Enconvo Cloud Plan** | 使用雲端連結讀取服務 |

## 讀取網頁

1. 將網址貼入對話中，並針對該網頁提出具體問題。
2. 在採用回答內容前，請先確認擷取到的內容與來源。

## 需要登入才能查看的網頁

搭配 **Local Fetch** 時，**瀏覽器輔助擷取** 可以透過已安裝 Enconvo 瀏覽器配套程式的 Chromium 核心瀏覽器來讀取網頁。

| 選項 | 作用 |
| --- | --- |
| **自動**（預設） | 重複使用你已經開啟的相符分頁，包含完整渲染內容與你的登入狀態。若直接擷取失敗或網頁需要 JavaScript，則使用暫時的背景分頁。 |
| **關閉** | 僅使用直接 HTTP 請求 |
| **永遠** | 一律透過瀏覽器擷取 |

若沒有連接瀏覽器，Local Fetch 會直接發起 HTTP 請求。其他服務供應商則只會擷取公開網址，無法使用你已登入的瀏覽器工作階段。若需操作互動式網頁，請使用[瀏覽器擴充功能](/zh-hant/features/browser-extension)或[使用瀏覽器](/zh-hant/features/browser-control)。

## 保存網頁內容

想留待日後查找某個網頁時，可以在[知識庫](/zh-hant/ai/knowledge-base)中使用 **新增 → 單一網頁** 加入網址。請確認匯入的網頁內容及其索引狀態；匯入之後，原本的網頁內容仍可能會有所變動。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 傳回的內容是空的 | 確認該網頁不需要額外互動即可閱讀，或改用 **Local Fetch** 並開啟 **瀏覽器輔助擷取**。登入畫面、被阻擋的請求、動態載入的內容以及不支援的網站，都可能導致無法擷取。 |
| 回答中提到了網頁上沒有的內容 | 請要求代理程式顯示它實際擷取到的內容，避免它自行猜測缺少的資訊。 |

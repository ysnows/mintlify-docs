---
title: "擷取網頁"
description: "讓你的代理程式透過網址讀取網頁，或將該頁面保存在知識庫中。"
---

當你已有網址，並希望代理程式讀取該頁面時，請使用擷取網頁。每個代理程式都能讀取你提供的連結；你可以選擇負責擷取的服務。如果需要先找出相關頁面，請使用[網頁搜尋](/zh-hant/ai/web-search)。

## 選擇供應商

1. 開啟**設定 → 擷取網頁**。
2. 選擇一個供應商，然後點按**設為預設**。

| 供應商 | 用途 |
| --- | --- |
| **Local Fetch** | 在你的 Mac 上免費擷取頁面，可選擇搭配瀏覽器輔助擷取 |
| **Jina AI Link Reader** | 透過 Jina 取得可讀的內容 |
| **Firecrawl Link Reader** | 透過 Firecrawl 取得內容 |
| **DeepSeek** | 使用你的 DeepSeek API 金鑰，將頁面讀取為 Markdown |
| **DeepSeek (Enconvo Cloud)** | 透過 Enconvo Cloud 將頁面讀取為 Markdown，不需要 API 金鑰 |
| **Enconvo Cloud Plan** | 使用 Cloud 的連結讀取服務 |

## 讀取頁面

1. 將網址貼到你的對話中，並針對該頁面提出具體的問題。
2. 在採信回答之前，請先檢查擷取到的內容與來源。

## 需要登入的頁面

使用 **Local Fetch** 時，**瀏覽器輔助擷取**可以透過安裝了 Enconvo Companion 擴充功能的 Chromium 系列瀏覽器來讀取頁面。

| 選項 | 作用 |
| --- | --- |
| **自動**（預設） | 重複使用你已開啟的相符分頁，內容已完整轉譯，並帶有你的登入狀態。當直接擷取失敗或頁面需要 JavaScript 時，會使用暫時的背景分頁。 |
| **關閉** | 僅使用直接的 HTTP |
| **永遠** | 一律透過瀏覽器擷取 |

若沒有已連接的瀏覽器，Local Fetch 會發出直接的 HTTP 請求。其他供應商則是擷取公開網址，無法取得你已登入的瀏覽器工作階段。對於互動式頁面，請使用[瀏覽器擴充功能](/zh-hant/features/browser-extension)或[使用瀏覽器](/zh-hant/features/browser-control)。

## 保存網頁內容

若希望日後能找到某個網址，請在[知識庫](/zh-hant/ai/knowledge-base)中使用**新增 → 單一網頁**加入它。請檢查已匯入的頁面及其索引狀態；網頁在你匯入之後可能會有所變動。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 傳回的內容是空的 | 確認頁面不需額外互動即可讀取，或使用搭配**瀏覽器輔助擷取**的 **Local Fetch**。登入畫面、被封鎖的請求、動態載入的內容與不支援的網站都可能導致無法擷取。 |
| 回答描述了頁面上沒有的內容 | 請代理程式出示它實際擷取到的內容，而不要對缺少的內容加以猜測。 |

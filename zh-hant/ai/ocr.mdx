---
title: "OCR"
description: "從螢幕的任何部分或圖片中複製文字，可在你的 Mac 上或透過線上服務辨識。"
---

OCR 會辨識截圖或圖片中的文字，讓你可以複製、貼上、翻譯，或針對它提問。當你無法選取文字時，例如圖片、影片畫面或掃描頁面中的文字，就可以使用它。你可以選擇由你的 Mac 還是由線上服務來辨識文字。

## 開始之前

Enconvo 需要螢幕錄製權限才能擷取你的螢幕。請參閱[權限](/zh-hant/configuration/permissions)。

## 從螢幕複製文字

1. 從 SmartBar 執行**截圖 OCR**。
2. 拖曳選取含有文字的區域。
3. 文字會在動態島中開啟。點按**複製**，或點按**貼上**（**⌘↩**）將它放進你正在使用的 App。

在同一個結果中，你也可以點按**翻譯**或**詢問 AI**。**⋯** 選單中有**保留原始換行**、**複製圖片**、**儲存圖片…**、**重新框選區域**、**加入知識庫**與 **OCR 設定…**。

若要用其他供應商重新辨識該區域，請點按文字上方的供應商名稱並選擇一個。當供應商知道每一行的位置時，可切換到圖片檢視，在截圖上選取各行，然後點按**複製所選**。

## 其他 OCR 指令

| 指令 | 作用 |
| --- | --- |
| **截圖 OCR** | 辨識螢幕區域，並在動態島中開啟文字 |
| **靜音截圖 OCR** | 辨識螢幕區域，並將文字複製到剪貼簿 |
| **OCR** | 辨識你提供的圖片中的文字 |
| **截圖翻譯** | 翻譯螢幕區域。請參閱[翻譯](/zh-hant/ai/translate) |
| **截圖解釋** | 解釋螢幕區域。請參閱[寫作工具](/zh-hant/features/writing-tools) |

## 選擇供應商

開啟**設定 → OCR**，選擇一個供應商，然後點按**設為預設**。

| 供應商 | 文字在哪裡辨識 |
| --- | --- |
| **Apple Native OCR** | 在你的 Mac 上，使用 Apple 自有的文字辨識 |
| **PP-OCRv6 (MLX)** | 在你的 Mac 上，於 Apple 晶片上使用 PaddleOCR 偵測與辨識模型。內容不會離開你的 Mac |
| **AI Model OCR** | 由你選擇的 AI 模型，依照它的**指令**辨識 |
| **Mistral OCR** | 由 Mistral 的線上服務，使用你的 Mistral 金鑰或 Mistral 登入 |
| **Mistral OCR (Enconvo Cloud Plan)** | 由 Mistral 的線上服務，透過你的 Enconvo Cloud 方案 |

每個 OCR 指令也可以使用自己的供應商：在**設定 → 外掛程式 → OCR** 下其設定中設定 **OCR 供應商**。各供應商的欄位請參閱[供應商目錄](/zh-hant/providers/catalog)。

## 取得更好的結果

擷取範圍要緊湊，並在文字容易閱讀的大小下進行。請手動檢查欄位、表格、標點符號、程式碼縮排，以及外觀相似的字元。

即使是 PDF 檔案，掃描的文件也可能需要 OCR。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 擷取畫面是空白的或無法開始 | 在[權限](/zh-hant/configuration/permissions)中檢查螢幕錄製權限 |
| **找不到文字** | 點按**重新框選區域**並選擇更緊湊的區域。手寫或風格化的字體使用**試試 AI 模型辨識**可能辨識得更好 |
| **無法辨識** | 點按**重試**，改試簡單的圖片，並閱讀供應商的錯誤訊息。**設定**會開啟 OCR 設定 |
| 各行黏在一起或在錯誤的位置斷行 | 在 **⋯** 選單中開啟或關閉**保留原始換行**，或用其他供應商重新辨識該區域 |
| 你想詢問螢幕上的內容，而不是複製其文字 | 使用 [Appshots](/zh-hant/features/appshots) 或[螢幕塗鴉](/zh-hant/features/screen-doodle) |

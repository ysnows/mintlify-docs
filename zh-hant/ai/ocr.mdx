OCR 能讀取螢幕截圖或圖片中的文字，方便你複製、貼上、翻譯或針對內容提問。當文字無法直接選取時（例如圖片、影片畫面或掃描頁面中的文字），就可以交給 OCR。你可以自行決定文字是在你的 Mac 本機辨識，還是透過線上服務處理。

## 開始之前

Enconvo 需要螢幕錄製權限才能擷取畫面。請參閱[權限](/zh-hant/configuration/permissions)。

## 從螢幕複製文字

1. 從 SmartBar 執行 **Screenshot OCR**。
2. 在螢幕上拖曳框選包含文字的區域。
3. 辨識出的文字會在動態島開啟。點選 **複製**，或點選 **貼上**（**⌘↩**）直接放入你正在使用的 App。

在同一個結果中，你也可以點選 **翻譯** 或 **詢問 AI**。**⋯** 選單則提供 **保留原始換行**、**複製圖片**、**儲存圖片…**、**重新框選區域**、**加入知識庫** 與 **OCR 設定…**。

如果想換另一個服務供應商重新辨識該區域，請點選文字上方的供應商名稱並重新挑選。當該供應商有回傳每一行的座標時，你可以切換到圖片檢視，直接在截圖上選取特定幾行，再點選 **複製選取內容**。

## 其他 OCR 指令

| 指令 | 用途 |
| --- | --- |
| **Screenshot OCR** | 辨識螢幕區域並在動態島開啟文字 |
| **Silent Screenshot OCR** | 辨識螢幕區域並直接將文字複製到剪貼簿 |
| **OCR** | 辨識你提供的圖片中的文字 |
| **Screenshot Translate** | 翻譯螢幕區域中的文字。請參閱[翻譯](/zh-hant/ai/translate) |
| **Screenshot Explain** | 解釋螢幕區域中的內容。請參閱[寫作工具](/zh-hant/features/writing-tools) |

## 選擇服務供應商

開啟 **設定 → OCR**，挑選一個服務供應商，然後點選 **設為預設**。

| 服務供應商 | 文字辨識位置 |
| --- | --- |
| **Apple Native OCR** | 在你的 Mac 本機上，使用 Apple 內建的文字辨識引擎 |
| **PP-OCRv6 (MLX)** | 在你的 Mac 本機上，使用在 Apple Silicon 上執行的 PaddleOCR 偵測與辨識模型，資料完全不會離開你的 Mac |
| **AI Model OCR** | 由你選取的 AI 模型依照其 **指示（Instruction）** 進行辨識 |
| **Mistral OCR** | 透過 Mistral 的線上服務辨識，使用你的 Mistral 金鑰或 Mistral 登入帳號 |
| **Mistral OCR (Enconvo Cloud Plan)** | 透過 Mistral 的線上服務辨識，使用你的 Enconvo Cloud 方案 |

每個 OCR 指令也能各自設定專屬的服務供應商：前往 **設定 → 外掛程式 → OCR**，設定該指令的 **OCR 供應商** 即可。各服務供應商的欄位說明請參閱[服務供應商目錄](/zh-hant/providers/catalog)。

## 獲得更佳辨識效果

框選範圍時盡量貼緊文字，並確保畫面上字體清晰易讀。欄位排版、表格、標點符號、程式碼縮排以及外觀相似的字元，建議以人工再核對一次。

掃描產生 PDF 檔案時，即使副檔名是 PDF，依然可能需要先進行 OCR 才能讀取文字。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 擷取畫面空白或無法啟動 | 在[權限](/zh-hant/configuration/permissions)中檢查螢幕錄製權限 |
| **找不到文字** | 點選 **重新框選區域**，改選更貼近文字的範圍。手寫或藝術字體可改試 **改用 AI Model OCR** |
| **無法讀取** | 點選 **重試**，換一張簡單的圖片測試，並查看供應商的錯誤訊息。點選 **設定** 可開啟 OCR 設定 |
| 文字行連在一起或斷行錯誤 | 在 **⋯** 選單開啟或關閉 **保留原始換行**，或換另一個服務供應商重新辨識該區域 |
| 你想針對畫面內容提問，而不是複製文字 | 請改用 [Appshots](/zh-hant/features/appshots) 或[螢幕塗鴉](/zh-hant/features/screen-doodle) |

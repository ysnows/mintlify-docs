記憶儲存你的代理程式在各個聊天之間保留的簡短事實，例如你的偏好、關於你的資訊，以及你做過的決定。每個代理程式都共用同一份記憶，並在每次聊天開始時讀取它們，已釘選的記憶會排在最前面。記憶不同於聊天逐字稿，也不同於存放文件的[知識庫](/zh-hant/ai/knowledge-base)。

你的記憶位於[知識庫](/zh-hant/ai/knowledge-base)內。在聊天視窗中，點擊側邊欄裡的 **知識庫**，並使用該欄頂端的 **知識庫** / **記憶** 切換開關即可檢視。記憶不會列在你的知識庫列表中，指向記憶的連結會在知識庫中開啟記憶。

**設定 → 記憶** 的頂端顯示了 **你的代理程式可以運用的內容**：你的記憶、聊天記錄、錄音和知識庫，以及各自的數量。

## 記憶如何儲存

代理程式在了解你的過程中儲存記憶。開啟 **自動從聊天中學習** 後，Enconvo 會在聊天安靜下來時回顧這段聊天：最後一則訊息三分鐘後，或累積了六則新訊息時。它會保留對之後的聊天有用的內容，並在該聊天末尾顯示一張帶有 **還原** 的記憶卡片。

學習會略過機密資訊、群組聊天和一次性任務。記憶不會用於即時通訊群組聊天，因為其他人也會看到回覆。

要自己新增一條，開啟 **設定 → 記憶**，點擊 **開啟記憶**，然後選擇 **新增 → 記憶**。

## 檢視與編輯記憶

1. 開啟 **設定 → 記憶** 並點擊 **開啟記憶**，或在聊天視窗中將知識庫切換為 **記憶**。
2. 使用 **篩選**、**標籤** 和 **類型** 縮小列表範圍，或在 **網格**、**列表** 和 **地圖** 之間切換。
3. 開啟一條記憶，檢視它的內容以及它是從哪個聊天中學到的。
4. 編輯不準確或過時的事實，或在檢視確認訊息後將其刪除。
5. 要讓某條記憶在每次聊天中都對代理程式顯示，右鍵點擊它並選擇 **釘選**。

請讓記憶條目保持簡潔、客觀，並明確說明涉及的人物或事物。

## 概念與地圖

在 **開啟記憶** 中選擇 **地圖**，可以看到記憶依其涉及的人物、專案、地點和主題分組顯示。每一個這樣的分組就是一個概念。

1. 點擊一個概念，檢視它的概覽、所屬記憶和相關概念。
2. 點擊 **就此提問**，開始一個關於它的聊天。
3. 要歸類仍在等待的記憶，點擊顯示等待數量的 **立即歸類 … 則** 按鈕。**重建** 會重新歸類每一條記憶：概念保留名稱，關聯會重新建立，空的概念會被移除。
4. **移除概念** 會移除該概念及其關聯，其中的記憶會保留。

記憶整理會在背景把新增和修改過的記憶歸類到概念下。當你就某個概念提問時，代理程式會完整閱讀它；當你在聊天中更正某個概念時，它們會重新命名或移除它。召回也能找到歸類在你提到的人物、專案或主題下的記憶，即使它們的措辭和你的問題不同。

## 設定

開啟 **設定 → 記憶**。

| 設定 | 作用 |
| --- | --- |
| **記憶**（頂端開關） | 為每個代理程式開啟或關閉記憶。關閉時不會學習、整理或召回任何內容，你的記憶會保留到你重新開啟時。 |
| **自動從聊天中學習** | 儲存關於你的事實、你的偏好以及你喜歡的做事方式。**最近學到的** 列出它保留的內容，並提供 **還原**。 |
| **整理記憶** | 在 Mac 閒置時合併重複項，在兩條互相矛盾的記憶中保留較新的一條，更新已過日期的計畫，並釘選代理程式絕不能遺漏的內容。每次更改都會保留較早的版本。 |
| **頻率** | **每天** 或 **每週** 整理一次。**立即整理** 會馬上執行。 |
| **更早的整理** | 還原整理在過去 90 天內做出的任何更改。 |
| **學習做法** | 讓技能像記憶學習事實那樣，學習你喜歡的任務完成方式。每次更改都會在聊天中顯示 **還原**，記憶審查和記憶整理也會照看技能。參閱[讓技能學習你的工作方式](/zh-hant/configuration/skills)。 |
| **召回** | 當回覆需要用到你說過或儲存過的內容時，代理程式尋找的範圍：**記憶**（始終開啟）、**聊天記錄**、**錄音** 和 **知識庫**。 |
| **搜尋** | 為記憶、聊天、錄音和知識庫建立索引的嵌入模型：**這台 Mac** 或 **Enconvo Cloud**。 |
| **記憶模型** | 學習和整理所用的輕量模型，在其服務供應商處依一般請求計費。 |

## 關於你

要向每個代理程式介紹你自己，請開啟 **設定 → 關於你**。你的所有代理程式、語音通話和虛擬形象都會使用這些資訊。

| 欄位 | 用途 |
| --- | --- |
| **首選稱呼** | 你的名字或暱稱，讓代理程式知道如何稱呼你。 |
| **個人簡介** | 關於你和你工作的簡短介紹。只新增你希望用於個人化回覆的內容。 |
| **回覆語言** | 代理程式回答所使用的語言。要為單一代理程式指定其他語言，請在其設定的 **行為** 下更改 **回覆語言**。 |

## 有意識地使用記憶

如果某個代理程式在自己的設定中關閉了 **Enable Memory**（啟用記憶），它就不會使用記憶。要測試某個事實是否會被重複使用，請開啟一個新聊天，提一個需要用到它的普通問題，而不要想當然地認為它已被儲存或召回。

不要為了省去重複輸入而儲存憑證或敏感資訊。根據代理程式和服務供應商的設定，模型請求中可能會包含召回的記憶。

## 記憶、知識與擷取

| 素材 | 最佳位置 |
| --- | --- |
| 可重複使用的簡短偏好或事實 | 記憶 |
| 文件與參考資料 | [知識庫](/zh-hant/ai/knowledge-base) |
| 一個隨口說出的想法 | [語音筆記](/zh-hant/features/voice-notes) |
| 其他 App 中可見的內容 | [快速擷取](/zh-hant/features/quick-capture) |
| 臨時的討論 | [聊天](/zh-hant/ai/chat) |

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 回答用到了過時的事實 | 在 **開啟記憶** 中找到這條記憶並更正或刪除它，而不只是更正某一則回覆。同時檢查目前對話的上下文。 |
| 代理程式什麼都不記得 | 確認 **設定 → 記憶** 中的 **記憶** 已開啟，並且該代理程式的 **Enable Memory** 已開啟。即時通訊群組聊天從不使用記憶。 |
| Enconvo 儲存了你不想儲存的內容 | 點擊聊天末尾記憶卡片上的 **還原**，或在 **設定 → 記憶** 的 **最近學到的** 中還原。 |
| 整理改動了你想保留的記憶 | 在 **設定 → 記憶** 中開啟 **更早的整理**，還原該更改。 |

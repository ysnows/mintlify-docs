記憶存放代理程式在各次聊天中保留的簡短事實，例如你的偏好、關於你的資訊，以及你做過的決定。每個代理程式共用同一份記憶，並在每次聊天開始時看到它們，已釘選的排在最前面。記憶不同於聊天記錄，也不同於存放文件的[知識庫](/zh-hant/ai/knowledge-base)。

這部影片介紹記憶、關於你、知識庫與快速擷取。

你的記憶位於[知識庫](/zh-hant/ai/knowledge-base)之中。在聊天視窗的側邊欄中點按**知識庫**，再使用其欄位頂端的**知識庫** / **記憶**切換開關即可查看。記憶不會列為你的知識庫之一，而指向記憶的連結會開啟切換到記憶的知識庫。

**設定 → 記憶**的頂端會顯示**你的代理程式可以運用的內容**：你的記憶、聊天記錄、錄音與知識庫，以及各自的數量。

## 記憶如何被儲存

代理程式會在認識你的過程中儲存記憶。開啟**自動從聊天中學習**後，Enconvo 會在聊天安靜下來之後回顧它：最後一則訊息之後三分鐘，或累積了六則新訊息時。它會保留日後聊天中會用到的內容，而**設定 → 記憶**中的**最近學到的**會列出每項變更，並附上**還原**。

學習時會略過機密資訊、群組聊天與一次性的任務。記憶不會出現在 IM 群組聊天中，因為其他人會讀到那裡的回覆。

若要自行新增，請開啟**設定 → 記憶**，點按**開啟記憶**，然後選擇**新增 → 記憶**。

## 檢視與編輯記憶

1. 開啟**設定 → 記憶**並點按**開啟記憶**，或在聊天視窗中將知識庫切換到**記憶**。
2. 使用**篩選**、**標籤**與**類型**縮小清單範圍，或在**網格**、**列表**與**地圖**之間切換。
3. 開啟某則記憶，檢視其內容以及學到它的聊天。
4. 編輯不正確或過時的事實，或在檢視確認訊息後將其刪除。
5. 若要讓代理程式在每次聊天中都看到某則記憶，請在其上按一下滑鼠右鍵並選擇**釘選**。

請保持條目簡潔、具事實性，並明確說明它與誰或什麼有關。

## 概念與地圖

在**開啟記憶**中選擇**地圖**，即可看到你的記憶依其所涉及的人物、專案、地點與主題分組。其中每一項都是一個概念。

1. 點按某個概念，即可查看它的概覽、它的記憶以及相關概念。
2. 點按**就此提問**，開始一則關於它的聊天。
3. 若要歸檔仍在等待的記憶，請點按會顯示等待數量的**立即歸檔 …**按鈕。**重建**會再次歸檔每一則記憶：概念會保留名稱，連結會重新建立，空的概念則會被移除。
4. **移除概念**會移除該概念及其連結，其記憶則會保留。

記憶整理會在背景將新增與變更的記憶歸檔到各個概念之下。當你詢問某個概念時，代理程式會完整讀取它；當你在聊天中修正某個概念時，它們會將其重新命名或移除。召回也能找到歸檔在你所指的人物、專案或主題之下的記憶，即使它們的用詞與你的問題不同。

## 設定

開啟**設定 → 記憶**。

| 設定 | 作用 |
| --- | --- |
| **記憶**（頂端的切換開關） | 為每個代理程式開啟或關閉記憶。關閉時，不會學習、整理或召回任何內容，而你的記憶會保留，待你重新開啟時使用。 |
| **自動從聊天中學習** | 儲存關於你的事實、你的偏好，以及你喜歡的做事方式。**最近學到的**會列出它保留的內容，並附上**還原**。 |
| **整理記憶** | 在你的 Mac 閒置時，合併重複項目、在兩則互相矛盾的記憶中保留較新的一則、更新日期已過的計畫，並釘選代理程式絕不能漏掉的內容。每項變更都會保留先前的版本。 |
| **頻率** | 整理的頻率為**每天**或**每週**。**立即整理**會馬上執行。 |
| **更早的整理** | 還原整理在過去 90 天內所做的任何變更。 |
| **學習做法** | 讓技能學習你喜歡的任務做法，就像記憶學習事實一樣。每項變更都會在聊天中顯示並附上**還原**，而記憶回顧與記憶整理也會照顧技能。請參閱[讓技能學習你的工作方式](/zh-hant/configuration/skills)。 |
| **召回** | 當回覆需要你說過或儲存過的內容時，代理程式會到哪裡尋找：**記憶**（一律開啟）、**聊天記錄**、**錄音**與**知識庫**。 |
| **搜尋** | 為記憶、聊天、錄音與知識庫建立索引的嵌入模型：**這台 Mac** 或 **Enconvo Cloud**。 |
| **記憶模型** | 學習與整理所使用的輕量模型，依其供應商以與其他請求相同的方式計費。 |

## 關於你

若要讓每個代理程式了解你，請開啟**設定 → 關於你**。你所有的代理程式、語音通話與 Avatar 都會使用它。

| 欄位 | 用途 |
| --- | --- |
| **慣用名稱** | 你的名字或暱稱，讓代理程式知道該如何稱呼你。 |
| **個人簡介** | 關於你與你工作的簡短介紹。只需加入你希望用來個人化回覆的內容。 |
| **回覆語言** | 代理程式回答時使用的語言。若要讓某個代理程式使用其他語言，請在其設定的**行為**下變更它的**回覆語言**。 |

## 審慎使用記憶

在自身設定中關閉了**啟用記憶**的代理程式不會使用記憶。若要測試某項事實是否會被重複使用，請開啟新的聊天並提出需要它的一般問題，而不要假設它已被儲存或召回。

請不要為了省去重新輸入而儲存憑證或敏感資訊。視代理程式與供應商設定而定，模型請求可能包含被召回的記憶。

## 記憶、知識與擷取

| 資料 | 最適合的位置 |
| --- | --- |
| 簡短且可重複使用的偏好或事實 | 記憶 |
| 文件與參考資料 | [知識庫](/zh-hant/ai/knowledge-base) |
| 一個隨口說出的想法 | [語音備註](/zh-hant/features/voice-notes) |
| 其他 App 中可見的內容 | [快速擷取](/zh-hant/features/quick-capture) |
| 暫時性的討論 | [聊天](/zh-hant/ai/chat) |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 回答使用了舊的事實 | 在**開啟記憶**中找到該則記憶並加以修正或刪除，而不是只修正某一則回覆。也請檢查目前對話的上下文。 |
| 代理程式什麼都不記得 | 確認**設定 → 記憶**中的**記憶**已開啟，且該代理程式的**啟用記憶**也已開啟。IM 群組聊天絕不會使用記憶。 |
| Enconvo 儲存了你不想要的內容 | 在**設定 → 記憶**的**最近學到的**下點按**還原**。 |
| 整理更動了你想保留的記憶 | 開啟**設定 → 記憶**中的**更早的整理**，並還原該變更。 |

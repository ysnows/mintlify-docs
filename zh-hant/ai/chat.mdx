聊天視窗是 Enconvo 用於持續對話的主要空間。當任務需要不只一次回答時，就使用聊天視窗：選擇一個代理程式，加入所需的素材，並將相關的聊天集中在一起。按下 **⌃⌘X** 即可開啟。

其他任務場景：快速提問或執行指令可使用 [SmartBar](/zh-hant/features/smartbar)，在特定 App 旁工作可使用 [App 側邊欄](/zh-hant/features/app-sidebar)，處理選取文字可使用 [PopBar](/zh-hant/features/popbar)，或使用[動態島](/zh-hant/features/dynamic-island)與[桌面寵物](/zh-hant/features/pet)作為常駐於螢幕上的精簡入口。[視窗管理](/zh-hant/features/window-management)比較了這些視窗的差異。

下方影片將在 2 分鐘內帶你瀏覽聊天視窗：選擇代理程式、為單一聊天切換模型與權限、加入檔案、選擇要製作的成果、提問與追問，以及重新找回你的聊天。

## 開始對話

1. 按下 **⌃⌘X**，或從 Enconvo 開啟**聊天視窗**。點擊**新增聊天**（**⌘N**）開始新對話。它會從你上次選擇的專案啟動；若要建立一般聊天，請在專案選擇器中選擇**沒有專案**。
2. 選擇由誰回答：點擊輸入框上方的代理程式卡片，或點擊聊天頂部的代理程式名稱。預設為 Mavis；卡片中也包含如 Writer 與 Researcher 等代理程式，以及如 Codex 和 Claude Code 等程式開發代理程式。
3. 檢查輸入框下方的標籤。模型標籤顯示此聊天所使用的模型；點擊它可僅針對目前聊天切換模型。盾牌標籤設定代理程式在行動前何時向你確認：**替我核准**只會在執行高風險步驟前詢問。
4. 點擊 **+** 加入檔案、圖片或螢幕截圖。若要製作特定類型的成果，請在輸入框下方的**做點什麼**列中選擇類型：**投影片**、**文件**、**設計**、**動作**、**儀表板**、**網頁**、**圖片**或**影片**。在專案中開啟的新聊天也會顯示這一列。參閱[作品](/zh-hant/features/artifacts)。
5. 輸入你的請求並按下 Return。回答會串流顯示在聊天中；若代理程式使用了工具，你可以在回覆中追蹤其進度。
6. 在同一個聊天中繼續追問。它會記住先前的對話，因此像「改成一天版」這樣簡短的請求就足夠了。

若要在你的另一台已配對電腦上開啟這個聊天，請使用訊息框中的**執行於**標籤挑選電腦；你輸入的內容會一併帶過去。參閱[其他電腦](/zh-hant/integrations/other-computers)。

請提出完整的要求。「用五個要點總結附加的提案，並列出待決問題」能同時告訴代理程式要讀取什麼，以及要回傳什麼。

你可以隨時從聊天標題列的代理程式名稱更換目前聊天的代理程式；SmartBar 與 App 側邊欄都有相同的選擇器。若要將對話交給[程式開發代理程式](/zh-hant/ai/coding-agents)，請用它開啟一個新聊天來繼續。當你分支（Fork）一個聊天時，可以挑選由哪個代理程式接手。

### 傳送前最佳化你的請求

輸入請求後，點擊麥克風旁的魔杖圖示（**增強提示詞**）。目前聊天使用的模型會結合既有的對話內容，將它改寫得更清楚、更完整，並把只有你知道的細節保留為 `[placeholders]` 佔位符。點擊**還原**（或按 **⌘Z**）可取回原本的文字，或點擊**再試一次**產生另一版改寫。

在你切換查看其他聊天時，訊息框會保留每個聊天尚未傳送的文字與附件，回來時草稿依然會在。當你編輯較早的訊息時，它附帶的圖片與檔案會連同文字一起回到訊息框中，讓你在傳送前移除或新增項目。

### 使用 Vim 按鍵編輯

在**設定 → 一般**的**鍵盤**下開啟 **Vim 模式**，或在訊息框中輸入 `/vim`。麥克風旁會顯示模式標籤，在 Normal 與 Visual 模式下會變成藍色。這兩種模式會以英文鍵盤配置輸入，切回 Insert 模式時則會恢復你原本使用的輸入法。

## 在代理程式運作時與它對話

你不需要乾等漫長的任務全部結束。

| 若要 | 這樣做 |
| --- | --- |
| 向執行中的任務補充內容 | 直接輸入並按下 Return。當你開始輸入或附加內容時，**停止**按鈕會變回**傳送**。代理程式會在下一個步驟讀取你的訊息。 |
| 排入訊息，待任務結束後傳送 | 按下 **⌘Return**，或按住 **⌘** 同時點擊**傳送**。 |
| 停止任務 | 點擊**停止**，或連按兩次 **Esc**。單次誤觸不會結束任務。 |

代理程式在繼續撰寫與執行工具的同時，Enconvo 會判斷你的新訊息是否需要改變方向，因此可以稍候的追問不會中斷並捨棄目前的步驟。與目前任務無關的請求會交給背景執行的子代理處理，原代理程式則繼續進行手邊的工作。

登入、安裝或提問卡片不會阻塞聊天：如果你直接傳送訊息而不回覆該卡片，聊天仍會繼續。

模型思考時，回覆中會顯示**正在思考…**以及目前經過的時間。

當任務結束時，代理程式的總結會先說明結果，再列出變更項目、檢查過的內容，以及需要你留意的事項。

## 設定目標

給代理程式一個終點狀態，它就會一輪接一輪持續運作，直到檢查確認目標已達成。

1. 輸入 `/goal` 後接任務完成時應符合的狀態，或從 **+** 選單中選擇**設定目標**。
2. 傳送。目標與已執行時間會顯示在訊息框上方。
3. 使用目標列來編輯、清除或繼續目標。目標進行期間，**+** 選單會提供**修改目標**。

## 使用臨時對話

對於不想留存記錄的一次性提問，可以在新聊天上開啟虛線氣泡開關（**臨時對話**）。App 側邊欄與動態島都有相同的開關。開啟時開關呈藍色，訊息框會呈現虛線邊框並帶有**臨時對話**標籤。

臨時對話不會進入聊天歷史記錄，不會儲存任何[記憶](/zh-hant/ai/memory)，並在離開時刪除。如果你之後還是想保留它，請點擊橫幅上的**保留對話**，它就會變成一般聊天。

## 選擇回覆的呈現方式

每個代理程式都有預設的回覆風格與智能介面（Intelligent UI）等級，決定它是否傾向以圖表、表格與卡片回答。若要針對單一聊天變更設定，請開啟 **+** 選單並選擇**使用風格**。挑選一種風格（例如**標準**）或智能介面等級，並選擇**用於所有**該代理程式的聊天，即可設為該代理程式的預設值。關於風格與等級，請參閱[代理程式](/zh-hant/ai/agents)。

回覆中的連結會顯示為帶有網站圖示的卡片。地圖連結會顯示包含地點名稱的真實地圖；多個地點會共用一張帶編號的地圖，路線則會顯示路徑線以及時間和距離。參閱[視覺化回答](/zh-hant/features/visual-answers)。

## 認識介面配置

側邊欄左側是一條窄長圖示欄，中間欄會跟隨所選項目切換內容。

- 圖示欄最上方是**聊天**（會以琥珀色數字顯示需要你處理的聊天數），接著是**排程工作**、**知識庫**與**外掛程式**。**看板**、**作品**、**媒體**等其他入口則放在 **···** 選單中。你的外掛程式位於分隔線下方，裝置切換器與「設定」選單則在最底部。「設定」選單也包含說明連結、**新功能**與**側邊欄捷徑**。
- 在圖示欄中選擇一個位置，中間欄就會顯示其分區、篩選條件與主要操作。**聊天**會回到你上次離開的位置。技能與 MCP 伺服器會從**外掛程式**直接在視窗內開啟。
- 按下 **⌥⌘1** 至 **⌥⌘9** 可依序開啟圖示欄上的入口。**⌘B** 可隱藏中間欄並保留圖示欄。
- **返回**與**前進**會記住你造訪過的頁面以及在每個頁面選取的分區。按住**返回**可查看列表。

### 自訂側邊欄

開啟 **···** 選單，或在圖示欄上的任意圖示點擊右鍵，選擇**自訂側欄…**。挑選要在圖示欄上顯示的入口並拖曳排序。你也可以將外掛程式拖曳到分隔線上方與常用入口並列，或拖回下方，並釘選或取消釘選任何入口或外掛程式。

### 捷徑

將最常開啟的頁面、專案與連結釘選到側邊欄。開啟側邊欄底部的「設定」選單，選擇**側邊欄捷徑**並新增項目。它們會顯示在**捷徑**群組中，你可以拖曳調整順序、重新命名或移除。

### 裝置切換器

側邊欄一次只顯示一台電腦。底部的裝置切換器會在本機與已配對的其他電腦之間切換，顯示其他電腦上等待處理的事項，並能在獨立視窗中開啟其中任何一台。**管理**位於**裝置**標題旁，**加入裝置**則可配對電腦、新增 SSH 主機或配對手機。參閱[其他電腦](/zh-hant/integrations/other-computers)、[配對你的手機](/zh-hant/integrations/pair-your-phone)與[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

每次更新後首次使用 Enconvo 時，側邊欄中的卡片會提供該版本的更新介紹影片。「設定」選單中的**新功能**會在**設定 → 教學**中開啟全部影片。

### 作品

**···** 選單中的**作品**會列出代理程式為你製作的網頁、文件與設計。在卡片或列表列上點擊右鍵可**開啟**、**重新命名**、**複製連結**、開啟製作它的聊天，或**刪除**。按住 **⌘** 或 **⇧** 點擊可複選並一併刪除，且支援**還原**。從未寫入任何內容的空白作品不會列在其中。

要分享網頁作品，點擊**發佈**。它會透過 Enconvo Cloud 上線至你專屬的 `name.site.enconvo.com` 連結，並可選填密碼保護。你也可以請代理程式為你發佈單一頁面或整個網站資料夾。

## 整理你的聊天

側邊欄會列出你最近的聊天，而專案則能在支援的地方將相關聊天歸類在一起。每個聊天都會儲存下來：點擊側邊欄中的**搜尋**（**⌘G**）即可依對話內容尋找聊天。開啟聊天的選單可進行**重新命名聊天**、**釘選聊天**、**移動到專案**、**封存聊天**或**刪除聊天記錄**。刪除聊天記錄前請先確認提示內容。

- 頂部的**進行中**只會彙整仍在等你處理、執行中，或有你尚未開啟的結果或失敗訊息的聊天，並各自標示專案與狀態。它的每一列操作方式與聊天列表相同：滑鼠懸停會出現**釘選**與**封存**，右鍵開啟選單，雙擊重新命名，或在觸控板上滑動封存。將游標移至群組標題上方可點擊**全部標為已讀**。
- 列表底部的**手機聊天記錄**存放你在 iPhone 或 Android 手機上開啟的聊天。可以在 Mac 上繼續對話；刪除其中一筆會同步刪除兩端記錄。參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。
- 代理程式在向 Codex、Claude Code 或其他代理程式求助時所開啟的聊天不會直接出現在列表中。你可以從發出請求的聊天內對應項目列開啟它。只要它仍處於開啟、釘選或等待你回覆的狀態，仍會佔有一列。
- 每個[排程工作](/zh-hant/workflows/scheduled-jobs)最近一次的執行記錄會在啟動後立即帶著時鐘標記顯示於列表中。
- **已釘選**群組可以摺疊，Worktree 所在的列也可以摺疊。
- 聊天旁的紫色旋轉圖示代表它的主要回覆已完成，但由它啟動的子代理或背景任務仍在執行中。其中的藍色圓點表示有新的回覆尚未閱讀。

### 一次操作多個聊天

1. 使用 **⌘** 點擊、**Shift** 點擊，或點擊列上的**選取**來挑選聊天。**⌘A** 可全選整個群組。
2. 使用出現的工具列將它們標為已讀（**⇧⌘U**）、封存（**E**）或刪除（**⌫**）。

刪除前會先詢問確認，列出選取的聊天、停止仍在執行的任務，並提供**改為封存**選項。標為已讀與封存都可以還原。

### 模型選擇

頂層的**新增聊天**可以設定代理程式的預設模型。專案內的新聊天會使用該專案的模型偏好設定。每個聊天都可以保留自己的模型與推理覆寫設定。在變更其他聊天也在使用的預設值前，請先閱讀[模型選擇](/zh-hant/ai/model-selection-guide)。

如果某個聊天的模型用完了 Enconvo Cloud 點數，請將該聊天切換至 Enconvo Cloud 以外的模型，並點擊點數用盡卡片上的**改用 … 重試**，以該模型重新執行訊息。若希望聊天能自動切換至備用模型，請在**設定 → AI 模型**中設定**後備**；參閱[用備用模型讓聊天不中斷](/zh-hant/ai/model-selection-guide)。

### 在 Worktree 中工作

在屬於 Git 儲存庫的專案中，聊天可以在主工作目錄與 Worktree 之間切換。使用聊天標題後的標籤即可切換，或直接請代理程式操作。聊天會帶著它修改的檔案一起移動，合併 Worktree 後變更就會回到主工作目錄。每次移動都會在對話中留下一行記錄。參閱[專案](/zh-hant/ai/projects)。

## 加入上下文與檔案

只加入該請求所需要的來源。檔案附件、螢幕擷取、知識庫查詢與瀏覽器頁面，各自會為代理程式提供不同類型的上下文。關於如何選擇來源請參閱[上下文感知](/zh-hant/features/context-awareness)，關於代理程式能對你的檔案進行哪些操作請參閱[檔案與資料夾](/zh-hant/ai/file-tools)。

- 訊息框在**權限**後方設有**即時螢幕**與[螢幕塗鴉](/zh-hant/features/screen-doodle)按鈕。即時螢幕專屬於你開啟它的那個視窗；其標籤會顯示已開啟狀態，點擊一下即可關閉。
- 輸入 `@` 可提及檔案、代理程式，或你的好友與團隊成員。當你點名某個人時，代理程式就會知道你指的是誰，便能在你要求時私訊對方、讀取其回覆，或撥打電話給他。
- 較大的影片或音訊檔案會以逐字稿或筆記的形式傳送給模型。資料夾與空檔案無法作為附件加入。

[記憶](/zh-hant/ai/memory)與[知識庫](/zh-hant/ai/knowledge-base)負責不同的任務：記憶存放代理程式會重複使用的事實，知識庫則儲存供它查閱的資料。兩者皆可從側邊欄圖示欄上的**知識庫**開啟，該欄頂部設有**知識庫** / **記憶**切換開關。

## 閱讀與重複使用回覆

展開回覆的執行細節即可查看每次工具呼叫及其結果。在回覆下方，**複製**、**朗讀**與**更多**可對該回覆執行操作。[視覺化回答](/zh-hant/features/visual-answers)能將圖表與互動內容直接放進回覆中。

程式碼區塊設有**複製**與自動換行按鈕，讓長行文字可以直接折行而不需橫向捲動。若要在所有回覆中套用自動換行，請在**設定 → 一般**的**外觀**下開啟**程式碼自動換行**。

透過連結分享聊天時，在聊天上傳的同時就能立即複製連結。之後點擊**更新連結**只會傳送有變更的內容。

代理程式為你開啟的網頁與檔案會顯示在聊天旁的側邊面板中。每個聊天都會記住你上次留下的面板開啟或關閉狀態。從未開啟過面板的聊天會先停在**新增**分頁，提供面板中的各種工具。面板中的各個分頁共用你拖曳調整的寬度；關閉最後一個分頁即會關閉面板。

| 分頁 | 快速鍵 | 顯示內容 |
| --- | --- | --- |
| **拉取請求** | **⌃⇧P** | 在於 GitHub 儲存庫中工作的聊天裡：顯示該分支的 Pull Request 及其檢查、審核與評論，或從 Worktree 聊天直接建立 Pull Request。 |
| **裝置** | **⌃⇧M** | 在完成一次性設定後，於聊天旁即時查看並控制 iOS 模擬器或 Android 模擬器。 |

若想用說的代替打字，可使用[聽寫](/zh-hant/features/dictation)透過語音輸入文字，或使用 [Live Talk](/zh-hant/features/live-voice) 進行雙向語音對話。

## 當 Enconvo 重新啟動時

若更新、結束應用程式或當機導致聊天在任務中途停止，Enconvo 恢復運行後該聊天會自動繼續。它會先檢查已經完成的部分再處理剩餘步驟，並把先前正在執行的子代理也帶回來。

## 設定

開啟**設定 → 聊天視窗**。

| 設定 | 作用 |
| --- | --- |
| **預設代理程式** | 聊天視窗中新聊天啟動時使用的代理程式。若你刪除了該代理程式，新聊天會恢復使用 Mavis。 |
| **外觀** | **淺色**、**深色**或**跟隨應用程式**。 |
| **快速鍵** | 從任何應用程式開啟聊天視窗。預設為 **⌃⌘X**。其他視窗的**在聊天視窗中開啟**按鈕也會顯示你所設定的按鍵。 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 回覆使用了錯誤的模型 | 檢查此聊天的模型選擇以及該代理程式的預設設定。 |
| 聊天顯示由另一個模型接手 | 當該聊天的模型無法使用時，會由**設定 → AI 模型**中的備用模型代為回答。一旦原模型恢復運作，聊天就會切回原本的模型。 |
| 代理程式看不到檔案或螢幕 | 檢查聊天的附件以及[權限](/zh-hant/configuration/permissions)。 |
| 某個工具無法使用 | 請檢查代理程式設定中的**工具與技能**，而不是換句話重複送出相同的請求。參閱[代理程式](/zh-hant/ai/agents)。 |
| 列表中找不到你要找的聊天 | 查看**進行中**與**手機聊天記錄**，或使用**搜尋**（**⌘G**）。代理程式自行開啟的聊天需從發出請求的聊天中開啟。 |
| 聊天顯示**無法顯示此對話** | 點擊**重新載入對話**。在此期間，聊天列表與訊息框仍可正常運作。 |

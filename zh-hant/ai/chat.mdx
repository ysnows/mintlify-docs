聊天視窗是 Enconvo 進行持續對話的主要空間。當工作需要不只一個答案時就用它：你選擇代理程式、加入它需要的素材，並把相關的聊天放在一起。按下 **⌃⌘X** 即可開啟。

其他情況請使用：[SmartBar](/zh-hant/features/smartbar) 處理快速提問或指令、[App 側邊欄](/zh-hant/features/app-sidebar)在某個 App 旁工作、[PopBar](/zh-hant/features/popbar) 處理選取的文字，或是[動態島](/zh-hant/features/dynamic-island)與[桌面寵物](/zh-hant/features/pet)這類常駐螢幕的小型入口。[視窗管理](/zh-hant/features/window-management)會將它們全部做比較。

下方的影片用 2 分鐘導覽聊天視窗：選擇代理程式、為單一聊天切換模型與權限、加入檔案、選擇要製作的內容、提問與追問，以及再次找到你的聊天。

## 開始對話

1. 按下 **⌃⌘X**，或從 Enconvo 開啟**聊天視窗**。按一下**新增聊天**（**⌘N**）開始新的聊天。它會從你上次選擇的專案開始；若要一般聊天，請在它的專案選擇器中選擇**沒有專案**。
2. 選擇由誰回答：按一下輸入框上方的代理程式卡片，或聊天頂端的代理程式名稱。預設為 Mavis；卡片中也有 Writer 與 Researcher 等代理程式，以及 Codex 與 Claude Code 等程式設計代理。
3. 檢查輸入框下方的標籤。模型標籤顯示此聊天使用的模型；按一下它即可僅為此聊天切換模型。盾牌標籤設定代理程式在行動前何時向你確認：**替我核准**只會在有風險的步驟之前詢問。
4. 按一下 **+** 加入檔案、圖片或螢幕截圖。若要製作特定內容，請在輸入框下方的**做點什麼**列中選擇一種類型：**投影片**、**文件**、**設計**、**動作**、**儀表板**、**網頁**、**圖片**或**影片**。專案內的新聊天也有這一列。請參閱 [Artifacts](/zh-hant/features/artifacts)。
5. 輸入你的要求並按下 Return。答案會即時串流到聊天中；如果代理程式使用工具，可在回覆中查看它們的進度。
6. 在同一個聊天中繼續追問。它會記得對話內容，所以像「改成一日版」這樣簡短的要求就夠了。

若要在你另一台已配對的電腦上開始聊天，請用訊息框中的**執行於**標籤選擇它；你輸入的內容會一併帶過去。請參閱[其他電腦](/zh-hant/integrations/other-computers)。

請要求完整的結果。「用五個重點摘要附件中的提案，並列出尚未解決的問題」同時告訴代理程式要閱讀什麼、以及要回傳什麼。

你之後可以從聊天標頭中的代理程式名稱變更聊天的代理程式；SmartBar 與 App 側邊欄也有相同的選擇器。若要把對話交給[程式設計代理](/zh-hant/ai/coding-agents)，請與它開一個新聊天繼續。當你分支一個聊天時，你可以選擇由哪個代理程式接續。

### 在傳送前改善你的要求

輸入要求後，按一下麥克風旁的魔杖（**強化提示詞**）。聊天本身的模型會參考目前為止的對話，將它改寫成更清楚、更完整的要求，並為只有你才知道的細節留下 `[placeholders]`。按一下**還原**（或按 **⌘Z**）即可取回你原本的文字，或按**再試一次**取得另一種改寫。

當你查看其他聊天時，訊息框會保留每個聊天尚未傳送的文字與附件，所以你回來時草稿仍在。當你編輯較早的訊息時，它的圖片與檔案會連同文字一起回到訊息框，讓你在傳送前可以移除其中一個或加入另一個。

### 使用 Vim 按鍵編輯

在**設定 → 一般**的**鍵盤**下開啟 **Vim 模式**，或在訊息框中輸入 `/vim`。麥克風旁的標籤會顯示目前的模式，在 Normal 與 Visual 模式下會變成藍色。這些模式使用英文鍵盤配置輸入，而 Insert 模式會還原你先前使用的輸入法。

## 在代理程式工作時與它對話

你不必等長時間的任務完成。

| 想要 | 做法 |
| --- | --- |
| 為正在執行的任務補充內容 | 輸入並按下 Return。一旦你輸入或附加了內容，**停止**按鈕會變回**傳送**。代理程式會在下一個步驟讀取你的訊息。 |
| 將訊息排入佇列，等任務結束後再送出 | 按 **⌘Return**，或在按一下**傳送**時按住 **⌘**。 |
| 停止任務 | 按一下**停止**，或按兩次 **ESC**。不小心按一次不會結束任務。 |

在 Enconvo 判斷你的訊息是否應該改變方向的同時，代理程式會繼續撰寫並執行它的工具，因此可以稍後處理的追問不會丟掉目前的步驟。與任務無關的要求會交給在背景工作的子代理程式，而代理程式則繼續執行。

登入、安裝或提問卡片不會阻擋聊天：如果你傳送訊息而不是回答它，聊天會繼續進行。

模型思考時，回覆會顯示**正在思考…**以及目前為止經過的時間。

任務結束時，代理程式的摘要會先說明結果，接著列出變更了什麼、檢查了什麼，以及哪些事項需要你注意。

## 設定目標

給代理程式一個最終狀態，它會一輪接一輪持續工作，直到檢查確認目標已達成。

1. 輸入 `/goal`，後面接上工作完成時應該成立的條件，或從 **+** 選單選擇**設定目標**。
2. 傳送。目標會連同已執行的時間顯示在訊息框上方。
3. 使用目標列來編輯、清除或繼續目標。目標進行中時，**+** 選單會提供**修改目標**。

## 使用臨時聊天

對於不想保留的一次性問題，請在新聊天中開啟虛線氣泡開關（**臨時對話**）。App 側邊欄與動態島也有相同的開關。開啟時，開關會變成藍色，訊息框的邊緣會變成虛線，並帶有**臨時對話**標籤。

臨時聊天不會出現在你的聊天記錄中、不會儲存[記憶](/zh-hant/ai/memory)，且在你離開時就會被刪除。若最後想保留它，請按一下橫幅上的**保留對話**；它就會變成一般聊天。

## 選擇回覆的外觀

每個代理程式都有預設的回覆風格與智慧介面等級，決定它多常以圖表、表格與卡片來回答。若要為單一聊天變更，請開啟 **+** 選單並選擇**使用風格**。選擇一種風格（例如**標準**）或智慧介面等級，並選擇**全部套用**，即可將它設為該代理程式所有聊天的預設值。風格與等級請參閱[代理程式](/zh-hant/ai/agents)。

回覆中的連結會以帶有網站圖示的卡片顯示。地圖的連結會顯示帶有地點名稱的真實地圖；多個地點共用一張編號的地圖，而路線會顯示它的線條以及時間與距離。請參閱[視覺化回答](/zh-hant/features/visual-answers)。

## 熟悉介面

側邊欄左側有一條窄的圖示列，以及一個跟隨它的中間欄。

- 圖示列的開頭是**聊天**，它會以琥珀色數字顯示需要你處理的聊天數量，接著是**已排程**、**知識庫**與**外掛程式**。**看板**、**作品**、**媒體**與其他位置則收在 **···** 選單中。你的外掛程式位於一條線的下方，裝置切換器與設定選單則在底部。設定選單也包含說明連結、**新功能**與**側邊欄捷徑**。
- 在圖示列上選擇一個位置，中間欄就會顯示它的區段、篩選條件與主要動作。**聊天**會回到你上次離開的地方。技能與 MCP 伺服器可從**外掛程式**直接在視窗中開啟。
- 按 **⌥⌘1** 到 **⌥⌘9**，依序開啟圖示列上顯示的項目。**⌘B** 會隱藏中間欄並保留圖示列。
- **返回**與**前進**會記住你造訪過的位置，以及你在每個位置選擇的區段。按住**返回**可以看到它們的清單。

### 自訂側邊欄

開啟 **···** 選單，或在圖示列的圖示上按右鍵，然後選擇**自訂側欄…**。選擇要在圖示列上顯示哪些位置，並將它們拖曳成你要的順序。將外掛程式拖到線的上方，就會與各位置並列；拖回下方則會放回原處。你也可以釘選或取消釘選任何位置或外掛程式。

### 捷徑

將你最常開啟的頁面、專案與連結釘選到側邊欄。開啟側邊欄底部的設定選單，選擇**側邊欄捷徑**，然後加入項目。它們會顯示在**捷徑**群組中，你可以在那裡拖曳排序、重新命名或移除。

### 裝置切換器

側邊欄一次只顯示一台電腦。位於底部的裝置切換器可在這台電腦與你已配對的電腦之間切換、顯示其他電腦上等待處理的事項，並可在各自的視窗中開啟任何一台。**管理**位於**裝置**標題旁，而**加入裝置**可配對電腦、加入 SSH 主機，或配對手機。請參閱[其他電腦](/zh-hant/integrations/other-computers)、[與手機配對](/zh-hant/integrations/pair-your-phone)與[電腦與 SSH 主機](/zh-hant/integrations/computers-and-ssh-hosts)。

更新後第一次使用 Enconvo 時，側邊欄中的一張卡片會提供該版本的更新影片。設定選單中的**新功能**會在**設定 → 教學**中開啟所有影片。

### Artifacts

**···** 選單中的**作品**會列出你的代理程式製作的頁面、文件與設計。在卡片或列上按右鍵，可以**開啟**、**重新命名**、**複製連結**、開啟製作它的聊天，或**刪除**。按住 **⌘** 或 **⇧** 點按可選取多個一起刪除，並可**還原**。你從未寫入內容的空白作品不會列出。

若要分享頁面作品，請按一下**發佈**。它會在 Enconvo Cloud 上以你自己的 `name.site.enconvo.com` 連結上線，並可選擇設定密碼。你也可以請代理程式替你發佈頁面或網站資料夾。

## 整理你的聊天

側邊欄會列出你最近的聊天，在可用的地方，專案會將相關的聊天放在一起。每個聊天都會被儲存：按一下側邊欄中的**搜尋**（**⌘G**），即可依對話內容找到聊天。開啟聊天的選單可以**重新命名聊天**、**釘選聊天**、**移動到專案**、**封存聊天**或**刪除聊天記錄**。刪除聊天記錄之前，請先閱讀確認訊息。

- 頂端的**已啟用**只收集仍需要你處理、正在執行，或有你尚未開啟的結果或失敗的聊天，並附上各自的專案與狀態。它的列與聊天清單的運作方式相同：將游標移上去可看到**釘選**與**封存**，按右鍵開啟選單，連按兩下可重新命名，或在觸控式軌跡板上滑動即可封存。將游標移到群組上可以**全部標為已讀**。
- 清單底部的**手機聊天記錄**收納你在 iPhone 或 Android 手機上開始的聊天。你可以在 Mac 上繼續它們；刪除其中一個會在兩邊同時刪除。請參閱[手機聊天](/zh-hant/integrations/iphone-phone-chats)。
- 你的代理程式在向 Codex、Claude Code 或其他代理程式求助時所開始的聊天不會列出。請從提出請求的聊天中的那一行開啟。它在開啟、已釘選或等待你回答期間，仍會有一列。
- 每個[排程工作](/zh-hant/workflows/scheduled-jobs)的最新執行，會在開始後立即以時鐘標記顯示在清單中。
- **已釘選**群組可以收合，工作樹的列也可以。
- 聊天上的紫色轉圈表示它的回覆已完成，但它啟動的子代理程式或背景任務仍在執行。其中的藍點表示有新的回覆可閱讀。

### 同時處理多個聊天

1. 用 **⌘** 點按、**Shift** 點按，或使用某一列的**選取**來選擇聊天。**⌘A** 會選取整個群組。
2. 使用出現的工具列將它們標為已讀（**⇧⌘U**）、封存（**E**），或刪除（**⌫**）。

刪除前會先詢問、列出這些聊天、停止仍在執行的聊天，並提供**改為封存**。標為已讀與封存都可以還原。

### 模型選擇

最上層的**新增聊天**可以設定代理程式的預設模型。專案內的新聊天使用該專案的模型偏好。每個聊天都可以保留自己的模型與推理覆寫。在你變更其他聊天所使用的預設值之前，請先閱讀[模型選擇](/zh-hant/ai/model-selection-guide)。

如果聊天的模型用完了 Enconvo Cloud 點數，請將聊天切換到 Enconvo Cloud 以外的模型，並在點數不足卡片上按一下**改用其他模型重試**，以便用它重新執行該訊息。若要讓聊天自動切換到備用模型，請在**設定 → AI 模型**中設定**後備**；請參閱[用備用模型讓聊天持續運作](/zh-hant/ai/model-selection-guide)。

### 在工作樹中工作

在屬於 git 儲存庫的專案中，聊天可以在主要檢出與工作樹之間移動。請使用聊天標題後面的標籤，或請它的代理程式處理。聊天會連同它變更的檔案一起移動，合併工作樹後就會回到主要檢出。每次移動時，對話中都會多出一行說明。請參閱[專案](/zh-hant/ai/projects)。

## 加入上下文與檔案

只加入請求所需的來源。檔案附件、螢幕擷取、知識庫查詢與瀏覽器頁面，各自為代理程式提供不同種類的上下文。請參閱[上下文感知](/zh-hant/features/context-awareness)選擇來源，並參閱[檔案與資料夾](/zh-hant/ai/file-tools)了解代理程式能對你的檔案做什麼。

- 訊息框在**權限**之後有**即時螢幕**與[螢幕塗鴉](/zh-hant/features/screen-doodle)的按鈕。即時螢幕屬於你開啟它的那個視窗；它的標籤顯示它已開啟，按一下即可關閉。
- 輸入 `@` 可提及檔案、代理程式，或你的朋友與團隊成員。當你指名某個人時，代理程式知道你指的是誰，因此在你要求時，可以私下傳訊息給對方、讀取對方的回覆，或打電話給對方。
- 大型影片或音訊檔案會以逐字稿或備註的形式交給模型。資料夾或空檔案無法附加。

[記憶](/zh-hant/ai/memory)與[知識庫](/zh-hant/ai/knowledge-base)的用途不同：記憶存放代理程式會重複使用的事實，而知識庫則儲存供它查詢的素材。兩者都可從側邊欄圖示列上的**知識庫**開啟，其欄位頂端有**知識庫** / **記憶**切換開關。

## 閱讀與重複使用回覆

展開回覆的工作詳細資料，即可查看每次工具呼叫及其結果。回覆下方的**複製**、**朗讀**與**更多**會對該回覆執行動作。[視覺化回答](/zh-hant/features/visual-answers)可以將圖表與互動內容直接放進回覆中。

程式碼區塊有**複製**與換行按鈕，讓過長的行可以換行，而不必左右捲動。若要讓每則回覆中的程式碼都換行，請在**設定 → 一般**的**外觀**下開啟**程式碼自動換行**。

當你以連結分享聊天時，連結在聊天上傳的同時就可以立即複製。之後，**更新連結**只會傳送有變更的部分。

代理程式為你開啟的頁面與檔案會顯示在聊天旁的側邊面板中。每個聊天都會依你離開時的樣子保持面板開啟或關閉。從未開啟過它的聊天會從**新增**分頁開始，該分頁提供面板的工具。它的分頁共用你拖曳設定的寬度，關閉最後一個分頁就會關閉面板。

| 分頁 | 快速鍵 | 顯示內容 |
| --- | --- | --- |
| **拉取請求** | **⌃⇧P** | 在 GitHub 儲存庫中工作的聊天：該分支的拉取請求及其檢查、審查與留言，或從工作樹聊天建立拉取請求。 |
| **裝置** | **⌃⇧M** | 經過一次性設定後，可在聊天旁觀看與控制的 iOS 模擬器或 Android 模擬器。 |

若想用說的取代打字，請使用[聽寫](/zh-hant/features/dictation)以語音撰寫，或使用 [Live Talk](/zh-hant/features/live-voice) 進行雙向口語對話。

## 當 Enconvo 重新啟動時

如果更新、結束或當機讓聊天在任務進行到一半時停止，Enconvo 回來之後，聊天會自動繼續進行。它會先檢查自己已經做了什麼，再完成其餘部分，並恢復它先前正在執行的子代理程式。

## 設定

開啟**設定 → 聊天視窗**。

| 設定 | 變更的內容 |
| --- | --- |
| **預設代理程式** | 聊天視窗中新聊天預設使用的代理程式。如果你刪除該代理程式，新聊天會回到 Mavis。 |
| **外觀** | **淺色**、**深色**或**跟隨應用程式**。 |
| **快速鍵** | 從任何 App 開啟聊天視窗。預設為 **⌃⌘X**。其他視窗的**在聊天視窗中開啟**按鈕會顯示你設定的按鍵。 |

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 回覆使用了錯誤的模型 | 除了代理程式的預設值，也請檢查此聊天的模型選擇。 |
| 聊天顯示由另一個模型接手 | 在聊天的模型無法使用期間，**設定 → AI 模型**中的備用模型代為回答。聊天的模型恢復正常後，會切換回它自己的模型。 |
| 代理程式看不到檔案或螢幕 | 檢查聊天的附件與[權限](/zh-hant/configuration/permissions)。 |
| 某個工具無法使用 | 檢查代理程式設定中的**工具和技能**，而不是重複換個說法提出相同的要求。請參閱[代理程式](/zh-hant/ai/agents)。 |
| 清單中找不到你要的聊天 | 檢查**已啟用**與**手機聊天記錄**，或使用**搜尋**（**⌘G**）。代理程式為自己開始的聊天，請從提出請求的聊天中開啟。 |
| 聊天顯示**無法顯示此對話** | 按一下**重新載入對話**。在此期間聊天清單與訊息框仍可正常運作。 |

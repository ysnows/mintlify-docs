title: "文字轉語音"
description: "讓 Enconvo 朗讀文字給你聽，或將文字轉換成音訊檔案。"
---

Enconvo 提供兩個語音相關指令。**朗讀**（Read Aloud）會透過動態島上的朗讀播放器為你唸出文字。**TTS(Text To Speech)** 則會使用你選擇的服務供應商，將文字轉換成音訊檔案。你也可以直接在對話中讓系統為你朗讀聊天回覆。

## 朗讀聊天回覆

點擊回覆下方的揚聲器按鈕。該按鈕會變成一個小型播放器，提供暫停、繼續與停止控制項，同時正在唸出的句子會在回覆中反白標示。同一時間只會朗讀一則回覆，關閉聊天視窗就會停止朗讀。

若要讓每則回覆自動朗讀，請在 SmartBar 或聊天視窗中開啟朗讀回覆功能。兩個視窗各自保留獨立的設定。

## 朗讀文字

1. 開啟**設定 → 文字轉語音**，設定一個服務供應商與語音。
2. 選取文字並執行**朗讀**（Read Aloud）。
3. 動態島上的播放器會逐句唸出內容。你可以用它暫停、繼續或停止、倒退或快轉、調整語速或語音，並顯示文字且反白目前朗讀到的句子。
4. 若該服務供應商支援，可在其設定中調整語音或語速。

當桌面上開啟了[虛擬形象](/zh-hant/features/avatar)時，虛擬形象會配合嘴型朗讀文字，動態島上的播放器則會保持精簡模式。

## 建立音訊檔案

搭配你想轉成語音的文字執行 **TTS(Text To Speech)**。檢視所提供之服務供應商、語音、語速與輸出格式選項，然後開啟生成的檔案確認發音與節奏。

[TTS 服務供應商目錄](/zh-hant/providers/catalog)列出了 Enconvo Cloud、直接連線服務、macOS 系統語音與本機選項。**Enconvo Cloud Voice** 是 Enconvo Cloud 自有的語音服務，支援超過 60 種語言且無需 API 金鑰。DeepSeek 提供女聲（Stella）與男聲（Tide）朗讀文字，可使用你自己的 DeepSeek API 金鑰或選擇 **DeepSeek (Enconvo Cloud)**。各服務供應商提供的控制項不盡相同：部分支援風格指令或情感表現標籤，其他則提供固定語音清單。

## 複製聲音

ElevenLabs、Fish Audio、Gemini 與 Qwen3 支援複製聲音。在**設定 → 文字轉語音**的服務供應商列表中，它們都會帶有專屬標誌。

1. 開啟**設定 → 文字轉語音**，挑選上述其中一個服務供應商，並開啟它的**聲音複製**分頁。
2. 上傳一段錄音，或點擊**錄製**並唸出畫面上顯示的文字。倒數計時可以取消，音量表會即時跟隨你的聲音，單次錄製會在 5 分鐘後自動結束。
3. 試聽你複製出來的聲音，接著就能在同一個分頁中使用、重新命名或刪除它。

你也可以點擊這些服務供應商**語音**選單旁的**複製聲音**。你複製的聲音會顯示在**語音**選單最上方，也能在那裡重新命名或刪除。

該分頁會顯示你為該服務供應商還剩餘多少個 Cloud 語音名額。達到上限時，刪除一個即可再複製新的聲音。如果在錄製期間關閉設定視窗，錄音會停止並保留已錄下的內容。

## 本機與雲端語音

本機服務供應商直接在你的 Mac 上運行，需要支援的硬體與模型檔案：Kokoro 與 Qwen3 在 MLX 上運行，而英文語音 Phonon 則可在搭載 Apple silicon 且執行 macOS 15 或更新版本的 Mac 上透過 Core ML 運行。**系統**（System）會使用 macOS 內建的語音。線上服務供應商——包含無需 API 金鑰的項目——都會透過網路傳送你的文字。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有聲音 | 檢查系統輸出裝置，以及播放是否處於暫停狀態。 |
| 生成失敗 | 檢查你的服務供應商存取權限，以及文字的長度和格式。 |
| 朗讀停止並提示服務供應商沒有 API 金鑰 | 在**設定 → 文字轉語音**中加入金鑰，或挑選在 Enconvo Cloud 或你 Mac 上運行的語音。 |
| 專有名詞發音不準確 | 先測試較短的樣本，並嘗試調整該服務供應商的發音或風格控制項。 |

---
title: "文字轉語音"
description: "讓 Enconvo 朗讀文字，或把文字轉成音訊檔案。"
---

Enconvo 有兩個語音指令。**朗讀**會在動態島的朗讀播放器中把文字念給你聽。**TTS(Text To Speech)** 則使用你選擇的供應商，把文字轉成音訊檔案。你也可以直接在對話中讓聊天回覆念給你聽。

## 朗讀聊天回覆

點選回覆下方的喇叭按鈕。按鈕會變成一個小播放器，有暫停、繼續和停止，而正在朗讀的句子會在回覆中醒目標示。一次只會朗讀一則回覆，關閉聊天就會停止。

若要朗讀每一則回覆，請在 Smart Bar 或聊天視窗中開啟朗讀回覆。每個視窗各自保有自己的設定。

## 朗讀文字

1. 開啟**設定 → 文字轉語音**，並設定供應商和聲音。
2. 選取文字並執行**朗讀**。
3. 動態島上的播放器會逐句朗讀。你可以用它暫停、繼續或停止、向前或向後跳、更改速度或聲音，並顯示標示出目前句子的文字。
4. 若供應商支援，可在供應商的設定中調整聲音或速度。

當[虛擬形象](/zh-hant/features/avatar)開啟時，它會一邊對嘴一邊朗讀文字，播放器則在動態島上維持精簡。

## 建立音訊檔案

以你想念出的文字執行 **TTS(Text To Speech)**。檢查它提供的供應商、聲音、速度和輸出格式，然後開啟產生的檔案，確認發音和節奏。

[TTS 供應商目錄](/zh-hant/providers/catalog)列出了 Enconvo Cloud、直連服務、macOS 系統和本機的選項。**Enconvo Cloud Voice** 是 Enconvo Cloud 自家的聲音，支援 60 多種語言，不需要 API 金鑰。DeepSeek 以女聲（Stella）或男聲（Tide）朗讀文字，可使用你自己的 DeepSeek API 金鑰，或以 **DeepSeek (Enconvo Cloud)** 使用。各家的控制項不同：有些供應商接受風格指示或表情標籤，有些則提供固定的聲音清單。

## 複製聲音

ElevenLabs、Fish Audio、Gemini 和 Qwen3 可以複製聲音。它們在**設定 → 文字轉語音**的供應商清單中會顯示徽章。

1. 開啟**設定 → 文字轉語音**，選擇其中一個供應商，並開啟它的**聲音複製**分頁。
2. 上傳一段錄音，或點選**錄製**並朗讀顯示的文字。倒數可以取消，音量表會跟著你的聲音變化，單次錄製會在 5 分鐘後自動結束。
3. 播放你複製的聲音，然後在同一個分頁中使用、重新命名或刪除它。

你也可以點選這些供應商的**語音**選單旁的**複製聲音**。你複製的聲音會顯示在**語音**選單的最上方，你也可以在那裡重新命名或刪除。

分頁會顯示你在該供應商還剩下多少個雲端聲音名額。達到上限時，請先刪除一個才能再複製另一個。如果你在錄製時關閉設定視窗，錄製會停止並保留已錄下的內容。

## 本機和雲端聲音

本機供應商在你的 Mac 上執行，需要支援的硬體和模型檔案：Kokoro 和 Qwen3 在 MLX 上執行，而英文聲音 Phonon 則在搭載 Apple 晶片、macOS 15 以上的 Mac 上以 Core ML 執行。**系統**使用 macOS 內建的聲音。線上供應商（包括不需要 API 金鑰的供應商）會透過網路傳送你的文字。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 沒有聲音 | 檢查系統的輸出裝置，以及播放是否處於暫停狀態。 |
| 產生失敗 | 檢查你對該供應商的存取權限，以及文字的長度和格式。 |
| 朗讀停止並顯示供應商沒有 API 金鑰 | 在**設定 → 文字轉語音**中加入金鑰，或選擇在 Enconvo Cloud 或你的 Mac 上執行的聲音。 |
| 名字念錯 | 用較短的樣本測試，並試試供應商的發音或風格控制項。 |

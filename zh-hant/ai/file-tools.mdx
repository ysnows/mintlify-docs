檔案工具讓代理程式可以尋找檔案、搜尋檔案內容、讀取檔案並編輯檔案。將代理程式指向某個資料夾或檔案，並用平常的話提問；它會挑選合適的工具，並顯示它使用了什麼。

## 開始之前

- **工作資料夾：**代理程式的**工作資料夾**位於其設定的**定義**部分，是相對路徑的起點。
- **核准：**聊天中的**權限**標籤決定代理程式何時要先詢問。選擇**請求核准**時，它在編輯工作資料夾以外的檔案之前會先詢問。讀取與搜尋則絕不會詢問。請參閱[核准操作](/zh-hant/ai/agents)。

## 從唯讀任務開始

1. 在代理程式的設定中，檢查它的檔案工具與它的**工作資料夾**。
2. 在聊天中，指定一個資料夾，或附上你想使用的檔案。
3. 提出有範圍的問題，例如「找出這個專案中的 Markdown 檔案並摘要 README。」
4. 在要求它變更任何內容之前，先查看代理程式所使用的檔案與工具輸出。

## 各工具的作用

| 工具 | 作用 |
| --- | --- |
| Glob | 依路徑樣式尋找檔案，例如 `**/*.md`，最新的排在前面 |
| Grep | 搜尋檔案內的文字，附有檔案樣式與行號 |
| Read File | 讀取文字檔、從文件中擷取文字，並讀取圖片、音訊與影片 |
| Edit File | 取代檔案中的確切文字，並回報它變更的行 |
| Write File | 建立檔案，或取代其全部內容 |

<Warning>
Write File 可能會在沒有警告的情況下覆寫既有的檔案。重要的文件請保留副本或使用版本控制，並在核准之前檢查目的地與變更內容。代理程式在聊天中變更的檔案會列在側邊面板的**變更**分頁中，並附有**還原**。
</Warning>

## 文件與媒體

讀取 PDF、Office 文件、圖片、音訊檔或影片時，可能會執行解析、OCR 或轉錄，而不是傳回原始位元組。對於音訊與影片，代理程式會讀取逐字稿。在試算表中，公式儲存格會讀取為它的值，若從未計算過，則讀取為公式本身。可使用哪些格式取決於已安裝的工具與你設定的供應商。請參閱 [OCR](/zh-hant/ai/ocr)、[語音轉寫](/zh-hant/features/transcription)與[知識庫](/zh-hant/ai/knowledge-base)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 存取錯誤 | 檢查代理程式的**工作資料夾**、**權限**標籤與 macOS 權限 |
| 文件讀取為空白 | 檢查檔案類型以及它是否可被解析。掃描的 PDF 可能需要 OCR |
| 編輯找不到它應該取代的文字 | 請代理程式在編輯之前，再次讀取目前的檔案 |

檔案工具讓代理程式能夠尋找檔案、搜尋檔案內容、讀取檔案並進行編輯。只要將代理程式指向某個資料夾或檔案，並用自然語言提出要求，它就會自行選用合適的工具，並向你展示它使用了什麼。

## 開始之前

- **工作資料夾**：位於代理程式設定的**定義**區段，是所有相對路徑的起點。
- **核准**：聊天中的**權限**標籤決定了代理程式何時需要先詢問你。設定為**請求核准**時，在編輯工作資料夾以外的檔案前都會先詢問；讀取與搜尋則永遠不會詢問。參閱[核准操作](/zh-hant/ai/agents)。

## 從唯讀任務開始

1. 在代理程式的設定中，確認它的檔案工具以及**工作資料夾**。
2. 在聊天中指定一個資料夾，或附上你想處理的檔案。
3. 提出一個範圍明確的問題，例如「找出這個專案裡的 Markdown 檔案並摘要 README」。
4. 先檢視代理程式存取了哪些檔案以及工具輸出內容，再請它進行任何修改。

## 各工具的功能

| 工具 | 作用 |
| --- | --- |
| Glob | 依路徑模式尋找檔案，例如 `**/*.md`，最新的檔案排在最前 |
| Grep | 搜尋檔案內的文字內容，提供檔案匹配模式與行號 |
| Read File | 讀取文字檔案、擷取文件中的文字，以及讀取圖片、音訊與影片 |
| Edit File | 精確替換檔案中的指定文字，並回報修改了哪些行 |
| Write File | 建立新檔案，或取代整個檔案的內容 |

<Warning>
Write File 可能會直接覆寫既有檔案而不再另行警告。對於重要文件，請先保留備份或使用版本控制，並在核准前確認目標路徑與修改內容。代理程式在單一聊天中修改過的檔案會列在側面板的**變更**分頁中，並附有**還原**按鈕。
</Warning>

## 文件與媒體

讀取 PDF、Office 文件、圖片、音訊檔案或影片時，系統可能會執行解析、OCR 或語音轉寫，而不是直接回傳原始位元組資料。處理音訊與影片時，代理程式讀取的是逐字稿。在試算表中，帶有公式的儲存格會讀取其計算結果數值；若從未計算過，則讀取公式本身。實際支援哪些格式取決於已安裝的工具與你設定的服務供應商。參閱 [OCR](/zh-hant/ai/ocr)、[語音轉寫](/zh-hant/features/transcription)與[知識庫](/zh-hant/ai/knowledge-base)。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 發生存取錯誤 | 檢查代理程式的**工作資料夾**、**權限**標籤，以及 macOS 系統權限 |
| 讀取文件時內容為空 | 檢查檔案類型以及是否可被解析。掃描版的 PDF 可能需要先經過 OCR 辨識 |
| 編輯時找不到要替換的文字 | 請代理程式先重新讀取一次目前的檔案內容，再進行編輯 |

---
title: "本機模型"
description: "在你自己的硬體上執行模型，並讓整個任務都留在你的 Mac 上。"
---

當你希望聊天內容保持私密，或想在沒有供應商帳號的情況下使用時，可以在你的 Mac 或你擁有的另一台電腦上執行模型。Enconvo 內建一個引擎，也能連接 Ollama 和 LM Studio。

## 選擇執行環境

| 執行環境 | 最適合 | 設定方式 |
| --- | --- | --- |
| [本機 LLM（MLX）](/zh-hant/providers/mlx) | 在搭載 Apple 晶片且執行 macOS 15 或更新版本的 Mac 上，於 Enconvo 內執行模型 | 在設定中選擇並下載模型 |
| [Ollama](/zh-hant/providers/ollama) | 你已經用 Ollama 管理的模型，位於這台 Mac 或伺服器上 | 啟動 Ollama 並設定它的位址 |
| [LM Studio](/zh-hant/providers/lm-studio) | 你已經在 LM Studio 中使用的模型，位於這台 Mac 或伺服器上 | 啟動 LM Studio 的伺服器並設定它的位址 |

## 從小處開始

1. 設定好執行環境，並下載或載入一個模型。
2. 傳送一則簡短的文字訊息。
3. 確認可以運作後，再加入文件或工具。
4. 在嘗試更大的模型之前，先觀察記憶體用量和速度。**設定 → 本機模型**會顯示這台 Mac 上的模型及其記憶體用量。

模型大小、量化方式、上下文長度和其他正在執行的工作，都會影響記憶體。請以模型選擇器顯示的大小為準，而不要套用固定的經驗法則。

## 讓整個任務都留在本機

只使用本機聊天模型，並不代表所有內容都留在你的 Mac 上。語音辨識、文字轉語音、OCR、文件解析、嵌入、重新排序、搜尋和 MCP 工具，各自使用自己的供應商。Enconvo 為其中幾項提供了本機供應商；[供應商目錄](/zh-hant/providers/catalog)中有完整列表。

**設定 → 本機模型**會顯示哪些功能在這台 Mac 上執行、哪些在雲端執行。網頁搜尋和其他線上服務仍然需要網際網路，而本機模型仍可能呼叫會把內容傳出你 Mac 的工具。

## 使用另一台電腦上的模型伺服器

請將伺服器設為接受網路連線，並把 Enconvo 的 **BaseUrl** 設為那台電腦的位址。`localhost` 永遠指的是執行 Enconvo 的這台 Mac。如果 macOS 封鎖連線，請在**系統設定 → 隱私權與安全性 → 區域網路**中開啟 Enconvo。

## 使用其他模型伺服器

若要使用 llama.cpp、vLLM、KoboldCpp 或 text-generation-webui 這類伺服器，請在**設定 → AI 模型**底部按一下**新增供應商**，然後選擇**相容 OpenAI**。將伺服器位址貼上作為基礎網址；Enconvo 接受有或沒有 `/v1` 的寫法，貼上完整端點也可以。如果伺服器不檢查金鑰，請將 API 金鑰留空。

## 小上下文中的長聊天

本機伺服器常以比模型所允許的更小的上下文來執行模型。Enconvo 會讀取 Ollama、llama.cpp、LM Studio、KoboldCpp 和 text-generation-webui 實際使用的上下文，並壓縮聊天內容以符合限制。在小上下文中，它會分段摘要較長的聊天。若要讓模型有更多空間，請在伺服器本身的設定中調高上下文長度。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 模型忘了長聊天的開頭 | 伺服器使用的上下文很小。請在伺服器設定中調高上下文長度，或開始新的聊天。 |
| 模型忽略工具或圖片 | 它不支援這些功能，所以 Enconvo 會在沒有它們的情況下回答。請選擇支援工具呼叫或圖片輸入的模型。 |
| 連線失敗 | 請閱讀錯誤訊息：Enconvo 會顯示伺服器本身的訊息並指出原因。請確認伺服器正在執行，且位址和連接埠正確。 |

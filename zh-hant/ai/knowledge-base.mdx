---
title: "知識庫"
description: "收集文件、筆記、網頁與資料夾，接著在對話中搜尋並針對內容提問。"
---

知識庫用來保存你希望 Enconvo 日後能找得到的資料：參考文件、專案筆記、儲存的網頁與語音筆記。當你指定它，或問題需要其中內容時，代理程式就會搜尋它。[記憶](/zh-hant/ai/memory)則不同：它保存的是代理程式跨對話為你記住的簡短事實。

## 開啟知識庫

- 在聊天視窗中，點選側邊欄的 **知識庫**。
- 或開啟 **設定 → 知識庫** 並點選任一個知識庫。
- 或從 Enconvo 的選單列選單選擇 **顯示知識庫視窗**，它會在聊天視窗中開啟知識庫。

你的[記憶](/zh-hant/ai/memory)也在這裡：使用知識庫欄頂端的 **知識庫** / **記憶** 開關即可在兩者間切換。記憶不會列在你的知識庫清單中。

在聊天視窗中點選頂端的知識庫名稱，即可檢視你所有的知識庫：包含各自的大小、本週新增的內容、需要處理的項目，以及哪些允許 AI 用戶端搜尋。

## 建立知識庫

1. 在所有知識庫總覽頁面或 **設定 → 知識庫** 中點選 **新增知識庫**，或在 SmartBar 中搜尋 **建立知識庫**。
2. 填入清楚的 **名稱**，並加上 **說明** 描述裡面存放的內容；代理程式會閱讀這段說明來判斷何時該搜尋這裡。
3. 在 **初始內容** 下方選擇 **空白**、**資料夾**（建立索引並保持同步）或 **檔案**。
4. 如果你想讓 Claude 或 Cursor 等 MCP 用戶端也能搜尋它，請開啟 **允許 AI 用戶端搜尋**。
5. 點選 **建立**。若選了資料夾或檔案，按鈕會顯示為 **建立並匯入** 或 **建立並加入**。

建議用不同的知識庫將互不相關的專案分開；在同一個知識庫內，則可再用資料夾整理項目。

## 新增內容

| 項目 | 用途 |
| --- | --- |
| **新增 → 筆記** | 一份可編輯的全新 Markdown 筆記 |
| **新增 → 檔案** | 從 Mac 加入支援的文件、圖片、音訊或影片 |
| **新增 → 單一網頁** | 擷取單一網址的內容 |
| **新增 → YouTube 影片** | 影片及其字幕 |
| **新增 → 貼文** | 來自 X、Reddit、Hacker News、Bluesky、知乎等平台的貼文 |
| **新增 → 匯入資料夾…** | 本機資料夾及其目錄結構，可選擇保持同步 |
| **新增 → 新增資料夾…** | 用來分類項目的資料夾 |
| 將檔案拖曳或貼上至知識庫 | 從 Finder 快速匯入 |
| [快速擷取](/zh-hant/features/quick-capture) | 儲存目前前景 App 的內容 |
| [語音筆記](/zh-hant/features/voice-notes) | 錄製並儲存一段口述筆記 |

文件解析器支援常見的純文字、Markdown、PDF、Office、EPUB 與結構化資料格式。圖片會透過 OCR 辨識，音訊與影片則會進行轉寫。解析品質與支援格式取決於選用的解析器與服務供應商。若有檔案被跳過或處理失敗，請檢查匯入預覽與各項目的狀態。

當你加入整個網站時，Enconvo 只會抓取該網址所屬的網站區段（例如文件網站中的某個部分），若同一頁面出現在兩個網址下，也只會建立一次索引。

## 分享知識庫

你可以透過電子郵件與他人分享知識庫，或分享給整個團隊。你和對方都必須登入 Enconvo 帳號。

<Steps>
  <Step title="開啟分享">
    開啟知識庫的 **⋯** 選單，選擇 **分享…**。
  </Step>
  <Step title="加入成員或你的團隊">
    使用 **透過電子郵件加入成員**，或開啟團隊存取權限，與團隊中的所有人分享。
  </Step>
  <Step title="選擇權限">
    選擇 **可檢視**、**可新增** 或 **可管理**。只有擁有者與具備管理權限的成員可以變更存取權限。
  </Step>
</Steps>

分享會在 Enconvo Cloud 存放一份該知識庫的副本。只有知識庫裡的內容會離開你的 Mac；記憶與聊天紀錄絕不會被分享。任何人新增的內容都會在幾秒內同步到每位成員的 Mac，且每個項目都會顯示是誰新增的。每位成員的 Mac 都會各自保存一份副本與索引，因此離線時也能搜尋。其他成員只能檢視已連結的資料夾。**動態** 會記錄變更了什麼以及由誰變更。

若要停止分享，請對該成員點選 **移除存取權限**，或選擇 **停止與團隊分享**。

## 瀏覽與尋找項目

- **格狀**、**列表** 與 **圖譜** 可切換檢視方式。列表是一張包含 **類型**、**標籤**、**資料夾**、**狀態** 與 **加入時間** 欄位的表格；圖譜則會把語意最接近的項目連結在一起。
- 項目上方的 **資料庫** 選單可在 **所有項目**、**最近加入**、**未加標籤** 與 **需要處理** 之間切換，並顯示對應數量。當有項目需要處理時，會出現一個小圓點提醒。
- **篩選**、**標籤** 與 **類型** 可進一步縮小顯示範圍。
- 在列表中勾選多列，即可一次移動、加上標籤、重建索引、刪除或一起展開對話。

## 已連結的資料夾

1. 選擇 **新增 → 匯入資料夾…**。
2. 選取來源資料夾，確認檔案數量與跳過的檔案後送出。
3. 選取該資料夾並展開詳細資訊，即可查看來源路徑、同步狀態與控制按鈕。
4. 點選 **立即同步**，或開啟 **自動同步** 讓 Enconvo 執行時自動追蹤變更。

來源資料夾會保留在磁碟上。新增與修改的檔案會自動匯入，從來源資料夾刪除的檔案也會從知識庫移除。隱藏檔案、不支援的格式以及超過 50 MB 的檔案會被跳過。Enconvo 的資料夾同步絕對不會編輯你的來源檔案。

如果來源外接硬碟被拔除或資料夾被移動，該資料夾會顯示 **找不到來源資料夾**，而且不會移除任何項目。重新接回硬碟，或點選 **重新連結…** 並選取新位置即可。關於處理與同步的疑難排解，請參閱[知識庫運作原理](/zh-hant/advanced/knowledge-base-advanced)。

## 針對資料來源提問

- **在知識庫中**：點選頂端 **項目** 旁的 **提問**。它與聊天視窗用的是同一個對話：這個知識庫會附加到你的第一個問題中，並在追問時再次搜尋，且對話會與你的其他對話一起保存。點選 **新對話** 即可開始新的提問。
- **在任何對話中**：輸入 **@**，從列表中挑選一個知識庫或裡面的單一項目。它會留在訊息輸入框上方供你後續追問，不用時也可從該處移除。點選它的標籤即可在知識庫中開啟它。

試著這樣問：

> 根據附加的專案筆記，列出所有與身分驗證相關的決策，並為每項決策註明出處。

代理程式會搜尋並閱讀所需資料。檢索只會挑選相關段落，而不是把整份文件全部送出。重要細節請直接點開引用的項目確認。如果漏了某個段落，請直接點名該項目，或檢查它是否已完成索引。

## 知識庫設定

點選知識庫標題列中的齒輪圖示（**知識庫設定**）。

| 區塊 | 包含內容 |
| --- | --- |
| **一般** | 知識庫的 **名稱** 與 **說明** |
| **索引與搜尋** | 需要處理的項目、搜尋模型，以及重建整個索引的 **重新建立索引…** |
| **來源與擷取** | 已連結資料夾的 **立即同步**、**自動同步** 與 **重新連結…**，以及前往快速擷取、語音筆記和 Chrome 擴充功能的捷徑 |
| **AI 用戶端 (MCP)** | 是否允許 AI 用戶端搜尋此知識庫。請參閱[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp)。 |
| **進階** | **知識庫 ID** 與 **刪除知識庫** |

預設知識庫與記憶無法刪除。

## 編輯與維護

點開任一筆記即可編輯其 Markdown 內容。透過項目與資料夾選單可以重新命名、移動、加標籤或移除內容。請留意移除確認訊息：從知識庫移除項目與刪除磁碟上的來源檔案是兩回事，而移除整個已連結資料夾絕對不會動到磁碟上的檔案。

<Warning>
對於來自已連結資料夾的項目，項目選單會顯示 **移至垃圾桶**。這會將磁碟上的真實檔案移到垃圾桶，接著該項目才會從知識庫中移除。
</Warning>

當項目處理失敗時，請先確認是內容擷取失敗還是索引建立失敗，再進行重試。有時文件在搜尋索引完成前就已經可以閱讀。

所有知識庫都共用同一個搜尋模型，可在 **設定 → 記憶** 的 **搜尋** 底下設定。它可以在這台 Mac 或 Enconvo Cloud 上執行，在兩者間切換會保留現有的搜尋索引。**索引與搜尋** 中的 **搜尋設定…** 可直接開啟該頁面。

## 連接其他 AI App

開啟 **知識庫設定 → AI 用戶端 (MCP)**，讓本機的 MCP 用戶端搜尋你勾選的知識庫。這是一項獨立、需主動開啟的唯讀服務。設定與分享控制請依循[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp) 進行。

## 資料處理

知識庫檔案與索引皆儲存在本機。你選用的雲端 OCR、語音轉寫、嵌入（embedding）、重排序（reranking）或對話服務供應商，仍會收到執行作業所需的內容。當搜尋模型在 Enconvo Cloud 上執行時，正在建立索引或搜尋的文字會傳送到雲端。檔案儲存在本機不代表供應商的處理過程完全離線。匯入敏感資料前，請先檢視[隱私與安全性](/zh-hant/configuration/privacy-security)以及你所選用的服務供應商。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 項目顯示索引錯誤 | 開啟 **資料庫 → 需要處理**，確認是內容擷取還是索引建立失敗，然後為該項目重建索引。 |
| 已連結的資料夾顯示 **找不到來源資料夾** | 重新接回磁碟機，或點選 **重新連結…** 並選擇資料夾的新位置。 |
| 回答漏掉了某份文件 | 確認該文件已完成索引，再用 **@** 直接點名它。 |
| 新加入的內容沒有建立索引 | 若搜尋模型在 Enconvo Cloud 上執行，請先登入帳號。登入前新內容不會建立索引，搜尋只會比對完全相符的字詞。 |

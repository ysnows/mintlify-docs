---
title: "知識庫"
description: "收集文件、備註、網頁與資料夾，然後在聊天中搜尋並就其內容提問。"
---

知識庫存放你希望 Enconvo 日後能找到的資料：參考文件、專案備註、儲存的網頁與語音備註。當你指向某個知識庫，或問題需要其中的內容時，代理程式便會搜尋它。[記憶](/zh-hant/ai/memory)則不同：它存放的是代理程式在各次聊天中記住的、與你有關的簡短事實。

## 開啟知識庫

- 在聊天視窗的側邊欄中，點按**知識庫**。
- 或開啟**設定 → 知識庫**，再點按某個知識庫。
- 或從 Enconvo 的選單列選單中選擇**顯示知識庫視窗**。它會在聊天視窗中開啟知識庫。

你的[記憶](/zh-hant/ai/memory)也在這裡：使用知識庫欄位頂端的**知識庫** / **記憶**切換開關，即可在兩者之間切換。記憶不會列在你的知識庫之中。

在聊天視窗中，點按頂端的知識庫名稱，即可查看你所有的知識庫：每個知識庫的大小、本週新增的內容、需要處理的項目，以及哪些知識庫可供 AI 用戶端搜尋。

## 建立知識庫

1. 在所有知識庫的總覽或**設定 → 知識庫**中點按**新增知識庫**，或在 SmartBar 中搜尋**建立知識庫**。
2. 為它取一個清楚的**名稱**，並加上**描述**，說明要放入什麼內容；代理程式會讀取它來判斷何時該到這裡搜尋。
3. 在**開始方式**下選擇**空白**、**一個資料夾**（會建立索引並保持同步）或**檔案**。
4. 如果希望 Claude 或 Cursor 等 MCP 用戶端能存取它，請開啟**允許 AI 用戶端搜尋**。
5. 點按**建立**。如果選了資料夾或檔案，按鈕會顯示為**建立並匯入**或**建立並新增**。

請使用不同的知識庫來區隔互不相關的專案。在同一個知識庫中，則可用資料夾來整理項目。

## 新增內容

| 入口 | 適用於 |
| --- | --- |
| **新增 → 備註** | 一則可編輯的新 Markdown 備註 |
| **新增 → 檔案** | 來自你 Mac 的支援文件、圖片、音訊或影片 |
| **新增 → 單一網頁** | 來自單一網址的內容 |
| **新增 → YouTube 影片** | 一部影片及其字幕 |
| **新增 → 發佈** | 來自 X、Reddit、Hacker News、Bluesky、知乎等平台的貼文 |
| **新增 → 匯入資料夾…** | 保留結構的本機資料夾，可選擇保持同步 |
| **新增 → 新增資料夾…** | 用來整理項目的資料夾 |
| 將檔案拖曳或貼上到知識庫 | 從 Finder 快速匯入 |
| [快速擷取](/zh-hant/features/quick-capture) | 儲存目前 App 的內容 |
| [語音備註](/zh-hant/features/voice-notes) | 錄製並儲存語音備註 |

文件載入器支援常見的文字、Markdown、PDF、Office、EPUB 與結構化資料格式。圖片會以 OCR 讀取，音訊與影片則會轉錄為文字。解析品質與支援的格式取決於所選的載入器與供應商。對於被略過或失敗的檔案，請查看匯入預覽與各項目的狀態。

當你新增整個網站時，Enconvo 只會處理網址所指向的網站區段，例如文件網站的某一部分，而且同一個頁面即使有兩個網址，也只會建立一次索引。

## 分享知識庫

你可以透過電子郵件，或與整個團隊分享知識庫。你需要登入 Enconvo 帳號，被分享的對象也一樣。

<Steps>
  <Step title="開啟分享">
    開啟知識庫的 **⋯** 選單，然後選擇**分享…**。
  </Step>
  <Step title="加入成員或你的團隊">
    使用**透過電子郵件加入成員**，或開啟團隊存取權限，與團隊中的所有人分享。
  </Step>
  <Step title="選擇每個人的權限">
    選擇**可檢視**、**可新增**或**可管理**。只有擁有者與可管理的成員能變更誰有存取權限。
  </Step>
</Steps>

分享時，會在 Enconvo Cloud 中放入該知識庫的一份副本。只有其中的內容會離開你的 Mac；記憶與聊天記錄絕不會被分享。任何人新增的內容會在數秒內傳到每一台 Mac，而且每個項目都會顯示是誰加入的。每位成員的 Mac 各自保有一份副本與索引，因此離線時也能搜尋。其他人只能檢視已連結的資料夾。**動態**會顯示有哪些變更以及是誰變更的。

若要停止分享，請對某位成員使用**移除存取權限**，或使用**停止與團隊分享**。

## 瀏覽與尋找項目

- **網格**、**列表**與**地圖**可切換檢視方式。列表是一張表格，包含**類型**、**標籤**、**資料夾**、**狀態**與**已加入**欄位。地圖會將每個項目與語意最接近的項目連在一起。
- 項目上方的**資料庫**選單可在**所有項目**、**最近新增**、**無標籤**與**需要處理**之間切換，並附上各自的數量。有項目需要處理時，會顯示一個圓點。
- **篩選**、**標籤**與**類型**可縮小顯示範圍。
- 在列表中，勾選多列即可一併移動、加上標籤、重新索引、刪除或就它們聊天。

## 已連結的資料夾

1. 選擇**新增 → 匯入資料夾…**。
2. 選取來源資料夾，檢查檔案數量與被略過的檔案，然後確認。
3. 選取該資料夾並顯示其詳細資訊，即可查看來源路徑、同步狀態與控制項。
4. 點按**立即同步**，或開啟**自動同步**，在 Enconvo 執行期間跟隨變更。

來源資料夾會保留在磁碟上。新增與變更的檔案會被匯入，而你從來源刪除的檔案也會從知識庫中移除。隱藏檔案、不支援的格式，以及超過 50 MB 的檔案會被略過。Enconvo 的資料夾同步絕不會編輯來源檔案。

如果來源磁碟被拔除或資料夾被移動，該資料夾會顯示**找不到來源資料夾**，且不會移除任何內容。請重新連接磁碟，或點按**重新連結…**並選擇新的位置。處理與同步的疑難排解，請參閱[知識庫的運作方式](/zh-hant/advanced/knowledge-base-advanced)。

## 就你的資料來源提問

- **在知識庫中**：點按頂端**項目**旁的**提問**。這與聊天視窗是同一個聊天：知識庫會附加在你的第一個問題上，後續追問時會再次搜尋，而且該聊天會與你的其他聊天一同儲存。點按**新增**即可開始新的提問。
- **在任何聊天中**：輸入 **@**，然後從清單中選擇一個知識庫或其中的某個項目。它會留在訊息輸入框上方供後續提問使用，你也可以在那裡移除它。點按它的標籤即可在知識庫中開啟。

試試看：

> 根據附上的專案備註，列出有關身分驗證的決策，並為每項決策註明來源。

代理程式會搜尋並讀取它所需的資料。檢索會挑選相關段落，而不是傳送每一份文件。請開啟被引用的項目來核實重要細節。如果缺少某個段落，請明確提及該項目，或確認它已完成索引。

## 知識庫設定

點按知識庫標題列中的齒輪（**知識庫設定**）。

| 區段 | 內容 |
| --- | --- |
| **一般** | 知識庫的**名稱**與**描述** |
| **索引與搜尋** | 需要處理的項目、搜尋模型，以及用來重建整個索引的**重新索引…** |
| **來源與擷取** | 已連結的資料夾（含**立即同步**、**自動同步**與**重新連結…**），以及前往快速擷取、語音備註與 Chrome 擴充功能的捷徑 |
| **AI 用戶端（MCP）** | AI 用戶端是否可以搜尋此知識庫。請參閱[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp)。 |
| **進階** | **知識庫 ID** 與**刪除知識庫** |

預設知識庫與記憶無法刪除。

## 編輯與維護

開啟備註即可編輯其 Markdown。使用項目與資料夾選單來重新命名、移動、加上標籤或移除內容。請閱讀移除時的確認訊息：將項目從知識庫移除與刪除來源檔案是不同的操作，而移除整個已連結的資料夾絕不會動到磁碟上的檔案。

<Warning>
對於來自已連結資料夾的項目，項目選單會顯示**移到垃圾桶**。它會將磁碟上的實際檔案移到垃圾桶，然後該項目就會離開知識庫。
</Warning>

當項目失敗時，請先確認是擷取失敗還是索引失敗，再重試。文件可能在其搜尋索引完成之前就已經可以讀取。

每個知識庫都使用相同的搜尋模型，可在**設定 → 記憶**的**搜尋**下設定。它可在這台 Mac 或 Enconvo Cloud 上執行，在兩者之間切換時會保留你的搜尋索引。**索引與搜尋**中的**搜尋設定…**會開啟該設定。

## 連接其他 AI App

開啟**知識庫設定 → AI 用戶端（MCP）**，讓本機 MCP 用戶端搜尋你選定的知識庫。這是一項獨立、需自行選擇啟用的唯讀服務。設定與分享控制請參閱[知識庫 MCP](/zh-hant/advanced/knowledge-base-mcp)。

## 資料處理

知識庫的檔案與索引儲存在本機。你所選的雲端 OCR、轉錄、嵌入、重新排序或聊天供應商，可能會收到它們運作所需的內容。當搜尋模型在 Enconvo Cloud 上執行時，要建立索引或搜尋的文字會傳送到那裡。檔案儲存在本機，並不代表供應商的處理也是離線的。匯入敏感資料之前，請先檢視[隱私權與安全性](/zh-hant/configuration/privacy-security)以及你的供應商。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 項目顯示索引錯誤 | 開啟**資料庫 → 需要處理**，確認是擷取失敗還是索引失敗，然後重新索引該項目。 |
| 已連結的資料夾顯示**找不到來源資料夾** | 重新連接磁碟，或點按**重新連結…**並選擇資料夾的新位置。 |
| 回答漏掉某份文件 | 確認該文件已完成索引，然後用 **@** 直接提及它。 |
| 新內容沒有被建立索引 | 如果搜尋模型在 Enconvo Cloud 上執行，請登入。在登入之前，新內容不會被建立索引，搜尋也只能找到相符的字詞。 |

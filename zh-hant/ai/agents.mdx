代理程式將指令、模型與工具結合起來，用於某一類工作。當你一再給出相同的指令，或某項工作需要特定的一組工具時，就可以建立一個。你可以在**設定 → 代理程式列表**中管理你的代理程式。

## 你一開始就有的代理程式

**Mavis** 是預設的代理程式：它會回答問題，也能使用你的 App、瀏覽網頁並處理你的檔案。內建的代理程式各自為一項工作而設計：**撰稿人**、**規劃師**、**審查者**、**顧問**、**研究員**、**設計師**與**程式設計師**。**Claude Code**、**Codex**、**Grok Build**、**Antigravity** 與 **Muse Code** 會與你已安裝的程式設計代理程式聊天，並在專案資料夾中工作，而 **Grok Bot** 則與 xAI 在雲端的代理程式聊天。請參閱[程式設計代理程式](/zh-hant/ai/coding-agents)。

從任何聊天頂端的代理程式選單，或聊天視窗輸入框上方的卡片中選擇代理程式。代理程式清單會將你最近聊過的代理程式排在最前面。

## 代理程式由什麼組成

在**設定 → 代理程式列表**中點按某個代理程式，即可開啟它的頁面。左側的各區段可跳到每個部分：

| 區段 | 設定的內容 |
| --- | --- |
| **指令** | 在每次對話之前告訴代理程式的內容。變更會在你輸入時自動儲存。 |
| **樣式** | 它的**回覆風格**，以及它的**智慧介面**等級：它多容易以圖表、表格與卡片來回答。請參閱[設定它的樣式](#設定它的樣式)。 |
| **模型** | 它用來撰寫的 AI 模型。每個代理程式可以使用不同的模型。 |
| **工具和技能** | 它可以使用什麼，以及它如何找到其餘的內容，還有它的技能資料夾，以及存放它的專門技能與它所處理檔案的**工作資料夾**。請參閱[選擇工具與技能](#選擇工具與技能)。 |
| **知識** | 它在哪些知識庫中尋找、依什麼順序，以及在知識庫中找不到答案時，是否搜尋網路。請參閱[選擇它的知識庫](#選擇它的知識庫)。 |
| **記憶** | 它讀取哪些記憶，以及是否記住新的事物。 |
| **語音** | 朗讀它的回覆所用的聲音。 |
| **行為** | 它看到什麼、如何執行，以及如何回覆，例如**回覆語言**與 **Cloud 點數執行上限**。 |
| **使用方** | 除了聊天之外，還有什麼會啟動這個代理程式，以及它的**連結、CLI 與 API** 列。 |

## 建立代理程式

1. 在**設定 → 代理程式列表**中，點按**新增代理程式**，或從 SmartBar 執行**建立代理**。
2. 輸入**標題**，並可選擇性地加入**虛擬形象**與說明其用途的**描述**。
3. 在**智慧體指令**下，描述它應該做什麼、需要什麼輸入，以及應如何呈現結果。
4. 在**它可以使用什麼？**下，從預設組合開始：**日常**（所有內建工具）、**程式設計**、**研究**或**寫作**。你之後可以在**工具和技能**下變更。
5. 選擇它的模型。在**推薦模型**下，Enconvo 會讀取描述並建議一個 Enconvo Cloud 模型，旁邊還有一個較便宜與一個更強的選項。點按**用這個**，或選擇其他選項。請參閱[使用推薦](/zh-hant/ai/model-selection-guide)。
6. 點按**建立機器人**。然後開啟該代理程式來選擇它的技能與知識。
7. 與它開始新的聊天，並測試一項簡單而典型的任務。

若要繪製虛擬形象而不是上傳，請開啟虛擬形象選擇器的**產生**分頁，可以在這裡，也可以稍後在代理程式的設定中。選擇一種風格（**扁平**、**3D**、**動漫**、**照片**、**線條**或**水彩**）並點按**產生**：你的圖片模型會根據代理程式的名稱與描述繪製四個虛擬形象。你可以加入細節並重新繪製，或點按你想要的那一個。在你點按**產生**之前，不會繪製任何內容。

指令範例：

```text
Help me turn meeting notes into actionable follow-ups.
Separate decisions, open questions, and action items.
For action items, preserve the owner and due date if stated;
otherwise mark them as unspecified.
```

## 設定它的樣式

在**樣式**下，有兩項設定決定代理程式的回覆讀起來如何。聊天可以從 **+** 選單的**使用風格**為自己選擇另一種風格。

**回覆風格**設定語氣、長度與格式：**標準**、**簡潔**、**講解**、**正式**，或你自己的風格。點按**新增風格**，即可根據描述或你自己的寫作樣本建立一個，並點按**管理**來編輯你的風格。

**智慧介面**設定它在未被要求時，多容易以圖表、表格與卡片來回答：

| 等級 | 作用 |
| --- | --- |
| **精選** | 為資料、比較與計畫繪製視覺內容。摘要與解釋則維持文字。 |
| **主動**（預設） | 只要圖表、表格或卡片讀起來更好，就會加入，即使在解釋之中也是如此。 |
| **視覺優先** | 以視覺內容為先，且一則回覆可以使用多個。回覆會稍微慢一些。 |

視覺內容越多，花費的時間越長，也會使用更多點數。IM 管道與語音回覆則維持文字。

## 選擇工具與技能

在**工具和技能**下，選擇代理程式如何找到它所使用的內容：

- **自動探索**（建議）會從必要的項目開始，並在任務需要時，找出任何已安裝的技能、外掛程式、Connector 或 MCP 伺服器。它依語意比對，因此即使請求的措辭與工具的描述不同，或以另一種語言撰寫，仍然能找到它。
- **僅我選擇的**會為代理程式提供固定的一組。挑選它可以使用的內建工具、技能與 MCP 伺服器。當任務需要其他內容時，它會告訴你缺少什麼，而不是自己去搜尋。

使用**自動探索**時，你仍然可以關閉這個代理程式絕不該碰的**內建工具**，在**已釘選的技能**下釘選技能，讓它們列在每次聊天中，並關閉**建議 Enconvo 商店中的外掛程式**，讓它不再提議要安裝的外掛程式。**技能資料夾**可為這個代理程式關閉個別的技能。

只給代理程式它的工作所需要的工具：

| 需求 | 功能 |
| --- | --- |
| 讀取與編輯文件 | [檔案工具](/zh-hant/ai/file-tools) |
| 尋找最新資訊 | [網頁搜尋](/zh-hant/ai/web-search)與[擷取網頁](/zh-hant/ai/web-fetch) |
| 在網站中操作 | [使用瀏覽器](/zh-hant/features/browser-control) |
| 操作桌面 App | [電腦操作](/zh-hant/features/computer-use) |
| 搜尋你的資料 | [知識庫](/zh-hant/ai/knowledge-base) |
| 重複使用某個程序 | [技能](/zh-hant/configuration/skills) |
| 連接外部服務 | [MCP 伺服器](/zh-hant/features/mcp) |
| 執行程式碼 | [程式碼執行器](/zh-hant/ai/code-runner) |
| 在一個步驟中進行多次工具呼叫 | [程式碼模式](/zh-hant/configuration/code-mode) |

模型必須支援你所選擇的工具與輸入類型。工具也需要各自的憑證、存取權限與設定，而且指令無法授予代理程式本來沒有的權限。

## 選擇它的知識庫

在**知識**下，選擇代理程式在哪裡尋找：

| 選項 | 作用 |
| --- | --- |
| **全部知識庫** | 當問題需要時，會在你的任何一個知識庫中尋找。 |
| **先查選定的** | 先在你加入的知識庫中尋找，找不到時再查其餘的。 |
| **只查選定的** | 只在你加入的知識庫中尋找。其他知識庫只有在你用 `@` 提及時才會開啟。 |

點按**新增知識庫**來選擇它們，並拖曳它們以調整它尋找的順序。

## 核准操作

執行模式旁邊的**權限**標籤，設定代理程式在行動之前何時要停下來詢問。它會顯示在聊天視窗、SmartBar、App 側邊欄與動態島的代理程式模式中。它們都會變更該代理程式的同一項設定，因此在其中一處的變更，也會顯示在其他地方。

| 模式 | 在下列情況之前詢問 |
| --- | --- |
| **請求核准** | 執行指令、編輯工作資料夾以外的檔案，以及在 App、瀏覽器或線上服務中操作 |
| **替我核准**（預設） | 只有看起來可能不安全的操作，例如刪除檔案、傳送訊息、發布或付款 |
| **完整取用** | 完全不詢問。代理程式會直接行動 |

讀取檔案、搜尋與查看螢幕絕不會詢問。**替我核准**也不會在只為自己設定 `PATH` 的指令，或刪除自己在暫存資料夾下所建立內容的指令之前詢問；刪除其他任何內容仍然會詢問。

當代理程式將工作交給另一個代理程式或程式設計代理程式時，被呼叫的那一個會以與你聊天的代理程式相同的模式工作。每張核准卡片都會說明是哪項設定導致它詢問，例如「詢問的原因是這個專案處於替我核准模式。」關於指令執行後有什麼會對它設限，請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

### 問題會出現在哪裡

問題會出現在聊天所執行的視窗中。如果該視窗沒有顯示該聊天（例如它被隱藏，或它是內嵌面板），問題就會移到動態島。如果 30 秒內無人在那裡回答，你配對的 iPhone 會收到提醒通知，即使聊天的視窗仍開啟在你正在使用的 App 後方。

如果你在沒有回答的情況下關閉了動態島的卡片，請點按動態島聊天中等待的步驟，即可再次看到選項。代理程式向你提出的問題運作方式相同。

### 回答問題

- **是，允許一次**會讓這一個操作執行。
- **是，且不再詢問**會在該聊天的其餘時間允許它，且即使 Enconvo 重新啟動後也會記住。
- 或輸入代理程式應該改做的事。

聊天在等待時，會在聊天視窗的列表、SmartBar 的最近聊天與動態島中顯示**等待核准**，而不是執行中。iPhone App 的聊天列表會將它標示為**需要核准**。

子代理會在它們的上層聊天中詢問，而問題會說明是子代理在詢問，以及它正在處理哪項任務。排程任務、工作流程與 IM 管道會在不詢問的情況下執行，因為沒有人在視窗前回答。

## 子代理

在代理程式模式中，代理程式可以將任務拆成多個部分，並同時啟動最多六個子代理，每個都在自己的對話中運作。它會在它們回報之後回答。它只會在拆分明顯有幫助時才這樣做，例如多個獨立的搜尋，或在你要求時。如果 AI 錯誤（例如速率限制）使子代理中途停止，代理程式仍會取得它目前為止找到的內容，並可在錯誤排除之後讓它繼續。

啟動子代理時，代理程式可以為它指定專屬的模型、推理強度、指令與名稱，或將目前的對話分支到其中。當代理程式自行選擇模型時，快速查詢、閱讀與簡單的重複工作會在你的供應商的小型模型上執行，較困難的推理會使用較高的強度，其餘則維持在你所選的模型上。子代理可以啟動自己的子代理，最多三層。

- **程式設計代理程式作為子代理。**Claude Code、Codex、Antigravity、Grok Build 與 Muse Code 都可以作為子代理工作。卡片會顯示程式設計代理程式的圖示、它的工作位置，以及它使用的工具呼叫、時間與 token。
- **獨立的工作樹。**當某個子代理在另一個子代理同時也在變更檔案時變更檔案，它會取得自己的 git 工作樹，因此兩個子代理絕不會覆寫彼此的工作。沒有變更的工作樹會在其子代理完成時移除。只製作設計、文件、投影片、研究或審查的子代理不需要工作樹，因此同時啟動多個子代理時，不會為每一個複製專案。
- **其他電腦。**代理程式可以在你另一台已配對的電腦上執行子代理，將任務交給那台電腦的代理程式或程式設計代理程式。請參閱[其他電腦](/zh-hant/integrations/other-computers)。
- **引導。**代理程式可以為執行中子代理的任務加入訊息、將它中斷，或連到同一個專案中另一個代理程式的聊天。停止某個聊天會停止它之下的每個子代理。
- **管線。**代理程式可以在一個步驟中執行一組規劃好的子代理，例如對一份檔案清單進行相同的檢查。失敗的執行可以接續進行，而不需要重新執行已完成的子代理。

### 平行聊天

當你要求代理程式為另一項任務開啟新的聊天時，它會開啟一個（以你要求的推理強度），並像你自己開始的聊天一樣，顯示在你於 Mac、iPhone 與 Android 上的聊天列表中。頂端的備註會說明是哪個聊天開啟了它。該任務的審查與測試仍會作為它的子代理執行。代理程式為自己開啟的聊天，可從它的卡片移到你的聊天列表。

### 追蹤子代理並與它們交談

聊天中的卡片會依任務列出每個子代理，並以圖示顯示它是執行中、等待你核准、已完成還是失敗。執行中子代理的列也會顯示它目前正在做什麼，以及它所使用的模型與強度。新的子代理在卡片出現的同時，也會顯示在訊息輸入框上方的背景匣中。

子代理所製作的內容，例如設計或文件，會在製作時顯示在它的列之下。點按它即可在聊天旁開啟；代理程式會在它的回答中以卡片的形式將它交給你。

- 點按某一列即可開啟該子代理的對話。它的工作區面板與 `@` 檔案搜尋會顯示啟動它的聊天的工作資料夾。在 SmartBar 與動態島中，它的工作會就地開啟。
- 在子代理的對話中輸入即可與它交談。它會在那裡回答你、可以向你提問、在該對話中請求核准，並繼續在同一個資料夾中工作。啟動它的代理程式會在它回答你時等待，然後看到它最新的回答。傳給已完成子代理的訊息會立即讓它重新開始，即使另一個子代理正在同一個資料夾中變更檔案也一樣。
- 在子代理的對話中，每則訊息都標有傳送它的代理程式。來自上層代理程式的訊息會說明它是引導了執行中的任務、等待、中斷它，還是開始了新的一輪。
- 聊天詳細資料中的**譜系**會顯示子代理的完整樹狀結構，共三層。在程式設計代理程式的聊天中，它會顯示啟動它的 Enconvo 聊天。
- 在聊天視窗的側邊欄中，聊天的子代理會列在它之下，而聊天列上的按鈕可摺疊該清單。

### 子代理角色

每個子代理都以某個角色開始：

| 角色 | 作用 |
| --- | --- |
| **預設** | 以啟動它的代理程式的身分工作，使用相同的指令、工具與模型 |
| **探索者** | 只會讀取檔案、搜尋與查看 App。無論**權限**標籤如何設定，它都無法編輯、執行會變更任何內容的指令，或在線上行動 |
| **你的其中一個代理程式** | 以該代理程式的身分執行，使用它自己的指令、工具與模型，並在與啟動它的聊天相同的工作資料夾中工作 |
| **專案協助程式** | 由專案在工作資料夾中，或其上層直到儲存庫根目錄的資料夾中的 `.claude/agents`、`.codex/agents` 或 `.enconvo/agents` 所定義。以啟動它的代理程式的身分工作，並遵循協助程式自己的指令。它只使用檔案中列出的工具，在檔案這樣指定時只會讀取，並在你的模型供應商有提供時使用協助程式的模型 |
| **你自己的協助程式** | 由你家目錄中的 `~/.enconvo/agents`、`~/.claude/agents` 或 `~/.codex/agents` 所定義，並可在每個聊天中使用。運作方式與專案協助程式相同 |

若要自行選擇，請在代理程式模式的聊天中輸入 `@`，並從**子代理**群組中挑選，該群組會列出協助程式、**探索者**，以及一般的**子代理**。代理程式會為你的訊息啟動該子代理、為它撰寫任務，並在它回報之後回答。你自己的代理程式則會留在選單的代理程式群組中。

請在每個代理程式的設定中清楚地描述它：負責拆分工作的代理程式會讀取這些描述，來決定哪一個適合某項任務。若要將任務以隊友的身分交給你的某個代理程式或程式設計代理程式，並使用它自己的推理強度，請參閱[代理程式協調器](/zh-hant/ai/agent-orchestrator)。

### 專案協助程式

專案協助程式與你自己的協助程式所使用的檔案，與 Claude Code 子代理及 Codex 代理程式角色相同，因此已經擁有它們的儲存庫或家目錄不需要額外設定。

- 當 Claude Code 檔案（在其 frontmatter 中含有 `name` 與 `description` 的 Markdown）設定了 `permissionMode: plan`，或只列出 `Read`、`Grep` 與 `Glob` 等讀取工具時，它是唯讀的。
- 當 Codex 檔案（含有 `description` 與 `developer_instructions` 的 TOML）設定了 `sandbox_mode = "read-only"` 時，它是唯讀的。
- 當供應商沒有提供協助程式的模型時，協助程式會改用聊天的模型。

Claude Code 檔案中的 `tools` 與 `disallowedTools` 決定協助程式可以使用代理程式的哪些工具。Enconvo 會將每個名稱對應到它自己的工具：

| 在協助程式檔案中 | 協助程式可以 |
|---|---|
| `Read`、`Grep`、`Glob`、`LS` | 讀取與搜尋檔案 |
| `Edit`、`MultiEdit`、`Write` | 編輯與建立檔案 |
| `Bash` | 執行任何 shell 指令 |
| `Bash(git diff:*)` | 只執行以 `git diff` 開頭的指令 |
| `WebSearch`、`WebFetch` | 搜尋網路並讀取網頁 |
| `mcp__github__get_issue`、`mcp__github` | 使用已連接 MCP 伺服器的某一個工具，或每一個工具 |

沒有 `tools` 行時，協助程式擁有除 `disallowedTools` 所列之外的每個工具。清單之外的呼叫不會執行，且協助程式會被告知它擁有哪些工具。每個協助程式仍然可以載入技能並向你提問。在 `.enconvo/agents` 檔案中，你也可以用 API 路徑列出 Enconvo 工具，例如 `browser-use/*`。

Claude Code 檔案中的技能、MCP 伺服器、輪次上限、背景與工作樹設定也會生效。

## 與代理程式互動的方式

- 在[聊天視窗](/zh-hant/ai/chat)、[SmartBar](/zh-hant/features/smartbar)、[App 側邊欄](/zh-hant/features/app-sidebar)或[動態島](/zh-hant/features/dynamic-island)中與它聊天。
- 設定**語音指令**，將語音請求傳送給你選擇的代理程式。請參閱[聽寫](/zh-hant/features/dictation)。
- 透過 [Live Talk](/zh-hant/features/live-voice) 與它交談，或透過[虛擬形象](/zh-hant/features/avatar)為它加上桌面角色。
- 以[即時通訊管道](/zh-hant/integrations/messaging)連接通訊 App。
- 以[排程工作](/zh-hant/workflows/scheduled-jobs)稍後執行它。
- 從 Enconvo 之外以連結、終端機指令或 API 呼叫來執行它。請參閱[連結、CLI 與 API](#連結、cli-與-api)。

### 連結、CLI 與 API

在**設定 → 代理程式列表**中開啟某個代理程式。在**使用方**下，**連結、CLI 與 API** 列有一個**顯示**按鈕。點按它即可取得以你的文字與檔案執行此代理程式的 Deeplink、終端機指令與 API 呼叫，每一項都可直接複製。AI 指令也有相同的列。

## 預設值與連續性

在變更多個聊天或管道所使用的代理程式之前，請先檢查[模型預設值](/zh-hant/ai/model-selection-guide)。為代理程式應該重複使用的事實設定[記憶](/zh-hant/ai/memory)，並將文件保存在知識庫中，而不是把所有內容都放進指令裡。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 請求失敗 | 先閱讀工具錯誤，或檢查是否缺少輸入。 |
| 你無法判斷是模型還是工具的問題 | 關閉選用工具後，用相同的請求再試一次，然後一次加回一個工具。 |
| 某個操作會變更檔案或外部服務 | 在核准之前，先檢查目的地與影響。 |
| 代理程式表示它缺少工具或技能 | 在**工具和技能**下，檢查它是否設為**僅我選擇的**，或是否有內建工具被關閉。 |
| 回覆中的圖表與卡片比你想要的更多，或花費太長時間 | 在**樣式**下將**智慧介面**設為**精選**，或為單一聊天從 **+** 選單的**使用風格**設定。 |

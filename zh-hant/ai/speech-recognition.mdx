Enconvo 中的每項語音功能都有各自的語音模型設定，所以你可以為聽寫挑選快速的串流模型，為長檔案挑選另一個模型。請在你實際使用的功能中選擇模型。

| 功能 | 設定位置 | 指南 |
| --- | --- | --- |
| 將語音輸入為文字 | **設定 → 聽寫模型** | [聽寫](/zh-hant/features/dictation) |
| 語音指令 | **設定 → 語音指令 → 收音** | [語音指令](/zh-hant/features/dictation) |
| Live Talk 通話 | **設定 → Live Talk → 收音** | [Live Talk](/zh-hant/features/live-voice) |
| 會議或講座錄音 | **設定 → 錄音模型** | [會議錄音](/zh-hant/features/meeting-recording) |
| 現有的音訊或影片檔案 | **設定 → 語音轉寫模型** | [語音轉寫](/zh-hant/features/transcription) |
| 即時字幕 | **設定 → 字幕產生模型** | [即時字幕](/zh-hant/features/live-captioning) |

## 選擇模型

1. 從上方表格開啟你所用功能的設定。
2. 在聽寫、錄音、語音轉寫或字幕模型頁面，使用**全部**、**Enconvo Cloud**、**本機**或**自訂供應商**來篩選清單。在語音指令和 Live Talk 中，**收音**會先顯示推薦的模型，再顯示其他語音模型。
3. 選擇一個模型，然後檢視它的語言和模型選項。

**Enconvo Cloud** 模型使用你的 Enconvo 帳號，不需要 API 金鑰。**Enconvo Cloud Fast** 是 Enconvo Cloud 自家的語音辨識，對所有人免費，並帶有綠色的**免費版**標籤。**自訂供應商**使用你自己在該供應商的 API 金鑰。**本機**模型（MLX 和 Core ML）在下載模型後，就在你的 Mac 上辨識語音。

[語音供應商目錄](/zh-hant/providers/catalog)列出所有已宣告的供應商，包括雲端服務，以及本機的 Parakeet、Qwen、Whisper、SenseVoice、Paraformer 和 Nemotron 變體。硬體需求和可用性取決於執行環境和你的版本。

## 值得注意的模型

| 模型 | 須知 |
| --- | --- |
| ElevenLabs Scribe v3 Live | 在一秒內串流出最初的字詞，在中文和嘈雜的音訊中錯誤較少。可搭配你的 ElevenLabs API 金鑰或 Enconvo Cloud，用於聽寫和語音輸入。中文和日文輸出的字詞之間沒有空格。當 Live Talk 使用 ElevenLabs 時，Live Talk 也會使用它。 |
| ElevenLabs Scribe v3 | 轉錄檔案，可搭配你的 ElevenLabs API 金鑰或 Enconvo Cloud。 |
| Enconvo Cloud Fast | 免費。它的即時模型會在你說話時顯示你的字詞，非同步模型則轉錄已錄製的檔案。 |
| Soniox | 在聽寫、錄音、語音轉寫、字幕、Live Talk 和會議字幕中使用 Soniox 的 v6 模型。你先前選擇的 v5 模型會自動改為 v6；Soniox 將於 2026 年 12 月 15 日停用 v5。 |
| DeepSeek | 用於語音轉寫和聽寫的轉錄，可使用你自己的 DeepSeek API 金鑰，或以不需金鑰的 **DeepSeek (Enconvo Cloud)** 使用。它能自動偵測 21 種語言。 |
| FluidVoice 的 Fluid Speech Pro | 在你的 Mac 和 iPhone 上執行，離線轉錄 25 種歐洲語言，錯誤比 Parakeet 更少，可在你說話時即時轉錄，或在說完後轉錄。需要 macOS 15 或 iOS 18 以上。 |

## 讓模型符合任務

| 功能 | 須知 |
| --- | --- |
| 串流 | 在你說話時產生部分文字。若希望字詞在你說話時就出現，請使用即時模型。 |
| 批次轉錄 | 在擷取或上傳後處理檔案。 |
| 語言提示和熱詞 | 在供應商支援時引導辨識。 |
| 說話者分離 | 區分不同的聲音。不保證能對應到正確的人名。 |
| 即時翻譯 | 僅有部分供應商和模型提供，並有來源語言和目標語言。 |
| 時間戳記和結構化輸出 | 取決於供應商和轉錄輸出格式。 |

## 用短樣本測試

先用你實際使用的語言、麥克風和術語錄一段短樣本並檢視，再處理長時間的會議。如果失敗，請閱讀錯誤訊息，了解檔案大小、格式、擷取、帳號或網路方面的詳細資訊。

本機模型的下載大小可能遠大於 App 本身。請檢查實際的下載大小和你的可用空間；各個本機語音模型所需的大小並不相同。

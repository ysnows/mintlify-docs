title: "網頁搜尋"
description: "讓你的代理程式搜尋網路上的最新資訊，並標示資料來源。"
---

網頁搜尋讓你的代理程式取得網路上的最新結果。每個代理程式都可以搜尋；你可以選擇它使用的搜尋服務，這與撰寫回答的模型是分開的。

## 選擇搜尋供應商

1. 開啟**設定 → 網頁搜尋**。
2. 選擇一個供應商。Enconvo Cloud 的選項不需要 API 金鑰；大多數其他供應商則需要加入你在該服務的金鑰。
3. 點按**設為預設**。

| 供應商 | 說明 |
| --- | --- |
| **自動** | 使用聊天模型自身的網頁搜尋，若模型沒有此功能，則改用其他供應商。請參閱[使用模型自帶的搜尋](#使用模型自帶的搜尋)。 |
| **Enconvo Cloud** | 每個已登入的帳號都可免費使用，不需要 API 金鑰 |
| **DeepSeek (Enconvo Cloud)** | 透過 Enconvo Cloud 使用 DeepSeek 搜尋，每個已登入的帳號都可免費使用 |
| **Gemini** | 透過 Gemini 模型使用 Google 搜尋的接地功能 |
| **Tavily**、**Bing**、**Brave**、**Google Custom**、**Exa** | 使用你在該服務的金鑰進行搜尋 |
| **Parallel** | Parallel 的 AI 搜尋索引，會傳回每個頁面中最相關的段落，需使用你的 Parallel API 金鑰 |
| **PipeLLM** | 透過你的 [PipeLLM](/zh-hant/providers/pipellm) 金鑰取得 Google 結果 |
| **DeepSeek** | 使用你的 DeepSeek API 金鑰進行 DeepSeek 搜尋 |
| **xAI X Search** | 搜尋 X 的貼文、個人檔案與串文，需使用 xAI API 金鑰或 xAI 登入 |
| **xAI X Search (Enconvo Cloud)** | 透過 Enconvo Cloud 方案進行 X 搜尋 |

供應商清單中會標示免費的選項。完整清單請參閱[供應商目錄](/zh-hant/providers/catalog)。部分模型也在其自身的供應商設定中提供內建的接地或搜尋選項。

## 使用模型自帶的搜尋

選擇**自動**時，若聊天所用的模型有網頁搜尋功能，每次搜尋都會使用該模型的網頁搜尋：OpenAI、Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、Z.ai 與 OpenRouter。它會使用你為該模型連接的金鑰或登入，並由該模型的供應商計費。

當模型沒有自己的搜尋，或其搜尋失敗時，自動會使用**回退搜尋**；除非你選擇其他供應商，否則回退搜尋為 **Enconvo Cloud**。

| 設定 | 作用 |
| --- | --- |
| **搜尋路線** | 顯示聊天模型會使用哪種搜尋，以及失敗時會發生什麼事。 |
| **優先用模型自帶的搜尋** | 預設為開啟。關閉後會一律使用回退搜尋。 |
| **回退搜尋** | 當模型沒有搜尋功能或搜尋失敗時所使用的供應商。 |

在聊天中，每個網頁搜尋步驟都會說明是哪種搜尋給出了回答，以及自動在回退時的原因。

## 使用 Parallel

1. 從 [Parallel](https://platform.parallel.ai) 取得 API 金鑰。
2. 在**設定 → 憑證管理 → Parallel** 中加入它。
3. 在**設定 → 網頁搜尋**中選擇 **Parallel**，並選擇**搜尋模式**：

| 搜尋模式 | 適用於 |
| --- | --- |
| **Turbo** | 最快的回答。它只讀取英文與日文的查詢。 |
| **快速** | 大多數搜尋。預設值。 |
| **Basic** | 每個頁面較長的段落。 |
| **進階** | 最深入的搜尋。約需 3 秒，費用也較高。 |

Parallel 會將每次搜尋的費用記在你的 Parallel 帳號上。

## 用代理程式搜尋

1. 提出具體的問題。如果有需要，請加上日期範圍或地點。
2. 代理程式會進行搜尋，並附上資料來源的連結來回答。
3. 開啟被引用的來源，確認它們確實支持該回答。

> 找出這個函式庫最新穩定版本的官方發行說明，並附上連結摘要重大變更。

## 選擇合適的網頁功能

| 需求 | 使用 |
| --- | --- |
| 找出相關的資料來源 | 網頁搜尋 |
| 讀取已知的網址 | [擷取網頁](/zh-hant/ai/web-fetch) |
| 在瀏覽器中開啟結果 | [快速連結](/zh-hant/features/quick-links) |
| 與已登入的網站互動 | [使用瀏覽器](/zh-hant/features/browser-control) |
| 搜尋 X 的貼文、個人檔案或串文 | **xAI X Search** 供應商 |

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 回答沒有來源 | 確認代理程式確實進行了搜尋，而不是只憑模型本身回答。請它搜尋網路。 |
| 供應商回報錯誤 | 檢查供應商的憑證，以及你的帳號在該服務的額度。 |
| 自動使用了回退搜尋 | 聊天模型沒有自己的網頁搜尋，或其搜尋失敗。聊天中的搜尋步驟會說明是哪一種情況。 |
| 結果在登入牆後或在互動式頁面上 | 使用支援的瀏覽器流程，例如[使用瀏覽器](/zh-hant/features/browser-control)。擷取公開網址並不能存取你已登入的工作階段。 |

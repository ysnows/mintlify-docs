Code Runner 為代理程式提供你 Mac 上的真實終端機環境，可用來執行建置、測試、指令碼、套件工具與開發伺服器。實際可執行哪些操作，取決於你電腦上已安裝的程式以及你帳號的權限。

<Warning>
除非你開啟代理程式的**沙盒**，否則指令都會以你帳號對檔案與網路的權限真實執行。執行任何會安裝軟體、修改檔案或影響線上服務的指令前，請務必仔細確認。
</Warning>

## 開始之前

- 為你使用的代理程式開啟 Code Runner。
- 聊天中的**權限**標籤決定代理程式何時需要預先詢問。**請求核准**會在執行指令前詢問你，而**替我核准**只會在看起來不安全的操作前詢問。請參閱[核准操作](/zh-hant/ai/agents)。
- 若要將代理程式的指令限制在工作資料夾內，並隔離你的金鑰與其他應用程式，請在同一個標籤中開啟**沙盒**。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

## 執行指令

給代理程式一個資料夾與明確的任務：

> 在我的範例專案中，執行現有的測試指令並回報結果，不要修改任何檔案。

代理程式會顯示指令的輸出內容，並告訴你它是否已結束或仍在執行中。若要讀取、編輯與搜尋檔案，代理程式會改用[檔案工具](/zh-hant/ai/file-tools)。

## 指令的執行方式

每個指令都會在虛擬終端機（pseudo-terminal）中執行，因此需要輸入內容的指令可以直接作答，無須另開新程序。

| 模式 | 適用情境 |
| --- | --- |
| **oneshot** | 會自行結束的指令，例如測試、建置或單次指令碼 |
| **long_running** | 伺服器、監聽程式（watcher），以及等待外部事件的程序 |
| **interactive** | REPL、終端機應用程式與互動式命令列工作階段 |

如果回傳結果包含 `status: running` 與 `session_id`，代表該程序仍在持續執行中。代理程式可以**讀取**它的輸出、**寫入**輸入給它，或**停止**它。若要回覆某個提示，代理程式必須寫入同一個工作階段；另外執行新指令並不會把輸入傳給原本的程序。

## 等待某項作業完成

當任務需要等待（例如等待建置寫出輸出檔或伺服器啟動）時，代理程式會使用 **Wait For** 工具，而不是執行 Shell 迴圈。它無須持續執行指令即可等待以下任一條件：

- 特定檔案出現
- 記錄檔中出現指定內容
- 某個程序或指令的工作階段結束
- 某個連接埠開啟，或某個網址開始回應

等待狀態會顯示在聊天的背景任務中。一旦條件達成、失敗或逾時，系統就會通知代理程式，在此期間它可以先處理其他工作。

## 工作資料夾與時間限制

當代理程式設定了 `workDir` 時，指令會在該資料夾執行；否則會在該聊天的工作資料夾中執行。指令會使用你的 Shell 環境，並載入你的專案與 Python 虛擬環境設定。除非在同一個工作階段中執行，否則各自獨立的指令不會共用暫存的 Shell 變數。

初次等待時間與指令的強制逾時上限分開計算。oneshot 指令最多會等待 30 秒以取得結果；若時間到了仍在執行，代理程式會收到目前的輸出內容並讓指令繼續執行。預設超過 30 分鐘後會強制停止指令。對於伺服器或監聽程式，應使用 long_running 模式，而不是將它視為失敗的 oneshot 指令。

## 設定

開啟**設定 → 外掛程式 → Code Runner**。

| 設定 | 變更內容 |
| --- | --- |
| **啟用 RTK** | 在代理程式讀取前壓縮冗長的指令輸出，以減少 Token 消耗。預設為開啟 |

如果在壓縮後的輸出中缺少你需要的細節，請要求執行範圍更精確的指令，或讀取記錄檔的相關片段。被截斷的輸出並不能證明指令執行成功。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 找不到指令（Command not found） | 確認該程式已安裝且可在你的 Shell 環境中使用 |
| 指令卡在等待輸入 | 請代理程式在同一個工作階段中回覆該提示。若指令等待的輸入無人能提供，該指令會立即結束 |
| 權限不足（Permission denied） | 檢查目標路徑與 macOS 權限。若已開啟沙盒，可點擊該步驟下方的提示列查看被阻擋的原因 |
| 指令逾時 | 閱讀最後的輸出內容，並在重新執行前選擇正確的執行模式 |
| 伺服器持續在背景執行 | 不再需要該伺服器時，請代理程式停止它的工作階段 |

程式碼執行器為代理程式提供你 Mac 上的真實終端機。可用於建置、測試、腳本、套件工具與開發伺服器。你已安裝的程式與你帳號的權限，決定了什麼可以執行。

<Warning>
除非你開啟代理程式的**沙盒**，否則指令會以你帳號對檔案與網路的存取權限真實執行。在任何會安裝軟體、變更檔案或影響線上服務的指令執行之前，請先檢視它。
</Warning>

## 開始之前

- 為你正在使用的代理程式開啟程式碼執行器。
- 聊天中的**權限**標籤決定代理程式何時要先詢問。**請求核准**會在執行指令之前詢問，而**替我核准**只會針對看起來不安全的操作詢問。請參閱[核准操作](/zh-hant/ai/agents)。
- 若要將代理程式的指令限制在工作資料夾內，並避開你的金鑰與其他 App，請在同一個標籤中開啟**沙盒**。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。

## 執行指令

為代理程式指定一個資料夾與具體的任務：

> 在我的範例專案中，執行現有的測試指令並回報結果。不要變更檔案。

代理程式會顯示指令的輸出，並告訴你它已完成還是仍在執行。若要讀取、編輯與搜尋檔案，代理程式會改用[檔案工具](/zh-hant/ai/file-tools)。

## 指令如何執行

每個指令都在偽終端機中執行，因此要求輸入的指令可以直接回應，而不需要啟動新的處理程序。

| 模式 | 適用於 |
| --- | --- |
| **oneshot** | 會自行結束的指令，例如測試、建置或腳本 |
| **long_running** | 伺服器、監看程式，以及等待外部事件的處理程序 |
| **interactive** | REPL、終端機 App 與互動式命令列工作階段 |

結果中出現 `status: running` 與 `session_id`，代表該處理程序仍在繼續。代理程式可以**讀取**它的輸出、對它**寫入**輸入，或**停止**它。若要回應提示，代理程式會寫入該工作階段；啟動另一個指令並不會回應提示。

## 等待某件事完成

當任務必須等待時，例如等待建置寫出輸出或伺服器啟動，代理程式會使用 **Wait For** 工具，而不是 shell 迴圈。它會在沒有任何指令執行的情況下，等待下列其中一項：

- 某個檔案出現
- 記錄檔中的某一行
- 某個處理程序或某個指令的工作階段結束
- 某個連接埠開啟，或某個位址有回應

等待會顯示在聊天的背景任務中。當條件達成、失敗或逾時時，代理程式會收到通知，並可在期間處理其他工作。

## 工作資料夾與時間限制

當代理程式設定了 `workDir` 時，指令會在其中執行，否則會在聊天的工作資料夾中執行。它們使用你的 shell，並已設定好你的專案與 Python 虛擬環境。個別的指令不會共用暫時的 shell 變數，除非它們在同一個工作階段中執行。

第一次等待與指令的硬性時間限制是分開的。oneshot 指令最多會等待 30 秒以取得結果；若屆時仍在執行，代理程式會取得目前為止的輸出，而工作繼續進行。指令預設在 30 分鐘後停止。對於伺服器或監看程式，請使用 long_running 模式，而不要把它當作失敗的 oneshot 指令。

## 設定

開啟**設定 → 外掛程式 → 程式碼執行器**。

| 設定 | 變更的內容 |
| --- | --- |
| **啟用 RTK** | 在代理程式讀取之前壓縮較長的指令輸出，以使用較少的 token。預設為開啟 |

如果壓縮後的輸出缺少你需要的細節，請要求更聚焦的指令，或記錄檔中的相關部分。被截斷的輸出並不能證明指令已成功。

## 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 找不到指令 | 確認該程式已安裝，且在你的 shell 中可用 |
| 指令在等待輸入 | 讓代理程式在同一個工作階段中回應提示。等待無人能提供的輸入的指令會立即結束 |
| 權限被拒絕 | 檢查目標路徑與 macOS 權限。開啟沙盒時，請點按步驟下方的那一行，查看它阻擋了什麼 |
| 指令逾時 | 閱讀最後的輸出，並在重新執行之前選擇正確的模式 |
| 伺服器持續執行 | 當你不再需要時，讓代理程式停止它的工作階段 |

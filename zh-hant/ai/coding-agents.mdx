description: "直接在 Enconvo 中與 Claude Code、Codex、Grok Build、Antigravity、Muse Code 和 Grok Bot 對話，並選擇它們可以使用哪些 Enconvo 功能。"

程式設計代理程式讓你直接在 Enconvo 聊天中使用你熟悉的 AI 寫程式工具，例如 Claude Code 與 Codex。當工作涉及專案資料夾中的程式碼時最適合使用：它們會顯示差異（diff）來編輯檔案、執行指令並在行動前詢問你，同時 Enconvo 會在聊天視窗、SmartBar 與手機上完整保留對話、歷史記錄與核准卡片。

| 程式設計代理程式 | 開發商 | 執行方式 |
| --- | --- | --- |
| **Claude Code** | Anthropic | 在你的 Mac 上執行，使用 Claude 登入 |
| **Codex** | OpenAI | 在你的 Mac 上執行，使用 ChatGPT 登入 |
| **Grok Build** | xAI | 在你的 Mac 上執行，使用 Grok 登入 |
| **Antigravity** | Google | 在你的 Mac 上執行，使用 Google 登入 |
| **Muse Code** | Meta | 在你的 Mac 上執行，使用 Meta 登入或本機模型 |
| **Grok Bot** | xAI | 在 xAI 雲端執行，透過你連接的例行程序（routine）運作 |

## 開始之前

每個程式設計代理程式在**設定 → 代理程式列表**中都有專屬頁面。點擊即可查看其**狀態**：

1. 如果顯示**未安裝**，請點擊**安裝**，或在終端機中執行畫面上顯示的指令後點擊**重新檢查**。若版本過舊則會顯示**更新**。
2. 在**帳號**底下點擊**使用 Claude 登入**、**使用 ChatGPT 登入**、**使用 Grok 登入**、**使用 Google 登入**或**使用 Meta 登入**。Enconvo 共用該代理程式在終端機命令列中的登入狀態。

當 Claude Code 或 Codex 的登入憑證將在十天內到期時，代理程式頁面、**更新**列表與專案看板都會提前提示並提供**重新登入**按鈕。看板任務若因程式設計代理程式登出而無法執行，狀態會顯示為**已暫停**，待你重新登入後隨即繼續。

使用本機模型執行的 Muse Code 無需登入 Meta 帳號。Grok Bot 則需要連接例行程序；請參閱[連接 Grok Bot](#連接-grok-bot)。

## 與程式設計代理程式對話

1. 在聊天視窗中，從代理程式卡片或代理程式選單選擇程式設計代理程式。
2. 選擇它要處理的專案資料夾。
3. 輸入你的需求並傳送。執行步驟、程式碼差異與指令會即時串流顯示在聊天中，需要確認的操作則會顯示為核准卡片供你回覆。

對話的核准規則遵循 Enconvo 的[權限模式](/zh-hant/ai/agents)。在**完整取用**模式下，新的 Claude Code 對話會以**略過權限**（當 Claude Code 本身設定允許時）啟動，而新的 Codex 對話會以**完整取用**啟動，因此兩者在執行操作前都不會停下來詢問。

在 Worktree（工作樹）對話中，側邊面板的 **Pull Request**（拉取請求）分頁（**⌃⇧P**）會顯示該分支在 GitHub 上的 Pull Request，或協助建立一個新的。請參閱[聊天視窗](/zh-hant/ai/chat)。

若要接續先前的對話，請選擇**繼續先前的工作階段**。你在該代理程式自己的終端機命令列中啟動的工作階段也會一併列出，並顯示你當時取的名稱。

你也可以將與 Mavis 開始的對話轉交給程式設計代理程式，只需開啟以它為對象的新對話接續即可。其他代理程式也能將程式設計代理程式作為子代理使用，專案也可以指派任務給它們或指定其中之一擔任專案負責人。請參閱[子代理](/zh-hant/ai/agents)與[專案](/zh-hant/ai/projects)。

### Claude Code：推理強度、快速模式與 Ultracode

Claude Code 對話中的推理強度選擇器可調整其思考深度。當該工作階段支援時，選擇器還會顯示**快速模式**與 **Ultracode** 開關。開啟 Ultracode 後，無論你選擇哪種推理強度，接下來的整個工作階段都會啟用工作流程編排，且切換推理強度時仍會保持開啟。輸入 `/effort ultracode` 也有相同效果。在新對話中，你可以在傳送第一則訊息前就先設定好快速模式與 Ultracode。

### Codex：警告訊息

Codex 的警告訊息不會佔用對話版面。輸入 `/warnings` 即可列出它們。

### Muse Code：在終端機中繼續

若要在終端機中繼續某個 Muse Code 對話，請選擇**在終端機中繼續**，或點擊**複製指令**複製執行命令。系統會在該資料夾中以 `muse resume` 開啟對話。當你在終端機中結束 Muse Code 並回到 Enconvo 傳送訊息時，你在終端機中執行的對話輪次會同步回該聊天中。

Muse Code 的核准提問會展示該次編輯將做出的變更。當你拒絕某個步驟時，你在點擊**拒絕**時附帶輸入的文字會在同一輪直接傳送給 Muse Code，讓它能立即據此調整。它的技能與 `/compact` 指令位於 `/` 選單中。

<Note>
Muse Code 的貢獻者模式預設為開啟，這會允許 Meta 使用你的提示詞與程式碼來訓練其模型。Enconvo 不會更動這項設定；如有需要請在 Muse Code 自己的設定中關閉。
</Note>

## 選擇程式設計代理程式可使用的 Enconvo 功能

程式設計代理程式可以在對話中使用 Enconvo 的外掛程式，例如傳訊給你的其他 Enconvo 代理程式、圖像與影片生成、記憶、瀏覽器以及電腦操作。在**設定 → 代理程式列表**的該代理程式頁面中，於 **Enconvo 能力**底下：

- 關閉 **Enconvo 能力**，即可禁止該代理程式存取所有 Enconvo 外掛程式。
- 或點擊**外掛程式**旁的**自訂**，逐一關閉特定外掛程式。關閉的外掛程式將對該代理程式隱藏，且任何呼叫都會被拒絕。

這項變更會立即套用到該代理程式已開啟的對話。位於客戶端工作區（Workspace）中的程式設計代理程式對話則完全受限於該工作區內部。

## 連接 Grok Bot

Grok Bot 執行於 xAI 的雲端。Enconvo 會將每則訊息傳送到你在 Grok Bot 建立的 Webhook 例行程序，並在回覆送達時顯示在聊天中（即使回覆較晚到達）。

1. 在 Grok Bot 中建立一個以 Webhook 作為觸發器的例行程序。
2. 在**設定 → 代理程式列表**中開啟 **Grok Bot**，點擊**例行程序說明**旁的**複製**，並將內容貼到該例行程序中。
3. 在同一頁面的憑證欄位填入該例行程序的 Webhook 網址與金鑰，接著點擊**測試**。測試最多會等待約 90 秒以接收例行程序的回覆。

在連接完成之前，代理程式選擇器會將 Grok Bot 顯示為**未設定**。每則訊息都會消耗你 Grok Bot 方案的每週額度。點擊**停止**只會讓 Enconvo 停止等待：該例行程序仍會在雲端繼續執行，稍後傳回的回覆依然會加入到聊天中。

每則訊息上限為 32,000 個字元。附加的檔案與圖片會留在你的 Mac 上，僅文字內容會被傳送出去。

### 讓 Grok Bot 呼叫 Enconvo

透過 Enconvo 的 MCP 伺服器，Grok Bot 可以回覆你的聊天、通知你的 Mac 與已配對的手機，以及請你 Mac 上的代理程式執行任務。

1. 在 Grok Bot 頁面的 **Grok Bot 呼叫 Enconvo** 底下點擊**連接**。你需要先登入 Enconvo 帳號。
2. 在 Grok Bot 中開啟 **Plugins**，加入畫面上顯示的**伺服器 URL**，並在 Grok Bot 要求時使用你的 Enconvo 帳號登入。

對你 Mac 上代理程式發出的每筆請求都會等待你的核准，除非你開啟**一律允許 ask_mac**。所有請求都會列在**這台 Mac 上的 Grok Bot** 對話中。點擊**中斷連線**即可停止 Grok Bot 呼叫 Enconvo；中斷連線或你的 Mac 離線時，仍在等待中的請求將會被撤回。

## 疑難排解

| 問題 | 解決方式 |
| --- | --- |
| 對話顯示代理程式尚未登入 | 在**設定 → 代理程式列表**中開啟該代理程式頁面並點擊**重新登入**。呼叫該代理程式的 Mavis 對話或 App 也會收到相同的登入錯誤，其看板任務則會暫停並顯示為**已暫停**，直到你登入為止。 |
| 代理程式顯示**未安裝**或版本過舊 | 在其頁面上點擊**安裝**或**更新**，然後點擊**重新檢查**。 |
| Muse Code 顯示 Enconvo 需要更新 | 更新 Enconvo 以相容較新版本的 Muse Code。 |
| Grok Bot 顯示**未設定** | 在 Grok Bot 頁面填入例行程序的 Webhook 網址與金鑰，然後點擊**測試**。 |
| Grok Bot 測試顯示訊息過多 | 例行程序或 Enconvo 目前阻擋了過多頻繁訊息。請稍後再試。 |
| 在終端機開啟的 Muse Code 對話無法傳送訊息 | 請先在終端機中結束 Muse Code 讓對話輪次同步回來，再從 Enconvo 傳送。 |

description: "在 Enconvo 中與 Claude Code、Codex、Grok Build、Antigravity、Muse Code 和 Grok Bot 對話，並選擇它們可以使用哪些 Enconvo 功能。"
---

程式設計代理就是你已經在用的 AI 寫程式工具，例如 Claude Code 和 Codex，只是改在 Enconvo 的聊天中執行。當工作內容是專案資料夾裡的程式碼時，就可以使用它：它會以 diff 編輯檔案、執行指令，並在動手前先詢問；而 Enconvo 會在聊天視窗、SmartBar 和你的手機上保留聊天、歷史紀錄與核准。

| 程式設計代理 | 開發商 | 執行位置 |
| --- | --- | --- |
| **Claude Code** | Anthropic | 在你的 Mac 上，使用 Claude 登入 |
| **Codex** | OpenAI | 在你的 Mac 上，使用 ChatGPT 登入 |
| **Grok Build** | xAI | 在你的 Mac 上，使用 Grok 登入 |
| **Antigravity** | Google | 在你的 Mac 上，使用 Google 登入 |
| **Muse Code** | Meta | 在你的 Mac 上，使用 Meta 登入，或使用其本機模型 |
| **Grok Bot** | xAI | 在 xAI 的雲端，透過你連接的例行程序執行 |

## 開始之前

每個程式設計代理在 **設定 → 代理程式列表** 中都有自己的頁面。點一下即可查看它的 **狀態**：

1. 如果顯示 **未安裝**，請點一下 **安裝**，或在「終端機」中執行畫面上顯示的指令，然後點一下 **重新檢查**。版本太舊時會顯示 **更新**。
2. 在 **帳號** 下，點一下 **使用 Claude 登入**、**使用 ChatGPT 登入**、**使用 Grok 登入**、**使用 Google 登入** 或 **使用 Meta 登入**。Enconvo 使用的登入狀態與該代理在「終端機」中自己的指令列相同。

當 Claude Code 或 Codex 的登入將在十天內到期時，代理的頁面、**更新** 列表和專案的看板都會提示，並附上 **重新登入**。如果看板任務的程式設計代理已登出，該任務會維持 **已暫停**，並在你登入後自動重新執行。

使用本機模型的 Muse Code 不需要 Meta 登入。Grok Bot 則需要一個例行程序；請參閱[連接 Grok Bot](#連接-grok-bot)。

## 與程式設計代理對話

1. 在聊天視窗中，從代理程式卡片或代理程式選單選擇該程式設計代理。
2. 選擇它要處理的專案資料夾。
3. 輸入你的需求並傳送。它的步驟、diff 和指令會即時顯示在聊天中，而它的核准提問會以卡片呈現，供你回答。

聊天中的核准遵循 Enconvo 的[權限模式](/zh-hant/ai/agents)。在 **完整取用** 下，新的 Claude Code 聊天會以 **略過權限** 開始（在 Claude Code 自己的設定允許時），新的 Codex 聊天則以 **完整取用** 開始，因此兩者在動手前都不會詢問。

在 worktree 聊天中，側邊面板的 **拉取請求** 分頁（**⌃⇧P**）會顯示該分支在 GitHub 上的拉取請求，或建立一個新的。請參閱[聊天視窗](/zh-hant/ai/chat)。

若要接續先前的工作階段，請選擇 **繼續先前的工作階段**。你在代理自己的指令列中開始的工作階段也會列出，並以你取的名稱顯示。

你也可以把用 Mavis 開始的聊天交給程式設計代理，方法是在與它的新聊天中繼續。其他代理程式可以把程式設計代理當作子代理使用，專案也可以交付任務給它們，或由其中一個主導專案。請參閱[子代理](/zh-hant/ai/agents)和[專案](/zh-hant/ai/projects)。

### Claude Code：推理強度、快速模式與 Ultracode

Claude Code 聊天中的強度選擇器用來設定它的推理強度。當工作階段支援時，選擇器也會顯示 **快速模式** 和 **Ultracode** 開關。Ultracode 會在該工作階段的剩餘時間內，以你選擇的強度開啟工作流程編排，而且更改強度後仍會維持開啟。輸入 `/effort ultracode` 也有同樣效果。在新的聊天中，你可以在傳送第一則訊息之前先設定快速模式和 Ultracode。

### Codex：警告

Codex 的警告不會出現在對話中。輸入 `/warnings` 即可列出。

### Muse Code：在終端機中繼續

若要在「終端機」中繼續 Muse Code 聊天，請選擇 **在終端機中繼續**，或選擇 **複製指令** 來複製指令。聊天會在其資料夾中以 `muse resume` 開啟。當你在那裡結束 Muse Code，並再次從 Enconvo 傳送訊息時，你在「終端機」中進行的回合會回到聊天中。

Muse Code 的核准提問會顯示編輯將造成的變更。當你拒絕某個步驟時，你在 **拒絕** 旁輸入的內容會在同一回合傳給 Muse Code，讓它能立刻據此行動。它的技能和 `/compact` 都在 `/` 選單中。

<Note>
Muse Code 的 Contributor mode 預設為開啟，這會讓 Meta 以你的提示詞和程式碼訓練其模型。Enconvo 不會更動此設定；若要關閉，請在 Muse Code 自己的設定中進行。
</Note>

## 選擇程式設計代理可以在 Enconvo 中使用什麼

程式設計代理可以在聊天中使用 Enconvo 的外掛程式，例如傳訊息給你的 Enconvo 代理程式、建立圖片和影片、記憶、瀏覽器和電腦操作。在 **設定 → 代理程式列表** 中該代理的頁面，**Enconvo 能力** 底下：

- 關閉 **Enconvo 能力**，可讓該代理無法使用 Enconvo 的所有外掛程式。
- 或者點一下 **外掛程式** 旁的 **自訂**，一次關閉一個外掛程式。關閉的外掛程式會對該代理隱藏，其呼叫也會被拒絕。

此變更也會套用到該代理已開啟的聊天。客戶工作區中的程式設計代理聊天會完全留在該工作區內。

## 連接 Grok Bot

Grok Bot 在 xAI 的雲端執行。Enconvo 會把每則訊息傳送到你在 Grok Bot 中建立的 Webhook 例行程序，並在聊天中顯示回覆，即使回覆較晚才到達也一樣。

1. 在 Grok Bot 中，建立一個使用 Webhook 觸發條件的例行程序。
2. 在 **設定 → 代理程式列表** 中開啟 **Grok Bot**，點一下 **例行程序說明** 旁的 **複製**，然後貼到該例行程序中。
3. 在同一頁新增該例行程序的 webhook URL 和金鑰作為憑證，然後點一下 **測試**。測試最多會等待例行程序回覆約 90 秒。

在例行程序連接之前，代理程式選擇器會將 Grok Bot 顯示為 **未設定**。每則訊息都會使用你 Grok Bot 方案的每週用量。**停止** 只會讓 Enconvo 不再等待：例行程序的執行仍會在雲端繼續，之後才到的回覆仍會加入聊天中。

一則訊息最多可有 32,000 個字元。附加的檔案和圖片會留在你的 Mac 上；只會傳送文字。

### 讓 Grok Bot 呼叫 Enconvo

透過 Enconvo 的 MCP 伺服器，Grok Bot 可以回覆你的聊天、通知你的 Mac 和已配對的手機，並請你 Mac 上的代理程式執行任務。

1. 在 Grok Bot 的頁面，**Grok Bot 呼叫 Enconvo** 底下，點一下 **連接**。你需要先登入你的 Enconvo 帳號。
2. 在 Grok Bot 中開啟 **Plugins**，新增所顯示的 **伺服器 URL**，並在 Grok Bot 要求時使用你的 Enconvo 帳號登入。

每個傳給你 Mac 上代理程式的請求都會等待你的核准，除非你開啟 **一律允許 ask_mac**。這些請求會列在 **這台 Mac 上的 Grok Bot** 聊天中。點一下 **中斷連線** 可讓 Grok Bot 停止呼叫 Enconvo；中斷連線或你的 Mac 離線，都會撤回仍在等待的請求。

## 疑難排解

| 問題 | 解決方法 |
| --- | --- |
| 聊天顯示代理尚未登入 | 在 **設定 → 代理程式列表** 中開啟該代理的頁面，點一下 **重新登入**。呼叫過該代理的 Mavis 聊天或 App 也會收到相同的登入錯誤，其看板任務會維持 **已暫停**，直到你登入。 |
| 代理顯示 **未安裝**，或版本太舊 | 在其頁面點一下 **安裝** 或 **更新**，然後點一下 **重新檢查**。 |
| Muse Code 顯示 Enconvo 需要更新 | 更新 Enconvo，以配合較新的 Muse Code。 |
| Grok Bot 顯示 **未設定** | 在 Grok Bot 的頁面新增例行程序的 webhook URL 和金鑰，然後點一下 **測試**。 |
| Grok Bot 的測試顯示訊息太多 | 例行程序或 Enconvo 暫時拒絕了過多訊息。請稍後再試。 |
| 在「終端機」中開啟的 Muse Code 聊天無法傳送 | 在「終端機」中結束 Muse Code 以帶回其回合，然後從 Enconvo 傳送。 |

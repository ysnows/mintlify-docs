---
title: "變數"
description: "在提示詞與其他支援範本的欄位中插入目前的輸入、選取的文字、應用程式上下文或日期。"
---

變數會填入每次都會變動的值，例如你在 SmartBar 中輸入的文字、在其他應用程式中選取的文字，或今天的日期。在支援範本的提示詞與偏好設定中使用變數，同一個 AI 指令、代理程式指示或工作流程就能處理你眼前的任何內容。開啟**設定 → 變數**即可瀏覽可用的變數。

## 可用變數

| 變數 | 提供的值 |
| --- | --- |
| Input Text | 目前的 SmartBar 輸入 |
| Selection Text | 目前應用程式中選取的文字 |
| Latest Clipboard | 最近的剪貼簿內容 |
| Active Application | 最前方應用程式的資訊 |
| Active Application Screenshot | 最前方視窗的圖片 |
| Active Screen Screenshot | 目前作用中螢幕的圖片 |
| Focused Window Content | 從目前聚焦視窗中擷取的內容 |
| Browser Active Tab | 目前分頁的 URL 以及可取得的頁面內容 |
| Current Folder | Finder 中開啟的資料夾 |
| Selected Files | Finder 中選取的檔案 |
| History Messages | 目前對話的歷史記錄 |
| Now | 目前的日期與時間 |
| Your Language | 你閱讀所用的語言：即你的**回覆語言**，設為「自動」時則為系統語言 |
| Opened Applications | 正在執行的應用程式資訊 |
| Opened Application Names | 正在執行的應用程式名稱 |

## 使用變數

1. 開啟你要自訂的 AI 指令、代理程式指示或工作流程欄位。
2. 確認該欄位支援變數；如果有選擇器，就使用選擇器。
3. 插入需要的值，並用無害的範例內容進行測試。
4. 檢查輸入為空或缺少權限時，結果是否會有所變化。

文字提示詞可以使用受支援的範本名稱，例如：

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

能使用哪些變數取決於指令與上下文，並非每個文字欄位都會解析範本。截圖與應用程式內容可能需要 macOS 權限，也需要模型支援相應類型的輸入。

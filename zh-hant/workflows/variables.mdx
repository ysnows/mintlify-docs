---
title: "變數"
description: "把目前輸入、選取的文字、App 上下文或日期插入提示詞，以及其他支援範本的欄位。"
---

變數會填入每次都不同的值，例如你在 SmartBar 中輸入的文字、在其他 App 中選取的文字，或今天的日期。在支援範本的提示詞和偏好設定中使用它們，同一個 AI 指令、Agent 指示或工作流程就能處理你眼前的任何內容。開啟 **設定 → 變數** 即可瀏覽可用的變數。

## 可用變數

| 變數 | 提供的值 |
| --- | --- |
| Input Text | 目前的 SmartBar 輸入 |
| Selection Text | 目前 App 中選取的文字 |
| Latest Clipboard | 最近一次的剪貼簿內容 |
| Active Application | 最前方 App 的資訊 |
| Active Application Screenshot | 最前方視窗的影像 |
| Active Screen Screenshot | 使用中螢幕的影像 |
| Focused Window Content | 從焦點視窗擷取的內容 |
| Browser Active Tab | 使用中分頁的 URL 和可取得的頁面內容 |
| Current Folder | 在 Finder 中開啟的資料夾 |
| Selected Files | 在 Finder 中選取的檔案 |
| History Messages | 目前的對話記錄 |
| Now | 目前的日期和時間 |
| Your Language | 你閱讀所用的語言：你的 **回覆語言**，設為自動時則為系統語言 |
| Opened Applications | 執行中 App 的資訊 |
| Opened Application Names | 執行中 App 的名稱 |

## 使用變數

1. 開啟你想自訂的 AI 指令、Agent 指示或工作流程欄位。
2. 確認該欄位支援變數；如果有選擇器，請使用它。
3. 插入你需要的值，並用無害的範例內容測試。
4. 檢查輸入為空或缺少權限時，結果是否會改變。

文字提示詞可以使用支援的範本名稱，例如：

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

可以使用哪些變數取決於指令和情境，而且並非每個文字欄位都會解析範本。螢幕截圖和 App 內容可能需要 macOS 權限，以及能接受該類輸入的模型。

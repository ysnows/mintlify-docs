---
title: "外掛程式"
description: "尋找、安裝及管理能為 Enconvo 帶來新指令、工具和連線的外掛程式。"
---

外掛程式會為 Enconvo 新增指令、供應商、工具和 API 路由。開啟 **設定 → 外掛程式**，即可搜尋目錄、安裝你需要的項目，並管理你已有的項目。

## 尋找並安裝外掛程式

<Steps>
  <Step title="開啟外掛程式">
    開啟 **設定 → 外掛程式**。按 **⌘K** 可跳到搜尋框。
  </Step>
  <Step title="搜尋">
    依任務或外掛程式的名稱搜尋。當目前的分頁沒有相符的項目時，頁面會提供其他分頁上的結果。
  </Step>
  <Step title="開啟它的頁面">
    點按外掛程式，閱讀它的說明、包含的內容，以及需要的條件。
  </Step>
  <Step title="安裝並設定">
    如果尚未安裝，請點按 **安裝**。然後加入它要求的任何供應商憑證或指令設定。
  </Step>
  <Step title="使用">
    點按 **立即體驗**、從 SmartBar 執行它的其中一個指令，或為應該使用它的 Agent 啟用它的工具。
  </Step>
</Steps>

外掛程式的頁面會列出它的指令及其設定。當你從 Enconvo 的其他地方開啟某個指令的設定時，你會進入該指令所屬外掛程式中的那個指令。

當外掛程式在聊天視窗中有檢視畫面時，例如[電子郵件](/zh-hant/integrations/email)，它的頁面會有 **開啟** 按鈕，可在那裡開啟該檢視，因此其中的內容，例如新增信箱，只需點按一下。有多個檢視的外掛程式則會有 **開啟** 選單。

## 外掛程式頁面

| 分頁 | 顯示內容 |
| --- | --- |
| **Enconvo** | 依類別排列的目錄。頂端的 **已安裝** 列出你已連接的連接器，以及你安裝或製作的外掛程式。**新上架** 顯示新的項目。 |
| **內建** | Enconvo 隨附的外掛程式：**搜尋** 包含你從 SmartBar 搜尋的清單，**控制** 包含電腦操作和使用瀏覽器。 |
| **Mac App** | 這台 Mac 上 Agent 可以使用的 App，例如行事曆、郵件和備忘錄。連接其中一個時，會向 macOS 要求權限，而不是要求帳號。請參閱 [Apple App](/zh-hant/integrations/apple-ecosystem)。 |
| **PopBar** | 相容 PopClip 的擴充功能，可在 [PopBar](/zh-hant/features/popbar) 中加入按鈕。 |
| **個人** | 你製作或匯入的外掛程式，以及你發佈到 Enconvo 商店的外掛程式。 |

若要帶入目錄以外的外掛程式，請使用 **建立外掛程式** 或 **新增** 選單：

| 選項 | 作用 |
| --- | --- |
| **建立外掛程式** | 描述你的需求，Agent 就會撰寫、測試並安裝外掛程式。 |
| **上傳外掛壓縮檔…** | 安裝 `.enconvo` 檔案，或 Claude Code 或 Codex 外掛程式的 `.zip`。 |
| **從 GitHub 加入…** | 從外掛程式儲存庫，或 Claude Code 或 Codex 市集安裝。 |
| **新增 MCP 伺服器…** | 開啟 [MCP 伺服器](/zh-hant/features/mcp)。 |
| **加入 PopBar 擴充功能…** 和 **從 PopClip 匯入…** | 將 PopClip 擴充功能加入 PopBar。 |
| **新增技能…** | 開啟[技能](/zh-hant/configuration/skills)。 |

## 找到合適的功能

| 任務 | 指南 |
| --- | --- |
| 改進或翻譯文字 | [寫作工具](/zh-hant/features/writing-tools)、[翻譯](/zh-hant/ai/translate) |
| 搜尋並閱讀網頁 | [網頁搜尋](/zh-hant/ai/web-search)、[讀取網頁](/zh-hant/ai/web-fetch) |
| 處理檔案或終端機 | [檔案工具](/zh-hant/ai/file-tools)、[程式碼執行器](/zh-hant/ai/code-runner) |
| 產生圖片、影片或語音 | [供應商目錄](/zh-hant/providers/catalog) |
| 處理郵件、行事曆、備忘錄或提醒事項 | [Apple App](/zh-hant/integrations/apple-ecosystem) |
| 連接外部工具 | [MCP 伺服器](/zh-hant/features/mcp) |
| 加入可重複使用的 Agent 指示 | [技能](/zh-hant/configuration/skills) |

商店中有些外掛程式會帶來整個服務的工具和指引：

- **Shopify** 讓 Agent 使用 Shopify 官方的 CLI 管理你的 Shopify 商店，並在做出每項變更之前先讓你看過。它可以跨多間商店運作。當你沒有指名時，Agent 會詢問是哪間商店，在它顯示的每項變更中標明商店名稱，並對於針對多間商店的變更，每間商店各執行一次。
- **Expo** 帶來 Expo 團隊的官方技能和 Expo MCP Server，取代較舊的唯讀 Expo 連接器。Agent 會建置、升級並發佈 Expo 和 React Native App，讀取你的 EAS 建置、記錄、當機和評論，而且只有在你核准每一項之後，才會開始建置和提交。你已有的 Expo 登入會沿用。

**Obsidian**、**Tailscale** 和 **Cloudflare** 也是外掛程式商店的外掛程式：請從外掛程式頁面安裝。你已有的副本會繼續運作並自行更新。Agent 從一開始就知道你安裝了 Obsidian、Tailscale、Cloudflare 和 Shopify 外掛程式中的哪些。

[內建指令目錄](/zh-hant/extensions/built-in-extensions)列出了已有文件說明的指令系列。你的版本中的商店項目和已安裝的外掛程式，可能與它不同。

## 指令、供應商和工具

- **指令**是你執行的動作。
- **供應商**提供某項功能，例如模型或聲音。
- **工具**是 Agent 可以呼叫的動作。

安裝外掛程式不一定會讓它的供應商成為預設，也不一定會為每個 Agent 開啟每個工具。

在 SmartBar 中，使用指令選擇器（預設為 `@`），或搜尋指令的標題。`/` 動作選單的用途不同；它不是外掛程式名稱的前綴。

## 在連接器中使用多個帳號

在你的 Mac 上登入的連接器，例如 Notion、Webflow 和 Linear，可以保存多個帳號。

- 在連接器的頁面上，選擇 **連接其他帳號** 來新增一個。**已連接的帳號** 會列出全部。
- 在 Agent 應該用來傳送或建立內容的帳號上選擇 **設為預設**。Agent 會從每個帳號讀取。
- 在請求中指名帳號，例如「用我的工作信箱寄出」，Agent 就會使用那一個。
- **中斷連線** 會移除一個帳號；**中斷所有帳號的連線** 會全部移除。

在客戶的工作區中，每個連接器各自保有預設帳號，顯示為 **預設於** 加上工作區的名稱。除非你指名其他帳號，否則 Agent 在那裡會使用該客戶的帳號。

## 關閉、更新或移除

在外掛程式的頁面上：

- 開關可開啟或關閉外掛程式。關閉時，Agent 無法找到或使用它，SmartBar 也不會列出它，或讓你用 `@` 叫出它。它的設定會被保留。
- **⋯** 選單有 **設定**、**檢查更新** 和 **解除安裝**。Enconvo 隨附的外掛程式無法解除安裝。

解除安裝外掛程式之前，請先檢查使用它的 Agent、工作流程和自訂指令。重設指令會還原它的設定。重設共用的供應商，也可能變更其他功能所使用的憑證；請參閱[憑證](/zh-hant/configuration/credentials)。

## 分享外掛程式

你可以用連結分享你製作的外掛程式，或資料夾位於這台 Mac 上的外掛程式，任何拿到連結的人都能安裝。

1. 在外掛程式的頁面上，點按 **分享…**。如果 Enconvo 要求，請登入你的 Enconvo 帳號。
2. 在 **誰可以安裝** 之下，選擇 **任何擁有連結的人** 或 **外掛程式商店**。
3. 點按 **發佈**，然後點按 **複製連結** 並傳送該連結。

Enconvo 在連結安裝每個版本之前，都會先檢查並審核，而連結會開啟外掛程式在 enconvo.com 上的頁面。每個安裝它的人都會得到自己的一份副本；它的資料、你的金鑰和你的登入都會留在你的 Mac 上。

若要變更已分享的外掛程式，請再次點按 **分享…**：傳送較新的版本、變更 **誰可以安裝**，或點按 **停止分享**。連結會失效，而已安裝該外掛程式的人會保留他們的副本。如果審核拒絕了某個版本，**分享…** 會顯示原因並提供 **在聊天中修正**。若要分享[空間](/zh-hant/features/spaces)，請參閱[分享空間](/zh-hant/features/spaces)。

## 自行打造

請使用[開發擴充功能](/zh-hant/extensions/developing)中的 TypeScript SDK 和 CLI。CLI 將建置、安裝、產生結構描述和發佈歸在 `enconvo plugin` 之下。發佈會讓外掛程式可在你自己的開發環境以外使用。

Enconvo 也會安裝 Codex、Claude Code 和可攜式外掛程式。請參閱 [Plugin Formats](/extensions/plugin-formats) 和[安裝外掛程式](/zh-hant/extensions/installing-plugins)。

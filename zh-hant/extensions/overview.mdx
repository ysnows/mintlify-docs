---
title: "外掛程式"
description: "尋找、安裝並管理外掛程式，為 Enconvo 增添新指令、工具與連線能力。"
---

外掛程式能為 Enconvo 加入指令、服務供應商、工具與 API 路由。開啟 **設定 → 外掛程式**，即可搜尋目錄、安裝所需項目並管理已擁有的外掛程式。

## 尋找並安裝外掛程式

<Steps>
  <Step title="開啟外掛程式">
    開啟 **設定 → 外掛程式**。按 **⌘K** 可快速跳至搜尋框。
  </Step>
  <Step title="搜尋">
    依任務或外掛程式名稱搜尋。若目前分頁沒有相符項目，頁面會提示你在其他分頁找到的結果。
  </Step>
  <Step title="開啟詳細頁面">
    點選外掛程式以閱讀說明、包含的內容以及所需條件。
  </Step>
  <Step title="安裝並設定">
    如果尚未安裝，請點選 **安裝**。接著補齊它所需的服務供應商憑證或指令設定。
  </Step>
  <Step title="開始使用">
    點選 **立即試用**、從 SmartBar 執行其中一個指令，或為需要它的代理程式啟用其工具。
  </Step>
</Steps>

外掛程式的頁面會列出它的所有指令與設定。當你從 Enconvo 其他地方開啟某個指令的設定時，就會直接跳到該外掛程式頁面中的對應指令。

當外掛程式在聊天視窗中有專屬檢視（例如[電子郵件](/zh-hant/integrations/email)）時，它的頁面會提供 **開啟** 按鈕直接在聊天視窗打開該檢視，讓你一鍵就能進入裡面的功能（例如新增信箱）。擁有多個檢視的外掛程式則會改以 **開啟** 選單顯示。

## 外掛程式頁面

| 分頁 | 顯示內容 |
| --- | --- |
| **Enconvo** | 依分類排列的目錄。頂端的 **已安裝** 會列出你已連接的連接器，以及你安裝或建立的外掛程式。**最近新增** 則顯示新上架項目。 |
| **內建** | 隨 Enconvo 一同提供的外掛程式：**搜尋** 包含你可從 SmartBar 搜尋的項目清單，**控制** 則包含「電腦操作」與「使用瀏覽器」。 |
| **Mac App** | 這台 Mac 上可讓代理程式使用的應用程式，例如行事曆、郵件與備忘錄。連接這類項目會向 macOS 請求權限，而不需要帳號密碼。請參閱 [Apple 生態整合](/zh-hant/integrations/apple-ecosystem)。 |
| **PopBar** | 與 PopClip 相容的擴充功能，可為 [PopBar](/zh-hant/features/popbar) 新增按鈕。 |
| **個人** | 你建立或匯入的外掛程式，以及你發佈到 Enconvo 商店的作品。 |

若要從目錄以外引入外掛程式，請使用 **建立外掛程式** 或 **新增** 選單：

| 選項 | 功能 |
| --- | --- |
| **建立外掛程式** | 描述你的需求，代理程式就會為你編寫、測試並安裝該外掛程式。 |
| **上傳外掛壓縮檔…** | 安裝 `.enconvo` 檔案，或 Claude Code／Codex 外掛程式 `.zip` 壓縮檔。 |
| **從 GitHub 加入…** | 從外掛程式儲存庫，或 Claude Code／Codex 市集安裝。 |
| **新增 MCP 伺服器…** | 開啟 [MCP 伺服器](/zh-hant/features/mcp)。 |
| **新增 PopBar 擴充功能…** 與 **從 PopClip 匯入…** | 將 PopClip 擴充功能加入 PopBar。 |
| **新增技能…** | 開啟[技能](/zh-hant/configuration/skills)。 |

## 尋找對應的功能

| 任務 | 指南 |
| --- | --- |
| 改善或翻譯文字 | [寫作工具](/zh-hant/features/writing-tools)、[翻譯](/zh-hant/ai/translate) |
| 搜尋與閱讀網頁 | [網頁搜尋](/zh-hant/ai/web-search)、[讀取網頁](/zh-hant/ai/web-fetch) |
| 處理檔案或終端機 | [檔案工具](/zh-hant/ai/file-tools)、[程式碼執行器](/zh-hant/ai/code-runner) |
| 生成圖片、影片或語音 | [服務供應商目錄](/zh-hant/providers/catalog) |
| 操作郵件、行事曆、備忘錄或提醒事項 | [Apple 生態整合](/zh-hant/integrations/apple-ecosystem) |
| 連接外部工具 | [MCP 伺服器](/zh-hant/features/mcp) |
| 加入可重複使用的代理程式指示 | [技能](/zh-hant/configuration/skills) |

商店中的部分外掛程式整合了整套服務的工具與指引：

- **Shopify** 讓代理程式透過 Shopify 官方 CLI 管理你的 Shopify 商店，並在每次變更前先向你展示內容。它支援多個商店：未指定時代理程式會詢問是哪一間，並在顯示每項變更時標明商店名稱；針對多個商店的變更則會逐店執行。
- **Expo** 帶來 Expo 團隊的官方技能與 Expo MCP Server，取代舊版的唯讀 Expo 連接器。代理程式可建置、升級並發佈 Expo 與 React Native App，讀取 EAS 建置紀錄、日誌、當機報告與審查狀態，並只在你逐次核准後啟動建置與送審。原本已完成的 Expo 登入狀態會直接沿用。

**Obsidian**、**Tailscale** 與 **Cloudflare** 也都屬於外掛程式商店的外掛程式：請從外掛程式頁面安裝。你原先已安裝的副本會繼續運作並自動更新。代理程式從一開始就能知道你安裝了 Obsidian、Tailscale、Cloudflare 或 Shopify 中的哪些外掛程式。

[內建指令目錄](/zh-hant/extensions/built-in-extensions)列出了已記錄的指令類別。你目前版本中的商店項目與已安裝外掛程式可能與之有所差異。

## 指令、服務供應商與工具

- **指令** 是你主動執行的動作。
- **服務供應商** 提供底層能力，例如模型或語音。
- **工具** 是代理程式可以呼叫的動作。

安裝外掛程式不一定會立刻將其服務供應商設為預設，也不一定會為所有代理程式開啟全部工具。

在 SmartBar 中，請使用指令選擇器（預設為 `@`）或搜尋指令標題。`/` 動作選單有其他用途，並不是外掛程式名稱的前綴。

## 在連接器中使用多個帳號

在 Mac 上登入的連接器（例如 Notion、Webflow 與 Linear）可同時保有超過一個帳號。

- 在該連接器的頁面點選 **連接其他帳號** 即可新增。**已連接的帳號** 會列出所有帳號。
- 在你想讓代理程式用來傳送或建立內容的帳號上點選 **設為預設**。代理程式則可從所有帳號讀取資料。
- 在請求中指名帳號（例如「用我的工作信箱寄出」），代理程式就會使用該帳號。
- **中斷連線** 會移除單一帳號；**中斷所有帳號連線** 則會移除全部。

在客戶的工作區（Workspace）中，每個連接器都會保有自己獨立的預設帳號，顯示為 **預設於** 加上工作區名稱。除非你另外指定，否則代理程式在該工作區會使用該客戶的帳號。

## 停用、更新或移除

在外掛程式的頁面中：

- 開關可開啟或關閉該外掛程式。關閉期間，代理程式無法找到或使用它，SmartBar 也不會列出它或讓你用 `@` 呼叫。它的設定仍會保留。
- **⋯** 選單包含 **設定**、**檢查更新** 與 **解除安裝**。隨 Enconvo 附帶的內建外掛程式無法解除安裝。

解除安裝外掛程式前，請先檢查有哪些代理程式、工作流程與自訂指令正在使用它。重設指令會還原該指令的設定。重設共用的服務供應商則可能一併影響其他功能所使用的憑證；請參閱[憑證](/zh-hant/configuration/credentials)。

## 分享外掛程式

你可以透過連結分享自己製作的外掛程式，或是這台 Mac 上某個資料夾裡的外掛程式，讓拿到連結的人都能安裝。

1. 在外掛程式頁面點選 **分享…**。若 Enconvo 要求登入，請登入你的 Enconvo 帳號。
2. 在 **誰可以安裝** 下方選擇 **知道連結的任何人** 或 **外掛程式商店**。
3. 點選 **發佈**，接著點選 **複製連結** 並傳送給他人。

Enconvo 會在連結開放安裝前檢查並審查每個版本，而連結會開啟 enconvo.com 上的外掛程式頁面。每位安裝的人都會取得自己的一份副本；該外掛程式的資料、你的金鑰與你的登入狀態都會留在你的 Mac 上。

若要修改已分享的外掛程式，請再次點選 **分享…**：可以上傳新版本、變更 **誰可以安裝**，或點選 **停止分享**。停止分享後連結會失效，但已安裝該外掛程式的使用者仍會保留自己的副本。如果審查未通過，**分享…** 會顯示原因並提供 **在聊天中修復**。若要分享[空間](/zh-hant/features/spaces)，請參閱[分享空間](/zh-hant/features/spaces)。

## 自行開發外掛程式

請使用[開發擴充功能](/zh-hant/extensions/developing)中的 TypeScript SDK 與 CLI。CLI 將建置、安裝、結構描述產生與發佈指令整合在 `enconvo plugin` 底下。發佈後，外掛程式就能供你本機開發環境以外的使用者安裝。

Enconvo 也支援安裝 Codex、Claude Code 與可攜式外掛程式。請參閱 [Plugin Formats](/extensions/plugin-formats) 與[安裝外掛程式](/zh-hant/extensions/installing-plugins)。

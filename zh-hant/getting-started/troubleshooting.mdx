在下方找到你的問題，並嘗試右欄的解決方式。大多數問題都出在服務供應商尚未連接、缺少 macOS 權限，或是 App 的副本太舊。如果這裡的方法都沒有幫助，請[傳送診斷資訊](#傳送診斷資訊)，並到 Discord 發問。

## 先試試這些

1. **結束並重新開啟 Enconvo。** 從 Enconvo 選單列圖示選擇**結束**，然後從**應用程式**開啟 Enconvo。
2. **更新。** 從選單列圖示選擇**檢查更新**，或在**設定 → 一般 → 更新**中按一下**檢查更新**。
3. **檢查模型。** 開啟**設定 → AI 模型**，確認你使用的服務供應商已連接。如果不確定，請登入你的 Enconvo 帳號並使用 [Auto Route](/zh-hant/providers/auto-route)。
4. **檢查權限。** 開啟**設定 → 權限**，並開啟功能所需的項目。請參閱[權限](/zh-hant/configuration/permissions)。

## 答案與模型

| 問題 | 解決方式 |
| --- | --- |
| 沒有答案，或出現與服務供應商有關的錯誤 | 在**設定 → AI 模型**中開啟該服務供應商，並按一下**驗證**。若是以方案登入，請開啟帳號卡片的選單，並按一下**重新連線**。 |
| 出現與限制、配額或點數有關的錯誤 | 檢查服務供應商的用量頁面，若是 Enconvo Cloud，則檢查**設定 → 點數用量**。暫時改用其他服務供應商。 |
| 所有雲端服務供應商都失敗 | 檢查你的網際網路連線。若在代理伺服器之後，請在**設定 → 一般**的**網路代理伺服器**下，檢查**使用系統網路代理設定**。開啟後，模型請求、網頁擷取與連接器都會透過系統代理，且代理的變更不必重新啟動 Enconvo 就會生效。你 Mac 與區域網路上的伺服器（例如 LM Studio 與 Ollama）仍會直接連線。 |
| 模型顯示在你的國家或地區無法使用 | 開啟**使用系統網路代理設定**，讓 Enconvo 的請求透過你的代理伺服器。 |
| 答案很慢 | 選擇更小或更快的模型、附加較少的上下文，或降低推理強度。本機模型在輸入很長時會變慢。 |
| 一個模型失敗，其他模型正常 | 問題出在該模型或服務供應商。請在聊天的模型選擇器中改選其他模型。 |
| Ollama 或 LM Studio 無法連線 | 確認伺服器正在執行，且 **BaseUrl** 與它的位址相符，然後按一下**模型名稱**旁的**重新整理**。請參閱 [Ollama](/zh-hant/providers/ollama) 或 [LM Studio](/zh-hant/providers/lm-studio)。 |

## 快速鍵與視窗

| 問題 | 解決方式 |
| --- | --- |
| 快速鍵沒有反應 | 可能有其他 App 使用相同的按鍵，例如 Spotlight、Raycast 或 Alfred。請在**設定 → 快捷鍵**中變更其中一個。 |
| 更新後快速鍵失效 | 結束並重新開啟 Enconvo。如果沒有幫助，請在「系統設定」中將 Enconvo 的輔助使用關閉再開啟。 |
| 找不到 App | 按一下選單列或 Dock 中的 Enconvo 圖示，或按 **⌥Space** 開啟 SmartBar。 |
| 你記得的 SmartBar 或聊天視窗按鍵沒有反應 | 預設值為 SmartBar 使用 **⌥Space**，聊天視窗使用 **⌃⌘X**。請檢查**設定 → 快捷鍵**。 |

## 選取的文字與螢幕

| 問題 | 解決方式 |
| --- | --- |
| PopBar 沒有出現，或 Enconvo 無法讀取選取的文字 | 在**系統設定 → 隱私權與安全性 → 輔助使用**中開啟 Enconvo。如果已經開啟，請先關閉，等待兩秒再開啟，然後重新開啟 Enconvo。安全欄位與部分自訂編輯器不會提供它們的文字。 |
| 螢幕截圖、OCR 或螢幕上下文失敗 | 在**系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製**中開啟 Enconvo，然後重新開啟 Enconvo。 |
| 權限已開啟，但更新後沒有作用 | 在「系統設定」的該清單中，用 **−** 移除 Enconvo，再重新加入，然後重新開啟 Enconvo。 |
| 某項功能不再詢問權限 | 你可能勾選了**不再詢問**。**設定 → 權限**會顯示每項權限的**使用方**清單，請在那裡授予權限。 |

## 語音與音訊

| 問題 | 解決方式 |
| --- | --- |
| 聽寫聽不到任何聲音 | 檢查麥克風權限，以及在**設定 → 聽寫**中選取的麥克風。 |
| 聽寫不準確或很慢 | 在**設定 → 聽寫模型**中試試其他語音模型。在**設定 → 詞典**中加入名稱與術語。 |
| 朗讀沒有聲音 | 檢查你 Mac 的音量與輸出裝置。在**設定 → 文字轉語音**中試試**系統**；它不需要金鑰，也能離線運作。 |

詳情請參閱[聽寫](/zh-hant/features/dictation)與[語音辨識](/zh-hant/ai/speech-recognition)。

## 知識庫

| 問題 | 解決方式 |
| --- | --- |
| 文件一直無法完成索引 | 在**設定 → 知識庫**中檢查嵌入服務供應商，並確認支援該檔案類型。 |
| 搜尋找不到任何東西 | 確認知識庫已附加到聊天。在知識庫的設定中降低分數門檻，或提高結果數量。 |
| 大型知識庫很慢 | 依主題將它拆成較小的知識庫。 |

請參閱[知識庫](/zh-hant/ai/knowledge-base)與[知識庫設定](/zh-hant/advanced/knowledge-base-advanced)。

## 瀏覽器、App 與外掛程式

| 問題 | 解決方式 |
| --- | --- |
| Enconvo 無法控制你的瀏覽器 | 從**設定 → 使用瀏覽器**安裝 Enconvo Companion 擴充功能，然後重新啟動瀏覽器。請參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。 |
| 代理程式無法使用你的 App | 開啟**設定 → 電腦操作**所要求的權限。請參閱[電腦操作](/zh-hant/features/computer-use)。 |
| 外掛程式指令失敗 | 開啟**設定 → 外掛程式**，檢查外掛程式的設定與憑證，並更新 Enconvo。 |
| 代理程式的指令因權限錯誤而失敗 | 可能是代理程式的沙盒擋下了它。請參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。 |

## 傳送診斷資訊

當 Enconvo 當機、閃退，或持續出現異常時，請將診斷記錄傳送給 Enconvo 團隊。從選單列圖示選擇**提交診斷資訊…**，或開啟**設定 → 診斷**。在任何資料離開你的 Mac 之前，Enconvo 會移除個人資料，例如檔案名稱、電子郵件地址、金鑰與你的提示詞內容，並讓你確切看到傳送了什麼。請參閱[隱私與安全性](/zh-hant/configuration/privacy-security)。

## 取得協助

- 到 [Discord](https://discord.gg/jYsdVRRK2k) 發問。請附上你的 Enconvo 版本（**設定 → 關於**）、macOS 版本、你做了什麼，以及發生了什麼事。
- 使用選單列選單中的**意見回饋**回報問題或建議功能。
- 查看[常見問題](/zh-hant/faq)取得快速解答。

在下方找到你遇到的問題，並嘗試右側欄位的解決方法。大多數問題都源自服務供應商未連線、缺少 macOS 權限，或 App 版本過舊。如果這裡的內容都幫不上忙，請[傳送診斷資訊](#傳送診斷資訊)並在 Discord 上提問。

## 先試試這幾步

1. **結束並重新開啟 Enconvo。** 從選單列裡的 Enconvo 圖示選擇 **結束**，然後從 **應用程式** 重新開啟 Enconvo。
2. **更新。** 從選單列圖示選擇 **檢查更新**，或在 **設定 → 一般 → 更新** 中點擊 **檢查更新**。
3. **檢查模型。** 開啟 **設定 → AI 模型**，確認你使用的服務供應商已連線。如果不確定，登入你的 Enconvo 帳號並使用 [Auto Route](/zh-hant/providers/auto-route)。
4. **檢查權限。** 開啟 **設定 → 權限**，開啟該功能所需的權限。參閱[權限](/zh-hant/configuration/permissions)。

## 回答與模型

| 問題 | 解決方法 |
| --- | --- |
| 沒有回答，或出現關於服務供應商的錯誤 | 在 **設定 → AI 模型** 中開啟該服務供應商並點擊 **驗證**。如果是方案登入，請開啟帳號卡片的選單並點擊 **重新連線**。 |
| 出現關於限制、配額或點數的錯誤 | 檢查該服務供應商的用量頁面，或 Enconvo Cloud 的 **設定 → 點數用量**。暫時切換到其他服務供應商。 |
| 所有雲端服務供應商都失敗 | 檢查你的網路連線。如果使用代理伺服器，請在 **設定 → 一般** 的 **網路代理伺服器** 下勾選 **使用系統網路代理設定**。開啟後，模型請求、網頁擷取與連接器都會經過系統代理伺服器，且更改代理設定時無需重新啟動 Enconvo 即可生效。Mac 本機與區域網路上的伺服器（例如 LM Studio 與 Ollama）仍會直接連線。 |
| 模型顯示在你所在的國家或地區無法使用 | 開啟 **使用系統網路代理設定**，讓 Enconvo 的請求透過你的代理伺服器送出。 |
| 回答速度慢 | 改選更小或更快的模型、減少附加的上下文，或降低推理強度。本機模型在輸入很長時速度會變慢。 |
| 某個模型失敗，其他模型正常 | 問題出在該模型或服務供應商。在聊天的模型選擇器中改選其他模型。 |
| Ollama 或 LM Studio 無法連線 | 確認伺服器正在執行且 **BaseUrl** 與其位址相符，接著點擊 **Model Name** 旁的 **重新整理**。參閱 [Ollama](/zh-hant/providers/ollama) 或 [LM Studio](/zh-hant/providers/lm-studio)。 |

## 快捷鍵與視窗

| 問題 | 解決方法 |
| --- | --- |
| 快捷鍵沒有反應 | 其他 App 可能佔用了相同的按鍵組合，例如 Spotlight、Raycast 或 Alfred。在 **設定 → 快捷鍵** 中更改其中一個。 |
| 更新後快捷鍵停止運作 | 結束並重新開啟 Enconvo。如果還是沒用，在系統設定中先關閉再重新開啟 Enconvo 的輔助使用權限。 |
| 找不到 App | 點擊選單列或 Dock 中的 Enconvo 圖示，或按 **⌥Space** 開啟 SmartBar。 |
| 你記得的 SmartBar 或聊天視窗按鍵沒有反應 | 預設值為 SmartBar 使用 **⌥Space**，聊天視窗使用 **⌃⌘X**。請檢查 **設定 → 快捷鍵**。 |

## 選取的文字與螢幕

| 問題 | 解決方法 |
| --- | --- |
| PopBar 沒有出現，或 Enconvo 無法讀取選取的文字 | 在 **系統設定 → 隱私權與安全性 → 輔助使用** 中開啟 Enconvo。如果已經開啟，請先關閉它，等待兩秒後再重新開啟，接著重新開啟 Enconvo。安全輸入欄位與部分自訂編輯器不會共享其中的文字。 |
| 截圖、OCR 或螢幕上下文失敗 | 在 **系統設定 → 隱私權與安全性 → 螢幕錄影與系統音訊錄製** 中開啟 Enconvo，然後重新開啟 Enconvo。 |
| 某個權限已開啟但在更新後沒有效果 | 在系統設定的該列表中用 **−** 移除 Enconvo，重新加入它，然後重新開啟 Enconvo。 |
| 某項功能不再詢問權限 | 你可能曾經勾選了 **不再詢問**。**設定 → 權限** 會顯示每項權限的 **使用者** 列表；請在那裡授予權限。 |

## 語音與音訊

| 問題 | 解決方法 |
| --- | --- |
| 聽寫聽不到任何聲音 | 檢查麥克風權限，以及 **設定 → 聽寫** 中選取的麥克風。 |
| 聽寫辨識不準或速度慢 | 在 **設定 → 聽寫模型** 中試試其他語音模型。把專有名詞與詞彙加入 **設定 → 詞典**。 |
| 朗讀沒有聲音 | 檢查 Mac 的音量與輸出裝置。試試 **設定 → 文字轉語音** 中的 **系統**；它不需要金鑰且可離線使用。 |

更多資訊請參閱[聽寫](/zh-hant/features/dictation)與[語音辨識](/zh-hant/ai/speech-recognition)。

## 知識庫

| 問題 | 解決方法 |
| --- | --- |
| 文件無法完成索引 | 檢查 **設定 → 知識庫** 中的嵌入服務供應商，以及檔案類型是否受支援。 |
| 搜尋找不到任何內容 | 確認知識庫已附加到聊天中。在知識庫的設定中調低分數門檻或提高回傳結果數量。 |
| 大型知識庫速度慢 | 依主題拆分成較小的知識庫，或加入重排序模型（reranker）。 |

參閱[知識庫](/zh-hant/ai/knowledge-base)與[知識庫設定](/zh-hant/advanced/knowledge-base-advanced)。

## 瀏覽器、App 與外掛程式

| 問題 | 解決方法 |
| --- | --- |
| Enconvo 無法控制你的瀏覽器 | 從 **設定 → 使用瀏覽器** 安裝 Enconvo Companion 擴充功能，然後重新啟動瀏覽器。參閱[瀏覽器擴充功能](/zh-hant/features/browser-extension)。 |
| 代理程式無法使用你的 App | 開啟 **設定 → 電腦操作** 要求的權限。參閱[電腦操作](/zh-hant/features/computer-use)。 |
| 外掛程式指令失敗 | 開啟 **設定 → 外掛程式**，檢查外掛程式的設定與憑證，並更新 Enconvo。 |
| 代理程式的指令因權限錯誤而失敗 | 代理程式沙盒可能阻擋了它。參閱[代理程式沙盒](/zh-hant/configuration/sandbox)。 |

## 傳送診斷資訊

當 Enconvo 凍結、當機或持續發生異常時，請將診斷日誌傳送給 Enconvo 團隊。從選單列圖示選擇 **提交診斷資訊…**，或開啟 **設定 → 診斷**。在任何資料離開你的 Mac 之前，Enconvo 會移除檔案名稱、電子郵件地址、金鑰與提示詞文字等個人詳細資訊，並向你顯示實際傳送的內容。參閱[隱私與安全性](/zh-hant/configuration/privacy-security)。

---
title: "Memory"
description: "Review and maintain facts an Agent can reuse."
---

Memory stores reusable information for Agents, such as preferences or facts that should carry beyond one reply. It is different from a conversation transcript and from a knowledge base of documents.

## Review memory

1. Open **Settings → Memory → Memory**.
2. Search or filter by the categories, types, and Agents shown in the interface.
3. Open a memory to review its content and associated information.
4. Edit inaccurate or outdated facts, or delete them after reviewing the confirmation.

The management interface also supports adding a memory directly. Keep entries concise, factual, and specific about who or what they concern.

## Use memory deliberately

Check the Agent's memory configuration when testing whether a fact should be reused. A fact in one Agent's context is not proof that every other Agent or chat will use it. Verify with a new, ordinary request rather than assuming memory capture or retrieval happened automatically.

Do not store credentials or sensitive information simply to avoid re-entering it. Model requests can include retrieved memory, depending on the Agent and provider configuration.

## Memory, knowledge, and capture

| Material | Best place |
| --- | --- |
| A short reusable preference or fact | Memory |
| Documents and reference material | [Knowledge Base](/ai/knowledge-base) |
| A quick spoken idea | [Voice Note](/features/voice-notes) |
| Content visible in another app | [Quick Capture](/features/quick-capture) |
| A temporary discussion | [Chat](/ai/chat) |

If an answer uses an old fact, inspect the stored memory and current conversation context. Correct the underlying entry rather than only correcting one reply.

The Chat Window is Enconvo's main space for ongoing conversations. Use it when the work takes more than one answer: you choose an Agent, add the material it needs, and keep related chats together. Press **⌥⌘D** to open it.

For other jobs, use [SmartBar](/features/smartbar) for a quick question or command, the [App Sidebar](/features/app-sidebar) to work beside one app, [PopBar](/features/popbar) to act on selected text, or the [Dynamic Island](/features/dynamic-island) and [Desktop Pet](/features/pet) for a small entry point that stays on screen. [Window Management](/features/window-management) compares them all.

The video below tours the Chat Window in 2 minutes: choose an Agent, switch the model and the permissions for one chat, add files, pick what to make, ask and follow up, and find your chats again.

## Start a conversation

1. Press **⌥⌘D**, or open **Chat Window** from Enconvo. Click **New chat** (**⌘N**) for a fresh one.
2. Choose who answers: click an Agent card above the input, or the Agent's name at the top of the chat. Mavis is the default; the cards also hold Agents such as Writer and Researcher, and coding agents such as Codex and Claude Code.
3. Check the chips under the input. The model chip shows the model for this chat; click it to switch for this chat only. The shield chip sets when the Agent checks with you before it acts: **Approve for me** asks only before risky steps.
4. Click **+** to add files, images, or a screenshot. To ask for a specific result, click a shortcut below the input, such as **Slides**, **Doc**, **Web page**, **Image**, or **Video**.
5. Type your request and press Return. The answer streams into the chat; if the Agent uses tools, follow their progress in the reply.
6. Ask a follow-up in the same chat. It remembers the conversation, so a short request such as "Make it a one-day version" is enough.

Ask for a complete result. “Summarize the attached proposal in five bullets and list open questions” tells the Agent both what to read and what to return.

## Organize your chats

The sidebar lists your recent chats, and projects keep related chats together where they're available. Every chat is saved: click **Search** (**⌘G**) in the sidebar to find one by what was said. Open a chat's menu to **Rename chat**, **Pin chat**, **Move to project**, **Archive chat**, or **Delete chat**. Read the confirmation before you delete a chat's history.

### Model choices

A top-level **New chat** can set the Agent's model default. A new chat inside a project uses that project's model preference. Each chat can keep its own model and reasoning override. Read [Model Selection](/ai/model-selection-guide) before you change defaults that other chats use.

## Add context and files

Add only the sources the request needs. A file attachment, a screen capture, a knowledge-base lookup, and a browser page each give the Agent a different kind of context. See [Context Awareness](/features/context-awareness) to choose sources, and [Files and Folders](/ai/file-tools) for what an Agent can do with your files.

[Memory](/ai/memory) and a [Knowledge Base](/ai/knowledge-base) do different jobs: memory holds facts the Agent reuses, and a knowledge base stores material for it to look up.

## Read and reuse replies

Expand a reply's work details to see each tool call and its result. Below a reply, **Copy**, **Read Aloud**, and **More** act on it. [Visual Answers](/features/visual-answers) can put diagrams and interactive content right in a reply.

To talk instead of type, use [Dictation](/features/dictation) to compose with your voice, or [Live Talk](/features/live-voice) for a two-way spoken conversation.

## Settings

Open **Settings → Chat Window**.

| Setting | What it changes |
| --- | --- |
| **Default Agent** | The Agent a new chat in the Chat Window starts with. |
| **Appearance** | **Light**, **Dark**, or **Follow App**. |
| **Hotkey** | Opens the Chat Window from any app. The default is **⌥⌘D**. |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A reply uses the wrong model | Check this chat's model selection as well as the Agent's default. |
| The Agent can't see a file or the screen | Check the chat's attachments and [Permissions](/configuration/permissions). |
| A tool isn't available | Check the tools turned on for the Agent instead of rephrasing the same request. |

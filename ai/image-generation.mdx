---
title: "Image Generation"
description: "Ask an Agent to create an image, or to change one you attach, with the image provider you choose."
---

Ask an Agent in chat to make an image, or to change an image you attach. Enconvo sends the request to the image provider you set in **Settings → Image Generation**, which is separate from the model you chat with.

## Before you start

1. Open **Settings → Image Generation** and pick a provider.
2. Set its **Credential Provider** (the key or account it uses) and its **Model Name**.
3. Click **Set as Default**.

The Enconvo Cloud providers, **OpenAI (Enconvo Cloud)** and **Google Gemini (Enconvo Cloud)**, need no API key of your own.

## Create an image

1. In a chat with an Agent, describe the subject, composition, style, and what the image is for.
2. Ask for a size, aspect ratio, or quality only when the model supports it.
3. Wait for the image. Generation can take longer than a text reply.
4. Open the result and save the image you want to keep.

Example:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

## Edit an image

1. Attach the source image to your message.
2. Describe the specific changes, and say what should stay the same.
3. Check the result for changes you didn't ask for.

Use a model that supports image editing or reference images.

## Providers

The [image provider catalog](/providers/catalog#image-generation) includes OpenAI, Gemini, xAI, OpenRouter, Kie.ai, Topview, Azure, Together, and their Enconvo Cloud versions where offered. What a provider can do depends on the model: a provider's name alone doesn't promise every editing mode.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The image doesn't generate | Check the provider's access and model, then read the provider's error |
| An edit ignores your image | Check that the model accepts image input and that the file is attached to the message |
| The input file is rejected | Check that the provider supports the file's format |

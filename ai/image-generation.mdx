title: "Image Generation"
description: "Generate and edit images with a configured image provider."
---

Configure image creation under **Settings → Global Providers Settings → Image Generation**. The image provider is separate from the model used for ordinary chat.

## Generate an image

1. Choose a provider and model in Image Generation settings and configure its access.
2. Use an Agent with image-generation tools, or the image-generation command available in your build.
3. Describe the subject, composition, style, and intended use.
4. Choose size, aspect ratio, or quality only from options supported by that model.
5. Wait for completion, open the result, and save the output you need.

Example:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

## Edit an image

Attach the source image and describe the specific changes. Choose a model that supports image editing/reference input. State what should stay consistent, and review the result for unintended changes.

The [image provider catalog](/providers/catalog#image-generation) includes OpenAI, Gemini, xAI, OpenRouter, Kie.ai, Topview, Azure, Together, Straico, and supported Cloud variants. Capabilities are model-specific; a provider name alone does not guarantee every editing mode.

## Troubleshooting

Check access, model availability, supported input formats, and the provider error. Generation can take longer than a text reply. If an edit ignores the attachment, confirm that the chosen model accepts image input and that the file was attached to the request.

Web Search supplies current search results to Enconvo. Configure it independently from the model that writes the answer.

## Search with an Agent

1. Open **Settings → Global Providers Settings → Web Search** and configure a provider.
2. Enable the needed search tool for your Agent.
3. Ask a specific question, including a date range or geography when relevant.
4. Open the cited sources and check that they support the answer.

Example: “Find the official release notes for this library's latest stable version and summarize breaking changes with links.”

## Choose the right web capability

| Need | Use |
| --- | --- |
| Discover relevant sources | Web Search |
| Read a known URL | [Web Fetch](/ai/web-fetch) |
| Open results in your browser | [Quick Links](/features/quick-links) |
| Interact with a signed-in website | [Browser Control](/features/browser-control) |
| Search X posts/profiles/threads | xAI X Search provider with supported access |

See [Provider Catalog](/providers/catalog#web-search) for available search services. Some models also expose built-in grounding/search options in their own provider settings.

## Troubleshooting

If sources are missing, check that the Agent actually used search rather than answering from the model alone. For provider errors, verify the selected search credential and account allowance. For a result behind a login or an interactive page, use a supported browser flow; fetching a public URL does not grant authenticated access.

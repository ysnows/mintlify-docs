title: "Web Search"

---

Web Search gives your Agents current results from the web. Every Agent can search; you choose the search service it uses, separately from the model that writes the answer.

## Choose a search provider

1. Open **Settings → Web Search**.
2. Pick a provider. The Enconvo Cloud options need no API key; for most others, add your key for that service.
3. Click **Set as Default**.

| Provider | Notes |
| --- | --- |
| **Enconvo Cloud** | No API key needed |
| **DeepSeek (Enconvo Cloud)** | DeepSeek Search through Enconvo Cloud, no API key needed |
| **Gemini** | Grounding with Google Search through a Gemini model |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | Search with your own key for that service |
| **DeepSeek** | DeepSeek Search with your DeepSeek API key |
| **xAI X Search** | Searches X posts, profiles, and threads, with an xAI API key or xAI sign-in |
| **xAI X Search (Enconvo Cloud)** | X search through the Enconvo Cloud Plan |

See [Provider Catalog](/providers/catalog#web-search) for the full list. Some models also have built-in grounding or search options in their own provider settings.

## Search with an Agent

1. Ask a specific question. Include a date range or a place when it matters.
2. The Agent searches and answers with links to its sources.
3. Open the cited sources and check that they support the answer.

## Choose the right web capability

| Need | Use |
| --- | --- |
| Discover relevant sources | Web Search |
| Read a known URL | [Web Fetch](/ai/web-fetch) |
| Open results in your browser | [Quick Links](/features/quick-links) |
| Interact with a signed-in website | [Browser Use](/features/browser-control) |
| Search X posts, profiles, or threads | **xAI X Search** provider |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The answer has no sources | Check that the Agent searched instead of answering from the model alone. Ask it to search the web. |
| The provider reports an error | Check the provider's credential and your account's allowance with that service. |
| The result is behind a login or on an interactive page | Use a supported browser flow such as [Browser Use](/features/browser-control). Fetching a public URL doesn't give access to your signed-in session. |

---
title: "Translation"
description: "Translate text, screenshots, and dictated input."
---

Use **Translator** for text or **Screenshot Translate** for content on screen. Translation uses the configured model and command settings; review the target language before running it.

## Translate selected text

1. Select the passage in another app.
2. Choose the translation command in PopBar or find **Translator** in SmartBar.
3. Set the target language in the available command controls.
4. Review the result before replacing or sending the original text.

## Translate a screenshot

Run **Screenshot Translate**, select the relevant region, and review both recognition and translation. An OCR mistake can change the translated meaning. See [OCR](/ai/ocr) for provider setup.

## Translate speech

Use **Dictation Translate** as a dictation post-action to convert recognized text into a target language. For realtime translated captions, choose a speech provider that exposes the supported live-translation options under [Live Captioning](/features/live-captioning).

## Customize results

Translation and Writing Toolkit commands follow the global AI model unless a command override is set. For recurring terminology, provide a glossary in a custom [AI Command](/features/ai-commands) or Agent instruction. Tell the model what to preserve, such as names, technical identifiers, or quoted passages.

If output uses the wrong language, check both the command's target and any post-action. If text is missing, review selected-text permissions or screenshot OCR first.

You don't have to choose: [Auto Route](/providers/auto-route), the default model, picks one for each message. When you want a specific model, this page helps you choose one and shows where the choice is saved.

## Choose by task

| Task | Look for |
| --- | --- |
| Quick rewrites and short answers | A fast, low-cost model |
| Multi-step Agent work | Reliable tool calls and reasoning support |
| Questions about a screenshot or image | Image input |
| Long documents | A long context window |
| Private work that stays on your Mac | A [local model](/ai/local-llm), plus local providers for the other steps |
| Voice conversations | [Live Talk](/features/live-voice), which has its own voice settings |
| Creating images or video | An [image](/ai/image-generation) or [video](/ai/video-generation) provider, not a chat model |

The model picker shows the models your providers offer right now. Models that support Fast mode show a Fast mode chip, which runs them faster at a higher price.

## Where the default is set

- **A new chat**: the model you pick in a top-level **New chat** becomes the Agent's default.
- **A project**: a new chat inside a project uses the project's own model.
- **An existing chat**: once a chat starts, it keeps its model and reasoning effort until you change them in that chat.
- **Chats without their own choice, and IM channels**: these follow the Agent's default.

After changing a default somewhere else, check the model shown in the chat before you send.

## Reasoning effort

Reasoning effort sets how long a model thinks before answering. Higher effort can give better answers to hard problems, but takes longer and uses more tokens. The levels depend on the model; a model without a thinking mode has no effort setting.

## Compare two models

Send the same small, real task to both. Check that the answer is correct, that tools finished, and how long it took and what it cost. **Details** under each reply shows the model, effort, tokens, time, and points or cost.

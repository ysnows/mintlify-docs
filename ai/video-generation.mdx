Use **Text to Video** or **Image to Video** with a configured video-generation provider. Video settings are separate from image generation and ordinary AI chat.

## Create a clip

1. Open **Settings → Global Providers Settings → Video Generation** and configure a provider/model.
2. Run **Text to Video**, or use **Image to Video** with a source image.
3. Describe the subject, action, camera behavior, and desired scene.
4. Choose the duration, resolution, and other options supported by that model.
5. Wait for the generation job to finish, then preview and save the result.

Start with a short clip when testing a new provider; generation can take time and use the selected provider's credit or Cloud points.

## Providers and input support

The [video provider catalog](/providers/catalog#video-generation) includes xAI, Gemini, OpenRouter, Kie.ai, Topview, and supported Cloud variants. Different models accept different inputs and resolutions. For example, Grok Imagine Video 1.5 adds a 1080p option that the base Grok Imagine Video model does not support.

An image-to-video request should specify what moves and what stays consistent. If the model accepts only one image or a limited duration, use those constraints in the request.

## Troubleshooting

If submission fails, check account access and supported request options. If a submitted job is still processing, inspect its status rather than immediately submitting another paid generation. Keep the input and returned error/status when asking for help, without sharing credentials.

For downloading, extracting audio, or compressing a completed clip, see [Media Utilities](/features/media-tools).

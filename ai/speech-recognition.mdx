Each voice feature in Enconvo has its own speech model setting, so you can pick a fast streaming model for Dictation and a different one for long files. Choose the model in the feature you are actually using.

| Feature | Where to set it | Guide |
| --- | --- | --- |
| Speech typed as text | **Settings → Dictation Models** | [Dictation](/features/dictation) |
| Voice Command | **Settings → Voice Command → Listen** | [Voice Command](/features/dictation) |
| Live Talk calls | **Settings → Live Talk → Listen** | [Live Talk](/features/live-voice) |
| Meeting or lecture recording | **Settings → Recording Models** | [Meeting Recording](/features/meeting-recording) |
| An existing audio or video file | **Settings → Transcription Models** | [Transcription](/features/transcription) |
| Realtime subtitles | **Settings → Captioning Model** | [Live Captioning](/features/live-captioning) |

## Choose a model

1. Open the setting for your feature from the table above.
2. On a Dictation, Recording, Transcription, or Captioning model page, filter the list with **All**, **Enconvo Cloud**, **Local**, or **Custom Providers**. In Voice Command and Live Talk, **Listen** shows the recommended models first, then any other speech model.
3. Pick a model, then review its language and model options.

**Enconvo Cloud** models use your Enconvo account, with no API key. **Custom Providers** use your own API key with that provider. **Local** models (MLX and Core ML) recognize speech on your Mac once their model is downloaded.

The [speech provider catalog](/providers/catalog#speech-recognition) lists every declared provider, including cloud services and local Parakeet, Qwen, Whisper, SenseVoice, Paraformer, and Nemotron variants. Hardware and availability depend on the runtime and your build.

## Match the model to the task

| Capability | What to know |
| --- | --- |
| Streaming | Produces partial text while you talk. Use a realtime model when you want words to appear as you speak. |
| Batch transcription | Processes a file after capture or upload. |
| Language hints and hot words | Guide recognition when the provider supports them. |
| Speaker diarization | Separates voices. It does not guarantee the right person's name. |
| Live translation | Offered only by some providers and models, with source and target languages. |
| Timestamps and structured output | Depend on the provider and the transcription output format. |

## Test with a short sample

Record a short sample with the language, microphone, and terms you actually use, and review it before you process a long meeting. If it fails, read the error for file size, format, extraction, account, or network details.

Local model downloads can be much larger than the app. Check the actual download size and your free space; local speech models don't all need the same.

---
title: "Web Fetch"
description: "Have your Agent read a web page from its URL, or keep the page in a knowledge base."
---

Use Web Fetch when you already have a URL and want the Agent to read the page. Every Agent can read a link you give it; you choose the service that fetches it. Use [Web Search](/ai/web-search) when you need to find relevant pages first.

## Choose a provider

1. Open **Settings → Web Fetch**.
2. Pick a provider and click **Set as Default**.

| Provider | Use |
| --- | --- |
| **Local Fetch** | Fetch pages on your Mac for free, with optional browser-assisted fetching |
| **Jina AI Link Reader** | Retrieve readable content through Jina |
| **Firecrawl Link Reader** | Retrieve content through Firecrawl |
| **DeepSeek** | Read pages as Markdown with your DeepSeek API key |
| **DeepSeek (Enconvo Cloud)** | Read pages as Markdown through Enconvo Cloud, no API key needed |
| **Enconvo Cloud Plan** | Use the Cloud link-reading service |

## Read a page

1. Paste the URL into your conversation and ask a specific question about it.
2. Check the retrieved content and source before relying on the answer.

## Pages behind a login

With **Local Fetch**, **Browser-Assisted Fetching** can read a page through a Chromium-family browser that has the Enconvo Companion extension.

| Option | What it does |
| --- | --- |
| **Auto** (default) | Reuses a matching tab you already have open, fully rendered and with your login. Uses a temporary background tab when a direct fetch fails or the page needs JavaScript. |
| **Off** | Direct HTTP only |
| **Always** | Always fetches through the browser |

Without a connected browser, Local Fetch makes a direct HTTP request. The other providers fetch the public URL and don't have your signed-in browser session. For interactive pages, use the [Browser Extension](/features/browser-extension) or [Browser Use](/features/browser-control).

## Keep web content

Add a URL with **Add → Single Web Page** in a [Knowledge Base](/ai/knowledge-base) when you want to find it later. Check the imported page and its indexing status; web pages can change after you import them.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The content comes back empty | Check that the page is readable without extra interaction, or use **Local Fetch** with **Browser-Assisted Fetching**. Login screens, blocked requests, dynamically loaded content, and unsupported sites can prevent extraction. |
| The answer describes things that aren't on the page | Ask the Agent to show what it actually retrieved, instead of guessing at missing content. |

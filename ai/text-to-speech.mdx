title: "Text-to-Speech"
description: "Read text aloud or create an audio file."
---

Enconvo offers two related commands: **Read Aloud** plays text in a floating playback bar; **TTS (Text To Speech)** creates an audio file using the selected provider.

## Read a passage

1. Open **Settings → Global Providers Settings → Text-to-Speech** and configure a provider and voice.
2. Select text and run **Read Aloud**, or use a chat reply's read-aloud action.
3. Use the floating bar to pause, resume, or stop playback.
4. Adjust the voice or speed in provider settings when supported.

## Create an audio file

Run **TTS (Text To Speech)** with the text you want to speak. Review the provider, voice, speed, and available output format. Open the generated file to check pronunciation and pacing.

The [TTS provider catalog](/providers/catalog#text-to-speech) lists Cloud, direct-service, macOS System, and local MLX options. Controls differ: some providers support style instructions or expressive tags, while others expose a fixed voice list.

## Local and cloud voices

Local Kokoro and Qwen3 MLX providers require supported hardware and model resources. System TTS uses macOS voices. Online providers, including services that do not require an API key, still send the input text over the network.

## Troubleshooting

If there is no sound, check the system output device and playback state. If generation fails, check provider access and supported text length/format. For mispronounced names, test a shorter sample and the provider's supported pronunciation or style controls.

For two-way conversation rather than reading a passage, use [Live Voice](/features/live-voice).

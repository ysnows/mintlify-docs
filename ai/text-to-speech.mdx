---
title: "Text-to-Speech"
description: "Have Enconvo read text aloud, or turn text into an audio file."
---

Enconvo has two commands for speech. **Read Aloud** reads text to you in the Read Aloud player on the Dynamic Island. **TTS(Text To Speech)** turns text into an audio file with the provider you choose. You can also have chat replies read to you right in the conversation.

## Read a chat reply aloud

Click the speaker button under a reply. The button turns into a small player with pause, resume, and stop, and the sentence being read is highlighted in the reply. Only one reply reads at a time, and closing the chat stops it.

To have every reply read aloud, turn on reading replies aloud in the Smart Bar or the Chat Window. Each window keeps its own setting.

## Read text aloud

1. Open **Settings → Text-to-Speech** and set up a provider and voice.
2. Select text and run **Read Aloud**.
3. The player on the Dynamic Island reads sentence by sentence. Use it to pause, resume, or stop, skip back or forward, change the speed or voice, and show the text with the current sentence highlighted.
4. Adjust the voice or speed in the provider's settings when it supports them.

When an [Avatar](/features/avatar) is open, it reads the text with lip sync, and the player stays compact on the Dynamic Island.

## Create an audio file

Run **TTS(Text To Speech)** with the text you want spoken. Check the provider, voice, speed, and output format it offers, then open the generated file to check pronunciation and pacing.

The [TTS provider catalog](/providers/catalog#text-to-speech) lists Enconvo Cloud, direct-service, macOS System, and local options. **Enconvo Cloud Voice** is Enconvo Cloud's own voice, in more than 60 languages with no API key. DeepSeek reads text in a female (Stella) or male (Tide) voice, with your own DeepSeek API key or as **DeepSeek (Enconvo Cloud)**. Controls differ: some providers take style instructions or expressive tags, while others offer a fixed list of voices.

## Clone a voice

ElevenLabs, Fish Audio, Gemini, and Qwen3 can clone a voice. They show a badge in the provider list in **Settings → Text-to-Speech**.

1. Open **Settings → Text-to-Speech**, pick one of these providers, and open its **Voice Clone** tab.
2. Upload a recording, or click **Record** and read the text shown. The countdown can be canceled, the level meter follows your voice, and a single take ends by itself after 5 minutes.
3. Play your cloned voice, then use it, rename it, or delete it from the same tab.

You can also click **Clone Voice** next to the **Voice** menu of these providers. Your cloned voices show at the top of the **Voice** menu, where you can rename or delete them too.

The tab shows how many Cloud voices you have left for that provider. When you reach the limit, delete one to clone another. If you close the Settings window while recording, the take stops and keeps what was recorded.

## Local and cloud voices

Local providers run on your Mac and need supported hardware and model files: Kokoro and Qwen3 run on MLX, and Phonon, an English voice, runs on Core ML on Macs with Apple silicon and macOS 15 or later. **System** uses the voices built into macOS. Online providers, including ones that need no API key, send your text over the network.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No sound | Check the system output device and whether playback is paused. |
| Generation fails | Check your access to the provider, and the length and format of the text. |
| Read Aloud stops and says the provider has no API key | Add the key in **Settings → Text-to-Speech**, or pick a voice that runs on Enconvo Cloud or your Mac. |
| Names are mispronounced | Test a shorter sample, and try the provider's pronunciation or style controls. |

---
title: "Text-to-Speech"
description: "Have Enconvo read text aloud, or turn text into an audio file."
---

Enconvo has two commands for speech. **Read Aloud** reads text to you in the Read Aloud player on the Dynamic Island. **TTS(Text To Speech)** turns text into an audio file with the provider you choose.

## Read text aloud

1. Open **Settings → Text-to-Speech** and set up a provider and voice.
2. Select text and run **Read Aloud**, or use a chat reply's read-aloud action.
3. The player on the Dynamic Island reads sentence by sentence. Use it to pause, resume, or stop, skip back or forward, change the speed or voice, and show the text with the current sentence highlighted.
4. Adjust the voice or speed in the provider's settings when it supports them.

When an [Avatar](/features/avatar) is open, it reads the text with lip sync, and the player stays compact on the Dynamic Island.

## Create an audio file

Run **TTS(Text To Speech)** with the text you want spoken. Check the provider, voice, speed, and output format it offers, then open the generated file to check pronunciation and pacing.

The [TTS provider catalog](/providers/catalog#text-to-speech) lists Enconvo Cloud, direct-service, macOS System, and local options. Controls differ: some providers take style instructions or expressive tags, while others offer a fixed list of voices.

## Local and cloud voices

Local providers run on your Mac and need supported hardware and model files: Kokoro and Qwen3 run on MLX, and Phonon, an English voice, runs on Core ML on Macs with Apple silicon and macOS 15 or later. **System** uses the voices built into macOS. Online providers, including ones that need no API key, send your text over the network.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No sound | Check the system output device and whether playback is paused. |
| Generation fails | Check your access to the provider, and the length and format of the text. |
| Names are mispronounced | Test a shorter sample, and try the provider's pronunciation or style controls. |

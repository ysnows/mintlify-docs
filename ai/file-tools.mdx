File tools let an Agent find files, search inside them, read them, and edit them. Point the Agent at a folder or a file and ask in plain words; it picks the right tool and shows you what it used.

## Before you start

- **Working folder:** an Agent's **Working Folder**, in the **Definition** part of its settings, is where relative paths start.
- **Approvals:** the **Permissions** chip in the chat decides when the Agent asks first. With **Ask for approval**, it asks before it edits files outside the working folder. Reading and searching never ask. See [Approve actions](/ai/agents#approve-actions).

## Start with a read-only task

1. In the Agent's settings, check its file tools and its **Working Folder**.
2. In the chat, name a folder or attach the file you want to use.
3. Ask a bounded question, such as “Find Markdown files in this project and summarize the README.”
4. Look at the files and tool output the Agent used before you ask it to change anything.

## What each tool does

| Tool | What it does |
| --- | --- |
| Glob | Finds files by path pattern, such as `**/*.md`, newest first |
| Grep | Searches the text inside files, with file patterns and line numbers |
| Read File | Reads text files, pulls the text out of documents, and reads images, audio, and video |
| Edit File | Replaces exact text in a file and reports the lines it changed |
| Write File | Creates a file, or replaces all of its contents |

<Warning>
Write File can overwrite an existing file without warning. Keep a copy or use version control for important documents, and check the destination and the change before you approve it. The files an Agent changes in a chat are listed in the side panel's **Changes** tab, with **Undo**.
</Warning>

## Documents and media

Reading a PDF, an Office document, an image, an audio file, or a video can run parsing, OCR, or transcription instead of returning raw bytes. For audio and video, the Agent reads the transcript. Which formats work depends on the installed tools and the providers you set up. See [OCR](/ai/ocr), [Transcription](/features/transcription), and [Knowledge Base](/ai/knowledge-base).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| An access error | Check the Agent's **Working Folder**, the **Permissions** chip, and the macOS permissions |
| A document reads as empty | Check the file type and whether it can be parsed. A scanned PDF may need OCR |
| An edit can't find the text it should replace | Ask the Agent to read the current file again before it edits |

Some jobs take more than one Agent: a researcher to find the facts, a writer to turn them into a post, a coder and a reviewer for a change. Name the Agents in a chat, and the Agent you're talking to becomes the lead. It writes a Work plan, gives each member its task, and checks the result against the goal. For ongoing work, a [Project](#projects) keeps the plans, chats, and files of one folder together.

The video below shows the whole flow in under 2 minutes: bring in Agents with @, the Work plan, the Board, and Projects.

## Give a job to several Agents

1. In any chat, type `@` and the start of an Agent's name, then press Return to pick it from the list. Add as many Agents as the job needs.
2. Describe what each one should do, and send. For example: "@Researcher find three facts about the Kyoto bamboo grove, then @Writer turn them into a short post."
3. The lead answers with a Work plan: the **Goal**, what must be true for it to be done, what it leaves out, and one task for each member. A task that needs another one's result waits for it.
4. If the plan waits for you, check it, then click **Start**, **Change plan**, or **Drop**. Members start when you start the plan.
5. When the tasks finish, the plan card shows each result, and the lead says whether the goal is met.

## Follow the Board

Click **Board** at the top of the chat to see its tasks as cards. Each task has a number, such as T-1, and moves from **To start** to **Running** to **Done**. **Needs you** holds anything waiting for your answer or approval.

| Control | What it does |
| --- | --- |
| **All** / **Needs you** | Show every task, or only the ones waiting for you. |
| **Group by** | Group the cards, for example by chat. |
| **Display** | Change what each card shows. |
| **Search tasks or T-12** | Find a task by its words or its number. |

**Board** in the sidebar shows the tasks from all your chats, with a count of the ones that need you.

## Projects

A Project groups related chats around one folder, and the folder's `AGENTS.md` becomes the Project's instructions. Click **+** next to **Projects** in the sidebar to open **Create project**:

- Enter a **Project name** to make a new folder in Documents, or click **Use an existing folder** or **Clone a repository**.
- Under **Start from**, pick **Blank** or a team: **Research Desk**, **Content Studio**, **App Builders**, or **Trip Planner**.

In a Project with members, the lead plans each goal, the members build it, and a review or test checks it. Members can include coding agents such as Claude Code and Codex. Each coding task works in its own copy of the code, and the plan's result card has a **Merge** button for when you're ready. Members can't push or merge themselves; only Enconvo merges and pushes.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Pressing Return sent the message instead of picking the Agent | Wait for the Agent list to appear under the input before you press Return. |
| A task is stuck in **Needs you** | Open the task, or the chat, and answer the question or approval it's waiting for. |
| A coding agent can't start | Install it and sign in first. See [Agents](/ai/agents). |

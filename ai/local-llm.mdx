---
title: "Local Models"
description: "Run models on your own hardware, and keep a whole task on your Mac."
---

Run models on your Mac, or on another computer you own, when you want chats to stay private or to work without a provider account. Enconvo has a built-in engine, and it also connects to Ollama and LM Studio.

## Choose a runtime

| Runtime | Best for | Setup |
| --- | --- | --- |
| [Local LLM (MLX)](/providers/mlx) | Running models inside Enconvo on an Apple Silicon Mac with macOS 15 or later | Pick and download a model in Settings |
| [Ollama](/providers/ollama) | Models you already manage with Ollama, on this Mac or a server | Start Ollama and set its address |
| [LM Studio](/providers/lm-studio) | Models you already use in LM Studio, on this Mac or a server | Start LM Studio's server and set its address |

## Start small

1. Set up the runtime and download or load a model.
2. Send a short text message.
3. Once that works, add documents or tools.
4. Watch memory use and speed before you try a larger model. **Settings → Local Models** shows the models on this Mac and how much memory they use.

Model size, quantization, context length, and other running tasks all affect memory. Use the size the model picker shows rather than a fixed rule.

## Keep the whole task local

A local chat model alone doesn't keep everything on your Mac. Speech recognition, text-to-speech, OCR, document parsing, embeddings, reranking, search, and MCP tools each use their own provider. Enconvo has local providers for several of them; the [provider catalog](/providers/catalog) lists them.

**Settings → Local Models** shows which features run on this Mac and which run in the cloud. Web search and other online services still need the internet, and a local model can still call tools that send content off your Mac.

## Use a model server on another computer

Set the server to accept network connections, and set Enconvo's **BaseUrl** to that computer's address. `localhost` always means the Mac running Enconvo. If macOS blocks the connection, turn on Enconvo in **System Settings → Privacy & Security → Local Network**.

A Knowledge Base holds material you want Enconvo to retrieve later. Use it for reference documents, project notes, captured webpages, and spoken notes. [Memory](/ai/memory) serves a different purpose: information an Agent retains across conversations.

## Create and open a knowledge base

1. Open **KnowledgeBase** from Settings, or search for **Create Knowledge Base** in SmartBar.
2. Give it a clear name and review its provider settings.
3. Open the knowledge base and use **Add** to import material.
4. Wait for processing to finish, then open an item to inspect the extracted content.

Use the knowledge base switcher to keep unrelated projects separate. Within a knowledge base, folders organize items; grid and list views provide different ways to browse them.

## Add content

| Entry | Use it for |
| --- | --- |
| **Add → Files** | Supported documents, images, audio, or video from your Mac |
| **Add → Note** | A new editable Markdown note |
| **Add → Single Web Page** | Content from one URL |
| **Add → Youtube Video** | A video and its available captions |
| **Import Folder** | A local folder with its structure and optional synchronization |
| Drag or paste files into the knowledge base | Fast import from Finder |
| [Quick Capture](/features/quick-capture) | Save the current app's content |
| [Voice Note](/features/voice-notes) | Record and save a spoken note |

Document loaders support common text, Markdown, PDF, Office, EPUB, and structured-data formats. Images need OCR; audio/video needs transcription. Parsing quality and supported formats depend on the selected loader and providers. Check the import preview and each item's processing status for files that are skipped or fail.

## Linked folders

1. Choose **Import Folder** from the folder area or empty-state action.
2. Select a source folder, review file counts and skipped files, and confirm.
3. Open its folder inspector to review the source path, synchronization status, and controls.
4. Choose **Sync Now**, or turn on **Auto-sync** to follow changes while Enconvo runs.

The source folder remains on disk. New and changed files are imported; deleted source files are removed from the linked knowledge base content. Hidden files, unsupported formats, and files above the import size limit are skipped. Enconvo's folder sync does not edit the source files.

If a source drive is disconnected, restore access or relink the folder before syncing. A missing source is handled separately from an intentionally deleted file. See [Knowledge Base Deep Dive](/advanced/knowledge-base-advanced) for processing and sync troubleshooting.

## Ask questions using your sources

Attach a knowledge base or a specific item using the context picker available in your chat or SmartBar. Review the attached source before submitting; the picker's available entries are the source of truth, rather than typing a special `@kb` command.

Try:

> Using the attached project notes, list the decisions about authentication and cite the source for each decision.

An Agent with knowledge tools can search and read available material. Retrieval selects relevant passages rather than sending every document. Open cited items to verify important details. If a passage is missing, attach the specific document or inspect whether it finished processing.

## Edit and maintain

Open a note to edit its Markdown. Use item and folder menus to rename, organize, export, or remove content where those actions are offered. Read the removal confirmation: removing knowledge base content and deleting a source file are different operations.

When an item fails, inspect whether extraction or embedding failed before retrying. A document may be readable before all search indexing is complete. Changing an embedding provider can require rebuilding embeddings; see the deep-dive guide before changing a populated knowledge base.

## Connect another AI app

Open the knowledge base's **Settings → Connect AI Clients (MCP)** to expose selected knowledge bases to a local MCP client. This is a separate, opt-in, read-only service. Follow [Knowledge Base MCP](/advanced/knowledge-base-mcp) for setup and visibility controls.

## Data handling

Knowledge base files and indexes are stored locally. Selected cloud OCR, transcription, embedding, reranking, or chat providers can receive the content needed for their work. Local storage does not imply that provider processing is offline. Review [Privacy & Security](/configuration/privacy-security) and the selected providers before importing sensitive material.

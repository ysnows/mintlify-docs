---
title: "Historial del portapapeles, marcadores y búsqueda de archivos"
description: "Busca lo que copiaste, tus marcadores del navegador y los archivos de tu Mac desde un atajo o SmartBar."
---

Historial del portapapeles, Buscar marcadores del navegador y Búsqueda de archivos son tres listas rápidas que buscas mientras escribes. Usa el Historial del portapapeles para pegar algo que copiaste antes, la búsqueda de marcadores para abrir una página guardada en cualquier navegador, y la Búsqueda de archivos para abrir un archivo sin Finder. Cada una se abre con su propio atajo, o desde SmartBar con un alias.

## Abrir una lista

1. Configura un atajo para la lista en **Ajustes → Atajo**, o en la página de ajustes de la lista, en **Ajustes → Plugins**.
2. Pulsa el atajo. Con **El atajo abre una ventana** activado, que es el valor predeterminado, la lista se abre en una ventana propia y SmartBar se queda como está.
3. Escribe para filtrar la lista, muévete a un elemento con las flechas y pulsa Return.

Para abrir una lista dentro de SmartBar, configura su **Alias**. Escribe el alias y un espacio en SmartBar, y la lista se abre ahí. La búsqueda de SmartBar muestra el alias de cada lista.

También puedes mencionar una lista con `@` en un chat, y el Agente busca en esa lista por ti.

## Pegar desde el Historial del portapapeles

El Historial del portapapeles guarda el texto, las imágenes y los archivos que copias. Puedes fijar favoritos y filtrar por enlaces, correos, colores, imágenes o archivos.

1. Abre el Historial del portapapeles.
2. Escribe una palabra de lo que copiaste.
3. Pulsa Return para pegar el elemento en la app que estabas usando. Pulsa **⌘C** para copiarlo. Con **Tecla Return** en copiar, **⌘Return** pega.

Cuando abres la lista sobre una ventana de Enconvo, Return pega en el cuadro de mensaje de esa ventana.

Los gestores de contraseñas y Acceso a Llaveros se dejan fuera de forma predeterminada, y las copias que las apps marcan como ocultas o temporales, como las contraseñas, nunca se registran.

## Abrir un marcador

Buscar marcadores del navegador lee los marcadores de Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox y Zen, incluidos los perfiles de Firefox y Zen guardados en una carpeta que elegiste. Una búsqueda también coincide con nombres de carpetas.

Pulsa Return para abrir el marcador en el navegador del que vino, o **⌘O** para abrirlo en tu navegador predeterminado. **Tecla Return** intercambia los dos.

## Encontrar un archivo

Búsqueda de archivos mira todo tu Mac de forma predeterminada. Usa el menú desplegable de su campo de búsqueda para buscar en un solo sitio en esta búsqueda, como **Mis carpetas**, **Inicio** o **Descargas**.

Pulsa Return para abrir el archivo, o **⌘Return** para mostrarlo en Finder. **Tecla Return** intercambia los dos.

## Ajustes

Abre **Ajustes → Plugins** y luego **Historial del portapapeles**, **Marcadores del navegador** o **Búsqueda de archivos**.

| Ajuste | Lista | Qué cambia |
| --- | --- | --- |
| **Alias** | Las tres | La palabra que escribes, y luego un espacio, en SmartBar para abrir la lista ahí. |
| **El atajo abre una ventana** | Las tres | Activado: el atajo abre la lista en su propia ventana. Desactivado: el atajo la abre en SmartBar. Activado de forma predeterminada. |
| **Tecla Return** | Las tres | Qué hace Return. Historial del portapapeles: **Pegar en la app al frente** o **Copiar al portapapeles**. Marcadores: **Abrir en su navegador** o **Abrir en el navegador predeterminado**. Archivos: **Abrir** o **Mostrar en Finder**. |
| **Registrar el historial del portapapeles** | Historial del portapapeles | Guarda un historial de lo que copias. Desactivarlo conserva los elementos ya guardados. |
| **Conservar el historial durante** | Historial del portapapeles | Cuánto tiempo permanecen los elementos, de **1 día** a **Siempre**. 3 meses de forma predeterminada. Los elementos fijados nunca se eliminan. |
| **Apps ignoradas** | Historial del portapapeles | Apps cuyas copias nunca se registran, por ID de paquete. |
| **Mostrar nombres de carpetas** | Marcadores | Muestra la carpeta de cada marcador. |
| **Navegadores desactivados** | Marcadores | Navegadores cuyos marcadores se dejan fuera. |
| **Buscar en** | Archivos | Dónde mira la Búsqueda de archivos al abrirse: **Este Mac**, **Mis carpetas**, **Inicio**, **Escritorio**, **Documentos**, **Descargas** o **Aplicaciones**. |
| **Carpetas de búsqueda** | Archivos | Las carpetas que busca **Mis carpetas**. Escritorio, Documentos y Descargas cuando está vacío. |
| **Mostrar archivos ocultos** | Archivos | Incluye archivos cuyo nombre empieza por un punto. |
| **Carpetas excluidas** | Archivos | Carpetas cuyo contenido nunca aparece. |

Un atajo o un alias que configuraste en las versiones web antiguas de estas listas se conserva.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El atajo abre SmartBar en lugar de una ventana | Activa **El atajo abre una ventana** para esa lista. |
| Falta una copia en el Historial del portapapeles | Revisa **Registrar el historial del portapapeles** y **Apps ignoradas**. Las copias ocultas, como las contraseñas, nunca se registran. |
| Faltan los marcadores de un navegador | Revisa **Navegadores desactivados**. |
| Un archivo no aparece | Revisa **Buscar en**, **Carpetas excluidas** y **Mostrar archivos ocultos**. |

Las Herramientas de escritura son un conjunto de comandos de un clic para el texto que seleccionas en cualquier aplicación. Corrige errores, cambia el tono, hazlo más corto o más largo, explícalo o resúmelo, o conviértelo en una lista o una tabla, sin salir de la aplicación en la que escribes.

## Editar el texto seleccionado

1. Selecciona texto en la aplicación en la que estás escribiendo.
2. Haz clic en un comando en [PopBar](/es/features/popbar), o abre [SmartBar](/es/features/smartbar) y busca el comando.
3. Lee el resultado. Con **Resaltar cambios** activado, el resultado marca lo que el comando añadió y quitó.
4. Haz clic en **Pegar** para reemplazar tu selección, o copia el resultado.

Cada comando conserva el idioma de tu texto y responde solo con el resultado. **Explicar** también responde en el idioma del texto seleccionado y trata cada ejecución por separado, no como parte de una anterior. Cuando el texto seleccionado plantea una pregunta o da una instrucción, el comando edita esas palabras; no las responde.

<Tip>
Activa el **Modo en línea** en un comando de confianza y se ejecutará sin ventana y pegará el resultado directamente sobre tu selección. Consulta [Cambiar un comando](#cambiar-un-comando).
</Tip>

## Elegir un comando

| Objetivo | Comandos |
| --- | --- |
| Corregir errores | Corregir ortografía y gramática, Revisar |
| Mejorar la redacción | Mejorar la escritura, Pulir, Reescribir, Natural, Edición con IA |
| Cambiar la longitud | Alargar, Acortar, Hacer más conciso |
| Cambiar el tono | Cambiar el tono a amistoso, seguro, informal o profesional |
| Entender el contenido | Explicar, Resumir, Extraer los puntos clave |
| Reformatear | Convertir en lista, Convertir en tabla |
| Correo electrónico | Pulir correo, Redactar una respuesta |
| Publicaciones en X | Pulir para X, Ajustar a 280 caracteres, Convertir en hilo, Sugerir una respuesta en X, Sugerir un comentario de cita en X |
| Traducir | Traductor, Traducir captura de pantalla (consulta [Traducción](/es/ai/translate)) |
| Algo en pantalla | Explicar captura de pantalla |
| Dictado | Pulir dictado, Traducir dictado, Editar dictado, Limpieza en el dispositivo (consulta [Dictado](/es/features/dictation)) |
| Expresión breve | Emoji |

**Natural** reescribe tu texto como lo escribiría un hablante nativo, en el mismo idioma. **Pulir correo** conserva tu propio saludo, despedida y nombre, y no añade firma. **Redactar una respuesta** escribe una respuesta al correo seleccionado en su idioma y su tono, y deja un breve marcador entre corchetes para un nombre, una fecha o una decisión que no puede conocer.

## Cambiar un comando

Abre **Ajustes → Comandos de IA** y elige el comando en **Integrado**. Su página muestra lo que hace el comando, con **Pruébalo** para ejecutarlo antes con algún texto.

| Ajuste | Qué cambia |
| --- | --- |
| **PopBar** | Añade el comando a PopBar o lo quita |
| **Resaltar cambios** | Marca en el resultado lo que el comando añadió y quitó |
| **Atajo de teclado** | Ejecuta el comando sobre el texto que seleccionas en cualquier aplicación |
| **Modo en línea** | Se ejecuta sin ventana y pega el resultado sobre tu selección |
| **Acción posterior** | Lo que hace el comando con la respuesta cuando termina |
| **Modelo de IA** | El modelo que usa este comando. De forma predeterminada sigue el modelo de todos los Comandos de IA |

Las instrucciones de un comando integrado son de solo lectura. Haz clic en **Personalizar** para crear tu propia copia, que puedes modificar con libertad.

Las herramientas de escritura se ejecutan con el modelo definido en **Ajustes → Comandos de IA → Todos los comandos**, salvo que un comando elija el suyo. Los mismos comandos también aparecen en **Ajustes → Plugins → Herramientas de escritura**, y el botón **Ajustes** de una ventana de resultado abre el comando que lo produjo.

## Obtener resultados fiables

Cuando una reescritura puede ir por varios caminos, indica a quién va dirigido el texto y qué debe conseguir. Nombra lo que debe quedar igual, como nombres, fechas, cifras y citas textuales.

Compara siempre el resultado con tu original antes de enviarlo. Un texto fluido puede haber cambiado el significado.

Para una instrucción que repites, crea tu propio [Comando de IA](/es/features/ai-commands).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Un comando no está en PopBar | Haz clic en **⌄** al final de PopBar, donde van los botones que no caben, o activa **PopBar** en la página del comando en **Ajustes → Comandos de IA** |
| PopBar no aparece | Consulta la [solución de problemas de PopBar](/es/features/popbar) |
| El resultado está en un idioma inesperado | Explicar responde en el idioma del texto seleccionado. Resumir conserva el idioma del texto salvo que definas su **Idioma de respuesta**. Los demás comandos conservan el idioma del texto |
| El resultado cambió el significado | Edítalo antes de pegarlo, o ejecuta el comando de nuevo con tu texto original |

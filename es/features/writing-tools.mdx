Las herramientas de escritura son un conjunto de comandos de un clic para el texto que seleccionas en cualquier app. Corrige errores, cambia el tono, hazlo más corto o más largo, explícalo o resúmelo, o conviértelo en una lista o una tabla, sin salir de la app en la que escribes.

## Editar el texto seleccionado

1. Selecciona texto en la app donde escribes.
2. Haz clic en un comando en [PopBar](/es/features/popbar), o abre [SmartBar](/es/features/smartbar) y busca el comando.
3. Lee el resultado. Cuando **Resaltar ediciones** está activado, el resultado marca lo que el comando añadió y quitó.
4. Haz clic en **Pegar** para sustituir tu selección, o copia el resultado.

Cada comando conserva el idioma de tu texto y responde solo con el resultado. **Explicar** también responde en el idioma del texto seleccionado, y trata cada ejecución por su cuenta, no como parte de una anterior. Cuando el texto seleccionado hace una pregunta o da una instrucción, el comando edita esas palabras; no las responde.

<Tip>
Activa el **Modo en línea** de un comando en el que confías, y se ejecuta sin ventana y pega el resultado directamente sobre tu selección. Consulta **Cambiar un comando** más abajo.
</Tip>

## Elegir un comando

| Objetivo | Comandos |
| --- | --- |
| Corregir errores | Corregir ortografía y gramática, Revisar |
| Mejorar la redacción | Mejorar la escritura, Pulir, Reescribir, Sonar nativo, Edición de IA |
| Cambiar la longitud | Hacer más largo, Hacer más corto, Hacer conciso |
| Cambiar el tono | Cambiar tono a amable, seguro, informal o profesional |
| Entender el contenido | Explicar, Resumir, Extraer puntos clave |
| Reformatear | Convertir en lista, Convertir en tabla |
| Correo | Pulir correo, Redactar una respuesta |
| Publicaciones en X | Pulir para X, Caber en 280 caracteres, Convertir en un hilo, Sugerir una respuesta en X, Sugerir un comentario de cita en X |
| Traducir | Traductor, Traducir captura (consulta [Traducción](/es/ai/translate)) |
| Algo en pantalla | Explicar captura |
| Dictado | Pulir dictado, Traducir dictado, Editar dictado, Limpieza en el dispositivo (consulta [Dictado](/es/features/dictation)) |
| Expresión corta | Emoji |

**Sonar nativo** reescribe tu texto como lo escribiría un hablante nativo, en el mismo idioma. **Pulir correo** conserva tu saludo, tu despedida y tu nombre, y no añade una firma. **Redactar una respuesta** escribe una respuesta al correo seleccionado en su idioma y tono, y deja un marcador corto entre corchetes para un nombre, una fecha o una decisión que no puede saber.

## Cambiar un comando

Abre **Ajustes → Comandos de IA** y elige el comando en **Integrados**. Su página muestra qué hace el comando, con **Probarlo** para ejecutarlo primero sobre un texto.

| Ajuste | Qué cambia |
| --- | --- |
| **PopBar** | Añade el comando a PopBar, o lo quita |
| **Resaltar ediciones** | Marca lo que el comando añadió y quitó en el resultado |
| **Atajo de teclado** | Ejecuta el comando sobre el texto que seleccionas en cualquier app |
| **Modo en línea** | Se ejecuta sin ventana y pega el resultado sobre tu selección |
| **Acción posterior** | Qué hace el comando con la respuesta cuando termina |
| **Modelo de IA** | El modelo que usa este comando. De forma predeterminada sigue el modelo de todos los comandos de IA |

Las instrucciones de un comando integrado son de solo lectura. Haz clic en **Personalizar** para hacer tu propia copia, que puedes cambiar con libertad.

Las herramientas de escritura se ejecutan en el modelo fijado en **Ajustes → Comandos de IA → Todos los comandos**, a menos que un comando elija el suyo. Los mismos comandos también aparecen en **Ajustes → Plugins → Herramientas de escritura**, y el botón **Ajustes** de una ventana de resultado abre el comando que lo produjo.

## Conseguir resultados fiables

Cuando una reescritura puede ir por varios caminos, di para quién es el texto y qué debe hacer. Nombra lo que debe quedarse igual, como nombres, fechas, cifras y citas literales.

Compara siempre el resultado con el original antes de enviarlo. Un texto fluido puede cambiar igual el significado.

Para una instrucción que repites, haz tu propio [comando de IA](/es/features/ai-commands).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Un comando no está en PopBar | Haz clic en **⌄** al final de PopBar, donde van los botones que no caben, o activa **PopBar** en la página del comando en **Ajustes → Comandos de IA** |
| PopBar no aparece | Consulta [Solución de problemas de PopBar](/es/features/popbar) |
| El resultado está en un idioma inesperado | Explicar responde en el idioma del texto seleccionado. Resumir conserva el idioma del texto a menos que fijes su **Idioma de respuesta**. Los demás comandos conservan el idioma del texto |
| El resultado cambió el significado | Edítalo antes de pegarlo, o vuelve a ejecutar el comando con tu texto original |

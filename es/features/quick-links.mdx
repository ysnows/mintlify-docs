title: "Enlaces rápidos"
description: "Abre una búsqueda web, un sitio web, un archivo, una carpeta o un deeplink desde SmartBar con un solo comando."
---

Los Enlaces rápidos convierten una búsqueda web, una dirección web, un archivo o una carpeta, o el deeplink de una aplicación en un comando que ejecutas desde SmartBar. Los marcadores rellenan el enlace con lo que escribes, el portapapeles, el texto seleccionado o la fecha. Enconvo incluye búsquedas de Google, YouTube y X listas para usar.

Los Enlaces rápidos abren un destino. La [Búsqueda web](/es/ai/web-search), en cambio, lleva resultados de búsqueda a una respuesta de IA, y el [Uso del navegador](/es/features/browser-control) permite que un Agente trabaje en páginas web.

## Buscar en la web desde SmartBar

1. Abre SmartBar y busca **Búsqueda en Google en el navegador**, **Búsqueda en YouTube en el navegador** o **Búsqueda en Twitter/X en el navegador**.
2. Escribe el texto de tu búsqueda como entrada del comando. El texto seleccionado también sirve.
3. Ejecuta el comando. La búsqueda se abre en tu navegador predeterminado.

## Crear un enlace rápido

1. Ejecuta **Crear enlace rápido** desde SmartBar.
2. Escribe un **Nombre**, como Buscar en GitHub.
3. Escribe el **Enlace**: una dirección web, la ruta de un archivo o una carpeta, o un deeplink. Haz clic en **Insertar marcador** para añadir uno, como `https://github.com/search?q={argument}`.
4. Para abrirlo en una aplicación concreta, escribe en **Abrir con** el nombre de una aplicación como Safari, la ruta de una aplicación o un identificador de paquete. Déjalo vacío para usar la aplicación predeterminada.
5. Haz clic en **Guardar**. Busca el nombre del enlace rápido en SmartBar para ejecutarlo.

Cuando ejecutas un enlace rápido, el texto que escribiste o seleccionaste rellena su primer argumento. Si un argumento obligatorio sigue vacío, Enconvo lo pide antes de abrir el enlace.

| Marcador | Se rellena con |
| --- | --- |
| `{argument name="Query"}` | Un valor que escribes cuando se abre el enlace rápido |
| `{clipboard}` | El texto del portapapeles |
| `{selection}` | El texto seleccionado en la aplicación que estás usando |
| `{date}`, `{time}`, `{datetime}` | La fecha actual, la hora o ambas |
| `{date format="yyyy-MM-dd"}` | La fecha en el formato que indiques |
| `{uuid}` | Un ID único nuevo |

Prueba primero un enlace nuevo con texto normal, incluyendo espacios y signos de puntuación.

## Gestionar tus enlaces rápidos

Ejecuta **Buscar enlaces rápidos** desde SmartBar para ver todos tus enlaces rápidos. Desde ahí puedes abrir, editar, duplicar o eliminar uno, y hacer clic en **Nuevo** para añadir otro.

El menú **Más** tiene **Importar enlaces rápidos…**, que lee las exportaciones de enlaces rápidos y de ajustes de Raycast, y **Exportar a Descargas**. Una exportación de ajustes de Raycast pide la frase de contraseña que elegiste al exportarla.

## Ajustes

Abre **Ajustes → Plugins → Enlaces rápidos**. Cada comando de búsqueda también tiene su propio **Enlace**, como `https://www.google.com/search?q={query}`, que puedes cambiar.

| Ajuste | Qué cambia |
| --- | --- |
| **Abrir en una ventana nueva** | Abre los enlaces rápidos web en una ventana nueva del navegador. Funciona con Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox y Zen; Safari, Arc y Orion abren el enlace como siempre. Desactivado de forma predeterminada |
| **Cuando no hay texto seleccionado** | Lo que hace un enlace con `{selection}` cuando no hay nada seleccionado: **Pedirlo** (el predeterminado) o **Usar el portapapeles** |
| **Confirmar antes de eliminar** | Pregunta antes de eliminar un enlace rápido. Activado de forma predeterminada |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Se abre la página equivocada | Comprueba el **Enlace** del enlace rápido y sus marcadores, y pruébalo con texto sencillo |
| El navegador no se abre | Comprueba tu navegador predeterminado, **Abrir con** del enlace rápido y que el comando esté instalado |
| Un enlace con `{selection}` pide texto | No había nada seleccionado. Selecciona primero el texto, o define **Cuando no hay texto seleccionado** como **Usar el portapapeles** |

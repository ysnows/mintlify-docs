title: "Utilidades multimedia"
description: "Comprime imágenes, vídeo y audio, guarda el sonido de un vídeo o descarga un vídeo desde un enlace."
---

Las Utilidades multimedia son comandos locales para las tareas multimedia de cada día: reducir el tamaño de archivos de imagen, vídeo o audio, guardar la banda sonora de un vídeo o descargar un vídeo de una página web. Encuéntralas en SmartBar, o en **Ajustes → Plugins**.

| Comando | Qué hace | Se guarda en |
| --- | --- | --- |
| **Comprimir imagen** | Comprime una o varias imágenes, o todas las imágenes de una carpeta y sus subcarpetas, con calidad ajustable | Reemplaza las imágenes originales |
| **Comprimir vídeo** | Reduce el tamaño de un archivo de vídeo | `~/Downloads` |
| **Comprimir audio** | Reduce el tamaño de un archivo de audio según la calidad que elijas y conserva su carátula (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extraer audio** | Guarda la pista de audio de un vídeo, o de todos los vídeos de una carpeta, como M4A (MP3 cuando la pista no se puede copiar) | `~/.cache/enconvo/transcribe` |
| **Descargador de vídeos en línea** | Descarga el vídeo o el audio de un enlace, como YouTube, TikTok, Instagram, Reddit, X o Vimeo | `~/Downloads` |

<Warning>
**Comprimir imagen** reemplaza tus imágenes originales de forma predeterminada. Para conservarlas, desactiva primero **Sobrescribir el archivo de imagen original** en sus ajustes; las copias comprimidas van entonces a una carpeta `enconvo-compressed-images` junto a las imágenes.
</Warning>

## Comprimir un archivo o extraer su audio

1. Selecciona los archivos en el Finder, o adjúntalos. Para Comprimir imagen también puedes elegir una carpeta: se comprimen sus imágenes y las de sus subcarpetas, y las copias conservan la misma estructura de carpetas.
2. Abre SmartBar y ejecuta el comando.
3. Abre la salida y compruébala.

Conserva el original mientras pruebas los ajustes de compresión. Los ajustes de cada comando están en **Ajustes → Plugins**: **Utilidades de imagen** para Comprimir imagen y **Utilidades multimedia** para los demás.

| Ajuste | Qué cambia |
| --- | --- |
| **Calidad** | De 0 a 100; más alta conserva más calidad y genera un archivo más grande. 80 de forma predeterminada |
| **Ruta de la carpeta de destino** | Dónde va el archivo comprimido: una ruta absoluta, o una ruta relativa al archivo |
| **Sobrescribir el archivo original** | Reemplaza el archivo original. Activado de forma predeterminada para imágenes, desactivado para vídeo y audio |

## Descargar un vídeo

1. Abre la página del vídeo en tu navegador, o copia su enlace.
2. Ejecuta **Descargador de vídeos en línea** desde SmartBar. Toma el enlace de la pestaña activa del navegador, o de un enlace que escribas.
3. Sigue el progreso en la Dynamic Island, donde puedes cancelar. Cuando termine, haz clic en **Mostrar en Finder**.

La descarga se guarda en tu historial de chat, y un archivo que ya descargaste se reutiliza en lugar de obtenerlo de nuevo. Que un sitio funcione depende del sitio y de a qué te deja acceder. Descarga solo contenido que tengas permiso para guardar.

| Ajuste | Qué cambia |
| --- | --- |
| **Directorio de salida** | Dónde van las descargas. `~/Downloads` de forma predeterminada |
| **Solo audio** | Descarga solo el audio |
| **Resolución favorita** | La resolución que se descarga, desde **Mejor** (la predeterminada) hasta 144p |
| **Forzar conversión a MP4 compatible** | Convierte el vídeo a un MP4 que se reproduce en todas partes. Activado de forma predeterminada; requiere más tiempo y CPU |
| **Usar cookies del navegador** | Inicia sesión con las cookies de tu navegador, para vídeos que solo tú puedes ver. Elige el navegador en **Navegador** |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| **No hay imágenes que comprimir** | Selecciona las imágenes en el Finder o adjúntalas y vuelve a ejecutar el comando |
| Falla una conversión | Comprueba el formato del archivo, que la carpeta de salida admita escritura y que tengas espacio libre en el disco |
| Un vídeo privado no se descarga | Activa **Usar cookies del navegador** y elige el navegador con el que has iniciado sesión |
| Las descargas de un sitio dejan de funcionar | Lee el error y actualiza el plugin antes de volver a intentarlo. Los sitios web cambian sus formatos y sus reglas de acceso |

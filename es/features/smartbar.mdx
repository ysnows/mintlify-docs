SmartBar es un lanzador que abres desde cualquier app para hacer una pregunta a un Agente o ejecutar un comando. Pulsa **⌥Space**, escribe y pulsa Return. Úsalo cuando quieras una respuesta rápida y volver después a lo que estabas haciendo.

Para otras tareas, usa la [Ventana de chat](/es/ai/chat) para conversaciones largas y archivos, la [Barra lateral de la app](/es/features/app-sidebar) para trabajar junto a una app, [PopBar](/es/features/popbar) para actuar sobre el texto seleccionado, o la [Dynamic Island](/es/features/dynamic-island) y la [Mascota de escritorio](/es/features/pet) como un punto de entrada pequeño que permanece en pantalla. [Gestión de ventanas](/es/features/window-management) las compara todas.

## Hacer una pregunta

1. Pulsa **⌥Space**, o el atajo que definiste en **Ajustes → SmartBar**.
2. Escribe tu pregunta. Elige antes otro Agente o modelo si lo necesitas.
3. Adjunta el contexto que necesita el Agente. No ve todas las apps abiertas; consulta [Añadir contexto](#añadir-contexto).
4. Pulsa Return y sigue la respuesta o el progreso de las herramientas. Para detener una respuesta, haz clic en el botón redondo de detener.
5. Copia el resultado o escribe un mensaje de seguimiento para continuar la conversación. Un mensaje que escribes mientras la tarea se ejecuta aparece al instante.

Cuando tus palabras coinciden con un comando, Return ejecuta la fila resaltada. Para enviar tus palabras al Agente en su lugar, pulsa **⌘Return** o haz clic en **Enviar a la IA**. **⌥Return** ejecuta la segunda acción de una fila.

En el modo Agente, el chip **Permisos** define cuándo pregunta el Agente antes de actuar, y su interruptor **Sandbox** limita los comandos del Agente a la carpeta de trabajo. Consulta [Sandbox del Agente](/es/configuration/sandbox).

## Buscar con caracteres de activación

Escribe uno de estos caracteres en SmartBar para buscar un tipo de elemento:

| Escribe | Para |
| --- | --- |
| `@` | Buscar comandos |
| `#` | Añadir contexto |
| `$` | Usar una habilidad |
| `>` | Mostrar tareas recientes |
| `/` | Abrir acciones, como la selección de modelo y de razonamiento |

Puedes cambiar los cuatro primeros en **Buscar**, dentro de **Ajustes → SmartBar**. `/` no se puede cambiar.

Elige elementos de la lista que se abre en lugar de escribir un nombre de memoria: la lista muestra los comandos y las fuentes de contexto que realmente tienes. Consulta [Herramientas de escritura](/es/features/writing-tools), [Enlaces rápidos](/es/features/quick-links) y [Conciencia del contexto](/es/features/context-awareness).

Algunas listas se abren con un alias: escribe el alias y un espacio, y [Historial del portapapeles, Búsqueda de marcadores o Búsqueda de archivos](/es/features/clipboard-history) se abre dentro de SmartBar.

## Añadir contexto

SmartBar puede recoger el texto seleccionado, la selección del Finder y la página actual del navegador al abrirse. Elige **Adjuntar**, **Sugerir** o **Desactivado** para cada uno en **Ajustes → Conciencia del contexto**. Para añadir cualquier otra cosa, escribe `#` y elige una fuente.

## Elegir un diseño

**Diseño** en **Ajustes → SmartBar** define lo que ves cuando se abre SmartBar:

| Diseño | Qué se abre |
| --- | --- |
| **Solo entrada** | Solo el campo de entrada |
| **Entrada y barra de herramientas** | La entrada, más acciones rápidas, el selector de modelo y los controles de voz |
| **Panel completo** | Todo lo anterior, más la lista bajo la entrada |

Con **Panel completo**, **Vista inicial** define lo que muestra la lista antes de escribir: **Prompts recomendados** o **Lista de comandos**. En todos los diseños, la lista y los resultados siguen apareciendo cuando escribes o ejecutas un comando.

## Ajustes

Abre **Ajustes → SmartBar**.

| Ajuste | Qué cambia |
| --- | --- |
| **Atajo de teclado** | Abre y cierra SmartBar desde cualquier app. El valor predeterminado es **⌥Space**. |
| **Agente predeterminado** | El Agente que responde a lo que escribes. |
| **Borrar conversación automáticamente** | Inicia una conversación nueva cuando SmartBar se abre tras haber estado cerrado este tiempo, desde **Nunca** hasta **Cada vez que se abre**. |
| **Diseño** | Lo que ves cuando se abre SmartBar (ver arriba). |
| **Apariencia** | Cristal claro u oscuro para SmartBar y la Barra lateral de la app, o **Seguir la app**. |
| **Cambiar fuente de entrada automáticamente** | Cambia a esta fuente de entrada mientras escribes en SmartBar y vuelve a la anterior cuando se cierra. |
| **Atajos de navegación** | Atajos con la tecla Control para moverte por listas y texto: **macOS** (⌃N ⌃P ⌃F ⌃B) o **Vim** (⌃J ⌃K ⌃L ⌃H). |
| **Buscar** | Los caracteres de activación de comandos, contexto, habilidades y tareas recientes. |
| **Calculadora** | Responde a operaciones matemáticas, unidades, divisas, fechas y zonas horarias mientras escribes. Activada de forma predeterminada. |
| **Tiempo y vuelos** | También consulta el tiempo, los vuelos y la hora en cualquier lugar. Desactivado de forma predeterminada. |

Cambiar un valor predeterminado no cambia todos los chats existentes. [Selección de modelo](/es/ai/model-selection-guide) explica cómo cada chat conserva su propia elección de modelo y de razonamiento.

## Voz y cálculos

Haz clic en el micrófono para decir tu pregunta con el [Dictado](/es/features/dictation). Para una conversación hablada, inicia [Live Talk](/es/features/live-voice); una llamada que inicias desde SmartBar pasa a la Dynamic Island.

Escribe una expresión aritmética, como `2+3*4`, y SmartBar muestra el resultado. La calculadora también convierte unidades y divisas, trabaja con fechas y zonas horarias y reparte un total, como en `25% off $60 split by 3`. Comprueba el resultado y la acción que ofrece antes de copiarlo.

Para consultar el tiempo, un vuelo o la hora en un lugar, activa **Tiempo y vuelos** en **Ajustes → SmartBar**. Después escribe `weather in London`, `Tokyo feels like`, un número de vuelo como `BA008` o `time in Chernivtsi`. Solo se envía el nombre del lugar o el número de vuelo, a Open-Meteo, adsbdb y adsb.lol. **Tiempo y vuelos** se comparte con la calculadora de la [Dynamic Island](/es/features/dynamic-island).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| SmartBar no se abre | Revisa **Atajo de teclado** en **Ajustes → SmartBar** y comprueba si otra app usa el mismo atajo. Si definiste tu propia tecla antes, se mantiene como la definiste. |
| Return ejecuta un comando en lugar de preguntar al Agente | Pulsa **⌘Return** o haz clic en **Enviar a la IA**. |
| Una suma o una consulta del tiempo no muestra nada | Revisa **Calculadora** y **Tiempo y vuelos** en **Ajustes → SmartBar**. |
| Falta una app o el texto seleccionado en el contexto | Revisa [Permisos](/es/configuration/permissions) y **Ajustes → Conciencia del contexto**. |
| Una solicitud falla | Revisa el proveedor seleccionado y lee el error que indica. |
| Falta un control de esta página | Puede que tu compilación sea anterior a esta guía. Consulta [Actualizaciones](/es/configuration/updates). |

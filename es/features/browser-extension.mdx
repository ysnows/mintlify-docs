---
title: "Extensiones del navegador"
description: "Instala la extensión Enconvo Companion para que Enconvo pueda trabajar en tu navegador real, con tus sesiones, cookies y extensiones."
---

La extensión de navegador de Enconvo, Enconvo Companion, permite que Enconvo controle tu navegador real cuando una tarea necesita el estado de tu navegador con las sesiones iniciadas. Úsala para sitios como LinkedIn, Gmail, Salesforce, paneles o herramientas internas, donde importan tus cookies y las extensiones de tu navegador. En Ajustes se llama **Complemento del navegador**.

Para páginas públicas, vistas previas locales o flujos de trabajo que no deben tocar tu perfil personal del navegador, usa mejor la automatización de navegador aislada.

## Configurar la extensión

<Steps>
  <Step title="Instala la extensión">
    Abre **Ajustes → Uso del navegador** y haz clic en **Instalar complemento del navegador** en **Extensiones del navegador**. Se abre la página de la extensión en la Chrome Web Store. También puedes instalarla desde la tienda de extensiones de tu navegador. Funciona en Chrome, Edge, Brave, Arc, Vivaldi, Opera y Firefox. El [tutorial en vídeo de Uso del ordenador](https://youtu.be/0CbQA7d8zqU?t=33) muestra la instalación en Chrome.
  </Step>
  <Step title="Mantén el navegador abierto">
    La extensión se conecta a Enconvo por sí sola, a través de `ws://localhost:11225`.
  </Step>
  <Step title="Revisa la ventana emergente">
    Haz clic en el icono de la extensión. La ventana emergente muestra **Chrome conectado**, **Edge conectado**, **Firefox conectado** o el nombre del navegador en el que estés.
  </Step>
  <Step title="Inicia una tarea de navegador">
    Pide a Enconvo que lea, haga clic, escriba, tome una captura de pantalla o gestione pestañas en el navegador.
  </Step>
</Steps>

## La ventana emergente

| Elemento | Qué muestra |
| --- | --- |
| Estado de la conexión | Si la extensión de este navegador está conectada a Enconvo |
| Navegador actual | El navegador con el que se conecta esta extensión, como Chrome, Edge, Brave o Firefox |
| Navegadores conectados | Los demás navegadores cuya extensión está conectada ahora a Enconvo |
| Versión | La versión instalada de la extensión |
| **Más información** | Abre esta página |

Si la ventana emergente indica que está desconectado, reinicia Enconvo y actualiza el navegador. Si sigue sin conectarse, desactiva la extensión y vuelve a activarla.

## Usar más de un navegador

Enconvo puede conectarse a varios navegadores a la vez. Cuando una tarea no indica un navegador, Enconvo elige uno en este orden:

1. El **Navegador predeterminado** que elegiste en los ajustes de Uso del navegador (**Ajustes → Uso del navegador**, luego **Ajustes** en el menú **⋯**).
2. El navegador predeterminado de tu Mac.
3. El navegador conectado que usaste más recientemente.

Las API de automatización también pueden indicar el navegador:

```json
{
  "browser": "edge"
}
```

Los valores habituales incluyen `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera` y `firefox`.

## Mantenerse en la pestaña correcta

Cuando empieza una tarea de navegador, Enconvo anota el navegador y la pestaña en los que trabaja. Los pasos posteriores se quedan en esa pestaña siempre que pueden, aunque la página abra una ventana emergente, se recargue o pierda el foco.

Para obtener los mejores resultados:

- Mantén la pestaña abierta hasta que termine la tarea.
- Indica el navegador cuando haya varios conectados.
- Di "usa la pestaña actual" cuando quieras que Enconvo actúe sobre la página que tienes delante.
- Pide que vuelva a mirar la página después de que navegue o de que envíes un formulario.

## Acceso a sitios web y seguridad

Las páginas web pueden contener instrucciones que tú no has escrito. En páginas sensibles, revisa el sitio y la acción antes de dejar que Enconvo continúe.

La extensión usa permisos del navegador para leer páginas, hacer clic, escribir, tomar capturas de pantalla, ver pestañas y leer cookies cuando una tarea lo necesita. Trata las páginas con sesión iniciada, el historial del navegador y las herramientas internas como datos sensibles.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La ventana emergente indica que está desconectado | Asegúrate de que Enconvo se está ejecutando, reinicia el navegador y luego desactiva y vuelve a activar la extensión. Comprueba que nada bloquea `localhost:11225`. |
| Se controla el navegador equivocado | Define el **Navegador predeterminado** en los ajustes de Uso del navegador, o pasa un valor de navegador como `edge`, `chrome` o `firefox` en la acción del navegador. |
| Está conectado, pero no se puede controlar una página | Las páginas del navegador como `chrome://` no se pueden controlar. Las páginas con una política de seguridad de contenido estricta, Shadow DOM cerrado y los avisos de permisos del navegador también pueden interferir. |
| No funciona la subida de un archivo | En la página de detalles de la extensión en tu navegador, activa el acceso a las URL de archivos. Las tareas que suben archivos locales o abren páginas respaldadas por archivos lo necesitan. |

El contexto es lo que acompaña a tu pregunta: el texto que seleccionaste, los archivos seleccionados en Finder, la página abierta en el navegador o una captura. El SmartBar puede recoger parte al abrirse, y puedes añadir más escribiendo `#`. El Agente responde entonces sobre lo que estás mirando, sin que tengas que explicarlo.

## Elegir qué recoge el SmartBar

1. Abre **Ajustes → Conciencia del contexto**.
2. En **Al abrir la Smart Bar**, pon cada fuente en **Adjuntar**, **Sugerir** o **Desactivado**.
3. Cambia a otra app, selecciona algo y abre el SmartBar para ver el resultado.

| Fuente | Qué añade | Predeterminado |
| --- | --- | --- |
| **Texto seleccionado** | Texto seleccionado en la app que estabas usando | **Adjuntar** |
| **Selección de Finder** | Archivos y carpetas seleccionados en Finder | **Sugerir** |
| **Página actual del navegador** | La página abierta en Safari, Chrome, Arc, Edge u otro navegador Chromium | **Sugerir** |

**Adjuntar** añade la fuente a la entrada en cuanto se abre el SmartBar. **Sugerir** la lista encima de los comandos, así la añades con un clic. **Desactivado** la deja fuera.

Solo el SmartBar usa estos ajustes. Los comandos que ejecutas sobre una selección siempre reciben el texto seleccionado. La primera vez que añades contexto de Finder o del navegador, macOS pregunta si Enconvo puede controlar esa app.

## Añadir contexto con #

1. En el SmartBar, escribe `#`.
2. Escribe una palabra para acotar la lista, como `#screen`, `#finder`, `#clipboard` o `#browser`.
3. Elige una fuente. Se añade a tu mensaje.
4. Escribe tu pregunta y envíala.

| Fuente | Qué añade |
| --- | --- |
| **Texto seleccionado** | El texto seleccionado en la ventana actual |
| **Clipboard Text** | El texto del portapapeles |
| **Current Application Content** | El texto de la app de delante |
| **Current Application Screenshot** | Una captura de la app de delante |
| **Current Screen Screenshot** | Una captura de toda la pantalla |
| **Live Screen Screenshot** | Una captura de la pantalla sin las ventanas de Enconvo |
| **User Select Area Screenshot** | Una captura de una zona que seleccionas |
| **Finder Selected Items** | Los archivos y carpetas seleccionados en Finder |
| **Finder Current Directory URL** | La carpeta abierta en Finder |
| **Browser Current Tab URL** | La dirección de la pestaña actual del navegador |

Tus ventanas abiertas también se listan, así puedes añadir una ventana de otra app. Para usar un carácter distinto de `#`, cambia **Contexto** en **Búsqueda**, dentro de **Ajustes → SmartBar**.

## Qué preguntar

Con la página del navegador adjunta, pide a Enconvo que resuma la página, la traduzca o extraiga la información clave. Con archivos de Finder adjuntos, pídele que describa los archivos, sugiera cómo organizarlos, ayude con un renombrado por lotes o analice su contenido.

<Note>
El contexto que adjuntas va al modelo que responde, o al proveedor que lo procesa. Revisa qué está adjunto y los ajustes de tu proveedor antes de trabajar con contenido sensible.
</Note>

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El texto seleccionado no se adjunta | Comprueba que **Texto seleccionado** esté en **Adjuntar**, y revisa [Permisos](/es/configuration/permissions). |
| Falta el contexto de Finder o del navegador | Permite que Enconvo controle esa app cuando macOS pregunte. Si lo rechazaste, permítelo en [Permisos](/es/configuration/permissions). |
| Escribir `#` no abre la lista | Comprueba el carácter de **Contexto** en **Ajustes → SmartBar**. |

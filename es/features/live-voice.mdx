title: "Live Talk"
description: "Llama a tu Agent y habla las cosas con él: te escucha, responde con su propia voz e inicia tareas mientras hablas."
---

Live Talk es una llamada de voz con tu Agent. Hablas sin mantener pulsada ninguna tecla, el Agent responde en voz alta y puede iniciar tareas con sus herramientas activadas mientras la llamada continúa. Para convertir la voz en texto escrito, usa el [Dictado](/es/features/dictation).

## Antes de empezar

Enconvo necesita acceso al Micrófono en macOS. Selecciona un micrófono y un altavoz que funcionen. Los servicios en la nube que usa una llamada gastan puntos de Enconvo Cloud; tus propias claves y los modelos de tu Mac no.

## Iniciar y finalizar una llamada

1. Abre un chat con el Agent con el que quieres hablar.
2. Haz clic en **Live Talk** junto al micrófono. Espera a que la llamada se conecte.
3. Habla. No hay ninguna tecla que mantener y puedes hablar por encima del Agent en cualquier momento para que se detenga y te escuche.
4. Para un trabajo más grande, nombra el resultado que quieres y da suficiente contexto. El trabajo se ejecuta como una tarea en su propio chat. Despliega los detalles del trabajo para ver su progreso o sus resultados.
5. Usa el control del micrófono para silenciar, o el control de colgar para finalizar la llamada. Las tareas siguen ejecutándose después de colgar.

Los turnos hablados se guardan en el historial de chat normal, así que al reabrir el chat puedes repasar el diálogo y los detalles del trabajo. Una llamada en silencio sigue conectada hasta que cuelgas. Los enlaces de una tarea en el chat te devuelven a la llamada.

## Preguntar sin iniciar una tarea

Algunas cosas las hace el Agent directamente en la llamada, sin iniciar una tarea: buscar en tu Memoria y en chats anteriores, guardar algo que le pidas que recuerde, leer tu Calendario y Recordatorios, buscar en tu correo y usar herramientas de solo lectura de tus servidores MCP. **Acciones rápidas** en Ajustes lista más.

Durante una tarea larga, el Agent te cuenta lo que la tarea ha encontrado hasta el momento.

## Silenciar al Agent

Dile al Agent que se calle o que deje de hablar durante un rato. No responde nada y guarda sus novedades hasta que lo llames por su nombre, le digas que puede volver a hablar, le escribas o hagas clic en el estado **En silencio**.

## Otras formas de llamar

Los Agents también pueden llamarte, en la app del iPhone o a tu número de teléfono, cuando una tarea te necesita; al contestar se inicia Live Talk. Consulta [Teléfono del agente](/es/features/agent-phone).

También puedes iniciar una llamada desde un [Avatar](/es/features/avatar), que entonces aparece como el interlocutor, o desde el Chat de voz de la [app del iPhone](/es/integrations/iphone-app). Durante una llamada en la app del iPhone o de Android, la herramienta **Pantalla remota** abre la pantalla de tu ordenador en una pequeña ventana flotante sobre la llamada; consulta [Usa la pantalla de tu ordenador](/es/integrations/iphone-app). Activa **Pantalla en directo** para que el Agent vea tu pantalla durante una llamada.

## Ajustes

Abre **Ajustes → Live Talk**:

| Ajuste | Qué cambia |
| --- | --- |
| **Escuchar** | Cómo te oye la llamada. **Enconvo Cloud Fast** (por defecto) y **ElevenLabs Scribe** (Scribe v3 Live) oyen cada palabra a medida que la dices. También puedes elegir un modelo que se ejecute en tu Mac, o cualquier modelo de voz. |
| **Pensar** | El modelo con el que habla el Agent. **Igual que el chat** (por defecto) usa un modelo rápido del propio proveedor del chat, así que una llamada en un chat con tu propia clave de API no gasta puntos de Enconvo Cloud. En un chat en Enconvo Cloud es Enconvo Fast, que responde con DeepSeek V4.1 Flash, también ve lo que le muestras y se factura como ese modelo; las llamadas con un plan de pago o una prueba siguen siendo gratuitas. Los trabajos más grandes van a tu Agent y se ejecutan con el modelo elegido para ese chat. |
| **Hablar** | La voz con la que responde el Agent, ElevenLabs v4 Turbo por defecto. Phonon se ejecuta en tu Mac, gratis y sin conexión, solo en inglés. Se aplica desde la siguiente llamada. |
| **Expresión de voz** | Cuánto puede cambiar el tono de cada respuesta para adaptarse a la conversación: **Desactivado**, **Sutil** o **Expresiva**. Funciona con voces de ElevenLabs, Fish Audio y Gemini. |
| **Nueva conversación tras** | Una llamada realizada dentro de estos minutos desde la última continúa donde se quedó, incluidas las llamadas de Avatar. **0** siempre la continúa. |
| **Acciones rápidas** | **Gestionar** abre **Ajustes → Acciones rápidas**, lo que el Agent hace al instante cuando se lo pides, sin iniciar una tarea. |

<Note>
El modelo de **Pensar** de Live Talk se define aquí. También puedes elegirlo en **Modelos de tareas** dentro de **Ajustes → Modelo de IA**.
</Note>

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La llamada no se conecta | Lee el error de conexión y revisa tus elecciones de **Escuchar**, **Pensar** y **Hablar**. Para los servicios en la nube, comprueba tus puntos en **Ajustes → Consumo de puntos**. |
| El micrófono no está disponible | Termina primero un Dictado o una grabación activos, y comprueba el acceso al Micrófono en macOS. |
| El Agent no puede realizar una acción | Revisa las herramientas y los permisos de ese Agent. La voz no añade herramientas que el Agent no tenga. |
| No se usa una voz nueva | Los cambios de voz se aplican desde la siguiente llamada. |
| La llamada termina con "The audio device changed" | Tu micrófono o altavoz se reinicia continuamente. Elige otro en **Ajustes del Sistema → Sonido** y empieza una llamada nueva. |
| El Agent dejó de responder | Puede que esté en silencio. Llámalo por su nombre o haz clic en el estado **En silencio**. |

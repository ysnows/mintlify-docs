Dibujo en pantalla te deja marcar una parte de la pantalla antes de preguntar a tu Agente. Dibuja flechas, círculos, resaltados o notas, y envía. La captura marcada se adjunta al chat como imagen, en la Isla dinámica, salvo que acabes de usar otro chat de Enconvo, como la Ventana de chat.

## Marca la pantalla

1. Pon delante el contenido sobre el que quieres preguntar.
2. Haz doble clic con el botón derecho para abrir Dibujo en pantalla, o pulsa el **Atajo** que definiste en **Ajustes → Dibujo en pantalla**.
3. Si **Primero, captura un área** está activado, arrastra para seleccionar la zona. Si no, dibuja directamente sobre la pantalla en vivo.
4. Elige una herramienta en la barra y marca la zona que quieres.
5. Pulsa **Enviar** (el avión de papel) o pulsa **⌘↩**.
6. Revisa la imagen adjunta y escribe una petición, como “¿Qué significa el aviso resaltado?”.

Dibujo en pantalla no tiene atajo hasta que definas uno. El doble clic con el botón derecho funciona desde el primer momento.

### Añade una etiqueta hablada

Mantén la tecla **Option** izquierda y habla para describir la forma que acabas de dibujar. Tus palabras aparecen junto a ella como texto. Para que Dibujo en pantalla escuche después de cada forma, activa **Hablar después de cada forma** en la barra de herramientas y haz una pausa para terminar cada etiqueta.

## Herramientas

| Herramienta o acción | Tecla |
| --- | --- |
| Flecha | **A** |
| Línea | **L** |
| Lápiz | **P** |
| Resaltador | **H** |
| Rectángulo | **R** |
| Círculo | **O** |
| Contador (marcas numeradas) | **N** |
| Texto | **T** |
| Seleccionar | **V** |
| Borrador | **E** |
| Color | **C** |
| Line Width | **⌘** + desplazamiento |
| **Pizarra** | **B** |
| **Resaltar cursor** | **K** |
| **Guardar como…** | **⌘S** |
| **Enviar** | **⌘↩** |

La barra también tiene **Deshacer**, **Rehacer**, **Borrar**, **Copiar al portapapeles** y **Cerrar**.

## Ajustes

Abre **Ajustes → Dibujo en pantalla**.

| Ajuste | Qué hace |
| --- | --- |
| **Primero, captura un área** | Selecciona una zona antes de dibujar. Desactívalo para dibujar directamente en la pantalla en vivo. Activado de forma predeterminada. |
| **Atajo** | Abre o cierra Dibujo en pantalla. Vacío de forma predeterminada. |
| **Doble clic con el botón derecho** | Abre o cierra Dibujo en pantalla con un doble clic rápido con el botón derecho. Activado de forma predeterminada. |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La capa no se abre | Revisa el **Atajo** y **Doble clic con el botón derecho** en **Ajustes → Dibujo en pantalla**, y revisa los [permisos de macOS](/es/configuration/permissions). |
| Solo necesitas toda la ventana de la app | Usa [Appshots](/es/features/appshots). |

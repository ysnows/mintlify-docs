El Dibujo en pantalla te permite marcar una parte de la pantalla antes de preguntar a tu Agent sobre ella. Dibuja flechas, círculos, resaltados o notas y envía. La captura marcada se adjunta a tu chat como imagen, en la Dynamic Island a menos que acabaras de usar otro chat de Enconvo, como la Ventana de chat.

## Marcar tu pantalla

1. Trae al frente el contenido sobre el que quieres preguntar.
2. Haz doble clic con el botón derecho para abrir el Dibujo en pantalla, o pulsa el **Atajo de teclado** que definiste en **Ajustes → Dibujo en pantalla**.
3. Si **Primero, captura un área** está activado, arrastra para seleccionar la región. Si no, dibuja directamente sobre la pantalla en vivo.
4. Elige una herramienta en la barra de herramientas y marca la zona que quieres señalar.
5. Haz clic en **Enviar** (el avión de papel) o pulsa **⌘↩**.
6. Revisa la imagen adjunta y escribe una petición, como "¿Qué significa la advertencia resaltada?"

El Dibujo en pantalla no tiene atajo hasta que defines uno. El doble clic con el botón derecho funciona desde el principio.

### Añadir una etiqueta hablada

Mantén pulsada la tecla **Opción** izquierda y habla para describir la forma que acabas de dibujar. Tus palabras aparecen junto a ella como texto. Para que el Dibujo en pantalla escuche después de cada forma que dibujes, activa **Hablar después de cada forma** en la barra de herramientas, y haz una pausa para terminar cada etiqueta.

## Herramientas

| Herramienta o acción | Tecla |
| --- | --- |
| Flecha | **A** |
| Línea | **L** |
| Pluma | **P** |
| Resaltador | **H** |
| Rectángulo | **R** |
| Círculo | **O** |
| Contador (marcadores numerados) | **N** |
| Texto | **T** |
| Seleccionar | **V** |
| Borrador | **E** |
| Color | **C** |
| Grosor de línea | **⌘** + desplazamiento |
| Pizarra | **B** |
| Resaltar cursor | **K** |
| Guardar como… | **⌘S** |
| Enviar | **⌘↩** |

La barra de herramientas también tiene **Deshacer**, **Rehacer**, **Borrar**, **Copiar al portapapeles** y **Cerrar**.

## Ajustes

Abre **Ajustes → Dibujo en pantalla**.

| Ajuste | Qué hace |
| --- | --- |
| **Primero, captura un área** | Selecciona una región antes de dibujar. Desactívalo para dibujar directamente sobre la pantalla en vivo. Activado por defecto. |
| **Atajo de teclado** | Abre o cierra el Dibujo en pantalla. Vacío por defecto. |
| **Doble clic con el botón derecho** | Abre o cierra el Dibujo en pantalla con un doble clic rápido con el botón derecho. Activado por defecto. |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La superposición no se abre | Revisa el **Atajo de teclado** y el **Doble clic con el botón derecho** en **Ajustes → Dibujo en pantalla**, y revisa los [permisos de macOS](/es/configuration/permissions). |
| Solo necesitas la ventana completa de la app | Usa [Appshots](/es/features/appshots) en su lugar. |

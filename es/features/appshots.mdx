Appshots añade la ventana de la app que está delante a tu chat como contexto. Úsalo cuando quieras preguntar sobre algo que ves en pantalla sin guardarlo en una base de conocimientos.

## Capturar la ventana de una app

1. Trae al frente la app sobre la que quieres preguntar.
2. Pulsa tu atajo de Appshots. Appshots no tiene atajo hasta que lo defines en **Atajo de teclado**, dentro de **Ajustes → Appshots**.
3. La ventana va a la SmartBar, la Ventana de chat o la Barra lateral de la app si una de ellas está abierta delante. Si no, va a la Dynamic Island. Suena un breve sonido de obturador.
4. Comprueba la ventana adjunta y haz después una pregunta concreta, como "Explica el error de esta ventana."

## Ajustes

Abre **Ajustes → Appshots**.

| Ajuste | Qué hace |
| --- | --- |
| **Activar Appshots** | Permite que el atajo añada la ventana de la app que está delante. Activado por defecto. |
| **Sonido de captura** | Reproduce un breve sonido de obturador cuando se añade un Appshot. El sonido confirma la captura; aun así, comprueba el adjunto antes de enviar. |
| **Atajo de teclado** | El atajo que añade la ventana. Ninguno por defecto. Puede ser un conjunto de teclas modificadoras, como las dos teclas **Opción** a la vez, o un atajo normal. |

## Elegir la herramienta de captura adecuada

| Objetivo | Usa |
| --- | --- |
| Preguntar sobre la ventana de la app actual | Appshots |
| Llamar la atención sobre una región antes de preguntar | [Dibujo en pantalla](/es/features/screen-doodle) |
| Guardar el contenido de la app actual para buscarlo más tarde | [Captura rápida](/es/features/quick-capture) |
| Extraer texto de una imagen | [OCR](/es/ai/ocr) |

El contenido capturado puede enviarse al modelo que uses para la petición. Consulta [Conciencia del contexto](/es/features/context-awareness) para ver otras formas de añadir contexto.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| No aparece ningún contexto | Revisa **Ajustes → Permisos**, sobre todo Grabación de pantalla y Accesibilidad. |
| Se captura la ventana equivocada | Vuelve a traer al frente la app de destino. Appshots captura la ventana de otra app, no las ventanas propias de Enconvo, como Ajustes. |
| El atajo no hace nada | Asegúrate de que **Activar Appshots** está activado y de que hay un **Atajo de teclado** definido. |
| El atajo hace otra cosa | Otra app usa las mismas teclas. Cambia el **Atajo de teclado** en **Ajustes → Appshots**. |

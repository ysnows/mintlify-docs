Cada función de voz de Enconvo tiene su propio ajuste de modelo de voz, así que puedes elegir un modelo de streaming rápido para el Dictado y otro distinto para archivos largos. Elige el modelo en la función que estés usando de verdad.

| Función | Dónde configurarlo | Guía |
| --- | --- | --- |
| Voz escrita como texto | **Ajustes → Modelos de dictado** | [Dictado](/es/features/dictation) |
| Comando de voz | **Ajustes → Comando de voz → Escuchar** | [Comando de voz](/es/features/dictation) |
| Llamadas de Live Talk | **Ajustes → Live Talk → Escuchar** | [Live Talk](/es/features/live-voice) |
| Grabación de reunión o clase | **Ajustes → Modelos de grabación** | [Grabación de reunión](/es/features/meeting-recording) |
| Un archivo de audio o vídeo que ya tienes | **Ajustes → Modelos de transcripción** | [Transcripción](/es/features/transcription) |
| Subtítulos en tiempo real | **Ajustes → Modelo de subtitulado** | [Subtitulado en directo](/es/features/live-captioning) |

## Elegir un modelo

1. Abre el ajuste de tu función en la tabla de arriba.
2. En una página de modelo de Dictado, Grabación, Transcripción o Subtitulado, filtra la lista con **Todos**, **Enconvo Cloud**, **Local** o **Proveedores personalizados**. En Comando de voz y Live Talk, **Escuchar** muestra primero los modelos recomendados y luego cualquier otro modelo de voz.
3. Elige un modelo y revisa su idioma y las opciones del modelo.

Los modelos de **Enconvo Cloud** usan tu cuenta de Enconvo, sin clave de API. **Enconvo Cloud Fast**, el reconocimiento de voz propio de Enconvo Cloud, es gratuito para todos y muestra una etiqueta verde **Gratuito**. **Proveedores personalizados** usan tu propia clave de API con ese proveedor. Los modelos **Local** (MLX y Core ML) reconocen la voz en tu Mac una vez descargado su modelo.

El [catálogo de proveedores de voz](/es/providers/catalog) lista todos los proveedores declarados, incluidos servicios en la nube y variantes locales de Parakeet, Qwen, Whisper, SenseVoice, Paraformer y Nemotron. El hardware y la disponibilidad dependen del runtime y de tu compilación.

## Modelos destacados

| Modelo | Qué saber |
| --- | --- |
| ElevenLabs Scribe v3 Live | Transmite las primeras palabras en menos de un segundo, con menos errores en chino y en audio con ruido. Úsalo para Dictado y entrada de voz con tu clave de API de ElevenLabs o Enconvo Cloud. El chino y el japonés salen sin espacios entre palabras. Live Talk lo usa cuando Live Talk usa ElevenLabs. |
| ElevenLabs Scribe v3 | Transcribe archivos, con tu clave de API de ElevenLabs o Enconvo Cloud. |
| Enconvo Cloud Fast | Gratuito. Su modelo en tiempo real muestra tus palabras mientras hablas, y su modelo asíncrono transcribe archivos grabados. |
| Soniox | Usa los modelos v6 de Soniox en Dictado, Grabación, Transcripción, Subtitulado, Live Talk y subtítulos de conferencias. Un modelo v5 que elegiste antes pasa a v6 por ti; Soniox retira v5 el 15 de diciembre de 2026. |
| DeepSeek | Transcribe para Transcripción y Dictado, con tu propia clave de API de DeepSeek o como **DeepSeek (Enconvo Cloud)** sin clave. Detecta 21 idiomas por sí solo. |
| Fluid Speech Pro by FluidVoice | Se ejecuta en tu Mac y en tu iPhone y transcribe 25 lenguas europeas sin conexión, con menos errores que Parakeet, en vivo mientras hablas o cuando terminas. Necesita macOS 15 o iOS 18 o posterior. |

## Ajustar el modelo a la tarea

| Capacidad | Qué saber |
| --- | --- |
| Streaming | Produce texto parcial mientras hablas. Usa un modelo en tiempo real cuando quieras que las palabras aparezcan a medida que hablas. |
| Transcripción por lotes | Procesa un archivo después de capturarlo o subirlo. |
| Pistas de idioma y palabras frecuentes | Orientan el reconocimiento cuando el proveedor las admite. |
| Diarización de hablantes | Separa las voces. No garantiza el nombre correcto de la persona. |
| Traducción en vivo | Solo la ofrecen algunos proveedores y modelos, con idiomas de origen y de destino. |
| Marcas de tiempo y salida estructurada | Dependen del proveedor y del formato de salida de la transcripción. |

## Probar con una muestra corta

Graba una muestra corta con el idioma, el micrófono y los términos que usas de verdad, y revísala antes de procesar una reunión larga. Si falla, lee el error para ver detalles de tamaño de archivo, formato, extracción, cuenta o red.

Las descargas de modelos locales pueden ser mucho más grandes que la app. Comprueba el tamaño real de la descarga y tu espacio libre; no todos los modelos de voz locales necesitan lo mismo.

No tienes que elegir: [Auto Route](/es/providers/auto-route), el modelo predeterminado, elige uno para cada mensaje. Cuando quieras un modelo concreto, esta página te ayuda a elegirlo y muestra dónde se guarda la elección.

## Elegir según la tarea

| Tarea | Busca |
| --- | --- |
| Reescrituras rápidas y respuestas cortas | Un modelo rápido y de bajo coste |
| Trabajo de Agente en varios pasos | Llamadas a herramientas fiables y soporte de razonamiento |
| Preguntas sobre una captura o una imagen | Entrada de imagen |
| Documentos largos | Una ventana de contexto larga |
| Trabajo privado que se queda en tu Mac | Un [modelo local](/es/ai/local-llm), más proveedores locales para los demás pasos |
| Conversaciones de voz | [Live Talk](/es/features/live-voice), que tiene sus propios ajustes de voz |
| Crear imágenes o vídeo | Un proveedor de [imagen](/es/ai/image-generation) o de [vídeo](/es/ai/video-generation), no un modelo de chat |

El selector de modelos muestra los modelos que ofrecen tus proveedores ahora mismo. Los modelos que admiten el Modo rápido muestran una pastilla de Modo rápido, que los ejecuta más rápido a un precio más alto.

## Usar las recomendaciones

Los selectores de modelos en Ajustes empiezan con tres sugerencias para ese tipo de trabajo: **El más adecuado**, **El más barato** y **Máxima calidad**. Cada una muestra una razón breve y su precio por 1M de tokens, de entrada y de salida. Bajo el ajuste, una línea te avisa cuando el modelo que elegiste cuesta muchas veces más que el recomendado.

Cuando creas un Agente en **Nuevo agente**, Enconvo lee la descripción del Agente y sugiere un modelo, con uno más barato y uno más potente al lado. Haz clic en uno para usarlo.

## Dónde se fija el valor predeterminado

- **Un chat nuevo**: el modelo que eliges en un **Nuevo chat** de nivel superior pasa a ser el predeterminado del Agente.
- **Un proyecto**: un chat nuevo dentro de un proyecto usa el modelo propio del proyecto.
- **Un chat existente**: una vez que un chat empieza, conserva su modelo y su esfuerzo de razonamiento hasta que los cambies en ese chat.
- **Chats sin elección propia y canales de mensajería instantánea**: siguen el valor predeterminado del Agente.

Después de cambiar un valor predeterminado en otro sitio, comprueba el modelo que muestra el chat antes de enviar.

## Esfuerzo de razonamiento

El esfuerzo de razonamiento define cuánto piensa un modelo antes de responder. Un esfuerzo mayor puede dar mejores respuestas a problemas difíciles, pero tarda más y usa más tokens. Los niveles dependen del modelo; un modelo sin modo de pensamiento no tiene ajuste de esfuerzo.

## Ventana de contexto

La ventana de contexto es cuánto de una conversación lee el modelo de una vez. Cuando un chat la supera, Enconvo compacta la parte anterior. Los modelos de Claude que pueden llegar a 1M de tokens empiezan en 500K, así que los chats largos se compactan antes y cuestan menos.

Para cambiar la ventana de contexto de un modelo, abre el proveedor en **Ajustes → Modelo de IA**, haz clic en **Gestionar modelos** (el engranaje junto a **Nombre del modelo**), edita el modelo y define **Ventana de contexto**.

## Elegir los modelos de las tareas en segundo plano

Las tareas pequeñas se ejecutan en segundo plano con un modelo barato: títulos de chat, sugerencias del siguiente mensaje, Live Talk, títulos y resúmenes de grabaciones, traducción de grabaciones y títulos de ideas. Por defecto cada una está en **Automático**, que usa un modelo pequeño:

- Los títulos de chat, las sugerencias del siguiente mensaje y Live Talk usan un modelo pequeño del propio proveedor del chat. Un chat con tu propia clave de API no gasta puntos de Enconvo Cloud en ellas.
- Las grabaciones y los títulos de ideas usan un modelo pequeño de tu proveedor predeterminado.
- Cuando el proveedor no tiene un modelo pequeño que Enconvo conozca, Automático usa el modelo del chat o tu modelo predeterminado.

Para elegir un modelo tú mismo:

<Steps>
  <Step title="Abrir Modelos de tarea">
    Abre **Ajustes → Modelo de IA** y haz clic en **Modelos de tarea** en la parte superior de la página.
  </Step>
  <Step title="Elegir una tarea">
    Haz clic en una tarea. **Automático** muestra qué modelo elige para cada proveedor.
  </Step>
  <Step title="Elegir un modelo">
    Haz clic en **Elige un modelo**, elige un proveedor y luego un modelo.
  </Step>
</Steps>

Desactiva el interruptor junto a **Sugerencias del siguiente mensaje** para dejar de sugerir tu siguiente mensaje después de cada respuesta. **Restablecer todo a Automático** devuelve cada tarea a **Automático**.

## Mantener los chats con modelos de respaldo

El Respaldo mantiene una respuesta en marcha cuando su modelo no se puede usar, por ejemplo cuando llega a un límite de uso, pierde el inicio de sesión o la clave, o no se puede alcanzar. La respuesta continúa en tu siguiente modelo de respaldo, y el chat dice qué modelo tomó el relevo y por qué.

<Steps>
  <Step title="Abrir Respaldo">
    Abre **Ajustes → Modelo de IA** y haz clic en **Respaldo** en la parte superior de la página.
  </Step>
  <Step title="Añadir respaldos">
    Haz clic en **Añadir modelo de respaldo** y elige un modelo. Puedes añadir hasta tres y arrastrarlos para cambiar el orden.
  </Step>
  <Step title="Definir el esfuerzo de cada respaldo">
    Para un modelo con niveles de razonamiento, elige su **Esfuerzo de razonamiento**. Cada respaldo conserva el suyo.
  </Step>
</Steps>

El panel muestra la cadena tal como funciona: primero **El modelo en uso**, luego tus respaldos numerados, cada uno marcado como **Listo** o **En pausa**. Haz clic en el nombre del modelo de un respaldo para cambiarlo a otro modelo de ese proveedor. En la lista de proveedores, cada proveedor que tiene un respaldo muestra una etiqueta **respaldo N** con su lugar en la cadena.

| Ajuste | Qué hace |
| --- | --- |
| **Cambiar también cuando el servicio esté saturado** | También cambia ante límites de tasa y errores del servidor, cuando se agotan los reintentos. |
| **Volver cuando el modelo funcione de nuevo** | Devuelve el chat a su propio modelo desde el siguiente turno, una vez que ese modelo funciona, nunca a mitad de un turno. |

Una petición rechazada por una política de seguridad nunca cambia de modelo.

## Comparar dos modelos

Envía la misma tarea pequeña y real a ambos. Comprueba que la respuesta es correcta, que las herramientas terminaron, cuánto tardó y cuánto costó. **Detalles** bajo cada respuesta muestra el modelo, el esfuerzo, los tokens, el tiempo y los puntos o el coste.

---
title: "Obtener contenido web"
description: "Haz que tu Agente lea una página web desde su URL, o conserva la página en una base de conocimientos."
---

Usa Obtener contenido web cuando ya tienes una URL y quieres que el Agente lea la página. Todos los Agentes pueden leer un enlace que les das; tú eliges el servicio que la obtiene. Usa la [Búsqueda web](/es/ai/web-search) cuando primero necesitas encontrar páginas relevantes.

## Elegir un proveedor

1. Abre **Ajustes → Obtener contenido web**.
2. Elige un proveedor y haz clic en **Establecer como predeterminado**.

| Proveedor | Uso |
| --- | --- |
| **Local Fetch** | Obtiene páginas en tu Mac gratis, con obtención asistida por el navegador de forma opcional |
| **Jina AI Link Reader** | Recupera contenido legible a través de Jina |
| **Firecrawl Link Reader** | Recupera contenido a través de Firecrawl |
| **DeepSeek** | Lee páginas como Markdown con tu clave de API de DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Lee páginas como Markdown a través de Enconvo Cloud, sin clave de API |
| **Enconvo Cloud Plan** | Usa el servicio de lectura de enlaces de Cloud |

## Leer una página

1. Pega la URL en la conversación y haz una pregunta concreta sobre ella.
2. Revisa el contenido recuperado y la fuente antes de fiarte de la respuesta.

## Páginas tras un inicio de sesión

Con **Local Fetch**, **Obtención asistida por el navegador** puede leer una página a través de un navegador de la familia Chromium que tenga la extensión Enconvo Companion.

| Opción | Qué hace |
| --- | --- |
| **Automático** (predeterminado) | Reutiliza una pestaña coincidente que ya tengas abierta, renderizada por completo y con tu sesión. Usa una pestaña temporal en segundo plano cuando una obtención directa falla o la página necesita JavaScript. |
| **Desactivado** | Solo HTTP directo |
| **Siempre** | Siempre obtiene a través del navegador |

Sin un navegador conectado, Local Fetch hace una petición HTTP directa. Los demás proveedores obtienen la URL pública y no tienen tu sesión iniciada en el navegador. Para páginas interactivas, usa la [Extensión del navegador](/es/features/browser-extension) o el [Uso del navegador](/es/features/browser-control).

## Conservar contenido web

Añade una URL con **Añadir → Una sola página web** en una [Base de conocimientos](/es/ai/knowledge-base) cuando quieras encontrarla más tarde. Revisa la página importada y su estado de indexación; las páginas web pueden cambiar después de importarlas.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El contenido vuelve vacío | Comprueba que la página se puede leer sin interacción extra, o usa **Local Fetch** con **Obtención asistida por el navegador**. Las pantallas de inicio de sesión, las peticiones bloqueadas, el contenido cargado de forma dinámica y los sitios no compatibles pueden impedir la extracción. |
| La respuesta describe cosas que no están en la página | Pide al Agente que muestre lo que realmente recuperó, en lugar de adivinar el contenido que falta. |

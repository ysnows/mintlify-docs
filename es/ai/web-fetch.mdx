---
title: "Obtener contenido web"
description: "Haz que tu Agente lea una página web a partir de su URL, o guarda la página en una base de conocimientos."
---

Usa Obtener contenido web cuando ya tengas una URL y quieras que el Agente lea la página. Todos los Agentes pueden leer un enlace que les des; tú eliges el servicio que lo obtiene. Usa la [Búsqueda web](/es/ai/web-search) cuando primero necesites encontrar páginas relevantes.

## Elegir un proveedor

1. Abre **Ajustes → Obtener contenido web**.
2. Elige un proveedor y haz clic en **Establecer como predeterminado**.

| Proveedor | Uso |
| --- | --- |
| **Local Fetch** | Obtén páginas en tu Mac gratis, con obtención asistida por el navegador opcional |
| **Jina AI Link Reader** | Recupera contenido legible a través de Jina |
| **Firecrawl Link Reader** | Recupera contenido a través de Firecrawl |
| **DeepSeek** | Lee páginas como Markdown con tu clave de API de DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Lee páginas como Markdown a través de Enconvo Cloud, sin clave de API |
| **Plan de Enconvo Cloud** | Usa el servicio de lectura de enlaces de Cloud |

## Leer una página

1. Pega la URL en tu conversación y haz una pregunta concreta sobre ella.
2. Comprueba el contenido recuperado y la fuente antes de fiarte de la respuesta.

## Páginas tras un inicio de sesión

Con **Local Fetch**, **Browser-Assisted Fetching** puede leer una página a través de un navegador de la familia Chromium que tenga la extensión Enconvo Companion.

| Opción | Qué hace |
| --- | --- |
| **Automático** (predeterminado) | Reutiliza una pestaña coincidente que ya tengas abierta, totalmente renderizada y con tu sesión iniciada. Usa una pestaña temporal en segundo plano cuando falla una obtención directa o la página necesita JavaScript. |
| **Desactivado** | Solo HTTP directo |
| **Siempre** | Obtiene siempre a través del navegador |

Sin un navegador conectado, Local Fetch hace una solicitud HTTP directa. Los demás proveedores obtienen la URL pública y no tienen la sesión iniciada de tu navegador. Para páginas interactivas, usa la [Extensión del navegador](/es/features/browser-extension) o el [Uso del navegador](/es/features/browser-control).

## Conservar contenido web

Añade una URL con **Añadir → Una sola página web** en una [base de conocimientos](/es/ai/knowledge-base) cuando quieras encontrarla más adelante. Comprueba la página importada y su estado de indexación; las páginas web pueden cambiar después de importarlas.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El contenido llega vacío | Comprueba que la página se pueda leer sin interacción adicional, o usa **Local Fetch** con **Browser-Assisted Fetching**. Las pantallas de inicio de sesión, las solicitudes bloqueadas, el contenido que se carga dinámicamente y los sitios no compatibles pueden impedir la extracción. |
| La respuesta describe cosas que no están en la página | Pide al Agente que muestre lo que recuperó realmente, en lugar de suponer el contenido que falta. |

Pide a un Agente en el chat que haga una imagen, o que cambie una imagen que adjuntes. Enconvo envía la solicitud al proveedor de imágenes que definas en **Ajustes → Generación de imágenes**, que es independiente del modelo con el que chateas.

## Antes de empezar

1. Abre **Ajustes → Generación de imágenes** y elige un proveedor.
2. Define su **Proveedor de credenciales** (la clave o la cuenta que usa) y su **Nombre del modelo**.
3. Haz clic en **Establecer como predeterminado**.

Los proveedores de Enconvo Cloud, **OpenAI (Enconvo Cloud)** y **Google Gemini (Enconvo Cloud)**, no necesitan una clave de API propia.

## Crear una imagen

1. En un chat con un Agente, describe el tema, la composición, el estilo y para qué es la imagen.
2. Pide un tamaño, una proporción o una calidad solo cuando el modelo lo admita.
3. Espera a la imagen. La generación puede tardar más que una respuesta de texto.
4. Haz clic en la imagen para abrirla junto al chat, donde puedes seguir editándola.

Ejemplo:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

También puedes elegir **Imagen** bajo el cuadro de mensaje de un chat nuevo. El modelo, sus ajustes y **Evitar** aparecen como etiquetas bajo el cuadro de mensaje, así que los defines antes de enviar. Para una biblioteca con todo lo que hiciste, temas guardados y correcciones de un clic, usa [Multimedia](/es/features/media).

## Editar una imagen

1. Adjunta la imagen de origen a tu mensaje, o haz clic en una imagen que hizo un Agente para abrirla en el editor de imágenes.
2. Describe los cambios concretos y di qué debe quedar igual.
3. Comprueba que el resultado no tenga cambios que no pediste.

Usa un modelo que admita la edición de imágenes o las imágenes de referencia.

En el editor de imágenes, el panel de ajustes muestra solo lo que admite el modelo elegido:

| Ajuste | Qué cambia |
| --- | --- |
| Resolución, proporción y calidad | El tamaño y el detalle de la siguiente versión |
| **Evitar** | Lo que se debe dejar fuera, en los modelos que admiten un prompt negativo |
| Variaciones | Cuántas versiones hace cada solicitud; te quedas con las que quieras |
| **Zona de edición** y **Marcas** | Pinta sobre la imagen para cambiar solo esa parte, o dibuja para guiar el cambio |
| GIF y **Fotogramas** | Una imagen animada hecha a partir de tus palabras |

Cada edición es una versión nueva, y cada imagen se conserva en [Multimedia](/es/features/media) y en `~/Enconvo/Media`. Para animar una imagen, haz clic en **Crear vídeo**.

### GPT Image 2.6

GPT Image 2.6 Flare y Sunburst están disponibles a través de OpenAI, Enconvo Cloud, PipeLLM y OpenRouter. Añaden un ajuste de complejidad (baja, media o alta), ediciones guiadas por marcas que dibujas y salida en SVG o GIF animado. SVG y GIF crean una imagen nueva a partir de tus palabras; no editan la actual.

## Proveedores

El [catálogo de proveedores de imágenes](/es/providers/catalog) incluye OpenAI, Gemini, xAI, OpenRouter, PipeLLM, Pollinations, Kie.ai, Topview, Azure, Together y sus versiones de Enconvo Cloud donde se ofrecen. El proveedor OpenAI también funciona con tu inicio de sesión de ChatGPT como credencial. Lo que puede hacer un proveedor depende del modelo: el nombre de un proveedor por sí solo no garantiza todos los modos de edición.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La imagen no se genera | Comprueba el acceso y el modelo del proveedor, y luego lee el error del proveedor |
| Una edición ignora tu imagen | Comprueba que el modelo acepte imágenes de entrada y que el archivo esté adjunto al mensaje |
| Se rechaza el archivo de entrada | Comprueba que el proveedor admita el formato del archivo |
| GPT Image 2.6 no se ofrece con tu inicio de sesión de ChatGPT | OpenAI no lo ofrece en los planes de ChatGPT; usa una clave de API de OpenAI o Enconvo Cloud |
| Un ajuste que quieres no está en el editor | El modelo elegido no lo admite; elige otro modelo |

Pide a un Agente en el chat que haga una imagen, o que cambie una imagen que adjuntes. Enconvo envía la petición al proveedor de imágenes que definas en **Ajustes → Generación de imágenes**, que es independiente del modelo con el que chateas.

## Antes de empezar

1. Abre **Ajustes → Generación de imágenes** y elige un proveedor.
2. Define su **Proveedor de credenciales** (la clave o cuenta que usa) y su **Nombre del modelo**.
3. Pulsa **Establecer como predeterminado**.

Los proveedores de Enconvo Cloud, **OpenAI (Enconvo Cloud)** y **Google Gemini (Enconvo Cloud)**, no necesitan una clave de API propia.

## Crear una imagen

1. En un chat con un Agente, describe el tema, la composición, el estilo y para qué es la imagen.
2. Pide un tamaño, una relación de aspecto o una calidad solo cuando el modelo lo admita.
3. Espera la imagen. Generarla puede tardar más que una respuesta de texto.
4. Pulsa la imagen para abrirla junto al chat, donde puedes seguir editándola.

Ejemplo:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

También puedes elegir **Imagen** bajo el cuadro de mensaje de un chat nuevo. El modelo, sus ajustes y **Evitar** aparecen como pastillas bajo el cuadro de mensaje, así los defines antes de enviar. Para una biblioteca de todo lo que has creado, temas guardados y correcciones de un clic, usa [Medios](/es/features/media).

## Editar una imagen

1. Adjunta la imagen de origen a tu mensaje, o pulsa una imagen que haya hecho un Agente para abrirla en el editor de imágenes.
2. Describe los cambios concretos y di qué debe quedarse igual.
3. Revisa el resultado por si hay cambios que no pediste.

Usa un modelo que admita edición de imágenes o imágenes de referencia.

En el editor de imágenes, el panel de ajustes muestra solo lo que acepta el modelo elegido:

| Ajuste | Qué cambia |
| --- | --- |
| Resolución, relación de aspecto y calidad | El tamaño y el detalle de la siguiente versión |
| **Evitar** | Qué dejar fuera, en modelos que aceptan un prompt negativo |
| Variaciones | Cuántas tomas hace cada petición; te quedas con las que quieras |
| **Zona de edición** y **Marcas** | Pinta sobre la imagen para cambiar solo esa parte, o dibuja para guiar el cambio |
| GIF y **Fotogramas** | Una imagen animada hecha a partir de tus palabras |

Cada edición es una versión nueva, y cada imagen se guarda en [Medios](/es/features/media) y en `~/Enconvo/Media`. Para animar una imagen, pulsa **Crear vídeo**.

### GPT Image 2.6

GPT Image 2.6 Flare y Sunburst están disponibles a través de OpenAI, Enconvo Cloud, PipeLLM y OpenRouter. Añaden un ajuste de complejidad (bajo, medio o alto), ediciones guiadas por las marcas que dibujas, y salida en SVG o GIF animado. SVG y GIF crean una imagen nueva a partir de tus palabras; no editan la actual.

## Proveedores

El [catálogo de proveedores de imágenes](/es/providers/catalog) incluye OpenAI, Gemini, xAI, OpenRouter, PipeLLM, Pollinations, Kie.ai, Topview, Azure, Together y sus versiones de Enconvo Cloud cuando se ofrecen. El proveedor de OpenAI también funciona con tu inicio de sesión de ChatGPT como credencial. Lo que puede hacer un proveedor depende del modelo: el nombre del proveedor por sí solo no promete todos los modos de edición.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La imagen no se genera | Comprueba el acceso y el modelo del proveedor, y lee el error del proveedor |
| Una edición ignora tu imagen | Comprueba que el modelo acepte entrada de imagen y que el archivo esté adjunto al mensaje |
| Se rechaza el archivo de entrada | Comprueba que el proveedor admita el formato del archivo |
| GPT Image 2.6 no se ofrece con tu inicio de sesión de ChatGPT | OpenAI no lo sirve a los planes de ChatGPT; usa una clave de API de OpenAI o Enconvo Cloud |
| Un ajuste que quieres no está en el editor | El modelo elegido no lo acepta; elige otro modelo |

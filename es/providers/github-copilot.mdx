title: "GitHub Copilot"
description: "Inicia sesión con una cuenta de GitHub que tenga un plan de Copilot y chatea con los modelos de tu plan."
---

Usa tu plan de GitHub Copilot como proveedor de Modelo de IA en Enconvo. Inicias sesión con la cuenta de GitHub que tiene el plan; no interviene ninguna clave de API. Los modelos premium cuentan para las solicitudes premium de tu plan.

## Conectar

<Steps>
  <Step title="Abre el proveedor">
    Abre **Ajustes → Modelo de IA → GitHub Copilot**.
  </Step>
  <Step title="Inicia el inicio de sesión">
    En **Autenticación**, haz clic en **Conectar**.
  </Step>
  <Step title="Introduce el código en GitHub">
    Tu navegador abre la página de dispositivos de GitHub, y Enconvo muestra el código que debes introducir allí. Introduce el código y autoriza el inicio de sesión.
  </Step>
  <Step title="Comprueba la cuenta">
    Vuelve a Enconvo y comprueba que está conectada la cuenta de GitHub que querías.
  </Step>
  <Step title="Elige un modelo">
    Selecciona un modelo y prueba con una solicitud corta.
  </Step>
</Steps>

Cerrar el cuadro de diálogo del código de Enconvo antes de autorizar cancela el inicio de sesión.

## Modelos y opciones

La lista de modelos muestra solo los modelos que puede usar tu plan de Copilot, con el modelo de chat predeterminado del propio Copilot primero. Copilot Free ofrece menos modelos que los planes de pago, así que puede que un modelo que viste en otro lugar no aparezca. Cada modelo usa los niveles de esfuerzo de razonamiento que Copilot ofrece para él.

## En el iPhone

La app de iPhone también puede iniciar sesión en GitHub Copilot, para los Chats del teléfono en el teléfono. Consulta [Chats del teléfono](/es/integrations/iphone-phone-chats).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El inicio de sesión no termina | Introduce el código en la página de GitHub antes de que caduque y luego haz clic en **Conectar** de nuevo para obtener un código nuevo. |
| El modelo que quieres no aparece | Tu plan de Copilot no lo incluye; elige otro modelo o mejora el plan. |
| Una solicitud falla con un error de modelo | Elige un modelo de la lista actual; es posible que un predeterminado elegido antes de que cambiara tu plan ya no se ofrezca. |
| Límite de velocidad o de uso | Las solicitudes premium de tu plan y los límites de velocidad de GitHub. |

Usa tu plan de GitHub Copilot como proveedor de Modelo de IA en Enconvo. Inicias sesión con la cuenta de GitHub que tiene el plan; no hay clave de API. Los modelos premium cuentan para las solicitudes premium de tu plan.

## Conectar

<Steps>
  <Step title="Abrir el proveedor">
    Abre **Ajustes → Modelo de IA → GitHub Copilot**.
  </Step>
  <Step title="Empezar el inicio de sesión">
    En **Autenticación**, pulsa **Conectar**.
  </Step>
  <Step title="Introducir el código en GitHub">
    El navegador abre la página de dispositivo de GitHub, y Enconvo muestra el código que hay que introducir allí. Introduce el código y autoriza el inicio de sesión.
  </Step>
  <Step title="Comprobar la cuenta">
    Vuelve a Enconvo y comprueba que esté conectada la cuenta de GitHub prevista.
  </Step>
  <Step title="Elegir un modelo">
    Selecciona un modelo y prueba una petición corta.
  </Step>
</Steps>

Cerrar el diálogo del código de Enconvo antes de autorizar cancela el inicio de sesión.

## Modelos y opciones

La lista de modelos muestra solo los modelos que puede usar tu plan de Copilot, con el valor predeterminado de chat de Copilot primero. Copilot Free ofrece menos modelos que los planes de pago, así que un modelo que viste en otro sitio puede no estar en la lista. Cada modelo usa los niveles de esfuerzo de razonamiento que Copilot ofrece para él.

## En el iPhone

La app de iPhone también puede iniciar sesión en GitHub Copilot, para los chats del teléfono. Consulta [Chats del teléfono](/es/integrations/iphone-phone-chats).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| El inicio de sesión no termina | Introduce el código en la página de GitHub antes de que caduque y pulsa **Conectar** otra vez para obtener un código nuevo. |
| El modelo que quieres no está en la lista | Tu plan de Copilot no lo incluye; elige otro modelo o mejora el plan. |
| Una petición falla con un error de modelo | Elige un modelo de la lista actual; un valor predeterminado elegido antes de que cambiara tu plan puede ya no ofrecerse. |
| Límite de ritmo o de uso | Las solicitudes premium de tu plan y los límites de ritmo de GitHub. |

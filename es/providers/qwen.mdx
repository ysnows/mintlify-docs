Usa los modelos Qwen de Alibaba en chats, Agentes y Comandos de IA. Conéctate con una clave de API de Alibaba Cloud Model Studio; Alibaba Cloud factura el uso a tu cuenta. Para el servicio de China continental (Bailian), usa [DashScope](/es/providers/dashscope).

## Conectar

<Steps>
  <Step title="Consigue una clave de API">
    Crea una clave en [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Añádela a Enconvo">
    Abre **Ajustes → Modelo de IA → Qwen**. En **Autenticación**, pega la clave en **Clave de API** y haz clic en **Validar**.
  </Step>
  <Step title="Elige un modelo">
    Elige un modelo en **Nombre del modelo** y envía un mensaje corto. Una respuesta significa que la conexión funciona.
  </Step>
</Steps>

Qwen se conecta solo con una clave de API.

## Modelos y opciones

| Ajuste | Qué hace |
| --- | --- |
| **Nombre del modelo** | El modelo que usa este proveedor. **Actualizar**, junto a él, recarga la lista; **Gestionar modelos** (el engranaje) añade o restaura modelos. |
| **Base Url** | En la credencial. El valor predeterminado es el endpoint internacional, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Cámbialo si tu clave pertenece a otra región. |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| **Validar** falla | Comprueba que la clave y **Base Url** pertenecen a la misma región, y pega de nuevo la clave completa. |
| Falta un modelo | Haz clic en **Actualizar** junto a **Nombre del modelo**. Para añadir un modelo tú, usa **Gestionar modelos**. |
| Errores de límite de uso | Revisa el uso y la cuota en Model Studio, o cambia a otro proveedor de momento. |

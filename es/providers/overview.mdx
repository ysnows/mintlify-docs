Un proveedor es el servicio detrás de una función de Enconvo: el modelo que responde un chat, la voz que lee en alto, el motor que busca en la web. Eliges uno para cada función, y puedes combinarlos.

El vídeo de abajo recorre **Ajustes → Modelo de IA** en 2 minutos: Auto Route, el plan Cloud, el inicio de sesión con un plan de ChatGPT, Claude, GitHub Copilot, Antigravity o Grok, las claves de API, los modelos en tu Mac, Ollama y LM Studio, y añadir un proveedor propio.

## Elige tu modelo de chat

<Steps>
  <Step title="Abre Modelo de IA">
    Abre **Ajustes → Modelo de IA**. La columna central lista todos los proveedores: **Auto Route** y **Enconvo Cloud Plan** arriba, y luego las empresas, los modelos locales y el resto de proveedores.
  </Step>
  <Step title="Elige un proveedor y conéctalo">
    Haz clic en un proveedor. Donde ofrezca ambas opciones, elige **Clave de API** para pagar al proveedor por solicitud con tu propia clave, o la opción de suscripción (por ejemplo **Suscripción de ChatGPT**) para iniciar sesión y usar lo que incluye tu plan.
  </Step>
  <Step title="Elige el modelo">
    Elige un modelo en **Nombre del modelo**, y un **Reasoning Effort** donde el proveedor lo tenga.
  </Step>
  <Step title="Hazlo el predeterminado">
    Haz clic en **Establecer como predeterminado**. Los chats y las funciones que no nombran un modelo propio lo usan ahora.
  </Step>
</Steps>

Para añadir un servicio que no está en la lista, haz clic en **Añadir nuevo proveedor** al final de la lista y elige **Compatible con OpenAI** o **Compatible con Anthropic**.

Puedes cambiar de proveedor cuando quieras; nada ata tus chats a una empresa.

La parte superior de **Ajustes → Modelo de IA** también tiene **Modelos de tarea**, para los modelos pequeños detrás de los títulos y las sugerencias del chat, y **Respaldo**, para modelos de reserva que toman el relevo cuando no se puede usar el modelo de un chat. Consulta [Elegir un modelo](/es/ai/model-selection-guide).

## Configura un proveedor para cada función

Cada función tiene su propia página de Ajustes: **Modelo de IA**, **Texto a voz**, **Búsqueda web**, **Generación de imágenes**, **Generación de vídeo**, **Web Fetch** y **OCR**. El reconocimiento de voz tiene páginas aparte para **Dictation Models**, **Recording Models**, **Transcription Models** y **Captioning Model**. Los embeddings y el reranking se configuran en la Base de conocimientos.

Elegir un modelo de chat no cambia el proveedor de voz, imagen o búsqueda. Configura cada uno donde quieras.

## Perfiles

Un perfil de proveedor guarda una clave o un inicio de sesión. Haz clic en **Añadir nuevo proveedor** en la página de un proveedor para guardar un segundo, por ejemplo una cuenta de trabajo. Algunos perfiles sirven a varias funciones: un perfil de OpenAI cubre el chat, los embeddings, el texto a voz, las imágenes y la transcripción, así que cambiar su clave las cambia todas. Consulta [Credenciales y perfiles](/es/configuration/credentials).

Dónde se configura el modelo predeterminado, y cómo cada chat conserva el suyo, está en [Elegir un modelo](/es/ai/model-selection-guide).

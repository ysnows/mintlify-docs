Usa los modelos GPT de OpenAI en chats, Agentes y Comandos de IA. Conéctate con una clave de API de OpenAI, que OpenAI factura por petición, o inicia sesión con tu plan de ChatGPT y usa su margen.

## Conectar

<Steps>
  <Step title="Obtener una clave de API">
    Crea una clave en la [plataforma de OpenAI](https://platform.openai.com/api-keys).
  </Step>
  <Step title="Añadirla a Enconvo">
    Abre **Ajustes → Modelo de IA → OpenAI**. En **Autenticación**, elige **Clave de API**, pega la clave y pulsa **Validar**.
  </Step>
  <Step title="Elegir un modelo">
    Elige un modelo en **Nombre del modelo** y envía un mensaje corto. Una respuesta significa que la conexión funciona.
  </Step>
</Steps>

<Tip>
¿Tienes un plan de ChatGPT? Elige **ChatGPT Subscription** en **Autenticación** y pulsa **Conectar**. Consulta [Suscripción de ChatGPT](/es/providers/openai_subscription).
</Tip>

Para guardar una segunda clave de OpenAI, por ejemplo una de trabajo, pulsa **Añadir nuevo proveedor** y crea otro perfil.

## Modelos y opciones

| Ajuste | Qué hace |
| --- | --- |
| **Nombre del modelo** | El modelo que usa este proveedor. **Actualizar** junto a él recarga la lista; **Gestionar modelos** (el engranaje) añade o restaura modelos. |
| **API Type** | En la credencial. **Responses API** (el predeterminado) o **Completions API**. Deja Responses salvo que un servicio compatible necesite Completions. |
| **URL base de la API** | En la credencial. El valor por defecto es `https://api.openai.com/v1`. Cámbialo solo para usar un servicio compatible con OpenAI. |

El mismo perfil de OpenAI también sirve embeddings, texto a voz, generación de imágenes y transcripción de OpenAI, así que cambiar su clave afecta también a esas funciones. Para usar otro modelo en un chat, elígelo en el selector de modelos de ese chat.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| **Validar** falla | Vuelve a pegar la clave entera y comprueba que esté activa y tenga facturación configurada en la plataforma de OpenAI. |
| Falta un modelo | Pulsa **Actualizar** junto a **Nombre del modelo**. Para añadir un modelo tú mismo, usa **Gestionar modelos**. |
| Falla un servicio compatible | Revisa **URL base de la API** y luego prueba **Completions API** como **API Type**. |
| Errores de límite de ritmo o de uso | Revisa el uso y los límites en la plataforma de OpenAI, o cambia a otro proveedor por ahora. |

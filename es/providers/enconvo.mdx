Enconvo Cloud te da modelos de varias empresas, además de herramientas de voz, imagen, vídeo y web, a través de tu cuenta de Enconvo. No hay claves de API que gestionar: las solicitudes usan los puntos de tu plan. Es la forma más rápida de empezar.

## Configuración

<Steps>
  <Step title="Inicia sesión">
    Inicia sesión en tu cuenta de Enconvo. Consulta [Cuenta](/es/configuration/account).
  </Step>
  <Step title="Elige Enconvo Cloud">
    Abre la página de Ajustes de lo que quieres hacer, como **Modelo de IA**, **Texto a voz** o **Generación de imágenes**, y elige el proveedor llamado **Enconvo Cloud** o **Enconvo Cloud Plan**.
  </Step>
  <Step title="Elige un modelo o una voz">
    Elige un modelo o una voz y ejecuta una solicitud corta.
  </Step>
</Steps>

Cada función tiene su propia elección de proveedor. Elegir Enconvo Cloud para el chat no cambia la voz, las imágenes, el vídeo, los embeddings, la reordenación ni las herramientas web; configura cada uno donde quieras.

## Los modelos propios de Enconvo

Enconvo Cloud tiene tres modelos propios, con nombres que indican el trabajo para el que sirven:

| Modelo | Úsalo para |
| --- | --- |
| **Enconvo Fast** | Turnos rápidos: respuestas cortas, reescrituras, acciones pequeñas. Es el modelo con el que empieza **Enconvo Cloud Plan**, y el predeterminado de los Comandos de IA. |
| **Enconvo Balanced** | Trabajo cotidiano con unos pocos pasos. |
| **Enconvo Ultra** | Tareas difíciles que necesitan un razonamiento profundo. |

Aparecen los primeros en **Enconvo Cloud Plan**, y [Auto Route](/es/providers/auto-route) los usa para sus rutas predeterminadas.

## Encuentra un modelo en el selector

La lista de **Enconvo Cloud Plan** agrupa los modelos por proveedor: primero los modelos propios de Enconvo, luego Anthropic, OpenAI, Google y el resto, cada uno con un recuento. Un proveedor muestra sus cuatro modelos más recientes; haz clic en **Show N earlier models** para ver los demás. La búsqueda enumera todas las coincidencias, y el modelo que usa tu chat siempre se muestra. Los modelos Claude aparecen sin el prefijo "Claude", como **Sonnet 5.5** y **Opus 5.5**.

En el selector de modelos de la Ventana de chat, un modelo de Cloud puede llevar una etiqueta:

| Etiqueta | Significado |
| --- | --- |
| **Nuevo** | Añadido en los últimos 14 días. |
| Un descuento, como **50% OFF** | El modelo cuesta menos por ahora. Apunta a la fila, o llega a ella con las teclas de flecha, para ver el precio habitual. |
| **Gratuito** | El modelo no usa puntos. |
| **Vista previa** | Una versión temprana del modelo. |
| Una fecha | El día en que el modelo deja Enconvo Cloud. |

Enconvo Cloud establece las etiquetas, así que cambian sin necesidad de actualizar la app.

## Puntos y uso

Los modelos cuestan distinto número de puntos. Ajustes muestra el precio de Cloud junto a cada modelo y proveedor, junto con lo que incluye tu plan, como los minutos gratuitos que te quedan este mes. Consulta las páginas del [Plan de Cloud](https://www.enconvo.com/cloud-plan) y de los [Precios de Cloud](https://www.enconvo.com/cloud-pricing) para ver los planes y las tarifas actuales. Para ver lo que has usado, abre **Ajustes → Consumo de puntos**.

[Auto Route](/es/providers/auto-route), el modelo predeterminado, se ejecuta con modelos de Enconvo Cloud. Elegir la ruta para cada mensaje es gratis; el modelo que responde usa puntos.

Algunos servicios de Cloud son gratuitos para todas las cuentas que han iniciado sesión:

- La búsqueda web con **Enconvo Cloud** y **DeepSeek (Enconvo Cloud)**. Consulta [Búsqueda web](/es/ai/web-search).
- El reconocimiento de voz con **Enconvo Cloud Fast**. Consulta [Reconocimiento de voz](/es/ai/speech-recognition).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Las solicitudes te piden iniciar sesión | Inicia sesión en **Ajustes → Cuenta**. |
| Las solicitudes fallan con un error de puntos o de saldo | Comprueba **Ajustes → Consumo de puntos** y luego tu plan en la página del [Plan de Cloud](https://www.enconvo.com/cloud-plan). |
| Falta un modelo | El selector muestra lo que incluye tu plan. Haz clic en **Actualizar** junto a **Nombre del modelo**. |

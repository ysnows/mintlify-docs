Enconvo Cloud te da modelos de varias empresas, más herramientas de voz, imagen, vídeo y web, a través de tu cuenta de Enconvo. No hay claves de API que gestionar: las peticiones usan los puntos de tu plan. Es la forma más rápida de empezar.

## Configurar

<Steps>
  <Step title="Iniciar sesión">
    Inicia sesión en tu cuenta de Enconvo. Consulta [Cuenta](/es/configuration/account).
  </Step>
  <Step title="Elegir Enconvo Cloud">
    Abre la página de Ajustes de lo que quieras hacer, como **Modelo de IA**, **Texto a voz** o **Generación de imágenes**, y elige el proveedor etiquetado **Enconvo Cloud** o **Enconvo Cloud Plan**.
  </Step>
  <Step title="Elegir un modelo o una voz">
    Elige un modelo o una voz y ejecuta una petición corta.
  </Step>
</Steps>

Cada función tiene su propia elección de proveedor. Elegir Enconvo Cloud para el chat no cambia la voz, las imágenes, el vídeo, los embeddings, el reranking ni las herramientas web; configura cada una donde quieras.

## Los modelos propios de Enconvo

Enconvo Cloud tiene tres modelos propios, nombrados según el trabajo al que se ajustan:

| Modelo | Úsalo para |
| --- | --- |
| **Enconvo Fast** | Turnos rápidos: respuestas cortas, reescrituras, acciones pequeñas. Es el modelo con el que empieza **Enconvo Cloud Plan**, y el predeterminado de los Comandos de IA. |
| **Enconvo Balanced** | El trabajo de cada día con unos pocos pasos. |
| **Enconvo Ultra** | Tareas difíciles que necesitan un razonamiento profundo. |

Aparecen primero en **Enconvo Cloud Plan**, y [Auto Route](/es/providers/auto-route) los usa en sus rutas predeterminadas.

## Encontrar un modelo en el selector

La lista de **Enconvo Cloud Plan** agrupa los modelos por proveedor: primero los propios de Enconvo, luego Anthropic, OpenAI, Google y el resto, cada uno con un recuento. Un proveedor muestra sus cuatro modelos más nuevos; pulsa **Show N earlier models** para ver los demás. La búsqueda lista todas las coincidencias, y el modelo que usa tu chat siempre se muestra. Los modelos de Claude se listan sin el prefijo «Claude», como **Sonnet 5.5** y **Opus 5.5**.

En el selector de modelos de la Ventana de chat, un modelo de Cloud puede llevar una etiqueta:

| Etiqueta | Significado |
| --- | --- |
| **Nuevo** | Añadido en los últimos 14 días. |
| Un descuento, como **50% OFF** | El modelo cuesta menos por ahora. Señala la fila, o llega a ella con las flechas, para ver el precio normal. |
| **Gratuito** | El modelo no usa puntos. |
| **Preview** | Una versión temprana del modelo. |
| Una fecha | El día en que el modelo sale de Enconvo Cloud. |

Enconvo Cloud define las etiquetas, así que cambian sin una actualización de la app.

## Puntos y uso

Los modelos cuestan distintas cantidades de puntos. Ajustes muestra el precio de Cloud junto a cada modelo y proveedor, junto con lo que incluye tu plan, como los minutos gratuitos que te quedan este mes. Consulta las páginas de [Cloud Plan](https://www.enconvo.com/cloud-plan) y [precios de Cloud](https://www.enconvo.com/cloud-pricing) para los planes y tarifas actuales. Para ver lo que has usado, abre **Ajustes → Consumo de puntos**.

[Auto Route](/es/providers/auto-route), el modelo predeterminado, se ejecuta en modelos de Enconvo Cloud. Elegir la ruta de cada mensaje es gratuito; el modelo que responde usa puntos.

Algunos servicios de Cloud son gratuitos para toda cuenta con sesión iniciada:

- Búsqueda web con **Enconvo Cloud** y **DeepSeek (Enconvo Cloud)**. Consulta [Búsqueda web](/es/ai/web-search).
- Reconocimiento de voz con **Enconvo Cloud Fast**. Consulta [Reconocimiento de voz](/es/ai/speech-recognition).

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Las peticiones te piden iniciar sesión | Inicia sesión en **Ajustes → Cuenta**. |
| Las peticiones fallan con un error de puntos o de saldo | Revisa **Ajustes → Consumo de puntos** y luego tu plan en la página de [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Falta un modelo | El selector muestra lo que incluye tu plan. Pulsa **Actualizar** junto a **Nombre del modelo**. |

Cada proveedor que uses necesita una credencial: una clave de API, o un inicio de sesión en un plan que ya pagas. La añades en la propia página de Ajustes del proveedor, y Enconvo la guarda en un perfil de proveedor que comparten todas las funciones que usan ese proveedor. **Ajustes → Gestión de credenciales** muestra todas tus credenciales en un solo lugar.

## Añadir un proveedor

<Steps>
  <Step title="Abrir una categoría">
    Abre la página de Ajustes de lo que quieras usar, como **Ajustes → Modelo de IA**, **Ajustes → Generación de imágenes** o **Ajustes → Texto a voz**.
  </Step>
  <Step title="Elegir el proveedor">
    Selecciona un proveedor. Para configurar una segunda copia, con otra clave o cuenta, elige **Añadir nuevo proveedor**.
  </Step>
  <Step title="Elegir cómo iniciar sesión">
    En **Autenticación**, elige **Clave de API**, o **Suscripción** cuando el proveedor te deje usar un plan que pagas.
  </Step>
  <Step title="Añadir la credencial">
    Pega tu clave de API, o termina el inicio de sesión del proveedor.
  </Step>
  <Step title="Probarla">
    Pulsa **Validar** si la página lo muestra, elige un modelo y prueba una petición corta.
  </Step>
</Steps>

Una clave de API factura la cuenta de API del proveedor. Una suscripción usa el uso incluido de tu plan y sus límites. El texto bajo **Autenticación** indica cuál usa la página.

## Perfiles compartidos

Un perfil de proveedor, como **OpenAI 2**, guarda la clave de API del proveedor y su inicio de sesión de suscripción, y aparece en todas las categorías que el proveedor admite. Renombrar o eliminar el perfil lo cambia en todas esas categorías, no solo en la página en la que estás.

Cada categoría conserva sus propios ajustes de modelo, voz y generación. Una clave de API nueva, en cambio, llega a todas las funciones que usan el perfil, así que pruébalas después de cambiarla.

Lo que ofrece un proveedor varía según la categoría. Un inicio de sesión que funciona para el chat de IA no significa que la API de voz en tiempo real del proveedor esté incluida. Cuando una categoría solo acepta una clave de API, su página lo dice y nombra las categorías donde funciona la suscripción.

## Consultar el uso de un plan

Un inicio de sesión de suscripción muestra tu cuenta y cuánto queda de tu plan. Un valor como **% restante** es el margen que te queda. Abre el menú de la tarjeta de la cuenta y elige **Actualizar uso** para actualizarlo, o **Volver a conectar** para iniciar sesión de nuevo.

Cuando Claude o Codex te ha concedido reinicios de límite gratuitos, una tarjeta de suscripción de Claude o ChatGPT muestra **Reinicios de límite gratuitos**: cuántos tienes y hasta cuándo. Pulsa **Usar restablecimiento** y confirma para rellenar tus límites. Si hay más de uno, la tarjeta los lista y usas el que elijas.

Que no se muestre el uso no significa que tu uso sea ilimitado.

## Gestionar tus credenciales

Abre **Ajustes → Gestión de credenciales**. La lista agrupa las credenciales por perfil de proveedor y luego muestra **Unused keys**: claves que ningún proveedor usa.

- Escribe en **Buscar proveedores...** para encontrar uno.
- Pulsa **Añadir nueva credencial** para crear otra credencial de un servicio que elijas.
- Para eliminar una credencial, pasa el cursor por encima y pulsa el icono de la papelera. Si un Conector de clave de API usa esa clave, la confirmación lo nombra, y **Eliminar y desconectar** lo desconecta hasta que le des otra clave.
- Pulsa **Limpiar** al final de la lista para eliminar de una vez todas las claves sin usar. El botón muestra cuántas hay y la confirmación las lista primero. Enconvo nunca elimina claves sin usar por su cuenta.

Pulsa una credencial para añadir o cambiar su clave. **Usado por** lista las funciones que dependen de ella, como **Modelo de IA** o **Texto a voz**; pulsa una para abrir esa página de Ajustes.

Las credenciales propias de un perfil no tienen botón de eliminar aquí. Se van cuando eliminas el proveedor.

Aparecen dos grupos más cuando los tienes: **Otros servicios**, para claves de servicios para los que Enconvo no tiene proveedor, e **Inicios de sesión**, para los inicios de sesión de sitios web y apps que guardaste.

## Cuando un agente necesita una clave

Cuando una tarea necesita la clave de API de un servicio, el agente muestra una tarjeta **Conectar** en el chat en lugar de pedirte que pegues la clave. La clave va a Gestión de credenciales, no a la conversación, y los chats posteriores la usan sin volver a preguntar.

Para un servicio para el que Enconvo no tiene proveedor, la tarjeta muestra el host al que se enviará la clave. La clave se guarda en **Otros servicios**, y el agente solo puede usarla en peticiones a ese host.

El agente nunca guarda la clave: nombra la credencial guardada y, donde una petición o un comando mostraría la clave, se lee `[redacted]`.

En un chat del teléfono, la tarjeta **Conectar** se muestra en tu iPhone y la clave se guarda en Gestión de credenciales en tu Mac. En un chat de mensajería instantánea, el agente nunca pide una clave; envía un enlace que abre el chat en Enconvo.

Si aun así pegas una clave de API en un mensaje, Enconvo la guarda en Gestión de credenciales y la sustituye por `[redacted]` en el chat guardado, para que las peticiones posteriores y tus otros dispositivos no la lleven. Una clave nueva que pegas para un servicio que ya tiene una sustituye a la clave guardada.

## Inicios de sesión de sitios web y apps

Cuando una tarea del navegador llega a una página de inicio de sesión, una tarjeta pide el nombre de usuario y la contraseña una sola vez. Enconvo los rellena solo en ese sitio, y el agente nunca ve la contraseña. Los inicios de sesión guardados aparecen en **Inicios de sesión**. Desmarca **Recordar este inicio de sesión** para usarlo solo en ese inicio.

Cuando el inicio de sesión de una app del Mac necesita una contraseña, la tarjeta nombra la app. Enconvo escribe el nombre de usuario y la contraseña solo en esa app, y la contraseña solo en un campo que oculta lo que escribes.

## Extremos personalizados

Los proveedores **OpenAI Compatible** y **Anthropic Compatible** tienen un campo de URL base de la API para tu propio servidor. Algunos proveedores integrados guardan su ajuste de extremo en **Gestión de credenciales**. Para un servidor de modelos en otro ordenador, consulta [Modelos locales](/es/ai/local-llm).

Solo las ventanas propias de Enconvo pueden cambiar a dónde se envía una clave guardada: la dirección de un proveedor o de una credencial, o el uso de una clave guardada por un servidor MCP. Se rechazan otros programas que usen la API local, el teléfono y los agentes.

## Cómo se guardan las claves

- Cada clave e inicio de sesión guardados se cifran con una clave que permanece en el Llavero de este Mac, así que una copia de la carpeta de ajustes de Enconvo no se puede leer en otro ordenador. Si vuelves a una versión anterior de Enconvo, vuelves a introducir tus claves.
- Otro programa que pida ajustes a la [API local](/es/advanced/cli-local-api) de Enconvo recibe `[hidden]` en lugar de cada clave. Un plugin de la tienda solo puede usar sus propias claves y la credencial elegida en sus ajustes.
- Solo el código que Enconvo instaló y que no ha cambiado puede abrir las claves guardadas. Ajustes muestra y comprueba las claves como antes.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La validación falla | Comprueba el perfil seleccionado, el método de autenticación, el extremo y que tu cuenta del proveedor tenga acceso. |
| Una función funciona y otra falla | Comprueba que la cuenta admita esa función y ese modelo. La página lo dice cuando una categoría solo acepta una clave de API. |
| Algo dejó de funcionar después de cambiar una clave | El perfil es compartido. Prueba las otras categorías que lo usan. |
| El área de uso muestra **Volver a conectar** | El inicio de sesión ha caducado. Pulsa **Volver a conectar** e inicia sesión de nuevo. |

Cada proveedor que usas necesita una credencial: una clave de API o un inicio de sesión en un plan que ya pagas. La añades en la página de Ajustes del propio proveedor, y Enconvo la guarda en un perfil de proveedor que comparten todas las funciones que usan ese proveedor. **Ajustes → Gestión de credenciales** muestra todas tus credenciales en un solo lugar.

## Añade un proveedor

<Steps>
  <Step title="Abre una categoría">
    Abre la página de Ajustes de lo que quieres usar, como **Ajustes → Modelo de IA**, **Ajustes → Generación de imágenes** o **Ajustes → Texto a voz**.
  </Step>
  <Step title="Elige el proveedor">
    Selecciona un proveedor. Para configurar una segunda copia, con otra clave u otra cuenta, elige **Añadir nuevo proveedor**.
  </Step>
  <Step title="Elige cómo iniciar sesión">
    En **Autenticación**, elige **Clave de API**, o **Suscripción** cuando el proveedor te permite usar un plan que pagas.
  </Step>
  <Step title="Añade la credencial">
    Pega tu clave de API o completa el inicio de sesión del proveedor.
  </Step>
  <Step title="Pruébala">
    Haz clic en **Validar** si la página lo muestra, elige un modelo y prueba con una solicitud corta.
  </Step>
</Steps>

Una clave de API se factura en la cuenta de API del proveedor. Una suscripción usa el consumo incluido en tu plan y sus límites. El texto bajo **Autenticación** te indica cuál de los dos usa la página.

## Perfiles compartidos

Un perfil de proveedor, como **OpenAI 2**, guarda la clave de API del proveedor y su inicio de sesión de suscripción, y aparece en todas las categorías que admite el proveedor. Cambiar el nombre del perfil o eliminarlo lo cambia en todas esas categorías, no solo en la página en la que estás.

Cada categoría conserva su propio modelo, voz y ajustes de generación. Sin embargo, una clave de API nueva llega a todas las funciones que usan el perfil, así que prueba esas funciones después de cambiarla.

Lo que ofrece un proveedor varía según la categoría. Que un inicio de sesión funcione para el chat de IA no significa que la API de voz en tiempo real del proveedor esté incluida. Cuando una categoría solo admite una clave de API, su página lo indica y nombra las categorías en las que la suscripción sí funciona.

## Consulta el uso de un plan

Un inicio de sesión de suscripción muestra tu cuenta y cuánto te queda del plan. Un valor como **% restante** es la cantidad que te queda disponible. Abre el menú de la tarjeta de la cuenta y elige **Actualizar uso** para actualizarlo, o **Volver a conectar** para iniciar sesión de nuevo.

Cuando Claude o Codex te han concedido reinicios de límite gratuitos, la tarjeta de una suscripción de Claude o ChatGPT muestra **Reinicios de límite gratuitos**: cuántos tienes y hasta cuándo. Haz clic en **Usar restablecimiento** y confirma para rellenar tus límites. Si tienes más de uno, la tarjeta los enumera y usas el que elijas.

Que no se muestre ningún uso no significa que tu uso sea ilimitado.

## Gestiona tus credenciales

Abre **Ajustes → Gestión de credenciales**. La lista agrupa las credenciales por perfil de proveedor y después muestra **Claves sin usar**: las claves que ningún proveedor usa.

- Escribe en **Buscar proveedores...** para encontrar uno.
- Haz clic en **Añadir nueva credencial** para crear otra credencial para un servicio que elijas.
- Para eliminar una credencial, pasa el cursor sobre ella y haz clic en el icono de la papelera. Si un Connector de clave de API usa esa clave, la confirmación lo nombra, y **Eliminar y desconectar** lo desconecta hasta que le des otra clave.
- Haz clic en **Limpiar** al final de la lista para eliminar de una vez todas las claves sin usar. El botón muestra cuántas hay, y la confirmación las enumera antes. Enconvo nunca elimina por su cuenta las claves sin usar.

Haz clic en una credencial para añadir o cambiar su clave. **Usado por** enumera las funciones que dependen de ella, como **Modelo de IA** o **Texto a voz**; haz clic en una para abrir esa página de Ajustes.

Las credenciales propias de un perfil no tienen botón de eliminar aquí. Desaparecen cuando eliminas el proveedor.

Aparecen dos grupos más cuando los tienes: **Otros servicios**, para las claves de servicios para los que Enconvo no tiene proveedor, e **Inicios de sesión**, para los inicios de sesión de sitios web y apps que guardaste.

## Cuando un agente necesita una clave

Cuando una tarea necesita la clave de API de un servicio, el agente muestra una tarjeta **Conectar** en el chat en lugar de pedirte que pegues la clave. La clave va a Gestión de credenciales, no a la conversación, y los chats posteriores la usan sin volver a preguntar.

Para un servicio para el que Enconvo no tiene proveedor, la tarjeta muestra el host al que se enviará la clave. La clave se guarda en **Otros servicios**, y el agente solo puede usarla en solicitudes a ese host.

El agente nunca tiene la clave en su poder: nombra la credencial guardada, y allí donde una solicitud o un comando mostraría la clave, se lee `[redacted]`.

En un chat del teléfono, la tarjeta **Conectar** aparece en tu iPhone, y la clave se guarda en Gestión de credenciales en tu Mac. En un chat de mensajería instantánea, el agente nunca pide una clave; en su lugar, envía un enlace que abre el chat en Enconvo.

Si pegas una clave de API en un mensaje de todos modos, Enconvo la guarda en Gestión de credenciales y la sustituye por `[redacted]` en el chat guardado, de modo que las solicitudes posteriores y tus otros dispositivos no la lleven. Una clave nueva que pegues para un servicio que ya tiene una sustituye a la clave guardada.

## Inicios de sesión de sitios web y apps

Cuando una tarea del navegador llega a una página de inicio de sesión, una tarjeta te pide el nombre de usuario y la contraseña una sola vez. Enconvo los rellena solo en ese sitio, y el agente nunca ve la contraseña. Los inicios de sesión guardados aparecen en **Inicios de sesión**. Desmarca **Recordar este inicio de sesión** para usarlo solo en ese inicio de sesión.

Cuando el inicio de sesión de una app de Mac necesita una contraseña, la tarjeta nombra la app. Enconvo escribe el nombre de usuario y la contraseña solo en esa app, y la contraseña solo en un campo que oculte lo que escribes.

## Endpoints personalizados

Los proveedores **Compatible con OpenAI** y **Compatible con Anthropic** tienen un campo de URL base de la API para tu propio servidor. Algunos proveedores integrados mantienen su ajuste de endpoint en **Gestión de credenciales**. Para un servidor de modelos en otro ordenador, consulta [Modelos locales](/es/ai/local-llm).

Solo las propias ventanas de Enconvo pueden cambiar adónde se envía una clave guardada: la dirección de un proveedor o de una credencial, o el uso que hace un servidor MCP de una clave guardada. Otros programas que usen la API local, el teléfono y los agentes son rechazados.

## Cómo se guardan las claves

- Cada clave e inicio de sesión guardados se cifra con una clave que permanece en el llavero de este Mac, de modo que una copia de la carpeta de ajustes de Enconvo no se puede leer en otro ordenador. Si vuelves a una versión anterior de Enconvo, tendrás que introducir de nuevo tus claves.
- Otro programa que pida ajustes a la [API local](/es/advanced/cli-local-api) de Enconvo recibe `[hidden]` en lugar de cada clave. Un plugin de la tienda solo puede usar sus propias claves y la credencial elegida en sus ajustes.
- Solo el código que Enconvo instaló y que no ha sido modificado puede abrir las claves guardadas. Ajustes muestra y comprueba las claves como antes.

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| La validación falla | Comprueba el perfil seleccionado, el método de autenticación, el endpoint y que tu cuenta del proveedor tenga acceso. |
| Una función funciona y otra falla | Comprueba que la cuenta admite esa función y ese modelo. La página indica cuándo una categoría solo admite una clave de API. |
| Algo dejó de funcionar después de cambiar una clave | El perfil es compartido. Prueba las demás categorías que lo usan. |
| El área de uso muestra **Volver a conectar** | El inicio de sesión ha caducado. Haz clic en **Volver a conectar** e inicia sesión de nuevo. |

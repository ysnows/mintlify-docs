Las ventanas y las funciones de voz de Enconvo se abren cada una con un atajo de teclado. **Ajustes → Atajo** enumera todos los atajos que usa Enconvo y el comando que ejecuta cada uno, para que puedas cambiar uno o averiguar qué hace una combinación de teclas. Los atajos guardados en tu Mac siempre prevalecen sobre los predeterminados de esta guía.

Este vídeo cubre los atajos y luego los demás ajustes que adaptan Enconvo a tu Mac: Conciencia del contexto, Appshots, Modelos locales, Permisos y Mantener activo.

## Atajos predeterminados

| Acción | Predeterminado |
| --- | --- |
| Mostrar SmartBar | **⌥Espacio** |
| Mostrar la Ventana de chat | **⌃⌘X** |
| Mostrar la Barra lateral de la app | **⌃⌘E** |
| Abrir Ajustes, desde dentro de Enconvo | **⌘,** |
| Iniciar el Dictado | **⌘ derecho** |
| Iniciar el Comando de voz | **⌥ derecho** |
| Pausar/reanudar el audio | **⌥P** |

Estos valores predeterminados solo se aplican si nunca estableciste tu propia tecla; una tecla que hayas establecido se queda como está. Captura rápida y Appshots no tienen atajo predeterminado: establece uno en sus páginas de Ajustes antes de usarlos.

## Cambia un atajo

1. Abre **Ajustes → Atajo**. La pestaña **Principales** contiene las funciones principales, **Otros atajos** contiene los comandos de IA, los plugins, los ajustes y los comandos que ninguna otra página muestra, y **Todos** muestra ambas.
2. Escribe en **Filtrar por nombre…** para encontrar un comando. Para encontrar el comando que hay detrás de una combinación de teclas, haz clic en **Buscar por atajo** y púlsala.
3. Haz clic en el campo de atajo del comando y pulsa la nueva combinación.
4. Si esas teclas ya ejecutan otro comando, el campo te lo indica. Elige **Usarlo aquí** para mover las teclas a este comando, o elige uno de los atajos libres que sugiere.
5. Cambia a otra app y prueba el atajo.

Para liberar las teclas de un atajo, quítalo del comando. Un mensaje con **Deshacer** te permite revertirlo.

Una insignia **Local** marca un atajo que solo funciona dentro de Enconvo, como Fijar SmartBar.

## Cómo pulsarla

Cuando grabas una tecla modificadora sola, como ⌘ derecho, el campo pregunta **Cómo pulsarla**:

| Opción | El comando se ejecuta cuando |
| --- | --- |
| **Mantener o tocar** | Mantienes la tecla, o la tocas para alternar |
| **Tocar** | Tocas la tecla para empezar y la tocas de nuevo para detener |
| **Mantener** | Mantienes la tecla pulsada; funciona mientras la mantienes |
| **Doble toque** | Tocas la tecla dos veces rápidamente |

Dos o más teclas modificadoras pulsadas al mismo tiempo cuentan como un único atajo. Cada campo muestra solo los tipos que admite su comando, y la descripción que hay junto a él indica cómo reacciona esa función.

## Dónde está el atajo de cada función

Además de la página Atajo, cada función tiene su atajo en su propia página de Ajustes:

| Función | Página de Ajustes |
| --- | --- |
| SmartBar | **Ajustes → SmartBar** |
| Dynamic Island | **Ajustes → Dynamic Island** |
| PopBar | **Ajustes → PopBar** |
| Barra lateral de la app | **Ajustes → Barra lateral de la app** |
| Dictado | **Ajustes → Dictado** |
| Comando de voz | **Ajustes → Comando de voz** |
| Appshots | **Ajustes → Appshots** |
| Dibujo en pantalla | **Ajustes → Dibujo en pantalla** |
| Nota de voz | **Ajustes → Nota de voz** |
| Captura rápida | **Ajustes → Captura rápida** |
| Un solo comando | Los ajustes de ese comando, cuando tiene un campo **Atajo de teclado** |

## Dentro de SmartBar

Escribe un carácter activador en SmartBar para buscar un tipo de elemento:

| Carácter | Abre |
| --- | --- |
| **@** | Comandos |
| **#** | Contexto para añadir a tu mensaje |
| **$** | Habilidades |
| **>** | Tareas recientes |

Cambia estos caracteres en **Buscar** dentro de **Ajustes → SmartBar**. El menú de barra diagonal contiene acciones como la selección de modelo y de razonamiento.

Para moverte por las listas con el teclado, elige **Atajos de navegación** en **Ajustes → SmartBar**: **macOS** usa **⌃N** **⌃P** **⌃F** **⌃B**, y **Vim** usa **⌃J** **⌃K** **⌃L** **⌃H**.

## Adapta Enconvo a tu Mac

La misma ventana de Ajustes contiene las otras opciones que recorre el vídeo:

| Página de Ajustes | Qué hace |
| --- | --- |
| **Conciencia del contexto** | Elige lo que SmartBar recoge de la app en la que estabas: el texto seleccionado, tu selección del Finder o la página de tu navegador. **Adjuntar** lo añade en cuanto se abre SmartBar, y **Sugerir** lo ofrece para añadirlo con un clic. Consulta [Conciencia del contexto](/es/features/context-awareness). |
| **Appshots** | Añade a la conversación la ventana que tienes delante con un atajo. Consulta [Appshots](/es/features/appshots). |
| **Modelos locales** | Muestra la IA que se ejecuta en este Mac, la memoria y el disco que usa, y dónde se ejecuta cada función. Consulta [Modelos locales](/es/ai/local-llm). |
| **Permisos** | Enumera lo que macOS permite hacer a Enconvo y por qué; **Conceder** arregla el que falte. Consulta [Permisos de macOS](/es/configuration/permissions). |
| **Mantener activo** | Evita que este Mac se suspenda mientras estás fuera, para que puedas seguir accediendo a él desde tu iPhone. |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Un atajo solo funciona dentro de Enconvo | Comprueba si tiene una insignia **Local**. Si no, comprueba Monitorización de entrada y Accesibilidad en [Permisos de macOS](/es/configuration/permissions), y si otra app usa las mismas teclas. |
| Al pulsar un atajo ocurre otra cosa | Usa **Buscar por atajo**. Si ningún comando de Enconvo usa esas teclas, las usa otra app o macOS. |
| Un atajo de tecla modificadora no se activa | Abre el atajo y comprueba **Cómo pulsarla**: mantener, tocar, doble toque o teclas pulsadas a la vez. |
| Un atajo de un vídeo o de otro Mac no funciona | Tus atajos pueden ser distintos. Consulta el actual en **Ajustes → Atajo**. |

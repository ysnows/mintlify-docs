Las ventanas y las funciones de voz de Enconvo se abren cada una con un atajo. **Ajustes → Atajo** lista cada atajo que usa Enconvo y el comando que ejecuta, para que puedas cambiar uno o saber qué hace una combinación de teclas. Los atajos guardados en tu Mac siempre prevalecen sobre los predeterminados de esta guía.

Este vídeo cubre los atajos y luego los demás ajustes que adaptan Enconvo a tu Mac: conciencia del contexto, Appshots, modelos locales, permisos y mantener activo.

## Atajos predeterminados

| Acción | Predeterminado |
| --- | --- |
| Mostrar SmartBar | **⌥Space** |
| Mostrar la Ventana de chat | **⌃⌘X** |
| Mostrar la Barra lateral de la app | **⌃⌘E** |
| Abrir Ajustes, desde dentro de Enconvo | **⌘,** |
| Iniciar el Dictado | **⌘ derecho** |
| Iniciar el Comando de voz | **⌥ derecho** |
| Pausar o reanudar el audio | **⌥P** |

Estos predeterminados solo se aplican si nunca fijaste tu propia tecla; una tecla que fijaste se queda como está. Captura rápida y Appshots no tienen atajo predeterminado: fija uno en sus páginas de Ajustes antes de usarlos.

## Cambiar un atajo

1. Abre **Ajustes → Atajo**. La pestaña **Principales** reúne las funciones principales, **Otros atajos** reúne comandos de IA, plugins, ajustes y comandos que ninguna otra página muestra, y **Todos** muestra ambos.
2. Escribe en **Filtrar por nombre…** para encontrar un comando. Para encontrar el comando detrás de una combinación de teclas, haz clic en **Buscar por atajo** y púlsala.
3. Haz clic en el campo de atajo del comando y pulsa la combinación nueva.
4. Si esas teclas ya ejecutan otro comando, el campo te lo dice. Elige **Usarlo aquí** para mover las teclas a este comando, o elige uno de los atajos libres que sugiere.
5. Cambia a otra app y prueba el atajo.

Para liberar las teclas de un atajo, quítalo del comando. Un mensaje con **Deshacer** te deja revertirlo.

Una insignia **Local** marca un atajo que solo funciona dentro de Enconvo, como fijar SmartBar.

## Cómo pulsarlo

Cuando grabas una sola tecla modificadora, como ⌘ derecho, el campo pregunta **Cómo pulsarla**:

| Opción | El comando se ejecuta cuando |
| --- | --- |
| **Mantener o tocar** | Mantienes la tecla, o la tocas para alternar |
| **Tocar** | Tocas la tecla para empezar, y la tocas otra vez para parar |
| **Mantener** | Mantienes la tecla pulsada; funciona mientras la mantienes |
| **Doble toque** | Tocas la tecla dos veces seguidas |

Dos o más teclas modificadoras pulsadas a la vez cuentan como un atajo. Cada campo muestra solo los tipos que admite su comando, y la descripción de al lado dice cómo reacciona esa función.

## Dónde está el atajo de cada función

Además de la página de atajos, cada función tiene su atajo en su propia página de Ajustes:

| Función | Página de Ajustes |
| --- | --- |
| SmartBar | **Ajustes → SmartBar** |
| Dynamic Island | **Ajustes → Dynamic Island** |
| PopBar | **Ajustes → PopBar** |
| Barra lateral de la app | **Ajustes → Barra lateral de la app** |
| Dictado | **Ajustes → Dictado** |
| Comando de voz | **Ajustes → Comando de voz** |
| Appshots | **Ajustes → Appshots** |
| Dibujo en pantalla | **Ajustes → Dibujo en pantalla** |
| Nota de voz | **Ajustes → Nota de voz** |
| Captura rápida | **Ajustes → Captura rápida** |
| Un solo comando | Los ajustes de ese comando, cuando tiene un campo **Atajo de teclado** |

## Dentro de SmartBar

Escribe un carácter de disparo en SmartBar para buscar un tipo de elemento:

| Carácter | Abre |
| --- | --- |
| **@** | Comandos |
| **#** | Contexto para añadir a tu mensaje |
| **$** | Habilidades |
| **>** | Tareas recientes |

Cambia estos caracteres en **Buscar** de **Ajustes → SmartBar**. El menú de barra diagonal reúne acciones como la selección de modelo y de razonamiento.

Para moverte por las listas con el teclado, elige **Atajos de navegación** en **Ajustes → SmartBar**: **macOS** usa **⌃N** **⌃P** **⌃F** **⌃B**, y **Vim** usa **⌃J** **⌃K** **⌃L** **⌃H**.

## Adaptar Enconvo a tu Mac

La misma ventana de Ajustes reúne las demás opciones que recorre el vídeo:

| Página de Ajustes | Qué hace |
| --- | --- |
| **Conciencia del contexto** | Elige qué recoge SmartBar de la app en la que estabas: el texto seleccionado, tu selección en Finder o la página del navegador. **Adjuntar** lo añade en cuanto se abre SmartBar, y **Sugerir** lo ofrece con un clic. Consulta [Conciencia del contexto](/es/features/context-awareness). |
| **Appshots** | Añade la ventana que tienes delante a la conversación con un atajo. Consulta [Appshots](/es/features/appshots). |
| **Modelos locales** | Muestra la IA que corre en este Mac, la memoria y el disco que usa, y dónde se ejecuta cada función. Consulta [Modelos locales](/es/ai/local-llm). |
| **Permisos** | Lista lo que macOS deja hacer a Enconvo y por qué; **Conceder** arregla uno que falta. Consulta [Permisos de macOS](/es/configuration/permissions). |
| **Mantener activo** | Impide que este Mac se duerma mientras estás fuera, para que puedas alcanzarlo desde tu iPhone. |

## Solución de problemas

| Problema | Qué hacer |
| --- | --- |
| Un atajo solo funciona dentro de Enconvo | Comprueba si tiene una insignia **Local**. Si no, revisa Supervisión de entrada y Accesibilidad en [Permisos de macOS](/es/configuration/permissions), y si otra app usa las mismas teclas. |
| Pulsar un atajo hace otra cosa | Usa **Buscar por atajo**. Si ningún comando de Enconvo usa las teclas, lo hace otra app o macOS. |
| Un atajo de tecla modificadora no se dispara | Abre el atajo y revisa **Cómo pulsarla**: mantener, tocar, doble toque o teclas pulsadas juntas. |
| Un atajo de un vídeo o de otro Mac no funciona | Tus atajos pueden ser distintos. Busca el actual en **Ajustes → Atajo**. |

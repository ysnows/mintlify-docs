Las variables rellenan valores que cambian cada vez, como el texto que escribiste en el SmartBar, el texto seleccionado en otra app o la fecha de hoy. Úsalas en prompts y preferencias que admiten plantillas, así un Comando de IA, una instrucción de Agente o un flujo de trabajo funciona con lo que tienes delante. Abre **Ajustes → Variables** para ver las variables disponibles.

## Variables disponibles

| Variable | Valor que aporta |
| --- | --- |
| Input Text | Entrada actual del SmartBar |
| Selection Text | Texto seleccionado en la app actual |
| Latest Clipboard | Contenido más reciente del portapapeles |
| Active Application | Información de la app de delante |
| Active Application Screenshot | Imagen de la ventana de delante |
| Active Screen Screenshot | Imagen de la pantalla activa |
| Focused Window Content | Contenido extraído de la ventana enfocada |
| Browser Active Tab | URL de la pestaña activa y contenido de página disponible |
| Current Folder | La carpeta abierta en Finder |
| Selected Files | Archivos seleccionados en Finder |
| History Messages | Historial de la conversación actual |
| Now | Fecha y hora actuales |
| Your Language | El idioma en el que lees: tu **Idioma de respuesta**, o el idioma del sistema cuando está en Automático |
| Opened Applications | Información de las apps en ejecución |
| Opened Application Names | Nombres de las apps en ejecución |

## Usar una variable

1. Abre el Comando de IA, la instrucción de Agente o el campo del flujo de trabajo que quieres personalizar.
2. Comprueba que el campo admita variables; usa su selector si lo tiene.
3. Inserta el valor que necesitas y pruébalo con contenido de ejemplo inofensivo.
4. Comprueba si una entrada vacía o un permiso que falta cambia el resultado.

Un prompt de texto puede usar nombres de plantilla admitidos, como:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Qué variables puedes usar depende del comando y del contexto, y no todos los campos de texto evalúan plantillas. Las capturas y el contenido de las apps pueden necesitar permisos de macOS y un modelo que acepte ese tipo de entrada.

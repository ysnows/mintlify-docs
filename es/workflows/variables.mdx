Las variables rellenan valores que cambian cada vez, como el texto que escribiste en SmartBar, el texto seleccionado en otra app o la fecha de hoy. Úsalas en prompts y preferencias que admiten plantillas, de modo que un Comando de IA, una instrucción de Agente o un flujo de trabajo funcione con lo que tengas delante. Abre **Ajustes → Variables** para ver las variables disponibles.

## Variables disponibles

| Variable | Valor que aporta |
| --- | --- |
| Input Text | La entrada actual de SmartBar |
| Selection Text | El texto seleccionado en la app actual |
| Latest Clipboard | El contenido más reciente del portapapeles |
| Active Application | Información de la app en primer plano |
| Active Application Screenshot | Imagen de la ventana en primer plano |
| Active Screen Screenshot | Imagen de la pantalla activa |
| Focused Window Content | Contenido extraído de la ventana con el foco |
| Browser Active Tab | URL de la pestaña activa y el contenido de página disponible |
| Current Folder | La carpeta abierta en Finder |
| Selected Files | Los archivos seleccionados en Finder |
| History Messages | El historial de la conversación actual |
| Now | Fecha y hora actuales |
| Your Language | El idioma en el que lees: tu **Idioma de respuesta**, o el idioma del sistema cuando está en Auto |
| Opened Applications | Información de las apps en ejecución |
| Opened Application Names | Nombres de las apps en ejecución |

## Usa una variable

1. Abre el campo del Comando de IA, la instrucción de Agente o el flujo de trabajo que quieres personalizar.
2. Comprueba que el campo admite variables; usa su selector cuando lo tenga.
3. Inserta el valor que necesitas y pruébalo con contenido de ejemplo inofensivo.
4. Comprueba si una entrada vacía o un permiso que falta cambia el resultado.

Un prompt de texto puede usar nombres de plantilla admitidos como:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Las variables que puedes usar dependen del comando y del contexto, y no todos los campos de texto evalúan plantillas. Las capturas de pantalla y el contenido de las apps pueden requerir permisos de macOS y un modelo que acepte ese tipo de entrada.

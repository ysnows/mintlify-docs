---
title: "Загрузка веб-страницы"
description: "Пусть агент прочитает веб-страницу по URL или сохраните страницу в базе знаний."
---

Используйте загрузку веб-страницы, когда URL уже есть и нужно, чтобы агент прочитал страницу. Любой агент умеет читать ссылку, которую вы ему даёте; сервис, который её загружает, выбираете вы. [Поиск в интернете](/ru/ai/web-search) нужен, когда сначала надо найти подходящие страницы.

## Выберите провайдера

1. Откройте **Настройки → Загрузка веб-страницы**.
2. Выберите провайдера и нажмите **Сделать по умолчанию**.

| Провайдер | Назначение |
| --- | --- |
| **Local Fetch** | Бесплатная загрузка страниц на вашем Mac, с необязательной помощью браузера |
| **Jina AI Link Reader** | Читаемый текст через Jina |
| **Firecrawl Link Reader** | Содержимое через Firecrawl |
| **DeepSeek** | Страницы как Markdown с вашим API-ключом DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Страницы как Markdown через Enconvo Cloud, без API-ключа |
| **Enconvo Cloud Plan** | Облачный сервис чтения ссылок |

## Прочитать страницу

1. Вставьте URL в беседу и задайте конкретный вопрос о странице.
2. Проверьте полученное содержимое и источник, прежде чем опираться на ответ.

## Страницы за входом

С **Local Fetch** настройка **Загрузка через браузер** может прочитать страницу через браузер семейства Chromium с расширением Enconvo Companion.

| Вариант | Что делает |
| --- | --- |
| **Авто** (по умолчанию) | Берёт уже открытую подходящую вкладку, полностью отрисованную и с вашим входом. Если прямая загрузка не удалась или странице нужен JavaScript, использует временную фоновую вкладку. |
| **Выкл.** | Только прямой HTTP |
| **Всегда** | Всегда загружает через браузер |

Без подключённого браузера Local Fetch делает прямой HTTP-запрос. Остальные провайдеры загружают публичный URL и не видят вашу сессию в браузере. Для интерактивных страниц используйте [расширение браузера](/ru/features/browser-extension) или [Browser Use](/ru/features/browser-control).

## Сохранить веб-содержимое

Добавьте URL через **Добавить → Одна веб-страница** в [базе знаний](/ru/ai/knowledge-base), если хотите найти её позже. Проверьте импортированную страницу и статус индексации: веб-страницы могут измениться после импорта.

## Устранение неполадок

| Проблема | Что сделать |
| --- | --- |
| Содержимое пустое | Проверьте, что страница читается без лишних действий, или используйте **Local Fetch** с **загрузкой через браузер**. Экраны входа, заблокированные запросы, динамически загружаемое содержимое и неподдерживаемые сайты могут мешать извлечению. |
| Ответ описывает то, чего на странице нет | Попросите агента показать, что он реально получил, а не додумывать недостающее. |

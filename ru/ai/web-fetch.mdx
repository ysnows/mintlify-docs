title: "Загрузка веб-страницы"
description: "Пусть Агент прочитает веб-страницу по её URL или сохраните страницу в базе знаний."

Используйте «Загрузку веб-страницы», когда у вас уже есть URL и вы хотите, чтобы Агент прочитал страницу. Каждый Агент может прочитать ссылку, которую вы ему дали; сервис, который её загружает, вы выбираете сами. Если сначала нужно найти подходящие страницы, используйте [Поиск в интернете](/ru/ai/web-search).

## Выберите провайдера

1. Откройте **Настройки → Загрузка веб-страницы**.
2. Выберите провайдера и нажмите **Сделать по умолчанию**.

| Провайдер | Для чего |
| --- | --- |
| **Local Fetch** | Бесплатная загрузка страниц на вашем Mac, при желании с помощью браузера |
| **Jina AI Link Reader** | Получение читаемого содержимого через Jina |
| **Firecrawl Link Reader** | Получение содержимого через Firecrawl |
| **DeepSeek** | Чтение страниц в виде Markdown с вашим API-ключом DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Чтение страниц в виде Markdown через Enconvo Cloud, API-ключ не нужен |
| **Enconvo Cloud Plan** | Облачный сервис чтения ссылок |

## Прочитайте страницу

1. Вставьте URL в разговор и задайте конкретный вопрос о странице.
2. Проверьте полученное содержимое и источник, прежде чем полагаться на ответ.

## Страницы за входом в аккаунт

В режиме **Local Fetch** функция **Browser-Assisted Fetching** может прочитать страницу через браузер семейства Chromium, в котором установлено расширение Enconvo Companion.

| Параметр | Что он делает |
| --- | --- |
| **Авто** (по умолчанию) | Использует подходящую уже открытую у вас вкладку: полностью отрисованную и с вашим входом в аккаунт. Использует временную фоновую вкладку, когда прямая загрузка не удалась или странице нужен JavaScript. |
| **Выкл.** | Только прямой HTTP |
| **Всегда** | Всегда загружает через браузер |

Без подключённого браузера Local Fetch выполняет прямой HTTP-запрос. Остальные провайдеры загружают публичный URL и не имеют доступа к сеансу вашего браузера с входом в аккаунт. Для интерактивных страниц используйте [Расширения для браузера](/ru/features/browser-extension) или [Browser Use](/ru/features/browser-control).

## Сохраните веб-содержимое

Добавьте URL через **Добавить → Отдельная веб-страница** в [Базе знаний](/ru/ai/knowledge-base), если хотите найти его позже. Проверьте импортированную страницу и статус её индексации: веб-страницы могут измениться после импорта.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Содержимое приходит пустым | Проверьте, что страницу можно прочитать без дополнительных действий, или используйте **Local Fetch** с **Browser-Assisted Fetching**. Извлечению могут мешать экраны входа, заблокированные запросы, динамически загружаемое содержимое и неподдерживаемые сайты. |
| В ответе описано то, чего нет на странице | Попросите Агента показать, что он на самом деле получил, вместо того чтобы он угадывал недостающее содержимое. |

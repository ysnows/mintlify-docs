Агенты для написания кода — это привычные вам ИИ-инструменты для программирования, например Claude Code и Codex, которые работают внутри чатов Enconvo. Используйте их, когда нужно работать с кодом в папке проекта: агент редактирует файлы и показывает изменения, запускает команды и спрашивает разрешения перед действиями, а Enconvo хранит чат, его историю и подтверждения в Окне чата, SmartBar и на вашем телефоне.

| Агент для написания кода | Разработчик | Где работает |
| --- | --- | --- |
| **Claude Code** | Anthropic | На вашем Mac, вход через Claude |
| **Codex** | OpenAI | На вашем Mac, вход через ChatGPT |
| **Grok Build** | xAI | На вашем Mac, вход через Grok |
| **Antigravity** | Google | На вашем Mac, вход через Google |
| **Muse Code** | Meta | На вашем Mac, вход через Meta или на локальной модели |
| **Grok Bot** | xAI | В облаке xAI, через подключаемую вами процедуру |

## Перед началом

У каждого агента для написания кода есть своя страница в **Настройки → Список агентов**. Откройте её, чтобы увидеть **Статус**:

1. Если указано **Не установлено**, нажмите **Установить** или выполните показанную команду в Терминале и нажмите **Повторить проверку**. Если версия слишком старая, появится кнопка **Обновить**.
2. В разделе **Учетная запись** нажмите **Войти через Claude**, **Войти через ChatGPT**, **Войти через Grok**, **Войти через Google** или **Войти через Meta**. Enconvo использует тот же вход, что и командная строка агента в Терминале.

Если вход в Claude Code или Codex истекает в течение десяти дней, об этом сообщают страница агента, список **Обновления** и Доска проекта, рядом с кнопкой **Войти снова**. Задача на Доске, чей агент для написания кода вышел из учётной записи, ждёт в статусе **Задержано** и снова запускается после входа.

Muse Code на локальной модели не требует входа через Meta. Для Grok Bot нужна процедура; см. [Подключение Grok Bot](#подключение-grok-bot).

## Чат с агентом для написания кода

1. В Окне чата выберите агента для написания кода на карточках агентов или в меню агентов.
2. Выберите папку проекта, в которой он будет работать.
3. Введите запрос и отправьте его. Шаги агента, изменения и команды появляются в чате по мере выполнения, а его вопросы о разрешениях отображаются карточками, на которые нужно ответить.

Подтверждения в чате подчиняются [режиму разрешений](/ru/ai/agents) Enconvo. При **Полном доступе** новый чат Claude Code начинается в режиме **Игнорировать разрешения** (если это позволяют собственные настройки Claude Code), а новый чат Codex — с **Полным доступом**, поэтому ни один из них не спрашивает перед действиями.

В чате рабочего дерева вкладка **Pull Request** на боковой панели (**⌃⇧P**) показывает pull request ветки на GitHub или создаёт его. См. [Окно чата](/ru/ai/chat).

Чтобы продолжить прежний сеанс, выберите **Возобновить предыдущий сеанс**. Сеансы, начатые в командной строке самого агента, тоже в списке, под заданными вами именами.

Чат, начатый с Mavis, можно передать агенту для написания кода, продолжив его в новом чате с ним. Другие агенты могут использовать агентов для написания кода как субагентов, а проект может поручать им задачи или поручить одному из них руководить проектом. См. [Субагенты](/ru/ai/agents) и [Проекты](/ru/ai/projects).

### Claude Code: усилие, быстрый режим и Ultracode

Переключатель усилия в чате Claude Code задаёт уровень рассуждений. Если сеанс это поддерживает, в нём также есть **Быстрый режим** и переключатель **Ultracode**. Ultracode включает оркестрацию рабочих процессов до конца сеанса при выбранном вами уровне усилия и остаётся включённым при его смене. То же делает команда `/effort ultracode`. В новом чате быстрый режим и Ultracode можно включить до первого сообщения.

### Codex: предупреждения

Предупреждения Codex не попадают в беседу. Введите `/warnings`, чтобы увидеть их список.

### Muse Code: продолжение в Терминале

Чтобы продолжить чат Muse Code в Терминале, выберите **Продолжить в Терминале** или **Скопировать команду**, чтобы скопировать её. Чат откроется командой `muse resume` в своей папке. Когда вы закроете там Muse Code и снова отправите сообщение из Enconvo, ходы, выполненные в Терминале, вернутся в чат.

Вопросы Muse Code о разрешениях показывают изменение, которое внесёт правка. Если вы отклоняете шаг, то текст, введённый при нажатии **Отклонить**, попадает к Muse Code в том же ходе, и он может сразу его учесть. Его навыки и `/compact` находятся в меню `/`.

<Note>
Режим Contributor в Muse Code включён по умолчанию, что позволяет Meta обучать свои модели на ваших запросах и коде. Enconvo оставляет его как есть; отключите его в собственных настройках Muse Code.
</Note>

## Выбор возможностей Enconvo для агента

Агенты для написания кода могут использовать плагины Enconvo в своих чатах, например отправку сообщений вашим агентам Enconvo, создание изображений и видео, память, браузер и Управление компьютером. На странице агента в **Настройки → Список агентов**, в разделе **Возможности Enconvo**:

- Отключите **Возможности Enconvo**, чтобы закрыть этому агенту доступ ко всем плагинам Enconvo.
- Или нажмите **Настроить** рядом с **Плагины** и отключайте плагины по одному. Отключённый плагин скрыт от этого агента, а его вызовы отклоняются.

Изменение действует и в уже открытых чатах агента. Чаты агентов для написания кода в рабочем пространстве клиента целиком остаются внутри этого рабочего пространства.

## Подключение Grok Bot

Grok Bot работает в облаке xAI. Enconvo отправляет каждое сообщение в процедуру с Webhook, которую вы создаёте в Grok Bot, и показывает ответ в чате, даже если он приходит с опозданием.

1. В Grok Bot создайте процедуру с триггером Webhook.
2. Откройте **Grok Bot** в **Настройки → Список агентов**, нажмите **Скопировать** рядом с **Инструкции процедуры** и вставьте их в процедуру.
3. Добавьте URL вебхука и ключ процедуры как учётные данные на той же странице, затем нажмите **Проверить**. Проверка ждёт ответа процедуры до 90 секунд.

Пока процедура не подключена, в выборе агентов Grok Bot отображается как **Не настроено**. Каждое сообщение расходует недельный лимит вашего тарифа Grok Bot. **Остановить** лишь прекращает ожидание в Enconvo: запуск процедуры продолжается в облаке, а поздний ответ всё равно добавляется в чат.

Сообщение может содержать до 32 000 символов. Прикреплённые файлы и изображения остаются на вашем Mac; отправляется только текст.

### Разрешите Grok Bot вызывать Enconvo

С MCP-сервером Enconvo Grok Bot может отвечать в ваших чатах, уведомлять ваш Mac и связанные телефоны и просить агента на вашем Mac выполнить задачу.

1. На странице Grok Bot в разделе **Grok Bot вызывает Enconvo** нажмите **Подключить**. Нужно быть авторизованным в учётной записи Enconvo.
2. В Grok Bot откройте **Плагины**, добавьте показанный **URL сервера** и войдите в учётную запись Enconvo, когда Grok Bot попросит.

Каждый запрос к агенту на вашем Mac ждёт вашего подтверждения, если вы не включили **Всегда разрешать ask_mac**. Запросы остаются в списке в чате **Grok Bot на этом Mac**. Нажмите **Отключить**, чтобы Grok Bot больше не вызывал Enconvo; при отключении, а также если ваш Mac уходит в офлайн, ожидающий запрос отзывается.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Чат сообщает, что агент не авторизован | Откройте страницу агента в **Настройки → Список агентов** и нажмите **Войти снова**. Чат Mavis или приложение, вызвавшее агента, получает ту же ошибку входа, а их задачи на Доске ждут в статусе **Задержано** до входа. |
| У агента указано **Не установлено** или версия слишком старая | Нажмите **Установить** или **Обновить** на его странице, затем **Повторить проверку**. |
| Muse Code сообщает, что Enconvo нужно обновить | Обновите Enconvo, чтобы он работал с более новым Muse Code. |
| Grok Bot показывает **Не настроено** | Добавьте URL вебхука и ключ процедуры на странице Grok Bot и нажмите **Проверить**. |
| Проверка Grok Bot сообщает о слишком большом числе сообщений | Процедура или Enconvo временно отклоняют слишком много сообщений. Повторите позже. |
| Чат Muse Code, открытый в Терминале, не отправляется | Закройте Muse Code в Терминале, чтобы вернуть его ходы, затем отправьте из Enconvo. |

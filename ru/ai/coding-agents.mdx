Агенты для кода — это AI-инструменты для кода, которыми вы уже пользуетесь, например Claude Code и Codex, запущенные внутри чатов Enconvo. Используйте их, когда работа — это код в папке проекта: они правят файлы с diff, запускают команды и спрашивают, прежде чем действовать, а Enconvo хранит чат, его историю и одобрения в окне чата, SmartBar и на телефоне.

| Агент для кода | Кто сделал | Где работает |
| --- | --- | --- |
| **Claude Code** | Anthropic | На вашем Mac, со входом в Claude |
| **Codex** | OpenAI | На вашем Mac, со входом в ChatGPT |
| **Grok Build** | xAI | На вашем Mac, со входом в Grok |
| **Antigravity** | Google | На вашем Mac, со входом в Google |
| **Muse Code** | Meta | На вашем Mac, со входом в Meta, или на своей локальной модели |
| **Grok Bot** | xAI | В облаке xAI, через рутину, которую вы подключаете |

## Перед началом

У каждого агента для кода своя страница в **Настройки → Список агентов**. Нажмите ее, чтобы увидеть **Status**:

1. Если показано **Не установлено**, нажмите **Установить** или выполните показанную команду в Terminal и нажмите **Повторить проверку**. Слишком старая версия показывает **Обновить**.
2. В **Account** нажмите **Sign in with Claude**, **Sign in with ChatGPT**, **Sign in with Grok**, **Sign in with Google** или **Sign in with Meta**. Enconvo использует тот же вход, что и собственная командная строка агента в Terminal.

Когда вход Claude Code или Codex истекает в течение десяти дней, страница агента, список **Updates** и доска проекта говорят об этом, с **Войти снова**. Задача доски, чей агент для кода вышел, ждет как **Задержано** и запускается снова, когда вы войдете.

Muse Code на своей локальной модели не требует входа Meta. Grok Bot нуждается в рутине; см. [Подключить Grok Bot](/ru/ai/coding-agents).

## Общаться с агентом для кода

1. В окне чата выберите агента для кода на карточках агентов или в меню агента.
2. Выберите папку проекта, в которой он работает.
3. Введите запрос и отправьте. Его шаги, diff и команды идут в чат, а вопросы об одобрении показываются карточками, на которые вы отвечаете.

Одобрения чата следуют [режиму разрешений](/ru/ai/agents) Enconvo. При **Полный доступ** новый чат Claude Code начинается в **Bypass permissions** (где это позволяют собственные настройки Claude Code), а новый чат Codex — в **Full access**, так что ни один не спрашивает, прежде чем действовать.

В чате рабочего дерева вкладка **Pull request** боковой панели (**⌃⇧P**) показывает pull request ветки на GitHub или создает его. См. [Окно чата](/ru/ai/chat).

Чтобы продолжить более ранний сеанс, выберите **Возобновить предыдущий сеанс**. Сеансы, которые вы начали в собственной командной строке агента, тоже перечислены, под именами, которые вы им дали.

Чат, начатый с Mavis, можно также передать агенту для кода, продолжив в новом чате с ним. Другие агенты могут использовать агентов для кода как субагентов, а проект может давать им задачи или поставить одного во главе проекта. См. [Субагенты](/ru/ai/agents) и [Проекты](/ru/ai/projects).

### Claude Code: усилие, быстрый режим и Ultracode

Выбор усилия в чате Claude Code задает усилие рассуждения. Когда сеанс это поддерживает, выбор также показывает **Fast mode** и переключатель **Ultracode**. Ultracode включает оркестрацию рабочего процесса до конца сеанса при любом выбранном усилии и остается включенным, когда вы меняете усилие. Ввод `/effort ultracode` делает то же. В новом чате быстрый режим и Ultracode можно задать до первого сообщения.

### Codex: предупреждения

Предупреждения Codex остаются вне разговора. Введите `/warnings`, чтобы перечислить их.

### Muse Code: продолжить в Terminal

Чтобы продолжить чат Muse Code в Terminal, выберите **Continue in Terminal** или **Скопировать команду**, чтобы скопировать ее. Чат открывается с `muse resume` в своей папке. Когда вы выходите из Muse Code там и снова отправляете из Enconvo, ходы, которые вы провели в Terminal, возвращаются в чат.

Вопросы одобрения Muse Code показывают изменение, которое внесла бы правка. Когда вы отклоняете шаг, то, что вы вводите с **Deny**, уходит в Muse Code в том же ходе, так что он может сразу на это действовать. Его навыки и `/compact` есть в меню `/`.

<Note>
Режим Contributor у Muse Code включен по умолчанию: он позволяет Meta обучать модели на ваших запросах и коде. Enconvo оставляет его как есть; выключите в собственных настройках Muse Code.
</Note>

## Выберите, чем агент для кода может пользоваться в Enconvo

Агенты для кода могут использовать плагины Enconvo в своих чатах: сообщения вашим агентам Enconvo, создание изображений и видео, память, браузер и управление компьютером. На странице агента в **Настройки → Список агентов**, в **Enconvo Capabilities**:

- Выключите **Enconvo Capabilities**, чтобы держать этого агента в стороне от всех плагинов Enconvo.
- Или нажмите **Настроить** рядом с **Плагины** и выключайте плагины по одному. Выключенный плагин скрыт от этого агента, и его вызовы отклоняются.

Изменение действует и на открытые чаты агента. Чаты агента для кода в Workspace клиента остаются целиком внутри этого Workspace.

## Подключить Grok Bot

Grok Bot работает в облаке xAI. Enconvo отправляет каждое сообщение в рутину Webhook, которую вы делаете в Grok Bot, и показывает ответ в чате, даже если он приходит с опозданием.

1. В Grok Bot создайте рутину с триггером Webhook.
2. Откройте **Grok Bot** в **Настройки → Список агентов**, нажмите **Copy** рядом с **Routine instructions** и вставьте их в рутину.
3. Добавьте URL webhook рутины и ключ как учетные данные на той же странице, затем нажмите **Проверить**. Проверка ждет ответ рутины до примерно 90 секунд.

Пока рутина не подключена, выбор агента показывает Grok Bot как **Не настроено**. Каждое сообщение использует недельное использование вашего плана Grok Bot. **Остановить** только прекращает ожидание Enconvo: запуск рутины идет в облаке, и ответ, который придет позже, все равно добавляется в чат.

Сообщение может быть до 32 000 символов. Приложенные файлы и изображения остаются на Mac; отправляется только текст.

### Пусть Grok Bot вызывает Enconvo

С сервером MCP Enconvo Grok Bot может отвечать в ваши чаты, уведомлять Mac и сопряженные телефоны и просить агента на Mac выполнить задачу.

1. На странице Grok Bot, в **Grok Bot calling Enconvo**, нажмите **Подключить**. Нужно быть вошедшим в учетную запись Enconvo.
2. В Grok Bot откройте **Плагины**, добавьте показанный **Server URL** и войдите в учетную запись Enconvo, когда Grok Bot спросит.

Каждый запрос агенту на Mac ждет вашего одобрения, если вы не включите **Всегда разрешать ask_mac**. Запросы остаются в чате **Grok Bot on this Mac**. Нажмите **Отключить**, чтобы Grok Bot перестал вызывать Enconvo; отключение или уход Mac в офлайн отзывает запрос, который еще ждет.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Чат говорит, что агент не вошел | Откройте страницу агента в **Настройки → Список агентов** и нажмите **Войти снова**. Чат Mavis или приложение, которое вызвало агента, получает ту же ошибку входа, а его задачи доски ждут как **Задержано**, пока вы не войдете. |
| Агент показывает **Не установлено** или слишком старую версию | Нажмите **Установить** или **Обновить** на его странице, затем **Повторить проверку**. |
| Muse Code говорит, что Enconvo нужно обновить | Обновите Enconvo, чтобы работать с более новым Muse Code. |
| Grok Bot показывает **Не настроено** | Добавьте URL webhook рутины и ключ на странице Grok Bot и нажмите **Проверить**. |
| Проверка Grok Bot говорит, что слишком много сообщений | Рутина или Enconvo пока отклоняет слишком много сообщений. Попробуйте позже. |
| Чат Muse Code, открытый в Terminal, не отправляется | Выйдите из Muse Code в Terminal, чтобы вернуть его ходы, затем отправьте из Enconvo. |

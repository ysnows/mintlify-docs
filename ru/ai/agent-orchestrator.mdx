Некоторые задачи требуют больше одного агента: исследователь, чтобы найти факты, автор, чтобы превратить их в пост, программист и рецензент для изменения в коде. Назовите агентов в чате, и агент, с которым вы говорите, станет ведущим. Он составит Рабочий план, даст каждому участнику его задачу и сверит результат с целью. Для постоянной работы [проект](#проекты) объединяет планы, чаты и файлы одной папки.

В видео ниже весь процесс показан меньше чем за 2 минуты: подключение агентов через @, Рабочий план, Доска и проекты.

## Поручите работу нескольким агентам

1. В любом чате введите `@` и начало имени агента, затем нажмите Return, чтобы выбрать его из списка. Добавьте столько агентов, сколько нужно для работы.
2. Опишите, что должен делать каждый, и отправьте сообщение. Например: «@Исследователь найди три факта о бамбуковой роще в Киото, затем @Автор превратит их в короткий пост».
3. Ведущий отвечает Рабочим планом: **Цель**, условия, при которых работа считается выполненной (**Критерий готовности**), то, что в неё не входит, и по одной задаче для каждого участника. Каждая задача получает цель и эти строки дословно. Задача, которой нужен результат другой, ждёт его и начинается с объединённой в неё неслитой работой той задачи.
4. Если план ждёт вас, проверьте его и нажмите **Начать**, **Изменить план** или **Сбросить**. Участники начинают работу, когда вы запускаете план.
5. Когда задачи завершены, карточка плана показывает каждый результат, а ведущий сообщает, достигнута ли цель.

Задачу можно поручить любому из ваших агентов или агентов для написания кода как участнику команды, даже если он не входит в проект. Назовите его в запросе и выберите уровень усилия рассуждений, если хотите, чтобы он думал глубже или отвечал быстрее.

Когда запускается план с Codex, Enconvo сначала запрашивает доступ к папке, чтобы выполнение не остановилось из-за этого, когда вы уже отойдёте.

## Следите за выполняемым планом

Пока план выполняется, строка над чатом показывает его цель, ход выполнения, стоимость и время. Нажмите на неё, чтобы открыть вид выполнения: шаги каждой задачи, что она нашла, какие подтверждения даёт, стоимость по участникам и причину, по которой задача не была выполнена.

Некоторые результаты ждут вас, прежде чем план продолжится. Нажмите **Передать дальше**, чтобы принять удержанный результат или замечание рецензии, или **Вернуть на доработку**, чтобы участник исправил его.

## Прочитайте результат

Когда план завершается, карточка результата начинается с итога и вашего следующего шага. Ниже приведены полные результаты каждой задачи. У задач по коду есть кнопка **Объединить**, а строка называет задачи, которые ещё нужно объединить.

Ведущий проверяет каждую строку **Критерия готовности** и указывает, какие задачи показывают, что он выполнен. Независимая проверка отмечает любое утверждение, которое задачи не подтверждают ясно. Если цель ещё не достигнута, ведущий может продолжить новыми планами для той же цели, до пяти, в рамках одного бюджета.

Ведущий также может предложить до трёх уроков, которые стоит учесть в последующих запусках. Сохраните или отбросьте каждый: в [Память](/ru/ai/memory) попадают только сохранённые.

## Следите за Доской

Нажмите **Доска** вверху чата, чтобы увидеть его задачи в виде карточек. У каждой задачи есть номер, например T-1, и она переходит от **Не начато** к **Выполняется** и затем к **Готово**. В **Требуется ваше участие** собрано всё, что ждёт вашего ответа или подтверждения.

| Элемент | Что делает |
| --- | --- |
| **Все** / **Требуется ваше участие** | Показать все задачи или только те, что ждут вас. |
| **Группировать по** | Сгруппировать карточки, например по идее или по **Чат**. |
| **Отображение** | Изменить, что показывает каждая карточка. |
| **Поиск задач или T-12** | Найти задачу по словам или номеру. |

**Доска** в меню **···** на панели значков боковой панели показывает задачи из всех ваших чатов. Чат с задачами также перечисляет их под своей строкой в боковой панели.

Если раунды проверки и исправления задачи продолжают находить одну и ту же проблему, раунды прекращаются, а не повторяются. Проверка, которую не удалось запустить, сообщает об этом, а не возвращает на доработку рабочий код.

## Проекты

Проект объединяет связанные чаты вокруг одной папки, а файл `AGENTS.md` этой папки становится инструкциями проекта. Нажмите **+** рядом с **Проекты** на боковой панели, чтобы открыть **Создать проект**:

- Введите **Название проекта**, чтобы создать новую папку в Документах, или нажмите **Использовать существующую папку** либо **Клонировать репозиторий**.
- В разделе **Начать с** выберите **Пусто** или команду: **Рабочий стол исследований**, **Студия контента**, **Конструкторы приложений** или **Планировщик поездок**.

### Клонирование репозитория

1. В **Создать проект** нажмите **Клонировать репозиторий**.
2. Вставьте URL GitHub, `owner/name` или любой адрес Git. Если вы вошли в GitHub, можно также выбрать один из своих репозиториев в списке.
3. Нажмите **Клонировать**. Репозиторий копируется в новую папку и открывается как проект.

### Кто выполняет работу

В проекте с участниками ведущий планирует каждую цель, участники её реализуют, а проверка или тест её контролирует. Среди участников могут быть агенты для написания кода, такие как Claude Code и Codex. Каждая задача по коду выполняется в собственной копии кода, а на карточке результата плана есть кнопка **Объединить**, когда вы будете готовы.

Проектом может руководить Claude Code, Codex, Grok Build или Antigravity. При наличии участников ведущий из числа агентов для написания кода планирует их работу в Рабочем плане и читает их результаты, как любой другой ведущий. В проекте без участников он выполняет работу сам в чате, без Рабочего плана и задач на Доске, пока вы не добавите участников.

В чате ведущего проекта можно поручить часть запроса модели по имени, например Opus 5.5, или назвать агента и модель вместе, например Claude Code на Opus 5.5. Ведущий также может запускать субагентов для собственной работы. Проект может выполнять свои цели и задачи через собственные рабочие процессы: см. [Используйте собственные рабочие процессы](/ru/ai/projects).

Участники не могут запускать планы, давать подтверждения, менять настройки, устанавливать программы или использовать ваши входы. Участники из числа агентов для написания кода не могут отправлять изменения, перемещать другие ветки или удалять рабочие деревья: объединяет и отправляет изменения только Enconvo. Полный доступ в чате ведущего проекта и в его задачах работает так же, как в любом другом чате. О Доске, идеях и настройках проекта см. [Проекты и Доска](/ru/ai/projects).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Нажатие Return отправило сообщение вместо выбора агента | Дождитесь появления списка агентов под полем ввода, прежде чем нажимать Return. |
| Задача застряла в **Требуется ваше участие** | Откройте задачу или чат и ответьте на вопрос или подтвердите то, чего она ждёт. |
| Агент для написания кода не запускается | Сначала установите его и войдите. См. [Агенты для написания кода](/ru/ai/coding-agents). |
| План Codex останавливается и запрашивает доступ к папке | Ответьте на вопрос о доступе к папке при запуске плана, чтобы выполнение могло продолжиться без вас. |

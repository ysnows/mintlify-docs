Поиск в интернете даёт агентам актуальные результаты из сети. Искать может каждый агент; службу поиска вы выбираете отдельно от модели, которая пишет ответ.

## Выберите провайдера поиска

1. Откройте **Настройки → Поиск в интернете**.
2. Выберите провайдера. Вариантам Enconvo Cloud ключ API не нужен; для большинства остальных добавьте свой ключ этой службы.
3. Нажмите **Сделать по умолчанию**.

| Провайдер | Примечания |
| --- | --- |
| **Auto** | Ищет собственным поиском модели чата и переходит к другому провайдеру, если у модели его нет. См. [Поиск поиском самой модели](/ru/ai/web-search). |
| **Enconvo Cloud** | Бесплатно для каждой вошедшей учётной записи, ключ API не нужен |
| **DeepSeek (Enconvo Cloud)** | DeepSeek Search через Enconvo Cloud, бесплатно для каждой вошедшей учётной записи |
| **Gemini** | Привязка к Google Search через модель Gemini |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | Поиск со своим ключом этой службы |
| **Parallel** | Поисковый индекс Parallel, который возвращает самые подходящие отрывки каждой страницы, с вашим ключом API Parallel |
| **PipeLLM** | Результаты Google через ваш ключ [PipeLLM](/ru/providers/pipellm) |
| **DeepSeek** | DeepSeek Search с вашим ключом API DeepSeek |
| **xAI X Search** | Ищет посты, профили и ветки X, с ключом API xAI или входом в xAI |
| **xAI X Search (Enconvo Cloud)** | Поиск по X через план Enconvo Cloud |

В списке провайдеров отмечены бесплатные варианты. Полный список — в [Каталоге провайдеров](/ru/providers/catalog). У некоторых моделей также есть встроенная привязка или поиск в настройках их провайдера.

## Поиск поиском самой модели

С **Auto** каждый поиск идёт через веб-поиск модели чата, если он у неё есть: OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai и OpenRouter. Используется ключ или вход, который вы подключили для этой модели, и счёт выставляет её поставщик.

Если у модели нет своего поиска или он не сработал, Auto использует **Резервный поиск** — **Enconvo Cloud**, если вы не выбрали другого провайдера.

| Настройка | Что делает |
| --- | --- |
| **Маршрут поиска** | Показывает, какой поиск работает для модели чата и что происходит при сбое. |
| **Предпочитать поиск модели** | Включено по умолчанию. Выключите, чтобы всегда использовать резервный поиск. |
| **Резервный поиск** | Провайдер, когда у модели нет поиска или он не сработал. |

В чате каждый шаг веб-поиска говорит, какой поиск ответил и почему Auto перешёл на запасной, если перешёл.

## Использование Parallel

1. Получите ключ API на [Parallel](https://platform.parallel.ai).
2. Добавьте его в **Настройки → Управление учётными данными → Parallel**.
3. В **Настройки → Поиск в интернете** выберите **Parallel** и режим поиска:

| Режим поиска | Для чего |
| --- | --- |
| **Turbo** | Самые быстрые ответы. Читает только запросы на английском и японском. |
| **Fast** | Большинство поисков. По умолчанию. |
| **Basic** | Более длинные отрывки с каждой страницы. |
| **Advanced** | Самый глубокий поиск. Занимает около 3 секунд и стоит дороже. |

Parallel списывает каждый поиск с вашей учётной записи Parallel.

## Поиск с агентом

1. Задайте конкретный вопрос. Укажите диапазон дат или место, если это важно.
2. Агент ищет и отвечает со ссылками на источники.
3. Откройте указанные источники и проверьте, что они подтверждают ответ.

## Какая возможность сети нужна

| Нужно | Используйте |
| --- | --- |
| Найти подходящие источники | Поиск в интернете |
| Прочитать известный URL | [Web Fetch](/ru/ai/web-fetch) |
| Открыть результаты в браузере | [Быстрые ссылки](/ru/features/quick-links) |
| Работать с сайтом, где вы вошли | [Browser Use](/ru/features/browser-control) |
| Искать посты, профили или ветки X | Провайдер **xAI X Search** |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| В ответе нет источников | Проверьте, что агент искал, а не ответил только из модели. Попросите искать в интернете. |
| Провайдер сообщает об ошибке | Проверьте учётные данные провайдера и лимит вашей учётной записи у этой службы. |
| Auto использовал резервный поиск | У модели чата нет своего веб-поиска, или он не сработал. Шаг поиска в чате говорит, какой. |
| Результат за входом или на интерактивной странице | Используйте поддерживаемый сценарий браузера, например [Browser Use](/ru/features/browser-control). Чтение публичного URL не даёт доступ к вашей сессии. |

Поиск в интернете даёт вашим Агентам свежие результаты из сети. Искать может каждый Агент; поисковый сервис вы выбираете отдельно от модели, которая пишет ответ.

## Выберите поискового провайдера

1. Откройте **Настройки → Поиск в интернете**.
2. Выберите провайдера. Варианты Enconvo Cloud не требуют API-ключа; для большинства остальных добавьте свой ключ от этого сервиса.
3. Нажмите **Сделать по умолчанию**.

| Провайдер | Примечания |
| --- | --- |
| **Авто** | Ищет с помощью собственного веб-поиска модели чата, а если у модели его нет, переключается на другого провайдера. См. [Поиск с помощью собственного поиска модели](#поиск-с-помощью-собственного-поиска-модели). |
| **Enconvo Cloud** | Бесплатно для каждого вошедшего в систему аккаунта, API-ключ не нужен |
| **DeepSeek (Enconvo Cloud)** | DeepSeek Search через Enconvo Cloud, бесплатно для каждого вошедшего в систему аккаунта |
| **Gemini** | Привязка к Google Search через модель Gemini |
| **Tavily**, **Bing**, **Brave**, **Google Custom**, **Exa** | Поиск с вашим собственным ключом от этого сервиса |
| **Parallel** | Поисковый ИИ-индекс Parallel, который возвращает самые релевантные фрагменты каждой страницы, с вашим API-ключом Parallel |
| **PipeLLM** | Результаты Google с вашим ключом [PipeLLM](/ru/providers/pipellm) |
| **DeepSeek** | DeepSeek Search с вашим API-ключом DeepSeek |
| **xAI X Search** | Ищет посты, профили и ветки в X с API-ключом xAI или входом в xAI |
| **xAI X Search (Enconvo Cloud)** | Поиск в X через тариф Enconvo Cloud |

В списке провайдеров бесплатные варианты отмечены. Полный список см. в [Каталоге провайдеров](/ru/providers/catalog). У некоторых моделей есть также встроенные параметры привязки к поиску в настройках их провайдера.

## Поиск с помощью собственного поиска модели

В режиме **Авто** каждый поиск выполняется с помощью веб-поиска той модели, которую использует чат, если он у неё есть: OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai и OpenRouter. Используется ключ или вход, которые вы подключили для этой модели, а оплату берёт разработчик модели.

Если у модели нет собственного поиска или её поиск не сработал, режим «Авто» использует **Резервный поиск**: это **Enconvo Cloud**, пока вы не выберете другого провайдера.

| Настройка | Что она делает |
| --- | --- |
| **Маршрут поиска** | Показывает, какой поиск выполняется для модели чата и что происходит при сбое. |
| **Предпочитать поиск модели** | По умолчанию включено. Выключите, чтобы всегда использовать резервный поиск. |
| **Резервный поиск** | Провайдер, который используется, если у модели нет поиска или он не сработал. |

В чате каждый шаг веб-поиска сообщает, какой поиск ответил и почему «Авто» переключился на резервный, если это случилось.

## Использование Parallel

1. Получите API-ключ в [Parallel](https://platform.parallel.ai).
2. Добавьте его в **Настройки → Управление учётными данными → Parallel**.
3. В **Настройки → Поиск в интернете** выберите **Parallel** и укажите **Режим поиска**:

| Режим поиска | Для чего |
| --- | --- |
| **Turbo** | Самые быстрые ответы. Читает только запросы на английском и японском. |
| **Быстро** | Для большинства поисков. По умолчанию. |
| **Базовый** | Более длинные фрагменты с каждой страницы. |
| **Дополнительно** | Самый глубокий поиск. Занимает около 3 секунд и стоит дороже. |

Parallel списывает плату за каждый поиск с вашего аккаунта Parallel.

## Поиск с помощью Агента

1. Задайте конкретный вопрос. Если это важно, укажите период или место.
2. Агент ищет и отвечает со ссылками на свои источники.
3. Откройте указанные источники и убедитесь, что они подтверждают ответ.

## Выберите подходящую веб-возможность

| Что нужно | Что использовать |
| --- | --- |
| Найти подходящие источники | Поиск в интернете |
| Прочитать известный URL | [Загрузка веб-страницы](/ru/ai/web-fetch) |
| Открыть результаты в браузере | [Быстрые ссылки](/ru/features/quick-links) |
| Работать с сайтом, где вы вошли в аккаунт | [Browser Use](/ru/features/browser-control) |
| Искать посты, профили или ветки в X | Провайдер **xAI X Search** |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| В ответе нет источников | Проверьте, что Агент выполнил поиск, а не ответил только на основе модели. Попросите его поискать в интернете. |
| Провайдер сообщает об ошибке | Проверьте учётные данные провайдера и лимит вашего аккаунта в этом сервисе. |
| «Авто» использовал резервный поиск | У модели чата нет собственного веб-поиска, или её поиск не сработал. Шаг поиска в чате показывает, что именно. |
| Результат находится за входом в аккаунт или на интерактивной странице | Используйте поддерживаемый сценарий работы в браузере, например [Browser Use](/ru/features/browser-control). Загрузка публичного URL не даёт доступа к вашему сеансу с входом в аккаунт. |

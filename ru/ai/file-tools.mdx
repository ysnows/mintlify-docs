Инструменты для файлов позволяют Агенту находить файлы, искать внутри них, читать и редактировать их. Укажите Агенту папку или файл и просите простыми словами; он выберет подходящий инструмент и покажет, чем воспользовался.

## Прежде чем начать

- **Рабочая папка:** **Рабочая папка** Агента в части **Определение** его настроек — это место, от которого отсчитываются относительные пути.
- **Одобрения:** метка **Разрешения** в чате определяет, когда Агент сначала спрашивает. При **Запросить одобрение** он спрашивает, прежде чем редактировать файлы вне рабочей папки. Чтение и поиск никогда не требуют вопроса. См. [Одобрение действий](/ru/ai/agents).

## Начните с задачи только для чтения

1. В настройках Агента проверьте его инструменты для файлов и **Рабочую папку**.
2. В чате назовите папку или прикрепите нужный файл.
3. Задайте ограниченный вопрос, например: «Найди файлы Markdown в этом проекте и кратко опиши README».
4. Прежде чем просить Агента что-либо изменить, посмотрите на файлы и вывод инструментов, которые он использовал.

## Что делает каждый инструмент

| Инструмент | Что он делает |
| --- | --- |
| Glob | Находит файлы по шаблону пути, например `**/*.md`, сначала самые новые |
| Grep | Ищет текст внутри файлов, с шаблонами файлов и номерами строк |
| Read File | Читает текстовые файлы, извлекает текст из документов и читает изображения, аудио и видео |
| Edit File | Заменяет точный текст в файле и сообщает, какие строки изменены |
| Write File | Создаёт файл или заменяет всё его содержимое |

<Warning>
Write File может перезаписать существующий файл без предупреждения. Для важных документов храните копию или используйте систему контроля версий и проверяйте место назначения и изменение, прежде чем одобрить его. Файлы, изменённые Агентом в чате, перечислены на вкладке **Изменения** боковой панели с кнопкой **Отменить**.
</Warning>

## Документы и медиа

При чтении PDF, документа Office, изображения, аудиофайла или видео может запускаться разбор, OCR или транскрибирование вместо возврата необработанных байтов. Для аудио и видео Агент читает расшифровку. В таблице ячейка с формулой читается как её значение или как сама формула, если она ни разу не вычислялась. Какие форматы работают, зависит от установленных инструментов и настроенных вами провайдеров. См. [OCR](/ru/ai/ocr), [Транскрибирование](/ru/features/transcription) и [База знаний](/ru/ai/knowledge-base).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Ошибка доступа | Проверьте **Рабочую папку** Агента, метку **Разрешения** и разрешения macOS |
| Документ читается как пустой | Проверьте тип файла и возможность его разбора. Отсканированному PDF может понадобиться OCR |
| Правка не находит текст, который нужно заменить | Попросите Агента снова прочитать текущий файл, прежде чем редактировать |

Инструменты файлов позволяют агенту находить файлы, искать в них, читать и править. Укажите агенту папку или файл и попросите обычными словами: он сам выберет инструмент и покажет, чем пользовался.

## Перед началом

- **Рабочая папка:** **Рабочая папка** агента в разделе **Определение** его настроек — начало относительных путей.
- **Одобрения:** чип **Разрешения** в чате решает, когда агент спрашивает заранее. С **Запросить одобрение** он спрашивает перед правкой файлов вне рабочей папки. Чтение и поиск никогда не спрашивают. См. [Одобрение действий](/ru/ai/agents).

## Начните с задачи только на чтение

1. В настройках агента проверьте инструменты файлов и **Рабочую папку**.
2. В чате назовите папку или приложите файл, с которым нужно работать.
3. Задайте ограниченный вопрос, например: «Найди файлы Markdown в этом проекте и кратко перескажи README».
4. Посмотрите файлы и вывод инструментов, которыми агент пользовался, прежде чем просить что-то менять.

## Что делает каждый инструмент

| Инструмент | Что делает |
| --- | --- |
| Glob | Находит файлы по шаблону пути, например `**/*.md`, сначала новые |
| Grep | Ищет текст внутри файлов, с шаблонами файлов и номерами строк |
| Read File | Читает текстовые файлы, извлекает текст из документов и читает изображения, аудио и видео |
| Edit File | Заменяет точный текст в файле и сообщает изменённые строки |
| Write File | Создаёт файл или заменяет всё его содержимое |

<Warning>
Write File может перезаписать существующий файл без предупреждения. Для важных документов храните копию или пользуйтесь системой версий и проверяйте назначение и изменение, прежде чем одобрять. Файлы, которые агент меняет в чате, перечислены на вкладке **Изменения** боковой панели, с **Отменить**.
</Warning>

## Документы и медиа

Чтение PDF, документа Office, изображения, аудио или видео может запускать разбор, OCR или транскрибирование вместо возврата сырых байтов. Для аудио и видео агент читает расшифровку. В таблице ячейка с формулой читается как значение или как сама формула, если она никогда не считалась. Какие форматы работают, зависит от установленных инструментов и настроенных провайдеров. См. [OCR](/ru/ai/ocr), [Транскрибирование](/ru/features/transcription) и [База знаний](/ru/ai/knowledge-base).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Ошибка доступа | Проверьте **Рабочую папку** агента, чип **Разрешения** и разрешения macOS |
| Документ читается пустым | Проверьте тип файла и можно ли его разобрать. Сканированному PDF может понадобиться OCR |
| Правка не находит текст для замены | Попросите агента снова прочитать текущий файл, прежде чем править |

У каждой голосовой функции Enconvo есть собственная настройка модели распознавания речи, поэтому для Диктовки можно выбрать быструю потоковую модель, а для длинных файлов — другую. Выбирайте модель в той функции, которой вы действительно пользуетесь.

| Функция | Где настраивается | Руководство |
| --- | --- | --- |
| Речь, набираемая как текст | **Настройки → Модели диктовки** | [Диктовка](/ru/features/dictation) |
| Голосовая команда | **Настройки → Голосовая команда → Слушать** | [Голосовая команда](/ru/features/dictation) |
| Звонки Live Talk | **Настройки → Live Talk → Слушать** | [Live Talk](/ru/features/live-voice) |
| Запись встречи или лекции | **Настройки → Модели записи** | [Запись встречи](/ru/features/meeting-recording) |
| Существующий аудио- или видеофайл | **Настройки → Модели транскрибирования** | [Транскрибирование](/ru/features/transcription) |
| Субтитры в реальном времени | **Настройки → Модель создания субтитров** | [Субтитры в реальном времени](/ru/features/live-captioning) |

## Выбор модели

1. Откройте настройку нужной функции из таблицы выше.
2. На странице моделей Диктовки, записи, транскрибирования или субтитров отфильтруйте список с помощью **Все**, **Enconvo Cloud**, **Локально** или **Пользовательские провайдеры**. В Голосовой команде и Live Talk раздел **Слушать** сначала показывает рекомендуемые модели, затем любые другие модели распознавания речи.
3. Выберите модель, затем просмотрите её параметры языка и модели.

Модели **Enconvo Cloud** используют вашу учётную запись Enconvo, ключ API не нужен. **Enconvo Cloud Fast**, собственное распознавание речи Enconvo Cloud, бесплатно для всех и помечено зелёным значком **Бесплатно**. **Пользовательские провайдеры** используют ваш собственный ключ API у этого провайдера. **Локальные** модели (MLX и Core ML) распознают речь на вашем Mac, как только их модель загружена.

В [каталоге провайдеров распознавания речи](/ru/providers/catalog) перечислены все заявленные провайдеры, включая облачные сервисы и локальные варианты Parakeet, Qwen, Whisper, SenseVoice, Paraformer и Nemotron. Оборудование и доступность зависят от среды выполнения и вашей сборки.

## Примечательные модели

| Модель | Что нужно знать |
| --- | --- |
| ElevenLabs Scribe v3 Live | Выдаёт первые слова меньше чем за секунду, с меньшим числом ошибок в китайском и при шумном звуке. Используйте её для Диктовки и голосового ввода с вашим ключом API ElevenLabs или через Enconvo Cloud. Китайский и японский выводятся без пробелов между словами. Live Talk использует её, когда Live Talk работает на ElevenLabs. |
| ElevenLabs Scribe v3 | Транскрибирует файлы с вашим ключом API ElevenLabs или через Enconvo Cloud. |
| Enconvo Cloud Fast | Бесплатно. Её модель реального времени показывает ваши слова по мере речи, а асинхронная модель транскрибирует записанные файлы. |
| Soniox | Использует модели Soniox v6 в Диктовке, записи, транскрибировании, субтитрах, Live Talk и субтитрах конференций. Выбранная ранее модель v5 автоматически переходит на v6; Soniox прекращает поддержку v5 15 декабря 2026 года. |
| DeepSeek | Транскрибирует для Транскрибирования и Диктовки с вашим собственным ключом API DeepSeek или как **DeepSeek (Enconvo Cloud)** без ключа. Сам определяет 21 язык. |
| Fluid Speech Pro от FluidVoice | Работает на вашем Mac и iPhone и транскрибирует 25 европейских языков без интернета, с меньшим числом ошибок, чем Parakeet, вживую по мере речи или после её окончания. Требуется macOS 15 или iOS 18 и новее. |

## Подбор модели под задачу

| Возможность | Что нужно знать |
| --- | --- |
| Потоковая обработка | Выдаёт промежуточный текст, пока вы говорите. Используйте модель реального времени, если хотите, чтобы слова появлялись по мере речи. |
| Пакетное транскрибирование | Обрабатывает файл после записи или загрузки. |
| Подсказки языка и ключевые слова | Помогают распознаванию, если провайдер их поддерживает. |
| Разделение говорящих | Разделяет голоса. Не гарантирует правильное имя человека. |
| Перевод в реальном времени | Доступен только у некоторых провайдеров и моделей, с исходным и целевым языками. |
| Временные метки и структурированный вывод | Зависят от провайдера и формата вывода транскрибирования. |

## Проверка на коротком образце

Запишите короткий образец с языком, микрофоном и терминами, которыми вы действительно пользуетесь, и проверьте его, прежде чем обрабатывать длинную встречу. Если не получилось, прочитайте ошибку: в ней будут сведения о размере файла, формате, извлечении звука, учётной записи или сети.

Загрузки локальных моделей могут быть намного больше самого приложения. Проверьте фактический размер загрузки и свободное место: не всем локальным моделям распознавания речи нужно одинаково много.

---
title: "Распознавание речи"
description: "Выберите речевую модель для каждой голосовой функции: Enconvo Cloud, свой ключ или модель на Mac."
---

У каждой голосовой функции Enconvo своя настройка речевой модели, поэтому для Диктовки можно взять быструю потоковую модель, а для длинных файлов — другую. Выбирайте модель в той функции, которой реально пользуетесь.

| Функция | Где задать | Руководство |
| --- | --- | --- |
| Речь, набранная как текст | **Настройки → Модели диктовки** | [Диктовка](/ru/features/dictation) |
| Голосовая команда | **Настройки → Голосовая команда → Слушать** | [Голосовая команда](/ru/features/dictation) |
| Звонки Live Talk | **Настройки → Live Talk → Слушать** | [Live Talk](/ru/features/live-voice) |
| Запись встречи или лекции | **Настройки → Модели записи** | [Запись встречи](/ru/features/meeting-recording) |
| Уже существующий аудио- или видеофайл | **Настройки → Модели транскрибирования** | [Транскрибирование](/ru/features/transcription) |
| Субтитры в реальном времени | **Настройки → Модель создания субтитров** | [Субтитры в реальном времени](/ru/features/live-captioning) |

## Выбрать модель

1. Откройте настройку своей функции из таблицы выше.
2. На странице модели Диктовки, Записи, Транскрибирования или субтитров отфильтруйте список: **Все**, **Enconvo Cloud**, **Локально** или **Пользовательские провайдеры**. В Голосовой команде и Live Talk раздел **Слушать** сначала показывает рекомендуемые модели, затем любую другую речевую модель.
3. Выберите модель и проверьте её язык и параметры модели.

Модели **Enconvo Cloud** используют учётную запись Enconvo, без ключа API. **Enconvo Cloud Fast**, собственное распознавание речи Enconvo Cloud, бесплатно для всех и показывает зелёную метку **Бесплатно**. **Пользовательские провайдеры** используют ваш ключ API у этого провайдера. **Локально** (MLX и Core ML) распознаёт речь на Mac после загрузки модели.

[Каталог речевых провайдеров](/ru/providers/catalog) перечисляет каждого объявленного провайдера, включая облачные службы и локальные варианты Parakeet, Qwen, Whisper, SenseVoice, Paraformer и Nemotron. Оборудование и доступность зависят от среды выполнения и сборки.

Используйте для Диктовки и Голосового ввода со своим ключом API ElevenLabs или через Enconvo Cloud. Китайский и японский выходят без пробелов между словами. Live Talk использует её, когда Live Talk работает через ElevenLabs. |
| ElevenLabs Scribe v3 | Транскрибирует файлы, со своим ключом API ElevenLabs или через Enconvo Cloud. |
| Enconvo Cloud Fast | Бесплатно. Её модель реального времени показывает слова по мере речи, а асинхронная транскрибирует записанные файлы. |
| Soniox | Использует модели Soniox v6 в Диктовке, Записи, Транскрибировании, субтитрах, Live Talk и субтитрах конференций. Модель v5, выбранная раньше, переходит на v6 сама; Soniox снимает v5 15 декабря 2026 года. |
| DeepSeek | Транскрибирует для Транскрибирования и Диктовки, со своим ключом API DeepSeek или как **DeepSeek (Enconvo Cloud)** без ключа. Сам определяет 21 язык. |
| Fluid Speech Pro by FluidVoice | Работает на Mac и iPhone и транскрибирует 25 европейских языков без сети, с меньшим числом ошибок, чем Parakeet, вживую или после окончания речи. Нужны macOS 15 или iOS 18 и новее. |

## Подобрать модель под задачу

| Возможность | Что знать |
| --- | --- |
| Поток | Выдаёт частичный текст, пока вы говорите. Берите модель реального времени, когда слова должны появляться по ходу речи. |
| Пакетное транскрибирование | Обрабатывает файл после записи или загрузки. |
| Подсказки языка и горячие слова | Направляют распознавание, если провайдер их поддерживает. |
| Разделение говорящих | Разделяет голоса. Не гарантирует правильное имя человека. |
| Перевод вживую | Есть только у части провайдеров и моделей, с исходным и целевым языками. |
| Временные метки и структурированный вывод | Зависят от провайдера и формата вывода транскрибирования. |

## Проверить на коротком образце

Запишите короткий образец на том языке, с тем микрофоном и теми терминами, которыми реально пользуетесь, и проверьте его, прежде чем обрабатывать длинную встречу. Если не получилось, прочитайте ошибку: размер файла, формат, извлечение, учётная запись или сеть.

Загрузки локальных моделей могут быть намного больше самого приложения. Проверьте фактический размер загрузки и свободное место: не всем локальным речевым моделям нужно одно и то же.

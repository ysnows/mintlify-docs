Чаты на телефоне — это собственные чаты приложения для iPhone. Они выполняются на телефоне, а не на вашем Mac, поэтому работают и без Mac в паре. Каждый чат на телефоне использует модель через баллы Enconvo Cloud, ваш собственный ключ API или тариф, на который вы входите на iPhone. Чаты на телефоне и личные инструкции синхронизируются через ваш аккаунт Enconvo.

Чтобы продолжить чат, который выполняется на вашем Mac, см. [Приложение для iPhone](/ru/integrations/iphone-app).

## Выбор модели по умолчанию

1. На iPhone откройте **Настройки → AI-модель**.
2. Нажмите **Модель по умолчанию** и выберите модель. Новые чаты начинаются с неё.
3. Чтобы сменить модель одного чата, используйте выбор модели в этом чате.

Enconvo на вашем Mac начинает с той же модели, если на Mac есть этот провайдер. Если модели Mac нет на iPhone, страница сообщает об этом в разделе **Модель по умолчанию** и подсказывает, что добавить или куда войти.

## Добавление ключа или провайдера

В **AI-модель** перечислены Enconvo Cloud и все провайдеры, которыми можно пользоваться на телефоне, включая PipeLLM.

1. Нажмите на провайдера, затем **Добавить ключ API** и вставьте ключ, созданный на сайте провайдера.
2. Чтобы добавить провайдера, которого нет в списке, нажмите **Добавить провайдера** и выберите провайдера, **Совместимо с OpenAI** или **Совместимо с Anthropic**. Для совместимого провайдера нужен адрес сервера, который понимает API Chat Completions или Responses от OpenAI либо API Messages от Anthropic.
3. Если у провайдера нет нужной вам модели, нажмите **Добавить модель по ID** на его странице.

Ключи хранятся в вашей связке ключей iCloud и отправляются только тому провайдеру, которому принадлежат.

## Вход через тариф

Пять провайдеров позволяют чатам на телефоне пользоваться тарифом, за который вы уже платите, без ключа API и без баллов Cloud:

| Провайдер | Тариф | Кнопка |
| --- | --- | --- |
| OpenAI | ChatGPT | **Войти через ChatGPT** |
| xAI | Grok | **Войти через Grok** |
| Mistral | Le Chat | **Войти через Mistral** |
| GitHub Copilot | Copilot | **Войти через GitHub** |
| Antigravity | Antigravity (Google) | **Войти через Google** |

<Steps>
  <Step title="Откройте провайдера">
    В **Настройки → AI-модель** нажмите на провайдера. Для OpenAI, xAI и Mistral выберите карточку тарифа в разделе **Аутентификация**. Другая карточка — **Ключ API**, а **Используется** отмечает ту, которой сейчас пользуются чаты на телефоне.
  </Step>
  <Step title="Войдите">
    Нажмите кнопку входа и завершите вход на открывшейся странице. Используйте аккаунт, в котором есть тариф.
  </Step>
  <Step title="Проверьте результат">
    Вернувшись на страницу провайдера, вы увидите свой тариф, свой аккаунт и количество моделей в вашем тарифе. Выберите модель или нажмите **Сделать по умолчанию**, чтобы новые чаты начинались с неё.
  </Step>
</Steps>

Вход через тариф остаётся на этом iPhone. Он не синхронизируется с iCloud или вашим Mac, а Mac хранит собственный вход. Действуют собственные лимиты использования тарифа.

### GitHub Copilot

После **Войти через GitHub** приложение показывает код GitHub. **Продолжить** копирует код и открывает страницу GitHub, где вы вставляете его и разрешаете Enconvo. Код остаётся на экране, пока открыта страница GitHub, так что его можно скопировать снова.

В списке моделей показаны только модели, доступные в вашем тарифе Copilot. Copilot Free предлагает меньше моделей, чем платные тарифы.

### Antigravity

Перед каждым входом приложение показывает **Перед входом в Antigravity**. Enconvo входит через собственного клиента Google приложения Antigravity, а Google может заблокировать аккаунт Antigravity, который используется вне Antigravity. Используйте аккаунт, которого не жалко потерять. **Принять** переходит ко входу Google, а **Отменить** оставляет всё как было.

Antigravity предлагает модели Gemini и Claude из вашего тарифа, каждую с уровнями усилия рассуждения, которые Antigravity для неё предусмотрел.

### Использование ChatGPT

Страница OpenAI показывает, сколько осталось от лимитов вашего тарифа ChatGPT за 5 часов и за неделю, когда сбрасывается каждый лимит и когда тариф продлевается. Нажмите **Обновить сведения об использовании** в меню аккаунта, чтобы обновить. Когда лимит исчерпан, страница сообщает об этом до его сброса.

### Выход

Откройте провайдера и выберите **Выйти** в меню аккаунта. Чатам, которые используют тариф, после выхода понадобится другая модель. Для Mistral ключ, созданный при входе, остаётся в вашем рабочем пространстве Mistral.

## Ответы продолжаются после выхода из приложения

С моделью Enconvo Cloud ответ может продолжаться после того, как вы вышли из приложения или заблокировали телефон. В **Облачные инструменты** поля сообщения включите **Запуск в облаке**. Чаты на ваших собственных ключах всегда отвечают на телефоне.

## Продолжение на компьютере

Перенесите чат на телефоне на компьютер в паре, чтобы продолжить там с агентом, файлами и инструментами этого компьютера. Это работает, даже пока ответ ещё выполняется.

1. Откройте меню чата или удерживайте чат на боковой панели и выберите **Продолжить на компьютере**. В меню назван компьютер, на который он переносится по умолчанию.
2. Выберите компьютер и агента и подтвердите.

Чат переносится на тот компьютер и продолжается там. Открытие ссылки на общий чат тоже спрашивает, где его продолжить.

## Голосовой чат с кнопки действия

Когда кнопка действия запускает голосовой чат, Dynamic Island спрашивает **Разрешить Enconvo видеть экран?** Выберите **Только голос** или **Показать экран**, чтобы Enconvo видел то, что вы читаете. Кнопка **Показать экран** в элементах управления звонком начинает или прекращает показ посреди звонка.

## Усилие рассуждения

Когда вы выбираете модель, которая рассуждает, выбор переходит к её уровням усилия рассуждения. Выбранное для модели усилие показано рядом с её провайдером в заголовке чата и применяется ко всем чатам с этой моделью. На странице тарифа перечислены только уровни, которые предлагает ваш тариф.

## Длинные чаты

Когда длинный чат приближается к контекстному окну модели, та же модель сжимает более старые сообщения, как на Mac. Чат сохраняет каждое сообщение, а отметка **Контекст сжат** показывает, где начинается сводка. Это всегда включено.

## Устранение неполадок

| Что вы видите | Что делать |
| --- | --- |
| **Не удалось завершить вход в ChatGPT** (или Grok, Mistral, GitHub Copilot, Antigravity) | Нажмите **Войти снова** и завершите вход на открывшейся странице. |
| **Ваш тариф не предлагает** модель | Выберите другую модель из списка тарифа. В Copilot Free предлагаются только некоторые модели. |
| **Загрузка списка моделей…** не заканчивается | Проверьте подключение iPhone к сети, затем выйдите со страницы провайдера и откройте её снова. |
| Модели Mac по умолчанию нет на iPhone | Добавьте ключ провайдера или войдите в его тариф, как подсказывает заметка в разделе **Модель по умолчанию**. |

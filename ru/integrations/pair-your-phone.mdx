---
title: "Пара с вашим телефоном"
description: "Создайте пару приложения Enconvo для iPhone или Android с Mac, ПК с Windows, настольным Linux или сервером Linux, у которого есть только терминал."
---

Приложение Enconvo на телефоне создаёт пару с каждым из ваших компьютеров, и их проекты и чаты оказываются на телефоне. Чат, который вы открываете с телефона, продолжает выполняться на том компьютере, с его файлами, приложениями и агентами. Телефон связывается с компьютером через ретранслятор Enconvo, а сообщения защищены сквозным шифрованием. Когда телефон и компьютер находятся в одной сети, приложение подключается к нему напрямую, поэтому дома или в офисе оно подключается и отвечает быстрее.

Каждый компьютер создаёт пару с телефоном отдельно. Пара из двух компьютеров (например, ноутбука с Linux и вашего Mac) не добавляет ни один из них на телефон: создайте пару телефона с каждым компьютером, которым хотите пользоваться с него.

## Перед началом

- **Скачайте приложение.** iPhone: [TestFlight](https://testflight.apple.com/join/MJQuEN28). Android: Google Play или APK. В **Скачать мобильное приложение** в **Настройки → Подключения** на вашем компьютере есть код загрузки для каждого; кнопка **Скачать мобильное приложение** плагина Mobile Companion открывает его тоже.
- **Используйте один аккаунт.** Войдите в приложение на телефоне и на компьютере в один и тот же аккаунт Enconvo. Создать пару могут только телефоны вашего аккаунта. Бесплатный аккаунт тоже может создать пару и пользоваться с телефона чатами компьютера и Удалённым экраном.
- **Держите компьютер включённым с запущенным Enconvo.** Телефон связывается с компьютером, только пока на нём работает Enconvo.

## Mac, Windows или настольный Linux

На всех трёх шаги одинаковые.

<Steps>
  <Step title="Покажите код создания пары на компьютере">
    Нажмите переключатель устройств внизу боковой панели, затем **Добавить устройство → Создать пару с телефоном**. Или откройте **Настройки → Подключения** и выберите **Показать код создания пары**. Появится QR-код. Он работает один раз и действует пять минут.
  </Step>
  <Step title="Отсканируйте его телефоном">
    В приложении Enconvo откройте **Удалённый доступ**, нажмите **Создать пару с компьютером** и наведите камеру на код. Можно также отсканировать его камерой iPhone, камерой Android или Google Lens: код открывает Enconvo, и вы подтверждаете компьютер там. Если приложение ещё не установлено, ссылка из кода поможет установить его, а затем создать пару.
  </Step>
  <Step title="Пользуйтесь компьютером с телефона">
    Пара создаётся за мгновение, и телефон показывает компьютер. Если подключено несколько компьютеров, переключайтесь между ними в разделе **Удалённый доступ**.
  </Step>
</Steps>

Если срок действия кода истёк, выберите **Показать новый код** и отсканируйте снова.

## Сервер Linux, у которого есть только терминал

У сервера нет окна для показа кода, поэтому его выводит командная строка. Для этого нужен Enconvo 2.5.15 Beta 1 или новее. Сначала выполните [Установку на сервер](/ru/getting-started/linux).

<Steps>
  <Step title="Войдите на сервере">
    ```bash
    enconvo login
    ```
    Подтвердите выведенный код на `enconvo.com/device`.
  </Step>
  <Step title="Держите Enconvo запущенным">
    ```bash
    enconvo service install
    ```
    Телефон связывается с сервером, только пока на нём работает Enconvo.
  </Step>
  <Step title="Выведите код создания пары">
    ```bash
    enconvo companion pair --phone
    ```
    Он рисует QR-код в терминале, под ним даёт ссылку и сообщает, когда код истечёт. Код работает один раз и действует пять минут.
  </Step>
  <Step title="Отсканируйте его или откройте ссылку">
    Отсканируйте код камерой телефона или откройте ссылку на телефоне. Подтвердите в приложении Enconvo, и сервер появится на телефоне.
  </Step>
</Steps>

- **По SSH**: код рисуется в вашем собственном терминале, так что работает и по SSH. Если строки переносятся, расширьте окно или откройте ссылку.
- **Вход**: код, набранный в вашем собственном терминале, ещё и выполняет вход в приложение на телефоне, поэтому отправляйте его только на свой телефон. Вывод, переданный по конвейеру или сохранённый, а также команда, которую запускает агент, печатают только ссылку, которая вход в приложение не выполняет: сначала войдите в приложение в тот же аккаунт.
- **Срок истёк**: запустите `enconvo companion pair --phone` снова.

## Управление телефонами в паре

**Настройки → Подключения** на каждом компьютере перечисляют его телефоны в паре.

| Чтобы | Сделайте так |
|---|---|
| Создать пару с другим телефоном | Покажите новый код и отсканируйте его этим телефоном. У компьютера может быть до 10 телефонов в паре. |
| Переименовать телефон | Нажмите на телефон, затем **Переименовать телефон** рядом с его названием. |
| Удалить телефон | Выберите **Удалить** рядом с ним. Этот телефон больше не сможет связаться с этим компьютером. |
| Начать заново | Выберите **Сбросить подключение**. Все телефоны удаляются, и им нужно создать пару заново. |

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Компьютера нет на телефоне | Создайте пару телефона именно с этим компьютером. Пара с другим компьютером его не добавляет. |
| **Срок действия этого кода истёк** | Покажите новый код или запустите команду снова и отсканируйте в течение пяти минут. |
| **Войдите, чтобы подключить телефон** | Войдите в Enconvo на компьютере. На сервере выполните `enconvo login`. |
| Сервер сообщает, что вход не выполнен | Выполните `enconvo login`, затем снова `enconvo companion pair --phone`. |
| Телефон показывает сервер как не в сети | Проверьте, что на нём запущен Enconvo: `enconvo service install`, а также `sudo loginctl enable-linger "$USER"`, если он останавливается при выходе из системы. |

Встроенные возможности сгруппированы ниже по задаче, которую они поддерживают. Доступность зависит от установленных расширений и сборки приложения. Реализации провайдеров перечислены отдельно в [каталоге возможностей провайдеров](/ru/providers/catalog).

Используйте SmartBar, чтобы найти команду по названию. Откройте **Настройки → Плагины**, чтобы посмотреть установленные расширения и настройки их команд. Инструменты агента можно выбрать в настройках агента, а не как отдельные команды запуска.

## Вспомогательные сервисы

Некоторые расширения дают инфраструктуру, а не команду, которую вы запускаете напрямую: Local API, конфигурацию, маршрутизацию учетных данных, разбор документов, среды моделей, хранение сообщений, индексацию поиска, управление плагинами и доставку в каналы. Используйте руководство задачи для возможности, которую они поддерживают, или [CLI и Local API](/ru/advanced/cli-local-api) для интеграции.

Mobile Companion соединяет приложение Enconvo для iPhone (бета) с Mac; см. [Приложение для iPhone](/ru/integrations/iphone-app), чтобы связать телефон. Для доступа через мессенджеры используйте [каналы мессенджеров](/ru/integrations/messaging).

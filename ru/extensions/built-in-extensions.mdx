Встроенные возможности сгруппированы ниже по задачам, которые они решают. Доступность зависит от установленных расширений и сборки приложения. Реализации провайдеров перечислены отдельно в [Каталоге возможностей провайдеров](/ru/providers/catalog).

Используйте SmartBar, чтобы найти команду по названию. Откройте **Настройки → Плагины**, чтобы просмотреть установленные расширения и настройки их команд. Инструменты Агента могут выбираться в настройках Агента и не появляться как отдельные команды запуска.

## Вспомогательные сервисы

Некоторые расширения предоставляют инфраструктуру, а не команду, которую вы запускаете напрямую: локальные API, конфигурацию, маршрутизацию учётных данных, разбор документов, среды выполнения моделей, хранение сообщений, индексацию поиска, управление плагинами и доставку через каналы. Используйте руководство по задаче для функции, которую они поддерживают, или [CLI и локальные API](/ru/advanced/cli-local-api) для интеграции.

Мобильный Companion подключает приложение Enconvo для iPhone (бета) к вашему Mac; чтобы подключить телефон, смотрите [Приложение для iPhone](/ru/integrations/iphone-app). Для доступа через мессенджеры используйте [Каналы мессенджеров](/ru/integrations/messaging).

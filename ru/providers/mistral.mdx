---
title: "Mistral AI"
description: "Общайтесь с моделями Mistral в Enconvo с помощью ключа API Mistral или вашего аккаунта Mistral."
---

Используйте модели Mistral в чатах, Агентах и AI Commands. Вставьте ключ API Mistral или войдите в свой аккаунт Mistral, и Enconvo создаст ключ за вас. В обоих случаях Mistral выставляет счёт за использование на ваш аккаунт.

## Подключение

<Tabs>
  <Tab title="Вход через Mistral">
    <Steps>
      <Step title="Откройте провайдера">
        Откройте **Настройки → AI-модель → Mistral AI**.
      </Step>
      <Step title="Войдите">
        В разделе **Аутентификация** выберите вход через аккаунт Mistral и нажмите **Подключить**. Войдите в свой аккаунт Mistral и выберите рабочее пространство. Вход работает так же, как вход в Mistral Vibe: он создаёт ключ API для этого рабочего пространства, так что ничего копировать не нужно.
      </Step>
      <Step title="Выберите модель">
        Выберите модель в поле **Название модели** и отправьте короткое сообщение.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Использовать ключ API">
    <Steps>
      <Step title="Получите ключ API">
        Создайте ключ в [консоли Mistral](https://console.mistral.ai/api-keys/).
      </Step>
      <Step title="Добавьте его в Enconvo">
        Откройте **Настройки → AI-модель → Mistral AI**. В разделе **Аутентификация** вставьте ключ в поле **Ключ API** и нажмите **Проверить**.
      </Step>
      <Step title="Выберите модель">
        Выберите модель в поле **Название модели** и отправьте короткое сообщение.
      </Step>
    </Steps>
  </Tab>
</Tabs>

После входа карточка аккаунта показывает ваш тариф, ключ и остаток лимитов в минуту.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Название модели** | Модель, которую использует этот провайдер. Кнопка **Обновить** рядом с ней перезагружает список, а **Управление моделями** (шестерёнка) добавляет или восстанавливает модели. |
| **Глубина рассуждений** (в чате) | Для Mistral Large 4, Medium 3.5 и Small 4: **Нет** отвечает без рассуждений, **Высокий** сначала думает. Large 4 думает по умолчанию. |

Транскрибирование Voxtral и Mistral OCR могут использовать тот же вход или ключ.

## На iPhone

Приложение для iPhone тоже может использовать ваш тариф Le Chat в чатах на телефоне. На iPhone откройте **Настройки → AI-модель → Mistral**, выберите карточку Le Chat в разделе **Аутентификация** и нажмите **Войти через Mistral**. См. [Чаты на телефоне](/ru/integrations/iphone-phone-chats).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Вставьте ключ целиком ещё раз и убедитесь, что он активен в консоли Mistral. |
| Вход перестал работать | Откройте меню карточки аккаунта и нажмите **Переподключить**. |
| Нет нужной модели | Нажмите **Обновить** рядом с полем **Название модели**. Чтобы добавить модель самостоятельно, воспользуйтесь **Управлением моделями**. |
| Ошибки лимита запросов | Минутный лимит вашего рабочего пространства исчерпан. Подождите минуту или проверьте лимиты в консоли Mistral. |

title: "Soniox"
description: "Используйте распознавание речи Soniox для диктовки, записей и транскрибирования файлов в Enconvo."
---

Soniox превращает речь в текст в реальном времени и из файлов на многих языках и может переводить субтитры по ходу записи. Используйте его через Enconvo Cloud без ключа или со своим ключом API Soniox.

<Note>
**Soniox (Enconvo Cloud)** не требует ключа API, а диктовка через Soniox бесплатна для участников с тарифом Cloud Plan, Lifetime и пробным периодом.
</Note>

## Подключение

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="Выберите провайдера">
        Откройте **Настройки → Модели диктовки** и выберите **Soniox (Enconvo Cloud)**.
      </Step>
      <Step title="Проверьте работу">
        Продиктуйте короткую фразу. Текст должен появляться по мере речи.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Свой ключ API">
    <Steps>
      <Step title="Получите ключ API">
        В [консоли Soniox](https://console.soniox.com) откройте свой проект и создайте ключ API.
      </Step>
      <Step title="Добавьте его в Enconvo">
        Откройте **Настройки → Модели диктовки** и выберите **Soniox**. Вставьте ключ в учётные данные Soniox и нажмите **Проверить**.
      </Step>
      <Step title="Проверьте работу">
        Продиктуйте короткую фразу. Текст должен появляться по мере речи.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Чтобы использовать Soniox также для записей или файлов, выберите его в **Настройки → Модели записи** или **Настройки → Модели транскрибирования**. На каждой странице выбор хранится отдельно.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Модель** | Модель Soniox. Модели реального времени, такие как **Soniox STT Realtime v5** (по умолчанию), пишут текст по мере речи; асинхронные модели, такие как **Soniox STT Async v5**, транскрибируют готовые файлы. См. [модели Soniox](https://soniox.com/docs/stt/models). |
| **Language Hints** | Языки, которым отдаётся предпочтение; по умолчанию английский и китайский. Добавьте несколько, если во время речи вы переключаете языки. |
| **Синхронный перевод** | Переводит субтитры по ходу записи. Сохранённая запись хранит расшифровку на исходном языке. По умолчанию выключено. |
| **Язык оригинала** | Язык аудио. **Авто** позволяет Soniox определить его самому. |
| **Translate To** | Язык переведённых субтитров. |
| **Speak Translation** | Озвучивает переведённые субтитры вашим голосом по умолчанию. По умолчанию выключено. |

У Soniox есть и провайдеры синтеза речи, со своим ключом или в Enconvo Cloud, в **Настройки → Синтез речи**.

Soniox обрабатывает аудио в облаке. Чтобы речь оставалась на вашем Mac, используйте вместо него локального провайдера, например Parakeet MLX, Qwen3 MLX или Whisper MLX.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Заново скопируйте ключ из консоли Soniox без лишних пробелов и проверьте, что он относится к нужному проекту. |
| Текст не появляется по мере речи | Выберите модель реального времени и снова запустите диктовку. |
| Слова распознаются не на том языке | Задайте в **Language Hints** языки, на которых вы действительно говорите. |
| Файл не даёт расшифровки | Попробуйте распространённый формат, например MP3, WAV, FLAC или M4A, и проверьте использование и оплату в Soniox. |

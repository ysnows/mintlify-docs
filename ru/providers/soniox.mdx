title: "Soniox"
description: "Используйте речь-в-текст Soniox для диктовки, записей и транскрибирования файлов в Enconvo."
---

Soniox превращает речь в текст в реальном времени и из файлов, на многих языках, и может переводить субтитры в реальном времени, пока вы записываете. Используйте его через Enconvo Cloud без ключа или со своим ключом API Soniox.

<Note>
**Soniox (Enconvo Cloud)** не нуждается в ключе API, и диктовка Soniox бесплатна для участников Cloud Plan, Lifetime и пробного периода.
</Note>

## Подключение

<Tabs>
  <Tab title="Enconvo Cloud">
    <Steps>
      <Step title="Выбрать провайдера">
        Откройте **Настройки → Модели диктовки** и выберите **Soniox (Enconvo Cloud)**.
      </Step>
      <Step title="Проверить">
        Продиктуйте короткое предложение. Текст должен появляться по мере речи.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Свой ключ API">
    <Steps>
      <Step title="Получить ключ API">
        В [Soniox Console](https://console.soniox.com) откройте проект и создайте ключ API.
      </Step>
      <Step title="Добавить его в Enconvo">
        Откройте **Настройки → Модели диктовки** и выберите **Soniox**. Вставьте ключ в учётные данные Soniox и нажмите **Проверить**.
      </Step>
      <Step title="Проверить">
        Продиктуйте короткое предложение. Текст должен появляться по мере речи.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Чтобы использовать Soniox и для записей или файлов, выберите его в **Настройки → Модели записи** или **Настройки → Модели транскрибирования**. Каждая страница хранит свой выбор.

## Модели и параметры

| Настройка | Что делает |
| --- | --- |
| **Model** | Модель Soniox. Модели реального времени, такие как **Soniox STT Realtime v5** (по умолчанию), пишут текст по мере речи; асинхронные модели, такие как **Soniox STT Async v5**, транскрибируют готовые файлы. См. [модели Soniox](https://soniox.com/docs/stt/models). |
| **Language Hints** | Языки, которым отдать предпочтение, по умолчанию английский и китайский. Добавьте несколько, если переключаете языки во время речи. |
| **Live Translation** | Переводит субтитры в реальном времени, пока вы записываете. Сохранённая запись хранит расшифровку на исходном языке. Выключено по умолчанию. |
| **Translate From** | Язык аудио. **Auto** позволяет Soniox определить его. |
| **Translate To** | Язык переведённых субтитров. |
| **Speak Translation** | Зачитывает переведённые субтитры голосом по умолчанию. Выключено по умолчанию. |

У Soniox также есть провайдеры синтеза речи, со своим ключом или на Enconvo Cloud, в **Настройки → Синтез речи**.

Soniox обрабатывает аудио в облаке. Чтобы оставить речь на Mac, используйте локального провайдера, например Parakeet MLX, Qwen3 MLX или Whisper MLX.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| **Проверить** не удаётся | Скопируйте ключ снова из Soniox Console без лишних пробелов и проверьте, что он принадлежит нужному проекту. |
| Текст не появляется, пока вы говорите | Выберите модель реального времени, затем начните диктовку снова. |
| Слова выходят на неверном языке | Задайте **Language Hints** языками, на которых вы действительно говорите. |
| Файл не даёт расшифровки | Попробуйте обычный формат, например MP3, WAV, FLAC или M4A, и проверьте использование и оплату Soniox. |

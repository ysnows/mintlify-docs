Enconvo Cloud даёт вам модели нескольких компаний, а также инструменты речи, изображений, видео и интернета через вашу учётную запись Enconvo. Ключами API управлять не нужно: запросы расходуют баллы вашего тарифа. Это самый быстрый способ начать.

## Настройка

<Steps>
  <Step title="Войдите">
    Войдите в свою учётную запись Enconvo. См. [Учетная запись](/ru/configuration/account).
  </Step>
  <Step title="Выберите Enconvo Cloud">
    Откройте страницу настроек для того, что хотите сделать, например **AI-модель**, **Синтез речи** или **Генерация изображений**, и выберите провайдера с названием **Enconvo Cloud** или **Enconvo Cloud Plan**.
  </Step>
  <Step title="Выберите модель или голос">
    Выберите модель или голос и выполните короткий запрос.
  </Step>
</Steps>

У каждой функции собственный выбор провайдера. Выбор Enconvo Cloud для чата не переключает речь, изображения, видео, эмбеддинги, переранжирование или веб-инструменты; настройте каждое там, где хотите.

## Собственные модели Enconvo

В Enconvo Cloud есть три собственные модели, названные по подходящей им работе:

| Модель | Для чего использовать |
| --- | --- |
| **Enconvo Fast** | Быстрые реплики: короткие ответы, переписывание, мелкие действия. Это модель, с которой начинается **Enconvo Cloud Plan**, и модель по умолчанию для AI Commands. |
| **Enconvo Balanced** | Повседневная работа с несколькими шагами. |
| **Enconvo Ultra** | Сложные задачи, требующие глубоких рассуждений. |

Они перечислены первыми в **Enconvo Cloud Plan**, и [Auto Route](/ru/providers/auto-route) использует их для своих маршрутов по умолчанию.

## Поиск модели в списке выбора

Список **Enconvo Cloud Plan** группирует модели по разработчикам: сначала собственные модели Enconvo, затем Anthropic, OpenAI, Google и остальные, у каждого указано количество. Разработчик показывает четыре самые новые модели; нажмите **Show N earlier models**, чтобы увидеть остальные. Поиск перечисляет все совпадения, а модель, которую использует ваш чат, показывается всегда. Модели Claude перечислены без префикса «Claude», например **Sonnet 5.5** и **Opus 5.5**.

В списке выбора модели в окне чата у облачной модели может быть тег:

| Тег | Значение |
| --- | --- |
| **Новое** | Добавлена за последние 14 дней. |
| Скидка, например **50% OFF** | Пока что модель стоит дешевле. Наведите указатель на строку или дойдите до неё клавишами со стрелками, чтобы увидеть обычную цену. |
| **Бесплатно** | Модель не расходует баллы. |
| **Предпросмотр** | Ранняя версия модели. |
| Дата | День, когда модель покидает Enconvo Cloud. |

Теги задаёт Enconvo Cloud, поэтому они меняются без обновления приложения.

## Баллы и использование

Модели стоят разное количество баллов. Настройки показывают облачную цену рядом с каждой моделью и провайдером, а также то, что включает ваш тариф, например оставшиеся в этом месяце бесплатные минуты. Актуальные тарифы и расценки смотрите на страницах [Cloud Plan](https://www.enconvo.com/cloud-plan) и [Cloud pricing](https://www.enconvo.com/cloud-pricing). Чтобы увидеть, сколько вы израсходовали, откройте **Настройки → Использование баллов**.

[Auto Route](/ru/providers/auto-route), модель по умолчанию, работает на облачных моделях Enconvo Cloud. Выбор маршрута для каждого сообщения бесплатный; модель, которая отвечает, расходует баллы.

Некоторые облачные сервисы бесплатны для каждой учётной записи, в которую выполнен вход:

- Веб-поиск через **Enconvo Cloud** и **DeepSeek (Enconvo Cloud)**. См. [Поиск в интернете](/ru/ai/web-search).
- Распознавание речи через **Enconvo Cloud Fast**. См. [Распознавание речи](/ru/ai/speech-recognition).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Запросы просят войти | Войдите в **Настройки → Учетная запись**. |
| Запросы завершаются ошибкой баллов или баланса | Проверьте **Настройки → Использование баллов**, затем свой тариф на странице [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Модели не хватает | Список выбора показывает то, что включает ваш тариф. Нажмите **Обновить** рядом с **Название модели**. |

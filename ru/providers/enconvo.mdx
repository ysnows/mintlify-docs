Enconvo Cloud даёт модели нескольких компаний, плюс речь, изображения, видео и веб-инструменты, через учётную запись Enconvo. Ключами API управлять не нужно: запросы используют баллы плана. Это самый быстрый способ начать.

## Настройка

<Steps>
  <Step title="Войти">
    Войдите в учётную запись Enconvo. См. [Учетная запись](/ru/configuration/account).
  </Step>
  <Step title="Выбрать Enconvo Cloud">
    Откройте страницу Настроек для того, что хотите сделать, например **AI Model**, **Синтез речи** или **Генерация изображений**, и выберите провайдера с подписью **Enconvo Cloud** или **Enconvo Cloud Plan**.
  </Step>
  <Step title="Выбрать модель или голос">
    Выберите модель или голос и запустите короткий запрос.
  </Step>
</Steps>

У каждой функции свой выбор провайдера. Выбор Enconvo Cloud для чата не переключает речь, изображения, видео, эмбеддинги, переранжирование или веб-инструменты; задайте каждый там, где нужно.

## Собственные модели Enconvo

У Enconvo Cloud три собственные модели, названные по работе, которой они подходят:

| Модель | Для чего |
| --- | --- |
| **Enconvo Fast** | Быстрые ходы: короткие ответы, переписывание, мелкие действия. Это модель, с которой начинает **Enconvo Cloud Plan**, и значение по умолчанию для AI Commands. |
| **Enconvo Balanced** | Повседневная работа в несколько шагов. |
| **Enconvo Ultra** | Трудные задачи, которым нужно глубокое рассуждение. |

Они перечислены первыми в **Enconvo Cloud Plan**, и [Auto Route](/ru/providers/auto-route) использует их для маршрутов по умолчанию.

## Найти модель в выборе

Список **Enconvo Cloud Plan** группирует модели по поставщику: сначала собственные модели Enconvo, затем Anthropic, OpenAI, Google и остальные, каждая с числом. Поставщик показывает четыре новейшие модели; нажмите **Show N earlier models**, чтобы увидеть остальные. Поиск перечисляет каждое совпадение, и модель, которую использует чат, всегда видна. Модели Claude перечислены без префикса «Claude», например **Sonnet 5.5** и **Opus 5.5**.

В выборе модели Окна чата модель Cloud может нести метку:

| Метка | Значение |
| --- | --- |
| **New** | Добавлена за последние 14 дней. |
| Скидка, например **50% OFF** | Модель пока стоит меньше. Наведите на строку или дойдите до неё стрелками, чтобы увидеть обычную цену. |
| **Free** | Модель не использует баллы. |
| **Preview** | Ранняя версия модели. |
| Дата | День, когда модель уходит из Enconvo Cloud. |

Метки задаёт Enconvo Cloud, поэтому они меняются без обновления приложения.

## Баллы и использование

Модели стоят разное число баллов. Настройки показывают цену Cloud рядом с каждой моделью и провайдером, вместе с тем, что входит в план, например сколько бесплатных минут осталось в этом месяце. Текущие планы и тарифы см. на страницах [Cloud Plan](https://www.enconvo.com/cloud-plan) и [Cloud pricing](https://www.enconvo.com/cloud-pricing). Чтобы увидеть, что вы использовали, откройте **Настройки → Points Usage**.

[Auto Route](/ru/providers/auto-route), модель по умолчанию, работает на моделях Enconvo Cloud. Выбор маршрута для каждого сообщения бесплатен; модель, которая отвечает, использует баллы.

Некоторые службы Cloud бесплатны для каждой вошедшей учётной записи:

- Веб-поиск с **Enconvo Cloud** и **DeepSeek (Enconvo Cloud)**. См. [Веб-поиск](/ru/ai/web-search).
- Распознавание речи с **Enconvo Cloud Fast**. См. [Распознавание речи](/ru/ai/speech-recognition).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Запросы просят войти | Войдите в **Настройки → Учетная запись**. |
| Запросы не удаются с ошибкой баллов или баланса | Проверьте **Настройки → Points Usage**, затем план на странице [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Модели нет | Выбор показывает, что входит в план. Нажмите **Refresh** рядом с **Model Name**. |

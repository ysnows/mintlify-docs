title: "xAI (Grok)"
description: "Общайтесь с моделями Grok в Enconvo с помощью ключа API xAI или вашей подписки Grok."
---

Используйте модели Grok от xAI в чатах, Агентах и AI Commands. Подключитесь с помощью ключа API xAI, использование по которому xAI оплачивает за каждый запрос, или войдите со своей подпиской Grok. В Настройках провайдер называется **X.AI-GROK**.

## Подключение

<Steps>
  <Step title="Получите ключ API">
    Создайте ключ в консоли xAI; как это сделать, показано в [кратком руководстве xAI](https://docs.x.ai/docs/quickstart#creating-an-api-key).
  </Step>
  <Step title="Добавьте его в Enconvo">
    Откройте **Настройки → AI-модель → X.AI-GROK**. В разделе **Аутентификация** выберите **Ключ API**, вставьте ключ и нажмите **Проверить**.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в поле **Название модели** и отправьте короткое сообщение. Если пришёл ответ, подключение работает.
  </Step>
</Steps>

<Tip>
Есть подписка Grok? Вместо этого выберите **Grok Subscription** в разделе **Аутентификация** и нажмите **Подключить**.
</Tip>

Чтобы хранить второй ключ xAI, нажмите **Добавить нового провайдера** и создайте ещё один профиль.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Название модели** | Модель, которую использует этот провайдер. Кнопка **Обновить** рядом с ней перезагружает список, а **Управление моделями** (шестерёнка) добавляет или восстанавливает модели. |
| **Базовый URL API** | Хранится в учётных данных. По умолчанию `https://api.x.ai/v1`. |

У xAI есть и отдельные провайдеры для синтеза речи, генерации изображений, транскрибирования, генерации видео и X Search. Они используют ключ или вход Grok из этого профиля; выбирайте каждый на его собственной странице Настроек.

## На iPhone

Приложение для iPhone тоже может использовать подписку Grok в чатах на телефоне. На iPhone откройте **Настройки → AI-модель → xAI**, выберите карточку Grok в разделе **Аутентификация** и нажмите **Войти через Grok**. См. [Чаты на телефоне](/ru/integrations/iphone-phone-chats).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Вставьте ключ целиком ещё раз и убедитесь, что он активен в консоли xAI. |
| Нет нужной модели | Нажмите **Обновить** рядом с полем **Название модели**. Чтобы добавить модель самостоятельно, воспользуйтесь **Управлением моделями**. |
| Вход через Grok перестал работать | Откройте меню карточки аккаунта и нажмите **Переподключить**. |
| Ошибки лимита запросов или использования | Проверьте использование в своём аккаунте xAI или пока переключитесь на другого провайдера. |

---
title: "Vercel AI Gateway"
description: "Общайтесь с моделями Vercel AI Gateway в Enconvo с помощью собственного ключа API Vercel AI Gateway."
---

Vercel AI Gateway открывает по одному ключу доступ к моделям многих компаний. Оплата и доступ определяются вашим аккаунтом Vercel. Добавьте ключ в Enconvo, чтобы использовать эти модели в чатах, Агентах и AI Commands. Vercel AI Gateway выставляет счёт за использование на ваш собственный аккаунт.

## Подключение

<Steps>
  <Step title="Получите ключ API">
    Создайте ключ в [Vercel AI Gateway](https://vercel.com/ai-gateway).
  </Step>
  <Step title="Добавьте его в Enconvo">
    Откройте **Настройки → AI-модель → Vercel AI Gateway**. В разделе **Аутентификация** вставьте ключ в поле **Ключ API** и нажмите **Проверить**.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в поле **Название модели** и отправьте короткое сообщение. Если пришёл ответ, подключение работает.
  </Step>
</Steps>

Чтобы хранить второй ключ Vercel AI Gateway, например рабочий, нажмите **Добавить нового провайдера** и создайте ещё один профиль.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Название модели** | Модель, которую использует этот провайдер. Кнопка **Обновить** рядом с ней перезагружает список, а **Управление моделями** (шестерёнка) добавляет или восстанавливает модели. |
| **Google Search Tool** | Позволяет совместимым моделям опирать ответы на поиск Google. По умолчанию выключено. |
| **URL Context Tool** | Позволяет совместимым моделям читать страницы по ссылкам из вашего сообщения. По умолчанию выключено. |

Чтобы использовать другую модель в одном чате, выберите её в списке моделей этого чата.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Вставьте ключ целиком ещё раз и убедитесь, что он активен в вашем аккаунте Vercel AI Gateway. |
| Нет нужной модели | Нажмите **Обновить** рядом с полем **Название модели**, чтобы перезагрузить список. Чтобы добавить модель самостоятельно, воспользуйтесь **Управлением моделями**. |
| Не работают изображения или инструменты | Выберите модель, которая поддерживает ввод изображений или вызов инструментов. |
| Ошибки лимита запросов или использования | Проверьте использование и лимиты в своём аккаунте Vercel AI Gateway или пока переключитесь на другого провайдера. |
| Ответы приходят медленно | Попробуйте модель поменьше, более короткий запрос или меньшую глубину рассуждений. |

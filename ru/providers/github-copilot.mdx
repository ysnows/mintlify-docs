Используйте план GitHub Copilot как провайдера модели AI в Enconvo. Вы входите с учётной записью GitHub, у которой есть план; ключ API не нужен. Премиум-модели идут в счёт премиум-запросов плана.

## Подключение

<Steps>
  <Step title="Откройте провайдера">
    Откройте **Настройки → Модель AI → GitHub Copilot**.
  </Step>
  <Step title="Начните вход">
    В разделе **Аутентификация** нажмите **Подключить**.
  </Step>
  <Step title="Введите код на GitHub">
    Браузер открывает страницу устройства GitHub, а Enconvo показывает код, который нужно туда ввести. Введите код и подтвердите вход.
  </Step>
  <Step title="Проверьте учётную запись">
    Вернитесь в Enconvo и проверьте, что подключена нужная учётная запись GitHub.
  </Step>
  <Step title="Выберите модель">
    Выберите модель и попробуйте короткий запрос.
  </Step>
</Steps>

Если закрыть диалог кода Enconvo до подтверждения, вход отменяется.

## Модели и параметры

Список моделей показывает только те, которыми может пользоваться ваш план Copilot, а модель чата Copilot по умолчанию стоит первой. У Copilot Free моделей меньше, чем у платных планов, поэтому модель, которую вы видели в другом месте, может не быть в списке. У каждой модели те уровни усилия рассуждения, которые Copilot для неё предлагает.

## На iPhone

Приложение iPhone тоже может войти в GitHub Copilot, для чатов телефона на телефоне. См. [Чаты телефона](/ru/integrations/iphone-phone-chats).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Вход не завершается | Введите код на странице GitHub, пока он не истёк, затем снова нажмите **Подключить**, чтобы получить новый код. |
| Нужной модели нет в списке | Ваш план Copilot её не включает; выберите другую модель или повысьте план. |
| Запрос падает с ошибкой модели | Выберите модель из текущего списка; значение по умолчанию, выбранное до смены плана, может больше не предлагаться. |
| Лимит скорости или использования | Премиум-запросы плана и лимиты скорости GitHub. |

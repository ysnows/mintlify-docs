---

Используйте свой тариф GitHub Copilot как провайдера AI-модели в Enconvo. Вы входите с учётной записью GitHub, у которой есть тариф; ключ API не нужен. Премиальные модели засчитываются в премиальные запросы вашего тарифа.

## Подключение

<Steps>
  <Step title="Откройте провайдера">
    Откройте **Настройки → AI-модель → GitHub Copilot**.
  </Step>
  <Step title="Начните вход">
    В разделе **Аутентификация** нажмите **Подключить**.
  </Step>
  <Step title="Введите код на GitHub">
    Браузер откроет страницу устройства GitHub, а Enconvo покажет код, который нужно там ввести. Введите код и авторизуйте вход.
  </Step>
  <Step title="Проверьте учётную запись">
    Вернитесь в Enconvo и проверьте, что подключена нужная учётная запись GitHub.
  </Step>
  <Step title="Выберите модель">
    Выберите модель и попробуйте короткий запрос.
  </Step>
</Steps>

Если закрыть окно с кодом в Enconvo до авторизации, вход будет отменён.

## Модели и параметры

В списке моделей показаны только модели, которые может использовать ваш тариф Copilot, причём первой стоит собственная модель чата Copilot по умолчанию. Copilot Free предлагает меньше моделей, чем платные тарифы, поэтому модель, которую вы видели в другом месте, может отсутствовать. Каждая модель использует уровни глубины рассуждений, которые Copilot предлагает для неё.

## На iPhone

Приложение для iPhone тоже может войти в GitHub Copilot — для чатов на телефоне. См. [Чаты на телефоне](/ru/integrations/iphone-phone-chats).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Вход не завершается | Введите код на странице GitHub до истечения его срока, затем снова нажмите **Подключить**, чтобы получить новый код. |
| Нужной модели нет в списке | Ваш тариф Copilot её не включает; выберите другую модель или повысьте тариф. |
| Запрос завершается ошибкой модели | Выберите модель из текущего списка; значение по умолчанию, выбранное до смены тарифа, могло перестать предлагаться. |
| Ограничение частоты или использования | Премиальные запросы вашего тарифа и ограничения частоты запросов GitHub. |

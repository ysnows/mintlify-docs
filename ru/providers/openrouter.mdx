---
title: "OpenRouter"
description: "Общайтесь с моделями OpenRouter в Enconvo с помощью собственного ключа API OpenRouter."
---

OpenRouter открывает по одному ключу API доступ к моделям многих компаний. Добавьте ключ в Enconvo, чтобы использовать эти модели в чатах, Агентах и AI Commands. OpenRouter выставляет счёт за использование на ваш собственный аккаунт.

## Подключение

<Steps>
  <Step title="Получите ключ API">
    Создайте ключ на [OpenRouter](https://openrouter.ai/).
  </Step>
  <Step title="Добавьте его в Enconvo">
    Откройте **Настройки → AI-модель → OpenRouter**. В разделе **Аутентификация** вставьте ключ в поле **Ключ API** и нажмите **Проверить**.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в поле **Название модели** и отправьте короткое сообщение. Если пришёл ответ, подключение работает.
  </Step>
</Steps>

Чтобы хранить второй ключ OpenRouter, например рабочий, нажмите **Добавить нового провайдера** и создайте ещё один профиль.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Название модели** | Модель, которую использует этот провайдер. Кнопка **Обновить** рядом с ней перезагружает список, а **Управление моделями** (шестерёнка) добавляет или восстанавливает модели. |
| **Google Search Tool** | Позволяет моделям Gemini опирать ответы на поиск Google. По умолчанию выключено. |
| **URL Context Tool** | Позволяет моделям Gemini читать страницы по ссылкам из вашего сообщения. По умолчанию выключено. |

Чтобы использовать другую модель в одном чате, выберите её в списке моделей этого чата.

У генерации изображений и видео есть собственные провайдеры OpenRouter в **Настройки → Генерация изображений** и **Настройки → Генерация видео**. Вызов инструментов и ввод изображений зависят от выбранной модели.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Вставьте ключ целиком ещё раз и убедитесь, что он активен в вашем аккаунте OpenRouter. |
| Нет нужной модели | Нажмите **Обновить** рядом с полем **Название модели**, чтобы перезагрузить список. Чтобы добавить модель самостоятельно, воспользуйтесь **Управлением моделями**. |
| Не работают изображения или инструменты | Выберите модель, которая поддерживает ввод изображений или вызов инструментов. |
| Ошибки лимита запросов или использования | Проверьте использование и лимиты в своём аккаунте OpenRouter или пока переключитесь на другого провайдера. |
| Ответы приходят медленно | Попробуйте модель поменьше, более короткий запрос или меньшую глубину рассуждений. |

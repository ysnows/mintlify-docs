Используйте модели Qwen от Alibaba в чатах, Агентах и AI Commands. Подключитесь с помощью ключа API из Alibaba Cloud Model Studio; Alibaba Cloud выставляет счёт за использование на ваш аккаунт. Для сервиса в материковом Китае (Bailian) используйте [DashScope](/ru/providers/dashscope).

## Подключение

<Steps>
  <Step title="Получите ключ API">
    Создайте ключ в [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Добавьте его в Enconvo">
    Откройте **Настройки → AI-модель → Qwen**. В разделе **Аутентификация** вставьте ключ в поле **Ключ API** и нажмите **Проверить**.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в поле **Название модели** и отправьте короткое сообщение. Если пришёл ответ, подключение работает.
  </Step>
</Steps>

Qwen подключается только по ключу API.

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Название модели** | Модель, которую использует этот провайдер. Кнопка **Обновить** рядом с ней перезагружает список, а **Управление моделями** (шестерёнка) добавляет или восстанавливает модели. |
| **Базовый URL** | Хранится в учётных данных. По умолчанию это международный адрес `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Измените его, если ваш ключ относится к другому региону. |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Убедитесь, что ключ и **Базовый URL** относятся к одному региону, затем вставьте ключ целиком ещё раз. |
| Нет нужной модели | Нажмите **Обновить** рядом с полем **Название модели**. Чтобы добавить модель самостоятельно, воспользуйтесь **Управлением моделями**. |
| Ошибки лимита запросов или использования | Проверьте использование и квоту в Model Studio или пока переключитесь на другого провайдера. |

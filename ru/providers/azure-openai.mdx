Используйте модели OpenAI, которые ваша организация разворачивает в Azure. Enconvo обращается к ресурсу Azure напрямую, так что доступ, квоты и счет идут по вашей подписке Azure.

## Перед началом

Нужен ресурс Azure OpenAI хотя бы с одним развертыванием модели. Из портала Azure скопируйте **key** ресурса, его **endpoint** и **deployment name**, которое вы дали модели. См. [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview), если еще не настроили.

## Подключить

<Steps>
  <Step title="Добавьте учетные данные">
    Откройте **Настройки → AI-модель → Azure OpenAI**. В разделе **Аутентификация** заполните **Ключ API**, **Endpoint** и **API Version**, затем нажмите **Проверить**. Endpoint выглядит как `https://<resource>.cognitiveservices.azure.com/`.
  </Step>
  <Step title="Задайте развертывание">
    Введите имя развертывания в **Azure OpenAI Api Deployment Name**. Используйте имя из ресурса Azure: оно может отличаться от имени модели.
  </Step>
  <Step title="Проверьте">
    Отправьте короткое сообщение. Ответ значит, что подключение работает.
  </Step>
</Steps>

## Модели и параметры

| Настройка | Что делает |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | Развертывание, к которому обращается этот провайдер. |
| **Потоковая передача** | Показывает ответ по мере написания. По умолчанию включено; выключите, если развертывание не поддерживает потоковую передачу. |
| **API Version** | В учетных данных. По умолчанию `2025-01-01-preview`. |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| **Проверить** не проходит | Проверьте, что ключ и **Endpoint** взяты из одного ресурса Azure. |
| Развертывание не найдено | Скопируйте имя развертывания из портала Azure точно. |
| Ответ так и не появляется | Выключите **Потоковая передача** и попробуйте снова. |
| Ошибки лимита или квоты | Поднимите квоту развертывания в Azure или пока переключитесь на другого провайдера. |

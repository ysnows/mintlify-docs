Используйте модели OpenAI, которые ваша организация развернула в Azure. Enconvo обращается к вашему ресурсу Azure напрямую, поэтому доступ, квоты и оплата определяются вашей подпиской Azure.

## Перед началом

Вам нужен ресурс Azure OpenAI хотя бы с одним развёртыванием модели. В портале Azure скопируйте **ключ** ресурса, его **конечную точку** и **имя развёртывания**, которое вы дали модели. Если вы ещё не настроили ресурс, см. [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview).

## Подключение

<Steps>
  <Step title="Добавьте учётные данные">
    Откройте **Настройки → AI-модель → Azure OpenAI**. В разделе **Аутентификация** заполните **Ключ API**, **Endpoint** и **API Version**, затем нажмите **Проверить**. Конечная точка выглядит так: `https://<resource>.cognitiveservices.azure.com/`.
  </Step>
  <Step title="Укажите развёртывание">
    Введите имя развёртывания в поле **Azure OpenAI Api Deployment Name**. Используйте имя из вашего ресурса Azure, оно может отличаться от названия модели.
  </Step>
  <Step title="Проверьте работу">
    Отправьте короткое сообщение. Если пришёл ответ, подключение работает.
  </Step>
</Steps>

## Модели и параметры

| Параметр | Что делает |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | Развёртывание, к которому обращается этот провайдер. |
| **Потоковая передача** | Показывает ответ по мере его написания. По умолчанию включена; выключите её, если ваше развёртывание не поддерживает потоковую передачу. |
| **API Version** | Хранится в учётных данных. По умолчанию `2025-01-01-preview`. |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Не проходит **Проверить** | Убедитесь, что ключ и **Endpoint** относятся к одному ресурсу Azure. |
| Развёртывание не найдено | Скопируйте имя развёртывания из портала Azure без изменений. |
| Ответ так и не появляется | Выключите **Потоковую передачу** и повторите попытку. |
| Ошибки лимита или квоты | Увеличьте квоту развёртывания в Azure или пока переключитесь на другого провайдера. |

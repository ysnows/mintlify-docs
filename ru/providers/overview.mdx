Провайдер — это сервис, стоящий за функцией Enconvo: модель, которая отвечает в чате, голос, который читает вслух, движок, который ищет в интернете. Вы выбираете одного для каждой функции и можете комбинировать их.

Видео ниже за 2 минуты проводит по **Настройки → AI-модель**: Auto Route, облачный тариф, вход с помощью тарифа ChatGPT, Claude, GitHub Copilot, Antigravity или Grok, ключи API, модели на вашем Mac, Ollama и LM Studio и добавление собственного провайдера.

## Выберите способ подключения

| Если вы хотите | Используйте | С чего начать |
| --- | --- | --- |
| Начать сразу, без ключей | Enconvo Cloud через вашу учётную запись Enconvo | [Enconvo Cloud](/ru/providers/enconvo) |
| Чтобы Enconvo выбирал модель для каждого сообщения | Auto Route, модель по умолчанию | [Auto Route](/ru/providers/auto-route) |
| Использовать тариф, за который вы уже платите | Вход через ChatGPT, Claude, Grok, Mistral, GitHub Copilot или Antigravity | [Вход с помощью тарифа](#вход-с-помощью-тарифа) |
| Платить провайдеру напрямую | Собственный ключ API | [Популярные провайдеры](#популярные-провайдеры) |
| Получить модели многих компаний с одним ключом | Шлюз, например OpenRouter или PipeLLM | [OpenRouter](/ru/providers/openrouter), [PipeLLM](/ru/providers/pipellm) |
| Хранить чаты на вашем Mac | Локальная модель | [Локальные модели](/ru/ai/local-llm) |
| Использовать модели, которые вы уже запускаете в Ollama или LM Studio | Провайдер **Ollama** или **LM Studio** | [Ollama](/ru/providers/ollama), [LM Studio](/ru/providers/lm-studio) |
| Использовать модели в собственных чатах приложения для iPhone | Чаты телефона | [Чаты телефона](/ru/integrations/iphone-phone-chats) |

## Выберите модель для чата

<Steps>
  <Step title="Откройте «AI-модель»">
    Откройте **Настройки → AI-модель**. Средний столбец перечисляет всех провайдеров: вверху **Auto Route** и **Enconvo Cloud Plan**, затем компании, локальные модели и все остальные провайдеры.
  </Step>
  <Step title="Выберите провайдера и подключите его">
    Нажмите на провайдера. Если доступны оба варианта, выберите **Ключ API**, чтобы платить провайдеру за каждый запрос по своему ключу, или вариант подписки (например, **ChatGPT Subscription**), чтобы войти и использовать то, что включено в ваш тариф.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в **Название модели** и **Глубина рассуждений**, если у провайдера она есть.
  </Step>
  <Step title="Сделайте её моделью по умолчанию">
    Нажмите **Сделать по умолчанию**. Чаты и функции, у которых нет собственной модели, теперь будут использовать её.
  </Step>
</Steps>

Чтобы добавить сервис, которого нет в списке, нажмите **Добавить нового провайдера** внизу списка и выберите **Совместимо с OpenAI** или **Совместимо с Anthropic**.

Провайдеров можно менять в любое время; ничто не привязывает ваши чаты к одной компании.

Вверху **Настройки → AI-модель** есть также **Task models** — для небольших моделей, создающих заголовки чатов и подсказки, и **Резервный вариант** — для резервных моделей, которые подхватывают работу, когда модель чата использовать нельзя. См. [Выбор модели](/ru/ai/model-selection-guide).

## Выбор провайдера для каждой функции

У каждой функции своя страница настроек: **AI-модель**, **Синтез речи**, **Поиск в интернете**, **Генерация изображений**, **Генерация видео**, **Загрузка веб-страницы** и **OCR**. У распознавания речи отдельные страницы: **Модели диктовки**, **Модели записи**, **Модели транскрибирования** и **Модель создания субтитров**. Эмбеддинги и переранжирование настраиваются в базе знаний.

Выбор модели для чата не меняет вашего провайдера речи, изображений или поиска. Настройте каждого там, где хотите.

## Профили

Профиль провайдера хранит один ключ или вход. Нажмите **Добавить нового провайдера** на странице провайдера, чтобы сохранить второй, например рабочую учётную запись. Некоторые профили обслуживают несколько функций: один профиль OpenAI покрывает чат, эмбеддинги, синтез речи, изображения и транскрибацию, поэтому смена его ключа меняет всё это. См. [Учётные данные и профили](/ru/configuration/credentials).

Где задаётся ваша модель по умолчанию и как каждый чат сохраняет свою, описано в разделе [Выбор модели](/ru/ai/model-selection-guide).

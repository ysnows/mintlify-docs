Провайдер — сервис за функцией Enconvo: модель, которая отвечает в чате, голос, который читает вслух, движок, который ищет в интернете. Вы выбираете по одному для каждой функции и можете их сочетать.

Видео ниже за 2 минуты проходит **Настройки → AI-модель**: Auto Route, тариф Cloud, вход тарифами ChatGPT, Claude, GitHub Copilot, Antigravity или Grok, API-ключи, модели на Mac, Ollama и LM Studio и добавление своего провайдера.

## Выберите, как подключаться

| Если вы хотите | Используйте | Начните здесь |
| --- | --- | --- |
| Начать сразу, без ключей | Enconvo Cloud через учетную запись Enconvo | [Enconvo Cloud](/ru/providers/enconvo) |
| Пусть Enconvo выбирает модель для сообщения | Auto Route, модель по умолчанию | [Auto Route](/ru/providers/auto-route) |
| Использовать тариф, который вы уже оплачиваете | Войдите через ChatGPT, Claude, Grok, Mistral, GitHub Copilot или Antigravity | [Вход тарифом](/ru/providers/overview) |
| Платить провайдеру напрямую | Свой API-ключ | [Популярные провайдеры](/ru/providers/overview) |
| Добраться до моделей многих компаний одним ключом | Шлюз вроде OpenRouter или PipeLLM | [OpenRouter](/ru/providers/openrouter), [PipeLLM](/ru/providers/pipellm) |
| Держать чаты на Mac | Локальная модель | [Локальные модели](/ru/ai/local-llm) |
| Использовать модели, которые уже работают в Ollama или LM Studio | Провайдер **Ollama** или **LM Studio** | [Ollama](/ru/providers/ollama), [LM Studio](/ru/providers/lm-studio) |
| Использовать модели в собственных чатах приложения для iPhone | Чаты телефона | [Чаты телефона](/ru/integrations/iphone-phone-chats) |

## Выберите модель чата

<Steps>
  <Step title="Откройте AI-модель">
    Откройте **Настройки → AI-модель**. Средняя колонка перечисляет всех провайдеров: **Auto Route** и **Enconvo Cloud Plan** сверху, затем компании, локальные модели и все остальные провайдеры.
  </Step>
  <Step title="Выберите провайдера и подключите его">
    Нажмите провайдера. Где есть оба варианта, выберите **API Key**, чтобы платить провайдеру за запрос своим ключом, или вариант подписки (например **ChatGPT Subscription**), чтобы войти и использовать то, что входит в тариф.
  </Step>
  <Step title="Выберите модель">
    Выберите модель в **Model Name** и **Reasoning Effort**, где у провайдера он есть.
  </Step>
  <Step title="Сделайте её моделью по умолчанию">
    Нажмите **Set as Default**. Чаты и функции, которые не называют свою модель, теперь используют её.
  </Step>
</Steps>

Чтобы добавить сервис, которого нет в списке, нажмите **Add New Provider** внизу списка и выберите **OpenAI Compatible** или **Anthropic Compatible**.

Провайдеров можно менять в любой момент; чаты не привязаны к одной компании.

Вверху **Настройки → AI-модель** также есть **Task models** для небольших моделей за заголовками чатов и подсказками и **Fallback** для запасных моделей, которые берут чат, когда его модель нельзя использовать. См. [Выбор модели](/ru/ai/model-selection-guide).

## Задайте провайдера для каждой функции

У каждой функции своя страница Настроек: **AI-модель**, **Text-to-Speech**, **Поиск в интернете**, **Image Generation**, **Video Generation**, **Web Fetch** и **OCR**. У распознавания речи отдельные страницы **Dictation Models**, **Recording Models**, **Transcription Models** и **Captioning Model**. Эмбеддинги и переранжирование задаются в Базе знаний.

Выбор модели чата не меняет провайдера речи, изображений или поиска. Задайте каждый там, где нужно.

## Профили

Профиль провайдера хранит один ключ или вход. Нажмите **Add New Provider** на странице провайдера, чтобы хранить второй, например рабочий аккаунт. Некоторые профили обслуживают несколько функций: один профиль OpenAI покрывает чат, эмбеддинги, синтез речи, изображения и транскрибирование, поэтому смена его ключа меняет все их. См. [Учётные данные и профили](/ru/configuration/credentials).

Где задана модель по умолчанию и как каждый чат хранит свою — в [Выборе модели](/ru/ai/model-selection-guide).

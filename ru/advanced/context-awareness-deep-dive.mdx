Эта страница объясняет, что стоит за функцией [Контекстная осведомленность](/ru/features/context-awareness): какие элементы Enconvo может считывать с вашего Mac, как он считывает каждый из них и как вы решаете, что попадёт в сообщение. Прочитайте её, когда хотите управлять тем, что доходит до модели, или когда ожидаемый контекст не появляется.

Контекстная осведомленность не следит за вашим экраном в фоновом режиме. Она считывает контекст, когда вы открываете SmartBar или когда сами добавляете элемент, — из приложения, которым вы пользовались непосредственно перед этим.

## Что может считывать Enconvo

Каждый вид контекста — это элемент, который можно добавить в сообщение.

| Элемент контекста | Что он содержит | Как Enconvo его считывает |
|---|---|---|
| **Selected Text** | Текст, выделенный в приложении | Универсальный доступ |
| **Current Application Content** | Заголовок и текст окна, адрес документа, если приложение его сообщает, и снимок окна | Универсальный доступ и захват окна |
| **Browser Current Tab URL** | Адрес передней вкладки, её заголовок и текст страницы | Apple Events; см. [Браузеры](#браузеры) |
| **Finder Selected Items** | Файлы и папки, выделенные в Finder, в виде путей | Apple Events |
| **Finder Current Directory URL** | Папка, открытая в переднем окне Finder | Apple Events |
| **Clipboard Text** | Текст в буфере обмена | Буфер обмена, только когда вы его добавляете |
| **User Select Area Screenshot** | Область экрана, которую вы выделяете | Захват экрана |
| **Current Application Screenshot** | Приложение, которым вы пользовались | Захват экрана |
| **Current Screen Screenshot** | Весь экран | Захват экрана |
| **Live Screen Screenshot** | Экран в его текущем виде, без окон Enconvo | Захват экрана |

Для элементов Finder Enconvo считывает пути, а не содержимое файлов.

### Браузеры

- **Адрес и заголовок**: считываются через Apple Events из Safari, Chrome, Edge, Arc и других браузеров на основе Chromium. Firefox не сообщает адрес своей вкладки, поэтому Enconvo не может его считать.
- **Текст страницы**: Safari сообщает его напрямую. Для других браузеров Enconvo считывает окно через Универсальный доступ, что работает, только пока браузер — приложение на переднем плане.

### Другие приложения

Редакторы кода, текстовые редакторы и все остальные приложения получают **Current Application Content**: заголовок окна, текст, который предоставляет Универсальный доступ, адрес документа, если приложение его сообщает, и снимок окна. Сколько это текста, зависит от приложения.

## Когда открывается SmartBar

Когда вы открываете SmartBar, он проверяет три источника в приложении, которым вы пользовались. В **Настройки → Контекстная осведомленность** задаётся, что происходит с каждым из них:

| Источник | По умолчанию | Что он захватывает |
|---|---|---|
| **Выделенный текст** | **Прикрепить** | Текст, выделенный в приложении, которым вы пользовались |
| **Выбор в Finder** | **Предложить** | Файлы и папки, выделенные в Finder |
| **Текущая страница браузера** | **Предложить** | Страница, открытая в Safari, Chrome, Arc, Edge или другом браузере на основе Chromium |

- **Прикрепить** добавляет элемент во ввод, как только открывается SmartBar.
- **Предложить** показывает его над командами, так что вы добавляете его одним щелчком. Текст предложенной страницы считывается, только когда вы на неё нажимаете.
- **Выкл.** оставляет источник без внимания.

Эти настройки использует только SmartBar. Команды, которые вы запускаете над выделенным фрагментом, всегда получают выделенный текст.

## Добавьте контекст сами

1. В SmartBar введите `#`.
2. Введите несколько букв, чтобы отфильтровать список элементов контекста.
3. Выберите один. Enconvo считает его и добавит в ваше сообщение.

Чтобы использовать другой символ, измените **Контекст** в **Настройки → SmartBar** в разделе **Поиск**. В той же группе задаются `@` для команд, `$` для навыков и `>` для недавних задач.

## Разрешения

| Разрешение | Для чего нужно |
|---|---|
| **Универсальный доступ** | Выделенный текст, содержимое окна и текст страниц из браузеров, кроме Safari |
| **Автоматизация** | Элементы Finder и страницы браузеров. macOS спрашивает при первом считывании Enconvo каждого приложения |
| **Запись экрана** (запись экрана и системного звука) | Снимки экрана и захват окна в **Current Application Content** |

Выдайте их в **Системные настройки → Конфиденциальность и безопасность**. Enconvo сам замечает изменение доступа к Универсальному доступу. Полный список см. в разделе [Разрешения](/ru/configuration/permissions).

## Контекст и токены

Контекст учитывается в контекстном окне модели. Текст страниц и снимки экрана — самые крупные элементы, и они могут:

- Замедлять ответы
- Стоить дороже с облачными моделями
- Оставлять меньше места для истории беседы

<Tip>
В длинном чате добавляйте страницу или снимок экрана только в то сообщение, которому они нужны, а не прикрепляйте их каждый раз.
</Tip>

## Конфиденциальность и поток данных

Захваченный контекст может стать частью сохранённой беседы или элемента базы знаний. Запросы к моделям и выбранные провайдеры OCR, эмбеддингов, транскрибации или других инструментов могут получать соответствующее содержимое. Различие между локальным хранением и обработкой провайдером описано в разделе [Конфиденциальность и безопасность](/ru/configuration/privacy-security).

Одна лишь локальная модель чата не делает все инструменты автономными. Проверяйте весь поток, включая доступ к браузеру, захваты и обработку провайдерами. Разрешения macOS уменьшают доступный контекст; они не гарантируют, что любое поле стороннего приложения можно отнести к конфиденциальным.

## Устранение неполадок

| Проблема | Что делать |
|---|---|
| Нет выделенного текста или содержимого окна | Включите Enconvo в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. Некоторые приложения не предоставляют свой текст через Универсальный доступ; скопируйте текст и вместо этого добавьте **Clipboard Text** через `#`. |
| Нет страницы браузера или элементов Finder | Включите Enconvo для этого приложения в **Системные настройки → Конфиденциальность и безопасность → Автоматизация**. |
| Нет адреса из Firefox | Firefox не сообщает адрес своей вкладки. Используйте другой браузер или скопируйте адрес. |
| Страница приходит без текста | Вне Safari текст страницы считывается, только пока браузер находится на переднем плане. Откройте SmartBar из браузера. |
| Контекст берётся не из того приложения | Контекст берётся из приложения, которым вы пользовались, когда открылся SmartBar. Дождитесь, пока нужное приложение окажется на переднем плане, затем откройте SmartBar. |
| Снимки экрана не получаются | Включите Enconvo в **Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука**. |

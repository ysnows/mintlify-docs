Эта страница объясняет, что стоит за [Контекстной осведомленностью](/ru/features/context-awareness): что Enconvo может прочитать с вашего Mac, как читает каждый элемент и как вы решаете, что попадает в сообщение. Читайте её, когда хотите контролировать, что доходит до модели, или когда ожидаемый контекст не появляется.

Контекстная осведомленность не следит за экраном в фоне. Она читает контекст, когда вы открываете SmartBar или сами добавляете элемент, из приложения, которым вы пользовались непосредственно перед этим.

## Что Enconvo может прочитать

Каждый вид контекста — элемент, который можно добавить в сообщение.

| Элемент контекста | Что содержит | Как Enconvo читает |
|---|---|---|
| **Selected Text** | Текст, выделенный в приложении | Универсальный доступ |
| **Current Application Content** | Заголовок и текст окна, адрес документа, когда приложение его даёт, и снимок окна | Универсальный доступ и захват окна |
| **Browser Current Tab URL** | Адрес передней вкладки, её заголовок и текст страницы | Apple Events; см. [Браузеры](/ru/advanced/context-awareness-deep-dive) |
| **Finder Selected Items** | Файлы и папки, выделенные в Finder, как пути | Apple Events |
| **Finder Current Directory URL** | Папка, открытая в переднем окне Finder | Apple Events |
| **Clipboard Text** | Текст в буфере обмена | Буфер обмена, только когда вы его добавляете |
| **User Select Area Screenshot** | Область экрана, которую вы выбираете | Захват экрана |
| **Current Application Screenshot** | Приложение, которым вы пользовались | Захват экрана |
| **Current Screen Screenshot** | Весь экран | Захват экрана |
| **Live Screen Screenshot** | Экран как сейчас, без окон Enconvo | Захват экрана |

Для элементов Finder Enconvo читает пути, а не содержимое файлов.

### Браузеры

- **Адрес и заголовок**: читаются через Apple Events из Safari, Chrome, Edge, Arc и других браузеров на Chromium. Firefox не отдаёт адрес вкладки, поэтому Enconvo его не читает.
- **Текст страницы**: Safari отдаёт его напрямую. Для других браузеров Enconvo читает окно через Универсальный доступ, и это работает, только пока браузер на переднем плане.

### Другие приложения

Редакторы кода, текстовые редакторы и все остальные приложения дают **Current Application Content**: заголовок окна, текст, который открывает Универсальный доступ, адрес документа, когда приложение его даёт, и снимок окна. Сколько текста — зависит от приложения.

## Когда открывается SmartBar

Когда вы открываете SmartBar, он проверяет три источника в приложении, которым вы пользовались. **Настройки → Context Awareness** задаёт, что происходит с каждым:

| Источник | По умолчанию | Что подхватывает |
|---|---|---|
| **Selected Text** | **Attach** | Текст, выделенный в приложении, которым вы пользовались |
| **Finder Selection** | **Suggest** | Файлы и папки, выделенные в Finder |
| **Current Browser Page** | **Suggest** | Страница, открытая в Safari, Chrome, Arc, Edge или другом браузере на Chromium |

- **Attach** добавляет элемент во ввод, как только открывается SmartBar.
- **Suggest** показывает его над командами, чтобы добавить одним кликом. Текст предложенной страницы читается только когда вы её нажимаете.
- **Выкл.** оставляет источник в покое.

Эти настройки использует только SmartBar. Команды, которые вы запускаете по выделению, всегда получают выделенный текст.

## Добавьте контекст сами

1. В SmartBar введите `#`.
2. Введите несколько букв, чтобы отфильтровать список элементов контекста.
3. Выберите один. Enconvo читает его и добавляет в сообщение.

Чтобы использовать другой символ, измените **Context** в **Настройки → SmartBar**, в разделе **Search**. Та же группа задаёт `@` для команд, `$` для навыков и `>` для недавних задач.

## Разрешения

| Разрешение | Нужно для |
|---|---|
| **Универсальный доступ** | Выделенный текст, содержимое окна и текст страницы из браузеров кроме Safari |
| **Automation** | Элементы Finder и страницы браузера. macOS спрашивает в первый раз, когда Enconvo читает каждое приложение |
| **Запись экрана** (Screen & System Audio Recording) | Снимки экрана и захват окна в **Current Application Content** |

Выдайте их в **System Settings → Privacy & Security**. Enconvo сам замечает изменение Универсального доступа. Полный список — в [Разрешениях](/ru/configuration/permissions).

## Контекст и токены

Контекст считается в окне контекста модели. Текст страницы и снимки экрана — самые крупные элементы, и они могут:

- замедлять ответы
- стоить дороже у облачных моделей
- оставлять меньше места истории разговора

<Tip>
В длинном чате добавляйте страницу или снимок только к сообщению, которому они нужны, а не каждый раз.
</Tip>

## Конфиденциальность и поток данных

Захваченный контекст может стать частью сохранённого разговора или элемента базы знаний. Запросы к модели и выбранные провайдеры OCR, эмбеддингов, транскрибирования или других инструментов могут получать соответствующее содержимое. Различие между локальным хранением и обработкой у провайдера — в [Конфиденциальности и безопасности](/ru/configuration/privacy-security).

Одна локальная модель чата не делает все инструменты офлайн. Проверьте весь поток, включая доступ к браузеру, захваты и обработку у провайдера. Разрешения macOS уменьшают доступный контекст; это не обещание, что каждое поле стороннего приложения можно классифицировать как чувствительное.

## Устранение неполадок

| Проблема | Что сделать |
| --- | --- |
| Нет выделенного текста или содержимого окна | Включите Enconvo в **System Settings → Privacy & Security → Accessibility**. Некоторые приложения не открывают текст через Универсальный доступ; скопируйте текст и добавьте **Clipboard Text** через `#`. |
| Нет страницы браузера или элементов Finder | Включите Enconvo для этого приложения в **System Settings → Privacy & Security → Automation**. |
| Нет адреса из Firefox | Firefox не отдаёт адрес вкладки. Используйте другой браузер или скопируйте адрес. |
| Страница приходит без текста | Вне Safari текст страницы читается, только пока браузер на переднем плане. Откройте SmartBar из браузера. |
| Контекст из не того приложения | Контекст берётся из приложения, которым вы пользовались, когда открылся SmartBar. Дождитесь, пока нужное приложение будет впереди, затем откройте SmartBar. |
| Снимки экрана не удаются | Включите Enconvo в **System Settings → Privacy & Security → Screen & System Audio Recording**. |

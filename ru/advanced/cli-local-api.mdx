Эта страница для разработчиков и опытных пользователей, которые хотят управлять Enconvo из Terminal, скрипта или другого приложения. Команда `enconvo` идёт вместе с настольным приложением Enconvo, отдельная установка не нужна, а приложение отдаёт маршруты каждого установленного плагина через локальный HTTP API.

В этом видео разбираются страница API, руководство по CLI и хуки.

Для команд, которые используют локальную среду, Enconvo должен быть запущен.

## Найти команды

```bash
enconvo -h
enconvo knowledge_base -h
```

Добавьте `-h` к команде, которую смотрите, чтобы увидеть её текущие подкоманды и параметры.

Откройте **Настройки → Руководство по CLI**, чтобы увидеть установленные расширения с командами CLI. Нажмите имя, чтобы скопировать команду `enconvo <name> -h`. Список установленных расширений определяет, что поддерживает ваше приложение.

Если оболочка не находит `enconvo`, откройте руководство по CLI в приложении и проверьте версию приложения и настройку командной строки.

## Вызвать локальный API

Приложение отдаёт каждый маршрут по адресу `http://localhost:54535/api/<extension>/<route>`. Отправьте `POST` с телом JSON:

```bash
curl -X POST http://localhost:54535/api/enconvo/extension/available_list \
  -H "Content-Type: application/json" \
  -d '{}'
```

Откройте **Настройки → API** и нажмите **Проверить API**, чтобы посмотреть доступные маршруты и схемы запросов, с примером для каждого. Пишите интеграцию по схеме установленной сборки: параметры маршрутов могут меняться вместе с расширениями.

## Запустить агента или AI Command снаружи Enconvo

В настройках каждого агента и каждой AI Command есть строка **Ссылка, CLI и API**. Там ссылка, команда `enconvo` и вызов локального API, которые запускают его с вашим текстом и файлами. Их можно скопировать.

| Способ | Что делает |
| --- | --- |
| Ссылка | Открывает новый чат и запускает там агента или AI Command |
| CLI | Запускает в фоне и печатает ответ |
| Local API | Запускает в фоне и возвращает ответ |

Ссылка выглядит так:

```text
enconvo://<extension>/<command>?input_text=<text>&window=<window>&files=<path>
```

- `input_text` — текст, который нужно отправить.
- `window` — `chat_window` или `dynamic_island`. Без него запуск идёт в Smart Bar.
- `files` прикрепляет файл по абсолютному пути или пути с `~/`. Повторите параметр для нескольких файлов, например чтобы отправить изображения из другого приложения или скрипта.

Из Terminal:

```bash
enconvo agent call "What's on my calendar today?"
enconvo ai-command run 'writing_package|translate' --input-text "Bonjour" --files ~/Desktop/note.png
enconvo writing_package convert_to_list "eggs, milk, bread"
```

Команды для письма, такие как перевод, сводка и преобразование в список, берут текст аргументом и отвечают, не добавляя чат в историю. `enconvo agent main` отвечает в новом чате, если агент занят в последнем.

Соответствующие маршруты локального API: `agent/call` (`agentId`, `message`, `context_files`) и `ai-command/run` (`command_key`, `input_text`, `files`).

### Проверить идущие чаты

- `agent/session/list` перечисляет чаты, которые идут сейчас, по всем агентам и проектам, включая чаты Claude Code и Codex, с названием, агентом и проектом каждого. Передайте `filter: "waiting"` для чатов, которые ждут вашего ответа, или `"active"` для обоих.
- `agent/session/status` проверяет один чат по `sessionId`.
- `agent/session/steer` добавляет сообщение в ход, который чат выполняет сейчас, не останавливая его. Чат, который не идёт, отвечает `not_running`; новый ход начинайте через `agent/call`. Запуск ниже полного доступа не может направлять ход Enconvo.

## Пользоваться безопасно

Если AI-клиенту нужен только поиск по базе знаний, используйте отдельное подключение [MCP базы знаний](/ru/advanced/knowledge-base-mcp), а не открывайте общий локальный API.

Локальный API и доступ к оболочке — широкие возможности: команды могут читать или менять локальные данные согласно своей реализации. В скриптах явно указывайте команду, вход и назначение.

Сохранённые API-ключи возвращаются как `[hidden]`, когда программа читает настройки через локальный API, и только собственные окна Enconvo могут менять, куда отправляется сохранённый ключ. См. [Учётные данные](/ru/configuration/credentials).

Горячую клавишу, заданную через локальный API, можно записать короткими именами модификаторов (`cmd`, `ctrl`, `alt`, `opt`, `fn`) или символами модификаторов. Сочетание со словом, которого Enconvo не знает, не регистрируется, а клавише, которая вводит символ, нужен Command, Control, Option или Function.

## Строить на этом

- [Разработка расширений](/ru/extensions/developing): добавьте свои команды и маршруты. Файл в `src/api/` плагина становится маршрутом здесь.
- [Справочник Extension API](/extensions/extension-api-reference): точки входа SDK.
- [Хуки](/ru/configuration/hooks): запускайте свои команды в заданных точках работы агента. Они берутся из вашего JSON-конфига, а **Настройки → Хуки** показывают загруженные.
- [Автоматизации](/ru/workflows/scheduled-jobs): запускайте работу в выбранное время.
- [Настройте Enconvo на сервере Linux](/ru/advanced/linux-server): задайте модели, агентов и плагины сервера, который добавил ваш Mac, той же командой `enconvo`.

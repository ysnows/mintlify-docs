Enconvo может отдавать ваши базы знаний MCP-совместимым AI-клиентам на том же Mac. Клиенты ищут и читают только те базы, которые вы открыли; доступ только на чтение. Это не то же, что **Настройки → MCP Servers**: там внешние инструменты добавляются к Агентам Enconvo.

## Подключить клиент

1. Откройте [Базу знаний](/ru/ai/knowledge-base) и нажмите шестерёнку (**Настройки базы знаний**), затем **AI-клиенты (MCP)**.
2. Включите **Включить MCP базы знаний**. По умолчанию оно выключено, и пока оно выключено, подключённые клиенты получают отказ.
3. Выберите, что клиенты могут видеть. **Поделиться этой базой знаний с клиентами AI** открывает ту базу, которая сейчас открыта, а **Общие базы знаний** показывает все такие базы. История диктовки и Память скрыты, пока вы их не включите.
4. В разделе **Подключить клиент** выберите клиент (Claude Code, Cursor, Codex или Claude Desktop) и скопируйте его настройку.
5. Попросите клиент перечислить базы знаний, затем найти одну и прочитать подходящий элемент.

Локальная точка:

```text
http://localhost:54535/knowledge_base/mcp
```

Она использует транспорт Streamable HTTP. Пока клиент ею использует, Enconvo должен быть запущен. Claude Desktop подключается через небольшой мост `mcp-remote`, поэтому для его настройки нужен Node.js. Следуйте инструкции для конкретного клиента в диалоге.

## Доступные инструменты

| Инструмент | Назначение |
| --- | --- |
| `kb_list` | Список видимых баз знаний |
| `kb_search` | Поиск по видимой базе знаний |
| `item_list` | Список элементов видимой базы знаний |
| `item_read` | Чтение текста проиндексированного элемента по страницам |

Инструменты только для чтения. Эта точка не открывает общие инструменты Памяти или Записей. При чтении элемента путь к источнику или URL может вернуться как метаданные.

## Доступ и обработка

Сервер принимает только подключения с этого же компьютера и не требует токен. Если его включить, локальные процессы смогут читать открытые вами базы знаний. Подключённый AI-клиент может отправить полученное своему провайдеру модели, поэтому проверьте и его настройки.

Поиск использует модель эмбеддингов, заданную в разделе **Поиск** в **Настройки → Память**. Если она работает на Enconvo Cloud, текст запроса отправляется туда. «Локальная точка» не значит, что поиск и ответ целиком идут без сети.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Connection refused | Убедитесь, что Enconvo и его Local API запущены. |
| Forbidden / 403 | Проверьте, что **Включить MCP базы знаний** включено, клиент подключается с этого Mac и его конфигурация совпадает с диалогом. |
| Knowledge base not found | Включите базу знаний в **Общие базы знаний**. Для клиентов скрытая и отсутствующая база выглядят одинаково. |
| В браузере URL открывается с 405 | GET из браузера — не MCP-запрос. Подключайтесь MCP-клиентом. |
| Длинный документ возвращается неполностью | Попросите клиент запросить следующие страницы через `item_read`. |

Чтобы закрыть весь доступ, выключите **Включить MCP базы знаний**. Чтобы сузить то, что клиенты могут получить, выключите отдельные базы знаний в **Общие базы знаний**.

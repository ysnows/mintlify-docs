Enconvo может предоставлять ваши базы знаний MCP-совместимым AI-клиентам на том же Mac. Клиенты могут искать и читать базы знаний, к которым вы открыли доступ, и ничего больше; доступ только для чтения. Это отдельная функция от **Настройки → Серверы MCP**, которая добавляет внешние инструменты Агентам Enconvo.

## Подключите клиент

1. Откройте [Базу знаний](/ru/ai/knowledge-base), нажмите на шестерёнку (**Настройки базы знаний**), затем **AI-клиенты (MCP)**.
2. Включите **Включить MCP базы знаний**. По умолчанию он выключен, а пока он выключен, подключённым клиентам отказывают.
3. Выберите, что могут видеть клиенты. **Поделиться этой базой знаний с клиентами AI** относится к открытой у вас базе, а **Общие базы знаний** перечисляет их все. История диктовки и Память скрыты, пока вы их не включите.
4. В разделе **Подключить клиент** выберите свой клиент (Claude Code, Cursor, Codex или Claude Desktop) и скопируйте его настройку.
5. Попросите клиент показать список баз знаний, затем найти что-нибудь в одной из них и прочитать подходящий элемент.

Локальный адрес:

```text
http://localhost:54535/knowledge_base/mcp
```

Используется транспорт Streamable HTTP. Не закрывайте Enconvo, пока клиент им пользуется. Claude Desktop подключается через небольшой мост `mcp-remote`, поэтому для его настройки нужен Node.js; следуйте инструкциям для конкретного клиента, показанным в диалоге.

## Доступные инструменты

| Инструмент | Назначение |
| --- | --- |
| `kb_list` | Показать список видимых баз знаний |
| `kb_search` | Искать в видимой базе знаний |
| `item_list` | Показать список элементов в видимой базе знаний |
| `item_read` | Читать проиндексированный текст элемента по страницам |

Инструменты только для чтения. Этот адрес не предоставляет общих инструментов для Памяти или Записей. При чтении элемента в метаданных может возвращаться путь к источнику или URL.

## Доступ и обработка

Сервер принимает только соединения с локального адреса и не требует токена. Включив его, вы позволяете локальным процессам читать базы знаний, к которым вы открыли доступ. Подключённый AI-клиент может отправить полученное своему провайдеру модели, поэтому проверьте также настройки этого клиента.

Поиск использует модель эмбеддингов, заданную в разделе **Поиск** в **Настройки → Память**. Когда она работает в Enconvo Cloud, текст поиска отправляется туда. «Локальный адрес» не означает, что все этапы поиска и ответа выполняются офлайн.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Соединение отклонено | Убедитесь, что Enconvo и его локальный API запущены. |
| Forbidden / 403 | Проверьте, что **Включить MCP базы знаний** включено, что клиент подключается с этого Mac и что его конфигурация совпадает с показанной в диалоге. |
| База знаний не найдена | Включите базу знаний в разделе **Общие базы знаний**. Для клиентов скрытые и несуществующие базы знаний выглядят одинаково. |
| При открытии URL в браузере появляется 405 | GET-запрос из браузера не является MCP-запросом. Подключитесь с помощью MCP-клиента. |
| Длинный документ приходит не полностью | Попросите клиент запросить следующие страницы через `item_read`. |

Чтобы закрыть любой доступ, выключите **Включить MCP базы знаний**. Чтобы сузить то, что клиенты могут получать, выключите отдельные базы знаний в разделе **Общие базы знаний**.

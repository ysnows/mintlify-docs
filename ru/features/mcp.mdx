[Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт, который позволяет моделям ИИ пользоваться внешними инструментами и данными. Каждый сервер MCP предлагает инструменты, которые агент может вызывать, например читать файлы, запрашивать базу данных или отправлять сообщение. Добавьте сервер в Enconvo, и агенты сами пользуются его инструментами, когда задаче они нужны.

## Добавить сервер в Настройках

<Steps>
  <Step title="Откройте серверы MCP">
    Откройте **Настройки** из значка Enconvo в строке меню (**Settings...**) или нажмите **⌘,**. Затем откройте **Настройки → Серверы MCP**.
  </Step>
  <Step title="Добавьте сервер">
    Нажмите **Добавить сервер** и введите **Имя сервера**. Выберите транспорт: **STDIO** для команды, которая работает на Mac, или **HTTP** или **SSE** для сервера по URL. Заполните поля и нажмите **Сохранить**.
  </Step>
  <Step title="Проверьте, что он подключается">
    Точка рядом с сервером становится зеленой, а строка показывает, сколько у него инструментов. Нажмите число инструментов, чтобы увидеть их.
  </Step>
  <Step title="Выберите, где применяются его инструменты">
    Используйте переключатель в строке сервера. Включен: Enconvo включает инструменты сервера каждый раз, когда помощник готовит ответ, везде. Выключен: они не загружаются везде, но сервер все еще можно добавить из SmartBar или включить для одного приложения в боковом меню приложения.
  </Step>
</Steps>

Серверы с OAuth открывают страницу входа при первом подключении. Если сервер показывает **Войти**, нажмите и закончите вход. **Предоставить доступ** появляется, когда подключенный сервер просит больше доступа, чем дал вход.

Серверы, которые идут с плагином, перечислены в **Из плагинов**.

<Tip>
Боковая панель Настроек длинная. Нажмите **⌘F** в Настройках и введите «MCP», чтобы перейти к панели, или откройте ее deeplink `enconvo://preference?pane=mcp_management`.
</Tip>

## Добавить сервер из CLI

```bash
# Add a stdio server
enconvo mcp add github --command npx --args "-y @modelcontextprotocol/server-github"

# Add an HTTP server
enconvo mcp add notion --transport http --url "https://mcp.notion.com/mcp"

# List servers
enconvo mcp servers list

# List tools
enconvo mcp tools list
```

## Импортировать серверы из другого приложения

Принесите конфигурации MCP, которыми уже пользуетесь в Claude Desktop, Cursor или другом инструменте.

1. В **Настройки → Серверы MCP** нажмите **Импортировать**.
2. В **Config Format** выберите **Claude Desktop** или **Codex CLI**.
3. Вставьте конфигурацию в **JSON Config**.
4. Нажмите **Импортировать**. Добавляется каждый сервер в ней.

## Установить пакет MCP

Пакет MCP — это файл `.mcpb`, который упаковывает сервер для запуска на Mac. В **Настройки → Серверы MCP** нажмите **Установить пакет** и выберите файл. Открытие файла `.mcpb` в Finder приводит туда же.

Сервер пакета работает на Mac с вашими разрешениями, так что ставьте пакеты только от тех, кому доверяете. Чтобы обновить, установите более новый файл `.mcpb`.

## Поделиться ссылкой установки

Ссылка установки добавляет сервер MCP в Enconvo одним нажатием. Она использует тот же формат, что `mcp.json`: имя и конфигурация транспорта.

```
https://enconvo.com/mcp/install?name=$NAME&config=$BASE64_ENCODED_CONFIG
```

| Компонент | Описание |
|-----------|-------------|
| `https://enconvo.com` | Веб-страница установки |
| `/mcp/install` | Путь |
| `name` | Параметр запроса для имени сервера |
| `config` | Параметр запроса для конфигурации JSON в base64 |

Веб-страница открывает deeplink `enconvo://` и показывает конфигурацию сервера на случай, если приложение не откроется.

### Сделать ссылку

1. Получите имя сервера и конфигурацию JSON.
2. Сделайте `JSON.stringify` конфигурации, затем закодируйте в base64.
3. Замените `$NAME` и `$BASE64_ENCODED_CONFIG` именем и закодированной конфигурацией.

Например, эта конфигурация:

```json Single MCP server config
{
  "exa": {
    "url": "https://mcp.exa.ai/mcp"
  }
}
```

дает такие результаты:

| Формат | Пример |
|--------|---------|
| Текстовая ссылка | `https://enconvo.com/mcp/install?name=exa&config=eyJ1cmwiOiJodHRwczovL21jcC5leGEuYWkvbWNwIn0=` |

### Что происходит, когда кто-то ее открывает

1. Он нажимает ссылку или вставляет ее в браузер.
2. Enconvo спрашивает **Add the MCP server "name"?** и показывает, что сервер запускает или к чему подключается. Он нажимает **Добавить**.
3. Открываются **Настройки → Серверы MCP**, сервер добавляется и начинает подключаться.
4. Когда он подключен, агенты могут пользоваться его инструментами.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Сервер не запускается | Проверьте команду и аргументы. Для сервера STDIO убедитесь, что программа установлена и есть в `PATH`. Для сервера Node.js убедитесь, что доступны `npx` или `node`. |
| Его инструменты не появляются | Проверьте, что точка сервера зеленая. Некоторым серверам нужен ключ API, прежде чем они предложат инструменты. Выключите сервер и включите снова. |
| Сервер показывает **Войти** | Нажмите и закончите вход на открывшейся странице. |
| Ошибки аутентификации | Проверьте, что ключи API верны и не истекли и что заданы переменные окружения, которые нужны серверу. |

Полную спецификацию MCP см. на [modelcontextprotocol.io](https://modelcontextprotocol.io).

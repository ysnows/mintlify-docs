[Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт, который позволяет моделям ИИ использовать внешние инструменты и данные. Каждый сервер MCP предлагает инструменты, которые может вызывать агент, например чтение файлов, запросы к базе данных или отправку сообщения. Добавьте сервер в Enconvo, и агенты будут сами использовать его инструменты, когда они нужны для задачи.

## Добавление сервера в настройках

<Steps>
  <Step title="Откройте серверы MCP">
    Откройте **Настройки** через значок Enconvo в строке меню (**Настройки...**) или нажмите **⌘,**. Затем откройте **Настройки → Серверы MCP**.
  </Step>
  <Step title="Добавьте сервер">
    Нажмите **Добавить сервер** и введите **Имя сервера**. Выберите транспорт: **STDIO** для команды, которая запускается на вашем Mac, или **HTTP** либо **SSE** для сервера по URL. Заполните его поля и нажмите **Сохранить**.
  </Step>
  <Step title="Убедитесь, что он подключается">
    Точка рядом с сервером становится зелёной, а в его строке показано, сколько у него инструментов. Нажмите на число инструментов, чтобы увидеть их.
  </Step>
  <Step title="Выберите, где применяются его инструменты">
    Используйте переключатель в строке сервера. Включён: Enconvo добавляет инструменты сервера всякий раз, когда ассистент готовит ответ, везде. Выключен: они не загружаются везде, но вы всё равно можете добавить сервер из SmartBar или включить его для одного приложения в Боковом меню приложения.
  </Step>
</Steps>

Серверы, которые используют OAuth, при первом подключении открывают страницу входа. Если у сервера показано **Пройти аутентификацию**, нажмите это и завершите вход. **Предоставить доступ** появляется, когда подключённый сервер запрашивает больше доступа, чем дал ваш вход.

Серверы, которые поставляются с плагином, перечислены в разделе **Из плагинов**.

<Tip>
Боковая панель настроек длинная. Нажмите **⌘F** в настройках и введите «MCP», чтобы перейти к нужному разделу, или откройте его по ссылке deeplink `enconvo://preference?pane=mcp_management`.
</Tip>

## Добавление сервера через CLI

```bash
# Add a stdio server
enconvo mcp add github --command npx --args "-y @modelcontextprotocol/server-github"

# Add an HTTP server
enconvo mcp add notion --transport http --url "https://mcp.notion.com/mcp"

# List servers
enconvo mcp servers list

# List tools
enconvo mcp tools list
```

## Импорт серверов из другого приложения

Перенесите конфигурации MCP, которые вы уже используете в Claude Desktop, Cursor или другом инструменте.

1. В **Настройки → Серверы MCP** нажмите **Импортировать**.
2. В поле **Формат конфигурации** выберите **Claude Desktop** или **Codex CLI**.
3. Вставьте конфигурацию в **Конфигурация JSON**.
4. Нажмите **Импортировать**. Будут добавлены все серверы из неё.

## Установка пакета MCP

Пакет MCP — это файл `.mcpb`, в который упакован сервер, запускаемый на вашем Mac. В **Настройки → Серверы MCP** нажмите **Установить пакет** и выберите файл. Открытие файла `.mcpb` в Finder приводит в то же место.

Сервер из пакета запускается на вашем Mac с вашими правами, поэтому устанавливайте пакеты только от людей, которым вы доверяете. Чтобы обновить пакет, установите более новый файл `.mcpb`.

## Как поделиться ссылкой установки

Ссылка установки добавляет сервер MCP в Enconvo одним щелчком. Она использует тот же формат, что и `mcp.json`: имя и конфигурацию транспорта.

```
https://enconvo.com/mcp/install?name=$NAME&config=$BASE64_ENCODED_CONFIG
```

| Компонент | Описание |
|-----------|-------------|
| `https://enconvo.com` | Веб-страница установки |
| `/mcp/install` | Путь |
| `name` | Параметр запроса с именем сервера |
| `config` | Параметр запроса с конфигурацией JSON в кодировке base64 |

Веб-страница открывает ссылку deeplink `enconvo://` и показывает конфигурацию сервера на случай, если приложение не откроется.

### Как составить ссылку

1. Возьмите имя сервера и его конфигурацию JSON.
2. Примените к конфигурации `JSON.stringify`, затем закодируйте её в base64.
3. Замените `$NAME` и `$BASE64_ENCODED_CONFIG` именем и закодированной конфигурацией.

Например, эта конфигурация:

```json Single MCP server config
{
  "exa": {
    "url": "https://mcp.exa.ai/mcp"
  }
}
```

даёт такие результаты:

| Формат | Пример |
|--------|---------|
| Текстовая ссылка | `https://enconvo.com/mcp/install?name=exa&config=eyJ1cmwiOiJodHRwczovL21jcC5leGEuYWkvbWNwIn0=` |

### Что происходит, когда кто-то открывает ссылку

1. Человек щёлкает ссылку или вставляет её в браузер.
2. Enconvo спрашивает **Добавить сервер MCP «name»?** и показывает, что сервер запускает или к чему подключается. Человек нажимает **Добавить**.
3. Открывается **Настройки → Серверы MCP**, сервер добавляется и начинает подключаться.
4. Когда он подключён, агенты могут использовать его инструменты.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Сервер не запускается | Проверьте команду и аргументы. Для сервера STDIO убедитесь, что программа установлена и находится в `PATH`. Для сервера Node.js убедитесь, что доступны `npx` или `node`. |
| Его инструменты не появляются | Проверьте, что точка сервера зелёная. Некоторым серверам нужен ключ API, прежде чем они предложат инструменты. Выключите сервер и включите снова. |
| У сервера показано **Пройти аутентификацию** | Нажмите это и завершите вход на открывшейся странице. |
| Ошибки аутентификации | Проверьте, что ключи API верны и не истекли, а переменные окружения, нужные серверу, заданы. |

Полную спецификацию MCP смотрите на [modelcontextprotocol.io](https://modelcontextprotocol.io).

Расширение для браузера Enconvo Companion позволяет Enconvo управлять вашим настоящим браузером, когда задаче нужно состояние браузера с выполненными входами. Используйте его для таких сайтов, как LinkedIn, Gmail, Salesforce, панели мониторинга или внутренние инструменты, где важны ваши cookie и расширения браузера. В настройках оно называется **Сопутствующее приложение для браузера**.

Для публичных страниц, локальных предпросмотров и сценариев, которые не должны затрагивать ваш личный профиль браузера, используйте изолированную автоматизацию браузера.

## Установка расширения

<Steps>
  <Step title="Установите расширение">
    Откройте **Настройки → Browser Use** и нажмите **Установить сопутствующее приложение для браузера** в разделе **Расширения для браузера**. Откроется страница расширения в Chrome Web Store. Его также можно установить из магазина расширений вашего браузера. Оно работает в Chrome, Edge, Brave, Arc, Vivaldi, Opera и Firefox. В [видеоуроке по Computer Use](https://youtu.be/0CbQA7d8zqU?t=33) показана установка в Chrome.
  </Step>
  <Step title="Не закрывайте браузер">
    Расширение подключается к Enconvo само, через `ws://localhost:11225`.
  </Step>
  <Step title="Проверьте всплывающее окно">
    Нажмите значок расширения. Во всплывающем окне отображается **Connected Chrome**, **Connected Edge**, **Connected Firefox** или название браузера, в котором вы находитесь.
  </Step>
  <Step title="Запустите задачу в браузере">
    Попросите Enconvo прочитать страницу, нажать, ввести текст, сделать снимок экрана или управлять вкладками в браузере.
  </Step>
</Steps>

## Всплывающее окно

| Элемент | Что показывает |
| --- | --- |
| Состояние подключения | Подключено ли расширение этого браузера к Enconvo |
| Текущий браузер | Браузер, под которым подключено это расширение, например Chrome, Edge, Brave или Firefox |
| Подключённые браузеры | Другие браузеры, расширения которых сейчас подключены к Enconvo |
| Версия | Установленная версия расширения |
| **Подробнее** | Открывает эту страницу |

Если во всплывающем окне написано, что подключения нет, перезапустите Enconvo и обновите браузер. Если подключиться по-прежнему не удаётся, выключите и снова включите расширение.

## Несколько браузеров

Enconvo может подключаться сразу к нескольким браузерам. Если задача не называет браузер, Enconvo выбирает его в таком порядке:

1. **Браузер по умолчанию**, выбранный в настройках Browser Use (**Настройки → Browser Use**, затем **Настройки** в меню **⋯**).
2. Браузер по умолчанию на вашем Mac.
3. Подключённый браузер, которым вы пользовались последним.

Браузер можно указать и в API автоматизации:

```json
{
  "browser": "edge"
}
```

Обычные значения: `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera` и `firefox`.

## Как остаться на нужной вкладке

Когда задача в браузере начинается, Enconvo запоминает браузер и вкладку, в которой работает. Следующие шаги по возможности остаются на этой вкладке, даже если страница открывает всплывающее окно, перезагружается или теряет фокус.

Чтобы получить лучший результат:

- Держите вкладку открытой, пока задача не завершится.
- Называйте браузер, если подключено несколько.
- Скажите «используй текущую вкладку», если хотите, чтобы Enconvo действовал на странице перед вами.
- Попросите заново посмотреть на страницу после перехода или отправки формы.

## Доступ к сайтам и безопасность

Веб-страницы могут содержать инструкции, которые писали не вы. На важных страницах проверьте сайт и действие, прежде чем позволить Enconvo продолжить.

Расширение использует разрешения браузера, чтобы читать страницы, нажимать, вводить текст, делать снимки экрана, видеть вкладки и читать cookie, когда это нужно задаче. Относитесь к страницам с выполненным входом, истории браузера и внутренним инструментам как к конфиденциальным данным.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Во всплывающем окне написано, что подключения нет | Убедитесь, что Enconvo запущен, перезапустите браузер, затем выключите и снова включите расширение. Проверьте, что ничто не блокирует `localhost:11225`. |
| Управляется не тот браузер | Задайте **Браузер по умолчанию** в настройках Browser Use или передайте в действии браузера значение, например `edge`, `chrome` или `firefox`. |
| Подключено, но страницей нельзя управлять | Страницами браузера, такими как `chrome://`, управлять нельзя. Помешать могут также страницы со строгой политикой безопасности содержимого, закрытый Shadow DOM и запросы разрешений браузера. |
| Не работает загрузка файла | На странице сведений о расширении в вашем браузере включите доступ к URL-адресам файлов. Он нужен задачам, которые загружают локальные файлы или открывают страницы из файлов. |

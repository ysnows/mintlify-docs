title: "Расширение браузера"
description: "Установите расширение Enconvo Companion, чтобы Enconvo работал в вашем настоящем браузере, с вашими входами, cookie и расширениями."
---

Расширение браузера Enconvo, Enconvo Companion, позволяет Enconvo управлять вашим настоящим браузером, когда задаче нужно ваше состояние входа. Пользуйтесь им на сайтах вроде LinkedIn, Gmail, Salesforce, панелей и внутренних инструментов, где важны cookie и расширения браузера. В настройках оно называется **Browser Companion**.

Для публичных страниц, локальных предпросмотров или рабочих процессов, которые не должны трогать личный профиль браузера, используйте изолированную автоматизацию браузера.

## Настроить расширение

<Steps>
  <Step title="Установите расширение">
    Откройте **Настройки → Browser Use** и нажмите **Установить сопутствующее приложение для браузера** в **Расширениях для браузера**. Откроется страница расширения в Chrome Web Store. Его можно установить и из магазина расширений браузера. Оно работает в Chrome, Edge, Brave, Arc, Vivaldi, Opera и Firefox. [Видеоурок по Управлению компьютером](https://youtu.be/0CbQA7d8zqU?t=33) показывает установку в Chrome.
  </Step>
  <Step title="Держите браузер открытым">
    Расширение само подключается к Enconvo по `ws://localhost:11225`.
  </Step>
  <Step title="Проверьте всплывающее окно">
    Нажмите значок расширения. Всплывающее окно показывает **Connected Chrome**, **Connected Edge**, **Connected Firefox** или имя браузера, в котором вы находитесь.
  </Step>
  <Step title="Начните задачу в браузере">
    Попросите Enconvo прочитать, нажать, ввести текст, сделать снимок экрана или управлять вкладками в браузере.
  </Step>
</Steps>

## Всплывающее окно

| Пункт | Что показывает |
| --- | --- |
| Состояние соединения | Подключено ли расширение этого браузера к Enconvo |
| Текущий браузер | Браузер, к которому подключено это расширение, например Chrome, Edge, Brave или Firefox |
| Подключённые браузеры | Другие браузеры, чьё расширение сейчас подключено к Enconvo |
| Версия | Версия установленного расширения |
| **Подробнее** | Открывает эту страницу |

Если всплывающее окно говорит, что соединения нет, перезапустите Enconvo и обновите браузер. Если всё ещё не подключается, выключите расширение и включите снова.

## Несколько браузеров

Enconvo может подключаться к нескольким браузерам сразу. Если задача не называет браузер, Enconvo выбирает в таком порядке:

1. **Браузер по умолчанию**, который вы выбрали в настройках Browser Use (**Настройки → Browser Use**, затем **Настройки** в меню **⋯**).
2. Браузер по умолчанию на Mac.
3. Подключённый браузер, которым вы пользовались последним.

API автоматизации тоже могут назвать браузер:

```json
{
  "browser": "edge"
}
```

Обычные значения: `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera` и `firefox`.

## Оставаться на нужной вкладке

Когда начинается задача в браузере, Enconvo запоминает браузер и вкладку, в которых работает. Дальнейшие шаги остаются на этой вкладке, когда могут, даже если страница открывает всплывающее окно, перезагружается или теряет фокус.

Для лучшего результата:

- Держите вкладку открытой, пока задача не закончится.
- Называйте браузер, когда подключено несколько.
- Скажите «используй текущую вкладку», если хотите, чтобы Enconvo действовал на странице перед вами.
- Просите свежий взгляд на страницу после перехода или отправки формы.

## Доступ к сайтам и безопасность

Веб-страницы могут содержать инструкции, которые вы не писали. На чувствительных страницах проверьте сайт и действие, прежде чем позволить Enconvo продолжать.

Расширение использует разрешения браузера, чтобы читать страницы, нажимать, вводить текст, делать снимки экрана, видеть вкладки и читать cookie, когда это нужно задаче. Страницы, где вы вошли, историю браузера и внутренние инструменты считайте чувствительными данными.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Всплывающее окно говорит, что соединения нет | Убедитесь, что Enconvo запущен, перезапустите браузер, затем выключите расширение и включите снова. Проверьте, что ничто не блокирует `localhost:11225`. |
| Управляется не тот браузер | Задайте браузер по умолчанию в настройках Browser Use или передайте значение браузера, например `edge`, `chrome` или `firefox`, в действии браузера. |
| Подключено, но страницей нельзя управлять | Страницами браузера вроде `chrome://` управлять нельзя. Мешать могут также страницы со строгой политикой безопасности содержимого, закрытый Shadow DOM и запросы разрешений браузера. |
| Загрузка файла не работает | На странице сведений расширения в браузере включите доступ к URL файлов. Он нужен задачам, которые загружают локальные файлы или открывают страницы из файлов. |

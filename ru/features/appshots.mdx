Appshots добавляет окно приложения на переднем плане в чат как контекст. Пользуйтесь им, когда хотите спросить о том, что на экране, не сохраняя это в базу знаний.

## Снять окно приложения

1. Выведите на передний план приложение, о котором хотите спросить.
2. Нажмите горячую клавишу Appshots. У Appshots нет клавиши, пока вы не зададите её в **Сочетание клавиш** в **Настройки → Appshots**.
3. Окно уходит в SmartBar, Окно чата или Боковое меню приложения, если одно из них открыто на переднем плане. Иначе оно уходит в Dynamic Island. Коротко звучит затвор.
4. Проверьте приложенное окно и задайте конкретный вопрос, например «Объясни ошибку в этом окне».

## Настройки

Откройте **Настройки → Appshots**.

| Настройка | Что делает |
| --- | --- |
| **Включить Appshots** | Позволяет горячей клавише добавить окно приложения на переднем плане. Включено по умолчанию. |
| **Записывать звук** | Проигрывает короткий звук затвора, когда добавлен Appshot. Звук подтверждает захват; всё равно проверьте вложение перед отправкой. |
| **Сочетание клавиш** | Сочетание, которое добавляет окно. По умолчанию нет. Это может быть набор клавиш-модификаторов, например обе клавиши **Option** вместе, или обычное сочетание. |

## Какой инструмент захвата выбрать

| Цель | Используйте |
| --- | --- |
| Спросить об окне текущего приложения | Appshots |
| Обратить внимание на область перед вопросом | [Рисование на экране](/ru/features/screen-doodle) |
| Сохранить содержимое текущего приложения для позднего поиска | [Быстрая запись](/ru/features/quick-capture) |
| Извлечь текст из изображения | [OCR](/ru/ai/ocr) |

Захваченное содержимое может уйти модели, которой вы пользуетесь для запроса. Другие способы добавить контекст — в [Контекстной осведомлённости](/ru/features/context-awareness).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Контекст не появляется | Проверьте **Настройки → Разрешения**, особенно запись экрана и Универсальный доступ. |
| Захвачено не то окно | Снова выведите нужное приложение на передний план. Appshots снимает окно другого приложения, а не собственные окна Enconvo, например Настройки. |
| Горячая клавиша ничего не делает | Убедитесь, что **Включить Appshots** включено и задано **Сочетание клавиш**. |
| Горячая клавиша делает что-то другое | Другое приложение использует те же клавиши. Измените **Сочетание клавиш** в **Настройки → Appshots**. |

Appshots добавляет в чат окно приложения на переднем плане в качестве контекста. Используйте его, когда хотите спросить о чём-то на экране, не сохраняя это в базу знаний.

## Снимок окна приложения

1. Выведите на передний план приложение, о котором хотите спросить.
2. Нажмите горячую клавишу Appshots. Пока вы не зададите её в **Сочетание клавиш** в **Настройки → Appshots**, у Appshots её нет.
3. Окно попадает в SmartBar, Окно чата или Боковое меню приложения, если одно из них открыто на переднем плане. В противном случае оно попадает на Dynamic Island. Проигрывается короткий звук затвора.
4. Проверьте прикреплённое окно, затем задайте конкретный вопрос, например: «Объясни ошибку в этом окне».

## Настройки

Откройте **Настройки → Appshots**.

| Параметр | Что делает |
| --- | --- |
| **Включить Appshots** | Позволяет горячей клавише добавлять окно приложения на переднем плане. Включено по умолчанию. |
| **Записывать звук** | Проигрывает короткий звук затвора при добавлении Appshot. Звук подтверждает захват; всё равно проверьте вложение перед отправкой. |
| **Сочетание клавиш** | Сочетание, которое добавляет окно. По умолчанию не задано. Это может быть набор клавиш-модификаторов, например обе клавиши **Option** вместе, или обычное сочетание. |

## Выбор подходящего инструмента захвата

| Цель | Что использовать |
| --- | --- |
| Спросить об окне текущего приложения | Appshots |
| Привлечь внимание к области, прежде чем спросить | [Рисование на экране](/ru/features/screen-doodle) |
| Сохранить содержимое текущего приложения для последующего поиска | [Быстрая запись](/ru/features/quick-capture) |
| Извлечь текст из изображения | [OCR](/ru/ai/ocr) |

Захваченное содержимое может быть отправлено модели, которую вы используете для запроса. Другие способы добавить контекст см. в [Контекстная осведомленность](/ru/features/context-awareness).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Контекст не появляется | Проверьте **Настройки → Разрешения**, особенно запись экрана и универсальный доступ. |
| Захватывается не то окно | Снова выведите нужное приложение на передний план. Appshots захватывает окно другого приложения, а не собственные окна Enconvo, например Настройки. |
| Горячая клавиша ничего не делает | Убедитесь, что **Включить Appshots** включено и **Сочетание клавиш** задано. |
| Горячая клавиша делает что-то другое | Другое приложение использует те же клавиши. Измените **Сочетание клавиш** в **Настройки → Appshots**. |

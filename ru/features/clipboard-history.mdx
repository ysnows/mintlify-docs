История буфера обмена, поиск по закладкам браузера и поиск файлов — это три быстрых списка, по которым вы ищете прямо во время ввода. Используйте историю буфера обмена, чтобы вставить то, что вы копировали раньше, поиск по закладкам — чтобы открыть сохранённую страницу в любом браузере, а поиск файлов — чтобы открыть файл без Finder. Каждый список открывается своим сочетанием клавиш или из SmartBar по псевдониму.

## Как открыть список

1. Задайте сочетание клавиш для списка в **Настройки → Сочетание клавиш** или на странице настроек самого списка в **Настройки → Плагины**.
2. Нажмите это сочетание. Если включён параметр **Сочетание клавиш открывает окно** (по умолчанию он включён), список открывается в собственном окне, а SmartBar остаётся как есть.
3. Вводите текст, чтобы отфильтровать список, переходите к элементу стрелками и нажмите Return.

Чтобы вместо этого открыть список внутри SmartBar, задайте его **Псевдоним**. Введите в SmartBar псевдоним и пробел, и список откроется там. В поиске SmartBar показан псевдоним каждого списка.

Список также можно упомянуть в чате через `@`, и Агент выполнит поиск по нему за вас.

## Вставка из истории буфера обмена

История буфера обмена хранит текст, изображения и файлы, которые вы копируете. Можно закреплять избранное и фильтровать по ссылкам, адресам электронной почты, цветам, изображениям или файлам.

1. Откройте историю буфера обмена.
2. Введите слово из того, что вы копировали.
3. Нажмите Return, чтобы вставить элемент в приложение, которым вы пользовались. Нажмите **⌘C**, чтобы вместо этого скопировать его. Если для **Клавиша Return** выбрано копирование, вставляет **⌘Return**.

Когда вы открываете список поверх одного из окон самого Enconvo, Return вставляет в поле сообщения этого окна.

Менеджеры паролей и «Связка ключей» по умолчанию исключены, а копии, которые приложения помечают как скрытые или временные, например пароли, не записываются никогда.

## Как открыть закладку

Поиск по закладкам браузера читает закладки Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox и Zen, включая профили Firefox и Zen, хранящиеся в выбранной вами папке. Поиск совпадает и с названиями папок.

Нажмите Return, чтобы открыть закладку в браузере, из которого она взята, или **⌘O**, чтобы открыть её в браузере по умолчанию. Параметр **Клавиша Return** меняет их местами.

## Как найти файл

По умолчанию поиск файлов ищет по всему вашему Mac. Раскрывающийся список в его поле поиска позволяет искать только в одном месте и только для этого поиска, например в **Мои папки**, **Главная** или **Загрузки**.

Нажмите Return, чтобы открыть файл, или **⌘Return**, чтобы показать его в Finder. Параметр **Клавиша Return** меняет их местами.

## Настройки

Откройте **Настройки → Плагины**, затем **История буфера обмена**, **Закладки браузера** или **Поиск файлов**.

| Параметр | Список | Что он меняет |
| --- | --- | --- |
| **Псевдоним** | Все три | Слово, которое вы вводите в SmartBar, а затем пробел, чтобы открыть список там. |
| **Сочетание клавиш открывает окно** | Все три | Включено: сочетание открывает список в собственном окне. Выключено: сочетание открывает его в SmartBar. По умолчанию включено. |
| **Клавиша Return** | Все три | Что делает Return. История буфера обмена: **Вставить в приложение на переднем плане** или **Скопировать в буфер обмена**. Закладки: **Открыть в соответствующем браузере** или **Открыть в браузере по умолчанию**. Файлы: **Открыть** или **Показать в Finder**. |
| **Записывать историю буфера обмена** | История буфера обмена | Хранит историю того, что вы копируете. При отключении уже сохранённые элементы остаются. |
| **Хранить историю** | История буфера обмена | Сколько времени хранятся элементы: от **1 день** до **Бессрочно**. По умолчанию 3 месяца. Закреплённые элементы не удаляются никогда. |
| **Игнорируемые приложения** | История буфера обмена | Приложения, копии из которых не записываются никогда, по идентификатору пакета. |
| **Показывать имена папок** | Закладки | Показывает папку каждой закладки. |
| **Отключённые браузеры** | Закладки | Браузеры, закладки которых исключены. |
| **Искать в** | Файлы | Где поиск файлов ищет при открытии: **Этот Mac**, **Мои папки**, **Главная**, **Рабочий стол**, **Документы**, **Загрузки** или **Приложения**. |
| **Папки для поиска** | Файлы | Папки, по которым ищет **Мои папки**. Если пусто, это «Рабочий стол», «Документы» и «Загрузки». |
| **Показывать скрытые файлы** | Файлы | Включает файлы, имена которых начинаются с точки. |
| **Исключенные папки** | Файлы | Папки, содержимое которых никогда не показывается. |

Сочетание клавиш или псевдоним, заданные вами в более старых веб-версиях этих списков, переносятся.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Сочетание клавиш открывает SmartBar вместо окна | Включите **Сочетание клавиш открывает окно** для этого списка. |
| Копии нет в истории буфера обмена | Проверьте **Записывать историю буфера обмена** и **Игнорируемые приложения**. Скрытые копии, например пароли, не записываются никогда. |
| Нет закладок какого-то браузера | Проверьте **Отключённые браузеры**. |
| Файл не отображается | Проверьте **Искать в**, **Исключенные папки** и **Показывать скрытые файлы**. |

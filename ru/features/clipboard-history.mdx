История буфера обмена, поиск закладок браузера и поиск файлов — три быстрых списка, которые фильтруются по мере набора. История буфера вставляет то, что вы копировали раньше, поиск закладок открывает сохранённую страницу в любом браузере, а поиск файлов открывает файл без Finder. Каждый открывается своим сочетанием или из SmartBar по псевдониму.

## Открыть список

1. Задайте сочетание для списка в **Настройки → Shortcut** или на его странице настроек в **Настройки → Плагины**.
2. Нажмите сочетание. С включённым **Hotkey Opens a Window**, это значение по умолчанию, список открывается в своём окне, а SmartBar остаётся как был.
3. Наберите, чтобы отфильтровать список, перейдите к элементу стрелками и нажмите Return.

Чтобы открыть список внутри SmartBar, задайте его **Alias**. Наберите псевдоним и пробел в SmartBar, и список откроется там. Поиск SmartBar показывает псевдоним каждого списка.

Список можно также упомянуть через `@` в чате, и агент поищет в нём за вас.

## Вставить из истории буфера

История буфера хранит текст, изображения и файлы, которые вы копируете. Можно закреплять избранное и фильтровать по ссылкам, почте, цветам, изображениям или файлам.

1. Откройте историю буфера.
2. Наберите слово из скопированного.
3. Нажмите Return, чтобы вставить элемент в приложение, с которым вы работали. **⌘C** копирует его вместо вставки. Если **Return Key** стоит на копирование, **⌘Return** вставляет.

Когда список открыт поверх одного из окон Enconvo, Return вставляет в поле сообщения этого окна.

Менеджеры паролей и Keychain Access по умолчанию не учитываются, а копии, которые приложения помечают как скрытые или временные, например пароли, никогда не записываются.

## Открыть закладку

Поиск закладок читает закладки Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox и Zen, включая профили Firefox и Zen в выбранной вами папке. Поиск совпадает и с именами папок.

Return открывает закладку в браузере, откуда она взята, а **⌘O** — в браузере по умолчанию. **Return Key** меняет их местами.

## Найти файл

Поиск файлов по умолчанию смотрит весь Mac. Выпадающий список в поле поиска ограничивает этот поиск одним местом, например **My Folders**, **Home** или **Downloads**.

Return открывает файл, **⌘Return** показывает его в Finder. **Return Key** меняет их местами.

## Настройки

Откройте **Настройки → Плагины**, затем **Clipboard History**, **Browser Bookmarks** или **File Search**.

| Настройка | Список | Что меняет |
| --- | --- | --- |
| **Alias** | Все три | Слово, которое вы набираете, затем пробел, в SmartBar, чтобы открыть список там. |
| **Hotkey Opens a Window** | Все три | Вкл.: сочетание открывает список в своём окне. Выкл.: сочетание открывает его в SmartBar. По умолчанию вкл. |
| **Return Key** | Все три | Что делает Return. История буфера: **Paste into the front app** или **Copy to the clipboard**. Закладки: **Open in its browser** или **Open in the default browser**. Файлы: **Open** или **Show in Finder**. |
| **Record Clipboard History** | История буфера | Ведёт историю скопированного. Выключение сохраняет уже сохранённые элементы. |
| **Keep History For** | История буфера | Как долго элементы остаются, от **1 Day** до **Forever**. По умолчанию 3 месяца. Закреплённые не удаляются. |
| **Ignored Apps** | История буфера | Приложения, чьи копии не записываются, по bundle ID. |
| **Show Folder Names** | Закладки | Показывает папку каждой закладки. |
| **Turned-off Browsers** | Закладки | Браузеры, чьи закладки не учитываются. |
| **Search In** | Файлы | Где поиск файлов смотрит при открытии: **This Mac**, **My Folders**, **Home**, **Desktop**, **Documents**, **Downloads** или **Applications**. |
| **Search Folders** | Файлы | Папки, которые ищет **My Folders**. Desktop, Documents и Downloads, если пусто. |
| **Show Hidden Files** | Файлы | Включает файлы, имена которых начинаются с точки. |
| **Excluded Folders** | Файлы | Папки, содержимое которых никогда не показывается. |

Сочетание или псевдоним, заданные в старых веб-версиях этих списков, переносятся.

## Устранение неполадок

| Проблема | Что сделать |
| --- | --- |
| Сочетание открывает SmartBar вместо окна | Включите **Hotkey Opens a Window** для этого списка. |
| Копии нет в истории буфера | Проверьте **Record Clipboard History** и **Ignored Apps**. Скрытые копии, например пароли, не записываются. |
| Нет закладок браузера | Проверьте **Turned-off Browsers**. |
| Файл не появляется | Проверьте **Search In**, **Excluded Folders** и **Show Hidden Files**. |

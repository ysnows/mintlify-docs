AI Command упаковывает повторяющийся запрос вместе с моделью и настройками, чтобы вы могли применять его к любому тексту одним щелчком. Используйте её для узкой задачи, например для переписывания ответа службы поддержки. Для более широкой работы с инструментами используйте [агента](/ru/ai/agents), для последовательности шагов — [рабочий процесс](/ru/workflows/introduction).

В видеоуроке ниже за 2 минуты создаётся команда, которая извлекает пункты действий из заметок о встрече: опишите её, попробуйте на собственном тексте, измените своими словами, добавьте в PopBar, задайте сочетание клавиш и запустите в другом приложении.

## Создайте команду

1. Откройте **Настройки → AI Commands** или запустите **Создать команду ИИ** из SmartBar и нажмите **Новая команда ИИ**.
2. Опишите своими словами, что должна делать команда, затем нажмите **Создать черновик**. Enconvo напишет название, значок и инструкции и сразу запустит их на примере.
3. Вставьте в образец немного собственного текста и нажмите **Повторить попытку**, чтобы увидеть результат на реальных данных.
4. Чтобы изменить поведение, введите изменение в **Хотите что-то изменить?**, например «сгруппируй по ответственным», и нажмите **Переписать**. Изменённые строки в инструкциях выделяются, а результат на образце запускается снова.
5. В разделе **Где использовать** оставьте включённым **Добавить в PopBar**, чтобы кнопка в PopBar появлялась при выделении текста, или нажмите **Добавить сочетание клавиш** и нажмите нужные клавиши.
6. Нажмите **Сохранить**.

Пример инструкции:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Запустите команду

- **Из PopBar:** выделите текст в любом приложении и нажмите кнопку команды. Когда результат готов, нажмите **Вставить**, чтобы заменить выделенное.
- **Сочетанием клавиш:** выделите текст и нажмите сочетание клавиш команды. Результат откроется в SmartBar, где его можно вставить.
- **Из SmartBar:** найдите команду по названию и запустите её на текущем вводе.
- **Через агента:** попросите агента в чате запустить команду. Когда команда завершится, агент продолжит ваш чат.

Чаты AI Commands, как встроенных, например «Перевести», так и ваших собственных, не отображаются в Окне чата, в **Истории** Dynamic Island и в списке чатов SmartBar.

## Измените команду

Откройте команду в **Настройки → AI Commands**, чтобы изменить её название и инструкции. Изменения сохраняются по мере ввода.

| Настройка | Что меняет |
| --- | --- |
| **PopBar** | Добавляет команду в PopBar или убирает её. |
| **Сочетание клавиш** | Клавиши, которые запускают команду на тексте, выделенном в любом приложении. |
| **Встроенный режим** | Работает без окна и вставляет результат поверх выделенного. |
| **Последующее действие** | Что команда делает с ответом по завершении, где это доступно. |
| **AI-модель** | Показывает, следует ли команда модели для всех AI Commands или использует выбранную для неё. Нажмите **Изменить**, чтобы выбрать. |

### Выберите модель для всех команд

AI Commands работают на Enconvo Fast, пока вы не выберете другую модель. Чтобы изменить её, откройте **Настройки → AI Commands** и нажмите **Все команды**. Модель в **AI-модель** также используется инструментами для письма, PopBar и функциями **Улучшить стиль** и **Перевести** Диктовки. **Использовать рекомендуемое** возвращает Enconvo Fast. Команды, выбравшие собственную модель, сохраняют её при смене этой; нажмите **Проверить**, чтобы увидеть их, или **Использовать … для всех**, чтобы перевести их на эту модель.

У встроенной команды вместо этого есть **Настроить**: оно создаёт вашу собственную копию, которую можно редактировать. У ваших собственных команд есть меню **⋯** с **Дублировать** и **Удалить**. Удаление команды также убирает её из PopBar и освобождает её сочетание клавиш.

## Используйте меняющийся контекст

Там, где поле поддерживает переменные, используйте выбор переменных, чтобы включить вводимый текст, выделенный текст, активное приложение или другой контекст. См. [Переменные](/ru/workflows/variables). Проверьте развёрнутый контекст, прежде чем использовать команду на приватных документах.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Команда пропала | Проверьте, что она сохранена, затем найдите её по названию. |
| Результат игнорирует выделенный текст | Проверьте настройки ввода и контекста команды и Универсальный доступ в [Разрешениях](/ru/configuration/permissions). |

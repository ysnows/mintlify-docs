AI Command упаковывает повторяемый запрос с его моделью и настройками, чтобы запускать его на любом тексте одним нажатием. Используйте его для узкой задачи, например переписать ответ поддержки. Для более широкой работы с инструментами используйте [агента](/ru/ai/agents); для последовательности шагов — [рабочий процесс](/ru/workflows/introduction).

Видеоурок ниже за 2 минуты делает команду, которая вытаскивает пункты действий из заметок встречи: опишите ее, попробуйте на своем тексте, измените своими словами, добавьте в PopBar, задайте горячую клавишу и запустите в другом приложении.

## Создать команду

1. Откройте **Настройки → AI Commands** или запустите **Create AI Command** из SmartBar и нажмите **New AI Command**.
2. Своими словами опишите, что должна делать команда, затем нажмите **Создать черновик**. Enconvo пишет заголовок, значок и инструкции и сразу запускает их на примере.
3. Вставьте свой текст в образец и нажмите **Повторить попытку**, чтобы увидеть результат на реальном вводе.
4. Чтобы изменить поведение, введите изменение в **Хотите что-то изменить?**, например «сгруппируй по владельцу», и нажмите **Переписать**. Измененные строки отмечены в инструкциях, и образец запускается снова.
5. В **Где использовать** оставьте **Добавить в PopBar** включенным, чтобы получать кнопку PopBar при выделении текста, или нажмите **Добавить сочетание клавиш** и нажмите нужные клавиши.
6. Нажмите **Сохранить**.

Пример инструкции:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Запустить команду

- **Из PopBar:** выделите текст в любом приложении и нажмите кнопку команды. Когда результат готов, нажмите **Вставить**, чтобы заменить выделение.
- **Горячей клавишей:** выделите текст и нажмите горячую клавишу команды. Результат открывается в SmartBar, откуда его можно вставить.
- **Из SmartBar:** найдите заголовок команды и запустите ее на текущем вводе.
- **От агента:** попросите агента в чате запустить команду за вас. Агент продолжает чат, когда команда закончена.

Чаты из AI Commands, встроенных вроде Translate и ваших, не показываются в окне чата, в **History** Dynamic Island и в списке чатов SmartBar.

## Изменить команду

Откройте команду в **Настройки → AI Commands**, чтобы править заголовок и инструкции. Изменения сохраняются по мере ввода.

| Настройка | Что меняет |
| --- | --- |
| **PopBar** | Ставит команду на PopBar или снимает ее. |
| **Сочетание клавиш** | Клавиши, которые запускают команду на тексте, выделенном в любом приложении. |
| **Встроенный режим** | Работает без окна и вставляет результат поверх выделения. |
| **Последующее действие** | Что команда делает с ответом, когда закончила, где это предлагается. |
| **AI-модель** | Показывает, следует ли команда модели для всех AI Commands или использует выбранную для нее. Нажмите **Изменить**, чтобы выбрать. |

### Выберите модель для всех команд

AI Commands работают на Enconvo Fast, пока вы не выберете другую модель. Чтобы изменить, откройте **Настройки → AI Commands** и нажмите **Все команды**. Модель в **AI-модель** также запускает инструменты для письма, PopBar и **Улучшить стиль** и **Translate** диктовки. **Использовать рекомендуемое** возвращает Enconvo Fast. Команды со своей моделью сохраняют ее, когда эта меняется; нажмите **Проверить**, чтобы увидеть их, или **Use … for all**, чтобы перевести их на эту модель.

Встроенная команда показывает **Настроить**: это делает вашу копию, которую можно править. У ваших команд меню **⋯** с **Дублировать** и **Удалить**. Удаление команды также снимает ее с PopBar и освобождает горячую клавишу.

## Использовать меняющийся контекст

Где поле поддерживает переменные, используйте выбор переменных, чтобы включить входной текст, выделенный текст, активное приложение или другой контекст. См. [Переменные](/ru/workflows/variables). Проверьте раскрытый контекст, прежде чем запускать команду на частных документах.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Команды нет | Проверьте, что она сохранена, затем найдите ее заголовок. |
| Результат игнорирует выделенный текст | Проверьте ввод и настройки контекста команды и «Универсальный доступ» в [Разрешениях](/ru/configuration/permissions). |

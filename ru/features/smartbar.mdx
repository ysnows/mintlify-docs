SmartBar — панель запуска, которую вы открываете из любого приложения, чтобы задать агенту вопрос или запустить команду. Нажмите **⌥Space**, наберите и нажмите Return. Берите её, когда нужен быстрый ответ, а затем возврат к делу.

Для других задач: [Окно чата](/ru/ai/chat) для длинных бесед и файлов, [боковое меню приложения](/ru/features/app-sidebar), чтобы работать рядом с одним приложением, [PopBar](/ru/features/popbar) для выделенного текста или [Dynamic Island](/ru/features/dynamic-island) и [питомец на рабочем столе](/ru/features/pet) как небольшая точка входа, которая остаётся на экране. [Управление окнами](/ru/features/window-management) сравнивает их все.

## Задать вопрос

1. Нажмите **⌥Space** или сочетание, заданное в **Настройки → SmartBar**.
2. Наберите вопрос. Сначала выберите другого агента или модель, если нужно.
3. Приложите контекст, который нужен агенту. Он не видит каждое открытое приложение; см. [Добавить контекст](/ru/features/smartbar).
4. Нажмите Return и следите за ответом или ходом инструментов. Чтобы остановить ответ, нажмите круглую кнопку остановки.
5. Скопируйте результат или наберите уточнение, чтобы продолжить беседу. Сообщение, набранное пока задача идёт, показывается сразу.

Когда слова совпадают с командой, Return запускает подсвеченную строку. Чтобы отправить слова агенту, нажмите **⌘Return** или **Send to AI**. **⌥Return** запускает второе действие строки.

В режиме агента чип **Разрешения** задаёт, когда агент спрашивает, прежде чем действовать, а его переключатель **Sandbox** ограничивает команды агента рабочей папкой. См. [Песочница агента](/ru/configuration/sandbox).

## Поиск по символам

Наберите один из этих символов в SmartBar, чтобы искать один вид элементов:

| Наберите | Чтобы |
| --- | --- |
| `@` | Искать команды |
| `#` | Добавить контекст |
| `$` | Использовать навык |
| `>` | Показать недавние задачи |
| `/` | Открыть действия, например выбор модели и рассуждений |

Первые четыре можно сменить в **Поиск** в **Настройки → SmartBar**. `/` сменить нельзя.

Выбирайте элементы из открывшегося списка, а не набирайте имя по памяти: список показывает команды и источники контекста, которые у вас есть. См. [Инструменты для письма](/ru/features/writing-tools), [Быстрые ссылки](/ru/features/quick-links) и [Контекстная осведомленность](/ru/features/context-awareness).

Некоторые списки открываются псевдонимом: наберите псевдоним и пробел, и [история буфера, поиск закладок или поиск файлов](/ru/features/clipboard-history) откроется внутри SmartBar.

## Добавить контекст

SmartBar может подхватить выделенный текст, выбор Finder и текущую страницу браузера при открытии. Для каждого выберите **Attach**, **Suggest** или **Выкл.** в **Настройки → Контекстная осведомленность**. Чтобы добавить что-то ещё, наберите `#` и выберите источник.

**Layout** в **Настройки → SmartBar** задаёт, что вы видите при открытии SmartBar:

| Раскладка | Что открывается |
| --- | --- |
| **Input Only** | Только поле ввода |
| **Input and Toolbar** | Поле ввода плюс быстрые действия, выбор модели и голосовое управление |
| **Full Panel** | Всё это плюс список под полем ввода |

С **Full Panel** настройка **Initial State View** задаёт, что список показывает до набора: **Recommended Prompts** или **Command List**. В любой раскладке список и результаты всё равно появляются, как только вы набираете или запускаете команду.

## Настройки

Откройте **Настройки → SmartBar**.

| Настройка | Что меняет |
| --- | --- |
| **Сочетание клавиш** | Открывает и закрывает SmartBar из любого приложения. По умолчанию **⌥Space**. |
| **Агент по умолчанию** | Агент, который отвечает на набранное. |
| **Auto Clear Conversation** | Начинает новую беседу, когда SmartBar открывается после того, как был закрыт столько времени, от **Never** до **Every time it opens**. |
| **Layout** | Что вы видите при открытии SmartBar (см. выше). |
| **Оформление** | Светлое или тёмное стекло для SmartBar и бокового меню приложения или **Как в приложении**. |
| **Auto-switch Input Source** | Переключается на этот источник ввода, пока вы печатаете в SmartBar, и обратно при закрытии. |
| **Navigation Bindings** | Сочетания Control для перемещения по спискам и тексту: **macOS** (⌃N ⌃P ⌃F ⌃B) или **Vim** (⌃J ⌃K ⌃L ⌃H). |
| **Поиск** | Символы-триггеры для команд, контекста, навыков и недавних задач. |
| **Calculator** | Считает математику, единицы, валюты, даты и часовые пояса по мере набора. По умолчанию вкл. |
| **Weather and Flights** | Также ищет погоду, рейсы и время в любом месте. По умолчанию выкл. |

Смена значения по умолчанию не меняет каждый существующий чат. [Выбор модели](/ru/ai/model-selection-guide) объясняет, как каждый чат держит свою модель и глубину рассуждений.

## Голос и вычисления

Нажмите микрофон, чтобы произнести вопрос через [диктовку](/ru/features/dictation). Для устного обмена начните [Live Talk](/ru/features/live-voice); звонок, начатый из SmartBar, переходит в Dynamic Island.

Наберите арифметическое выражение, например `2+3*4`, и SmartBar покажет результат. Калькулятор также переводит единицы и валюты, работает с датами и часовыми поясами и делит сумму, как в `25% off $60 split by 3`. Проверьте результат и предлагаемое действие, прежде чем копировать.

Чтобы искать погоду, рейс или время в месте, включите **Weather and Flights** в **Настройки → SmartBar**. Затем наберите `weather in London`, `Tokyo feels like`, номер рейса вроде `BA008` или `time in Chernivtsi`. Отправляется только название места или номер рейса, в Open-Meteo, adsbdb и adsb.lol. **Weather and Flights** общий с калькулятором [Dynamic Island](/ru/features/dynamic-island).

## Устранение неполадок

| Проблема | Что сделать |
| --- | --- |
| SmartBar не открывается | Проверьте **Сочетание клавиш** в **Настройки → SmartBar** и нет ли другого приложения с тем же сочетанием. Если вы задавали свою клавишу раньше, она остаётся вашей. |
| Return запускает команду вместо вопроса агенту | Нажмите **⌘Return** или **Send to AI**. |
| Сумма или погода ничего не показывают | Проверьте **Calculator** и **Weather and Flights** в **Настройки → SmartBar**. |
| Приложения или выделенного текста нет в контексте | Проверьте [Разрешения](/ru/configuration/permissions) и **Настройки → Контекстная осведомленность**. |
| Запрос не удаётся | Проверьте выбранного провайдера и прочитайте ошибку, которую он сообщает. |
| Элемента на этой странице нет | Ваша сборка может быть старше этого руководства. См. [Обновления](/ru/configuration/updates). |

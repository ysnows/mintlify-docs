Инструменты для письма — это набор команд в один клик для текста, который вы выделяете в любом приложении. Исправляйте ошибки, меняйте тон, делайте текст короче или длиннее, объясняйте или резюмируйте его, превращайте в список или таблицу, не выходя из приложения, в котором вы пишете.

## Редактирование выделенного текста

1. Выделите текст в приложении, где вы пишете.
2. Нажмите команду в [PopBar](/ru/features/popbar) или откройте [SmartBar](/ru/features/smartbar) и найдите команду.
3. Прочитайте результат. Когда включено **Выделять правки**, в результате отмечено, что команда добавила и удалила.
4. Нажмите **Вставить**, чтобы заменить выделенное, или скопируйте результат.

Каждая команда сохраняет язык вашего текста и отвечает одним лишь результатом. **Объяснить** тоже отвечает на языке выделенного текста и воспринимает каждый запуск отдельно, а не как продолжение предыдущего. Если выделенный текст содержит вопрос или инструкцию, команда редактирует эти слова, а не отвечает на них.

<Tip>
Включите **Встроенный режим** для команды, которой вы доверяете, и она будет запускаться без окна и вставлять результат прямо поверх выделенного. См. [Изменение команды](#изменение-команды).
</Tip>

## Выберите команду

| Цель | Команды |
| --- | --- |
| Исправить ошибки | Исправить орфографию и грамматику, Вычитать |
| Улучшить формулировки | Улучшить текст, Улучшить стиль, Переписать, Как у носителя, AI Edit |
| Изменить длину | Сделать длиннее, Сделать короче, Сделать лаконичнее |
| Изменить тон | Изменить тон: дружелюбный, уверенный, непринуждённый или профессиональный |
| Понять содержание | Объяснить, Создать краткое содержание, Выделить главное |
| Переформатировать | Преобразовать в список, Преобразовать в таблицу |
| Электронная почта | Улучшить письмо, Написать ответ |
| Посты в X | Улучшить для X, Уместить в 280 символов, Превратить в тред, Предложить ответ в X, Предложить цитату с комментарием в X |
| Перевести | Переводчик, Перевод скриншота (см. [Перевод](/ru/ai/translate)) |
| Что-то на экране | Объяснение скриншота |
| Диктовка | Улучшение диктовки, Перевод диктовки, Правка диктовки, Обработка на устройстве (см. [Диктовка](/ru/features/dictation)) |
| Короткое выражение | Emoji |

**Как у носителя** переписывает ваш текст так, как написал бы носитель языка, на том же языке. **Улучшить письмо** сохраняет ваше приветствие, завершение и имя и не добавляет подпись. **Написать ответ** пишет ответ на выделенное письмо на его языке и в его тоне и оставляет в квадратных скобках короткую заготовку для имени, даты или решения, которых он знать не может.

## Изменение команды

Откройте **Настройки → AI Commands** и выберите команду в разделе **Встроенные**. На её странице описано, что она делает, а кнопка **Попробовать** позволяет сначала запустить её на каком-нибудь тексте.

| Настройка | Что она меняет |
| --- | --- |
| **PopBar** | Добавляет команду в PopBar или убирает её оттуда |
| **Выделять правки** | Отмечает в результате, что команда добавила и удалила |
| **Сочетание клавиш** | Запускает команду для текста, выделенного в любом приложении |
| **Встроенный режим** | Запускается без окна и вставляет результат поверх выделенного |
| **Последующее действие** | Что команда делает с ответом, когда закончит |
| **AI-модель** | Модель, которую использует эта команда. По умолчанию она следует модели для всех AI Commands |

Инструкции встроенной команды доступны только для чтения. Нажмите **Настроить**, чтобы сделать собственную копию, которую можно свободно изменять.

Инструменты для письма работают на модели, заданной в **Настройки → AI Commands → Все команды**, если команда не выбирает свою. Те же команды перечислены и в **Настройки → Плагины → Инструменты для письма**, а кнопка **Настройки** в окне результата открывает команду, которая его создала.

## Получайте надёжные результаты

Когда переписать текст можно по-разному, укажите, для кого он и что должен делать. Назовите то, что должно остаться неизменным: имена, даты, цифры и цитируемые формулировки.

Всегда сравнивайте результат с оригиналом, прежде чем отправлять его. Гладкий текст всё равно может изменить смысл.

Для инструкции, которую вы повторяете, создайте собственную [AI Command](/ru/features/ai-commands).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Команды нет в PopBar | Нажмите **⌄** в конце PopBar, куда попадают не поместившиеся кнопки, или включите **PopBar** на странице команды в **Настройки → AI Commands** |
| PopBar не появляется | См. [устранение неполадок PopBar](/ru/features/popbar) |
| Результат на неожиданном языке | «Объяснить» отвечает на языке выделенного текста. «Создать краткое содержание» сохраняет язык текста, если вы не задали его **Язык ответа**. Остальные команды сохраняют язык текста |
| Результат изменил смысл | Отредактируйте его перед вставкой или запустите команду снова с исходным текстом |

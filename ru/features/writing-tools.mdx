Набор инструментов для письма — это команды в одно нажатие для текста, который вы выделяете в любом приложении. Исправляйте ошибки, меняйте тон, делайте короче или длиннее, объясняйте или резюмируйте или превращайте в список или таблицу, не покидая приложение, в котором пишете.

## Править выделенный текст

1. Выделите текст в приложении, где пишете.
2. Нажмите команду в [PopBar](/ru/features/popbar) или откройте [SmartBar](/ru/features/smartbar) и найдите команду.
3. Прочитайте результат. Когда **Подсвечивать правки** включено, результат отмечает, что команда добавила и убрала.
4. Нажмите **Вставить**, чтобы заменить выделение, или скопируйте результат.

Каждая команда сохраняет язык вашего текста и отвечает только результатом. **Explain** также отвечает на языке выделенного текста и считает каждый запуск отдельным, а не частью предыдущего. Когда выделенный текст задает вопрос или дает инструкцию, команда правит эти слова; она на них не отвечает.

<Tip>
Включите **Встроенный режим** для команды, которой доверяете, и она работает без окна и вставляет результат прямо поверх выделения. См. [Изменить команду](/ru/features/writing-tools).
</Tip>

## Выбрать команду

| Цель | Команды |
| --- | --- |
| Исправить ошибки | Fix Spelling & Grammar, Proofread |
| Улучшить формулировку | Improve Writing, Polish, Rewrite, Sound Native, AI Edit |
| Изменить длину | Make Longer, Make Shorter, Make Concise |
| Изменить тон | Change Tone Friendly, Confident, Casual или Professional |
| Понять содержимое | Explain, Summarize, Extract Key Points |
| Переформатировать | Convert to List, Convert to Table |
| Эл. почта | Polish Email, Draft a Reply |
| Посты в X | Polish for X, Fit in 280 Characters, Turn into a Thread, Suggest a Reply on X, Suggest a Quote Comment on X |
| Перевести | Translator, Screenshot Translate (см. [Перевод](/ru/ai/translate)) |
| Что-то на экране | Screenshot Explain |
| Диктовка | Dictation Polish, Dictation Translate, Dictation Edit, On-Device Cleanup (см. [Диктовка](/ru/features/dictation)) |
| Короткое выражение | Emoji |

**Sound Native** переписывает текст так, как написал бы носитель языка, на том же языке. **Отполировать письмо** сохраняет ваше приветствие, подпись и имя и не добавляет подпись. **Draft a Reply** пишет ответ на выделенное письмо на его языке и в его тоне и оставляет короткий заполнитель в квадратных скобках для имени, даты или решения, которых не может знать.

## Изменить команду

Откройте **Настройки → AI Commands** и выберите команду в **Встроенные**. Ее страница показывает, что делает команда, с **Попробовать**, чтобы сначала запустить на каком-то тексте.

| Настройка | Что меняет |
| --- | --- |
| **PopBar** | Добавляет команду в PopBar или убирает ее |
| **Подсвечивать правки** | Отмечает, что команда добавила и убрала в результате |
| **Сочетание клавиш** | Запускает команду на тексте, который вы выделяете в любом приложении |
| **Встроенный режим** | Работает без окна и вставляет результат поверх выделения |
| **Действие после** | Что команда делает с ответом, когда закончила |
| **AI-модель** | Модель, которую использует эта команда. По умолчанию она следует модели для всех AI Commands |

Инструкции встроенной команды только для чтения. Нажмите **Настроить**, чтобы сделать свою копию, которую можно свободно менять.

Инструменты письма работают на модели, заданной в **Настройки → AI Commands → Все команды**, если команда не выбирает свою. Те же команды также перечислены в **Настройки → Плагины → Writing Toolkit**, а кнопка **Настройки** в окне результата открывает команду, которая его сделала.

## Получать надежные результаты

Когда переписывание может пойти несколькими путями, скажите, для кого текст и что он должен делать. Назовите, что должно остаться тем же: имена, даты, цифры и цитаты.

Всегда сравнивайте результат с оригиналом, прежде чем отправлять. Беглый вывод все еще может изменить смысл.

Для инструкции, которую повторяете, сделайте свою [AI Command](/ru/features/ai-commands).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Команды нет на PopBar | Нажмите **⌄** в конце PopBar, куда уходят кнопки, которые не помещаются, или включите **PopBar** на странице команды в **Настройки → AI Commands** |
| PopBar не появляется | См. [устранение неполадок PopBar](/ru/features/popbar) |
| Результат на неожиданном языке | Explain отвечает на языке выделенного текста. Summarize сохраняет язык текста, если вы не задали его **Язык ответа**. Остальные команды сохраняют язык текста |
| Результат изменил смысл | Поправьте его, прежде чем вставлять, или запустите команду снова с оригинальным текстом |

Медиа-утилиты — это локальные команды для повседневных задач с медиа: уменьшить размер изображений, видео- или аудиофайлов, сохранить звуковую дорожку видео или скачать видео с веб-страницы. Найдите их в SmartBar или в **Настройки → Плагины**.

| Команда | Что она делает | Куда сохраняет |
| --- | --- | --- |
| **Image Compress** | Сжимает одно или несколько изображений либо все изображения в папке и её подпапках с настраиваемым качеством | Заменяет исходные изображения |
| **Video Compress** | Уменьшает размер видеофайла | `~/Downloads` |
| **Audio Compress** | Уменьшает размер аудиофайла до выбранного вами качества и сохраняет обложку (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Сохраняет звуковую дорожку видео или каждого видео в папке в формате M4A (MP3, если дорожку нельзя скопировать) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Скачивает видео или аудио по ссылке, например с YouTube, TikTok, Instagram, Reddit, X или Vimeo | `~/Downloads` |

<Warning>
**Image Compress** по умолчанию заменяет ваши исходные изображения. Чтобы их сохранить, сначала выключите **Overwrite Original Image File** в его настройках; тогда сжатые копии попадут в папку `enconvo-compressed-images` рядом с изображениями.
</Warning>

## Сожмите файл или извлеките из него звук

1. Выберите файлы в Finder или прикрепите их. Для Image Compress можно также выбрать папку: сжимаются её изображения и изображения в её подпапках, а копии сохраняют ту же структуру папок.
2. Откройте SmartBar и запустите команду.
3. Откройте результат и проверьте его.

Пока вы пробуете настройки сжатия, сохраняйте оригинал. Настройки каждой команды находятся в **Настройки → Плагины**: **Image Utils** для Image Compress и **Media Utils** для остальных.

| Настройка | Что она меняет |
| --- | --- |
| **Качество** | От 0 до 100; чем выше, тем лучше качество и больше файл. По умолчанию 80 |
| **Путь к папке назначения** | Куда попадает сжатый файл: абсолютный путь или путь относительно файла |
| **Overwrite Original … File** | Заменяет исходный файл. По умолчанию включено для изображений, выключено для видео и аудио |

## Скачайте видео

1. Откройте страницу видео в браузере или скопируйте его ссылку.
2. Запустите **Online Video Downloader** из SmartBar. Он берёт ссылку из активной вкладки браузера или из введённой вами ссылки.
3. Следите за ходом в Dynamic Island, где можно отменить загрузку. Когда всё готово, нажмите **Показать в Finder**.

Загрузка сохраняется в историю вашего чата, а уже скачанный файл используется повторно, а не загружается снова. Работает ли сайт, зависит от самого сайта и от того, к чему он вам даёт доступ. Скачивайте только тот контент, который вам разрешено сохранять.

| Настройка | Что она меняет |
| --- | --- |
| **Output Directory** | Куда попадают загрузки. По умолчанию `~/Downloads` |
| **Audio Only** | Скачивает только звук |
| **Favorite Resolution** | Разрешение для загрузки, от **Best** (по умолчанию) до 144p |
| **Force Convert to Compatible MP4** | Преобразует видео в MP4, который воспроизводится везде. По умолчанию включено; требует дополнительного времени и ресурсов процессора |
| **Use Browser Cookies** | Входит в аккаунт с помощью cookie вашего браузера, для видео, которые видите только вы. Выберите браузер в **Браузер** |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| **No images to compress** | Выберите изображения в Finder или прикрепите их, затем запустите команду снова |
| Преобразование не удаётся | Проверьте формат файла, что папка вывода доступна для записи и что на диске есть свободное место |
| Закрытое видео не скачивается | Включите **Use Browser Cookies** и выберите браузер, в котором вы вошли в аккаунт |
| Загрузки с сайта перестают работать | Прочитайте ошибку и обновите плагин, прежде чем пробовать снова. Сайты меняют форматы и правила доступа |

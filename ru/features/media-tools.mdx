Медиаутилиты — локальные команды для обычных дел с медиа: уменьшить изображения, видео или аудио, сохранить звуковую дорожку видео или скачать видео с веб-страницы. Найдите их в SmartBar или в **Настройки → Плагины**.

| Команда | Что делает | Куда сохраняет |
| --- | --- | --- |
| **Image Compress** | Сжимает одно или несколько изображений или каждое изображение в папке и её подпапках, с настраиваемым качеством | Заменяет исходные изображения |
| **Video Compress** | Уменьшает видеофайл | `~/Downloads` |
| **Audio Compress** | Уменьшает аудиофайл по выбранному качеству и сохраняет обложку (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Сохраняет аудиодорожку видео или каждого видео в папке как M4A (MP3, если дорожку нельзя скопировать) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Скачивает видео или аудио по ссылке, например YouTube, TikTok, Instagram, Reddit, X или Vimeo | `~/Downloads` |

<Warning>
**Image Compress** по умолчанию заменяет исходные изображения. Чтобы сохранить их, сначала выключите **Overwrite Original Image File** в его настройках; сжатые копии тогда идут в папку `enconvo-compressed-images` рядом с изображениями.
</Warning>

## Сжать файл или извлечь аудио

1. Выберите файлы в Finder или прикрепите их. Для Image Compress можно также выбрать папку: сжимаются её изображения и изображения в подпапках, а копии сохраняют ту же структуру папок.
2. Откройте SmartBar и запустите команду.
3. Откройте результат и проверьте его.

Сохраните оригинал, пока пробуете настройки сжатия. Настройки каждой команды — в **Настройки → Плагины**: **Image Utils** для Image Compress и **Media Utils** для остальных.

| Настройка | Что меняет |
| --- | --- |
| **Качество** | От 0 до 100; выше сохраняет больше качества и делает файл больше. По умолчанию 80 |
| **Destination Folder Path** | Куда идёт сжатый файл: абсолютный путь или путь относительно файла |
| **Overwrite Original … File** | Заменяет исходный файл. По умолчанию включено для изображений, выключено для видео и аудио |

## Скачать видео

1. Откройте страницу видео в браузере или скопируйте ссылку.
2. Запустите **Online Video Downloader** из SmartBar. Он берёт ссылку из активной вкладки браузера или из ссылки, которую вы вводите.
3. Следите за ходом в Dynamic Island, где можно отменить. Когда готово, нажмите **Показать в Finder**.

Загрузка сохраняется в историю чата, а уже скачанный файл используется снова, а не скачивается заново. Работает ли сайт, зависит от сайта и от того, что он вам позволяет. Скачивайте только то, что вам разрешено сохранять.

| Настройка | Что меняет |
| --- | --- |
| **Output Directory** | Куда идут загрузки. По умолчанию `~/Downloads` |
| **Audio Only** | Скачивает только аудио |
| **Favorite Resolution** | Разрешение для загрузки, от **Best** (по умолчанию) до 144p |
| **Force Convert to Compatible MP4** | Преобразует видео в MP4, который играет везде. Включено по умолчанию; занимает дополнительное время и процессор |
| **Use Browser Cookies** | Входит с cookie вашего браузера, для видео, которые видите только вы. Выберите браузер в **Browser** |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| **No images to compress** | Выберите изображения в Finder или прикрепите их, затем запустите команду снова |
| Преобразование не удаётся | Проверьте формат файла, что папка вывода доступна для записи и что есть свободное место |
| Личное видео не скачивается | Включите **Use Browser Cookies** и выберите браузер, в котором вы вошли |
| Загрузки с сайта перестают работать | Прочитайте ошибку и обновите плагин, прежде чем пробовать снова. Сайты меняют форматы и правила доступа |

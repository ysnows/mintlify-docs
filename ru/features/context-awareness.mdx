title: "Контекстная осведомленность"
description: "Выберите, что SmartBar подхватывает из приложения, которым вы пользовались, и добавляйте больше контекста с помощью #."
---

Контекст — это то, что отправляется вместе с вашим вопросом: выделенный текст, файлы, выбранные в Finder, страница, открытая в браузере, или снимок экрана. SmartBar может подхватить часть этого при открытии, а остальное можно добавить, набрав `#`. После этого Агент отвечает о том, на что вы смотрите, и вам не нужно ничего объяснять.

## Что SmartBar подхватывает

1. Откройте **Настройки → Контекстная осведомленность**.
2. В разделе **При открытии Smart Bar** для каждого источника выберите **Прикрепить**, **Предложить** или **Выкл.**.
3. Переключитесь на другое приложение, выделите что-нибудь и откройте SmartBar, чтобы увидеть результат.

| Источник | Что добавляет | По умолчанию |
| --- | --- | --- |
| **Выделенный текст** | Текст, выделенный в приложении, которым вы пользовались | **Прикрепить** |
| **Выбор в Finder** | Файлы и папки, выбранные в Finder | **Предложить** |
| **Текущая страница браузера** | Страница, открытая в Safari, Chrome, Arc, Edge или другом браузере на Chromium | **Предложить** |

**Прикрепить** добавляет источник во ввод сразу при открытии SmartBar. **Предложить** показывает его над командами, так что добавить его можно одним щелчком. **Выкл.** не добавляет его.

Эти настройки использует только SmartBar. Команды, которые вы запускаете для выделенного фрагмента, всегда получают выделенный текст. При первом добавлении контекста из Finder или браузера macOS спрашивает, можно ли Enconvo управлять этим приложением.

## Добавление контекста с помощью #

1. В SmartBar введите `#`.
2. Введите слово, чтобы сузить список, например `#screen`, `#finder`, `#clipboard` или `#browser`.
3. Выберите источник. Он добавится в ваше сообщение.
4. Введите вопрос и отправьте его.

| Источник | Что добавляет |
| --- | --- |
| **Selected Text** | Текст, выделенный в текущем окне |
| **Clipboard Text** | Текст из буфера обмена |
| **Current Application Content** | Текст приложения на переднем плане |
| **Current Application Screenshot** | Снимок экрана приложения на переднем плане |
| **Current Screen Screenshot** | Снимок всего экрана |
| **Live Screen Screenshot** | Снимок экрана без окон Enconvo |
| **User Select Area Screenshot** | Снимок выбранной вами области |
| **Finder Selected Items** | Файлы и папки, выбранные в Finder |
| **Finder Current Directory URL** | Папка, открытая в Finder |
| **Browser Current Tab URL** | Адрес текущей вкладки браузера |

Список ваших открытых окон тоже есть, так что можно добавить окно другого приложения. Чтобы использовать вместо `#` другой символ, измените **Контекст** в разделе **Поиск** в **Настройки → SmartBar**.

## О чём спрашивать

Если прикреплена страница браузера, попросите Enconvo кратко изложить страницу, перевести её или выделить ключевую информацию. Если прикреплены файлы Finder, попросите описать файлы, предложить, как их организовать, помочь с пакетным переименованием или проанализировать их содержимое.

<Note>
Контекст, который вы прикрепляете, отправляется модели, которая отвечает, или провайдеру, который его обрабатывает. Прежде чем работать с конфиденциальным содержимым, проверьте, что прикреплено, и настройки вашего провайдера.
</Note>

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Выделенный текст не прикрепляется | Проверьте, что для **Выделенный текст** выбрано **Прикрепить**, и посмотрите [Разрешения](/ru/configuration/permissions). |
| Нет контекста из Finder или браузера | Разрешите Enconvo управлять этим приложением, когда macOS спросит. Если вы отказали, разрешите это в [Разрешения](/ru/configuration/permissions). |
| Ввод `#` не открывает список | Проверьте символ **Контекст** в **Настройки → SmartBar**. |

Переменные подставляют значения, которые каждый раз меняются: текст, который вы ввели в SmartBar, текст, выделенный в другом приложении, или сегодняшнюю дату. Используйте их в промптах и параметрах, которые поддерживают шаблоны, чтобы одна команда AI Commands, одна инструкция Агента или один рабочий процесс работали с тем, что у вас перед глазами. Откройте **Настройки → Переменные**, чтобы просмотреть доступные переменные.

## Доступные переменные

| Переменная | Подставляемое значение |
| --- | --- |
| Input Text | Текущий ввод в SmartBar |
| Selection Text | Текст, выделенный в текущем приложении |
| Latest Clipboard | Последнее содержимое буфера обмена |
| Active Application | Сведения о приложении на переднем плане |
| Active Application Screenshot | Изображение окна на переднем плане |
| Active Screen Screenshot | Изображение активного экрана |
| Focused Window Content | Содержимое, извлечённое из окна в фокусе |
| Browser Active Tab | URL активной вкладки и доступное содержимое страницы |
| Current Folder | Папка, открытая в Finder |
| Selected Files | Файлы, выбранные в Finder |
| History Messages | История текущего диалога |
| Now | Текущие дата и время |
| Your Language | Язык, на котором вы читаете: ваш **Язык ответа** или язык системы, если выбрано «Авто» |
| Opened Applications | Сведения о запущенных приложениях |
| Opened Application Names | Названия запущенных приложений |

## Использование переменной

1. Откройте поле команды AI Commands, инструкции Агента или рабочего процесса, которое хотите настроить.
2. Убедитесь, что поле поддерживает переменные; если у него есть средство выбора, используйте его.
3. Вставьте нужное значение и проверьте на безобидном примере содержимого.
4. Проверьте, меняют ли результат пустой ввод или отсутствие разрешения.

Текстовый промпт может использовать поддерживаемые имена шаблонов, например:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Какие переменные можно использовать, зависит от команды и контекста, и не каждое текстовое поле вычисляет шаблоны. Для снимков экрана и содержимого приложений могут понадобиться разрешения macOS и модель, которая принимает такой тип ввода.

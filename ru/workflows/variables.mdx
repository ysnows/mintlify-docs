Переменные подставляют значения, которые меняются каждый раз: текст, который вы ввели в SmartBar, текст, выделенный в другом приложении, или сегодняшнюю дату. Используйте их в промптах и настройках с шаблонами, чтобы одна AI Command, инструкция агента или рабочий процесс работали с тем, что сейчас перед вами. Откройте **Настройки → Переменные**, чтобы посмотреть доступные переменные.

## Доступные переменные

| Переменная | Какое значение подставляется |
| --- | --- |
| Input Text | Текущий ввод SmartBar |
| Selection Text | Текст, выделенный в текущем приложении |
| Latest Clipboard | Последнее содержимое буфера обмена |
| Active Application | Сведения о приложении на переднем плане |
| Active Application Screenshot | Изображение окна на переднем плане |
| Active Screen Screenshot | Изображение активного экрана |
| Focused Window Content | Содержимое, извлечённое из окна в фокусе |
| Browser Active Tab | URL активной вкладки и доступное содержимое страницы |
| Current Folder | Папка, открытая в Finder |
| Selected Files | Файлы, выбранные в Finder |
| History Messages | История текущего разговора |
| Now | Текущие дата и время |
| Your Language | Язык, на котором вы читаете: ваш **Язык ответа** или язык системы, когда выбран Auto |
| Opened Applications | Сведения о запущенных приложениях |
| Opened Application Names | Имена запущенных приложений |

## Как использовать переменную

1. Откройте AI Command, инструкцию агента или поле рабочего процесса, которое хотите настроить.
2. Проверьте, что поле поддерживает переменные; если есть выбор, пользуйтесь им.
3. Вставьте нужное значение и проверьте на безобидном примере.
4. Проверьте, меняет ли результат пустой ввод или отсутствующее разрешение.

В текстовом промпте можно использовать поддерживаемые имена шаблонов, например:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Какие переменные доступны, зависит от команды и контекста, и не каждое текстовое поле разбирает шаблоны. Снимки экрана и содержимое приложений могут требовать разрешений macOS и модели, которая принимает такой ввод.

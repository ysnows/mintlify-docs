<Note>
Enconvo для Windows находится в бета-версии и выходит в канале обновлений **Бета**. Она рассчитана на повседневное использование, но между сборками что-то ещё может меняться. Если что-то сломалось, сообщите нам на [сайте обратной связи](https://feedback.enconvo.com).
</Note>

**Текущая бета-версия: 2.5.13 Beta 3** (`2.5.13-beta-3`). Чтобы узнать, какая версия у вас, откройте **Настройки → Основные → Обновления**.

## Требования

- **Windows 10 версии 2004 (сборка 19041) или новее либо Windows 11.**
- **64-разрядный Intel/AMD (x64).** Сборки для Windows на Arm пока нет.
- **Microsoft Edge WebView2 Runtime.** На нём работают окна Enconvo. В Windows 11 он встроен. Если в Windows 10 окна остаются пустыми, см. [Устранение неполадок](#устранение-неполадок).

## Загрузка бета-версии

Бета-версия поставляется в виде установщика `Enconvo-<version>-win32-x64-setup.exe`. В имени файла указан номер версии беты.

Для текущей беты, 2.5.13 Beta 3, скачайте [Enconvo-2.5.13-beta-3-win32-x64-setup.exe](https://file.enconvo.com/win32-x64/beta/Enconvo-2.5.13-beta-3-win32-x64-setup.exe).

Чтобы всегда получать самую новую бету, выполните это в PowerShell. Команда читает ленту бета-версий, скачивает установщик в папку «Загрузки» и проверяет, что файл получен целым.

```powershell
$feed = "https://file.enconvo.com/win32-x64/beta"
$latest = Invoke-RestMethod "$feed/latest.json"
$file = $latest.files.exe.url
$out = "$env:USERPROFILE\Downloads\$file"
$ProgressPreference = "SilentlyContinue"   # downloads much faster in Windows PowerShell
Invoke-WebRequest "$feed/$file" -OutFile $out
if ((Get-FileHash $out -Algorithm SHA256).Hash -eq $latest.files.exe.sha256) {
  "Downloaded Enconvo $($latest.version) to $out"
} else {
  "The download is damaged. Delete it and run this again."
}
```

## Установка

<Steps>
  <Step title="Запустите установщик">
    Откройте скачанный файл `.exe`. Если Windows покажет **Windows защитила ваш компьютер**, нажмите **Подробнее**, затем **Все равно запустить**. SmartScreen показывает это для приложений, которых он ещё не знает.
  </Step>
  <Step title="Выберите папку">
    Enconvo устанавливается только для вашей учётной записи и не требует прав администратора. Папка по умолчанию: `%LOCALAPPDATA%\Programs\Enconvo`. Если выберете другую, она должна быть пустой или уже содержать Enconvo.
  </Step>
  <Step title="Откройте Enconvo">
    Оставьте на последней странице отмеченным пункт **Открыть Enconvo** или позже откройте **Enconvo** из меню «Пуск». Его значок появится в области уведомлений на панели задач.
  </Step>
  <Step title="Войдите">
    Войдите в свой аккаунт Enconvo, затем переходите к [быстрому старту](/ru/quickstart).
  </Step>
</Steps>

Если во время установки Enconvo запущен, установщик предложит сначала закрыть его.

## Обновление

Бета-сборка остаётся в канале «Бета». Чтобы изменить это, откройте **Настройки → Основные** и выберите **Канал обновлений**. См. [Обновления](/ru/configuration/updates).

Enconvo сам проверяет наличие новой версии. Когда она готова, нажмите **Обновить** в окне чата. Проверить можно и прямо сейчас в разделе **Настройки → Основные → Обновления**.

Обновление устанавливается на месте: Enconvo закрывается, показывает ход работы установщика и снова открывается уже в новой версии.

## Устранение неполадок

| Что вы видите | Что делать |
| --- | --- |
| **Windows защитила ваш компьютер** при открытии установщика | Нажмите **Подробнее**, затем **Все равно запустить** |
| **Для Enconvo нужна 64-разрядная Windows** | Enconvo не работает в 32-разрядной Windows |
| Установщик не использует выбранную вами папку | Выберите пустую папку или папку, в которой уже находится Enconvo |
| Окна Enconvo остаются пустыми или не открываются | Установите [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), затем снова откройте Enconvo |
| Нажатие на уведомление Enconvo ничего не делает | Открывайте Enconvo обычным способом, а не через **Запуск от имени администратора** |

## Удаление Enconvo

Откройте **Параметры → Приложения → Установленные приложения** (в Windows 10: **Параметры → Приложения → Приложения и возможности**), найдите **Enconvo** и выберите **Удалить**.

Ваши настройки и чаты хранятся в папке `.config\enconvo` в вашей пользовательской папке (`%USERPROFILE%\.config\enconvo`). Удалите эту папку, чтобы стереть и их.

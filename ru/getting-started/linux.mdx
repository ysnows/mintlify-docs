<Note>
Enconvo для Linux находится в бета-версии и выходит в канале обновлений **Бета**. Она рассчитана на повседневное использование, но между сборками что-то ещё может меняться. Если что-то сломалось, сообщите нам на [сайте обратной связи](https://feedback.enconvo.com).
</Note>

**Текущая бета-версия: 2.5.13 Beta 3** (`2.5.13-beta-3`). Чтобы узнать, какая версия у вас, откройте **Настройки → Основные → Обновления**. На сервере её выводит команда `enconvo update --check`.

## Выберите, как вы будете его запускать

| У вас есть | Что вы получите | Начните здесь |
| --- | --- | --- |
| Настольный компьютер с Linux (GNOME, KDE и другие) | Приложение Enconvo с окнами чата и настроек | [Установка на настольный компьютер](#установка-на-настольный-компьютер) |
| Сервер или облачный компьютер без рабочего стола | Enconvo работает в фоновом режиме, а пользоваться им можно из браузера на вашем компьютере | [Установка на сервер](#установка-на-сервере) |

## Требования

- **64-разрядный Intel/AMD (x86-64).** Сборки для ARM пока нет.
- **Ubuntu 22.04, Debian 12, RHEL 9, Amazon Linux 2023 или новее.** Rocky Linux и AlmaLinux 9 считаются RHEL 9. На более старых системах Enconvo не запустится: в них слишком старая библиотека C.
- **Память:** рекомендуем не менее 2 ГБ свободной памяти, а если агент будет использовать браузер, то 4 ГБ.
- **Обычная учётная запись пользователя.** Запускайте Enconvo от своего имени, а не от root, потому что его агент выполняет команды с правами этого пользователя. На сервере создайте пользователя специально для Enconvo.

## Загрузка бета-версии

Бета-версия поставляется в трёх видах: `.deb` для Debian и Ubuntu, `.rpm` для Fedora, RHEL, Rocky, AlmaLinux и openSUSE и переносимый архив `.tar.gz` для всего остального. В имени каждого файла указан номер версии беты. Для 2.5.13 Beta 3 это:

- `enconvo_2.5.13~beta~3_amd64.deb`
- `enconvo-2.5.13~beta~3-1.x86_64.rpm`
- `Enconvo-2.5.13-beta-3-linux-x64.tar.gz`

Эти команды находят самую новую бету и скачивают её.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo_[^"]*\.deb')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Fedora, RHEL, Rocky, AlmaLinux, openSUSE">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'enconvo-[^"]*\.rpm')
    curl -fLO "$FEED/$FILE"
    ```
  </Tab>
  <Tab title="Переносимый .tar.gz">
    ```bash
    FEED=https://file.enconvo.com/linux-x64/beta
    FILE=$(curl -fsSL $FEED/latest.json | grep -o 'Enconvo-[^"]*\.tar\.gz')
    curl -fLO "$FEED/$FILE"
    tar xzf "$FILE"
    ```

    Будет распакована папка `Enconvo`. Запускайте Enconvo оттуда и используйте `./Enconvo/enconvo` везде, где на этой странице написано `enconvo`.
  </Tab>
</Tabs>

## Установка на настольный компьютер

Менеджер пакетов также устанавливает всё, что нужно окнам приложения: GTK и WebKitGTK.

<Tabs>
  <Tab title="Debian, Ubuntu">
    ```bash
    sudo apt install ./enconvo_*.deb
    ```
  </Tab>
  <Tab title="Fedora, openSUSE">
    ```bash
    sudo dnf install ./enconvo-*.rpm      # Fedora
    sudo zypper install ./enconvo-*.rpm   # openSUSE
    ```
  </Tab>
  <Tab title="Переносимый .tar.gz">
    Установите GTK 3 и WebKitGTK 4.1 из репозиториев вашего дистрибутива, затем запустите Enconvo из его папки:

    ```bash
    ./Enconvo/enconvo
    ```
  </Tab>
</Tabs>

В RHEL 9, Rocky Linux 9 и AlmaLinux 9 нет WebKitGTK 4.1, который нужен окнам приложения, поэтому в этих системах [запускайте Enconvo как на сервере](#установка-на-сервере).

Откройте **Enconvo** из меню приложений, войдите в аккаунт и переходите к [быстрому старту](/ru/quickstart). Значок Enconvo появляется в системном трее там, где рабочий стол его показывает.

## Установка на сервере

Серверу не нужны библиотеки рабочего стола, поэтому не устанавливайте их.

<Steps>
  <Step title="Установите пакет">
    <Tabs>
      <Tab title="Debian, Ubuntu">
        ```bash
        sudo apt install --no-install-recommends ./enconvo_*.deb
        ```
      </Tab>
      <Tab title="Fedora, RHEL, Rocky, AlmaLinux">
        ```bash
        sudo dnf install --setopt=install_weak_deps=False ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="openSUSE">
        ```bash
        sudo zypper install --no-recommends ./enconvo-*.rpm
        ```
      </Tab>
      <Tab title="Переносимый .tar.gz">
        Устанавливать ничего не нужно: используйте распакованную папку `Enconvo`.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Запустите Enconvo как службу">
    ```bash
    enconvo service install --web
    ```

    Теперь Enconvo работает в фоновом режиме и отдаёт окна чата и настроек как веб-сайт только на этом компьютере, по адресу `127.0.0.1:54580`. Он снова запускается при загрузке сервера. Если команда сообщает, что служба работает, только пока вы вошли в систему, выполните команду `sudo loginctl enable-linger`, которую она выводит.
  </Step>
  <Step title="Войдите">
    ```bash
    enconvo login
    ```

    Enconvo выведет короткий код. Откройте `enconvo.com/device` на телефоне или компьютере, убедитесь, что на странице указан ваш аккаунт, и подтвердите код в течение 10 минут.
  </Step>
  <Step title="Откройте Enconvo со своего компьютера">
    Выполните это на своём компьютере и оставьте команду работать:

    ```bash
    ssh -N -L 54580:127.0.0.1:54580 you@your-server
    ```

    Откройте [http://localhost:54580](http://localhost:54580) в браузере. Вы получите те же окно чата и настройки, что и в приложении для компьютера.
  </Step>
</Steps>

Чтобы использовать этот сервер из приложения Enconvo на телефоне, выполните `enconvo companion pair --phone` и отсканируйте выведенный код. См. [Связывание с телефоном](/ru/integrations/pair-your-phone).

### Доступ без SSH-туннеля

Туннель — самый безопасный способ подключения, потому что на сервере ничто не открыто для сети. У сайта те же полные права, что и у вашего аккаунта, и он может добраться до файлов сервера, поэтому любой, кто может его открыть, получает и то и другое.

Чтобы открывать его напрямую с других компьютеров, например в частной сети или через VPN:

```bash
enconvo service install --web 0.0.0.0:54580
enconvo service url
```

`enconvo service url` выводит адрес вместе с токеном подключения. Храните этот адрес в тайне и не открывайте этот порт в интернет.

Для публичного адреса поставьте перед Enconvo обратный прокси с HTTPS и сообщите Enconvo адрес, по которому он доступен:

```bash
enconvo service install --web --web-url https://enconvo.example.com
```

С HTTPS сайт можно также установить как приложение на телефон или компьютер.

## Использование Browser Use на сервере

Агент может работать в браузере на сервере без экрана: при первой необходимости Enconvo запускает собственный браузер без графического интерфейса, который называется Enconvo Browser. Сначала установите Chromium.

<Tabs>
  <Tab title="Debian">
    ```bash
    sudo apt install chromium
    ```
  </Tab>
  <Tab title="Ubuntu">
    ```bash
    sudo snap install chromium
    ```
  </Tab>
  <Tab title="Fedora">
    ```bash
    sudo dnf install chromium
    ```
  </Tab>
  <Tab title="RHEL, Rocky, AlmaLinux">
    Chromium берётся из [EPEL](https://docs.fedoraproject.org/en-US/epel/):

    ```bash
    sudo dnf install epel-release
    sudo dnf install chromium
    ```
  </Tab>
</Tabs>

Затем попросите агента, например: «Открой news.ycombinator.com и скажи, какая там главная новость».

Enconvo Browser хранит собственные данные входа. Когда сайту нужны вы, для входа или проверки, агент показывает вам живой вид страницы в вашем браузере, где вы можете сами нажимать и вводить текст. Он закрывается после 30 минут бездействия и при следующем запуске возвращает свои вкладки.

Страница, доступная только с сервера, например сервер разработки, который агент запустил на `localhost`, тоже открывается рядом с чатом как живой вид, так что это работает через SSH-туннель.

## Что где работает

| Функция | Настольный Linux | Сервер |
| --- | --- | --- |
| Окно чата, Настройки | Да | Да, в браузере |
| Агенты, инструменты, файлы, документы, артефакты | Да | Да |
| Browser Use | Да | Да, с Chromium |
| База знаний, Память, Автоматизации, Рабочие процессы | Да | Да |
| Модели Enconvo Cloud, веб-поиск, OCR, создание изображений, речь | Да | Да |
| Управление компьютером | Да | Нет: нет экрана, которым можно управлять |
| Глобальные сочетания клавиш, Диктовка, Голосовая заметка, Записи, Рисование на экране, Appshots, уведомления | Да | Нет: для них нужен рабочий стол |

В Wayland для глобальных сочетаний клавиш нужен рабочий стол, который предоставляет их приложениям.

В Linux этих функций нет: SmartBar, PopBar, Dynamic Island, Голосовая команда, Аватар, Питомец на рабочем столе, Боковое меню приложения, Live Talk и Субтитры. SmartBar, PopBar, Dynamic Island, Голосовая команда, Аватар и Питомец на рабочем столе есть в [бета-версии для Windows](/ru/getting-started/windows).

Локальные модели чата запускаются из файлов GGUF в системах с glibc 2.38 или новее. Модели MLX требуют Mac.

## Ваш аккаунт в Linux

Если ваш аккаунт используется и в [приложении для iPhone](/ru/integrations/iphone-app), выбранные вами модели чата, речи и изображений по умолчанию переходят вместе с аккаунтом на этот компьютер. Провайдер, работающий на вашем собственном ключе API, не переходит, потому что ключи не копируются. Если хотите того же провайдера и здесь, добавьте ключ в **Настройках** на этом компьютере.

Если часовой пояс сервера отличается от часового пояса вашего браузера, Enconvo предложит использовать ваш для времени и [Автоматизаций](/ru/workflows/scheduled-jobs).

## Обновление

Бета-сборка остаётся в канале «Бета». Чтобы изменить это, откройте **Настройки → Основные** и выберите **Канал обновлений**. См. [Обновления](/ru/configuration/updates).

На настольном компьютере нажмите **Обновить** в окне чата, когда эта кнопка появится. Переносимая сборка обновляет себя сама. Для `.deb` или `.rpm` Enconvo загружает новый пакет в папку «Загрузки», а вы устанавливаете его, как описано в разделе [Установка на настольный компьютер](#установка-на-настольный-компьютер).

На сервере:

```bash
enconvo update --check   # is there a newer version?
enconvo update           # download and check it
```

Если вы установили `.deb` или `.rpm`, `enconvo update` загружает новый пакет и выводит команду для его установки от имени root. Выполните эту команду, затем перезапустите службу:

```bash
systemctl --user restart enconvo
```

Если вы используете переносимый `.tar.gz`, `enconvo update` сам заменяет папку и перезапускает её службу. Если новая версия не запускается, он возвращает старую.

## Устранение неполадок

| Что вы видите | Что делать |
| --- | --- |
| `enconvo` сообщает, что приложению для компьютера нужны GTK 3 и WebKitGTK 4.1 | На настольном компьютере установите названные пакеты. На сервере или в RHEL 9 используйте `enconvo service install --web` |
| `GLIBC_2.34 not found` или сообщение со списком поддерживаемых систем | Система слишком старая: используйте одну из перечисленных в разделе [Требования](#требования) |
| `dnf` сообщает `nothing provides libwebkit2gtk-4.1.so.0` | У вас старый пакет. Установите текущую бету [командой для сервера](#установка-на-сервере) |
| Enconvo останавливается, когда вы выходите из системы на сервере, или не запускается после перезагрузки | Выполните `sudo loginctl enable-linger "$USER"` |
| `localhost:54580` не открывается | Проверьте, что команда `ssh -L` всё ещё работает и что `systemctl --user status enconvo` показывает active |
| Сайт запрашивает токен | Выполните `enconvo service url` на сервере и откройте выведенный адрес |
| Агент сообщает, что не может запустить Enconvo Browser | [Установите Chromium](#использование-browser-use-на-сервере). Google Chrome 137 и новее не могут загрузить расширение, которое нужно Enconvo Browser |
| Срок действия кода истёк | Снова выполните `enconvo login`, чтобы получить новый |

Чтобы прочитать журнал Enconvo на сервере:

```bash
journalctl --user -u enconvo -n 100
```

## Удаление Enconvo

```bash
enconvo service uninstall
sudo apt remove enconvo     # Debian, Ubuntu
sudo dnf remove enconvo     # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper remove enconvo  # openSUSE
```

Ваши настройки и чаты хранятся в `~/.config/enconvo`. Удалите эту папку, чтобы стереть и их.

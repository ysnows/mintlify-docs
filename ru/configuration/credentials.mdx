Каждому используемому провайдеру нужны учётные данные: ключ API или вход в тариф, за который вы уже платите. Вы добавляете их на странице настроек самого провайдера, а Enconvo хранит их в профиле провайдера, общем для всех функций, которые используют этого провайдера. **Настройки → Управление учётными данными** показывает все ваши учётные данные в одном месте.

Это видео заканчивается разделом «Управление учётными данными», после разделов «Аватар» и «Каналы мессенджеров».

## Добавление провайдера

<Steps>
  <Step title="Откройте категорию">
    Откройте страницу настроек для того, что хотите использовать, например **Настройки → AI-модель**, **Настройки → Генерация изображений** или **Настройки → Синтез речи**.
  </Step>
  <Step title="Выберите провайдера">
    Выберите провайдера. Чтобы настроить его вторую копию, для другого ключа или учётной записи, выберите **Добавить нового провайдера**.
  </Step>
  <Step title="Выберите способ входа">
    В разделе **Аутентификация** выберите **Ключ API** или **Подписка**, если провайдер позволяет использовать оплаченный вами тариф.
  </Step>
  <Step title="Добавьте учётные данные">
    Вставьте ключ API или завершите вход у провайдера.
  </Step>
  <Step title="Проверьте">
    Нажмите **Проверить**, если страница показывает эту кнопку, выберите модель и попробуйте короткий запрос.
  </Step>
</Steps>

Ключ API списывает средства с аккаунта API провайдера. Подписка использует включённый в ваш тариф объём и его лимиты. Текст в разделе **Аутентификация** подскажет, что использует страница.

## Общие профили

Профиль провайдера, например **OpenAI 2**, хранит ключ API провайдера и вход по подписке и появляется в каждой категории, которую провайдер поддерживает. Переименование или удаление профиля меняет его во всех этих категориях, а не только на текущей странице.

Каждая категория хранит собственные настройки модели, голоса и генерации. Но новый ключ API действует на все функции, использующие профиль, поэтому после смены ключа проверьте эти функции.

Что именно предлагает провайдер, зависит от категории. Вход, работающий для AI-чата, не означает, что в него включён API голоса в реальном времени. Если категория принимает только ключ API, об этом сказано на её странице, а также перечислены категории, где работает подписка.

## Проверка использования тарифа

Вход по подписке показывает вашу учётную запись и сколько осталось от тарифа. Значение вроде **% осталось** — это остаток доступного вам объёма. Откройте меню карточки учётной записи и выберите **Обновить сведения об использовании**, чтобы обновить его, или **Переподключить**, чтобы войти заново.

Если Claude или Codex предоставили вам бесплатные сбросы лимита, на карточке подписки Claude или ChatGPT отображается **Сброс бесплатного лимита**: сколько у вас сбросов и до какого срока. Нажмите **Использовать сброс** и подтвердите, чтобы восстановить лимиты. Если сбросов несколько, карточка перечисляет их, и вы используете выбранный.

Если данные об использовании не показаны, это не означает, что использование не ограничено.

## Управление учётными данными

Откройте **Настройки → Управление учётными данными**. Список группирует учётные данные по профилям провайдеров, а затем показывает **Неиспользуемые ключи**: ключи, которые не использует ни один провайдер.

- Введите текст в поле **Поиск провайдеров...**, чтобы найти нужного.
- Нажмите **Добавить новые учетные данные**, чтобы создать ещё одни учётные данные для выбранной службы.
- Чтобы удалить учётные данные, наведите на них указатель и нажмите значок корзины. Если этот ключ использует коннектор с ключом API, подтверждение назовёт его, а **Удалить и отключить** отключит его, пока вы не дадите ему другой ключ.
- Нажмите **Навести порядок** внизу списка, чтобы удалить сразу все неиспользуемые ключи. Кнопка показывает их количество, а подтверждение сначала перечисляет их. Enconvo никогда не удаляет неиспользуемые ключи сам.

Нажмите на учётные данные, чтобы добавить или изменить ключ. **Используется в** перечисляет функции, которые от них зависят, например **AI-модель** или **Синтез речи**; нажмите на одну из них, чтобы открыть соответствующую страницу настроек.

У собственных учётных данных профиля здесь нет кнопки удаления. Они удаляются вместе с провайдером.

Ещё две группы появляются, когда у вас есть соответствующие данные: **Другие службы** — для ключей к службам, для которых в Enconvo нет провайдера, и **Данные для входа** — для сохранённых входов на сайты и в приложения.

## Когда агенту нужен ключ

Когда для задачи нужен ключ API какой-то службы, агент показывает в чате карточку **Подключить**, а не просит вставить ключ. Ключ попадает в «Управление учётными данными», а не в разговор, и последующие чаты используют его без повторного запроса.

Для службы, для которой в Enconvo нет провайдера, карточка показывает хост, на который будет отправлен ключ. Ключ сохраняется в разделе **Другие службы**, и агент может использовать его только в запросах к этому хосту.

Сам ключ у агента никогда не хранится: он называет сохранённые учётные данные, а везде, где запрос или команда показали бы ключ, отображается `[redacted]`.

В чате Phone карточка **Подключить** показывается на вашем iPhone, а ключ сохраняется в «Управлении учётными данными» на вашем Mac. В чате мессенджера агент никогда не просит ключ; вместо этого он присылает ссылку, которая открывает чат в Enconvo.

Если вы всё же вставите ключ API в сообщение, Enconvo сохранит его в «Управлении учётными данными» и заменит в сохранённом чате на `[redacted]`, чтобы последующие запросы и другие ваши устройства его не содержали. Новый ключ, который вы вставляете для службы, у которой он уже есть, заменяет сохранённый.

## Входы на сайты и в приложения

Когда задача в браузере доходит до страницы входа, карточка один раз запрашивает имя пользователя и пароль. Enconvo подставляет их только на этом сайте, а агент пароль не видит. Сохранённые данные для входа отображаются в разделе **Данные для входа**. Снимите флажок **Запомнить эти данные для входа**, чтобы использовать их только для этого входа.

Когда для входа в приложение на Mac нужен пароль, карточка называет это приложение. Enconvo вводит имя пользователя и пароль только в это приложение, причём пароль — только в поле, скрывающее вводимые символы.

## Собственные конечные точки

У провайдеров **Совместимо с OpenAI** и **Совместимо с Anthropic** есть поле базового URL API для вашего собственного сервера. Некоторые встроенные провайдеры хранят настройку конечной точки в **Управлении учётными данными**. Про сервер моделей на другом компьютере читайте в разделе [Локальные модели](/ru/ai/local-llm).

Изменить адрес, на который отправляется сохранённый ключ, могут только собственные окна Enconvo: адрес провайдера или учётных данных либо использование сохранённого ключа сервером MCP. Другие программы, использующие Local API, телефон и агенты получают отказ.

## Как хранятся ключи

- Каждый сохранённый ключ и вход шифруется ключом, который хранится в связке ключей (Keychain) этого Mac, поэтому копию папки настроек Enconvo нельзя прочитать на другом компьютере. Если вы вернётесь к более старой версии Enconvo, ключи придётся ввести снова.
- Другая программа, запрашивающая у [Local API](/ru/advanced/cli-local-api) Enconvo настройки, получает `[hidden]` вместо каждого ключа. Плагин из магазина может использовать только собственные ключи и учётные данные, выбранные в его настройках.
- Открывать сохранённые ключи может только код, который установил Enconvo и который не был изменён. Настройки показывают и проверяют ключи, как и прежде.

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Проверка не проходит | Проверьте выбранный профиль, способ аутентификации, конечную точку и наличие доступа в аккаунте провайдера. |
| Одна функция работает, а другая нет | Проверьте, что учётная запись поддерживает эту функцию и модель. Если категория принимает только ключ API, об этом сказано на странице. |
| Что-то перестало работать после смены ключа | Профиль общий. Проверьте другие категории, которые его используют. |
| В области использования показано **Переподключить** | Срок действия входа истёк. Нажмите **Переподключить** и войдите заново. |

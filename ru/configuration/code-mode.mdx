---
title: "Code Mode"
description: "Пусть агент напишет короткий скрипт, который сделает много вызовов инструментов сразу и вернёт только результат."
---

Code Mode позволяет агенту сделать за один шаг то, на что иначе ушло бы много: он пишет короткий скрипт, который делает много вызовов инструментов, параллельно или по порядку, и читает только результат. Берите его, когда задача повторяет один и тот же вызов для многих элементов, например проверяет список страниц или собирает результаты из нескольких сервисов: так быстрее, и чат не заполняется каждым промежуточным результатом.

Code Mode вы сами не вызываете. Когда он включён, агент берёт его для подходящих задач, а в чате появляется карточка с вызовами, которые сделал скрипт.

## Настройте Code Mode

1. Откройте **Настройки → Code Mode**. Можно также открыть **Code Mode** на вкладке **Встроенные** страницы плагинов.
2. В **Доступ скриптов** включите, что скрипт может вызывать. Каждый вызов по-прежнему спрашивает вас так, как сказано в [режиме разрешений](/ru/ai/agents) чата.
3. Выберите, какие модели могут писать скрипты, что показывать в чате и что делать, если скрипт работает долго.

## Настройки

**Доступ скриптов** перечисляет, что скрипт может вызывать:

| Доступ | Что разрешает | По умолчанию |
| --- | --- | --- |
| **Плагины** | Поиск, база знаний, документы и другие маршруты плагинов | Вкл. |
| **Коннекторы и MCP** | Связанные учётные записи и инструменты MCP | Вкл. |
| **Файлы** | Чтение и запись файлов | Вкл. |
| **Команды оболочки** | Запуск команд в терминале | Вкл. |
| **Браузер** | [Browser Use](/ru/features/browser-control) в вашем браузере | Вкл. |
| **Приложения** | [Управление компьютером](/ru/features/computer-use) в пределах списка доступа к приложениям | Вкл. |
| **Другие агенты** | Запуск или сообщения субагентам | Выкл. |
| **Вызовы модели** | Небольшая модель, чтобы сводить или оценивать элементы | Вкл. |

Остальные параметры:

| Параметр | Варианты |
| --- | --- |
| **Использовать с** | **Модели, хорошо пишущие код** (остальные вызывают по одному) или **Все модели**. |
| **Показывать в чате** | **Вызовы** или **Вызовы и код**. |
| **Когда скрипт работает долго** | **Продолжать, до 2 часов** в фоне или **Остановить через 10 минут**. |

## Code Mode вне чата

Когда скрипт работает вне чата, например в автоматизации, он вызывает только инструменты, которые читают: встроенные поиски и чтения, публичные веб-страницы, обычные файлы и инструменты MCP, которые не сообщают, что что-то меняют. Enconvo проверяет каждый вызов ещё раз прямо перед запуском.

## Скрипт в навыке

Навык может хранить скрипт Code Mode в своей папке `scripts` и запускать его как один из шагов. См. [Навыки](/ru/configuration/skills).

## Устранение неполадок

| Проблема | Что сделать |
| --- | --- |
| Агент вызывает по одному | Проверьте **Использовать с**. С **Моделями, хорошо пишущими код**, остальные модели не используют Code Mode. |
| Скрипт не достаёт инструмент | Включите этот вид доступа в **Доступ скриптов**. Вне чата скрипты только читают. |
| Длинный скрипт остановился | С **Остановить через 10 минут** более длинные скрипты заканчиваются. Выберите **Продолжать, до 2 часов**. |

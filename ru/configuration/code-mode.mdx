title: "Code Mode"
description: "Позвольте агенту написать один короткий скрипт, который выполнит множество вызовов инструментов сразу и вернёт только результат."
---

Code Mode позволяет агенту сделать за один шаг то, на что иначе ушло бы много: он пишет короткий скрипт, который выполняет множество вызовов инструментов, параллельно или по порядку, и возвращает только результат. Обращайтесь к нему, когда задача повторяет один и тот же вызов для многих элементов, например проверку списка страниц или сбор результатов из нескольких сервисов: работа идёт быстрее, а чат не заполняется каждым промежуточным результатом.

Вы не вызываете Code Mode сами. Когда он включён, агент использует его, когда задача подходит, а в чате отображается карточка с вызовами, которые выполнил скрипт.

## Настройте Code Mode

1. Откройте **Настройки → Code Mode**. Также можно открыть **Code Mode** на вкладке **Встроенные** страницы «Плагины».
2. В разделе **Доступ скриптов** включите то, что скрипт может вызывать. Каждый вызов по-прежнему запрашивает у вас подтверждение согласно [режиму разрешений](/ru/ai/agents) чата.
3. Выберите, каким моделям разрешено писать скрипты, что показывает чат и что происходит, когда скрипт работает долго.

## Настройки

**Доступ скриптов** перечисляет то, что скрипт может вызывать:

| Доступ | Что разрешает | По умолчанию |
| --- | --- | --- |
| **Плагины** | Поиск, база знаний, документы и другие маршруты плагинов | Включено |
| **Connectors и MCP** | Ваши привязанные учётные записи и инструменты MCP | Включено |
| **Файлы** | Чтение и запись файлов | Включено |
| **Команды оболочки** | Выполнение команд в терминале | Включено |
| **Браузер** | [Browser Use](/ru/features/browser-control) в вашем собственном браузере | Включено |
| **Приложения** | [Управление компьютером](/ru/features/computer-use) в рамках его списка доступа к приложениям | Включено |
| **Другие агенты** | Запуск субагентов или отправка им сообщений | Отключено |
| **Вызовы моделей** | Небольшая модель, чтобы подвести итог или оценить элементы | Включено |

Остальные параметры:

| Параметр | Варианты |
| --- | --- |
| **Использовать с** | **Модели, хорошо пишущие код** (остальные выполняют вызовы по одному) или **Все модели**. |
| **Показывать в чате** | **Вызовы** или **Вызовы и код**. |
| **Когда скрипт работает долго** | **Продолжать, до 2 часов** в фоновом режиме или **Остановить через 10 минут**. |

## Code Mode вне чата

Когда скрипт выполняется вне чата, например в автоматизации, он вызывает только инструменты чтения: встроенные поиск и чтение, общедоступные веб-страницы, обычные файлы и инструменты MCP, которые не заявляют об изменениях. Enconvo проверяет каждый вызов ещё раз непосредственно перед его выполнением.

## Используйте скрипт в навыке

Навык может хранить скрипт Code Mode в собственной папке `scripts` и запускать его как один из своих шагов. См. [Навыки](/ru/configuration/skills).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Агент выполняет вызовы по одному | Проверьте **Использовать с**. При **Модели, хорошо пишущие код** другие модели не используют Code Mode. |
| Скрипт не может обратиться к инструменту | Включите этот вид доступа в **Доступ скриптов**. Вне чата скрипты только читают. |
| Долгий скрипт остановился | При **Остановить через 10 минут** более долгие скрипты завершаются. Выберите **Продолжать, до 2 часов**. |

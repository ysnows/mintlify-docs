title: "Разрешения macOS"
description: "Какие разрешения macOS использует Enconvo, как выдать нужные функции и что делать, если захват или ввод перестали работать."
---

Некоторым функциям Enconvo нужен доступ, который macOS просит одобрить: видеть экран или печатать в других приложениях. **Настройки → Разрешения** перечисляет каждое разрешение, что оно включает и выдано ли оно. Текстовому чату они не нужны, поэтому Enconvo не спрашивает при запуске: он спрашивает в первый раз, когда вы пользуетесь функцией, которой нужно разрешение, и говорит, какая функция спросила.

## Когда Enconvo спрашивает

Когда вы пользуетесь функцией, которой нужно ещё не выданное разрешение, Enconvo открывает окно разрешения, называет функцию и предлагает **Открыть «Системные настройки»**. Можно выбрать **Не сейчас**.

Чтобы функция больше не спрашивала, отметьте **Больше не спрашивать** для неё в окне. Тогда она не спросит, пока вы не измените это на странице разрешений. Для записи экрана, когда доступ ждёт только перезапуска, окно предлагает **Перезапустить**.

## Выдать разрешение

1. Откройте **Настройки → Разрешения**.
2. Найдите разрешение и нажмите **Предоставить**.
3. macOS показывает свой запрос или открывает нужную панель в **Системные настройки → Конфиденциальность и безопасность**. Для Универсального доступа и Мониторинга ввода включите переключатель Enconvo в этой панели сами.
4. Если macOS просит, завершите Enconvo и откройте снова.
5. Вернувшись в Enconvo, вы увидите в строке **Предоставлено**. Попробуйте функцию снова.

Страница сама проверяет снова, когда вы к ней возвращаетесь. Нажмите **Обновить**, чтобы проверить сразу.

## Какие функции используют разрешение

Под каждым разрешением **Используется в** перечисляет функции, которым оно нужно, и будет ли каждая спрашивать:

| Состояние | Значение |
| --- | --- |
| **Спрашивает при использовании** | Функция запросит разрешение в следующий раз, когда вы ей воспользуетесь. |
| **Отклонено · спрашивает по горячей клавише** | Вы отклонили; функция спросит снова только по своей горячей клавише. |
| **Не будет спрашивать** | Вы выбрали **Больше не спрашивать**. Нажмите, чтобы вернуть **Спрашивает при использовании**. |
| **Выкл.** или **Плагин выключен** | Функция или её плагин выключены. |

## Для чего каждое разрешение

| Разрешение | Для чего |
| --- | --- |
| Универсальный доступ | Чтение интерфейсов приложений, щелчки, ввод и управление окнами: Управление компьютером, PopBar, выделенный текст и вставка текста |
| Запись экрана | Снимки экрана, по которым агенты видят содержимое приложений: Управление компьютером, Appshots, контекст экрана и захваты OCR. macOS может называть это «Запись экрана и системного звука», и оно также покрывает захват системного звука. |
| Мониторинг ввода | Глобальный ввод с клавиатуры для PopBar, горячих клавиш и двойных модификаторов, пока на переднем плане другие приложения |
| Микрофон | Диктовка, Голосовая команда, Голосовая заметка, запись встречи, субтитры в реальном времени и Live Talk |
| Уведомления | Уведомление macOS, когда сессия агента закончилась или ждёт вашего внимания |
| Камера | Живые фото с камеры переключателем камеры SmartBar |
| Геопозиция | Местная погода в Dynamic Island и контекст места для агентов |
| Автоматизация | Управление другими приложениями через Apple Events: чтение вкладок браузера, выделения Finder, Mail, Сообщений и System Events |
| Локальная сеть | Подключение к серверам моделей на другом компьютере в вашей сети. На странице разрешений его нет; ищите в **Системные настройки → Конфиденциальность и безопасность → Локальная сеть**. |

Календарь, Напоминания, Заметки, Почта и другие приложения Apple подключаются на странице **Плагины**. См. [Приложения Apple](/ru/integrations/apple-ecosystem).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Разрешение включено, но захват всё равно не работает | Завершите Enconvo и откройте снова, затем попробуйте ещё раз. Убедитесь, что включили именно то приложение Enconvo, которое запущено, а не старую копию. |
| Функция никогда не просит нужное разрешение | Проверьте её строку в **Используется в**. Если там **Не будет спрашивать**, нажмите её или выдайте разрешение через **Предоставить**. |
| Запись экрана показана как выданная, но захват не работает | Нажмите **Перезапустить** в окне разрешения или завершите Enconvo и откройте снова. |
| Диктовка показывает текст, но не вставляет его | Проверьте Универсальный доступ и что целевое поле принимает ввод или вставку. |
| Горячая клавиша работает только внутри Enconvo | Проверьте Мониторинг ввода и Универсальный доступ. См. [Сочетания клавиш](/ru/configuration/keyboard-shortcuts) про клавиши, которые пересекаются с другими приложениями. |
| Сервер модели на другом компьютере не подключается | Проверьте Локальную сеть и что сервер слушает свой сетевой адрес. |
| Нет баннера, когда агент заканчивает | Проверьте Уведомления здесь, Фокус macOS и **Отправлять системное уведомление** в [Уведомлениях](/ru/configuration/notifications). |

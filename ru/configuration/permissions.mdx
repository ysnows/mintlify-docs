title: "Разрешения macOS"
description: "Узнайте, какие разрешения macOS использует Enconvo, предоставьте нужные для функции и исправьте захват или набор текста, которые перестали работать."
---

Некоторым функциям Enconvo нужен доступ, который macOS просит вас подтвердить, например видеть экран или набирать текст в других приложениях. **Настройки → Разрешения** перечисляет каждое разрешение, что оно обеспечивает и предоставлено ли оно. Текстовому чату они не нужны, поэтому Enconvo не спрашивает при запуске: он спрашивает при первом использовании функции, которой нужно разрешение, и сообщает, какая функция его запросила.

## Когда Enconvo спрашивает

Когда вы используете функцию, которой нужно не предоставленное вами разрешение, Enconvo открывает своё окно разрешений, называет функцию и предлагает **Открыть «Системные настройки»**. Можно также выбрать **Не сейчас**.

Чтобы функция больше не спрашивала, установите в окне флажок **Больше не спрашивать** для этой функции. Тогда она не будет спрашивать, пока вы не измените это на странице «Разрешения». Для записи экрана, когда доступ ждёт только перезапуска, в окне предлагается **Перезапустить**.

## Предоставление разрешения

1. Откройте **Настройки → Разрешения**.
2. Найдите разрешение и нажмите **Предоставить**.
3. macOS покажет свой запрос или откроет нужный раздел в **Системные настройки → Конфиденциальность и безопасность**. Для «Универсального доступа» и «Мониторинга ввода» включите переключатель Enconvo в этом разделе самостоятельно.
4. Если macOS попросит, завершите и снова откройте Enconvo.
5. В Enconvo в строке появится **Предоставлено**. Повторите попытку использовать функцию.

Страница сама проверяет состояние заново, когда вы к ней возвращаетесь. Нажмите **Обновить**, чтобы проверить сразу.

## Какие функции используют разрешение

Под каждым разрешением **Используется в** перечисляет функции, которым оно нужно, и показывает, будет ли каждая из них спрашивать:

| Состояние | Значение |
| --- | --- |
| **Спрашивает при использовании** | Функция запросит разрешение при следующем использовании. |
| **Отклонено · спрашивает по горячей клавише** | Вы отклонили; функция снова спросит только при нажатии её горячей клавиши. |
| **Не будет спрашивать** | Вы выбрали **Больше не спрашивать**. Нажмите на это состояние, чтобы вернуться к **Спрашивает при использовании**. |
| **Выкл.** или **Плагин выключен** | Функция или плагин, к которому она относится, выключены. |

## Для чего нужно каждое разрешение

| Разрешение | Для чего используется |
| --- | --- |
| Универсальный доступ (Accessibility) | Чтение интерфейсов приложений, нажатия, набор текста и управление окнами: «Управление компьютером», PopBar, выделенный текст и вставка текста |
| Запись экрана (Screen Recording) | Снимки экрана, позволяющие агентам видеть содержимое приложений: «Управление компьютером», Appshots, контекст экрана и захват для OCR. macOS может называть его «Запись экрана и системного звука»; оно также охватывает захват системного звука. |
| Мониторинг ввода (Input Monitoring) | Глобальный ввод с клавиатуры для PopBar, горячих клавиш и срабатываний по двойному нажатию модификатора, пока на переднем плане другие приложения |
| Микрофон | Диктовка, «Голосовая команда», голосовые заметки, запись встреч, живые субтитры и Live Talk |
| Уведомления | Уведомление macOS, когда сеанс агента завершён или требует вашего внимания |
| Камера | Живые фото с камеры по переключателю камеры в SmartBar |
| Геолокация | Местная погода в Dynamic Island и контекст местоположения для агентов |
| Автоматизация | Управление другими приложениями через Apple Events: чтение вкладок браузера, выбранных объектов Finder, «Почты», «Сообщений» и System Events |
| Локальная сеть | Подключение к серверам моделей на другом компьютере в вашей сети. Её нет на странице «Разрешения»; найдите её в **Системные настройки → Конфиденциальность и безопасность → Локальная сеть**. |

Календарь, «Напоминания», «Заметки», «Почта» и другие приложения Apple подключаются на странице **Плагины**. См. [Приложения Apple](/ru/integrations/apple-ecosystem).

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Разрешение включено, но захват по-прежнему не работает | Завершите и снова откройте Enconvo, затем повторите попытку. Убедитесь, что вы включили то приложение Enconvo, которое запущено, а не старую копию. |
| Функция никогда не запрашивает нужное ей разрешение | Проверьте её строку в разделе **Используется в**. Если там **Не будет спрашивать**, нажмите на это состояние или предоставьте разрешение кнопкой **Предоставить**. |
| Запись экрана показана как предоставленная, но захват не работает | Нажмите **Перезапустить** в окне разрешений или завершите и снова откройте Enconvo. |
| Диктовка показывает текст, но не вставляет его | Проверьте «Универсальный доступ» и то, что целевое поле принимает набор или вставку текста. |
| Горячая клавиша работает только внутри Enconvo | Проверьте «Мониторинг ввода» и «Универсальный доступ». О горячих клавишах, конфликтующих с другими приложениями, см. [Сочетания клавиш](/ru/configuration/keyboard-shortcuts). |
| Сервер моделей на другом компьютере не подключается | Проверьте «Локальную сеть» и то, что сервер слушает по своему сетевому адресу. |
| Нет баннера, когда агент завершает работу | Проверьте «Уведомления» здесь, «Фокусирование» macOS и **Отправить системное уведомление** в разделе [Уведомления](/ru/configuration/notifications). |

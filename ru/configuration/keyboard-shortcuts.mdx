Окна и голосовые функции Enconvo открываются горячими клавишами. **Настройки → Сочетание клавиш** перечисляет все горячие клавиши Enconvo и команды, которые они запускают, чтобы вы могли изменить любую из них или узнать, что делает то или иное сочетание. Горячие клавиши, сохранённые на вашем Mac, всегда важнее значений по умолчанию из этого руководства.

В этом видео рассказано о сочетаниях клавиш, а затем о других настройках, которые подгоняют Enconvo под ваш Mac: «Контекстная осведомленность», Appshots, «Локальные модели», «Разрешения» и «Не усыплять».

## Сочетания по умолчанию

| Действие | По умолчанию |
| --- | --- |
| Показать SmartBar | **⌥Space** |
| Показать окно чата | **⌃⌘X** |
| Показать боковое меню приложения | **⌃⌘E** |
| Открыть настройки, находясь в Enconvo | **⌘,** |
| Начать диктовку | **правая ⌘** |
| Начать голосовую команду | **правая ⌥** |
| Пауза/продолжение аудио | **⌥P** |

Эти значения действуют, только если вы никогда не задавали собственную клавишу; заданная вами клавиша остаётся без изменений. У «Быстрой записи» и Appshots нет горячей клавиши по умолчанию: задайте её на страницах их настроек, прежде чем использовать эти функции.

## Изменение горячей клавиши

1. Откройте **Настройки → Сочетание клавиш**. Вкладка **Основные** содержит главные функции, **Другие сочетания клавиш** — AI-команды, плагины, настройки и команды, которых нет на других страницах, а **Все** показывает обе.
2. Введите текст в поле **Фильтр по имени…**, чтобы найти команду. Чтобы найти команду по сочетанию клавиш, нажмите **Поиск по горячей клавише** и нажмите это сочетание.
3. Нажмите на поле горячей клавиши команды и нажмите новое сочетание.
4. Если эти клавиши уже запускают другую команду, поле сообщит об этом. Выберите **Использовать здесь**, чтобы перенести клавиши на эту команду, или выберите одну из предложенных свободных горячих клавиш.
5. Переключитесь в другое приложение и попробуйте горячую клавишу.

Чтобы освободить клавиши, удалите горячую клавишу у команды. Сообщение с кнопкой **Отменить** позволяет вернуть всё обратно.

Значок **Локально** помечает горячую клавишу, которая работает только внутри Enconvo, например «Закрепить SmartBar».

## Способ нажатия

Когда вы записываете одну клавишу-модификатор, например правую ⌘, поле спрашивает **Способ нажатия**:

| Вариант | Команда запускается, когда вы |
| --- | --- |
| **Удерживать или нажать** | Удерживаете клавишу или нажимаете её для переключения |
| **Касание** | Нажимаете клавишу, чтобы начать, и нажимаете ещё раз, чтобы остановить |
| **Удерживать** | Удерживаете клавишу; работает, пока вы её держите |
| **Двойное касание** | Быстро нажимаете клавишу дважды |

Две или более клавиш-модификаторов, нажатые одновременно, считаются одной горячей клавишей. Каждое поле показывает только те способы, которые поддерживает его команда, а описание рядом объясняет, как реагирует эта функция.

## Где находится горячая клавиша каждой функции

Помимо страницы «Сочетание клавиш», горячая клавиша каждой функции есть на её собственной странице настроек:

| Функция | Страница настроек |
| --- | --- |
| SmartBar | **Настройки → SmartBar** |
| Dynamic Island | **Настройки → Dynamic Island** |
| PopBar | **Настройки → PopBar** |
| Боковое меню приложения | **Настройки → Боковое меню приложения** |
| Диктовка | **Настройки → Диктовка** |
| Голосовая команда | **Настройки → Голосовая команда** |
| Appshots | **Настройки → Appshots** |
| Рисование на экране | **Настройки → Рисование на экране** |
| Голосовая заметка | **Настройки → Голосовая заметка** |
| Быстрая запись | **Настройки → Быстрая запись** |
| Отдельная команда | Настройки этой команды, если у неё есть поле **Сочетание клавиш** |

## Внутри SmartBar

Введите в SmartBar символ-триггер, чтобы искать элементы одного вида:

| Символ | Что открывает |
| --- | --- |
| **@** | Команды |
| **#** | Контекст, добавляемый к сообщению |
| **$** | Навыки |
| **>** | Недавние задачи |

Эти символы меняются в разделе **Поиск** в **Настройки → SmartBar**. Меню слэша содержит такие действия, как выбор модели и уровня рассуждений.

Чтобы перемещаться по спискам с клавиатуры, выберите **Сочетания клавиш для навигации** в **Настройки → SmartBar**: **macOS** использует **⌃N** **⌃P** **⌃F** **⌃B**, а **Vim** — **⌃J** **⌃K** **⌃L** **⌃H**.

## Настройка Enconvo под ваш Mac

В том же окне настроек есть другие параметры, о которых рассказано в видео:

| Страница настроек | Что делает |
| --- | --- |
| **Контекстная осведомленность** | Выбирает, что SmartBar берёт из приложения, в котором вы были: выделенный текст, выбранное в Finder или страницу в браузере. **Прикрепить** добавляет это сразу при открытии SmartBar, а **Предложить** предлагает это в один клик. См. [Контекстная осведомленность](/ru/features/context-awareness). |
| **Appshots** | Добавляет окно перед вами в разговор по горячей клавише. См. [Appshots](/ru/features/appshots). |
| **Локальные модели** | Показывает AI, работающий на этом Mac, используемые им память и диск и то, где запускается каждая функция. См. [Локальные модели](/ru/ai/local-llm). |
| **Разрешения** | Перечисляет, что macOS позволяет Enconvo и зачем; **Предоставить** исправляет недостающее. См. [Разрешения macOS](/ru/configuration/permissions). |
| **Не усыплять** | Не даёт этому Mac уснуть, пока вас нет, чтобы вы могли обратиться к нему с iPhone. |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Горячая клавиша работает только внутри Enconvo | Проверьте, есть ли у неё значок **Локально**. Если нет, проверьте «Мониторинг ввода» и «Универсальный доступ» в [Разрешениях macOS](/ru/configuration/permissions), а также не использует ли те же клавиши другое приложение. |
| Нажатие горячей клавиши делает что-то другое | Используйте **Поиск по горячей клавише**. Если ни одна команда Enconvo не использует эти клавиши, их использует другое приложение или macOS. |
| Горячая клавиша на основе клавиши-модификатора не срабатывает | Откройте горячую клавишу и проверьте **Способ нажатия**: удержание, касание, двойное касание или одновременное нажатие клавиш. |
| Сочетание из видео или с другого Mac не работает | Ваши горячие клавиши могут отличаться. Посмотрите актуальное в **Настройки → Сочетание клавиш**. |

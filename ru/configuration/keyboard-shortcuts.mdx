Окна и голосовые функции Enconvo открываются горячими клавишами. **Настройки → Сочетание клавиш** перечисляет все горячие клавиши Enconvo и команды, которые они запускают, чтобы можно было изменить одну или узнать, что делает сочетание. Клавиши, сохраненные на вашем Mac, всегда важнее значений по умолчанию в этом руководстве.

В этом видео сначала сочетания клавиш, затем остальные настройки, которыми Enconvo подстраивается под Mac: контекстная осведомленность, Appshots, локальные модели, разрешения и «Не усыплять».

## Сочетания по умолчанию

| Действие | По умолчанию |
| --- | --- |
| Показать SmartBar | **⌥Space** |
| Показать окно чата | **⌃⌘X** |
| Показать боковое меню приложения | **⌃⌘E** |
| Открыть настройки из Enconvo | **⌘,** |
| Начать диктовку | **Right ⌘** |
| Начать голосовую команду | **Right ⌥** |
| Пауза и продолжение звука | **⌥P** |

Эти значения действуют, только если вы сами не задали клавишу; заданная клавиша остается как есть. У быстрой записи и Appshots нет горячей клавиши по умолчанию: задайте ее на их страницах настроек, прежде чем пользоваться.

## Изменить горячую клавишу

1. Откройте **Настройки → Сочетание клавиш**. Вкладка **Основные** содержит главные функции, **Другие сочетания клавиш** — AI Commands, плагины, настройки и команды, которых нет на других страницах, а **Все** показывает и то и другое.
2. Введите текст в **Фильтр по имени…**, чтобы найти команду. Чтобы найти команду по сочетанию, нажмите **Поиск по горячей клавише** и нажмите его.
3. Нажмите поле горячей клавиши команды и нажмите новое сочетание.
4. Если эти клавиши уже запускают другую команду, поле сообщит об этом. Выберите **Использовать здесь**, чтобы перенести клавиши на эту команду, или возьмите одно из свободных сочетаний, которые предлагает Enconvo.
5. Переключитесь в другое приложение и проверьте горячую клавишу.

Чтобы освободить клавиши, уберите их у команды. Сообщение с **Отменить** позволяет вернуть как было.

Значок **Локально** отмечает горячую клавишу, которая работает только внутри Enconvo, например закрепить SmartBar.

## Как нажимать

Если вы записываете одну клавишу-модификатор, например Right ⌘, поле спрашивает **Способ нажатия**:

| Вариант | Команда запускается, когда вы |
| --- | --- |
| **Удерживать или нажать** | Удерживаете клавишу или нажимаете ее, чтобы переключить |
| **Касание** | Нажимаете клавишу, чтобы начать, и еще раз, чтобы остановить |
| **Удерживать** | Держите клавишу; работает, пока держите |
| **Двойное касание** | Быстро нажимаете клавишу дважды |

Две или больше клавиш-модификаторов, нажатых одновременно, считаются одной горячей клавишей. В каждом поле показаны только способы, которые поддерживает команда, а описание рядом говорит, как на это реагирует функция.

## Где лежит горячая клавиша каждой функции

Кроме страницы сочетаний, у каждой функции есть горячая клавиша на своей странице настроек:

| Функция | Страница настроек |
| --- | --- |
| SmartBar | **Настройки → SmartBar** |
| Dynamic Island | **Настройки → Dynamic Island** |
| PopBar | **Настройки → PopBar** |
| Боковое меню приложения | **Настройки → Боковое меню приложения** |
| Диктовка | **Настройки → Диктовка** |
| Голосовая команда | **Настройки → Голосовая команда** |
| Appshots | **Настройки → Appshots** |
| Рисование на экране | **Настройки → Рисование на экране** |
| Голосовая заметка | **Настройки → Голосовая заметка** |
| Быстрая запись | **Настройки → Быстрая запись** |
| Одна команда | Настройки этой команды, если у нее есть поле **Сочетание клавиш** |

## Внутри SmartBar

Введите символ-триггер в SmartBar, чтобы искать один вид элементов:

| Символ | Открывает |
| --- | --- |
| **@** | Команды |
| **#** | Контекст для сообщения |
| **$** | Навыки |
| **>** | Недавние задачи |

Эти символы меняются в **Поиск** в **Настройки → SmartBar**. Меню косой черты содержит действия вроде выбора модели и усилия рассуждения.

Чтобы перемещаться по спискам с клавиатуры, выберите **Сочетания клавиш для навигации** в **Настройки → SmartBar**: **macOS** использует **⌃N** **⌃P** **⌃F** **⌃B**, а **Vim** — **⌃J** **⌃K** **⌃L** **⌃H**.

## Подогнать Enconvo под Mac

В том же окне настроек лежат остальные пункты из видео:

| Страница настроек | Что делает |
| --- | --- |
| **Контекстная осведомленность** | Выбирает, что SmartBar берет из приложения, в котором вы были: выделенный текст, выбор в Finder или страницу в браузере. **Прикрепить** добавляет это сразу при открытии SmartBar, **Предложить** предлагает одним нажатием. См. [Контекстная осведомленность](/ru/features/context-awareness). |
| **Appshots** | Добавляет окно перед вами в разговор горячей клавишей. См. [Appshots](/ru/features/appshots). |
| **Локальные модели** | Показывает ИИ на этом Mac, память и диск, которые он занимает, и где работает каждая функция. См. [Локальные модели](/ru/ai/local-llm). |
| **Разрешения** | Перечисляет, что macOS разрешает Enconvo и зачем; **Предоставить** исправляет недостающее. См. [Разрешения macOS](/ru/configuration/permissions). |
| **Не усыплять** | Не дает этому Mac уснуть, пока вас нет, чтобы до него можно было дотянуться с iPhone. |

## Устранение неполадок

| Проблема | Что делать |
| --- | --- |
| Горячая клавиша работает только внутри Enconvo | Проверьте, есть ли у нее значок **Локально**. Если нет, проверьте «Мониторинг ввода» и «Универсальный доступ» в [Разрешения macOS](/ru/configuration/permissions) и не занимает ли те же клавиши другое приложение. |
| Нажатие горячей клавиши делает что-то другое | Используйте **Поиск по горячей клавише**. Если ни одна команда Enconvo не занимает клавиши, их занимает другое приложение или macOS. |
| Горячая клавиша из модификатора не срабатывает | Откройте ее и проверьте **Способ нажатия**: удержание, касание, двойное касание или клавиши вместе. |
| Сочетание из видео или с другого Mac не работает | Ваши горячие клавиши могут отличаться. Посмотрите текущее в **Настройки → Сочетание клавиш**. |

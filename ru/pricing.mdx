Enconvo разделяет приложение и AI, который оно вызывает. Лицензия открывает приложение. AI может идти из баллов Enconvo Cloud, вашего ключа API, плана провайдера, в который вы входите, или модели на Mac, и каждый счёт выставляется в своём месте. Смотрите **Настройки → Учетная запись** и сайт Enconvo, какие планы и цены доступны вашей учётной записи сейчас.

## Как платить за AI

| Доступ | Что покрывает | Где видно использование |
| --- | --- | --- |
| Бессрочная лицензия Enconvo | Доступ к функциям приложения | **Бессрочная лицензия** в **Настройки → Учетная запись** |
| План Enconvo Cloud | Облачные модели и службы, оплата баллами | **Настройки → Использование баллов** |
| Свой ключ API | Запросы к этому провайдеру | Собственная учётная запись API провайдера |
| План провайдера, в который вы входите | Поддерживаемые планом функции и лимиты | Страница провайдера в Настройках |
| Локальные модели | Работают на вычислениях, памяти и хранилище Mac плюс загрузки моделей | Ваш Mac |

Покупка лицензии приложения не добавляет платный кредит API ни у одного провайдера. Чат-план провайдера тоже не включает все его API.

## Планы Enconvo

- **Бессрочная лицензия**: разовая покупка приложения, уровни Standard и Premium, с бонусными баллами. AI со своими ключами API — сколько угодно. Teams — бессрочная лицензия для организаций: вы покупаете места и назначаете каждое по электронной почте. См. [Teams](/ru/configuration/account).
- **Enconvo Cloud**: месячный или годовой план уровней Plus, Pro и Max. Каждый месяц добавляет баллы и облачные модели, которым ключ API не нужен.
- **Пробный Standard**: бесплатная учётная запись может получить разовый 7-дневный пробный Standard без карты. Когда он предлагается, в **Настройки → Учетная запись** появляется **Начать пробный период**.
- **Коды**: коды лицензий и пробные коды активируются в **Настройки → Активировать код**. Код лицензии Teams делает вашу учётную запись администратором команды мест этого кода, с 50 000 облачных баллов на место.

Бессрочные лицензии всегда называются Standard и Premium, поэтому не делят имя с облачными планами Plus и Pro.

## Как тратятся облачные баллы

Сначала тратятся баллы подписки. Они сбрасываются до суммы плана при каждом продлении. Баллы пополнения, из пакетов пополнения и бессрочных лицензий, не сгорают.

Стоимость запроса зависит от модели и способа доступа, которым функция реально пользуется. Текст, изображения, видео, транскрибирование, эмбеддинги и голос в реальном времени могут стоить по-разному.

## Проверить неожиданное использование

1. Откройте **Настройки → Использование баллов** для Enconvo Cloud или собственную страницу использования провайдера для своих ключей API.
2. Откройте **Настройки → Статистика использования**, чтобы увидеть оценку стоимости, токены и запросы по модели, провайдеру и функции.
3. Ищите запланированные задачи, долгие задачи, поиск и запросы генерации, которые делят один профиль провайдера.

Enconvo разделяет приложение и AI, который оно вызывает. Лицензия открывает приложение. AI может приходить из баллов Enconvo Cloud, вашего собственного ключа API, тарифа провайдера, в который вы входите, или модели на вашем Mac, и каждый вариант оплачивается отдельно. Актуальные тарифы и цены, доступные вашей учётной записи, смотрите в **Настройки → Учетная запись** и на сайте Enconvo.

## Способы оплаты AI

| Доступ | Что покрывает | Где виден расход |
| --- | --- | --- |
| Бессрочная лицензия Enconvo | Доступ к функциям приложения | **Бессрочная лицензия** в **Настройки → Учетная запись** |
| Тариф Enconvo Cloud | Облачные модели и сервисы, оплата баллами | **Настройки → Использование баллов** |
| Собственный ключ API | Запросы к этому провайдеру | Собственный аккаунт API у провайдера |
| Тариф провайдера, в который вы входите | Поддерживаемые функции и лимиты тарифа | Страница провайдера в настройках |
| Локальные модели | Работают на вычислительных ресурсах, памяти и диске вашего Mac, плюс загрузка моделей | Ваш Mac |

Покупка лицензии на приложение не добавляет платный кредит API ни у одного провайдера. Чат-тариф провайдера также не включает все API этого провайдера.

## Тарифы Enconvo

- **Бессрочная лицензия**: разовая покупка приложения в вариантах Standard и Premium, с бонусными баллами. Пользуйтесь AI со своими ключами API сколько угодно. Teams — это бессрочная лицензия для организаций: вы покупаете места (Seats) и назначаете каждое по электронной почте. См. [Teams](/ru/configuration/account).
- **Enconvo Cloud**: ежемесячный или годовой тариф Plus, Pro и Max. Он ежемесячно добавляет баллы и открывает облачные модели, для которых не нужен ключ API.
- **Пробный период Standard**: бесплатная учётная запись может получить однократный 7-дневный пробный период Standard без карты. Когда он доступен, в **Настройки → Учетная запись** появляется **Начать пробный период**.
- **Коды**: коды лицензий и пробных периодов активируются в **Настройки → Активировать код**. Код Teams License делает вашу учётную запись администратором команды для мест из этого кода, по 50 000 облачных баллов на каждое место.

Бессрочные лицензии всегда называются Standard и Premium, чтобы их названия не совпадали с облачными тарифами Plus и Pro.

## Как расходуются облачные баллы

Сначала расходуются баллы подписки. При каждом продлении они сбрасываются до количества, предусмотренного вашим тарифом. Баллы пополнения, полученные из пакетов пополнения и бессрочных лицензий, никогда не сгорают.

Стоимость запроса зависит от модели и способа доступа, который на самом деле использует функция. Текст, изображения, видео, транскрибация, эмбеддинги и голос в реальном времени могут стоить по-разному.

## Проверка неожиданного расхода

1. Откройте **Настройки → Использование баллов** для Enconvo Cloud или страницу использования у самого провайдера, если вы используете собственные ключи API.
2. Откройте **Настройки → Статистика использования**, чтобы увидеть примерную стоимость, токены и запросы по моделям, провайдерам и функциям.
3. Поищите запланированные задачи, долгие задачи, а также запросы поиска и генерации, которые используют один и тот же профиль провайдера.

Enconvo keeps the app and the AI it calls apart. A license unlocks the app. The AI can come from Enconvo Cloud points, your own API key, a provider plan you sign in to, or a model on your Mac, and each one is billed in its own place. Check **Settings → Account** and the Enconvo website for the plans and prices your account can get now.

## Ways to pay for AI

| Access | What it covers | Where usage shows |
| --- | --- | --- |
| Enconvo lifetime license | App feature access | **Lifetime Licence** in **Settings → Account** |
| Enconvo Cloud plan | Cloud models and services, paid in points | **Settings → Points Usage** |
| Your own API key | Requests to that provider | The provider's own API account |
| A provider plan you sign in to | The plan's supported features and limits | The provider's page in Settings |
| Local models | Runs on your Mac's compute, memory, and storage, plus any model downloads | Your Mac |

Buying an app license doesn't add paid API credit with any provider. A provider's chat plan doesn't include all of that provider's APIs either.

## Enconvo plans

- **Lifetime license**: a one-time purchase of the app, in Plus and Pro tiers, with bonus points. Use AI with your own API keys as much as you like. Teams is the lifetime license for organizations: you buy Seats and assign each one by email. See [Teams](/configuration/account#teams).
- **Enconvo Cloud**: a monthly or yearly plan in Plus, Pro, and Max tiers. It adds points each month and Cloud models that need no API key.
- **Plus trial**: a free account can get a one-time 7-day Plus trial with no card needed. When it's offered, **Start trial** appears in **Settings → Account**.
- **Codes**: license codes and trial codes activate in **Settings → Redeem Code**.

For current plans and prices:

- [Enconvo website](https://www.enconvo.com)
- [Enconvo Cloud Plan](https://www.enconvo.com/cloud-plan)
- [Cloud model pricing](https://www.enconvo.com/cloud-pricing)

## How Cloud points are used

Subscription points are used first. They reset to your plan's amount on each renewal. Top-up points, from top-up packs and lifetime licenses, never expire.

What a request costs depends on the model and the access method the feature actually uses. Text, images, video, transcription, embeddings, and realtime voice can each be priced differently.

## Check unexpected usage

1. Open **Settings → Points Usage** for Enconvo Cloud, or the provider's own usage page for your own API keys.
2. Open **Settings → Usage Statistics** to see estimated cost, tokens, and requests by model, provider, and feature.
3. Look for scheduled tasks, long-running tasks, retrieval, and generation requests that share the same provider profile.

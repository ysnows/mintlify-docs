Enconvo supports several ways to access AI. Check your **Settings → Account** page and the official website for the plans, entitlements, and prices currently available to your account.

| Access | Where usage is accounted for |
| --- | --- |
| Enconvo app license | App feature access shown in Account |
| Enconvo Cloud Plan | Cloud usage and points shown in Points Usage |
| Your own API key | The selected model provider's API account |
| Supported provider subscription | The connected provider account's supported capabilities and limits |
| Local models | Your Mac's compute, memory, storage, and any required model downloads |

Buying an app license does not itself create paid API credit with every provider. A provider's chat subscription also does not imply access to all of that provider's APIs.

## Current plan information

- [Enconvo website](https://www.enconvo.com)
- [Enconvo Cloud Plan](https://www.enconvo.com/cloud-plan)
- [Cloud model pricing](https://www.enconvo.com/cloud-pricing)

Use the model and access method actually selected in the feature when checking cost. Text, images, video, transcription, embeddings, and realtime voice can have different accounting.

## Check unexpected usage

Open **Points Usage** for Enconvo Cloud, or the provider's own usage page for BYOK. Review scheduled jobs, long-running tasks, retrieval, and generation requests that may have used the same provider profile.

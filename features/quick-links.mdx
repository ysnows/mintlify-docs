title: "Quick Links"

---

Quick Links turns a search query or configured URL into a browser action. Built-in commands include **Google Search in Browser**, **YouTube Search in Browser**, and **Twitter/X Search in Browser**.

## Search from SmartBar

1. Open SmartBar and find the browser-search command you want.
2. Enter the search text as the command's input.
3. Run the command and check the result in your default browser.

Quick Links opens a destination. [Web Search](/ai/web-search) instead supplies search results to an AI response, and [Browser Control](/features/browser-control) lets an Agent interact with pages.

## Configure a link

Open **Settings → Plugins → Quick Links** and select **Quick Link** or a search command. Review its URL template and supported input variables before saving your own configuration. Test with ordinary text first, including spaces or punctuation.

If the destination is wrong, check the command's template and input. If the browser does not open, check your default browser and whether the command is installed.

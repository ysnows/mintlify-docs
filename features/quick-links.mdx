Quicklinks turn a web search, a web address, a file or folder, or an app's deeplink into a command you run from SmartBar. Placeholders fill in the link with what you type, the clipboard, the selected text, or the date. Enconvo comes with Google, YouTube, and X searches ready to use.

Quicklinks open a destination. [Web Search](/ai/web-search) instead brings search results into an AI answer, and [Browser Use](/features/browser-control) lets an Agent work in web pages.

## Search the web from SmartBar

1. Open SmartBar and find **Google Search in Browser**, **YouTube Search in Browser**, or **Twitter/X Search in Browser**.
2. Type your search text as the command's input. Selected text works too.
3. Run the command. The search opens in your default browser.

## Create a quicklink

1. Run **Create Quicklink** from SmartBar.
2. Enter a **Name**, such as Search GitHub.
3. Enter the **Link**: a web address, a file or folder path, or a deeplink. Click **Insert Placeholder** to add one, such as `https://github.com/search?q={argument}`.
4. To open it in a particular app, enter an app name such as Safari, an app path, or a bundle id in **Open With**. Leave it empty to use the default app.
5. Click **Save**. Search for the quicklink's name in SmartBar to run it.

When you run a quicklink, the text you typed or selected fills its first argument. If a required argument is still empty, Enconvo asks for it before opening the link.

| Placeholder | Filled with |
| --- | --- |
| `{argument name="Query"}` | A value you type when the quicklink opens |
| `{clipboard}` | The text on the clipboard |
| `{selection}` | The text selected in the app you're using |
| `{date}`, `{time}`, `{datetime}` | The current date, time, or both |
| `{date format="yyyy-MM-dd"}` | The date in the format you give |
| `{uuid}` | A new unique ID |

Test a new link with ordinary text first, including spaces and punctuation.

## Manage your quicklinks

Run **Search Quicklinks** from SmartBar to see every quicklink. From there you can open, edit, duplicate, or delete one, and click **New** to add another.

The **More** menu has **Import Quicklinks…**, which reads Raycast quicklink and settings exports, and **Export to Downloads**. A Raycast settings export asks for the passphrase you chose when you exported it.

## Settings

Open **Settings → Plugins → Quicklinks**. Each search command also has its own **Link**, such as `https://www.google.com/search?q={query}`, that you can change.

| Setting | What it changes |
| --- | --- |
| **Open in New Window** | Opens web quicklinks in a new browser window. Works with Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox, and Zen; Safari, Arc, and Orion open the link as usual. Off by default |
| **When There's No Selected Text** | What a `{selection}` link does when nothing is selected: **Ask for it** (the default) or **Use the clipboard** |
| **Confirm Before Deleting** | Asks before you delete a quicklink. On by default |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The wrong page opens | Check the quicklink's **Link** and its placeholders, then try it with plain text |
| The browser doesn't open | Check your default browser, the quicklink's **Open With**, and that the command is installed |
| A `{selection}` link asks for text | Nothing was selected. Select the text first, or set **When There's No Selected Text** to **Use the clipboard** |

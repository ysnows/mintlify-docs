---
title: "Companion Orb and Desktop Pet"
description: "Find the current replacement for the legacy Companion Orb."
---

The **Companion Orb** is a legacy interface. Current builds replace it with the **Desktop Pet**. If you used an older version, look under **Settings → Primary Function Area → Pet**; the old Orb toggle is no longer the current setup path.

| What you want | Current feature |
| --- | --- |
| A small character that shows Agent activity | [Desktop Pet](/features/pet) |
| A character assigned to an Agent, with voice chat | [Avatar](/features/avatar) |
| A compact conversation at the top of the screen | [Dynamic Island](/features/dynamic-island) |
| An assistant alongside another app | [App Sidebar](/features/app-sidebar) |
| A full conversation workspace | [Chat Window](/ai/chat) |

On migration, users with the old Orb enabled receive the Pet instead. Review **When tapped, open** and **Session cards** in Pet settings to choose how it behaves. Older Orb screenshots and hotkeys do not describe the current Pet or Avatar controls.

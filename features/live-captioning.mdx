---
title: "Live Captioning"
description: "Read realtime subtitles and revisit captioning sessions."
---

Live Captioning produces subtitles while audio is playing or being captured. Its saved sessions appear separately from imported transcription files and meeting recordings.

## Start captioning

1. Open **Settings → Captioning → Captioning Model** and select a model suitable for realtime recognition.
2. Open **Live Captioning** and choose **Start Captioning**, or invoke the corresponding command.
3. Select the audio source and controls offered by the captioning panel. Grant microphone or system-audio capture access as required.
4. Start the audio you want to follow and check that subtitles appear.
5. Stop captioning when finished, then open the saved session from the Live Captioning list.

## Translation

Some speech providers expose live translation, source/target language, or spoken-translation options. Configure those in the selected captioning provider. Not every speech model supports realtime translation; file-transcription support alone does not imply live-captioning support.

## Review a session

Open a saved session to review its transcript and available processing results. Check names, numbers, and speaker labels against the audio when accuracy matters. Use [Speech Assets](/configuration/speech-assets) to maintain vocabulary and speaker names.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| No subtitles | Audio source, input level, capture permissions, and selected provider |
| Text appears only after stopping | Whether the selected model supports streaming |
| Wrong language | Recognition language or language hints |
| Translation is absent | Provider translation support and target language |
| Session has a processing error | Error details in the saved item; do not assume missing speech |

For a completed file, use [Transcription](/features/transcription). For recording a meeting, use [Meeting Recording](/features/meeting-recording).

---
title: "Live Captioning"
description: "Read subtitles in real time while audio plays, and revisit each captioning session later."
---

Live Captioning shows subtitles while audio is playing or being captured, such as a talk, a video, or a call. Each session is saved in its own list, apart from imported transcription files and meeting recordings.

## Start captioning

1. Open **Settings → Captioning Model** and select a model that supports realtime recognition.
2. Open **Settings → Live Captioning**, click **Add**, and choose **Start Captioning**. On an empty list, click **Start Captioning**. You can also run the **Start Live Captioning** command.
3. Select the audio source and the controls the captioning panel offers. Grant microphone or system-audio access when macOS asks.
4. Start the audio you want to follow and check that subtitles appear.
5. Stop captioning when you finish, then open the saved session from the **Live Captioning** list.

## Translate captions

Some speech providers offer live translation, with source and target languages or spoken translation. Turn these on in the selected captioning model's own settings. Not every speech model supports realtime translation, and support for file transcription does not mean a model supports live captioning.

## Review a session

Open a saved session to review its transcript and processing results. When accuracy matters, check names, numbers, and speaker labels against the audio. Use [Dictionary and Speakers](/configuration/speech-assets) to keep vocabulary and speaker names up to date.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No subtitles | Check the audio source, input level, capture permissions, and selected model. |
| Text appears only after you stop | Choose a model that streams. |
| Wrong language | Set the recognition language or language hints in the model's settings. |
| No translation | Check that the model supports translation, and set the target language. |
| The session shows a processing error | Read the error details in the saved item. Don't assume the speech is missing. |

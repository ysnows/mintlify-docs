title: "Live Talk"
description: "Call your Agent and talk things through: it listens, answers in its own voice, and starts tasks while you talk."
---

Live Talk is a voice call with your Agent. You talk without holding a key, the Agent answers out loud, and it can start tasks with its enabled tools while the call goes on. To turn speech into typed text instead, use [Dictation](/features/dictation).

## Before you start

Enconvo needs Microphone access in macOS. Select a working microphone and speaker. The Cloud services a call uses spend Enconvo Cloud points; your own keys and models on your Mac don't.

## Start and end a call

1. Open a chat with the Agent you want to talk to.
2. Click **Live Talk** beside the microphone. Wait for the call to connect.
3. Talk. There is no key to hold, and you can talk over the Agent at any time to make it stop and listen.
4. For a bigger job, name the result you want and give enough context. The job runs as a task in its own chat. Expand the working details to see its progress or results.
5. Use the microphone control to mute, or the hang-up control to end the call. Tasks keep running after you hang up.

Spoken turns are saved in the regular chat history, so reopening the chat lets you review the dialogue and work details. A quiet call stays connected until you hang up. A task's links in the chat bring you back to the call.

## Ask without starting a task

Some things the Agent does right in the call, without starting a task: search your Memory and past chats, save something you ask it to remember, read your Calendar and Reminders, search your mail, and use read-only tools of your MCP servers. **Quick Actions** in Settings lists more.

During a long task, the Agent tells you what the task has found so far.

## Quiet the Agent

Tell the Agent to be quiet or to stop talking for a while. It answers nothing and holds its news until you call it by name, say it can talk again, type to it, or click the **QUIET** status.

## Other ways to call

Agents can also call you, on the iPhone app or your phone number, when a task needs you; answering starts Live Talk. See [Agent Phone](/features/agent-phone).

You can also start a call from an [Avatar](/features/avatar), which then appears as the speaker, or from Voice Chat in the [iPhone app](/integrations/iphone-app). During a call on the iPhone or Android app, the **Remote Screen** tool opens your computer's screen in a small floating window over the call; see [Use your computer's screen](/integrations/iphone-app#use-your-computers-screen). Turn on **Live Screen** to let the Agent see your screen during a call.

## Settings

Open **Settings → Live Talk**:

| Setting | What it changes |
| --- | --- |
| **Listen** | How the call hears you. **Enconvo Cloud Fast** (the default) and **ElevenLabs Scribe** (Scribe v3 Live) hear each word as you say it. You can also pick a model that runs on your Mac, or any speech model. |
| **Think** | The model the Agent talks with. **Same as the Chat** (the default) uses a fast model of the chat's own provider, so a call in a chat on your own API key doesn't spend Enconvo Cloud points. In a chat on Enconvo Cloud it is Enconvo Fast, which answers with DeepSeek V4.1 Flash, also sees what you show it, and is billed as that model; calls on a paid plan or trial stay free. Bigger jobs go to your Agent and run on the model picked for that chat. |
| **Speak** | The voice the Agent answers in, ElevenLabs v4 Turbo by default. Phonon runs on your Mac, free and offline, in English only. Applies from the next call. |
| **Voice Expression** | How much the tone of each reply may change to fit the conversation: **Off**, **Subtle**, or **Expressive**. Works with ElevenLabs, Fish Audio, and Gemini voices. |
| **New conversation after** | A call within this many minutes of the last one picks up where it left off, Avatar calls included. **0** always continues it. |
| **Quick Actions** | **Manage** opens **Settings → Quick Actions**, the things the Agent does at once when you ask, without starting a task. |

<Note>
Live Talk's **Think** model is set here. You can also pick it under **Task models** in **Settings → AI Model**.
</Note>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The call doesn't connect | Read the connection error, then check your **Listen**, **Think**, and **Speak** choices. For Cloud services, check your points in **Settings → Points Usage**. |
| The microphone is unavailable | Finish an active Dictation or recording first, and check macOS Microphone access. |
| The Agent can't perform an action | Review that Agent's tools and permissions. Voice doesn't add tools the Agent lacks. |
| A new voice isn't used | Voice changes apply from the next call. |
| The call ends with "The audio device changed" | Your microphone or speaker keeps restarting. Choose another one in **System Settings → Sound**, then start a new call. |
| The Agent stopped answering | It may be quiet. Call it by name, or click the **QUIET** status. |

Writing Toolkit is a set of one-click commands for the text you select in any app. Fix mistakes, change the tone, make it shorter or longer, explain or summarize it, or turn it into a list or a table, without leaving the app you write in.

## Edit selected text

1. Select text in the app where you're writing.
2. Click a command in [PopBar](/features/popbar), or open [SmartBar](/features/smartbar) and search for the command.
3. Read the result. When **Highlight edits** is on, the result marks what the command added and removed.
4. Click **Paste** to replace your selection, or copy the result.

Each command keeps your text's language and replies with the result alone. When the selected text asks a question or gives an instruction, the command edits those words; it doesn't answer them.

<Tip>
Turn on **Inline Mode** for a command you trust, and it runs without a window and pastes the result straight over your selection. See [Change a command](#change-a-command).
</Tip>

## Choose a command

| Goal | Commands |
| --- | --- |
| Correct errors | Fix Spelling & Grammar, Proofread |
| Improve wording | Improve Writing, Polish, Rewrite, Sound Native, AI Edit |
| Change length | Make Longer, Make Shorter, Make Concise |
| Change tone | Change Tone Friendly, Confident, Casual, or Professional |
| Understand content | Explain, Summarize, Extract Key Points |
| Reformat | Convert to List, Convert to Table |
| Email | Polish Email, Draft a Reply |
| Posts on X | Polish for X, Fit in 280 Characters, Turn into a Thread, Suggest a Reply on X, Suggest a Quote Comment on X |
| Translate | Translator, Screenshot Translate (see [Translation](/ai/translate)) |
| Something on screen | Screenshot Explain |
| Dictation | Dictation Polish, Dictation Translate, Dictation Edit, On-Device Cleanup (see [Dictation](/features/dictation)) |
| Short expression | Emoji |

**Sound Native** rewrites your text the way a native speaker would write it, in the same language. **Polish Email** keeps your own greeting, sign-off, and name, and doesn't add a signature. **Draft a Reply** writes a reply to the selected email in its language and tone, and leaves a short placeholder in square brackets for a name, date, or decision it can't know.

## Change a command

Open **Settings → AI Commands** and pick the command under **Built-in**. Its page shows what the command does, with **Try it** to run it on some text first.

| Setting | What it changes |
| --- | --- |
| **PopBar** | Adds the command to PopBar, or takes it off |
| **Highlight edits** | Marks what the command added and removed in the result |
| **Hotkey** | Runs the command on the text you select in any app |
| **Inline Mode** | Runs without a window and pastes the result over your selection |
| **Post Action** | What the command does with the answer when it's done |
| **AI Model** | The model this command uses. By default it follows the model for all AI Commands |

A built-in command's instructions are read-only. Click **Customize** to make your own copy, which you can change freely.

Writing tools run on the model set in **Settings → AI Commands → All Commands**, unless a command picks its own. The same commands are also listed under **Settings → Plugins → Writing Toolkit**, and the **Settings** button in a result window opens the command that produced it.

## Get reliable results

When a rewrite could go several ways, say who the text is for and what it should do. Name what must stay the same, such as names, dates, figures, and quoted wording.

Always compare the result with your original before you send it. Fluent output can still change the meaning.

For an instruction you repeat, make your own [AI Command](/features/ai-commands).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A command isn't on PopBar | Click **⌄** at the end of PopBar, where the buttons that don't fit go, or turn on **PopBar** on the command's page in **Settings → AI Commands** |
| PopBar doesn't appear | See [PopBar troubleshooting](/features/popbar#troubleshooting) |
| The result is in an unexpected language | Explain answers in your Response Language. Summarize keeps the text's language unless you set its **Response Language**. The other commands keep the text's language |
| The result changed the meaning | Edit it before you paste, or run the command again with your original text |

title: "PopBar"
description: "Run configurable commands on selected text from a compact toolbar."
---

PopBar appears near selected text when enabled. Its commands can explain, translate, edit, search, copy, or read the selection aloud.

## Use PopBar

1. Open **Settings → Primary Function Area → PopBar** and enable it.
2. Select a short passage in a supported app.
3. Choose an action in the toolbar.
4. Review the result before using the command's copy, paste, or replacement action.

You can also run **Show PopBar** with an assigned shortcut. Selection detection depends on the app and Accessibility permission; secure fields and some custom editors may not expose selectable text.

## Configure the command list

In PopBar settings, edit **PopBar Command List** to add, remove, and reorder commands. The list can include Ask AI, Ask in Sidebar, Open Link, Search, Copy, Translate, Explain, Fix Spelling, AI Edit, and Read Aloud. The actual toolbar reflects your configured list.

Customize labels and whether a command shows an icon or text where those controls are available. Add a reusable [AI Command](/features/ai-commands) or a [Writing Toolkit](/features/writing-tools) command for your own editing workflow.

## Control where it appears

Review **PopBar Excluded Application** and the activation options in the same settings pane. Exclude apps where automatic selection actions would interrupt your work. Escape dismisses the current toolbar.

## Troubleshooting

- **No toolbar:** check Enable, Accessibility permission, and app exclusions.
- **Wrong text:** make a fresh selection and invoke PopBar again.
- **Missing command:** inspect PopBar Command List and verify that the command's plugin is installed.
- **Result does not replace text:** the destination app may not allow replacement; copy the result and paste it into an editable field.

## Change the result's model or settings

For commands with an AI model setting, the result toolbar offers a model picker. Changing it updates the command's default for later runs too. The result window's Settings button opens the command that produced that result, such as **Plugins → Writing Toolkit → Explain**.

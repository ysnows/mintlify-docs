An Avatar is a desktop character that stands for one of your Agents. In voice calls it speaks with animation synced to its voice, while the Agent keeps its usual instructions and tools.

## Set up a character

1. Open **Settings → Avatar**.
2. Find a character in **Gallery** and click **Download** to get its base package.
3. When the download finishes, choose the Agent it stands for and click **Bind Avatar**. Each Agent has one Avatar, and each Avatar belongs to one Agent.
4. Choose the character's **Quality**.
5. Click **Open** to show the Agent's Avatar on your desktop.

An Avatar's calls speak with the voice set in **Settings → Live Talk → Speak**, and a voice change applies to the next call.

**Optional downloads** lists additional packages for that character, such as higher-resolution textures or motions when available. Start with the base package and choose a quality that suits your Mac.

To make your own character, click **Create a character** and pick its face, fur, and name, or click **Import file…** to add an OpenAvatar character file.

## Talk and interact

Set up [Live Talk](/features/live-voice), then use the Avatar's conversation controls to start talking. Right-click the character for voice, history, settings, and character controls. The chat bubble shows conversation text and voice activity.

You can move the character, scroll to rotate it, and Control-scroll or pinch to zoom. Clicks on the transparent margins pass through to the desktop.

## Switch characters

The desktop **Character** menu does not reassign Agents. Selecting a character assigned to another Agent opens that Agent's Avatar. An unassigned character is shown through the main Agent. To change which Agent a character belongs to, use **Settings → Avatar**.

The Avatar switch in the menu bar or the Dynamic Island opens the main Agent with its assigned character.

## Settings

Each downloaded character's card in **Settings → Avatar** has these controls:

| Setting | What it changes |
| --- | --- |
| **Agent** | The Agent the character stands for. Assigning a new pair replaces their previous bindings; voice, appearance, and chat history are kept. |
| **Quality** | The rendering quality. **Minimal**, the default, uses the least GPU, CPU, and battery. **Balanced** and **Best quality** add lighting, shading, and larger textures, and use more GPU. |
| **Optional downloads** | Extra packages for the character, and package updates. |

**Natural lip sync**, above the gallery, downloads an on-device model that shapes every Avatar's lips from the voice it speaks with. It needs a Mac with Apple silicon.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Quality** can't be changed | Download the character and assign an Agent first. |
| A download fails | Read the error on the card, check your connection and free disk space, and click **Retry**. |
| The character is blurry when enlarged | Choose a higher **Quality**, and check **Optional downloads** for textures. |
| A call won't start | Check your [Live Talk](/features/live-voice) settings and macOS Microphone access. |
| The wrong Agent answers | Check the character's **Agent** in **Settings → Avatar**. |

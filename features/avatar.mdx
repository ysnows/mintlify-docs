An Avatar is a desktop character connected to an Agent. It presents voice conversations with speech-synchronized animation while the Agent uses its normal instructions and tools.

## Set up a character

1. Open **Settings → Agents → Avatar**.
2. Choose a character in the gallery and download its base package.
3. Assign an Agent when prompted. Each Agent has one Avatar assignment, and each character is assigned to one Agent.
4. Choose the character's **Quality** and **Voice**. Voice changes apply to the next voice conversation.
5. Click **Open** to show the assigned Agent's Avatar.

**Optional downloads** lists additional packages for that character, such as higher-resolution textures or motions when available. Start with the base package and choose a quality appropriate for your Mac.

## Talk and interact

Set up [Realtime Voice](/features/live-voice), then use the Avatar's conversation controls to start talking. Right-click the character for available voice, history, settings, and character controls. The chat bubble shows conversation text and voice activity.

You can move the character, use scroll to rotate it, and use Control-scroll or a pinch gesture to zoom. Transparent margins allow clicks to pass through to the desktop.

## Character selection and Agent identity

The desktop **Character** menu does not reassign Agents. Selecting a character assigned to another Agent opens that Agent's Avatar. An unassigned character is shown through the main Agent. Change permanent assignments in Settings.

The Avatar switch in the menu bar or Dynamic Island opens the main Agent with its assigned character.

## Troubleshooting

| Problem | Check |
| --- | --- |
| Voice or quality controls are unavailable | Download the character and assign an Agent first |
| Download fails | Read the gallery error, check connectivity and free disk space, and retry |
| Character is blurry when enlarged | Review rendering quality and available optional textures |
| Call will not start | Review Realtime Voice access and microphone permissions |
| The wrong Agent answers | Review the character's Agent assignment |

A [Pet](/features/pet) is a separate desktop companion with different controls.

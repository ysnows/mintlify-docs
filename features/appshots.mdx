Appshots adds the window of the app in front to your chat as context. Use it when you want to ask about something on screen without saving it to a knowledge base.

## Capture an app window

1. Bring the app you want to ask about to the front.
2. Press both **Option** keys at the same time. This is the default hotkey.
3. The window goes to the SmartBar, Chat Window, or App Sidebar if one of them is open in front. Otherwise it goes to the Dynamic Island. A short shutter sound plays.
4. Check the attached window, then ask a specific question, such as "Explain the error in this window."

## Settings

Open **Settings → Appshots**.

| Setting | What it does |
| --- | --- |
| **Enable Appshots** | Lets the hotkey add the frontmost app window. On by default. |
| **Capture sound** | Plays a short shutter sound when an Appshot is added. The sound confirms the capture; still check the attachment before you send. |
| **Hotkey** | Both **Option** keys together by default. You can use another set of modifier keys or an ordinary shortcut. |

## Choose the right capture tool

| Goal | Use |
| --- | --- |
| Ask about the current app window | Appshots |
| Draw attention to a region before asking | [Screen Doodle](/features/screen-doodle) |
| Save the current app's content for later search | [Quick Capture](/features/quick-capture) |
| Extract text from an image | [OCR](/ai/ocr) |

Captured content can be sent to the model you use for the request. See [Context Awareness](/features/context-awareness) for other ways to add context.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No context appears | Check **Settings → Permissions**, especially Screen Recording and Accessibility. |
| The wrong window is captured | Bring the target app to the front again. Appshots captures another app's window, not Enconvo's own windows such as Settings. |
| The hotkey does something else | Another app uses the same keys. Change the **Hotkey** in **Settings → Appshots**. |

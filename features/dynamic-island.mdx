The Dynamic Island keeps quick Agent requests and activity near the top of your display. You can type, use voice, attach context, and return to an in-progress conversation.

## Start a request

1. Open **Settings → Primary Function Area → Dynamic Island** and enable it.
2. Move to the top-center wake area or use the configured **Shortcut** to expand it.
3. Type a request, or select one of the **Home Shortcuts**.
4. Review any attached context before submitting. [Appshots](/features/appshots) and [Screen Doodle](/features/screen-doodle) help you ask about other apps.
5. Follow progress and open the result when the task finishes.

## Make it fit your desktop

| Setting | What it changes |
| --- | --- |
| Hide when collapsed | Keep the compact island hidden until hover or shortcut activation |
| Exclude notch area | Avoid hover activation inside the physical notch |
| Hover expand delay | How long to hover before expanding |
| Auto dismiss delay | How long the expanded panel stays open after interaction |
| Display | Select a display or follow the mouse |
| Hide on fullscreen | Hide on a display occupied by a fullscreen app |
| Show in screen recordings | Include the island in screenshots and recordings |
| Default Agent | The Agent used for a new request from the island |
| Home Shortcuts | Commands shown on its home screen |

## Voice and completion

[Live Voice](/features/live-voice) offers a spoken conversation; ordinary voice input transcribes a prompt. Starting Live Talk from SmartBar hands the call to the Dynamic Island in current builds.

Choose whether a completed island session expands automatically under [Notifications](/configuration/notifications). That setting is separate from macOS notifications.

## Troubleshooting

If it appears on another display, check the Display setting. If it disappears in fullscreen or does not appear in a screen recording, check the corresponding visibility setting before changing permissions. Use the shortcut to distinguish a hover-activation issue from a disabled panel.

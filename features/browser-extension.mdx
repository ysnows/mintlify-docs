---
title: "Browser Extension"
description: "Install the Enconvo Companion extension so Enconvo can work in your real browser, with your sign-ins, cookies, and extensions."
---

The Enconvo browser extension, Enconvo Companion, lets Enconvo control your real browser when a task needs your signed-in browser state. Use it for sites such as LinkedIn, Gmail, Salesforce, dashboards, or internal tools, where your cookies and browser extensions matter. Settings calls it **Browser Companion**.

For public pages, local previews, or workflows that shouldn't touch your personal browser profile, use isolated browser automation instead.

## Set up the extension

<Steps>
  <Step title="Install the extension">
    Open **Settings → Browser Use** and click **Install Browser Companion** in **Browser Extensions**. The extension's Chrome Web Store page opens. You can also install it from your browser's extension store. It works in Chrome, Edge, Brave, Arc, Vivaldi, Opera, and Firefox. The [Computer Use video tutorial](https://youtu.be/0CbQA7d8zqU?t=33) shows the install in Chrome.
  </Step>
  <Step title="Keep the browser open">
    The extension connects to Enconvo on its own, over `ws://localhost:11225`.
  </Step>
  <Step title="Check the popup">
    Click the extension's icon. The popup shows **Connected Chrome**, **Connected Edge**, **Connected Firefox**, or the name of the browser you're in.
  </Step>
  <Step title="Start a browser task">
    Ask Enconvo to read, click, type, take a screenshot, or manage tabs in the browser.
  </Step>
</Steps>

## The popup

| Item | What it shows |
| --- | --- |
| Connection status | Whether this browser's extension is connected to Enconvo |
| Current browser | The browser this extension is connected as, such as Chrome, Edge, Brave, or Firefox |
| Connected browsers | The other browsers whose extension is connected to Enconvo now |
| Version | The installed extension version |
| **Learn more** | Opens this page |

If the popup says disconnected, restart Enconvo and refresh the browser. If it still doesn't connect, turn the extension off and on again.

## Use more than one browser

Enconvo can connect to several browsers at once. When a task doesn't name a browser, Enconvo picks one in this order:

1. The **Default Browser** you chose in the Browser Use settings (**Settings → Browser Use**, then **Settings** in the **⋯** menu).
2. Your Mac's default browser.
3. The connected browser you used most recently.

Automation APIs can also name the browser:

```json
{
  "browser": "edge"
}
```

Common values include `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera`, and `firefox`.

## Stay on the right tab

When a browser task starts, Enconvo notes the browser and tab it's working in. Later steps stay on that tab whenever they can, even if the page opens a popup, reloads, or loses focus.

For the best results:

- Keep the tab open until the task finishes.
- Name the browser when several are connected.
- Say "use the current tab" when you want Enconvo to act on the page in front of you.
- Ask for a fresh look at the page after it navigates or you submit a form.

## Website access and safety

Web pages can contain instructions you didn't write. On sensitive pages, review the site and the action before you let Enconvo continue.

The extension uses browser permissions to read pages, click, type, take screenshots, see tabs, and read cookies when a task needs them. Treat signed-in pages, browser history, and internal tools as sensitive data.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The popup says disconnected | Make sure Enconvo is running, restart the browser, then turn the extension off and on again. Check that nothing blocks `localhost:11225`. |
| The wrong browser is controlled | Set **Default Browser** in the Browser Use settings, or pass a browser value such as `edge`, `chrome`, or `firefox` in the browser action. |
| Connected, but a page can't be controlled | Browser pages such as `chrome://` can't be controlled. Pages with a strict content security policy, closed Shadow DOM, and browser permission prompts can also get in the way. |
| A file upload doesn't work | On the extension's details page in your browser, turn on access to file URLs. Tasks that upload local files or open file-backed pages need it. |

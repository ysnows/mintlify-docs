SmartBar is a launcher you open from any app to ask an Agent a question or run a command. Press **⇧⌘D**, type, and press Return. Reach for it when you want a quick answer and then get back to what you were doing.

For other jobs, use the [Chat Window](/ai/chat) for long conversations and files, the [App Sidebar](/features/app-sidebar) to work beside one app, [PopBar](/features/popbar) to act on selected text, or the [Dynamic Island](/features/dynamic-island) and [Desktop Pet](/features/pet) for a small entry point that stays on screen. [Window Management](/features/window-management) compares them all.

## Ask a question

1. Press **⇧⌘D**, or the hotkey you set in **Settings → SmartBar**.
2. Type your question. Pick another Agent or model first if you need one.
3. Attach the context the Agent needs. It doesn't see every open app; see [Add context](#add-context).
4. Press Return and follow the answer or the tool progress.
5. Copy the result, or type a follow-up to continue the conversation.

## Search with trigger characters

Type one of these characters in SmartBar to search one kind of item:

| Type | To |
| --- | --- |
| `@` | Search commands |
| `#` | Add context |
| `$` | Use a skill |
| `>` | Show recent tasks |
| `/` | Open actions, such as model and reasoning selection |

You can change the first four under **Search** in **Settings → SmartBar**. `/` can't be changed.

Pick items from the list that opens instead of typing a name from memory: the list shows the commands and context sources you actually have. See [Writing Toolkit](/features/writing-tools), [Quick Links](/features/quick-links), and [Context Awareness](/features/context-awareness).

## Add context

SmartBar can pick up the selected text, the Finder selection, and the current browser page when it opens. Choose **Attach**, **Suggest**, or **Off** for each one in **Settings → Context Awareness**. To add anything else, type `#` and pick a source.

**Layout** in **Settings → SmartBar** sets what you see when SmartBar opens:

| Layout | What opens |
| --- | --- |
| **Input Only** | Just the input field |
| **Input and Toolbar** | The input, plus quick actions, the model picker, and voice controls |
| **Full Panel** | All of that, plus the list below the input |

With **Full Panel**, **Initial State View** sets what the list shows before you type: **Recommended Prompts** or **Command List**. In every layout, the list and results still appear once you type or run a command.

## Settings

Open **Settings → SmartBar**.

| Setting | What it changes |
| --- | --- |
| **Hotkey** | Opens and closes SmartBar from any app. The default is **⇧⌘D**. |
| **Default Agent** | The Agent that answers what you type. |
| **Auto Clear Conversation** | Starts a new conversation when SmartBar opens after being closed this long, from **Never** to **Every time it opens**. |
| **Layout** | What you see when SmartBar opens (see above). |
| **Appearance** | Light or dark glass for SmartBar and the App Sidebar, or **Follow App**. |
| **Auto-switch Input Source** | Switches to this input source while you type in SmartBar, and back when it closes. |
| **Navigation Bindings** | Control-key shortcuts for moving through lists and text: **macOS** (⌃N ⌃P ⌃F ⌃B) or **Vim** (⌃J ⌃K ⌃L ⌃H). |
| **Search** | The trigger characters for commands, context, skills, and recent tasks. |

Changing a default doesn't change every existing chat. [Model Selection](/ai/model-selection-guide) explains how each chat keeps its own model and reasoning choice.

## Voice and calculations

Click the microphone to speak your question with [Dictation](/features/dictation). For a spoken back-and-forth, start [Live Talk](/features/live-voice); a call you start from SmartBar moves to the Dynamic Island.

Type an arithmetic expression, such as `2+3*4`, and SmartBar shows the result. Check the result and the action it offers before you copy it.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| SmartBar doesn't open | Check **Hotkey** in **Settings → SmartBar**, and look for another app that uses the same shortcut. |
| An app or the selected text is missing from the context | Check [Permissions](/configuration/permissions) and **Settings → Context Awareness**. |
| A request fails | Check the selected provider and read the error it reports. |
| A control on this page is missing | Your build may be older than this guide. See [Updates](/configuration/updates). |

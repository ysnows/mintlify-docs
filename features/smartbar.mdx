SmartBar is a compact launcher for conversations and commands. Open it with your configured shortcut, commonly **Shift + Command + D**.

## Make a request

1. Open SmartBar and type a question.
2. Select an Agent or model when needed.
3. Attach the relevant context rather than assuming the Agent sees every open app.
4. Submit and follow the response or tool progress.
5. Copy the result or continue the conversation.

## Commands, context, and recent tasks

The trigger characters are configurable under **Settings → Primary Function Area → SmartBar**. The default fields are:

| Input | Purpose |
| --- | --- |
| `@` | Search commands |
| `#` | Pick context sources |
| `>` | Find recent tasks |
| `/` | Open actions such as model and reasoning selection |

Choose from the picker rather than typing an assumed tool identifier. Installed commands and available contexts can vary. See [Writing Toolkit](/features/writing-tools), [Quick Links](/features/quick-links), and [Context Awareness](/features/context-awareness).

| Layout | Initial appearance |
| --- | --- |
| Input Only | Just the input field |
| Input and Toolbar | Input, quick actions, model picker, and voice controls |
| Full Panel | Also show the command list when opened |

These settings control how SmartBar opens. Command lists and results still appear when you type or run a command.

## Useful settings

Choose the **Default Agent**, initial state, context behavior, navigation bindings, and conversation-clearing behavior on the SmartBar settings page. **Shake to Dynamic Island** lets you hand off the floating interaction using the supported gesture when enabled.

Per-chat model and reasoning behavior is described in [Model Selection](/ai/model-selection-guide). Changing a default is not the same as changing every existing chat.

## Voice and calculations

Use the microphone for [Dictation](/features/dictation). Use Live Talk for [Live Voice](/features/live-voice); current builds hand SmartBar calls to the Dynamic Island.

Type a simple arithmetic expression such as `2+3*4` to use the calculator result. Check the displayed result and action before copying it.

## Troubleshooting

If SmartBar does not open, check its hotkey and competing shortcuts. If an app or selected text is missing from context, check [Permissions](/configuration/permissions). If results fail, inspect the selected provider and the reported error. See [Updates](/configuration/updates) when a documented control is missing from your build.

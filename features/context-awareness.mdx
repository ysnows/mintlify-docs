Context is what goes along with your question: the text you selected, the files selected in Finder, the page open in your browser, or a screenshot. The SmartBar can pick some of it up as it opens, and you can add more by typing `#`. The Agent then answers about what you're looking at, without you explaining it.

## Choose what the SmartBar picks up

1. Open **Settings → Context Awareness**.
2. Under **When the Smart Bar Opens**, set each source to **Attach**, **Suggest**, or **Off**.
3. Switch to another app, select something, and open the SmartBar to see the result.

| Source | What it adds | Default |
| --- | --- | --- |
| **Selected Text** | Text selected in the app you were using | **Attach** |
| **Finder Selection** | Files and folders selected in Finder | **Suggest** |
| **Current Browser Page** | The page open in Safari, Chrome, Arc, Edge, or another Chromium browser | **Suggest** |

**Attach** adds the source to the input as soon as the SmartBar opens. **Suggest** lists it above the commands, so you add it with one click. **Off** leaves it out.

Only the SmartBar uses these settings. Commands you run on a selection always receive the selected text. The first time you add Finder or browser context, macOS asks whether Enconvo may control that app.

## Add context with #

1. In the SmartBar, type `#`.
2. Type a word to narrow the list, such as `#screen`, `#finder`, `#clipboard`, or `#browser`.
3. Pick a source. It's added to your message.
4. Type your question and send it.

| Source | What it adds |
| --- | --- |
| **Selected Text** | The text selected in the current window |
| **Clipboard Text** | The text on the clipboard |
| **Current Application Content** | The text of the app in front |
| **Current Application Screenshot** | A screenshot of the app in front |
| **Current Screen Screenshot** | A screenshot of the whole screen |
| **Live Screen Screenshot** | A screenshot of the screen without Enconvo's windows |
| **User Select Area Screenshot** | A screenshot of a region you select |
| **Finder Selected Items** | The files and folders selected in Finder |
| **Finder Current Directory URL** | The folder open in Finder |
| **Browser Current Tab URL** | The address of the browser's current tab |

Your open windows are listed too, so you can add a window from another app. To use a different character than `#`, change **Context** under **Search** in **Settings → SmartBar**.

## What to ask

With the browser page attached, ask Enconvo to summarize the page, translate it, or pull out the key information. With Finder files attached, ask it to describe the files, suggest how to organize them, help with a batch rename, or analyze their contents.

<Note>
Context you attach goes to the model that answers, or to the provider that processes it. Review what's attached and your provider settings before you work with sensitive content.
</Note>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Selected text isn't attached | Check that **Selected Text** is set to **Attach**, and check [Permissions](/configuration/permissions). |
| Finder or browser context is missing | Allow Enconvo to control that app when macOS asks. If you declined, allow it in [Permissions](/configuration/permissions). |
| Typing `#` doesn't open the list | Check the **Context** character in **Settings → SmartBar**. |

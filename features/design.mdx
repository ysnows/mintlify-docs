title: "Design Canvases"
description: "Have an Agent lay out screens, posters, emails, and other designs on a canvas of artboards, and give them a design system from your own brand."
---

A design canvas is where an Agent shows how something should look: app screens, wireframes, a pricing page in two versions, a poster, or an email. Each piece is an artboard on a canvas you pan, zoom, select, and edit beside the chat. Use it when you're deciding on a look before anything is built.

## Make a design

1. Start a new chat and pick **Design** under the message box, or ask for a design in any chat.
2. Describe the screens or piece, who it's for, and what to compare. Attach a screenshot or a sketch to start from.
3. Send it. The artboards draw on the canvas as the Agent works, several at a time.

Each kind of project gets its own size and layout rules: phone screens come out at phone size, a poster at poster size, an email at email width.

Example:

```text
Two options for a pricing page, side by side.
Three plans, monthly and yearly, with the middle plan highlighted.
```

## Change a design

Ask the Agent for what to change, such as an icon, a color, or a line of text. It changes just that part, and only the artboards it touches redraw.

To change something yourself:

- Select an element and open **Properties** in the side panel to set its layout, fill, border, type, and effects. A design opens with this panel closed; in a narrow window it opens as a sheet over the canvas.
- Use **Tweaks** for the options an artboard offers, and **Outline** for its layers.
- Hold Space, or pick the hand tool, to pan. The pencil and pen draw on the canvas.
- Select an element and use **Export** to save it as **Export PNG** or **Export JPEG**.

To share the canvas with people or your Team, or go back to an earlier version, see [Artifacts](/features/artifacts).

## Use a design system

A design system gives a canvas, or a deck, your exact colors, type styles, fonts, and components.

- **Import one**: ask the Agent to turn a folder of your code, a tokens file, or an npm package into a design system. It keeps the exact values and real components, then runs a check that says what the system still lacks.
- **Switch the look**: open the **Theme** tab in the side panel and pick a system. The canvas switches to its colors and text styles.
- **Keep it current**: when the system has changed since the design used it, the **Theme** tab says it is behind its source. Click **Sync** to bring the changes in.

Decks use design systems from their own **Design system** menu. See [Slides](/features/slides#use-a-design-system).

## Import a design project

Click **Import** in the **Artifacts** library and choose a design's project folder, zipped. Uploads kept in the folder's `assets/` or `_blobs/` come in with it.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A font looks different on some artboards | The font shows only on artboards that load it; ask the Agent to load it |
| The **Theme** tab has no system | Ask the Agent to add or import one |
| A system says its source can't be found | The folder or package it came from moved; import it again |
| Export fails with "hasn't finished drawing the export" | Update Enconvo, then export again |

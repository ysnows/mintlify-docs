App Sidebar opens an Enconvo conversation beside an app window. It uses that app's context, so you can read, write, or work without copying information into a separate chat. Reach for it when your question is about the app in front of you.

For other jobs, use [SmartBar](/features/smartbar) for a quick question or command, the [Chat Window](/ai/chat) when you need more room for history and files, [PopBar](/features/popbar) to act on selected text, or the [Dynamic Island](/features/dynamic-island) and [Desktop Pet](/features/pet) for a small entry point that stays on screen. [Window Management](/features/window-management) compares them all.

The video below shows App Sidebar in 2.5.13: open it beside Chrome with **⌃⌘E**, set how it works on a site, list a video's key moments and jump to one, then compress photos selected in Finder.

## Open the sidebar

1. Bring the app you want help with to the front.
2. Press **⌃⌘E**, run **Show App Sidebar** from Enconvo, or click the handle beside the app window.
3. Ask a specific question, and check the attached context before you send.

The hotkey is set in **Settings → App Sidebar**. Earlier versions used **⇧⌘T**; if you never changed it, Enconvo moved it to **⌃⌘E**. See [Keyboard Shortcuts](/configuration/keyboard-shortcuts) to change it.

## What the sidebar can see

What the sidebar gets depends on the app and on the permissions you've granted:

- A browser can provide the page title, URL, and content.
- Finder can provide the selected files.
- Other apps may provide selected text, accessible window content, or a screenshot.

A code editor doesn't necessarily expose the whole project or every open file. When the context is incomplete, add [Appshots](/features/appshots) or attach the files yourself.

Try asking “Explain the selected paragraph,” “Help me rewrite this draft more concisely,” or “Describe what is visible in this window.”

### The page card and starters

On a web page, a new sidebar chat opens on a card for the page. A video's card shows its length, whether it has captions, and how many chapters it has. Under the card are starters made for the site. On YouTube they are **Summarize this video**, **List the key moments with timestamps**, and **Show the transcript**. Click one to send it.

In an answer about a video, each time is a link. Click it, and the video jumps to that moment.

### Settings for a site

The card's pill names the site and where its settings come from, such as **YouTube · Built-in**. Click the pill to change how the sidebar works on that site:

| Setting | What it changes |
| --- | --- |
| **Read the page** | Lets the sidebar read the whole page when a question needs it. |
| **Answer in** | **My language**, or **The page's language**. |
| **Summaries** | **Default**, **Chapters with times**, **Short paragraph**, or **Bullet points**. |
| **Instructions** | Your own instructions for answers on this site. |
| **Starters** | The starters shown under the card. Remove one, or type a new one in **Add a starter**. |

Once you change something, the pill shows **Yours**.

### Files in Finder

Select files in Finder, then press **⌃⌘E**. The starters follow what you selected. For images they are **Compress the selected images**, **Convert the selected images to JPEG**, and **Resize the selected images**. Compressing writes new copies with `-compressed` in the name next to the originals, and leaves the originals as they were.

### Per-app and per-site presets

**Settings → Applications** holds a profile for each app the sidebar works with:

| Setting | What it changes |
| --- | --- |
| **Attach Screenshot** | Attaches a screenshot of the app's window to every App Sidebar message. On by default. |
| **Attach Full App State** | Attaches the full accessibility state instead of the compact summary. Uses many more tokens. |
| **Skills**, **MCP Servers**, **Plugins** | Preset for this app and offered to the Agent when the app hosts an App Sidebar conversation. |

**Settings → Websites** holds the same presets for websites, used when the browser is on a matching page.

## Chat and act in the app

Continue a conversation, start a new one, or use the window controls to keep the sidebar nearby. App context gives the Agent information to read. To click or type in the app for you, the Agent needs [Computer Use](/features/computer-use) or [Browser Use](/features/browser-control) tools.

## Settings

Open **Settings → App Sidebar**.

| Setting | What it changes |
| --- | --- |
| **Enable App Sidebar** | Shows the handle beside app windows and turns on the hotkey. When it's off, both are gone. |
| **Default Agent** | The Agent that answers in the sidebar. |
| **Hide for all apps** | Hides the sidebar's handle in every app. |
| **Hide App Side Bar Handle when the below application is at front** | Apps where the handle stays hidden. |
| **Hotkey** | Opens the sidebar for the app in front. The default is **⌃⌘E**. |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The sidebar doesn't attach to the app | Bring the app window to the front and open the sidebar again. |
| Text from the app is missing | Check Accessibility in [Permissions](/configuration/permissions), the apps that hide the handle, and the attached context. |
| You need more room for history or files | Continue in the [Chat Window](/ai/chat). |

title: "App Sidebar"
description: "Work with an assistant alongside the application or website you are using."
---

App Sidebar places an Enconvo conversation alongside an app window. It uses the available app context to help you read, write, or work without repeatedly copying information into a separate chat.

## Open and configure

1. Focus the app you want help with.
2. Run **Show App Sidebar** from Enconvo, or use its assigned shortcut.
3. Where enabled, click the side hint on the app window to open the sidebar.
4. Ask a specific question and review the attached context before submitting.

Open **Settings → App Sidebar** for sidebar behavior. **Applications** and **Websites** configure app- and site-specific destinations. Check [Shortcut settings](/configuration/keyboard-shortcuts) for your installed hotkey rather than relying on an older video's defaults.

## What context is available

Browser integrations can provide a page title, URL, and content. Finder context can include selected files. Other apps may expose selected text, accessible window content, or a screenshot, depending on permissions and the app itself. A code editor does not necessarily expose a full project or every open file.

Try: “Explain the selected paragraph,” “Help me rewrite this draft more concisely,” or “Describe what is visible in this window.” Add [Appshots](/features/appshots) or explicit files when the available context is incomplete.

## Chat and actions

Continue a conversation, start another one, or use the available window controls to keep the assistant nearby. App context supplies information; interacting with app controls requires the appropriate [Computer Use](/features/computer-use) or [Browser Control](/features/browser-control) tools on the Agent.

## Troubleshooting

If the sidebar does not attach, bring the intended app window forward and reopen it. If text is missing, check Accessibility permission, app exclusions, and the attached context. Use the [Chat Window](/ai/chat) when you need more room for history or files.

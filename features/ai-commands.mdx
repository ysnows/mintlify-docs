An AI Command packages a repeated prompt with its model and settings. Use one for a focused operation such as rewriting a support reply; use an [Agent](/ai/agents) for broader work with tools, or a [Workflow](/workflows/introduction) for a sequence of steps.

## Create a command

1. Open **Settings → AI Commands**, or run **Create AI Command** from SmartBar, and click **New AI Command**.
2. Describe what the command should do in your own words, then click **Draft**. Enconvo writes the title, icon, and instructions, and runs them on an example right away.
3. Paste some of your own text into the sample and click **Try Again** to see the result on real input.
4. To change the behavior, type the change in **Anything to change?**, for example "group them by owner", and click **Redraft**. The changed lines are marked in the instructions, and the sample result runs again.
5. Under **Where to use it**, keep **Add to PopBar** on to get a PopBar button whenever you select text, or click **Add hotkey** and press the keys you want.
6. Click **Save**.

You can still edit the title, the instructions, and the AI model in the editor. Use the global model when you want the command to follow your general model preference.

Example instruction:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Run a command

- **From PopBar:** select text in any app and click the command's button. When the result is ready, click **Paste** to replace the selection.
- **From a hotkey:** select the text and press the command's hotkey. The result opens in SmartBar, where you can paste it.
- **From SmartBar:** search the command's title and run it on the current input.

## Use changing context

Where a field supports variables, use the variable picker to include input text, selected text, the active app, or other context. See [Variables](/workflows/variables). Inspect the expanded context before using a command with private documents.

## Maintain commands

Revisit the command's settings when changing its model, prompt, or shortcut. **More → Reset configuration**, where available, restores defaults after confirmation; read the prompt before resetting a customized command.

If a command is missing, check that it was saved and search its title. If output ignores selected text, review the input/context settings and Accessibility permission.

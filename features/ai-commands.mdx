An AI Command packages a prompt you repeat with its model and settings, so you can run it on any text in one click. Use one for a focused job such as rewriting a support reply. For broader work with tools, use an [Agent](/ai/agents); for a sequence of steps, use a [Workflow](/workflows/introduction).

## Create a command

1. Open **Settings → AI Commands**, or run **Create AI Command** from SmartBar, and click **New AI Command**.
2. Describe what the command should do in your own words, then click **Draft**. Enconvo writes the title, icon, and instructions, and runs them on an example right away.
3. Paste some of your own text into the sample and click **Try Again** to see the result on real input.
4. To change the behavior, type the change in **Anything to change?**, for example "group them by owner", and click **Redraft**. The changed lines are marked in the instructions, and the sample result runs again.
5. Under **Where to use it**, keep **Add to PopBar** on to get a PopBar button whenever you select text, or click **Add hotkey** and press the keys you want.
6. Click **Save**.

Example instruction:

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Run a command

- **From PopBar:** select text in any app and click the command's button. When the result is ready, click **Paste** to replace the selection.
- **From a hotkey:** select the text and press the command's hotkey. The result opens in SmartBar, where you can paste it.
- **From SmartBar:** search for the command's title and run it on the current input.

## Change a command

Open the command in **Settings → AI Commands** to edit its title and instructions. Changes save as you type.

| Setting | What it changes |
| --- | --- |
| **PopBar** | Puts the command on the PopBar, or takes it off. |
| **Hotkey** | Keys that run the command on the text you've selected in any app. |
| **Inline Mode** | Runs without a window and pastes the result over your selection. |
| **Post Action** | What the command does with the answer once it's done, where offered. |
| **AI Model** | Shows whether the command follows the model for all AI Commands or uses one picked for it. Click **Change** to choose. |

A built-in command shows **Customize** instead: it makes your own copy, which you can edit. Your own commands have a **⋯** menu with **Duplicate** and **Delete**. Deleting a command also removes it from the PopBar and frees its hotkey.

## Use changing context

Where a field supports variables, use the variable picker to include the input text, the selected text, the active app, or other context. See [Variables](/workflows/variables). Check the expanded context before you use a command on private documents.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A command is missing | Check that it was saved, then search for its title. |
| The output ignores the selected text | Check the command's input and context settings, and Accessibility in [Permissions](/configuration/permissions). |

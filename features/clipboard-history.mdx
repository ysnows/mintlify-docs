title: "Clipboard History, Bookmarks, and File Search"
description: "Search what you copied, your browser bookmarks, and the files on your Mac from a hotkey or SmartBar."
---

Clipboard History, Search Browser Bookmarks, and Search Files are three quick lists you search as you type. Use Clipboard History to paste something you copied earlier, Bookmark Search to open a saved page in any browser, and File Search to open a file without Finder. Each opens from its own hotkey, or from SmartBar with an alias.

## Open a list

1. Set a hotkey for the list in **Settings → Shortcut**, or on the list's own settings page under **Settings → Plugins**.
2. Press the hotkey. With **Hotkey Opens a Window** on, which is the default, the list opens in a window of its own and SmartBar stays as it is.
3. Type to filter the list, move to an item with the arrow keys, and press Return.

To open a list inside SmartBar instead, set its **Alias**. Type the alias and a space in SmartBar, and the list opens there. SmartBar search shows each list's alias.

You can also `@`-mention a list in a chat, and the Agent searches that list for you.

## Paste from Clipboard History

Clipboard History keeps the text, images, and files you copy. You can pin favorites and filter by links, emails, colors, images, or files.

1. Open Clipboard History.
2. Type a word from what you copied.
3. Press Return to paste the item into the app you were using. Press **⌘C** to copy it instead. With **Return Key** set to copy, **⌘Return** pastes.

When you open the list over one of Enconvo's own windows, Return pastes into that window's message box.

Password managers and Keychain Access are left out by default, and copies that apps mark as concealed or temporary, such as passwords, are never recorded.

## Open a bookmark

Search Browser Bookmarks reads the bookmarks of Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox, and Zen, including Firefox and Zen profiles kept in a folder you chose. A search matches folder names too.

Press Return to open the bookmark in the browser it came from, or **⌘O** to open it in your default browser. **Return Key** swaps the two.

## Find a file

Search Files looks on your whole Mac by default. Use the dropdown in its search field to search one place for this search only, such as **My Folders**, **Home**, or **Downloads**.

Press Return to open the file, or **⌘Return** to show it in Finder. **Return Key** swaps the two.

## Settings

Open **Settings → Plugins**, then **Clipboard History**, **Browser Bookmarks**, or **File Search**.

| Setting | List | What it changes |
| --- | --- | --- |
| **Alias** | All three | The word you type, then a space, in SmartBar to open the list there. |
| **Hotkey Opens a Window** | All three | On: the hotkey opens the list in its own window. Off: the hotkey opens it in SmartBar. On by default. |
| **Return Key** | All three | What Return does. Clipboard History: **Paste into the front app** or **Copy to the clipboard**. Bookmarks: **Open in its browser** or **Open in the default browser**. Files: **Open** or **Show in Finder**. |
| **Record Clipboard History** | Clipboard History | Keeps a history of what you copy. Turning it off keeps the items already saved. |
| **Keep History For** | Clipboard History | How long items stay, from **1 Day** to **Forever**. 3 months by default. Pinned items are never removed. |
| **Ignored Apps** | Clipboard History | Apps whose copies are never recorded, by bundle ID. |
| **Show Folder Names** | Bookmarks | Shows each bookmark's folder. |
| **Turned-off Browsers** | Bookmarks | Browsers whose bookmarks are left out. |
| **Search In** | Files | Where File Search looks when it opens: **This Mac**, **My Folders**, **Home**, **Desktop**, **Documents**, **Downloads**, or **Applications**. |
| **Search Folders** | Files | The folders **My Folders** searches. Desktop, Documents, and Downloads when empty. |
| **Show Hidden Files** | Files | Includes files whose names start with a dot. |
| **Excluded Folders** | Files | Folders whose contents never show up. |

A shortcut or alias you set on the older web versions of these lists carries over.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The hotkey opens SmartBar instead of a window | Turn on **Hotkey Opens a Window** for that list. |
| A copy is missing from Clipboard History | Check **Record Clipboard History** and **Ignored Apps**. Concealed copies, such as passwords, are never recorded. |
| A browser's bookmarks are missing | Check **Turned-off Browsers**. |
| A file doesn't show up | Check **Search In**, **Excluded Folders**, and **Show Hidden Files**. |

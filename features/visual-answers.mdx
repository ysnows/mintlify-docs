---
title: "Visual Answers"
description: "Get a diagram, chart, or interactive widget right in the chat instead of plain text."
---

Ask an Agent to show its answer, and it draws the visual right in the conversation: an SVG diagram, an HTML preview, or an interactive widget you can click and adjust. Use it when a picture, a chart, or a small calculator explains more than paragraphs would. The Agent needs its visual tools to do this.

## Ask for a visual

Say what question the visual should answer:

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

For a chart or a calculator, include the data and its units. A polished visual can still have wrong facts or math, so check them.

## Use and save a visual

1. Wait until the visual finishes drawing, then use any controls it has. Some widgets send a follow-up prompt back to the chat.
2. Point to the finished visual and click **⋯** at its top right.
3. Choose **Copy to clipboard**, or **Download file** and confirm the file name. Visuals drawn with the app's own cards, tables, and charts offer **Download image** instead, which saves a PNG to your Downloads folder.

A saved image captures one moment of the visual; it doesn't keep its interactive controls. After you change a widget's values, **Reset values** in the same menu puts them back.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| You get code instead of a visual | Check the Agent's enabled tools, then ask it to show the result in the conversation |
| A widget looks incomplete | Wait for it to finish, then ask for a simpler version |
| You need an image file, not a chat widget | Use [Image Generation](/ai/image-generation) |

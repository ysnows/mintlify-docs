title: "Transcription"

Use Transcription for media you already have. **Recordings** stores captured meetings; **Live Captioning** stores captioning sessions. These views share the same recording-detail experience but show different sources.

## Import a file

1. Open **Settings → Transcription → Transcription Models** and select a provider.
2. Open **Transcription** and choose **Import File**, or the audio/video import action.
3. Select a supported file and wait for extraction and transcription to finish.
4. Open the item and review the transcript and processing status.
5. Correct important speaker names, terms, and figures before using the result.

You can also run the **Transcribe** command. Its settings include output format, speaker diarization, and transcription provider.

## Outputs and follow-up

Open a saved item's transcript and available summary/chat views. Ask questions about the transcript rather than assuming every detail was recognized correctly. The selected provider and command determine timestamp, structured-output, and diarization support.

For vocabulary and speaker naming, see [Speech Assets](/configuration/speech-assets). For later retrieval with other documents, see [Knowledge Base](/ai/knowledge-base).

## Processing failures

Current builds distinguish transcription failures from “no speech.” Read the error and available diagnostic details. A problem can come from audio extraction, provider file limits, account access, or the service itself; title generation and search indexing can fail separately from transcription.

If the transcript is already saved, check whether the failed stage is only a title or indexing step before importing the same file again. Keep the original media until you have verified the transcript.

See [Speech Recognition](/ai/speech-recognition) for choosing a file-capable provider.

Enconvo gives you several ways in for the same everyday work. Pick one by how much room and context the task needs, and set the shortcuts you'll use most.

## Choose a window

| Window | Use it to | Open it | Guide |
| --- | --- | --- | --- |
| SmartBar | Ask a quick question or run a command | **⇧⌘D** | [SmartBar](/features/smartbar) |
| Chat Window | Hold ongoing conversations with history and files | **⌥⌘D** | [Chat Window](/ai/chat) |
| App Sidebar | Work beside another app | **⌃⌘E**, or the handle beside the app window | [App Sidebar](/features/app-sidebar) |
| PopBar | Act on selected text | Select text | [PopBar](/features/popbar) |
| Dynamic Island | Type a quick request and follow sessions at the top of the screen | Point at the top center of the screen | [Dynamic Island](/features/dynamic-island) |
| Pet | Keep a character on the desktop that shows Agent activity | Click the Pet | [Desktop Pet](/features/pet) |
| Avatar | Talk to an Agent character by voice | See its guide | [Avatar](/features/avatar) |

## Set the shortcuts that open them

Open **Settings → Shortcut**, or the feature's own settings page, and check the assigned combination and activation mode. SmartBar, the Chat Window, and the App Sidebar have default shortcuts. The Dynamic Island and PopBar have none until you set one.

Global shortcuts can conflict with macOS, input methods, and other apps. If a shortcut doesn't open its window, choose a combination nothing else uses. See [Keyboard Shortcuts](/configuration/keyboard-shortcuts).

## Keep a result in view

Use the pin or window controls of the window you're in. To keep SmartBar on top while you go back to another app, run **Pin SmartBar**, or press **⌘P** in SmartBar.

Press Escape or use the window's close control when you're done. Closing a window doesn't delete the conversation.

## Multiple displays

Check the display options in each window's settings, especially **Show on** for the Dynamic Island. After you change your display arrangement, open the window again and check that it's on the screen you expect. The App Sidebar follows the app window it's attached to, and permissions and the app's own window behavior can affect how it attaches.

## Where results appear

Some commands have a **Window Mode** or output setting that decides where the result appears. Voice input can also paste into the app in front, so check where your cursor is before you dictate.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A window doesn't open | Check its shortcut and the active display, and whether it's behind another app. |
| It still doesn't open, or a permission is missing | See [Troubleshooting](/getting-started/troubleshooting). |

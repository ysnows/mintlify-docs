Enconvo offers several surfaces for the same everyday work. Choose one based on how much space and context you need.

| Surface | Best use | Guide |
| --- | --- | --- |
| SmartBar | Launch a command or ask a quick question | [SmartBar](/features/smartbar) |
| Chat Window | Ongoing conversations, history, and files | [Chat](/ai/chat) |
| App Sidebar | Work alongside another application | [App Sidebar](/features/app-sidebar) |
| PopBar | Act on selected text | [PopBar](/features/popbar) |
| Dynamic Island | Compact top-screen input and session status | [Dynamic Island](/features/dynamic-island) |
| Pet | Desktop access and Agent activity | [Desktop Pet](/features/pet) |
| Avatar | An Agent character and voice interaction | [Avatar](/features/avatar) |

## Set activation shortcuts

Open **Settings → General → Shortcut** or the feature's own settings. Review the assigned combination and activation mode. Global shortcuts can conflict with macOS, input methods, and other apps; choose an unused combination if an entry does not open.

## Keep the right result visible

Use the pin or window controls exposed by the active surface. **Pin SmartBar** is also available as a native command. A pinned surface can remain visible while you return to another app. Press Escape or use the surface's close control when finished; closing a window is different from deleting a conversation.

## Multiple displays

Review display-related options in each surface's settings, especially Dynamic Island. After changing display arrangements, reopen the intended surface and confirm that it is on the screen you expect. App Sidebar follows the target app window; permissions and app-specific window behavior can affect attachment.

## Result destinations

Some command settings include a **Window Mode** or output destination. Use the options offered for that command to decide where the result appears. Voice input can also paste into the focused application, so check the input target before dictating.

If a window is missing, check its assigned shortcut, the active display, and whether it is behind another app. See [Troubleshooting](/getting-started/troubleshooting) for permission and launch issues.

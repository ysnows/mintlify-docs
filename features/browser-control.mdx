---
title: "Browser Use"
description: "Let an Agent read and work in your real browser tabs, with the sign-ins your browser already has."
---

Browser Use lets an Agent work in browser tabs that have the Enconvo Companion extension connected. It can read a page, click controls, fill in fields, check the result, and manage tabs, all with the sign-ins your browser already has. Reach for it when a task needs a website you're signed in to.

## Set up

<Steps>
  <Step title="Install the extension">
    Install [Enconvo Companion from the Chrome Web Store](https://chromewebstore.google.com/detail/enconvo-companion/afaklbihknigbnjdkegbnenkheogejkd) in a supported Chromium browser, or click **Install Browser Companion** in **Settings → Browser Use**. For other browsers, use the extension package made for that browser.
  </Step>
  <Step title="Keep both running">
    Keep Enconvo and the browser open.
  </Step>
  <Step title="Check the connection">
    Click the extension's icon. The popup shows **Connected** and the browser's name.
  </Step>
  <Step title="Check access">
    Make sure the Agent you'll use has the browser tools, and approve any website the extension asks about.
  </Step>
  <Step title="Try a read-only task">
    Start with something that changes nothing, such as "Read this page and summarize the main points."
  </Step>
</Steps>

Safari doesn't use the Chromium extension. In Safari, [Computer Use](/features/computer-use) clicks and types on the screen instead, so not every browser can do the same things. See [Browser Extension](/features/browser-extension) for the popup, connected browsers, tab targeting, and website approvals.

## Work in a specific tab

Name the browser and the page in your request:

> In Edge, read the current documentation tab and list the three setup steps. Keep the page open.

The Agent reads the page, picks an element, acts, and checks what changed. Page elements can change after a navigation or a live update. If the Agent loses an element, ask it for a fresh look at the page.

## What it can do

| Area | Examples |
| --- | --- |
| Navigation | Open a URL, go back or forward, reload, wait for a condition |
| Reading | Page state, visible text, attributes, screenshots, selected content |
| Interaction | Click, type, fill, select, press keys, scroll, drag |
| Browser organization | See and manage tabs, windows, and connected sessions |
| Advanced tools | Page evaluation, cookies, storage, history, and browser-specific inspection |

What works depends on the browser, the page, the extension version, and the tools you turned on. Browser pages such as `chrome://` and other restricted content may be out of reach.

<Warning>
Browser Use acts on your real accounts. Say whether a task should only prepare a draft or also submit it.
</Warning>

## Settings

| Setting | Where | What it changes |
| --- | --- | --- |
| **Default Browser** | **Settings → Browser Use**, then **Settings** in the **⋯** menu | The browser tasks use when you don't name one. **Auto (System Default)** follows your Mac's default browser. |
| **Browser Extensions** | **Settings → Browser Use** | Lists the browsers that have the extension, each **Connected** or **Disconnected**. |

You can also name a browser in the task itself.

For developers, the `browser-use/status` Local API route reports the connection state, and **Settings → APIs** lists the installed routes and their schemas.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Not connected | Check that the extension is turned on and Enconvo is running, and look at the popup. The extension connects to Enconvo on this Mac through port 11225. |
| Wrong browser or tab | Name the browser and the page, and ask for a fresh look at the page. |
| A click or fill fails | Look at the page as it is now. A dialog, a navigation, or an embedded frame may have moved the target. |
| The screenshot is blank | Bring the tab to the front and wait for the page to load. |
| The website asks you to sign in | Sign in to the site as usual. Being signed in to the browser doesn't mean every site's session is still valid. |

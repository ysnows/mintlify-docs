---
title: "Dashboards"
description: "Have an Agent turn your data into a page of numbers and charts you keep, check every figure against its row, and keep it up to date."
---

A dashboard is a page of numbers and charts an Agent builds from your data, for figures you track, review, or report on. Every number is tied to the row it came from, so you can check it. Use it when you'll come back to the numbers; for a one-off answer, just ask in the chat.

## Make a dashboard

1. Start a new chat and pick **Dashboard** under the message box, or ask for one in any chat.
2. Attach the data: a CSV, TSV, or JSON file, or click **Open a spreadsheet** in the **Make something** row. You can also point the Agent at a connected service, a file on your Mac, or a web address.
3. Say what to track and how to break it down.

Example:

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

The dashboard opens beside the chat. When the Agent adds filters, each one shows as a menu, a switch, or a box at the top.

## Check a number

1. Click **Check a number** in the dashboard's header.
2. Click any figure.
3. Enconvo shows the row behind it, where it came from, and whether the two match.

To ask about a number, comment on it. Start the comment with `@Enconvo` to get an answer from the Agent.

## See where the data comes from

Click **Sources**. Each set of data shows where it comes from, how many rows it has, and when it last changed. Data that is past due shows **Out of date**. Click **Download CSV** to save a set of data.

## Keep the numbers up to date

A dashboard built from a connected service, a file on your Mac, or a web address can update itself, once you allow it.

1. When the dashboard asks **Keep these numbers up to date?**, check what each source reads, then click **Allow**. You can also click **Allow updates** next to a source in **Sources**.
2. The numbers update on the schedule the Agent set, such as **Every hour**, or **When you refresh**. Click **Refresh** to update them now.
3. To stop, click **Stop updating** next to the source.

When an update fails, the dashboard keeps the last numbers and says why.

<Note>
A source that doesn't say it only reads data runs only when you click **Refresh**. On a shared dashboard, everyone in it sees what the source reads.
</Note>

## Download or move a dashboard

Click **Download** and choose:

| Option | What you get |
| --- | --- |
| **Download PDF** | A PDF of the page |
| **Download image** | A picture of the page |
| **Download HTML** | One HTML file that opens in any browser |
| **Download project (.zip)** | The whole project, to import on another computer |

To bring a project in, click **Import** in the **Artifacts** library and choose the zip. Comments come with it; updates from a connected service need allowing again there.

To share the dashboard with people or your Team, click **Share**. See [Artifacts](/features/artifacts#share-an-artifact). The dashboard also opens in the iPhone and Android apps; see [Artifacts](/features/artifacts#open-artifacts-on-your-phone).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A number and its row don't match | Ask the Agent about it in a comment, or ask it to fix the calculation |
| A source shows **Out of date** | Click **Refresh**, or allow updates for it |
| **Couldn't update the numbers** | Read the reason, fix the source's access, then click **Refresh** |
| The dashboard is empty | Describe the dashboard and its data in a chat |

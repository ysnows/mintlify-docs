Enconvo includes local utility commands alongside its AI generation tools. Find them in SmartBar or under **Settings → Plugins**.

| Command | Use |
| --- | --- |
| Image Compress | Compress one or more images with adjustable quality |
| Video Compress | Reduce a video's file size |
| Audio Compress | Reduce an audio file's size |
| Extract Audio | Save audio from a video |
| Online Video Downloader | Download supported online video or audio from a URL |

## Compress or convert a file

1. Find the command in SmartBar.
2. Supply the file or files as input, using the command's file controls or supported context.
3. Review output quality, destination, and overwrite options in the command's settings.
4. Run the command and open the output to check it.

Keep the original when experimenting with compression. Image Compress supports batch input and either overwrite or a custom output folder; choose the destination deliberately.

## Download media

Give **Online Video Downloader** the supported page URL and review the available audio/video options. Availability depends on the source site and access requirements. Download only content you are authorized to save.

## Troubleshooting

For a failed conversion, check the input format, writable output location, and available disk space. If an online download stops working, inspect the error and update the utility before trying again; websites can change their formats and access rules.

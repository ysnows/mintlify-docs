title: "Media Utilities"
description: "Compress images, video, and audio, save the sound from a video, or download a video from a link."
---

Media Utilities are local commands for everyday media chores: make images, video, or audio files smaller, save the soundtrack of a video, or download a video from a web page. Find them in SmartBar, or under **Settings → Plugins**.

| Command | What it does | Saves to |
| --- | --- | --- |
| **Image Compress** | Compresses one or more images, with adjustable quality | Replaces the original images |
| **Video Compress** | Makes a video file smaller | `~/Downloads` |
| **Audio Compress** | Makes an audio file smaller (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Saves the audio track of a video, or of every video in a folder, as M4A (MP3 when the track can't be copied) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Downloads the video or audio from a link, such as YouTube, TikTok, Instagram, Reddit, X, or Vimeo | `~/Downloads` |

<Warning>
**Image Compress** replaces your original images by default. To keep them, turn off **Overwrite Original Image File** in its settings first; the compressed copies then go to an `enconvo-compressed-images` folder next to the images.
</Warning>

## Compress a file or extract its audio

1. Select the files in Finder, or attach them.
2. Open SmartBar and run the command.
3. Open the output and check it.

Keep the original while you try out compression settings. Each command's settings are under **Settings → Plugins**: **Image Utils** for Image Compress, and **Media Utils** for the others.

| Setting | What it changes |
| --- | --- |
| **Quality** | From 0 to 100; higher keeps more quality and makes a bigger file. 80 by default |
| **Destination Folder Path** | Where the compressed file goes: an absolute path, or a path relative to the file |
| **Overwrite Original … File** | Replaces the original file. On by default for images, off for video and audio |

## Download a video

1. Open the video's page in your browser, or copy its link.
2. Run **Online Video Downloader** from SmartBar. It takes the link from the browser's active tab, or from a link you type.
3. Follow the progress in the Dynamic Island, where you can cancel. When it's done, click **Show in Finder**.

The download is saved to your chat history, and a file you already downloaded is reused instead of fetched again. Whether a site works depends on the site and on what it lets you access. Download only content you're allowed to save.

| Setting | What it changes |
| --- | --- |
| **Output Directory** | Where downloads go. `~/Downloads` by default |
| **Audio Only** | Downloads only the audio |
| **Favorite Resolution** | The resolution to download, from **Best** (the default) down to 144p |
| **Force Convert to Compatible MP4** | Converts the video to an MP4 that plays everywhere. On by default; it takes extra time and CPU |
| **Use Browser Cookies** | Signs in with your browser's cookies, for videos only you can see. Choose the browser in **Browser** |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **No images to compress** | Select the images in Finder or attach them, then run the command again |
| A conversion fails | Check the file's format, that the output folder is writable, and that you have free disk space |
| A private video won't download | Turn on **Use Browser Cookies** and choose the browser you're signed in with |
| Downloads from a site stop working | Read the error and update the plugin before you try again. Websites change their formats and access rules |

Computer Use lets Enconvo operate the apps on your Mac when a task needs more than text. It looks at the app in front, finds the controls it can see, clicks or types into fields, scrolls lists, drags items, chooses files, uses app menus, and waits for the app to respond before the next step.

Use it for desktop tasks such as:

- Filling in a form in a Mac app
- Selecting a file in a file picker
- Moving around a settings window
- Clicking a toolbar button or a menu item
- Working through an app task with several steps
- Reading what's visible in the current window

For websites, Browser Use works inside your own browser through the Enconvo browser extension (Browser Companion). In a browser without the extension, such as Safari, Computer Use clicks and types on the screen instead.

The video tutorial below sets up Computer Use and Browser Use and uses them from start to finish in 5 minutes: turn it on and grant its two permissions, add the browser extension to Chrome, hold the right Option key and ask, watch it work in Safari, in Chrome, and in a Mac app, and hand it a whole task.

## Turn on Computer Use

Computer Use needs two macOS permissions: Accessibility, to click and type, and Screen Recording, to see the screen.

<Steps>
  <Step title="Open the Computer Use settings">
    Open **Settings → Computer Use** and make sure the switch is on.
  </Step>
  <Step title="Check both permissions">
    **Accessibility** and **Screen Recording** should both show **Enabled**.
  </Step>
  <Step title="Grant a missing permission">
    If one shows **Required**, click **Open** beside it, then turn on Enconvo under that permission in **System Settings → Privacy & Security**. Back in Enconvo, click **Refresh**. If the status still doesn't change, quit and reopen Enconvo.
  </Step>
</Steps>

## Add the browser extension

<Steps>
  <Step title="Open the Browser Use settings">
    Open **Settings → Browser Use**. **Browser Extensions** lists the browsers that have the extension, with their connection status.
  </Step>
  <Step title="Install Browser Companion">
    Click **Install Browser Companion**. The extension's page opens in the Chrome Web Store.
  </Step>
  <Step title="Add the extension">
    Click **Add to Chrome**, then **Add extension**. Open the browser's extensions menu and pin the extension so it stays in the toolbar.
  </Step>
  <Step title="Check the connection">
    Back in **Settings → Browser Use**, the browser shows **Connected**. Edge, Arc, and Brave are set up the same way.
  </Step>
</Steps>

See [Browser Extension](/features/browser-extension) for the extension's popup, supported browsers, and troubleshooting.

## Run a task

Ask for the outcome you want, not a list of clicks.

<Steps>
  <Step title="Open the target app">
    Bring the app or window you want Enconvo to work in to the front.
  </Step>
  <Step title="Hold the right Option key and ask">
    Hold the right **Option** key, say what you need, then let go. Name the app and the page, for example: "In Safari, on this page, find the cheapest nonstop flight" or "Open the settings panel and turn off launch at login." You can also type the request to an Agent.
  </Step>
  <Step title="Watch it work">
    A glow marks the window Enconvo is working in, and the Dynamic Island shows each step. You can take over or stop the task at any time.
  </Step>
  <Step title="Confirm sensitive steps">
    For destructive, financial, account, or permission-changing actions, confirm the step before Enconvo goes on.
  </Step>
  <Step title="Get the result">
    Enconvo looks at the app, acts, waits for the result, and keeps going until the task is done or needs your confirmation. When it finishes, it tells you the result.
  </Step>
</Steps>

### In your browser

> "Open the Wikipedia pages for Mount Fuji and Mount Rainier, and tell me which one is taller."

With the extension connected, Browser Use opens its own tabs in a tab group in the background, so the page you're on stays put. While the extension is at work, the browser shows a bar at the top of the page; don't cancel it. When the task is done, the pages it used stay open in their tabs.

## What Computer Use can do

| Action | Examples |
|--------|----------|
| **Inspect app state** | Read the current window, controls, menu items, selected text, and visible fields |
| **Click and double-click** | Click buttons, sidebar rows, toolbar items, menu commands, and coordinates |
| **Type and press keys** | Fill in fields, submit forms, use shortcuts such as **⌘S** |
| **Scroll** | Move through lists, tables, settings panes, or long documents |
| **Drag** | Drag files, rows, sliders, or selection handles when the app supports it |
| **Use file pickers** | Select files and folders in Open and Save dialogs |
| **Wait after actions** | Check the app again after a click, a navigation, or a loading step |

## Examples

| Ask | What Enconvo does |
| --- | --- |
| "In this file picker, select the newest screenshot from my Desktop." | Looks at the file picker, goes to the folder, selects the file, and confirms the dialog. |
| "Open this app's preferences and disable notifications." | Uses the app's menus, finds the setting, turns it off, and checks the result. |
| "In Clock, add Tokyo and London to World Clock." | Finds each city, adds it to the list, and checks that both were added. |
| "Find my résumé and apply to this job posting." | Finds the file, fills in every field of the form, attaches the file, and submits it. Review the form before you let it submit. |
| "Copy the confirmation code from Mail and paste it into the login window." | Reads the visible windows, switches between them, copies the text, and pastes it into the field. |

## Stay safe

<Warning>
Computer Use works with real apps and real data. Check the screen before you let Enconvo submit forms, change account settings, delete files, make purchases, or send messages.
</Warning>

- Keep the target window visible when you can.
- Give a specific goal and any limits.
- Review before Enconvo acts on private or financial pages.
- Stop the task if what's on screen no longer matches what you asked for.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Enconvo can't see an app's controls | Check that Enconvo has the Accessibility permission, then restart Enconvo and the app. Some apps expose fewer controls than others; screenshots and clicks by position can still work. |
| Clicks go to the wrong app | Bring the app to the front before you start. With several windows open, name the app or window in your request. |
| Selecting a file in a file picker fails | Make sure the file exists and the picker accepts that file type. For a file in iCloud or on a network drive, wait for it to finish downloading. |
| A task moves on too quickly | Ask Enconvo to wait for something you can see, such as "wait until the Save button is enabled" or "continue after the table reloads." |

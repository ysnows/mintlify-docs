## Overview

Computer Use lets EnConvo operate native macOS apps when a task needs more than
text generation. It can inspect the active app, find visible controls, click or
type into fields, scroll lists, drag items, choose files, use app menus, and
wait for the app state to change before continuing.

Use Computer Use for desktop workflows such as:

- Filling a form in a native app
- Selecting a file in a macOS file picker
- Navigating a settings window
- Clicking a toolbar button or menu item
- Moving through a multi-step app workflow
- Reading what is visible in the current window

For websites, Browser Use works inside your own browser through the Enconvo
browser extension (Browser Companion). In a browser without the extension, such
as Safari, Computer Use clicks and types on the screen instead.

The video tutorial below sets up Computer Use and Browser Use and uses them from
start to finish in 5 minutes: turn it on and grant its two permissions, add the
browser extension to Chrome, hold the right Option key and ask, watch it work in
Safari, in Chrome, and in a Mac app, and hand it a whole task.

## Turn On Computer Use

Computer Use relies on macOS Accessibility, to click and type, and Screen
Recording, to see the screen.

<Steps>
  <Step title="Open the Computer Use settings">
    Open **Settings → Plugins → Computer Use** and make sure the switch is on.
  </Step>
  <Step title="Check both permissions">
    **Accessibility** and **Screen Recording** should both show **Enabled**.
  </Step>
  <Step title="Grant a missing permission">
    If one is not enabled, open **System Settings → Privacy & Security**, enable
    EnConvo under that permission, then click **Refresh** in the Computer Use
    settings. If the status still does not change, quit and reopen EnConvo.
  </Step>
</Steps>

## Add The Browser Extension

<Steps>
  <Step title="Open the Browser Use settings">
    Open **Settings → Plugins → Browser Use**. Your installed browsers are listed
    with their connection status.
  </Step>
  <Step title="Install Browser Companion">
    Next to a browser that is not connected, click **Install Browser
    Companion**. The extension opens in the browser's extension store, such as
    the Chrome Web Store.
  </Step>
  <Step title="Add the extension">
    Click **Add to Chrome**, then **Add extension**. Open the browser's
    extensions menu and pin the extension so it stays in the toolbar.
  </Step>
  <Step title="Check the connection">
    Back in **Settings → Plugins → Browser Use**, the browser shows
    **Connected**. Edge, Arc, and Brave are set up the same way.
  </Step>
</Steps>

See [Enconvo Browser Extension](/features/browser-extension) for the extension's
popup, supported browsers, and troubleshooting.

## What Computer Use Can Do

| Action | Examples |
|--------|----------|
| **Inspect app state** | Read the current window, controls, menu items, selected text, and visible fields |
| **Click and double-click** | Click buttons, sidebar rows, toolbar items, menu commands, and coordinates |
| **Type and press keys** | Fill inputs, submit forms, use shortcuts like `Cmd + S` |
| **Scroll** | Move through lists, tables, settings panes, or long documents |
| **Drag** | Drag files, rows, sliders, or selection handles when the app supports it |
| **Use file pickers** | Select files and folders in native open/save dialogs |
| **Wait after actions** | Re-check app state after a click, navigation, or loading step |

## Running A Computer Use Task

Ask EnConvo for the outcome you want, not the low-level action list.

<Steps>
  <Step title="Open the target app">
    Bring the app or window you want EnConvo to control to the foreground.
  </Step>
  <Step title="Hold the right Option key and ask">
    Hold the right **Option** key, say what you need, then release the key. Name
    the app and the page, for example: "In Safari, on this page, find the
    cheapest nonstop flight" or "Open the settings panel and turn off launch at
    login." You can also type the request to an Agent.
  </Step>
  <Step title="Watch it work">
    A glow marks the window EnConvo is working in, and the Dynamic Island shows
    each step. You can take over or stop the task at any time.
  </Step>
  <Step title="Review sensitive actions">
    For destructive, financial, account, or permission-changing actions,
    confirm the step before EnConvo continues.
  </Step>
  <Step title="Let EnConvo continue">
    EnConvo will inspect the app, act, wait for the result, and continue until
    the workflow is complete or needs your confirmation. When it finishes, it
    tells you the result.
  </Step>
</Steps>

### In Your Browser

> "Open the Wikipedia pages for Mount Fuji and Mount Rainier, and tell me which
> one is taller."

With the extension connected, Browser Use opens its own tabs in a tab group in
the background, so the page you are on stays put. While the extension is at
work, the browser shows a bar at the top of the page; do not cancel it. When the
task is done, the pages it used stay open in their tabs.

## Examples

### Choose A File In A Native File Picker

> "In this file picker, select the newest screenshot from my Desktop."

EnConvo can inspect the native file picker, navigate folders, select the file,
and confirm the dialog.

### Change A Setting In Another App

> "Open this app's preferences and disable notifications."

EnConvo can use app menus, search visible settings, toggle controls, and verify
the result.

### Add Items In A Mac App

> "In Clock, add Tokyo and London to World Clock."

EnConvo can find each item, add it to the list, and check that both were added.

### Hand It A Whole Task

> "Find my résumé and apply to this job posting."

EnConvo can find the file first, fill in every field of the form, attach the
file, and submit it. Review the form before you let it submit.

### Work Across Multiple Windows

> "Copy the confirmation code from Mail and paste it into the login window."

EnConvo can read visible windows, switch focus, copy text, and paste into the
target field.

## Safety Guidance

<Warning>
Computer Use can interact with real apps and real data. Review the screen before
allowing EnConvo to submit forms, change account settings, delete files, make
purchases, or send messages.
</Warning>

Best practices:

- Keep the target window visible when possible.
- Give specific goals and constraints.
- Avoid asking EnConvo to act on private or financial pages without review.
- Stop the task if the visible app state no longer matches your intent.

## Troubleshooting

<AccordionGroup>
  <Accordion title="EnConvo cannot see app controls">
    Confirm EnConvo has Accessibility permission, then restart EnConvo and the
    target app. Some apps expose fewer controls than others; screenshots and
    coordinate actions may still help.
  </Accordion>
  <Accordion title="Clicks go to the wrong app">
    Bring the target app to the foreground before starting. If multiple windows
    are open, mention the app or window name in your request.
  </Accordion>
  <Accordion title="File picker selection fails">
    Make sure the file exists and the picker allows that file type. If the file
    is in iCloud or a network location, wait for it to finish downloading first.
  </Accordion>
  <Accordion title="A workflow continues too quickly">
    Ask EnConvo to wait for a specific visible result, such as "wait until the
    Save button is enabled" or "continue after the table reloads."
  </Accordion>
</AccordionGroup>

Screen Doodle lets you mark up part of the screen before you ask your Agent about it. Draw arrows, circles, highlights, or notes, then send. The marked-up screenshot is attached to your chat as an image, in the Dynamic Island unless you were just using another Enconvo chat such as the Chat Window.

## Mark up your screen

1. Bring the content you want to ask about to the front.
2. Double right-click to open Screen Doodle, or press the **Hotkey** you set in **Settings → Screen Doodle**.
3. If **Capture Region First** is on, drag to select the region. Otherwise draw directly over the live screen.
4. Pick a tool in the toolbar and mark the area you mean.
5. Click **Send** (the paper plane) or press **⌘↩**.
6. Review the attached image and type a request, such as "What does the highlighted warning mean?"

Screen Doodle has no hotkey until you set one. Double right-click works right away.

### Add a spoken label

Hold the left **Option** key and speak to describe the shape you just drew. Your words appear next to it as text. To have Screen Doodle listen after every shape you draw, turn on **Speak After Each Shape** in the toolbar, and pause to finish each label.

## Settings

Open **Settings → Screen Doodle**.

| Setting | What it does |
| --- | --- |
| **Capture Region First** | Select a region before drawing. Turn it off to draw directly on the live screen. On by default. |
| **Hotkey** | Opens or closes Screen Doodle. Empty by default. |
| **Double Right-Click** | Opens or closes Screen Doodle with a quick double right-click. On by default. |

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The overlay doesn't open | Check the **Hotkey** and **Double Right-Click** in **Settings → Screen Doodle**, and check [macOS permissions](/configuration/permissions). |
| You only need the whole app window | Use [Appshots](/features/appshots) instead. |

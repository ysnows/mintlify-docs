Built-in capabilities are grouped below by the task they support. Availability depends on installed extensions and the app build. Provider implementations are listed separately in the [Provider Capability Catalog](/providers/catalog).

Use SmartBar to find a command by title. Open **Settings → Plugins** to review installed extensions and their command settings. Agent tools may be selected in Agent settings rather than appearing as standalone launcher commands.

## Supporting services

Some extensions provide infrastructure rather than a command you launch directly: local APIs, configuration, credential routing, document parsing, model runtimes, message storage, search indexing, plugin management, and channel delivery. Use the task guide for the feature they support, or [CLI and Local APIs](/advanced/cli-local-api) for integration work.

The Mobile Companion runtime is under development in this workspace. It is not presented here as an available iOS installation flow; use [IM Channels](/integrations/messaging) for documented access through messaging apps.

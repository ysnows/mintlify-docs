Plugins add commands, providers, tools, and API routes to Enconvo. Open **Settings → Plugins → Plugins** to search the catalog and inspect installed plugins.

## Find and configure a plugin

1. Search by the task or plugin name.
2. Open its detail page and review its description, commands, and requirements.
3. Install it if it is not already installed.
4. Configure any required provider credentials or command settings.
5. Run a command from SmartBar, or enable its tools for the Agent that should use it.

The **Installed** strip provides quick access to installed plugins. A plugin's detail page lists commands and their settings. Opening a command's settings from another surface takes you back to that command within its plugin.

## Commands, providers, and tools

A command is an executable action. A provider supplies a capability such as a model or voice. A tool is an action an Agent can call. Installing a plugin does not necessarily choose its provider globally or enable every tool for every Agent.

In SmartBar, use its configured command picker (normally `@`) or search a command's title. The `/` action menu serves a different purpose; it is not a universal plugin-name prefix.

## Update or remove

Use the plugin's available update or uninstall controls and review the confirmation. Check Agents, workflows, and custom commands that depend on it before removal. Resetting a command restores its settings; resetting a shared provider can also affect credentials used by other capabilities. See [Credentials](/configuration/credentials).

## Develop a plugin

Use the TypeScript SDK and CLI described in [Developing Extensions](/extensions/developing). The current CLI groups build, install, schema generation, and publish under `enconvo plugin`. Publishing makes a plugin available outside your local development environment.

Cada fornecedor que utiliza precisa de uma credencial: uma chave de API ou um início de sessão num plano que já paga. Adiciona-a na página de Definições do próprio fornecedor, e o Enconvo guarda-a num perfil de fornecedor que todas as funcionalidades que utilizam esse fornecedor partilham. **Definições → Gestão de credenciais** mostra todas as suas credenciais num só local.

## Adicionar um fornecedor

<Steps>
  <Step title="Abra uma categoria">
    Abra a página de Definições do que quer utilizar, como **Definições → Modelo de IA**, **Definições → Geração de imagens** ou **Definições → Texto para voz**.
  </Step>
  <Step title="Escolha o fornecedor">
    Selecione um fornecedor. Para configurar uma segunda cópia do mesmo, para outra chave ou conta, escolha **Adicionar novo fornecedor**.
  </Step>
  <Step title="Escolha como iniciar sessão">
    Em **Autenticação**, escolha **Chave de API**, ou **Subscrição** quando o fornecedor lhe permite utilizar um plano que paga.
  </Step>
  <Step title="Adicione a credencial">
    Cole a sua chave de API ou conclua o início de sessão do fornecedor.
  </Step>
  <Step title="Teste">
    Clique em **Validar** se a página o mostrar, escolha um modelo e experimente um pedido curto.
  </Step>
</Steps>

Uma chave de API é faturada na conta de API do fornecedor. Uma subscrição utiliza a utilização incluída no seu plano e os respetivos limites. O texto em **Autenticação** indica qual dos dois a página utiliza.

## Perfis partilhados

Um perfil de fornecedor, como **OpenAI 2**, guarda a chave de API do fornecedor e o início de sessão da subscrição, e aparece em todas as categorias que o fornecedor suporta. Mudar o nome do perfil ou eliminá-lo altera-o em todas essas categorias, e não apenas na página em que está.

Cada categoria mantém o seu próprio modelo, voz e definições de geração. No entanto, uma nova chave de API chega a todas as funcionalidades que utilizam o perfil, por isso teste essas funcionalidades depois de a alterar.

O que um fornecedor oferece varia consoante a categoria. Um início de sessão que funciona no chat de IA não significa que a API de voz em tempo real do fornecedor esteja incluída. Quando uma categoria só aceita uma chave de API, a sua página di-lo e indica as categorias em que a subscrição funciona.

## Consultar a utilização de um plano

Um início de sessão de subscrição mostra a sua conta e quanto do seu plano resta. Um valor como **% restante** é a quota que ainda tem disponível. Abra o menu do cartão da conta e escolha **Atualizar utilização** para o atualizar, ou **Voltar a ligar** para iniciar sessão novamente.

Quando o Claude ou o Codex lhe concedeu redefinições de limite gratuitas, o cartão de uma subscrição Claude ou ChatGPT mostra **Redefinições de limite gratuitas**: quantas tem e até quando. Clique em **Usar redefinição** e confirme para repor os seus limites. Se tiver mais do que uma, o cartão lista-as e utiliza a que escolher.

Quando não aparece nenhuma utilização, isso não significa que a sua utilização seja ilimitada.

## Gerir as suas credenciais

Abra **Definições → Gestão de credenciais**. A lista agrupa as credenciais por perfil de fornecedor e mostra depois as **Chaves não utilizadas**: chaves que nenhum fornecedor utiliza.

- Escreva em **Pesquisar fornecedores...** para encontrar um.
- Clique em **Adicionar nova credencial** para criar outra credencial para um serviço à sua escolha.
- Para eliminar uma credencial, passe o cursor sobre ela e clique no ícone do caixote do lixo. Se um Conector de chave de API utilizar essa chave, a confirmação nomeia-o, e **Eliminar e desligar** desliga-o até lhe dar outra chave.
- Clique em **Limpar** no fim da lista para eliminar de uma só vez todas as chaves não utilizadas. O botão mostra quantas são, e a confirmação lista-as primeiro. O Enconvo nunca elimina chaves não utilizadas por conta própria.

Clique numa credencial para adicionar ou alterar a sua chave. **Usado por** lista as funcionalidades que dependem dela, como **Modelo de IA** ou **Texto para voz**; clique numa para abrir essa página de Definições.

As credenciais próprias de um perfil não têm aqui botão de eliminar. Desaparecem quando elimina o fornecedor.

Mais dois grupos aparecem quando os tem: **Outros serviços**, para chaves de serviços para os quais o Enconvo não tem fornecedor, e **Inícios de sessão**, para os inícios de sessão de sites e aplicações que guardou.

## Quando um agente precisa de uma chave

Quando uma tarefa precisa da chave de API de um serviço, o agente mostra um cartão **Ligar** no chat em vez de lhe pedir para colar a chave. A chave vai para a Gestão de credenciais, e não para a conversa, e os chats seguintes utilizam-na sem voltar a pedir.

Para um serviço para o qual o Enconvo não tem fornecedor, o cartão mostra o anfitrião para onde a chave será enviada. A chave é guardada em **Outros serviços**, e o agente só a pode utilizar em pedidos a esse anfitrião.

O agente nunca guarda a chave: nomeia a credencial guardada e, onde um pedido ou comando mostraria a chave, lê-se `[redacted]`.

Numa conversa do telemóvel, o cartão **Ligar** aparece no seu iPhone, e a chave é guardada na Gestão de credenciais no seu Mac. Num chat de mensagens instantâneas, o agente nunca pede uma chave; envia antes uma ligação que abre o chat no Enconvo.

Se, mesmo assim, colar uma chave de API numa mensagem, o Enconvo guarda-a na Gestão de credenciais e substitui-a por `[redacted]` no chat guardado, para que os pedidos seguintes e os seus outros dispositivos não a transportem. Uma nova chave que cole para um serviço que já tem uma substitui a chave guardada.

## Inícios de sessão em sites e aplicações

Quando uma tarefa do navegador chega a uma página de início de sessão, um cartão pede o nome de utilizador e a palavra-passe uma única vez. O Enconvo preenche-os apenas nesse site, e o agente nunca vê a palavra-passe. Os inícios de sessão guardados aparecem em **Inícios de sessão**. Desmarque **Memorizar este início de sessão** para o utilizar apenas nesse início de sessão.

Quando o início de sessão de uma aplicação do Mac precisa de uma palavra-passe, o cartão nomeia a aplicação. O Enconvo escreve o nome de utilizador e a palavra-passe apenas nessa aplicação, e a palavra-passe apenas num campo que oculte o que escreve.

## Endpoints personalizados

Os fornecedores **Compatível com OpenAI** e **Compatível com Anthropic** têm um campo de URL base da API para o seu próprio servidor. Alguns fornecedores incluídos mantêm a definição do endpoint em **Gestão de credenciais**. Para um servidor de modelos noutro computador, consulte [Modelos locais](/pt/ai/local-llm).

Só as janelas do próprio Enconvo podem alterar o destino para onde uma chave guardada é enviada: o endereço de um fornecedor ou credencial, ou a utilização de uma chave guardada por um servidor MCP. Outros programas que utilizam a API local, o telemóvel e os agentes são recusados.

## Como as chaves são guardadas

- Cada chave e início de sessão guardado é cifrado com uma chave que permanece na Keychain deste Mac, pelo que uma cópia da pasta de definições do Enconvo não pode ser lida noutro computador. Se voltar a uma versão mais antiga do Enconvo, introduza as suas chaves novamente.
- Outro programa que peça definições à [API local](/pt/advanced/cli-local-api) do Enconvo recebe `[hidden]` no lugar de cada chave. Um plugin da loja só pode utilizar as suas próprias chaves e a credencial escolhida nas suas definições.
- Só o código que o Enconvo instalou e que não foi alterado pode abrir chaves guardadas. As Definições mostram e verificam as chaves como antes.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| A validação falha | Verifique o perfil selecionado, o método de autenticação, o endpoint e se a sua conta de fornecedor tem acesso. |
| Uma funcionalidade funciona e outra falha | Verifique se a conta suporta essa funcionalidade e esse modelo. A página indica quando uma categoria só aceita uma chave de API. |
| Algo deixou de funcionar depois de alterar uma chave | O perfil é partilhado. Teste as outras categorias que o utilizam. |
| A área de utilização mostra **Voltar a ligar** | O início de sessão expirou. Clique em **Voltar a ligar** e inicie sessão novamente. |

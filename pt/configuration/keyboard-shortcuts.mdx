As janelas e as funcionalidades de voz do Enconvo abrem-se, cada uma, com um atalho de teclado. **Definições → Atalho** lista todos os atalhos que o Enconvo utiliza e o comando que cada um executa, para que possa alterar um ou descobrir o que faz uma combinação de teclas. Os atalhos guardados no seu Mac prevalecem sempre sobre os valores predefinidos neste guia.

Este vídeo aborda os Atalhos e depois as outras definições que adaptam o Enconvo ao seu Mac: Compreensão do contexto, Appshots, Modelos locais, Permissões e Impedir a suspensão.

## Atalhos predefinidos

| Ação | Predefinição |
| --- | --- |
| Mostrar a SmartBar | **⌥Space** |
| Mostrar a Janela de chat | **⌃⌘X** |
| Mostrar a Barra lateral da aplicação | **⌃⌘E** |
| Abrir as Definições, a partir do Enconvo | **⌘,** |
| Iniciar o Ditado | **⌘ direita** |
| Iniciar o Comando de voz | **⌥ direita** |
| Pausar/Retomar o áudio | **⌥P** |

Estas predefinições só se aplicam se nunca definiu uma tecla própria; uma tecla que tenha definido mantém-se como está. A Captura rápida e os Appshots não têm atalho predefinido: defina um nas respetivas páginas de Definições antes de os utilizar.

## Alterar um atalho

1. Abra **Definições → Atalho**. O separador **Principais** reúne as funcionalidades principais, **Outros atalhos** reúne comandos de IA, plugins, definições e comandos que nenhuma outra página mostra, e **Todos** mostra ambos.
2. Escreva em **Filtrar por nome…** para encontrar um comando. Para encontrar o comando por trás de uma combinação de teclas, clique em **Procurar por atalho** e prima-a.
3. Clique no campo do atalho do comando e prima a nova combinação.
4. Se essas teclas já executam outro comando, o campo avisa-o. Escolha **Usar aqui** para mover as teclas para este comando, ou escolha um dos atalhos livres que ele sugere.
5. Mude para outra aplicação e experimente o atalho.

Para libertar as teclas de um atalho, remova-o do comando. Uma mensagem com **Anular** permite-lhe desfazer essa ação.

Um selo **Local** assinala um atalho que só funciona dentro do Enconvo, como Fixar a SmartBar.

## Como premir

Quando grava uma tecla modificadora sozinha, como ⌘ direita, o campo pergunta **Como premir**:

| Opção | O comando é executado quando |
| --- | --- |
| **Manter ou tocar** | Mantém a tecla premida, ou toca nela para alternar |
| **Toque** | Toca na tecla para iniciar e toca novamente para parar |
| **Manter** | Mantém a tecla premida; funciona enquanto a mantém |
| **Toque duplo** | Toca na tecla duas vezes rapidamente |

Duas ou mais teclas modificadoras premidas ao mesmo tempo contam como um único atalho. Cada campo mostra apenas os tipos que o seu comando suporta, e a descrição ao lado indica como essa funcionalidade reage.

## Onde está o atalho de cada funcionalidade

Além da página Atalho, cada funcionalidade tem o seu atalho na sua própria página de Definições:

| Funcionalidade | Página de Definições |
| --- | --- |
| SmartBar | **Definições → SmartBar** |
| Dynamic Island | **Definições → Dynamic Island** |
| PopBar | **Definições → PopBar** |
| Barra lateral da aplicação | **Definições → Barra lateral da aplicação** |
| Ditado | **Definições → Ditado** |
| Comando de voz | **Definições → Comando de voz** |
| Appshots | **Definições → Appshots** |
| Desenho no ecrã | **Definições → Desenho no ecrã** |
| Nota de voz | **Definições → Nota de voz** |
| Captura rápida | **Definições → Captura rápida** |
| Um único comando | As definições desse comando, quando tem um campo **Atalho de teclado** |

## Dentro da SmartBar

Escreva um caractere de ativação na SmartBar para pesquisar um tipo de item:

| Caractere | Abre |
| --- | --- |
| **@** | Comandos |
| **#** | Contexto a adicionar à sua mensagem |
| **$** | Competências |
| **>** | Tarefas recentes |

Altere estes caracteres em **Pesquisar** em **Definições → SmartBar**. O menu de barra reúne ações como a seleção do modelo e do raciocínio.

Para percorrer listas com o teclado, escolha **Atalhos de navegação** em **Definições → SmartBar**: **macOS** utiliza **⌃N** **⌃P** **⌃F** **⌃B**, e **Vim** utiliza **⌃J** **⌃K** **⌃L** **⌃H**.

## Adaptar o Enconvo ao seu Mac

A mesma janela de Definições reúne as outras escolhas que o vídeo percorre:

| Página de Definições | O que faz |
| --- | --- |
| **Compreensão do contexto** | Escolhe o que a SmartBar recolhe da aplicação em que estava: o texto selecionado, a sua seleção do Finder ou a página do seu navegador. **Anexar** adiciona-o assim que a SmartBar abre, e **Sugerir** oferece-o para um clique. Consulte [Compreensão do contexto](/pt/features/context-awareness). |
| **Appshots** | Adiciona a janela que tem à sua frente à conversa com um atalho. Consulte [Appshots](/pt/features/appshots). |
| **Modelos locais** | Mostra a IA em execução neste Mac, a memória e o disco que utiliza e onde cada funcionalidade é executada. Consulte [Modelos locais](/pt/ai/local-llm). |
| **Permissões** | Lista o que o macOS permite ao Enconvo fazer e porquê; **Conceder** corrige uma que falte. Consulte [Permissões do macOS](/pt/configuration/permissions). |
| **Impedir a suspensão** | Impede que este Mac entre em suspensão enquanto está ausente, para que ainda lhe possa aceder a partir do seu iPhone. |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Um atalho só funciona dentro do Enconvo | Verifique se tem um selo **Local**. Se não tiver, verifique a Monitorização de entrada e a Acessibilidade em [Permissões do macOS](/pt/configuration/permissions) e se outra aplicação utiliza as mesmas teclas. |
| Premir um atalho faz outra coisa | Utilize **Procurar por atalho**. Se nenhum comando do Enconvo utilizar as teclas, é outra aplicação ou o macOS que as utiliza. |
| Um atalho com tecla modificadora não dispara | Abra o atalho e verifique **Como premir**: manter, tocar, toque duplo ou teclas premidas em conjunto. |
| Um atalho de um vídeo ou de outro Mac não funciona | Os seus atalhos podem ser diferentes. Consulte o atual em **Definições → Atalho**. |

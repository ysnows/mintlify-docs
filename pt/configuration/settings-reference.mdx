---
title: "Referência das definições"
description: "Cada entrada da barra lateral das Definições, o que controla e o guia que a explica."
---

Cada entrada da barra lateral das Definições do Enconvo, pela ordem da barra lateral, com o guia que a explica. Para abrir as Definições, clique no ícone do Enconvo na barra de menus e escolha **Definições**. Para saltar para uma entrada, escreva o nome dela em **Pesquisar nas definições**, ou escreva uma pergunta e prima Return para perguntar à IA onde está uma definição.

Os guias escrevem os caminhos das Definições com os nomes abaixo, como **Definições → SmartBar**.

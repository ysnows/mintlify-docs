---
title: "Obter conteúdo da Web"
description: "Peça ao seu Agente que leia uma página Web a partir do URL, ou guarde a página numa base de conhecimento."
---

Use Obter conteúdo da Web quando já tem um URL e quer que o Agente leia a página. Todos os Agentes podem ler uma ligação que lhes dê; o serviço que a obtém é escolhido por si. Use a [Pesquisa na Web](/pt/ai/web-search) quando precisar de encontrar primeiro páginas relevantes.

## Escolher um fornecedor

1. Abra **Definições → Obter conteúdo da Web**.
2. Escolha um fornecedor e clique em **Definir como predefinido**.

| Fornecedor | Utilização |
| --- | --- |
| **Local Fetch** | Obtém páginas no seu Mac gratuitamente, com obtenção assistida pelo navegador opcional |
| **Jina AI Link Reader** | Obtém conteúdo legível através da Jina |
| **Firecrawl Link Reader** | Obtém conteúdo através da Firecrawl |
| **DeepSeek** | Lê páginas como Markdown com a sua chave de API da DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Lê páginas como Markdown através do Enconvo Cloud, sem chave de API |
| **Enconvo Cloud Plan** | Usa o serviço de leitura de ligações da Cloud |

## Ler uma página

1. Cole o URL na conversa e faça uma pergunta específica sobre ele.
2. Verifique o conteúdo obtido e a fonte antes de confiar na resposta.

## Páginas protegidas por início de sessão

Com o **Local Fetch**, a **Browser-Assisted Fetching** pode ler uma página através de um navegador da família Chromium que tenha a extensão Enconvo Companion.

| Opção | O que faz |
| --- | --- |
| **Automático** (predefinição) | Reutiliza um separador correspondente que já tenha aberto, totalmente processado e com o seu início de sessão. Usa um separador temporário em segundo plano quando uma obtenção direta falha ou a página precisa de JavaScript. |
| **Desativado** | Apenas HTTP direto |
| **Sempre** | Obtém sempre através do navegador |

Sem um navegador ligado, o Local Fetch faz um pedido HTTP direto. Os outros fornecedores obtêm o URL público e não têm a sessão iniciada do seu navegador. Para páginas interativas, use a [Extensão do navegador](/pt/features/browser-extension) ou a [Utilização do navegador](/pt/features/browser-control).

## Guardar conteúdo da Web

Adicione um URL com **Adicionar → Página Web única** numa [Base de conhecimento](/pt/ai/knowledge-base) quando o quiser encontrar mais tarde. Verifique a página importada e o seu estado de indexação; as páginas Web podem mudar depois de as importar.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| O conteúdo chega vazio | Verifique se a página é legível sem interação adicional, ou use o **Local Fetch** com **Browser-Assisted Fetching**. Ecrãs de início de sessão, pedidos bloqueados, conteúdo carregado dinamicamente e sites não suportados podem impedir a extração. |
| A resposta descreve coisas que não estão na página | Peça ao Agente que mostre o que realmente obteve, em vez de adivinhar o conteúdo em falta. |

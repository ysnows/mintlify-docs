As variáveis preenchem valores que mudam de cada vez, como o texto que escreveu na SmartBar, o texto selecionado noutra app ou a data de hoje. Use-as em prompts e preferências que suportam modelos, para que um Comando de IA, uma instrução de Agent ou um fluxo de trabalho funcione com o que tem à sua frente. Abra **Definições → Variáveis** para ver as variáveis disponíveis.

## Variáveis disponíveis

| Variável | Valor fornecido |
| --- | --- |
| Input Text | Entrada atual da SmartBar |
| Selection Text | Texto selecionado na app atual |
| Latest Clipboard | Conteúdo mais recente da área de transferência |
| Active Application | Informações da app em primeiro plano |
| Active Application Screenshot | Imagem da janela em primeiro plano |
| Active Screen Screenshot | Imagem do ecrã ativo |
| Focused Window Content | Conteúdo extraído da janela em foco |
| Browser Active Tab | URL do separador ativo e conteúdo disponível da página |
| Current Folder | A pasta aberta no Finder |
| Selected Files | Ficheiros selecionados no Finder |
| History Messages | Histórico da conversa atual |
| Now | Data e hora atuais |
| Your Language | O idioma que lê: o seu **Idioma das respostas** ou o idioma do sistema quando está em Automático |
| Opened Applications | Informações das apps em execução |
| Opened Application Names | Nomes das apps em execução |

## Usar uma variável

1. Abra o campo do Comando de IA, da instrução de Agent ou do fluxo de trabalho que quer personalizar.
2. Verifique se o campo suporta variáveis; use o seletor do campo, se tiver um.
3. Insira o valor de que precisa e teste com conteúdo de exemplo inofensivo.
4. Verifique se uma entrada vazia ou uma permissão em falta altera o resultado.

Um prompt de texto pode usar nomes de modelo suportados, como:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

As variáveis que pode usar dependem do comando e do contexto, e nem todos os campos de texto avaliam modelos. As capturas de ecrã e o conteúdo das apps podem exigir permissões do macOS e um modelo que aceite esse tipo de entrada.

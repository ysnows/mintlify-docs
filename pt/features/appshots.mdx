Os Appshots acrescentam como contexto à sua conversa a janela da app em primeiro plano. Use-os quando quiser perguntar sobre algo no ecrã sem o guardar numa base de conhecimento.

## Capturar a janela de uma app

1. Traga para a frente a app sobre a qual quer perguntar.
2. Prima o seu atalho dos Appshots. Os Appshots não têm atalho até definir um em **Atalho de teclado** em **Definições → Appshots**.
3. A janela vai para a SmartBar, a Janela de chat ou a Barra lateral da aplicação, se uma delas estiver aberta em primeiro plano. Caso contrário, vai para a Dynamic Island. Toca um breve som de obturador.
4. Verifique a janela anexada e depois faça uma pergunta específica, como "Explica o erro nesta janela."

## Definições

Abra **Definições → Appshots**.

| Definição | O que faz |
| --- | --- |
| **Ativar Appshots** | Permite que o atalho acrescente a janela da app em primeiro plano. Ativado por predefinição. |
| **Som de captura** | Reproduz um breve som de obturador quando um Appshot é acrescentado. O som confirma a captura; verifique na mesma o anexo antes de enviar. |
| **Atalho de teclado** | O atalho que acrescenta a janela. Nenhum por predefinição. Pode ser um conjunto de teclas modificadoras, como as duas teclas **Opção** em conjunto, ou um atalho normal. |

## Escolher a ferramenta de captura certa

| Objetivo | Usar |
| --- | --- |
| Perguntar sobre a janela da app atual | Appshots |
| Chamar a atenção para uma região antes de perguntar | [Desenho no ecrã](/pt/features/screen-doodle) |
| Guardar o conteúdo da app atual para pesquisar mais tarde | [Captura rápida](/pt/features/quick-capture) |
| Extrair texto de uma imagem | [OCR](/pt/ai/ocr) |

O conteúdo capturado pode ser enviado ao modelo que usa para o pedido. Consulte [Compreensão do contexto](/pt/features/context-awareness) para outras formas de acrescentar contexto.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Não aparece nenhum contexto | Verifique **Definições → Permissões**, em especial Gravação de ecrã e Acessibilidade. |
| É capturada a janela errada | Traga novamente a app pretendida para a frente. Os Appshots capturam a janela de outra app, não as janelas do próprio Enconvo, como as Definições. |
| O atalho não faz nada | Certifique-se de que **Ativar Appshots** está ativo e de que está definido um **Atalho de teclado**. |
| O atalho faz outra coisa | Outra app usa as mesmas teclas. Altere o **Atalho de teclado** em **Definições → Appshots**. |

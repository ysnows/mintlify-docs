O Histórico da área de transferência, a Pesquisa de favoritos do navegador e a Pesquisa de ficheiros são três listas rápidas que pesquisa enquanto escreve. Use o Histórico da área de transferência para colar algo que copiou antes, a Pesquisa de favoritos para abrir uma página guardada em qualquer navegador e a Pesquisa de ficheiros para abrir um ficheiro sem o Finder. Cada uma abre com o seu próprio atalho, ou a partir da SmartBar com um alias.

## Abrir uma lista

1. Defina um atalho para a lista em **Definições → Atalho**, ou na página de definições da própria lista em **Definições → Plugins**.
2. Prima o atalho. Com **O atalho abre uma janela** ativado, que é a predefinição, a lista abre numa janela própria e a SmartBar fica como está.
3. Escreva para filtrar a lista, mova-se para um item com as teclas de seta e prima Return.

Para abrir uma lista dentro da SmartBar, defina o seu **Alias**. Escreva o alias e um espaço na SmartBar e a lista abre aí. A pesquisa da SmartBar mostra o alias de cada lista.

Também pode mencionar uma lista com `@` numa conversa, e o Agente pesquisa essa lista por si.

## Colar a partir do Histórico da área de transferência

O Histórico da área de transferência guarda o texto, as imagens e os ficheiros que copia. Pode afixar favoritos e filtrar por ligações, emails, cores, imagens ou ficheiros.

1. Abra o Histórico da área de transferência.
2. Escreva uma palavra do que copiou.
3. Prima Return para colar o item na aplicação que estava a usar. Prima **⌘C** para o copiar. Com a **Tecla Enter** definida para copiar, **⌘Return** cola.

Quando abre a lista sobre uma das janelas do próprio Enconvo, Return cola na caixa de mensagem dessa janela.

Os gestores de palavras-passe e o Acesso às Chaves ficam de fora por predefinição, e as cópias que as aplicações marcam como ocultas ou temporárias, como palavras-passe, nunca são registadas.

## Abrir um favorito

A Pesquisa de favoritos do navegador lê os favoritos do Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox e Zen, incluindo perfis do Firefox e do Zen guardados numa pasta que escolheu. Uma pesquisa corresponde também a nomes de pastas.

Prima Return para abrir o favorito no navegador de onde veio, ou **⌘O** para o abrir no seu navegador predefinido. A **Tecla Enter** troca os dois.

## Encontrar um ficheiro

A Pesquisa de ficheiros procura por predefinição em todo o seu Mac. Use o menu pendente no seu campo de pesquisa para pesquisar num só local apenas nesta pesquisa, como **Minhas pastas**, **Início** ou **Transferências**.

Prima Return para abrir o ficheiro, ou **⌘Return** para o mostrar no Finder. A **Tecla Enter** troca os dois.

## Definições

Abra **Definições → Plugins** e depois **Histórico da área de transferência**, **Favoritos do navegador** ou **Pesquisa de ficheiros**.

| Definição | Lista | O que altera |
| --- | --- | --- |
| **Alias** | As três | A palavra que escreve, seguida de um espaço, na SmartBar para abrir a lista aí. |
| **O atalho abre uma janela** | As três | Ativado: o atalho abre a lista na sua própria janela. Desativado: o atalho abre-a na SmartBar. Ativado por predefinição. |
| **Tecla Enter** | As três | O que Return faz. Histórico da área de transferência: **Colar na aplicação da frente** ou **Copiar para a área de transferência**. Favoritos: **Abrir no navegador dele** ou **Abrir no navegador predefinido**. Ficheiros: **Abrir** ou **Mostrar no Finder**. |
| **Registar o histórico da área de transferência** | Histórico da área de transferência | Mantém um histórico do que copia. Desativá-lo mantém os itens já guardados. |
| **Manter o histórico durante** | Histórico da área de transferência | Quanto tempo os itens ficam, de **1 dia** a **Para sempre**. 3 meses por predefinição. Os itens afixados nunca são removidos. |
| **Apps ignorados** | Histórico da área de transferência | Aplicações cujas cópias nunca são registadas, por ID do pacote. |
| **Mostrar nomes das pastas** | Favoritos | Mostra a pasta de cada favorito. |
| **Navegadores desativados** | Favoritos | Navegadores cujos favoritos ficam de fora. |
| **Pesquisar em** | Ficheiros | Onde a Pesquisa de ficheiros procura quando abre: **Este Mac**, **Minhas pastas**, **Início**, **Mesa**, **Documentos**, **Transferências** ou **Aplicações**. |
| **Pastas de pesquisa** | Ficheiros | As pastas que **Minhas pastas** pesquisa. Mesa, Documentos e Transferências quando está vazio. |
| **Mostrar ficheiros ocultos** | Ficheiros | Inclui ficheiros cujos nomes começam por um ponto. |
| **Pastas excluídas** | Ficheiros | Pastas cujo conteúdo nunca aparece. |

Um atalho ou alias que tenha definido nas versões web mais antigas destas listas mantém-se.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| O atalho abre a SmartBar em vez de uma janela | Ative **O atalho abre uma janela** para essa lista. |
| Falta uma cópia no Histórico da área de transferência | Verifique **Registar o histórico da área de transferência** e **Apps ignorados**. As cópias ocultas, como palavras-passe, nunca são registadas. |
| Faltam os favoritos de um navegador | Verifique **Navegadores desativados**. |
| Um ficheiro não aparece | Verifique **Pesquisar em**, **Pastas excluídas** e **Mostrar ficheiros ocultos**. |

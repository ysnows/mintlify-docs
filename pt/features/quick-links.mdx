Os Links rápidos transformam uma pesquisa na Web, um endereço Web, um ficheiro ou pasta, ou o deeplink de uma aplicação num comando que executa a partir da SmartBar. Os marcadores preenchem o link com o que escreve, a área de transferência, o texto selecionado ou a data. O Enconvo já traz prontas para usar as pesquisas no Google, no YouTube e no X.

Os Links rápidos abrem um destino. A [Pesquisa na Web](/pt/ai/web-search) traz, em vez disso, resultados de pesquisa para uma resposta de IA, e a [Utilização do navegador](/pt/features/browser-control) permite que um Agente trabalhe em páginas Web.

## Pesquisar na Web a partir da SmartBar

1. Abra a SmartBar e encontre **Google Search in Browser**, **YouTube Search in Browser** ou **Twitter/X Search in Browser**.
2. Escreva o texto da pesquisa como entrada do comando. O texto selecionado também funciona.
3. Execute o comando. A pesquisa abre-se no seu navegador predefinido.

## Criar um link rápido

1. Execute **Criar link rápido** a partir da SmartBar.
2. Introduza um **Nome**, como Pesquisar no GitHub.
3. Introduza o **Link**: um endereço Web, um caminho de ficheiro ou pasta, ou um deeplink. Clique em **Inserir marcador** para adicionar um, como `https://github.com/search?q={argument}`.
4. Para o abrir numa aplicação em particular, introduza em **Abrir com** o nome de uma aplicação, como Safari, um caminho de aplicação ou um identificador de pacote. Deixe vazio para usar a aplicação predefinida.
5. Clique em **Guardar**. Procure o nome do link rápido na SmartBar para o executar.

Quando executa um link rápido, o texto que escreveu ou selecionou preenche o seu primeiro argumento. Se um argumento obrigatório continuar vazio, o Enconvo pede-o antes de abrir o link.

| Marcador | Preenchido com |
| --- | --- |
| `{argument name="Query"}` | Um valor que escreve quando o link rápido se abre |
| `{clipboard}` | O texto da área de transferência |
| `{selection}` | O texto selecionado na aplicação que está a usar |
| `{date}`, `{time}`, `{datetime}` | A data atual, a hora atual ou ambas |
| `{date format="yyyy-MM-dd"}` | A data no formato que indicar |
| `{uuid}` | Um novo ID único |

Teste um link novo primeiro com texto normal, incluindo espaços e pontuação.

## Gerir os seus links rápidos

Execute **Search Quicklinks** a partir da SmartBar para ver todos os links rápidos. A partir daí pode abrir, editar, duplicar ou eliminar um, e clicar em **Novo** para adicionar outro.

O menu **Mais** tem **Importar links rápidos…**, que lê exportações de links rápidos e de definições do Raycast, e **Exportar para Transferências**. Uma exportação de definições do Raycast pede a frase-passe que escolheu ao exportar.

## Definições

Abra **Definições → Plugins → Links rápidos**. Cada comando de pesquisa também tem o seu próprio **Link**, como `https://www.google.com/search?q={query}`, que pode alterar.

| Definição | O que altera |
| --- | --- |
| **Abrir em nova janela** | Abre os links rápidos Web numa nova janela do navegador. Funciona com Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox e Zen; o Safari, o Arc e o Orion abrem o link normalmente. Desativado por predefinição |
| **When There's No Selected Text** | O que faz um link com `{selection}` quando nada está selecionado: **Ask for it** (a predefinição) ou **Use the clipboard** |
| **Confirm Before Deleting** | Pergunta antes de eliminar um link rápido. Ativado por predefinição |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Abre-se a página errada | Verifique o **Link** do link rápido e os respetivos marcadores e depois experimente com texto simples |
| O navegador não abre | Verifique o seu navegador predefinido, o **Abrir com** do link rápido e se o comando está instalado |
| Um link com `{selection}` pede texto | Nada estava selecionado. Selecione primeiro o texto, ou defina **When There's No Selected Text** como **Use the clipboard** |

Peça a um Agente que mostre a sua resposta e ele desenha o elemento visual diretamente na conversa: um diagrama SVG, uma pré-visualização HTML ou um widget interativo em que pode clicar e ajustar. Use-o quando uma imagem, um gráfico ou uma pequena calculadora explicarem mais do que parágrafos. Para isso, o Agente precisa das suas ferramentas visuais.

Uma resposta visual vive na conversa. Quando quiser algo para guardar, editar, apresentar ou partilhar, como uma apresentação, um painel, um design ou um documento, peça antes um [artefacto](/pt/features/artifacts).

## Pedir um elemento visual

Diga a que pergunta o elemento visual deve responder:

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

Para um gráfico ou uma calculadora, inclua os dados e as respetivas unidades. Um elemento visual bem acabado pode, ainda assim, ter factos ou cálculos errados, por isso verifique-os.

## Ligações, mapas e gráficos nas respostas

Algumas respostas tornam-se visuais sem que o peça:

- As **ligações** aparecem como cartões com o ícone do site.
- Os **locais** aparecem num mapa real com o nome do local. Vários locais partilham um mapa numerado, e um percurso mostra o seu traçado com a duração e a distância.
- Os **gráficos** que o Agente cria têm as cores verificadas, para que cada série se mantenha distinta com daltonismo e nas aparências clara e escura. Os números, as datas e as palavras de estado aparecem no seu idioma.

## Usar e guardar um elemento visual

1. Aguarde até o elemento visual terminar de ser desenhado e depois use os controlos que tiver. Alguns widgets enviam um prompt de seguimento de volta à conversa.
2. Aponte para o elemento visual concluído e clique em **⋯** no canto superior direito.
3. Escolha **Copiar para a área de transferência**, ou **Descarregar ficheiro** e confirme o nome do ficheiro. Os elementos visuais desenhados com os cartões, as tabelas e os gráficos da própria aplicação oferecem antes **Descarregar imagem**, que guarda um PNG na sua pasta Transferências.

Uma imagem guardada captura um momento do elemento visual; não mantém os seus controlos interativos. Depois de alterar os valores de um widget, **Repor valores** no mesmo menu volta a colocá-los como estavam.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Obtém código em vez de um elemento visual | Verifique as ferramentas ativadas do Agente e peça-lhe que mostre o resultado na conversa |
| Um widget parece incompleto | Aguarde que termine e depois peça uma versão mais simples |
| Precisa de um ficheiro de imagem, não de um widget de conversa | Use a [Geração de imagens](/pt/ai/image-generation) |
| Quer manter o gráfico e voltar a ele | Peça um [Painel](/pt/features/dashboards) |

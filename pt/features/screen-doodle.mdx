O Desenho no ecrã permite-lhe marcar parte do ecrã antes de perguntar ao seu Agente sobre ela. Desenhe setas, círculos, realces ou notas e depois envie. A captura de ecrã marcada é anexada à sua conversa como imagem, na Dynamic Island, a menos que estivesse a usar outra conversa do Enconvo, como a Janela de chat.

## Marcar o seu ecrã

1. Traga para a frente o conteúdo sobre o qual quer perguntar.
2. Clique duas vezes com o botão direito para abrir o Desenho no ecrã, ou prima o **Atalho de teclado** que definiu em **Definições → Desenho no ecrã**.
3. Se **Primeiro, captura uma área** estiver ativo, arraste para selecionar a região. Caso contrário, desenhe diretamente sobre o ecrã em direto.
4. Escolha uma ferramenta na barra de ferramentas e marque a zona a que se refere.
5. Clique em **Enviar** (o avião de papel) ou prima **⌘↩**.
6. Reveja a imagem anexada e escreva um pedido, como "O que significa o aviso realçado?"

O Desenho no ecrã não tem atalho até definir um. O duplo clique com o botão direito funciona de imediato.

### Acrescentar uma etiqueta falada

Mantenha premida a tecla **Opção** esquerda e fale para descrever a forma que acabou de desenhar. As suas palavras aparecem ao lado dela como texto. Para que o Desenho no ecrã ouça depois de cada forma que desenha, ative **Falar após cada forma** na barra de ferramentas e faça uma pausa para terminar cada etiqueta.

## Ferramentas

| Ferramenta ou ação | Tecla |
| --- | --- |
| Seta | **A** |
| Linha | **L** |
| Caneta | **P** |
| Marcador de texto | **H** |
| Retângulo | **R** |
| Círculo | **O** |
| Contador (marcadores numerados) | **N** |
| Texto | **T** |
| Selecionar | **V** |
| Borracha | **E** |
| Cor | **C** |
| Espessura da linha | **⌘** + deslocar |
| Quadro branco | **B** |
| Realce do cursor | **K** |
| Guardar como… | **⌘S** |
| Enviar | **⌘↩** |

A barra de ferramentas também tem **Anular**, **Refazer**, **Limpar**, **Copiar para a área de transferência** e **Fechar**.

## Definições

Abra **Definições → Desenho no ecrã**.

| Definição | O que faz |
| --- | --- |
| **Primeiro, captura uma área** | Selecione uma região antes de desenhar. Desative para desenhar diretamente no ecrã em direto. Ativado por predefinição. |
| **Atalho de teclado** | Abre ou fecha o Desenho no ecrã. Vazio por predefinição. |
| **Duplo clique com o botão direito** | Abre ou fecha o Desenho no ecrã com um duplo clique rápido com o botão direito. Ativado por predefinição. |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| A sobreposição não abre | Verifique o **Atalho de teclado** e o **Duplo clique com o botão direito** em **Definições → Desenho no ecrã** e consulte as [permissões do macOS](/pt/configuration/permissions). |
| Só precisa da janela inteira da app | Use antes os [Appshots](/pt/features/appshots). |

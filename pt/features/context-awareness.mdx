---
title: "Compreensão do contexto"
description: "Escolha o que a SmartBar capta da app que estava a usar e acrescente mais contexto com #."
---

O contexto é o que acompanha a sua pergunta: o texto que selecionou, os ficheiros selecionados no Finder, a página aberta no navegador ou uma captura de ecrã. A SmartBar pode captar parte dele ao abrir, e pode acrescentar mais escrevendo `#`. O Agente responde então sobre o que está a ver, sem que tenha de o explicar.

## Escolher o que a SmartBar capta

1. Abra **Definições → Compreensão do contexto**.
2. Em **Ao abrir a Smart Bar**, defina cada fonte como **Anexar**, **Sugerir** ou **Desativado**.
3. Mude para outra app, selecione algo e abra a SmartBar para ver o resultado.

| Fonte | O que acrescenta | Predefinição |
| --- | --- | --- |
| **Texto selecionado** | Texto selecionado na app que estava a usar | **Anexar** |
| **Seleção do Finder** | Ficheiros e pastas selecionados no Finder | **Sugerir** |
| **Página atual do navegador** | A página aberta no Safari, Chrome, Arc, Edge ou outro navegador Chromium | **Sugerir** |

**Anexar** acrescenta a fonte à entrada assim que a SmartBar abre. **Sugerir** lista-a acima dos comandos, para a acrescentar com um clique. **Desativado** deixa-a de fora.

Só a SmartBar usa estas definições. Os comandos que executa sobre uma seleção recebem sempre o texto selecionado. Na primeira vez que acrescenta contexto do Finder ou do navegador, o macOS pergunta se o Enconvo pode controlar essa app.

## Acrescentar contexto com #

1. Na SmartBar, escreva `#`.
2. Escreva uma palavra para reduzir a lista, como `#screen`, `#finder`, `#clipboard` ou `#browser`.
3. Escolha uma fonte. É acrescentada à sua mensagem.
4. Escreva a sua pergunta e envie-a.

| Fonte | O que acrescenta |
| --- | --- |
| **Selected Text** | O texto selecionado na janela atual |
| **Clipboard Text** | O texto na área de transferência |
| **Current Application Content** | O texto da app em primeiro plano |
| **Current Application Screenshot** | Uma captura de ecrã da app em primeiro plano |
| **Current Screen Screenshot** | Uma captura de ecrã de todo o ecrã |
| **Live Screen Screenshot** | Uma captura de ecrã sem as janelas do Enconvo |
| **User Select Area Screenshot** | Uma captura de ecrã de uma região que selecionar |
| **Finder Selected Items** | Os ficheiros e pastas selecionados no Finder |
| **Finder Current Directory URL** | A pasta aberta no Finder |
| **Browser Current Tab URL** | O endereço do separador atual do navegador |

As suas janelas abertas também são listadas, para poder acrescentar uma janela de outra app. Para usar um carácter diferente de `#`, altere **Contexto** em **Pesquisar** em **Definições → SmartBar**.

## O que perguntar

Com a página do navegador anexada, peça ao Enconvo que resuma a página, a traduza ou extraia as informações principais. Com ficheiros do Finder anexados, peça-lhe que descreva os ficheiros, sugira como organizá-los, ajude a mudar nomes em lote ou analise o conteúdo.

<Note>
O contexto que anexa vai para o modelo que responde, ou para o fornecedor que o processa. Reveja o que está anexado e as definições do seu fornecedor antes de trabalhar com conteúdo sensível.
</Note>

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| O texto selecionado não é anexado | Verifique se **Texto selecionado** está definido como **Anexar** e consulte [Permissões](/pt/configuration/permissions). |
| Falta o contexto do Finder ou do navegador | Permita que o Enconvo controle essa app quando o macOS pedir. Se recusou, permita-o em [Permissões](/pt/configuration/permissions). |
| Escrever `#` não abre a lista | Verifique o carácter de **Contexto** em **Definições → SmartBar**. |

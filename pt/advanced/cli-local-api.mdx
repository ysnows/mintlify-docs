Esta página destina-se a programadores e utilizadores avançados que querem controlar o Enconvo a partir do Terminal, de um script ou de outra app. O comando `enconvo` vem com a app Enconvo para computador, sem instalação separada, e a app disponibiliza as rotas de todos os plugins instalados através de uma API HTTP local.

Este vídeo aborda a página de APIs, o Guia da CLI e os Ganchos.

Mantenha o Enconvo em execução para os comandos que usam o seu runtime local.

## Encontrar comandos

```bash
enconvo -h
enconvo knowledge_base -h
```

Acrescente `-h` ao comando que está a investigar para ver os seus subcomandos e opções atuais.

Abra **Definições → Guia da CLI** para ver as extensões instaladas que expõem comandos da CLI. Clique num nome para copiar o respetivo comando `enconvo <name> -h`. A lista de extensões instaladas é a referência para o que a sua app suporta.

Se a sua shell não encontrar o `enconvo`, abra o Guia da CLI da app e verifique a versão da app instalada e a configuração da linha de comandos.

## Chamar a Local API

A app disponibiliza cada rota em `http://localhost:54535/api/<extension>/<route>`. Envie um `POST` com um corpo JSON:

```bash
curl -X POST http://localhost:54535/api/enconvo/extension/available_list \
  -H "Content-Type: application/json" \
  -d '{}'
```

Abra **Definições → APIs** e clique em **Verificar as API** para inspecionar as rotas disponíveis e os esquemas de pedido, com um exemplo para cada uma. Use o esquema da sua versão instalada ao escrever uma integração; os parâmetros das rotas podem mudar à medida que as extensões evoluem.

## Executar um Agente ou Comando de IA fora do Enconvo

As definições de cada Agente e de cada Comando de IA têm uma linha **Link, CLI e API**. Mostra o link, o comando `enconvo` e a chamada da API local que o executam com o seu texto e ficheiros, prontos a copiar.

| Forma | O que faz |
| --- | --- |
| Link | Abre uma nova conversa e executa aí o Agente ou o Comando de IA |
| CLI | Executa-o em segundo plano e mostra a resposta |
| Local API | Executa-o em segundo plano e devolve a resposta |

Um link tem esta forma:

```text
enconvo://<extension>/<command>?input_text=<text>&window=<window>&files=<path>
```

- `input_text` é o texto a enviar.
- `window` é `chat_window` ou `dynamic_island`. Omita-o para executar na SmartBar.
- `files` anexa o ficheiro no caminho absoluto ou `~/` indicado. Repita-o para vários ficheiros, por exemplo para enviar imagens de outra app ou script.

A partir do Terminal:

```bash
enconvo agent call "What's on my calendar today?"
enconvo ai-command run 'writing_package|translate' --input-text "Bonjour" --files ~/Desktop/note.png
enconvo writing_package convert_to_list "eggs, milk, bread"
```

Os comandos de escrita, como Traduzir, Resumir e Converter em lista, recebem o texto como argumento e respondem sem acrescentar uma conversa ao seu histórico. O `enconvo agent main` responde numa nova conversa quando o agente está ocupado na mais recente.

As rotas da API local correspondentes são `agent/call` (`agentId`, `message`, `context_files`) e `ai-command/run` (`command_key`, `input_text`, `files`).

### Consultar as conversas em curso

- `agent/session/list` lista as conversas em curso neste momento em todos os agentes e Projetos, incluindo as do Claude Code e do Codex, com o título, o agente e o Projeto de cada uma. Passe `filter: "waiting"` para as conversas à espera da sua resposta, ou `"active"` para ambas.
- `agent/session/status` verifica uma conversa pelo seu `sessionId`.
- `agent/session/steer` acrescenta uma mensagem ao turno que uma conversa está a executar, sem a parar. Uma conversa que não está em execução responde `not_running`; inicie antes um novo turno com `agent/call`. Uma execução abaixo de Acesso total não pode orientar um turno do Enconvo.

## Use-o em segurança

Para um cliente de IA que só precisa de obter dados da base de conhecimento, use a ligação dedicada [Knowledge Base MCP](/pt/advanced/knowledge-base-mcp) em vez de expor a API local geral.

Trate o acesso à API local e à shell como capacidades poderosas: os comandos podem ler ou modificar dados locais de acordo com a sua implementação. Mantenha os scripts explícitos quanto ao comando, à entrada e ao destino.

As chaves de API guardadas voltam como `[hidden]` quando um programa lê as definições através da API local, e só as janelas do próprio Enconvo podem alterar o destino para onde uma chave guardada é enviada. Consulte [Credenciais](/pt/configuration/credentials).

Um atalho de teclado definido através da API local pode usar nomes curtos de modificadores (`cmd`, `ctrl`, `alt`, `opt`, `fn`) ou os símbolos dos modificadores. Um atalho com uma palavra que o Enconvo não conhece não é registado, e uma tecla que escreve precisa de Command, Control, Option ou Function.

## Construir sobre ele

- [Developing Extensions](/pt/extensions/developing): acrescente os seus próprios comandos e rotas. Um ficheiro em `src/api/` de um plugin torna-se uma rota aqui.
- [Extension API Reference](/extensions/extension-api-reference): os pontos de entrada do SDK.
- [Ganchos](/pt/configuration/hooks): execute os seus próprios comandos em pontos definidos do trabalho de um Agente. Vêm da sua configuração JSON, e **Definições → Ganchos** lista os que estão carregados.
- [Tarefas agendadas](/pt/workflows/scheduled-jobs): execute trabalho à hora escolhida.
- [Configurar o Enconvo num servidor Linux](/pt/advanced/linux-server): defina os modelos, agentes e plugins de um servidor que o seu Mac adicionou, com o mesmo comando `enconvo`.

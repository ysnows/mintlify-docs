O Enconvo Cloud oferece-lhe modelos de várias empresas, além de ferramentas de voz, imagem, vídeo e Web, através da sua conta Enconvo. Não há chaves de API para gerir: os pedidos utilizam os pontos do seu plano. É a forma mais rápida de começar.

## Configurar

<Steps>
  <Step title="Inicie sessão">
    Inicie sessão na sua conta Enconvo. Consulte [Conta](/pt/configuration/account).
  </Step>
  <Step title="Escolha o Enconvo Cloud">
    Abra a página de Definições do que quer fazer, como **Modelo de IA**, **Texto para voz** ou **Geração de imagens**, e escolha o fornecedor com a etiqueta **Enconvo Cloud** ou **Enconvo Cloud Plan**.
  </Step>
  <Step title="Escolha um modelo ou uma voz">
    Escolha um modelo ou uma voz e execute um pedido curto.
  </Step>
</Steps>

Cada funcionalidade tem a sua própria escolha de fornecedor. Escolher o Enconvo Cloud para o chat não muda a voz, as imagens, o vídeo, os embeddings, a reordenação nem as ferramentas Web; defina cada um onde quiser.

## Os modelos do próprio Enconvo

O Enconvo Cloud tem três modelos próprios, com nomes que indicam o trabalho a que se adequam:

| Modelo | Utilize-o para |
| --- | --- |
| **Enconvo Fast** | Interações rápidas: respostas curtas, reescritas, pequenas ações. É o modelo em que o **Enconvo Cloud Plan** começa e o predefinido para os Comandos de IA. |
| **Enconvo Balanced** | Trabalho do dia a dia com alguns passos. |
| **Enconvo Ultra** | Tarefas difíceis que exigem raciocínio profundo. |

Estão listados primeiro em **Enconvo Cloud Plan**, e a [Rota automática](/pt/providers/auto-route) utiliza-os nas suas rotas predefinidas.

## Encontrar um modelo no seletor

A lista do **Enconvo Cloud Plan** agrupa os modelos por fabricante: primeiro os modelos do próprio Enconvo, depois a Anthropic, a OpenAI, a Google e os restantes, cada um com uma contagem. Um fabricante mostra os seus quatro modelos mais recentes; clique em **Mostrar N modelos anteriores** para ver os outros. A pesquisa lista todas as correspondências, e o modelo que o seu chat utiliza aparece sempre. Os modelos Claude são listados sem o prefixo "Claude", como **Sonnet 5.5** e **Opus 5.5**.

No seletor de modelos da Janela de chat, um modelo Cloud pode ter uma etiqueta:

| Etiqueta | Significado |
| --- | --- |
| **Novo** | Adicionado nos últimos 14 dias. |
| Um desconto, como **50% de desconto** | O modelo custa menos por agora. Aponte para a linha, ou chegue a ela com as teclas de seta, para ver o preço normal. |
| **Gratuito** | O modelo não utiliza pontos. |
| **Pré-visualização** | Uma versão antecipada do modelo. |
| Uma data | O dia em que o modelo sai do Enconvo Cloud. |

O Enconvo Cloud define as etiquetas, pelo que mudam sem uma atualização da aplicação.

## Pontos e utilização

Os modelos custam números diferentes de pontos. As Definições mostram o preço Cloud junto de cada modelo e fornecedor, juntamente com o que o seu plano inclui, como os minutos gratuitos que ainda tem este mês. Consulte as páginas do [Plano Cloud](https://www.enconvo.com/cloud-plan) e dos [Preços do Cloud](https://www.enconvo.com/cloud-pricing) para os planos e as tarifas atuais. Para ver o que utilizou, abra **Definições → Utilização de pontos**.

A [Rota automática](/pt/providers/auto-route), o modelo predefinido, é executada em modelos do Enconvo Cloud. Escolher a rota para cada mensagem é gratuito; o modelo que responde utiliza pontos.

Alguns serviços Cloud são gratuitos para todas as contas com sessão iniciada:

- Pesquisa na Web com **Enconvo Cloud** e **DeepSeek (Enconvo Cloud)**. Consulte [Pesquisa na Web](/pt/ai/web-search).
- Reconhecimento de voz com o **Enconvo Cloud Fast**. Consulte [Reconhecimento de voz](/pt/ai/speech-recognition).

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Os pedidos pedem-lhe que inicie sessão | Inicie sessão em **Definições → Conta**. |
| Os pedidos falham com um erro de pontos ou de saldo | Verifique **Definições → Utilização de pontos** e depois o seu plano na página do [Plano Cloud](https://www.enconvo.com/cloud-plan). |
| Falta um modelo | O seletor mostra o que o seu plano inclui. Clique em **Atualizar** junto a **Nome do modelo**. |

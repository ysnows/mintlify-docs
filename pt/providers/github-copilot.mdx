---
title: "GitHub Copilot"
description: "Inicie sessão com uma conta do GitHub que tenha um plano Copilot e converse com os modelos do seu plano."
---

Utilize o seu plano GitHub Copilot como fornecedor de Modelo de IA no Enconvo. Inicia sessão com a conta do GitHub que tem o plano; não está envolvida nenhuma chave de API. Os modelos premium contam para os pedidos premium do seu plano.

## Ligar

<Steps>
  <Step title="Abra o fornecedor">
    Abra **Definições → Modelo de IA → GitHub Copilot**.
  </Step>
  <Step title="Inicie o início de sessão">
    Em **Autenticação**, clique em **Ligar**.
  </Step>
  <Step title="Introduza o código no GitHub">
    O seu navegador abre a página de dispositivos do GitHub, e o Enconvo mostra o código a introduzir aí. Introduza o código e autorize o início de sessão.
  </Step>
  <Step title="Verifique a conta">
    Volte ao Enconvo e verifique se a conta do GitHub pretendida está ligada.
  </Step>
  <Step title="Escolha um modelo">
    Selecione um modelo e experimente um pedido curto.
  </Step>
</Steps>

Fechar a caixa de diálogo do código do Enconvo antes de autorizar cancela o início de sessão.

## Modelos e opções

A lista de modelos mostra apenas os modelos que o seu plano Copilot pode utilizar, com o modelo de chat predefinido do próprio Copilot em primeiro lugar. O Copilot Free oferece menos modelos do que os planos pagos, pelo que um modelo que viu noutro local pode não estar listado. Cada modelo utiliza os níveis de esforço de raciocínio que o Copilot oferece para ele.

## No iPhone

A aplicação para iPhone também pode iniciar sessão no GitHub Copilot, para as Conversas do telemóvel no próprio telemóvel. Consulte [Conversas do telemóvel](/pt/integrations/iphone-phone-chats).

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| O início de sessão não termina | Introduza o código na página do GitHub antes de expirar e clique novamente em **Ligar** para obter um novo código. |
| O modelo que quer não está listado | O seu plano Copilot não o inclui; escolha outro modelo ou melhore o plano. |
| Um pedido falha com um erro de modelo | Escolha um modelo da lista atual; um modelo predefinido escolhido antes de o seu plano mudar pode já não ser oferecido. |
| Limite de taxa ou de utilização | Os pedidos premium do seu plano e os limites de taxa do GitHub. |

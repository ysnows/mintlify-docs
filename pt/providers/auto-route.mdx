description: "Deixe o Enconvo escolher o modelo para cada mensagem, com base no tipo de trabalho que ela pede."

A Rota automática executa cada mensagem no modelo que definiu para esse tipo de trabalho: um modelo rápido para conversa de circunstância, um mais forte para problemas difíceis. É o modelo de IA predefinido para quem não escolheu nenhum e é o primeiro da lista **Modelo de IA**.

## Como funciona

Define algumas rotas. Cada rota descreve um tipo de trabalho e nomeia o modelo que o faz. Para cada mensagem, o Enconvo escolhe a rota que melhor se adapta e envia a mensagem para o modelo dessa rota. A escolha é gratuita e exige que tenha sessão iniciada na sua conta Enconvo.

As rotas predefinidas são todas executadas no Enconvo Cloud:

| Rota | Utilizada para | Modelo predefinido |
| --- | --- | --- |
| **Tarefas simples** | Cumprimentos, respostas factuais curtas, perguntas de sim ou não, ações de um só passo | Enconvo Fast |
| **Escrita e perguntas e respostas** | Conversar, responder a perguntas, redigir, reescrever, traduzir, resumir | Enconvo Fast |
| **Tarefas médias** | Pequenas alterações de código, ler um ficheiro ou uma página, comparar opções, elaborar um plano | Enconvo Balanced |
| **Tarefas complexas** | Código não trivial, decisões de design, pesquisa em muitas fontes, documentos longos | Enconvo Ultra |

Uma mensagem que não se enquadra em nenhuma rota é executada na rota marcada como **Recurso**: **Tarefas simples**, ou a primeira rota se remover essa.

Depois de um chat estar em curso, a Rota automática mantém-no no seu modelo atual quando a mudança para um mais barato custaria mais no total. Passar para outro modelo perde a cache do pedido, o que pode fazer a mudança custar mais do que ficar.

## Alterar as rotas

<Steps>
  <Step title="Abra a Rota automática">
    Abra **Definições → Modelo de IA → Rota automática** e encontre **Rotas de modelos**.
  </Step>
  <Step title="Edite uma rota">
    Clique numa rota para alterar o seu nome, **Trabalho que esta rota assume**, **Modelo** e **Esforço**. O modelo pode vir de qualquer fornecedor que tenha configurado, incluindo as suas próprias chaves de API.
  </Step>
  <Step title="Adicione ou remova rotas">
    Clique em **Adicionar rota** para um novo tipo de trabalho, ou em **Remover rota** para eliminar uma. **Repor** recupera as rotas predefinidas.
  </Step>
</Steps>

Descreva o trabalho de cada rota em palavras simples. Quanto mais clara a descrição, melhor as mensagens chegam ao modelo certo.

## Ver que rota respondeu

Clique em **Detalhes** por baixo de uma resposta para ver o modelo e a rota da Rota automática que o escolheu, juntamente com o esforço, os pontos ou o custo, os tokens e o tempo.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| A Rota automática pede-lhe que inicie sessão | Escolher uma rota exige a sua conta Enconvo. Inicie sessão em **Definições → Conta**. |
| As mensagens chegam ao modelo errado | Torne as descrições de **Trabalho que esta rota assume** das rotas mais distintas. |
| O modelo de uma rota falha | Abra essa rota e verifique o fornecedor do seu modelo, ou escolha outro modelo. |

O Conector do Gmail traz o seu e-mail para o Enconvo. Peça a um agente para encontrar correio importante, resumir uma conversa, redigir uma resposta ou limpar a caixa de entrada, e ele usa o Gmail por você. Liga a conta Google uma vez, através da sua conta Enconvo; não há projeto Google Cloud nem chave de API para configurar.

Uma conta Gmail que liga aqui também aparece em [E-mail](/pt-br/integrations/email), onde pode ler, ordenar e responder você mesmo.

## Antes de começar

Entre na sua conta Enconvo em **Definições → Conta**. Os Conectores são gratuitos em todos os planos, mas precisam de uma conta Enconvo.

## Ligar o Gmail

<Steps>
  <Step title="Encontrar o Gmail">
    Abra **Definições → Plugins** e pesquise **Gmail** no separador **Enconvo**. Clique nele para abrir a página.
  </Step>
  <Step title="Ligar">
    Clique em **Ligar**. O navegador abre o login do Google.
  </Step>
  <Step title="Permitir o acesso">
    Escolha a conta Google e reveja o acesso que pede antes de permitir. O ecrã de consentimento do Google mostra a Composio, a parceira de integração do Enconvo.
  </Step>
  <Step title="Conferir o resultado">
    De volta ao Enconvo, o seu endereço aparece em **Conta**. Clique em **Experimentar agora**, ou peça primeiro a um agente uma pergunta só de leitura, como "Resume os e-mails não lidos da minha caixa de entrada de hoje."
  </Step>
</Steps>

Se pedir a um agente sobre o correio antes de o Gmail estar ligado, o chat mostra um cartão para o ligar.

## O que os agentes podem fazer

| Área | O que os agentes podem fazer |
| --- | --- |
| Ler | Pesquisar correio, abrir mensagens e conversas, transferir anexos, listar etiquetas e rascunhos |
| Organizar | Acrescentar e remover etiquetas, arquivar, mover mensagens para o Lixo e restaurá-las |
| Escrever | Criar e enviar rascunhos, enviar correio novo, responder e reencaminhar |

A pesquisa usa a própria sintaxe de pesquisa do Gmail, como `from:john@example.com`, `subject:invoice` ou `after:2024/01/01`.

Quando os agentes escrevem ou enviam correio, podem definir Para, CC e BCC, escrever um corpo em texto simples ou HTML, responder dentro de uma conversa existente e anexar ficheiros do Mac: até 10 ficheiros, cada um até 95 MB. Ficheiros acima do que um e-mail pode levar (25 MB juntos) vão como ligações de transferência em file.enconvo.com, e qualquer pessoa com a ligação pode transferir o ficheiro.

<Warning>
Os agentes podem enviar correio sem perguntar primeiro. Peça um rascunho quando quiser revê-lo. O Enconvo nunca apaga correio de forma permanente; apagar move-o para o Lixo.
</Warning>

## Opções

Estas aparecem na página do Gmail depois de uma conta estar ligada.

| Opção | O que muda |
| --- | --- |
| **Disponível em todos os chats** | Ligado: os agentes podem usar o Gmail em todas as conversas. Desligado: os agentes usam-no só quando o menciona com `@` ou um Perfil o inclui. |
| **Alertas de e-mail** | Avisa-o na Dynamic Island e no telemóvel quando chega correio importante. Fica desligado até o ligar em **Tarefas agendadas → E-mails importantes**, e o interruptor **Telemóvel** envia alertas para um iPhone ou telemóvel Android emparelhado. O Enconvo pergunta antes de ligar, porque o remetente, o assunto e o início de cada correio novo vão para o Enconvo Cloud para julgar a importância. O correio nunca é guardado lá. |
| **Ligar outra conta** | Acrescenta outro endereço Gmail, até 5. |

Com várias contas, os agentes leem de todas, e enviam ou criam correio com a conta predefinida, a menos que nomeie outra, como "envia a partir do meu endereço de trabalho". Escolha **Tornar predefinido** no menu de uma conta para mudar a predefinição.

## Usar o Gmail nos chats

Depois de o Gmail estar ligado, peça o que precisa. O agente escolhe as ferramentas certas do Gmail.

**Pesquisar e resumir:**
```
"Find all emails from John in the last week and summarize them"
```

**Redigir uma resposta:**
```
"Draft a reply to the latest email from marketing@company.com thanking them for the report"
```

**Limpar a caixa de entrada:**
```
"Archive all newsletters from the past month"
```

**Gerir etiquetas:**
```
"Create a label called 'Q1 Reports' and move all emails with 'quarterly report' in the subject there"
```

**Limpar correio antigo (vai para o Lixo):**
```
"Delete all promotional emails older than 6 months"
```

## Ideias para fluxos de trabalho

O Gmail também funciona em [fluxos de trabalho](/pt-br/workflows/introduction) e [tarefas agendadas](/pt-br/workflows/scheduled-jobs):

| Ideia | O que faz |
| --- | --- |
| **Resumo diário de e-mail** | Pesquisa e-mails não lidos, resume-os e apresenta um briefing de manhã |
| **Categorizar automaticamente** | Pesquisa e-mails novos e aplica etiquetas com base no conteúdo |
| **Lembrete de seguimento** | Encontra e-mails à espera de resposta e cria lembretes |
| **Geração de relatórios** | Pesquisa e-mails que correspondem aos seus critérios e compila um relatório de resumo |

## Privacidade

- **Através do Enconvo Cloud e da Composio**: o correio passa pelo Enconvo Cloud e pela Composio só para fazer o que pede, e não é guardado.
- **A palavra-passe fica no Google**: entra na própria página do Google, por isso o Enconvo nunca vê a palavra-passe do Google.
- **A pedido**: os agentes leem o Gmail só quando uma tarefa precisa. A única exceção são os **Alertas de e-mail**, que, quando os liga, conferem cada correio novo à medida que chega.
- **Revogável**: clique em **Desligar** na página do Gmail para remover o acesso em todos os dispositivos. Também pode remover o acesso nas [permissões da Conta Google](https://myaccount.google.com/permissions).

## Solução de problemas

| Problema | O que fazer |
| --- | --- |
| **Ligar** está esbatido | Entre primeiro na sua conta Enconvo em **Definições → Conta**. |
| O Gmail mostra **Voltar a ligar** | O acesso expirou. Clique em **Voltar a ligar** e entre de novo com o Google. |
| O agente não usa o Gmail | Confira se o Gmail está ligado. Se **Disponível em todos os chats** estiver desligado, mencione o Gmail com `@` no chat. |
| Uma pesquisa não encontra nada | Experimente primeiro uma consulta mais simples, como `from:john`, e confira se o correio está numa conta ligada. A pesquisa do Gmail funciona como no site do Gmail. |
| Um anexo não é enviado | Confira se os caminhos dos ficheiros estão corretos e se os ficheiros existem no Mac. |

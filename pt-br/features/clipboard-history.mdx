Histórico da área de transferência, Pesquisa de marcadores do navegador e Pesquisa de arquivos são três listas rápidas que você pesquisa à medida que escreve. Use o Histórico da área de transferência para colar algo que copiou antes, a Pesquisa de marcadores para abrir uma página guardada em qualquer navegador, e a Pesquisa de arquivos para abrir um arquivo sem o Finder. Cada uma abre com o próprio atalho, ou a partir da SmartBar com um alias.

## Abrir uma lista

1. Defina um atalho para a lista em **Definições → Atalho**, ou na própria página de definições da lista em **Definições → Plugins**.
2. Prima o atalho. Com **O atalho abre uma janela** ligado, que é a predefinição, a lista abre numa janela própria e a SmartBar fica como está.
3. Escreva para filtrar a lista, mova-se até um item com as setas e prima Return.

Para abrir uma lista dentro da SmartBar, defina o **Alias**. Escreva o alias e um espaço na SmartBar, e a lista abre lá. A pesquisa da SmartBar mostra o alias de cada lista.

Também pode mencionar uma lista com `@` num chat, e o Agente pesquisa essa lista por você.

## Colar a partir do Histórico da área de transferência

O Histórico da área de transferência guarda o texto, as imagens e os arquivos que você copia. Pode afixar favoritos e filtrar por links, e-mails, cores, imagens ou arquivos.

1. Abra o Histórico da área de transferência.
2. Escreva uma palavra do que copiou.
3. Prima Return para colar o item no app que estava a usar. Prima **⌘C** para o copiar em vez disso. Com **Tecla Return** definida para copiar, **⌘Return** cola.

Quando você abre a lista sobre uma das janelas do próprio Enconvo, Return cola na caixa de mensagem dessa janela.

Gestores de palavras-passe e o Acesso às Chaves ficam de fora por predefinição, e cópias que os apps marcam como ocultas ou temporárias, como palavras-passe, nunca são registadas.

## Abrir um marcador

A Pesquisa de marcadores do navegador lê os marcadores do Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox e Zen, incluindo perfis do Firefox e do Zen guardados numa pasta que você escolheu. Uma pesquisa também corresponde a nomes de pastas.

Prima Return para abrir o marcador no navegador de onde veio, ou **⌘O** para o abrir no navegador predefinido. **Tecla Return** troca os dois.

## Encontrar um arquivo

A Pesquisa de arquivos olha para o Mac inteiro por predefinição. Use o menu pendente no campo de pesquisa para pesquisar num só sítio nesta pesquisa, como **As minhas pastas**, **Início** ou **Transferências**.

Prima Return para abrir o arquivo, ou **⌘Return** para o mostrar no Finder. **Tecla Return** troca os dois.

## Definições

Abra **Definições → Plugins** e depois **Histórico da área de transferência**, **Marcadores do navegador** ou **Pesquisa de arquivos**.

| Definição | Lista | O que altera |
| --- | --- | --- |
| **Alias** | As três | A palavra que você escreve, e depois um espaço, na SmartBar para abrir a lista lá. |
| **O atalho abre uma janela** | As três | Ligado: o atalho abre a lista na própria janela. Desligado: o atalho abre-a na SmartBar. Ligado por predefinição. |
| **Tecla Return** | As três | O que Return faz. Histórico da área de transferência: **Colar no app da frente** ou **Copiar para a área de transferência**. Marcadores: **Abrir no seu navegador** ou **Abrir no navegador predefinido**. Arquivos: **Abrir** ou **Mostrar no Finder**. |
| **Registar o histórico da área de transferência** | Histórico da área de transferência | Guarda um histórico do que você copia. Desligar mantém os itens já guardados. |
| **Manter o histórico durante** | Histórico da área de transferência | Quanto tempo os itens ficam, de **1 dia** a **Para sempre**. 3 meses por predefinição. Os itens afixados nunca são removidos. |
| **Apps ignoradas** | Histórico da área de transferência | Apps cujas cópias nunca são registadas, pelo bundle ID. |
| **Mostrar nomes de pastas** | Marcadores | Mostra a pasta de cada marcador. |
| **Navegadores desligados** | Marcadores | Navegadores cujos marcadores ficam de fora. |
| **Pesquisar em** | Arquivos | Onde a Pesquisa de arquivos olha quando abre: **Este Mac**, **As minhas pastas**, **Início**, **Ambiente de trabalho**, **Documentos**, **Transferências** ou **Aplicações**. |
| **Pastas de pesquisa** | Arquivos | As pastas que **As minhas pastas** pesquisa. Ambiente de trabalho, Documentos e Transferências quando está vazio. |
| **Mostrar arquivos ocultos** | Arquivos | Inclui arquivos cujo nome começa por um ponto. |
| **Pastas excluídas** | Arquivos | Pastas cujo conteúdo nunca aparece. |

Um atalho ou alias que você definiu nas versões web mais antigas destas listas é mantido.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| O atalho abre a SmartBar em vez de uma janela | Ligue **O atalho abre uma janela** para essa lista. |
| Falta uma cópia no Histórico da área de transferência | Confira **Registar o histórico da área de transferência** e **Apps ignoradas**. Cópias ocultas, como palavras-passe, nunca são registadas. |
| Faltam os marcadores de um navegador | Confira **Navegadores desligados**. |
| Um arquivo não aparece | Confira **Pesquisar em**, **Pastas excluídas** e **Mostrar arquivos ocultos**. |

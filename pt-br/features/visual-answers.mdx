description: "Receba um diagrama, um gráfico ou um widget interativo direto no chat, em vez de texto simples."
---

Peça a um Agente para mostrar a resposta, e ele desenha o visual na conversa: um diagrama SVG, uma pré-visualização em HTML ou um widget interativo que você clica e ajusta. Use quando uma imagem, um gráfico ou uma calculadora pequena explicam mais do que parágrafos. O Agente precisa das ferramentas visuais para fazer isso.

Uma resposta visual vive na conversa. Quando você quer algo para guardar, editar, apresentar ou partilhar, como um deck, um painel, um design ou um documento, peça um [artefato](/pt-br/features/artifacts).

## Pedir um visual

Diga que pergunta o visual deve responder:

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

Para um gráfico ou uma calculadora, inclua os dados e as unidades. Um visual bem acabado ainda pode ter fatos ou contas errados, então confira.

## Links, mapas e gráficos nas respostas

Algumas respostas ficam visuais sem você pedir:

- **Links** aparecem como cartões com o ícone do site.
- **Lugares** aparecem num mapa real com o nome do lugar. Vários lugares partilham um mapa numerado, e um percurso mostra a linha com o tempo e a distância.
- **Gráficos** que o Agente faz têm as cores conferidas, para cada série continuar distinta com daltonismo e nos modos claro e escuro. Números, datas e palavras de estado aparecem no seu idioma.

## Usar e guardar um visual

1. Espere o visual terminar de desenhar e use os controles que ele tiver. Alguns widgets devolvem um pedido de continuação ao chat.
2. Aponte para o visual pronto e clique em **⋯** no canto superior direito.
3. Escolha **Copy to clipboard** ou **Download file** e confirme o nome do arquivo. Visuais desenhados com os cartões, tabelas e gráficos do próprio app oferecem **Download image**, que guarda um PNG na pasta Transferências.

Uma imagem guardada captura um momento do visual; não conserva os controles interativos. Depois de mudar os valores de um widget, **Reset values** no mesmo menu os repõe.

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Você recebe código em vez de um visual | Confira as ferramentas ativadas do Agente e peça para mostrar o resultado na conversa |
| Um widget parece incompleto | Espere ele terminar e peça uma versão mais simples |
| Você precisa de um arquivo de imagem, não de um widget no chat | Use a [Geração de imagens](/pt-br/ai/image-generation) |
| Você quer guardar o gráfico e voltar a ele | Peça um [Painel](/pt-br/features/dashboards) |

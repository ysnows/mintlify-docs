Os Links rápidos transformam uma pesquisa na web, um endereço web, um arquivo ou pasta, ou o deeplink de um app num comando que você executa a partir da SmartBar. Os marcadores preenchem o link com o que você digita, a área de transferência, o texto selecionado ou a data. O Enconvo vem com pesquisas Google, YouTube e X prontas a usar.

Os Links rápidos abrem um destino. A [Pesquisa na Web](/pt-br/ai/web-search) em vez disso traz resultados de pesquisa para uma resposta de IA, e o [Uso do navegador](/pt-br/features/browser-control) deixa um Agente trabalhar em páginas web.

## Pesquisar na web a partir da SmartBar

1. Abra a SmartBar e encontre **Google Search in Browser**, **YouTube Search in Browser** ou **Twitter/X Search in Browser**.
2. Digite o texto da pesquisa como entrada do comando. O texto selecionado também serve.
3. Execute o comando. A pesquisa abre no navegador predefinido.

## Criar um link rápido

1. Execute **Criar link rápido** a partir da SmartBar.
2. Introduza um **Nome**, como Search GitHub.
3. Introduza o **Link**: um endereço web, um caminho de arquivo ou pasta, ou um deeplink. Clique em **Inserir marcador** para adicionar um, como `https://github.com/search?q={argument}`.
4. Para o abrir num app concreto, introduza um nome de app como Safari, um caminho de app ou um bundle id em **Abrir com**. Deixe vazio para usar o app predefinido.
5. Clique em **Guardar**. Procure o nome do link rápido na SmartBar para o executar.

Quando você executa um link rápido, o texto que digitou ou selecionou preenche o primeiro argumento. Se um argumento obrigatório ainda estiver vazio, o Enconvo pede-o antes de abrir o link.

| Marcador | Preenchido com |
| --- | --- |
| `{argument name="Query"}` | Um valor que você digita quando o link rápido abre |
| `{clipboard}` | O texto da área de transferência |
| `{selection}` | O texto selecionado no app que você está a usar |
| `{date}`, `{time}`, `{datetime}` | A data atual, a hora, ou as duas |
| `{date format="yyyy-MM-dd"}` | A data no formato que você dá |
| `{uuid}` | Um ID único novo |

Teste um link novo com texto comum primeiro, incluindo espaços e pontuação.

## Gerir os links rápidos

Execute **Search Quicklinks** a partir da SmartBar para ver cada link rápido. De lá pode abrir, editar, duplicar ou eliminar um, e clicar em **Novo** para adicionar outro.

O menu **Mais** tem **Importar links rápidos…**, que lê exportações de links rápidos e de definições do Raycast, e **Exportar para Transferências**. Uma exportação de definições do Raycast pede a frase-passe que você escolheu ao exportar.

## Definições

Abra **Definições → Plugins → Links rápidos**. Cada comando de pesquisa também tem o próprio **Link**, como `https://www.google.com/search?q={query}`, que você pode mudar.

| Definição | O que muda |
| --- | --- |
| **Abrir em nova janela** | Abre links rápidos web numa janela nova do navegador. Funciona com Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox e Zen; Safari, Arc e Orion abrem o link como de costume. Desligado por predefinição |
| **When There's No Selected Text** | O que um link `{selection}` faz quando nada está selecionado: **Ask for it** (a predefinição) ou **Use the clipboard** |
| **Confirm Before Deleting** | Pergunta antes de você eliminar um link rápido. Ligado por predefinição |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Abre a página errada | Confira o **Link** do link rápido e os marcadores, depois experimente com texto simples |
| O navegador não abre | Confira o navegador predefinido, o **Abrir com** do link rápido e se o comando está instalado |
| Um link `{selection}` pede texto | Nada estava selecionado. Selecione o texto primeiro, ou defina **When There's No Selected Text** para **Use the clipboard** |

As Ferramentas de escrita são um conjunto de comandos de um clique para o texto que seleciona em qualquer app. Corrija erros, mude o tom, torne-o mais curto ou mais longo, explique ou resuma, ou transforme-o numa lista ou tabela, sem sair do app em que escreve.

## Editar texto selecionado

1. Selecione texto no app em que está a escrever.
2. Clique num comando na [PopBar](/pt-br/features/popbar), ou abra o [SmartBar](/pt-br/features/smartbar) e pesquise o comando.
3. Leia o resultado. Quando **Destacar edições** está ligado, o resultado marca o que o comando acrescentou e removeu.
4. Clique em **Colar** para substituir a seleção, ou copie o resultado.

Cada comando mantém o idioma do texto e responde só com o resultado. **Explicar** também responde no idioma do texto selecionado, e trata cada execução por si, não como parte de uma anterior. Quando o texto selecionado faz uma pergunta ou dá uma instrução, o comando edita essas palavras; não as responde.

<Tip>
Ligue o **Modo inline** para um comando em que confia, e ele corre sem janela e cola o resultado diretamente sobre a seleção. Veja [Mudar um comando](/pt-br/features/writing-tools).
</Tip>

## Escolher um comando

| Objetivo | Comandos |
| --- | --- |
| Corrigir erros | Corrigir ortografia e gramática, Rever |
| Melhorar a redação | Melhorar a escrita, Aperfeiçoar, Reescrever, Soar nativo, Edição de IA |
| Mudar o comprimento | Tornar mais longo, Tornar mais curto, Tornar conciso |
| Mudar o tom | Mudar o tom para Amigável, Confiante, Casual ou Profissional |
| Entender o conteúdo | Explicar, Resumir, Extrair pontos principais |
| Reformatar | Converter para lista, Converter para tabela |
| E-mail | Aperfeiçoar e-mail, Rascunhar uma resposta |
| Publicações no X | Aperfeiçoar para o X, Caber em 280 caracteres, Transformar num fio, Sugerir uma resposta no X, Sugerir um comentário de citação no X |
| Traduzir | Tradutor, Traduzir captura de ecrã (veja [Tradução](/pt-br/ai/translate)) |
| Algo no ecrã | Explicar captura de ecrã |
| Ditado | Aperfeiçoar do Ditado, Traduzir do Ditado, Editar do Ditado, Limpeza no dispositivo (veja [Ditado](/pt-br/features/dictation)) |
| Expressão curta | Emoji |

**Soar nativo** reescreve o texto como um falante nativo o escreveria, no mesmo idioma. **Aperfeiçoar e-mail** mantém a sua saudação, despedida e nome, e não acrescenta uma assinatura. **Rascunhar uma resposta** escreve uma resposta ao e-mail selecionado no idioma e tom dele, e deixa um marcador curto entre parênteses retos para um nome, data ou decisão que não pode saber.

## Mudar um comando

Abra **Definições → Comandos de IA** e escolha o comando em **Integrado**. A página mostra o que o comando faz, com **Experimentar** para o executar em algum texto primeiro.

| Definição | O que muda |
| --- | --- |
| **PopBar** | Acrescenta o comando à PopBar, ou tira-o |
| **Destacar edições** | Marca o que o comando acrescentou e removeu no resultado |
| **Tecla de atalho** | Executa o comando no texto que seleciona em qualquer app |
| **Modo inline** | Corre sem janela e cola o resultado sobre a seleção |
| **Ação posterior** | O que o comando faz com a resposta quando termina |
| **Modelo de IA** | O modelo que este comando usa. Por predefinição segue o modelo de todos os Comandos de IA |

As instruções de um comando integrado são só de leitura. Clique em **Personalizar** para fazer uma cópia sua, que pode mudar à vontade.

As ferramentas de escrita correm no modelo definido em **Definições → Comandos de IA → Todos os comandos**, a menos que um comando escolha o próprio. Os mesmos comandos também estão listados em **Definições → Plugins → Ferramentas de escrita**, e o botão **Definições** numa janela de resultado abre o comando que o produziu.

## Obter resultados fiáveis

Quando uma reescrita pode seguir vários caminhos, diga para quem é o texto e o que deve fazer. Nomeie o que tem de ficar igual, como nomes, datas, números e texto citado.

Compare sempre o resultado com o original antes de o enviar. Uma saída fluente ainda pode mudar o sentido.

Para uma instrução que repete, crie o seu próprio [Comando de IA](/pt-br/features/ai-commands).

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Um comando não está na PopBar | Clique em **⌄** no fim da PopBar, onde vão os botões que não cabem, ou ligue **PopBar** na página do comando em **Definições → Comandos de IA** |
| A PopBar não aparece | Veja [resolução de problemas da PopBar](/pt-br/features/popbar) |
| O resultado está num idioma inesperado | Explicar responde no idioma do texto selecionado. Resumir mantém o idioma do texto, a menos que defina o **Idioma das respostas**. Os outros comandos mantêm o idioma do texto |
| O resultado mudou o sentido | Edite-o antes de colar, ou execute o comando de novo com o texto original |

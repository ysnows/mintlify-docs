O Desenho no ecrã deixa você marcar parte do ecrã antes de perguntar ao Agente sobre ela. Desenhe setas, círculos, realces ou notas, e depois envie. A captura marcada é anexada ao chat como imagem, na Dynamic Island, a menos que você estivesse a usar outro chat do Enconvo, como a Janela de chat.

## Marcar o ecrã

1. Traga para a frente o conteúdo sobre o qual quer perguntar.
2. Faça duplo clique com o botão direito para abrir o Desenho no ecrã, ou pressione o **Atalho** que definiu em **Definições → Desenho no ecrã**.
3. Se **Capturar a região primeiro** estiver ligado, arraste para selecionar a região. Caso contrário, desenhe diretamente sobre o ecrã ao vivo.
4. Escolha uma ferramenta na barra e marque a área que quer dizer.
5. Clique em **Enviar** (o avião de papel) ou pressione **⌘↩**.
6. Revise a imagem anexada e digite um pedido, como “O que significa o aviso realçado?”

O Desenho no ecrã não tem atalho até você definir um. O duplo clique com o botão direito funciona de imediato.

### Acrescentar uma etiqueta falada

Mantenha a tecla **Option** esquerda e fale para descrever a forma que acabou de desenhar. As suas palavras aparecem ao lado como texto. Para o Desenho no ecrã ouvir depois de cada forma que você desenha, ligue **Falar depois de cada forma** na barra, e pause para terminar cada etiqueta.

## Ferramentas

| Ferramenta ou ação | Tecla |
| --- | --- |
| Seta | **A** |
| Linha | **L** |
| Caneta | **P** |
| Marcador | **H** |
| Retângulo | **R** |
| Círculo | **O** |
| Contador (marcadores numerados) | **N** |
| Texto | **T** |
| Selecionar | **V** |
| Borracha | **E** |
| Cor | **C** |
| Espessura da linha | **⌘** + scroll |
| Quadro branco | **B** |
| Realce do cursor | **K** |
| Guardar como… | **⌘S** |
| Enviar | **⌘↩** |

A barra também tem **Desfazer**, **Refazer**, **Limpar**, **Copiar para a área de transferência** e **Fechar**.

## Definições

Abra **Definições → Desenho no ecrã**.

| Ajuste | O que faz |
| --- | --- |
| **Capturar a região primeiro** | Selecione uma região antes de desenhar. Desligue para desenhar diretamente no ecrã ao vivo. Ligado por predefinição. |
| **Atalho** | Abre ou fecha o Desenho no ecrã. Vazio por predefinição. |
| **Duplo clique com o botão direito** | Abre ou fecha o Desenho no ecrã com um duplo clique rápido com o botão direito. Ligado por predefinição. |

## Solução de problemas

| Problema | O que fazer |
| --- | --- |
| A sobreposição não abre | Confira o **Atalho** e o **Duplo clique com o botão direito** em **Definições → Desenho no ecrã**, e confira as [permissões do macOS](/pt-br/configuration/permissions). |
| Você só precisa da janela inteira do app | Use [Appshots](/pt-br/features/appshots). |

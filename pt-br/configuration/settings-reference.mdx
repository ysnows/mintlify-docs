title: "Referência de Definições"
description: "Cada entrada na barra lateral de Definições, o que controla e o guia que a explica."
---

Cada entrada na barra lateral de Definições do Enconvo, na ordem da barra lateral, com o guia que a explica. Para abrir Definições, clique no ícone do Enconvo na barra de menus e escolha **Definições**. Para saltar para uma entrada, escreva o nome em **Pesquisar definições**, ou escreva uma pergunta e prima Return para perguntar à IA onde está uma definição.

Os guias escrevem caminhos de Definições com os nomes abaixo, como **Definições → SmartBar**.

As janelas e os recursos de voz do Enconvo abrem cada um com uma tecla de atalho. **Definições → Atalho** lista cada tecla de atalho que o Enconvo usa e o comando que executa, para você mudar uma ou descobrir o que uma combinação de teclas faz. As teclas guardadas no seu Mac prevalecem sempre sobre as predefinições deste guia.

Este vídeo cobre Atalhos e depois as outras definições que adaptam o Enconvo ao seu Mac: Compreensão do contexto, Appshots, Modelos locais, Permissões e Impedir a suspensão.

## Atalhos predefinidos

| Ação | Predefinição |
| --- | --- |
| Mostrar SmartBar | **⌥Space** |
| Mostrar Janela de chat | **⌃⌘X** |
| Mostrar Barra lateral da aplicação | **⌃⌘E** |
| Abrir Definições, de dentro do Enconvo | **⌘,** |
| Iniciar Ditado | **Right ⌘** |
| Iniciar Comando de voz | **Right ⌥** |
| Pausar/retomar áudio | **⌥P** |

Estas predefinições só se aplicam se você nunca definiu a sua própria tecla; uma tecla que definiu fica como está. Captura rápida e Appshots não têm tecla de atalho predefinida: defina uma nas páginas de Definições deles antes de os usar.

## Mudar uma tecla de atalho

1. Abra **Definições → Atalho**. O separador **Principais** tem os recursos principais, **Outros atalhos** tem comandos de IA, plugins, definições e comandos que nenhuma outra página mostra, e **Tudo** mostra os dois.
2. Escreva em **Filtrar por nome…** para encontrar um comando. Para encontrar o comando por trás de uma combinação de teclas, clique em **Procurar por atalho** e prima-a.
3. Clique no campo de tecla de atalho do comando e prima a combinação nova.
4. Se essas teclas já executam outro comando, o campo diz-lhe. Escolha **Usar aqui** para passar as teclas para este comando, ou escolha uma das teclas livres que sugere.
5. Mude para outro app e experimente a tecla de atalho.

Para libertar as teclas de um atalho, remova-o do comando. Uma mensagem com **Desfazer** deixa desfazer isso.

Um distintivo **Local** marca uma tecla de atalho que só funciona dentro do Enconvo, como Fixar SmartBar.

## Como premir

Quando grava uma tecla modificadora sozinha, como Right ⌘, o campo pergunta **Como premir**:

| Opção | O comando corre quando você |
| --- | --- |
| **Manter ou tocar** | Mantém a tecla, ou toca para alternar |
| **Tocar** | Toca na tecla para começar e toca de novo para parar |
| **Manter** | Mantém a tecla premida; funciona enquanto a mantém |
| **Toque duplo** | Toca na tecla duas vezes depressa |

Duas ou mais teclas modificadoras premidas ao mesmo tempo contam como uma tecla de atalho. Cada campo mostra só os tipos que o comando suporta, e a descrição ao lado diz como esse recurso reage.

## Onde fica a tecla de atalho de cada recurso

Além da página Atalho, cada recurso tem a tecla de atalho na própria página de Definições:

| Recurso | Página de Definições |
| --- | --- |
| SmartBar | **Definições → SmartBar** |
| Dynamic Island | **Definições → Dynamic Island** |
| PopBar | **Definições → PopBar** |
| Barra lateral da aplicação | **Definições → Barra lateral da aplicação** |
| Ditado | **Definições → Ditado** |
| Comando de voz | **Definições → Comando de voz** |
| Appshots | **Definições → Appshots** |
| Desenho no ecrã | **Definições → Desenho no ecrã** |
| Nota de voz | **Definições → Nota de voz** |
| Captura rápida | **Definições → Captura rápida** |
| Um único comando | As definições desse comando, quando tem um campo **Tecla de atalho** |

## Dentro do SmartBar

Escreva um caráter de gatilho no SmartBar para pesquisar um tipo de item:

| Caráter | Abre |
| --- | --- |
| **@** | Comandos |
| **#** | Contexto a acrescentar à mensagem |
| **$** | Competências |
| **>** | Tarefas recentes |

Mude estes carateres em **Pesquisa** em **Definições → SmartBar**. O menu de barra tem ações como seleção de modelo e de raciocínio.

Para percorrer listas com o teclado, escolha **Atalhos de navegação** em **Definições → SmartBar**: **macOS** usa **⌃N** **⌃P** **⌃F** **⌃B**, e **Vim** usa **⌃J** **⌃K** **⌃L** **⌃H**.

## Adaptar o Enconvo ao seu Mac

A mesma janela de Definições tem as outras escolhas que o vídeo percorre:

| Página de Definições | O que faz |
| --- | --- |
| **Compreensão do contexto** | Escolhe o que o SmartBar recolhe do app em que você estava: o texto selecionado, a seleção do Finder ou a página no navegador. **Anexar** acrescenta-o assim que o SmartBar abre, e **Sugerir** oferece-o com um clique. Veja [Compreensão do contexto](/pt-br/features/context-awareness). |
| **Appshots** | Acrescenta a janela à sua frente à conversa com uma tecla de atalho. Veja [Appshots](/pt-br/features/appshots). |
| **Modelos locais** | Mostra a IA a correr neste Mac, a memória e o disco que usa, e onde cada recurso corre. Veja [Modelos locais](/pt-br/ai/local-llm). |
| **Permissões** | Lista o que o macOS deixa o Enconvo fazer e porquê; **Conceder** corrige uma em falta. Veja [Permissões do macOS](/pt-br/configuration/permissions). |
| **Impedir a suspensão** | Impede este Mac de dormir enquanto você está ausente, para ainda o alcançar a partir do iPhone. |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| Uma tecla de atalho só funciona dentro do Enconvo | Veja se tem um distintivo **Local**. Se não, confira Monitorização de entrada e Acessibilidade em [Permissões do macOS](/pt-br/configuration/permissions), e se outro app usa as mesmas teclas. |
| Premir uma tecla de atalho faz outra coisa | Use **Procurar por atalho**. Se nenhum comando do Enconvo usa as teclas, outro app ou o macOS usa. |
| Uma tecla de atalho de modificador não dispara | Abra a tecla de atalho e confira **Como premir**: manter, tocar, toque duplo ou teclas premidas juntas. |
| Um atalho de um vídeo ou de outro Mac não funciona | As suas teclas podem ser diferentes. Procure a atual em **Definições → Atalho**. |

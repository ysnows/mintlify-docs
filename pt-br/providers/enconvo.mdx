O Enconvo Cloud dá modelos de várias empresas, além de voz, imagem, vídeo e ferramentas da Web, pela sua conta Enconvo. Não há chaves de API para gerir: os pedidos usam os pontos do seu plano. É a forma mais rápida de começar.

## Configurar

<Steps>
  <Step title="Iniciar sessão">
    Inicie sessão na sua conta Enconvo. Veja [Conta](/pt-br/configuration/account).
  </Step>
  <Step title="Escolher o Enconvo Cloud">
    Abra a página de Definições do que quer fazer, como **Modelo de IA**, **Texto para voz** ou **Geração de imagens**, e escolha o fornecedor com o rótulo **Enconvo Cloud** ou **Enconvo Cloud Plan**.
  </Step>
  <Step title="Escolher um modelo ou uma voz">
    Escolha um modelo ou uma voz e faça um pedido curto.
  </Step>
</Steps>

Cada função tem a sua escolha de fornecedor. Escolher o Enconvo Cloud para o chat não muda voz, imagens, vídeo, embeddings, reranking nem ferramentas da Web; defina cada um onde quiser.

## Os modelos do próprio Enconvo

O Enconvo Cloud tem três modelos próprios, nomeados pelo trabalho a que se destinam:

| Modelo | Use para |
| --- | --- |
| **Enconvo Fast** | Turnos rápidos: respostas curtas, reescritas, ações pequenas. É o modelo com que o **Enconvo Cloud Plan** começa, e o padrão dos Comandos de IA. |
| **Enconvo Balanced** | Trabalho do dia a dia com alguns passos. |
| **Enconvo Ultra** | Tarefas difíceis que precisam de raciocínio profundo. |

Aparecem primeiro em **Enconvo Cloud Plan**, e o [Auto Route](/pt-br/providers/auto-route) usa-os nas rotas padrão.

## Encontrar um modelo no seletor

A lista **Enconvo Cloud Plan** agrupa modelos por fornecedor: primeiro os do Enconvo, depois Anthropic, OpenAI, Google e o resto, cada um com uma contagem. Um fornecedor mostra os quatro modelos mais recentes; clique em **Mostrar N modelos anteriores** para ver os outros. A pesquisa lista todas as correspondências, e o modelo que o seu chat usa aparece sempre. Os modelos Claude aparecem sem o prefixo "Claude", como **Sonnet 5.5** e **Opus 5.5**.

No seletor de modelo da Janela de chat, um modelo Cloud pode ter uma etiqueta:

| Etiqueta | Significado |
| --- | --- |
| **Novo** | Adicionado nos últimos 14 dias. |
| Um desconto, como **50% OFF** | O modelo custa menos por agora. Aponte para a linha, ou chegue a ela com as setas, para ver o preço normal. |
| **Gratuito** | O modelo não usa pontos. |
| **Pré-visualização** | Uma versão inicial do modelo. |
| Uma data | O dia em que o modelo sai do Enconvo Cloud. |

O Enconvo Cloud define as etiquetas, por isso mudam sem uma atualização da app.

## Pontos e uso

Os modelos custam números diferentes de pontos. As Definições mostram o preço Cloud junto de cada modelo e fornecedor, e o que o seu plano inclui, como os minutos grátis que restam este mês. Veja as páginas [Cloud Plan](https://www.enconvo.com/cloud-plan) e [Cloud pricing](https://www.enconvo.com/cloud-pricing) para planos e tarifas atuais. Para ver o que já usou, abra **Definições → Utilização de pontos**.

O [Auto Route](/pt-br/providers/auto-route), o modelo padrão, corre em modelos do Enconvo Cloud. Escolher a rota de cada mensagem é grátis; o modelo que responde usa pontos.

Alguns serviços Cloud são grátis para todas as contas com sessão iniciada:

- Pesquisa na Web com **Enconvo Cloud** e **DeepSeek (Enconvo Cloud)**. Veja [Pesquisa na Web](/pt-br/ai/web-search).
- Reconhecimento de voz com **Enconvo Cloud Fast**. Veja [Reconhecimento de voz](/pt-br/ai/speech-recognition).

## Solução de problemas

| Problema | O que fazer |
| --- | --- |
| Os pedidos pedem para iniciar sessão | Inicie sessão em **Definições → Conta**. |
| Os pedidos falham com um erro de pontos ou de saldo | Confira **Definições → Utilização de pontos** e depois o seu plano na página [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Falta um modelo | O seletor mostra o que o seu plano inclui. Clique em **Atualizar** ao lado de **Nome do modelo**. |

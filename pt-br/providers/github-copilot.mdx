---

Use o seu plano GitHub Copilot como fornecedor de Modelo de IA no Enconvo. Você entra com a conta GitHub que tem o plano; não há chave de API. Os modelos premium contam para os pedidos premium do seu plano.

## Ligar

<Steps>
  <Step title="Abrir o fornecedor">
    Abra **Definições → Modelo de IA → GitHub Copilot**.
  </Step>
  <Step title="Iniciar o login">
    Em **Autenticação**, clique em **Ligar**.
  </Step>
  <Step title="Introduzir o código no GitHub">
    O navegador abre a página de dispositivo do GitHub, e o Enconvo mostra o código a introduzir lá. Introduza o código e autorize o login.
  </Step>
  <Step title="Conferir a conta">
    Volte ao Enconvo e confira se a conta GitHub pretendida está ligada.
  </Step>
  <Step title="Escolher um modelo">
    Selecione um modelo e experimente um pedido curto.
  </Step>
</Steps>

Fechar o diálogo do código do Enconvo antes de autorizar cancela o login.

## Modelos e opções

A lista de modelos mostra só os modelos que o seu plano Copilot pode usar, com o padrão de chat do próprio Copilot primeiro. O Copilot Free oferece menos modelos do que os planos pagos, por isso um modelo que viu noutro sítio pode não estar listado. Cada modelo usa os níveis de esforço de raciocínio que o Copilot oferece para ele.

## No iPhone

O app do iPhone também pode entrar no GitHub Copilot, para Chats do telemóvel no telefone. Veja [Chats do telemóvel](/pt-br/integrations/iphone-phone-chats).

## Solução de problemas

| Problema | O que fazer |
| --- | --- |
| O login não termina | Introduza o código na página do GitHub antes de expirar e clique de novo em **Ligar** para um código novo. |
| O modelo que quer não está listado | O seu plano Copilot não o inclui; escolha outro modelo ou atualize o plano. |
| Um pedido falha com um erro de modelo | Escolha um modelo da lista atual; um padrão escolhido antes de o plano mudar pode já não ser oferecido. |
| Taxa ou limite de utilização | Os pedidos premium do seu plano e os limites de taxa do GitHub. |

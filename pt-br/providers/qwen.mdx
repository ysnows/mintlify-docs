Use os modelos Qwen da Alibaba em chats, Agentes e Comandos de IA. Ligue com uma chave de API do Alibaba Cloud Model Studio; a Alibaba Cloud cobra o uso na sua conta. Para o serviço da China continental (Bailian), use [DashScope](/pt-br/providers/dashscope).

## Ligar

<Steps>
  <Step title="Obter uma chave de API">
    Crie uma chave no [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="Adicionar ao Enconvo">
    Abra **Definições → Modelo de IA → Qwen**. Em **Autenticação**, cole a chave em **Chave de API** e clique em **Validar**.
  </Step>
  <Step title="Escolher um modelo">
    Escolha um modelo em **Nome do modelo** e envie uma mensagem curta. Uma resposta significa que a ligação funciona.
  </Step>
</Steps>

O Qwen liga só com uma chave de API.

## Modelos e opções

| Definição | O que faz |
| --- | --- |
| **Nome do modelo** | O modelo que este fornecedor usa. **Atualizar** ao lado recarrega a lista; **Gerir modelos** (a engrenagem) adiciona ou restaura modelos. |
| **Base Url** | Na credencial. O padrão é o endpoint internacional, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Mude se a sua chave pertencer a outra região. |

## Resolução de problemas

| Problema | O que fazer |
| --- | --- |
| **Validar** falha | Confira se a chave e **Base Url** pertencem à mesma região e cole a chave inteira de novo. |
| Falta um modelo | Clique em **Atualizar** ao lado de **Nome do modelo**. Para adicionar um modelo você mesmo, use **Gerir modelos**. |
| Erros de limite de taxa ou de uso | Confira o uso e a quota no Model Studio, ou mude para outro fornecedor por agora. |

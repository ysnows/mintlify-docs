Peça a um Agente no chat para fazer uma imagem, ou para alterar uma imagem que você anexa. O Enconvo envia o pedido ao fornecedor de imagem definido em **Definições → Geração de imagens**, que é separado do modelo com o qual você conversa.

## Antes de começar

1. Abra **Definições → Geração de imagens** e escolha um fornecedor.
2. Defina o **Fornecedor de credenciais** (a chave ou conta que ele usa) e o **Nome do modelo**.
3. Clique em **Definir como predefinido**.

Os fornecedores do Enconvo Cloud, **OpenAI (Enconvo Cloud)** e **Google Gemini (Enconvo Cloud)**, não precisam de uma chave de API sua.

## Criar uma imagem

1. Num chat com um Agente, descreva o assunto, a composição, o estilo e para que a imagem serve.
2. Peça um tamanho, proporção ou qualidade só quando o modelo suportar.
3. Espere a imagem. A geração pode demorar mais do que uma resposta em texto.
4. Clique na imagem para abri-la ao lado do chat, onde você pode continuar editando.

Exemplo:

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

Você também pode escolher **Imagem** sob a caixa de mensagem de um chat novo. O modelo, os ajustes dele e **Evitar** aparecem como pills sob a caixa de mensagem, para você defini-los antes de enviar. Para uma biblioteca de tudo o que você fez, assuntos salvos e correções de um clique, use [Multimédia](/pt-br/features/media).

## Editar uma imagem

1. Anexe a imagem de origem à mensagem, ou clique numa imagem que um Agente fez para abri-la no editor de imagens.
2. Descreva as alterações específicas e diga o que deve permanecer igual.
3. Confira o resultado em busca de mudanças que você não pediu.

Use um modelo que suporte edição de imagem ou imagens de referência.

No editor de imagens, o painel de ajustes mostra só o que o modelo escolhido aceita:

| Ajuste | O que muda |
| --- | --- |
| Resolução, proporção e qualidade | O tamanho e o detalhe da próxima versão |
| **Evitar** | O que deixar de fora, para modelos que aceitam um prompt negativo |
| Variações | Quantas versões cada pedido gera; você fica com as que quiser |
| **Área de edição** e **Marcação** | Pinte na imagem para mudar só essa parte, ou desenhe para orientar a mudança |
| GIF e **Quadros** | Uma imagem animada feita a partir das suas palavras |

Cada edição é uma versão nova, e cada imagem fica em [Multimédia](/pt-br/features/media) e em `~/Enconvo/Media`. Para animar uma imagem, clique em **Criar vídeo**.

### GPT Image 2.6

GPT Image 2.6 Flare e Sunburst estão disponíveis pela OpenAI, Enconvo Cloud, PipeLLM e OpenRouter. Eles acrescentam um ajuste de complexidade (baixa, média ou alta), edições guiadas por marcações que você desenha, e saída em SVG ou GIF animado. SVG e GIF criam uma imagem nova a partir das suas palavras; não editam a atual.

## Fornecedores

O [catálogo de fornecedores de imagem](/pt-br/providers/catalog) inclui OpenAI, Gemini, xAI, OpenRouter, PipeLLM, Pollinations, Kie.ai, Topview, Azure, Together e as versões Enconvo Cloud quando oferecidas. O fornecedor OpenAI também funciona com o login do ChatGPT como credencial. O que um fornecedor pode fazer depende do modelo: o nome do fornecedor sozinho não promete todos os modos de edição.

## Solução de problemas

| Problema | O que fazer |
| --- | --- |
| A imagem não é gerada | Confira o acesso e o modelo do fornecedor e leia o erro dele |
| Uma edição ignora a sua imagem | Confira se o modelo aceita entrada de imagem e se o arquivo está anexado à mensagem |
| O arquivo de entrada é recusado | Confira se o fornecedor suporta o formato do arquivo |
| GPT Image 2.6 não é oferecido com o login do ChatGPT | A OpenAI não o serve aos planos do ChatGPT; use uma chave de API da OpenAI ou o Enconvo Cloud |
| Um ajuste que você quer não está no editor | O modelo escolhido não o aceita; escolha outro modelo |

## Requirements

Current Enconvo builds target **macOS 14 or later**. Download the build appropriate for Apple Silicon or Intel from [enconvo.com](https://www.enconvo.com). On-device MLX features require Apple Silicon; individual local models also need sufficient memory and disk space.

## Install

1. Download the DMG from the official website.
2. Open it and drag **Enconvo** into **Applications**.
3. Launch the copy in Applications.
4. Complete the app's onboarding and connect a model using the [Quick Start](/quickstart).
5. Grant feature permissions when prompted. See [macOS Permissions](/configuration/permissions) for what each permission enables.

Keep the app in Applications so launch shortcuts, permissions, and updates refer to a consistent copy.

## Update

Use **Check for Updates** from the Enconvo menu bar item. Choose **Production**, **Beta**, or **Dev** under **Settings → General → Updates**. See [Updates](/configuration/updates) for channel behavior.

App and extension versions are separate. If a feature is absent or an integration behaves differently, check both the app and installed extension updates.

## Common installation problems

| Problem | Next step |
| --- | --- |
| The app does not launch | Confirm macOS compatibility and that the download finished |
| Permissions appear enabled but do not work | Quit and reopen the running copy; avoid launching a different old copy |
| Local model fails to download | Check disk space, connectivity, and that the selected runtime supports your Mac |
| You cannot find the app window | Use the menu bar item or configured SmartBar shortcut |

If macOS reports that the download is damaged or untrusted, obtain a fresh installer from the official website instead of disabling system security controls.

---
title: "Variables"
description: "Insert your current input, selected text, app context, or the date into prompts and other fields that accept templates."
---

Variables fill in values that change each time, such as the text you typed in SmartBar, the text selected in another app, or today's date. Use them in prompts and preferences that support templating, so one AI Command, Agent instruction, or workflow works on whatever you have in front of you. Open **Settings → Variables** to browse the available variables.

## Available variables

| Variable | Value supplied |
| --- | --- |
| Input Text | Current SmartBar input |
| Selection Text | Text selected in the current app |
| Latest Clipboard | Most recent clipboard content |
| Active Application | Frontmost app information |
| Active Application Screenshot | Image of the frontmost window |
| Active Screen Screenshot | Image of the active screen |
| Focused Window Content | Content extracted from the focused window |
| Browser Active Tab | Active tab URL and available page content |
| Current Folder | The folder open in Finder |
| Selected Files | Files selected in Finder |
| History Messages | Current conversation history |
| Now | Current date and time |
| Your Language | The language you read: your **Response Language**, or the system language when it is Auto |
| Opened Applications | Running app information |
| Opened Application Names | Names of the running apps |

## Use a variable

1. Open the AI Command, Agent instruction, or workflow field you want to customize.
2. Check that the field supports variables; use its picker when it has one.
3. Insert the value you need and test with harmless sample content.
4. Check whether an empty input or a missing permission changes the result.

A text prompt can use supported template names such as:

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Which variables you can use depends on the command and context, and not every text field evaluates templates. Screenshots and app content can need macOS permissions and a model that accepts that kind of input.

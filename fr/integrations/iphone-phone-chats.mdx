Les discussions du téléphone sont les discussions propres à l’app iPhone. Elles s’exécutent sur le téléphone, pas sur votre Mac, et fonctionnent donc sans Mac jumelé. Chaque discussion du téléphone utilise un modèle via des points Enconvo Cloud, votre propre clé API ou une offre à laquelle vous vous connectez sur l’iPhone. Les discussions du téléphone et les instructions personnelles se synchronisent via votre compte Enconvo.

Pour poursuivre plutôt une discussion qui s’exécute sur votre Mac, consultez [App iPhone](/fr/integrations/iphone-app).

## Choisir le modèle par défaut

1. Sur l’iPhone, ouvrez **Réglages → Modèle d’IA**.
2. Touchez **Modèle par défaut** et choisissez un modèle. Les nouvelles discussions démarrent avec lui.
3. Pour changer le modèle d’une discussion, utilisez le sélecteur de modèle de cette discussion.

Enconvo sur votre Mac démarre avec le même modèle lorsque le Mac dispose de ce fournisseur. Si le modèle du Mac n’est pas disponible sur l’iPhone, la page l’indique sous **Modèle par défaut** et suggère ce qu’il faut ajouter ou à quoi se connecter.

## Ajouter une clé ou un fournisseur

**Modèle d’IA** liste Enconvo Cloud et chaque fournisseur utilisable sur le téléphone, PipeLLM compris.

1. Touchez un fournisseur, puis **Ajouter une clé API**, et collez une clé que vous avez créée sur le site du fournisseur.
2. Pour ajouter un fournisseur qui n’est pas dans la liste, touchez **Ajouter un fournisseur** et choisissez un fournisseur, **Compatible OpenAI** ou **Compatible Anthropic**. Un fournisseur compatible nécessite l’adresse d’un serveur qui parle l’API Chat Completions ou Responses d’OpenAI, ou l’API Messages d’Anthropic.
3. Si un fournisseur ne liste pas un modèle dont vous avez besoin, touchez **Ajouter un modèle par ID** sur sa page.

Les clés restent dans votre trousseau iCloud et ne sont envoyées qu’au fournisseur auquel elles appartiennent.

## Se connecter avec une offre

Cinq fournisseurs permettent aux discussions du téléphone d’utiliser une offre que vous payez déjà, sans clé API et sans points Cloud :

| Fournisseur | Offre | Bouton |
| --- | --- | --- |
| OpenAI | ChatGPT | **Se connecter avec ChatGPT** |
| xAI | Grok | **Se connecter avec Grok** |
| Mistral | Le Chat | **Se connecter avec Mistral** |
| GitHub Copilot | Copilot | **Se connecter avec GitHub** |
| Antigravity | Antigravity (Google) | **Se connecter avec Google** |

<Steps>
  <Step title="Ouvrir le fournisseur">
    Dans **Réglages → Modèle d’IA**, touchez le fournisseur. Pour OpenAI, xAI et Mistral, choisissez la carte de l’offre sous **Authentification**. L’autre carte est **Clé API**, et **En cours d’utilisation** marque celle qu’utilisent actuellement les discussions du téléphone.
  </Step>
  <Step title="Se connecter">
    Touchez le bouton de connexion et terminez la connexion sur la page qui s’ouvre. Utilisez le compte qui possède l’offre.
  </Step>
  <Step title="Vérifier le résultat">
    De retour sur la page du fournisseur, vous voyez votre offre, votre compte et le nombre de modèles inclus dans votre offre. Choisissez un modèle, ou touchez **Définir par défaut** pour y faire démarrer les nouvelles discussions.
  </Step>
</Steps>

La connexion à une offre reste sur cet iPhone. Elle ne se synchronise ni vers iCloud ni vers votre Mac, et le Mac garde sa propre connexion. Les limites d’utilisation propres à l’offre s’appliquent.

### GitHub Copilot

Après **Se connecter avec GitHub**, l’app affiche un code GitHub. **Continuer** copie le code et ouvre la page de GitHub, où vous le collez et autorisez Enconvo. Le code reste à l’écran tant que la page de GitHub est ouverte, vous pouvez donc le copier à nouveau.

La liste des modèles n’affiche que les modèles que votre offre Copilot peut utiliser. Copilot Free propose moins de modèles que les offres payantes.

### Antigravity

Avant chaque connexion, l’app affiche **Avant de vous connecter à Antigravity**. Enconvo se connecte avec le client Google propre à l’app Antigravity, et Google peut suspendre un compte Antigravity qu’il voit utilisé en dehors d’Antigravity. Utilisez un compte que vous pouvez vous permettre de perdre. **Accepter** passe à la connexion Google, et **Annuler** laisse tout comme avant.

Antigravity propose les modèles Gemini et Claude de votre offre, chacun avec les niveaux d’effort de raisonnement qu’Antigravity prévoit pour lui.

### Utilisation de ChatGPT

La page d’OpenAI montre ce qui reste des limites sur 5 heures et hebdomadaires de votre offre ChatGPT, quand chaque limite se réinitialise et quand l’offre se renouvelle. Touchez **Actualiser l’utilisation** dans le menu du compte pour la mettre à jour. Quand une limite est épuisée, la page l’indique jusqu’à sa réinitialisation.

### Se déconnecter

Ouvrez le fournisseur et choisissez **Se déconnecter** dans le menu du compte. Les discussions qui utilisent l’offre ont besoin d’un autre modèle après la déconnexion. Pour Mistral, la clé créée par la connexion reste dans votre espace de travail Mistral.

## Continuer à répondre après avoir quitté l’app

Avec un modèle Enconvo Cloud, une réponse peut continuer après que vous avez quitté l’app ou verrouillé le téléphone. Dans les **Outils Cloud** de la zone de message, activez **Exécuter dans le cloud**. Les discussions sur vos propres clés répondent toujours sur le téléphone.

## Continuer sur votre ordinateur

Déplacez une discussion du téléphone vers un ordinateur jumelé pour la poursuivre là-bas avec l’agent, les fichiers et les outils de cet ordinateur. Cela fonctionne même pendant qu’une réponse est encore en cours.

1. Ouvrez le menu de la discussion, ou maintenez la discussion dans la barre latérale, et choisissez **Continuer sur l’ordinateur**. Le menu nomme l’ordinateur vers lequel elle va par défaut.
2. Choisissez l’ordinateur et l’agent, puis confirmez.

La discussion passe sur cet ordinateur et continue là-bas. Ouvrir le lien d’une discussion partagée demande aussi où la poursuivre.

## Discussion vocale depuis le bouton Action

Quand le bouton Action démarre une discussion vocale, la Dynamic Island demande **Laisser Enconvo voir votre écran ?** Choisissez **Voix seule**, ou **Partager l’écran** pour qu’Enconvo voie ce que vous lisez. Le bouton **Partager l’écran** dans les commandes d’appel démarre ou arrête le partage en cours d’appel.

## Effort de raisonnement

Quand vous choisissez un modèle qui réfléchit, le sélecteur passe à ses efforts de raisonnement. L’effort que vous choisissez pour un modèle s’affiche à côté de son fournisseur dans l’en-tête de la discussion et s’applique à toutes les discussions sur ce modèle. La page d’une offre ne liste que les niveaux que votre offre propose.

## Longues discussions

Quand une longue discussion approche de la fenêtre de contexte de son modèle, le même modèle résume les messages plus anciens, comme sur le Mac. La discussion conserve chaque message, et une marque **Contexte compacté** indique où commence le résumé. Cette fonction est toujours activée.

## Dépannage

| Ce que vous voyez | Que faire |
| --- | --- |
| **La connexion ChatGPT n’a pas abouti** (ou Grok, Mistral, GitHub Copilot, Antigravity) | Touchez **Se reconnecter** et terminez la connexion sur la page qui s’ouvre. |
| **Votre offre ne propose pas** un modèle | Choisissez un autre modèle dans la liste de l’offre. Sur Copilot Free, seuls certains modèles sont proposés. |
| **Récupération des modèles…** ne se termine pas | Vérifiez la connexion réseau de l’iPhone, puis quittez la page du fournisseur et rouvrez-la. |
| Le modèle par défaut du Mac n’est pas sur l’iPhone | Ajoutez la clé du fournisseur, ou connectez-vous à son offre, comme le suggère la note sous **Modèle par défaut**. |

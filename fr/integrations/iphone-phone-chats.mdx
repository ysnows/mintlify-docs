Les chats du téléphone sont les chats propres à l’app iPhone. Ils tournent sur le téléphone, pas sur votre Mac, donc ils fonctionnent sans Mac jumelé. Chaque chat du téléphone utilise un modèle via les points Enconvo Cloud, votre propre clé API, ou un forfait auquel vous vous connectez sur l’iPhone. Les chats du téléphone et les instructions personnelles se synchronisent via votre compte Enconvo.

Pour continuer un chat qui tourne sur votre Mac, voir [App iPhone](/fr/integrations/iphone-app).

## Choisir le modèle par défaut

1. Sur l’iPhone, ouvrez **Réglages → Modèle IA**.
2. Touchez **Modèle par défaut** et choisissez un modèle. Les nouveaux chats commencent avec lui.
3. Pour changer le modèle d’un chat, utilisez le sélecteur de modèle dans ce chat.

Enconvo sur votre Mac démarre avec le même modèle quand le Mac a ce fournisseur. Si le modèle du Mac n’est pas disponible sur l’iPhone, la page le dit sous **Modèle par défaut**, et suggère quoi ajouter ou à quoi se connecter.

## Ajouter une clé ou un fournisseur

**Modèle IA** liste Enconvo Cloud et chaque fournisseur que vous pouvez utiliser sur le téléphone, PipeLLM compris.

1. Touchez un fournisseur, puis **Ajouter une clé API**, et collez une clé créée sur le site du fournisseur.
2. Pour ajouter un fournisseur qui n’est pas dans la liste, touchez **Ajouter un fournisseur** et choisissez un fournisseur, **Compatible OpenAI**, ou **Compatible Anthropic**. Un fournisseur compatible a besoin de l’adresse d’un serveur qui parle l’API Chat Completions ou Responses d’OpenAI, ou l’API Messages d’Anthropic.
3. Si un fournisseur ne liste pas un modèle dont vous avez besoin, touchez **Ajouter un modèle par ID** sur sa page.

Les clés restent dans votre trousseau iCloud et ne sont envoyées qu’au fournisseur auquel elles appartiennent.

## Se connecter avec un forfait

Cinq fournisseurs permettent aux chats du téléphone d’utiliser un forfait que vous payez déjà, sans clé API et sans points Cloud :

| Fournisseur | Forfait | Bouton |
| --- | --- | --- |
| OpenAI | ChatGPT | **Se connecter avec ChatGPT** |
| xAI | Grok | **Se connecter avec Grok** |
| Mistral | Le Chat | **Se connecter avec Mistral** |
| GitHub Copilot | Copilot | **Se connecter avec GitHub** |
| Antigravity | Antigravity (Google) | **Se connecter avec Google** |

<Steps>
  <Step title="Ouvrir le fournisseur">
    Dans **Réglages → Modèle IA**, touchez le fournisseur. Pour OpenAI, xAI et Mistral, choisissez la carte du forfait sous **Authentification**. L’autre carte est **Clé API**, et **En cours d’utilisation** marque celle que les chats du téléphone utilisent maintenant.
  </Step>
  <Step title="Se connecter">
    Touchez le bouton de connexion et terminez la connexion sur la page qui s’ouvre. Utilisez le compte qui a le forfait.
  </Step>
  <Step title="Vérifier le résultat">
    De retour sur la page du fournisseur, vous voyez votre forfait, votre compte, et combien de modèles sont sur votre forfait. Choisissez un modèle, ou touchez **Définir par défaut** pour commencer les nouveaux chats avec lui.
  </Step>
</Steps>

La connexion d’un forfait reste sur cet iPhone. Elle ne se synchronise pas vers iCloud ni vers votre Mac, et le Mac garde sa propre connexion. Les limites d’usage propres au forfait s’appliquent.

### GitHub Copilot

Après **Se connecter avec GitHub**, l’app affiche un code GitHub. **Continuer** copie le code et ouvre la page de GitHub, où vous le collez et autorisez Enconvo. Le code reste à l’écran tant que la page de GitHub est ouverte, donc vous pouvez le copier à nouveau.

La liste des modèles n’affiche que les modèles que votre forfait Copilot peut utiliser. Copilot Free offre moins de modèles que les forfaits payants.

### Antigravity

Avant chaque connexion, l’app affiche **Avant de vous connecter à Antigravity**. Enconvo se connecte avec le propre client Google de l’app Antigravity, et Google peut suspendre un compte Antigravity qu’il voit utilisé en dehors d’Antigravity. Utilisez un compte que vous pouvez vous permettre de perdre. **Accepter** continue vers la connexion Google, et **Annuler** laisse tout comme c’était.

Antigravity propose les modèles Gemini et Claude de votre forfait, chacun avec les niveaux d’effort de raisonnement qu’Antigravity a pour lui.

### Usage ChatGPT

La page d’OpenAI montre combien il reste des limites de 5 heures et hebdomadaire de votre forfait ChatGPT, quand chaque limite se réinitialise, et quand le forfait se renouvelle. Touchez **Actualiser l’utilisation** dans le menu du compte pour la mettre à jour. Quand une limite est épuisée, la page le dit jusqu’à sa réinitialisation.

### Se déconnecter

Ouvrez le fournisseur et choisissez **Se déconnecter** dans le menu du compte. Les chats qui utilisent le forfait ont besoin d’un autre modèle après la déconnexion. Pour Mistral, la clé créée par la connexion reste dans votre espace de travail Mistral.

## Continuer de répondre après avoir quitté l’app

Avec un modèle Enconvo Cloud, une réponse peut continuer après que vous quittez l’app ou verrouillez le téléphone. Dans **Outils cloud** de la zone de message, activez **Exécuter dans le cloud**. Les chats sur vos propres clés répondent toujours sur le téléphone.

## Continuer sur votre ordinateur

Déplacez un chat du téléphone vers un ordinateur jumelé pour continuer là avec l’agent, les fichiers et les outils de cet ordinateur. Cela fonctionne même pendant qu’une réponse tourne encore.

1. Ouvrez le menu du chat, ou maintenez le chat dans la barre latérale, et choisissez **Continuer sur l’ordinateur**. Le menu nomme l’ordinateur vers lequel il va par défaut.
2. Choisissez l’ordinateur et l’agent, et confirmez.

Le chat se déplace vers cet ordinateur et y continue. Ouvrir le lien d’un chat partagé demande aussi où le continuer.

## Chat vocal depuis le bouton Action

Quand le bouton Action démarre un chat vocal, Dynamic Island demande **Autoriser Enconvo à voir votre écran ?** Choisissez **Voix uniquement**, ou **Partager l’écran** pour qu’Enconvo voie ce que vous lisez. Le bouton **Partager l’écran** dans les commandes de l’appel démarre ou arrête le partage en cours d’appel.

## Effort de raisonnement

Quand vous choisissez un modèle qui réfléchit, le sélecteur continue vers ses efforts de raisonnement. L’effort que vous choisissez pour un modèle s’affiche à côté de son fournisseur dans l’en-tête du chat et s’applique à chaque chat sur ce modèle. La page d’un forfait ne liste que les niveaux que votre forfait offre.

## Longs chats

Quand un long chat approche de la fenêtre de contexte de son modèle, le même modèle résume les messages plus anciens, comme sur le Mac. Le chat garde chaque message, et une marque **Contexte compacté** montre où le résumé commence. C’est toujours activé.

## Dépannage

| Ce que vous voyez | Que faire |
| --- | --- |
| **La connexion ChatGPT ne s’est pas terminée** (ou Grok, Mistral, GitHub Copilot, Antigravity) | Touchez **Se reconnecter** et terminez la connexion sur la page qui s’ouvre. |
| **Votre forfait ne propose pas** un modèle | Choisissez un autre modèle dans la liste du forfait. Sur Copilot Free, seuls certains modèles sont proposés. |
| **Liste des modèles…** ne se termine pas | Vérifiez la connexion réseau de l’iPhone, puis quittez la page du fournisseur et rouvrez-la. |
| Le modèle par défaut du Mac n’est pas sur l’iPhone | Ajoutez la clé du fournisseur, ou connectez-vous à son forfait, comme le suggère la note sous **Modèle par défaut**. |

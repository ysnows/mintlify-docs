L'app Enconvo iPhone se jumelle avec votre Mac, pour que les projets et les chats de votre Mac soient sur votre téléphone. Chaque chat que vous ouvrez depuis le téléphone continue de tourner sur votre Mac, avec ses fichiers, ses apps et ses agents. Ce tutoriel jumelle un téléphone du début à la fin : connectez-vous, affichez le code de jumelage sur le Mac, et scannez-le avec l'iPhone.

<YouTubePlayer videoId="rYhgz_SjnNs" title="Comment jumeler votre iPhone avec votre Mac dans Enconvo" />

La vidéo dure 1 minute 12 secondes. Les étapes écrites ci-dessous suivent le même ordre, avec l'horodatage correspondant à chaque étape.

<Note>
L'app iPhone est en bêta. Installez-la depuis [TestFlight](https://testflight.apple.com/join/MJQuEN28), ou scannez le code TestFlight sous **Télécharger l'app mobile** dans **Réglages → Connexions** sur votre Mac. Le jumelage exige Enconvo 2.5.6 bêta ou une version ultérieure sur le Mac. L'app iPhone sur TestFlight et l'app Android sur Google Play sont disponibles dans les Amériques, l'Europe, le Moyen-Orient, le Japon, la Corée et l'Asie du Sud-Est. L'APK Android s'installe partout.
</Note>

## Jumeler votre iPhone

Pour jumeler avec un PC Windows, un bureau Linux ou un serveur Linux qui n'a qu'un terminal, voir [Jumeler avec votre téléphone](/fr/integrations/pair-your-phone).

<Steps>
  <Step title="Se connecter sur votre iPhone (0:07)">
    Installez l'app iPhone et connectez-vous avec le même compte Enconvo que votre Mac : avec Apple, avec Google, ou avec un code à 6 chiffres envoyé par e-mail. Seuls les téléphones connectés à votre compte peuvent se jumeler avec lui. Un compte gratuit peut se jumeler, utiliser les chats du Mac et l'Écran distant, et utiliser l'Avatar.
  </Step>
  <Step title="Afficher le code de jumelage (0:16)">
    Sur le Mac, ouvrez **Réglages → Connexions** et sélectionnez **Afficher le code de jumelage**. Le code QR est valable cinq minutes. S'il expire, sélectionnez **Afficher un nouveau code**.
  </Step>
  <Step title="Le scanner avec votre iPhone (0:22)">
    Sur le téléphone, ouvrez **À distance** et touchez **Associer un ordinateur** (**Pair a Mac** dans la vidéo), puis pointez l'appareil photo vers le code sur votre Mac. L'appareil photo de l'iPhone fonctionne aussi : il ouvre Enconvo, et vous confirmez le Mac là. Les deux se jumellent en un instant. Votre téléphone atteint le Mac via le relais Enconvo, et les messages sont chiffrés de bout en bout.
  </Step>
  <Step title="Votre Mac, sur votre téléphone (0:34)">
    Une fois que le Mac s'affiche comme **En ligne** dans À distance, ses projets et ses chats sont là, sur votre téléphone.
  </Step>
  <Step title="Ouvrir n'importe quel chat (0:40)">
    Ouvrez n'importe quel chat et reprenez là où vous vous étiez arrêté. Le chat tourne toujours sur votre Mac, donc il peut utiliser les fichiers, les apps et les agents de ce Mac.
  </Step>
  <Step title="Le garder joignable (0:47)">
    Dans **Connexions** (ou **Réglages → Rester éveillé**), activez **Empêcher la mise en veille de ce Mac**. Cela empêche le Mac de se mettre en veille, sur batterie aussi, pour que votre téléphone puisse toujours l'atteindre. Vous pouvez aussi garder l'écran allumé, le faire s'éteindre après un délai, ou garder le Mac éveillé capot fermé (cela demande une fois le mot de passe administrateur).
  </Step>
  <Step title="Retirer un téléphone (0:52)">
    Téléphone perdu ? Dans **Connexions → Téléphones jumelés**, sélectionnez **Supprimer** à côté. Ce téléphone ne peut plus atteindre votre Mac. Pour l'utiliser à nouveau, jumelez-le avec un nouveau code.
  </Step>
</Steps>

Quand le Mac le dit sous le code, le scanner connecte aussi l'iPhone à votre compte Enconvo. Ne scannez un tel code qu'avec votre propre iPhone.

## Ce que vous pouvez faire depuis votre téléphone

Une fois jumelé, vous pouvez :

- Parcourir les projets et les chats de votre Mac, et continuer n'importe quel chat.
- Répondre aux questions qu'un agent pose pendant qu'il travaille sur votre Mac.
- Être averti quand un chat se termine, et répondre depuis la notification.
- Voir et contrôler l'écran de votre Mac avec **Écran distant**.
- Discuter avec des modèles d'IA sur le téléphone lui-même, avec les points Enconvo Cloud, votre propre clé API, ou un forfait auquel vous vous connectez (ChatGPT, Grok, Le Chat, GitHub Copilot ou Antigravity). Voir [Chats du téléphone](/fr/integrations/iphone-phone-chats).
- Discuter et appeler des amis et des coéquipiers, et rejoindre une visioconférence. Voir [Appels et amis sur votre téléphone](/fr/integrations/phone-calls-and-friends).

L'app appelle un Mac, un PC Windows ou une machine Linux jumelé votre **ordinateur**. L'app Android fonctionne de la même façon, sauf si une section dit le contraire.

## Travailler dans les chats de votre ordinateur

Un chat de votre ordinateur se présente et fonctionne comme là-bas, avec les tâches d'arrière-plan, les sous-agents et le pilotage.

- **Accueil** affiche vos chats actifs juste au-dessus de la zone de message. Balayez la poignée de la carte vers le haut, ou touchez **Tous**, pour voir chaque chat actif regroupé selon ce qui a besoin de vous, ce qui tourne et ce qui a des résultats.
- Le groupe **Actif** de la barre latérale rassemble les chats qui vous attendent, ont échoué, tournent encore ou gardent un résultat non lu. Un point bleu marque un résultat que personne n'a lu, et un anneau qui tourne un chat en cours. **Épinglés** et **Récents** se replient.
- Ce que vous envoyez pendant qu'une réponse tourne pilote la tâche en cours, comme Retour le fait sur le Mac. La zone affiche alors « Orientez la tâche en cours… ».
- Touchez un sous-agent pour ouvrir ses étapes dans une feuille au-dessus du chat. Elle s'ouvre à l'étape la plus récente et suit la nouvelle sortie. Balayez vers le bas pour la fermer.
- Les questions d'approbation proposent les propres choix de l'agent, comme sur le Mac.
- Pour changer l'agent d'un chat, touchez l'agent sous le titre du chat. **Créer une branche à partir d'ici** vous laisse choisir l'agent de la branche.
- La feuille du modèle affiche le forfait de votre abonnement, ses limites de 5 heures et hebdomadaire avec ce qu'il reste et quand elles se réinitialisent, et la limite propre d'un modèle sur sa ligne.
- Joignez des photos et des vidéos depuis la photothèque. Les vidéos vont à l'ordinateur telles quelles.
- Dans **Réglages → Avatar** de l'app, choisissez si le bouton d'appel de la zone de message affiche l'avatar ou l'icône des barres vocales.

Quand votre ordinateur est hors ligne ou se reconnecte encore, vous pouvez toujours envoyer : le téléphone répond à ce qu'il peut, comme les questions et les recherches web, et envoie les messages qui ont besoin de l'ordinateur une fois qu'il se connecte.

Un document ou un lien que le téléphone ne peut pas ouvrir dit de l'ouvrir sur votre ordinateur.

## Utiliser l'écran de votre ordinateur

Touchez l'icône d'affichage en haut à droite d'**Accueil**, ou **Écran distant** dans le menu d'un chat, pour voir l'écran de votre ordinateur et le contrôler.

| Mode | Effet d'un toucher |
| --- | --- |
| **Trackpad** | Glissez n'importe où pour déplacer le pointeur, et touchez pour cliquer là où est le pointeur. Des indices enseignent les gestes à mesure que vous les utilisez. |
| **Toucher** | Touchez là où vous voulez cliquer. |
| **Regarder seulement** | Rien : vous ne faites que regarder. |

Le bouton de mode affiche le nom du mode actuel. Pincez pour zoomer ; en **Trackpad**, l'image zoome autour du pointeur et le suit.

Pour garder l'écran flottant pendant que vous faites autre chose, touchez le bouton Image dans l'image en haut à gauche, ou pincez vers l'intérieur. L'écran flotte au-dessus de vos chats, et au-dessus des autres apps quand vous quittez Enconvo.

Pendant un appel Live Talk, l'outil **Écran distant** ouvre l'écran dans une petite fenêtre flottante au-dessus de l'appel. Il fonctionne comme un trackpad, avec une pastille de mode pour passer à **Toucher** ou **Regarder seulement**, un bouton clavier pour taper sur l'ordinateur, et **Plein écran** pour ouvrir la vue habituelle.

## Notifications

- La notification d'une réponse terminée montre le début de la réponse. Utilisez **Répondre** dessus pour répondre sans ouvrir l'app.
- Aucune notification n'arrive tant que l'app est ouverte, ou tant que vous utilisez votre Mac, sauf si vous avez envoyé ce message depuis le téléphone.
- Une fois que vous avez lu un chat terminé sur un appareil, sa notification disparaît des autres. Une question qui attend encore une réponse reste.
- Sur Android 14 et versions ultérieures, activez **Notifications plein écran** dans les Réglages de l'app si Android les a désactivées.

## Partager vers Enconvo

Partagez une page, une photo ou un fichier vers Enconvo depuis une autre app, et la feuille **Envoyer à** vous laisse choisir un nouveau chat ou n'importe quel chat récent. Activez **Toujours partager dans une nouvelle discussion** dans la feuille, ou dans les Réglages de l'app, pour sauter la question.

## Projets et artefacts

- Ouvrez les **Idées** et le **Tableau** d'un projet, changez ses réglages, démarrez un **Nouveau projet**, et agissez sur une carte de plan de travail : répondre, fusionner, démarrer ou réessayer une tâche, ouvrir une pull request, ou noter et démarrer une idée.
- Le menu `@` liste les membres du projet, les flux de travail et les agents qui peuvent rejoindre.
- Les decks, tableaux de bord et films Motion s'ouvrent depuis un chat ou la bibliothèque d'artefacts, où vous pouvez commenter, demander à @Enconvo, partager, exporter et présenter.

## App Android

L'app Android se jumelle et fonctionne de la même façon. Connectez-vous avec Google ou un code à 6 chiffres envoyé par e-mail. La zone de message tient sur une ligne, avec un bouton appareil photo, des pastilles rapides pour l'ordinateur, le projet et les **Compétences**, et un panneau plus avec les photos et vidéos récentes.

L'app Android téléchargée depuis enconvo.com vérifie les mises à jour à chaque ouverture. **Ignorer cette version** masque une version jusqu'à ce qu'une plus récente sorte ; **Plus tard** masque l'alerte jusqu'à la prochaine ouverture de l'app.

## Gérer les téléphones jumelés

**Réglages → Connexions** liste chaque téléphone jumelé et montre si les téléphones peuvent atteindre ce Mac maintenant.

| Tâche | Comment |
| --- | --- |
| Jumeler un autre téléphone | Sélectionnez **Jumeler un autre téléphone** et scannez le nouveau code. Un Mac peut avoir jusqu'à 10 téléphones jumelés. |
| Renommer un téléphone | Cliquez sur le téléphone, puis sur **Renommer le téléphone** à côté de son nom. |
| Retirer un téléphone | Sélectionnez **Supprimer** à côté dans **Téléphones jumelés**. |
| Recommencer | Sélectionnez **Réinitialiser la connexion**. Enconvo crée une nouvelle clé de connexion et retire chaque téléphone jumelé. Chaque téléphone scanne alors un nouveau code. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le téléphone ne peut pas atteindre votre Mac | Vérifiez que le Mac est éveillé, connecté et en ligne, et que **Connexions** l'affiche comme **En ligne**. Activez **Empêcher la mise en veille de ce Mac** pour qu'il reste joignable. |
| Le téléphone dit que le Mac a refusé un message, l'écran ou le terminal | Le Mac n'a pas d'accès Appareil pour lui. Suivez les étapes que le téléphone affiche. |
| Le code dit **Ce code a expiré** | Sélectionnez **Afficher un nouveau code** et scannez à nouveau dans les cinq minutes. |
| Le Mac dit **Connectez-vous pour jumeler un téléphone** | Cliquez sur **Se connecter** et connectez-vous sur le Mac. Votre iPhone et votre Mac doivent utiliser le même compte Enconvo. |
| Le Mac dit qu'il **a besoin d'une nouvelle clé de connexion** | Le relais a une clé différente pour ce Mac, par exemple après une restauration depuis une sauvegarde. Sélectionnez **Réinitialiser la connexion**, puis jumelez à nouveau chaque téléphone. |
| **L'accès à Companion a été désactivé** | L'accès a été désactivé depuis un de vos appareils, et aucun téléphone ne peut atteindre vos Mac tant que vous ne sélectionnez pas **Réactiver l'accès**. |

title: "OCR"
description: "Copiez le texte de n’importe quelle partie de votre écran ou d’une image, lu sur votre Mac ou par un service en ligne."
---

L’OCR lit le texte d’une capture d’écran ou d’une image, pour que vous puissiez le copier, le coller, le traduire ou poser une question dessus. Utilisez-le quand vous ne pouvez pas sélectionner le texte, comme dans une image, une image vidéo ou une page numérisée. Vous choisissez si le texte est lu sur votre Mac ou par un service en ligne.

## Avant de commencer

Enconvo a besoin de l’autorisation Enregistrement de l’écran pour capturer votre écran. Voir [Autorisations](/fr/configuration/permissions).

## Copier le texte de l’écran

1. Lancez **OCR de capture d’écran** depuis SmartBar.
2. Faites glisser sur la zone qui contient le texte.
3. Le texte s’ouvre dans la Dynamic Island. Cliquez sur **Copier**, ou sur **Coller** (**⌘↩**) pour le placer dans l’app que vous utilisez.

Depuis le même résultat, vous pouvez aussi cliquer sur **Traduire** ou **Demander à l’IA**. Le menu **⋯** contient **Conserver les retours à la ligne d’origine**, **Copier l’image**, **Enregistrer l’image…**, **Resélectionner la zone**, **Ajouter à la base de connaissances** et **Réglages OCR…**.

Pour relire la zone avec un autre fournisseur, cliquez sur le nom du fournisseur au-dessus du texte et choisissez-en un. Quand le fournisseur sait où se trouve chaque ligne, passez à la vue image pour sélectionner des lignes sur la capture, puis cliquez sur **Copier la sélection**.

## Autres commandes OCR

| Commande | Ce qu’elle fait |
| --- | --- |
| **OCR de capture d’écran** | Lit une zone de l’écran et ouvre le texte dans la Dynamic Island |
| **OCR de capture silencieux** | Lit une zone de l’écran et copie le texte dans le presse-papiers |
| **OCR** | Lit le texte d’une image que vous lui donnez |
| **Traduction de capture** | Traduit une zone de l’écran. Voir [Traduction](/fr/ai/translate) |
| **Explication de capture** | Explique une zone de l’écran. Voir [Boîte à outils d’écriture](/fr/features/writing-tools) |

## Choisir un fournisseur

Ouvrez **Réglages → OCR**, choisissez un fournisseur et cliquez sur **Définir par défaut**.

| Fournisseur | Où le texte est lu |
| --- | --- |
| **OCR natif Apple** | Sur votre Mac, avec la reconnaissance de texte d’Apple |
| **PP-OCRv6 (MLX)** | Sur votre Mac, avec les modèles de détection et de reconnaissance PaddleOCR sur Apple silicon. Rien ne quitte votre Mac |
| **OCR par modèle d’IA** | Par le modèle d’IA que vous choisissez, selon son **Instruction** |
| **Mistral OCR** | Par le service en ligne de Mistral, avec votre clé Mistral ou votre connexion Mistral |
| **Mistral OCR (forfait Enconvo Cloud)** | Par le service en ligne de Mistral, via votre forfait Enconvo Cloud |

Chaque commande OCR peut aussi utiliser son propre fournisseur : réglez **Fournisseur OCR** dans ses réglages sous **Réglages → Plugins → OCR**. Voir [Catalogue des fournisseurs](/fr/providers/catalog) pour les champs de chaque fournisseur.

## Obtenir de meilleurs résultats

Capturez une zone serrée et lisible, à une taille où le texte se lit facilement. Vérifiez à la main les colonnes, les tableaux, la ponctuation, l’indentation du code et les caractères qui se ressemblent.

Un document numérisé peut avoir besoin de l’OCR même quand c’est un fichier PDF.

## Dépannage

| Problème | Que faire |
| --- | --- |
| La capture est vide ou ne démarre pas | Vérifiez l’autorisation Enregistrement de l’écran dans [Autorisations](/fr/configuration/permissions) |
| **Aucun texte trouvé** | Cliquez sur **Resélectionner la zone** et choisissez une zone plus serrée. L’écriture manuscrite ou un caractère stylisé peut mieux se lire avec **Essayer l’OCR par modèle d’IA** |
| **Lecture impossible** | Cliquez sur **Réessayer**, essayez une image simple et lisez l’erreur du fournisseur. **Réglages** ouvre les réglages OCR |
| Les lignes se suivent ou se coupent au mauvais endroit | Activez ou désactivez **Conserver les retours à la ligne d’origine** dans le menu **⋯**, ou relisez la zone avec un autre fournisseur |
| Vous voulez poser une question sur quelque chose à l’écran, pas copier son texte | Utilisez [Appshots](/fr/features/appshots) ou le [Dessin à l’écran](/fr/features/screen-doodle) |

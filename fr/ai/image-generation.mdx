Demandez à un Agent dans le chat de créer une image, ou de modifier une image que vous joignez. Enconvo envoie la requête au fournisseur d’images défini dans **Réglages → Génération d’images**, qui est distinct du modèle avec lequel vous discutez.

## Avant de commencer

1. Ouvrez **Réglages → Génération d’images** et choisissez un fournisseur.
2. Définissez son **Fournisseur d’identifiants** (la clé ou le compte qu’il utilise) et son **Nom du modèle**.
3. Cliquez sur **Définir par défaut**.

Les fournisseurs Enconvo Cloud, **OpenAI (Enconvo Cloud)** et **Google Gemini (Enconvo Cloud)**, n’ont pas besoin de clé API personnelle.

## Créer une image

1. Dans une discussion avec un Agent, décrivez le sujet, la composition, le style et l’usage de l’image.
2. Ne demandez une taille, un format ou une qualité que si le modèle les prend en charge.
3. Attendez l’image. La génération peut prendre plus de temps qu’une réponse textuelle.
4. Cliquez sur l’image pour l’ouvrir à côté du chat, où vous pouvez continuer à la modifier.

Exemple :

```text
Create a square illustration for a guide to organizing research.
Show three labeled folders on a tidy desk, with a warm neutral palette.
Leave the top third clear for a title.
```

Vous pouvez aussi choisir **Image** sous la zone de message d’une nouvelle discussion. Le modèle, ses réglages et **À éviter** s’affichent sous forme de pastilles sous la zone de message, ce qui vous permet de les définir avant l’envoi. Pour une bibliothèque de tout ce que vous avez créé, des sujets enregistrés et des corrections en un clic, utilisez [Médias](/fr/features/media).

## Modifier une image

1. Joignez l’image source à votre message, ou cliquez sur une image créée par un Agent pour l’ouvrir dans l’éditeur d’images.
2. Décrivez les modifications précises, et indiquez ce qui doit rester identique.
3. Vérifiez que le résultat ne comporte pas de changements que vous n’avez pas demandés.

Utilisez un modèle qui prend en charge la modification d’images ou les images de référence.

Dans l’éditeur d’images, le panneau de réglages n’affiche que ce que le modèle choisi accepte :

| Réglage | Ce qu’il modifie |
| --- | --- |
| Résolution, format et qualité | La taille et le niveau de détail de la version suivante |
| **À éviter** | Ce qu’il faut exclure, pour les modèles qui acceptent un prompt négatif |
| Variations | Le nombre de versions produites par requête ; vous gardez celles que vous voulez |
| **Zone à modifier** et **Annotations** | Peignez sur l’image pour ne modifier que cette partie, ou dessinez pour guider la modification |
| GIF et **Images** | Une image animée créée à partir de vos mots |

Chaque modification est une nouvelle version, et chaque image est conservée dans [Médias](/fr/features/media) et dans `~/Enconvo/Media`. Pour animer une image, cliquez sur **Créer une vidéo**.

### GPT Image 2.6

GPT Image 2.6 Flare et Sunburst sont disponibles via OpenAI, Enconvo Cloud, PipeLLM et OpenRouter. Ils ajoutent un réglage de complexité (faible, moyenne ou élevée), des modifications guidées par des annotations que vous dessinez, et une sortie SVG ou GIF animé. Le SVG et le GIF créent une nouvelle image à partir de vos mots ; ils ne modifient pas l’image actuelle.

## Fournisseurs

Le [catalogue des fournisseurs d’images](/fr/providers/catalog) comprend OpenAI, Gemini, xAI, OpenRouter, PipeLLM, Pollinations, Kie.ai, Topview, Azure, Together, et leurs versions Enconvo Cloud lorsqu’elles existent. Le fournisseur OpenAI fonctionne aussi avec votre connexion ChatGPT comme identifiant. Ce qu’un fournisseur sait faire dépend du modèle : le nom d’un fournisseur ne garantit pas à lui seul tous les modes de modification.

## Dépannage

| Problème | Que faire |
| --- | --- |
| L’image ne se génère pas | Vérifiez l’accès et le modèle du fournisseur, puis lisez l’erreur du fournisseur |
| Une modification ignore votre image | Vérifiez que le modèle accepte une image en entrée et que le fichier est joint au message |
| Le fichier d’entrée est refusé | Vérifiez que le fournisseur prend en charge le format du fichier |
| GPT Image 2.6 n’est pas proposé avec votre connexion ChatGPT | OpenAI ne le fournit pas aux offres ChatGPT ; utilisez une clé API OpenAI ou Enconvo Cloud |
| Un réglage souhaité n’est pas dans l’éditeur | Le modèle choisi ne l’accepte pas ; choisissez un autre modèle |

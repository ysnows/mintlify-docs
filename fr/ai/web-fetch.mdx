---
title: "Récupérer le contenu web"
description: "Demandez à votre Agent de lire une page web à partir de son URL, ou conservez la page dans une base de connaissances."
---

Utilisez Récupérer le contenu web quand vous avez déjà une URL et voulez que l’Agent lise la page. Chaque Agent peut lire un lien que vous lui donnez ; vous choisissez le service qui le récupère. Utilisez la [Recherche web](/fr/ai/web-search) quand vous devez d’abord trouver des pages pertinentes.

## Choisir un fournisseur

1. Ouvrez **Réglages → Récupérer le contenu web**.
2. Choisissez un fournisseur et cliquez sur **Définir par défaut**.

| Fournisseur | Utilisation |
| --- | --- |
| **Local Fetch** | Récupère gratuitement les pages sur votre Mac, avec une récupération assistée par le navigateur en option |
| **Jina AI Link Reader** | Récupère un contenu lisible via Jina |
| **Firecrawl Link Reader** | Récupère le contenu via Firecrawl |
| **DeepSeek** | Lit les pages en Markdown avec votre clé API DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Lit les pages en Markdown via Enconvo Cloud, sans clé API |
| **Enconvo Cloud Plan** | Utilise le service de lecture de liens du Cloud |

## Lire une page

1. Collez l’URL dans votre conversation et posez une question précise à son sujet.
2. Vérifiez le contenu récupéré et la source avant de vous fier à la réponse.

## Pages protégées par une connexion

Avec **Local Fetch**, **Browser-Assisted Fetching** peut lire une page via un navigateur de la famille Chromium doté de l’extension Enconvo Companion.

| Option | Fonction |
| --- | --- |
| **Automatique** (par défaut) | Réutilise un onglet correspondant que vous avez déjà ouvert, entièrement affiché et avec votre connexion. Utilise un onglet temporaire en arrière-plan quand une récupération directe échoue ou que la page a besoin de JavaScript. |
| **Désactivé** | HTTP direct uniquement |
| **Toujours** | Récupère toujours via le navigateur |

Sans navigateur connecté, Local Fetch effectue une requête HTTP directe. Les autres fournisseurs récupèrent l’URL publique et n’ont pas accès à la session de votre navigateur connecté. Pour les pages interactives, utilisez l’[Extension de navigateur](/fr/features/browser-extension) ou l’[Utilisation du navigateur](/fr/features/browser-control).

## Conserver du contenu web

Ajoutez une URL avec **Ajouter → Page web unique** dans une [Base de connaissances](/fr/ai/knowledge-base) quand vous voulez la retrouver plus tard. Vérifiez la page importée et l’état de son indexation ; les pages web peuvent changer après leur import.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le contenu revient vide | Vérifiez que la page est lisible sans interaction supplémentaire, ou utilisez **Local Fetch** avec **Browser-Assisted Fetching**. Les écrans de connexion, les requêtes bloquées, le contenu chargé dynamiquement et les sites non pris en charge peuvent empêcher l’extraction. |
| La réponse décrit des choses qui ne figurent pas sur la page | Demandez à l’Agent de montrer ce qu’il a réellement récupéré, au lieu de deviner le contenu manquant. |

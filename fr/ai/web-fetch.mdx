---
title: "Récupération web"
description: "Faites lire une page web à votre Agent à partir de son URL, ou gardez la page dans une base de connaissances."
---

Utilisez la récupération web quand vous avez déjà une URL et voulez que l’Agent lise la page. Chaque Agent peut lire un lien que vous lui donnez ; vous choisissez le service qui la récupère. Utilisez la [Recherche web](/fr/ai/web-search) quand vous devez d’abord trouver les pages pertinentes.

## Choisir un fournisseur

1. Ouvrez **Réglages → Récupérer le contenu web**.
2. Choisissez un fournisseur et cliquez sur **Définir par défaut**.

| Fournisseur | Usage |
| --- | --- |
| **Récupération locale** | Récupère des pages sur votre Mac gratuitement, avec une récupération assistée par le navigateur en option |
| **Jina AI Link Reader** | Récupère un contenu lisible via Jina |
| **Firecrawl Link Reader** | Récupère du contenu via Firecrawl |
| **DeepSeek** | Lit les pages en Markdown avec votre clé API DeepSeek |
| **DeepSeek (Enconvo Cloud)** | Lit les pages en Markdown via Enconvo Cloud, sans clé API |
| **Forfait Enconvo Cloud** | Utilise le service de lecture de liens Cloud |

## Lire une page

1. Collez l’URL dans votre conversation et posez une question précise dessus.
2. Vérifiez le contenu récupéré et la source avant de vous fier à la réponse.

## Pages derrière une connexion

Avec **Récupération locale**, la **récupération assistée par le navigateur** peut lire une page via un navigateur de la famille Chromium qui a l’extension Companion d’Enconvo.

| Option | Ce qu’elle fait |
| --- | --- |
| **Automatique** (défaut) | Réutilise un onglet correspondant déjà ouvert, entièrement rendu et avec votre connexion. Utilise un onglet d’arrière-plan temporaire quand une récupération directe échoue ou que la page a besoin de JavaScript. |
| **Désactivé** | HTTP direct seulement |
| **Toujours** | Récupère toujours via le navigateur |

Sans navigateur connecté, la récupération locale fait une requête HTTP directe. Les autres fournisseurs récupèrent l’URL publique et n’ont pas votre session de navigateur connectée. Pour les pages interactives, utilisez l’[extension de navigateur](/fr/features/browser-extension) ou l’[Utilisation du navigateur](/fr/features/browser-control).

## Garder du contenu web

Ajoutez une URL avec **Ajouter → Page web unique** dans une [Base de connaissances](/fr/ai/knowledge-base) quand vous voulez la retrouver plus tard. Vérifiez la page importée et son état d’indexation ; les pages web peuvent changer après l’import.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le contenu revient vide | Vérifiez que la page est lisible sans interaction supplémentaire, ou utilisez la **Récupération locale** avec la **récupération assistée par le navigateur**. Les écrans de connexion, les requêtes bloquées, le contenu chargé dynamiquement et les sites non pris en charge peuvent empêcher l’extraction. |
| La réponse décrit des choses qui ne sont pas sur la page | Demandez à l’Agent de montrer ce qu’il a réellement récupéré, au lieu de deviner le contenu manquant. |

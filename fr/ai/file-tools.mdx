Les outils de fichiers permettent à un Agent de trouver des fichiers, d’y chercher du texte, de les lire et de les modifier. Indiquez un dossier ou un fichier et demandez en langage courant : l’Agent choisit l’outil adapté et vous montre ce qu’il a utilisé.

## Avant de commencer

- **Dossier de travail :** le **Dossier de travail** d’un Agent, dans la partie **Définition** de ses réglages, est le point de départ des chemins relatifs.
- **Approbations :** la puce **Autorisations** dans le chat décide quand l’Agent demande d’abord. Avec **Demander l’approbation**, il demande avant de modifier des fichiers hors du dossier de travail. La lecture et la recherche ne demandent jamais. Voir [Approuver les actions](/fr/ai/agents).

## Commencer par une tâche en lecture seule

1. Dans les réglages de l’Agent, vérifiez ses outils de fichiers et son **Dossier de travail**.
2. Dans le chat, nommez un dossier ou joignez le fichier à utiliser.
3. Posez une question bornée, par exemple « Trouve les fichiers Markdown de ce projet et résume le README. »
4. Relisez les fichiers et la sortie des outils avant de demander une modification.

## Ce que fait chaque outil

| Outil | Ce qu’il fait |
| --- | --- |
| Glob | Trouve des fichiers par motif de chemin, comme `**/*.md`, les plus récents d’abord |
| Grep | Cherche du texte dans les fichiers, avec des motifs de fichiers et des numéros de ligne |
| Read File | Lit les fichiers texte, extrait le texte des documents, et lit les images, l’audio et la vidéo |
| Edit File | Remplace un texte exact dans un fichier et indique les lignes modifiées |
| Write File | Crée un fichier, ou remplace tout son contenu |

<Warning>
Write File peut écraser un fichier existant sans avertissement. Conservez une copie ou utilisez un contrôle de version pour les documents importants, et vérifiez la destination et la modification avant de les approuver. Les fichiers qu’un Agent modifie dans un chat apparaissent dans l’onglet **Modifications** du panneau latéral, avec **Annuler**.
</Warning>

## Documents et médias

Lire un PDF, un document Office, une image, un fichier audio ou une vidéo peut lancer une analyse, de l’OCR ou une transcription au lieu de renvoyer les octets bruts. Pour l’audio et la vidéo, l’Agent lit la transcription. Dans une feuille de calcul, une cellule de formule se lit comme sa valeur, ou comme la formule elle-même si elle n’a jamais été calculée. Les formats pris en charge dépendent des outils installés et des fournisseurs configurés. Voir [OCR](/fr/ai/ocr), [Transcription](/fr/features/transcription) et [Base de connaissances](/fr/ai/knowledge-base).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une erreur d’accès | Vérifiez le **Dossier de travail** de l’Agent, la puce **Autorisations** et les autorisations macOS |
| Un document se lit comme vide | Vérifiez le type de fichier et s’il peut être analysé. Un PDF scanné peut nécessiter l’OCR |
| Une modification ne trouve pas le texte à remplacer | Demandez à l’Agent de relire le fichier actuel avant de le modifier |

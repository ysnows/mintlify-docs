Chaque fonction vocale d’Enconvo a son propre réglage de modèle, pour que vous puissiez choisir un modèle de streaming rapide pour la Dictée et un autre pour les longs fichiers. Choisissez le modèle dans la fonction que vous utilisez vraiment.

| Fonction | Où le régler | Guide |
| --- | --- | --- |
| Parole saisie en texte | **Réglages → Modèles de dictée** | [Dictée](/fr/features/dictation) |
| Commande vocale | **Réglages → Commande vocale → Écouter** | [Commande vocale](/fr/features/dictation) |
| Appels Live Talk | **Réglages → Live Talk → Écouter** | [Live Talk](/fr/features/live-voice) |
| Enregistrement de réunion ou de cours | **Réglages → Modèles d’enregistrement** | [Enregistrement de réunion](/fr/features/meeting-recording) |
| Un fichier audio ou vidéo existant | **Réglages → Modèles de transcription** | [Transcription](/fr/features/transcription) |
| Sous-titres en temps réel | **Réglages → Modèle de sous-titrage** | [Sous-titrage en direct](/fr/features/live-captioning) |

## Choisir un modèle

1. Ouvrez le réglage de votre fonction dans le tableau ci-dessus.
2. Sur une page de modèle de Dictée, d’Enregistrement, de Transcription ou de Sous-titrage, filtrez la liste avec **Tous**, **Enconvo Cloud**, **Local** ou **Fournisseurs personnalisés**. Dans Commande vocale et Live Talk, **Écouter** montre d’abord les modèles recommandés, puis tout autre modèle vocal.
3. Choisissez un modèle, puis vérifiez ses options de langue et de modèle.

Les modèles **Enconvo Cloud** utilisent votre compte Enconvo, sans clé API. **Enconvo Cloud Fast**, la reconnaissance vocale propre à Enconvo Cloud, est gratuit pour tout le monde et porte une étiquette verte **Gratuit**. Les **Fournisseurs personnalisés** utilisent votre propre clé API chez ce fournisseur. Les modèles **Local** (MLX et Core ML) reconnaissent la parole sur votre Mac une fois leur modèle téléchargé.

Le [catalogue des fournisseurs vocaux](/fr/providers/catalog) liste chaque fournisseur déclaré, y compris les services cloud et les variantes locales Parakeet, Qwen, Whisper, SenseVoice, Paraformer et Nemotron. Le matériel et la disponibilité dépendent de l’environnement d’exécution et de votre version.

## Modèles notables

| Modèle | À savoir |
| --- | --- |
| ElevenLabs Scribe v3 Live | Diffuse les premiers mots en moins d’une seconde, avec moins d’erreurs en chinois et dans un audio bruyant. Utilisez-le pour la Dictée et la saisie vocale avec votre clé API ElevenLabs ou Enconvo Cloud. Le chinois et le japonais sortent sans espaces entre les mots. Live Talk l’utilise quand Live Talk utilise ElevenLabs. |
| ElevenLabs Scribe v3 | Transcrit des fichiers, avec votre clé API ElevenLabs ou Enconvo Cloud. |
| Enconvo Cloud Fast | Gratuit. Son modèle temps réel affiche vos mots pendant que vous parlez, et son modèle asynchrone transcrit les fichiers enregistrés. |
| Soniox | Utilise les modèles v6 de Soniox dans la Dictée, l’Enregistrement, la Transcription, le Sous-titrage, Live Talk et les sous-titres de conférence. Un modèle v5 choisi auparavant passe à la v6 pour vous ; Soniox retire la v5 le 15 décembre 2026. |
| DeepSeek | Transcrit pour la Transcription et la Dictée, avec votre propre clé API DeepSeek ou comme **DeepSeek (Enconvo Cloud)** sans clé. Il détecte 21 langues tout seul. |
| Fluid Speech Pro by FluidVoice | Tourne sur votre Mac et votre iPhone et transcrit 25 langues européennes hors ligne, avec moins d’erreurs que Parakeet, en direct pendant que vous parlez ou une fois que vous avez fini. Nécessite macOS 15 ou iOS 18 ou plus récent. |

## Adapter le modèle à la tâche

| Capacité | À savoir |
| --- | --- |
| Streaming | Produit un texte partiel pendant que vous parlez. Utilisez un modèle temps réel quand vous voulez que les mots apparaissent au fur et à mesure. |
| Transcription par lot | Traite un fichier après la capture ou l’envoi. |
| Indices de langue et mots favoris | Orientent la reconnaissance quand le fournisseur les prend en charge. |
| Diarisation des locuteurs | Sépare les voix. Elle ne garantit pas le bon nom de personne. |
| Traduction en direct | Proposée seulement par certains fournisseurs et modèles, avec langues source et cible. |
| Horodatages et sortie structurée | Dépendent du fournisseur et du format de sortie de la transcription. |

## Tester avec un court extrait

Enregistrez un court extrait avec la langue, le microphone et les termes que vous utilisez vraiment, et relisez-le avant de traiter une longue réunion. En cas d’échec, lisez l’erreur pour la taille du fichier, le format, l’extraction, le compte ou le réseau.

Les téléchargements de modèles locaux peuvent être bien plus volumineux que l’app. Vérifiez la taille réelle du téléchargement et votre espace libre ; les modèles vocaux locaux n’ont pas tous les mêmes besoins.

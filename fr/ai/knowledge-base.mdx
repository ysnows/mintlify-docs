title: "Base de connaissances"
description: "Rassemblez des documents, des notes, des pages web et des dossiers, puis recherchez-y et posez vos questions dans le chat."
---

Une base de connaissances contient le contenu qu’Enconvo doit pouvoir retrouver plus tard : documents de référence, notes de projet, pages web enregistrées et notes vocales. Les Agents y cherchent quand vous la désignez, ou quand une question a besoin de ce qu’elle contient. La [Mémoire](/fr/ai/memory) est différente : elle conserve les courtes informations que vos Agents retiennent sur vous d’une discussion à l’autre.

## Ouvrir la base de connaissances

- Dans la Fenêtre de chat, cliquez sur **Base de connaissances** dans la barre latérale.
- Ou ouvrez **Réglages → Base de connaissances** et cliquez sur une base de connaissances.
- Ou choisissez **Afficher la fenêtre de la base de connaissances** dans le menu d’Enconvo de la barre des menus. Cela ouvre la base de connaissances dans la Fenêtre de chat.

Vos [Souvenirs](/fr/ai/memory) s’y trouvent aussi : utilisez le sélecteur **Base de connaissances** / **Mémoire** en haut de la colonne Base de connaissances pour passer des uns aux autres. La Mémoire ne figure pas parmi vos bases de connaissances.

Dans la Fenêtre de chat, cliquez sur le nom de la base de connaissances en haut pour voir toutes vos bases de connaissances : la taille de chacune, ce qui a été ajouté cette semaine, ce qui demande votre attention et celles où les clients IA peuvent chercher.

## Créer une base de connaissances

1. Cliquez sur **Nouvelle base de connaissances** dans l’aperçu de toutes les bases de connaissances ou dans **Réglages → Base de connaissances**, ou cherchez **Créer une base de connaissances** dans la SmartBar.
2. Donnez-lui un **Nom** clair. Ajoutez une **Description** de ce qu’elle contient ; les Agents la lisent pour décider quand y chercher.
3. Sous **Commencer avec**, choisissez **Vide**, **Un dossier** (indexé et gardé synchronisé) ou **Fichiers**.
4. Activez **Autoriser les clients IA à y chercher** si vous voulez que des clients MCP tels que Claude ou Cursor puissent y accéder.
5. Cliquez sur **Créer**. Avec un dossier ou des fichiers, le bouton affiche **Créer et importer** ou **Créer et ajouter**.

Utilisez des bases de connaissances distinctes pour séparer des projets sans rapport. Au sein d’une base de connaissances, les dossiers servent à organiser les éléments.

## Ajouter du contenu

| Entrée | À utiliser pour |
| --- | --- |
| **Ajouter → Note** | Une nouvelle note Markdown modifiable |
| **Ajouter → Fichiers** | Des documents, images, fichiers audio ou vidéo pris en charge, depuis votre Mac |
| **Ajouter → Page web unique** | Le contenu d’une seule URL |
| **Ajouter → Vidéo YouTube** | Une vidéo et ses sous-titres |
| **Ajouter → Publication** | Une publication de X, Reddit, Hacker News, Bluesky, Zhihu, etc. |
| **Ajouter → Importer un dossier…** | Un dossier local avec sa structure, éventuellement gardé synchronisé |
| **Ajouter → Nouveau dossier…** | Un dossier pour organiser les éléments |
| Faire glisser ou coller des fichiers dans la base de connaissances | Import rapide depuis le Finder |
| [Capture rapide](/fr/features/quick-capture) | Enregistrer le contenu de l’app active |
| [Note vocale](/fr/features/voice-notes) | Enregistrer et sauvegarder une note vocale |

Les chargeurs de documents prennent en charge les formats courants : texte, Markdown, PDF, Office, EPUB et données structurées. Les images sont lues avec l’OCR, et les fichiers audio et vidéo sont transcrits. La qualité de l’analyse et les formats pris en charge dépendent du chargeur et des fournisseurs sélectionnés. Consultez l’aperçu de l’import et l’état de chaque élément pour repérer les fichiers ignorés ou en échec.

Quand vous ajoutez un site web entier, Enconvo reste dans la section du site vers laquelle pointe l’adresse, par exemple une partie d’un site de documentation, et n’indexe qu’une fois une page accessible par deux adresses.

## Partager une base de connaissances

Partagez une base de connaissances avec des personnes par e-mail, ou avec toute votre équipe. Vous devez être connecté à votre compte Enconvo, et les personnes avec qui vous partagez aussi.

<Steps>
  <Step title="Ouvrir le partage">
    Ouvrez le menu **⋯** de la base de connaissances et choisissez **Partager…**.
  </Step>
  <Step title="Ajouter des personnes ou votre équipe">
    Utilisez **Ajouter des personnes par e-mail**, ou activez l’accès de l’équipe pour la partager avec tous les membres de votre équipe.
  </Step>
  <Step title="Choisir ce que chacun peut faire">
    Choisissez **Peut consulter**, **Peut ajouter** ou **Peut gérer**. Seuls le propriétaire et les personnes qui peuvent gérer modifient qui a accès.
  </Step>
</Steps>

Le partage place une copie de cette base de connaissances dans Enconvo Cloud. Seul son contenu quitte votre Mac ; la Mémoire et l’historique des discussions ne sont jamais partagés. Ce que chacun ajoute atteint tous les Mac en quelques secondes, et chaque élément indique qui l’a ajouté. Le Mac de chaque membre conserve sa propre copie et son propre index, si bien que la recherche fonctionne hors ligne. Les autres personnes ne peuvent que consulter un dossier lié. **Activité** montre ce qui a changé et qui l’a modifié.

Pour arrêter le partage, utilisez **Retirer l’accès** sur une personne, ou **Ne plus partager avec l’équipe**.

## Parcourir et retrouver des éléments

- **Grille**, **Liste** et **Carte** changent l’affichage. La liste est un tableau avec les colonnes **Type**, **Étiquettes**, **Dossier**, **État** et **Ajouté**. La carte relie chaque élément à ceux dont le sens est le plus proche.
- Le menu **Bibliothèque** au-dessus de vos éléments permet de passer entre **Tous les éléments**, **Ajoutés récemment**, **Sans étiquette** et **À vérifier**, avec leurs totaux. Un point apparaît quand quelque chose demande votre attention.
- **Filtrer**, **Étiquettes** et **Types** restreignent ce qui est affiché.
- Dans la liste, cochez des lignes pour les déplacer, les étiqueter, les réindexer, les supprimer ou en discuter ensemble.

## Dossiers liés

1. Choisissez **Ajouter → Importer un dossier…**.
2. Sélectionnez un dossier source, vérifiez le nombre de fichiers et les fichiers ignorés, puis confirmez.
3. Sélectionnez le dossier et affichez ses détails pour voir le chemin source, l’état de la synchronisation et les commandes.
4. Cliquez sur **Synchroniser maintenant**, ou activez **Synchronisation automatique** pour suivre les changements tant qu’Enconvo est ouvert.

Le dossier source reste sur le disque. Les fichiers nouveaux et modifiés sont importés, et les fichiers que vous supprimez de la source sont retirés de la base de connaissances. Les fichiers masqués, les formats non pris en charge et les fichiers de plus de 50 Mo sont ignorés. La synchronisation de dossier d’Enconvo ne modifie jamais les fichiers sources.

Si le disque source est débranché ou si le dossier a été déplacé, le dossier affiche **Dossier source introuvable** et rien n’est supprimé. Reconnectez le disque, ou cliquez sur **Associer à nouveau…** et choisissez le nouvel emplacement. Consultez [Fonctionnement des bases de connaissances](/fr/advanced/knowledge-base-advanced) pour le traitement et le dépannage de la synchronisation.

## Poser des questions sur vos sources

- **Dans la base de connaissances** : cliquez sur **Demander** à côté de **Éléments** en haut. C’est le même chat que dans la Fenêtre de chat : la base de connaissances est jointe à votre première question et de nouveau consultée pour les questions suivantes, et la discussion est enregistrée avec vos autres discussions. Cliquez sur **Nouveau** pour poser une nouvelle question.
- **Dans n’importe quelle discussion** : tapez **@** et choisissez une base de connaissances ou l’un de ses éléments dans la liste. Elle reste au-dessus de la zone de message pour les questions suivantes, et vous pouvez l’en retirer. Cliquez sur sa pastille pour l’ouvrir dans la base de connaissances.

Essayez :

> À partir des notes de projet jointes, liste les décisions concernant l’authentification et cite la source de chacune.

Un Agent recherche et lit le contenu dont il a besoin. La récupération choisit les passages pertinents au lieu d’envoyer tous les documents. Ouvrez les éléments cités pour vérifier les détails importants. Si un passage manque, mentionnez l’élément précis, ou vérifiez que son indexation est terminée.

## Réglages de la base de connaissances

Cliquez sur l’engrenage (**Réglages de la base de connaissances**) dans l’en-tête de la base de connaissances.

| Section | Contenu |
| --- | --- |
| **Général** | Le **Nom** et la **Description** de la base de connaissances |
| **Index et recherche** | Les éléments à vérifier, le modèle de recherche et **Réindexer…** pour reconstruire tout l’index |
| **Sources et capture** | Les dossiers liés avec **Synchroniser maintenant**, **Synchronisation automatique** et **Associer à nouveau…**, ainsi que des raccourcis vers la Capture rapide, la Note vocale et l’extension Chrome |
| **Clients IA (MCP)** | Indique si les clients IA peuvent chercher dans cette base de connaissances. Voir [MCP de la base de connaissances](/fr/advanced/knowledge-base-mcp). |
| **Avancé** | L’**ID de la base de connaissances** et **Supprimer la base de connaissances** |

La base de connaissances par défaut et la Mémoire ne peuvent pas être supprimées.

## Modifier et entretenir

Ouvrez une note pour modifier son Markdown. Utilisez les menus des éléments et des dossiers pour renommer, déplacer, étiqueter ou retirer du contenu. Lisez la confirmation de suppression : retirer un élément d’une base de connaissances et supprimer un fichier source sont deux opérations différentes, et retirer un dossier lié entier ne touche jamais aux fichiers sur le disque.

<Warning>
Pour un élément qui provient d’un dossier lié, le menu de l’élément affiche **Déplacer vers la corbeille**. Il place le vrai fichier du disque dans la corbeille, puis l’élément quitte la base de connaissances.
</Warning>

Quand un élément échoue, vérifiez si c’est l’extraction ou l’indexation qui a échoué avant de réessayer. Un document peut être lisible avant la fin de son indexation pour la recherche.

Toutes les bases de connaissances utilisent le même modèle de recherche, défini sous **Rechercher** dans **Réglages → Mémoire**. Il s’exécute sur ce Mac ou sur Enconvo Cloud, et le passage de l’un à l’autre conserve votre index de recherche. **Réglages de recherche…** dans **Index et recherche** l’ouvre.

## Connecter une autre app d’IA

Ouvrez **Réglages de la base de connaissances → Clients IA (MCP)** pour autoriser des clients MCP locaux à chercher dans les bases de connaissances que vous choisissez. C’est un service distinct, facultatif et en lecture seule. Suivez [MCP de la base de connaissances](/fr/advanced/knowledge-base-mcp) pour la configuration et les contrôles de partage.

## Traitement des données

Les fichiers et les index de la base de connaissances sont stockés localement. Les fournisseurs d’OCR, de transcription, d’embedding, de reclassement ou de chat dans le cloud que vous sélectionnez peuvent recevoir le contenu dont ils ont besoin pour leur travail. Quand le modèle de recherche s’exécute sur Enconvo Cloud, le texte à indexer ou à rechercher y est envoyé. Stocker les fichiers localement ne signifie pas que le traitement par les fournisseurs se fait hors ligne. Consultez [Confidentialité et sécurité](/fr/configuration/privacy-security) et vos fournisseurs avant d’importer des contenus sensibles.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un élément affiche une erreur d’indexation | Ouvrez **Bibliothèque → À vérifier**, vérifiez si l’extraction ou l’indexation a échoué, puis réindexez l’élément. |
| Un dossier lié indique **Dossier source introuvable** | Reconnectez le disque, ou cliquez sur **Associer à nouveau…** et choisissez le nouvel emplacement du dossier. |
| Une réponse ignore un document | Vérifiez que l’indexation du document est terminée, puis mentionnez-le directement avec **@**. |
| Le nouveau contenu n’est pas indexé | Si le modèle de recherche s’exécute sur Enconvo Cloud, connectez-vous. Tant que vous ne l’êtes pas, le nouveau contenu n’est pas indexé et la recherche ne trouve que les mots exacts. |

---
title: "Base de connaissances"
description: "Rassemblez documents, notes, pages web et dossiers, puis recherchez-les et interrogez-les dans le chat."
---

Une base de connaissances contient ce que vous voulez qu’Enconvo retrouve plus tard : documents de référence, notes de projet, pages web enregistrées et notes parlées. Les Agents la consultent quand vous la désignez, ou quand une question a besoin de ce qu’elle contient. La [Mémoire](/fr/ai/memory) est autre chose : elle garde de courts faits que vos Agents retiennent sur vous d’un chat à l’autre.

## Ouvrir la base de connaissances

- Dans la Fenêtre de chat, cliquez sur **Base de connaissances** dans la barre latérale.
- Ou ouvrez **Réglages → Base de connaissances** et cliquez sur une base.
- Ou choisissez **Afficher la fenêtre de la base de connaissances** dans le menu de la barre des menus d’Enconvo. Cela ouvre la base de connaissances dans la Fenêtre de chat.

Vos [Mémoires](/fr/ai/memory) s’y trouvent aussi : utilisez le commutateur **Base de connaissances** / **Mémoire** en haut de la colonne Base de connaissances pour passer de l’une à l’autre. La Mémoire n’apparaît pas parmi vos bases de connaissances.

Dans la Fenêtre de chat, cliquez sur le nom de la base en haut pour voir toutes vos bases : la taille de chacune, ce qui a été ajouté cette semaine, ce qui demande de l’attention, et celles que les clients d’IA peuvent rechercher.

## Créer une base de connaissances

1. Cliquez sur **Nouvelle base de connaissances** dans la vue d’ensemble de toutes les bases ou dans **Réglages → Base de connaissances**, ou recherchez **Créer une base de connaissances** dans le SmartBar.
2. Donnez-lui un **Nom** clair. Ajoutez une **Description** de ce qui y va ; les Agents la lisent pour décider quand chercher là.
3. Sous **Commencer avec**, choisissez **Vide**, **Un dossier** (indexé et tenu à jour) ou **Fichiers**.
4. Activez **Laisser les clients d’IA la rechercher** si vous voulez que des clients MCP comme Claude ou Cursor y accèdent.
5. Cliquez sur **Créer**. Avec un dossier ou des fichiers, le bouton indique **Créer et importer** ou **Créer et ajouter**.

Utilisez des bases séparées pour tenir à l’écart des projets sans rapport. Dans une base, les dossiers organisent les éléments.

## Ajouter du contenu

| Entrée | À utiliser pour |
| --- | --- |
| **Ajouter → Note** | Une nouvelle note Markdown modifiable |
| **Ajouter → Fichiers** | Documents, images, audio ou vidéo pris en charge depuis votre Mac |
| **Ajouter → Page web unique** | Le contenu d’une URL |
| **Ajouter → Vidéo YouTube** | Une vidéo et ses sous-titres |
| **Ajouter → Publication** | Une publication de X, Reddit, Hacker News, Bluesky, Zhihu, et d’autres |
| **Ajouter → Importer un dossier…** | Un dossier local avec sa structure, éventuellement tenu à jour |
| **Ajouter → Nouveau dossier…** | Un dossier pour organiser les éléments |
| Glisser ou coller des fichiers dans la base | Import rapide depuis le Finder |
| [Capture rapide](/fr/features/quick-capture) | Enregistrer le contenu de l’app au premier plan |
| [Note vocale](/fr/features/voice-notes) | Enregistrer et conserver une note parlée |

Les chargeurs de documents prennent en charge les formats courants de texte, Markdown, PDF, Office, EPUB et données structurées. Les images sont lues par OCR, et l’audio et la vidéo sont transcrits. La qualité d’analyse et les formats pris en charge dépendent du chargeur et des fournisseurs choisis. Consultez l’aperçu d’import et le statut de chaque élément pour les fichiers ignorés ou en échec.

Quand vous ajoutez un site entier, Enconvo reste dans la section du site que son adresse désigne, par exemple une partie d’un site de documentation, et n’indexe qu’une fois une page trouvée sous deux adresses.

## Partager une base de connaissances

Partagez une base par e-mail, ou avec toute votre équipe. Vous devez être connecté à votre compte Enconvo, tout comme les personnes avec qui vous partagez.

<Steps>
  <Step title="Ouvrir Partager">
    Ouvrez le menu **⋯** de la base et choisissez **Partager…**.
  </Step>
  <Step title="Ajouter des personnes ou votre équipe">
    Utilisez **Ajouter des personnes par e-mail**, ou activez l’accès de l’équipe pour la partager avec tout le monde dans votre équipe.
  </Step>
  <Step title="Choisir ce que chacun peut faire">
    Choisissez **Peut consulter**, **Peut ajouter** ou **Peut gérer**. Seuls le propriétaire et les personnes qui peuvent gérer changent qui a accès.
  </Step>
</Steps>

Le partage place une copie de cette base dans Enconvo Cloud. Seul ce qu’elle contient quitte votre Mac ; la Mémoire et l’historique des chats ne sont jamais partagés. Ce que chacun ajoute arrive sur chaque Mac en quelques secondes, et chaque élément indique qui l’a ajouté. Le Mac de chaque membre garde sa propre copie et son propre index, donc la recherche fonctionne hors ligne. Les autres ne peuvent que consulter un dossier lié. **Activité** montre ce qui a changé et qui l’a changé.

Pour arrêter le partage, utilisez **Retirer l’accès** sur une personne, ou **Arrêter le partage avec l’équipe**.

## Parcourir et trouver des éléments

- **Grille**, **Liste** et **Carte** changent la vue. La liste est un tableau avec les colonnes **Type**, **Tags**, **Dossier**, **Statut** et **Ajouté**. La carte montre chaque élément relié à ceux qui lui sont les plus proches en sens.
- Le menu **Bibliothèque** au-dessus de vos éléments passe entre **Tous les éléments**, **Ajoutés récemment**, **Sans tag** et **À vérifier**, avec leurs nombres. Un point indique quand quelque chose demande de l’attention.
- **Filtrer**, **Tags** et **Types** restreignent ce qui est affiché.
- Dans la liste, cochez des lignes pour les déplacer, les taguer, les réindexer, les supprimer ou en parler ensemble dans le chat.

## Dossiers liés

1. Choisissez **Ajouter → Importer un dossier…**.
2. Sélectionnez un dossier source, vérifiez le nombre de fichiers et les fichiers ignorés, puis confirmez.
3. Sélectionnez le dossier et affichez ses détails pour voir le chemin source, l’état de synchronisation et les commandes.
4. Cliquez sur **Synchroniser maintenant**, ou activez **Synchronisation automatique** pour suivre les changements tant qu’Enconvo tourne.

Le dossier source reste sur le disque. Les fichiers nouveaux et modifiés sont importés, et les fichiers que vous supprimez de la source sont retirés de la base. Les fichiers cachés, les formats non pris en charge et les fichiers de plus de 50 Mo sont ignorés. La synchronisation de dossiers d’Enconvo ne modifie jamais les fichiers source.

Si le disque source est débranché ou le dossier déplacé, le dossier affiche **Dossier source introuvable** et rien n’est retiré. Rebranchez le disque, ou cliquez sur **Relier…** et choisissez le nouvel emplacement. Voir [Fonctionnement des bases de connaissances](/fr/advanced/knowledge-base-advanced) pour le traitement et le dépannage de la synchronisation.

## Interroger vos sources

- **Dans la base de connaissances** : cliquez sur **Demander** à côté de **Éléments** en haut. C’est le même chat que la Fenêtre de chat : la base est jointe à votre première question et recherchée à nouveau pour les suites, et le chat est enregistré avec vos autres chats. Cliquez sur **Nouveau** pour poser une nouvelle question.
- **Dans n’importe quel chat** : tapez **@** et choisissez une base ou l’un de ses éléments dans la liste. Elle reste au-dessus du champ pour les questions suivantes, où vous pouvez la retirer. Cliquez sur sa puce pour l’ouvrir dans la base de connaissances.

Essayez :

> À partir des notes de projet jointes, liste les décisions sur l’authentification et cite la source de chaque décision.

Un Agent recherche et lit le matériel dont il a besoin. La récupération choisit des passages pertinents au lieu d’envoyer chaque document. Ouvrez les éléments cités pour vérifier les détails importants. Si un passage manque, mentionnez l’élément précis, ou vérifiez qu’il a fini d’être indexé.

## Réglages de la base de connaissances

Cliquez sur l’engrenage (**Réglages de la base de connaissances**) dans l’en-tête de la base.

| Section | Ce qu’on y trouve |
| --- | --- |
| **Général** | Le **Nom** et la **Description** de la base |
| **Index et recherche** | Les éléments qui demandent de l’attention, le modèle de recherche, et **Réindexer…** pour reconstruire tout l’index |
| **Sources et capture** | Les dossiers liés avec **Synchroniser maintenant**, **Synchronisation automatique** et **Relier…**, plus des raccourcis vers Capture rapide, Note vocale et l’extension Chrome |
| **Clients IA (MCP)** | Si les clients d’IA peuvent rechercher cette base. Voir [MCP de la base de connaissances](/fr/advanced/knowledge-base-mcp). |
| **Avancé** | L’**Identifiant de la base** et **Supprimer la base de connaissances** |

La base par défaut et la Mémoire ne peuvent pas être supprimées.

## Modifier et entretenir

Ouvrez une note pour modifier son Markdown. Utilisez les menus de l’élément et du dossier pour renommer, déplacer, taguer ou retirer du contenu. Lisez la confirmation de suppression : retirer un élément d’une base et supprimer un fichier source sont des opérations différentes, et retirer un dossier lié entier ne touche jamais les fichiers sur le disque.

<Warning>
Pour un élément qui vient d’un dossier lié, le menu de l’élément indique **Mettre à la corbeille**. Il déplace le vrai fichier sur le disque vers la Corbeille, puis l’élément quitte la base.
</Warning>

Quand un élément échoue, vérifiez si l’extraction ou l’indexation a échoué avant de réessayer. Un document peut être lisible avant que son indexation pour la recherche soit terminée.

Chaque base utilise le même modèle de recherche, défini sous **Recherche** dans **Réglages → Mémoire**. Il s’exécute sur ce Mac ou sur Enconvo Cloud, et passer de l’un à l’autre conserve votre index de recherche. **Réglages de recherche…** dans **Index et recherche** l’ouvre.

## Connecter une autre app d’IA

Ouvrez **Réglages de la base de connaissances → Clients IA (MCP)** pour laisser les clients MCP locaux rechercher les bases que vous choisissez. C’est un service distinct, facultatif et en lecture seule. Suivez [MCP de la base de connaissances](/fr/advanced/knowledge-base-mcp) pour la configuration et les contrôles de partage.

## Traitement des données

Les fichiers et les index de la base sont stockés localement. Les fournisseurs cloud d’OCR, de transcription, d’embeddings, de reranking ou de chat que vous choisissez peuvent recevoir le contenu dont ils ont besoin pour leur travail. Quand le modèle de recherche s’exécute sur Enconvo Cloud, le texte indexé ou recherché y est envoyé. Stocker les fichiers localement ne signifie pas que le traitement chez le fournisseur se fait hors ligne. Consultez [Confidentialité et sécurité](/fr/configuration/privacy-security) et vos fournisseurs avant d’importer des documents sensibles.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un élément affiche une erreur d’indexation | Ouvrez **Bibliothèque → À vérifier**, voyez si l’extraction ou l’indexation a échoué, puis réindexez l’élément. |
| Un dossier lié indique **Dossier source introuvable** | Rebranchez le disque, ou cliquez sur **Relier…** et choisissez le nouvel emplacement du dossier. |
| Une réponse omet un document | Vérifiez que le document a fini d’être indexé, puis mentionnez-le directement avec **@**. |
| Le nouveau contenu n’est pas indexé | Si le modèle de recherche s’exécute sur Enconvo Cloud, connectez-vous. Tant que vous ne le faites pas, le nouveau contenu n’est pas indexé et la recherche ne trouve que les mots correspondants. |

Utilisez les modèles GPT d’OpenAI dans les chats, les Agents et les Commandes IA. Connectez-vous avec une clé API OpenAI, facturée par OpenAI à chaque requête, ou connectez-vous avec votre abonnement ChatGPT et utilisez son quota.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur la [plateforme OpenAI](https://platform.openai.com/api-keys).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → OpenAI**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un abonnement ChatGPT ? Choisissez plutôt **Abonnement ChatGPT** sous **Authentification** et cliquez sur **Connecter**. Voir [Abonnement ChatGPT](/fr/providers/openai_subscription).
</Tip>

Pour conserver une deuxième clé OpenAI, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Rôle |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |
| **Type d’API** | Dans l’identifiant. **API Responses** (le défaut) ou **API Completions**. Gardez Responses sauf si un service compatible exige Completions. |
| **URL de base de l’API** | Dans l’identifiant. Le défaut est `https://api.openai.com/v1`. Ne la changez que pour utiliser un service compatible OpenAI. |

Le même profil OpenAI sert aussi les embeddings OpenAI, la synthèse vocale, la génération d’images et la transcription, donc changer sa clé affecte aussi ces fonctions. Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau toute la clé et vérifiez qu’elle est active et que la facturation est configurée sur la plateforme OpenAI. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Un service compatible échoue | Vérifiez **URL de base de l’API**, puis essayez **API Completions** comme **Type d’API**. |
| Erreurs de limite de débit ou d’usage | Vérifiez l’usage et les limites sur la plateforme OpenAI, ou passez à un autre fournisseur pour l’instant. |

Utilisez les modèles GPT d’OpenAI dans les discussions, les Agents et les Commandes IA. Connectez-vous avec une clé API OpenAI, qu’OpenAI facture à chaque requête, ou connectez-vous avec votre abonnement ChatGPT pour utiliser son quota.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur la [plateforme OpenAI](https://platform.openai.com/api-keys).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → OpenAI**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un abonnement ChatGPT ? Choisissez plutôt **ChatGPT Subscription** sous **Authentification**, puis cliquez sur **Connecter**. Voir [ChatGPT Subscription](/fr/providers/openai_subscription).
</Tip>

Pour conserver une seconde clé OpenAI, par exemple une clé professionnelle, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **API Type** | Dans l’identifiant. **Responses API** (par défaut) ou **Completions API**. Gardez Responses, sauf si un service compatible exige Completions. |
| **URL de base de l’API** | Dans l’identifiant. La valeur par défaut est `https://api.openai.com/v1`. Ne la modifiez que pour utiliser un service compatible OpenAI. |

Le même profil OpenAI sert aussi aux embeddings, à la synthèse vocale, à la génération d’images et à la transcription d’OpenAI ; changer sa clé affecte donc aussi ces fonctions. Pour utiliser un autre modèle dans une seule discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active et que la facturation est configurée sur la plateforme OpenAI. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Un service compatible échoue | Vérifiez **URL de base de l’API**, puis essayez **Completions API** comme **API Type**. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et les limites sur la plateforme OpenAI, ou passez temporairement à un autre fournisseur. |

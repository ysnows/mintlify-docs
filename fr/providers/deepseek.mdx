---
title: "DeepSeek"
description: "Discutez avec les modèles DeepSeek dans Enconvo à l’aide de votre propre clé API DeepSeek."
---

DeepSeek propose ses modèles via une clé API. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les Agents et les Commandes IA. DeepSeek facture l’usage à votre propre compte. Il apparaît sous **Deep Seek** dans les Réglages.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur la [plateforme DeepSeek](https://platform.deepseek.com/api_keys).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Deep Seek**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une deuxième clé DeepSeek, par exemple pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

La même clé fonctionne pour DeepSeek dans d’autres fonctions. Choisissez **DeepSeek** comme fournisseur dans **Réglages → Synthèse vocale**, **Réglages → Recherche web**, **Réglages → Récupérer le contenu web** et **Réglages → OCR** (listé comme **DeepSeek OCR**), ainsi que dans **Modèles de dictée** ou **Modèles de transcription** pour la reconnaissance vocale. Chacune de ces fonctions a aussi une option **DeepSeek (Enconvo Cloud)** qui n’exige pas de clé et s’exécute sur votre compte Enconvo.

## Modèles et options

| Réglage | Ce qu’il fait |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |

Pour utiliser un autre modèle dans un seul chat, choisissez-le dans le sélecteur de modèle de ce chat.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans votre compte DeepSeek. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge l’entrée d’images ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Vérifiez l’usage et les limites dans votre compte DeepSeek, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte ou un effort de raisonnement plus faible. |

Utilisez votre forfait Google Antigravity comme fournisseur de modèle d’IA dans Enconvo. Vous vous connectez avec votre compte Google ; aucune clé API n’intervient.

<Warning>
Enconvo se connecte avec le client Google de l’app Antigravity elle-même, que Google n’offre pas aux autres apps. Google peut suspendre un compte Antigravity qu’il voit utilisé en dehors d’Antigravity. Utilisez un compte que vous pouvez vous permettre de perdre.
</Warning>

## Connecter

<Steps>
  <Step title="Ouvrir le fournisseur">
    Ouvrez **Réglages → Modèle d’IA → Antigravity**.
  </Step>
  <Step title="Démarrer la connexion">
    Dans **Authentification**, cliquez sur **Connecter**.
  </Step>
  <Step title="Lire l’avertissement">
    Enconvo affiche **Avant de vous connecter à Antigravity**. Lisez le risque, puis cliquez sur **Accepter** pour continuer. **Annuler** ferme la fenêtre et laisse votre compte tel quel.
  </Step>
  <Step title="Se connecter avec Google">
    Votre navigateur ouvre la connexion Google. Choisissez le compte et autorisez l’accès.
  </Step>
  <Step title="Vérifier le compte">
    Revenez à Enconvo et vérifiez que le compte voulu est connecté.
  </Step>
  <Step title="Choisir un modèle">
    Sélectionnez un modèle et essayez une courte demande.
  </Step>
</Steps>

Enconvo demande à chaque connexion ou reconnexion d’Antigravity, depuis la page du fournisseur ou depuis son identifiant.

## Modèles et options

Antigravity propose les modèles Gemini et Claude de votre forfait. Chaque modèle affiche les niveaux d’effort de raisonnement qu’Antigravity offre pour lui. Gemini 4 Carbon nécessite un forfait Google AI Ultra ; Gemini 4 Hydrogen apparaît lorsque votre forfait le propose.

## Sur l’iPhone

L’app iPhone peut aussi se connecter à Antigravity, pour les chats téléphoniques sur le téléphone. Elle vous demande d’abord d’accepter le même risque. Voir [Chats téléphoniques](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| La connexion ne se termine pas | Terminez la connexion Google dans le navigateur, puis revenez à Enconvo ; cliquez sur **Connecter** pour réessayer. |
| Google indique que le compte est restreint | Le compte a peut-être été suspendu pour un usage en dehors d’Antigravity ; utilisez un autre compte ou un autre fournisseur. |
| Le modèle voulu n’est pas listé | Votre forfait Antigravity ne l’inclut pas. |
| Limite de débit ou d’usage | Les limites de votre forfait ; attendez qu’elles se réinitialisent ou choisissez un autre fournisseur. |

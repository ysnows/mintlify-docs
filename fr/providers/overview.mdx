Un fournisseur est le service derrière une fonction d’Enconvo : le modèle qui répond à un chat, la voix qui lit à voix haute, le moteur qui cherche sur le web. Vous en choisissez un pour chaque fonction, et vous pouvez les combiner.

La vidéo ci-dessous parcourt **Réglages → Modèle d’IA** en 2 minutes : Auto Route, le forfait Cloud, la connexion avec un forfait ChatGPT, Claude, GitHub Copilot, Antigravity ou Grok, les clés API, les modèles sur votre Mac, Ollama et LM Studio, et l’ajout de votre propre fournisseur.

| Si vous voulez | Utilisez | Commencez ici |

| Démarrer tout de suite, sans clés | Enconvo Cloud, via votre compte Enconvo | [Enconvo Cloud](/fr/providers/enconvo) |

## Choisir votre modèle de chat

<Steps>
  <Step title="Ouvrir Modèle d’IA">
    Ouvrez **Réglages → Modèle d’IA**. La colonne du milieu liste chaque fournisseur : **Auto Route** et **Forfait Enconvo Cloud** en haut, puis les sociétés, les modèles locaux et tous les autres fournisseurs.
  </Step>
  <Step title="Choisir un fournisseur et le connecter">
    Cliquez sur un fournisseur. Là où les deux existent, choisissez **Clé API** pour payer le fournisseur à la requête avec votre propre clé, ou l’option d’abonnement (par exemple **Abonnement ChatGPT**) pour vous connecter et utiliser ce que votre forfait inclut.
  </Step>
  <Step title="Choisir le modèle">
    Choisissez un modèle sous **Nom du modèle**, et un **Effort de raisonnement** là où le fournisseur en a un.
  </Step>
  <Step title="En faire le modèle par défaut">
    Cliquez sur **Définir par défaut**. Les chats et les fonctions qui ne nomment pas leur propre modèle l’utilisent désormais.
  </Step>
</Steps>

Pour ajouter un service qui n’est pas listé, cliquez sur **Ajouter un nouveau fournisseur** en bas de la liste et choisissez **Compatible OpenAI** ou **Compatible Anthropic**.

Vous pouvez changer de fournisseur à tout moment ; rien n’attache vos chats à une seule société.

Le haut de **Réglages → Modèle d’IA** a aussi **Modèles de tâche**, pour les petits modèles derrière les titres et suggestions de chat, et **Secours**, pour les modèles de secours qui prennent le relais quand le modèle d’un chat ne peut pas être utilisé. Voir [Choisir un modèle](/fr/ai/model-selection-guide).

## Régler un fournisseur pour chaque fonction

Chaque fonction a sa propre page de Réglages : **Modèle d’IA**, **Synthèse vocale**, **Recherche web**, **Génération d’images**, **Génération de vidéos**, **Récupérer le contenu web** et **OCR**. La reconnaissance vocale a des pages distinctes pour les **Modèles de dictée**, les **Modèles d’enregistrement**, les **Modèles de transcription** et le **Modèle de sous-titrage**. Les embeddings et le reranking se règlent dans la Base de connaissances.

Choisir un modèle de chat ne change pas votre fournisseur de parole, d’image ou de recherche. Réglez chacun là où vous le voulez.

## Profils

Un profil de fournisseur contient une clé ou une connexion. Cliquez sur **Ajouter un nouveau fournisseur** sur la page d’un fournisseur pour en conserver un deuxième, par exemple un compte professionnel. Certains profils servent plusieurs fonctions : un profil OpenAI couvre le chat, les embeddings, la synthèse vocale, les images et la transcription, donc changer sa clé les change tous. Voir [Identifiants et profils](/fr/configuration/credentials).

Où votre modèle par défaut est réglé, et comment chaque chat garde le sien, est dans [Choisir un modèle](/fr/ai/model-selection-guide).

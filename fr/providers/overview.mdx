Un fournisseur est le service derrière une fonctionnalité d’Enconvo : le modèle qui répond dans un chat, la voix qui lit à voix haute, le moteur qui cherche sur le web. Vous en choisissez un pour chaque fonctionnalité, et vous pouvez les mélanger.

La vidéo ci-dessous présente **Réglages → Modèle d’IA** en 2 minutes : Auto Route, l’offre Cloud, la connexion avec un abonnement ChatGPT, Claude, GitHub Copilot, Antigravity ou Grok, les clés API, les modèles sur votre Mac, Ollama et LM Studio, et l’ajout d’un fournisseur de votre choix.

## Choisir votre modèle de chat

<Steps>
  <Step title="Ouvrir Modèle d’IA">
    Ouvrez **Réglages → Modèle d’IA**. La colonne du milieu liste tous les fournisseurs : **Auto Route** et **Enconvo Cloud Plan** en haut, puis les entreprises, les modèles locaux et tous les autres fournisseurs.
  </Step>
  <Step title="Choisir un fournisseur et le connecter">
    Cliquez sur un fournisseur. Lorsqu’il propose les deux, choisissez **Clé API** pour payer le fournisseur à la requête avec votre propre clé, ou l’option d’abonnement (par exemple **Abonnement ChatGPT**) pour vous connecter et utiliser ce que votre abonnement inclut.
  </Step>
  <Step title="Choisir le modèle">
    Choisissez un modèle sous **Nom du modèle**, et un **Effort de raisonnement** lorsque le fournisseur en propose un.
  </Step>
  <Step title="En faire le modèle par défaut">
    Cliquez sur **Définir par défaut**. Les chats et les fonctionnalités qui ne nomment pas de modèle propre l’utilisent désormais.
  </Step>
</Steps>

Pour ajouter un service qui n’est pas listé, cliquez sur **Ajouter un nouveau fournisseur** en bas de la liste et choisissez **Compatible OpenAI** ou **Compatible Anthropic**.

Vous pouvez changer de fournisseur à tout moment ; rien ne lie vos chats à une seule entreprise.

Le haut de **Réglages → Modèle d’IA** propose aussi **Modèles de tâches**, pour les petits modèles derrière les titres de chat et les suggestions, et **Secours**, pour les modèles de secours qui prennent le relais lorsque le modèle d’un chat est inutilisable. Voir [Choisir un modèle](/fr/ai/model-selection-guide).

## Définir un fournisseur pour chaque fonctionnalité

Chaque fonctionnalité a sa propre page de Réglages : **Modèle d’IA**, **Synthèse vocale**, **Recherche web**, **Génération d’images**, **Génération de vidéos**, **Récupérer le contenu web** et **OCR**. La reconnaissance vocale a des pages distinctes pour les **Modèles de dictée**, les **Modèles d’enregistrement**, les **Modèles de transcription** et le **Modèle de sous-titrage**. Les embeddings et le reclassement se règlent dans la Base de connaissances.

Choisir un modèle de chat ne change pas votre fournisseur de voix, d’images ou de recherche. Réglez chacun là où vous le souhaitez.

## Profils

Un profil de fournisseur contient une clé ou une connexion. Cliquez sur **Ajouter un nouveau fournisseur** sur la page d’un fournisseur pour en garder un second, par exemple un compte professionnel. Certains profils servent plusieurs fonctionnalités : un profil OpenAI couvre le chat, les embeddings, la synthèse vocale, les images et la transcription, si bien que changer sa clé les change tous. Voir [Identifiants et profils](/fr/configuration/credentials).

L’endroit où votre modèle par défaut est défini, et la façon dont chaque chat garde le sien, sont expliqués dans [Choisir un modèle](/fr/ai/model-selection-guide).

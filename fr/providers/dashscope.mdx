DashScope est le service de modèles d’Alibaba Cloud en Chine continentale, aussi appelé Bailian (阿里云百炼). Pour le service Qwen international, utilisez [Qwen](/fr/providers/qwen). Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les Agents et les Commandes IA. DashScope facture l’usage sur votre propre compte.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans [Alibaba Cloud Bailian (阿里云百炼)](https://bailian.console.aliyun.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → DashScope**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une deuxième clé DashScope, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Rôle |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |

Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau toute la clé et vérifiez qu’elle est active dans votre compte DashScope. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge la saisie d’images ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Vérifiez l’usage et les limites dans votre compte DashScope, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte, ou un effort de raisonnement plus bas. |

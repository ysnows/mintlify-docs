Enconvo Cloud vous donne des modèles de plusieurs sociétés, plus la voix, l'image, la vidéo et les outils web, via votre compte Enconvo. Il n'y a pas de clés API à gérer : les requêtes utilisent les points de votre forfait. C'est le moyen le plus rapide de commencer.

## Configuration

<Steps>
  <Step title="Se connecter">
    Connectez-vous à votre compte Enconvo. Voir [Compte](/fr/configuration/account).
  </Step>
  <Step title="Choisir Enconvo Cloud">
    Ouvrez la page Réglages de ce que vous voulez faire, par exemple **Modèle d'IA**, **Synthèse vocale** ou **Génération d'images**, et choisissez le fournisseur **Enconvo Cloud** ou **Enconvo Cloud Plan**.
  </Step>
  <Step title="Choisir un modèle ou une voix">
    Choisissez un modèle ou une voix et lancez une courte requête.
  </Step>
</Steps>

Chaque fonction a son propre choix de fournisseur. Choisir Enconvo Cloud pour le chat ne change pas la voix, les images, la vidéo, les embeddings, le reranking ni les outils web : réglez chacun là où vous le voulez.

## Les modèles propres à Enconvo

Enconvo Cloud a trois modèles à lui, nommés selon le travail qu'ils conviennent :

| Modèle | À utiliser pour |
| --- | --- |
| **Enconvo Fast** | Les tours rapides : réponses courtes, réécritures, petites actions. C'est le modèle sur lequel **Enconvo Cloud Plan** démarre, et le défaut des Commandes IA. |
| **Enconvo Balanced** | Le travail de tous les jours, en quelques étapes. |
| **Enconvo Ultra** | Les tâches difficiles qui demandent un raisonnement profond. |

Ils sont listés en premier sous **Enconvo Cloud Plan**, et [Auto Route](/fr/providers/auto-route) les utilise pour ses routes par défaut.

## Trouver un modèle dans le sélecteur

La liste **Enconvo Cloud Plan** groupe les modèles par éditeur : les modèles d'Enconvo d'abord, puis Anthropic, OpenAI, Google, et le reste, chacun avec un compte. Un éditeur montre ses quatre modèles les plus récents ; cliquez sur **Afficher N modèles plus anciens** pour voir les autres. La recherche liste chaque correspondance, et le modèle que votre chat utilise s'affiche toujours. Les modèles Claude sont listés sans le préfixe « Claude », par exemple **Sonnet 5.5** et **Opus 5.5**.

Dans le sélecteur de modèle de la fenêtre de chat, un modèle Cloud peut porter une étiquette :

| Étiquette | Signification |
| --- | --- |
| **New** | Ajouté dans les 14 derniers jours. |
| Une réduction, par exemple **50% OFF** | Le modèle coûte moins pour l'instant. Pointez la ligne, ou atteignez-la avec les flèches, pour voir le prix habituel. |
| **Free** | Le modèle n'utilise pas de points. |
| **Preview** | Une version anticipée du modèle. |
| Une date | Le jour où le modèle quitte Enconvo Cloud. |

Enconvo Cloud pose les étiquettes, donc elles changent sans mise à jour de l'app.

## Points et utilisation

Les modèles coûtent des nombres de points différents. Les Réglages affichent le prix Cloud à côté de chaque modèle et fournisseur, ainsi que ce que votre forfait inclut, comme les minutes gratuites qu'il vous reste ce mois-ci. Voir les pages [Cloud Plan](https://www.enconvo.com/cloud-plan) et [Cloud pricing](https://www.enconvo.com/cloud-pricing) pour les forfaits et tarifs actuels. Pour voir ce que vous avez utilisé, ouvrez **Réglages → Utilisation des points**.

[Auto Route](/fr/providers/auto-route), le modèle par défaut, tourne sur des modèles Enconvo Cloud. Choisir la route de chaque message est gratuit ; le modèle qui répond utilise des points.

Certains services Cloud sont gratuits pour chaque compte connecté :

- La recherche web avec **Enconvo Cloud** et **DeepSeek (Enconvo Cloud)**. Voir [Recherche web](/fr/ai/web-search).
- La reconnaissance vocale avec **Enconvo Cloud Fast**. Voir [Reconnaissance vocale](/fr/ai/speech-recognition).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Les requêtes vous demandent de vous connecter | Connectez-vous dans **Réglages → Compte**. |
| Les requêtes échouent avec une erreur de points ou de solde | Vérifiez **Réglages → Utilisation des points**, puis votre forfait sur la page [Cloud Plan](https://www.enconvo.com/cloud-plan). |
| Un modèle manque | Le sélecteur montre ce que votre forfait inclut. Cliquez sur **Actualiser** à côté de **Nom du modèle**. |

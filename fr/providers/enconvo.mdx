Enconvo Cloud vous donne des modèles de plusieurs entreprises, ainsi que des outils de voix, d’image, de vidéo et de web, via votre compte Enconvo. Il n’y a aucune clé API à gérer : les requêtes utilisent les points de votre offre. C’est le moyen le plus rapide de démarrer.

## Configuration

<Steps>
  <Step title="Se connecter">
    Connectez-vous à votre compte Enconvo. Voir [Compte](/fr/configuration/account).
  </Step>
  <Step title="Choisir Enconvo Cloud">
    Ouvrez la page de Réglages correspondant à ce que vous voulez faire, comme **Modèle d’IA**, **Synthèse vocale** ou **Génération d’images**, et choisissez le fournisseur nommé **Enconvo Cloud** ou **Enconvo Cloud Plan**.
  </Step>
  <Step title="Choisir un modèle ou une voix">
    Choisissez un modèle ou une voix et lancez une courte requête.
  </Step>
</Steps>

Chaque fonctionnalité a son propre choix de fournisseur. Choisir Enconvo Cloud pour le chat ne change pas la voix, les images, la vidéo, les embeddings, le reclassement ni les outils web ; réglez chacun là où vous le souhaitez.

## Les modèles propres à Enconvo

Enconvo Cloud a trois modèles à lui, nommés d’après le travail auquel ils conviennent :

| Modèle | À utiliser pour |
| --- | --- |
| **Enconvo Fast** | Les tours rapides : réponses courtes, reformulations, petites actions. C’est le modèle sur lequel **Enconvo Cloud Plan** démarre, et le modèle par défaut des Commandes IA. |
| **Enconvo Balanced** | Le travail courant en quelques étapes. |
| **Enconvo Ultra** | Les tâches difficiles qui demandent un raisonnement approfondi. |

Ils sont listés en premier sous **Enconvo Cloud Plan**, et [Auto Route](/fr/providers/auto-route) les utilise pour ses routes par défaut.

## Trouver un modèle dans le sélecteur

La liste **Enconvo Cloud Plan** regroupe les modèles par éditeur : les modèles propres à Enconvo d’abord, puis Anthropic, OpenAI, Google et les autres, chacun avec un compteur. Un éditeur affiche ses quatre modèles les plus récents ; cliquez sur **Afficher N modèles précédents** pour voir les autres. La recherche liste toutes les correspondances, et le modèle utilisé par votre chat s’affiche toujours. Les modèles Claude sont listés sans le préfixe « Claude », comme **Sonnet 5.5** et **Opus 5.5**.

Dans le sélecteur de modèle de la Fenêtre de chat, un modèle Cloud peut porter une étiquette :

| Étiquette | Signification |
| --- | --- |
| **Nouveau** | Ajouté au cours des 14 derniers jours. |
| Une remise, comme **50% OFF** | Le modèle coûte moins cher pour le moment. Pointez la ligne, ou atteignez-la avec les touches fléchées, pour voir le prix normal. |
| **Gratuit** | Le modèle n’utilise aucun point. |
| **Aperçu** | Une version préliminaire du modèle. |
| Une date | Le jour où le modèle quitte Enconvo Cloud. |

Enconvo Cloud définit les étiquettes, elles changent donc sans mise à jour de l’app.

## Points et consommation

Les modèles coûtent des nombres de points différents. Les Réglages affichent le prix Cloud à côté de chaque modèle et fournisseur, avec ce que votre offre inclut, comme les minutes gratuites qu’il vous reste ce mois-ci. Voir les pages [Offre Cloud](https://www.enconvo.com/cloud-plan) et [Tarifs Cloud](https://www.enconvo.com/cloud-pricing) pour les offres et les tarifs actuels. Pour voir ce que vous avez utilisé, ouvrez **Réglages → Utilisation des points**.

[Auto Route](/fr/providers/auto-route), le modèle par défaut, s’exécute sur des modèles Enconvo Cloud. Le choix de la route pour chaque message est gratuit ; le modèle qui répond utilise des points.

Certains services Cloud sont gratuits pour tous les comptes connectés :

- La recherche web avec **Enconvo Cloud** et **DeepSeek (Enconvo Cloud)**. Voir [Recherche web](/fr/ai/web-search).
- La reconnaissance vocale avec **Enconvo Cloud Fast**. Voir [Reconnaissance vocale](/fr/ai/speech-recognition).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Les requêtes vous demandent de vous connecter | Connectez-vous sous **Réglages → Compte**. |
| Les requêtes échouent avec une erreur de points ou de solde | Vérifiez **Réglages → Utilisation des points**, puis votre offre sur la page [Offre Cloud](https://www.enconvo.com/cloud-plan). |
| Un modèle est absent | Le sélecteur affiche ce que votre offre inclut. Cliquez sur **Actualiser** à côté de **Nom du modèle**. |

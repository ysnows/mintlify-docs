Utilisez les modèles OpenAI que votre organisation déploie sur Azure. Enconvo communique directement avec votre ressource Azure ; l’accès, les quotas et la facturation suivent donc votre abonnement Azure.

## Avant de commencer

Il vous faut une ressource Azure OpenAI avec au moins un déploiement de modèle. Depuis le portail Azure, copiez la **clé** de la ressource, son **point d’accès** (endpoint) et le **nom du déploiement** que vous avez donné au modèle. Voir [Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/overview) si vous n’en avez pas encore configuré.

## Connecter

<Steps>
  <Step title="Ajouter l’identifiant">
    Ouvrez **Réglages → Modèle d’IA → Azure OpenAI**. Sous **Authentification**, renseignez **Clé API**, **Endpoint** et **API Version**, puis cliquez sur **Valider**. Le point d’accès ressemble à `https://<resource>.cognitiveservices.azure.com/`.
  </Step>
  <Step title="Définir le déploiement">
    Saisissez le nom de votre déploiement dans **Azure OpenAI Api Deployment Name**. Utilisez le nom indiqué dans votre ressource Azure, qui peut différer du nom du modèle.
  </Step>
  <Step title="Tester">
    Envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Azure OpenAI Api Deployment Name** | Le déploiement appelé par ce fournisseur. |
| **Streaming** | Affiche la réponse au fur et à mesure qu’elle s’écrit. Activé par défaut ; désactivez-le si votre déploiement ne prend pas en charge le streaming. |
| **API Version** | Dans l’identifiant. La valeur par défaut est `2025-01-01-preview`. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Vérifiez que la clé et **Endpoint** proviennent de la même ressource Azure. |
| Le déploiement est introuvable | Copiez exactement le nom du déploiement depuis le portail Azure. |
| La réponse n’apparaît jamais | Désactivez **Streaming** et réessayez. |
| Erreurs de débit ou de quota | Augmentez le quota du déploiement dans Azure, ou passez temporairement à un autre fournisseur. |

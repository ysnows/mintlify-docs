title: "Vercel AI Gateway"

---

Vercel AI Gateway achemine une clé vers des modèles de nombreuses entreprises. La facturation et l’accès suivent votre compte Vercel. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les agents et les commandes IA. Vercel AI Gateway facture l’usage à votre propre compte.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans [Vercel AI Gateway](https://vercel.com/ai-gateway).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Vercel AI Gateway**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une seconde clé Vercel AI Gateway, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Ce qu’il fait |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |
| **Outil de recherche Google** | Permet aux modèles compatibles d’ancrer les réponses dans Google Search. Désactivé par défaut. |
| **Outil de contexte d’URL** | Permet aux modèles compatibles de lire les pages des liens de votre message. Désactivé par défaut. |

Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans votre compte Vercel AI Gateway. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge l’entrée d’images ou les appels d’outils. |
| Erreurs de débit ou de limite d’usage | Vérifiez l’usage et les limites dans votre compte Vercel AI Gateway, ou passez à un autre fournisseur pour le moment. |
| Les réponses sont lentes | Essayez un modèle plus petit, une entrée plus courte, ou un effort de raisonnement plus faible. |

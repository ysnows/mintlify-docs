title: "Cerebras"
description: "Discutez avec les modèles Cerebras dans Enconvo avec votre propre clé API Cerebras."
---

Cerebras propose ses modèles via une clé API. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les discussions, les Agents et les Commandes IA. Cerebras facture l’usage sur votre propre compte. Le fournisseur apparaît sous le nom **Cerebras AI** dans les Réglages.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur [Cerebras](https://cerebras.ai/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Cerebras AI**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une seconde clé Cerebras, par exemple une clé professionnelle, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |

Pour utiliser un autre modèle dans une seule discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

Pour le détail des modèles et leurs limites, voir la [documentation d’inférence de Cerebras](https://inference-docs.cerebras.ai/openai).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active dans votre compte Cerebras. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui accepte les images en entrée ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et les limites dans votre compte Cerebras, ou passez temporairement à un autre fournisseur. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte ou un effort de raisonnement plus faible. |

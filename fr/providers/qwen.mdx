Utilisez les modèles Qwen d’Alibaba dans les chats, les Agents et les Commandes IA. Connectez-vous avec une clé API d’Alibaba Cloud Model Studio ; Alibaba Cloud facture l’utilisation à votre compte. Pour le service de Chine continentale (Bailian), utilisez [DashScope](/fr/providers/dashscope).

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Qwen**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Qwen se connecte uniquement avec une clé API.

## Modèles et options

| Réglage | Effet |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **URL de base** | Dans l’identifiant. La valeur par défaut est le point de terminaison international, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Changez-la si votre clé appartient à une autre région. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Vérifiez que la clé et l’**URL de base** appartiennent à la même région, puis collez à nouveau la clé entière. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Erreurs de débit ou de limite d’utilisation | Vérifiez l’utilisation et le quota dans Model Studio, ou passez à un autre fournisseur pour l’instant. |

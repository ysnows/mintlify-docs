Utilisez les modèles Qwen d’Alibaba dans les discussions, les Agents et les Commandes IA. Connectez-vous avec une clé API d’Alibaba Cloud Model Studio ; Alibaba Cloud facture l’usage sur votre compte. Pour le service de Chine continentale (Bailian), utilisez [DashScope](/fr/providers/dashscope).

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Qwen**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

Qwen se connecte uniquement avec une clé API.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **Base Url** | Dans l’identifiant. La valeur par défaut est le point d’accès international, `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Modifiez-la si votre clé appartient à une autre région. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Vérifiez que la clé et **Base Url** appartiennent à la même région, puis collez de nouveau la clé en entier. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et le quota dans Model Studio, ou passez temporairement à un autre fournisseur. |

Utilisez les modèles Claude d’Anthropic dans les chats, les Agents et les Commandes IA. Connectez-vous avec une clé API Anthropic, facturée par Anthropic à la requête, ou connectez-vous avec votre forfait Claude.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans la [console Anthropic](https://console.anthropic.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Anthropic**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un forfait Claude ? Choisissez **Abonnement Claude** sous **Authentification** à la place et cliquez sur **Connecter**. Voir [Abonnement Claude](/fr/providers/anthropic_subscription).
</Tip>

Pour conserver une deuxième clé Anthropic, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Effet |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **URL de base de l’API** | Dans l’identifiant. La valeur par défaut est `https://api.anthropic.com`. Ne la changez que pour utiliser un service compatible Anthropic. |

Les contrôles de raisonnement dans le chat dépendent du modèle choisi. Claude Fable 5.2, le modèle le plus capable d’Anthropic, accepte un effort de raisonnement de **Faible** à **Maximale** et propose le mode Fast avec une clé API. Les modèles Claude qui peuvent aller jusqu’à 1 M de jetons démarrent avec un contexte de 500 K ; vous pouvez l’augmenter dans **Gérer les modèles**. Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans la console Anthropic. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Erreurs de débit ou de limite d’utilisation | Vérifiez l’utilisation et les limites dans la console Anthropic, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une entrée plus courte, ou un effort de raisonnement plus faible. |

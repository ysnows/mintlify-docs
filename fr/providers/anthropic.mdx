Utilisez les modèles Claude d’Anthropic dans les discussions, les Agents et les Commandes IA. Connectez-vous avec une clé API Anthropic, qu’Anthropic facture à chaque requête, ou connectez-vous avec votre abonnement Claude.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans la [console Anthropic](https://console.anthropic.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Anthropic**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un abonnement Claude ? Choisissez plutôt **Claude Subscription** sous **Authentification**, puis cliquez sur **Connecter**. Voir [Claude Subscription](/fr/providers/anthropic_subscription).
</Tip>

Pour conserver une seconde clé Anthropic, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **URL de base de l’API** | Dans l’identifiant. La valeur par défaut est `https://api.anthropic.com`. Ne la modifiez que pour utiliser un service compatible Anthropic. |

Les commandes de raisonnement de la discussion dépendent du modèle choisi. Claude Fable 5.2, le modèle le plus performant d’Anthropic, accepte un effort de raisonnement de **Faible** à **Maximale** et propose le mode Fast avec une clé API. Les modèles Claude qui acceptent jusqu’à 1 M de jetons démarrent avec un contexte de 500 K ; vous pouvez l’augmenter dans **Gérer les modèles**. Pour utiliser un autre modèle dans une seule discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active dans la console Anthropic. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et les limites dans la console Anthropic, ou passez temporairement à un autre fournisseur. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte ou un effort de raisonnement plus faible. |

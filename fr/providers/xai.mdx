---

Utilisez les modèles Grok de xAI dans les discussions, les Agents et les commandes d’IA. Connectez-vous avec une clé API xAI, que xAI facture à la requête, ou connectez-vous avec votre forfait Grok. Il apparaît comme **X.AI-GROK** dans les Réglages.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans la console xAI ; le [démarrage rapide xAI](https://docs.x.ai/docs/quickstart#creating-an-api-key) montre comment.
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → X.AI-GROK**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un forfait Grok ? Choisissez **Abonnement Grok** sous **Authentification** à la place et cliquez sur **Connecter**.
</Tip>

Pour garder une seconde clé xAI, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Ce qu’il fait |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |
| **API Base Url** | Dans l’identifiant. Le défaut est `https://api.x.ai/v1`. |

xAI a aussi ses propres fournisseurs pour la synthèse vocale, la génération d’images, la transcription, la génération de vidéo et X Search. Ils partagent la clé ou la connexion Grok de ce profil ; choisissez chacun dans sa propre page de Réglages.

## Sur l’iPhone

L’app iPhone peut aussi utiliser un forfait Grok dans les chats du téléphone. Sur l’iPhone, ouvrez **Réglages → Modèle d’IA → xAI**, choisissez la carte Grok sous **Authentification**, et touchez **Se connecter avec Grok**. Voir [Chats du téléphone](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau toute la clé et vérifiez qu’elle est active dans la console xAI. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| La connexion Grok ne fonctionne plus | Ouvrez le menu de la carte du compte et cliquez sur **Reconnecter**. |
| Erreurs de débit ou de limite d’usage | Vérifiez l’usage dans votre compte xAI, ou passez à un autre fournisseur pour l’instant. |

description: "Discutez avec les modèles Grok dans Enconvo avec une clé API xAI ou votre abonnement Grok."
---

Utilisez les modèles Grok de xAI dans les discussions, les Agents et les Commandes IA. Connectez-vous avec une clé API xAI, que xAI facture à chaque requête, ou connectez-vous avec votre abonnement Grok. Le fournisseur apparaît sous le nom **X.AI-GROK** dans les Réglages.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans la console xAI ; le [guide de démarrage xAI](https://docs.x.ai/docs/quickstart#creating-an-api-key) explique comment.
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → X.AI-GROK**. Sous **Authentification**, choisissez **Clé API**, collez la clé, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

<Tip>
Vous avez un abonnement Grok ? Choisissez plutôt **Grok Subscription** sous **Authentification**, puis cliquez sur **Connecter**.
</Tip>

Pour conserver une seconde clé xAI, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **URL de base de l’API** | Dans l’identifiant. La valeur par défaut est `https://api.x.ai/v1`. |

xAI dispose aussi de ses propres fournisseurs pour la synthèse vocale, la génération d’images, la transcription, la génération de vidéos et X Search. Ils partagent la clé ou la connexion Grok de ce profil ; choisissez chacun dans sa propre page des Réglages.

## Sur l’iPhone

L’app iPhone peut aussi utiliser un abonnement Grok dans les Discussions du téléphone. Sur l’iPhone, ouvrez **Réglages → Modèle d’IA → xAI**, choisissez la carte Grok sous **Authentification**, puis touchez **Se connecter avec Grok**. Voir [Discussions du téléphone](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active dans la console xAI. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| La connexion Grok ne fonctionne plus | Ouvrez le menu de la carte du compte et cliquez sur **Reconnecter**. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage dans votre compte xAI, ou passez temporairement à un autre fournisseur. |

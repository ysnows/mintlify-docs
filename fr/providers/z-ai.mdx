---

Z.AI propose ses modèles via une clé API. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les Agents et les Commandes IA. Z.AI facture l’utilisation à votre propre compte.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur [Z.AI](https://z.ai/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Z.AI**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une deuxième clé Z.AI, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Effet |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |

Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

Pour les détails des modèles et les limites, voir la [documentation Z.AI](https://docs.z.ai/).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans votre compte Z.AI. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge l’entrée d’image ou les appels d’outils. |
| Erreurs de débit ou de limite d’utilisation | Vérifiez l’utilisation et les limites dans votre compte Z.AI, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une entrée plus courte, ou un effort de raisonnement plus faible. |

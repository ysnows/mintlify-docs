title: "Xiaomi MiMo"
description: "Discutez avec les modèles Xiaomi MiMo dans Enconvo avec votre propre clé API Xiaomi MiMo."
---

Xiaomi MiMo propose ses modèles via une clé API. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les discussions, les Agents et les commandes d’IA. Xiaomi MiMo facture l’usage à votre propre compte.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur la [plateforme Xiaomi MiMo](https://platform.xiaomimimo.com/).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Xiaomi MiMo**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour garder une seconde clé Xiaomi MiMo, par exemple pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Ce qu’il fait |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |

Pour utiliser un autre modèle dans une discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau toute la clé et vérifiez qu’elle est active dans votre compte Xiaomi MiMo. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge l’entrée d’images ou les appels d’outils. |
| Erreurs de débit ou de limite d’usage | Vérifiez l’usage et les limites dans votre compte Xiaomi MiMo, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une entrée plus courte, ou un effort de raisonnement plus bas. |

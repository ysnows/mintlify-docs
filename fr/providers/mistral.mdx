title: "Mistral AI"
description: "Discutez avec les modèles Mistral dans Enconvo avec une clé API Mistral ou votre compte Mistral."
---

Utilisez les modèles de Mistral dans les chats, les Agents et les Commandes IA. Collez une clé API Mistral, ou connectez-vous avec votre compte Mistral et laissez Enconvo créer la clé pour vous. Mistral facture l’utilisation à votre compte dans les deux cas.

## Connexion

<Tabs>
  <Tab title="Se connecter avec Mistral">
    <Steps>
      <Step title="Ouvrir le fournisseur">
        Ouvrez **Réglages → Modèle d’IA → Mistral AI**.
      </Step>
      <Step title="Se connecter">
        Sous **Authentification**, choisissez la connexion au compte Mistral et cliquez sur **Connecter**. Connectez-vous avec votre compte Mistral et choisissez un espace de travail. La connexion fonctionne comme celle de Mistral Vibe : elle crée une clé API pour cet espace, donc rien à copier.
      </Step>
      <Step title="Choisir un modèle">
        Choisissez un modèle dans **Nom du modèle** et envoyez un court message.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Utiliser une clé API">
    <Steps>
      <Step title="Obtenir une clé API">
        Créez une clé dans la [console Mistral](https://console.mistral.ai/api-keys/).
      </Step>
      <Step title="L’ajouter à Enconvo">
        Ouvrez **Réglages → Modèle d’IA → Mistral AI**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
      </Step>
      <Step title="Choisir un modèle">
        Choisissez un modèle dans **Nom du modèle** et envoyez un court message.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Une fois connecté, la carte du compte affiche votre forfait, la clé et ce qu’il reste de vos limites par minute.

## Modèles et options

| Réglage | Effet |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **Effort de raisonnement** (dans le chat) | Pour Mistral Large 4, Medium 3.5 et Small 4 : **Aucun** répond sans réfléchir, **Élevée** réfléchit d’abord. Large 4 réfléchit par défaut. |

La transcription Voxtral et Mistral OCR peuvent utiliser la même connexion ou la même clé.

## Sur l’iPhone

L’app iPhone peut aussi utiliser votre forfait Le Chat dans les chats du téléphone. Sur l’iPhone, ouvrez **Réglages → Modèle d’IA → Mistral**, choisissez la carte Le Chat sous **Authentification**, et touchez **Se connecter avec Mistral**. Voir [Chats du téléphone](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans la console Mistral. |
| La connexion cesse de fonctionner | Ouvrez le menu de la carte du compte et cliquez sur **Reconnecter**. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle**. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Erreurs de limite de débit | La limite par minute de votre espace de travail est épuisée. Attendez une minute, ou vérifiez les limites dans la console Mistral. |

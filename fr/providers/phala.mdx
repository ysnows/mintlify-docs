title: "Phala"
description: "Discutez avec les modèles Phala dans Enconvo avec votre propre clé API Phala."
---

Phala exécute les modèles sur du matériel de calcul confidentiel. Utilisez une clé API **Confidential AI**. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les discussions, les Agents et les Commandes IA. Phala facture l’usage sur votre propre compte.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé sur [Phala Cloud](https://cloud.phala.ai).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Phala**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une seconde clé Phala, par exemple une clé professionnelle, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |

Pour utiliser un autre modèle dans une seule discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

**Valider** envoie une requête de discussion minimale, avec au plus un jeton en sortie. Enconvo définit lui-même le point d’accès. La vision et les appels d’outils dépendent du modèle ; qu’un modèle les prenne en charge ne signifie pas que les autres le font.

Pour le détail des modèles et leurs limites, voir la [documentation Phala Confidential AI](https://docs.phala.com/phala-cloud/confidential-ai/confidential-model/confidential-ai-api).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active dans votre compte Phala. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui accepte les images en entrée ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et les limites dans votre compte Phala, ou passez temporairement à un autre fournisseur. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte ou un effort de raisonnement plus faible. |

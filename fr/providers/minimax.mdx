title: "MiniMax"

MiniMax propose ses modèles par une clé API. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les Agents et les Commandes IA. MiniMax facture l’usage sur votre propre compte. Il apparaît comme **Minimax AI** dans les Réglages.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans le [centre utilisateur MiniMax](https://platform.minimax.io/user-center/basic-information).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Minimax AI**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une deuxième clé MiniMax, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Rôle |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou restaure des modèles. |

Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

MiniMax a aussi un fournisseur de synthèse vocale. Choisissez-le sous **Réglages → Synthèse vocale**.

Pour les détails et les limites des modèles, voir la [référence API MiniMax](https://platform.minimax.io/docs/api-reference/api-overview).

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau toute la clé et vérifiez qu’elle est active dans votre compte MiniMax. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge la saisie d’images ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Vérifiez l’usage et les limites dans votre compte MiniMax, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte, ou un effort de raisonnement plus bas. |

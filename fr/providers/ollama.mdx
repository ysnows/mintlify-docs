title: "Ollama"

Utilisez Ollama pour exécuter des modèles sur votre propre matériel, sur ce Mac ou sur un autre ordinateur de votre réseau. Enconvo envoie les discussions au serveur Ollama, aucun compte chez un fournisseur n’est donc nécessaire.

## Se connecter sur ce Mac

<Steps>
  <Step title="Démarrer Ollama">
    Installez [Ollama](https://ollama.ai/), démarrez-le et téléchargez un modèle avec les outils d’Ollama.
  </Step>
  <Step title="Indiquer son adresse à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Ollama**. Sous **Authentification**, laissez **BaseUrl** sur `http://127.0.0.1:11434`, sauf si vous avez changé le port d’Ollama.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

## Se connecter à un autre ordinateur

1. Sur l’autre ordinateur, configurez Ollama pour qu’il accepte les connexions de votre réseau, et pas seulement les siennes.
2. Dans Enconvo, définissez **BaseUrl** sur l’adresse réseau de cet ordinateur, en gardant le port et le chemin. `127.0.0.1` et `localhost` désignent toujours le Mac qui exécute Enconvo.
3. Si macOS bloque la connexion, activez Enconvo dans **Réglages Système → Confidentialité et sécurité → Réseau local**.

N’ouvrez le serveur qu’aux réseaux de confiance.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste depuis le serveur. |
| **Response Timeout** | La durée d’attente pour que le serveur démarre ou poursuive une réponse. La valeur par défaut est **Sans limite** ; sur votre propre matériel, un long prompt peut prendre plusieurs minutes avant le premier mot. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| Connexion refusée | Vérifiez qu’Ollama est lancé et que **BaseUrl** contient la bonne adresse et le bon port. Pour un autre ordinateur, vérifiez qu’il accepte les connexions réseau. |
| Réseau inaccessible | Vérifiez le réseau, ainsi que l’autorisation **Réseau local** dans les Réglages Système. |
| La liste de modèles est vide | Chargez ou téléchargez un modèle dans Ollama, puis cliquez sur **Actualiser**. |
| Une réponse s’interrompt en cours de route | Réglez **Response Timeout** sur une valeur plus longue ou sur **Sans limite**. |
| Les outils ou les images échouent | Choisissez un modèle qui prend en charge les appels d’outils ou les images en entrée. |
| Mémoire insuffisante | Choisissez un modèle plus petit, ou raccourcissez la saisie. |

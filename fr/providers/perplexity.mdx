title: "Perplexity"
description: "Discutez avec les modèles Perplexity dans Enconvo avec votre propre clé API Perplexity."
---

Les modèles Sonar de Perplexity cherchent sur le web en répondant. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les chats, les Agents et les Commandes IA. Perplexity facture l’utilisation à votre propre compte.

## Connexion

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans les [réglages API Perplexity](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Perplexity**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Une réponse signifie que la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une deuxième clé Perplexity, par exemple une pour le travail, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Effet |
| --- | --- |
| **Nom du modèle** | Le modèle que ce fournisseur utilise. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **frequencyPenalty** | Réduit la chance de mots répétés. La valeur par défaut est 1. |

Pour utiliser un autre modèle dans un chat, choisissez-le dans le sélecteur de modèle de ce chat.

Ce fournisseur de chat est distinct de **Réglages → Recherche web** : choisir Perplexity ici ne change pas le fournisseur de recherche que vos agents utilisent. Quand une réponse porte sur l’actualité, ouvrez les sources qu’elle cite.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez à nouveau la clé entière et vérifiez qu’elle est active dans votre compte Perplexity. |
| Un modèle manque | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui prend en charge l’entrée d’image ou les appels d’outils. |
| Erreurs de débit ou de limite d’utilisation | Vérifiez l’utilisation et les limites dans votre compte Perplexity, ou passez à un autre fournisseur pour l’instant. |
| Les réponses sont lentes | Essayez un modèle plus petit, une entrée plus courte, ou un effort de raisonnement plus faible. |

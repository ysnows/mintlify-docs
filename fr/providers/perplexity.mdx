---
title: "Perplexity"
description: "Discutez avec les modèles Perplexity dans Enconvo avec votre propre clé API Perplexity."
---

Les modèles Sonar de Perplexity effectuent des recherches sur le web pendant qu’ils répondent. Ajoutez votre clé à Enconvo pour utiliser ces modèles dans les discussions, les Agents et les Commandes IA. Perplexity facture l’usage sur votre propre compte.

## Connecter

<Steps>
  <Step title="Obtenir une clé API">
    Créez une clé dans les [réglages de l’API Perplexity](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="L’ajouter à Enconvo">
    Ouvrez **Réglages → Modèle d’IA → Perplexity**. Sous **Authentification**, collez la clé dans **Clé API**, puis cliquez sur **Valider**.
  </Step>
  <Step title="Choisir un modèle">
    Choisissez un modèle dans **Nom du modèle** et envoyez un court message. Si une réponse arrive, la connexion fonctionne.
  </Step>
</Steps>

Pour conserver une seconde clé Perplexity, par exemple une clé professionnelle, cliquez sur **Ajouter un nouveau fournisseur** et créez un autre profil.

## Modèles et options

| Réglage | Fonction |
| --- | --- |
| **Nom du modèle** | Le modèle utilisé par ce fournisseur. **Actualiser** à côté recharge la liste ; **Gérer les modèles** (l’engrenage) ajoute ou rétablit des modèles. |
| **frequencyPenalty** | Réduit le risque de répétition de mots. La valeur par défaut est 1. |

Pour utiliser un autre modèle dans une seule discussion, choisissez-le dans le sélecteur de modèle de cette discussion.

Ce fournisseur de discussion est distinct de **Réglages → Recherche web** : choisir Perplexity ici ne change pas le fournisseur de recherche que vos Agents utilisent. Lorsqu’une réponse porte sur l’actualité, ouvrez les sources qu’elle cite.

## Dépannage

| Problème | Que faire |
| --- | --- |
| **Valider** échoue | Collez de nouveau la clé en entier et vérifiez qu’elle est active dans votre compte Perplexity. |
| Un modèle est absent | Cliquez sur **Actualiser** à côté de **Nom du modèle** pour recharger la liste. Pour ajouter un modèle vous-même, utilisez **Gérer les modèles**. |
| Les images ou les outils échouent | Choisissez un modèle qui accepte les images en entrée ou les appels d’outils. |
| Erreurs de limite de débit ou d’usage | Consultez l’usage et les limites dans votre compte Perplexity, ou passez temporairement à un autre fournisseur. |
| Les réponses sont lentes | Essayez un modèle plus petit, une saisie plus courte ou un effort de raisonnement plus faible. |

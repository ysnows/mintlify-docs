---

Utilisez votre forfait GitHub Copilot comme fournisseur de modèle d’IA dans Enconvo. Vous vous connectez avec le compte GitHub qui possède le forfait ; aucune clé API n’est en jeu. Les modèles premium comptent dans les demandes premium de votre forfait.

## Connecter

<Steps>
  <Step title="Ouvrir le fournisseur">
    Ouvrez **Réglages → Modèle d’IA → GitHub Copilot**.
  </Step>
  <Step title="Lancer la connexion">
    Dans **Authentification**, cliquez sur **Connecter**.
  </Step>
  <Step title="Saisir le code sur GitHub">
    Votre navigateur ouvre la page d’appareil de GitHub, et Enconvo affiche le code à y saisir. Saisissez le code et autorisez la connexion.
  </Step>
  <Step title="Vérifier le compte">
    Revenez dans Enconvo et vérifiez que le compte GitHub voulu est connecté.
  </Step>
  <Step title="Choisir un modèle">
    Sélectionnez un modèle et essayez une courte demande.
  </Step>
</Steps>

Fermer la boîte de dialogue du code d’Enconvo avant d’autoriser annule la connexion.

## Modèles et options

La liste des modèles n’affiche que ceux que votre forfait Copilot peut utiliser, avec le modèle de chat par défaut de Copilot en premier. Copilot Free propose moins de modèles que les forfaits payants, donc un modèle vu ailleurs peut ne pas être listé. Chaque modèle utilise les niveaux d’effort de raisonnement que Copilot propose pour lui.

## Sur l’iPhone

L’app iPhone peut aussi se connecter à GitHub Copilot, pour les chats Téléphone sur le téléphone. Voir [Chats Téléphone](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| La connexion ne se termine pas | Saisissez le code sur la page GitHub avant qu’il n’expire, puis cliquez à nouveau sur **Connecter** pour un nouveau code. |
| Le modèle voulu n’est pas listé | Votre forfait Copilot ne l’inclut pas ; choisissez un autre modèle ou passez à un forfait supérieur. |
| Une demande échoue avec une erreur de modèle | Choisissez un modèle dans la liste actuelle ; un défaut choisi avant le changement de forfait peut ne plus être proposé. |
| Limite de débit ou d’usage | Les demandes premium de votre forfait et les limites de débit de GitHub. |

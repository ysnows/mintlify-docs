Utilisez votre abonnement GitHub Copilot comme fournisseur de Modèle d’IA dans Enconvo. Vous vous connectez avec le compte GitHub qui a l’abonnement ; aucune clé API n’intervient. Les modèles premium comptent dans les requêtes premium de votre abonnement.

## Connexion

<Steps>
  <Step title="Ouvrir le fournisseur">
    Ouvrez **Réglages → Modèle d’IA → GitHub Copilot**.
  </Step>
  <Step title="Lancer la connexion">
    Dans **Authentification**, cliquez sur **Connecter**.
  </Step>
  <Step title="Saisir le code sur GitHub">
    Votre navigateur ouvre la page d’appareil de GitHub, et Enconvo affiche le code à y saisir. Saisissez le code et autorisez la connexion.
  </Step>
  <Step title="Vérifier le compte">
    Revenez dans Enconvo et vérifiez que le bon compte GitHub est connecté.
  </Step>
  <Step title="Choisir un modèle">
    Sélectionnez un modèle et essayez une courte requête.
  </Step>
</Steps>

Fermer la boîte de dialogue du code d’Enconvo avant d’autoriser annule la connexion.

## Modèles et options

La liste des modèles n’affiche que les modèles que votre abonnement Copilot peut utiliser, avec en premier le modèle de chat par défaut de Copilot. Copilot Free propose moins de modèles que les abonnements payants, si bien qu’un modèle vu ailleurs peut ne pas être listé. Chaque modèle utilise les niveaux d’effort de raisonnement que Copilot propose pour lui.

## Sur l’iPhone

L’app iPhone peut aussi se connecter à GitHub Copilot, pour les chats Phone sur le téléphone. Voir [Discussions du téléphone](/fr/integrations/iphone-phone-chats).

## Dépannage

| Problème | Que faire |
| --- | --- |
| La connexion ne se termine pas | Saisissez le code sur la page de GitHub avant son expiration, puis cliquez de nouveau sur **Connecter** pour obtenir un nouveau code. |
| Le modèle voulu n’est pas listé | Votre abonnement Copilot ne l’inclut pas ; choisissez un autre modèle ou passez à une offre supérieure. |
| Une requête échoue avec une erreur de modèle | Choisissez un modèle dans la liste actuelle ; un modèle par défaut choisi avant le changement de votre abonnement peut ne plus être proposé. |
| Limite de débit ou d’utilisation | Les requêtes premium de votre abonnement et les limites de débit de GitHub. |

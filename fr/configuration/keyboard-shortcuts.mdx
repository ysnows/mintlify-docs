Les fenêtres et les fonctions vocales d’Enconvo s’ouvrent chacune avec un raccourci. **Réglages → Raccourci** liste chaque raccourci qu’Enconvo utilise et la commande qu’il lance, pour que vous puissiez en modifier un ou savoir ce que fait une combinaison de touches. Les raccourcis enregistrés sur votre Mac l’emportent toujours sur les valeurs par défaut de ce guide.

Cette vidéo couvre les raccourcis, puis les autres réglages qui adaptent Enconvo à votre Mac : Compréhension du contexte, Appshots, Modèles locaux, Autorisations et Empêcher la mise en veille.

## Raccourcis par défaut

| Action | Par défaut |
| --- | --- |
| Afficher SmartBar | **⌥Space** |
| Afficher la Fenêtre de chat | **⌃⌘X** |
| Afficher la Barre latérale de l’app | **⌃⌘E** |
| Ouvrir les Réglages, depuis Enconvo | **⌘,** |
| Démarrer la Dictée | **Right ⌘** |
| Démarrer la Commande vocale | **Right ⌥** |
| Mettre en pause ou reprendre l’audio | **⌥P** |

Ces valeurs par défaut ne s’appliquent que si vous n’avez jamais défini votre propre touche ; une touche que vous définissez reste telle quelle. Capture rapide et Appshots n’ont pas de raccourci par défaut : définissez-en un sur leurs pages de réglages avant de les utiliser.

## Modifier un raccourci

1. Ouvrez **Réglages → Raccourci**. L’onglet **Principaux** contient les fonctions principales, **Autres raccourcis** contient les commandes IA, les plugins, les réglages et les commandes qu’aucune autre page n’affiche, et **Tous** montre les deux.
2. Saisissez du texte dans **Filtrer par nom…** pour trouver une commande. Pour trouver la commande derrière une combinaison de touches, cliquez sur **Chercher par raccourci** et appuyez dessus.
3. Cliquez sur le champ de raccourci de la commande et appuyez sur la nouvelle combinaison.
4. Si ces touches lancent déjà une autre commande, le champ vous le dit. Choisissez **L’utiliser ici** pour attribuer les touches à cette commande, ou choisissez l’un des raccourcis libres proposés.
5. Passez à une autre app et essayez le raccourci.

Pour libérer les touches d’un raccourci, retirez-le de la commande. Un message avec **Annuler** permet de revenir en arrière.

Un badge **Local** marque un raccourci qui ne fonctionne qu’à l’intérieur d’Enconvo, comme Épingler SmartBar.

## Comment appuyer

Lorsque vous enregistrez une seule touche de modification, comme Right ⌘, le champ demande **Façon d’appuyer** :

| Option | La commande s’exécute lorsque vous |
| --- | --- |
| **Maintenir ou appuyer** | Maintenez la touche, ou appuyez pour basculer |
| **Appui** | Appuyez pour démarrer, et appuyez encore pour arrêter |
| **Maintenir** | Maintenez la touche enfoncée ; cela fonctionne tant que vous la tenez |
| **Double appui** | Appuyez deux fois rapidement |

Deux touches de modification ou plus enfoncées en même temps comptent comme un seul raccourci. Chaque champ n’affiche que les modes que sa commande prend en charge, et la description à côté indique comment cette fonction réagit.

## Où se trouve le raccourci de chaque fonction

En plus de la page Raccourci, chaque fonction a son raccourci sur sa propre page de réglages :

| Fonction | Page de réglages |
| --- | --- |
| SmartBar | **Réglages → SmartBar** |
| Dynamic Island | **Réglages → Dynamic Island** |
| PopBar | **Réglages → PopBar** |
| Barre latérale de l’app | **Réglages → Barre latérale de l’app** |
| Dictée | **Réglages → Dictée** |
| Commande vocale | **Réglages → Commande vocale** |
| Appshots | **Réglages → Appshots** |
| Dessin à l’écran | **Réglages → Dessin à l’écran** |
| Note vocale | **Réglages → Note vocale** |
| Capture rapide | **Réglages → Capture rapide** |
| Une seule commande | Les réglages de cette commande, lorsqu’elle a un champ **Raccourci clavier** |

## Dans SmartBar

Saisissez un caractère déclencheur dans SmartBar pour chercher un type d’élément :

| Caractère | Ouvre |
| --- | --- |
| **@** | Commandes |
| **#** | Contexte à ajouter à votre message |
| **$** | Compétences |
| **>** | Tâches récentes |

Modifiez ces caractères sous **Rechercher** dans **Réglages → SmartBar**. Le menu slash contient des actions comme le choix du modèle et du raisonnement.

Pour parcourir les listes au clavier, choisissez **Raccourcis de navigation** dans **Réglages → SmartBar** : **macOS** utilise **⌃N** **⌃P** **⌃F** **⌃B**, et **Vim** utilise **⌃J** **⌃K** **⌃L** **⌃H**.

## Adapter Enconvo à votre Mac

La même fenêtre de réglages contient les autres choix que la vidéo parcourt :

| Page de réglages | Ce qu’elle fait |
| --- | --- |
| **Compréhension du contexte** | Choisit ce que SmartBar récupère de l’app où vous étiez : le texte sélectionné, votre sélection dans le Finder, ou la page dans votre navigateur. **Joindre** l’ajoute dès l’ouverture de SmartBar, et **Suggérer** le propose en un clic. Voir [Compréhension du contexte](/fr/features/context-awareness). |
| **Appshots** | Ajoute la fenêtre devant vous à la conversation avec un raccourci. Voir [Appshots](/fr/features/appshots). |
| **Modèles locaux** | Affiche l’IA qui tourne sur ce Mac, la mémoire et le disque qu’elle utilise, et où chaque fonction s’exécute. Voir [Modèles locaux](/fr/ai/local-llm). |
| **Autorisations** | Liste ce que macOS autorise Enconvo à faire et pourquoi ; **Accorder** corrige une autorisation manquante. Voir [Autorisations macOS](/fr/configuration/permissions). |
| **Empêcher la mise en veille** | Empêche ce Mac de se mettre en veille pendant votre absence, pour que vous puissiez encore y accéder depuis votre iPhone. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un raccourci ne fonctionne qu’à l’intérieur d’Enconvo | Vérifiez s’il a un badge **Local**. Sinon, vérifiez Surveillance de l’entrée et Accessibilité dans [Autorisations macOS](/fr/configuration/permissions), et si une autre app utilise les mêmes touches. |
| Appuyer sur un raccourci fait autre chose | Utilisez **Chercher par raccourci**. Si aucune commande Enconvo n’utilise ces touches, c’est une autre app ou macOS. |
| Un raccourci de touche de modification ne se déclenche pas | Ouvrez le raccourci et vérifiez **Façon d’appuyer** : maintenir, appui, double appui, ou touches enfoncées ensemble. |
| Un raccourci d’une vidéo ou d’un autre Mac ne fonctionne pas | Vos raccourcis peuvent différer. Consultez celui en cours dans **Réglages → Raccourci**. |

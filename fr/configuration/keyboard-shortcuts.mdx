Les fenêtres et les fonctions vocales d’Enconvo s’ouvrent chacune avec un raccourci clavier. **Réglages → Raccourci** liste tous les raccourcis qu’Enconvo utilise et la commande qu’ils exécutent, pour que vous puissiez en changer un ou découvrir ce que fait une combinaison de touches. Les raccourcis enregistrés sur votre Mac l’emportent toujours sur les valeurs par défaut de ce guide.

Cette vidéo présente les Raccourcis, puis les autres réglages qui adaptent Enconvo à votre Mac : Compréhension du contexte, Appshots, Modèles locaux, Autorisations et Empêcher la mise en veille.

## Raccourcis par défaut

| Action | Par défaut |
| --- | --- |
| Afficher la SmartBar | **⌥Espace** |
| Afficher la Fenêtre de chat | **⌃⌘X** |
| Afficher la Barre latérale de l’app | **⌃⌘E** |
| Ouvrir les Réglages, depuis Enconvo | **⌘,** |
| Démarrer la Dictée | **⌘ droite** |
| Démarrer la Commande vocale | **⌥ droite** |
| Mettre l’audio en pause ou le reprendre | **⌥P** |

Ces valeurs ne s’appliquent que si vous n’avez jamais défini votre propre touche ; une touche que vous avez définie reste telle quelle. Capture rapide et Appshots n’ont pas de raccourci par défaut : définissez-en un sur leurs pages de Réglages avant de les utiliser.

## Modifier un raccourci

1. Ouvrez **Réglages → Raccourci**. L’onglet **Principaux** contient les fonctions principales, **Autres raccourcis** contient les commandes d’IA, les plugins, les réglages et les commandes qu’aucune autre page n’affiche, et **Tous** affiche les deux.
2. Saisissez dans **Filtrer par nom…** pour trouver une commande. Pour trouver la commande associée à une combinaison de touches, cliquez sur **Chercher par raccourci** et appuyez dessus.
3. Cliquez sur le champ de raccourci de la commande et appuyez sur la nouvelle combinaison.
4. Si ces touches exécutent déjà une autre commande, le champ vous le dit. Choisissez **L’utiliser ici** pour déplacer les touches vers cette commande, ou choisissez l’un des raccourcis libres qu’il suggère.
5. Passez à une autre app et essayez le raccourci.

Pour libérer les touches d’un raccourci, retirez-le de la commande. Un message avec **Annuler** vous permet de revenir en arrière.

Un badge **Local** signale un raccourci qui ne fonctionne que dans Enconvo, comme Épingler la SmartBar.

## Façon d’appuyer

Lorsque vous enregistrez une touche de modification seule, comme ⌘ droite, le champ demande **Façon d’appuyer** :

| Option | La commande s’exécute quand vous |
| --- | --- |
| **Maintenir ou appuyer** | Maintenez la touche, ou appuyez dessus pour basculer |
| **Appui** | Appuyez sur la touche pour démarrer, et appuyez de nouveau pour arrêter |
| **Maintenir** | Maintenez la touche enfoncée ; elle agit tant que vous la maintenez |
| **Double appui** | Appuyez deux fois rapidement sur la touche |

Deux touches de modification ou plus pressées en même temps comptent comme un seul raccourci. Chaque champ n’affiche que les types que sa commande prend en charge, et la description à côté indique comment cette fonction réagit.

## Où se trouve le raccourci de chaque fonction

En plus de la page Raccourci, chaque fonction a son raccourci sur sa propre page de Réglages :

| Fonction | Page de Réglages |
| --- | --- |
| SmartBar | **Réglages → SmartBar** |
| Dynamic Island | **Réglages → Dynamic Island** |
| PopBar | **Réglages → PopBar** |
| Barre latérale de l’app | **Réglages → Barre latérale de l’app** |
| Dictée | **Réglages → Dictée** |
| Commande vocale | **Réglages → Commande vocale** |
| Appshots | **Réglages → Appshots** |
| Dessin à l’écran | **Réglages → Dessin à l’écran** |
| Note vocale | **Réglages → Note vocale** |
| Capture rapide | **Réglages → Capture rapide** |
| Une seule commande | Les réglages de cette commande, lorsqu’elle a un champ **Raccourci clavier** |

## Dans la SmartBar

Saisissez un caractère déclencheur dans la SmartBar pour rechercher un type d’élément :

| Caractère | Ouvre |
| --- | --- |
| **@** | Les commandes |
| **#** | Le contexte à ajouter à votre message |
| **$** | Les compétences |
| **>** | Les tâches récentes |

Changez ces caractères sous **Rechercher** dans **Réglages → SmartBar**. Le menu des barres obliques contient des actions comme le choix du modèle et du raisonnement.

Pour parcourir les listes au clavier, choisissez **Raccourcis de navigation** dans **Réglages → SmartBar** : **macOS** utilise **⌃N** **⌃P** **⌃F** **⌃B**, et **Vim** utilise **⌃J** **⌃K** **⌃L** **⌃H**.

## Adapter Enconvo à votre Mac

La même fenêtre de Réglages contient les autres choix que la vidéo présente :

| Page de Réglages | Ce qu’elle fait |
| --- | --- |
| **Compréhension du contexte** | Choisit ce que la SmartBar récupère de l’app où vous étiez : le texte sélectionné, votre sélection dans le Finder ou la page de votre navigateur. **Joindre** l’ajoute dès l’ouverture de la SmartBar, et **Suggérer** la propose en un clic. Voir [Compréhension du contexte](/fr/features/context-awareness). |
| **Appshots** | Ajoute à la conversation la fenêtre devant vous avec un raccourci. Voir [Appshots](/fr/features/appshots). |
| **Modèles locaux** | Montre l’IA qui tourne sur ce Mac, la mémoire et le disque qu’elle utilise, et où chaque fonction s’exécute. Voir [Modèles locaux](/fr/ai/local-llm). |
| **Autorisations** | Liste ce que macOS permet à Enconvo de faire et pourquoi ; **Accorder** corrige une autorisation manquante. Voir [Autorisations macOS](/fr/configuration/permissions). |
| **Empêcher la mise en veille** | Empêche ce Mac de se mettre en veille quand vous êtes absent, pour que vous puissiez toujours l’atteindre depuis votre iPhone. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un raccourci ne fonctionne que dans Enconvo | Vérifiez s’il a un badge **Local**. Sinon, vérifiez Surveillance de l’entrée et Accessibilité dans [Autorisations macOS](/fr/configuration/permissions), et si une autre app utilise les mêmes touches. |
| Appuyer sur un raccourci fait autre chose | Utilisez **Chercher par raccourci**. Si aucune commande d’Enconvo n’utilise ces touches, c’est une autre app ou macOS. |
| Un raccourci à touche de modification ne se déclenche pas | Ouvrez le raccourci et vérifiez **Façon d’appuyer** : maintenir, appui, double appui ou touches pressées ensemble. |
| Un raccourci vu dans une vidéo ou sur un autre Mac ne marche pas | Vos raccourcis peuvent être différents. Cherchez le raccourci actuel dans **Réglages → Raccourci**. |

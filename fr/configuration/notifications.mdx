Enconvo peut vous signaler qu’une session d’Agent est terminée en ouvrant la Dynamic Island, en envoyant une notification macOS, ou les deux. Vous le configurez dans **Réglages → Notifications**, avec les heures calmes pour les moments où vous ne voulez pas être dérangé.

## Configurer les alertes de fin

1. Ouvrez **Réglages → Notifications**.
2. Si la page indique **Les notifications sont désactivées pour Enconvo**, cliquez sur **Activer**, ou autorisez Enconvo dans **Réglages Système → Notifications**.
3. Sous **À la fin de la session**, activez ou désactivez chaque interrupteur. Ils fonctionnent indépendamment.
4. Lancez une courte requête à l’Agent et attendez qu’elle se termine.

| Réglage | Ce qu’il fait |
| --- | --- |
| **Ouvrir la Dynamic Island** | Lorsqu’une session que vous avez lancée depuis la Dynamic Island se termine, l’île s’étend pour afficher le résultat. |
| **Envoyer une notification système** | Envoie une notification macOS avec le début de la réponse lorsqu’une session se termine. Cliquez sur la notification pour rouvrir la session dans la fenêtre d’où elle a démarré. |

Les réglages de concentration et de notifications de macOS peuvent masquer les bannières même lorsque ces interrupteurs sont activés.

## Heures calmes

Les heures calmes mettent en attente les questions des Agents, les alertes e-mail et les tâches terminées jusqu’à la fin de la période calme, sur ce Mac et sur votre iPhone associé. Rien n’est approuvé à votre place pendant l’attente.

1. Dans **Réglages → Notifications**, trouvez **Actualités**.
2. Activez **Heures calmes**, puis définissez **Début** et **Fin**.
3. Choisissez ce qui passe quand même :

| Réglage | Ce qu’il fait |
| --- | --- |
| **Toujours signaler les approbations** | Les demandes d’approbation vous parviennent quand même pendant les heures calmes. |
| **Toujours signaler les questions** | Les questions des Agents vous parviennent quand même pendant les heures calmes. |

Le menu d’Enconvo dans la barre des menus propose aussi **Heures calmes**, et **Suspendre les actualités 1 heure** pour une courte pause.

Les alertes e-mail sont désactivées jusqu’à ce que vous les activiez dans **Tâches planifiées → E-mails importants**. Les alertes e-mail que vous avez déjà activées ou configurées continuent de fonctionner. Leur interrupteur **Téléphone** envoie les alertes à un iPhone ou à un téléphone Android associé.

## Résultats planifiés

Une notification système est différente de l’envoi du résultat d’une tâche planifiée vers Telegram ou un autre chat de messagerie instantanée. Vous réglez l’envoi des résultats dans l’éditeur de la [tâche planifiée](/fr/workflows/scheduled-jobs).

Une tâche planifiée peut aussi envoyer sa propre notification Mac lorsqu’elle s’exécute (**M’avertir lors de l’exécution**). Cette notification suit aussi **Envoyer une notification système**. L’historique d’exécution de la tâche indique si chaque exécution a fonctionné et si son résultat a été livré.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Aucune bannière quand une session se termine | Vérifiez que **Envoyer une notification système** est activé, que macOS autorise les notifications d’Enconvo et que le mode de concentration ne les masque pas. |
| La Dynamic Island ne s’est pas ouverte | **Ouvrir la Dynamic Island** ne s’applique qu’aux sessions que vous avez lancées depuis la Dynamic Island. |
| Une question ou une tâche terminée est arrivée en retard | Les heures calmes l’ont peut-être retenue. Activez **Toujours signaler les questions**, ou changez **Début** et **Fin**. |

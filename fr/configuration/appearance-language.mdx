---

**Réglages → Général** regroupe les choix qui changent l’apparence d’Enconvo et la langue qu’il utilise. Cette page explique comment changer la langue de l’interface, rendre Enconvo plus lisible et trouver un réglage sans savoir où il se trouve.

## Changer la langue de l’interface

1. Ouvrez **Réglages → Général** et trouvez **Langue**.
2. Choisissez une langue dans **Langue de l’app**. **Langue du système** utilise la langue de votre Mac.
3. Enconvo propose d’aligner votre **Langue des réponses**. Acceptez si vous voulez que les agents répondent aussi dans la nouvelle langue.

**Langue de l’app** change les menus, les boutons et les réglages sur cet appareil : anglais, chinois simplifié, chinois traditionnel, japonais, coréen, espagnol, allemand, français, italien, portugais, ukrainien et russe. Les apps iPhone et Android proposent les mêmes langues dans leurs propres réglages.

**Langue des réponses** est distincte : les agents, les appels vocaux et l’Avatar y répondent, et le traducteur traduit vers cette langue.

## Ajuster l’apparence d’Enconvo

Ouvrez **Réglages → Général** et trouvez **Apparence**.

| Réglage | Ce qu’il change |
| --- | --- |
| **Contraste** | Renforce ou adoucit les bordures, les séparateurs et le texte secondaire dans tout Enconvo. |
| **Largeur du chat** | Jusqu’où les messages et le champ de saisie s’élargissent dans une grande fenêtre : **Confortable**, **Large** ou **Pleine largeur**. |
| **Retour à la ligne du code** | Renvoie à la ligne les longues lignes des blocs de code au lieu de défiler horizontalement. |

## Trouver un réglage

Saisissez du texte dans le champ de recherche en haut de la barre latérale des réglages. Les réglages correspondants s’affichent au fur et à mesure ; cliquez sur l’un d’eux pour y accéder.

Pour poser une question sur vos réglages :

1. Saisissez la question dans le champ de recherche, puis appuyez sur Retour, ou cliquez sur **Demander à l’IA**.
2. La réponse s’ouvre à côté de la barre latérale, avec des cartes pour les réglages mentionnés.
3. Cliquez sur **Afficher dans les réglages** d’une carte pour y aller, ou activez ou désactivez un interrupteur directement dans la carte.
4. Saisissez une suite dans **Poser une autre question…**, ou cliquez sur **Continuer dans le chat** pour poursuivre dans la Fenêtre de chat.

Demander à l’IA utilise votre modèle d’IA par défaut. Si aucun n’est configuré, il propose **Ouvrir les réglages du modèle d’IA**.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une partie du texte reste en anglais après le changement de langue | Mettez Enconvo à jour, puis signalez ce qui reste avec **Donner son avis** dans le menu de la barre de menus. |
| Les agents répondent dans une langue différente de l’interface | Définissez **Langue des réponses** dans **Réglages → Général → Langue**. |
| Demander à l’IA ne répond pas | Configurez un modèle dans **Réglages → Modèle d’IA**. |
| Le texte est difficile à lire | Augmentez **Contraste** dans **Réglages → Général → Apparence**. |

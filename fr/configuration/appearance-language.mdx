title: "Langue, apparence et recherche dans les réglages"
description: "Choisissez la langue de l’interface d’Enconvo, ajustez le contraste et la largeur du chat, et trouvez n’importe quel réglage en le cherchant ou en demandant à l’IA."
---

**Réglages → Général** contient les choix qui changent l’apparence d’Enconvo et la langue dans laquelle il parle. Utilisez cette page pour changer la langue de l’interface, rendre Enconvo plus lisible et trouver un réglage sans savoir où il se trouve.

## Changer la langue de l’interface

1. Ouvrez **Réglages → Général** et trouvez **Langue**.
2. Choisissez une langue dans **Langue de l’app**. **Langue du système** utilise la langue de votre Mac.
3. Enconvo propose de changer votre **Langue des réponses** pour qu’elle corresponde. Acceptez si vous voulez que les Agents répondent aussi dans la nouvelle langue.

**Langue de l’app** change les menus, les boutons et les réglages sur cet appareil : anglais, chinois simplifié, chinois traditionnel, japonais, coréen, espagnol, allemand, français, italien, portugais, ukrainien et russe. Les apps iPhone et Android proposent les mêmes langues dans leurs propres réglages.

**Langue des réponses** est distincte : les Agents, les appels vocaux et l’Avatar répondent dans cette langue, et le Traducteur traduit vers elle.

## Ajuster l’apparence d’Enconvo

Ouvrez **Réglages → Général** et trouvez **Apparence**.

| Réglage | Ce qu’il change |
| --- | --- |
| **Contraste** | Renforce ou adoucit les bordures, les séparateurs et le texte secondaire dans tout Enconvo. |
| **Largeur du chat** | La largeur que prennent les messages et le champ de saisie dans une grande fenêtre : **Confortable**, **Large** ou **Pleine largeur**. |
| **Retour à la ligne du code** | Replie les longues lignes des blocs de code au lieu de les faire défiler latéralement. |

## Trouver un réglage

Saisissez dans le champ de recherche en haut de la barre latérale des Réglages. Les réglages correspondants s’affichent pendant la saisie ; cliquez sur l’un d’eux pour y accéder.

Pour poser une question sur vos réglages à la place :

1. Saisissez la question dans le champ de recherche, puis appuyez sur Retour, ou cliquez sur **Demander à l’IA**.
2. La réponse s’ouvre à côté de la barre latérale, avec des cartes pour les réglages qu’elle mentionne.
3. Cliquez sur **Afficher dans les réglages** sur une carte pour accéder à ce réglage, ou activez ou désactivez un interrupteur directement dans la carte.
4. Saisissez une autre question dans **Poser une autre question…**, ou cliquez sur **Continuer dans le chat** pour poursuivre dans la Fenêtre de chat.

Demander à l’IA utilise votre modèle d’IA par défaut. Si aucun n’est configuré, il propose **Ouvrir les réglages du modèle d’IA**.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Du texte reste en anglais après le changement de langue | Mettez Enconvo à jour, puis signalez ce qui reste avec **Donner son avis** dans le menu de la barre des menus. |
| Les Agents répondent dans une autre langue que l’interface | Définissez **Langue des réponses** dans **Réglages → Général → Langue**. |
| Demander à l’IA ne répond pas | Configurez un modèle dans **Réglages → Modèle d’IA**. |
| Le texte est difficile à lire | Augmentez **Contraste** dans **Réglages → Général → Apparence**. |

<Note>
Enconvo pour Windows est en bêta et sort sur le canal de mise à jour **Bêta**. Il est conçu pour un usage quotidien, mais des choses peuvent encore changer d’une version à l’autre. Si quelque chose casse, dites-le-nous sur le [site d’avis](https://feedback.enconvo.com).
</Note>

**Bêta actuelle : 2.5.13 Beta 3** (`2.5.13-beta-3`). Pour voir quelle version vous avez, ouvrez **Réglages → Général → Mises à jour**.

## Configuration requise

- **Windows 10 version 2004 (build 19041) ou une version ultérieure, ou Windows 11.**
- **Intel/AMD 64 bits (x64).** Il n’y a pas encore de version pour Windows sur Arm.
- **Microsoft Edge WebView2 Runtime.** Les fenêtres d’Enconvo s’exécutent dessus. Windows 11 l’inclut. Sur Windows 10, voir [Dépannage](#dépannage) si les fenêtres restent vides.

## Télécharger la bêta

La bêta arrive sous forme d’installateur, `Enconvo-<version>-win32-x64-setup.exe`. Le nom du fichier porte le numéro de version de la bêta.

Pour la bêta actuelle, 2.5.13 Beta 3, téléchargez [Enconvo-2.5.13-beta-3-win32-x64-setup.exe](https://file.enconvo.com/win32-x64/beta/Enconvo-2.5.13-beta-3-win32-x64-setup.exe).

Pour obtenir toujours la bêta la plus récente, lancez ceci dans PowerShell. Il lit le flux bêta, télécharge l’installateur dans votre dossier Téléchargements, et vérifie que le fichier est arrivé intact.

```powershell
$feed = "https://file.enconvo.com/win32-x64/beta"
$latest = Invoke-RestMethod "$feed/latest.json"
$file = $latest.files.exe.url
$out = "$env:USERPROFILE\Downloads\$file"
$ProgressPreference = "SilentlyContinue"   # downloads much faster in Windows PowerShell
Invoke-WebRequest "$feed/$file" -OutFile $out
if ((Get-FileHash $out -Algorithm SHA256).Hash -eq $latest.files.exe.sha256) {
  "Downloaded Enconvo $($latest.version) to $out"
} else {
  "The download is damaged. Delete it and run this again."
}
```

## Installer

<Steps>
  <Step title="Lancer l’installateur">
    Ouvrez le `.exe` que vous avez téléchargé. Si Windows affiche **Windows a protégé votre PC**, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**. SmartScreen affiche ceci pour les apps qu’il ne connaît pas encore.
  </Step>
  <Step title="Choisir un dossier">
    Enconvo s’installe uniquement pour votre compte et n’a pas besoin des droits d’administrateur. Le dossier par défaut est `%LOCALAPPDATA%\Programs\Enconvo`. Si vous en choisissez un autre, il doit être vide ou déjà contenir Enconvo.
  </Step>
  <Step title="Ouvrir Enconvo">
    Laissez **Ouvrir Enconvo** coché sur la dernière page, ou ouvrez **Enconvo** depuis le menu Démarrer plus tard. Son icône apparaît dans la zone de notification de la barre des tâches.
  </Step>
  <Step title="Se connecter">
    Connectez-vous avec votre compte Enconvo, puis continuez avec le [Démarrage rapide](/fr/quickstart).
  </Step>
</Steps>

Si Enconvo est en cours d’exécution lorsque vous installez, l’installateur demande de le fermer d’abord.

## Mettre à jour

Une version bêta reste sur le canal Bêta. Pour le changer, ouvrez **Réglages → Général** et définissez **Canal de mise à jour**. Voir [Mises à jour](/fr/configuration/updates).

Enconvo cherche une nouvelle version de lui-même. Lorsqu’une est prête, cliquez sur **Mettre à jour** dans la Fenêtre de chat. Vous pouvez aussi vérifier maintenant dans **Réglages → Général → Mises à jour**.

La mise à jour s’installe sur place : Enconvo se ferme, affiche la progression de l’installateur, et se rouvre sur la nouvelle version.

## Dépannage

| Ce que vous voyez | Que faire |
| --- | --- |
| **Windows a protégé votre PC** lorsque vous ouvrez l’installateur | Cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même** |
| **Enconvo a besoin de Windows 64 bits** | Enconvo ne fonctionne pas sur Windows 32 bits |
| L’installateur n’utilise pas le dossier que vous avez choisi | Choisissez un dossier vide, ou le dossier où Enconvo se trouve déjà |
| Les fenêtres d’Enconvo restent vides ou ne s’ouvrent pas | Installez le [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), puis rouvrez Enconvo |
| Cliquer sur une notification Enconvo ne fait rien | Ouvrez Enconvo normalement, pas avec **Exécuter en tant qu’administrateur** |

## Retirer Enconvo

Ouvrez **Paramètres → Applications → Applications installées** (sur Windows 10, **Paramètres → Applications → Applications et fonctionnalités**), trouvez **Enconvo**, et choisissez **Désinstaller**.

Vos réglages et vos chats restent dans le dossier `.config\enconvo` de votre dossier utilisateur (`%USERPROFILE%\.config\enconvo`). Supprimez ce dossier pour les retirer aussi.

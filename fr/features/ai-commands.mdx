Une Commande IA regroupe un prompt que vous répétez avec son modèle et ses réglages, pour que vous puissiez l’exécuter sur n’importe quel texte en un clic. Utilisez-en une pour une tâche précise, comme reformuler une réponse du support. Pour un travail plus large avec des outils, utilisez un [Agent](/fr/ai/agents) ; pour une suite d’étapes, utilisez un [Flux de travail](/fr/workflows/introduction).

## Créer une commande

1. Ouvrez **Réglages → Commandes IA**, ou lancez **Créer une commande IA** depuis SmartBar, puis cliquez sur **Nouvelle commande IA**.
2. Décrivez avec vos propres mots ce que la commande doit faire, puis cliquez sur **Rédiger**. Enconvo écrit le titre, l’icône et les instructions, et les exécute aussitôt sur un exemple.
3. Collez une partie de votre propre texte dans l’exemple et cliquez sur **Réessayer** pour voir le résultat sur une vraie entrée.
4. Pour modifier le comportement, saisissez le changement dans **Quelque chose à modifier ?**, par exemple « regroupe-les par responsable », puis cliquez sur **Rédiger à nouveau**. Les lignes modifiées sont repérées dans les instructions, et le résultat de l’exemple est recalculé.
5. Sous **Où l’utiliser**, laissez **Ajouter à la PopBar** activé pour obtenir un bouton PopBar chaque fois que vous sélectionnez du texte, ou cliquez sur **Ajouter un raccourci** et appuyez sur les touches de votre choix.
6. Cliquez sur **Enregistrer**.

Exemple d’instruction :

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Exécuter une commande

- **Depuis la PopBar :** sélectionnez du texte dans n’importe quelle app et cliquez sur le bouton de la commande. Quand le résultat est prêt, cliquez sur **Coller** pour remplacer la sélection.
- **Depuis un raccourci clavier :** sélectionnez le texte et appuyez sur le raccourci de la commande. Le résultat s’ouvre dans SmartBar, où vous pouvez le coller.
- **Depuis SmartBar :** recherchez le titre de la commande et exécutez-la sur l’entrée actuelle.
- **Depuis un Agent :** demandez à un Agent dans le chat d’exécuter une commande pour vous. L’Agent poursuit votre chat quand la commande est terminée.

Les chats issus des Commandes IA, qu’il s’agisse de commandes intégrées comme Traduire ou des vôtres, n’apparaissent pas dans la Fenêtre de chat, dans l’**Historique** de la Dynamic Island ni dans la liste des chats de SmartBar.

## Modifier une commande

Ouvrez la commande dans **Réglages → Commandes IA** pour modifier son titre et ses instructions. Les modifications s’enregistrent au fil de la frappe.

| Réglage | Ce qu’il modifie |
| --- | --- |
| **PopBar** | Place la commande dans la PopBar, ou l’en retire. |
| **Raccourci clavier** | Touches qui exécutent la commande sur le texte sélectionné dans n’importe quelle app. |
| **Mode en ligne** | S’exécute sans fenêtre et colle le résultat à la place de votre sélection. |
| **Action après la réponse** | Ce que la commande fait de la réponse une fois terminée, là où c’est proposé. |
| **Modèle d’IA** | Indique si la commande suit le modèle de toutes les Commandes IA ou en utilise un choisi pour elle. Cliquez sur **Modifier** pour choisir. |

### Choisir le modèle de toutes les commandes

Les Commandes IA s’exécutent avec Enconvo Fast, sauf si vous choisissez un autre modèle. Pour le changer, ouvrez **Réglages → Commandes IA** et cliquez sur **Toutes les commandes**. Le modèle sous **Modèle d’IA** exécute aussi les outils d’écriture, la PopBar, ainsi que **Peaufiner** et **Traduire** de la Dictée. **Utiliser le recommandé** rétablit Enconvo Fast. Les commandes qui choisissent leur propre modèle le conservent quand celui-ci change ; cliquez sur **Voir** pour les afficher, ou sur **Utiliser … pour toutes** pour les basculer sur ce modèle.

Une commande intégrée affiche **Personnaliser** à la place : cela crée votre propre copie, que vous pouvez modifier. Vos propres commandes ont un menu **⋯** avec **Dupliquer** et **Supprimer**. Supprimer une commande la retire aussi de la PopBar et libère son raccourci clavier.

## Utiliser un contexte changeant

Là où un champ prend en charge les variables, utilisez le sélecteur de variables pour inclure le texte d’entrée, le texte sélectionné, l’app active ou un autre contexte. Consultez [Variables](/fr/workflows/variables). Vérifiez le contexte développé avant d’utiliser une commande sur des documents privés.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une commande est introuvable | Vérifiez qu’elle a bien été enregistrée, puis recherchez son titre. |
| Le résultat ignore le texte sélectionné | Vérifiez les réglages d’entrée et de contexte de la commande, ainsi que l’Accessibilité dans [Autorisations](/fr/configuration/permissions). |

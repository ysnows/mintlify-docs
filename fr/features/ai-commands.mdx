Une commande IA regroupe une consigne que vous répétez, avec son modèle et ses réglages, pour la lancer sur n’importe quel texte en un clic. Utilisez-en une pour une tâche précise, comme réécrire une réponse d’assistance. Pour un travail plus large avec des outils, utilisez un [Agent](/fr/ai/agents) ; pour une suite d’étapes, utilisez un [flux de travail](/fr/workflows/introduction).

## Créer une commande

1. Ouvrez **Réglages → Commandes IA**, ou lancez **Créer une commande IA** depuis SmartBar, puis cliquez sur **Nouvelle commande IA**.
2. Décrivez ce que la commande doit faire avec vos mots, puis cliquez sur **Rédiger**. Enconvo rédige le titre, l’icône et les instructions, et les exécute tout de suite sur un exemple.
3. Collez une partie de votre propre texte dans l’exemple et cliquez sur **Réessayer** pour voir le résultat sur une vraie entrée.
4. Pour changer le comportement, saisissez la modification dans **Quelque chose à modifier ?**, par exemple « regroupe-les par responsable », et cliquez sur **Rédiger à nouveau**. Les lignes modifiées sont marquées dans les instructions, et le résultat d’exemple s’exécute à nouveau.
5. Sous **Où l’utiliser**, laissez **Ajouter à la PopBar** activé pour obtenir un bouton PopBar dès que vous sélectionnez du texte, ou cliquez sur **Ajouter un raccourci** et appuyez sur les touches voulues.
6. Cliquez sur **Enregistrer**.

Exemple d’instruction :

```text
Rewrite the input as a short, friendly support reply.
Preserve names, dates, product names, and technical details.
Return only the rewritten reply.
```

## Lancer une commande

- **Depuis PopBar :** sélectionnez du texte dans n’importe quelle app et cliquez sur le bouton de la commande. Lorsque le résultat est prêt, cliquez sur **Coller** pour remplacer la sélection.
- **Depuis un raccourci :** sélectionnez le texte et appuyez sur le raccourci de la commande. Le résultat s’ouvre dans SmartBar, où vous pouvez le coller.
- **Depuis SmartBar :** cherchez le titre de la commande et lancez-la sur l’entrée en cours.
- **Depuis un agent :** demandez à un agent dans le chat de lancer une commande pour vous. L’agent reprend votre chat une fois la commande terminée.

Les chats issus des commandes IA, intégrées comme Traduire ou les vôtres, n’apparaissent pas dans la Fenêtre de chat, l’**Historique** de Dynamic Island, ni la liste de chats de SmartBar.

## Modifier une commande

Ouvrez la commande dans **Réglages → Commandes IA** pour modifier son titre et ses instructions. Les modifications s’enregistrent au fur et à mesure de la saisie.

| Réglage | Ce qu’il change |
| --- | --- |
| **PopBar** | Place la commande sur PopBar, ou l’en retire. |
| **Raccourci clavier** | Touches qui lancent la commande sur le texte sélectionné dans n’importe quelle app. |
| **Mode en ligne** | S’exécute sans fenêtre et colle le résultat par-dessus votre sélection. |
| **Action après la réponse** | Ce que la commande fait de la réponse une fois terminée, là où c’est proposé. |
| **Modèle d’IA** | Indique si la commande suit le modèle de toutes les commandes IA ou en utilise un choisi pour elle. Cliquez sur **Modifier** pour choisir. |

### Choisir le modèle de toutes les commandes

Les commandes IA s’exécutent sur Enconvo Fast, sauf si vous choisissez un autre modèle. Pour le changer, ouvrez **Réglages → Commandes IA** et cliquez sur **Toutes les commandes**. Le modèle sous **Modèle d’IA** exécute aussi les outils d’écriture, PopBar, ainsi que **Peaufiner** et **Traduire** de la Dictée. **Utiliser le recommandé** revient à Enconvo Fast. Les commandes qui choisissent leur propre modèle le gardent lorsque celui-ci change ; cliquez sur **Voir** pour les consulter, ou sur **Utiliser … pour toutes** pour les passer sur ce modèle.

Une commande intégrée affiche **Personnaliser** à la place : cela crée votre propre copie, que vous pouvez modifier. Vos propres commandes ont un menu **⋯** avec **Dupliquer** et **Supprimer**. Supprimer une commande la retire aussi de PopBar et libère son raccourci.

## Utiliser un contexte changeant

Lorsqu’un champ prend en charge les variables, utilisez le sélecteur de variables pour inclure le texte saisi, le texte sélectionné, l’app active ou un autre contexte. Voir [Variables](/fr/workflows/variables). Vérifiez le contexte développé avant d’utiliser une commande sur des documents privés.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une commande manque | Vérifiez qu’elle a été enregistrée, puis cherchez son titre. |
| Le résultat ignore le texte sélectionné | Vérifiez l’entrée et les réglages de contexte de la commande, et Accessibilité dans [Autorisations](/fr/configuration/permissions). |

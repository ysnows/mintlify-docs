title: "Liens rapides"
description: "Ouvrez une recherche web, un site, un fichier, un dossier ou un Deeplink depuis SmartBar avec une seule commande."

Les liens rapides transforment une recherche web, une adresse web, un fichier ou un dossier, ou le Deeplink d’une app en une commande que vous lancez depuis SmartBar. Les espaces réservés remplissent le lien avec ce que vous saisissez, le presse-papiers, le texte sélectionné ou la date. Enconvo arrive avec les recherches Google, YouTube et X prêtes à l’emploi.

Les liens rapides ouvrent une destination. La [Recherche web](/fr/ai/web-search) intègre plutôt les résultats de recherche dans une réponse d’IA, et l’[Utilisation du navigateur](/fr/features/browser-control) laisse un agent travailler dans des pages web.

## Chercher sur le web depuis SmartBar

1. Ouvrez SmartBar et trouvez **Google Search in Browser**, **YouTube Search in Browser** ou **Twitter/X Search in Browser**.
2. Saisissez votre texte de recherche comme entrée de la commande. Le texte sélectionné fonctionne aussi.
3. Lancez la commande. La recherche s’ouvre dans votre navigateur par défaut.

## Créer un lien rapide

1. Lancez **Créer un lien rapide** depuis SmartBar.
2. Saisissez un **Nom**, par exemple Rechercher sur GitHub.
3. Saisissez le **Lien** : une adresse web, un chemin de fichier ou de dossier, ou un Deeplink. Cliquez sur **Insérer un espace réservé** pour en ajouter un, par exemple `https://github.com/search?q={argument}`.
4. Pour l’ouvrir dans une app précise, saisissez un nom d’app comme Safari, un chemin d’app ou un identifiant de bundle dans **Ouvrir avec**. Laissez vide pour utiliser l’app par défaut.
5. Cliquez sur **Enregistrer**. Cherchez le nom du lien rapide dans SmartBar pour le lancer.

Quand vous lancez un lien rapide, le texte saisi ou sélectionné remplit son premier argument. Si un argument requis est encore vide, Enconvo le demande avant d’ouvrir le lien.

| Espace réservé | Rempli avec |
| --- | --- |
| `{argument name="Query"}` | Une valeur que vous saisissez à l’ouverture du lien rapide |
| `{clipboard}` | Le texte du presse-papiers |
| `{selection}` | Le texte sélectionné dans l’app que vous utilisez |
| `{date}`, `{time}`, `{datetime}` | La date actuelle, l’heure, ou les deux |
| `{date format="yyyy-MM-dd"}` | La date dans le format que vous donnez |
| `{uuid}` | Un nouvel identifiant unique |

Testez un nouveau lien d’abord avec du texte ordinaire, espaces et ponctuation compris.

## Gérer vos liens rapides

Lancez **Search Quicklinks** depuis SmartBar pour voir tous les liens rapides. De là, vous pouvez en ouvrir, modifier, dupliquer ou supprimer un, et cliquer sur **Nouveau** pour en ajouter un autre.

Le menu **Plus** contient **Importer des liens rapides…**, qui lit les exports de liens rapides et de réglages Raycast, et **Exporter dans Téléchargements**. Un export de réglages Raycast demande la phrase secrète choisie lors de l’export.

## Réglages

Ouvrez **Réglages → Plugins → Liens rapides**. Chaque commande de recherche a aussi son propre **Lien**, par exemple `https://www.google.com/search?q={query}`, que vous pouvez modifier.

| Réglage | Ce qu’il change |
| --- | --- |
| **Ouvrir dans une nouvelle fenêtre** | Ouvre les liens rapides web dans une nouvelle fenêtre de navigateur. Fonctionne avec Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox et Zen ; Safari, Arc et Orion ouvrent le lien comme d’habitude. Désactivé par défaut |
| **Quand aucun texte n’est sélectionné** | Ce que fait un lien `{selection}` quand rien n’est sélectionné : **Le demander** (par défaut) ou **Utiliser le presse-papiers** |
| **Confirmer avant de supprimer** | Demande avant de supprimer un lien rapide. Activé par défaut |

## Dépannage

| Problème | Que faire |
| --- | --- |
| La mauvaise page s’ouvre | Vérifiez le **Lien** du lien rapide et ses espaces réservés, puis essayez avec du texte simple |
| Le navigateur ne s’ouvre pas | Vérifiez votre navigateur par défaut, **Ouvrir avec** du lien rapide, et que la commande est installée |
| Un lien `{selection}` demande du texte | Rien n’était sélectionné. Sélectionnez d’abord le texte, ou réglez **Quand aucun texte n’est sélectionné** sur **Utiliser le presse-papiers** |

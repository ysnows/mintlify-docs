Les Liens rapides transforment une recherche web, une adresse web, un fichier ou un dossier, ou le deeplink d’une app en commande que vous lancez depuis la SmartBar. Des espaces réservés complètent le lien avec ce que vous saisissez, le presse-papiers, le texte sélectionné ou la date. Enconvo est livré avec des recherches Google, YouTube et X prêtes à l’emploi.

Les Liens rapides ouvrent une destination. La [Recherche web](/fr/ai/web-search) amène plutôt des résultats de recherche dans une réponse de l’IA, et l’[Utilisation du navigateur](/fr/features/browser-control) permet à un Agent de travailler dans des pages web.

## Rechercher sur le web depuis la SmartBar

1. Ouvrez la SmartBar et trouvez **Google Search in Browser**, **YouTube Search in Browser** ou **Twitter/X Search in Browser**.
2. Saisissez votre texte de recherche comme entrée de la commande. Le texte sélectionné fonctionne aussi.
3. Lancez la commande. La recherche s’ouvre dans votre navigateur par défaut.

## Créer un lien rapide

1. Lancez **Créer un lien rapide** depuis la SmartBar.
2. Saisissez un **Nom**, par exemple Search GitHub.
3. Saisissez le **Lien** : une adresse web, un chemin de fichier ou de dossier, ou un deeplink. Cliquez sur **Insérer un espace réservé** pour en ajouter un, comme `https://github.com/search?q={argument}`.
4. Pour l’ouvrir dans une app particulière, saisissez un nom d’app comme Safari, un chemin d’app ou un identifiant de bundle dans **Ouvrir avec**. Laissez vide pour utiliser l’app par défaut.
5. Cliquez sur **Enregistrer**. Cherchez le nom du lien rapide dans la SmartBar pour le lancer.

Quand vous lancez un lien rapide, le texte saisi ou sélectionné remplit son premier argument. Si un argument obligatoire est encore vide, Enconvo le demande avant d’ouvrir le lien.

| Espace réservé | Remplacé par |
| --- | --- |
| `{argument name="Query"}` | Une valeur que vous saisissez à l’ouverture du lien rapide |
| `{clipboard}` | Le texte du presse-papiers |
| `{selection}` | Le texte sélectionné dans l’app que vous utilisez |
| `{date}`, `{time}`, `{datetime}` | La date, l’heure ou les deux, actuelles |
| `{date format="yyyy-MM-dd"}` | La date dans le format que vous indiquez |
| `{uuid}` | Un nouvel identifiant unique |

Testez d’abord un nouveau lien avec du texte ordinaire, y compris des espaces et de la ponctuation.

## Gérer vos liens rapides

Lancez **Search Quicklinks** depuis la SmartBar pour voir tous vos liens rapides. De là, vous pouvez en ouvrir, modifier, dupliquer ou supprimer un, et cliquer sur **Nouveau** pour en ajouter un autre.

Le menu **Plus** propose **Importer des liens rapides…**, qui lit les exports de liens rapides et de réglages de Raycast, et **Exporter dans Téléchargements**. Un export de réglages Raycast demande la phrase secrète que vous avez choisie lors de l’export.

## Réglages

Ouvrez **Réglages → Plugins → Liens rapides**. Chaque commande de recherche a aussi son propre **Lien**, comme `https://www.google.com/search?q={query}`, que vous pouvez modifier.

| Réglage | Ce qu’il modifie |
| --- | --- |
| **Ouvrir dans une nouvelle fenêtre** | Ouvre les liens rapides web dans une nouvelle fenêtre de navigateur. Fonctionne avec Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox et Zen ; Safari, Arc et Orion ouvrent le lien comme d’habitude. Désactivé par défaut |
| **Quand aucun texte n’est sélectionné** | Ce que fait un lien `{selection}` quand rien n’est sélectionné : **Le demander** (par défaut) ou **Utiliser le presse-papiers** |
| **Confirmer avant de supprimer** | Demande confirmation avant de supprimer un lien rapide. Activé par défaut |

## Dépannage

| Problème | Que faire |
| --- | --- |
| La mauvaise page s’ouvre | Vérifiez le **Lien** du lien rapide et ses espaces réservés, puis essayez avec du texte simple |
| Le navigateur ne s’ouvre pas | Vérifiez votre navigateur par défaut, le réglage **Ouvrir avec** du lien rapide et que la commande est installée |
| Un lien `{selection}` demande du texte | Rien n’était sélectionné. Sélectionnez d’abord le texte, ou réglez **Quand aucun texte n’est sélectionné** sur **Utiliser le presse-papiers** |

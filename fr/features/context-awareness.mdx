Le contexte est ce qui accompagne votre question : le texte que vous avez sélectionné, les fichiers sélectionnés dans le Finder, la page ouverte dans votre navigateur, ou une capture d’écran. SmartBar peut en récupérer une partie à l’ouverture, et vous pouvez en ajouter en tapant `#`. L’Agent répond alors à propos de ce que vous regardez, sans que vous ayez à l’expliquer.

## Choisir ce que SmartBar récupère

1. Ouvrez **Réglages → Compréhension du contexte**.
2. Sous **À l'ouverture de la Smart Bar**, réglez chaque source sur **Joindre**, **Suggérer** ou **Désactivé**.
3. Passez à une autre app, sélectionnez quelque chose et ouvrez SmartBar pour voir le résultat.

| Source | Ce qu’elle ajoute | Défaut |
| --- | --- | --- |
| **Texte sélectionné** | Texte sélectionné dans l’app que vous utilisiez | **Joindre** |
| **Sélection du Finder** | Fichiers et dossiers sélectionnés dans le Finder | **Suggérer** |
| **Page actuelle du navigateur** | La page ouverte dans Safari, Chrome, Arc, Edge ou un autre navigateur Chromium | **Suggérer** |

**Joindre** ajoute la source à la saisie dès que SmartBar s’ouvre. **Suggérer** la liste au-dessus des commandes, pour l’ajouter en un clic. **Désactivé** la laisse de côté.

Seul SmartBar utilise ces réglages. Les commandes que vous lancez sur une sélection reçoivent toujours le texte sélectionné. La première fois que vous ajoutez le contexte du Finder ou du navigateur, macOS demande si Enconvo peut contrôler cette app.

## Ajouter du contexte avec #

1. Dans SmartBar, tapez `#`.
2. Tapez un mot pour réduire la liste, par exemple `#screen`, `#finder`, `#clipboard` ou `#browser`.
3. Choisissez une source. Elle est ajoutée à votre message.
4. Tapez votre question et envoyez-la.

| Source | Ce qu’elle ajoute |
| --- | --- |
| **Selected Text** | Le texte sélectionné dans la fenêtre actuelle |
| **Clipboard Text** | Le texte du presse-papiers |
| **Current Application Content** | Le texte de l’app au premier plan |
| **Current Application Screenshot** | Une capture de l’app au premier plan |
| **Current Screen Screenshot** | Une capture de tout l’écran |
| **Live Screen Screenshot** | Une capture de l’écran sans les fenêtres d’Enconvo |
| **User Select Area Screenshot** | Une capture d’une zone que vous sélectionnez |
| **Finder Selected Items** | Les fichiers et dossiers sélectionnés dans le Finder |
| **Finder Current Directory URL** | Le dossier ouvert dans le Finder |
| **Browser Current Tab URL** | L’adresse de l’onglet actuel du navigateur |

Vos fenêtres ouvertes sont aussi listées, pour ajouter une fenêtre d’une autre app. Pour utiliser un autre caractère que `#`, changez **Contexte** sous **Rechercher** dans **Réglages → SmartBar**.

## Que demander

Avec la page du navigateur jointe, demandez à Enconvo de résumer la page, de la traduire ou d’en extraire l’essentiel. Avec des fichiers du Finder joints, demandez-lui de décrire les fichiers, de suggérer comment les organiser, d’aider à un renommage par lot ou d’analyser leur contenu.

<Note>
Le contexte que vous joignez va au modèle qui répond, ou au fournisseur qui le traite. Relisez ce qui est joint et vos réglages de fournisseur avant de travailler sur un contenu sensible.
</Note>

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le texte sélectionné n’est pas joint | Vérifiez que **Texte sélectionné** est réglé sur **Joindre**, et vérifiez les [Autorisations](/fr/configuration/permissions). |
| Le contexte du Finder ou du navigateur manque | Autorisez Enconvo à contrôler cette app lorsque macOS le demande. Si vous avez refusé, autorisez-le dans les [Autorisations](/fr/configuration/permissions). |
| Taper `#` n’ouvre pas la liste | Vérifiez le caractère **Contexte** dans **Réglages → SmartBar**. |

Un tableau de bord est une page de chiffres et de graphiques qu’un Agent construit à partir de vos données, pour des indicateurs que vous suivez, examinez ou dont vous rendez compte. Chaque chiffre est lié à la ligne dont il provient, ce qui vous permet de le vérifier. Utilisez-le quand vous reviendrez sur les chiffres ; pour une réponse ponctuelle, demandez simplement dans le chat.

## Créer un tableau de bord

1. Lancez une nouvelle discussion et choisissez **Tableau de bord** sous la zone de message, ou demandez-en un dans n’importe quelle discussion.
2. Joignez les données : un fichier CSV, TSV ou JSON, ou cliquez sur **Ouvrir un tableur** dans la rangée **Créer quelque chose**. Vous pouvez aussi indiquer à l’Agent un service connecté, un fichier de votre Mac ou une adresse web.
3. Dites quoi suivre et comment le décomposer.

Exemple :

```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

Le tableau de bord s’ouvre à côté du chat. Quand l’Agent ajoute des filtres, chacun s’affiche en haut sous forme de menu, d’interrupteur ou de champ.

## Vérifier un chiffre

1. Cliquez sur **Vérifier un chiffre** dans l’en-tête du tableau de bord.
2. Cliquez sur n’importe quel chiffre.
3. Enconvo affiche la ligne qui le sous-tend, son origine, et si les deux concordent.

Pour poser une question sur un chiffre, commentez-le. Commencez le commentaire par `@Enconvo` pour obtenir une réponse de l’Agent.

## Voir d’où viennent les données

Cliquez sur **Sources**. Chaque ensemble de données indique d’où il vient, combien de lignes il contient et quand il a changé pour la dernière fois. Les données dont la mise à jour est en retard affichent **Obsolète**. Cliquez sur **Télécharger le CSV** pour enregistrer un ensemble de données.

## Garder les chiffres à jour

Un tableau de bord construit à partir d’un service connecté, d’un fichier de votre Mac ou d’une adresse web peut se mettre à jour tout seul, une fois que vous l’avez autorisé.

1. Quand le tableau de bord demande **Garder ces chiffres à jour ?**, vérifiez ce que lit chaque source, puis cliquez sur **Autoriser**. Vous pouvez aussi cliquer sur **Autoriser les mises à jour** à côté d’une source dans **Sources**.
2. Les chiffres se mettent à jour selon le calendrier défini par l’Agent, par exemple **Toutes les heures**, ou **Quand vous actualisez**. Cliquez sur **Actualiser** pour les mettre à jour maintenant.
3. Pour arrêter, cliquez sur **Arrêter les mises à jour** à côté de la source.

Quand une mise à jour échoue, le tableau de bord conserve les derniers chiffres et en indique la raison.

<Note>
Une source qui n’indique pas qu’elle ne fait que lire des données ne s’exécute que lorsque vous cliquez sur **Actualiser**. Sur un tableau de bord partagé, tous ceux qui y ont accès voient ce que lit la source.
</Note>

## Télécharger ou déplacer un tableau de bord

Cliquez sur **Télécharger** et choisissez :

| Option | Ce que vous obtenez |
| --- | --- |
| **Télécharger le PDF** | Un PDF de la page |
| **Télécharger l’image** | Une image de la page |
| **Télécharger le HTML** | Un fichier HTML unique qui s’ouvre dans n’importe quel navigateur |
| **Télécharger le projet (.zip)** | Le projet entier, à importer sur un autre ordinateur |

Pour importer un projet, cliquez sur **Importer** dans la bibliothèque **Artefacts** et choisissez le zip. Les commentaires sont inclus ; les mises à jour depuis un service connecté doivent y être autorisées à nouveau.

Pour partager le tableau de bord avec des personnes ou votre équipe, cliquez sur **Partager**. Voir [Artefacts](/fr/features/artifacts). Le tableau de bord s’ouvre aussi dans les apps iPhone et Android ; voir [Artefacts](/fr/features/artifacts).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un chiffre et sa ligne ne concordent pas | Interrogez l’Agent à ce sujet dans un commentaire, ou demandez-lui de corriger le calcul |
| Une source affiche **Obsolète** | Cliquez sur **Actualiser**, ou autorisez les mises à jour pour cette source |
| **Impossible de mettre à jour les chiffres** | Lisez la raison, corrigez l’accès de la source, puis cliquez sur **Actualiser** |
| Le tableau de bord est vide | Décrivez le tableau de bord et ses données dans une discussion |

---

Un tableau de bord est une page de chiffres et de graphiques qu’un Agent construit à partir de vos données, pour des chiffres que vous suivez, relisez ou rapportez. Chaque chiffre est lié à la ligne d’où il vient, pour que vous puissiez le vérifier. Utilisez-le quand vous reviendrez aux chiffres ; pour une réponse ponctuelle, demandez simplement dans la discussion.

## Faire un tableau de bord

1. Démarrez une nouvelle discussion et choisissez **Tableau de bord** sous la zone de message, ou demandez-en un dans n’importe quelle discussion.
2. Joignez les données : un fichier CSV, TSV ou JSON, ou cliquez sur **Ouvrir un tableur** dans la rangée **Créer quelque chose**. Vous pouvez aussi indiquer à l’Agent un service connecté, un fichier sur votre Mac, ou une adresse web.
3. Dites quoi suivre et comment le découper.

Exemple :


```text
Weekly sales by region from the spreadsheet I attach.
Show the total, the change from last week, and the top five products.
```

Le tableau de bord s’ouvre à côté de la discussion. Quand l’Agent ajoute des filtres, chacun apparaît comme un menu, un interrupteur ou une case en haut.

## Vérifier un chiffre

1. Cliquez sur **Vérifier un chiffre** dans l’en-tête du tableau de bord.
2. Cliquez sur n’importe quel chiffre.
3. Enconvo affiche la ligne derrière, d’où elle vient, et si les deux correspondent.

Pour poser une question sur un chiffre, commentez-le. Commencez le commentaire par `@Enconvo` pour obtenir une réponse de l’Agent.

## Voir d’où viennent les données

Cliquez sur **Sources**. Chaque ensemble de données montre d’où il vient, combien de lignes il a, et quand il a changé pour la dernière fois. Les données en retard affichent **Obsolète**. Cliquez sur **Télécharger le CSV** pour enregistrer un ensemble de données.

## Garder les chiffres à jour

Un tableau de bord construit à partir d’un service connecté, d’un fichier sur votre Mac ou d’une adresse web peut se mettre à jour tout seul, une fois que vous l’autorisez.

1. Quand le tableau de bord demande **Garder ces chiffres à jour ?**, vérifiez ce que chaque source lit, puis cliquez sur **Autoriser**. Vous pouvez aussi cliquer sur **Autoriser les mises à jour** à côté d’une source dans **Sources**.
2. Les chiffres se mettent à jour selon l’horaire fixé par l’Agent, comme **Toutes les heures**, ou **Quand vous actualisez**. Cliquez sur **Actualiser** pour les mettre à jour maintenant.
3. Pour arrêter, cliquez sur **Arrêter les mises à jour** à côté de la source.

Quand une mise à jour échoue, le tableau de bord garde les derniers chiffres et dit pourquoi.

<Note>
Une source qui ne dit pas qu’elle ne fait que lire les données ne tourne que quand vous cliquez sur **Actualiser**. Sur un tableau de bord partagé, tout le monde y voit ce que la source lit.
</Note>

## Télécharger ou déplacer un tableau de bord

Cliquez sur **Télécharger** et choisissez :

| Option | Ce que vous obtenez |
| --- | --- |
| **Télécharger le PDF** | Un PDF de la page |
| **Télécharger l’image** | Une image de la page |
| **Télécharger le HTML** | Un fichier HTML qui s’ouvre dans n’importe quel navigateur |
| **Télécharger le projet (.zip)** | Le projet entier, à importer sur un autre ordinateur |

Pour importer un projet, cliquez sur **Importer** dans la bibliothèque **Artefacts** et choisissez le zip. Les commentaires viennent avec ; les mises à jour d’un service connecté doivent être autorisées de nouveau là-bas.

Pour partager le tableau de bord avec des personnes ou votre équipe, cliquez sur **Partager**. Voir [Artefacts](/fr/features/artifacts). Le tableau de bord s’ouvre aussi dans les apps iPhone et Android ; voir [Artefacts](/fr/features/artifacts).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Un chiffre et sa ligne ne correspondent pas | Demandez à l’Agent dans un commentaire, ou demandez-lui de corriger le calcul |
| Une source affiche **Obsolète** | Cliquez sur **Actualiser**, ou autorisez les mises à jour pour elle |
| **Impossible de mettre à jour les chiffres** | Lisez la raison, corrigez l’accès de la source, puis cliquez sur **Actualiser** |
| Le tableau de bord est vide | Décrivez le tableau de bord et ses données dans une discussion |

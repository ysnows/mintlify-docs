Note vocale enregistre une idée dite à voix haute dans une base de connaissances pour que vous puissiez la retrouver plus tard. Utilisez la [Dictée](/fr/features/dictation) quand vous voulez plutôt du texte saisi dans une autre app.

## Avant de commencer

Créez ou choisissez une [Base de connaissances](/fr/ai/knowledge-base) pour vos notes. Note vocale n’a aucun raccourci tant que vous n’en définissez pas un.

## Configurer le raccourci

1. Ouvrez **Réglages → Note vocale**.
2. Cliquez sur **Raccourci des notes vocales** et appuyez sur le raccourci souhaité. Choisissez si vous le maintenez ou si vous appuyez dessus.
3. Réglez **Enregistrer dans** sur la base de connaissances où vont vos notes. Au départ, c’est la **Base de connaissances par défaut**.

## Enregistrer une note

1. Appuyez sur votre **Raccourci des notes vocales** et dites une courte note. En mode maintien, maintenez le raccourci pendant que vous parlez.
2. Relâchez le raccourci, ou utilisez les commandes d’enregistrement, pour terminer l’enregistrement. La note est enregistrée.
3. Ouvrez la base de connaissances de destination et relisez l’élément enregistré et sa transcription.

## Faciliter la recherche de vos notes

Dites le sujet et les noms utiles dans l’enregistrement, par exemple : « Projet Atlas : demander au designer les icônes d’onboarding mises à jour. » Vérifiez les noms, les chiffres et les dates importants dans la transcription avant de vous y fier.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le raccourci ne fait rien | Définissez un **Raccourci des notes vocales**, et assurez-vous que **Activer la capture rapide** est activé dans **Réglages → Capture rapide**. Ce commutateur active à la fois les raccourcis de Capture rapide et de Note vocale. |
| Pas d’audio | Vérifiez l’autorisation Micro et le périphérique d’entrée sélectionné. |
| La note n’est pas là où vous l’attendiez | Vérifiez **Enregistrer dans** dans **Réglages → Note vocale**. |
| La transcription échoue | Lisez l’erreur et vérifiez le fournisseur vocal configuré avant d’enregistrer de nouveau la même note. |

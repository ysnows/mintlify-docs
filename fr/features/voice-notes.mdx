Note vocale enregistre une idée parlée dans une base de connaissances pour que vous puissiez la retrouver plus tard. Utilisez la [Dictée](/fr/features/dictation) lorsque vous voulez que le texte soit saisi dans une autre app.

## Avant de commencer

Créez ou choisissez une [Base de connaissances](/fr/ai/knowledge-base) pour vos notes. Note vocale n’a pas de raccourci tant que vous n’en définissez pas un.

## Configurer le raccourci

1. Ouvrez **Réglages → Note vocale**.
2. Cliquez sur **Raccourci des notes vocales** et appuyez sur le raccourci voulu. Choisissez si vous le maintenez ou si vous appuyez dessus.
3. Définissez **Enregistrer dans** sur la base de connaissances où vont vos notes. Au départ, c’est **Base de connaissances par défaut**.

## Enregistrer une note

1. Appuyez sur votre **Raccourci des notes vocales** et dites une courte note. En mode maintien, gardez le raccourci enfoncé pendant que vous parlez.
2. Relâchez le raccourci, ou utilisez les commandes d’enregistrement, pour terminer. La note est enregistrée.
3. Ouvrez la base de connaissances de destination et relisez l’élément enregistré et sa transcription.

## Rendre les notes plus faciles à retrouver

Dites le sujet et les noms utiles dans l’enregistrement, par exemple : « Projet Atlas : demander à la designer les icônes d’intégration mises à jour. » Vérifiez les noms, les nombres et les dates importants dans la transcription avant de vous y fier.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le raccourci ne fait rien | Définissez un **Raccourci des notes vocales**, et vérifiez que **Activer la capture rapide** est activé dans **Réglages → Capture rapide**. Cet interrupteur active les raccourcis de Capture rapide et de Note vocale. |
| Pas d’audio | Vérifiez l’autorisation Microphone et le périphérique d’entrée sélectionné. |
| La note n’est pas là où vous l’attendiez | Vérifiez **Enregistrer dans** dans **Réglages → Note vocale**. |
| La transcription échoue | Lisez l’erreur et vérifiez le fournisseur de parole configuré avant de réenregistrer la même note. |

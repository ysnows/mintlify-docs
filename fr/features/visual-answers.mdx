---
title: "Réponses visuelles"
description: "Obtenez un schéma, un graphique ou un widget interactif directement dans le chat plutôt qu’un simple texte."
---

Demandez à un Agent de montrer sa réponse, et il dessine le visuel directement dans la conversation : un schéma SVG, un aperçu HTML ou un widget interactif sur lequel vous pouvez cliquer et que vous pouvez ajuster. Utilisez-le quand une image, un graphique ou une petite calculatrice explique mieux que des paragraphes. L’Agent a besoin de ses outils visuels pour cela.

Une réponse visuelle vit dans la conversation. Quand vous voulez quelque chose à conserver, modifier, présenter ou partager, comme une présentation, un tableau de bord, un design ou un document, demandez plutôt un [artefact](/fr/features/artifacts).

## Demander un visuel

Indiquez à quelle question le visuel doit répondre :

```text
Show how this request moves from the browser to the API and database.
Use a small diagram and explain the failure points.
```

```text
Create an interactive comparison of these three plans.
Let me change the monthly usage and see the estimated total.
```

Pour un graphique ou une calculatrice, fournissez les données et leurs unités. Un visuel soigné peut quand même contenir des faits ou des calculs erronés ; vérifiez-les.

## Liens, cartes et graphiques dans les réponses

Certaines réponses deviennent visuelles sans que vous le demandiez :

- Les **liens** s’affichent sous forme de cartes avec l’icône du site.
- Les **lieux** s’affichent sur une vraie carte avec le nom du lieu. Plusieurs lieux partagent une même carte numérotée, et un itinéraire affiche son tracé avec sa durée et sa distance.
- Les **graphiques** créés par l’Agent voient leurs couleurs vérifiées, de sorte que chaque série reste distincte pour les personnes daltoniennes et dans les apparences claire et sombre. Les nombres, les dates et les mots d’état s’affichent dans votre langue.

## Utiliser et enregistrer un visuel

1. Attendez que le visuel ait fini de se dessiner, puis utilisez ses éventuelles commandes. Certains widgets renvoient un prompt de suivi dans le chat.
2. Pointez le visuel terminé et cliquez sur **⋯** en haut à droite.
3. Choisissez **Copier dans le presse-papiers**, ou **Télécharger le fichier** et confirmez le nom du fichier. Les visuels dessinés avec les cartes, tableaux et graphiques de l’app proposent à la place **Télécharger l’image**, qui enregistre un PNG dans votre dossier Téléchargements.

Une image enregistrée capture un instant du visuel ; elle ne conserve pas ses commandes interactives. Après avoir modifié les valeurs d’un widget, **Réinitialiser les valeurs** dans le même menu les rétablit.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Vous obtenez du code au lieu d’un visuel | Vérifiez les outils activés de l’Agent, puis demandez-lui d’afficher le résultat dans la conversation |
| Un widget semble incomplet | Attendez qu’il ait fini, puis demandez une version plus simple |
| Vous avez besoin d’un fichier image, pas d’un widget de chat | Utilisez la [Génération d’images](/fr/ai/image-generation) |
| Vous voulez conserver le graphique et y revenir | Demandez un [Tableau de bord](/fr/features/dashboards) |

Le dessin à l’écran vous permet d’annoter une partie de l’écran avant d’interroger votre Agent. Dessinez des flèches, des cercles, des surlignages ou des notes, puis envoyez. La capture annotée est jointe à votre chat comme image, dans Dynamic Island, sauf si vous veniez d’utiliser un autre chat Enconvo comme la Fenêtre de chat.

## Annoter votre écran

1. Mettez au premier plan le contenu sur lequel vous voulez poser une question.
2. Faites un double-clic droit pour ouvrir le dessin à l’écran, ou appuyez sur le **Raccourci clavier** défini dans **Réglages → Dessin à l’écran**.
3. Si **Capturez d’abord une zone** est activé, faites glisser pour sélectionner la zone. Sinon, dessinez directement sur l’écran en direct.
4. Choisissez un outil dans la barre d’outils et marquez la zone voulue.
5. Cliquez sur **Envoyer** (l’avion en papier) ou appuyez sur **⌘↩**.
6. Relisez l’image jointe et saisissez une demande, par exemple « Que signifie l’avertissement surligné ? »

Le dessin à l’écran n’a pas de raccourci tant que vous n’en définissez pas un. Le double-clic droit fonctionne tout de suite.

### Ajouter une étiquette parlée

Maintenez la touche **Option** gauche et parlez pour décrire la forme que vous venez de dessiner. Vos mots apparaissent à côté, en texte. Pour que le dessin à l’écran écoute après chaque forme, activez **Parler après chaque forme** dans la barre d’outils, et faites une pause pour terminer chaque étiquette.

## Outils

| Outil ou action | Touche |
| --- | --- |
| Flèche | **A** |
| Ligne | **L** |
| Plume | **P** |
| Surligneur | **H** |
| Rectangle | **R** |
| Cercle | **O** |
| Compteur (marqueurs numérotés) | **N** |
| Texte | **T** |
| Sélectionner | **V** |
| Gomme | **E** |
| Couleur | **C** |
| Épaisseur du trait | **⌘** + défilement |
| Tableau blanc | **B** |
| Mise en évidence du curseur | **K** |
| Enregistrer sous… | **⌘S** |
| Envoyer | **⌘↩** |

La barre d’outils a aussi **Annuler**, **Rétablir**, **Effacer**, **Copier dans le presse-papiers** et **Fermer**.

## Réglages

Ouvrez **Réglages → Dessin à l’écran**.

| Réglage | Ce qu’il fait |
| --- | --- |
| **Capturez d’abord une zone** | Sélectionnez une zone avant de dessiner. Désactivez-le pour dessiner directement sur l’écran en direct. Activé par défaut. |
| **Raccourci clavier** | Ouvre ou ferme le dessin à l’écran. Vide par défaut. |
| **Double-clic droit** | Ouvre ou ferme le dessin à l’écran par un double-clic droit rapide. Activé par défaut. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| La superposition ne s’ouvre pas | Vérifiez le **Raccourci clavier** et le **Double-clic droit** dans **Réglages → Dessin à l’écran**, et vérifiez les [autorisations macOS](/fr/configuration/permissions). |
| Vous n’avez besoin que de toute la fenêtre de l’app | Utilisez plutôt [Appshots](/fr/features/appshots). |

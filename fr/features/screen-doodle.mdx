Dessin à l’écran vous permet d’annoter une partie de l’écran avant d’interroger votre Agent. Tracez des flèches, des cercles, des surlignages ou des notes, puis envoyez. La capture d’écran annotée est jointe à votre discussion sous forme d’image, dans la Dynamic Island, sauf si vous veniez d’utiliser une autre discussion Enconvo comme la Fenêtre de chat.

## Annoter votre écran

1. Amenez au premier plan le contenu sur lequel vous voulez poser une question.
2. Faites un double clic droit pour ouvrir Dessin à l’écran, ou appuyez sur le **Raccourci clavier** que vous avez défini dans **Réglages → Dessin à l’écran**.
3. Si **Capturez d’abord une zone** est activé, faites glisser pour sélectionner la zone. Sinon, dessinez directement sur l’écran en direct.
4. Choisissez un outil dans la barre d’outils et marquez la zone que vous voulez désigner.
5. Cliquez sur **Envoyer** (l’avion en papier) ou appuyez sur **⌘↩**.
6. Vérifiez l’image jointe et saisissez une demande, par exemple « Que signifie l’avertissement surligné ? »

Dessin à l’écran n’a aucun raccourci tant que vous n’en définissez pas un. Le double clic droit fonctionne tout de suite.

### Ajouter une étiquette parlée

Maintenez la touche **Option** de gauche et parlez pour décrire la forme que vous venez de dessiner. Vos mots apparaissent à côté sous forme de texte. Pour que Dessin à l’écran écoute après chaque forme dessinée, activez **Parler après chaque forme** dans la barre d’outils, et faites une pause pour terminer chaque étiquette.

## Outils

| Outil ou action | Touche |
| --- | --- |
| Flèche | **A** |
| Ligne | **L** |
| Stylo | **P** |
| Surligneur | **H** |
| Rectangle | **R** |
| Cercle | **O** |
| Compteur (marqueurs numérotés) | **N** |
| Texte | **T** |
| Sélection | **V** |
| Gomme | **E** |
| Couleur | **C** |
| Épaisseur du trait | **⌘** + défilement |
| Tableau blanc | **B** |
| Surbrillance du curseur | **K** |
| Enregistrer sous… | **⌘S** |
| Envoyer | **⌘↩** |

La barre d’outils comporte aussi **Annuler**, **Rétablir**, **Effacer**, **Copier dans le presse-papiers** et **Fermer**.

## Réglages

Ouvrez **Réglages → Dessin à l’écran**.

| Réglage | Ce qu’il fait |
| --- | --- |
| **Capturez d’abord une zone** | Sélectionnez une zone avant de dessiner. Désactivez-le pour dessiner directement sur l’écran en direct. Activé par défaut. |
| **Raccourci clavier** | Ouvre ou ferme Dessin à l’écran. Vide par défaut. |
| **Double-clic droit** | Ouvre ou ferme Dessin à l’écran par un rapide double clic droit. Activé par défaut. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| La surcouche ne s’ouvre pas | Vérifiez le **Raccourci clavier** et le **Double-clic droit** dans **Réglages → Dessin à l’écran**, et consultez les [autorisations macOS](/fr/configuration/permissions). |
| Il vous faut seulement la fenêtre entière de l’app | Utilisez plutôt [Appshots](/fr/features/appshots). |

title: "Appshots"

---

Appshots ajoute la fenêtre de l’app au premier plan à votre chat comme contexte. Utilisez-le lorsque vous voulez poser une question sur ce qui est à l’écran sans l’enregistrer dans une base de connaissances.

## Capturer une fenêtre d’app

1. Mettez au premier plan l’app sur laquelle vous voulez poser une question.
2. Appuyez sur votre raccourci Appshots. Appshots n’a pas de raccourci tant que vous n’en définissez pas un sous **Raccourci clavier** dans **Réglages → Appshots**.
3. La fenêtre va dans SmartBar, la Fenêtre de chat ou la Barre latérale de l’app si l’un d’eux est ouvert au premier plan. Sinon, elle va dans Dynamic Island. Un court son d’obturateur se joue.
4. Vérifiez la fenêtre jointe, puis posez une question précise, par exemple « Explique l’erreur dans cette fenêtre. »

## Réglages

Ouvrez **Réglages → Appshots**.

| Réglage | Ce qu’il fait |
| --- | --- |
| **Activer Appshots** | Permet au raccourci d’ajouter la fenêtre de l’app au premier plan. Activé par défaut. |
| **Enregistrer le son** | Joue un court son d’obturateur lorsqu’un Appshot est ajouté. Le son confirme la capture ; vérifiez quand même la pièce jointe avant d’envoyer. |
| **Raccourci clavier** | Le raccourci qui ajoute la fenêtre. Aucun par défaut. Il peut être un ensemble de touches de modification, comme les deux touches **Option** ensemble, ou un raccourci ordinaire. |

## Choisir le bon outil de capture

| Objectif | Utiliser |
| --- | --- |
| Poser une question sur la fenêtre de l’app actuelle | Appshots |
| Attirer l’attention sur une zone avant de demander | [Dessin à l’écran](/fr/features/screen-doodle) |
| Enregistrer le contenu de l’app actuelle pour une recherche ultérieure | [Capture rapide](/fr/features/quick-capture) |
| Extraire le texte d’une image | [OCR](/fr/ai/ocr) |

Le contenu capturé peut être envoyé au modèle que vous utilisez pour la demande. Voir [Compréhension du contexte](/fr/features/context-awareness) pour d’autres façons d’ajouter du contexte.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Aucun contexte n’apparaît | Vérifiez **Réglages → Autorisations**, surtout l’enregistrement de l’écran et l’accessibilité. |
| La mauvaise fenêtre est capturée | Remettez l’app cible au premier plan. Appshots capture la fenêtre d’une autre app, pas les fenêtres propres à Enconvo comme les Réglages. |
| Le raccourci ne fait rien | Vérifiez que **Activer Appshots** est activé, et qu’un **Raccourci clavier** est défini. |
| Le raccourci fait autre chose | Une autre app utilise les mêmes touches. Changez le **Raccourci clavier** dans **Réglages → Appshots**. |

title: "Appshots"

---

Appshots ajoute à votre discussion, comme contexte, la fenêtre de l’app au premier plan. Utilisez-le quand vous voulez poser une question sur quelque chose à l’écran sans l’enregistrer dans une base de connaissances.

## Capturer la fenêtre d’une app

1. Amenez au premier plan l’app sur laquelle vous voulez poser une question.
2. Appuyez sur votre raccourci Appshots. Appshots n’a aucun raccourci tant que vous n’en définissez pas un sous **Raccourci clavier** dans **Réglages → Appshots**.
3. La fenêtre va dans la SmartBar, la Fenêtre de chat ou la Barre latérale de l’app si l’une d’elles est ouverte au premier plan. Sinon, elle va dans la Dynamic Island. Un court son d’obturateur retentit.
4. Vérifiez la fenêtre jointe, puis posez une question précise, par exemple « Expliquez l’erreur dans cette fenêtre. »

## Réglages

Ouvrez **Réglages → Appshots**.

| Réglage | Ce qu’il fait |
| --- | --- |
| **Activer Appshots** | Permet au raccourci d’ajouter la fenêtre de l’app au premier plan. Activé par défaut. |
| **Son de capture** | Joue un court son d’obturateur quand un Appshot est ajouté. Le son confirme la capture ; vérifiez tout de même la pièce jointe avant d’envoyer. |
| **Raccourci clavier** | Le raccourci qui ajoute la fenêtre. Aucun par défaut. Il peut s’agir d’un ensemble de touches de modification, comme les deux touches **Option** ensemble, ou d’un raccourci ordinaire. |

## Choisir le bon outil de capture

| Objectif | Utiliser |
| --- | --- |
| Poser une question sur la fenêtre de l’app actuelle | Appshots |
| Attirer l’attention sur une zone avant de poser une question | [Dessin à l’écran](/fr/features/screen-doodle) |
| Enregistrer le contenu de l’app actuelle pour le rechercher plus tard | [Capture rapide](/fr/features/quick-capture) |
| Extraire du texte d’une image | [OCR](/fr/ai/ocr) |

Le contenu capturé peut être envoyé au modèle que vous utilisez pour la demande. Consultez [Compréhension du contexte](/fr/features/context-awareness) pour d’autres façons d’ajouter du contexte.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Aucun contexte n’apparaît | Vérifiez **Réglages → Autorisations**, en particulier Enregistrement de l’écran et Accessibilité. |
| La mauvaise fenêtre est capturée | Amenez de nouveau l’app cible au premier plan. Appshots capture la fenêtre d’une autre app, pas les fenêtres propres à Enconvo comme les Réglages. |
| Le raccourci ne fait rien | Assurez-vous que **Activer Appshots** est activé et qu’un **Raccourci clavier** est défini. |
| Le raccourci fait autre chose | Une autre app utilise les mêmes touches. Modifiez le **Raccourci clavier** dans **Réglages → Appshots**. |

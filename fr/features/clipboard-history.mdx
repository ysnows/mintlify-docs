---
title: "Historique du presse-papiers, Favoris et Recherche de fichiers"
description: "Recherchez ce que vous avez copié, vos favoris de navigateur et les fichiers de votre Mac depuis un raccourci clavier ou SmartBar."
---

L’Historique du presse-papiers, la Recherche dans les favoris du navigateur et la Recherche de fichiers sont trois listes rapides que vous interrogez en saisissant du texte. Utilisez l’Historique du presse-papiers pour coller quelque chose que vous avez copié plus tôt, la Recherche de favoris pour ouvrir une page enregistrée dans n’importe quel navigateur, et la Recherche de fichiers pour ouvrir un fichier sans passer par le Finder. Chacune s’ouvre avec son propre raccourci clavier, ou depuis SmartBar avec un alias.

## Ouvrir une liste

1. Définissez un raccourci clavier pour la liste dans **Réglages → Raccourci**, ou sur la page de réglages propre à la liste sous **Réglages → Plugins**.
2. Appuyez sur le raccourci. Quand **Le raccourci ouvre une fenêtre** est activé, ce qui est le cas par défaut, la liste s’ouvre dans sa propre fenêtre et SmartBar reste tel quel.
3. Saisissez du texte pour filtrer la liste, atteignez un élément avec les touches fléchées, puis appuyez sur Retour.

Pour ouvrir plutôt une liste dans SmartBar, définissez son **Alias**. Saisissez l’alias puis une espace dans SmartBar, et la liste s’y ouvre. La recherche de SmartBar affiche l’alias de chaque liste.

Vous pouvez aussi mentionner une liste avec `@` dans un chat, et l’Agent la parcourt pour vous.

## Coller depuis l’Historique du presse-papiers

L’Historique du presse-papiers conserve le texte, les images et les fichiers que vous copiez. Vous pouvez épingler vos favoris et filtrer par liens, e-mails, couleurs, images ou fichiers.

1. Ouvrez l’Historique du presse-papiers.
2. Saisissez un mot de ce que vous avez copié.
3. Appuyez sur Retour pour coller l’élément dans l’app que vous utilisiez. Appuyez sur **⌘C** pour le copier à la place. Quand **Touche Retour** est réglée sur copier, **⌘Retour** colle.

Quand vous ouvrez la liste par-dessus l’une des fenêtres d’Enconvo, Retour colle dans la zone de message de cette fenêtre.

Les gestionnaires de mots de passe et Trousseau d’accès sont exclus par défaut, et les copies que les apps marquent comme masquées ou temporaires, comme les mots de passe, ne sont jamais enregistrées.

## Ouvrir un favori

La Recherche dans les favoris du navigateur lit les favoris de Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox et Zen, y compris les profils Firefox et Zen conservés dans un dossier que vous avez choisi. Une recherche porte aussi sur les noms de dossiers.

Appuyez sur Retour pour ouvrir le favori dans le navigateur dont il provient, ou sur **⌘O** pour l’ouvrir dans votre navigateur par défaut. **Touche Retour** inverse les deux.

## Trouver un fichier

La Recherche de fichiers explore par défaut tout votre Mac. Utilisez le menu déroulant de son champ de recherche pour chercher à un seul endroit, pour cette recherche uniquement, comme **Mes dossiers**, **Accueil** ou **Téléchargements**.

Appuyez sur Retour pour ouvrir le fichier, ou sur **⌘Retour** pour l’afficher dans le Finder. **Touche Retour** inverse les deux.

## Réglages

Ouvrez **Réglages → Plugins**, puis **Historique du presse-papiers**, **Favoris du navigateur** ou **Recherche de fichiers**.

| Réglage | Liste | Ce qu’il modifie |
| --- | --- | --- |
| **Alias** | Les trois | Le mot que vous saisissez, suivi d’une espace, dans SmartBar pour y ouvrir la liste. |
| **Le raccourci ouvre une fenêtre** | Les trois | Activé : le raccourci ouvre la liste dans sa propre fenêtre. Désactivé : le raccourci l’ouvre dans SmartBar. Activé par défaut. |
| **Touche Retour** | Les trois | Ce que fait Retour. Historique du presse-papiers : **Coller dans l’app au premier plan** ou **Copier dans le presse-papiers**. Favoris : **Ouvrir dans son navigateur** ou **Ouvrir dans le navigateur par défaut**. Fichiers : **Ouvrir** ou **Afficher dans le Finder**. |
| **Enregistrer l'historique du presse-papiers** | Historique du presse-papiers | Conserve un historique de ce que vous copiez. Le désactiver conserve les éléments déjà enregistrés. |
| **Conserver l'historique pendant** | Historique du presse-papiers | Combien de temps les éléments restent, de **1 jour** à **Toujours**. 3 mois par défaut. Les éléments épinglés ne sont jamais supprimés. |
| **Apps ignorées** | Historique du presse-papiers | Les apps dont les copies ne sont jamais enregistrées, par identifiant de bundle. |
| **Afficher le nom des dossiers** | Favoris | Affiche le dossier de chaque favori. |
| **Navigateurs désactivés** | Favoris | Les navigateurs dont les favoris sont exclus. |
| **Rechercher dans** | Fichiers | L’endroit où la Recherche de fichiers cherche à l’ouverture : **Ce Mac**, **Mes dossiers**, **Accueil**, **Bureau**, **Documents**, **Téléchargements** ou **Applications**. |
| **Dossiers de recherche** | Fichiers | Les dossiers que **Mes dossiers** parcourt. Bureau, Documents et Téléchargements quand la liste est vide. |
| **Afficher les fichiers masqués** | Fichiers | Inclut les fichiers dont le nom commence par un point. |
| **Dossiers exclus** | Fichiers | Les dossiers dont le contenu n’apparaît jamais. |

Un raccourci ou un alias que vous avez défini sur les anciennes versions web de ces listes est conservé.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le raccourci ouvre SmartBar au lieu d’une fenêtre | Activez **Le raccourci ouvre une fenêtre** pour cette liste. |
| Une copie est absente de l’Historique du presse-papiers | Vérifiez **Enregistrer l'historique du presse-papiers** et **Apps ignorées**. Les copies masquées, comme les mots de passe, ne sont jamais enregistrées. |
| Les favoris d’un navigateur sont absents | Vérifiez **Navigateurs désactivés**. |
| Un fichier n’apparaît pas | Vérifiez **Rechercher dans**, **Dossiers exclus** et **Afficher les fichiers masqués**. |

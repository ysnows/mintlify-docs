---
title: "Historique du presse-papiers, favoris et recherche de fichiers"
description: "Cherchez ce que vous avez copié, vos favoris de navigateur et les fichiers de votre Mac depuis un raccourci ou SmartBar."
---

Historique du presse-papiers, Recherche de favoris du navigateur et Recherche de fichiers sont trois listes rapides que vous filtrez en tapant. Utilisez l’historique du presse-papiers pour coller quelque chose copié plus tôt, la recherche de favoris pour ouvrir une page enregistrée dans n’importe quel navigateur, et la recherche de fichiers pour ouvrir un fichier sans Finder. Chacune s’ouvre depuis son propre raccourci, ou depuis SmartBar avec un alias.

## Ouvrir une liste

1. Définissez un raccourci pour la liste dans **Réglages → Raccourci**, ou sur la page de réglages de la liste sous **Réglages → Plugins**.
2. Appuyez sur le raccourci. Avec **Le raccourci ouvre une fenêtre** activé, ce qui est le défaut, la liste s’ouvre dans sa propre fenêtre et SmartBar reste tel quel.
3. Tapez pour filtrer la liste, allez à un élément avec les flèches, et appuyez sur Retour.

Pour ouvrir une liste dans SmartBar à la place, définissez son **Alias**. Tapez l’alias puis un espace dans SmartBar, et la liste s’ouvre là. La recherche SmartBar affiche l’alias de chaque liste.

Vous pouvez aussi mentionner une liste avec `@` dans une discussion, et l’Agent cherche dans cette liste pour vous.

## Coller depuis l’historique du presse-papiers

L’historique du presse-papiers garde le texte, les images et les fichiers que vous copiez. Vous pouvez épingler des favoris et filtrer par liens, e-mails, couleurs, images ou fichiers.

1. Ouvrez l’historique du presse-papiers.
2. Tapez un mot de ce que vous avez copié.
3. Appuyez sur Retour pour coller l’élément dans l’app que vous utilisiez. Appuyez sur **⌘C** pour le copier à la place. Avec **Touche Retour** réglée sur copier, **⌘Retour** colle.

Quand vous ouvrez la liste au-dessus d’une fenêtre d’Enconvo, Retour colle dans la zone de message de cette fenêtre.

Les gestionnaires de mots de passe et Trousseau d’accès sont exclus par défaut, et les copies que les apps marquent comme masquées ou temporaires, comme les mots de passe, ne sont jamais enregistrées.

## Ouvrir un favori

La recherche de favoris du navigateur lit les favoris de Safari, Chrome, Edge, Brave, Arc, Dia, Vivaldi, Opera, Chromium, Comet, Firefox et Zen, y compris les profils Firefox et Zen gardés dans un dossier que vous avez choisi. Une recherche correspond aussi aux noms de dossiers.

Appuyez sur Retour pour ouvrir le favori dans le navigateur d’où il vient, ou sur **⌘O** pour l’ouvrir dans votre navigateur par défaut. **Touche Retour** échange les deux.

## Trouver un fichier

La recherche de fichiers regarde tout votre Mac par défaut. Utilisez le menu déroulant de son champ de recherche pour chercher un seul endroit pour cette recherche, comme **Mes dossiers**, **Accueil** ou **Téléchargements**.

Appuyez sur Retour pour ouvrir le fichier, ou sur **⌘Retour** pour le montrer dans le Finder. **Touche Retour** échange les deux.

## Réglages

Ouvrez **Réglages → Plugins**, puis **Historique du presse-papiers**, **Favoris du navigateur** ou **Recherche de fichiers**.

| Réglage | Liste | Ce que cela change |
| --- | --- | --- |
| **Alias** | Les trois | Le mot que vous tapez, puis un espace, dans SmartBar pour ouvrir la liste là. |
| **Le raccourci ouvre une fenêtre** | Les trois | Activé : le raccourci ouvre la liste dans sa propre fenêtre. Désactivé : le raccourci l’ouvre dans SmartBar. Activé par défaut. |
| **Touche Retour** | Les trois | Ce que fait Retour. Historique du presse-papiers : **Coller dans l’app au premier plan** ou **Copier dans le presse-papiers**. Favoris : **Ouvrir dans son navigateur** ou **Ouvrir dans le navigateur par défaut**. Fichiers : **Ouvrir** ou **Afficher dans le Finder**. |
| **Enregistrer l’historique du presse-papiers** | Historique du presse-papiers | Garde un historique de ce que vous copiez. Le désactiver conserve les éléments déjà enregistrés. |
| **Conserver l’historique pendant** | Historique du presse-papiers | Combien de temps les éléments restent, de **1 jour** à **Toujours**. 3 mois par défaut. Les éléments épinglés ne sont jamais retirés. |
| **Apps ignorées** | Historique du presse-papiers | Apps dont les copies ne sont jamais enregistrées, par identifiant de bundle. |
| **Afficher les noms de dossiers** | Favoris | Affiche le dossier de chaque favori. |
| **Navigateurs désactivés** | Favoris | Navigateurs dont les favoris sont exclus. |
| **Rechercher dans** | Fichiers | Où la recherche de fichiers regarde à l’ouverture : **Ce Mac**, **Mes dossiers**, **Accueil**, **Bureau**, **Documents**, **Téléchargements** ou **Applications**. |
| **Dossiers de recherche** | Fichiers | Les dossiers que **Mes dossiers** cherche. Bureau, Documents et Téléchargements quand c’est vide. |
| **Afficher les fichiers cachés** | Fichiers | Inclut les fichiers dont le nom commence par un point. |
| **Dossiers exclus** | Fichiers | Dossiers dont le contenu n’apparaît jamais. |

Un raccourci ou un alias défini sur les anciennes versions web de ces listes est conservé.

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le raccourci ouvre SmartBar au lieu d’une fenêtre | Activez **Le raccourci ouvre une fenêtre** pour cette liste. |
| Une copie manque dans l’historique du presse-papiers | Vérifiez **Enregistrer l’historique du presse-papiers** et **Apps ignorées**. Les copies masquées, comme les mots de passe, ne sont jamais enregistrées. |
| Les favoris d’un navigateur manquent | Vérifiez **Navigateurs désactivés**. |
| Un fichier n’apparaît pas | Vérifiez **Rechercher dans**, **Dossiers exclus** et **Afficher les fichiers cachés**. |

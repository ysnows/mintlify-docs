Les outils d’écriture sont un ensemble de commandes en un clic pour le texte que vous sélectionnez dans n’importe quelle app. Corrigez les erreurs, changez le ton, raccourcissez ou allongez, expliquez ou résumez, ou transformez le texte en liste ou en tableau, sans quitter l’app où vous écrivez.

## Modifier le texte sélectionné

1. Sélectionnez du texte dans l’app où vous écrivez.
2. Cliquez sur une commande dans [PopBar](/fr/features/popbar), ou ouvrez [SmartBar](/fr/features/smartbar) et cherchez la commande.
3. Lisez le résultat. Lorsque **Surligner les modifications** est activé, le résultat marque ce que la commande a ajouté et retiré.
4. Cliquez sur **Coller** pour remplacer votre sélection, ou copiez le résultat.

Chaque commande conserve la langue de votre texte et ne renvoie que le résultat. **Expliquer** répond aussi dans la langue du texte sélectionné, et traite chaque exécution pour elle-même plutôt que comme la suite d’une précédente. Lorsque le texte sélectionné pose une question ou donne une instruction, la commande modifie ces mots ; elle n’y répond pas.

<Tip>
Activez le **Mode en ligne** pour une commande en laquelle vous avez confiance : elle s’exécute sans fenêtre et colle le résultat directement par-dessus votre sélection. Voir [Modifier une commande](#modifier-une-commande).
</Tip>

## Choisir une commande

| Objectif | Commandes |
| --- | --- |
| Corriger les erreurs | Corriger l’orthographe et la grammaire, Relire |
| Améliorer la formulation | Améliorer l’écriture, Peaufiner, Réécrire, Natif, Édition IA |
| Changer la longueur | Allonger, Raccourcir, Rendre concis |
| Changer le ton | Changer le ton : amical, confiant, décontracté ou professionnel |
| Comprendre le contenu | Expliquer, Résumer, Extraire les points clés |
| Reformater | Convertir en liste, Convertir en tableau |
| E-mail | Peaufiner l’e-mail, Rédiger une réponse |
| Publications sur X | Peaufiner pour X, Tenir en 280 caractères, Transformer en fil, Suggérer une réponse sur X, Suggérer un commentaire de citation sur X |
| Traduire | Traducteur, Traduire la capture d’écran (voir [Traduction](/fr/ai/translate)) |
| Quelque chose à l’écran | Expliquer la capture d’écran |
| Dictée | Peaufiner la dictée, Traduire la dictée, Modifier la dictée, Nettoyage sur l'appareil (voir [Dictée](/fr/features/dictation)) |
| Expression courte | Emoji |

**Natif** réécrit votre texte comme un locuteur natif l’écrirait, dans la même langue. **Peaufiner l’e-mail** conserve votre propre formule d’appel, votre formule de politesse et votre nom, et n’ajoute pas de signature. **Rédiger une réponse** écrit une réponse à l’e-mail sélectionné dans sa langue et son ton, et laisse un court espace réservé entre crochets pour un nom, une date ou une décision qu’elle ne peut pas connaître.

## Modifier une commande

Ouvrez **Réglages → Commandes IA** et choisissez la commande sous **Intégré**. Sa page indique ce que fait la commande, avec **Essayez** pour la lancer d’abord sur un texte.

| Réglage | Ce qu’il change |
| --- | --- |
| **PopBar** | Ajoute la commande à PopBar, ou l’en retire |
| **Surligner les modifications** | Marque ce que la commande a ajouté et retiré dans le résultat |
| **Raccourci clavier** | Lance la commande sur le texte que vous sélectionnez dans n’importe quelle app |
| **Mode en ligne** | S’exécute sans fenêtre et colle le résultat par-dessus votre sélection |
| **Action après la réponse** | Ce que la commande fait de la réponse lorsqu’elle a terminé |
| **Modèle d’IA** | Le modèle que cette commande utilise. Par défaut, elle suit le modèle de toutes les commandes IA |

Les instructions d’une commande intégrée sont en lecture seule. Cliquez sur **Personnaliser** pour créer votre propre copie, que vous pouvez modifier librement.

Les outils d’écriture s’exécutent sur le modèle défini dans **Réglages → Commandes IA → Toutes les commandes**, sauf si une commande choisit le sien. Les mêmes commandes sont aussi listées sous **Réglages → Plugins → Outils d’écriture**, et le bouton **Réglages** d’une fenêtre de résultat ouvre la commande qui l’a produit.

## Obtenir des résultats fiables

Lorsqu’une réécriture peut prendre plusieurs directions, dites à qui le texte s’adresse et ce qu’il doit faire. Nommez ce qui doit rester identique, comme les noms, les dates, les chiffres et les formulations citées.

Comparez toujours le résultat à votre original avant de l’envoyer. Un texte fluide peut encore changer le sens.

Pour une instruction que vous répétez, créez votre propre [commande IA](/fr/features/ai-commands).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une commande n’est pas sur PopBar | Cliquez sur **⌄** à la fin de PopBar, où vont les boutons qui ne tiennent pas, ou activez **PopBar** sur la page de la commande dans **Réglages → Commandes IA** |
| PopBar n’apparaît pas | Voir [Dépannage de PopBar](/fr/features/popbar) |
| Le résultat est dans une langue inattendue | Expliquer répond dans la langue du texte sélectionné. Résumer conserve la langue du texte, sauf si vous définissez sa **Langue des réponses**. Les autres commandes conservent la langue du texte |
| Le résultat a changé le sens | Modifiez-le avant de coller, ou relancez la commande avec votre texte original |

Les Outils d’écriture sont un ensemble de commandes en un clic pour le texte que vous sélectionnez dans n’importe quelle app. Corrigez les erreurs, changez le ton, raccourcissez ou allongez le texte, expliquez-le ou résumez-le, ou transformez-le en liste ou en tableau, sans quitter l’app dans laquelle vous écrivez.

## Modifier le texte sélectionné

1. Sélectionnez du texte dans l’app où vous écrivez.
2. Cliquez sur une commande dans [PopBar](/fr/features/popbar), ou ouvrez la [SmartBar](/fr/features/smartbar) et cherchez la commande.
3. Lisez le résultat. Quand **Surligner les modifications** est activé, le résultat marque ce que la commande a ajouté et supprimé.
4. Cliquez sur **Coller** pour remplacer votre sélection, ou copiez le résultat.

Chaque commande conserve la langue de votre texte et ne répond que par le résultat. **Expliquer** répond aussi dans la langue du texte sélectionné, et traite chaque exécution séparément plutôt que comme la suite d’une précédente. Quand le texte sélectionné pose une question ou donne une instruction, la commande modifie ces mots ; elle n’y répond pas.

<Tip>
Activez le **Mode en ligne** pour une commande en laquelle vous avez confiance : elle s’exécute sans fenêtre et colle le résultat directement sur votre sélection. Voir [Modifier une commande](#modifier-une-commande).
</Tip>

## Choisir une commande

| Objectif | Commandes |
| --- | --- |
| Corriger les erreurs | Corriger l’orthographe et la grammaire, Relire |
| Améliorer la formulation | Améliorer l’écriture, Peaufiner, Réécrire, Natif, Édition IA |
| Changer la longueur | Allonger, Raccourcir, Rendre concis |
| Changer le ton | Changer le ton : amical, assuré, décontracté ou professionnel |
| Comprendre le contenu | Expliquer, Résumer, Extraire les points clés |
| Remettre en forme | Convertir en liste, Convertir en tableau |
| E-mail | Peaufiner l’e-mail, Rédiger une réponse |
| Publications sur X | Peaufiner pour X, Tenir en 280 caractères, Transformer en fil, Suggérer une réponse sur X, Suggérer un commentaire de citation sur X |
| Traduire | Traducteur, Screenshot Translate (voir [Traduction](/fr/ai/translate)) |
| Quelque chose à l’écran | Screenshot Explain |
| Dictée | Dictation Polish, Dictation Translate, Dictation Edit, Nettoyage sur l’appareil (voir [Dictée](/fr/features/dictation)) |
| Expression courte | Emoji |

**Natif** réécrit votre texte comme le ferait un locuteur natif, dans la même langue. **Peaufiner l’e-mail** conserve votre formule d’appel, votre formule de politesse et votre nom, et n’ajoute pas de signature. **Rédiger une réponse** écrit une réponse à l’e-mail sélectionné, dans sa langue et son ton, et laisse un court espace réservé entre crochets pour un nom, une date ou une décision qu’elle ne peut pas connaître.

## Modifier une commande

Ouvrez **Réglages → Commandes IA** et choisissez la commande sous **Intégré**. Sa page montre ce que fait la commande, avec **Essayez** pour l’exécuter d’abord sur un texte.

| Réglage | Ce qu’il modifie |
| --- | --- |
| **PopBar** | Ajoute la commande à PopBar, ou l’en retire |
| **Surligner les modifications** | Marque dans le résultat ce que la commande a ajouté et supprimé |
| **Raccourci clavier** | Exécute la commande sur le texte que vous sélectionnez dans n’importe quelle app |
| **Mode en ligne** | S’exécute sans fenêtre et colle le résultat sur votre sélection |
| **Action après la réponse** | Ce que la commande fait de la réponse une fois terminée |
| **Modèle d’IA** | Le modèle que cette commande utilise. Par défaut, elle suit le modèle de toutes les Commandes IA |

Les instructions d’une commande intégrée sont en lecture seule. Cliquez sur **Personnaliser** pour en faire votre propre copie, que vous pouvez modifier librement.

Les outils d’écriture s’exécutent sur le modèle défini dans **Réglages → Commandes IA → Toutes les commandes**, sauf si une commande choisit le sien. Les mêmes commandes figurent aussi sous **Réglages → Plugins → Outils d’écriture**, et le bouton **Réglages** d’une fenêtre de résultat ouvre la commande qui l’a produit.

## Obtenir des résultats fiables

Quand une reformulation peut aller dans plusieurs directions, indiquez à qui s’adresse le texte et ce qu’il doit accomplir. Nommez ce qui doit rester identique, comme les noms, les dates, les chiffres et les citations.

Comparez toujours le résultat avec votre original avant de l’envoyer. Un texte fluide peut quand même changer le sens.

Pour une instruction que vous répétez, créez votre propre [Commande IA](/fr/features/ai-commands).

## Dépannage

| Problème | Que faire |
| --- | --- |
| Une commande n’est pas dans PopBar | Cliquez sur **⌄** à la fin de PopBar, où vont les boutons qui ne tiennent pas, ou activez **PopBar** sur la page de la commande dans **Réglages → Commandes IA** |
| PopBar n’apparaît pas | Voir le [dépannage de PopBar](/fr/features/popbar) |
| Le résultat est dans une langue inattendue | Expliquer répond dans la langue du texte sélectionné. Résumer conserve la langue du texte, sauf si vous définissez sa **Langue des réponses**. Les autres commandes conservent la langue du texte |
| Le résultat a changé le sens | Modifiez-le avant de le coller, ou relancez la commande avec votre texte d’origine |

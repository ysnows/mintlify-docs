Capture rapide enregistre le contenu de l’app actuelle dans une base de connaissances pour plus tard. Chaque capture garde une capture d’écran de la fenêtre et son texte : pour un navigateur, le contenu de la page, et pour une vidéo YouTube, ses sous-titres. [Appshots](/fr/features/appshots) joint une fenêtre d’app à la question que vous posez maintenant ; Capture rapide crée un élément de base de connaissances que vous conservez.

## Capturer quelque chose à garder

1. Mettez l’app qui contient le contenu au premier plan.
2. Appuyez sur votre raccourci Capture rapide, ou ouvrez l’[Île dynamique](/fr/features/dynamic-island) et cliquez sur **Capture rapide**. Capture rapide n’a pas de raccourci tant que vous n’en définissez pas un sous **Raccourci** dans **Réglages → Capture rapide**.
3. Enconvo prend l’image et affiche sa pilule dès que vous appuyez sur le raccourci, puis enregistre la capture dans la base de connaissances définie dans **Enregistrer dans**, la base de connaissances par défaut sauf si vous en avez choisi une autre. Un court son d’obturateur se joue.
4. La notification indique ce qui a été enregistré et où. Cliquez sur **Ouvrir** pour le voir dans la base de connaissances, ou sur **Annuler** pour retirer la capture.

Si un enregistrement échoue, la notification propose **Réessayer** et **Ignorer**. [Note vocale](/fr/features/voice-notes) a les mêmes **Annuler**, **Réessayer** et **Ignorer**.

L’indexation et le résumé peuvent se terminer un peu après l’apparition de l’élément.

## Réglages

Ouvrez **Réglages → Capture rapide**.

| Réglage | Rôle |
| --- | --- |
| **Activer la capture rapide** | Permet au raccourci d’enregistrer l’app actuelle. Il active ou désactive aussi le raccourci [Note vocale](/fr/features/voice-notes). Activé par défaut. |
| **Enregistrer dans** | La base de connaissances où vont les captures. Les captures ne peuvent pas aller dans la Mémoire. |
| **Son de capture** | Joue un court son d’obturateur quand une capture est enregistrée. |
| **Résumé automatique** | Résume chaque capture avec l’IA. Le résumé s’affiche dans l’aperçu de l’élément et est recherchable. |
| **Raccourci** | Le raccourci qui enregistre l’app actuelle. Aucun par défaut. Ce peut être un double appui sur une touche de modification, comme la touche **Maj** droite, ou un raccourci ordinaire. |

**Résumé automatique** envoie le texte capturé à votre modèle d’IA. Vérifiez les réglages de votre modèle et de votre fournisseur si vous voulez contrôler où le contenu capturé est traité.

### Publications X

La section **X** de la même page règle le fonctionnement de l’[extension de navigateur](/fr/features/browser-extension) Enconvo sur x.com.

| Réglage | Rôle |
| --- | --- |
| **Style de carte** | Affiche les publications enregistrées comme une **Publication** ou une **Capture d’écran**. Changer de style change aussi les publications enregistrées plus tôt. |
| **Quand vous ajoutez un signet sur X** | Ce que fait le bouton de signet de X : **Signet sur X**, **Signet et enregistrer dans Enconvo**, ou **Enregistrer dans Enconvo seulement**. Tant que vous n’avez pas choisi, Enconvo demande au premier signet. Retirer un signet conserve la publication dans Enconvo. |
| **Bouton Demander à Enconvo** | Affiche le bouton Enconvo à côté de Grok dans l’en-tête de chaque publication, pour poser une question sur la publication et ses réponses. |
| **Résumé automatique des publications X** | Résume chaque publication enregistrée et son fil avec l’IA. |
| **Catégories automatiques des publications enregistrées** | Étiquette chaque publication enregistrée avec les sujets dont elle parle. Nécessite d’être connecté. |

## Dépannage

| Problème | Que faire |
| --- | --- |
| Le contenu manque ou est incomplet | Vérifiez les [Autorisations](/fr/configuration/permissions), mettez l’app voulue au premier plan, et essayez un petit exemple bien visible. |
| Vous ne trouvez pas la capture | Vérifiez **Enregistrer dans**, puis ouvrez cette base de connaissances. L’indexation et le résumé peuvent se terminer après la première apparition de l’élément. |
| Le raccourci ne fait rien | Vérifiez que **Activer la capture rapide** est activé, et qu’un **Raccourci** est défini. |

title: "Utilitaires multimédias"
description: "Compressez des images, des vidéos et de l’audio, enregistrez le son d’une vidéo ou téléchargez une vidéo à partir d’un lien."
---

Les Utilitaires multimédias sont des commandes locales pour les tâches courantes sur les médias : alléger des fichiers image, vidéo ou audio, enregistrer la bande-son d’une vidéo ou télécharger une vidéo depuis une page web. Vous les trouvez dans la SmartBar, ou sous **Réglages → Plugins**.

| Commande | Fonction | Enregistre dans |
| --- | --- | --- |
| **Image Compress** | Compresse une ou plusieurs images, ou toutes les images d’un dossier et de ses sous-dossiers, avec une qualité réglable | Remplace les images d’origine |
| **Video Compress** | Allège un fichier vidéo | `~/Downloads` |
| **Audio Compress** | Allège un fichier audio selon la qualité choisie, et conserve sa pochette (MP3, WAV, M4A, AAC, OGG, FLAC) | `~/Downloads` |
| **Extract Audio** | Enregistre la piste audio d’une vidéo, ou de toutes les vidéos d’un dossier, en M4A (MP3 quand la piste ne peut pas être copiée) | `~/.cache/enconvo/transcribe` |
| **Online Video Downloader** | Télécharge la vidéo ou l’audio d’un lien, comme YouTube, TikTok, Instagram, Reddit, X ou Vimeo | `~/Downloads` |

<Warning>
**Image Compress** remplace par défaut vos images d’origine. Pour les conserver, désactivez d’abord **Overwrite Original Image File** dans ses réglages ; les copies compressées vont alors dans un dossier `enconvo-compressed-images` à côté des images.
</Warning>

## Compresser un fichier ou en extraire l’audio

1. Sélectionnez les fichiers dans le Finder, ou joignez-les. Pour Image Compress, vous pouvez aussi choisir un dossier : ses images et celles de ses sous-dossiers sont compressées, et les copies conservent la même arborescence.
2. Ouvrez la SmartBar et lancez la commande.
3. Ouvrez la sortie et vérifiez-la.

Conservez l’original pendant que vous essayez des réglages de compression. Les réglages de chaque commande se trouvent sous **Réglages → Plugins** : **Image Utils** pour Image Compress, et **Media Utils** pour les autres.

| Réglage | Ce qu’il modifie |
| --- | --- |
| **Qualité** | De 0 à 100 ; plus la valeur est élevée, plus la qualité est conservée et plus le fichier est gros. 80 par défaut |
| **Chemin du dossier de destination** | Où va le fichier compressé : un chemin absolu, ou un chemin relatif au fichier |
| **Overwrite Original … File** | Remplace le fichier d’origine. Activé par défaut pour les images, désactivé pour la vidéo et l’audio |

## Télécharger une vidéo

1. Ouvrez la page de la vidéo dans votre navigateur, ou copiez son lien.
2. Lancez **Online Video Downloader** depuis la SmartBar. Il prend le lien de l’onglet actif du navigateur, ou d’un lien que vous saisissez.
3. Suivez la progression dans la Dynamic Island, où vous pouvez annuler. Quand c’est terminé, cliquez sur **Afficher dans le Finder**.

Le téléchargement est enregistré dans votre historique de discussions, et un fichier déjà téléchargé est réutilisé au lieu d’être récupéré à nouveau. Le fonctionnement avec un site dépend du site et de ce qu’il vous permet d’atteindre. Ne téléchargez que du contenu que vous avez le droit d’enregistrer.

| Réglage | Ce qu’il modifie |
| --- | --- |
| **Output Directory** | Où vont les téléchargements. `~/Downloads` par défaut |
| **Audio Only** | Télécharge uniquement l’audio |
| **Favorite Resolution** | La résolution à télécharger, de **Best** (par défaut) jusqu’à 144p |
| **Force Convert to Compatible MP4** | Convertit la vidéo en MP4 lisible partout. Activé par défaut ; cela demande du temps et du processeur en plus |
| **Use Browser Cookies** | Se connecte avec les cookies de votre navigateur, pour les vidéos que vous seul pouvez voir. Choisissez le navigateur dans **Navigateur** |

## Dépannage

| Problème | Que faire |
| --- | --- |
| **No images to compress** | Sélectionnez les images dans le Finder ou joignez-les, puis relancez la commande |
| Une conversion échoue | Vérifiez le format du fichier, que le dossier de sortie est accessible en écriture et que vous avez de l’espace disque libre |
| Une vidéo privée ne se télécharge pas | Activez **Use Browser Cookies** et choisissez le navigateur dans lequel vous êtes connecté |
| Les téléchargements depuis un site cessent de fonctionner | Lisez l’erreur et mettez le plugin à jour avant de réessayer. Les sites web changent leurs formats et leurs règles d’accès |

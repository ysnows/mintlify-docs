title: "Extensions de navigateur"
description: "Installez l’extension Enconvo Companion pour qu’Enconvo puisse travailler dans votre vrai navigateur, avec vos connexions, vos cookies et vos extensions."
---

L’extension de navigateur Enconvo, Enconvo Companion, permet à Enconvo de piloter votre vrai navigateur lorsqu’une tâche a besoin de l’état connecté de celui-ci. Utilisez-la pour des sites comme LinkedIn, Gmail, Salesforce, des tableaux de bord ou des outils internes, où vos cookies et vos extensions de navigateur comptent. Les Réglages l’appellent **Compagnon du navigateur**.

Pour des pages publiques, des aperçus locaux ou des workflows qui ne doivent pas toucher votre profil de navigateur personnel, utilisez plutôt l’automatisation de navigateur isolée.

## Installer l’extension

<Steps>
  <Step title="Installer l’extension">
    Ouvrez **Réglages → Utilisation du navigateur** et cliquez sur **Installer le compagnon de navigateur** dans **Extensions de navigateur**. La page de l’extension sur le Chrome Web Store s’ouvre. Vous pouvez aussi l’installer depuis la boutique d’extensions de votre navigateur. Elle fonctionne dans Chrome, Edge, Brave, Arc, Vivaldi, Opera et Firefox. Le [tutoriel vidéo sur l’Utilisation de l’ordinateur](https://youtu.be/0CbQA7d8zqU?t=33) montre l’installation dans Chrome.
  </Step>
  <Step title="Garder le navigateur ouvert">
    L’extension se connecte toute seule à Enconvo, via `ws://localhost:11225`.
  </Step>
  <Step title="Vérifier la fenêtre contextuelle">
    Cliquez sur l’icône de l’extension. La fenêtre contextuelle affiche **Connected Chrome**, **Connected Edge**, **Connected Firefox**, ou le nom du navigateur dans lequel vous êtes.
  </Step>
  <Step title="Lancer une tâche de navigateur">
    Demandez à Enconvo de lire, de cliquer, de saisir, de faire une capture d’écran ou de gérer les onglets dans le navigateur.
  </Step>
</Steps>

## La fenêtre contextuelle

| Élément | Ce qu’il affiche |
| --- | --- |
| État de la connexion | Si l’extension de ce navigateur est connectée à Enconvo |
| Navigateur actuel | Le navigateur sous lequel cette extension est connectée, comme Chrome, Edge, Brave ou Firefox |
| Navigateurs connectés | Les autres navigateurs dont l’extension est connectée à Enconvo en ce moment |
| Version | La version installée de l’extension |
| **En savoir plus** | Ouvre cette page |

Si la fenêtre contextuelle indique une déconnexion, redémarrez Enconvo et actualisez le navigateur. Si la connexion ne se fait toujours pas, désactivez puis réactivez l’extension.

## Utiliser plusieurs navigateurs

Enconvo peut se connecter à plusieurs navigateurs à la fois. Lorsqu’une tâche ne nomme aucun navigateur, Enconvo en choisit un dans cet ordre :

1. Le **Default Browser** que vous avez choisi dans les réglages de l’Utilisation du navigateur (**Réglages → Utilisation du navigateur**, puis **Réglages** dans le menu **⋯**).
2. Le navigateur par défaut de votre Mac.
3. Le navigateur connecté que vous avez utilisé le plus récemment.

Les API d’automatisation peuvent aussi nommer le navigateur :

```json
{
  "browser": "edge"
}
```

Les valeurs courantes comprennent `chrome`, `google_chrome`, `edge`, `brave_browser`, `arc`, `vivaldi`, `opera` et `firefox`.

## Rester sur le bon onglet

Quand une tâche de navigateur démarre, Enconvo note le navigateur et l’onglet dans lesquels elle travaille. Les étapes suivantes restent sur cet onglet autant que possible, même si la page ouvre une fenêtre contextuelle, se recharge ou perd le focus.

Pour de meilleurs résultats :

- Gardez l’onglet ouvert jusqu’à la fin de la tâche.
- Nommez le navigateur lorsque plusieurs sont connectés.
- Dites « utilise l’onglet actuel » quand vous voulez qu’Enconvo agisse sur la page que vous avez sous les yeux.
- Demandez à regarder à nouveau la page après une navigation ou l’envoi d’un formulaire.

## Accès aux sites web et sécurité

Les pages web peuvent contenir des instructions que vous n’avez pas écrites. Sur les pages sensibles, vérifiez le site et l’action avant de laisser Enconvo continuer.

L’extension utilise les autorisations du navigateur pour lire les pages, cliquer, saisir, faire des captures d’écran, voir les onglets et lire les cookies lorsqu’une tâche en a besoin. Traitez les pages connectées, l’historique du navigateur et les outils internes comme des données sensibles.

## Dépannage

| Problème | Que faire |
| --- | --- |
| La fenêtre contextuelle indique une déconnexion | Vérifiez qu’Enconvo est en cours d’exécution, redémarrez le navigateur, puis désactivez et réactivez l’extension. Vérifiez que rien ne bloque `localhost:11225`. |
| Le mauvais navigateur est piloté | Définissez **Default Browser** dans les réglages de l’Utilisation du navigateur, ou indiquez une valeur de navigateur telle que `edge`, `chrome` ou `firefox` dans l’action de navigateur. |
| Connecté, mais une page ne peut pas être pilotée | Les pages du navigateur comme `chrome://` ne peuvent pas être pilotées. Les pages avec une politique de sécurité de contenu stricte, un Shadow DOM fermé et les invites d’autorisation du navigateur peuvent aussi poser problème. |
| Un envoi de fichier ne fonctionne pas | Sur la page de détails de l’extension dans votre navigateur, activez l’accès aux URL de fichiers. Les tâches qui envoient des fichiers locaux ou ouvrent des pages issues de fichiers en ont besoin. |

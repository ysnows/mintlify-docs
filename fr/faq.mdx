## Premiers pas

<AccordionGroup>
  <Accordion title="Sur quels Mac Enconvo fonctionne-t-il ?">
    macOS 14 ou ultérieur, sur Apple Silicon et Intel. Certaines fonctionnalités sur l’appareil, comme [LLM local (MLX)](/fr/providers/mlx), nécessitent Apple Silicon. Voir [Installation](/fr/installation).
  </Accordion>
  <Accordion title="Ai-je besoin d’une clé API ?">
    Non. Connectez-vous à votre compte Enconvo et [Enconvo Cloud](/fr/providers/enconvo) fonctionne sans clé. Vous pouvez aussi vous connecter avec un abonnement que vous payez déjà, comme ChatGPT ou Claude, ajouter votre propre clé API, ou exécuter un modèle sur votre Mac. Voir [Fournisseurs](/fr/providers/overview).
  </Accordion>
  <Accordion title="En quoi payer Enconvo diffère-t-il de payer l’IA ?">
    Une licence débloque l’app. L’IA est facturée là où elle s’exécute : les points Enconvo Cloud, votre compte chez le fournisseur, ou votre propre Mac. Voir [Offres et tarifs](/fr/pricing).
  </Accordion>
  <Accordion title="Puis-je utiliser Enconvo dans ma langue ?">
    Oui. Choisissez l’une des douze langues d’interface, ukrainien et russe compris, dans **Langue de l’app** sous **Réglages → Général → Langue**. Les Agents répondent dans votre **Langue des réponses**, que vous réglez au même endroit. Voir [Langue, apparence et recherche dans les réglages](/fr/configuration/appearance-language).
  </Accordion>
  <Accordion title="Pourquoi Enconvo demande-t-il une autorisation quand j’utilise une fonctionnalité ?">
    Enconvo ne demande pas les autorisations macOS au lancement. Il les demande la première fois que vous utilisez une fonctionnalité qui en a besoin, et nomme cette fonctionnalité. Cochez **Ne plus demander** pour empêcher une fonctionnalité de demander. Voir [Autorisations macOS](/fr/configuration/permissions).
  </Accordion>
  <Accordion title="Une fonctionnalité de ces docs est absente de mon app. Pourquoi ?">
    Certaines fonctionnalités arrivent d’abord sur le canal Bêta. Vérifiez votre version et votre [canal de mise à jour](/fr/configuration/updates), puis cherchez la fonctionnalité dans le [Répertoire des fonctionnalités](/fr/reference/feature-directory).
  </Accordion>
</AccordionGroup>

## Modèles

<AccordionGroup>
  <Accordion title="Quel modèle dois-je utiliser ?">
    Si vous hésitez, gardez [Auto Route](/fr/providers/auto-route) : il choisit un modèle pour chaque message. Pour en choisir un vous-même, voir [Choisir un modèle](/fr/ai/model-selection-guide).
  </Accordion>
  <Accordion title="J’ai changé le modèle par défaut. Pourquoi mon chat utilise-t-il encore l’ancien ?">
    Un chat garde le modèle avec lequel il a démarré jusqu’à ce que vous le changiez dans ce chat. Les Projets et les Agents ont aussi leurs propres valeurs par défaut. Voir [Choisir un modèle](/fr/ai/model-selection-guide).
  </Accordion>
  <Accordion title="Un modèle local garde-t-il tout hors ligne ?">
    Seulement les étapes qui s’exécutent chez des fournisseurs locaux. La recherche web, les serveurs MCP distants, la reconnaissance vocale dans le cloud et les embeddings dans le cloud envoient quand même des données hors de votre Mac. Voir [Modèles locaux](/fr/ai/local-llm) et [Confidentialité et sécurité](/fr/configuration/privacy-security).
  </Accordion>
</AccordionGroup>

## Voix

<AccordionGroup>
  <Accordion title="Quelle est la différence entre Dictée, Commande vocale et Live Talk ?">
    [Dictée](/fr/features/dictation) saisit ce que vous dites dans l’app que vous utilisez. Commande vocale envoie ce que vous dites à un Agent comme requête. [Live Talk](/fr/features/live-voice) est une conversation parlée en va-et-vient avec un Agent.
  </Accordion>
  <Accordion title="Enconvo peut-il enregistrer et transcrire des réunions ?">
    Oui. [L’enregistrement de réunion](/fr/features/meeting-recording) enregistre et transcrit au fil de l’eau, et [Transcription](/fr/features/transcription) fonctionne sur les fichiers audio et vidéo que vous avez déjà.
  </Accordion>
</AccordionGroup>

## Contexte et connaissances

<AccordionGroup>
  <Accordion title="Quelle est la différence entre Appshots et Capture rapide ?">
    [Appshots](/fr/features/appshots) joint à une question la fenêtre de l’app que vous regardez. [Capture rapide](/fr/features/quick-capture) enregistre ce qui est à l’écran dans une base de connaissances pour plus tard.
  </Accordion>
  <Accordion title="Quelle est la différence entre la Mémoire et la Base de connaissances ?">
    La [Mémoire](/fr/ai/memory) contient les faits que les Agents apprennent sur vous et réutilisent. La [Base de connaissances](/fr/ai/knowledge-base) contient les documents que vous ajoutez, et les Agents y cherchent des réponses. Les deux se trouvent dans la Base de connaissances : l’interrupteur **Base de connaissances** / **Mémoire** en haut de sa colonne permet de passer de l’une à l’autre.
  </Accordion>
  <Accordion title="D’autres apps d’IA peuvent-elles utiliser mes bases de connaissances Enconvo ?">
    Oui, via [MCP de la Base de connaissances](/fr/advanced/knowledge-base-mcp), que vous activez et que vous limitez aux bases de connaissances de votre choix.
  </Accordion>
</AccordionGroup>

## Agents et automatisation

<AccordionGroup>
  <Accordion title="Les Agents peuvent-ils utiliser les outils d’autres apps et services ?">
    Oui, via les [plugins](/fr/extensions/overview), les [Compétences](/fr/configuration/skills) et les [serveurs MCP](/fr/features/mcp). Les Agents peuvent aussi utiliser votre [navigateur](/fr/features/browser-control) et vos [apps](/fr/features/computer-use) lorsque vous l’autorisez.
  </Accordion>
  <Accordion title="Puis-je limiter ce que les commandes d’un Agent peuvent toucher ?">
    Oui. Activez **Bac à sable** dans la pastille **Autorisations** de l’Agent : ses commandes ne peuvent alors modifier que le dossier de travail et le dossier temporaire, et ne peuvent ni lire vos clés ni contrôler d’autres apps. Voir [Bac à sable de l’Agent](/fr/configuration/sandbox).
  </Accordion>
  <Accordion title="Des tâches peuvent-elles s’exécuter pendant mon absence ?">
    Oui. Les [Tâches planifiées](/fr/workflows/scheduled-jobs) s’exécutent selon un calendrier tant qu’Enconvo est lancé et que votre Mac est éveillé. Connectez un [canal de messagerie instantanée](/fr/integrations/messaging) pour recevoir les résultats dans une app de chat.
  </Accordion>
</AccordionGroup>

## Aide

<AccordionGroup>
  <Accordion title="Où signaler un problème ?">
    Posez la question sur [Discord](https://discord.gg/jYsdVRRK2k) avec votre version d’Enconvo, ce que vous avez fait et ce qui s’est passé, ou utilisez **Donner son avis** dans le menu de la barre des menus. Enconvo Feedback vous permet de vous connecter avec **Continue with Apple**. Retirez d’abord le contenu privé et les clés des captures d’écran et des journaux. Voir [Dépannage](/fr/getting-started/troubleshooting).
  </Accordion>
</AccordionGroup>

## Premiers pas

<AccordionGroup>
  <Accordion title="Sur quels Mac Enconvo fonctionne-t-il ?">
    macOS 14 ou une version ultérieure, sur Apple Silicon et Intel. Certaines fonctions sur l’appareil, comme [LLM local (MLX)](/fr/providers/mlx), nécessitent Apple Silicon. Voir [Installation](/fr/installation).
  </Accordion>
  <Accordion title="Ai-je besoin d’une clé API ?">
    Non. Connectez-vous à votre compte Enconvo et [Enconvo Cloud](/fr/providers/enconvo) fonctionne sans clé. Vous pouvez aussi vous connecter avec un forfait que vous payez déjà, comme ChatGPT ou Claude, ajouter votre propre clé API, ou exécuter un modèle sur votre Mac. Voir [Fournisseurs](/fr/providers/overview).
  </Accordion>
  <Accordion title="En quoi payer Enconvo diffère-t-il de payer l’IA ?">
    Une licence débloque l’app. L’IA est facturée là où elle s’exécute : points Enconvo Cloud, compte de votre fournisseur, ou votre propre Mac. Voir [Forfaits et tarifs](/fr/pricing).
  </Accordion>
  <Accordion title="Puis-je utiliser Enconvo dans ma langue ?">
    Oui. Choisissez l’une des douze langues d’interface, ukrainien et russe compris, dans **Langue de l’app** sous **Réglages → Général → Langue**. Les agents répondent dans votre **Langue des réponses**, que vous définissez au même endroit. Voir [Langue, apparence et recherche dans les réglages](/fr/configuration/appearance-language).
  </Accordion>
  <Accordion title="Pourquoi Enconvo demande-t-il une autorisation lorsque j’utilise une fonction ?">
    Enconvo ne demande pas les autorisations macOS au lancement. Il les demande la première fois que vous utilisez une fonction qui en a besoin, et nomme la fonction. Cochez **Ne plus demander** pour qu’une fonction cesse de demander. Voir [Autorisations macOS](/fr/configuration/permissions).
  </Accordion>
  <Accordion title="Une fonction de cette documentation manque dans mon app. Pourquoi ?">
    Certaines fonctions arrivent d’abord sur le canal Bêta. Vérifiez votre version et le [canal de mise à jour](/fr/configuration/updates), puis cherchez la fonction dans le [Répertoire des fonctions](/fr/reference/feature-directory).
  </Accordion>
</AccordionGroup>

## Modèles

<AccordionGroup>
  <Accordion title="Quel modèle dois-je utiliser ?">
    Si vous n’êtes pas sûr, gardez [Auto Route](/fr/providers/auto-route) : il choisit un modèle pour chaque message. Pour en choisir un vous-même, voir [Choisir un modèle](/fr/ai/model-selection-guide).
  </Accordion>
  <Accordion title="J’ai changé le modèle par défaut. Pourquoi mon chat utilise-t-il encore l’ancien ?">
    Un chat conserve le modèle avec lequel il a commencé jusqu’à ce que vous le changiez dans ce chat. Les projets et les agents ont aussi leurs propres valeurs par défaut. Voir [Choisir un modèle](/fr/ai/model-selection-guide).
  </Accordion>
  <Accordion title="Un modèle local garde-t-il tout hors ligne ?">
    Seulement les étapes qui s’exécutent sur des fournisseurs locaux. La recherche web, les serveurs MCP distants, la parole dans le cloud et les embeddings cloud envoient encore des données hors de votre Mac. Voir [Modèles locaux](/fr/ai/local-llm) et [Confidentialité et sécurité](/fr/configuration/privacy-security).
  </Accordion>
</AccordionGroup>

## Voix

<AccordionGroup>
  <Accordion title="Quelle est la différence entre Dictée, Commande vocale et Live Talk ?">
    La [Dictée](/fr/features/dictation) saisit ce que vous dites dans l’app que vous utilisez. La commande vocale envoie ce que vous dites à un agent comme une demande. [Live Talk](/fr/features/live-voice) est une conversation parlée, dans les deux sens, avec un agent.
  </Accordion>
  <Accordion title="Enconvo peut-il enregistrer et transcrire des réunions ?">
    Oui. L’[enregistrement de réunion](/fr/features/meeting-recording) enregistre et transcrit au fil de l’eau, et la [Transcription](/fr/features/transcription) s’applique aux fichiers audio et vidéo que vous avez déjà.
  </Accordion>
</AccordionGroup>

## Contexte et connaissances

<AccordionGroup>
  <Accordion title="Quelle est la différence entre Appshots et Capture rapide ?">
    [Appshots](/fr/features/appshots) joint la fenêtre de l’app que vous regardez à une question. La [Capture rapide](/fr/features/quick-capture) enregistre ce qui est à l’écran dans une base de connaissances pour plus tard.
  </Accordion>
  <Accordion title="Quelle est la différence entre Mémoire et Base de connaissances ?">
    La [Mémoire](/fr/ai/memory) contient les faits que les agents apprennent sur vous et réutilisent. La [Base de connaissances](/fr/ai/knowledge-base) contient les documents que vous ajoutez, et les agents les consultent pour répondre. Les deux vivent dans la base de connaissances : l’interrupteur **Base de connaissances** / **Mémoire** en haut de sa colonne passe de l’une à l’autre.
  </Accordion>
  <Accordion title="D’autres apps d’IA peuvent-elles utiliser mes bases de connaissances Enconvo ?">
    Oui, via [MCP de la base de connaissances](/fr/advanced/knowledge-base-mcp), que vous activez et limitez aux bases de connaissances de votre choix.
  </Accordion>
</AccordionGroup>

## Agents et automatisation

<AccordionGroup>
  <Accordion title="Les agents peuvent-ils utiliser des outils d’autres apps et services ?">
    Oui, via les [plugins](/fr/extensions/overview), les [Compétences](/fr/configuration/skills) et les [serveurs MCP](/fr/features/mcp). Les agents peuvent aussi utiliser votre [navigateur](/fr/features/browser-control) et vos [apps](/fr/features/computer-use) lorsque vous l’autorisez.
  </Accordion>
  <Accordion title="Puis-je limiter ce que les commandes d’un agent peuvent toucher ?">
    Oui. Activez **Bac à sable** dans la puce **Autorisations** de l’agent : ses commandes ne peuvent modifier que le dossier de travail et les fichiers temporaires, et ne peuvent ni lire vos clés ni contrôler d’autres apps. Voir [Bac à sable de l’agent](/fr/configuration/sandbox).
  </Accordion>
  <Accordion title="Les tâches peuvent-elles s’exécuter en mon absence ?">
    Oui. Les [automatisations](/fr/workflows/scheduled-jobs) s’exécutent selon un calendrier tant qu’Enconvo est ouvert et que votre Mac est éveillé. Connectez un [canal de messagerie instantanée](/fr/integrations/messaging) pour recevoir les résultats dans une app de chat.
  </Accordion>
</AccordionGroup>

## Aide

<AccordionGroup>
  <Accordion title="Où signaler un problème ?">
    Posez la question sur [Discord](https://discord.gg/jYsdVRRK2k) avec votre version d’Enconvo, ce que vous avez fait et ce qui s’est passé, ou utilisez **Donner son avis** dans le menu de la barre de menus. Donner son avis Enconvo permet de se connecter avec **Continuer avec Apple**. Retirez d’abord le contenu privé et les clés des captures d’écran et des journaux. Voir [Dépannage](/fr/getting-started/troubleshooting).
  </Accordion>
</AccordionGroup>

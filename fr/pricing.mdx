Enconvo sépare l’app de l’IA qu’elle appelle. Une licence débloque l’app. L’IA peut venir des points Enconvo Cloud, de votre propre clé API, d’un abonnement chez un fournisseur auquel vous vous connectez, ou d’un modèle sur votre Mac, et chacune de ces options est facturée à son propre endroit. Consultez **Réglages → Compte** et le site web d’Enconvo pour connaître les offres et les prix que votre compte peut obtenir aujourd’hui.

## Les façons de payer l’IA

| Accès | Ce qu’il couvre | Où voir la consommation |
| --- | --- | --- |
| Licence à vie Enconvo | L’accès aux fonctionnalités de l’app | **Licence à vie** dans **Réglages → Compte** |
| Offre Enconvo Cloud | Les modèles et services Cloud, payés en points | **Réglages → Utilisation des points** |
| Votre propre clé API | Les requêtes envoyées à ce fournisseur | Le compte API du fournisseur |
| Un abonnement chez un fournisseur auquel vous vous connectez | Les fonctionnalités et les limites prises en charge par l’abonnement | La page du fournisseur dans les Réglages |
| Modèles locaux | S’exécutent sur la puissance de calcul, la mémoire et le stockage de votre Mac, plus les téléchargements de modèles | Votre Mac |

L’achat d’une licence de l’app n’ajoute aucun crédit API payant chez un fournisseur. L’abonnement de chat d’un fournisseur n’inclut pas non plus toutes les API de ce fournisseur.

## Les offres Enconvo

- **Licence à vie** : un achat unique de l’app, en niveaux Standard et Premium, avec des points offerts. Utilisez l’IA avec vos propres clés API autant que vous le souhaitez. Teams est la licence à vie pour les organisations : vous achetez des Seats et vous attribuez chacun par e-mail. Voir [Teams](/fr/configuration/account).
- **Enconvo Cloud** : une offre mensuelle ou annuelle aux niveaux Plus, Pro et Max. Elle ajoute des points chaque mois et des modèles Cloud qui ne demandent aucune clé API.
- **Essai Standard** : un compte gratuit peut obtenir un essai Standard unique de 7 jours, sans carte bancaire. Lorsqu’il est proposé, **Démarrer l’essai** apparaît dans **Réglages → Compte**.
- **Codes** : les codes de licence et les codes d’essai s’activent dans **Réglages → Utiliser un code**. Un code de licence Teams fait de votre compte l’administrateur d’équipe des Seats du code, avec 50 000 points Cloud par Seat.

Les licences à vie s’appellent toujours Standard et Premium, afin de ne pas partager de nom avec les offres Cloud Plus et Pro.

Pour connaître les offres et les prix actuels :

- [Site web d’Enconvo](https://www.enconvo.com)
- [Offre Enconvo Cloud](https://www.enconvo.com/cloud-plan)
- [Tarifs des modèles Cloud](https://www.enconvo.com/cloud-pricing)

## Comment les points Cloud sont utilisés

Les points d’abonnement sont utilisés en premier. Ils reviennent au montant de votre offre à chaque renouvellement. Les points de recharge, issus des packs de recharge et des licences à vie, n’expirent jamais.

Le coût d’une requête dépend du modèle et de la méthode d’accès que la fonctionnalité utilise réellement. Le texte, les images, la vidéo, la transcription, les embeddings et la voix en temps réel peuvent chacun avoir un prix différent.

## Vérifier une consommation inattendue

1. Ouvrez **Réglages → Utilisation des points** pour Enconvo Cloud, ou la page de consommation du fournisseur pour vos propres clés API.
2. Ouvrez **Réglages → Statistiques d’utilisation** pour voir le coût estimé, les tokens et les requêtes par modèle, par fournisseur et par fonctionnalité.
3. Cherchez les tâches planifiées, les tâches de longue durée, la recherche documentaire et les requêtes de génération qui partagent le même profil de fournisseur.

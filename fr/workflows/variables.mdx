---
title: "Variables"
description: "Insérez votre saisie actuelle, le texte sélectionné, le contexte de l'application ou la date dans les prompts et les autres champs qui acceptent des modèles."
---

Les variables insèrent des valeurs qui changent à chaque fois, comme le texte saisi dans SmartBar, le texte sélectionné dans une autre application ou la date du jour. Utilisez-les dans les prompts et les préférences qui prennent en charge les modèles, afin qu'une Commande IA, une instruction d'Agent ou un flux de travail s'applique à ce que vous avez sous les yeux. Ouvrez **Réglages → Variables** pour parcourir les variables disponibles.

## Variables disponibles

| Variable | Valeur fournie |
| --- | --- |
| Input Text | Saisie actuelle de SmartBar |
| Selection Text | Texte sélectionné dans l'application en cours |
| Latest Clipboard | Contenu le plus récent du presse-papiers |
| Active Application | Informations sur l'application au premier plan |
| Active Application Screenshot | Image de la fenêtre au premier plan |
| Active Screen Screenshot | Image de l'écran actif |
| Focused Window Content | Contenu extrait de la fenêtre active |
| Browser Active Tab | URL de l'onglet actif et contenu de page disponible |
| Current Folder | Le dossier ouvert dans le Finder |
| Selected Files | Fichiers sélectionnés dans le Finder |
| History Messages | Historique de la conversation en cours |
| Now | Date et heure actuelles |
| Your Language | La langue que vous lisez : votre **Langue des réponses**, ou la langue du système quand elle est sur Auto |
| Opened Applications | Informations sur les applications en cours d'exécution |
| Opened Application Names | Noms des applications en cours d'exécution |

## Utiliser une variable

1. Ouvrez le champ de la Commande IA, de l'instruction d'Agent ou du flux de travail que vous voulez personnaliser.
2. Vérifiez que le champ prend en charge les variables ; utilisez son sélecteur s'il en a un.
3. Insérez la valeur dont vous avez besoin et testez avec un contenu d'exemple sans conséquence.
4. Vérifiez si une saisie vide ou une autorisation manquante modifie le résultat.

Un prompt textuel peut utiliser des noms de modèle pris en charge, tels que :

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Les variables utilisables dépendent de la commande et du contexte, et tous les champs de texte n'évaluent pas les modèles. Les captures d'écran et le contenu des applications peuvent nécessiter des autorisations macOS et un modèle qui accepte ce type d'entrée.

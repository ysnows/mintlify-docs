---
title: "Variables"
description: "Insérez votre saisie actuelle, le texte sélectionné, le contexte de l’app ou la date dans les prompts et les autres champs qui acceptent des modèles."
---

Les variables remplissent des valeurs qui changent à chaque fois, comme le texte saisi dans SmartBar, le texte sélectionné dans une autre app, ou la date du jour. Utilisez-les dans les prompts et les préférences qui prennent en charge les modèles, pour qu’une Commande IA, une instruction d’Agent ou un flux de travail s’applique à ce que vous avez devant vous. Ouvrez **Réglages → Variables** pour parcourir les variables disponibles.

## Variables disponibles

| Variable | Valeur fournie |
| --- | --- |
| Input Text | Saisie actuelle de SmartBar |
| Selection Text | Texte sélectionné dans l’app actuelle |
| Latest Clipboard | Contenu le plus récent du presse-papiers |
| Active Application | Informations sur l’app au premier plan |
| Active Application Screenshot | Image de la fenêtre au premier plan |
| Active Screen Screenshot | Image de l’écran actif |
| Focused Window Content | Contenu extrait de la fenêtre active |
| Browser Active Tab | URL de l’onglet actif et contenu de page disponible |
| Current Folder | Dossier ouvert dans le Finder |
| Selected Files | Fichiers sélectionnés dans le Finder |
| History Messages | Historique de la conversation actuelle |
| Now | Date et heure actuelles |
| Your Language | La langue que vous lisez : votre **Langue des réponses**, ou la langue du système lorsqu’elle est sur Auto |
| Opened Applications | Informations sur les apps en cours d’exécution |
| Opened Application Names | Noms des apps en cours d’exécution |

## Utiliser une variable

1. Ouvrez la Commande IA, l’instruction d’Agent ou le champ de flux de travail à personnaliser.
2. Vérifiez que le champ prend en charge les variables ; utilisez son sélecteur lorsqu’il en a un.
3. Insérez la valeur dont vous avez besoin et testez avec un contenu d’exemple inoffensif.
4. Vérifiez si une saisie vide ou une autorisation manquante change le résultat.

Un prompt texte peut utiliser des noms de modèles pris en charge, par exemple :

```text
Today is {{ now }}.
Rewrite the following input as a concise checklist:
{{ input_text }}
```

Les variables utilisables dépendent de la commande et du contexte, et tous les champs de texte n’évaluent pas les modèles. Les captures d’écran et le contenu des apps peuvent nécessiter des autorisations macOS et un modèle qui accepte ce type d’entrée.
